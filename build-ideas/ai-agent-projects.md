# AI Agent Projects

This list contains project templates and concepts to expand your portfolio and master this specific developer area.

### Hacker News Research Agent

*   **Difficulty**: Intermediate
*   **Stack**: `Python, LangGraph, DuckDuckGo API`
*   **What to Build**: A state-based agent that monitors Hacker News stories, fetches linked articles, summarizes main points, and creates markdown reports.
*   **Why It Matters**: Demonstrates multi-step loops and StateGraph state management.
*   **Recommended Vault Resources**: [agent-frameworks/](../workspace-archive/agent-frameworks/README.md)
*   **Portfolio Angle**: Shows you can construct production-grade state machines.
*   **Monetization Angle**: Premium daily tech newsletter subscription.
