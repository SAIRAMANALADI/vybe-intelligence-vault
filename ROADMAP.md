# Roadmap

This roadmap outlines the past, present, and future direction of the Vybe Intelligence Vault. 

---

## Current Focus

- **Auto-updating AI intelligence vault**: Automated backend ingestion running on scheduled loops.
- **Workspace archive**: Flattened, classified developer files structured across thematic categories.
- **Developer stacks**: Focused coverage of AI agents, RAG, Model Context Protocol (MCP), templates, and prompts.
- **Public safety scan**: Pre-push verification scanner ensuring zero credential or private file exposure.
- **GitHub Actions scheduled sync**: Automated sync cycles pushing updates directly to the vault.

## Next Phase

- **Enhanced search index**: Advanced text parsing generating richer machine-readable and human-readable indexes.
- **Curated best-of pages**: Focused developer highlights listing top framework libraries and implementations.
- **Structured learning paths**: Refined step-by-step guides enabling rapid onboarding for specific stacks.
- **Refined build ideas**: Practical portfolio project plans mapped to level-appropriate difficulty tiers.
- **Broken link detection**: Integrated scheduler scripts validating external URL targets for rot.
- **Community submission queue**: Structured issue templates facilitating high-quality resource suggestions from builders.

## Later Phase

- **Lightweight website or GitHub Pages**: Hosting a frontend display directly from vault files (optional later phase, not currently implemented).
- **Searchable web frontend**: A fast interface enabling users to query keywords and filter resource tables in the browser.
- **Public metadata API**: JSON endpoints detailing category distributions and resource statistics.
- **Community voting**: Mechanisms for builders to upvote or recommend specific vault items.
- **Expanded source coverage**: Support for additional developer platforms, APIs, and RSS feeds.
