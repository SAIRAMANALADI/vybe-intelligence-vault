# Contributing to Vybe Intelligence Vault

Welcome! We are thrilled that you want to help make this AI builder intelligence vault more useful, polished, and open-source friendly.

By contributing, you help developers find the best resources for AI engineering, advanced web development, automation, and startup building.

---

## How to Contribute

### 1. Suggest a Resource
If you know of a tool, library, dataset, template, or guide that should be in the vault, please open an issue using the [Resource Suggestion Template](.github/ISSUE_TEMPLATE/resource-suggestion.md).

### 2. Report a Broken Link
If you spot a dead URL, please open an issue using the [Broken Link Report Template](.github/ISSUE_TEMPLATE/broken-link.md) or submit a Pull Request directly fixing it.

### 3. Request a New Category
If the vault is missing an important focus area, suggest a new category by opening an issue using the [Category Request Template](.github/ISSUE_TEMPLATE/category-request.md).

### 4. Provide Quality Feedback
If a resource summary is inaccurate, contains wrong tags, or is misclassified, please open an issue using the [Quality Feedback Template](.github/ISSUE_TEMPLATE/quality-feedback.md).

### 5. Submit a Pull Request
If you wish to make edits directly:
- Fork the repository.
- Make your clean markdown changes.
- Ensure your PR follows the rules in the [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md).
- Submit the PR for review.

## Content Guidelines

We maintain high quality and legality standards for what enters the vault.

### Allowed Content
- **Public resources**: Links to open public articles, guides, and tutorials.
- **Open-source repositories**: Links to active, public code repositories.
- **Public documentation**: References to developer documentation and API guides.
- **Public tools**: Free-tier or open developer utilities.
- **Public datasets**: Free and open datasets, benchmarks, or evaluation pools.
- **Public prompts**: legally shareable prompts, system instructions, or IDE config files.

### Disallowed Content
- **Leaked prompts**: Proprietary system prompts or leaked instructions.
- **Paid course content**: Paywalled courses, books, or subscriber-only write-ups.
- **Private files**: Local configurations, proprietary scripts, or internal architectures.
- **Login-only resources**: Tools or resources that require registration to view any content.
- **Secrets**: API keys, credentials, tokens, or local .env configurations.
- **Personal data**: Email addresses, private names, or sensitive information.
- **Copyrighted content**: Copying full copyrighted materials without permission. Keep summaries short and link to original sources.
