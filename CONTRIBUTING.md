# Contributing to Vybe Intelligence Vault

First of all, thank you for checking out this project and wanting to contribute! We want to keep this knowledge base accurate, clean, and highly organized.

## How Can You Help?
1. **Fix Broken Links**: Since web content changes, source URLs might break. If you spot a broken link, submit a PR to update it.
2. **Correct Formatting**: If automated markdown rendering is messy or code segments are not formatted correctly, PRs to clean up files are highly appreciated.
3. **Enhance Indexing**: If you notice a tag or category that could be improved, you can suggest it in an issue.

## Pull Request Guidelines
* Ensure that the changes do not add any private information (personal user paths, emails, secrets).
* Keep summaries readable and follow the existing frontmatter schema:
  ```yaml
  title: "Example Title"
  archive_category: "category-slug"
  source_category: "source-slug"
  source_url: "https://example.com"
  local_vault_path: "path/to/file.md"
  tags:
    - tag1
  ```

Thank you for helping keep the vault clean and open for everyone!
