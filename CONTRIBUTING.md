# Contributing to Vybe Intelligence Vault

Thank you for wanting to contribute! We want to keep this knowledge base accurate, clean, and highly structured for AI agents and human developers alike.

---

## How You Can Help

1.  **Fix Broken Links** — Web links move or rot. If you spot a broken origin link, submit a PR to correct it.
2.  **Format Cleanups** — Sometimes automated parsing gets messy. Clean markdown fixes are always welcome.
3.  **Tagging and Metadata** — Suggest improvements to tags, categories, or index navigation paths.
4.  **Prompts and Instructions** — Share custom configurations, Cursor system rules, or helpful agent instructions.

---

## Pull Request Guidelines

To maintain vault structure and security, please ensure your PR follows these rules:

*   **No Private Data** — Double-check that your submission does not contain API keys, credentials, local user directories, or private emails.
*   **Keep Metadata Intact** — Keep summaries readable and preserve the target frontmatter structure:

```yaml
title: "Example Resource Name"
archive_category: "category-slug"
source_category: "source-slug"
source_url: "https://example.com"
local_vault_path: "path/to/file.md"
tags:
  - tag1
  - tag2
```

Thank you for helping us keep the vault clean, up-to-date, and open for everyone!
