# Vybe Intelligence Vault

A free open-source AI + advanced web-development workspace archive generated from public resources.

---

## What This Repo Is
The **Vybe Intelligence Vault** is a curated, automatically synchronized repository of daily and weekly intelligence reports, learning path templates, advanced web development frameworks, and AI research paper summaries. The content is gathered dynamically from various public resources and organized into a clean, searchable markdown database.

## Who It Is For
* **AI Engineers & Researchers**: Looking for curated summaries on recent models, agentic frameworks, and RAG optimization.
* **Modern Web Developers**: Seeking high-quality articles, components, and notes on 3D graphics (WebGL/WebGPU/Three.js) and advanced CSS layout techniques.
* **Students & Lifelong Learners**: Searching for structured learning path guidelines and skills indexing.

---

## What It Contains

* **AI Engineering Resources**: Summaries of emerging LLM architectures and prompting guides.
* **Agent / RAG / MCP Resources**: Curated notes on tool integration, model-context protocol (MCP) servers, and vector store configurations.
* **Prompt Libraries**: Structured templates and guides for prompting.
* **Web Development & 3D Frontend**: Deep dives into shaders, WebGL, WebGPU, and advanced UI micro-animations.
* **Skills & Learning Paths**: Living indexes grouping learning targets.
* **Daily / Weekly Intelligence Reports**: Comprehensive digests summarizing the hot topics in technology.
* **Workspace Archive**: Folders organized by category for clean, static browsing.

---

## Folder Guide

* **`ai/`**: Summarized articles, news, and research on artificial intelligence.
  * `agents/`: Agentic systems, multi-agent frameworks, and patterns.
  * `models/`: General developments in large language models and vision models.
  * `research/`: Academic preprints and theoretical papers.
  * `rag/`: Retrieval Augmented Generation, chunking, and vectors.
* **`web-development/`**: Articles and resources on modern frontend technologies.
* **`skills/`**: Automatically populated markdown files indexing core skills and related files.
* **`daily-digests/`**: Daily aggregations of news and resources.
* **`weekly-reports/`**: Weekly summaries of the vault additions.
* **`workspace-archive/`**: An organized mirror of vault assets with metadata.
* **`_index/`**: Navigation index files (by tag, source, etc.).

## How to Use This Repo

### How to Clone
You can clone this repository locally to browse it offline or hook it up to your local markdown viewer (like Obsidian, Logseq, or Foam):
```bash
git clone https://github.com/sairaman436/vybe-intelligence-vault.git
```

### How to Browse
* **By Tag**: Open `_index/tag-index.md` to see resources organized by tags.
* **By Source**: Open `_index/source-index.md` to view articles categorized by origin.
* **By Skill**: Open `_index/skill-index.md` to review resources grouped by specific tech skills.
* **Daily Digests**: Open `daily-digests/` to read the daily logs.
