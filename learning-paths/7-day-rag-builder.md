# 7-Day RAG Builder Learning Path

## Focus Area
Embeddings, vector databases, and semantic search.

## Weekly Day-by-Day Plan
*   **Day 1**: Examine vector math, semantic lookup models, and token limits.
*   **Day 2**: Integrate PyPDF and set up basic sentence-based text chunking.
*   **Day 3**: Load a local vector engine (Qdrant/SQLite-vss) and store chunks.
*   **Day 4**: Write semantic search retrieval queries against your vector store.
*   **Day 5**: Formulate LLM prompts utilizing retrieved context to answer queries.
*   **Day 6**: Add reranking strategies to prioritize high-relevance chunks.
*   **Day 7**: Validate quality, format source links, and write API tests.

## End of Week Output
A self-contained PDF query backend supporting semantic lookup and source attribution.
