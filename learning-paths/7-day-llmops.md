# 7-Day LLMOps Learning Path

## Focus Area
Local LLM inference, tracing, and model evaluations.

## Weekly Day-by-Day Plan
*   **Day 1**: Understand inference pipelines, llama.cpp, Ollama, and quantization.
*   **Day 2**: Install Ollama locally and download quantized models.
*   **Day 3**: Setup Langfuse server locally using Docker containers.
*   **Day 4**: Instrument your Python code to log LLM queries to Langfuse.
*   **Day 5**: Create automated evaluation scripts for model output checking.
*   **Day 6**: Integrate safety guardrail layers (moderation checks).
*   **Day 7**: Perform latency checks, document logs, and track token usage.

## End of Week Output
A localized inference server monitored by Langfuse with automated eval tests.
