# 7-Day AI Frontend Learning Path

## Focus Area
Web chat interfaces, dashboards, and stream rendering.

## Weekly Day-by-Day Plan
*   **Day 1**: Explore chat layout constraints, message types, and styling guides.
*   **Day 2**: Build a static message dashboard layout using TailwindCSS.
*   **Day 3**: Integrate API route handler streaming JSON text streams.
*   **Day 4**: Render stream text on the frontend using Vercel AI SDK.
*   **Day 5**: Configure markdown parsing and code snippet styling inside chat bubbles.
*   **Day 6**: Add system state banners and auto-scroll behaviors.
*   **Day 7**: Test responsiveness, mobile viewports, and clean code styles.

## End of Week Output
A responsive Next.js chatbot interface supporting text streaming and markdown blocks.
