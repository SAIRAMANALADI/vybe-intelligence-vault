# 7-Day AI Engineering Learning Path

## Focus Area
AI app patterns, tool calling, and API orchestration.

## Weekly Day-by-Day Plan
*   **Day 1**: Understand Large Language Model APIs, tokens, and context window dynamics.
*   **Day 2**: Implement basic text prompt generation and raw JSON outputs.
*   **Day 3**: Add error handlers, retry fallbacks, and rate limit protections.
*   **Day 4**: Build structured outputs using Pydantic schemas.
*   **Day 5**: Integrate tool calling (function declarations) inside the LLM prompt loop.
*   **Day 6**: Add system parameters and session history logging.
*   **Day 7**: Hardcode safety rules, package the codebase, and finalize tests.

## End of Week Output
A working command line agent that calls external APIs, handles exceptions, and saves session logs.
