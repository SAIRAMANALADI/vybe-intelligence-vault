# CSS Grid Layout (level 1) | Can I use... Support tables for HTML5, CSS3, etc

## Summary

- **CSS Grid Layout (Level 1)** provides a grid-based layout system using `grid-*` properties and the `fr` unit, enabling predictable column/row sizing and content division (W3C Candidate Recommendation, 94.94% global support).

- **Browser Support**: Full support in modern Chrome (57+), Edge (16+), Safari (10.1+), Firefox (52+), and Opera (44+); partial support in IE10/11; unsupported in Opera Mini and older versions (pre-2017).

- **Polyfills & Resources**: Legacy polyfills exist (e.g., [Grid-Layout-Polyfill](https://github.com/codler/Grid-Layout-Polyfill)), with modern alternatives (e.g., [css-grid-polyfill](https://github.com/FremyCompany/css-grid-polyfill/)); subgrid support tracked separately ([caniuse](https://caniuse.com/css-grid#feat=css-subgrid)).
