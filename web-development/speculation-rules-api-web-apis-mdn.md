# Speculation Rules API - Web APIs | MDN

## Summary

- **Purpose**: The Speculation Rules API enhances performance for future navigations by prefetching/prerendering document URLs, primarily benefiting multi-page applications (MPAs) over single-page applications (SPAs).

- **Improvements**: It replaces deprecated Chrome-only `prerender` and expands on `prefetch`, offering a more configurable syntax for specifying speculative loading rules.

- **Limitations**: The API does not handle subresource prefetches; `<link rel="prefetch">` must be used for those cases. It remains experimental with limited cross-browser support.
