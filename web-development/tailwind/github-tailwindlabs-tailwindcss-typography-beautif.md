# GitHub - tailwindlabs/tailwindcss-typography: Beautiful typographic defaults for HTML you don't control. · GitHub

## Summary

- **Installation & Setup**: Install via `npm install -D @tailwindcss/typography`, then add `@plugin "@tailwindcss/typography"` to `style.css` or register in `tailwind.config.js` for v3. Requires base `@import "tailwindcss"` directive.

- **Core Functionality**: Applies typographic defaults via `prose` classes (e.g., `prose`, `prose-gray`, `prose-lg`) to unstyled HTML (Markdown/CMS content), with modifiers for grayscale (`slate`, `zinc`, etc.), size (`sm`, `xl`, etc.), and dark mode (`prose-invert`).

- **Customization & Overrides**: Supports element-specific modifiers (e.g., `prose-h1:text-blue-600`), sandboxing via `not-prose`, custom themes via CSS variables or `typography` config in `tailwind.config.js`, and max-width overrides with `max-w-none`.
