# Styles and CSS | Docs

## Summary

- Astro supports **scoped styles** (default) via `astro-cid-*` attributes, preventing CSS leakage while preserving specificity; global styles require explicit opt-out via `<style is:global>`.
- **Cascading order** prioritizes: `<link>` tags → imported styles → scoped styles; conflicts resolve by last-imported or higher specificity.
- **Tailwind integration** requires either `astro add tailwind` (Vite plugin for v4) or manual setup; legacy v3 uses `@astrojs/tailwind` integration.
