# Install Tailwind CSS with Astro - Tailwind CSS

## Summary

- **Installation & Setup**: Tailwind CSS v4.3 integrates with Astro via `@tailwindcss/vite`; requires adding the plugin to `astro.config.mjs` and importing `global.css` with `@import "tailwindcss"` for utility class usage.
- **Core Utility Classes**: Supports atomic styling across layout (flex/grid), spacing, typography, backgrounds, borders, effects, filters, transforms, and interactivity (e.g., `flex`, `gap`, `text-sm`, `bg-blue-500`, `transition`).
- **Advanced Features**: Includes dark mode, responsive design, custom theme variables, and state modifiers (hover/focus) via utility classes like `dark:` and `md:`.
