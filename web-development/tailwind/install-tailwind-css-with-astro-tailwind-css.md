# Install Tailwind CSS with Astro - Tailwind CSS

## Summary

- **Installation & Setup**: Tailwind CSS v4.3 integrates with Astro via `@tailwindcss/vite` plugin; requires `npm install tailwindcss @tailwindcss/vite`, Vite plugin configuration in `astro.config.mjs`, and importing `@import "tailwindcss"` in `global.css`.
- **Core Utility Classes**: Supports 50+ CSS properties (e.g., `flex`, `grid`, `padding`, `margin`, `bg-color`) via utility-first classes with responsive (`md:`, `lg:`), state (`hover:`, `focus:`), and dark mode (`dark:`) variants.
- **Advanced Features**: Includes filters (`blur`, `brightness`), transforms (`rotate`, `scale`), transitions, and interactivity controls (`scroll-margin`, `cursor`) with full SVG (`fill`, `stroke`) and accessibility (`forced-color-adjust`) support.
