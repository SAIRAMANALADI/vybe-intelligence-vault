# CSS Grid Layout: A New Layout Module for the Web | WebKit

## Summary

- **CSS Grid Layout** introduces a two-dimensional layout system with `display: grid` or `inline-grid`, replacing older methods (tables, floats, flexbox) for complex grid designs.
- **Key features** include track sizing (fixed, intrinsic, `fr` units), named grid lines/areas, and automatic item placement via `grid-row`/`grid-column` properties.
- **Alignment & responsiveness** are native: `justify-content`/`align-content` for track distribution and `justify-self`/`align-self` for item alignment, with media queries enabling adaptive layouts.
