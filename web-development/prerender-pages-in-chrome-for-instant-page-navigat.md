# Prerender pages in Chrome for instant page navigations | Web Platform | Chrome for Developers

## Summary

- **Chrome 109+ and Edge 109+ support the Speculation Rules API** for prerendering pages, enabling instant navigations via `<script type="speculationrules">` with `prefetch` or `prerender` directives.
- **Firefox does not support prerendering** as of January 2026, while Safari requires enabling a flag (`chrome://flags/#enable-prerender2`).
- **Prerendering is resource-intensive**, requiring careful implementation to avoid excessive memory/CPU usage, with Chrome enforcing a 20-page limit per browser session.
