## Summary
AgentDeals is an MCP server that aggregates free tiers, startup credits, and developer tool deals from 1,500+ vendors across 54 categories. It enables AI agents and developers to discover and compare infrastructure offers programmatically or via a hosted service.

## Key Features
- Aggregates 1,500+ verified deals across 54 categories with real-time pricing data
- Provides 4 MCP tools (search_deals, plan_stack, compare_vendors, track_changes) and 17 REST API endpoints for programmatic access
- Supports local stdio, remote HTTP, and one-click integrations with Claude Code, Cursor, and VS Code
- Tracks pricing changes and free tier modifications to ensure up-to-date recommendations
- Includes eligibility filters for startups, students, OSS projects, and geographic regions

## Why It Matters for RAG Builders
AgentDeals provides critical, real-time pricing and deal data for AI agents to make informed infrastructure recommendations without relying on outdated training data.
