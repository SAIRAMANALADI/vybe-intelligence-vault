## Summary
Agentic Search Crawler 2026 indexes the web based on 'agentic readiness'—how well a site can be consumed by AI agents. It scores sites on dimensions like llms.txt presence, OpenAPI availability, MCP endpoints, and AI plugin manifests, enabling agents to prioritize high-quality, actionable sources.

## Key Features
- Agentic readiness scoring system (0-100) based on AI-friendly criteria
- Automated discovery of llms.txt, OpenAPI specs, MCP endpoints, and AI plugin manifests
- Dual storage backend (PostgreSQL for metadata, Elasticsearch for full-text search)
- REST API and MCP server for agent integration
- Pre-indexed 8,000+ AI-friendly sites with customizable crawling profiles

## Why It Matters for RAG Builders
It enables AI agents to efficiently discover and interact with websites optimized for machine consumption, reducing noise and improving the quality of RAG inputs.
