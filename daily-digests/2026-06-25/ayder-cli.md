## Summary
ayder-cli is a terminal-based multi-provider AI agent chat client that enables autonomous coding assistance with file system tools and shell access. It supports local and cloud LLM providers like Ollama, Anthropic, OpenAI, and Gemini, offering a flexible, agentic workflow for software development tasks.

## Key Features
- Multi-provider support (Ollama, OpenAI, Anthropic, Gemini, DeepSeek, Qwen, GLM) with optional SDKs for minimal core installation
- 16 built-in tools for file operations, shell commands, and web access with path sandboxing and safe mode
- Textual TUI with slash commands, tool confirmation modals, and diff previews for interactive agentic workflows
- Context-aware token management with Ollama-specific optimizations and driver-aware compression
- Multi-agent SDLC harness for orchestrating complex software development pipelines with configurable roles

## Why It Matters for RAG Builders
ayder-cli provides a lightweight, terminal-native agent framework that bridges local and cloud LLMs, enabling secure, autonomous coding workflows with fine-grained tool permissions and multi-agent orchestration for RAG builders.
