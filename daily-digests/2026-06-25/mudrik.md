## Summary
Mudrik is an open-source Windows AI assistant that captures and interprets on-screen UI elements to perform actions, answer questions, or guide users step-by-step through tasks. It integrates with any LLM provider and operates via global hotkeys for seamless interaction.

## Key Features
- Captures and interprets on-screen UI elements via Windows UI Automation or screenshots for Chromium apps
- Executes actions like typing, clicking, or pressing shortcuts based on AI instructions
- Auto-Guide mode with an on-screen owl cursor for step-by-step task guidance
- Supports 18+ LLM providers (Anthropic, OpenAI, DeepSeek, etc.) with easy API key configuration
- Sandboxed execution with no shell commands or filesystem writes, ensuring security
