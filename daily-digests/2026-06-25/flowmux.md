## Summary
FlowMux is a GTK4-based terminal application designed for AI agent workflows, offering a multiplexer interface with integrated browser control and desktop notifications. It enables AI agents to interact with terminal panes and WebKitGTK browsers via IPC, supporting task automation and real-time monitoring.

## Key Features
- Integrated terminal and WebKitGTK browser in a single pane-based workspace
- IPC socket for AI agent control (snapshot, click, type, read state)
- Desktop notifications for AI agent lifecycle events (task completion, errors)
- Persistent workspace and session state with cross-platform support (Linux, macOS, Flatpak)
- Customizable keybindings, agent CLI, and system integration (cookie import, SSH workspaces)

## Why It Matters for RAG Builders
FlowMux provides a unified terminal and browser interface for AI agents to execute and monitor tasks, streamlining RAG workflows with real-time interaction and automation capabilities.
