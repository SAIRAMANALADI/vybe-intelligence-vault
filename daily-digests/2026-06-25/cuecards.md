## Summary
cuecards is a profile manager for AI coding agents like Claude Code and Codex that scopes skills, MCP servers, persona, and quality gates to individual project directories, reducing unnecessary context and token costs while improving agent performance.

## Key Features
- Per-directory profile management for AI agents, ensuring only relevant skills and tools are loaded
- 69 pre-built profiles for common stacks (e.g., backend, frontend, Rust, Python) with auto-detection
- Cost and token usage tracking with comparisons to baseline profiles
- Multi-agent compatibility (Claude Code, Codex, Cursor, Cline, etc.) via unified profile materialization
- Built-in rigor with reviewer gates and confidence tags to validate agent outputs

## Why It Matters for RAG Builders
It reduces token waste and improves AI agent performance by dynamically scoping context to project-specific needs, making RAG pipelines more efficient and cost-effective.
