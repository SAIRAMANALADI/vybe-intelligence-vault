## Summary
TrendRadar is an AI-driven public opinion and trend monitoring tool that aggregates news from multiple platforms, filters content via keywords or AI-based interest descriptions, and delivers personalized alerts through 10+ channels like WeChat, Feishu, Telegram, and email. It supports RSS subscriptions, AI-powered summarization, and MCP integration for advanced natural language analysis.

## Key Features
- Aggregates news from multiple platforms in real-time with RSS support
- AI-powered filtering via keyword matching or natural language interest descriptions
- Multi-channel notifications (WeChat, Feishu, Telegram, Email, etc.)
- MCP integration for AI-driven natural language analysis and trend prediction
- Docker-based deployment with GitHub Actions automation
