## Summary
An HR service portal built with n8n automation workflows that enables self-service leave applications with manager approval, a live leave dashboard, and an OpenAI-powered HR assistant protected by input and output guardrails.

## Key Features
- Self-service leave application with human-in-the-loop manager approval via email
- Live leave dashboard displaying balance, days taken, and recent applications
- OpenAI-powered HR assistant for answering HR-related queries
- Input guardrail LLM classifier to block prompt injection and malicious requests
- Output guardrail LLM classifier to prevent sensitive data leaks in responses

## Why It Matters for RAG Builders
This repository demonstrates a practical integration of n8n workflows with OpenAI guardrails for secure, automated HR processes, offering a blueprint for building robust AI-driven self-service portals.
