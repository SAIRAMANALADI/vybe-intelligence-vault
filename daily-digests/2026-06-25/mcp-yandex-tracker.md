## Summary
mcp-yandex-tracker is a Windows-based server application that simplifies integration with Yandex Tracker's API using the Model Context Protocol (MCP). It enables non-technical users to manage tasks and projects through Yandex Tracker without complex setup.

## Key Features
- Simplifies Yandex Tracker API access for non-developers
- Uses Model Context Protocol (MCP) for seamless communication
- Runs as a background service on Windows
- Supports AI agent integration for enhanced task handling
- Provides logging and configuration for troubleshooting
