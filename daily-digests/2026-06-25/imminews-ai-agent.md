## Summary
An automated AI agent that leverages Google's Gemini AI to monitor European immigration, investment, and visa regulations news. It generates professional social media drafts and delivers them via Telegram, running autonomously on GitHub Actions.

## Key Features
- Automated Google News search with rotating keywords for targeted monitoring
- AI-powered analysis using Google Gemini 1.5 Flash to generate structured social media drafts
- Real-time Telegram notifications with HTML-formatted content delivery
- Cloud-native deployment via GitHub Actions for 24/7 autonomous operation
- Deduplication system using history.txt to avoid duplicate news processing
