## Summary
Episteme is an offline-first, single-binary knowledge graph system that connects software engineering design patterns, refactoring techniques, and laws through 201 semantic relationships. Built for AI agents, it integrates directly with tools like Claude Code and Cursor to provide structured, citable engineering expertise.

## Key Features
- Single-binary deployment with cross-platform support (macOS, Linux, Windows)
- 201 semantic relationships connecting 22 GoF patterns, 66 refactorings, 56 laws, and 17 code smells
- MCP-compatible tools and agents for seamless AI integration (Claude Code, Cursor, etc.)
- Local embeddings via fastembed (ONNX Runtime) for semantic search without external dependencies
- Deterministic AST-based analysis with citable entity IDs for consistent, traceable results

## Why It Matters for RAG Builders
Episteme provides structured, connected engineering knowledge that AI agents can use to deliver consistent, traceable, and offline-capable software analysis and refactoring guidance.
