## Summary
A Telegram messaging component for Zylos agents that enables AI agents to interact via Telegram, supporting private chats, group monitoring, and media sharing with zero-configuration setup.

## Key Features
- Seamless Telegram chat integration for AI agents with private and group conversation support
- Smart group monitoring that automatically follows designated discussions without requiring @mentions
- Zero-configuration setup where the first user interaction auto-binds admin privileges
- Media support for sending and receiving photos, documents, and files
- CLI and natural language commands for managing the bot (e.g., whitelisting users, enabling smart groups, restarting)
