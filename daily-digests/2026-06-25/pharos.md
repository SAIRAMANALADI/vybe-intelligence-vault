## Summary
Pharos is a Tauri-based terminal multiplexer for macOS that unifies AI agent sessions (Claude Code, Codex, SSH, tmux) into a single native app. It acts as a silent overlay layer, providing workspace management, real-time state tracking, and CLI automation for AI-driven development workflows.

## Key Features
- Unified terminal interface for AI agent sessions (Claude Code, Codex, SSH, tmux) with workspace switching
- Automated state detection (running/idle/waiting) and source tracking (Claude, Codex, shell, tmux)
- CLI primitives for blocking waits, event timeline analysis, and workspace state management
- Blueprint pane for local-first, git-friendly app planning with structured requirements and flows
- Android debugging panel with mirroring, embedding, logs, and shell access

## Why It Matters for RAG Builders
Pharos streamlines AI agent workflows by centralizing terminal sessions and automating state tracking, making it essential for developers building RAG systems that require seamless orchestration of multiple AI-driven tasks.
