## Summary
A Claude Code plugin that automates end-to-end AI development workflows, from idea to pull request, using a harness for long-running AI agents with structured context management and cross-session learning. It enables automated ticket creation, multi-agent implementation, security audits, code reviews, and PR generation.

## Key Features
- End-to-end automation from idea to PR with zero intervention
- Harness for long-running AI agents with closed inner-loop engineering (act → verify → correct → continue)
- Strict context management and information firewalls to prevent contamination
- Cross-session knowledge base that improves accuracy over time
- Ultracode orchestration for parallel multi-verifier panels in AC evaluation

## Why It Matters for RAG Builders
