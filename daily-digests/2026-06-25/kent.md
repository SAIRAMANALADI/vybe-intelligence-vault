## Summary
Kent is a high-performance coding agent designed for professional engineers, optimizing for output quality, long-running tasks, and token efficiency. It provides a robust framework for collaborative coding with features like async execution, customizable subagents, and transparent workflows.

## Key Features
- High-performance coding agent with superior compaction quality and context retention
- Customizable supervisor agent for real-time review and steering of main agent
- Async shell execution with 0-token ralph loops and parallelization via Git worktrees
- Token-efficient tools (patch, shell, ask) with smart optimizations and caching mechanisms
- Transparent, native transcript UI with detailed inspection of all inputs and outputs
