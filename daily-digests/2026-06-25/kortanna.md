## Summary
Kortanna is a disciplined, drop-in framework for orchestrating multi-session AI development workflows using Claude Code. It provides guardrails, templates, and the Van Clief / Interpretable Context Methodology (ICM) to enforce structured planning, task execution, and review processes.

## Key Features
- Planner-worker model for task delegation and execution
- Pre-configured guardrails (merge-only main, review-before-push, single-writer planning board)
- Goal-driven work with verifiable done-conditions via `/goal` command
- Three-layer memory system (global brain, project memory, session capture)
- Built-in commands (`/wrap`, `/groom`, `/ship`, `/freshness`, `/council`) for disciplined workflows

## Why It Matters for RAG Builders
It provides a structured, repeatable framework for scaling AI-driven development workflows while enforcing discipline, quality, and collaboration best practices.
