## Summary
Kiro Telegram Bot bridges the Kiro CLI to Telegram, enabling users to control an AI coding assistant remotely via the Agent Client Protocol (ACP). It supports project switching, live session monitoring, scheduled tasks, multi-image prompts, and 24/7 background service deployment across Windows, Linux, and macOS.

## Key Features
- Remote control of Kiro CLI via Telegram with live session monitoring and management
- Multi-session support with project switching, resume, and kill-by-PID functionality
- Scheduled tasks and queued follow-ups for asynchronous AI agent interactions
- Cross-platform 24/7 background service deployment with auto-restart and self-healing
- Rich UI features including live progress bars, status panels, and multi-image prompt handling
