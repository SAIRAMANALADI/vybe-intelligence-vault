## Summary
Agent Kit Admin is a team-focused platform for managing and sharing MCP Servers and Agent Skills, enabling private publishing, version control, and one-click installation for AI agent ecosystems like Cursor and Claude Code.

## Key Features
- Private team-based package registry for MCP Servers and Agent Skills
- Version control and publishing for reusable AI tools
- CLI tool (akit) for seamless integration with Cursor/Claude Code
- Web UI for visual package management and team administration
- OAuth support for enterprise SSO (WeChat Work, Feishu, DingTalk)

## Why It Matters for RAG Builders
It provides a centralized platform for teams to manage and distribute reusable AI agent tools, streamlining collaboration and deployment in AI engineering workflows.
