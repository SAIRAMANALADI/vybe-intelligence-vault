## Summary
AirMCP is a governance-focused MCP server for Apple ecosystems that enables secure, audited, and human-in-the-loop (HITL) automation across macOS apps, Siri, Shortcuts, and AI clients like Claude or Cursor. It provides a safety layer with HMAC-chained audit logs, rate limiting, OAuth scope gating, and emergency stop controls.

## Key Features
- 286+ tools across 29 modules for Apple ecosystem automation (JXA + Swift bridges)
- HMAC-chained audit logs with tamper detection and real-time monitoring
- Human-in-the-loop (HITL) approval gates for sensitive/destructive actions
- OAuth 2.1 scope gating and rate limiting (60/min + 10 destructive/hr)
- Native SwiftUI menubar app for local-first control and client orchestration

## Why It Matters for RAG Builders
AirMCP provides critical governance primitives like audit logging, HITL approval, and scope gating for Apple-native AI automation, ensuring safe and compliant RAG/AI stack deployments in macOS environments.
