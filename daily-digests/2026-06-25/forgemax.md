## Summary
forgemax is a local sandboxed MCP gateway that simplifies the management of multiple AI tools and servers by collapsing them into two core tools, enabling efficient local execution and coordination for Windows users.

## Key Features
- Collapses multiple servers and tools into two core gateways for simplified management
- Local sandbox operation ensures secure and isolated execution environment
- Supports AI agent coordination and efficient tool calling
- Reduces memory and processing load by avoiding duplicated services
- Works offline for core functions, requiring internet only for updates or external data
