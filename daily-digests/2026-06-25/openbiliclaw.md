## Summary
OpenBiliClaw is a local-first, privacy-focused AI agent that builds personalized content discovery systems by deeply understanding user behavior across multiple platforms like Bilibili, Xiaohongshu, Douyin, YouTube, X, and Zhihu. It actively searches for content based on a user's psychological profile rather than relying on platform algorithms.

## Key Features
- Builds a five-layer psychological profile (events → preferences → awareness → insights → soul) to deeply understand user interests and cognitive style.
- Actively discovers and recommends content across multiple platforms (Bilibili, Xiaohongshu, Douyin, YouTube, X, Zhihu, and more) based on user-specific insights rather than platform algorithms.
- 100% local execution with data stored in SQLite; supports custom LLM API keys or local Ollama models for privacy.
- Provides transparent reasoning for recommendations and allows user feedback to refine future suggestions.
- Supports both desktop and mobile web interfaces for seamless cross-device usage.

## Why It Matters for RAG Builders
