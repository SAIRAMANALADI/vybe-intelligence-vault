## Summary
Dunetrace is a real-time monitoring and alerting system designed to detect structural failures in production AI agents within 15 seconds of run completion. It provides Slack/webhook alerts, a dashboard, and integrations with tools like Langfuse for root-cause analysis and automated fixes.

## Key Features
- 17 built-in detectors for structural failure patterns (e.g., tool loops, cost spikes, prompt injection) with no LLM required
- Slack/webhook alerts within 15 seconds of run completion, including actionable fixes and rate context
- Integration with Langfuse for LLM-powered root-cause analysis and one-click prompt fixes
- Runtime guardrails (policies) to cap costs, tool calls, or switch models mid-run
- MCP server for querying agent signals directly from editors like Claude Code or Cursor

## Why It Matters for RAG Builders
Dunetrace enables AI engineering teams to proactively detect and resolve production AI agent failures before they escalate, reducing costs and improving reliability.
