## Summary
A skill-driven plugin for the Obscura headless browser that enables AI coding agents to perform web scraping, browser automation, and data extraction via slash commands. It integrates seamlessly with popular AI tools like Claude Code, Codex CLI, and Antigravity.

## Key Features
- Provides slash commands for web scraping and data extraction (e.g., /obscura-fetch, /obscura-scrape)
- Supports stealth mode for anti-detection and tracker blocking
- Integrates with multiple AI tools (Claude Code, Codex CLI, Antigravity, Cursor, OpenCode, Cline)
- Includes a self-directed web data collection agent (obscura-browser)
- Offers pre-built binaries and multiple installation methods (Homebrew, Rust toolchain, shell scripts)

## Why It Matters for RAG Builders
It enables AI agents to autonomously perform web scraping and browser automation, reducing manual effort in data collection and extraction tasks.
