## Summary
GZA is an AI agent task runner that enables batch processing of coding tasks by distributing them across isolated Docker containers, allowing parallel execution with git branch isolation for each task. It automates workflows for AI coding agents, enabling fire-and-forget task execution and streamlined review/merge processes.

## Key Features
- Parallel task execution in isolated Docker containers with dedicated git branches
- Support for multiple AI providers (Claude Code, OpenAI Codex, Gemini CLI)
- Automated batch workflow management with intelligent orchestration
- Task history and status tracking with filtering capabilities
- Background task execution and resume/retry functionality

## Why It Matters for RAG Builders
GZA streamlines AI agent workflows by enabling scalable, parallel task execution with isolation, reducing manual oversight and accelerating batch processing for large-scale codebase tasks.
