## Summary
A production-ready MCP server that bridges AI assistants (e.g., Claude, GPT) with Nextcloud instances, enabling natural language interactions for managing notes, calendars, contacts, files, and more through a secure API. It operates as a standalone server with deep CRUD operations across multiple Nextcloud apps.

## Key Features
- 110+ MCP tools for comprehensive Nextcloud app coverage (Notes, Calendar, Contacts, Files, Deck, etc.)
- Semantic search integration with Qdrant and Ollama for vector-powered RAG
- Multi-user authentication via Login Flow v2 or Basic Auth with app passwords
- Flexible deployment options (Docker, Kubernetes, local, VM)
- Tag-based file exclusion for sensitive data management

## Why It Matters for RAG Builders
It enables AI assistants to securely and efficiently interact with Nextcloud data, unlocking advanced RAG capabilities for personal and enterprise workflows.
