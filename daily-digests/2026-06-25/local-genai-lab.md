## Summary
A full-stack local-first GenAI lab for building and testing tool-assisted chat workflows with a React frontend and Spring Boot backend. It integrates local and remote model providers (Ollama, Bedrock, Hugging Face), persistent session memory, MCP-backed AWS tooling, and a RAG workspace for querying local documentation.

## Key Features
- Full-stack tool-assisted chat with backend-side orchestration and provider abstraction
- Persistent session memory with resume, search, filter, import, and export capabilities
- MCP-backed local tool execution for AWS audits, reports, and artifact generation
- RAG workspace for querying local documentation with cited source chunks and multiple retrieval modes (lexical, vector in-memory, vector Qdrant)
- Streaming responses, API observability, and structured report rendering

## Why It Matters for RAG Builders
It provides a comprehensive local-first environment for building and testing GenAI workflows with tool integration, RAG, and multi-provider support, reducing the complexity of assembling such a stack from scratch.
