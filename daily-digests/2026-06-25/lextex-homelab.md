## Summary
lextex-homelab is a WSL2-based homelab setup for Windows that integrates Lexi AI agent and Dextex WiFi into a unified system. It provides a pre-configured Ubuntu environment with tools like OpenClaw, Tailscale VPN, Cloudflare Tunnel, and 24/7 health monitoring for running home servers and AI services.

## Key Features
- Pre-configured Ubuntu environment on WSL2 for seamless Windows integration
- Automated setup with OpenClaw, Tailscale, and Cloudflare Tunnel
- Secure remote access via Tailscale VPN and Cloudflare Tunnel
- 24/7 system health monitoring with CPU, memory, and service tracking
- Easy updates and customization through structured folder layout
