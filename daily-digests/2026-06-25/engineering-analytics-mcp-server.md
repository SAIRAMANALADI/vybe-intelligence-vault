## Summary
The Keypup MCP Server integrates Keypup's engineering analytics platform with any MCP-compatible AI assistant, enabling natural language queries to generate reports on delivery, quality, and team workload without requiring manual query construction or coding.

## Key Features
- Natural language to structured query conversion for engineering data
- Read-only tools for exploring datasets, fields, and formula operators
- Seamless integration with MCP-compatible AI assistants (Claude, Cursor, ChatGPT Desktop, etc.)
- Support for OAuth 2.1 and API token authentication methods
- Pre-built datasets for issues, pull requests, activity events, comments, commits, and reviews

## Why It Matters for RAG Builders
It bridges AI assistants with engineering analytics platforms, enabling developers to query software delivery and performance metrics conversationally without writing code or learning query languages.
