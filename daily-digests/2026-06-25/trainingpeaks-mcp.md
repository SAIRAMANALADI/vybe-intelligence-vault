## Summary
A desktop application that provides a Model Context Protocol (MCP) server for accessing TrainingPeaks fitness data, enabling users to query workouts, CTL/ATL/TSB metrics, and power personal records via natural language without requiring API approval.

## Key Features
- Query workouts and fitness metrics (CTL/ATL/TSB) via natural language
- No API approval required—works with any TrainingPeaks account
- User-friendly desktop interface for non-technical users
- Multi-platform support (Windows and macOS)
- Secure access to personal fitness data

## Why It Matters for RAG Builders
It simplifies integration with TrainingPeaks data for AI assistants and RAG systems by providing a ready-to-use MCP server for fitness analytics.
