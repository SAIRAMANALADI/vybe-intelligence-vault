## Summary
Vicky is a lightweight, maintainable Kotlin agent framework designed for building AI assistants with OpenAI-compatible protocols. It supports custom agent modes, tool systems, semantic memory, and dynamic scripting with TypeScript integration.

## Key Features
- Customizable agent modes (SILENT, VERBOSE, CHAT) with configurable tool usage and output behavior
- Annotation-based tool definition with KSP code generation for seamless tool registration
- Semantic memory system with Qdrant integration for long-term context retention and distillation
- Dynamic TypeScript scripting support with automatic class injection and tool bridging
- Modular architecture with core, KSP processor, and scripting modules for flexible deployment

## Why It Matters for RAG Builders
Vicky provides a robust, extensible foundation for building AI agents with advanced tooling, memory, and scripting capabilities, making it essential for developers integrating RAG systems with custom agent workflows.
