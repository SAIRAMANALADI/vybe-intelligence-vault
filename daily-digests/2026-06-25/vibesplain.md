## Summary
vibesplain is an MCP server that performs deterministic static analysis on codebases using Tree-Sitter to generate an Architectural Dossier. It scores files by importance and complexity, produces decision cards, and outputs a self-contained HTML UI for AI agents to understand project architecture without LLM calls or network access.

## Key Features
- Generates an Architectural Dossier with decision cards for high-importance files
- Uses Tree-Sitter for AST parsing and scoring (gravity/heat metrics)
- Self-contained HTML UI for offline viewing of project architecture
- Integrates with popular AI coding agents (Claude, Gemini, Cursor, Windsurf)
- Zero LLM calls, API keys, or network dependency

## Why It Matters for RAG Builders
It provides AI agents with a structured, deterministic understanding of codebases, enabling better decision-making and reducing reliance on LLM-generated insights.
