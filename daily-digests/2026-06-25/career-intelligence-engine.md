## Summary
A multi-agent job-search automation system that orchestrates seven specialized agents to find, filter, score, and tailor job applications based on a user's profile. It integrates with job APIs, performs semantic matching against a CV, and generates personalized résumés and cover letters.

## Key Features
- Multi-agent orchestration with LangGraph for job search pipeline
- Semantic scoring of job roles against user CV using Sentence Transformers
- Automated generation of tailored résumés and cover letters
- Configurable filters for geography, language, and role type
- Provider-agnostic LLM gateway with failover and cost-aware routing
