## Summary
FOTAI is a web-based AI photography assistant that provides real-time guidance on photography techniques, composition, equipment selection, and photo editing. It integrates OpenAI's Responses API to maintain conversational context and is built as a portfolio project demonstrating full-stack development skills.

## Key Features
- Real-time AI chat with context preservation via `previous_response_id`
- Responsive UI with React, TypeScript, and TailwindCSS
- Secure proxy backend for OpenAI API integration
- Local storage persistence for chat history
- Deployment-ready with Vercel (frontend) and Railway (backend)
