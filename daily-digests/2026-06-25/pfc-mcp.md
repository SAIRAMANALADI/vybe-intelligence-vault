## Summary
pfc-mcp is an MCP server that bridges AI agents with ITASCA PFC, a discrete element method (DEM) simulation software, enabling natural language interaction for running simulations, executing code, and browsing documentation through the Model Context Protocol.

## Key Features
- Connects AI agents to ITASCA PFC via MCP for natural language interaction
- Supports PFC versions 6.0, 7.0, and 9.0 with hierarchical documentation browsing
- Provides interactive REPL and task lifecycle management for simulations
- Enables multi-client compatibility with tools like Claude Code and Gemini CLI
- Includes self-upgrading bridge for seamless updates and maintenance

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and control specialized simulation software like ITASCA PFC, expanding the capabilities of RAG systems in scientific and engineering domains.
