## Summary
SkyTwin is a digital twin system that learns user preferences, decision patterns, and risk tolerances to autonomously handle tasks like email triage, calendar management, and subscriptions. It operates proactively by ingesting signals from connected accounts and escalating only when uncertain, with built-in safety constraints and explainable decision-making.

## Key Features
- Progressive trust system with autonomy tiers and safety constraints
- Structured memory model for preferences, patterns, and episodic data
- Embedded LLM (llama.cpp) with optional hosted API integration
- Explainable decision-making with provenance tracking
- Cross-platform desktop app with no terminal or Docker dependency
