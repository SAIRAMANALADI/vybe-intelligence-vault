## Summary
Cartograph is a local-first CLI tool for managing reusable code modules (widgets) for AI agents, enabling search, installation, validation, and versioning of language-specific code components across projects. It enforces strict validation pipelines to ensure widget quality and reliability.

## Key Features
- Language-agnostic widget creation and management with strict validation (tests, coverage, contamination scanning)
- Local-first registry with optional cloud support for team sharing
- Automated agent configuration (Claude, Cursor, Codex, Gemini) via `cartograph setup`
- Multi-language support (Python, JS/TS, Nim, OpenSCAD, SystemVerilog, Angular, PHP, Terraform, Go) with native validation engines
- Non-interactive CLI commands outputting JSON for AI agent compatibility

## Why It Matters for RAG Builders
Cartograph solves the critical problem of reusable code loss in AI agent workflows by providing a structured, validated system for storing and sharing code modules, drastically reducing redundant development effort.
