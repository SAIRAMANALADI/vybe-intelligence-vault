## Summary
Noxrunner is a Python-based CLI tool and library for executing tests in a sandboxed environment, enabling safe and offline-capable test runs without external dependencies. It provides a lightweight solution for running tests locally or against remote backends.

## Key Features
- Sandboxed test execution to prevent system interference
- Local offline mode for testing without internet connectivity
- Lightweight design using only Python's standard library
- Cross-platform support (Windows, macOS, Linux)
- Simple CLI for running and managing tests
