## Summary
Carbon is an open-source, API-first manufacturing platform providing ERP, MES, and QMS solutions with full-stack type safety, realtime subscriptions, and extensible architecture for custom manufacturing workflows.

## Key Features
- Full-stack TypeScript with end-to-end type safety from database to UI
- Realtime database subscriptions and row-level security (RLS)
- Modular monorepo architecture with Turborepo for scalable development
- Attribute-based and role-based access control (ABAC/RBAC) with user groups
- Extensible API-first platform with MCP client/server support and webhooks

## Why It Matters for RAG Builders
Carbon provides a modern, API-first foundation for building custom manufacturing solutions, addressing gaps in traditional ERP systems with extensibility and realtime capabilities.
