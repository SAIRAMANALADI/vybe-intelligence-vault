## Summary
A Windows-based task management tool that automates to-do list organization using a multi-agent system. It runs as a background service, handling task discovery, planning, execution, and review without requiring manual intervention.

## Key Features
- Runs as a background daemon on Windows, minimizing user interaction
- Uses multiple software agents for parallel task discovery, planning, and execution
- Automatically updates task statuses and integrates with git worktrees for parallel work
- Simple setup and UI for non-technical users
- Self-updating system with minimal system resource usage
