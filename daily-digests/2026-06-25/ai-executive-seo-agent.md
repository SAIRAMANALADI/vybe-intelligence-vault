## Summary
An autonomous AI agent for SEO automation that orchestrates local LLM (Ollama) with Google APIs and DataForSEO to perform technical audits, keyword research, rank tracking, and content gap analysis. The system integrates FastAPI backend, vanilla JS frontend, and Celery workers for background tasks.

## Key Features
- Ollama-integrated local LLM for AI-driven SEO analysis and content generation
- Comprehensive SEO toolkit including technical audits, keyword research, and rank tracking
- Google Search Console and DataForSEO API integrations for real-time data
- Celery-based background workers for scalable task execution
- Vanilla JS frontend with FastAPI backend for a lightweight, self-contained system
