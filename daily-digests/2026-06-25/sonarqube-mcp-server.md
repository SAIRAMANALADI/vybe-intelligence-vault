## Summary
The SonarQube MCP Server is a Model Context Protocol (MCP) server that integrates SonarQube's code quality and security analysis capabilities directly into AI agents and development environments. It enables agents to analyze code snippets, retrieve project metrics, and assess technical debt or security risks in real-time.

## Key Features
- Seamless integration with SonarQube Server or Cloud for real-time code analysis
- Supports direct code snippet analysis within agent contexts
- Provides tools for retrieving project metrics, technical debt, and security risks
- Offers branch support and project key resolution for targeted analysis
- Containerized deployment with Docker for easy setup and scalability
