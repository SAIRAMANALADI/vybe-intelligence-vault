## Summary
HederaToolbox is an MCP (Model Context Protocol) server providing AI agents with structured, metered access to the Hedera ecosystem, including HCS topics, tokens, identity, smart contracts, governance, and compliance tools. It enables agents to reason about Hedera operations with pay-per-call pricing in HBAR and no registration requirements.

## Key Features
- 23 tools/modules for Hedera ecosystem interaction (HCS, tokens, governance, identity, compliance)
- Pay-per-call pricing in HBAR with no registration required
- Tamper-proof record-keeping via HCS for audit trails and compliance
- Integration with Fixatum DID for reputation and KYC verification
- Production-ready examples for autonomous agents (reputation monitoring, compliance, whale alerts, due diligence, DAO governance)
