## Summary
frontprompt is a Python tool that integrates a real Chromium browser with an in-page overlay for annotating web pages and driving them via an AI agent. It provides structured state persistence across cross-origin navigations and exposes an MCP server for agent-driven browser automation.

## Key Features
- Real-time in-page overlay (shadow-DOM HUD) for interactive annotation
- MCP server exposing tools for AI agent navigation and interaction
- State persistence across cross-origin navigations
- Zero-setup installation via Claude Code plugin or standalone CLI
- Embedded Svelte overlay with no external runtime dependencies

## Why It Matters for RAG Builders
It enables AI agents to interact with and annotate web pages persistently, bridging the gap between static web content and dynamic agent-driven workflows.
