## Summary
A Chrome/Edge side panel browser extension that connects web context to the Hermes Agent runtime, enabling real-time interaction with local or remote Hermes API servers for AI-driven tasks like summarization, transcription, and session management.

## Key Features
- Chrome/Edge side panel integration with Hermes Agent runtime
- Configurable local or remote API server connectivity
- Automatic synchronization of models, sessions, skills, and profiles
- Secure read-only browser context capture with untrusted text wrapping
- Voice dictation support via local Hermes audio transcription API

## Why It Matters for RAG Builders
It bridges web browsing context directly to AI agent runtimes, enabling seamless, secure, and real-time AI interactions within the browser environment for RAG and agent-based workflows.
