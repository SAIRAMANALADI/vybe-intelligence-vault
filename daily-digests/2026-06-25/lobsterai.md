## Summary
LobsterAI is an open-source, desktop-grade AI agent assistant developed by NetEase Youdao, designed to perform real-world office tasks such as data analysis, document creation, and automation. It integrates with local tools, files, and systems, enabling users to command their computer via multiple IM platforms like WeChat and Feishu.

## Key Features
- 24/7 desktop-grade AI assistant with real-time tool execution in local environment
- Cross-platform support (macOS, Windows) with mobile command access via IM platforms
- Built on OpenClaw framework with extensible Skills, Expert Kits, and MCP server integration
- Persistent memory and context-aware task execution with user approval gating for security
- Pre-built Python runtime for Windows and support for scheduled, recurring tasks
