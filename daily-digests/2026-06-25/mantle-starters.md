## Summary
Mantle-starters provides blank-first starter templates for Mantle provisioning, enabling deterministic repository generation with vendored UI primitives from Kiwa. It simplifies bootstrapping by eliminating the need for external registry access during initial setup.

## Key Features
- Blank-first starter templates for rapid bootstrapping
- Vendored Kiwa UI primitives for offline-first generation
- Provision bundles and overlays for type-specific customization
- Automated validation and type checking workflows
- GitHub-release scaffolding for versioned deployments

## Why It Matters for RAG Builders
