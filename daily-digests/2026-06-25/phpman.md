## Summary
phpMan is an open-source web interface and MCP server that provides structured access to Unix man pages, perldoc, Python docs, Ruby docs, and texinfo. It offers both a REST API and MCP protocol for AI agents to query documentation programmatically.

## Key Features
- Provides structured JSON and MCP-compatible access to Unix man pages, perldoc, pydoc, and Ruby docs
- Supports full-text search via FTS5 with SQLite backend
- Implements Model Context Protocol (MCP) for seamless AI agent integration
- Offers both REST API and MCP endpoints for flexible querying
- Includes auto-detection for command types (man, perldoc, pydoc, etc.)

## Why It Matters for RAG Builders
phpMan enables AI agents to programmatically query and integrate Unix documentation, enhancing RAG pipelines with accurate, structured, and up-to-date reference material.
