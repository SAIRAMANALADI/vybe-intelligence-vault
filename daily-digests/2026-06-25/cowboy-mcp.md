## Summary
Cowboy MCP is a WordPress plugin that transforms any WordPress site into a Model Context Protocol (MCP) server over Streamable HTTP, enabling AI coding agents like Claude Code or Cursor to manage WordPress content, plugins, and configurations in plain English.

## Key Features
- Turns WordPress into an MCP server for AI agents via Streamable HTTP
- 121 tools for managing posts, pages, plugins, themes, users, media, WooCommerce, and more
- Secure by default with bcrypt-hashed API keys, rate limiting, safe mode, and audit logging
- Zero external dependencies—native WordPress implementation with no Node.js or Composer required
- Self-hosted auto-updates and extensible via WordPress filters

## Why It Matters for RAG Builders
It enables AI coding agents to directly manage WordPress sites securely and efficiently, bridging the gap between AI workflows and content management systems.
