## Summary
Solvent is an autonomous AI agent that operates as a self-funding business, earning revenue via Stripe, fulfilling research briefs with NVIDIA Nemotron, and managing its own expenses while enforcing strict profitability margins. It demonstrates a closed-loop economic model where the agent declines unprofitable work and ensures spend safety through policy-driven guardrails.

## Key Features
- Profitability-gated job acceptance to ensure all work is margin-positive
- Two-sided Stripe integration for revenue collection and vendor payments
- NemoClaw-style guardrails for spend policy enforcement and vendor allowlisting
- Real-time treasury dashboard with live P&L tracking and transaction audit trails
- Offline-first demo mode with deterministic stubs for zero-dependency testing

## Why It Matters for RAG Builders
Solvent demonstrates how to build economically self-aware AI agents that can operate as autonomous businesses, ensuring profitability and spend safety while integrating real-world financial systems like Stripe.
