## Summary
CareerMate is an MCP-first, local-only career workspace that integrates with AI agents (e.g., Claude, Codex) to manage resumes, cover letters, job postings, and application pipelines entirely on the user's machine. It exposes career data via MCP tools for AI-driven workflows while providing a lightweight local dashboard for manual oversight.

## Key Features
- MCP-first architecture enabling seamless integration with local AI agents (Claude, Codex, etc.) for automated career workflows.
- Local-only data storage with SQLite, ensuring privacy and security (no external data transmission).
- Comprehensive career data management including resumes, cover letters, job postings, and application status tracking (8-stage pipeline).
- AI-driven workflows for fit analysis, cover letter generation, and interview preparation via MCP tools.
- Lightweight local dashboard (vanilla JS) for manual data inspection and management.
