## Summary
MCP server for Rendex that enables AI agents to render webpages, HTML, or Markdown into images, PDFs, or clean extracted content via the Model Context Protocol. Supports dynamic OG images, branded artifacts, and visual-diff website monitoring.

## Key Features
- Render webpages, HTML, or Markdown to images/PDFs with fine-grained control over viewport, format, and rendering options
- Extract clean reader-mode content from SPAs or dynamic pages as Markdown, JSON, or HTML for LLM ingestion
- Generate signed, hosted, edge-cached image URLs for dynamic OG images or shared artifacts
- Create branded artifacts (PDF, PNG, share page) with custom logos, colors, and layouts in a single call
- Visual-diff website monitoring with real-Chrome captures, text diffs, and webhook notifications

## Why It Matters for RAG Builders
It provides AI agents with essential rendering and extraction capabilities for web content, enabling dynamic OG images, clean text extraction for RAG, and automated monitoring of web changes.
