## Summary
An agentic AI-powered supply chain diagnostic platform built on the Anthropic Claude SDK that assesses end-to-end supply chain health across 8 SCOR-aligned domains against 2026 world-class benchmarks in under 60 seconds. Features a browser-based UI, MCP server integration, and autonomous market intelligence gathering.

## Key Features
- Assesses supply chain health across 8 SCOR-aligned domains (Demand, Procurement, Manufacturing, Inventory, Logistics, Warehousing, Risk, Sustainability) with 2026 benchmarks
- Autonomous live market intelligence and web search integration for real-time data
- MCP server (stdio transport) with 3 tools (run_assessment, get_benchmarks, get_assessment_history) for Claude Desktop/Code compatibility
- 5 user personas (Analyst, Executive, Consultant, Enterprise, Government) with tailored assessments and outputs
- Phase 2 integrations: Slack, Jira, email, SQLite memory engine, and proactive risk monitoring

## Why It Matters for RAG Builders
It provides a rapid, agentic assessment of supply chain health with autonomous data gathering, making it essential for AI-driven supply chain optimization and decision-making.
