## Summary
Presenton is an open-source AI-powered presentation generator and API that enables users to create, edit, and export professional presentations from prompts or documents. It supports self-hosting, desktop apps, and cloud deployment with flexible model provider integrations.

## Key Features
- AI-powered presentation generation from prompts or documents
- Support for multiple AI model providers (OpenAI, Gemini, Ollama, etc.)
- Self-hosted deployment options (Docker, desktop app, cloud)
- Full PPTX and PDF export with professional formatting
- Built-in MCP server for programmatic presentation generation

## Why It Matters for RAG Builders
Presenton provides an open-source, self-hostable alternative for AI-driven presentation generation, reducing SaaS lock-in and enabling full control over data and models for RAG builders.
