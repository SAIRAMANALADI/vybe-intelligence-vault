## Summary
rijksmuseum-mcp+ is an MCP (Model Context Protocol) server that bridges AI assistants with enriched metadata from the Rijksmuseum's open-access collections, enabling advanced semantic search, provenance analysis, and artwork similarity comparisons beyond the museum's native APIs.

## Key Features
- Enhanced metadata search with 30+ filterable parameters, including subject, depicted persons/places, and geospatial proximity
- Semantic and full-text search across multiple metadata fields for interpretive queries
- Structured provenance analysis with over 100,000 parsed ownership events and transfer types
- Artwork similarity comparisons using AI-based visual and metadata analysis
- Integration with Iconclass for hierarchical concept-based exploration and cross-institution art research

## Why It Matters for RAG Builders
It provides AI engineers with a powerful, enriched interface to cultural heritage data, enabling advanced RAG applications with semantic, geospatial, and provenance-aware search capabilities for art and museum collections.
