## Summary
A polyglot AI agent service providing hybrid retrieval (dense + sparse + rerank), durable agent checkpoints, human-in-the-loop approvals, and multi-participant conversations via a single WebSocket protocol. Supports Kubernetes, AWS serverless, and local deployments with a unified binary.

## Key Features
- Unified WebSocket protocol across 5 languages (Rust, TypeScript, Go, .NET, Python)
- Hybrid retrieval (dense + sparse + rerank) with pgvector/DynamoDB/S3 Vectors
- Durable agent checkpoints and multi-participant conversation support
- Three deployment flavors: Kubernetes, AWS serverless, and local (in-memory)
- Human-in-the-loop approvals and tool action confirmation workflows

## Why It Matters for RAG Builders
It provides a unified, protocol-driven AI agent orchestration layer that simplifies building and deploying RAG systems with hybrid retrieval, durable state, and multi-agent interactions across multiple deployment environments.
