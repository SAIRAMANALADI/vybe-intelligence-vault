## Summary
A local MCP server that integrates Telegram personal accounts (not bots) with AI agents like Cursor and Claude Desktop, enabling natural-language queries over Telegram channels, folders, and messages for digests and search.

## Key Features
- 20+ MCP tools for Telegram channel and message management (create, search, join, leave, etc.)
- QR-based login for secure Telegram account access without SMS
- Supports digests and full-text search across folders and channels
- Post links included in message metadata for direct access
- Modular architecture with TypeScript and ESM support

## Why It Matters for RAG Builders
It enables AI agents to interact with Telegram data in real-time, unlocking advanced RAG capabilities for personalized digests and contextual search over private channels.
