## Summary
Pentagonal is an AI-powered smart contract forge that generates, audits, fixes, and compiles Solidity and Anchor/Rust contracts across 8 chains. It features an 8-agent adversarial security audit system, token intelligence lookups, and a self-learning security rules engine.

## Key Features
- 8-agent adversarial security audit system covering reentrancy, flash loans, MEV, and more
- AI-powered contract generation for Solidity (EVM) and Anchor/Rust (Solana)
- Token intelligence with market data, holder analysis, and honeypot detection
- Self-learning security rules engine that improves with every audit
- Multi-chain support (Ethereum, Base, Polygon, Arbitrum, Optimism, BSC, Avalanche, Solana)
