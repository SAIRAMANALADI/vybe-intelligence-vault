## Summary
claude-code-safety-net is a protective plugin designed to prevent harmful Git and filesystem commands from executing, acting as a safety shield for users' files and data. It provides a user-friendly interface and cross-platform support to mitigate risks during command execution.

## Key Features
- Prevents execution of destructive Git and filesystem commands
- User-friendly interface for non-technical users
- Cross-platform support (Windows, macOS, Linux)
- Local execution with no data collection
- Regular updates for security enhancements
