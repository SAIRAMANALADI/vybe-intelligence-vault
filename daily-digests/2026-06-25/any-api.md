## Summary
any-api is a unified gateway that simplifies integration with multiple AI models by providing a single interface to route requests between services like OpenAI, Claude, and Gemini. It abstracts protocol differences and format conversions, enabling seamless cross-model interactions.

## Key Features
- Unified interface for multiple AI models (OpenAI, Claude, Gemini, etc.)
- Automatic format conversion between model requests/responses
- Lightweight deployment via Cloudflare Workers
- Simplified integration for developers
- Cross-platform support (Windows, macOS, Linux)
