## Summary
Gearlynx is a highly accurate cross-platform Atari Lynx emulator written in C++ with support for Windows, macOS, Linux, BSD, and RetroArch. It includes an embedded Model Context Protocol (MCP) server for AI-assisted debugging and tooling, enabling integration with AI agents like GitHub Copilot and Claude.

## Key Features
- Highly accurate Atari Lynx emulation with full commercial and homebrew ROM support
- Embedded MCP server for AI-assisted debugging and hardware inspection
- Cross-platform support (Windows, macOS, Linux, BSD, RetroArch)
- Advanced debugging tools including breakpoints, disassembly, and memory inspection
- Save states, rewind support, and programmable shader chains for enhanced emulation
