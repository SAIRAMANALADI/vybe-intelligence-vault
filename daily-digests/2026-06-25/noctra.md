## Summary
Noctra automates Linear ticket implementation by dispatching coding agents (Claude Code, OpenAI Codex, GitHub Copilot, or Google Antigravity) to create PRs from tickets moved to 'Next', streamlining the development workflow from ticket to PR while you sleep.

## Key Features
- Automated ticket-to-PR conversion with isolated git worktrees per ticket
- Supports multiple coding agents (Claude Code, OpenAI Codex, GitHub Copilot, Google Antigravity)
- Optional multi-model review gate using Gemini for independent validation
- Telegram integration for real-time alerts and control
- Supports Docker and cloud deployments (Fly, Render, Railway, DigitalOcean)
