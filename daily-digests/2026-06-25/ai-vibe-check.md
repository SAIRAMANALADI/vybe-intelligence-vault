## Summary
AI-Vibe-Check is a desktop application that tracks developer well-being by analyzing posts from Hacker News and Reddit to generate a daily 'Developer Anxiety Score' and mood trends. It provides visual data representation and self-updating features for insights into emotional state.

## Key Features
- Daily Developer Anxiety Score generation from social media data
- Visual data representation with graphs and charts
- Self-updating dashboard for latest features and bug fixes
- Cross-platform support (Windows, macOS, Linux)
- Automated data fetching from Hacker News and Reddit
