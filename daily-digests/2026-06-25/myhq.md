## Summary
MyHQ is a self-hosted platform for managing autonomous AI agents via Telegram or a web dashboard, enabling users to coordinate specialized agents (Leads) for tasks like DevOps, finance, and research. Built on Claude Code, it integrates deeply with system operations while maintaining user control through approval gates.

## Key Features
- Hierarchical agent coordination with Atlas (coordinator) and specialized Leads (e.g., DevOps, Finance)
- Telegram and web dashboard interfaces for real-time interaction and monitoring
- Memory tiering (hot/warm/cold) with automatic decay and recall optimization
- Proactive monitoring and heartbeat system for automated issue detection
- Skills library for compounding reusable workflows and procedures
