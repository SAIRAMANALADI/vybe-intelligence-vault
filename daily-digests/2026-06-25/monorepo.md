## Summary
Mnemonic Protocol provides a verifiable, persistent memory layer for AI agents, enabling semantically searchable, cryptographically signed, and optionally blockchain-anchored memories. It exposes functionality via the Model Context Protocol (MCP) for seamless integration with MCP-compatible clients like Claude or Cursor.

## Key Features
- Semantically embedded memories for recall by meaning, not keywords
- Cryptographically signed memories (COSE_Sign1) with Ed25519 identity for verifiable authorship
- Optional on-chain anchoring on Solana and Arweave for independent verification
- Exposure via Model Context Protocol (MCP) for drop-in integration with MCP-compatible clients
- Local and full storage modes with dynamic pricing for production use

## Why It Matters for RAG Builders
It enables AI agents to maintain persistent, verifiable, and portable memories across sessions and models, ensuring trustless recall and auditability for critical applications.
