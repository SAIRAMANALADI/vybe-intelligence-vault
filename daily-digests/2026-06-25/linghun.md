## Summary
Linghun is a local-first, evidence-first AI programming runtime that integrates large language models with real-world projects, tools, permissions, and verification systems. It acts as an engineering exoskeleton for models, ensuring actions are grounded in actual code, evidence, and validation rather than hallucinations or unchecked assumptions.

## Key Features
- Evidence-first engineering loop: binds model outputs to real file reads, tool executions, and Git states to minimize hallucinations
- Local-first architecture with strict permission and security boundaries for code execution and model provider keys
- Workflow Matrix for complex tasks: durable jobs, background tasks, multi-agent coordination, and phased execution with verification gates
- AntiCodeBlob system to enforce architectural hygiene and prevent codebase degradation during modifications
- Cross-platform support (Windows, macOS, Linux) with native terminal and path handling, including Chinese language and non-ASCII path compatibility
