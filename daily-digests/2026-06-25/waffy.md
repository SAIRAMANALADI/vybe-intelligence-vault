## Summary
Waffy is an open-source Chrome extension that provides AI-powered browser automation via a side panel, enabling users to perform tasks like clicking elements, filling forms, and extracting data using natural language instructions and vision-capable models.

## Key Features
- Natural language automation for browser tasks
- Vision-based interaction with screenshots and coordinates
- Multi-stage pipeline with configurable models for planning, execution, and validation
- Local storage of API keys and conversation history for privacy
- Support for multiple AI providers and flexible model configuration
