## Summary
AION is a local-first AI super-agent that runs entirely on-device, combining Rust and Next.js to provide an observable, persistent AI assistant with a functional mind, darwinian memory, and self-improving capabilities. It integrates LLMs (Ollama), vector databases, WASM skills, and E2E-encrypted sync for privacy-focused AI interactions.

## Key Features
- 100% local execution with Ollama LLM and embeddings (BGE-M3) for zero inference costs and data privacy
- Observable functional mind with Global Workspace Theory (GWT), Φ-like integration index, and real-time state monitoring
- Darwinian vector memory and lazy knowledge graph for incremental, self-improving knowledge retention
- Self-generating WASM skills executed in a sandboxed, deny-all environment with governance controls
- End-to-end encrypted sync, multi-agent crew orchestration, and autonomous life cycles for persistent AI cognition
