## Summary
SolHunt is a secure Solana recovery protocol and developer tool designed to help users and AI agents recover trapped SOL, revoke dangerous delegations, and optimize account state. It operates entirely client-side with no backend signing authority, ensuring maximum security against drainers.

## Key Features
- Nine production-grade recovery engines for reclaiming SOL, revoking permissions, and harvesting fees
- 100% client-side transaction construction with no backend signing authority
- Native MCP integration for autonomous AI agent interactions
- Instruction-level isolation to prevent transfer paradigms and drainer risks
- Open-source and MIT-licensed for transparency and community auditing

## Why It Matters for RAG Builders
SolHunt provides a critical security layer for Solana users and AI agents by enabling safe recovery of trapped assets while eliminating trust assumptions through client-side execution.
