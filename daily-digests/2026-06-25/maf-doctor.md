## Summary
MAF Doctor is a .NET global tool and MCP server designed to diagnose, explain, prescribe, and verify Microsoft Agent Framework (MAF) agents and workflows. It provides CLI commands, Roslyn analyzers, and an automated migration assistant for upgrading or migrating from Semantic Kernel to MAF.

## Key Features
- 27 executable MCP tools, 7 resources, and 10 prompts for agentic workflows
- CLI commands for health grading, auto-fixing, and scaffolding MAF agents
- Roslyn analyzers (MAF001/MAF002/MAF003) for IDE write-time enforcement
- Cross-framework migration assistant for Semantic Kernel to MAF
- Self-updating knowledge base aligned with MAF version releases

## Why It Matters for RAG Builders
MAF Doctor streamlines MAF agent development by providing automated diagnostics, migration support, and IDE-integrated analyzers, reducing manual effort and improving code quality for RAG and AI stack builders.
