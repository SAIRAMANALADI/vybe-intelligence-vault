## Summary
The OneBrain CLI is a local-first Rust binary that powers the OneBrain personal AI OS for Obsidian. It provides a deterministic, cross-platform command-line interface for scaffolding vaults, syncing plugins, running scheduled skills, diagnosing vault health, and self-updating across AI harnesses like Claude Code and Gemini CLI.

## Key Features
- Scaffolds and manages Obsidian vaults with deterministic behavior across platforms
- Syncs the OneBrain plugin and supports scheduled skills execution
- Provides vault diagnostics and health checks for AI agents
- Self-updating binary with SHA-256 verification for security
- Cross-harness compatibility with Claude Code and Gemini CLI

## Why It Matters for RAG Builders
It standardizes and simplifies AI agent interactions with Obsidian vaults by providing a single, deterministic CLI that ensures consistent behavior and reduces token usage in RAG pipelines.
