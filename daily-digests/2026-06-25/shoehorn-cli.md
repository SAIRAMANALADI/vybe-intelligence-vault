## Summary
Shoehorn CLI is a command-line interface for the Shoehorn Intelligent Developer Platform, enabling users to interact with service catalogs, manage governance actions, run Forge workflows, and handle GitOps resources via a rich terminal-based TUI.

## Key Features
- Interactive TUI for browsing service catalogs and managing resources
- Support for Forge workflows and mold execution
- Governance actions and scorecard visibility
- Multi-platform installation via Homebrew, Mise, Scoop, and manual binary
- Authentication and CI/CD integration for catalog quality checks
