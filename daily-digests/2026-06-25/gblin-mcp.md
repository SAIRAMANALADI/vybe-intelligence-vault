## Summary
GBLIN-MCP is an MCP server enabling AI agents to hold capital in GBLIN, a diversified on-chain index on Base mainnet with a Crash Shield mechanism. It allows agents to JIT-swap GBLIN to USDC for x402 invoice payments while earning yield on idle capital.

## Key Features
- Exposes 8 MCP tools for GBLIN treasury operations (free and paid via x402)
- Supports atomic JIT swaps for x402 invoice payments with dynamic slippage
- Integrates with ElizaOS and other AI agent frameworks via MCP
- Enforces 48h timelock governance for trustless on-chain operations
- Provides real-time treasury state, NAV, and Crash Shield status

## Why It Matters for RAG Builders
It enables AI agents to hold and actively manage capital in a yield-bearing on-chain index while ensuring instant liquidity for payments, bridging AI agent economics with decentralized finance.
