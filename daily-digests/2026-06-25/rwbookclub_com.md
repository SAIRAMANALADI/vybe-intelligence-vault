## Summary
A monorepo for the R/W Book Club, hosting a static website, a shared knowledge corpus, and Oliver, a Discord agent. The project uses Git as the source of truth for club data, with Eleventy for the website and Python for corpus management and the Discord bot.

## Key Features
- Git-backed knowledge corpus as the single source of truth for club data
- Static website built with Eleventy consuming the corpus for dynamic content
- Oliver, a Discord bot using the corpus as context for answering questions via Claude
- Automated deployment to GitHub Pages on data or template changes
- Comprehensive data schema with per-entity text files for books, members, reviews, and meetings
