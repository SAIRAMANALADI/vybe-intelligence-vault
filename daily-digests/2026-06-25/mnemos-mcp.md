## Summary
mnemos-mcp is a self-hosted, private knowledge server that transforms documents into searchable, isolated collections using local vector search. It enables users to organize, ingest, and query private data without relying on external services or vendor lock-in.

## Key Features
- Multi-collection isolation for organizing data by topic or context
- Deterministic document ingestion for consistent results
- Local vector search for fast, private retrieval without external dependencies
- 100% private data processing with zero vendor lock-in
- Cross-platform support (Windows, macOS, Linux)
