## Summary
An open-source MCP (Model Context Protocol) server that enables AI assistants to interact with LinkedIn data through a user's authenticated browser session. It provides tools to fetch profiles, companies, jobs, messages, and other LinkedIn data for integration into AI workflows.

## Key Features
- Access LinkedIn profiles, companies, jobs, and messages via authenticated browser session
- Supports profile section filtering (experience, education, skills, etc.)
- Provides search capabilities for people, companies, and jobs
- Enables messaging interactions (inbox, conversations, sending messages)
- Supports local deployment with Docker or direct installation

## Why It Matters for RAG Builders
It bridges AI assistants with real-time LinkedIn data, enabling richer context for RAG systems and automated workflows without requiring direct API access.
