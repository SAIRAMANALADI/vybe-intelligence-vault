## Summary
Workflow Blueprint is a Next.js-based task-planning workspace with board-based task management, subtasks, recurring work, and notes, featuring a first-class agent-access layer. It includes a full read/write REST API, per-user scoped API tokens, and an in-repo MCP server for headless AI agent integration.

## Key Features
- Board-based task planning with subtasks and recurring work
- Full read/write REST API with per-user scoped API tokens
- In-repo MCP server for headless AI agent integration
- Multi-agent development workflow with PR-level guardrails (Verifier rules)
- Machine-readable API contract with CI drift detection via OpenAPI and Zod schemas
