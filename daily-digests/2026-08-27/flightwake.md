## Summary
flightwake is an ultra-lightweight framework designed to record and manage work for strong AI coding agents, ensuring continuity across sessions without runtime dependencies. It uses pure Markdown files stored in git to track state, decisions, traps, and records, enabling seamless handoffs between agents or human collaborators.

## Key Features
- Zero runtime dependencies with pure Markdown and git-based storage
- Triggers for recording decisions, traps, and state updates (e.g., /fw-coldstart, /fw-record)
- STATE.md for tracking current position and next-step entry points
- DECISIONS.md and TRAPS.md for append-only logs of critical actions and pitfalls
- CI integration for enforcing state freshness (e.g., preventing stale STATE)

## Why It Matters for RAG Builders
It ensures AI agents and human collaborators can seamlessly resume work across sessions by maintaining a persistent, git-tracked record of state, decisions, and traps without adding runtime overhead.
