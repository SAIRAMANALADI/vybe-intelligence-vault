## Summary
Honcho is a memory infrastructure system designed for building stateful AI agents that require persistent, evolving context. It enables agents to store, reason over, and query conversations, events, and documents to maintain accurate representations of users, agents, and groups over time.

## Key Features
- Reasoning-first memory extraction from conversations and events, not just chunk matching
- Peer-centric model tracking users, agents, groups, projects, and ideas over time
- Hybrid search combining BM25 and vector embeddings for accurate retrieval
- Managed service (api.honcho.dev) or self-hosted FastAPI server deployment options
- SDKs for Python and TypeScript with MCP integrations for popular agent frameworks

## Why It Matters for RAG Builders
Honcho provides the critical memory infrastructure that enables AI agents to retain and reason over long-term context, a foundational requirement for building advanced, stateful RAG systems.
