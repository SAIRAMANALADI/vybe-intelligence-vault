## Summary
cortex-viz is a read-only visualization layer for Cortex that transforms memory stores, Claude Code session history, and codebase graphs into six interactive reading angles: a neural galaxy, 3D brain, execution trace, consolidation kanban, knowledge browser, and wiki. It renders data without writing memories, offering real-time, exact counts and deep insights into code and memory structures.

## Key Features
- Six live reading angles (Graph, Brain, Trace, Knowledge, Wiki, Board) for deep data exploration
- Neuroscience-inspired 3D brain visualization with real MNI152 atlas coordinates
- Real-time execution trace with exact counts and git diffs
- Consolidation kanban with physics-based stage progression
- Standalone Trace view without Cortex/PostgreSQL dependency

## Why It Matters for RAG Builders
It provides unparalleled transparency into AI agent workflows, memory consolidation, and codebase structure, enabling RAG builders to debug, optimize, and understand complex AI interactions and data flows.
