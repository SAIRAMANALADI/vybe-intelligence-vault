## Summary
keenetic-mcp is a Model Context Protocol (MCP) server that enables AI assistants to control Keenetic routers via natural language commands. It bridges AI tools like Claude Code or Cursor with Keenetic routers to manage Wi-Fi, VPN, device access, and network settings without requiring router-side installations.

## Key Features
- Enables AI assistants to manage Keenetic routers via natural language commands
- Supports read-only and write modes for secure network control
- Integrates with AI tools like Claude Code, Cursor, or Codex via MCP
- Provides plugin-based skills for dynamic task execution (e.g., Wi-Fi management, VPN routing)
- Local-first architecture with no cloud dependency or router-side installations

## Why It Matters for RAG Builders
It simplifies network management for AI-driven workflows by allowing seamless, conversational control of Keenetic routers without technical expertise.
