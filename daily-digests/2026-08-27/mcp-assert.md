## Summary
mcp-assert is a testing framework for MCP (Model Context Protocol) servers that validates protocol compliance, schema correctness, and tool behavior using real transport mechanisms like stdio, SSE, or HTTP. It identifies 24 types of schema issues and provides deterministic assertions for MCP tools.

## Key Features
- Real protocol testing over stdio/SSE/HTTP (no mocks)
- 24 static analysis rules for schema correctness and agent usability
- Automated test generation and adversarial fuzzing
- Multi-language support (Go, TypeScript, Python, etc.)
- CI/CD integration with GitHub Actions, JUnit XML, and regression detection

## Why It Matters for RAG Builders
It ensures MCP servers are protocol-compliant and schema-correct, preventing common failures that break agent integrations and enabling reliable RAG pipelines.
