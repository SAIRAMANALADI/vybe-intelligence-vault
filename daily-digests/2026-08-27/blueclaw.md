## Summary
BlueClaw is a terminal-first observability and debugging toolkit for AI agents, enabling structured tracing, regression testing, and reproducible runs. It supports multi-model providers (Claude, Ollama, OpenAI, Gemini) and provides HTTP/Telegram interfaces for real-time interaction.

## Key Features
- Structured JSON traces and per-turn event streams for debugging agent behavior
- Regression testing with YAML-based specs and CI integration (TAP/JUnit)
- Context management with observation masking to reduce token costs
- HTTP API with bearer auth, SSE streaming, and file uploads
- Telegram bridge for mobile interaction with per-chat workspaces
