## Summary
OpenMozi is a self-hosted, desktop AI agent that executes real tasks on your machine, including code edits, document generation, and automation. It operates entirely locally with optional server mode and supports multiple LLM providers.

## Key Features
- Executes real deliverables verified against the filesystem (no fake success)
- Supports 25+ LLM providers with regional endpoint overrides
- In-app document generation and interactive previews (Word, Excel, PDF, PowerPoint)
- Long-term memory and scheduled automation with reusable task templates
- Hackable architecture with 5-layer runtime and optional ONLYOFFICE integration

## Why It Matters for RAG Builders
OpenMozi provides a robust, self-hosted framework for building AI agents that execute real tasks locally, reducing dependency on cloud-based solutions and enabling full control over data and workflows.
