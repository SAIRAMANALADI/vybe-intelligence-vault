## Summary
OpenCode Permission Reviewer is an unofficial community plugin for OpenCode that acts as a tool-free AI reviewer for every `ask` permission. It evaluates requests, policies, and session context to automatically allow safe actions, deny with feedback, or escalate to the user, ensuring critical risks are never approved without review.

## Key Features
- Tool-free AI reviewer for OpenCode `ask` permissions with no recursive tool access
- Policy-controlled automatic approvals, denials, or escalations based on risk assessment
- Read-only evidence enrichment (SSH, Git, scripts) with automatic credential redaction
- Auditable JSONL logs with SHA-256 hashed remote commands for security
- Optional TUI overlay for real-time review state visibility and native approval control integration

## Why It Matters for RAG Builders
It reduces manual review overhead for safe actions while ensuring critical risks are never auto-approved, making AI agent workflows both efficient and secure.
