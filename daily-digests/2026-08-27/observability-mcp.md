## Summary
A unified observability gateway for AI agents that normalizes data from multiple observability backends (e.g., Prometheus, Loki) into a single MCP endpoint, enabling agents to query and analyze incidents with pre-computed topology and anomaly detection tools.

## Key Features
- Unified MCP endpoint for multiple observability backends with pluggable connectors
- Cross-signal anomaly detection and weighted health scoring for robust incident analysis
- Built-in web UI for configuration, monitoring, and real-time agent behavior inspection
- Dynamic label resolution and service discovery across Prometheus and Loki
- Inspect & enforce mode for learning agent behavior and blocking abnormal tool calls

## Why It Matters for RAG Builders
It provides a single normalized interface for AI agents to query and analyze observability data, reducing hallucinations and enabling smaller or local models to perform incident triage accurately without needing to learn multiple query languages.
