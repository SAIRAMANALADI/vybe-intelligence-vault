## Summary
Echo is a local persistent memory system for AI agents and developers, enabling durable memory storage with fast recall and explicit governance. It integrates with AI workflows via the Model Context Protocol (MCP) and provides a CLI for human interaction, all built in Go with SQLite, FTS5, and DuckDB.

## Key Features
- Persistent memory storage with context scoping and tagging for AI agents
- Dual-interface architecture (MCP server and CLI) for seamless AI and human interaction
- Fast local recall with SQLite FTS5 full-text search and sub-10ms query performance
- Safety mechanisms for destructive operations (retrieve-confirm-act flow)
- Analytics and telemetry via DuckDB for usage tracking and cost estimation

## Why It Matters for RAG Builders
Echo solves the statelessness gap in LLM workflows by providing durable, queryable memory layers essential for RAG systems and agent frameworks.
