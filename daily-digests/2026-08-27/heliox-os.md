## Summary
Heliox OS is an open-source, privacy-first AI agent that enables users to control their entire computer via natural language, voice, and hand gestures. It functions as a proactive, autonomous multi-agent system with advanced cognitive features like TRIBE v2 integration for neuro-adaptive interactions.

## Key Features
- Modular multi-agent architecture with specialized agents (System, Code, Web, Monitor, Communication)
- Proactive AI system with TRIBE v2 cognitive engine for neuro-adaptive interactions
- Natural language, voice, and hand gesture control with real-time screen awareness
- Fire-and-forget autonomous task execution with verification and rollback support
- Privacy-first design with five-tier permission system and local processing
