## Summary
A community-driven, source-only customization of the GenericAgent framework tailored for Windows desktop environments. It enhances long-conversation behavior, cache management, desktop interaction, and observability while maintaining strict user-data boundaries and security constraints.

## Key Features
- DeepSeek-aware cache accounting and token usage with explicit provider-cost semantics
- Durable per-session drafts, run state, and tool/reasoning journals with progressive disclosure
- Main-chat subagent activity without separate conductor workspace
- Dry-run-first, hash-verified, backed-up installation with strict user-data preservation
- Explicit model selection with sticky new-chat inheritance and no silent failover

## Why It Matters for RAG Builders
It provides a secure, community-driven desktop agent framework with advanced cache economics and long-conversation UX optimizations critical for local AI deployments.
