## Summary
AMOS Desktop is a native desktop application that serves as the local operator for the governed AMOS company brain, enabling secure, governed AI workflows with explicit control over where intelligence runs and how company context is accessed. It bridges local workspaces with AMOS's managed platform for durable organizational memory and governance.

## Key Features
- Native desktop app for macOS (Apple Silicon/Intel) and Windows with signed releases and auto-updates
- Explicit control over local vs. company context with secure memory isolation and encryption
- Support for multiple intelligence profiles (AMOS Intelligence, Bedrock, local models, provider APIs)
- Governed workflows with approvals, receipts, and policy enforcement for consequential actions
- Offline capabilities with server-signed briefings, encrypted drafts, and resumable task checkpoints

## Why It Matters for RAG Builders
AMOS Desktop provides a critical local execution layer for governed AI workflows, enabling secure, human-controlled interactions with company systems while maintaining model independence and policy enforcement.
