## Summary
AgentForge WebUI is a React-based single-page application (SPA) that provides a frontend interface for interacting with the AgentForge backend. It visualizes the agent's think-act-observe loop, manages sessions, connectors, and command permissions, and offers a rich chat experience with streaming updates.

## Key Features
- Real-time streaming of agent's think-act-observe loop via WebSocket
- Mode picker for 14+ agent modes (chat, search, coding, etc.) with visual differentiation
- Command Permissions modal for managing shell/SSH policies and user profiles
- Connectors UI for multi-account Google, GitLab, and GitHub integrations
- Canvas workspace, bookmarks, session history, and file uploads with inline previews

## Why It Matters for RAG Builders
It provides a polished, feature-rich frontend for AgentForge, enabling seamless interaction with AI agents and their outputs in a single, interactive UI.
