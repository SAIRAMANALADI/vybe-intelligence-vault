## Summary
Cockroach Browser is a local-first TypeScript runtime that provides a secure, governed Chromium environment for AI agents to interact with web pages without inheriting machine-level access. It emphasizes explicit authority control, verifiable evidence, and policy-bounded operations for safe automation.

## Key Features
- Isolated Chromium sessions with explicit authority controls to prevent silent credential or profile access
- Semantic page snapshots, screenshots, PDFs, and network observations with verifiable evidence chains
- Maqam-governed actions requiring operator approval for high-authority operations like CAPTCHA handling
- Authenticated MCP server and REST API for programmatic access with policy-bounded job execution
- Local-first architecture with Docker support, persistent profiles, and human-in-the-loop challenge resolution

## Why It Matters for RAG Builders
It provides a secure, auditable, and policy-governed browser runtime essential for AI agents to safely interact with web content without compromising system integrity or exposing sensitive credentials.
