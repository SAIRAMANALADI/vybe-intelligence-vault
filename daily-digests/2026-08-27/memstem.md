## Summary
Memstem provides a unified memory and skill infrastructure for AI agents, acting as a central knowledge store that pulls memories from connected AI environments via filesystem watchers. It offers hybrid search, pluggable adapters, and an MCP-native API for seamless integration with modern AI agents.

## Key Features
- Pull-based memory ingestion via filesystem watchers (immune to AI upgrades)
- Hybrid search combining BM25, cosine similarity, and reciprocal rank fusion
- Pluggable adapters for multiple AI environments (Claude Code, OpenClaw, Codex, etc.)
- MCP-native API for seamless integration with modern AI agents
- Self-hosted embedder support (Ollama, Qwen3, etc.) with optional cloud providers

## Why It Matters for RAG Builders
Memstem eliminates version-fragility in AI memory systems by using pull-based ingestion and markdown-canonical storage, ensuring reliable, unified knowledge sharing across multiple AI agents and environments.
