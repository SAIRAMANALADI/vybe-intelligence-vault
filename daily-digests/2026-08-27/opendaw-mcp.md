## Summary
openDAW MCP is an MCP server that provides 532 tools for AI agents to programmatically control openDAW, a browser-based digital audio workstation. It enables agents to create, manipulate, and render music projects with full DAW functionality, including tracks, instruments, effects, MIDI, automation, and DSP scripting.

## Key Features
- 532 MCP tools for full DAW control (tracks, instruments, effects, MIDI, automation)
- Scriptable DSP devices (Werkstatt, Apparat, Spielwerk) with JavaScript compilation
- Suno AI integration for end-to-end music generation pipelines
- Stem separation with 7 SOTA models and GPU acceleration
- Agent skills with decision points for adaptive workflows across genres
