## Summary
Slopweaver is a local-first tool that builds an organization-specific world model from GitHub history by ingesting repositories, performing tiered synthesis (bronze → silver → gold), and enabling question-asking capabilities entirely on-device. It serves as a zero-config, privacy-focused alternative to hosted enterprise search solutions.

## Key Features
- Local-first synthesis of GitHub history into an organization-specific knowledge model
- Tiered data processing pipeline (bronze → silver → gold) for structured knowledge extraction
- Zero-key architecture with optional GitHub token for private repos
- Built-in security hygiene gate to detect and prevent secret leaks
- Claude Code plugin integration for seamless local deployment

## Why It Matters for RAG Builders
Slopweaver enables AI engineers to build secure, private, and organization-specific RAG systems by transforming raw GitHub data into structured knowledge models entirely on-device.
