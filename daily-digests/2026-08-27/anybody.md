## Summary
Anybody is an AI-powered app generator that transforms plain language prompts into functional applications in real time. Users can attach files for context and receive live code streaming with step-by-step status updates via WebSocket.

## Key Features
- Real-time app generation with live code streaming and status updates via WebSocket
- Supports file attachments (up to 5 files, 10MB each) for contextual prompts
- Project control features: start, cancel, resume, and auto-reconnect on disconnect
- Modern stack with Next.js 16, React 19, TypeScript, and Tailwind CSS
- Responsive design with TypeScript type safety and accessible UI components

## Why It Matters for RAG Builders
Anybody enables RAG builders to integrate real-time AI-driven app generation with live feedback and file context, streamlining the development of interactive AI-powered applications.
