## Summary
Veritas-Core is a production-grade agent infrastructure evolved from research foundations to deliver trustworthy, secure, and observable multi-agent systems. It features a runtime state machine, 3-tier memory architecture, and a dedicated trust layer for validation and security.

## Key Features
- Runtime state machine for agent lifecycle management with 10 states and retry logic
- 3-tier persistent memory (Conversation, Profile, History) for robust context handling
- Trust Layer with memory validation, agent permissions, and prompt injection defense
- Modular agent and tool architecture (6 cognitive agents + 5 generator tools)
- Secure EventBus and provider abstraction for scalable and maintainable systems
