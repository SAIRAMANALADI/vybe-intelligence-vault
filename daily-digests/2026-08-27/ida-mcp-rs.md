## Summary
Headless IDA Pro MCP server enabling AI-powered reverse engineering by exposing IDA Pro's capabilities as a Model Context Protocol (MCP) server. Provides programmatic access to disassembly, decompilation, function analysis, and binary inspection for AI agents.

## Key Features
- Headless IDA Pro integration via MCP for AI agents
- Supports disassembly, decompilation, and function analysis
- Multi-platform support (macOS, Linux, Windows)
- HTTP/SSE worker pool for multi-client stateful sessions
- dyld_shared_cache analysis for Apple binaries
