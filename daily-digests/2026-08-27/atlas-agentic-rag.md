## Summary
Atlas is a cohesive agentic RAG platform that integrates hybrid search (vector + BM25), knowledge graph retrieval, multi-model routing, and MCP tool-calling with built-in guardrails and a reproducible evaluation harness. It supports offline operation with local fallbacks and scales to hosted services like Redis, Langfuse, and cloud models.

## Key Features
- Hybrid retrieval combining vector, BM25, and knowledge graph with reciprocal-rank fusion and cross-encoder reranking
- Multi-model agent routing across Claude, OpenAI, Ollama, vLLM, and Bedrock with semantic caching
- Built-in guardrails for prompt injection, PII redaction, and content filtering with fail-closed safety
- Reproducible evaluation harness with LLM-as-judge metrics and CI-gated baseline comparisons
- Offline-first design with local fallbacks and Docker/Kubernetes deployment support

## Why It Matters for RAG Builders
Atlas provides a production-grade, end-to-end agentic RAG framework with rigorous evaluation and safety features, making it essential for building reliable and scalable AI systems.
