## Summary
Sherwood Exchange is a privacy-first decentralized exchange on Robinhood Chain, featuring a shielded ZK pool for private trades, a public multi-DEX aggregator, and an autonomous AI agent for live commerce. It combines zero-knowledge proofs with cross-chain functionality and a utility token ($SWOOD).

## Key Features
- Shielded trading via ZK Groth16 proofs with Poseidon Merkle trees for privacy
- Public multi-DEX aggregator supporting 1,000+ tokens including tokenized stocks
- Autonomous AI agent executing live swaps, quotes, and on-ramping on Virtuals ACP
- Privacy-Pools compliance with automated association-set approvers (ASP)
- $SWOOD token with staking, governance, and fee tier discounts
