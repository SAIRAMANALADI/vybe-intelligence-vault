## Summary
CrateDB is a distributed SQL database designed for real-time storage and analysis of massive datasets. It combines SQL query capabilities with NoSQL scalability, supporting time-series, geospatial, and document-oriented data models.

## Key Features
- Distributed SQL query execution with auto-sharding and auto-replication
- Support for time-series, geospatial, and document-oriented data models
- PostgreSQL compatibility and PostgreSQL wire protocol support
- Horizontal scalability with self-healing and auto-rebalancing clusters
- Containerized deployment with Docker and Kubernetes support
