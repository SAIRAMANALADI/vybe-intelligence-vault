## Summary
KinetAios is a local-first, multi-engine AI agent dashboard that enables users to run and switch between multiple AI engines (Claude Code, Codex, and a built-in ReAct loop) from a single window. It features cross-engine long-term memory, a plugin system, and no account or relay server requirements.

## Key Features
- Run and switch between three AI engines (Direct, Claude Code, Codex) from one window
- Cross-engine long-term memory with automatic fact extraction and SQLite storage
- Built-in ReAct loop with tool-level concurrency and context compaction
- MCP client and server integration for remote agent control and tool discovery
- Plugin system supporting tools, slash commands, hooks, and panels with per-need injection

## Why It Matters for RAG Builders
KinetAios provides a unified, local-first platform for managing multiple AI agents with cross-engine memory and a plugin ecosystem, reducing context loss and improving workflow efficiency for RAG builders.
