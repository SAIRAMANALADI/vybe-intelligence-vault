## Summary
FlowFlow is a voice notes application for iPhone and Mac that captures, transcribes, and organizes spoken ideas into searchable notes. It enables users to chat with their notes using RAG-powered AI, with features like offline transcription, multi-device sync, and web search integration.

## Key Features
- Real-time voice capture with auto-transcription (cloud or on-device)
- RAG-powered chat with hybrid search (BM25 + vector + RRF + LLM rerank)
- Multi-device encrypted LAN P2P sync with QR pairing
- Offline transcription with local Whisper models and custom dictionary
- Web search integration per chat via Exa API

## Why It Matters for RAG Builders
FlowFlow provides a robust, local-first RAG stack with advanced features like hybrid search, multi-device sync, and offline transcription, making it essential for AI engineers building voice-driven or note-taking applications.
