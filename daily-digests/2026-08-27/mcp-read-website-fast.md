## Summary
A fast, token-efficient MCP server for extracting and converting web content into clean Markdown, optimized for AI agents and LLM pipelines. It leverages Mozilla Readability and Turndown for high-quality extraction while minimizing token usage and memory footprint.

## Key Features
- Fast, token-efficient web content extraction using Mozilla Readability and Turndown
- Smart caching with SHA-256 hashed URLs for performance optimization
- Polite crawling with robots.txt support and rate limiting to avoid overloading servers
- Concurrent fetching and stream-first design for low memory usage
- Link preservation and optional chunking for downstream processing and knowledge graphs

## Why It Matters for RAG Builders
It enables AI agents and RAG pipelines to efficiently extract clean, structured web content with minimal token overhead, improving performance and reducing costs.
