## Summary
Fama is a local-first dashboard and voice narration tool for monitoring Claude Code agent activity in real-time. It tails transcript files, provides a live visual dashboard, and optionally narrates agent thoughts and actions via free local voices or cloud-based OpenAI TTS with customizable personas.

## Key Features
- Live visual dashboard streaming agent activity (thinking, tool calls, results) via SSE
- Optional cloud or local voice narration with customizable personas and accents
- Rewrite step to condense raw agent thoughts into natural spoken lines with cost tracking
- Desktop app with system tray support and update checks (Windows-focused)
- Privacy-first design: local by default, no telemetry, optional OpenAI integration billed to user

## Why It Matters for RAG Builders
Fama provides an ambient, always-on window into AI agent activity, enabling developers to monitor and hear agent workflows without keeping the chat pane in focus, while prioritizing privacy and local-first operation.
