## Summary
trw-mcp is an MCP server designed to provide persistent engineering memory for AI coding agents, enabling cross-session recall, evidence-backed delivery, and spec-driven development. It integrates with the TRW Framework to accumulate and retrieve project-specific knowledge, improving AI-assisted development workflows.

## Key Features
- Cross-session recall of project knowledge stored in `.trw/` directory
- Integration with TRW Framework for spec-driven development and verification gates
- 46 MCP tools for session management, learning, quality checks, and code intelligence
- 28 skills for slash-command workflows and zero-token triggers
- Local-first architecture with optional offline mode and no outbound network calls by default

## Why It Matters for RAG Builders
It enables AI coding agents to retain and recall project-specific knowledge across sessions, improving consistency and reducing redundant context re-learning in RAG pipelines.
