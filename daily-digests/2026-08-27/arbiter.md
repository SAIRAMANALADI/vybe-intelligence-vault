## Summary
Arbiter is a multi-agent orchestration runtime designed for secure, durable, and event-driven agent systems. It provides a single native binary that supports interactive TUI, remote TUI, one-shot commands, and HTTP+SSE API modes for local-first or networked deployments.

## Key Features
- Single native binary with no external runtime dependencies beyond model provider keys
- Supports multiple modes: interactive TUI, remote TUI, one-shot commands, and HTTP+SSE API
- Durable memory and event streaming with tenant isolation for multi-user scenarios
- Constitution-driven agent behavior with glob matching for real-time event routing
- Built-in sandboxing for secure agent execution (configurable)

## Why It Matters for RAG Builders
Arbiter simplifies the deployment and management of secure, event-driven multi-agent systems with durable memory, making it essential for building robust RAG pipelines and AI applications.
