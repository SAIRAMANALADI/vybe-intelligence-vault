## Summary
AI Interviewer is a Laravel-based platform that automates technical hiring by providing AI-powered coding challenges, timed sessions, and automated code reviews. It was designed to function before structured LLM outputs existed, relying on prompt engineering and custom parsing to extract structured data from free-form AI responses.

## Key Features
- AI-powered coding challenges with timed sessions and automated reviews
- In-session AI assistant for real-time hints and Q&A without revealing answers
- Gamification with XP, leaderboards, and performance metrics for candidates
- Legacy LLM integration techniques for handling unstructured outputs (JSON repair, separators, wildcard prompts)
- Role-based access control for recruiters, admins, and candidates

## Why It Matters for RAG Builders
It provides a production-proven reference for integrating LLMs into real-world workflows before structured outputs were reliable, offering insights into prompt engineering, parsing, and automation for hiring pipelines.
