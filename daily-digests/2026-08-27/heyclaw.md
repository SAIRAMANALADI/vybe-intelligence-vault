## Summary
HeyClaw is a lightweight, open-source voice-first personal AI agent that listens locally for a wake word, processes real-time voice sessions, and connects speech to a Python agent powered by Gemini, Mem0, MCP tools, and workspace skills. It separates device-facing audio from the backend, enabling remote intelligence while keeping satellites lightweight.

## Key Features
- Local wake-word detection with openWakeWord for hands-free activation
- Real-time speech-to-text and text-to-speech via ElevenLabs Speech Engine
- Persistent user memory using Mem0 for long-term context retention
- Dynamically discovered MCP tools and workspace skills for extensible functionality
- Separate backend and satellite architecture for scalable, modular deployment

## Why It Matters for RAG Builders
HeyClaw provides a modular, voice-first agent framework that integrates LLM reasoning, persistent memory, and tool use while keeping audio processing lightweight and scalable for RAG and AI stack builders.
