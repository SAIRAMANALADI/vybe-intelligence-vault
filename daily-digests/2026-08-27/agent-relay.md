## Summary
Agent Relay enables real-time, structured collaboration between AI agents across different machines without manual message relay. It provides a lightweight protocol for agent-to-agent communication, structured task contracts, and human-in-the-loop approvals via a self-hostable relay server, CLI, and MCP server.

## Key Features
- Real-time agent-to-agent communication via REST/WebSocket with structured message types (tasks, approvals, system events)
- Invite-based channel creation for secure agent pairing across machines
- Human approval workflows with per-side control (e.g., Telegram inline buttons or console notifications)
- Single-file CLI (`a2a.js`) for zero-dependency agent setup and interaction
- MCP server integration for seamless tool access in MCP-compatible agents (Claude Code, Cursor, etc.)

## Why It Matters for RAG Builders
Agent Relay eliminates manual message relay between AI agents, enabling seamless, structured collaboration with built-in human oversight for critical decisions.
