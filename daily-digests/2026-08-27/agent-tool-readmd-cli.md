## Summary
A Linux-native, offline text-to-speech CLI tool designed for AI agents and accessibility, featuring sentence-by-sentence highlighting, markdown-aware reading, and a resident daemon for low-latency speech synthesis.

## Key Features
- Resident daemon architecture for sub-second speech initiation after first load
- Markdown-aware reading with intelligent handling of headings, tables, and code blocks
- Interactive read-along window with keyboard controls for speed, volume, and navigation
- Agent-ready CLI with JSON output and strict exit codes for programmatic integration
- Offline neural TTS using Piper ONNX models with optional voice preloading

## Why It Matters for RAG Builders
It enables AI agents to deliver spoken responses with minimal latency and rich formatting support, while also serving as a powerful accessibility tool for users with visual impairments.
