## Summary
A Model Context Protocol (MCP) server for Gradle that enables AI agents to interact with Gradle projects, run tasks, audit dependencies, and explore JVM runtime environments. It provides structured tools for project mapping, smart task execution, and dependency/source search.

## Key Features
- Agent Skills for guided Gradle workflows (e.g., running builds, auditing dependencies)
- Project mapping and exploration of multi-project structures, tasks, and properties
- Smart task execution with background monitoring and noise-free output capture
- Dependency and source code search across project dependencies, plugins, and Gradle internals
- Interactive Kotlin REPL for testing project utilities and exploring APIs

## Why It Matters for RAG Builders
It enables AI agents to directly interact with Gradle projects, automating complex build tasks and dependency management for RAG pipelines.
