## Summary
Artel is a self-hosted coordination layer for AI agent fleets, providing shared memory with semantic search, task management, async messaging, and session handoffs. It enables multi-agent collaboration via REST/MCP interfaces and supports mesh networking for distributed instances.

## Key Features
- Shared memory with semantic search and confidence decay based on relevance and age
- Task management and async messaging for agent coordination without a central scheduler
- Session handoffs to resume agent work with full context across restarts
- Mesh networking via mDNS and CRDT-based memory replication for distributed instances
- Compile mode for source-anchored memory that recompiles when code changes, ensuring accuracy

## Why It Matters for RAG Builders
Artel provides a critical infrastructure layer for RAG builders by enabling multi-agent collaboration, shared knowledge retention, and context-aware task execution, all while ensuring memory consistency and relevance through advanced decay and grounding mechanisms.
