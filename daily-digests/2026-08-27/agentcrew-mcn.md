## Summary
AgentCrew MCN is an open-source multi-agent system designed for automated content marketing, enabling AI agents to generate, publish, and analyze content across platforms like Juejin, Zhihu, and Dev.to with minimal human intervention.

## Key Features
- Pluggable multi-agent architecture with specialized roles (Writer, Publisher, Analyst)
- Retrieval-augmented generation (RAG) for knowledge base integration
- Cross-platform publishing with extensible adapters (Juejin, Zhihu, Dev.to)
- Smart scheduling and analytics dashboard for performance tracking
- MCP protocol readiness for future integration

## Why It Matters for RAG Builders
