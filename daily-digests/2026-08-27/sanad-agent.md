## Summary
Sanad Agent is a local-first, cross-platform AI agent framework that enables users to manage native Dart agents across multiple devices (desktop, mobile, web) from a unified Flutter client interface. It supports offline model execution, workspace isolation, and parallel task management for AI-driven workflows.

## Key Features
- Local-first execution with offline model support (Ollama, LM Studio, llama.cpp)
- Unified Flutter client for managing agents across desktop, mobile, and web
- Workspace isolation with scoped context, permissions, and provider configurations
- Parallel task execution with steering and queuing capabilities
- Extensible via MCP servers and skills for custom tool integration

## Why It Matters for RAG Builders
Sanad Agent simplifies the deployment and management of AI agents across multiple devices, making it ideal for RAG builders who need scalable, local-first solutions with unified control interfaces.
