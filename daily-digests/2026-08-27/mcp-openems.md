## Summary
An MCP server that integrates openEMS FDTD simulation for AI-assisted design of antennas and RF structures, providing analytical calculators and script generation for full-wave simulations.

## Key Features
- Analytical design calculators for patch, dipole, monopole, horn, and helix antennas
- Automated generation of openEMS Python simulation scripts
- Integration with the eng-mcp-suite for broader engineering workflows
- Support for microstrip and coupled-line transmission lines
- Validation of designs via full-wave FDTD simulation when openEMS is installed

## Why It Matters for RAG Builders
It enables AI-driven RF and antenna design workflows by bridging analytical calculations with full-wave simulation, accelerating the prototyping and validation of electromagnetic structures.
