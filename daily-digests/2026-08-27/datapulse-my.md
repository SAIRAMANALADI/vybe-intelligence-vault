## Summary
DataPulse MY is an open-source trust layer for Malaysian public datasets, providing freshness monitoring, schema validation, and health reports for 122 official datasets. It enables AI agents and RAG systems to consume verified, machine-readable data without custom integrations.

## Key Features
- Provides 122 official Malaysian datasets with verified licences (CC BY 4.0, OGL)
- Eight-status trust taxonomy for honest freshness assessment (fresh, aging, stale, etc.)
- Machine-readable manifests and health envelopes for AI/RAG consumption
- MCP server for native agent queries (search, get dataset, find stale, etc.)
- Weekly automated monitoring with RSS feed for health changes

## Why It Matters for RAG Builders
DataPulse MY streamlines RAG and AI pipelines by providing verified, machine-readable Malaysian public data with freshness signals, eliminating the need for custom integrations or scraping.
