## Summary
A collection of agentic skills for Matrix, distributed as a Claude Code plugin, enabling AI agents to interact with Matrix rooms, administer Synapse homeservers, and compose structured announcements. The skills support end-to-end encryption, rich formatting, and server administration via dedicated APIs.

## Key Features
- Enables AI agents to send, read, edit, and react to Matrix messages with full E2EE support
- Provides Synapse homeserver administration tools for room management, health checks, and graph visualization
- Offers structured announcement templates for release notes, digests, and postmortems with HTML-to-PNG rendering
- Supports multiple installation methods (Claude Code plugin, npx, Composer, npm) for flexibility
- Includes device verification and SAS emoji verification for secure E2EE setup
