## Summary
graph-memory is a knowledge graph context engine designed to compress and retain long conversation histories into structured knowledge graphs, enabling agents to recall relevant context across sessions and avoid context explosion. It integrates with OpenClaw to provide dual-path recall (precise and generalized) and episodic context for improved accuracy.

## Key Features
- Dual-path recall system combining precise entity-level and generalized community-level search for optimal context retrieval
- Episodic context preservation by linking original conversation snippets to graph nodes for faithful context reconstruction
- Automatic community detection and summarization to enable semantic recall across related skills and tasks
- Universal embedding support for any OpenAI-compatible endpoint, ensuring flexibility in model choices
- 75% token compression in long conversations while maintaining context relevance via structured knowledge graphs

## Why It Matters for RAG Builders
It transforms raw conversation histories into structured, retrievable knowledge graphs, enabling AI agents to retain and recall context efficiently across sessions, which is critical for building robust RAG systems.
