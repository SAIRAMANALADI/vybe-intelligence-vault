## Summary
PageVault enables publishing HTML or Markdown artifacts to a URL with configurable access control (public, email-gated, or client portals) directly from AI chat tools like Claude or ChatGPT. It is self-hosted on Cloudflare Workers with optional Zero Trust access policies.

## Key Features
- Publish HTML/Markdown artifacts to a URL directly from AI chat tools without leaving the conversation
- Configurable access tiers: Public (open URL), Secured (email-gated), or Portals (client-based access)
- Self-hosted on Cloudflare Workers with optional Zero Trust integration for secure access control
- MCP server embedded in the Worker for agent-based search and retrieval of published documents
- Supports per-client portals with searchable collections for long-term engagement tracking

## Why It Matters for RAG Builders
PageVault streamlines the secure sharing and retrieval of AI-generated artifacts, enabling seamless integration with agent workflows while maintaining control over access and data locality.
