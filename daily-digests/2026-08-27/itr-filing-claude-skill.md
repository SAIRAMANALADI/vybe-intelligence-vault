## Summary
A standalone Windows application that automates the preparation of Indian ITR-2 tax returns for Assessment Year 2026-27 by reconciling financial documents, classifying income, and generating a compliant JSON output for submission to the tax portal.

## Key Features
- Reconciles AIS, TIS, Form 26AS, and Form 16 with user-provided financial data
- Classifies capital gains (short-term/long-term) based on tax rules
- Calculates tax liability under old vs. new tax regimes
- Generates a JSON file compliant with the official tax portal schema
- Processes data locally for privacy and security
