## Summary
adkit is a plug-and-play automation tool for Meta (Facebook + Instagram) ads, enabling terminal or AI-agent-driven campaign creation, targeting, and optimization with AI-generated creatives. It emphasizes safety by default with dry-run modes and PAUSED object creation.

## Key Features
- One-command campaign launch from YAML briefs with optional AI-generated creatives
- Safe-by-default execution: all objects created PAUSED and dry-run until explicit activation
- Terminal and AI-agent (Claude Code) driven workflows with built-in cost guardrails
- Optimization engine for live ad performance analysis with plain-language recommendations
- Modular MCP server for integration with any MCP-capable AI agent
