## Summary
Radar is an open-source Kubernetes UI that provides real-time visualization of cluster topology, resources, traffic, and audit logs through a single binary. It supports local and in-cluster deployments, integrates with Helm and GitOps, and includes an MCP server for AI agent interactions.

## Key Features
- Single-binary deployment with no dependencies or CRDs required
- Real-time topology and resource visualization with live updates
- Built-in MCP server for AI agent integration and cluster queries
- Supports local and in-cluster deployments with RBAC and authentication
- Airgapped-friendly and private by design (no cloud sync or telemetry)

## Why It Matters for RAG Builders
Radar provides essential real-time Kubernetes visibility and AI agent integration capabilities, making it critical for RAG builders who need to monitor and query Kubernetes clusters dynamically.
