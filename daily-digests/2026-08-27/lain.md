## Summary
LAIN is a persistent MCP server that builds a queryable knowledge graph of codebases by analyzing symbols, dependencies, and co-change history. It enables AI coding assistants to perform structural reasoning like blast radius analysis and transitive dependency tracing, enhancing code navigation and refactoring capabilities.

## Key Features
- Persistent knowledge graph of codebases with structural and semantic relationships
- Blast radius and dependency tracing for change impact analysis
- Hybrid semantic search using ONNX embeddings for code retrieval
- Integration with AI coding assistants via MCP (Claude Code, Cursor, Windsurf, Cline)
- Build and test error enrichment with architectural context

## Why It Matters for RAG Builders
LAIN provides critical structural and semantic context for AI agents to reason about codebases beyond local file analysis, enabling accurate change impact predictions and architectural insights.
