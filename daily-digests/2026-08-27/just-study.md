## Summary
A self-hosted, 30-day study course generator that automates research, validation, and daily learning sessions. Users specify a topic, and the system creates a structured 30-day curriculum with daily lessons, quizzes, and adaptive remediation, all executed locally without external dependencies.

## Key Features
- Automated 30-day course generation from a user-specified topic with structured daily lessons
- Fixed 100-point rubric for source validation and cross-verification of claims
- Daily learning flow: lecture → quiz → remediation → reflection → completion
- MCP server with 12 tools for course management, research, and learning state tracking
- Self-contained SQLite + Markdown storage with checksum validation for data integrity

## Why It Matters for RAG Builders
It streamlines the tedious process of curating and validating study materials, enabling AI engineers to focus on learning rather than content preparation.
