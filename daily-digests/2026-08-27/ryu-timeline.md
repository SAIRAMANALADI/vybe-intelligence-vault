## Summary
ryu-timeline is a CapCut-style scrubber UI for visualizing and navigating captured screen, input, window, audio, and other data lanes with keyframe previews and a Dayflow work journal. It operates as a read-only companion to the Ryu capture service, enabling jump-to-moment focus and timeline exploration.

## Key Features
- CapCut-style scrubber interface for navigating captured data lanes
- Keyframe preview player for visualizing moments in time
- Dayflow work journal integration for contextualizing captured data
- Jump-to-moment focus for precise navigation
- Read-only companion UI that binds to the `timeline:read` capability

## Why It Matters for RAG Builders
It provides a critical UI layer for visualizing and interacting with captured data streams, essential for RAG builders needing temporal context and structured navigation of multimedia inputs.
