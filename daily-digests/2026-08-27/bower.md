## Summary
Bower is a Python-based tool that organizes Google Drive files by scanning existing structures, building a preference profile from user patterns, and applying domain-specific categorization to reorganize files non-destructively. It ensures safe operations by only renaming, moving, or updating file descriptions without deletion.

## Key Features
- Scans and analyzes existing Google Drive file structures
- Builds a preference profile from observed user organization patterns
- Applies domain-specific categorization rules for reorganization
- Performs non-destructive operations (renames, moves, description updates)
