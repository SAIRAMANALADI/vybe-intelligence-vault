## Summary
The official C# SDK for the Model Context Protocol (MCP), enabling .NET applications to implement and interact with MCP clients and servers. It provides tools for building, hosting, and extending MCP-compliant applications with support for HTTP, dependency injection, and interactive UI applications.

## Key Features
- Full support for MCP protocol versions (2024-11-05 and 2026-07-28)
- Modular packages for clients, servers, and HTTP transport
- Dependency injection and hosting extensions for ASP.NET Core
- Cross-application access via Identity Assertion Authorization Grant flow
- Comprehensive API documentation and samples for quick onboarding

## Why It Matters for RAG Builders
It provides essential tooling for .NET developers to integrate MCP-compliant agents and tools into their applications, enabling standardized LLM context management.
