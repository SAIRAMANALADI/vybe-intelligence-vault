## Summary
TDPilot is an AI-powered control layer for TouchDesigner that enables agents like Claude or Cursor to interactively build, debug, and verify TouchDesigner networks in real-time. It provides transactional operations, snapshots, and full activity logging to ensure safety and reliability during AI-driven patch development.

## Key Features
- 114 MCP tools for comprehensive TouchDesigner control, including planning, execution, and validation
- Transactional operations with snapshots and rollback capabilities for safety and reliability
- Reviewed operator atlas with 656 TouchDesigner operator cards grounded in official Derivative docs
- Screenshot verification and error scanning to validate AI-generated changes
- Technique memory system for storing and reusing validated network patterns locally

## Why It Matters for RAG Builders
TDPilot enables AI agents to safely and iteratively build, debug, and verify TouchDesigner networks, bridging the gap between abstract AI planning and real-time visual programming with transactional safety and local control.
