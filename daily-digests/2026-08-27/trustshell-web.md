## Summary
TrustShell-Web provides an open security baseline and scanner for self-hosted or on-device AI agents, offering a 42-item checklist to assess vulnerabilities and output security ratings (A/B/C/D). It includes a CLI tool for local scans and an online platform for remote assessments.

## Key Features
- 42-item security baseline covering 10 categories with severity ratings and scoring model
- CLI-based scanner for local AI agent assessments with zero dependencies
- Online platform for remote scanning of public targets with SSRF protection
- Automated detection for network-based vulnerabilities and manual checks for filesystem/human-involved risks
- CI/CD-friendly exit codes (A=0, B/C=1, D=2) for integration into pipelines

## Why It Matters for RAG Builders
It provides a standardized, open security baseline for AI agents, helping builders identify and mitigate critical vulnerabilities before deployment.
