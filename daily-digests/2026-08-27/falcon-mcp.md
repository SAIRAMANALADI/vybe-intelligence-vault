## Summary
falcon-mcp is a Model Context Protocol (MCP) server that bridges AI agents with the CrowdStrike Falcon platform, enabling programmatic access to security capabilities like threat intelligence, detections, and host management for automated security operations.

## Key Features
- Comprehensive security module coverage (detections, host management, threat intelligence, etc.)
- Dynamic mode for reduced context window overhead in AI agents
- Read-only and tool-level access restrictions for security compliance
- Docker and CLI support for flexible deployment
- Rich documentation and module-specific tooling for deep security operations
