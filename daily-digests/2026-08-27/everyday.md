## Summary
Everyday CLI is a high-performance, memory-safe Rust toolkit that serves as a local-first command interface for AI agents to interact with personal data like email, calendar, RSS feeds, notes, todos, bookmarks, and structured memory. It prioritizes agent-first JSON output for seamless integration with AI workflows.

## Key Features
- Unified CLI structure for managing personal data across multiple services (mail, calendar, RSS, notes, todos, bookmarks, memory)
- Agent-first JSON output mode for seamless AI integration and structured data consumption
- Credential safety via OS keyring (no credentials stored on disk)
- High performance with cold start under 100ms and cross-platform support (Windows, macOS, Linux)
- Local SQLite storage for notes, todos, and bookmarks, enabling offline-first operation

## Why It Matters for RAG Builders
Everyday CLI provides a secure, local-first bridge for AI agents to interact with personal data without exposing credentials or relying on third-party services, making it essential for privacy-focused RAG and agentic systems.
