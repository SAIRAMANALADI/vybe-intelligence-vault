## Summary
RoleCraft is a zero-dependency CLI tool designed as the package manager for AI agents, enabling installation, testing, publishing, and management of skills and MCP servers across 86+ agents. It operates offline-first and requires no signup or external dependencies.

## Key Features
- Zero-dependency CLI with only Node.js built-ins, ensuring minimal supply-chain risk
- Unified installation of AI agent skills and MCP servers in a single command
- Security scoring (0–100) with static analysis to detect vulnerabilities like prompt injection or command injection
- Offline-first operation with optional GitHub-powered community registry for skill discovery and publishing
- CI/CD integration via GitHub Action and lockfile-based re-installation for reproducible environments

## Why It Matters for RAG Builders
RoleCraft simplifies the management of AI agent skills and MCP servers, reducing setup complexity and security risks for RAG builders.
