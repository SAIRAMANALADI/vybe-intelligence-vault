## Summary
recon is a passive domain intelligence tool that gathers public metadata from DNS records, certificate transparency logs, and unauthenticated identity discovery endpoints to provide typed observations about a domain's public technology and identity namespace. It operates locally without credentials, API keys, or active scanning, offering versioned JSON output and an MCP server for automation.

## Key Features
- Passive collection of DNS, certificate transparency, and identity endpoint data without active scanning or credentials
- Versioned JSON output with stable schema for automation and integration
- Local MCP server for integration with AI agents and tools
- Batch and delta modes for efficient processing of multiple domains
- Built-in posture profiles for fintech, healthcare, SaaS, and other sectors

## Why It Matters for RAG Builders
