## Summary
A TypeScript-based SDK for AI chatbots that provides persistent, per-user memory with bi-temporal facts, semantic search, emotional capture, contradiction detection, and multi-stage memory consolidation. Designed to enhance LLM prompts with structured context and long-term memory capabilities.

## Key Features
- Bi-temporal fact tracking (valid-time and transaction-time) for precise historical context
- Automated fact extraction, semantic deduplication, and contradiction detection with inline and async modes
- Emotional capture using VAD analysis and session texture for continuity across conversations
- Multi-stage memory consolidation (episodic, daily, weekly) with provider-agnostic LLM integration
- Knowledge graph integration via Neo4j for structured entity relationships and subgraphs

## Why It Matters for RAG Builders
It provides a robust, production-ready memory layer for AI agents, enabling persistent context, contradiction-free knowledge, and emotional continuity, which are critical for building advanced RAG systems.
