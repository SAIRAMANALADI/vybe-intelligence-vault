## Summary
DeepWrite is a methodology for AI-assisted deep content creation, packaged as an executable skill for AI agents. It provides a structured writing system with validated frameworks, enabling non-experts to produce high-quality articles through agent-driven workflows.

## Key Features
- Five validated writing modes tailored to different scenarios (e.g., industry history storytelling, event deep dives)
- Four narrative frameworks and five readability techniques for structured content generation
- Dual-review process for fact-checking and logical validation before publication
- Agent-executable skill (SKILL.md) compatible with tools like Claude Code and Cursor
- Methodology derived from 100+ real-world deep articles, ensuring practical applicability

## Why It Matters for RAG Builders
DeepWrite provides a repeatable, agent-executable framework for generating high-quality, fact-checked content, reducing the cognitive load on writers and improving consistency in AI-assisted writing pipelines.
