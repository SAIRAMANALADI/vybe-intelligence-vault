## Summary
PharmaSkill is an AI agent skill designed for drug repurposing, autonomously identifying existing drugs for new disease indications through multi-database reasoning, molecular analysis, and literature evidence retrieval. It integrates PubChem, ChEMBL, and PubMed to generate ranked candidate drugs with supporting evidence and molecular structures.

## Key Features
- Autonomous 6-step ReAct pipeline for drug repurposing analysis
- Multi-database integration (PubChem, ChEMBL, PubMed) with resilience and caching
- Data-driven 6-dimensional scoring system (mechanism, literature, molecular similarity, bioactivity, drug-likeness, KB precedent)
- Benchmark evaluation with clinically validated ground truth (MRR 0.80, 2.5x improvement over random baseline)
- MCP protocol support and FastAPI-based API with streaming output

## Why It Matters for RAG Builders
PharmaSkill streamlines drug repurposing by automating complex multi-database research, reducing development time and costs while providing evidence-backed candidate drugs for new therapeutic uses.
