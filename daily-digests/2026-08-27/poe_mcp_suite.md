## Summary
A suite of Model Context Protocol (MCP) servers providing deep, live integration with Path of Exile for AI agents, enabling build simulation, trade lookups, loot filtering, and wiki searches. The suite includes four independently developed MCP tools and a workflow framework optimized for Claude Code.

## Key Features
- Real-time Path of Exile build simulation via Path of Building integration
- Trade and price lookup through poe.ninja and ExileExchange
- Wiki and economy data lookups for up-to-date game mechanics
- Workflow framework with playbooks for task-specific AI agent guidance
- Supports both headless and live TCP connections to Path of Building

## Why It Matters for RAG Builders
This suite bridges the gap between outdated AI model knowledge and live Path of Exile data, enabling AI agents to provide accurate, real-time assistance for build optimization, trade decisions, and game mechanics.
