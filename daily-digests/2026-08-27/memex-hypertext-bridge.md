## Summary
Knowledge Nexus is a persistent personal wiki system that automatically extracts, organizes, and interconnects insights from LLM conversations into a searchable knowledge graph. It bridges ephemeral AI sessions with permanent storage, enabling users to retain and build upon valuable information across interactions.

## Key Features
- Automatic extraction of key concepts, decisions, and code snippets from LLM conversations in real-time
- Graph-based organization with visual mind maps showing topic relationships across sessions
- Multi-platform sync supporting ChatGPT, Claude, Gemini, and local LLM deployments
- Offline-first architecture with dual-database storage (SQLite for queries, Neo4j for graph traversals)
- Rich export options including Markdown, JSON, PDF, and interactive HTML knowledge bases

## Why It Matters for RAG Builders
It solves the critical problem of losing valuable insights from ephemeral LLM sessions by creating a persistent, searchable, and interconnected repository that grows smarter with each conversation.
