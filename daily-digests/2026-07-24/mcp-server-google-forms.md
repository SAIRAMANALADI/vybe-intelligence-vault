## Summary
A local MCP server that enables Claude Code to create, edit, and publish Google Forms programmatically. It provides a suite of tools for form management, including question handling, response retrieval, and quiz mode configuration.

## Key Features
- Full CRUD operations for Google Forms (create, read, update, delete)
- Supports 9 question types including quizzes, file uploads, and linear scales
- Real-time form state verification and publishing control
- Response listing with pagination for large datasets
- Seamless integration with Claude Code via MCP protocol

## Why It Matters for RAG Builders
It enables AI agents like Claude Code to programmatically manage Google Forms, streamlining data collection and automation workflows for RAG systems.
