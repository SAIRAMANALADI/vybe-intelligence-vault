## Summary
A Model Context Protocol (MCP) server that enables seamless GitLab integration with Claude Code, allowing users to manage issues, epics, CI/CD pipelines, and project metadata directly through natural language commands.

## Key Features
- Full GitLab API integration for issue, epic, label, and project management
- CI/CD pipeline monitoring with job log retrieval and trace downloads
- Direct project access using namespace/project-name paths
- Optimized CLI flags to disable unused tool categories for efficiency
- Comprehensive documentation and Docker deployment support
