## Summary
MacPad Pro is an extension-friendly macOS plain-text editor designed for developers who need a lightweight yet powerful editing environment. It supports syntax highlighting, built-in text commands, and a modular extension system for themes, tools, and AI-agent workflows.

## Key Features
- Plain-text editing with syntax highlighting for PHP and C-family languages
- Extension Manager for downloading, activating, and managing modular extensions
- Local-first extension behavior for clipboard, snippets, backups, and document tools
- AI extensions for summarization, code explanation, refactoring, and meeting notes cleanup
- Support for local and remote OpenAI-compatible agents with user-configurable settings

## Why It Matters for RAG Builders
