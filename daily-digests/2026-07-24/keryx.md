## Summary
Keryx is a fullstack TypeScript framework designed to unify backend and AI agent interactions by enabling a single action class to handle HTTP, WebSocket, CLI, background tasks, and MCP tool calls with shared validation, middleware, and responses. It integrates Drizzle ORM, Resque-based background tasks, streaming responses, and OAuth 2.1 for AI agents.

## Key Features
- Single action class handles HTTP, WebSocket, CLI, background tasks, and MCP tool calls with unified validation and middleware
- Built-in MCP tool support with OAuth 2.1 authentication and typed errors for AI agents
- Drizzle ORM with auto-migrations and database transactions for robust data management
- Streaming responses (SSE, chunked binary) across all transports with per-transport behavior
- Companion Vite + React frontend with end-to-end type safety and no code generation

## Why It Matters for RAG Builders
Keryx eliminates the need for separate MCP servers and schemas by exposing validated backend actions directly as AI agent tools, streamlining RAG pipeline integration and reducing maintenance overhead.
