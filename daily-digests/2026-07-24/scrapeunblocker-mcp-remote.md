## Summary
A hosted HTTP Model Context Protocol (MCP) server for ScrapeUnblocker, deployed as a Vercel serverless function. It enables MCP clients like claude.ai to fetch web pages, parsed JSON, or Google search results via ScrapeUnblocker's anti-bot API using a user-provided API key.

## Key Features
- Hosted MCP server for seamless integration with claude.ai and other MCP clients
- Supports fetching raw HTML, AI-parsed JSON, or Google search results
- Dual authentication modes: custom API key or OAuth 2.1 (via Auth0)
- Deployable as a Vercel serverless function with configurable max duration
- Discovery endpoints for OAuth-protected resource metadata
