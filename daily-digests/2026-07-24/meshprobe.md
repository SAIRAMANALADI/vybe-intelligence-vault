## Summary
MeshProbe provides AI agents with a typed interface to inspect and interact with 3D models (GLB, glTF, OBJ, STL) via a persistent Blender worker, enabling operations like camera control, lighting adjustments, component queries, and evidence rendering without modifying source files.

## Key Features
- Persistent Blender-backed sessions for 3D model inspection with checkpointing and crash recovery
- Typed CLI and MCP interface for agent interaction (familiar Playwright-like model)
- Camera control (translation, rotation, perspective/orthographic projection), lighting adjustments, and component marking
- Evidence rendering (Eevee/Cycles) with depth/normal EXR outputs and contact sheets for evaluation
- Sandboxed qualification harness for reproducible agent testing with pinned evaluation corpora

## Why It Matters for RAG Builders
MeshProbe enables AI agents to programmatically inspect and manipulate 3D models in a controlled, reproducible environment, bridging the gap between raw model data and agent-driven evaluation workflows.
