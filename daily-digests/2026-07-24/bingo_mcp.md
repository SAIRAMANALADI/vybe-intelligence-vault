## Summary
bingo_mcp is a Model Context Protocol (MCP) application that enables interactive bingo games via chat commands, rendering a 5×5 bingo card with a drawing machine widget. It reuses drawing logic and sound effects from a submodule while providing AI-agent-specific instructions for deployment and customization.

## Key Features
- Integrates bingo game logic via MCP for AI agents
- Renders interactive 5×5 bingo card with drawing machine widget
- Uses submodule for core drawing logic and sound effects
- Provides AI-agent-specific instructions via APM for deployment and customization
- Supports structured UI/UX guidelines for widget rendering (CSS, CSP, esbuild)
