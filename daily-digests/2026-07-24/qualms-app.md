## Summary
Qualms is a CLI-first QA automation framework designed to establish a structured process for quality assurance workflows, featuring a Tauri-based desktop client and modular execution layers. It provides a scaffold for QA automation without locking into specific VM providers or browser automation tools.

## Key Features
- CLI-first architecture for QA automation workflows
- Tauri 2 and SvelteKit-based desktop client
- Modular execution layers for local and VM-based testing
- Runtime-validated contracts for QA trace and bridge protocols
- Neutral desktop shell design to decouple UI from core logic

## Why It Matters for RAG Builders
Qualms provides a flexible scaffold for building QA automation pipelines, enabling RAG builders to integrate structured testing and validation into their AI workflows.
