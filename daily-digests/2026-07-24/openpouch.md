## Summary
OpenPouch is an agent-native hosting platform designed to enable coding agents to deploy applications autonomously with minimal human intervention. It provides a CLI and MCP server for agent-driven deployments, governed by policy files and deployment manifests, while running apps on its own infrastructure.

## Key Features
- Agent-driven deployments with zero human verification (no CAPTCHA, no account creation)
- CLI and MCP server for seamless integration with coding agents like Claude Code or Cursor
- Governed deployment lifecycle with policy enforcement and human approval gates for production
- Open file formats (deploy.manifest.json, deploy.policy.json, DEPLOYMENT.md) for machine-readable and human-readable deployment records
- Supports both openpouch's own infrastructure and BYO providers like Render or Vercel

## Why It Matters for RAG Builders
OpenPouch eliminates friction in AI-driven deployments by providing a fully agent-native hosting platform, enabling seamless automation and governance for RAG and AI stack builders.
