## Summary
Ally is a desktop AI coding assistant designed to interact with local projects through natural language. It enables users to read, edit, search, and manage files, execute commands, and delegate tasks to sub-agents while maintaining workspace boundaries and security.

## Key Features
- Natural language interaction with local projects for code understanding and editing
- Multi-agent delegation with parallel tool execution and progress tracking
- Sandboxed HTML rendering for interactive tool outputs within chat
- MCP server integration for extensibility and tool discovery
- Cross-platform support (Windows, macOS, Linux) with built-in ripgrep for code search

## Why It Matters for RAG Builders
Ally provides a robust local-first agent framework for AI-driven coding assistants, enabling secure and interactive development workflows without relying on cloud-based solutions.
