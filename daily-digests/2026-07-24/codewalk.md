## Summary
Codewalk is an AI-powered codebase intelligence tool that analyzes any repository to provide module detection, dependency graphs, blast radius analysis, and AI-driven code reviews. It enables developers to understand large codebases quickly and perform tasks like semantic search, execution flow tracing, and automated PR reviews with context-aware insights.

## Key Features
- Automated module detection and dependency graph generation using Tree-sitter parsing
- Blast radius analysis to assess impact of code changes across the repository
- AI chat with RAG for answering questions about the codebase with citations
- Multi-stage AI-powered code review with OWASP security checks and custom rubrics
- MCP server integration for seamless IDE agent interactions (VS Code, Cursor, Claude Code)

## Why It Matters for RAG Builders
Codewalk provides a foundational intelligence layer for RAG builders by transforming raw codebases into structured, queryable knowledge graphs with dependency-aware retrieval, enabling more accurate and context-rich AI responses.
