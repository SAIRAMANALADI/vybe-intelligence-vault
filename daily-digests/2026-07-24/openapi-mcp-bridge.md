## Summary
A generic MCP server that converts any OpenAPI/Swagger specification into MCP tools, enabling AI assistants to search, explore, and execute REST APIs dynamically. It bridges OpenAPI specs with AI workflows via the Model Context Protocol (MCP).

## Key Features
- Converts any OpenAPI/Swagger spec into MCP tools for AI assistants
- Supports multiple authentication types (bearer, API key, basic, none)
- Offers fuzzy and embedding-based search for endpoint discovery
- Enables batch execution of API endpoints with rate limiting
- Provides guardrails for destructive operations and safety checks

## Why It Matters for RAG Builders
It enables AI assistants to dynamically interact with any REST API through a standardized MCP interface, eliminating manual tool integration and expanding AI capabilities for automation and data retrieval.
