## Summary
An AI-powered agent that recommends local hiking and walking trails by detecting user location, checking weather conditions, querying OpenStreetMap for green areas, and generating personalized recommendations using an LLM. Operates locally or via a Hugging Face Spaces demo with zero cost.

## Key Features
- Automated location detection via IP geolocation with fallback mechanisms
- Real-time weather integration to assess outdoor conditions
- Batch querying of OpenStreetMap for nearby green areas and trails
- Conversational memory for follow-up questions and personalized recommendations
- Zero-cost operation using free APIs and local LLM inference
