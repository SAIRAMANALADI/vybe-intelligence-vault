## Summary
k402-mcp is an MCP server that provides agent-payable APIs for AI agents, enabling pay-per-call access to text tools, web reading, embeddings, Kaspa blockchain data, GPU model tiers, covenants-as-a-service, and RISC Zero attestation services. Payments are settled in Kaspa (KAS) with no accounts or API keys required.

## Key Features
- Agent-native payment system with USD-pegged pricing settled on Kaspa L1
- Comprehensive toolset including text processing, embeddings, web reading, and blockchain data access
- Covenants-as-a-service for Silverscript smart contracts
- RISC Zero zk-attestation-as-a-service for proof generation and verification
- Zero-account, zero-API-key model with per-session funding and balance tracking

## Why It Matters for RAG Builders
It enables AI agents to autonomously discover, fund, and use pay-per-call APIs without traditional billing infrastructure, leveraging Kaspa's fast and low-cost settlement for seamless integration into RAG and agent workflows.
