## Summary
A workflow skill pack and router for coding agents that provides standardized skills and routing logic across multiple agent platforms like OpenCode, GitHub Copilot, and Claude Code. It centralizes skill definitions and exports them to native formats for seamless integration.

## Key Features
- Centralized skill definitions with platform-specific exports for OpenCode, GitHub Copilot, and Claude Code
- Deterministic router with priority-based skill matching and no ambiguity
- Cost-aware execution profiles for optimal agent/model delegation
- Unified installer for seamless setup across platforms
- Kaizen-first default workflow with iterative, small-coherent changes

## Why It Matters for RAG Builders
It standardizes agent workflows and routing logic, enabling consistent and efficient coding agent behavior across multiple platforms while reducing duplication and maintenance overhead.
