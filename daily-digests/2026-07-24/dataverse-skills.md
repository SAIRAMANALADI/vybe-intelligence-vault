## Summary
Dataverse Skills provides a plugin-based framework for AI coding agents to interact with Microsoft Dataverse through natural language. It abstracts Dataverse MCP server, CLI, Python SDK, and PAC CLI into specialized skills for data management, querying, deployment, and administration.

## Key Features
- Specialized skills for Dataverse operations (connect, query, CRUD, metadata, solution management, admin, security)
- Natural language interface for Dataverse interactions via AI coding agents
- Integration with Dataverse MCP server, CLI, Python SDK, and PAC CLI
- Least-privilege security model with role-based access control
- Cross-environment solution deployment and lifecycle management

## Why It Matters for RAG Builders
It enables AI agents to seamlessly interact with Microsoft Dataverse, streamlining CRM data operations and reducing manual coding overhead for RAG and AI stack builders.
