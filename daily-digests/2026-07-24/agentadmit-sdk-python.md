## Summary
The AgentAdmit SDK for Python enables user-mediated authorization for AI agents in Python applications, supporting FastAPI, Flask, and Django. It provides scoped access control, token generation, revocation, audit logging, and integration with MCP servers for secure AI agent interactions.

## Key Features
- User-mediated AI agent authorization with scoped access control
- Integration with FastAPI, Flask, and Django frameworks
- Support for MCP server integration (STDIO and HTTP transport)
- Consent ledger for caller-identity management (human, in-app AI, external agents)
- Presence verification via WebAuthn for sensitive operations

## Why It Matters for RAG Builders
It provides a secure, user-controlled authorization layer for AI agents, preventing prompt injection and enabling scoped access to APIs without exposing raw data.
