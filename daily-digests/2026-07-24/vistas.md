## Summary
Vistas is a local MCP server providing Swedish immigration and work-regulation data with official citations and versioned rules. It operates offline using an openly licensed SQLite snapshot, ensuring queries never leave the user's machine while delivering legally sourced regulatory information.

## Key Features
- Local-first architecture with no backend or data collection
- Bitemporal versioning of rules with observed and legal validity windows
- Layered citations (statute vs. agency guidance) with paragraph-level precision
- Open dataset under CC-BY license with full compliance verification
- Built-in evaluation suite for retrieval accuracy and citation correctness

## Why It Matters for RAG Builders
Vistas provides a critical, legally grounded data source for RAG systems handling Swedish immigration queries, ensuring accuracy and compliance with official citations while operating entirely offline.
