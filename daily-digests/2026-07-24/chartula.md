## Summary
Chartula is a cross-platform .NET CLI tool that generates audience-specific changelogs from merged pull requests, ensuring factual accuracy and eliminating hallucinations by grounding outputs in verified PR data.

## Key Features
- Generates multiple audience-specific changelogs (technical, customer, product) from a single source of truth
- Grounds outputs in verified PR data to prevent hallucinations
- Runs locally as a .NET CLI tool with no hosting costs
- Supports configuration via YAML for customization
- Includes a faithfulness check to validate output against facts

## Why It Matters for RAG Builders
Chartula ensures accurate, audience-tailored release notes are generated directly from PRs, reducing manual effort and eliminating inconsistencies in communication.
