## Summary
Axisrobo AEP (Agent Event Protocol) is an open protocol designed for asynchronous communication between AI agents, tools, memory systems, and multi-agent runtimes. It complements MCP by enabling event streams, long-running task lifecycles, and durable delivery mechanisms across multiple languages and transport bindings.

## Key Features
- 17 protocol specifications covering session, subscription, task lifecycle, error handling, and transport layers
- Four reference implementations (TypeScript, Python, Go, Java) with cross-language conformance verified via shared fixtures
- Four transport bindings (stdio, WebSocket, SSE, gRPC) for local and distributed runtimes
- SQLite-backed delivery stores with retry, dead-letter, and replay support
- MCP interoperability for seamless integration with synchronous tool invocation systems

## Why It Matters for RAG Builders
AEP provides the missing asynchronous event layer essential for building scalable, resilient, and interoperable multi-agent AI systems that require real-time coordination and feedback.
