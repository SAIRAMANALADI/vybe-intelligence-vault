## Summary
KnowledgeForge is an enterprise-grade, multi-tenant AI knowledge agent that enables secure natural language querying of internal documents with role-based access control. It combines agentic RAG, graph-enhanced retrieval, and persistent memory for production-grade accuracy and observability.

## Key Features
- Enterprise-grade multi-tenant RBAC with department-level document isolation and role-based access (admin/member/viewer)
- Agentic RAG pipeline with LangGraph orchestration, intent routing, and Corrective RAG (CRAG) for hallucination mitigation
- Graph-enhanced retrieval (LightRAG) for multi-hop reasoning and structural knowledge discovery
- Persistent memory system (mem0) for cross-session personalization and fact extraction with semantic search
- Full observability stack with LangSmith, Langfuse, and Prometheus for tracing, metrics, and cost control

## Why It Matters for RAG Builders
KnowledgeForge provides a production-ready, secure, and scalable foundation for building enterprise AI knowledge agents with advanced RAG capabilities, multi-tenancy, and observability essential for RAG/AI stack builders.
