## Summary
Wardn Hub is a registry and submission platform for Model Context Protocol (MCP) server definitions, providing a browser-based interface for discovering, submitting, and managing MCP server metadata. It enables users to browse published servers, submit new or updated server definitions, and track submission states while ensuring structured workflows for maintainers and moderators.

## Key Features
- Registry for MCP server definitions with versioning and audit history
- Guided submission workflow for new servers and updates via web UI or API
- Role-based access control for organizations, users, and moderators
- GitHub repository import for server metadata and documentation
- Support for package-based (UVX, npm, PyPI, OCI) and remote MCP servers

## Why It Matters for RAG Builders
Wardn Hub simplifies the discovery, submission, and management of MCP server definitions, enabling AI engineers to build and maintain robust RAG pipelines with structured, versioned, and audited server metadata.
