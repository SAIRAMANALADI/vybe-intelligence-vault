## Summary
Mentis es un asistente virtual RAG omnicanal diseñado para optimizar la gestión de información clínica en consultorios psicológicos, integrando una plataforma web moderna con un bot de Telegram. Combina IA avanzada, recuperación de datos contextual y una experiencia de usuario fluida para garantizar respuestas consistentes y profesionales.

## Key Features
- Recuperación Aumentada (RAG) con base vectorial en Neon PostgreSQL para consultas contextuales en documentos clínicos
- Arquitectura omnicanal unificada que integra web y Telegram desde un mismo agente de IA
- Frontend responsivo con animaciones GSAP para mejorar la experiencia de usuario y reducir la fricción cognitiva
- Orquestación visual de flujos lógicos en n8n con manejo avanzado de memoria de sesión y enrutamiento condicional
- Pipeline automatizado de ingestión ETL para procesar y vectorizar documentos clínicos en la base de datos

## Why It Matters for RAG Builders
Proporciona un caso de estudio real y funcional para integrar RAG en entornos profesionales con múltiples canales de interacción, demostrando cómo combinar IA, orquestación y UX para aplicaciones prácticas en salud.
