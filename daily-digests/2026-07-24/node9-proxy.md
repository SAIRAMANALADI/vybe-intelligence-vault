## Summary
Node9 is a security and governance layer for AI agents that discovers, protects, and reviews agent activities in real-time. It scans for credential leaks, blocks risky commands, and provides posture assessments to mitigate exposure risks.

## Key Features
- Real-time discovery of credential leaks and agent activities
- Dynamic blocking of risky commands (e.g., `rm -rf`, `DROP TABLE`)
- Posture scoring and remediation guidance for exposed systems
- Agent-CI security scanning for GitHub Actions and repos
- Sandboxed execution environments with kernel-enforced egress controls

## Why It Matters for RAG Builders
Node9 provides critical runtime security and governance for AI agents, preventing credential leaks, risky operations, and supply chain attacks in agentic workflows.
