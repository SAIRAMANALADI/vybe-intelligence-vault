## Summary
An AI agent automation workflow that automates link-building outreach by discovering prospects, qualifying opportunities, finding contacts, drafting personalized emails, tracking responses, and scheduling follow-ups. Built for Zo Computer and compatible with Claude AI, it operates without paid APIs or external integrations.

## Key Features
- Six-stage pipeline: Discover, Qualify, Contact, Draft, Track, Follow-up
- No paid APIs or external integrations required (uses built-in web tools)
- Manual approval workflow for all outreach drafts and sends
- Compatible with Zo Computer and Claude AI (Claude Code or claude.ai)
- Local file-based storage for prospects, contacts, and outreach drafts

## Why It Matters for RAG Builders
It streamlines manual link-building tasks with AI-driven automation, reducing effort while maintaining control over outreach quality and approval.
