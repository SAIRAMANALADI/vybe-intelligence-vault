## Summary
A RAG-based document Q&A API that enables natural language queries over private documents with grounded answers and source citations. It supports tool-using agents for multi-step reasoning and integrates a minimal React frontend for interactive chat.

## Key Features
- Retrieval-Augmented Generation (RAG) with grounded answers and source citations
- Tool-using agent with multi-step reasoning (e.g., order lookup + return policy checks)
- Pluggable embeddings (local or cloud) and paragraph-aware chunking for better retrieval
- Minimal React frontend with CORS-enabled API integration
- In-memory conversation history with session support for follow-up questions

## Why It Matters for RAG Builders
This repository provides a production-ready RAG framework with agent capabilities, enabling developers to build grounded, auditable Q&A systems over private documents with minimal infrastructure overhead.
