## Summary
A monorepo personal website built with Next.js 15, React 19, NestJS 10, and MongoDB, integrating GitHub Issues and Repos as a CMS. Features a unified component library, shared hooks, and TypeScript-based type safety across frontend and backend.

## Key Features
- GitHub Issues as CMS with NestJS backend aggregation
- App Router + ISR for performance and freshness balance
- Unified component library with theme system
- OpenAPI/Swagger for API contract documentation
- Error and loading state management with Result and Skeleton components
