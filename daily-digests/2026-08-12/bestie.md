## Summary
Bestie is a self-hosted, local-first AI companion CLI designed for privacy and customization, supporting Vietnamese-first interactions by default. It offers configurable characters, local memory, multi-channel communication (Telegram/Zalo), and a safety-first permission model for developers.

## Key Features
- Configurable AI companion with character customization and local-first memory
- Support for OpenAI-compatible LLM providers with secure API key management
- Multi-channel communication via Telegram and Zalo with local polling
- Safety-first permission model for local read/write/action tools
- Built-in diagnostics, update checks, and regression evaluations

## Why It Matters for RAG Builders
Bestie provides a privacy-preserving, developer-friendly framework for building and deploying personalized AI companions with local memory and multi-channel integration, critical for RAG stacks prioritizing user control and security.
