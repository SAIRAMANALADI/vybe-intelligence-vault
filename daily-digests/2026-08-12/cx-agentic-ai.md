## Summary
Checkmarx Agentic AI provides MCP servers and plugins to integrate Checkmarx One security scanning into AI coding workflows. It enables AI assistants to scan, analyze, and remediate security vulnerabilities in real-time, either on-demand or as an automatic fail-safe during code generation.

## Key Features
- MCP server for AI clients (Claude, Cursor, Copilot) to call Checkmarx One security tools
- Fail-closed security gates for Claude Code, GitHub Copilot CLI, and Cursor plugins
- Real-time vulnerability scanning and blocking during code generation
- Automated remediation workflows via MCP tools
- Comprehensive documentation for setup, authentication, and troubleshooting

## Why It Matters for RAG Builders
It bridges the gap between AI-driven code generation and security compliance by embedding automated security checks directly into AI workflows, reducing vulnerabilities introduced by AI assistants.
