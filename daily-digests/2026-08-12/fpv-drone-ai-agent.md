## Summary
FPV-Drone-AI-Agent enables autonomous flight control for EMAX Nanohawk 1S FPV drones using AI, eliminating the need for manual piloting. It integrates with Betaflight flight controllers, ExpressLRS, and MAVLink to provide real-time, AI-driven navigation and control.

## Key Features
- Autonomous takeoff, navigation, and landing without manual input
- AI-driven adaptive flight path calculation using sensor inputs
- Real-time MAVLink communication with flight controllers
- Compatibility with ExpressLRS for long-range control
- No programming skills required for setup and operation
