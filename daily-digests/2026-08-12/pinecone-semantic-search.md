## Summary
A production-grade semantic search application that enables natural language querying over uploaded Q&A documents using Pinecone's vector database and integrated inference API. Users can upload text files, which are automatically embedded and indexed, then query the data via a Streamlit-based UI.

## Key Features
- Integrated embeddings via Pinecone's server-side inference (no manual embedding calls required)
- Modular architecture with clear separation of concerns (UI, business logic, and Pinecone client layers)
- Config validation and typed exceptions for robust error handling
- Retry mechanisms with exponential backoff for transient failures
- Batched document uploads with size limits and 88% test coverage

## Why It Matters for RAG Builders
This repository provides a turnkey solution for building RAG pipelines with Pinecone, eliminating the need for manual embedding management and offering a production-ready UI for document ingestion and querying.
