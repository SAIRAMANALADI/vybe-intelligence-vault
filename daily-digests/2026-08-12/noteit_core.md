## Summary
A note-taking system built on plain Markdown and structured using the PARA method, where all functionality is defined as natural-language instructions for Claude Code rather than traditional code. The actual notes reside in a separate vault repository, making this a logic layer for managing note-taking workflows via LLM-driven prompts.

## Key Features
- PARA-structured note organization (Projects, Areas, Resources, Archive)
- Skills defined as natural-language instructions for Claude Code (no compiled code)
- Integration with external tools like Obsidian and Git for data management
- YAML frontmatter for metadata (priority, status, tags)
- Planned features for task management and weekly reviews
