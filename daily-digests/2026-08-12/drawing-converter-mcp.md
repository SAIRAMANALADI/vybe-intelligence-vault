## Summary
A Model Context Protocol (MCP) server that converts technical drawings (PDFs) and engineering callouts between metric and imperial units. It enables AI assistants to extract, classify, and convert dimensions, tolerances, threads, and surface roughness directly from PDFs, producing a converted copy with stamped values.

## Key Features
- Converts PDF technical drawings between metric and imperial units with precision
- Supports dimensions, tolerances, GD&T, threads, surface roughness, and weights
- Produces a converted PDF with stamped values matching original callouts
- Offline and deterministic with no API keys required
- Integrates seamlessly with MCP-enabled AI assistants

## Why It Matters for RAG Builders
It enables AI assistants to perform accurate, shop-floor-grade unit conversions directly on technical drawings, reducing manual errors and streamlining engineering workflows.
