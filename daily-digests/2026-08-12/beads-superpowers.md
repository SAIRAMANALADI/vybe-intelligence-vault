## Summary
A plugin for AI coding agents like Claude Code and Codex that enforces disciplined development practices, including test-driven development, systematic debugging, and persistent memory management. It uses a Dolt-backed issue tracker to maintain context across sessions and supports parallel subagent workflows.

## Key Features
- Enforces test-driven development (RED-GREEN-REFACTOR loop) with failing tests before implementation
- Uses Dolt-backed persistent memory to maintain context across AI coding sessions
- Supports parallel subagent workflows for independent task execution
- Provides systematic debugging with 4-phase root-cause analysis
- Includes structured project management skills like brainstorming, writing-plans, and session handoffs

## Why It Matters for RAG Builders
It provides a robust framework for disciplined AI agent workflows, ensuring consistent, test-driven, and context-aware development practices essential for building reliable RAG systems.
