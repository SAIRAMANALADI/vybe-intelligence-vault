## Summary
MCP Safety Warden is a proxy server that wraps any MCP server to add behavioral profiling, security scanning, risk gating, and safe execution to its tools. It operates in proxy or audit mode to enhance security for MCP-based AI workflows.

## Key Features
- Multi-stage security pipeline (Recon, Planner, Hacker, Auditor, Supervisor) for comprehensive threat detection
- Behavioral profiling with effect classification, destructiveness scoring, and risk tagging
- Real-time argument and output injection scanning with 20+ attack categories
- Automated source code analysis (entropy, AST, taint flow, rug-pull detection) for MCP servers
- Drift detection and credential protection with encrypted storage and automatic redaction

## Why It Matters for RAG Builders
It provides critical security hardening for MCP servers, ensuring safe execution and auditing of tools in AI workflows to prevent prompt injection, credential exposure, and other malicious behaviors.
