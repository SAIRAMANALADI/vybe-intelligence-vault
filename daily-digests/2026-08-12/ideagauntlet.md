## Summary
IdeaGauntlet is an open-source CLI and library designed to stress-test product ideas through adversarial critique, multi-role debate, synthetic user objections, and validation planning. It helps founders and engineers refine ideas before investing significant resources into development.

## Key Features
- Multi-mode analysis including quick critique, court mode, synthetic users, and MVP planning
- Agent-native integrations with tools like Claude Code, Cursor, and MCP clients
- Interactive REPL for iterative idea refinement and drill-down analysis
- HTML report export with radar charts and Mermaid diagrams for visual feedback
- Score benchmarking against a dataset of 50 real startup ideas for contextual insights

## Why It Matters for RAG Builders
IdeaGauntlet provides a systematic way to validate and refine product ideas before development, reducing the risk of building the wrong thing and saving time and resources for RAG/AI stack builders.
