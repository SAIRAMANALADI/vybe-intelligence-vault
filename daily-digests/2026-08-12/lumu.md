## Summary
LUMU is a self-hosted AI agent framework designed to run on private servers or local machines, offering long-term memory, tool usage, task automation, and private knowledge retrieval. It emphasizes data privacy, extensibility, and real-world task execution.

## Key Features
- Long-term memory system with decay, integration, and conflict resolution for persistent context retention
- Extensible toolset with AST-based discovery and semantic activation to manage context overhead
- Private knowledge retrieval via vector search (BGE-small-zh-v1.5) for accurate document augmentation
- Skill system enabling natural language-defined capabilities with hot-reloading and self-learning
- Multi-agent orchestration for parallel task execution with isolated contexts

## Why It Matters for RAG Builders
LUMU provides a robust, privacy-focused framework for building and deploying AI agents capable of real-world task execution with persistent memory and extensible tools, making it essential for RAG builders seeking self-hosted, production-ready solutions.
