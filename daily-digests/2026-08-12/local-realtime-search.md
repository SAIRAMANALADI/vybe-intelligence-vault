## Summary
A local-first realtime web research tool for LM Studio that enables ChatGPT-like research capabilities without API keys or cloud LLMs. It integrates with LM Studio via MCP to provide clickable citations, adaptive research modes, and resilient SearXNG-based search backends.

## Key Features
- MCP tool (`local_research`) for LM Studio to enable realtime web research with clickable citations
- Adaptive research modes (`fast`, `balanced`, `deep`, `deepsearch`, `auto`) for varying query complexity
- Resilient SearXNG backend with fallback to DuckDuckGo HTML and weather provider (`wttr.in`)
- Windows one-click launcher for Docker, SearXNG, and LM Studio integration
- Diagnostic tools (`local_status`, `local_recover`) for backend health and recovery

## Why It Matters for RAG Builders
It enables local, realtime web research for AI models without relying on paid APIs or cloud services, making it essential for privacy-focused and cost-effective RAG pipelines.
