## Summary
A lightweight collaboration protocol for multi-agent and multi-session projects that organizes AI agents into departmental teams with structured task management, handoffs, and audit trails. It ensures seamless session transitions and long-term task state persistence via project files.

## Key Features
- Centralized task state management via immutable `tasks/TASK-*.json` files
- Department-based team organization with clear role boundaries and handoff protocols
- Modular scripts for task, session, and fact logging with strict consistency checks
- Explicit user authorization required for session transitions and task execution
- Lightweight protocol designed for Codex Skills integration with minimal runtime dependencies

## Why It Matters for RAG Builders
It provides a structured framework for organizing multi-agent workflows into departmental teams with clear handoffs and audit trails, reducing context loss and improving collaboration reliability in AI-driven projects.
