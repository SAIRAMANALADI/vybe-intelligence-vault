## Summary
Quant Data provides market-statistics skills for AI agents, offering measured edges and honest reporting for index futures and equities. It integrates natively with Claude Code, Codex CLI, and Gemini CLI, and can also be used as a remote MCP server or standalone HTTP API.

## Key Features
- Provides measured market statistics (e.g., Brooks price-action events, Weis volume waves, max pain, dealer gamma exposure) with historical win rates and disclaimers
- Integrates natively with multiple AI agent platforms (Claude Code, Codex CLI, Gemini CLI) and works as a remote MCP server or standalone API
- Offers free tier with anonymous access and email-based API keys (10 calls/day), plus paid plans for unlimited use
- Enforces strict rules to prevent misleading claims, including baselines, disclaimers, and out-of-distribution flags
- Includes educational analytics and fact-checking of trading literature claims against historical data
