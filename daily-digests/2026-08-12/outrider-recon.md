## Summary
outrider-recon is an agentic reconnaissance tool designed for bug bounty, penetration testing, and security teams. It maps external attack surfaces, identifies exposed assets, and ranks findings by severity and attack-path value to prioritize safe next steps without crossing into exploitation.

## Key Features
- Agentic recon workflow with 11 Claude skills and 90 capabilities for comprehensive asset discovery
- Ranked attack-path intelligence with confidence, severity, and detectability scoring
- Integration with public bug-bounty intelligence (HackerOne Hacktivity) for technique references
- Optional MCP server with 5 live enrichment tools (DNS, EPSS, Wayback Machine, etc.)
- Deterministic scope validation, evidence integrity, and policy enforcement for safe recon

## Why It Matters for RAG Builders
It transforms raw recon data into prioritized, evidence-backed attack paths, enabling security teams to focus on high-impact vulnerabilities without unnecessary manual triage.
