## Summary
A Model Context Protocol (MCP) server and autonomous agent for Proton Suite (Mail, Pass, Calendar, Drive) that integrates with Proton Bridge and pass-cli to provide secure, local-first email management, password auditing, and cross-product organization tools via a standardized MCP interface.

## Key Features
- 15+ MCP tools for Mail (IMAP/SMTP via Bridge), Pass, Calendar (stub), and Drive operations
- Secure local execution with stdio and HTTP modes (bearer auth + allowlist)
- Autonomous email organization with dry-run planning and fraud/spam detection
- Proton Pass integration for password auditing and generation without exposing secrets
- Comprehensive documentation, playbooks, and deployment guides for DevOps and users

## Why It Matters for RAG Builders
It provides a secure, standardized MCP interface to Proton Suite services, enabling AI agents to automate email management, password auditing, and cross-product workflows while preserving local-first privacy and security.
