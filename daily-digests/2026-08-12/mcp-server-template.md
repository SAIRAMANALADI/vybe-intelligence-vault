## Summary
A Model Context Protocol (MCP) server template designed to provide a foundation for building custom AI and automation tool APIs. It enables dynamic tool loading, HTTP API access, and easy extension for AI agents and automation workflows.

## Key Features
- Dynamic tool loading from the `tools/` directory for easy extension
- HTTP API with optional authentication for tool access
- Built-in example tools (e.g., echo) with clear documentation
- Support for Docker and systemd for production deployment
- Modular architecture for adding custom tools with Zod schema validation

## Why It Matters for RAG Builders
This template simplifies the creation of MCP servers, enabling AI engineers to rapidly build and deploy custom tool APIs for AI agents and automation workflows.
