## Summary
OpenZIM MCP is a high-performance Model Context Protocol (MCP) server that enables AI models to interact with ZIM format knowledge archives (e.g., Wikipedia, Wiktionary) in a structured, offline manner. It provides tools for querying, searching, and navigating ZIM archives with smart retrieval, link-graph extraction, and archive-type presets.

## Key Features
- 8 specialized tools for advanced ZIM archive interaction (e.g., zim_query, zim_search, zim_links)
- Simple-mode natural-language query tool for small-model deployment
- Archive-type presets for optimized retrieval (e.g., Wikipedia, Stack Exchange)
- Inbound link discovery and link-graph extraction for content relationship mapping
- Streamable HTTP transport with bearer auth, CORS, and health endpoints

## Why It Matters for RAG Builders
It provides structured, offline access to vast knowledge repositories like Wikipedia, enabling AI models to perform intelligent retrieval and analysis without relying on live internet connections.
