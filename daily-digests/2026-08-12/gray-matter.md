## Summary
Gray Matter is a local-first MCP gateway/orchestrator that unifies Neuron (semantic memory) and NeuRAG (knowledge base) into a single brain for AI clients. It acts as a pass-through proxy, unified pulse generator, and cross-store bridge manager, enabling seamless collaboration between memory and knowledge systems.

## Key Features
- Single-server registration for multiple AI tools (Neuron + NeuRAG)
- Unified `gray_matter_pulse(topic)` call combining memory, knowledge, bridges, and flash recall
- Persistent warm workers for sub-servers to avoid cold-start penalties
- Cross-store bridges with Hebbian learning (promotion/decay based on usage)
- Context cache with TTL + LRU and targeted invalidation for efficient retrieval

## Why It Matters for RAG Builders
It simplifies RAG/AI stack integration by unifying memory and knowledge systems into a single orchestrator, reducing registration overhead and enabling advanced cross-store collaboration.
