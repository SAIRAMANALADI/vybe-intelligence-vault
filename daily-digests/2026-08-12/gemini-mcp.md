## Summary
A Model Context Protocol (MCP) server that integrates Google's Gemini API into AI assistants like Claude Desktop, enabling inline image, SVG, video generation, grounded chat, deep research, and media analysis with seamless tool integration.

## Key Features
- Inline rendering of generated images, SVGs, and videos directly in AI assistants like Claude Desktop
- Grounded chat and deep research with Google Search integration for up-to-date responses
- Supports image generation, editing, and analysis with configurable resolution and token optimization
- SVG generation for production-ready vector graphics with multiple styling options
- Video generation using Veo 3.1 with synchronized audio and thumbnail extraction

## Why It Matters for RAG Builders
