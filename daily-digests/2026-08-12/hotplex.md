## Summary
HotPlex Gateway is a high-performance Go-based gateway that unifies access to AI coding agents across multiple platforms (Web, Slack, Feishu) via a single WebSocket interface (AEP v1 protocol). It abstracts agent differences, provides session management, and includes built-in UI, security, and observability features.

## Key Features
- Unified WebSocket interface (AEP v1) for any AI coding agent with backpressure-aware streaming and automatic LLM retries
- Pluggable worker backends (Claude Code, OpenCode Server, ACP, Codex CLI) with 5-level config fallback
- Multi-platform delivery (Slack, Feishu, Web) with embedded UI, voice input/output, and AI-native cron scheduler
- Enterprise-grade security with SSRF protection, API key auth, and path traversal prevention
- End-to-end observability with Prometheus metrics, OpenTelemetry tracing, and structured logging

## Why It Matters for RAG Builders
HotPlex simplifies integrating AI coding agents across platforms by providing a single, protocol-agnostic gateway that handles session management, security, and multi-modal interactions out of the box.
