## Summary
VASTlint is a high-performance, pure-Rust VAST XML validator that checks ad tags against the IAB Tech Lab VAST specification across all published versions. It provides a web-based validator, MCP server, and native bindings for real-time ad pipelines to ensure compliance and prevent revenue loss from malformed tags.

## Key Features
- Validates VAST XML against IAB Tech Lab specifications (versions 2.0 to 4.3) including structural, URI, MIME type, currency, and Ad-ID rules
- Provides a native MCP server for integration with AI agents like Claude and Cursor, enabling programmatic validation
- Offers native bindings for Go, Erlang, and WASM for real-time ad pipelines with sub-millisecond latency
- Includes a zero-dependency Rust core with SLSA Level 2 build provenance and verifiable artifacts
- Supports self-hosting via Docker or static binaries, with ephemeral validation and full privacy controls

## Why It Matters for RAG Builders
VASTlint ensures VAST XML compliance in programmatic ad buying, preventing revenue loss from malformed tags and enabling seamless integration with AI-driven ad tech stacks.
