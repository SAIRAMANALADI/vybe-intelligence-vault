## Summary
IronHive.Agent is a reusable .NET-based agent engine for building AI-powered CLI tools. It provides core agent loops, context management, MCP plugin integration, permission systems, and built-in tools for secure and scalable agent operations.

## Key Features
- Streaming agent loop with configurable per-turn overrides for chat options
- Smart context compaction, goal reminders, and prompt caching
- Rule-based permission system for files, commands, and tools
- MCP plugin support with Stdio and HTTP/SSE transport options
- Built-in tools (Read, Write, Shell, Glob, Grep, Todo) and sub-agent system

## Why It Matters for RAG Builders
IronHive.Agent provides a robust, modular foundation for building secure and scalable AI-powered CLI tools with built-in safety, context management, and MCP integration.
