## Summary
A FastAPI-based Model Context Protocol (MCP) server for Highway Capacity Manual (HCM) analysis and transportation engineering calculations, enabling semantic search, validation, and reasoning over HCM documentation with support for Chapters 12 and 15 methodologies.

## Key Features
- Semantic search over HCM documentation with ChromaDB integration
- Comprehensive HCM Chapter 15 (two-lane highways) and Chapter 12 (basic freeways) analysis tools
- Full-corpus validation engine with 300+ rules (HCM, AASHTO, MUTCD, HSM, ADA) and citations
- Knowledge-graph reasoning for abductive design repair, inverse design, and defeasible code reconciliation
- MCP server compatibility for integration with AI assistants like Claude and GitHub Copilot

## Why It Matters for RAG Builders
This repository provides a specialized MCP server for transportation engineering that enables AI assistants to perform HCM-compliant analyses and validations, bridging the gap between AI workflows and domain-specific regulatory frameworks.
