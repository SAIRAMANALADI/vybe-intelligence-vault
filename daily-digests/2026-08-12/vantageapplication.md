## Summary
Vantage is a browser-based AI market dashboard featuring an animated news anchor that provides real-time stock analysis, answers questions, reads news, and hosts interactive features. It operates fully in the browser with optional cloud or local AI inference, market data, and voice capabilities.

## Key Features
- Fully browser-based single-page application with zero backend setup required for core functionality
- Supports both cloud and local AI inference (Ollama, vLLM) with AMD Radeon/ROCm acceleration
- Integrates with DataHub for schema-aware AI answers, transparently disclosing when data is missing
- Optional backend for accounts, meetings, billing, and hosted AI with graceful fallbacks
- Modular key system for AI, market data, voice, and media APIs with demo modes when keys are absent

## Why It Matters for RAG Builders
It demonstrates a practical, local-first AI agent architecture with transparent data handling and fallback mechanisms, valuable for building robust RAG systems that balance cloud and on-device inference.
