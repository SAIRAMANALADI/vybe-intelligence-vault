## Summary
A desktop AI studio that unifies multiple coding agents (Claude Code, Codex, Antigravity, GitHub Copilot CLI) and live Unity Editor control into a single application. It provides a unified interface for AI-driven Unity development with embedded MCP integration, project awareness, and a robust approval-gated system for file and terminal operations.

## Key Features
- Unified interface for multiple AI agents (Claude Code, Codex, Antigravity, GitHub Copilot CLI, and cloud APIs) with hot-swapping capability
- Live Unity Editor control via embedded Unity MCP with 40+ tools for scene, GameObject, and component manipulation
- Project-aware AI with keyword-based project search and architectural mapping for Unity C# projects
- Robust approval-gated system for file operations, terminal commands, and Unity Editor actions to ensure safety
- Embedded OmniSharp LSP for real-time C# diagnostics, IntelliSense, and Unity API autocompletion without requiring local .NET installation

## Why It Matters for RAG Builders
It streamlines AI-driven Unity development by consolidating multiple agents and live Unity control into a single, approval-gated interface, reducing context switching and improving productivity for RAG and AI stack builders.
