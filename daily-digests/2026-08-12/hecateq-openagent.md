## Summary
Hecateq OpenAgent is a customized fork of oh-my-openagent designed to integrate with the Hecateq workflow engine, offering multi-model agent orchestration, parallel background agents, LSP/AST tooling, and a robust lifecycle hook system for advanced AI-driven development workflows.

## Key Features
- 13 specialized AI agents with Hecateq-specific roles (e.g., Hecateq God, Planner, Sisyphus)
- 60+ lifecycle hooks across 5 tiers for extensible automation and safety
- Hecateq orchestration pipeline with dependency graph, agent selection, and repair loops
- Memory system with bootstrap, manifest, and continuation for stateful workflows
- CLI commands (hecateq plan/run/resume) for direct workflow control

## Why It Matters for RAG Builders
