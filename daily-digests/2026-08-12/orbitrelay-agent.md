## Summary
OrbitRelay is a command-line personal assistant that processes natural-language requests through configurable hosted model connections and executes workspace-confined file and Python tools for task completion. It emphasizes safety, approval policies, and session management for interactive and automated workflows.

## Key Features
- Configurable hosted model connections (OpenAI, Gemini, Grok, DeepSeek, Codex CLI)
- Workspace-confined file and Python tool execution with safety boundaries
- Interactive and policy-based tool approval (read-only, pre-approved, interactive)
- Local session persistence with resumable conversations and structured summaries
- Event-driven model with streaming support and secret-free logging

## Why It Matters for RAG Builders
OrbitRelay provides a secure, configurable framework for building AI agents that interact with local tools and hosted LLMs while enforcing safety and approval policies, making it essential for RAG builders who need controlled agentic workflows.
