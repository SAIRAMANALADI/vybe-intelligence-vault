## Summary
An official Rust implementation of the Model Context Protocol (MCP) SDK, providing async runtime support with Tokio. It enables building clients and servers for MCP-compliant tools, resources, and prompts with full compatibility across MCP specification versions.

## Key Features
- Full implementation of MCP specification (2025-11-25 and 2026-07-28)
- Async runtime support with Tokio for high-performance applications
- Procedural macros for automatic tool and handler generation
- Support for tools, resources, prompts, and multi-round-trip requests
- Compatibility with server discovery, subscriptions, and OAuth workflows

## Why It Matters for RAG Builders
It provides a robust, async Rust SDK for building MCP-compliant agents and tools, essential for integrating AI models with external systems in production environments.
