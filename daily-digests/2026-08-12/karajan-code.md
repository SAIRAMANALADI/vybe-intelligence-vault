## Summary
Karajan Code is a local, multi-agent coding orchestrator that automates software development workflows using TDD principles, MCP-based agent coordination, and vanilla JavaScript. It integrates with existing AI providers (Claude, Codex, Gemini, etc.) to plan, implement, test, and review code autonomously or interactively.

## Key Features
- TDD-first pipeline with automated test generation and execution
- Integration with multiple AI providers (Claude, Codex, Gemini, etc.) for distributed agent roles
- SonarQube integration for code quality and security gates
- Autonomous and interactive modes with conflict resolution via an Arbiter system
- Local-first architecture with no API costs, leveraging existing CLI subscriptions

## Why It Matters for RAG Builders
Karajan Code provides a repeatable, automated pipeline for AI-driven software development, enabling RAG builders to integrate structured, multi-agent workflows that enforce quality and reproducibility without relying on cloud-based API costs.
