## Summary
Crate.io is a company profile repository documenting CrateDB, a distributed SQL database designed for real-time analytics on large operational datasets. It supports multiple data types including time-series, JSON, full-text search, vectors, geospatial, and relational data, while maintaining PostgreSQL wire-protocol compatibility.

## Key Features
- Unifies multiple data types (time-series, JSON, vectors, geospatial) under a single SQL interface
- PostgreSQL wire-protocol compatible for seamless integration with existing tools
- Built on Lucene for efficient full-text and vector search capabilities
- Designed for horizontal scalability to handle large operational datasets
- Supports real-time analytics on streaming and historical data
