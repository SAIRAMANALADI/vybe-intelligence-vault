## Summary
Odin is a local cloud infrastructure design tool that allows users to visually compose AWS architectures on a canvas, compile them to Terraform/OpenTofu, and deploy them locally with IAM-enforced permissions. It bridges visual design with infrastructure-as-code while enforcing security policies in real-time.

## Key Features
- Visual drag-and-drop AWS architecture design with real-time Terraform compilation
- Local deployment of AWS-compatible services (Postgres, S3, Lambda, etc.) via gateway
- IAM permission enforcement through drawn edges with policy validation
- Deterministic translation from canvas to HCL with bidirectional sync
- AI-assisted natural language operations (e.g., 'odin chat') for infrastructure changes

## Why It Matters for RAG Builders
Odin simplifies the gap between visual infrastructure design and secure, reproducible deployments, making it essential for teams prototyping or testing AWS architectures locally before production.
