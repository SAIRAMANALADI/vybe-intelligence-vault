## Summary
A Python-based AI agent that analyzes cryptocurrency markets while ensuring factual accuracy through a deterministic 4-layer anti-hallucination pipeline. It generates cryptographic receipts (SHA-256) to prove corrections made to LLM outputs, providing verifiable insights for capital-sensitive decisions.

## Key Features
- 4-layer anti-hallucination pipeline with deterministic math engine
- Cryptographic SHA-256 receipts for audit trails
- Numeric overrides to enforce factual accuracy over LLM outputs
- Pre-configured demo mode for BTC/ETH with zero setup
- Market regime detection (e.g., ranging, bullish, bearish)
