## Summary
Enterprise AI Agent is a Python-based demo system built with Streamlit, LangChain, LangGraph, and Chroma for enterprise knowledge assistance. It combines RAG, function calling, multi-step workflows, human approval, and task persistence for business intelligence and report generation.

## Key Features
- Multi-format document parsing (TXT, Markdown, PDF, DOCX) with local knowledge base management
- Native Qwen function calling with enterprise tool integration (sales data, project status, calculations)
- LangGraph-based multi-step report generation workflow with human approval and task persistence
- Evidence-based RAG with source attribution and streaming responses
- Comprehensive observability with task tracking, token usage, and automated testing (24 tests)

## Why It Matters for RAG Builders
This repository provides a production-ready blueprint for enterprise AI agents combining RAG, function calling, and workflow automation with human-in-the-loop approvals, making it essential for building scalable AI systems.
