## Summary
Portview is a lightweight, cross-platform CLI tool and MCP server for inspecting, managing, and diagnosing network ports and processes. It provides a user-friendly TUI and JSON output to visualize port usage, detect conflicts, and interact with processes, including Docker containers and remote hosts.

## Key Features
- Interactive TUI with live refresh for monitoring ports and processes
- MCP server integration for AI agents to query and act on ports without shelling out
- Remote inspection over SSH with agentless fallback for Linux/macOS/Windows
- Diagnostic tool (portview doctor) to detect conflicts, leaks, and resource hogs
- Docker integration to manage containerized services alongside host processes

## Why It Matters for RAG Builders
Portview simplifies port and process management for AI stack builders by providing a fast, dependency-free tool with MCP support, enabling seamless integration with AI agents for real-time diagnostics and control.
