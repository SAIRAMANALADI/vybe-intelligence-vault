## Summary
A Model Context Protocol (MCP) server for HaloPSA, enabling AI assistants to interact with HaloPSA's ticketing, client, asset, agent, and invoice management systems through a decision tree-based tool loading architecture.

## Key Features
- Hierarchical tool loading with domain-specific navigation for reduced cognitive load
- Interactive ticket cards with in-card actions for MCP Apps like Claude Desktop
- One-click deployment to Cloudflare Workers and DigitalOcean App Platform
- Rate-limited API client with automatic throttling for HaloPSA
- Brandable UI components via environment variables for MCP Apps

## Why It Matters for RAG Builders
It enables AI assistants to seamlessly interact with HaloPSA's ecosystem, streamlining workflow automation for support, client, and asset management.
