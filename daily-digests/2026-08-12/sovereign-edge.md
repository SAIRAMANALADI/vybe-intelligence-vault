## Summary
Sovereign Edge is an early-stage, privacy-first mobile application designed to run fully offline AI inference and chat on iOS and Android devices. It aims to provide a local-only AI companion with optional, permissioned connectors for limited external interactions.

## Key Features
- Fully offline AI chat with no network requests during inference
- Optional, permissioned connectors for limited external interactions
- Cross-platform support for iOS and Android
- Privacy-focused architecture with clear trust tiers
- CI/CD pipeline with linting, typechecking, and native build verification

## Why It Matters for RAG Builders
It enables fully offline, privacy-preserving AI interactions on mobile devices, addressing critical gaps in local LLM deployment for RAG builders.
