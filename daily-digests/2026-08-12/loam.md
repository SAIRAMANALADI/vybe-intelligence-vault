## Summary
loam is a collection of structured workflow skills for AI coding agents, enabling persistent planning, execution, and knowledge management across sessions. It provides a router-based system to dynamically invoke skills for planning, memory management, and agent coordination.

## Key Features
- Structured skill-based workflows for AI agents with a persistent memory layer
- Router skill (`loam::using`) for dynamic skill invocation based on user intent
- Checkpointing and resuming capabilities to maintain session continuity
- Memory management skills for querying, amending, and auditing knowledge bases
- Integration with popular agent platforms (Claude Code, OpenCode, Cursor, Codex)

## Why It Matters for RAG Builders
loam solves the critical problem of session continuity and knowledge persistence for AI agents, enabling them to build on past work and maintain context across sessions without starting from scratch.
