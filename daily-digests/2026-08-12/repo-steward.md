## Summary
Repo Steward is an autonomous agent designed to automate the operational maintenance of open-source repositories, including triaging issues, reviewing pull requests, authoring bug-fix PRs, and monitoring project websites. It operates as a maintainer's assistant, executing tasks autonomously while deferring final decisions to the user via a live dashboard.

## Key Features
- Autonomous PR/issue triage and review across multiple iterations with staged approvals
- Live dashboard for real-time decision-making and oversight with draft/live mode toggles
- Multi-engine AI backend support (Claude Code, Codex, Gemini, local models via OpenCode)
- Audit logging and decision tracking with structured event records (JSONL)
- Site uptime monitoring and incident escalation with automated investigations

## Why It Matters for RAG Builders
It streamlines open-source repository maintenance by automating repetitive tasks while ensuring human oversight, reducing maintainer burnout and improving project sustainability.
