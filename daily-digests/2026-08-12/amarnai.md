## Summary
Amarnai is an open-source, self-hostable AI email triage assistant for Gmail (with Outlook beta support) that sorts and labels inboxes using AI models while maintaining read-only access. It requires user approval for drafts and supports both local and production LLM/embedding providers.

## Key Features
- Read-only Gmail and Outlook integration with no email mutation
- Custom taxonomy-based email sorting using AI embeddings and LLMs
- Real-time sync via Google Cloud Pub/Sub or Microsoft Graph notifications
- Support for multiple LLM/embedding providers (Ollama, Gemini, OpenAI)
- User-approved drafts with no auto-sending for safety

## Why It Matters for RAG Builders
Amarnai provides a critical tool for AI engineers to prototype and deploy email triage systems with read-only integrations, ensuring data privacy while leveraging advanced AI models for sorting and categorization.
