## Summary
code-review-graph is a Windows-based tool that builds a static analysis graph of software codebases to optimize AI-driven code reviews. It generates a local `code-map.json` file representing code relationships, enabling AI tools to focus on relevant portions of large projects while preserving data privacy.

## Key Features
- Automated static analysis to map code relationships into a graph structure
- Generates a `code-map.json` file for AI tools to reference, reducing irrelevant context
- Supports multiple programming languages via Tree-sitter parsing
- Runs entirely locally with no cloud dependency, ensuring code privacy
- Simple GUI for scanning projects and building the graph

## Why It Matters for RAG Builders
It enables AI tools to efficiently analyze large codebases by providing a structured, privacy-preserving map of code relationships, reducing token waste and improving review accuracy.
