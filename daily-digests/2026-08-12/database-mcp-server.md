## Summary
A production-ready Model Context Protocol (MCP) provider for SQL databases (MySQL, MariaDB, PostgreSQL, SQLite) that enables AI agents to interact with databases via 21 MCP tools. Features secure credential storage, schema introspection, query optimization, and federated queries.

## Key Features
- 21 MCP tools for database interaction including schema introspection, query execution, and optimization
- Secure credential storage with AES-GCM encryption
- Federated query support for cross-database joins and subqueries
- Schema evolution tracking and drift detection
- Structured JSON logging and comprehensive error handling

## Why It Matters for RAG Builders
It enables AI agents to securely and efficiently interact with SQL databases via the MCP standard, simplifying RAG pipelines that require dynamic data retrieval and schema-aware query generation.
