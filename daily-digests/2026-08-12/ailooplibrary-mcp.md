## Summary
A read-only MCP server providing access to the AI Loop Library, which offers 63+ bounded, verifiable work loops for coding agents. It enables agents to select, critique, and design agentic workflows with transparent ranking, state management, and human approval gates.

## Key Features
- Provides 63+ pre-defined, verifiable agent work loops with triggers, stop conditions, and budgets
- Transparent lexical ranking system for loop selection with confidence signals
- Tools to critique and design custom loops based on anti-pattern rubrics
- Generates executable markdown protocols with state skeletons and approval gates
- Single-file, dependency-free Python implementation with stdio transport

## Why It Matters for RAG Builders
It enables AI agents to reliably execute bounded, verifiable workflows with human oversight, reducing hallucinations and improving task completion quality in RAG and agentic systems.
