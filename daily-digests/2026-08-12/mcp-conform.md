## Summary
mcp-conform is a neutral cross-client MCP (Model Context Protocol) conformance validation tool that verifies MCP server behavior and Zero-Touch OAuth compliance across multiple clients with a single command, generating a publishable consistency matrix.

## Key Features
- Single-command execution to validate MCP server behavior and OAuth compliance
- Generates a cross-client consistency matrix (behavior + auth) with pass/fail/skip statuses
- Supports Zero-Touch OAuth discovery and challenge validation
- Outputs machine-readable JSON and badges for CI/CD integration
- Extensible adapter system for new MCP clients (e.g., Claude Code, Cursor, Gemini)

## Why It Matters for RAG Builders
It provides objective, vendor-neutral validation of MCP server compliance across clients, ensuring interoperability and reducing fragmentation in the MCP ecosystem.
