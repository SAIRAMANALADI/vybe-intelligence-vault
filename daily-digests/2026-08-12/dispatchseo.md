## Summary
DispatchSEO is an open-source SEO automation tool that integrates with AI agents like Claude Code and Codex to automate keyword research, content generation, and rank tracking. It transforms AI agents into SEO managers by leveraging existing product knowledge and Search Console data to create pull requests for content optimization.

## Key Features
- AI agent-driven keyword research using Search Console and Google Autocomplete data
- Automated content pipeline that generates pull requests for guides or tools based on approved keywords
- Real-time rank tracking with daily position checks and trend analysis
- Dashboard for approving, rejecting, or reordering keyword ideas with reasoning
- Unattended overnight builder for automated content generation and deployment

## Why It Matters for RAG Builders
DispatchSEO bridges the gap between AI agents and SEO by automating content creation and rank tracking, enabling AI-driven SEO workflows without manual intervention.
