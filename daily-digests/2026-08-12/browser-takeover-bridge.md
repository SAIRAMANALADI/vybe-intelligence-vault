## Summary
Browser Takeover Bridge enables AI agents to securely control already-open authenticated Chrome or Edge tabs without requiring new browser profiles or remote debugging ports. It provides a local-first bridge and companion extension for MCP-compatible agents to interact with trusted browser sessions.

## Key Features
- Secure control of existing browser tabs with user authentication
- Localhost bridge for MCP-compatible AI agents (REST and MCP endpoints)
- Trusted-site restrictions and operational safety controls
- Supports Chrome and Edge with Shadow DOM and iframe handling
- Real-time tab lifecycle events and diagnostic health reporting

## Why It Matters for RAG Builders
It enables AI agents to interact with authenticated web sessions without compromising user security or requiring complex setup, making it essential for RAG pipelines needing real-world web interaction.
