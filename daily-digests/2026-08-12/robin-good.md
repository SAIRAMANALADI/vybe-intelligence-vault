## Summary
Robin Good is a self-learning memecoin trading agent for Robinhood Chain that automatically scans, trades, and learns from Uniswap v3 listings and momentum breakouts. It includes a real-time dashboard for monitoring trades, portfolio performance, and agent insights while enforcing strict risk management.

## Key Features
- Real-time Uniswap v3 scanning for new listings and momentum breakouts
- Automated entry/exit with hard risk caps (daily loss, position size, etc.)
- Self-learning loop that adapts strategy parameters based on trade outcomes
- Interactive dashboard for live monitoring of trades, portfolio, and agent lessons
- Honeypot and rug detection with blacklisting and liquidity validation
