## Summary
An AI-powered engineering assistant integrated into Siemens TIA Portal via an Add-In, enabling contextual explanations, code review, dependency analysis, and controlled change proposals using the Model Context Protocol (MCP). The system captures TIA Portal context, processes it through an agent runtime, and provides read-only or approved write operations.

## Key Features
- Contextual explanations for PLC code and objects within TIA Portal
- Dependency analysis and reference tracing for Siemens PLC projects
- Read-only agent runtime with structured MCP tooling for safe operations
- Approval-based change proposal system with version validation
- Modular architecture isolating Siemens dependencies to a single adapter

## Why It Matters for RAG Builders
It bridges AI agents with industrial PLC engineering environments, enabling safe, context-aware automation for Siemens TIA Portal projects.
