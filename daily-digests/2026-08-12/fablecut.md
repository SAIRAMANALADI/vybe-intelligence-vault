## Summary
FableCut is a browser-based, non-linear video editor that exposes its entire timeline as a JSON document, enabling both human and AI agents to edit videos collaboratively in real-time. It supports advanced editing features, AI-driven automation, and seamless integration with AI tools via MCP/REST APIs.

## Key Features
- Timeline exposed as editable JSON for AI agent integration
- Real-time collaboration between humans and AI agents via MCP/REST
- Advanced video editing features (keyframes, transitions, chroma key, speed ramps)
- AI-powered reference video analysis and blueprint generation
- Zero npm dependencies, lightweight Node.js server

## Why It Matters for RAG Builders
FableCut enables AI agents to directly manipulate video timelines as JSON, making it a critical tool for automating complex video editing workflows and integrating AI-driven creativity into production pipelines.
