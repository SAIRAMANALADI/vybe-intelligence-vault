## Summary
Gensee Crate provides full-stack, long-horizon runtime safety for AI coding agents by monitoring system events, user requests, agent tool calls, and memory. It enforces real-time policy-based controls for security and safety while tracking provenance across sessions for lineage and auditability.

## Key Features
- Real-time enforcement of configurable safety policies for AI coding agents
- Cross-session provenance tracking and lineage graphs for auditability
- Low-latency sidecar deployment on macOS and Linux
- Integration with popular AI coding agents like Claude Code, Codex, and Antigravity
- Local encrypted telemetry storage with configurable encryption settings
