## Summary
Fortémi is an intelligent, Rust-based database designed to transform unstructured organizational data into AI-ready, searchable, and provenance-aware structures. It combines a normalized schema with data-science tooling for RAG, agent memory, and knowledge management workflows, supporting multimodal ingestion and hybrid search.

## Key Features
- Hybrid search combining BM25, dense vectors, and RRF fusion with MMR diversity reranking for semantic and keyword-based retrieval.
- Automatic knowledge graph construction with SNN similarity scoring, PFNET sparsification, and Louvain community detection for semantic linking.
- 13 extraction adapters for multimodal data (images, audio, video, 3D models, emails, spreadsheets, archives) with provenance tracking.
- Multi-provider LLM inference (Ollama, OpenAI, OpenRouter, llama.cpp) with hot-swap runtime configuration and OAuth2/API key authentication.
- Edge-first deployment with GPU/CPU scalability, spatial-temporal search, and real-time events via SSE/WebSocket.

## Why It Matters for RAG Builders
Fortémi provides a unified, AI-optimized data substrate for RAG and agent systems, enabling seamless multimodal ingestion, hybrid search, and knowledge graph integration to build context-aware applications.
