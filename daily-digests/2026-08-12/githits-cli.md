## Summary
GitHits CLI provides a local MCP server that connects AI coding agents to indexed open-source code, documentation, and package metadata. It enables agents to search, read, and analyze real-world implementations and dependencies without relying solely on model memory or local context.

## Key Features
- Local MCP server for AI coding agents to fetch real-world code examples and documentation
- Supports multi-language package inspection (npm, PyPI, Crates, etc.) and vulnerability scanning
- Enables code search, grep, and read operations across indexed repositories without cloning
- Integrates with popular coding tools (Claude, Cursor, VS Code, etc.) via auto-configuration
- Provides dependency upgrade reviews, changelog analysis, and license filtering
