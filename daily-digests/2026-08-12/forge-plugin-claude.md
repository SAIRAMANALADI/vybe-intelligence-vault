## Summary
Forge is an AI-powered product development lifecycle (PDLC) automation plugin for Claude Code that routes user requests through structured workflows for feature requests, bug fixes, and architectural tasks without requiring trigger words.

## Key Features
- Automated routing of development requests (features, bugs, stories) through structured PDLC workflows
- MCP Server integration for workflow management and state updates
- Autopilot skill for intent detection and workflow initiation
- Workflow authoring and management for organization admins
- Session state tracking with hooks for user prompts, tool usage, and workflow continuation
