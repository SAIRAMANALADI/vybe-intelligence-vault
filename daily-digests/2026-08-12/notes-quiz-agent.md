## Summary
notes-quiz-agent is a local desktop application that converts study notes in PDF format into interactive quizzes, flashcards, and mock exams using local LLMs and vector databases. It prioritizes privacy by processing all data offline without internet dependency.

## Key Features
- Converts PDF notes into adaptive quizzes and flashcards using local LLMs
- Supports spaced repetition for long-term memory retention
- Generates mock exams with customizable difficulty and time limits
- Processes and stores data entirely offline for privacy
- Integrates with Ollama for local LLM inference

## Why It Matters for RAG Builders
It provides a privacy-preserving, offline-capable agent framework for transforming static documents into interactive learning tools using RAG and local LLMs.
