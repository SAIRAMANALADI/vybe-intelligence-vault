## Summary
A Model Context Protocol (MCP) server that provides a Markdown-first interface to Notion, enabling AI agents to interact with Notion pages, databases, blocks, and comments efficiently through composite tools and bulk operations.

## Key Features
- Markdown-first input/output for Notion content, simplifying AI agent interactions
- Composite tools (8 tools, 39 actions) for bulk operations and reduced API calls
- Dual transport modes: local stdio and remote HTTP with OAuth 2.1 support
- Auto-pagination and bulk operations to minimize manual cursor handling
- Tiered token optimization (~77% reduction) via compressed descriptions and on-demand help

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate with Notion as a structured knowledge source, reducing complexity and token usage while supporting both local and remote deployments.
