## Summary
Yavio is an open-source, self-hosted analytics platform designed to provide visibility into how users interact with MCP servers and ChatGPT applications. It captures tool calls, user interactions, funnels, errors, and retention metrics with minimal SDK integration and offers a full analytics dashboard for insights.

## Key Features
- Zero-config MCP instrumentation with automatic tool call tracking
- Cross-layer correlation of server-side and client-side interactions via trace IDs
- Multi-tenant workspace support with role-based access control
- PII stripping at both SDK and server layers for privacy compliance
- Full analytics dashboard with funnels, retention, and error analysis

## Why It Matters for RAG Builders
Yavio provides critical visibility into user interactions and tool performance for AI applications, enabling developers to optimize MCP servers and ChatGPT apps based on real usage data.
