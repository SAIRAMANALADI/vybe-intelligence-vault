## Summary
A Telegram-controlled agent that interprets plain-language commands or voice notes to perform GUI actions like mouse movements, clicks, typing, and screen interactions. It combines LLM reasoning with computer control capabilities for hands-free task automation.

## Key Features
- Interprets plain-language or voice commands to perform GUI actions (mouse, keyboard, screen interactions)
- Takes screenshots and uses LLM reasoning to determine next steps
- Supports cancellation and session continuity across restarts
- Modular 'hands' CLI for platform-specific input/output operations
- Secure token handling and atomic config file writes

## Why It Matters for RAG Builders
It enables hands-free automation of computer tasks via natural language, bridging the gap between AI reasoning and real-world GUI interactions for RAG builders.
