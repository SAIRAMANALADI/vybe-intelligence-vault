## Summary
AgentLoop is a multi-step autonomous research agent that plans, searches the live web, reflects on gaps, and synthesizes structured reports with tool-use and memory. It demonstrates agentic AI beyond simple LLM wrapping by implementing conditional loops and long-term memory.

## Key Features
- Conditional agentic loops with LangGraph for dynamic decision-making
- Real tool-calling with Tavily web search and Groq LLM integration
- Dual memory system: short-term state and SQLite long-term memory
- Live observability via streaming trace events in the UI
- Structured report synthesis with cited sources
