## Summary
Ayle is a top-down 2D pixel art game simulating an AI-driven office environment where agents with distinct personalities interact, form relationships, and experience emergent social behaviors. Built with Godot 4.6 and GDScript, it includes an optional LLM backend for enhanced AI decision-making and deep memory systems.

## Key Features
- AI-powered agents with procedurally generated personalities and memories
- Emergent social dynamics including friendships, rivalries, and romances
- Deep memory system influencing agent decisions and dialogues
- Optional LLM backend (Ollama) for enhanced AI decision-making
- God Mode for interactive environment manipulation and agent spawning
