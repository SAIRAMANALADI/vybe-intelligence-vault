## Summary
mcp-dotnet provides two Model Context Protocol (MCP) stdio servers built on .NET 10, enabling secure access to Microsoft Teams and Azure DevOps via Entra ID authentication. It offers read-only operations by default with opt-in gates for writes and sends.

## Key Features
- Two standalone MCP stdio servers (Teams and Azure DevOps) for secure API access
- Read-only operations by default with opt-in gates for writes and sends
- Interactive Entra ID authentication via device code or browser flow
- Supports real-time message waiting and search capabilities
- Configurable via environment variables or .mcp.json files

## Why It Matters for RAG Builders
It enables secure, standardized access to Microsoft Teams and Azure DevOps data for AI agents and tools via the MCP standard, simplifying integration and authentication workflows.
