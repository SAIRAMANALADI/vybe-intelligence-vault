## Summary
OpenAgentEmail provides a self-hosted email solution for AI agents, enabling unlimited mailboxes on a custom domain with OTP and verification-link extraction. It supports REST and MCP interfaces for seamless integration with agent workflows.

## Key Features
- Unlimited identities with a single catch-all mailbox on your domain
- Scoped tokens for secure per-identity access (REST + MCP)
- Built-in OTP and verification-link extraction for automated signups
- Web dashboard for human inspection with admin overview and identity management
- Support for custom SMTP relays and DNS configuration via guided setup

## Why It Matters for RAG Builders
It eliminates dependency on third-party email services for AI agents by providing a self-hosted, scalable, and secure alternative with OTP extraction and MCP integration.
