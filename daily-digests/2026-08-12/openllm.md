## Summary
OpenLLM simplifies self-hosting open-source LLMs by providing an OpenAI-compatible API for running any supported model (e.g., Llama, Qwen, Phi) with a single command, including a built-in chat UI and support for custom models and cloud deployment via BentoCloud.

## Key Features
- Run any open-source LLM (e.g., Llama, Qwen, Phi) as an OpenAI-compatible API with a single command
- Built-in chat UI for interactive model exploration
- Support for custom model repositories and enterprise-grade cloud deployment (Docker, Kubernetes, BentoCloud)
- State-of-the-art inference backends (vLLM) for optimized performance
- Seamless integration with existing tools and frameworks via OpenAI-compatible endpoints
