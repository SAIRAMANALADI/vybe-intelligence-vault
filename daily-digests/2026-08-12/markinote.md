## Summary
MarkiNote is a self-hosted Markdown workspace that integrates a guarded AI agent capable of reading, editing, organizing, and managing documents autonomously. It transforms a directory of Markdown files into a browser-based knowledge workspace with AI-assisted capabilities.

## Key Features
- 11 bounded AI tools for file operations (read, write, edit, create, delete, move) with opt-in write access and one-time approvals
- Autonomous AI agent capable of multi-step tool usage, file rollback, and audit logging
- Supports DeepSeek and Kimi AI models with streaming SSE responses and real-time tool visualization
- Modular monolith architecture with FastAPI backend, React 19 frontend, and NGINX gateway
- Built-in reliability features including dirty-buffer protection, conflict detection, and content versioning

## Why It Matters for RAG Builders
MarkiNote provides a critical foundation for RAG builders by offering a secure, self-hosted environment where AI agents can autonomously manage and interact with document repositories, enabling advanced retrieval and generation workflows.
