## Summary
Massu is an AI Engineering Governance Platform that enhances AI coding assistants with session memory, feature registry, code intelligence, and rule enforcement. It transforms general-purpose AI tools into governed engineering environments with cross-session learning, architectural drift detection, and observability features.

## Key Features
- Cross-session session memory with full-text search and failure recall
- Feature registry (Sentinel) for tracking features and detecting impact during refactors
- Code intelligence tools for import chain analysis, coupling detection, and domain boundary enforcement
- Rule engine for contextual coding rules surfaced during file edits
- Observability with session replay, prompt analysis, and cost tracking

## Why It Matters for RAG Builders
Massu ensures governance, security, and architectural integrity in AI-driven software development by providing critical oversight tools that prevent drift, vulnerabilities, and knowledge loss during AI-assisted coding sessions.
