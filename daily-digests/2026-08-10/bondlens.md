## Summary
BondLens AI is an explainable, evidence-grounded agent for analyzing Chinese bond market data. It prioritizes live data from AkShare, falls back to cached snapshots or local samples, and provides structured evidence trails, risk profiles, and guardrails for safe LLM-enhanced responses.

## Key Features
- Live-first data pipeline with AkShare integration and fallback mechanisms
- Deterministic agent workflow with structured evidence ledgers and risk profiles
- LLM guardrails for numeric claims and unsafe investment language checks
- Replay dashboard for auditing agent runs without exposing raw JSON
- Portfolio-ready deployment with Docker, CI, and comprehensive eval suites
