## Summary
Django ORM Lens is a multi-platform tool that provides live visualization, navigation, and ER diagram generation for Django models. It integrates with VS Code, terminals, and AI agents via MCP to simplify schema exploration without requiring Django runtime or database access.

## Key Features
- Live sidebar tree of all Django models, fields, and relationships in VS Code
- Interactive Mermaid ER diagram with cardinality arrows and theme support
- Hover cards for quick field and relation inspection without file navigation
- Standalone CLI and MCP server for terminal and AI agent integration
- Zero runtime dependencies and offline-first operation

## Why It Matters for RAG Builders
It accelerates AI agent and developer workflows by providing instant, structured access to Django schema metadata without requiring Django runtime or database access.
