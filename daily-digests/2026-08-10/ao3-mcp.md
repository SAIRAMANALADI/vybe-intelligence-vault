## Summary
A Model Context Protocol (MCP) server that enables AI agents to interact with Archive of Our Own (AO3) to search, summarize, and rank fanfiction. It leverages AI for natural language queries and provides structured outputs for efficient context management.

## Key Features
- Enables AI agents to query AO3 for fanfiction using natural language prompts
- Provides summarization and ranking of stories based on user-defined criteria (e.g., plot pacing, character development)
- Integrates with MCP-compatible AI clients for seamless context management
- Reduces context window bloat by generating concise summaries of long fanfiction works
- Supports customizable search filters (e.g., tropes, word count, excluded tags)

## Why It Matters for RAG Builders
It bridges AI agents with AO3, enabling efficient discovery and analysis of fanfiction while optimizing context usage for RAG pipelines.
