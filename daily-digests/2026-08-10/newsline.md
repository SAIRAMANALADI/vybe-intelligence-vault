## Summary
Newsline aggregates headlines from 17 politically diverse news outlets, providing a JSON API, web reader, and MCP server to deliver real-time news with left/center/right bias tags and blindspot detection for stories covered by only one side.

## Key Features
- Aggregates headlines from 17 diverse news outlets with bias tags (-2 to +2)
- Provides blindspot detection for stories covered by only one political side
- Offers three access methods: web reader, JSON API, and MCP server
- Stateless HTTP API with no rate limits or authentication requirements
- Lightweight Cloudflare Worker deployment with no backend storage
