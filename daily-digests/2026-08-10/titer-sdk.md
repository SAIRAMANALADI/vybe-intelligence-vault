## Summary
The @titer/sdk repository provides a TypeScript/JavaScript SDK for Titer, an on-chain security policy firewall and time-lock vault designed to protect autonomous AI agents on Solana. It enables secure treasury management by separating agent hot wallets from primary vaults and enforcing policy-based transaction validations.

## Key Features
- Intercepts and validates agent transactions against security policies before execution
- Separates agent hot wallets from primary treasury vaults for enhanced security
- Supports allowlist validation, daily spending caps, and anomaly time-locks
- Integrates seamlessly with ElizaOS for AI agent workflows
- Provides deterministic policy enforcement and manual override capabilities

## Why It Matters for RAG Builders
It enables secure, policy-driven treasury management for autonomous AI agents on Solana, reducing fraud risk and ensuring compliance with predefined security rules.
