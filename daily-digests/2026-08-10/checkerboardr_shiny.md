## Summary
CheckerBoardR.shiny is a Shiny-based web portal for analyzing drug combination synergy, antagonism, and dose-response curves with advanced visualization and modeling capabilities. It supports multiple synergy models, interactive 2D/3D plots, and deployment via Docker or native Shiny Server.

## Key Features
- Supports 4-Parameter Logistic (4PL) Hill Curves for dose-response fitting
- Implements multiple synergy models: HSA, Bliss, Loewe, ZIP
- Interactive 3D Plotly surfaces and 2D ggplot heatmaps with dynamic annotations
- Docker containerization for easy deployment and reproducibility
- Integrated Python MCP server for programmatic LLM interactions
