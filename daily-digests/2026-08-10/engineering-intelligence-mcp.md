## Summary
A production-ready Model Context Protocol (MCP) server for Express.js applications that enables AI clients to inspect backend systems through structured engineering tools. It exposes Git history, Winston logs, OpenAPI contracts, and sandboxed source code via a secure provider-based architecture.

## Key Features
- MCP-compliant server with official MCP SDK integration
- Tool registry-based architecture for extensible providers
- Dynamic exposure of Git history, Winston logs, and OpenAPI contracts
- Sandboxed source code access for secure inspection
- Validated with MCP Inspector and Claude Desktop

## Why It Matters for RAG Builders
It enables AI clients to securely inspect and analyze backend systems without direct file access, improving debugging and development workflows.
