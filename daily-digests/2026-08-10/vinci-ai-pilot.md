## Summary
Vinci AI Pilot is a self-hosted AI agent for marketing intelligence that automates competitor research by querying public web sources via Telegram, analyzing findings with Claude API, and delivering structured reports in Google Sheets and XLSX format with source citations.

## Key Features
- Telegram-based query interface for real-time competitor research
- Multi-source data collection (web, social media, APIs) with source attribution
- Claude API-powered analysis with evidence-backed conclusions
- Automated report generation in Google Sheets and XLSX formats
- Offline regression testing ($0 cost) with CI/CD integration

## Why It Matters for RAG Builders
It provides an end-to-end framework for automating competitive intelligence workflows, reducing manual research effort while ensuring traceable, evidence-based insights for RAG pipelines.
