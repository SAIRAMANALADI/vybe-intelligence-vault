## Summary
A B2B travel-management demo integrating Auth0 RBAC and Organizations with an AI assistant whose tools are dynamically gated by the user's permissions. Demonstrates role-based access control, multi-tenancy via Auth0 Organizations, and permission-filtered AI tooling in a single FastAPI process.

## Key Features
- Role-based access control with Auth0 Roles and Organizations for multi-tenancy
- Permission-gated AI chat tools dynamically filtered by user scopes
- Step-up authentication via CIBA for destructive actions and approvals
- Integrated Google Calendar and Gmail tools via Token Vault
- In-memory mock data for rapid prototyping and workshop use

## Why It Matters for RAG Builders
It provides a practical blueprint for building secure, permission-aware AI agents with Auth0 integration, demonstrating how to enforce fine-grained access control in AI tooling without complex orchestration frameworks.
