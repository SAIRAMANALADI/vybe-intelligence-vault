## Summary
OpenCrawling is a Java and Spring Framework-based reference implementation of the Open Ingestion Standard (OIS), designed to securely integrate and orchestrate data flows from diverse repositories into vector search outputs. It leverages modern Java 25 features, Spring Boot, Spring AI, and vector search infrastructure to enable enterprise-grade data ingestion and transformation.

## Key Features
- Reference implementation of Open Ingestion Standard (OIS) for secure, decoupled data integration
- Modular architecture with Kafka-based event streaming for scalable data pipelines
- AI-powered observability (AIOps) with OpenTelemetry integration for automated root cause analysis
- Support for multiple vector databases (Milvus, Qdrant, OpenSearch, Vespa) and embedding models
- Admin UI for real-time monitoring, job scheduling, and connector configuration

## Why It Matters for RAG Builders
OpenCrawling provides a vendor-neutral, enterprise-grade framework for securely integrating diverse data sources into vector search outputs, essential for building robust RAG pipelines with observability and scalability.
