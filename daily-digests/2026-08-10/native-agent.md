## Summary
NativeAgent is a Swift-native, cross-platform agent runtime for macOS and iOS that provides a unified local runtime for conversation, memory, tools, and cognition. It enables seamless agent operation across multiple surfaces like Mac, iPhone, Telegram, Slack, and local bridges without relying on external APIs or hidden daemons.

## Key Features
- Unified runtime for conversation, memory, and tools across multiple surfaces (Mac, iPhone, Telegram, Slack, etc.)
- Fluid Context system for canonical persona, memory, and cognition with SQLite-backed durability
- Policy-aware tools and skills with lazy loading and canonical skill management
- TrustCenter and approvals for secure, fail-closed operations with receipts and replay safety
- Optional cognitive substrate and organism kernel for bounded continuity and state management

## Why It Matters for RAG Builders
NativeAgent provides a robust, local-first agent framework that unifies multi-surface operations with strict trust boundaries, making it essential for building secure, scalable AI agents with persistent memory and cross-platform consistency.
