## Summary
An unofficial Robinhood API mapping, CLI, and MCP server enabling terminal or agent-driven control of a real Robinhood account with live reads and gated writes. It provides a comprehensive toolkit for trading, portfolio management, and research with a focus on agentic automation and safety.

## Key Features
- Comprehensive Robinhood API mapping with 300+ endpoints, including brokerage, crypto, and options routes
- CLI and MCP server with full parity for reads and writes, enabling agent-driven trading workflows
- Dry-run and live-write gating for all trades, with pending-duplicate deduping and idempotency
- Built-in research and memory systems (ball-knowledge.md, trading-log.md) for cross-session agent intelligence
- Advanced features like dividend/income tracking, options strategy quoting, rolling, and tax document management

## Why It Matters for RAG Builders
It enables agent-driven, automated trading workflows with real-time account control and safety gating, bridging the gap between research, decision-making, and execution in a single pipeline.
