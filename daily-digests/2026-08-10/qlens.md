## Summary
QLens is a lightweight image viewer and manager designed to replicate the simplicity of Picasa while introducing an open, AI-era image tagging protocol (`qltag.db`). It enables efficient tagging, batch processing, and AI-driven image analysis without excessive token usage.

## Key Features
- Lightweight Picasa-style image viewer with fast performance and minimal UI clutter
- Open and extensible image tagging protocol (`qltag.db`) stored per folder for portability
- MCP server integration enabling AI agents to interact with the image library without burning tokens
- Built-in batch processing with pre-compression to optimize AI analysis costs
- Concurrent read/write support via WAL-enabled SQLite database for multi-agent collaboration

## Why It Matters for RAG Builders
QLens provides a critical bridge between image management and AI-driven workflows by enabling efficient, token-optimized tagging and analysis while maintaining a lightweight user experience.
