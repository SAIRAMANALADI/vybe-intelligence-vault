## Summary
Tiger CLI is a command-line interface for managing Tiger Cloud database services, offering lifecycle operations, authentication, and configuration management. It includes an integrated Model Context Protocol (MCP) server to enable AI assistants to interact programmatically with Tiger Cloud infrastructure.

## Key Features
- Comprehensive CLI for Tiger Cloud database service management (create, start, stop, resize, delete, etc.)
- Integrated MCP server for AI assistants to interact with database services programmatically
- Schema introspection and query execution capabilities via MCP tools
- Read-only mode support to prevent accidental mutations in AI agent contexts
- Multi-platform installation (macOS, Linux, Windows) with package manager support

## Why It Matters for RAG Builders
Tiger CLI bridges the gap between AI assistants and Tiger Cloud infrastructure, enabling seamless, programmatic database operations for RAG and AI stack builders.
