## Summary
Flow-Like is a local-first, source-available platform for building end-to-end workflows, data pipelines, AI agents, and apps in a single runtime. It combines a visual workflow studio, a native data layer, and on-device AI capabilities, enabling offline operation and deployment flexibility.

## Key Features
- Visual no-code workflow studio with type-aware wiring and live validation
- Built-in native data layer supporting terabytes of data with hybrid keyword and vector search
- On-device AI integration (LLMs, embeddings, vision, speech) with full lineage and guardrails
- Cross-platform runtime (laptop, server, phone, edge) with offline-first design
- Extensible node system supporting 15+ languages via WebAssembly sandboxing

## Why It Matters for RAG Builders
Flow-Like unifies workflows, data, and AI into a single platform, eliminating the need for disparate tools and reducing integration complexity for RAG and AI stack builders.
