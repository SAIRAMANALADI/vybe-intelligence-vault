## Summary
Memory-bank is a Windows-based tool designed to provide long-term memory storage for AI chat sessions, preserving project context, rules, and history across conversations to reduce token usage and improve AI performance consistency.

## Key Features
- Saves and restores AI chat context across sessions
- Reduces token consumption by maintaining long-term memory
- Works offline with local file storage for privacy
- Supports automatic recovery and manual editing of memory files
- Compatible with professional-grade AI models like Claude
