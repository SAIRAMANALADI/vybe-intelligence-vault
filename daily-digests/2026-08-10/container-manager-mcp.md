## Summary
Container Manager MCP is a production-grade Model Context Protocol (MCP) server and agent framework for managing Docker, Docker Swarm, Podman, and Kubernetes containers through CLI, API, or MCP interfaces. It provides unified tooling for container operations, multi-host orchestration, and ontology-driven inventory ingestion.

## Key Features
- Full coverage for Docker, Podman, Swarm, and Kubernetes with 300+ MCP tools
- Multi-context parallel operations across distributed hosts via SSH tunneling
- Ontology-driven inventory ingestion for knowledge graph integration
- Enterprise-grade security with OIDC, Eunomia policies, and execution context tracking
- Native telemetry, tracing, and integrated AI agent support (ACP/A2A)

## Why It Matters for RAG Builders
It provides a unified, secure, and scalable interface for AI agents to manage containerized environments across multiple orchestration platforms, critical for automating infrastructure operations in RAG pipelines.
