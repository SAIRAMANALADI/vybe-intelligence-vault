## Summary
A genericized memory subsystem designed for multi-agent AI architectures, enabling persistent memory management, rule-based governance, and cross-agent synchronization. The system supports per-agent customization and anti-obsolescence through archival and soft-pass checks.

## Key Features
- Genericized memory subsystem for multi-agent deployment (Sally/Spiro)
- Anti-obsolescence via archival of unused lessons and soft-pass checks
- Rule-based governance with hard/soft rules and personality traits
- Cross-platform compatibility (Unix/Windows with cron/Task Scheduler)
- Per-agent customization for identity, rules, and user context

## Why It Matters for RAG Builders
It provides a structured, scalable approach to managing persistent memory and governance rules for AI agents, critical for building self-evolving and cross-agent aware systems.
