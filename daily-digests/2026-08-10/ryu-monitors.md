## Summary
ryu-monitors is a website monitoring tool for the Ryu ecosystem that tracks price changes, stock availability, keyword presence, content differences, and uptime status. It supports cross-device notifications and integrates with the Ryu platform for scalable monitoring and alerting.

## Key Features
- Multi-type monitoring (price, stock, keywords, content diff, uptime)
- Extensible fetch backend (HTTP or Spider crawler)
- Cross-device notification fan-out (Expo, Telegram, webhooks, etc.)
- SQLite-based state persistence for snapshot comparisons
- React-based companion UI with self-contained HTML deployment

## Why It Matters for RAG Builders
ryu-monitors provides essential real-time monitoring capabilities for RAG pipelines that rely on dynamic web data, enabling automated updates and alerting when critical information changes.
