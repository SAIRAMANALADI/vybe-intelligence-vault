## Summary
A JavaScript SDK providing JSON schemas, protocol specifications, and helper functions for the Genome Evolution Protocol (GEP). It ensures consistent asset_id values across implementations by centralizing schemas and protocol-level utilities, avoiding drift in downstream projects.

## Key Features
- Centralized JSON schemas for Genes, Capsules, Mutations, Tasks, and EvolutionEvents
- Deterministic asset_id computation using SHA-256 and canonicalization
- Protocol constants and enums for consistent implementation across runtimes
- Zero runtime dependencies and lightweight design
- Stable API with clear versioning and stability guarantees

## Why It Matters for RAG Builders
It ensures protocol-level consistency and interoperability for RAG systems by providing a single source of truth for asset schemas and identifiers, preventing silent drift across implementations.
