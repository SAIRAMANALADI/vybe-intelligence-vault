## Summary
A TypeScript-based MCP server providing 19 public instruction tools and 3 utility tools, backed by 72 internal skills across 16 domain families. It offers hierarchical prompting, code hygiene, visualization, memory optimization, and agile planning capabilities for AI agents.

## Key Features
- 19 public instruction tools and 3 utility tools exposed via MCP
- 72 internal skills organized into 16 domain families for specialized AI tasks
- Bio-inspired adaptive routing (ACO, Hebbian, Slime-mould, etc.) for dynamic workflows
- Governance layer with prompt-injection hardening, PII guardrails, and policy validation
- Zero runtime LLM calls; provides advisory outputs for agent orchestration

## Why It Matters for RAG Builders
It provides a structured, tool-rich framework for AI agents to perform complex tasks like code analysis, orchestration, and governance, reducing development overhead for RAG builders.
