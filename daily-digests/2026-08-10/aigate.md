## Summary
A self-hosted AI platform that consolidates inference, tool use, browser automation, image generation, speech synthesis, transcription, object storage, agentic code execution, and more behind a single OpenAI-compatible endpoint. Designed for seamless integration with existing clients via a unified API.

## Key Features
- Unified OpenAI-compatible endpoint for all AI services (inference, tools, storage, etc.)
- Multi-provider model routing with automatic fallback and rate-limit handling
- Built-in MCP tools for browser automation, code execution, image generation, and more
- Modular architecture with opt-in services via environment flags
- Comprehensive security with network isolation, auth, and sandboxed execution

## Why It Matters for RAG Builders
It simplifies the deployment and management of a full AI stack by consolidating multiple services into a single, self-hosted platform with an OpenAI-compatible API.
