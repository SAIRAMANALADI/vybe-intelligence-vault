## Summary
Lineage Oracle is an AI agent that answers data warehouse lineage and impact questions with grounded citations from dbt models, Airflow DAGs, and DuckDB schemas. It builds a NetworkX lineage graph and Voyage-3 embedding index to provide accurate, traceable answers to queries like 'What feeds X?' or 'What breaks if I drop Y?'

## Key Features
- Grounded answers with citations from SQL files and DAGs
- NetworkX-based lineage graph for tracing dependencies
- Voyage-3 embeddings for semantic search across artifacts
- Two-phase system: indexing and query execution
- Built-in evaluation harness for measuring accuracy and citation precision

## Why It Matters for RAG Builders
Lineage Oracle enables RAG builders to create systems that provide accurate, traceable answers to data lineage and impact questions, reducing reliance on manual documentation and improving data reliability.
