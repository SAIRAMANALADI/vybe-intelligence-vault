## Summary
Nexa Agent is a terminal-first local AI agent framework with iterative tool-calling, multi-provider support, and a self-improvement memory system. It features a TUI, Web UI, and 40 AI skills across six categories, enabling autonomous task execution and real-time interaction.

## Key Features
- 40 AI skills across 6 categories with real implementations and stubs
- Interactive TUI with 4-panel live terminal UI and 18 slash commands
- Web UI built with Next.js and React for collapsible sidebar and sandbox
- 33 tools including 13 core and 20 planning tools for autonomous task execution
- Self-improvement memory system with SQLite FTS5 full-text search and learning graph

## Why It Matters for RAG Builders
Nexa Agent provides a robust, extensible framework for building autonomous AI agents with multi-provider support, real-time tool execution, and self-improvement capabilities, making it essential for RAG builders seeking advanced agent orchestration.
