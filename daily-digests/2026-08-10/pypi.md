## Summary
A Python package repository hosting tools for the ResQ disaster response platform, including a FastMCP server for AI agent integration and zero-dependency data structures for search, rescue, and geospatial operations.

## Key Features
- FastMCP server (`resq-mcp`) enabling AI agents to interact with drone fleets, simulations, and disaster intelligence systems
- Zero-dependency data structures (`resq-dsa`) for efficient search, rescue, and geospatial operations including Bloom Filters, Count-Min Sketch, and Graph algorithms
- Automated semantic versioning and publishing to PyPI using conventional commits and trusted publisher OIDC
- Modular architecture with clear separation between MCP server and data structures
- Docker support for containerized deployment of the MCP server
