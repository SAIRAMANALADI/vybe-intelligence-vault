## Summary
An unofficial MCP server for Bosch eBike Flow that enables read-only access to bike data, including battery health, ride activities, component versions, and service history via OAuth authentication with Bosch's public API endpoints.

## Key Features
- Read-only access to Bosch eBike Flow data via official public OAuth client
- Tracks battery health, charge cycles, and degradation trends over time
- Provides per-ride activity data including distance, elevation, power, and CO2 emissions
- Supports live state-of-charge monitoring and component firmware versions
- Auto-sync capabilities with local SQLite caching for efficient data retrieval

## Why It Matters for RAG Builders
It enables AI systems to integrate real-world eBike telemetry and battery analytics for predictive maintenance, usage insights, and personalized recommendations in RAG applications.
