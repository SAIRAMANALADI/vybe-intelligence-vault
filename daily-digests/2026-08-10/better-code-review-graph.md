## Summary
An MCP server that builds a knowledge graph of codebases using Tree-sitter to enable token-efficient code reviews via semantic search and call-graph resolution. It parses code structures, tracks dependencies, and provides precise context to AI agents for targeted analysis.

## Key Features
- Builds structural code graphs (functions, classes, imports) with Tree-sitter parsing
- Enables semantic search and call-graph resolution for token-efficient code reviews
- Supports local ONNX embeddings (zero-config) or cloud-based embedding chains
- Provides temporal tracking of code changes via versioned nodes and edges
- Offers security scanning via optional Semgrep integration

## Why It Matters for RAG Builders
It enables AI agents to perform precise, context-aware code reviews by resolving dependencies and semantic relationships, reducing token usage and improving review accuracy.
