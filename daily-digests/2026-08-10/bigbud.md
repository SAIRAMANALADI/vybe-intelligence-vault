## Summary
bigbud is an AI-powered workspace that integrates research, writing, coding, file management, and Git workflows into a unified interface, supporting both desktop and web environments with advanced automation features like real-time streaming, speech-to-text, and computer use capabilities.

## Key Features
- Multi-provider AI agent integration (Claude, Copilot, Codex, OpenCode, Pi, Cursor)
- Remote project access over SSH with local UI experience
- Computer use automation for browser and macOS desktop control
- Real-time streaming and speech-to-text powered by OpenAI
- Thread forking and organization for multi-turn conversations
