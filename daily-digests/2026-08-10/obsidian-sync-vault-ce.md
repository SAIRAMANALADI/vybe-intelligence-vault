## Summary
A plugin for Obsidian that syncs cloud storage (e.g., Baidu Netdisk, OneDrive, Aliyun) with local vaults, enabling seamless access, linking, and embedding of cloud resources in notes. It includes an MCP server for AI agents to interact with cloud files and supports multi-device synchronization.

## Key Features
- Bi-directional sync between cloud storage and Obsidian vaults with conflict resolution
- Built-in MCP server for AI agents (e.g., Claude Code, Cursor) to access and manipulate cloud files
- CLI commands for automation and AI workflows
- End-to-end encryption for Markdown files and support for multiple cloud services (Baidu, OneDrive, Aliyun, etc.)
- Real-time collaborative editing and online preview for images, PDFs, audio, and video

## Why It Matters for RAG Builders
It bridges cloud storage with AI workflows, enabling LLMs and agents to directly access and manipulate files for RAG pipelines while maintaining Obsidian integration.
