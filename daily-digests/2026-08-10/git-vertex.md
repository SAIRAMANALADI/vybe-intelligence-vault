## Summary
Git Vertex is a modern, multi-surface Git client offering a desktop app, VS Code extension, terminal UI, and MCP server for coding agents. It provides a fast, visual interface for branch management, staging, rebasing, and commit operations with AI-powered commit message generation.

## Key Features
- Interactive commit graph for branch visualization and management
- AI-powered commit message generation with multiple provider support
- Cross-platform support (desktop, VS Code, terminal, MCP server)
- Interactive rebase and conflict prediction (requires Git 2.40+)
- Structured Git context for coding agents via MCP server
