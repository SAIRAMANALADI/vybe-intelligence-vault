## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with the ThreatLocker Portal API, allowing management of computers, approval requests, audit logs, and organizations through natural language commands.

## Key Features
- Stateless architecture with fresh connections per request for scalability
- Gateway mode support for multi-tenant deployments via HTTP headers
- Interactive elicitation prompts for missing parameters during AI interactions
- Comprehensive error handling and structured logging for reliability
- Docker support for production-ready containerization and deployment

## Why It Matters for RAG Builders
It bridges AI assistants with ThreatLocker's zero-trust application allowlisting and approval workflows, enabling secure, natural language-driven management of endpoint security policies.
