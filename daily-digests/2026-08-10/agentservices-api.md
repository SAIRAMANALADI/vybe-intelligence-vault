## Summary
AgentServices provides a monetized API layer for AI agents, enabling pay-per-request access to 50+ endpoints covering crypto data, market intelligence, DeFi analytics, AI inference, and dispute resolution using the x402 micropayment protocol on Base Mainnet.

- x402 micropayment protocol integration for pay-per-request monetization on Base Mainnet
- MCP server compatibility for seamless AI agent integration

- Coinbase AgentKit action provider for typed, documented API interactions
