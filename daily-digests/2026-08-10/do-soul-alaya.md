## Summary
Do-SOUL Alaya is a local-first memory plane for CLI coding agents, designed to provide cross-session, evidence-gated memory management without cloud dependencies. It ensures durable claims are auditable, traceable, and governed by a structured ontology, addressing the limitations of vector databases in agent memory systems.

## Key Features
- Governance-first memory system with six distinct lifecycle phases (perception, governance, durability, recall, receipt, maintenance)
- SQLite-backed storage for local ownership and no telemetry or cloud round-trips
- Evidence-gated durability with explicit governance rules to prevent hallucinations and ensure traceability
- MCP and CLI interfaces for seamless integration with coding agents like Codex and Claude Code
- Comprehensive benchmarking system with reproducible recall metrics and diagnostics

## Why It Matters for RAG Builders
It provides a structured, auditable, and evidence-gated memory system for CLI agents, ensuring durable claims are traceable and governed, which is critical for reliable RAG implementations.
