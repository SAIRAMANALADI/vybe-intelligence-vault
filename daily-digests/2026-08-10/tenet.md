## Summary
Tenet is an AI agent that automates GitHub issue resolution and pull request reviews by exploring repositories, writing fixes, and opening PRs when triggered via GitHub comments. It supports multiple LLM providers and integrates with GitHub Apps for seamless workflow automation.

## Key Features
- Automated issue resolution via `/tenet-build` comment trigger
- Structured PR reviews with haikus, Mermaid diagrams, and severity-scored findings
- Sandboxed agent execution in Docker with Google Cloud Run
- Multi-LLM provider support (OpenAI, Anthropic, Google, etc.)
- Encrypted API key storage and user quota management

## Why It Matters for RAG Builders
Tenet streamlines GitHub workflows by automating issue resolution and PR reviews, reducing manual effort for developers and enabling faster iteration cycles in AI-driven projects.
