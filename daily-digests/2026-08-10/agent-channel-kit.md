## Summary
A self-hosted framework for integrating personal AI agents with communication channels like WeChat, enabling text automation and real-time GPT Voice capabilities. Focuses on architecture, interfaces, and fault boundaries rather than one-click installers.

## Key Features
- Supports private/group chats, file/image transfers, and tool calls via REST API
- Enables real-time GPT Voice with full-duplex group calls using Codex Voice Gateway
- Modular architecture with clear separation of text and voice capabilities
- Includes fault-tolerant services for cache, entry recovery, and auto-answering
- Provides detailed deployment guides and diagnostic scripts for Linux environments

## Why It Matters for RAG Builders
It enables seamless integration of AI agents with personal communication channels, unlocking real-time voice and text automation capabilities for RAG and agent-based systems.
