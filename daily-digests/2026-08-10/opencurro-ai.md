## Summary
OpenCurro AI is a production-grade autonomous AI agent workspace that enables sandboxed file operations, shell execution, and web search through a real-time chat interface. It integrates with multiple LLM providers and runs in an isolated Novita sandbox for secure execution.

## Key Features
- Autonomous agent loop with tool-calling capabilities (8 built-in tools)
- Isolated Novita sandbox for secure file and shell operations
- Real-time streaming chat interface with SSE for tokens and tool outputs
- Support for multiple LLM providers (OpenRouter, Groq, NVIDIA NIM)
- Extensible architecture with registry pattern for providers, tools, and sandboxes

## Why It Matters for RAG Builders
It provides a robust, production-ready framework for building and deploying autonomous AI agents with secure sandboxed execution and multi-provider LLM support.
