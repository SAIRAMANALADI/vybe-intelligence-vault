## Summary
A lightweight web-based WeChat bot management console that enables QR code binding, bot control, AI-powered auto-replies, and plugin-based automation for WeChat interactions via the iLink/ClawBot protocol.

## Key Features
- QR code binding with encrypted credential storage for persistent sessions
- AI-powered auto-replies with multi-turn conversation context via MiniMax/Anthropic API
- Built-in plugin marketplace with 6+ plugins for proactive messaging (weather, stocks, exchange rates) and on-demand queries
- Automatic bot recovery on server/container restart and persistent data storage via Docker volumes
- Multi-user isolation with separate credentials, chat logs, and plugin configurations

## Why It Matters for RAG Builders
It provides a modular and extensible framework for integrating AI-powered WeChat bots into workflows, enabling automation and real-time interactions with minimal setup overhead.
