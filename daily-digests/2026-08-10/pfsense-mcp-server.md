## Summary
A Model Context Protocol (MCP) server that enables natural language management of pfSense firewalls through AI assistants like Claude Desktop. It provides 327 tools for firewall, VPN, routing, DNS, and system management with built-in safety guardrails and automatic config backups.

## Key Features
- 327 tools covering firewall, VPN, routing, DNS, DHCP, and system management
- 9-layer safety guardrail system with confirmation gates, rate limiting, and audit logging
- Automatic config backups before destructive operations with rollback support
- Supports multiple authentication methods (Basic Auth, API Key, JWT)
- Wire-format verified against pfSense REST API v2.9.0 for compatibility

## Why It Matters for RAG Builders
It enables AI-driven security automation for pfSense firewalls, reducing manual configuration errors and enabling natural language-based management for security teams.
