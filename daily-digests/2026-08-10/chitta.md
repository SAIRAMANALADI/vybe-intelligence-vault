## Summary
Chitta is a permission-aware memory system for AI agents that combines a knowledge graph and vector memory into a unified MCP server or embeddable SDK. It enables secure, multi-tenant knowledge storage and retrieval with fine-grained access control, ACL filtering, and temporal reasoning capabilities.

## Key Features
- Hybrid memory system combining knowledge graph and vector embeddings with ACL-based access control
- Temporal reasoning and bi-temporal storage for historical context and belief revision
- Self-correcting memory with contradiction detection and confidence-aware updates
- Multi-tenant support with per-user permission filtering across a shared knowledge graph
- MCP server and embeddable SDK with 17+ tool integrations (Claude, Cursor, VS Code, etc.)

## Why It Matters for RAG Builders
Chitta solves the critical challenge of permission-aware knowledge sharing in AI agents, enabling secure, multi-tenant RAG systems where users only access what they're authorized to see while maintaining a unified knowledge graph.
