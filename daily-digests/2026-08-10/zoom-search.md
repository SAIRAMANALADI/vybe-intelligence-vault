## Summary
Zoom Search is an AI agent tool designed to enhance search and evidence gathering for agentic applications. It improves source discovery, traceability, and answer grounding by rewriting search queries, zooming into high-value domains, and returning structured, sourced answers with metrics.

## Key Features
- Agent-ready search tool with structured outputs (sources, warnings, metrics)
- Query rewriting for stronger search variants to improve evidence quality
- Source-domain zoom-in for focused high-value domain discovery
- Traceable outputs with provenance, duplicates, and runtime metrics
- MCP and LangGraph integration for seamless agent workflows

## Why It Matters for RAG Builders
Zoom Search significantly improves the quality and traceability of search results for RAG pipelines by optimizing queries and focusing on high-value sources, reducing hallucinations and improving answer grounding.
