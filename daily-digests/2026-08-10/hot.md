## Summary
Hot Dev is an open-source platform for building backend workflows, AI agents, and service orchestration with a custom language (Hot) and runtime. It provides execution tracing, a local dev runtime, and single-command deploys for scalable, event-driven applications.

## Key Features
- Unified language and runtime for workflows, AI agents, and tasks
- Built-in execution tracing and local development environment
- Support for MCP tools, webhooks, schedules, and long-running tasks
- Single-command deployment to Hot Dev Cloud or self-hosted infrastructure
- Extensible with a standard library and provider integrations

## Why It Matters for RAG Builders
Hot Dev simplifies the orchestration of complex AI workflows and agents, reducing integration overhead for RAG builders by providing a unified runtime and deployment model.
