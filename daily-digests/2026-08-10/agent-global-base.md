## Summary
AGENT-GLOBAL-BASE is a markdown-first, agent-native knowledge base and organizational simulation designed as an LLM engineering laboratory. It provides a governance framework for agent systems, departments, pipelines, and applied LLM research through structured documentation and Python implementations.

## Key Features
- Markdown-first organizational knowledge base with agent profiles and skill specifications
- Agent Systems Engineering (ASE) framework for governance and compliance
- Five-module LLM engineering stack (prompt, context, harness, RAG, multi-agent)
- Structured pipeline definitions for departments and studios (13-stage mobile pipeline)
- Append-only optimization history and canonical source documentation
