## Summary
A shared wire protocol repository for the Cindy client and server, providing TypeScript packages for cross-platform protocol definitions, validation, and runtime contracts. It serves as the single source of truth for shared protocol types and schemas used in desktop, mobile, and server applications.

## Key Features
- Single authoritative source for shared protocol definitions across client and server
- Type-safe TypeScript packages for protocol validation and runtime contracts
- Git submodule integration for seamless dependency management in consuming repositories
- Strict append-only change discipline with versioned protocol updates
- Zero runtime dependencies with platform-specific constraints (e.g., React Native compatibility)
