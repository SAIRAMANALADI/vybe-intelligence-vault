## Summary
A suite of pure-TypeScript, zero-dependency engines for sports betting and DFS applications, providing auditable settlement, odds math, and entertainment scoring. The repository includes core engines, CLI tools, React components, and an MCP server for AI agent integration.

## Key Features
- Pure-TypeScript, zero-dependency core engines for deterministic sports betting and DFS logic
- Auditable settlement with validation reports and audit trails for dispute prevention
- Odds math including no-vig fair lines, parlays, EV, Kelly staking, and period analytics
- Entertainment scoring with ML predictions and personalized game recommendations
- MCP server exposing 11 tools for AI agent integration and deterministic computation
