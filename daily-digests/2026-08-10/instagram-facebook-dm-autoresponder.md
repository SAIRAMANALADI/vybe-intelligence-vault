## Summary
An n8n workflow that automates responses to Instagram and Facebook DMs using an AI agent, logs conversations in Chatwoot, and enables seamless human handoff via Telegram notifications. It integrates Zernio for unified inbox management and OpenAI's gpt-4.1 for AI-driven replies.

## Key Features
- Automated AI responses to Instagram/Facebook DMs using OpenAI gpt-4.1 via LangChain
- Real-time logging of conversations in Chatwoot for visibility and audit trails
- Seamless human handoff with Telegram notifications and Chatwoot integration
- PostgreSQL-backed chat memory for AI agent context retention
- Unified inbox management via Zernio for Instagram and Facebook DMs

## Why It Matters for RAG Builders
It streamlines customer support automation across social platforms while ensuring human oversight and seamless handoffs, reducing response times and improving user experience.
