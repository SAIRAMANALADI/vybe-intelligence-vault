## Summary
robotframework-lynqa is a Robot Framework library that integrates with Lynqa, an AI-powered test execution agent. It enables writing test scenarios in plain Gherkin syntax and automates their execution against web applications without requiring local keyword implementation or test maintenance.

## Key Features
- Write test scenarios in plain Gherkin syntax using Given/When/Then keywords
- Autonomous execution of tests by Lynqa AI agent without local keyword implementation
- Automatic handling of UI changes, reducing test maintenance overhead
- Comprehensive execution evidence and reporting for each test step
- Integration with Lynqa REST API via pylynqa Python client

## Why It Matters for RAG Builders
It streamlines AI-driven test automation by enabling natural-language test scenarios that are autonomously executed, reducing manual effort and maintenance for RAG and AI stack builders.
