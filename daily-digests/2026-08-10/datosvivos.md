## Summary
DatosVivos es un catálogo unificado de 25,226 datasets abiertos de Colombia, actualizado diariamente, que integra fuentes heterogéneas (Socrata, CKAN, DCAT) para ofrecer un panorama en vivo del ecosistema de datos públicos. Incluye herramientas para tomadores de decisiones, ciudadanos y agentes de IA, con funcionalidades como NL2SQL verificado, MCP server para integración con agentes, y tableros interactivos con análisis de frescura y calidad de datos.

## Key Features
- Catálogo consolidado de 25,226 datasets de Colombia con actualización diaria automática
- Motor NL2SQL generativo con verificación determinista de 3 capas para consultas en lenguaje natural
- MCP server que expone herramientas para agentes de IA (Claude, OpenAI, etc.)
- Tableros interactivos con análisis de frescura, acceso y calidad de datos por entidad y territorio
- Integración de múltiples protocolos (Socrata, CKAN, DCAT) y fuentes heterogéneas

## Why It Matters for RAG Builders
Proporciona un catálogo unificado y verificable de datos abiertos colombianos, esencial para construir sistemas RAG con información actualizada y de alta calidad, eliminando barreras técnicas y garantizando respuestas precisas.
