## Summary
TerseSharp is a Roslyn-powered MCP server that enables coding agents to semantically navigate, read, edit, and refactor .NET solutions with minimal token usage. It replaces textual tools like `Read` and `Grep` with precise, compile-aware operations for C# and XAML files.

## Key Features
- Semantic navigation and refactoring of .NET solutions using Roslyn, avoiding textual tools like `Read` and `Grep`
- Compile-gated edits and renames to prevent introducing errors, with rollback on failure
- Type-checked XAML bindings for WPF, Avalonia, WinUI, and MAUI, ensuring consistency between C# and markup
- Parallel worktrees for handling multiple workspaces and ambiguous queries
- Hard enforcement hooks to block built-in tools for C#/.NET files, ensuring agents use TerseSharp exclusively

## Why It Matters for RAG Builders
TerseSharp drastically reduces token usage and improves accuracy for RAG/AI agents working with .NET codebases by providing semantic, compile-aware tools that replace inefficient textual operations.
