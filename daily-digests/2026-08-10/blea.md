## Summary
BLEA is a universal Agent Plugin for safe, deterministic Bluetooth Low Energy (BLE) automation, providing AI agents with portable skills, a machine-readable CLI, and a local MCP server for BLE diagnostics and state management.

## Key Features
- Portable Agent Plugin with MCP and Skill integration for AI agents
- Deterministic CLI with JSON/JSONL output for scripting and automation
- Local MCP server exposing structured BLE tools with managed sessions
- Evidence capture, diff, and replay for offline debugging and CI validation
- Guarded writes and exchange workflows with explicit authorization and safety checks

## Why It Matters for RAG Builders
BLEA provides essential tools for AI agents to safely interact with BLE devices, enabling deterministic diagnostics, state management, and offline validation critical for RAG and automation workflows.
