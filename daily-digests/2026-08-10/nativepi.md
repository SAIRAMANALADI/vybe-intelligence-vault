## Summary
NativePi is a cross-platform desktop application that provides a graphical interface for the Pi coding agent, enabling users to manage projects, conversations, and extensions locally on Windows, macOS, and Linux without cloud dependencies.

## Key Features
- Integrates with Pi coding agent via JSON RPC for seamless agent loop control
- Supports graphical extensions with React-based rendering and custom UI components
- Provides local project and session management with Git integration and diff visualization
- Enables remote access via secure tunnels for mobile or secondary device interaction
- Offers model and tool configuration without requiring cloud storage or telemetry

## Why It Matters for RAG Builders
NativePi enhances the Pi coding agent by providing a native desktop interface that simplifies project and session management while preserving the agent's core functionality and extensibility.
