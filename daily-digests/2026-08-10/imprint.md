## Summary
Imprint is a tool that records real browser sessions to generate deterministic MCP (Model Context Protocol) tools for AI agents. It eliminates runtime token costs and exploration variability by compiling recorded workflows into executable tools that agents can call reliably.

## Key Features
- Records real browser sessions to generate deterministic MCP tools
- Supports multiple backend ladders (API, DOM, stealth-fetch, CDP-replay) for reliability
- Automatically redacts credentials and PII during compilation
- Integrates with popular AI platforms (Claude, Codex, Hermes)
- Provides live verification and backend probing for bot-protected sites

## Why It Matters for RAG Builders
Imprint enables AI agents to execute complex browser workflows deterministically without burning tokens or risking exploration failures, making it essential for building reliable RAG systems that interact with dynamic web interfaces.
