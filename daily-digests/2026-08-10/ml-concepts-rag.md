## Summary
An end-to-end RAG application that answers machine learning questions using a curated Wikipedia knowledge base, providing source-backed explanations and Mermaid concept maps. It automates data ingestion, retrieval, and monitoring with a focus on educational clarity and reproducibility.

## Key Features
- Automated Wikipedia data ingestion and embedding with Prefect workflows
- Hybrid retrieval combining vector search and cross-encoder re-ranking
- Source-backed answers with expandable citations and Mermaid concept maps
- Comprehensive monitoring with Supabase and Grafana dashboards
- Dual LLM provider fallback (Groq/Llama-3.1-8b and OpenAI/GPT-4o-mini)
