## Summary
PHANTOM is an autonomous AI assistant designed for penetration testing, security research, and general-purpose tasks. It enables real-time tool execution, unbounded agent loops, and persistent context with a self-improving AI backend and a dark-themed UI.

## Key Features
- Zero-config tool execution with automatic dependency installation
- Unlimited autonomous agent loops with recursive tool calls
- Persistent SQLite memory store for long-term context retention
- Multi-agent defense system with planner, orchestrator, and specialist agents
- Native Model Context Protocol (MCP) server integration for typed JSON schemas

## Why It Matters for RAG Builders
PHANTOM provides a robust framework for building autonomous AI agents capable of complex, multi-step security operations with persistent memory and real-time tool execution, making it ideal for RAG builders seeking advanced agentic workflows.
