## Summary
The Carbone MCP Server is an official Model Context Protocol (MCP) server that enables AI assistants to generate, convert, and manage documents dynamically. It supports 100+ formats, template-based document generation, batch processing, and advanced PDF customization.

## Key Features
- Supports 100+ document formats (PDF, DOCX, XLSX, PNG, HTML, CSV, etc.)
- Template-based document generation with JSON data merging
- Batch document generation with async processing via webhooks
- Advanced PDF customization (watermarks, passwords, encryption, multi-engine support)
- Multi-language and localization support with currency/timezone handling

## Why It Matters for RAG Builders
It bridges AI assistants with robust document automation, enabling seamless generation and conversion of professional documents at scale for RAG and AI workflows.
