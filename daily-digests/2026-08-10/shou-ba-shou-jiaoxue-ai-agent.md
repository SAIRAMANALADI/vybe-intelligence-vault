## Summary
A production-grade AI AgentOps framework and educational project that guides users from zero to a deployable AI agent system with Harbor AgentOps 3.2. It emphasizes deterministic workflows, tenant-bound security, and sealed fault testing with real-time RAG and approval gates.

## Key Features
- State-machine-driven agent execution with checkpointing and recovery
- Tenant-bound four-eyes approval and capability-based tool governance
- Sealed fault lab for reproducible incident simulation and validation
- Hybrid RAG pipeline combining BM25, Qwen3 Embedding, and adaptive RRF
- Deterministic policy compiler for plan IR with risk-aware execution

## Why It Matters for RAG Builders
It provides a production-ready framework for building secure, auditable, and recoverable AI agents with rigorous RAG and approval workflows essential for enterprise AI deployments.
