## Summary
A remote Model Context Protocol (MCP) server for searching and booking mountain holiday rentals in France, connecting travelers directly with property owners without commissions. It provides tools for multi-criteria searches, availability checks, and owner inquiries.

## Key Features
- Multi-criteria rental search (destination, dates, budget, amenities)
- Real-time availability and pricing checks for specific dates
- Direct owner contact via inquiry system with user consent
- Public, rate-limited access without authentication
- Integration with AI assistants via MCP for seamless booking workflows

## Why It Matters for RAG Builders
It enables AI assistants to directly query and interact with a specialized vacation rental database, streamlining the booking process for users without requiring manual navigation through third-party platforms.
