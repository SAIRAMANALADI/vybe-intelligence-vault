## Summary
mctl-api is a dual-protocol (REST + MCP) control plane API for the mctl.ai Internal Developer Platform, enabling management of services, workspaces, databases, and platform operations. It serves as a central gateway for AI coding assistants, Backstage, and CLI tools.

## Key Features
- Dual-protocol access (REST + MCP) for AI assistants and traditional tools
- GitOps-driven deployments via ArgoCD and Argo Workflows
- Multi-authentication support (GitHub, OIDC, OAuth 2.0 PKCE)
- Comprehensive audit logging with PostgreSQL backend
- Built-in rate limiting and OpenAPI documentation

## Why It Matters for RAG Builders
It provides a unified control plane for managing AI-driven development workflows, enabling seamless integration with AI assistants and GitOps-based deployments.
