## Summary
Yunspire is a local-first, self-growing knowledge hub for individuals that integrates a controlled Agent runtime with Obsidian Vaults for durable knowledge storage and SQLite for runtime state management. It enables AI-assisted workflows for conversation, search, content creation, task automation, and knowledge maintenance while enforcing strict security and data ownership boundaries.

## Key Features
- Controlled Agent runtime with deterministic task execution and verification
- Obsidian Vault as the authoritative source for knowledge storage and retrieval
- Hybrid search combining FTS, local vector embeddings, and optional neural embeddings with RRF fusion
- Multi-vendor model routing with strict policy enforcement and budget controls
- Secure, isolated media processing for PDFs, images, videos, and Office documents

## Why It Matters for RAG Builders
Yunspire provides a robust, local-first framework for building secure, traceable AI agents that integrate deeply with personal knowledge systems like Obsidian, making it essential for RAG builders prioritizing data ownership and controlled execution environments.
