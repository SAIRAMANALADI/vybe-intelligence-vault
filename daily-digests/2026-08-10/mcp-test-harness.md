## Summary
A pytest-style testing framework designed for Model Context Protocol (MCP) servers, enabling automated validation of correctness, performance, and security for AI agent connectors. It replaces manual MCP Inspector testing with deterministic, code-first CI gates.

## Key Features
- Automated MCP server testing with pytest-style assertions and fixtures
- Support for stateful and stateless (SEP-2575) MCP server validation
- Comprehensive reporting (JUnit, SARIF, HTML, JSON) for CI/CD integration
- Chaos testing and resiliency experiments for hardened server validation
- GitHub Action and Docker container support for seamless CI deployment

## Why It Matters for RAG Builders
It provides a critical CI gate for validating MCP servers, ensuring AI agent connectors are correct, performant, and secure before deployment.
