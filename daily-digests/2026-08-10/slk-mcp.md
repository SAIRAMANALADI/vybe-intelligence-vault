## Summary
slk-mcp is a Slack MCP server that integrates with AI coding assistants like Claude Code, GitHub Copilot, and Cursor to provide Slack workspace interactions. It enables features such as morning recaps, unread summaries, mentions tracking, decision detection, message search, and voice message transcription.

## Key Features
- Morning recaps and unread summaries across Slack channels
- Decision detection and message search capabilities
- Voice message transcription via whisper.cpp integration
- Multi-workspace support with configurable tokens
- Compact digest generation for efficient information retrieval

## Why It Matters for RAG Builders
