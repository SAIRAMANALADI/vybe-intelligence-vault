## Summary
A browser extension that captures entire web pages as high-resolution PDFs directly on the user's device, supporting both desktop and Android. It auto-scrolls pages, handles lazy-loaded content, and preserves searchable text for OCR or AI processing without requiring uploads or accounts.

## Key Features
- Full-page PDF capture with auto-scroll for lazy-loaded content
- Local processing with no data collection or uploads
- Preserves searchable text and citation metadata for AI/OCR pipelines
- Supports headless installation and automation for AI agents
- Privacy-compliant with minimal permissions (no <all_urls> access)
