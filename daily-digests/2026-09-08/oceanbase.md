## Summary
OceanBase Database is a distributed relational database developed by Ant Group, designed for high availability, linear scalability, and cost efficiency. It supports hybrid transactional/analytical processing (HTAP) and is compatible with MySQL, making it suitable for large-scale enterprise workloads.

## Key Features
- Supports transparent scalability with up to 1,500 nodes, PB-scale data, and trillions of rows in a single cluster
- Delivers ultra-fast performance with TPC-C 707 million tmpC and TPC-H 15.26 million QphH @30000GB benchmarks
- Enables real-time analytics with built-in HTAP capabilities without additional cost
- Provides continuous availability with RPO=0 (zero data loss) and RTO < 8 seconds
- Offers MySQL compatibility for seamless migration and integration
