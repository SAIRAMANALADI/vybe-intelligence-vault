## Summary
Pepe is an Elixir/OTP-based AI agent runtime that enables users to define agents, connect to any OpenAI-compatible model, and execute tool-calling loops with built-in supervision for fault isolation. It supports multiple interfaces including HTTP, WebSocket, CLI, Telegram, and WhatsApp.

## Key Features
- Lightweight process-per-conversation architecture with OTP supervision for fault isolation
- Supports any OpenAI-compatible model provider (OpenAI, OpenRouter, Groq, Ollama, etc.) with zero code changes
- Multiple interaction surfaces: HTTP API, WebSocket, CLI, Telegram, WhatsApp, and web dashboard
- Built-in tool-calling loop with configurable agents, skills, and permissions
- Self-contained binary deployment with no runtime dependencies

## Why It Matters for RAG Builders
Pepe provides a robust, fault-tolerant runtime for deploying AI agents with tool-calling capabilities, making it ideal for production-grade RAG systems that require multi-channel access and high availability.
