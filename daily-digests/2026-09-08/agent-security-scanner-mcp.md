## Summary
A security scanner designed to audit AI agents and MCP servers for vulnerabilities, package hallucinations, prompt injections, and supply chain risks. It provides CLI tools, AST/taint analysis, and LLM-powered semantic reviews to ensure safe AI agent operations.

## Key Features
- AST and taint analysis for deep code vulnerability detection across 12 languages
- Package hallucination detection using a 4.3M+ package registry (zero false positives)
- LLM-powered semantic code review with intent profiling for context-aware security
- Prompt injection and jailbreak detection with 59+ rules and multi-encoding bypass hardening
- Compliance evaluation against SOC2, GDPR, and other frameworks with evidence collection
