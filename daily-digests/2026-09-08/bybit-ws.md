## Summary
An AI-native trading engine for Bybit that implements a Bollinger Grid strategy with auto-entries, ATR-adaptive stop-loss/take-profit, trailing stops, DCA, self-learning, and post-trade cluster analysis. Includes an MCP server for AI agents and supports Telegram/ntfy alerts.

## Key Features
- Bollinger Grid strategy with auto-entries for LONG/SHORT/JUNK tiers
- ATR-adaptive stop-loss/take-profit and trailing stops
- Self-learning and post-trade cluster analysis for risk management
- MCP server for direct integration with AI agents (Claude, Codex, etc.)
- Telegram/ntfy alerts and Prometheus metrics for monitoring
