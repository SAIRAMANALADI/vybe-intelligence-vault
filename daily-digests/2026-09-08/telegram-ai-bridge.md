## Summary
A self-hosted, always-on bridge enabling heterogeneous AI agents (Claude Code, Codex, Gemini) to collaborate in Telegram groups via the A2A-TG protocol. Features shared memory, loop suppression, and real-time bidirectional media exchange for parallel agent workflows.

## Key Features
- Heterogeneous AI agent coordination via A2A-TG protocol with generation-counted loop guards
- Parallel agent sessions with shared memory (SQLite/Redis) for unified context
- Bidirectional media exchange (screenshots, files, code outputs) between agents and Telegram
- Production-grade reliability with rate limiting, retry logic, and graceful shutdown
- Owner-gated, always-on deployment with phone-first control via Telegram

## Why It Matters for RAG Builders
It enables seamless, real-time collaboration between multiple AI agents in a single interface, reducing terminal dependency and streamlining complex workflows for developers.
