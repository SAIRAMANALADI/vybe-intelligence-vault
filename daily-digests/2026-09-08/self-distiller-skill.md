## Summary
self-distiller-skill is a Windows application that enables users to transform their self-talk into an AI persona for reflection, emotion tracking, and cognitive defusion. It supports both text and voice modes, allowing users to interact with their own thoughts in a structured, distanced manner.

## Key Features
- Text mode for typed self-reflection and chat analysis
- Voice mode with cloned voice for immersive interaction
- Daily mirror practice and thought journaling capabilities
- Supports ACT therapy and cognitive defusion exercises
- Local Windows application with no cloud dependency
