## Summary
A structured agent skill package for researchers that decomposes core research competencies into 10 trainable skills and 1 role, based on the principles from 'How to Be Good at Research'. It provides executable workflows, templates, and memory systems to automate and optimize research processes.

## Key Features
- 10 modular, trainable research skills (e.g., problem selection, literature deep-reading, experiment design) with predefined time-boxed workflows
- Automated memory system with structured templates for research logs, project context, and failure analysis
- Interactive initialization for customizing research profiles (e.g., domain, style, tools)
- Integration with Claude Code for natural language triggering of skills via role-based or keyword-based invocation
- Fixed rituals and workflows (e.g., daily paper reading, failure autopsies, taste training) to enforce disciplined research habits

## Why It Matters for RAG Builders
It provides a systematic, agent-driven framework to automate and optimize core research workflows, reducing cognitive load and improving reproducibility for AI engineers building RAG systems.
