## Summary
An MCP (Model Context Protocol) server providing real-time cryptocurrency data, portfolio tools, and calculators for AI agents. It offers live prices, conversions, gas tracking, and portfolio valuation without requiring API keys by default.

## Key Features
- Live cryptocurrency prices with market cap, volume, and rank from CoinGecko
- Portfolio valuation and profit/loss calculations with fee support
- EVM gas tracking with USD transfer cost estimates
- Zero-config setup with optional API key support for higher limits
- Supports stdio, HTTP, and MCP registry deployments
