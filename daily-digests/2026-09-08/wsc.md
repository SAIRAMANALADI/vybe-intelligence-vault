## Summary
A prose linter and AI-slop detector that identifies overrepresented words, phrases, and sentence structures in AI-generated text, along with classic writing issues. It offers multiple interfaces including a web editor, HTTP API, MCP server, CLI, and GitHub Action.

## Key Features
- Detects 8 types of writing issues including AI tells, weasel words, passive voice, and nominalizations with research-backed word lists
- Multiple interfaces: web editor, HTTP API, MCP server (local/remote), CLI, and GitHub Action
- Configurable via `.wscrc.json` with JSON Schema support for autocompletion
- Privacy-focused: web editor runs in-browser; no text sent to servers unless explicitly using API/MCP
- Extensive testing suite with 341 tests across 18 files

## Why It Matters for RAG Builders
It provides a reliable, research-backed way to detect AI-generated text patterns and improve writing quality, which is critical for maintaining authenticity and clarity in AI-assisted content pipelines.
