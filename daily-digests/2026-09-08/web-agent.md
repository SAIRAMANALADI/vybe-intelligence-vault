## Summary
An autonomous vision-language web agent that interprets natural-language instructions to drive a real Chromium browser, perform web searches, navigate pages, read and interpret PDFs, analyze figures, and generate cited reports. It combines Vision-Language Models with DOM snapshots to autonomously execute multi-step web tasks.

## Key Features
- Autonomous browser navigation and interaction with structured DOM and screenshot observations
- Vision-Language Model integration for multimodal planning and figure analysis
- Robust document intelligence pipeline for PDF parsing, figure resolution, and OCR cascades
- Model-agnostic planner supporting OpenAI-compatible endpoints with automatic vision detection
- Comprehensive robustness engineering with loop detection, timeouts, checkpointing, and failure handling

## Why It Matters for RAG Builders
It enables AI systems to autonomously perform complex web-based tasks, extract and interpret structured data from PDFs and figures, and generate cited reports, which is critical for building advanced RAG pipelines that require real-world web interaction and document understanding.
