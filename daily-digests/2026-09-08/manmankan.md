## Summary
A local-first A-share stock observation tool for retail investors that provides data-driven insights without offering financial advice. It aggregates stock positions, key price levels, and market data into a single, auditable interface for both human users and AI agents.

## Key Features
- Provides auditable stock data (positions, key levels, market snapshots) without financial advice or recommendations
- Offers both Web UI and CLI/JSON/MCP interfaces for human and AI consumption
- Supports local data storage with strict privacy controls (no telemetry, no cloud sync)
- Includes dry-run and schema discovery for AI agents to plan queries before fetching data
- Designed for extensibility to multiple markets (A-share focus currently)

## Why It Matters for RAG Builders
It provides a privacy-preserving, auditable data layer for AI agents to analyze A-share stocks without exposing sensitive user inputs or making financial decisions.
