## Summary
A Hermes-first AI virtual entertainment company runtime that orchestrates Discord-based AI agents (e.g., CEO, team leads) to automate meetings, tasks, and reporting within a structured company workflow. Implements a MeetingRun-centric runtime architecture v2 with validation, scheduling, and projection layers.

## Key Features
- MeetingRun-centric runtime architecture v2 with 29-role org chart registry
- GLM/Codex-based validation and auditing for decision-making
- Discord-safe projection layer for real-time agent interactions
- Phase-gated implementation with deterministic orchestration and live smoke testing
- Persistent Second Brain knowledge loop for long-term memory and context
