## Summary
Mantic.sh is a context-aware code search engine designed to prioritize relevance over raw speed, enabling AI agents and developers to find code with high accuracy using semantic and structural analysis. It supports advanced features like go-to-definition, find-references, and learned context caching.

## Key Features
- Hybrid intelligence search combining heuristic and neural reranking for superior relevance
- Go-to-definition and find-references capabilities across entire monorepos
- Learned context caching for adaptive ranking and team knowledge sharing
- Zero-query mode for proactive context generation and impact analysis
- Local-first privacy with zero data egress, optimized for AI agent workflows

## Why It Matters for RAG Builders
Mantic.sh is essential for RAG builders as it drastically reduces context retrieval overhead by filtering irrelevant files and prioritizing structural relevance, enabling faster and more accurate AI agent responses.
