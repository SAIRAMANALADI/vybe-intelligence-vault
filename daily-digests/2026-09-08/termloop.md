## Summary
TermLoop is a minimal Telegram bot and MCP server for spaced repetition of professional terminology, helping users reinforce vocabulary through self-assessment and priority-based review scheduling. It enables adding terms directly from LLM conversations via an MCP endpoint.

## Key Features
- Personalized spaced repetition with priority-based review scheduling
- Telegram bot for interactive term recall and self-assessment
- MCP server for seamless term addition from LLM conversations
- Deterministic priority math and state machine for review flow management
- Lightweight, self-contained deployment with SQLite and Docker

## Why It Matters for RAG Builders
TermLoop streamlines vocabulary reinforcement for AI engineers by integrating spaced repetition with LLM workflows, reducing cognitive load during technical discussions.
