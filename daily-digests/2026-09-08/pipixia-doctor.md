## Summary
PipiXia Doctor is an AI agent health diagnostics and self-healing toolkit designed to monitor, diagnose, and repair AI agents through automated checks, prescription matching, and snapshot-based recovery. It supports agent state archiving, feedback-driven learning, and convergence gate validation for robust AI system maintenance.

## Key Features
- Automated agent health checks with deep diagnostics (system load, heartbeat, memory, skills integrity)
- Prescription engine for matching issues with 90+ predefined solutions and feedback-driven learning
- Agent state snapshotting and recovery with SHA-256 verification and dry-run support
- Convergence gate validation for product consistency and clean-clone verification
- Unified CLI with 11+ commands for check, test, snapshot, and learning workflows
