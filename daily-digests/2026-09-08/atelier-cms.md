## Summary
Atelier is an AI-native, self-hosted CMS built on Drupal that enables users to manage website content entirely through natural language commands. It combines a conversational AI operator console with static site export capabilities for flexible deployment.

## Key Features
- AI-driven content management via natural language commands
- Built-in AI provider integration (Anthropic, OpenAI, Ollama)
- Static site export for deployment flexibility (Netlify, Cloudflare, Vercel, etc.)
- Self-contained appliance with automated updates and rollback
- Drupal-powered backend with curated, opinionated defaults

## Why It Matters for RAG Builders
Atelier bridges the gap between AI-driven content creation and traditional CMS workflows, enabling RAG builders to integrate conversational interfaces with structured content management.
