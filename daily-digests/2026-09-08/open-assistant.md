## Summary
A self-hosted multi-agent personal assistant system that integrates with productivity tools like email, files, calendars, and notes through natural conversations. It uses a modular architecture with 9 specialized agents and 88+ tools to manage daily tasks autonomously.

## Key Features
- Integrates with 8+ productivity tools (Gmail, Outlook, Notion, Nextcloud, WhatsApp, etc.) via modular agents
- Supports 88+ callable tools for task automation and data retrieval
- Privacy-focused with single-user, self-hosted deployment in a single Docker container
- Advanced features like cron jobs, conversation memory, and automated personality shaping
- Comprehensive monitoring, audit logging, and health checks for observability
