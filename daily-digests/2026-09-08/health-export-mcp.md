## Summary
An open-source, zero-dependency MCP server that enables AI agents to query Apple Health/HealthKit data in natural language. It provides 190 metrics as clean JSON for local-first, read-only access to health data via MCP-compatible clients or webhooks.

## Key Features
- Zero-dependency, local-first MCP server for Apple Health data access
- Supports 190+ metrics including HRV, sleep, resting heart rate, workouts, and VO₂ max
- Integrates with MCP-compatible AI agents (Claude, Cursor, ChatGPT, OpenClaw, Hermes)
- Read-only, privacy-focused with optional pairing for access control
- Provides 7 MCP tools for querying, comparing, and exporting health data in natural language

## Why It Matters for RAG Builders
It enables AI agents to directly access real-time, personalized health data for personalized insights, coaching, and analysis without relying on cloud services or stale data exports.
