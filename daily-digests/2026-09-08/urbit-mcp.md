## Summary
A Model Context Protocol (MCP) interface for Urbit, enabling LLMs to interact with Urbit ships as MCP servers. It facilitates tool execution, resource access, and slash commands for AI agents running on Urbit.

## Key Features
- Enables MCP server functionality on Urbit ships for AI agent interaction
- Supports tool execution, resource access, and slash commands via MCP
- Integrates with Codex, Claude Code, and Opencode for AI-driven Urbit interactions
- Provides authentication and session management for secure MCP server access
- Supports dynamic addition of tools, prompts, and resources via AI requests

## Why It Matters for RAG Builders
It bridges Urbit's decentralized computing platform with MCP-enabled AI agents, enabling secure and extensible tool integration for RAG systems.
