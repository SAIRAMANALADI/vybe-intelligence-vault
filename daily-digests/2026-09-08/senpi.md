## Summary
senpi is an opinionated TypeScript monorepo fork of pi-mono, designed as a lightweight coding-agent runtime for AI assistants like Dori. It extends upstream with built-in extensions, dynamic prompts, and model-specific presets while maintaining compatibility with the pi ecosystem.

## Key Features
- Dynamic intent-gate system for forced prompt validation before tool use
- Built-in extensions for model-specific presets (GPT-5, Claude Opus, Kimi K2.6)
- Modular permission system with allow/deny rules and TUI prompts
- Adaptive context compaction for session recovery and memory management
- Seamless integration with upstream pi-mono and extensible via `senpi install`

## Why It Matters for RAG Builders
senpi provides a lightweight, opinionated foundation for building AI coding agents with pre-configured extensions and dynamic prompts, reducing setup complexity for RAG/AI stack builders.
