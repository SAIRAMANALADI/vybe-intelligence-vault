## Summary
PC Build Agent is an AI-powered tool that generates custom PC build configurations based on user-provided budget and use-case requirements, returning detailed parts lists with pricing and compatibility checks via a FastAPI interface.

## Key Features
- Generates multi-tier PC build plans based on budget and use-case
- Provides real-time pricing and historical price data for parts
- Includes compatibility checks and upgrade path suggestions
- Supports tool-calling LLMs for dynamic part selection
- Delivers structured responses with budget status and warnings
