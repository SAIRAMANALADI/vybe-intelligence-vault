## Summary
MudrikNow is an open-source Windows AI assistant that captures and interprets on-screen UI elements to enable real-time interaction, guidance, and task automation via natural language commands or predefined actions.

## Key Features
- Real-time UI element scanning and interpretation via Windows UI Automation
- Context-aware AI actions including typing, clicking, and keyboard shortcuts
- Auto-Guide mode with an interactive owl cursor for step-by-step task guidance
- Sandboxed AI capabilities with no shell or filesystem write access
- Support for 140+ LLM providers via OpenCode and models.dev

## Why It Matters for RAG Builders
MudrikNow enables AI agents to interact directly with desktop applications, bridging the gap between AI capabilities and real-world user interfaces for seamless task automation and guidance.
