## Summary
Tabductor enables AI agents to interact with a user's Chrome browser session via an MCP server, allowing local control of tabs, sessions, and browsing activities through standard input/output communication.

## Key Features
- Enables AI agents to control Chrome via local stdio MCP server
- Leverages Chrome DevTools Protocol for real-time session interaction
- Lightweight and designed for integration with AI workflows
- Supports tab management, session access, and browsing actions
- Open-source and extensible for custom use cases
