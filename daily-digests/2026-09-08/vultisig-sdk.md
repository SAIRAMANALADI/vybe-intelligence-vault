## Summary
The Vultisig SDK provides a self-custodial multi-chain wallet solution designed for AI agents and developers, enabling secure cross-chain transactions, swaps, and portfolio management across 40+ blockchains using MPC (Multi-Party Computation) security without seed phrases.

## Key Features
- Supports 40+ blockchains with human-readable transaction amounts and portfolio tracking
- MPC security with two vault types: Fast Vault (2-of-2) and Secure Vault (N-of-M threshold signing)
- Built-in cross-chain swaps via THORChain, 1inch, KyberSwap, and LiFi with automatic routing
- Dry-run mode for previewing fees and transaction outcomes before execution
- Programmatic SDK and CLI for AI agents, bots, and developers with TypeScript support and JSON output

## Why It Matters for RAG Builders
It enables AI agents and developers to securely manage multi-chain assets and execute transactions without exposing private keys, reducing security risks in automated workflows.
