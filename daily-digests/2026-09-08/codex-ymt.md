## Summary
Codex YMT is a Codex plugin and local MCP server that enables YouTube metadata localization by translating video titles and descriptions into multiple languages via Codex. It ensures safe, reviewable updates through Google OAuth and YouTube Data API v3 integration.

## Key Features
- Translates YouTube titles and descriptions into multiple languages using Codex
- Provides safe, reviewable updates with explicit approval before publishing
- Preserves existing localizations and prevents stale updates
- Supports per-channel translation instructions and draft restoration
- Uses Google OAuth for secure, user-controlled API access

## Why It Matters for RAG Builders
It streamlines multilingual YouTube content management for creators, ensuring accurate and safe metadata localization without requiring separate translation APIs.
