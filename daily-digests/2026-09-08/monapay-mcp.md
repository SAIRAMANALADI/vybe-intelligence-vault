## Summary
monapay-mcp is an MCP (Model Context Protocol) server for MONA Pay, a Vietnamese payment gateway API. It enables AI agents and developers to interact with MONA Pay's services (e.g., VietQR, webhooks, virtual accounts) directly within their IDEs like Claude Code or Cursor, streamlining payment integration and transaction monitoring.

## Key Features
- Direct IDE integration via MCP for real-time payment and transaction management
- Supports VietQR, virtual accounts (VA), webhooks, Telegram, and email notifications
- Toolset for creating checkouts, generating QR codes, verifying webhook signatures, and managing bank accounts
- Sandbox mode for testing transactions without real money transfers
- Comprehensive documentation and code snippets for quick integration

## Why It Matters for RAG Builders
It simplifies payment integration for AI agents and developers by providing an MCP server for MONA Pay, reducing setup time and enabling seamless real-time transaction monitoring.
