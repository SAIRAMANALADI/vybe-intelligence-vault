## Summary
Nocturne is a privacy-focused, offline voice dictation application for macOS that converts spoken words into typed text using local AI models. It leverages Apple's Neural Engine and CoreML for fast, private speech-to-text transcription without cloud dependency.

## Key Features
- Runs entirely on-device with no internet required
- Supports 12 languages with local AI models
- Integrates with Ollama for local text polishing
- Custom dictionary and snippets for personalized dictation
- Privacy-focused with no data collection or cloud processing
