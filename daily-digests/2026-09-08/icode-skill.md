## Summary
ICode is a Claude Code Skill that implements a structured 6-step end-to-end coding workflow (Plan → Review → Finalize → Code → Deep Check → Audit) with quality gates, adversarial review, cross-project memory, and crash recovery. It enables model switching between steps and supports cost-efficient trimmed workflows.

## Key Features
- Closed-loop 6-step coding workflow with optional step-by-step execution
- Adversarial review and anti-laziness quality gates (27 rules)
- Cross-project history retrieval with verdict-based anti-misleading injection
- Project-level knowledge base generation and auto-injection
- Resumable runs and crash recovery via `.ico_metadata.json`
