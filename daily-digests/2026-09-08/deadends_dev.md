## Summary
deadends.dev is a structured failure knowledge infrastructure that provides deterministic, country-scoped dead ends and workarounds for AI agents, covering both code errors and real-world country-specific rules to prevent hallucinations and incorrect advice.

## Key Features
- Prevents AI agents from repeating known failures in code and real-world scenarios with 90% Precision@1
- Provides country-specific dead ends (visa rules, legal taboos, cultural norms) via ISO country codes
- Deterministic, hallucination-free responses with primary-sourced data and community-validated success rates
- Supports MCP servers, Python SDK, and API endpoints for seamless integration with AI agents
- Includes error transition graphs to handle cascading failures (e.g., error A leads to error B 78% of the time)

## Why It Matters for RAG Builders
It eliminates AI agent hallucinations by providing deterministic, country-specific failure knowledge, ensuring agents avoid repeating known errors and giving culturally appropriate advice.
