## Summary
gori is a fast, keyboard-driven HTTP intercepting proxy and security toolkit designed for terminal use. It captures, intercepts, replays, and analyzes HTTP/1.1, HTTP/2, WebSocket, gRPC, and SSE traffic, offering features like fuzzing, decoding, and vulnerability scanning.

## Key Features
- Captures and intercepts HTTP/1.1, HTTP/2, WebSocket, gRPC, and SSE traffic in real-time
- Provides a TUI, CLI (`gori run`), and MCP server for AI agents to interact with captured traffic
- Includes fuzzing, decoding, vulnerability scanning, and session token analysis tools
- Supports searchable history, replay, and side-by-side comparison of HTTP flows
- Offers keyboard-first workflow with customizable hotkeys and themes

## Why It Matters for RAG Builders
gori enables AI agents to dynamically capture, analyze, and manipulate HTTP traffic, making it essential for testing and improving RAG systems that rely on real-world web interactions.
