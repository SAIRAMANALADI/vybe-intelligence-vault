## Summary
A Model Context Protocol (MCP) server providing 9 specialized tools for quantitative finance, including stock analysis, options analytics, implied volatility radar, Monte Carlo simulations, AI prediction signals, pre-trade risk scanning, research reports, and chart visualization. Designed for AI agents and quant developers to integrate market data analysis into workflows.

## Key Features
- 9 integrated tools for stock and options analysis, including implied volatility radar, Monte Carlo simulations, and AI-driven predictions
- Supports both remote and self-hosted MCP deployments with Python SDK compatibility
- Provides pre-trade risk scanning, research report generation, and chart visualization for market data insights
- Tiered access control with rate limiting for freemium users and bearer token authentication
- Designed for seamless integration with AI agents (Claude, Cursor, ChatGPT) via MCP protocol
