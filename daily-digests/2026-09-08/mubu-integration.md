## Summary
mubu-integration transforms Mubu (幕布), a popular outlining tool, into a Markdown-native, AI-agent-controllable outliner with lossless round-trip import/export. It enables command-line and programmatic control of Mubu documents, making it ideal for AI memory systems and knowledge base synchronization.

## Key Features
- Lossless Markdown ↔ Mubu document round-trip conversion preserving headings, checkboxes, and notes
- Command-line and AI-agent controllable interface for managing Mubu outlines
- OPML and FreeMind export for compatibility with other outlining tools
- Automatic token refresh and local credential storage with secure permissions
- 115+ automated tests across multiple Python versions with CI/CD verification

## Why It Matters for RAG Builders
It enables AI agents to directly read and write structured Mubu outlines as Markdown, bridging the gap between outlining tools and AI memory systems for seamless knowledge management.
