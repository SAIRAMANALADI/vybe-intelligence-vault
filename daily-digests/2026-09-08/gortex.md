## Summary
Gortex is a high-performance code-intelligence engine that indexes code into a graph database and exposes it via CLI, MCP Server, and web UI. It enables AI agents and IDEs to query code contextually with up to 50x fewer tokens by leveraging graph-native lookups and cross-repository analysis.

## Key Features
- Graph-based code indexing with 257 language/grammar support
- Cross-repository API contract detection and resolution
- Up to 50x token reduction for AI agent responses via graph-native queries
- Multi-agent integration (19+ coding assistants) with zero-config setup
- Semantic search with embedded embeddings and vector/BM25 fusion

## Why It Matters for RAG Builders
Gortex enables AI agents to query code contextually with minimal token usage, reducing noise and improving accuracy in RAG pipelines by leveraging graph-based knowledge instead of raw file reads.
