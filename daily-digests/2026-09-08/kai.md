## Summary
Kai is a local, multi-client personal engineering system that acts as a persistent AI collaborator with repo-aware coding, memory, scheduling, PR review, and multi-backend operation. It runs on user-controlled hardware, supports multiple client interfaces (Workshop browser and Telegram), and provides durable agent sessions with isolated multi-user operation.

## Key Features
- Local-first operation with full filesystem and shell access for agent execution
- Multi-client support via Workshop browser and Telegram with isolated user sessions
- Durable memory and context preservation across restarts and workspace switches
- Multi-backend agent harnesses (Claude Code, OpenAI Codex, Goose, OpenCode, Pi) with normalized routing
- Background automation for PR review, issue triage, scheduling, and webhook-driven workflows

## Why It Matters for RAG Builders
Kai provides a robust, local-first orchestrator for AI agents that enables persistent, repo-aware coding assistants with multi-backend flexibility and secure multi-user isolation, making it essential for building scalable, production-grade RAG systems.
