## Summary
Airstrings-cli is a command-line interface for managing application strings, locales, and bundles via the AirStrings platform. It enables local-first string management, offline-safe publishing, and AI-assisted localization workflows through an MCP server integration.

## Key Features
- Local-first string management with CSV-based workspaces for offline editing
- Offline-safe bundle publishing with Ed25519 signature verification for immutable delivery artifacts
- MCP server integration for AI-assisted string management and localization workflows
- Project-specific workspace configuration with environment switching and credential management
- Machine-readable JSON output for programmatic integration and automation

## Why It Matters for RAG Builders
It streamlines localization workflows for AI and RAG applications by enabling offline string management, secure bundle distribution, and AI-driven string updates via MCP tools.
