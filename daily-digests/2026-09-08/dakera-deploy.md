## Summary
Dakera-deploy provides production-ready infrastructure for deploying the Dakera memory platform, enabling AI agents to store and retrieve persistent, session-aware memory across Docker, Kubernetes, or Helm environments. It supports hybrid retrieval, knowledge graphs, and session management with built-in embeddings.

## Key Features
- Supports multi-format deployment (Docker, Kubernetes, Helm) with HA and monitoring profiles
- Hybrid retrieval combining BM25 and vector search (HNSW) for efficient long-term memory
- Built-in knowledge graphs for entity relationships and temporal reasoning
- Production-grade security, encryption, and authentication with MinIO storage backend
- Pre-configured observability stack (Prometheus + Grafana) for metrics and dashboards

## Why It Matters for RAG Builders
It provides the critical infrastructure layer for deploying self-hosted, production-ready AI agent memory systems essential for RAG pipelines requiring persistent, session-aware context.
