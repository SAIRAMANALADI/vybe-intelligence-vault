## Summary
AssistAI is an Eclipse IDE plugin that transforms the IDE into an MCP (Model Context Protocol) server, enabling external AI agents to interact with Java projects through Eclipse's APIs. It provides real-time code editing, refactoring, debugging, and build capabilities while preserving workspace sync and local history.

## Key Features
- Exposes Eclipse IDE as an MCP server for AI agents to read, edit, and debug Java projects in real time
- Preserves Eclipse workspace sync, incremental compilation, and local history for accurate AI agent interactions
- Provides MCP tools for code analysis, navigation, refactoring, testing, and debugging via Eclipse APIs
- Supports external agents like Claude Code, OpenAI Codex, and Claude Desktop through HTTP MCP endpoints
- Includes built-in LLM chat view for inline interactions and context-aware guidance for AI agents

## Why It Matters for RAG Builders
It bridges the gap between AI agents and IDEs, enabling precise, real-time code interactions while maintaining workspace integrity, which is critical for RAG builders working with Java projects.
