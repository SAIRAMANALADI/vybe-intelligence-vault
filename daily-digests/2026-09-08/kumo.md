## Summary
Kumo is a high-performance terminal multiplexer designed to weave AI agents into a unified terminal interface, enabling real-time monitoring and management of multiple AI CLI tools within a single TUI. Built in Rust with a ratatui frontend, it provides real terminal emulation, split panes, and agent lifecycle tracking.

## Key Features
- Real terminal emulation with VT/xterm support for accurate shell and TUI behavior
- Split panes and sessions with mouse-drag resizing and zoom functionality
- Agent lifecycle detection and status tracking (working, blocked, idle) with visual indicators
- AI CLI pane integration for tools like opencode, claude, and codex with auto-detection
- Lightweight design with minimal CPU and memory overhead (~0.7% CPU, ~6MB memory)

## Why It Matters for RAG Builders
Kumo streamlines the management of multiple AI agents in a single terminal interface, reducing context switching and improving productivity for AI-driven workflows.
