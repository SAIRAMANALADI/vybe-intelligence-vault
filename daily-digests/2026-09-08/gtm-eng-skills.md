## Summary
A collection of AI agent skills for Claude Code that enable GTM (Go-To-Market) engineering workflows, including lead enrichment, signal discovery, TAM building, and outbound automation. Powered by the Deepline CLI, it orchestrates 40+ data providers with cost-aware routing and waterfall fallbacks.

## Key Features
- Turns Claude Code into a GTM engineering workstation with 40+ integrated data providers
- Cost-aware waterfall routing for enrichment tasks with provider fallbacks
- Strict identity validation and false-positive prevention for LinkedIn URL lookups
- Modular skills system with markdown-based skill definitions for easy extension
- Supports cloud workflows, cron triggers, and webhook-based automation
