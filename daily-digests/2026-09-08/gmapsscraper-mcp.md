## Summary
A Model Context Protocol (MCP) server that enables AI clients like Claude, Cursor, and Windsurf to scrape structured business data from Google Maps, including emails, addresses, ratings, and coordinates, via a simple API key integration.

## Key Features
- Integrates with AI clients (Claude, Cursor, Windsurf) via MCP for seamless Google Maps data scraping
- Supports both synchronous and asynchronous scraping workflows with job tracking
- Returns structured business data including emails, addresses, ratings, and coordinates
- Free tier available (10 credits) with paid plans for higher usage
- Local execution over stdio with no additional infrastructure required

## Why It Matters for RAG Builders
It enables AI agents to dynamically enrich context with real-time Google Maps business data, enhancing RAG applications with up-to-date location-based insights.
