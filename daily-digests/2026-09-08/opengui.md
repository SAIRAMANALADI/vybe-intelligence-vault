## Summary
OpenGUI is a mobile GUI agent framework for Android that enables AI agents to see, understand, and operate real Android app interfaces on devices. It integrates with DeepSeek Harness to provide automated UI interaction, task planning, and execution for long-running mobile workflows.

## Key Features
- Real-time Android UI interaction and automation via AccessibilityService
- Integration with DeepSeek Harness for plugin-based deployment and task dispatch
- Graph-based orchestration for long-running tasks with state management
- Multi-model support for planning and execution (e.g., Doubao, Qwen, OpenAI)
- Standby device dispatch via Discord, Telegram, Feishu, or REST API

## Why It Matters for RAG Builders
OpenGUI provides a critical bridge between AI agents and real Android devices, enabling automated GUI interaction for tasks like testing, social media management, and game workflows, which is essential for building robust RAG systems that require real-world device interaction.
