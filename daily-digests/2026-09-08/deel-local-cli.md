## Summary
A zero-dependency CLI coding agent that operates entirely on local models and private gateways, ensuring all data processing stays on the user's machine (127.0.0.1) unless explicitly configured otherwise. It provides a secure, vendor-agnostic environment for AI-driven coding tasks with built-in compliance and audit features.

## Key Features
- Zero external dependencies and no install scripts, ensuring minimal attack surface and compliance-friendly deployment.
- Strict local-only data processing by default, with explicit opt-in for external vendor APIs.
- Built-in compliance tools like audit logs, SBOM generation, and import-review reports for corporate environments.
- Multi-language support (Korean, English, Japanese, Chinese) with automated language verification tests.
- Advanced features like `/undo` for conversation/file rollback, auto-compaction for long conversations, and Korean model presets.

## Why It Matters for RAG Builders
It provides a secure, vendor-agnostic framework for AI-driven coding tasks that prioritizes data privacy and compliance, making it essential for RAG builders who need to operate in restricted or air-gapped environments.
