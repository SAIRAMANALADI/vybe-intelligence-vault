## Summary
PawnLogic is a terminal-first autonomous AI agent framework designed for complex task orchestration, logic reasoning, and CTF-oriented workflows. It supports multi-provider model routing, persistent memory, real local tool execution, and MCP integration with a focus on trust-boundary management and modularity.

## Key Features
- Multi-provider model routing with built-in aliases for DeepSeek, OpenAI, and Anthropic
- Persistent SQLite-backed workspace with searchable history and audit logs
- Real local tool execution including shell commands, Docker containers, browser automation, and CTF-specific tools
- Trust-boundary UX with explicit warnings for high-risk operations and configurable policy enforcement
- MCP integration for extensibility with external tools and services

## Why It Matters for RAG Builders
