## Summary
The FHIR MCP Server bridges Fast Healthcare Interoperability Resources (FHIR) APIs with the Model Context Protocol (MCP), enabling AI/LLM tools to securely search, retrieve, and analyze clinical data via standardized MCP interfaces.

## Key Features
- MCP-compatible transport (stdio, SSE, streamable HTTP) for FHIR APIs
- SMART-on-FHIR authentication support for secure access to clinical data
- Response filtering using FHIRPath to reduce payload sizes and improve efficiency
- Seamless integration with MCP clients like VS Code, Claude Desktop, and MCP Inspector
- Docker and Docker Compose support for easy deployment and testing

## Why It Matters for RAG Builders
