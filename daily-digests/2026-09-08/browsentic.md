## Summary
Browsentic enables agentic browsing by allowing AI agents to control and interact with your existing logged-in browser, including real sessions and logins. It combines a browser extension with a local daemon to drive web pages, answer questions, and perform tasks without requiring cloud services or API keys.

## Key Features
- Drives your real, logged-in browser with existing sessions and logins
- Supports multiple AI agent CLIs (Claude Code, Codex, Antigravity) and doubles as an MCP server
- 51+ page capabilities including reading, clicking, form submission, screenshots, and tool execution
- Live tools feature allows agents to write and save reusable scripts for specific sites
- Privacy-focused with guardrails, approvals, and local-only execution

## Why It Matters for RAG Builders
Browsentic bridges the gap between AI agents and real-world browsing by enabling secure, agent-driven interactions with authenticated browsers, making it essential for RAG systems that require real-time web access and user session integration.
