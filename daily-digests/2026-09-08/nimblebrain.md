## Summary
NimbleBrain is a self-hosted platform for MCP (Model Context Protocol) apps and agent automations, providing an interactive UI, scheduled agent runs, and a unified tool registry. It acts as both an MCP client and server, enabling seamless integration with external MCP servers and clients.

## Key Features
- Unified tool registry aggregating tools from multiple MCP servers into a single namespace
- Interactive UI with live agent-UI data sync and scheduled agent runs
- Skill-driven prompt composition with two-phase matching (triggers and keywords)
- Streamable HTTP MCP server endpoint for external client consumption
- Workspace isolation for secure multi-tenant deployments

## Why It Matters for RAG Builders
NimbleBrain simplifies the orchestration of MCP-based agents and tools, enabling RAG builders to integrate and manage multiple agents and tools seamlessly in a self-hosted environment.
