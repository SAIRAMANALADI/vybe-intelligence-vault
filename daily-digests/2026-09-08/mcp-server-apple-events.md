## Summary
A Model Context Protocol (MCP) server that provides native integration with Apple Reminders and Calendar on macOS via the EventKit framework, enabling full CRUD operations for reminders, subtasks, lists, and calendar events through a standardized interface.

## Key Features
- Full CRUD operations for Apple Reminders and Calendar via MCP
- Native macOS EventKit integration with round-trip sync to Reminders.app and Calendar.app
- Support for priority, tags, subtasks, and multi-criteria filtering
- Flexible date formats with timezone awareness and comprehensive input validation
- Pre-built, universal, code-signed binary for seamless deployment

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and manage Apple Reminders and Calendar data, bridging the gap between natural language AI workflows and native macOS productivity tools.
