## Summary
A lightweight Houdini toolkit plugin for CLI and IDE environments (Claude Code, Codex, Antigravity) that bundles four skills and an MCP server for inspecting `.bgeo.sc` caches and USD scene files without requiring a Houdini installation.

## Key Features
- Four specialized skills for Houdini CLI interaction, environment management, install detection, and USD/bgeo inspection
- Bundled MCP server (`houdini-lite`) for direct `.bgeo.sc` and USD file inspection without Houdini installation
- Auto-detection of Houdini installations for CLI-driven workflows
- Cross-platform support (Windows/Linux) for Houdini tool integration
- Plugin compatibility with Claude Code, Codex, and Antigravity CLI/IDE

## Why It Matters for RAG Builders
It streamlines Houdini asset inspection and automation for AI agents, enabling RAG pipelines to interact with 3D scene data without requiring a full Houdini installation.
