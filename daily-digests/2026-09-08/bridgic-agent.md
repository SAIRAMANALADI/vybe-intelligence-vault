## Summary
Bridgic Agent is a local-first desktop agent and intelligent automation workflow builder that enables users to describe desired outcomes and automatically generates, executes, and evolves workflows without requiring automation expertise.

## Key Features
- Agent-led workflow generation via `/build` command without requiring automation expertise
- Multi-agent support for parallel, long-running, and complex task execution
- Workspace and runtime isolation with Git-backed checkpoints for versioning and recovery
- Embedded Chromium browser for session-scoped automation with visible tabs and shared state
- Permission and security model with request, auto, and full modes for controlled execution

## Why It Matters for RAG Builders
Bridgic Agent simplifies the creation and management of automated workflows, reducing the barrier to entry for AI-driven task automation and enabling scalable, long-running agent systems.
