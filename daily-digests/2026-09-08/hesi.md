## Summary
Hesi is a web-based terminal bridging platform that integrates AI agents, CLI tools, and browser automation into a unified workspace. It enables multi-agent collaboration workflows where AI assistants and CLI agents (e.g., opencode, codex) autonomously discuss, plan, and execute tasks end-to-end within a single chat interface.

## Key Features
- Fully autonomous multi-agent workflows (AI discussion → planning → execution → reporting) with real-time streaming output.
- Headless CLI agent execution (opencode, codex, aider) for clean, TUI-free interactions integrated into AI discussions.
- Persistent memory and cross-session recall for AI agents, enabling context-aware task execution and decision-making.
- Browser automation via Chrome DevTools Protocol (CDP) for web interaction, DOM manipulation, and network monitoring.
- Modular MCP server architecture for tool integration, security policies, and session management with rate limiting.

## Why It Matters for RAG Builders
Hesi enables RAG builders to create autonomous AI workflows that combine multi-agent collaboration with terminal and browser automation, reducing manual intervention and improving task completion reliability.
