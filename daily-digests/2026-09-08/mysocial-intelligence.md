## Summary
Mysocial Intelligence provides an MCP server and AI skills to read and analyze a user's social media history (Instagram, TikTok, YouTube, LinkedIn, Threads) for use by AI assistants like Claude or ChatGPT. It enables evidence-based content creation, audience research, and brand partnership outreach.

## Key Features
- Reads and analyzes social media history across multiple platforms (Instagram, TikTok, YouTube, LinkedIn, Threads)
- Provides AI skills for next-post generation, creator research, brand documentation, product cataloging, and outreach
- Uses OAuth 2.1 for secure account integration with existing Mysocial accounts
- Offers 66 MCP tools for granular social media data access and analysis
- Supports evidence-based content strategy and brand partnership discovery
