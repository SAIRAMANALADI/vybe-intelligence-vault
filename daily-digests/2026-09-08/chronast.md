## Summary
Chronast is an MCP (Model Context Protocol) server for Claude Desktop that provides local time, date, elapsed-time tracking, duration math, and timezone conversion without network calls or telemetry. It enables chronological awareness for AI agents running entirely on the user's machine.

## Key Features
- Provides 8 tools for time/date operations (current time, date, elapsed time, duration math, timezone conversion)
- Runs entirely locally with no network calls or telemetry
- Supports configurable gap thresholds for session tracking
- Includes privacy policy and state isolation per conversation
- Open-source (MIT) with CI testing across platforms

## Why It Matters for RAG Builders
Chronast enables AI agents to maintain accurate chronological awareness without external dependencies, improving reliability for time-sensitive tasks in local-first workflows.
