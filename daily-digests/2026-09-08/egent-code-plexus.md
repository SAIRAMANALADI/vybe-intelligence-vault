## Summary
EgentCodePlexus (ecp) is a high-performance, stateless code intelligence graph designed for AI agents, enabling sub-second structural queries, impact analysis, and cross-repo API contract discovery across 31 languages. It eliminates token waste, hallucinations, and refactor risks by providing compact, agent-focused outputs and explicit unknowns (BlindSpots).

## Key Features
- Sub-2.6s cold indexing for 22k files with <175ms query latency
- Stateless, zero-warmup CLI with mmap-based rkyv graph files
- BlindSpot records for explicit unknowns to prevent hallucinations
- Polyglot support for 31 languages (deep + structural parsing)
- Compact TOON/JSON outputs optimized for LLM context windows
