## Summary
dshline is a terminal-native frontend for the DeepSeek Harness plugin ecosystem, providing a native terminal UI that integrates with Harness capabilities without requiring separate provider runtimes or state stores. It bridges Harness plugins to terminal-based interactions while leveraging Harness's existing services for models, settings, and credentials.

## Key Features
- Native terminal UI with real scrollback and scrolling support
- Integrates with DeepSeek Harness plugin ecosystem via standard capability contracts
- Supports session management, plugin browsing, and model switching through Harness services
- Lightweight and dependency-light renderer focused on terminal correctness
- Generic capability integration without provider-specific code

## Why It Matters for RAG Builders
dshline enables RAG builders to interact with DeepSeek Harness plugins directly in a terminal-native environment, simplifying integration and reducing overhead for terminal-based AI workflows.
