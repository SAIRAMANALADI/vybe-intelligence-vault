## Summary
A local MCP (Model Context Protocol) bridge and AI agent toolkit for Webstudio that enables offline design, mutation, and cloud synchronization of Webstudio projects without API limits or rate restrictions. It integrates with AI coding assistants like Cursor, Claude Code, and Google Antigravity to provide full JSX, Radix UI, and asset management capabilities.

## Key Features
- Enables 100% offline Webstudio project manipulation via local `.webstudio/data.json` files without cloud API limits.
- Provides a GUI control center for seamless setup, session management, and project synchronization.
- Supports full JSX, Radix UI, animations, tokens, and asset management with instant Immer-based transactions.
- Integrates with AI coding assistants (Cursor, Claude Code, Google Antigravity) via MCP commands for design and code generation.
- Automates asset uploads to Webstudio Cloud using browser session cookies and CSRF tokens for unlimited media handling.

## Why It Matters for RAG Builders
It eliminates API limits and rate restrictions for Webstudio projects, enabling AI agents to design and modify projects locally with full feature support before seamless cloud synchronization.
