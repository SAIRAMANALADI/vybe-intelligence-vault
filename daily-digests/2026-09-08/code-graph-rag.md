## Summary
Code-Graph-RAG is a multi-language codebase analysis tool that parses source code into a knowledge graph using Tree-sitter and Memgraph, enabling natural language queries, AI-driven code editing, and structural optimizations across monorepos.

## Key Features
- Parses 15+ languages (Python, TypeScript, Rust, Go, Java, C/C++, etc.) into a unified graph schema using Tree-sitter
- Enables natural language queries and AI-driven code editing with AST-based surgical patching and diff preview
- Supports dynamic call tracing via eBPF and test runs to overlay runtime behavior on static analysis
- Provides dead code detection, code optimization against best practices, and structural search with ast-grep
- Offers MCP server integration for direct interaction with MCP clients like Claude Code

## Why It Matters for RAG Builders
It transforms raw codebases into queryable knowledge graphs, enabling AI systems to understand, edit, and optimize code with precision and context-awareness.
