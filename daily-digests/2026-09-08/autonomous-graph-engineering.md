## Summary
Autonomous Graph Engineering provides a TypeScript runtime and plugin system for transforming user requests into bounded, verified execution graphs with explicit control planes. It prevents unbounded agent loops by enforcing deterministic DAGs, independent verification, and human approval gates for consequential actions.

## Key Features
- Intent-preserving deterministic prompt compiler with semantic refinement
- Bounded DAG execution with isolated workers, cross-checking, and repair loops
- Explicit budgets for concurrency, tokens, time, and repair with atomic checkpoints
- Independent verifier and fingerprint-bound human approval gates for side effects
- Multi-host plugin support for Codex, Claude Code, Cursor, GitHub Copilot, and Hermes Agent

## Why It Matters for RAG Builders
It provides a critical framework for building safe, auditable, and bounded AI workflows that prevent unbounded agent loops while enabling complex task decomposition with explicit control and verification.
