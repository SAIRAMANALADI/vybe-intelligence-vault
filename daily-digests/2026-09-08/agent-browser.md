## Summary
Agent Browser provides a self-hosted, headed Chrome session for AI agents, enabling real-time observation and takeover by humans. Agents interact via a JSON API while users monitor the same live session through noVNC, facilitating seamless collaboration during tasks like logins or 2FA prompts.

## Key Features
- Single headed Chrome session shared between agents and humans via noVNC
- JSON API for agent interaction with bounded actions (navigate, click, type, etc.)
- Real-time readable text and accessibility tree output before screenshots
- MCP server integration for seamless use with AI frameworks like Claude Code
- Strict security boundaries with loopback-only noVNC and destination validation

## Why It Matters for RAG Builders
It enables AI agents to collaborate with humans in real-time within the same browser session, reducing errors and improving task completion for complex workflows like logins or 2FA prompts.
