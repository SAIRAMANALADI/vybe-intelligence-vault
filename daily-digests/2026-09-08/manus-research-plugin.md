## Summary
A Claude Code plugin that delegates user story creation, requirements gathering, and discovery research to a Manus.im agent, then imports the generated markdown into the project for implementation. It bridges deep research workflows with AI-driven code generation.

## Key Features
- Delegates research and requirements gathering to Manus.im agent via API
- Generates structured markdown output with YAML frontmatter for version control
- Supports slash commands and bash orchestration for seamless workflow integration
- Provides structured JSON output via JSON Schema for programmatic consumption
- Offers INVEST, Given/When/Then, MoSCoW, and job stories formats for requirements

## Why It Matters for RAG Builders
It streamlines the critical gap between high-level prompts and executable specifications by automating research and requirements generation, enabling AI agents to produce better, more detailed code from well-defined inputs.
