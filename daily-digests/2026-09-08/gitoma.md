## Summary
Gitoma is an autonomous AI agent that autonomously improves GitHub repositories by analyzing code, planning fixes, committing changes, opening pull requests, and performing adversarial self-reviews. It operates locally, integrates with external tools, and maintains cross-run memory for iterative improvements.

## Key Features
- Self-correcting critic stack with 22+ guards to validate patches and prevent regressions
- Local-first execution with no external data exposure
- Cross-run memory via Layer0 for iterative learning and context retention
- Extensible architecture with MCP, HTTP, and gRPC integrations
- Resumable and observable workflows with real-time cockpit and structured logging

## Why It Matters for RAG Builders
Gitoma automates and enhances GitHub repository maintenance by combining autonomous planning, execution, and self-review, reducing manual effort while improving code quality through iterative AI-driven improvements.
