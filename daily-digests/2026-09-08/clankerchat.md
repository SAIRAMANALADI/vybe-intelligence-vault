## Summary
clankerchat is a local communication layer for coding agents (Claude Code, Codex, OpenCode) that enables direct messaging, broadcasts, and request/reply interactions without a human relay. It uses SQLite for durable state management and integrates with Git repositories or a shared user line.

## Key Features
- Durable message storage with SQLite for persistence across sessions
- Support for direct messaging, broadcasts, and request/reply workflows between agents
- Git repository-scoped or shared user-wide communication lines
- Integration with Claude Code, Codex, and OpenCode via CLI hooks
- Human-readable watch mode and JSON Lines output for monitoring conversations

## Why It Matters for RAG Builders
It enables seamless multi-agent collaboration and coordination in local development environments, reducing manual relaying of messages and improving workflow efficiency for AI-driven coding tasks.
