## Summary
A Java Spring Boot framework implementing the Model Context Protocol (MCP) for enterprise AI agents to securely invoke tools like database queries, web searches, and system monitoring. Designed for Java-centric enterprises with SPI-based extensibility and Spring AI Alibaba integration.

## Key Features
- SPI-based tool extension with automatic discovery and registration
- Enterprise-grade security (SQL injection protection, IP whitelisting, RBAC, audit logs)
- Native Spring AI Alibaba integration for DashScope/Qwen model compatibility
- SSE streaming for real-time tool execution results
- Containerized deployment with Docker Compose and multi-profile support

## Why It Matters for RAG Builders
It fills a critical gap in the MCP ecosystem by providing a Java-native, enterprise-ready framework for AI agents to securely and extensibly invoke tools, leveraging Spring Boot's ecosystem and addressing the 90% of enterprises using Java backends.
