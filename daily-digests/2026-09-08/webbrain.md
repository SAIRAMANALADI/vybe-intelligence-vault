## Summary
WebBrain is an open-source AI browser agent that integrates with Chrome, Firefox, and Edge as a side-panel extension, enabling users to interact with web pages, automate tasks, and execute multi-step workflows using their preferred LLM or local models.

## Key Features
- Side-panel AI agent for real-time web interaction and automation
- Supports local and cloud-based LLMs with OpenAI-compatible endpoints
- Multi-step agent with configurable tool-use tiers and modes (Ask/Act/Dev)
- Built-in slash commands for scheduling, watching pages, and workflow management
- Per-tab conversation history with token-aware context management

## Why It Matters for RAG Builders
WebBrain enables seamless integration of AI agents into everyday browsing, empowering users to automate complex web tasks and interact with pages dynamically, making it essential for AI-driven web automation workflows.
