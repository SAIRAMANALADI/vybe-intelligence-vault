## Summary
Agent Letterbox for Herdr is a coordination layer that enables seamless task handoffs between multiple AI coding agents within a Herdr terminal session. It acts as a durable message relay system, ensuring tasks are tracked, acknowledged, and processed without manual copy-paste relaying.

## Key Features
- Durable task letters stored as files with envelopes for long-term record-keeping
- Live doorbell notifications for instant agent wake-up without terminal clutter
- ACK/NACK/RESULT lifecycle for clear task ownership and progress tracking
- Cross-agent communication via standardized protocol (SPEC.md)
- Recovery from agent crashes or compacted terminals using inbox persistence

## Why It Matters for RAG Builders
It provides a reliable, inspectable coordination layer for multi-agent AI workflows, eliminating manual relay work and ensuring durable task records for debugging and auditing.
