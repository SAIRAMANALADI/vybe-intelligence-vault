## Summary
ActableSite MCP is a remote, read-only Model Context Protocol (MCP) server designed to audit public website readiness and AI crawler policies. It provides tools to evaluate website metadata, structured data, and compliance with AI crawler token standards.

## Key Features
- Exposes three read-only tools for website auditing and AI crawler policy checks
- Supports Streamable HTTP transport for MCP clients
- Provides discovery metadata via `.well-known/mcp.json` and `.well-known/mcp/server-card.json`
- Enforces strict safety contracts (no write operations, private network access, or authentication)
- Includes a live verifier for protocol and tool inventory validation

## Why It Matters for RAG Builders
It enables RAG builders to validate public website readiness and AI crawler compliance, ensuring data sources meet essential indexing and accessibility standards.
