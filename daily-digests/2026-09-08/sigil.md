## Summary
Sigil is a TUI-first coding agent designed for reviewable and resumable repository work, enabling developers to interact with AI models directly in the terminal while maintaining control over edits, tool activity, and session recovery.

## Key Features
- TUI-first workspace for seamless terminal-based coding agent interactions
- Review-before-risk workflow with approvals and diff inspection before executing changes
- Resumable sessions to recover interrupted tasks without rerunning unfinished tools
- Support for multiple AI providers and custom MCP integrations
- Built-in safety, permissions, and privacy controls for secure repository work

## Why It Matters for RAG Builders
Sigil empowers AI engineers to build safer, more controlled, and reviewable coding agents directly in the terminal, reducing risks in automated repository edits.
