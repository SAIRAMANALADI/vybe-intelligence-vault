## Summary
corlinman is a self-hosted intelligent-agent platform that provides durable memory, real tools, multi-channel chat, and a human-in-the-loop operations plane. It enables AI agents to run with persistent context, sandboxed plugins, and auditable governance on user-owned hardware.

## Key Features
- Unified agent loop supporting multiple LLM providers (OpenAI, Anthropic, Google, DeepSeek, Qwen, GLM) with hot-swap capabilities.
- Real tools as plugins with optional Docker sandboxing, human approval gates, and JSON-RPC/gRPC transport for security and flexibility.
- Hybrid memory system combining SQLite session history with FTS5 (BM25) knowledge base for auditable, persistent context.
- Multi-channel I/O support (QQ, Telegram, Discord, Slack, Feishu, cron, OpenAI-compatible endpoints) with shared agent logic.
- Tidepool admin console for real-time governance, observability (OTel + Prometheus), live config reload, and approval workflows.

## Why It Matters for RAG Builders
corlinman provides a production-grade, self-hosted agent framework with durable memory, sandboxed tools, and governance, making it essential for building auditable, scalable RAG and AI agent systems.
