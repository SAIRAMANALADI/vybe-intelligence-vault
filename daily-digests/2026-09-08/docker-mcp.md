## Summary
docker-mcp-server is an MCP (Model Context Protocol) server that enables AI agents to manage Docker environments, including containers, images, networks, volumes, and swarm services. It provides full Docker daemon access, supports remote daemons, and offers read-only modes for monitoring without risk of changes.

## Key Features
- Full Docker daemon management via MCP tools (containers, images, networks, volumes, swarm services, secrets, configs, nodes, plugins)
- Support for local and remote Docker daemons (TCP, TLS, SSH, or Unix socket)
- Read-only and no-destructive modes to prevent accidental changes
- Optimized for lazy tool loading in MCP clients and configurable tool exclusion
- Prebuilt container images (full and no-scout variants) for easy deployment

## Why It Matters for RAG Builders
It enables AI agents to directly manage Docker environments, bridging the gap between AI workflows and containerized infrastructure for seamless automation and monitoring.
