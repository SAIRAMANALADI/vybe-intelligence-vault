## Summary
dct is a deterministic context tracker that provides persistent, queryable memory for AI coding assistants by maintaining a shared SQLite/PostgreSQL database across projects. It enables structured tracking of issues, todos, changelogs, plans, and session handoffs via MCP and CLI tools.

## Key Features
- Shared SQLite/PostgreSQL database for persistent, queryable project state across all repositories
- Structured tracking of issues, todos, changelogs, plans, and sprints with priorities and checkpoints
- MCP-native integration with CLI tools for seamless AI assistant workflows
- Session handoffs and pickup workflows to resume work across sessions
- Soft-delete ledger and changelog-first releases for versioned tracking

## Why It Matters for RAG Builders
dct eliminates context loss in AI-assisted development by providing a persistent, queryable memory layer that integrates directly with MCP-capable assistants, ensuring continuity and structured tracking across projects.
