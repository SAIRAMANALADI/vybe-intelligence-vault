## Summary
Data Steward is a local-first multi-device data management assistant for Windows and Android that enables users to interact with their files using natural language. It integrates a Hermes Agent for intent understanding and task planning, with a FastAPI-based hub handling authentication, permissions, and secure file operations.

## Key Features
- Natural language interaction for file and data queries across Windows and Android
- Hermes Agent for intent understanding, task planning, and tool selection with strict safety constraints
- Secure multi-device pairing with TLS, certificate pinning, and human-readable short-code confirmation
- Idempotent operations, persistent sessions, and offline recovery with SQLite and WebSocket synchronization
- Controlled content understanding with fail-closed security for file operations and user confirmations

## Why It Matters for RAG Builders
It provides a secure, agent-driven framework for automating multi-device data management tasks with strict safety and user control, essential for building reliable RAG systems that interact with real-world file systems.
