## Summary
This repository provides an MCP server that enables efficient access to Cisco Nexus Dashboard's OpenAPI schemas, allowing developers to query and compare multiple ND releases with lower token usage. It supports versioned schema management and diffing for API development.

## Key Features
- Supports loading and querying multiple Nexus Dashboard OpenAPI schema versions side-by-side
- Provides versioned schema access with optional default version selection
- Includes tools for schema comparison (diff_versions) and listing available schemas
- Designed for integration with Claude Code and standalone MCP server usage
- Handles component schema scoping to avoid naming conflicts across files

## Why It Matters for RAG Builders
This MCP server simplifies access to Cisco Nexus Dashboard's OpenAPI schemas, enabling AI agents to dynamically query and compare API versions for accurate RAG responses in network management contexts.
