## Summary
Scraps is a wiki-link documentation compiler that treats documentation like a programming language, enabling typed, queryable artifacts for both human readers and AI agents. It compiles wiki-linked markdown into static HTML sites and JSON outputs for programmatic access.

## Key Features
- Treats wiki-linked markdown as typed primitives (links, tags, embeds) for structured compilation
- Compiles to both static HTML sites and queryable JSON outputs for AI agents
- CLI-first tool with built-in JSON support for seamless agent integration
- Supports MCP server for standardized agent communication
- Includes AI integration plugins for workflows like ingest, query, and linting

## Why It Matters for RAG Builders
Scraps enables AI agents to interact with documentation as structured, queryable data, bridging the gap between human-readable wikis and machine-usable knowledge bases.
