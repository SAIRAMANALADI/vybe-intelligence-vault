## Summary
Muraqib is a nightly Playwright-based QA tool that monitors live applications for regressions. It uses AI (Claude) to automatically open PRs with fixes when tests fail, while also detecting silent failures like hard-killed jobs or misconfigured alerts. The tool runs entirely within GitHub Actions with no hosted service or monthly costs.

## Key Features
- Nightly Playwright test execution against production environments
- Automated PR creation with AI-generated fixes for failed tests
- Silent failure detection (e.g., hard-killed jobs, misconfigured alerts)
- Weekly digest emails summarizing test results and failures
- Self-hosted in GitHub Actions with no hosted service or monthly fees

## Why It Matters for RAG Builders
Muraqib ensures critical regressions in live applications are detected and addressed promptly, even when traditional monitoring fails to alert due to silent job cancellations or misconfigurations.
