## Summary
Genio is an autonomous multimodal AI systems engineer designed to manage infrastructure, generate technical content, and self-heal errors. It dynamically routes models, repairs code, and produces media content in Tunisian Arabic while integrating with local and cloud-based AI models.

## Key Features
- Dynamic model routing based on GPU/VRAM metrics to optimize performance
- Self-healing pipeline that detects, diagnoses, and repairs runtime errors autonomously
- Full media production pipeline including terminal recording, audio synthesis, and video editing
- Evolving memory system that stores past errors to prevent recurrence
- Cross-platform deployment with Linux, Windows, Android, and iOS clients
