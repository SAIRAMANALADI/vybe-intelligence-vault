## Summary
iML Work is an enterprise-grade intelligent assistant and automation workflow system designed for intranet environments, enabling employees to deploy AI agents that perform real-world tasks in legacy business systems like OA, CRM, and ERP without requiring API integrations. It combines a monorepo architecture with Electron-based desktop clients, a Spring Boot SaaS management platform, and an FDE (Frontline Deployment Engineer) toolkit for low-code automation.

## Key Features
- Monorepo architecture with Electron desktop clients, Spring Boot SaaS backend, and FDE toolkit for unified management and execution.
- Physical skill definitions via YAML-frontmatter SKILL.md files for instant SOP activation without client redevelopment.
- Zero-code legacy system integration using Playwright and nut-js for RPA-driven automation with session persistence.
- 100% offline vector storage and dual sandbox isolation (Pyodide WASM + Docker) for compliance and security in sensitive environments.
- Interactive execution drawer with real-time terminal logs, human-in-the-loop confirmations, and risk-aware automation suspension.

## Why It Matters for RAG Builders
It enables AI engineers to deploy enterprise-grade agents that perform real-world tasks in legacy systems without API dependencies, bridging the gap between AI automation and real-world business workflows.
