## Summary
North Agent is a lightweight, embeddable Python Agent Runtime designed to simplify the integration of AI agents into host applications. It abstracts model calls, tool execution, skills, runtime events, and context persistence into a stable boundary, allowing applications to focus on business logic and user experience.

## Key Features
- Embeddable Python Agent Runtime for seamless integration into host applications
- Supports synchronous, streaming, and single-call agent lifecycles
- Built-in tool registration, async middleware, error handling, and loop detection
- Context persistence with Memory, SQLite, and PostgreSQL checkpointers
- Normalized model/tool event tracking and token usage metrics

## Why It Matters for RAG Builders
North Agent simplifies the deployment and management of AI agents in production environments by providing a stable, embeddable runtime with built-in persistence and event tracking.
