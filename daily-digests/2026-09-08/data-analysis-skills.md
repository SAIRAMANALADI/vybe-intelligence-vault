## Summary

## Key Features
- Generates single-file interactive HTML reports with embedded charts and narratives, not just raw data or static images.
- Supports multiple AI agent platforms (Claude Code, Codex, WorkBuddy) with adaptive interaction methods (structured questions or text-based choices).
- Industry-agnostic but provides tailored analysis for retail, SaaS, finance, media, and other sectors with domain-specific metrics.
- Follows a strict five-phase workflow (data understanding, cleaning, analysis, reporting, delivery) with built-in statistical rigor and transparency.
