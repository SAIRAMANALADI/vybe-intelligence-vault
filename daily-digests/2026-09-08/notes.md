## Summary
A standalone CLI and MCP server for managing repo-scoped Markdown notes, enabling safe read/write operations, handoff-tagged notes, and agent integration via MCP. Includes a private capture PWA for note collection and an Omarchy plugin for enhanced note management.

## Key Features
- Repo-scoped Markdown note storage and retrieval
- MCP server for agent workflows with safe read/write operations
- Private capture PWA for browser-based note collection
- Omarchy plugin for integrated note browsing, search, and editing
- Automated packaging for Linux (deb, RPM, AUR) and versioned releases
