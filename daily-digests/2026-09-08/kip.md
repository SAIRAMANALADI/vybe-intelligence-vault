## Summary
KIP (Knowledge Interaction Protocol) is an open protocol enabling AI agents to accumulate, structure, and leverage experiential knowledge for continuous learning and decision-making. It bridges LLMs with persistent, auditable memory systems to transform interactions into actionable insights and skills.

## Key Features
- Structured experience accumulation with goal-directed trajectories (Events, Experiences, Steps)
- Persistent, auditable memory with confidence and memory strength tracking
- Procedural skill compilation from past experiences without retraining
- Action-aware recall for pre-action briefings (constraints, risks, applicable skills)
- Portable knowledge capsules for migration and exchange of memory graphs

## Why It Matters for RAG Builders
KIP provides the foundational protocol for AI agents to move beyond static knowledge to dynamic, self-improving learning systems by structuring experiences into retrievable, actionable memory.
