## Summary
Mochi is a desktop AI companion application that transforms command-line interactions into a warm, animated Live2D character interface. It combines a Rust-based Tauri frontend with a Python FastAPI backend powered by LangGraph for cognitive processing.

## Key Features
- Live2D animated AI companion for desktop with emotional expression
- LangGraph-powered backend for cognitive agent orchestration
- Tauri-based cross-platform desktop shell with Rust backend
- WebSocket-based real-time communication between frontend and backend
