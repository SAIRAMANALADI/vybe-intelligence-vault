## Summary
Closet Context is a full-stack prototype of an explainable AI stylist that prioritizes transparency in how it uses user data, assumptions, and recommendations. It provides a responsive React-based web and mobile interface, a Chrome extension, and a local/Express API for wardrobe management and AI-driven outfit generation.

## Key Features
- Explainable outfit recommendations with wardrobe ID binding and confidence scoring
- Visible agent state and reasoning during multi-step interactions
- Editable taste profile and privacy controls with JSON export
- Chrome extension for seamless wardrobe item import without background tracking
- Demo mode for API-free interaction and static hosting compatibility

## Why It Matters for RAG Builders
