## Summary
ValidPilot Verify is an MCP-based verification platform for AI-generated code, enabling automated validation of web interfaces with evidence collection, error diagnosis, and structured reporting. It provides 128 atomic tools for browser operations, accessibility checks, visual regression, and assertion validation.

## Key Features
- 128 atomic verification tools for browser operations, accessibility, and assertions
- Automated evidence collection with timestamped screenshots and HAR files
- AI-driven error diagnosis with root cause analysis and confidence scoring
- Structured validation reports in Markdown with embedded evidence
- Integration with MCP-compatible AI assistants (Cursor, Claude, Windsurf, etc.)

## Why It Matters for RAG Builders
It provides essential verification and evidence collection capabilities for AI agents generating web interfaces, ensuring reliability and traceability in RAG pipelines.
