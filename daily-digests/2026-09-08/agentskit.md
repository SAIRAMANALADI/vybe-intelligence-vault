## Summary
AgentsKit is a lightweight, modular JavaScript toolkit for building AI agents with zero lock-in. It provides 24 composable packages covering adapters, runtime, tools, memory, RAG, UI, and observability, enabling developers to start small and scale to full-stack agent systems.

## Key Features
- 24 focused, zero-dependency packages with formal contracts for interoperability
- Lightweight core (10KB gzip) with support for React, Vue, Svelte, Solid, Angular, and terminal UIs
- Built-in autonomous runtime with ReAct loop, tool delegation, and multi-agent support
- Plug-and-play RAG, memory (vector/graph/encrypted), and observability integrations
- Provider-agnostic adapters (OpenAI, Anthropic, Ollama, etc.) with one-line swaps

## Why It Matters for RAG Builders
It simplifies building production-grade AI agents by providing a modular, lightweight alternative to bloated frameworks, reducing integration overhead and enabling rapid iteration.
