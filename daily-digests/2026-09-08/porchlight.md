## Summary
Porchlight is an autonomous exit-interview system that captures and remembers the reasons members leave, then proactively wins them back when those specific issues are resolved using semantic reasoning and long-term memory via the Minds platform.

## Key Features
- Automated exit interviews capturing structured return-conditions in members' own words
- Semantic condition matching to identify when a member's reason for leaving is resolved
- Proactive win-back messaging quoting the member's original reason for departure
- Real-time churn board tracking departure reasons and recovery metrics
- Offline MOCK mode for full demoability without API dependencies

## Why It Matters for RAG Builders
Porchlight demonstrates how autonomous agents with long-term memory and semantic reasoning can transform reactive churn management into proactive, personalized win-back campaigns that directly address the root causes of member departure.
