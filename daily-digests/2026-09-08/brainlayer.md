## Summary
BrainLayer provides persistent memory for MCP-compatible AI agents, enabling shared organizational memory across sessions and agents. It offers local-first storage with a SQLite backend, real-time indexing, and a suite of 13 MCP tools for memory management, search, and knowledge graph operations.

## Key Features
- 13 MCP-compatible tools for memory operations (search, store, recall, digest, etc.)
- Local-first storage using SQLite with vector embeddings and FTS5 for hybrid search
- Real-time JSONL indexing with ~1s latency and watcher-based updates
- Knowledge graph for entities, relations, and person lookups
- Optional macOS companion app (BrainBar) with UI and MCP integration

## Why It Matters for RAG Builders
BrainLayer solves the critical problem of AI agent amnesia by providing persistent, shared memory across sessions and agents, enabling continuous learning and avoiding redundant work.
