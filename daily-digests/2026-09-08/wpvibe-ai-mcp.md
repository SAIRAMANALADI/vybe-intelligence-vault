## Summary
WPVibe is an open-source WordPress plugin that integrates the Model Context Protocol (MCP) to make self-hosted WordPress sites accessible to AI assistants like Claude, ChatGPT, and Cursor. It exposes WordPress operations as MCP-callable REST endpoints, enabling AI-driven content management, theme editing, and WP-CLI command execution via natural language.

## Key Features
- Exposes WordPress operations as MCP tools for AI assistants
- Enables AI-driven content creation, editing, and publishing
- Supports theme editing with sandboxed draft-preview-publish workflows
- Integrates WP-CLI commands via native PHP dispatch (34 allowlisted commands)
- Provides secure OAuth authentication and capability-checked operations
