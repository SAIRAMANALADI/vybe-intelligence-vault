## Summary
cursor-browser-bridge enables remote control of Cursor IDE's built-in browser from MCP clients like Claude Code or Codex via SSH. It allows navigation, interaction, and screenshot capture without leaving the Cursor IDE environment.

## Key Features
- Remote browser control via SSH from MCP clients
- Seamless integration with Cursor IDE
- Screenshot capture and text input capabilities
- Cross-platform support (Windows, macOS, Linux)
- No programming skills required for basic use
