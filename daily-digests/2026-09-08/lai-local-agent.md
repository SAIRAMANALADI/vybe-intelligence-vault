## Summary
LAI is a compact, auditable coding agent designed for local LLMs, optimized for constrained context, batch operations, and forensic auditing. It integrates with VS Code to enable fast, bounded local cycles for planning, debugging, implementation, testing, and review.

## Key Features
- Mode-specific tools and prompts optimized for local LLMs with low overhead
- Batch inspection and transactional patching with repository confinement and symlink checks
- Validation, acceptance, and evidence gates for secure and auditable operations
- Compact workspace state, metrics, and forensic audit records (JSONL)
- Persistent Git-aware workspace handoff for seamless agent transitions

## Why It Matters for RAG Builders
LAI enables efficient, auditable, and low-overhead agentic workflows for local LLMs, making it ideal for developers building constrained, high-performance AI systems.
