## Summary
Harness Mobile is a native iOS SwiftUI client that brings DeepSeek Harness' Agent workflow to iPhones, enabling on-device execution of model inference, tools, plugins, and commands while relying on user-configured API endpoints for model calls.

## Key Features
- BYOK (Bring Your Own Key) model inference via user-configured HTTPS APIs for DeepSeek, OpenAI-compatible, and Anthropic models
- On-device Agent loop with local tool execution (files, OCR, location, notifications, contacts, calendar, etc.) and embedded iSH ARM64 Alpine Linux for shell commands
- Native SwiftUI interface with session management, trajectory tracking, and real-time activity support
- Cordis Host-half plugin system with GitHub/marketplace installation, dynamic tool/prompt contributions, and lifecycle management
- Strict on-device execution boundary with no remote command forwarding, ensuring data privacy and security

## Why It Matters for RAG Builders
It enables AI engineers to deploy agentic workflows directly on iOS devices with full control over data and execution, bridging mobile capabilities with advanced AI models.
