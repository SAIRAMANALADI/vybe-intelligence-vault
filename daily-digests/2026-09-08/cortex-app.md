## Summary
Cortex is an open-source institutional memory system for the agentic era, designed to serve as long-term memory for both humans and AI agents. It ingests documents, extracts entities, and builds a scalable knowledge graph in Neo4j, enabling advanced GraphRAG capabilities and seamless integration with AI stacks.

## Key Features
- Automated entity extraction and relationship discovery into a Neo4j knowledge graph
- Hybrid search combining vector, keyword, and graph traversal for RAG
- Collection-level organization with scoped knowledge graphs for multi-tenant use
- Web import via MDHarvest (Crawl4ai) for seamless document ingestion from URLs
- Advanced deduplication and semantic entity resolution for high-quality graph construction

## Why It Matters for RAG Builders
Cortex provides a portable, scalable long-term memory backbone for RAG systems, enabling persistent knowledge retention and advanced GraphRAG capabilities that enhance AI agent performance and human-AI collaboration.
