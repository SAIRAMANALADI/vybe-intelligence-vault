## Summary
FinanceMCP is a professional financial data MCP server that integrates Tushare and Binance APIs to provide real-time financial data and technical analysis for AI assistants like Claude. It aggregates 100+ financial data interfaces into 18 MCP tools covering stocks, funds, bonds, macroeconomics, and news.

## Key Features
- Aggregates 100+ financial data interfaces into 18 standardized MCP tools for AI models
- Supports multi-market data (A-shares, US stocks, HK stocks, forex, futures, funds, bonds, options)
- Provides 5 core technical indicators (MACD, RSI, KDJ, BOLL, MA) with intelligent data pre-fetching
- Offers both cloud-hosted and local deployment options with zero-configuration public services
- Integrates with FinNote for end-to-end financial analysis and document generation workflows
