## Summary
LVIS App is an extensible Electron-based desktop agent workspace designed for AI-driven chat, plugin workflows, local indexing, meetings, and MS Graph integration. It provides a modular plugin runtime, managed marketplace for extensions, and hybrid retrieval combining local and cloud data sources.

## Key Features
- Tiled chat workspace with multi-conversation support and workbench model
- Manifest-driven plugin runtime with dynamic loading and managed marketplace
- Hybrid retrieval system fusing local BM25/vector and cloud adapter results
- Overlay trigger surface for plugin-initiated conversation proposals
- Cross-platform installer packaging for macOS, Linux, and Windows

## Why It Matters for RAG Builders
It provides a robust, extensible desktop environment for AI agents, enabling seamless integration of plugins, local indexing, and hybrid retrieval for RAG pipelines.
