## Summary
Rivet automates GitHub Agentic Workflows for pull-request review, issue triage, and owner-authorized repair using a pinned, checksum-verified compiler. It ensures least-privilege security by default and requires human-controlled setup via guided installer or manual commands.

## Key Features
- Pull-request review automation with bounded output and least-authority GitHub App
- Issue triage with write authority (repair mode requires explicit upgrade)
- Guided installer for human-controlled setup and verification
- Pinned, checksum-verified compiler for managed workflows
- Fail-closed safety model with dry-run and draft PR options

## Why It Matters for RAG Builders
Rivet provides a secure, human-verified framework for automating AI-driven GitHub workflows, reducing manual review burden while enforcing least-privilege security and auditability.
