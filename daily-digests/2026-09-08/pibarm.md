## Summary
pibarm enhances the Pi agent framework with safety-focused workflows, including read-only planning, explicit question prompts, isolated execution via git worktrees, and subagent management. It integrates MCP tools, role-based presets, and Obsidian note export for agent transparency and collaboration.

## Key Features
- Read-only planning mode with explicit question prompts before execution
- Isolated execution via git worktrees to avoid active repo contamination
- Role-based presets for model/tool/thinking configuration
- MCP tool integration through `mcporter` for extended agent capabilities
- Obsidian note export for session documentation and traceability
