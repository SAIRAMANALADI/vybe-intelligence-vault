## Summary
C-Embedded Agent is an AI-powered firmware engineering assistant designed to automate the development lifecycle for STM32F103 microcontrollers, including requirement analysis, code generation, compilation, debugging, and hardware validation. It bridges AI-driven development with embedded systems workflows.

## Key Features
- AI-driven firmware code generation for STM32F103 using HAL/CMSIS
- Automated compilation, debugging, and ST-Link flashing workflow
- Hardware validation with serial communication and ADC/PWM checks
- Support for importing existing STM32 projects and IOC files
- Benchmarking and comparison tools for AI vs baseline compilation success rates

## Why It Matters for RAG Builders
It accelerates embedded firmware development by automating code generation, compilation, and hardware validation, reducing manual effort and errors for STM32-based AI engineering workflows.
