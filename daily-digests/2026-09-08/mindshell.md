## Summary
MindShell is an open-source graphical agent workbench designed for long-running coding tasks, enabling controlled code editing, permissions, checkpoints, and event-backed recovery. It provides a visible execution environment for AI agents, ensuring traceability and reliability in complex workflows.

## Key Features
- Graphical interface for managing agent tasks, windows, and permissions in a single console
- Controlled code editing with verification and drift detection to prevent overwrites
- Event Log as the single source of truth for replayable facts and recovery
- Checkpoints and runtime session rebuilds for long-task reliability and crash recovery
- Permission tiers (R0-R4) with a hardline boundary for safety and accountability

## Why It Matters for RAG Builders
MindShell provides a critical foundation for building reliable, traceable, and recoverable AI agent workflows, especially for long-running coding tasks where visibility and safety are paramount.
