## Summary
A Model Context Protocol (MCP) server that integrates PinMeTo's location and review data (Google, Facebook, Apple) with AI assistants, enabling natural language queries for business insights and automated report generation.

## Key Features
- Connects PinMeTo location data to AI assistants via MCP for natural language queries
- Supports Google, Facebook, and Apple insights (ratings, reviews, keywords, and performance metrics)
- Enables time-based aggregations and comparisons (daily, monthly, quarterly, year-over-year)
- Provides optional PDF/PowerPoint report generation for business presentations
- Compatible with MCP clients like Claude Desktop, VS Code, Cursor, and ChatGPT desktop app
