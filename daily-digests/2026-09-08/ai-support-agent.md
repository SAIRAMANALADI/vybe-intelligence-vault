## Summary
A full-stack AI front desk solution for small businesses that enables customers to upload their business documents (e.g., policies, FAQs) and deploy an AI agent that answers customer questions grounded in that content. The agent can be embedded on the business's website via a single script tag and includes lead capture and analytics features.

## Key Features
- End-to-end RAG pipeline with document ingestion, chunking, and embedding using Gemini
- Embeddable AI agent widget deployable via a single script tag on any website
- Real-time lead capture during conversations (name, email, phone)
- Dashboard for managing documents, leads, and analytics
- Streamed, grounded responses with token-by-token delivery

## Why It Matters for RAG Builders
This repository provides a production-ready, embeddable AI agent framework that demonstrates a complete RAG pipeline with lead capture, making it essential for developers building customer-facing AI solutions.
