## Summary
jiasu is a Windows-focused automation tool that integrates disk cleanup, system speed optimization, and security hardening into a single AI-driven maintenance skill. It combines reverse-engineered techniques from Tencent PC Manager with best practices from top open-source Windows optimization projects.

## Key Features
- One-click AI-driven maintenance for Windows systems with cleanup, speedup, and security tasks
- Deep disk scanning to identify and remove large cache files (e.g., 36GB+ from apps like CapCut)
- Junction-based AppData migration to free up C: drive space without breaking applications
- Boot acceleration via delayed startup tasks, service tweaks, and system optimizations
- Security hardening with telemetry disabling, bloatware removal, and Defender/VBS checks
