## Summary
ioBroker.mcp is an MCP (Model Context Protocol) server adapter for ioBroker that exposes ioBroker's functionality as a streamable HTTP-based MCP server, enabling MCP-capable clients like Claude Desktop to interact with ioBroker's states, objects, and services programmatically.

## Key Features
- Exposes ioBroker as an MCP server with streamable HTTP transport for MCP-capable clients
- Supports standalone and web extension deployment modes for flexible integration
- Provides 20+ MCP tools for reading/writing states, managing objects, querying history, and system diagnostics
- Includes network diagnostics (ICMP ping, TCP probe) and adapter repository search for troubleshooting and recommendations
- Configurable authentication, SSL/TLS, and granular permissions for secure and controlled access

## Why It Matters for RAG Builders
It enables AI agents and MCP clients to programmatically interact with ioBroker's home automation ecosystem, bridging the gap between AI workflows and physical device control.
