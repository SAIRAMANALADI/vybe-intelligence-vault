## Summary
A Windows desktop application that automates the download and organization of course materials from Monash University's Moodle platform, including lecture recordings converted to searchable transcripts, assignments, and weekly summaries. Optional AI-powered summaries of lecture transcripts are available via API integration.

## Key Features
- Automated download and organization of course materials into weekly folders with no manual intervention required after initial setup
- Conversion of lecture recordings (Panopto/YouTube) into searchable, AI-summarized text transcripts without downloading video files
- Optional AI integration for generating revision-ready summaries of lecture transcripts via multiple provider APIs (Gemini, OpenAI, Ollama, etc.)
- Weekly summary notes that track new files, recordings, and upcoming assessments, ensuring users stay updated on course changes
- Fully local operation with no telemetry or external servers; session cookies and API keys are stored locally and never exposed

## Why It Matters for RAG Builders
It streamlines the retrieval and organization of educational content, reducing manual effort for students while enabling AI-driven summarization of lecture materials for RAG pipelines.
