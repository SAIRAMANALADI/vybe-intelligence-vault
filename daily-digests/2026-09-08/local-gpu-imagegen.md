## Summary
A Model Context Protocol (MCP)-first control plane for executing and managing ComfyUI workflows locally with cryptographic model identity, explicit approvals, and durable run evidence. It enables agent-driven image generation without modifying existing ComfyUI setups or silently downloading models.

## Key Features
- Enables agent-driven execution of ComfyUI workflows without backend modifications
- Provides cryptographic model identity and explicit approvals for reproducibility
- Supports durable run evidence with byte-identical output hashes and review records
- Offers opt-in managed startup for Windows portable ComfyUI installations
- Ensures no silent model downloads or switches, preserving user-supplied model authority

## Why It Matters for RAG Builders
It bridges agent frameworks with local GPU-based image generation while enforcing reproducibility, trust, and auditability, making it essential for RAG builders who need controlled, traceable AI workflows.
