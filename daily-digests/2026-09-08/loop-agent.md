## Summary
Loop is an autonomous agent framework that plans, executes, and verifies tasks in a sandboxed environment, producing tamper-evident receipts for replayable audits. It prioritizes security and verifiability over breadth, ensuring tasks are completed with least-authority principles and independent verification.

## Key Features
- Sandboxed task execution with default-deny network policies
- Tamper-evident, hash-chained receipts for verified task completion
- Independent verifier re-executes checks on fresh workspace copies
- Capability-scoped, signed skills to prevent tampering
- Multi-platform support (web, Telegram, Slack) with human-in-the-loop approvals

## Why It Matters for RAG Builders
Loop provides a secure, verifiable alternative to chat-first agents, ensuring tasks are completed with auditable proof and least-authority security, critical for AI stack builders prioritizing safety and reliability.
