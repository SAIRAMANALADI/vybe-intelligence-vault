## Summary
EdgeEver is an open-source, AI-native self-hosted notes workspace designed as a modern Evernote alternative with a three-pane layout, native AI agent integration, and portable data architecture. It supports zero-cost deployment on Cloudflare or self-hosted setups via Docker.

## Key Features
- Zero-cost deployment on Cloudflare or self-hosted via Docker with scalable storage
- Native AI agent integration via Model Context Protocol (MCP) for smart note organization and summarization
- Portable data architecture with lossless ZIP backups and SQLite-based open data format
- Classic three-pane layout with rich text and Markdown dual-view editing, Mermaid diagram rendering, and offline drafts
- Multi-device sync, public note sharing, and one-click rich copy for newsletters or blogs
