## Summary
claude-code-law-zero is a Windows-based tool designed to safely manage and clean up files generated by Claude Code projects, preventing accidental deletions through a deprecate-observe-clean workflow. It operates locally, ensuring project isolation and data privacy while providing rollback capabilities for recovered files.

## Key Features
- Safe file cleanup with deprecate-observe-clean workflow to prevent accidental deletions
- Project isolation to avoid cross-contamination between different Claude Code projects
- Rollback feature for restoring accidentally deleted files
- Quiet background operation with minimal CPU and memory usage
- Simple setup and installation for Windows users

## Why It Matters for RAG Builders
