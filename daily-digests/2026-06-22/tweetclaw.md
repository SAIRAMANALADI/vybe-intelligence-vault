## Summary
TweetClaw is an OpenClaw plugin for X/Twitter automation, enabling search, posting, media management, follower exports, monitoring, and giveaway draws. It integrates with Xquik's billing system for account-backed or pay-per-use operations.

## Key Features
- Search tweets, replies, and user timelines with structured tools
- Post tweets, replies, and manage media uploads/downloads
- Monitor accounts for new tweets, replies, retweets, and quotes
- Export followers and run giveaway draws with account-backed or pay-per-use billing
- Supports MPP pay-per-use for 31 read-only endpoints without requiring an account
