## Summary
A backend server for the xiaozhi-esp32 open-source smart hardware project, providing AI-driven voice interaction, device control, and multi-modal capabilities via MQTT, WebSocket, and MCP protocols. Supports ASR, TTS, LLM, VLLM, voiceprint recognition, and knowledge retrieval for ESP32-based devices.

## Key Features
- Supports multiple AI models (LLM, VLLM, ASR, TTS) via open interfaces for flexible integration.
- Enables real-time voice interaction, voiceprint recognition, and multi-device control via MQTT/WebSocket.
- Provides a web-based management console for device and user management, with multi-language support.

## Why It Matters for RAG Builders
It serves as a critical orchestration layer for ESP32-based AI hardware, enabling seamless integration of voice, vision, and device control in RAG and AI-driven systems.
