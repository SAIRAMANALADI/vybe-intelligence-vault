## Summary
Serena is an MCP-compatible toolkit that provides semantic code retrieval, editing, refactoring, and debugging capabilities for AI agents, functioning as an IDE at the symbol level. It integrates with any LLM client to enable faster, more reliable codebase operations in complex projects.

## Key Features
- Semantic code retrieval and editing via LSP or JetBrains plugin
- Cross-file symbol renaming, moving, and reference lookups
- Support for 40+ programming languages with extensible backend
