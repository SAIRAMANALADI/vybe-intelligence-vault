## Summary
OpenMetadata is an open-source platform designed to provide a unified metadata knowledge graph for AI and data management. It connects technical metadata, data quality signals, lineage, ownership, usage, policies, and organizational memory into a single context layer for AI assistants and agents.

## Key Features
- Unified metadata knowledge graph connecting 130+ connectors, lineage, and semantics
- Organizational memory preservation via MCP, APIs, and semantic search
- Governance and trust signals including data contracts, policies, and quality tests

## Why It Matters for RAG Builders
OpenMetadata provides the essential context layer that AI systems need to discover, understand, and trust enterprise data beyond raw database connectors.
