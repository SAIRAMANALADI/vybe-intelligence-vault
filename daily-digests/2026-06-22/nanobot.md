## Summary
nanobot is an open-source, lightweight personal AI agent designed for long-running tasks, real-world workflows, and multi-channel interactions. It emphasizes simplicity, modularity, and ownership while providing a bundled WebUI, chat integrations, memory, MCP support, and automation capabilities.

## Key Features
- Ultra-lightweight and modular agent core with extensible tools and MCP support
- Multi-channel chat integration (Telegram, Discord, Slack, WeChat, Email, etc.) with thread-aware sessions
- Built-in WebUI workbench for real-time agent interaction, file editing, and project workspaces
