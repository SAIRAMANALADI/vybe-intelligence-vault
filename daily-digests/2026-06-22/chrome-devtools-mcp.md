## Summary
Chrome DevTools for agents (`chrome-devtools-mcp`) is an MCP server that enables AI coding assistants to control and inspect a live Chrome browser, providing deep debugging, automation, and performance analysis capabilities through the Model-Context-Protocol (MCP).

## Key Features
- Enables AI agents to automate and inspect Chrome browsers via MCP for reliable debugging and automation.
- Provides advanced performance insights using Chrome DevTools traces and CrUX API integration.
- Supports network request analysis, screenshots, console logging, and heap snapshots for deep debugging.
