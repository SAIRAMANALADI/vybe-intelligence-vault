## Summary
A lightweight notification system that provides desktop and phone alerts for AI coding agents like Claude Code, Codex, and Cursor. It unifies notifications across platforms with zero dependencies and supports both toast notifications and push notifications via ntfy.

## Key Features
- Unified desktop notifications for Windows, macOS, and Linux using native OS tools
- Phone push notifications via ntfy.sh (no account required)
- Automatic setup and configuration for popular AI coding agents (Claude, Codex, Cursor, Gemini)
- Zero dependencies with pure Node.js built-ins
- Click-to-focus functionality to return to the AI tool window

## Why It Matters for RAG Builders
It ensures AI engineers never miss critical agent events like task completion or input requests, improving workflow efficiency and reducing context switching.
