## Summary
A live-updating index of LLM agent frameworks discovered on GitHub, refreshed every 15 minutes via GitHub Actions. It tracks new repos, ranks them by activity signals, and provides a structured feed for developers to query or browse.

## Key Features
- Continuously scans GitHub for new LLM agent frameworks using GitHub Search API
- Auto-updates every 15 minutes via GitHub Actions cron job
- Ranks frameworks by activity signals (stars, commits, etc.)
- Provides a structured, queryable feed of current agent frameworks
- Supports multiple languages and regions with localized READMEs

## Why It Matters for RAG Builders
It provides a real-time, reliable source of emerging LLM agent frameworks, enabling developers to stay updated on the latest tools and innovations in the field.
