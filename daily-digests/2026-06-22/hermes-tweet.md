## Summary
Hermes Tweet is a native plugin for the Hermes Agent that enables structured X (Twitter) automation through Xquik, providing tools for search, account management, tweet interactions, and social media monitoring as part of the Hermes ecosystem.

## Key Features
- Native Hermes Agent plugin with PyPI package distribution
- 99 agent-callable Xquik endpoints and 31 read endpoints for structured X/Twitter interactions
- Strict security model with read/action tool separation and default action disabling
- Comprehensive CI pipeline with linting, testing, security scanning, and dependency audits
- Bundled skills, slash commands, and documentation for seamless Hermes Agent integration

## Why It Matters for RAG Builders
Hermes Tweet provides a secure, structured, and agent-friendly way to integrate X/Twitter automation into Hermes workflows, enabling AI agents to perform social media tasks with proper access controls and least-privilege operations.
