## Summary
Bah is an AI-powered browser that executes natural language commands to navigate and interact with the web autonomously. It combines a full-featured browser with an AI agent that reads page content, performs real mouse/keyboard actions, and handles tasks like opening tabs, filling forms, or deleting emails.

## Key Features
- Executes natural language commands to automate web tasks (e.g., 'open Gmail and delete spam')
- Uses real mouse/keyboard inputs (not synthetic events) for reliable interaction with dynamic pages
- Supports both cloud (DeepSeek) and local (Ollama) AI models for flexibility
- Includes adblocking, safe browsing, and stealth features to avoid detection
- Provides a full-featured browser UI with tabs, history, downloads, and multi-language support
