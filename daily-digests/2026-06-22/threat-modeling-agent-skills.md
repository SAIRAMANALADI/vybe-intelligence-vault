## Summary
A repository providing agent skills for threat modeling frameworks like STRIDE, PASTA, and DREAD, enabling AI agents to perform structured threat identification and risk assessment with minimal setup.

## Key Features
- Pre-built agent skills for STRIDE, PASTA, and DREAD threat modeling frameworks
- Structured threat identification and risk scoring capabilities
- Integration with Mermaid.js for visual threat modeling diagrams
- Support for converting threat models to HTML with sortable tables
- Modular design for easy extension to additional frameworks
