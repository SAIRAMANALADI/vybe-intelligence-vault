## Summary
SiYuan is a privacy-first, self-hosted personal knowledge management (PKM) system that supports block-level note-taking, Markdown WYSIWYG editing, and fine-grained references with bidirectional linking for organizing and refactoring knowledge.

## Key Features
- Block-level reference and bidirectional linking for granular knowledge organization
- Markdown WYSIWYG editor with advanced formatting and embeds (charts, formulas, PDF annotations)
- Self-hosted, privacy-first architecture with Docker and multi-platform support (desktop, mobile, web) including AI integration via OpenAI API

## Why It Matters for RAG Builders
SiYuan provides a structured, block-level knowledge base that can serve as a high-quality data source for RAG pipelines, enabling fine-grained retrieval and contextual understanding of user-generated content.
