## Summary
TariffBrain is an AI-native trade compliance microservice that autonomously classifies products, calculates duties, and screens for regulatory agencies across 217 jurisdictions using structured reasoning with large language models.

## Key Features
- Autonomous HTS classification across 217 jurisdictions using AI reasoning
- Real-time duty calculation with support for multiple rate types
- PGA screening against 50+ regulatory agencies (FDA, FCC, REACH, etc.)
- Explainable AI outputs with full citations and confidence scoring
- Profile-based configuration for per-client or per-region customization
