## Summary
PM Review Copilot is a set of skills designed for product managers to manage project memory and review outputs from AI agents. It provides structured review of long documents, version drift detection, hallucination checks, and label consistency audits to help PMs efficiently identify gaps, conflicts, and risks in multi-project workflows.

## Key Features
- Local project memory persistence for durable context storage and retrieval
- Structured review of PRDs, strategies, and multi-round agent outputs
- Version drift detection to identify deleted constraints, changed metrics, or altered assumptions
- Label consistency auditing for multi-rater or repeated model labeling outputs
- Memory lifecycle management with decay and prioritization mechanisms

## Why It Matters for RAG Builders
It streamlines the critical bottleneck of human review in AI agent workflows by automating memory management, risk detection, and consistency checks, enabling PMs to focus on high-value decision-making.
