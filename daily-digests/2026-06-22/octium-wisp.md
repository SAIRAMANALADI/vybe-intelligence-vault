## Summary
Octium is an open-source CLI terminal client that integrates OpenAI GPT and Anthropic Claude APIs, enabling developers to interact with AI models directly from the command line. It supports real-time streaming responses, multilingual translation, code generation, and offline caching for enhanced productivity.

## Key Features
- Dual API integration (OpenAI GPT and Anthropic Claude) with seamless switching
- Real-time streaming responses for code generation and translations
- Offline caching and context window management for efficient token usage
- Multilingual support for 50+ languages with auto-detection
- Session logging and secure local key management
