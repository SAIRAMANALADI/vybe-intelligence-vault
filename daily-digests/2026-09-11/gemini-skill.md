## Summary
A browser automation tool that controls the Gemini web interface via Chrome DevTools Protocol (CDP) to enable AI image generation, text conversations, and image extraction. It also includes an MCP server for programmatic access and supports Atlas Cloud Provider integration.

## Key Features
- Automates Gemini web interface operations (image generation, text chat, image extraction) via CDP
- Provides an MCP server for seamless integration with AI agents and tools
- Supports Atlas Cloud Provider for OpenAI-compatible API access
- Daemon mode for persistent browser sessions with automatic cleanup
- Includes anti-detection measures (Stealth plugin) to avoid website blocking

## Why It Matters for RAG Builders
This tool enables programmatic control of Gemini's web interface, making it essential for automating AI-driven workflows like image generation and text extraction without manual intervention.
