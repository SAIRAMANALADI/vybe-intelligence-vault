## Summary
Editmamei is a Model Context Protocol (MCP) server that enables natural-language photo editing by orchestrating Adobe Photoshop through AI-driven commands. It acts as a bridge between AI assistants and Photoshop, allowing users to describe edits in plain language while Photoshop executes them using standard tools like adjustment layers, masks, and filters.

## Key Features
- Natural-language photo editing via AI orchestration without generative model pixel manipulation
- Integration with Adobe Photoshop 2026 for non-destructive edits using standard tools (layers, masks, adjustments)
- On-device scene awareness and object/face detection for precise selections and edits
- Support for both Community (free) and Pro (paid) feature sets with advanced capabilities like Camera Raw develop and warp tools
- Privacy-focused with local execution and optional anonymous telemetry

## Why It Matters for RAG Builders
Editmamei bridges the gap between AI assistants and professional photo editing tools, enabling seamless, natural-language-driven workflows that leverage existing Photoshop installations for precise, non-destructive edits.
