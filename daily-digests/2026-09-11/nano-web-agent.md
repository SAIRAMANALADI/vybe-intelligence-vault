## Summary
A Chrome extension that transforms LLMs (Google Gemini API or Ollama local models) into autonomous web agents capable of perceiving, reasoning, and acting within browser environments. It automates tasks like form filling, clicking, and scrolling by converting web pages into simplified accessibility trees and executing tool-based actions.

## Key Features
- Multi-LLM support (Google Gemini API and Ollama local models) with seamless switching
- Efficient accessibility tree extraction for lightweight DOM representation and reduced token usage
- Real-time browser interaction via tool calls (click, type, scroll, wait, finish)
- Visual agent status indicator for transparency and manual interruption
- Resilient asynchronous agent loop with continuous perception-action feedback

## Why It Matters for RAG Builders
It enables RAG builders to integrate autonomous web agents that can interact with live web interfaces, expanding AI capabilities beyond static data retrieval to dynamic task execution.
