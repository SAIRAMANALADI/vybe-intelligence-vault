## Summary
A lightweight web portal designed to browse learning workspaces on a headless Hermes Agent server. It dynamically scans filesystem directories, indexes lessons, and serves wrapped lesson views in the browser without requiring a database or external services.

## Key Features
- Automatic discovery of learning workspaces via filesystem scanning
- Dynamic lesson wrapping with minimal HTML/CSS injections for navigation
- Lightweight FastAPI backend with no external dependencies
- Systemd service integration for easy deployment and management
- Supports raw reference document access alongside wrapped lessons

## Why It Matters for RAG Builders
It provides a simple, filesystem-driven UI for browsing and serving structured learning content, reducing complexity for AI agents managing educational materials.
