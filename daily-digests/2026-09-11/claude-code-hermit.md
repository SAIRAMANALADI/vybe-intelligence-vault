## Summary
Claude Code plugin that transforms a Claude Code instance into a 24/7 autonomous agent with stateful operations, learning loops, and proactive task execution. It enables persistent, cost-aware, and observable agent behavior with operator-gated decision-making and remote control capabilities.

## Key Features
- 24/7 autonomous agent with stateful operations and session management
- Operator-gated proposal system for self-improvement and learning loops
- Remote control and multi-channel notifications (Discord, Telegram)
- Cost-aware scheduling with zero model token usage for quiet operations
- Native integration with Claude Code Artifacts for observability and reporting

## Why It Matters for RAG Builders
It enables the creation of persistent, self-improving AI agents that can operate autonomously with minimal human intervention, reducing operational overhead and improving task continuity for RAG and AI stack builders.
