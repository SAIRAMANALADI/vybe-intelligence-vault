## Summary
A one-command installer and daily wellness operator that transforms the Hermes agent into a local-first wellness profile with 15 wellness MCP connectors, onboarding, skills, and recovery-aware operating models. All data and credentials remain on the user's machine.

## Key Features
- One-command setup for a dedicated Hermes wellness profile with 15 pre-configured MCP connectors (WHOOP, Garmin, Oura, Strava, Fitbit, etc.)
- Recovery-aware operating model (SOUL.md) and onboarding (ONBOARDING.md) for context-aware agent interactions
- Local-first architecture ensuring no tokens or data leave the user's machine
- Daily operator skills for recovery, nutrition, and setup planning with real-time data access
- Pre-validated agent-readiness with 90–97/100 scores on MCP-scorecard checks

## Why It Matters for RAG Builders
It provides a turnkey, local-first solution for integrating multiple wellness data sources into an AI agent framework, reducing setup complexity and ensuring data privacy for RAG builders.
