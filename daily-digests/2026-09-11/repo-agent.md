## Summary
Free Repo Agent is a VS Code extension that provides an autonomous AI coding agent for editing files, running commands, and performing repo-aware tasks. It supports model switching, vision-based UI component generation, MCP plugins, and AI-powered code review with self-verification capabilities.

## Key Features
- Autonomous multi-file code editing with inline approvals (Keep/Undo)
- Repo-aware chat with deep repository indexing and retrieval
- Self-verifying edits with auto-typecheck/build and error fixing
- Vision-based UI component generation from screenshots
- Staff-engineer level AI code review with customizable rules

## Why It Matters for RAG Builders
It provides a free, lightweight alternative to paid AI coding agents with autonomous editing, repo awareness, and verification capabilities, making it essential for developers seeking cost-effective AI-assisted coding workflows.
