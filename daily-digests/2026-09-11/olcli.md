## Summary
olcli is a command-line interface for Overleaf that enables bidirectional sync, local editing, and remote compilation of LaTeX projects directly from the terminal. It supports self-hosted instances and integrates with Git and AI agents via an MCP server.

## Key Features
- Bidirectional sync between local and Overleaf projects with conflict detection
- Git remote helper for native git workflows with Overleaf projects
- MCP server for AI assistant integration (Claude, Cursor, Windsurf)
- Remote compilation and PDF generation with support for multi-document projects
- Smart ignore patterns for LaTeX build artifacts and OS noise

## Why It Matters for RAG Builders
It enables seamless local editing and version control for LaTeX projects while leveraging Overleaf's cloud compilation, making it ideal for AI-driven workflows and automated pipelines.
