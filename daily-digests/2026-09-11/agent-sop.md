## Summary
Agent SOP provides a standardized operating procedure (SOP) framework for Claude Code sessions, ensuring consistent context management, state tracking, and workflow enforcement across multiple agents. It includes a fixed file structure, six non-negotiable rules, slash commands for session lifecycle management, and a compliance checker to enforce discipline.

## Key Features
- Fixed file set for durable session context (Backlog, feature-map, agent-memory, build-plans)
- Six non-negotiable rules and enforcement gates via machine-checkable scripts
- Support for 3-5 parallel agents on separate git worktrees with conflict-free tracking
- Five slash commands (/restart-sop, /update-sop, /update-agent-sop, /migrate-to-multi-agent, /finish) for session lifecycle management
- Compliance checker scoring projects 0-100 across 94 checks for code projects

## Why It Matters for RAG Builders
Agent SOP ensures durable, cross-session context and state tracking for AI agents, reducing context loss and improving consistency in multi-agent workflows.
