## Summary
Mythic Agent CLI is a Viking-themed terminal-based AI coding assistant that functions as a multi-agent system with a Terminal User Interface (TUI). It integrates advanced LLM capabilities, GitHub automation, and sub-agent coordination to streamline coding workflows.

## Key Features
- Interactive TUI with Tokyo Night theme for immersive coding experience
- Six specialized sub-agents (Skald, Architect, Forge Worker, Auditor, Cartographer, Scribe) for task delegation
- Seamless GitHub integration with slash commands for commits, issues, and PRs
- Multi-provider LLM support (OpenRouter, DeepSeek, OpenAI, OpenCode Go)
- Command approval system for safe execution of terminal commands

## Why It Matters for RAG Builders
It provides a structured, multi-agent framework for AI-driven coding with built-in safety and automation, reducing context switching and improving developer productivity.
