## Summary
Pandora is a local-first agent platform offering a Tauri desktop app and Rust CLI, both powered by a governed Rust runtime. It enables secure, policy-bound execution of AI agents with features like effect permits, memory management, and adversarial resilience through a structured authorization pipeline.

## Key Features
- Governed effect execution pipeline with immutable execution profiles and one-shot permits
- Local-first architecture with Tauri desktop and Rust CLI for secure, offline-capable operations
- Durable session management and multi-agent workflows with scoped memory and cryptographic device trust
- Adversarial resilience through quarantine boundaries, fuzz-tested parsers, and append-only evidence chains
- Modular package system with Harnesses, Genes, and providers for extensible agent capabilities

## Why It Matters for RAG Builders
Pandora provides a robust, security-first framework for building and governing AI agents with strict policy enforcement and auditability, critical for RAG builders requiring controlled, reliable agent interactions.
