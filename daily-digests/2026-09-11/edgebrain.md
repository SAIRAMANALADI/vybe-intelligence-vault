## Summary
EdgeBrain is an open-source edge AI platform enabling autonomous real-world decision systems to run locally without cloud dependencies. It simulates IoT devices, processes sensor data, and executes AI-driven actions in real-time.

## Key Features
- Multi-agent AI system (Data, Decision, Action agents) with plugin architecture
- Real-time IoT device simulation (11 devices across 3 rooms) with configurable sensors
- Hybrid decision engine combining threshold rules, anomaly detection (Z-Score, IQR, Gradient), and predictive analytics
- Production-grade infrastructure with Docker Compose, PostgreSQL, Redis, and MQTT
- Interactive React dashboard with 5 pages for monitoring, analytics, and system configuration

## Why It Matters for RAG Builders
EdgeBrain provides a complete, local-first framework for building and deploying AI-driven edge systems, eliminating cloud dependencies and enabling privacy-preserving, low-latency automation.
