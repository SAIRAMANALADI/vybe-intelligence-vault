## Summary
A Model Context Protocol (MCP) server that bridges AI models with WinDbg/CDB for Windows crash dump analysis and remote debugging, enabling natural language interaction with debugging tools.

## Key Features
- Natural language interface for WinDbg/CDB commands via MCP-compatible clients
- Supports crash dump analysis, live remote debugging, and batch processing
- Multiple transport options (stdio and streamable-http)
- Customizable with filter scripts for output manipulation (e.g., PII redaction)
- Comprehensive documentation and client configuration guides

## Why It Matters for RAG Builders
It enables AI models to directly interact with Windows debugging tools, automating crash analysis and reducing manual debugging effort for RAG and AI stack builders.
