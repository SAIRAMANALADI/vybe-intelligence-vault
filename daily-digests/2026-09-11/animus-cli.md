## Summary
Animus CLI is a Rust-based orchestrator for autonomous AI agent teams, enabling solo founders and indie hackers to manage parallel projects by defining agent workflows in YAML, scheduling tasks, and automating PRs while integrating with coding agents like Claude, Codex, and Gemini.

## Key Features
- Parallel agent execution across multiple projects using git worktrees
- Plugin-first architecture with modular providers, subjects, and workflow runners
- Local-first execution with no external code dependencies
- YAML-based workflow definitions for task automation and PR generation
- Daemon scheduling with health monitoring and structured event streaming

## Why It Matters for RAG Builders
Animus CLI enables RAG builders to orchestrate multiple AI agents efficiently, reducing manual coordination overhead and accelerating autonomous workflow execution across diverse projects.
