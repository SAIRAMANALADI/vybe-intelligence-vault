## Summary
A security testing framework designed to evaluate the robustness of AI agents against adversarial attacks across multiple protocols (MCP, A2A, L402, x402) and payment systems. It includes 595 executable security tests to assess protocol integrity, operational governance, and decision governance.

## Key Features
- 595 executable security tests across 43 modules for MCP, A2A, L402, and x402 protocols
- Three-layer security testing: protocol integrity, operational governance, and decision governance
- Active exploitation and adversarial testing rather than static analysis
- Comprehensive coverage of payment systems including Visa TAP, Mastercard Agentic Tokens, and settlement finality
- Integration with AIUC-1 certification and NIST AI 800-2 standards

## Why It Matters for RAG Builders
It provides critical adversarial testing capabilities to identify vulnerabilities in AI agent systems before deployment, ensuring robustness against real-world attacks.
