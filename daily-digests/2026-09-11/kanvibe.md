## Summary
KanVibe is a keyboard-first desktop Kanban workspace designed to streamline AI coding workflows by integrating branch-based task tracking with real-time terminal sessions and AI agent hooks for automatic status updates.

## Key Features
- Real-time Kanban board with 5 task statuses (TODO, PROGRESS, PENDING, REVIEW, DONE) and drag-and-drop task management
- Branch-based task creation with automatic git worktree and terminal session setup (tmux/zellij)
- AI agent hooks integration (Claude Code, Gemini CLI, Codex CLI, OpenCode) for automatic status tracking
- Keyboard-first controls with Vim-style navigation, quick search, and task actions
- Multi-pane terminal layouts with customizable commands and SSH remote support

## Why It Matters for RAG Builders
KanVibe streamlines AI coding workflows by unifying task tracking, terminal sessions, and AI agent automation into a single keyboard-driven interface, reducing context switching and improving productivity for RAG and AI stack builders.
