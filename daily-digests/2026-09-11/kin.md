## Summary
Kin is a semantic system of record for AI-written software that records software as a graph of entities, relations, changes, and provenance. It enables humans and AI agents to query and review the impact of changes before they merge, providing exact context instead of re-reading repositories.

## Key Features
- Graph-based semantic record of software entities and relationships
- Pre-merge impact analysis for AI-written changes using `kin impact`
- Built-in MCP server for AI agent integration
- Transparent filesystem projection via `kin-vfs` for compatibility with existing tools
- Hosted collaboration and control plane (KinLab) for team workflows

## Why It Matters for RAG Builders
Kin provides the critical semantic layer needed to validate AI-generated code changes before they merge, reducing risk and improving reliability in AI-driven software development workflows.
