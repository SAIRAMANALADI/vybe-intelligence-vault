## Summary
Talunor is a terminal-based, autonomous AI agent written in Go, featuring a multi-tier memory system backed by SQLite. It serves as both a functional agent and a pedagogical guide for building cognitive-loop agents with guardrails, emphasizing software engineering over prompt engineering.

## Key Features
- Multi-tier memory system with SQLite for persistent, auditable storage
- Built-in tools (calculator, time, recall_memory, bash, web_fetch) with approval gating
- Sandboxed execution environments (nerdctl or namespaces) for safe tool use
- Step-by-step course and documentation for building cognitive-loop agents
- Supports both local (Ollama) and hosted (OpenRouter) model providers

## Why It Matters for RAG Builders
Talunor provides a transparent, engineering-focused blueprint for building trustworthy AI agents with persistent memory and guarded tool use, making it essential for developers seeking to understand or replicate such systems.
