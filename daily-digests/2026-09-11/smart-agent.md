## Summary
Smart Agent is a multi-platform AI content analysis engine that automates data collection and analysis across 7 Chinese social media platforms (e.g., Zhihu, Bilibili, Xiaohongshu, Douyin). It uses 7 specialized AI agents to generate structured reports on trending content, competitor strategies, and user sentiment.

## Key Features
- 7-platform data collection (Zhihu, Bilibili, Xiaohongshu, Douyin, Kuaishou, Weibo, Tieba) with anti-scraping bypass
- 7 specialized AI agents for trend analysis, sentiment reading, copywriting, and content remixing
- LangGraph-based orchestration with CriticAgent for self-correction and quality control
- MCP Server for natural language integration with AI assistants like Claude Desktop
- Go binary and Docker support for zero-dependency deployment

## Why It Matters for RAG Builders
Smart Agent provides a scalable framework for automating multi-platform social media analysis and AI-driven content strategy, reducing manual effort and enabling data-driven decision-making for RAG builders.
