## Summary
Package Spelunker is an evidence-backed repository-intelligence and retrieval engine for TypeScript, JavaScript, Node.js, and monorepos. It normalizes and links workspace code to exact package APIs, compiles task-specific context for coding agents, and avoids executing inspected package code.

## Key Features
- Normalizes workspace packages, projects, and symbols without executing code
- Links local code to exact dependency APIs and registry artifacts
- Produces versioned, evidence-backed context packs within token/item budgets
- Supports npm, pnpm, Yarn, and Bun monorepos with deterministic snapshots
- Exposes analysis via CLI and MCP server for agent integration

## Why It Matters for RAG Builders
It provides critical, evidence-backed context for AI agents working with monorepos and package ecosystems, enabling accurate dependency resolution and semantic analysis without executing untrusted code.
