## Summary
A Godot plugin that enables Kimi Code to play Godot games in a turn-based manner, bridging AI and human gameplay loops by compensating for AI limitations like low frame sampling, imprecise pixel understanding, and slow decision-making. It integrates seamlessly with Godot's input system and provides offline documentation for reference.

## Key Features
- Turn-based AI gameplay loop with human-like input handling via Godot's InputMap and `_unhandled_input`
- Compensates for AI limitations (low FPS, pixel imprecision, timing issues) with slow-motion, telemetry, and frame-number embedding
- Zero-dependency autoload script (`pilot.gd`) and bash runner (`run.sh`) for easy integration into any Godot ≥4.4 project
- Supports AI playtesting and human-AI collaborative gameplay with real-time feedback and demo recording
- Provides offline pinned documentation for Godot engine classes

## Why It Matters for RAG Builders
It enables AI agents like Kimi to interact with games in a structured, human-like manner, reducing the gap between AI and human gameplay for testing and automation.
