## Summary
Glyphic is a rendering engine that converts structured JSON input into deterministic SVG, PNG, and React Flow outputs for 18 diagram types. It serves as infrastructure for LLMs and agents to generate production-quality diagrams without relying on DSLs, headless browsers, or vendor-locked SaaS solutions.

## Key Features
- Supports 18 diagram types (architecture, sequence, ERD, UML, Gantt, etc.) with a single validated schema
- Deterministic output (byte-identical SVG/PNG) without headless browsers or Chromium
- Native MCP server integration for seamless AI agent tool calls
- High-performance Rust-based rasterization for PNG output
- React Flow JSON output for interactive diagrams

## Why It Matters for RAG Builders
Glyphic eliminates the need for LLMs to generate fragile DSLs or rely on vendor-locked diagram services, providing a robust, schema-driven engine for producing accurate, production-ready diagrams from structured data.
