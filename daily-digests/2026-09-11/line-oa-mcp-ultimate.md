## Summary
A Model Context Protocol (MCP) server that enables AI agents to operate LINE Official Accounts (OAs) through natural language, eliminating manual UI interactions. It supports messaging, rich menus, coupons, insights, and LINE Shopping (MyShop) integrations with zero-setup image hosting and multi-OA management.

## Key Features
- 51+ tools for LINE OA operations (messaging, rich menus, coupons, insights, and LINE Shopping)
- Zero-setup image hosting for Rich Messages (attach an image and send it directly)
- Multi-OA management with runtime switching and fan-out capabilities for agencies
- Thai localization with full i18n support and documentation
- Pre-flight validation, quota guardrails, and quiet-hour warnings for safe operations

## Why It Matters for RAG Builders
It bridges AI agents with LINE Official Accounts, enabling natural-language automation for marketing, customer support, and e-commerce operations without manual UI interactions.
