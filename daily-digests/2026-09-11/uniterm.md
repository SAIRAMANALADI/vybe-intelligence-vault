## Summary
uniTerm is a cross-platform terminal application supporting 30+ protocols (SSH, RDP, SFTP, databases, Kubernetes) with an integrated autonomous AI agent for multi-turn shell command execution. It combines remote access, file transfer, and container management in a single UI with advanced personalization features.

## Key Features
- Supports 30+ protocols including SSH, RDP, SFTP, databases, and Kubernetes for comprehensive remote access
- Built-in autonomous AI agent that plans and executes multi-turn shell commands without manual intervention
- Cross-platform support (Windows, macOS, Linux) with cloud sync for settings and connections
- Highly customizable UI with split panes, themes, and keyboard-driven workflows
- Integrated file transfer, database clients, and container management in a single application

## Why It Matters for RAG Builders
uniTerm provides a unified interface for remote system access and AI-driven automation, reducing context switching for developers and enabling seamless integration of AI agents into terminal workflows.
