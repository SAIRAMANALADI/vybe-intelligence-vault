## Summary
Context Forge is a structured project management tool designed to accelerate large-scale AI-driven development by maintaining traceable, hierarchical project state and providing AI agents with full context awareness. It enables multi-project management with phases, slices, tasks, and worktrees while offering CLI, MCP server, and slash command interfaces.

## Key Features
- Hierarchical project state tracking with phases, slices, and tasks for AI agents
- Multi-interface access (CLI, MCP server, slash commands, and visualizer)
- Structured JSON output for AI pipelines and automation
- Worktree support for parallel initiatives without conflicts
- Review gating for deterministic workflow progression

## Why It Matters for RAG Builders
