## Summary
A desktop installer application designed to simplify the setup of Claude Code and associated development tools across Windows, macOS, and Linux. It provides a guided GUI for installing, managing, and reviewing tools, plugins, and Convex components without requiring terminal commands or manual configurations.

## Key Features
- Guided GUI for installing Claude Code and optional tools without terminal commands
- Curated catalog of 35+ Claude Code tools and 145+ Convex components
- Cross-platform support for Windows, macOS, and Linux
- Dry-run mode for reviewing installation plans before execution
- Built-in tool advisor (Compass) for private guidance and recommendations

## Why It Matters for RAG Builders
It simplifies the setup and management of Claude Code and related tools, reducing friction for AI engineers and developers building RAG systems.
