## Summary
Yums AI is a read-only Gmail inbox analyzer that uses OpenAI's API to classify and summarize unread emails into 'Actions' (requiring a response) and 'Notices' (informational). It authenticates via OAuth2, processes emails securely, and outputs structured reports without modifying the inbox.

## Key Features
- Read-only Gmail inbox access via OAuth2 with no password handling
- AI-powered classification of emails into 'Actions' and 'Notices' using OpenAI's API
- Structured JSON output for reliable parsing and summary generation
- Terminal and Markdown report generation with timestamped outputs
- Standalone test script for validating classification behavior without live Gmail access

## Why It Matters for RAG Builders
Yums AI streamlines email triage for RAG builders by automating the classification of unread emails, reducing manual review time and enabling structured data extraction for downstream AI applications.
