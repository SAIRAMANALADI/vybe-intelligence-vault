## Summary
Portawhip is a lightweight control plane that discovers, synchronizes, and routes capabilities (tools, skills, MCP servers, and hooks) across AI coding agents like Claude Code, Cursor, and VS Code. It provides a unified interface to manage and align agent surfaces without bloating prompts with unnecessary context.

## Key Features
- Discovers and catalogs installed capabilities across multiple AI coding agents and surfaces
- Hybrid lexical + local semantic routing engine for precise capability matching
- Synchronizes tools, skills, and hooks across hosts with read-only safety defaults
- Interactive TUI and CLI tools for inventory, routing, and configuration management
- Privacy-focused with local routing and opt-in package execution

## Why It Matters for RAG Builders
Portawhip eliminates context bloat in RAG systems by dynamically surfacing only the relevant capabilities for a given task, reducing prompt size and improving agent efficiency.
