## Summary
An AI-powered skill for engineering academic papers into compilable LaTeX projects from heterogeneous input formats (DOCX, PDF, Markdown, etc.). Supports optional Chinese-to-English translation, 8+1 journal template integration, asset management, and 12-item quality assurance with automated compilation.

## Key Features
- Multi-format input support (DOCX, PDF, Markdown, LaTeX, PPTX, XLSX)
- Built-in 8+1 journal templates (Elsevier, Springer, MDPI, etc.) with template migration
- Optional Chinese-to-English academic translation with terminology memory
- Automated LaTeX compilation with pdflatex/xelatex and bibtex
- 12-item quality assurance pipeline covering translation, LaTeX compliance, and asset integrity

## Why It Matters for RAG Builders
It streamlines the conversion of diverse academic documents into standardized LaTeX projects, reducing manual effort and ensuring consistency for RAG pipelines requiring structured academic content.
