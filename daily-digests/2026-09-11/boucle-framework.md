## Summary
Boucle Framework provides enforceable hooks for Claude Code to validate and restrict unsafe or unauthorized commands, addressing gaps in CLAUDE.md rules and permission systems. It includes 7 standalone hooks, an `enforce-hooks` policy tool, and a searchable corpus of 1,900+ tests and known limitations.

## Key Features
- Enforces CLAUDE.md rules and permissions that are otherwise unenforced by default
- 7 standalone hooks plus `enforce-hooks` for policy management and audit tooling
- 1,900+ automated tests and a searchable corpus of known limitations with severity ratings
- Real-time verification of hook effectiveness using Claude-style JSON payloads
- Cross-platform support (macOS, Linux, Windows) with CI/CD integration guides

## Why It Matters for RAG Builders
It provides critical safety enforcement for AI agents like Claude Code, preventing irreversible actions and ensuring compliance with defined rules in RAG and agentic workflows.
