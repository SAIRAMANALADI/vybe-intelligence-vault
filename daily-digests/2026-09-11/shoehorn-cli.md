## Summary
Shoehorn CLI is a command-line interface for the Shoehorn Intelligent Developer Platform, enabling developers to interact with service catalogs, manage governance actions, run Forge workflows, and handle GitOps resources via a rich terminal-based TUI.

- Support for Forge workflows, governance actions, and GitOps resources
- Authentication and identity verification via CLI commands
