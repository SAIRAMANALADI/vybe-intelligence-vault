## Summary
A high-performance Go-based CLI tool and MCP server for macOS that integrates with Apple Music/iTunes, offering ultra-fast SQLite FTS5 search, smart playback control, and 14 MCP tools for AI/LLM applications.

## Key Features
- Ultra-fast SQLite FTS5 search with <7ms query performance
- 14 MCP tools for AI/LLM applications (search, playback, EQ, radio stations)
- Database-first architecture with normalized SQLite schema and persistent Apple Music IDs
- Smart playback control with ID-based track lookup and playlist context support
- Context-aware cancellation propagation from MCP requests to SQLite queries and JXA processes

## Why It Matters for RAG Builders
It enables AI/LLM applications to seamlessly interact with Apple Music libraries via the MCP protocol, providing fast search and playback control for RAG systems.
