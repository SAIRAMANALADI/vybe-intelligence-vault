## Summary
aussie-shield is an autonomous, privacy-first threat intelligence engine designed to detect scams targeting Australian residents and businesses. It provides real-time analysis of messages, URLs, ABNs, and phone numbers using local and external threat feeds while prioritizing user privacy.

## Key Features
- Multi-vector threat detection (URLs, messages, ABNs, phone numbers) tailored for Australian scam patterns
- 100% client-side evaluation for private checks with optional deep analysis via Cloudflare Workers AI
- Integration with MCP servers for AI assistants like Claude Desktop
- Local allowlist and impersonation analysis with external threat feed lookups (RDAP, Google Safe Browsing, etc.)
- ABN verification with live Australian Business Register API and name mismatch detection for invoice fraud
