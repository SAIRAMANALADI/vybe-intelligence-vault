## Summary
ellmos-homebase-mcp is an alpha MCP server for local-first LLM orchestration, providing memory, knowledge management, routing, swarm patterns, API probing, persistent state, and plugin discovery in a single stdio server. It targets local LLMs (Ollama, Qwen, Llama) with SQLite-based storage and supports external LLM providers as MCP clients.

## Key Features
- 45 MCP tools across 11 functional modules (memory, knowledge, state, routing, swarm, API probing, automation, plugins, etc.)
- SQLite-based persistent storage with no cloud dependency
- Support for local LLMs (Ollama, Qwen, Llama) and external providers via MCP clients
- Multi-language i18n support (en, de, es, zh, ja, ru)
- Modular architecture with optional canonical engine integration

## Why It Matters for RAG Builders
It provides a critical local-first orchestration layer for RAG builders, enabling persistent memory, knowledge management, and multi-agent swarm patterns without cloud dependencies.
