## Summary
DEVLYN-CLI is a context engineering toolkit for AI coding agents that provides structured prompts, agent orchestration, and automated pipelines for tasks like debugging, code review, UI design, and product specs. It enables hands-free development workflows through skills like ideation, resolution, and design.

## Key Features
- Multi-agent skill installation and management (Claude Code, Codex, Grok, omp, Pi)
- Structured ideation and spec generation with `/devlyn:ideate`
- Hands-free resolution pipeline with `/devlyn:resolve` for coding tasks
- Queue-based task management with `/devlyn:queue` for unattended execution
- Benchmarking and pair-mode verification for quality assurance

## Why It Matters for RAG Builders
It streamlines AI agent workflows by providing a standardized, orchestrated pipeline for ideation, resolution, and verification, reducing manual intervention and improving consistency in AI-driven development tasks.
