## Summary
Delx Wellness is a registry of open-source Model Context Protocol (MCP) servers that provide local-first connectors for wearables, nutrition, and health data. It enables AI agents to read real-world body context (sleep, HRV, workouts, food) without data ever leaving the user's machine.

## Key Features
- Registry of 16+ open-source MCP servers for wearables and nutrition data
- Local-first privacy with zero data leaving the user's machine
- Auto-detection and composition of multiple connectors via `delx-living-body`
- Rule-based synthesis engine for unified wellness context
- Pre-configured profiles for popular AI agents (Claude, Cursor, ChatGPT, Hermes, OpenClaw)

## Why It Matters for RAG Builders
It provides essential local-first connectors for AI agents to access real-world wellness data, enabling richer and more personalized RAG applications without compromising user privacy.
