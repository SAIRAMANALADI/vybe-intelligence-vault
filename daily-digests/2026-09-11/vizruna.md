## Summary
Vizruna is a local-first, browser-based workspace for developing, debugging, and managing Pi-powered AI agents with visual controls, evidence tracking, and versioned configurations. It provides a unified interface for agent composition, runtime monitoring, and performance evaluation.

## Key Features
- Visual Agent Composer with versioned snapshots and immutable configurations
- Real-time runtime monitoring with token/usage tracking and tool execution visibility
- Agent Evaluation Studio for regression testing and performance comparison
- Prompt Contract v2 with evidence-based validation and provenance tracking
- Context Governor for large-text compression and evidence preservation
