## Summary
DiviOps provides an AI harness for WordPress site authoring, enabling AI agents to interact with Divi and WordPress via an MCP server, WordPress plugin, and skills. It facilitates Divi-native page building, schema introspection, design token management, and secure custom field operations.

## Key Features
- MCP server for AI agent integration with WordPress/Divi via REST API
- DiviOps Agent WordPress plugin for schema, design tokens, and SCF/CPT management
- Pre-built skills (e.g., divi-5-builder) for Divi block format validation and design rules
- 74+ tools for page authoring, design system management, schema introspection, and WP-CLI passthrough
- Pro plugin for advanced features, license gating, and paid coverage slices

## Why It Matters for RAG Builders
DiviOps bridges AI agents with WordPress/Divi ecosystems, enabling automated, schema-aware site authoring and management for RAG pipelines.
