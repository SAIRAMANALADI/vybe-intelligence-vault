## Summary
dMoERA MCP Server is a Model Context Protocol (MCP) server that exposes the dMoERA Creator API as tools for AI agents, enabling discovery, backtesting, deployment, and management of crypto trading strategies and hedge funds.

## Key Features
- Exposes dMoERA Creator API as MCP tools for AI agents (Claude, Cursor, etc.)
- Supports discovery of trading domains, bots, and market regimes
- Enables sandboxed backtesting and full 7-stage strategy validation
- Facilitates hedge fund creation, management, and risk cap customization
- Integrates with tournament systems for competitive strategy evaluation

## Why It Matters for RAG Builders
