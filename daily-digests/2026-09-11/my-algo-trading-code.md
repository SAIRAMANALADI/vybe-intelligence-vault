## Summary
A comprehensive algorithmic trading suite for NIFTY/BANKNIFTY/FINNIFTY indices featuring signal generation, backtesting, multithreaded paper/live trading, and broker integration. Includes an optional LLM-based trading agent for discretionary price-action strategies.

## Key Features
- Multithreaded paper/live trading runner with per-strategy toggles and risk controls
- 13+ signal generators (SMA, Bollinger Bands, RSI, etc.) and backtesting framework
- Optional LLM trading agent (Claude-based) for discretionary price-action strategies
- Broker-agnostic execution with Kotak Neo, Shoonya, Flattrade, and Dhan support
- Real-time market data via WebSocket or REST, with config-drift audit and CI/CD gates
