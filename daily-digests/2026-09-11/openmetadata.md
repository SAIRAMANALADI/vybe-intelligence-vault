## Summary
OpenMetadata is an open-source platform designed to provide a unified context layer for AI and data systems, offering metadata management, data cataloging, governance, and organizational memory through a knowledge graph. It connects technical metadata, quality signals, lineage, semantics, and tribal knowledge to enable AI assistants and agents to discover, understand, and trust enterprise data.

## Key Features
- Unified metadata knowledge graph connecting 130+ connectors for technical, operational, and semantic metadata
- Organizational memory system preserving tribal knowledge as governed memory nuggets tied to data assets
- Semantic search and MCP server enabling AI assistants to interact with metadata via natural language
- Data quality, lineage, and governance features including policies, data contracts, and certifications
- Open standards support (OpenLineage, DCAT, DPROD, PROV-O) for interoperability and schema-first architecture

## Why It Matters for RAG Builders
OpenMetadata provides the essential context, memory, and governance layer that AI systems need to safely and effectively reason over enterprise data, eliminating the need for raw database connectors alone.
