## Summary
Claudexor is a local-first control plane for managing AI coding agents like Codex CLI, Claude Code, Cursor CLI, and OpenCode. It provides a unified interface for running, auditing, and optimizing agent sessions with features like multi-account credential profiles, quota tracking, cross-model review, and deterministic execution.

## Key Features
- Unified interface for multiple AI coding agents (Codex, Claude, Cursor, OpenCode)
- Multi-account credential profiles with isolated login and quota tracking
- Cross-model review and best-of-N race execution with independent reviewers
- Deterministic gates, protected paths, and honest budget/quota accounting
- Local-first architecture with no telemetry, files as source of truth

## Why It Matters for RAG Builders
Claudexor provides essential orchestration and governance for AI coding agents, enabling reliable, auditable, and cost-controlled multi-agent workflows critical for RAG and AI stack builders.
