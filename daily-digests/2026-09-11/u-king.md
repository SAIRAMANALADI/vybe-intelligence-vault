## Summary
U-King is an open-source AI installer and workspace manager designed for Windows and macOS, providing a desktop-guided setup for AI development environments. It automates the installation, configuration, and validation of AI tools, runtimes, and model providers to ensure seamless usability without manual terminal interactions.

## Key Features
- Automated AI tool installation and configuration with guided UI workflows
- Pre-flight system checks and real-time connectivity testing for models and tools
- Portable mode for Windows (U-disk compatible) and macOS support
- Built-in multi-AI workbench with project-based session management
- Privacy-focused local key storage and optional official API proxy service
