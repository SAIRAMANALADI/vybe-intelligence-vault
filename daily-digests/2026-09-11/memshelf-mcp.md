## Summary
memshelf-mcp is a memory management system for AI agents that offloads bulky conversation history and tool outputs to a local, git-backed shelf. It uses an index-based retrieval system to keep only essential metadata in context while enabling precise recall of detailed episodes on demand.

## Key Features
- Episodic memory storage with git-backed durability and portability
- Index-based retrieval to minimize context bloat (220:1 token savings demonstrated)
- Digest validation contract to ensure recall accuracy and consistency
- Multi-agent compatibility via MCP and standardized shelf format
- Built-in token economy tracking and optimization advice

## Why It Matters for RAG Builders
It enables AI agents to maintain long-term memory without context bloat, drastically reducing token usage while preserving detailed recall capabilities essential for RAG systems.
