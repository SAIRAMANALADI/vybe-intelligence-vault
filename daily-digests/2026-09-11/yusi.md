## Summary
Yusi is an open-source AI companion focused on long-term memory and privacy, designed to organize personal experiences, conversations, and life events into sustainable memory structures for deeper AI understanding and interaction.

## Key Features
- Layered memory system combining short-term, mid-term, and long-term context with vector retrieval for sustained AI understanding
- Privacy-preserving encrypted diary and memory storage with scoped access control
- Life Graph for exploring relationships between people, places, events, and emotions
- Model Control Plane for unified model routing, failover, and weight management across scenarios
- MCP Gateway for standardized integration with external AI models and clients

## Why It Matters for RAG Builders
Yusi provides a privacy-first framework for building AI companions with long-term memory and contextual understanding, essential for RAG systems requiring deep personalization and sustained user interaction.
