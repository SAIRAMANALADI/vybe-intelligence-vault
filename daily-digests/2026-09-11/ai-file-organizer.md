## Summary
An intelligent file organization system that uses adaptive learning and confidence-based decision-making to automate file management while minimizing user intervention. It integrates with cloud storage and supports plugin-based extensibility for custom classifiers.

## Key Features
- 7-day smart staging period for observation before file organization
- Confidence-based decision modes (NEVER/MINIMAL/SMART/ALWAYS) for user control
- 3-tier deduplication (size → MD5 → SHA256) for robust file handling
- Adaptive learning from user corrections to improve future decisions
- Rollback system for undoing organization actions
