## Summary
A package manager for AI agent assets that enables installation, locking, and governance of skills, CLIs, MCPs, and loops across multiple AI runtimes like Codex, Claude Code, Cursor, and Kiro. It provides dependency resolution, version pinning, and an enterprise-grade skill library.

## Key Features
- Unified asset schema for skills, CLIs, MCPs, plugins, hooks, subagents, and loops with pinned versions
- Dependency resolution with lockfile (`ai-kit.lock`) and checksum verification for reliability
- Multi-runtime support for Codex, Claude Code, Cursor, and Kiro (project or global scope)
- GitHub direct install for skills without requiring a private registry
- Enterprise skill library with curated diagnostic and infrastructure skills

## Why It Matters for RAG Builders
It standardizes and simplifies the management of reusable AI agent assets, reducing fragmentation and accelerating AI workflow development.
