## Summary
Hermes Doctor is an AI agent self-diagnosis and security self-healing plugin for the Hermes framework. It provides health checks, prescription matching, repair plans, case records, and Feishu bot integration to ensure agent reliability and performance.

## Key Features
- Automated health checks with multi-dimensional scoring (project structure, runtime health, security compliance, dependencies, performance, observability)
- Prescription matching for error resolution with risk-aware repair plans (L0-L3 safety levels)
- Feishu bot integration for natural language diagnostics and repair requests
- LangChain-style callback monitoring for step-by-step agent observability
- One-click setup with smoke tests, convergence gates, and clean-clone verification

## Why It Matters for RAG Builders
It ensures AI agents remain reliable and secure by automating diagnostics, error resolution, and performance monitoring, reducing manual intervention and downtime.
