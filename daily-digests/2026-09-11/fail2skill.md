## Summary
Fail2Skill is a verification-gated memory and execution harness for coding agents that turns failed attempts into reusable, verified skills by running agents in isolated Git worktrees, evaluating results with repository-native commands, and applying patches only after all configured gates pass.

## Key Features
- Isolated execution in disposable Git worktrees to prevent repository contamination
- Repository-native verification gates (e.g., npm test) to validate agent outputs
- Failure-to-skill learning: creates reusable lessons only from verified passes
- Transactional patching with hashing and validation before applying changes
- Portable verified memory export (SKILL.md) for compatible agent environments

## Why It Matters for RAG Builders
It ensures coding agents never repeat the same mistake by transforming failed attempts into verified, reusable skills through repository-native validation and isolated execution.
