## Summary
An n8n workflow that monitors Gmail for job openings, evaluates role fit against a candidate profile using OpenAI, and prepares truthful application materials (drafts or kits) for human approval before submission.

## Key Features
- Monitors Gmail for unread job-related emails every 5 minutes
- Evaluates job openings against candidate profile using OpenAI for classification and tailoring
- Scores role fit based on resume, LinkedIn, portfolio, work authorization, and salary preferences
- Requires human approval before creating Gmail drafts or sending application kits
- Generates recruiter-ready drafts or candidate-facing application kits with tailored pitch and cover letter

## Why It Matters for RAG Builders
It streamlines the job application process by automating initial screening and preparation while ensuring human oversight for accuracy and authenticity.
