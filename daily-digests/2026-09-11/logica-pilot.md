## Summary
Logica Pilot is an AI-native browser with an embedded autonomous AI copilot that replaces Playwright for web automation tasks. It uses semantic perception and indexed element maps to reduce perception tokens by 5–185× compared to raw HTML or screenshot-based approaches, while learning site-specific interactions locally for improved efficiency and reliability.

## Key Features
- Semantic perception with indexed element maps (5–185× fewer tokens than raw HTML or screenshots)
- Autonomous AI copilot for goal-driven web navigation, clicking, typing, scrolling, and reading
- Local site memory and learning (per-site interaction history stored on-device)
- CLI, MCP, and programmatic API with 36 identical tools across interfaces
- Persistent session management (login persistence, ad-blocking, and local data storage)

## Why It Matters for RAG Builders
Logica Pilot drastically reduces token costs and improves reliability for RAG systems by replacing raw HTML or screenshot-based web perception with semantic, indexed element maps and autonomous AI-driven navigation.
