## Summary
A comprehensive MCP (Model Context Protocol) server for advanced PDF operations, offering 37 tools for reading, searching, creating, merging, splitting, watermarking, stamping, form filling, redacting, annotating, comparing, optimizing, and more. Built on open-source libraries like pdf-lib and unpdf.

## Key Features
- 37 specialized tools for PDF operations including reading, searching, merging, splitting, and annotating
- Supports form filling, watermarking, stamping, and secure redaction (with warnings)
- Built on open-source libraries (pdf-lib, unpdf) for reliability and transparency
- Integrates seamlessly with MCP clients like Claude Code via simple one-line commands
- Includes advanced features like N-up page layout, dynamic headers/footers, and PDF validation/repair
