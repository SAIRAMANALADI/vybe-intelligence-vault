## Summary
A fast, efficient MCP server for capturing high-quality screenshots of web pages, optimized for AI vision workflows. Automatically tiles full pages into 1072x1072 chunks and integrates seamlessly with Claude Vision API and other AI models.

## Key Features
- Fast screenshot capture using Puppeteer headless browser
- Automatic tiling of full pages into 1072x1072 chunks for AI processing
- Optimized for Claude Vision API with 1.15 megapixel resolution
- Supports screencast capture with animated WebP export
- MCP-native integration for seamless AI workflows

## Why It Matters for RAG Builders
This tool enables AI vision workflows to capture and process web content efficiently with optimized resolutions and tiling, making it essential for RAG builders integrating web data.
