## Summary
An open-source tool that automatically matches new government subsidy information to a company's profile and delivers relevant updates to preferred channels like Slack, email, or LINE without requiring servers, databases, or API keys. It leverages a public subsidy data feed and AI coding agents for setup and channel implementation.

## Key Features
- AI-guided setup and channel configuration for seamless onboarding
- Privacy-focused local matching of subsidy data with company profiles (no external data transmission)
- Supports multiple delivery channels (Slack, email, LINE) via AI-generated adapters
- Uses a public subsidy data feed (12,000+ grants, daily updates) with SHA-256 verification
- Serverless, database-free, and API-key-free operation via GitHub Actions

## Why It Matters for RAG Builders
It streamlines the discovery and delivery of relevant subsidies to businesses, reducing manual effort and ensuring timely access to funding opportunities through automated, privacy-preserving matching.
