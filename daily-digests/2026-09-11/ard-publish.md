## Summary
A Python package for creating, validating, and publishing Agentic Resource Discovery (ARD) manifests, enabling AI agents to discover APIs, MCP servers, or AI agents without prior installation. It ensures manifests are correctly formatted and discoverable by public registries.

## Key Features
- Builds and validates ARD manifests for AI agent discoverability
- Supports MCP servers, APIs, and AI agents via standardized media types
- Command-line tools for manifest generation, validation, and submission to registries
- Ensures manifests are findable by verifying registry indexing and representative queries
- Provides DNS verification and rate-limiting keys for private entries

## Why It Matters for RAG Builders
It simplifies the critical step of making AI tools discoverable to other agents, ensuring seamless integration and interoperability in AI ecosystems.
