## Summary
SparkCrew is an AI collaboration platform enabling shared context between humans and AI for conversations, tasks, and results. It focuses on personal and team-based AI interactions with file management, background AI tasks, and execution tools like browser automation and terminal operations.

## Key Features
- Shared context between people and AI for seamless collaboration
- Support for personal AI conversations and team-based topics/threads
- Integration with execution tools like browser automation and terminal tasks
- Isolated workspaces and background AI task execution
- Dual-language documentation (Korean and English)
