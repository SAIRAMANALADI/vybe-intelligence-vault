## Summary
Codex Router is a transparent, zero-touch failover gateway designed for OpenAI Codex and agentic workflows, intelligently routing requests between local inference, cost-effective cloud models (Minimax M3), and premium flagship models (OpenAI Luna/Gemini) based on task complexity and context size.

## Key Features
- Automatic failover between local, Minimax M3, and premium models (OpenAI Luna/Gemini) with zero user interruption
- Real-time token analytics dashboard with cost tracking and quota monitoring across providers
- Smart routing based on task complexity, context size, and domain-specific rules (e.g., ComfyUI, Suno, BioMed)
- Built-in tool call parameter sanitization and circuit breaker mechanism to prevent infinite loops or failures
- Supports 500k to 2M context windows and integrates with VS Code Codex UI for seamless agent workflows

## Why It Matters for RAG Builders
It optimizes AI agent workflows by intelligently balancing cost, performance, and reliability, ensuring high-quality outputs while minimizing expenses and downtime.
