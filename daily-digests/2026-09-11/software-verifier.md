## Summary
A software verification tool that automates full functional testing of applications by parsing specifications, executing real interactions (clicks, form fills) via headless browsers, Electron, mini-programs, or Appium, and generating detailed pass/fail reports with screenshots and error logs.

## Key Features
- Pluggable drivers for Edge, Electron, mini-programs, and Appium to simulate real user interactions
- Step-based DSL for defining test scenarios with actions like click, fill, wait, and assertions
- Self-evolving knowledge base that captures and reuses solutions for common failures
- Opt-in contribution backflow mechanism to crowdsource and improve test playbooks
- MCP server integration enabling other AI agents to leverage verification capabilities

## Why It Matters for RAG Builders
It automates rigorous functional testing of AI applications, ensuring reliability and reducing manual effort in validating software behavior against specifications.
