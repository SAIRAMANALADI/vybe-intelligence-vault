## Summary
A plugin for DeepSeek Harness that enables dynamic model switching for subagents and plan execution, allowing users to assign different models to different workflow stages without altering the core DSH workflow.

## Key Features
- Dynamic model assignment for subagents and plan execution
- Preserves the main conversation model while using custom models for other tasks
- Plan execution model selection during plan approval
- Visualization of subagent model usage and context details
- Compatibility with DeepSeek Harness 0.1.2-rc.1+

## Why It Matters for RAG Builders
It enables precise control over model usage in AI workflows, optimizing performance and cost by matching models to specific tasks within DeepSeek Harness.
