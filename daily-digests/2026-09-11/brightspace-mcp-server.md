## Summary
A Model Context Protocol (MCP) server that integrates AI assistants with D2L Brightspace, enabling natural language queries for grades, assignments, announcements, course content, and more across any school using the platform.

## Key Features
- Seamless integration with D2L Brightspace via MCP for real-time data retrieval (grades, assignments, announcements, etc.)
- Automated authentication with Duo MFA support and encrypted token storage for security
- Smart caching and rate limiting to optimize API calls and prevent throttling
- Cross-platform compatibility with major AI clients (Claude, ChatGPT, Cursor, Windsurf)
- Extensible architecture for adding new schools or custom tools via forking and PRs

## Why It Matters for RAG Builders
It bridges AI assistants with educational platforms like Brightspace, enabling dynamic, real-time access to course data for personalized learning and productivity tools.
