## Summary
caddis is a Claude Code harness and plugin system designed to enhance AI agent capabilities through structured workflows, slash-commands, subagents, and a four-layer memory model. It provides a portable skill library and conventions for AI-driven development workflows across multiple platforms.

## Key Features
- Structured slash-commands for AI workflows (e.g., /feature-plan, /implement, /handoff)
- Subagents for specialized tasks (e.g., code-reviewer, tester, security-analyst)
- Four-layer memory model for persistent context across sessions
- Portable skill library with tiered access (core vs. extras)
- Cross-platform compatibility with per-harness bundles for Codex, Antigravity, etc.
