## Summary
A local control plane that bridges ChatGPT with Google Antigravity, enabling ChatGPT to act as a high-level architect while Antigravity handles local filesystem operations, code modifications, and session persistence. It facilitates seamless task delegation and iterative refactoring without manual copy-pasting.

## Key Features
- Dual control interfaces (OpenAPI 3.1 and MCP SSE) for ChatGPT integration
- Priority task queue with background asynchronous scheduling
- Filesystem boundary guard to prevent directory traversal attacks
- Session continuity for iterative refactoring without re-sending context
- Developer dashboard with real-time WebSocket logs and API key management
