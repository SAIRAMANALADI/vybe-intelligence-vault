## Summary
Mellivora Malatang is a desktop agent chat client designed to integrate an AI agent into real-world project workflows, enabling it to read code, query databases, and interact with servers while maintaining user control over actions. It organizes work by project and provides a unified interface for complex tasks.

## Key Features
- Project-based session organization with parallel task support
- Granular control over agent actions with approval workflows
- Plan-first execution model for complex tasks with user annotations
- Unified interface for code, databases, and server interactions
- Local-first architecture with no external data sharing

## Why It Matters for RAG Builders
It bridges the gap between AI agents and real-world project workflows by providing a controlled, integrated environment for agents to perform multi-step tasks while maintaining user oversight.
