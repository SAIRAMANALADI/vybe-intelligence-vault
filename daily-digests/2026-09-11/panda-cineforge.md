## Summary
Panda CineForge is a specialized AI-to-AI skill-forging engine designed for film and video production workflows, enabling agents to autonomously generate, refine, and deploy production-ready skills. It bridges the gap between raw AI capabilities and professional-grade filmmaking tools.

## Key Features
- Dual-mode skill forging (cold/hot forge) for batch and real-time skill generation
- Layered cascade recall (R0–R5) for structured and semantic skill routing
- Five-layer skill forging pipeline for knowledge fusion and combinatorial innovation
- Unified SkillAsset format enabling seamless integration with production systems
- Graceful degradation to prevent crashes on missing dependencies

## Why It Matters for RAG Builders
