## Summary
agentic-harness provides a persistent runtime layer for AI coding agents, offering context memory, persona-based guardrails, and autonomous loop orchestration that survives across sessions. It acts as an operating system for AI tools like Claude Code, Cursor, and GitHub Copilot.

## Key Features
- Persistent memory and context storage across sessions for AI agents
- Autonomous loop orchestration with persona-based guardrails (implementer, reviewer, researcher, architect)
- Project-specific context bundles (packs) for seamless switching between clients or projects
- Background job queue (DevCompanion) for async tasks like code reviews and refactors
- Integration with popular AI coding tools (Claude Code, Cursor, GitHub Copilot, Gemini CLI)

## Why It Matters for RAG Builders
It provides the critical runtime infrastructure for AI agents to operate autonomously with persistent context, enabling scalable and repeatable AI-assisted software delivery workflows.
