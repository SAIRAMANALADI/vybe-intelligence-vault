## Summary
Lulu Ads provides a monetization layer for MCP servers and AI agents by attaching disclosed, labeled sponsored data fields to tool outputs. It enables publishers to earn revenue via CPA (Cost Per Action) without risking prompt injection or breaking tool functionality.

## Key Features
- Disclosed sponsored data fields attached to tool outputs without prompt injection risks
- 70% revenue share for publishers on CPA basis with 300ms fail-open timeout
- Framework-agnostic integration with Python, TypeScript, and MCP SDKs
- Strict privacy guarantees: no PII, no user profiling, and allowlisted context only
- Widget rendering for MCP Apps UI with CSP-compliant logo inlining

## Why It Matters for RAG Builders
It enables AI agent and MCP server developers to monetize their tools ethically and transparently while maintaining tool integrity and user trust.
