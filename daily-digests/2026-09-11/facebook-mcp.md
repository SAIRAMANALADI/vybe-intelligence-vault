## Summary
A Model Context Protocol (MCP) server for interacting with Facebook Pages via Meta's Graph API, enabling AI agents to post, schedule, analyze insights, and moderate comments across multiple Pages.

## Key Features
- 15 tools for Facebook Pages management including posting, scheduling, and insights analysis
- Supports real-time scheduling with Meta handling publication
- Comment moderation and reply drafting capabilities
- Permanent Page tokens via Meta app integration
- Cross-platform client support (Claude, VS Code, Cursor, etc.)
