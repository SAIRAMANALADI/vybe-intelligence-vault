## Summary
EvoSkills is a modular skill repository designed to extend the EvoScientist AI agent with domain-specific expertise for academic research. It provides installable knowledge packs that cover the entire research lifecycle, from ideation and literature review to experiment execution, paper writing, and rebuttal preparation.

## Key Features
- 16 modular skills covering the full research lifecycle (ideation, experimentation, writing, review)
- Persistent memory integration (evo-memory) for cross-cycle learning and self-evolution
- MCP server marketplace for external tool integration (e.g., paper retrieval, web search)
- Structured workflows with counterintuitive tactics (e.g., rejection simulation, reverse-outlining)
- Bilingual support (English/Chinese) and multi-agent collaboration features
