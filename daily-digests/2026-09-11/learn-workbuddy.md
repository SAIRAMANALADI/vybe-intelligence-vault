## Summary
A 24-chapter educational blueprint for building a desktop AI assistant (WorkBuddy-style) from scratch, focusing on agent engineering, tool integration, memory systems, and security governance. It provides executable Python code and architecture diagrams to teach the full stack of a production-grade agent harness.

## Key Features
- 24 structured chapters covering agent loops, tool dispatch, sidecar servers, and audit sandboxes
- Multi-provider support (DeepSeek, OpenAI, Anthropic) with offline and online modes
- Six-layer architecture (UI, Agent, Tools, Extensions, Memory, Security) for scalable agent systems
- Built-in memory systems (workspace, user, cloud) and context management techniques
- Comprehensive security and governance with permission hooks, sandboxing, and audit trails
