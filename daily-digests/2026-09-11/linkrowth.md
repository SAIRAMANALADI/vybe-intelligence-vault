## Summary
Linkrowth is an AI agent designed to grow LinkedIn authority by generating thoughtful, expertise-signaling comments on relevant posts. It operates as a human-in-the-loop system, where the AI drafts comments that recruiters or clients would notice, while ensuring the final output aligns with the user's voice and positioning.

## Key Features
- Stable core abstraction (`engage(post, context)`) that remains unchanged across architectural layers
- Swappable LLM providers (OpenAI, Gemini, Claude, Kimi) with minimal configuration changes
- Modular architecture with CLI, API, and browser extension components
- Built-in evaluation harness for measuring prompt and model performance
- Public, layered development approach where each new layer addresses a specific failure mode

## Why It Matters for RAG Builders
