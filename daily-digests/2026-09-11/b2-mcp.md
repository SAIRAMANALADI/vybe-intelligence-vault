## Summary
A Model Context Protocol (MCP) server for Backblaze B2 Cloud Storage that enables MCP-compatible AI clients to interact with B2 buckets, files, keys, Object Lock, and S3-compatible storage through a secure, capability-aware toolset of 40 tools.

## Key Features
- 40 capability-aware tools for B2 and S3 operations (buckets, keys, Object Lock, lifecycle, presigned URLs)
- Secure secret management with durable sinks and explicit destructive-action policies
- Bundled Backblaze B2 skills pack for common workflows (backup/restore, lifecycle, migration)
- Multi-transport support (stdio, HTTP, Docker) with environment-based configuration
- Comprehensive testing (94.3% coverage) and CI/CD with CodeQL and npm publishing

## Why It Matters for RAG Builders
It provides a secure, standardized interface for AI clients to interact with Backblaze B2 Cloud Storage, enabling seamless integration for RAG pipelines requiring cloud storage access.
