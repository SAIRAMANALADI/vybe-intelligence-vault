## Summary
A high-performance MCP server that enables secure, governed SQL access across six major databases (SQLite, PostgreSQL, MySQL, SQL Server, Oracle, Firebird) with strict AST validation, human-in-the-loop approval for DML operations, and an embedded Admin Panel for enterprise governance.

## Key Features
- Strict SQL parsing and validation via AST to prevent LLM hallucinations and security risks
- Multi-database support (SQLite, PostgreSQL, MySQL, SQL Server, Oracle, Firebird)
- Human-in-the-loop DML approval with read-only impact preview and MCP Elicitation
- Embedded Admin Panel for database management, policy enforcement, and audit tracking
- Enterprise-grade security with OIDC SSO, TOTP MFA, Prometheus metrics, and SIEM integration

## Why It Matters for RAG Builders
It provides a secure, governed bridge between LLMs and SQL databases, eliminating hallucinations and security risks while enabling enterprise-grade access control and human oversight for AI-driven data operations.
