## Summary
A read-only MCP server that exposes health and cultural activity data from a personal dashboard (health-ojimpo.com) to AI assistants like Claude, enabling natural language queries for insights into mental health trends, activity patterns, and historical data.

## Key Features
- Read-only access to health/cultural activity scores and trends via MCP tools
- Supports both stdio and Streamable HTTP transport modes for local and remote AI interactions
- Provides historical score data, recent activities, and raw records with filtering options
- Designed for low-risk, authentication-free operation with controlled output sizes
- Integrates seamlessly with existing health-ojimpo backend via Docker network

## Why It Matters for RAG Builders
It enables AI assistants to perform natural language analysis on personal health and cultural activity data, bridging the gap between static dashboards and interactive insights for mental health monitoring.
