## Summary
Izzi AI is a cross-platform desktop application that serves as a gateway for managing, orchestrating, and interacting with multiple open-source AI agents (e.g., OpenClaw, Hermes, AutoGPT) through a unified liquid-glass UI. It leverages IzziAPI for model routing and cost tracking, enabling users to run agents locally or via Docker without requiring terminal access.

## Key Features
- Unified desktop interface for managing multiple AI agents (OpenClaw, Hermes, AutoGPT, etc.) with parallel tab-based interactions
- One API key access to 200+ models via IzziAPI’s smart routing and budget control
- Built-in marketplace for discovering, installing, and managing agent extensions and bundles
- Real-time cost dashboard with spend tracking, budget alerts, and model-specific breakdowns
- Cross-platform support (Windows, macOS) with auto-update and one-click setup wizards

## Why It Matters for RAG Builders
It simplifies the deployment and management of multiple AI agents for RAG builders by providing a unified desktop interface and cost-effective model routing.
