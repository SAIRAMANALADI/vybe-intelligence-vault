## Summary
IronCore Labs provides application-layer encryption tools that enable organizations to keep sensitive data private while maintaining usability. Their solutions include SaaS Shield for tenant-controlled encryption, Cloaked Search for encrypting Elasticsearch/OpenSearch, and Cloaked AI for encrypting AI workloads.

## Key Features
- Tenant-controlled envelope encryption with customer-managed keys (BYOK)
- Transparent encrypting proxy for Elasticsearch and OpenSearch (Cloaked Search)
- Encryption for AI workloads (Cloaked AI)
- Multi-tenant SaaS security with minimal performance impact
- Support for customer-managed keys in cloud environments
