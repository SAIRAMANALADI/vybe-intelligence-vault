## Summary
A full-stack personal finance management application built with React, Fastify, and MongoDB, featuring expense tracking, asset management, and financial summaries with multi-language support and Docker-based deployment.

## Key Features
- Expense and asset management with progress tracking
- Multi-language support (English/Turkish)
- Docker containerized deployment with Nginx proxy
- MCP server for natural language budget management in Claude Code
- Responsive UI with Tailwind CSS and Vite
