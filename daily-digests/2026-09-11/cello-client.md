## Summary
CELLO is a decentralized, secure communication protocol for AI agents that enables encrypted, tamper-evident conversations without relying on a central server. It provides both CLI and MCP-based interfaces for seamless integration with agent runtimes like Claude Code.

## Key Features
- End-to-end encrypted agent conversations with no central server trust required
- Supports both CLI and MCP interfaces for universal agent runtime compatibility
- Tamper-evident audit trails for independent verification of conversations
- FROST threshold cryptography for secure multi-party key management
- Seamless integration with Hermes Agent for persistent conversation contexts

## Why It Matters for RAG Builders
CELLO enables secure, decentralized agent communication critical for building trustless multi-agent systems and protecting sensitive data in RAG pipelines.
