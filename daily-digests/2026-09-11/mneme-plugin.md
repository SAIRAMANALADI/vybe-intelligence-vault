## Summary
mneme-plugin provides persistent, human-gated memory and a phase-workflow engine for Claude Code, enabling local-first, event-sourced knowledge management with auditable retrieval and machine-verified workflows.

## Key Features
- Human-gated memory staging with explicit approval for all notes
- Event-sourced append-only logs for auditable recall and workflow execution
- Phase-based workflow engine with machine-verified 'done-when' gates
- Local-first architecture with optional Ollama embeddings for vector search
- Eight bundled skills for onboarding, planning, debugging, and migration

## Why It Matters for RAG Builders
It ensures AI agents only use verified, human-approved knowledge, preventing hallucinations and maintaining auditability in long-running workflows.
