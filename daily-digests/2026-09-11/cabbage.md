## Summary
Cabbage is a CLI-driven project documentation lifecycle and workflow gate system designed for AI Agent teams and modern software development. It enforces rigid, executable, and verifiable CI workflow gates to ensure PRDs, impact analyses, architecture designs, and other artifacts are complete before coding begins.

## Key Features
- Rigid workflow gates enforce documentation completeness before coding (e.g., `gate implementation`, `gate merge`).
- Content signing and anti-rot mechanisms track dependencies and invalidate downstream stages if upstream artifacts change.
- Strict placeholder and dead-link interception with automated Markdown validation.
- Automated synchronization and archiving of verified changes into standardized documentation trees.
- Modern VitePress integration with Mermaid support and GitHub Pages deployment.

## Why It Matters for RAG Builders
Cabbage ensures AI engineering teams maintain rigorous, verifiable, and tamper-proof documentation workflows, reducing technical debt and improving collaboration in AI-driven projects.
