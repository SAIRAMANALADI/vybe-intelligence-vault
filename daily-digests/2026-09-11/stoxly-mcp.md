## Summary
Stoxly MCP Server provides free fundamental analysis of stocks and ETFs for AI agents, evaluating companies and funds against a 10-point checklist and returning a 0–10 score, verdict, and detailed metrics via a remote MCP server endpoint.

## Key Features
- Provides 10-point fundamental analysis for stocks (P/E, PEG, ROE, etc.) and ETFs (expense ratio, returns, volatility, etc.)
- Returns a 0–10 score, verdict, and detailed metrics for any publicly traded ticker
- Remote MCP server with no local installation required
- Aggregates data from multiple financial sources (Yahoo Finance, SEC EDGAR, etc.)
- Supports both US and international tickers (e.g., SAP.DE)
