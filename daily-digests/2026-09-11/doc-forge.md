## Summary
DocForge is a deterministic-first document generator that converts prompts into polished Markdown or HTML files with live previews. It prioritizes graceful degradation, ensuring a working offline fallback even when AI models are unavailable, and supports both CLI and VS Code extension workflows.

## Key Features
- Graceful degradation with a priority ladder of generators (AI, BYO-key, offline templates)
- Live preview with streaming drafts and section-level regeneration
- Deterministic presets (readme, blog, report, etc.) and prompt heuristics for template selection
- Strict HTML sanitization and CSP enforcement for security
- Cross-platform CLI and VS Code extension with diff-based approval workflows

## Why It Matters for RAG Builders
DocForge ensures reliable document generation with AI or offline templates, reducing failures in RAG pipelines by providing a fallback mechanism and structured output for downstream processing.
