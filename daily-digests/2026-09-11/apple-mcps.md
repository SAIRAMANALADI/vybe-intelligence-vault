## Summary
A suite of Model Context Protocol (MCP) servers that provide AI agents with local, structured access to core Apple macOS applications like Mail, Calendar, Reminders, Messages, and Files. Enables agents to interact with native Apple apps while keeping data local and secure.

## Key Features
- Unified and standalone MCP servers for Apple apps (Mail, Calendar, Reminders, Messages, etc.)
- Local stdio and streamable-http transport support for secure, low-latency interactions
- Built-in permission management and health tools for seamless macOS integration
- Generated Python wrappers and tool catalogs for code-mode clients
- Full MCP spec 2026-07-28 compliance with backward compatibility

## Why It Matters for RAG Builders
It enables AI agents to securely and locally interact with macOS applications, bridging the gap between AI capabilities and native user data without cloud dependency.
