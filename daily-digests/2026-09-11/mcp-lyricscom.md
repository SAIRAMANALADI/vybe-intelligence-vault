## Summary
An MCP server for lyrics.com that enables searching songs by lyrics, title, or artist, and fetching full lyrics text without requiring an API key or account. It acts as a bridge between lyrics.com's public pages and MCP clients.

## Key Features
- Search songs by lyrics, title, or artist with configurable pagination
- Fetch full lyrics text for any song using its ID or URL
- Built-in rate limiting and throttling detection to avoid bans
- In-memory caching to reduce redundant requests to lyrics.com
- Configurable user-agent and request timing to comply with lyrics.com's policies

## Why It Matters for RAG Builders
It provides a reliable, no-configuration way to integrate song lyrics into RAG pipelines or AI assistants without relying on proprietary APIs.
