## Summary
A local-first tool that converts arbitrary text or public web content into structured Xiaohongshu (Little Red Book) long-form drafts, preserving source metadata and enabling manual editing before publication. It supports multi-model API fallback and local storage of generated content.

## Key Features
- Converts arbitrary text or URLs into structured Xiaohongshu long-form drafts with preserved source metadata
- Supports multi-model API fallback (Gemini, Groq, Zhipu, SiliconFlow, OpenRouter) with automatic degradation
- Local storage of generated content, prompts, and history with strict privacy controls
- Customizable prompt templates for title, body, summary, and tags with versioning support
- Manual review and editing workflow before final publication to Xiaohongshu

## Why It Matters for RAG Builders
It streamlines the creation of structured, platform-compliant long-form content for Xiaohongshu while preserving source attribution and enabling manual oversight, reducing manual effort in content repurposing.
