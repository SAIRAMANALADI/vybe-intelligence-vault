## Summary
OpenClip is an AI-powered creative studio that automates video production through conversational AI. It uses a multi-agent pipeline to handle research, scriptwriting, visuals, audio, editing, and cross-platform publishing via a modern terminal UI or API.

## Key Features
- Conversational video production with AI agent (OpenHer) guiding users through the process
- Multi-agent pipeline for parallelized research, scriptwriting, visual generation, audio, and editing
- Cross-platform publishing to YouTube, TikTok, Instagram, and others with OAuth integration
- Modern Textual-based TUI with real-time streaming, slash commands, and keyboard shortcuts
- Professional-grade output with structured EDL, bundled fonts, and automated QA
