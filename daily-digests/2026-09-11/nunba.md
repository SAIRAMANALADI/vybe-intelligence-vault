## Summary
Nunba is a desktop AI companion that runs entirely on local hardware, offering offline chat, voice, and vision capabilities with a visible switch to toggle between Local, Hybrid, and Hive processing modes for flexibility and privacy.

## Key Features
- Runs entirely on local hardware with optional cloud provider integration via Hybrid mode
- Supports voice input/output, vision (VLM), and autonomous agents with constitutional filtering
- Visible Local/Hybrid/Hive switch for real-time processing mode selection
- Federated learning with peer-to-peer delta sharing while keeping raw data local
- Cross-platform deployment (Windows, Linux, Android) with signed installers and headless backend support

## Why It Matters for RAG Builders
Nunba provides a privacy-preserving, multimodal agent framework that bridges local and federated AI capabilities, making it essential for builders seeking flexible, offline-capable assistants with autonomous agent support.
