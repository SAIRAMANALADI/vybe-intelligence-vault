## Summary
Luna is a local-first native agent for Android that integrates Dart for UI, Java for device interactions, and llama.cpp for on-device inference. It provides a controlled workspace where users grant access to a single folder and a model, enabling secure, scoped file operations and on-device reasoning without terminal or web access.

## Key Features
- Scoped file operations with granular permissions (read, write, delete, etc.)
- On-device GGUF model inference via llama.cpp with SHA-256 verification
- Secure credential storage using Android Keystore and AES/GCM encryption
- Backup and undo functionality for all file changes
- Support for cloud and local model endpoints (Ollama, OpenAI-compatible)

## Why It Matters for RAG Builders
Luna provides a secure, local-first agent framework for Android that enables on-device reasoning and controlled file operations, reducing dependency on cloud APIs while maintaining privacy and performance.
