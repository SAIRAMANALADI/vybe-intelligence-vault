## Summary
agent-parkour is a universal, ultra-fast cross-agent prompt compiler and context synchronizer designed to eliminate configuration fragmentation across modern AI coding assistants like Claude Code, Cursor, GitHub Copilot, and Google Antigravity. It enables zero-cost, local-first rule management with a single source of truth (AGENTS.md) and compiles rules in under 10ms.

## Key Features
- Single Source of Truth (SSOT) with AGENTS.md for unified rule management across multiple AI IDEs
- Ultra-fast deterministic compilation (<10ms) with zero API costs by default
- Automatic context-aware rule decomposition and JIT skill packaging to reduce token consumption by 80%+
- Cross-agent migration and synchronization (e.g., GitHub Copilot to Google Antigravity) with dry-run and backup support
- Optional generative AI augmentation for advanced semantic rule decomposition (Gemini, Ollama, etc.)

## Why It Matters for RAG Builders
It streamlines AI agent rule management by unifying configurations across tools, reducing token waste and manual effort for RAG and AI stack builders.
