## Summary
Jeden is a local-first coding-agent harness that executes tasks in a developer's terminal while keeping policy, tools, sessions, and memory under local control. It enables secure, interactive, and automated coding tasks with explicit approvals for file writes and commands.

## Key Features
- Interactive and one-shot task execution with local approvals for writes/commands
- Jailed tools and path restrictions for secure file system operations
- Durable session transcripts and artifacts stored locally
- Multi-modal integration via RPC, ACP, headless mode, and SDKs (TypeScript/Python)
- Policy-driven model routing through Brama with HMAC-signed OpenAI-compatible endpoints

## Why It Matters for RAG Builders
Jeden provides a critical layer of local control and security for AI-driven coding agents, ensuring sensitive operations remain under developer oversight while enabling seamless integration with existing workflows and tools.
