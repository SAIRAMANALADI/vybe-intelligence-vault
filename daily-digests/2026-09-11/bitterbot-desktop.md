## Summary
Bitterbot Desktop is a local-first personal AI agent that combines persistent biological memory, emotional intelligence, and a P2P skills economy. It runs on user devices, remembers interactions, dreams autonomously to consolidate knowledge, and trades proven skills with other agents.

## Key Features
- Biological memory system with forgetting curves and consolidation pipelines
- Dream Engine with 12 specialized modes for self-optimization and skill evolution
- Hormonal system (Dopamine, Cortisol, Oxytocin) shaping agent behavior and responses
- P2P skills marketplace for trading proven agent capabilities using USDC
- Proactive recall and canonical facts ledger for zero-cost identity and directive memory injection

## Why It Matters for RAG Builders
Bitterbot provides a self-contained, biologically inspired framework for building persistent, emotionally intelligent AI agents that learn, adapt, and trade skills autonomously, reducing reliance on external RAG systems.
