## Summary
A lightweight CLI tool that detects installed AI coding-agent binaries on a user's machine and launches the selected agent, with support for interactive selection and argument passthrough.

## Key Features
- Zero-setup execution via `npx agentpick` without pre-installation
- Automatic detection of installed AI coding-agent CLIs in the system PATH
- Smart launching logic (auto-launch for single agent, interactive picker for multiple agents)
- Argument passthrough to the chosen agent for direct prompt execution
- Extensible registry for adding custom agents via a simple JSON config file

## Why It Matters for RAG Builders
Simplifies the workflow for AI engineers and developers by providing a unified launcher for multiple AI coding agents, reducing context switching and setup overhead.
