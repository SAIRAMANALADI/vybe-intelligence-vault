## Summary
Dazzle is an agent-native SaaS framework that enables domain-first application development using structured DSL declarations for entities, roles, rules, and workflows. It executes these declarations directly at runtime without code generation, optimizing for correctness, inspectability, and change locality in domain-heavy applications.

## Key Features
- Direct execution of domain declarations without code generation, ensuring no drift between design and runtime
- Structured DSL for modeling business entities, roles, rules, and workflows with explicit HTMX interaction contracts
- Epistemic engineering practices for knowledge representation, including stems, counter-priors, and agent didactics
- Three-layer prior correction system to mitigate LLM-driven software development biases (grammar restriction, inference-time bias correction, post-hoc filtering)
- Built-in RBAC, scope validation, and compliance evidence generation for governance-heavy applications

## Why It Matters for RAG Builders
Dazzle provides a structured, inspectable, and bias-resistant substrate for building AI-collaborative SaaS applications, reducing inference overhead for agents and ensuring correctness in domain-heavy systems.
