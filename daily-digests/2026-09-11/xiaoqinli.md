## Summary
Xiaoqinli (xql) is a minimalist, secure transpiler that converts structured JSON AST inputs into native idiomatic code for 42+ target platforms. It operates as a single Go binary with zero runtime dependencies, ensuring safety and efficiency for AI agent workflows.

## Key Features
- Converts JSON AST to 42+ target platforms (Go, Python, PHP, Ruby, Android, iOS, etc.) with idiomatic output
- Zero runtime dependencies and zero third-party libraries, ensuring minimal attack surface
- Security-focused design with strict capability checks, symbol conflict resolution, and vulnerability fixes
- Multi-file project support with proper import resolution and cross-file type checking
- Built-in validation, diagnostics, and learned fixes for robust code generation

## Why It Matters for RAG Builders
It enables AI agents to generate production-ready, idiomatic code across multiple platforms from a single AST input, reducing integration complexity and security risks in RAG pipelines.
