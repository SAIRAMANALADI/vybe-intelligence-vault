## Summary
mArvIn is an AI sidekick designed to run as a persistent background service on a server, providing an interactive CLI and HTTP interface for managing AI agents, models, and workflows. It simplifies the deployment and configuration of AI services with automated setup and systemd integration.

## Key Features
- Automated installation and setup with systemd integration for persistent background operation
- Interactive CLI and HTTP API for managing AI agents and models
- Supports configuration of API keys, models, and agents via environment files and JSON configs
- Built-in commands for service management (reload, update, status, logs)
- Lightweight and fast execution using Bun runtime
