## Summary
FastCUA transforms Windows GUIs into a fast, executable interface for AI agents by providing a local-first runtime that combines UI Automation (UIA) text navigation with optional screenshots, multi-action execution, and a human control plane. It enables agents to interact with Windows applications via a shared daemon and MCP server.

## Key Features
- UIA-first navigation with optional screenshot-based targeting for complex UIs
- Shared resident daemon and native host for multi-agent coordination
- Multi-action execution per model turn via persistent JS environment
- Human control plane with global keys (F7-F10) for pause, approval, and interjection
- Policy-driven safety with whitelisted apps and human approval for unknown executables

## Why It Matters for RAG Builders
FastCUA provides a critical bridge between AI agents and Windows applications, enabling reliable, multi-step desktop automation with human oversight and policy controls essential for RAG/AI stack builders.
