## Summary
Polako automates GitHub issue resolution by working through the lowest open issue, delegating implementation tasks to Claude Code, and managing pull requests until they are merged. It operates unattended, one issue at a time, ensuring human oversight at every critical step.

## Key Features
- Unattended issue resolution with human gates (no auto-merging)
- Integration with Claude Code for AI-driven implementation
- State management entirely in GitHub (issues, PRs, labels)
- Planning and health-checking capabilities via dedicated skills
- Cost tracking and performance metrics for each run
