## Summary
A generic, subclassable Model Context Protocol (MCP) gateway that enables asynchronous tool execution over WebSocket connections. It acts as a middleware between MCP clients and providers, dynamically registering and routing capabilities without prior knowledge of provider domains.

## Key Features
- Dynamic registration and routing of MCP tools/resources/prompts from providers without prior knowledge
- Subclassable Gateway class for custom domain logic and route extensions
- Asynchronous tool execution via WebSocket connections between clients and providers
- Extensible authentication, token management, and security strategies
- Production-ready deployment with Docker support and one-click deploy options

## Why It Matters for RAG Builders
It simplifies the integration of MCP providers with clients by abstracting transport and routing, enabling scalable and secure AI tool orchestration in RAG systems.
