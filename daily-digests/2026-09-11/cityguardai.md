## Summary
CityGuard AI is an autonomous AI agent designed for real-time urban risk monitoring and incident response. It ingests multi-source signals (crowd density, traffic, surveillance) via Elastic MCP, uses Google Cloud Agent Builder for reasoning, and triggers automated responses through MongoDB and GitLab MCP integrations.

## Key Features
- Multi-source signal ingestion and anomaly detection via Elastic MCP
- Chain-of-thought reasoning for severity classification and decision-making
- Automated incident logging and response dispatch using MongoDB and GitLab MCP
- Interactive city map with real-time risk visualization and pulse animations
- Zero-config static deployment to GitHub Pages with no server requirements
