## Summary
A lightweight MCP server that bridges Vertex AI Search with the Model Context Protocol (MCP), enabling retrieval of configurable search snippets and extractive segments for document discovery in RAG pipelines.

## Key Features
- Exposes Vertex AI Search as an MCP-compliant tool for seamless integration with RAG systems
- Supports both stdio and streamable HTTP modes for flexible deployment
- Configurable via YAML, environment variables, or command-line parameters
- Provides extractive segments and snippets for precise document discovery
- Pre-compiled executables for macOS, Linux, and Windows for easy setup

## Why It Matters for RAG Builders
