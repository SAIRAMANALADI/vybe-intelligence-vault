## Summary
mcp-blender is an MCP server that exposes 218 Blender tools to any MCP-compatible AI client, enabling AI-driven 3D modeling, AI-based 3D generation, and Microsoft Flight Simulator content creation workflows. It bridges Blender's bpy API with external AI agents via the Model Context Protocol.

## Key Features
- 218 MCP tools covering modeling, materials, sculpting, animation, and rendering in Blender
- AI self-refinement loop for iterative 3D model improvement using vision models
- Multi-backend AI 3D generation (Hyper3D, Meshy, Tripo, Stable Fast 3D, Hunyuan3D)
- Microsoft Flight Simulator (MSFS) content pipeline integration for LODs, collisions, and liveries
- Poly Haven integration for free HDRIs, textures, and models without API keys

## Why It Matters for RAG Builders
It enables AI agents to directly control Blender for automated 3D modeling, AI-driven content generation, and iterative refinement, bridging the gap between AI workflows and professional 3D design tools.
