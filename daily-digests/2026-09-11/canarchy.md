## Summary
CANarchy is a stream-first CAN bus toolkit designed for analysts, security researchers, and AI agents, enabling machine-readable event streaming, J1939 heavy-vehicle support, and MCP integration for agent-driven CAN analysis.

## Key Features
- Stream-first typed event output (JSON/JSONL) for machine readability and piping to downstream tools or agents
- First-class J1939 support with PGN/SPN decoding, TP reassembly, and DM1 fault parsing
- Built-in MCP server for direct integration with AI agents like Claude
- Interactive TUI for live bus monitoring and analysis
- Active-transmit safety model and dry-run planning for secure fuzzing and replay

## Why It Matters for RAG Builders
CANarchy provides a structured, machine-readable interface to CAN bus data, enabling AI agents and automation tools to directly analyze, decode, and interact with vehicle networks without manual parsing or scraping.
