## Summary
Agent Deck is a terminal-based session manager and orchestration tool for AI coding agents like Claude Code, OpenCode, and others. It provides a unified TUI and CLI to monitor, fork, archive, and manage multiple agent sessions across projects with features like MCP integration, skills management, and fleet orchestration via a conductor system.

## Key Features
- Unified TUI and CLI for managing multiple AI agent sessions (Claude, OpenCode, Codex, etc.)
- Session forking, archiving, and cost tracking with real-time monitoring
- MCP and Skills Manager for dynamic tool and skill integration per session
- Conductor system for fleet-wide orchestration, notifications, and remote control (Telegram/Slack/Discord)
- Declarative group management with per-group and per-conductor configuration overrides

## Why It Matters for RAG Builders
Agent Deck simplifies the management of multiple AI coding agents, enabling scalable orchestration and monitoring essential for building robust RAG systems with diverse agent workflows.
