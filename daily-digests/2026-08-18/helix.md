## Summary
Helix is a portable skill pack for AI agents designed to streamline QA workflows, including FE/API test-case preparation, Playwright ticket testing, bug retesting, and defect filing. It integrates with multiple AI agents and IDEs via the Agent Skills format, enabling automated and semi-automated testing processes.

## Key Features
- Portable skill pack for AI agents with standardized workflows for FE/API test-case preparation and bug retesting
- Supports multiple AI agents (Claude Code, Cursor, GitHub Copilot, etc.) via Agent Skills format
- Automated quality checks aligned with ISTQB/ISO/IEC/IEEE 29119-3 standards
- Delivers outputs in CSV/Excel, Jira comments, and Test.md format for agent-native compatibility
- Auto-update mechanism with health checks and workspace linking for team collaboration
