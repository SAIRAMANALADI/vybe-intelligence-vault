## Summary
A plugin for Obsidian that integrates a full-featured code editor with AI agent capabilities, enabling Claude (or compatible models) to maintain and organize an Obsidian vault while providing advanced code editing, diagnostics, and git review tools.

## Key Features
- Full-featured code editor with syntax highlighting for 50+ languages and diagnostics for 48 languages
- AI agent integration (Claude, Kimi K2, DeepSeek) for vault maintenance and code editing with approval-gated changes
- Git review tools including branch graph, inline blame, and diffs directly in Obsidian
- Language server protocol (LSP) support for advanced features like autocomplete, navigation, and diagnostics
- One-click launch of AI agents and seamless context sharing between notes and code files

## Why It Matters for RAG Builders
It bridges the gap between AI agents and personal knowledge management by enabling AI-driven maintenance of Obsidian vaults while providing professional-grade code editing and git review capabilities within a single interface.
