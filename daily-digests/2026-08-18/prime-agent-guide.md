## Summary
An interactive, bilingual (English/Korean) guide for Prime Agent, a RLM-native terminal coding and research harness. It provides a detailed, visual, and hands-on explanation of Prime Agent's architecture, programming model, and features through an interactive single-page website.

## Key Features
- Bilingual (EN/KO) toggle with persistent language preference
- Interactive architecture diagram with clickable components for detailed explanations
- Animated RLM (Recursive Language Model) loop visualization
- Syntax-highlighted code blocks with copy-to-clipboard functionality
- Fully responsive design with smooth scroll animations
