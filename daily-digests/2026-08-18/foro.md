## Summary
Foro provides a sovereign infrastructure platform and SDK for deploying Model Context Protocol (MCP) servers with zero-configuration. It simplifies the deployment process by converting locally running MCP servers into publicly accessible endpoints with stable HTTPS URLs, eliminating the need for Dockerfiles or complex pipelines.

## Key Features
- Zero-configuration deployment of MCP servers with stable HTTPS endpoints
- Local validation and simulation of deployment environment via `foro dev` and `foro check`
- Consistent runtime behavior between local and deployed environments using `foro.run(server)`
- Simplified secret management with `foro.secret(name)` for clear error messages
- Automated versioning and changelog generation via semantic-release

## Why It Matters for RAG Builders
Foro eliminates deployment friction for MCP servers, enabling RAG builders to quickly and reliably deploy their models as stable, publicly accessible endpoints without complex infrastructure setup.
