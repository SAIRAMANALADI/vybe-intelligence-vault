## Summary
A Scrypted plugin that exposes a Streamable HTTP Model Context Protocol (MCP) endpoint with OAuth authentication, enabling AI assistants to interact with Scrypted servers for device management, log inspection, plugin operations, and server administration.

## Key Features
- Exposes a Streamable HTTP MCP endpoint for AI assistants to connect to Scrypted servers
- OAuth 2.1 Authorization Server with dynamic client registration, PKCE, and JWT access tokens
- Comprehensive toolset for managing plugins, devices, logs, users, and server administration
- Secure backup and restore functionality with destructive operation safeguards
- Configurable token lifetimes and client registration limits for security and scalability

## Why It Matters for RAG Builders
It enables AI assistants to securely interact with Scrypted servers for real-time device management and system administration, bridging the gap between AI workflows and smart home ecosystems.
