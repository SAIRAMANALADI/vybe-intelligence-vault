## Summary
A Model Context Protocol (MCP) server that provides automation capabilities for managing Beget hosting services, including domains, DNS, websites, databases, email, backups, and account statistics via a standardized MCP-compatible interface.

## Key Features
- MCP-compatible server for Beget hosting API with stdio transport
- Supports read and write operations (with explicit write permissions)
- Provides tools for method discovery, documentation retrieval, and generic API calls
- Includes dry-run mode for safe testing of operations
- Offers machine-readable method metadata and comprehensive documentation corpus
