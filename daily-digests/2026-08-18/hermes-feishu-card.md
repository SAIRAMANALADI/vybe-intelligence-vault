## Summary
This repository provides a patch and tooling to upgrade Hermes' Feishu (飞书) adapter responses from plain text to interactive, updatable cards. It ensures process messages are preserved and enables in-place updates of cards without losing context.

## Key Features
- Converts plain text Feishu replies to interactive, updatable cards
- Preserves all process messages (tool calls) without loss
- Supports in-place card updates using PATCH requests
- Includes a one-click patching script for Hermes' Feishu adapter
- Provides manual and automated verification tools for card functionality

## Why It Matters for RAG Builders
It enables RAG builders to enhance Feishu bot interactions with dynamic, updatable UI elements while preserving conversation context.
