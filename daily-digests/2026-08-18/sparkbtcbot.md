## Summary
A Bitcoin Layer 2 wallet skill for AI agents that enables autonomous Bitcoin transactions, including payments, deposits, and merchant purchases via Spark (a self-custodial Bitcoin L2 network). Designed for integration into LLM agent frameworks or standalone use with encryption-backed wallet security.

## Key Features
- Self-custodial Bitcoin wallet via BIP39 mnemonic with encryption at rest
- Instant, near-zero-fee Spark-to-Spark transfers and Lightning invoice support
- L402 paywall integration for API access control and pay-per-request models
- Merchant purchase capabilities for real-world goods (gift cards, eSIMs, VPNs) over Lightning
- Unilateral-exit backup system for recovery in case of operator downtime

## Why It Matters for RAG Builders
It enables AI agents to autonomously handle Bitcoin transactions, expanding their utility for real-world economic interactions while maintaining self-custody and security.
