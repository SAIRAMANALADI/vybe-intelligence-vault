## Summary
Kiro Crew is an open-source, persistent development workspace that runs locally or remotely, enabling continuous, self-improving agent sessions across multiple surfaces like desktop apps, web dashboards, CLI, and messaging platforms. It supports long-running tasks, self-learning capabilities, and modular extensions through installable apps and tools.

## Key Features
- Persistent agent sessions that survive restarts and retain context across interactions
- Self-learning and self-evolving capabilities through durable lessons and reusable skills
- Multi-surface access via desktop app, web dashboard, CLI, and messaging integrations (Slack, Discord, etc.)
- Long-running, unattended task execution with checkpointing and validation
- Extensible architecture with installable apps, MCP servers, and custom tools

## Why It Matters for RAG Builders
Kiro Crew enables RAG builders to create persistent, self-improving agent systems that can handle long-running tasks and maintain context across sessions, reducing the need for manual intervention and improving automation efficiency.
