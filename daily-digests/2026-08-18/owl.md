## Summary
Owl is an open-source retirement planning optimizer that uses mixed-integer linear programming to co-optimize withdrawal strategies, Roth conversions, and Social Security claiming for US retirees. It integrates tax efficiency, Monte Carlo simulations, and explainable AI insights for financial decision-making.

## Key Features
- Tax-optimized retirement income strategies with embedded federal/state tax calculations
- Mixed-integer linear programming for mathematically optimal withdrawal sequencing
- Monte Carlo simulation with sequence-of-returns risk and longevity modeling
- MCP server for AI-native access (Claude, Gemini, Cursor, VS Code, etc.)
- Explainable results with shadow price analysis and tax bracket optimization
