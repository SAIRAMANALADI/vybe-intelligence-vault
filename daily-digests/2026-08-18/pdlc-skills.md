## Summary
pdlc-skills is a Claude Code plugin that enforces a Product Development Life Cycle (PDLC) workflow with 35 standardized stages, ensuring AI-driven engineering produces auditable artifacts, tests-first development, and state-tracked progress. It transforms soft AI conventions into hard contracts by persisting files, enforcing TDD, and running self-checks.

## Key Features
- 35 standardized PDLC stages with slash commands (e.g., `/pdlc-feature`, `/pdlc-tdd`)
- Hard contracts enforcing tests-first development, artifact persistence, and state tracking
- Per-feature state machine with self-checks and auto-repair mechanisms
- Document templates for PRDs, designs, tests, and reviews
- Loop automation for multi-stage workflows (e.g., `tdd → implement → review`)

## Why It Matters for RAG Builders
It ensures AI-driven engineering produces auditable, production-ready artifacts by enforcing hard contracts like tests-first development and persistent state tracking, eliminating chat-only outputs.
