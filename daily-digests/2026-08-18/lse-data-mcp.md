## Summary
An unofficial Model Context Protocol (MCP) server that provides read-only access to the London Strategic Edge market-data API, enabling MCP clients to query financial data such as OHLCV candles, company profiles, fundamentals, insider transactions, dividends, and economic events through a standardized interface.

## Key Features
- Provides 15 read-only tools for querying financial market data via the London Strategic Edge API
- Supports structured responses with pagination and truncation handling for large datasets
- Integrates with operating system credential stores for secure API key management
- Offers local validation of date formats and response size limits to optimize API calls
- Includes discovery endpoints for instruments, datasets, and timeframes

## Why It Matters for RAG Builders
It enables MCP-compatible AI agents to seamlessly integrate real-time financial market data for RAG applications without requiring direct API integration.
