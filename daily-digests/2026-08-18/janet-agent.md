## Summary
Janet is a local CLI agent designed to build and maintain portable project wikis in plain Markdown using the Open Knowledge Format (OKF). It enables users to ingest, query, and visualize project knowledge while ensuring data remains open, diffable, and usable without the agent.

## Key Features
- Portable project wikis in plain Markdown using OKF for structured knowledge storage
- Project-scoped conversation history and knowledge bundles
- Deterministic conformance checking and semantic drift audits via `janet lint`
- Integration with Agent Client Protocol (ACP) for standardized agent interactions
- Offline-capable with self-contained skills and no external API dependencies for core operations

## Why It Matters for RAG Builders
Janet provides a structured, portable, and offline-capable way to maintain project knowledge wikis, making it essential for teams building RAG systems that require reliable, version-controlled, and human-readable documentation.
