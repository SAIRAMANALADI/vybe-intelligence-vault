## Summary
Codetrip is a hybrid graph-augmented code intelligence engine that transforms source repositories into typed code graphs, enabling advanced code analysis, semantic retrieval, and dependency exploration. It supports multi-language parsing and provides tools for indexing, searching, and traversing codebases via CLI, Go library, or MCP server.

## Key Features
- Typed code graph generation with 38+ node label types and typed edges
- Hybrid retrieval combining lexical, source, and semantic search with RRF fusion
- Graph traversal and shortest path analysis over typed relationships
- Atomic snapshots for deterministic repository indexing and updates
- Multi-language support (Go, TypeScript, Python, Java, Rust, etc.)

## Why It Matters for RAG Builders
Codetrip enables RAG builders to transform raw codebases into structured, queryable knowledge graphs, enhancing semantic retrieval and dependency-aware context generation for AI applications.
