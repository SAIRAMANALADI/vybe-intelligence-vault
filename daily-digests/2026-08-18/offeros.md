## Summary
OfferOS is a local-first, open-source AI job-application copilot for the North American market. It provides a Next.js web app for managing job applications, tailoring résumés, drafting cover letters, and analyzing job postings, alongside a Chrome extension for autofilling ATS forms like Greenhouse, Lever, and Workday.

## Key Features
- Local-first architecture with SQLite for data storage and no cloud dependency
- Chrome extension for autofilling ATS forms (Greenhouse, Lever, Ashby, iCIMS, Workday) with tailored résumés and cover letters
- Agent workspace for grounded AI pipelines (résumé tailoring, JD analysis, cover letter generation) with user verification gates
- Prompt-injection fencing and security measures to prevent malicious input manipulation
- Privacy-focused design with server-side LLM key handling and no page HTML uploads

## Why It Matters for RAG Builders
OfferOS streamlines the job application process with AI-powered automation while prioritizing privacy and local control, making it valuable for developers building secure, user-centric AI tools.
