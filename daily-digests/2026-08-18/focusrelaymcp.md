## Summary
FocusRelay is a native Swift MCP server and CLI for macOS that enables AI assistants to interact with OmniFocus through documented APIs. It allows secure reading and updating of tasks, projects, and metadata while ensuring privacy and performance.

## Key Features
- Native Swift MCP server for fast, local OmniFocus interactions
- Supports 14 model-facing tools for reading and updating tasks/projects
- Preview and verification for safe updates with previews and post-save validation
- Compact responses to keep AI assistant queries focused and efficient
- Homebrew installation for easy macOS integration
