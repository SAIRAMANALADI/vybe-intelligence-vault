## Summary
AgentHub is a self-hosted, multi-agent platform designed to build and orchestrate teams of AI agents with real-time observability and production-grade security. It replaces chatbot-style agents with a full orchestration loop including Router, Executor, Critic, and Summarizer roles.

## Key Features
- Built-in multi-agent team orchestration with 6 specialized roles (Router, Planner, Executor, Critic, Summarizer, Search)
- Real-time streaming and logging with WebSocket/SSE for agent interactions and state tracking
- Production-grade security with JWT auth, RBAC, ABAC, and sandboxed code execution
- Pluggable search pipeline with BM25, dense vectors, and reranking with fallback mechanisms
- Comprehensive observability via Prometheus, Grafana, and OTLP tracing

## Why It Matters for RAG Builders
AgentHub provides a robust, self-hosted framework for building and managing teams of AI agents with production-grade orchestration, security, and observability, eliminating the need for custom multi-agent workflows.
