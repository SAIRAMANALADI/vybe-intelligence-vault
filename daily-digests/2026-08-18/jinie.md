## Summary
Jinie is an AI-driven desktop pipeline that converts natural language descriptions (including English, Urdu, and Roman Urdu) into production-ready React Native applications with Firebase hosting. It leverages self-trained ML models for requirement extraction, UI layout recommendation, and code generation, enabling local execution and reproducibility.

## Key Features
- Converts natural language prompts (including Urdu/English) into React Native apps with Firebase hosting
- Uses self-trained ML models (DistilBERT, CodeT5-small) for requirement extraction and code generation
- Provides a decoupled desktop client-server architecture for local execution and reproducibility
- Includes automated testing, preflight checks, and live deployment pipelines
- Supports interactive design token selection (colors, fonts, layouts) for customization

## Why It Matters for RAG Builders
Jinie accelerates mobile app development by automating the translation of requirements into production-ready React Native code, reducing development time and enabling non-technical users to build apps from natural language descriptions.
