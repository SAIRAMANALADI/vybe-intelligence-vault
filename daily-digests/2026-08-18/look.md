## Summary
Look is an image-to-action system that infers user intent from images, resolves ambiguities through research, and generates validated action drafts for tasks like calendar entries, shopping lists, receipt processing, and more. It ensures safety by requiring explicit user confirmation before executing any action.

## Key Features
- Infers intent from images (receipts, documents, menus, etc.)
- Resolves ambiguity via research and option reduction before prompting the user
- Generates validated action drafts requiring explicit user confirmation
- Supports multi-domain use cases (calendar, shopping, civic reports)
- Integrates with OCAS architecture for skill configuration

## Why It Matters for RAG Builders
Look streamlines structured action extraction from unstructured images, reducing manual input and improving automation for AI-driven workflows.
