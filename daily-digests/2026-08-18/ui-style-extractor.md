## Summary
ui-style-extractor is a Windows desktop application that extracts design systems (colors, fonts, spacing, layouts) from UI pages and converts them into reusable Markdown guides and validation demos. It helps maintain consistency in AI-generated pages or when replicating existing designs.

## Key Features
- Extracts colors, fonts, spacing, and layout rules from UI pages
- Generates reusable Markdown style guides and validation demos
- Supports local HTML files or live URLs as input sources
- Creates comparison demos to validate AI-generated pages against original designs
- Portable Windows application with no complex setup required

## Why It Matters for RAG Builders
It enables AI engineers to capture and replicate design systems accurately, ensuring consistency in AI-generated UI outputs.
