## Summary
ragent is a Rust-based AI coding agent for the terminal, offering multi-provider LLM orchestration, a comprehensive tool system, and a terminal UI. It supports local-first defaults, session management, and extensible agent presets with zero runtime dependencies.

## Key Features
- Multi-provider LLM support with local-first defaults (e.g., Ollama)
- Comprehensive tool system (~150 tools across 18 categories including file ops, shell, GitHub/GitLab, and browser automation)
- Terminal UI with ratatui, slash commands, and streaming chat with markdown rendering
- HTTP server for REST/SSE API integration with external frontends
- Session management, memory system, code indexing, and prompt optimization

## Why It Matters for RAG Builders
ragent provides a robust, extensible framework for building AI-powered coding agents with multi-provider LLM support and a rich tool ecosystem, making it essential for developers integrating agentic workflows into their RAG stacks.
