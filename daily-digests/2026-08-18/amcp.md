## Summary
AMCP is an out-of-the-box coding-agent runtime designed for immediate use in terminals, IDEs, servers, and Telegram. It provides a pre-configured multi-agent system with built-in tools, memory, skills, and MCP/ACP integration for autonomous and inspectable agent workflows.

## Key Features
- Built-in multi-agent architecture with primary/subagent roles (coder, explorer, planner, focused_coder)
- Persistent memory system with MEMORY.md and HISTORY.md for cross-session knowledge retention
- Extensible skills and slash commands system for custom agent behaviors
- Multiple interfaces: CLI, ACP for IDEs (e.g., Zed), HTTP/WebSocket server, and Telegram bot
- MCP/ACP integration for seamless tool and protocol compatibility

## Why It Matters for RAG Builders
AMCP provides a production-ready, extensible agent framework that accelerates RAG and AI stack development by offering pre-built multi-agent orchestration, memory, and tooling out of the box.
