## Summary
agentprobe is a Windows-based desktop application designed to test, validate, and secure AI agents by recording runs, checking outputs against rules, and identifying vulnerabilities like prompt injection risks. It emphasizes local-first testing, cost tracking, and observability for AI agent behavior.

## Key Features
- Records and replays AI agent runs for analysis
- Includes 35+ built-in assertions for output validation
- Performs prompt injection fuzzing to identify security risks
- Tracks token usage and cost per agent run
- Supports local-first testing with Windows desktop app

## Why It Matters for RAG Builders
It provides a critical safety and validation layer for AI agents by enabling rigorous local testing, reducing risks of prompt injection, and ensuring cost and behavior transparency before deployment.
