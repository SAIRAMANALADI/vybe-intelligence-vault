## Summary
Hope is an AI alignment and review tool designed to help users work with AI while maintaining visibility, understanding, and control over the process. It provides focused tools for aligning task understanding, reviewing work products, diffing code changes, refining completed work, and clarifying language.

## Key Features
- Align: Pre-implementation task alignment to surface misunderstandings and establish shared understanding before coding begins.
- Diff: Code change review tool that explains behavior, links claims to evidence, and generates interactive HTML artifacts for informed judgment.
- Toxic Review: Evidence-linked, prioritized review of work products to challenge assumptions without disrespecting contributors.
- Polish: Refines completed work within explicit preservation constraints to avoid unintended behavioral changes.
- Write: Language refinement tool that improves clarity without altering meaning, facts, or citations.

## Why It Matters for RAG Builders
