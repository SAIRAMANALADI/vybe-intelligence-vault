## Summary
A CLI tool and 44 Claude Code skills that automate Power BI analytics workflows, enabling natural-language prompts to generate TOM, ADOMD, TMDL, PBIR, and Fabric REST calls for data engineering, discovery, and delivery without web UIs or config sprawl.

## Key Features
- 44 pre-built Claude Code skills for Power BI workflows (DAX, TMDL, BPA, Deneb, Fabric CLI, etc.)
- CLI-based automation with direct TOM/ADOMD/Fabric REST interop for Power BI Desktop and Fabric
- Multi-install detection for Power BI Desktop (MSI and Microsoft Store variants)
- Seamless integration with Claude Code for natural-language prompt execution
- Supports data engineering, discovery, and delivery workflows with minimal configuration

## Why It Matters for RAG Builders
It streamlines Power BI analytics workflows by automating complex tasks through natural language, reducing manual effort and accelerating board-ready report delivery.
