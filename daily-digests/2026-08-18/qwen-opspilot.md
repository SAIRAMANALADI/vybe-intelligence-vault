## Summary
Qwen OpsPilot is an evidence-first autopilot agent designed to diagnose and simulate remediation for ambiguous Windows operational symptoms using Qwen's planning and diagnostic capabilities. It enforces strict safety policies, requires human approval for simulated changes, and generates deterministic audit reports without altering real systems.

## Key Features
- Ambiguous symptom diagnosis with live Qwen planning and evidence citations
- Strict schema-validated read-only tool execution with policy-based denials
- Human-in-the-loop approval for simulated remediation with HMAC-bound integrity
- Deterministic verification and audit report generation without real system changes
- Offline deterministic testing with optional live Qwen integration
