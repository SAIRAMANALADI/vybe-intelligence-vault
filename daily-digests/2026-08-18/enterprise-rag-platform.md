## Summary
A production-grade Retrieval-Augmented Generation (RAG) platform built as a distributed Spring Boot microservices system with PostgreSQL/pgvector for vector storage, local Ollama models for inference, and a browser-based UI. It supports document ingestion, multi-modal data handling, and dynamic diagram generation from text content.

## Key Features
- Distributed Spring Boot microservices architecture with independent services for auth, ingestion, RAG, and chat
- PostgreSQL + pgvector for vector storage with hybrid search capabilities
- Local-first inference via Ollama (no external API dependencies for embeddings or chat)
- Multi-modal document ingestion (PDF, DOCX, Markdown, images via vision models, audio via Whisper)
- Dynamic diagram generation from text content using Mermaid.js and LLM reasoning

## Why It Matters for RAG Builders
It provides a production-ready, scalable RAG platform with local-first inference and multi-modal support, reducing dependency on external APIs while ensuring enterprise-grade reliability and security.
