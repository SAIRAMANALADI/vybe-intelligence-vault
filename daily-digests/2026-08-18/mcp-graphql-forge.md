## Summary
mcp-graphql-forge is a lightweight, configuration-driven MCP server that converts GraphQL endpoints into modular MCP tools defined via YAML files, enabling secure and intentional API interactions for AI agents.

## Key Features
- Configuration-driven tool generation via YAML files for GraphQL queries
- Support for multiple output formats (raw, JSON, TOON) optimized for LLM consumption
- Modular and secure API interactions with configurable authentication
- Lightweight and extensible with pre-compiled binaries for multiple platforms
- Dual-mode operation (stdio and streamable HTTP) for flexible deployment

## Why It Matters for RAG Builders
It simplifies integrating GraphQL APIs into AI agents by abstracting queries into reusable MCP tools, reducing development overhead and enhancing security.
