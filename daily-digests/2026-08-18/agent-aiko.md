## Summary
Agent-Aiko is a personality-driven AI agent framework that enables users to assign, customize, and switch between AI personas (e.g., Aiko) across multiple agent environments like Claude Code, Codex, and Gemini CLI. It provides tools for persona management, voice interaction, and multi-agent orchestration.

## Key Features
- Cross-platform persona management for Claude Code, Codex, and Gemini CLI with unified configuration storage in `~/.aiko/`
- Dynamic persona switching via slash commands (e.g., `/aiko-mode`, `/aiko-select`) with support for named personas and fuzzy matching
- Built-in voice interaction (TTS) with multiple engine support (say, VOICEVOX, Irodori-TTS, avatar) and daemon mode for background operation
- Persona export/import functionality for sharing custom personas without exposing user-specific data
- Reference implementation for multi-agent operations (e.g., Reviewer, Scout, Lab, Janitor) in the `reference/` directory

## Why It Matters for RAG Builders
Agent-Aiko simplifies the deployment and management of consistent AI personas across different agent frameworks, enabling RAG builders to create and switch between specialized personas for varied tasks without reinventing the wheel.
