## Summary
Browy is a Chromium extension that integrates with GitHub Copilot to enable AI-driven automation within real browser tabs. It provides both a side panel chat and a DevTools panel CLI for interacting with web pages, automating tasks, and debugging via the Chrome DevTools Protocol.

## Key Features
- Real browser tab interaction via accessibility tree snapshots and Chrome DevTools Protocol
- Dual UI surfaces: side panel chat for day-to-day tasks and DevTools panel CLI for power users
- Leverages existing GitHub Copilot subscription for model access, avoiding additional API costs
- Local-first architecture with no server-side processing or telemetry collection
- Supports multi-step automation, form filling, scraping, and debugging with first-class tools

## Why It Matters for RAG Builders
Browy enables AI agents to directly interact with real browser environments, bridging the gap between AI automation and practical web-based workflows for developers and power users.
