## Summary
Blast Radius Autopilot is an autonomous agent that computes evidence-backed column-level change impact from query history and downstream SQL definitions, generates migration fixes, statically verifies its own patches, and contributes assessments back to a data catalog like DataHub. It operates within a structured build loop with verified discipline and public-data constraints.

## Key Features
- Autonomous build loop with verified discipline and living documentation
- Computes column-level change impact from query history and SQL lineage
- Generates and statically verifies migration fixes before catalog write-back
- Gated write-back mechanism with PASS/REVIEW_REQUIRED/FAIL verdicts
- Dataset-agnostic and public-data-only compliance

## Why It Matters for RAG Builders
It enables automated, evidence-backed schema change management with built-in safety guarantees, reducing manual review overhead for RAG and AI stack builders.
