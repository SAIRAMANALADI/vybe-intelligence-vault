## Summary
A native iOS and macOS productivity app that allows users to manage to-dos and appointments via voice or text input, with on-device AI parsing and iCloud sync. Features include natural language scheduling, built-in calendar, sub-lists, and a Hermes agent terminal for advanced automation on macOS.

## Key Features
- Natural language input for tasks and appointments with on-device AI parsing
- Built-in calendar with graphical month view and reminders
- Sub-lists and drag-to-rearrange functionality with iCloud sync
- Hermes agent terminal for macOS with planner:// command bridge
- Full undo support and local data privacy
