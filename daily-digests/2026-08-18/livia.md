## Summary
Livia is a self-hosted AI executive assistant that automates scheduling, correspondence, research, and bookings via a dedicated Gmail inbox. It integrates with Anthropic's API for reasoning and Google APIs for calendar and email operations, configured entirely through a web-based setup wizard.

## Key Features
- Self-hosted AI executive assistant with zero code configuration
- Integrates with Gmail and Google Calendar for scheduling and correspondence
- Uses Anthropic API for natural language understanding and drafting responses
- Web-based setup wizard for easy configuration and deployment
- Supports agent harness connectivity via standardized endpoints (e.g., `/task`, `/chat`)

## Why It Matters for RAG Builders
Livia provides a practical, self-hosted framework for building AI agents that interact with real-world tools like email and calendars, reducing the complexity of integrating AI into business workflows.
