## Summary
A Spring Boot application that automates GitHub Pull Request reviews using Anthropic's Claude API via Spring AI. It fetches PR changes, sends them to Claude for structured review, aggregates results, and emails a detailed HTML report to configured recipients without posting comments back to GitHub.

## Key Features
- Automated PR review using Anthropic Claude via Spring AI
- Asynchronous processing with immediate webhook response (202 Accepted)
- Structured JSON-based review aggregation and scoring
- HTML email reporting with color-coded severity breakdowns
- GitHub webhook signature validation and event filtering

## Why It Matters for RAG Builders
It streamlines code review workflows by automating PR analysis with AI, reducing manual effort and accelerating feedback cycles for development teams.
