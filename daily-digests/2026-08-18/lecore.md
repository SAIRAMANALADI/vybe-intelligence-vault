## Summary
leCore is a foundational engine that unifies memory, geometry, physics, and computation by representing all data as hypervectors in a high-dimensional space, processed with reversible algebraic operations. Built with pure NumPy, it enables associative memory, structured knowledge reasoning, 3D rendering, physics simulation, and program execution within a single substrate.

## Key Features
- Represents all data types (memory, geometry, physics) as hypervectors in a unified space
- Uses reversible algebraic operations (bind, bundle, cleanup) for computation
- Supports associative memory, structured knowledge reasoning, and program execution
- Includes optional accelerators (Numba, Zig, CuPy) for performance
- Provides a plain-language capability catalog for dynamic tool discovery

## Why It Matters for RAG Builders
leCore provides a single, interpretable substrate for integrating memory, geometry, and physics into RAG systems without relying on neural networks or GPUs, enabling more transparent and composable AI architectures.
