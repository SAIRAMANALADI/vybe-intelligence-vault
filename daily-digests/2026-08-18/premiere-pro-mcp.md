## Summary
An MCP (Model Context Protocol) server that enables AI assistants to directly control Adobe Premiere Pro through 269 tools, covering media import, timeline editing, effects, keyframes, and export workflows via ExtendScript and QE DOM APIs.

## Key Features
- 269 tools covering media import, timeline editing, effects, keyframes, and export workflows
- File-based IPC bridge for reliable cross-platform communication between AI clients and Premiere Pro
- Extensive project and sequence inspection tools for real-time AI-driven editing
- Support for remote deployment via Fly.io for cloud-based MCP clients
- Comprehensive ExtendScript API reference and best practices resources for AI context
