## Summary
Gotham Grid is a retro-styled agentic dashboard that tracks creative and civic tech projects across major cities using a multi-loop AI agent. It combines GitHub API searches with optional Tavily web searches and Groq LLM parsing to surface and score projects, with full tool call tracing and cost controls.

## Key Features
- Multi-loop AI agent with quality scoring and query refinement (up to 3 loops)
- Dual-source discovery: GitHub API + optional Tavily web search with Groq LLM parsing
- Real-time tool call tracing, cost budgeting ($0.10 cap), and timeout guards
- CRT phosphor terminal aesthetic with boot sequence and VT323 font
- Static city data layer for instant load, with live scan mode for dynamic updates

## Why It Matters for RAG Builders
