## Summary
A global configuration repository for OpenCode, a terminal-based AI coding agent. It provides reusable commands, skills, and MCP server configurations via an OCX bundle, enabling customizable AI coding workflows with provider integrations and TUI keybindings.

## Key Features
- Pre-configured OCX bundle for OpenCode with reusable commands and skills
- Support for multiple AI providers (OpenAI, Google) with custom base URLs and API keys
- Customizable TUI themes, keybindings, and plugins for OpenCode
- Integration with Context7 MCP server for enhanced AI workflows
- Automated release and registry publishing via GitHub Actions

## Why It Matters for RAG Builders
It provides a standardized, reusable configuration framework for OpenCode, simplifying the setup of AI coding agents with pre-configured providers, MCP servers, and TUI customizations.
