## Summary
A design toolkit enabling AI agents to compose layered HTML-based visuals (e.g., marketing materials) with a Figma-like browser editor, supporting pixel-perfect PNG exports without AI token consumption. Focuses on Vietnamese text safety and modular workflows for AI-driven design processes.

## Key Features
- Layered HTML composition system (Background → Art → Adjustment → Text) with slot-based templates for modular design
- In-browser Figma-like review editor with multi-select, snap guides, undo/redo, comments, and bilingual UI (Vietnamese/English)
- Local review server enabling one-click Save-to-source and Export-PNG operations without AI token usage
- Knowledge scaffold (sessions/patterns/prompts) for iterative AI agent workflows and prompt refinement
- Supports offline font fetching, transparent asset trimming, and CSS-based adjustments for non-destructive edits

## Why It Matters for RAG Builders
It enables AI agents to design and review visuals efficiently without token-heavy AI image generation, ensuring pixel-perfect outputs and language safety for non-Latin scripts.
