## Summary
Jigen DB is a high-performance vector database written from scratch in C# for the .NET platform. It supports both in-process embeddings and standalone server deployment with gRPC/REST APIs, optimized for AI applications requiring efficient vector search and storage.

## Key Features
- In-process engine with memory-mapped storage and crash recovery
- Disk-backed HNSW approximate nearest neighbor indexing with concurrent operations
- Standalone server with gRPC/REST APIs and typed .NET client
- Built-in text embedding generation via ONNX Runtime (CPU/GPU support)
- Content filtering and periodic durability checkpoints for data persistence

## Why It Matters for RAG Builders
Jigen DB provides a performant, .NET-native vector database solution with embedded or server deployment options, critical for AI applications needing scalable and efficient vector search in C# ecosystems.
