## Summary
A public Model Context Protocol (MCP) server deployed as a Cloudflare Worker that converts GitHub repositories or documentation sites into agent-ready context. It enables AI agents to either pack entire repos into token-counted blobs or search for relevant passages with file/line references.

## Key Features
- Converts entire GitHub repos or documentation sites into agent-ready context blobs
- Supports both packing (full repo) and searching (relevant passages) with file/line references
- Integrates Mozilla Readability and Turndown for HTML-to-Markdown conversion
- Implements SSRF protection and bounded fetching for security
- Deployable as a Cloudflare Worker with optional GitHub token authentication

## Why It Matters for RAG Builders
It provides a critical layer for RAG pipelines by transforming raw repositories and documentation into structured, searchable, and token-efficient context for AI agents.
