## Summary
easyclaude provides a local, browser-based graphical interface for the full Claude Code agent, enabling non-technical users to interact with a powerful coding agent without using a terminal. It includes security profiles, multi-agent orchestration, and project management while running entirely on the user's machine.

## Key Features
- Full Claude Code agent capabilities exposed via a visual UI with streaming activity and file diffs
- Three configurable security profiles (Locked, Standard, Open) with OS-level sandboxing and command filtering
- Multi-agent orchestrator for parallel task execution across roles (e.g., backend, frontend)
- Project management dashboard with conversation history and automatic state restoration
- Local-only server with anti-CSRF protection and confinement to a single project folder

## Why It Matters for RAG Builders
It democratizes access to advanced AI coding agents by providing a user-friendly interface that lowers the barrier to entry for non-technical users while maintaining robust security and multi-agent capabilities.
