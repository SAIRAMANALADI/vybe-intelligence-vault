## Summary
Metrik is a local-first desktop application that tracks and visualizes AI agent usage metrics, including official quotas, locally parsed token counts, and estimated costs based on public pricing. It operates offline, avoids displaying unavailable or fabricated data, and supports multiple agents like ChatGPT, Claude, and Kimi.

## Key Features
- Real-time desktop widget displaying usage metrics with customizable opacity and positioning
- Separation of official quotas, local token parsing, and cost estimates to avoid misleading billing data
- Multi-agent support with detailed session breakdowns, CSV export, and cost estimation based on public pricing
- Multi-device synchronization via shared folders (e.g., Syncthing, OneDrive) for aggregated statistics
- Strict privacy: no storage of conversation content, no default credential access, and offline-first operation

## Why It Matters for RAG Builders
It provides accurate, local-first tracking of AI agent usage metrics without relying on cloud APIs, ensuring privacy and cost transparency for developers and users.
