## Summary
A hands-on playground demonstrating Spring AI 2.0 patterns including chat, RAG, structured extraction, tool-calling agents, and multi-agent orchestration. The project integrates a local Ollama LLM with a pgvector-backed PostgreSQL store and features a SvelteKit frontend for interactive exploration.

## Key Features
- Interactive AI chat with streaming and blocking responses
- Document ingestion pipeline with Apache Tika and pgvector embeddings
- Structured extraction of unstructured text into typed POJOs
- Tool-calling autonomous agents with simulated Java tool beans
- Concurrent multi-agent orchestration with virtual thread support

## Why It Matters for RAG Builders
It provides a practical reference for implementing Spring AI 2.0 patterns like RAG, agents, and orchestration with a modern frontend, accelerating AI stack development.
