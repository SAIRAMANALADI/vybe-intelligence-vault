## Summary
browser-harness-bidi provides a lightweight, WebDriver BiDi-compliant harness to connect LLMs directly to real browsers for automation, inspection, and interaction. It enables agents to dynamically extend functionality via editable helper workspaces while adhering to W3C standards for cross-browser automation.

## Key Features
- WebDriver BiDi-first architecture for future-proof browser automation
- Editable agent workspace for dynamic helper code injection during execution
- Managed browser sessions (Firefox/Chrome) via CLI commands (`bidi-firefox`, `bidi-chrome`)
- Comprehensive interaction and domain skills for reusable automation patterns
- Network observation, storage manipulation, and screenshot capabilities

## Why It Matters for RAG Builders
It provides a standards-compliant, agent-editable browser harness that bridges LLMs to real-world browser automation, enabling dynamic and self-improving web interaction workflows.
