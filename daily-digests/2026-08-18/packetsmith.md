## Summary
PacketSmith is a terminal-based agent that enables natural language interaction with Cisco Packet Tracer to build and visualize network topologies in real-time. It acts as a user-friendly interface on top of the MCP-Packet-Tracer extension, providing a split-screen TUI for live network configuration and monitoring.

## Key Features
- Natural language interface for network configuration via terminal
- Real-time topology visualization in a split-screen TUI
- Integration with MCP-Packet-Tracer for direct Packet Tracer control
- Supports live tool result streaming and state tracking
- Modular engine system for easy addition of new AI agents (e.g., Codex, OpenCode)

## Why It Matters for RAG Builders
PacketSmith simplifies network topology design and automation by bridging natural language with Cisco Packet Tracer, making it accessible for AI-driven network engineering workflows.
