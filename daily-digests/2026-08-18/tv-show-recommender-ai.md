## Summary
TV-Show-Recommender-AI is a desktop application that provides personalized TV show recommendations using embeddings, cosine similarity, and fuzzy matching. It also generates AI-powered posters and suggestions to enhance user experience.

## Key Features
- Personalized TV show recommendations based on user favorites
- Uses embeddings and cosine similarity for accurate matching
- Fuzzy matching to handle typos and imprecise inputs
- AI-generated posters and show ideas via OpenAI integration
- Cross-platform support (Windows, macOS, Linux) with a simple CLI
