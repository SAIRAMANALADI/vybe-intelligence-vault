## Summary
MCPGate is an enterprise-grade MCP (Model Context Protocol) bridge and agent server written in Go, providing a secure, self-updating bridge for MCP clients and servers with a React-based management dashboard.

## Key Features
- Enterprise-grade MCP bridge with agent and bridge modes for MCP clients/servers
- Self-updating binary with SHA256 and ed25519 signature verification for security
- React + TypeScript management dashboard embedded in the binary for monitoring and configuration
- Cross-platform support (Linux, macOS, FreeBSD, Windows) with automated installers
- Built-in SQLite database for tasks, audits, and configuration with workspace isolation

## Why It Matters for RAG Builders
MCPGate simplifies the integration of MCP-compliant clients and servers into AI workflows by providing a secure, self-managing bridge with built-in orchestration and monitoring capabilities.
