## Summary
Newmark Agent is a local-first desktop workspace for AI-assisted software development, research, and automation, offering a unified GUI, TUI, and CLI with multi-model routing, persistent workspaces, and controlled tool access. It emphasizes user privacy by keeping all data and credentials locally stored.

## Key Features
- Multi-model work with audited auto-routing based on capability, cost, and reliability signals
- Persistent workspaces with conversation, drafts, archives, and workflows scoped to targets
- Three interfaces (GUI, TUI, CLI) sharing the same backend and local state
- Controlled tool access with policy and approval boundaries for terminal, files, browser, GitHub, SSH, and automation
- Long-running work with context compression, durable runs, and resumable execution

## Why It Matters for RAG Builders
Newmark Agent provides a privacy-focused, local-first agent framework with multi-model routing and controlled tool access, making it essential for building secure, customizable AI workflows without relying on hosted backends.
