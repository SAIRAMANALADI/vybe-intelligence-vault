## Summary
Archivist is a production-ready Retrieval-Augmented Generation (RAG) system built with FastAPI that enables document ingestion, semantic/hybrid search, cross-encoder re-ranking, and LLM-powered answer generation. It supports pluggable LLM and vector database providers, with full observability via Prometheus and Grafana.

## Key Features
- Pluggable LLM and vector database providers (OpenAI, Cohere, Qdrant, PostgreSQL/pgvector)
- Hybrid search combining dense vector and keyword-based retrieval with RRF
- Cross-encoder re-ranking for improved precision in retrieval
- Golden-dataset-driven evaluation for retrieval metrics (Recall@k, Precision@k, MRR)
- Full observability stack with Prometheus and Grafana for monitoring

## Why It Matters for RAG Builders
Archivist provides a robust, production-grade RAG pipeline with modular components for LLM and vector DB integration, making it essential for AI engineers building scalable and observable retrieval systems.
