## Summary
SuperLocalMemory is a local-first agent memory system designed for persistent agent context with explicit operating modes, auditable retrieval, and optional optimization tools. It supports three deployment surfaces: proxy, MCP tools, or skill, and combines dense/lexical retrieval with graph, temporal, and associative scoring without requiring Docker or cloud APIs by default.

## Key Features
- Three deployment surfaces: Proxy, MCP tools, or Skill for flexible integration
- Combines semantic, lexical, temporal, graph, and Hopfield retrieval methods
- Local-first runtime with optional cloud backup and enrichment (provider-backed)
- Explicit memory boundaries (personal, shared, global) with default-deny cross-profile recall
- Built-in cache, compression, and audit controls with provenance tracking

## Why It Matters for RAG Builders
SuperLocalMemory provides a unified local-first memory control plane for RAG builders, enabling persistent agent context with auditable retrieval and privacy-preserving operations without mandatory cloud dependencies.
