## Summary
ASDD (Agentic Spec-Driven Development) is a contribution pipeline for AI-assisted software projects that enforces strict disclosure, security, and review gates to minimize defects in AI-authored code. It ensures every change is attributable, reviewed against a spec, and merged by a human, with automated checks blocking unvalidated or unsafe contributions.

## Key Features
- Mandatory authorship disclosure for AI-generated code in PRs and commit trailers
- Deterministic intake gate with hard checks (DCO, lane tags, disclosure)
- Multi-lens review (code, security, spec, quality) with independent model calls
- Human-controlled merge authority with tiered auto-merge options
- Security lens with deterministic rules, SAST, and model-based analysis

## Why It Matters for RAG Builders
ASDD provides a critical safety and governance layer for AI-assisted software development by enforcing rigorous checks and human oversight to prevent defects and security risks in AI-authored code.
