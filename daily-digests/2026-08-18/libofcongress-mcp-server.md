## Summary
A Model Context Protocol (MCP) server providing access to the Library of Congress (LOC) digital collections, Chronicling America newspapers, and LC Subject Headings. Enables search, retrieval, and structured metadata access via STDIO or HTTP for AI agents.

## Key Features
- Six specialized tools for searching LOC digital collections, newspapers, and subject headings with full OCR text
- Structured metadata retrieval for LOC items including contributors, subjects, and resource links
- Chronicling America newspaper search with OCR text excerpts and full-page OCR retrieval
- LC Subject Headings (LCSH) lookup with controlled vocabulary and stable URIs
- Configurable rate limiting, error handling, and recovery hints for robust AI agent integration

## Why It Matters for RAG Builders
It provides structured, high-quality access to the Library of Congress's vast digital archives, enabling AI agents to retrieve authoritative historical and cultural data for RAG applications.
