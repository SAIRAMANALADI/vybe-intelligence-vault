## Summary
Marqo is an open-source, multimodal vector search engine that enables developers to index text and images, generate embeddings on-the-fly, and perform tensor, lexical, or hybrid search via a single REST API. It bundles model inference (e.g., Sentence Transformers, OpenCLIP) internally and supports self-hosting with minimal setup.

## Key Features
- Supports text and image indexing with multimodal embeddings
- Offers tensor, lexical, and hybrid search capabilities
- Bundles model inference (Sentence Transformers, OpenCLIP) internally
- Single REST API for index management, search, and embedding generation
- Self-hostable via Docker with minimal configuration

## Why It Matters for RAG Builders
Marqo simplifies the integration of multimodal vector search into RAG pipelines, reducing the need for external embedding services and enabling hybrid retrieval strategies.
