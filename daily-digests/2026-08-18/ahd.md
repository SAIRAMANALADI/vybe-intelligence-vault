## Summary
AHD is a guardrail and evaluation framework for AI-generated design, including web UI and image generation. It provides a named taxonomy of design failures, a prompt compiler to constrain model outputs, and a reproducible evaluation loop to score raw vs. compiled outputs against the taxonomy.

## Key Features
- Named taxonomy of 39 AI design slop tells with versioned and linted rules
- Prompt compiler that converts structured briefs into constrained model instructions
- Reproducible evaluation loop with weekly CI workflows and published reports
- Multi-modal vision critic for scoring rendered outputs against design rules
- MCP server for integration with AI agents and editor plugins

## Why It Matters for RAG Builders
AHD provides a standardized way to measure and reduce AI design failures, ensuring higher-quality outputs for RAG and AI stack builders.
