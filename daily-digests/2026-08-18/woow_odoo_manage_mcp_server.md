## Summary
A production-ready admin bundle for managing ivnvxd/mcp-server-odoo, providing a web GUI, built-in MCP reverse proxy, and process manager all in a single container. It simplifies MCP server administration with real-time monitoring, token management, and Odoo connection configuration.

## Key Features
- All-in-one container with web GUI, MCP reverse proxy, and process manager
- Real-time dashboard with health monitoring and log streaming
- Built-in MCP reverse proxy replacing nginx for token-authenticated access
- One-click token rotation and permission management
- Supports Standard and YOLO modes for Odoo connection flexibility

## Why It Matters for RAG Builders
It streamlines the management of MCP servers integrated with Odoo, reducing operational overhead and enabling non-technical users to administer MCP tools via a browser.
