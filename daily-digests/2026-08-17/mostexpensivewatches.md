## Summary
MostExpensiveWatches provides a free, open dataset and API for ultra-luxury watch auction records, including hammer prices, market estimates, and brand information. It offers an MCP server, CLI tool, and comprehensive datasets for AI agents and applications.

## Key Features
- Free, no-API-key HTTP/JSON-RPC API with 43 endpoints for watch auction data
- MCP server integration for AI agents with tools like search_inventory and get_market_estimate
- CC-BY 4.0 licensed datasets (1,150+ hammer prices, grail index, price index) with daily updates
- Python CLI tool (mew.py) for dependency-free local queries
- OpenAPI 3.1 documentation and live snapshots for easy integration

## Why It Matters for RAG Builders
It provides high-quality, structured luxury watch auction data essential for AI-driven market analysis, valuation models, and agent-based applications.
