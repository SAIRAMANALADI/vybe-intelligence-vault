## Summary
A monorepo hosting multiple AceDataCloud MCP (Model Context Protocol) servers, each providing specialized functionality like vision, audio, image generation, video processing, search, and utility tools. The servers are automatically published to PyPI, VS Code Marketplace, JetBrains Marketplace, Smithery, and the MCP Registry.

## Key Features
- Monorepo structure with modular MCP servers for different functionalities (vision, audio, video, search, etc.)
- Automated publishing pipeline to PyPI, VS Code, JetBrains, Smithery, and MCP Registry
- Sync pipeline ensures consistency between documentation and server implementations
- Supports CalVer versioning for reliable updates
- CI/CD with linting (ruff) and testing (pytest) for Python 3.10/3.11/3.12

## Why It Matters for RAG Builders
This monorepo provides a centralized and automated way to deploy and manage multiple MCP servers, simplifying integration for RAG builders who need multi-modal or specialized AI tooling.
