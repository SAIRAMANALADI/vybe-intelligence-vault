## Summary
A local-first Model Context Protocol (MCP) server designed to automate Schema.org JSON-LD generation, GA4 metric validation, /llm.txt auditing, and content stickiness analytics for AI-driven content optimization and search engine visibility.

## Key Features
- Automated Schema.org JSON-LD generation for tech articles and FAQ pages
- GA4 metric validation and content stickiness scoring
- /llm.txt auditing for AI search engine compatibility
- Security.txt and RFC 9116 compliance auditing
- Structured answer snippet extraction for Perplexity and SearchGPT
