## Summary
Unterm is a cross-platform terminal designed to be controllable by AI agents via MCP (Model Context Protocol) and JSON-RPC. It serves as an 'Agent Cockpit' for managing multiple AI agents, providing features like live agent state tracking, an Inbox for prioritized tasks, and a Review system for diffing, merging, and rolling back agent outputs.

## Key Features
- MCP-controllable terminal with 103 authenticated methods for AI agent integration
- Agent Cockpit for managing live agent states, Inbox, and fleets of agents in isolated worktrees
- Review system for diffing, merging, and rolling back agent outputs with verification
- Cross-platform support (macOS, Linux, Windows) with GPU-accelerated rendering
- Local-first architecture with no cloud dependency for core operations

## Why It Matters for RAG Builders
Unterm provides a critical orchestration layer for AI agents to interact with terminals, enabling seamless automation, supervision, and collaboration across multiple agents in a unified cockpit.
