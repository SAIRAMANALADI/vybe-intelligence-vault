## Summary
ArchRenderAgent automates the conversion of architectural massing screenshots into photorealistic renders using a local Chrome browser and the user's own ChatGPT or Gemini subscription. It ensures faithfulness to the original design while allowing manual refinements and iterative improvements.

## Key Features
- Faithful iterative rendering with tamper checks against the original base image
- Quota-saving dual-path iteration (incremental edits vs. full redraws)
- Region-specific manual edits with freehand tools
- Bilingual UI (Chinese/English) with persistent language preference
- Offline vision model support (Ollama) and local super-resolution (Swin2SR)

## Why It Matters for RAG Builders
It enables architects and designers to generate high-quality architectural renders locally using their own AI subscriptions while maintaining strict control over the design fidelity and iterative process.
