## Summary
mcp-bright-data is a Model Context Protocol (MCP) server that integrates Bright Data's Web Unlocker and SERP APIs, enabling AI agents to access web scraping and search engine results data. It is part of the Pipeworx gateway, which connects agents to over 1325 live data sources.

## Key Features
- Provides MCP-compatible access to Bright Data's Web Unlocker for web scraping
- Offers SERP API integration for search engine results data
- Part of the Pipeworx gateway, enabling access to 1325+ data sources
- Supports plain English queries via ask_pipeworx for simplified tool usage
- Designed for seamless integration with AI agents like Claude Desktop and Cursor

## Why It Matters for RAG Builders
It enables AI agents to reliably access real-time web and search data through a standardized MCP interface, critical for RAG systems requiring up-to-date information.
