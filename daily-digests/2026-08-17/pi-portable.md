## Summary
Pi Portable provides a no-install launcher for the pi coding agent, enabling it to run directly from a USB drive or folder across Windows, macOS, and Linux. It bundles a portable Node.js runtime and keeps all state, dependencies, and configurations within the drive itself.

## Key Features
- Bundles portable Node.js runtime to avoid system dependencies
- Keeps all state, configurations, and dependencies within the drive folder
- Supports authentication via API keys or provider login (Claude, ChatGPT, etc.)
- Includes a sync command to mirror laptop configurations to the drive
- Works on Windows, macOS, and Linux with platform-specific launchers

## Why It Matters for RAG Builders
It enables AI engineers to run the pi coding agent in a truly portable, no-install environment, ensuring consistency across machines and simplifying deployment for RAG stacks.
