## Summary
Ollamancer is a fully-local, terminal-first AI agent for Ollama designed for honesty, small-model reliability, and privacy. It operates entirely offline, offering 34 native tools, MCP integration, local RAG, vision capabilities, and dual-model planning while ensuring deterministic controls against hallucinations.

## Key Features
- 34 native tools + MCP servers + full shell access for agentic workflows
- Local RAG with `bge-m3` embeddings for semantic code search
- Deterministic hallucination controls and small-model reliability engineering
- Dual-model planning/execution and cross-model review for quality assurance
- Privacy modes (ephemeral sessions, offline operation) and Docker sandboxing

## Why It Matters for RAG Builders
It provides a privacy-preserving, locally deployable agent framework with built-in reliability and honesty controls, critical for RAG builders needing trustworthy, offline-capable AI agents.
