## Summary
An MCP server enabling LLMs to interact with OPC-UA industrial automation servers for reading, writing, browsing, searching, and subscribing to live data via stdio or HTTP with persistent caching and searchable address space indexing.

## Key Features
- Read/write OPC-UA node values with type validation
- Subscribe to live data updates with persistent caching
- Browse and search OPC-UA address space with fuzzy matching
- Persistent caching of reads, browse results, and type info
- Supports multiple authentication modes (anonymous, username/password, certificate)

## Why It Matters for RAG Builders
It bridges LLMs with industrial automation systems, enabling secure and efficient real-time data access for AI-driven control and monitoring in manufacturing and IoT environments.
