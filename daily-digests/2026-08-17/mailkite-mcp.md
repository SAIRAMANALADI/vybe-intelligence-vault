## Summary
@mailkite/mcp is an official Model Context Protocol (MCP) server for MailKite, enabling AI agents to send and receive emails via a verified domain. It provides tools for email management, domain verification, and inbox routing, designed to integrate seamlessly with AI-driven workflows.

## Key Features
- Provides MCP-compliant tools for AI agents to send and receive emails
- Supports verified domain integration for secure email operations
- Offers inbox routing with built-in agent capabilities for automated responses
- Available as a hosted service or local installation with static API keys
- Part of a unified MailKite API contract across multiple programming languages
