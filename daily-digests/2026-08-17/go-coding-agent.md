## Summary
A Go-based coding agent harness designed for real-world software engineering tasks, emphasizing reliable execution, context management, and safety boundaries. It provides a runtime for agentic workflows with tool calling, session recovery, and traceability.

## Key Features
- Agent runtime with streaming responses, tool calling, and session limits
- Safety mechanisms including workspace isolation, symlink protection, and human approval
- Incremental JSONL-based context persistence and session recovery
- Optional JSONL tracing for observability of runs, model calls, and tool executions
- CLI-driven interaction with TTY support and session control commands
