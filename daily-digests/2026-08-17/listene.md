## Summary
ListenE is an AI-powered English learning agent that integrates listening materials, interactive flashcards, sentence review, and a learning workspace. It consists of a NestJS backend with PostgreSQL and an Android Jetpack Compose client.

## Key Features
- AI-driven English listening practice with smart flashcards
- Sentence and vocabulary review with LLM-powered insights
- Unified learning workspace for structured study sessions
- Cross-platform backend (NestJS) and Android client (Jetpack Compose)
- PostgreSQL database for persistent learning data
