## Summary
A hardened TypeScript MCP server providing secure, read-only access to Google Search Console for AI agents with strict property allowlisting and resource containment policies.

## Key Features
- Strict read-only access via Google's `webmasters.readonly` scope
- Exact property allowlisting with normalization-aware validation
- Bounded execution limits (input/output, concurrency, timeouts)
- Agent-ready MCP protocol with Zod-typed tool contracts
- Multiple authentication modes (stored OAuth tokens or ADC)
