## Summary
A Zendesk MCP (Model Context Protocol) pack that enables AI agents to interact with Zendesk data via OAuth, including tools for listing, retrieving, and searching tickets and users. It is part of the Pipeworx gateway, which connects AI agents to over 1394 data sources.

## Key Features
- Provides MCP tools for Zendesk ticket and user management (list, get, search)
- Supports OAuth authentication for secure access to Zendesk data
- Integrates with Pipeworx gateway for broader data source connectivity
- Enables plain English queries via `ask_pipeworx` for simplified AI agent interactions
- Offers pagination support for handling large datasets

## Why It Matters for RAG Builders
It simplifies AI agent integration with Zendesk by providing standardized MCP tools, enabling seamless retrieval and management of support data for RAG applications.
