## Summary
A production-grade MCP server and REST API for automating Google NotebookLM, offering 33 endpoints for Q&A, content generation (audio, video, infographics, reports, presentations), and source management. Supports multi-account rotation, Docker deployment, and integration with n8n, Zapier, and Claude Code.

## Key Features
- 33 REST endpoints for NotebookLM integration (n8n, Zapier, Make, curl)
- MCP server for Claude Code, Cursor, and Codex with structured tooling
- Citation-backed Q&A with 5 source citation formats (inline, footnotes, JSON, etc.)
- Multi-format content generation (audio, video, infographics, reports, presentations)
- Multi-account rotation with auto-reauthentication for long-running batches

## Why It Matters for RAG Builders
It provides a robust, scalable interface to Google NotebookLM for AI workflows, enabling automated Q&A, content generation, and retrieval-augmented generation (RAG) pipelines with citation-backed accuracy.
