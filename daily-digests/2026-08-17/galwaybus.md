## Summary
GalwayBus is a Kotlin Multiplatform app that displays real-time bus times for Galway city across Android, iOS, and Desktop platforms. It provides live departures, nearby stops, on-map tracking, and stop search functionality using a shared Compose Multiplatform UI and a Ktor backend for GTFS data.

## Key Features
- Cross-platform UI with Compose Multiplatform (Android, iOS, Desktop)
- Real-time bus tracking and live departures using GTFS-Realtime data
- Nearby stops discovery and stop search functionality
- Shared business logic across platforms with Kotlin Multiplatform
- Integration with Google Maps for live tracking visualization
