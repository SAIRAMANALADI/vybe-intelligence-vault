## Summary
An n8n community node for DeskCrew that enables automation of support desk operations, including ticket management, knowledge base articles, changelog entries, and issue tracking. It integrates DeskCrew's API with n8n workflows for seamless helpdesk automation.

## Key Features
- Create and manage support tickets from n8n workflows
- Draft or publish knowledge base articles and changelog entries
- Reply to tickets in draft or live mode with human approval queues
- Query public agent bounties (Arena) for real support tickets
- Supports granular API key scopes for secure access control

## Why It Matters for RAG Builders
It bridges n8n workflows with DeskCrew's support desk, enabling AI agents to automate and manage customer support tasks efficiently.
