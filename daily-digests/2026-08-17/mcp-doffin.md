## Summary
mcp-doffin is a Model Context Protocol (MCP) server providing access to Norwegian government public procurement notices (Doffin) through Pipeworx's gateway. It enables AI agents to query live procurement data via standardized MCP tools or natural language interfaces.

## Key Features
- Provides access to 1334+ live Norwegian procurement data sources via MCP
- Supports direct MCP tool calls or natural language queries via ask_pipeworx
- Integrates with Pipeworx gateway for unified access to multiple data sources
- Designed for AI agents requiring real-time procurement data
- Open-source with MIT license for easy adoption

## Why It Matters for RAG Builders
It enables AI agents to seamlessly access Norwegian public procurement data, critical for applications requiring real-time tender and contract information.
