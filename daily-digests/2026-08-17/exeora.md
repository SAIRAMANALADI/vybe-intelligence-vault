## Summary
Exeora provides secure, outbound-initiated execution environments for AI agents, enabling MCP clients to connect to development environments on any machine without requiring open ports, tunnels, or source code uploads. It acts as a secure bridge between AI clients and local or remote machines.

## Key Features
- Secure outbound WebSocket connections from CLI to gateway, bypassing firewall restrictions
- Granular project-based access control with allow/deny lists for commands and tools
- Multi-client support (Claude, ChatGPT, Cursor, VS Code, etc.) via MCP protocol
- Real-time approval workflows for file edits, writes, and command executions
- Project isolation with structural separation to prevent cross-project access

## Why It Matters for RAG Builders
Exeora enables secure, firewall-friendly execution of AI agent tools on any machine, eliminating the need for complex networking setups while providing granular security controls essential for RAG and agent systems.
