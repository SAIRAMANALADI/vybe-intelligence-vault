## Summary
claudeFS is a browser extension (Chrome/Edge MV3) that connects a local folder to claude.ai, enabling Claude to read, search, and edit files directly from the chat interface without requiring a desktop app, API key, or command line. It leverages the File System Access API for secure local file operations.

## Key Features
- Seamless integration with claude.ai for direct file operations (read, search, edit)
- Supports plain-text files (code, Markdown, JSON, CSV) with 5MB per-file limit
- Local-only file operations with no server transmission or external API dependencies
- Diff confirmation dialog for all write operations to ensure user safety
- Works on claude.ai's free plan with no additional setup required

## Why It Matters for RAG Builders
claudeFS enables AI agents like Claude to interact with local file systems securely and efficiently, bridging the gap between cloud-based AI and local development workflows.
