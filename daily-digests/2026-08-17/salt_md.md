## Summary
salt.md is an open-source workspace designed for both humans and AI agents, offering realtime collaboration, document editing, and structured databases in a single self-hosted binary. It integrates an MCP server directly into the application, enabling agents to work within the same workspace as humans with shared permissions and history.

## Key Features
- Unified workspace for humans and AI agents with realtime collaboration
- Integrated MCP server enabling agents to directly interact with documents and databases
- Self-hosted with a single binary and SQLite backend for simplicity
- Structured databases with advanced querying, filtering, and visualization
- Granular permissions and activity tracking for both human and agent actions

## Why It Matters for RAG Builders
It provides a seamless, self-hosted environment where AI agents can directly manipulate and contribute to structured work alongside humans, eliminating the need for separate systems or bolted-on AI features.
