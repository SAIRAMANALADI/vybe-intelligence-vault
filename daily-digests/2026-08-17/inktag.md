## Summary
InkTag is a cross-platform C# utility and desktop application for bulk-editing metadata in comic book archives (`.cbz` and `.cbr`). It includes a CLI, MCP server, and Avalonia GUI, enabling AI agents to programmatically read, update, and extract cover images from comic metadata.

## Key Features
- Supports dual-format comic archives (.cbz and .cbr) with random-access processing
- Provides AI-agent-friendly CLI and MCP server with structured JSON output and dry-run safety
- Includes cross-platform desktop GUI with native menu integration and auto-updater
- Enables multimodal cover image extraction for visual LLM inspection
- Implements atomic-like file swapping with backups to prevent data loss

## Why It Matters for RAG Builders
InkTag enables AI agents to programmatically manage and enrich comic book metadata, making it essential for RAG pipelines requiring structured comic data processing and visual content extraction.
