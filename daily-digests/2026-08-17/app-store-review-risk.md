## Summary
A deterministic static scanner and agent workflow designed to catch potential App Store rejection risks in Xcode repositories or pull requests before submission. It provides target-aware, file-level evidence for AI agents to verify and address issues locally or in CI/CD pipelines.

## Key Features
- Deterministic static scanner with stable finding IDs and exact file evidence
- Target-aware checks for privacy manifests, entitlements, and metadata scoped to submitted Xcode targets
- Diff-aware analysis to focus on new or changed risks in pull requests
- Supports multiple Apple platforms (iOS, macOS, visionOS, etc.) and TestFlight/notarization paths
- Agent-ready output formats (compact, JSON, markdown) for AI-driven review workflows

## Why It Matters for RAG Builders
It enables AI engineering teams to preemptively identify and resolve App Store rejection risks in code and configurations, reducing manual review cycles and improving submission success rates.
