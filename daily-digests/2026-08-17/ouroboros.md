## Summary
Ouroboros is an open-source, self-evolving AI agent framework designed to maintain continuous identity, memory, and history across tasks and restarts. It operates as a native desktop app or headless CLI, enabling autonomous evolution, swarm coordination, and external project work while supporting both remote and local model inference.

## Key Features
- Continuous identity and memory across restarts and tasks
- Autonomous evolution with Git-integrated change tracking
- Supports both local GGUF models and remote API-based inference
- Coordinates live swarms of specialist agents for parallel task execution
- Native desktop app and headless CLI with unified runtime

## Why It Matters for RAG Builders
Ouroboros provides a foundational framework for building self-improving, persistent AI agents with advanced memory and swarm coordination capabilities, critical for RAG systems requiring long-term context and adaptive behavior.
