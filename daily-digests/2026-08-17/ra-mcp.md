## Summary
ra-mcp is a Model Context Protocol (MCP) server and CLI tool that enables search, browsing, and analysis of transcribed historical documents from the Swedish National Archives (Riksarkivet). It provides full-text search, handwritten text recognition, and interactive document viewing as MCP tools for LLM clients.

## Key Features
- Full-text search across millions of AI-transcribed historical pages
- Handwritten Text Recognition (HTR) for unstructured documents
- Interactive document viewing with MCP UI resources (e.g., in Claude)
- CLI and TUI for local and remote document browsing
- Integration with LLM clients via MCP protocol

## Why It Matters for RAG Builders
It provides essential tools for accessing and querying vast archives of historical documents, enabling RAG systems to ground responses in verified, transcribed content from the Swedish National Archives.
