## Summary
Libero is a self-hostable AI teammate for Slack designed to act as a shared agent within Slack channels, with persistent memory, admin-governed tool access, and asynchronous task execution. It prioritizes governance and security, ensuring tool credentials are isolated and every action is audited.

## Key Features
- Shared agent sessions per Slack channel with persistent memory
- Admin-governed tool access via team sheets (TOML manifests)
- Human-in-the-loop approvals for dangerous tool calls
- Append-only audit logging for all actions and tool calls
- LLM-agnostic architecture with provider flexibility

## Why It Matters for RAG Builders
Libero provides a secure, governance-first framework for deploying AI agents in Slack that ensures credential isolation and auditability, critical for enterprise RAG deployments.
