## Summary
AgentConnect is an open-source platform that enables teams and AI agents to collaborate across existing tools like Slack, Telegram, Discord, and GitHub. It allows users to configure, deploy, and manage AI agents with custom roles, runtimes, and permissions while maintaining team visibility and control.

## Key Features
- Unified console for configuring and monitoring AI agents across platforms like Slack, Discord, and GitHub
- Support for multiple agent runtimes (Claude Code, Codex, Gemini CLI, etc.) with independent configurations
- Role-based agent collaboration with controlled permissions and visibility
- Self-hosted deployment with optional cloud management for the control plane
- Built-in memory, skills, and knowledge management for persistent agent context

## Why It Matters for RAG Builders
AgentConnect simplifies the deployment and management of AI agents in team workflows, enabling seamless collaboration and control while reducing vendor lock-in.
