## Summary
Cube Container is an AI-controlled container orchestration platform that replaces traditional DevOps with natural language operations via the Model Context Protocol (MCP). It provides 178 tools for managing containers, VMs, networking, security, and hypervisor resources through a unified interface.

## Key Features
- 178 MCP tools covering full DevOps lifecycle (containers, VMs, networking, secrets, backups, etc.)
- Dual backend support (Docker for production, Cube for edge nodes) with auto-detection
- Hypervisor management (KVM/libvirt, ZFS, GPU passthrough, cloud-init) and Proxmox VE integration
- TOTP 2FA (Steam Guard style) for human admin operations and API key-based access for automation
- Secure sandboxing with KVM-isolated VMs for untrusted code execution and tamper-evident audit trails

## Why It Matters for RAG Builders
It enables AI agents to autonomously manage complex container and hypervisor environments through natural language, reducing DevOps overhead and enabling self-healing, scalable infrastructure.
