## Summary
Norman MCP Server integrates accounting, invoicing, and tax filing capabilities directly into AI assistants like Claude, Cursor, and ChatGPT via the Model Context Protocol (MCP). It enables users to manage finances, file VAT returns, and even found German companies (GmbH/UG) through natural language interactions.

## Key Features
- Seamless integration with AI assistants (Claude, Cursor, ChatGPT) via MCP for financial task automation
- End-to-end German company formation (GmbH/UG) including document generation and notary hand-off
- Automated VAT return filing and tax deduction identification for European businesses
- Multi-platform support (Claude Code, OpenClaw, n8n, Replit) with OAuth authentication
- Real-time financial insights, invoice management, and receipt synchronization from Gmail/Stripe

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and critical financial workflows, enabling developers to build agents that can autonomously handle bookkeeping, tax compliance, and business formation for European users.
