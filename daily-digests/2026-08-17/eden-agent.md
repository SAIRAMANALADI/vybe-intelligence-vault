## Summary
eden-agent is a TypeScript-based coding agent framework designed to build trustworthy, replayable, and evidence-driven terminal products. It focuses on event-sourced execution, durable approvals, and verifier-owned completion while avoiding thin wrappers around existing agent frameworks.

## Key Features
- Event-sourced execution with durable JSONL replay
- Snapshot-safe editing and monotonic capabilities
- Explicit workspace trust and separate fake-action approval
- Deterministic fake-model step and task execution
- Verifier-owned completion with recovery paths

## Why It Matters for RAG Builders
It provides a robust foundation for building trustworthy, replayable coding agents with explicit boundaries and verifiable outcomes, critical for AI engineering stacks requiring reliability and auditability.
