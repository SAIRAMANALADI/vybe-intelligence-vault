## Summary
Flywheel is a unified router and harness that routes prompts to any AI model (local or hosted) while verifying answers and generating re-checkable receipts. It combines routing, local execution, and external verification into a single zero-dependency surface.

## Key Features
- Routes to any AI model (local or hosted) with a single API surface
- Verifies answers externally and generates re-checkable receipts
- Supports offline operation with local model execution
- Zero dependencies; runs with standard Python library only
- Provides a unified UI for routing, verification, and receipt management

## Why It Matters for RAG Builders
Flywheel enables RAG builders to ensure answer reliability through external verification and re-checkable receipts, bridging the gap between routing and trustworthy AI outputs.
