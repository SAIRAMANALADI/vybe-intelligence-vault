## Summary
Lorikeet is an AI-powered customer support agent designed for regulated industries, enabling workflow-based orchestration across chat, email, and voice. It integrates with helpdesk systems (Zendesk, Intercom, Front) and internal tools via typed, no-code actions, while providing a programmatic API surface for conversations, messages, webhooks, actions, and knowledge ingestion.

## Key Features
- Workflow-based AI agent orchestration with skills-based routing
- Multi-channel support (chat, email, voice) with unified conversation management
- No-code tool integration for calling into helpdesks and internal systems
- Secure webhook and event-driven architecture with HMAC verification
- Knowledge ingestion and retrieval for context-aware responses

## Why It Matters for RAG Builders
Lorikeet provides a robust framework for building secure, workflow-driven AI agents that integrate seamlessly with existing support systems and internal tools, making it essential for RAG builders targeting regulated industries.
