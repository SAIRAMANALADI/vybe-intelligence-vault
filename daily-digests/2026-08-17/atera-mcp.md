## Summary
A Model Context Protocol (MCP) server for interacting with the Atera RMM API, enabling AI assistants to manage tickets, devices, alerts, and customer records through a decision-tree-based tool discovery architecture.

## Key Features
- Decision tree architecture for efficient tool discovery and reduced context overhead
- Full API coverage for customers, agents, tickets, alerts, and contacts
- Interactive ticket cards with in-card actions for MCP Apps hosts
- Built-in rate limiting (700 req/min) via the node-atera client
- One-click deployment options for Cloudflare Workers and DigitalOcean

## Why It Matters for RAG Builders
It enables AI assistants to seamlessly interact with Atera RMM systems for IT management tasks, reducing manual intervention and improving automation in RAG pipelines.
