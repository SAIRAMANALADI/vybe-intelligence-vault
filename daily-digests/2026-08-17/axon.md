## Summary
Axon is a local observability tool designed for LangChain and OpenTelemetry-instrumented AI agents, providing real-time monitoring and debugging capabilities through a dashboard that visualizes LLM calls, tool invocations, and chain executions without requiring cloud services or data transmission outside your environment.

## Key Features
- Real-time trace visualization with multiple views (Transcript, Waterfall, Tree, Raw)
- Local SQLite database for storing trace data with no cloud dependency
- OTLP-compatible endpoint for seamless integration with LangChain and OpenTelemetry
- CLI-based setup and management for easy project initialization and control
- Docker support for environment-agnostic deployment
