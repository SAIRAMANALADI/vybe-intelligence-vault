## Summary
A Windows-native semantic search tool that enables fast, context-aware text retrieval using vector embeddings and caching. Designed for non-technical users to search large text collections with high accuracy without requiring GPUs or complex setups.

- Smart caching for fast performance on large text collections
- No GPU or specialized hardware required; runs on standard Windows PCs
- Supports multiple document formats (.txt, .md, .csv)
