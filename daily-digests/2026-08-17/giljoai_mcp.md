## Summary
GiljoAI MCP is a context engineering platform that enables AI-assisted software development by defining product context once and sharing it with all connected agents. It acts as a passive MCP server, storing product knowledge, generating structured prompts, and coordinating multi-agent workflows without writing code or calling AI models directly.

## Key Features
- Defines product context (description, tech stack, architecture) once and shares it with all agents for consistent understanding.
- Coordinates multi-agent workflows via the Model Context Protocol (MCP) without executing code or calling AI models.
- 360 Memory feature captures project outcomes, decisions, and patterns for reuse in future projects.
- Real-time dashboard for monitoring agent activity, progress, and direct messaging with orchestrators.
- Supports self-hosting with privacy-first design and compatibility with major AI coding tools (Claude, Codex, ChatGPT, etc.).

## Why It Matters for RAG Builders
It bridges the gap between product definition and agentic coding by ensuring all AI tools work from a shared, structured context, reducing misalignment and improving consistency in software development outcomes.
