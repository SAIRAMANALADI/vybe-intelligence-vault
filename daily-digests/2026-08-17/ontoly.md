## Summary
Ontoly is a JavaScript- and TypeScript-native software intelligence engine that transforms source code into a deterministic Software Graph, enabling tools like agents, MCP servers, and IDEs to query a shared semantic representation without repeatedly parsing files or rebuilding context.

## Key Features
- Builds a deterministic Software Graph from JavaScript/TypeScript repositories with stable IDs for caching and diffing
- Provides a query engine for neighborhood expansion, dependency traversal, impact analysis, and pattern matching
- Offers MCP capabilities for structured graph queries to AI agents and tools
- Includes 14+ portable Agent Skills for architecture review, dependency analysis, impact analysis, and more
- Generates derived artifacts like Semantics (concept graphs, feature ownership) and History (ownership, hotspots, churn)

## Why It Matters for RAG Builders
Ontoly provides a foundational semantic layer that eliminates redundant code parsing and enables AI tools to query a shared, deterministic representation of software, drastically improving efficiency and accuracy in RAG and agent-based workflows.
