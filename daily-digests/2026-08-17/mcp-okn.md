## Summary
An MCP server enabling LLMs to query the Proto-OKN federated SPARQL endpoint, discover relevant knowledge graphs, and execute domain-specific queries across interconnected scientific datasets. It bridges multiple knowledge graphs via verified crosswalks for multi-domain research and analysis.

## Key Features
- Federated SPARQL query execution over Proto-OKN knowledge graphs
- Automated discovery of relevant knowledge graphs via registry metadata
- Verified crosswalk catalog for multi-graph data integration
- End-to-end case studies with interactive reports and transcripts
- Natural language prompt processing with structured query generation
