## Summary
vromvrom-engine is an asynchronous multi-agent LLM orchestrator that dynamically routes tasks to the best-performing models using hybrid routing, Elo scoring, and self-healing mechanisms. It supports 18+ LLM providers, integrates with Home Assistant, and offers an OpenAI-compatible proxy API for seamless IDE integration.

## Key Features
- Hybrid routing pipeline (Regex → ML → LLM → Elo scoring) for adaptive task delegation
- Dynamic Elo scoring system that adapts model selection based on task domain performance
- Self-healing architecture with circuit breakers, exponential backoff, and provider fallback
- OpenAI-compatible proxy API enabling drop-in replacement for IDEs like Cursor or Cline
- Native Home Assistant integration with built-in tools for smart home control and monitoring

## Why It Matters for RAG Builders
It provides a robust, cost-aware, and adaptive framework for orchestrating multiple LLMs, reducing operational overhead and improving task resolution efficiency for RAG and AI stack builders.
