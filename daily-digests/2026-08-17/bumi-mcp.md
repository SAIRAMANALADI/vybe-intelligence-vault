## Summary
Bumi MCP is a Model Context Protocol (MCP) server and REST bridge designed to control the Noetix Bumi humanoid robot. It provides telemetry, health checks, and gated motion control via a REST API, with support for both mock and physical hardware modes.

## Key Features
- MCP server for humanoid robot control with REST bridge capabilities
- Mock bridge mode for CI/testing without physical hardware
- Telemetry and health endpoints for monitoring robot status
- Gated motion control for safe operation
- Integration with Noetix SDK for advanced robot functions

## Why It Matters for RAG Builders
It provides a standardized interface for controlling and integrating humanoid robots like the Noetix Bumi into AI systems, enabling seamless telemetry and motion control for RAG and agent frameworks.
