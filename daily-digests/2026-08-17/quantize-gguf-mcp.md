## Summary
A hosted MCP server by QuantizeLab that enables AI assistants to quantize Hugging Face models into GGUF format and publish them directly to user profiles. The service operates via a cloud endpoint with no self-hosting option, requiring API key authentication for access.

## Key Features
- Quantizes Hugging Face models to GGUF format (Q4_K_M) up to 33B parameters
- Hosted MCP server with free tier and credit-based pricing
- Safety-first design with cost preview, confirmation, and automatic refunds on failure
- Supports multiple MCP clients (Claude, Cursor, etc.) via standardized configuration
- Encrypted storage of Hugging Face tokens and one-way hashed API keys

## Why It Matters for RAG Builders
It simplifies the quantization and deployment of Hugging Face models to GGUF format, reducing friction for RAG builders who need optimized models for local or edge inference.
