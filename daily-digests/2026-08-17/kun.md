## Summary
Kun is a local-first AI Agent workspace that unifies GUI and TUI interfaces for coding, writing, design, research, and automation. It enables end-to-end task execution from requirement clarification to delivery verification within a single runtime environment.

## Key Features
- Unified runtime for desktop GUI and terminal TUI with shared task state and model connections
- Agent Graph for complex task decomposition, parallel execution, and dependency-based verification
- Multi-modal support for code, writing, design, PDF/image research, and automation
- Extensible architecture with Skills, MCP, and .kunx extensions
- Persistent task history, plan tracking, and verifiable deliverables from requirements to acceptance

## Why It Matters for RAG Builders
Kun provides a cohesive environment for AI agents to handle end-to-end workflows, ensuring traceability, collaboration, and verifiable outcomes critical for RAG and AI stack builders.
