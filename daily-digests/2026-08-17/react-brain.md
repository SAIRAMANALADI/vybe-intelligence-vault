## Summary
react-brain is a continuously verified decision corpus for React and React Native ecosystem engineering, providing context-keyed recommendations, source-verified facts, and a CLI/MCP server for coding agents. It serves as an encyclopedia, tutorial, and mentor skill to guide project-specific improvements.

## Key Features
- Continuously verified decision corpus with dated, source-verified recommendations for React and React Native
- CLI tooling for stack composition, project assessment, and learning path generation
- MCP server for integration with coding agents like Claude Code
- Self-audit and quality gates (linting, testing, and corpus freshness checks)
- Adaptive learning paths tailored to specific project repositories
