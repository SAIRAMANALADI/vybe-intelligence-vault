## Summary
prompt-shield is a self-learning security tool designed to protect AI systems from prompt injection attacks by using 21 built-in detectors, a vector similarity vault, and community-driven threat intelligence. It operates as a standalone application with a three-layer defense mechanism to monitor and block harmful prompts.

## Key Features
- 21 built-in detectors for common prompt injection patterns
- Vector similarity vault for detecting obfuscated or modified threats
- Self-learning detection that improves over time with new attack data
- Three-layer defense (input scanning, behavior analysis, response filtering)
- Community threat intelligence integration for real-time updates
