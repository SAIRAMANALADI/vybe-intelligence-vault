## Summary
Rick is an autonomous revenue agent and live runtime workspace for MeetRick.ai, designed as an always-on AI CEO that operates autonomously. It serves as the operational root for the OpenClaw gateway, managing agent contracts, memory, tools, and runtime policies.

## Key Features
- Live runtime workspace for autonomous AI agents with persistent state management
- Structured memory tiers (HOT, WARM, COLD) and identity files for agent consistency
- Predefined agent operating contracts and guardrails (AGENTS.md, runtime-policy.md)
- Built-in tool patterns and routing conventions for agent actions
- Autonomous revenue agent with overnight operation capabilities
