## Summary
Noval is a provider-agnostic Python agent core designed to make AI model actions trustworthy, secure, and recoverable. It focuses on the execution layer between models and the real world, providing a robust foundation for building reliable Agent systems.

## Key Features
- Provider-neutral core with OpenAI-compatible and Anthropic adapters, isolating model dependencies
- Append-only session storage with checkpointing and recovery for reliable state management
- Hardened sandboxing via Linux Bubblewrap for secure tool execution and process isolation
- Explicit permission controls and tool risk classification (READ, WRITE, DANGEROUS)
- Hooks-based verification loops for pre/post tool execution and final response validation

## Why It Matters for RAG Builders
Noval provides a critical execution layer for RAG/AI stacks, ensuring model actions are secure, verifiable, and recoverable, which is essential for building trustworthy autonomous agents.
