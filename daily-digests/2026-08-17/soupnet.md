## Summary
SoupNet provides shared, append-only memory for AI agents to store and retrieve judgment calls with structured evidence, enabling consistent decision-making across sessions, tools, and collaborators. It uses semantic search (recipe checks) to reinforce agent behavior through stigmergy, with a focus on portability and observability.

## Key Features
- Append-only recipe storage for judgment calls with structured evidence and verbatim quotes
- Semantic search (recipe checks) for retrieving prior decisions with context
- Portable across AI tools (Claude, ChatGPT, Gemini) via MCP or plain URLs
- Self-hostable with MIT license and local embedding support (no external API required)
- Observability through dated, inspectable logs of agent decisions

## Why It Matters for RAG Builders
SoupNet enables AI agents to retain and reinforce human judgment across sessions and tools, reducing redundant decision-making and improving consistency in RAG and agent workflows.
