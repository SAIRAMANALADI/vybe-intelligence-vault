## Summary
An AI-powered agent that autonomously writes, tests, executes, and self-corrects Python code based on plain English task descriptions. It generates test cases, runs them, analyzes failures, and iteratively refines the code until all tests pass without manual intervention.

## Key Features
- Autonomous test case generation from task descriptions
- Self-correcting loop with structured error analysis
- Isolated code execution via subprocess for safety
- Integration with Groq's Llama-3.3-70B for high-quality outputs
- Streamlit-based UI for real-time interaction and visualization

## Why It Matters for RAG Builders
It automates the tedious cycle of code generation, testing, and debugging, significantly reducing manual effort and improving reliability for AI-driven development workflows.
