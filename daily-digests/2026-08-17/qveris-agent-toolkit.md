## Summary
QVeris Agent Toolkit provides a unified platform for agents to discover, inspect, call, and audit real-world tools via CLI, MCP server, Python SDK, and REST API. It enables seamless integration with 10,000+ capabilities across diverse categories like finance, weather, and maps.

## Key Features
- Discover 10,000+ capabilities across 15+ categories with natural language queries
- Inspect tools for parameters, success rates, latency, and billing rules before invocation
- Call tools via CLI, MCP, Python SDK, or REST API with structured pre-settlement billing
- Audit usage and credits ledger to track charges and balance changes without context bloat
- Zero-prompt-token CLI for token-efficient tool invocation in agent workflows

## Why It Matters for RAG Builders
