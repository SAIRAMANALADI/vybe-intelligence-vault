## Summary
Shell AI OS Controller is a local-first AI desktop assistant and automation platform that integrates a React/Vite/WebGL UI with Python-based AI providers, tools, and runtime diagnostics. It bridges chat, voice, desktop automation, and structured workflows into a unified control layer for AI-native desktop environments.

## Key Features
- 460+ catalogued Python tools with guarded execution gateway
- React/Vite/WebGL Electron UI with live telemetry and voice integration
- Local SQLite memory with tags, importance scoring, and time decay
- Project RAG v2 with BM25/TF-IDF fallback and semantic embeddings
- Safety policy layer (SAFE/ASK/BLOCK) with audit logging and dry-run support

## Why It Matters for RAG Builders
It provides a unified, local-first AI control layer that orchestrates tools, memory, and automation for RAG builders seeking to integrate desktop-level workflows and diagnostics.
