## Summary
MalikClaw is an ultra-lightweight, production-grade AI agent framework written in Go, designed to run on low-cost hardware like $10 SBCs or Android devices with minimal resource usage. It provides a full agent loop with planning, execution, observation, and reflection capabilities.

## Key Features
- Production-grade agent loop with PLAN → ACT → OBSERVE → REFLECT → MEMORY UPDATE cycle
- Runs on <10MB RAM and <1s boot time, enabling deployment on $10 hardware like Orange Pi Zero or Raspberry Pi
- Multi-language support (Urdu, English, Japanese, French, Portuguese, Vietnamese, and more)
- Mobile automation via ADB for Android devices, including screenshots, taps, swipes, and text input
- Extensible plugin system with MCP support for business integrations (Odoo, Gmail, Calendar, TikTok, LinkedIn, etc.)

## Why It Matters for RAG Builders
MalikClaw enables AI engineers to build and deploy lightweight, production-grade agents on resource-constrained hardware, reducing costs and improving privacy for edge AI applications.
