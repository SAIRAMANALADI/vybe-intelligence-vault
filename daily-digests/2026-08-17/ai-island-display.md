## Summary
AI Island Display is a native macOS application that transforms the MacBook notch into a glanceable, real-time activity center for AI coding sessions. It provides visibility into running, waiting, and completed AI agent sessions with token usage and cost tracking, all while maintaining a minimal and non-intrusive UI.

## Key Features
- Notch-first UI that integrates with MacBook's physical notch for compact, glanceable status
- Real-time tracking of AI coding sessions (running, waiting, completed, failed) with session details
- Token usage and cost estimation for AI sessions based on public API pricing
- One-click navigation back to the originating terminal or editor for any session
- Local-first operation with no cloud backend or telemetry, ensuring privacy

## Why It Matters for RAG Builders
It provides a non-intrusive, native macOS interface for monitoring AI agent activity, improving developer productivity by centralizing session visibility and reducing context switching.
