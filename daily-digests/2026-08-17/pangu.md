## Summary
Pangu is an industrial-grade project initialization skill for AI agents that transforms an empty directory into a production-ready project with comprehensive quality guardrails, including language scaffolding, Git/GitHub CI pipelines, pre-commit/lefthook checks, and 80%+ coverage enforcement across 9 languages and 3 multi-language hybrid setups.

## Key Features
- One-click initialization for 9 languages with pre-configured quality checks (linting, security audits, coverage ≥80%)
- Support for 3 multi-language hybrid setups (monorepo, FFI Rust→Python, FFI Rust→Node)
- GitHub CI quality gates with conditional registry publishing (crates.io, PyPI, npm, etc.)
- Dual local hook systems (pre-commit + lefthook) with unified thresholds to avoid CI failures
- Comprehensive documentation and reference guides for toolchain configurations and standards
