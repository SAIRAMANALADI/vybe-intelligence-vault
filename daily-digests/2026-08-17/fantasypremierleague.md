## Summary
A Kotlin Multiplatform (KMP) Compose Multiplatform project demonstrating a Fantasy Premier League app across Android, iOS, and Desktop. It includes an AI agent built with Koog (Gemini + tool calling) and an MCP server for exposing player/fixture data to external tools like Claude Desktop.

## Key Features
- Cross-platform app development (Android, iOS, Desktop) using Kotlin Multiplatform and Compose Multiplatform
- Integration of an AI agent using Koog with Gemini API and tool calling capabilities
- MCP server exposing Fantasy Premier League data for external tool integration (e.g., Claude Desktop)
- Use of Jetpack libraries (ViewModel, Navigation 3, Room, DataStore) in shared KMP code
- Demonstrates Kotlin Notebook for interactive data exploration and visualization
