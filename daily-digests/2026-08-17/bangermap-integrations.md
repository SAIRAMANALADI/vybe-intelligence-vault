## Summary
A collection of integrations for YouTube outlier research, providing tools to identify videos that significantly outperform their channel's baseline performance. Includes an MCP server and an n8n community node, both sharing a common scoring engine.

## Key Features
- Identifies YouTube video outliers using a shared scoring engine
- Provides an MCP server for integration with Claude Code/Desktop
- Offers an n8n community node for workflow automation
- Uses personal YouTube Data API keys for free quota management
- Supports channel graph discovery for deeper research

## Why It Matters for RAG Builders
It enables AI builders to integrate YouTube outlier detection into their workflows without relying on third-party metered services, leveraging free API quotas for cost-effective research.
