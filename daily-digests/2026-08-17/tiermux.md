## Summary
TierMux is a free, open-source VS Code AI coding assistant that intelligently routes requests across 22+ free-tier LLM providers, offering auto-failover, smart routing, and codebase learning. It eliminates the need for manual provider management while ensuring reliability and performance.

## Key Features
- Intelligent provider routing with failover across 22+ free-tier LLM providers
- Auto-classification of tasks (code edit, debugging, etc.) for optimal model selection
- Codebase learning via user feedback and file edits to match style preferences
- Three operational modes: Ask, Plan, and Agent with checkpointing and diff review
- Keyless provider support and custom OpenAI-compatible endpoint integration

## Why It Matters for RAG Builders
TierMux simplifies AI-powered coding by pooling unreliable free-tier providers into a single, self-healing interface, reducing downtime and manual configuration for RAG and AI stack builders.
