## Summary
DanNet is a Danish-language WordNet implemented as a semantic lexicon and knowledge graph using RDF and OWL standards. It provides structured lexical and semantic data for Danish, enabling integration with AI systems, semantic search, and natural language processing tasks.

## Key Features
- Native RDF representation with OWL inference support via Apache Jena
- Multiple export formats (RDF, CSV, WN-LMF) for compatibility with various tools
- Companion datasets (COR, DDS, OEWN extension) for enriched semantic data
- MCP server for direct LLM integration (e.g., Claude Desktop)
- SHACL validation for data integrity and consistency

## Why It Matters for RAG Builders
DanNet provides a structured, semantically rich lexical resource for Danish that can enhance RAG systems by improving contextual understanding and enabling precise semantic queries.
