## Summary
Local MCP enables AI agents to natively interact with macOS applications and local data sources via the MCP protocol, providing direct access to tools like Mail, Calendar, Teams, Slack, and iMessage without requiring API keys or cloud APIs. It supports both local AI clients and web-based AIs through an optional encrypted relay.

## Key Features
- Direct access to 233+ local tools across 22 app categories (Mail, Calendar, Teams, Slack, iMessage, etc.) without API keys or OAuth
- Supports both local AI clients (Claude Desktop, Cursor, VS Code) and web-based AIs (ChatGPT, Claude.ai) via optional encrypted relay
- 100% local execution with no cloud processing or data storage, ensuring privacy and GDPR compliance
- Automated setup and configuration for popular AI clients, reducing deployment friction
- Advanced features like reusable workflows, screen recording/editing, and built-in browser automation for web interactions

## Why It Matters for RAG Builders
Local MCP unlocks native, API-free access to critical macOS applications for AI agents, enabling secure, real-time RAG augmentation without cloud dependencies or API key management.
