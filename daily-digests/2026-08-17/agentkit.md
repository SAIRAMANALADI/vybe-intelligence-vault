## Summary
AgentKit is an MCP server that exposes enterprise KPIs, health scores, forecasting, and anomaly detection as tools and resources for MCP-compatible agents like Claude Desktop, LangGraph, and CrewAI. It enables agents to query real-time business metrics and generate executive summaries.

## Key Features
- 6 MCP tools for querying KPIs, health scores, anomalies, and forecasting metrics
- 6 MCP resources for real-time enterprise data (Finance, Growth, Operations, etc.)
- LangGraph 3-agent workflow (Planner → Analyst → Reporter) for complex queries
- Provider-agnostic LLM routing via LiteLLM for cost and performance optimization
- Comprehensive benchmarking and evaluation suites for reproducibility

## Why It Matters for RAG Builders
AgentKit provides a standardized way to integrate real-time business intelligence into AI agents, enabling them to perform complex analytical tasks and generate actionable insights.
