## Summary
mcp-pcb-emcopilot is an AI-powered Model Context Protocol (MCP) server that provides 93 tools for PCB design review, focusing on EMC, signal integrity, power integrity, thermal analysis, and DFM. It parses multiple PCB layout formats and generates detailed audit-grade reports for fabrication validation.

## Key Features
- 93 specialized tools for PCB analysis across EMC, SI, PI, thermal, and DFM domains
- Multi-format PCB layout parsing (KiCad, ODB++, Gerber, IPC-2581, Altium, STEP)
- Physics-based analyzers with IPC-grounded impedance calculations and compliance predictions
- AI-native integration via Model Context Protocol for agent-driven workflows
- Automated generation of audit-grade DOCX reports with embedded board renders and annotated findings

## Why It Matters for RAG Builders
It enables AI agents to perform comprehensive PCB design reviews for EMC, signal integrity, and power integrity, reducing fabrication risks and accelerating design validation.
