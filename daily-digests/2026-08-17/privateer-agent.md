## Summary
Privateer is a privacy-first, safe-by-default distribution of the Pi coding agent that allows users to bring their own model while maintaining full control over data privacy and inference security. It supports multiple providers, including local and TEE-attested options, with built-in safety gates and verifiable privacy guarantees.

## Key Features
- Privacy-first inference with TEE-attested and on-device PII gate for verified privacy
- Provider-agnostic model switching with no vendor lock-in (supports OpenRouter, Anthropic, OpenAI, Ollama, etc.)
- Built-in safe-by-default permission gates for destructive commands, shell access, and data exfiltration
- Extensible via Pi extensions and MCP servers for custom workflows and integrations
- Remote approval and monitoring via Privateer app for unattended agent runs

## Why It Matters for RAG Builders
Privateer enables RAG builders to deploy privacy-preserving, verifiable agentic systems without sacrificing flexibility or control over model providers and data handling.
