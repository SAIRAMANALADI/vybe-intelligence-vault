## Summary
mcp-vitest provides Vitest-native testing utilities for Model Context Protocol (MCP) servers, enabling in-process testing with real SDK clients without subprocess overhead. It supports both MCP SDK v1 and v2, offering typed matchers, snapshot testing, and structured output validation for robust server testing.

## Key Features
- In-process testing of MCP servers without subprocess overhead or port management
- Full support for both MCP SDK v1 and v2 with automatic detection and routing
- Typed matchers (e.g., `toHaveTool`, `toMatchOutputSchema`) for comprehensive assertions
- Snapshot testing for regression safety and API stability checks
- Progress callbacks, cancellation, and timeout support via real SDK client integration

## Why It Matters for RAG Builders
It simplifies and accelerates the testing of MCP servers by providing a seamless, in-process testing framework that mirrors real-world SDK interactions, ensuring reliability and reducing integration complexity for RAG builders.
