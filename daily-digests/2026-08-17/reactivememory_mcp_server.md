## Summary
ReactiveMemory MCP Server provides AI assistants with a persistent, queryable, locally-stored memory system using vector search, a temporal knowledge graph, and a vault-structured content store. It enables durable external memory for agents, copilots, and AI workflows to remember, reason over, and navigate accumulated knowledge across sessions.

## Key Features
- Persistent, queryable memory system with vector search for semantic retrieval
- Temporal knowledge graph to track facts, their validity periods, and relationships over time
- Vault-structured content store organized into Sectors, Vaults, and Drawers for hierarchical memory management
- Write-ahead logging and deduplication to maintain lean, efficient storage
- Integration with MCP protocol for seamless agent interaction and memory operations

## Why It Matters for RAG Builders
It provides a critical persistent memory layer for AI agents, enabling them to retain and reason over context across sessions without relying on external services or APIs.
