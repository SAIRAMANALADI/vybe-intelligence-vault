## Summary
An open-source repository accompanying the Chinese book '深入理解 AI Agent：设计原理与工程实践' by Bojie Li, providing the full text, compiled PDF, and chapter-wise code examples for building and understanding AI agents. It covers core concepts like context engineering, tool integration, memory systems, and multi-agent collaboration with practical implementations and benchmarks.
