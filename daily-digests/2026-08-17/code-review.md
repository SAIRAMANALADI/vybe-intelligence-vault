## Summary
An agent-driven code review tool that integrates with GitLab CI and GitHub Actions to automate merge request reviews, parse inline comments, and post deduplicated discussions while reporting token usage and cost.

## Key Features
- Agent-driven code review with LLM models
- Platform-agnostic (GitLab CI and GitHub Actions support)
- Deduplication of inline comments and discussions
- Token usage and cost reporting per run
- Configurable severity thresholds and review depth

## Why It Matters for RAG Builders
It automates and standardizes code reviews in CI pipelines, reducing manual effort and improving consistency while providing actionable insights from LLMs.
