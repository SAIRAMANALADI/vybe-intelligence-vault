## Summary
AI Video Assistant is an end-to-end meeting and video intelligence tool that transcribes audio/video files (English or Hinglish), generates summaries, extracts action items and key decisions, and enables RAG-powered chat with the transcript via a Streamlit UI.

## Key Features
- Dual transcription engine supporting English (Whisper) and Hinglish (Sarvam AI)
- Automated summarization and extraction of action items, decisions, and open questions
- RAG-powered chat interface for querying the transcript contextually
- Custom Streamlit UI with dark theme for seamless user interaction
- Flexible input handling for multiple audio/video formats

## Why It Matters for RAG Builders
This tool streamlines meeting and video processing by automating transcription, summarization, and RAG-powered querying, making it essential for teams needing structured insights from unstructured audio/video data.
