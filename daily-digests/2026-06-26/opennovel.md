## Summary
OpenNovel is a local-first, CLI-driven narrative operating system for long-form fiction that combines human-authored Markdown content with AI-driven state tracking, consistency verification, and autonomous writing pipelines. It integrates structured state extraction, causal event graphing, and multi-agent collaboration for iterative novel creation.

## Key Features
- Four-agent autonomous pipeline (Writer, Critic, Manager, Director) for end-to-end novel generation
- Causal event graph and foreshadowing tracking for narrative consistency
- Model-agnostic LLM integration with three-layer fallback and stage-specific routing
- Human-in-the-loop approval workflow with full rollback and diff review
- MCP server integration for seamless AI tool integration (e.g., Claude Code)

## Why It Matters for RAG Builders
