## Summary
SerpentStack is a full-stack Windows-based app template that provides a pre-configured starting point for building modern applications with integrated AI-assisted development capabilities. It bundles a React/TypeScript frontend, FastAPI backend, Postgres database, and Terraform cloud setup into a single downloadable package.

## Key Features
- Pre-configured React/TypeScript frontend with modern UI components
- FastAPI backend for handling app logic and API requests
- Postgres database integration for persistent data storage
- Terraform files for repeatable cloud infrastructure deployment
- Included agent skills for AI-assisted development workflows
