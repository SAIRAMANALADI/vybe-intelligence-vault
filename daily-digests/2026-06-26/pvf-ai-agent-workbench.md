## Summary
PVF Ai Agent Workbench is a portable, read-only inspection toolkit designed to assist AI agents in analyzing and editing Portable Virtual Files (PVF) for safer workflows. It provides a structured knowledge base and controlled write capabilities for PVF fields, routes, and safety rules.

## Key Features
- Portable scaffold for AI agent-based PVF inspection and editing
- Pre-loaded knowledge base for PVF fields, routes, and safety rules
- Read-only inspection mode with controlled write workflows
- Bundled Node.js runtime for simplified Windows deployment
- Explicit safety measures for PVF modifications (backup, smallest edit, save, readback)

## Why It Matters for RAG Builders
It provides a structured, safe environment for AI agents to inspect and modify PVF files, reducing errors and improving workflow reliability for game asset management.
