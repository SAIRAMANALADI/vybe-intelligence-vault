## Summary
AI Factory is a self-hosted orchestrator that transforms plain-language user requests into reviewable AI-generated code drafts, such as static web pages or browser-based tools. It emphasizes human oversight, transparency, and controlled AI collaboration, delivering outputs as downloadable ZIPs or draft pull requests for engineering review.

## Key Features
- Converts natural language requirements into actionable engineering plans with AI agents working in parallel.
- Delivers outputs as reviewable drafts (ZIP files or PRs) with detailed evaluation reports for transparency.
- Implements governance profiles for risk-based change control, including human approval gates and audit trails.
- Supports both new project creation and modifications to existing repositories via Git integrations.
- Provides a discovery flow ('幫我想想') to help users with vague ideas generate concrete project requirements.

## Why It Matters for RAG Builders
AI Factory bridges the gap between high-level AI-generated drafts and human-controlled engineering review, ensuring reliable, transparent, and auditable AI-assisted development workflows.
