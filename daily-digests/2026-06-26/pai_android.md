## Summary
PAi Android is a native Android AI agent with an autonomous decision engine, tool system, and proactive capabilities. It supports multi-provider AI models, local inference, and extensive device integration for tasks like email, SMS, calls, and weather.

## Key Features
- ReAct decision loop for autonomous agent behavior
- Multi-provider AI support (DeepSeek, OpenAI, Ollama, etc.) with smart routing
- Extensive device tool integration (email, SMS, calls, location, weather)
- Proactive mode with scheduler, memory system, and notification listener
- On-device local AI inference via Ollama and LocalAiInteraction
