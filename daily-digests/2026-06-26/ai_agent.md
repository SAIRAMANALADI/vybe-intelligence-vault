## Summary
AI_Agent is a Hermes-first AI virtual entertainment company runtime that orchestrates Discord-based AI agents for company operations, including personal assistants and department heads (e.g., content, art, tech, marketing). It implements a MeetingRun-centric runtime architecture v2 for meeting coordination, task execution, and validation.

## Key Features
- MeetingRun-centric runtime architecture for structured AI company operations
- Discord-based AI agents with role-specific responsibilities (CEO, content, art, tech, marketing, quality)
- Validation layer with GLM/Codex for risk assessment and correction loops
- Deterministic orchestration with file-based state management and logging
- Phase-gated implementation with hardening and live smoke testing
