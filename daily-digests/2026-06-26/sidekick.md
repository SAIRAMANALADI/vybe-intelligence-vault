## Summary
Sidekick is a self-hosted autonomous AI agent platform designed to run on a remote machine, providing persistent memory, a knowledge base, and 91 built-in MCP tools. It enables AI agents to execute remote commands, manage projects, and extend their own capabilities without code changes.

## Key Features
- Persistent memory and knowledge base for AI agents across sessions
- 91 built-in specialized MCP tools for remote execution and automation
- Self-extending capabilities via natural language teaching
- Autonomous agent bridge for multi-step task execution
- Comprehensive metrics and monitoring with Grafana dashboards
