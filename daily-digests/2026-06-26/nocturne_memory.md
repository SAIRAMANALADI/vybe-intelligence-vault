## Summary
Nocturne Memory is a long-term memory server for MCP-compatible AI agents that enables persistent, structured, and sovereign memory across sessions, models, and tools. It replaces vector RAG with a URI-based graph memory system, allowing AI to autonomously manage its own identity, knowledge, and evolution.

## Key Features
- URI-based memory graph with hierarchical and associative routing, avoiding semantic shredding of vector RAG
- Autonomous CRUD operations for AI agents to create, update, and delete their own memories with version control and rollback
- Conditional disclosure triggers enabling precise memory recall based on context, not random cosine similarity
- Namespace isolation for hosting multiple independent AI personalities with separate memory spaces
- Visual Dashboard for human oversight, memory editing, audit trails, and cleanup of orphaned or outdated memories

## Why It Matters for RAG Builders
It provides a critical foundation for building sovereign AI agents that retain identity, knowledge, and context across sessions and models, eliminating the amnesia and fragmentation inherent in vector RAG-based memory systems.
