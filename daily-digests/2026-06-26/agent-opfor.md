## Summary
OPFOR is an open-source adversary emulation tool designed to red-team AI agents, LLM applications, and MCP servers by simulating real-world attacks. It provides multiple interfaces (CLI, browser extension, MCP server, SDK) to test security vulnerabilities across OWASP and EU AI Act standards.

## Key Features
- Multi-mode execution (CLI, browser extension, MCP server, SDK, skills) for diverse team access
- Comprehensive OWASP and EU AI Act evaluator suites covering LLM, agentic AI, MCP, API, and bias vulnerabilities
- Trace-aware testing with integrations for Langfuse and Netra to capture internal agent states
- Autonomous red-teaming via `opfor hunt` for adaptive attack campaigns
- Detailed, reproducible reports in HTML and JSON formats for CI/CD integration

## Why It Matters for RAG Builders
OPFOR enables AI engineers to proactively identify and mitigate security vulnerabilities in AI agents and LLM applications before deployment, ensuring robustness against real-world adversarial attacks.
