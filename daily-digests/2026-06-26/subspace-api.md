## Summary
subspace-api is an Express-based RESTful API and stateless Model Context Protocol (MCP) server providing real-time data tools via OAuth-secured endpoints. It integrates with services like weather, stock quotes, DC Metro, flight tracking, and Discord activities for AI and application use cases.

## Key Features
- Stateless MCP server over HTTP with OAuth 2.0 bearer token security
- Integrated tools for weather, stock quotes, DC Metro, and flight tracking
- TRMNL plugin support for e-ink display integration
- Keycloak-compatible authentication for secure resource access
- Modular architecture with Docker and environment variable configuration
