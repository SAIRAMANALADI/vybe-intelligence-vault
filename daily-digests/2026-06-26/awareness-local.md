## Summary
Awareness-Local provides persistent, local memory for AI agents by storing notes in Markdown files and enabling fast search via SQLite and embeddings. It operates offline and integrates with tools like Claude Code, Cursor, and Windsurf through MCP, ensuring agent context remains private and user-controlled.

## Key Features
- Stores agent memory in local Markdown files for easy readability and backup
- Hybrid search combining SQLite FTS5 and embeddings for precise and semantic retrieval
- Offline-first design with no cloud dependency or account requirements
- MCP server integration for seamless connection with AI tools like Claude Code and Cursor
- Web dashboard for managing, searching, and editing memory entries locally

## Why It Matters for RAG Builders
It enables AI agents to maintain persistent, private, and locally stored context without relying on external services, enhancing control and security for developers.
