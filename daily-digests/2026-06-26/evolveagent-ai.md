## Summary
EvolveAgent AI is a workspace-aware multi-agent orchestration system designed for autonomous research and governed AI workflows. It features a Master Orchestrator Agent, specialist agents, real API diagnostics, citation tracking, and adaptive learning, all within a modular React/FastAPI stack.

## Key Features
- Master Orchestrator Agent for task classification and routing
- Governed research sessions with citation tracking and source credibility scoring
- Real API diagnostics and dry-run checks for text, image, and transcription providers
- Local vector-style memory retrieval with tiered storage (hot, warm, archived)
- Mission Control for goal planning, task graphs, and progress tracking

## Why It Matters for RAG Builders
It provides a robust framework for building governed, multi-agent AI systems with built-in research capabilities, memory intelligence, and governance, reducing the complexity of integrating these features from scratch.
