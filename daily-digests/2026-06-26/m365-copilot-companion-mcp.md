## Summary
A personal MCP server that extends Microsoft 365 Copilot with over 138 tools to interact with local files, Python execution, databases, Office documents, and more, enabling autonomous task automation on a user's laptop without additional licensing.

## Key Features
- 138+ extensible tools for file, Python, database, and Office operations on local machines
- Autonomous relay for hands-free task execution with Copilot Studio integration
- Supports SWE-bench and HumanEval benchmarks with high pass rates (71.7% and 100% respectively)
- Self-hosted Python-based server with optional native chat UI (WPF) for local interaction
- Audit logging, kill-switch, and adaptive throttling for safe and transparent operation

## Why It Matters for RAG Builders
It bridges the gap between cloud-based AI assistants and local machine capabilities, enabling RAG and AI stacks to interact with local files, databases, and tools without relying on external services or additional licensing.
