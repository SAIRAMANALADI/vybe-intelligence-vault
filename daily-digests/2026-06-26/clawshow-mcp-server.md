## Summary
ClawShow provides an AI-callable MCP server with 11 tools for small businesses, enabling instant backend operations like payment processing, electronic signatures, booking management, and website generation without requiring user signups or dashboards.

## Key Features
- 11 AI-callable tools for SMB operations (payments, eSign, bookings, etc.)
- Zero signup required with auto-provisioned namespaces
- eIDAS Article 26 AES-compliant electronic signatures
- Multi-provider payment integration (Stripe, Stancer, SumUp)
- Real-time progress tracking and webhook callbacks for eSign workflows
