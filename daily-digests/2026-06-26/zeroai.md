## Summary
ZeroAI is an Android application that enables users to interact with AI assistants directly from their mobile devices. It supports multiple AI providers and messaging tools, combining Kotlin for the Android UI and Rust for core logic via UniFFI for cross-platform efficiency.

## Key Features
- Cross-provider AI chat support (OpenAI, Anthropic, Google Gemini, etc.)
- Integration with messaging platforms (Telegram, Discord, Google Messages)
- Modern Android UI built with Jetpack Compose
- Rust-based core logic for performance and safety
- UniFFI for seamless Kotlin-Rust interoperability

## Why It Matters for RAG Builders
ZeroAI provides a mobile-first interface for AI interactions, bridging multiple providers and messaging tools in a single app, which is valuable for users seeking unified AI access on Android.
