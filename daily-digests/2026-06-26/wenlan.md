## Summary
Wenlan is a local, daemon-first personal knowledge library that captures, refines, and distills AI agent interactions into trustworthy, source-cited wiki pages. It operates as a living memory system with hybrid retrieval, versioned git storage, and MCP-compatible tools for seamless integration with AI workflows.

## Key Features
- Hybrid retrieval combining vector embeddings, FTS5 text search, and graph context for precise recall
- Autonomous distillation of atomic memories into structured, source-cited wiki pages between sessions
- Git-versioned local storage under `~/.wenlan/` with plain Markdown artifacts for full data ownership
- MCP-compatible daemon serving multiple clients (Claude Code, VS Code, Cursor, etc.) with unified context
- Explicit spaces (work, personal, client-X) and conflict resolution for multi-project or multi-user workflows

## Why It Matters for RAG Builders
Wenlan provides a critical infrastructure layer for RAG systems by ensuring captured agent knowledge is trustworthy, versioned, and continuously refined into high-quality, source-backed context for future retrieval.
