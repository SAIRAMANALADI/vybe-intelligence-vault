## Summary
A CLI and MCP server that unifies AI coding tool skills into a single canonical store, syncing them across tools like Claude, Codex, Kimi, Cursor, and Zed. It compiles skills into tool-specific formats and provides a compiler pipeline for cross-tool compatibility.

## Key Features
- Unifies skills from multiple AI tools into a single store
- Compiles skills into tool-specific formats on-the-fly
- Supports 20+ AI tools including Claude, Codex, Kimi, and Cursor
- Provides MCP server for programmatic access to skills
- Includes security scanning with NVIDIA SkillSpector

## Why It Matters for RAG Builders
It eliminates skill fragmentation across AI tools by providing a unified store and compiler pipeline, reducing manual setup and improving cross-tool compatibility for RAG builders.
