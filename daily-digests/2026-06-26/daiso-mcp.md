## Summary
Daiso MCP provides AI agents with real-time access to Korean retail, convenience store inventory, fuel prices, and movie theater schedules via MCP, CLI, and Codex Skill interfaces. It eliminates the need for API keys by offering direct integration with platforms like ChatGPT, Claude, and Grok.

## Key Features
- MCP server for AI agent integration (ChatGPT, Claude, Grok)
- CLI tool for direct terminal access and scripting
- Comprehensive Korean retail and convenience store inventory checks
- Fuel price comparison and station locator via Opinet API
- Movie theater schedules and seat availability for CGV, Megabox, and Lotte Cinema

## Why It Matters for RAG Builders
It enables AI agents to perform real-time, context-aware queries on Korean retail, fuel, and entertainment data without requiring custom API integrations, streamlining RAG pipelines for localized applications.
