## Summary
Zara is an empathetic AI engineering partner that acts as a persistent, multi-agent orchestration system with cognitive memory, semantic embeddings, and self-improving capabilities. It combines Model Context Protocol (MCP) with a 10-agent specialist team to automate software development workflows while enforcing structured methodologies like TDD and continuous learning.

## Key Features
- 10 specialized agents with servant leadership coordination for software engineering tasks
- 3-layer cognitive memory system (episodic, semantic, procedural) with temporal decay and semantic embeddings
- 132-signal skill routing with adaptive learning and 27 project-specific skills
- Self-improving reflection loops with outcome-weighted learning and blindspot detection
- Enforcement of structured development methodologies (TDD, planning, verification) via skill-gated workflows
