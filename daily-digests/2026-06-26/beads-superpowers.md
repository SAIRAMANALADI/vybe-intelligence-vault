## Summary
A plugin for AI coding agents like Claude Code and Codex that enforces disciplined development practices such as test-driven development, systematic debugging, and persistent memory across sessions using a Dolt-backed issue tracker called 'beads'.

## Key Features
- Enforces test-driven development (TDD) with a strict RED-GREEN-REFACTOR loop
- Provides 22 skills for disciplined coding practices (e.g., brainstorming, systematic debugging, parallel subagent execution)
- Uses a Dolt-backed database for persistent memory and context retention across AI agent sessions
- Supports parallel subagent-driven development with isolated Git worktrees
- Integrates with multiple AI coding agents (Claude Code, Codex, OpenCode, etc.) via plugin systems

## Why It Matters for RAG Builders
It ensures AI coding agents follow disciplined development practices and retain context across sessions, improving code quality and reducing debugging overhead for RAG builders.
