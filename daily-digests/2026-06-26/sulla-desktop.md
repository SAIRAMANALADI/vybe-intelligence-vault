## Summary
Sulla Desktop is a free, desktop-native autonomous AI agent that operates entirely locally or with remote APIs. It features persistent memory, subconscious agents for dynamic context management, and a sandboxed environment for secure task execution.

## Key Features
- Subconscious agent system for dynamic context handling and memory recall
- Observational memory with identity file promotion for persistent context
- Short-term memory distillation to optimize context window usage
- Sandboxed environment with Docker workspaces for secure task execution
- Cross-platform support (macOS, Windows, Linux) with one-command installation

## Why It Matters for RAG Builders
It provides a secure, locally-run autonomous agent framework with advanced memory and context management, enabling RAG builders to integrate persistent, adaptive AI assistants into their workflows.
