## Summary
OpenColor is a lightweight cross-platform desktop color picker designed for VibeCoding workflows. It enables users to capture colors from anywhere on the screen, organize them into named palettes, and export natural-language color systems for AI agent prompts.

## Key Features
- Real-time screen color capture with live preview
- Manual color entry and HSL visual picker
- Image-based color quantization and palette import
- Named palettes with role, family, and note tagging
- Natural-language export for AI agent prompts

## Why It Matters for RAG Builders
OpenColor streamlines color selection and palette management for AI-driven workflows, enabling seamless integration of visually consistent color systems into AI agent prompts.
