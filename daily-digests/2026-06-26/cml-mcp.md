## Summary
cml-mcp is a Model Context Protocol (MCP) server that enables AI assistants to interact with Cisco Modeling Labs (CML) using natural language. It provides 51 tools for managing labs, nodes, links, packet captures, and configurations, bridging AI workflows with network simulation environments.

## Key Features
- 51 MCP tools for comprehensive CML lab management (labs, nodes, links, PCAP, annotations)
- Natural language interface for AI assistants (Claude, Cursor, etc.) to control CML environments
- Supports PyATS for CLI command execution on virtual devices
- Modular architecture with HTTP and STDIO transport modes
- Access control via YAML-based ACLs for HTTP mode

## Why It Matters for RAG Builders
It enables AI-driven network automation by allowing AI assistants to directly manage and configure Cisco Modeling Labs, reducing manual scripting and accelerating network simulation workflows.
