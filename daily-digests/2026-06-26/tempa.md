## Summary
Tempa is a self-hosted, local-first AI agent that integrates with Gmail, Calendar, Google Meet, and WhatsApp to provide unified memory, multi-agent coordination, and RAG-powered responses. It acts as a system core for always-on, always-connected AI workflows.

## Key Features
- Unified RAG memory across Gmail, Calendar, Meet, Slack, and WhatsApp using ChromaDB
- Varys coordinator for task orchestration and hybrid AI workflows (Claude Code CLI + LangGraph)
- Local-first architecture with data stored on-premise for privacy
- WhatsApp bridge for QR-based login, messaging, and reminders with RAG context
- Dashboard and CLI tools for system health monitoring, setup, and manual orchestration

## Why It Matters for RAG Builders
Tempa provides a critical unified memory and orchestration layer for RAG builders, enabling seamless integration of multiple data sources and AI agents while ensuring data privacy and local control.
