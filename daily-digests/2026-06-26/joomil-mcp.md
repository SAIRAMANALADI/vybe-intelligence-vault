## Summary
A Model Context Protocol (MCP) server providing programmatic access to Joomil.ch, Switzerland's leading French-speaking classifieds marketplace. It enables browsing, searching, and retrieving detailed listings across 34 categories and 45,000+ active ads in French-speaking regions.

## Key Features
- Natural-language query parsing with `suggest_filters` for dynamic filter generation
- Comprehensive search capabilities across 34 categories with strict canton filtering
- Detailed listing retrieval including images, descriptions, and seller metadata
- Hierarchical category browsing with parent-child relationships
- Real-time data access to 45,000+ active listings in Switzerland's French-speaking regions

## Why It Matters for RAG Builders
This MCP server enables AI agents to programmatically interact with a large Swiss classifieds dataset, enhancing RAG systems with real-world product and service listings for applications like recommendation engines or market analysis.
