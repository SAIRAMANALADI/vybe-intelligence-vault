## Summary
An MCP server that integrates a user's resume with Claude Desktop to provide intelligent job fit analysis, including match scoring, skill gap identification, and interview question generation.

## Key Features
- Analyzes job fit for any job description using the resume
- Provides a numeric match score (0-100) for job alignment
- Identifies skill gaps between the resume and job requirements
- Generates likely interview questions based on the job description
- Seamless integration with Claude Desktop via MCP
