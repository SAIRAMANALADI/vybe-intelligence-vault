## Summary
EvoScientist is a self-evolving AI research framework that enables autonomous AI scientists to explore, generate insights, and iteratively improve through a multi-agent system. It supports vibe research, scientific workflows, and integrates with multiple AI providers and tools for end-to-end research automation.

## Key Features
- Multi-agent team with 6 specialized sub-agents (plan, research, code, debug, analyze, write) for collaborative workflows
- Self-evolving memory system that auto-distills user profiles and observations across sessions
- Multi-provider support (Anthropic, OpenAI, Google, MiniMax, NVIDIA) with unified configuration
- Multi-channel integration (CLI, TUI, WebUI, Telegram, Slack, Feishu, WeChat) for flexible interaction
- Scientific workflow engine with adaptive tools, context editing, and MCP/skills plugin system

## Why It Matters for RAG Builders
EvoScientist provides a robust, out-of-the-box framework for building autonomous AI research agents that can iteratively improve and adapt, reducing the need for human-in-the-loop interventions in RAG and AI stack development.
