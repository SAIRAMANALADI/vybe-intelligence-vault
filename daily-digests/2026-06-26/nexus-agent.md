## Summary
NexusAgent is a macOS menu bar application and Telegram bot that bridges messaging platforms with locally-installed AI coding CLI tools, enabling remote access to agentic capabilities like file editing, terminal commands, and MCP tools from any device via Telegram or direct macOS integration.

## Key Features
- Bridges Telegram messages to local AI CLI tools (e.g., Gemini CLI) for remote agentic capabilities
- Supports session continuity via in-memory or file-based session management
- Provides a native macOS menu bar app for seamless local control and monitoring
- Includes security layers like user ID whitelisting, local-only execution, and approval modes
- Modular architecture with pluggable provider support and structured JSON output parsing

## Why It Matters for RAG Builders
It enables developers to remotely interact with local AI coding agents through familiar interfaces like Telegram, expanding accessibility and workflow integration for agentic AI systems.
