## Summary
Weave Protocol is an enterprise-grade security suite for AI agents, enabling cryptographic verification, real-time threat detection, and compliance across multiple agent frameworks. It provides a portable security policy standard (WARD.md) enforced via adapters for MCP, Claude Code, Google Antigravity, and Microsoft Agent Framework.

## Key Features
- Portable security policy standard (WARD.md) enforced across MCP, Claude Code, Google Antigravity, and Microsoft Agent Framework
- Real-time threat detection and auditing with cryptographic verification
- Operator dashboard for live monitoring of enforcement surfaces and activity feeds
- CLI-driven setup for framework-specific security middleware integration
- Multi-channel supply chain security via Tollere
