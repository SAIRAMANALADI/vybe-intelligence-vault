## Summary
claude-code-wechat-channel is a Windows-based bridge that connects WeChat messages to Claude Code sessions via the ClawBot ilink API, enabling users to manage chat flows within a single workflow without switching between applications.

## Key Features
- Seamless integration between WeChat and Claude Code for unified chat management
- Uses ClawBot ilink API for message routing and API connectivity
- Windows-native setup with simple installation and configuration
- Supports real-time message forwarding and automated replies
- Includes troubleshooting and logging for debugging
