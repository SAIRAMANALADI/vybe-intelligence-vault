## Summary
Captain Claw is an open-source AI agent framework with multi-agent orchestration, autonomous cognitive systems, and a full management dashboard. It supports local and remote execution, integrates with major LLM providers, and includes 48 built-in tools for tasks like terminal interaction, memory management, and multi-agent collaboration.

## Key Features
- Multi-agent orchestration with autonomous decision-making and learning loops
- Real-time terminal interaction via persistent pseudo-terminal sessions (PTY)
- Conversation topic memory with full Flight Deck panel for browsing and refinement
- Basna (agentic ensemble routing) for parallel multi-agent task execution and synthesis
- Extensible archetype library and per-tenant model tiers for custom agent configurations

## Why It Matters for RAG Builders
