## Summary
Agent Passport System MCP is an enforcement and accountability layer for AI agents, providing identity management, delegation, governance, and signed receipts as modular tools. It enables secure agent interactions through cryptographic attestations and policy enforcement across 150+ tools.

## Key Features
- 150+ modular tools for agent governance, identity, and enforcement
- Cryptographic attestations and signed receipts for accountability
- Multi-profile support (essential, full, and domain-specific)
- ProxyGateway for two-phase execution with replay protection
- Intent Network for agent-mediated matching and collaboration
