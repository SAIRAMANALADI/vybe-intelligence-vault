## Summary
A lightweight Docker Compose template for deploying the Hermes Agent on ARM64 systems, optimized for production use with Coolify. It enables AI agent interactions via platforms like Telegram, Discord, or APIs without the Hermes WebUI overhead.

## Key Features
- ARM64-compatible deployment template for Hermes Agent
- Lightweight setup without Hermes WebUI
- Persistent Docker volumes for data storage
- Health checks and graceful shutdown support
- Scalable for multiple independent Hermes instances
