## Summary
Oteny Talents is an open catalog of AI personas (Talents) designed for the Oteny platform, enabling users to deploy specialized AI assistants on Telegram. Each Talent is a content bundle defining a persona and skills, executed within a secure, scope-locked environment.

## Key Features
- Open catalog of AI personas (Talents) with defined skills and personas
- Secure, scope-locked execution environment for safe AI interactions
- Standardized authoring process with linting and self-check scripts
- Apache-2.0 licensed for open contribution and reuse
- GitHub Actions CI for automated Talent validation

## Why It Matters for RAG Builders
It provides a standardized, open framework for creating and deploying specialized AI assistants, reducing development overhead for RAG builders.
