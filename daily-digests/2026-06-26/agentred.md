## Summary
AgentRed is an AI agent security testing framework that evaluates AI agents against 160+ attack vectors across 35 categories, including prompt injection, tool hijacking, RAG poisoning, and multi-agent exploitation. It generates detailed HTML/JSON reports with remediation advice using a privacy-first architecture.

## Key Features
- 160+ attack test cases derived from latest academic research (OWASP, arXiv, USENIX)
- 7-stage pipeline including adaptive test generation and AI-powered remediation advisor
- Privacy-first architecture with 3-level sanitization to protect sensitive data
- Supports local directory, prompt text, and live API endpoint testing modes
- Generates detailed HTML reports with radar charts, severity tables, and remediation suggestions
