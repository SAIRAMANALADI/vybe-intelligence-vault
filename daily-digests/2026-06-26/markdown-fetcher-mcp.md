## Summary
A next-generation MCP server that converts HTML to clean, structured Markdown with enhanced Turndown.js rules, semantic preservation, and AI integration. Designed for AI training pipelines, knowledge bases, and content archiving with streaming support and multilingual compatibility.

## Key Features
- Enhanced Turndown.js with custom rules for 50+ popular websites
- Streaming conversion with sub-200ms performance for most pages
- Multilingual Markdown support (CJK, Arabic, Cyrillic, RTL)
- AI-enhanced conversion via OpenAI/Claude API integration
- Responsive output modes (GitHub, Obsidian, Notion-compatible)

## Why It Matters for RAG Builders
This tool streamlines the critical preprocessing step of converting web content to clean Markdown, which is essential for building high-quality RAG datasets and AI training pipelines.
