## Summary
WinkTerm is an open-source AI-powered terminal that enables real-time collaboration by allowing an AI to type commands directly into the user's terminal session (PTY). Unlike traditional chatbots, it operates alongside the user in the same terminal process, enabling seamless command execution and editing.

## Key Features
- Shared PTY session enabling AI to type commands directly into the user's terminal input line
- In-terminal chat with persistent history and streaming resume capabilities
- Agent API for external AI agents to drive terminal sessions, SSH, and file transfers
- Multi-model support with OpenAI, Anthropic, Ollama, or any OpenAI-compatible endpoint
- Docker and desktop app deployments with built-in SSH and file transfer functionality

## Why It Matters for RAG Builders
WinkTerm enables AI agents to directly interact with terminal sessions, bridging the gap between AI suggestions and real-time command execution for more efficient and collaborative operations.
