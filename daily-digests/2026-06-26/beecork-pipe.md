## Summary
Beecork Pipe provides infrastructure to make Claude Code always-on and reachable from anywhere via messaging platforms like Telegram, WhatsApp, or Discord. It enables scheduling, persistent memory, and automated task execution without requiring terminal access.

## Key Features
- Always-on Claude Code sessions with persistent context across restarts
- Multi-platform messaging integration (Telegram, WhatsApp, Discord, webhooks)
- Task scheduling and watchers for automated workflows
- Cross-session memory and knowledge base for context retention
- MCP server with 38+ tools for managing tabs, memory, cron jobs, and more
