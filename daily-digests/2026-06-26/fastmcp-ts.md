## Summary
A TypeScript framework for building Model Context Protocol (MCP) servers, clients, and interactive applications. It provides tools to convert TypeScript functions into MCP tools, resources, and prompts, with support for authentication, middleware, and generative UI components.

## Key Features
- Build MCP servers, clients, and apps in TypeScript with automatic input schema inference using Standard Schema-compatible libraries like Zod.
- Support for authentication, middleware (logging, rate limiting), and ambient context for logging, progress tracking, and LLM sampling.
- Interactive UI components and generative UI for building dynamic, LLM-driven applications.
- Multi-server client support with namespaced tool access and sampling adapters for major AI providers (Anthropic, OpenAI, Google).
- CLI tools for inspecting, calling, and managing MCP servers, including editor integrations for Claude and Cursor.

## Why It Matters for RAG Builders
It provides a robust TypeScript framework for building MCP-compliant agents and tools, enabling seamless integration with LLM ecosystems and interactive applications.
