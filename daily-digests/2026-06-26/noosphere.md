## Summary
Noosphere is a self-hosted knowledge and memory layer that enables AI agents and humans to collaboratively store, organize, and recall project knowledge through a shared Markdown wiki and API-driven memory system. It bridges the gap between transient chat transcripts and persistent documentation.

## Key Features
- Unified memory system for AI agents and humans with shared PostgreSQL/Redis backend
- Markdown-based wiki with revision history, tags, and Obsidian sync support
- Scoped access control via API keys and user roles for secure knowledge sharing
- Multi-provider memory recall with ranking, deduplication, and conflict resolution
- Agent tools for auto-capture, auto-recall, and manual memory management

## Why It Matters for RAG Builders
Noosphere provides a critical unified memory layer that enables AI agents to retain and recall project context while allowing humans to curate and browse knowledge, bridging the gap between transient interactions and persistent documentation.
