## Summary
An MCP server providing a Model Context Protocol interface for ConnectWise Automate, enabling AI assistants to interact with RMM tools via a decision tree architecture for domain navigation and tool execution.

## Key Features
- Decision tree architecture for intuitive domain navigation (computers, clients, alerts, scripts)
- Lazy loading of client initialization and domain handlers for performance optimization
- Comprehensive API coverage for managing computers, clients, alerts, and scripts
- Support for both integrator and user authentication methods
- One-click deployment options for DigitalOcean and Cloudflare Workers
