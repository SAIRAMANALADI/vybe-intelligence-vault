TokenForge CLI is a context compression engine designed to optimize token usage for AI-assisted development by intelligently pre-processing code structures, distilling function signatures, and filtering AI responses to reduce token consumption by 70–90%. It acts as a middleware proxy between codebases and AI models, supporting multiple frameworks and AI providers.

- Multi-provider support (OpenAI, Anthropic, Google) and zero-dependency mode for universal compatibility
