## Summary
ResearcherSkill transforms AI coding agents into autonomous research assistants by providing a single markdown file (`researcher.md`) that enables agents to design, execute, and refine experiments across any codebase or problem domain with minimal setup.

## Key Features
- Autonomous experiment design and execution with hypothesis testing
- Built-in convergence detection and strategy pivoting for stuck agents
- Session resume capability across multiple runs
- Supports both quantitative metrics (build time, test pass rate) and qualitative rubrics
- Non-linear branching for exploring multiple optimization paths simultaneously

## Why It Matters for RAG Builders
It enables AI agents to autonomously improve codebases, APIs, and configurations by designing and validating experiments, reducing manual effort in optimization tasks.
