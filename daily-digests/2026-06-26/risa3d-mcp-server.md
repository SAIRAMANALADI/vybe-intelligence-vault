## Summary
A Model Context Protocol (MCP) server and CLI toolkit that enables AI assistants like Claude to interact with RISA-3D structural model files (.r3d) in plain English. It bridges the gap between RISA-3D's lack of a public API and AI-driven workflows by parsing and modifying .r3d files directly.

## Key Features
- Direct parsing and modification of RISA-3D .r3d files without requiring RISA-3D API
- 40+ MCP tools for model interrogation, QA/QC, load parsing, material takeoffs, and model comparison
- Standalone CLI for debugging and report generation without AI integration
- Regression-tested parser and write-tools for reliability
- Supports batch workflows, model cloning, and Excel/SAF exports

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with RISA-3D structural models, unlocking AI-assisted workflows for structural engineers without requiring manual data extraction or API automation.
