## Summary
comind-mcp is a self-hosted gateway that aggregates, curates, and composes tools from MCP servers, OpenAPI specs, and HTTP services into virtual MCP endpoints for agents. It enables multi-user isolation, scheduling, secrets management, and observability for AI agent workflows.

## Key Features
- Aggregates MCP servers, OpenAPI specs, and HTTP services into curated toolsets
- Virtual MCP endpoints (groups) with per-agent API keys and isolated tool access
- Composite tools for multi-step intent execution with templating and tracing
- Built-in scheduler and self-cron tools for agent-driven task automation
- Secrets vault with runtime substitution and source-scoped credentials

## Why It Matters for RAG Builders
It simplifies the integration of diverse MCP servers and APIs into unified, agent-accessible toolsets with built-in security, scheduling, and observability for RAG and AI agent systems.
