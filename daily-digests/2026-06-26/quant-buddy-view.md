## Summary
quant-buddy-view is a dashboard publishing layer for financial data analysis and quantitative research that transforms investment ideas into auto-updating, shareable web dashboards. It bridges data exploration and visualization without backend infrastructure, enabling dynamic, real-time data rendering via formula packages.

## Key Features
- Auto-updating dashboards with live data fetched via formula packages
- Seamless integration with AI agents (Claude Code, Cursor, OpenClaw) for deployment
- Pre-built templates for market analysis, stock valuation, and strategy tracking
- Zero backend infrastructure required; pure static HTML with dynamic data fetching
- Supports custom dashboard creation with shared data kernel for consistency

## Why It Matters for RAG Builders
