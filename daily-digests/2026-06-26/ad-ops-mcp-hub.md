## Summary
AdSynthesis Engine is an MCP (Model Context Protocol) server that unifies AI-driven ad operations across Google Ads, Meta Ads, GA4, TikTok Ads, and LinkedIn Ads. It enables natural language control of 300+ ad operations with human-in-the-loop safety and cross-platform performance synthesis.

## Key Features
- Unified natural language interface for 300+ ad operations across 5 major platforms
- Human-in-the-loop safety protocol for all write operations
- Intelligent query routing and cross-platform performance synthesis
- AI client agnosticism (ChatGPT, Claude, Gemini, Cursor)
- Pre-built operation templates for rapid deployment
