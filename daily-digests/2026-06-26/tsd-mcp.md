## Summary
A Model Context Protocol (MCP) server that enables natural language interaction with Tekla Structural Designer (TSD) models via the Remoting API. It allows engineers to query, analyze, and estimate structural models directly through AI assistants like Claude without manual interface navigation.

## Key Features
- Natural language querying of TSD models via MCP for real-time analysis
- Comprehensive steel takeoff and material cost estimation with breakdowns by member/type/section
- Design review tools including utilization ratios, failing members, and validation error extraction
- Seamless integration with Claude Desktop for conversational model interaction
- Read-only access to live TSD models without file exports or manual data extraction

## Why It Matters for RAG Builders
It bridges the gap between structural engineering workflows and AI assistants by enabling direct, conversational access to Tekla Structural Designer models, reducing manual effort in model analysis and estimation.
