## Summary
ConvertigoMCP is a Model Context Protocol (MCP) server project that exposes Convertigo tools, prompts, resources, and project management capabilities via a local Streamable HTTP endpoint. It enables agentic workflows for creating, validating, and managing Convertigo projects through MCP-compatible clients like Mistral Vibe, Codex, and Claude Code.

## Key Features
- Exposes Convertigo tools and resources via MCP endpoint for agentic project creation
- Supports Streamable HTTP transport for MCP clients (Mistral Vibe, Codex, Claude Code)
- Provides CRUD templates for mobile applications (TplEntityPage, TplHome, TplLogin)
- Enables project validation, save, and runtime checks through MCP tools
- Includes shared components for error handling, loading states, and dashboard cards

## Why It Matters for RAG Builders
