## Summary
AOS is a file-system-based operating system framework for AI agents, providing a structured runtime environment with kernel rules, a standardized file system, a desktop interface, and persistent memory. It transforms AI interactions from single-session conversations into a continuously running, auditable system.

## Key Features
- Standardized 10-directory file system with strict role-based constraints for AI agent operations
- AOS Viewer desktop environment for real-time system visibility, control, and auditability
- Built-in Skills (WKIS, migration, consistency checks) for reusable AI workflows
- Cross-session persistent memory via structured file storage (04_MEMORY/)
- Zero-code dependency deployment with executable desktop interface and platform adapters

## Why It Matters for RAG Builders
It provides a structured, auditable, and persistent runtime environment for AI agents, enabling reliable long-term task execution and knowledge retention across sessions.
