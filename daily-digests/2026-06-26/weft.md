## Summary
Weft is a modular AI agent platform featuring a Rust-based core runtime with an OpenAI-compatible API, a capability-based plugin system, and a Flutter desktop client. It enables multi-agent team orchestration, persistent memory, tool use, and extensibility via WASM/native packages, supporting AI-augmented applications like an RSS reader and video-editing canvas.

## Key Features
- OpenAI-compatible core runtime with multi-provider routing and failover
- Capability-based plugin system for extensibility via WASM/native packages
- Multi-agent team orchestration with DAG-based workflows and role delegation
- Persistent memory and context engine for proactive AI assistance
- Built-in tools (shell, files, web, git) with semantic tool selection

## Why It Matters for RAG Builders
