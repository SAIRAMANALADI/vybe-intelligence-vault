## Summary
Zeus is a local-first AI agent orchestrator with a real-time web and mobile UI that enables AI agents to perform computer tasks like file operations, command execution, browser automation, and task scheduling. It operates entirely offline with no cloud dependency, storing all data locally in a user-editable directory.

## Key Features
- Local-first architecture with no cloud dependency, ensuring data privacy and offline functionality
- Full-featured web and mobile UI with PWA support, enabling agent control from any device
- Built-in tools for file operations, command execution, web search, and vision-driven browser automation
- Sub-agent delegation, workflow automation, and scheduled jobs with layered memory management
- Self-contained integrations for models (Ollama), search (SearXNG), and browser (Chromium) within `~/.zeus`

## Why It Matters for RAG Builders
Zeus provides a complete, local-first platform for building and deploying AI agents that can interact with and control a computer, making it essential for developers seeking privacy-preserving, offline-capable agent orchestration.
