## Summary
Nucleus MCP is a portable decision log and governance tool for AI agents that enables persistent memory, execution verification, and human-in-the-loop corrections across sessions and tools. It operates as an MCP server with 114 tools for memory management, task orchestration, compliance, and reliability tracking.

## Key Features
- Portable decision log (`.brain`) for AI tools with plain file storage (JSON + markdown)
- Three-frontier reliability loop: GROUND (verification), ALIGN (corrections), COMPOUND (learning)
- 114 MCP tools for memory, tasks, sessions, governance, and orchestration
- Compliance automation for regulatory frameworks (EU DORA, MAS TRM, SOC2)
- Telemetry with opt-in privacy controls and anonymous aggregate reporting
