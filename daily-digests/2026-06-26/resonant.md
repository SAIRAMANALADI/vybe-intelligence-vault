## Summary
Resonant is a persistent, autonomous AI companion framework built on the Claude Code Agent SDK. It enables self-directed AI agents that remember context, manage sessions, and interact across multiple channels while running locally with SQLite storage.

## Key Features
- Session continuity with daily rotation and named threads
- Agent-directed autonomy with routines, impulses, and failsafes
- Multi-channel interactions (web UI, Discord, Telegram, voice)
- Local SQLite storage with no cloud dependency beyond Claude Code
- Semantic search and canvas editor for rich interactions

## Why It Matters for RAG Builders
Resonant provides a robust framework for building self-directed AI companions with persistent memory and multi-channel autonomy, reducing the complexity of integrating agent orchestration into RAG systems.
