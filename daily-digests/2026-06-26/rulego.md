## Summary
RuleGo is a lightweight, high-performance, embedded rule engine and orchestration framework built in Go. It enables dynamic, component-based rule chain execution for real-time business logic processing, data integration, and workflow automation.

## Key Features
- Component-based architecture for flexible rule chain composition
- Embedded and standalone deployment modes with dynamic rule updates
- Built-in support for 50+ reusable components (HTTP, MQTT, JavaScript, etc.)
- High-performance processing with coroutine and object pooling
- Context isolation and AOP mechanisms for reliable concurrency

## Why It Matters for RAG Builders
RuleGo enables dynamic, low-overhead orchestration of AI workflows and data pipelines, making it essential for building scalable, real-time RAG systems with complex business logic.
