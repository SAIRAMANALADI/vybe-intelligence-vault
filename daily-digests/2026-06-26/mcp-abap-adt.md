## Summary
mcp-abap-adt is an MCP server that provides AI agents with controlled, full CRUD access to SAP ABAP repositories via ADT (ABAP Development Tools). It enables deep ABAP analysis, iterative development, and repository navigation for both on-premise and cloud-based SAP systems.

## Key Features
- Full CRUD operations for ABAP artifacts (classes, interfaces, CDS views, RAP artifacts, etc.)
- Deep ABAP analysis tools (where-used, semantic analysis, dependency mapping)
- Multi-system support (SAP ECC/S/4HANA, ABAP Cloud, legacy systems)
- Destination-based authentication (JWT/XSUAA, service keys, RFC)
- Embeddable server for integration with existing applications

## Why It Matters for RAG Builders
It provides AI agents with real-time, structured access to SAP ABAP systems, enabling accurate RAG pipelines and automated ABAP development workflows grounded in live system data.
