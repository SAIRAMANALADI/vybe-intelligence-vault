## Summary
n2-arachne is a Windows desktop application designed to streamline AI context preparation by filtering and organizing large sets of files or notes into focused, noise-free inputs for AI tools and agents. It helps optimize context windows for LLMs by selecting only the most relevant files and dependencies.

## Key Features
- Scans and maps project file structures to identify key files
- Filters out noise to create focused AI context inputs
- Supports dependency tracking for accurate context assembly
- Local storage for project data and cache (SQLite-based)
- Exports clean, optimized context for direct use in AI tools
