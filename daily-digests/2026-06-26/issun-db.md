## Summary
IssunDB is a high-performance embedded graph database designed for AI applications, offering ACID-compliant property graph modeling with Cypher query support. It enables fast graph traversal, analytics, and hybrid search for building GraphRAG pipelines and knowledge graph systems.

## Key Features
- ACID-compliant property graph model with Cypher query support
- High-performance graph traversal and analytics using sparse matrix operations
- Built-in vector, text, and hybrid search capabilities for AI applications
- Multi-language support including Rust, Python, CLI, HTTP, and MCP APIs
- Cross-platform compatibility with Docker containerization for easy deployment

## Why It Matters for RAG Builders
IssunDB provides a critical foundation for GraphRAG and knowledge graph systems by enabling efficient graph storage, traversal, and hybrid search at scale.
