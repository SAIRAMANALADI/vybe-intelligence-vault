## Summary
tinycode is a local-first AI coding assistant designed to run air-gapped with zero cloud dependencies, leveraging your own LLMs (Ollama, vLLM, or OpenAI-compatible endpoints). It offers a terminal UI, web UI, and desktop app, along with 24 built-in agents and 9 skills for coding tasks.

## Key Features
- Supports local LLMs (Ollama, vLLM) with air-gapped operation as primary use case
- Three interfaces: terminal UI (TUI), web UI (SolidJS + TailwindCSS), and desktop app (Electron)
- 24 built-in agents for tasks like code review, debugging, planning, and security analysis
- 9 built-in skills for specialized workflows (e.g., AI slop cleaner, deep initialization, MCP setup)
- Plugin system (`@tinycode/plugin`) with lifecycle hooks and tool registration for extensibility

## Why It Matters for RAG Builders
tinycode empowers AI engineering teams to build and deploy local-first coding assistants with minimal cloud dependency, enhancing privacy and control while providing a robust multi-interface agent framework.
