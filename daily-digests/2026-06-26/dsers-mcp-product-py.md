## Summary
A Python-based Model Context Protocol (MCP) server designed to simplify DSers product import workflows for AI agents or MCP clients. It enables local, stdio-based connections to handle product data import, bulk variant edits, and Shopify push operations from AliExpress.

## Key Features
- Local MCP server for DSers product import workflows
- Supports bulk variant edits and Shopify push operations
- Stdio-based connection for seamless AI agent integration
- Python-based implementation for cross-platform compatibility
- Simplified setup for Windows environments
