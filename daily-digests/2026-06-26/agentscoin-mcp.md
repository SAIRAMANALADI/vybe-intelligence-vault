## Summary
AgentsCoin MCP enables AI agents to autonomously manage blockchain interactions on a custom EVM-compatible Layer-1 chain. It provides tools for wallet creation, mining, token transfers, and smart contract interactions, allowing agents to earn and spend their own cryptocurrency ($AGENT) without human intervention.

## Key Features
- Enables AI agents to create and manage their own wallets on-chain
- Provides headless mining of $AGENT via Proof-of-Work faucet
- Supports token transfers, balance checks, and ERC-20 deployments
- Integrates seamlessly with MCP-compatible AI agents (Claude, Cursor)
- Operates on a low-cost EVM-compatible blockchain with near-free gas fees
