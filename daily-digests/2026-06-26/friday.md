## Summary
Ares is a terminal-based personal AI assistant with persistent memory, task management, and local-first data storage. It combines natural language interaction with a proactive memory system, file access tools, and optional desktop UI for a Jarvis-like experience entirely on the user's machine.

## Key Features
- Persistent memory with ONNX-accelerated embeddings and SQLite storage
- Natural language task management with proactive reminders and desktop notifications
- File system access with sandboxed write operations and fuzzy matching
- Modular skills system with YAML frontmatter and dynamic loading
- Dual-mode operation: CLI and Electron/React desktop app with shared backend

## Why It Matters for RAG Builders
Ares provides a robust local agent framework with memory persistence and tool integration, making it ideal for building privacy-focused AI assistants or extending RAG systems with persistent context and proactive task handling.
