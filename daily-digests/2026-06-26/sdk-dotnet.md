## Summary
The RoxyAPI .NET SDK provides a fully typed client library for integrating astrology, Vedic astrology, numerology, tarot, and other esoteric domains into .NET applications. It simplifies access to a multi-domain API with verified astronomical data and supports AI agents, web apps, and mobile platforms.

## Key Features
- Fully typed .NET client for 12+ esoteric domains (astrology, tarot, numerology, etc.)
- Verified against NASA JPL Horizons for astronomical accuracy
- Supports .NET 8, .NET Framework 4.6.1+, Unity, and Mono
- Simplified geocoding and timezone handling for chart calculations
- Generated from OpenAPI spec for automatic endpoint updates
