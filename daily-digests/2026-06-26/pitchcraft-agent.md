## Summary
TicketGuard is an AI agent that investigates suspicious ticket resale listings or seller communications to detect scams. It uses an 8-step investigation pipeline powered by Google ADK, Gemini 2.5 Flash, and MongoDB Atlas for vector search, hybrid retrieval, and risk scoring, returning evidence-backed scam-risk verdicts.

## Key Features
- 8-step investigation pipeline with deterministic risk scoring in MongoDB
- Hybrid retrieval using MongoDB Vector Search and Atlas Search
- Multi-modal input handling (text, PDF, images, URLs)
- Live SSE streaming for real-time feedback
- Agent memory and change streams for continuous learning
