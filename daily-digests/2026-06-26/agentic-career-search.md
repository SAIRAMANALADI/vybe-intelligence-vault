## Summary
An AI-agent backend designed for autonomous job discovery, providing explainable decision-making, durable event logging, and production-grade reliability for career search automation.

## Key Features
- Deterministic decision engine with rationale traces for explainable job recommendations
- Durable event logging and state-machine run lifecycle for debugging and replay
- Configurable LLM provider integrations (Gemini, Kimi, Claude, GPT-compatible)
- Graceful fallback mechanisms for API outages and vendor lock-in avoidance
- Production-grade API endpoints for job source management, run control, and health checks
