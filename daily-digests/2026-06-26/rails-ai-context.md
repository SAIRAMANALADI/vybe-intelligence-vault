## Summary
A Ruby gem that provides structured AI context for Rails applications by exposing 39 tools via MCP server or CLI, enabling AI agents to understand Rails internals (models, controllers, routes, schema) with minimal token usage and zero configuration.

## Key Features
- 39 structured tools for Rails app introspection (models, controllers, routes, schema, etc.)
- MCP server and CLI interfaces for seamless AI agent integration
- Reduces token usage by up to 98% compared to raw file reads
- Prevents common AI misinterpretations (encrypted columns, Devise methods, Turbo wiring)
- Zero-config setup with auto-discovery via `.mcp.json`

## Why It Matters for RAG Builders
It eliminates AI guesswork in Rails app interactions by providing precise, structured context, drastically reducing token waste and iteration cycles for RAG/AI stack builders.
