## Summary
Animus is an AI-controllable Minecraft bot with a modular architecture that separates the 'body' (Mineflayer-based bot) from the 'brain' (AI model or interactive controller). It enables autonomous or interactive gameplay, including building, movement, and command execution via HTTP API or in-game chat.

## Key Features
- Swappable AI brains (Claude API or local LLM like llama.cpp/Ollama)
- HTTP control API for remote command execution and state monitoring
- In-game chat command support with operator allowlist
- Bedrock protocol support via alternative body implementation
- Isolated test server setup for local development
