## Summary
FlowGate is a typed document pipeline system designed to enforce accountability for AI agents by requiring proof of work before tasks are approved. It acts as a gate between an agent's claim of completion and the actual verification of that work, ensuring structured review and approval processes.

## Key Features
- Typed document pipeline with auto-numbering and chaining (Requirement → Task → Task Report)
- Review gates for approval, rejection, or revision requests with full history tracking
- Remote worker API with scoped Bearer tokens and dry-run validation
- Real-time updates via Server-Sent Events (SSE) and notification feed
- Multi-database support (SQLite, MySQL, PostgreSQL) with automated migrations

## Why It Matters for RAG Builders
FlowGate ensures AI agents cannot falsely claim task completion by enforcing structured verification and approval, making it essential for building reliable and accountable AI-driven workflows.
