## Summary
EstaCoda is an open-source terminal-native AI agent runtime designed for agent evolution, enabling agents to improve over time through real-world execution. It supports multi-channel operations (CLI, Telegram, WhatsApp, Discord, Email), persistent memory, tool use, scheduling, and reviewable skill/workflow proposals.

## Key Features
- Agent self-improvement loop with reviewable proposals, evidence, and approvals
- Multi-channel operation (CLI, Telegram, WhatsApp, Discord, Email)
- Persistent memory and durable workflows across sessions
- Provider-agnostic architecture supporting local and cloud LLMs
- Built-in Arabic language support with bidirectional terminal rendering

## Why It Matters for RAG Builders
EstaCoda provides a governed, reviewable framework for building long-lived AI agents that evolve safely and transparently, making it essential for teams prioritizing trust and control in agentic systems.
