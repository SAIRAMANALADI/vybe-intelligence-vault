## Summary
Flow-Next is an AI agent orchestration plugin that provides a structured, spec-driven workflow for AI coding agents, enabling durable task decomposition, cross-model adversarial reviews, and evidence-based PR generation. It operates entirely within the repository with zero external dependencies.

## Key Features
- Durable spec management with six named handover objects for structured workflows
- Cross-model adversarial reviews at every stage to ensure quality and reduce drift
- Task decomposition into dependency-ordered, context-sized units for efficient execution
- Receipts and evidence tracking for every task, ensuring proof of completion
- Multi-platform support (Claude Code, OpenAI Codex, Factory Droid, Grok Build) with zero external dependencies

## Why It Matters for RAG Builders
Flow-Next provides a critical framework for structuring and validating AI-driven development workflows, ensuring reliability, traceability, and quality through adversarial reviews and evidence-based processes.
