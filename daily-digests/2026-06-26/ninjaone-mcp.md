## Summary
A Model Context Protocol (MCP) server for NinjaOne, enabling AI assistants to interact with NinjaOne's device monitoring, patching, scripting, and alert management tools. It uses a decision tree architecture for efficient tool loading and lazy initialization.

## Key Features
- Hierarchical tool loading with decision tree architecture for reduced cognitive load
- Supports multiple NinjaOne domains (devices, organizations, alerts, tickets)
- One-click deployment to Cloudflare Workers and DigitalOcean
- OAuth 2.0 authentication with automatic token refresh
- Prebuilt Docker image and `.mcpb` bundle for zero-setup deployment

## Why It Matters for RAG Builders
This MCP server enables AI assistants to securely and efficiently interact with NinjaOne's IT management tools, expanding the capabilities of RAG systems in enterprise environments.
