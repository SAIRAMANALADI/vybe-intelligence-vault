## Summary
SeshatOS is a self-hosted, multi-user AI platform that combines a desktop application, REST API, and agent governance system. It provides a full-stack environment for running autonomous AI teams with persistent memory, RAG capabilities, and multi-provider LLM support.

## Key Features
- Multi-user authentication with RBAC and workspace isolation
- Persistent sessions with memory injection and structured plans
- Hybrid RAG (BM25 + vector search) with multi-backend support
- Built-in MCP client and server configuration management
- Scheduled tasks, audit logging, and quotas for governance

## Why It Matters for RAG Builders
SeshatOS provides a comprehensive, self-hosted platform for building and managing autonomous AI teams with robust RAG capabilities, multi-provider LLM support, and governance features essential for production-grade AI applications.
