## Summary
Hover is a local-first VS Code extension that uses AI to generate Playwright test specifications from plain English descriptions or autonomous QA exploration. It drives real Chrome browsers via Playwright MCP, producing deterministic, CI-ready test specs without embedding AI dependencies.

## Key Features
- Generates Playwright test specs from plain English descriptions or autonomous QA exploration
- Supports both local coding-agent CLIs (Claude Code, Codex, etc.) and BYOK API keys
- Autonomous QA testing mode with API and penetration testing toggles
- Deterministic, portable specs that run in CI without AI dependencies
- Multi-environment account management with secure credential handling

## Why It Matters for RAG Builders
Hover bridges the gap between AI-assisted test generation and production-ready Playwright specs, enabling RAG builders to automate high-quality test coverage without embedding AI dependencies in their CI pipelines.
