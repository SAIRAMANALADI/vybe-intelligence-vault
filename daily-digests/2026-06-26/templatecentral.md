## Summary
A Claude Code plugin that automates the scaffolding of production-ready projects across four stacks (Next.js, Vite+React, FastAPI, NestJS) with pre-configured tooling, testing, and AI agent integration. Users can generate fully configured projects with a single prompt.

## Key Features
- One-prompt project generation for Next.js, Vite+React, FastAPI, and NestJS stacks
- Pre-configured tooling (TypeScript, ESLint, Prettier, Docker, Vitest, Husky/lefthook)
- AI harness with 7-event hook kit for security, validation, and context recovery
- Automatic generation of AGENTS.md and CLAUDE.md for agent orchestration
- Modular skill system for adding capabilities (auth, database, testing, etc.) post-scaffolding

## Why It Matters for RAG Builders
It drastically reduces setup time for AI-driven projects by automating the generation of production-ready stacks with pre-configured tooling and agent integration, enabling faster iteration and deployment.
