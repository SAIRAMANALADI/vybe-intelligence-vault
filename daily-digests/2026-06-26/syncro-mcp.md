## Summary
A Model Context Protocol (MCP) server for Syncro MSP that implements a decision tree architecture for efficient tool navigation, enabling AI assistants to interact with Syncro's MSP functionality (tickets, assets, contacts, invoices) via a structured, domain-specific interface.

## Key Features
- Decision tree-based tool navigation for efficient domain switching
- Lazy loading of domain handlers and Syncro client for performance
- Full Syncro API coverage including customers, tickets, assets, contacts, and invoices
- One-click deployment options for Cloudflare Workers and DigitalOcean
- Rate limiting handling via the underlying Syncro SDK

## Why It Matters for RAG Builders
It provides AI assistants with structured, domain-aware access to Syncro MSP's functionality, enabling seamless integration for RAG systems managing IT service operations.
