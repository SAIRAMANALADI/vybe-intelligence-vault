## Summary
Oracle5 (Kali) is a local-first AI assistant designed for Linux systems, offering hands-on desktop control, security auditing, pentesting tooling, and multi-provider LLM integration. It prioritizes user control, privacy, and explicit approval for any action with potential side effects.

## Key Features
- Runs as a native GTK4 app on Linux with X11/Wayland support
- Provides security auditing and pentesting tooling with explicit user approval for actions
- Supports multi-provider LLM integration (SiliconFlow, Groq, Novita, GitHub Models, Google AI Studio)
- Includes voice control (STT/TTS) and desktop automation (window control, OCR, keystrokes)
- Allows self-modification and self-written tools in a sandboxed environment

## Why It Matters for RAG Builders
Oracle5 provides a privacy-focused, user-controlled AI agent framework for Linux that integrates security tooling and desktop automation, making it ideal for power users and security professionals who need a local, customizable assistant.
