## Summary
frontfrisk is a coding-agent skill designed to audit and fix accessibility and visual issues in frontend code written by AI agents. It checks for WCAG contrast violations, missing accessibility labels, keyboard navigation issues, and token/spacing drift before the UI is shipped.

## Key Features
- Automated WCAG contrast ratio checks for visual accessibility compliance
- Detection of missing alt text, labels, and ARIA attributes
- Keyboard navigation and focusability validation
- Token and spacing drift detection against design system variables
- Seamless integration with AI coding agents (Claude, Cursor, Gemini, etc.)

## Why It Matters for RAG Builders
It ensures AI-generated frontend code meets accessibility and visual design standards before deployment, reducing post-ship failures and improving user experience.
