## Summary
Academic Oracle is an adaptive AI learning platform that transforms passive knowledge consumption into deep understanding through structured reasoning, active recall, and exam simulation. It bridges learning and evaluation modes to optimize retention, intuition, and real exam performance.

## Key Features
- Dual-mode learning system (Learning Mode + Exam Mode) with structured reasoning flows
- Oracle Memory system for tracking understanding, mistakes, and progress across sessions
- Integrated quiz and exam platform with examiner-style grading and performance analysis
- Tiered help system for adaptive exam conditions (Level 0-3 assistance)
- PDF exam processing with automated question extraction, mark scheme parsing, and analytics export
