## Summary
An autonomous AI-powered penetration testing agent that runs entirely locally using Google's Gemma 4-12B model via LM Studio. It performs autonomous reconnaissance, attack loops, and generates professional pentest reports while learning from failures through a persistent negative experience cache.

## Key Features
- Fully local deployment with no cloud dependency or API keys
- Autonomous recon and attack loops using 22 integrated security tools
- Persistent negative experience cache to avoid repeating failed attempts
- Automatic generation of branded HTML pentest reports on session completion
- Self-harnessing and self-correcting learning mechanism

## Why It Matters for RAG Builders
It provides a fully local, autonomous framework for penetration testing that leverages local LLMs to reduce dependency on cloud services while improving efficiency through persistent learning.
