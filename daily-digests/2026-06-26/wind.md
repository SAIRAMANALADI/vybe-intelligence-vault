## Summary
Wind is a utility-first styling framework for Flutter that enables developers to write Tailwind CSS-like className strings directly in their widget tree, reducing boilerplate and accelerating UI development. It includes 27 W-prefix widgets, dark mode, responsive design, and three AI integration layers for modern Flutter app development.

## Key Features
- Tailwind CSS syntax for Flutter widgets with className strings
- 27 W-prefix widgets (e.g., WDiv, WText, WButton) for rapid UI construction
- First-class dark mode, responsive design, and state/platform prefixes
- AI-first integration with MCP server and agent skills for coding assistants
- Server-driven UI via WDynamic for dynamic widget rendering from JSON
