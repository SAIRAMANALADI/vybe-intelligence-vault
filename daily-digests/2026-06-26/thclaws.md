## Summary
thClaws is a native-Rust AI agent workspace that provides a multi-surface agent harness (desktop GUI, CLI, headless, and webapp) with built-in tools for coding, automation, and coordination. It supports multi-provider LLMs, MCP servers, skills, and plugins, enabling sovereign AI workflows on local or cloud models.

## Key Features
- Multi-surface agent harness (GUI, CLI, headless, webapp) with a single binary
- Multi-provider support including OpenRouter Fusion, Anthropic, OpenAI, Google Gemini, and local models via Ollama
- Built-in Media Studio for image/video generation and editing across multiple providers
- Agent Teams and concurrent subagents for complex orchestration and parallel workflows
- Knowledge Management System (KMS) with grep-based indexing and session memory via `/dream`

## Why It Matters for RAG Builders
thClaws provides a sovereign, multi-surface agent framework with deep MCP integration, making it essential for building modular, extensible AI agents that can operate across desktop, CLI, and web environments while supporting diverse LLM providers.
