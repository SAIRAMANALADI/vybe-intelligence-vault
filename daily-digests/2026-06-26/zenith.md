## Summary
Zenith is a plain-text design document format and engine that enables AI agents to safely create, edit, and validate design files like posters, decks, and diagrams. It compiles `.zen` files deterministically to pixel-exact PNGs or print-ready PDFs, ensuring consistency and auditability.

## Key Features
- Plain-text `.zen` format for human-readable and diffable design files
- Deterministic compilation to PNG/PDF with pixel-exact output
- Comprehensive validation and diagnostics for safety and correctness
- Agent-native CLI and API for programmatic design editing
- Modular Rust-based architecture with clean crate boundaries
