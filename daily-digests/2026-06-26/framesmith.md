## Summary
Framesmith is an open-source MCP server that enables AI coding agents to create and manage visual UI designs through a structured canvas system. It provides a browser-based viewer for reviewing, inspecting, and managing designs before any framework code is written.

## Key Features
- MCP-compatible server for AI coding agents to create and manage UI canvases
- Standalone browser viewer for reviewing designs at multiple breakpoints
- Quality inspector with heuristic scoring and auto-fixable issue resolution
- Design-system panel for inspecting resolved design tokens and inheritance
- Batch operations for scene graph manipulation via text-based commands

## Why It Matters for RAG Builders
Framesmith bridges the gap between AI-generated UI designs and human review by providing a visual canvas and inspection tools, ensuring designs are validated before implementation.
