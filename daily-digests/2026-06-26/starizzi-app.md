## Summary
Starizzi is a cross-platform desktop application that serves as a multi-agent gateway for Windows and macOS, enabling users to run, chat with, and orchestrate multiple open-source AI agents like OpenClaw, Hermes, AutoGPT, and CrewAI through a single liquid-glass interface. It integrates with IzziAPI for unified model access and agent management.

## Key Features
- Unified gateway for multiple AI agents (OpenClaw, Hermes, AutoGPT, CrewAI, etc.) with parallel chat support
- One-click setup and configuration via Express mode or custom setup, including Docker-based agent deployment
- IzziAPI integration for unified access to 200+ models (GPT, Claude, Gemini) with smart routing and cost tracking
- Built-in marketplace for discovering, installing, and managing agent extensions and bundles
- Liquid-glass UI with auto-update functionality and real-time agent status streaming

## Why It Matters for RAG Builders
Starizzi simplifies the deployment and management of multiple AI agents in a single desktop interface, reducing setup complexity and enabling seamless orchestration for RAG and AI workflow builders.
