## Summary
A production-ready AI agent pipeline that automates birthday wishes and life event congratulations across multiple social platforms (LinkedIn, WhatsApp, Facebook, Instagram, Twitter/X, Slack) using LangChain, browser automation, and AI models like Gemini 2.5 Pro. Features include multi-language support, sentiment analysis, memory systems, and a unified command center dashboard.

## Key Features
- Multi-platform birthday wish automation (LinkedIn, WhatsApp, Facebook, Instagram, Twitter/X, Slack)
- AI-generated personalized wishes with sentiment analysis and tone matching
- Memory system (ChromaDB) for long-term relationship tracking and personalization
- Unified command center dashboard for real-time monitoring and control
- Multi-language support (17 languages) and voice message generation
