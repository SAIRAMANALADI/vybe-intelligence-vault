## Summary
A research-focused personal AI assistant implementing a biologically-inspired cognitive architecture with persistent memory, local LLM inference, and agentic orchestration. Designed for educational and experimental purposes to explore advanced AI system design patterns.

## Key Features
- 7-stage pre-LLM gateway pipeline for security, governance, and intent classification
- Seshat memory protocol with episodic-to-semantic promotion pipeline
- Single-brain architecture using Qwen3.5-35B for unified reasoning
- Delegation and expansion strategies with sub-agent spawning
- Biologically-inspired homeostasis loop (Brainstem) for system stability
