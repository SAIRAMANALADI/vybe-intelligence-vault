## Summary
OctoAgent is a white-box, task-centric multi-agent platform designed for business operations, system administration, research, and office automation. It provides fully auditable and reproducible workflows with visible reasoning steps, tool calls, and artifacts, contrasting with closed-agent alternatives like OpenClaw.

## Key Features
- Fully inspectable and auditable agent workflows with transparent tool calls and reasoning steps
- Supports multi-agent orchestration with subagent collaboration and tool-budget middleware
- Integrated RAG store (FAISS) for knowledge retrieval and synthesis
- Dual-licensed (SSPL v1 + commercial) with strict commercial usage controls
- Preconfigured Docker deployment for local or server-based operation with optional host installation

## Why It Matters for RAG Builders
OctoAgent enables RAG builders to create fully auditable, reproducible, and transparent AI agent workflows that integrate seamlessly with retrieval systems for enterprise-grade automation.
