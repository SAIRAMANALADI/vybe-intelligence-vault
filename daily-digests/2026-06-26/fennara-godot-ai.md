## Summary
Fennara Godot AI bridges Godot game engine projects with MCP clients and AI agents, enabling real-time inspection, editing, and validation of Godot scenes, scripts, and runtime data. It provides a local MCP server, CLI tools, and an in-editor chat dock for AI-driven game development workflows.

## Key Features
- Live connection to Godot editor for inspecting scenes, scripts, and runtime logs
- CLI and MCP server for external AI tools (Claude, Cursor, etc.) to interact with Godot projects
- Built-in in-editor chat dock with project-aware tools and provider flexibility
- Automated project guidance generation for AI agents (AGENTS.md, guidelines.md)
- Cross-platform support (Windows, macOS, Linux) with platform-specific webview for chat

## Why It Matters for RAG Builders
Fennara enables AI agents to directly interact with and validate live Godot projects, bridging the gap between static file edits and dynamic game engine feedback for more accurate and efficient AI-driven game development.
