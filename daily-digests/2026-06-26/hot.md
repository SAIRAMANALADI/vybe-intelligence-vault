## Summary
Hot Dev is an open-source platform for building backend workflows, AI agents, and service orchestration using the Hot language. It provides a compiler, runtime, CLI, scheduler, and web-based dashboard for deploying and managing distributed systems.

## Key Features
- Unified language (Hot) for defining workflows, events, schedules, and MCP tools
- Built-in execution tracing, local dev runtime, and single-command deploys
- Supports webhooks, event-driven architectures, and long-running tasks
- Integrated scheduler for time-based workflows and AI agent orchestration
- CLI and dashboard for development, testing, and deployment

## Why It Matters for RAG Builders
Hot Dev simplifies the orchestration of AI agents and backend workflows, reducing complexity in building scalable, event-driven systems for RAG pipelines and agentic applications.
