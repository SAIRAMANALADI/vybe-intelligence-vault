## Summary
Juno is a native macOS desktop application that enables AI to autonomously control a user's computer through voice or text commands. It leverages Anthropic's Computer Use API to perform tasks like form filling, file management, web browsing, and app navigation without scripting or macros.

## Key Features
- Native macOS app built with Tauri and Rust for performance and lightweight operation
- Multi-agent orchestration with specialized agents (Desktop, Browser, File) for parallel task execution
- Voice control with local Whisper transcription supporting 99+ languages
- MCP integration for extending functionality with custom tools and APIs
- CLI tool (juno-cua) for AI coding agents to gain desktop automation capabilities

## Why It Matters for RAG Builders
Juno bridges the gap between AI agents and real-world desktop environments, enabling seamless automation of complex tasks for RAG builders seeking to integrate computer control into their workflows.
