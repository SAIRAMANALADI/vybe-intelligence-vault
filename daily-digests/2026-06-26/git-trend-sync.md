## Summary
git-trend-sync is a Windows desktop application that automatically discovers trending GitHub repositories and matches them to a user's local codebase. It helps developers stay updated on relevant tools, libraries, and AI projects without manual research.

## Key Features
- Automated discovery of trending GitHub repositories
- Codebase matching to identify relevant tools and libraries
- Customizable topic tracking (e.g., AI, RAG, MCP)
- Windows desktop application with simple setup
- Activity-based scoring for prioritizing matches
