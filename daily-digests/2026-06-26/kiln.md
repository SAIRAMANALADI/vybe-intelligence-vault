## Summary
Kiln is an open-source MCP server and CLI tool that enables AI agents to autonomously design, slice, and 3D print physical objects across a wide range of printers and slicers. It bridges natural language prompts to end-to-end 3D printing workflows, eliminating manual intervention.

## Key Features
- End-to-end AI-driven 3D printing from natural language prompts
- Supports 15+ printer types (Bambu, Prusa, Creality, Klipper, OctoPrint, etc.)
- 838 MCP capabilities and 224 CLI commands for agent interaction
- Autonomous design, slicing, queueing, monitoring, and failure recovery
- Cross-platform CLI and MCP server with zero-config setup for popular AI clients

## Why It Matters for RAG Builders
Kiln enables AI agents to autonomously execute complex 3D printing workflows, reducing manual effort and accelerating prototyping and manufacturing processes for RAG builders integrating physical output generation.
