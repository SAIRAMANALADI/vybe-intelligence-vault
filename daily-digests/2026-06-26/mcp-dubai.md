## Summary
MCP-Dubai is an MCP server providing AI agents with access to Dubai and UAE public data APIs (e.g., prayer times, exchange rates, school ratings) and curated business setup knowledge (e.g., free zone comparisons, visa recommendations, banking options). It bridges gaps in official APIs with anonymous and structured data sources.

## Key Features
- 108 tools across 33 features for Dubai/UAE public data and business setup guidance
- Curated business knowledge domains (e.g., free zones, visas, banking) with verified freshness dates
- Anonymous API integrations (e.g., prayer times, exchange rates, school ratings) requiring no credentials
- Structured response envelopes with source attribution and retrieval timestamps for traceability
- Tiered system (Tier 0: anonymous APIs, Tier 1: OAuth APIs, Tier 2: curated business knowledge)
