## Summary
open-brain-template is a visual dashboard for managing AI memory systems, enabling users to organize notes, links, and memory nodes in a structured brain map. It integrates with MCP-compatible AI tools and leverages Supabase for data storage and Vercel for hosting.

## Key Features
- Visual brain map for organizing AI memory nodes and connections
- MCP-compatible for seamless integration with AI tools
- Supabase-backed data storage for persistence and reuse
- Vercel-hosted deployment for web accessibility
- Clean, intuitive interface for tracking ideas and context
