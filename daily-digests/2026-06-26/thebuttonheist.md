## Summary
TheButtonHeist is an iOS automation framework that enables agents and tests to interact with apps using accessibility intent rather than screen coordinates, providing structured receipts of app state changes. It treats the app's accessibility contract as a live world model, enabling reliable and readable automation for both human and AI-driven testing.

## Key Features
- Semantic interaction via accessibility intent (activate, type, wait) instead of coordinates
- Structured receipts capturing before/after state changes and evidence
- Reusable heist plans for composable automation workflows
- Expectation-based validation tied to accessibility contracts
- Support for both human-authored and AI-generated automation plans

## Why It Matters for RAG Builders
It provides a reliable, intent-driven interface for AI agents to interact with iOS apps, eliminating the need for coordinate-based automation and enabling structured evidence collection for RAG systems.
