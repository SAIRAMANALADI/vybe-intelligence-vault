## Summary
Koza Agent is a terminal-based, extensible AI agent framework featuring 99+ tools across 25+ categories, dual memory systems, sub-agents, and cross-platform scheduling. It supports multi-LLM providers, a rich TUI, and integrations like Telegram, Discord, and WhatsApp.

## Key Features
- 99+ tools across 25+ skill categories for diverse task automation
- Dual memory system (working memory + permanent SQLite storage)
- Rich Textual-based TUI with setup wizard and Kanban board
- Sub-agent spawning for parallel task execution
- Multi-platform scheduling with cron/Task Scheduler integration

## Why It Matters for RAG Builders
