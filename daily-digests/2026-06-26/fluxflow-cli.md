## Summary
Flux Flow is an autonomous terminal AI agent built with Node.js and Ink, offering a React-based CLI interface for interactive and agentic workflows. It supports multi-model AI providers, IDE integration, and advanced features like file rollback, multimodal analysis, and document generation.

## Key Features
- Multi-provider AI engine support (Google, DeepSeek, OpenRouter, NVIDIA)
- VS Code extension for real-time error detection and fixes
- Transaction-based file rollback and version control
- Native multimodal analysis (images, PDFs)
- Autonomous project alignment with custom instructions
