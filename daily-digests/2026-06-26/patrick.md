## Summary
Patrick is an open-source, agent-first patent prosecution assistant that drafts and redlines office actions and claim amendments directly in Microsoft Word files as native tracked changes. It operates entirely on the user's local machine with no proprietary lock-in or external servers.

## Key Features
- Edits Word documents as native tracked changes with user approval
- Grounded in real legal sources (EPC, EPO Guidelines, case law) and prior art
- Fully transparent system with visible prompts, tool calls, and costs
- Supports multiple AI providers (Anthropic, OpenAI, Google) with user-provided keys
- In-document semantic search and claim charting for prior art analysis

## Why It Matters for RAG Builders
It provides a transparent, local-first agent framework for legal document editing and prior art analysis, reducing dependency on proprietary tools while ensuring compliance and control for patent professionals.
