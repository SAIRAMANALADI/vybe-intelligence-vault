## Summary
Godot-MCP is an AI-powered plugin that integrates the Godot game engine with the Model Context Protocol (MCP), enabling AI agents to inspect, modify, and automate Godot Editor operations such as scene editing, node management, and resource handling via natural language commands.

## Key Features
- 39 built-in MCP tools for Godot Editor operations (node, scene, resource, script management)
- Supports both C# and GDScript for script editing and execution
- Cloud or self-hosted MCP server connectivity via ai-game.dev or custom deployments
- Visual feedback capabilities (screenshots, viewport capture) for AI inspection
- CLI tooling (godot-cli) for seamless plugin installation and project setup

## Why It Matters for RAG Builders
It bridges AI agents with the Godot game engine, enabling automated game development workflows and reducing manual effort in scene and script management.
