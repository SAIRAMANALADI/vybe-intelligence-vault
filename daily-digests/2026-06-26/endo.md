## Summary
Endo is a cross-platform shell and scripting language that blends functional programming paradigms inspired by F# with traditional command-line interfaces. It enables structured pipelines with typed records, pattern matching, and type inference while maintaining compatibility with standard shell operations.

## Key Features
- Structured pipelines passing typed records instead of plain text
- F#-inspired functional programming with pattern matching and type inference
- Cross-platform compatibility (Linux, macOS, Windows) with native performance
- Explicit error handling via Result and Option types
- Context-aware tab completions informed by the type system
