## Summary
DecTell AI is a Windows desktop application that enables non-technical users to upload business datasets, clean and analyze data, build predictive models, test what-if scenarios, and query data in plain language to derive actionable insights for decision-making.

## Key Features
- One-click data cleaning and preprocessing
- Automated exploratory data analysis and trend identification
- Built-in machine learning for forecasting and predictions
- Interactive what-if scenario testing
- Plain language Q&A for querying datasets
