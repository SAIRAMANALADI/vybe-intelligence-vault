## Summary
A ComfyUI sidebar panel that integrates an autonomous AI agent (Claude or ChatGPT) to edit workflows, install custom nodes, and manage graph operations via natural language commands. Runs on the user's subscription without API keys.

## Key Features
- Live graph editing with undo/redo support via Ctrl+Z
- Multi-provider support (Claude or ChatGPT) with feature parity
- One-shot workflow loading and installer pack integration
- Cost-aware workflow execution with local-GPU vs. paid-API checks
- Autonomous custom node installation and ComfyUI restart handling

## Why It Matters for RAG Builders
It enables AI agents to directly manipulate and automate ComfyUI workflows using natural language, reducing manual setup and iteration time for RAG and AI pipeline builders.
