## Summary
The Apify MCP Server enables AI agents to dynamically interact with thousands of web scraping, automation, and data extraction tools from the Apify Store via the Model Context Protocol (MCP). It supports structured tool discovery, OAuth, and agentic payments for seamless integration with AI workflows.

## Key Features
- Dynamic discovery and integration of 8,000+ Apify Actors as MCP tools
- Supports OAuth and API token authentication for secure access
- Agentic payments via x402 (USDC) and Skyfire (PAY tokens) for frictionless transactions
- Compatible with major MCP clients like Claude, VS Code, and Cursor
- Provides structured input/output schemas for AI agent tool calls

## Why It Matters for RAG Builders
It bridges AI agents with thousands of pre-built web scraping and automation tools, enabling seamless data extraction and task automation within RAG pipelines.
