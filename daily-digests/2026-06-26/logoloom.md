## Summary
logoloom is a Windows desktop application that enables users to generate logos and brand kits locally using simple prompts. It exports clean SVG files and supports the creation of favicons, icons, and other brand assets without requiring cloud services or complex design tools.

## Key Features
- Generates logos from short prompts or brand names
- Exports clean SVG files for scalability
- Creates favicons, icons, and other brand assets
- Runs locally on Windows with MCP-native support
- Supports quick brand kit assembly from a single design

## Why It Matters for RAG Builders
