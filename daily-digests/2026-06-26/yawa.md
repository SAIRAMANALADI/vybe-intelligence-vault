## Summary
yawa is a self-hosted, privacy-focused web analytics platform that replaces traditional dashboards with an MCP (Model Context Protocol) server, enabling AI clients like Claude to query traffic data in natural language. It eliminates the need for cookie banners or GDPR consent while providing lightweight tracking and embedded DuckDB storage.

## Key Features
- Privacy-first analytics with no cookie banners or GDPR consent required
- MCP server for querying data via AI clients (e.g., Claude) in plain language
- Lightweight JavaScript tracker with optional Web Vitals collection
- Embedded DuckDB for efficient data storage and querying
- 26+ analytics tools for detailed traffic insights (pageviews, referrers, UTM campaigns, etc.)
