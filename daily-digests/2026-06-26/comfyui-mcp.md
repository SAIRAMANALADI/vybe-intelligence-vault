## Summary
A Claude Code plugin and MCP server for ComfyUI that enables AI agents to generate images, videos, and manage workflows, models, and custom nodes. It supports live graph editing, autonomous agents, and multi-provider compatibility (Claude and ChatGPT).

## Key Features
- 89 MCP tools for ComfyUI interaction, including workflow execution, model management, and node authoring
- 22 AI skills covering model-specific generation guides, troubleshooting, and node authoring for popular models (Flux, WAN, LTX 2.3, Qwen, etc.)
- Autonomous agents (e.g., comfy-explorer, comfy-debugger) for research, debugging, and optimization of ComfyUI workflows
- Panel agent for live graph editing and autonomous workflow execution directly in ComfyUI's sidebar (Claude or ChatGPT)
- 13 installer packs for one-command setup of custom nodes, models, and workflows

## Why It Matters for RAG Builders
It bridges AI agents with ComfyUI, enabling autonomous workflow generation, debugging, and execution for RAG and AI stack builders.
