## Summary
An MCP server that enables AI assistants (Cursor, Copilot, Claude, Cline) to interact with IBM Cloud Code Engine for building, pushing, and deploying containers using natural language. It abstracts Docker, Podman, and IBM Container Registry complexities for seamless AI-driven DevOps workflows.

## Key Features
- Enables AI assistants to autonomously deploy containers to IBM Code Engine without requiring Docker/Code Engine expertise
- Supports multi-step workflows (build → push → deploy) with automatic error correction and validation
- Integrates with IBM Container Registry for image management and pull secrets
- Provides VS Code extension and npm package for easy setup and local development
- Offers custom domain mapping with TLS certificate management for production deployments

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and cloud-native DevOps, allowing AI agents to autonomously manage container deployments on IBM Cloud Code Engine, reducing manual intervention and accelerating AI-driven application delivery.
