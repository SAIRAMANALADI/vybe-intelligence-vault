## Summary
NexoAgent is a local-first AI agent desktop application and web console that integrates conversation, multi-model orchestration, tool calling, persistent memory, local knowledge bases, skill systems, scheduled tasks, and channel integrations into a unified workspace for personal assistants, development collaboration, and team internal agent scenarios.

## Key Features
- Multi-session chat with persistent history and memory (SQLite + embedding retrieval)
- Support for multiple AI models (OpenAI/Anthropic compatible) with dynamic switching
- Built-in tool ecosystem (web search, HTTP requests, shell commands, file operations, multimodal tools)
- Local knowledge base management with Markdown file support and vector retrieval
- Unified desktop (Electron) and web console with shared backend and state

## Why It Matters for RAG Builders
NexoAgent provides a comprehensive, local-first agent framework that simplifies the integration of RAG pipelines, tool calling, and multi-model orchestration for AI builders seeking a unified workspace.
