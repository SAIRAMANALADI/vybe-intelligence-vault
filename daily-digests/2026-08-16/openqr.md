## Summary
OpenQR is a free, open-source QR code generator that runs entirely in the browser with no watermarks, tracking, or usage limits. It supports dynamic QR codes, a REST API, and an MCP server for programmatic access, while maintaining strict privacy by keeping all generation client-side.

## Key Features
- 100% client-side QR generation with no server calls (except optional map tiles)
- Supports multiple export formats: PNG, JPEG, WebP, SVG, and PDF up to 4096px
- Dynamic QR codes with scan analytics and editable destinations (via hosted API)
- Rich payload support: URLs, text, emails, Wi-Fi, SMS, WhatsApp, and location
- Embeddable React component with customizable branding and post-download actions

## Why It Matters for RAG Builders
OpenQR provides a privacy-focused, watermark-free alternative for generating and managing QR codes, which is essential for AI systems requiring clean, customizable, and client-side QR generation.
