## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Web Data Forms, allowing natural language operations like searching, creating, updating, and managing submissions and workflows within structured business data forms.

## Key Features
- Exposes 9 tools for CRUD operations on submissions and workflows via MCP
- Supports natural language queries for form data and workflows
- Stateless design with runtime credential passing for security
- Provides schema and sample submissions for form structure discovery
- Enables workflow status, priority, and assignee updates
