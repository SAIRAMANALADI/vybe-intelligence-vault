## Summary
Tact is a terminal interface for Nanocodex, providing a TUI-based agent orchestration tool with features like subagents, memory management, session forking, and review capabilities for AI-driven workflows.

## Key Features
- Subagents for parallel task execution and delegation
- Bounded cross-session memory with SQLite storage
- Session forking and resume capabilities for workflow continuity
- Browser-based review tool for workspace changes and agent feedback
- Customizable themes and configuration via TOML files

## Why It Matters for RAG Builders
