## Summary
A LangGraph-based multi-node agent that automates company analysis by converting a company name into a comprehensive report. It resolves the company to a stock ticker, fetches market data, gathers and re-ranks news articles using a BGE cross-encoder, drafts an analysis with an LLM, and exports the final report as a Word document.

## Key Features
- Multi-node LangGraph agent pipeline for end-to-end company analysis
- Automated stock ticker resolution using DART registry and fuzzy matching
- News article re-ranking with BGE cross-encoder to filter irrelevant content
- Supports both OpenAI and local Ollama LLMs for report generation
- Exports final analysis as a Word document for immediate use
