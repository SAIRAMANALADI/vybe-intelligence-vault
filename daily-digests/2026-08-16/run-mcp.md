## Summary
A thin MCP client that enables dynamic testing and interaction with Model Context Protocol (MCP) servers for both humans and AI agents. It provides REPL, headless CLI, and agent-driven modes to test, debug, and manage MCP servers without manual configuration or restarts.

## Key Features
- Dynamic MCP server testing without config edits or restarts
- Three interaction modes: Agent Server, Interactive REPL, and Headless CLI
- Automatic interception of large payloads (images, text) to disk
- Watch mode for auto-reconnect on file changes during development
- Agent tools for dynamic server spawning and inspection

## Why It Matters for RAG Builders
It streamlines MCP server testing and debugging for AI agents and developers, eliminating manual configuration and restarts while enabling dynamic interaction.
