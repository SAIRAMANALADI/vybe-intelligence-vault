## Summary
A Model Context Protocol (MCP) server offering advanced date, time, timezone, and calendar operations using Luxon. Designed for AI agents and applications requiring robust temporal data handling with MCP protocol support.

## Key Features
- Global IANA timezone support for all 400+ identifiers
- Comprehensive time calculations (add, subtract, diff, duration, stats)
- Multiple output formats (ISO, RFC2822, SQL, locale-aware, custom)
- Temporal Context Envelope for passive time-awareness in every response
- Token-optimized outputs for efficient AI agent interactions
