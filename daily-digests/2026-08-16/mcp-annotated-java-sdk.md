## Summary
A lightweight, annotation-driven SDK for building Model Context Protocol (MCP) servers in plain Java without requiring Spring. It simplifies MCP server development by generating low-level bindings from annotated Java methods, enabling rapid creation of MCP-compatible tools, resources, and prompts.

## Key Features
- Annotation-based MCP server development (no Spring required)
- Compile-time binding generation for MCP components
- Support for Resources, Tools, Prompts, and Completions
- STDIO and STREAMABLE server modes for flexibility
- Type-aware JSON schema generation from Java signatures

## Why It Matters for RAG Builders
It enables Java developers to quickly build and deploy MCP servers for AI applications without the overhead of Spring, accelerating RAG pipeline integration.
