## Summary
A local-first RAG platform for scientific documents supporting bilingual (Greek/English) Q&A with page-level citations, anti-hallucination mechanisms, and a rigorous evaluation framework. It emphasizes cross-lingual retrieval, reproducibility, and measurable performance metrics.

## Key Features
- Hybrid dense (bge-m3) and sparse (BM25) retrieval with Reciprocal Rank Fusion (RRF)
- Anti-hallucination relevance gate with calibrated thresholds for out-of-corpus refusal
- Cross-lingual Q&A with Greek-to-English translation for retrieval and answer generation
- Built-in evaluation framework with LLM-as-judge, RAGAS, and deterministic metrics
- Page-level expansion for context-aware generation with source citations

## Why It Matters for RAG Builders
It provides a robust, locally deployable RAG stack with rigorous anti-hallucination safeguards and cross-lingual capabilities, essential for building trustworthy AI systems handling scientific documents.
