## Summary
An AI-agent backend designed for autonomous job discovery with explainable decisions and production-grade operations. It provides a deterministic decision engine with rationale traces, durable event logging, and configurable LLM enrichment for job search automation.

## Key Features
- Deterministic decision engine with rationale traces for explainable job recommendations
- Durable event logging and state-machine run lifecycle for debugging and replay
- Configurable LLM enrichment with support for multiple providers (Gemini, Kimi, Claude, GPT)
- Tool/adapters abstraction for seamless integration with job sources (Greenhouse, Lever, Workable, etc.)
- Safety controls including timeouts, bounded scope, and graceful fallback during API outages

## Why It Matters for RAG Builders
It provides a robust framework for building autonomous AI agents that require explainable decisions, durable operations, and multi-provider LLM integration, critical for production-grade RAG systems.
