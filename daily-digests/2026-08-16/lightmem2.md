## Summary
LightMem2 is a modular framework designed for long-running LLM agent memory and context management, reducing context growth and serving costs in shared-session workloads. It achieves significant token and cost reductions compared to vanilla setups.

## Key Features
- TokenPilot component for stabilizing reusable prompt prefixes and trimming oversized tool outputs
- Supports multiple LLM hosts (OpenClaw, Codex, Claude Code) with host-specific adapters
- Provides visual inspectors and runtime reports for monitoring memory and context usage
- Achieves up to 95.7% fewer input tokens and 87.0% lower costs in benchmark tests
- Modular architecture with reusable packages for host-agnostic runtime logic

## Why It Matters for RAG Builders
LightMem2 directly addresses the critical challenge of context bloat in long-running LLM agents, enabling more efficient and cost-effective RAG deployments by optimizing memory usage and reducing token consumption.
