## Summary
Munin is a threat intelligence and red teaming orchestration platform built on the Model Context Protocol (MCP), designed for autonomous agent coordination, dynamic tool generation, and persistent memory management in security operations.

## Key Features
- ReAct-based autonomous agent with multi-step reasoning and self-diagnostics
- Durable persistence with SQLite/Turso for semantic and episodic memory
- Dynamic tool and subagent generation via tool_forge and graph_forge
- Human-in-the-loop (HITL) security circuits for controlled operations
- Integration with Hugin (RAG system) for cybersecurity knowledge graphs

## Why It Matters for RAG Builders
Munin provides a robust framework for autonomous security operations, enabling AI-driven threat intelligence and red teaming with persistent memory, dynamic tooling, and strict governance for safe deployment.
