## Summary
A specialized agent harness for writing, editing, and translating long-form fiction using Git-backed workspaces, immutable edit proposals, and author-controlled review workflows. It adapts coding agent principles like scoped tasks, controlled context, and validation to novel writing while maintaining clear separation between analysis and edits.

## Key Features
- Git-friendly novel workspaces with durable passage references and stable IDs
- Immutable, content-addressed edit proposals with source preconditions and preservation receipts
- Task-aware context packets with explicit focus, dependency, and temporal boundaries
- Writer Harness Bench for deterministic reliability gates, paired comparisons, and confidence intervals
- Explicit author authority with staged review and approval workflows before Git commits
