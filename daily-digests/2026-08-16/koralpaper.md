## Summary
KoralPaper is a free, offline sketch studio that enables hand-drawn diagrams, sticky-note boards, charts, and stop-motion animations directly in the browser. It integrates with Claude Desktop for AI-assisted drawing and runs as a PWA with zero dependencies.

## Key Features
- Hand-drawn vector diagrams and sketches with a wobbly, organic aesthetic
- Integration with Claude Desktop for AI-assisted drawing and editing via MCP
- Support for 8 hand-drawn chart types, tables, and data visualization from pasted spreadsheets
- Brand kit for consistent styling across documents and AI-generated content
- Time-lapse studio for stop-motion animations and frame-by-frame recording

## Why It Matters for RAG Builders
KoralPaper provides a lightweight, offline-capable UI for creating and iterating on visual content, including AI-assisted diagrams, making it essential for RAG builders who need to generate or refine visual assets alongside text.
