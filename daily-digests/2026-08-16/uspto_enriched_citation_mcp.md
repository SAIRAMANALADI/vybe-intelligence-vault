## Summary
A high-performance Model Context Protocol (MCP) server providing access to USPTO patent citation APIs, including Enriched Citations v3 (AI-extracted passage locations) and Office Action Citations v2 (raw Form 892/1449 data). It enables token-saving context reduction, progressive disclosure workflows, and seamless cross-MCP integration for patent lifecycle analysis.

## Key Features
- Dual USPTO citation APIs (Enriched v3 and OA v2) with 90-95% token reduction
- Progressive disclosure workflows for efficient data retrieval
- Interactive MCP Apps UI panels for citation results and statistics
- Cross-MCP integration for complete patent lifecycle analysis
- Secure API key management with Windows DPAPI encryption

It provides essential patent citation data with AI-enhanced context for RAG systems, enabling accurate prior art analysis and patentability research.
