## Summary
Altium Copilot integrates Claude AI with Altium Designer to provide real-time, read-only access to hardware design files, enabling engineers to query schematics and PCB layouts directly from their chat interface without manual data extraction.

## Key Features
- Real-time read access to Altium projects via Claude AI, enabling natural language queries about schematics and PCB layouts
- Automated net tracing, component analysis, and variant comparisons with structured responses
- Specialist modes for schematic reviews and circuit brainstorming with multi-phase audits
- PCB awareness for routing analysis, crosstalk detection, and stackup inspection
- Project packaging for cross-functional team sharing without requiring Altium licenses

## Why It Matters for RAG Builders
It bridges the gap between hardware design tools and AI assistants, enabling seamless, context-aware queries for hardware engineers without manual data extraction.
