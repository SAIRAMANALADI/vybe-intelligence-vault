## Summary
NavisHelper is a Navisworks Manage plugin and local MCP server designed for BIM coordinators and design engineers. It enables advanced model search, selection, visibility control, viewpoint management, property export, and Clash Detective workflows through 100 registered MCP tools.

## Key Features
- 100 registered MCP tools for model manipulation and analysis
- Advanced model search by name, properties, bounding box, or hierarchy
- Visibility control, viewpoints, and selection set management
- Property export to CSV/XLSX/JSONL formats
- Clash Detective workflows with test listing, isolation, and reporting

## Why It Matters for RAG Builders
It provides a powerful MCP-based interface to integrate Navisworks with AI workflows for BIM coordination and model analysis, enabling automated and interactive model manipulation.
