## Summary
A production-ready, microservices-based RAG system that converts Obsidian markdown vaults into an interactive API using Google Gemini 2.5 and serverless vector databases. The system decouples data ingestion, retrieval, and generation into scalable components.

## Key Features
- Decoupled architecture separating ingestion, retrieval, and generation layers
- Integration with Google Gemini 2.5 for advanced LLM capabilities
- Serverless vector database support (Qdrant/ChromaDB)
- Authentication middleware for secure API access
- Interactive UI with Reflex for real-time chat with notes

## Why It Matters for RAG Builders
It provides a scalable, modular framework for integrating Obsidian vaults into RAG pipelines, enabling seamless knowledge retrieval and generation with enterprise-grade architecture.
