## Summary
A Model Context Protocol (MCP) server that provides real-time local system statistics, including CPU, RAM, disk, network, GPU, and process monitoring. Designed to integrate with LLM assistants for enhanced system awareness and diagnostics.

## Key Features
- Real-time CPU, RAM, disk, and network monitoring with per-core and per-interface granularity
- GPU and thermal metrics with cross-platform support (Windows, macOS, Linux)
- Task Manager-style process aggregation and health diagnostics
- 100% TypeScript with Vitest for robust testing and CI/CD integration
- Seamless integration with MCP-compatible clients like Claude, Cursor, and VS Code

## Why It Matters for RAG Builders
It enables LLM assistants to access real-time system metrics for better decision-making, debugging, and performance optimization in AI workflows.
