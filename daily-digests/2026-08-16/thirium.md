## Summary
Thirium is a local AI agent with a graphical user interface designed for programming tasks, including file editing, shell and git operations, and integration with MCP, plugins, and services like GitHub, GitLab, Jira, and Linear. It supports both local models via Ollama and cloud APIs without subscriptions or tracking.

## Key Features
- Supports both local (Ollama) and cloud-based AI models (OpenAI, Anthropic, Gemini, etc.) without subscriptions or tracking
- Integrates with file systems, shell, git, and external services (GitHub, GitLab, Jira, Linear) for code operations
- Features a CLI tool (viper) for terminal-based interactions and automation, including batch processing and self-improvement
- Provides drag-and-drop and keyboard shortcuts for file attachments, web page reading, and screenshot capture for context
- Includes sub-agent delegation for tasks like code review, refactoring, testing, and project exploration with a visible self-improve queue

## Why It Matters for RAG Builders
Thirium provides a versatile, local-first AI agent framework that simplifies integrating advanced AI capabilities into programming workflows without vendor lock-in or privacy concerns.
