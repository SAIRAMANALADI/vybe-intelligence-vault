## Summary
A Model Context Protocol (MCP) server enabling AI agents to interact with PulseChain, including market research, smart contract operations, and encrypted agent wallets for token transactions. Designed to integrate seamlessly with AI applications like Cursor or Claude.

## Key Features
- Enables AI agents to perform PulseChain data research and market analysis
- Supports smart contract reviews and creation via agent interaction
- Facilitates swap quotes, prices, and executions on PulseX/Piteas
- Provides encrypted agent wallets for secure token transactions
- Includes research-only mode to prevent unintended transactions

## Why It Matters for RAG Builders
It empowers AI agents to autonomously interact with PulseChain ecosystems, enabling real-world DeFi operations while maintaining security through encrypted wallets and research-only modes.
