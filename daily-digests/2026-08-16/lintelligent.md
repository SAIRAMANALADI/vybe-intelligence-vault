## Summary
LINTelligent is an AI-integrated backend service for code linting that analyzes code snippets or GitHub files for issues using an LLM provider. It supports asynchronous processing, webhook notifications, and provides an MCP server for AI-agent integration.

## Key Features
- Asynchronous code review processing with background job queue (Hangfire)
- Support for direct code snippets or GitHub file URLs as input
- MCP server for seamless AI-agent integration (e.g., Claude Desktop)
- Webhook notifications for review completion
- Clean Architecture with Adapter pattern for LLM provider abstraction

## Why It Matters for RAG Builders
LINTelligent streamlines AI-driven code review workflows by enabling agents to autonomously submit and retrieve linting results, reducing manual intervention in RAG pipelines.
