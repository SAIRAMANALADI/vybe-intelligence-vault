## Summary
A Model Context Protocol (MCP) server that generates OpenAPI/Swagger specifications from natural language API descriptions. It supports REST endpoint generation, schema creation, and full API specification assembly, with built-in EU AI Act compliance features.

## Key Features
- Generates OpenAPI/Swagger specs from natural language descriptions
- Supports REST endpoint, schema, and full spec generation
- MCP protocol compliant for seamless integration with AI assistants
- Built-in EU AI Act compliance with risk management and transparency features
- HMAC-signed attestations for verifiable compliance reports

## Why It Matters for RAG Builders
It automates the creation of OpenAPI specs from natural language, reducing manual effort in documenting APIs for RAG pipelines and ensuring compliance with regulatory frameworks like the EU AI Act.
