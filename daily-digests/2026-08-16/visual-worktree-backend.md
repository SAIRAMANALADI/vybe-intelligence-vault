## Summary
A FastAPI backend service for the Visual Worktree AI intelligent assistant, enabling model interactions via LangChain's ChatOpenAI and Deep Agents. It provides chat interfaces, health checks, and model configuration with OpenAI API compatibility.

## Key Features
- FastAPI-based backend with health check and chat endpoints
- Integration with LangChain's ChatOpenAI and Deep Agents for model calls
- Support for OpenAI API and compatible endpoints via configurable base URL
- LangSmith tracing for observability of model calls and tool execution
- Secure runtime model configuration via Electron client with encrypted storage
