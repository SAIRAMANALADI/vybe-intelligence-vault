## Summary
Animus is an AI-controllable Minecraft bot with a modular architecture that separates the 'body' (Mineflayer-based bot) from the 'brain' (local LLM or remote API-driven controller). It enables autonomous or interactive gameplay, including building, movement, and task execution via HTTP API or in-game commands.

## Key Features
- Swappable AI brains (local LLM or remote API like Claude) for flexible control
- HTTP-based control API for remote command execution and state monitoring
- In-game command interface for operators with allowlist-based access control
- Supports both Java and Bedrock Minecraft servers with distinct body implementations
- Autonomous building and task execution using local models (Ollama/llama.cpp)

## Why It Matters for RAG Builders
It provides a modular framework for integrating AI agents with Minecraft, enabling autonomous or interactive gameplay that can be extended to other game environments or real-world robotic control systems.
