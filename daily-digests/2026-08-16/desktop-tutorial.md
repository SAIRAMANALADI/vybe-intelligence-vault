## Summary
C3MR is an integrated operational management system designed for field collection operations, featuring a React-based web admin portal, a Telegram Mini App for field officers, and an AI assistant with 14 tools. It replaces manual spreadsheet-based workflows with automated assignment, real-time tracking, and AI-driven insights.

## Key Features
- Unified data management with a single source of truth via PostgreSQL
- AI-powered assistant with 14 typed tools for operational queries and task assignment
- Telegram Mini App for field officers to avoid app installation barriers
- Automated weekly reports and real-time progress visibility for managers
- Role-based access control (RBAC) and JWT authentication with security best practices
