## Summary
BIT is a privacy-first Android AI assistant that runs large language models, vision models, image generation, document retrieval, and speech synthesis entirely on-device without cloud dependency. It leverages the llama.kt SDK, a Kotlin-native wrapper for GGUF model inference, to enable local AI capabilities on Android 10+ devices.

## Key Features
- Runs GGUF models locally with llama.kt SDK for text and vision tasks
- Supports RAG with hybrid vector and BM25 retrieval for documents
- On-device image generation using Stable Diffusion 1.5
- Structured tool calling with grammar-constrained decoding (GBNF)
- Long-term memory with episodic storage and configurable decay

## Why It Matters for RAG Builders
BIT provides a complete, privacy-preserving on-device AI stack for Android, enabling developers to build agentic applications without cloud dependencies or data exposure.
