## Summary
PlexMCP is an open Model Context Protocol (MCP) server for Plex Media Server, enabling AI agents to interact with media libraries via natural language. It includes a Tauri-based desktop app and an optional web interface for browsing, search, and chat.

## Key Features
- Model Context Protocol (MCP) server for Plex Media Server integration
- Tauri-based desktop app with embedded Python backend for easy deployment
- Optional glass-style web app for browsing, search, and chat
- Supports LanceDB for vector-based semantic search and RAG
- Comprehensive documentation and quick-start guides for developers

## Why It Matters for RAG Builders
PlexMCP enables AI agents to seamlessly interact with Plex Media Server libraries, unlocking natural language access to media metadata and content for RAG applications.
