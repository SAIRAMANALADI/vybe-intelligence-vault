## Summary
gospect-mcp is a Go-only, report-first code scanner exposed as an MCP server that indexes Go modules, runs deterministic analyzers, and reports genuine bugs, dead code, stale docs, and outdated APIs without modifying code. It acts as a non-invasive diagnostic tool for Go projects.

## Key Features
- Non-invasive code scanning with no modifications to source files
- Deterministic analyzers for bugs, dead code, and outdated APIs
- Multi-module monorepo support with nested go.mod discovery
- Integration with MCP clients for AI agent workflows
- Baseline mode for tracking new findings in existing codebases

## Why It Matters for RAG Builders
It provides a reliable, report-first static analysis tool for Go projects that integrates seamlessly with AI agents via MCP, enabling automated code quality checks without altering source code.
