## Summary
ateam-mcp is an MCP server that enables AI assistants (ChatGPT, Claude, etc.) to build, validate, and deploy multi-agent systems directly to the ADAS platform. It abstracts complex platform interactions into natural language commands, eliminating manual configuration and context switching for developers.

## Key Features
- 12 MCP tools for spec retrieval, validation, deployment, and management of multi-agent systems
- Seamless integration with AI assistants (ChatGPT, Claude, Cursor, Windsurf, etc.) via MCP protocol
- Automated validation pipeline for skills and solutions before deployment
- Incremental updates and redeployment capabilities for existing systems
- Remote HTTP endpoint for cross-platform compatibility with MCP clients
