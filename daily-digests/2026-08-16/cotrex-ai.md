## Summary
Cotrex AI is a protocol-first AI runtime designed as the execution layer for the Cotrex agent OS. It abstracts AI inference providers behind a stable, typed protocol and provides an orchestration pipeline to convert capability requests into model inference, ensuring models are replaceable while the protocol remains consistent.

## Key Features
- Stable, typed protocol for AI inference abstraction
- Modular provider system with support for llama.cpp, mock, and JSON fixtures
- Event-sourced kernel with projections for workspace state and context
- Orchestration pipeline for context assembly, prompt generation, and response parsing
- Cross-platform packaging and distribution with GitHub Releases

## Why It Matters for RAG Builders
Cotrex AI provides a standardized, protocol-driven approach to AI inference orchestration, enabling seamless integration and replacement of models while maintaining consistency in agent-based workflows.
