## Summary
A Model Context Protocol (MCP) server that enables AI agents to control Copper Mountain Vector Network Analyzers (VNAs) via TCP/IP SCPI. Exposes 45 tools for sweep configuration, calibration, measurement, and export, bridging hardware automation with AI-driven workflows.

## Key Features
- 45 MCP tools for VNA control (sweep, calibration, measurement, export)
- Direct TCP/IP SCPI communication with Copper Mountain VNAs (no VISA dependency)
- Supports RVNA, TRVNA, S2VNA, and S4VNA families with structured data output
- Pre-configured measurement templates for common RF test scenarios (antennas, filters, cables)
- AGPL-3.0 licensed, part of the eng-mcp-suite ecosystem for RF/EMC engineering
