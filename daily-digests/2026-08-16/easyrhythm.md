## Summary
EasyRhythm is an enterprise-grade intelligent customer service system built on multi-agent orchestration, integrating LLM guardrails, streaming responses, and CRM integration patterns. It automates customer query routing, intent classification, and entity extraction for domains like flight bookings and refunds.

## Key Features
- Multi-agent orchestration with specialized agents (flight, booking, FAQ, refunds) for domain-specific query handling
- Hybrid intent classification engine with confidence scoring and fallback mechanisms for robust NLU
- Entity extraction pipeline combining regex and LLM for structured data extraction (flight numbers, seats, dates)
- Real-time streaming responses via SSE with LLM guardrails for safety and relevance checks
- CRM integration patterns and enterprise-grade quality gates for production readiness
