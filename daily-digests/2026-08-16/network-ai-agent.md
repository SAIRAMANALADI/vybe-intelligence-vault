## Summary
An AI-driven Network Operations Center (NOC) automation platform that simulates real-time network incident detection and automated remediation using FastAPI, Streamlit, and Jinja2 templating. It ingests syslog webhooks, parses diagnostic data via regex, and enforces human-in-the-loop approval for high-risk network changes.

## Key Features
- Webhook-based syslog alert ingestion for real-time incident detection
- Dynamic regex parsing and Jinja2 templating for vendor-specific CLI remediation scripts
- Human-in-the-Loop (HITL) approval workflow for high-risk network changes
- Asynchronous task execution with auto-refreshing Streamlit UI for status updates
- Database purge API for resetting test state and clearing historical data

## Why It Matters for RAG Builders
