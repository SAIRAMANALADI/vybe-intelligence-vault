## Summary
A multilingual agent skill pack that transforms AI agents into guided learning coaches by creating structured learning repositories for any subject. It enables interactive, day-by-day learning sessions directly in the chat, with built-in systems for exercises, reviews, and progress tracking.

## Key Features
- Creates structured learning repositories for any subject with Day 1 starting in the chat
- Five integrated learning systems: Knowledge Map, Glossary, Exercise, Project, and Review
- Material-grounded learning mode for building plans from PDFs, PPTs, or notes
- Knowledge Reliability Layer to reduce hallucinations and track source verification
- Multi-platform support with adapters for Codex, Claude Code, Coze, and others

## Why It Matters for RAG Builders
It provides a reusable framework for AI agents to deliver structured, interactive, and verifiable learning experiences, reducing the need for manual prompt engineering and improving knowledge retention for RAG systems.
