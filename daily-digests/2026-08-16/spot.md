## Summary
Spot automates restaurant reservation bookings across multiple platforms (SevenRooms, Resy, Tock, OpenTable, etc.) using browser automation and plain-language requests. It also integrates with Voyage to create Travel Context entries for confirmed bookings.

## Key Features
- Multi-platform reservation handling (SevenRooms, Resy, Tock, OpenTable, etc.)
- Plain-language request processing for bookings
- Automatic Travel Context entry in Voyage for confirmed reservations
- Venue discovery powered by Yelp
- Watchlist monitoring with background sweeps every 15 minutes

## Why It Matters for RAG Builders
Spot streamlines restaurant reservation automation for AI agents, reducing manual intervention and enabling seamless integration with travel planning systems like Voyage.
