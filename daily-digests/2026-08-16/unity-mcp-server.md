## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Unity projects without requiring the Unity Editor. It provides structured access to project metadata, scenes, scripts, assets, and configurations via MCP-compatible IDEs or applications.

## Key Features
- Provides 101+ MCP tools for querying Unity project metadata, scenes, scripts, assets, and configurations without opening the Unity Editor
- Supports any MCP-capable IDE or application (Cursor, Claude, VS Code, etc.) via stdio protocol
- Enables AI assistants to programmatically analyze and interact with Unity projects
- Includes tools for project settings, build configurations, asset management, and scene analysis
- Lightweight and editor-free, relying solely on project filesystem access

## Why It Matters for RAG Builders
It bridges AI assistants with Unity projects, enabling automated analysis, code generation, and project management without requiring the Unity Editor.
