## Summary
HoloCore Context Engine is a local-first AI knowledge system that integrates a shared Markdown Archive, project-local structural Atlas, and episodic Animus memory into a unified CLI and MCP server. It provides focused context to AI assistants to reduce input tokens while maintaining project-specific knowledge organization.

## Key Features
- Shared Archive for verified knowledge across projects
- Project-local Atlas for structural mapping and dependency tracking
- Episodic Animus memory for historical context and recall
- Automated memory capture hooks for AI clients (Claude Code, Codex, etc.)
- CLI and MCP server for seamless AI assistant integration
