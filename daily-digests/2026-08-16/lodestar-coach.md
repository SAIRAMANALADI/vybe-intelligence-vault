## Summary
Lodestar is an evidence-grounded, agentic AI health and training coach that combines grounded RAG with cited answers, real-time tools, and a CI-gated evaluation harness to ensure quality and safety. It integrates hybrid retrieval, long-term memory, and safety guardrails into a production-ready application with observability and cost controls.

## Key Features
- Hybrid retrieval (vector + keyword) with Reciprocal Rank Fusion for grounded answers with citations
- Agentic tools via Gemini function calling for logging workouts, nutrition, and computing personalized energy targets with safety clamps
- CI-gated evaluation harness using a golden dataset and LLM-as-judge to enforce quality thresholds
- Long-term memory integration for personalized and consistent user interactions across sessions
- Production-grade observability with tracing, metrics dashboard, caching, and rate limiting
