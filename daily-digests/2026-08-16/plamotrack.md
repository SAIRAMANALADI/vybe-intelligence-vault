## Summary
plamotrack is a self-hosted collection and build tracker for Gunpla (Gundam plastic models) and related hobby supplies. It provides a Kanban-style pipeline for managing kit statuses, order tracking, inventory management, and an MCP server for voice or AI-driven updates.

## Key Features
- Drag-and-drop Kanban board for tracking kit statuses (pre-ordered to complete)
- Order tracking with automatic kit creation and stock updates upon receipt
- Inventory management for tools, consumables, and upgrades with low-stock alerts
- Embedded MCP server for AI/agent-driven updates via natural language
- CSV import/export for data portability and backups

## Why It Matters for RAG Builders
It provides a specialized, self-hosted tool for tracking hobby projects and supplies, enabling AI agents to manage inventory and updates via MCP, which is valuable for hobbyists and developers building AI-driven workflows.
