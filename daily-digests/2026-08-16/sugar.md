## Summary
Sugar is a local-first persistent memory layer for AI coding agents, enabling cross-session and cross-project context retention. It provides project-specific and global memory stores with semantic search, MCP integration, and optional autonomous task execution.

## Key Features
- Project and global memory stores with SQLite backend for offline use
- Semantic search via sentence-transformers with fallback to keyword search
- MCP integration for direct memory access by AI agents (Claude Code, OpenCode, Goose)
- Optional autonomous task queue for issue resolution and feature implementation
- Seven memory types with time-to-live (TTL) policies for dynamic knowledge management

## Why It Matters for RAG Builders
Sugar eliminates AI agent amnesia by providing persistent, project-specific and global context storage, enabling more coherent and efficient coding assistance across sessions and projects.
