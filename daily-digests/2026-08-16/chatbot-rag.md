## Summary
A self-hosted, multi-tenant RAG chatbot platform designed for enterprise SaaS operations, enabling tenant-scoped document ingestion, stateless chat, and OpenAI-compatible APIs with hybrid retrieval and usage tracking.

## Key Features
- Multi-tenant data isolation with tenant-scoped documents, API keys, and usage tracking
- Hybrid retrieval pipeline combining dense (BGE-M3) and sparse (BM25) search with Qdrant
- Stateless chat architecture for scalability, with frontend-managed transcripts
- OpenAI-compatible public API for seamless tenant application integration
- Comprehensive admin console for tenant management, document operations, and usage analytics

## Why It Matters for RAG Builders
This platform provides a production-ready, multi-tenant RAG foundation with enterprise-grade retrieval, scalability, and operational visibility, essential for building robust AI-powered SaaS applications.
