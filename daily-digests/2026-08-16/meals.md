## Summary
A meal planning application with a recipe library, aisle-sorted shopping list, and AI-friendly API layer. It supports multi-user households, offline-first mobile access, and integrates with external AI assistants via MCP and REST APIs.

## Key Features
- AI-friendly REST API and MCP server with 21 task-level tools for external AI assistants
- Recipe library with URL ingestion, manual entry, and AI-assisted parsing for unstructured data
- Aisle-sorted shopping list with provenance tracking, merging, and offline-first mobile support
- Multi-user household model with invite-based permissions and per-user API tokens
- Offline-capable iOS app with instant interactions and sync-on-connect functionality
