## Summary
DeepseekNova is a native AI programming agent with a terminal-first design, achieving 94% cache hit rates. It features a modular Rust-based framework with multi-step reasoning, built-in tools, and a Tauri-powered desktop UI for seamless AI-assisted development workflows.

## Key Features
- Four-layer memory system (MemoryStore, SkillManager, UserProfile, RecallEngine) for cross-session context retention
- Six built-in skills (frontend-developer, coding-copilot, loop-engineering, etc.) with Plan/Act/YOLO execution modes
- Sandboxed execution with security isolation and real-time token tracking
- Project artifact generation (Wiki, knowledge cards, memory distillation)
- Dual display modes (icon/text) and three theme options (light/dark/system)
