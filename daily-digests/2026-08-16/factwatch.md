## Summary
FactWatch is an open-source fact-checking platform where humans curate claims and an AI agent powered by Google Gemini periodically re-verifies them using Google Search. The system logs all reasoning steps publicly and updates verdicts automatically via GitHub Actions.

## Key Features
- Human-AI collaborative fact-checking with public reasoning logs
- Automated daily re-verification of claims using Google Gemini and Search
- Transparent observatory tracking all agent runs and verdicts
- GitHub-based workflow for seamless integration and deployment
- Supports multiple verdict types (TRUE, FALSE, MISLEADING, etc.) with confidence scoring

## Why It Matters for RAG Builders
FactWatch provides a transparent, automated system for maintaining up-to-date fact-checking datasets, which is critical for RAG builders needing reliable, verifiable sources.
