## Summary
Wikimate is a Claude Code plugin and MCP server that organizes scattered materials (web links, PDFs, chat logs, text) into Obsidian vaults as notes, with optional Notion indexing. It automates note creation, deduplication, health checks, and retrieval via natural language commands.

## Key Features
- Automated note organization in Obsidian vaults via natural language commands (e.g., '정리해줘')
- Dry-run planning with human approval before execution to prevent unintended changes
- Automatic detection and indexing of Obsidian vaults for seamless integration
- Vault health diagnostics (duplicate detection, broken links, orphaned notes) with safe fixes
- Optional Notion indexing for bidirectional or unidirectional cross-referencing

## Why It Matters for RAG Builders
Wikimate streamlines the ingestion and structuring of unstructured data into knowledge bases, critical for RAG pipelines that rely on clean, linked, and deduplicated notes for accurate retrieval and context.
