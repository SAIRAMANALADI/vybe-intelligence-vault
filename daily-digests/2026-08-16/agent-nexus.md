## Summary
Agent Nexus is a self-hosted, model-agnostic AI agent orchestration platform that enables users to build, run, and observe AI agents backed by any LLM (Anthropic, OpenAI, Gemini, Ollama). It supports multi-agent workflows, MCP server integration, vector memory with RAG, and full observability with run traces.

## Key Features
- Model-agnostic agent builder with configurable tools, memory, and guardrails
- Multi-agent workflows with visual canvas editor and crash-resumable runs
- Vector memory with layered scopes, approval gates, and connector-based RAG (GitHub, Confluence, Filesystem)
- Agentic RAG for dynamic context retrieval during agent execution
- Full observability with run traces, cost tracking, and usage dashboards

## Why It Matters for RAG Builders
Agent Nexus provides a comprehensive, self-hosted platform for building and orchestrating AI agents with advanced RAG capabilities, making it essential for developers who need full control over agent behavior, memory, and workflows without vendor lock-in.
