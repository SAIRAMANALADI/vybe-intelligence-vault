## Summary
A specialized AI learning platform for university-level mathematics featuring an AI problem-solving assistant with multi-modal input (image, voice, text) and a RAG-powered knowledge base for Q&A. It supports symbolic computation, guided teaching, and personalized learning tracking.

## Key Features
- Multi-modal problem solving: image recognition, voice input, and text-based queries
- Symbolic computation with SymPy for precise mathematical solutions without floating-point errors
- Socratic teaching mode to guide users through problem-solving steps
- RAG-powered knowledge base with semantic search and citation-backed answers
- Personalized learning features including a mistake notebook and learning profile
