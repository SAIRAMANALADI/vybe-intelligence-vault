## Summary
Speko Calls is a demo repository showcasing how developers can integrate real outbound phone calls into AI agents using the Speko platform. It demonstrates secure, disclosed AI-to-human calls with built-in safety rails, business line verification, and rate limiting.

## Key Features
- Secure outbound call placement via MCP with disclosed AI identity
- Business line verification and safety enforcement server-side
- Modular architecture separating MCP server (no secrets) from backing API (holds keys)
- Pre-call readiness checks and post-call outcome reporting
- CLI and programmatic interfaces for call initiation and management

## Why It Matters for RAG Builders
It provides a practical blueprint for securely integrating real-world telephony into AI agents while enforcing critical safety and compliance measures.
