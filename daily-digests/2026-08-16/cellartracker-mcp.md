## Summary
A Model Context Protocol (MCP) server that connects AI assistants like Claude to CellarTracker, enabling natural language queries of wine inventory, drinking recommendations, purchase history, and tasting notes directly from a user's CellarTracker account.

## Key Features
- Direct integration with CellarTracker via CSV export endpoint for real-time data access
- Supports both Desktop Extension (.mcpb) and Claude Code Plugin for flexible deployment
- Provides 11 tools for querying inventory, recommendations, stats, and tasting notes
- Includes skills for AI interpretation of wine data and purchase evaluation frameworks
- Auto-refreshes data every 24 hours and supports manual refresh for up-to-date insights

## Why It Matters for RAG Builders
It enables AI assistants to interact with personal wine cellar data through natural language, simplifying inventory management and decision-making for wine enthusiasts.
