## Summary
Symbiosis Brain provides persistent, local memory for Claude Code using a markdown-based vault system. It enables AI agents to retain project-specific context, decisions, and knowledge across sessions without relying on cloud APIs or invasive modifications.

## Key Features
- Persistent, git-trackable markdown vault for storing project context and decisions
- Hybrid search (FTS5 + vector) for efficient local retrieval without API dependencies
- Bi-temporal knowledge management with `valid_from`/`valid_to` timestamps to prevent stale data
- Automated hooks and skills that integrate memory recall and saving into Claude Code's lifecycle
- Tool routing and MCP server for seamless integration with existing workflows

## Why It Matters for RAG Builders
It enables AI agents like Claude Code to retain and recall project-specific context across sessions without cloud dependencies, reducing manual re-explanation and improving productivity.
