## Summary
AIDA is a production-ready AI-driven business intelligence dashboard and conversational analyst for grocery retail, combining a modern UI, XGBoost demand forecasting, and Google Gemini API integration to provide actionable insights and supply chain optimization recommendations.

## Key Features
- Interactive Glassmorphism UI with real-time KPI tracking and theme switching
- XGBoost-based demand forecasting with R² score of 0.72 for inventory planning
- Gemini API-powered conversational assistant with automatic function calling and local fallback
- Modular database interface supporting SQLite and MongoDB with factory pattern
- PDF/CSV report generation for structured analytics and inventory insights

## Why It Matters for RAG Builders
It provides a turnkey solution for grocery retailers to leverage AI-driven insights and automation, reducing manual analysis overhead while improving decision-making through predictive analytics and conversational interfaces.
