## Summary
Oh My Claudian is an Obsidian plugin that integrates coding agents directly into the Obsidian vault, enabling multi-step workflows, file operations, and inline edits. It extends the base Claudian plugin with Oh My Pi (OMP) support via ACP for model discovery and selection.

## Key Features
- Sidebar chat with conversation history and multiple tabs
- Inline edits with word-level diff preview
- Support for multiple AI providers (Claude, Codex, Grok, OMP, OpenCode, Pi)
- ACP-backed Oh My Pi (OMP) integration for model discovery and selection
- MCP support for enhanced agent capabilities

## Why It Matters for RAG Builders
It bridges Obsidian's note-taking environment with AI coding agents, enabling seamless integration of AI-driven workflows directly within a knowledge vault.
