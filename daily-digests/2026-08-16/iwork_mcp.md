## Summary
iwork-mcp is an MCP server that enables AI assistants like Claude to automate Apple iWork applications (Numbers, Pages, Keynote) via JavaScript for Automation (JXA). It provides 117 tools for document creation, editing, and export, bridging AI workflows with native macOS productivity apps.

## Key Features
- 117 tools for Numbers, Pages, and Keynote automation
- Full document creation, editing, and export support (PDF, Excel, Word, etc.)
- Creator Studio AI tools integration (Magic Fill, Super Resolution, etc.)
- Template discovery and batch operations for compound tasks
- Cross-platform compatibility with MCP clients (Claude, Codex, etc.)

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with native macOS productivity tools, unlocking automated document and presentation generation for RAG pipelines.
