## Summary
Liyuan is an AI agent-driven role-playing application that enhances narrative experiences by optimizing memory management, enabling user-driven plot decisions, and providing dynamic visual panels. It introduces novel features like context pruning, decision cards, and cross-session knowledge retention for immersive storytelling.

## Key Features
- Memory optimization via context pruning and structured ledgers, reducing context usage by 53-63% while preserving narrative integrity
- User-driven plot decisions through interactive decision cards for critical story branches
- Dynamic agent-generated panels (e.g., maps, equipment libraries) for real-time visualization
- Cross-session knowledge retention with exportable worldbooks and structured lore management
- World-line branching and deterministic rollback for exploring alternate endings without data loss
