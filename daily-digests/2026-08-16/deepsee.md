## Summary
deepsee enables text-only models like DeepSeek to process and understand images by converting them into textual descriptions using vision APIs or local OCR. It integrates seamlessly with various clients (Claude Code, Cursor, MCP) to provide native image-reading capabilities without vendor lock-in.

## Key Features
- Converts images to text for text-only LLMs using vision APIs or local OCR
- Supports multiple vision providers (e.g., Zhipu, Aliyun, Ollama) with automatic failover
- Integrates with Claude Code, Cursor, MCP clients, and CLI tools
- Zero-dependency core with optional vision API keys for extended functionality
- Offers demo mode and local OCR for zero-cost usage

## Why It Matters for RAG Builders
It bridges the gap between text-only models and multimodal capabilities, enabling RAG systems to process visual data without requiring native vision model support.
