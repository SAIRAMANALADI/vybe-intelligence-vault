## Summary
A Flatpak-based desktop launcher for Grok (xAI's terminal coding agent) that provides a graphical interface, context menu integration, and automatic installation of the Grok CLI for Linux users.

## Key Features
- Provides a desktop icon and menu entry for Grok Build to simplify user access
- Automatically installs Grok CLI if missing, with progress tracking in the terminal
- Supports right-click context menu integration for project folders (GNOME, KDE, Cinnamon)
- Auto-detects and launches user-preferred terminal emulator for Grok TUI
- Lightweight wrapper that reuses the official Grok CLI installation for compatibility

## Why It Matters for RAG Builders
It bridges the gap between CLI tools and non-technical users by providing a polished desktop experience for Grok Build while maintaining full access to the native CLI.
