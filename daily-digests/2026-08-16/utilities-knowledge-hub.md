## Summary
An enterprise-grade AI chatbot for utilities companies that integrates Knowledge Graph traversal, RAG document retrieval, dataset access governance, and automated IT ticket escalation into a unified intelligent interface.

## Key Features
- Hybrid Knowledge Graph and RAG retrieval using NetworkX and LangChain
- Deterministic rule-based fallback engine for offline operation
- Role-based access control for dataset governance
- Automated IT ticket generation for access requests
- Live telemetry querying and installation forecasting

## Why It Matters for RAG Builders
It provides a unified, enterprise-ready AI interface for utilities companies to troubleshoot, query data, and manage access with built-in governance and automation.
