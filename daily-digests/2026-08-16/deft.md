## Summary
Deft is a self-hostable, source-available workspace that unifies human collaboration and AI agent interactions within a single platform. It enables teams to manage chat, tasks, knowledge, calendar, and approvals while allowing AI agents to safely access and act on workspace data via MCP or native tools.

## Key Features
- Unified workspace for humans and AI agents with shared chat, tasks, knowledge, and calendar context
- Built-in agent runtime (Defty) and support for external agents via MCP or HTTP clients
- Governed AI actions with approval workflows, receipts, and activity history
- Provider-neutral AI configuration supporting OpenAI, Anthropic, local models, and more
- Real-time collaboration with structured mentions, threads, and rich text editing

## Why It Matters for RAG Builders
Deft eliminates the need to manually copy context into AI chats by providing a unified workspace where agents can safely retrieve and act on permission-aware data, making it essential for building robust RAG systems with governed AI interactions.
