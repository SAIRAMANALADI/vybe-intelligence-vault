## Summary
BumbleHive is a lightweight Python SDK designed to simplify the creation of agent loops with minimal code. It provides a runtime environment for managing model calls, tool integration, and session persistence, supporting both terminal and structured application outputs.

## Key Features
- Lightweight Python SDK for building agent loops in minimal code
- Supports MCP servers and built-in tools for extensibility
- Multiple runtime APIs (run_console, run, stream) for different use cases
- Optional desktop application for a complete product experience
- Built-in session persistence, streaming events, and observability hooks

## Why It Matters for RAG Builders
