## Summary
AideAgent is a cross-platform desktop AI assistant that combines chat, tool execution, and local RAG capabilities into a single application. It supports both cloud and local AI models, integrates with external services via MCP, and offers deep extensibility through a skills system and WeChat bot integration.

## Key Features
- Dual runtime support (built-in AideAgent loop and OpenCode CLI via ACP)
- Local RAG with hybrid search (FTS5 + vector embeddings + RRF reranking)
- Extensible MCP ecosystem for integrating external services (e.g., Edge Browser, Computer Use)
- Skills system for teaching AI custom tasks via simple Markdown files
- WeChat bot integration for bidirectional AI communication

## Why It Matters for RAG Builders
AideAgent provides a unified, extensible platform for building and deploying AI agents with local RAG, MCP integration, and multi-model support, reducing the complexity of integrating disparate AI tools into a single workflow.
