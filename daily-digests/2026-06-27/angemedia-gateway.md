## Summary
AngeMedia Gateway is an OpenAI-compatible image and video generation gateway designed for AI Agents, NAS, and self-hosted workflows. It acts as a media-generation sibling to AngeVoice, focusing on model routing, prompt enhancement, and stable local media delivery.

## Key Features
- OpenAI-compatible image and video generation endpoints with standardized API
- Built-in media localization for stable local asset delivery
- Provider catalog and routing API for dynamic model selection
- Minimal Web Studio for administration, job tracking, and asset management
- Multi-provider support with configurable fallback chains and custom provider onboarding

## Why It Matters for RAG Builders
It provides a unified, self-hosted gateway for integrating multiple media generation models into RAG pipelines while ensuring stable, localized asset delivery and secure provider management.
