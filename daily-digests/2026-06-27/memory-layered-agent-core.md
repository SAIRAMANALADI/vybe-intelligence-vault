## Summary
Mnemosyne Core is a persistent memory framework for AI assistants that enables long-term personality consistency and contextual recall across sessions. It implements a layered memory architecture (ephemeral, working, personality, user profile, and temporal layers) to build digital relationships with AI agents.

## Key Features
- Layered memory system with ephemeral, working, personality, and temporal layers
- Personality persistence via SOUL.md configuration files
- Multi-platform integration with OpenAI, Claude, and local LLMs
- Adaptive memory consolidation and intelligent forgetting
- Privacy-focused local-first architecture with optional encrypted cloud sync

## Why It Matters for RAG Builders
It enables AI agents to maintain long-term personality consistency and contextual recall, which is critical for building lifelike, persistent digital assistants in RAG systems.
