## Summary
Whetstone is a Claude Code plugin that enforces engineering discipline in AI coding agents by providing structured workflows, skills, and multi-agent orchestration for PHP, Python, TypeScript, React, and infrastructure projects. It ensures agents plan, verify, debug, and review systematically rather than producing polished but undisciplined output.

## Key Features
- Enforces structured workflows with commands like /ia-brainstorm, /ia-plan, /ia-work, /ia-review, and /ia-compound for disciplined AI-driven development
- Provides 30+ skills for PHP, Python, TypeScript, React, Rust, Bash, Terraform, and PostgreSQL to shape agent behavior based on file types and tasks
- Supports multi-agent orchestration and agent-native architecture design for complex systems
- Includes a skill distillery to generate new skills from community sources and a converter for non-Claude Code agents (e.g., Codex, OpenCode)
- Integrates with tools like codesage for structural code intelligence and enforces production-grade patterns (e.g., strict typing, testing, observability)

## Why It Matters for RAG Builders
Whetstone ensures AI coding agents follow rigorous engineering processes, reducing undisciplined output and improving code quality, reliability, and maintainability in AI-driven development workflows.
