## Summary
Marmot is an open-source data catalog designed to simplify data discovery and metadata management for teams and AI agents. It enables cataloging of tables, topics, queues, APIs, and dashboards with rich metadata, interactive lineage, and AI-ready integrations.

## Key Features
- Single-binary deployment for quick setup and minimal infrastructure overhead
- Full-text and structured search with metadata filters for rapid data asset discovery
- Interactive lineage visualization to trace data flows and analyze impact
- AI-ready exposure of certified metadata via MCP, API, and UI
- Plugin-based architecture supporting tables, topics, queues, APIs, and dashboards
