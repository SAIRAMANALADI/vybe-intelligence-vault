## Summary
context-doctor is a diagnostic tool designed to visualize and analyze the usage of the OpenClaw context window. It provides insights through terminal output, PNG visualizations, and JSON data exports, helping users monitor token usage, file health, and available space over time.

## Key Features
- Terminal-based text output for immediate feedback
- PNG image generation to visualize context window data patterns
- JSON export for structured data analysis and integration with other tools
- No installation required; portable executable for Windows
- Supports multiple output formats via command-line options

## Why It Matters for RAG Builders
