## Summary
DataSpoke is an AI-powered sidecar extension for DataHub, designed as a loosely coupled companion to enhance metadata management with five core features: Ingestion Control, Validation, Ontology Generation, Metadata Generation, and Governance. It provides both a baseline product and a productized scaffold for building custom AI-driven data catalogs.

## Key Features
- Five baseline features (Ingestion Control, Validation, Ontology Generation, Metadata Generation, Governance) as modular spokes
- API-first design with a canonical API contract for extensibility
- AI-powered scaffold for custom spoke development using Claude Code conventions
- Production-ready Helm chart with PostgreSQL (pgvector + Apache AGE), Redis, and Airflow
- Development environment automation with Kubernetes and dev peripherals

## Why It Matters for RAG Builders
DataSpoke provides a structured, AI-augmented framework to extend DataHub's metadata capabilities, enabling scalable and customizable data governance for RAG pipelines.
