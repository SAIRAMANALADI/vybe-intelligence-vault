## Summary
A plugin for DLT Viewer that exposes DLT log analysis capabilities via the Model Context Protocol (MCP), enabling AI agents and MCP-compatible clients to query and retrieve information from DLT log files.

## Key Features
- Query and retrieve DLT log data via MCP for AI agents
- Filter logs by CTID, APID, log level, timestamp range, and keywords with pagination
- Generate and persist Markdown reports with clickable navigation links
- Retrieve full payloads for specific message IDs
- Integrate with DLT Viewer for real-time log analysis

## Why It Matters for RAG Builders
It bridges DLT log analysis with AI agents via MCP, enabling automated log querying and insights for automotive diagnostics and system monitoring.
