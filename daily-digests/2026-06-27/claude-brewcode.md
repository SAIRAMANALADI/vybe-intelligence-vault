## Summary
claude-brewcode is a suite of four Claude Code plugins designed to enhance AI-driven development workflows by enabling infinite task execution with automatic context handoff, documentation tools, text utilities, and visual workflows. It automates knowledge persistence and state management during Claude Code sessions.

## Key Features
- Infinite task execution with automatic context handoff and knowledge persistence
- 16 agents and 33 skills for development, documentation, and text utilities
- Semantic code search and multi-agent debate capabilities
- Documentation auto-sync, PDF conversion, and publishing tools
- Security scanning and CI/CD integration for robust workflows

## Why It Matters for RAG Builders
It enables AI agents to maintain long-running, context-aware tasks without losing state, making it essential for building sophisticated RAG systems that require persistent knowledge and seamless handoffs.
