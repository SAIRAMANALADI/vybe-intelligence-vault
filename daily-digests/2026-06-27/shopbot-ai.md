## Summary
ShopBot AI is an MCP-powered e-commerce support agent that integrates LLMs with real systems like MySQL databases and FAISS-based retrieval pipelines to provide accurate, non-hallucinatory responses for order status, policies, and product availability queries.

## Key Features
- Real-time order status checks via MySQL integration
- FAISS-based semantic search for knowledge base retrieval
- Intent routing using Gemini to minimize hallucinations
- Modular MCP tool layer for extensible functionality
- Local deployment with FAISS to avoid hosted vector DB costs
