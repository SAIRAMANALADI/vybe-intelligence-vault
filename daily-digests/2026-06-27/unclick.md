## Summary
UnClick provides an MCP-compatible server that exposes 450+ callable endpoints across 178+ tools for AI agents, enabling seamless integration with developer utilities, social media, e-commerce, finance, and more without requiring separate package installations.

## Key Features
- 450+ callable endpoints across 178+ tools for AI agents
- Persistent cross-session memory with legacy alias support
- Dynamic endpoint discovery via hidden catalog tools
- Compatibility with Claude, ChatGPT, Cursor, and other MCP clients
- Split licensing (AGPL-3.0 for platform, MIT/Apache-2.0 for clients)

## Why It Matters for RAG Builders
