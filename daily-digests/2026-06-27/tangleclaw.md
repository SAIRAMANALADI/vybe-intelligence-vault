## Summary
TangleClaw is a local AI coding session orchestrator that wraps AI agents in persistent tmux sessions, enabling seamless session continuity across network drops, device switches, and reconnects. It provides a full-stack platform for managing multi-engine AI coding workflows with methodology enforcement, project groups, and mobile access via a PWA dashboard.

## Key Features
- Persistent AI coding sessions via tmux, surviving network drops and device switches
- Multi-engine support (Claude Code, Codex, Gemini CLI, Aider, OpenClaw) with engine-native config generation
- Methodology enforcement through pluggable JSON templates and Prawduct integration
- Project groups with shared markdown documents and document locking for collaborative workflows
- Zero-dependency architecture using Node.js 22+ standard library only

## Why It Matters for RAG Builders
TangleClaw eliminates the friction of interrupted AI coding sessions by ensuring continuity and enabling governed, multi-engine workflows with methodology enforcement, making it essential for AI stack builders who require reliable, persistent, and scalable AI agent interactions.
