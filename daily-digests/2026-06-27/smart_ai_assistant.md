## Summary
A Windows-based AI assistant that enables users to query and extract answers from their own PDF documents using RAG techniques, conditional workflows, and the Gemini API. The app provides a Streamlit-based UI for document upload, chat interaction, and response tracking via LangSmith.

## Key Features
- Document-based question answering from PDFs using vector search (FAISS)
- Conditional workflows for handling different types of queries (e.g., direct answers, document search, follow-ups)
- Integration with the Gemini API for generating responses
- LangSmith monitoring for tracking assistant behavior and response quality
- Streamlit-based clean and intuitive web interface for Windows

## Why It Matters for RAG Builders
It provides a ready-to-use, Windows-native tool for building RAG applications that query private PDF documents with minimal setup, leveraging modern AI workflows and monitoring.
