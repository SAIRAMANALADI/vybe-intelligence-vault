## Summary
A Tauri-based terminal aggregator that unifies multi-workspace management with built-in AI agent integration, including Claude Code and Codex agents, file browsers, Git tools, and snippet managers. Designed for developers to streamline workflows with persistent terminals, agent sessions, and cross-platform support.

## Key Features
- Multi-workspace terminal management with drag-and-drop reordering and detachable windows
- Built-in Claude Code and Codex AI agents with configurable permission modes and session resumption
- Integrated file browser, Git viewer, snippet manager, and markdown preview with live updates
- Semantic code navigation via `cx` CLI for efficient agent context usage
- Cross-platform support (Windows, macOS, Linux) with mobile app compatibility

## Why It Matters for RAG Builders
It streamlines AI agent workflows by unifying terminals, agents, and tools in a single cross-platform app, reducing context switching for developers building RAG systems.
