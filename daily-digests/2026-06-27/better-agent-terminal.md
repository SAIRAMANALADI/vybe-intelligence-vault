## Summary
A Tauri-powered terminal aggregator that unifies multi-workspace management with built-in AI agent integration, including Claude Code and Codex support, file browsing, Git integration, and semantic code navigation tools.

## Key Features
- Multi-workspace terminal management with drag-and-drop reordering and detachable windows
- Built-in Claude Code and Codex AI agent panels with permission controls and session management
- Integrated file browser, Git viewer, snippet manager, and markdown preview with live updates
- Semantic code navigation via Tree-sitter-based CLI (cx) for efficient context management
- Cross-platform support (Windows, macOS, Linux) with mobile app compatibility

## Why It Matters for RAG Builders
It streamlines AI-driven development workflows by combining terminal aggregation with embedded agent capabilities, reducing context switching and enhancing productivity for RAG builders.
