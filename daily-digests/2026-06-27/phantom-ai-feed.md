## Summary
A local, privacy-preserving information pipeline for Chinese AI/ML engineers that automates daily/weekly digest generation, interview question review, and on-prem RAG knowledge base creation. It uses synthetic data for deterministic testing and avoids external network calls or cloud dependencies.

## Key Features
- Automated daily/weekly digest generation from synthetic or real feeds
- Local FTS5 full-text search for on-prem RAG knowledge base
- Spaced repetition system (SRS) for interview question review
- Deterministic synthetic data loops for testing without network calls
- Privacy-first design with no external data sharing or cloud dependencies

## Why It Matters for RAG Builders
It provides a privacy-preserving, local-first pipeline for building and maintaining RAG knowledge bases tailored for Chinese AI engineers, eliminating the need for cloud services or external data exposure.
