## Summary
External Brain is a self-hosted MCP server that provides persistent, long-term memory for AI coding agents across tools like Claude Code, Cursor, and GitHub Copilot. It captures, extracts, and retrieves reusable skills and rules from coding sessions, enabling AI agents to retain and apply learned knowledge over time.

## Key Features
- Automatic extraction of durable skills and rules from AI coding sessions without manual input
- Universal MCP compatibility with major AI coding tools (Claude Code, Cursor, GitHub Copilot, etc.)
- Semantic retrieval of relevant knowledge using pgvector embeddings for context injection
- Grounded Oracle with citations for answering questions based on past sessions and skills
- Self-improving knowledge base with daily synthesis, decay of stale knowledge, and multilingual UI support

## Why It Matters for RAG Builders
External Brain solves the critical problem of fragmented, siloed AI memory by providing a unified, self-hosted knowledge layer that persists across tools and teams, enabling AI agents to retain and apply learned context over time.
