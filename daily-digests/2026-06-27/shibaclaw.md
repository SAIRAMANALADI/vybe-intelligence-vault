## Summary
ShibaClaw is a self-hosted, security-first AI agent framework designed to 'just work' out of the box with minimal configuration. It supports 22 providers, 11 chat channels, and includes a built-in WebUI, desktop app, and MCP integration for seamless automation and tool usage.

## Key Features
- Security-first architecture with built-in CVE auditing, prompt-injection wrapping, and SSRF protection
- Supports 22 providers natively via official SDKs (no LiteLLM proxy required)
- Built-in WebUI, desktop app (Windows), and mobile-friendly interface for cross-platform access
- 3-level memory system with proactive learning and auto-compaction for context retention
- MCP-ready with lazy tool loading to reduce token overhead and improve efficiency
