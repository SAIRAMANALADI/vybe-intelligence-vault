## Summary
Tula is an open-source desktop application designed to consolidate and organize personal health data from various sources like wearables, lab reports, genomics, and EHR records into a single interface. It transforms raw health data into structured insights for AI agents or personal review.

## Key Features
- Consolidates health data from multiple sources (wearables, labs, EHR, genomics) into one interface
- Supports FHIR and common health data formats for interoperability
- Designed for local, private use to ensure data security
- Provides structured insights for AI agents or personal health tracking
- Open-source and extensible with OpenClaw skills
