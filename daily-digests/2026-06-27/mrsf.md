## Summary
MRSF (Markdown Review Sidecar Format) is a standardized, portable format for storing review comments outside Markdown files using sidecar YAML files. It enables durable, machine-actionable review workflows for Markdown documentation, integrating with CLI tools, MCP servers, and editor plugins.

## Key Features
- Portable sidecar YAML files for review comments, keeping Markdown files clean
- Anchoring system for comments tied to line/span positions with re-anchoring after edits
- CLI and MCP server for programmatic access and AI agent integrations
- Python SDK and Node.js CLI with 1:1 parity
- Editor integrations (VS Code, Monaco, Tiptap, Milkdown/Crepe) for inline review workflows

## Why It Matters for RAG Builders
MRSF provides a structured, version-controlled way to manage review comments in Markdown workflows, enabling AI agents and automated tools to reliably interact with and reason about feedback without cluttering source files.
