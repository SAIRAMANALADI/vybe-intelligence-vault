## Summary
OPC is an adaptive agent orchestrator that simulates a full team of 16 specialist agents to autonomously build, review, and verify software projects from a single brief. It enforces zero-trust quality gates through a digraph-based pipeline with mechanical verdicts.

## Key Features
- 16 built-in specialist agents (PM, Designer, Security, etc.) with role-based protocols
- Digraph-based pipeline with mechanical verdicts (no LLM judgment for critical outputs)
- Autonomous loops for unattended, multi-hour project execution (e.g., 10+ hours without intervention)
- Zero-trust architecture with four enforcement layers (L0-L3) and guardrails like oscillation detection and plan integrity checks
- Extensible via hooks and companion extensions (e.g., design-intelligence for visual validation)

## Why It Matters for RAG Builders
