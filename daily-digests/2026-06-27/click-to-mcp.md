## Summary
click-to-mcp automates the conversion of Python Click or Typer CLI applications into Model Context Protocol (MCP) servers, enabling AI agents to invoke CLI tools directly without manual boilerplate or schema definitions.

## Key Features
- Automatically wraps existing Click/Typer CLIs as MCP servers with zero code changes
- Supports both stdio and HTTP+SSE transports for MCP clients
- Provides CLI discovery, tool listing, and client configuration generation
- Handles nested command groups, arguments, options, and enums with JSON Schema mapping
- Includes built-in demo and extensive examples for quick integration

## Why It Matters for RAG Builders
It eliminates the manual effort of converting CLI tools into MCP servers, enabling AI agents to seamlessly invoke CLI commands as structured tools, accelerating RAG and agent-based workflows.
