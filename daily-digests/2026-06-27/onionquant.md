## Summary
OnionQuant is a production-grade multi-agent AI system that simulates a virtual company for quantitative market analysis, organizing 15+ LLM-powered agents into specialized departments. It demonstrates advanced agent orchestration, cost-aware model routing, persistent cross-session memory, and real-time SSE push notifications for AI-native quantitative research.

## Key Features
- 15+ specialized LLM agents organized into a virtual company hierarchy with CEO and department-level agents
- Dual-tier LLM routing for cost optimization (80% cost reduction on high-volume tasks)
- Persistent cross-session memory without vector databases (TF-IDF + cosine similarity + SHA-256 dedup)
- Real-time SSE push notifications for live dashboard updates and WeChat integration
- Production-grade deployment with Cloudflare Tunnel, Watchdog auto-recovery, and pre-commit hooks
