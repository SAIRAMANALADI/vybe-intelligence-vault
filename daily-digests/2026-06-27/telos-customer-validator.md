## Summary
The Telos Customer Validator is an AI-powered tool designed to validate startup ideas before development begins by simulating adversarial customer interactions, scoring pain points, and generating actionable validation reports. It integrates with Claude Code and OpenAI models to provide founder accountability and market fit analysis.

## Key Features
- Adversarial customer roleplay with 13 distinct personas to challenge assumptions
- Real-time validation scoring (0-10) with weighted criteria for pain points and market fit
- Concierge onboarding using Socratic questioning to refine startup hypotheses
- Multilingual and multicultural adaptation for global customer validation
- Integration with Claude Code and OpenAI APIs for hybrid AI model optimization

## Why It Matters for RAG Builders
It prevents wasted development effort by validating startup ideas against adversarial customer feedback before any code is written, reducing the risk of building products nobody wants.
