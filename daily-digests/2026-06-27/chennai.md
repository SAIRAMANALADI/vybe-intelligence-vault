## Summary
chennai is a hybrid AI agent and terminal user interface for exploring AppThreat's atom files, enabling interactive static analysis, data-flow tracing, and AI-assisted code and security analysis. It combines a TUI with a built-in AI agent for querying code structures and vulnerabilities directly from the terminal.

## Key Features
- Interactive TUI for exploring atom files with keyboard-driven navigation
- Built-in AI agent supporting Anthropic and OpenAI-compatible providers for security and code analysis
- Direct access to graph queries and chen DSL for arbitrary code structure exploration
- Data-flow analysis with source-to-sink tracing and mitigation indicators
- Automated SBOM generation via cdxgen for dependency-aware analysis

## Why It Matters for RAG Builders
It provides an all-in-one terminal-based environment for AI-assisted static analysis and vulnerability detection, bridging the gap between raw code graphs and actionable insights for RAG builders.
