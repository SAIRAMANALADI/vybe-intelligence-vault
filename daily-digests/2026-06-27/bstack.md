## Summary
bstack is a portable harness metalayer for AI-native development, providing twenty irreducible primitives and thirty curated agent skills to transform agent-driven workspaces into self-operating systems with governance, safety, and orchestration capabilities.

## Key Features
- Twenty irreducible primitives addressing specific failure modes in unsupervised agent sessions (e.g., session amnesia, destructive operations, invisible work, knowledge graph rot)
- Thirty curated agent skills spanning foundation, memory, orchestration, research, design, platform specialties, and strategy
- Governance layer with formal stability proofs (Recursive Controlled Systems hierarchy) and L3 stability margin
- Lifecycle commands (bootstrap, doctor, repair, status, validate, revamp) for installation, verification, and maintenance
- Empirical benchmarking (bench) and metrics collection for skill evolution and performance measurement
