## Summary
MemoryForge is a persistent memory engine for AI agents that provides local-first memory storage with optional decentralized cloud sync. It offers 8 MCP tools and 5 auto-engines to automate memory management, ensuring agents retain context across sessions without manual intervention.

## Key Features
- 8 MCP tools for memory management (store, search, recall, list, forget, context, export, share)
- 5 auto-engines for automatic memory handling (naming, merging, priority scoring, decay archiving, context injection)
- Local-first storage with optional Shelby decentralized cloud sync for cross-device memory persistence
- Zero external dependencies for Free tier (23MB in-process embedding model, no API keys required)
- PreCompact auto-capture ensures key learnings are saved even if the terminal is force-closed
