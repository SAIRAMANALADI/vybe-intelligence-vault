## Summary
agentskills-mcp is a FastMCP server designed to discover, install, and manage agent skills from curated GitHub repositories. It acts as a centralized hub for browsing, selecting, and integrating skills into AI agent workflows or MCP-compatible tools.

## Key Features
- Browse and discover skills from curated GitHub collections
- Install and manage skills from a centralized interface
- Add custom skill sources for extensibility
- Integrates with MCP-compatible AI tools and agents
- Supports Windows with Python-based or pre-packaged execution
