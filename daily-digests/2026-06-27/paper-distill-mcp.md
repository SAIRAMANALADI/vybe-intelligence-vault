## Summary
paper-distill-mcp is a Windows-based desktop application designed to simplify the search, organization, and distribution of academic papers across multiple platforms. It leverages the Model Context Protocol (MCP) to enable seamless integration with various clients and services for paper curation.

## Key Features
- Search academic papers using keywords with a clean, user-friendly interface
- Save and organize papers in a personal library for later access
- Push papers to email, cloud storage (Dropbox, Google Drive), or reading apps (Pocket, Read-it-Later)
- Automatic updates to ensure the latest features and fixes
- Multi-platform support for distributing papers to mobile devices
