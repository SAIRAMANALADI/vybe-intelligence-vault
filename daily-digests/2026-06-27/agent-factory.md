## Summary
agent-factory is a Windows-based desktop application providing 84 pre-built AI agent prompts and tools across 12 departments and 20 industry-specific playbooks. It enables non-technical users to automate tasks, generate content, and interact with LLMs like ChatGPT, Claude, and Gemini without coding or complex setup.

## Key Features
- 84 production-ready AI agent prompts for 12 departments (marketing, HR, IT, etc.)
- 20 industry-specific playbooks (finance, healthcare, retail, etc.)
- Self-expanding library that generates new prompts and agents automatically
- No coding required with a user-friendly Windows desktop interface
- Comprehensive glossary for AI and prompt-engineering terms
