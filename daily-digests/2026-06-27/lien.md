## Summary
Lien enables AI coding assistants to deeply understand codebases through local semantic search and analysis. It indexes code locally, integrates via the Model Context Protocol (MCP), and provides tools for impact analysis, complexity metrics, and cross-repository search.

## Key Features
- 100% local and private code indexing with no external API calls
- Semantic search for natural language queries about codebases
- Cross-repository search using Qdrant backend for organizational use
- MCP integration with tools like Cursor and Claude Code for seamless AI assistance
- Complexity analysis with human-friendly metrics (test paths, mental load, time to understand)
