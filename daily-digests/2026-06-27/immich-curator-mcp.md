## Summary
An MCP server that integrates with Immich to automate photo curation, duplicate detection, geographic album creation, and AI-powered gallery publishing. It leverages AI models (OpenAI/Claude) for conflict resolution and metadata translation, enabling seamless, privacy-focused photo management.

## Key Features
- Automated duplicate detection using perceptual hashing and AI-powered conflict resolution
- Geographic clustering to create intelligent travel albums from GPS data
- One-click publishing of responsive, multilingual web galleries with dark/light mode
- 24/7 daemon mode for continuous library monitoring and real-time curation
- Privacy-first architecture with encrypted API calls and no third-party photo storage

## Why It Matters for RAG Builders
It streamlines photo library organization by automating curation tasks, reducing manual effort, and enhancing accessibility through AI-driven insights and multilingual support.
