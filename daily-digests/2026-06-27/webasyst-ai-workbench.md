## Summary
Webasyst Tapestry is an AI-driven orchestrator that automates the generation, validation, and deployment of Webasyst components, themes, and plugins using natural language instructions. It bridges AI with the Webasyst framework to transform vague requests into production-ready code without manual boilerplate.

## Key Features
- Intent-to-App pipeline for generating Webasyst components from natural language
- Semantic theme weaver for brand-consistent UI generation
- Multi-model AI routing for optimized cost and quality
- Live preview generation for real-time component validation
- Automated documentation and migration path analysis for generated components

## Why It Matters for RAG Builders
It accelerates Webasyst development by automating repetitive tasks and enabling non-experts to generate production-ready components, reducing time-to-market and improving consistency.
