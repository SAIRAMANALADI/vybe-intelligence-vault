## Summary
A public observatory for auditing and verifying the readiness of Model Context Protocol (MCP) servers, providing signed, time-limited certificates and agent-readable readiness records. It enables external validation of MCP server functionality, tool discoverability, and reachability without endorsing quality or safety.

## Key Features
- External auditing of MCP servers for tool discoverability, reachability, and schema validity
- Three-tier readiness levels: Observed, Claimed, and Certified
- Signed, time-limited certificates for offline verification
- Open participation model for builders and agents to audit or claim servers
- Pre-flight tool for MCP server submission to directories like Claude Connectors

## Why It Matters for RAG Builders
It provides a critical layer of validation and transparency for MCP servers, ensuring they meet basic functional requirements before being used in AI applications, reducing integration failures and improving reliability for RAG builders.
