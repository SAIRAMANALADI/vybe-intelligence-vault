## Summary
AgentShield is a security observability layer for AI-powered coding agents like Claude Code and Codex, providing real-time monitoring, intent inference, and cryptographic audit trails to prevent malicious or unintended actions while ensuring compliance with standards like SOC 2 and ISO 27001.

## Key Features
- Hash-anchored permission chains for tamper-proof audit trails using SHA-3 cryptographic hashing
- Sandbox intent inference with behavioral ML models to predict and block risky agent actions
- Multi-agent support for Claude Code, Codex, Gemini CLI, and Cursor with granular permission controls
- Real-time threat dashboard with drill-down capabilities and mobile-responsive design
- Automated compliance report generation (SOC 2, ISO 27001) and rollback engine for incident recovery

## Why It Matters for RAG Builders
AgentShield provides critical security oversight for AI coding agents, preventing catastrophic automation errors and ensuring compliance in production environments where agent actions must be auditable and reversible.
