## Summary
Ronin is a masterless, terminal-native AI coding agent inspired by Claude Code, enabling users to read, edit, and run code directly from the terminal. It is provider-agnostic, supporting models from Anthropic, Gemini, Cerebras, Groq, OpenRouter, Ollama, and OpenAI, with a focus on free-tier usage and security hardening.

## Key Features
- Provider-agnostic agent framework supporting free and paid LLM providers (Claude, Gemini, Cerebras, Groq, Ollama, etc.)
- Terminal-native UI with live markdown rendering, diff previews, and approval gates for edits and shell commands
- Built-in multi-agent orchestration for parallel task execution across models and roles (researcher, implementer, reviewer, tester)
- Comprehensive security hardening, evals, and memory management with 2,232+ tests for reliability
- Extensible via 200+ plugins, local/remote MCP server integrations, and project memory (RONIN.md, CLAUDE.md, AGENTS.md)

## Why It Matters for RAG Builders
Ronin provides a flexible, terminal-native framework for building and deploying AI agents that can leverage multiple LLM providers, making it essential for RAG builders seeking provider-agnostic, secure, and extensible agent architectures.
