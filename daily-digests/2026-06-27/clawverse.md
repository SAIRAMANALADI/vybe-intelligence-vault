## Summary
Clawverse is a persistent isometric pixel-art island builder with real-time multiplayer features, allowing users to create, share, and interact with customizable islands. It combines a Flask backend with SQLite for persistence and vanilla JavaScript for rendering.

## Key Features
- Persistent isometric world with 32x32 tile grid and Z-layers for depth
- AI-powered layout assistant and tile generation for rapid world-building
- Real-time multiplayer presence with Server-Sent Events (SSE) and visitor tracking
- Progress and achievement system with XP tracking for user engagement
- Visitor mode with read-only access, social interactions, and gift system

## Why It Matters for RAG Builders
Clawverse provides a unique sandbox for AI-driven world-building and real-time multiplayer interaction, making it valuable for testing AI agents in dynamic, persistent environments.
