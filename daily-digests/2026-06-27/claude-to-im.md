## Summary
Claude-to-IM is a Windows-based bridge application that connects Claude Code SDK to popular instant messaging platforms like Telegram, Discord, and Feishu, enabling AI interactions without complex server setups.

## Key Features
- Seamless integration of Claude Code with Telegram, Discord, and Feishu
- Host-agnostic and runs locally on Windows without server dependencies
- Lightweight with low resource consumption
- Supports OAuth and API key authentication for secure connections
- Configurable message filtering and logging for debugging
