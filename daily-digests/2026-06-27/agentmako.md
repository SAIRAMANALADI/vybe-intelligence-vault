## Summary
agentmako is a local-first codebase intelligence engine that provides structured context and diagnostics for AI coding tools. It indexes repositories, builds SQLite-backed fact databases, and offers evidence-backed answers to project-specific questions, enabling agents to understand and navigate codebases efficiently.

## Key Features
- Local SQLite-backed fact database for project indexing and querying
- MCP server integration for seamless agent communication
- Reef Engine for structured fact extraction and findings
- Hot-reloaded YAML rule packs for customizable project conventions
- Dashboard and CLI tools for real-time project insights and diagnostics
