## Summary
A collection of Rust and Python projects focused on LLM inference infrastructure, profiling, and optimization. Includes tools for GPU/CPU profiling, cold-start analysis, Kubernetes operators, and distributed system performance investigations, all validated on real hardware.

## Key Features
- End-to-end LLM inference profiling with per-token timing and GPU/CPU correlation
- eBPF-based cold-start analysis for vLLM, tracing kernel and driver interactions
- Kubernetes operator for cold-start-aware vLLM deployment and lifecycle management
- Controlled experiments isolating performance trade-offs (e.g., CUDA graphs)
- Production-grade optimization service (OptimEngine) with OR-Tools integration
