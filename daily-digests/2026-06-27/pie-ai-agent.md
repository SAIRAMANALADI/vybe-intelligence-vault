## Summary
Pie is an open-source AI agent integrated into the Chrome sidebar that automates browser tasks using natural language commands. It reads pages, clicks, types, and performs multi-step workflows across tabs, PDFs, and rich editors while supporting BYOK for 11 LLM providers or an optional subscription service.

## Key Features
- Native browser integration with Chrome sidebar for real-time task execution
- Multi-step task automation across tabs, PDFs, and rich editors (e.g., Google Docs)
- Support for 11 LLM providers via BYOK or optional subscription service
- Reusable workflows (Skills) for automating repetitive tasks
- Privacy-first design with encrypted API keys and optional local model support (Ollama roadmap)

## Why It Matters for RAG Builders
Pie enables AI-driven browser automation for RAG pipelines by offloading complex, multi-step web interactions to an agent, reducing manual data extraction and task execution overhead.
