## Summary
A Windows desktop application enabling multi-chain batch crypto payments, payroll, swaps, and invoicing with wallet integration and the Spraay x402 gateway for secure transactions.

## Key Features
- Multi-chain batch crypto payments with a single interface
- Built-in payroll and invoice management for crypto transactions
- Integration with Spraay x402 gateway for fast and secure transactions
- Direct wallet connection without storing private keys on servers
- Recurring payment batch creation and management
