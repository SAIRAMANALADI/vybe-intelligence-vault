## Summary
canvas-cowork is a Windows desktop application that provides a spatial canvas for managing AI-generated content, tasks, and agent interactions from the command line. It enables users to create, organize, and recall nodes containing text, images, video, and agent outputs in a visual workspace.

## Key Features
- Spatial canvas for organizing AI-generated content and tasks
- Support for text, image, video, and agent output nodes
- Built-in recall and management tools for past work
- Windows desktop application with CLI integration
- Visual layout for tracking multi-step AI workflows
