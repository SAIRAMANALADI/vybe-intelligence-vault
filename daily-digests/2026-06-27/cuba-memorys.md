## Summary
Cuba-Memorys is a Model Context Protocol (MCP) server that provides persistent, neuroscience-inspired long-term memory for AI agents using a knowledge graph, adaptive decay algorithms, and anti-hallucination grounding. It enables AI coding assistants to retain and retrieve context across sessions with sub-millisecond performance.

## Key Features
- FSRS-6 adaptive decay for realistic memory retention and recall
- Hebbian + BCM metaplasticity for self-normalizing memory importance
- 4-signal RRF fusion search with entropy-routed adaptive ranking
- Knowledge graph with typed relations, Leiden communities, and Brandes centrality
- Anti-hallucination verification and error memory with pattern detection

## Why It Matters for RAG Builders
Cuba-Memorys enables AI agents to retain and retrieve context across sessions with neuroscience-backed memory models, reducing hallucinations and improving decision-making in RAG pipelines.
