## Summary
A specialized AI agent skill for creating, scheduling, or canceling real-time Live Activities on iPhone via the PinToIsland (上岛记) API, enabling users to display pickup codes, reminders, or order details on the Dynamic Island or Lock Screen.

## Key Features
- Supports creation of pickup code Live Activities (e.g., food orders, package tracking)
- Enables scheduled reminders via Live Activity
- Allows cancellation of Live Activities by `activity_id`
- Maps external order data (e.g., Luckin Coffee) to PinToIsland format
- Secure token storage for PinToIsland API authentication
