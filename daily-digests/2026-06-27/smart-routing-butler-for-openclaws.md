## Summary
Smart Routing Butler is a self-hosted, OpenAI-compatible API router designed to intelligently dispatch AI model requests based on cost, latency, and quality metrics. It acts as a local proxy layer for AI agents and developer tools, enabling seamless model switching and fallback mechanisms.

## Key Features
- OpenAI-compatible local proxy with standard endpoints for seamless integration with AI tools like OpenClaw, Cursor, and Continue
- Multi-layer intelligent routing (L0-L3) combining caching, semantic matching, and user-defined rules for precise model dispatching
- Flexible rule creation via visual editor, natural language input, or AI-guided questionnaire for automated rule generation
- High availability with auto-fallback and circuit breaker mechanisms to ensure continuous service during model failures
- Full observability through a Next.js dashboard with request logs, token usage analytics, and rule hit analysis

## Why It Matters for RAG Builders
It simplifies and optimizes AI model routing for RAG builders by providing a self-hosted, cost-effective, and flexible solution to dynamically select and switch between models based on task requirements and performance metrics.
