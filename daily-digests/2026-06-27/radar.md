## Summary
Radar is a modern, local-first Kubernetes UI that provides real-time visibility into cluster topology, resource management, Helm operations, and GitOps workflows without requiring cluster-side installation or cloud dependencies.

## Key Features
- Zero-install Kubernetes UI with single-binary deployment and no cluster-side agents or CRDs
- Real-time topology visualization and resource browsing with interactive graphs and tables
- Built-in Helm management, GitOps support for FluxCD/ArgoCD, and image filesystem viewer
- AI-ready MCP server for enabling AI assistants to query and interact with Kubernetes clusters
- Air-gapped and offline-capable with smart caching, parallel loading, and progressive rendering

## Why It Matters for RAG Builders
Radar provides a lightweight, local-first Kubernetes UI that simplifies cluster visibility and management, making it essential for developers and AI systems needing real-time access to Kubernetes resources without heavy dependencies.
