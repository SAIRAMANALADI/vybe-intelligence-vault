## Summary
laravel-rag is a Laravel-based application designed to simplify the implementation of Retrieval-Augmented Generation (RAG) pipelines on Windows. It enables users to index, search, and query their own documents using vector and hybrid search methods, with support for both SQLite and PostgreSQL backends.

## Key Features
- Pre-configured RAG pipeline with Laravel for rapid deployment
- Support for vector search (pgvector/sqlite-vec) and hybrid search
- Agentic retrieval and streaming responses for dynamic AI interactions
- Filament admin panel for managing documents, indexes, and evaluations
- MCP server integration for connecting to external AI tools

## Why It Matters for RAG Builders
It provides a ready-to-use, Windows-friendly RAG pipeline that simplifies document indexing and retrieval for AI applications.
