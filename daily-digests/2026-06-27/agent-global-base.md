## Summary
AGENT-GLOBAL-BASE is a markdown-first, agent-native knowledge base and organizational simulation designed as an LLM engineering laboratory. It provides a governance framework for agent systems, skill specifications, and pipeline definitions without a traditional build system or entry point.

## Key Features
- Markdown-first documentation system for agent profiles, skills, and pipelines
- Agent Systems Engineering (ASE) framework for governance and compliance
- Modular LLM engineering stack with five layers (prompt, context, harness, RAG, multi-agent)
- Organizational simulation with three co-resident systems (Company, Studio, Lab)
- Append-only optimization history and strict document authority hierarchy

## Why It Matters for RAG Builders
It provides a structured, governance-driven approach to designing, documenting, and executing agent-based systems, making it essential for building scalable and compliant AI engineering workflows.
