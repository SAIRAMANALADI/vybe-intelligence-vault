## Summary
DeployDiff CLI is a tool for previewing infrastructure changes, estimating cost impacts, and generating rollback commands before deployment. It supports multiple infrastructure-as-code providers like Terraform, CloudFormation, and Pulumi.

## Key Features
- Preview infrastructure changes with human-readable diffs and property-level details
- Estimate cost impact before deployment using provider-native pricing
- Generate rollback commands to reverse infrastructure changes
- Multi-provider support for Terraform, CloudFormation, and Pulumi
- MCP server mode for AI agent integration

## Why It Matters for RAG Builders
It enables AI-driven infrastructure management by providing pre-deployment visibility into changes, costs, and rollback strategies, reducing deployment risks.
