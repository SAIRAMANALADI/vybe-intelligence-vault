## Summary
Sao is a lightweight, locally-hosted desktop application that provides a minimalist GUI for solo developers to interact with LLMs and execute local tools via the Model Context Protocol (MCP). It prioritizes speed, privacy, and simplicity with a decoupled architecture and no telemetry.

## Key Features
- Decoupled GUI and backend architecture for high performance
- Supports LLM hot-switching across multiple providers (OpenAI, Anthropic, Ollama, GitHub Copilot)
- Integrates Model Context Protocol (MCP) for local tool execution (e.g., WebFetch)
- Local SQLite database for conversation history with no telemetry
- Single-session focus to prevent context bleed

## Why It Matters for RAG Builders
Sao provides a lightweight, privacy-focused desktop interface for solo developers to interact with LLMs and MCP tools, reducing reliance on heavy IDEs or cloud-based solutions.
