## Summary
OhMyAgent is a self-hosted AI agent gateway with a persistent memory system that enables agents to remember, understand, and respect user boundaries. It supports multi-platform deployment, token-efficient operations, and includes an approval engine for secure tool execution.

## Key Features
- Persistent, searchable memory system with hybrid retrieval (vector + full-text search) and LLM-driven summarization
- Built-in approval engine for secure tool execution with path-scoped file access and configurable profiles
- Token-efficient design with layered context, progressive skill loading, and on-demand tool activation
- Multi-platform support including Termux (Android), desktop apps (Windows/macOS/Linux), and Docker
- DreamCycle nightly maintenance for memory hygiene, entity extraction, and persona distillation

## Why It Matters for RAG Builders
It provides a robust framework for building AI agents with persistent memory and secure tool execution, critical for long-term user interaction and trust in RAG systems.
