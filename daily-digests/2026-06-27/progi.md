## Summary
Progi is an MCP-native workflow engine designed to teach AI agents personalized workflows, enabling consistent task execution without context loss. It integrates with MCP clients to automate and monitor multi-step processes through structured playbooks and a web-based monitoring interface.

## Key Features
- MCP-native workflow engine for seamless AI agent integration
- Structured workflow authoring via plain-language descriptions and playbooks
- Real-time monitoring dashboard for task progress and output history
- Persistent workflows stored in SQLite, surviving context resets
- Two-pass workflow creation: skeleton generation followed by playbook refinement

## Why It Matters for RAG Builders
Progi enables AI agents to follow personalized, repeatable workflows, reducing manual re-explanation and improving consistency in task execution for RAG and AI stack builders.
