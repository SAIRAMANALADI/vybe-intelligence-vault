## Summary
Cloche is an open-source desktop screenshot CLI that captures any window or screen, frames the result as a polished presentation card, and outputs stable JSON for automation or AI agents. It supports Linux and Windows, works headless or via hotkeys, and includes optional MCP server integration.

## Key Features
- Captures active window, screen, or region with polished output
- Emits stable JSON for automation and AI agents
- Supports hotkey workflows and MCP server mode
- Generates share-ready presentation cards with metadata
- Cross-platform (Linux and Windows) with Rust-based implementation

## Why It Matters for RAG Builders
Cloche provides a reliable, headless way to generate polished screenshots and structured metadata for RAG pipelines and AI agents, bridging the gap between raw captures and agent-ready inputs.
