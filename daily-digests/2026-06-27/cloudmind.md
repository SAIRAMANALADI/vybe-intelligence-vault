## Summary
CloudMind is an open-source, Cloudflare-native personal AI memory system that enables users to store, process, and retrieve their own knowledge (URLs, notes, PDFs, etc.) in a searchable and answerable format. It leverages Cloudflare's serverless infrastructure for scalable, low-ops deployment.

## Key Features
- User-owned knowledge storage with BYOC (Bring Your Own Cloud) model
- Hybrid retrieval combining semantic search (Vectorize) and metadata filtering (D1)
- Library-grounded Q&A with source-aware responses
- Stateless MCP server for AI client integration
- Workflow-driven processing for normalization, chunking, embedding, and indexing

## Why It Matters for RAG Builders
CloudMind provides a critical, user-owned alternative to hosted knowledge SaaS, enabling RAG builders to deploy a private, scalable, and fully controllable memory layer on Cloudflare's serverless stack.
