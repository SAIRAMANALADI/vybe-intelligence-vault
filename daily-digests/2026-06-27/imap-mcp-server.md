## Summary
An MCP server providing secure IMAP email integration with encrypted credential storage, connection pooling, and comprehensive email operations for AI assistants and applications.

## Key Features
- Secure IMAP/SMTP email operations with encrypted credential storage (AES-256)
- Connection pooling for efficient IMAP account management
- Comprehensive email operations: search, read, send, move, mark, delete, and bulk operations
- Multi-account support with pre-configured settings for 15+ email providers
- Type-safe implementation with TypeScript and MCP compliance
