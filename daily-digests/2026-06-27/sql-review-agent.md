## Summary
An agentic AI system that reviews BigQuery SQL queries before execution to catch performance issues, estimate costs, and suggest optimizations. It integrates with LLMs, MCP clients, and provides CLI, web, and MCP-based interfaces for SQL review.

## Key Features
- Dry-run SQL queries to estimate cost without execution
- Schema-aware issue detection (partition filters, full scans, cartesian joins)
- Automated SQL rewrite suggestions with severity ratings
- Multi-modal interfaces (CLI, web UI, MCP server)
- Integration with LLM providers (Gemini, Claude) for intelligent analysis

## Why It Matters for RAG Builders
It automates SQL review for BigQuery, reducing costs and performance risks by catching issues before execution, which is critical for RAG pipelines relying on large-scale data processing.
