## Summary
ClawStash provides persistent storage for AI agents, enabling them to save, organize, and retrieve text, code, configs, and files across sessions via MCP or REST API. It includes features like full-text search, version history, GitHub backup, and a web GUI for manual management.

## Key Features
- Persistent storage for AI agents with session-spanning memory
- Full-text search and structured retrieval via tags and metadata
- Token-efficient MCP tools with lazy-loaded content
- Version history and diffable changes for all stored data
- GitHub backup integration for automated or manual mirroring

## Why It Matters for RAG Builders
ClawStash is essential for RAG builders as it provides a reliable, persistent storage layer for AI agents to manage and retrieve context across sessions, reducing token waste and enabling dynamic, long-term memory integration.
