## Summary
PaperCortex is a Windows-based local AI tool designed to organize, search, and extract data from documents in Paperless-ngx. It enables semantic search, auto-classification, receipt extraction, and DATEV accounting exports while maintaining full data privacy.

## Key Features
- Semantic search for documents by meaning, not just keywords
- Auto-classification of documents into predefined categories (invoices, receipts, contracts, etc.)
- Receipt data extraction (merchant, date, amount, tax, etc.)
- DATEV export for accounting workflows
- MCP server integration for Claude Code and local AI workflows

## Why It Matters for RAG Builders
PaperCortex streamlines document processing for RAG builders by providing a local, privacy-preserving way to organize, extract, and export structured data from unstructured documents.
