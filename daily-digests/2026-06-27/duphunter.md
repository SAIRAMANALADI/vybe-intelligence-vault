## Summary
duphunter is a desktop tool designed to identify near-duplicate Python code by analyzing code structure using Abstract Syntax Tree (AST) parsing. It helps developers and non-programmers clean up redundant code in Python projects through a user-friendly interface.

## Key Features
- AST-driven detection for structural code similarity analysis
- User-friendly GUI requiring no programming knowledge
- Detailed side-by-side comparison of duplicate code sections
- Fast scanning with exportable results (CSV/JSON)
- Supports exclusion lists and adjustable scan depth
