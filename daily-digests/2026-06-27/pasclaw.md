## Summary
PasClaw is an ultra-lightweight personal AI agent written in Delphi Object Pascal, offering a command-line assistant with tool calling, MCP integration, an HTTP gateway, and an OpenAI-compatible API. It supports multiple LLM providers, built-in tools, parallel dispatch, and persistent sessions with sandboxed safety features.

## Key Features
- Supports 19 LLM providers with fallback chains and streaming SSE
- Built-in sandboxed tools (filesystem, web search/fetch, memory, shell execution)
- MCP integration (stdio and Streamable HTTP) with hub fallback
- Persistent sessions with auto-compaction and working-state snapshots
- HTTP gateway with OpenAI-compatible API and embedded web UI

## Why It Matters for RAG Builders
PasClaw provides a lightweight, embeddable AI agent framework in Delphi with robust tooling and MCP support, making it ideal for developers needing a customizable, Pascal-based AI assistant.
