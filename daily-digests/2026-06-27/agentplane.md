## Summary
AgentPlane provides an operations control plane for AI agents to safely execute, validate, and audit infrastructure tasks like service restarts, deployments, and rollbacks with built-in planning, verification, and audit trails.

## Key Features
- AI-friendly command execution with natural language input
- Automated planning, validation, and rollback for operations
- Complete audit trails for all actions with timestamped records
- Secrets isolation and security-first design
- Extensible architecture with 5-domain model and projection model
