## Summary
Delx Wellness is an open-source registry of local-first Model Context Protocol (MCP) connectors that enable AI agents to access health and wellness data from wearables, nutrition trackers, and other devices without data leaving the user's machine. It provides a unified interface for integrating sleep, HRV, workouts, food intake, and more into AI workflows.

## Key Features
- Registry of open-source MCP servers for health and wellness data sources
- Supports zero-credential quick starts (e.g., Nourish, Cycle Coach)
- Auto-detects and composes multiple connectors via `delx-living-body`
- Local-first and read-only to ensure data privacy
- Modular design allowing independent connector installation and updates

## Why It Matters for RAG Builders
Delx Wellness provides a critical bridge for AI agents to securely and privately access real-time health and wellness data from diverse sources, enabling more personalized and context-aware interactions.
