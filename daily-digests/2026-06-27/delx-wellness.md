## Summary
Delx Wellness is a registry of open-source Model Context Protocol (MCP) servers that enable AI agents to securely access local-first health and wellness data from wearables, nutrition trackers, and other devices without data leaving the user's machine.

## Key Features
- Registry of open-source MCP connectors for wearables, nutrition, recovery, and training data
- Local-first architecture ensuring zero data leaves the user's machine
- Supports OAuth 2.0 and local file-based authentication for seamless integration
- Auto-detection and composition of multiple connectors via `delx-living-body` for unified agent access
- Comprehensive documentation and quick-start guides for various health data sources

## Why It Matters for RAG Builders
Delx Wellness provides essential local-first connectors that enable AI agents to securely access real-time health and wellness data, making it critical for building context-aware RAG systems in personal wellness applications.
