## Summary
An end-to-end autonomous data analysis agent that transforms natural language goals into complete data analysis workflows, including data acquisition, cleaning, exploration, modeling, visualization, report generation, and self-review validation.

## Key Features
- Goal-driven analysis converting natural language into executable tasks
- Multi-agent collaboration with specialized roles (Planner, Data, Cleaner, Analyst, Visualizer)
- Automated data cleaning, exploration, and modeling with method selection
- Self-review validation ensuring analysis reliability and traceability
- Skill persistence for reusing and replaying analysis workflows
