## Summary
Codra is an open-source, local-first AI coding agent designed for real software engineering tasks. It enables developers to run supervised AI agents locally, plan and execute code changes, verify results, and interact with browsers—all while maintaining full control over their codebase and environment.

## Key Features
- Local-first execution with direct filesystem and terminal access
- Planner → Executor → Verifier → Repair loop with human approval checkpoints
- Git integration for version control and change tracking
- Multi-provider support (Ollama, OpenAI-compatible, mock)
- MCP server integration for extended tooling and skills

## Why It Matters for RAG Builders
Codra provides a transparent, local-first alternative to cloud-based AI coding agents, empowering developers to build, inspect, and trust AI-driven software engineering workflows within their own environments.
