## Summary
Sleepwalker provides AI Visibility and Content Intelligence tools to help teams monitor how AI systems reference their brand and identify content gaps. It enables running AI-search checks, inspecting citations, scoring content, and saving results across multiple platforms like ChatGPT, Perplexity, Grok, and Gemini.

## Key Features
- Multi-platform AI search checks (ChatGPT, Perplexity, Grok, Gemini)
- Content scoring and trend analysis for SEO and brand monitoring
- MCP server for agent integrations (e.g., Claude)
- CLI and API for automation and scripting
- Centralized workspace for storing and reviewing results

## Why It Matters for RAG Builders
Sleepwalker enables RAG builders to monitor and optimize how their content is referenced by AI systems, ensuring accuracy and visibility in AI-driven search results.
