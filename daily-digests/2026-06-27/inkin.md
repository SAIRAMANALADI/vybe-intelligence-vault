## Summary
InkIn is a web application that transforms photos into artistic styles like comics, anime, watercolor, or oil paintings using AI-powered APIs. It provides a user-friendly interface for uploading images and generating stylized outputs with minimal configuration.

## Key Features
- Supports multiple AI APIs (OpenAI, Doubao, Qwen, GLM, etc.) with OpenAI-compatible formats
- Local-first operation with optional API-based processing
- Drag-and-drop interface for seamless user experience
- Multiple artistic styles (anime, watercolor, oil painting, cyberpunk, etc.)
- Responsive design with Vue 3 frontend and Flask backend
