## Summary
llmtest-perf is a performance testing tool designed to validate and compare LLM inference systems under load, focusing on latency, throughput, and regression detection. It provides repeatable test cases and CI/CD integration for Windows users.

## Key Features
- Run performance checks for LLM inference systems
- Compare current results with earlier runs for regression detection
- Track response time, throughput, and latency metrics
- Support Python-based testing with pytest and PyTorch
- Designed for Windows with simple setup and execution
