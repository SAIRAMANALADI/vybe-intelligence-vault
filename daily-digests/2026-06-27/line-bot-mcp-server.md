## Summary
A Model Context Protocol (MCP) server implementation that bridges LINE Messaging API with AI agents, enabling seamless integration of LINE Official Account messaging capabilities into AI workflows. It provides tools for sending text/flex messages, managing rich menus, and retrieving user profiles or follower lists.

## Key Features
- Supports sending text and highly customizable flex messages via LINE
- Provides tools for managing rich menus (create, delete, set default)
- Enables retrieval of user profiles, follower IDs, and message quotas
- Offers both direct messaging and broadcast capabilities
- Compatible with MCP-compatible AI agents like Claude Desktop or Cline

## Why It Matters for RAG Builders
It enables AI agents to interact directly with users via LINE, a widely used messaging platform, expanding the reach and functionality of RAG systems in real-world applications.
