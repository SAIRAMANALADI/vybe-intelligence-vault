## Summary
Jean2 is a persistent, autonomous AI agent server that runs locally on your machine, connects to any LLM, and executes tasks without interruption. It features goal-driven workflows, persistent memory, self-programming skills, and browser automation, with support for multiple models and MCP integration.

## Key Features
- Persistent 24/7 server with no telemetry or vendor lock-in
- Goal Mode with real-time evaluator for autonomous task completion
- Persistent memory and self-programming skills via SKILL.md files
- Parallel workflows with subagent orchestration for efficiency
- Browser automation and MCP server integration for real-world tasks

## Why It Matters for RAG Builders
Jean2 provides a self-hosted, autonomous AI agent framework that prioritizes data privacy and customization, making it ideal for RAG builders who need persistent, tool-driven agents with full control over memory and behavior.
