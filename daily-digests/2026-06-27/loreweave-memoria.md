## Summary
LoreConvo enables persistent, cross-surface memory for AI assistants like Claude, ensuring continuity of context across devices, sessions, and time. It transforms ephemeral conversations into a living narrative with encrypted journaling, selective recall, and multi-platform sync.

## Key Features
- Cross-device and cross-session memory persistence for AI assistants
- Encrypted Lore Journal with selective redaction and retention controls
- Multi-platform support (desktop, mobile, web, API endpoints)
- Integration with Claude and OpenAI APIs for hybrid workflows
- Automated diagnostics and self-healing sync mechanisms

## Why It Matters for RAG Builders
LoreConvo eliminates the need for AI assistants to restart from scratch, enabling seamless continuity of context across all user interactions and surfaces, which is critical for RAG systems requiring long-term memory integration.
