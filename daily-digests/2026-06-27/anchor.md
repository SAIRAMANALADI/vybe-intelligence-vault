## Summary
Anchor is a local-first MCP-compatible memory tool that indexes GitHub PR history, local code, tests, regressions, and architecture patterns to provide AI coding agents with evidence-backed context for safer code changes. It enables agents to access repo and org memory without SaaS dependencies or telemetry.

## Key Features
- Indexes GitHub PR history, review comments, and commits for evidence-backed context
- Local codebase indexing with symbols, tests, and architecture patterns stored in SQLite
- Cross-repo impact analysis to understand blast radius of changes
- MCP-compatible tooling for seamless integration with AI coding agents (Cursor, Claude Code, VS Code, etc.)
- Privacy-focused with read-only GitHub access and no telemetry or SaaS dependencies

## Why It Matters for RAG Builders
