## Summary
NeonDeck is a hybrid web-based IDE that combines a browser-based UI with a daemon node for executing code, files, and Docker containers. It enables secure, agent-driven coding workflows with sandboxed environments and WebSocket communication.

## Key Features
- Hybrid architecture with browser UI and daemon node for secure execution
- Sandboxed Docker containers with strict resource limits and read-only filesystems
- Central agent proxy that securely handles provider API keys (never exposed to browser)
- Live preview and file management integrated into a three-panel IDE
- Supports headless deployment on servers like Raspberry Pi 5 for production use

## Why It Matters for RAG Builders
NeonDeck provides a secure, scalable environment for running AI agents and code execution in a sandboxed manner, critical for building trustworthy RAG systems.
