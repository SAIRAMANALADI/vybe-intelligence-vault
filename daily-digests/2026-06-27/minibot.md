## Summary
MiniBot is a lightweight, local-first coding agent prototype designed for auditable, deterministic execution of AI-driven code modifications and debugging tasks. It emphasizes structured tool calls, context management, layered memory, recovery mechanisms, and benchmark-driven validation for reliable agent workflows.

## Key Features
- ReAct-style tool calling with structured protocol and schema validation
- Layered memory system (working, relevant, stable, pending) with non-blocking extraction
- Deterministic benchmark harness for regression testing and evaluation
- Provider-aware prompt caching and context compression for efficiency
- Built-in permission pipeline and workspace safety boundaries to prevent path escapes
