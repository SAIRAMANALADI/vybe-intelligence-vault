## Summary
designer-skill-mcp is a plug-and-play Model Context Protocol (MCP) server that enhances AI agents with UI design capabilities, including intent dispatching, reference files, and anti-slop quality checks. It enables agents to generate, refine, and validate UI code with minimal configuration.

## Key Features
- Plug-and-play MCP server with zero-config setup for AI agents
- Intent dispatching for vague design requests (e.g., 'make it pop')
- 15+ reference files covering typography, color, motion, accessibility, and anti-slop rules
- 44-rule deterministic detector for catching generic or flawed UI before deployment
- Seamless integration with Claude Code, Codex, Cursor, VS Code, and other AI coding environments

## Why It Matters for RAG Builders
It provides AI agents with structured design guidance and quality gates, ensuring generated UI is both aesthetically sound and technically robust without requiring manual oversight.
