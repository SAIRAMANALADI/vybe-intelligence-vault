## Summary
Agent Nexus is a self-hosted, model-agnostic AI agent orchestration platform that enables users to build, deploy, and observe AI agents with support for multiple LLMs, tools, and multi-agent workflows. It provides full observability, memory management, and RAG capabilities for enterprise-grade AI applications.

## Key Features
- Model-agnostic agent builder with support for Anthropic, OpenAI, Gemini, and Ollama
- Visual workflow canvas for designing multi-agent pipelines and supervisor hierarchies
- Layered memory system with pgvector embeddings and RAG connectors (Filesystem, GitHub, Confluence)
- Full run traces, cost tracking, and observability with latency distribution metrics
- Risk-based tool approval gates, MCP server integration, and webhook triggers for automation

## Why It Matters for RAG Builders
Agent Nexus provides a comprehensive, self-hosted platform for building and deploying AI agents with advanced RAG, multi-agent workflows, and full observability, eliminating vendor lock-in while ensuring data privacy and control.
