## Summary
A Windows desktop application that monitors and classifies Telegram messages using AI, providing a React-based dashboard for real-time tracking, filtering, and analysis of message categories like spam, important, questions, and normal messages.

- AI-powered classification into spam, important, question, and normal categories
- React-based dashboard for visualizing and managing messages
- Local Windows desktop application with easy setup and configuration
- Support for OpenAI-compatible LLM APIs for message sorting
