## Summary
rag-ready-extractor is a desktop application that cleans and structures messy content from websites and PDFs into token-optimized, importance-scored data for RAG pipelines. It requires no programming skills and outputs data in JSON or CSV formats.

## Key Features
- Extracts and cleans text from PDFs and websites
- Assigns semantic importance scores to content
- Tokenizes data for efficient RAG pipeline integration
- Supports batch processing and multiple output formats (JSON, CSV)
- User-friendly GUI with no coding required

## Why It Matters for RAG Builders
It streamlines the critical preprocessing step for RAG pipelines by transforming raw documents into clean, token-optimized data ready for vector databases and AI models.
