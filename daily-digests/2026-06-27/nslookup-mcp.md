## Summary
nslookup-mcp is a Windows application that simplifies DNS record lookups, propagation checks, and certificate monitoring via nslookup.io. It provides a user-friendly GUI for DNS-related tasks and integrates as an MCP server for programmatic access.

## Key Features
- Performs DNS record lookups (A, AAAA, MX, TXT, NS)
- Checks DNS propagation status after changes
- Monitors SSL/TLS certificate validity
- Acts as an MCP server for integration with other AI tools
- Provides clean, readable output for quick analysis
