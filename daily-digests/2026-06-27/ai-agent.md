## Summary
Zetryn Trading is an open-source AI agent framework designed for autonomous memecoin trading on Solana. It combines hard-rule guardrails with LLM-driven analysis to generate auditable trading decisions, while allowing developers to extend functionality via knowledge packs and tools.

## Key Features
- Hybrid decision-making with hard-rule guardrails and LLM analysis for auditable trading decisions
- Two agents: Scanner (slow, LLM-driven) and Sniper (fast, rule-based with optional LLM audit)
- Knowledge vs Skills system for extensibility without framework forks
- Multi-provider LLM failover and throttling via KeyPool and LLMRouter
- Reflective learning from past decisions to improve future outcomes

## Why It Matters for RAG Builders
It provides a structured, auditable framework for integrating LLMs into trading decisions while balancing speed and safety, making it valuable for AI-driven trading systems.
