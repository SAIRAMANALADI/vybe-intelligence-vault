## Summary
Wellness Nourish is a local-first Model Context Protocol (MCP) server for nutrition tracking, enabling AI agents to perform food search, barcode lookup, meal logging, hydration tracking, and personalized coaching without requiring OAuth or exposing data externally.

## Key Features
- Local-first MCP server with no external token exposure or OAuth requirements
- Comprehensive nutrition tools: food search, barcode lookup, meal logging, hydration tracking, and daily/weekly summaries
- Support for photo-assisted meal estimation and barcode image decoding via ZXing
- Brazilian food catalog (pt-BR) and carbon-aware nutrition summaries
- CLI and MCP client integration with ready-to-use examples for popular editors (Claude, Cursor, ChatGPT)

## Why It Matters for RAG Builders
Wellness Nourish provides a privacy-preserving, local-first nutrition layer that AI agents can integrate to enable context-aware dietary tracking and coaching without compromising user data security.
