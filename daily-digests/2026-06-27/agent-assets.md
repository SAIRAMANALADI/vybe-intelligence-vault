## Summary
A VS Code-native customization kit that transforms GitHub Copilot into a project-level Directly Responsible Individual (DRI) with enforceable, spec-driven workflows, 14-surface audits, and three-Gate governance. Designed for Chinese-first workflows but includes English documentation for broader adoption.

## Key Features
- Enforces project-level DRI (Directly Responsible Individual) role for Copilot with strict governance gates
- 14-surface audits for comprehensive project health checks (documentation, data, architecture, security, compliance)
- Three-Gate decision system (Strategy, Critical Design, Real-World Side Effects) to limit user intervention to critical decisions only
- 60+ semantic skills for automated workflows (specs writing, execution, project stewardship, bug audits, root cause analysis)
- Zero-install, clone-and-use approach with VS Code native integration (AGENTS.md, .github/instructions/, .vscode/settings.json)

## Why It Matters for RAG Builders
It provides a structured, auditable framework to turn Copilot into a disciplined project steward, reducing drift and ensuring compliance with engineering standards while maintaining flexibility for critical decisions.
