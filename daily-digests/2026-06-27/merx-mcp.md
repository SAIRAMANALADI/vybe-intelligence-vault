## Summary
merx-mcp is a Windows-based MCP server that enables AI agents to interact with the TRON blockchain by providing tools for token transfers, balance checks, token swaps, and resource management (energy/bandwidth). It simplifies TRON operations for agents through a configurable, local server setup.

## Key Features
- 55+ TRON-specific tools for AI agents
- Supports USDT, TRX transfers, and token swaps
- Transaction simulation to validate actions before execution
- Energy and bandwidth resource optimization for TRON operations
- Simple config-based setup for quick deployment
