## Summary
Iva is a personal AI agent that operates within Telegram, offering long-term memory, voice/video transcription, and task management. It runs on a user-owned server with minimal setup, prioritizing privacy and self-hosted control over AI interactions.

## Key Features
- Long-term memory structured as a hierarchical tree (leaves, branches, trunk) for efficient recall and organization
- One-command installation with minimal configuration required
- Supports voice/video transcription via Deepgram and open models (DeepSeek, Kimi, GLM)
- Self-hosted with memory stored in plain Markdown files and backed up via Git
- Customizable personality and rules directly in the chat interface

## Why It Matters for RAG Builders
Iva provides a privacy-focused, self-hosted personal AI agent with long-term memory that can be deployed in minutes, reducing reliance on third-party services while maintaining high functionality.
