## Summary
ChatCrystal is a local-first AI Personal Knowledge Management (PKM) application designed to organize, search, and reuse AI coding conversations. It distills scattered AI interactions into structured notes, supports semantic search, and exposes MCP tools for agent integration.

## Key Features
- Imports and distills AI coding conversations into structured notes with titles, summaries, and tags
- Semantic search with embeddings and relation-aware result expansion for efficient knowledge retrieval
- Tag-based knowledge graph for visualizing co-occurrence relationships between knowledge points
- CLI and MCP tools for agent integration, enabling reusable AI work memory
- Local-first deployment with configurable LLM and embedding providers

## Why It Matters for RAG Builders
ChatCrystal provides a structured, searchable, and reusable memory system for AI coding conversations, enabling agents to leverage past interactions for improved context and efficiency.
