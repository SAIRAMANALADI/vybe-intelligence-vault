## Summary
email-design-mcp is a Windows-based tool that enables users to design, generate, and export responsive email templates using AI assistance without requiring API keys. It leverages MJML for responsive email design and integrates with AI assistants like Claude and Cursor for content generation.

## Key Features
- AI-powered email content generation with Claude and Cursor integration
- Responsive email templates using MJML for cross-device compatibility
- Local MCP server for seamless AI and template handling without API keys
- Brand-aware tools for consistent email design and editing
- Visual editor with live preview for real-time adjustments
