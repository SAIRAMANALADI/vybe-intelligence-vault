## Summary
ui-style-extractor is a Windows desktop application that converts existing UI pages into reusable style guides and validation demos by extracting design elements like colors, fonts, spacing, and layout rules into Markdown files.

## Key Features
- Extracts colors, fonts, spacing, and layout rules from UI pages
- Generates reusable Markdown style guides and validation demos
- Supports local HTML files and live web pages as input
- Creates comparison demos for AI-generated pages
- Provides structured output for design consistency checks

## Why It Matters for RAG Builders
It enables AI engineers to quickly capture and validate UI design systems, ensuring consistency when generating or modifying pages.
