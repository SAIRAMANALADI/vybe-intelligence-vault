## Summary
gws-os is a Windows-based tool that integrates Google Workspace (Gmail, Calendar, Drive) into a unified interface with a memory system to track relevance, trust, and patterns across accounts. It is designed for learning-first workflows and integrates with Claude Code for AI-driven task automation.

## Key Features
- Unified interface for Gmail, Calendar, and Drive across multiple Google accounts
- Memory system using CAR Protocol to track relevance, trust, and patterns
- Built-in CLI for automation and integration with Claude Code
- Local-first learning flow to improve task prioritization over time
- Trust progression and relevance scoring for smarter content surfacing
