## Summary
A Windows desktop application that enables local semantic search for documents using embeddings and vector similarity, designed to integrate with MCP clients for AI-driven document retrieval without cloud dependency or API keys.

## Key Features
- Local semantic search for documents without cloud dependency
- Integration with MCP clients for AI-driven retrieval
- Supports multiple file formats (PDF, TXT, Markdown, DOCX, HTML, code files)
- Privacy-focused with no API keys or cloud access required
- Automatic indexing and re-indexing for updated documents

## Why It Matters for RAG Builders
It provides a privacy-preserving, offline-capable semantic search tool that integrates seamlessly with MCP clients, enabling RAG systems to retrieve local documents without exposing sensitive data to the cloud.
