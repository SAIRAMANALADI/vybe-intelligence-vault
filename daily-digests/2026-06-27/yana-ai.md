## Summary
Yana AI is a personal agent operating system designed as an orchestration layer between humans and AI coding tools, providing runtime safety hooks, context routing, and security gates to intercept and validate AI actions before execution.

## Key Features
- 9-layer gate system for intercepting and validating AI actions before execution
- 1,980 pre-defined skills and 97 specialist agents for task routing and specialization
- Rust-based runtime (yana-rt) for vulnerability scanning and supply chain protection
- Memory tiers with Merkle-chained integrity checks to prevent tampering
- Integration with 15+ AI coding tools (Claude Code, Cursor, GitHub Copilot, etc.)
