## Summary
remote-collab-agents enables multi-machine collaboration by allowing Claude Code agents to coordinate across Windows PCs for remote command execution, file synchronization, and distributed task workflows. It simplifies setup with tools like Tailscale, Syncthing, and SSH to link machines into a unified system.

## Key Features
- Enables three machines to operate as a single collaborative team for code execution and file management
- Uses Tailscale for secure, private network connectivity between machines
- Integrates Syncthing for real-time file synchronization across shared folders
- Supports SSH for remote command execution and task delegation
- Provides a structured workflow with input, working, output, and logs folders for organized collaboration
