## Summary
Codex Pooler is a self-hosted gateway that acts as a stable intermediary for Codex-compatible agents, tools, and automation, enabling credential isolation, client normalization, and routing across multiple upstream Codex accounts while providing a unified Pool API key for clients.

## Key Features
- Stable Pool API keys for credential isolation and client normalization
- Eligibility-aware routing based on model support, quota, health, and policy
- OpenAI-compatible SDK surface for seamless integration with existing tools
- Session-aware websockets for resumable Codex sessions without HTTP translation
- Operator dashboard for managing Pools, accounts, API keys, and usage analytics
