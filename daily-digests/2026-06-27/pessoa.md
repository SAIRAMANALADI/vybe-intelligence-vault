## Summary
Pessoa is a local, LLM-agnostic AI agent infrastructure blueprint designed for pragmatic deployment of open-source models (e.g., Gemma) with localized system prompts. It enables EU-based teams to achieve data privacy and performance without relying on sovereign foundation models.

## Key Features
- LLM-agnostic architecture allowing seamless model switching (e.g., Ollama to vLLM)
- Decoupled memory layer (mem0 + Qdrant) for persistent, scalable context
- Multi-modal agent capabilities via FastAPI and FastMCP for API/MCP integrations
- Local-first deployment with Portuguese system prompts for language enforcement
- Modular persona system using Claude Skills for dynamic role specialization
