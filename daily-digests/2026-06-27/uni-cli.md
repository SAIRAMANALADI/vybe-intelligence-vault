## Summary
Uni-CLI is a universal agent control plane for real software, enabling agents to interact with computers through governed, policy-driven operations across websites, browsers, desktop apps, local tools, and agent protocols. It provides a unified runtime for intent-based automation with evidence tracking and self-repair capabilities.

## Key Features
- Unified agent-to-computer control loop with intent-based operation discovery and execution
- Policy-gated execution modes (open, confirm, locked) for safe automation
- AgentEnvelope v2 output format with data, context, retryability, and evidence hooks
- Multi-substrate support: web, browser, desktop, local tools, files, and agent protocols
- Built-in repair and delivery mechanisms for objective-level failure diagnosis and rerouting

## Why It Matters for RAG Builders
Uni-CLI provides a critical control surface for AI agents to safely and reliably interact with real software environments, bridging the gap between agent intent and governed computer-use automation.
