## Summary
OwnPlanner is an AI-powered personal planning assistant that integrates with Google Gemini to manage tasks, notes, and organization through intelligent conversation. It supports multiple interfaces including a React-based web app, CLI, and MCP tools for automation.

## Key Features
- Layered .NET architecture for maintainability and testability
- Multi-interface support (Web, CLI, MCP tools) for flexible interaction
- Google Gemini API integration for intelligent task and note management
- Per-user SQLite databases for data isolation and security
- Automated testing and CI/CD with Docker image publishing
