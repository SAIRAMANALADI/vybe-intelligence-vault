## Summary
Piyaz is an agentic workspace designed to enable seamless collaboration between humans and AI coding agents on software projects. It replaces repetitive context briefings by maintaining a shared, evolving project knowledge graph that tracks tasks, decisions, dependencies, and execution history.

## Key Features
- Shared project context network for humans and AI agents, eliminating repetitive briefings
- End-to-end task orchestration via the Composer workflow (Claude Code only), automating research, planning, implementation, and review
- Dynamic task decomposition and dependency management with real-time graph updates
- Multi-agent plugin system for Claude Code, Codex, Cursor, and Antigravity with unified MCP tools
- Self-hostable under AGPL-3.0 with versioned migrations for seamless upgrades

## Why It Matters for RAG Builders
Piyaz eliminates the overhead of re-explaining project context to AI agents by maintaining a living knowledge graph, enabling truly autonomous and collaborative AI-driven software development.
