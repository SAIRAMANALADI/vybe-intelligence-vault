## Summary
FindJobs-Agent is a full-stack job search assistant that automates job board crawling, resume parsing, LLM-powered job analysis, and AI mock interviews. It integrates multiple components into a cohesive workflow to streamline job hunting and interview preparation.

## Key Features
- Multi-source job crawling from major tech companies with API and Selenium support
- LLM-driven job analysis for extracting requirements, skills, and classifications
- Resume parsing and matching with skill scoring and percentage-based fit calculation
- AI mock interview generation and simulation with real-time feedback
- React-based frontend for seamless user interaction and workflow integration

## Why It Matters for RAG Builders
It provides an end-to-end automated pipeline for job seekers to efficiently match resumes to job postings and prepare for interviews using AI, reducing manual effort and improving accuracy.
