## Summary
yeti-agent is a Windows desktop application that automates browser tasks using AI agents, enabling users to run repeatable web interactions like form filling, data extraction, and login automation without coding. It leverages the Chrome DevTools Protocol (CDP) to control Chrome and integrate with AI providers like OpenAI, Anthropic, or Gemini.

## Key Features
- Runs AI-driven browser tasks 24/7 without manual intervention
- Integrates with major AI providers (OpenAI, Anthropic, Gemini) for task execution
- Uses Chrome DevTools Protocol (CDP) for precise browser control and interaction
- Supports Windows with a simple GUI for task setup and monitoring
- Enables automation of repetitive web tasks like form filling, data checks, and logins
