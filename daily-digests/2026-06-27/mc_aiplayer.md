## Summary
AIBot is an autonomous AI agent for Minecraft that uses a large language model (LLM) like DeepSeek to interpret natural-language commands and execute complex tasks such as mining, building, farming, and surviving in a real-world Minecraft environment. It operates as a server-side Fabric mod for Minecraft 1.21.3.

## Key Features
- Natural-language goal interpretation via LLM (DeepSeek or OpenAI-compatible models)
- Hybrid architecture: LLM plans, deterministic task engines execute with 36 state machines
- Full survival loop including mining, crafting, farming, combat, and survival mechanics
- Real-terrain reliability with multi-seed verification and safety nets for threats like drowning or lava
- In-game control panel for monitoring and interaction

## Why It Matters for RAG Builders
