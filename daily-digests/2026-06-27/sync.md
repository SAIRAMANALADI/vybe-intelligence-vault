## Summary
Sync is a desktop application that provides project management and quality control for AI agents, ensuring they adhere to defined specifications, constraints, and roadmaps without hallucinations or deviations. It acts as a governance layer to maintain consistency and accountability in agent-driven workflows.

## Key Features
- Enforces agent adherence to structured project specs, constraints, and decisions to prevent hallucinations or architectural drift.
- Built-in MCP server for seamless integration with AI agents like Claude Code, Cursor, and Zed.
- Advanced widget system for visualizing project state, tracking agent activity, and interacting with the system via dynamic UI elements.
- Automated quality gates that flag stale context, forcing agents to pause and seek approval before proceeding.
- Multi-project management with a Project Hub for organizing, switching, and steering projects or workspaces.

## Why It Matters for RAG Builders
