## Summary
vibe-editor is a desktop application that acts as a multi-agent dispatcher for AI coding tools like Claude Code and Codex. It enables users to dynamically recruit teams of AI agents, manage them in real-time via an infinite canvas, and oversee their collaborative work through a Tauri-based UI.

## Key Features
- Dynamic team recruitment and management of up to 30 AI agents with real-time message injection via embedded MCP hub
- Infinite canvas mode for spatial organization of agents, files, diffs, and terminals
- Built-in editor, git diff viewer, file tree, and session history for seamless review and collaboration
- Silent auto-updater and cross-platform support (Windows, macOS, Linux)
- Self-installing vibe-team Skill for standardized agent protocols and behaviors

## Why It Matters for RAG Builders
It streamlines multi-agent AI workflows by providing a unified, real-time control room for orchestrating and monitoring collaborative coding tasks, reducing terminal chaos and improving productivity.
