## Summary
PaulusAI is an autonomous digital companion with persistent multi-store memory, an affective (emotional) system, continuous learning, and tool-based interaction. It operates as either an interactive terminal chat or a Telegram bot, supporting multiple LLM providers and local models like Ollama.

## Key Features
- Multi-store memory system with episodic and semantic components, including vector embeddings and keyword fallback
- Functional affective system using PAD (pleasure/arousal/dominance) mood driven by an OCC appraisal engine
- Continuous learning with memory consolidation, skill distillation, and salience-based forgetting
- Pluggable sandbox for safe tool execution (local, Docker, or SSH) with high-impact action approval gates
- Provider-agnostic LLM integration via LiteLLM, supporting Anthropic, OpenAI, Gemini, OpenRouter, and local models

## Why It Matters for RAG Builders
PaulusAI provides a robust framework for building autonomous agents with persistent memory, emotional systems, and secure tool integration, essential for advanced RAG and AI agent architectures.
