## Summary
IntentCtrl provides an embedded AI runtime for React applications, enabling real-time AI assistants with streaming chat, tool integration, and session management. It allows developers to embed AI-powered chat interfaces with customizable tools and permissions directly into their web apps.

## Key Features
- Real-time streaming chat with AI responses via a React hook
- Page-aware AI that understands the current UI context
- Built-in and custom tool integration with typed inputs (Zod schemas)
- Granular permissions and approval workflows for sensitive actions
- Persistent session management for seamless user experiences

## Why It Matters for RAG Builders
IntentCtrl simplifies embedding AI assistants into React apps with minimal setup, making it essential for developers building interactive AI-driven user interfaces.
