## Summary
A production-grade AI code review and agent orchestration system that automates PR reviews, routes LLM tasks based on criticality, and exposes technical Q&A via API and Telegram. It integrates with Bright Data's web scraping tools and Oracle Autonomous DB for persistence.

## Key Features
- Automated PR and push code reviews with deterministic security/complexity checks
- Dynamic LLM routing (Claude Opus 4 for critical tasks, Groq Llama for standard reviews)
- Persistent technical memory in Oracle Autonomous DB for context-aware responses
- Telegram and API interfaces for real-time technical Q&A and research tasks
- Integration with Bright Data's web scraping tools for autonomous research agent capabilities
