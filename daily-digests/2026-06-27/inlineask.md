## Summary
InlineAsk is a browser extension that enables users to select text on any webpage and instantly ask AI questions about it without leaving the page or switching tabs, streamlining research and learning workflows.

## Key Features
- Instant AI question answering from selected text on any webpage without tab switching
- Streaming responses for real-time feedback and minimal latency
- Supports multiple AI providers (OpenAI, Claude, Qwen, MiniMax, local models)
- Privacy-focused with direct API calls (no third-party data exposure)
- Keyboard shortcuts and draggable UI for seamless workflow integration

## Why It Matters for RAG Builders
InlineAsk eliminates context-switching overhead for RAG builders by enabling instant, in-place AI queries directly from selected text, significantly improving research and documentation workflows.
