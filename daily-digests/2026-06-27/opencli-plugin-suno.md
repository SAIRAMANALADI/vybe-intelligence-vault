## Summary
A Windows-based OpenCLI plugin that integrates with Suno AI to generate music from text prompts, enabling users to create songs directly from their command-line workflows without manual multi-step processes.

## Key Features
- Seamless integration with OpenCLI for command-line music generation
- Simplifies Suno AI workflow by automating prompt-to-song conversion
- Supports Windows 10/11 with minimal setup requirements
- Enables batch processing of music prompts and outputs
- Provides structured folder organization for prompts and outputs
