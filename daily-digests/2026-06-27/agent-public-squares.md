## Summary
Agent Public Squares (APS) is a tool that enables multiple users working on the same project to hand off tasks to each other's local AI agents via a shared Google Drive. It facilitates clear, trackable task exchanges with versioning, status tracking, and collaboration workflows tailored for AI-driven development environments.

## Key Features
- Enables task handoff between local AI agents via shared Google Drive folders
- Provides structured, versioned handoff packages with clear status tracking
- Supports one-to-one task exchanges with explicit recipient assignment
- Includes local quality checks and validation commands for reliability
- Designed for controlled trials and collaborative workflow refinement

## Why It Matters for RAG Builders
APS streamlines task handoffs between AI agents in collaborative projects, reducing ambiguity and improving traceability in multi-user workflows.
