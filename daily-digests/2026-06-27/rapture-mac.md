## Summary
Rapture for Mac is a menu-bar macOS app that captures Siri-dictated iMessages as timestamped .txt files in a user-selected folder, enabling seamless integration with any AI assistant or agent system. It operates locally with zero outbound network traffic, requiring only macOS permissions for Full Disk Access and Messages automation.

## Key Features
- Captures Siri-dictated iMessages as timestamped .txt files without unlocking the iPhone
- Zero outbound network traffic; vendor-neutral and privacy-focused
- Integrates with any AI assistant or agent via a simple folder interface
- Auto-updates with notarized DMG releases and EdDSA signature verification
- Provides starter configs for popular AI tools like Claude Code, OpenClaw, and Hermes

## Why It Matters for RAG Builders
It provides a hands-free, local-only pipeline for capturing voice-dictated thoughts from iMessages and converting them into structured text files, making it essential for RAG builders who need reliable, privacy-preserving input sources.
