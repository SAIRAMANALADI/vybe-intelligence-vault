## Summary
MindGenius AI is an AI agent that plans, reads PDFs, and generates editable mind maps in real-time with visible tool-calling loops. It supports multi-provider API keys (OpenAI, Claude, DeepSeek, Kimi) and offers a browser-based, self-hostable solution for interactive knowledge mapping.

## Key Features
- Real-time editable mind maps with surgical node edits (rename, delete, re-parent) without full re-renders.
- Built-in lightweight RAG for PDF ingestion and retrieval (chunking, embeddings, in-memory cosine search).
- Multi-step agent loop with visible tool-calling (Vercel AI SDK v5) for planning and execution.
- Bring-your-own-key architecture (OpenAI, Claude, DeepSeek, Kimi) with keys stored client-side only.
- Keyboard-first canvas with shortcuts (Tab, Enter, F2, Del) and import/export support (PNG, SVG, Markdown, OPML, Mermaid).

## Why It Matters for RAG Builders
MindGenius AI provides a production-ready agent framework with integrated RAG and mind mapping capabilities, enabling developers to build interactive, explainable AI workflows with minimal setup.
