## Summary
ragpipe is a Python tool designed to simplify the creation of retrieval-augmented generation (RAG) pipelines by providing three core functions: ingest(), query(), and pipe(). It enables users to process files, Git repositories, and web pages into vector data for search and chat workflows, supporting both local and hosted model setups.

## Key Features
- Simplified RAG pipeline setup with three core functions (ingest, query, pipe)
- Supports multiple content sources: files, Git repos, and web pages
- Compatible with local (Ollama) and hosted (OpenAI) models
- Works with Qdrant and Pinecone vector databases
- Uses YAML configs and CLI for easy setup and repeatable workflows

## Why It Matters for RAG Builders
ragpipe streamlines the creation of RAG pipelines by reducing manual setup, making it easier for developers to integrate document ingestion, vector storage, and querying into their AI workflows.
