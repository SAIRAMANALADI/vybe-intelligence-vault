## Summary
A Windows-based toolkit for federal contracting that automates the creation of key acquisition documents like IGCEs, SOWs, and PWSs, while integrating live data from federal sources such as USASpending, GSA CALC+, and BLS OEWS.

## Key Features
- Automated IGCE (Independent Government Cost Estimate) generation for FFP, T&M, and cost-reimbursement contracts
- SOW (Statement of Work) and PWS (Performance Work Statement) drafting tools with structured templates
- Live API integrations with USASpending, GSA CALC+, BLS OEWS, and other federal data sources
- Market research report generation for acquisition planning and file support
- Windows-native application with minimal setup requirements
