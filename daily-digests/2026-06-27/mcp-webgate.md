## Summary
mcp-webgate is a Windows application designed as an MCP server to facilitate web search with reduced context noise for AI agents. It enables AI apps to perform web searches while controlling the amount and format of data passed into the model's context.

## Key Features
- Acts as an MCP server for AI apps to perform web searches
- Filters and trims search results to reduce context noise
- Supports multiple search backends like Brave Search and SearxNG
- Easy setup with pre-built Windows executable
- Designed to integrate seamlessly with MCP-compatible AI applications

## Why It Matters for RAG Builders
It enables AI agents to perform web searches without overwhelming the model's context with raw HTML or excessive data, improving efficiency and relevance in RAG pipelines.
