## Summary
A persistent memory and context management system for AI coding assistants that enables session continuity, sprint tracking, decision logging, and knowledge base synchronization via the Model Context Protocol (MCP). Designed to work with major AI tools like Claude Code, Cursor, and OpenAI Codex.

## Key Features
- Persistent memory storage across sessions for AI assistants
- Sprint tracking and agile workflow integration
- Decision logging with Architecture Decision Records (ADR)
- 20 specialized MCP tools for context management
- Cross-platform support (Windows, macOS, Linux) with multilingual UI

## Why It Matters for RAG Builders
It solves the critical problem of AI assistants losing context between sessions, enabling continuous project awareness and reducing repetitive explanations for RAG and AI stack builders.
