## Summary
A Windows-native desktop application that enables fast, contextual semantic search over large text collections using vector embeddings and caching. Designed for non-technical users, it processes documents locally without requiring GPUs or cloud services.

## Key Features
- Semantic search using vector embeddings for contextual understanding
- Smart caching for fast retrieval of large text collections
- No GPU or cloud dependency; runs entirely on Windows CPUs
- Supports multiple document formats (.txt, .md, .csv)
- User-friendly interface requiring no technical expertise

## Why It Matters for RAG Builders
Provides a lightweight, local-first solution for building and querying vector-based text indexes, reducing dependency on cloud services for semantic search workflows.
