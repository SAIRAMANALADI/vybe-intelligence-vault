## Summary
uniTerm is a cross-platform terminal emulator with an integrated autonomous AI Agent that can plan and execute multi-turn shell commands, similar to Claude Code. It supports local shells, remote protocols (SSH, Telnet, Mosh), file transfers, remote desktop, databases, and real-time server monitoring in a unified interface.

## Key Features
- Autonomous AI Agent for multi-turn shell command execution with LLM integration (Anthropic/OpenAI-compatible)
- Comprehensive terminal support (SSH, Telnet, Mosh, Serial, Local, WSL) with file transfer and remote desktop capabilities
- Built-in database client (MySQL, PostgreSQL, rqlite) and real-time server monitoring
- Cross-platform deployment (Windows, macOS, Linux) with cloud sync for configurations
- Customizable workspace with split panes, themes, and internationalization (9 languages)
