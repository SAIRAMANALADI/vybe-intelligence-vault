## Summary
cli-in-wechat is a Windows application that bridges WeChat with command-line AI tools (e.g., Claude Code, Codex, Gemini) via the official iLink Bot API, enabling users to send prompts and receive AI-generated responses directly within WeChat.

## Key Features
- Seamless integration of WeChat with command-line AI tools
- Supports multiple AI models (Claude Code, Codex, Gemini, Kimi, OpenCode)
- Session synchronization and tool switching via iLink Bot API
- Simple setup with minimal configuration required
- Message routing between WeChat and AI tools

## Why It Matters for RAG Builders
It enables AI engineers to leverage WeChat as a unified interface for interacting with diverse command-line AI tools, reducing context-switching and improving productivity.
