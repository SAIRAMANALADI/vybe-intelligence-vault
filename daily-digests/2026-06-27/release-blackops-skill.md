## Summary
A Claude Code / AI skill that automates the process of assessing, testing, packaging, and publicly releasing any repository as a clean, self-contained artifact while scrubbing AI/Claude attribution from its git history.

## Key Features
- Eight-phase automated workflow for repo assessment, testing, packaging, and release
- DPI-safe screenshot capture for documentation
- Git history scrubbing to remove AI/Claude attribution markers
- Read-only batch assessment mode for multiple repos
- Self-contained skill with YAML frontmatter for agent integration

## Why It Matters for RAG Builders
It streamlines the process of turning raw AI-generated or experimental code into a clean, publishable release while ensuring attribution is properly managed, reducing manual effort and improving discoverability.
