## Summary
claude-code-boss-mode enhances Claude Code by adding a structured decision-making layer to evaluate tasks, plans, and pull requests from CEO, Engineering Manager (EM), and Product Manager (PM) perspectives. It helps users cut scope, assess risks, and make clearer choices before investing time in development.

## Key Features
- Three-layer decision framework (CEO, EM, PM) for evaluating tasks
- Commands like `/boss`, `/boss-pr`, `/boss-plan`, and `/boss-roast` for targeted reviews
- Blunt feedback to identify weak planning, overbuilt features, or risky changes
- Pre-work review to cut scope before coding begins
- Windows-native local tool for seamless integration with Claude Code

## Why It Matters for RAG Builders
It provides a structured way to validate AI-driven development tasks, reducing scope creep and improving decision quality before costly implementation.
