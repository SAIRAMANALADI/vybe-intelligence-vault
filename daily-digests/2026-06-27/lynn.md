## Summary
Lynn is an open-source desktop and CLI AI agent that combines a GUI-based conversation interface with a session map for task tracking, headless worker capabilities for parallel task execution, real-time voice interaction, and long-term memory. It supports local GGUF models (27B/35B) and integrates with external agents like Codex, Claude, and Qwen.

## Key Features
- Unified GUI and CLI interface with session-based task tracking and memory
- Headless worker mode for parallel task execution by external agents (Codex, Claude, Qwen)
- Real-time voice interaction via StepFun Realtime API
- Local GGUF model support (27B/35B) with optimized inference via llama.cpp
- Agent regression testing kit and contract-based task execution for CI/CD integration

## Why It Matters for RAG Builders
Lynn provides a robust framework for building and orchestrating AI agents with session-aware task management, real-time voice, and headless worker capabilities, making it essential for RAG builders who need structured agent workflows and long-term memory integration.
