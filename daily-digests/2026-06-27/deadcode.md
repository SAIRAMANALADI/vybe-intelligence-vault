## Summary
DeadCode is a CLI tool designed to detect and remove unused exports, dead routes, orphaned CSS, and unreferenced components in TypeScript, React, and Next.js projects. It helps developers optimize bundle size and maintain cleaner codebases.

## Key Features
- Detects unused exports, dead routes, orphaned CSS, and unreferenced components
- Supports TypeScript, React, and Next.js projects
- Safe auto-removal with `--dry-run` preview mode
- CI/CD integration with JSON output and fail thresholds
- Monorepo support and ignore patterns for large projects

## Why It Matters for RAG Builders
DeadCode helps RAG builders maintain lean, optimized codebases by identifying and removing unused code, reducing bundle sizes and improving performance.
