## Summary
PennyLearn is an AI-powered, self-hosted study companion that transforms how users interact with information by providing adaptive tutoring, personalized study plans, and seamless integration with productivity tools like calendars and todo lists.

## Key Features
- Adaptive tutoring with OpenAI and Claude API integration for personalized learning paths
- Contextual memory module that tracks user progress and adjusts study plans dynamically
- Multi-platform support including Telegram, web, and command-line interfaces
- Spaced repetition and flashcard creation for improved retention
- Integration with calendars, todo lists, and reservation systems for seamless life management
