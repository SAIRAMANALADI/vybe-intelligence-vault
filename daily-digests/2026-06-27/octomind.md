## Summary
Octomind is an open-source runtime for deploying specialist AI agents with zero-config flexibility. It enables one-command agent deployment across any domain, model, or MCP server, while providing adaptive context management, cost control, and policy-based guardrails.

## Key Features
- Zero-config agent deployment with community-driven specialist agents
- Adaptive context compaction for long-running sessions
- Per-step model selection and hard spending caps
- Guardrails and hooks as policy-as-code for deterministic safety
- Intent-driven context activation to minimize tool bloat

## Why It Matters for RAG Builders
Octomind streamlines the deployment of specialized AI agents, reducing setup time from 45 minutes to seconds while ensuring cost control and safety through policy-as-code, making it essential for scalable RAG and AI agent systems.
