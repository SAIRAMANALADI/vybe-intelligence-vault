## Summary
Mobilecode-open is an open-source iOS companion app for opencode, enabling users to remotely pilot an opencode serve instance from their iPhone with a live, continuous-link feel. It is fully self-hosted, auditable, and designed to keep all code, credentials, and conversations private within the user's own infrastructure.

## Key Features
- Direct integration with opencode serve for remote code agent control
- Two customizable skins (Matrix and OpenCode) with toggleable effects
- Live updates via SSE with adaptive polling and local notifications
- iOS integrations including home screen widgets and Live Activity
- Full opencode surface support including sessions, file operations, and diagnostics

## Why It Matters for RAG Builders
It provides a fully auditable, self-hosted iOS interface for remote AI coding agents, ensuring privacy and control over sensitive data while enabling mobile access to development workflows.
