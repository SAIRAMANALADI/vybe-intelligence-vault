## Summary
Lacuna is a CLI tool that automates test generation for untested code by analyzing coverage gaps, writing tests, and verifying their execution in a single workflow. It integrates with AI models (local or cloud-based) to intelligently create and refine tests.

## Key Features
- Automated test generation for untested code segments
- Supports multiple test runners (Jest, Vitest, Pytest, etc.)
- Integrates with local or cloud-based AI models for context-aware test writing
- Retry mechanism for failing tests with iterative fixes
- Configuration-driven setup for customization and project-specific rules
