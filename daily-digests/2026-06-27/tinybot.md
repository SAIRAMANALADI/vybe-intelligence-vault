## Summary
Tinybot is a lightweight, extensible AI agent framework designed for building personal and multi-agent assistants with integrated memory, tooling, and automation capabilities. It supports multi-platform chat integration, real-time memory processing, and self-evolving experience systems.

## Key Features
- Real-time editable memory system with semantic search and vector storage
- Cowork architecture for multi-agent team collaboration and task scheduling
- Experience self-evolution system for continuous learning from problem-solving
- MCP support for seamless integration with external tools and servers
- OpenAI-compatible API for easy integration with existing clients
