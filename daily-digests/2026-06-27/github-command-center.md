## Summary
A Windows desktop application that consolidates GitHub tasks like pull requests, issues, workflows, and local Git management into a single dark-themed interface, eliminating the need for browser-based workflows.

## Key Features
- Consolidates GitHub pull requests, issues, and workflows in one interface
- Local Git repository management with commit, push, and branch operations
- Dark-themed UI for reduced eye strain
- Self-hosted and offline-capable after initial setup
- Supports Windows 10/11 with minimal system requirements
