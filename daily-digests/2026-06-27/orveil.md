## Summary
Orveil is a self-hosted monitoring solution that extends beyond basic uptime checks to include incident severity tracking, SLA monitoring, post-mortems, and an AI assistant. It integrates with MCP and supports over 26 monitor types, alerts via Apprise, and Prometheus metrics in a single Docker container.

## Key Features
- 26+ monitor types including HTTP, DNS, Docker, Proxmox, and AI services like Ollama
- Incident tracking with severity levels (P1-P4), war room, and post-mortem reports
- MCP server integration for AI assistants to query monitors and incidents
- Apprise notifications supporting 100+ channels (Pushover, Telegram, Discord, Slack, email)
- Prometheus metrics endpoint for Grafana integration and SLA tracking

## Why It Matters for RAG Builders
