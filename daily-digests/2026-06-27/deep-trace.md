## Summary
deep-trace is a systematic five-question root cause analysis (RCA) protocol designed specifically for AI agents, adapted from Toyota's 5 Whys methodology. It helps diagnose failures by tracing errors back to their root causes in instruction, process, or design layers, rather than applying symptom patches that lead to recurring issues.

## Key Features
- Five-question RCA drill with hard constraints and gate checks for each question
- AI agent-specific error signature classification (8 codes)
- Actionable output format with acceptance criteria and error tags
- Meta-principles for extracting reusable design rules instead of symptom patches
- Self-reflection protocol to apply RCA to its own failures

## Why It Matters for RAG Builders
deep-trace provides a structured, repeatable method to eliminate recurring AI agent failures by addressing root causes rather than symptoms, significantly improving system reliability and reducing instruction patch inflation.
