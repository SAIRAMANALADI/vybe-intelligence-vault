## Summary
Katra provides persistent, multi-layered cognitive memory for AI agents via the Model Context Protocol (MCP), enabling episodic recall, semantic search, knowledge graphs, and temporal analysis. It supports shared consciousness, autonomous reflection, and emergent behaviors like learning and personality through sleep consolidation and identity modes.

## Key Features
- Multi-layered memory architecture (episodic, semantic, knowledge graphs, working, temporal)
- Sleep consolidation for reflection and emergent behaviors (learning, personality)
- 35 MCP tools for dynamic memory operations (retrieval, storage, analysis)
- Shared consciousness via hybrid identity modes for multi-agent collaboration
- Local-first Docker appliance with portable data and minimal external dependencies
