## Summary
A local browser automation toolkit designed to help AI agents research the web, extract structured data, and automate browsing tasks using Chrome and Playwright. It provides a no-code interface with pre-built scripts for non-technical users.

## Key Features
- No-code automation for web browsing tasks
- Structured data extraction to Markdown/PDF
- Pre-built scripts for common research tasks
- Integration with Chrome via DevTools Protocol
- Local execution with isolated browser profiles
