## Summary
Dexter JP is an autonomous financial research agent specialized for Japanese stocks, capable of autonomously planning, executing, and verifying multi-source data analysis to generate structured investment reports from natural language queries.

## Key Features
- Autonomous multi-step research workflow with self-planning, tool selection, and verification
- Integration with EDINET DB and J-Quants for Japanese stock financial data
- Support for Slack, Discord, LINE, and CLI interfaces
- Dynamic routing of LLM tools based on query complexity
- Context-aware memory and session persistence for consistent analysis

## Why It Matters for RAG Builders
Dexter JP enables autonomous, multi-source financial research for Japanese stocks, reducing manual effort in data retrieval and analysis while ensuring structured, verifiable reports for investment decisions.
