## Summary
ConfigDrift is a CLI tool designed to detect and prevent configuration drift across multiple environments by comparing configuration files (YAML, JSON, TOML, .env) and flagging discrepancies before they cause incidents.

## Key Features
- Multi-format support for YAML, JSON, TOML, and .env files
- Severity-based classification of drift (Info, Warning, Breaking)
- CI/CD integration with silent mode for gating deployments
- Automated comparison of entire environment directories
- Rich terminal output with colorized diffs and machine-readable JSON

## Why It Matters for RAG Builders
ConfigDrift ensures consistency across environments, preventing costly production incidents by catching misconfigurations early in the development lifecycle.
