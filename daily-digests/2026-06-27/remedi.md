## Summary
Remedi is an AI-powered AWS security scanner and auto-remediator that scans 8 AWS services, generates structured findings, and automatically fixes vulnerabilities after human approval. It ensures compliance with CIS Benchmarks and provides real-time verification of fixes.

## Key Features
- Multi-service AWS security scanning (IAM, S3, VPC, Security Groups, EC2, RDS, Lambda, CloudTrail)
- Human-in-the-loop safety gate for approval before remediation
- Automated vulnerability fixing with parallel execution and verification
- CIS Benchmark compliance tracking and real-time scoring
- Secure credential management with Fernet encryption and automatic purging
