## Summary
Primer is a VS Code extension that enhances AI coding agents with persistent memory, enforceable guardrails, and real-time audit trails. It integrates with popular AI tools like Claude, Cursor, and Windsurf via MCP to provide session continuity, file protection, and accountability.

## Key Features
- Persistent memory across sessions and agents for continuity
- Enforceable guardrails to block or warn against restricted file operations
- Real-time audit trail capturing all agent actions in the VS Code sidebar
- Seamless integration with MCP-compatible AI tools (Claude, Cursor, Windsurf, etc.)
- Session resumption with automatic injection of prior actions for context

## Why It Matters for RAG Builders
Primer ensures AI agents operate reliably, securely, and accountably by providing persistent memory, enforceable guardrails, and a transparent audit trail, reducing the need for manual oversight.
