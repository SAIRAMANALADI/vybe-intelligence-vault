## Summary
RepoCiv transforms local AI agent workspaces into an interactive Civilization-style dashboard where repositories are visualized as cities, AI agents as units, and background processes as buildings. It provides a hexagonal macro map and a RimWorld-style isometric local view for real-time monitoring and interaction with agent workflows.

## Key Features
- Hexagonal macro map and 3D WebGL/2.5D isometric local views for immersive workspace navigation
- Real-time integration with AI agents via HTTP/WebSocket bridge and MCP server support
- Priority Matrix system to prioritize tasks and files for agents based on urgency and risk
- Fatigue system simulating agent workload and recovery mechanics
- Built-in event logging (Gaceta) for auditing agent activities and system events
