## Summary
AgentPal is a lightweight framework designed to simplify the creation and management of AI teams by introducing 'Pals'—portable, role-based companions that encapsulate identity, knowledge, skills, memory, workflows, and collaboration rules. It operates as a Markdown/JSON/protocol workspace layer for existing agent runtimes like Codex and Claude Code, enabling users to organize and orchestrate AI agents without building complex multi-agent systems.

## Key Features
- Portable Pal companions with identity, skills, memory, and workflows
- No-code Pal creation and governance via PalSmith
- Integration with existing agent runtimes (Codex, Claude Code, etc.)
- Formal Skill asset standard with 219 mapped skills
- Task Package standards and context slicing for efficient execution

## Why It Matters for RAG Builders
AgentPal bridges the gap between fragmented skills and heavy multi-agent systems by providing a lightweight, portable framework for building and orchestrating AI teams, reducing complexity for RAG builders.
