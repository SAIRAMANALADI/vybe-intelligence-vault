## Summary
A Model Context Protocol (MCP) server that enables AI agents like Codex to control a desktop session programmatically. It provides tools for screenshots, mouse/keyboard input, window inspection, and clipboard operations across Windows, Linux, and macOS.

## Key Features
- Provides MCP-compliant tools for screenshots, mouse movement, clicks, scrolling, and keyboard input
- Supports Windows (native Win32), Linux, and macOS (command-backed adapters)
- Includes a bundled Codex Skill for safe desktop-use workflows
- Offers cursor position tracking and visible window discovery
- Designed for low-latency, high-reliability desktop interaction

## Why It Matters for RAG Builders
It enables AI agents to safely and programmatically interact with desktop environments, bridging the gap between AI reasoning and real-world UI control for RAG and agent-based systems.
