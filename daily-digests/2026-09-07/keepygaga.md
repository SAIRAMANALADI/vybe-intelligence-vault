## Summary
Keepygaga is a lightweight, cross-agent core memory system that stores only durable, user-defined facts in local Markdown files, enabling consistent agent behavior across multiple coding environments like Codex, Claude Code, and Grok without relying on external databases or embeddings.

## Key Features
- Deliberate core memory selection for agents, avoiding noise from irrelevant context
- Cross-host synchronization of user facts across multiple coding agents (Codex, Claude Code, Grok, etc.)
- Lightweight MCP server with eight tools for memory operations (list, read, create, update, etc.)
- CLI-based installation, operation, and diagnostics with no external dependencies
- Private Markdown-based memory root (e.g., Obsidian vault) for human inspection and editing

## Why It Matters for RAG Builders
It provides a standardized, portable way for AI agents to maintain consistent user-specific context across different environments without bloating memory with irrelevant data.
