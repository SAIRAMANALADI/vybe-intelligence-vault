## Summary
grokrc is a remote control tool for xAI's Grok Build CLI, enabling users to drive terminal coding agents from their phones using the Agent Client Protocol (ACP) instead of screen scraping. It provides a Progressive Web App (PWA) interface for managing agent sessions, approvals, and terminal interactions over a secure WebSocket connection.

## Key Features
- Real-time agent session management via PWA on mobile devices
- Native support for xAI's Grok Build CLI using ACP JSON-RPC protocol
- One-tap approvals and tool calls with structured permissions
- Secure pairing with single-use codes and constant-time token hashing
- Terminal + phone shared session with read-only and interactive modes

## Why It Matters for RAG Builders
It enables structured, secure remote control of coding agents via ACP, eliminating the need for screen scraping and providing a mobile-first interface for AI-driven development workflows.
