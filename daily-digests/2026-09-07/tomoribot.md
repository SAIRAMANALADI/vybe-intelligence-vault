## Summary
TomoriBot is a self-hosted, customizable Discord AI assistant and role-playing system featuring long-term memory, multi-persona support, tool calling, multimodality, and API/local model integration. It enables agentic AI interactions, media generation, and SillyTavern character card compatibility within Discord.

## Key Features
- Long-term memory with RAG and STM for context retention across channels
- Multi-persona support with customizable behaviors and shareable character cards
- 200+ native Discord slash commands for configuration and management
- Agentic tool calling (web search, reminders, media generation, etc.) via MCP and local endpoints
- SillyTavern integration for importing/exporting character presets and cards

## Why It Matters for RAG Builders
TomoriBot provides a robust, self-hostable framework for building AI agents within Discord, enabling advanced memory, persona management, and tool integration critical for scalable AI applications.
