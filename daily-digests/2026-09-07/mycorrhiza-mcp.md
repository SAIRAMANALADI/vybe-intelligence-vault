## Summary
Mycorrhiza-MCP provides persistent, auditable memory for any MCP-compatible client using a SHA-256 hash chain stored in a local SQLite database. It enables cross-session continuity for AI interactions without relying on external services, ensuring data ownership and cryptographic integrity.

## Key Features
- SHA-256 hash chain for tamper-proof memory persistence
- Local SQLite storage with user ownership and export capability
- Three MCP tools: remember, recall, and chain_status for integrity verification
- Cross-session memory retrieval without external dependencies
- Minimal storage footprint (~92 MB/year) with cryptographic verification

## Why It Matters for RAG Builders
It enables AI systems to maintain continuity across sessions and model updates without relying on proprietary services, ensuring user-owned, auditable memory persistence for RAG and agent frameworks.
