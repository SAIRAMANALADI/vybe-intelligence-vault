## Summary
Agentic Scheduling is an AI-powered tool that synchronizes multiple calendars (Google, Outlook) and automates meeting scheduling via a 24/7 AI agent. Users can manage their calendars, book meetings, and receive reminders over WhatsApp, Slack, email, or a web interface without manual coordination.

## Key Features
- Synchronizes multiple Google/Outlook calendars into a unified view
- AI agent handles scheduling requests via text (WhatsApp/Slack/web) and books meetings automatically
- Public booking page with real-time availability checks to prevent double-booking
- Multi-channel reminders (email, WhatsApp) with retry logic for failed deliveries
- Chrome extension to overlay personal availability on third-party Calendly pages
