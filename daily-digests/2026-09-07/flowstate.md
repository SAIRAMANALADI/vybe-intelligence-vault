## Summary
FlowState is a native macOS application that enables voice-driven interaction with your screen and codebase. It leverages OpenAI's realtime voice model to perform tasks like analyzing screenshots, editing code via Claude Code, and managing development workflows entirely on-device.

## Key Features
- Voice-first interaction with screen and codebase using OpenAI's realtime voice model
- On-device execution with user-provided API keys, ensuring privacy and no telemetry
- Dev Mode integration with Claude Code for live code editing and task queuing
- Continuous screen capture with multi-monitor support and GPU-accelerated backdrops
- Built-in cost tracking, undo functionality, and conversation memory for seamless workflows

## Why It Matters for RAG Builders
FlowState bridges the gap between voice-driven AI assistants and local development workflows, enabling hands-free coding and screen interaction while maintaining privacy and control over API costs.
