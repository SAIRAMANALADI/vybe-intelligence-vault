## Summary
agnt is a development tool that bridges AI coding agents with browser capabilities, enabling real-time visual debugging, DOM inspection, sketching, error capture, and structured data exchange to enhance AI-assisted coding workflows.

## Key Features
- Bidirectional bridge between AI agents and browsers for visual and contextual feedback
- Real-time DOM inspection, screenshots, and accessibility audits via injected `__devtool` API
- Sketch mode for wireframing and direct UI feedback to agents
- Automated error capture and structured logging for token-efficient AI context
- MCP server integration for seamless agent communication (Claude Code, Cursor, etc.)

## Why It Matters for RAG Builders
It enables AI coding agents to perceive and interact with browser contexts in real-time, drastically improving the accuracy and efficiency of AI-assisted frontend development and debugging.
