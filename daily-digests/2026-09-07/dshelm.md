## Summary
DSHelm is an explainable multi-model scheduling layer for DeepSeek Harness (DSH) that enables intelligent model routing based on capabilities, costs, and user-defined policies. It provides traceable decision-making for planner, worker, and reviewer roles while integrating seamlessly with the DSH ecosystem.

## Key Features
- Hard condition filtering for model selection (runtime, authentication, context, cost)
- Resolution Trace for auditable decision-making with provenance tracking
- User/project/request-level policy overrides for customizable routing
- Seamless integration with DSH ecosystem without duplicating session or tooling logic
- Web control panel for visualizing model assignments and trace explanations

## Why It Matters for RAG Builders
DSHelm enables RAG builders to dynamically select optimal models for different stages of a workflow while maintaining transparency and traceability, reducing costs and improving performance through intelligent routing.
