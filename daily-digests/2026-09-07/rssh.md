## Summary
RSSH is an AI-powered SSH client designed to act as an operations copilot, enabling users to connect to hosts and query system status naturally. It proposes commands, highlights side effects, and executes them only after user approval, with sensitive data redacted locally.

## Key Features
- AI-assisted command proposal with side-effect visibility and user approval gates
- Cross-platform support (desktop, mobile, JetBrains IDEs, CLI) with shared SQLite data store
- Local redaction of sensitive data and shape validation before any payload leaves the machine
- Dynamic discovery for Docker containers and Kubernetes pods with ephemeral terminal access
- Session recording, port forwarding, SFTP, and multi-session workbench with color-coded command blocks

## Why It Matters for RAG Builders
RSSH bridges the gap between natural language queries and secure, controlled command execution in remote operations, reducing human error while maintaining strict data privacy.
