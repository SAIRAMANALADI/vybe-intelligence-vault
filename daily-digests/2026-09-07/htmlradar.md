## Summary
HTMLRadar is an open-source alternative to DocSend designed for tracking HTML documents generated by LLMs. It provides section-level dwell analytics, per-viewer dashboards, and retroactive share management, enabling precise insights into document engagement without requiring file uploads.

## Key Features
- Section-level dwell tracking with auto-detected sections (headings, slides, containers)
- Per-viewer dashboards with live refresh, aggregated across all shares of a document
- Retroactive share management (password, expiry, allow-list updates without revocation)
- MCP server for agent integration to publish and track HTML documents programmatically
- Privacy-respecting analytics with no raw IP storage, bot filtering, and engagement-time methodology

## Why It Matters for RAG Builders
HTMLRadar provides critical document engagement insights for RAG builders who generate HTML outputs, enabling precise tracking of reader behavior beyond simple open/click metrics.
