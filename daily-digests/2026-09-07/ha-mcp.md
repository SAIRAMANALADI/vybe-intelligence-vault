## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Home Assistant, providing deep control over smart home automation, entity management, and system administration through a comprehensive set of tools and APIs.

## Key Features
- 41 specialized tools for Home Assistant entity queries, automation CRUD, and system administration
- Hybrid architecture combining WebSocket for real-time operations and REST API for automation/script/scene management
- Fine-grained access control with read-only mode, whitelist/blacklist filtering, and tool-level permissions
- Automatic reconnection with exponential backoff and post-mutation state confirmation for reliability
- Comprehensive CRUD operations for automations, scripts, scenes, helpers, and system entities

## Why It Matters for RAG Builders
It provides AI assistants with direct, programmatic control over Home Assistant ecosystems, enabling advanced automation management and smart home interactions essential for RAG builders integrating home automation.
