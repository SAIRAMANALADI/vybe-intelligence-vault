## Summary
IndieBiz OS is a personal AI agent system and shared media warehouse that compiles plain language into an actionable language (IBL) and enables AI agents to read and interact with a filesystem-based media network. It transforms raw data into dynamic platforms (e.g., YouTube, blogs, shopping malls) without pre-built UIs, leveraging a decentralized, agent-driven architecture.

## Key Features
- Compiles natural language into IBL (action language) for automation and app creation
- Shared warehouse with schema-on-read filesystem serving as a dynamic media network
- Decentralized neighbor discovery and subscription via `/manifest` JSON protocol
- Agent-driven publishing and consumption of content without platform intermediaries
- Modular AI exoskeleton for personal workflow automation and cognitive augmentation

## Why It Matters for RAG Builders
IndieBiz OS redefines how AI agents interact with data by making the filesystem the primary interface, enabling seamless, decentralized media networks and personal AI automation without relying on traditional platforms or APIs.
