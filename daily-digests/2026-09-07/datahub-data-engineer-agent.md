## Summary
An autonomous agent that automates root cause analysis for data incidents within DataHub, measuring blast radius, acting on findings, and writing structured post-mortems back to the catalog as institutional memory to accelerate future triage.

## Key Features
- Automated root cause analysis via column-level lineage walks in DataHub
- Blast radius ranking of impacted assets (datasets, charts, dashboards, models) by usage
- Structured post-mortem write-back to DataHub with searchable institutional memory
- Integration with DataHub MCP server and Python SDK for metadata reads/writes
- Measured performance improvements (24% fewer tool calls, 14% less time) with memory recall

## Why It Matters for RAG Builders
It automates critical data incident triage workflows, reducing mean time to resolution and preserving institutional knowledge for faster future responses.
