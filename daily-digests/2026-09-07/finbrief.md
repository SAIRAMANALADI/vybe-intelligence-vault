## Summary
FinBrief is a personalized AI financial briefing agent that collects macro financial indicators and economic news daily, generates market reports and topic-specific card news, and delivers them via Discord or Slack. It leverages Supabase with pgvector for RAG-based retrieval and LangGraph for workflow orchestration.

## Key Features
- Daily macro financial indicator and news collection with automated ingestion
- Supabase pgvector-based RAG for evidence retrieval and topic matching
- LangGraph-powered report and card generation pipeline with mock and live modes
- Discord/Slack slash command integration for natural language subscription management
- Observability with LiteLLM retry/fallback and Langfuse tracing

## Why It Matters for RAG Builders
It provides a production-ready framework for building personalized financial AI agents with RAG, workflow orchestration, and multi-channel delivery, reducing time-to-market for RAG stack builders.
