## Summary
dsh-web-tools enhances DeepSeek Harness by unifying multi-provider web search and content extraction across 8+ platforms, including social media like Xiaohongshu and Twitter/X. It normalizes search intents via SearchHints and compiles provider-specific parameters for optimized retrieval while ensuring resilience through multi-key pooling and automated failover.

## Key Features
- Unified search interface for 8+ web providers with native capability adaptation
- SearchHints-based query normalization for provider-specific parameter compilation
- Direct native browser integration for Xiaohongshu and Twitter/X with session management
- Multi-API-key pooling, failover chains, and 429 cooldown handling for resilience
- Deterministic provider routing and session-level search mode toggles

## Why It Matters for RAG Builders
It eliminates single-provider bottlenecks in RAG pipelines by enabling resilient, multi-source web retrieval with native platform capabilities, ensuring high uptime and rich context extraction for AI agents.
