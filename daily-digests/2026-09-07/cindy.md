## Summary
Cindy is an open-source AI agent framework that runs locally on your machine, enabling real-world task automation across desktop, mobile, and integrated tools. It supports multiple AI models and harnesses (e.g., Claude Code, Codex) with continuous memory, skills, and tool integration.

## Key Features
- Runs locally with access to real files and logged-in apps for secure, private task execution
- Supports multiple AI models and harnesses (e.g., Claude Code, Codex) with seamless switching and parallel task execution
- Continuous memory, skills, and tools shared across harnesses and models for consistent task handling
- Extensible via plugins, MCP integration, and custom skills for tailored automation workflows
- Cross-platform support for desktop, mobile, and remote devices with offline-first capabilities

## Why It Matters for RAG Builders
Cindy provides a robust, open-source foundation for building and deploying AI agents that execute real-world tasks locally, reducing dependency on cloud services while enabling deep integration with existing tools and workflows.
