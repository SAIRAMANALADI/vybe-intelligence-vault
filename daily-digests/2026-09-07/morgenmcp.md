## Summary
MorgenMCP is an MCP (Model Context Protocol) server that integrates the Morgen calendar API, enabling AI assistants and clients to interact with calendars, events, tasks, and tags programmatically. It provides a bridge between Morgen's API and MCP-compatible clients like Claude Desktop.

## Key Features
- 22 tools for managing accounts, calendars, events, tasks, and tags via Morgen API
- Read-only mode to restrict operations for safety
- Configurable limits and timezone support for event rendering
- Seamless integration with MCP clients like Claude Desktop
- Versioned releases for stable deployments

## Why It Matters for RAG Builders
