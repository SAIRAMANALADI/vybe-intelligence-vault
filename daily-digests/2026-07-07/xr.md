## Summary
XR is a secure, self-hosted AI agent framework designed for trust, transparency, and local-first operation. It supports BYOK (Bring Your Own Key) for providers, spend capping, tamper-evident memory, and multi-agent orchestration with a focus on safety and auditability.

## Key Features
- BYOK (Bring Your Own Key) support for 20+ providers or fully local models
- Spend capping enforced in code with hard budget limits
- Tamper-evident memory engine with SHA-256 hash chains and audit logs
- Multi-agent runtime with supervisor workflows and typed action schemas
- Plugin and MCP platform for extensibility with explicit permissions and approvals

## Why It Matters for RAG Builders
