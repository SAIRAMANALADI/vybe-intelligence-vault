## Summary
A lightweight sidecar agent and MCP server that bridges agentic coding tools with live Java runtime behavior using bytecode-level instrumentation. It enables probe-verified inspection, regression checks, and deterministic debugging workflows by attaching to a running JVM via ByteBuddy and JDWP.

## Key Features
- Bytecode-level runtime signal capture via Java agent instrumentation
- Framework-aware data synthesis and fail-closed tool contracts for reliable agent orchestration
- Multi-probe registry with deterministic profile routing and cross-probe correlation
- Regression suite orchestration with step-level conditionals and ordered prerequisite execution
- Spring Boot integration launcher for auto-inferred agent setup and probe port assignment

## Why It Matters for RAG Builders
It provides runtime-proven insights and deterministic debugging capabilities for Java applications, enabling RAG builders to ground AI workflows in actual JVM behavior rather than static analysis alone.
