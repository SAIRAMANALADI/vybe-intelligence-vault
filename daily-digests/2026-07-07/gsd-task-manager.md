## Summary
A privacy-first task manager based on the Eisenhower Matrix that helps users prioritize tasks by urgency and importance while storing all data locally. Features include task dependencies, recurring tasks, analytics, and optional cloud sync via PocketBase.

## Key Features
- Privacy-first local storage with optional PocketBase cloud sync
- Eisenhower Matrix-based task prioritization with drag-and-drop
- Advanced analytics dashboard with completion metrics and trend analysis
- Task dependencies, recurring tasks, and batch operations for bulk management
- PWA support with offline functionality and smart notifications

## Why It Matters for RAG Builders
It provides a structured, privacy-focused approach to task prioritization and management, which can be integrated into AI workflows for better productivity tracking and automation.
