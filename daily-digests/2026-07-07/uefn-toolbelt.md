## Summary
UEFN TOOLBELT is a Python-based utility suite designed to enhance development workflows within Fortnite Creative's Unreal Editor for Fortnite (UEFN) by providing 355 professional tools for asset management, device cataloging, and Verse code generation. It enables AI agents to autonomously read level state, generate Verse code, and deploy game logic with minimal manual intervention.

## Key Features
- 355+ professional tools for UEFN Python integration, covering asset management, device cataloging, and Verse code generation
- AI-agent readiness with structured dict returns and tool manifests for seamless AI interaction
- Autonomous Verse code generation and deployment from live level state, reducing setup time from 30+ minutes to seconds
- Comprehensive device cataloging (4,698 Creative devices across 35 categories) with machine-readable indices for AI agents
- Security-focused design with audited code, no network calls, and scoped editor transactions for safe execution
