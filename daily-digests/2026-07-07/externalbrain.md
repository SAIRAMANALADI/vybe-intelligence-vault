## Summary
External Brain is a self-hosted MCP server and webapp that provides persistent, long-term memory for AI coding agents across tools, projects, and teams. It automatically extracts reusable skills from coding sessions, stores them in a Postgres + pgvector knowledge base, and retrieves them semantically to improve AI tool performance over time.

## Key Features
- Automatic extraction of durable skills, rules, and patterns from coding sessions without manual input
- Universal MCP compatibility with tools like Claude Code, Cursor, and GitHub Copilot
- Semantic retrieval using pgvector for context-aware AI responses
- Self-improving knowledge base with daily synthesis and decay of low-value skills
- Grounded Oracle for cited answers based on your own codebase and sessions

## Why It Matters for RAG Builders
It eliminates knowledge silos in AI coding workflows by providing a shared, self-hosted memory layer that improves agent performance across tools, projects, and teams without vendor lock-in.
