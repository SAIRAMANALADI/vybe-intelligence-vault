## Summary
TaskFlow is a collaborative task management application for teams that enables shared task tracking, real-time updates, and background notifications. It provides a simple interface for managing work with live sync capabilities.

## Key Features
- Shared task creation and tracking for teams
- Real-time updates via WebSockets for live collaboration
- Secure authentication using JWT tokens
- Background notifications powered by RabbitMQ and FastAPI
- Data persistence with PostgreSQL and Redis caching
