## Summary
prd-spec-generator is a TypeScript MCP server that transforms feature descriptions into structured Product Requirements Documents (PRDs) through a stateless reducer pipeline. It enforces deterministic validation, multi-judge verification, and closed-loop calibration to ensure reliability and actionability of generated outputs.

## Key Features
- Stateless reducer pipeline for PRD generation with 10 pipeline steps
- Deterministic Hard Output Rules validation for structural correctness
- Multi-judge Bayesian reliability calibration with SQLite-backed posteriors
- Closed-loop calibration with externally-grounded falsifiers and held-out partitions
- Integration with companion projects (Cortex, zetetic-team-subagents, automatised-pipeline) for codebase intelligence and persistent memory

## Why It Matters for RAG Builders
It ensures PRDs generated by AI agents are structurally sound, verifiable, and actionable by enforcing deterministic validation, multi-judge consensus, and closed-loop calibration, reducing hallucinations and improving downstream pipeline reliability.
