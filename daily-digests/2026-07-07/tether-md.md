## Summary
Tether-md is a Windows desktop application that enables users to manage comments and AI-powered suggestions in markdown files without cluttering the original text. It provides a clean interface for reviewing, accepting, or rejecting changes while maintaining the integrity of the document.

- AI-powered suggestions with change previews (additions/deletions)
