## Summary
The @clamp-sh/mcp repository provides a Model Context Protocol (MCP) server for Clamp Analytics, enabling AI agents like Claude, Cursor, and VS Code Copilot to interactively query analytics data, create funnels, set alerts, and perform diagnostics without leaving the development environment.

## Key Features
- Integrates with AI agents (Claude, Cursor, VS Code) via MCP for seamless analytics access
- Supports 50+ tools for traffic, revenue, events, funnels, cohorts, and alerts
- Typed tool schemas with output validation for reliable agent interactions
- Hosted Remote MCP for one-click installation in supported editors
- Pre-built prompts for common analytics workflows (weekly reports, traffic diagnosis, etc.)

## Why It Matters for RAG Builders
It bridges AI agents directly to live analytics data, enabling autonomous diagnostic and reporting workflows without manual dashboard navigation.
