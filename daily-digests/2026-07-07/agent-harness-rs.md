## Summary
A Rust-based open-source framework providing the 'Agent Harness' layer for AI agents, enabling production-ready agent loops, tool use, MCP integration, sandboxed execution, and multi-agent orchestration beyond the LLM core.

## Key Features
- Modular Rust crates for core agent loop, tools, MCP, and sandboxing
- Support for multiple LLM providers (DeepSeek, OpenAI-compatible)
- Sandboxed execution with process, Wasm, and planned K8s isolation
- Execution tracing for debugging and replay
- Multi-agent orchestration and subagent delegation

## Why It Matters for RAG Builders
It provides the critical harness layer that turns LLMs into production-ready agents with tool use, sandboxing, and orchestration capabilities essential for RAG and AI system builders.
