## Summary
An autonomous AI-powered penetration testing agent that operates entirely locally using Google's Gemma 4-12B model via LM Studio. It performs autonomous recon, attack loops, and generates professional pentest reports while learning from failures through a persistent negative cache system.

## Key Features
- Fully local operation with no cloud dependency or API keys
- Persistent negative cache learning to avoid repeated failures
- Autonomous recon, attack loops, and professional report generation
- 24 integrated security tools for comprehensive vulnerability assessment
- Self-aware and adaptive skill injection based on attack goals
