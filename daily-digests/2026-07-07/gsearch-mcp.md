## Summary
gsearch-mcp enables AI tools to perform real-time Google searches via the Model Context Protocol (MCP) using a single Go binary. It provides grounding for AI agents by fetching up-to-date web results without external runtime dependencies.

## Key Features
- Single Go binary with zero runtime dependencies
- Enables real-time Google search grounding for AI tools
- Integrates with MCP for seamless AI agent communication
- Lightweight and easy to deploy
- Supports dynamic, up-to-date web search results
