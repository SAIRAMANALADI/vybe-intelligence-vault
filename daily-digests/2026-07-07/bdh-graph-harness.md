## Summary
BDH Graph Harness transforms Obsidian vaults into dynamic knowledge graphs using Hebbian synaptic plasticity, embedding-based retrieval, and real-time visualization. It enables adaptive, biologically-inspired learning where notes act as neurons, wikilinks as synapses, and queries trigger co-activation-based weight updates.

## Key Features
- Hebbian synaptic plasticity for adaptive graph learning and weight updates
- Real-time vis.js visualization with live node activation and edge pulsing
- Obsidian vault integration with server-side file watching and incremental updates
- Sleep-cycle consolidation for synaptic downscaling, pruning, and stale node removal
- MCP server and Obsidian plugin for seamless integration with AI agents and editors
