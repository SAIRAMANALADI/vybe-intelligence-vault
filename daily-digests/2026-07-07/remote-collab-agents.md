## Summary
remote-collab-agents enables multi-machine collaboration for Claude Code agents, allowing distributed execution of tasks, file synchronization, and workflow coordination across Windows PCs. It simplifies setup with tools like Tailscale, SSH, and Syncthing to unify remote agents into a single collaborative system.

## Key Features
- Enables three machines to operate as a unified team for Claude Code tasks
- Automates file synchronization across machines using Syncthing
- Simplifies network setup with Tailscale for private, secure connections
- Supports role-based task distribution (e.g., planning, coding, review)
- Provides a shared folder structure for input, working, output, and logs
