## Summary
Loom provides a document-native workflow for AI-assisted development, enabling structured, scoped, and persistent context for AI agents through a document graph system. It replaces ephemeral chat sessions with version-controlled markdown documents that track ideas, designs, requirements, and implementations.

## Key Features
- Structured document graph for AI context with typed, linked markdown documents
- Scoped and fresh AI sessions by loading only relevant documents for each task
- Human-in-the-loop workflow with approval gates at every phase transition
- MCP server integration for compatibility with AI agents like Claude Code and Cursor
- Version-controlled state with auditable context derived from documents

## Why It Matters for RAG Builders
Loom transforms AI development workflows by providing persistent, structured context that prevents context drift and enables auditable, resumable AI sessions, making it essential for building reliable RAG and agent systems.
