## Summary
OCP (Open Claude Proxy) transforms a Claude Pro/Max subscription into an OpenAI-compatible API endpoint, enabling local IDEs and tools to leverage Anthropic's models without additional API costs. It supports multi-user LAN sharing, per-key quotas, response caching, and IDE auto-configuration.

## Key Features
- Converts Claude Pro/Max subscription into an OpenAI-compatible API endpoint on localhost or LAN
- Supports multi-user sharing with per-key quotas, independent usage tracking, and revocation
- Provides IDE auto-configuration for tools like Cline, Continue.dev, OpenCode, and OpenClaw
- Includes optional response caching with per-key isolation and stampede protection
- Offers SSE heartbeat for long-running reasoning sessions to prevent timeouts

## Why It Matters for RAG Builders
OCP enables AI engineers to maximize the value of existing Claude subscriptions by converting them into a flexible, local OpenAI-compatible API for seamless integration with multiple IDEs and tools.
