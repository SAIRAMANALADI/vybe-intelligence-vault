## Summary
An open-source MCP (Model Context Protocol) server that enables AI assistants to interact with LinkedIn data through a user's authenticated browser session. It provides tools to fetch profiles, companies, jobs, messages, and other LinkedIn data for integration into AI workflows.

## Key Features
- Access LinkedIn profiles, companies, jobs, and messages via authenticated browser session
- Supports profile data extraction with explicit section selection (experience, education, skills, etc.)
- Provides messaging capabilities (inbox, conversations, and message sending)
- Offers job search and company research tools
- Compatible with MCP clients like Claude Desktop and supports multiple deployment methods (Docker, uvx, local)

## Why It Matters for RAG Builders
It enables AI assistants to securely and efficiently retrieve real-time LinkedIn data for RAG pipelines, enhancing contextual understanding and personalization in AI applications.
