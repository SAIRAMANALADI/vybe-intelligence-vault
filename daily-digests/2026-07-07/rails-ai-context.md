## Summary
A Ruby gem that provides structured AI context for Rails applications by exposing 39 tools via MCP server or CLI to help AI agents understand Rails internals, reducing guesswork and improving response accuracy with token-efficient data.

## Key Features
- 39 read-only tools for Rails app introspection (schema, models, controllers, routes, views, etc.)
- MCP server and CLI interfaces for seamless AI agent integration
- Structured, token-efficient data output to reduce context window usage
- Prevents common AI misinterpretations (e.g., Devise methods, encrypted columns, Turbo Stream wiring)
- Measured token savings up to 98% for complex tasks like method tracing

## Why It Matters for RAG Builders
It provides AI agents with accurate, structured context about Rails applications, drastically reducing hallucinations and improving the quality of generated code or responses.
