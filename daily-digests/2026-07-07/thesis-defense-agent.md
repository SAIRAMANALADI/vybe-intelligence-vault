## Summary
A learning-focused AI Agent repository designed to simulate thesis defense training scenarios using RAG, Tool Calling, and Agent Harness capabilities. It provides a modular framework for building and evaluating AI agents in a controlled environment with comprehensive deployment and observability features.

## Key Features
- Modular Agent Harness with Tool Calling and Session Management
- Comprehensive RAG pipeline with hybrid retrieval, reranking, and benchmarking
- Task State persistence and resumable workflows for long-running processes
- Built-in observability with Prometheus, Alertmanager, and Kubernetes manifests
- Multi-backend storage support (PostgreSQL, Qdrant, Milvus) with backup/restore capabilities

## Why It Matters for RAG Builders
It provides a production-ready blueprint for building and deploying AI agents with robust RAG, tool integration, and observability features essential for scalable AI engineering.
