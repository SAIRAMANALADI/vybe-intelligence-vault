## Summary
Agent Foundry is a local-first system that transforms real-world work experiences into reusable, reviewable, and deployable agent capabilities across multiple AI environments like Codex, ChatGPT, and Claude Code. It bridges the gap between transient insights and durable, portable agent behaviors through a structured workflow of harvesting, reviewing, and publishing practices and assets.

## Key Features
- Separation of Core, User Vault, and runtime components for modularity and scalability
- Structured workflows for harvesting, reviewing, and publishing reusable agent capabilities
- Support for multiple AI agent environments (Codex, ChatGPT, Claude Code, Hermes) via adapters
- Human approval gates to ensure durability and reliability of agent behaviors
- Capability packs for standardized, reusable agent practices and multi-agent collaboration

## Why It Matters for RAG Builders
Agent Foundry enables RAG and AI stack builders to convert ephemeral agent insights into portable, reviewable, and deployable capabilities, ensuring consistency and reliability across sessions and environments.
