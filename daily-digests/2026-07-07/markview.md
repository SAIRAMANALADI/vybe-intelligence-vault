## Summary
MarkView is a native macOS markdown preview application with an MCP server for integration with Claude Code. It provides live rendering of markdown content in a native window, supporting features like Mermaid diagrams, syntax highlighting, and bidirectional scroll sync.

## Key Features
- Native macOS markdown preview with live rendering
- MCP server for seamless integration with Claude Code
- Support for Mermaid diagrams, syntax highlighting, and GitHub Flavored Markdown
- Quick Look integration for Finder previews
- Multi-tab support with scroll position preservation and auto-save

## Why It Matters for RAG Builders
