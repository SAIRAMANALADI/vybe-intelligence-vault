## Summary
LatticeAI is a local-first Digital Brain platform that preserves AI context, conversations, documents, decisions, and project workflows on a user's computer by default. It provides a private memory layer for AI interactions, enabling model-agnostic knowledge retention and portable Brain archives.

## Key Features
- Preserves conversations, documents, decisions, and project context locally by default
- Provides a portable encrypted Brain archive for backup, restore, and export
- Supports scoped memory isolation and workspace-based knowledge graph traversal
- Enforces ToolRegistry policy for direct Tool API calls and installer execution
- Offers a Living Brain UX with concentric memory rings and source-aware recall

## Why It Matters for RAG Builders
LatticeAI enables RAG builders to preserve and manage private AI memory layers, ensuring context retention across model switches and workflows without relying on external cloud services.
