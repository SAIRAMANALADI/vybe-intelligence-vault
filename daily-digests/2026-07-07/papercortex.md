## Summary
PaperCortex is a Windows-based local AI tool designed to organize, search, and extract data from documents in Paperless-ngx. It enables semantic search, auto-classification, receipt data extraction, and DATEV accounting exports while maintaining full local control over files and AI processing.

## Key Features
- Semantic search for documents by meaning, not just keywords
- Auto-classification of documents into categories (invoices, receipts, contracts, etc.)
- Receipt data extraction (merchant, date, amount, tax, etc.)
- DATEV accounting export compatibility
- MCP server integration for Claude Code and local AI workflows

## Why It Matters for RAG Builders
PaperCortex streamlines document processing for RAG builders by providing local semantic search, structured data extraction, and accounting-ready exports, reducing dependency on cloud services while enhancing document intelligence workflows.
