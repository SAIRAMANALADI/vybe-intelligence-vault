## Summary
A Model Context Protocol (MCP) server that enables AI clients (e.g., Claude) to control Adobe After Effects via natural language commands. It supports multilingual text (including Arabic/RTL), deep project inspection, background rendering, and arbitrary ExtendScript execution with 47 specialized tools.

## Key Features
- 47 specialized tools for composition, layer, and animation control via natural language
- First-class Arabic/RTL text support with auto-detection and right-to-left alignment
- Background rendering and visual feedback tools like `see-frame` and `contact-sheet`
- Deep project inspection with locale-independent property lookups
- Arbitrary ExtendScript execution for full After Effects feature access

## Why It Matters for RAG Builders
