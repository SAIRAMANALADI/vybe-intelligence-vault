## Summary
ATRI is a local-first AI Agent-native music workstation that enables LLMs to directly manipulate DAW project structures (MIDI, automation, harmony tracks) instead of generating raw audio. It integrates an LLM runtime with a Rust-based audio host, VST3 bridge, and Vue dashboard for real-time music engineering collaboration.

## Key Features
- Direct LLM access to DAW project structures (MIDI, automation, harmony tracks) for editable outputs
- Rust-based real-time audio host with VST3 plugin support and ASIO compatibility
- Agent toolchain for symbolic music editing (velocity humanization, CC curves, harmony planning)
- Vue dashboard for visual DAW project management and AI collaboration
- Optional Neo4j knowledge graph for structured music theory and context retrieval

## Why It Matters for RAG Builders
ATRI bridges the gap between AI-generated music and professional DAW workflows by enabling LLMs to directly manipulate editable project structures, making AI a true collaborator in music creation rather than a black-box audio generator.
