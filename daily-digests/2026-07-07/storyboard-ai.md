## Summary
storyboard-ai is a Windows desktop application designed to help users quickly create and organize visual storyboards for video planning, pitch decks, and preproduction workflows. It simplifies scene and shot planning with a drag-and-drop interface and local file storage.

## Key Features
- Drag-and-drop reordering of storyboard frames
- Add scene notes and descriptions to frames
- Save and export storyboards for sharing or review
- Lightweight and fast setup with no complex dependencies
- Designed for short films, school projects, and pitch decks
