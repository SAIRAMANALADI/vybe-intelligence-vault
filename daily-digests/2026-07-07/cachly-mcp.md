## Summary
cachly-mcp is an MCP server that provides persistent, shared memory for AI assistants, enabling them to retain context across sessions and teams. It automatically learns from git history and commits, offering team-wide knowledge retention, causal root-cause analysis, and predictive failure detection.

## Key Features
- Automatic git history ingestion for team knowledge retention
- Causal root-cause analysis via `causal_trace` for debugging efficiency
- Team-wide expertise mapping and collaboration graphs
- Predictive failure detection from past incident patterns
- Model-agnostic persistence (works with Claude, Cursor, Copilot, etc.)

## Why It Matters for RAG Builders
It eliminates context loss in AI assistants by providing persistent, team-shared memory that learns from git history, significantly improving debugging efficiency and reducing onboarding time for AI-driven development workflows.
