## Summary
Mealforge is a self-hosted AI meal-planning application that enables users to plan weekly meals conversationally with MCP-capable AI models. It generates tailored recipes, provides step-by-step cooking instructions, and automatically derives a grocery list grouped by store sections, all without relying on a pre-built recipe catalog.

## Key Features
- Conversationally plan meals with any MCP-capable AI model (e.g., LibreChat, Claude)
- Automatically generates a grocery list grouped by store sections from meal plans
- Provides step-by-step cook mode and recipe cards for each meal
- Supports favoriting and history to avoid repeating recent meals
- Self-hosted with Docker, requiring minimal setup and configuration

## Why It Matters for RAG Builders
Mealforge bridges the gap between AI-driven meal planning and practical kitchen execution by providing a structured, shoppable, and cookable output from conversational AI planning.
