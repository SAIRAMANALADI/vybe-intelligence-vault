## Summary
veo is a Windows desktop application designed to simplify the local execution of AI Studio apps on Windows machines without requiring manual setup of a full development stack. It provides a user-friendly interface for downloading, installing, and running AI applications locally.

## Key Features
- Simplified local AI app execution on Windows without manual dev stack setup
- Pre-packaged releases for easy download and installation
- Support for integrating Gemini API keys for enhanced functionality
- User-friendly GUI for managing and running AI Studio apps
- Automated updates via release downloads
