## Summary
A Model Context Protocol (MCP) server that automates the retrieval and analysis of Korean national research and development (R&D) regulations for compliance checks. It integrates with the National Law Information Center's OpenAPI to fetch hierarchical regulations (laws, decrees, rules, and administrative notices) and provides structured, evidence-based responses to regulatory queries.

## Key Features
- Automated retrieval of Korean R&D regulations (laws, decrees, rules, and notices) via OpenAPI integration
- Hierarchical regulation analysis (Tier 1: laws/decrees/rules; Tier 2: administrative notices)
- Structured, evidence-based responses with cited provisions and hierarchical precedence checks
- Supports multi-step regulatory review workflows (e.g., funding limits, approval processes, reporting requirements)
- Provides installation options for Claude.ai and local setups with API key configuration

## Why It Matters for RAG Builders
It streamlines the retrieval and analysis of Korean R&D regulations, reducing manual effort for compliance checks and enabling AI systems to provide accurate, evidence-backed regulatory guidance.
