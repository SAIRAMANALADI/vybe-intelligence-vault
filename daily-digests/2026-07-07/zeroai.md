## Summary
ZeroAI is an Android application that enables users to interact with AI assistants directly from their mobile devices. It supports multiple AI providers and messaging tools, combining Kotlin for the Android frontend with Rust for core logic via UniFFI.

## Key Features
- Cross-provider AI chat and agent tasks on Android
- Rust-based core logic for performance and safety
- UniFFI bridge for Kotlin-Rust interoperability
- Jetpack Compose UI for modern Android development
- Support for messaging integrations (Telegram, Discord, etc.)
