## Summary
git-trend-sync is a Windows desktop application that automatically discovers trending GitHub repositories and matches them to a user's local codebase, helping developers stay updated with relevant tools and libraries without manual research.

## Key Features
- Automated trend discovery from GitHub repositories
- Codebase matching to identify relevant tools and libraries
- Customizable topic tracking (e.g., AI, RAG, MCP)
- Windows-native desktop application with simple setup
- Activity-based scoring for prioritizing trending repos

## Why It Matters for RAG Builders
