## Summary
Lien is a local-first code-intelligence layer for AI agents that provides structural analysis (e.g., dependency impact, complexity hotspots, test associations) and fast lexical search over codebases. It integrates seamlessly with MCP-compatible tools like Cursor and Claude Code, enabling agents to make informed edits without external dependencies.

## Key Features
- Structural code analysis (dependency impact, complexity metrics, test associations)
- Fast lexical search (FTS5/BM25) over code, docstrings, and symbols
- Seamless MCP integration for AI coding assistants (Cursor, Claude Code)
- Self-hostable GitHub Action for PR reviews (Lien Review)
- 100% local, private, and offline with no model downloads required

## Why It Matters for RAG Builders
Lien provides critical structural and lexical context for AI agents to safely and intelligently edit code, eliminating the need for external embeddings or APIs while ensuring privacy and performance.
