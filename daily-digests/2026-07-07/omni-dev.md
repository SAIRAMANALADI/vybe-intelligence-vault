## Summary
omni-dev is a Rust-based AI-powered toolkit for intelligent Git commit message generation, PR creation, and workflow automation. It transforms messy commit histories into conventional commit formats with project-aware AI suggestions and supports advanced features like contextual analysis, parallel processing, and MCP server capabilities for Atlassian tools.

## Key Features
- AI-powered commit message and PR description generation with contextual awareness
- Supports parallel processing for large commit ranges and batch improvements
- MCP server exposing Git, Atlassian (Jira/Confluence), and Datadog tools
- Browser bridge for SSO-gated dashboards and Snowflake SQL service
- Safety-first design with working directory validation and error recovery

## Why It Matters for RAG Builders
It streamlines Git workflows by automating commit message and PR generation with AI, reducing manual effort and improving consistency in collaborative development.
