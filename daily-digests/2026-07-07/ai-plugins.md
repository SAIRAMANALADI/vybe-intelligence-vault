## Summary
vwf is an opinionated workflow plugin for Claude Code that transforms vague ideas into shipped products through four disciplined phases: Product, Blueprint, Plan, and Execute. It enforces structured workflows, TDD, code reviews, and production verification with high-touch approval gates.

## Key Features
- Four-phase disciplined workflow (Product → Blueprint → Plan → Execute)
- Autonomous execution with strict TDD and multi-stage reviews (code, security, UX, E2E)
- Opinionated structure enforcing workspace shape and reference stacks
- Whole-product coherence reviews and API contract freezing post-deployment
- High-touch approval gates with unattended autonomous execution phases

## Why It Matters for RAG Builders
It provides a rigorous, automated framework for turning product ideas into production-ready code with enforced quality gates, making it essential for teams prioritizing reliability and traceability in AI-driven development.
