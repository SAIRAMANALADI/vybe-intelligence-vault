## Summary
ARES is an open-source embodied AI operating system designed to deploy persistent, autonomous intelligences capable of orchestrating local AI stacks, automating workflows, and interacting via a native AI avatar. It integrates with Hermes Agent and JROS for tooling and robotics, offering a modular architecture for continuous intelligence.

## Key Features
- Persistent entity with memory and drives across sessions
- Modular backend selector (Hermes, JROS, or Hybrid mode)
- Character avatar browser with 14 visual personas and lore
- Native macOS app with voice and animated avatar eyes
- Hot-reload for development and multi-model LLM routing

## Why It Matters for RAG Builders
ARES provides a robust framework for deploying persistent, autonomous AI agents that can orchestrate complex workflows and integrate with external tools, making it essential for building advanced RAG systems with persistent memory and multi-modal interactions.
