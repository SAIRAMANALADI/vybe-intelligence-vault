## Summary
Reqly is an API testing tool designed for AI agents, enabling zero-human-pipeline workflows from codebase analysis to CI integration. It provides MCP server capabilities, CLI, and web UI for building, running, and exporting API collections and flows as plain YAML files.

## Key Features
- MCP server for seamless AI agent integration with 30+ tools for API testing workflows
- Plain YAML collections stored in `.reqly/` for git-native, human-readable, and agent-writable configurations
- Zero-human-pipeline automation: agents read code, build collections, write flows, and export CI configurations in one session
- Auto-capture of inbound/outbound traffic and webhooks for effortless collection generation
- Local-first architecture with no cloud dependency, supporting CLI, desktop app, and VS Code extension

## Why It Matters for RAG Builders
Reqly enables AI agents to autonomously handle API testing workflows from codebase analysis to CI integration, eliminating manual effort and accelerating development cycles.
