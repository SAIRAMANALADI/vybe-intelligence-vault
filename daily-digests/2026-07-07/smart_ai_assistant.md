## Summary
A Windows-based AI assistant that enables users to query and extract answers from their own PDF documents using vector search, conditional workflows, and the Gemini API. The app provides a guided chat interface with Streamlit and supports local document processing.

## Key Features
- PDF document ingestion and vector-based search using FAISS
- Conditional workflows for handling different question types
- Integration with the Gemini API for AI responses
- Streamlit-based user interface for a clean chat experience
- LangSmith monitoring for tracking assistant behavior and performance

## Why It Matters for RAG Builders
It provides a simple, local-first solution for building RAG systems that can query private PDF documents with minimal setup overhead.
