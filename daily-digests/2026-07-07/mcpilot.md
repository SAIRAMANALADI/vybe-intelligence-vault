## Summary
MCPilot is a desktop application designed to simplify the management of Model Context Protocol (MCP) servers through a visual interface. It eliminates the need for command-line inputs by providing one-click controls for starting, stopping, and monitoring multiple MCP server instances.

## Key Features
- One-click server lifecycle management (start/stop)
- Real-time log monitoring for active servers
- Multi-instance support for managing multiple MCP services
- Built-in debugging and diagnostic tools
- Resource monitoring (CPU/memory usage)
