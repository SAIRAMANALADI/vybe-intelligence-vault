## Summary
ZoN CreatorOS is a context-native creative operating system that transforms fragmented ideas, memories, and goals into structured, production-ready artifacts using persistent context, intelligent agent orchestration, and domain-specific production engines. It bridges raw creative input with structured outputs like release plans, content calendars, and project roadmaps.

## Key Features
- Persistent scoped memory with FAISS and knowledge graphs for context retention
- Multi-agent orchestration (Orchestrator, Research, Planning, Memory, Workflow Agents)
- Domain-specific production engines for structured artifact generation (plans, calendars, roadmaps)
- Hardware-optimized compute stack leveraging AMD NPUs and GPUs for local and cloud inference
- Creator profile engine for style, brand voice, and long-term goal alignment

## Why It Matters for RAG Builders
ZoN CreatorOS provides a unified framework for turning unstructured creative input into structured, actionable outputs while preserving context and enabling hardware-optimized agent orchestration, critical for scalable RAG systems in creative domains.
