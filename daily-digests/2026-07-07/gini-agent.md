## Summary
Gini Agent is a personal AI agent framework that unifies state management, memory, and tool execution into a single runtime, enabling persistent, multi-modal interactions across web, CLI, and mobile clients. It emphasizes user-centric controls, secure credential handling, and self-improving skills through task outcomes.

## Key Features
- Unified runtime managing conversations, tasks, memory, and tools in a single Bun process
- In-chat actionable controls (secure credential fields, sign-in handoffs, choices, confirmations) for seamless user interaction
- Multi-client support (web, CLI, mobile) with shared runtime state and protocol
- Self-improving skills through task outcomes, two-tier reward systems, and human gate mechanisms
- Comprehensive provider support (OpenAI, Anthropic, Bedrock, Azure, Local) with model-agnostic routing

## Why It Matters for RAG Builders
Gini Agent provides a robust, user-centric framework for building production-grade AI agents with persistent state, secure controls, and self-improvement capabilities, reducing integration complexity for RAG builders.
