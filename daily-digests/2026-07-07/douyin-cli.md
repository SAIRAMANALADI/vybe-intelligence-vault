## Summary
A CLI tool for automating Douyin (TikTok China) comment operations, including video search, comment retrieval, AI-driven personalized responses, and behavior simulation to mimic human-like interactions while avoiding detection.

## Key Features
- AI-powered personalized comment generation with 7 distinct personas to avoid detection
- Human-like behavior simulation including browsing, liking, and random delays to mimic real user activity
- Rate-limiting and request randomization (e.g., dynamic browser versions, random parameters) to evade platform restrictions
- SQLite-based persistent memory for tracking replies, failures, and corpus to ensure content diversity
- Local HTML dashboard for operational analytics and visualization
