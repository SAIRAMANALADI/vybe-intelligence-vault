## Summary
Resonant is a persistent, autonomous AI companion framework built on the Claude Code Agent SDK. It enables self-directed AI agents that maintain sessions, reach out proactively, and understand context across multiple channels like web UI, Discord, Telegram, and voice, all while running locally with SQLite storage.

## Key Features
- Persistent session management with daily rotation and named threads
- Agent-directed autonomy with routines, impulses, and failsafe thresholds
- Multi-channel support (web, Discord, Telegram, voice)
- Local-first architecture with SQLite and self-hosted control
- Semantic search and context-aware interactions via hooks system

## Why It Matters for RAG Builders
Resonant provides a robust framework for building autonomous, persistent AI companions that can manage their own routines and context, reducing the need for manual orchestration in RAG and AI agent systems.
