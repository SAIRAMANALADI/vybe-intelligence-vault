## Summary
mcp-brasil is a Windows-based MCP server that provides AI agents and applications with access to 41 public Brazilian APIs, enabling seamless retrieval of government, civic, and public service data for AI workflows.

## Key Features
- Provides access to 41 public Brazilian APIs through a single MCP server
- Simplifies integration of Brazilian public data into AI workflows
- Pre-configured for use with MCP-compatible clients like Claude Desktop
- No manual API configuration required; handles authentication and data fetching
- Windows-native executable for easy deployment

## Why It Matters for RAG Builders
It enables AI agents to efficiently access and utilize Brazilian public data, expanding the scope of AI applications in regions with rich but fragmented government datasets.
