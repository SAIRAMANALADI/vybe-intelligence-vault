## Summary
canvas-cowork is a Windows desktop application that provides a spatial canvas for managing AI-generated content, tasks, and agent interactions from the command line. It enables users to create, organize, and recall nodes containing text, images, video, and agent outputs in a shared visual workspace.

## Key Features
- Spatial canvas for organizing AI-generated content and tasks
- Support for text, image, video, and agent output nodes
- Recall and reuse past work for continuity
- Node management (move, edit, group) for clean workflows
- Windows desktop application with CLI integration
