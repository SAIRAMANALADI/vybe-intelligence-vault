## Summary
A local Model Context Protocol (MCP) server for Meta, Instagram, and Facebook Ads, enabling AI clients to interact with Meta's Marketing API. It provides 78 tools for managing campaigns, ads, insights, audiences, and more via OAuth or access token authentication.

## Key Features
- 78 tools for Meta Ads management (campaigns, ads, insights, audiences, etc.)
- Supports both access token and local OAuth authentication flows
- Cursor-based pagination for scalable data retrieval
- Async insights reporting with CSV export for MMM workflows
- Secure token redaction in responses and OAuth callback server

## Why It Matters for RAG Builders
It enables AI agents and MCP clients to programmatically interact with Meta Ads data, streamlining automation for marketing workflows and insights generation.
