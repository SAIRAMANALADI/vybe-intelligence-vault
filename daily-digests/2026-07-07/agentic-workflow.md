## Summary
agentic-workflow is a template system designed to help Windows users quickly set up AI-driven development workflows for software projects. It automates the creation of project-specific files like task lists, review checklists, and AI prompt files to streamline development and task management.

## Key Features
- Automated generation of project-specific files (task lists, review checklists, AI prompts)
- Bootstrap process to scan project structure and create tailored workflow files
- Designed for Windows users with simple setup and minimal system requirements
- Supports parallel agent spawning and multi-step execution via Backlog.md
- Template-based project setup for repeatable AI-assisted development flows
