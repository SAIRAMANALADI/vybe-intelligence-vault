## Summary
AgentQL MCP Server is a Model Context Protocol (MCP) server that enables structured data extraction from web pages using AgentQL's capabilities. It acts as a bridge between web data and AI agents or applications.

- Integrates seamlessly with MCP-compatible applications (Claude, VS Code, Cursor, Windsurf)
- Supports configuration via API keys for secure access
- Provides debugging tools like MCP Inspector for development
- Offers one-click installation for popular IDEs
