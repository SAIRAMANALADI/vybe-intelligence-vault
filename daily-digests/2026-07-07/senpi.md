## Summary
senpi is an opinionated TypeScript monorepo fork of pi-mono, designed as a lightweight coding-agent runtime for AI assistants like Dori. It adds built-in extensions and core tweaks to enhance agent capabilities while maintaining upstream compatibility.

## Key Features
- Built-in extensions for intent gating, todo enforcement, and per-model prompt presets
- Dynamic system prompt with intent gate for forced tool-use validation
- Permission system with allow/deny rules and TUI prompts
- Session recovery and context compaction for adaptive memory management
- Modular installable extensions for LSP, AST-grep, web search, and goal tracking

## Why It Matters for RAG Builders
senpi provides a lightweight, extensible runtime for AI coding agents with built-in features critical for RAG pipelines, reducing integration overhead while ensuring robust agent behavior.
