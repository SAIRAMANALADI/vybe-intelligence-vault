## Summary
A pure-Python Model Context Protocol (MCP) server providing local, real-time byte-wrangling utilities including encoding, hashing, cryptographic primitives, Ethereum/EVM tooling, and serialization formats. It operates entirely offline with no network dependencies.

## Key Features
- Comprehensive byte encoding/decoding (hex, Base64, Base32, Base58, etc.)
- Cryptographic hashing (SHA, MD5, CRC, HMAC) and password hashing (scrypt, PBKDF2, bcrypt, argon2)
- Ethereum/EVM toolset (keccak, ABI/RLP encoding, BIP-39 mnemonics, HD key derivation)
- Serialization support (CBOR, MessagePack, bencode, ASN.1, SSZ, protobuf)
- Local, offline computation with no external API dependencies

## Why It Matters for RAG Builders
It provides essential local byte-level and cryptographic utilities for RAG pipelines, ensuring data integrity, encoding/decoding, and secure processing without external dependencies.
