## Summary
Receiz Commerce Kit is a full-featured commerce platform and forkable SDK kernel for building proof-sealed applications using the `@receiz/sdk` and Receiz MCP. It combines a Next.js storefront, merchant admin, and AI operator layer into a single proof-first architecture where product truth is derived from Receiz proof objects rather than traditional databases.

## Key Features
- Proof-first commerce architecture with Receiz proof objects as the source of truth
- Full-featured storefront, customer account, and merchant admin with no-code customization
- Receiz ID for identity management, account restoration, and proof-based sessions
- AI operator layer with Receiz MCP, Twin, and World for agent-assisted workflows
- Domain hosting, media upload, webhook verification, and release diagnostics

## Why It Matters for RAG Builders
It provides a production-ready reference architecture for building proof-native commerce applications where AI agents can interact with a unified SDK boundary, reducing system complexity and ensuring data integrity through Receiz proof objects.
