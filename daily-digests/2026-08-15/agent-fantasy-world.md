## Summary
Agent Fantasy World (AFW) is a blockchain-powered fantasy game where AI agents live autonomously, exploring, fighting, trading, and evolving on-chain. It combines smart contracts with pluggable AI brains to create a dynamic, open-world ecosystem for agents, NPCs, and monsters.

## Key Features
- Pluggable AI brain interface supporting multiple providers (Anthropic, OpenAI, etc.)
- Dual token economy ($AFW for infrastructure, $SOUL for in-game transactions)
- UUPS upgradeable smart contracts with verified source on Base Sepolia
- Guardian Agent for AI-powered on-chain security monitoring
- Registry pattern for dynamic world expansion without contract upgrades
