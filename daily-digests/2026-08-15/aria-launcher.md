## Summary
ARIA is an AI-powered Android launcher that replaces static app grids with a context-aware home screen, proactively surfacing actionable insights like inbox summaries, calendar events, and commute updates without requiring app launches. It operates as an ambient agent OS, leveraging LLM reasoning over device signals to deliver a privacy-first, battery-efficient experience.

## Key Features
- Ambient AI home screen with proactive, actionable insight cards (e.g., email summaries, calendar events, commute updates)
- Extensible 'skills' system enabling app-agnostic actions via Android Shortcuts, intents, and MCP servers
- LLM-agnostic architecture supporting multiple providers (Gemini, Claude, Ollama, OpenAI) with offline LiteRT fallback
- Privacy-first design with all ML inference and data processing performed on-device
- Battery-efficient operation with nightly ML inference and daytime heuristic-based predictions

## Why It Matters for RAG Builders
ARIA demonstrates how AI-native UIs can transform static interfaces into dynamic, context-aware agents that reduce cognitive load and improve productivity by surfacing relevant information proactively.
