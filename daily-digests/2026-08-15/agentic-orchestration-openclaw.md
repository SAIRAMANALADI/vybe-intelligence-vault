## Summary
A plugin for OpenClaw that transforms single-agent LLM interactions into a multi-agent orchestration system, enabling complex task decomposition, specialized agent routing, and persistent session memory. It automates backend setup and integrates CrewAI-based orchestration with local or cloud models.

## Key Features
- Automated backend setup and management for zero-config deployment
- Dynamic multi-agent planning with specialized roles (research, triage, writing, etc.)
- Model-agnostic support (Ollama, OpenAI, Anthropic, Hugging Face) with automatic provider selection
- Persistent session memory and knowledge base across conversations
- Seamless integration with OpenClaw tools and MCP servers (GitHub, docs, filesystem, etc.)

## Why It Matters for RAG Builders
It enables RAG builders to offload complex, multi-step tasks to a deterministic multi-agent system, reducing hallucinations and improving efficiency while maintaining local-first flexibility.
