## Summary
A collection of 45 stateless utility tools designed for AI agents, providing deterministic, API-key-free functionality for URL/HTTP operations, DNS/RDAP lookups, JWT inspection, encoding, parsing, cron scheduling, and composite reports. Built for MCP-native agent environments.

## Key Features
- 45 stateless utility tools for AI agents with no session or cache dependency
- Supports MCP-native integration with manifest, connection status, and privacy audit tools
- Deterministic outputs with no LLM calls or fuzzy results
- Public endpoint-only network calls (rdap.org, dns.google, user-supplied URLs)
- Fast execution with most tools under 100ms and networked tools under 5s

## Why It Matters for RAG Builders
Provides essential stateless utility tools that AI agents rely on for deterministic, API-key-free operations, reducing dependency on external services and improving reliability in RAG pipelines.
