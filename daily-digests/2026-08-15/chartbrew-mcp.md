## Summary
chartbrew-mcp is a bridge that connects AI agents to Chartbrew dashboards and datasets using the Model Context Protocol (MCP). It enables AI tools like Claude, Cursor, and GitHub Copilot to query and interact with live data, charts, and analytics in Chartbrew.

## Key Features
- Connects AI agents to Chartbrew dashboards and datasets via MCP
- Supports secure embedding and restricted access modes for privacy
- Enables AI tools to query live data and generate insights
- Works with popular AI assistants like Claude, Cursor, and GitHub Copilot
- Provides read-only and unrestricted modes for flexible data access

## Why It Matters for RAG Builders
