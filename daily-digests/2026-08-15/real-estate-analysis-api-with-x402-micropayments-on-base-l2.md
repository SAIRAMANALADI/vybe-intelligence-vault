## Summary
A real estate analysis API that provides structured property data extraction, FHA compliance scanning, and investment metric calculations with x402 micropayments on Base L2. Designed for autonomous AI agents with no API keys or subscriptions required.

## Key Features
- Pay-per-call pricing via x402 micropayments on Base L2 (USDC)
- Structured property data extraction from raw listing text
- FHA compliance scanning with 50+ violation patterns
- Investment metric calculations (cap rate, cash-on-cash, DSCR, etc.)
- MCP server integration for direct AI agent compatibility

## Why It Matters for RAG Builders
It enables AI agents to autonomously pay for real estate analysis services without subscriptions or API keys, reducing friction in agent workflows.
