## Summary
RxyCode is a plan-and-execute AI coding agent with hierarchical task decomposition, safe tool orchestration, and anti-hallucination validation. It features a streaming OpenTUI terminal UI, tiered caching, and 30+ built-in tools for file operations, shell commands, web search, and more.

## Key Features
- Hierarchical task decomposition with parallel execution and dependency awareness
- Dedicated validator to check tool results against original goals before reporting success
- Three-level caching (exact hash, semantic similarity, Provider KV) for blazing-fast responses
- 30+ built-in tools including file ops, shell, web search, git, RAG, and MCP integration
- OpenTUI terminal UI with streaming output, ScrollBox chat, and native textarea

## Why It Matters for RAG Builders
RxyCode provides a robust, plan-and-execute framework for AI agents with built-in safety and validation, making it essential for building reliable RAG systems that require complex tool orchestration and anti-hallucination guarantees.
