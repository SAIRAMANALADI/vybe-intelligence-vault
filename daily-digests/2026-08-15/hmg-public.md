## Summary
HMG (Holographic Memory Graph) provides durable, branch-aware, and governable long-term memory for AI coding agents, ensuring context persistence across sessions and preventing repeated relearning of previously settled decisions or codebase knowledge.

## Key Features
- Branch-scoped memory isolation (tenant → workspace → repository → branch) for traceable context across sessions
- Governance controls (quarantine, seal, tombstone) to manage sensitive or risky memory atoms
- One-shot recall via MCP tools or HTTP API, returning complete context without prompt-stuffing or context window limits
- Correction lineage and audit trails for all memory operations, ensuring traceability and versioning
- 49 MCP tools and SDKs (Python/TypeScript) for seamless integration with 19+ AI agents and clients

## Why It Matters for RAG Builders
HMG eliminates the critical gap of persistent, auditable context for AI agents, enabling reliable long-term memory without sacrificing governance or branch-awareness, which is essential for building trustworthy RAG and agentic systems.
