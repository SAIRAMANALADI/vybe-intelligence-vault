## Summary
Merchant Context provides a standardized schema and tooling to enable buyer agents to discover, compare, and act on merchant offers with structured, machine-readable context. It includes a schema for commerce readiness, an MCP inspector service, and a checklist for integration.

## Key Features
- Standardized JSON schema for merchant offers and context
- MCP-based inspector service for validating merchant endpoints
- Agentic commerce readiness checklist for integration guidance
- x402 payment protocol support for secure transactions
- Protocol mapping to existing commerce standards

## Why It Matters for RAG Builders
It provides a critical layer of structured, machine-readable context for buyer agents to reliably discover and act on merchant offers, reducing ambiguity and improving integration efficiency.
