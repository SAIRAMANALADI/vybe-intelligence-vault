## Summary
Terse is an on-device AI agent butler that optimizes, monitors, and manages AI coding agents like Claude Code, Cursor, and Copilot. It compresses prompts by 40–70%, enforces budget limits, and provides live diagnostics to reduce API costs and improve efficiency.

## Key Features
- Live monitoring of AI coding agents (tokens, cost, cache efficiency, burn rate)
- Prompt compression (40–70%) with code protection using multiple techniques
- Budget circuit breaker to prevent runaway agent spend before API calls
- MCP server discovery, risk-scoring, and management without JSON editing
- 25 one-click diagnostic scans to identify and fix waste (cache thrash, duplicate tool calls, etc.)
