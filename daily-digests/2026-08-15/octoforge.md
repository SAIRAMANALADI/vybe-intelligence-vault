## Summary
OctoForge is a self-hosted, multi-user agent platform designed for teams, featuring a typed Python core that can be embedded into custom stacks. It enables teams to deploy a shared assistant that learns new skills, manages internal APIs securely, and handles concurrent interactions across multiple users and channels.

## Key Features
- Typed Python core with Protocol-based ports for embedding in custom stacks
- Dynamic skill and knowledge management stored in a database, enabling runtime updates without redeployment
- Structured secret management with encrypted storage and zero exposure to the model or logs
- Concurrent exchange-based dialogs with durable obligations and background task support
- Multi-user isolation with ownership-based SQL predicates and cross-user operator console

## Why It Matters for RAG Builders
OctoForge provides a robust, embeddable framework for building secure, scalable multi-user agent systems with dynamic skill integration and runtime configurability, critical for teams needing customizable AI assistants.
