## Summary
Assemblash is a local-first visual document engine and MCP server designed to enable humans and AI agents to create, modify, and render structured visual documents. It provides a machine-readable document model, a local API, and an MCP server for agent access, focusing on composable layers and templates rather than full image-editing suites.

## Key Features
- Structured visual document model with layers, groups, and templates
- Local API and MCP server for agent and human interaction
- Deterministic rendering and export (PNG, SVG)
- Headless operation with optional reference UI
- Agent-native operations with validation and undo support

## Why It Matters for RAG Builders
Assemblash provides a programmable middle layer for structured visual composition that bridges human and AI agent workflows, enabling reliable, reversible, and inspectable document editing essential for RAG pipelines.
