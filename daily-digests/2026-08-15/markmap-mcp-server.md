## Summary
A Model Context Protocol (MCP) server that converts Markdown into interactive mind maps using markmap, with optional server-side export to PNG/JPG/SVG for agent-friendly delivery. Runs entirely locally without third-party API dependencies.

## Key Features
- Converts Markdown headings and nested lists into interactive HTML mind maps
- Supports server-side export to PNG/JPG/SVG via Playwright for direct agent consumption
- Configurable return modes (path, content, or both) and open behavior (always, never, agent-decided)
- Privacy-first with fully local conversion and no cloud API dependencies
- Includes browser preview, export toolbar, and offline HTML support

## Why It Matters for RAG Builders
It enables AI agents to dynamically generate and deliver interactive mind maps from Markdown content, enhancing RAG systems with structured visualizations for better user understanding.
