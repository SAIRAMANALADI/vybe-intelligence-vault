## Summary
Vedākṣha is a clean-room Rust ephemeris and Vedic astrology engine designed for agentic-AI applications, offering sub-arcsecond planetary precision with algorithms traced to primary sources. It provides a property-graph representation of astrological charts and integrates with the Model Context Protocol (MCP) for AI agent interactions.

## Key Features
- Sub-arcsecond planetary precision with 851 tests and 24,350 oracle rows for validation against JPL Horizons
- Clean-room implementation with cited algorithms and no GPL contamination, ensuring provenance and auditability
- Agentic-AI-native via Model Context Protocol (MCP) server with 12 tools and property-graph chart representations
- Multi-platform support: Rust, Python, WASM, and Docker, with zero-data analytical ephemeris for edge deployment
- Comprehensive Vedic astrology features including nakshatras, dashas, vargas, yogas, shadbala, and ayanamshas
