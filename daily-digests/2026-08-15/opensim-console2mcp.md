## Summary
A Java-based bridge that connects the OpenSimulator REST console to the MCP (Model Context Protocol) protocol, enabling seamless integration between OpenSimulator and MCP-compatible clients or tools.

## Key Features
- Bridges OpenSimulator REST console with MCP protocol for standardized communication
- Supports multiple transport modes (stdio, HTTP, SSE) for flexibility in deployment
- Dockerized with multi-arch support (AMD64, ARM64) for easy deployment
- Integrates with OpenSimulator Docker stack via environment variables
- Provides debug and diagnostics features for troubleshooting

## Why It Matters for RAG Builders
It enables OpenSimulator users to leverage MCP-compatible AI tools and frameworks by standardizing the interface between OpenSimulator's REST console and modern AI ecosystems.
