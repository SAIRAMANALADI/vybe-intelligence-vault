## Summary
DjenisAiAgent is an experimental agent framework for observable computer automation on Windows, enabling structured tool calls to interact with desktop applications and browsers under explicit permission boundaries. It uses Gemini for reasoning and enforces strict policy tiers to ensure safe execution.

## Key Features
- Permission-tiered tool execution with explicit boundaries (observe, interact, system)
- Structured ReAct loop for iterative reasoning and action with Gemini
- Runtime policy enforcement and audit logging with redaction
- Dual-mode deployment (Windows native or Docker-based remote browser automation)
- Authenticated local web console with WebSocket-based screen streaming
