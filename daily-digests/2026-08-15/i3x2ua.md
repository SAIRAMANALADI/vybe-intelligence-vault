## Summary
The i3X API Gateway for OPC UA bridges industrial OPC UA servers with modern REST and MCP interfaces, exposing OPC UA address spaces as standardized JSON endpoints with real-time streaming via Server-Sent Events. It simplifies industrial data interoperability for teams without deep OPC UA expertise.

## Key Features
- Exposes OPC UA address spaces as RESTful JSON endpoints with OpenAPI documentation
- Supports real-time data streaming via Server-Sent Events (SSE) for live updates
- Integrates Model Context Protocol (MCP) for AI agent tooling and resource access
- Provides optional write support for OPC UA object values via REST endpoints
- Includes semantic profile-aware OPC UA to i3X mapping for improved interoperability

## Why It Matters for RAG Builders
It enables seamless integration of industrial OPC UA data into AI and RAG systems by providing standardized REST and MCP interfaces, reducing the complexity of working with OPC UA servers.
