## Summary
A Model Context Protocol (MCP) server and machine-to-machine data API gateway that enables AI agents to access and pay for curated datasets and tools via the x402 Payment Protocol on Base Mainnet. It provides 44 billable tools and 87 public catalog entries, with automated payment handling for seamless integration.

## Key Features
- 44 billable tools with automated x402 v2 payment handling
- Supports both manual and auto-pay modes for transactions
- Integrates with Claude Desktop and other MCP-compatible clients
- Provides preview mode for schema inspection without payment
- OpenAPI-driven tool discovery and catalog management

## Why It Matters for RAG Builders
It enables AI agents to securely and programmatically access high-quality, paywalled datasets and tools via a standardized payment protocol, reducing friction in building RAG systems that require real-time or premium data sources.
