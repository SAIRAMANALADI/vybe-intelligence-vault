## Summary
Kery is an autonomous AI agent framework designed to test web applications for bugs without requiring manual test scripts. It crawls, plans, and executes tests, then generates detailed reports with screenshots and bounding boxes for visual, functional, and UX issues.

## Key Features
- Intent-driven autonomous testing with no manual script maintenance
- Multi-agent system (Navigator, Review, Triage) for comprehensive bug detection
- Visual, functional, and UX bug reporting with screenshots and bounding boxes
- MCP server for IDE integration (Claude, Cursor, etc.) and real-time testing
- Agent memory for self-healing navigation and false positive reduction

## Why It Matters for RAG Builders
Kery automates web application testing with AI agents, reducing manual effort and improving bug detection accuracy for RAG and AI stack builders.
