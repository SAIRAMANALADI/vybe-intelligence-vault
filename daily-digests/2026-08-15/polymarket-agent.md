## Summary
A web-based AI agent that analyzes Polymarket prediction markets to identify mispriced opportunities by comparing AI-estimated fair values against market odds. It provides real-time edge detection, sentiment analysis, and visual reasoning for traders.

## Key Features
- AI-powered fair value estimation for prediction markets
- Edge detection (>5% discrepancy between AI and market odds)
- Real-time AI reasoning with visual typing effects
- Sentiment gauge for market mood analysis
- Visual probability bars and neural network animations
