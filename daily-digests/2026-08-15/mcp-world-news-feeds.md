## Summary
mcp-world-news-feeds is a Model Context Protocol (MCP) server providing curated international news feeds as structured data for AI agents. It enables real-time access to over 1394+ live news sources with normalized metadata and fallback proxy mechanisms for robust feed fetching.

## Key Features
- Curated list of 1394+ international news feeds with normalized metadata (title, link, published, summary)
- Direct and proxy-based feed fetching with CF-robust fallback for blocked sources
- Seamless integration with MCP clients (Claude Desktop, Cursor, Windsurf) and plain-English query support via ask_pipeworx
- Filtering capabilities by category, keyword, or feed ID for targeted data retrieval
- Part of a larger MCP gateway ecosystem for AI agents

## Why It Matters for RAG Builders
It provides structured, real-time news data essential for RAG pipelines requiring up-to-date world events and enables AI agents to dynamically fetch and process external content.
