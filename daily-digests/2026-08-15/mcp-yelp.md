## Summary
mcp-yelp is a Model Context Protocol (MCP) server that wraps the Yelp Fusion API, enabling AI agents to search for local businesses, retrieve business details, and fetch reviews. It is part of the Pipeworx ecosystem, which provides a unified gateway to over 1,394 live data sources.

## Key Features
- Provides MCP-compatible tools for Yelp API integration (search_businesses, get_business, get_reviews)
- Supports plain English queries via ask_pipeworx for automated tool selection
- Part of a larger gateway (Pipeworx) with 1,394+ data sources
- Handles upstream API reliability issues (e.g., reviews endpoint 404s)
- Offers both direct MCP server and full gateway integration options

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate real-time Yelp business data into RAG pipelines, enhancing local search and recommendation capabilities.
