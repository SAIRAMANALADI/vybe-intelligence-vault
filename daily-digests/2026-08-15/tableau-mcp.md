## Summary
Tableau MCP is an official Tableau-supported suite of developer primitives that enables AI applications to integrate with Tableau's data visualization and analytics platform. It provides tools, resources, and prompts to facilitate natural language interactions with Tableau data sources and workbooks.

## Key Features
- Enables natural language queries against Tableau data sources and workbooks
- Supports both hosted (Tableau Cloud) and self-hosted deployment options
- Provides OAuth 2.1 authentication for secure access control
- Offers MCP-compatible client integrations for popular AI tools like Slack, Claude, and ChatGPT
- Includes enterprise deployment guides for Tableau Server customers

## Why It Matters for RAG Builders
It bridges AI applications with Tableau's powerful data visualization capabilities, enabling AI agents to retrieve, analyze, and present data insights directly from Tableau workbooks and data sources.
