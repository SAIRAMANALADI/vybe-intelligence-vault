## Summary
streamlit-mcp enables agents to natively interact with Streamlit applications over the MCP protocol, allowing introspection, manipulation of widgets, and reading of rendered output without browser automation. It bridges Streamlit apps with AI agents by exposing tools for widget control and custom functions.

## Key Features
- Expose Streamlit apps as MCP servers for agent interaction
- Introspect and manipulate widgets (e.g., text inputs, sliders, buttons) via MCP tools
- Support for custom semantic tools via `@mcp_tool` decorator
- HTTP/SSE transport with bearer token authentication for secure access
- Human-in-the-loop mode for live agent interaction in the browser

## Why It Matters for RAG Builders
It enables AI agents to directly interact with Streamlit applications, expanding the tooling available for RAG pipelines and agentic workflows without requiring browser automation.
