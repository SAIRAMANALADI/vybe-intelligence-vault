## Summary
An MCP server enabling AI assistants to interact with AutoLISP-capable CAD software (e.g., BricsCAD) for real-time 2D drafting and 3D solid modeling without requiring COM, SDKs, or plugins. It leverages AutoLISP and DXF commands to bridge AI workflows with professional CAD tools on Linux.

## Key Features
- 100+ MCP tools for 2D drafting (dimensions, hatches, blocks) and 3D solid modeling (extrude, booleans, slice)
- Real-time CAD interaction via AutoLISP file bridge and DXF commands
- Batch operations with atomic undo groups for efficient AI workflows
- Verification tools (bounding boxes, intersection checks, exact measurements) without screenshots
- Portable across AutoLISP-capable CADs (AutoCAD, ARES Commander, ZWCAD, etc.)

## Why It Matters for RAG Builders
It enables AI systems to directly interact with professional CAD software for precise 2D and 3D modeling, unlocking advanced design automation without proprietary SDKs or Windows dependencies.
