## Summary
Funplay MCP for Unity is an MIT-licensed Unity Editor MCP server that enables AI assistants (e.g., Claude Code, Cursor, LM Studio) to interactively build, modify, and validate Unity projects via 128 built-in tools. It supports scene creation, script generation, runtime validation, input simulation, and editor automation through in-memory C# execution.

## Key Features
- 128 built-in MCP tools for scene editing, script generation, and runtime validation
- In-memory C# execution (`execute_code`) for direct Unity API access without project file writes
- Play Mode automation with input simulation, screenshots, and performance analysis
- One-click MCP client configuration for popular AI tools (Claude, Cursor, LM Studio, etc.)
- Project Skills manager for AI workflow customization and tool exposure control

## Why It Matters for RAG Builders
It bridges AI assistants directly into the Unity Editor, enabling rapid prototyping and automation of game development tasks through natural language prompts.
