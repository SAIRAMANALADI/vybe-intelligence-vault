## Summary
A TypeScript MCP server providing deterministic PRD (Product Requirements Document) verification and generation for AI agents like Codex, Gemini CLI, and Claude Code. It enforces Hard Output Rules, cross-section traceability, and closed-loop reliability calibration with multi-judge consensus.

## Key Features
- Portable verifier for PRD sections and documents with deterministic Hard Output Rules (no LLM calls)
- Closed-loop reliability calibration with Bayesian posteriors, Kaplan-Meier survival math, and KPI gate tuning
- 17 MCP tools for orchestration, validation, and context management
- Multi-judge consensus system with externally-grounded oracles and held-out partition seals
- Cross-platform support for Codex, Gemini CLI, Claude Code, and CI pipelines

## Why It Matters for RAG Builders
It ensures AI-generated PRDs are structurally sound, traceable, and reliable before downstream code generation or sprint planning, preventing costly hallucinations in agentic pipelines.
