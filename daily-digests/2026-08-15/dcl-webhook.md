## Summary
DCL Trust Oracle provides a deterministic policy evaluation layer for LLM outputs with a tamper-evident audit chain using cryptographic micropayments via the x402 protocol. It offers both REST API and MCP server interfaces for verifiable forensic analysis without storing raw content.

## Key Features
- Deterministic policy evaluation for LLM outputs with tamper-evident audit chains
- Dual REST API and MCP server interfaces with identical pricing via x402 micropayments
- Metadata-only architecture—raw content is never stored, only cryptographic hashes and decision metadata
- Built-in policies for safety, jailbreak detection, content quality, and general-purpose evaluation
- Post-action forensic analysis with deep audit capabilities and chain integrity verification

## Why It Matters for RAG Builders
It enables verifiable, tamper-evident policy enforcement for AI systems with cryptographic micropayments, ensuring trust and accountability in LLM outputs without storing sensitive data.
