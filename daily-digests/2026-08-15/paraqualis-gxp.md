## Summary
A Claude Code plugin providing a comprehensive toolkit for life-sciences regulatory compliance and computer-system validation (CSV). It automates GAMP 5, 21 CFR Part 11, EU GMP Annex 11, eCFR, and openFDA workflows, including an IQ/OQ/PQ qualification engine that drafts validation packs in minutes.

## Key Features
- Automated generation of IQ/OQ/PQ qualification packs for any application
- Regulatory compliance checks for GAMP 5, 21 CFR Part 11, and EU GMP Annex 11
- Live eCFR and openFDA API integration for real-time regulatory text and data
- Parallel sub-agent architecture for concurrent qualification tasks
- Document protection hook to enforce change control on approved records
