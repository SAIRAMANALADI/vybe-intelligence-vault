## Summary
FlowForge is a client-side web application that enables users to visually build, chain, and execute complex AI pipelines using interactive DAG node graphs with zero code required. It supports 400+ AI models from OpenRouter for text, image, video, and other multi-modal tasks, all executed directly in the browser for data privacy.

## Key Features
- Drag-and-drop visual AI pipeline builder with infinite canvas and node-based workflows
- Supports 400+ AI models (text, image, video, audio) via OpenRouter with multi-API key management
- Client-side execution ensures 100% data privacy with no backend server costs
- Smart file content extraction for PDF, DOCX, TXT, and other formats with auto Markdown conversion
- Touch-optimized interface with keyboard shortcuts, auto-save, and Google Drive sync for workflows

## Why It Matters for RAG Builders
FlowForge empowers RAG builders to visually design and test multi-modal AI pipelines with zero code, ensuring rapid prototyping and deployment of complex workflows directly in the browser.
