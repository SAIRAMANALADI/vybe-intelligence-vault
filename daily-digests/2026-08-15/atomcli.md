## Summary
AtomCLI is an open-source terminal-based AI coding assistant that enables developers to write, debug, and refactor code directly from the command line using an interactive TUI with mouse support. It supports multiple AI providers, local data storage, and extensibility via MCP servers and skills.

## Key Features
- Interactive TUI with mouse support and syntax highlighting for seamless terminal-based coding
- Multi-provider AI integration with automatic model routing and fallback mechanisms
- Local data storage with persistent memory and offline semantic search for privacy
- Extensible via MCP servers and skills for custom tools and specialized workflows
- Built-in developer tools like test generation, security scanning, and performance analysis

## Why It Matters for RAG Builders
AtomCLI provides a privacy-focused, terminal-native AI agent framework that integrates seamlessly into developer workflows, enabling efficient code generation, debugging, and refactoring without cloud dependency.
