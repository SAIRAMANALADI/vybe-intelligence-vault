## Summary
A personality-first desktop AI companion that acts as a digital partner with character, memory, and a living world. It emphasizes relationship continuity over tool optimization, featuring multiple protagonists, a dynamic world simulation, mutable behavior, and local-first memory storage.

## Key Features
- Three protagonist slots with active switching and role continuity
- Living world simulation with day scripts, Moments, and wardrobe/bookshelf systems
- Mutable behavior layer with gated reflection for dynamic personality evolution
- Local-first architecture using SQLite and vector-based memory recall
- Sandboxed runtime with permission-gated tools and MCP (Model Context Protocol) support

## Why It Matters for RAG Builders
It provides a unique framework for building AI companions with persistent character and memory, essential for applications requiring long-term user relationships and dynamic interaction.
