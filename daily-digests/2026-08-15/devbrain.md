## Summary
DevBrain is an Azure-native remote MCP server that provides persistent, shared access to developer knowledge via Azure Functions and Cosmos DB. It eliminates the need for repeated file uploads by enabling any AI tool to connect to a single knowledge store deployed once in the Microsoft Azure ecosystem.

## Key Features
- Single deployment for shared knowledge across all projects and AI tools
- OAuth 2.0 with Dynamic Client Registration for seamless authentication
- Cosmos DB-backed persistent storage with project isolation
- Safe document editing via two-step preview and apply workflows
- Support for chunked document uploads for large files

## Why It Matters for RAG Builders
DevBrain eliminates the repetitive overhead of uploading context for every AI tool by providing a centralized, persistent knowledge store that any MCP-compatible AI can access seamlessly.
