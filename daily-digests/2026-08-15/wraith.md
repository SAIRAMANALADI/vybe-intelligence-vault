## Summary
Wraith is a mature Java-based AI agent framework that evolves from a CLI tool to a desktop application and IM gateway (QQ/Feishu bots). It supports multi-agent collaboration, RAG, MCP integration, and advanced features like TUI, LSP diagnostics, and Git side-history snapshots.

## Key Features
- Multi-agent collaboration with planner, worker, and reviewer roles
- Built-in RAG with code vectorization and semantic search
- MCP protocol support for dynamic tool integration
- TUI and desktop app with inline/lanterna/plain renderers
- Git side-history snapshots and rollback for version control
