## Summary
A Windows-based desktop application that enables teams to query enterprise documents (PDFs, Word, text) using a local RAG-powered chatbot, providing answers with cited sources while keeping all data private and on-premises.

## Key Features
- Local RAG implementation for private document querying without cloud dependency
- Supports multiple document formats (PDF, DOCX, TXT, MD) with source citation
- Multi-user support for team collaboration with centralized document storage
- Offline-capable after initial setup with no external data transmission
- User-friendly interface requiring no technical expertise for setup or operation

## Why It Matters for RAG Builders
It provides an accessible, privacy-focused RAG solution for enterprises to instantly query internal knowledge bases without cloud dependency or complex infrastructure.
