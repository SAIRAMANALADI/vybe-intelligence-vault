## Summary
A FastAPI-based chat agent framework leveraging LangGraph for multi-agent orchestration, featuring security guardrails, Postgres-backed conversation checkpointing, and integration with OpenSearch RAG and MCP servers for customer support workflows.

## Key Features
- Built on LangGraph for multi-agent orchestration with specialized routing (e.g., triage to sales, billing, or support specialists)
- Security guardrails including input sanitization, PII detection via Presidio, and output validation
- Postgres-backed conversation checkpointing for stateful interactions
- Integration with OpenSearch for RAG and remote MCP servers for extended tooling
- Comprehensive testing suite (unit, integration, regression) with LLM-judge evaluations

## Why It Matters for RAG Builders
It provides a secure, scalable foundation for building multi-agent AI systems with RAG integration and robust conversation management.
