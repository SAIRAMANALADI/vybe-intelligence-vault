## Summary
Chamber is a desktop workspace for creating, running, and coordinating AI agents with a focus on Agent-to-Agent (A2A) collaboration. It provides a shared operating environment where agents can delegate tasks, exchange messages, and manage stateful workflows, powered by GitHub Copilot.

## Key Features
- A2A-first agent collaboration with peer-to-peer messaging and task delegation
- Shared operating room for agents with identity, memory, and tools
- Stateful task tracking, progress monitoring, and cancellation
- Lens views, Canvas pages, and cron jobs for UI and automation
- Marketplace integration for extending agent capabilities

## Why It Matters for RAG Builders
Chamber enables RAG builders to create and coordinate autonomous AI agents that can delegate tasks, share context, and collaborate on complex workflows, reducing the need for manual orchestration.
