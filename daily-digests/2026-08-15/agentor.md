## Summary
Agentor is a Python framework for building, deploying, and managing long-running AI agents with durability, observability, and security. It supports multi-agent communication, MCP server integration, and serverless deployment via Celesto's platform.

## Key Features
- FastAPI-compatible MCP server with decorator API for tool security
- Multi-agent communication via A2A protocol with standardized endpoints
- Serverless deployment with Celesto platform and CLI support
- Built-in observability with agent tracing and monitoring
- Dynamic skill loading from Markdown files for lightweight agent specialization

## Why It Matters for RAG Builders
Agentor simplifies the development and deployment of robust, scalable AI agents with built-in security and observability, making it essential for RAG builders who need reliable agent orchestration.
