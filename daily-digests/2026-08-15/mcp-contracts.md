## Summary
mcp-contracts provides contract safety for MCP servers by versioning, diffing, and validating tool schemas to prevent breaking changes and tool poisoning. It enables teams to pin, test, and enforce MCP interface contracts in CI/CD pipelines.

## Key Features
- Semantic diff engine for MCP tool schemas with breaking/warning/safe classifications
- Contract testing suite for live server validation against baselines
- Signed baselines with Ed25519/RSA support for integrity verification
- Multi-server composition support with dependency graph rendering
- CI-native integration with GitHub Actions, GitLab CI, and CircleCI

## Why It Matters for RAG Builders
It ensures MCP server interfaces remain stable and secure by catching breaking changes and tool poisoning before they impact AI agents.
