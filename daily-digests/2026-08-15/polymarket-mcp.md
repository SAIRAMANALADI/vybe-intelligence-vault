## Summary
A Model Context Protocol (MCP) server providing programmatic access to Polymarket's prediction market data, enabling agents and chatbots to discover, analyze, and interact with markets, events, and trading activity without authentication.

## Key Features
- 7 MCP tools for market discovery, event analysis, and trading data retrieval
- Real-time access to Polymarket's public APIs (Gamma Markets and Data API)
- Comprehensive market analysis with probabilities, volume, liquidity, and sentiment
- 4 pre-built prompts for common workflows (trending markets, event comparison, etc.)
- 3 curated resources for trending markets, categories, and featured events

## Why It Matters for RAG Builders
