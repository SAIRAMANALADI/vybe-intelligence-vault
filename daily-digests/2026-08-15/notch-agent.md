## Summary
NotchAgent is a macOS-native coding agent that integrates with Claude, Codex, and ChatGPT, providing a minimal UI panel that emerges from the Mac's notch. It enables hands-free coding assistance via hotkeys or mouse hover, with persistent chat history and file attachment support.

## Key Features
- Emerges from the Mac's notch with a minimal, non-intrusive UI
- Supports Claude, Codex, and ChatGPT via CLI or embedded web view
- Persistent chat history with session resumption and file attachments
- Global hotkey (Option+Space) and hover-based activation
- Streaming responses and tool activity visualization

## Why It Matters for RAG Builders
NotchAgent provides a novel, space-efficient UI for coding agents on macOS, making it easier for developers to integrate AI assistance into their workflow without disrupting their primary applications.
