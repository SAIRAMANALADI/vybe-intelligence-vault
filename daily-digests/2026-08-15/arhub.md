## Summary
ArHub is a desktop agent workspace designed for research writing, data analysis, and engineering tasks. It integrates agents, files, editors, and workflows into a unified workspace, enabling seamless task execution with persistent state, checkpoints, and artifacts.

## Key Features
- Unified workspace combining agents, files, and editors for seamless task execution
- Persistent state with checkpoints, logs, and artifacts for task resumption and review
- Support for multiple OpenAI-compatible models with independent configuration per agent role
- Extensible Skill workflows and declarative manifest-based extensions
- Built-in document processing with Markdown/LaTeX editing, PDF/DOCX preview, and export

## Why It Matters for RAG Builders
ArHub provides a cohesive environment for AI-driven research and engineering tasks, enabling persistent, multi-step workflows with agent collaboration and document integration, which is critical for building advanced RAG systems.
