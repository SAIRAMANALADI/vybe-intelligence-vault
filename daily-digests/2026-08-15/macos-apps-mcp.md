## Summary
A local MCP server that provides read-and-organize access to Apple's built-in macOS productivity apps (Mail, Reminders, Notes) via the Model Context Protocol (MCP). It enables AI clients like Claude or Cursor to interact with these apps locally using AppleScript, ensuring no data leaves the user's machine.

## Key Features
- 23 tools for interacting with Mail, Reminders, and Notes via MCP clients
- Local execution with no third-party data transmission
- AppleScript-based automation for native macOS app control
- Pagination and ISO 8601 date handling for search operations
- Supports integration with popular MCP clients like Claude Desktop and Cursor

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with macOS productivity apps for tasks like organizing emails, managing reminders, and creating notes, all while keeping data local and private.
