## Summary
Argus is an agent harness designed to enable small or modest LLMs to reliably execute multi-step agentic tasks with structured tooling, memory, scheduling, and a live-trace dashboard for real-time monitoring and control.

## Key Features
- Live-trace dashboard (Observatory) for real-time monitoring of agent decisions and tool calls
- Built-in and dynamically created tools with AST-gated sandboxes and SSRF protection
- Skills with deterministic execution paths for structured procedural knowledge
- SQL-based structured data querying with natural-language-to-SQL capabilities
- Persistent memory with semantic and keyword-based recall, and multi-model role support

## Why It Matters for RAG Builders
Argus provides the critical scaffolding for small or self-hosted LLMs to reliably perform complex agentic tasks, bridging the gap between frontier models and resource-constrained environments.
