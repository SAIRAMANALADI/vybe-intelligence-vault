## Summary
A multi-engine autonomous coding agent runner that provides a unified interface for interacting with different agent engines like Claude Code, OpenAI Codex, and Nous Hermes. It abstracts vendor-specific APIs behind a single adapter layer to avoid lock-in.

## Key Features
- Unified interface for multiple agent engines (Claude Code, Codex, Hermes)
- Zero runtime dependencies with pure Node.js + TypeScript
- Extensible engine architecture via a simple interface
- Availability probing to check engine readiness
- Programmatic and CLI usage with normalized outputs

## Why It Matters for RAG Builders
It enables RAG builders to seamlessly switch between different agent engines without rewriting integrations, reducing vendor lock-in and simplifying multi-agent workflows.
