## Summary
Claude-brewcode is a suite of four plugins for Claude Code designed to enhance AI-driven development workflows. It enables infinite task execution, quorum reviews, skill/agent creation, semantic search, documentation tools, and text utilities to streamline AI-assisted coding and project management.

## Key Features
- Four integrated plugins (brewcode, brewdoc, brewtools, brewui) for development, documentation, utilities, and UI workflows
- Infinite task execution with bounded units, quorum reviews, and delegation contracts for AI agents
- Semantic code search via Semble MCP server for enhanced RAG capabilities
- Automated documentation sync, PDF conversion, and publishing to brewpage.app
- Text optimization, secrets scanning, and plugin management utilities

## Why It Matters for RAG Builders
It provides a structured framework for AI agents to execute tasks efficiently with clear delegation and scope management, critical for building robust RAG systems.
