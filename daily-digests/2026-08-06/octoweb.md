## Summary
Octoweb is a keyboard-first, AI-augmented browser built on WebKit and Rust, designed to amplify thinking by minimizing mouse use and integrating AI assistants directly into the browsing experience. It features an MCP server for AI-driven browser control and proactive learning capabilities.

## Key Features
- Keyboard-first navigation with fuzzy-search command palette and fast-access slots
- Built-in AI sidebar powered by local agents via ACP for real-time assistance
- MCP server exposing 20+ tools for AI-driven browser control and automation
- Proactive learning agent for pattern recognition and memory of browsing habits
- Session restore, ad/tracker blocking, and smart tab hibernation for efficiency

## Why It Matters for RAG Builders
Octoweb enables AI stack builders to integrate browser automation and real-time AI assistance directly into their workflows, reducing reliance on manual interactions and extending RAG capabilities with live web content.
