## Summary
LunAI is a reinforcement learning project designed to train agents for bullet-hell games in a Touhou-style environment using PPO algorithms. It provides a customizable pygame-based game environment, multi-scale observation maps, reward functions, and curriculum-based training stages.

## Key Features
- Custom pygame-based Touhou-style game environment for RL training
- Multi-scale observation maps (blue/yellow/red) for bullet density and speed
- Baseline MLP and CNN PPO agents with configurable training scripts
- Curriculum-based staged training with level files
- Parallel environment sampling for efficient GPU utilization
