## Summary
A Rust-based MCP server and CLI for sending notifications through an Apprise API server, exposing an MCP tool (`apprise`) and a CLI (`rapprise`) to send tagged or one-off notifications, check health, and integrate with AI agents or workflows.

## Key Features
- Exposes an MCP tool (`apprise`) for sending notifications via tags or one-off URLs through an Apprise API server
- Supports stdio and HTTP MCP transport modes for local or shared deployments
- Provides CLI (`rapprise`) for scripting, debugging, and direct notification sends
- Includes health checks, setup commands, and prompt-based critical alert workflows
- Supports secure authentication via static tokens, OAuth, and verified release installation

## Why It Matters for RAG Builders
It enables AI agents and workflows to send notifications through a wide range of delivery backends via the Apprise API, enhancing observability and alerting in AI-driven systems.
