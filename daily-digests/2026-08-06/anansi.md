## Summary
Anansi is a self-healing, adversarial web scraper designed to handle hostile sites by automatically repairing broken selectors, switching to browsers when needed, and maintaining a coherent anti-bot identity. It includes an MCP server for LLM-driven crawling and data extraction.

## Key Features
- Automatic repair of broken CSS selectors with confidence scoring and healing strategies
- Silent browser fallback (Playwright) for JavaScript-heavy or hostile sites
- Coherent anti-bot identity with TLS fingerprint mimicry and persona matching
- Incremental re-crawling with ETag/Last-Modified/content hashing for efficiency
- Pydantic-based data validation and coercion for structured output

## Why It Matters for RAG Builders
Anansi enables reliable, long-term web scraping in adversarial environments, reducing maintenance overhead and ensuring consistent data extraction for RAG pipelines.
