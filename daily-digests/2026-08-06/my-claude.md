## Summary
my-claude is an all-in-one agent harness for Claude Code that dynamically discovers, classifies, and routes tasks to 200+ specialist agents, skills, and MCP tools without requiring configuration. It acts as a meta-orchestrator, delegating work to the most suitable specialist based on intent and capability matching.

## Key Features
- Dynamic runtime discovery of 200+ agents, skills, and MCP tools without manual configuration
- Priority-based task routing with 4-tier matching system (P1-P4) for optimal specialist assignment
- Built-in 3-phase sprint workflow (Design → Execute → Review) for end-to-end task completion
- Integration with 7 open-source agent frameworks (OMC, OMO, ECC, Agency Agents, etc.) for extensibility
- Automated verification and retry mechanism to ensure task accuracy and reliability
