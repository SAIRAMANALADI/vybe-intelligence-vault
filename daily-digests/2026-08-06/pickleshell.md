## Summary
PickleShell enables ChatGPT to interact directly with a local development environment by providing a secure tunnel to an Agent, Browser, and Terminal service running on a user's machine. It allows AI assistants to execute tasks like file editing, testing, and browser automation while maintaining strict security and isolation.

## Key Features
- Secure outbound-only tunnel for AI assistant access to local services
- Agent service with MCP tools for file operations, session management, and task execution
- Browser automation via Playwright for web interaction and testing
- Strict workspace isolation and file transfer controls with path validation
- Async workflow with session continuity and cancellation support

## Why It Matters for RAG Builders
PickleShell bridges the gap between AI assistants like ChatGPT and local development environments, enabling secure, direct task execution without exposing machines to inbound risks.
