## Summary
Mantis is a signal-to-execution AI system that monitors DeFi protocols across multiple chains (Mantle, Arbitrum, HashKey, Ethereum) to detect smart money wallet clusters using z-score anomaly detection. It enriches signals via Claude Sonnet 5 and delivers alerts or autonomously executes trades based on predefined intents.

## Key Features
- Real-time DeFi protocol monitoring across 4 chains with multi-chain RPC polling
- Z-score anomaly detection for smart money wallet clusters with wallet intelligence enrichment
- LLM-powered signal enrichment via Claude Sonnet 5 for plain-English alerts
- Intent-based autonomous execution layer with ERC-8004 on-chain agent identity logging
- Immutable on-chain audit logging for all signals and executions via SignalAuditLog.sol

## Why It Matters for RAG Builders
Mantis bridges the gap between real-time DeFi signal detection and autonomous execution, providing a critical infrastructure layer for AI-driven trading agents and RAG systems requiring verifiable, auditable, and multi-chain financial intelligence.
