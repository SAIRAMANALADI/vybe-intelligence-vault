## Summary
gtm-mcp is a self-hosted outreach pipeline designed to automate B2B cold outreach workflows within Claude Code. It integrates with Apollo for lead discovery, SmartLead for campaign execution, and leverages Claude for AI-driven classification, personalization, and sequence generation without offloading reasoning to external servers.

## Key Features
- Automated lead discovery via Apollo API
- AI-driven company classification and contact enrichment
- Personalized outreach sequence generation using Claude
- Seamless integration with SmartLead for campaign deployment
- Self-hosted pipeline with local reasoning in Claude Code

## Why It Matters for RAG Builders
