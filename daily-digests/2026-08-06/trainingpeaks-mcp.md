## Summary
A Model Context Protocol (MCP) server that bridges TrainingPeaks with AI assistants like Claude, enabling natural language interaction with workout data, fitness metrics, and athlete settings. It eliminates the need for API approval by using secure cookie authentication, allowing users to query, create, and manage training plans via conversational commands.

## Key Features
- 78+ tools for comprehensive TrainingPeaks data manipulation via natural language
- Secure cookie-based authentication (no API approval required)
- Structured workout creation with auto-computed IF/TSS metrics
- Full CRUD operations for workouts, events, and athlete settings
- Fitness trend analysis (CTL, ATL, TSB) and performance tracking

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with TrainingPeaks data, allowing users to manage workouts, fitness metrics, and training plans through natural conversation without manual API approvals.
