## Summary
MCPHub is a unified management platform for Model Context Protocol (MCP) servers, enabling centralized control, flexible routing, and dynamic orchestration of multiple MCP servers via HTTP/SSE endpoints. It simplifies deployment, monitoring, and scaling of MCP-based tools and resources.

## Key Features
- Centralized management of multiple MCP servers with a unified dashboard
- Flexible routing via HTTP/SSE endpoints (all servers, groups, or individual servers)
- Smart routing with vector semantic search for AI-powered tool discovery
- Hot-swappable server configuration with zero downtime
- OAuth 2.0 and social login support for secure authentication

## Why It Matters for RAG Builders
MCPHub streamlines the deployment and management of MCP servers, making it essential for RAG builders who need scalable, secure, and flexible orchestration of AI tools and resources.
