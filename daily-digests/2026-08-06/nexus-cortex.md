## Summary
Nexus Cortex is a headless, multi-provider AI agent harness designed as a library or server to orchestrate agents across various LLM providers. It supports embedding, CLI scripting, and stateful agent operations with built-in tools, context management, and portable agent memory.

## Key Features
- Supports 12+ LLM providers with 92+ models, enabling seamless switching and routing
- Headless and scriptable CLI with auto-starting stateful agent server
- Built-in tools including MCP integration, sandboxed artifacts, and git/PR tooling
- Portable agent memory (Canon) with append-only JSONL sessions and git-backed history
- Embeddable TypeScript library for custom agent development and integration

## Why It Matters for RAG Builders
Nexus Cortex provides a unified, production-ready harness for building and deploying multi-provider AI agents with portable memory and built-in tooling, essential for scalable RAG and agentic workflows.
