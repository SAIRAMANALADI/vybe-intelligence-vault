## Summary
SatisfactoryMCP is an MCP server and local web map that enables AI assistants like Claude to interact with the game Satisfactory. It reads game save files and provides tools to plan factories, trace logistics, analyze power usage, and visualize world data locally without network access.

## Key Features
- Reads Satisfactory save files and game data locally for accurate planning and analysis
- Provides 42 MCP tools for querying game state, planning factories, and tracing logistics
- Includes a live-updating web map for visualizing terrain, factories, and resources
- Honest factory planning that respects game constraints and avoids overstated outputs
- Supports natural language queries for factory design, power analysis, and resource tracking
