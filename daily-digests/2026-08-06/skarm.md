## Summary
Skarm is a modern, multi-tenant issue tracker designed for teams to plan, track, and ship projects collaboratively. It combines real-time Kanban boards, AI-powered triage, B2B billing, and integrations with GitHub and Figma in a Next.js 16, Convex, and Clerk stack.

## Key Features
- Real-time Kanban boards with drag-and-drop and fractional sorting
- AI-powered issue drafting, triage, and duplicate detection via vector embeddings
- Multi-tenant workspaces with B2B billing and role-based access control
- Two-way sync with GitHub and Figma for seamless workflow integration
- Dependency graph visualization and cycle analytics for project management
