## Summary
A Model Context Protocol (MCP) server providing 60+ tools for Microsoft Graph integration, enabling AI agents to interact with Outlook, Teams, OneDrive, SharePoint, OneNote, and Entra ID via delegated OAuth or app-only authentication over stdio or Streamable HTTP.

## Key Features
- 60+ tools covering calendar, email, meetings, Teams chat, files, people, directory, tasks, and OneNote
- Auth-agnostic design with delegated OAuth or app-only token handling
- Read/write separation enforced via request headers or environment variables
- Supports stdio and Streamable HTTP for MCP client integration
- Battle-tested in production with a small, inspectable dependency footprint

## Why It Matters for RAG Builders
This MCP server enables AI agents to securely and efficiently interact with Microsoft Graph, unlocking rich integrations with Outlook, Teams, and OneDrive for RAG pipelines.
