## Summary
DataMorph CLI is a batch data format converter that streams large files (10GB+) between formats like CSV, JSON, Parquet, YAML, Avro, and Protobuf without memory issues. It automates schema inference and validation for seamless data transformation and CI/CD integration.

## Key Features
- Streaming row-by-row processing for files over 10GB to avoid memory overflow
- Automatic schema inference and validation for data integrity
- Supports 6+ format pairs (CSV, JSON, YAML, Parquet, Avro, Protobuf) with bidirectional conversion
- CI/CD-friendly with exit codes for schema validation failures
- Batch directory conversion with recursive processing

## Why It Matters for RAG Builders
DataMorph eliminates manual scripting for large-scale data format conversions, reducing errors and improving efficiency in AI/ML pipelines and data engineering workflows.
