## Summary
A shared memory and coordination server for multiple AI coding agents built on the Model Context Protocol (MCP). It provides persistent knowledge storage, multi-agent coordination, task management, and function registry with auto-enrichment, enabling seamless collaboration across sessions and agents.

## Key Features
- Persistent knowledge base with vector search via ChromaDB for cross-session recall
- Multi-agent coordination with file locking, messaging, and heartbeat monitoring to prevent conflicts
- Task and backlog management for tracking work items and agent assignments
- Function registry with auto-enrichment via librarian daemon for code analysis and semantic search
- Production-tested with 6+ agents over 500+ sessions on commercial IoT platforms

## Why It Matters for RAG Builders
It provides the critical infrastructure for multi-agent AI systems to collaborate effectively, retain context, and avoid redundant work, making it essential for scalable RAG and AI engineering stacks.
