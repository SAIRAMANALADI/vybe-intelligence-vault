## Summary
mcp-zippopotam is a Model Context Protocol (MCP) server that wraps the Zippopotam.us API, providing free, no-auth ZIP/postal code lookups for 60+ countries. It enables AI agents to resolve geographic locations by ZIP code or retrieve postal codes for a given city, state, or country.

## Key Features
- Free and no authentication required for ZIP/postal code lookups
- Supports 60+ countries with sub-second response times
- Provides city, state/province, and latitude/longitude data
- Integrates seamlessly with MCP clients (Claude Desktop, Cursor, Windsurf, etc.)
- Enables plain-English queries via ask_pipeworx for simplified agent interactions

## Why It Matters for RAG Builders
It provides a lightweight, no-cost solution for AI agents to resolve geographic locations by ZIP code, enabling geo-aware workflows without complex setup or authentication.
