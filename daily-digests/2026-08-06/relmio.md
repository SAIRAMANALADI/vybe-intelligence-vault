## Summary
Relmio is a local browser-based installer and sidecar that enables self-hosted n8n workflows to authenticate with OpenAI-compatible endpoints via a ChatGPT/Codex OAuth session, bridging n8n's API expectations with OpenAI's OAuth flow without modifying the existing n8n setup.

## Key Features
- Local browser-based installer for seamless setup without manual configuration
- Private Docker sidecar that translates n8n's OpenAI API requests to ChatGPT/Codex OAuth sessions
- Supports GPT-5.6 model aliases (e.g., gpt-5.6-sol, gpt-5.6-luna) for n8n workflows
- Zero modifications to existing n8n instances, containers, or workflows
- Cross-platform installers (macOS, Linux, WSL, Windows) with checksum-verified Node.js runtime

## Why It Matters for RAG Builders
Relmio enables self-hosted AI workflows like n8n to securely leverage ChatGPT/Codex models via OAuth without exposing OpenAI API keys, bridging the gap between local automation and proprietary AI services.
