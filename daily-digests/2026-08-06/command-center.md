## Summary
Command Center is an Obsidian plugin that transforms the note-taking app into a personal operational OS with multi-agent orchestration, hybrid RAG, and persistent memory. It enables framework-agnostic AI workflows, provider-aware model routing, and headless automation directly within Obsidian vaults.

## Key Features
- Interview-driven onboarding and configuration for personalized AI workflows
- Multi-provider model routing with 12 supported providers (local and cloud)
- Hybrid vault RAG with stationary indexes and persistent memory for efficient retrieval
- ReAct-based multi-agent engine with safeguards for safe parallel execution
- Native Obsidian workflows and Bases integration for headless automation

## Why It Matters for RAG Builders
Command Center provides a framework-agnostic, local-first AI orchestration layer directly integrated with Obsidian, enabling advanced RAG and multi-agent workflows without external dependencies.
