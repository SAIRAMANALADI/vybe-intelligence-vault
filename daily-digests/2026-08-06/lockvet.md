## Summary
Lockvet analyzes lockfile changes in dependency updates to identify vulnerabilities, breaking changes, license shifts, and suspicious package bumps across 29 lockfile formats and SBOMs. It provides detailed reports via CLI, browser, MCP server, or GitHub/GitLab/Bitbucket integrations.

## Key Features
- Detailed lockfile diff analysis with vulnerability, license, and age tracking
- Supports 29 lockfile formats and SBOMs (CycloneDX/SPDX)
- Integrates with GitHub/GitLab/Bitbucket/Azure DevOps PRs via API
- MCP server for AI assistant integration (Claude, Cursor, etc.)
- CI/CD compatible with SARIF, JSON, and markdown output formats

## Why It Matters for RAG Builders
Lockvet provides critical dependency risk analysis for RAG/AI stacks by exposing vulnerabilities, breaking changes, and suspicious bumps in lockfiles, ensuring AI systems rely on secure and stable dependencies.
