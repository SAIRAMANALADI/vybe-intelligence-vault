## Summary
Network Sketcher is an AI-native network design tool that generates L1/L2/L3 topology diagrams, device tables, and AI-ready context files from structured network data or natural-language workflows. It offers three editions: Local MCP for direct LLM integration, Online for browser-based use, and Offline for desktop GUI/CLI.

## Key Features
- AI-native Local MCP edition for direct LLM client integration (Cursor, Claude Code)
- Generates L1/L2/L3 topology diagrams, device tables, and AI context files from natural language or structured data
- Supports import from live inventory tools (ACI, Catalyst Center, Meraki, NetBox, etc.) via Cisco Extension converters
- Three editions: Local MCP (stdio-based), Online (browser-based), and Offline (GUI/CLI)
- Exports diagrams in SVG/PowerPoint formats and device tables in HTML

## Why It Matters for RAG Builders
It enables AI agents to autonomously design, document, and visualize network topologies, streamlining infrastructure planning and reducing manual effort in RAG pipelines.
