## Summary
MemForge is a self-evolving, evidence-based memory layer designed to bridge institutional context gaps for AI coding agents. It ingests and structures team knowledge from sources like Confluence, Jira, GitHub Pages, and agent sessions, enabling agents to search, verify, and reuse durable facts, decisions, and procedures with full provenance.

## Key Features
- Multi-source memory ingestion (Confluence, Jira, GitHub Pages, Teams, local files)
- Evidence-based memory storage with full provenance and source tracing
- MCP-enabled agent plugins for Codex and Claude Code integration
- React-based admin UI for memory management and review workflows
- Self-hosted or local deployment with SQLite and Chroma vector search

## Why It Matters for RAG Builders
MemForge is essential for RAG/AI stack builders as it provides a robust, evidence-backed memory layer that ensures AI agents have access to accurate, up-to-date institutional context, reducing hallucinations and improving decision-making.
