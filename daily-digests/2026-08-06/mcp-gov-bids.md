## Summary
This repository provides an MCP (Model Context Protocol) server for accessing open and historical US government bid solicitations from city and county portals, updated daily. It is part of the Pipeworx ecosystem, which connects AI agents to over 1,334 live data sources.

## Key Features
- Provides real-time access to US government bid solicitations from city and county portals
- Part of the Pipeworx MCP gateway, enabling integration with AI agents
- Supports plain English queries via the ask_pipeworx interface
- Updated daily to ensure data freshness
- MIT licensed for open-source use
