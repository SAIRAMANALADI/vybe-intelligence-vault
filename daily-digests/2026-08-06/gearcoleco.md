## Summary
Gearcoleco is a highly accurate, cross-platform ColecoVision emulator written in C++ with support for Windows, macOS, Linux, BSD, and RetroArch. It includes an embedded Model Context Protocol (MCP) server for AI-assisted debugging and tooling, enabling integration with AI agents like GitHub Copilot and Claude.

## Key Features
- Accurate Z80, TMS9918 VDP, and SN76489 PSG emulation with support for Super Game Module (SGM) and MegaCart ROMs
- Embedded MCP server for AI-assisted debugging with tools for execution control, memory inspection, and hardware status
- Cross-platform support including Windows, macOS, Linux, BSD, and RetroArch with portable mode
- Advanced debugging features like save states, rewind, breakpoints, disassembly, and VRAM viewer
- Agent Skills integration for specialized AI tasks such as game debugging and ROM hacking
