## Summary
Taprun is a browser automation tool that captures logged-in browser tasks into deterministic .plan.json programs, enabling zero-LLM-token replays for repetitive tasks like data extraction or form submissions. It integrates with AI agents (Claude, Cursor, etc.) via MCP for seamless capture and replay workflows.

## Key Features
- Capture logged-in browser tasks into deterministic .plan.json programs for zero-LLM-token replays
- Seamless integration with AI agents (Claude, Cursor, Cline, Windsurf) via MCP for on-demand task automation
- Silent failure detection and drift monitoring via `tap verify` with 4-arm verdicts (live/drifted/unreachable/broken)
- Supports Chrome extension for real browser sessions or headless Playwright runtime for CI/CD isolation
- Open protocol with TypeScript types and JSON Schema for third-party tooling and runtime interoperability

## Why It Matters for RAG Builders
Taprun eliminates recurring LLM token costs for repetitive browser tasks by capturing them once into deterministic plans, making it essential for cost-efficient RAG pipelines requiring logged-in session automation.
