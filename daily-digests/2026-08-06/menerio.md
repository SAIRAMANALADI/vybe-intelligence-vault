## Summary
Menerio is a central event hub designed to synchronize personal data across multiple apps by acting as a backbone for event-driven communication. It ensures data consistency and ownership clarity while connecting isolated tools into a unified system.

## Key Features
- Centralized event ingestion and storage for personal data
- Hub-and-spoke model for app communication via a central event bus
- Single source of truth for data ownership across connected apps
- Supabase-backed scalable data layer with authentication
- Event-based architecture for real-time synchronization
