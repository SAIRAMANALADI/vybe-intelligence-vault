## Summary
A lightweight bridge enabling browser-based UIs to interact with a local Codex instance, offering an embedded chat UI, headless client, and Node.js bridge for seamless integration without exposing credentials to the browser.

- Prebuilt, zero-compilation installation for rapid deployment
- Embeddable chat UI via iframe or Web Component with lifecycle events
