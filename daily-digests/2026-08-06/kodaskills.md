## Summary
KodaSkills is a collection of reusable agent skills (instructions) for the Koda AI assistant, enabling focused task execution through modular, YAML-defined skill sets. It supports both local and global skill installations across Koda plugins and CLI tools.

## Key Features
- Reusable agent skills with YAML frontmatter for metadata and instructions
- Supports local and global skill installations for flexibility
- Automated metadata generation via GitHub Actions on updates
- Compatible with Koda plugins (VSCode/JetBrains) and CLI tools
- Structured skill activation and management workflows

## Why It Matters for RAG Builders
