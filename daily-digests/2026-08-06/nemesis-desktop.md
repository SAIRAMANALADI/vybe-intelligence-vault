## Summary
Nemesis Desktop is a cross-platform desktop application for macOS, Windows, and Linux that serves as a local study agent, integrating assignments, notes, research, and agent-based chat into a unified workspace with independent data storage.

## Key Features
- Unified workspace for assignments, notes, and research with agent-based chat
- Cross-platform support (macOS, Windows, Linux) with independent data storage
- Built-in AI provider integration (user-managed subscriptions)
- Session-based workflow with real-time citations and sources tracking
- Automated updates and simplified school setup via natural language input
