## Summary
Konrad is an open-source, sandboxed AI coworker that runs locally on your machine, enabling secure interaction with sensitive files using your own models. It operates within a containerized environment with strict egress controls to ensure data privacy and security.

## Key Features
- Runs entirely on local hardware with containerized isolation to protect sensitive data
- Supports both local models (LM Studio, Ollama, llama.cpp) and trusted API providers
- Includes a built-in egress firewall to restrict network access to approved hosts
- Provides pre-configured skills for document processing, spreadsheets, and image editing
- Automated background updates for the container image and subscribed layers

## Why It Matters for RAG Builders
Konrad enables secure, local-first AI workflows for handling sensitive data without relying on cloud services, making it essential for privacy-conscious RAG builders.
