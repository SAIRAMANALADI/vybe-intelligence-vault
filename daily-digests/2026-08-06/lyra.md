## Summary
Lyra is a Sui-native, non-custodial AI finance agent that enables users to delegate financial actions via natural language while enforcing deterministic, on-chain policies. Funds are held in an owner-controlled vault, and every action is validated by Move smart contracts to ensure compliance with user-defined guardrails.

## Key Features
- Natural language goal delegation with AI-driven action proposals
- On-chain policy enforcement via Move smart contracts (budget, slippage, protocols, recipients)
- Non-custodial vault architecture where funds remain in owner-controlled treasury
- Multi-interface support (CLI, Web, Telegram, Gateway daemon) with unified agent identity
- Auditable on-chain receipts (Walrus) and deterministic policy re-validation for every action

## Why It Matters for RAG Builders
It provides a secure, auditable framework for AI-driven financial actions on-chain, ensuring user sovereignty and policy compliance without custodial risk.
