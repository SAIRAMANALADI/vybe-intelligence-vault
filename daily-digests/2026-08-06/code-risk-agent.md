## Summary
CodeRisk Agent is an AI-powered local code security analysis tool that performs deep vulnerability detection using LLMs running entirely on AMD GPUs. It combines static analysis, semantic understanding, and triple cross-validation to identify and explain security risks with full evidence chains, all while keeping code and data local for compliance.

## Key Features
- Local AMD GPU-accelerated LLM inference for privacy-compliant analysis
- Triple cross-validation system combining tool rules, CWE knowledge base, and local CVE database
- Self-learning memory system to improve accuracy over multiple scans
- Full evidence chains with source code snippets, CWE classifications, and fix suggestions
- Parallel agent architecture for efficient multi-layered analysis

## Why It Matters for RAG Builders
It enables privacy-compliant, deep code security analysis for enterprises by leveraging local AMD GPUs to run LLMs, eliminating the need for cloud-based code uploads while providing detailed vulnerability insights.
