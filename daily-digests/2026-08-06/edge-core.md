## Summary
Edge Core is an open-source, self-hostable control plane for managing distributed Linux and edge device fleets. It provides secure WireGuard mesh networking, SSH proxy access, remote command execution, Prometheus metrics aggregation, and MCP server integration via a single REST API.

## Key Features
- Masterless control plane with horizontal scalability via independent admin clusters
- Secure WireGuard mesh networking with DERP relay fallback for NAT traversal
- Centralized SSH proxy access without exposing port 22 on edge nodes
- Remote command execution and self-update capabilities across entire fleets
- MCP server integration for AI-driven fleet operations via standardized tools

## Why It Matters for RAG Builders
Edge Core provides a unified, self-hostable control plane for managing distributed Linux fleets, enabling secure remote operations, AI-driven automation, and seamless integration with existing monitoring and orchestration tools.
