## Summary
LibrAIum is a local-first desktop app for curating and managing GitHub repositories with an integrated MCP server, enabling AI agents like Claude Code to interact with curated libraries for project recommendations and dependency decisions.

## Key Features
- Git-native storage with Markdown/YAML entries for each repository
- Reception layer synthesizing third-party signals (issues, adoption, limitations) for informed decisions
- Desktop GUI with fuzzy search, category management, and Git operations
- MCP server exposing tools for repository search, comparison, and project suggestions
- Private-by-design architecture with OS keychain integration and no telemetry

## Why It Matters for RAG Builders
LibrAIum enables AI engineers to curate and dynamically query trusted repositories, ensuring RAG stacks are built with vetted, up-to-date components while integrating seamlessly with AI workflows via MCP.
