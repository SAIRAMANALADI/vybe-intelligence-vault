## Summary
A privacy-first, fully local AI coding agent with a React web UI, interactive CLI, and Node.js REST server, all powered by Ollama. Enables autonomous code editing, file system operations, web research, and terminal command execution without cloud dependencies.

## Key Features
- Fully local, no cloud dependencies or API keys required
- React web UI with live streaming chat, drag-and-drop file attachments, and tool approval workflows
- Interactive CLI with REPL mode, slash commands, and auto-approve functionality
- Advanced AST/LSP-powered developer tools for code navigation, diagnostics, and editing
- Configurable tool complexity profiles to match model capabilities (simple/medium/advanced)

## Why It Matters for RAG Builders
It provides a privacy-preserving, fully local alternative for building autonomous coding agents with robust tooling and UI integration, critical for developers needing offline or secure AI workflows.
