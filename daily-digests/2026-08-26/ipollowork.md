## Summary
iPolloWork is a local-first, open-source desktop application for building and running AI agent workflows on personal files, serving as an alternative to proprietary AI coworking tools like Claude Cowork. It supports 50+ LLMs, extensible agents via skills/plugins, and team collaboration through shareable setups.

## Key Features
- Supports 50+ LLMs with custom provider keys for flexibility
- Extensible via skills, plugins, and MCP servers for custom workflows
- Local-first architecture with optional remote sharing for team collaboration
- Real-time streaming and execution plan visualization for agentic workflows
- Cross-platform desktop app (macOS, Windows, Linux) with CLI and server modes

## Why It Matters for RAG Builders
iPolloWork provides a flexible, local-first framework for building and deploying AI agent workflows, reducing vendor lock-in while enabling team collaboration and extensibility for RAG builders.
