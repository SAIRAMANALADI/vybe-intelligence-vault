## Summary
Nedster Ironclad is a local-first, hardware-aware coding agent framework that uses an asymmetric swarm of specialized models (router, coder, reasoner, critic) for secure, verifiable task execution with a live mission-control TUI and capability-gated tooling.

## Key Features
- Asymmetric swarm architecture with specialized models for planning, execution, and critique
- Hardware-aware model scheduling and residency management for VRAM/CPU optimization
- Verifiable state via HMAC hash-chained SQLite WAL event ledger
- Capability-gated tool execution with runtime-owned authority and policy boundaries
- Live mission-control TUI for real-time task monitoring and system telemetry

## Why It Matters for RAG Builders
Nedster provides a secure, hardware-optimized framework for building multi-agent AI systems with verifiable state and capability-gated tooling, essential for reliable local-first RAG deployments.
