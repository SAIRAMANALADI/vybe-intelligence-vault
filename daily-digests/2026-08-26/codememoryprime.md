## Summary
CodeMemoryPrime (CMP) is a lightweight, Rust-based tool designed to provide long-term memory and context retention for AI coding assistants by locally indexing codebases and project documentation. It enables AI tools to instantly recall project structures, functions, and architectural decisions without redundant re-reading of files.

## Key Features
- Instant re-indexing of code changes (sub-0.2s updates)
- Preserves contextual relationships (functions, classes, imports) for AI understanding
- Single compiled binary with no external dependencies
- Persistent memory storage across sessions
- Offline-capable with local model integration (Ollama, LM Studio)

## Why It Matters for RAG Builders
It eliminates the need for AI assistants to repeatedly re-explain project context, drastically reducing token costs and improving coding efficiency for RAG-based AI stacks.
