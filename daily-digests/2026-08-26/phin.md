## Summary
Phin is a native macOS desktop app that provides a unified interface for working with multiple databases (PostgreSQL, MySQL, SQLite, MongoDB) while integrating AI-powered chat for querying and analysis. It offers schema-aware AI assistance, read-only query execution by default, and secure local storage of database credentials.

## Key Features
- Unified interface for PostgreSQL, MySQL, SQLite, and MongoDB with consistent UX
- AI chat that understands your database schema and drafts queries with explicit approval for writes
- Local credential storage via macOS Keychain with no plaintext exposure
- Integration with Claude Code for AI-driven data exploration and read-only queries
- Safety-first design with auto-approval for reads and mandatory approval for writes
