## Summary
Codex Delegate MCP is an MCP (Model Context Protocol) bridge that enables AI coding agents like Claude Code, Cursor, or Copilot to delegate implementation tasks to the OpenAI Codex CLI. It streamlines workflows by offloading boilerplate code generation to Codex while keeping high-level task planning and review with the primary agent.

## Key Features
- Delegates implementation tasks to OpenAI Codex CLI while keeping task planning and review with the primary AI agent
- Supports multiple MCP clients (Claude Code, Cursor, Copilot, VS Code, JetBrains, etc.)
- Provides clean, structured JSON results with file changes, token usage, and status updates
- Offers four modes: agent edits, plan approval, read-only Q&A, and review of uncommitted work
- Includes self-diagnosing tools like 'doctor' for setup validation and parallel/cancellable task execution

## Why It Matters for RAG Builders
It enables AI agents to focus on high-level task planning and review while offloading boilerplate implementation to a specialized model, improving efficiency and reducing costs for RAG/AI stack builders.
