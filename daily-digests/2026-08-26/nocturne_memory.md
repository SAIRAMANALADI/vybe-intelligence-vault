## Summary
Nocturne Memory is a long-term memory server for MCP-compatible AI agents, enabling persistent, structured, and sovereign memory across sessions, models, and tools. It replaces vector RAG with a URI-based graph memory system, allowing AI to autonomously manage its own identity, knowledge, and evolution.

## Key Features
- URI-based memory graph with hierarchical and associative links, avoiding semantic shredding of vector RAG
- AI-driven CRUD operations for memory with version control and human audit via Dashboard
- Conditional disclosure routing for precise memory recall based on context
- Namespace isolation for managing multiple AI personas with independent memory spaces
- Real-time visual memory explorer and editor with diff-based review and rollback

## Why It Matters for RAG Builders
Nocturne Memory enables AI agents to develop persistent, sovereign identities and knowledge bases, transcending the limitations of vector RAG and session-bound memory systems for true long-term autonomy.
