## Summary
Seeker is a local-first personal AI agent platform that combines a shell with toggleable mini-apps for privacy-focused task execution. It ensures sensitive data remains on-device, API keys are stored securely, and AI processing is strictly controlled via a robust security model.

## Key Features
- Local-first architecture with SQLite/IndexedDB for data storage and system keychain for secure API key management
- Agent-native interface with slash commands, quick chips, and project workspaces for structured task execution
- Modular mini-apps (e.g., job-seeking, note-taking) that can be toggled on/off without losing data
- Multi-protocol AI model support (OpenAI, Anthropic, Gemini, Ollama) with user-controlled model selection
- Strict security model enforcing data isolation, user confirmation for destructive actions, and untrusted content handling

## Why It Matters for RAG Builders
Seeker provides a privacy-preserving, modular framework for building and deploying AI agents with strict data control, making it ideal for RAG systems requiring secure, local-first processing.
