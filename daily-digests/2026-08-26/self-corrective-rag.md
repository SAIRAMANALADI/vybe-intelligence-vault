## Summary
Self-Corrective-RAG is a query optimization and relevance evaluation system for RAG pipelines that dynamically rewrites queries and adapts search strategies using LangGraph and Google Gemini. It enhances retrieval accuracy through cyclical graph-based refinement and self-correction mechanisms.

## Key Features
- Dynamic query rewriting for improved retrieval accuracy
- Cyclical graph architecture for adaptive search strategies
- Integration with Google Gemini for relevance evaluation
- User-friendly interface for non-technical users
- Open-source and customizable

## Why It Matters for RAG Builders
It provides a self-corrective mechanism to optimize RAG pipelines by dynamically refining queries and evaluating document relevance, significantly improving retrieval performance.
