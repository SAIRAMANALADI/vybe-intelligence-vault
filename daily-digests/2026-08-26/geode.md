## Summary
Geode is an Obsidian plugin that enables secure, encrypted remote sync of your vault across devices while providing an MCP server and API for agent access. It aims to replicate the seamless experience of Apple Notes for Obsidian users.

## Key Features
- End-to-end encrypted remote sync for Obsidian vaults across devices
- Built-in MCP server for agent access to the vault
- REST API for programmatic interactions with the vault
- Multi-platform support including iOS
- Security-first design with automated vulnerability scanning

## Why It Matters for RAG Builders
Geode enables AI agents to securely interact with and maintain Obsidian vaults as memory systems, unlocking advanced note-taking and knowledge management workflows.
