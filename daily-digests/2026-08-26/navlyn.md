## Summary
Navlyn is a C#/.NET tool designed to guide AI coding agents by providing semantic code navigation and investigation capabilities. It helps agents focus on relevant code targets, dependencies, and changes, reducing context drift and improving edit accuracy.

## Key Features
- Semantic symbol targeting for C# and Visual Basic codebases
- MCP server integration for AI coding agents (GitHub Copilot, Codex, Claude Code)
- CLI tools for shell, CI, and verification workflows
- Workspace auto-discovery and configuration for multi-project repos
- Post-edit diff verification to ensure changes stay on target
