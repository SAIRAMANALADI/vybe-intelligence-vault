## Summary
Agency Orchestrator is a zero-code framework that enables multi-AI role collaboration to automatically generate complete solutions from a single prompt. It orchestrates 216+ specialized AI agents (roles) to work in parallel, producing deliverables like business plans, code reviews, or market analyses without manual configuration.

## Key Features
- Zero-code YAML-based workflows with automatic DAG generation for parallel task execution
- 216+ pre-built AI roles (agents) covering domains like engineering, finance, marketing, and design
- Supports 11 LLM providers (7 without API keys) including DeepSeek, Claude, and Gemini CLI
- Web Studio and desktop app for visual workflow design, execution, and monitoring
- AI-powered prompt optimization, team (loadout) management, and resume/retry for failed steps

## Why It Matters for RAG Builders
It enables RAG builders to automate multi-agent collaboration for complex tasks, reducing manual orchestration overhead and improving output quality through parallelized expert roles.
