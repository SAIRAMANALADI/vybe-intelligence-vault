## Summary
Aegis Omnisearch Agent is a lightweight, high-performance RAG AI agent built from scratch without bloated frameworks. It uses local ONNX models for embeddings, a custom ReAct loop for autonomous tool usage, and Google's Gemini API for generation, prioritizing privacy and efficiency.

## Key Features
- Custom-built ReAct loop for autonomous reasoning and tool usage
- Local ONNX embeddings for cost-efficient, CPU-based vector generation
- Zero-downtime MLOps with GitHub Webhook integration for hot-swappable model updates
- Stateless BYOK architecture ensuring user privacy and flexibility
- Grounded citations and sliding window chunking for accurate, context-aware responses

## Why It Matters for RAG Builders
Aegis provides a lean, privacy-focused alternative to bloated RAG frameworks, ideal for developers seeking high-performance, customizable agent architectures with minimal overhead.
