## Summary
ministr is a local, MIT-licensed MCP server that provides AI coding agents with AST-level codebase understanding, enabling semantic search, symbol navigation, reference graphs, and cross-language bridge detection across 40+ languages. It operates entirely locally with no cloud dependencies.

## Key Features
- AST-level codebase understanding for precise semantic search
- Symbol navigation and real reference graph generation
- Cross-language bridge detection across 40+ languages
- Local-first operation with no cloud dependencies
- Compatibility with MCP clients like Claude Code, Cursor, and Copilot

## Why It Matters for RAG Builders
It enables AI coding agents to deeply understand and navigate codebases locally, improving accuracy and reducing reliance on external tools for code intelligence.
