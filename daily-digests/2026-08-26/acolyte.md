## Summary
Acolyte is a terminal-first AI coding agent designed for transparent, observable, and developer-controlled execution. It features a single-pass lifecycle, on-demand memory, and overridable behaviors, enabling full visibility into agent decisions and actions.

## Key Features
- Single-pass lifecycle for deterministic agent behavior
- On-demand memory retrieval for context-aware execution
- Transparent execution with visible decision-making processes
- Overridable behaviors for customizable agent actions
- Terminal-first UI with visual regression testing
