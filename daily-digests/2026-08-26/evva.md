## Summary
EVVAgent (evva) is a terminal-based ReAct coding agent that supports multiple LLM providers, parallel tool dispatch, and async sub-agents. It features a modular architecture with swappable UI components and a TUI or CLI interface for interactive and automated agent workflows.

## Key Features
- Multi-provider LLM support with a unified client interface
- Parallel tool dispatch and async sub-agent execution
- Swappable UI with Bubble Tea TUI and plain-text CLI
- Modular architecture for easy extension (new providers, tools, or UIs)
- Built-in multi-agent swarm system with web workstation

## Why It Matters for RAG Builders
EVVAgent provides a flexible, terminal-based framework for building and deploying ReAct agents with multi-provider LLM support, making it essential for developers integrating agentic workflows into their AI stacks.
