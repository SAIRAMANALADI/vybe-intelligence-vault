## Summary
IncidentOps Core is a backend system designed for engineering evidence collection and incident investigation, ingesting code, logs, and operational data to provide cited search results and diagnostics for runtime incidents. It serves as a deterministic collector and retriever of project-scoped evidence with missing-data warnings.

## Key Features
- Deterministic evidence ingestion with normalized document batches
- Hybrid retrieval combining vector, lexical, and metadata search
- Cited answers with missing-evidence diagnostics
- Project-scoped RBAC and authentication
- MCP server for tool integration and automation

## Why It Matters for RAG Builders
IncidentOps Core provides a structured, evidence-backed approach to incident investigation, enabling RAG systems to ground answers in verifiable data and reduce hallucinations by exposing missing evidence.
