## Summary
A full-stack health and care monitoring system for a dog named Benny, integrating FastMCP backend, React/Vite/Tailwind frontend, and MCP tools for care events, loneliness detection, and robot patrol integration.

## Key Features
- FastMCP-based MCP server with care event tools (water refill, bark detection, sausage delivery, etc.)
- Loneliness detection via 5-minute patrol job and movement tracking
- React/Vite/Tailwind frontend with dashboard, chat, and onboarding wizard
- Boomy-robot patrol integration with actor-based event logging
- SQLite-backed care diary with REST API and Swagger documentation
