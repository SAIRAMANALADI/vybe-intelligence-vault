## Summary
Provides a Model Context Protocol (MCP) server that exposes BigCommerce's full developer platform (REST, GraphQL, webhooks, OAuth) as structured tools for AI assistants like Cursor, Claude, and Windsurf. Enables precise, API-backed answers about BigCommerce's ecosystem without hallucinations.

## Key Features
- 12 MCP tools for searching, retrieving, and generating BigCommerce API code and documentation
- Covers 171 REST endpoints, 42 webhook scopes, 21 OAuth scopes, and 30 GraphQL operations
- Live documentation fetcher for real-time updates from developer.bigcommerce.com
- Pre-built code examples in Node.js, Python, PHP, and cURL for common operations
- Integrates seamlessly with Cursor, Claude, Windsurf, and other MCP-compatible AI tools

## Why It Matters for RAG Builders
