## Summary
BeatOS is a local-first desktop and web application designed for beat producers to catalog, analyze, tag, and export audio files with built-in AI assistance. It combines a SQLite-backed library with AI-driven metadata tagging, loopkit packaging, and assisted publishing to platforms like BeatStars and NetEase.

## Key Features
- Local-first SQLite catalog for beats with multi-format audio support (WAV/MP3/FLAC)
- Built-in AI Agent for natural language catalog queries and automated tagging (BPM, key, genre, mood)
- MCP server integration for external AI clients (Claude, ChatGPT, Codex) to interact with the library
- Assisted publishing to platforms like BeatStars and NetEase with browser automation (Pro feature)
- Loopkit and beat pack export with customizable metadata and packaging options

## Why It Matters for RAG Builders
BeatOS streamlines the workflow for beat producers by automating tedious metadata tagging and publishing tasks, reducing manual labor while integrating AI for scalable catalog management and export automation.
