## Summary
WebPi is an interactive CLI terminal for the Pi AI assistant, delivered as a full-screen Streamlit application. It bridges browser-based xterm.js terminals to a real Linux PTY via WebSocket, enabling real-time interaction with Pi in an isolated workspace environment.

## Key Features
- Full-screen terminal interface for Pi AI assistant via Streamlit
- Real-time WebSocket communication between browser and Linux PTY
- Isolated temporary workspaces for each session with secure permissions
- Pre-configured with Node 22 runtime and Pi 0.80.6 for immediate use
- Uses google/gemini-2.5-flash via exa-direct provider without requiring an API key

## Why It Matters for RAG Builders
WebPi provides a unique way to interact with AI assistants like Pi in a terminal environment, which is valuable for developers and users who prefer CLI-based workflows over traditional chat interfaces.
