## Summary
Stella is a memory-augmented QQ group chatbot designed for private deployments, focusing on converting group chat interactions into persistent, retrievable memories. It leverages local small language models (SLMs) for memory processing, summarization, and RAG-enhanced retrieval using SQLite FTS5.

## Key Features
- Local SLM integration for memory processing and summarization
- SQLite FTS5-based RAG for enhanced memory retrieval
- Pipeline-based architecture with pre/post hooks for extensibility
- Automated memory compression and deduplication
- Proactive conversation participation based on group activity

## Why It Matters for RAG Builders
Stella provides a robust framework for building memory-augmented AI agents that can retain and retrieve contextual information from chat interactions, critical for RAG systems requiring long-term memory integration.
