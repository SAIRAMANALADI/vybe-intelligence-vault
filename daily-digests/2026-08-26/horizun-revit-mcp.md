## Summary
Horizun Revit MCP is an open-source Model Context Protocol (MCP) server that bridges AI clients like Codex and Claude to Autodesk Revit for typed BIM queries, verified model edits, family authoring, and interoperability workflows. It enables secure, reliable automation and data exchange between Revit and AI-driven tools.

## Key Features
- Typed BIM queries and verified model edits with post-commit validation
- Family authoring with parameter, formula, and nested element support
- Interoperability with IFC, DWG, PDF, FBX, and Power BI exports
- Idempotent operations with bounded request queues and error handling
- Open-source under Apache 2.0 with reproducible benchmarks and CI testing

## Why It Matters for RAG Builders
It provides a secure, reliable bridge between AI clients and Revit, enabling automated BIM workflows, model edits, and data extraction for RAG and AI-driven construction applications.
