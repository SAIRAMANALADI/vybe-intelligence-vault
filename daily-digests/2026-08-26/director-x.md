## Summary
Director X is an open-source Codex plugin and AI video production harness that transforms creative briefs into end-to-end video productions. It coordinates research, scripting, asset generation, editing, review, and delivery while maintaining persistent production state, approvals, and provenance tracking.

## Key Features
- Native Codex Goals integration for persistent production tracking and approvals
- Dedicated specialist agents (e.g., DX-Director, DX-Asset-Manager) for modular video production tasks
- Live production canvas for real-time asset visualization, relationships, and review evidence
- Provider-neutral routing for images, video, speech, music, and editing tools
- Evidence-driven generation repair with single-variable adjustments and budget controls
