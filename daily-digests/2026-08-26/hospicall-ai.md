## Summary
HospiCall-AI is a self-hosted, zero-cost AI voice receptionist designed for hospitals, enabling callers to book doctor appointments via local speech-to-text, intent recognition, and text-to-speech processing. All components run locally on a laptop without cloud dependencies.

## Key Features
- Fully local deployment with no cloud APIs or monthly fees
- Fast-path intent recognition for common requests (<100ms latency)
- Integration with Whisper for speech-to-text and OmniVoice for text-to-speech
- SQLite-backed appointment booking engine with synthetic demo data
- Modular architecture with FastAPI backend and Ollama for LLM inference

## Why It Matters for RAG Builders
It provides a privacy-preserving, cost-effective solution for automating hospital voice reception tasks using local AI models, reducing reliance on cloud services.
