## Summary
A hardened, privacy-focused Fedora 44-based workstation designed for AI-agent workflows, featuring 41 functional modules for security, privacy, and system hardening. It includes opt-in AI tools, local inference support, and a documented threat model for resistance against common local-network and ISP observation.

## Key Features
- 41 functional modules for security, privacy, and system hardening (SELinux, firewalld, USBGuard, AIDE, etc.)
- Built-in AI-agent workspace with opt-in tools (Claude Code, Codex CLI, Ollama, LM Studio) and 52 AI-navigable docs
- LAN isolation with inbound DROP rules, nftables, and XDP/TC boundary for network security
- Hardened VSCodium with privacy-default settings and no vendor agent code
- Btrfs + Snapper root snapshot rollback and LUKS2 disk encryption support

## Why It Matters for RAG Builders
It provides a secure, privacy-focused foundation for AI engineers to build and deploy RAG systems without compromising on security or exposing sensitive data to external agents.
