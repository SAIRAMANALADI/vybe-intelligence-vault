## Summary
Cain is an AI-powered penetration testing engineer designed for real-world authorized security assessments, focusing on business logic flaws, cloud misconfigurations, and adaptive attack strategies in enterprise environments. It operates within strict legal and ethical boundaries while providing auditable evidence and reproducible proof-of-concepts.

## Key Features
- Real-world authorized security assessment capabilities with business logic focus
- Built-in cloud penetration module covering AWS, Azure, GCP, and major Chinese cloud providers
- Deterministic state machine with hard engineering constraints for safety and reproducibility
- Dual-LLM split (Planner/Executor) for strategic and tactical operations
- Workspace external memory for crash-resumable, auditable state management
