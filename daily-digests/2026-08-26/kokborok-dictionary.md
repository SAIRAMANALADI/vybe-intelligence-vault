## Summary
A Kokborok-English dictionary and translator application that combines static dataset lookups with AI-powered analysis using Google Gemini API for contextual meaning and examples.

## Key Features
- Static dictionary lookup with JSON datasets for Kokborok and English words
- AI-powered analysis via Google Gemini API for contextual meanings and examples
- Voice input support using Web Speech API
- Custom Python pipeline for extracting structured data from PDF dictionaries
- React-based frontend with TypeScript and Tailwind CSS for responsive UI
