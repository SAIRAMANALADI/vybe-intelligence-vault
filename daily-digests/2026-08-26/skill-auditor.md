## Summary
skill-auditor is a CLI tool that audits agent skills (e.g., SKILL.md files) against the actual state of a project to detect drift, measure alignment, and suggest improvements. It helps maintain accurate and up-to-date skills for AI agents by scoring technical and neutral skills based on project dependencies and patterns.

## Key Features
- Scores alignment between skills and project dependencies (e.g., package.json, imports)
- Detects coverage gaps and suggests fixes for agent skills
- Supports multiple checklists (frontend, website specification domains)
- Provides machine-readable JSON output for integration with CI/CD pipelines
- Includes static compliance checks for website specifications (opt-in)

## Why It Matters for RAG Builders
It ensures AI agents maintain accurate and up-to-date skills by continuously auditing and optimizing them against the project's real dependencies and patterns.
