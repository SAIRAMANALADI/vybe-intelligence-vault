## Summary
An MCP (Model Context Protocol) server that provides programmatic access to Anime News Network's encyclopedia and news feeds. It enables searching anime/manga titles, retrieving detailed entries, and fetching recent news without requiring an API key or account.

## Key Features
- Search anime/manga titles with compact results and retrieve full entries by ID
- Fetch cast, staff, episodes, releases, related content, news, and reviews for any title
- Access recent news, reviews, and combined feeds with configurable limits
- Built-in rate limiting, caching, and error handling for reliable API interactions
- No API key or account required; adheres to Anime News Network's usage guidelines

## Why It Matters for RAG Builders
Provides structured, no-auth access to a comprehensive anime/manga encyclopedia and news feeds, making it a valuable data source for RAG systems focused on anime content.
