## Summary
A zero-dependency Python tool for analyzing Facebook Marketplace listings, providing scam detection, price comparison, vehicle deep analysis, and image extraction. It functions as a CLI, Python library, MCP server, and Claude skill, enabling integration with AI tools like Claude, Cursor, and VS Code.

## Key Features
- Zero-dependency Python 3.8+ tool with no API keys or login required
- 7-factor scam score (0-100) with red-flag detection for payment scams, pressure tactics, and fake profiles
- Market price comparison with outlier-resistant median-based methodology and vehicle normalization
- Vehicle deep analysis (year, km, PS/kW, TÜV, fuel, transmission, color) and image extraction
- MCP server and Claude skill integration for AI tool compatibility (Claude, Cursor, VS Code, etc.)
