## Summary
ProxmoxMCP-Plus is a security-conscious control plane that bridges AI agents, MCP clients, and OpenAPI tooling to Proxmox VE for managing VMs, LXCs, snapshots, backups, ISOs, and persistent jobs through dual access paths (MCP and HTTP).

## Key Features
- Dual access paths: Native MCP for AI agents and OpenAPI for HTTP automation
- Comprehensive Proxmox operations: VM/LXC lifecycle, snapshots, backups, ISOs, and storage management
- Persistent job tracking with async task polling, retry, cancel, and audit history
- Security-first design: Proxmox API tokens, TLS validation, command guardrails, and MCP host/origin controls
- Multi-architecture Docker support (AMD64 and ARM64) with supply-chain hardening

## Why It Matters for RAG Builders
It provides a unified, secure interface for AI agents and automation tools to interact with Proxmox VE, eliminating the need for custom scripts and API stitching in RAG and AI workflows.
