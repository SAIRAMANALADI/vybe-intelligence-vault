## Summary
Physiquinator is a cross-platform workout tracking app built with .NET MAUI and Blazor Hybrid, featuring AI-powered training analysis, smart rest timers, and local SQLite storage. It includes a web client with an MCP server for AI agent integration.

## Key Features
- Cross-platform workout tracking with .NET MAUI and Blazor Hybrid
- On-device AI assistant for training analysis with OpenAI or Ollama integration
- Smart rest timer with Android floating overlay and exact alarms
- Local SQLite storage for offline-first data persistence
- MCP server for AI agent integration (Claude, Cursor, Copilot)

## Why It Matters for RAG Builders
Physiquinator provides a robust, cross-platform foundation for integrating AI-driven workout analysis and MCP-compatible agent interactions, making it essential for RAG builders targeting fitness or personal health applications.
