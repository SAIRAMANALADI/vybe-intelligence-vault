## Summary
ultrasearch is a keyless, multi-backend web search tool that retrieves, deduplicates, and synthesizes web content into citation-checked research reports. It supports five modes (topic, bug, research, learn, startup) and an optional agentic deep-research tier for exhaustive, verified investigations.

## Key Features
- Keyless web search across multiple backends (e.g., Wikipedia, Stack Overflow, arXiv) with fallback cascades
- Deterministic retrieval with deduplication, caching, and Wayback Machine rescue for dead links
- Tiered report generation (TL;DR SUMMARY and detailed REPORT) with embedded citations and model hints
- Self-contained HTML and Markdown outputs for portability and readability
- Deep-research tier with decomposition, adversarial verification, and contradiction detection

## Why It Matters for RAG Builders
It provides a robust, citation-checked foundation for RAG systems by ensuring retrieved web content is grounded, deduplicated, and verifiable, eliminating hallucinations from stale training data.
