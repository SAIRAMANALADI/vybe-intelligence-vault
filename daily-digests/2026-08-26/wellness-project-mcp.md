## Summary
A hosted Model Context Protocol (MCP) server that synchronizes health and fitness data from Apple Health, Fitbit, Oura, and Google Health Connect into a single account, enabling AI assistants like Claude and ChatGPT to read and interact with workouts, sleep, nutrition, and recovery metrics in plain English without manual exports or self-hosting.

## Key Features
- 60+ tools for reading and writing health/fitness data (workouts, sleep, nutrition, recovery, etc.)
- Hosted MCP server with OAuth and API key authentication for seamless integration with Claude and ChatGPT
- Inline interactive chart widgets for visualizing trends (e.g., Fit Score, sleep, running mileage)
- Supports Apple Health, Fitbit, Oura, and Google Health Connect with no self-hosting required
- Row-level security ensuring data privacy and user-specific access control

## Why It Matters for RAG Builders
It eliminates the need for AI engineers to build and maintain custom MCP servers for health data integration, providing a ready-to-use solution for connecting wearables and fitness data to AI assistants.
