## Summary
Iris is a self-hosted, self-extending AI operator that dynamically writes and deploys its own skills, provisions infrastructure, and manages sub-agents in Docker or Firecracker microVMs. It operates via Slack, Telegram, or a built-in web UI, enabling autonomous task execution without cloud dependencies.

## Key Features
- Dynamic skill generation and hot-reloading without redeployment
- Sub-agent fleet management with Docker or Firecracker isolation
- Multi-transport support (Slack, Telegram, web UI) with pluggable architecture
- Defense-in-depth sandboxing via Firecracker microVMs with KVM and seccomp
- Provider-agnostic LLM integration with configurable retry and compaction

## Why It Matters for RAG Builders
Iris enables RAG builders to deploy autonomous, self-healing AI agents that dynamically extend their capabilities and orchestrate specialized sub-agents, reducing operational overhead and enhancing scalability.
