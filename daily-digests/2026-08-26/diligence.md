## Summary
Self-hosted fitness rewards platform with AI agent integration via an MCP connector. Users earn points through workouts and food logging, spend them on rewards, and leverage science-based onboarding (PAR-Q+, BREQ-2) for personalized engagement.

## Key Features
- 14-tool MCP connector for AI agent integration (e.g., Claude) to log workouts, track food, and manage meal plans
- Science-based onboarding with PAR-Q+, Transtheoretical Model, and BREQ-2 motivation profiling
- Points-based behavioral economy with configurable rewards and daily/weekly targets
- Dual deployment options: lightweight pip install for personal use or Docker Compose for multi-user setups
- Zero cloud dependencies; all data stored locally with encrypted integrations (Strava, Polar, etc.)

## Why It Matters for RAG Builders
It provides a unique self-hosted platform for AI-driven fitness coaching with a robust MCP connector, enabling agents to interact with user data for personalized health and wellness management.
