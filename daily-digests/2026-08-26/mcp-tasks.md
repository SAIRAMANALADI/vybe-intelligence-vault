## Summary
mcp-tasks is an MCP (Model Context Protocol) server designed to manage tasks efficiently for AI workflows. It supports multi-format task files (Markdown, JSON, YAML) and provides tools for task creation, search, update, and organization with minimal LLM API calls.

## Key Features
- Minimal tool count (5 tools) to reduce AI confusion and API calls
- Supports Markdown, JSON, and YAML task files with auto-detection
- Powerful search, filtering, and organization with customizable workflow states
- Type-safe with TypeScript and Zod validation
- Safe operations (AI can only add/move tasks, not delete or rewrite)

## Why It Matters for RAG Builders
It streamlines task management for AI workflows by providing a structured, multi-format system that minimizes LLM API calls and reduces tool confusion.
