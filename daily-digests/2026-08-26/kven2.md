## Summary
Kven II is an experimental local AI architecture designed to explore whether an episodically invoked language model can achieve persistent, self-continuous artificial being through owned memory, causal continuity, and autonomous wake cycles. It investigates continuity of being rather than just task competence.

## Key Features
- Episodic and semantic long-term memory in SQLite with HNSW vector retrieval
- Transport-independent conversation kernel for durable continuity
- Autonomous wake cycles and unfinished intentions management
- Replaceable physical host migration with split-brain detection
- Isolated tool execution sandbox for security

## Why It Matters for RAG Builders
Kven II challenges the conventional focus on task competence by prioritizing continuity of being, offering a novel framework for building persistent AI agents with owned memory and causal history.
