## Summary
ELING is a self-improving terminal AI agent written in Go, featuring persistent memory, dynamic tool execution, multi-provider LLM support, and a 3-panel Bubbletea TUI. It includes an 8-layer memory architecture, MCP protocol integration, and autonomous skill learning.

## Key Features
- 8-layer memory architecture with RRF fusion for unified search across all layers
- Dynamic tool execution with sandboxed bash, file operations, and web tools
- Auto-learning and forgetting mechanism for persistent skill acquisition
- Full MCP protocol client for external tool integration
- 3-panel Bubbletea TUI with real-time streaming, syntax highlighting, and session management
