## Summary
A local-first AI-powered games collection featuring 50+ browser games with real AI opponents, 107 OpenSpiel games, and Japanese language learning tools. All games run locally with no cloud dependency, and the system includes an MCP server for agent accessibility.

## Key Features
- 50+ browser games with real AI opponents (Stockfish, KataGo, etc.)
- MCP server for agent-accessible game analysis and automation
- Local-first architecture with no cloud dependency
- Japanese language learning tools (kanji, JLPT drills)
- P2P multiplayer support via WebSocket and Firebase
