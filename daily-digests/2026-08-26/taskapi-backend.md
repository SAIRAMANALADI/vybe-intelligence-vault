## Summary
A FastAPI-based backend for a task/project manager powered by a LangGraph-orchestrated ReAct AI agent. It integrates 17 tools, ChromaDB for RAG, and LangSmith for tracing, enabling real-time task management and AI-driven responses grounded in live database retrieval.

## Key Features
- LangGraph-orchestrated ReAct agent with tool-calling capabilities
- Real-time streaming responses via `astream_events`
- RAG integration with ChromaDB for grounded responses
- End-to-end tracing with LangSmith for observability
- Async SQLAlchemy 2.0 with PostgreSQL for scalable data handling

## Why It Matters for RAG Builders
This repository provides a production-ready example of a LangGraph-based ReAct agent integrated with RAG and tracing, essential for building advanced AI-driven task management systems.
