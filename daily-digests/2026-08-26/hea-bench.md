## Summary
hea-bench provides open, interpretable tools for calculating thermodynamic and geometric descriptors for high-entropy alloys (HEAs) and oxides (HEOs), including classic empirical phase-prediction rules. It offers Python, browser, desktop, and MCP server interfaces with transparent, closed-form calculations validated against primary literature.

## Key Features
- Computes 10+ standard HEA/HEO descriptors (e.g., ΔS_mix, δ, Ω, VEC) from any composition using transparent closed-form expressions.
- Supports four interfaces: Python library, zero-install browser app, native desktop app, and MCP server for AI agents.
- Includes empirical phase-prediction rules (e.g., Yang–Zhang Ω, King Φ) with auditable citations and units.
- Provides high-entropy oxide (HEO) descriptors with automatic oxidation-state assignment and formability verdicts.
- Offers parity-tested JavaScript core for browser/desktop apps, ensuring consistency with Python calculations.

## Why It Matters for RAG Builders
It enables RAG/AI stack builders to ground material science calculations in transparent, auditable descriptors and rules, reducing hallucinations in alloy and oxide phase predictions.
