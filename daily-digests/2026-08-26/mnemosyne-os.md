## Summary
Mnemosyne OS is a cognitive memory operating system designed for AI agents to manage long-term memory across sessions, projects, and time. It distills raw conversations into structured knowledge layers, supports hybrid 5D search, and integrates natively with agent frameworks like Hermes via MCP tools and memory hooks.

## Key Features
- Five-dimensional hybrid search (semantic, BM25, temporal, trust, heat) with ~200ms latency
- Multi-layer memory distillation pipeline (L1 fragments → L5 user profile) with LLM-driven summarization
- Knowledge lifecycle management (Research → Engineering → Archive Halls) with temporal validity and conflict detection
- Entity knowledge graph (Apache AGE) for relational context and multi-hop queries
- Agent-native integration via Hermes MCP tools (15) and Memory Provider hooks (10) for zero-config memory management

## Why It Matters for RAG Builders
Mnemosyne OS provides a foundational memory system for AI agents, enabling true long-term context retention, structured knowledge distillation, and relational reasoning beyond traditional vector databases or RAG pipelines.
