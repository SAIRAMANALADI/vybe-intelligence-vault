## Summary
An agentic AI recruiter assistant that automates multi-round candidate screening by parsing job descriptions, searching resumes, and executing hybrid semantic-keyword ranking with interactive constraint refinement. Built with LangGraph, ChromaDB, and MCP for modular orchestration and real-time recruiter dashboard interaction.

## Key Features
- Multi-round screening pipeline with coarse filtering, deep analysis, and final recommendations
- Hybrid semantic-keyword search over ChromaDB with BM25 Okapi for resume ranking
- Model Context Protocol (MCP) dual-mode gateway for modular tool integration and orchestration
- Interactive Streamlit dashboard for real-time constraint refinement and candidate comparison
- Rate limit safeguards and token management for free-tier API usage optimization

## Why It Matters for RAG Builders
It provides a modular, agentic framework for automating and refining candidate screening in RAG pipelines, reducing manual effort while improving precision through hybrid search and interactive feedback loops.
