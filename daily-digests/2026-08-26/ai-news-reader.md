## Summary
An automated daily tech news digest pipeline that filters, deduplicates, and scores AI/tech news from Gmail newsletters, then delivers a prioritized digest via Gmail draft and Telegram. The entire system is configured as a Claude Code Routine with no application code or server maintenance required.

## Key Features
- Automated newsletter triage from multiple sources (LinkedIn, TLDR, Substack)
- Deduplication and merging of duplicate news coverage across sources
- Scoring system (1–5 🔥) based on source count, impact, and actionability
- Delivery via Gmail draft and Telegram message for human review before sending
- 30-day history tracking in Google Drive to avoid redundant stories

## Why It Matters for RAG Builders
It demonstrates a fully automated, no-code pipeline for filtering and prioritizing AI/tech news, reducing manual triage workload and showcasing MCP connectors for seamless cloud service integration.
