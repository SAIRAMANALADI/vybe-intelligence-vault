## Summary
A personal AI job-search assistant built as a Claude Skills package on a single GitHub repository. It provides guided onboarding, persistent profile management, multi-source job sourcing, fit evaluation, tailored CV generation, and application tracking—all version-controlled and inspectable.

## Key Features
- Guided onboarding from CV to first search intent with automated profile creation
- Multi-source job sourcing with LinkedIn/Indeed alerts integration
- Automated job-role fit evaluation and tailored CV/cover letter generation
- Repo-first application tracking with Gmail integration for follow-ups
- Batch routine for deduplication, filtering, and digest generation

## Why It Matters for RAG Builders
It provides a structured, agent-driven framework for automating and personalizing job search workflows, reducing manual effort while maintaining full data control and auditability.
