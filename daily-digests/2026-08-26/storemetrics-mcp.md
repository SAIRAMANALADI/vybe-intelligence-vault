## Summary
StoreMetrics MCP Server enables AI agents to register e-commerce websites, install tracking, and query real-time analytics like visitors, revenue, funnels, and live activity without requiring human account setup or OAuth. It provides a remote, streamable HTTP-based MCP server for seamless integration.

## Key Features
- Zero-signup agent registration for websites via a single API call
- Read-only, site-scoped MCP tokens for secure analytics access
- Comprehensive real-time metrics including visitors, revenue, funnels, and live activity
- Support for streaming and event-based data retrieval
- Automated garbage collection for unclaimed sites after 7 days

## Why It Matters for RAG Builders
It simplifies the integration of real-time e-commerce analytics into AI agents without requiring human setup or credentials, enabling seamless end-to-end automation.
