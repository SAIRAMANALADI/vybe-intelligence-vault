## Summary
Lorapok AI Agent is an autonomous terminal-first AI coding agent that integrates multi-provider LLMs (Google Gemini, OpenRouter, Perplexity AI) with live terminal execution, Git orchestration, and REST API capabilities for terminal engineering and full-stack development tasks.

## Key Features
- Multi-provider LLM integration (Google Gemini, OpenRouter, Perplexity AI) with live model probing and sanitization
- Autonomous terminal execution with interactive REPL, file operations, and Git management (commits, branches, stashing)
- Token-saving response caching and real-time token capacity tracking for efficient LLM usage
- Docker-first isolated environment with host volume mounting for safe execution
- REST API server with encrypted secrets vault (AES-256-GCM) for secure API key storage

## Why It Matters for RAG Builders
