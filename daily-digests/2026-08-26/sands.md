## Summary
Sands is a natural-language calendar management tool that reads, creates, modifies, and deletes events across personal and work calendars while resolving time references to ISO 8601 ranges. It supports recurring events, privacy scoping, and travel time computation via the Google Places Distance Matrix API.

## Key Features
- Natural-language date/time parsing and resolution to ISO 8601 ranges
- Multi-calendar read/write with privacy scoping (work events appear as busy blocks with titles suppressed)
- Travel time computation via Google Places Distance Matrix API
- Undo support for all actions within 24 hours
- Recurring event handling with scope control
