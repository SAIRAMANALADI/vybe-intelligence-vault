## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Pi-hole v6 DNS ad-blockers via a standardized API. It provides full control over Pi-hole instances, including query logs, allow/deny lists, group management, and stats, with multi-instance support.

## Key Features
- Multi-instance Pi-hole management with full API coverage
- Auto-detection of exact vs. regex domain lists for allow/deny operations
- Docker-ready deployment with security hardening and health checks
- Streamable HTTP transport for MCP client compatibility
- Advanced features like regex landmine detection and blocking control

## Why It Matters for RAG Builders
It bridges AI assistants with Pi-hole DNS management, enabling automated and AI-driven network administration for homelabs and enterprise environments.
