## Summary
StrataNote is a modern collaborative Markdown knowledge base and note-taking web application that combines Obsidian-like features (bidirectional wiki-links, graph view, folders) with real-time multi-user editing, version control, and administration tools.

## Key Features
- Real-time multi-user editing with conflict resolution
- Bidirectional wiki-links and interactive graph view
- Version control with full revision history and trash bin recovery
- Local sync agent for offline editing with automatic background synchronization
- Admin moderation, comments, and access control features

## Why It Matters for RAG Builders
StrataNote provides a robust, collaborative environment for managing and versioning Markdown-based knowledge bases, which is critical for RAG pipelines requiring structured, up-to-date, and multi-user-maintained documentation.
