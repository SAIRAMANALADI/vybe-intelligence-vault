## Summary
MengDie Code is a local-first, Chinese-first coding agent designed for domestic developers, focusing on verifiable memory, evidence-driven retrospectives, and compatibility with Chinese models and macOS/Windows environments. It emphasizes trustworthy memory, auditability, and controlled execution while still in early development.

## Key Features
- Verifiable and traceable memory system with sources, scope, and validity periods
- Evidence-driven retrospective mechanism for auditable decision-making
- Controlled execution with approval workflows for file edits and shell commands
- Multi-platform support prioritizing macOS and Windows with Go single-binary distribution
- Structured Doctor for local environment diagnostics and provider configuration

## Why It Matters for RAG Builders
