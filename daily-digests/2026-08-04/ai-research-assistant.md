## Summary
An autonomous research assistant agent that uses LangChain and Anthropic's Claude to autonomously search the web or Wikipedia, compile findings into structured reports, and save results locally. It leverages tool-calling agents for decision-making and multi-source retrieval.

## Key Features
- Autonomous tool-calling agent with decision-making for web or Wikipedia search
- Multi-source retrieval integrating DuckDuckGo and Wikipedia APIs
- Structured output validation using Pydantic schemas
- Automatic persistence of research results to local files
- Built on LangChain's agent framework for modularity and extensibility
