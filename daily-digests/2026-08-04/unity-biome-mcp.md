## Summary
Unity Biome MCP enables AI clients and in-editor chat to control the Unity Editor via the Model Context Protocol (MCP). It allows inspecting scenes, editing GameObjects, running playtests, and capturing results through structured tools, bridging AI workflows with Unity development.

## Key Features
- 145+ registered MCP tools for scene inspection, editing, and diagnostics
- PlayTest DSL for automated playtesting and verification workflows
- In-Unity Chat with AI skill integration for contextual development
- Batch operations for efficient multi-step Unity commands
- Extensible plugin system for custom tools and AI agents
