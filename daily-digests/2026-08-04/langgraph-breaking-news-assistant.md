## Summary
A conversational news assistant that fetches live global headlines in real-time using LangGraph and Groq, summarizes them, and maintains conversation context for natural follow-ups via a Streamlit UI.

## Key Features
- Real-time news fetching via Currents API to avoid stale LLM knowledge
- Tool-calling agent loop with LangGraph's StateGraph for dynamic decision-making
- Conversation memory using LangGraph's MemorySaver for contextual follow-ups
- Clean, sourced summaries with links to original articles
- Custom Streamlit UI with an in-app guide and dark purple-themed interface
