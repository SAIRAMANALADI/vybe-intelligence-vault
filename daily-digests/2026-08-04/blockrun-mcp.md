## Summary
BlockRun MCP is an MCP-compatible server that enables AI agents (like Claude) to interact with real-time data sources, execute trades, and perform research tasks, all pay-per-call via USDC micropayments. It integrates live market data, web search, crypto trading, and media generation tools into a single self-custody wallet system.

## Key Features
- Real-time market data integration (Polymarket, Kalshi, Binance, etc.) with live trading capabilities via self-custody wallets
- Pay-per-call USDC micropayments for all tools (no subscriptions or API keys required)
- Multi-modal toolset including image/video generation, speech synthesis, music creation, and web search
- Support for Base and Solana networks with seamless wallet switching and funding
- Modular tool profiles (e.g., 'trading', 'media', 'research') for optimized agent interactions

## Why It Matters for RAG Builders
BlockRun MCP enables AI agents to execute real-time data retrieval, research, and transactions with minimal friction, bridging the gap between AI capabilities and real-world actions through a unified, pay-per-call system.
