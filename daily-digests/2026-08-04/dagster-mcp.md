## Summary
An MCP server that provides AI agents with full visibility and control over Dagster instances, enabling autonomous monitoring, diagnosis, and remediation of data pipelines through 20+ tools across runs, assets, jobs, schedules, and instance health.

## Key Features
- 20+ tools for autonomous DataOps workflows covering runs, assets, jobs, schedules, and instance health
- Read-only and write operations with configurable permissions via environment variables
- Multi-environment support for managing multiple Dagster instances
- Consolidated failure diagnosis and asset health checks for rapid issue resolution
- Compatibility with any MCP client (Claude Code, Cursor, etc.)

## Why It Matters for RAG Builders
It enables AI agents to autonomously monitor, diagnose, and fix data pipelines in real-time, reducing downtime and operational overhead for RAG and AI stack builders.
