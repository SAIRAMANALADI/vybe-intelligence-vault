## Summary
AgentPlaybooks provides a vendor-neutral platform for managing AI agent skills, personas, MCP servers, and memory in portable playbooks, enabling cross-platform agent consistency and self-hosting without vendor lock-in.

## Key Features
- Portable playbook format for AI agent skills, personas, and memory
- CLI and Claude Code plugin for local auditing and synchronization
- Role-Based Access Control (RBAC) for API keys and collaborators
- Versioned canvas documents for long-running agent workflows
- Encrypted secrets management with proxy endpoints for secure API calls

## Why It Matters for RAG Builders
AgentPlaybooks enables AI engineers to maintain portable, vendor-agnostic agent configurations, reducing lock-in and simplifying cross-platform deployment and collaboration.
