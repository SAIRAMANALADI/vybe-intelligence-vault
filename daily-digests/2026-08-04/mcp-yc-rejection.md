## Summary
mcp-yc-rejection is a Model Context Protocol (MCP) server that provides Y Combinator (YC) rejection responses for startup ideas, wrapped around StupidAPIs. It integrates with Pipeworx's gateway to offer AI agents access to this data source.

## Key Features
- Provides instant YC rejection responses for any startup idea via MCP
- Integrates with Pipeworx gateway for broader data source access
- Supports plain English queries via ask_pipeworx for ease of use
- Lightweight and easy to deploy as an MCP server
- Part of a larger ecosystem of 1394+ data sources

## Why It Matters for RAG Builders
It enables AI agents to generate realistic YC rejection responses for startup ideas, useful for training, testing, or simulating feedback loops in RAG applications.
