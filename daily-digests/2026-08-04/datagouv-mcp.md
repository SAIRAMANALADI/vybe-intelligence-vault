## Summary
A Model Context Protocol (MCP) server that enables AI chatbots to interact with data.gouv.fr, the French national open data platform. It allows users to search, explore, and analyze datasets through natural language queries without manual browsing.

## Key Features
- Enables natural language queries for French open datasets via AI chatbots
- Supports multiple MCP clients (Claude, ChatGPT, Mistral, etc.)
- Hosted public endpoint for immediate use without self-hosting
- Docker-based deployment for easy setup and scalability
- Read-only tools with no authentication required

## Why It Matters for RAG Builders
It bridges AI chatbots with French open data, enabling seamless dataset exploration and analysis for RAG systems without manual data retrieval.
