## Summary
Smooth is a CLI and orchestration platform for coordinating teams of AI agents (operatives) to work on real projects with adversarial tool surveillance. It provides a single binary for agent orchestration, model routing, and infrastructure management without requiring Docker, Node.js, or runtime dependencies.

## Key Features
- Single 10MB binary with no runtime dependencies
- Agent orchestration with adversarial tool surveillance (Narc)
- Semantic routing slots for model selection and provider abstraction
- Built-in pearl tracker (Dolt-backed) for durable state management
- Interactive TUI and web UI for real-time agent monitoring

## Why It Matters for RAG Builders
Smooth streamlines the deployment and management of AI agent teams, reducing operational overhead and enabling scalable, secure orchestration for RAG and AI applications.
