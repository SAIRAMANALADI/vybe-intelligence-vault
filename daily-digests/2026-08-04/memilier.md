## Summary
Hemilier is a desktop AI agent application that enables conversational interactions, tool calls, file/command operations, and web searches. It supports both local models via Ollama and cloud-based models (DeepSeek, MiniMax, OpenAI-compatible) and is built with Electron, React, and TypeScript.

## Key Features
- Streaming conversations with Markdown, code highlighting, and math rendering (KaTeX)
- 15+ built-in tools for file editing, command execution, web search, and memory management
- Strict permission gateway for file/command/network operations with safety confirmations
- Sandboxed workspace restricting all operations to a selected directory
- Plugin marketplace for one-click installation of skills (Word, Excel, PDF, etc.)
