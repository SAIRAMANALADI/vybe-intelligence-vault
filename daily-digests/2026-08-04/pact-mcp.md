## Summary
pact-mcp provides Model Context Protocol (MCP) servers for safe, auditable access to Pact 5 smart-contract development on Kadena Chainweb. It enables AI agents to interact with REPL tests, scan for critical language traps, estimate gas, and query or submit transactions without handling private keys.

## Key Features
- Provides MCP-compatible servers for Pact 5 and Chainweb, enabling AI agents to interact with smart-contract development tools
- Offers read-only access to testnet and mainnet with strict security baselines (no private key exposure, audit logging, prompt-injection stripping)
- Includes tools for REPL test execution, critical-trap scanning, gas estimation, interface diffing, and module deployment simulation
- Supports local devnet, testnet, and mainnet environments with configurable profiles and network allowlists
- Integrates seamlessly with VS Code, Claude, Cursor, and other MCP-compatible clients via npm packages

## Why It Matters for RAG Builders
It enables AI agents to safely and audibly interact with Kadena's Pact smart-contract ecosystem, bridging the gap between AI development and blockchain operations.
