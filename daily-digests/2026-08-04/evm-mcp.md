## Summary
An MCP (Model Context Protocol) server providing comprehensive access to Ethereum Virtual Machine (EVM) JSON-RPC methods for AI workflows. Enables querying any EVM-compatible network (Ethereum, Polygon, Arbitrum, etc.) through popular node providers like Infura, Alchemy, or custom RPC endpoints.

## Key Features
- Supports 20+ EVM JSON-RPC methods for querying blockchain data, transactions, and contracts
- Enables transaction simulation (read-only) with plain English revert reasons and gas estimation
- Works with any EVM-compatible network (Ethereum, Polygon, Arbitrum, etc.) and node provider (Infura, Alchemy, QuickNode, local nodes)
- Supports address aliases, ENS names, and custom network/provider configurations
- One-click installation in Cursor and manual setup for Claude Desktop and other MCP-compatible environments

## Why It Matters for RAG Builders
It provides essential EVM blockchain access and simulation capabilities for AI agents and workflows, enabling secure and flexible interactions with decentralized networks without requiring direct wallet management.
