## Summary
OwnPlanner is an AI-powered personal planning assistant that integrates task management, note-taking, and intelligent conversation via Google Gemini. It supports multiple interfaces including a React-based web app, a console CLI, and MCP tools for automation.

## Key Features
- Layered .NET 10 architecture with clear separation of concerns (Domain, Application, Infrastructure, Presentation)
- Multi-interface support: React web app, console CLI, and MCP tools for automation
- Integration with Google Gemini for intelligent conversation and task planning
- Per-user SQLite databases for secure and isolated data storage
- GDPR compliance features including data export and account deletion

## Why It Matters for RAG Builders
OwnPlanner provides a robust, multi-interface framework for building AI-powered planning assistants with MCP tool integration, making it valuable for developers creating conversational AI applications.
