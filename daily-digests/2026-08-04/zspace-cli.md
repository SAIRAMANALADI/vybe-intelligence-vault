## Summary
zspace-cli provides a CLI, Python SDK, and MCP Server to manage files on ZSpace (极空间) NAS devices without SSH or direct network access. It reverse-engineers the ZSpace desktop client's internal API to enable file operations, automation, and AI agent integration.

## Key Features
- Zero-config CLI for ZSpace NAS file operations (ls, mv, cp, rm, etc.)
- Python SDK for automation and scripting with typed interfaces
- MCP Server integration for AI agents (Claude, Cursor) to manage NAS files
- Reverse-engineered API proxy via ZSpace desktop client (no SSH or port forwarding required)
- Media Manager skill for organizing movies and TV series on NAS

## Why It Matters for RAG Builders
It enables seamless file management and automation for ZSpace NAS users, particularly useful for AI agents needing direct NAS integration without complex networking setups.
