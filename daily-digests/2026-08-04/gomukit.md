## Summary
gomukit provides prebuilt, interactive HTML widgets for MCP Apps in Go, enabling CRUD-style UIs like tables, forms, and card carousels to be embedded directly in a single Go binary. These widgets render in compliant MCP hosts (e.g., Claude, ChatGPT) without external dependencies, adhering to the MCP Apps extension specification.

## Key Features
- Self-contained HTML widgets embedded in Go binary with zero external files
- Compliance with MCP Apps extension specification (io.modelcontextprotocol/ui)
- Host-aware theming and locale support (dark mode, numbers/dates formatting)
- Prebuilt widgets: Table, Form, Card, CardList, Menu, Confirm, DatePicker
- Sandboxed preview server for testing without local setup

## Why It Matters for RAG Builders
It enables MCP server developers to ship interactive, host-rendered UIs directly from Go without frontend expertise, reducing complexity for RAG/AI stack builders.
