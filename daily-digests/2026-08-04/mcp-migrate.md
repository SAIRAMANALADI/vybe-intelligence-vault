## Summary
mcp-migrate is a tool designed to automatically detect and fix breaking changes introduced by the MCP 2026-07-28 specification revision in server implementations. It identifies protocol-level incompatibilities, deprecated features, and missing updates, providing both diagnostic checks and automated code fixes.

## Key Features
- Automated detection of MCP 2026-07-28 breaking changes in server code
- Interactive and machine-readable output with severity grading (breaking/deprecated/advisory)
- Dry-run and safe-only modes for controlled fixes
- 21 rules covering protocol, transport, and capability changes
- 5 automated fixers with conservative, review-flagged transformations

## Why It Matters for RAG Builders
It ensures MCP server implementations remain compatible with the latest protocol revisions, reducing manual migration effort and preventing runtime failures in AI applications.
