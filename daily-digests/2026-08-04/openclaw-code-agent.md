## Summary
OpenClaw Code Agent is a stateful plugin for OpenClaw that enables managed coding sessions with Claude Code, Codex, and experimental OpenCode. It provides plan approval, session lifecycle management, worktree isolation, and follow-through for merges/PRs directly from chat interfaces like Telegram or Discord.

## Key Features
- Plan-first execution with approval workflows (direct, delegated, or user-approved)
- State-driven decision UX with interactive buttons for merge/PR/later/discard actions
- Worktree isolation for sandboxed development with lifecycle states (active, merged, released, dismissed)
- Multi-harness support (Claude Code, Codex, OpenCode) with shared control plane and routing
- Full session persistence, suspension, resumption, and recovery across restarts

## Why It Matters for RAG Builders
It streamlines AI-driven coding workflows by providing a robust, orchestrated interface for managing agent sessions, approvals, and follow-through, reducing manual intervention and improving observability in RAG/AI stacks.
