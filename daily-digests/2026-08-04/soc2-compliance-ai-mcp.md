## Summary
An MCP server that automates SOC 2 Type II compliance assessments, generating control matrices, identifying gaps, and producing audit-ready documentation against all five Trust Service Criteria (Security, Availability, Processing Integrity, Confidentiality, Privacy).

- Automated SOC 2 Trust Service Criteria assessments across all five principles
- Control gap analysis and prioritized remediation planning
- Generation of audit-ready control matrices and evidence checklists
- EU AI Act compliance integration for risk management and transparency
- Production-ready MCP server with PyPI and Smithery distribution
