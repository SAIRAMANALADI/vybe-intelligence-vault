## Summary
A community-curated directory and hosted registry for Model Context Protocol (MCP) servers, providing structured profiles, searchable metadata, and install-config previews via a free public API. It enables agents and developers to discover, verify, and integrate MCP servers efficiently.

## Key Features
- Hosted, searchable registry of 7,747+ MCP servers with structured metadata
- Free public API for searching, filtering, and fetching server profiles
- Automated catalog normalization and install-config generation for clients like Claude Desktop, Cursor, and VS Code
- Community-driven cleanup and verification workflows for maintaining data quality
- Public profile pages and badges for MCP server maintainers

## Why It Matters for RAG Builders
It provides a centralized, agent-ready registry of MCP servers with structured metadata and install-config previews, making it easier for RAG builders to discover, verify, and integrate MCP servers into their workflows.
