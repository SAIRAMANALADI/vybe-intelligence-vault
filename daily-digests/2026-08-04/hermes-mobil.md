## Summary
A native Android client (Kotlin + Jetpack Compose) for a self-hosted personal AI agent, enabling streaming chat, live voice interactions, camera-based image understanding, and on-device phone control without relying on WebView.

## Key Features
- Native chat with streaming replies, markdown rendering, and tool-call cards over WebSocket
- Live voice interaction via Gemini Live API with bidirectional audio and barge-in
- Full-screen camera integration for real-time image understanding
- On-device phone control via intent-based tools (e.g., open apps, flashlight, directions)
- Session continuity with persistence and fallback to recent sessions

## Why It Matters for RAG Builders
It provides a first-class native mobile interface for self-hosted AI agents, enabling seamless integration with device capabilities and real-time interactions beyond standard web-based clients.
