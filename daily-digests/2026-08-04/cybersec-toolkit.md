## Summary
A cybersecurity toolkit with embedded AI integration via an MCP server, enabling AI agents to discover, recommend, and execute 580+ security tools across 18 modules and 14 profiles. It bridges traditional tool installation with an AI-driven control plane for interactive and autonomous security operations.

## Key Features
- Modular installer for 580+ security tools across Linux and Termux with 18 modules and 14 profiles
- Embedded MCP server enabling AI agents to interactively discover, recommend, and execute tools under governed policies
- Governed execution path with security policies (allowlists, argument sanitization, network restrictions, and rate limiting)
- Dual-mode operation: companion (user-guided) or autonomous (explicitly authorized) tool execution
- Cross-client compatibility with major AI clients (Claude, OpenCode, Codex, Gemini CLI, etc.) via standardized MCP configurations

## Why It Matters for RAG Builders
It uniquely combines a comprehensive security toolkit with an AI control plane, enabling AI agents to dynamically select and execute tools while enforcing security policies, bridging the gap between static toolsets and intelligent automation.
