## Summary
paper-distill-mcp is a Windows-based desktop application that simplifies academic paper discovery, organization, and distribution across platforms using the Model Context Protocol (MCP). It enables users to search, save, and push research papers to email, cloud storage, or reading apps without requiring technical expertise.

## Key Features
- Search academic papers using simple keywords with local or API-based indexing
- Save and organize papers in a personal library with folder support
- Push papers to email, cloud storage (Dropbox, Google Drive), or reading apps (Pocket)
- Automatic updates and background synchronization for seamless use
- User-friendly interface designed for non-technical users
