## Summary
SpringClaw is a self-hosted, governed AI agent runtime built on Spring Boot 3.5 and Spring AI 1.1, designed for multi-model orchestration, memory management, tool governance, and skill execution. It provides a production-grade agent pipeline with observability, channel adapters, and a Vue 3 operations console for real-world deployment and learning.

## Key Features
- Multi-model runtime with provider switching, failover, and usage accounting
- Governed tool execution with AOP-based permission, risk, and audit controls
- MySQL-backed event stream and Redis vector store for memory and semantic recall
- Skill runtime supporting Python, builtin, and prompt-based skills with controlled execution
- Vue 3 admin console for operations, observability, and pipeline inspection

## Why It Matters for RAG Builders
SpringClaw provides a production-ready, observable agent runtime with governance and memory features, making it essential for building reliable, auditable AI systems.
