## Summary
Flint is a visualization intermediate language that enables AI agents to generate polished, expressive charts from simple, human-editable specifications. It compiles compact chart specs into backend-native formats like Vega-Lite, ECharts, or Chart.js, optimizing layout, scales, and aesthetics automatically.

## Key Features
- Semantic chart specifications with 70+ predefined semantic types (e.g., Rank, Temperature, Price)
- Automatic layout optimization for sizing, spacing, labels, and legends based on data and chart type
- Multi-backend support compiling to Vega-Lite, ECharts, and Chart.js from a single input
- Agent-ready MCP server for interactive chart creation, validation, and rendering in chat environments
- Dynamic chart widgets enabling real-time type switching and property editing without rebuilding specs

## Why It Matters for RAG Builders
Flint streamlines AI agent-driven chart generation by abstracting verbose configuration into semantic specs, ensuring reliable, high-quality visualizations with minimal effort.
