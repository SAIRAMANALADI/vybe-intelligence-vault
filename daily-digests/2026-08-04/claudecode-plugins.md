## Summary
A persistent memory plugin for Claude Code that stores and retrieves project insights as a knowledge graph, enabling cross-session context retention with typed relationships and automatic distillation of relevant information.

## Key Features
- Persistent cross-session memory using a knowledge graph structure
- Automatic distillation of project insights, decisions, and codebase architecture
- Typed relationships and node-centric organization for efficient context retrieval
- Local-first deployment with no external databases or API keys
- Preloaded memory at session start for immediate context availability

## Why It Matters for RAG Builders
It enables AI agents like Claude Code to retain and retrieve project-specific context across sessions without manual re-explanation, improving RAG efficiency and developer productivity.
