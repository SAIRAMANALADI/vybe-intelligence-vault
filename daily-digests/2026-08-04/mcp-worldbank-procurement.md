## Summary
A Model Context Protocol (MCP) server providing keyless access to World Bank procurement notices, including tenders, awards, and country-specific data. It enables AI agents to query global development projects and contracts programmatically.

## Key Features
- Keyless access to 412k+ World Bank procurement notices with full-text search and filters
- Tools for searching tenders, awards, and country-specific notices
- Integration with MCP clients (Claude Desktop, Cursor, Windsurf)
- Plain English query support via ask_pipeworx
- Public notice URLs and detailed procurement records

## Why It Matters for RAG Builders
Provides critical, structured access to global development procurement data for RAG systems needing real-time tender and contract information.
