## Summary
An AI-driven GitHub workflow template that automates issue triaging, proposal generation, implementation, testing, and PR creation. It leverages opencode.ai for AI-powered automation, enabling end-to-end issue resolution with minimal human intervention.

## Key Features
- Fully automated issue classification and triaging using AI
- AI-generated technical proposals and development documentation
- Automated implementation, testing, and PR creation via `/approve` command
- Self-healing code via AI-driven rework on test failures (up to 10 attempts)
- Seamless integration with GitHub Actions and opencode.ai

## Why It Matters for RAG Builders
It streamlines AI-powered issue resolution by automating the entire workflow from triage to PR, reducing manual effort and accelerating development cycles for RAG and AI stack builders.
