## Summary
xcircl-agent provides a compliance-aware API and SDK for querying verified U.S. regulated-care provider data, specifically GLP-1/weight-management clinics. It offers a free tier with identity fields and paid tiers unlocking compliance signals, cash prices, and timestamps via an MCP server or TypeScript SDK.

## Key Features
- MCP server integration for AI agents (Claude/ChatGPT)
- TypeScript SDK for custom integrations
- Free tier with identity fields and paid tiers for compliance signals and pricing
- Source-linked and timestamped data from official registries (NPPES, FDA, state boards)
- Zero-setup API with live coverage tracking
