## Summary
Sigma Code is an open-source coding agent designed to handle long-running tasks with state persistence, interruption recovery, and evidence-backed completion. It executes commands in a native sandbox, persists sessions for recovery, and ensures changes are validated before finalization.

## Key Features
- Native sandbox execution with OS-level isolation for security and reliability
- Durable sessions that persist across interruptions and process restarts
- Evidence-backed completion requiring validation and review before finalizing changes
- Multi-surface support (desktop, TUI, CLI, automation) via a unified runtime
- Transparent evaluation and preregistered benchmarks for performance tracking

## Why It Matters for RAG Builders
Sigma Code provides a robust framework for building resilient, interruption-resistant AI coding agents with built-in validation and recovery mechanisms, essential for production-grade RAG systems.
