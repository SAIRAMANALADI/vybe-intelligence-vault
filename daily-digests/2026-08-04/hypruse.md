## Summary
hypruse is an MCP server that enables AI agents to interact with a Hyprland Wayland desktop environment natively, providing tools for window management, screenshots, and input control without requiring root, portals, or X11 dependencies.

## Key Features
- Semantic desktop state retrieval (monitors, workspaces, windows) via `hyprctl` IPC
- Native screenshots with coordinate-mapping metadata for pixel-perfect interactions
- Direct input control (mouse clicks, keyboard typing) over Wayland protocols
- Workspace and window management via Hyprland's IPC without root or portals
- Security-conscious design with activity beacons and panic keybinds for user safety

## Why It Matters for RAG Builders
It provides AI agents with native, secure, and efficient control over a Wayland desktop, bridging the gap for Linux-based AI workflows where such capabilities are otherwise limited or non-existent.
