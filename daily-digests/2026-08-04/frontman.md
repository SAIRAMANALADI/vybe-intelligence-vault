## Summary
Frontman is an open-source AI coding agent that enables real-time, in-browser editing of frontend applications. It allows non-technical users to make precise UI changes by clicking elements and describing edits in plain English, which are then applied to the actual source files with hot reload.

## Key Features
- Real-time DOM and component tree inspection for precise editing
- Supports multiple frameworks (Next.js, Astro, Vite, React, Vue, Svelte)
- BYOK (Bring Your Own Key) for LLM integration with major providers
- Hot reload integration for instant feedback on changes
- Open-source with Apache 2.0 and AGPL-3.0 licensing

## Why It Matters for RAG Builders
Frontman bridges the gap between non-technical stakeholders and frontend development by enabling real-time, context-aware UI edits directly in the browser, reducing friction in design and product workflows.
