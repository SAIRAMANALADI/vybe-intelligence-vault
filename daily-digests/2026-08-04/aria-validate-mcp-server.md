## Summary
An MCP (Model Context Protocol) server for validating ARIA (Accessible Rich Internet Applications) attributes and roles using the aria-query library. It enables AI models to query and validate ARIA compliance rules dynamically.

## Key Features
- Validates ARIA attribute and role compliance using the aria-query library
- Integrates seamlessly with MCP clients like Claude Desktop
- Supports dynamic querying of ARIA rules and attributes
- Provides real-time validation for accessibility standards
- Lightweight and optimized for AI-driven workflows

## Why It Matters for RAG Builders
It enables AI models to validate ARIA compliance dynamically, ensuring generated UI components meet accessibility standards.
