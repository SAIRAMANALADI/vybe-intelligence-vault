## Summary
An AI Codex Skill designed to extract defensible resume highlights and interview-ready project evidence from AI applications, Agent frameworks, and LLM engineering projects. It analyzes code, documentation, tests, and execution traces to generate structured bullet points, STAR stories, and technical explanations tailored for internship candidates.

## Key Features
- Extracts project highlights from code, tests, and execution traces with evidence validation
- Differentiates team capabilities from individual contributions to avoid misrepresentation
- Generates structured resume bullets, STAR stories, and technical explanations in Chinese
- Supports evidence grading for AI Harness, Agent Runtime, model evaluation, and tool calls
- Provides templates and validation scripts for standardized output formats
