## Summary
docker-telethon-plus wraps the Telethon MTProto client library behind a JSON HTTP API and Model Context Protocol (MCP) endpoint, enabling AI agents and HTTP clients to interact with Telegram accounts programmatically. It provides full account access via a single session string, eliminating the need for repeated login codes.

## Key Features
- Wraps Telethon behind a JSON HTTP API for programmatic Telegram access
- Provides a Model Context Protocol (MCP) endpoint for AI agents
- Supports full account access with a single session string
- Includes built-in rate-limiting and anti-flood measures to prevent Telegram bans
- Offers bulk operations and caching for efficient Telegram interactions
