## Summary
Kyrei is a cross-platform local AI coding agent with a built-in TypeScript/Node engine, multi-provider orchestration, and desktop-first UX. It enables secure, customizable AI workflows with project memory, skills, and team collaboration features.

## Key Features
- Local TypeScript/Node engine with streaming responses and verifiable tools
- Unlimited OpenAI-, Anthropic-, and Google-compatible provider support with account pooling and load balancing
- Team mode and pipeline commands for research, implementation, review, and testing
- Project memory, skills, cron tasks, and built-in search/reading tools
- Secure Kiro Organization pool for isolated API keys, model policies, and account verification

## Why It Matters for RAG Builders
Kyrei provides a flexible, local-first framework for building and orchestrating AI agents with multi-provider support, making it essential for developers who need customizable, secure, and team-ready AI workflows.
