## Summary
RediSearch is a Redis module that provides advanced full-text search, secondary indexing, and vector similarity search capabilities for Redis. It enables fast querying, filtering, and aggregations on Redis data with low memory overhead.

## Key Features
- Full-text indexing with stemming, phonetic matching, and fuzzy search
- Vector similarity search (KNN, filtered KNN, range queries)
- Support for geospatial, numeric, and boolean queries
- Aggregations engine for complex data analysis
- Incremental indexing with low performance overhead
