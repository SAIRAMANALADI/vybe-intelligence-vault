## Summary
Grimoire is a read-only MCP server that provides live access to Unreal Engine 5 (UE5) project assets, including Blueprints, variables, functions, materials, and structs. It bridges UE5's Python API with MCP clients like Claude for real-time project introspection and reasoning.

## Key Features
- Live read access to UE5 Blueprints, variables, functions, and materials via MCP
- Bounded query tools for efficient graph traversal and flow analysis
- SQLite cache for persistent project state across sessions
- Integration with MCP clients like Claude for AI-driven project reasoning
- Opt-in depth tools for function bodies and live flow analysis

## Why It Matters for RAG Builders
Grimoire enables AI agents to directly inspect and reason about live UE5 project assets, bridging the gap between game development and AI-driven automation or documentation workflows.
