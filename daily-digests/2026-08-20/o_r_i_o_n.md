## Summary
O.R.I.O.N. is a local-first AI desktop agent and mission-control system designed for safe autonomy, approval-gated tool execution, persistent memory, and mission planning. It includes Aurora OS, a visual command center for managing AI workflows, security controls, and release governance.

## Key Features
- Approval-gated tool execution and desktop workflows with safety controls
- Mission planning, workflow blueprints, and execution history with governance
- Persistent memory engine and vector-based knowledge retrieval
- Aurora OS dashboard with real-time analytics, security profiles, and plugin registry
- Local-first architecture with Tauri desktop app shell and one-click launch
