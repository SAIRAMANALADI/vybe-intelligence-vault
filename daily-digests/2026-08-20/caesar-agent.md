## Summary
Caesar is an autonomous AI research agent that performs deep web exploration using a dynamic knowledge graph and synthesizes creative, grounded answers through an adversarial Generator-Verifier loop. It outperforms state-of-the-art deep research agents in creativity benchmarks while being fully open-source.

## Key Features
- Stateful Perceive-Think-Act exploration loop with dynamic policy routing
- Adversarial Generator-Verifier loop for multi-draft synthesis and self-correction
- Dynamic knowledge graph for context-aware reasoning and episodic memory
- Pluggable LLM backend supporting OpenAI, Anthropic, Google, and local models
- Reproducible experiment JSON with full provenance tracking and artifact merging

## Why It Matters for RAG Builders
Caesar provides a fully open-source, graph-based alternative to proprietary deep research agents, enabling RAG builders to implement stateful, adversarial, and creative agentic workflows beyond simple retrieval.
