## Summary
A unified MCP server implementing all twelve Kinetic Gain Protocol Suite specifications, DefenseTech tooling, and AI Claims Decision Card v0.1. Exposes 75 callable tools for agents to validate, inspect, and chain governance artifacts across multiple domains like AEO, AI Evidence, Agent Cards, and clinical/incident reporting.

## Key Features
- 75 callable tools covering 12 Kinetic Gain Protocol Suite specs and DefenseTech tooling
- Supports validation, inspection, and chaining of governance artifacts (e.g., AEO, AI Evidence, Agent Cards)
- Includes ed25519 attestation, audit-stream event composition, and live chain verification
- CLI mode for CI/CD and pre-commit validation of Suite JSON documents
- Cross-spec workflows enabled via unified server (e.g., fetch Tool Card URI and inspect in one conversation)

## Why It Matters for RAG Builders
It provides a single, standardized interface for agents to validate, inspect, and chain governance artifacts across multiple AI governance protocols, reducing integration complexity for RAG builders.
