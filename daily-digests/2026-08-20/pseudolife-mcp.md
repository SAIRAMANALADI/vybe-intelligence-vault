## Summary
PseudoLife-MCP is an MCP server that provides persistent long-term memory for Claude Code, enabling LLMs to retain context across sessions. It combines associative memory, canonical fact storage, a knowledge graph, procedural lessons, and document RAG into a unified system with sleep-like consolidation and a web-based Cortex Console.

## Key Features
- 8-tier recency-tiered associative memory store with novelty gating and contradiction detection
- Canonical fact cortex with temporal supersession and contender parking for deterministic reads
- Knowledge graph with transitive/inverse inference and closed relation vocabulary
- Sleep-like dream consolidation with configurable extractors (local CPU or Claude Sonnet)
- Cortex Console web UI for monitoring, querying, and managing memory systems

## Why It Matters for RAG Builders
It enables LLMs like Claude to retain and reason over long-term context across sessions, eliminating the need for repetitive context re-explanation and improving continuity in AI-driven workflows.
