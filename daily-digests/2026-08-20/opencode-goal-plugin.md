## Summary
A session-scoped plugin for OpenCode that enables goal-driven workflows with auto-continuation, persistence, and evidence-gated completion. It allows users to set objectives, enforce safety limits, and resume sessions until goals are achieved or blocked.

## Key Features
- Session-scoped goals with persistent state across turns and compaction
- Guarded auto-continuation with configurable limits (turns, time, tokens, no-progress)
- Evidence-gated completion requiring substantiated claims before marking goals as done
- Multi-goal support with focus/backgrounding and ordered sequences
- Project-local restart recovery with bounded lifecycle ledger and state persistence

## Why It Matters for RAG Builders
It enables reliable, unattended goal-driven workflows in OpenCode by enforcing structured completion and persistence, critical for RAG builders integrating autonomous agent systems.
