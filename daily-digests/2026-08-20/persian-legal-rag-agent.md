## Summary
A specialized agentic Retrieval-Augmented Generation (RAG) system designed for Persian legal document question answering. It processes Persian legal texts, including scanned documents via OCR, and retrieves relevant legal articles using metadata-aware vector search with LanceDB. The system includes query rewriting, intent classification, LLM-based reranking, and grounded answer generation.

## Key Features
- End-to-end Persian legal document processing with OCR support for scanned PDFs
- Metadata-aware vector retrieval using LanceDB with structured filtering (law name, article number, clause number)
- Agentic pipeline with query rewriting, intent classification, and LLM-based reranking for improved answer relevance
- Grounded answer generation with inline source references and RAGAS evaluation for quality metrics
- Performance and latency analysis with benchmarking datasets for seven Iranian legal documents

## Why It Matters for RAG Builders
This repository provides a production-ready template for building Persian-language legal RAG systems with advanced features like OCR, metadata filtering, and LLM-based reranking, critical for AI engineers working on domain-specific retrieval applications.
