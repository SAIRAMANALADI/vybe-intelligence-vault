## Summary
An AI-powered document question-answering system leveraging Retrieval-Augmented Generation (RAG) to process PDFs, generate semantic embeddings, and deliver context-aware answers using Google's Gemini models with ChromaDB for vector storage.

## Key Features
- PDF text extraction with page number preservation
- Overlapping text chunking for improved retrieval accuracy
- Semantic embeddings via Google Gemini Embedding API
- Persistent Chroma vector database for efficient storage and retrieval
- Context-aware answer generation using Google Gemini
