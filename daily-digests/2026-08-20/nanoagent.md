## Summary
NanoAgent is a local-first AI coding agent designed for desktop, terminal, editor, and CI workflows. It enables repository-aware code understanding, planning, editing, validation, and automated PR reviews while maintaining human control and local data privacy.

## Key Features
- Cross-platform support (desktop, CLI, VS Code, Visual Studio, CI)
- Repository-aware code understanding and editing with approval controls
- Profile-based workflows (implementation, planning, review, exploration)
- Versionable workspace memory in `.nanoagent/` files for team collaboration
- Built-in LSP-powered code intelligence for symbols, diagnostics, and refactoring

## Why It Matters for RAG Builders
NanoAgent provides a unified, local-first AI agent framework that bridges the gap between interactive coding assistance and automated CI workflows, ensuring human oversight while enabling scalable AI-driven development.
