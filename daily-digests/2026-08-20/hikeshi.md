## Summary
HIKESHI is an autonomous incident response AI agent for small SRE teams, inspired by Edo-period firefighters. It combines multi-agent diagnostics, human-in-the-loop (HITL) approval, and real-time remediation with a focus on safety boundaries and transparent decision-making.

## Key Features
- Multi-agent diagnostic pipeline (Triage→Investigate→RAG→Remediate) with real-time SSE feedback
- Human-in-the-loop (HITL) 1-click approval for irreversible operations, ensuring safety boundaries
- Isolation/quarantine ('敲き') feature to contain incidents before root-cause resolution
- Agentic RAG with source-attributed KB integration for explainable diagnostics
- Self-improving postmortem system that evolves KB with human-approved incident learnings

## Why It Matters for RAG Builders
It provides a practical, safety-first framework for autonomous incident response in AI systems, bridging the gap between AI-driven diagnostics and human oversight with measurable quality gates.
