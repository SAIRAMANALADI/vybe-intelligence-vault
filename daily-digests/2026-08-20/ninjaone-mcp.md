## Summary
A Model Context Protocol (MCP) server for NinjaOne, enabling AI assistants to interact with NinjaOne's IT management platform through a decision-tree-based tool architecture. It provides domain-specific tools for devices, organizations, alerts, and tickets with lazy loading for efficiency.

## Key Features
- Hierarchical tool loading with decision-tree architecture for reduced cognitive load and faster initial response times
- Domain-specific tools for devices, organizations, alerts, and tickets with interactive card support (SEP-1865)
- One-click deployment options for Cloudflare Workers and DigitalOcean App Platform with prebuilt container images
- OAuth 2.0 authentication with automatic token refresh and multi-region support (US, EU, OC)
- Client-side filtering and pagination for tickets and devices with clear state management

## Why It Matters for RAG Builders
It enables AI assistants to securely and efficiently interact with NinjaOne's IT management platform, unlocking automation for device monitoring, patching, scripting, and alert management.
