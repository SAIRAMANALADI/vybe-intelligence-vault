## Summary
InfoSlides.MCP is a CLI and MCP server that enables AI agents to provision, manage, and stream digital signage content to smart TVs or HLS-capable displays. It supports anonymous workspace creation, live data feeds, and integrates seamlessly with MCP clients like Claude Code or Cursor.

## Key Features
- Anonymous workspace provisioning with no account required
- 27 MCP tools for end-to-end signage management (slideshows, devices, schedules, data triggers)
- Supports PowerPoint, PDF, images, and live data-driven templates
- Native AOT-compiled binary with zero runtime dependencies
- Free permanent plan (1 screen, 4 slideshows, 2 users, 200 MB)

## Why It Matters for RAG Builders
It enables AI agents to autonomously provision and manage digital signage, reducing manual setup and expanding automation capabilities for RAG/AI stacks.
