## Summary
Contexa is an open-source AI-native post-authentication runtime control plane designed to continuously evaluate and constrain authenticated behavior within Spring Boot applications. It provides zero-trust runtime decisions to challenge, block, escalate, or allow requests based on dynamic analysis, complementing upstream security discovery tools like Glasswing.

## Key Features
- AI-driven runtime decision engine with 5-action controls (ALLOW, CHALLENGE, BLOCK, ESCALATE, PENDING_ANALYSIS)
- Dynamic authorization and policy evaluation at request time
- Integration with LLM and RAG for contextual security decisions
- Modular architecture with Spring Boot auto-configuration
- Proof-backed verification and benchmarking capabilities

## Why It Matters for RAG Builders
Contexa fills the critical gap in AI-native security stacks by providing runtime zero-trust controls for authenticated requests, reducing exploit windows and ensuring continuous protection after upstream discovery.
