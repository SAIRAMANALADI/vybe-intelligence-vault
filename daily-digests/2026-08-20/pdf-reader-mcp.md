## Summary
An MCP (Model Context Protocol) server designed to inspect and analyze the internal structure of PDF documents, including metadata, text, images, annotations, and tagged content. It provides deep structural insights beyond basic text extraction, enabling precise analysis of PDFs for AI and RAG applications.

## Key Features
- Comprehensive PDF internal structure inspection (objects, catalogs, tags, fonts, annotations, signatures)
- Logical text extraction in tagged PDFs (ISO 32000-2 compliant) with structure-aware ordering
- Multi-tier toolset (17 tools) for basic, structural, and validation operations
- Structured error handling with unified error codes for AI-driven error interpretation
- Support for remote PDF processing, multi-column layouts, and compact whitespace handling

## Why It Matters for RAG Builders
It enables precise extraction and structural analysis of PDF content, critical for building high-quality RAG systems that require accurate document understanding beyond simple text extraction.
