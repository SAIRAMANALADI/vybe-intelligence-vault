## Summary
FrootAI is a vendor-neutral, eval-first framework for building and orchestrating composable AI agents and solutions. It provides a unified ecosystem for infrastructure, platform, and application teams to develop, evaluate, and deploy deterministic AI systems across multiple LLMs and environments.

## Key Features
- Vendor-neutral agent deployment across multiple LLMs (Claude, GPT, Gemini, Bedrock, etc.) with zero code changes
- Eval-first approach with 638/638 spec conformance and regression-tested quality gates
- Composable solution plays and skills with open-source MIT licensing and no vendor lock-in
- Edge-native MCP server powered by Cloudflare Workers for near-zero cold starts
- FAI Protocol for wiring AI primitives (agents, skills, hooks, workflows) into production-ready systems

## Why It Matters for RAG Builders
FrootAI provides a critical glue layer for RAG builders by enabling deterministic, vendor-neutral agent orchestration with built-in evaluation and compliance, reducing integration complexity and ensuring reliability across diverse AI ecosystems.
