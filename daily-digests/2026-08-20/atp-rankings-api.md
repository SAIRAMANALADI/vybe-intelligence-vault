## Summary
A Python-based project for collecting, analyzing, and visualizing ATP tennis rankings data with web scraping, database management, interactive web interfaces, and AI integration via Model Context Protocol (MCP).

## Key Features
- Automated scraping of ATP rankings data from atptour.com
- SQLite database with 2,600+ weeks of historical rankings (1973-2025)
- Interactive FastAPI web interface with Chart.js visualizations
- Model Context Protocol (MCP) server for AI assistant access
- CLI tools for player statistics and comparisons with Matplotlib graphs
