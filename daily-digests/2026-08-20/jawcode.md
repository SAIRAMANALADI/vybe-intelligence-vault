## Summary
Jawcode is a Bun-native coding-agent harness that implements an IPABCD workflow (Interview, Plan, Audit, Build, Check, Done) for structured software development. It supports 46 providers and 3,600+ models, enabling autonomous or human-in-the-loop agent execution with persistent evidence and adversarial verification.

## Key Features
- Implements IPABCD workflow (Interview, Plan, Audit, Build, Check, Done) with explicit gates for each stage
- Supports 46 providers and 3,600+ models with seamless model switching and 1M context support
- Five role agents (executor, architect, planner, critic, executor_ext) for parallel, non-duplicative work
- Bun-native runtime with prompt caching, streaming tool output, and Rust-backed native bindings for performance
- Human-in-the-loop (HITL) or human-on-the-loop (HOTL) control modes with persistent evidence and correction de-anchoring

## Why It Matters for RAG Builders
Jawcode provides a structured, verifiable, and auditable workflow for AI-driven software development, ensuring reliability and reducing hallucinations through adversarial verification and persistent evidence.
