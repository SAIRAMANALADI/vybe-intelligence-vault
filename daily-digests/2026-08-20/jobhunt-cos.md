## Summary
A local job-search automation tool that runs within Claude Code to find, score, and apply to job postings across company career pages. It tailors resumes, fills application forms, and ensures manual approval before submission, all while maintaining privacy and avoiding automation pitfalls like LinkedIn restrictions or incorrect submissions.

## Key Features
- Polling job boards via public APIs (Greenhouse, Lever, Ashby) without requiring keys or incurring costs
- Scoring job matches with transparent, editable rubrics and manual approval before submission
- Tailoring CVs and cover letters directly from a master profile without fabricating information
- Filling application forms in a visible browser session with screenshots for verification
- Self-tuning mechanism that refines scoring rules based on application outcomes

## Why It Matters for RAG Builders
It provides a privacy-preserving, cost-effective way to automate tedious job application tasks while ensuring accuracy and manual oversight, reducing the risk of errors or account restrictions.
