## Summary
A production-ready reference RAG service that grounds LLM-generated answers in user-provided documents, served via a typed API with full infrastructure support including containerization, Kubernetes deployment, observability, and CI/CD pipelines.

## Key Features
- Evidence-grounded LLM generation with document grounding via vector search (NumPy, FAISS, or Qdrant)
- Typed API with input validation, authentication, and structured logging
- Containerized and Kubernetes-deployable with Helm charts and CI/CD pipelines
- Prometheus metrics and health checks (/health, /ready, /metrics)
- Support for multiple LLM backends (Mock, OpenAI) and embedding methods (hash, semantic)

## Why It Matters for RAG Builders
It provides a production-grade, deployable RAG service template with full infrastructure support, enabling AI engineers to build grounded, scalable, and observable RAG systems quickly.
