## Summary
A pip-installable plugin that adds Microsoft Teams voice/video (CVI) capabilities to the Hermes Agent, enabling realtime speech-to-speech, streaming STT→agent→TTS, camera/screen vision, and meeting recaps. It integrates with StandIn, a hosted media bridge, to connect Teams calls to Hermes without requiring Azure bot registration.

## Key Features
- Seamless integration with Hermes Agent via pip-installable plugin
- Supports realtime speech-to-speech and streaming STT→agent→TTS workflows
- Enables camera/screen vision and lip-synced avatar cues during Teams calls
- Generates meeting recaps and minutes with optional Word document attachments
- HMAC-authenticated WebSocket bridge for secure StandIn media bridge connections

## Why It Matters for RAG Builders
This plugin bridges Microsoft Teams calls to Hermes Agent, enabling realtime voice/video interactions and AI-driven meeting recaps, which is critical for AI stack builders integrating Teams with conversational AI systems.
