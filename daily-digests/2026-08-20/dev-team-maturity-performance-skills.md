## Summary
A pair of Claude Agent Skills that transform raw Jira exports into governed, explainable engineering maturity analyses. The solution includes a setup wizard for customizing KPIs and a deterministic engine that computes traceable KPIs, detects patterns, and recommends interventions from a fixed catalog without LLM hallucinations.

## Key Features
- Deterministic KPI computation from Jira data with full traceability to source fields
- Rule-based pattern detection for consistent, repeatable maturity scoring
- Fixed intervention catalog to avoid LLM-generated recommendations
- Onboarding workflow for customizing KPIs and thresholds per organization
- Structured output separating facts, signals, and interventions for auditability

## Why It Matters for RAG Builders
It provides a governed, repeatable framework for analyzing engineering team maturity from Jira data, eliminating guesswork and hallucinations in AI-driven assessments.
