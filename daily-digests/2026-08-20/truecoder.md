## Summary
TrueCoder is a terminal-native coding agent that executes commands in a policy-checked, sandboxed, and auditable environment. It integrates a Textual TUI, OpenAI-compatible LLM client, and a Docker-based execution plane to ensure secure, policy-compliant, and immutable command execution with durable audit trails.

## Key Features
- Policy-checked and approval-gated command execution with immutable audit logs
- Docker-based sandbox with non-root, read-only, and network-denied execution
- Textual TUI with live execution cards, approval workflows, and token accounting
- Persistent project-scoped SQLite sessions for transactional state management
- Seven built-in tools (read, write, edit, list, glob, grep, shell) with atomic operations and concurrency safety

## Why It Matters for RAG Builders
TrueCoder provides a secure, auditable, and policy-compliant execution plane for AI agents, ensuring safe and reliable code manipulation in production environments.
