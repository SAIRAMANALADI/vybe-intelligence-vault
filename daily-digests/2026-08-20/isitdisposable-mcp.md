## Summary
An MCP server that enables AI agents to verify if an email address or domain is disposable using the isitdisposable.com API. It integrates seamlessly with MCP hosts like Claude Desktop or Code for real-time validation.

## Key Features
- Provides tools to check single or batch email/domain disposability via MCP
- Fails open on network/API errors, ensuring agent reliability
- Supports both email and domain checks with detailed metadata (e.g., MX validation, relay detection)
- Lightweight deployment via `npx` with no manual installation required
- Free tier available for API key access

## Why It Matters for RAG Builders
It enables AI agents to filter out disposable emails or domains during user registration or communication, improving data quality and reducing spam risks in RAG pipelines.
