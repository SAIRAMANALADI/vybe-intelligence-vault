## Summary
A Model Context Protocol (MCP) server and CLI package that bridges AI agents, local scripts, and coding harnesses to RemNote via the RemNote Automation Bridge plugin. Enables bidirectional interaction with RemNote knowledge bases for notes, flashcards, and journaling.

## Key Features
- Enables AI agents (e.g., Claude Code) to interact with RemNote via MCP for note/flashcard creation, search, and updates
- Provides `remnote-cli` for local shell automation and `remnote-mcp-stdio` for stdio-based MCP clients
- Supports multi-agent concurrent connections to the same RemNote knowledge base
- Offers remote access via tunneling (e.g., ngrok) for cloud-based AI clients
- Includes comprehensive documentation, version compatibility guides, and troubleshooting resources

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and extend RemNote knowledge bases, bridging structured knowledge with agentic workflows for enhanced RAG and automation capabilities.
