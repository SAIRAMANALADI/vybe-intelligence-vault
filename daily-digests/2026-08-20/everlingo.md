## Summary
EverLingo is an AI-powered language learning companion that captures and organizes contextual notes during language study, enabling personalized and adaptive learning experiences. It transforms lookups, translations, and conversations into structured knowledge that can be recalled later to reinforce memory.

## Key Features
- Captures learning context during lookups, translations, and conversations to create contextual notes
- Personalized AI responses tailored to user preferences and language level
- Multi-platform access including browser extension, PWA, terminal TUI, and WeChat integration
- Notes stored in open standards (OKF) for portability and compatibility with external tools like Obsidian
- Dynamic user profile adaptation based on learning history and stated preferences

## Why It Matters for RAG Builders
EverLingo bridges the gap between transient AI interactions and persistent knowledge retention, making it essential for AI engineers building RAG systems that require contextual memory and personalized learning experiences.
