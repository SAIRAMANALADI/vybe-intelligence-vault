## Summary
Tersign-js is a TypeScript SDK and MCP server for creating, signing, and verifying counter-signed EIP-712 receipts in the agent economy. It provides a neutral, hash-chained ledger for agent commerce, enabling verifiable evidence trails for transactions, compliance records, and dispute resolution.

## Key Features
- Counter-signed EIP-712 receipts with hash-chained ledgers for immutable transaction records
- MCP server for agent integration with tools like `issue_receipt`, `verify_receipt`, and `open_dispute`
- Compliance record support (EU Art-226b, EN 16931, GDPR-minimized) with structured evidence envelopes
- Local verification of receipts via CLI or HTTP API without requiring API keys
- Conformance vectors for RFC 8785 (JCS) and keccak256 to ensure cross-implementation compatibility

## Why It Matters for RAG Builders
Tersign-js provides a critical infrastructure layer for RAG builders by ensuring verifiable, tamper-proof evidence trails for agent transactions, compliance, and disputes, enabling trustless verification in AI-driven commerce.
