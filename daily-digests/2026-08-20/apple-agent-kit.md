## Summary
Apple Agent Kit is a spec-first knowledge system that pre-digests official Apple documentation into atomic Knowledge Contracts for AI coding agents, enabling deterministic routing via Skills to reduce token usage and improve implementation consistency for Apple platform development tasks.

## Key Features
- Transforms Apple documentation into atomic Knowledge Contracts for efficient routing
- Uses deterministic Skills to minimize token usage and hallucination risks
- Supports 30+ specialized Skills covering UI, networking, security, and more
- Preserves traceability to official Apple documentation for compliance
- Designed for scalability with hundreds of reusable Knowledge Contracts

## Why It Matters for RAG Builders
It provides a structured, token-efficient way for AI agents to access and apply Apple platform conventions without hallucinating or over-consuming documentation.
