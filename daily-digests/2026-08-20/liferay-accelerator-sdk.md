## Summary
A hardened SDK designed to accelerate Liferay DXP integration by providing dynamic catalog adapters, runtime auto-discovery, and contract enforcement for API orchestration between legacy and modern Liferay Commerce models.

## Key Features
- Dynamic catalog adapters for seamless integration between legacy and modern Liferay Commerce models
- Runtime auto-discovery of target DXP capabilities to dynamically select the correct adapter
- Contract enforcement via OpenAPI specification validation for inbound and outbound payloads
- Transient error resilience with configurable retry thresholds and soft-status error mapping
- AI Bootstrapper Skill for automated setup and scaffolding

## Why It Matters for RAG Builders
It simplifies and accelerates the integration of Liferay DXP with modern e-commerce systems, reducing development overhead for AI-driven commerce applications.
