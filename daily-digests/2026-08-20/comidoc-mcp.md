## Summary
Comidoc MCP Server provides verified Udemy coupon and course data with live redemption capacity tracking for AI agents. It exposes a remote MCP server endpoint for searching courses, fetching offers, and retrieving trending data without requiring self-hosting.

## Key Features
- Live redemption capacity tracking for Udemy coupons (remaining uses, freshness state)
- Comprehensive course and offer search with advanced filters (categories, languages, levels, expiry, discounts)
- Trending course and topic data over 24h, 7d, or 30d windows
- Anonymous access with small hourly quota or key-based tiers (free to $49/month)
- Integration-ready via MCP protocol for AI agents and tools
