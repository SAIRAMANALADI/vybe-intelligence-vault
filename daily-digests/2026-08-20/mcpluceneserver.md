## Summary
MCPLuceneServer is a Model Context Protocol (MCP) server that exposes Apache Lucene's full-text search capabilities via a conversational interface. It enables AI assistants like Claude to index, search, and manage document collections (PDFs, Office files, etc.) with advanced features like semantic search, JDBC metadata enrichment, and real-time document crawling.

## Key Features
- Automatic document crawling and real-time indexing for PDFs, Office files, and more
- Hybrid search combining keyword (BM25) and semantic (KNN) search with multilingual-e5 embeddings
- JDBC metadata enrichment for structured data integration from databases
- Advanced query profiling and debugging tools for search optimization
- Dual transport support (STDIO for Claude Desktop, HTTP for web clients)

## Why It Matters for RAG Builders
It provides a robust, conversational interface to Apache Lucene's search capabilities, enabling AI assistants to efficiently index and retrieve documents for RAG applications with minimal setup.
