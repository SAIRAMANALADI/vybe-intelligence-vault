## Summary
A full-stack AI chatbot built with React and Node.js, powered by Google's Gemini API. It enables real-time conversational chat with streaming responses and supports uploading PDFs to ask context-grounded questions using Retrieval-Augmented Generation (RAG).

## Key Features
- Real-time streaming chat responses with typewriter effect
- PDF upload and context-grounded Q&A using RAG with ChromaDB
- Automatic fallback between Gemini models for rate limiting
- Persistent chat history and active document in MongoDB
- Batch embedding requests with retry logic for rate limits

## Why It Matters for RAG Builders
This repository provides a practical, end-to-end implementation of a RAG-powered chatbot using Google's Gemini API, demonstrating critical integration patterns for AI engineers building production-grade retrieval systems.
