## Summary
Nocturne Codex is a local desktop engineering workspace designed to facilitate collaboration between developers and AI agents, particularly with OpenAI's Codex CLI. It organizes project context, persistent conversations, agent activities, and Git awareness into a structured workflow without replacing developer judgment.

## Key Features
- Persistent AI conversations stored locally in SQLite for continuity across sessions
- Structured engineering loop (Analyze, Plan, Explain, Suggest, Approve, Implement, Validate)
- Review Mode for read-only analysis and Build Mode for safe code modifications
- Workspace memory and project health tracking with actionable suggestions
- Secure Electron architecture with sandboxing and validated IPC payloads

## Why It Matters for RAG Builders
Nocturne Codex provides a structured, secure, and developer-centric environment for integrating AI agents into the software development lifecycle, making it essential for RAG builders who need reliable collaboration workflows.
