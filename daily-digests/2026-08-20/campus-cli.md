## Summary
campus-cli is an unofficial CLI and MCP server that integrates Blackboard Learn (UPC Aula Virtual) with AI assistants like ChatGPT and Claude, enabling direct access to courses, assignments, grades, and materials without browser interaction. It supports both terminal-based commands and MCP protocol for AI tool integration.

## Key Features
- Direct Blackboard Learn integration via SSO without requiring university OAuth keys
- CLI for manual terminal-based access to courses, assignments, grades, and materials
- MCP server mode for AI assistants (Claude, Cursor, Copilot, etc.) to query Blackboard data
- Supports downloading files, folders, and attachments locally
- Extensible API for raw Blackboard endpoint queries and scripting

## Why It Matters for RAG Builders
It bridges Blackboard Learn with AI assistants via MCP, enabling seamless access to academic data for RAG pipelines without manual data extraction.
