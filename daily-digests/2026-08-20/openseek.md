## Summary
OpenSeek is an open-source terminal-based coding agent that provides a multi-provider, MCP-compatible environment with Plan/Agent/YOLO modes for autonomous or guided AI-driven development tasks.

## Key Features
- Supports 28+ built-in AI providers (OpenAI-compat, Anthropic, Google, local models) with transparent cost tracking
- Three operational modes: Plan (read-only), Agent (confirmed execution), and YOLO (full autonomy)
- Integrated MCP client for extensibility and LSP support for real-time diagnostics
- Headless HTTP/SSE runtime API for IDE bridges and CI integration
- Configurable via layered settings (env, project, user, defaults) with security sandboxing

## Why It Matters for RAG Builders
OpenSeek provides an open-source, multi-provider alternative to closed-source coding agents, enabling RAG builders to integrate autonomous or guided AI workflows with flexible provider routing and cost transparency.
