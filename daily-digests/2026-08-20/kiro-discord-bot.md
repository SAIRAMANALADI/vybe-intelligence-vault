## Summary
A Discord bot and control plane for managing project-bound ACP agents via Discord channels and threads. It integrates with agent engines like Kiro CLI or OMP, providing MCP tool access, operational controls, and automation features such as cron jobs and memory management.

## Key Features
- Project-bound agent sessions tied to Discord channels and directories
- Support for several agent engines (Kiro CLI, OMP) with flexible switching
- MCP tool discovery and policy-based exposure per channel
- Operational controls including cron jobs, audit logs, and memory management
- A2A (Agent-to-Agent) runtime cutover and trust peer management

## Why It Matters for RAG Builders
It provides a unified Discord-based control plane for managing and orchestrating project-bound AI agents, simplifying multi-agent workflows and MCP tool integration for RAG builders.
