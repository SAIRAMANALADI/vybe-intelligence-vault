## Summary
philidor-mcp is a Windows-based server application that analyzes and compares risk scores for over 700 DeFi vaults across protocols like Aave and Morpho. It provides users with clear risk metrics and comparisons without requiring API keys or complex setup.

## Key Features
- Analyzes risk scores for 700+ DeFi vaults across multiple protocols
- Enables side-by-side comparison of vaults and risk factors
- No API keys or complex setup required for operation
- Supports popular protocols like Aave, Morpho, and Ethereum-based vaults
- Runs on Windows 10+ with minimal system requirements
