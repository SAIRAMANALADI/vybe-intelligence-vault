## Summary
AlgoLog is a self-hosted tool for competitive programmers to log, rate, and revisit coding problems across platforms like LeetCode and Codeforces. It uses spaced repetition, similarity search, and optional AI enrichment to help users improve their problem-solving skills.

## Key Features
- Self-rating system for problem submissions with difficulty scores and honesty flags
- Spaced repetition scheduler for revisiting weak topics and overdue problems
- Similarity search using pgvector embeddings to find related problems from personal history
- Weekly digest generation with optional AI enrichment for tips and web-searched problems
- MCP server integration for querying practice history and study materials from AI clients
