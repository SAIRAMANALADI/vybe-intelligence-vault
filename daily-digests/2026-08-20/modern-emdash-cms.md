## Summary
A bilingual (Arabic/English) personal portfolio built with Astro SSR and EmDash CMS, deployed as a Cloudflare Worker. It includes a built-in MCP server for AI agent access to content and supports sandboxed plugins via Cloudflare Workers.

## Key Features
- Bilingual Arabic/English i18n with RTL/LTR support
- Built-in MCP server exposing 46 tools for AI agent access to content
- Sandboxed plugin system via Cloudflare Worker Loaders
- RSS aggregator plugin with AI-powered summarization, translation, and media handling
- Cloudflare D1 database for content storage and Cloudflare R2 for media

## Why It Matters for RAG Builders
It provides a production-ready template for deploying bilingual, AI-accessible content systems with MCP integration and plugin extensibility on Cloudflare Workers.
