## Summary
BitAtlas is a zero-knowledge cloud storage platform designed for both humans and AI agents, offering end-to-end encryption and secure document management. It enables agents to safely interact with sensitive data via the Model Context Protocol (MCP) while ensuring European data sovereignty.

## Key Features
- Client-side AES-256-GCM encryption ensuring server never accesses plaintext data
- Native support for AI agents via Model Context Protocol (MCP) with 7 tools for file operations
- Pay-per-request model using USDC on Base Network with anonymous access (x402 standard)
- European-hosted infrastructure compliant with GDPR for data sovereignty
- Personal vault for secure storage of sensitive documents like identity papers or medical records

BitAtlas provides a secure, agent-friendly storage layer essential for RAG systems handling sensitive or private data while maintaining compliance and privacy.
