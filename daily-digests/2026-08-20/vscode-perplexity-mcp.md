## Summary
A monorepo providing a Perplexity MCP server and VS Code extension for integrating Perplexity AI's search, reasoning, and research capabilities directly into 15+ IDEs and MCP-capable clients via a long-lived browser session.

## Key Features
- Long-lived Perplexity browser session integration for MCP clients
- VS Code extension with embedded MCP daemon and webview dashboard
- Auto-configuration for 20+ MCP-capable IDEs (Cursor, Windsurf, Claude Desktop, etc.)
- Standalone npm package for direct MCP client integration
- Secure session management with encrypted vault and profile support

## Why It Matters for RAG Builders
It enables seamless integration of Perplexity AI's advanced search and reasoning capabilities into development environments, enhancing RAG pipelines with real-time, authenticated access to Perplexity's tools.
