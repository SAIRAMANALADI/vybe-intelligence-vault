## Summary
plori provides cloud-based AI agents with persistent machines, real disk storage, CLI tools, and memory, accessible via MCP and REST APIs. Each agent operates as a remote server, scaling to zero when idle, and integrates seamlessly with MCP clients like Claude, Cursor, and VS Code.

## Key Features
- Persistent agent machines with real disk storage and memory
- 18+ tools for agent lifecycle management, scheduling, and workflows
- Remote MCP server with OAuth 2.1 and API key authentication
- Scalable to zero when idle, reducing resource usage
- Integration with popular MCP clients (Claude, Cursor, VS Code, Codex)

## Why It Matters for RAG Builders
plori enables AI agents to operate with persistent, stateful environments and real tools, making it essential for building advanced, long-running agent systems in RAG and AI stacks.
