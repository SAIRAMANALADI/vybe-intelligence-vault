## Summary
CampusMemory is a persistent-memory learning coach that extracts, stores, and retrieves durable learner facts across sessions using Qwen Cloud for structured extraction. It provides a visible memory vault with one-click forget controls, ensuring context retention without hiding stored data.

## Key Features
- Structured memory extraction via Qwen Cloud API for durable facts
- Bounded retrieval with importance, keyword overlap, and recency scoring
- Conflict resolution for stable keys (e.g., replacing outdated study time)
- User-controlled forgetting and memory expiration with audit trails
- Transparent memory vault UI for inspecting stored and recalled facts

## Why It Matters for RAG Builders
CampusMemory solves the critical RAG challenge of maintaining persistent, user-controlled context across sessions, ensuring AI assistants retain relevant learner facts without manual re-input.
