## Summary
Morrowind MCP is a Model Context Protocol (MCP) server that bridges the Morrowind game to external LLM AIs, enabling AI agents to interact with the game world, tools, and resources via standardized MCP interfaces.

## Key Features
- Enables AI agents to interact with Morrowind game world via MCP standard
- Supports tools, resources, prompts, and notifications for AI integration
- Configurable via layered JSON configurations (default, local, env) for flexibility
- Provides test scripts for unit, integration, and server-to-client communication validation
- Handles session management with SSE streams and JSON-RPC over HTTP

## Why It Matters for RAG Builders
It provides a standardized way for AI agents to interact with and extract context from the Morrowind game environment, expanding the scope of AI-driven game analysis and automation.
