## Summary
IntelliRecon is a browser-native AI recon console that integrates a Claude-driven agent with MCP security tools, enabling unified terminal and agent workflows for security reconnaissance. It combines a terminal, agent chat, and knowledge base in a single UI, with a minimal backend bridging browser limitations and MCP servers.

## Key Features
- Unified agent-terminal workflow with shared shell session and findings
- 9 specialized recon modes (e.g., JavaScript Recon, API Mapping, Authorization Analysis)
- Durable SQLite knowledge base for persistent per-target reconnaissance data
- Swappable LLM backends (Anthropic or OpenRouter-compatible gateways)
- Terminal handoff with structured `HANDOFF.md` and `run.json` for seamless session continuity

## Why It Matters for RAG Builders
IntelliRecon streamlines AI-driven security reconnaissance by merging agent-driven tooling with a shared terminal and knowledge base, reducing context switching and enabling continuous, autonomous pentesting workflows.
