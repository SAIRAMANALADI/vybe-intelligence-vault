## Summary
A minimalist AI agent framework implemented in pure Python without external agent libraries, demonstrating a deterministic loop for task execution with tool integration. Supports local (Ollama), remote (OpenAI/Anthropic/Gemini), and mixed-mode execution for flexible AI agent development.

## Key Features
- Pure Python implementation with no external agent frameworks, using a simple while loop for task execution
- Three execution modes: local (Ollama-only), remote (cloud providers), and mixed (local orchestrates with remote delegation)
- Built-in reliability layer with retry mechanisms, circuit breakers, and provider fallback for network resilience
- Support for MCP (Model Context Protocol) for extensible tool integration and custom tool definitions
- Comprehensive deployment pipeline for CI/CD automation and mobile app releases
