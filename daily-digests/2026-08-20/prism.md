## Summary
PRISM is a self-hosted AI agent framework that runs entirely on local hardware, enabling agents to dynamically modify their environment, build interactive widgets, and integrate with various services without relying on cloud APIs. It combines a Go backend with a vanilla JS frontend and supports multi-user deployments with shared workspaces.

## Key Features
- Agents can dynamically create and embed interactive widgets in the dashboard
- Sandboxed workspace for code execution and tool generation without host machine access
- Supports multi-user deployments with accounts, groups, and shared workspaces
- Integrates with email, calendar, tasks, notes, and external services via OAuth or app passwords
- Automatically allocates subdomains and ports for embedded services using Traefik

## Why It Matters for RAG Builders
PRISM empowers AI agents with true agency over their environment, enabling dynamic tool creation, self-modifying dashboards, and seamless integration with local services, making it ideal for building autonomous, self-hosted AI systems.
