## Summary
AGMA (AG Minecraft Agent) is a secure AI agent framework for Minecraft 1.21.11 that integrates with Paper servers and offers both a server-integrated plugin and a standalone client mod for Fabric/Forge. It enables private AI interactions via OpenAI, Anthropic, DeepSeek, or local endpoints without exposing server context or enabling arbitrary commands.

## Key Features
- Private AI interactions for players via server-integrated plugin or standalone client
- Supports multiple LLM providers (OpenAI, Anthropic, DeepSeek, Gemini) and local endpoints
- Strict security model with loopback-only Runtime, permission-gated commands, and schema validation
- Optional Fabric client mod for overlays, build previews, and rich UI integration
- Built-in diagnostics, cost tracking, and provider configuration management

## Why It Matters for RAG Builders
AGMA provides a secure, modular framework for integrating AI agents into Minecraft servers, enabling private, controlled interactions without exposing server context or enabling arbitrary commands, which is valuable for AI stack builders focused on secure, game-integrated agent systems.
