## Summary
Lorekeeper is a self-improving memory system for AI agents that enables persistent, context-aware interactions across sessions without cloud dependencies. It provides a local MCP server for storing, retrieving, and enhancing agent memories with automatic scoring, decay, and knowledge graph linking.

## Key Features
- Hybrid search combining semantic vectors, BM25, time-decay, and usage frequency for high-precision memory retrieval
- Automatic self-improvement through feedback loops that adjust memory scores and decay weak memories
- Lightweight knowledge graph formation via auto-linking of related memories without manual effort
- Universal MCP compatibility with major AI coding agents (Claude Code, Cursor, Hermes, etc.)
- Full-featured local dashboard for browsing, editing, and managing memories with backup/restore capabilities

## Why It Matters for RAG Builders
Lorekeeper eliminates the need for repetitive context re-entry in AI agents by providing a persistent, self-improving memory system that enhances agent performance over time without cloud dependencies.
