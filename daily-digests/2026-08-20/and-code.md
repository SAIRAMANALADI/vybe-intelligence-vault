## Summary
AndCode is a native Android application that provides a touch-first GUI for running AI coding agents like OpenCode, Claude Code, and Google Antigravity locally on Android devices or remotely on a PC/Mac/Linux. It eliminates the need for terminals or SSH by wrapping agent runtimes in a user-friendly mobile interface.

## Key Features
- Native Android GUI for AI coding agents with no terminal required
- On-device runtime via PRoot with Alpine Linux or Debian environments
- Support for OpenCode, Claude Code, and Google Antigravity agents
- Real-time streaming responses, tool approvals, and session management
- Seamless runtime switching (handoff) between local and remote agents

## Why It Matters for RAG Builders
It democratizes AI coding agent access by bringing them to mobile devices with a native interface, enabling developers to interact with agents anywhere without needing a PC or terminal.
