## Summary
Workbuddian integrates the WorkBuddy/CodeBuddy CLI into Obsidian as an AI agent, enabling in-vault chat with streaming replies, image analysis, note referencing, and conversation management without leaving the notes app.

## Key Features
- In-vault AI chat with streaming Markdown rendering and collapsible tool/think blocks
- Image vision support for screenshot analysis within Obsidian
- Direct note and file referencing via @-mentions for contextual responses
- Persistent conversation history with multi-tab management and export options
- Cross-platform support (Windows/macOS) with auto-discovery of CodeBuddy CLI and Node.js

## Why It Matters for RAG Builders
Workbuddian bridges local AI agents with Obsidian's note-taking ecosystem, enabling seamless contextual AI assistance directly within users' knowledge bases.
