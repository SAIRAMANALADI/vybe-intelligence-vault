## Summary
Call Sara is a Claude Code skill that acts as a personal accountant, managing financial data in a plain-text Beancount ledger and providing financial insights, budgeting, and expense tracking through natural language interactions.

## Key Features
- Automated financial ledger management with Beancount for double-entry accounting
- Natural language interaction via Claude Code for financial queries and advice
- Expense tracking, forecasting, and waste detection (e.g., redundant subscriptions)
- Privacy-focused design with data stored locally and encrypted secrets
- Interactive dashboard (Fava) for visualizing net worth, income, and expenses

## Why It Matters for RAG Builders
It provides a privacy-preserving, automated way to manage financial data for RAG systems that require structured, auditable, and real-time financial insights.
