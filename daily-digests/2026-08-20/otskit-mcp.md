## Summary
OTSkit-MCP is an MCP server that enables AI agents to interact with OpenTimestamps for Bitcoin-based document timestamping, verification, and monitoring. It exposes tools for stamping, upgrading, and verifying proofs directly from agent conversations.

## Key Features
- Exposes MCP tools for stamping, upgrading, and verifying Bitcoin timestamps via AI agents
- Supports local file hashing and direct file stamping in one step
- Includes a scheduler for automated timestamp upgrades and monitoring
- Uses SQLite for local proof storage and management
- Provides CLI commands for server management, monitoring, and configuration

## Why It Matters for RAG Builders
It enables AI agents to securely timestamp and verify documents on the Bitcoin blockchain, ensuring tamper-proof proof-of-existence for RAG pipelines.
