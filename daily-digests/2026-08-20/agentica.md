## Summary
Agentica is an async-first Python framework designed to build and run autonomous AI agents that perform long-running tasks, multi-agent collaboration, and persistent cross-session memory. It provides a harness for agents to execute real-world workflows with built-in safety, cost control, and self-evolution capabilities.

## Key Features
- Async-first agentic loop with built-in context compression, cost budgeting, and dead-loop protection for long-running tasks
- 40+ built-in tools (search, file operations, code execution, browser, OCR, image generation) and 20+ model integrations
- Persistent cross-session memory with relevance-based retrieval and drift defense, synchronized to global `AGENTS.md`
- Self-evolving skill system that compiles learned experiences into reusable `SKILL.md` files for cross-session reuse
- CLI and Web Gateway for out-of-the-box deployment, supporting `/goal` long-task loops and multi-agent workflows

## Why It Matters for RAG Builders
Agentica provides a robust, production-ready framework for building autonomous AI agents that can handle real-world tasks beyond simple chat interactions, making it essential for RAG builders seeking scalable, self-improving agent systems.
