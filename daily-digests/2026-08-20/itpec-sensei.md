## Summary
A local-first CLI tool for practicing ITPEC exam questions (Fundamental IT Engineer / IT Passport) with timed drills, progress tracking, and an MCP server for AI-assisted conversational practice sessions.

## Key Features
- Timed practice sessions with configurable limits (per-question or whole-session)
- Progress tracking with streaks, accuracy metrics, and activity heatmaps stored locally
- Review mode and weak-topic-weighted practice for targeted improvement
- MCP server for AI assistants (Claude Code, Codex CLI) to run conversational practice sessions
- Support for resuming, repeating, or deleting practice sessions with granular control

## Why It Matters for RAG Builders
Provides a structured, local-first way to generate and track practice data for AI assistants, enabling conversational exam drills with real-time feedback and progress analytics.
