## Summary
hax is a lightweight, terminal-native coding agent written in C, designed for minimal resource usage while providing interactive and automation-friendly AI assistance. It supports multiple LLM providers and models, with streaming Markdown output and inspectable transcripts.

## Key Features
- Single native C binary with minimal dependencies (few MBs of RAM usage)
- Streaming Markdown and tool invocation output with terminal-native rendering
- Support for multiple LLM providers (OpenAI, Anthropic, llama.cpp, etc.)
- Interactive REPL and one-shot mode with clean stdout/stderr for scripting
- Inspectable transcripts and wire protocol traces for debugging

## Why It Matters for RAG Builders
It provides a lightweight, terminal-native agent framework that can integrate with local or remote LLMs, making it ideal for AI engineers building RAG systems with minimal overhead.
