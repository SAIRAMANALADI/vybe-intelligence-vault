## Summary
KnowledgeReduce is a Python-based tool for distilling documents into compact, reliability-rated knowledge facts suitable for fine-tuning or RAG applications. It extracts facts from text, HTML, Markdown, or PDFs, filters and ranks them by quality, and exports them as JSONL or text digests, with optional knowledge graph and vector embedding capabilities.

## Key Features
- Pure-Python, dependency-light core with optional extras for spaCy and PDF support
- Reliability-rated fact extraction with quality filtering and deduplication
- Knowledge graph management with optional vector embeddings and blockchain verification
- Supports multiple output formats (chat JSONL, instruction JSONL, text digest)
- Idempotent document ingestion with provenance tracking and reproducible training set compilation

## Why It Matters for RAG Builders
It provides a lightweight, reliable pipeline for transforming unstructured documents into high-quality, model-absorbable knowledge facts, essential for building robust RAG systems and fine-tuning datasets.
