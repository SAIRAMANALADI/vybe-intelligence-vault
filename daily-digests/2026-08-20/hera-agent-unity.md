## Summary
Hera Agent Unity bridges AI coding agents with a live Unity Editor, enabling agents to inspect, modify, and verify Unity projects in real-time. It automates the feedback loop between AI-generated code and Unity's runtime state, reducing manual intervention and improving reliability.

## Key Features
- Real-time Unity Editor inspection and modification via CLI commands
- Automated compile, test, and runtime verification for AI-generated code
- Multi-project support with project-safe multi-Editor targeting
- Low-token CLI responses for efficient AI context consumption
- Input System automation for UI testing and interaction replay
