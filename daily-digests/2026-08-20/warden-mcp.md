## Summary
warden-mcp is an MCP server that integrates with Vaultwarden or Bitwarden to enable credential-aware AI agents to securely access, manage, and automate interactions with vault items like passwords, TOTP codes, and secure notes without hardcoding secrets.

## Key Features
- Secure credential retrieval and management for AI agents via MCP
- Supports Vaultwarden and Bitwarden vaults with CLI integration
- Provides read-only and read-write operations for vault items
- Offers HTTP and stdio transport modes for flexibility
- Includes security features like secret redaction and read-only mode

## Why It Matters for RAG Builders
It enables AI agents to securely access and use credentials from Vaultwarden or Bitwarden without exposing secrets in prompts or configurations, enhancing automation workflows while maintaining security.
