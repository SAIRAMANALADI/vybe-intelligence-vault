## Summary
A specialized agentic tool for screenwriters that processes unstructured feedback (PDFs, emails) to categorize notes, flag conflicts, and generate a scene-by-scene revision checklist. It persists structured analytics in ClickHouse and provides live dashboards for note frequencies and conflict rates.

## Key Features
- Automated categorization of screenwriting feedback by type, character, and scene
- Conflict detection and resolution tracking for contradictory notes
- Scene-by-scene revision checklist prioritized by severity
- Real-time analytics dashboard for note distributions and conflict rates
- Seamless integration with ClickHouse for persistent storage and querying

## Why It Matters for RAG Builders
It streamlines the screenwriting feedback process by automating note organization and conflict resolution, enabling writers to focus on creative revisions while leveraging structured analytics for data-driven decisions.
