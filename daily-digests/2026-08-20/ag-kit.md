## Summary
AG Kit is an agent engineering framework designed for Antigravity, providing a production-ready workspace with rules, skills, specialist agents, workflows, persistent memory, MCP integration, and a native safety hook for secure agent operations.

## Key Features
- Pre-built specialist agents (20+) with role definitions and intelligent routing
- Persistent memory management with context compression and durable storage
- Integrated safety hooks for blocking destructive commands (e.g., filesystem deletions)
- MCP configuration and synchronization for workspace tooling
- Production-ready workflows (e.g., /plan, /coordinate, /orchestrate) with SemVer contracts

## Why It Matters for RAG Builders
