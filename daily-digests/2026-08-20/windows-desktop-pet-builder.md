## Summary
A toolkit that enables users to create interactive, AI-generated Windows desktop pets from their pet photos. It provides step-by-step guidance, AI prompts, and scripts to generate draggable, mouse-responsive, and animated pets with physics-based behaviors.

## Key Features
- Step-by-step guide for creating custom Windows desktop pets from pet photos
- Provides AI prompts for generating pet images with consistent features
- Includes scripts for Windows environment validation and project initialization
- Supports draggable, mouse-responsive, and physics-based animations
- Offers AI agent integration with pre-built prompts for Codex, Claude Code, etc.
