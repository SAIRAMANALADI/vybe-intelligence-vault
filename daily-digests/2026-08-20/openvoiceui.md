## Summary
OpenVoiceUI is an open-source, voice-controlled AI platform that enables hands-free interaction with a live web canvas, allowing users to build and interact with web applications, dashboards, and music in real time through voice commands. It integrates with various LLMs, TTS, and STT providers via OpenClaw and supports plugin-based extensibility.

## Key Features
- Hands-free AI interaction with real-time web canvas rendering for dashboards, apps, and tools
- Integration with multiple LLM, TTS, and STT providers via OpenClaw gateway
- AI music generation with Suno and playlist management
- Plugin-based extensibility for custom faces, canvas pages, and workflows
- Long-term memory with context engine plugin and session persistence

## Why It Matters for RAG Builders
OpenVoiceUI provides a unique, hands-free interface for AI agents to dynamically generate and interact with live web applications, making it essential for builders seeking to create voice-first, interactive AI systems.
