## Summary
Autonomous GitHub issue-to-PR engine that autonomously reads issues, plans work, edits code, validates changes, and opens pull requests with durable workflow state and checkpointing for resumable operations.

## Key Features
- Durable state-machine workflow with checkpointing for interrupted run resumption
- Autonomous issue triage, analysis, and code editing with validation gates
- GitHub operations mediated via MCP server for operational separation
- Autonomous test generation and validation for edited code
- Structured PR review and documentation updates with auditability
