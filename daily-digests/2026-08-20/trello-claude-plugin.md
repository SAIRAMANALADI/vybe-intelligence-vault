## Summary
A Claude Code plugin that integrates Trello data into the AI context by fetching card, list, and board content as clean Markdown using only a Trello API key. It operates read-only with zero dependencies and no external server requirements.

## Key Features
- Fetch Trello card details (description, labels, due date, assignees, checklists, comments, attachments) as Markdown
- List all open cards in a Trello list or board
- Structured analysis of cards for AI context (type, summary, risks, next steps)
- Zero dependencies and no npm install required
- Read-only operations with local credential management

## Why It Matters for RAG Builders
This plugin enables seamless integration of Trello project management data into AI workflows, enhancing context for RAG systems by providing structured, up-to-date project information directly from Trello.
