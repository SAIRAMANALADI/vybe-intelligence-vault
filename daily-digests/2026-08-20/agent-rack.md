## Summary
agent-rack is an MCP server that bridges CLI AI coding agents (Claude Code, Codex, OpenCode, Antigravity) into any MCP-compatible client, enabling parallel sub-agent execution, structured code reviews, and seamless integration with tools like VS Code, Cursor, and Claude Desktop.

## Key Features
- Wraps CLI AI coding agents (Claude Code, Codex, OpenCode, Antigravity) as MCP tools for seamless integration with any MCP client
- Supports synchronous (`agent_run`) and asynchronous (`agent_session_*`) sub-agent execution with background session management
- Provides a structured, adversarial-capable code review tool (`agent_review`) that returns validated JSON instead of free text
- Enables parallel sub-agent execution with log streaming, follow-up input, and cancellation for long-running tasks
- Offers 9 packaged commands and 2 auto-activated guidance skills for popular MCP clients like Claude Code and Cursor

## Why It Matters for RAG Builders
It simplifies the integration of CLI AI coding agents into any MCP-compatible workflow, enabling parallel task execution, structured code reviews, and vendor diversity without requiring API key management or model calls.
