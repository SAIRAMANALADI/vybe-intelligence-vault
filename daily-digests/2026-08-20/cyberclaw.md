## Summary
CyberClaw is a transparent agent control system designed to manage digital tasks through smart agents while providing full visibility into agent actions. It emphasizes user control, safety, and reliability with features like dual-phase command checks and a dual-level memory system.

## Key Features
- Transparent logging of all agent actions for auditability and trust
- Dual-phase command approval (planning + user confirmation) for safety
- Dual-level memory system (short-term and long-term) for task consistency
- Heart-beat monitor for real-time task status tracking and stall detection
- Local data storage with user-controlled syncing for privacy
