## Summary
A methodology skill and deterministic harness for self-improving agents that iteratively enhance any skill, repository, or project within a sandboxed environment. It implements an un-gameable acceptance gate to ensure 'accepted' changes reflect real improvements, not self-deception, and closes six common cheating paths in open-ended domains.

## Key Features
- Un-gameable acceptance gate ensuring real improvements via heterogeneous judges and deterministic adjudication
- Six concrete anti-self-deception paths closed (e.g., immutable decision-code, anchor verification, judge collusion prevention)
- Methodology-agnostic signal sourcing: adapts evaluation to the target domain (programmatic, anchor-based, or generative)
- Sandboxed self-iteration loop with rollback and recovery capabilities
- Designed for open-ended domains lacking ground truth, bridging gaps in existing self-improving agent literature

## Why It Matters for RAG Builders
It provides a robust framework for building trustworthy self-improving agents in domains where ground truth is absent, ensuring improvements are verifiable and not self-deceptive.
