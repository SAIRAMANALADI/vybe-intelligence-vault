## Summary
mcpscore is a lighthouse tool for auditing MCP (Model Context Protocol) servers, providing scored, actionable reports on protocol conformance, tool quality, security, and readiness for the latest MCP spec. It helps developers identify and fix issues before deployment to ensure interoperability with AI agents.

## Key Features
- Automated MCP server auditing with deterministic scoring (0-100)
- Multi-transport support (STDIO, Streamable HTTP, SSE) with auto-detection
- 71 rules across protocol, tools quality, security & auth, and readiness categories
- Machine-readable JSON output for CI/CD integration and programmatic use
- Supports Python and Node.js MCP servers with typed interfaces

## Why It Matters for RAG Builders
It ensures MCP servers meet protocol standards before deployment, preventing silent failures in AI agents and guaranteeing interoperability with RAG and agent frameworks.
