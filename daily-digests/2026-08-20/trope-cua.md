## Summary
Trope CUA enables AI agents to interact with desktop applications on Windows and macOS in the background without disrupting the user's active session. It provides tools for inspecting windows, capturing screenshots and accessibility trees, and executing safe actions like clicks or keystrokes via MCP, a daemon, or CLI.

## Key Features
- Cross-platform desktop agent interaction (Windows and macOS)
- Background-safe actions with receipt validation for cursor, foreground, and safety checks
- MCP stdio server and daemon mode for persistent agent workflows
- Visual agent cursor overlay without hardware cursor interference
- Trajectory recording and replay for debugging and regression testing

## Why It Matters for RAG Builders
Trope CUA is essential for AI agents that need to safely interact with real desktop applications without disrupting user workflows, enabling seamless integration into RAG and agentic systems.
