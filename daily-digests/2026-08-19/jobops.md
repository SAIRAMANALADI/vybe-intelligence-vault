## Summary
jobops is a self-hosted Model Context Protocol (MCP) server that automates the full job-search workflow, including portal scanning, JD evaluation, resume/cover letter generation, outreach drafting, and negotiation briefs. It integrates with MCP-aware chat clients to execute mechanical tasks while keeping the chat client as the central brain.

## Key Features
- Full job-search loop automation via MCP-compatible chat clients (Claude Desktop, Cursor, etc.)
- Portal scanning (Greenhouse, Ashby, Lever, Workday, etc.) with Playwright scrapers
- JD evaluation with A-F scoring, archetype detection, and ATS-friendly resume/cover letter generation
- Non-destructive workflow with soft-delete, restore, and versioned career packet editing
- Integration with LLMs (Gemini, DeepSeek) for batch evaluation and materials generation

## Why It Matters for RAG Builders
It streamlines the entire job-search process by orchestrating tools and workflows through an MCP server, reducing manual effort and improving consistency for AI-driven career management.
