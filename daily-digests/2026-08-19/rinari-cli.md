## Summary
Rinari-CLI is a terminal-based AI assistant that connects to local or remote OpenAI-compatible LLM endpoints, offering an interactive chat REPL, autonomous coding agent, and a suite of built-in tools for tasks like Git operations, file editing, and web search. It emphasizes privacy by keeping all prompts local and supports MCP for dynamic tool integration.

## Key Features
- Interactive chat REPL with streaming and conversation history
- Autonomous coding agent capable of exploring, editing, testing, and committing code
- 10+ built-in tools including Git operations, file editing, code search, and web search
- Support for MCP servers to dynamically extend agent capabilities
- Privacy-focused with local-only prompt processing and configurable LLM endpoints

## Why It Matters for RAG Builders
Rinari-CLI provides a powerful, privacy-conscious agent framework for automating coding tasks and integrating local LLMs into terminal workflows, making it essential for developers building AI-driven development tools.
