## Summary
Irida is a local-first personal agent framework that provides a unified interface for interacting with multiple AI runtimes, including the Cursor SDK and Anthropic Claude Agent SDK. It offers a terminal UI, memory management, cron automation, and gateway integrations for Telegram and webhooks.

## Key Features
- Supports multiple AI runtimes (Cursor SDK, Anthropic Claude Agent SDK) via a unified interface
- Built-in terminal UI (Ink) with session management, slash commands, and file operations
- Memory system with full-text search, semantic search (pgvector), and encrypted storage
- Cron automation with topic delegation, digest generation, and prompt guards
- Gateway integrations for Telegram and webhooks with stable session management and pairing

## Why It Matters for RAG Builders
It provides a flexible, local-first framework for building and deploying AI agents with multi-engine support, memory management, and automation capabilities, reducing integration complexity for RAG builders.
