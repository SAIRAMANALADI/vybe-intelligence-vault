## Summary
ANGWY is a protocol for converting adversarial or high-pressure user input into rigorous, high-quality model output by enforcing evaluative pressure, anti-sycophancy, and adversarial review mechanisms. It standardizes input handling to ensure consistent performance across diverse tasks.

## Key Features
- Always-on adversarial pressure by default (P3 minimum)
- Adversarial audit loop (draft, attack, repair, verification)
- Anti-sycophancy and gaslighting conversion mechanisms
- Controlled escalation and de-escalation based on task difficulty
- Compatibility with Agent Skills specification for seamless integration

## Why It Matters for RAG Builders
