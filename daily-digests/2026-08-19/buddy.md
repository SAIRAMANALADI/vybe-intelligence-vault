## Summary
Buddy is a native desktop AI assistant that provides non-technical users with a persistent, learning memory assistant. It captures, organizes, and remembers conversations across sessions, acting as a second brain without requiring file management or complex configurations.

## Key Features
- Persistent memory across sessions with structured markdown files
- Provider-independent LLM integration (Anthropic, OpenAI, Google)
- Organic reminders via OS notifications for tasks and deadlines
- Git-backed local storage for transparency and data ownership
- Built-in consolidation and learning from user interactions

## Why It Matters for RAG Builders
Buddy provides a privacy-focused, persistent memory layer for AI assistants that can be integrated into RAG systems to enhance context retention and user-specific adaptation.
