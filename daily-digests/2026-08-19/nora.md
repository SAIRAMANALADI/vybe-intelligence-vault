## Summary
Nora is a self-hosted AI agent operations platform that enables users to deploy, monitor, and manage autonomous agent fleets (OpenClaw and Hermes) on their own infrastructure. It provides a unified control plane with lifecycle management, monitoring, and integrations for AI agent workflows.

## Key Features
- Unified control plane for deploying and managing OpenClaw and Hermes agent fleets on Docker or Kubernetes
- Live operator access with streaming logs, interactive terminals, and embedded dashboards for OpenClaw/Hermes
- Comprehensive monitoring, alerting, and budget management for agent operations
- 69+ integrations with LLM providers, vector DBs, and cloud services via MCP servers
- Multi-tenant workspaces with RBAC, secrets management, and automated backups

## Why It Matters for RAG Builders
Nora simplifies the deployment and management of AI agent fleets, reducing operational overhead and enabling scalable, self-hosted AI workflows for production environments.
