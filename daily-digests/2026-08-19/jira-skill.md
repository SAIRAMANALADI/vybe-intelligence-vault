## Summary
A Claude Code plugin providing Jira integration through two specialized skills: jira-communication for API operations and jira-syntax for Jira wiki markup syntax, templates, and validation. Designed for AI agents supporting the Agent Skills open standard.

## Key Features
- Zero MCP overhead with direct script execution via Bash
- Full API coverage for Jira Server/DC and Cloud
- Supports JSON output for programmatic processing
- Portable skills following the Agent Skills open standard
- Comprehensive CLI tools for issues, worklogs, sprints, and transitions

## Why It Matters for RAG Builders
This plugin enables AI agents to seamlessly interact with Jira for issue management, automation, and workflow execution, reducing manual overhead in development and project tracking.
