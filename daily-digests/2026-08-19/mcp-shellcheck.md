## Summary
An MCP server that integrates ShellCheck for shell script linting, enabling AI agents to analyze scripts for bugs, stylistic issues, and best practices. Provides structured, JSON-formatted results for seamless integration with AI coding assistants.

## Key Features
- File and inline shell script analysis via ShellCheck
- Support for multiple shells (bash, sh, dash, ksh, ash)
- Configurable checks, severity filtering, and warning exclusions
- Structured JSON output for easy parsing by AI agents
- Production-ready with async support, testing, and logging

## Why It Matters for RAG Builders
It enables AI agents to perform automated shell script analysis, improving code quality and reducing errors in AI-generated or AI-assisted shell scripts.
