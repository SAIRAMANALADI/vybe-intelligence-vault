## Summary
jobfindsme is an AI-powered job search tool that simultaneously queries BOSS直聘 and 猎聘 platforms to find matching job postings based on a user's resume. It provides deterministic, explainable matching with structured output and supports incremental radar for tracking new, updated, or closed positions.

## Key Features
- Simultaneous multi-platform job search (BOSS直聘 + 猎聘) via a single natural language command
- Deterministic resume-to-job matching with structured output and explainable signals
- Incremental radar for tracking new, updated, or closed job postings
- Local processing with privacy-preserving resume handling (PDF/MD parsing to structured facts)
- Integration with AI agents (Claude, Codex, Cursor) via MCP stdio protocol
