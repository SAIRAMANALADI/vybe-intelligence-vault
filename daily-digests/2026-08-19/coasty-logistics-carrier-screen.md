## Summary
An AI agent that automates the retrieval of motor carrier safety records from the federal SAFER register by driving a real browser, reading the page, and reporting results. It demonstrates agentic computer-use automation with zero dependencies and offline capability.

## Key Features
- Zero-dependency execution with pure Node.js built-ins
- Offline mock mode for $0 cost and no API keys
- Agent-driven browser automation with vision model input
- Structured safety and cost controls to prevent accidental spend
- Self-capturing demo generation from agent's own frames
