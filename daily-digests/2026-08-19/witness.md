## Summary
witness is a local memory and self-improvement engine for Claude Code and OpenCode that captures coding sessions to distill patterns, habits, and knowledge evolution over time. It serves as a person-centric growth archive with provenance, providing structured insights via an MCP server and plain files without injecting data into sessions.

## Key Features
- Captures and archives coding sessions verbatim (raw layer) with append-only storage
- Distills observations into evolving facets with bi-temporal change history for trend analysis
- Supports modular lenses for domain-specific insights (e.g., math, default global lens)
- Single pure-Go binary with no external dependencies or cloud services required
- Provides MCP server for structured data access and agent-friendly interactions

## Why It Matters for RAG Builders
It enables AI agents to understand and reflect a user's cognitive growth patterns, providing structured, person-centric memory that enhances personalized AI interactions and coaching.
