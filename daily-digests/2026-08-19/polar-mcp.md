## Summary
Polar MCP is a local-first Model Context Protocol (MCP) server that enables AI agents to access Polar wearable data, including training load, sleep metrics, Nightly Recharge, and HRV data, without exposing tokens or sensitive data to external servers.

## Key Features
- Local-first OAuth flow with tokens stored securely on the user's machine
- Comprehensive Polar AccessLink Dynamic API v4 integration for training, sleep, and physiological data
- Privacy-preserving modes (structured, summary, raw) with GPS redaction by default
- Pre-configured setup via Delx Wellness Hermes for one-command installation
- Rich toolset for daily/weekly summaries, training load analysis, and recovery tracking

## Why It Matters for RAG Builders
It enables AI agents to securely and locally access detailed Polar wearable data, empowering personalized training and recovery insights without compromising user privacy.
