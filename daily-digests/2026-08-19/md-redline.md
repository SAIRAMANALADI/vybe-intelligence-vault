## Summary
md-redline enables inline review comments for markdown specs, prompts, and design docs with AI agent integration. It allows users to highlight text, leave comments, and have AI agents read and address feedback directly, all stored as invisible HTML markers in the markdown file itself.

## Key Features
- Inline comment system with HTML markers embedded directly in markdown files
- Two-way AI agent review workflow via MCP server (agent requests reviews and leaves feedback)
- Anchored questions and threaded replies for structured agent-human interaction
- Multi-tab editing with session persistence and real-time reload
- Cross-platform support (macOS, Linux, Windows) with atomic file writes and conflict detection

## Why It Matters for RAG Builders
It streamlines the review process for AI agents and humans by enabling inline feedback in markdown files, reducing context switching and improving collaboration efficiency.
