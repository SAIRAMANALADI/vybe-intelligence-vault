## Summary
An autonomous business-intelligence agent that transforms Canadian public demographic and housing data into executive retail-banking strategy briefs. It aggregates live data from Statistics Canada, CMHC, and the Bank of Canada to generate structured, decision-ready insights for financial institutions, served via a hosted web generator, MCP tool server, or CLI.

## Key Features
- Pulls live data from authoritative Canadian sources (Statistics Canada, CMHC, Bank of Canada) without requiring backend infrastructure for core functionality
- Generates structured, decision-ready strategy briefs mapping demographic and cost-of-living data to specific banking product opportunities
- Offers three access tiers: hosted web generator, MCP tool server, and CLI for technical users
- Implements guardrails for low-confidence data, source traceability, and regulatory compliance disclaimers
- Supports scheduled email delivery and community gallery via Cloudflare Worker and Neon Postgres

## Why It Matters for RAG Builders
It demonstrates a production-ready autonomous agent pattern for transforming live public data into trusted, decision-ready insights, offering a transferable model for RAG systems that require real-time data synthesis and structured output generation.
