## Summary
FeatureBoard-MCP is a local, markdown-backed project management tool that integrates directly with Claude Desktop/Cowork as an MCP extension. It enables AI agents to plan, log, prioritize, and execute tickets in plain language while maintaining a live, interactive board artifact with analytics, testing, CRM, and media studio capabilities—all stored as plain markdown files.

## Key Features
- AI-native project board with live artifact rendering and analytics dashboard
- 195+ tools for board management, testing, CRM, media studio, and code review
- Markdown-backed ticket storage with atomic writes and zero migration requirements
- Agent-driven churn loop with work packet optimization and cost tracking
- Multi-model testing, sprint close-out reports, and timeline visualization

## Why It Matters for RAG Builders
It provides a local-first, agent-driven project management system that tightly integrates with AI workflows, reducing diff churn and improving focus while maintaining full data ownership.
