## Summary
HOOX is a high-performance, edge-native algorithmic trading framework built entirely on Cloudflare Workers. It enables ultra-low latency trading (median 22ms) by leveraging Cloudflare's global network, Service Bindings, and autonomous AI risk management across 330+ edge locations.

## Key Features
- Ultra-low latency trading with median 22ms signal-to-ack latency via Cloudflare's global edge network
- Autonomous AI risk manager with multi-provider LLM fallback and Vectorize RAG for trade history
- Zero-trust microservice mesh using Service Bindings and Durable Objects for internal communication
- Built-in idempotency, rate limiting, and guaranteed delivery via Cloudflare Queues
- Comprehensive CLI and TUI tooling for local development, deployment, and monitoring

## Why It Matters for RAG Builders
HOOX demonstrates how edge-native architectures can collapse latency and cost barriers for real-time AI-driven trading, offering a blueprint for high-performance, fault-tolerant AI systems.
