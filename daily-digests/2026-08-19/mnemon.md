## Summary
mnemon is a self-hosted Model Context Protocol (MCP) server that provides a unified memory vault for AI agents and clients like Claude Code, Cursor, and claude.ai. It combines hybrid BM25 and vector search for efficient memory retrieval while ensuring data remains under user control.

## Key Features
- Hybrid BM25 + vector search for memory retrieval with composite scoring
- Cross-device memory sharing via Fly.io and AWS S3 for remote vaults
- Standing tier for persistent context injection in AI sessions
- Automated memory lifecycle management (decay, archival, and rebuilding)
- Streamlit dashboard for visualization and interactive exploration of memory vaults

## Why It Matters for RAG Builders
mnemon provides a critical infrastructure layer for RAG systems by enabling persistent, cross-device memory management with hybrid search, ensuring context consistency and reducing hallucinations in AI agents.
