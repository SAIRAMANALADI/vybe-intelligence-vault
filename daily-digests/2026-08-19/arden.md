## Summary
Arden is a local-first personal AI agent that integrates conversations, memory, tools, and recurring tasks into a unified workspace. It combines a Python backend with an Electron desktop app to create a durable system for managing personal workflows and automations.

- Unified workspace for conversations, memory, and tools
