## Summary
A real-time financial web search API designed for financial agents, investment research systems, and data platforms. It enables retrieval of public web content such as financial reports, announcements, and regulatory disclosures with advanced filtering by domains, time ranges, market regions, and languages.

## Key Features
- Domain-specific web search with configurable domains (e.g., sec.gov, company websites)
- Time-range filtering (predefined or custom) for freshness control
- Multi-language and market-region support for localized results
- Standardized HTTP API with Bearer token authentication
- Pre-built client examples in Python and Postman collections
