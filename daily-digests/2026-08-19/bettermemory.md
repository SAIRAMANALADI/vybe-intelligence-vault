## Summary
bettermemory provides persistent, verifiable memory for AI coding agents like Claude Code, enabling cross-session recall of project-specific knowledge while actively managing memory staleness and trustworthiness. It stores memories as human-readable markdown files with automated staleness checks and usage attribution.

## Key Features
- Persistent cross-session memory for AI agents with staleness detection and verification
- Human-readable markdown storage with git sync and hand-editable files
- Automated trust scoring for memories based on file changes, commits, and age
- Usage attribution tracking to measure memory effectiveness and prevent silent context injection
- Built-in evaluation metrics and curation tools to manage memory rot

## Why It Matters for RAG Builders
It enables AI agents to retain and verify project-specific knowledge across sessions without bloating context, reducing redundant explanations and improving reliability in long-term interactions.
