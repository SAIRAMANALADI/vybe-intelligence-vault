## Summary
Corresync is a local-first Model Context Protocol (MCP) server and CLI tool that unifies email and calendar access across multiple providers (Outlook, Gmail, Microsoft 365, JMAP, IMAP/SMTP, CalDAV) into a single local interface for AI agents and users.

## Key Features
- Unified local MCP server and CLI for multiple email/calendar providers
- Provider-neutral architecture with explicit authentication flows
- Preview-then-commit safety model for consequential writes
- Cross-account search and agenda projections with provenance tracking
- Support for standards-based protocols (IMAP, CalDAV, JMAP) and provider APIs

## Why It Matters for RAG Builders
Corresync enables AI agents to securely and locally access unified email and calendar data across providers, reducing dependency on proprietary APIs and enhancing privacy for RAG applications.
