## Summary
OhMyAgent is a self-hosted AI agent gateway with a persistent memory system, designed to remember user context, respect boundaries via a policy engine, and optimize token usage. It runs across platforms including Termux, desktop, and server environments.

## Key Features
- Persistent, searchable memory system with vector similarity and full-text search for long-term context retention
- Built-in approval engine for tool execution with path-scoped file access and configurable visibility profiles
- Token-efficient design with layered context, progressive skill loading, and on-demand tool activation
- Multi-platform support including Termux (Android), desktop apps (Electron/Tauri), and remote gateways
- LLM-driven summarization, DreamCycle nightly maintenance, and entity graph expansion for enhanced recall

## Why It Matters for RAG Builders
OhMyAgent provides a robust framework for building AI agents with persistent memory and strict policy controls, essential for applications requiring long-term user context and secure tool execution.
