## Summary
freejarvis is a self-hosted command deck that serves as a voice-enabled interface for interacting with AI agents or models. It replaces subscription-based 'personal AI OS' tools by providing local voice input/output, tool execution, memory management, and scheduling without requiring accounts or per-minute fees.

## Key Features
- Voice-first interaction with local speech recognition and text-to-speech (browser-based or ElevenLabs)
- Integration with self-hosted Hermes Agent or standalone OpenAI-compatible models
- Built-in tools for file operations, scheduling, web reading, and memory management
- Real-time visual feedback via an interactive orb and state-based UI color changes
- Local-first architecture with no mandatory cloud dependencies or subscription fees

## Why It Matters for RAG Builders
It provides a privacy-focused, self-hosted alternative to cloud-based AI assistants with voice interaction and tool orchestration, reducing dependency on paid services while maintaining functionality.
