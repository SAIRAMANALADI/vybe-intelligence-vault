## Summary
An MCP server providing specialized knowledge and decision support for Coordinate Reference Systems (CRS) worldwide, including regional expertise packs, UTM fallback, and CRS recommendation capabilities. It focuses on knowledge provision and decision support rather than direct coordinate transformation.

## Key Features
- Comprehensive CRS search by EPSG code, name, region, or prefecture
- Regional expertise packs (Japan, US, UK) with extensible architecture
- CRS recommendation engine with multi-zone support for complex regions
- Offline operation via local database with no external API dependencies
- Internationalized tool definitions and parameter descriptions in English

## Why It Matters for RAG Builders
It provides critical geospatial knowledge and decision support for AI agents working with coordinate systems, enabling accurate CRS selection and transformation routing in RAG applications.
