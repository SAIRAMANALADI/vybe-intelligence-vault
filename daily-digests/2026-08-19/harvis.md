## Summary
HARVIS is a hackable, voice-controlled AI assistant for Windows that executes local and remote tasks via customizable skills. It supports multiple AI models (Claude, Groq, Ollama, OpenAI, Gemini) and integrates with system tools for automation, vision, and orchestration.

## Key Features
- 100% local wake word detection and speech recognition (Whisper) with acoustic fingerprinting for personalized wake words.
- Supports multiple AI models (Claude, Groq, Ollama, OpenAI, Gemini) with unified tool integration and hot-swapping mid-conversation.
- Extensible via Python skills (one-file additions) with built-in toolset for system automation, vision, SSH, and messaging.
- Real-time echo cancellation and privacy controls (mute, local audio processing, no cloud microphone).
- Built-in observability (turnos.jsonl) and debugging tools for tracking tool calls, durations, and failures.

## Why It Matters for RAG Builders
HARVIS provides a modular, local-first framework for building voice-controlled AI agents that can integrate with existing tools and models, making it ideal for RAG builders seeking hands-free automation and multi-modal task execution.
