## Summary
StandTerm is a local-first browser terminal enabling secure, persistent SSH, local shell, and UART sessions with agent-controlled access. It bridges human operators and AI agents through typed APIs, structured screen renders, and explicit authorization gates for safe automation workflows.

## Key Features
- Persistent browser terminal tabs attached to a live server process across page reloads
- Agent panel with explicit human-input leases and privacy modes for safe AI automation
- External Agent Mirror for loopback JSON control of terminals with bearer-token authentication
- Cross-platform support for WSL2, Windows, macOS, and Linux with platform-specific launchers
- Secure browser authorization with HTTPS and certificate management for non-loopback access

## Why It Matters for RAG Builders
StandTerm provides a secure, agent-ready terminal interface that enables human-in-the-loop automation for AI agents without requiring direct shell access or brittle screenshot polling.
