## Summary
A terminal-based AI programming assistant built in Rust that enables code writing, review, refactoring, and debugging directly in the command line. It compiles to a single binary with no external runtime dependencies and supports streaming conversations, tool integration, and multi-agent workflows.

## Key Features
- Streaming conversations with real-time AI responses and inference visualization
- Built-in tool execution (file I/O, Bash, web fetching) and MCP protocol support for extensibility
- SKILL system for reusable workflows and project-specific knowledge via SKILL.md files
- Planning mode for read-only analysis before execution to prevent unintended changes
- Sub-agent delegation for parallel task processing and session management with history

## Why It Matters for RAG Builders
It provides a lightweight, Rust-based terminal agent framework that integrates seamlessly into CLI workflows for AI-driven code assistance without external runtime dependencies.
