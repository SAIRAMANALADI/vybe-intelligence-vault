## Summary
A twelve-skill plugin designed for solo-maintainer workflows where humans direct AI agents across the full development lifecycle. It provides structured governance, project bootstrap, phase delivery, review orchestration, verification, and workflow evolution with explicit human approval gates.

## Key Features
- Twelve modular skills covering project bootstrap, product discovery, phase delivery, review orchestration, and verification
- Explicit human approval gates for all critical decisions (specs, merges, releases)
- Built-in evaluation harness for routing and execution tests (15 cases per skill)
- Cross-cutting skills for session economics, weaker model optimization, and workflow evolution
- GitHub governance and documentation migration for existing repositories

## Why It Matters for RAG Builders
It provides a structured, human-directed framework for AI agent workflows that ensures governance, verification, and iterative improvement, critical for scalable and trustworthy AI-driven development.
