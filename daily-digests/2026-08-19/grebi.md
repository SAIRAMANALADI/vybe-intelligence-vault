## Summary
GrEBI is an HPC pipeline that aggregates biomedical knowledge graphs from multiple sources using ontologies and LLM embeddings, enabling integrative queries across resources. It provides a development server and MCP endpoint for machine-accessible access to the integrated data.

## Key Features
- Aggregates and merges data from multiple biomedical resources into unified knowledge graphs
- Uses LLM embeddings and ontologies for semantic integration and entity resolution
- Provides a development server and MCP endpoint for programmatic access
- Includes automated E2E tests with snapshot validation for pipeline integrity
- Supports HPC-scale processing with Docker and Nextflow
