## Summary
awesome-mcp-security is a Windows application designed to evaluate the security of over 800 MCP servers by performing nine automated checks, including prompt injection, toxic flows, and compliance risks. It provides daily-updated security scores and detailed reports to help users assess server safety without requiring technical expertise.

## Key Features
- Nine automated security checks for MCP servers
- Daily-updated security scores and reports
- Simple Windows GUI for non-technical users
- Clear risk assessment with actionable insights
- Regular updates to improve test accuracy
