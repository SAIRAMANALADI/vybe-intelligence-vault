## Summary
Excel Vision MCP is an MCP (Model Context Protocol) server that enables AI agents to extract and process both text and embedded images from Excel files (.xlsx/.xlsm). It bridges the gap between text-only data extraction and multimodal AI capabilities by providing full content reading, including diagrams, charts, and screenshots embedded in spreadsheets.

## Key Features
- Extracts embedded images from Excel files with cell-position mapping for context
- Supports full content reading (text + images) in a single call via `read_full_content`
- Cross-platform compatibility (macOS, Linux, Windows) with local processing for privacy
- Smart pagination and performance optimizations for handling large spreadsheets efficiently
- Provides tools for text search, sheet listing, and workbook overview for structured data access

## Why It Matters for RAG Builders
It enables AI agents to fully understand and analyze Excel documents by processing both text and embedded visuals, which is critical for RAG systems handling real-world business documents.
