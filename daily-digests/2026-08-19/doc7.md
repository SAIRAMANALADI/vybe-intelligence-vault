## Summary
doc7 is a local Windows application that converts documents (PDFs, DOCX, etc.) into clean, structured Markdown using visual understanding and a vision language model, preserving headings, tables, images, and formatting for AI tools and note-taking apps.

## Key Features
- Converts PDFs, DOCX, and scanned documents to Markdown with visual layout understanding
- Preserves headings, tables, images, lists, and code blocks in the output
- Runs entirely locally with no data sent to external servers
- Uses a vision language model for accurate document structure reconstruction
- Simple GUI for drag-and-drop or file selection workflow
