## Summary
The dbt MCP Server is an MCP (Model Context Protocol) server that enables AI agents to interact with dbt projects, providing tools for SQL execution, semantic layer queries, project discovery, CLI commands, and administrative API access. It bridges dbt with AI workflows for enhanced data context and automation.

## Key Features
- Provides MCP-compliant tools for dbt project interaction, including SQL execution and generation
- Supports semantic layer queries for metrics, dimensions, and entities with filtering options
- Offers discovery tools for models, sources, exposures, and lineage with detailed metadata
- Includes dbt CLI integration for executing commands like build, run, test, and compile
- Features administrative API access for job management, project listing, and artifact retrieval

## Why It Matters for RAG Builders
This server is essential for AI agents needing deep integration with dbt projects to provide accurate context, execute queries, and automate data workflows within RAG systems.
