## Summary
SenClaw is a local-first framework for building and managing personal AI agents with a Rust-based daemon and a Flutter desktop app. It provides runtime machinery for LLMs, including permissions, memory, scheduling, multi-agent orchestration, and local model support, enabling fully offline AI systems.

## Key Features
- Local and cloud LLM support with native MLX/Candle inference for offline use
- Multi-agent orchestration with DAG team execution and tool permissions
- Hybrid memory system combining SQLite, vector search, and curated knowledge graphs
- Space Apps for installable mini-apps with MCP tool integration
- Cross-platform desktop and mobile apps with unified agent access

## Why It Matters for RAG Builders
SenClaw provides a robust, local-first runtime for building and deploying personal AI agents with advanced multi-agent orchestration and memory systems, reducing dependency on cloud services while ensuring privacy and control.
