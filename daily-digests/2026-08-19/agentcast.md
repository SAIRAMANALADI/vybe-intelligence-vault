## Summary
AgentCast is a Rust-based workspace for an MCP-first agent launcher, runtime, registry, and gateway designed to discover, normalize, and invoke MCP-compatible coding agents and tools. It provides a local gateway for managing MCP servers, actions, resources, and prompts with deterministic tool invocation.

## Key Features
- Discovers and normalizes MCP server tools into launcher actions
- Provides HTTP gateway and MCP stdio server for tool invocation
- Supports registry metadata search and MCP install plans
- Includes OAuth helper flows for protected routes
- Offers CLI and API surfaces for managing actions, resources, and prompts

## Why It Matters for RAG Builders
AgentCast simplifies the integration and management of MCP-compatible tools and agents, enabling RAG builders to streamline tool discovery, normalization, and invocation in a unified runtime.
