## Summary
A production-ready Model Context Protocol (MCP) server implementing a 5-layer temporal intelligence system for AI agents. It tracks causality, manages memory, predicts future needs, adapts prediction weights, and shapes context presentation through personality modes.

## Key Features
- 5-layer temporal intelligence system (Past, Present, Future, Adaptive, Personality)
- Causal chain tracking and dependency auto-detection
- Predictive pre-fetching with composite scoring (temporal, causal, frequency)
- Per-project meta-learning for adaptive prediction weights
- Personality modes (historian, prophet, archaeologist, minimalist, auditor) for context presentation
