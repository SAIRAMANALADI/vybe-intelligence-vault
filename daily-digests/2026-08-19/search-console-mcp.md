## Summary
A Model Context Protocol (MCP) server that unifies Google Search Console, Bing Webmaster Tools, and GA4 data into a single API for AI agents, eliminating manual CSV exports and enabling direct querying for SEO insights like cannibalization, anomalies, and opportunity scoring.

## Key Features
- Unified API for Google Search Console, Bing Webmaster Tools, and GA4 with 40+ tools
- Automated SEO math (cannibalization, anomalies, opportunity scoring) performed server-side
- Multi-account support with auto-resolution per site
- Secure credential storage (OS keychain or AES-256 encryption)
- CLI and MCP client integration for seamless AI agent access

## Why It Matters for RAG Builders
It streamlines SEO data access for AI agents by eliminating manual exports and enabling direct, context-aware queries for actionable insights.
