## Summary
NumGuard is an MCP server that provides a verification layer for numerical claims in agent economies, particularly for financial metrics like Sharpe ratios and backtest results. It offers tamper-evident signed receipts, deflated Sharpe ratio calculations, and on-chain verification tools to ensure trust in agent-generated numbers.

## Key Features
- Deflated Sharpe Ratio calculation for backtest validation
- Signed, portable receipts proving numerical claims were verified
- On-chain verification tools (e.g., verify_agent, audit_addresses)
- Prepaid credits and x402 pay-per-call for agent-driven payments
- Comprehensive integrity battery for backtests (leakage, autocorrelation, regime stability, etc.)

## Why It Matters for RAG Builders
NumGuard provides the critical trust layer for AI agents and systems that rely on numerical claims, ensuring verifiable integrity and accountability in agent-generated metrics and backtests.
