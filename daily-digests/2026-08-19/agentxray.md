## Summary
AgentXRay is a lightweight web-based dashboard for visualizing, analyzing, and optimizing AI agent sessions across multiple platforms like OpenClaw, Codex, Claude Code, Hermes, and OMP. It provides real-time insights into session logs, tool calls, prompts, and performance metrics.

## Key Features
- Unified interface for multiple AI agent platforms (OpenClaw, Codex, Claude Code, Hermes, OMP)
- Real-time session browser with filtering, search, and spawn tracking
- Prompt extraction and optimization with Claude-powered suggestions
- Interactive tool call inspection with performance metrics (model inference vs. tool execution time)
- Session insights dashboard with error clustering, retry detection, and trend analysis

## Why It Matters for RAG Builders
AgentXRay provides critical visibility into AI agent sessions, enabling developers to debug, optimize, and refine prompts and workflows for better RAG and agentic system performance.
