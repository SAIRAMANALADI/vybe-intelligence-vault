## Summary
ChatSpatial is an MCP server that enables natural language-driven spatial transcriptomics analysis by orchestrating 65 methods across 15 analytical categories through 20 schema-validated tools, ensuring reproducibility and cross-platform compatibility.

## Key Features
- Schema-enforced tool orchestration for 65 spatial transcriptomics methods
- Supports 10x Visium, Xenium, Slide-seq v2, MERFISH, and seqFISH data formats
- MCP-compatible for integration with Claude Code, Codex, and other clients
- Comprehensive documentation with installation, configuration, and troubleshooting guides
- Docker and Python package deployment options with versioned releases

## Why It Matters for RAG Builders
ChatSpatial standardizes and simplifies spatial transcriptomics workflows for AI-driven research, enabling reproducible and cross-platform analysis through natural language prompts.
