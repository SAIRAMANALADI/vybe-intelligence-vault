## Summary
Meme Swap is a local, privacy-focused AI face-swapping tool that enables users to replace faces in GIFs or videos entirely offline on macOS. It integrates FaceFusion with a Next.js web app, Electron desktop client, and MCP server for AI tool integration.

## Key Features
- 100% local processing with no cloud dependency or data uploads
- Supports multiple AI models for face swapping, enhancement, and expression restoration
- Provides web, desktop, and MCP server interfaces for flexible integration
- Integrates Giphy for seamless meme search and conversion
- Optimized for Apple Silicon with CoreML acceleration and ONNX Runtime

## Why It Matters for RAG Builders
It provides a privacy-preserving, offline-capable AI face-swapping pipeline that can be integrated into RAG systems as a tool for dynamic media manipulation.
