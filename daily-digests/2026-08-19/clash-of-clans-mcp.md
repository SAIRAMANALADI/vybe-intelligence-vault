## Summary
A Model Context Protocol (MCP) server that integrates with the official Clash of Clans API to provide AI-assisted clan analysis for war grading, elder promotion screening, and CWL carry-forward decisions. It exposes configurable tools for generating leadership-ready reports and automating clan management workflows.

## Key Features
- Exposes MCP tools for real-time clan data retrieval (war logs, member stats, CWL groups)
- Configurable rubric engine for automated war grading, elder promotion screening, and CWL carry-forward recommendations
- Snapshot functionality to store historical war data for trend analysis
- Markdown report generation for leadership-ready summaries (participation, rule compliance, performance leaderboards)
- Supports mid-war status reports for real-time war room insights

## Why It Matters for RAG Builders
