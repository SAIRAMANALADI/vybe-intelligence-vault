## Summary
A dual Rust and .NET implementation of an AI programming assistant core designed for multi-turn conversations, tool execution, and session management. It supports JSON-RPC daemon mode for integration with CLIs, editors, or future UIs, and includes offline and remote provider support.

## Key Features
- Dual Rust/.NET implementations for cross-language validation and performance optimization
- Multi-turn AI conversations with tool execution (file, search, process, shell) and streaming output
- Portable session storage in JSONL format with support for recovery, branching, and context compression
- JSON-RPC daemon mode for seamless integration with CLIs, editors, or future UIs
- Support for multiple AI providers (OpenAI, Groq, Mistral, MiniMax, Google, OpenRouter) with offline and remote provider discovery

## Why It Matters for RAG Builders
It provides a robust, dual-implementation framework for building AI agents with tool execution and session management, critical for RAG pipelines requiring multi-turn interactions and external tool integration.
