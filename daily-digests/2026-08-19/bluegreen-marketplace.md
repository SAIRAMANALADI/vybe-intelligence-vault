## Summary
bluegreen-marketplace is a plugin distribution registry for the hal AI-native company layer, enabling direct integration of CRM, project management, and building-inspection workflows into Claude Code via modular plugins. It serves as the public registry for Blue Green AI's Claude Code plugins.

## Key Features
- Modular plugin system for extending Claude Code with domain-specific skills
- Supports CRM, project management, and building inspection workflows
- Uses MCP for standardized agent communication and tool integration
- Self-contained plugin development under a unified repository structure
- OAuth-based authentication for secure access to external services
