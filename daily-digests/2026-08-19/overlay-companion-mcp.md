## Summary
Overlay Companion MCP enables AI assistants to interact with desktop environments by creating visual overlays, capturing screenshots, simulating mouse/keyboard actions, and managing clipboard operations. It acts as a bridge between AI tools (e.g., Cherry AI) and local or remote desktops via a modular MCP server and KasmVNC-based infrastructure.

## Key Features
- AI-driven desktop interaction via MCP server for real-time commands
- Visual overlay creation (shapes, text, highlights) for GUI testing and guidance
- Multi-monitor support with KasmVNC for seamless remote desktop access
- Clipboard synchronization bridge for cross-system data transfer
- Modular architecture with containerized deployment for easy setup

## Why It Matters for RAG Builders
It empowers AI systems to directly manipulate and observe desktop environments, enabling advanced automation, GUI testing, and human-in-the-loop workflows critical for RAG pipelines requiring real-world interaction.
