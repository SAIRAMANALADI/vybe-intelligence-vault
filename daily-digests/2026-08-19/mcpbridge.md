## Summary
MCP REST Bridge is a self-hosted gateway that converts REST, GraphQL, or MCP servers into secure, governed AI tools via the Model Context Protocol (MCP). It provides OpenAPI-to-MCP auto-discovery, RBAC, circuit breaking, and a real-time admin UI for managing tools and guardrails, all in a single binary without requiring Kubernetes.

## Key Features
- OpenAPI/GraphQL/REST auto-discovery to MCP tools with per-tool guardrails
- RBAC, SSRF protection, prompt-injection sanitization, and circuit breaking
- Real-time admin UI for managing servers, tools, and policies
- MCP-to-MCP gateway with Streamable HTTP/SSE support
- CLI for config-as-code and CI/CD integration

## Why It Matters for RAG Builders
MCP REST Bridge simplifies the integration of REST, GraphQL, and MCP services into secure, governed AI tools, eliminating the need for complex orchestration while providing enterprise-grade security and observability.
