## Summary
A high-performance microservice for localized vector matchmaking and semantic search, designed as a sidecar to the AcademicGateway-Backend. It handles embedding generation, vector storage, and real-time semantic queries using LanceDB and Nomic-Embed-Text, enabling efficient matchmaking for academic entities like students, professors, and projects.

## Key Features
- Real-time vector synchronization with zero-downtime bulk ingestion via Blue/Green deployment
- CQRS architecture for decoupled write (sync) and read (search) operations
- GPU-accelerated embedding generation with PyTorch and Nomic-Embed-Text
- Production-grade observability with structured logging, tracing, and metrics
- Idempotent deletions and VRAM-safe batch processing for large-scale data

## Why It Matters for RAG Builders
It provides a scalable, high-performance vector search backend essential for RAG systems requiring real-time semantic matchmaking and efficient embedding storage.
