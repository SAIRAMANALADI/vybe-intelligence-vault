## Summary
assisted-review is a CLI tool that transforms PR/MR reviews by breaking them into focused chunks, integrating AI commentary via Claude Code, and providing a dedicated browser UI for efficient review. It persists state locally and supports GitHub/GitLab with optional Jira integration.

## Key Features
- Chunk-based PR/MR review interface for focused analysis
- AI commentary integration via headless Claude Code
- Local state persistence for session resumption
- Support for GitHub, GitLab, and optional Jira integration
- Keyboard-driven navigation and comment drafting

## Why It Matters for RAG Builders
It streamlines PR/MR reviews by breaking them into manageable chunks with AI assistance, reducing cognitive load and improving review quality for AI stack builders.
