## Summary
Zara is a NixOS flake providing a CLI-based natural language interface and voice-to-text utility using Whisper. It supports wake-word mode and plans to integrate text-to-speech (TTS) in the future.

- Natural language command interface via CLI
- Voice-to-text input using Whisper (CPU/GPU support)
- Wake-word mode for hands-free activation
- NixOS flake for reproducible deployment
- Planned integration of text-to-speech (TTS)
