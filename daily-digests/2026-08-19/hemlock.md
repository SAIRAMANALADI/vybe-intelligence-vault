## Summary
Hemlock is a full-stack AI-powered penetration testing tool that integrates agent-driven autonomous testing with manual verification. It automates reconnaissance, testing, validation, and reporting for web applications while providing evidence chains and human-in-the-loop controls for accuracy.

## Key Features
- Autonomous AI-driven penetration testing with ReAct-based tool orchestration (43+ built-in tools)
- Full-stack integration including proxy, repeater, intruder, and vulnerability management
- Evidence chain closure with raw request/response pairs and three-state semantic validation
- Multi-agent collaboration (5 roles: reconnaissance, attack, verification, intelligence, reporting)
- Human-in-the-loop safety controls for sensitive operations (DoS, RCE, data deletion)

## Why It Matters for RAG Builders
Hemlock provides a critical bridge between AI automation and human oversight in security testing, enabling RAG builders to integrate robust, evidence-backed vulnerability detection into their workflows.
