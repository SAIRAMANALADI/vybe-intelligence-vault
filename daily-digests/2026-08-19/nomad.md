## Summary
Nomad is a real-time travel companion that dynamically adapts itineraries based on live data like weather, budget, and pace, using AI for narration while ensuring decisions are made by deterministic planners. It operates fully offline with fallback engines when API keys are missing.

## Key Features
- Dynamic itinerary rewriting based on live weather, budget, and pace constraints
- Deterministic planner with fallback engines for zero API key operation
- Proactive engine that scans and adjusts plans unprompted (e.g., weather, budget, closing times)
- Seamless offline-to-online transition with visible provider status tracking
- Modular architecture with FastAPI backend and Next.js frontend, supporting Supabase for storage
