## Summary
Elffuss Claw is a browser-based agentic operating system where the chat interface dynamically generates and renders applications as self-contained HTML. It runs entirely in the browser using WebGPU for local model inference, enabling zero-install, privacy-preserving AI workflows.

## Key Features
- Generates and renders applications on-demand as self-contained HTML within sandboxed iframes
- Runs local AI models entirely in the browser via WebGPU (e.g., Gemma-4 E2B, Qwen2.5-0.5B)
- Persistent memory, tasks, and encrypted vault (AES-256-GCM) with local-only data handling
- Supports opt-in external model integration (OpenAI, Anthropic, Ollama) while defaulting to local inference
- File System Access API integration for reading/writing files and automating folder-based workflows

## Why It Matters for RAG Builders
It demonstrates a fully client-side agentic framework that eliminates backend dependencies while enabling dynamic, privacy-preserving AI-driven application generation.
