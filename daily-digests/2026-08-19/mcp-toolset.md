## Summary
A collection of cross-platform Model Context Protocol (MCP) servers written in .NET that enable local-first, structured interactions with tools like Git operations, file management, text search, and text editing. Each server is a self-contained console app designed for privacy and security, running entirely on the user's machine.

## Key Features
- Cross-platform .NET 10 servers with self-contained executables
- Local-only execution with no external network calls
- Structured, typed JSON responses for AI assistants
- Security-focused design with root confinement and denylists
- Modular servers for Git ops, file vault, text search, and text editing

## Why It Matters for RAG Builders
It provides essential, secure, and structured local tooling for AI assistants to interact with files, Git, and text without cloud dependencies or privacy risks.
