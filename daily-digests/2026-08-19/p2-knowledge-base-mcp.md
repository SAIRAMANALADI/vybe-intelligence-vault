## Summary
P2 Knowledge Base MCP is an MCP server that connects AI assistants like Claude, Codex, and Cursor to a comprehensive Propeller 2 (P2) microcontroller knowledge base, including PASM2 instructions, Spin2 methods, hardware architecture, and OBEX community code objects.

## Key Features
- Provides AI assistants with real-time access to Propeller 2 documentation and community code
- Supports cross-platform deployment (macOS, Windows, Linux, Raspberry Pi)
- Integrates with PNut-TS and PNut-Term-TS for full compile-download-test workflows
- Offers headless mode for CI/CD and autonomous AI-driven hardware testing
- Caches knowledge base content locally for low-latency queries

## Why It Matters for RAG Builders
It enables AI assistants to autonomously generate, compile, and debug Propeller 2 code by providing instant access to hardware-specific knowledge, reducing development time and errors for embedded systems.
