## Summary
hollr is a CLI tool that monitors agent-based coding workflows and alerts users via voice, desktop notifications, sounds, or webhooks when an agent finishes or requires input, eliminating the need for constant terminal supervision.

## Key Features
- Multi-agent support (Claude Code, Codex, Copilot CLI, Gemini CLI, Cursor, opencode, Antigravity, Amp)
- Local-first with zero telemetry; only webhooks send metadata off-device
- Interactive setup with byte-reversible configuration changes
- Read-aloud, desktop notifications, sounds, and phone/webhook alerts for agent events
- Project-specific toggles and quiet hours for flexible control

## Why It Matters for RAG Builders
It enhances developer productivity by eliminating the need to babysit CLI coding agents, ensuring timely intervention only when necessary.
