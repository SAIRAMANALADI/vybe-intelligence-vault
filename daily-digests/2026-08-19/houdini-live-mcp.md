## Summary
A tool that enables Claude Desktop to interactively inspect and query an open Houdini session, including reading VEX code, geometry, simulation state, and viewport screenshots, without manual copy-pasting. It provides two MCP servers for local Houdini integration.

## Key Features
- Enables Claude Desktop to directly query an open Houdini session for nodes, VEX code, geometry, and simulation state
- Provides two MCP servers: one for Houdini documentation and another for live scene inspection
- Supports viewport screenshots and dynamic scene analysis without manual copy-pasting
- Local-only execution with automatic token-based authentication for security
- Automated setup via PowerShell script for Windows, with manual steps for Mac/Linux

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and Houdini workflows, enabling seamless, interactive debugging and analysis of Houdini scenes without manual intervention.
