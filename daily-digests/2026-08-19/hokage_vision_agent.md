## Summary
Hokage Vision Agent is an agentic computer vision workbench designed for anime character detection using YOLO and PySide6. It provides a modular platform for dataset validation, annotation, training, model evaluation, and GUI/CLI/API interfaces, with a focus on safe data governance and reproducible workflows.

## Key Features
- Modular agentic workflows for detection, training, and evaluation with allowlisted tools
- Docker-first development and deployment with CI/CD pipelines for testing and packaging
- PySide6 desktop GUI, FastAPI service, and CLI for unified interaction
- Synthetic dataset validation, annotation assistance, and training dry-runs for reproducibility
- Rule-based agent with optional LLM extension points and strict data governance
