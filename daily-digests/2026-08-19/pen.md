## Summary
Pen is a headless, extension-first rich text editor engine designed for AI collaboration, offering a schema-driven document model and modular architecture for building customizable editing experiences.

## Key Features
- Headless runtime with explicit extension composition for flexible integration
- Schema-driven document model with canonical mutation paths via `editor.apply()`
- Support for AI-driven features like inline autocomplete, suggest mode, and tool integration
- Multi-renderer architecture (React, Vue, DOM) decoupled from core runtime
- Built-in collaboration primitives via Yjs and transport layers (SSE, direct)

## Why It Matters for RAG Builders
Pen provides a flexible, headless foundation for building AI-powered rich text editors with modular extensions, enabling seamless integration of AI features like suggestions, automation, and collaboration.
