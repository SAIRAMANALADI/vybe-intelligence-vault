## Summary
MergePilot is a local-first AI-powered desktop assistant that integrates with Azure DevOps to provide pull request reviews, repository context analysis, and delivery workflow automation directly from a developer's local environment without requiring source code to be hosted in a third-party service.

## Key Features
- Local-first runtime with optional Azure-backed persistence for data storage
- Pull request review with file, thread, pipeline, and policy evidence analysis
- Approval-gated workflow actions for mutating Git and delivery operations
- Project Link feature to map local repositories to Azure DevOps contexts
- Desktop app with a local daemon for seamless integration and performance

## Why It Matters for RAG Builders
MergePilot enables AI-driven pull request reviews and repository context analysis while maintaining local-first control over source code, making it ideal for teams prioritizing data privacy and developer autonomy.
