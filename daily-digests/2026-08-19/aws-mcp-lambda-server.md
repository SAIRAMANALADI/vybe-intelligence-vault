## Summary
This repository implements a Model Context Protocol (MCP) server designed to run on AWS Lambda, enabling seamless integration with MCP clients like Claude Desktop. It provides a serverless architecture for MCP tooling and API interactions.

## Key Features
- Deploys MCP servers on AWS Lambda for serverless execution
- Supports OAuth 2.0 authentication via AWS Cognito
- Provides extensible MCP tools (e.g., weather forecast tool)
- Includes a Hono.js-based RESTful API for MCP interactions
- Offers GitHub Actions CI/CD pipeline for automated testing and deployment

## Why It Matters for RAG Builders
It enables AI agents and clients like Claude Desktop to interact with serverless MCP tools and APIs on AWS, simplifying the deployment and scalability of AI-driven workflows.
