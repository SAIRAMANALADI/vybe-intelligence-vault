## Summary
mcp-diffbot is a Model Context Protocol (MCP) server that enables AI agents to interact with Diffbot's Knowledge Graph for company enrichment and web content extraction. It serves as a gateway to access Diffbot's data via Pipeworx's MCP infrastructure.

## Key Features
- Provides MCP-compliant interface for Diffbot's Knowledge Graph and web extraction APIs
- Integrates with Pipeworx gateway for access to 1209+ live data sources
- Supports plain English queries via ask_pipeworx for simplified agent interactions
- Enables AI agents to enrich company data and extract web content programmatically
- Part of a broader MCP ecosystem for seamless AI tool integration

## Why It Matters for RAG Builders
