## Summary
trajecktory is a local, AI-driven job-search pipeline with a web dashboard that automates scanning, evaluating, tailoring, and tracking job applications. It integrates with Claude Code and other AI tools to optimize resumes, cover letters, and outreach while providing analytics and follow-up management.

## Key Features
- AI-powered job posting evaluation with structured scoring (A-F) across 10 dimensions
- Automated resume and cover letter customization per role using docx templates
- Local web dashboard for pipeline tracking, analytics, and follow-up management
- Integration with Claude Code and other AI tools for agentic workflows
- Pre-configured portals for 45+ companies and 19 job boards with liveness checks

## Why It Matters for RAG Builders
