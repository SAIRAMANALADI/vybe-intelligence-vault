## Summary
olcli is a command-line interface for Overleaf that enables bidirectional sync, local editing, and compilation of LaTeX projects directly from the terminal. It supports self-hosted instances, integrates with Git, and offers an MCP server for AI agent automation.

## Key Features
- Bidirectional sync with Overleaf projects, preserving folder structure and handling deletions
- Native Git remote support for seamless version control integration
- MCP server for AI assistants (Claude, Cursor, Windsurf) with 14 tools for project management
- Smart ignore patterns for LaTeX build artifacts and OS noise, extendable via `.olignore`
- Library API for programmatic access to Overleaf projects and TypeScript support

## Why It Matters for RAG Builders
It streamlines LaTeX project management by enabling local editing, version control, and AI-driven automation, reducing dependency on Overleaf's web interface for developers and researchers.
