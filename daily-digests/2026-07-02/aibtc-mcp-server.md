## Summary
A Bitcoin-native Model Context Protocol (MCP) server enabling AI agents to interact with Bitcoin and Stacks ecosystems, including wallet management, DeFi operations, NFT handling, and x402 payments. Designed for seamless integration with MCP-compatible clients like Claude Code and VS Code.

## Key Features
- 150+ tools for Bitcoin L1 and Stacks L2 operations, including wallet management, DeFi trading, NFT handling, and sBTC peg
- Secure wallet storage with AES-256-GCM encryption and local file permissions
- Integration with MCP-compatible clients (Claude Code, VS Code, Cursor, etc.) for AI agent orchestration
- OpenRouter bridge for direct model interaction without adopting a framework
- Comprehensive Bitcoin and Stacks support including UTXO management, fee estimation, and transaction broadcasting
