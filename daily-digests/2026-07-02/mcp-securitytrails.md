## Summary
mcp-securitytrails is a Model Context Protocol (MCP) server that wraps the SecurityTrails API, enabling AI agents to query domain and subdomain data programmatically. It is part of the Pipeworx ecosystem, which provides a unified gateway to over 1200+ live data sources for AI applications.

## Key Features
- Wraps SecurityTrails API for domain and subdomain intelligence
- Integrates seamlessly with MCP-compatible clients (Claude, Cursor, etc.)
- Part of Pipeworx gateway for unified access to 1200+ data sources
- Supports plain English queries via ask_pipeworx for simplified usage
- Enables AI agents to enrich datasets with domain/subdomain information

## Why It Matters for RAG Builders
