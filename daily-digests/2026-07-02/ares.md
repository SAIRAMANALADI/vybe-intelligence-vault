## Summary
ARES is an open-source embodied AI operating system designed to deploy a persistent, autonomous intelligence that orchestrates local AI stacks, automates workflows, and interacts via a native AI avatar. It integrates multiple backends, supports persistent memory, and offers both a web UI and a native macOS application.

## Key Features
- Persistent entity with memory and drives across sessions
- Hybrid backend support (Hermes, JROS, or Hybrid mode)
- Built-in persona system with 14+ characters and JROS integration
- Native macOS app with voice, animated avatar, and hot-reload
- Multi-model routing with cloud-first and local fallback options
