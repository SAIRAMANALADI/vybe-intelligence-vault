## Summary
A static, SEO-first directory that indexes and ranks public Model Context Protocol (MCP) servers from GitHub, automatically updated weekly. It provides a searchable, crawlable interface for discovering MCP servers by stars, recency, and language.

## Key Features
- Automated weekly scraping of GitHub for MCP servers using GitHub Search API
- Static site generation with Astro for fast, SEO-friendly pages
- Ranking and categorization of servers by stars, recency, and language
- Featured listings with optional monetization via one-time fees
- Cloudflare Workers deployment for low-cost, scalable hosting

## Why It Matters for RAG Builders
It provides a centralized, up-to-date catalog of MCP servers, simplifying discovery and integration for AI engineers building RAG systems.
