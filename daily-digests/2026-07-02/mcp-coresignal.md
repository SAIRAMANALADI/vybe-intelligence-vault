## Summary
mcp-coresignal is a Model Context Protocol (MCP) server providing access to LinkedIn-adjacent company and employee data from Coresignal. It integrates with Pipeworx's MCP gateway to enable AI agents to query structured professional data via standardized tools.

## Key Features
- Provides structured company and employee data via MCP tools
- Integrates with Pipeworx's gateway for access to 1209+ data sources
- Supports plain English queries through ask_pipeworx for simplified interaction
- Compatible with MCP clients like Claude Desktop, Cursor, and Windsurf
- MIT licensed for open-source use

## Why It Matters for RAG Builders
It enables AI agents to enrich RAG pipelines with high-quality professional data from Coresignal via a standardized MCP interface.
