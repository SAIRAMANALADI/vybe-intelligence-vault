## Summary
Agent Guidance MCP is an MCP (Model Context Protocol) server that provides AI agents with structured guidance, coding standards, skills, and project context tools via Stdio transport. It enables agents to access task pipelines, guidance operations, and project context for bounded code editing workflows.

## Key Features
- Provides structured task pipelines for AI agents to follow coding standards and workflows
- Offers guidance operations for querying standards, skills, and project context
- Includes project context tools for file tree exploration, search, and snapshot export
- Supports UI/UX operations for domain-specific agent interactions
- Designed for integration with MCP-compatible clients like Claude, Cursor, and Cline

## Why It Matters for RAG Builders
It standardizes agent workflows by providing structured guidance and project context, enabling more reliable and consistent AI-driven code editing and development.
