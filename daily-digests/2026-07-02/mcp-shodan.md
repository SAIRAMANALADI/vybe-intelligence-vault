## Summary
mcp-shodan is a Model Context Protocol (MCP) server that wraps the Shodan REST API, enabling AI agents to query internet-connected device data, vulnerabilities, and services programmatically. It is part of the Pipeworx ecosystem, which provides a unified gateway to over 1209 data sources for AI applications.

## Key Features
- Wraps the full Shodan REST API for AI agent access
- Integrates with Pipeworx gateway for 1209+ data sources
- Supports plain English queries via ask_pipeworx
- Compatible with MCP clients like Claude Desktop and Cursor
- Enables programmatic access to internet-connected device data

## Why It Matters for RAG Builders
It provides AI agents with direct access to Shodan's vast dataset of internet-connected devices and vulnerabilities, enhancing RAG systems with real-world cybersecurity insights.
