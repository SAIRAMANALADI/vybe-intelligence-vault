## Summary
A production-grade OpenAI-compatible API gateway that routes requests through Cursor's Agent SDK, enabling self-hosted access to Cursor's models and features via a web dashboard, CLI, or direct API integration.

## Key Features
- OpenAI-compatible API server for seamless integration with existing clients (LangChain, LiteLLM, Continue.dev, etc.)
- Built-in web dashboard for setup, monitoring, and configuration with live activity tracking and session management
- Command-line interface (CLI) for scripting, automation, and headless deployment
- Supports streaming, multi-turn conversations, tool/function calling, and real-time model switching
- Cross-platform support (Windows, Linux, macOS) with verified compatibility and automated testing

## Why It Matters for RAG Builders
It enables AI engineers to self-host and integrate Cursor's advanced agent capabilities into their RAG pipelines without relying on Cursor's cloud API, providing greater control and customization.
