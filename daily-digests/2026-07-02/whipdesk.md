## Summary
WhipDesk enables remote control of a developer's desktop from any mobile browser, allowing users to view the screen, interact with AI coding agents, and receive job completion notifications without installing additional apps or granting kernel extensions.

## Key Features
- Live screen streaming via WebRTC (H.264) or WebSocket (JPEG) with resolution-independent input handling
- Full desktop control including mouse, touch, and keyboard input for interacting with AI agents or CLIs
- Job completion notifications via webhooks or file watchers with optional push notifications to mobile devices
- Peer-to-peer encrypted communication (DTLS) with optional cloud relay for remote access, ensuring data never flows through third-party servers
- Cross-platform support (macOS, Windows, Linux) with prebuilt binaries and npm packages for easy installation

## Why It Matters for RAG Builders
WhipDesk empowers AI engineering teams to remotely monitor and control their development environments, enabling seamless interaction with AI coding agents from any mobile device without compromising privacy or requiring additional software installations.
