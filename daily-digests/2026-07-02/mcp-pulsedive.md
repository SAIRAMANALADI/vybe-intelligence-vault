## Summary
mcp-pulsedive is a Model Context Protocol (MCP) server that provides threat intelligence Indicator of Compromise (IOC) enrichment by integrating with Pulsedive.com. It enables AI agents to query live threat intelligence data through a standardized MCP interface.

## Key Features
- Provides real-time IOC enrichment via Pulsedive.com
- Integrates seamlessly with MCP-compatible AI agents (Claude, Cursor, etc.)
- Supports plain English queries through ask_pipeworx for simplified usage
- Part of a larger gateway offering 1209+ live data sources
- MIT licensed for open-source adoption
