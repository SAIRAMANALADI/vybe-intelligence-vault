## Summary
SocialLoop MCP Server enables AI assistants to create, manage, and publish events, tickets, guest lists, discounts, and affiliate programs directly via the Model Context Protocol (MCP). It provides hosted endpoints for seamless integration with AI tools like Claude, ChatGPT, and Cursor without requiring API keys or user accounts upfront.

## Key Features
- Hosted MCP server with OAuth and open endpoints for AI assistant integration
- End-to-end event creation, ticketing, guest management, and affiliate programs
- Supports RSVP, paid tickets, tiered pricing, and pay-what-you-want models
- Automated discount code generation and affiliate payouts via Stripe
- Real-time analytics and production management tools (budget, vendors, run-of-show)

## Why It Matters for RAG Builders
It enables AI agents to autonomously manage events and ticketing, bridging the gap between AI assistants and real-world operational tasks for event organizers.
