## Summary
rizz is a local-first Project Intelligence Engine that scans a repository to generate a project-scoped relational brain, enabling evidence-backed insights, explanations, and reviews via a local HTML portal (Mission Control). It prioritizes local data storage and interoperability for AI agents and tools.

## Key Features
- Generates a local project brain with structured relational data (entities, flows, graph) for interoperability with AI agents
- Opt-in model-backed chat and TUI for interactive exploration and setup
- Evidence-backed explanations and reviews of code changes using git diffs
- Mission Control portal for visualizing project architecture and risks
- Supports multiple model routes (OpenRouter, Codex, OpenAI/Anthropic placeholders)

## Why It Matters for RAG Builders
rizz provides a local, project-scoped brain that enables AI agents to understand and interact with codebases using stable, evidence-backed relational data without relying on cloud scraping or proprietary APIs.
