## Summary
claude-atelier is a zero-dependency enforcement framework for Claude Code that provides runtime rules, hooks, named agents, persistent memory, and review gates to enforce coding standards, token efficiency, and security. It replaces prose-based rules with system-level rails for disciplined AI-assisted development.

## Key Features
- 16 enforcement hooks blocking destructive actions (e.g., unsigned commits, missing tests)
- 22 named agents (e.g., Steve for iOS, Gaëlle for Go) and 21 skills for domain-specific tasks
- Dynamic vault (Peter) for persistent project memory with graph-based context retrieval
- Review gates (/review-oracle) with 4 parallel agents for automated code review and security checks
- Token routing and compression to reduce costs by up to 90% via model selection and context management
