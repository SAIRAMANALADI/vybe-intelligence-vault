## Summary
mcp-eodhd is an MCP (Model Context Protocol) server that wraps EOD Historical Data (eodhd.com), providing AI agents and applications with access to financial market data. It is part of the Pipeworx ecosystem, which connects AI agents to over 1200 live data sources.

## Key Features
- Wraps EOD Historical Data for AI agent access
- Integrates with MCP clients like Claude Desktop, Cursor, and Windsurf
- Supports plain English queries via ask_pipeworx
- Part of a larger gateway with 1209+ data sources
- MIT licensed for open-source use

## Why It Matters for RAG Builders
It enables AI agents to seamlessly access and query financial market data from EODHD, expanding their capabilities for RAG applications.
