## Summary
FleetQ is an open-source, self-hosted platform for orchestrating autonomous multi-agent AI systems with a visual DAG builder, human-in-the-loop approvals, and MCP server integration. It supports a wide range of LLMs and provides production-grade features like audit trails, budget controls, and real-time monitoring.

## Key Features
- Visual DAG-based workflow builder with 8 node types for complex agent orchestration
- 675+ MCP tools across 45 domains for programmatic LLM-driven control
- Human-in-the-loop approvals and policy-governed autonomy with audit trails
- Multi-agent crews with coordinator/worker roles and weighted QA scoring
- Budget controls with credit ledger, pessimistic locking, and auto-pause on overspend

## Why It Matters for RAG Builders
FleetQ provides a production-ready platform for orchestrating autonomous multi-agent AI systems, enabling scalable, governed, and observable workflows essential for enterprise RAG and AI automation deployments.
