## Summary
BrainRegion is an AI collaboration infrastructure designed to facilitate review, consultation, planning, and memory tasks for software projects. It provides a modular MCP server and CLI for multi-model review processes, external expert consultation, and structured task planning with deterministic region-based routing.

## Key Features
- Modular MCP server and CLI for AI-driven review and planning tasks
- Multi-model review pipeline with role-specific reviewers (e.g., planner, safety, architecture)
- External consultation tools for expert model advice on complex problems
- Deterministic region-based routing for context scheduling (e.g., `route_regions`)
- Knowledge base integration for project-specific context and historical cases

## Why It Matters for RAG Builders
