## Summary
Local Coding Agent transforms a local machine into an MCP-compatible coding workspace for AI agents, enabling file editing, command execution, Git operations, and live health monitoring via a dashboard. It integrates with AI tools like Claude Code, OpenAI Codex, and Cursor for secure local development.

## Key Features
- MCP-compatible server for AI agents to interact with local files, commands, and Git repositories
- Live dashboard with health metrics, tool calls, and approval workflows
- Safety policies (safe/balanced/full) with approval-based command execution
- Cross-platform support (Windows, macOS, Linux) with CLI and optional GUI tray app
- Network diagnostics and tunnel integration for secure remote access

## Why It Matters for RAG Builders
It provides a secure, local MCP-compatible workspace for AI agents to safely edit code, run commands, and interact with Git, bridging the gap between cloud-based AI tools and local development environments.
