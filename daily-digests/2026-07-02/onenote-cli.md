## Summary
A command-line interface (CLI) tool that integrates OneNote with terminal workflows and AI agents, enabling seamless browsing, reading, editing, and exporting of OneNote content as markdown or HTML. It supports full-text search, local caching, and AI-native features like RAG over notebooks.

## Key Features
- Full-text search across OneNote notebooks, sections, and pages with context snippets
- Export OneNote content to Markdown or HTML with embedded media and metadata
- AI-native features like RAG over notebooks and LLM summarization (planned)
- Path-based addressing for notebooks, sections, and pages for easy CLI navigation
- Local caching for offline access and large library support

## Why It Matters for RAG Builders
It bridges the gap between OneNote and AI workflows by enabling structured, searchable, and exportable access to notebooks via CLI and AI agents, making it essential for users who rely on OneNote for knowledge management.
