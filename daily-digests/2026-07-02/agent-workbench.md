## Summary
agent-workbench is a local-first terminal-based agent TUI workbench for disciplined software development, providing an interactive coding-agent experience with a local HTTP/SSE server, typed SDK, permission-gated runtime, and thin terminal UI client. It emphasizes safety, structured workflows, and modular architecture for AI-driven development tasks.

## Key Features
- Local HTTP/SSE server for agent coordination and streaming responses
- Permission-gated runtime with allow/ask/deny policies for secure operations
- Typed SDK for client-server communication and resource management
- SQLite-based storage with Drizzle ORM for session and ledger persistence
- Pre-run planner and token health monitoring for risk mitigation

## Why It Matters for RAG Builders
