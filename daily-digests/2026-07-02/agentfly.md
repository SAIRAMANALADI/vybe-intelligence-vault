## Summary
AgentFly is a unified configuration center for managing multiple AI agents, enabling one-click setup and testing of AI models across different providers with automatic endpoint detection and performance benchmarking.

## Key Features
- Unified configuration management for multiple AI agents and providers
- Automatic endpoint detection and performance testing (latency, TTFT, throughput)
- Support for custom and built-in providers (DeepSeek, Anthropic, OpenAI)
- One-click command-line interface for launching and testing agents
- Environment variable integration for secure API key management

## Why It Matters for RAG Builders
AgentFly simplifies the setup and benchmarking of AI agents across providers, reducing integration overhead for RAG builders.
