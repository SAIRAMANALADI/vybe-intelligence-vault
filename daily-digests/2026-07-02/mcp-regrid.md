## Summary
mcp-regrid is a Model Context Protocol (MCP) server that wraps the Regrid Parcel API v2, enabling AI agents to access and query parcel data from Regrid.com. It is part of the Pipeworx ecosystem, which provides a gateway to over 1209 live data sources for AI applications.

## Key Features
- Wraps Regrid Parcel API v2 for AI agent access
- Integrates with Pipeworx gateway for 1209+ data sources
- Supports plain English queries via ask_pipeworx
- Compatible with MCP clients like Claude Desktop and Cursor
- Provides structured tool-based and natural language interfaces

## Why It Matters for RAG Builders
It enables AI agents to seamlessly access and query parcel data from Regrid, expanding the data sources available for RAG applications.
