## Summary
mcp-quiver provides an MCP (Model Context Protocol) server for accessing Quiver Quantitative's alternative data on public companies via Pipeworx's gateway. It enables AI agents to query financial and market data programmatically or through natural language interfaces.

## Key Features
- Provides MCP-compliant access to Quiver Quantitative's alternative financial data
- Supports direct tool calls or natural language queries via ask_pipeworx
- Integrates with Pipeworx gateway for unified access to 1209+ data sources
- Designed for seamless integration with AI agents (Claude, Cursor, Windsurf, etc.)
- MIT licensed for open-source adoption
