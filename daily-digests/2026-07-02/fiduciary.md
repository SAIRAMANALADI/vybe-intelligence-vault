## Summary
Fiduciary is a local-first personal finance advisor that connects to bank accounts via Plaid, stores data in SQLite, and uses an LLM agent to provide tailored financial advice grounded in real user data. All data remains on the user's machine with no cloud storage or telemetry.

## Key Features
- Local data storage with SQLite for privacy and control
- Integration with Plaid for real-time bank account syncing
- Customizable LLM-based financial advisor with tailored advice
- Comprehensive privacy and threat model documentation
- Modular skill-based architecture for extensibility

## Why It Matters for RAG Builders
It provides a privacy-preserving, locally-hosted alternative to cloud-based financial advisors, enabling secure and personalized financial guidance using real user data.
