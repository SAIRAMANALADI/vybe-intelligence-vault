## Summary
endgame-ai is a local autonomous desktop agent that observes the screen, controls the computer, reasons, acts, verifies, reflects, and self-modifies to achieve user-defined goals. It operates as a 'living organism' with self-evolution capabilities, committing improvements to its own codebase via Git.

## Key Features
- End-to-end task automation with multi-step planning and execution
- Real-time desktop observation and interaction via UIA/Win32
- Self-modification and Git-based evolution for continuous improvement
- Fresh screen rule for reliable state observation and verification
- Macro-step planning with dynamic granularity for efficient task completion
