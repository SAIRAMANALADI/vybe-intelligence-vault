## Summary
hevy-mcp is an MCP (Model Context Protocol) server implementation that enables AI assistants to interact with the Hevy fitness tracking API. It provides tools for managing workouts, routines, exercise templates, and webhook subscriptions, requiring a Hevy PRO subscription for full functionality.

## Key Features
- Full MCP server implementation for Hevy API with stdio transport
- Type-safe API client generated via Kubb from OpenAPI spec
- In-memory caching for exercise templates to reduce API latency
- Built-in Sentry monitoring for observability and error tracking
- Supports webhook subscriptions for real-time workout event notifications

## Why It Matters for RAG Builders
hevy-mcp enables AI assistants to directly interact with fitness data, making it essential for AI-powered personal training or workout planning applications.
