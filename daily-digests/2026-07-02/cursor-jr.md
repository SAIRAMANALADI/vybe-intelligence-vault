## Summary
CursorJr is a Russian-language subagent mentor for Cursor IDE, designed to help non-technical users (entrepreneurs, marketers, designers, content creators) understand and effectively use Cursor's features like Ask, Plan, Agent, Rules, Skills, MCP, and Canvas without technical jargon.

## Key Features
- Provides human-readable explanations of Cursor's modes (Ask, Plan, Agent, Debug) and tools (Rules, Skills, MCP, Canvas)
- Offers a 7-day learning path for beginners with structured playbooks and wizards
- Includes a maintainer subagent for knowledge base updates and health checks
- Automates repetitive tasks and guides users on when to use rules, skills, MCP, or full automations
- Supports slash commands for quick access to mentoring and maintenance tasks
