## Summary
An MCP server that enables persistent, cross-session memory and knowledge graph capabilities (GraphRAG) for AI agents using Neo4j as the backend. It provides structured memory storage, entity-relationship modeling, and advanced graph analytics for long-term contextual understanding.

## Key Features
- Persistent cross-session memory with semantic similarity search
- Typed entity and relationship modeling with confidence scoring
- Automated contradiction detection and graph pruning
- Document provenance tracking and community detection
- Exponential confidence decay and session-level diffs for recency

## Why It Matters for RAG Builders
It provides essential long-term memory and structured knowledge representation for AI agents, enabling persistent context and GraphRAG capabilities critical for advanced RAG systems.
