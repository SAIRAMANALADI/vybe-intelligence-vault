## Summary
4D-BioMem is a biologically inspired long-term memory system for AI agents that simulates human-like memory decay and retention. It manages agent memories across four dimensions (time, task features, risk rules, and semantic vectors) with synaptic pruning to naturally forget low-value information while permanently retaining critical data.

## Key Features
- Four-dimensional memory management (T, F, R, V) for dynamic retention and decay of memories
- Synaptic pruning mechanism with mathematical weight decay formula for natural forgetting
- Dual-pathway memory retrieval (subconscious hard matching vs. conscious semantic search)
- Risk-aware memory locking to permanently retain critical information (e.g., allergies, passwords)
- Integration with Hermes Agent for seamless cross-session memory management
