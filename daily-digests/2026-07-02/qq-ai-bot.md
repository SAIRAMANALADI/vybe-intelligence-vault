## Summary
A production-grade QQ AI bot that bridges QQ (via OneBot 11) with local AI agents using the ACP protocol. It handles session management, progress streaming, and supports integration with NapCat or LLOneBot for seamless AI interactions.

## Key Features
- OneBot 11 forward/reverse WebSocket support for QQ integration
- ACP-based agent communication with session persistence and progress streaming
- Compatibility with NapCat and LLOneBot for QQ access
- Group and private chat session isolation with customizable system prompts
- Built-in Docker demo stack for quick validation of the QQ ↔ AI pipeline

## Why It Matters for RAG Builders
It simplifies the integration of QQ with AI agents by providing a robust bridge layer for session management and progress streaming, reducing setup complexity for RAG builders.
