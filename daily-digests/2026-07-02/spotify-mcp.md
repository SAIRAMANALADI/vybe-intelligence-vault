## Summary
spotify-mcp is an MCP (Model Context Protocol) server that enables AI assistants like Claude to control Spotify playback via natural language commands. It bridges AI workflows with Spotify's Web API, allowing seamless music interaction through voice or text.

## Key Features
- Natural language playback control (e.g., 'play something like early Bill Evans')
- Compact tool-based interface with 11 focused tools for playback, search, and library management
- PKCE-based OAuth flow for secure Spotify authentication without client secrets
- Seamless integration with AI clients like Claude Desktop, Claude Code, and Cursor
- Error handling that provides actionable instructions for troubleshooting
