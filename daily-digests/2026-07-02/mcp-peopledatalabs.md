## Summary
This repository provides a Model Context Protocol (MCP) server wrapper for the People Data Labs (PDL) person and company enrichment API, enabling AI agents to access real-time business and contact data through a standardized interface.

## Key Features
- Wraps People Data Labs enrichment API for AI agent access
- Supports both direct MCP client integration and plain-English querying via ask_pipeworx
- Part of a larger gateway (Pipeworx) providing access to 1209+ data sources
- Enables real-time person and company data enrichment
- MIT licensed for open-source use

## Why It Matters for RAG Builders
It simplifies integration of People Data Labs' rich business and contact data into AI agents and RAG pipelines through a standardized MCP interface.
