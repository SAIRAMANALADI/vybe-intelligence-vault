## Summary
Versus Incident is a self-hosted AI-driven Site Reliability Engineering (SRE) agent that autonomously detects and escalates unexpected system issues by learning normal log patterns and routing anomalies to chat channels and on-call platforms.

## Key Features
- AI SRE Agent that learns normal log patterns and auto-detects anomalies without predefined alert rules
- Multi-channel incident notifications (Slack, Teams, Telegram, Email, etc.)
- Webhook integration for existing monitoring tools (Grafana, Sentry, CloudWatch, etc.)
- Customizable templating and on-call integrations (PagerDuty, Opsgenie, ServiceNow)
- Admin dashboard for configuration, pattern learning, and incident history

## Why It Matters for RAG Builders
It automates incident detection and response by learning normal system behavior, reducing manual alert rule maintenance and improving SRE efficiency for AI-driven systems.
