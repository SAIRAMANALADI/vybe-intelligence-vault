## Summary
mcp-findymail is a Model Context Protocol (MCP) server for Findymail, a B2B email finder and reverse-email lookup service. It enables AI agents to query email data and contact information through a standardized MCP interface, integrating with the Pipeworx gateway for broader data source access.

## Key Features
- Provides B2B email finding and reverse-email lookup capabilities via MCP
- Integrates with Pipeworx gateway for access to 1209+ live data sources
- Supports plain English queries through ask_pipeworx for simplified agent interactions
- Designed for seamless integration with AI agents (Claude Desktop, Cursor, Windsurf, etc.)
- MIT licensed for open-source adoption

## Why It Matters for RAG Builders
It enables AI agents to programmatically discover and verify B2B contact information, enhancing RAG pipelines with accurate and up-to-date email data.
