## Summary
Tableau MCP is an official Tableau-supported suite of developer primitives (tools, resources, and prompts) designed to simplify the integration of Tableau data and analytics into AI applications. It provides MCP-compatible clients with secure, OAuth-authenticated access to Tableau Cloud or self-hosted Tableau Server instances.

## Key Features
- OAuth 2.1 authentication for secure access to Tableau Cloud or Server
- MCP-compatible server for seamless integration with AI clients (Slack, Claude, ChatGPT, etc.)
- Pre-built tools for querying data, exploring content, and managing workbooks/datasources
- Hosted service option for quick setup or self-hosted deployment for enterprise control
- Comprehensive documentation and client integration guides
