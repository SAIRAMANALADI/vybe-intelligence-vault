## Summary
mcp-serpapi is a Model Context Protocol (MCP) server that wraps SerpApi's search engine APIs, enabling AI agents to query web search results via a standardized interface. It is part of the Pipeworx gateway, which provides access to 1209+ live data sources for AI applications.

## Key Features
- Wraps SerpApi search engines for AI agent integration
- Part of Pipeworx gateway with access to 1209+ data sources
- Supports plain English queries via ask_pipeworx
- Compatible with MCP clients like Claude Desktop, Cursor, and Windsurf
- MIT licensed for open-source use

## Why It Matters for RAG Builders
It simplifies integrating real-time web search capabilities into RAG systems by providing a standardized MCP interface for SerpApi.
