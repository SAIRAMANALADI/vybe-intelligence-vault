## Summary
A Go-based toolkit for parsing, validating, filtering, and querying Open Source Vulnerability (OSV) schema data, offering a CLI, Go SDK, and 6 AI agent skills for seamless integration into RAG and AI workflows.

## Key Features
- Go SDK for parsing and validating OSV JSON/YAML vulnerability data with generics support
- Pre-built CLI for quick vulnerability analysis and filtering (Linux/macOS/Windows)
- 6 AI agent skills for auto-triggered vulnerability parsing, validation, and querying in Claude Code
- Supports 19 ecosystems (npm, PyPI, Maven, Go, etc.) with ecosystem-specific filtering
- Structured output for CVSS scores, version ranges, Maven GAV, and event timelines
