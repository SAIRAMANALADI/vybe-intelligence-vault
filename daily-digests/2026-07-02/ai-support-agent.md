## Summary
A production-grade prototype support agent for a fictional enterprise hardware and cloud company, demonstrating a full RAG stack with deterministic business rules, mock CRM/ticketing integrations, streaming chat UI, and an observability dashboard.

## Key Features
- Hybrid document chunking for precision retrieval (sub-document granularity)
- Deterministic rules engine with 6 configurable rules (ESCALATE, ROUTE, ANSWER)
- Mock Salesforce/Zendesk integrations for CRM and ticketing workflows
- Real-time streaming chat UI with session trace logging and debug dashboard
- In-memory vector search using cosine similarity for efficient retrieval
