## Summary
A Tauri-based desktop application and local viewer for automatically archiving Weibo group chat messages with AI-powered daily summaries and agentic Q&A. Supports multi-group sync, incremental updates, and structured JSON exports.

## Key Features
- Automated Weibo group chat message archiving with incremental updates and multi-group support
- Native Tauri desktop app with QR-code login (no manual cookie handling) and local web-based viewer
- AI-powered daily summaries and agentic Q&A for querying archived conversations
- Structured JSON exports with media proxying, search, and contextual message threading
- Cross-platform support (macOS, Linux, WSL) with scheduled sync and cookie auto-renewal

## Why It Matters for RAG Builders
Provides a robust, automated pipeline for archiving and querying Weibo group chat data, enabling RAG systems to leverage historical conversations with AI-enhanced retrieval and summarization.
