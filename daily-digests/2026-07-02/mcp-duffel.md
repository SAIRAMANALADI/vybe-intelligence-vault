## Summary
mcp-duffel is a Model Context Protocol (MCP) server that enables AI agents to interact with the Duffel Flights API for live flight search and pricing. It is part of the Pipeworx gateway, which connects AI agents to over 1,200 live data sources.

## Key Features
- Provides live flight search and pricing via the Duffel Flights API
- Integrates seamlessly with MCP clients like Claude Desktop, Cursor, and Windsurf
- Part of the Pipeworx gateway for unified access to 1,209+ data sources
- Supports plain English queries via ask_pipeworx for simplified agent interactions
- Open-source and MIT licensed for easy adoption

## Why It Matters for RAG Builders
It enables AI agents to dynamically fetch real-time flight data, enhancing RAG systems with accurate and up-to-date travel information.
