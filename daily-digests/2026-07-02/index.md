## Summary
Index is a tool for mapping large codebases and documentation into verifiable, offline HTML maps that help developers and AI agents understand system architecture. It generates dependency graphs, verified wikis, and two-layer atlases from real code evidence without runtime dependencies.

## Key Features
- Generates verifiable, offline HTML maps from code and documentation
- Derives dependency graphs from real evidence (imports, manifests, file:line references)
- Supports single-repo wikis and multi-repo workspace atlases
- Includes verification mode to detect drift or tampering
- Zero runtime dependencies and fully deterministic output

## Why It Matters for RAG Builders
Index provides a reliable, evidence-based way to map and verify codebases, ensuring AI agents and developers can understand system architecture without relying on undocumented knowledge or fragile memory.
