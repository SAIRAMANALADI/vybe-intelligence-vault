## Summary
MyAgens is a self-hosted, personal AI fleet manager that runs on your local machine, enabling interaction via Telegram or a private web dashboard. It coordinates autonomous Claude Code agents for tasks like file operations, code execution, and service monitoring, with strict security controls and offline capabilities.

## Key Features
- Hierarchical agent system with Atlas as the coordinator and specialized Leads for domains
- Strict security controls including approval gates for risky actions and AES-256 encrypted vault
- Dual interfaces: Telegram bot and private web dashboard for real-time monitoring and interaction
- Proactive monitoring with heartbeat alerts and autonomous task delegation
- Offline-first design with no telemetry or cloud dependency

## Why It Matters for RAG Builders
It provides a secure, self-hosted framework for deploying and managing autonomous AI agents locally, reducing reliance on cloud services while maintaining high operational flexibility.
