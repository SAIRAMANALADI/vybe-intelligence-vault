## Summary
A Model Context Protocol (MCP) server that enables AI assistants to inspect, control, and automate Firefox browsers via WebDriver BiDi and Selenium WebDriver. It provides tools for page navigation, DOM interaction, network monitoring, and privileged operations like script execution and extension management.

## Key Features
- Automates Firefox via WebDriver BiDi for AI assistant integration
- Supports page navigation, DOM interaction, and network monitoring
- Enables privileged operations like script execution and extension management
- Works with MCP clients like Claude Code, Cursor, and Cline
- Supports both local Firefox and Firefox for Android automation

## Why It Matters for RAG Builders
It bridges AI assistants with browser automation, enabling RAG systems to interact with live web content, perform debugging, and extract structured data from dynamic pages.
