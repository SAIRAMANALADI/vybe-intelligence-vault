## Summary
mcp-walkscore is a Model Context Protocol (MCP) server that wraps the Walk Score API, enabling AI agents to query walkability data for locations. It is part of the Pipeworx ecosystem, which provides access to 1209+ live data sources via a unified gateway.

## Key Features
- Wraps the Walk Score API for walkability data retrieval
- Integrates with MCP clients like Claude Desktop, Cursor, and Windsurf
- Part of Pipeworx's unified gateway for 1209+ data sources
- Supports plain English queries via ask_pipeworx
- MIT licensed for open-source use

## Why It Matters for RAG Builders
It provides AI agents with real-time walkability data, enhancing location-based decision-making and contextual understanding in RAG systems.
