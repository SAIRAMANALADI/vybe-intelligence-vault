## Summary
mcp-easypost is a Model Context Protocol (MCP) server that provides AI agents with access to EasyPost's multi-carrier shipping rates and package tracking capabilities. It acts as a gateway to integrate shipping data into AI workflows seamlessly.

## Key Features
- Provides real-time multi-carrier shipping rates via EasyPost API
- Enables package tracking through MCP-compatible AI agents
- Integrates with Pipeworx gateway for access to 1209+ data sources
- Supports plain English queries via ask_pipeworx for simplified usage
- Designed for seamless integration with MCP clients like Claude Desktop and Cursor
