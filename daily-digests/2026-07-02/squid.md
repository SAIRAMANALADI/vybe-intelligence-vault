## Summary
Squid is a Claude Code plugin that automates software development by transforming feature specifications into reviewed pull requests through a multi-agent pipeline. It streamlines coding workflows by handling planning, implementation, testing, review, and CI validation with minimal human intervention.

## Key Features
- End-to-end feature implementation pipeline with 5 specialized agents (PA, SWE, Tester, PR Reviewer, On-Call)
- Interactive project scaffolding via `/squid-scaffold` for Python, TypeScript, Go, and infrastructure stacks
- Automated task planning, implementation, testing, and PR review with human approval gates
- Integration with `caveman` for output compression and conventional commits
- Supports per-project installation and local plugin development for testing

## Why It Matters for RAG Builders
Squid streamlines AI-driven software development by automating multi-agent collaboration, reducing human oversight to just two approval gates while ensuring code quality through specialized agents.
