## Summary
Gherkio is a declarative integration testing platform that enables writing API integration tests in YAML instead of imperative code. It compiles to a single static Go binary with zero external dependencies, making it ideal for CI/CD pipelines, Docker, and air-gapped environments.

## Key Features
- Declarative YAML DSL for writing integration tests without imperative boilerplate
- Zero runtime dependencies with a single static Go binary for portability
- Rich assertion engine with 30+ built-in matchers and JWT auto-decoding
- Native MCP server for AI assistant integration (Cursor, Claude, Cline, etc.)
- Outbound network sandboxing, SSRF prevention, and sensitive field masking

## Why It Matters for RAG Builders
Gherkio simplifies API integration testing by enabling declarative, maintainable YAML-based workflows that integrate seamlessly with CI/CD and AI tools, reducing boilerplate and improving test readability.
