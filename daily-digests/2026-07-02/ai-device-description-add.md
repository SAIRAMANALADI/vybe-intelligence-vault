## Summary
A lightweight open standard enabling IoT devices to self-describe to AI systems via a JSON document at a well-known endpoint, embedding safety, constraints, and ethical rules directly into the device's metadata for secure and autonomous AI interaction.

## Key Features
- Self-describing IoT devices with embedded safety and ethical constraints
- Minimal implementation requiring only a single HTTP endpoint and JSON document
- Protocol-agnostic design compatible with any existing device interface
- Three-tier autonomy system for risk-matched deployment
- Open standard with CC BY 4.0 license, no cloud dependency

## Why It Matters for RAG Builders
ADD enables AI systems to safely and autonomously interact with IoT devices by embedding critical context, constraints, and ethical rules directly into the device's self-description, reducing integration effort and mitigating risks in AI-driven automation.
