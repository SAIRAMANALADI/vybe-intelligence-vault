## Summary
A plugin for Obsidian that integrates Claude Code to maintain and organize vaults, offering a real-time code editor with syntax highlighting, diagnostics, and git integration. It enables AI-driven vault management while preserving link structures and providing granular control over AI edits.

## Key Features
- Integrates Claude Code CLI for AI-driven vault maintenance with approval-gated edits
- Real-time code editor with syntax highlighting for 50+ languages and diagnostics for 48 languages
- Git integration with branch status, blame, and history graph for change tracking
- One-click launch of Claude Code terminal directly from Obsidian
- Language server support for advanced features like autocomplete, hover docs, and go-to-definition

## Why It Matters for RAG Builders
It bridges AI-powered automation with Obsidian's knowledge management, enabling RAG builders to leverage structured vaults and AI-driven maintenance for dynamic, scalable knowledge bases.
