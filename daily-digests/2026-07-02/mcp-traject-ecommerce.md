## Summary
A Model Context Protocol (MCP) server providing ecommerce data integration for Amazon (via Rainforest API) and Walmart (via BlueCart API) as part of the Pipeworx gateway. Enables AI agents to query real-time ecommerce data through a standardized MCP interface.

## Key Features
- Provides MCP-compliant interface for Amazon and Walmart ecommerce data
- Supports real-time product and pricing data retrieval
- Integrates with Pipeworx gateway for unified access to 1209+ data sources
- Enables plain English queries via ask_pipeworx for simplified agent interactions
- Offers both direct MCP server and gateway-based access models

## Why It Matters for RAG Builders
It simplifies access to critical ecommerce data for AI agents, enabling real-time market analysis and decision-making without complex API integrations.
