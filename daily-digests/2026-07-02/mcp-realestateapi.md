## Summary
mcp-realestateapi is a Model Context Protocol (MCP) server that provides real estate data access, including property search, detailed property information, and skip-tracing capabilities via the RealEstateAPI.com service. It integrates with Pipeworx's MCP gateway to connect AI agents to live real estate data sources.

## Key Features
- Provides property search, detail, and skip-trace functionality via RealEstateAPI.com
- Integrates seamlessly with AI agents through the MCP protocol
- Accessible via Pipeworx's gateway for broader data source connectivity
- Supports plain English queries through the ask_pipeworx interface
- MIT licensed for open-source use

## Why It Matters for RAG Builders
