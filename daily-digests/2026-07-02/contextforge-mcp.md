## Summary
ContextForge MCP is an open-source Model Context Protocol (MCP) server that provides persistent, searchable memory for AI coding assistants like Claude, Cursor, and GitHub Copilot. It enables long-term project knowledge retention, semantic search, and team collaboration via a cloud-based backend.

## Key Features
- Persistent memory across AI coding sessions and tools via MCP
- Semantic search for knowledge retrieval by meaning, not keywords
- Git integration for automatic syncing of commits and PRs
- Team collaboration with shared projects and real-time sync
- Task tracking with issue management and project status

## Why It Matters for RAG Builders
It enables AI engineering teams to maintain long-term, searchable project memory across multiple AI tools, reducing context loss and improving productivity in RAG and agent-based workflows.
