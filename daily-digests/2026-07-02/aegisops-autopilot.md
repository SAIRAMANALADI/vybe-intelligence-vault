## Summary
AegisOps Autopilot is a production-incident autopilot system designed to transform ambiguous alerts into traced remediation workflows. It integrates memory recall, multi-agent diagnosis, tool-backed evidence gathering, risk scoring, and human approval gates to automate incident response.

## Key Features
- Converts ambiguous alerts into structured remediation workflows
- Supports both live Qwen Cloud mode and offline demo mode for deterministic testing
- Integrates memory recall, multi-agent diagnosis, and tool-backed evidence gathering
- Includes human approval gates and patch/runbook generation for post-incident learning
- Provides judge-verifiable tool surface via OpenAPI spec and MCP stdio server
