## Summary
AegisOps Autopilot is a production-incident autopilot system designed to transform ambiguous alerts into traced remediation workflows. It leverages memory recall, multi-agent diagnosis, tool-backed evidence gathering, risk scoring, and human approval gates to automate incident response, with both live Qwen Cloud and offline demo modes for flexibility.

## Key Features
- Converts ambiguous alerts into structured remediation workflows with traced steps
- Supports both live Qwen Cloud integration and offline deterministic demo modes
- Integrates memory recall, tool-backed evidence gathering, and risk scoring
- Includes human approval gates and patch/runbook generation for post-incident learning
- Provides judge-verifiable tool surfaces, OpenAPI specs, and MCP stdio server for orchestration
