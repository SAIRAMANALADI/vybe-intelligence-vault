## Summary
HADARA is a portable agentic development workbench designed to keep long-running AI-assisted software workflows inspectable, resumable, and evidence-backed. It binds non-deterministic LLM agent work into structured, production-oriented workflows using features like Task Capsules, Session Continuity, and Evidence Logs.

## Key Features
- Task Capsules for scoped, resumable, and evidenced work units
- Evidence Logs for recording validation proof without exposing raw logs
- Handoff Protocols to preserve state for subsequent operators or agents
- Structured CLI with lifecycle commands and diagnostics for machine-readable workflows
- Document Governance for classifying and managing project documentation states
