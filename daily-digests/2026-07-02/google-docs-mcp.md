## Summary
A Model Context Protocol (MCP) server that enables persistent Google Workspace automation, including Google Docs, Sheets, Slides, and Drive operations. It specializes in creating and managing native Google Docs tabs, retrofitting existing documents, and installing per-user automation workflows that run on Google's infrastructure.

## Key Features
- Creates and manages native Google Docs tabs programmatically via the Google Docs API
- Retrofits existing .docx or Google Docs into tabbed format while preserving complex elements like tables, drawings, and equations
- Installs per-user Workspace automation runtimes for scheduled, reactive, or menu-triggered workflows
- Provides 134+ tools for Google Docs, Sheets, Slides, and Drive operations, including find/replace, document conversion, and trash management
- Self-documenting MCP server with connect-time instructions, structured guides, and CI test status verification
