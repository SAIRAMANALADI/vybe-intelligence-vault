## Summary
NetLogo MCP is the first MCP (Model Context Protocol) server for NetLogo, enabling AI assistants to create, run, and analyze agent-based models through natural language conversation. It bridges NetLogo simulations with AI workflows, allowing users to define models, run experiments, and export results without manual coding or GUI interaction.

## Key Features
- Enables AI assistants to create and run NetLogo models via natural language prompts
- Supports 25+ tools for model creation, simulation, data collection, and export
- Integrates with CoMSES Net for accessing peer-reviewed agent-based models
- Offers headless mode for CI/CD and GUI mode for live visualization
- Provides BehaviorSpace support for parallel parameter sweeps and experiments

## Why It Matters for RAG Builders
