## Summary
vwf is an opinionated workflow plugin for Claude Code that transforms vague feature requests into shipped, reviewed code through three disciplined phases: Blueprint (define the product), Plan (diff and scope changes), and Execute (implement under TDD with code and security reviews). It enforces structured, test-driven development with high-touch oversight and optional autonomy via autopilot mode.

## Key Features
- Three-phase workflow (Blueprint, Plan, Execute) for structured development
- Enforces test-driven development (TDD) and coverage gates
- Integrates automated code and security reviews with subagents
- Supports both high-touch interactive and autonomous autopilot modes
- Maintains version-controlled blueprint and plan documents for traceability

## Why It Matters for RAG Builders
It provides a rigorous, structured approach to AI-driven code generation that ensures quality, security, and maintainability through enforced TDD and review gates, making it essential for production-grade RAG and AI stack builders.
