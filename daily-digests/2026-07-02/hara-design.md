## Summary
hara-design enables terminal-driven design generation and prototyping by converting natural language briefs into interactive HTML assets using 150 brand-grade design systems. It integrates with hara CLI, Claude Code, and Codex to provide live previews and self-contained deliverables for landing pages, dashboards, and app prototypes.

## Key Features
- Generates self-contained interactive HTML from natural language briefs
- Supports 150 brand-grade design systems for high-quality outputs
- Live-reload preview server for real-time iteration
- Handoff feature to export design tokens and components for downstream agents
- Integrates with hara CLI, Claude Code, and Codex for seamless workflows

## Why It Matters for RAG Builders
