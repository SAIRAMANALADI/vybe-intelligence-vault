## Summary
Infinity Context provides a reusable, source-grounded memory infrastructure for AI coding agents, enabling reliable context management through Postgres as the canonical truth, Qdrant for vector search, and Graphiti for graph-based memory. It supports review-gated learning, thread-scoped memory, and MCP/SDK integrations.

## Key Features
- Postgres as canonical truth with derived Qdrant/Graphiti indexes
- Review-gated memory suggestions with approval/rejection workflows
- Thread-scoped memory isolation and cleanup
- MCP and SDK integrations for agent compatibility
- Local visual browser for memory inspection and management
