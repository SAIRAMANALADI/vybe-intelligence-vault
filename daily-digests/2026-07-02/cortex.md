## Summary
Cortex is an open-source AI backend control plane that unifies model routing, agent tools, OpenAI-compatible APIs, and private workspaces into a single programmable runtime. It enables teams to build AI applications without locking into a single provider or brittle prompt chains.

## Key Features
- Unified API for multiple AI providers (OpenAI, Azure, Gemini, Claude, etc.) with OpenAI-compatible endpoints
- Dynamic model routing with latency sampling, health checks, and group-based aliases
- Entity-agent harness with tool discovery, streaming progress, and memory-aware context
- Private containerized workspaces for isolated agent execution with Docker and Azure support
- Extensible pathway system for adding custom capabilities with minimal boilerplate

## Why It Matters for RAG Builders
Cortex provides a stable, production-ready backend layer that decouples AI applications from provider-specific SDKs, enabling multi-model routing, agentic tool loops, and private workspaces while maintaining operational flexibility.
