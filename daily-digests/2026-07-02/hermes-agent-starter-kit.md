## Summary
A self-hosted starter kit for building domain-specific autonomous assistants on top of Hermes Agent. It provides a practical operating pattern for transforming a chatbot into a supervised agent system with memory, skills, schedules, and safety mechanisms.

## Key Features
- Supervised autonomy with human approval gates for risky actions
- Stateful memory and workflow tracking across sessions
- Structured skill system for autonomy, drafting, and reporting
- Safe write policies for low-risk state transitions
- Privacy scanning and synthetic data for public demos
