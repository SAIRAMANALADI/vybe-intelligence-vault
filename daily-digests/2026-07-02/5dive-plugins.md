## Summary
A plugin marketplace providing Telegram bot integrations for various AI agent CLIs, enabling users to interact with agents via Telegram messages. The repository includes forks of Anthropic's official plugin for Claude Code and MCP-based extensions for OpenAI Codex, xAI Grok, Google Antigravity, and opencode.

## Key Features
- Telegram bot integration for multiple AI agent CLIs (Claude Code, OpenAI Codex, xAI Grok, Google Antigravity, opencode)
- Supports both push-based (Claude Code) and poll-based (MCP) agent communication
- Auto-relay and stop-reply gating for enhanced user experience
- Centralized plugin marketplace with parity testing for consistency across forks
- Handles Anthropic Teams account restrictions via managed settings

## Why It Matters for RAG Builders
It provides a unified, extensible bridge for AI agents to interact with users via Telegram, simplifying deployment and enhancing accessibility for RAG and AI stack builders.
