## Summary
Zenith is an umbrella monorepo that orchestrates a modular AI desktop product ecosystem, including a Tauri-based shell, React UI, Rust agent runtime, Go backend, and documentation site. It serves as the single entry point to clone, build, and deploy the full stack.

## Key Features
- Centralized submodule management for a multi-repo AI stack
- Automated release train with dependency-aware versioning
- Clear routing for developers to access specific components
- Daily nightly versioning with calendar-based auto-bump
- CI validation for submodule pointer integrity

## Why It Matters for RAG Builders
