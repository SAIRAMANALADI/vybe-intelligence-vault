## Summary
mcp-datalastic is a Model Context Protocol (MCP) server providing real-time AIS vessel position data from Datalastic via Pipeworx's gateway. It enables AI agents to query live maritime vessel tracking information through standardized MCP tooling.

## Key Features
- Provides live AIS vessel positions via MCP protocol
- Integrates with Pipeworx gateway for 1209+ data sources
- Supports plain English queries via ask_pipeworx
- Compatible with MCP clients like Claude Desktop and Cursor
- MIT licensed open-source implementation
