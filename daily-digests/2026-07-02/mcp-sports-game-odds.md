## Summary
The mcp-sports-game-odds repository provides an MCP (Model Context Protocol) server that wraps the Sports Game Odds API, enabling AI agents to fetch live sports betting odds and related data. It is part of the Pipeworx ecosystem, which aggregates over 1209 live data sources for AI applications.

## Key Features
- Wraps the Sports Game Odds API for real-time sports betting data access
- Integrates seamlessly with MCP clients like Claude Desktop, Cursor, and Windsurf
- Part of the Pipeworx gateway, providing access to 1209+ live data sources
- Supports plain English queries via the ask_pipeworx interface
- MIT licensed for open-source use
