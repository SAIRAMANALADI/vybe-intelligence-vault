## Summary
Fabulist is an AI-native desktop writing studio that integrates with Claude Code to provide an agent-assisted editing environment. Each document is a versioned, git-backed project where users can collaborate with an AI agent through comments, suggested edits, and chat, with full control over approvals and version history.

## Key Features
- Real-time AI agent collaboration within documents via Claude Code
- Inline suggested edits with human approval workflows
- Git-backed versioning and rewindable history for each document
- Comment threads anchored to document text for contextual AI interaction
- Local-first privacy with all data stored on the user's machine

## Why It Matters for RAG Builders
Fabulist bridges the gap between AI agents and human writers by providing a controlled, versioned environment where AI can assist with document creation while preserving human oversight and privacy.
