## Summary
A skill module that transforms AI agents (e.g., Claude) into facilitators for the ancient Indian self-knowledge board game 'Leela' (Jnana-chaupada). It simulates dice rolls, board mechanics, and reflective dialogue based on the 72-cell canonical map by Harish Johari.

## Key Features
- Full 72-cell board simulation with 9 ladders and 10 snakes based on Harish Johari's canon
- State persistence via file storage for resuming sessions
- Dual dice roll modes: digital (agent-driven) or physical (user-provided)
- Reflective dialogue and questions for each cell to guide self-exploration
- Lightweight Python engine using only standard library
