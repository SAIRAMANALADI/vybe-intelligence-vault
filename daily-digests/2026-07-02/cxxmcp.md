## Summary
A production-ready C++17 SDK for the Model Context Protocol (MCP) that enables building MCP servers and clients directly in native C++ applications. It provides full protocol coverage, cross-SDK conformance validation, and multiple transport options for seamless integration.

## Key Features
- Full MCP protocol coverage with typed, capability-gated helpers for tools, prompts, resources, and more
- Cross-SDK conformance validation (99% server, 100% client) against the official MCP runner
- Multiple transport options: stdio, process-stdio, Streamable HTTP, WebSocket, and legacy SSE
- RMCP-style Peer/Service architecture designed for embedding into native C++ applications
- Standard CMake SDK consumption with support for Conan, vcpkg, and FetchContent

## Why It Matters for RAG Builders
It provides a robust, conformance-tested C++ SDK for building MCP-compliant agents and tools, enabling seamless integration of AI capabilities into native C++ applications.
