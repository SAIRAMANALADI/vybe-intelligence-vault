## Summary
June is an open-source, privacy-focused AI workspace for macOS that provides local chat, voice dictation, meeting notes, and a sandboxed agent. It routes AI model requests through a TEE-attested, zero-data-retention API while keeping all user data on-device by default.

## Key Features
- Local-first AI workspace with all data stored on-device by default
- Privacy-preserving model routing via TEE-attested June API with zero data retention
- Built-in chat, voice dictation, meeting notes, and sandboxed agent capabilities
- Open-source and cryptographically verifiable deployment chain
- Cross-platform support (macOS primary, Windows app shell available)
