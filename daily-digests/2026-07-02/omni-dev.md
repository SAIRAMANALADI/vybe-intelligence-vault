## Summary
omni-dev is an AI-powered toolkit for Git commit message improvement, PR generation, and Atlassian workflow integration. It transforms messy commit histories into conventional commit formats using contextual AI analysis and provides MCP server capabilities for Jira, Confluence, and Datadog.

## Key Features
- AI-powered commit message rewriting with contextual awareness
- Professional PR generation with AI-generated descriptions
- MCP server for Jira, Confluence, and Datadog integration
- Browser bridge for SSO-gated dashboard access (e.g., Grafana, Loki)
- Parallel processing for large commit ranges and batch operations
