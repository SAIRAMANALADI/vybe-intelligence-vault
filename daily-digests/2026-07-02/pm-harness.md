## Summary
Marionette is a desktop AI coding harness that embeds an LLM as a kernel component, driving any model (frontier or open-weights) through a structured pilot loop over Puppetmaster's durable state. It features CodeGraph-aware retrieval, a portable cross-session wiki, multi-worker delegation, and a three-pane Electron-based UI with a stdlib Python backend.

## Key Features
- Structured pilot loop for LLM-driven coding tasks with tool execution (read, search, edit, run, delegate)
- CodeGraph-aware retrieval for efficient, self-healing structural context injection
- Portable cross-session LLM wiki for durable memory and knowledge retention
- Multi-worker delegation via Puppetmaster for scalable, auditable task execution
- Full-auto mode with safety guards for unattended objective pursuit and command screening
