## Summary
A Go library for web content enrichment that fetches pages, extracts article text, parses structured data (JSON-LD/Microdata), and searches for contextual information. It provides modular packages for different enrichment tasks like text extraction, structured data parsing, and web search.

## Key Features
- Modular Go library with separate packages for extraction, structured data parsing, and web search
- Supports article text extraction using trafilatura and structured data parsing (JSON-LD/Microdata)
- Includes SSRF-safe HTTP fetching with stealth and caching interfaces
- Provides web search context via multiple providers (DDG, Startpage, Brave, Google)
- Supports schema.org types like Place, Article, Event, and Organization

## Why It Matters for RAG Builders
It streamlines preprocessing and enrichment of web content for RAG pipelines, reducing manual parsing and improving data quality.
