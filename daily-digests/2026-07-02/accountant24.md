## Summary
Accountant24 is a local-first AI agent for personal finance that enables users to track spending in plain language, import bank statements and receipts, and query financial data using any LLM, including local models. All data is stored as plain text files on the user's machine with built-in git versioning.

## Key Features
- Natural language spending logging and queries
- Automated import of bank statements and receipts
- Built-in git versioning for all financial data
- Supports local LLMs for offline use
- Double-entry bookkeeping with hledger integration

## Why It Matters for RAG Builders
It provides a privacy-focused, AI-powered alternative to traditional finance tracking tools, enabling secure and automated personal finance management with local data control.
