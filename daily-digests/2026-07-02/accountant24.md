## Summary
Accountant24 is a local-first AI agent for personal finance that enables users to track spending, import bank statements and receipts, and query financial data using natural language. All data is stored as plain text files on the user's machine with built-in version control via git.

## Key Features
- Natural language transaction logging and querying
- Automated import of bank statements and receipts with OCR
- Built-in git versioning for all financial data changes
- Supports both cloud and local LLM providers
- Double-entry bookkeeping with hledger for accurate accounting

## Why It Matters for RAG Builders
It provides a privacy-focused, AI-powered alternative for personal finance management that integrates seamlessly with existing accounting tools while leveraging natural language for effortless interaction.
