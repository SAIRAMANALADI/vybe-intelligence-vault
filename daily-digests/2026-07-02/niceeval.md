## Summary
NiceEval is a lightweight, developer-friendly tool for evaluating AI agents, supporting both sandboxed (Docker/E2B) and direct integration modes. It enables fine-grained testing of multi-turn conversations, tool calls, and agent behaviors, with readable reporting for debugging and optimization.

## Key Features
- Supports two integration modes: sandboxed (Docker/E2B) for coding agents and direct for web agents
- Fine-grained evaluation of multi-turn conversations, tool calls, and agent behaviors
- Readable reporting and debugging tools for agent behavior analysis
- Multi-language support with documentation in 8 languages
- Extensible via custom agent adapters for any AI agent framework

## Why It Matters for RAG Builders
NiceEval fills a critical gap in AI agent evaluation by providing a lightweight, flexible tool for testing complex agent behaviors beyond simple input-output matching, essential for RAG and agent system builders.
