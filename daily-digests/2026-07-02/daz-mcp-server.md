## Summary
A Model Context Protocol (MCP) server that wraps the DazScriptServer HTTP plugin, enabling integration of DAZ Studio functionality into AI workflows via standardized MCP interfaces.

## Key Features
- Wraps DazScriptServer HTTP plugin for DAZ Studio to expose functionality via MCP
- Enables AI agents to interact with DAZ Studio through standardized MCP interfaces
- Simplifies integration of 3D modeling workflows into AI-driven pipelines
- Lightweight and focused on bridging DAZ Studio with AI tools
- Open-source with minimal dependencies
