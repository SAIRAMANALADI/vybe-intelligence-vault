## Summary
HiveMem is a sovereign personal knowledge management system designed to store and manage private data locally with append-only versioning, ensuring data sovereignty, persistence, and portability. It aggregates knowledge from various AI tools and real-life files, providing advanced search, temporal knowledge graph capabilities, and automated agent workflows.

## Key Features
- Append-only versioning with temporal queries for historical data retrieval
- 6-signal ranked search combining semantic, keyword, recency, and graph proximity
- Automated document ingestion pipeline with OCR, summarization, and deduplication
- Privacy-by-realm enforcement with per-realm model routing and approval workflows
- Full instance portability via encrypted archive exports and one-command restores
