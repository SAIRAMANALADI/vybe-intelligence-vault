## Summary
mcp-tradier is a Model Context Protocol (MCP) server that provides stock and options market data via the Tradier Brokerage API. It acts as a gateway for AI agents to access real-time financial data through the Pipeworx platform.

## Key Features
- Provides stock and options market data via Tradier Brokerage API
- Integrates with MCP clients (Claude Desktop, Cursor, Windsurf, etc.)
- Supports plain English queries via ask_pipeworx for automated tool selection
- Part of Pipeworx gateway with access to 1209+ live data sources
- MIT licensed for open-source use
