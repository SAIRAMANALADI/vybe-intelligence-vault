## Summary
An MCP server and live 3D map for accessing the Pentagon's declassified UAP/UFO files, providing AI agents with searchable, geolocated records from 1944–2026 across seven federal agencies via public-domain data.

## Key Features
- MCP server for AI agents to query 238 declassified UAP files by location, agency, era, or type
- Geospatial search with radius-based queries for nearby incidents
- Live 3D globe map visualizing geolocated records with agency-based coloring
- Direct integration with war.gov/UFO for source verification
- Public-domain data with no API keys or authentication required
