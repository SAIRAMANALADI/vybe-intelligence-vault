## Summary
TalosAI is an open-source, self-hostable AI agent that learns from interactions, stores knowledge in a file-based memory system, and operates via Telegram or terminal. It emphasizes honesty by verifying claims against tool results and supports multiple LLM providers.

## Key Features
- File-based memory system that persists knowledge across sessions
- Honest responses validated against tool results or memory
- Supports multiple LLM providers (local and cloud)
- Built-in verifier to ensure factual accuracy of responses
- Subagents for delegated tasks and web search capabilities
