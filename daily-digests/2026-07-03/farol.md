## Summary
FAROL is an AI agent designed for offshore RPAS (Remotely Piloted Aircraft Systems) operations analytics, enabling natural language queries over real operational data with zero numeric hallucination. It combines LLM tool-calling with deterministic Pandas computations to deliver auditable, real-time insights for offshore operations teams.

## Key Features
- Natural language query processing with zero numeric hallucination through deterministic Pandas computations
- Separation of reasoning (LLM) and computation (Pandas) for auditable results
- Offline fallback mode with local keyword routing for uninterrupted demo functionality
- Synthetic data generation with domain-specific physics (e.g., wind seasonality, battery degradation)
- Graceful degradation and public deployment with CI/CD for reliability

## Why It Matters for RAG Builders
