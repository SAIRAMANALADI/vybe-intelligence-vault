## Summary
A Rust-native toolkit for building production-grade AI agent runtimes with strongly typed contracts, provider-neutral LLM adapters, streaming, storage, and observability. It enables explicit control over agent loops, tool execution, and runtime state without opaque framework abstractions.

## Key Features
- Strongly typed contracts for LLM providers, tools, and runtime components
- Provider-neutral architecture supporting OpenAI, Anthropic, and custom backends
- Streaming-first agent loop with explicit event modeling and observability
- Production-ready features like session persistence, snapshots, and health checks
- Modular design with feature-gated adapters for storage, queues, and RAG

## Why It Matters for RAG Builders
It provides a robust, Rust-native foundation for building scalable and auditable AI agent runtimes with explicit control over tool execution, provider integration, and runtime state management.
