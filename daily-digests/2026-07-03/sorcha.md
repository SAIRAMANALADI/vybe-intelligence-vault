## Summary
Sorcha is a decentralized register platform enabling secure, multi-participant data flow orchestration through cryptographic guarantees, immutable ledgers, and field-level encryption. It allows organizations to define structured workflows (blueprints) for multi-party data exchange, validation, and recording with real-time notifications and AI integration capabilities.

## Key Features
- Blueprint-driven workflow orchestration with conditional routing and schema validation
- Immutable distributed ledger with Merkle-tree dockets and cryptographic signing
- Field-level encryption and selective disclosure for multi-tenant data access control
- Post-quantum cryptographic wallet support (ML-DSA, ML-KEM, SLH-DSA)
- AI integration via MCP server and blueprint design assistance

## Why It Matters for RAG Builders
Sorcha provides a secure, auditable foundation for AI-driven multi-party workflows, ensuring data integrity and selective access control critical for RAG systems handling sensitive or regulated information.
