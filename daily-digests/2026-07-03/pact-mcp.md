## Summary
pact-mcp provides Model Context Protocol (MCP) servers for Pact 5 and Kadena Chainweb, enabling AI agents to safely interact with smart contract development workflows, including REPL testing, gas estimation, and Chainweb node queries without exposing private keys.

## Key Features
- Safe, auditable access to Pact 5 development loop via MCP-compatible clients (Claude, Cursor, VS Code)
- Two specialized servers: Pact Tooling (REPL testing, gas estimation, critical-trap scanning) and Chainweb API (node queries, module deployment, SPV proofs)
- Strict security baseline with no private key exposure, audit logging, and prompt-injection protection
- Zero-install usage via npx for rapid deployment in AI agent workflows
- Read-only compatibility with testnet and mainnet for Chainweb API
