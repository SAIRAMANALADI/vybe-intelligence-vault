## Summary
CyberClaw is a Windows-based agent control system that provides transparent, user-controlled task automation with real-time visibility into agent actions. It emphasizes safety, reliability, and local data privacy through a dual-memory architecture and audit-ready operations.

## Key Features
- Real-time transparent logging of all agent actions for full visibility
- Dual-level memory system (short-term and long-term) for consistent task handling
- Two-phase command approval (planning + user confirmation) for safety and control
- Heart-beat monitor for active task tracking and immediate stall notifications
- Local data storage with user-controlled sync and privacy settings
