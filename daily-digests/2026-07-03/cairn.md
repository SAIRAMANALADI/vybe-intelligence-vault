## Summary
Cairn is a local-first, MCP-native DocsGraph tool that transforms repository documentation and structured documents into a navigable graph for AI agents. It enables precise, structure-aware retrieval of documentation sections, cross-references, and entities, reducing token usage and improving retrieval accuracy for RAG systems.

## Key Features
- Converts docs into a structured graph with trees, summaries, entities, cross-references, and vector overlays
- MCP-native tooling for AI agents with stable section anchors and repo-scoped tools
- Local-first deployment with vendor-neutral embeddings and pluggable components
- Incremental sync with failure isolation and concurrent session handling
- Configurable document discovery and indexing with support for Markdown, PDFs, and optional MarkItDown conversion

## Why It Matters for RAG Builders
Cairn enables AI agents to navigate and retrieve documentation with precision, reducing token waste and improving RAG accuracy by leveraging structured document graphs instead of naive chunking.
