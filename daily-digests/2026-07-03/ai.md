## Summary
A Java-based framework for AI operations built on Nasdanika's resource sets and model abstractions. It enables semantic mapping, graph-aware RAG, and contextual AI reasoning by leveraging embeddings, vector stores, and chat completions.

## Key Features
- Graph-aware semantic search leveraging model relationships and graph distances
- Integration with OpenAI and Ollama for embeddings and chat completions
- HNSWLib-based vector store with efficient loading and querying
- CLI tools for vector store generation, embeddings, and semantic search server
- Extensible model abstraction layer for AI component integration
