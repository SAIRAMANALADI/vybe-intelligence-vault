## Summary
mcp-fsolar is a multi-mode package that connects to Felicity Solar cloud systems to expose real-time battery data, including per-cell voltages, SOC, SOH, temperatures, and health metrics. It supports MCP server integration, REST APIs, Node.js libraries, and event-driven pipelines for AI and automation workflows.

## Key Features
- Multi-mode integration: MCP server, REST API, Node.js library, and event-driven pipelines
- Real-time battery metrics: SOC, SOH, cell voltages, temperatures, and health trends
- Event-driven architecture: webhooks and EventEmitter for reactive workflows
- TypeScript-first with full type definitions and generated types
- Docker and Home Assistant add-on support for easy deployment

## Why It Matters for RAG Builders
