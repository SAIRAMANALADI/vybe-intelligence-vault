## Summary
NestRS is a Rust-based framework designed for building scalable backend applications with native performance. It provides a modular architecture with dependency injection, REST/GraphQL/WebSocket support, and a CLI for scaffolding, targeting developers seeking high-performance Rust backends.

## Key Features
- Modular IoC container with dependency injection for Rust applications
- Built-in support for REST, GraphQL, WebSocket, and MCP protocols
- CLI tooling for scaffolding features, resources, and applications
- Unified layer pool for guards, pipes, interceptors, and filters
- Dev container with pre-configured Rust, Postgres, and Redis for rapid setup
