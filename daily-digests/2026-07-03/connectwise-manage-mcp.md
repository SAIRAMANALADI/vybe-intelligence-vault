## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with ConnectWise Manage PSA software, providing 51 tools for managing tickets, companies, contacts, projects, time entries, and more through natural language conversation.

## Key Features
- 51 pre-built tools for ConnectWise Manage operations (tickets, companies, contacts, projects, time entries, etc.)
- Supports both cloud-hosted and self-hosted ConnectWise instances
- One-click deployment to DigitalOcean and Cloudflare Workers
- HTTP transport mode for multi-tenant gateway deployments
- Comprehensive API key management and configuration via environment variables

## Why It Matters for RAG Builders
