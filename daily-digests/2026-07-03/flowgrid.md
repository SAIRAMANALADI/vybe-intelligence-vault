## Summary
FlowGrid (FLG) is a local-first project workflow tool designed for non-coding knowledge work, enabling single-operator agent relay for strategy, marketing, research, and operations professionals. It structures vague business problems into auditable, transferable project systems using plain-text files and a patch-first write strategy.

## Key Features
- Local-first project ledger with plain-text files for persistent project memory
- Patch-first write strategy for medium/high-risk updates requiring human review
- Two-layer state protocol (formal ledger + pending patches) for agent continuity
- Decision-aware logging with 9-field structured entries for rationale and reversibility
- CLI-driven workflow with commands for initialization, framing, closeout, and handoff
