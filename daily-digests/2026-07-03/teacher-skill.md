## Summary
teacher-skill is a Windows application that captures a teacher's unique teaching style, personality, and knowledge into a portable AI skill file. This file can then be used with AI chat systems to generate responses mimicking the teacher's explanations for personalized learning.

## Key Features
- Captures and encodes a teacher's unique teaching style and knowledge into a portable skill file
- Local processing ensures privacy and data safety with no cloud uploads required
- Generates AI responses that mimic the teacher's explanations and tone
- Supports multiple skill files for different teachers or subjects
- Adjustable personality settings to fine-tune the AI's response style
