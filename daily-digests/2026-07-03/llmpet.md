## Summary
A desktop pet that monitors and visually reacts to the state of Claude Code and similar coding agents, displaying real-time expressions, speech bubbles, and authorization prompts. It tracks token usage, costs, and session history while providing a detailed dashboard for AI engineering workflows.

## Key Features
- Real-time agent state visualization with expressive animations (working, thinking, waiting, etc.)
- Token usage and cost tracking with historical trends and session breakdowns
- One-click authorization prompts for agent actions
- Customizable skins (octopus, pixel monster, cat meme)
- Local-first architecture with secure HTTP hooks for agent interaction

## Why It Matters for RAG Builders
It enhances AI agent workflows by providing intuitive, real-time visual feedback and monitoring capabilities, improving developer productivity and transparency in agent operations.
