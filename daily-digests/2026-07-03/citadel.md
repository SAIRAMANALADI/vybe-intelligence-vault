## Summary
Citadel is a local-first encrypted memory engine for AI agents, combining an embedded SQL/vector database with zero-LLM ingest, hybrid retrieval, and cryptographic forgetting. It enables secure, persistent, and privacy-preserving memory storage for agentic systems.

## Key Features
- Zero-LLM ingest with raw conversation storage for privacy and cost efficiency
- Hybrid retrieval combining SQL, vector search, BM25, and cross-encoder reranking
- Cryptographic forgetting via key destruction at per-atom, region, or store granularity
- Embedded SQL engine with full ACID compliance, JOINs, CTEs, and JSON support
- MCP server integration for seamless agent memory access in IDEs and clients

## Why It Matters for RAG Builders
Citadel provides a secure, local-first alternative to cloud-based memory systems for AI agents, enabling privacy-preserving long-term memory with deterministic retrieval and cryptographic data erasure.
