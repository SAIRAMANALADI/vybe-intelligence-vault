## Summary
KnowFlow is an AI-powered document chat application that enables users to upload PDFs, DOCX files, or URLs and interact with them in real-time using Arabic or English. It leverages the Claude Haiku API for streaming responses and Supabase for authentication and storage.

## Key Features
- Supports bilingual interactions in Arabic and English with RTL support
- Real-time streaming responses via Claude Haiku API
- Multi-format document ingestion (PDF, DOCX, URLs)
- Authentication and storage via Supabase
- Deployable on Vercel and Railway with minimal setup

## Why It Matters for RAG Builders
KnowFlow simplifies document-based RAG workflows by providing a ready-to-use bilingual chat interface with streaming capabilities, reducing integration effort for AI engineers.
