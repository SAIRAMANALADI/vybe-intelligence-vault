## Summary
A monorepo providing AI coding agent toolkits, MCP servers, and npm packages focused on UX design, accessibility, and frontend tooling. Includes plugins for Claude Code and reusable libraries for design systems, color theory, and code intelligence.

## Key Features
- Comprehensive MCP server ecosystem for AI agents (e.g., a11y-audit, design-token, typography)
- Lightning Code Index (lci) for sub-millisecond semantic code search and call-hierarchy analysis
- Browser superpowers plugin (agnt) for dev server management, visual regression, and debugging
- Shared npm packages for design tokens, color theory, typography, and image processing
- Integration with Claude Code plugins for seamless AI agent workflows
