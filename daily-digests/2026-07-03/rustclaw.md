## Summary
RustClaw is a lightweight Rust-based framework for running AI agents on desktop environments, enabling automation tasks across platforms like Telegram, Discord, and GitHub with minimal resource usage.

## Key Features
- Supports local (Ollama) and remote (Anthropic) AI model integration
- Multi-platform automation via Telegram, Discord, and GitHub
- Minimal resource usage (under 8 MB RAM, 20 MB disk space)
- Local configuration storage for security and privacy
- Scalable with multiple independent instances

## Why It Matters for RAG Builders
RustClaw enables developers to build and deploy lightweight, resource-efficient AI agents directly on user desktops for real-time automation without complex server setups.
