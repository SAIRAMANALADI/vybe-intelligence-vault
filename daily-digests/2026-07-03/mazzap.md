## Summary
Mazzap v2 is a georeferenced 3D digital-twin engine that transforms real-world terrain into an interactive, browser-based 3D model with natural language querying capabilities. It enables users to visualize, analyze, and interact with geospatial data without requiring cloud services or complex builds.

## Key Features
- Interactive 3D terrain rendering from DEM data with multiple surface modes (aerial, hillshade, elevation)
- Click-to-identify functionality for real-world GPS coordinates, elevation, and map features
- Atlas layers for importing and reprojecting vector/raster geospatial files with auto-styling
- G.A.I.A. (Geospatial Agroecological Intelligent Agent) for natural language querying of the twin's data
- Live telemetry integration via Meshtastic/LoRA gateways and QField survey companion for field data collection

## Why It Matters for RAG Builders
Mazzap v2 provides a self-contained, georeferenced 3D digital twin engine that simplifies the creation and interaction with geospatial data, making it essential for AI stack builders who need to integrate real-world spatial context into their models.
