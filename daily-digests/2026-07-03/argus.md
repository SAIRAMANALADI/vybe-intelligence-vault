## Summary
Argus is an open-source, keyless-first geospatial situational-awareness globe that renders live public data on a MapLibre globe. It supports both manual operation and AI agent interaction, providing real-time layers like aircraft, traffic cameras, weather alerts, and disaster events.

## Key Features
- Live public data rendering on a MapLibre globe with AI agent tool parity
- Region-specific layer streaming to optimize performance and reduce data load
- Interactive features including entity panels, watches, and playback for historical data
- Keyless-first operation with optional free keys for enhanced features
- Modular feed system for easy addition of new public data sources

## Why It Matters for RAG Builders
Argus provides a critical UI component for visualizing real-time geospatial data in RAG systems, enabling dynamic and interactive situational awareness dashboards.
