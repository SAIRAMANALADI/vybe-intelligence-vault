## Summary
TitanVault is a turnkey, fully-local AI workstation distribution designed exclusively for AMD Ryzen AI Max+ 395 (Strix Halo) hardware. It provides a complete on-device AI stack including LLM inference, voice processing, document parsing, browser automation, and AI agents, all running locally without cloud dependencies.

## Key Features
- One-command installation with automated GPU driver setup, Docker image building, and model downloads
- Supports 35B parameter LLM inference fully on-device with Vulkan GPU offload
- Integrates speech recognition, document parsing, image generation, and AI agents in a unified portal
- Includes original components like TitanVault Portal, Aham Voice, and SenseVoice for enhanced functionality
- Offline installation support with fallback mirrors and offline image packs for restricted networks

## Why It Matters for RAG Builders
TitanVault simplifies the deployment of a complete, private AI stack on AMD hardware, eliminating cloud dependencies and manual configuration overhead for RAG and AI agent builders.
