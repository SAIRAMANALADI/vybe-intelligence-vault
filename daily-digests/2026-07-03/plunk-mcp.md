## Summary
A Model Context Protocol (MCP) server for Plunk, an open-source self-hosted email platform. It exposes 84 tools across Plunk's API, enabling AI agents like Claude to interact with transactional emails, contacts, campaigns, workflows, and analytics.

## Key Features
- 84 tools across 11 categories (contacts, campaigns, workflows, analytics, etc.)
- Capability detection to hide unsupported endpoints dynamically
- Full lifecycle management for campaigns, workflows, and segments
- Transactional email sending and event tracking
- Supports multiple Plunk projects via separate MCP server instances

## Why It Matters for RAG Builders
It bridges the gap between Plunk's API and AI agents, enabling seamless integration of advanced email automation features into AI workflows.
