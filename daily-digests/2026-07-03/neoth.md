## Summary
NEOTH is a local-first personal AI system designed to act as a loyal, private assistant with verifiable memory, consent-gated tools, and multi-tiered recall capabilities. It integrates with daily tools, supports coding workflows, and provides audit trails for sensitive decisions.

## Key Features
- Five-tier memory system (episode, profile, ground truth, consolidated, long-term) with external vault integration
- Consent-gated tools and plugins with capability-based access control and audit logging
- Multi-provider LLM routing with fail-closed privacy and provider fallback tracking
- Babel-Index for self-diagnosis and collapse prediction of its own runtime
- WASM plugin sandboxing with signature checks, revocation, and hostcall auditing

## Why It Matters for RAG Builders
NEOTH provides a verifiable, privacy-preserving framework for building autonomous AI agents with auditable memory and consent-gated tool access, critical for trustworthy RAG and AI stack deployments.
