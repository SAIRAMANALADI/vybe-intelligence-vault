## Summary
openDAW-MCP is a Model Context Protocol (MCP) server that enables AI agents to programmatically control openDAW, a browser-based digital audio workstation. It provides 211 tools for real-time manipulation of tracks, instruments, effects, MIDI, automation, and audio rendering via a headless Chromium instance.

## Key Features
- 211 MCP tools for real-time DAW control including tracks, instruments, effects, and automation
- Headless Chromium integration via Playwright for browser-based DAW interaction
- Full mastering chain with LUFS measurement and auto-gain for streaming-ready output
- Scriptable devices (Apparat, Werkstatt, Spielwerk) with JavaScript DSP support
- Dockerized deployment with bundled openDAW and Vite dev server

## Why It Matters for RAG Builders
It enables AI agents to programmatically compose, mix, and master music in a real DAW environment, bridging the gap between AI creativity and professional audio production workflows.
