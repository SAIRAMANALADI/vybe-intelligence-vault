## Summary
skill-registry provides a standardized `.skill.json` format and CLI for managing modular agent capabilities, enabling validation, indexing, and templating of agent skills with zero dependencies.

## Key Features
- Standardized `.skill.json` format for defining agent skills with tools, prompts, and dependencies
- CLI for initializing, validating, indexing, and managing skill manifests
- Zero-dependency design ensuring portability and ease of integration
- Programmatic API for validation, indexing, and template generation
- Supports modular, reusable agent capabilities for local development

## Why It Matters for RAG Builders
It standardizes agent skill definitions, enabling seamless integration and reuse of modular capabilities in RAG and AI agent ecosystems.
