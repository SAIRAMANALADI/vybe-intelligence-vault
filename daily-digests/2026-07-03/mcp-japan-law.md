## Summary
This repository provides a Model Context Protocol (MCP) server for accessing Japanese national laws and ordinances via the e-Gov Law API. It enables AI agents to query and retrieve legal data from Japan's official government sources.

## Key Features
- Provides access to Japanese national laws and ordinances through the e-Gov Law API
- Integrates with MCP clients like Claude Desktop, Cursor, and Windsurf
- Supports plain English queries via the ask_pipeworx interface
- Part of the Pipeworx gateway ecosystem with 1234+ data sources
- MIT licensed for open-source use
