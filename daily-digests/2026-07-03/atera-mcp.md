## Summary
A Model Context Protocol (MCP) server for interacting with the Atera RMM API, enabling AI assistants to manage IT operations tasks such as ticketing, device monitoring, alerts, and customer management through a structured decision-tree architecture.

## Key Features
- Decision tree-based tool discovery for efficient navigation and reduced context overhead
- Full API coverage for Atera RMM including customers, agents, tickets, alerts, and contacts
- Lazy client loading to minimize startup time and resource usage
- Built-in rate limiting (700 req/min) via the underlying node-atera client
- One-click deployment options for Cloudflare Workers and DigitalOcean App Platform

## Why It Matters for RAG Builders
This MCP server enables AI assistants to seamlessly integrate with Atera RMM, unlocking automated IT operations management for tasks like ticketing and device monitoring.
