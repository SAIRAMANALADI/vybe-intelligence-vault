## Summary
An AI-powered job application assistant that automates job discovery, resume scoring, and application drafting. It scans 130+ company careers pages nightly, scores job postings against a user's resume using LLMs, and sends alerts via Telegram. Users can also generate tailored resumes and cover letters on demand.

## Key Features
- Nightly automated job discovery and scoring across 130+ companies using LLM-based fit analysis (0-100 scale)
- Telegram notifications for top job matches with detailed scoring explanations and direct application links
- On-demand generation of tailored resumes and cover letters using the user's resume and job description
- Multiple LLM backend support (OpenRouter free tier, Anthropic API, or Claude CLI) with automatic fallback
- CSV export functionality for job tracking and analysis with configurable score and date filters

## Why It Matters for RAG Builders
It streamlines the job application process by automating discovery, scoring, and drafting, reducing manual effort and improving application relevance through LLM-powered resume-job alignment.
