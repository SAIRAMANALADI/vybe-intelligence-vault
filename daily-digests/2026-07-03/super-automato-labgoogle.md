## Summary
Super Automato LabGoogle is an agent-native CLI harness that automates Google Labs FX (Flow/Veo video generation, MusicFX) and NotebookLM (chat, sources, Audio Overview podcasts) via a persistent Playwright browser profile. It enables autonomous content seeding from the terminal or AI agents with JSON output and screenshot proofs for every step.

## Key Features
- Agent-native CLI for autonomous content seeding (Veo, MusicFX, NotebookLM)
- Persistent Playwright browser profile with headless Chromium for Google Labs automation
- Director orchestrator for end-to-end film pipeline (brief → script → video → music → assemble)
- Project reuse for Flow to avoid spam and accumulate multi-scene films in one project
- JSON output and screenshot proofs for every command, with ffmpeg-based assembly (concat/mix/mux)

## Why It Matters for RAG Builders
It provides a critical automation layer for AI agents to autonomously generate, orchestrate, and assemble multimedia content using Google Labs and NotebookLM, reducing manual intervention in RAG pipelines.
