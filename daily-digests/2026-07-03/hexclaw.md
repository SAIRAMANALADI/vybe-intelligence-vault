## Summary
HexClaw is an enterprise-grade, self-hosted AI Agent framework designed for secure, scalable, and feature-rich personal agent deployments. It integrates multi-model LLM routing, RAG-powered knowledge retrieval, tool calling, and MCP server support with robust security layers and 13 platform integrations.

## Key Features
- Six-layer security gateway (auth, rate limiting, cost control, injection detection, RBAC, audit logging)
- Multi-model LLM routing with provider failover and cost optimization
- Built-in Skill system with 20+ preconfigured tools (search, weather, code execution, file ops, media generation, etc.)
- Knowledge base with hybrid FTS5 + vector retrieval and 5-stage RAG pipeline
- 13 platform integrations (Web, Telegram, Discord, Slack, WeChat, Email, etc.)

## Why It Matters for RAG Builders
HexClaw provides a secure, production-ready foundation for building RAG-powered AI agents with enterprise-grade tooling, multi-platform support, and robust security controls essential for scalable deployments.
