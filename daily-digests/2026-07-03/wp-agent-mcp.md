## Summary
WP Agent is an MCP server that enables AI assistants like Claude to publish and manage self-hosted WordPress sites directly through chat. It provides 69 tools for content creation, SEO, media handling, and site administration via OAuth 2.0 authentication.

## Key Features
- 69 tools for WordPress content and site management via AI assistants
- Keyless OAuth 2.0 authentication with dynamic client registration
- Streamable HTTP endpoint for remote MCP server access
- Supports content generation, SEO, media, and site administration
- Data ownership preserved with self-hosted WordPress credentials
