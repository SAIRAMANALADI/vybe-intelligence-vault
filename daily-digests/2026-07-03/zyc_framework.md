## Summary
ZYC.Framework is a high-performance, modular desktop automation framework built on .NET 10 and WPF, designed for extensible UI and hybrid development with Blazor and WebView2. It supports distributed orchestration via .NET Aspire and offers enterprise-grade features like task management, localization, and exception handling.

## Key Features
- Modular architecture with dynamic plugin loading and independent module development
- Hybrid UI support via Blazor and WebView2 for seamless web-desktop integration
- Built-in .NET Aspire integration for distributed application orchestration and service governance
- Enterprise-oriented features including task management, exception handling, and localization
- Multi-workspace and multi-tab navigation with URI-based routing and state persistence
