## Summary
An open-source CLI tool that autonomously crawls a live website and generates a human-readable report with pass/fail coverage, drafted bug lists, and a runnable end-to-end test suite using TypeScript and Playwright. It operates as a black-box system, inferring tests from the live site without requiring source code access.

## Key Features
- Autonomous website crawling and discovery of pages/endpoints without source code access
- Generates a runnable Playwright test suite with TypeScript for functional/smoke testing
- Produces a human-readable report with coverage metrics, drafted bugs, and cost analysis
- Supports LLM integration (Anthropic, OpenAI, Ollama, OpenRouter, etc.) for classification and test generation
- Checkpointing and caching for efficient resuming and reduced redundant operations

## Why It Matters for RAG Builders
It automates the creation of end-to-end test suites and coverage reports for live websites, reducing manual effort and enabling continuous testing without requiring source code access.
