## Summary
A Kubernetes-based GitOps repository for deploying and managing AI workloads, including LLM inference services, model serving infrastructure, and AI applications like Open WebUI, ComfyUI, and opencode. It leverages Flux CD for continuous delivery and integrates MCP servers for enhanced AI workflows.

## Key Features
- GitOps-based AI workload management with Flux CD for declarative deployments
- Supports multiple LLM inference engines (Ollama, llama.cpp, vLLM, KServe) with GPU acceleration
- Includes AI applications like Open WebUI, ComfyUI, n8n, and opencode for interactive workflows
- Persistent storage and backup integration (RESTic) for data resilience
- MCP server integrations for Kubernetes, Grafana, GitHub, and other services
