## Summary
MCP server for Claude that provides tools to interact with the SuperOps.ai PSA/RMM platform via its GraphQL API, enabling unified ticketing, asset, client, and technician management for AI assistants.

## Key Features
- Decision tree architecture for domain navigation (clients, tickets, assets, technicians)
- Full CRUD operations for entities via GraphQL API
- Lazy loading of domain modules for optimized startup
- Custom GraphQL query/mutation support for advanced operations
- One-click deployment to Cloudflare Workers and DigitalOcean

## Why It Matters for RAG Builders
