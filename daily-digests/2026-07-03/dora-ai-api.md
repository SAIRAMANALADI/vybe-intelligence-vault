## Summary
Dora AI API is a lightweight RESTful API for AI agents featuring persistent memory via MongoDB, web tool integration, and dynamic skill loading. It leverages the Groq LLM for chat functionality and is designed for easy deployment.

## Key Features
- AI chat powered by Groq LLM with free tier access
- MongoDB-backed persistent memory for user context
- Web tools integration for search, URL fetching, and image generation
- Dynamic skill loading for runtime capability expansion
- RESTful API endpoints for chat, memory, and skills management
