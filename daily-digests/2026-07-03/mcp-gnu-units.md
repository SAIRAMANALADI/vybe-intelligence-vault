## Summary
mcp-gnu-units is an MCP server that provides AI agents with precise, offline unit conversion using the GNU units database. It supports over 3000 units, compound expressions, and dimensional analysis while ensuring deterministic and traceable conversions.

## Key Features
- Supports 3000+ units of measurement (length, mass, time, temperature, etc.)
- Evaluates compound unit expressions (e.g., kW*h, acre*ft)
- Reduces quantities to SI base units with exact numerics
- Offline and deterministic with bundled GNU units database
- Includes tools for searching units, defining units, and listing prefixes

## Why It Matters for RAG Builders
It enables AI agents to perform accurate, offline unit conversions and dimensional analysis, reducing errors in RAG pipelines that handle real-world data.
