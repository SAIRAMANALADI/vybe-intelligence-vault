## Summary
PromptImprover is an MCP-first prompt governance layer designed to refine and contextualize AI prompts before execution. It integrates with engineering workflows, adds repo-aware context, and records evidence to improve future AI interactions.

## Key Features
- MCP-based prompt refinement server (`universal-refiner`) for cross-CLI integration
- FlexSearch-based RAG snippets for injecting relevant codebase examples into prompts
- SQLite-backed persistent memory for storing refinement rules, patterns, and prompt history
- Repo-aware context detection (language, framework, architecture) at startup
- Operational traceability with history, timelines, and prompt-to-outcome correlation

## Why It Matters for RAG Builders
PromptImprover provides a structured, evidence-backed approach to prompt refinement and governance, essential for building reliable and auditable AI engineering workflows.
