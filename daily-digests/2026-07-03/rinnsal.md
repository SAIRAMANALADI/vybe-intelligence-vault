## Summary
Rinnsal is a lightweight, local-first infrastructure layer for LLM agent projects, providing SQLite-based memory, task management, connector abstractions, and chain automation with zero external dependencies. It is designed for small autonomous-agent projects needing minimal setup.

## Key Features
- SQLite-based memory system for facts, notes, lessons, and sessions
- Task management with priorities, status tracking, and agent assignment
- Connector abstraction for Telegram, Discord, and Home Assistant
- Chain automation for sequential LLM agent runs with handoff and loop modes
- Embeddable core with zero external dependencies (pure Python stdlib)

## Why It Matters for RAG Builders
Rinnsal provides a minimal, dependency-free foundation for building and orchestrating local LLM agents, reducing setup complexity for RAG and AI stack builders.
