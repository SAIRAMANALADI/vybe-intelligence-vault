## Summary
Agent SEO Engine is a local-first tool that provides deterministic SEO scoring, search-intent classification, and opportunity prioritization for AI agents. It enables agents to perform SEO checks before content rewrites or publishing, ensuring compliance with SEO best practices.

## Key Features
- Search intent classification (informational, navigational, transactional, commercial investigation)
- Markdown article SEO scoring with deterministic checks
- GSC-style opportunity prioritization by impressions, position, CTR gap, and conversions
- Optional MCP server for integration with agent runtimes like Codex, Claude, and Cursor
- Local execution with no required API keys

## Why It Matters for RAG Builders
It enables AI agents to perform accurate, deterministic SEO checks before content publishing, reducing guesswork and improving content quality in RAG pipelines.
