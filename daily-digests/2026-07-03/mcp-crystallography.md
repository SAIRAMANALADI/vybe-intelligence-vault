## Summary
This repository provides a Model Context Protocol (MCP) server for accessing the Crystallography Open Database (COD), enabling AI agents to query crystallography data via a standardized interface. It is part of the Pipeworx ecosystem, which aggregates over 1234 live data sources for AI-driven applications.

## Key Features
- Provides MCP server for Crystallography Open Database (COD) access
- Enables AI agents to query crystallography data via standardized tools
- Part of Pipeworx gateway for aggregating 1234+ live data sources
- Supports plain English queries through ask_pipeworx
- Integrates seamlessly with MCP clients like Claude Desktop and Cursor
