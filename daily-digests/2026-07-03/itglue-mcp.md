## Summary
An MCP server that provides AI assistants like Claude with programmatic access to IT Glue's documentation, asset management, and configuration data via the Model Context Protocol (MCP). Enables secure, API-driven interactions with IT Glue's ecosystem for AI-driven workflows.

## Key Features
- Provides MCP-compliant tools for querying IT Glue organizations, configurations, locations, passwords, documents, and flexible assets
- Supports both local (stdio) and remote (HTTP) deployments with configurable authentication modes (env or gateway)
- Includes health checks and region-specific API endpoints for IT Glue (US, EU, AU)
- Offers one-click deployments to DigitalOcean and Cloudflare Workers
- Handles JWT-based elevated operations (e.g., document folder enumeration) with secure credential management

## Why It Matters for RAG Builders
This MCP server enables AI assistants to securely and programmatically interact with IT Glue's documentation and asset management systems, unlocking automated workflows for IT operations and support tasks.
