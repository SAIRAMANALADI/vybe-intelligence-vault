## Summary
A GPT-4o tool-calling agent that performs unsupervised anomaly detection on network traffic using Isolation Forest, enriches findings with CVE and MITRE ATT&CK context, and generates analyst-grade threat reports. Validated on real-world botnet datasets with tunable precision-recall trade-offs.

## Key Features
- Unsupervised Isolation Forest detector validated on real-world CTU-13 botnet dataset
- GPT-4o tool-calling agent for automated threat triage and contextual enrichment with CVE/MITRE ATT&CK
- Interactive Streamlit demo for real-time threshold tuning and anomaly visualization
- Offline-capable via Ollama for air-gapped deployments
- Research-backed diagnostics for score-overlap analysis and threshold optimization

## Why It Matters for RAG Builders
