## Summary
Agent-Worlds is a multi-agent operating system for creating autonomous LLM-powered NPCs that inhabit a persistent 2D pixel-art world. It enables AI characters to live autonomously with memory, skills, social dynamics, and emergent behaviors, serving as both a research sandbox and a game development toolkit.

## Key Features
- Autonomous agent cycles with daily routines and persistent memory
- Multi-LLM architecture supporting hybrid intelligence per agent
- Skill learning and progression system with mastery thresholds
- Social relationship dynamics with affinity, trust, and familiarity vectors
- MCP protocol for standardized model-agnostic context management

## Why It Matters for RAG Builders
It provides a modular framework for building and studying autonomous AI agents that interact in persistent, dynamic environments, enabling advanced RAG applications with memory, social context, and emergent behaviors.
