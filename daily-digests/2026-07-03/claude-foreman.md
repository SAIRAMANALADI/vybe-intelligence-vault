## Summary
Claude Foreman is an autonomous coding supervisor that automates GitHub issue resolution by routing tasks to free AI models (e.g., Kimi, Gemini) running in Windsurf, Antigravity, or Cursor. It handles decomposition, review, and escalation while managing the entire workflow from issue assignment to PR creation or escalation.

## Key Features
- Automates end-to-end GitHub issue resolution with minimal human intervention
- Supports adaptive routing of tasks to optimal free AI models (e.g., Kimi, Gemini)
- Integrates with Windsurf, Antigravity, Cursor, and Devin Desktop LLM Gateway
- Includes safety guards like dirty worktree checks, pre-flight verifications, and closing reference validation
- Self-improving via retrospective analysis and adaptive routing adjustments
