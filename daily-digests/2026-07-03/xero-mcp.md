## Summary
A Model Context Protocol (MCP) server for the Xero Accounting API that enables MCP-compatible clients like Claude to interact with Xero's accounting data, including contacts, invoices, payments, accounts, and reports.

## Key Features
- Provides MCP-compatible tools for Xero accounting data (contacts, invoices, payments, accounts, reports)
- Supports both stdio and HTTP transport modes for flexible integration
- Offers one-click deployment to DigitalOcean and Cloudflare Workers
- Includes gateway mode for multi-tenant credential management
- Published as an npm package on GitHub Packages for easy installation

## Why It Matters for RAG Builders
It bridges Xero's accounting data with MCP-compatible AI clients, enabling seamless automation and retrieval of financial data for RAG systems.
