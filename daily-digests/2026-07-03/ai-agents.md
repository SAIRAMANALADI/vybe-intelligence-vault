## Summary
AI-Agents is a user-friendly Windows application that leverages the ReAct pattern to automate everyday tasks like web searches, math calculations, and time tracking using AI. It simplifies complex workflows through a clean interface without requiring technical expertise or server management.

## Key Features
- Implements the ReAct pattern for step-by-step reasoning and tool selection
- Integrates web search, calculator, and time tracking tools for task automation
- Provides a clean, no-code interface for non-technical users
- Uses Groq for cloud-based AI inference and DuckDuckGo for web searches
- Supports Windows 10/11 with minimal system requirements
