## Summary
Modern, typed, and asynchronous Python SDK for accessing public FFBB (French Basketball Federation) data, including clubs, competitions, matches, rankings, venues, officials, and Meilisearch search capabilities.

## Key Features
- Typed Python client with Pydantic v2 models for structured data validation and autocompletion
- Asynchronous and synchronous API support with automatic token management
- Comprehensive FFBB data coverage including clubs, competitions, matches, rankings, and venues
- Built-in Meilisearch integration for fast and flexible search across FFBB datasets
- Automated API drift detection and schema monitoring for reliability

## Why It Matters for RAG Builders
Provides a robust, typed, and asynchronous interface to access and search FFBB basketball data, essential for AI agents or applications requiring structured sports data integration.
