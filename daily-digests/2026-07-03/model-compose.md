## Summary
model-compose enables developers to define, compose, and deploy AI systems (agents, RAG pipelines, MCP servers) declaratively using YAML, supporting hybrid cloud and local model execution without vendor lock-in.

## Key Features
- Declarative AI system composition via YAML with no custom code required
- Hybrid execution supporting both cloud APIs (OpenAI, Anthropic, etc.) and local models (HuggingFace, vLLM, llama.cpp)
- Built-in support for 20+ reusable components including agents, vector stores, HTTP clients, and shell commands
- Portable deployment across native, Docker, and distributed environments with runtime flexibility
- Real-time streaming, human-in-the-loop workflows, and protocol-agnostic serving (HTTP, WebSocket, MCP)

## Why It Matters for RAG Builders
It eliminates vendor lock-in for AI systems by enabling portable, hybrid AI workflows defined declaratively, making it essential for RAG builders seeking flexibility and control.
