## Summary
Eris is a battle-tested, open-source weather API and MCP server that consolidates data from OpenWeatherMap, OpenStreetMap, and IP geolocation into a single clean API. It provides weather data by coordinates or IP address and serves as a public MCP server for AI agents.

## Key Features
- Public MCP server endpoint compatible with AI agents like Claude and Cursor
- 100% test coverage enforced via SonarCloud with zero code smells or duplications
- Consolidates weather data from multiple sources (OpenWeatherMap, OpenStreetMap, IP geolocation)
- Supports both coordinate-based and IP-based weather queries
- Automated CI/CD pipeline with Docker image deployment and live updates

## Why It Matters for RAG Builders
Eris provides a reliable, no-setup MCP server for AI agents to fetch real-time weather data, reducing integration overhead for RAG builders.
