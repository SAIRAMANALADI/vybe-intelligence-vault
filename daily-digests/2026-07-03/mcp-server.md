## Summary
DollhouseMCP is an open-source MCP server that enables dynamic customization of AI models through modular personas, skills, templates, agents, memories, and ensembles. It provides a structured portfolio system for managing AI behaviors and capabilities with permission policies and a semantic API (MCP-AQL) for safe, progressive tool discovery.

## Key Features
- Modular AI customization via 6 element types (personas, skills, templates, agents, memories, ensembles)
- MCP-AQL semantic API (CRUDE endpoints) for safe, progressive tool discovery and permission control
- Local portfolio system (~/.dollhouse/portfolio/) for managing AI behaviors and capabilities
- Bidirectional skill format converter (Dollhouse ↔ agent skills) for cross-platform compatibility
- Interactive setup wizard and one-click install for major MCP-compatible AI clients
