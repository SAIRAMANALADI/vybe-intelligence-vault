## Summary
A collection of portable Agent Skills designed to teach AI coding agents how to interact with the BAT AI Tools ecosystem, enabling automated packaging and submission of AI tools to bataitools.com.

## Key Features
- Portable skill definitions for AI agents (e.g., Cursor, Claude Code)
- 4-step workflow for submitting AI tools (extract, assets, translate, submit)
- Seamless integration with bataitools.com via bat-cli
- Supports natural language triggers for autonomous execution
- Cross-platform compatibility (local and remote installation)
