## Summary
Dora AI Agent is a lightweight API-driven AI agent framework that enables natural conversations with Groq LLM, persistent memory storage via MongoDB, and dynamic skill loading for web tools and capabilities. It provides a RESTful interface for seamless integration into AI workflows.

## Key Features
- Natural language chat powered by Groq LLM with free-tier access
- MongoDB-backed persistent memory for user context across sessions
- Built-in web tools for search, URL fetching, and image generation
- Dynamic skill loading to hot-add new capabilities at runtime
- Simple REST API for easy integration with other systems
