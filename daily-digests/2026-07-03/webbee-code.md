## Summary
Webbee is a terminal-based coding agent that integrates with Imperal Cloud to read, write, and execute code locally while leveraging cloud-based reasoning via the ICNLI protocol. It enables users to interact with their files and connected apps using plain English commands.

## Key Features
- Cloud-based reasoning with local file operations
- Three operational modes (default, plan, autopilot) for granular control
- Integration with Imperal Cloud apps (mail, notes, tasks)
- No model keys required on local machine
- Open protocol (ICNLI) for model interchangeability

## Why It Matters for RAG Builders
Webbee enables seamless integration of cloud-based AI reasoning with local code operations, reducing the need for local model management while maintaining user control over critical actions.
