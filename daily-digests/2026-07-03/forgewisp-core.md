## Summary
Forgewisp enables safe, function-calling AI agents to run entirely in the browser by registering frontend functions as validated tools with risk-tier execution, streaming, reasoning streams, and an audit log. It provides a catalog of pre-built browser tools and supports MCP server integration.

## Key Features
- Register frontend functions as validated agent tools with JSON Schema
- Risk-tier execution model (read/write/destructive) with developer confirmation
- OpenAI-compatible streaming with multiple reasoning modes (extended, tag-based, native)
- Audit log for all function calls, validations, and executions
- Subagent orchestration for delegating tasks to child agents

## Why It Matters for RAG Builders
Forgewisp enables secure, client-side AI agents with validated tool execution and risk controls, reducing backend dependencies while ensuring safe and auditable operations.
