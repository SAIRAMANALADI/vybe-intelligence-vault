## Summary
Vublox Agent Tools is an MCP (Model Context Protocol) server that enables AI agents to discover live football matches, player profiles, and fan-shot video clips from Vublox without requiring an API key. It provides real-time sports data access for AI-driven applications.

## Key Features
- Real-time access to live football matches and scores
- Player profile discovery and linking
- Fan-shot video clip integration
- No API key required for usage
- Seamless integration with AI agents via MCP
