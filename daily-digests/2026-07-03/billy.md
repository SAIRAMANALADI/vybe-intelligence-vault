## Summary
Billy is a self-hosted personal AI assistant integrated with Telegram that orchestrates local or cloud-based AI models to perform tasks like email management, CRM, research, document generation, and skill learning. It operates as a single-user system with strict safety guards.

## Key Features
- Dispatch-first orchestrator using LangGraph for modular agent workflows
- Supports both local (Ollama) and cloud AI models with provider-agnostic configuration
- Integrates with email, CRM, research, document/media generation, and skill learning
- Enforces strict safety guards (no self-editing, no unprompted email sending)
- Designed for single-user personal assistant use with persistent memory

## Why It Matters for RAG Builders
