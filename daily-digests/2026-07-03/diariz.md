## Summary
Diariz is a self-hosted, multi-user platform for recording, transcribing, and analyzing meetings with speaker diarization, speaker identification, summarization, action item extraction, and chat capabilities. It supports both browser and system audio capture, integrates with OpenAI-compatible LLMs, and provides advanced features like cross-recording speaker recognition and MCP server integration for Claude.

## Key Features
- Multi-user audio recording (mic/system loopback) with live input monitoring
- Server-side transcription with WhisperX and pyannote for speaker diarization and word-level timestamps
- Cross-recording speaker identification using SpeechBrain ECAPA voiceprints in pgvector
- Automated summarization, action item extraction, and professional meeting minutes generation
- Chat over transcripts with OpenAI-compatible LLM endpoints and built-in tools for search and analysis

## Why It Matters for RAG Builders
Diariz provides a comprehensive, self-hosted pipeline for transforming raw audio into structured, searchable, and actionable meeting data, making it essential for RAG builders who need high-quality, speaker-aware transcripts with advanced metadata and LLM integration.
