## Summary
A plugin marketplace for Claude Code that allows users to install and manage plugins from a single source. The repository includes a marketplace manifest and a sample plugin (pinpoint) for live in-browser UI annotation and note-taking.

## Key Features
- Centralized plugin management for Claude Code with a single installation command
- Supports live in-browser UI annotation via the pinpoint plugin
- Streamlined updates for all installed plugins
- Modular repository structure with per-plugin directories
- Open-source MIT license for community contributions
