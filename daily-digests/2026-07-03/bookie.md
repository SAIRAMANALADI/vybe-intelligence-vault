## Summary
Bookie is an MCP server that provides double-entry bookkeeping for freelancers and landlords, enabling LLMs like Claude or GPT to manage financial records, categorize transactions, reconcile statements, and generate tax reports without relying on traditional accounting software like QuickBooks.

## Key Features
- Double-entry ledger for accurate financial tracking
- LLM-driven categorization and reconciliation of transactions
- Integration with bank statements via CSV imports
- Tax report generation (Schedule C, Schedule E)
- Multi-machine ledger sharing via Neon Postgres

## Why It Matters for RAG Builders
Bookie enables AI-driven financial management by providing a correct, auditable double-entry ledger that LLMs can interact with programmatically, eliminating the need for manual spreadsheet-based bookkeeping.
