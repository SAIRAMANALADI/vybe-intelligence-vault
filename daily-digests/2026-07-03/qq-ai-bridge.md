## Summary
QQ-AI-Bridge enables remote control of AI agents like Claude Code or Codex on a local PC via QQ (a popular Chinese messaging app). Users can send commands from their phone QQ to execute tasks, receive results, and manage multi-turn interactions without needing to access the computer directly.

## Key Features
- Bidirectional QQ-to-AI agent communication for remote task execution
- Multi-engine support (Claude Code, Codex) with engine-specific routing
- Automatic task logging and result archiving in Markdown format
- Self-healing watchdog for NapCat/QQ bridge resilience and auto-recovery
- Security controls including owner QQ verification and emergency lock commands

## Why It Matters for RAG Builders
