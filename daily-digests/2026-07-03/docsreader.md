## Summary
DocsReader is a native desktop application that provides a clean, local interface for reading and managing agent-written markdown documentation, memory, and tasks. It integrates with AI agents via an MCP server, enabling bidirectional synchronization between agent-managed markdown files and a user-friendly reading interface across macOS, Linux, and Windows.

## Key Features
- Native desktop app for reading markdown with advanced rendering (tables, math, diagrams, code blocks)
- Bidirectional integration with AI agents via bundled MCP server for writing docs, memory, and tasks
- Workspace management with live reload, git status tracking, and external change detection
- Cross-platform support (macOS, Linux, Windows) with signed and notarized releases
- Minimalist, ADHD-friendly UI with customizable themes, split views, and fuzzy search

## Why It Matters for RAG Builders
DocsReader bridges the gap between AI agent workflows and human-readable documentation by providing a native interface for managing agent-written markdown, ensuring seamless collaboration and readability without vendor lock-in.
