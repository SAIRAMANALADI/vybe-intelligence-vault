## Summary
mcp-materials provides computed (DFT) materials structures and thermodynamic properties via an MCP (Model Context Protocol) server, enabling AI agents to access curated materials science data sources. It is part of the Pipeworx ecosystem, which aggregates 1234+ live data sources for AI-driven applications.

## Key Features
- Provides computed materials structures and thermodynamic properties via MCP
- Integrates with Pipeworx gateway for access to 1234+ live data sources
- Supports plain English queries via ask_pipeworx for simplified interaction
- Designed for AI agents and MCP clients (Claude Desktop, Cursor, Windsurf, etc.)
- Open-source with MIT license for broad accessibility

## Why It Matters for RAG Builders
