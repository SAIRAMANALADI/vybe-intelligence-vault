## Summary
A Claude Code plugin providing a life-sciences regulatory and CSV toolkit for computer-system validation (CSV), covering GAMP 5, 21 CFR Part 11, EU GMP Annex 11, eCFR, and openFDA. It includes slash commands, auto-invoked skills, parallel sub-agents, and an IQ/OQ/PQ qualification engine to generate draft validation documentation.

## Key Features
- Automated generation of IQ/OQ/PQ qualification packs for GxP compliance
- Real-time access to eCFR, openFDA, and regulatory frameworks via slash commands
- Parallel sub-agent architecture for concurrent qualification tasks
- Auto-invoked skills for 21 CFR Part 11 and GAMP 5 advisory support
- Document protection hook to enforce change control for approved records
