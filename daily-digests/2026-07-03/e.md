## Summary
A fast, GPU-accelerated native code editor built in Rust with first-class PHP/Laravel support, an integrated terminal, and a right-hand AI agent panel for running CLI coding agents like Elyra or Claude Code alongside your code.

## Key Features
- GPU-accelerated reactive UI with responsive native performance
- Built-in AI agent panel for running CLI coding agents (Elyra, Claude Code, Codex) with deep editor co-op
- First-class PHP/Laravel support including framework-aware completion, Eloquent relationship graphs, and Laravel intelligence features
- Integrated terminal, source control, database panel, and debugging tools (Xdebug, DAP)
- Semantic search, visual undo tree, and session persistence with auto-updater

## Why It Matters for RAG Builders
