## Summary
Xenesis AIDE is a desktop workbench for AI agents, enabling them to interact with terminals, files, viewers, and live UI rendering through a shared Capability Registry. It supports multiple AI providers and allows agents to control the same desktop environment for tasks like terminal execution, file editing, and dashboard generation.

## Key Features
- Shared Capability Registry (650+ nodes, 390+ methods) for unified agent control
- Live UI rendering via XCON and Gowoori for charts, tables, and dashboards
- Terminal automation with PTY support (node-pty/ConPTY) and safety gates
- Remote CLI control through gateway channels (Telegram, Discord, Slack)
- Data-bound dashboards that update dynamically based on underlying data
