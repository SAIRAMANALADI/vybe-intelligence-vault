## Summary
HEADING OS is a sovereign, security-first operating system designed for executives to manage research, communications, CRM, content, and operations using Claude Code as the agent foundation. It enforces strict separation between shareable engine code and private data, ensuring data privacy and security through multiple enforcement layers.

## Key Features
- Strict engine-data separation with six enforcement layers to prevent data leakage
- Human-gated outbound messaging to ensure no unauthorized data transmission
- Console-first design with terminal and Claude Code chat operability
- Modular skills, hooks, and daemons for extensible workflows
- Comprehensive security model with progress watchdogs and verified completion

## Why It Matters for RAG Builders
