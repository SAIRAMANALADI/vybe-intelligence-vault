## Summary
OpenCowork is a minimal Electron-based desktop application built with React and TypeScript, designed to mirror the visual style of the OpenCowork web platform. It provides a local file workspace for read-only file access and integration with task submissions, enforcing strict security boundaries via Electron's main process.

## Key Features
- Minimal Electron + React + TypeScript shell with OpenCowork visual language
- Secure local file workspace with read-only access and granular permissions
- Feature-first renderer architecture with clear component boundaries
- Preload bridge exposing only bounded filesystem operations
- Task submissions with approved local file context
