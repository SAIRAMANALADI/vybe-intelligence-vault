## Summary
slide-maker automates the creation of native, editable PowerPoint presentations from papers, code, or documents, ensuring every element (text, charts, equations) remains click-to-edit in the final PPTX file. It integrates with AI assistants like Codex or Claude Code for interactive generation and includes an independent critic review for quality assurance.

## Key Features
- Generates native editable PPTX files with real text boxes, shapes, and charts (not images)
- Integrates with Codex and Claude Code for interactive slide creation
- Includes an independent critic agent to review and refine slides before delivery
- Supports speaker notes and native PowerPoint click-build animations for bullet reveals
- Provides pre-built templates for various presentation types (papers, products, data analysis, etc.)
