## Summary
Vexi is an open-source AI coding agent for the terminal that enables developers to interact with AI models locally using their own API keys. It supports multilingual interactions, project memory, custom skills, and advanced features like code explanation, replay exports, and MCP server integration.

## Key Features
- Zero-config setup with BYOK (Bring Your Own Key) support for multiple AI providers
- Project memory system that compresses and retains context across sessions
- Custom skills system for enforcing coding conventions and styles
- Built-in code explanation in multiple languages with RTL support for Arabic
- MCP client/server capabilities for seamless integration with other AI tools

## Why It Matters for RAG Builders
