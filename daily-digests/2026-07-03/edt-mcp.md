## Summary
EDT-MCP is an MCP (Model Context Protocol) server plugin for 1C:EDT that enables AI assistants like Claude, GitHub Copilot, and Cursor to interact with 1C:EDT workspaces. It provides a comprehensive set of tools for code analysis, metadata management, and application control within the 1C platform ecosystem.

## Key Features
- MCP Protocol 2025-11-25 compliant with streamable HTTP transport and SSE support
- Comprehensive toolset for 1C:EDT workspace interaction including error reporting, content assist, and metadata refactoring
- Real-time server status bar with interactive controls for AI agent communication
- Tool management system with group-based enable/disable presets for AI assistant control
- Form inspection capabilities including screenshots and YAML layout snapshots

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and the 1C:EDT platform, enabling advanced code analysis and metadata management for AI-driven development in the 1C ecosystem.
