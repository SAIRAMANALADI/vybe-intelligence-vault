## Summary
mbeditor is a local desktop application that converts markdown text into professionally formatted WeChat articles, integrating with AI agents for content generation and layout automation. It streamlines the process of creating polished posts for WeChat Official Accounts.

## Key Features
- Converts markdown to WeChat-ready HTML with one click
- Integrates with AI agents for content drafting and refinement
- Local-first architecture ensuring data privacy and security
- Drag-and-drop image resizing for mobile-optimized posts
- Supports light/dark themes and custom CSS for branding
