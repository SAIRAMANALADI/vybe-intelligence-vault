## Summary
NexoraAI is a local-first desktop application that enables users to build complete web projects by interacting with a GGUF-based LLM running entirely on their machine. It orchestrates real-time file generation, iterative edits, and project execution without relying on cloud services or external APIs.

## Key Features
- Local GGUF inference with automatic model-size-adaptive prompting for optimal performance
- Real-time surgical edits via SEARCH/REPLACE blocks for efficient iteration
- Integrated agent actions (npm package management, font downloads, shell commands, HTTP fetches)
- One-click project execution with live dev server and automatic build error detection
- Privacy-preserving workflow with no data leaving the user's machine

## Why It Matters for RAG Builders
