## Summary
A Model Context Protocol (MCP) server implementation that provides web scraping, content extraction, and search capabilities via the Olostep API. It enables MCP-compatible AI agents to interact with web data in real time through structured tools and parsers.

## Key Features
- Scrape websites in HTML, Markdown, JSON, or plain text with optional parsers
- Batch scraping of up to 10k URLs and autonomous site crawling
- AI-powered answers with citations and structured JSON outputs
- Geo-targeted content routing and configurable wait times for JavaScript-heavy sites
- Comprehensive error handling, polling for async jobs, and website URL discovery

## Why It Matters for RAG Builders
It provides MCP-compatible AI agents with real-time web scraping and search capabilities, essential for building dynamic RAG systems that require up-to-date or domain-specific web data.
