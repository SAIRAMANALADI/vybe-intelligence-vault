## Summary
Regenerator 2000 is a modern, interactive 6502 disassembler designed for Commodore 8-bit machines, offering both a keyboard-driven TUI for manual analysis and an MCP server for programmatic AI-driven disassembly. It supports a wide range of file formats and features advanced analysis, debugging, and export capabilities.

## Key Features
- Interactive TUI for manual disassembly with keyboard navigation and undo/redo support
- MCP server for AI-driven programmatic disassembly and analysis
- Support for multiple Commodore file formats (PRG, CRT, D64, etc.) and assemblers (64tass, ACME, etc.)
- Advanced features like binary unpacking, debugger integration, and project management
- Export capabilities to ASM, HTML, and label files with customizable enums and labels

## Why It Matters for RAG Builders
