## Summary
SenClaw is a local-first framework for building and deploying personal AI agents with multi-agent orchestration, memory management, and cross-platform support. It provides a Rust-based daemon, a Flutter desktop app, and local model inference (MLX/Candle) for offline AI capabilities.

## Key Features
- Local and cloud LLM support with MLX/Candle runtime for offline inference
- Multi-agent orchestration with DAG-based team execution and virtual workers
- Hybrid memory system combining SQLite, vector search, and curated knowledge graphs
- Cross-platform desktop and mobile app with native Flutter UI
- Space Apps for installable mini-apps with MCP tool integration

## Why It Matters for RAG Builders
SenClaw provides a robust, local-first framework for building production-grade personal AI agents with advanced orchestration and memory capabilities, reducing dependency on cloud services while enabling offline operation.
