## Summary
Calame is a self-hosted web application that transforms any PostgreSQL, MySQL, or SQLite database into a secure MCP (Model Context Protocol) server with fine-grained access control, PII masking, and natural language querying capabilities.

## Key Features
- Turns any SQL database into an MCP server with configurable access profiles
- Fine-grained permissions, PII masking, and row-level data scoping per profile
- Built-in chat interface for natural language queries with pluggable LLM providers
- Supports multiple authentication methods including OAuth 2.1, OIDC SSO, and Bearer tokens
- Docker and reverse-proxy templates for easy deployment and scalability

## Why It Matters for RAG Builders
Calame is essential for AI engineers building RAG systems as it provides a secure, flexible way to expose databases as MCP servers, enabling fine-grained access control and natural language querying without vendor lock-in.
