## Summary
A Model Context Protocol (MCP) server for deep, local research on cryptocurrency tokens, aggregating data from multiple sources like CoinGecko and DeFiLlama to generate structured reports without requiring an API key.

## Key Features
- Multi-source cryptocurrency data aggregation (CoinGecko, DeFiLlama, etc.)
- Structured research reports with technical, market, and social sentiment data
- Resource management for storing and referencing search results
- Status tracking for research progress across sections
- Bypasses HTML scraping limitations via direct API calls

## Why It Matters for RAG Builders
It provides a free, local, and structured way to gather and analyze cryptocurrency data, reducing dependency on external APIs and enabling deeper AI-driven research.
