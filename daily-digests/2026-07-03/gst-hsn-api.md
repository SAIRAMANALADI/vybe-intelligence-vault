## Summary
A specialized API for accurate GST HSN and SAC code lookups in India, providing condition-aware GST rate calculations compliant with GST 2.0 regulations. It offers real-time tax rate data, bulk lookup, and MCP integration for AI agents.

## Key Features
- 48,752 HSN codes and 681 SAC codes with real-time GST rate lookups
- Condition-aware rate resolution (price thresholds, end-use, supply nature)
- MCP endpoint for seamless AI agent integration
- Bulk lookup and autocomplete endpoints for efficiency
- Compliant with CBIC GST 2.0 regulations (effective 2025-09-22)

## Why It Matters for RAG Builders
It provides critical, up-to-date GST tax rate data for Indian businesses and AI agents, ensuring compliance and accuracy in financial and tax workflows.
