## Summary
Network Sketcher is an AI-native network design tool that generates L1/L2/L3 topology diagrams, device tables, and AI-ready context files from structured network data or natural-language workflows. It offers three editions: Local MCP for direct LLM integration, Online for browser-based use, and Offline for desktop GUI/CLI operations.

## Key Features
- AI-native Local MCP edition for direct LLM client integration (Cursor, Claude Code)
- Generates L1/L2/L3 topology diagrams, device tables, and AI context files from natural language or structured data
- Supports import from live inventory via Cisco DevNet converters (ACI, Catalyst Center, Meraki, NetBox, etc.)
- Three editions: Local MCP (stdio-based), Online (web service), and Offline (desktop GUI/CLI)
- Exports diagrams in SVG/PowerPoint formats and device tables in HTML

## Why It Matters for RAG Builders
Network Sketcher enables AI agents to autonomously design, validate, and document network topologies, bridging the gap between natural language prompts and executable network designs for RAG and AI-driven infrastructure automation.
