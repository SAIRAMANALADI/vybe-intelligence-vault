## Summary
A hands-free, Iron Man-style voice AI agent for desktops that listens for wake words, executes PC control actions with permission guardrails, and renders holographic HUD panels. Built on the Claude Agent SDK with persistent memory, MCP integrations, and an Electron-based desktop app.

## Key Features
- Wake-word activation with continuous listening and echo guard
- Permission-gated PC control with explicit user confirmation for risky actions
- Persistent memory via Obsidian vault with reflective consolidation
- Holographic HUD with declarative UI panels generated by the agent
- Layered TTS fallback chain (ElevenLabs → Piper → browser voice)

## Why It Matters for RAG Builders
It provides a production-ready framework for building secure, voice-controlled AI agents with permission guardrails and persistent memory, critical for RAG systems requiring real-world PC interaction.
