## Summary
OpenScience is an AI agent framework designed to autonomously conduct scientific research by reading literature, forming hypotheses, writing and executing code, running experiments, and generating reports. It operates as a browser-based workspace and supports integration with multiple AI models and scientific databases.

## Key Features
- End-to-end research automation: literature review, hypothesis formation, code execution, experiment running, and report generation in a single session
- Model-agnostic architecture supporting frontier and open-weight models from multiple providers
- Integration with 250+ scientific tools and databases (UniProt, PDB, arXiv, PubChem, etc.)
- Browser-based workspace with file tree, editor, terminal, and inline rendering for scientific visualizations
- Extensible via TypeScript SDK, plugins, custom agents, and MCP servers

## Why It Matters for RAG Builders
It enables fully autonomous AI-driven scientific research, reducing manual effort and accelerating discovery by automating the entire research loop from literature review to experimentation and reporting.
