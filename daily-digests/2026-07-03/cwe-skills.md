## Summary
CWE Skills provides an AI-native integration layer for Common Weakness Enumeration (CWE) data, offering Skills, Go SDK, CLI, and MCP interfaces for parsing, validating, searching, and navigating CWE weaknesses and relationships.

## Key Features
- AI-native Skills integration for LLMs and agents
- Go SDK for programmatic CWE data access and manipulation
- CLI tool for shell scripts and dev workflows with 40+ subcommands
- Offline XML catalog parsing and in-memory registry for local operations
- Relationship navigation, tree construction, and search/filter capabilities

## Why It Matters for RAG Builders
It enables AI systems to programmatically understand, query, and reason about CWE weaknesses, enhancing security-focused AI applications with structured vulnerability data.
