## Summary
Company Docs MCP transforms internal documentation into an AI-searchable knowledge base by ingesting markdown, HTML, PDFs, or web pages, converting them into vectors, and storing them in Supabase for semantic search. Teams can query the knowledge base via MCP-compatible AI tools like Claude or Cursor.

## Key Features
- Supports multiple content formats (markdown, HTML, PDF, URLs, website crawls)
- Leverages Cloudflare Workers AI for vector embeddings without third-party API keys
- Integrates with Supabase for vector search and storage
- Enables AI tools (Claude, Cursor) to query internal docs via MCP
- Auto-detects categories and tags or uses YAML frontmatter for customization

## Why It Matters for RAG Builders
It provides a turnkey solution for turning internal documentation into a queryable knowledge base that AI agents can use for RAG, eliminating the need for manual prompt engineering or external API dependencies.
