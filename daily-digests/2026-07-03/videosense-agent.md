## Summary
VideoSense-Agent is an AI agent that processes video libraries by watching, reasoning, and answering user queries with playable clips, charts, and step-by-step proof. It uses a self-driven loop with Gemini 2.5 to dynamically decide actions like video analysis, semantic search, and cost tracking.

## Key Features
- Dynamic agent loop with Gemini 2.5 for real-time video analysis and reasoning
- Answers include playable clips, charts, and step-by-step proof of reasoning
- Self-monitoring cost tracking with live telemetry and budget controls
- Cross-session memory with append-only transcript storage
- Production-ready deployment on Cloud Run with 146 automated tests

## Why It Matters for RAG Builders
It provides a framework for building AI agents that can autonomously process and reason over video data, offering verifiable, multi-modal answers essential for RAG systems requiring dynamic, proof-backed responses.
