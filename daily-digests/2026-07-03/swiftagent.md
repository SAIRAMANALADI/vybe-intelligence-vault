## Summary
SwiftAgent is a lightweight, modular Swift framework for building local LLM agents with zero external dependencies. It supports Ollama and llama.cpp via OpenAI-compatible APIs and includes ReAct loops, tool integration, and memory management for macOS and iOS.

## Key Features
- Zero external dependencies (pure Foundation + URLSession)
- ReAct loop for multi-step reasoning and tool use
- Built-in support for Ollama and llama.cpp via OpenAI-compatible APIs
- Streaming responses with AsyncThrowingStream and SSE
- Modular plugin architecture for logging, monitoring, and tracing

## Why It Matters for RAG Builders
SwiftAgent enables developers to build lightweight, local-first AI agents in Swift with minimal dependencies, making it ideal for privacy-focused and offline-capable applications.
