## Summary
MantisClaw is a multi-platform desktop Computer Use Agent (CUA) that enables autonomous browser and computer automation across Windows, Linux, and Mac OS. It allows users to control agents via messaging platforms like WhatsApp, Telegram, and Slack, with built-in tools for webcam access, browser interactions, and workflow execution.

## Key Features
- Multi-platform support (Windows, Linux, Mac OS Intel/Apple Silicon)
- Real browser automation with cloudflare bypass capabilities
- Unlimited agents and scenarios with self-healing skills
- Integration with messaging channels (WhatsApp, Telegram, Slack, etc.)
- Built-in tools for screenshots, clicks, scrolling, and document generation
