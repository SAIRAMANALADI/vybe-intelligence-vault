## Summary
Netfix is a macOS-local network diagnostic and configuration assistant that simplifies proxy setup, validation, and deployment. It allows users to paste proxy connection details, pre-checks their validity, saves them securely to the macOS Keychain, and deploys them with one-click while providing rollback capabilities.

## Key Features
- One-click proxy deployment with pre-check validation to ensure connectivity before applying changes
- Secure storage of proxy credentials in macOS Keychain with local-first privacy guarantees
- Automated backup and rollback of network settings to prevent misconfigurations
- MCP server integration for AI agents (Codex, Kimi, Claude, Cursor, MiniMax) to enable structured diagnostics and fixes
- Local-only diagnostics and rule-based explanations without requiring API keys for core functionality

## Why It Matters for RAG Builders
Netfix streamlines proxy configuration for macOS users by automating validation, deployment, and rollback, reducing setup friction and improving reliability for AI engineering workflows.
