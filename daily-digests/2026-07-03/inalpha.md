## Summary
Inalpha is a professional quant agent framework where LLM agents research, validate, and evolve trading strategies under strict audit controls. It enables multi-market factor-based trading with machine-approved orders, ensuring every decision is provable and traceable.

## Key Features
- LLM-driven strategy evolution with sandboxed code generation and multi-objective fitness evaluation
- Machine-approved order routing with one-shot approval tokens, ensuring no direct LLM order placement
- Factor lab with time-series Rank IC ranking and cross-sectional panel scoring for dynamic alpha selection
- Multi-perspective research with structured analyst panels and opposing-stance debates for robust decision-making
- Unified kernel for backtest, paper trading, and live execution with declarative risk engine and audit-grade logging
