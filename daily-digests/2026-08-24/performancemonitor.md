## Summary
A free, open-source SQL Server performance monitoring tool offering 30+ collectors, real-time alerts, a graphical plan viewer, and an MCP server for AI-powered analysis. Supports SQL Server 2016–2025, Azure SQL, and AWS RDS with both Full and Lite editions.

## Key Features
- 30+ specialized T-SQL collectors with configurable schedules and presets (Off, Aggressive, Balanced, Low-Impact)
- Real-time alerts for blocking, deadlocks, and high CPU via system tray, email, or webhooks
- Built-in MCP server with 55+ tools for AI-powered analysis of monitoring data
- Graphical plan viewer with native ShowPlan rendering and operator-level cost breakdown
- Recommendations engine with informed-consent dialog for applying fixes directly

It provides deep SQL Server performance insights with AI integration, enabling proactive troubleshooting and optimization for RAG/AI stack builders managing SQL Server environments.
