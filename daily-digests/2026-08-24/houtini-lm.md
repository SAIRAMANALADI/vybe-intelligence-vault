## Summary
Houtini LM is an MCP server that offloads bounded, well-defined coding tasks from Claude Code to local or cloud-based LLMs, reducing token usage and costs. It acts as a bridge between an orchestrator (Claude Code) and various LLM endpoints, optimizing task delegation for efficiency.

## Key Features
- Seamless integration with Claude Code via MCP for task delegation
- Automatic model discovery and profiling using HuggingFace metadata
- Performance tracking with real-time token/s and TTFT metrics
- Dynamic model routing based on task type and model capabilities
- Persistent caching of model performance and token savings data

## Why It Matters for RAG Builders
It enables AI engineers to significantly reduce costs and latency by offloading routine coding tasks to local or cloud LLMs while keeping complex reasoning with high-end models like Claude.
