## Summary
Optimus Agent is a durable, local-first AI agent runtime with a native desktop shell, evidence-backed memory, policy-controlled tools, and multi-agent workflows. It supports Ubuntu and Windows, offering both Electron-based and legacy shells with robust process management and SQLite-backed state.

## Key Features
- Durable Rust runtime with SQLite state for persistent agent memory and workflows
- Policy-controlled tool execution with approval workflows and process cancellation
- Native desktop shell (Electron/React) with legacy fallback (Wry/Tao) for cross-platform support
- Multi-agent sessions, campaigns, and cron-based automation with streaming chat
- Strict versioning, parity checks, and performance regression testing for reliability

## Why It Matters for RAG Builders
Optimus Agent provides a robust, local-first framework for building and deploying AI agents with durable workflows, policy controls, and cross-platform desktop integration, critical for production-grade RAG and agentic systems.
