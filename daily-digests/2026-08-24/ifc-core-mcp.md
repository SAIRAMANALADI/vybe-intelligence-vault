## Summary
An MCP server providing structured access to the IFC4.3 specification (ISO 16739-1:2024) as a reference for AI systems. It enables lookup of IFC entity definitions, attributes, inheritance hierarchies, and PropertySets without parsing IFC model files.

## Key Features
- Structured access to IFC4.3 specification (ISO 16739-1:2024) as a reference
- Entity search by name or description keyword with dual Markdown/JSON output
- Retrieval of complete entity definitions including attributes, inheritance, WHERE rules, and documentation
- Inheritance tree visualization for ancestor and descendant hierarchies
- PropertySet lookup with full documentation and search capabilities

## Why It Matters for RAG Builders
It provides a critical reference layer for AI systems working with IFC data, enabling accurate and standardized lookups of entity definitions and relationships without requiring file parsing.
