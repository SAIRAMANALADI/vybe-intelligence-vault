## Summary
ProxyDoctor is a lightweight Go-based CLI and web tool for diagnosing network connectivity issues through proxies, including HTTP, HTTPS, SOCKS4, and SOCKS5. It compares direct and proxied connections, identifies misconfigurations, and exposes tested proxies as local forward proxies for immediate use.

## Key Features
- Comprehensive proxy diagnostics (DNS, IP leak, TLS, port connectivity, route tracing)
- Direct vs. proxied connection comparison for issue isolation
- Local forward proxy exposure for immediate browser/curl/wget usage
- Plugin system for extensibility (checks, exports, middleware)
- MCP server integration for AI assistant compatibility

## Why It Matters for RAG Builders
ProxyDoctor simplifies debugging proxy-related issues for AI engineers, ensuring reliable connectivity and secure proxy configurations in AI pipelines.
