## Summary
Commonlands MCP is a public Model Context Protocol (MCP) server for precision optics, enabling lens selection, field of view (FoV) calculations, and Shopify product verification. It provides live backend integration for optics data and read-only access to Shopify product catalogs for safe buyer handoffs.

## Key Features
- Live optics backend for lens catalog and FoV calculations via AWS Lambda and DynamoDB
- Read-only Shopify product verification with public data policy enforcement
- Safe buyer handoff to Shopify carts with explicit confirmation requirements
- Rate-limited and abuse-controlled public MCP endpoint
- Telemetry integration for observability without exposing sensitive data

## Why It Matters for RAG Builders
It provides a critical bridge between optics engineering and e-commerce, enabling AI agents to accurately select lenses and verify purchasable product details without exposing sensitive data or performing unauthorized writes.
