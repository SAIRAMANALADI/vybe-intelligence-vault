## Summary
A unified OpenAI-compatible API gateway aggregating 10+ domestic and international AI service providers, featuring reusable prompt workflows (Action/Template), quality monitoring, a management console, MCP server, and prepaid billing system.

## Key Features
- OpenAI-compatible API with automatic routing, failover, and cost optimization across 10+ providers
- Reusable prompt workflows (Action/Template) with versioning, dry-run, and quality monitoring
- MCP Streamable HTTP server with 28 tools for AI editors (Claude, Cursor, etc.)
- Prepaid balance system with atomic deductions and reconciliation against upstream billing
- Unified management console for keys, models, channels, and usage analytics

## Why It Matters for RAG Builders
It simplifies multi-provider AI API management by offering a single OpenAI-compatible endpoint with built-in routing, billing, and prompt engineering workflows, reducing integration complexity for RAG builders.
