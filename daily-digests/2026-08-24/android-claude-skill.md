## Summary
A Claude Code skill that enables AI agents to build, audit, and refactor Android applications following Google's architecture guidelines and best practices. It provides comprehensive patterns for Jetpack Compose, Clean Architecture, and Kotlin Multiplatform while enforcing code quality through a 10-dimension audit workflow.

## Key Features
- Enables AI agents to generate production-ready Android code following Google's architecture guidance
- Provides a 10-dimension code audit workflow for refactoring existing Android, Jetpack Compose, and KMP projects
- Includes pre-configured templates for Gradle version catalogs, settings, and feature modules
- Supports offline-first architecture with Room and reactive streams
- Integrates seamlessly with Claude Code for automated Android development tasks
