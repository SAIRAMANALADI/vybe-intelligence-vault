## Summary
An MCP server that integrates GitHub project management with AI-powered task generation, requirements traceability, and intelligent project planning. It transforms project ideas into actionable tasks with full end-to-end tracking from business requirements to implementation using GitHub's GraphQL API.

## Key Features
- AI-powered task generation and breakdown from PRDs
- End-to-end requirements traceability with bidirectional links
- Multi-provider AI support (Claude, GPT, Gemini, Perplexity)
- Full GitHub Projects v2 integration with real-time sync
- Enterprise-grade change management and impact analysis

## Why It Matters for RAG Builders
It bridges the gap between high-level AI planning and executable GitHub tasks, enabling seamless RAG workflows with traceable, AI-enhanced project management.
