## Summary
systemprompt-demo is a Windows desktop application that acts as a secure gateway for AI tools, enabling policy enforcement, audit logging, and cost tracking for interactions with external AI services like Claude. It operates as a local mediator to control data flow and ensure compliance.

## Key Features
- Enforces security policies for AI requests to prevent unauthorized data exfiltration
- Maintains detailed audit trails of all AI interactions, prompts, and tool calls
- Tracks and reports costs associated with AI agent workflows
- Operates as a lightweight background process with minimal system overhead
- Supports integration with Claude Code and other AI tools via local gateway
