## Summary
AgentRQ is a real-time collaboration platform enabling seamless interaction between human operators and AI agents via the Model Context Protocol (MCP). It provides a shared workspace for task management, agent delegation, and synchronized communication, supporting integrations with tools like Claude, Gemini CLI, and OpenAI Codex.

## Key Features
- Decoupled service-oriented architecture with Go backend and Vue.js frontend
- Real-time task and workspace synchronization via SSE and MCP
- Supervisor (CoreMCP) for global multi-workspace management and statistics
- Native integrations with Claude Code, Gemini CLI, and OpenAI Codex
- Google OAuth2 authentication with JWT-based session management

## Why It Matters for RAG Builders
AgentRQ streamlines AI-human collaboration by providing a unified platform for task delegation, real-time updates, and multi-agent orchestration, making it essential for building scalable RAG systems with human-in-the-loop capabilities.
