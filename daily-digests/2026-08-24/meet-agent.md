## Summary
A local-only AI agent named Tekki that joins Google Meet calls as a stick-figure avatar, listens to conversations, processes them using Ollama and Whisper, and responds with synthetic voice via Kokoro. All processing occurs on the user's machine without cloud dependency.

## Key Features
- Runs entirely on local hardware with no cloud dependency
- Integrates as a participant in Google Meet calls via device emulation
- Uses Ollama for LLM inference, Whisper for speech-to-text, and Kokoro for text-to-speech
- Stick-figure avatar rendering for low-latency, uncanny-valley-free interaction
- Telegram bot interface for meeting link submission and control

## Why It Matters for RAG Builders
It demonstrates a fully local, privacy-preserving AI agent framework that can participate in real-time video calls, showcasing how to integrate multiple local AI models for interactive applications.
