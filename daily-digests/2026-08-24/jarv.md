## Summary
Jarv is a scriptable, multi-provider AI agent designed to function like a Unix shell tool. It enables users to pipe input, script interactions, and leverage any AI model (cloud or local) for tasks like command execution, file editing, web searches, and parallel subagent orchestration.

## Key Features
- Supports any AI model (cloud or local) with provider switching via flags
- Scriptable one-shot mode and piped stdin for seamless integration with Unix pipelines
- Interactive session with persistent context, undo/redo, and history tree
- Parallel subagent orchestration for distributed task execution
- Built-in command safety controls with configurable confirmation levels
