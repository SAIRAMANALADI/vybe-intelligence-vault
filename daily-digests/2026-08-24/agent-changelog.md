## Summary
Agent Changelog is an automated tool that tracks and displays version updates for AI agent frameworks like OpenClaw and Hermes Agent by parsing GitHub Releases and generating browsable HTML changelogs with highlights and translations.

## Key Features
- Automated sync of GitHub Releases via daily cron jobs
- Parses and extracts 'Highlights' sections from release notes
- Generates clean, browsable HTML changelog pages
- Supports multilingual summaries (Chinese and English)
- GitHub Pages auto-deployment for accessibility

## Why It Matters for RAG Builders
It simplifies tracking and documenting updates for AI agent frameworks, ensuring RAG builders stay informed about critical changes without manual effort.
