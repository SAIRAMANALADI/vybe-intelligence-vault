## Summary
AI Canvas is a plugin for codex/claude code that enables bidirectional communication between AI agents and a visual canvas. It uses tldraw and shadcn/ui to render agent-generated content (text, images, videos, files) as interactive cards, which can be manipulated and later pulled back into the conversation flow.

## Key Features
- Real-time bidirectional communication between AI agents and a visual canvas using MCP Server
- Supports pushing text, Markdown, images, videos, audio, and files as interactive cards to the canvas
- Enables dragging, scaling, rotating, grouping, and annotating cards within the canvas
- Allows selecting cards and pulling their content back into the AI conversation via slash commands
- Integrates seamlessly with codex and claude code through MCP prompts and resources

## Why It Matters for RAG Builders
It bridges the gap between AI agents and visual collaboration, enabling richer, interactive, and persistent context sharing in RAG workflows.
