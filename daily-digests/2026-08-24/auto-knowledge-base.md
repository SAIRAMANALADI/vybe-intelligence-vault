## Summary
A lightweight MCP-compatible knowledge base system that enables zero-LLM retrieval with sub-10ms latency. It supports structured knowledge ingestion, role-aware search, and lifecycle management using SQLite with FTS5 and vector embeddings.

## Key Features
- Sub-10ms retrieval latency with zero LLM dependency
- BM25 full-text search combined with optional vector hybrid search (RRF fusion)
- Role-aware knowledge retrieval with diffusion activation for relevance
- Lifecycle management (staging → confirmed → FSRS-6 decay → frozen) with truth and provenance scoring
- 14 MCP tools for seamless integration with Claude Code, Cursor, and Windsurf

## Why It Matters for RAG Builders
It provides a high-performance, zero-LLM-dependency knowledge retrieval system essential for building scalable RAG pipelines with role-aware and lifecycle-managed knowledge.
