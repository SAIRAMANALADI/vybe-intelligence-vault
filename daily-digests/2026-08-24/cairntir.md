## Summary
Cairntir is a local-first, open-source memory system for AI coding agents that eliminates cross-session amnesia by providing persistent, verbatim storage of decisions, facts, and lessons. It operates as an MCP server, enabling seamless integration with clients like Claude Code, Cursor, and Codex.

## Key Features
- Verbatim, append-only memory storage with no summarization or loss of detail
- Prediction-bound drawers for structured reasoning and hypothesis tracking
- Belief-as-distribution ranking for calibrated memory retrieval and scoring
- MCP server compatibility for integration with Claude Code, Cursor, Codex, and other clients
- Portable signed format for team collaboration and gossip-able memory sharing

## Why It Matters for RAG Builders
Cairntir eliminates the productivity tax of re-explaining context to AI agents across sessions, enabling seamless, long-term memory retention for RAG and AI stack builders.
