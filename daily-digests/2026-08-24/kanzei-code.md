## Summary
A self-hosted AI coding agent built in Rust and Tauri that autonomously develops its own features by executing tasks from a backlog, including writing, testing, committing, and releasing code. It features a custom harness system for hard-gated rule enforcement, multi-agent collaboration, and transparent context management.

## Key Features
- Self-developing agent that writes, tests, and releases its own features from a backlog
- Custom harness system with hard-gated rules (permissions, state machines, citation integrity) enforced in code
- Multi-agent collaboration with dual personas (pair-programming and autonomous modes)
- Multi-channel LLM support (Codex, Claude, Kimi, Ollama) with subscription reuse and local model fallback
- Transparent context management with real-time progress tracking, event-sourced sessions, and SQLite persistence

## Why It Matters for RAG Builders
It provides a transparent, self-hosted framework for building autonomous AI agents that can iteratively develop and improve their own capabilities, reducing dependency on proprietary cloud services.
