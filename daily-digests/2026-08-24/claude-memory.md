## Summary
claude-memory is a persistent memory plugin for Claude Code that enables session continuity across crashes, restarts, or system maintenance by automatically saving and restoring important context and session data locally on Windows systems.

## Key Features
- Automatically saves session data between Claude Code runs
- Recovers sessions seamlessly after crashes or restarts
- Stores memory locally without external dependencies
- Minimal resource usage with background operation
- Cross-platform support for Windows 10+

## Why It Matters for RAG Builders
It ensures AI-driven workflows retain critical context and continuity, reducing manual re-input and improving productivity for developers using Claude Code.
