## Summary
Phi Browser is an open-source, native macOS browser built with AppKit and SwiftUI, designed for collaborative human-AI interaction. It integrates an AI agent capable of autonomous browsing, local memory storage, and on-device AI processing via Apple's Foundation Models or custom models.

## Key Features
- Native macOS app with AppKit and SwiftUI, not Electron-based
- AI agent that performs autonomous browsing tasks with visible action logs
- Local memory storage as editable files for transparency and control
- Supports on-device AI via Apple's Foundation Models or custom models (Ollama/LM Studio)
- Reusable agent skills defined in an open SKILL.md standard with runtime permissions

## Why It Matters for RAG Builders
Phi Browser enables seamless human-AI collaboration within a single native browser, offering transparency, local control, and autonomous agent capabilities critical for advanced RAG and AI workflows.
