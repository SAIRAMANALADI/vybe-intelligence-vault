## Summary
RTCF is a hosted MCP server that transforms rough user requests into structured, high-quality prompts using the Role, Task, Context, Format (RTCF) framework. It supports both English and Thai, integrates seamlessly with MCP clients like Claude and ChatGPT, and offers a free tier with 5 credits per day.

## Key Features
- Converts rough requests into structured prompts using RTCF framework (Role, Task, Context, Format)
- Supports both English and Thai languages
- Offers a free tier with 5 credits/day and no sign-up required
- Integrates with MCP clients like Claude and ChatGPT via custom connectors
- Provides a REST API for programmatic access and automation

## Why It Matters for RAG Builders
RTCF streamlines prompt engineering by automating the creation of structured, high-quality prompts, reducing manual effort and improving AI response consistency for RAG builders.
