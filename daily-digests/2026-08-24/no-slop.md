## Summary
No Slop is a local-first AI writing cleanup engine that detects and rewrites common LLM-generated text patterns, scores input quality, and flags structural issues requiring human review. It supports multiple interfaces including a browser UI, REST API, CLI, MCP server, and a Python backend.

## Key Features
- Deterministic cleanup of AI-generated text patterns (e.g., em-dash overload, filler phrases, inflated vocabulary)
- AI-writing detection with a 0-100 slop score and signal breakdown
- Multiple interfaces (browser UI, REST API, CLI, MCP server, Python backend) sharing a single core engine
- Human-in-the-loop review for structural issues and agent integration via MCP tools
- Local-first architecture with no hosted service or API key requirements

## Why It Matters for RAG Builders
It provides a robust, local-first solution for cleaning and scoring AI-generated text, essential for maintaining high-quality RAG datasets and improving AI output reliability.
