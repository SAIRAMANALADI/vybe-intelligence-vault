## Summary
A decentralized AI-powered platform for community-owned mineral resource governance, designed to detect exploitation, track extraction, and automate revenue distribution via smart contracts. Built for Kenyan miners using NVIDIA's Superagent Blueprint and Polygon blockchain.

## Key Features
- Five sovereign AI agents (Sentinel, Auditor, Advocate, Oracle, Ambassador) for monitoring, finance, legal, market, and community engagement
- Automated revenue distribution via smart contracts (70/20/10 split) on Polygon PoS
- Exploitation detection using fair deal calculators and geological analysis tools
- Multi-modal AI pipeline combining vision (EfficientNet-B4), satellite imagery (Sentinel-2), and quantum ML (experimental)
- Offline-first Flutter mobile app with Swahili and local language support

## Why It Matters for RAG Builders
It provides a decentralized, AI-driven framework to empower communities with real-time mineral intelligence, automate fair revenue distribution, and detect exploitation, addressing systemic resource extraction injustices in Africa.
