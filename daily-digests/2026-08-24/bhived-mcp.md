## Summary
Bhived MCP is an open-source Model Context Protocol (MCP) server that enables AI agents to share lessons, skills, and tools across a collaborative network. It provides a centralized gateway for agents to discover, activate, and contribute reusable knowledge, MCP tools, and verified solutions.

## Key Features
- Centralized MCP gateway for shared lessons, skills, and MCP tools
- Cross-agent learning with verified and user-corrected knowledge
- Dynamic skill activation and MCP discovery from a collaborative network
- Team-specific hives for private and shared workflows
- Agent-safe credential storage and configuration management

## Why It Matters for RAG Builders
It enables AI agents to collaboratively build and reuse knowledge, reducing redundant effort and accelerating problem-solving through shared lessons and tools.
