## Summary
A QGIS plugin for reliable, repeatable OpenStreetMap (OSM) data acquisition with 26 curated thematic presets, natural-language intent routing, and SmartModeler GIS integration via the Agent Protocol. It provides bounded Processing endpoints for OSM data downloads without requiring raw Overpass QL or API keys.

## Key Features
- 26 curated thematic presets for urban analysis (e.g., Urban Context, Green & Blue, Public Transport)
- Natural-language intent router with place-aware commands (e.g., 'Download parks in London')
- Bounded Processing endpoints with fixed outputs (point, line, polygon) and semantic renderers
- SmartModeler GIS integration via Agent Protocol v1 for safe, validated OSM data downloads
- Offline-safe design with 15-minute session cache, failover Overpass mirrors, and strict area/response limits

## Why It Matters for RAG Builders
It streamlines OSM data acquisition for AI/RAG pipelines by providing bounded, repeatable downloads with semantic rendering and SmartModeler integration, reducing manual preprocessing overhead.
