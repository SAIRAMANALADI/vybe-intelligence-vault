## Summary
ComputeLedger is a CLI, library, and MCP server for generating cryptographically signed receipts of compute usage (GPU-hours, hardware, duration) and maintaining a tamper-evident local ledger. It enables independent verification of compute claims without relying on any specific cloud provider or external service.

## Key Features
- Generates cryptographically signed compute usage receipts (Ed25519 signatures) for GPU-hours, hardware, and duration
- Maintains a hash-chained local ledger to ensure tamper-evidence and integrity of historical records
- Cross-language interoperability via deterministic canonical-JSON serialization for receipts
- Agent-native design with MCP server support for structured tooling and JSON output
- Provider-agnostic and offline-verifiable, requiring no accounts, APIs, or network calls

## Why It Matters for RAG Builders
It provides a portable, independently verifiable proof of compute usage that bridges gaps in trust between providers and consumers, essential for auditing and accountability in multi-cloud or on-prem environments.
