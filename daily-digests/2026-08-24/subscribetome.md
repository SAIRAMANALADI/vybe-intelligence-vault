## Summary
subscribetome is a secure API key and subscription manager for Claude Code that integrates with the OS keychain to prevent API keys from ever being exposed in chat. It enables secure key management, real-time spend tracking, and multi-user team attribution for AI workflows.

## Key Features
- Secure API key storage in OS keychain with zero exposure in chat
- Real-time spend tracking and inventory management via local dashboard
- Multi-user team attribution with Ed25519 signing identities
- Credential broker for server-side key injection to prevent leaks
- Defense-in-depth security hardening and audit logging

## Why It Matters for RAG Builders
It eliminates a critical security risk in AI workflows by ensuring API keys never touch the chat interface, while enabling scalable team collaboration with verified attribution.
