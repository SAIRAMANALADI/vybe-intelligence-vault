## Summary
Elixir client library for PaveDB, a vector database, enabling Elixir applications to connect, interact, and perform vector search operations with a PaveDB HTTP server while adhering to its OpenAPI contract.

## Key Features
- Connects to PaveDB HTTP server with tenant and API key support
- Provides high-level and low-level helpers for collection and document operations
- Supports vector search with configurable parameters (k, filters)
- Includes query replay functionality for debugging and analysis
- Returns structured {:ok, value} or {:error, %PaveDBClient.Error{}} responses

## Why It Matters for RAG Builders
This client enables seamless integration of PaveDB's vector search capabilities into Elixir applications, critical for RAG pipelines requiring efficient document retrieval.
