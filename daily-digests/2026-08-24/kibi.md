## Summary
Kibi is a repo-local, per-git-branch knowledge base for software projects that stores and links entities like requirements, tests, architecture decisions, and code symbols to ensure end-to-end traceability. It provides a queryable Prolog-based knowledge graph with MCP and CLI interfaces for AI agents and developers.

## Key Features
- Repo-local, branch-specific knowledge base with automatic synchronization via git hooks
- Eight core entity types (requirements, tests, ADRs, events, etc.) with strict modeling rules
- MCP and CLI interfaces for AI agents and developers to query/update the knowledge base
- Automated validation and traceability checks to prevent orphaned features and technical debt
- Semantic advisor for modeling requirements into machine-checkable facts and predicates

## Why It Matters for RAG Builders
Kibi provides a structured, verifiable memory layer for AI agents during software development, ensuring traceability between code and documentation while enabling agents to query and update project knowledge without risking file corruption.
