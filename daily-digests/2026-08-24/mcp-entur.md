## Summary
mcp-entur is a Model Context Protocol (MCP) server providing real-time access to Norway's public transport data (Entur) across all modes and regions. It serves as a gateway for AI agents to query nationwide transport schedules, stops, and routes via standardized MCP tools.

## Key Features
- Provides nationwide access to Norway's public transport data (Entur)
- Integrates with MCP clients (Claude Desktop, Cursor, Windsurf, etc.)
- Supports plain English queries via ask_pipeworx for simplified agent interactions
- Part of a larger gateway (Pipeworx) with 1325+ live data sources
- MIT licensed for open-source adoption

## Why It Matters for RAG Builders
It enables AI agents to seamlessly access real-time Norwegian public transport data, critical for travel planning and logistics applications.
