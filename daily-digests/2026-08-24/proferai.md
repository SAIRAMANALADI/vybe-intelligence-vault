## Summary
ProferAI is a local-first AI desktop application built on the Claude Agent SDK, enabling multi-model AI interactions, collaborative sub-agents, scheduled task automation, and team workspace collaboration. It supports remote tablet access and integrates with various AI providers for chat and agent workflows.

## Key Features
- Multi-model AI chat and agent support with Anthropic, DeepSeek, Kimi, and others
- Collaborative sub-agent workflows for parallel task execution and result aggregation
- Scheduled task automation with persistent scheduling and failure recovery
- Team workspace with role-based access control, skills sharing, and file synchronization
- Remote tablet access via Capacitor for mobile interaction with desktop agent

## Why It Matters for RAG Builders
ProferAI provides a robust framework for building and deploying AI agents with collaboration and automation capabilities, essential for teams scaling AI workflows beyond individual use cases.
