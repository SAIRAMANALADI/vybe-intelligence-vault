## Summary
rokadoc-mcp-server enables AI assistants to interact with NTT Docomo's RAG service 'rokadoc' via the Model Context Protocol (MCP), allowing document conversion and retrieval through standardized MCP clients like VS Code, Kiro, and Claude Desktop.

## Key Features
- Exposes rokadoc RAG service capabilities as MCP tools for seamless AI assistant integration
- Supports document conversion (PDF, Word, Excel, PowerPoint) with page range filtering
- Provides RAG search functionality with tag-based filtering and space-specific queries
- Configurable via environment variables for API keys and base URLs (including on-premises)
- Supports multiple MCP clients (VS Code, Kiro, Claude Desktop) with detailed setup instructions

## Why It Matters for RAG Builders
It bridges NTT Docomo's rokadoc RAG service with MCP-compatible AI assistants, enabling direct document processing and retrieval workflows for AI engineering stacks.
