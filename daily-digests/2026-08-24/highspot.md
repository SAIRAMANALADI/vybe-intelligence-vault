## Summary
Highspot is a sales enablement platform providing a REST API and MCP Server for managing content, training programs, pitch analytics, CRM integrations, and AI-driven sales workflows. It enables AI agents to interact with sales enablement data and tools via standardized protocols.

## Key Features
- REST API for content, users, groups, pitches, and analytics management
- MCP Server enabling LLMs to search content, manage pitches, and generate Digital Rooms
- OAuth 2.0 and API key authentication for secure access
- Insights Layer APIs for AI-driven sales workflows
- SOC 2 Type 2 and ISO 27001:2022 certified for security and compliance
