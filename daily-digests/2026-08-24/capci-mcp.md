## Summary
Capci MCP is a remote Model Context Protocol (MCP) server that converts plain-text prompts into publish-ready diagrams, charts, and animated visuals without leaving AI tools like Claude, VS Code, or Antigravity. It eliminates the need for manual diagramming by generating architecture, sequence, ER, and other diagram types directly from AI agent interactions.

## Key Features
- Generates multiple diagram types (architecture, sequence, ER, flowchart, etc.) from plain-text prompts
- Supports animated diagram exports (GIFs) for dynamic visualizations
- Integrates seamlessly with AI tools like Claude, VS Code, and Antigravity via MCP
- Offers branded diagram generation with customizable themes and logos
- Provides refinement tools to iteratively adjust diagrams in-place

## Why It Matters for RAG Builders
Capci MCP streamlines the AI-to-diagram workflow by enabling agents to generate publish-ready visuals directly within their tools, eliminating manual diagramming steps and accelerating AI-driven documentation and design processes.
