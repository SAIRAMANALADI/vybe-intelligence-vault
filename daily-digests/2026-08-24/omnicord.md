## Summary
Omnicord is an MCP server that enables AI assistants to control and automate Discord server operations, including chat, moderation, administration, and full server building from natural language briefs. It acts as a secure bridge between AI clients and Discord, enforcing safety gates for destructive actions.

## Key Features
- 150+ tools for Discord operations including messaging, moderation, and server structure management
- Destructive actions gated behind preview and confirmation tokens for safety
- Supports both stdio and HTTP transports with robust security controls
- Automated server building from natural language briefs with blueprint saving and diffing
- Real-time event subscriptions and live server diagnostics

## Why It Matters for RAG Builders
Omnicord provides a secure, AI-native interface to Discord, enabling RAG builders to integrate real-time community management and automation into their AI agents without exposing sensitive bot tokens or requiring cloud services.
