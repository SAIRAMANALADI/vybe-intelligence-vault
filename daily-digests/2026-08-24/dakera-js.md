## Summary
TypeScript/JavaScript SDK for Dakera AI, a self-hosted memory engine enabling AI agents to store, recall, and search memories with hybrid vector and full-text capabilities. The SDK supports agent memory, sessions, knowledge graphs, and real-time streaming for RAG workflows.

## Key Features
- Agent memory management with importance scoring and sessions
- Hybrid search combining vector similarity and BM25 full-text search
- Knowledge graph traversal and entity extraction for structured memory
- Real-time streaming (SSE) for event-driven memory updates
- Cross-platform compatibility (Node.js, browsers, Deno, Bun, Cloudflare Workers)

## Why It Matters for RAG Builders
It provides a robust, self-hosted memory engine for AI agents with hybrid search and knowledge graph capabilities, reducing dependency on external vector databases and embedding services for RAG pipelines.
