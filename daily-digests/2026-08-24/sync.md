## Summary
Sync is a local-first desktop application and CLI tool that enables developers to manage AI agents by providing structured context, automatic staleness tracking, and block-by-block code review. It ensures agents adhere to project specifications and decisions while maintaining full control over code merges into the main branch.

## Key Features
- Structured project specifications and acceptance criteria drafted by agents and reviewed by users
- Block-by-block code review with explanations, ensuring nothing merges without explicit user approval
- Automatic staleness tracking for decisions and documentation, flagging outdated entries in real-time
- Built-in MCP server for seamless integration with AI agents like Claude Code, Codex, and OpenCode
- Local-first architecture with no SaaS, telemetry, or external dependencies

## Why It Matters for RAG Builders
Sync provides a critical control layer for AI-driven development workflows, ensuring agents operate within clear, user-approved boundaries while automating tedious review and documentation tasks.
