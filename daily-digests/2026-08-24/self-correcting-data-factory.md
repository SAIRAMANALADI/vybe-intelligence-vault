## Summary
An automated, self-healing B2B lead enrichment pipeline that ingests digital footprints, audits scraped company profiles, and outputs validated datasets for outbound campaigns. It orchestrates search API fallbacks, LLM-based audits, and schema validation to ensure high-quality target intelligence.

## Key Features
- Automated search API fallbacks (Serper, Tavily, Jina Reader, Firecrawl) to bypass bot blocks and unstructured HTML
- Structured LLM audits with auto-correction for empty or invalid data values
- Human-in-the-Loop (HITL) governance for final dataset validation and brand alignment
- 80/15/5 architectural pattern for clean separation of ingestion, logic, and validation layers
- Token-optimized content truncation and deterministic schema validation

## Why It Matters for RAG Builders
