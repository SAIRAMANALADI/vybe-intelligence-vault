## Summary
thingctx converts API, device, or process descriptions into secure, transport-agnostic AI agent tools using W3C Web of Things Thing Descriptions. It enables agents to interact with systems without holding credentials, supporting HTTP, MQTT, RTSP, subprocess, and custom transports while enforcing granular authorization and approval policies.

## Key Features
- Converts Thing Descriptions (TD) or OpenAPI specs into AI agent tools without exposing credentials to the agent
- Supports multiple transports (HTTP, MQTT, RTSP, subprocess, custom) per call with granular routing
- Enforces two-layer security: approval gating (human-in-the-loop) and policy-based authorization (per caller/operation)
- Integrates with LLM providers via litellm for seamless agent loops
- Provides MCP bridge for agents requiring MCP tool delivery

## Why It Matters for RAG Builders
thingctx enables secure, multi-protocol AI agent interactions with any system by abstracting descriptions into tools while keeping credentials and authorization policies under strict control.
