## Summary
ForgeTeam is an open-source AI coding framework that enables a single developer to deliver full-stack projects with team-like efficiency. It uses a pure Shell + Markdown architecture with zero dependencies, integrating seamlessly with AI tools like Claude Code, Cursor, Codex, and OpenCode.

## Key Features
- Automated task routing based on change scale (Micro/Standard/Full workflows)
- Four-stage verification gate (Build → Test → Run → Safety) for code quality assurance
- Cross-session memory and self-evolution capabilities for continuous improvement
- Extensible architecture with support for custom skills and enterprise integrations
- Multi-platform compatibility with native support for Claude Code, Cursor, Codex, and OpenCode
