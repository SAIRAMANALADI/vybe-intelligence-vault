## Summary
agent-audit is a security tool designed to audit AI coding agents like Claude Code, Codex CLI, and OpenClaw for vulnerabilities, misconfigurations, and insecure practices. It scans project files, plugins, and session histories against 296 security rules to identify risks such as prompt injection, insecure file access, and improper plugin storage.

## Key Features
- Scans 296 security rules covering prompt injection, insecure file access, and plugin misconfigurations
- Local-first execution with no data uploads to external servers
- Supports custom rule toggling and exclusions for false positives
- Automatically detects common agent folders (.claude-code, .codex, etc.)
- Provides risk-level categorization (Critical, Warning, Info) with actionable insights

## Why It Matters for RAG Builders
It ensures AI coding agents operate securely by identifying vulnerabilities in configurations and session histories before they are exploited.
