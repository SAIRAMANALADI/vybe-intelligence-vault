## Summary
A Docker-based system for securely running Claude Code with Remote Control on a VPS, featuring multi-session management, GitHub OAuth authentication, and automated workspace isolation.

## Key Features
- Multi-session web-based manager for creating, controlling, and destroying isolated Claude Code sessions
- GitHub OAuth authentication with ACL-based access control for secure multi-user environments
- Automatic HTTPS provisioning via Caddy with Let's Encrypt certificates
- Sandboxed workspaces with isolated Docker volumes for each session
- Dynamic GitHub token injection for seamless repository access without SSH keys

## Why It Matters for RAG Builders
It enables secure, scalable, and user-friendly deployment of Claude Code agents on VPS infrastructure with robust access control and workspace isolation.
