## Summary
A minimal-dependency Python coding agent framework designed for daily use and customization, ported from an Emacs-based agent harness. It provides a robust agent loop, context management, and safety features for autonomous or semi-autonomous coding tasks.

## Key Features
- Agent loop with completion supervision and tool-result sanitization
- CJK-aware token estimation and automatic context compaction
- Rich set of OpenAI-compatible tools (Edit, Bash, Glob, Grep, etc.)
- Plan/Build modes with read-only constraints and safety tiers
- Persistent sessions, undo/redo, and TUI-based slash commands

## Why It Matters for RAG Builders
It provides a lightweight, customizable framework for building and deploying autonomous coding agents with built-in safety and context management, reducing integration overhead for RAG stacks.
