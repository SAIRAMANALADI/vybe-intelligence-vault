## Summary
storeshots-mcp is an MCP (Model Context Protocol) server that automates the generation of pixel-perfect App Store and Google Play screenshots for mobile apps. It renders device frames, branded headlines, and exact store dimensions locally, enabling AI agents to produce polished visuals without manual design work or external services.

## Key Features
- Generates pixel-perfect App Store and Google Play screenshots with exact store dimensions
- Renders device frames (iPhone, Android, iPad, tablet) programmatically
- Supports multi-language sets with correct typography and special characters
- Deterministic output ensuring consistent results for the same input
- Integrates seamlessly with any MCP-capable AI agent (Claude, Cursor, VS Code, etc.)

## Why It Matters for RAG Builders
It eliminates the manual and time-consuming process of creating store-ready screenshots, allowing AI agents to automate marketing asset generation for mobile apps with zero external dependencies.
