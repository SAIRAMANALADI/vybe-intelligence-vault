## Summary
Baymax is a robotics simulation prototype for a forward-deployed nurse robot that performs hospital safety rounds, listens to patient speech, detects vital signs, and escalates incidents via structured API dispatch. It combines MuJoCo physics, Gemini Robotics-ER for high-level skill selection, and a safety-constrained controller for deterministic navigation and dispatch.

## Key Features
- MuJoCo-based physics simulation for realistic robot dynamics and collision detection
- Gemini Robotics-ER integration for vision-grounded high-level skill selection
- Safety-constrained controller ensuring deterministic navigation and incident dispatch
- Structured API-based incident escalation with replayable evidence bundles
- Headless validation and visual simulation modes for testing and demonstration

## Why It Matters for RAG Builders
Baymax demonstrates a critical loop for embodied AI in healthcare by integrating perception, navigation, speech processing, and structured incident escalation in a reproducible simulation environment.
