## Summary
Relay is an open-source AI-powered job application infrastructure that automates job discovery, resume customization, and application preparation while preserving user control over final submissions. It combines a web workspace, agents, and a browser extension to streamline the job search process without compromising user agency or data privacy.

## Key Features
- Career Graph for verifiable resume data and immutable history
- Multi-agent system (Resume, JobMatch, AppPrep, Interview) orchestrated via LangGraph
- Client-side delivery via Chrome Manifest V3 extension for secure form filling
- Human-in-the-loop (HITL) gates for final review and submission control
- PostgreSQL + pgvector for structured data and vector search capabilities

## Why It Matters for RAG Builders
Relay provides a trustworthy, agent-driven framework for automating job search tasks while ensuring user oversight, making it ideal for RAG builders seeking to integrate verifiable, human-validated AI workflows.
