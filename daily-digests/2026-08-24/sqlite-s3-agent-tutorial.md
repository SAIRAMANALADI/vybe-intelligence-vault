## Summary
A tutorial repository demonstrating a serverless agent architecture using SQLite as a state store, rehydrated from S3, with AWS Lambda and Amazon Bedrock for LLM interactions. The example includes a Discord bot that fetches weather and Bitcoin data, processes it via an LLM, and posts updates to Discord.

## Key Features
- Serverless agent architecture with no database server required
- State persistence via SQLite file stored in S3
- Integration with Amazon Bedrock for LLM-powered message generation
- Discord bot for real-time updates
- Cost-effective design with minimal AWS resource usage
