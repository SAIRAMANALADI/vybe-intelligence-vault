## Summary
This repository provides an accelerator for deploying and inspecting Azure AI Search MCP Server and Fabric Ontology Knowledge Sources through Foundry IQ, enabling source-level evidence for every answer. It supports live validation of knowledge sources without requiring Azure or Fabric resources upfront.

## Key Features
- Supports MCP Server and Fabric Ontology Knowledge Sources for live grounding
- Provides source-level evidence for every answer with inspectable activity, references, and sourceData
- Offers multiple deployment profiles (offline, mcp-only, byo-fabric, full) for flexibility
- Includes plan-first automation for validating tools, configuration, and cloud resources
- Features ownership-aware cleanup to delete generated Azure and Fabric assets while preserving BYO resources

## Why It Matters for RAG Builders
This accelerator streamlines the integration of live knowledge sources into RAG pipelines, ensuring traceable, governed, and evidence-backed responses for AI applications.
