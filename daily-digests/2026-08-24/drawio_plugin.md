## Summary
A Draw.io MCP plugin that extends the upstream `@drawio/mcp` server to generate native, fully-editable draw.io diagrams from natural language prompts. It adds 13 builder tools, validation pipelines, and domain-specific corrections for high-quality, editable diagrams across AI coding assistants like Kiro, Claude, Cursor, and Copilot CLI.

## Key Features
- Extends upstream `@drawio/mcp` with 13 additional builder tools for diagram construction
- Includes validation pipelines and topological correction engines for high-quality output
- Supports domain-specific validators (AWS, PFD/P&ID, mining, etc.)
- Multi-client compatibility (Kiro, Claude, Cursor, Copilot CLI, Antigravity)
- Enables round-trip editing of existing `.drawio` files

## Why It Matters for RAG Builders
It bridges the gap between natural language prompts and native draw.io diagrams, enabling AI agents to generate fully editable, high-fidelity diagrams for architecture, engineering, and documentation workflows.
