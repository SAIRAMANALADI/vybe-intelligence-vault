## Summary
Xquik is a production-grade Twitter/X scraper API and alternative to the official X API, offering structured data access for tweets, profiles, followers, engagement metrics, and more. It provides REST APIs, typed SDKs, MCP tools, webhooks, and exports for AI agents and production applications.

## Key Features
- 126 REST API operations for comprehensive X data access (tweets, profiles, followers, engagement, etc.)
- MCP v2.5.4 with 118 MCP operations for AI agent integration (Claude, Codex, Cursor, etc.)
- HMAC webhooks and real-time monitoring for event-driven workflows
- 23 extraction tools with usage estimates and support for bulk exports (CSV, JSON, PDF, etc.)
- Confirmation-gated writes for safe publishing actions (tweets, replies, likes, etc.)

## Why It Matters for RAG Builders
