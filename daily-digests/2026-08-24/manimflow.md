## Summary
ManimFlow is a Streamlit-based AI agent that converts natural-language animation requests into rendered Manim videos. It autonomously plans scenes, generates Manim code, repairs errors, and produces MP4 outputs with optional YouTube uploads.

## Key Features
- Converts text prompts into Manim animations with autonomous AI agents
- Live progress streaming and error repair loop for robust rendering
- VS Code-style Monaco file explorer for generated Manim code
- Isolated workspaces for each render to ensure clean execution
- Optional YouTube upload with encrypted OAuth and resumable transfers

## Why It Matters for RAG Builders
ManimFlow streamlines the creation of high-quality animations from natural language, reducing manual coding effort and enabling rapid prototyping for AI-driven video generation pipelines.
