## Summary
Seshat is an open-source Go agent runtime designed for governed, multi-provider, self-hostable execution of AI agents. It provides a headless engine for running autonomous agent workflows with built-in tools, MCP integration, and multi-provider routing, enabling developers to embed or deploy agentic systems under their own control.

## Key Features
- Governed multi-turn agent execution with persistent sessions and audit trails
- Multi-provider routing supporting 15+ LLM providers and 60+ built-in tools
- Self-hostable deployment with CLI, gRPC, and Go SDK interfaces
- Sandboxed execution environments for tools like file edits, bash, and web browsing
- MCP integration for extensibility and modular agentic workflows

## Why It Matters for RAG Builders
Seshat provides a critical open-source runtime layer for building governed, multi-provider AI agents without vendor lock-in, enabling developers to deploy autonomous agent systems under their own infrastructure.
