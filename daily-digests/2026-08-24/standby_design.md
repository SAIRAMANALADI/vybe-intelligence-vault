## Summary
A collection of lightweight, client-side design tools for developers and designers, including an OKLCH-based color palette generator with no build steps or dependencies. Features pure HTML/CSS/JS implementations for rapid prototyping and deployment.

## Key Features
- Interactive OKLCH-based color palette generator with no dependencies
- Supports two modes: Balanced Midpoint and Exact Brand Match
- 18-step surface hierarchy for light, core, dark, and high-contrast modes
- Click-to-copy and CSS export for seamless integration
- Zero build step, pure HTML/CSS/JS with Dockerized deployment

## Why It Matters for RAG Builders
Provides essential client-side tools for generating and managing design tokens, particularly OKLCH color palettes, which are critical for consistent and accessible AI-driven design systems.
