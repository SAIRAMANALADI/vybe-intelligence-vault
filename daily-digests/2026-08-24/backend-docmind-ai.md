## Summary
A .NET 8 backend implementing a Clean Architecture + CQRS RAG system for document processing and AI-powered question answering. Users upload PDF/DOCX files, and the system extracts, chunks, embeds, and stores content in Qdrant for retrieval, enabling grounded answers with citations.

## Key Features
- Clean Architecture + CQRS backend with MediatR for structured command/query handling
- End-to-end RAG pipeline: document upload, text extraction, chunking, embedding, and vector storage in Qdrant
- Real-time streaming answers with page-level citations via SignalR and Semantic Kernel
- Multi-provider LLM support (OpenAI or GitHub Models) with Redis caching for embeddings
- Production-ready deployment with Docker, PostgreSQL, Redis, and Hangfire for background jobs

## Why It Matters for RAG Builders
It provides a production-grade, modular backend for RAG systems with a focus on document processing, vector storage, and real-time AI-powered Q&A, making it essential for AI stack builders.
