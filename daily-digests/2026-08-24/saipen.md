## Summary
SAIPEN is a vendor-neutral continuation protocol for AI coding agents that enables seamless project resumption with zero rebriefing. It uses a state-based system to track project tasks, allowing agents to pick up work without relying on model memory.

## Key Features
- State-based project resumption with `/saipen continue` for instant task pickup
- Automated evolution via HUNT/ADD cycles for continuous software improvement
- GOAL mode for dynamic objective pivoting without task loss
- Multi-agent coordination support via extensions for concurrent agent operation
- Zero dependencies and vendor-neutral design for broad compatibility

## Why It Matters for RAG Builders
SAIPEN eliminates the need for rebriefing agents by externalizing project memory, making it essential for building robust, long-running AI-driven development workflows.
