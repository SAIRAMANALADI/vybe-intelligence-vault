## Summary
A cross-platform AI agent skill, plugin, and MCP server that enables editable MathType 7 equations in Microsoft Word and PowerPoint. It integrates with Codex, Claude, and ChatGPT to provide native equation numbering, dynamic references, and direct PowerPoint equation insertion via COM automation.

## Key Features
- Creates editable Equation.DSMT4 OLE objects in Word and PowerPoint instead of images or Unicode
- Supports inline, centered, and numbered equations with dynamic cross-references
- Integrates with Codex, Claude, and ChatGPT via MCP or plugin architecture
- Preserves source Office files and validates generated output
- Provides portable skill and local MCP server for seamless AI agent workflows

## Why It Matters for RAG Builders
It bridges AI agents with Microsoft Office for professional-grade equation editing, enabling RAG systems to generate and manipulate editable mathematical content directly in documents.
