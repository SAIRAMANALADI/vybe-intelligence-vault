## Summary
A Model Context Protocol (MCP) proxy server for Google Stitch, enabling AI-powered UI design generation directly from the terminal via tools like Claude Code. It bridges the Stitch API with MCP to facilitate screen generation, design system management, and variant creation.

## Key Features
- Proxies Google Stitch API via MCP for terminal-based UI design generation
- Dynamic tool fetching from Stitch API at startup for real-time functionality
- Auto-enrichment of design system context in variant generation prompts
- Supports natural language editing of existing screens and projects
- Integrates with Claude Code for seamless AI-driven design workflows

## Why It Matters for RAG Builders
It enables AI agents like Claude Code to generate, edit, and iterate on UI designs programmatically, bridging the gap between AI workflows and design tools.
