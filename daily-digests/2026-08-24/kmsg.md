## Summary
kmsg is an unofficial CLI and native MCP server for KakaoTalk on macOS, enabling users to read, monitor, and send messages via Accessibility automation. It provides structured JSON output for AI agents and local automation workflows.

## Key Features
- Read and monitor KakaoTalk messages in real-time with structured JSON output
- Send text and images via Accessibility-controlled UI automation
- Native MCP server for AI agents (Claude Code, Codex) with dry-run safety checks
- Background-safe operations with self-healing AX path cache and recovery modes
- Homebrew-supported installation and skill integration for AI coding agents

## Why It Matters for RAG Builders
It enables AI agents and automation tools to interact with KakaoTalk on macOS, bridging a critical gap for users in regions where KakaoTalk is dominant but lacks official API support.
