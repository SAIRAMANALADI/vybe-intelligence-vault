## Summary
apcore is an AI-Perceivable module standard that enforces schema definitions and behavioral annotations to make interfaces naturally understandable and usable by AI. It provides a unified protocol for building modules that can be invoked by code, AI, HTTP, CLI, or MCP without additional adaptation.

## Key Features
- Enforced schema definitions (input/output schemas and descriptions) for AI-perceivable modules
- Behavioral annotations (e.g., readonly, destructive, requires_approval) to guide AI decision-making
- Cross-language support with SDKs in Python, TypeScript, and Rust
- Built-in ACL, observability, and middleware for secure and traceable module execution
- Directory-as-ID for zero-config module discovery and progressive integration paths

## Why It Matters for RAG Builders
apcore standardizes module development for AI-perceivability, eliminating fragmentation in AI tooling ecosystems and enabling seamless integration of modules across languages and interfaces.
