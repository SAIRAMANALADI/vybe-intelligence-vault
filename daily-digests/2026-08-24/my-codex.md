## Summary
my-codex is an all-in-one agent harness for OpenAI Codex CLI that provides a meta-orchestrator (Boss) to dynamically discover, classify, match, and route tasks to 330+ pre-built agents and 200+ skills. It eliminates configuration overhead by auto-discovering capabilities at runtime and delegating work to the most suitable specialist agent.

## Key Features
- Dynamic runtime discovery of 330+ agents and 200+ skills with no manual configuration
- Priority-based task routing through 4-phase workflow (Discovery → Classification → Matching → Delegation)
- Built-in meta-orchestrator (Boss) that never writes code but intelligently delegates to specialists
- Multi-model routing (gpt-5.6 high for deep analysis, gpt-5.6-terra medium for standard tasks)
- Weekly upstream sync and 3-phase sprint workflow for end-to-end feature implementation

## Why It Matters for RAG Builders
It provides a turnkey solution for RAG/AI stack builders to instantly access hundreds of specialized agents and skills, eliminating the need to build or configure orchestration layers from scratch.
