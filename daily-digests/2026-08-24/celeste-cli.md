## Summary
Celeste CLI is a premium, agentic terminal AI assistant with a corrupted-aesthetic TUI built on Go and Bubble Tea. It functions as a standalone agentic development tool with 45 built-in tools, code graph analysis, semantic search, and multi-provider LLM support.

## Key Features
- Premium TUI with corrupted-aesthetic styling and flicker-free rendering using Bubble Tea
- 45 built-in tools including file I/O, shell, web search, code review, git, crypto, and subagent orchestration
- Code graph with MinHash+BM25 fusion, structural reranking, and tree-sitter parsing for accurate call-graph edges
- Multi-provider support (Grok, OpenAI, Anthropic, Gemini, Sakana, Venice.ai, Vertex AI, OpenRouter)
- Session persistence with JSONL auto-save, resume, and cost tracking with live pricing display

## Why It Matters for RAG Builders
Celeste CLI provides a robust, agentic terminal interface with deep code analysis and semantic search capabilities, making it essential for AI engineers building RAG systems that require structured code understanding and autonomous tool execution.
