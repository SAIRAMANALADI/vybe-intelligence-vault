## Summary
A progressive tutorial repository that deconstructs the core mechanisms of AI agents like Claude Code, Cursor, and Devin through six minimal demos. Each demo isolates a key component (e.g., ReAct loop, memory, tools, planning, multi-agent collaboration, safety) to build foundational understanding.

## Key Features
- Six orthogonal demos breaking down agent components (ReAct loop, memory, tools, planning, multi-agent, safety)
- Single-file implementations (200-600 lines) for easy understanding and execution
- Comprehensive teaching materials including scripts, videos, and runnable logs
- Modular design allowing independent exploration of each concept
- Compatibility with Anthropic SDK and BigModel API for flexible deployment

## Why It Matters for RAG Builders
It provides a hands-on, foundational understanding of AI agent architectures, enabling developers to build custom agents with core components like memory, tools, and safety constraints.
