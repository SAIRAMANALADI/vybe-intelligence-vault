## Summary
md2do is a CLI tool and ecosystem for managing TODO items directly within markdown files, offering smart parsing, rich filtering, native Todoist sync, multi-source ingestion, and AI integration via MCP. It bridges markdown-based task management with modern productivity tools like Obsidian, VS Code, and AI assistants.

## Key Features
- Markdown-native TODO parsing with rich metadata (assignees, priorities, due dates, tags)
- Native two-way sync with Todoist API for seamless task synchronization
- Multi-source ingestion from Teams, Outlook, Slack, or JSONL without requiring API credentials
- AI-powered MCP server for integration with Claude and other AI assistants
- Obsidian plugin and VS Code integration for enhanced task visibility and management

## Why It Matters for RAG Builders
md2do streamlines task management for developers who prefer markdown by integrating with modern AI tools and productivity platforms, enabling seamless synchronization and AI-driven task analysis.
