## Summary
A local Retrieval-Augmented Generation (RAG) pipeline designed for company policy question answering, transforming raw documents into an AI-ready knowledge base with document processing, embeddings, vector search, and local LLM answer generation.

## Key Features
- End-to-end RAG pipeline from raw documents to answer generation
- Semantic retrieval with ChromaDB and Sentence Transformers
- Local LLM integration via Ollama for privacy-preserving generation
- FastAPI endpoints for serving answers with source citations
- Logging, validation, and error handling for robustness

## Why It Matters for RAG Builders
This repository provides a practical, production-ready blueprint for building secure, local RAG systems that ground LLM responses in company-specific knowledge, reducing hallucinations and ensuring compliance.
