## Summary
SchemaCrawler AI provides an MCP (Model Context Protocol) server that enables AI agents to interactively query and understand database schema metadata. It leverages SchemaCrawler, a free database schema discovery tool, to facilitate seamless integration between AI systems and database structures.

## Key Features
- Provides an MCP server for AI agents to interact with database schemas
- Enables interactive interrogation of database metadata for AI applications
- Integrates with SchemaCrawler for comprehensive schema discovery
- Supports logging and configuration for debugging and monitoring
- Offers Docker and MCP-compatible deployments for ease of use
