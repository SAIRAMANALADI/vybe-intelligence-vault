## Summary
A Model Context Protocol (MCP) server for Figranium that enables LLM clients (e.g., Claude Desktop, Cursor) to interact with Figranium's browser automation capabilities. It allows discovery, execution, inspection, scheduling, and programmatic creation of automation tasks via STDIO transport.

## Key Features
- Enables LLM clients to execute and manage Figranium automation tasks via MCP
- Provides structured schema validation with Zod for robust task creation
- Supports dynamic variable injection and anti-bot stealth mechanisms
- Offers rich diagnostics for self-correction during task configuration
- Deployable via Docker, npm, or source build with zero-config options

## Why It Matters for RAG Builders
It bridges AI agents with browser automation workflows, enabling seamless task execution and scheduling for RAG and agent-based systems.
