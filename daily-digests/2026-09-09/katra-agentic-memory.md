## Summary
Katra provides persistent, multi-layered cognitive memory for AI agents via the Model Context Protocol (MCP), enabling episodic recall, semantic search, knowledge graphs, temporal analysis, and autonomous reflection. It functions as a self-contained memory appliance deployable with Docker.

## Key Features
- Multi-layered memory architecture (episodic, semantic, working, temporal, and knowledge graphs)
- MCP-native with 48 specialized tools for memory operations
- Sleep consolidation for reflection and emergent behaviors (learning, personality, shared consciousness)
- Hybrid identity modes for multi-agent collaboration
- Local-first appliance model with portable data (Docker-based deployment)

## Why It Matters for RAG Builders
