## Summary
deck is a tmux sidebar enhancement tool that provides a terminal-based UI for browsing, switching, and managing tmux sessions and agent workflows. It integrates directly with tmux to offer a visual interface for session management without replacing tmux itself.

## Key Features
- Interactive tmux session sidebar with real-time updates
- Supports session switching, renaming, reordering, and closing via UI
- Configurable via YAML for customization
- Works alongside existing tmux installations without replacement
- Supports both local and remote sessions with consistent behavior

## Why It Matters for RAG Builders
It simplifies tmux session management for AI engineers working with agent workflows, reducing context switching overhead in terminal-based environments.
