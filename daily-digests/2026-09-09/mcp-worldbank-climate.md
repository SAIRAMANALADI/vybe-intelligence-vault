## Summary
This repository provides an MCP (Model Context Protocol) server for accessing World Bank Climate Change Knowledge Portal (CCKP) data, enabling AI agents to retrieve historical climate observations and CMIP6 projections for any country. It simplifies complex climate data queries through structured tools and plain-English interfaces.

## Key Features
- Provides structured tools (`get_climate_data`, `list_options`) for querying World Bank climate data
- Supports historical observations and CMIP6 climate-model projections
- Simplifies complex indicator code assembly for users
- Offers plain-English query interface via `ask_pipeworx`
- Part of a larger MCP gateway with 1394+ live data sources

## Why It Matters for RAG Builders
