## Summary
Fuse is a local .NET tool that provides a persistent semantic index and pre-write compiler verification for coding agents. It enables agents to resolve dependency injection wiring, review code changes, and validate edits against the compiler without modifying the working tree.

## Key Features
- Persistent semantic index for .NET projects using MSBuild and Roslyn
- Pre-write compiler verification (`fuse_check`) to catch errors before file writes
- Dependency injection and route wiring resolution via `fuse_find`
- Branch-aware code review (`fuse_review`) with provenance tracking
- Impact analysis (`fuse_impact`) and refactoring (`fuse_refactor`) with compiler-backed safety

## Why It Matters for RAG Builders
Fuse ensures AI coding agents produce compiler-verified, semantically correct edits in .NET projects, reducing runtime errors and improving agent reliability.
