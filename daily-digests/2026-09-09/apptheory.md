## Summary
AppTheory is a contract-first serverless runtime for AWS Lambda that ensures consistent request handling, middleware, and event normalization across Go, TypeScript, and Python. It provides a unified runtime model for Lambda Function URL, API Gateway, ALB, and other event sources, with strict contract verification and MCP integration.

## Key Features
- Unified handler entrypoint for multiple AWS Lambda event sources (API Gateway, ALB, SQS, etc.)
- Strict contract verification across Go, TypeScript, and Python runtimes (245 shared fixtures)
- Tiered middleware system (P0/P1/P2) with observability and guardrails
- Built-in Model Context Protocol (MCP) runtime for AI agent integrations
- Immutable GitHub Releases for version-aligned distribution across languages

## Why It Matters for RAG Builders
AppTheory ensures consistent, verifiable serverless behavior across languages and AI-generated code, making it essential for building reliable RAG pipelines and AI agent systems on AWS Lambda.
