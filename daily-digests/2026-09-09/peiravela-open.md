## Summary
PEIRAVELA-open is the Apache-2.0 SDK/UI tier for the AxisRobo possible-world experiment control plane, enabling governed simulation worlds, reproducible experiments, and provenance-complete evidence generation for autonomous systems. It provides generated TypeScript/JavaScript clients, an OpenAPI contract, a Studio frontend, and tools for independent verification of simulation evidence.

## Key Features
- Generated TypeScript and JavaScript clients for the PEIRAVELA control-plane API
- Public OpenAPI contract and format schemas for independently verifiable simulation evidence
- Studio console frontend for managing and visualizing experiments
- Independent evidence verifier tool (tar + SHA-256) for external evaluators
- Prebuilt binaries and examples for quick integration and testing
