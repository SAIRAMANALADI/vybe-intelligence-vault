## Summary
MCPJam Inspector is an open-source testing and evaluation platform for Model Context Protocol (MCP) server developers, enabling interactive debugging, cross-client validation, and automated conformance checks across 16 client configurations and 170+ models.

## Key Features
- Interactive MCP server debugging with full JSON-RPC trace visibility
- Cross-client evaluation across 16 client configurations (ChatGPT, Claude, Cursor, etc.)
- Automated OAuth conformance checks with step-by-step debugging
- Programmatic SDK for custom integrations and CI/CD pipelines
- Workspaces for team collaboration and shared server configurations
