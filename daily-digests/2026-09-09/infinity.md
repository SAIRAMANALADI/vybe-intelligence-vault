## Summary
Infinity is an AI-native database designed for LLM applications, offering ultra-fast hybrid search capabilities across dense vectors, sparse vectors, tensors, full-text, and structured data. It enables seamless integration with RAG pipelines and other AI workflows.

## Key Features
- Supports hybrid search combining dense vectors, sparse vectors, tensors, and full-text with sub-millisecond latency
- Single-binary architecture with no dependencies, simplifying deployment
- High-performance query processing with 15K+ QPS on million-scale datasets
- Intuitive Python API and embedded module for AI developers
- Supports multiple rerankers including RRF, weighted sum, and ColBERT

## Why It Matters for RAG Builders
Infinity provides the critical vector and hybrid search infrastructure needed for high-performance RAG systems, enabling real-time retrieval with sub-millisecond latency for AI-native applications.
