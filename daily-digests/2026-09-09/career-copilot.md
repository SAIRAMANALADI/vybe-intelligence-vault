## Summary
Career-copilot is a Windows desktop application that automates the job search process using AI. It scrapes job listings, matches them to user skills, generates tailored resumes and cover letters, and tracks application progress in a visual pipeline.

## Key Features
- AI-driven job listing matching based on skills and resume content
- Automated generation of tailored cover letters and resumes
- Visual pipeline for tracking application status (To Apply, Applied, Interview, Offer)
- Integration with GitHub for authentication and job board access
- Local data storage with no cloud dependency for privacy
