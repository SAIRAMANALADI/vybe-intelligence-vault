## Summary
MCP Image Generator is an MCP server that enables AI assistants to generate and edit high-quality images from natural language descriptions. It optimizes prompts for visual clarity and purpose-awareness, supporting multiple image providers like Google Gemini, OpenAI GPT Image, and BytePlus Seedream.

## Key Features
- Built-in prompt optimization using Subject-Context-Style framework for enhanced visual clarity
- Supports three major image providers: Google Gemini, OpenAI GPT Image, and BytePlus Seedream
- Three quality presets (fast, balanced, quality) for speed, cost, and fidelity trade-offs
- Image editing capabilities with natural language instructions and style preservation
- High-resolution output (up to 4K) and flexible aspect ratios for diverse use cases

## Why It Matters for RAG Builders
It streamlines AI-driven image generation and editing within MCP-compatible workflows, reducing manual prompt engineering effort while ensuring high-quality, purpose-aware visual outputs.
