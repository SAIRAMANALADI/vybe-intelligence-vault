## Summary
gsc-mcp is a local MCP server that provides Google Search Console data access via a single Go binary, enabling AI agents to query site performance metrics without runtime dependencies. It bridges Google's ADC authentication with MCP-compatible tools for SEO analysis.

## Key Features
- Single Go binary with zero runtime dependencies for local deployment
- Supports Google ADC authentication for seamless user access without service accounts
- Provides 9 pre-built tools for SEO analysis (e.g., performance queries, CTR gaps, traffic decline diagnosis)
- Integrates with AI agents (Claude Code, Codex, Cursor, Hermes) via MCP protocol
- Includes automated installation scripts and skill packs for agent-ready analysis

## Why It Matters for RAG Builders
It enables AI agents to directly query Google Search Console data for SEO insights without requiring complex service account setups or manual API integrations.
