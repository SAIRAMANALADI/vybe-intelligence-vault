## Summary
Bifrost AI Gateway is a high-performance, OpenAI-compatible AI gateway that unifies access to 23+ AI providers (OpenAI, Anthropic, AWS Bedrock, Google Vertex, etc.) through a single API. It offers automatic failover, load balancing, semantic caching, and enterprise-grade features like governance and observability.

## Key Features
- Unified OpenAI-compatible API for 23+ AI providers with zero downtime
- Automatic failover and intelligent load balancing across providers
- Semantic caching to reduce costs and latency for repeated queries
- Enterprise-grade governance with budget management, rate limiting, and OIDC integration
- Model Context Protocol (MCP) support for external tool integration
