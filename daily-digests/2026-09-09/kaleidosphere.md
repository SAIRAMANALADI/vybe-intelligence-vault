## Summary
KaleidoSphere is a local-first Business and Decision Intelligence tool that analyzes enterprise database metadata (Oracle/MSSQL) to generate evidence-bound technical catalogs, guide BI requirements discovery, and provide deterministic insights without exposing raw data or credentials. It integrates with Apache Superset for dashboarding and offers bounded LLM interactions for intent classification.

## Key Features
- Analyzes Oracle/MSSQL metadata with read-only queries to build versioned technical catalogs
- Guides BI requirements discovery with deterministic briefs and provenance tracking
- Integrates with Apache Superset for fixed dashboard previews without direct source access
- Supports bounded LLM interactions for intent classification (no free-form SQL)
- Provides deterministic promotion workflows with fail-closed preflight checks

## Why It Matters for RAG Builders
It enables RAG builders to safely analyze enterprise database metadata and generate evidence-backed insights without exposing raw data or credentials, reducing LLM-to-SQL risks.
