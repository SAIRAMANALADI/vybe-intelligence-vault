## Summary
Freya is an AI assistant agent written in Go that drives a real browser to automate tasks like website generation, document creation, and system operations. It emphasizes state-checked completion over subjective judgments and runs efficiently offline on low-end hardware.

## Key Features
- Drives a real browser via DevTools Protocol for accurate automation
- Refuses to claim completion until all state checks pass (e.g., links, syntax, layout)
- Tiered memory system with budgeted context windows and append-only archives
- Background job isolation for concurrent tasks with stable prefixes
- Built-in guardrails for safety, risk classification, and audit logging
