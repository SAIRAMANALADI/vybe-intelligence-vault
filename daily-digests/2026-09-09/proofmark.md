## Summary
Proofmark is an autonomous AI penetration-testing agent that dynamically exploits targets in an isolated sandbox, validates findings with reproducible proof-of-concepts, and generates tamper-evident, signed run records. It ensures no false positives by only reporting exploits it can prove, making it ideal for security teams and developers seeking trustworthy, automated pentesting.

## Key Features
- Proves exploits with reproducible proof-of-concepts, eliminating false positives from static scanners
- Enforces strict authorization and scope, refusing out-of-scope requests before execution
- Generates tamper-evident, signed run records for verifiable and replayable pentesting
- Supports multi-agent strategies (recon + exploit) and provider-agnostic LLM integration
- Safe against production with destructive HTTP method blocking and prompt-injection resistance
