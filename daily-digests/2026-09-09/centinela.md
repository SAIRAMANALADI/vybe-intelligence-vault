## Summary
Centinela is a lightweight, defense-in-depth cybersecurity daemon for Linux/WSL that monitors network traffic and processes in real-time. It provides plain-language explanations of detected threats, alerts users, and optionally executes automated containment actions (e.g., blocking IPs, closing ports, killing processes) via user or AI agent confirmation.

## Key Features
- Real-time network and process monitoring with plain-language threat explanations
- Opt-in automated containment (block IP, close port, kill process) triggered by user or AI agent confirmation
- Offline threat intelligence (IOCs) integration to reduce false positives
- Baseline learning to establish normal behavior and minimize alert noise
- Local JSONL-based bridge for AI agent notifications and confirmation polling

## Why It Matters for RAG Builders
Centinela provides a lightweight, explainable, and opt-in automated threat containment system that bridges human oversight with AI agent capabilities, making it valuable for building secure, interactive RAG pipelines.
