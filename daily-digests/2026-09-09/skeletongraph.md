## Summary
SkeletonGraph is a zero-LLM, tree-sitter-based structural indexer that reranks lexical retrieval and fetches precise function-level context for AI coding agents. It builds cross-file call graphs, computes PageRank centrality, and exposes an MCP server or CLI for IDE integration, enabling token-efficient and accurate code retrieval.

## Key Features
- Zero-LLM structural indexing using tree-sitter and call graphs
- BM25 reranking with PageRank centrality for precise function retrieval
- MCP server integration for IDEs like Cursor, Claude Code, and Copilot
- CLI pipeline for terminal-based retrieval and execution
- Dynamic model routing and cost-aware execution

## Why It Matters for RAG Builders
SkeletonGraph significantly improves retrieval quality for AI coding agents by replacing expensive exploratory file reads with a deterministic graph-based pipeline, reducing token waste and accelerating task resolution.
