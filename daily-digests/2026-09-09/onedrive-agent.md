## Summary
A Python-based AI agent that identifies duplicate and convertible files in OneDrive, proposes cleanup actions, and executes them only after explicit human approval. Built as a portfolio artifact to demonstrate BA/PM discipline in AI agent development, including requirements, design, governance, and iterative delivery.

## Key Features
- Duplicate file detection with MD5 hashing for accuracy
- Convertible file format identification (e.g., legacy formats)
- Explicit human approval gate for all destructive actions
- State machine with restart-and-resume capability for resilience
- Comprehensive governance artifacts (RAID log, decision log, Agile backlog)

## Why It Matters for RAG Builders
