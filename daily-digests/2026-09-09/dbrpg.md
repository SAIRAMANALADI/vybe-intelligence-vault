## Summary
DBRPG is a solo text-based RPG set in a Dragon Ball-inspired universe, where an AI agent acts as the Game Master (MJ) by reading and interpreting the repository's content (rules, lore, prompts, and state) to narrate, arbitrate, and manage game sessions in French, including via Telegram.

## Key Features
- AI-driven Game Master (MJ) that reads and interprets repo content for dynamic storytelling
- Structured repository for rules, lore, state, and sessions with clear separation of concerns
- Integration with Telegram for live gameplay and state persistence via Git commits
- Built-in integrity checks (pre-commit hooks) to prevent corruption of game state and content
- Modular design with hooks for customization (e.g., new campaigns, characters, or rules)
