## Summary
The agentscore-py repository is the official Python SDK for AgentScore, a service providing identity verification and compliance gating for agentic commerce. It enables KYC, age verification, sanctions screening, and jurisdiction checks for agents with or without wallets.

## Key Features
- Synchronous and asynchronous API clients for AgentScore services
- Support for wallet-based and credential-based identity verification
- Comprehensive policy enforcement (KYC, age, sanctions, jurisdiction)
- Wallet-signer matching and OFAC SDN sanctions screening
- Session management for first-time agent verification and polling

## Why It Matters for RAG Builders
It provides essential identity verification and compliance tools for AI agents engaging in commerce, ensuring regulatory adherence and fraud prevention.
