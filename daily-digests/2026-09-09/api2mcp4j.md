## Summary
api2mcp4j is a zero-to-low-code solution for converting existing Spring Boot REST APIs into MCP (Model Context Protocol) servers. It automatically scans and exposes `@RestController` methods as MCP tools without requiring code refactoring or extensive annotations.

## Key Features
- Automatic discovery and conversion of `@RestController` methods into MCP tools with minimal configuration
- Multi-parser support combining Swagger, Javadoc, Spring MVC metadata, and Jackson for rich tool descriptions
- Non-intrusive integration requiring no changes to existing business logic or REST endpoints
- Full MCP SDK compatibility including callbacks, resources, prompts, and protocol 2026-07-28 features
- Customizable scanning scope via annotations like `@ToolScan` and `@ResourceScan`

## Why It Matters for RAG Builders
It enables RAG/AI stack builders to instantly expose existing Spring Boot REST APIs as MCP tools without refactoring, accelerating AI agent integration with production systems.
