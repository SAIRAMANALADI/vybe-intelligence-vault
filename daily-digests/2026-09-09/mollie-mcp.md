## Summary
This repository implements a Model Context Protocol (MCP) server that interfaces with the Mollie API to retrieve payment data, create payment links, and fetch profile or payment method information. It enables natural language queries about Mollie transactions and account details via an LLM.

## Key Features
- Exposes MCP tools for fetching transactions, payment links, and profile info
- Enables natural language queries about Mollie payment data via LLM
- Supports creating payment links dynamically with specified amounts
- Provides real-time access to Mollie API data (transactions, methods, profile)
- Designed for integration with MCP-compatible clients like GitHub Copilot

## Why It Matters for RAG Builders
This MCP server enables LLMs to interact with Mollie payment data in real-time, allowing for natural language queries and automated financial workflows without rigid UIs.
