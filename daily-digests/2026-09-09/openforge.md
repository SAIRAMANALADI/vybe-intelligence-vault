## Summary
OpenForge is a local-first AI agent framework that consolidates terminal, TUI, web UI, and desktop interfaces into a unified system. It provides 43 built-in tools, 44 skills across 6 categories, and 41 intelligence modules, all operating with data privacy by default and SQLite-based memory management.

## Key Features
- Unified home directory (`~/.openforge/`) for centralized data, memory, and configuration management
- 43 built-in tools covering filesystem, terminal, git, research, multimodality, and MCP integration
- 44 skills across 6 categories (code intelligence, web research, creative media, communication, data analytics, DevOps)
- 41 intelligence modules for self-improvement, healing, learning, and adaptive persona management
- Support for 25 LLM providers (cloud and local) with seamless switching and endpoint compatibility
