## Summary
A plugin that enables AI assistants like Claude, ChatGPT, or Codex to delegate browser-based tasks to the Pluno Chrome extension, improving reliability and speed for web interactions. It acts as a routing layer between AI models and the Pluno browser extension.

## Key Features
- Delegates browser tasks from AI assistants to the Pluno Chrome extension for faster execution
- Fallback mechanism to native browser control if Pluno extension is unavailable
- Supports integration with Claude, ChatGPT, and Codex
- Requires Pluno Chrome extension for full functionality
- Secure plugin with no executable hooks, relying on Pluno extension for authentication and execution

## Why It Matters for RAG Builders
It bridges AI assistants with specialized browser automation tools, enabling more reliable and efficient web task execution for RAG systems.
