## Summary
This repository transforms Oak National Academy's open curriculum into AI-native infrastructure by providing MCP apps, engineering tools, and an agentic framework. It enables teachers and developers to build AI-powered educational applications using Oak's curriculum data, semantic search, and knowledge graphs.

## Key Features
- MCP app server for integrating Oak curriculum with AI assistants like ChatGPT and Claude
- TypeScript SDK generated from OpenAPI schema for typed curriculum access
- Hybrid semantic search for curriculum resources using Elasticsearch
- Agentic engineering framework for AI-amplified innovation in education
- Knowledge graph surfaces and graph projection conventions for structured curriculum data

## Why It Matters for RAG Builders
It provides modular, reusable AI-native infrastructure for building educational applications that leverage Oak's high-quality curriculum data, reducing development costs and accelerating innovation in the education sector.
