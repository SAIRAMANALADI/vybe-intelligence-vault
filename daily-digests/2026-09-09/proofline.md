## Summary
Proofline is a conflict-aware match-verification and settlement layer for World Cup products and AI agents, converting attributed sports observations into reproducible evidence packets. It anchors canonical event hashes on the Injective EVM testnet and exposes a verifiable decision path via the VARA agent framework.

## Key Features
- VARA agent framework for verifiable decision paths with full provenance
- Conflict-aware evidence graph with quarantine for disputed claims
- Injective EVM anchoring of canonical event hashes for immutability
- x402 payment protocol for premium proof settlement with on-chain verification
- MCP server for AI agent integration with policy-capped spending rules

## Why It Matters for RAG Builders
Proofline provides a robust, conflict-aware framework for verifying and settling AI agent decisions using immutable blockchain anchoring, essential for building trustworthy RAG systems in high-stakes domains like sports or finance.
