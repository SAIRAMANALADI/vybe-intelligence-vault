## Summary
AI Papers Reader is an AI agent that automates the curation of weekly digests of the latest AI research papers, tailored to user-specified topics. It leverages APIs, LLMs, and CI/CD pipelines to fetch, process, and publish paper summaries as markdown files on a static website.

## Key Features
- Automated weekly paper digest generation using GitHub Actions
- Customizable topic-based filtering via prompt templates
- Integration with Hugging Face's Daily Papers API for metadata retrieval
- Static website deployment for easy access to digests
- Gemini 2.5 Flash LLM for relevance filtering and summarization
