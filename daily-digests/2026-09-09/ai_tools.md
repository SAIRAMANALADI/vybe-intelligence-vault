## Summary
AI Tools is a comprehensive web application for managing, testing, and interacting with local LLM infrastructure, including llama.cpp servers, vector databases, and AI agents. It provides a unified UI for model management, agent tooling, and data conversion workflows.

## Key Features
- Unified web UI for managing llama.cpp servers, including model selection, server control, and real-time logs
- Extensible AI agent with dynamic tool registry, SQLite-based memory, and WebSocket streaming
- Integrated ChromaDB client for vector database management, document vectorization, and semantic search
- Standalone data conversion tools (URL to Markdown, PDF to Markdown, HTML to Markdown)
- Comprehensive configuration UI for llama.cpp servers, embedding models, and agent tools

## Why It Matters for RAG Builders
It simplifies the setup and management of local LLM infrastructure, making it easier to build and test RAG pipelines with integrated agent tooling and vector databases.
