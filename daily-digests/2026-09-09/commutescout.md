## Summary
CommuteScout provides a live map of California road conditions, a route planner, and an AI assistant that answers questions about traffic using real-time data from 13 public agency feeds. It also offers an MCP server for integration with AI assistants like Claude.

## Key Features
- Live statewide map with incidents, closures, cameras, and wildfires
- Route planner with live traffic conditions and multi-format export
- AI assistant for answering questions about drives using real-time data
- MCP server for integration with AI assistants like Claude
- Watch-area alerts for incidents, closures, and wildfires

## Why It Matters for RAG Builders
