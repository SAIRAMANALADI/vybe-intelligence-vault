## Summary
Markplane is an AI-native project management tool that stores tasks, epics, and plans as markdown files directly in a Git repository. It enables AI coding assistants to understand project context, dependencies, and priorities through a token-efficient context layer, eliminating the need for external SaaS tools.

## Key Features
- Stores project data as markdown files in Git, enabling version control and seamless integration with existing workflows.
- Generates a token-efficient `.context/` directory with compressed summaries for AI assistants to consume.
- Built-in MCP server for AI coding assistants to manage tasks, epics, and plans via natural language commands.
- Real-time sync between CLI, MCP, and web UI with WebSocket for instant updates.
- Configurable workflows, dependency tracking, and cross-references for structured project management.

## Why It Matters for RAG Builders
It bridges the gap between AI coding assistants and project context by embedding structured, version-controlled project data directly in the repository, enabling AI to understand and act on project goals without external tools.
