## Summary
Frank is an open-source, self-hosted coding agent harness that allows users to define, customize, and run their own agent workflows. It provides a modular architecture with a library, machine loaders, a daemon, and multiple client interfaces, enabling full control over agent behavior and tooling.

## Key Features
- Open-source harness with editable system prompts and tooling
- Multi-layer architecture (library, machine loaders, daemon, clients)
- Daemon-based session management for crash isolation and addressability
- Supports any LangChain-compatible model provider
- Native macOS app and terminal/CLI clients with unified API

## Why It Matters for RAG Builders
Frank empowers RAG builders to customize agent behavior, tooling, and guardrails, ensuring full control over the agent's execution environment and capabilities.
