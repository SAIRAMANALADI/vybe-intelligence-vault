## Summary
SEO Audit Console is an MCP server that merges Google Search Console data, a first-party site crawl, and optional DataForSEO market data to generate a prioritized, conversation-driven technical SEO audit. It identifies actionable issues, ranks findings by recoverable traffic potential, and provides paste-ready fixes directly within Claude.

## Key Features
- Merges Search Console, crawl data, and optional market data for a prioritized audit
- Ranks findings by expected recoverable traffic, not just severity
- Generates paste-ready fixes (e.g., 301 rules, JSON-LD, internal links)
- Identifies keyword cannibalization, striking-distance queries, and content gaps
- Provides AI-search readiness checks and structured data validation

## Why It Matters for RAG Builders
It automates and contextualizes technical SEO audits by merging real search data with crawl insights, enabling faster, more accurate, and actionable optimizations for AI and RAG stack builders.
