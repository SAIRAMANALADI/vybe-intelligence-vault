## Summary
ImmuneAgent is an AI agent that monitors DataHub lineage to detect corrupted upstream data, evaluates risk severity using governance tags, and autonomously raises incidents to halt downstream pipelines before corrupted data spreads.

## Key Features
- Autonomous detection of corrupted data using DataHub lineage
- Severity evaluation based on governance tags (e.g., 'Authoritative Source', 'Most Queried')
- Real-time incident raising in DataHub via GraphQL
- Pipeline halting mechanism to prevent downstream corruption
- Compatibility with MCP-based agent workflows

## Why It Matters for RAG Builders
It provides a proactive, autonomous solution for preventing data corruption propagation in AI pipelines by leveraging lineage and governance signals.
