## Summary
CodeWhale is an open-source terminal-based coding agent built in Rust, designed to assist developers with coding tasks directly from the command line. It supports multiple AI providers, offers granular control over agent actions, and includes features like session management, approval modes, and extensibility via MCP servers.

## Key Features
- Multi-provider support for hosted and local AI models (Ollama, vLLM, SGLang)
- Granular approval modes and repository rules for controlled agent access
- Session management with durable goals and workflow organization
- Extensible via MCP servers and custom hooks
- Cross-platform installation (npm, Cargo, Docker, Nix, etc.)

## Why It Matters for RAG Builders
CodeWhale provides a flexible, terminal-native agent framework that integrates seamlessly with RAG pipelines by enabling AI-driven coding assistance with fine-grained control and extensibility.
