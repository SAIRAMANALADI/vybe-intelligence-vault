## Summary
A portable autonomous AI agent with a GUI built on LangGraph, designed for developers to execute tasks like file operations, shell commands, process management, and web search without complex infrastructure. It emphasizes safety, portability, and zero-config execution with a single binary.

## Key Features
- Graph-based runtime with bounded recovery and self-correction using LangGraph
- Mixed-mode parallel tool execution with streaming CLI output and fuzzy replay suppression
- Built-in approval system for critical actions and configurable model profiles
- Durable checkpoints and session persistence for seamless resumption
- Portable single-binary deployment with PyInstaller and no Docker dependency

## Why It Matters for RAG Builders
It provides a lightweight, portable, and safe framework for building autonomous AI agents that can execute local tasks and integrate with MCP servers, reducing dependency on heavy infrastructure for RAG builders.
