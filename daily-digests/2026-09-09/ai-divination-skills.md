## Summary
A Python-based toolkit providing auditable divination methods (tarot, I Ching, Xiao Liu Ren, Bazi) for AI agents, where the tool generates the divination result and the AI interprets it. Designed for symbolic reasoning, reproducibility, and safe integration with agent workflows.

## Key Features
- Separates divination generation (audited scripts) from AI interpretation for clear safety boundaries
- Supports multiple divination systems: tarot, I Ching, Xiao Liu Ren, and Bazi (Four Pillars)
- Provides MCP server and CLI tools for seamless integration with AI agents (Claude, Codex, Cursor, etc.)
- Includes multilingual documentation and per-client adapter configurations for major AI platforms
- Emphasizes reproducibility with seeded mode for demos and auditable JSON outputs

## Why It Matters for RAG Builders
