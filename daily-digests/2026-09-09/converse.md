## Summary
Converse MCP Server is an MCP-compliant tool that enables Claude to interact with multiple AI models from various providers (OpenAI, Google, Anthropic, etc.) through a unified interface. It supports single-model chats, multi-model consensus, and asynchronous task execution with smart summarization features.

## Key Features
- Unified interface to interact with 10+ AI model providers (OpenAI, Google, Anthropic, Mistral, etc.)
- Supports both synchronous and asynchronous model interactions with background task execution
- Consensus tool for gathering multiple AI model perspectives on complex decisions
- Smart summarization for auto-generated titles and progress updates on async tasks
- File and image support for richer model interactions
