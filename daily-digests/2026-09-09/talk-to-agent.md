## Summary
Talk-to-Agent is a local realtime voice demo that connects a browser microphone to Google's Gemini Live API via a Python backend and WebRTC, enabling asynchronous audio streaming and low-latency voice interactions for a French-language interview simulation.

## Key Features
- Local realtime voice interaction with Google's Gemini Live API
- Bidirectional WebRTC audio streaming for low-latency communication
- Asynchronous Python backend with FastAPI for handling audio processing
- Resampling and conversion of audio to compatible formats for Gemini Live
- Compact demo showcasing integration of multiple realtime technologies
