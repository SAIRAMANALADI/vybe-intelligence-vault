## Summary
A Fabric mod for Minecraft 1.21.3 that creates a server-side AI agent capable of executing natural-language commands through LLM planning and deterministic task execution. The bot handles mining, crafting, farming, and survival tasks while adhering to strict or operator-defined profiles.

## Key Features
- Natural-language goal planning via LLM (DeepSeek or OpenAI-compatible)
- 34 deterministic task state machines for mining, crafting, farming, and survival
- Strict and operator profiles with configurable capabilities and safety policies
- Versioned runtime snapshots for state persistence and restart recovery
- In-game control panel for monitoring bot status, inventory, and health

## Why It Matters for RAG Builders
It demonstrates a robust integration of LLM-driven planning with deterministic execution in a complex, real-time environment, offering insights into safety, state management, and task decomposition for AI agent frameworks.
