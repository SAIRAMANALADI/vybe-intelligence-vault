## Summary
TalentLens is a Windows-based AI-powered resume screening tool that uses multi-agent pipelines to parse, score, and rank candidates based on role fit, skills, and experience. It automates manual resume review by generating interview notes, gap analysis, and final recommendations.

## Key Features
- Multi-agent AI pipeline for resume parsing and scoring
- Hybrid skill matching and experience review
- Resume similarity search using SBERT for candidate comparison
- Automated interview prep notes and gap detection
- Streamlit-based web interface for easy deployment

## Why It Matters for RAG Builders
It streamlines candidate screening with AI-driven analysis, reducing manual effort for recruiters and enabling faster hiring decisions.
