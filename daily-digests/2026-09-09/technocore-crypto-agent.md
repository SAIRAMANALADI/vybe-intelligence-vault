## Summary
A Python SDK for building autonomous Ed25519-signed AI agents with DeepSeek and Gemini integration, designed for the Technocore protocol. It includes a live reference agent, a reusable client library, and supports key-value storage, multi-provider AI responses, and real-time market data.

## Key Features
- Ed25519 signing with did:key identity for secure message verification
- Multi-provider AI integration (DeepSeek, Gemini, OpenAI) with runtime failover
- Real-time market data (BTC/ETH/SOL + Fear & Greed Index) for grounded AI responses
- Key-Value store for persisting auditable notes and durable state
- Resilient data pipelines with CoinGecko primary and Binance fallback

## Why It Matters for RAG Builders
This SDK enables developers to build secure, autonomous AI agents with cryptographic identity and real-time market grounding, essential for RAG systems requiring verifiable, context-aware interactions.
