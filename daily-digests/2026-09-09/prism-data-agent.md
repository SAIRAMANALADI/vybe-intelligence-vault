## Summary
Prism is an AI-powered data analyst agent that processes plain English queries about datasets by decomposing them into parallel tasks, executing SQL, Python, and chart generation in parallel, and verifying results before delivering grounded answers with interactive visualizations. It runs fully local by default but supports hosted LLM providers.

## Key Features
- Decomposes complex queries into parallel sub-tasks for concurrent execution
- Supports multiple data sources: CSV uploads, SQL databases (Postgres, MySQL, SQLite), and bundled sample datasets
- Pluggable LLM providers (Ollama, Claude, OpenAI, DeepSeek) with one environment variable switch
- Built-in verification loop to validate and refine answers before final output
- Real-time streaming UI with live progress updates and interactive SVG charts

## Why It Matters for RAG Builders
Prism enables RAG builders to integrate a self-contained, parallelized AI data analyst agent that can decompose and execute complex analytical queries with built-in verification, reducing the need for manual query writing and improving answer reliability.
