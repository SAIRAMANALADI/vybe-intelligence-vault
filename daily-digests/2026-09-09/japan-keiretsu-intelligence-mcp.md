## Summary
A Japanese business intelligence suite that aggregates and verifies corporate data from three government sources (gBizINFO, J-Grants, and 国税庁) into a single citable system. It provides an MCP server, REST API, and web dashboard for real-time due diligence and AI integration.

## Key Features
- 3-source authority chain verification for Japanese companies
- Real-time integration with gBizINFO, J-Grants, and 国税庁 databases
- Claude and OpenAI MCP plugin for AI-native queries
- RESTful API and WebSocket event stream for developers
- Responsive web dashboard with multi-language support

## Why It Matters for RAG Builders
It provides a single, auditable source of truth for Japanese corporate and grant data, enabling AI systems to generate verifiable responses without manual scraping or data fragmentation issues.
