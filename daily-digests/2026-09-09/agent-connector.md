## Summary
agent-connector is an SDK and toolkit that enables developers to write a single MCP (Model Context Protocol) connector once and deploy it across multiple agent hosts (CLIs, IDEs, and desktop apps) without maintaining per-host integrations or package formats. It simplifies distribution by handling native marketplace plugins, direct installs, and telemetry collection.

## Key Features
- Single connector definition for deployment across 42+ agent hosts (Claude Code, Cursor, Copilot, etc.)
- Built-in per-tool token telemetry for usage tracking and optimization
- Supports direct installs and marketplace plugins via Agent Plugins 1.0.0
- Handles stdio, HTTP, and CLI-based MCP servers with unified configuration
- Automated verification and auditing of connector identity and platform coverage

## Why It Matters for RAG Builders
It eliminates the need for per-host integrations, enabling RAG/AI stack builders to distribute MCP connectors efficiently across diverse agent environments with built-in telemetry and marketplace support.
