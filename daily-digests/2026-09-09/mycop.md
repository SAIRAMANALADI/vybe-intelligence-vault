## Summary
mycop is an AI-powered code security scanner designed to detect and fix vulnerabilities in AI-generated code across multiple languages like Python, JavaScript, TypeScript, Go, and Java. It combines pattern matching, AST analysis, and AI-driven explanations to provide comprehensive security insights.

## Key Features
- Comprehensive security scans using pattern matching and AST analysis
- AI-powered explanations for detected vulnerabilities
- Auto-fix capabilities to resolve security issues automatically
- 200 built-in security rules covering OWASP Top 10 and CWE Top 25
- User-friendly interface for non-technical users
