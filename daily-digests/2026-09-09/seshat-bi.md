## Summary
Seshat BI is an agent-first readiness system for transforming messy retail data into trusted Power BI deliverables with evidence-backed governance. It enforces a seven-stage medallion pipeline where each stage requires explicit human approval and validation before progression.

## Key Features
- Seven-stage readiness pipeline with enforced sequencing and human approval gates
- Static and live governance checks for SQL, TMDL, DAX, and metric contracts
- Portable proof surfaces (HTML reports, JSON, SARIF) for auditability
- Agent-safe MCP governor that exposes governance state without enabling execution
- Governed statistical evidence engine for reproducible analytics validation

## Why It Matters for RAG Builders
Seshat BI ensures AI agents and BI pipelines operate on trustworthy, evidence-backed data by enforcing human-approved governance gates, preventing self-approval of critical decisions in analytics workflows.
