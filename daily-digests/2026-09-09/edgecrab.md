## Summary
EdgeCrab is a Rust-native autonomous AI agent framework inspired by Nous Hermes and OpenClaw, offering persistent memory, multi-platform messaging integration, and a lightweight terminal-based TUI. It combines autonomous reasoning with always-on presence for personal and coding assistance.

## Key Features
- ReAct tool loop with autonomous reasoning and tool execution
- Persistent memory and Honcho user modeling for cross-session learning
- 17 messaging gateway integrations (Discord, Slack, WhatsApp, etc.)
- Lightweight Rust binary (~49 MB) with zero runtime dependencies
- Built-in security hardening (path jails, SSRF guards, command scanning)

## Why It Matters for RAG Builders
EdgeCrab provides a high-performance, secure, and extensible agent framework that bridges autonomous reasoning with persistent user interaction, making it ideal for building scalable RAG systems with multi-modal tooling and cross-platform accessibility.
