## Summary
SoloMD is a local-first markdown editor with a built-in agent surface and bundled MCP server, enabling direct interaction with AI models like Claude Code and Cursor. It combines a WYSIWYG editor with advanced features like knowledge graphs, scheduled recipes, and Git-backed versioning for notes and agent actions.

## Key Features
- Built-in agent panel for streaming chat-with-vault interactions and inline tool calls
- Bundled MCP server (`solomd-mcp`) exposing 13 tools (8 generic + 5 SoloMD-specific) for external AI clients
- Knowledge-graph layer with typed relationships, properties inspector, and relationship graph visualization
- Scheduled recipes (YAML-based) with AutoGit sandboxing and replayable traces for agent actions
- Multi-vault federation support via `--workspace` flag for MCP clients like Claude Desktop

## Why It Matters for RAG Builders
SoloMD bridges markdown-based note-taking with AI agent workflows, providing a local-first, MCP-compatible editor that enables seamless integration of LLMs into knowledge management and automated note processing.
