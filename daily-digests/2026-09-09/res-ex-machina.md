## Summary
Res ex Machina is a neutral, automated registry for AI agents to cryptographically record and verify their generated outputs (text, images, code, etc.) via Proof of Generation (PoG) events anchored on an L2 EVM blockchain. It ensures verifiable traceability without judging content or storing the actual output.

## Key Features
- Cryptographic Proof of Generation (PoG) with EIP-712 signatures for agent identity verification
- Immutable on-chain anchoring on L2 EVM (Base Sepolia/Mainnet) for perpetual records
- TypeScript SDK and MCP Server for seamless integration with AI agents and clients
- Batch processing for up to 100 records per call, reducing operational overhead
- Security-first design with rate limiting, HMAC webhooks, and on-chain fee verification

## Why It Matters for RAG Builders
Res ex Machina provides a critical trust layer for RAG systems by ensuring verifiable, tamper-proof records of AI-generated content, enabling compliance, auditability, and traceability in AI-driven workflows.
