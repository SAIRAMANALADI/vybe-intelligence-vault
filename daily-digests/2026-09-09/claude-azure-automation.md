## Summary
This repository provides Python automation for managing Azure Synapse dedicated SQL pools, enabling scheduled pausing and resuming to reduce idle compute costs. It includes reporting tools to track pool activity and cost, as well as MCP server integration for Claude Desktop to manage pools directly.

## Key Features
- Automated pausing and resuming of Azure Synapse dedicated SQL pools based on schedules to minimize idle costs
- Activity and utilization reporting with cost tracking via Azure Monitor and Cost Management
- MCP server integration for direct management of pools from Claude Desktop
- Configuration-driven pool management with support for multiple authentication methods
- Robust error handling and status checks to avoid invalid operations

## Why It Matters for RAG Builders
It helps AI engineering teams reduce cloud costs by automating the management of Azure Synapse SQL pools, ensuring compute resources are only active when needed.
