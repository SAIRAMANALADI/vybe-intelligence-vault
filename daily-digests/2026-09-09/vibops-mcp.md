## Summary
vibops-mcp is a provider-agnostic MCP server designed to unify GPU infrastructure management across multiple cloud providers and on-prem clusters. It abstracts fragmentation in GPU operations, cost tracking, and governance into a single interface for AI assistants and agents.

## Key Features
- Unified MCP server for GPU fleet management across AWS, GCP, Azure, on-prem, and other providers
- 74+ tools for observation, action, governance, and FinOps with real-time cost attribution
- LLM Inference Proxy for transparent OpenAI-compatible API with per-agent cost tracking
- Agent Infrastructure Control Plane for FinOps, budget enforcement, and model access policies
- Compliance and governance tools including AI Act, SOC 2, RGPD, and immutable audit logging

## Why It Matters for RAG Builders
It provides a critical abstraction layer for RAG/AI stack builders to manage, govern, and optimize GPU infrastructure across heterogeneous environments with unified cost and compliance tracking.
