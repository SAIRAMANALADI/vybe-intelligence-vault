## Summary
Scopewalker MCP is a local Model Context Protocol (MCP) server that enforces stricter codebase standards for AI agents by analyzing code complexity, size thresholds, documentation coverage, and code smells. It operates entirely offline, ensuring no data leaves the user's machine.

## Key Features
- 8 read-only MCP tools for deep codebase analysis (e.g., complexity metrics, line counts, code smells)
- Enforces size thresholds and detects oversized functions/files
- Supports multiple languages (TypeScript, Python, Go, Rust, Java, C/C++, Ruby)
- Local execution with no network calls or external dependencies
- Integrates with popular AI agent environments (Claude, Cursor, VS Code, Windsurf, Antigravity CLI)

## Why It Matters for RAG Builders
It provides critical codebase analysis tools for AI agents to enforce quality standards and prevent bloated, unmaintainable code during development.
