## Summary
The Gandr MCP server enables text-to-speech capabilities within any MCP-compatible agent, such as Claude Desktop or Cursor. It provides tools for synthesizing speech, listing available voices, and tracking API usage.

## Key Features
- Synthesize text to speech with customizable voices, sample rates, pitch, and pacing
- List available voices for selection
- Track API usage with `get_usage` tool
- Compatible with any MCP-compatible agent (e.g., Claude Desktop, Cursor)
- Simple deployment via Python and environment variables

## Why It Matters for RAG Builders
It enables AI agents to generate speech output dynamically, enhancing multimodal interactions and accessibility in RAG applications.
