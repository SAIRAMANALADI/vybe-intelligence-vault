## Summary
Loredex is a universal control system for coding-agent teamwork that provides shared memory, cross-project handoffs, and structured knowledge management across repositories. It enables agents to inherit full working context and collaborate seamlessly through MCP and Obsidian dashboards.

## Key Features
- Automated filing and routing of markdown files into a structured vault with deterministic, LLM, or heuristic classification
- Shared memory layer for agents via MCP server for real-time context retrieval and handoffs
- Obsidian plugin for native dashboards, handoff tracking, and vault synchronization
- Deterministic indexing with auto-generated MOCs and native Obsidian databases for navigation
- Idempotent operations with zero lock-in, ensuring plain markdown outputs and git-friendly changes

## Why It Matters for RAG Builders
Loredex eliminates fragmented agent knowledge by providing a unified, structured memory layer that enables seamless collaboration and context inheritance across projects and teams.
