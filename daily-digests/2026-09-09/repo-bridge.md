## Summary
repo-bridge transforms ChatGPT Web into a real coding agent by providing an MCP server that grants direct, secure access to local or remote repositories for reading, editing, building, testing, and git operations without requiring an OpenAI API key or incurring per-token charges.

## Key Features
- Enables ChatGPT Web to act as a full coding agent with read/write access to repositories
- Supports autonomous test-fix loops, file editing, and git workflows (branch, commit, PR)
- Model-agnostic and operates without per-token API costs or OpenAI API keys
- Implements strict security measures including workspace sandboxing, executable allowlists, and OAuth 2.1 authentication
- Provides 30+ tools for workspace management, file operations, execution, and git integration

## Why It Matters for RAG Builders
It eliminates the need for manual code pasting or API-based interactions by enabling AI models to directly manipulate repositories, streamlining development workflows and reducing operational friction for RAG/AI stack builders.
