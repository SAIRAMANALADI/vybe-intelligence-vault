## Summary
FFBB MCP Server provides real-time and historical French basketball (FFBB) data via the Model Context Protocol (MCP), enabling AI assistants to query schedules, standings, live scores, and team summaries with optimized caching and aggregation for low-latency responses.

## Key Features
- Streamable HTTP MCP endpoint for seamless AI assistant integration
- Comprehensive FFBB data access: schedules, standings, live scores, and team summaries
- Optimized caching with Stale-While-Revalidate (SWR) and persistent SQLite storage
- Aggregated responses to minimize LLM context and API calls
- Publicly hosted instance with low-latency performance (< 30s live score updates)

## Why It Matters for RAG Builders
It provides a critical bridge for AI assistants to access real-time and structured French basketball data, enabling richer, context-aware responses for sports-related queries.
