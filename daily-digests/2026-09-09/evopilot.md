## Summary
EvoPilot is an evidence-driven control plane for governing the evolution, release, and deployment of AI-agent products. It automates loop engineering, human approval workflows, and CI/CD integration while ensuring auditable release decisions for multi-tenant SaaS environments.

## Key Features
- Loop Engineering with durable state, checkpoints, and replay capabilities for AI-agent evolution
- GlobalGoal planning layer for decomposing objectives into governed targets and release decisions
- Human-in-the-loop approvals for high-risk actions like code upgrades and releases
- SaaS multi-tenancy with RBAC, tenant isolation, and scoped secrets
- Comprehensive evidence ingestion from runtime events, traces, evaluations, and user feedback

## Why It Matters for RAG Builders
EvoPilot provides the critical governance layer for safely evolving and releasing AI-agent products in production, ensuring auditable, evidence-backed decisions and seamless CI/CD integration.
