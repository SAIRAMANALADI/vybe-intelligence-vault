## Summary
A toolkit for AI agents to generate schema-validated slide decks from rough notes, supporting 75+ themes and exporting to editable PowerPoint, Keynote, and Google Slides. Includes MCP tools for seamless integration with coding agents.

## Key Features
- Schema-validated Deck JSON for agent-driven editing and diffing
- 75+ pre-built themes with live preview and customization
- Native editable PPTX export with round-trip support
- MCP server for direct integration with AI agents (Claude, Cursor, etc.)
- CLI and plugin-based installation for rapid deployment

## Why It Matters for RAG Builders
It enables AI agents to autonomously generate polished, editable slide decks from unstructured notes, bridging the gap between raw output and professional presentation quality.
