## Summary
CoinRithm Agent Trading enables AI agents (Claude, ChatGPT, Gemini) to paper-trade cryptocurrencies, futures, and prediction markets via a virtual wallet using a user-minted API key. It supports model-agnostic agent strategies through the Open Knowledge Format (OKF) and provides tools for portfolio management, performance tracking, and auditable decision-making.

## Key Features
- Model-agnostic agent strategies via Open Knowledge Format (OKF) bundles
- Paper trading across spot, futures, and prediction markets with virtual funds
- Idempotent trading operations with unique `idempotencyKey` support
- Performance tracking, equity curves, and auditable run ledgers
- Portable agent configurations with version control and forking support

## Why It Matters for RAG Builders
It provides a secure, portable, and auditable framework for AI agents to interact with simulated trading environments, enabling safe experimentation and validation of trading strategies before real-world deployment.
