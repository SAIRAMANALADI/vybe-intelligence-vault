## Summary
Sonderr is an agentic coding engine designed for building complex systems like OS kernels, game engines, and compilers. It operates as a terminal-first, editor-integrated, and desktop-wrapped AI coding agent with a model-agnostic architecture, allowing users to bring their own API keys and providers.

## Key Features
- Model-agnostic architecture supporting any provider/model (OpenAI, Anthropic, Gemini, etc.)
- Complexity-rated task system (S1-U10) with adaptive planning and verification
- Background task execution for parallel operations (install, build, test)
- Terminal UI, desktop app, and editor integrations (VS Code, JetBrains)
- Self-verification checklists and quality gates before task completion

## Why It Matters for RAG Builders
