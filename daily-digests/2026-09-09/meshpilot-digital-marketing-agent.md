## Summary
MeshPilot is a self-hostable autonomous AI marketing agent designed to run 24/7 in the cloud, performing tasks like social media management, content creation, and SEO with per-brand memory and a learning loop. It operates as a single agent rather than a complex multi-agent mesh, offering tools for autonomous decision-making and execution.

## Key Features
- Per-brand persistent memory with hybrid recall (pgvector + FTS)
- Native tool-use loop with deterministic policy gates for safety
- Multi-model routing with cross-provider failover (Claude, GLM, Kimi, etc.)
- Self-scheduling and background job execution with cost budgeting
- Open-core model (AGPL-3.0) with managed cloud option

## Why It Matters for RAG Builders
It provides a robust, self-hostable framework for building autonomous AI agents with memory, policy controls, and multi-brand scalability, critical for RAG systems requiring persistent context and safe tool integration.
