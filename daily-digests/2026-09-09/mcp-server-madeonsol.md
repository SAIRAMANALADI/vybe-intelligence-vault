## Summary
MCP server providing real-time Solana KOL intelligence, deployer analytics, and on-chain token tracking via the MadeOnSol API. Enables agents to query KOL trades, deployer signals, token surges, and holder data with sub-second latency.

## Key Features
- Real-time KOL trade feeds with <3s latency (paid keys) or 5-min delayed (free tier)
- Token surge/revival detection with pre-confirmation signals (~500ms before on-chain)
- Deployer reputation scoring and historical as-of-date queries for backtesting
- Holder census with exact counts, labeled wallets, and exclusion metrics
- Webhook and WebSocket streaming for real-time event notifications
