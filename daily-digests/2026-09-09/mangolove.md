## Summary
MangoLove is a wrapper for Claude Code that enforces a 4-track quality methodology, risk-based safety gates, and measurable workflows to ensure deterministic software development outcomes. It integrates impact scoring, mandatory reviews, and secret scanning to transform quality from aspiration to verifiable default.

## Key Features
- 4-track risk-based methodology (Trivial/Small/Medium/Large) with automated impact scoring
- Deterministic safety gates for irreversible commands (e.g., rm -rf, SQL DROP, terraform destroy)
- Mandatory multi-agent reviews for Medium/Large changes with find-verify workflow
- Secret scanning and commit blocking for sensitive data leaks
- Measurable quality metrics via `mangolove efficacy` and `mangolove eval`

## Why It Matters for RAG Builders
MangoLove provides a structured, measurable framework to enforce quality and safety in AI-driven development workflows, reducing human error and ensuring compliance with rigorous standards.
