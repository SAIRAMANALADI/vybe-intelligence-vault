## Summary
ContextMemory is an open-source agentic memory gateway that provides persistent, editable, and versionable wiki-style memory for LLMs. It acts as an OpenAI-compatible endpoint, enabling session-based markdown wiki storage, retrieval, and agentic tools without requiring client rewrites.

## Key Features
- Wiki-style memory storage and retrieval with versioning and editing capabilities
- OpenAI-compatible chat endpoint for seamless integration with existing SDKs
- MCP server support for Cursor and Claude for quick memory operations
- Self-hostable or available as a zero-ops cloud service
- Supports agentic tools like sandboxing, HITL (human-in-the-loop), and MCP integrations

## Why It Matters for RAG Builders
ContextMemory provides a unique, editable, and versionable memory system for LLMs that bridges the gap between persistent context and human-readable knowledge management, making it essential for building advanced RAG systems with long-term memory.
