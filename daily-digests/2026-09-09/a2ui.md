## Summary
A2UI Catalog provides a declarative vocabulary of 474+ UI atoms for AI agents to compose interfaces efficiently, reducing token usage and improving predictability. It includes renderers for web, Google Apps Script, and MCP, enabling agents to generate stable, reusable UI components without writing raw HTML or CSS.

## Key Features
- 474+ pre-defined UI atoms for agents to compose interfaces declaratively
- Multi-surface compatibility (web, Google Meet, Apps Script, email, PDF, etc.) with degradation notes
- MCP server for agent integration and catalog browsing
- Open-source renderers for web and Google Apps Script (no CDN or external dependencies)
- ARD manifest and machine-readable spec for agent discovery and validation

## Why It Matters for RAG Builders
A2UI Catalog enables AI agents to generate stable, reusable UI components with minimal token overhead, reducing costs and improving reliability in RAG and agentic systems.
