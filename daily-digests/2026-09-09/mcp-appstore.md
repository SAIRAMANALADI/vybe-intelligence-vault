## Summary
An MCP (Model Context Protocol) server that enables LLMs to search, analyze, and retrieve data from the Google Play Store and Apple App Store. It provides tools for app discovery, keyword analysis, review sentiment analysis, and competitor insights, primarily targeting App Store Optimization (ASO) use cases.

## Key Features
- Search apps by name, platform, and country with configurable result limits
- Fetch detailed app metadata including descriptions, ratings, screenshots, and pricing
- Analyze top keywords for apps with brand dominance and competition metrics
- Perform sentiment analysis on app reviews to extract user insights and common themes
- Retrieve raw reviews with developer responses for deeper analysis

## Why It Matters for RAG Builders
It provides structured, real-time app store data and insights that enhance RAG pipelines for ASO, competitor analysis, and user sentiment tracking.
