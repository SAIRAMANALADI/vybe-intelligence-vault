## Summary
adstream-mcp is an open-source MCP (Model Context Protocol) connector that provides a data access layer for ads and commerce analytics across major platforms like Meta, TikTok, Google, and commerce sources. It enables AI clients to safely interact with provider data through normalized, provider-agnostic tools while enforcing strict safety and validation protocols.

## Key Features
- Provider-agnostic tools for Meta, TikTok, Google, and commerce sources with normalized data envelopes
- Strict safety protocols for write operations (opt-in, dry-run, confirmation required)
- Canonical tool surface with pagination, metadata, and warnings for robust data retrieval
- Support for dynamic creative formats and WhatsApp Business Account discovery tools
- Modular architecture with provider adapters, MCP core, and credential resolution layer

## Why It Matters for RAG Builders
It provides a secure, standardized way for AI agents to access and interact with ads and commerce data across multiple platforms, enabling safer and more efficient RAG pipelines for marketing analytics.
