## Summary
FundzWatch MCP Server provides AI agents with real-time business-event intelligence via the Model Context Protocol (MCP), enabling access to verified funding rounds, executive moves, UCC refinancing windows, and AI-scored leads without requiring an API key for 7 of its 14 tools.

## Key Features
- 14 MCP tools for live business-event intelligence (7 key-less, 7 key-required)
- Cross-dataset cohorts like funded-and-hiring, money-in-motion, and refinancing windows
- AI-scored leads matched to ICP with buyer intent and outreach guidance
- Directories of 8,600+ lenders and 65,000+ brokers from UCC and Form 5500 data
- Seamless integration with Claude, Cursor, Windsurf, Cline, and other MCP clients
