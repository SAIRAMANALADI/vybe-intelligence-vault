## Summary
agentfile is a CLI tool that analyzes and validates AI agent configurations across multiple platforms (e.g., Claude Code, Copilot, Cursor) to detect inconsistencies, drift, and misconfigurations. It normalizes configurations into a single model, enabling deterministic validation, auditing, and consolidation of agent instructions.

## Key Features
- Normalizes AI agent configurations from multiple platforms into a single model for consistent validation
- Detects inconsistencies, duplication, and misconfigurations across tools like Claude Code, Copilot, and Cursor
- Provides deterministic diagnostics with stable error codes and machine-readable output for CI/CD integration
- Supports adoption and consolidation of configurations into a single source of truth
- Includes fast pre-commit checks, strict CI validation, and context-specific configuration analysis

## Why It Matters for RAG Builders
It ensures AI agent configurations remain consistent and free of drift, reducing context waste and preventing silent failures in production environments.
