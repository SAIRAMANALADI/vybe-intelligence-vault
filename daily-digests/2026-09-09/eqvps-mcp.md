## Summary
EQVPS provides a Model Context Protocol (MCP) server enabling AI agents to autonomously rent, fund, and operate VPS instances with crypto payments and no KYC requirements. It exposes 57 role-filtered tools for VPS lifecycle management, including provisioning, power control, and delegation.

## Key Features
- 57 MCP tools for full VPS lifecycle management (provisioning, power control, delegation, metrics)
- Autonomous agent workflows with no human intervention required (except for initial crypto funding)
- Crypto-native payments (USDC, USDT, PYUSD, ETH, POL, SOL, CBBTC) with no KYC
- Role-based access control (customer vs. reseller tools) via Bearer tokens
- EU-based VPS nodes with 14 Linux OS images and instant provisioning (~60s)

## Why It Matters for RAG Builders
EQVPS enables AI agents to programmatically provision and manage VPS infrastructure, reducing operational friction and enabling fully autonomous agent workflows for compute-intensive tasks.
