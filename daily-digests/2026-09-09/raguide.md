## Summary
raguide is a conversational AI shopping-guide agent for 3C electronics (phones, laptops, headphones) built on a dual-layer RAG architecture (Agentic + Modular) with multi-agent orchestration, eval-driven optimization, and end-to-end observability. It enables real-time, grounded product recommendations via natural language queries with full transparency and modular retrieval pipelines.

## Key Features
- Dual-layer RAG architecture with Agentic (multi-agent) and Modular (6-stage pipeline) retrieval for robust grounding and decision-making.
- Eval-driven optimization with 5-dimensional weighted scoring (0.712 → 0.838) and 75 gold-set test cases for continuous improvement.
- End-to-end observability via Langfuse, Prometheus, and Grafana with 32 panels, 9 alerts, and real-time traceability.
- Multi-modal and structured retrieval (text, images, structured specs) with cross-modal validation and SQL-based filtering.
- Ports & Adapters LLM abstraction layer with multi-provider routing, fallback chains, and zero hardcoded secrets.

## Why It Matters for RAG Builders
It provides a production-grade reference implementation for building enterprise-grade RAG systems with agentic orchestration, rigorous evaluation, and full-stack observability, critical for AI stack builders seeking reliability and scalability.
