## Summary
joshbot is a lightweight, self-hosted personal AI assistant written in Go, designed for seamless integration with any LLM provider. It features autonomous memory management, skill self-creation, subagent delegation, and multi-channel support including Telegram and CLI.

## Key Features
- Self-learning memory with structured fact storage and deduplication
- Dynamic skill creation and approval workflow for extensibility
- Subagent delegation for complex, multi-step tasks
- Multi-provider LLM support with automatic fallback chains
- Proactive tasks and scheduled reminders with persistent job storage

## Why It Matters for RAG Builders
joshbot provides a production-ready, self-hosted agent framework with autonomous memory and skill systems, reducing integration overhead for RAG builders seeking customizable, multi-provider AI assistants.
