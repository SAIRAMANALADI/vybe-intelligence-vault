## Summary
Nativewright is a Windows-based tool that automates web browser interactions with human-like behavior, including randomized mouse movements, natural typing cadence, and physics-based scrolling. It is designed to bypass anti-bot detection while maintaining persistent Chrome profiles for AI agents and automation tasks.

## Key Features
- Mimics human-like mouse movements and typing to avoid bot detection
- Supports persistent Chrome profiles for seamless login state retention
- Command-line interface for scripting and automation workflows
- Physics-based scrolling and randomized mouse paths for stealth
- Local execution with no data transmission to external servers
