## Summary
A Pi extension that enables AI agents to dynamically decide whether a response should be delivered as one or multiple chat bubbles, ensuring semantic grouping and human-like message delivery without artificial delays or forced splits.

## Key Features
- Dynamic message splitting based on semantic units rather than punctuation or delays
- Support for one or multiple chat bubbles per agent response
- Hard per-turn message caps (default 4) with soft limits (~700 chars per bubble)
- Idempotent delivery with toolCallId for replay protection
- Modular design separating message logic from platform-specific adapters

## Why It Matters for RAG Builders
It enables AI agents to deliver responses in a more human-like and semantically coherent way, improving user experience in chat-based applications.
