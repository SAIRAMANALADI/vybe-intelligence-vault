## Summary
FrontMCP is a TypeScript-first framework for building Model Context Protocol (MCP) servers with decorators, dependency injection, and built-in auth and transport. It simplifies MCP server development by handling protocol, sessions, and execution flow while enabling deployment across multiple environments.

## Key Features
- Typed MCP server development with decorators and Zod schemas for end-to-end type safety
- Built-in authentication (OAuth/JWKS/DCR), sessions, and dependency injection
- Streamable HTTP + SSE transport with support for multiple deployment targets (Node, Vercel, AWS Lambda, Cloudflare Workers)
- Production-ready features including observability, high-availability transport, and 95%+ tested core
- Extensible ecosystem with plugins, OpenAPI adapters, UI components, and E2E testing framework

## Why It Matters for RAG Builders
FrontMCP simplifies the development of production-grade MCP servers, enabling AI engineers to focus on business logic while handling protocol complexity, transport, and security out of the box.
