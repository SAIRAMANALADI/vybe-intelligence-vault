## Summary
Parley is a voice-first portal that enables hands-free interaction with AI agents via the OpenAI Responses API. It provides configurable speech-to-text (STT) and text-to-speech (TTS) capabilities, background audio support, and real-time WebRTC calling, making it ideal for in-pocket use.

## Key Features
- Hands-free voice interaction with AI agents via OpenAI Responses API compatibility
- Configurable STT/TTS providers (Deepgram, ElevenLabs, OpenAI Whisper)
- Background audio support for in-pocket use with lockscreen-friendly PWA
- Real-time WebRTC calling and barge-in capabilities
- Extensible right-drawer module system for future UI surfaces

## Why It Matters for RAG Builders
Parley provides a critical voice-first interface layer for RAG/AI stacks, enabling seamless hands-free interaction with agents while supporting multiple deployment environments from Raspberry Pi to cloud servers.
