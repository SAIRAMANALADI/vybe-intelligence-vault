## Summary
Janus is a locally-run, autonomous AI agent that executes tasks via CLI or Telegram, leveraging tools like shell commands, file operations, and subagents. It features persistent memory with hybrid search, safety gates, and multi-provider LLM support for robust task automation.

## Key Features
- Hybrid memory search combining FTS5 and vector embeddings for semantic retrieval
- Multi-provider LLM support with failover and streaming capabilities
- Persistent cron scheduler with SQLite-backed task management
- Subagent spawning for parallel task execution and modular workflows
- Safety gates and confirmation prompts for destructive actions

## Why It Matters for RAG Builders
Janus provides a robust, locally-deployable framework for building autonomous AI agents with persistent memory and multi-tool execution, essential for developers integrating RAG systems with real-world task automation.
