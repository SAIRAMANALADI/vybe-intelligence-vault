## Summary
AutoPatch-J is an AI-driven code repair agent designed for Java repositories, leveraging static scanning and LLM reasoning to generate controlled patches with human-in-the-loop review. It enforces strict task boundaries, evidence-based patching, and isolated context to ensure safe and auditable code modifications.

## Key Features
- Static scanning with Semgrep for evidence-based patching
- Strict task boundary enforcement (intent recognition, tool whitelisting)
- Human-in-the-loop review for patch application or rejection
- Isolated context for repair vs. general chat to prevent contamination
- Modular architecture with clear separation of workflow, agent, and LLM layers

## Why It Matters for RAG Builders
AutoPatch-J provides a controlled, evidence-based framework for AI-assisted Java code repair, ensuring safe and auditable modifications while leveraging LLM reasoning for minimal patch generation.
