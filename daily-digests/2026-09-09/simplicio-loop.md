## Summary
simplicio-loop is a universal AI orchestrator designed to automate and govern end-to-end agent workflows, transforming high-level intent into verified, dependency-aware task execution with built-in safety gates, evidence tracking, and rollback capabilities.

## Key Features
- Contract-first task execution with explicit acceptance criteria and dependencies
- Parallel, isolated worktree execution with dependency-aware fan-out and convergence
- Built-in safety gates, verification, and rollback mechanisms for robust delivery
- Multi-agent stage coordination with four-way review (security, quality, runtime, blast radius)
- Durable memory and evidence tracking integrated into the execution lifecycle

## Why It Matters for RAG Builders
It provides a production-grade framework for automating and governing AI agent workflows with verifiable evidence, reducing token waste and ensuring reliable, auditable outcomes for RAG and AI stack builders.
