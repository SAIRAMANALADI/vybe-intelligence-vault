## Summary
Figsnap MCP provides Figma design file access as MCP tools via a local daemon, Figma plugin, and MCP server. It enables AI agents to extract, preview, and edit Figma components (PNG, React, HTML, CSS) without external dependencies or accounts.

## Key Features
- 39 MCP tools for reading and writing Figma designs (PNG, React, HTML, CSS extraction)
- Local daemon (`figsnap-mcp-daemon`) with loopback-only HTTP/WebSocket endpoints
- Figma plugin for real-time design access and edits (opt-in)
- Saved component sets stored locally (per user/file/machine)
- No external dependencies, accounts, or network beyond localhost

## Why It Matters for RAG Builders
It bridges Figma designs directly into AI agent workflows via MCP, enabling seamless design extraction and editing without cloud dependencies.
