## Summary
Poke Around enables remote command execution and file access on your local machine via a Poke AI assistant, supporting macOS, Linux, and Windows. It acts as a bridge between your device and the Poke AI platform, allowing secure or restricted interactions based on configured modes.

## Key Features
- Multi-platform support (macOS, Linux, Windows) with native installation methods
- Three permission modes (full, limited, sandbox) for granular security control
- Agent system for custom JavaScript scripts with environment variable support
- OAuth-based authentication and secure credential storage
- Service management for persistent daemon operation

## Why It Matters for RAG Builders
Poke Around provides a secure bridge for AI assistants to interact with local machines, enabling advanced RAG systems to execute tools and access files remotely while maintaining user-controlled security policies.
