## Summary
A curated, bilingual (English/Traditional Chinese) repository of distilled summaries from 133 AI engineering talks, organized into 9 thematic categories and 9 cross-cutting insights. The project generates a self-contained, dependency-free static site from composable Markdown sources.

## Key Features
- Systematic distillation of 133 AI engineering talks into skimmable summaries and cross-cutting insights
- Bilingual support (English/Traditional Chinese) with language toggle and persistent user preference
- Self-contained static site (single `index.html`) with no external dependencies or server requirements
- Composable Markdown sources with automated build pipeline (poll → triage → review → deploy)
- Personal note-taking feature with saved highlights persisting in browser storage
