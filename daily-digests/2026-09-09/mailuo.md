## Summary
Mailuo transforms chat screenshots into structured action cards, contact memory, and relationship insights, enabling zero-manual-entry personal CRM workflows. It separates image recognition (OCR or vision models) from structured understanding, with a focus on grounded, user-confirmed insights and long-term memory accumulation.

## Key Features
- Dual-mode processing: local OCR (Android BYOK) or cloud vision fallback for screenshots
- Structured action cards and contact memory with user confirmation workflows
- Entity resolution with alias management and grounded relationship insights
- Atkinson-Shiffrin memory model integration for long-term knowledge retention
- Privacy-first architecture with local storage and optional self-hosting

## Why It Matters for RAG Builders
Mailuo provides a privacy-preserving, structured approach to converting unstructured chat data into actionable CRM insights, reducing manual entry while maintaining grounded, evidence-based relationship tracking for AI agents.
