## Summary
Talon is a multi-platform agentic AI harness that runs on Telegram, Discord, Microsoft Teams, Terminal, and a cross-platform Desktop/Mobile companion app (Flutter). It supports pluggable backends (Claude, Kilo, OpenCode, Codex, OpenAI Agents) and provides full tool access via MCP, enabling persistent background agents, goals, and skills.

## Key Features
- Multi-frontend support (Telegram, Discord, Teams, Terminal, Desktop/Mobile app)
- Pluggable backend system with streaming, model fallback, and context recovery
- Full MCP tool access (messaging, media, history, web fetch, cron jobs, goals, file system, etc.)
- Persistent background agents (Heartbeat, Dream, Goals, Triggers, Skills)
- Hot-reloadable plugin system with built-in integrations (GitHub, MemPalace, Playwright, Brave Search)

## Why It Matters for RAG Builders
Talon provides a unified framework for deploying agentic AI across multiple platforms with pluggable backends and MCP tooling, making it essential for building scalable, multi-modal AI systems.
