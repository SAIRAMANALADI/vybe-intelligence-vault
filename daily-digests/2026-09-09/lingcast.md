## Summary
LingCast is an end-to-end AI digital-human live-streaming platform that enables users to create customizable digital humans, generate base videos via LivePortrait, and stream real-time interactions with lip-sync using Edge-TTS and Wav2Lip. It integrates DeepSeek LLM for dynamic replies and supports live streaming via SRS.

## Key Features
- Avatar creation with persona profiles and Edge-TTS voice selection
- Real-time LLM-powered replies with DeepSeek integration
- GPU-free lip-sync using Wav2Lip ONNX for lightweight inference
- Dual-mode deployment (Docker for infrastructure, native AI worker for performance)
- Live subtitle customization and multi-language support (Chinese/English)
