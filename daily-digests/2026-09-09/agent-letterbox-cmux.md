## Summary
Agent Letterbox for cmux is a coordination layer that enables multi-agent AI coding teams to hand off tasks and maintain durable records of interactions directly on disk. It transforms separate agent terminals into a live, collaborative team with built-in message archiving and recovery.

## Key Features
- Durable task handoffs stored as Markdown files on disk, preserving context and history
- Live doorbell notifications in agent terminals for instant coordination
- ACK/NACK/RESULT lifecycle for clear task ownership and progress tracking
- Cross-agent communication without human relay, reducing manual overhead
- Supports recovery from crashes or compacted terminals via inbox persistence

## Why It Matters for RAG Builders
It provides a reliable, inspectable coordination layer for multi-agent AI workflows, ensuring tasks and decisions are preserved as durable records rather than ephemeral terminal interactions.
