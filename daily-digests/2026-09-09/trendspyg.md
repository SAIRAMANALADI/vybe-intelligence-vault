## Summary
A modern, actively-maintained Python library and CLI for accessing Google Trends data, offering real-time trending topics, keyword analysis over time, and historical archiving. It serves as a robust alternative to the archived pytrends library with enhanced features and agent-friendly integrations.

## Key Features
- Real-time trending topics and keyword analysis with multiple data retrieval methods (RSS, CSV, Explore)
- Historical archiving of trending data via local SQLite for retrospective analysis
- Agent-ready MCP server for seamless integration with AI coding assistants like Claude
- Async support for parallel fetching and real-time monitoring of trend changes
- Normalized output schema for consistent data processing across different retrieval paths
