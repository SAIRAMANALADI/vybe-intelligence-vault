## Summary
A free, open-source plugin that enables Codex to interact with OpenProject by managing work packages, including creation, updates, and comments via OpenProject's API v3. It supports both Community and Enterprise editions and runs locally for secure credential handling.

## Key Features
- Read and write operations on OpenProject work packages (create, update, comment)
- Supports both OpenProject Community and Enterprise editions
- Local deployment with secure credential handling via environment files
- Provides Codex-native workflow guidance and tools for safe natural-language actions
- Cross-platform compatibility (macOS, Linux, Windows)

## Why It Matters for RAG Builders
