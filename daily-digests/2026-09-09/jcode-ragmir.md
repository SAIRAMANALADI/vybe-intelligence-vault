## Summary
Ragmir is a confidential, local-first RAG (Retrieval-Augmented Generation) tool designed for coding agents and automation workflows. It indexes project files locally, retrieves cited evidence, and integrates with agents via CLI, TypeScript API, or MCP server without requiring cloud services or API keys.

## Key Features
- Local indexing and retrieval of project files with citations and line/page references
- Multiple interfaces: CLI, TypeScript API, MCP server, and optional local chat/TTS
- Supports semantic retrieval with optional local model downloads
- Privacy-first design with no cloud dependencies by default
- Modular architecture with optional packages for chat, TTS, and OCR

## Why It Matters for RAG Builders
Ragmir enables secure, offline RAG workflows for AI agents, ensuring confidential codebases and documents are processed locally without exposing sensitive data to external services.
