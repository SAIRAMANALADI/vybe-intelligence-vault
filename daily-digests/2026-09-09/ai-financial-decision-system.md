## Summary
Billweave is a localized, auditable personal finance analysis tool designed to consolidate and analyze scattered bill data from platforms like WeChat, Alipay, and bank statements. It automates the process of cleaning, deduplicating, and generating clear financial reports entirely locally.

## Key Features
- Three-layer pipeline (data, calculation, presentation) with auditable intermediate outputs (JSON/CSV)
- Cross-platform deduplication (withdrawals, deposits, refunds, and settlements)
- Multi-format bill parsing (CSV, Excel, PDF) with automatic encoding and header detection
- AI-assisted categorization with a confirmation queue for unmatched transactions
- 100% local processing with no external API calls or data uploads

## Why It Matters for RAG Builders
It provides a robust, auditable pipeline for processing and analyzing financial data locally, reducing reliance on cloud-based tools and enabling secure, automated financial insights.
