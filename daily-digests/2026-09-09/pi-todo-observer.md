## Summary
A persistent, hierarchical todo sidebar for the Pi coding agent that observes and tracks task progress asynchronously. It maintains a separate in-memory observer session to review agent turns and provide a structured view of planned, active, blocked, and completed work.

## Key Features
- Persistent, non-blocking sidebar overlay for real-time task tracking
- Hierarchical todo and sub-todo organization with state tracking (pending, in-progress, blocked, completed)
- Asynchronous observation of agent turns without interrupting main workflow
- Configurable model, provider, and context limits for flexibility
- Full-session recalculation for sessions predating the extension

## Why It Matters for RAG Builders
It enhances agent productivity by providing real-time, structured task tracking and progress visualization, reducing cognitive load for developers using Pi.
