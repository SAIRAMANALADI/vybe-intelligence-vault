## Summary
JotNow is a note-taking and memory management tool for AI agents, allowing users to save, search, and export notes via an MCP server, CLI, or desktop app. It integrates seamlessly with agents like Claude Code and Codex to capture and recall context.

## Key Features
- MCP server integration for AI agents to save and retrieve notes dynamically
- CLI for direct note management and search via commands like `jotnow add` and `jotnow search`
- Local mode for offline note storage via the desktop app
- Tagging, search by keyword or semantic meaning (Pro), and export to markdown
- Environment variable support for CI/CD and containerized environments

## Why It Matters for RAG Builders
JotNow streamlines context management for RAG systems by enabling agents to persistently store and retrieve notes, reducing hallucinations and improving recall of past interactions.
