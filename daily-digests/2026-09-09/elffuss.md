## Summary
Elffuss-core is a shared browser-based agent runtime that enables AI-powered applications to run entirely in the browser without mandatory builds or backend services. It powers products like Elffuss Claw (an agentic OS) and Elffuss Code (a VS Code-like IDE with an agent).

## Key Features
- Runs entirely in the browser with no mandatory backend or build step
- ACE-lite context management with token budgeting to prevent overflow
- Dynamic skill injection from public repositories (e.g., Anthropic skills)
- Safe markdown rendering with full escaping for chat interfaces
- Provider-agnostic API adapter for OpenAI-compatible and Anthropic models

## Why It Matters for RAG Builders
It enables fully client-side AI agent applications with minimal setup, reducing infrastructure dependencies and accelerating development for RAG builders.
