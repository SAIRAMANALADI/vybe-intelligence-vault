## Summary
MCPProxy is a secure gateway and proxy for managing and federating multiple Model Context Protocol (MCP) servers, enabling AI agents to scale beyond API limits while providing advanced security, token efficiency, and cross-platform support.

## Key Features
- Federates hundreds of MCP servers with a single endpoint, bypassing API limits (e.g., Cursor's 40-tool limit, OpenAI's 128-function cap)
- Reduces token usage by ~99% and improves accuracy by 43% via dynamic tool discovery and schema deferral
- Advanced security with automatic quarantine, tool poisoning attack prevention, and pluggable security scanners (Snyk, Semgrep, Trivy)
- Cross-platform support with a single binary for macOS, Windows, and Linux, including embedded web UI and optional menu-bar app
- Activity logging, audit trails, and preflight checks for headless automations to validate tool readiness

## Why It Matters for RAG Builders
MCPProxy is essential for RAG/AI stack builders as it enables secure, scalable, and efficient management of multiple MCP servers, reducing costs and improving reliability while mitigating security risks like tool poisoning attacks.
