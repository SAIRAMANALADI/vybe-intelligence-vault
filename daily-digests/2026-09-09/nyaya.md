## Summary
A monorepo providing Indian-law tooling with an MCP server, Next.js frontend, and LangGraph-based chat assistant for legal research. It covers statutes like the Constitution, IPC, CrPC, and landmark Supreme Court judgments, enabling retrieval-augmented legal assistance.

## Key Features
- MCP server exposing 16 tools and 11 resources for Indian legal statutes and judgments
- LangGraph-based chat assistant with supervisor-synthesis agent architecture for retrieval-grounded responses
- Unified deployment via Docker on Railway, serving SPA, REST API, MCP, and chat from a single origin
- Corpus hydration pipeline with sanitization and rate limiting for security and integrity
- Static Next.js frontend with client-side data fetching and streaming SSE for chat responses
