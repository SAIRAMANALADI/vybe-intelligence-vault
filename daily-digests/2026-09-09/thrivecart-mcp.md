## Summary
A Model Context Protocol (MCP) server that integrates ThriveCart's API with AI agents like Claude Code, enabling 24 tools for managing products, transactions, revenue, customers, subscriptions, and affiliates across multiple ThriveCart accounts simultaneously.

## Key Features
- 24 tools for ThriveCart data access (products, transactions, subscriptions, affiliates, etc.)
- Multi-account support with separate data isolation to prevent cross-account errors
- Read/write operations with safety guards (e.g., `confirm: true` for irreversible actions)
- Pre-configured prompts for common queries like revenue reports and customer lookups
- Supports HTTP transport and Docker deployment for flexibility

## Why It Matters for RAG Builders
It bridges ThriveCart's siloed data with AI agents, enabling seamless, multi-account revenue and customer insights without manual exports or joins.
