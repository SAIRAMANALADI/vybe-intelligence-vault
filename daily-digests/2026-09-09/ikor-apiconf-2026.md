## Summary
Ikor is a lightweight Windows-native desktop application that enables voice-driven typing, app-aware AI formatting, and secure financial transactions via spoken commands. It integrates with Monnify's sandbox API for wallet top-ups and leverages local AI models for transcription and intent parsing.

## Key Features
- Real-time voice-to-text with low-latency transcription using Groq Whisper
- App-aware AI formatting (ScribePro) for context-sensitive output (e.g., code blocks in IDEs, mentions in Slack)
- Secure voice-triggered financial operations via Monnify Sandbox API with human-in-the-loop approval
- Local AI model fallback for offline transcription and intent parsing
- Dynamic window positioning and DPI scaling for multi-monitor environments

## Why It Matters for RAG Builders
Ikor demonstrates how voice-driven agents can integrate financial operations and app-aware AI formatting, providing a blueprint for secure, human-approved voice automation in productivity tools.
