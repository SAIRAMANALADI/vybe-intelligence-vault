## Summary
Domi is a local-first Personal Coding Workbench that integrates multi-model chat, executable agent workflows, project files, terminals, and a built-in browser into a single Electron desktop application. It enables isolated work sessions, Git workflows, and long-running task continuity for coding and AI-assisted development.

## Key Features
- Local-first architecture with isolated worktree sessions for safe code modifications and testing
- Multi-model chat support (Anthropic, OpenAI, Google, DeepSeek, etc.) with HTTP tool integration
- Executable agent workflows for multi-step coding tasks, testing, and service deployment
- Built-in terminal, browser, and lightweight Git workflows integrated into a unified workspace
- Long-running task continuity with session handoff, follow-up queues, and context compression

## Why It Matters for RAG Builders
Domi provides a cohesive local-first environment for AI agents to interact with codebases, execute tasks, and collaborate with users in a controlled, isolated workspace, bridging the gap between AI assistance and practical coding workflows.
