## Summary
AccessFlow is an open-source database access governance platform that acts as a SQL and NoSQL proxy, enforcing review, approval, and audit workflows between teams and production data. It supports multiple database engines and provides dynamic data masking, row-level security, and AI-driven query analysis.

## Key Features
- Proxy-first execution with encrypted credential storage and human approval workflows
- Configurable review policies with AI-driven risk scoring and automated routing
- Dynamic data masking and row-level security for granular access control
- Support for 15+ database engines (SQL and NoSQL) with extensible connectors
- Tamper-evident audit logging and compliance reporting with data classification

## Why It Matters for RAG Builders
AccessFlow ensures secure, auditable, and governed database access, reducing risks of data breaches and unauthorized changes while enabling self-service workflows for engineering teams.
