## Summary
GrokDesk is a native, open-source macOS desktop client for Grok Build that provides a modern SwiftUI interface to interact with local Grok Build runtime via ACP/JSON-RPC. It enables seamless conversations, session management, and skill invocation without embedding a terminal or reimplementing the agent.

## Key Features
- Native macOS client with Markdown, code blocks, and attachment previews
- Chronological activity tracking for sessions, skills, and runtime events
- Multi-account authentication with isolated credentials and routing controls
- Local session discovery, archiving, and context compaction
- Drag-and-drop file handling and full previews

## Why It Matters for RAG Builders
GrokDesk provides a polished, native macOS interface for interacting with local Grok Build runtimes, simplifying AI agent management and conversation workflows for developers.
