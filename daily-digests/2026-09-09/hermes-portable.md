## Summary
Hermes Portable is a zero-install, zero-trace, cross-platform portable version of the Hermes Agent that runs entirely from a USB drive or local directory. It bundles all dependencies (Python, Node.js, venv) and ensures no system traces are left behind, enabling seamless multi-platform AI agent deployment.

## Key Features
- Zero-install and zero-trace deployment via USB drive or local directory
- Cross-platform support (macOS, Linux, Windows) with universal packaging
- Built-in configuration center for model selection, API key management, and logging
- Persistent memory and self-growing skills for continuous agent improvement
- Multi-channel integration (Telegram, Discord, Slack, WhatsApp, email, CLI)

## Why It Matters for RAG Builders
It enables AI engineers to deploy and test Hermes Agent seamlessly across multiple platforms without system dependencies or cleanup, making it ideal for portable, sandboxed AI workflows.
