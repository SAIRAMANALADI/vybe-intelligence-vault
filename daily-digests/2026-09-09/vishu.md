## Summary
Vishu is a local-first personal-assistant AI that aggregates multiple LLM provider keys (including local models) into a single ring to avoid rate limits. It supports vision, voice, memory, and a bidirectional MCP gateway for real-world task execution, with built-in security and verification features.

## Key Features
- Aggregates multiple LLM provider keys (including local models) into a single ring to avoid rate limits via failover or balance modes
- Bidirectional MCP gateway enabling seamless integration with external tools and apps (e.g., GitHub, Gmail, custom MCP servers)
- Local vision (Moondream) and voice (Whisper.cpp + Piper) capabilities for real-world task execution
- Owned markdown memory vault with SQLite vector/FTS index for persistent, editable, and portable memory
- Verified secure builds with deterministic OWASP Top-10 scanning and multi-agent orchestration for reliability

## Why It Matters for RAG Builders
Vishu eliminates rate limit bottlenecks in AI agent workflows by intelligently pooling provider keys and local models, ensuring uninterrupted task execution for RAG and agent-based systems.
