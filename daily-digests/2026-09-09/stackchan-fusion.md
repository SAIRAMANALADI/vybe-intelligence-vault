## Summary
StackChan Fusion integrates a voice-controlled M5Stack robot with local AI agents (agy, pi, claude, codex) via a fusion gateway, enabling bidirectional communication between the robot and multiple agents through MCP and Docker Toolkit.

## Key Features
- Bidirectional communication between a voice-controlled robot and local AI agents (agy, pi, claude, codex) via MCP and Docker Toolkit
- Fusion gateway for unified tool exposure and event management across agents
- Docker MCP Toolkit integration for seamless client-side agent access (Codex, Claude Code, VS Code)
- Automated deployment scripts for gateway, agents, and server MCP configurations
- Real-time connectivity verification and system tray monitoring for operational status
