## Summary
OpenPhoenix is a privacy-focused, self-contained AI assistant delivered as a single static Rust binary. It operates locally or across multiple chat platforms without external dependencies, offering terminal, Telegram, and other integrations while ensuring minimal data retention and high security.

## Key Features
- Single static binary with zero runtime dependencies
- Multi-channel support (Telegram, Discord, Slack, etc.) and terminal chat
- Configurable memory modes (ghost, session, recall) with no hidden databases
- Automatic API key detection and model selection on first run
- Strict security defaults (empty allowlist, no web UI, mode 600 config)

## Why It Matters for RAG Builders
OpenPhoenix provides a lightweight, secure, and portable AI assistant framework that prioritizes privacy and minimalism, making it ideal for users who need a self-contained, multi-platform solution without external dependencies.
