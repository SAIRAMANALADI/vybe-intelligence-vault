## Summary
ChatWalaʻau is a full-stack localhost AI agent runtime that integrates a modern chat UI, tools, RAG, and MCP into a single `pip install` package. It enables local-first AI agent development with built-in features like model switching, agent tools, knowledge graphs, and an OpenAI-compatible API.

## Key Features
- Full-stack localhost AI agent runtime with integrated chat UI and tools
- Built-in RAG pipeline over PDFs using ChromaDB with pipeline jobs engine
- Multi-provider model support (Azure OpenAI, Anthropic, OpenAI, Microsoft Foundry) with runtime switching
- MCP native integration for connecting external tools and servers
- Declarative agent definition, memory management, and ontology-based knowledge graphs
