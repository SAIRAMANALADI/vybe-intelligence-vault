## Summary
A production-grade Model Context Protocol (MCP) server that enables AI agents (e.g., Cursor, Claude Desktop) to interact with OpenRouter's multimodal AI models for chat, vision, audio, and video capabilities. It provides 19 tools across 300+ models with robust security, async operations, and extensive testing.

## Key Features
- Supports 19 tools across text, vision, audio, and video capabilities with 300+ OpenRouter models
- Production-hardened with input/output path sandboxes, SSRF guards, and structured errors
- Async operations for long-running models (e.g., video generation) with progress notifications
- Cross-platform deployment via npm, Docker, Python (uvx), and MCP registries
- 770+ automated tests (unit, mock, regression, and live integration) ensuring reliability

## Why It Matters for RAG Builders
It provides a unified, secure, and scalable interface for AI agents to leverage multimodal capabilities from OpenRouter, simplifying integration for RAG builders.
