## Summary
A template repository for building MCP servers that provide AI assistants with plain-English access to official, public data about a specific metro area, including property records, permits, civic data, schools, and public safety. It includes a specification, a list of cities, and a standardized template for new implementations.

## Key Features
- Standardized template for building city-specific MCP servers with minimal setup
- Pre-built libraries for error handling, retry logic, geocoding, and logging
- Tiered tool gating for scaling to 20+ tools per server
- Contract testing to ensure MCP tool compliance
- Apache 2.0 licensed for commercial and open-source use

## Why It Matters for RAG Builders
It provides a standardized, production-ready template for building MCP servers that expose local public data, reducing development time and ensuring consistency for AI assistants.
