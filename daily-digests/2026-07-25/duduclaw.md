## Summary
DuDuClaw is an open-source, self-hostable AI agent platform that bridges AI command-line tools like Claude Code, Codex, and Gemini with popular communication platforms (Telegram, LINE, Discord, Slack, etc.). It provides a 24/7 AI assistant with conversation memory, multi-LLM failover, and a built-in web dashboard for managing agents and workflows.

## Key Features
- Supports 9+ communication channels (Telegram, LINE, Discord, Slack, etc.) with per-agent bot tokens and native formatting.
- Multi-LLM runtime with automatic failover, context retention, and 4 switching strategies.
- Built-in 138+ MCP tools for communication, memory, agent orchestration, ERP integration, and more.
- Self-evolution engine (GVU² dual-loop) with MistakeNotebook for continuous improvement.
- Comprehensive security layer with PolicyKernel, OS sandboxing, and AES-256-GCM encryption.

## Why It Matters for RAG Builders
DuDuClaw simplifies the deployment of production-grade AI agents across multiple platforms and LLMs, reducing infrastructure overhead while ensuring scalability, security, and self-improvement capabilities for RAG builders.
