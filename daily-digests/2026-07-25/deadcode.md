## Summary
DeadCode is a CLI tool designed to detect and remove unused exports, dead routes, orphaned CSS, and unreferenced components in TypeScript, React, and Next.js projects. It helps developers optimize bundle size and maintain clean codebases.

## Key Features
- Detects unused exports, dead routes, orphaned CSS, and unreferenced components
- Supports TypeScript, React, and Next.js projects
- Safe auto-removal with `--dry-run` preview to avoid breaking changes
- CI/CD integration with JSON output for automated pipelines
- Monorepo support and ignore/include patterns for flexible scanning

## Why It Matters for RAG Builders
DeadCode helps RAG builders maintain clean, optimized codebases by identifying and removing unused code, reducing bundle size and improving performance.
