## Summary
agent-harness is a Windows desktop tool designed to build, run, and test coding agents locally. It provides a clean interface for executing agent workflows, testing prompts, and connecting to AI services like OpenRouter or Anthropic.

## Key Features
- Local agent workflow execution for testing and learning
- Support for OpenRouter and Anthropic AI services
- Streaming agent loops with tool control and session saving
- Simple configuration for API keys and model selection
- Designed for educational and experimental use

## Why It Matters for RAG Builders
It provides a hands-on way to prototype, test, and understand agent workflows before integrating them into larger RAG or AI systems.
