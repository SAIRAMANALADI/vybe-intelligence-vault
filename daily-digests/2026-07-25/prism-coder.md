## Summary
Prism Coder is an MCP server that provides persistent memory, knowledge graphs, and offline tool-routing for AI agents like Claude and Cursor. It enables long-term agent memory across sessions, multi-agent coordination, and local-first inference using an open-weight model fleet.

## Key Features
- Persistent session memory that survives across agent sessions via local SQLite or cloud sync
- Knowledge graph for semantic, keyword, and graph-based search with citations
- Multi-agent Hivemind for coordinating multiple AI agents on the same project
- Cognitive routing to dynamically select the right memory store (episodic, semantic, procedural)
- Behavioral verification and session drift detection to ensure agent reliability

## Why It Matters for RAG Builders
It enables AI agents to retain long-term memory and context across sessions, improving reliability and reducing redundant explanations for RAG and AI stack builders.
