## Summary
A local MCP server and web interface enabling AI agents to play six classic board games with enforced rules, state management, and optional chat integration. The server handles game logic while the web lobby provides a cozy UI for human-AI interaction and match tracking.

## Key Features
- Six rule-enforcing game engines (Tic-tac-toe, Connect Four, Checkers, Backgammon, Chess, Battleship)
- MCP tool integration for AI-driven gameplay
- Local web Game Room with lobby, ledger, and trophy cabinet
- Automatic match recording and postgame annotation
- Themed UI with optional chat integration

## Why It Matters for RAG Builders
It provides a lightweight, rule-enforcing local game server with MCP tools, enabling AI agents to interact with humans in structured, turn-based gameplay while maintaining state integrity.
