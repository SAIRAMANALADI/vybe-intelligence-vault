## Summary
UltraGameStudio is an AI coding agent specialized for game development, enabling users to generate code, assets, and workflows for engines like Unity, Unreal, Godot, and Web. It integrates asset generation (images, 3D models, audio, video) with coding tasks in a unified chat interface.

## Key Features
- Generates code, assets, and workflows for Unity, Unreal, Godot, and Web engines in a single interface
- Supports asset generation for images, 3D models, 2D sprites, audio, video, and skeletal rigging
- Built-in multi-provider routing with free/low-cost channels to optimize API usage
- Dynamic workflow harness (`/studio`) for complex multi-step tasks with auto-switching strategies
- 40+ game-dev specialist roles for targeted expertise across programming, design, art, and production

## Why It Matters for RAG Builders
UltraGameStudio bridges the gap between AI coding agents and game development by unifying code generation with asset creation, enabling faster iteration and reducing reliance on manual asset pipelines.
