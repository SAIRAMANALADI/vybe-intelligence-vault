## Summary
A collection of AI-assisted automation tools for EPLAN Electric P8 and EPLAN EEC Pro 2026, leveraging the Model Context Protocol (MCP) to enable real-time interaction with EPLAN via LLMs. Includes a local MCP server for direct EPLAN control and remote Cloudflare Workers for semantic search over EPLAN documentation.

## Key Features
- Local MCP server for direct EPLAN Electric P8 and EEC Pro 2026 control with 156+ tools
- Remote Cloudflare Workers for semantic search over EPLAN documentation via MCP and REST API
- Dynamic tool registration for EPLAN actions with auto-detection of installed versions
- Automated validation of EPLAN actions against official documentation
- Cross-platform compatibility with Windows path handling and .NET runtime auto-selection
