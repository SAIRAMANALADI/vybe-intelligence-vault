## Summary
A next-generation MCP server that converts HTML content into clean, structured Markdown with surgical precision, preserving semantic hierarchy and readability. It enhances Turndown.js with smart heuristics for tables, code blocks, and multilingual support, designed for AI training pipelines and knowledge base population.

## Key Features
- Enhanced Turndown.js engine with custom rules for 50+ popular websites
- Smart HTML sanitization and semantic structure preservation
- Streaming conversion for large documents with sub-200ms performance
- Multilingual Markdown support including CJK, Arabic, and RTL languages
- Seamless integration with OpenAI, Claude, and MCP clients for AI workflows

## Why It Matters for RAG Builders
It streamlines the conversion of web content into clean Markdown, a critical preprocessing step for RAG pipelines and AI training data preparation.
