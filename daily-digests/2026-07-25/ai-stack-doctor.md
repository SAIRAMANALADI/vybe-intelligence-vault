## Summary
AI Stack Doctor is an open-source AI infrastructure audit tool that provides a comprehensive health check of AI stacks, including scores, peer benchmarks, ROI estimates, compliance flags, and actionable recommendations. It supports self-hosting or a hosted service model for non-technical users.

## Key Features
- 6-tool agentic audit loop for deep AI stack analysis
- 44 company profiles across 5 regions with industry-specific benchmarks
- ROI and cost analysis for every recommendation
- 14 compliance frameworks (GDPR, CCPA, EU AI Act, etc.)
- MCP server integration for Claude Desktop users
