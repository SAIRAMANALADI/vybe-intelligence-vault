## Summary
A production-grade AI code review and agent orchestration system that automates PR/push reviews, routes between LLMs based on task criticality, and integrates autonomous research agents with Bright Data's web data tools. It persists technical memory in Oracle Autonomous DB and exposes Q&A via API/Telegram.

## Key Features
- Autonomous PR/push code reviews with deterministic security/complexity checks and LLM synthesis
- Dynamic LLM routing (Claude Opus 4 for critical tasks, Groq Llama for standard reviews)
- Persistent technical memory in Oracle Autonomous DB with structured data lifecycle
- Autonomous research agent with Bright Data tool integration for web data enrichment
- Telegram API for real-time Q&A, voice messages, and daily briefings

## Why It Matters for RAG Builders
It provides a robust, production-ready framework for automating AI-driven code reviews and agent orchestration, reducing bottlenecks and enabling scalable technical oversight with minimal operational cost.
