## Summary
AISH is a Rust-based AI-powered shell that enables natural language interaction with terminal environments, combining full PTY support with configurable security controls and plugin-based extensibility for system operations and troubleshooting.

## Key Features
- Full PTY support for interactive programs (vim, ssh, top)
- Natural language command generation and execution with risk assessment
- Configurable security policies and sandbox pre-run for safe AI operations
- Extensible plugin system with hot reloading for custom skills
- Multi-model support with local and remote LLM integration

## Why It Matters for RAG Builders
AISH bridges the gap between AI-driven automation and secure terminal operations, enabling RAG systems to safely execute and validate shell commands while providing extensible tooling for system management.
