## Summary
An unofficial Model Context Protocol (MCP) server that enables AI assistants to interact with Fastmail's email, contacts, and calendar data via the Fastmail JMAP API. Provides 52+ tools for email management, contact operations, and calendar events with full CRUD capabilities.

## Key Features
- 52+ tools for email, contacts, and calendar operations with full CRUD support
- Advanced email features including attachments, threading, and bulk operations
- Supports JMAP, CalDAV, and WebDAV APIs for comprehensive data access
- Claude Desktop Extension (.dxt) for seamless integration with AI assistants
- Security-hardened with credential redaction and path confinement for attachments

## Why It Matters for RAG Builders
It provides AI assistants with direct, structured access to Fastmail's email, contacts, and calendar data, enabling richer context-aware interactions and workflow automation.
