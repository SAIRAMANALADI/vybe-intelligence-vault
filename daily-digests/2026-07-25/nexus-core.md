## Summary
Nexus Core is an open-source regime-adaptive financial analysis engine that provides MCP tool orchestration and REST APIs for financial data, options pricing, regime detection, and DeFi analytics. It serves as the foundational layer for Protocol Wealth's research engine, enabling AI clients to access financial domain logic via standardized protocols.

## Key Features
- Regime-adaptive financial analysis with 5 market states (Growth, Transition, Hard Asset, Deflation, Repression)
- MCP tool orchestration for AI clients (Claude, GPT, Gemini) to access financial domain logic
- Comprehensive options pricing and overlay strategies (covered calls, cash-secured puts, collars)
- DeFi and on-chain analytics (Uniswap V3, Aerodrome Slipstream, wallet balances, vaults)
- Multi-tier access control and PII filtering for compliance and security

## Why It Matters for RAG Builders
Nexus Core provides a standardized, regime-aware financial analysis engine that enables AI clients to integrate complex financial logic without domain expertise, reducing development overhead for RAG/AI stack builders.
