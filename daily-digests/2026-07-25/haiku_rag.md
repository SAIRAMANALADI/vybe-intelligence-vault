## Summary
Haiku RAG is an agentic Retrieval-Augmented Generation (RAG) framework built on LanceDB, Pydantic AI, and Docling. It enables multimodal and cross-modal search, vision-aware QA, and complex analytical tasks with citations and structured document handling.

## Key Features
- Hybrid search (vector + full-text) with Reciprocal Rank Fusion
- Multimodal and cross-modal search with vision-aware QA
- Sandboxed Python code execution for complex analytical tasks
- Conversational RAG with session memory and chat TUI/web app
- Production-grade ingester with async workers, retries, and dead-letter queue

## Why It Matters for RAG Builders
Haiku RAG provides a comprehensive, production-ready framework for building advanced multimodal RAG systems with structured document handling and agentic capabilities.
