## Summary
Dottie is a self-evolving MLOps factory and agent operating system designed to train, evaluate, serve, and deploy custom LLMs with a closed-loop workflow. It emphasizes reproducibility, data versioning, and a single-CLI doctrine where the agent's only tool is the self-extending `scout` CLI for tool discovery and self-evolution.

## Key Features
- Closed-loop MLOps pipeline: data → train → eval → serve → agent → deploy → retrain
- Single-CLI doctrine with `scout` as the sole tool for self-evolution and task execution
- Reproducible training and evaluation with deterministic scripts, data versioning, and telemetry hygiene
- Modular monorepo with dedicated packages for factory, CLI, skills, and evaluation harness
- Supports self-evolving agent capabilities via `forge` commands for tool creation and integration

## Why It Matters for RAG Builders
Dottie provides a comprehensive, self-contained framework for building and deploying custom LLMs with agentic capabilities, making it essential for RAG builders seeking end-to-end automation and self-improving systems.
