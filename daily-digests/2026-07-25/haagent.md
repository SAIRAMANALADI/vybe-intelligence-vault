## Summary
HaAgent is a local-first personal AI assistant that operates from any directory, providing a Textual TUI-based workspace for file operations, document editing, project analysis, and multi-turn task execution with session recovery and memory management.

## Key Features
- Operates from any directory with workspace root awareness
- Textual TUI for session management, tool approvals, and context handling
- Multi-session recovery and memory candidate review
- Supports local and hybrid model configurations (Ollama, LM Studio, OpenAI-compatible)
- Observable runtime with episode packages for inspection and validation

## Why It Matters for RAG Builders
HaAgent simplifies local AI agent deployment with a user-friendly TUI and workspace-aware tools, making it easier to integrate and manage AI workflows for RAG builders.
