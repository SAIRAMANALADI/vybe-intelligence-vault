## Summary
vBot is a self-hosted personal AI agent framework that integrates with existing projects, supports multiple AI models, and provides persistent memory, skills, and multi-channel interaction via web UI, desktop app, CLI, or messaging platforms like Telegram and Discord.

## Key Features
- Multi-channel interaction (web UI, desktop app, CLI, Telegram, Discord)
- Support for any AI model (OpenAI, Anthropic, Ollama, etc.) with automatic fallback
- Persistent memory and workspace per agent with long-term session retention
- Extensible via local Python hooks, bundled extensions (e.g., Home Assistant), and reusable skills
- Built-in cron scheduler for unattended task automation and scheduled agent execution

## Why It Matters for RAG Builders
vBot simplifies the deployment and management of AI agents with persistent memory and multi-channel access, making it essential for RAG builders who need scalable, self-hosted agent frameworks.
