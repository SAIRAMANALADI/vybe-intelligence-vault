## Summary
PowerPoint Agent is an AI-powered tool that automates the creation of professional PowerPoint presentations for use cases like consulting, finance, or education. It leverages the Qwen AI model to generate slides based on user prompts.

## Key Features
- Generates PowerPoint slides from natural language prompts
- Supports custom branding with logo upload and color settings
- Serverless architecture using AWS Lambda and Terraform
- Integrates with Qwen AI via DashScope SDK
- Automated deployment via GitHub Actions
