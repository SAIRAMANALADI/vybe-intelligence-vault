## Summary
mcp-score enables AI-driven music notation by converting natural language descriptions into publication-ready scores via MusicXML and live MuseScore integration. It combines an MCP server, a Claude Code skill, and a MuseScore plugin for real-time score manipulation.

## Key Features
- Natural language to MusicXML score generation via AI agents
- Real-time score manipulation in MuseScore via WebSocket plugin
- 18+ MCP tools for live score editing (transposition, chords, barlines, etc.)
- Claude Code skill for autonomous score creation from plain English prompts
- Cross-platform compatibility with MuseScore, Dorico, and Sibelius

## Why It Matters for RAG Builders
It bridges the gap between AI-generated music ideas and executable notation, enabling seamless integration of natural language processing with professional music composition workflows.
