## Summary
KDNA Skills provides adapter skills for AI agents to load KDNA judgment assets (`.kdna` files) via a standardized loader. It enables agents to discover, validate, and apply judgment rules without altering system policies, ensuring safe and controlled integration of domain-specific knowledge.

## Key Features
- Standardized loader for `.kdna` judgment assets
- Multi-agent support (Codex, Claude Code, OpenCode, Cursor, GitHub Copilot)
- MCP server for stable tool-based access to KDNA assets
- Explicit runtime trace vocabulary for error handling and policy compliance
- Conservative single-asset loading to prevent silent blending of domains

## Why It Matters for RAG Builders
It enables AI agents to safely and systematically integrate domain-specific judgment rules via KDNA assets, enhancing reasoning without compromising safety or system policies.
