## Summary
A Cursor IDE plugin that automates the product development lifecycle (PDLC) by routing AI-driven requests through structured workflows via a hosted MCP server. It enables intent detection, workflow management, and session tracking for engineering tasks like feature requests, bug fixes, and code reviews.

## Key Features
- Intent detection for feature requests, bug reports, and PR reviews via `forge-autopilot` skill
- Structured PDLC workflows managed by a hosted Forge MCP server
- Session tracking and state management through lifecycle hooks (`beforeSubmitPrompt`, `stop`, `preToolUse`, `postToolUse`)
- Workflow authoring and management for organizations via `forge-workflow` skill
- OAuth authentication and admission proposal system for workflow validation

## Why It Matters for RAG Builders
It streamlines AI-powered engineering workflows by automating intent detection and structured task routing, reducing manual intervention in PDLC processes.
