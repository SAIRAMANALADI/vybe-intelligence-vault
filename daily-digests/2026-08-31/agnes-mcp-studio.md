## Summary
Agnes Media MCP provides a FastMCP-based server for image and video generation using the Agnes AI API, designed to integrate with AI agents via MCP protocol. It includes a Skill component for decision-making and a server for execution, enabling seamless media generation workflows.

## Key Features
- FastMCP-based server for media generation tasks (images/videos)
- Includes Skill component for intelligent agent decision-making
- Supports both domestic (China) and international Agnes AI API endpoints
- Provides tools for image generation, editing, and video creation with configurable parameters
- Designed for seamless integration with AI agents via MCP protocol
