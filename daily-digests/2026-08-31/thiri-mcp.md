## Summary
THIRI is a deterministic music theory MCP server and API that enables AI agents to analyze chords, perform Roman-numeral analysis, generate voicings, and reharmonize progressions with computational accuracy. It addresses hallucinations in music theory by providing a hosted, agent-native solution for chord analysis and composition.

## Key Features
- Deterministic chord analysis with Roman-numeral and harmonic function labeling
- Voicing generation and voice-leading scoring for instrument-ready outputs
- Reharmonization with 8 techniques (e.g., Coltrane changes, modal interchange)
- Hosted MCP server and REST API for seamless AI agent integration
- Server-side audio rendering (WAV) via Csound without local installation
