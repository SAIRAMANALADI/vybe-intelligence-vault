## Summary
FenCun is a personal 'perfume decision agent' that recommends which perfume to wear from your collection based on real-time context like weather, time of day, and occasion. It provides actionable usage guidance (spray amount, application spots, longevity estimates) without fabricating unverifiable metrics.

## Key Features
- Real-time context integration (weather, time, occasion) for personalized perfume recommendations
- Deterministic rule engine for explainable scoring and usage guidance (no fabricated metrics)
- Natural language scene parsing via DeepSeek for intent understanding
- Personalized feedback loop that adapts recommendations based on user responses
- Lightweight, client-side implementation with zero external dependencies for core functionality

## Why It Matters for RAG Builders
It demonstrates how deterministic rule engines and LLMs can collaborate to deliver precise, context-aware recommendations without hallucinations, offering a blueprint for AI agents in niche decision-making domains.
