## Summary
Genwave is a WordPress plugin that provides authentication, licensing, and API gateway infrastructure for the Genwave AI Agent platform. It enables secure site integration with AI-powered content generation and management features.

## Key Features
- Secure token-based authentication with AES-256-CBC encryption
- License management and domain verification for WordPress sites
- Credit balance tracking for AI usage
- API gateway integration for Genwave AI Agent
- Multi-language support (48+ languages) for AI content generation
