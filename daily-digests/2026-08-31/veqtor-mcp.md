## Summary
Veqtor MCP is a local Model Context Protocol (MCP) server designed to enable AI clients to interact with DOCX documents for verifiable contract negotiation history and tracked-change edits. It provides deterministic tools for reading redlines, verifying quotations, and applying counterproposals while maintaining local provenance.

## Key Features
- Extracts and verifies tracked changes in DOCX files with hashes and references
- Supports deterministic counterproposal batch preflight and atomic edits
- Maintains local provenance via decision records and fail-closed boundaries
- Integrates with Claude Code and Claude Desktop via MCP
- Provides bounded XML parsing and ZIP member validation for security

## Why It Matters for RAG Builders
Veqtor MCP enables AI-driven contract negotiation workflows by providing verifiable, tracked-change document processing with local provenance, ensuring transparency and reliability in legal document automation.
