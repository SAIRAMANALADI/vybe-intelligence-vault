## Summary
VRCForge is a local AI workbench designed for supervised VRChat avatar editing, integrating a Tauri desktop agent, FastAPI runtime, and Unity Editor tools. It enables users to review, apply, and restore avatar changes with explicit control and safety mechanisms.

## Key Features
- Supervised avatar editing with scan-plan-preview-approval workflow
- Integration with Unity Editor and Tauri desktop agent
- Agentic runtime with durable goal execution and memory controls
- Skill packages (.vsk) with Ed25519 signing and SHA-256 validation
- Safety-first approach with checkpoints, rollback, and explicit user approvals

## Why It Matters for RAG Builders
VRCForge provides a critical supervised workflow for AI-driven VRChat avatar editing, ensuring safety and control in asset modifications while integrating local AI agents and Unity tools.
