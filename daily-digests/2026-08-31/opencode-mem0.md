## Summary
OpenCode-Mem0 is an OpenCode plugin that provides persistent memory for coding agents using a local vector database (SQLite + USearch). It enables automatic memory capture, hybrid search, and user profile learning without requiring cloud services, ensuring all data remains on the user's machine.

## Key Features
- 7-factor memory scoring system for relevance and decay management
- Hybrid search combining vector similarity (USearch) and full-text search (SQLite FTS5)
- STM/LTM dual-store lifecycle with intelligent conflict resolution
- Auto-capture of memories from idle sessions with privacy filtering
- Web UI for browsing, searching, and managing memories locally

## Why It Matters for RAG Builders
It enables coding agents to retain context and learn from past interactions without cloud dependency, enhancing RAG systems with persistent, local memory management.
