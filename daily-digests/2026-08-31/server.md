## Summary
MariaDB Server is a high-performance, open-source relational database forked from MySQL, offering advanced features like native vector search, pluggable storage engines, and clustering. It serves as a drop-in replacement for MySQL while providing additional capabilities for modern AI and data workloads.

## Key Features
- Native vector search with HNSW indexing for AI/ML workloads
- Pluggable storage engines supporting diverse data models (InnoDB, MyRocks, ColumnStore)
- Synchronous clustering (Galera) and advanced replication for high availability
- Full MySQL compatibility with Oracle SQL mode for stored routines
- Built-in security features including encryption, RBAC, and TLS

MariaDB's native vector search and SQL capabilities make it a critical backend for RAG systems requiring structured data storage and efficient similarity search.
