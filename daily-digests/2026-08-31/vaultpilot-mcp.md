## Summary
VaultPilot MCP is a self-custodial DeFi toolkit for AI agents that enables secure, hardware-verified transaction preparation and signing across multiple blockchains using Ledger devices. It ensures tamper-evident execution even if the agent, MCP server, or host is compromised.

## Key Features
- Cross-chain DeFi portfolio aggregation and position tracking across Ethereum, Solana, Bitcoin, Litecoin, and TRON
- Hardware-verified transaction preparation and signing via Ledger devices to prevent tampering
- Support for 190+ tools including lending, staking, swaps, bridges, and forensic chain reads
- Security-first design with on-device attestation, contract verification, and second-LLM cross-checks
- Integration with MCP-compatible clients like Claude Code, Cursor, and hosted MCP endpoints

## Why It Matters for RAG Builders
It provides a critical security layer for AI agents interacting with DeFi protocols by ensuring hardware-verified, tamper-evident transaction execution across multiple blockchains.
