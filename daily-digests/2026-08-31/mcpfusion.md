## Summary
MCP Fusion is a TypeScript framework for building secure, MCP 2.0-native servers with enforced architectural security, state gating, and AI-ready governance. It enables AI coding agents to generate governed MCP servers from machine-readable contracts (SKILL.md) while ensuring data privacy and workflow compliance.

## Key Features
- 100% MCP 2.0 compliance with full feature support and deprecation handling
- Architectural security enforced via egress firewalls, state gating, and prompt injection detection
- AI-ready SKILL.md contract for generating governed MCP servers automatically
- Governance stack with behavioral digests, lockfiles, and runtime attestation
- Multi-pathway development (YAML, typed MVA, FSM) with zero-code to full-control options

## Why It Matters for RAG Builders
MCP Fusion provides the critical security and governance layer required for building reliable, auditable MCP servers that AI agents can safely interact with in production environments.
