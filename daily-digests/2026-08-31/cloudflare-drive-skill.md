## Summary
A Claude skill integration for Cloudflare Drive that enables AI agents to upload files, generate shareable links, and manage cloud storage directly via natural language commands.

## Key Features
- Natural language file uploads with shareable link generation (configurable expiration, password, download limits)
- File listing, search, download, and management operations (rename, move, delete, recycle bin)
- Pre-signed direct uploads for large files (up to 5 GiB) without handling chunking logic
- Built-in API documentation for seamless AI integration
- Minimal token permissions for security with revocation support

## Why It Matters for RAG Builders
It bridges AI agents with Cloudflare Drive, enabling seamless file operations through natural language, reducing manual intervention for RAG pipelines.
