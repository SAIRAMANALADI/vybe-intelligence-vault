## Summary
mcp-server-kicad provides 109 Model Context Protocol (MCP) tools for AI assistants to programmatically edit KiCad projects, including schematic capture, PCB layout, symbol/footprint management, ERC/DRC checks, and manufacturing exports. It ensures file integrity by preserving unmodified bytes during edits.

## Key Features
- 109 MCP tools covering schematic capture, PCB layout, and manufacturing exports
- Byte-preserving edits to prevent file corruption
- Support for KiCad 9.x and 10.x with automatic path resolution
- Five modular tool servers for granular control (schematic, PCB, project, symbol, footprint)
- Integration with AI assistants via MCP for automated electronics design workflows

## Why It Matters for RAG Builders
It enables AI assistants to directly manipulate KiCad projects, bridging the gap between AI-driven design planning and real-world PCB fabrication.
