## Summary
VS MCP Server is a Visual Studio extension that exposes IDE features through the Model Context Protocol (MCP), enabling AI assistants like Claude to programmatically interact with Visual Studio for tasks such as file manipulation, debugging, and project management.

## Key Features
- Enables AI assistants to control Visual Studio via MCP for file, project, and solution operations
- Provides 30+ tools for document editing, debugging, build management, and navigation
- Supports both HTTP and legacy SSE protocols for MCP client communication
- Configurable auto-start, port binding, and logging for flexible deployment
- Backward-compatible port for Visual Studio 2022 17.12 and .NET 9
