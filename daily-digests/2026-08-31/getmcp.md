## Summary
A universal installer and configuration tool for MCP (Model Context Protocol) servers that standardizes setup across 19 AI applications with support for multiple config formats (JSON, YAML, TOML, JSONC). It provides a canonical format, auto-detection, and a registry of 105+ pre-configured servers.

## Key Features
- Canonical config format aligned with MCP registry schema for consistency across apps
- Auto-detection of 19 AI applications and their specific config formats (JSON, YAML, TOML, JSONC)
- Registry of 105+ pre-configured MCP servers with support for stdio and remote transports
- Library-first design with npm packages (@getmcp/core, @getmcp/generators, @getmcp/registry, @getmcp/cli) for programmatic use
- Zero runtime dependencies and offline/local-first operation with config generation

## Why It Matters for RAG Builders
It eliminates the fragmentation in MCP server configuration across AI tools, enabling seamless integration and deployment of servers for RAG pipelines.
