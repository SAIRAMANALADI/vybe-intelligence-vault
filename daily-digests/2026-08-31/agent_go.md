## Summary
agent_go is a structured orchestration tool that wraps Claude Code to break complex tasks into isolated, concurrently executable subtasks using a Plan-Decompose-Execute workflow. It ensures structured execution, cost control, and recovery mechanisms for AI-driven software engineering tasks.

## Key Features
- Structured Plan-Decompose-Execute workflow for complex tasks
- Isolated subtasks in git worktrees with concurrent execution
- Topological wave scheduling for parallel subtask execution
- Built-in cost control with multi-layer budgeting (L1/L2/L3)
- MCP server/client support for external tool integration

## Why It Matters for RAG Builders
agent_go provides a robust framework for decomposing and executing complex AI-driven tasks with structured workflows, cost control, and recovery mechanisms, making it essential for scalable RAG and AI engineering pipelines.
