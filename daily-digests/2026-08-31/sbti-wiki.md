## Summary
A desktop application providing a comprehensive Chinese-language wiki for the SBTI personality test, displaying all 27 possible outcomes including standard types, the HHHH fallback, and the DRUNK hidden result. The tool serves as a centralized reference for personality archetypes and their traits.

## Key Features
- Displays all 27 SBTI personality test outcomes in a single interface
- Supports offline viewing of personality descriptions and traits
- Includes HHHH fallback and DRUNK hidden results for completeness
- Allows side-by-side comparison of personality profiles
- Customizable display modes (light/dark theme) and font sizes
