## Summary
projectmem is a local-first memory and judgment layer for AI coding agents that captures issues, attempts, fixes, and decisions to prevent repeated failures and improve agent efficiency. It integrates with AI tools like Claude Code and Cursor via an MCP server, offering pre-commit warnings, session briefings, and visualizations of project history.

## Key Features
- Persistent event-sourced memory layer for AI agents with 15 MCP tools for integration with popular IDEs
- Pre-commit warnings that prevent repeating failed approaches by leveraging stored memory
- Cross-project global dashboard (`pjm dashboard`) for aggregated insights across multiple repositories
- Visualization suite (Showoff, Flow, Time Spine) for interactive project history and memory exploration
- Stale-memory detection and session-start briefings to keep AI agents informed and efficient

## Why It Matters for RAG Builders
It provides a persistent, local-first memory layer that enables AI coding agents to retain context, avoid repeating failures, and improve efficiency by leveraging past project experiences.
