## Summary
A bilingual AI-powered workflow for generating, beautifying, and reviewing professional PowerPoint presentations from technical briefs or existing decks. It supports Chinese, English, and dual-language outputs while preserving original files.

## Key Features
- Two workflows: create new PPTs or beautify existing ones while preserving structure and content
- Supports Continuous and Checkpointed execution modes for user control
- Multi-language support (Chinese, English, and dual-language outputs)
- Preserves original files and generates reviewed copies with versioning
- Integrates with AI agents to automate PPT creation, review, and quality checks
