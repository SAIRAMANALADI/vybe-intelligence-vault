## Summary
speclaw is a toolkit that transforms any codebase into a spec-driven, agent-ready environment by generating a project constitution (LAWS.md), a local code graph (Compass) for efficient navigation, and a disciplined workflow (Spec) for AI coding agents. It operates entirely locally without LLMs, cloud, or API keys.

## Key Features
- Generates a project constitution (LAWS.md) and agent contracts from real codebase rules
- Provides a local code graph (Compass) for token-efficient code navigation and understanding
- Offers a disciplined spec workflow (draft → build → sync → archive) for structured AI agent operations
- Operates 100% locally with no LLM, cloud, or API dependencies
- Supports both CLI and MCP server integration for seamless agent integration

## Why It Matters for RAG Builders
speclaw ensures AI agents adhere to project-specific rules and conventions by codifying them into enforceable laws, reducing errors and improving consistency in automated code generation.
