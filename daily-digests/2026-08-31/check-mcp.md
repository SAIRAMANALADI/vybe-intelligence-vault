## Summary
A Model Context Protocol (MCP) server wrapper for Check, a command firewall that validates shell commands before execution for AI agents. It provides real-time command validation to prevent unsafe or invalid commands from running.

## Key Features
- Validates shell commands before execution to prevent unsafe operations
- Integrates seamlessly with MCP clients like Cursor, Windsurf, and Claude Desktop
- Automatically mints a free API key on first run with no signup required
- Supports both validation-only and validation-then-execution workflows
- Offers 120 free checks daily with pay-as-you-go pricing thereafter

## Why It Matters for RAG Builders
It ensures AI agents execute only safe and valid shell commands, reducing hallucinations and security risks in automated workflows.
