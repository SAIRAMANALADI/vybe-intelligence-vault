## Summary
LongParser is a Windows-based desktop application that converts documents (PDF, DOCX, PPTX, XLSX, CSV) into clean, AI-ready text chunks for RAG systems. It supports human-in-the-loop review, OCR for scanned PDFs, and includes a FastAPI server for local or team use.

## Key Features
- Supports multiple file formats (PDF, DOCX, PPTX, XLSX, CSV)
- Human-in-the-loop review for quality control
- OCR integration for scanned PDFs
- FastAPI server for API-based document processing
- Privacy-focused local processing

## Why It Matters for RAG Builders
