## Summary
A native Irodori Table connector extension for Qdrant, providing a Rust-based driver to integrate Qdrant vector databases with the Irodori extension marketplace. It enables vector similarity search, filtered ANN search, and metadata queries through standardized ABI calls.

## Key Features
- Native Rust driver for Qdrant with ABI exports for Irodori Table
- Supports multiple authentication methods (API key, bearer token, client certificate, etc.)
- Enables vector similarity search, filtered ANN search, and metadata queries
- Flexible endpoint and transport modes (direct, SSH tunnel, SOCKS5, proxies)
- 0BSD licensed, allowing broad usage and modification

## Why It Matters for RAG Builders
This connector bridges Qdrant vector databases with the Irodori Table ecosystem, enabling seamless RAG workflows for AI applications requiring vector search and metadata retrieval.
