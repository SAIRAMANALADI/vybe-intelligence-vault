## Summary
The Eveoy MCP server is a Cloudflare Worker-based agent endpoint that enables AI assistants to interact with Eveoy's services for marketing and sales automation. It provides tools for learning about Eveoy, generating quotes, capturing brand profiles, and ordering verified in-store customer visits, all without requiring user authentication.

## Key Features
- Streamable HTTP MCP endpoint with SSE legacy support for broader compatibility
- 11 tools and 5 prompts for end-to-end marketing and sales workflows
- Anonymous agent interactions with no sign-in required for purchases
- Real-time CRM integration with Zoho for lead and deal tracking
- Strict public-only data classifier to prevent exposure of internal information
