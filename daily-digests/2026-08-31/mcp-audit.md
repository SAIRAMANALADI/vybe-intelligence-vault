## Summary
A Python security scanner for Model Context Protocol (MCP) servers that identifies vulnerabilities like prompt injection, over-broad permissions, weak input validation, and credential leaks before AI agents interact with them.

## Key Features
- Scans MCP servers for security flaws including prompt injection, credential leaks, and unconstrained tool capabilities
- Supports both stdio and Streamable HTTP MCP server transports
- Provides CLI with JSON and Markdown output for CI integration and reporting
- Includes six built-in rules with clear severity levels (critical, high, medium, low)
- Designed for easy extension with custom rules and Python-native integration

## Why It Matters for RAG Builders
It proactively identifies security risks in MCP servers before AI agents integrate them, preventing prompt injection and credential leaks that could compromise AI systems.
