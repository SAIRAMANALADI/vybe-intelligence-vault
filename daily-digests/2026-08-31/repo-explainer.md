## Summary
explainmyrepo automates the creation of high-quality, visual explainers for GitHub repositories, transforming opaque codebases into clear, art-directed web pages with architecture diagrams, data-flow visualizations, and AI-ready knowledge packs. It ensures output meets strict quality standards via an independent grading system before deployment.

## Key Features
- Generates bespoke, art-directed explainer pages with real architecture and data-flow diagrams derived from the repository's code.
- Produces three artifacts: a live explainer web page, a GitHub repo for edits, and a downloadable AI knowledge pack with vector embeddings and MCP server.
- Enforces a strict quality gate with independent vision-model critics and operator questions, ensuring output meets high standards before deployment.
- Includes a learning loop where every build's outcomes and reader feedback improve future builds, closing the feedback cycle.
- Supports public and private repositories with a single Claude Code skill, adaptable via hosted website, CLI, or plugin.

## Why It Matters for RAG Builders
It eliminates the opacity of GitHub repositories by generating high-quality, visually rich explainers that make complex codebases accessible to both humans and AI systems, reducing onboarding friction and improving AI-assisted development accuracy.
