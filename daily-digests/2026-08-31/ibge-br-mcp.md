## Summary
An MCP server providing real-time access to Brazil's official public data from IBGE APIs, enabling AI assistants to query live, structured geographic, demographic, economic, and health data with full provenance and citation support.

## Key Features
- 22 specialized tools covering all major IBGE data domains (geography, demographics, economics, health)
- Automatic provenance blocks with canonical URLs, reference periods, and citations for every response
- 460+ automated tests with 97%+ core coverage and robust error handling
- Configurable caching with TTL and exponential backoff for network resilience
- Full TypeScript support with strict typing and comprehensive validation

## Why It Matters for RAG Builders
It ensures AI assistants can provide accurate, citable, and up-to-date Brazilian public data by querying official IBGE APIs in real time, eliminating guesswork from training data.
