## Summary
Lydia Agent is a self-improving AI agent framework designed for autonomous skill creation, memory persistence, and cross-platform interaction. It supports multiple LLM providers, scheduled automations, and sub-agent delegation while running efficiently on low-cost infrastructure like $5 VPS or serverless setups.

## Key Features
- Built-in learning loop with autonomous skill creation and self-improvement during use
- Cross-platform messaging gateway (Telegram, Discord, Slack, WhatsApp, Signal, CLI)
- Closed-loop memory system with periodic nudges and FTS5 session search for recall
- Supports scheduled automations and parallel sub-agent delegation
- Runs on diverse infrastructure (local, Docker, SSH, Modal, Daytona) with serverless persistence

## Why It Matters for RAG Builders
Lydia Agent provides a robust, self-improving framework for building AI agents that learn, adapt, and operate autonomously across platforms, making it essential for developers seeking scalable, memory-aware agent systems.
