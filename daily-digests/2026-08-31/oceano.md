## Summary
Oceano is a self-hosted, local-first AI agent that operates entirely on your own machine, providing ChatGPT-style chat with real tools, a persistent workspace, and a suite of built-in capabilities. It integrates local model serving, web browsing, memory, document search, and multi-modal interactions while ensuring data privacy.

## Key Features
- Runs entirely locally with optional remote model endpoints for delegation
- 102 built-in tools including filesystem, shell, web browsing, email, calendar, and MCP integration
- Persistent memory and document RAG with semantic search and graph visualization
- GPU-aware installation with automatic backend selection (CUDA/Vulkan/ROCm/CPU)
- Real-time headless browser control and multi-tab live streaming

## Why It Matters for RAG Builders
Oceano provides a comprehensive, self-contained local AI agent framework with deep tool integration and privacy-preserving capabilities, making it ideal for builders who need an all-in-one solution for secure, offline-capable AI applications.
