## Summary
A Model Context Protocol (MCP) server that bridges Canvas LMS with AI assistants, enabling natural language interactions for course management, grading, and analytics. It provides 111 tools to interact with Canvas via REST APIs, facilitating AI-driven educational workflows.

## Key Features
- 111 tools for Canvas LMS operations (courses, assignments, grading, discussions, analytics, etc.)
- Natural language processing integration with AI assistants (Claude, Cursor, etc.)
- Secure authentication via Canvas API tokens and domain configuration
- CLI and configuration support for local and remote deployment
- Supports both classic and modern (LTI) Canvas quizzes

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with Canvas LMS, automating educational workflows and reducing manual tasks for educators.
