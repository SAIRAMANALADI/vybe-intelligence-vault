## Summary
A zero-dependency Python library for deterministic agent memory with verifiable erasure, tamper-evident record-keeping, and compliance evidence for EU AI Act/GDPR. It ensures corrections persist, deletions are provable, and memory integrity is measurable across systems.

## Key Features
- Deterministic memory writes with no LLM dependency on the write path
- Verifiable erasure with signed receipts and offline-verifiable evidence
- Tamper-evident record-keeping via hash-linked receipts and content-bound audits
- EU AI Act/GDPR compliance evidence layer for agent memory
- Residue scanning tool to verify data deletion across storage systems

## Why It Matters for RAG Builders
It provides critical infrastructure for RAG builders to ensure memory integrity, compliance, and verifiable data deletion, addressing gaps in existing agent-memory solutions.
