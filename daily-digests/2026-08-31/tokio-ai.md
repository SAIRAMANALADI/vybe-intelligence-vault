## Summary
TokIO AI is an open-source financial research agent that rigorously tests claims using statistical methods like permutation tests and multiple-testing corrections before providing insights. It integrates real-time financial data (price history, SEC filings) with disciplined hypothesis testing to avoid false patterns in stock analysis.

## Key Features
- Pulls real-time financial data (OHLCV price history, SEC filings) without requiring API keys for basic use
- Runs permutation tests and multiple-testing corrections to validate claims before trusting results
- Interactive CLI for querying financial hypotheses and receiving statistically validated answers
- Modular architecture with a pure-Python rigor engine and tool-based agent loop
- Supports ranking stocks by performance and testing technical conditions for predictive patterns

## Why It Matters for RAG Builders
