## Summary
Agent OS is a NixOS-based system that boots directly into a local AI agent shell, replacing traditional desktop interfaces with a conversational AI. It prioritizes sovereignty, offline capability, and local-first memory management using markdown files.

## Key Features
- Bootable NixOS system with autologin to an AI shell
- Local model inference (Qwen 2.5 7B) with no cloud dependency
- Markdown-based memory system (`~/memory/`) for human-readable knowledge storage
- Strict egress firewall (default-DROP) with fail-loud sealing for sovereignty
- Declarative system configuration via Nix flakes for reproducibility

## Why It Matters for RAG Builders
