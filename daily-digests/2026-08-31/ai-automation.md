This repository provides a collection of AI automation workflows built using n8n, an open-source low-code automation platform. - Pre-built n8n workflows for AI automation tasks like chatbots, RAG agents, and MCP servers
- Integration with vector databases (Pinecone) and cloud databases (Supabase, PostgreSQL)
