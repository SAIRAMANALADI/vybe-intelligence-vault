## Summary
Synaptic is a source-grounded code maintenance platform that combines API maintenance, repository memory, and a persistent knowledge graph to help engineers and AI assistants understand, track, and safely modify codebases. It provides structural clarity, impact analysis, and automated repair planning for large-scale software projects.

## Key Features
- Persistent, queryable knowledge graph for 30+ programming languages using tree-sitter parsers
- API maintenance system for detecting breaking changes and planning bounded repairs
- Repository memory for preserving historical context, decisions, and artifacts
- Dynamic-dispatch awareness and SQL auditing for performance and security analysis
- MCP server integration for AI assistant workflows and automated tooling

## Why It Matters for RAG Builders
Synaptic provides essential structural and historical context for AI-driven code maintenance, enabling safer, more accurate refactoring and dependency updates in large codebases.
