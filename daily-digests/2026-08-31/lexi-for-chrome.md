## Summary
Lexi for Chrome is a Chrome extension that integrates Lexi's AI-powered legal assistant directly into the browser's side panel, enabling users to analyze legal documents, flag risky terms, extract key dates, and interact with web content via chat or optional agent mode.

## Key Features
- Seamless integration with Lexi's AI pipeline for legal document analysis and chat
- Agent mode for automated form-filling and interactions (opt-in and per-site)
- Privacy-focused architecture with local session storage and no external tracking
- Cross-platform chat history sync between extension and web app
- Jurisdiction-neutral by default with optional user-defined context

## Why It Matters for RAG Builders
It provides a practical, privacy-conscious way to integrate AI-powered legal analysis into everyday browsing workflows, reducing friction for users who need to review or interact with legal documents online.
