## Summary
An MCP (Model Context Protocol) server for Centreon monitoring written in Go, exposing 88 tools for real-time monitoring, configuration management, and infrastructure operations. Integrates with MCP-compatible AI clients like Claude Code or Desktop.

## Key Features
- 88 tools covering monitoring, configuration, downtimes, acknowledgements, and infrastructure management
- Three transport modes: stdio, HTTP (streamable), and HTTP gateway mode
- Gateway mode with token caching (50-minute cache) for multi-tenant deployments
- Structured JSON logging with configurable log levels
- Self-signed certificate support and reverse proxy compatibility

## Why It Matters for RAG Builders
It bridges Centreon's monitoring capabilities with AI workflows via MCP, enabling AI agents to interact with infrastructure data and perform real-time operations.
