## Summary
Another Brain provides long-term memory sharing for AI coding agents via a lightweight, local-first MCP server. It enables agents like Claude Code and Codex to retain and recall shared context without external dependencies, using SQLite for storage and local ONNX embeddings for semantic search.

## Key Features
- Lightweight, single-executable MCP server with no external dependencies or servers
- Hybrid search combining semantic similarity and full-text keyword matching
- Self-expiring memories with adjustable lifespans and soft deletion for recoverability
- One-shot setup and harness integration across multiple AI coding agents (Claude, Codex, Cursor, etc.)
- Local ONNX embeddings for CPU-based semantic search with no network requirements

## Why It Matters for RAG Builders
It enables AI agents to share and retain context over time without external infrastructure, reducing hallucinations and improving consistency in long-running tasks.
