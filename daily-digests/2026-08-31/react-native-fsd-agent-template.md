## Summary
A React Native + Expo template with Feature-Sliced Design (FSD) architecture, designed for AI agent-based full-lifecycle development. It includes 10 specialized agents and 9 skills to automate the entire pipeline from ideation to deployment, with a post-launch continuous improvement loop.

## Key Features
- AI-driven full-lifecycle development pipeline with 10 specialized agents
- Feature-Sliced Design (FSD) architecture for modular and scalable code
- Post-launch continuous improvement loop for iterative enhancements
- Pre-configured tech stack with React Native, Expo, TypeScript, and Zustand
- Automated QA, design system, and deployment workflows
