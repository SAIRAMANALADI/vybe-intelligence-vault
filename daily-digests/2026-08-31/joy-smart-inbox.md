## Summary
A deployable demo showcasing an AI agent that resolves patient inbox messages by interacting with practice systems through a multi-step tool-using loop. It integrates governance, guardrails, and safety checks to handle sensitive healthcare data responsibly.

## Key Features
- Multi-step tool-using agentic loop with Gemini for patient message resolution
- Deterministic safety net bypassing the agent for emergencies
- Comprehensive governance and guardrails (input/output safety, PHI redaction)
- Policy-driven human-in-the-loop release decisions and audit trails
- LLM-as-judge evaluation with CI-style regression gates

## Why It Matters for RAG Builders
It demonstrates how to build responsible, multi-step AI agents for sensitive domains like healthcare with robust governance and safety mechanisms.
