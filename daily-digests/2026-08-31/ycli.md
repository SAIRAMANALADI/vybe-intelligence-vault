## Summary
ycli is a unified Yandex 360 toolkit that provides CLI, MCP server, Python SDK, and Claude Code plugin interfaces to interact with Yandex Tracker, Wiki, and Forms. It enables seamless integration for both human users and AI agents with minimal setup.

## Key Features
- Unified SDK supporting CLI, MCP server, Python library, and Claude Code plugin
- Read-only MCP server for safe AI agent exploration of Yandex 360 resources
- Near-complete API coverage for Tracker, Wiki, and Forms with 230+ operations
- 100% test coverage and typed models for reliability
- Zero-friction setup with environment-based authentication
