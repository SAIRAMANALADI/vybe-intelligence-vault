## Summary
A remote MCP server that integrates Oura Ring health data with AI chat clients like ChatGPT or Claude, enabling conversational queries about sleep, activity, readiness, and vitals without requiring a dedicated UI or app.

## Key Features
- Task-oriented tools (10) that group Oura API endpoints for natural language queries
- Token-efficient responses with pre-processed data (e.g., durations in minutes, baked-in units)
- Read-only operations with `readOnlyHint` to avoid unnecessary user confirmations
- Support for both real Oura Ring data and sandbox mode for testing
- Flexible deployment options (local, Docker, remote) with zero-config demo mode

## Why It Matters for RAG Builders
It bridges the gap between wearable health data and AI chat clients, enabling seamless, conversational analysis of personal health metrics without requiring custom dashboards or manual data processing.
