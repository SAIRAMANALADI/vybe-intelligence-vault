## Summary
plugin-kit-ai enables developers to build AI agent plugins once and deploy them across multiple platforms like Claude, Codex, Gemini, Cursor, and OpenCode without duplicating code. It provides a standardized workflow for authoring, validating, and generating plugin outputs from a single source of truth.

## Key Features
- Single-source plugin authoring under `plugin/` directory with generated outputs managed automatically
- Supports multiple AI agent platforms (Claude, Codex, Gemini, Cursor, OpenCode) with platform-specific validation
- CLI tools for initialization, inspection, generation, validation, and deployment of plugins
- Agent Plugins 1.0 standard for consistent plugin definitions and compatibility across clients
- Built-in CI/CD workflows for testing, documentation, and release management

## Why It Matters for RAG Builders
It simplifies the creation and deployment of AI agent plugins by enabling a single codebase to target multiple platforms, reducing duplication and maintenance overhead for RAG builders.
