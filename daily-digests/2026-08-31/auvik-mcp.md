## Summary
A Model Context Protocol (MCP) server for the Auvik network monitoring API, enabling programmatic interaction with Auvik's platform for managing devices, networks, alerts, and other network infrastructure data.

## Key Features
- 25+ pre-built tools for Auvik API endpoints covering devices, networks, alerts, and billing
- Supports both HTTP and stdio transports for flexible deployment
- Type-safe implementation with TypeScript and Zod validation
- Multi-tenant support for single-tenant and gateway modes
- Docker-ready containerized solution with health checks
