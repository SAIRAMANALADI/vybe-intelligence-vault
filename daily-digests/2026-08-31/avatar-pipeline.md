## Summary
avatar-pipeline is a desktop application that converts plain English text into 3D WebGL animations using local AI and a Next.js frontend with a FastAPI backend. It enables users to generate repeatable 3D motion sequences from natural language commands without requiring a full developer stack.

## Key Features
- Converts plain English text into 3D WebGL animations in real-time
- Uses local AI (Groq API + Llama-3.3) for structured command interpretation
- Provides a desktop-ready application with minimal setup required
- Supports repeatable and stable animation sequences for demos and testing
- Integrates Next.js frontend with FastAPI backend and Docker for deployment

## Why It Matters for RAG Builders
It simplifies the creation of AI-driven 3D animations from natural language, making it accessible for rapid prototyping and training workflows without complex development setups.
