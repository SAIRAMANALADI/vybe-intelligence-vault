## Summary
Blacksite is a VS Code extension that provides an AI coding agent with deep workspace integration, enabling file edits, shell execution, search, LSP-backed code intelligence, and browser automation. It offers a visual codebase map, multi-phase planning, ticket management, and local data storage for project context.

## Key Features
- Agentic chat with file edits, shell execution, and LSP-backed code intelligence
- Interactive codebase map with star-field visualization and relationship arcs
- Durable multi-phase plans with session persistence and ticket management
- Embedded SQLite workbench with vector search and optional pgvector support
- Ticket Loops for supervised unattended queue execution with spend tracking
