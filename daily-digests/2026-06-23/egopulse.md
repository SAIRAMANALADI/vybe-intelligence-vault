## Summary
EgoPulse is a self-hosted AI agent runtime written in Rust that enables multi-agent systems with independent memory, tooling, and sessions. It supports multiple interfaces (Web UI, Discord, Telegram, TUI, CLI) and features advanced memory management with episodic, semantic, and prospective layers.

## Key Features
- Multi-agent support with independent memory and tooling per agent
- Three-layer memory system (episodic, semantic, prospective) with sleep batch processing
- PULSE system for selective attention and activation of agent awareness
- Supports multiple interfaces (Web UI, Discord, Telegram, TUI, CLI) in a single binary
- Built-in tools, MCP integration, and configurable system prompts
