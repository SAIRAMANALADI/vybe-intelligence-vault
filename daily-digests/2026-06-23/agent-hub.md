## Summary
Agent Hub is a local-first AI agent workspace that enables users to chat with AI, manage files, and automate tasks entirely on their machine. It supports multiple AI providers like Ollama, OpenAI, DeepSeek, and Google Gemini, and integrates with external tools via MCP servers and OAuth connectors.

## Key Features
- Custom state-machine ReAct loop with iteration limits and SSE streaming for real-time responses
- Multi-layered security with permission modes, danger pattern blocking, and LLM safety classifiers
- Over 40 built-in tools for file operations, office suites, Google Workspace, GitHub, Slack, and Notion
- Sub-agent system with runtime spawning, monitoring, and plan-based execution
- Long-term memory with auto-extraction and persistent context across sessions

## Why It Matters for RAG Builders
Agent Hub provides a robust, local-first framework for building and managing AI agents with advanced safety, tool integration, and multi-provider support, making it essential for developers constructing complex RAG and agentic systems.
