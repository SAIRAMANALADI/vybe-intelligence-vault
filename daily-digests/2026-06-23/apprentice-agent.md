## Summary
AURA is a multi-surface personal AI assistant platform featuring a CLI, FastAPI backend, React web app, browser extension, and Telegram integration. It combines a local-first assistant runtime with agentic tool loops, shared memory, and experimental cognitive systems.

## Key Features
- Multi-surface presence (CLI, Web, Extension, Telegram)
- Persistent memory and retrieval with knowledge graph integration
- Agentic tool execution (82+ tools including shell, git, code editing, and web fetch)
- Local-first architecture with optional cloud-backed model routing
- Experimental cognitive subsystems (emotion, dreaming, multi-agent orchestration)
