## Summary
A full-stack starter template for building streaming, tool-use AI agents with a React-based chat UI, multi-user authentication, and runtime LLM configuration. It provides a deployable foundation with provider-agnostic LLM integration via LiteLLM, tool-use capabilities, and optional Telegram bot integration.

## Key Features
- Provider-agnostic LLM integration via LiteLLM (supports Anthropic, OpenAI, Gemini, etc.)
- Streaming tool-use agent with real-time reasoning and user-visible answer assembly
- Multi-user authentication with admin LLM configuration and usage tracking
- React-based chat UI with markdown, charts, tables, and export to HTML/PDF
- Optional Telegram bot integration for chat-based agent interaction

## Why It Matters for RAG Builders
It provides a production-ready foundation for building and deploying tool-use AI agents with minimal setup, reducing time-to-market for RAG stack builders.
