## Summary
Muser is a local-first, offline-capable image search and curation tool that indexes images for semantic, color, and reverse-image search, with additional features for AI-generated content detection, aesthetic scoring, and training set curation for LoRA models.

## Key Features
- Semantic and color-based image search with SigLIP embeddings
- On-device core with optional cloud-based captioning and generation
- AI-origin detection via C2PA and AI-likelihood scoring
- Curation tools for LoRA training sets with aesthetic scoring
- MCP server for integration with AI assistants like Claude Desktop

## Why It Matters for RAG Builders
Muser provides a powerful, local-first pipeline for indexing, searching, and curating images, making it essential for AI engineers building RAG systems that require high-quality, provenance-verified visual data.
