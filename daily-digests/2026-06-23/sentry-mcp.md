## Summary
Sentry's MCP service enables human-in-the-loop coding agents to interact with Sentry's debugging and error monitoring tools via the Model Context Protocol (MCP). It acts as a middleware to the Sentry API, optimized for development workflows and AI-driven debugging.

## Key Features
- Human-in-the-loop coding agent support for Sentry via MCP
- AI-powered natural language search for Sentry events, issues, and traces
- Remote and stdio transport modes for self-hosted deployments
- OAuth and token-based authentication for secure access
- Integration with Claude Code, Cursor, and other MCP-compatible tools

## Why It Matters for RAG Builders
It bridges Sentry's error monitoring capabilities with AI-driven coding agents, enabling automated debugging and issue resolution in development workflows.
