## Summary
SagaSmith Agent is an autonomous AI Dungeon Master (DM) system for D&D 5e campaigns, built on NanoBot. It provides full rule adjudication, combat simulation, campaign management, and multi-platform chat integration, enabling AI-driven gameplay across 19+ platforms.

## Key Features
- Full D&D 5e rule engine with 8,000+ SRD chunks and hybrid retrieval (exact, FTS, semantic)
- Real-time d20 combat engine with initiative tracking, damage calculation, and turn management
- Multi-platform chat integration (QQ, Telegram, Discord, Slack, WebSocket, etc.) with mention-only policies
- Campaign lifecycle management with snapshot save/load/verify/undo and SQLAlchemy ORM
- Autonomous module generation and import (PDF/HTML/DOCX) with structural parsing and vector embeddings

## Why It Matters for RAG Builders
SagaSmith Agent provides a complete, production-ready AI Dungeon Master framework that integrates rule adjudication, combat simulation, and multi-platform chat, making it essential for building immersive AI-driven tabletop RPG experiences.
