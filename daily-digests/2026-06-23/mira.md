## Summary
Mira is a self-hosted AI-powered code review tool that integrates with GitHub to provide automated PR reviews using your choice of LLM. It emphasizes data privacy, customizable rules, and a comprehensive dashboard for tracking vulnerabilities, dependencies, and review metrics.

## Key Features
- Self-hosted AI code review with full data privacy (no third-party SaaS)
- Comprehensive dashboard for tracking vulnerabilities, dependencies, and review metrics
- Supports any OpenAI-compatible endpoint (OpenRouter, vLLM, Ollama, etc.) or AWS Bedrock
- Organizational package inventory and CVE alerts with blast-radius analysis
- Configurable noise filtering, confidence thresholds, and learning loop for actionable feedback

## Why It Matters for RAG Builders
Mira provides a privacy-focused, self-hosted alternative to SaaS code review tools, enabling teams to leverage LLMs for automated PR reviews while maintaining full control over their data and infrastructure.
