## Summary
Voidly Pay is an off-chain credit ledger and hire marketplace designed for AI agents, enabling atomic settlement through Ed25519-signed envelopes and a public ledger. It provides SDKs, adapters, and tools for integrating agent-based payments and escrow systems.

## Key Features
- Agent-owned Ed25519 keypairs for signing transactions
- Atomic settlement against a public ledger via `agent_hire` calls
- Multi-language SDKs (TypeScript, Python) and CLI tools
- Extensive adapter ecosystem for AI frameworks (OpenAI, LangChain, CrewAI, etc.)
- Comprehensive design invariants and OpenAPI documentation for interoperability

## Why It Matters for RAG Builders
Voidly Pay provides a standardized, agent-native payment and escrow system that simplifies integrating AI agents into economic workflows, reducing complexity for RAG builders.
