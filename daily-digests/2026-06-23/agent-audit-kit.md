## Summary
AgentAuditKit is a security scanner designed to audit MCP-connected AI agent pipelines for vulnerabilities, misconfigurations, and compliance violations. It provides deterministic rule-based scanning with 225 rules across 11 security categories and supports 13 agent platforms.

## Key Features
- 225 deterministic security rules covering 11 categories, including OWASP Agentic Top 10 and MCP Top 10
- Supports 13 agent platforms and 16 CLI commands for scanning, discovery, verification, and reporting
- Compliance mapping to 13 frameworks (EU AI Act, SOC 2, ISO 27001, NIST AI RMF, etc.) with PDF report generation
- Zero cloud dependencies, runs fully offline with Sigstore-signed releases and SBOM generation
- 48-hour CVE-to-rule SLA and public MCP Security Index leaderboard for transparency

## Why It Matters for RAG Builders
AgentAuditKit is essential for RAG builders to ensure their AI agent pipelines are secure, compliant, and free from vulnerabilities that could compromise data integrity or system safety.
