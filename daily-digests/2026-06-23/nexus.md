## Summary
Nexus is an autonomous AI research agent that plans its own search strategy, retrieves real-time information from the web, and generates structured reports using an agentic architecture (LangGraph + ReAct pattern). It enables users to refine outputs and export research as PDFs.

## Key Features
- Autonomous research planning and execution using LangGraph and ReAct pattern
- Live web search integration via Tavily API for real-time data retrieval
- Persistent memory with ChromaDB for caching and instant retrieval of past research
- User-driven report refinement through natural language follow-up instructions
- PDF export functionality for generated research reports
