## Summary
Push is a self-hosted, chat-first development tool that integrates GitHub, terminal, CI, and AI workflows into a single conversational interface. It enables developers to manage repositories, execute tasks, and deploy code directly from a chat interface, with support for mobile and local CLI usage.

## Key Features
- Single conversational interface for GitHub, terminal, CI, and AI workflows
- Self-hosted and provider-flexible (supports Cloudflare, Modal, and custom model stacks)
- Mobile-first design with Android app and web interface
- Sandbox execution for ephemeral workspaces with export capabilities
- GitHub-native workflows including branch-aware chats, PR reviews, and commit/push operations

## Why It Matters for RAG Builders
Push streamlines AI-assisted development by collapsing fragmented workflows into a unified, chat-driven interface, reducing context switching and enabling seamless execution across devices and environments.
