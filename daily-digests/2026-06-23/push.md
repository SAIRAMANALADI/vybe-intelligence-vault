## Summary
Push is a self-hosted, chat-first platform that consolidates mobile development workflows—GitHub, terminal, CI, code, and AI—into a single conversational interface. It enables users to explore, edit, execute, and deploy code directly from a chat, supporting both GitHub-backed repos and ephemeral scratch workspaces.

## Key Features
- Single conversational interface for GitHub, terminal, CI, and AI tasks
- Self-hosted and provider-flexible (supports Cloudflare, Modal, or custom models)
- Ephemeral scratch workspaces for prototyping without GitHub auth
- Branch-aware chats, PR reviews, and commit/push workflows
- CLI and web/Android interfaces with sandboxed execution environments

## Why It Matters for RAG Builders
Push eliminates tool fragmentation for AI-driven development by unifying GitHub, execution, and AI workflows into a single chat interface, making it essential for builders seeking execution control without platform lock-in.
