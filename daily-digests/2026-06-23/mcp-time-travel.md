## Summary
mcp-time-travel is a debugging tool designed to record, replay, and analyze calls made by MCP (Model Context Protocol) agents. It provides a transparent proxy to capture agent interactions deterministically, enabling step-by-step debugging and reverse analysis of tool calls.

## Key Features
- Records and replays MCP agent tool calls deterministically
- Step-by-step forward and reverse debugging of agent interactions
- Transparent proxy for capturing agent calls without code changes
- User-friendly Windows GUI for recording and replaying sessions
- Structured logging of tool calls for post-mortem analysis

## Why It Matters for RAG Builders
It enables RAG builders to debug and validate agent interactions efficiently, ensuring reliability and transparency in tool call sequences.
