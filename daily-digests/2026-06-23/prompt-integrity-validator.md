## Summary
Prompt Lint is a static analysis tool designed to validate and lint AI prompt templates for grammar, structure, and security issues before deployment. It acts as a linter for prompts, ensuring they are optimized, free of hallucination triggers, and secure against injections, supporting multiple models and languages.

## Key Features
- Deterministic rule-based linting for prompts with 47+ predefined rules
- Multi-model support for Claude, ChatGPT, Gemini, and Llama
- CLI and CI/CD integration for automated prompt validation
- Responsive HTML report and dashboard for violation tracking
- Multilingual support for 16 languages with localized rule messages

## Why It Matters for RAG Builders
Prompt Lint ensures AI prompts are structurally sound, secure, and optimized before deployment, reducing hallucinations, injection risks, and token waste in RAG pipelines.
