## Summary
A modular TypeScript framework designed to simplify the development of LLM-powered applications, offering a unified streaming API, agent loops, CLI tools, and orchestration capabilities across four distinct packages.

## Key Features
- Unified LLM streaming API supporting multiple providers
- Modular agent loops with multi-turn tool execution
- Ready-to-use CLI coding agent with OAuth and TUI
- Orchestrator for managing multiple coding agents across projects
- Zero-bloat design with independent package functionality
