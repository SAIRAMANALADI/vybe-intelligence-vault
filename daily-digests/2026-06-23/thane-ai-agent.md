## Summary
Thane is an autonomous AI agent designed for home automation that learns, remembers, and acts based on sensor data and user preferences. It integrates with Home Assistant to provide context-aware automation, persistent memory, and multi-model routing while prioritizing privacy and cost efficiency.

## Key Features
- Autonomous operation with full API access to Home Assistant devices and sensors
- Persistent memory for learned preferences, routines, and facts across restarts
- Privacy-by-design architecture with local SQLite storage and optional cloud model delegation
- Cost-efficient multi-model routing (90%+ local model usage)
- Single binary deployment with optional containerized support

## Why It Matters for RAG Builders
Thane enables AI agents to autonomously understand and act on home automation data with persistent memory and privacy-preserving architecture, making it essential for building context-aware, cost-effective home AI systems.
