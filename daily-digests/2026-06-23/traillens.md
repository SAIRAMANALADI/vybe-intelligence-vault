## Summary
TrailLens is a multi-agent AI assistant designed for landscape photographers, automating photo selection, critique, travelogue generation, and next-trip planning from a batch of hiking photos. It features a custom aesthetic scoring model fine-tuned for landscape photography and integrates multiple specialized agents for end-to-end workflow automation.

## Key Features
- Multi-agent orchestration with supervisor-driven routing and human-in-the-loop (HITL) review
- Custom aesthetic scoring model fine-tuned for landscape photography using Q-Align + LoRA
- Automated photo culling, critique, travelogue generation, and next-trip planning
- Modular architecture with MCP servers for EXIF, weather, and astronomical data integration
- Zero-dependency fallback mode for guaranteed one-click reproducibility
