## Summary
headless-ida is a command-line tool for automated binary analysis using IDA Pro's headless mode, enabling users to analyze executables, DLLs, or malware without a GUI. It simplifies reverse engineering and security analysis through JSON output and batch processing.

- Headless binary analysis using IDA Pro's idalib without GUI dependency
- JSON output for structured and machine-readable results
