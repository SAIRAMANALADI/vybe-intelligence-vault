## Summary
Stardust is an open-source desktop AI agent platform that combines a powerful chat interface with an extensible plugin system. It integrates with 60+ AI models, supports MCP tools, sandboxed code execution, and multi-project management in a modern UI.

## Key Features
- Extensible plugin system with React/TSX and 60+ host APIs
- Multi-model AI chat with streaming responses and token tracking
- Sandboxed code execution for JavaScript and Python with npm/pip support
- MCP Gateway for connecting to any MCP-compatible server
- Multi-project workspace with independent contexts and Supabase memory
