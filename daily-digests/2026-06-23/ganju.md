## Summary
Ganju is an open-source platform for building and hosting Model Context Protocol (MCP) servers, enabling users to turn knowledge and integrations into hosted MCP endpoints accessible by AI clients like Claude, ChatGPT, or custom chat bots across multiple platforms.

## Key Features
- Hosted MCP servers with customizable tools and resources
- RAG over uploaded files, websites, or cloud drives with vector search
- Native integrations with Gmail, Slack, Google Calendar, and more
- Multi-tenant architecture with role-based access control
- Support for chat-channel bots across Telegram, Slack, WhatsApp, and Discord

## Why It Matters for RAG Builders
Ganju simplifies the creation and hosting of MCP servers, enabling seamless integration of custom knowledge and tools into AI workflows for RAG builders.
