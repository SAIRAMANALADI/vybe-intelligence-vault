## Summary
SeekerClaw is an Android-based AI agent that runs a Node.js-powered assistant on-device, enabling 24/7 interactions via Telegram or Discord. It integrates Solana wallets for autonomous USDC payments, device control, and access to 63+ tools and 44 paid API endpoints, transforming the agent into an economic actor on Solana.

## Key Features
- 24/7 AI agent running as a foreground service on Android with Node.js backend
- Autonomous USDC payments via burner wallet (x402 protocol) with configurable caps
- Multi-provider AI support (Claude, OpenAI, OpenRouter, custom gateways) with extended thinking
- 63+ built-in tools and 44 paid API endpoints across 10 services (opt-in)
- Solana wallet integration (main wallet for user-controlled actions, burner wallet for agent transactions)

## Why It Matters for RAG Builders
SeekerClaw enables AI agents to autonomously transact on Solana, bridging the gap between AI decision-making and real-world economic actions while running entirely on-device.
