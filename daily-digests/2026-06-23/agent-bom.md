## Summary
agent-bom is an open-source security scanner and self-hosted control plane for AI/MCP infrastructure that builds a comprehensive AI Bill of Materials (BOM) across agents, MCP servers, packages, cloud estate, and identities. It provides unified evidence models, attack-path analysis, and runtime enforcement capabilities for securing AI stacks.

## Key Features
- Unified AI BOM generation across agents, MCP servers, packages, and cloud estate
- Multi-hop attack-path analysis and blast radius visualization
- Runtime proxy/gateway enforcement and inline firewall controls
- Compliance evidence generation with ZIP bundles for auditors
- Self-hosted dashboard and CLI/REST/MCP tooling interfaces

## Why It Matters for RAG Builders
It provides critical security and compliance visibility for AI stacks by mapping dependencies, vulnerabilities, and attack paths across agents, MCP servers, and cloud infrastructure.
