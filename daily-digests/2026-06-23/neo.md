## Summary
Neo.mjs is a self-evolving AI engineering organism that deploys a cross-model swarm of agents (Claude, Gemini, GPT) to autonomously maintain, improve, and deploy software. It combines an Agent OS (Brain) with a multi-threaded application engine (Body) to enable AI-driven software evolution, real-time collaboration, and cloud-deployable AI teams for any codebase.

## Key Features
- Deploys a swarm of AI agents (Claude, Gemini, GPT) that collaborate via shared memory and Active Hybrid GraphRAG for cross-model reasoning.
- Runs a self-evolving Agent OS (Brain) with Memory Core, Native Edge Graph, DreamService, and GitHub workflow automation.
- Provides a multi-threaded application engine (Body) for high-performance, real-time UI and data processing.
- Enables cloud-deployable AI teams that can be pointed at any codebase for autonomous maintenance and improvement.
- Implements the MX loop (Model Experience) where internal friction becomes tickets, tickets become PRs, and PRs become skills and memory.

## Why It Matters for RAG Builders
Neo.mjs redefines AI-driven software development by enabling autonomous, multi-agent teams to maintain and evolve codebases, reducing human oversight while improving quality and innovation.
