## Summary
markapatent-mcp provides programmatic access to TÜRKPATENT's trademark, patent, and industrial design databases via a Model Context Protocol (MCP) server. It enables applications like Claude Desktop or 5ire to query official IP data without manual website interaction.

## Key Features
- Six search types covering trademarks, patents, and industrial designs
- Supports Nice, IPC/CPC, and Locarno classification-based queries
- Paging for large result sets to manage performance
- MCP-compliant server for seamless integration with LLM tools
- Windows installer and portable executable options

## Why It Matters for RAG Builders
It enables AI systems to dynamically fetch and integrate official Turkish IP data for RAG applications without manual scraping or API limitations.
