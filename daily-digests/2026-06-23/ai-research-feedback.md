## Summary
AI-research-feedback is a Windows-based tool that uses AI-driven multi-agent review to provide detailed feedback on academic economics papers before submission. It automates checks for spelling, grammar, math, tables, references, and contribution evaluation, simulating a journal referee's assessment without requiring technical expertise.

## Key Features
- Multi-agent review system with six specialized agents for comprehensive paper analysis
- Checks spelling, grammar, academic style, and internal consistency
- Evaluates mathematics, equations, tables, and figures for errors or omissions
- Provides a consolidated report with actionable feedback for paper improvement
- No technical skills required; runs on Windows with minimal setup
