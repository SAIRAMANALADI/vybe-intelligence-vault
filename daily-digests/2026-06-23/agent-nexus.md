## Summary
agent-nexus is a local bridge service that connects Discord messages to local coding agents like Claude Code CLI or Codex CLI, enabling Discord-based control of local projects. It routes Discord mentions and slash commands to local agent backends for execution.

## Key Features
- Discord message and slash command routing to local agents
- Support for Claude Code CLI and Codex CLI backends
- Session management with allowlist-based access control
- Multi-instance deployment with configurable home directories
- Streaming responses, typing indicators, and tool invocation status

## Why It Matters for RAG Builders
It enables seamless integration of local coding agents with Discord, allowing AI engineers to manage and interact with agents directly from a familiar chat interface.
