## Summary
CodeAware Studio enhances AI coding agents by transforming raw search sessions into actionable insights through hybrid retrieval, self-benchmarking, and cross-encoder reranking. It logs and analyzes agent interactions to improve future search performance.

## Key Features
- Hybrid BM25 + semantic search for precise code retrieval
- Cross-encoder reranking for improved result relevance
- Self-benchmarking engine to quantify and improve retrieval performance
- Responsive UI dashboard for real-time session analysis
- Integration with OpenAI and Claude APIs for enhanced query understanding
