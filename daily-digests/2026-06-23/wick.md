## Summary
Wick is a Go-based framework and runtime for building internal tools, AI agents, and hosting LLM agents (Claude, Codex, Gemini) as Slack, Telegram, or web bots. It enables AI-assisted scaffolding of Go applications and provides a modular system for tools, jobs, connectors, and agents with built-in UI and scheduling.

## Key Features
- AI-assisted scaffolding of Go applications with real code generation
- Host LLM agents (Claude/Codex/Gemini) as Slack, Telegram, or web bots with no framework overhead
- Modular system for tools, jobs, connectors, and agents with built-in UI and scheduling
- Command Gate for secure Bash command execution with approval workflows and auditing
- MCP endpoint for LLM-facing connectors and operations

## Why It Matters for RAG Builders
Wick bridges the gap between AI-assisted development and production-ready agent hosting, enabling rapid internal tooling and secure LLM integration with minimal boilerplate.
