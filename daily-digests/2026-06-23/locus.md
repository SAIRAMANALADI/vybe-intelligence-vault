## Summary
Locus for Unity is an open-source AI agent designed to automate and enhance game development workflows within the Unity Editor. It enables in-editor operations, runtime analysis, automated knowledge systems, and visual version control for Unity projects.

## Key Features
- In-editor AI-driven C# code generation and modification with Roslyn integration
- Runtime state analysis and debugging with frame-by-frame state sampling
- Automated knowledge system for design document generation and long-term memory preservation
- Visual version control with semantic diff analysis for Unity YAML assets
- Multi-model LLM API support and parallel asset database scanning for performance

## Why It Matters for RAG Builders
Locus streamlines Unity game development by automating repetitive tasks and enabling AI-driven debugging and version control, reducing manual effort and accelerating iteration cycles for RAG and AI stack builders.
