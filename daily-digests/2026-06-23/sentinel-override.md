## Summary
Sentinel Override is a vision-powered, self-healing AI browser automation agent designed for IT professionals and MSPs. It enables multi-portal investigations, M365 admin tasks, and threat hunts by autonomously navigating, interacting with, and reporting on web interfaces with full visibility and auditability.

## Key Features
- Vision-first element interaction with numbered overlays and index-based actions for precise DOM navigation
- Real-time status narration and reasoning cards for full transparency into agent decisions and actions
- Self-healing execution with post-action verification, confidence scoring, and coordinate-based fallback for dynamic pages
- Multi-provider LLM strategy with adaptive routing, cost tracking, and API health monitoring
- Forensic run logs with source-cited reports, screenshots, and HTML export for compliance and sharing
