## Summary
BlenderMCP is a tool that bridges Blender, a 3D modeling software, with Claude AI using the Model Context Protocol (MCP). It enables real-time AI assistance for 3D modeling tasks, simplifying complex scene creation and manipulation through AI-driven prompts.

## Key Features
- Real-time AI assistance for Blender users via Claude
- Seamless integration with Blender 3.0+ using MCP
- Simplifies complex 3D modeling tasks through AI prompts
- Cross-platform support (Windows, macOS, Linux)
- Community-driven support via Discord
