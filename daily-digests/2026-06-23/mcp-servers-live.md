## Summary
Auto-updated index of Model Context Protocol (MCP) servers discovered via GitHub Search API, refreshed every 15 minutes. Provides a real-time catalog of actively maintained MCP integrations with freshness metrics like stars, commits, and release activity.

## Key Features
- Automated discovery of MCP servers via GitHub Search API every 15 minutes
- Real-time tracking of stars, commits, and release freshness
- Multi-language support with categorized listings (Python, TypeScript, C#, Go, etc.)
- Integration with mcp-doctor for health-checking installed MCP servers
- Multi-language READMEs (English, Chinese, Japanese, Korean, Spanish, Portuguese)

## Why It Matters for RAG Builders
It provides a continuously updated, reliable source of actively maintained MCP servers, reducing discovery time and ensuring developers can integrate fresh, production-ready integrations into their RAG stacks.
