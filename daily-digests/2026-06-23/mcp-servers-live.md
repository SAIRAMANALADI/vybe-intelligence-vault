## Summary
An auto-updated index of Model Context Protocol (MCP) servers hosted on GitHub, refreshed every 15 minutes via GitHub Actions. It tracks real-time activity, including stars, commits, and releases, to provide developers with an always-current catalog of actively maintained MCP integrations.

## Key Features
- Auto-updates every 15 minutes via GitHub Actions cron job
- Tracks stars, commits, and release freshness for real-time accuracy
- Provides installable links for MCP servers directly in the index
- Multi-language support with translated READMEs (English, Chinese, Japanese, Korean, Spanish, Portuguese)
- Integrates with mcp-doctor for health-checking installed MCP servers

## Why It Matters for RAG Builders
This repository provides a continuously updated, reliable source of actively maintained MCP servers, eliminating manual curation and ensuring developers can always discover fresh, production-ready integrations for AI workflows.
