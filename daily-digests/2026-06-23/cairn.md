## Summary
Cairn is an autonomous QA agent that explores web applications, designs test cases based on ISO/IEC/IEEE 29119-4 standards, and generates executable Playwright tests with self-repair capabilities. It operates via CLI or library, supporting UI, API, unit, and documentation testing with Langfuse integration for self-improvement.

## Key Features
- Autonomous test case design (ATC/MTC) based on ISO/IEC 29119-4 methodologies
- Self-repairing and self-improving test suites with Langfuse integration
- Multi-mode operation: design, automate, and explore pipelines
- Interactive TUI for guided workflows and live dashboards
- Supports authenticated sessions and configurable checklists for targeted testing

## Why It Matters for RAG Builders
Cairn automates the generation of high-quality, self-validating test cases for AI-driven applications, reducing manual QA effort while ensuring robust coverage and continuous improvement through feedback loops.
