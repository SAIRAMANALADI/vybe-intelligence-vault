## Summary
simplicio-loop is a runtime-agnostic AI orchestrator that autonomously drains backlogs by discovering, implementing, verifying, merging, and closing work end-to-end on any LLM or runtime. It operates 24/7 behind safety gates and a cost kill-switch, reducing token usage by up to 96%.

## Key Features
- Runtime-agnostic super-plugin with 6 modular skills (orchestrator, loop, orient, review, compress, learn)
- Supports 11 runtimes (Claude, Cursor, VS Code, Gemini, Aider, etc.) with a unified protocol
- End-to-end automation: discover → implement → verify → merge → close → 24/7 watcher
- 43 extension points with LLM fallbacks and native command bindings for efficiency
- Aggressive token economy (up to 96% fewer tokens) via terminal-first execution and compression
