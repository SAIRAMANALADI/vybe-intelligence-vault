## Summary
Notchly is a lightweight native macOS app that transforms the MacBook notch into an interactive control surface, offering music controls, battery status, focus animations, and Codex AI alerts without collecting personal data.

## Key Features
- Compact control surface replacing the MacBook notch with interactive widgets
- Integration with Spotify, Apple Music, and media playback controls
- Battery status monitoring and low-battery alerts
- Codex AI alerts for task approvals and completions
- Local-first design with no data collection or cloud dependencies
