## Summary
vstack is a Python library that adapts 34 organizational behavior (OB) frameworks from human team dynamics to diagnose failures in AI agent systems. It provides diagnostic patterns, tools, and integrations to identify root causes of agent failures and recommend targeted interventions.

## Key Features
- 34 diagnostic patterns adapted from OB research (e.g., After-Action Review, Five Dysfunctions, Psychological Safety) for AI agents
- CLI and Python API for diagnosing agent traces (single-agent, multi-agent, or org-scale)
- Integration with major LLM providers (Anthropic, OpenAI, Ollama) and observability tools (LangSmith, Phoenix, Arize)
- Trace ingestion from existing logs (OpenAI/Anthropic chat logs, OpenTelemetry spans, LangSmith runs)
- GitHub Action for automated diagnostics in CI/CD pipelines

## Why It Matters for RAG Builders
It provides a forensic vocabulary and structured approach to diagnose AI agent failures using 70 years of organizational behavior research, enabling targeted fixes instead of vague improvements.
