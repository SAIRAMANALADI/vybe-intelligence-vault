## Summary
A collection of production-ready Claude Agent Skills for SEO tasks, powered by the SE Ranking remote MCP server. These skills transform raw SEO API data into actionable deliverables like content briefs, AI Search share of voice reports, technical audits, backlink gap analyses, and competitive intelligence.

## Key Features
- 26 pre-built SEO skills for Claude Agents, including content briefs, AI Search share of voice, technical audits, and backlink gap analysis
- Seamless integration with SE Ranking MCP server via OAuth, eliminating manual API token management
- Multi-platform support: Claude Desktop, Claude Code, Cursor, and manual installation options
- Comprehensive example outputs with real-world data for 25 skills, demonstrating skill composition and deliverable quality
- Automated CI/CD validation, release automation, and signed releases for reliability and maintainability
