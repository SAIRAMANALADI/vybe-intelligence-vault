## Summary
A local-first multi-agent engineering harness designed for planning, executing, reviewing, and evidencing AI-driven repository work with explicit operator control and auditable workflows. It emphasizes human approval, provider state visibility, and release evidence over unbounded autonomy.

## Key Features
- Managed agent workflow with planner, executor, reviewer, and specialist lanes
- Explicit operator control via approval gates, action inbox, and provider oversight
- Provider registry with fallback policies, attention remediation, and telemetry
- File-backed runtime state and mission artifacts for auditable execution
- Deterministic smoke scripts for portfolio claims, evidence hygiene, and provider validation
