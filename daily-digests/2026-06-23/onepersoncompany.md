## Summary
OnePersonCompany is a Windows desktop application that automates the conversion of daily progress notes into structured reports, release notes, social media posts, and weekly reviews for solo developers and small teams. It leverages LLMs to transform raw input into polished, shareable content.

## Key Features
- Converts daily notes into structured reports, release notes, and social media posts
- Exports results as shareable PNG cards for easy distribution
- Supports local and cloud-based LLM processing
- Provides a simple GUI for input and generation
- Offers demo mode for quick testing without full installation
