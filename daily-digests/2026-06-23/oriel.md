## Summary
Oriel is a lightweight, open-source GUI for managing Docker/Colima containers via a browser UI or an MCP server for AI-driven control. It serves as a minimal, Electron-free alternative to Docker Desktop with built-in MCP support for AI agents.

## Key Features
- Dual-mode operation: browser UI or MCP server for AI agents
- Supports Docker, Colima, OrbStack, Podman, and remote daemons
- Built-in MCP server for secure, secret-masked AI control of containers
- Lightweight (~15–30 MB RAM, ~13 MB binary) with no Electron dependency
- Self-update, themeable UI, and real-time streaming logs

## Why It Matters for RAG Builders
Oriel bridges the gap between human and AI-driven container management by providing a lightweight, secure MCP server that enables AI agents to safely control Docker/Colima environments with the same validation and guardrails as its browser UI.
