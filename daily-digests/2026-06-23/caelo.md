## Summary
Caelo is an open-source desktop client for xAI's Grok API, unifying chat, image/video generation, voice interaction, and an agentic coding module into a single application. It prioritizes privacy with local-first architecture, no telemetry, and user-controlled API keys.

## Key Features
- Unified interface for chat, image/video, voice, and coding agent with shared context and history
- Private by design: local-first, no telemetry, sandboxed file operations, and fail-closed security
- Agentic coding module with file tools, approval gates, checkpoints, and subagent teams
- Extensible via MCP servers, slash commands, hooks, skills, and a package marketplace
- Auto-updating signed installer with delta updates and local API key management

## Why It Matters for RAG Builders
Caelo provides a unified, privacy-focused desktop interface for xAI's Grok API, simplifying multi-modal AI interactions and agentic workflows for developers and end-users.
