## Summary
FusionClaw is an agent-native business operating system that unifies CRM, operations, content creation, marketing, and finance into a single Next.js application with a Postgres database. It exposes all functionality via 234 MCP tools, enabling AI agents to automate and manage business workflows autonomously.

## Key Features
- 234 MCP tools exposing full business functionality to AI agents
- Self-improving agent fleet with Skill Forge and Karpathy reflection loop
- Generative UI for skill outputs (scorecards, email previews, intel cards)
- Unified Postgres database for CRM, finance, marketing, and operations
- Cost-optimized model routing via Thompson sampling bandit

## Why It Matters for RAG Builders
FusionClaw provides a complete, agent-native platform for RAG builders to integrate autonomous business automation into their AI stacks, reducing the need for custom tooling and enabling seamless agent-driven workflows.
