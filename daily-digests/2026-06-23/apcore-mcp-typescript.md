## Summary
apcore-mcp is a TypeScript library that automatically converts apcore module registries into Model Context Protocol (MCP) tools and OpenAI-compatible function calling formats. It bridges apcore modules to MCP clients and AI orchestrators with zero boilerplate.

## Key Features
- Converts apcore modules to MCP tools and OpenAI-compatible function calls with zero boilerplate
- Supports multiple transport protocols: stdio, Streamable HTTP, and SSE
- Includes a browser-based Tool Explorer UI for interactive testing and schema browsing
- Provides dynamic registration and runtime updates for tools via registry changes
- Offers built-in approval mechanisms, error mapping, and JWT authentication for secure tool execution

## Why It Matters for RAG Builders
It simplifies the integration of apcore modules into AI orchestrators and MCP clients by automating the conversion to standardized tool formats, reducing development overhead and enabling seamless tool discovery and execution.
