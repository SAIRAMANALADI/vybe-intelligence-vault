## Summary
A Rust-based MCP (Model Context Protocol) server and client SDK that enables AI agents to control a computer by launching applications, reading screen content, clicking elements, entering text, and simulating keyboard inputs without requiring virtual machines or pixel-based interactions.

## Key Features
- Launch applications directly from AI commands
- Read screen content for real-time context
- Simulate mouse clicks and keyboard inputs
- Cross-platform compatibility (macOS native support)
- Seamless integration with AI agents via MCP
