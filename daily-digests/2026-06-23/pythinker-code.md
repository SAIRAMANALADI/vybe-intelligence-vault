## Summary
Pythinker Code is a terminal-native AI engineering agent that prioritizes review, security, and debugging before generating code. It audits repositories, scans for vulnerabilities, and performs root-cause analysis, then writes code only after thorough analysis, all within a shell-based workflow.

## Key Features
- Review-first AI workflow that audits code before generating changes
- Built-in subagents for code review, security scanning, debugging, and implementation
- ACP and MCP protocol support for seamless IDE and tool integration
- Shell command mode for direct terminal interaction with preserved context
- Extensible via hooks, plugins, and custom skills

## Why It Matters for RAG Builders
Pythinker ensures AI-generated code is rigorously reviewed and secure before implementation, reducing errors and vulnerabilities in RAG pipelines.
