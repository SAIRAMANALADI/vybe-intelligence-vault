## Summary
Keen Code is a minimalistic, terminal-based AI coding agent written in Go, designed for efficient software engineering tasks. It emphasizes simplicity, conservative context management, and a lean toolset to avoid unnecessary complexity while supporting multiple AI providers.

## Key Features
- Multi-provider support (Anthropic, OpenAI, Gemini, DeepSeek, etc.) with easy model switching
- Conservative context management using TurnMemory summaries to reduce noise and improve efficiency
- Built-in minimal tools (read_file, write_file, edit_file, glob, grep, bash) for core coding tasks
- Skills system for specialized workflows (planning, debugging, refactoring, code review)
- Session management with persistent and resumable sessions

## Why It Matters for RAG Builders
Keen Code demonstrates how AI agents can autonomously develop and refine coding agents, offering a lightweight, context-efficient alternative for AI-driven software engineering workflows.
