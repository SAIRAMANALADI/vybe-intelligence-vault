## Summary
A desktop application for exploring Graph Retrieval-Augmented Generation (GraphRAG) using Neo4j, enabling users to build, compare, and evaluate different retrievers and conversational agents with a user-friendly interface.

## Key Features
- Supports multiple retriever types: Vector, Vector+Cypher, and Text2Cypher
- Custom router for streamlined agent workflows
- Built-in evaluation workflow to compare agent performance
- User-friendly interface for non-technical users
- Integrates with Neo4j for advanced graph-based retrieval

## Why It Matters for RAG Builders
It provides a practical toolkit for building and evaluating GraphRAG-based agents, bridging the gap between semantic and graph-based retrieval for enhanced AI applications.
