## Summary
mcp-terminal-server enables interactive terminal sessions within Claude Code and Claude Desktop via an MCP server, allowing users to run command-line tools directly in the chat interface without leaving the application. It supports multi-session PTY and xterm.js for a seamless terminal experience.

## Key Features
- Inline terminal display within Claude Code/Desktop
- Multi-session PTY support for concurrent terminal sessions
- Full xterm.js compatibility for interactive terminal emulation
- Seamless integration with MCP-compatible applications
- Designed for Windows 10/11 with straightforward setup
