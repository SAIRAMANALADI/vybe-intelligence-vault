## Summary
MCP server for comprehensive video analysis that extracts transcripts, key frames, OCR text, and metadata from video URLs and local files. It uniquely combines multiple video analysis capabilities into a single tool, enabling AI agents to process video content contextually.

## Key Features
- Multi-format video support (Loom, direct URLs, local files)
- Unified analysis combining transcripts, frames, OCR, and metadata
- Scene-change detection and dense frame sampling options
- Optional TwelveLabs Pegasus integration for AI-generated transcripts and summaries
- Whisper fallback for audio transcription with multiple backend options
