## Summary
A full-stack AI chat platform with streaming SSE responses, multi-turn conversations, and MCP tool integration. Supports user authentication, session persistence with PostgreSQL (including pgvector), and automated frontend generation.

## Key Features
- Real-time streaming responses with SSE and resumable sessions
- Multi-turn tool calling with structured visualization of results
- User authentication via SMS, WeChat, and JWT
- Session management with history persistence in PostgreSQL (pgvector)
- Automated frontend generation for rapid UI deployment

## Why It Matters for RAG Builders
Provides a robust, production-ready framework for building AI agents with streaming capabilities, tool integration, and persistent session management, critical for scalable RAG applications.
