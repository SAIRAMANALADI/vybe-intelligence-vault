## Summary
A Model Context Protocol (MCP) server that enables AI agents to fetch, filter, and analyze Steam game reviews and forum discussions, focusing on player sentiment, temporal trends, and metadata-driven insights to uncover genuine player opinions beyond store page noise.

## Key Features
- Server-side filtering and aggregation of Steam reviews to reduce noise and focus on relevant data
- Temporal precision for comparing player sentiment over time (e.g., launch vs. recent reviews)
- Rich metadata context (playtime, sentiment, language) to distinguish long-term player feedback from quick impressions
- Unified workflow for reviews, forums, and official announcements to provide holistic game insights
- Resumable and background data fetching with automatic cleanup for efficiency

## Why It Matters for RAG Builders
It provides structured, filtered, and metadata-rich Steam game data that AI agents can use to generate accurate, context-aware insights about player sentiment and trends without overwhelming context windows.
