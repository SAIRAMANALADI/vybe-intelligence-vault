## Summary
TextForge AI is a pretext plugin and MCP toolkit that enables large language models to perform DOM-free text measurement, layout optimization, and spatial reasoning with pixel-perfect precision. It bridges linguistic and visual text understanding for AI-native applications.

## Key Features
- DOM-free text measurement engine with sub-pixel accuracy
- MCP tools for spatial text reasoning (e.g., TextWidthEstimator, LayoutOptimizer)
- Multi-API support for OpenAI and Claude with function calling integration
- Multilingual and Unicode-aware text processing (120+ scripts)
- Responsive layout intelligence with breakpoint-aware text generation

## Why It Matters for RAG Builders
TextForge AI enables AI models to generate visually precise text layouts without relying on browser-based DOMs, making it essential for developers building AI-native design tools, automated UI generation, or content that must fit exact dimensions.
