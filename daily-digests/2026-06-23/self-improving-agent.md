## Summary
A self-improving agent framework that automatically logs errors, corrections, and feature requests to structured markdown files, promoting key learnings to specialized workspace files for continuous improvement of AI agents.

## Key Features
- Automatically captures command failures, user corrections, and missing features
- Routes events to structured markdown logs (ERRORS.md, LEARNINGS.md, FEATURE_REQUESTS.md)
- Promotes broadly applicable learnings to specialized files (AGENTS.md, TOOLS.md, SOUL.md)
- Integrates with OpenClaw for seamless activation on relevant triggers
- Enables agents to improve over time without manual review

## Why It Matters for RAG Builders
It enables AI agents to autonomously learn from errors and user feedback, reducing manual oversight and improving performance iteratively.
