## Summary
A Model Context Protocol (MCP) server that provides programmatic access to Twitter/X data, including user profiles, tweets, follower events, and KOL tracking. It enables AI assistants to fetch and analyze Twitter data via a standardized interface.

## Key Features
- Retrieves user profiles, tweets, and follower events via MCP tools
- Supports advanced search with filters (hashtags, engagement, etc.)
- Tracks KOL (Key Opinion Leader) followers and deleted tweets
- Multi-client compatibility (Claude, Cursor, Windsurf, etc.)
- Secure token-based authentication with environment/config support

## Why It Matters for RAG Builders
It provides structured, programmatic access to Twitter/X data, enabling AI assistants to fetch real-time social media insights for RAG pipelines without direct API integration.
