## Summary
Distillery is a team knowledge base plugin for Claude Code that captures, classifies, and surfaces team knowledge through conversational commands. It transforms raw information from meetings, documents, and conversations into searchable vector embeddings stored in DuckDB, enabling natural language retrieval and synthesis.

## Key Features
- 14 Claude Code slash commands for capturing, searching, and synthesizing team knowledge
- Local or hosted deployment with DuckDB for vector storage and fastembed for embeddings
- Automated deduplication, classification, and synthesis of team knowledge
- GitHub integration for syncing issues, PRs, and repository activity
- Ambient feed monitoring and team activity dashboards

## Why It Matters for RAG Builders
Distillery streamlines the capture and retrieval of team knowledge, reducing information loss and enabling AI systems to leverage high-quality, context-rich data for RAG applications.
