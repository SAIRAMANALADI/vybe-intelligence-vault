## Summary
PiDeck is a desktop workbench for managing multiple pi coding Agent sessions across isolated project folders. It provides a unified UI to orchestrate projects, sessions, conversations, configurations, and tools by launching and coordinating multiple pi RPC processes.

## Key Features
- Multi-project workspace with isolated pi Agent sessions per project
- Built-in chat interface with Markdown rendering and streaming output
- Visual configuration management for pi models, auth, and settings
- Embedded terminal dock per Agent with shell command execution
- Session history import/export and management with Git integration

## Why It Matters for RAG Builders
PiDeck simplifies the orchestration of multiple isolated pi Agents in a unified desktop environment, making it easier to manage complex AI workflows across projects.
