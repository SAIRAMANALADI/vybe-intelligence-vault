## Summary
Tabularis is an open-source, cross-platform database client for PostgreSQL, MySQL/MariaDB, and SQLite, featuring SQL notebooks, visual EXPLAIN, AI integration, and a plugin system for extensibility.

## Key Features
- Cross-platform support (Windows, macOS, Linux) with multiple installation options (Snap, Flatpak, AppImage, AUR, WinGet)
- SQL notebooks with Markdown cells, cross-cell variables, and chart visualizations
- Built-in MCP server for AI agent integration and local AI text-to-SQL (Ollama)
- Visual EXPLAIN with interactive plan graphs for query optimization
- Extensible plugin system supporting any language via JSON-RPC over stdio

## Why It Matters for RAG Builders
Tabularis provides a modern, AI-augmented database client with notebooks and visual tools that streamline query development and debugging for RAG pipelines.
