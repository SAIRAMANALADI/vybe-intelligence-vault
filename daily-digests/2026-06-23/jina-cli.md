## Summary
jina-cli is a lightweight Windows command-line tool that converts web pages, blogs, news, and social media posts into clean, LLM-friendly formats like Markdown, plain text, or HTML using the Jina AI Reader API.

## Key Features
- Converts URLs to Markdown, plain text, or HTML for easy LLM ingestion
- Supports social media, blogs, and news sites with minimal setup
- Lightweight and runs directly from Windows command prompt
- Uses Jina AI Reader API for clean, structured content extraction
- Allows saving output to files with customizable formats

It streamlines web content extraction into LLM-friendly formats, reducing preprocessing overhead for RAG pipelines.
