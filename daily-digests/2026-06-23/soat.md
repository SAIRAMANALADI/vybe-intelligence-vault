## Summary
SOAT provides open-source infrastructure for building production-ready AI agents, offering a self-hostable Node.js server with IAM, vector search, conversational memory, agent orchestration, and MCP support. It abstracts away common AI application infrastructure needs, allowing developers to focus on product logic.

## Key Features
- Unified IAM system with policies and project-based access control
- PostgreSQL-backed vector search for documents, memories, and knowledge
- Multi-agent workflows with tool-calling and reasoning loops
- Declarative agent formations for dependency-aware deployments
- Four client surfaces (REST, MCP, CLI, SDK) with consistent behavior

## Why It Matters for RAG Builders
SOAT eliminates the need to rebuild core AI infrastructure for every project, providing a production-ready orchestration layer that integrates seamlessly with RAG pipelines and agentic workflows.
