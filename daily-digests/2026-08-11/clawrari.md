## Summary
Clawrari is an opinionated, battle-tested operating system for OpenClaw that transforms AI assistants from stateless chatbots into durable infrastructure with session continuity, behavioral rules, and self-improvement loops. It provides a structured framework for building production-grade AI systems with file-first memory, explicit routing, and reusable skills.

## Key Features
- File-first memory system with session continuity and durable storage
- Explicit behavioral rules defined in SOUL.md, USER.md, and AGENTS.md
- Structured async workflows using queue and ledger patterns
- Published model playbook for routing and overlays with updated effort-ladder
- Agent observability with trace → usage → scorecard → report chain
