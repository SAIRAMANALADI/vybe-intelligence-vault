## Summary
PgArachne transforms PostgreSQL into a secure JSON-RPC 2.0 API gateway with zero boilerplate, enabling direct mapping of HTTP requests to database functions. It supports real-time notifications via SSE, native MCP integration for AI agents, and robust authentication mechanisms.

## Key Features
- Zero-boilerplate API creation by mapping JSON-RPC methods to PostgreSQL functions
- Native MCP support for AI agents (Claude Desktop, Cursor) to discover and call PostgreSQL functions as tools
- Real-time notifications via SSE for PostgreSQL LISTEN/NOTIFY channels
- Secure authentication with JWT and PostgreSQL role masquerading
- Production-ready features including connection pooling, Prometheus metrics, and graceful shutdowns

## Why It Matters for RAG Builders
PgArachne enables AI engineers to instantly expose PostgreSQL functions as secure, self-describing APIs with MCP support, eliminating boilerplate and accelerating AI agent integration.
