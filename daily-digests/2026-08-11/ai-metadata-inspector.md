## Summary
AI-Metadata-Inspector is a Windows-native tool that extracts hidden AI-generated metadata (prompts, model names, settings) from images and videos created by tools like Stable Diffusion, Midjourney, or DALL-E. It integrates into the Windows right-click menu for quick access and operates entirely locally without cloud processing.

## Key Features
- Extracts AI metadata (prompts, model names, settings) from images/videos locally
- Integrates directly into Windows file explorer via right-click menu
- Supports batch processing for multiple files
- No data leaves the user's machine (privacy-focused)
- Fast processing with results appearing in under one second

## Why It Matters for RAG Builders
It enables RAG builders to recover and utilize original AI-generated prompts and metadata from files, improving data provenance and retrieval accuracy.
