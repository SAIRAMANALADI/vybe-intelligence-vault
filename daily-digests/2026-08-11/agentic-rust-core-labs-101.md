## Summary
A pedagogical curriculum designed to teach autonomous agent development using the Rig 0.41 framework in Rust. It consists of 20 structured labs that bridge basic LLM API usage to production-grade, reasoning-driven AI systems through hands-on retyping exercises.

## Key Features
- 20 structured labs covering agent fundamentals, tooling, observability, and advanced architectures
- Zero-friction setup with automated OllamaEnv bootstrapper for model management
- Hands-on retyping exercises to build muscle memory and deep understanding
- Covers key agentic concepts like tool calling, context attachment, and RAG integration
- Includes policy control, streaming events, and durable agent state management

## Why It Matters for RAG Builders
It provides a rigorous, hands-on foundation for building production-grade autonomous agents in Rust, critical for developers aiming to implement robust AI systems beyond basic LLM wrappers.
