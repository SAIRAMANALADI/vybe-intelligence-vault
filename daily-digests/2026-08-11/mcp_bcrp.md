## Summary
Provides dual-interface access to Peru's Central Reserve Bank (BCRP) macroeconomic data via Python/MCP and native Stata workflows. Enables AI agents and analysts to retrieve, search, and transform 5,000+ economic indicators from the BCRP statistical API.

## Key Features
- Dual Python/Stata interfaces for BCRP data access with separate runtimes and tests
- FastMCP server for MCP-compatible AI applications to query economic indicators
- Asynchronous data retrieval and catalog search in Python
- Native Stata package with caching, transformations, and metadata output
- Comprehensive test suites and documentation for both Python and Stata implementations

## Why It Matters for RAG Builders
It provides standardized, programmatic access to Peru's official macroeconomic data, enabling AI agents and analysts to integrate high-quality economic indicators into RAG pipelines for financial or economic analysis.
