## Summary
The @lolikai/mcp repository provides an MCP (Model Context Protocol) server for accessing Lolik's trend-intelligence API, enabling real-time trend analysis, virality scoring, and monetization opportunities directly within MCP clients like Claude Desktop or Cursor. It simplifies integration by allowing one-command execution via `npx` without requiring local cloning or builds.

## Key Features
- One-command execution via `npx` for instant setup
- 13 MCP tools for real-time trend analysis, forecasting, and virality scoring
- Pay-per-use credit system aligned with Lolik's REST API
- Seamless integration with Claude Desktop, Cursor, and other MCP clients
- Pre-configured tools for content briefs, opportunities, and pattern validation
