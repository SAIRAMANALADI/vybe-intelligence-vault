## Summary
Relay is a local-first, self-hosted agent orchestrator that enables cross-repo delegation and coordination for AI agents. It allows a single orchestrator agent to delegate tasks to agents in other repositories, forming a delegation tree for complex workflows like multi-repo feature rollouts or dependency upgrades.

## Key Features
- Cross-repo agent-to-agent delegation with dependency-aware task trees
- Local-first, self-hosted architecture with state stored in `~/.relay/`
- Three dashboards (CLI, TUI, GUI) for unified monitoring and interaction
- GitHub Projects v2 integration for automated ticket tracking and synchronization
- Unattended mode with budget and time constraints for autonomous AI-driven workflows

## Why It Matters for RAG Builders
Relay enables seamless coordination of AI agents across multiple repositories, eliminating the need for manual babysitting of tasks and providing a unified audit trail for architectural decisions, making it essential for large-scale AI-driven development workflows.
