## Summary
A hybrid agentic recommendation system that combines behavioral analytics with RAG-based semantic search to deliver hyper-personalized product recommendations. It uses LangGraph for multi-step reasoning, Pinecone for vector search, and FastAPI for a scalable backend with a Jinja2 frontend.

## Key Features
- Agentic reasoning pipeline with LangGraph and OpenAI for multi-step personalized recommendation narratives
- Hybrid recommendation strategy combining rule-based behavioral scoring and Pinecone vector search
- Real-time analytics dashboard with Chart.js for visualizing user engagement and match confidence scores
- Secure session authentication with bcrypt and HTTP-only cookies
- AWS CI/CD pipeline for scalable deployment with GitHub Actions
