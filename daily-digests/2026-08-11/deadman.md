## Summary
deadman is an open-source multi-agent platform designed for post-death and medical navigation scenarios. It provides structured guidance, compliance checks, and secure data handling without offering legal/medical advice or performing tasks on behalf of users.

## Key Features
- 6 specialized agents for post-death and medical navigation tasks
- 15-rule priority chain (L0-L8) enforcing safety, compliance, and transparency
- 4-layer memory system (working/episodic/semantic/procedural) for context retention
- Enterprise-grade security with PBKDF2-HMAC-SHA256, AES-256-GCM encryption, and PII masking
- Dead Man Switch with multi-factor verification and automated notifications

## Why It Matters for RAG Builders
It provides a structured, compliant, and secure framework for building agent-based systems handling sensitive post-death and medical scenarios, ensuring safety and regulatory adherence.
