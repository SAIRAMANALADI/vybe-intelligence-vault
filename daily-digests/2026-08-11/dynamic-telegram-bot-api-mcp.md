## Summary
A Model Context Protocol (MCP) server that dynamically exposes the complete Telegram Bot API as a set of stable tools, enabling seamless integration with AI workflows. It parses Telegram's official documentation into a normalized local catalog, ensuring methods and objects are always up-to-date without code changes.

## Key Features
- Dynamic catalog of Telegram Bot API methods and objects parsed from official documentation
- Five stable MCP tools for searching, inspecting, and calling Telegram API methods
- Automatic schema refresh without source-code changes
- Secure token management via workspace-specific .env files
- Built-in validation, rate limiting, and security controls

## Why It Matters for RAG Builders
It enables AI agents and MCP clients to dynamically interact with the Telegram Bot API without manual code updates, streamlining automation and workflow integration.
