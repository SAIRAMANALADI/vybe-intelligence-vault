## Summary
DOMicile is an AI-agent skill and design system that enables real-time, interactive UI iteration through annotated HTML documents. It bridges AI-generated code and human feedback by allowing agents or developers to fix UI issues directly in a browser-based working document.

## Key Features
- Interactive HTML working documents with feedback rails for real-time UI iteration
- 15 reusable HTML primitives and 5 archetype templates for rapid prototyping
- Agent Skills compatibility for seamless integration with AI agents
- Cross-stack support (React, Astro, Rust/Egui) with token parity enforcement
- Optional Rust-based server for persistent feedback and live collaboration

## Why It Matters for RAG Builders
DOMicile streamlines the AI-to-human collaboration loop for UI development, enabling precise, iterative fixes without regenerating entire codebases.
