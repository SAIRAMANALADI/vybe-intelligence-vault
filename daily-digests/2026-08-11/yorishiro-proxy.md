## Summary
Yorishiro Proxy is an AI-first MITM (Man-in-the-Middle) proxy tool designed for AI agents, enabling traffic interception, recording, and replay through the Model Context Protocol (MCP). It provides real-time inspection, modification, and automated testing capabilities for multi-protocol traffic.

## Key Features
- AI-native MITM proxy with MCP integration for seamless AI agent control
- Multi-protocol support including HTTP/1.1, HTTP/2, gRPC, WebSocket, and Raw TCP
- Traffic interception, recording, and replay with per-protocol typed schemas
- Embedded Web UI for visual inspection and interactive testing
- Safety filters, rate limiting, and plugin system for extensibility

## Why It Matters for RAG Builders
It empowers AI agents to autonomously intercept, analyze, and manipulate network traffic for security testing, debugging, and automated workflows without manual intervention.
