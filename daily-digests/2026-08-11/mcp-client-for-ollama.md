## Summary
A Python-based terminal client that enables interaction with Model Context Protocol (MCP) servers using Ollama or other LLM providers. It provides a rich TUI for harnessing local LLMs to execute tools, manage prompts/resources, and enable agent workflows with safety controls.

## Key Features
- Interactive terminal UI (TUI) for MCP server interaction with Ollama or other LLM providers
- Supports core MCP primitives: tools, prompts, and resources with streaming responses
- Agent mode with configurable tool execution loops and human-in-the-loop (HIL) safety controls
- Multi-server support with dynamic model switching and hot-reloading for development
- Advanced features like thinking mode, reasoning effort levels, and performance metrics

## Why It Matters for RAG Builders
It simplifies the integration of local LLMs with MCP servers, enabling secure and interactive tool execution for RAG pipelines without requiring extensive coding.
