## Summary
1Helm provides a self-hosted, durable AI agent framework that assigns permanent 'resident' agents to jobs, each with persistent memory, private Linux environments, and scheduled obligations. It enables continuous learning and skill retention across sessions, model swaps, and restarts, treating AI agents as long-term employees rather than temporary chat sessions.

## Key Features
- Permanent AI residents with private Linux computers and durable memory
- Skipper-based boundary management for host credentials and cross-channel operations
- Skill learning and procedure crystallization from real workflows
- Multi-platform support (macOS, Windows, Linux) with synchronized releases
- Model-agnostic architecture with OAuth/API key management and fallback routing

## Why It Matters for RAG Builders
1Helm enables RAG builders to create AI systems that retain context, skills, and institutional knowledge over time, eliminating the need for repetitive retraining and session-based memory limitations.
