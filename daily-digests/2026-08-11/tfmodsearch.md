## Summary
TFModSearch is an MCP server that provides intelligent search capabilities for Terraform AWS module documentation using hybrid search (keyword matching, BM25, and semantic embeddings). It offers a pre-built search index with embeddings for 54 curated Terraform AWS modules, enabling AI assistants to accurately find and reference official module documentation.

## Key Features
- Hybrid search engine combining keyword matching, BM25, and semantic embeddings for accurate module discovery
- Pre-built search index with embeddings for 54 curated Terraform AWS modules, ready to use out-of-the-box
- Seamless integration with MCP clients like Claude Desktop, Codex, and GitHub Copilot
- CPU-only inference with BAAI/bge-base-en-v1.5 model for fast, private, and deterministic search
- Configurable search weights and built-in path validation for security

## Why It Matters for RAG Builders
TFModSearch provides AI agents with a reliable, offline knowledge base of Terraform AWS modules, eliminating hallucinations and ensuring generated code references accurate, up-to-date documentation.
