## Summary
PageIndex is a vectorless, reasoning-based RAG engine that transforms long documents into hierarchical tree structures for agentic, context-aware retrieval. It replaces traditional vector similarity search with LLM-driven reasoning over document trees, enabling human-like document analysis without chunking or vector databases.

## Key Features
- Eliminates vector databases and chunking by using hierarchical tree indexing for retrieval
- Leverages LLM reasoning for context-aware, traceable, and explainable document search
- Supports agentic workflows for multi-step reasoning over long documents
- Achieves state-of-the-art accuracy (98.7% on FinanceBench) outperforming traditional vector RAG
- Offers self-hosted, cloud, and enterprise deployment options with MCP and API integrations

## Why It Matters for RAG Builders
PageIndex redefines RAG by replacing opaque vector similarity with transparent, reasoning-driven retrieval, making it essential for AI systems requiring precise, context-aware document analysis.
