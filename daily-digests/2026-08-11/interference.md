## Summary
Interference is an open-source AI coding agent that operates directly in the terminal, enabling users to describe tasks which the agent then executes via an agentic tool-calling loop. It emphasizes permissioned, plan/build modes, session persistence, and extensible skills for software engineering workflows.

## Key Features
- Plan/Build modes with explicit permissions and read-only exploration
- 11 built-in tools (read, write, edit, bash, grep, etc.) with safe execution
- Session persistence with undo/redo and project memory
- Extensible skills and subagents for parallel task delegation
- Multi-provider support (DeepSeek, OpenAI, Anthropic, etc.) with real-time cost tracking

## Why It Matters for RAG Builders
Interference provides a permissioned, terminal-native AI coding agent with robust tooling and session management, making it ideal for developers seeking transparent, secure, and extensible AI-assisted software engineering.
