- Fetches fully rendered HTML from any URL, bypassing anti-bot protections
- Provides structured JSON output for parsed web content
- Supports Google search queries via MCP tools
- Integrates seamlessly with MCP clients like Claude
- Uses user-provided API keys for direct access (no data sharing)
