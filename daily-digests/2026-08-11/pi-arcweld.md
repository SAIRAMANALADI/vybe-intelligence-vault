## Summary
A curated local workspace for managing a Pi agent environment with pinned upstream source, user extensions, system instructions, and reproducible runtime tooling. It ensures auditable and isolated development while keeping local changes separate from the upstream Pi repository.

## Key Features
- Pins upstream Pi source via Git submodule for auditable dependency management
- Supports curated user extensions and local MCP servers for tooling
- Maintains system instructions and runtime artifacts in an isolated build directory
- Provides scripts for building, updating, and validating the workspace
- Enforces Git hygiene and separation of local vs. upstream changes

## Why It Matters for RAG Builders
