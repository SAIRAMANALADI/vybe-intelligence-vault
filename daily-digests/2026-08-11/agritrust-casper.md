## Summary
AgriTrust is an autonomous trade-finance protocol for emerging-market farmers that tokenizes real-world-asset (RWA) invoices and uses an AI underwriting agent to evaluate creditworthiness via off-chain data feeds. It automates the full lifecycle of financing, repayment, and settlement on the Casper blockchain using the Odra framework.

## Key Features
- Autonomous AI-driven underwriting with explainable risk verdicts posted on-chain
- Tokenized RWA invoices enabling trustless financing for farmers
- x402 micropayments for off-chain data verification, ensuring auditable costs
- Full lifecycle automation: register → evaluate → fund → repay → settle/default
- MCP-style read layer for seamless integration with LLM agents and tools

## Why It Matters for RAG Builders
It demonstrates how AI agents can autonomously evaluate and finance real-world assets by leveraging blockchain for trustless settlement and micropayments for data access, bridging off-chain data with on-chain execution.
