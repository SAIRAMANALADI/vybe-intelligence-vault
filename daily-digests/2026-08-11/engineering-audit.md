## Summary
A local MCP server and tooling suite that audits AI coding assistants (Claude Code, Codex CLI, Gemini CLI) against a rules pack to produce self-contained HTML reports with actionable findings, GitHub issue filing, and inline trigger fragments for real-time rule application during development.

## Key Features
- Local MCP server for rule-based audits with schema-validated findings
- Self-contained HTML reports with actionable findings, citations, and GitHub issue filing
- Inline trigger fragments for real-time rule application during development
- Support for multiple AI assistants (Claude Code, Codex CLI, Gemini CLI)
- Deterministic evaluation with no LLM dependency for core functionality
