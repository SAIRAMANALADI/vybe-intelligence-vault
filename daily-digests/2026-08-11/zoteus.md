## Summary
Zoteus is an MCP (Model Context Protocol) server that provides AI agents and clients with safe, local-first access to a user's Zotero library, enabling real-time searches, citations, and bibliographic formatting without hallucinations or external dependencies.

## Key Features
- Full Zotero Web API v3 and desktop local API integration for reads and writes
- Hybrid keyword + semantic search across metadata, full text, and annotations with page numbers
- Safe, transactional writes with reversible operations and confirmation-gated deletions
- CSL bibliography formatting (~2,800 styles) and citeproc-js support
- Local-first, private, and open-source (MIT licensed) with no Python dependency

## Why It Matters for RAG Builders
Zoteus enables RAG systems to ground responses in a user's verified Zotero library, eliminating hallucinations and ensuring accurate citations while maintaining local-first privacy.
