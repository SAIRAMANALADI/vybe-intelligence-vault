## Summary
duphunter is a Windows-based tool designed to detect near-duplicate Python code by analyzing code structure using Abstract Syntax Trees (AST). It helps developers identify and refactor redundant code to improve maintainability and clarity.

## Key Features
- AST-driven detection for structural code clone analysis
- Simple GUI for non-technical users
- Fast scanning of large Python projects
- Exportable results in CSV/JSON formats
- Exclusion list for ignoring specific files/folders
