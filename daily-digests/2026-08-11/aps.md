## Summary
APS (Agent Profile System) is a local-first tool for running commands and agent workflows under isolated profiles with configurable isolation levels (process, platform, or container). It enables secure, environment-specific execution of AI agents with secrets management, session tracking, and cross-platform support.

## Key Features
- Configurable isolation levels (process, platform, container) for secure agent execution
- Secrets management with automatic environment injection for LLM CLI tools
- Session tracking and management with inspect, logs, and terminate capabilities
- Cross-platform support (macOS, Linux, Windows) with graceful degradation
- Git integration and TUI interface for profile and workflow management

## Why It Matters for RAG Builders
APS enables secure, isolated execution of AI agents with configurable environments, making it essential for building robust and secure RAG pipelines with multi-agent workflows.
