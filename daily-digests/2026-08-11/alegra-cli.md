## Summary
Alegra-CLI is a fast, scriptable command-line interface for the Alegra accounting API, enabling terminal-based management of contacts, invoices, payments, and other financial resources with support for multiple output formats and a built-in MCP server for AI agent integration.

## Key Features
- Full Alegra API coverage with typed Go client and resource-specific commands
- Multi-format output (table, JSON, YAML, CSV) with column customization
- Built-in MCP server for AI agent integration and structured tool access
- Profile management, shell completion, and pre-flight validation for country-specific rules
- Dry-run mode, rate limiting, and offline reference catalogs for reliability

## Why It Matters for RAG Builders
It provides a robust, scriptable interface to Alegra's accounting API, enabling AI agents and automation pipelines to interact with financial data efficiently and securely.
