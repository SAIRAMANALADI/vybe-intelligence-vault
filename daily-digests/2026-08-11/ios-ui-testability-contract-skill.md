## Summary
A toolkit and agent skill designed to diagnose and fix XCUITest failures in iOS apps by analyzing accessibility identifiers, launch routes, and UI contract issues. It provides a local CLI scanner and an installable agent skill to resolve 'element not found' errors and flaky navigation in SwiftUI and UIKit.

## Key Features
- Local CLI scanner for identifying accessibility identifier risks and collisions in SwiftUI/UIKit code
- Agent skill for diagnosing and patching XCUITest failures using failure artifacts and UI tree analysis
- Supports triage of failure summaries, UI trees, scenarios, and planner validation errors
- Zero-dependency local execution with no network requests or source code uploads
- Integrates with GitHub CLI for agent skill installation and workflow automation

## Why It Matters for RAG Builders
It streamlines the debugging of XCUITest failures by automating the identification and resolution of accessibility contract issues, reducing manual effort and improving test reliability in iOS apps.
