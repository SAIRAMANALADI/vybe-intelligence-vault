## Summary
A production-grade RAG customer support agent designed to answer queries using company documents with verifiable citations, hallucination guardrails, and a security-hardened API layer. It features hybrid search, LangGraph-based orchestration, and a React-based frontend for real-time interaction.

## Key Features
- Hybrid search with dense and sparse embeddings fused via Reciprocal Rank Fusion (RRF)
- LangGraph state machine for multi-node orchestration (route, retrieve, grade, generate, verify, fallback)
- Verifiable source citations with structured references for every answer
- Security-hardened API with JWT authentication, rate limiting, and prompt injection detection
- Built-in evaluation pipeline with RAGAS and DeepEval metrics against a golden QA dataset

## Why It Matters for RAG Builders
This repository provides a complete, production-ready RAG agent framework with robust retrieval, orchestration, and security features, making it essential for AI engineers building reliable customer support systems.
