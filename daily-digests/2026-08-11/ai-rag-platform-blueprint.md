## Summary
A production-oriented reference architecture for deploying an internal AI, LLM, and RAG platform. It provides a blueprint for gateway routing, model serving, vector storage, observability, and operational best practices, excluding model training.

## Key Features
- Production-grade reference architecture for AI/LLM/RAG systems
- Modular design with gateway, orchestrator, and model serving layers
- Comprehensive observability stack (Prometheus, Grafana)
- Multi-vector DB support (Qdrant, Milvus, Weaviate, pgvector)
- Operational best practices for security, backups, and scaling
