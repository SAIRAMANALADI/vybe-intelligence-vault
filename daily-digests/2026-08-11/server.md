## Summary
FOWOCO Server is a Spring Boot backend designed to manage HR workflows for foreign workers, focusing on secure document handling, approvals, and audit trails. It integrates with AI for workflow assistance while enforcing strict data isolation and security principles.

## Key Features
- Secure HR workflow management for foreign workers with role-based access control
- AI runtime integration for workflow assistance without direct decision-making
- Strict tenant isolation using company_id for data security
- Comprehensive audit logging for compliance and traceability
- Transactional outbox pattern for reliable event processing

## Why It Matters for RAG Builders
It provides a secure, auditable backend for HR workflows that integrates AI assistance while ensuring data isolation and compliance, critical for building robust RAG systems in regulated environments.
