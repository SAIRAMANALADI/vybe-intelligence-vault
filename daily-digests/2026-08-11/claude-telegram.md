## Summary
claude-telegram is a Python service that bridges Telegram with the claude CLI, enabling users to interact with Claude Code from their mobile devices while maintaining full skill/MCP parity. It also provides a localhost push endpoint for sending Telegram notifications from scripts or cron jobs.

## Key Features
- Telegram-to-Claude CLI bridge with full feature parity
- Bearer-protected localhost push endpoint for cron jobs and scripts
- Per-chat asyncio.Lock for concurrency control and cancellation
- Secret-safe logging with configurable verbosity
- Built-in commands like /reset, /cd, /cwd, /cost, and /stop

## Why It Matters for RAG Builders
It enables remote interaction with Claude Code via Telegram, extending AI workflows to mobile devices and integrating cron-based notifications seamlessly.
