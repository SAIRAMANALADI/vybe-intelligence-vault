## Summary
framesmith is an open-source MCP server that transforms AI coding agents into capable UI designers by providing a visual canvas, vetted design patterns, and a quality evaluation system. It enables agents to generate polished, non-slop UI designs before writing any framework code, ensuring high-quality outputs through structured feedback and iterative refinement.

## Key Features
- 11 vetted page patterns (e.g., dashboard, auth, pricing) with regression-tested quality scores > 95
- Real-time quality evaluation with `canvas_evaluate` (6 categories + cliché-tell detection) and `READY`/`NOT READY` directives
- Point-and-tell feedback system for precise human critique integrated into the design workflow
- Open JSON design persistence with content-hash versioning (`canvas_version`) for traceability and CI/CD gates
- Standalone browser viewer for reviewing, inspecting, and managing designs with quality and design-system panels

## Why It Matters for RAG Builders
It bridges the gap between AI-generated UI slop and polished, production-ready designs by enforcing quality standards and structured feedback loops before any code is written.
