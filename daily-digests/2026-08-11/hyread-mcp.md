## Summary
A Model Context Protocol (MCP) server that enables AI agents to query Taiwan's public library HyRead eBook collections, bypassing Cloudflare Turnstile protections using headless browser automation.

## Key Features
- Direct integration with 41 public libraries in Taiwan via HyRead platform
- Bypasses Cloudflare Turnstile using Camoufox headless browser for reliable access
- Supports three MCP tools: keyword search, full library scan, and book availability check
- Zero-infrastructure deployment via local stdio execution with no API keys required
- Optimized for low-frequency, polite usage to avoid service disruption

## Why It Matters for RAG Builders
This tool unlocks access to Taiwan's public library eBook collections for AI agents, enabling localized RAG applications with real-time book availability data without relying on unofficial or unstable APIs.
