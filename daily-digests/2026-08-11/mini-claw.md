## Summary
MiniClaw is a self-hosted personal AI agent built with Python, designed for learning and daily use. It supports CLI and Feishu (Lark) interactions, integrates tools like file operations and HTTPS requests, and enforces security policies with approval workflows.

## Key Features
- Dual interaction via CLI and Feishu (Lark) private chat
- Built-in Textual TUI with streaming responses, tool trace, and audit logging
- Strict policy engine with approval workflows for tool execution
- Persistent memory using SQLite and Markdown files
- Offline evaluation framework with 273+ tests and 21 agent scenarios
