## Summary
oh-my-memory is a self-hosted, cross-platform memory server designed to provide persistent memory, hybrid search, knowledge graph integration, and session management for AI Agents. It features advanced memory scoring, conflict resolution, and multi-layered memory routing.

## Key Features
- Advanced memory scoring with Q-Learning and FSRS v6 for spaced repetition
- Multi-layered memory routing (Episodic → Semantic → Automatic)
- Hybrid search combining vector, memory, and knowledge graph retrieval
- Knowledge graph engine with BFS queries and community detection
- Plugin SDK and MCP server for extensibility and code indexing

## Why It Matters for RAG Builders
It provides a robust, self-hosted memory infrastructure essential for building RAG systems with persistent context, conflict resolution, and intelligent retrieval across multiple data modalities.
