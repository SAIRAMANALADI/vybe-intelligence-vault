## Summary
A Ruby gem providing a curated, offline dataset of 18.5k+ vehicle makes and models across 6 kinds (cars, motorcycles, etc.) with popularity rankings, availability by country, and Rails integration. Includes an MCP server for AI agents and validation helpers.

## Key Features
- Offline dataset of 18.5k+ makes and models with 6 vehicle kinds and body types
- Popularity rankings and availability by country from official registers
- Rails form helpers and ActiveModel validators for seamless integration
- MCP server for AI agents to ground vehicle data without external APIs
- Fuzzy search, smart lookups, and client-side dependent pickers

## Why It Matters for RAG Builders
Provides a reliable, offline-ready dataset for vehicle-related applications, reducing API dependency and enabling AI agents to access accurate vehicle data without hallucinations.
