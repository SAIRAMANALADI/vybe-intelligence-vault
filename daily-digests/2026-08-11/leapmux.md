## Summary
LeapMux is a multi-agent workspace manager that enables concurrent execution of coding agents and shell terminals in isolated git worktrees and branches, with session persistence and end-to-end encrypted communication. It supports both local and remote deployments via a browser or native desktop app.

## Key Features
- Supports multiple coding agents (Claude Code, GitHub Copilot, Cursor, etc.) running concurrently in isolated workspaces
- End-to-end encrypted communication between frontend and workers via Noise protocol
- Session persistence across restarts with git worktree and branch isolation
- Pluggable database backend (SQLite, PostgreSQL, MySQL, etc.) for workspace state management
- Hybrid deployment modes: local, remote, browser-based, or native desktop app

## Why It Matters for RAG Builders
LeapMux streamlines multi-agent workflows by providing a unified workspace for concurrent coding agents, reducing context switching and improving productivity in AI-driven development environments.
