## Summary
Mentor is a multi-skill goal execution orchestrator that decomposes goals into task graphs, supervises execution, and analyzes outcomes to propose improvements. It operates in runtime mode for task routing and failure repair, and heartbeat mode for performance scoring and self-improvement proposals.

## Key Features
- Decomposes goals into supervised task graphs for structured execution
- Layered failure escalation and automated repair mechanisms
- Heartbeat mode for performance analysis and baseline scoring
- Weekly self-improvement proposals routed to Forge for iterative enhancement
- Journal-based schema validation and inconsistency detection
