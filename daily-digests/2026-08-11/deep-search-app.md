## Summary
Deep Search is a local-first Tauri desktop application for AI-powered research that runs entirely on the user's machine, using their own API keys and storage. It exposes an MCP proxy for coding agents to perform guarded, source-verified research with enforced guardrails and persistent memory.

## Key Features
- Local-first architecture with BYOK (Bring Your Own Keys) for LLMs and search providers
- Enforced research guardrails requiring source fetching, reading, and cross-checking before answering
- Persistent research memory with per-topic folders and vector search indexing
- MCP proxy for seamless integration with coding agents (Claude Desktop, Codex, etc.)
- Supports multiple LLM and search providers (Anthropic, OpenRouter, Brave Search, Exa, etc.)

## Why It Matters for RAG Builders
It provides a critical layer of guardrails and persistent memory for RAG systems, ensuring reliable, source-verified research while maintaining full local control and privacy.
