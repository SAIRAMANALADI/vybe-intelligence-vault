## Summary
A modular AI coding agent that automates code-related tasks such as generation, debugging, refactoring, and documentation using the OpenAI Responses API. It supports multiple programming languages and provides a clean architecture with FastAPI, Pydantic v2, and tool-based execution.

## Key Features
- Supports seven core agent actions: explain, review, refactor, generate, debug, write tests, and generate documentation
- Planning, tool calling, short-term memory, and reasoning capabilities built-in
- Clean Architecture with domain, services, infrastructure, and API layers
- Zero-database design using lightweight JSON file storage for persistence
- Interactive UI with a single-page dashboard and auto-generated API docs
