## Summary
MineIntent is an AI companion project for Minecraft Java Edition designed to interact naturally with players, collaborate on activities, and simulate believable human-like behavior within the game world. It aims to blend seamlessly with other players while adhering to server rules and avoiding detection as an automated entity.

## Key Features
- Event-driven companion system with continuous interaction capabilities
- Natural language chat-based collaboration with players (e.g., wood collection)
- Constrained, verifiable action execution with timeouts and cancellations
- Persistent memory and context-aware decision-making
- Self-hosted integration testing with PaperMC 1.21.1 for realistic validation

## Why It Matters for RAG Builders
MineIntent demonstrates how to build AI agents that interact believably within constrained, rule-bound environments like games, offering insights into constrained autonomy, memory consistency, and human-like behavior modeling for RAG systems.
