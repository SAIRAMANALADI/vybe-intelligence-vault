## Summary
A high-performance C++20 library with Python bindings for reading, writing, and manipulating unstructured mesh files across 40+ formats. Supports advanced operations like mesh conversion, transformation, refinement, and field interpolation with optional parallel backends.

## Key Features
- Supports 40+ mesh file formats with zero-copy numpy I/O boundary
- Optional parallel processing with selectable backends (OpenMP, TBB, Kokkos)
- Standalone C++ binary and Python API with identical behavior
- Advanced mesh operations: conversion, transformation, refinement, partitioning, and field interpolation
- Declarative pipeline execution via JSON settings for complex workflows

## Why It Matters for RAG Builders
It streamlines mesh data handling in AI/ML pipelines by providing a unified, high-performance interface for reading, writing, and transforming mesh files across multiple formats and languages.
