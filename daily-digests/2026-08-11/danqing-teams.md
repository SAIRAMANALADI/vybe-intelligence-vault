## Summary
DanQing Teams is an AI agent collaboration platform that enables pure LLM-driven orchestration of multi-agent workflows without human-maintained graphs or workflows. It uses a unified 'Tool' abstraction for all capabilities, including sub-agent delegation, user interaction, and external API calls, with hard context isolation for child agents.

## Key Features
- Pure LLM-driven control flow with no developer-maintained workflows or graphs
- Unified 'Tool' abstraction for all capabilities (sub-agent delegation, user interaction, file operations, etc.)
- Hard context isolation for child agents with structured report returns to parent
- Persistent turn logs enabling full replay, debugging, and human-in-the-loop edits
- Supports interactive demos, research reports, and mini-games via built-in UI

## Why It Matters for RAG Builders
