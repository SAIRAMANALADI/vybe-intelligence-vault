## Summary
Statelet SDKs provide official client libraries for Statelet, an AI-native distributed database combining key-value storage, vector search, and a temporal causal graph. The SDKs wrap a shared gRPC contract and support multiple languages including Python, Node.js, Go, Rust, Java, and C++.

## Key Features
- Unified client libraries for Python, Node.js, Go, Rust, Java, and C++
- Shared gRPC contract for consistent API across languages
- LangChain integration for vector stores, chat history, and graph stores
- Automated protobuf synchronization across SDKs
- Independent versioning and releases for each SDK

## Why It Matters for RAG Builders
Statelet SDKs enable seamless integration of Statelet's AI-native database features into applications across multiple programming languages, simplifying RAG pipeline development.
