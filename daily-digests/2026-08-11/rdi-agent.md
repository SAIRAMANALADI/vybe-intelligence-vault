## Summary
RDI-Agent is a production-grade LangGraph-based cognitive guard agent implementing the Reality-Driven Iteration (RDI) SOP. It enforces Evidence-First auditing before code modifications, featuring zero-config environment discovery, a three-stage probe matrix, and human-audit sovereignty via dry-run mode.

## Key Features
- Zero-config environment discovery (auto-detects Rust/Go/Python/Node)
- Three-stage probe matrix (static check → runtime execution → LLM analysis)
- Human-audit sovereignty with dry-run mode (--commit required for persistence)
- Seven-step Evidence-First loop (Verify Reality → Verify Measurement → Evidence Gate → Change One Thing → Build Knowledge → Freeze And Observe → Reopen Only With Evidence)
- Optimization trap detection (explanation trap, metric worship, narrative bias, etc.)

## Why It Matters for RAG Builders
RDI-Agent enforces rigorous evidence-based iteration in AI agents, preventing blind optimization and ensuring changes are grounded in verifiable data, which is critical for reliable RAG and AI system development.
