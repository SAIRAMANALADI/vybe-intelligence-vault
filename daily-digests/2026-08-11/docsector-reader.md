## Summary
Docsector Reader is a modern documentation rendering engine built with Vue 3, Quasar v2, and Vite, designed to transform Markdown content into interactive, navigable, and AI-friendly documentation sites with advanced features like i18n, dark/light mode, and AI integration capabilities.

## Key Features
- AI-optimized Markdown rendering with raw text export for LLM ingestion
- Built-in MCP server and WebMCP tools for AI assistant integration
- Advanced i18n, dark/light mode, and syntax highlighting
- Automatic sitemap, robots.txt, and AI crawler detection
- Extensible with custom blocks (Mermaid, KaTeX, terminal, API references)

## Why It Matters for RAG Builders
It provides a turnkey solution for building AI-ready documentation sites that seamlessly integrate with RAG pipelines and AI assistants through standardized discovery mechanisms and raw content delivery.
