## Summary
A Windows-based desktop application that transforms plain text Markdown files into a private, AI-powered knowledge base for note-taking, research, and contextual querying. It indexes local documents to enable accurate, personalized AI responses without cloud dependency.

## Key Features
- Converts plain text Markdown files into a structured knowledge graph for AI consumption
- Local-first architecture ensuring privacy and data ownership
- Built-in linting system to validate and improve note structure
- Automatic indexing and background updates for changed files
- Customizable AI model settings for speed vs. depth trade-offs

## Why It Matters for RAG Builders
It provides a privacy-focused, local alternative for building and querying a personal knowledge base, critical for RAG systems requiring domain-specific or proprietary data without cloud exposure.
