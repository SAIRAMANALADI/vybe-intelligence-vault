## Summary
mdv is a fast markdown workspace designed for both human users and AI agents, offering split-screen editing, live preview, shareable links, and a built-in MCP server for agent-driven document publishing and collaboration.

## Key Features
- Split-screen markdown editor with live preview for seamless human editing
- One-click shareable links for public or private document access
- Line-anchored comments with automatic outdated detection for collaborative reviews
- Built-in MCP server enabling AI agents to publish, read, and update documents programmatically
- GitHub Flavored Markdown support with Mermaid diagrams and Shiki syntax highlighting

## Why It Matters for RAG Builders
mdv bridges the gap between AI-generated content and human collaboration by providing a structured, shareable markdown workspace with MCP integration, enabling seamless agent-to-human document workflows.
