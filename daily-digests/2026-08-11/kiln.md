## Summary
Kiln is an open-source MCP server that enables AI agents to design, slice, queue, monitor, and manage 3D printing workflows end-to-end across multiple printer types and slicing backends. It bridges natural language prompts to physical 3D printing via a unified control plane.

## Key Features
- End-to-end AI-driven 3D printing pipeline from natural language prompts to physical output
- Supports 10+ printer types and slicing backends (OctoPrint, Moonraker, Bambu Lab, Prusa, etc.)
- 840+ MCP capabilities and 224 CLI commands for AI agent orchestration
- Real-time printer monitoring, failure recovery, and resume-from-layer functionality
- Integrated design, slicing, and decoration tools with support for photos, QR codes, and procedural textures

## Why It Matters for RAG Builders
Kiln enables AI agents to autonomously execute complex 3D printing workflows, reducing manual intervention and accelerating prototyping and manufacturing processes for RAG and AI stack builders.
