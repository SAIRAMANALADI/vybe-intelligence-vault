## Summary
SprintPulse AI is an AI-powered sprint risk intelligence platform that correlates standup updates, Jira ticket movements, and Git commit activity to detect delivery risks early. It provides role-aware decision briefs and exposes MCP tools for agent integration, enabling proactive sprint management.

## Key Features
- Real-time detection of say-do gaps between standups, Jira, and Git activity
- TOON-encoded AI prompts for efficient token usage and cost optimization
- Role-aware decision briefs for Scrum Masters, Product Owners, and Engineering Managers
- MCP server exposing 6 tools for agent integration (e.g., Claude Code, Cursor)
- Automated transcript ingestion from WebVTT or plain text for standup analysis

## Why It Matters for RAG Builders
SprintPulse bridges the critical gap between what teams say in standups and what their Jira/Git activity proves, enabling early detection of sprint risks and proactive intervention to prevent failures.
