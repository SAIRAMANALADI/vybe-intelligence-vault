## Summary
RunJam is a local-first desktop application that unifies management and execution of multiple AI agents (Claude Code, Codex CLI, Gemini CLI) in a single interface. It provides auto-detection, one-click installation, unified chat, project workspaces, and built-in local model support via llama.cpp.

## Key Features
- Auto-detection and one-click installation of AI agents (Claude Code, Codex CLI, Gemini CLI)
- Unified chat interface with real-time streaming, Markdown rendering, and syntax highlighting
- Built-in project workspace with file explorer, code editor, and terminal per project
- Local model support via llama.cpp for offline, cost-free inference
- Unified model configuration with automatic protocol proxy and cache optimization

## Why It Matters for RAG Builders
RunJam simplifies the management of multiple AI agents and models in a single local-first interface, reducing operational overhead and enabling seamless multi-agent workflows for RAG builders.
