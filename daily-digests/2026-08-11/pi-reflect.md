## Summary
pi-reflect is a tool for iterative self-improvement of AI coding agents by analyzing session transcripts and reference material to make surgical edits to behavioral files (e.g., AGENTS.md, MEMORY.md, SOUL.md). It helps agents converge toward defined targets by identifying gaps and applying targeted corrections.

## Key Features
- Surgical edits to markdown files based on LLM analysis of session transcripts and reference material
- Automatic versioning via Git commits for full edit history and convergence tracking
- Customizable targets (behavioral rules, memory, personality) with configurable prompts
- Supports multiple data sources (files, commands, URLs) with lookback and size limits
- Impact metrics (correction rate, rule recidivism) to measure convergence progress

## Why It Matters for RAG Builders
It enables AI agents to autonomously refine their behavior, memory, and personality over time, reducing manual oversight and improving long-term performance in RAG systems.
