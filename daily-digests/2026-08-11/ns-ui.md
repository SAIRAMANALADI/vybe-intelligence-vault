## Summary
ns-ui is a shadcn-compatible registry of 298 React components designed for zero-config installation via URL, eliminating package dependencies. It includes two collections: a restrained 'core' set and a flashy 'loud' showcase, all validated by rigorous Playwright testing.

## Key Features
- Install components directly via URL without package dependencies using shadcn
- Two curated collections ('core' and 'loud') with interactive, visually distinct components
- Rigorous Playwright-based validation ensuring accessibility, theming, and interaction fidelity
- Built-in MCP server and CLI for agent-driven component discovery and installation
- Live registry with interactive previews and bookmarking for saved components

## Why It Matters for RAG Builders
It streamlines UI component integration for RAG builders by enabling zero-config, agent-driven component installation and validation.
