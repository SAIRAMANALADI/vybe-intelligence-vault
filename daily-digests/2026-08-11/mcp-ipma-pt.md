## Summary
This repository provides an MCP (Model Context Protocol) server for accessing real-time weather, UV index, sea state, and earthquake data from IPMA Portugal. It is part of the Pipeworx gateway, which connects AI agents to over 1317 live data sources.

## Key Features
- Provides structured access to IPMA Portugal's weather, UV, sea state, and earthquake data
- Integrates seamlessly with MCP clients like Claude Desktop, Cursor, and Windsurf
- Part of a larger gateway (Pipeworx) offering 1317+ live data sources
- Supports plain English queries via ask_pipeworx for simplified usage
- MIT licensed for open-source adoption
