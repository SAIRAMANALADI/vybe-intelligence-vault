## Summary
This repository implements a Model Context Protocol (MCP) server for VictoriaMetrics' vmanomaly, enabling AI assistants to interact with vmanomaly's REST API for anomaly detection, model management, and observability insights. It bridges AI workflows with VictoriaMetrics' time-series anomaly detection capabilities.

## Key Features
- Seamless integration with vmanomaly REST API for AI-assisted anomaly detection
- Embedded vmanomaly documentation with full-text search and fuzzy matching
- Model management, configuration generation, and alert rule creation for vmalert
- Health monitoring and data-driven recommendations for model tuning
- Supports multiple transport modes (stdio, HTTP, SSE) for MCP clients

## Why It Matters for RAG Builders
