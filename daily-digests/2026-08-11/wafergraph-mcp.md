## Summary
A remote MCP server exposing wafergraph.com's semiconductor and AI supply-chain dataset as five read-only tools for MCP-speaking AI agents. The dataset includes 565 companies, supplier/customer relationships, and a 74-deal M&A corpus, accessible via a Cloudflare Worker with no authentication or cost.

## Key Features
- Exposes 5 read-only tools for querying semiconductor and AI supply-chain data via MCP
- Provides company profiles, supplier/customer graphs, and M&A deal corpus with attribution
- No authentication or cost required for access
- Streamable HTTP transport with Cloudflare Worker backend
- Field-verified data with whitelisted fields for trust and reliability

## Why It Matters for RAG Builders
It provides structured, high-quality semiconductor and AI supply-chain data essential for RAG systems needing real-time or near-real-time insights into company relationships and market dynamics.
