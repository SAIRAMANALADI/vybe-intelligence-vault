## Summary
An end-to-end RAG application that enables users to upload PDF documents, extract text, generate vector embeddings, store them in a FAISS vector database, and answer user questions using Google Gemini with context from the uploaded documents.

## Key Features
- Multi-PDF upload and processing
- Semantic search using FAISS vector store
- Context-aware responses with Google Gemini Pro
- Interactive Streamlit-based UI
- Fast document retrieval and embedding generation

## Why It Matters for RAG Builders
It provides a practical, end-to-end implementation of a RAG pipeline for document-based question answering, leveraging Google Gemini and FAISS for efficient retrieval and generation.
