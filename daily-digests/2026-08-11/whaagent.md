## Summary
WhaAgent is a multi-tenant WhatsApp AI platform that connects AI agents to WhatsApp users via a Go gateway and a Python FastAPI backend. It enables deployment of intelligent agents (e.g., general-purpose, developer, news) with support for 10+ LLM providers and MCP tools, facilitating real-time conversational AI on WhatsApp.

## Key Features
- Multi-tenant WhatsApp gateway with concurrent session management
- LangGraph-powered agent framework with Summarize-Router-Agent state graph
- Support for 12+ built-in agents (assistant, developer, news, etc.) and custom agent registration
- Integration with 10+ LLM providers (OpenAI, Anthropic, Google, Ollama, etc.)
- MCP tool layer for external API integrations and local tool execution

## Why It Matters for RAG Builders
WhaAgent enables seamless deployment of AI agents on WhatsApp, bridging conversational AI with real-world messaging platforms for scalable, multi-tenant applications.
