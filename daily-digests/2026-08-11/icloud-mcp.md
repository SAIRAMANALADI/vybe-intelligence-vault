## Summary
This MCP server enables AI assistants like Claude to interact with Apple services (Email, Calendar, Contacts, Reminders, Notes, Messages, Safari) via the Model Context Protocol. It supports both local macOS access via AppleScript and remote iCloud access via IMAP/CalDAV/CardDAV protocols.

## Key Features
- Dual-mode operation: local (macOS AppleScript) and cloud (iCloud protocols) for flexible deployment
- 41 tools across 7 services (Email, Calendar, Contacts, Reminders, Notes, Messages, Safari) with full CRUD operations
- Secure authentication via AppleScript permissions or app-specific passwords for cloud mode
- Runtime mode switching between LOCAL and CLOUD without restarting the server
- Cross-platform compatibility (cloud mode) and macOS-native speed (local mode)

## Why It Matters for RAG Builders
This MCP server bridges AI assistants with Apple's ecosystem, enabling seamless integration for tasks like email management, calendar scheduling, and contact updates within RAG pipelines.
