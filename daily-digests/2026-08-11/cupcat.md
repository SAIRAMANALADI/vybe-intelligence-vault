## Summary
CupCat is a free, local-first AI-native video editor for Windows where an AI agent (Claude) operates the timeline directly via plain language commands. It combines ~100 editing tools with local AI models (Whisper, Piper, sherpa-onnx) and integrates with external AI services (Higgsfield) for generative tasks, all while ensuring user privacy and zero credits.

## Key Features
- AI-driven timeline editing with ~100 tools (cut, trim, captions, reframing, etc.) via plain language commands
- Local AI toolbox (Whisper, Piper, sherpa-onnx, ffmpeg) for transcription, TTS, audio separation, and video processing without cloud dependency
- MCP server integration enabling external AI clients (Claude Code/Desktop) to edit timelines directly
- Pro editing capabilities (multicam, HDR, ProRes export, keyframe curves) with user-initiated exports
- Zero-credit local features with optional generative AI (Higgsfield) for video/image upscaling and background removal

## Why It Matters for RAG Builders
CupCat demonstrates how AI agents can directly manipulate complex timelines in creative applications while prioritizing local processing and user privacy, offering a blueprint for agentic workflows in media editing.
