## Summary
CALM provides a live, graph-verified map of codebases to enable AI coding agents to edit code with full visibility into dependencies, call graphs, and safety constraints. It replaces guesswork with compiler-verified edges and hard pre-edit gates to prevent silent breakages.

## Key Features
- Real-time, compiler-verified call graphs for 13+ languages out of the box
- Hard safety gates on write paths to prevent silent breakages (e.g., hub symbol edits require explicit confirmation)
- Confidence-graded dependency edges (textual → inferred → resolved → formal)
- Multi-tier indexing with 24 languages parsed and 12 with formal verification paths
- Cross-process edit locks and single-writer indexing for concurrent editor sessions

## Why It Matters for RAG Builders
CALM provides AI agents with a trustworthy, live dependency map to eliminate guesswork during code edits, ensuring safer and more reliable automated refactoring.
