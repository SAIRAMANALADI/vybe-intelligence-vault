## Summary
Onlyboxes is a self-hosted code execution sandbox platform designed for individuals and small teams, featuring a control-plane (console) and execution-plane (worker) architecture with support for REST APIs and MCP tools for secure, isolated code execution.

## Key Features
- Separated control and execution planes with horizontal scaling for workers
- Multi-language and multi-runtime support (e.g., Python, terminal sessions)
- Built-in MCP tools for Python execution, terminal sessions, and image reading
- Full account system for resource isolation and stateful container management
- One-click installer and manual deployment options with detailed configuration guides

## Why It Matters for RAG Builders
It provides a secure, scalable, and self-hosted sandbox environment for executing code and managing sessions, which is critical for RAG builders needing isolated execution environments for dynamic data processing.
