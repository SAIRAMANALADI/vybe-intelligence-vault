## Summary
A no-code framework for building AI research agents using Claude Code. It guides users through an interview to configure a research agent tailored to their needs, enabling automated report generation without writing code.

## Key Features
- No-code setup via interactive interview with Claude
- Modular workflows defined in plain-language files (workflows/, sources.md)
- Agent behavior customizable through editable files (agent-profile.md, workflows/research.md)
- Automated report generation with `/research` command
- Supports iterative agent refinement via `/setup-agent`

## Why It Matters for RAG Builders
It democratizes AI agent creation by enabling non-technical users to build and customize research agents without coding, accelerating RAG pipeline development.
