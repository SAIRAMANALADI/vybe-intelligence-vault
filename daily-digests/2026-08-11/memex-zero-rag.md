## Summary
MeMex-Zero-RAG is a production-ready personal knowledge base system that compiles structured, interlinked wiki content from raw sources using LLMs without embeddings or vector databases. It enforces zero hallucination through strict citation requirements, supports multi-agent collaboration via git worktrees, and includes an optional MCP server for agent integration.

## Key Features
- Zero hallucination enforcement with mandatory source citations for every claim
- LLM-agnostic architecture supporting Claude, GPT, Llama, and other agents
- Multi-agent support via git worktrees with human-in-the-loop conflict resolution
- Optional knowledge graph visualization for wikilink relationships
- MCP server integration for exposing the wiki to external agents

## Why It Matters for RAG Builders
It provides a git-native, zero-infrastructure alternative to RAG that compounds knowledge over time rather than rediscovering it per query, making it ideal for long-term knowledge retention and multi-agent collaboration.
