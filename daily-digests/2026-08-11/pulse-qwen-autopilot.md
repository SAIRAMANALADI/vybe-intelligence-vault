## Summary
Pulse Qwen Autopilot is a human-gated emergency coordination agent that interprets ambiguous emergency reports, validates nearby care facilities, and generates a constraint-checked plan for human approval before any external action. It uses Qwen Cloud for reasoning and Alibaba Function Compute for deterministic tool execution.

## Key Features
- Bounded Qwen reasoning loop with four strict tools (protocol selection, facility search, plan preparation, coordination submission)
- Human approval gate before any external action, ensuring safety and accountability
- Deterministic validation of facility IDs, plan hashes, and tool execution order
- Synthetic emergency report processing with no real patient data exposure
- Alibaba Function Compute backend with FastAPI proxy for secure, auditable operations

## Why It Matters for RAG Builders
It demonstrates a robust, human-gated agent framework for high-stakes scenarios where LLM reasoning must be tightly controlled and validated before action.
