## Summary
A modular toolkit for integrating AI-driven 3D geospatial control into CesiumJS applications. It provides protocol-agnostic command execution, multiple integration paths (browser agents, WebMCP, function calling, MCP runtime), and 60+ tools for camera, entities, layers, and spatial analysis.

## Key Features
- Protocol-agnostic Cesium command executor with 60+ tools across 12 toolsets
- Four integration paths: browser agent, WebMCP, function calling, and MCP runtime
- Transport-neutral tool contracts for browser-safe operations
- Native WebMCP adapter for Chrome 149+ experimental browsers
- Versioned to track CesiumJS releases with independent MCP patch iterations
