## Summary
Poolstatis is an agent-native product analytics system designed for coding agents (via MCP) rather than human users. It enables semantic metric registration, event ingestion, and automated decision-making based on product hypotheses and evidence windows.

## Key Features
- Semantic metric registry with required purpose definitions for maintainability
- MCP server for agent-driven instrumentation and querying
- Automated decision-making based on evidence windows and hypotheses
- Headless admin SPA for project and metric management
- Docker-based self-hosting with minimal setup

## Why It Matters for RAG Builders
It provides a structured, agent-friendly approach to product analytics that aligns with automated decision-making workflows, reducing manual dashboard reliance for AI-driven development.
