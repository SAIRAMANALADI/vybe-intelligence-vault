## Summary
A high-performance Model Context Protocol (MCP) filesystem server written in Go, designed for Claude Desktop and Claude Code. It provides 20 optimized tools for file operations, Git integration, and JavaScript minification with advanced features like atomic batch operations, risk assessment, and real-time observability via a separate dashboard.

## Key Features
- 17 core tools plus Git and JavaScript minification with zero tool bloat
- Intelligent editing with automatic backups, risk assessment, and rollback on failure
- 3-tier caching with file watcher invalidation for O(1) reads and streaming I/O for large files
- WSL/Windows path translation and compact mode for token-efficient responses
- Atomic batch operations, pipeline system with DAG-based parallel execution, and real-time dashboard for observability
