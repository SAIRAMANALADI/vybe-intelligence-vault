## Summary
This repository provides a Cursor rules file (.mdc) that integrates the VirtualSMS MCP server for AI agents to handle SMS verification, number rentals, proxies, and cloud browser sessions using real SIM cards. It simplifies account verification workflows for developers and AI systems.

## Key Features
- Drop-in Cursor rules for seamless SMS verification and OTP handling
- Access to 40 MCP tools for SMS, number rentals, and proxies
- Supports real SIM cards across 145+ countries and 2500+ services
- Zero-install option via hosted MCP server or local npm package
- Proxy and cloud browser session integration for bypassing geo-restrictions
