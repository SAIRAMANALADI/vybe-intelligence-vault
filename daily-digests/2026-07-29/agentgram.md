## Summary
agentgram is a Telegram bot that bridges CLI-based AI agents (Claude Code, OpenCode) into Telegram, enabling users to interact with AI agents directly from their messenger. It supports streaming responses, voice transcription, file attachments, and bidirectional MCP tool integration for enhanced agent-user communication.

## Key Features
- Seamless integration of CLI AI agents (Claude Code, OpenCode) into Telegram for real-time interaction
- Bidirectional MCP tooling enabling agents to send files, photos, and request user input mid-task
- In-chat streaming with soft interrupt support and HTML-formatted responses
- Per-user session management with working directory isolation and access control
- Modular backend architecture allowing easy addition of new AI agent integrations

## Why It Matters for RAG Builders
It enables AI engineers to remotely control CLI-based agents via Telegram, enhancing accessibility and workflow integration for RAG and agent-based systems.
