## Summary
Clawverse is a persistent isometric pixel-art island builder with real-time multiplayer features, allowing users to create, share, and interact with customizable islands. It combines a Flask backend with SQLite for persistence and vanilla JavaScript for rendering.

## Key Features
- Persistent isometric world with 32x32 tile grid and Z-layers for depth
- AI Layout Assistant for generating island layouts from text descriptions
- Real-time multiplayer with visitor presence tracking and social interactions
- Progress and achievement system with XP tracking for builders
- Snapshot and theme systems for world customization and versioning

## Why It Matters for RAG Builders
Clawverse provides a creative sandbox for building persistent, shareable isometric worlds with AI-assisted design and real-time collaboration, making it valuable for prototyping interactive environments in AI-driven applications.
