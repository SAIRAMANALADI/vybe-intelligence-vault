## Summary
Octomind is an open-source runtime for deploying specialist AI agents with zero-configuration flexibility. It enables domain-specific agents to be installed and run with a single command, supporting dynamic tool activation, adaptive session management, and policy-driven guardrails for autonomous operations.

## Key Features
- Zero-config deployment of specialist agents via a registry of pre-configured agents (TAPs)
- Adaptive session compaction to maintain context sharpness over long sessions without truncation
- Cost control plane with per-step model selection, real-time spending tracking, and hard caps
- Policy-as-code guardrails with pre-call denies, post-result hooks, and post-turn validators for deterministic safety
- Intent-driven context activation that dynamically loads only relevant skills and tools based on user intent

## Why It Matters for RAG Builders
Octomind simplifies the deployment of specialized AI agents with built-in governance and cost controls, making it essential for building reliable, autonomous RAG systems that scale across domains without manual intervention.
