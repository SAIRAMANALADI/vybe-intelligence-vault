## Summary
ClawCode transforms Claude Code into a persistent AI agent by adding memory, personality, multi-channel messaging, and 24/7 service capabilities directly as a plugin. It enables agents to retain context across sessions, adapt to user language, and integrate with platforms like WhatsApp, Telegram, and Discord without requiring a separate runtime or additional API billing.

## Key Features
- Persistent identity and personality across sessions via lifecycle hooks and injected context files (SOUL.md, IDENTITY.md)
- Multi-channel messaging integration (WhatsApp, Telegram, Discord, Slack, iMessage) with platform-adaptive formatting
- Active memory system with bilingual recall (Spanish ↔ English) and nightly dreaming consolidation for long-term retention
- Always-on service mode with systemd/launchd support for 24/7 agent operation and background tasks
- Smart import from OpenClaw agents, channel scope privacy controls, and execution gate guardrails for safe tool usage

## Why It Matters for RAG Builders
ClawCode enables RAG builders to create persistent, context-aware AI agents that retain user-specific knowledge and personality without requiring external harnesses or additional API costs, directly enhancing the reliability and personalization of RAG systems.
