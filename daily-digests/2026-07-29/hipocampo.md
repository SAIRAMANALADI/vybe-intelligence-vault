## Summary
Hipocampo is a dual-memory persistence system for autonomous AI agents, combining PostgreSQL 17 with pgvector for hybrid search and a Model Context Protocol (MCP) server. It enables persistent memory, error learning loops, and prompt compression to enhance agent adaptability and efficiency.

## Key Features
- Dual-memory architecture with PostgreSQL 17 and pgvector for hybrid search (BIRE v3.7)
- Sparse Selective Caching (SSC) and prompt compression (20-50% token reduction)
- Memory graph and hierarchy for semantic relationships and consolidation
- Session memory, auto-summarization, and proactive context preloading
- Native MCP server integration with 22+ tools for seamless AI agent interaction

## Why It Matters for RAG Builders
Hipocampo provides persistent, stateful memory and hybrid search capabilities essential for building autonomous AI agents that learn and adapt across sessions while reducing context window usage through advanced prompt compression.
