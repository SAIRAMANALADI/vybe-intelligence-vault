## Summary
AMFS (Agent Memory File System) provides a shared cognitive layer for multi-agent systems, enabling agents to discover, handoff, and learn from shared knowledge with version-controlled memory, confidence scoring, and outcome-based feedback loops.

## Key Features
- Version-controlled agent memory with branching, diffs, and rollbacks (Git-like operations)
- Confidence scoring that evolves based on real-world outcomes (success/failure of deployments)
- Hybrid search combining full-text, semantic, recency, and confidence for ranked results
- Knowledge graph auto-materialization for tracking relationships between entities and agents
- MCP server integration for seamless use with Cursor, Claude Desktop, and other MCP clients

## Why It Matters for RAG Builders
AMFS enables multi-agent systems to share, validate, and learn from collective knowledge, reducing redundancy and improving decision-making through versioned memory and outcome-driven confidence adjustments.
