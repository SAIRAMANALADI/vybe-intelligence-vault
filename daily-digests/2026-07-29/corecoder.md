## Summary
CoreCoder is a minimal Python implementation distilling the architectural patterns of Claude Code into ~1,400 lines, providing a blueprint for building AI coding agents. It serves as a teaching tool and foundation for developers to understand and replicate core agentic systems.

## Key Features
- Distilled architectural patterns from 512K lines of Claude Code into ~1,400 lines of Python
- Supports parallel tool execution with ThreadPool for efficient agent operations
- Implements 3-layer context compression for managing large conversation histories
- Provides sub-agent isolation with isolated context for modular agent behavior
- Includes session persistence for saving and resuming agent interactions
