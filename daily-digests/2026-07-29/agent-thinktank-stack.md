## Summary
Sprintra Memory-Sync Agent (SMSA) is a persistent context management system for AI coding assistants that enables continuity across sessions by maintaining project memory, sprint tracking, decision logging, and knowledge base delivery via the Model Context Protocol (MCP). It integrates with major AI tools like Claude Code, Cursor, and OpenAI Codex.

## Key Features
- Persistent memory storage across sessions for AI assistants
- Sprint tracking and agile workflow management
- Decision logging with Architecture Decision Records (ADR)
- 20 specialized MCP tools for context management
- Cross-platform support (Windows, macOS, Linux) and multilingual compatibility

## Why It Matters for RAG Builders
SMSA enables AI coding assistants to retain project context and continuity across sessions, eliminating the need to repeat context and improving developer productivity in long-term projects.
