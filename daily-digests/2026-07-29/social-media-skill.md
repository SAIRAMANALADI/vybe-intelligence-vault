## Summary
A collection of 150 reusable Skills for social media research, content collection, and monitoring across 18 platforms. These Skills enable agents to bypass platform restrictions by using BrowserAct for browser automation, allowing structured data extraction from logged-in sessions or dynamic content.

- Uses BrowserAct for handling dynamic content, logins, and anti-bot measures
- Supports cross-platform workflows like creator discovery, competitor monitoring, and trend analysis

- Designed for agent-based automation with reusable Skill instructions
