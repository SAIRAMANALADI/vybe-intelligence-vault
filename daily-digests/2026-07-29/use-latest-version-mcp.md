## Summary
An MCP server providing real-time package version lookups and dependency management across 39 registries, enabling AI agents to query live registry data for accurate dependency truth and safe upgrade pipelines.

## Key Features
- Live version lookups across 39 registries (npm, PyPI, Maven, etc.)
- Safe upgrade pipeline with dry-run validation and rollback support
- Semver comparison and conflict detection for dependency resolution
- Project scanning for manifests and lock files (package.json, requirements.txt, etc.)
- Local-first operation with optional GitHub token for rate limiting

## Why It Matters for RAG Builders
It ensures AI agents and workflows always operate with current dependency data, eliminating training-data staleness in package versions.
