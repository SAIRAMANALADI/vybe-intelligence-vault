## Summary
Nika-Agents is a plugin marketplace for the Nika workflow automation system, enabling AI agents to delegate repeatable tasks to Nika for verification, budget control, and traceability. It provides MCP oracles, slash commands, and skills for integration with Codex, Claude Code, and Hermes clients.

## Key Features
- MCP oracle with 8 read-only tools for workflow inspection and validation
- Authoring skill (`nika-authoring`) for check-repair loops before token expenditure
- Slash commands (`/nika:check`, `/nika:explain`, `/nika:new`) for agent interaction
- Multi-client support (Codex, Claude Code, Hermes) with plugin marketplace integration
- Version-pinned integrations and drift detection via `mirror.json`

## Why It Matters for RAG Builders
Nika-Agents enables AI agents to offload and verify repeatable tasks efficiently, reducing token waste and improving reliability in RAG pipelines.
