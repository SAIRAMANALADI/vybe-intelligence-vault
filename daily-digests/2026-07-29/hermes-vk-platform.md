## Summary
A plugin adapter for the Hermes Agent that enables VK Messenger and VK community bot interactions via VK Group Long Poll API. It facilitates inbound message handling, outbound replies, media attachments, and access control for VK communities.

## Key Features
- Inbound VK message handling via Group Long Poll API
- Outbound replies and media uploads through VK API
- Access control with allowlists and configurable policies
- Deduplication of repeated Long Poll events
- Support for inbound and outbound media attachments (photos, documents, voice, video)

## Why It Matters for RAG Builders
It enables Hermes Agent to integrate with VK Messenger communities, expanding AI agent interactions to a major social platform with robust access control and media handling.
