## Summary
Muse is a local-first personal AI agent that builds a private, user-specific model from personal notes and files, ensuring all data stays on the user's machine. It learns individual preferences, goals, and facts while maintaining zero cloud egress by default and citing every claim to prevent fabrication.

## Key Features
- Builds a private, user-specific model from personal notes and files without cloud egress by default
- Forgets corrections immediately and cites every claim to prevent fabrication
- Supports multi-agent orchestration, MCP servers, and deterministic safety guards
- Integrates with local tools (calendar, notes, tasks) and messaging platforms (Telegram, Discord, Slack)
- Runs on local open-source models (e.g., gemma4:12b via Ollama) with provider-neutral architecture

## Why It Matters for RAG Builders
Muse provides a privacy-preserving, user-specific AI agent framework that ensures grounded recall and zero fabrication, critical for building trustworthy RAG systems.
