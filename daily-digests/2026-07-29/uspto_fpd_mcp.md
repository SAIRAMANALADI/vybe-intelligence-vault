## Summary
A high-performance Model Context Protocol (MCP) server for the USPTO Final Petition Decisions API, offering token-saving context reduction, user-customizable fields, and cross-MCP integration for comprehensive patent lifecycle analysis.

## Key Features
- Token-saving context reduction for focused responses (80-99% reduction)
- User-customizable fields via YAML configuration without code changes
- Cross-MCP integration with Patent File Wrapper (PFW) MCP for unified patent lifecycle analysis
- Secure API key storage using Windows DPAPI encryption
- Advanced OCR capabilities with Mistral OCR for scanned PDFs and cost transparency

## Why It Matters for RAG Builders
This MCP server enables AI agents to efficiently retrieve and analyze USPTO Final Petition Decisions with reduced token usage and seamless integration into broader patent lifecycle workflows.
