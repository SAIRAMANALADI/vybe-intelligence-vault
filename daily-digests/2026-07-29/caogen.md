## Summary
CaoGen is a multi-vendor AI desktop workspace designed to unify model configurations, project rules, and workflows into a single controllable environment. It enables users to manage AI-driven tasks, code execution, and file operations across macOS, Windows, and Linux.

## Key Features
- Unified multi-vendor model management with intelligent routing and failover
- Project-level AI workflow rules and memory with configurable prompts and constraints
- Built-in terminal, file editor, and multi-format document preview (PDF, Office, Markdown)
- 3D office visualization for session, agent, and task state tracking
- Git worktree isolation, diff review, and PR/MR creation for safe code changes

## Why It Matters for RAG Builders
CaoGen provides a unified AI-driven desktop environment that simplifies multi-vendor model integration and project workflows, reducing complexity for RAG builders who need a cohesive interface for agent orchestration and task management.
