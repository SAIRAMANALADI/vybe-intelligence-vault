## Summary
DeployDiff CLI enables developers to preview infrastructure changes, estimate cost impacts, and generate rollback commands for Terraform, CloudFormation, and Pulumi plans before deployment, reducing deployment risks.

## Key Features
- Preview infrastructure changes with human-readable diffs and resource summaries
- Estimate cost impact of changes using provider-native pricing data
- Generate provider-specific rollback commands to reverse deployments
- Multi-provider support for Terraform, CloudFormation, and Pulumi
- MCP server mode for AI agent integration (e.g., Claude Code, Cursor)

## Why It Matters for RAG Builders
DeployDiff ensures safer, cost-aware infrastructure deployments by providing actionable insights before changes are applied, critical for AI-driven automation and CI/CD pipelines.
