## Summary
ContextBridge is a local-first MCP server that indexes codebases via Graphify output and provides ranked, compact retrieval of relevant files, symbols, and dependencies for AI coding agents. It reduces token usage by delivering focused context instead of raw source files.

## Key Features
- Hybrid keyword + vector search for precise file and symbol retrieval
- Domain-aware ranking via swappable profile plugins
- Optional local LLM analysis stage for further context compression
- Real-time dashboard for monitoring retrieval quality and token savings
- Supports multiple retrieval modes (Hybrid, Semantic, Keyword)

## Why It Matters for RAG Builders
ContextBridge drastically reduces token costs and noise in RAG pipelines by delivering only the most relevant code context to AI agents, making it essential for efficient and accurate AI-driven code analysis.
