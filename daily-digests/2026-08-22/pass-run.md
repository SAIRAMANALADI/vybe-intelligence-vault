## Summary
pass-run is a Windows utility that securely injects secrets from password-store tools like `pass` or `passage` into environment variables at runtime, enabling programs to access credentials without exposing them in plaintext or requiring manual input.

## Key Features
- Securely injects secrets from `pass` or `passage` into environment variables at runtime
- No storage of plaintext secrets on disk
- Works with any program that reads environment variables
- Lightweight and easy to integrate into existing workflows
- Supports Windows 10+ with minimal dependencies

## Why It Matters for RAG Builders
It simplifies secure secret management for Windows users by bridging Unix-style password stores with Windows environment variables, reducing exposure risks in AI and application workflows.
