## Summary
NOMOS is a local-first personal AI agent that operates entirely on the user's machine, prioritizing privacy, security, and user control. It includes built-in lightweight models, memory management, and governance policies to ensure safe and auditable AI interactions.

## Key Features
- 100% local execution with fail-closed policies to prevent unauthorized data egress
- Built-in lightweight AI model (~400MB) requiring no GPU or cloud dependency
- Reproducible builds with cryptographic provenance (SLSA/Sigstore) and SBOM verification
- Governed skills and connectors with mandatory user approval for sensitive actions
- Automated routing engine that prioritizes local models and provides transparency in decision-making

## Why It Matters for RAG Builders
NOMOS provides a secure, auditable, and user-controlled framework for deploying AI agents locally, addressing critical privacy and governance concerns in RAG and AI stack implementations.
