## Summary
A lightweight Elixir-based MCP server that runs over stdio transport, enabling local hybrid search, intelligent knowledge memory, and AI-powered tooling for HexDocs, GitHub issues, and package documentation. It integrates with Mistral models for embeddings and chat completions.

## Key Features
- Hybrid search combining FTS5 and vector similarity for semantic re-ranking in a single SQL query
- Intelligent knowledge memory with multi-stage LLM curation for deduplication and structuring
- Automated ingestion of HexDocs, GitHub issues, and Hex.pm packages using Mistral embeddings
- Compatibility with Claude Code, Cursor, and Google Antigravity CLI via MCP
- Telemetry and token usage tracking for monitoring and optimization

## Why It Matters for RAG Builders
It provides a local, AI-powered MCP server for RAG systems, enabling hybrid search, knowledge memory, and tooling without relying on external cloud services.
