## Summary
POV Agent is an early-stage Flutter-based local-first assistant that uses device cameras for real-time scene observation, on-device YOLO object detection, and stable scene tracking to answer questions about the current environment without cloud dependency.

## Key Features
- On-device YOLO object detection with bounding boxes and confidence scores
- Stable scene tracking from noisy detections to suppress false positives
- Recorded-video input mode for testing without physical camera hardware
- Feature-first clean architecture with domain, application, data, and presentation layers
- Session-scoped data handling with no persistent storage of camera frames or audio

## Why It Matters for RAG Builders
POV Agent demonstrates a local-first approach to multimodal AI agents, reducing cloud dependency while enabling real-time scene-aware interactions on mobile devices.
