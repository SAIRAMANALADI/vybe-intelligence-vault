## Summary
LSBible SDK Monorepo provides multi-language SDKs (TypeScript and Python) and an MCP server for accessing the Legacy Standard Bible (LSB) API. It enables structured, type-safe Bible data retrieval with rich formatting preservation and search analytics for AI and application integrations.

## Key Features
- Multi-language SDKs (TypeScript and Python) with full type safety and IDE autocomplete
- Model Context Protocol (MCP) server for seamless AI application integration
- Rich text formatting preservation (red-letter, italics, small-caps, etc.)
- Structured parameter design eliminating string parsing ambiguity
- Search distribution analytics for text-based queries across Bible sections
