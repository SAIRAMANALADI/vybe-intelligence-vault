## Summary
Restork is a local-first agent workspace designed for research, study, and work, enabling users to transform local knowledge and cloud reasoning into a reviewable, recoverable loop. It emphasizes privacy, approval-based actions, and layered memory systems without requiring external dependencies like LangGraph or graph databases.

## Key Features
- Governed Core with Research, Study, and Work modes sharing a unified system
- Local-first architecture with Obsidian Markdown as the source of truth
- Layered memory system (Working, Episodic, Semantic, Profile) with inspectable and correctable layers
- Approval-based writes with single-use, expiring, and digest-bound capabilities
- Privacy-first design with opt-in cloud model access and no silent data exposure

## Why It Matters for RAG Builders
Restork provides a privacy-preserving, governed framework for integrating local knowledge with cloud reasoning, essential for building secure and auditable AI agent workflows.
