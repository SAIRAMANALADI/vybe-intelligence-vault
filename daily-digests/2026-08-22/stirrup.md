## Summary
Stirrup is a lightweight Python framework designed to simplify the creation of AI agents by providing a flexible, model-centric foundation with built-in best practices for context management, tool integration, and execution environments. It emphasizes minimal interference with model decision-making while offering modular components for rapid agent development.

## Key Features
- Model-agnostic agent loop with flexible LLM provider support (OpenAI-compatible, LiteLLM, custom clients)
- Built-in tools for code execution (local/Docker/E2B), web search/browsing, MCP client integration, and document handling
- Modular skills system for extending agent capabilities with domain-specific tools
- Automatic context management with conversation summarization to handle token limits
- Human-in-the-loop support for real-time user feedback and tool customization via Pydantic models

## Why It Matters for RAG Builders
Stirrup provides a lightweight yet powerful foundation for building production-grade AI agents with minimal boilerplate, enabling rapid iteration and customization while adhering to best practices for reliability and scalability.
