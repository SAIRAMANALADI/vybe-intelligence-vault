## Summary
OpenEcon Data provides AI agents with accurate, real-time economic data from 10+ official sources (FRED, World Bank, IMF, etc.) via a Model Context Protocol (MCP) server and web UI. It enables natural language queries for economic indicators without requiring manual API integration or code.

## Key Features
- 330K+ economic indicators from 10+ official sources with real-time updates
- Model Context Protocol (MCP) server for seamless AI agent integration
- Natural language query processing for plain English economic data requests
- Multi-country comparisons and conversational follow-ups for dynamic data exploration
- Self-hostable with optional cloud deployment and Pro Mode for advanced analysis
