## Summary
IsaacAgent is a specialized AI coding agent for The Binding of Isaac: Repentance Lua mod development, offering a Cursor/OpenCode-like desktop experience with Isaac-specific tools, knowledge bases, and workflows to streamline mod creation and debugging.

## Key Features
- Chat-driven mod development with streaming responses and tool-calling for file operations, scaffolding, and diagnostics
- Built-in Isaac API knowledge base (74 vanilla + 130+ REPENTOGON callbacks) and semantic search over 480+ embedded modding docs
- Multi-provider LLM support (OpenAI-compatible or Ollama) with encrypted credential storage and persistent chat history
- 16 specialized tools for file operations, XML validation, Lua diagnostics, and Isaac-specific API lookups
- Project-aware workflows with sandboxed file operations, live log monitoring, and visual diff viewers

## Why It Matters for RAG Builders
IsaacAgent provides a tailored AI-driven development environment for Isaac modders, reducing the complexity of mod creation and debugging with specialized tools and knowledge bases.
