## Summary
Pipe is a Semantic Pipeline Runtime (SPR) language designed for AI infrastructure, offering MCP-native server and client capabilities with a built-in Go-based interpreter. It simplifies AI pipeline development by treating AI operations like `summarize` or `translate` as language primitives, reducing boilerplate and enabling rapid deployment of AI workflows.

## Key Features
- MCP-native server and client with 7 builtins, enabling seamless integration with 100+ community MCP servers
- Pipeline-native syntax with sequential (`>`) and parallel (`>>`) operators for efficient AI workflows
- Lockdown AI agents with declarative sandbox profiles restricting file, network, and exec access
- Ship AI pipelines 10x faster with 43 built-in AI operations (summarize, translate, embed, etc.) and no SDK dependencies
- Deployable as a single ~7MB statically-linked binary across Linux, macOS, Windows, and browsers via WebAssembly

## Why It Matters for RAG Builders
Pipe eliminates vendor lock-in and boilerplate in AI pipelines by embedding MCP and AI primitives directly into a language, enabling RAG builders to deploy secure, parallelized, and vendor-agnostic workflows in seconds.
