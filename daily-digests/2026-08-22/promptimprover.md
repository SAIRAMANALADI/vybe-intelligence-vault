## Summary
Promptimprover is an MCP-first prompt governance system that intercepts, classifies, and refines raw engineering prompts using repository context and reinforcement learning before they reach an LLM. It ensures higher execution success by dynamically improving prompts based on past failures and contextual evidence.

## Key Features
- Universal MCP server for cross-CLI and editor-agnostic prompt refinement
- Intelligent governance layer that evaluates and refines prompts using repository context
- RAG-based retrieval with FlexSearch for injecting relevant codebase examples
- SQLite-backed persistent memory for storing prompt history and learned patterns
- Reinforcement Learning from AI Feedback (RLAIF) for dynamic prompt improvement

## Why It Matters for RAG Builders
It provides a critical governance layer for RAG systems by ensuring prompts are contextually optimized before reaching LLMs, reducing errors and improving reliability in AI-driven workflows.
