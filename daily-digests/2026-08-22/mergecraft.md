## Summary
mergeCraft is a standalone Bring-Your-Own-Key (BYOK) GitHub Action designed to automate AI-powered PR reviews directly within GitHub. It eliminates the need for proprietary SaaS accounts by leveraging user-provided credentials for AI providers like Claude, OpenAI, or Google Gemini.

## Key Features
- Standalone GitHub Action requiring no proprietary SaaS backend
- Supports multiple AI providers (Claude, OpenAI, Google Gemini, Cursor) with subscription or API key authentication
- Configurable via YAML for model selection, static checks, and fallback strategies
- Local scaffolding and authentication commands for seamless setup
- Enforces secure workflows with restricted shell and push permissions

## Why It Matters for RAG Builders
mergeCraft enables developers to integrate AI-driven PR reviews directly into GitHub without relying on third-party services, reducing costs and dependency on external platforms while maintaining full control over credentials and workflows.
