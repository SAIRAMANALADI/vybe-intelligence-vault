## Summary
Mixedbread is a Berlin-based AI search and retrieval platform offering embeddings, rerankers, multimodal stores, document parsing, structured extraction, and connector-based ingestion via a hosted REST API. It powers RAG and agent retrieval over text, PDFs, images, audio, and video across 100+ languages.

## Key Features
- High-performance embeddings (mxbai-embed, Wholembed v3) with Matryoshka dimensions and multi-encoding support
- Advanced reranking (mxbai-rerank v1/v2/v3-listwise) for improved retrieval relevance
- Multimodal stores supporting text, images, audio, and video with semantic search and Q&A
- Asynchronous document parsing and structured extraction with JSON Schema guidance
- Open weights models published on Hugging Face for transparency and customization

## Why It Matters for RAG Builders
Mixedbread provides essential components for building robust RAG pipelines, including embeddings, reranking, and multimodal retrieval, all accessible via a well-documented REST API.
