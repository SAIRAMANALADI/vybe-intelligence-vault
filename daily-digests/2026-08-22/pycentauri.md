## Summary
pycentauri is a local-network toolkit for controlling Elegoo Centauri Carbon 3D printers (CC1 and CC2 models) via Python, CLI, MCP server, REST/SSE HTTP server, web dashboard, and RTSP bridge. It enables direct LAN communication without cloud dependencies, supporting printer discovery, status monitoring, file management, and real-time control.

## Key Features
- Supports both Elegoo Centauri Carbon 1 (CC1) and 2 (CC2) models with auto-protocol detection
- Provides multiple interfaces: Python library, CLI, MCP server, HTTP REST/SSE server, web dashboard, and RTSP bridge
- Enables direct LAN communication without cloud dependencies or Elegoo servers
- Offers advanced features like file management, Canvas multi-filament support, and real-time status monitoring
- Includes a built-in web dashboard for mobile-friendly printer control and monitoring

## Why It Matters for RAG Builders
It provides essential local-network control and monitoring capabilities for Elegoo Centauri Carbon 3D printers, enabling AI agents and automation systems to integrate seamlessly with these devices without cloud dependencies.
