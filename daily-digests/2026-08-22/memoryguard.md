## Summary
MemoryGuard is a local-first governance layer for shared memory in coding agents, ensuring organized, reversible, and secure memory management. It prevents duplication, conflicts, and unsafe data exposure while preserving evidence and enabling rollback capabilities.

## Key Features
- Automatic organization and deduplication of agent memory writes
- Scoped rules for governance (Agent, project, provider, role targeting)
- Evidence preservation and rollback capabilities for memory states
- Quarantine of sensitive data (secrets, tokens) to prevent exposure
- Separation of governed memory and raw conversation history

## Why It Matters for RAG Builders
MemoryGuard ensures reliable, secure, and reversible memory management for AI agents, preventing context pollution and enabling trustworthy RAG applications.
