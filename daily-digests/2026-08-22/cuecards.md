## Summary
cuecards is a lightweight shim that dynamically scopes AI agent skills, MCPs, and personas per project directory, reducing token overhead and improving agent performance by loading only relevant tools for the task at hand.

## Key Features
- Per-directory profile resolution to load only relevant skills and MCPs
- 85+ pre-built profiles for common stacks (e.g., backend, frontend, Rust, Python)
- Zero telemetry and minimal resource footprint with cold start under 200ms
- Supports 10+ AI agents (Claude, Cursor, Cline, etc.) with unified profile configuration
- Built-in rigor with reviewer gates and confidence tags for quality control

## Why It Matters for RAG Builders
It drastically reduces token costs and improves AI agent performance by dynamically loading only the relevant skills and tools for each project, eliminating unnecessary overhead.
