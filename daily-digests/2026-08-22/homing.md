## Summary
Homing is a self-hosted gateway that translates terminal interactions into chat-based interfaces (e.g., Feishu or Telegram), enabling remote execution of AI-driven coding agents directly from messaging platforms. It prioritizes security, real-time visibility, and minimal typing overhead for users.

## Key Features
- Real-time process tracking via interactive chat cards (files read, commands executed, duration)
- Two-phase authorization for file modifications (plan review before execution)
- Multi-platform support (Feishu and Telegram with identical functionality)
- Zero third-party dependencies (pure Node.js built-ins)
- Automated setup and system service registration for seamless deployment

## Why It Matters for RAG Builders
Homing bridges the gap between AI-driven coding agents and user-friendly chat interfaces, enabling secure, real-time remote execution without exposing backend systems to external APIs.
