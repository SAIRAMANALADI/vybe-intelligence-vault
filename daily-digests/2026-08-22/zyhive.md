## Summary
ZyHive is an AI team operating system designed to manage multi-agent teams with role-based configurations, memory systems, and collaboration tools. It enables self-hosted deployment for individuals or small teams to orchestrate AI agents as team members with specialized skills and workflows.

## Key Features
- Multi-agent team management with role-based configurations (identity, soul, skills, and memory)
- Dynamic tool ecosystem with fine-grained permissions and real-time tool checks
- Four-layer memory system (core, projects, daily, topics) with semantic search and distillation
- Cross-channel messaging integration (Telegram, Feishu, Web, and in-app) with automatic contact profiling
- Cron-based task scheduling, goal planning with Gantt charts, and sub-agent dispatching

## Why It Matters for RAG Builders
ZyHive provides a structured framework for orchestrating and managing multiple AI agents as a cohesive team, which is critical for building scalable and collaborative RAG systems.
