## Summary
The Copilot Goal System extends GitHub Copilot CLI, MCP, and VS Code Copilot Chat with persistent goal management, lifecycle hooks, and proof-based completion gates. It ensures long-running tasks survive context loss, parallel sessions, and tool drift while enforcing evidence-backed validation before goal closure.

## Key Features
- Persistent goal state management across sessions and tools
- Proof-based completion gates requiring evidence for goal closure
- Lifecycle hooks for context restoration, drift blocking, and subagent isolation
- Integration with GitHub Copilot CLI, MCP, and VS Code Copilot Chat
- Automated state snapshots and recovery mechanisms

## Why It Matters for RAG Builders
It enables reliable, long-running AI agent workflows by enforcing structured goal persistence and validation, critical for production-grade RAG and agent systems.
