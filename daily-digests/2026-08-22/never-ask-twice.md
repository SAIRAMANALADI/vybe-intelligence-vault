## Summary
Never Ask Twice is an enterprise-grade support memory agent that retains customer context across sessions using structured memory tiers (working, episodic, semantic) with forgetting policies and deterministic evaluation. It leverages Qwen Cloud for embeddings and distillation, and exposes MCP tools for agent interoperability.

## Key Features
- Structured memory tiers (working, episodic, semantic) with provenance tracking
- Deterministic evaluation harness for measurable memory performance (re-ask rate, recall accuracy)
- Forgetting policies (TTL, supersession, budgeted recall) for audit-safe memory management
- MCP stdio surface exposing 4 memory tools for agent interoperability
- Dual deployment targets (Railway live, Alibaba FC ready) with Neon Postgres backend

## Why It Matters for RAG Builders
It provides a production-ready framework for building memory-augmented agents that retain and retrieve critical customer context across sessions, essential for RAG systems requiring persistent state and auditable memory.
