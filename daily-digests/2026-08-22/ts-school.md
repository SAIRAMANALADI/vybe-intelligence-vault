## Summary
A static TypeScript teaching site that compares idiomatic JavaScript with TypeScript fixes, using the Strada compiler API for diagnostics. It includes an optional on-device AI chat assistant powered by Gemma and supports deployment via GitHub Pages.

## Key Features
- Interactive TypeScript/JS comparison lessons with real-time compiler diagnostics
- Optional on-device AI chat assistant (Gemma) for personalized learning
- Static site generation with Vite-SSG for fast, pre-rendered content
- Strict security posture with CSP, no code execution, and local model caching
- OpenSpec-driven development for structured curriculum and workflow management

## Why It Matters for RAG Builders
It provides a structured, interactive way to learn TypeScript with real compiler feedback, making it valuable for AI engineers building educational tools or documentation systems.
