## Summary
An MCP server that exposes the ISO 20022 camt.053 bank statement library as tools for AI agents, enabling parsing, validation, and generation of reversing-entry XML documents for financial statements.

## Key Features
- Exposes 19+ MCP tools for parsing, validating, and reversing ISO 20022 camt.053 bank statements
- Supports CBPR+/HVPS+ readiness checks and rulebook citations for SEPA and cross-border payments
- Provides pagination for large datasets and error handling via JSON-serializable payloads
- Integrates with MCP clients (e.g., Claude Desktop, Cursor) for seamless AI agent workflows
- Part of a modular suite (camt053) with shared services for CLI, REST API, and LSP integration

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and process standardized bank statements, streamlining financial data integration and automation in RAG pipelines.
