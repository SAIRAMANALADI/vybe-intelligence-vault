## Summary
OpenPlan MCP Server is an MCP-based tool that enables AI agents to decompose goals into executable plans, track progress with cost tracking and deviation analysis, and learn from past project data via a local-first SQLite database and optional Mesh API sync.

## Key Features
- Goal decomposition into costed execution phases with estimates
- Checkpointing and deviation tracking for progress monitoring
- Session retrospectives with accuracy and learning insights
- Local-first SQLite database for persistent project data
- Optional Mesh API sync for cross-session cost learning

## Why It Matters for RAG Builders
It provides AI agents with structured planning, tracking, and learning capabilities essential for autonomous project execution and continuous improvement.
