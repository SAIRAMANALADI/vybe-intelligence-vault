## Summary
ryu-calendar is a UI component for visualizing and managing scheduled agent workflows and jobs within the Ryu ecosystem. It provides Month, Week, Day, and Agenda views to display past runs from history and upcoming runs from cron/interval schedules, along with a New Automation dialog for scheduling new jobs.

## Key Features
- Multi-view calendar (Month/Week/Day/Agenda) for scheduled runs and history
- New Automation dialog for scheduling agent jobs via cron/interval
- Integrated with Ryu's Core for schedule storage and run history
- Companion-only app with prebuilt single-file bundle for easy deployment
- Capability grant (`calendar:crud`) for secure bridge operations

## Why It Matters for RAG Builders
It provides a critical interface for visualizing and managing scheduled agent workflows, essential for RAG builders who need to track and schedule automated tasks.
