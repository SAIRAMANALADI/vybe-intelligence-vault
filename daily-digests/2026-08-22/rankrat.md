## Summary
Rankrat is a self-hosted MCP server that aggregates SEO and web performance data from multiple providers (Google, Bing, GA4, PageSpeed, etc.) into a unified API and toolset for agents. It enables read-only or bounded write operations for site audits, monitoring, and remediation with explicit credential scoping.

## Key Features
- Unified API for multi-provider SEO and performance data (Google Search Console, Bing, GA4, PageSpeed, etc.)
- Explicit read-only mode with optional bounded write capabilities for remediation
- MCP over stdio and Streamable HTTP for agent integration
- Persistent monitoring and issue tracking with resubmission workflows
- Docker-based deployment with configurable security boundaries

## Why It Matters for RAG Builders
Rankrat simplifies the integration of diverse SEO and web performance data sources into a single, self-hosted service, enabling AI agents to perform comprehensive site audits and remediation with explicit credential scoping.
