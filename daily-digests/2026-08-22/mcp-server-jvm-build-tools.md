## Summary
An MCP server providing a unified interface to execute and manage builds for JVM build tools (Maven, Gradle, SBT) through the Model Context Protocol (MCP). It enables AI agents to interact with build systems programmatically for compilation, testing, dependency analysis, and more.

## Key Features
- Unified API for Maven, Gradle, and SBT builds via a single MCP server
- Auto-detection of project build systems (pom.xml, build.gradle, build.sbt)
- 30 MCP tools for build execution, dependency checks, and project analysis
- Security hardening with shell injection protection and input validation
- Docker image pre-configured with JDK 21 and full build toolchain

## Why It Matters for RAG Builders
It enables AI agents to autonomously execute, debug, and optimize JVM builds, reducing manual intervention and accelerating CI/CD workflows.
