## Summary
Plancia is a local-first productivity tool that aggregates tasks, sessions, and project data from AI agents like Claude Code and Codex into a unified dashboard. It provides spoken daily recaps, a unified task board, and voice-controlled interactions to streamline AI-driven workflows without telemetry or external dependencies.

## Key Features
- Unified task board integrating Claude Code and Codex sessions
- Spoken daily recaps with actionable proposals based on real data
- Voice-controlled Jarvis panel for hands-free task management
- Local-first architecture with no telemetry or external servers
- Event logging system for real-time state synchronization

## Why It Matters for RAG Builders
Plancia bridges the gap between AI agent outputs and human workflows by unifying disparate task sources into a single, actionable interface.
