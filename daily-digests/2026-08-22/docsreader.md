## Summary
DocsReader is a native desktop application that provides a clean, interactive interface for reading and managing agent-managed markdown corpora. It enables AI agents to write to plain markdown files while users read and interact with the same files in a structured, user-friendly app across macOS, Linux, and Windows.

## Key Features
- Real-time synchronization with AI agents via MCP server, enabling live updates as agents write to markdown files
- Rich markdown rendering with GitHub-flavored Markdown, KaTeX math, Mermaid diagrams, and Shiki syntax highlighting
- Interactive task board with kanban-style drag-and-drop workflows and acceptance-criteria checklists
- Multi-platform support (macOS, Linux, Windows) with native installers and notarized releases
- Split-view editing, interactive checklists, and five distinct lenses (Tree, Recent, Tags, Pinned, Tasks)

## Why It Matters for RAG Builders
DocsReader bridges the gap between AI agent workflows and human-readable documentation by providing a native interface for managing agent-generated markdown content, ensuring seamless collaboration and transparency.
