## Summary
This repository provides a Termux-compatible, Bionic-libc build of the open-source AI coding agent opencode, enabling native execution on Android devices without requiring proot, chroot, or a Linux VM. It patches upstream dependencies to ensure compatibility with Android's Bionic linker and ships as a self-contained .deb package for one-command installation.

## Key Features
- Native Android execution via Termux without root or VMs
- Patched Bun runtime for Bionic libc compatibility
- Automated build pipeline with upstream version tracking
- Self-contained .deb package for one-command installation
- Supports Anthropic, OpenAI, and OpenAI-compatible LLM providers

## Why It Matters for RAG Builders
It enables AI coding agents like opencode to run natively on Android devices, expanding accessibility for mobile developers and users who need on-the-go coding assistance.
