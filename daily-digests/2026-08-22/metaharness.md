## Summary
MetaHarness is a CLI and framework factory that generates custom AI agent harnesses tailored to any repository, enabling users to create branded, repo-aware agents with MCP servers, memory, governance policies, and deployment-ready scaffolding for multiple agent hosts like Claude Code, OpenAI Codex, and GitHub Actions.

## Key Features
- Generates custom AI agent harnesses from any GitHub repository or blank slate in under 60 seconds
- Supports 9+ agent hosts (Claude Code, OpenAI Codex, GitHub Actions, etc.) with default-deny security policies
- Includes MCP server, memory namespace, governance policy, and witness-signed provenance by default
- Features Darwin Mode for self-improving harnesses and Weight-EFT for cost-efficient model tuning
- Allows publishing harnesses as branded npm packages for organizational use

## Why It Matters for RAG Builders
MetaHarness enables RAG builders to create highly optimized, repo-specific agent frameworks that reduce costs, improve performance, and ensure security while integrating seamlessly with existing AI stacks.
