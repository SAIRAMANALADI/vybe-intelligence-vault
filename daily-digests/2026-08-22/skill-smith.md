## Summary
skill-smith is a meta-skill orchestrator for creating high-quality Claude Code skills by enforcing a research-first, acceptance-gated workflow. It scaffolds skills to a strict spec, validates them against rigorous gates, and delegates iteration to specialized tools like market-intel and self-evolve.

## Key Features
- Research-first design via integration with market-intel for landscape and frontier analysis
- Deterministic scaffolding of skills to Skill-Repo-Spec v1 with 7 required files and badges
- Rigorous acceptance gate enforcing eval lift, trigger rate, token budget, dedup, security, and spec conformance
- Batch creation of multiple skills with global library-budget management
- Delegation to self-evolve for regression-gated improvement of accepted skills

## Why It Matters for RAG Builders
It ensures AI engineering teams can consistently generate production-grade skills by enforcing research-backed, validated, and iteratively improved workflows, reducing silent failures and improving reliability in RAG systems.
