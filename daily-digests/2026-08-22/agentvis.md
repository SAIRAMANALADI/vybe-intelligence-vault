## Summary
AgentVis is a local-first AI agent runtime platform for Windows that enables multi-agent collaboration, long-running task execution, and human-in-the-loop control with built-in visualization, memory, RAG, and sandboxed security. It operates entirely offline with no server deployment required.

## Key Features
- Master Brain and Sub-Agent collaboration with visual FSM runtime
- Five-layer security model with process/network sandboxing and command blocking
- Three-layer memory system supporting long-running task continuity
- Built-in RAG knowledge base with BM25, embeddings, and reranking support
- Human-in-the-loop intervention with natural language corrections and scheduled tasks

## Why It Matters for RAG Builders
AgentVis provides a secure, local-first environment for building and managing multi-agent systems with robust visualization and human oversight, critical for AI stack builders prioritizing privacy and control.
