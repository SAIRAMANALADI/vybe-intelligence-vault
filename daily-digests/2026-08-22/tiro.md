## Summary
Tiro is a local-first reading OS that saves web pages and email newsletters as clean markdown, enriches them with AI-extracted tags and summaries, and uses Claude Opus 4.6 for deep cross-document reasoning. It provides daily digests, trust analysis, and adaptive reading preferences while ensuring data ownership and security.

## Key Features
- Local-first data storage with markdown, SQLite, and ChromaDB for full data ownership
- AI enrichment with tags, entities, summaries, and cross-document reasoning using Claude Opus 4.6
- Security-hardened architecture with password auth, CSRF protection, XSS mitigation, and atomic data operations
- Multi-platform deployment options including desktop apps, Docker, CLI, and mobile PWA
- Automated ingestion from RSS/Atom feeds, email newsletters, and existing reading libraries like Readwise

## Why It Matters for RAG Builders
Tiro provides a secure, local-first infrastructure for RAG pipelines to ingest, enrich, and reason over documents while ensuring data privacy and ownership.
