## Summary
A Model Context Protocol (MCP) server that aggregates job listings from multiple job boards and company career sites, enabling AI clients like Claude Code to search and retrieve job postings programmatically.

## Key Features
- Aggregates job listings from 6+ platforms including LinkedIn, Google Careers, and TSMC
- Supports filtering by experience level and salary sorting for targeted searches
- Compatible with MCP clients like Claude Code, Codex, and Gemini CLI
- Lightweight installation via Homebrew, Go, Docker, or direct binary
- Respects site terms of service by using public endpoints without scraping

## Why It Matters for RAG Builders
It provides AI agents with real-time access to job listings across multiple platforms, enabling automated job search workflows and integration with AI-driven career tools.
