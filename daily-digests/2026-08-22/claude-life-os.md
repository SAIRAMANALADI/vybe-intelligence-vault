## Summary
A personal agent workspace for Claude Code that organizes a user's life into concentric circles (identity, work, domains, knowledge, systems, life, and archive) to enable an AI to navigate and respond as a personalized assistant rather than a generic developer tool.

## Key Features
- Concentric folder architecture for organizing personal life data (identity, decisions, people, projects, etc.)
- Two-gate system: navigation gate (CLAUDE.md) and answer gate (context_router.md) for context-aware AI responses
- Privacy-first design with on-demand memory loading and rejection tracking
- No coding required for setup; guided onboarding via interview process
- Optional power-ups for voice transcription, brain-dumping, and conversation memory

## Why It Matters for RAG Builders
It enables AI agents to navigate and respond to personal life contexts with precision, reducing generic advice and improving relevance through structured, user-specific organization.
