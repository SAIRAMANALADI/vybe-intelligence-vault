## Summary
A high-performance Model Context Protocol (MCP) server designed to enable AI agents to discover and search local content repositories. It provides full-text search, dynamic resource discovery, and dual transport support (stdio/SSE) for seamless integration with AI workflows.

## Key Features
- Full-text search with stemming, fuzzy matching, and configurable boosting via Bleve
- Dynamic resource and prompt discovery from local content directories
- Dual transport support (stdio for local agents, SSE for remote/Docker deployments)
- Optional authentication (basic auth or API key) for secure access
- Cross-platform compatibility (Linux, macOS, Windows)

## Why It Matters for RAG Builders
It bridges the gap between AI agents and team-specific knowledge repositories, enabling context-aware RAG systems to access and search custom content efficiently.
