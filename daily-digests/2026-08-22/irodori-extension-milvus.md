## Summary
A native Irodori Table connector extension for Milvus, providing metadata, ABI exports, and driver implementation to enable vector database integration within the Irodori extension marketplace. It facilitates Milvus-specific operations like similarity search, filtered ANN search, and collection health checks.

## Key Features
- Native Milvus connector for Irodori Table with direct ABI integration
- Supports multiple authentication methods (API key, bearer token, mTLS, etc.)
- Enables vector similarity search, filtered ANN search, and collection health monitoring
- Provides structured metadata and query results via native ABI calls
- Cross-platform release packaging with platform-specific native artifacts

## Why It Matters for RAG Builders
This extension enables seamless integration of Milvus as a vector database backend for RAG pipelines, providing standardized connectors and query capabilities essential for AI stack builders.
