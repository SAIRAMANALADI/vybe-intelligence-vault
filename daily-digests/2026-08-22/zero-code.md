## Summary
Zero-code is a desktop application that enables users to build software applications through natural language descriptions and visual workflows without manual coding. It leverages AI agents and automated code generation to handle task planning, workflow orchestration, and project management locally.

## Key Features
- AI-powered task planning and workflow design from natural language inputs
- Automated code generation with adherence to standard practices
- Visual project tracking with real-time progress updates
- Local execution with a built-in database for project storage
- Specialized AI agents for managing file storage, database updates, and logic
