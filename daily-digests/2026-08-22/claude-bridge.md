## Summary
claude-bridge is a VS Code plugin and CLI tool that enables multi-chat orchestration for Claude Code sessions, allowing persistent chats to communicate, share context, and search across each other's transcripts via local filesystem-based messaging and metadata tools.

## Key Features
- Peer-to-peer messaging between Claude Code chats with reliable inbox delivery
- Cross-session search and read capabilities across all project chats
- Real-time context usage monitoring and autocompact risk alerts
- Bundled role playbooks for manager and memory-keeper agents
- Local filesystem-based communication with zero API keys or network dependencies

## Why It Matters for RAG Builders
It enables persistent, queryable multi-agent workflows in Claude Code, reducing context loss and enabling seamless collaboration between agents and humans within a single VS Code environment.
