## Summary
DataStoria is an AI-native console for ClickHouse that enables natural language data exploration, smart query optimization, and intelligent visualization. It integrates with multiple LLM providers and provides a privacy-focused, browser-based interface for cluster diagnostics and management.

## Key Features
- Natural language to SQL generation with AI optimization
- Intelligent visualization with chart spec generation
- Multi-cluster monitoring and management with real-time metrics
- Agent-based architecture supporting multiple LLM providers
- 100% local execution with no data collection

## Why It Matters for RAG Builders
DataStoria streamlines ClickHouse workflows by combining AI-driven query generation, optimization, and visualization in a single privacy-focused tool, making it essential for RAG builders managing complex data pipelines.
