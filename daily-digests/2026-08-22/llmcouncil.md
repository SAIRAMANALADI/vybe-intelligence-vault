## Summary
llmcouncil is a Windows-based tool that enables multi-LLM collaboration by allowing multiple AI models (e.g., GPT-5, Gemini 2.5, Claude) to debate, critique, vote, and synthesize answers for improved reliability and depth. It integrates with Claude Code and MCP setups for workflow automation.

## Key Features
- Multi-model collaboration with voting, debate, and critique mechanisms
- Integration with Claude Code and MCP for workflow automation
- Structured multi-agent review (MAV protocols) for improved answer quality
- Windows-native tool with simple setup and configuration
- Supports API-based LLMs (GPT, Gemini, Claude) for parallel processing
