## Summary
Audit_User_Agent is an automated multi-agent system that audits and critiques social media content across YouTube, Instagram, and blogs. It uses three sequential agents (scout, measure, reviewer) to identify opportunities, collect metrics, and evaluate content quality, all orchestrated via GitHub Actions.

## Key Features
- Three-agent pipeline (scout, measure, reviewer) for content lifecycle management
- Automated issue reporting with per-repo detail and digest summaries
- Multi-channel metrics collection (YouTube, Instagram, blogs)
- Customizable rubrics for content evaluation (e.g., editorial quality, growth metrics)
- Graceful degradation for missing or unavailable data sources

## Why It Matters for RAG Builders
It provides an automated, evidence-based system to audit and improve content performance across multiple platforms, reducing manual review effort and enabling data-driven content strategy.
