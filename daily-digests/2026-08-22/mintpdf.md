## Summary
MintPDF is a REST API and MCP server that converts HTML or Markdown to clean, styled PDFs without requiring templates, dashboards, or signups. It supports both direct API calls and MCP client integration for seamless document generation in AI workflows.

## Key Features
- Converts HTML or Markdown to PDF with default styling for tables, code blocks, and headings
- Offers both REST API and MCP server for integration with AI agents and clients
- No templates or dashboards required; supports direct document generation from code or agents
- Auto-deletes generated files after one hour with no document storage or account needed
- Supports customization of page format, margins, headers, footers, and page numbers

## Why It Matters for RAG Builders
MintPDF streamlines the conversion of agent-generated Markdown or HTML into polished PDFs, eliminating the need for manual formatting or template management in RAG and AI workflows.
