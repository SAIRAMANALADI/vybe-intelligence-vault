## Summary
kubewhy is an air-gapped Kubernetes root-cause analysis tool that uses a local LLM to diagnose why Kubernetes resources are failing, providing detailed explanations by reading logs, events, and resource limits without sending data to external APIs. It offers multiple interfaces including CLI, REST API, MCP server, browser UI, and a controller for automated failure detection.

## Key Features
- Read-only Kubernetes diagnostics with no external API dependencies
- Multi-interface support (CLI, REST API, MCP server, browser UI, controller)
- Automated failure detection and root-cause analysis without manual prompts
- Token-efficient tool projections to avoid context window limits
- Verified claims and confidence reporting in diagnostics

## Why It Matters for RAG Builders
kubewhy enables RAG builders to integrate automated, air-gapped Kubernetes diagnostics into their systems, ensuring reliable and secure failure analysis without exposing sensitive cluster data to external services.
