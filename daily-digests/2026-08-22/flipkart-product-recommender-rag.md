## Summary
A product recommendation system leveraging RAG architecture to provide personalized shopping suggestions using Groq LLaMA-3, LangChain, and AstraDB vector search. The system is designed for scalability with containerized deployment via Docker and Kubernetes.

## Key Features
- Personalized product recommendations using RAG architecture
- Integration with Groq LLaMA-3 for advanced AI-driven suggestions
- Containerized deployment with Docker and Kubernetes for scalability
- Support for HuggingFace embeddings and AstraDB vector search
- Monitoring tools (Prometheus and Grafana) for performance tracking
