## Summary
A VS Code extension that integrates a voice-first AI code assistant powered by Google's Gemini Live API, enabling real-time conversational interactions with code context, workspace search, and rich attachments for enhanced developer productivity.

## Key Features
- Real-time voice interaction with Gemini Live API, including streaming audio input/output
- Automatic capture of selected code and surrounding context for AI analysis
- In-memory workspace search and file reading for contextual responses
- Rich attachments (files, images) and code actions (copy/apply) for seamless workflow integration
- Local chat history with transcript restoration and secure API key storage

## Why It Matters for RAG Builders
It bridges the gap between AI-powered code assistance and real-time developer workflows by enabling natural voice interactions with full code context, reducing context-switching and accelerating problem-solving.
