## Summary
A multi-platform AI-powered travel planning system that generates personalized itineraries, manages bookings, and integrates with external services like weather and mapping APIs. It supports user-facing apps (web, WeChat mini-program), an admin dashboard, and a backend AI agent using LangGraph for structured travel planning.

## Key Features
- Multi-platform support (web, WeChat mini-program, admin dashboard)
- AI-driven travel itinerary generation with structured output
- Integration with external APIs for weather, mapping, and route planning
- Real-time budget and time validation for itineraries
- Admin dashboard for managing users, trips, bookings, and AI agent logs
