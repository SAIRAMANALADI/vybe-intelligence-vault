## Summary
Codemaster-AI is a privacy-first, terminal-driven local AI coding engine that indexes entire repositories and performs development tasks locally using Ollama. It combines hybrid retrieval (dense vectors + BM25) with agent-based workflows to generate, review, and explain code without external server dependencies.

## Key Features
- Local LLM orchestration via Ollama for 100% code privacy
- Hybrid retrieval combining dense vectors (all-MiniLM-L6-v2) and BM25 for accurate context
- Agent-driven workflows (Generator, Reviewer, Explainer) for verified code generation
- Patch-based fixes with provenance checks and `.patch` file output for safe application
- Interactive TUI and CLI tools (ai-generate, ai-fix) for seamless terminal integration

## Why It Matters for RAG Builders
Codemaster-AI enables RAG/AI stack builders to deploy a privacy-preserving, local-first agent framework that integrates hybrid retrieval and verified generation for secure, context-aware coding assistance.
