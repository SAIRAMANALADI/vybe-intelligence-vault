## Summary
A portable Agent Plugins package for Mailtea that provides AI agents with skills and an MCP server to send, schedule, and manage emails, newsletters, and publication websites. It enables AI clients to interact with Mailtea's control plane for transactional email, audience management, automations, and infrastructure tasks.

## Key Features
- Portable Agent Plugins package with MCP server for AI agent integration
- Supports transactional email, newsletters, and scheduling via standardized tools
- Provides structured email design and publication website building skills
- Enables audience management, automations, and infrastructure control
- Client-managed authentication with secure token injection
