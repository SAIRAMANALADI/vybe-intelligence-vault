## Summary
Gamachine is a desktop application that unifies multiple AI coding agents (Claude Code, Codex, Antigravity, etc.) and live Unity Editor control into a single interface with a unified approval system. It enables developers to interact with AI tools, edit code, run terminals, and control Unity scenes from one window.

## Key Features
- Unified interface for 7+ AI agents and cloud APIs with identical user experience
- Live Unity Editor control via MCP with 46+ tools (scene management, input simulation, etc.)
- Project-aware RAG system for C# code analysis and architecture mapping
- Embedded OmniSharp LSP for real-time C# diagnostics and IntelliSense without external dependencies
- Secure approval gate system for file operations, terminal commands, and Unity mutations

## Why It Matters for RAG Builders
It streamlines AI-driven Unity development by consolidating disparate tools into a single, secure, and project-aware environment, reducing setup friction and improving developer productivity.
