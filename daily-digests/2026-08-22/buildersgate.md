## Summary
Builders Gate is an MCP server designed to facilitate multi-agent collaboration for game development using Claude Code. It provides a centralized SQLite-based project database, role-specific agent tools, and a local dashboard for managing game development workflows.

## Key Features
- Centralized SQLite project database for state management across agents
- Role-specific agent tools (art, gameplay, narrative, QA, audio, tech)
- Local dashboard for real-time monitoring and work dispatch
- Godot and Blender adapters for game engine integration
- Enforced scope tiers, asset locks, and spend ceilings to prevent conflicts
