## Summary
A Telegram bot agent built with Haystack for tool-calling, Pinecone for long-term memory, and OpenAI for chat/vision/embeddings. It enables personalized, context-aware conversations with features like weather lookup, cat facts, dog image analysis, and user photo interpretation.

## Key Features
- Tool-calling agent with configurable system prompts and companion tools (cat facts, dog images, weather)
- Long-term memory via Pinecone with per-user isolation using namespaces and user_id filtering
- Short-term dialogue context stored in RAM for follow-up queries like 'yes' or 'show me'
- OpenAI-compatible proxy support for flexible API integrations
- User photo analysis with vision capabilities for breed identification
