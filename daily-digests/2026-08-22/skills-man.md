## Summary
skills-man is a Rust-based CLI tool designed to install, manage, and synchronize AI agent skills from GitHub repositories. It organizes skills locally or globally, tracks installations via a TOML file, and supports sharing skills across multiple agent CLIs.

## Key Features
- Install and manage AI agent skills from GitHub repositories with version control
- Support for local and global skill directories with configurable modes
- Synchronization and update capabilities with checksum-based change detection
- Environment variable management for secure GitHub API access
- Symlink-based sharing of skills across multiple agent CLIs

## Why It Matters for RAG Builders
It streamlines the distribution and synchronization of AI agent skills, reducing setup friction and ensuring consistency across teams and tools.
