## Summary
A workspace designed for building agentic AI systems in quantitative finance, currently focused on market data management, chart visualization, and a declarative computation graph foundation. It provides a backend API, frontend UI, and MCP server for external agent integration.

## Key Features
- Declarative GraphSpec runtime for indicators and strategies
- MCP server for external agent integration (Claude, Cursor, etc.)
- Hive-partitioned Parquet warehouse for market data storage
- Next.js frontend with dynamic chart visualization and data management
- Axum-based HTTP API for catalogs, jobs, and studio runs

## Why It Matters for RAG Builders
It provides a foundational platform for agentic AI in quantitative finance with MCP integration, enabling external agents to drive market research and strategy development.
