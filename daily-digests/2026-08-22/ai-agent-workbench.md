## Summary
A self-hosted web console (FastAPI + PWA) for remotely controlling AI coding agents (Codex CLI/Kimi CLI) from a mobile browser. Features PIN-gated approval workflows, bubblewrap sandboxing, multi-layered security, and audit logging.

## Key Features
- Dual-agent backend supporting Codex CLI and Kimi CLI with task-level switching
- PWA-enabled mobile interface for remote task management and file operations
- PIN-gated approval workflow for high-risk operations with full audit logging
- Bubblewrap sandboxing for secure AI agent execution with strict path whitelisting
- Two-stage release pipeline with smoke-test rollback and automated monitoring

## Why It Matters for RAG Builders
It provides a secure, self-hosted orchestration layer for managing AI coding agents remotely, emphasizing sandboxing, approval workflows, and auditability—critical for production-grade RAG and AI agent deployments.
