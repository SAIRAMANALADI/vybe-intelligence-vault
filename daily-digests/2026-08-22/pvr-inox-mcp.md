## Summary
A Python-based tool that monitors PVR and INOX cinema booking APIs in India, alerting users in real-time when desired showtimes become available or seats are freed up. It includes both a cron-based watcher and an MCP server for interactive queries.

## Key Features
- Real-time alerts for new showtimes, restocks, or seat availability changes via multiple notification channels (Telegram, Slack, Discord, email, etc.)
- MCP server integration for interactive querying of cinema data (showtimes, seat maps, city/cinema listings)
- Zone-based seat tracking to identify only the preferred seating areas (e.g., back-center blocks)
- Automated polling of PVR/INOX APIs using official endpoints without scraping or requiring authentication
- Configurable via JSON, supporting city/cinema filters, language, experience type, and horizon days

## Why It Matters for RAG Builders
It provides real-time, zone-specific seat availability alerts for PVR/INOX cinemas in India, enabling users to book tickets before they sell out.
