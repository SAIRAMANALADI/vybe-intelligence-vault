## Summary
Org AI Force is an enterprise-grade Angular 21 and NestJS prototype for an AI agent workspace, featuring admin governance, RAG-ready services, MCP-style integrations, and deterministic resilience testing. It demonstrates a structured approach to internal AI agent deployment with policy-driven execution and failure scenario handling.

## Key Features
- Policy-driven agent execution with frontend/backend separation of concerns
- Deterministic resilience lab for testing degraded dependency scenarios
- MCP-style tool integrations and Playwright browser workers
- Admin-governed tool registry and approval workflows
- Comprehensive documentation and demo surfaces for reviewer evaluation
