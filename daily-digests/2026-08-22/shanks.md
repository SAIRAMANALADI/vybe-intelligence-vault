## Summary
Shanks is a LangGraph-based workflow framework for executing Ralph-style agent tasks, transforming task plans into repeatable, fault-tolerant workflows that include planning, building, critiquing, validation, and deployment. It supports preflight checks, checkpointing, and interactive resumption for iterative development.

## Key Features
- LangGraph-based workflow execution with fault tolerance and checkpointing
- Preflight checks for environment validation before task execution
- Interactive resumption and approval workflows for human-in-the-loop tasks
- Built-in safety budgets (time, attempts, tokens, cost) with configurable limits
- Mermaid viewer for visualizing workflows and recovery paths

## Why It Matters for RAG Builders
Shanks provides a robust framework for orchestrating multi-agent workflows with checkpointing and safety controls, making it essential for building reliable RAG pipelines that require iterative planning, validation, and human approval.
