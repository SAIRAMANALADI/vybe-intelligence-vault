## Summary
Caliban is a Rust-based agent harness that provides operator-controlled model routing, memory management, skills, and prompt context for building AI agents. It supports multiple providers (Anthropic, OpenAI, Google, Ollama) and offers persistent sessions, TUI, sandboxing, and declarative routing.

## Key Features
- Provider-agnostic model routing with support for Anthropic, OpenAI, Google, and local Ollama
- Persistent sessions, checkpoints, and auto-memory with local-first data sovereignty
- Interactive TUI and headless modes with structured JSON output
- Declarative settings layering, permissions, and hooks for fine-grained control
- Built-in tools (Read, Write, Edit, Bash, WebSearch, etc.) and sub-agent support

## Why It Matters for RAG Builders
Caliban provides a robust, operator-controlled foundation for building and deploying AI agents with multi-provider support, sandboxing, and persistent memory, making it essential for RAG builders seeking flexibility and control.
