## Summary
discord-mcp is a local, typed Model Context Protocol (MCP) server that connects AI clients to Discord, providing 192 tools for messages, moderation, members, channels, and more. It enables AI agents to interact with Discord securely and reliably with safety controls and observability features.

## Key Features
- 192 typed tools for Discord operations (messages, moderation, members, channels, etc.)
- Safety controls with explicit confirmation for destructive operations
- Reliable Discord access with retries, rate-limit handling, and circuit breaking
- OpenTelemetry traces, metrics, and structured logs for observability
- Migration adapters for existing Discord MCP setups

## Why It Matters for RAG Builders
It enables AI agents to securely and reliably interact with Discord through a standardized MCP interface, expanding their operational capabilities in community management and real-time communication.
