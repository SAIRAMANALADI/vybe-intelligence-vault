## Summary
SkillDepot is an open marketplace for AI Agent skills tailored for cross-border e-commerce sellers and developers. It enables users to discover, share, and download pre-built AI skills for platforms like Alibaba International, Amazon, Shopify, and WordPress, with one-click integration into workflows.

## Key Features
- Open marketplace for discovering and sharing AI Agent skills with metadata (SKILL.md) for easy integration
- Pre-built skills for major e-commerce platforms (Alibaba, Amazon, Shopify, WordPress)
- Personalized ranking and scoring system for skills based on downloads, likes, and contributions
- One-click deployment using Docker Compose for local and production environments
- Support for JWT, WeChat login, and email verification for user authentication
