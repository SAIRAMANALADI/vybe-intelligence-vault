## Summary
Codexa is a local-first governance layer for AI coding agents that provides edit-lifecycle oversight, including plan conformance, drift review, and verification crediting. It builds deterministic codebase maps to track file changes, symbol impacts, and test coverage, ensuring agents adhere to planned edits and report verifiable outcomes.

## Key Features
- Drift loop with rename-aware pre-edit and post-edit reviews to detect unintended changes
- Verification ledger that validates reported commands against a faithful POSIX-shell subset to prevent exit-masking
- Graph-aware relational packets for bounded process and functional module clusters
- Fail-closed evaluation harness that ensures raw baselines do not outperform Codexa's outputs
- Local-first, zero API keys, and model-agnostic architecture for seamless integration with any MCP host

## Why It Matters for RAG Builders
Codexa provides critical oversight for RAG/AI stack builders by ensuring AI coding agents adhere to planned edits, detect drift, and verify reported outcomes, reducing risks of unintended changes and unverified claims in automated workflows.
