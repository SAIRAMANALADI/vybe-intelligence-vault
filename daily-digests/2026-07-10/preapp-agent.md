## Summary
PreApp Agent provides a CLI and integration layer for sharing AI-generated work (e.g., reports, HTML slides) with stakeholders, collecting feedback, and feeding it back into agent workflows. It bridges the gap between agent outputs and human review processes.

## Key Features
- Publish AI-generated artifacts (HTML, directories, zips) with stable versioned links
- Collect human feedback via shareable links with precise locators (text/image targeting)
- Convert feedback into structured Agent Fix Briefs (Markdown/JSON) for agent consumption
- Two-stage feedback gate ensuring human validation before agent edits
- Multi-agent support (Claude Code, Codex, OpenClaw, Hermes) with skill recipes

## Why It Matters for RAG Builders
PreApp Agent closes the critical gap between AI-generated outputs and human review by enabling seamless feedback integration into agent workflows, ensuring continuous improvement of AI deliverables.
