## Summary
SiPer Agent is a standalone AI agent framework featuring stateful UI, multi-model support, multi-agent systems, and 27 built-in tools. It operates with a backend-driven DOM snapshot architecture, enabling real-time updates via WebSocket and HTTP, while maintaining full independence from frameworks like LangChain or AutoGPT.

## Key Features
- Backend-driven DOM snapshot architecture with delta updates for real-time UI rendering
- Multi-model LLM support with OpenAI-compatible providers and model validation
- 27 built-in tools including file operations, code execution, web search, and vision analysis
- Multi-agent system with isolated sessions, memory, and configurations per agent
- Cross-platform support (Windows, Linux, macOS) with dynamic port allocation and service management scripts

## Why It Matters for RAG Builders
SiPer Agent provides a lightweight, framework-agnostic foundation for building modular AI agents with stateful UIs and multi-model capabilities, reducing dependency overhead while enabling rapid prototyping and deployment.
