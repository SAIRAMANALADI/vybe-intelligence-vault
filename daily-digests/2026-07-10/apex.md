## Summary
Apex is a self-hosted AI platform that provides multi-model chat, persistent memory, and an extensible skills engine in a single Python file. It enables secure, zero-data-leakage AI interactions with support for Claude, Grok, Codex, and local models like Ollama.

## Key Features
- Multi-model routing with support for Claude, Grok, Codex, and local models (Ollama/MLX)
- Persistent memory system with semantic search and whisper injection for automatic context recall
- Extensible skills engine allowing custom slash commands via markdown files
- Production-grade security with mTLS, TLS, atomic writes, and secrets isolation
- Admin dashboard with health monitoring, credential management, and session control

## Why It Matters for RAG Builders
Apex provides a unified, self-hosted platform for orchestrating multiple AI models with persistent memory and security, making it essential for building scalable, secure, and customizable RAG systems.
