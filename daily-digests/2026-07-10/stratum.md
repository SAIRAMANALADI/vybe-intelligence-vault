## Summary
Stratum is a state machine dispatch server and Python library for governing AI agent workflows with typed contracts, postconditions, and auditable execution traces. It enables structured, portable, and retry-safe workflows for AI coding agents like Claude Code and Codex.

## Key Features
- Typed YAML specs for workflow definitions with versioning and contracts
- Postcondition enforcement and structured failure context for retries
- Human-in-the-loop gates with approval/revise/kill routing
- MCP server integration for Claude Code and Codex agents
- Python library for building production LLM systems with decorators
