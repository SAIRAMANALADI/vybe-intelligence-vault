## Summary
WhipDesk enables remote control of a desktop machine from any mobile browser, allowing users to interact with AI coding agents and tools without installing additional apps. It leverages peer-to-peer WebRTC for secure, low-latency screen sharing and input control.

## Key Features
- Live screen streaming optimized for mobile data with viewport cropping and adaptive bitrate
- AI-agent monitoring with auto-notifications for job completion or failures
- Full input control (mouse, touch, keyboard) for interacting with AI tools and CLIs
- LashStash for recording and replaying multi-step automations
- Private by design with DTLS encryption, PIN challenges, and brute-force protection

## Why It Matters for RAG Builders
