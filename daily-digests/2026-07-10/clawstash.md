## Summary
ClawStash provides persistent storage for AI agents, enabling them to save, organize, and retrieve text, code, configs, and files across sessions via MCP or REST API. It includes features like full-text search, version history, GitHub backup, and a web GUI for manual management.

## Key Features
- Persistent storage for AI agents with session-spanning recall
- Full-text search and structured metadata/tagging for efficient retrieval
- MCP and REST API support for seamless agent integration
- Version history and diffable changes for content tracking
- GitHub backup and Mermaid diagram rendering for enhanced usability
