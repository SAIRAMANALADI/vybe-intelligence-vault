## Summary
Cortex is a persistent, neuroscience-inspired memory engine for AI agents like Claude Code, enabling local-first storage and retrieval of contextual knowledge with intelligent forgetting and consolidation mechanisms. It operates entirely on-device using SQLite or PostgreSQL with pgvector for scalable vector search.
