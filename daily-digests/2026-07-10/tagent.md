## Summary
TAgent is a production-grade Java-based AI Agent engineering framework built on Spring Boot and Spring AI. It provides a complete lifecycle for AI agent requests, including routing, runtime assembly, planning, execution, RAG, memory management, MCP tool governance, human-in-the-loop approvals, and streaming SSE outputs with full observability.

## Key Features
- Three execution modes: Fixed, Auto, and Flow with DAG orchestration
- Dynamic MCP tool supplementation via semantic matching and request-time tool calls
- Four-layer memory system (Working, Chat, Long-Term, Episodic) with semantic retrieval
- Agentic RAG with four query strategies (SIMPLE, HYDE, FUSION, DECOMPOSE)
- Full lifecycle observability with Prometheus, Jaeger, ELK, and custom event logging

## Why It Matters for RAG Builders
TAgent provides a comprehensive, production-ready Java framework for building and deploying AI agents with advanced capabilities like dynamic tool governance, agentic RAG, and full observability, making it essential for enterprise-grade AI engineering stacks.
