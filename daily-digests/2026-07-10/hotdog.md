## Summary
hotdog is a lightweight, zero-dependency AI agent framework designed for tool calling and extensibility. It connects to any OpenAI-compatible LLM API, manages conversation context, and executes tools through a hook-driven architecture, prioritizing simplicity and minimal setup.

## Key Features
- Zero-dependency architecture with Bun runtime for instant setup
- Extensible hook-driven system for adding tools, CLI commands, and behaviors
- Support for tool calling (file ops, bash, HTTP, web search, MCP, etc.)
- Profiles for composable agent configurations with roles and behavioral aspects
- Automatic context compaction, streaming responses, and retry logic for robustness

## Why It Matters for RAG Builders
It simplifies building and deploying AI agents with tool-calling capabilities, reducing setup friction while maintaining extensibility for RAG and AI workflows.
