## Summary
A pre-configured Docker container for AI agent development, bundling popular AI coding tools like Claude Code, Codex, and RTK with a shell launcher for seamless integration and persistent state management across sessions.

## Key Features
- Pre-installed AI coding tools (Claude Code, Codex, RTK) for immediate productivity
- Persistent container state under `~/.agent-stack` for auth and settings separation from host
- Shell launcher (`agent`) with support for Docker socket mounting and SSH agent forwarding
- Cross-platform compatibility with macOS and Colima Docker backend
- Built-in support for TCP bridges, environment variable injection, and custom shell plugins

## Why It Matters for RAG Builders
It provides a turnkey environment for AI agent builders to rapidly prototype and deploy multi-tool workflows with persistent state and seamless host integration.
