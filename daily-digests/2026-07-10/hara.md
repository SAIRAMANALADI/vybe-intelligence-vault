## Summary
hara is a coding agent CLI that operates as a configurable, governed organization of role-agents, enabling task decomposition, parallel execution, and multi-platform chat integration with persistent memory and self-evolution capabilities.

## Key Features
- Role-based agent organization with task routing and ownership boundaries
- Plan DAG execution with parallel atom processing and verification gates
- Multi-platform chat gateway (10+ platforms) with two-way image/file support
- Persistent memory system with lexical-first design and self-evolution via playbooks
- Multi-provider support with live streaming, reasoning visibility, and sandboxed execution

## Why It Matters for RAG Builders
It provides a governed, scalable framework for AI-driven coding tasks with role specialization, memory persistence, and multi-platform integration, essential for building robust RAG systems that require structured agent collaboration.
