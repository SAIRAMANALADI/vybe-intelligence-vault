## Summary
Myelin is a procedural memory system for AI agents that automatically learns reusable workflows from repeated actions, enabling knowledge transfer across agents via MCP. It observes agent behavior, clusters action sequences, and promotes recurring patterns into executable procedures with Bayesian confidence tracking.

## Key Features
- Automated procedure learning from repeated agent actions with confidence tracking
- Knowledge graph construction from observations with temporal state tracking
- Multi-signal context assembly for agents (episodic, semantic, procedural, entity, temporal)
- Cross-agent knowledge transfer via capability-aware procedure adaptation
- Cognitive processes for memory consolidation, reflection, and decay

## Why It Matters for RAG Builders
Myelin eliminates redundant agent workflows by learning and reusing proven procedures, significantly improving efficiency and consistency in multi-agent systems.
