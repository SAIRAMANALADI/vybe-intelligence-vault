## Summary
A Model Context Protocol (MCP) server that provides real-time access to 277 official Saudi economic datasets from GASTAT/DataSaudi, enabling AI clients like Claude or Cursor to answer questions in plain English or Arabic without requiring API keys or dataset knowledge.

## Key Features
- Provides live access to 277 curated GASTAT datasets via a keyless API
- Supports natural language queries in both English and Arabic
- Integrates seamlessly with AI clients like Claude and Cursor
- Includes three MCP tools: list_cubes, describe_cube, and query_cube
- Honest data completeness reporting with no silent failures or misrepresentations

## Why It Matters for RAG Builders
It enables AI agents to fetch and reason over real-time Saudi economic data without requiring manual dataset discovery or API key management, bridging a critical gap for RAG systems targeting regional economic insights.
