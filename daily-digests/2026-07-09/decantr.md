## Summary
Decantr is an AI frontend governance layer that provides typed contracts, route-scoped context, and machine-actionable evidence for AI-edited frontend codebases. It ensures UI changes remain coherent and aligned with product intent by defining governance contracts, verifying implementations, and offering local evidence for repair and CI/CD workflows.

## Key Features
- Typed contracts for frontend governance (DNA and Blueprint layers) to enforce visual and system axioms
- Route-scoped context and authority blocks for AI assistants to ensure coherent UI changes
- Local evidence generation and verification loops for CI/CD and repair workflows
- MCP server integration for direct AI tooling interaction and governance enforcement
- Hybrid adoption paths for brownfield, greenfield, and contract-only workflows

## Why It Matters for RAG Builders
