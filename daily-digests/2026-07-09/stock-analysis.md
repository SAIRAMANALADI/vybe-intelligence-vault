## Summary
A CLI tool that generates deterministic, evidence-driven stock market analysis reports and machine-readable JSON evidence packs for AI agents, quant researchers, and investors. It supports A/HK/US stocks, funds, and portfolios with multi-source data fallback and data-quality scoring.

## Key Features
- Deterministic CLI for repeatable market recaps without black-box signals
- Generates both human-readable Markdown reports and machine-readable JSON evidence packs
- Supports A/HK/US stocks, funds, and portfolios with investor lenses (Buffett, Munger, Simons, etc.)
- Multi-source data fallback with explicit source metadata and quality scoring
- Agent-friendly design with stable command surface for automation and tool-calling workflows
