## Summary
Cloche is an agent-neutral desktop capture tool that generates polished, share-ready frames from screenshots or screen recordings, with stable JSON output for AI agents and CLI tools. It supports region/window/screen capture, optional MCP server integration, and presentation styling for READMEs and social media.

## Key Features
- Agent-neutral CLI for capturing desktop frames (window, region, screen, or active app)
- Stable JSON output for programmatic consumption by shells, hotkeys, and AI agents
- Polished presentation cards with gradients, shadows, and rounded corners for shareable outputs
- Optional MCP server for direct integration with coding agents (Claude Code, Codex, OpenClaw)
- Hotkey workflow for rapid region capture and clipboard-ready polished frames

## Why It Matters for RAG Builders
Cloche bridges the gap between raw desktop capture and AI agent workflows by providing stable, polished outputs and JSON metadata, enabling seamless integration with RAG pipelines and agentic systems.
