## Summary
The Smarter Weather Developer Platform repository provides SDKs, documentation, and integration tools for interacting with the Smarter Weather REST API and hosted MCP servers. It includes client libraries, agent skills, and an OpenAPI specification for developers building AI-driven weather applications.

## Key Features
- Hosted MCP server bridges for weather data and onboarding via `@smarterweather/mcp-weather` and `@smarterweather/mcp-onboarding`
- OpenAPI specification for the Smarter Weather REST API at `api.smarterweather.com`
- TypeScript and Python SDKs with examples and cookbooks for rapid integration
- Agent skills for AI coding assistants (Cursor, Claude) to automate weather API usage
- Developer dashboard for account management, API key provisioning, and billing
