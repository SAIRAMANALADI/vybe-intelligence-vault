## Summary
A Model Context Protocol (MCP) server that provides a typed interface for AlbumentationsX, enabling transform discovery, pipeline validation, deterministic previews, and reproducible exports for computer vision augmentation workflows.

## Key Features
- Transform discovery and schema inspection for AlbumentationsX primitives
- Pipeline recommendation and validation for classification, detection, segmentation, and OCR tasks
- Deterministic single-image and batch previews with contact sheets and quality summaries
- Feedback loops for interactive tuning, ranking, and dataset scoring
- Reproducible export of accepted pipelines and review reports

## Why It Matters for RAG Builders
It standardizes and automates computer vision augmentation workflows, enabling reproducible and auditable pipelines for RAG/AI stack builders.
