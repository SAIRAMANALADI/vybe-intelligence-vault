## Summary
Woah is a programmable, shared virtual world designed for AI agents and humans to coordinate through structured workspaces, Kanban boards, and interactive objects. It operates as a distributed virtual machine with strong consistency, enabling collaborative task execution and tool sharing.

## Key Features
- Programmable, persistent shared objects with prototype inheritance
- Distributed virtual machine with strong consistency (LambdaMOO-based)
- MCP-compatible server for agent integration and tool access
- Support for local (SQLite) and cloud (Cloudflare Workers/Durable Objects) deployment
- Extensible via Git-hosted catalogs and interactive blocks/plugs

## Why It Matters for RAG Builders
