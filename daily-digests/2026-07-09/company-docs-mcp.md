## Summary
Company Docs MCP transforms internal documentation into an AI-searchable knowledge base by ingesting markdown, HTML, PDFs, or web pages, converting them into vectors, and storing them in a Supabase database. Teams can query this knowledge base via MCP-compatible AI tools like Claude or Cursor.

## Key Features
- Supports multiple content formats (markdown, HTML, PDFs, URLs, website crawls)
- Leverages Cloudflare Workers AI for vector embeddings without third-party API keys
- Integrates with Supabase for vector search and storage
- Enables team-wide access via MCP-compatible AI tools (Claude, Cursor, Slack)
- Automated ingestion and publishing with CLI tooling

## Why It Matters for RAG Builders
It provides a turnkey solution for turning static internal documentation into a dynamic, AI-accessible knowledge base, eliminating the need for manual retrieval and improving RAG system accuracy.
