## Summary
A Model Context Protocol (MCP) server plugin that integrates WhatsApp as a native channel for Claude Code, enabling bidirectional AI interactions directly from WhatsApp. Users can send messages, media, and voice notes to Claude, receive responses, and manage tasks remotely without requiring WhatsApp Business API or third-party services.

## Key Features
- Bidirectional messaging between WhatsApp and Claude Code via MCP server
- Full media support including photos, voice notes, videos, and documents
- Automatic voice message transcription using mlx-whisper
- Granular access control with allowlists, pairing codes, and group policies
- Scheduled cron tasks for automated WhatsApp notifications

## Why It Matters for RAG Builders
It enables seamless remote interaction with AI assistants like Claude Code through a widely used messaging platform, reducing friction for users who prefer WhatsApp for communication and task management.
