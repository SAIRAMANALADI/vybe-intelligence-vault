## Summary
A GUI desktop orchestrator (Electron-based) that enables parallel git worktree management, local server control, and AI agent interactions alongside IntelliJ IDEA. It provides a unified workspace for debugging, merging, and tracking multiple branches with embedded terminals and live logs.

## Key Features
- Parallel git worktree management with embedded PTY terminals for AI agents (Claude Code)
- Unified GUI for branch debugging, local server control, and log monitoring
- Monaco-based diff viewer and 3-way merge conflict resolver
- Session persistence with cross-machine visibility (abduco integration)
- Multi-window support and embedded browser for PR/CI status and server URLs

## Why It Matters for RAG Builders
It streamlines parallel AI agent workflows across multiple git branches, reducing context switching and enabling seamless debugging and merging in a single desktop environment.
