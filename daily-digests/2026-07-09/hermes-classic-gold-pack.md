## Summary
A cosmetic enhancement pack for the Hermes-Agent desktop app, offering a gold-themed UI, animated pets (Noir Neko), a custom status bar (TelemetryTape), and optional caduceus-themed background and loader. Designed to personalize the agent's appearance without altering core functionality.

## Key Features
- Gold-themed UI with light/dark mode support for Hermes-Agent desktop
- Two animated pets (Noir Neko and Noir Neko ASCII Fine) for interactive desktop companions
- Custom TelemetryTape status bar displaying real-time agent metrics (tokens, throughput, system resources)
- Optional caduceus-themed background and loader animations for enhanced visual identity
- AI-assisted one-prompt installation and uninstallation for seamless setup
