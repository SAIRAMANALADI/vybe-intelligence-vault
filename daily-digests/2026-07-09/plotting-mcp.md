## Summary
A Model Context Protocol (MCP) server that converts CSV data into visualizations, enabling AI assistants and chat applications to generate and display charts, maps, and graphs dynamically.

## Key Features
- Supports multiple plot types (line, bar, pie, world maps) with flexible JSON-based configuration
- Generates base64-encoded PNG images for seamless integration with AI chat interfaces
- Built-in geospatial visualization using Cartopy for coordinate-based data
- Optimized for fast CSV parsing and plot generation with modern Python tooling
- Deployable via Docker and ToolHive for secure, scalable environments

## Why It Matters for RAG Builders
It enables AI systems to dynamically generate and display visualizations from raw data, enhancing user understanding and interaction in RAG applications.
