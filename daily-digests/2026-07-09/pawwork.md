## Summary
PawWork is an open-source desktop AI agent for macOS and Windows that automates document processing, research, writing, coding, and local file tasks using 75+ AI model providers. It serves as a user-friendly alternative to proprietary tools like Codex App and Claude Cowork, enabling non-technical users to perform complex AI-driven workflows without terminal access.

## Key Features
- Supports 75+ AI model providers including OpenAI, Claude, Gemini, DeepSeek, and local models via Ollama/LM Studio
- Full desktop app with native support for Office files (Word, Excel, PowerPoint), PDFs, CSV, and code projects
- Task cards for structured, non-technical workflows without requiring terminal access
- Built-in web search and browser automation for research and data collection
- Open-source under Apache 2.0 with signed macOS builds and unsigned Windows builds

## Why It Matters for RAG Builders
PawWork provides a no-code, desktop-native AI agent framework that bridges the gap between local file systems and multi-model AI capabilities, making it ideal for RAG builders who need to integrate document processing and automation into their workflows.
