## Summary
VoxNote is a Windows desktop application for cloud-based speech-to-text transcription, speaker diarization, and durable meeting transcript management. It supports Kazakh, Russian, and English code-switching meetings and integrates with the Mini-AGI ecosystem as the voice/audio intake layer.

## Key Features
- Cloud-based transcription and diarization via AssemblyAI, Deepgram, Gladia, or Speechmatics
- Support for Kazakh, Russian, and English code-switching meetings
- Durable transcript artifacts (transcript.md) with optional speaker labels
- Integration with Hermes Desktop via MCP tools and webhooks
- Built-in microphone recording, audio cutter, and document attachment processing

## Why It Matters for RAG Builders
VoxNote provides essential cloud-based transcription and diarization capabilities for AI stacks, enabling accurate meeting capture and downstream processing in RAG and agentic workflows.
