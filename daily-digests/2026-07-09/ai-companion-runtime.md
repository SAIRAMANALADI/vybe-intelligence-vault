## Summary
A real-time AI companion runtime designed for eldercare scenarios, featuring WebSocket-based streaming conversations, risk detection (health emergencies, scams, emotional distress), tool integration, long-term memory, and full-chain trace observability.

## Key Features
- WebSocket-based streaming conversations with structured message protocols (trace, risk alerts, deltas, tool results)
- Multi-tier risk detection (health emergencies, scams, emotional distress) with immediate interception for critical alerts
- Dynamic personality and memory recall (L0-L4) with importance-ranked retrieval and user profile integration
- Agent Harness orchestration with model hot-swapping, tool dispatching, and configurable timeouts/retries
- Full-chain trace observability (TTFT, latency, token usage) with Jaeger/Prometheus/Grafana integration

## Why It Matters for RAG Builders
This runtime provides a robust, production-ready foundation for building eldercare-focused AI companions with built-in safety, memory, and observability features critical for RAG systems in sensitive domains.
