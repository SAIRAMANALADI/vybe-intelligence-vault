## Summary
An AI-powered task planning application built with Next.js that enables users to break down goals into actionable tasks via conversational AI, schedule them with due dates, and manage them across multiple plans with persistent storage in PostgreSQL.

## Key Features
- AI-powered goal decomposition into structured task plans with priorities and due dates
- Personal context integration for tailored AI recommendations based on user preferences
- Incremental plan updates via AI chat without regenerating completed or unchanged tasks
- Interactive calendar and map views for visualizing tasks and locations
- User authentication with email/password or Google OAuth and persistent data storage
