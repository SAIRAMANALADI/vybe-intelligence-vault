## Summary
A lightweight agentic coding CLI built in Rust, designed for local AI models like llama.cpp or vLLM. It enables dynamic multi-agent workflows, parallel tool calls, and MCP client integration via OpenAI-compatible APIs.

## Key Features
- Extremely lightweight Rust single binary
- Docker-sandbox-native with folder mounting support
- OpenAI Chat Completions + Responses APIs compatibility
- Dynamic multi-agent workflows with parallel tool calls
- Built for small local models (llama.cpp/vLLM)

## Why It Matters for RAG Builders
Enables lightweight, local-first agentic workflows for RAG builders without heavy cloud dependencies.
