## Summary
build123d-mcp is an MCP (Model Context Protocol) server that enables AI/LLM applications to interact with build123d, a Python-based parametric CAD toolkit. It allows assistants to create, render, measure, and export CAD models incrementally, improving AI-driven 3D modeling workflows.

## Key Features
- Enables AI/LLM apps to execute build123d code in a persistent CAD session
- Provides rendering, measurement, and validation tools for CAD models
- Supports incremental model building with real-time feedback
- Exports models in multiple formats (STEP, STL, DXF, SVG)
- Integrates with popular AI/LLM applications via MCP

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and CAD tools, enabling precise, iterative 3D modeling workflows that significantly improve AI-driven design accuracy and efficiency.
