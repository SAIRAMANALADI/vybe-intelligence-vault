## Summary
MockHero is a synthetic test data API that generates realistic, relational data for databases using structured schemas, plain English prompts, or pre-built templates. It supports 156 field types, auto-locale matching, and multiple output formats like JSON, CSV, and SQL.

## Key Features
- 156 field types across 15+ categories with auto-locale support for 22 locales
- Relational data generation with foreign key integrity and deterministic seeds
- Three input modes: structured schema, plain English prompt, or pre-built templates
- Multiple output formats: JSON, CSV, and SQL dialects (Postgres, MySQL, SQLite)
- MCP server integration for AI agents and remote/local deployment options

## Why It Matters for RAG Builders
MockHero streamlines the creation of realistic, relational test data for AI and RAG pipelines, reducing setup time and improving data quality for development and testing.
