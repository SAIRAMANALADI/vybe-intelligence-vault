## Summary
VibeDev is a governance framework for AI-driven software development (Vibe Coding) that enforces structured development cycles, security audits via VibeShield, and dual-mode operation (technical and layman). It includes automated risk management, cost estimation, anti-feature-creep mechanisms, and localized support for Brazilian contexts.

## Key Features
- Structured AI-driven development cycle with defined phases and gates
- Automated security auditing via VibeShield with triggers for sensitive actions
- Dual-mode operation (technical and layman) with jargon translation and cost estimation
- Anti-feature-creep mechanisms to contain scope during development
- Localized support for Brazilian contexts (BRL, LGPD, Pix-first)
