## Summary
uniTerm is a cross-platform terminal application supporting 20+ protocols (SSH, RDP, SFTP, databases) with an integrated autonomous AI agent for multi-turn shell command execution. It combines a feature-rich terminal, file transfer, remote desktop, and database client into a single interface.

## Key Features
- Supports 20+ protocols including SSH, RDP, SFTP, and multiple databases
- Built-in autonomous AI agent for planning and executing multi-turn shell commands
- Cross-platform support (Windows, macOS, Linux) with cloud sync for settings
- Split-pane workspace with customizable themes and keybindings
- Integrated file transfer, remote desktop, and server monitoring tools
