## Summary
A modular, production-ready AI agent framework for Node.js that enables rapid development of reliable AI agents with zero dependencies. It supports 21 LLM providers, 23 framework bridges, multi-agent orchestration, and visual workflow building for complex agent systems.

## Key Features
- Supports 21 major LLM providers with unified API and native function calling
- 23 framework bridges for bidirectional integration with LangChain, CrewAI, MCP, and more
- Multi-agent orchestration with pipelines, parallel execution, routing, and handoffs
- Visual workflow builder with node graphs, conditions, branches, and transforms
- Zero dependencies, pure Node.js, with real-time streaming and event system

## Why It Matters for RAG Builders
It provides a unified, modular foundation for building and orchestrating AI agents across multiple LLM providers and frameworks, accelerating RAG and AI stack development with production-ready tooling.
