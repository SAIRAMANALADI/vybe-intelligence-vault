## Summary
CyberSentry is an autonomous AI-powered ethical hacking agent that performs intelligent website security audits using Llama 3.1 70B on NVIDIA NIM. It orchestrates 8 advanced security tools via a ReAct loop architecture to detect vulnerabilities, generate professional reports, and provide actionable remediation guidance.

## Key Features
- Autonomous decision-making using Llama 3.1 70B to coordinate 8 security tools
- ReAct loop architecture for intelligent tool orchestration and result interpretation
- Real-time terminal visualization with live progress and color-coded severity indicators
- Professional markdown security reports with CVSS-style severity ratings and remediation steps
- Integration with NVIDIA NIM for high-performance LLM inference
