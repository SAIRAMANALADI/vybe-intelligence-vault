## Summary
RepoBrain transforms any codebase into an AI-ready knowledge engine, enabling grounded Q&A with file paths and line numbers across multiple IDEs like Claude Code, Cursor, and Codex. It automates the creation of a contextual knowledge base for repositories, replacing manual documentation with a multi-agent system that reads and indexes code autonomously.

## Key Features
- Automated knowledge base generation via multi-agent cluster that reads and indexes code modules
- Cross-IDE compatibility (Claude Code, Cursor, Codex, Windsurf, etc.) with unified slash commands
- Grounded answers with file paths, line numbers, and git history for accuracy
- Benchmark-proven 99% factual correctness and 2.1x faster performance than Codex CLI
- Interactive setup and incremental refresh for dynamic codebases

## Why It Matters for RAG Builders
RepoBrain eliminates the need for manual documentation or context files by automating the creation of a high-fidelity knowledge base for any codebase, making it essential for RAG/AI stack builders who require accurate, real-time context for AI-driven development.
