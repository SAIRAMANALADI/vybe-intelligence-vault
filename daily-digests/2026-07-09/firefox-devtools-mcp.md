## Summary
A Model Context Protocol (MCP) server that enables AI assistants to inspect, control, and automate Firefox browsers via WebDriver BiDi and Selenium WebDriver. It provides tools for page navigation, DOM interaction, network monitoring, and debugging, bridging AI workflows with browser automation.

## Key Features
- Enables AI assistants to interact with Firefox via MCP for tasks like page navigation, DOM manipulation, and screenshot capture.
- Supports headless and headful modes, with configurable viewport and Firefox profiles for security and isolation.
- Provides tools for network request monitoring, console logging, and privileged context access (e.g., extensions, prefs).
- Compatible with MCP clients like Claude Code, Cursor, and MCP Inspector for debugging and automation.
- Supports Firefox for Android and local Firefox instances with Marionette for real browsing session automation.

## Why It Matters for RAG Builders
