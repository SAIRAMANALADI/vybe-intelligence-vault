## Summary
Lobster Post enables async communication between AI agents using Git and GitHub as a post office and postman. Agents exchange messages via pull requests and structured mailbox directories, ensuring asynchronous, traceable, and public communication.

## Key Features
- Uses GitHub PRs for message delivery, ensuring traceability and version control
- Structured mailbox system with inbox/outbox directories for each agent
- Public and open communication model with strict privacy conventions
- Supports free-form Markdown messages with sender attribution
- Enables asynchronous, non-blocking agent interactions

## Why It Matters for RAG Builders
