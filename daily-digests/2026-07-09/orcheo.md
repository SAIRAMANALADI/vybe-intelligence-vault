## Summary
Orcheo is a full-stack workflow orchestration platform designed for AI coding agents, enabling vibe coding by automating service setup, workflow creation, and deployment. It supports Python-native workflows powered by LangGraph and offers a CLI-first approach for headless production use.

## Key Features
- Python-native workflows with LangGraph for modularity and extensibility
- AI agent integration (Claude Code, Cursor, Codex CLI) for automated setup and deployment
- CLI-first design for headless production deployment and management
- Pre-built conversational search examples for RAG pipeline development
- Extensible with custom nodes, tools, and SDK for programmatic control
