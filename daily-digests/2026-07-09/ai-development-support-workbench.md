## Summary
A technical PoC repository that evolves a single development-support problem from a basic LLM application to a grounded RAG system and finally to a bounded AI agent workflow, with formal evaluations of quality, retrieval, latency, and token costs. It focuses on structuring ambiguous requirements into actionable artifacts and validating LLM engineering decisions.

## Key Features
- Progressive evolution from LLM app to grounded RAG to bounded agent workflow with formal evaluations at each stage
- Structured decomposition of ambiguous requirements into artifacts like Jira tasks, acceptance criteria, and implementation plans
- Provider-agnostic structured output validation using Zod for consistent comparisons across models (OpenAI, Gemini, Claude)
- Bounded agent workflow with deterministic revision decisions, tool use, and state management for controlled multi-step LLM orchestration
- Comprehensive cost/quality trade-off analysis including latency, token usage, retrieval metrics, and quality rubrics

## Why It Matters for RAG Builders
It provides a rigorous framework for evaluating and comparing LLM-based workflows, helping AI engineers make informed decisions about architecture trade-offs in RAG and agent systems.
