## Summary
A Model Context Protocol (MCP) server that enables control of WiZ smart lights via FastMCP. It allows users to manage lighting across multiple rooms, adjust colors, brightness, and apply preset scenes through a structured API.

## Key Features
- Seamless integration with WiZ smart lights via MCP
- Support for turning lights on/off, adjusting colors, and brightness
- Ability to apply preset lighting scenes (e.g., Sunset, Party)
- Multi-room control with simple API calls
- Discovery of lights on the local network

## Why It Matters for RAG Builders
It provides a standardized way to integrate smart lighting control into AI-driven home automation systems using the MCP protocol.
