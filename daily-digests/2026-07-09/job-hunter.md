## Summary
Job Hunter automates the repetitive aspects of job hunting by scraping job listings across major boards, scoring them against user profiles, tailoring resumes and cover letters, and tracking applications via an interactive dashboard or autonomous LLM-driven pipelines.

## Key Features
- Multi-source job scraping with filtering and exclusions
- AI-driven resume and cover letter tailoring per job listing
- Interactive agent mode (Claude Code/VS Code) or autonomous LLM API mode
- Native desktop dashboard for tracking applications, insights, and analytics
- Strict data contract ensuring user-owned files remain untouched by updates

## Why It Matters for RAG Builders
Job Hunter streamlines the job application process by automating tedious tasks, enabling AI engineers to focus on high-value interactions rather than repetitive workflows.
