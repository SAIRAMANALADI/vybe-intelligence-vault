## Summary
Doc77 is a lightweight local document preview and management tool supporting Markdown, PDF, and various file formats. It provides a web-based dashboard for browsing, searching, and managing documents with AI-assisted features, MCP server integration for file operations, and local network sharing capabilities.

## Key Features
- Multi-format document preview (Markdown, PDF, Office, code, images)
- MCP server for secure file operations with AI agents
- Local network sharing with password protection
- AI-driven document summarization and interaction
- Approval workflow for write operations with atomic rollback

## Why It Matters for RAG Builders
Doc77 provides a secure, local-first document management and preview solution with MCP integration, enabling AI agents to safely interact with local file systems for RAG and document processing workflows.
