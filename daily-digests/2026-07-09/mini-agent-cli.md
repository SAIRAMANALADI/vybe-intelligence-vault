## Summary
A lightweight CLI-based AI agent that interacts with the filesystem (read, write, list files) using Google Gemini's tool-calling capabilities. Designed as a hands-on project to demonstrate agentic workflows in a terminal environment.

## Key Features
- Interactive CLI chat loop with colored output for user and agent messages
- JSON-based tool-calling protocol for structured agent-LLM interaction
- Built-in filesystem tools: readFile, writeFile, and listDir
- Agent reasoning display showing why a tool was selected
- Multi-turn conversation with tool result injection for seamless workflows

## Why It Matters for RAG Builders
Demonstrates core agentic patterns like tool-calling and multi-turn reasoning in a minimal, production-ready CLI format, making it ideal for learning or integrating into larger AI systems.
