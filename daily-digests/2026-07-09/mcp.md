## Summary
A suite of open-source MCP servers providing AI applications with standardized access to AWS services, documentation, and best practices via the Model Context Protocol (MCP). These servers enable LLMs to interact with AWS resources, retrieve real-time documentation, and execute cloud-native workflows securely.

## Key Features
- Standardized MCP-based integration with AWS services for LLMs
- Real-time access to AWS documentation and best practices
- Support for multiple transport mechanisms (stdio, streamable HTTP)
- Pre-built tools for infrastructure management, data operations, and AI workflows
- Security-first design with IAM-based permissions and CloudTrail audit logging

## Why It Matters for RAG Builders
It enables AI agents to securely interact with AWS services, retrieve up-to-date documentation, and automate cloud-native workflows, bridging the gap between LLMs and AWS ecosystems.
