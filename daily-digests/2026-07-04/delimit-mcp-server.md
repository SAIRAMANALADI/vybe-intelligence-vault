## Summary
Delimit provides a governance chain for AI-written code, wrapping AI coding assistants to enforce merge gates, record changes, and generate signed, replayable attestations for every code merge. It ensures policy compliance, detects breaking changes, and maintains an auditable trail of decisions and artifacts.

## Key Features
- Wraps AI coding assistants (Claude Code, Cursor, Codex, etc.) with signed governance gates
- Generates replayable attestations for every merge with HMAC-SHA256 signatures
- Detects breaking changes, leaked secrets, and policy violations in code changes
- Supports multi-model deliberation and autonomous build orchestration
- Provides offline-verifiable receipts and public replay URLs for transparency
