## Summary
A Model Context Protocol (MCP) server that enables AI assistants to fetch and interact with Yahoo Finance data via the yfinance library. It provides real-time stock information, financial statements, news, sector rankings, and professional chart generation for AI-driven financial analysis.

## Key Features
- Provides comprehensive stock data including financials, valuation metrics, and trading information via MCP tools
- Fetches real-time financial news, press releases, and sector rankings for any ticker
- Generates professional financial charts (candlestick, VWAP, volume profile) as WebP images for AI consumption
- Supports advanced screeners for equities, funds, and custom financial queries with sorting and pagination
- Offers options data, ownership details, and historical price history with technical analysis capabilities

## Why It Matters for RAG Builders
It bridges AI assistants with real-time financial data and professional charting, enabling RAG systems to generate accurate, data-rich financial insights and visualizations.
