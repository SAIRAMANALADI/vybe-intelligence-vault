## Summary
AI Flow enables multi-agent orchestration for autonomous AI workflows via versioned `.flow.yaml` files. It allows users to define, version, and execute complex multi-role workflows with explicit control, autonomy, and consistency in outputs.

## Key Features
- Define autonomous AI workflows in versioned `.flow.yaml` files with explicit roles, tools, and prompts.
- Three execution patterns: Pipeline (sequential), Iterative (looping), and Fork-Join (parallel) for flexible workflow design.
- Autonomous tool use with role-specific tool allowlists and up to 15 rounds of tool interactions per role.
- Progressive disclosure rendering ensures critical instructions always fit in the token window for consistent outputs.
- Built-in flow library with production-ready workflows for common tasks like code review, PR description, and incident triage.

## Why It Matters for RAG Builders
AI Flow provides a structured, versionable, and autonomous way to orchestrate multi-agent workflows, ensuring consistent, repeatable, and scalable AI-driven tasks critical for RAG and AI stack builders.
