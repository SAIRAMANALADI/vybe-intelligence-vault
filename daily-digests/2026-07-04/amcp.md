## Summary
AMCP is an out-of-the-box coding-agent runtime designed for immediate use in terminals, IDEs, servers, and Telegram. It provides a fully functional agent with built-in tools, memory, multi-agent orchestration, and MCP/ACP integration without requiring extensive setup or plugin installation.

## Key Features
- Built-in coding tools (read/write files, apply patches, execute shell commands, web search/fetch)
- Multi-agent architecture with primary/subagent support (coder, explorer, planner, focused_coder)
- Persistent memory system with MEMORY.md and HISTORY.md for cross-session knowledge retention
- Multiple interfaces (CLI, ACP for IDEs, HTTP/WebSocket server, Telegram bot, cron automation)
- Skills system for reusable behaviors and slash commands for custom workflows

## Why It Matters for RAG Builders
AMCP provides a production-ready, extensible agent runtime that accelerates RAG/AI stack development by eliminating the need to assemble core agent capabilities from scratch.
