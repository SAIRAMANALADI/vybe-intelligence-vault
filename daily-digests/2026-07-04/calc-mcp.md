## Summary
Calc MCP is a Model Context Protocol (MCP) server that provides 21 deterministic tools for precise mathematical, cryptographic, date, encoding, and text operations. It addresses common AI limitations like hallucinated calculations, fake randomness, and timezone errors by running computations locally.

## Key Features
- 21 specialized tools for math, hashing, encoding, date arithmetic, and text processing
- Deterministic and secure local computation with no external data transmission
- Integration with MCP-compatible clients (Claude, VS Code, Cursor, etc.)
- Supports Docker and direct npx installation for easy deployment
- Comprehensive toolset including SHA-256, UUID generation, cron parsing, and unit conversion

## Why It Matters for RAG Builders
