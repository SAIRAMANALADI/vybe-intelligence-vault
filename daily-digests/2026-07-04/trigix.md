## Summary
Trigix is an enterprise-grade, AI-native workflow automation platform featuring a Rust execution engine, 180+ node types, and a visual canvas. It supports RAG, agents, MCP, and integrates with AI models, APIs, databases, and SaaS tools for complex workflow automation.

## Key Features
- 180+ pre-built node types including AI models, SaaS integrations, and data transforms
- Rust-based execution engine with DAG scheduling, parallel execution, and retries
- Built-in RAG over pgvector and agent tool-use loop with MCP protocol support
- Enterprise-grade features like SSO, RBAC, multi-tenancy, and audit logging
- Extensible via custom node SDKs in Python and TypeScript/JavaScript

## Why It Matters for RAG Builders
Trigix provides a robust, AI-native platform for orchestrating complex RAG pipelines and agent workflows with enterprise-grade scalability and extensibility.
