## Summary
OmniTerm provides a unified browser-based dashboard for monitoring and interacting with AI coding agents (e.g., Claude Code, Codex) via tmux. It centralizes agent status tracking, terminal access, file management, and Git worktree awareness in a single interface.

## Key Features
- Real-time monitoring of AI coding agents (Claude Code, Codex, etc.) with live status badges and notifications
- Built-in terminal and file browser with syntax highlighting for 13 languages
- Git worktree awareness with automatic discovery and session grouping by branch
- Single binary deployment with embedded frontend and SQLite backend
- Cross-platform support via npm, shell script, or Docker

## Why It Matters for RAG Builders
OmniTerm simplifies the management of AI coding agents by providing a centralized, browser-based interface for monitoring and interaction, reducing the need for manual terminal multiplexing.
