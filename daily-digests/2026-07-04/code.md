## Summary
SOREX Code is a VS Code extension that integrates a configurable language model with workspace tools for codebase exploration, editing, diagnostics, and agent workflows. It supports multiple model providers, repository indexing, and context management for AI-driven coding tasks.

## Key Features
- Configurable model providers (local and cloud) with direct API key management
- Workspace tools for file operations, diagnostics, and terminal execution
- Repository indexing with lexical, vector, and hybrid ranking modes
- Context budgeting and token management for long coding sessions
- Permission-based modes (Ask, Explore, Plan, Edit, Agent) for controlled AI interactions

## Why It Matters for RAG Builders
SOREX Code enables AI-driven coding workflows directly within VS Code, bridging the gap between language models and practical development tasks with configurable tools and context controls.
