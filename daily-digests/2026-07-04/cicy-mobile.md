## Summary
A cross-platform mobile client for the CiCy agent platform, enabling users to browse agents, chat with them, and join teams via QR code scanning. Supports iOS, Android, web/PWA, and Telegram Mini App deployments from a single Expo codebase.

## Key Features
- Single codebase for iOS, Android, web/PWA, and Telegram Mini App deployments
- QR code scanning to join teams directly via the client's backend (CICY_PUBLIC_URL)
- Two-tier chat history caching (in-memory + persistent) for instant agent access
- Automated CI/CD for web, Android, and iOS releases with GitHub Actions
- Telegram Mini App integration with native QR scanner and optimized bundle loading

## Why It Matters for RAG Builders
It provides a unified, cross-platform interface for interacting with agent-based systems, simplifying deployment and user access across multiple environments.
