## Summary
A VS Code-integrated SAP orchestration tool that enables natural language interaction with SAP systems (ABAP, BAPI, GUI) without requiring SAP GUI or Eclipse. It dynamically routes tasks through ADT, RFC, or GUI paths, learns from execution outcomes, and automates complex workflows like material creation, transport management, and ABAP code analysis.

## Key Features
- Natural language SAP interaction via VS Code chat (no SAP GUI/Eclipse required)
- Dynamic routing engine that selects the fastest path (ADT, RFC, GUI) and adapts based on performance and success metrics
- 8-stage spec-to-transport pipeline for end-to-end ABAP development workflows with peer reviews and static analysis
- Self-learning engine that records MCP call outcomes, adapts routing decisions, and discovers system features
- Comprehensive skill catalog (85+ skills) covering ABAP, BTP, UI5, integration, HANA, and security

## Why It Matters for RAG Builders
It streamlines SAP development and operations by enabling AI-driven, natural language interactions with SAP systems while dynamically optimizing execution paths, reducing manual effort and accelerating workflows for RAG/AI stack builders.
