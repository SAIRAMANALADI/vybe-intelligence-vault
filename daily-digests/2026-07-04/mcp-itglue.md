## Summary
An MCP server for the IT Glue API that enables AI assistants to read and safely write documentation for MSPs. It provides tools for document management, semantic vector search, and role-based access control.

## Key Features
- Semantic vector search for IT Glue documentation using OpenAI or Azure OpenAI embeddings
- Role-based access control with viewer/editor/admin tiers and BYOK (Bring Your Own Key) support
- Support for stdio and HTTP transports, including Docker deployment
- Automatic and manual vector index refresh via webhooks or API calls
- Comprehensive document and flexible asset management tools

## Why It Matters for RAG Builders
It enables AI assistants to securely interact with IT Glue documentation, enhancing RAG systems with accurate, context-aware document retrieval and editing capabilities.
