## Summary
OnionClaw provides AI agents with full Tor network access and dark web data through a zero-config OpenClaw skill or standalone tool. It enables autonomous OSINT, threat intelligence, and dark web monitoring with identity rotation and LLM-driven analysis.

## Key Features
- Full Tor network integration with identity rotation via `renew.py`
- 18 dark web search engines with real-time health checks
- Standalone and OpenClaw skill deployment options
- LLM-driven analysis modes for OSINT synthesis
- Autonomous dark web crawling and scraping with zero human intervention
