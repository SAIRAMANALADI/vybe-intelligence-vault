## Summary
dashcraft is a headless React dashboard library that provides drag-and-drop grids, resizable widgets, and charting capabilities (via recharts) without enforcing a design system. It includes an MCP codegen server for AI-native code generation and persistence features for saving layouts.

## Key Features
- Headless React dashboard engine with boolean prop API for interactivity (drag, resize, settings, delete)
- Built-in support for KPI cards, recharts (bar, line, area, pie, scatter, radar), and hierarchy charts (heatmap, treemap, sunburst)
- Automatic layout persistence via localStorage with a single `persistenceKey` prop
- AI-native tooling including `llms.txt`, `AGENTS.md`, and an MCP codegen server for screenshot-to-code conversion
- Monorepo structure with a core library, documentation site, and MCP server for extensibility
