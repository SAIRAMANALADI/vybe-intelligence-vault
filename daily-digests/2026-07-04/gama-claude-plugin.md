## Summary
A Claude AI agent plugin integrated into the GAMA Platform IDE that acts as an intelligent assistant for simulation modeling, capable of reading compiler errors, editing GAML code, running experiments, and interacting with live simulations in real-time.

## Key Features
- Real-time integration with GAMA Platform IDE for compiler error analysis and code editing
- Live simulation bridge enabling pause, step, inspect, and mutate operations on running simulations
- Project-wide semantic indexing for GAML code navigation and symbol lookup
- Headless validation and execution of experiments with monitor and display snapshot analysis
- Safe, diff-based code edits with undo history and approval workflows

## Why It Matters for RAG Builders
It bridges the gap between AI assistance and domain-specific simulation environments, enabling AI agents to directly interact with live simulations for real-time debugging, modeling, and experimentation.
