## Summary
The @makethisbetter/mcp repository provides an MCP server that integrates user feedback directly into coding agents like Claude Code, Cursor, and Windsurf. It enables agents to pull, triage, and resolve user-reported issues or requests without manual intervention.

## Key Features
- Seamless integration with MCP-compatible coding agents (Claude Code, Cursor, Windsurf, VS Code)
- Five tools for managing feedback workflow: list, detail, pick, resolve, and dismiss
- AI triage analysis and prioritization of user feedback
- Automated notification to users upon issue resolution
- Support for self-hosted instances via configurable API endpoints

## Why It Matters for RAG Builders
This MCP server streamlines the feedback-to-fix pipeline, enabling AI agents to autonomously resolve user-reported issues, reducing manual effort and improving developer productivity.
