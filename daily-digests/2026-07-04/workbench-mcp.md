## Summary
A zero-dependency MCP server that transforms a Windows workstation into an AI-agent workbench, enabling system control, persistent memory, file intelligence, and remote fleet management via SSH. Designed for seamless integration with Claude Desktop using stdio transport.

## Key Features
- Zero-dependency Python server with stdlib-only implementation for robust deployment
- Persistent SQLite FTS5 knowledge base with structured memory organization (insights, skills, patterns)
- System control tools (PowerShell, Python execution, process management, screenshots)
- File intelligence with big-data analysis modes (stats, patterns, anomalies, distribution)
- Remote fleet management via SSH with environment normalization for Windows OpenSSH issues
