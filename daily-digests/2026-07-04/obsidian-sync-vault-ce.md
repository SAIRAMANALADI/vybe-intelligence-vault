## Summary
A plugin for Obsidian that synchronizes cloud storage (e.g., Baidu Netdisk, OneDrive, Aliyun) with local vaults, enabling seamless access, linking, and embedding of cloud resources in notes. Includes an MCP server for AI agents to interact with cloud files in real-time.

## Key Features
- Synchronizes cloud storage (e.g., Baidu, OneDrive, Aliyun) with Obsidian vaults, enabling real-time access to files without local storage bloat.
- Built-in MCP server for AI agents (e.g., Claude Code, Cursor) to directly read, write, and manage cloud files via SSE.
- Supports bi-directional sync, conflict resolution, and end-to-end encryption for Markdown files.
- Provides CLI commands for automation and AI workflows, including file listing, searching, and reading.
- Offers collaborative editing, online preview for images/PDFs, and support for multiple cloud services.

## Why It Matters for RAG Builders
It bridges cloud storage with AI workflows, enabling LLMs and agents to seamlessly access and manipulate files in real-time, reducing local storage constraints and enhancing RAG pipelines.
