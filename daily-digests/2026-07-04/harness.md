## Summary
Harness is a Rust-native control plane for orchestrating fleets of parallel AI coding agents (e.g., Claude Code, Codex) with governance, policy enforcement, and observability. It standardizes agent lifecycle management, cross-agent review, and automated remediation while integrating with GitHub and OpenTelemetry.

## Key Features
- Fleet orchestration for parallel AI coding agents with unified lifecycle management
- Starlark-based policy engine for sandboxed rule evaluation and governance
- Automated cross-agent code review to prevent self-review bias
- OpenTelemetry-native observability with async-safe trace/metric export
- GitHub webhook automation for task triggering via @harness mentions

## Why It Matters for RAG Builders
Harness provides the critical infrastructure for scaling AI agent fleets with governance, ensuring reliability, security, and observability in production RAG and AI systems.
