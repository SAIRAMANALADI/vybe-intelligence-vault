## Summary
Neloo is a general-purpose AI agent workspace combining a Next.js frontend with a LangGraph and Deep Agents backend, enabling chat-based task execution, tool use, file workflows, code execution, and third-party integrations for building and deploying AI agents.

## Key Features
- Modular agent architecture with LangGraph and Deep Agents for flexible task execution
- Support for multiple model providers (OpenAI, Claude, DeepSeek, etc.) and OpenAI-compatible APIs
- Built-in tool calling, sub-agents, and human-in-the-loop workflows
- File upload/download, code execution (local/E2B/Docker), and web search via Tavily
- Optional Supabase integration for storage, auth, and database persistence

## Why It Matters for RAG Builders
Neloo provides a robust, modular framework for building and deploying AI agents with integrated tooling, sandbox execution, and multi-provider support, making it essential for RAG builders seeking scalable agent architectures.
