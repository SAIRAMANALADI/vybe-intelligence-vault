## Summary
A terminal user interface (TUI) for interacting with AI agents, built on the agent-core framework and leveraging OpenTUI for rendering. It provides a command-line interface for managing and executing AI agent workflows directly from the terminal.

## Key Features
- Interactive terminal-based UI for AI agents
- Cross-platform support (Windows and Linux x64)
- Customizable keybindings for improved UX (e.g., Shift+Enter for newlines)
- Automated agent hooks for post-turn validation and formatting
- Early-stage but actively developed with regular releases

## Why It Matters for RAG Builders
