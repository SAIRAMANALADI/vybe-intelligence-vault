## Summary
A collection of macOS desktop automation skills and a self-improving task router for AI agents using Cua Driver. It enables reliable computer-use agents to control macOS desktops with dynamic path selection and learning from past executions.

## Key Features
- Self-improving task router with 5-tier fallback (CLI → CDP → Cua Driver → Vision AI)
- Persistent learning via SQLite history database for optimized path selection
- Context-aware fallback and consecutive failure skip mechanisms
- 9 pre-built skills for common macOS automation tasks (e.g., git operations, browser control)
- Integration with Hermes Agent, Claude Code, and other AI coding tools
