## Summary
Official MCP server for Brilliant Directories that enables AI agents to interact with a Brilliant Directories site via a standardized API. Provides tools to manage members, posts, leads, reviews, pages, and other resources exposed by the Brilliant Directories REST API.

## Key Features
- Enables AI agents to manage Brilliant Directories resources (members, posts, pages, etc.) via MCP tools
- Supports both hosted (easy) and self-hosted (advanced) deployment options
- Provides OpenAPI 3.1 specification for resource discovery and field validation
- Includes granular API permission controls via Brilliant Directories' Advanced Endpoints
- Compatible with major AI clients (Claude, Cursor, Windsurf, n8n, etc.)
