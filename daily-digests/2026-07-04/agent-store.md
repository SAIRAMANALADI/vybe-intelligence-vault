## Summary
A curated toolkit for the Hermes Agent ecosystem, providing skills, fleet orchestration patterns, MCP server implementations, and agent personality templates to enable multi-agent systems and AI workflow automation.

- Multi-agent fleet orchestration with routing and QA gates

- Machine-readable catalog.json for skill indexing and discovery
