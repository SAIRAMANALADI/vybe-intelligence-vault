## Summary
A utility for managing multiple isolated Claude Desktop sessions on Windows, enabling separate accounts, chat histories, and settings without manual sign-in/out. It acts as a profile manager for the official Claude Desktop client.

## Key Features
- Enables running multiple isolated Claude Desktop sessions simultaneously
- Separates login credentials, chat history, and settings per profile
- Simple GUI for adding, launching, and managing profiles
- Local storage of profile data with no external data collection
- Troubleshooting tools for common issues like blank screens or launch failures

## Why It Matters for RAG Builders
It simplifies managing multiple Claude accounts locally, reducing friction for users who need separate work and personal sessions.
