## Summary
slide-maker converts research papers, code repositories, documents, or topics into fully editable PowerPoint presentations (PPTX) with native text boxes, charts, equations, and animations. It leverages specialized AI agents to plan, generate, and critically review decks before delivery, ensuring high-quality, source-backed presentations.

## Key Features
- Converts papers, repos, or topics into native editable PPTX with real text boxes, charts, and equations
- Uses specialized AI agents (planner, critic, arbiter, asset-prep) for structured, reviewed output
- Includes full speaker notes and native click-build animations for presentations
- Supports template-based customization and iterative refinement via build scripts
- Provides independent critic review to ensure accuracy and visual quality before delivery
