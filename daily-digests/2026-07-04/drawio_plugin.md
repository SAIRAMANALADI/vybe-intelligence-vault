## Summary
A plugin that enables AI coding assistants to generate native, fully-editable draw.io diagrams from natural language prompts. It supports multiple AI clients and ensures diagrams are created with native mxGraph XML for full editability and validation.

## Key Features
- Generates native draw.io XML diagrams from natural language prompts, ensuring full editability and compatibility
- Supports multiple AI clients (Kiro, Claude, Cursor, Copilot CLI, Antigravity) with zero-script installations
- Includes auto-validation for layout collisions and formatting errors before presenting diagrams
- Enables round-trip editing by reading, modifying, and re-rendering existing `.drawio` files
- Provides rich skill knowledge and examples to ensure AI produces correct, domain-specific diagrams on the first try

## Why It Matters for RAG Builders
It bridges the gap between natural language AI and precise diagramming tools, enabling AI to generate fully editable, production-ready diagrams that integrate seamlessly into engineering workflows.
