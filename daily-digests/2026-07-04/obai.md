## Summary
OBaI is an open-source multi-agent platform designed for stock research, strategy backtesting, and prediction market intelligence. It leverages parallel agent dispatch, MCP servers, and self-hosted observability tools to deliver comprehensive financial insights and executable trading strategies.

## Key Features
- Parallel agent dispatch with agents-as-tools pattern for simultaneous specialist execution
- Self-hosted Opik tracing for end-to-end observability and evaluation of agent workflows
- Comprehensive financial data integration from FMP, Exa, Polymarket, and Coinbase
- Autonomous strategy design and backtesting with iterative refinement and validation
- Modular MCP server architecture with streamable-http transport for scalable tooling

## Why It Matters for RAG Builders
OBaI provides a robust, modular framework for building AI-driven financial research and trading systems, enabling developers to integrate specialized agents, data sources, and backtesting tools into a unified platform.
