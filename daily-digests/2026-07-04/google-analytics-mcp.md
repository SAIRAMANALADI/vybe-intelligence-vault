## Summary
A Model Context Protocol (MCP) server that enables AI agents and copilots to directly access and analyze Google Analytics 4 (GA4) data with built-in schema discovery, metric auto-aliasing, and server-side aggregation for seamless integration with AI workflows.

## Key Features
- Autonomous self-healing for schema and query errors
- Metric auto-aliasing to prevent common query failures
- Server-side aggregation for efficient data processing
- Multi-platform support (Claude, ChatGPT, Gemini, VS Code, etc.)
- Live schema discovery and troubleshooting guides

## Why It Matters for RAG Builders
It bridges AI agents with real-time GA4 data, enabling autonomous analysis and reducing manual data wrangling for AI-driven decision-making.
