## Summary
ra-mcp is an MCP (Model Context Protocol) server and CLI for accessing and interacting with transcribed historical documents from the Swedish National Archives (Riksarkivet). It enables full-text search, document browsing, and archival research through MCP-compatible clients or a standalone CLI.

## Key Features
- Full-text search across millions of AI-transcribed historical pages
- Handwritten text recognition and document viewing capabilities
- Interactive terminal browser (TUI) for archival research
- CLI and MCP server for integration with LLM clients
- Supports multiple datasets including court records, biographical lexicons, and geographical records

## Why It Matters for RAG Builders
It provides critical access to large-scale historical document datasets for RAG systems, enabling enriched context with culturally significant and domain-specific knowledge.
