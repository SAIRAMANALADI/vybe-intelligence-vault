## Summary
A CLI tool that bridges user feedback from a web widget to terminal-based workflows, enabling AI agents or developers to triage, claim, and resolve feedback items efficiently. It integrates with an AI-powered platform for automated analysis and user notifications upon resolution.

## Key Features
- Pulls user feedback directly into the terminal for agent or developer review
- Supports JSON output for seamless AI agent integration
- Enables claiming, resolving, and dismissing feedback items with status updates
- OTP-based authentication for secure access
- Self-hosting support for custom API endpoints

## Why It Matters for RAG Builders
It streamlines the feedback-to-fix pipeline for AI agents by providing a terminal interface to pull, triage, and resolve user-reported issues, reducing manual overhead in RAG workflows.
