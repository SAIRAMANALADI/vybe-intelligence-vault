## Summary
BDH Graph Harness transforms Obsidian vaults into dynamic knowledge graphs using Hebbian synaptic plasticity for adaptive retrieval. It combines vector embeddings, BM25 lexical search, and real-time graph visualization to enable context-aware, self-organizing knowledge systems.

## Key Features
- Converts Obsidian notes into neurons with embeddings and wikilinks into synapses
- Implements Hebbian synaptic plasticity for adaptive, self-organizing retrieval
- Hybrid search combining vector similarity and BM25 with adaptive thresholding
- Real-time visualization of graph activation and synaptic weight updates
- MCP server and Hermes Agent integration for seamless AI tooling compatibility

## Why It Matters for RAG Builders
BDH Graph Harness enables AI systems to dynamically organize and retrieve knowledge from personal or organizational vaults with biologically inspired learning, enhancing RAG pipelines with contextual awareness and adaptive retrieval.
