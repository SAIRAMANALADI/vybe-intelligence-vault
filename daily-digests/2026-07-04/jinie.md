## Summary
Jinie is an AI-driven desktop pipeline that converts text descriptions (including English, Urdu, and Roman Urdu) into production-ready React Native applications with Firebase hosting. It leverages self-trained ML models for requirement extraction, UI layout recommendation, and code generation, ensuring local execution and reproducibility.

## Key Features
- Converts freeform text prompts into React Native apps with Firebase hosting
- Supports English, Urdu, and Roman Urdu for requirement input
- Uses self-trained DistilBERT and CodeT5-small models for NLP and code generation
- Provides a decoupled desktop client-server architecture with live preview and testing
- Includes automated verification, preflight checks, and Firebase deployment

## Why It Matters for RAG Builders
Jinie accelerates mobile app development by automating the translation of requirements into production-ready React Native code, reducing manual effort and enabling rapid prototyping for AI engineering teams.
