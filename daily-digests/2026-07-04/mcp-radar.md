## Summary
mcp-radar is a static GitHub Pages site that maintains an auto-updating directory of MCP servers, providing both a browsable interface and a JSON endpoint for programmatic access. The data is regenerated daily via GitHub Actions using curated sources like best-of-mcp-servers and optional enrichment from mcp-servers-hub.

## Key Features
- Auto-updating directory of MCP servers via GitHub Actions
- Static site with browsable interface and JSON endpoint
- Daily data regeneration using GitHub API and curated sources
- Monetization paths (sponsorships, paid curation, alerts)
- Local development support via static HTML

## Why It Matters for RAG Builders
It provides a centralized, auto-updated directory of MCP servers that simplifies discovery and integration for RAG builders.
