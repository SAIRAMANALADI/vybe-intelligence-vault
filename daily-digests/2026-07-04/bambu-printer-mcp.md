## Summary
A Model Context Protocol (MCP) server for controlling Bambu Lab 3D printers on Windows, enabling STL/3MF file handling, slicing integration with BambuStudio, and direct printer control via MQTT.

## Key Features
- MCP server for Bambu Lab printer integration with external tools
- STL and 3MF file handling for 3D model preparation
- Direct printer control via MQTT and Bambu Studio integration
- Windows-native setup with simple installation process
- Automation of print workflows and status monitoring
