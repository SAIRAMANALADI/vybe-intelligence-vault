## Summary
Mylo is a terminal-based agent built with Langchain and Textual for analyzing GitHub and GitLab repositories. It simplifies code discovery and analysis by fetching, retrieving, and inspecting files, leveraging AST for deep analysis across 16 programming languages.

## Key Features
- Supports multiple LLM providers (OpenAI, Anthropic, Google, Groq) with configurable API keys and memory limits
- Fetches, retrieves, and analyzes files from GitHub/GitLab repositories with AST-based deep analysis
- Terminal-based TUI with token usage tracking and dynamic context trimming
- Model profiles for quick switching between configurations and memory limits
- Supports 16 programming languages for AST parsing and analysis

## Why It Matters for RAG Builders
Mylo streamlines code discovery and analysis for AI engineers by integrating repository interaction with LLM capabilities, enabling efficient retrieval and inspection of codebases for RAG pipelines.
