## Summary
An MCP (Model Context Protocol) server that provides global weather data, alerts, historical records, and specialized features like air quality, marine conditions, and wildfire tracking to AI systems. It integrates NOAA and Open-Meteo APIs without requiring API keys.

## Key Features
- Global weather forecasts with 16-day coverage and hourly/daily granularity
- Comprehensive air quality, marine, and wildfire monitoring
- Historical weather data dating back to 1940
- Smart caching system to optimize API calls and reduce latency
- Location search, saved locations, and timezone-aware timestamps

## Why It Matters for RAG Builders
It provides essential real-time and historical weather data to AI systems, enabling accurate contextual responses for applications requiring environmental awareness.
