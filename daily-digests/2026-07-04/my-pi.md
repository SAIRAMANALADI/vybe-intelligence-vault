## Summary
A minimalist, curated setup for the Pi coding agent featuring 10 packages, 59 skills, and a 10-step autonomous workflow designed to eliminate bloat and prioritize CLI-based interactions over MCP servers.

## Key Features
- 10-step autonomous workflow for end-to-end coding tasks
- Curated selection of 59 skills optimized for efficiency and minimalism
- Integration with external CLIs (Bright Data, Octocode, GitHub CLI) for web and code research
- Persistent memory and session management via pi-hermes-memory
- LSP-based diagnostics and error checking with pi-lens
