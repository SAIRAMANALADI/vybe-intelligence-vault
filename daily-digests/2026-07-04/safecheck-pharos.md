## Summary
SafeCheck is an on-chain security agent designed for the Pharos Agent Carnival, auditing smart contracts and tokens for dangerous patterns, simulating transactions to detect honeypots, and exposing its services via a paid agent-to-agent x402 protocol. It includes a Solidity-based attestation registry and a TypeScript-based payment loop for secure interactions.

## Key Features
- Pre-transaction safety audits for smart contracts and tokens
- Wallet risk assessment for approvals and honeypots
- On-chain attestation registry for security verdicts
- Paid agent-to-agent service via x402 protocol
- Automated deployment and testing with Foundry
