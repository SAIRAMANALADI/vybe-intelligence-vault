## Summary
A comprehensive wrapper for the crt.sh Certificate Transparency search engine, providing access via Skills, MCP, CLI, and Go SDK. It enables AI agents, developers, and security professionals to search CT logs, retrieve certificates, investigate CAs, and perform compliance checks.

## Key Features
- Multi-modal access (Skills, MCP, CLI, Go SDK) for seamless integration with AI agents and human workflows
- Comprehensive crt.sh API wrapper supporting 22+ search types, 7 match modes, and advanced filtering
- Built-in certificate linting (cablint, x509lint, zlint, keylint) and compliance checks
- Automated sync between Skills, MCP server, CLI, and SDK for consistency and reliability
- Pre-built binaries and one-click setup for popular AI tools like Claude Code and Cursor

## Why It Matters for RAG Builders
It provides a unified, AI-friendly interface to crt.sh's Certificate Transparency data, enabling automated security monitoring, certificate analysis, and threat intelligence for RAG pipelines.
