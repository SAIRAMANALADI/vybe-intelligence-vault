## Summary
Argus is a retrieval platform for AI agents that routes search across 14 providers, recovers dead URLs, captures site content, and builds local research packs with traceable artifacts. It supports zero-key setups, topology-aware acquisition, and multi-turn sessions for conversational context.

## Key Features
- Routes search across 14 providers with budget-aware routing and automatic fallback
- 12-step content extraction with quality gates and residential IP optimization
- Dead URL recovery using Wayback Machine and archive fallbacks
- Opinionated workflows for capturing sites, recovering articles, and building research packs
- Supports HTTP API, CLI, MCP server, and Python SDK for seamless integration

## Why It Matters for RAG Builders
Argus streamlines reliable retrieval, content extraction, and evidence persistence for RAG pipelines, eliminating the need to stitch multiple APIs together.
