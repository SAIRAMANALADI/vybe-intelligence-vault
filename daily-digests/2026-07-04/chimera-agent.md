## Summary
Chimera is an open-source AI agent framework that combines multiple AI models to solve complex tasks, remembers past interactions, and learns from experience. It integrates tool usage, self-verification, and safety checks to autonomously complete goals while improving over time.

## Key Features
- Blends multiple AI models for higher accuracy on complex queries using a judge-synthesizer pipeline
- Autonomously plans, executes, and verifies tasks with tool usage and self-correction (verify-or-revert)
- Long-term memory system that consolidates knowledge and learns reusable skills from repeated tasks
- Multi-platform deployment with support for Discord, Telegram, Slack, and more as chat bots
- Built-in safety checks, sandboxed code execution, and audit logging for secure operation

## Why It Matters for RAG Builders
Chimera provides a robust, self-improving framework for building autonomous AI agents that can reason across multiple models, execute tasks reliably, and adapt over time, making it essential for RAG builders seeking advanced agentic capabilities.
