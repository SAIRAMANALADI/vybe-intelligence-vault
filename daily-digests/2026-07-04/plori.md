## Summary
Plori provides persistent cloud computers for AI agents, offering real disk storage, tools, and memory that survive between conversations. Agents scale to zero when idle, and users interact with them via a web app or MCP/REST APIs.

## Key Features
- Remote MCP server with streamable HTTP transport for seamless integration
- Persistent agent machines with real disk storage and tools
- Idle agents scale to zero to optimize resource usage
- Supports OAuth 2.1 and API key authentication for headless environments
- 15 tools across agents, runs, human-in-the-loop, and scheduling

## Why It Matters for RAG Builders
Plori enables AI agents to maintain persistent, stateful environments with real tools and storage, bridging the gap between stateless LLMs and practical, long-running agent systems.
