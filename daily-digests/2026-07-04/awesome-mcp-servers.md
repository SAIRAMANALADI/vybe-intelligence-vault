## Summary
A community-curated directory and hosted registry of Model Context Protocol (MCP) servers, providing structured profiles, searchable APIs, and install-config previews for AI agents and applications. The repository aggregates 7,747 unique MCP server links and normalizes them into a searchable index with public API access.

## Key Features
- Hosted, searchable registry of 7,747+ MCP servers with structured profiles
- Public API for querying servers by category, transport, auth type, and more
- Automated generation of install-config previews for popular MCP clients
- Community-driven cleanup queue for maintaining catalog quality
- Badge system for MCP server READMEs linking to indexed profiles

## Why It Matters for RAG Builders
It provides a centralized, searchable registry of MCP servers that AI agents can use to discover, verify, and integrate tools dynamically, reducing setup friction and improving interoperability.
