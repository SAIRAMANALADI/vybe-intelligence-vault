## Summary
An AI-powered enterprise complaint management system that monitors Gmail inboxes in real time, extracts structured ticket data using a local LLM, orchestrates processing via a LangGraph multi-agent state machine, and presents insights through an interactive Streamlit dashboard with dual SQLite and Excel storage.

## Key Features
- Real-time Gmail monitoring with push/polling fallback modes
- LangGraph-based multi-agent pipeline for structured complaint processing
- Local LLM (Llama 3.1 8B via Ollama) for zero-cost, private AI extraction
- Dual SQLite + Excel storage with two-way synchronization
- Interactive Streamlit dashboard for real-time insights and status management
