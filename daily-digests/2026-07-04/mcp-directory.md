## Summary
Protodex is a comprehensive index of 18,146+ Model Context Protocol (MCP) servers, enabling users to discover, search, and categorize MCP-compatible tools for AI agents and applications like Claude and Cursor. It provides a browsable directory with metadata, tools, and rankings to help users find battle-tested solutions.

## Key Features
- Searchable index of 18,146+ MCP servers with instant filtering and ranking
- Weekly automated updates via GitHub scraper to maintain current data
- 13 categorized sections (AI/LLM, Database, DevOps, etc.) for easy navigation
- Individual server pages with metadata, tools, and related repositories
- Open-source tooling to scrape, categorize, and export MCP server data
