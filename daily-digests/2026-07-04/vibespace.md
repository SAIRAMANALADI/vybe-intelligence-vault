## Summary
VibeSpace is a backend-agnostic web workspace designed for managing multiple concurrent coding agent CLI sessions (e.g., Claude Code, Codex) from a browser. It provides a tiling window manager, structured chat view, file explorer, and code editor with persistence, multi-session support, and dual-mode (terminal/chat) interfaces.

## Key Features
- Backend-agnostic adapter system supporting Claude Code, Codex, and custom backends
- Dual-mode sessions: terminal (TUI via xterm.js) and structured chat view with markdown rendering
- Persistent multi-session workspace with dtach for survival across server restarts and dropped connections
- Tiling window manager with virtual desktops, tab groups, and customizable UI layouts
- Advanced features like session forking, search, minimap navigation, and interactive permissions

## Why It Matters for RAG Builders
VibeSpace provides a unified, persistent, and scalable interface for managing multiple coding agents simultaneously, eliminating terminal fragmentation and enabling seamless collaboration and task switching for AI engineering workflows.
