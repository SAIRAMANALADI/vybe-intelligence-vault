## Summary
Logica Pilot is an AI-native browser with an embedded autonomous AI copilot that replaces Playwright for web automation tasks. It uses semantic perception (indexed element maps) to reduce token usage by 5–185× compared to raw HTML or screenshot-based approaches, while learning site-specific patterns for improved efficiency over time.

## Key Features
- Semantic perception via indexed element maps (5–185× fewer tokens than raw HTML/screenshot approaches)
- Site memory system that learns and warm-starts tasks for improved efficiency and reliability over time
- Zero-dependency pure CDP engine with headless and desktop modes
- CLI and MCP integration for seamless agent ecosystem compatibility (Claude Desktop, Cursor, Cline)
- Persistent session management (local login state, cookies, and history)

## Why It Matters for RAG Builders
Logica Pilot drastically reduces token costs and improves reliability for RAG systems by replacing raw HTML or screenshot-based web perception with semantic, indexed element maps and site-specific memory, enabling more efficient and scalable AI-driven web automation.
