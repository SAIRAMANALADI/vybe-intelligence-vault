## Summary
A Claude Code Agent Skill that autonomously implements, tests, and fixes Flutter applications by running them on real devices or simulators, interacting with the UI via Semantics labels, and enforcing deterministic Patrol assertions. It supports both iOS and Android with a self-repairing loop and CI-ready verification layers.

## Key Features
- Autonomous implement-test-fix loop for Flutter apps with ≤5 self-repair rounds
- Element-driven interaction via Semantics labels for precise UI tapping and verification
- Deterministic Patrol assertions by Key for replayable, CI-ready regression testing
- Cross-platform support (iOS and Android) with platform-specific edge cases abstracted
- Offline fixture testing for pure logic validation before device interaction

## Why It Matters for RAG Builders
It enables fully autonomous Flutter development workflows by bridging the gap between AI agents and mobile UI testing, ensuring reliable, deterministic, and CI-compatible automation for Flutter applications.
