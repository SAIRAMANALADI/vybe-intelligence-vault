## Summary
A cross-platform mobile and desktop client for controlling a local AI coding agent via an authenticated tunnel. Enables remote interaction with files, git operations, chat, and media previews directly from Android or macOS devices.

## Key Features
- Cross-platform native UI for Android and macOS
- Direct connection to local AI agent via authenticated tunnel
- Real-time chat, file editing, and git operations
- Media streaming (images, videos) without full downloads
- QR code-based machine pairing for seamless setup

## Why It Matters for RAG Builders
It provides a critical mobile and desktop interface for managing and interacting with local AI coding agents, enabling remote control and real-time collaboration without cloud dependency.
