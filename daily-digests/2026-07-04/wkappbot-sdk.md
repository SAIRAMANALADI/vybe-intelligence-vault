## Summary
WKAppBot SDK enables AI agents to control Windows and Android applications without screen takeover, using UIA, Win32, CDP, and ADB for automation. It supports focusless operation, self-healing UI recovery, and multi-AI delegation for tasks like trading bots, browser AI sessions, and legacy app automation.

## Key Features
- Focusless automation using UIA and Win32 PostMessage to avoid screen takeover
- Self-healing UI recovery with OCR and Vision API fallback for owner-drawn controls
- Multi-AI delegation (GPT, Gemini, Claude) for parallel task execution and debate
- Experience DB for caching automation patterns and reducing redundant computations
- Android automation via ADB with unified command surface for cross-platform control

## Why It Matters for RAG Builders
WKAppBot SDK bridges the gap between AI agents and real-world applications by enabling reliable, focusless automation with self-healing capabilities, making it essential for building robust RAG systems that interact with desktop and mobile apps.
