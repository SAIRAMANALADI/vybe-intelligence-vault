## Summary
WebSculpt provides procedural memory for AI agents by converting proven web browsing workflows into reusable, locally stored CLI commands. It eliminates redundant exploration by distilling successful paths into domain-specific actions that can be invoked directly, saving context space and improving efficiency for repeated tasks.

## Key Features
- Converts repetitive web browsing tasks into reusable CLI commands for zero-cost reuse
- Integrates with existing Chrome sessions to preserve login states and cookies
- Supports both zero-dependency HTTP commands and browser-based automation
- Implements a three-phase skill delivery system (explore, capture, library) for structured workflows
- Provides scope isolation to manage command visibility and reduce context noise
