## Summary
Zero is a local terminal-based AI coding agent that allows users to inspect repositories, edit files, run commands, and manage sessions with fine-grained control over models and permissions. It supports both interactive TUI and headless execution modes.

## Key Features
- Interactive TUI with model/provider pickers, slash commands, and live tool rendering
- Headless execution mode for scripting and CI/CD integration
- Fine-grained permission control for file writes, shell commands, and network access
- Support for 25+ AI providers and local models (Ollama, LM Studio)
- Durable local sessions with resumable, searchable, and forking capabilities

## Why It Matters for RAG Builders
Zero empowers RAG builders with a secure, local-first agent framework that integrates seamlessly into development workflows while maintaining strict control over permissions and context.
