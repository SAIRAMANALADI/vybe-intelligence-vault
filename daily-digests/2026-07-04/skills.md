## Summary
A Claude Code Skills package that provides slash commands for managing user feedback, enabling AI agents to triage, analyze, and resolve issues directly from the terminal. It integrates with the Make This Better platform to streamline bug fixes and feature requests without context-switching.

## Key Features
- Slash commands for feedback management (e.g., /makethisbetter pick, resolve, list)
- Automated context collection (screenshots, console errors, AI analysis) for issue resolution
- Integration with Make This Better CLI and API for seamless workflows
- Support for self-hosted instances via configurable API endpoints
- Identity verification (JWT) for authenticated feedback submission
