## Summary
A self-hosted TypeScript integration that bridges Devin AI into Telegram, enabling users to interact with an AI software engineer directly via Telegram commands and chat sessions with persistent state management.

## Key Features
- Telegram command-based interaction with Devin AI
- Persistent session state via PostgreSQL for restart recovery
- Adaptive polling for efficient updates
- Built-in templates for common AI tasks
- Pull request notifications from Devin sessions
