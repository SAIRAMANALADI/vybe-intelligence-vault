## Summary
DeadLibrary-CLI is a deterministic code generation framework that enables AI coding agents to produce consistent, production-ready code via structured CLI commands. It replaces probabilistic LLM output with a deterministic compiler, ensuring correctness and reducing hallucinations, token waste, and API costs.

## Key Features
- Macro commands for scaffolding complete Angular components, services, and themes in a single command
- Artifact commands for precise code fragment generation in 8 languages (TypeScript, Python, Java, etc.)
- Universal expression syntax for cross-language logic compilation without rewriting
- Intent tracking via manifests and command parity files to ensure deterministic rebuilds
- Integration with popular AI coding agents (Claude Code, Cursor, Windsurf, etc.)

## Why It Matters for RAG Builders
DeadLibrary-CLI eliminates hallucinations and inconsistencies in AI-generated code by offloading deterministic compilation to a CLI, making it essential for building reliable RAG pipelines.
