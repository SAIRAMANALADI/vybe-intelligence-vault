## Summary
Portkey Admin MCP Server exposes the full Portkey Admin API as an MCP (Model Context Protocol) server, providing 150 tools for managing prompts, configs, API keys, analytics, and more. It enables programmatic control over Portkey's enterprise features via a standardized MCP interface.

## Key Features
- 150+ tools covering prompts, configs, API keys, analytics, and user management
- Supports both stdio and experimental HTTP transport (Streamable HTTP/SSE)
- Enterprise-gated tools with clear scope requirements (e.g., org-level analytics)
- Configurable tool domains for focused subsets (e.g., prompts, analytics)
- Full audit trail and logging capabilities for compliance and debugging

## Why It Matters for RAG Builders
