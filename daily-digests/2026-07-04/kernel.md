## Summary
A modular, open-source terminal AI agent framework with 35+ specialist agents, 600+ tools, and support for 20+ AI providers. It includes a POSIX-like OS substrate (agent-os), provenance engineering for regulated industries, and orchestration pipelines for multi-agent workflows.

## Key Features
- 35+ specialist agents with auto-routing for tasks like coding, research, finance, and security
- 600+ built-in tools spanning files, git, web, databases, creative apps, and scientific computing
- Support for 20+ AI providers with zero lock-in and offline/local model options
- POSIX-like OS substrate (agent-os) with capabilities, namespaces, quotas, audit trails, and vaults
- Provenance and orchestration engineering for regulated industries and multi-step workflows
