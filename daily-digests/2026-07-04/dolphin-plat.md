## Summary
Dolphin is an experimental CLI-based AI assistant that extends LLM capabilities through a modular skills and plugins system, enabling tool calls, conversation management, file operations, and user interaction with configurable AI effort levels.

## Key Features
- Modular skills and plugins system for extensible AI capabilities
- Configurable AI effort levels (fine, normal, high) for task depth control
- Built-in file operations, calculator, web search, and PowerShell execution with safety confirmations
- Embedding model integration for semantic search and RAG workflows
- Persistent configuration, backup management, and DPC file protection for security

## Why It Matters for RAG Builders
It provides a flexible framework for building AI agents with tool-calling and skill-based extensibility, critical for RAG pipelines requiring dynamic interaction and file/system operations.
