## Summary
memi provides a local design intelligence layer for AI coding agents to audit, understand, and safely modify real-world shadcn/Tailwind products. It generates evidence-backed interface memory including tokens, components, screenshots, routes, UX audits, and registry exports to guide AI-driven frontend changes.

## Key Features
- Generates design-agent briefs with evidence commands and cost controls for AI workflows
- Performs UX, craft, and diagnostic audits to identify interface risks and opportunities
- Extracts and normalizes tokens, components, and registry items for AI consumption
- Provides MCP server and agent skill kits for integration with Codex, Claude Code, Cursor, and other AI tools
- Supports Figma-independent and Figma-integrated workflows for comprehensive interface understanding

## Why It Matters for RAG Builders
It bridges the gap between AI coding agents and real-world design systems, enabling agents to operate with evidence-backed context rather than guesswork.
