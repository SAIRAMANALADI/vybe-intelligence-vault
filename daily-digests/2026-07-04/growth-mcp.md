## Summary
Growth MCP is an MCP server that packages growth marketing domain knowledge into actionable tools for AI assistants like Claude. It enables direct integration of growth analytics, campaign design, retention analysis, and A/B testing into chat workflows without requiring manual data processing.

## Key Features
- 25+ pre-built tools for growth marketing analytics (retention, A/B testing, churn prediction, voucher design)
- Direct integration with AI assistants (Claude, Cursor) via MCP protocol
- Supports multiple data sources (CSV, BigQuery, Mixpanel) for flexible analytics
- Domain-specific knowledge layer with prompts, resources, and benchmarks
- Local-first processing with no server uploads, ensuring data privacy

## Why It Matters for RAG Builders
It bridges the gap between raw growth marketing data and AI-driven decision-making by providing structured, actionable tools that AI assistants can invoke directly in chat, accelerating experimentation and reducing manual analysis overhead.
