## Summary
Ogcode is a token-efficient agentic coding workbench designed to optimize context engineering for AI-driven development. It curates relevant context for each turn, reducing token usage by 70%+ while improving accuracy, and enables infinite context sessions by recalling facts from a persistent knowledge graph instead of replaying full transcripts.

## Key Features
- Context engineering: Extracts only task-relevant context per turn, reducing token usage by 70%+ and improving model accuracy.
- Infinite context: Uses agentic session memory to recall facts from a knowledge graph, enabling unbounded conversations without hitting model context limits.
- Plan Mode: Decomposes user goals into structured tasks, executes them in parallel via isolated git worktrees, and auto-generates pull requests.
- Git-native workflow: Integrates git worktrees for conflict-free parallel task execution and automated PR creation.
- Multi-model support: Works with any LLM, from frontier models to local small models, without performance degradation.
