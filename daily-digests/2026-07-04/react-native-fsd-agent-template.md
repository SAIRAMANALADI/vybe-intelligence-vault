## Summary
A React Native + Expo template with Feature-Sliced Design (FSD) architecture, powered by a Claude Code AI agent harness. It automates the full app development lifecycle from ideation to deployment, including continuous post-launch improvement loops.

## Key Features
- AI-driven full-lifecycle app development with 10 specialized agents and 9 skills for automation
- Feature-Sliced Design (FSD) architecture for modular and scalable code organization
- Automated pipeline from ideation to deployment, including post-launch continuous improvement loops
- Production-ready modules for ads (AdMob), analytics (Firebase), and secure storage
- Built-in quality checks, testing (Vitest), and linting (ESLint + Prettier) for robust code
