## Summary
KamehaDB is a local-first, cross-platform desktop database workspace that unifies SQL, NoSQL, vector, and ledger databases into a single Tauri-based app. It enables users to browse schemas, run queries, interact with AI using real schema context, and manage database migrations all while keeping metadata local.

## Key Features
- Unified workspace for 12+ database engines (SQL, NoSQL, vector, ledger)
- AI chat with real schema context for generating queries, pipelines, and commands
- Schema timeline, diff, and migration assistant for tracking and applying changes
- Local-first architecture with no telemetry or hosted proxy
- Embedded native tooling (PSQL terminal, MongoDB explorer, Redis browser, Qdrant 3D map)

## Why It Matters for RAG Builders
KamehaDB streamlines database interaction and AI-assisted query generation for RAG builders by providing a unified, local-first workspace with real schema context and migration tools.
