## Summary
SI Coder Agent is a modular set of Claude Code slash commands (`/sc-*`) that automate zero-human full-stack deployment of Next.js + Convex applications to self-hosted or managed environments. It orchestrates GitHub, Dokploy, Vercel, Convex, and DNS to deliver a live, verified URL without manual intervention.

## Key Features
- Modular slash commands (`/sc-*`) for end-to-end deployment workflows
- Supports self-hosted (Dokploy + Convex) and managed (Vercel + Convex Cloud) paths
- Orchestrates GitHub, DNS, backend, and frontend deployments with idempotent operations
- Security-hardened with no-shell execution, TLS verification, and secret redaction
- Includes stubs for extensibility (e.g., Cloudflare, Stripe, Clerk) and comprehensive testing

## Why It Matters for RAG Builders
It enables AI agents to autonomously deploy full-stack applications end-to-end, reducing manual DevOps overhead and accelerating RAG/AI stack development.
