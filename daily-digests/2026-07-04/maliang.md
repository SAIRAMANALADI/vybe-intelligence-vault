## Summary
Maliang is an AI agent skill for design systems that converts prose-first DESIGN.md specifications into executable UI code across multiple frameworks. It provides a six-command pipeline from design intent to framework-specific implementations, including HarmonyOS, Flutter, and Element Plus.

## Key Features
- Six-command pipeline from DESIGN.md to framework-specific code (HarmonyOS, Flutter, Element Plus)
- Prose-first design methodology with markdown-based specifications
- Real-time preview with Element Plus and device templates
- Comprehensive reference documentation for design dimensions and framework mappings
- Supports 13 design system styles with reusable UI markdown components
