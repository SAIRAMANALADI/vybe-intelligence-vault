## Summary
A Claude Code-style coding agent featuring a Python core with a Rust/Ratatui full-screen TUI or rich CLI fallback. It supports agent loops, verify harnesses, context engineering, and two wire protocols (OpenAI-compatible and Anthropic native) for production use, benchmarking, and research.

## Key Features
- Full-screen TUI with live plan panel, fuzzy file completion, and tool-approval modals
- Independent reviewer/verifier harness for structured feedback and correctness verdicts
- Progressive context compaction and project memory auto-recall for efficient token usage
- Dual protocol support (OpenAI-compatible and Anthropic native) with streaming and multi-provider switching
- Extensible architecture with MCP servers, custom slash commands, and lifecycle hooks

## Why It Matters for RAG Builders
It provides a production-ready, extensible agent framework for AI-assisted coding with robust verification and context management, essential for building reliable RAG systems.
