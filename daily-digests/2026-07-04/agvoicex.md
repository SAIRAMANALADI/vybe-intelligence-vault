## Summary
AgVoiceX is a self-hosted, local-first AI voice-agent platform enabling teams to build multi-tenant business agents with FastAPI, Next.js, PostgreSQL, and local AI providers like Ollama or LM Studio. It provides a production-ready foundation for privacy-focused, portable AI agent deployments with voice capabilities.

## Key Features
- Multi-tenant agent configuration with tenant-aware APIs and persistence
- Local-first AI runtime with Ollama/LM Studio integration and structured intent detection
- Production-grade admin console with Next.js, TypeScript, and Tailwind for managing agents, prompts, and workflows
- Voice agent capabilities via browser microphone streaming, local STT/TTS, and WebSocket orchestration
- Business workflow automation with n8n integration and PostgreSQL-backed domain models

## Why It Matters for RAG Builders
AgVoiceX provides a critical foundation for building privacy-focused, production-ready AI voice agents with multi-tenancy and local AI runtime support, reducing dependency on hosted LLM services.
