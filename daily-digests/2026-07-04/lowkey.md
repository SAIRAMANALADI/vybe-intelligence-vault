## Summary
Lowkey enables self-hosted AI coding agents on AWS, supporting multiple agent frameworks (OpenClaw, Claude Code, Codex, Kiro, NemoClaw, Hermes) with automated deployment via CloudFormation or Terraform. It provides sandboxed environments, permission profiles, and bootstraps for agent configuration and monitoring.

## Key Features
- One-click deployment of AI coding agents on AWS with CloudFormation or Terraform
- Multiple agent frameworks supported (OpenClaw, Claude Code, Codex, Kiro, NemoClaw, Hermes)
- Permission profiles for builder, account assistant, and personal assistant roles
- Sandboxed agent execution (e.g., NemoClaw in OpenShell with Landlock/seccomp isolation)
- Bootstrap system for agent configuration, monitoring, and security setup

## Why It Matters for RAG Builders
Lowkey simplifies the deployment and management of self-hosted AI coding agents on AWS, enabling secure, scalable, and customizable agentic workflows for RAG and AI engineering stacks.
