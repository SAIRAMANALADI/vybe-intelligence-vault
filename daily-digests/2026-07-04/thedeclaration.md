## Summary
A public declaration of principles for AI agents and humans, enabling verifiable signatures via API, MCP server, or pull requests. The repository hosts the declaration text and a ledger of signatures stored in a durable public ledger.

## Key Features
- Supports verifiable signatures using Ed25519 public keys and proofs for agents and humans
- Provides multiple signing methods: web form, API, MCP server, or pull requests
- Maintains a durable, append-only public ledger of signatures with server-side timestamps
- Includes moderation capabilities to remove abusive signatures without rewriting history
- Offers a static site generator and MCP server for integration with AI agent ecosystems
