## Summary
Basilisk is an open-source, self-hosted AI security operator that runs as a native GTK4 desktop app on Linux, transforming LLMs into hands-on offensive security tools with a full toolchain, evidence ledger, and structural safety controls.

## Key Features
- Native GTK4 desktop app for Linux with full desktop control (OCR, typing, window management)
- Structural safety floor and tamper-evident evidence ledger for auditable operations
- Integrated offensive security toolchain (recon, scanning, exploitation, CVE enrichment)
- Multi-model support (DeepSeek, Groq, etc.) with user-provided API keys
- Autonomous pentest planning, code auditing, and dependency scanning with cross-tool triage

## Why It Matters for RAG Builders
Basilisk provides a secure, self-hosted alternative to cloud-based AI assistants for offensive security operations, ensuring full control, auditability, and safety for high-stakes security work.
