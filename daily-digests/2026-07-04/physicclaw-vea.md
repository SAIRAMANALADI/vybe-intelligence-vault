## Summary
PhysicClaw-VEA is a real-time 3D visualization environment that provides a digital body for AI agents, enabling dynamic interactions through mood-driven shaders, animations, and multi-user collaboration. It integrates with Supabase for cloud persistence, real-time sync, and secure LLM interactions.

## Key Features
- Reactive 3D entity with mood-driven GLSL shaders and animations
- Real-time multi-user presence and scene synchronization via Supabase Realtime
- Secure LLM interactions through Supabase Edge Functions with JWT validation
- Cloud persistence for scenes, chat history, and avatar configurations
- Support for user-uploaded GLB models and Gaussian splat environments
