## Summary
Senpi is an opinionated fork of the Pi coding agent framework, providing a self-extensible interactive coding agent with multi-provider LLM support, tool calling, and state management. It includes a CLI, runtime, and unified LLM API for building and deploying AI agents.

## Key Features
- Unified multi-provider LLM API supporting OpenAI, Anthropic, Google, and more
- Interactive coding agent CLI with permission management and containerization support
- Agent runtime with tool calling, state management, and extensible architecture
- Terminal UI library with differential rendering for enhanced user experience
- Strict supply-chain hardening with pinned dependencies and automated security checks

## Why It Matters for RAG Builders
Senpi provides a robust, extensible foundation for building AI agents with multi-provider LLM support, making it essential for developers integrating advanced agentic workflows into RAG systems.
