## Summary
A production-grade knowledge base operating system that enables AI agents to compile raw sources into persistent, cross-linked Markdown wikis with concurrency control, multi-provider LLM integration, full-text search, and community detection. Designed for agent-native workflows with no database or API lock-in.

## Key Features
- Compiles raw sources into persistent, cross-linked Markdown wikis with concurrency control and atomic writes
- Multi-provider LLM integration with LiteLLM fallback, structured output, and retry mechanisms
- SQLite FTS5 full-text search with SHA256 freshness detection and incremental updates
- Louvain community detection for knowledge graph optimization and insights
- Agent-native MCP server for programmatic access with zero subprocess overhead

## Why It Matters for RAG Builders
It transforms raw documents into a living, self-maintaining wiki that agents can query without repeated retrieval, reducing RAG latency and cost while enabling persistent knowledge compounding.
