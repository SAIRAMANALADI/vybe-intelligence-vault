## Summary
hotdog is a lightweight, zero-dependency AI agent framework designed for tool calling and extensibility. It connects to OpenAI-compatible LLM APIs, manages conversation context, and executes tools through a hook-driven architecture, prioritizing simplicity and minimal setup.

## Key Features
- Zero-dependency architecture with Bun runtime for rapid execution
- Extensible hook-driven system for tools, CLI commands, and behaviors
- Support for Model Context Protocol (MCP) servers for third-party tool integration
- Profiles and aspects for customizable agent behavior and roles
- Interactive CLI, one-shot prompts, and web UI with real-time streaming

## Why It Matters for RAG Builders
hotdog provides a minimal, extensible foundation for building AI agents with tool-calling capabilities, reducing setup friction while enabling rapid prototyping and integration with existing systems.
