## Summary
dev-backlog provides a local sprint execution hub that synchronizes with GitHub Issues, enabling AI coding agents (like Claude Code or Codex) and humans to collaborate using a shared Markdown-based sprint file. It replaces traditional issue trackers with a thin local mirror and explicit sync workflows.

## Key Features
- Synchronizes GitHub Issues with a local sprint file for AI/human collaboration
- Explicit sync via GitHub CLI with dry-run support for safety
- Thin task mirror in Markdown for AI agents to read without API calls
- Supports task states ([ ], [~], [x]) for visibility into in-flight work
- Includes helper scripts for sprint initialization, status checks, and progress updates

## Why It Matters for RAG Builders
It bridges the gap between GitHub Issues and AI coding agents by providing a shared execution plan that keeps both humans and AI aligned without requiring new infrastructure.
