## Summary
claude-context-lint is a tool designed to audit and optimize the context usage in Claude AI interactions by analyzing CLAUDE.md files, MCP schemas, and system prompts to identify wasted tokens and improve efficiency.

## Key Features
- Analyzes CLAUDE.md files for token waste
- Audits MCP schemas to ensure optimal context usage
- Identifies redundant or inefficient system prompts
- Provides actionable recommendations for context reduction
- Integrates with Claude API for real-time context evaluation
