## Summary
Angel OS is a federated, constitutional AI-native platform where enterprises run sovereign AI guardians (Leo) on their own infrastructure. It combines Payload CMS, Next.js, React, and PostgreSQL to create a multi-tenant, decentralized ecosystem with built-in token economies, federated governance, and real-time observability.

## Key Features
- Federated governance with sovereign enterprise nodes and decentralized identity
- Constitutional AI with configurable AI provider routing (OpenAI, Google, Cloudflare, etc.)
- Built-in token economy (Angel Tokens, Karma Coins, Legacy Tokens) with blockchain-like ledger
- Real-time observability and self-healing toolchain with multi-channel escalation
- Multi-tenant marketplace with fair revenue splits (60/20/15/5) and works distribution
