## Summary
Demiurge is a lightweight, open-source, and extensible desktop agent engine that integrates local desktop capabilities, project context, tool systems, and LLM endpoints into a controllable agent. It supports role-based interactions, tool execution, memory management, and continuous goal-driven workflows.

## Key Features
- Role and engine separation with structured character cards and runtime policies
- Local-first architecture with Tauri and Rust backend for security and performance
- Hybrid RAG system combining BM25 and remote embedding models for knowledge retrieval
- Sandboxed tool execution with permission overlays and user confirmation gates
- Continuous goal-driven workflows with multi-agent orchestration and workflow DSL

## Why It Matters for RAG Builders
Demiurge provides a modular and secure framework for building controllable desktop agents with integrated RAG, tool execution, and memory systems, making it essential for AI engineers developing production-ready agentic applications.
