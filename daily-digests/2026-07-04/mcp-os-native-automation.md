## Summary
FEOM is a high-performance front-end automation framework for Windows AI agents, enabling deterministic, low-latency UI operations without vision tokens. It leverages native OS APIs (UIA, Win32) to achieve sub-10ms execution times and supports headless or minimized window operations.

## Key Features
- Sub-10ms UI operations via native OS APIs (UIA/Win32)
- Zero vision token dependency for front-end automation
- Headless and minimized window support for background execution
- Hybrid terminal+MCP mode for 73% faster end-to-end workflows
- Production-grade safety checks (focus verification, no Alt+F4)
