## Summary
Opptrix is an open-source AI-powered research assistant for China A-shares, enabling users to query financial data, perform factor screening, backtesting, and generate structured investment analysis via natural language. It supports both web and desktop (Electron) interfaces with a React-based UI and Fastify API backend.

## Key Features
- Natural language querying for stock research with 40+ MCP tools for market data, factors, and institutional insights
- Multi-session chat with persistent history and structured analysis output
- Local SQLite factor database for full-market screening and backtesting
- Cross-platform support (web and Electron desktop) with shared React UI
- Modular architecture with Fastify API, React frontend, and TypeScript monorepo

## Why It Matters for RAG Builders
Opptrix provides a robust, open-source framework for integrating LLM-driven financial research tools with MCP, enabling AI engineers to build and extend investment research assistants with minimal overhead.
