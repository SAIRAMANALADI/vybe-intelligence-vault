## Summary
PyMCP Kit is a lightweight, capability-first MCP (Model Context Protocol) server toolkit for FastAPI, enabling the creation of MCP-compliant servers with streamable HTTP and stdio transports. It supports opt-in draft protocol versions, tool/prompt/resource registries, task execution, and optional authentication hooks.

## Key Features
- Full MCP protocol support with stable and draft revisions (2024-11-05 to 2026-07-28)
- Streamable HTTP and stdio transport options for MCP servers
- Built-in tool, prompt, and resource registries with parameterized templates
- Task-aware execution with progress tracking, cancellation, and result polling
- Optional authentication, OAuth integration, and middleware support

## Why It Matters for RAG Builders
PyMCP Kit simplifies the development of MCP-compliant servers, enabling seamless integration with AI agents and RAG systems by providing a standardized, lightweight, and extensible framework.
