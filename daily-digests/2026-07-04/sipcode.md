## Summary
Sipcode is a command-line tool designed to optimize Claude Code sessions by detecting context bloat, deduplicating file reads, and measuring token savings. It operates locally with zero network calls, providing real-time feedback on session efficiency and cost reduction.

## Key Features
- Context-rot detection to identify bloated sessions and warn users
- Re-read deduplication to skip duplicate file reads and reduce token usage
- Real-time spend telemetry with daily, monthly, and projected cost tracking
- Reproducible benchmarking with a locked 20-task corpus showing 62.6% median savings
- 15 MCP tools for self-introspection and project health scoring
