## Summary
gsearch-mcp is a lightweight Go-based MCP (Model Context Protocol) server that enables AI tools to perform real-time Google searches for grounding responses. It operates as a single binary with zero runtime dependencies, simplifying integration into AI workflows.

## Key Features
- Single Go binary with zero runtime dependencies for easy deployment
- Enables real-time Google search grounding for AI tools via MCP
- Simplifies integration with AI workflows through standardized protocol
- Lightweight and efficient for low-latency search operations
- Designed for seamless embedding in AI agent frameworks
