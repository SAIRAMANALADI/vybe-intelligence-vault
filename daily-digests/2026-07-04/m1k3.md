## Summary
M1K3 is a native AI companion for Apple Silicon Macs that runs entirely on-device, offering local LLM inference, live voice interaction, a personal knowledge graph with RAG, encrypted call transcription, and an MCP server for agent integration—all without cloud dependency or telemetry.

## Key Features
- Full local inference with MLX and Apple Foundation Models (Gemma, Qwen) for privacy and performance
- Live voice interaction with streaming STT and neural TTS (Kokoro) for real-time conversations
- Personal knowledge graph with hybrid FTS + embedding retrieval and grounded citations for RAG
- Encrypted, on-device call transcription and memory with Keychain integration for security
- Local agent with ReAct tool-calling and MCP server for seamless integration with external AI tools

## Why It Matters for RAG Builders
M1K3 enables fully private, on-device AI workflows with RAG and agent capabilities, eliminating cloud dependency and telemetry concerns for developers building secure, local-first AI systems.
