## Summary
Mabara is a push-to-talk voice coding agent that enables hands-free interaction with a codebase using local speech recognition and synthesis. It integrates with Claude Code to allow real-time voice-driven code editing, approvals, and git operations with built-in safety checks.

## Key Features
- Push-to-talk voice interface with pre-roll buffer for seamless interaction
- Streaming speech synthesis with adaptive sentence batching and barge-in support
- Voice-gated tool safety with verbal approvals for edits and shell commands
- Git safety net with automatic checkpoints, revert, and commit capabilities
- Dual-model switching (Haiku/Sonnet) for balancing speed and quality mid-session

## Why It Matters for RAG Builders
Mabara enables hands-free, real-time code editing and interaction, reducing friction for developers who prefer voice commands and providing a novel interface for AI-driven coding assistants.
