## Summary
Agenthood provides a society of specialized AI agents as plain Markdown skill files, designed to enforce software engineering standards, review code, and automate workflows. It integrates with existing AI runtimes like Claude Code or Copilot or operates autonomously via a TypeScript CLI.

## Key Features
- 16 pre-built AI agents (e.g., Reviewer, Architect, Auditor) as Markdown skill files for zero-config integration
- TypeScript CLI for autonomous agent execution, workflows, and project health monitoring
- Multi-LLM provider support with automatic failover and streaming responses
- Built-in memory tiers (short-term, long-term, episodic) and RAG capabilities for contextual reasoning
- Strict adherence to Conventional Commits and automated quality gates for CI/CD pipelines

## Why It Matters for RAG Builders
Agenthood standardizes AI-driven software engineering by providing enforceable, portable agent roles that improve code quality, automate reviews, and reduce human oversight in development workflows.
