## Summary
admtools-mcp is a Windows-based server application that simplifies the management of domains, DNS, email, and billing for hosting platforms like ukraine.com.ua and hosting.xyz. It provides a user-friendly web interface and 13 built-in tools for non-technical users to handle administrative tasks without programming knowledge.

## Key Features
- Domain management (add, edit, delete) for supported platforms
- DNS record configuration (A, MX, CNAME, TXT)
- Email account creation and management
- Billing and subscription tracking
- 13 built-in administrative tools in a single interface
