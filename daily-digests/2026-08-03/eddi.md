## Summary
EDDI is a production-grade, config-driven multi-agent orchestration middleware for conversational AI that coordinates users, AI agents, and business systems through intelligent routing, persistent memory, and API orchestration without requiring custom code.

## Key Features
- Config-driven agent behavior with versioned JSON configurations for safe updates without redeployment
- Built-in support for 12+ LLM providers, MCP, A2A, Slack, OpenAPI, and OAuth 2.0
- Persistent memory, user data management, and cross-session context with HMAC-SHA256 immutable ledger
- Enterprise-grade compliance (GDPR, HIPAA, EU AI Act) with envelope-encrypted secrets vault and SSRF protection
- Dynamic multi-agent group conversations with configurable discussion styles (e.g., Task Force, Peer Review)

## Why It Matters for RAG Builders
EDDI provides a robust, enterprise-ready framework for orchestrating multi-agent systems with built-in compliance and scalability, reducing the complexity of deploying production-grade conversational AI applications.
