## Summary
govctl is a governance-as-code CLI tool designed to bring structured control and traceability to AI-assisted software development workflows. It enables teams to manage RFCs, ADRs, work items, and verification guards directly in their repositories, ensuring AI-generated changes are reviewable, phase-gated, and aligned with governance artifacts.

## Key Features
- Spec-first governance with RFCs, ADRs, and work items as core artifacts
- Verification guards and lifecycle gates for executable completion checks
- Stable CLI interface for agents and humans to interact with governed artifacts
- Brownfield adoption via migration workflows for existing repositories
- Project-wide search and dependency tracking for work items and loops

## Why It Matters for RAG Builders
govctl provides the critical governance layer needed to make AI-assisted development traceable, reviewable, and production-ready by embedding structured artifacts and verification directly into the repository workflow.
