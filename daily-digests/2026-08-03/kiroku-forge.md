## Summary
KirokuForge is a Markdown-first agent skill designed to maintain a durable project memory hub for AI agents and developers. It organizes project context into structured, human-readable files and tracks to preserve essential knowledge without archiving raw conversations.

## Key Features
- Structured Markdown-based project memory with predefined files (STATE.md, ARCHITECTURE.md, DECISIONS.md, etc.)
- Task-specific workstreams (tracks) for focused, durable context management
- Selective reading model to minimize agent context load while preserving critical details
- Automated scaffolding and validation via CLI scripts (init_hub.py, check_hub.py)
- Human-readable and authoritative memory with minimal metadata

## Why It Matters for RAG Builders
KirokuForge ensures AI agents and developers retain essential project context across sessions without rediscovering prior work, making it critical for long-running or complex projects.
