## Summary
comfyui-workflow-skill converts plain English prompts into ready-to-use ComfyUI workflow JSON files, enabling rapid generation of image, video, audio, 3D, and LLM workflows without manual node assembly. It includes 34 built-in templates, 360+ node definitions, and auto model download capabilities.

## Key Features
- Converts plain English prompts into ComfyUI workflow JSON automatically
- Includes 34 built-in templates and 360+ node definitions for diverse tasks
- Supports auto model download for seamless setup
- Works as a skill for AI coding agents like Claude Code and Cursor
- Multi-model support for SD1.5, SDXL, SD3, FLUX, Wan2.2, and more

## Why It Matters for RAG Builders
It accelerates RAG pipeline development by automating the creation of ComfyUI workflows from natural language, reducing manual effort and setup time for AI-generated content tasks.
