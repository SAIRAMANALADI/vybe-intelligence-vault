## Summary
coble is a local, provider-agnostic CLI coding agent designed to make an AI agent's trust boundary explicit and auditable. It provides a secure, sandboxed environment for executing agentic workflows with human-in-the-loop approvals and durable SQLite-checkpointed sessions.

## Key Features
- Provider-agnostic support for OpenAI, Anthropic, Google, Ollama, and local models
- OS-level sandboxing with default-deny egress for secure execution of commands
- Durable SQLite-checkpointed sessions with human-in-the-loop approvals
- Built-in eval suite with deterministic scripted tests and model baselines
- Explicit trust boundary design with detailed security documentation and threat model

## Why It Matters for RAG Builders
It provides a transparent, auditable framework for building secure agentic systems with explicit trust boundaries, critical for RAG/AI stack builders prioritizing safety and control.
