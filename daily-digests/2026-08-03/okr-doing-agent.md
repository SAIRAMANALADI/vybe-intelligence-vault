## Summary
OKR Doing Agent is a local execution agent designed to transform traditional OKR tracking into actionable execution within Logseq. It automates the setup of a personal OKR system, asset inventory, migration, and periodic reviews, ensuring goals are not just tracked but actively pursued.

## Key Features
- Automated OKR system installation in Logseq with previews and conflict checks
- Asset inventory and migration for legacy OKR data from local files or Evernote/Yinxiang
- Periodic review cycles (weekly, monthly, quarterly, yearly) with Bayesian update principles
- Integration with Claude Code and Codex as plugins for seamless execution
- Safety-first design with dry-run previews, user confirmations, and backup checks

## Why It Matters for RAG Builders
It bridges the gap between goal setting and execution by automating the setup and maintenance of a personal OKR system, making it essential for AI engineers building productivity or RAG-based personal knowledge systems.
