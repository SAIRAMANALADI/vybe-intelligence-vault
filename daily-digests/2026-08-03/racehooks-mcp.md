## Summary
MCP server for RaceHooks that exposes motorsport analytics and data as tools/resources for AI assistants like Claude, Cursor, and Windsurf. Enables real-time access to live session data, webhooks, simulations, and account metrics via OAuth 2 authentication.

## Key Features
- Exposes RaceHooks account as MCP tools/resources for AI assistants
- Supports live session data, webhooks, simulations, and account metrics
- OAuth 2.0 authentication with auto-refreshing tokens
- Local stdio process with no network binding for security
- Pre-configured prompts for guided workflows (e.g., setup_race_event_webhook)

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with real-time motorsport data and analytics, enhancing RAG systems with live timing and event-driven insights.
