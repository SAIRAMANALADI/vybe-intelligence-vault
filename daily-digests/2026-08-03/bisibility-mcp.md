## Summary
The @bisibility/mcp repository provides a Model Context Protocol (MCP) server that exposes bisibility's SEO tools to AI agents, enabling keyword research, rank tracking, and backlink analysis via a standardized interface.

## Key Features
- Exposes bisibility's SEO tools (keyword research, rank tracking, backlink analysis) to AI agents via MCP
- Supports stdio and HTTP transport for MCP clients
- Configurable toolsets and read-only mode for security and control
- Integrates with bisibility's SDK for standardized API interactions
- Provides environment-based configuration for API keys, project IDs, and toolsets

## Why It Matters for RAG Builders
It enables AI agents to directly interact with bisibility's SEO tools, streamlining workflows for keyword research, rank tracking, and backlink analysis without manual API calls.
