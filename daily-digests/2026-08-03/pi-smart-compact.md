## Summary
A verification-oriented context compaction extension for the Pi Coding Agent that preserves operational coding state (goals, files, decisions, errors, constraints, and open loops) with deterministic ground truth extraction and repair mechanisms.

## Key Features
- Preserves operational coding state (goals, files, decisions, errors, constraints, open loops) with deterministic ground truth extraction
- Four-stage EESV pipeline (Extract, Explore, Synthesize, Verify) with adaptive model usage and repair mechanisms
- Automatic and manual compaction modes with configurable profiles (light, balanced, aggressive) and focus/budget controls
- Built-in safety and privacy safeguards including secret/PII scrubbing, collision-safe file verification, and deterministic repairs
- Open-loop management, damage monitoring, and adaptive feedback for continuous improvement

## Why It Matters for RAG Builders
It ensures critical coding state and context are preserved during compaction, reducing hallucinations and improving reliability for AI agents in long-running sessions.
