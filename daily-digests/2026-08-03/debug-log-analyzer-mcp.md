## Summary
An MCP server that enables AI assistants to analyze Salesforce Apex debug logs for performance bottlenecks, slow methods, governor limit usage, and SOQL/DML bottlenecks. It provides structured tools for parsing logs, executing anonymous Apex, and generating performance insights.

## Key Features
- Parses Apex debug logs to identify slow methods and performance bottlenecks
- Detects governor limit usage and SOQL/DML bottlenecks with structured analysis
- Executes anonymous Apex code and saves debug logs for further analysis
- Provides configurable debug levels and org-specific execution
- Integrates seamlessly with MCP-compatible AI clients for natural language queries

## Why It Matters for RAG Builders
It enables AI assistants to efficiently analyze Salesforce Apex debug logs, helping developers quickly identify performance issues and optimize code without manual log parsing.
