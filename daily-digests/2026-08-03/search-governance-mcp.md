## Summary
An open-source, local-first Model Context Protocol (MCP) server designed for AI search crawler governance, brand safety guardrails, canonical integrity validation, and IndexNow notifications. It provides tools to audit crawler directives, enforce content policies, and ensure compliance with search engine requirements.

## Key Features
- Parses robots.txt for AI search bot access rules (e.g., GPTBot, ClaudeBot)
- Audits canonical link integrity to prevent duplicate content issues
- Enforces brand safety guardrails by scanning for restricted keywords
- Generates IndexNow API payloads for Bing, Yandex, and Naver
- Monitors system health and processing latency for governance throughput
