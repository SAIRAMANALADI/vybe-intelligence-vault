## Summary
mcp-samgov is a Model Context Protocol (MCP) server providing access to SAM.gov data, including federal contract opportunities and entity registration information. It serves as a gateway for AI agents to interact with U.S. federal procurement data.

## Key Features
- Provides real-time access to SAM.gov federal contract opportunities
- Supports entity registration data retrieval
- Integrates with AI agents via Model Context Protocol (MCP)
- Offers plain English query interface via ask_pipeworx
- Part of a larger gateway (Pipeworx) with 1337+ data sources

## Why It Matters for RAG Builders
It enables AI agents to dynamically fetch and process U.S. federal procurement data, critical for applications in government contracting, market analysis, and compliance.
