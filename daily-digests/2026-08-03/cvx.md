## Summary
CVX is a CLI tool that transforms structured YAML input into professionally designed CV PDFs entirely locally. It supports AI-assisted content generation, validation, and rendering with themes, layouts, and ATS-compatible variants.

## Key Features
- Converts YAML content into polished CV PDFs with themes and layouts
- Supports AI-assisted content generation and validation
- Provides ATS-safe single-column variant for job applications
- Includes MCP server for agent integration (Claude, Cursor, VS Code)
- Validates content against a canonical JSON Schema with semantic error reporting

## Why It Matters for RAG Builders
CVX streamlines the creation of professional, ATS-compatible CVs from structured input, making it essential for developers and AI agents building resume-generation workflows.
