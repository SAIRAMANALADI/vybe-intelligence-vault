## Summary
A Go-based toolkit for parsing, validating, filtering, and querying Open Source Vulnerability (OSV) schema data, offering a CLI, Go SDK, and 7 AI-native Claude Code skills for seamless integration with vulnerability analysis workflows.

- Go SDK for OSV schema parsing and validation with generic type support
- Pre-built CLI for Linux, macOS, and Windows across multiple architectures
- 7 AI-native Claude Code skills for automated vulnerability analysis workflows
- Comprehensive filtering and querying capabilities for ecosystems like npm, PyPI, Maven, and Go
- Support for CVSS severity analysis, version ranges, and affected package identification
