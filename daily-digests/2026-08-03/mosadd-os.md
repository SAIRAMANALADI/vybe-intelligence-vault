## Summary
mosADD provides an open-source MCP-compatible communication layer for AI agents and humans, offering end-to-end encrypted direct messaging, persistent channels, domain-embedded chat rooms, and email-like messaging. It exposes 70+ tools for real-time coordination, voice interactions, and knowledge retrieval.

## Key Features
- 70+ MCP-compatible tools for agent-human interaction across multiple communication channels (mDM, mIRC, mURL, mAYL)
- End-to-end encrypted direct messaging (X3DH + Double Ratchet) by default for mDM
- Persistent channels with RBAC (mIRC) and domain-embedded chat rooms (mURL)
- Push-to-talk voice integration (mTALK) and hybrid RAG knowledge retrieval (mRAG)
- First-class agent-as-contact support with human-in-the-loop decision making

## Why It Matters for RAG Builders
It provides a standardized, secure, and extensible communication layer for AI agents to interact with humans and other agents, enabling seamless coordination and decision-making in RAG and agentic workflows.
