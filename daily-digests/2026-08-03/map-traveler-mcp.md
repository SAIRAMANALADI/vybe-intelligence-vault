## Summary
A Model Context Protocol (MCP) server that enables virtual travel experiences using Google Maps, allowing an avatar to traverse locations and interact with real-world environments via AI-driven instructions and image generation.

## Key Features
- Virtual travel simulation with Google Maps integration, enabling avatar movement and location-based interactions.
- Supports real-time and skip-based movement modes for flexible journey execution.
- Integrates with multiple AI image generation services (Gemini, Stability.ai, PixAI, ComfyUI) for dynamic avatar rendering.
- Provides SNS (Bluesky) integration for posting travel updates and interacting with social feeds.
- Offers customizable prompts and role-based configurations for tailored traveler personas.

## Why It Matters for RAG Builders
It provides a unique framework for simulating real-world travel experiences within AI agents, enabling dynamic, location-aware interactions and content generation for RAG systems.
