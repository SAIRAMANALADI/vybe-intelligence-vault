## Summary
A zero-dependency CLI and coding agent for Node.js that acts as an LLM-driven terminal assistant with self-awareness, file manipulation, shell access, and project context integration. It enables hands-on terminal interactions while maintaining strict workspace confinement and approval-based safety policies.

## Key Features
- Shell access with timeouts and output capping across platforms
- File tools for atomic edits, patching, and line-ending-aware file operations
- Project context loading via AGENTS.md/CLAUDE.md for build/test command awareness
- Live self-model (proprioception) with drift-proof architecture and test ratchets
- Approval-based safety system for shell commands, file writes, and external reads

## Why It Matters for RAG Builders
It provides a secure, self-aware agent framework for RAG builders to integrate terminal automation and file manipulation with strict safety controls and project context awareness.
