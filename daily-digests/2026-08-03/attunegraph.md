## Summary
@attunegraph/core is an agent-neutral temporal and provenance graph engine that compiles bounded source observations into immutable projections and a working graph for agent decision-making. It emphasizes provenance tracking, temporal correctness, and source authority without altering or inferring truth from graph proximity.

## Key Features
- Agent-neutral graph engine with temporal and provenance capabilities
- Immutable projections and working graph compilation for agent decisions
- Durable local SQLite adapter and in-memory store options
- Strict source authority and abstention semantics to prevent truth inference from graph proximity
- Portable NDJSON wire format with golden fixtures for deterministic replay

## Why It Matters for RAG Builders
It provides a critical foundation for building reliable, provenance-aware RAG systems by ensuring temporal correctness and source authority in agent decision-making graphs.
