## Summary
Brass-Monkey is a secure and cognitively optimized CLI extension and MCP bridge for Odoo, enabling AI agents to navigate complex ERP/CRM architectures, manage multiple instances, and perform audited record operations with high context-window efficiency.

## Key Features
- Breadth vs. Depth Search Paradigm for efficient record discovery and detailed dashboards
- In-Memory Metadata Caching for 0ms latency in model configuration queries
- Hierarchical menu navigation with pruned, recursive JSON trees
- Self-healing action resolution for dynamic Odoo action type support
- OS-level security with API key storage in system keychains

## Why It Matters for RAG Builders
Brass-Monkey enables AI agents to securely and efficiently interact with Odoo's complex ERP systems, making it essential for building intelligent automation and RAG pipelines in enterprise environments.
