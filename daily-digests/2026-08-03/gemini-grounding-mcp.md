## Summary
This repository provides an MCP (Model Context Protocol) server that enables MCP clients like Claude Code to perform web-grounded research via the Gemini API. It enhances responses with inline citations, source lists, and token usage metrics, ensuring verifiable and transparent AI-generated answers.

## Key Features
- Inline citation markers in answers with numbered source lists for verifiability
- Token usage tracking (input, output, thinking) for cost transparency
- Supports Google Search, URL Context, and Code Execution in a single call
- Configurable model and thinking level per call or persistently
- Command-line tool for testing and debugging without MCP client setup

## Why It Matters for RAG Builders
It enables RAG builders to integrate reliable, web-grounded research with verifiable citations directly into their AI pipelines.
