## Summary
Compartment is an MCP server providing durable, encrypted agentic memory for AI agents, enabling persistent and secure storage of conversations, decisions, and preferences without cloud dependency. It offers fast local search, cryptographic security, and seamless integration with popular AI agents like Claude, Hermes, and OpenClaw.

## Key Features
- Persistent, encrypted memory storage for AI agents with zero cloud dependency
- Sub-12ms hybrid search (vector + keyword) with deterministic importance ranking
- AEAD encryption for all data at rest, including embedding vectors
- One-command installation and integration with major AI agents (Claude, Hermes, OpenClaw)
- Tamper-evident audit logs, cryptographic deletion, and offline-first architecture

## Why It Matters for RAG Builders
Compartment eliminates the forgetting problem in AI agents by providing a secure, offline, and persistent memory layer that integrates seamlessly with existing workflows, enabling true long-term learning and context retention without sacrificing privacy or performance.
