## Summary
A deterministic readiness checker for Model Context Protocol (MCP) servers to assess compatibility with the 2026-07-28 breaking changes. It provides graded reports via a web demo or a skill for agents, identifying critical issues like deprecated handshakes, session state, and authentication flaws.

## Key Features
- Grades MCP server compatibility with the 2026-07-28 MCP specification rewrite
- Provides both a web demo and an agent skill for automated migration guidance
- Detects critical issues like deprecated handshakes, session state, and OAuth compliance
- Includes heuristic source code scanning and live HTTP probing for comprehensive checks
- Offers per-rule remediation guidance with links to the MCP specification
