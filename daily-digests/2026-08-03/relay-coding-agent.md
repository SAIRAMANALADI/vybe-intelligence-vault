## Summary
Relay is an open-source Electron-based desktop coding agent designed to support non-mainstream LLM providers like DeepSeek, Qwen, and GLM. It offers both a Chat workspace and a Code workspace with real-time file editing, command execution, and browser automation capabilities.

## Key Features
- Supports non-mainstream LLM providers (DeepSeek, Qwen, GLM, etc.) alongside mainstream options
- Dual workspace: Chat for conversational AI and Code for file editing and command execution
- Embedded shared browser for web interaction, including login persistence and automation
- Human-in-the-loop permissions (Ask/Approve/Full) for file and command execution
- MCP plugin support for integrations like Notion, Linear, GitHub, and more

## Why It Matters for RAG Builders
Relay expands access to diverse LLM providers for AI engineers, enabling experimentation beyond mainstream options while providing a robust desktop coding agent framework.
