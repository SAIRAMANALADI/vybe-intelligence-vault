## Summary
Maganu is a custom AI agent powered by Claude AI, deployed as a Node.js server with WhatsApp integration via Twilio. It enables conversational AI interactions, scheduled automations, and REST API access for direct chat and messaging.

## Key Features
- Powered by Claude AI for advanced conversational capabilities
- WhatsApp integration via Twilio for real-time messaging
- Session-based conversation memory for context retention
- Scheduled automations (e.g., daily briefings, ecosystem checks)
- REST API for direct chat and message sending
