## Summary
MicroCRM is an open-source agentic CRM that leverages Micro Blocks as its sole database, eliminating the need for a traditional CRM database. It features a resident research agent that enriches pipeline data with evidence-based enrichment loops, ensuring traceability and human oversight.

## Key Features
- Resident research agent with evidence-based enrichment loop for pipeline data
- No traditional database; relies on Micro Blocks for data storage and sync
- Traceable data provenance with human oversight for weak evidence
- Fully open-source (MIT) and self-hostable
- Modular architecture with Turborepo and shared TypeScript types

## Why It Matters for RAG Builders
MicroCRM demonstrates how agentic workflows can enhance CRM systems with evidence-based automation while leveraging external databases like Micro Blocks for scalability and simplicity.
