## Summary
Ankole is an open-source, self-hosted AgentOS designed for shared AI colleagues, enabling long-running, durable agents with their own identities, memory, and permissions. It moves AI work from private chat interfaces into team-visible channels and infrastructure-controlled contexts, supporting real responsibilities like code reviews, customer support, and operations.

## Key Features
- Actor-based runtime for long-lived AI agents with durable identities and state
- Shared, team-visible agent workspaces for collaboration and auditability
- ZeroMQ-based live control fabric for real-time steering and backpressure
- PostgreSQL-backed durable ledger for recovery, audit, and reconciliation
- Multi-provider support (Slack, webhooks, schedules) with normalized signal input

## Why It Matters for RAG Builders
Ankole provides a robust, self-hosted foundation for building and deploying long-running, collaborative AI agents with durable memory and real responsibilities, essential for enterprise-grade RAG and multi-agent systems.
