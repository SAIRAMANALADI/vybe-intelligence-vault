## Summary
A thin Claude Code skill that triages commercial research topics into 15 specialized data domains, auto-detects and configures the required MCP sources, and delegates heavy retrieval to existing deep-research tools while enforcing citation guardrails and quality checks.

## Key Features
- Automated triage of research topics into 15 specialized data domains (e.g., X/Twitter, SEO, crypto, ecommerce)
- Dynamic detection and configuration of required MCP sources with guided installation commands
- Delegation of heavy retrieval and synthesis to existing tools like deep-research and research-lit
- Enforced citation guardrails including multi-source corroboration, adversarial verification, and mandatory disconfirmation
- Deterministic refresh pipeline with adversarial verification and GitHub API gate for quality control

## Why It Matters for RAG Builders
It streamlines the integration of specialized commercial data sources into RAG pipelines by automating source detection, configuration, and quality validation, reducing setup overhead and ensuring reliable, citable outputs.
