## Summary
Jacobian provides an MCP server, CLI, and Python library for executable mathematics, enabling AI agents to perform composable mathematical operations with inspectable artifacts and independent verification. It separates evidence generation from trust decisions, ensuring only operator-authorized checkers can emit verified results.

## Key Features
- Composable mathematical operations for AI agents with inspectable artifacts
- Independent verification boundary separating evidence generation from trust decisions
- Support for polynomial algebra, exact linear algebra, graph theory, SAT/SMT, and formal proofs
- MCP server and CLI for integration with AI agents and clients
- Backend-agnostic capability catalog with runtime discovery and invocation

## Why It Matters for RAG Builders
Jacobian enables AI agents to perform rigorous, verifiable mathematical reasoning with transparent evidence, critical for building trustworthy RAG systems that require exact computation and formal proof.
