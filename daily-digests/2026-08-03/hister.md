## Summary
Hister is a privacy-focused, self-hosted search engine that indexes full-text content from visited web pages, local files, and imported datasets. It supports semantic search via configurable embeddings endpoints and provides multiple interfaces including a web UI, terminal, and MCP for AI assistant integration.

## Key Features
- Full-text indexing of web pages and local files with privacy guarantees
- Semantic search support via configurable embeddings endpoints
- Multiple interfaces: web UI, terminal, command line, and MCP for AI assistants
- Automatic browser indexing through Firefox/Chrome extensions
- Multi-user support with optional public search mode for shared instances

## Why It Matters for RAG Builders
Hister enables RAG builders to create private, self-hosted search layers for indexing and retrieving context from documents, web pages, and files without relying on third-party services.
