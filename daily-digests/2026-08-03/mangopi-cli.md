## Summary
Mangopi CLI is a lightweight, single-file autonomous coding agent for the terminal that operates with zero external dependencies, using only Python's standard library. It enables local-first AI-driven coding workflows with minimal overhead and maximum hackability.

## Key Features
- Single-file, zero-dependency runtime for easy auditing and customization
- 3-agent autonomous pipeline (Implementer, Verifier, Updater) for iterative code refinement
- Smart provider routing with tiered model selection (low/medium/high) for cost and performance optimization
- Built-in safety checks for shell commands and file operations to prevent accidental damage
- Persistent local sessions with automatic context compacting to manage large conversations
