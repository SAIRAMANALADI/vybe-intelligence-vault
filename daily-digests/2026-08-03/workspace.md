## Summary
Workspace is a local-first Electron application that provides a unified, native-first environment for managing computer work through 'Spaces'—folders that act as portable working contexts with an integrated Pi assistant. It emphasizes ordinary folder usage while enhancing them with structured navigation, reusable libraries, and AI-driven capabilities.

## Key Features
- Creates portable 'Spaces' from existing folders without conversion or movement
- Integrates a native Pi assistant for AI-driven task automation and chat
- Supports reusable 'Library' materials and 'Skills' for consistent workflows
- Provides a structured UI with Files, Chats, Capabilities, Library, and History surfaces
- Includes a CLI for inspecting Spaces, tasks, and capabilities via a read-only protocol

## Why It Matters for RAG Builders
It provides a structured, local-first environment for organizing and interacting with AI-driven tools and files, making it easier to manage complex workflows with an integrated assistant.
