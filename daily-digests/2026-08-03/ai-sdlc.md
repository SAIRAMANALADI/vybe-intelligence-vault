## Summary
AI-SDLC Framework is a decision engine and autonomous orchestrator for spec-driven AI workflows, enabling operators to frontload critical decisions and govern AI agent execution deterministically. It bridges the gap between contract specification and shipped code, ensuring reliability and reducing AI-driven code churn.

## Key Features
- Definition-of-Ready gate for operator-driven decision enforcement
- Autonomous pipeline orchestrator with dependency graph traversal and task dispatching
- Cross-harness review system with DSSE attestations for independent validation
- Declarative governance with JSON Schema-based resource definitions
- Operator TUI for real-time pipeline monitoring and decision stewardship
