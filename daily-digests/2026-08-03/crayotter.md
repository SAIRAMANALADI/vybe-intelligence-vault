## Summary
Crayotter is a multimodal, agent-driven video editing system that autonomously transforms a single text request into a fully edited video through a three-phase workflow: material preparation, editing research, and execution. It integrates planning, deep editing research, and tool-based execution with full traceability for debugging and iteration.

## Key Features
- End-to-end video generation from a single text prompt with minimal user input
- Three-phase workflow: planning, editing research, and tool-based execution with full logging and trace visualization
- Multimodal material understanding and analysis for informed editing decisions
- Resource-aware DAG scheduling with bounded concurrency, retries, and checkpoint/resume capabilities
- Built-in narration, subtitles, audio mixing, and export with support for multiple platforms (Bilibili, Douyin, YouTube, etc.)

## Why It Matters for RAG Builders
Crayotter provides a traceable, autonomous framework for transforming text into high-quality videos, reducing manual effort in video production and enabling scalable AI-driven creative workflows.
