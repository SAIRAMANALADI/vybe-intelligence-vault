## Summary
UniFi MCP provides Model Context Protocol (MCP) servers for Ubiquiti UniFi controllers, enabling AI agents to interact with Network, Protect, and Access applications via standardized MCP tools for automation and management.

## Key Features
- MCP-compliant servers for UniFi Network, Protect, and Access controllers
- Lazy-loading meta-tools for efficient tool discovery and execution
- Cloud Relay architecture for secure multi-location routing and token boundaries
- REST and GraphQL API for non-MCP clients
- Preview-then-confirm mutation flow for safe AI-driven changes

## Why It Matters for RAG Builders
