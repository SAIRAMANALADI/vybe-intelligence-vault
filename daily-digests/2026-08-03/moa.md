## Summary
Moa is a self-hosted coding agent that runs on your local machine or development server, allowing you to steer AI-driven development tasks from anywhere via a web UI or mobile interface. It integrates with Anthropic or OpenAI models to perform tasks like editing code, running tests, and managing Docker environments while keeping all operational state and credentials on your infrastructure.

## Key Features
- Runs on your local machine or development server, ensuring full control over code and environment
- Supports multi-session management with live telemetry and parallel agent workflows
- Integrates with Anthropic or OpenAI models via OAuth or API keys
- Provides a web UI, TUI, and CLI for seamless interaction from desktop or mobile
- Supports delegated subagents, custom tools, and project-specific instructions via AGENTS.md

## Why It Matters for RAG Builders
