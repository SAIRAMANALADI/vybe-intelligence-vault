## Summary
koreanpulse is an MCP server that provides real-time English translations and summaries of Korean stock market disclosures, including DART filings, foreign-holder 5%-rule flows, and activist investor campaigns. It bridges the language gap for AI agents and traders by surfacing KRX/KOSPI/KOSDAQ equity data in a structured, agent-friendly format.

## Key Features
- Real-time DART corporate disclosure tracking with English translations
- Foreign-holder 5%-rule flow monitoring and classification (paid tier)
- Korean activist investor filing alerts (paid tier)
- 16-sector Korean industry news aggregation and translation
- Seamless MCP integration for AI agents (Claude, Cursor, ChatGPT)

## Why It Matters for RAG Builders
It provides critical Korean equity market intelligence in English for AI agents and traders, filling a major language and data accessibility gap in real-time primary sources.
