## Summary
Keeper.sh is an open-source calendar syncing tool that aggregates events from remote iCal or ICS sources and pushes them to multiple calendars to ensure time slot alignment. It includes an MCP server for AI agent calendar access and supports self-hosting or cloud deployment.

## Key Features
- Aggregates calendar events from remote sources (iCal, ICS, CalDAV, Google, Outlook)
- Pushes aggregated events to one or multiple destination calendars
- Includes an MCP server for AI agent calendar access
- Supports self-hosting with full feature parity to cloud version
- Open-source under AGPL-3.0 with easy setup via Docker

## Why It Matters for RAG Builders
