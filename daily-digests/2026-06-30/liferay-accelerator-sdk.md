## Summary
A hardened SDK designed to accelerate Liferay DXP integration by providing dynamic adapters, runtime auto-discovery, and contract enforcement for batch processing, workflow automation, and API orchestration.

## Key Features
- Dynamic Catalog Adapters for legacy and modern Liferay Commerce models
- Runtime Auto-Discovery of DXP capabilities to select optimal adapters
- Contract Enforcement using Liferay DXP OpenAPI specifications
- Transient Error Resilience with configurable retry thresholds
- Hardened integration for batch, workflow, and API orchestration
