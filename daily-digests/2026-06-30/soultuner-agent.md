## Summary
SoulTuner-Agent is a locally deployable AI music recommendation agent that combines Hybrid RAG, knowledge graphs, and long-term memory to deliver personalized music discovery. It understands natural language queries, learns user preferences over time, and curates immersive music journeys while supporting both local and online music libraries.

## Key Features
- Hybrid retrieval combining graph-based, dense vector, BM25, and personalized retrieval with weighted RRF fusion
- Multi-modal music search using MuQ-MuLan (primary), M2D-CLAP (fallback), and OMAR-RQ (acoustic similarity)
- Long-term memory system with GraphZep for persistent user preference tracking across sessions
- Natural language intent recognition with hard/soft constraints and multi-turn inheritance
- Docker-based deployment with CPU/GPU support for full-stack or lightweight setups

## Why It Matters for RAG Builders
SoulTuner-Agent demonstrates a production-grade implementation of Hybrid RAG with multi-modal retrieval, long-term memory, and intent-aware agent orchestration, making it a critical reference for AI engineers building advanced RAG systems.
