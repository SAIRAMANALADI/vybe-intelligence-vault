## Summary
Aura Work is an open-source, multi-provider desktop AI agent platform designed for local-first, permission-gated, and self-hostable workflows. It enables secure, extensible AI automation with encrypted local storage and marketplace-driven extensions for skills, MCP connectors, and plugins.

## Key Features
- Multi-provider AI integration (OpenAI, Anthropic, Gemini, DeepSeek, Ollama) with intelligent routing
- Encrypted local vault for secure storage of API keys and sensitive data
- Universal Workspace for handling documents, spreadsheets, PDFs, and automation workflows
- Permission-gated and self-hostable with optional signed updates and VM isolation
- Extensible marketplace for Skills, MCP connectors, and plugins with localized metadata

## Why It Matters for RAG Builders
Aura Work provides a secure, extensible framework for building and deploying AI agents with local-first workflows, making it essential for developers prioritizing privacy and customization in RAG systems.
