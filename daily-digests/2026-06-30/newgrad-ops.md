## Summary
newgrad-ops is an agentic career operating system designed to help students secure their first tech job by transforming AI coding assistants into a command center for application tracking, resume tailoring, interview prep, GitHub audits, and referral management.

## Key Features
- Agentic career operating system for internship/new-grad job search
- Company-specific prep packs with tailored LeetCode patterns and behavioral themes
- Resume and GitHub portfolio auditing with actionable improvement plans
- Curated problem lists (NeetCode 150, Blind 75, Monster 50) mapped to interview patterns
- Ethical referral templates and alumni outreach management

## Why It Matters for RAG Builders
It provides a structured, AI-integrated framework for new grads to systematically prepare for tech interviews and job applications, reducing guesswork and improving efficiency.
