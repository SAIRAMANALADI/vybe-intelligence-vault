## Summary
A Common Lisp SDK for the Model Context Protocol (MCP) and Agent-to-Agent Protocol (A2A), providing servers, clients, agents, and a behavioral specification engine for AI-driven workflows.

## Key Features
- Full MCP 2025-11-5 conformance with 44/44 checks passing
- Supports both stdio and Streamable HTTP (SSE) transports
- Built-in REPL agent with multi-provider support (Anthropic, Groq, OpenAI)
- Behavioral specification engine with property-based testing and PostgreSQL codegen
- Agent swarm for task decomposition and runtime tool creation

## Why It Matters for RAG Builders
