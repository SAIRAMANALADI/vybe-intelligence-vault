## Summary
A helper server for Kotlin Multiplatform projects that indexes and provides fast lookup of Apple framework APIs from klib files, enabling real-time symbol and method searches without external dependencies.

## Key Features
- Builds a local index of klib files for offline Apple framework API lookup
- Provides compact, searchable cards for symbols, classes, and methods
- Supports real-time indexing and metadata inspection
- Configurable via settings.json for port, refresh rate, and scan paths
- Optimized for Windows with SSD storage recommendations for performance

## Why It Matters for RAG Builders
It accelerates Kotlin Multiplatform development by enabling fast, local API lookups for iOS frameworks, reducing dependency on external documentation and improving developer productivity.
