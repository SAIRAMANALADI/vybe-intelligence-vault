## Summary
Shiny Fishstick compiles websites into semantic SDKs and Model Context Protocol (MCP) servers for AI agents, eliminating the need for raw HTML parsing or brittle CSS selectors by converting UI actions into typed, reliable API calls.

## Key Features
- Compiles websites into typed SDKs (Python, TypeScript, Rust) for AI agents
- Generates MCP servers for direct LLM tool integration
- Upgrades UI actions to direct API calls, reducing token overhead by up to 99.9%
- Includes a BFS crawler, DOM analyzer, and intent classifier for semantic action mapping
- Provides a dashboard for visual inspection and management of compiled specs

## Why It Matters for RAG Builders
It eliminates the need for AI agents to parse raw HTML or maintain brittle selectors by compiling websites into reliable, typed SDKs and MCP servers, drastically improving efficiency and reliability for RAG and agentic workflows.
