## Summary
A desktop application that provides a comprehensive Chinese-language wiki of all 27 possible outcomes from the SBTI personality test, including standard types, the HHHH fallback, and the DRUNK hidden result. The tool organizes and displays personality archetypes for offline reference and comparison.

## Key Features
- Displays all 27 SBTI personality test outcomes in one centralized application
- Supports offline usage with no internet connection required after installation
- Includes 25 standard personality types, HHHH fallback, and DRUNK hidden result
- Allows side-by-side comparison of personality profiles via right-click
- Provides customization options like light/dark theme and font size adjustments
