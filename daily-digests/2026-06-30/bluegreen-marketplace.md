## Summary
bluegreen-marketplace is a Claude Code plugin distribution layer for the hal AI-native company layer, enabling field-work SMEs to integrate CRM, project management, and building-inspection workflows directly into their Claude client via plugins.

## Key Features
- Distributes plugins for CRM, project management, and building-inspection workflows
- Supports auto-updates via the marketplace
- Provides MCP server for cross-provider compatibility (Claude, Gemini, OpenAI)
- Includes unified task and project tagging system
- Offers OAuth-based authentication for secure access
