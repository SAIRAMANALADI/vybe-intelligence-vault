## Summary
oh-my-matrix is an OpenClaw-native orchestration extension suite designed to transform OpenClaw into a sustainable autonomous agent runtime stack. It provides continuous execution, dynamic multi-agent workflows, and runtime permission policies for secure agent operations.

## Key Features
- Autopilot plugin for long-running continuous task execution with goal management, retry queues, stall detection, and evidence tracking
- Dynamic Workflows for AI-generated multi-agent orchestration programs (.prose) with 8 execution modes (fan-out, pipeline, adversarial verification, etc.)
- Permission Policy runtime safety layer with before_tool_call hooks to enforce default-deny security for destructive operations
- OpenClaw-native plugin architecture with hooks for session lifecycle, tool calls, and state projection
- Development harness with CI/CD, testing, and documentation pipelines for maintainability
