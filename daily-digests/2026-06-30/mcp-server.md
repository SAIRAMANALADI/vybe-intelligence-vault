## Summary
The Kontent.ai MCP Server is an official implementation of the Model Context Protocol (MCP) that bridges Kontent.ai's headless CMS with AI-powered tools like Claude, Cursor, and VS Code. It enables natural language interactions with structured content operations, including content modeling, taxonomy management, and content item manipulation.

## Key Features
- Enables natural language interactions with Kontent.ai content via MCP-compatible AI tools
- Supports comprehensive content operations including content types, taxonomies, and content items
- Offers both single-tenant (STDIO) and multi-tenant (Streamable HTTP) deployment modes
- Provides AI-powered semantic search for content discovery and management
- Includes robust security measures to mitigate indirect prompt injection risks
