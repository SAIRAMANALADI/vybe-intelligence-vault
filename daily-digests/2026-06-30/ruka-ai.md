## Summary
Ruka AI is a Python-based CLI agent that leverages OpenRouter AI models to perform file operations, terminal command execution, and multi-step agentic workflows. It provides a terminal UI inspired by Claude Code, with session management and security best practices for local AI-driven automation.

## Key Features
- Full file and folder management (read, write, delete, copy, move)
- Terminal command execution via natural language
- Multi-step agentic loop for complex workflows
- Session management with save/load/rename/delete functionality
- Terminal UI with Claude Code-inspired styling and real-time interruptions

## Why It Matters for RAG Builders
Ruka AI enables AI-driven automation of file operations and terminal commands, reducing manual effort for developers and power users while integrating seamlessly with OpenRouter models for natural language processing.
