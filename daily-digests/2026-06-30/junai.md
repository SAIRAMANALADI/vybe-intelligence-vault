## Summary
junai is a deterministic agent framework for VS Code and GitHub Copilot that replaces hallucinated LLM routing with a Python state machine, ensuring predictable, auditable, and git-blameable agent transitions across 9 pipeline stages with 25 specialized agents.

## Key Features
- 25 specialized AI agents (e.g., Architect, Implementer, Tester, Security Analyst) with dynamic loading
- 9-stage deterministic pipeline with Python state machine for auditable, hallucination-free routing
- Three pipeline modes: supervised (full control), assisted (auto-routing with gate approval), and autopilot (beta, minimal approval)
- 121 reusable skills, 30 prompts, and 24 instruction files for extensibility
- VS Code extension for zero-setup deployment and Copilot Chat-native UX

## Why It Matters for RAG Builders
junai eliminates the unpredictability of LLM-driven agent routing by enforcing deterministic, auditable pipelines, making it essential for AI stack builders who require reliability and control in agent workflows.
