## Summary
Claudinho is a lightweight, open-source tool that provides live football (soccer) scores and fixtures for the 2026 men's World Cup directly in the terminal, Claude Code/Cursor CLI statuslines, and MCP clients. It requires no API keys or signups, bundling all 104 fixtures for offline use.

## Key Features
- Real-time live scores and fixtures with no API key required
- CLI, statusline, and MCP server integration for AI agents and terminals
- Offline-capable bundled data for fixtures and standings
- Prediction market signals (Polymarket) for match favorites
- Multi-language support (en, es, pt, fr) with localized commentary

## Why It Matters for RAG Builders
Claudinho provides a simple, no-setup way to integrate live sports data into AI workflows, terminals, and agent statuslines, enhancing real-time context for AI-driven applications.
