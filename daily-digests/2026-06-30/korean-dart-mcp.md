## Summary
A Model Context Protocol (MCP) server that provides AI assistants with direct access to OpenDART's 83 financial APIs, transforming raw corporate filings into structured, LLM-friendly formats. It includes specialized tools for financial analysis, XBRL parsing, insider trading signals, and document extraction.

## Key Features
- 83 OpenDART APIs compressed into 15 intuitive tools for AI assistants
- XBRL parsing with full presentation/calculation linkbase support and automated validation
- HWP/PDF attachment extraction and conversion to markdown for LLM consumption
- Pre-built financial analysis tools (insider signals, disclosure anomalies, Buffett-style quality checklists)
- Automated 90-day chunking for large-scale disclosures and parallel page fetching

## Why It Matters for RAG Builders
