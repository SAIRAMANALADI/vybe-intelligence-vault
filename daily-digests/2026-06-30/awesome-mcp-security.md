## Summary
awesome-mcp-security is a Windows desktop application that scans and evaluates the security of over 800 MCP servers using nine standardized checks, providing clear safety scores and risk assessments updated daily. It simplifies AI agent security assessment for non-technical users.

## Key Features
- Nine automated security checks for MCP servers including prompt injection, toxic flows, and data privacy
- Daily updated security scores for over 800 MCP servers
- Simple Windows GUI with search and scan functionality
- Clear risk breakdowns without requiring technical expertise
- Administrator-friendly installation and troubleshooting
