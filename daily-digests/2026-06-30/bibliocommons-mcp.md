## Summary
A Model Context Protocol (MCP) server that enables interaction with BiblioCommons-powered public libraries, allowing users to search catalogs, manage holds, check out digital items, and perform account operations via a standardized interface.

## Key Features
- Search library catalogs with format filtering
- Place, cancel, and manage holds for physical and digital items
- Check out and renew loans, including digital checkouts
- List branches and verify library health
- Supports multi-user authentication via WorkOS OAuth

## Why It Matters for RAG Builders
It provides a standardized MCP interface to interact with BiblioCommons-powered libraries, enabling seamless integration for AI agents managing library accounts and resources.
