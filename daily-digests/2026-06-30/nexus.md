## Summary
N.E.X.U.S. is a Python-based personal AI assistant leveraging the Anthropic Claude API to create a tool-using agent with persistent memory, real-time tool execution, and dual interfaces (terminal and web HUD). It integrates RAG for document search, market news tracking, expense management, task scheduling, and advanced features like NinjaTrader trading, voice interaction, and multi-user security.

## Key Features
- Tool-using agentic loop with Claude API for dynamic tool execution (file I/O, web search, commands, trading, etc.)
- Persistent memory across sessions with structured long-term notes and search capabilities
- Dual interfaces: terminal client (full tools) and web HUD (streaming, voice, PWA, and dashboard with real-time updates)
- Advanced integrations: NinjaTrader trading, Google Calendar/Gmail, expense tracking, task management, and market news aggregation
- Multi-user security with 2FA, CSRF protection, and role-based data isolation
