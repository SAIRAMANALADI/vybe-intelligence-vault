## Summary
Mempalace is a lightweight, local-first tool that builds and manages permanent memory for AI systems by storing and organizing user notes and data in a secure SQLite database. It enables AI models to recall contextually relevant information from a user's past work.

## Key Features
- Local SQLite-based storage for notes and data with no external dependencies
- Seamless integration with AI models to provide contextual memory recall
- Optional cloud sync via Turso for multi-device consistency
- Rust-based for performance, stability, and security
- Windows-native installer for easy setup and deployment

## Why It Matters for RAG Builders
Mempalace provides a lightweight, privacy-preserving way to equip AI systems with persistent memory, reducing reliance on heavy external dependencies while ensuring fast and secure data access.
