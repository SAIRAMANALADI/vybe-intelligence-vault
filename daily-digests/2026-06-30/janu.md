## Summary
Janu XR is a Python-based prototype designed to guide first-time users through Galaxy XR headset setup via an eight-step conversational interface. It tracks failures, provides structured evaluation logs, and offers a FastAPI interface for session management and Android dashboard integration.

## Key Features
- Eight-step conversational setup guide with explicit failure tracking for critical steps
- Session persistence and structured evaluation logs stored locally
- FastAPI interface for session management and data retrieval
- Android dashboard for inspecting evaluation logs and failure insights
- Gemini API integration for image description, translation, and grounded search

## Why It Matters for RAG Builders
Janu XR provides a structured framework for tracking and diagnosing XR setup failures, which is valuable for improving user onboarding experiences in AI-driven XR applications.
