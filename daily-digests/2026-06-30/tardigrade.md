## Summary
Tardigrade is an AI-powered synthetic user-testing tool that automates browser-based audits of web applications. It uses a multimodal LLM to explore web apps, capture screenshots and DOM snapshots, and score them against predefined or custom rubrics, providing evidence-backed findings.

## Key Features
- Drives real browsers (via Playwright) to simulate user interactions
- Captures screenshots, DOM snapshots, console logs, and network errors for every step
- Scores sessions against built-in or custom rubrics (UX, functional, conversion)
- Provides an interactive dashboard for replaying sessions and reviewing findings
- Supports any OpenAI-compatible LLM endpoint for flexibility

## Why It Matters for RAG Builders
Tardigrade automates and standardizes web app audits with AI-driven exploration and evidence-backed scoring, reducing manual QA effort while improving consistency and reproducibility.
