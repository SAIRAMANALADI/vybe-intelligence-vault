## Summary
mcp-superset is a Windows-based server that extends Apache Superset with over 128 tools for managing dashboards, datasets, SQL queries, and user access. It integrates the Model Context Protocol (MCP) to enable AI tools and large language models (LLMs) to interact with Superset dashboards and data efficiently.

## Key Features
- Extends Apache Superset with 128+ tools for dashboard and chart management
- Integrates Model Context Protocol (MCP) for AI/LLM data interaction
- Provides SQL Lab for direct SQL query execution without coding
- Supports user access control and role-based permissions
- Windows-native installer with a user-friendly interface

## Why It Matters for RAG Builders
