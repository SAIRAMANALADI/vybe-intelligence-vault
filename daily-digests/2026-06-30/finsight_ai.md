## Summary
FinSight AI is a personal finance intelligence tool that ingests transactions, enables search via pgvector, and provides a stateful advisor grounded in user data. It supports Canadian bank CSV imports, optional Plaid sync, budgeting, and spending insights.

## Key Features
- Transaction ingest from Canadian bank CSVs with optional Plaid sync
- Stateful advisor using LangGraph for workflow orchestration
- pgvector-powered semantic search over transaction history
- Budgeting and spending insights via LLM analysis
- Local deployment with Ollama and Supabase for authentication
