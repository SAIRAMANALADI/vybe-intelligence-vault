## Summary
Aurevoy is a local-first personal AI agent that autonomously plans and executes tasks based on high-level goals, such as file operations, code editing, research, and image analysis. It runs entirely on your machine, integrates with your preferred LLM provider, and emphasizes user control and data privacy.

## Key Features
- Autonomous task planning and execution without step-by-step instructions
- Local execution with support for custom LLM providers and API keys
- Multimodal capabilities including image analysis and file operations
- User preference learning and context-aware task adaptation
- Built-in skill system with slash commands and extensibility via MCP

## Why It Matters for RAG Builders
Aurevoy enables developers to build AI agents that autonomously handle complex, multi-step tasks while maintaining full data privacy and user control.
