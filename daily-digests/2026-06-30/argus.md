## Summary
ArgusCode is an open-source, model-agnostic AI coding workbench that provides verification, traceability, and reliability for AI agents. It includes a TUI-based workbench, scriptable harness, and MCP-native tools to ensure agents prove their work through gates, traces, and on-repo evaluations.

## Key Features

- Time-travel debugging with trace replay and forking capabilities
- On-repo evaluation engine to quantify agent reliability with pass-rate metrics

- Zero-migration integration with existing project rules and MCP servers
