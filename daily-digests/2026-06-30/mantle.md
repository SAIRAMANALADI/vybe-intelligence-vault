## Summary
Mantle is an agent-native headless CMS designed for AI agents as first-class authors, enabling content modeling through prompting rather than manual configuration. It provides structured JSON diagnostics, locked-grammar manifests, and static markdown mirrors for agent-friendly content management.

## Key Features
- Agent-first authoring via YAML manifests and structured prompts
- Locked-grammar validation and diagnostics to prevent production failures
- Static markdown mirrors for agent-friendly content crawling
- Modular plugin system for extensible marketplace capabilities
- Pre-configured Cloudflare Workers deployment with MCP endpoints

## Why It Matters for RAG Builders
Mantle enables AI agents to autonomously build and manage content-driven web services, reducing manual configuration overhead and ensuring consistency through structured diagnostics and agent-native tooling.
