## Summary
A step-by-step educational project that demonstrates how to build a minimal Claude Code-like coding agent in Python without relying on frameworks like LangChain or LangGraph. It focuses on teaching the core mechanics of multi-turn conversations, tool usage, context management, and streaming output.

## Key Features
- Step-by-step implementation of a Claude Code-like agent from scratch in Python
- Supports multi-turn conversations, tool calls, and streaming output
- Includes context compression, permissions management, and session handling
- Uses DeepSeek's Anthropic API compatible interface for low-cost testing
- Provides detailed tutorials and reference code for each feature
