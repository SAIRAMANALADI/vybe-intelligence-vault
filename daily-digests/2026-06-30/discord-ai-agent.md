## Summary
A self-hosted AI agent for private Discord servers that enables natural language interactions via @ai mentions, with permission-aware memory, tool integration, and self-updating capabilities through isolated Kubernetes sandboxes.

## Key Features
- Natural language interaction via @ai mentions with Discord permissions awareness
- Permission-aware memory over indexed Discord history using pgvector embeddings
- Integrated tools for web search, image generation, channel summaries, and stats
- Self-updating capabilities via isolated Kubernetes sandbox jobs with GitHub PR automation
- Private server skills stored in Postgres for contextual responses

## Why It Matters for RAG Builders
It provides a permission-aware, self-hosted AI agent framework for Discord communities that integrates memory, tools, and self-updating capabilities while keeping data private.
