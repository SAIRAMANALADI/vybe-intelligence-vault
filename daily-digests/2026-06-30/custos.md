## Summary
CUSTOS is an autonomous keeper and community agent for the Arcis Protocol, deployed on Base mainnet. It automates critical DeFi operations like yield harvesting, loan monitoring, debt servicing, and community engagement through a modular skill-based architecture.

## Key Features
- Modular skill-based architecture with 9 specialized agents (e.g., VaultKeeper, CreditKeeper, TelegramSkill)
- Real-time protocol monitoring and automated yield harvesting/rebalancing
- Multi-channel community engagement via Telegram, X (Twitter), and natural language processing
- Automated liquidation alerts, debt servicing, and TVL tracking
- Graceful skill disabling for missing credentials (e.g., social media APIs)
