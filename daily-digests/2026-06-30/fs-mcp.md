## Summary
FS-MCP is a Model Context Protocol (MCP) server that provides AI agents like Claude with comprehensive file system integration, enabling directory management, file operations, and Office document handling. It includes a web-based permissions manager and pre-built executables for macOS, Windows, and Linux.

## Key Features
- Pre-built executables for cross-platform deployment (macOS, Windows, Linux) without Node.js dependencies
- Comprehensive file system operations: read, write, create, delete, copy, move, and rename files/directories
- Office document support: create and read Excel (.xlsx), PowerPoint (.pptx), and Word (.docx) files
- Advanced directory tree visualization with customizable depth and filtering options
- Web-based permissions manager for granular read/write access control with real-time updates

## Why It Matters for RAG Builders
FS-MCP enables AI agents to securely interact with local file systems and Office documents, expanding their capabilities for tasks requiring file manipulation and data extraction.
