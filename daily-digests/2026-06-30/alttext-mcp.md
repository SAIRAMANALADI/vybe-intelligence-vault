## Summary
An MCP server that enables AI assistants to generate alt text, manage image libraries, and audit web pages for accessibility using the AltText.ai API. Compatible with MCP-compatible clients like Claude Desktop, Cursor, and Windsurf.

## Key Features
- Generates alt text for images from URLs or local files with multilingual support
- Manages image libraries with CRUD operations and search functionality
- Audits web pages for missing alt text and queues bulk generation
- Supports cryptographic verification of package provenance via npm audit signatures
- Integrates seamlessly with MCP-compatible AI clients for real-time accessibility tasks

It streamlines accessibility compliance for AI-driven applications by automating alt text generation and image management, reducing manual effort and improving user experience.
