## Summary
IronClaw Desktop is a native macOS client for the IronClaw Rust knowledge agent, built with Tauri v2. It provides a polished native shell with macOS conventions, bundling a static WebUI and managing a local sidecar for seamless AI agent interactions.

## Key Features
- Native macOS client with Keychain-backed credentials and menu-bar tray
- Bundled local IronClaw sidecar for offline/online AI agent operations
- Support for file attachments (PDF, Office formats) with client-side text extraction and OCR
- One-click NEAR AI Cloud sign-in and model management via Settings
- Signed auto-updater and notarized macOS releases for security

## Why It Matters for RAG Builders
It provides a polished, native macOS interface for interacting with the IronClaw AI agent, simplifying user onboarding and enhancing usability with local sidecar management and secure credential storage.
