## Summary
A Neovim plugin that integrates AI agents like Gemini, Qwen, and Claude Code directly into the editor workflow, enabling seamless AI-assisted coding, diff management, and multi-agent support via MCP backend.

## Key Features
- Seamless integration of multiple AI agents (Gemini, Qwen, Claude) into Neovim
- Real-time diff views and acceptance/rejection of AI suggestions
- Multi-agent support with auto-detection and customizable command sets
- Tmux integration for persistent AI sessions across editor restarts
- Flexible sidebar styles and key binding customization

## Why It Matters for RAG Builders
It enhances developer productivity by bringing AI agent capabilities directly into Neovim, reducing context switching and enabling efficient code review and modification workflows.
