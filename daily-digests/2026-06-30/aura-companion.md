## Summary
Aura Companion is a self-learning web UI for managing multi-agent sessions with Claude Code and Codex, featuring Council Mode for paired agent collaboration and an adaptive knowledge base that evolves with each session.

## Key Features
- Council Mode for paired agent collaboration with orchestrator and observer sessions
- Adaptive knowledge base (.agents/knowledge/) that evolves with each session via skills like /prime, /learn, /self-reflect, and /evolve
- Carmack Council skill chain for engineering review and domain expert guidance
- Real-time streaming output and tool-call visibility with permission control
- Session persistence and state management with checkpointing and filesystem protocol (.council/)

## Why It Matters for RAG Builders
Aura Companion provides a structured, multi-agent framework for AI-driven development with built-in self-improvement, making it essential for teams building advanced RAG or agentic systems.
