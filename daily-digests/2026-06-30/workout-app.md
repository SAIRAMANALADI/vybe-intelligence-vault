## Summary
GymLogic is a mobile-first PWA for tracking strength training with offline support, progression analytics, and an MCP server enabling AI agents to interact with training data, design programs, and adapt workouts via natural language.

## Key Features
- MCP-native integration enabling AI agents to read, analyze, and modify training data via natural language
- Offline-first PWA with localStorage sync and fingerprint-based deduplication
- AI-generated programs with dry-run preview and commit workflows
- Comprehensive exercise library with 360+ exercises, muscle group filters, and rich metadata
- Progression tracking with Epley estimated 1RM, PR detection, and analytics dashboards

## Why It Matters for RAG Builders
It provides a seamless MCP-native interface for AI agents to interact with and modify training data, enabling dynamic, conversational workout planning and adaptation for RAG/AI stack builders.
