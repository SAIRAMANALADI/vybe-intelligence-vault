## Summary
Relay is an open-source desktop coding agent built with Electron that enables users to leverage non-mainstream LLM providers (e.g., DeepSeek, Qwen, GLM) alongside mainstream options. It offers both chat and code workspaces with file editing, command execution, and MCP plugin support.

## Key Features
- Supports multiple LLM providers including non-mainstream and Chinese models
- Dual workspace: Chat for conversational AI and Code for file editing and command execution
- Human-in-the-loop permissions for file and command execution
- MCP plugin integration for tools like Notion, Linear, GitHub, and more
- Secure local encryption of API keys and credentials

## Why It Matters for RAG Builders
Relay expands access to diverse LLM providers for AI engineers, reducing dependency on mainstream options and enabling experimentation with emerging models.
