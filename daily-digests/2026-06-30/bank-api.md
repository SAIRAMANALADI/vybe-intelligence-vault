## Summary
The Bank API is a design reference project that provides a compliant, modern API for financial services, featuring OWASP security, OpenAPI v3.2.0, GDPR/CCPA compliance, and event-driven architecture with CloudEvents. It includes an MCP server for AI integration and supports sidecar-based deployments.

## Key Features
- OWASP API Security Top 10 v2023 compliance via Spectral ruleset
- Event-driven architecture with CloudEvents and outbox pattern
- Model Context Protocol (MCP) server for AI integration
- Comprehensive compliance with GDPR, CCPA, and Dutch Public Sector API rules
- Sidecar-based deployment with Dapr, OpenTelemetry, and S3Proxy
