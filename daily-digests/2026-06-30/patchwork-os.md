## Summary
Patchwork OS is a local-first personal AI runtime that provides a pluggable model provider system, hot-reloadable tools, YAML-based automation recipes, and a delegation policy with an approval queue. It operates entirely on the user's machine and supports both a standalone dashboard and IDE integration for developers.

## Key Features
- Pluggable model providers with multi-model support
- 177+ built-in tools (LSP, debugger, terminal, git, GitHub) with hot-reloadable plugins
- YAML-based automation recipes triggered by events (cron, file save, webhook)
- Delegation policy with risk-tiered approval queues and durable trace memory
- Standalone dashboard and IDE bridge (VS Code, Cursor, JetBrains) for oversight and control

## Why It Matters for RAG Builders
Patchwork OS enables RAG builders to integrate local-first AI orchestration with robust tooling and approval workflows, ensuring secure, user-controlled automation without vendor lock-in.
