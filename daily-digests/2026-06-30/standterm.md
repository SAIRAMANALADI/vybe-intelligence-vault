## Summary
StandTerm is a local-first browser-based terminal that enables SSH, host-local shells, UART sessions, and controlled external-agent access across multiple platforms. It provides persistent terminal tabs that remain connected to the server process even after browser reloads, making it ideal for human-in-the-loop automation and AI agent workflows.

## Key Features
- Persistent browser terminal tabs connected to a live server process across page reloads
- Supports SSH, local shell, and UART sessions with platform-specific backends
- Agent panel for human-in-the-loop automation with explicit typed state and privacy controls
- External Agent Mirror for local CLI agents to interact with terminals via loopback HTTP JSON
- Cross-platform support for WSL2, Windows, macOS, and Linux with platform-specific launchers

## Why It Matters for RAG Builders
StandTerm enables AI agents to safely observe, type, and recover in live terminal sessions while keeping human operators in control, bridging the gap between automated workflows and supervised operations.
