## Summary
An open, comparative catalog of tools and systems used to build, deploy, and operate autonomous AI agents, tracking 912 systems across 85 attributes with 528 typed relationships. It serves as a centralized resource for builders to compare, analyze, and identify gaps in AI agent infrastructure.

## Key Features
- Comprehensive dataset of 912 AI agent systems with 85 attributes per entry, including license, maturity, deployment model, and compliance posture.
- Typed relationships between systems (e.g., built-on, extends, competes-with) enabling lineage and ecosystem mapping.
- Provenance tracking for every claim with tiered verification (T1-T3) and source citations for auditability.
- MCP server and CLI tools for programmatic access to the catalog, enabling integration with AI workflows.
- Automated freshness checks and self-maintaining workflows to ensure data accuracy and relevance.
