## Summary
ClawTrap is an AI-native horror game where players navigate a procedurally generated maze while an AI agent observes their actions, adapts the environment in real-time, and uses their local files to create personalized traps. The game leverages episodic memory and procedural generation to deliver a unique experience.

## Key Features
- Procedurally generated maze that adapts to player actions in real-time
- AI agent observes and remembers player behavior across sessions
- Integration with local files to personalize traps and horror elements
- WebSocket-based communication for dynamic agent-player interaction
- Windows-native executable with no programming knowledge required for play
