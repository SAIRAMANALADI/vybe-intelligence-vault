## Summary
An MCP server that enables AI assistants like Claude or ChatGPT to interact with StudioMeyer Agents' AI audit fleet data, allowing users to query reports, compare periods, and configure agent settings directly from their AI tools.

## Key Features
- Read-only tools to fetch latest reports, search findings, and compare periods
- Self-service configuration tools to set focus topics, competitor watchlists, and report styles
- DSGVO-compliant data export and deletion (Art. 20/17)
- Multi-tenant API bridge with customer-scoped data access
- Audit trail for all configuration changes

## Why It Matters for RAG Builders
It enables seamless integration of StudioMeyer's AI audit fleet data into AI assistants, allowing users to query and configure agents directly from their chat interfaces.
