## Summary
Career-copilot is a Windows desktop application that automates the job search process using AI. It scans job listings, matches them to user skills, generates tailored resumes and cover letters, and tracks application progress in a visual pipeline.

## Key Features
- AI-driven job listing matching based on user skills and resume
- Automated generation of tailored cover letters and resumes
- Visual pipeline for tracking application status (To Apply, Applied, Interview, Offer)
- GitHub account integration for secure authentication
- Built-in resume builder for users without existing documents
