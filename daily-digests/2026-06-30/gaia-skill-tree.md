## Summary
Gaia is an open-source registry and skill graph for AI agents that verifies capabilities through a public ledger of code-execution runs, license checks, and security audits. It enables developers to claim, fuse, and validate agent skills with evidence-backed trust metrics.

## Key Features
- Public ledger of verified AI agent skills with evidence grades and trust metrics
- Tiered star system (0★–6★) for ranking agent capabilities and skill fusion paths
- CLI and TUI for scanning, installing, and managing skills locally or globally
- MCP server integration for seamless agent-to-registry communication
- Static JSON API for programmatic access to the registry and trust ledger

## Why It Matters for RAG Builders
Gaia provides a standardized, evidence-backed registry for AI agent skills, enabling trust and reproducibility in RAG and agentic systems by mapping capabilities and their provenance.
