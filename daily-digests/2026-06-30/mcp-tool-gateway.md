## Summary
A portfolio demo project implementing an MCP-style tool gateway for enterprise AI agents, focusing on tool registry, schema validation, RBAC policies, human review, trace evidence, and audit logging. It provides a sandboxed environment for tool execution and governance workflows.

## Key Features
- Tool registry with schema validation and risk classification
- RBAC policy enforcement and human review workflows
- Trace evidence and audit logging for tool calls
- Sandboxed tool execution with read-only constraints
- MCP-style JSON-RPC adapter for tool and prompt management

## Why It Matters for RAG Builders
It demonstrates critical governance and audit capabilities for AI agent tool orchestration, bridging the gap between raw tool execution and enterprise-grade control.
