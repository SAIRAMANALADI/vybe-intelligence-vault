## Summary
LingXi is an LLM-driven autonomous penetration testing agent framework designed for security assessments. It automates reconnaissance, exploitation, flag submission, and experience accumulation through a multi-agent system with planner, executor, and reflector roles.

## Key Features
- Autonomous penetration testing workflow with closed-loop execution (reconnaissance, exploitation, flag submission, and reflection)
- Multi-agent collaboration (Main Agent, Advisor Agent, Reflector) for robust problem-solving
- Modular tool integration (Shell, Python, Kali, API gateways, MCP servers)
- Knowledge system with memory layers (runtime, structured experience, external CTF writeups)
- High observability via Rich Console and FastAPI + SSE Web Dashboard
