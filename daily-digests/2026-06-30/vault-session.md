## Summary
Vault-Session is a browser extension that securely exports and imports browser login sessions (cookies) using AES-256-GCM encryption, enabling seamless migration of active logins across devices without relying on third-party servers.

## Key Features
- Securely exports browser cookies and login sessions into encrypted files
- Supports cross-browser compatibility (Chrome, Firefox, Brave)
- Uses AES-256-GCM encryption to protect sensitive data
- No third-party servers involved; data remains local
- Open-source and free to use

## Why It Matters for RAG Builders
It provides a secure and private way to migrate browser sessions across devices, reducing friction for users managing multiple logins without compromising security.
