## Summary
DCT Agent is a multi-server AI agent framework supporting Ollama, OpenRouter, and OpenAI-compatible providers (e.g., DeepSeek, Qwen, Groq). It enables autonomous agent mode, multi-agent squads, hierarchical task orchestration, and advanced memory management with failover and load-balancing capabilities.

## Key Features
- Supports Ollama, OpenRouter, and OpenAI-compatible providers with automatic failover and load-balancing
- Multi-agent squads with parallel task execution and role-based specialization
- Hierarchical task orchestration via DAG-based decomposition and parallel wave execution
- Advanced memory system with core persona, project context, and vector RAG for long-term autonomy
- Built-in agent tools for file operations, web interaction, vision, and autonomous code execution
