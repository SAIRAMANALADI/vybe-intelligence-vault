## Summary
观澜 (Guanlan) 是一个面向 AI Agent 的中文互联网研究工具，专为中文网络环境优化。它提供信源路由、网页阅读、热榜观察、证据包输出等功能，帮助 Agent 高效获取和整理可追溯的中文互联网内容。

## Key Features
- 智能信源路由：根据查询类型自动选择官方媒体、社区样本、RSS 或垂类媒体等最优信源
- 网页正文提取与质量检测：将网页转换为干净的 Markdown 格式，并提供正文质量、噪声评估和追溯链路
- 热榜与趋势观察：通过 `hotnews` 和 `feeds` 模块实时监控中文互联网热点动态
- 证据包输出：支持多种格式（如 `context`、`dossier`、`timeline`）为 Agent 提供结构化研究证据
- 长期意图雷达：`watch` 功能将一次性查询固化为持续观察意图，按需触发并复用搜索状态
