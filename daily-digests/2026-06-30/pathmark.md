## Summary
Pathmark provides a local memory layer for AI coding agents like Codex, Claude Code, and Gemini CLI, enabling seamless context sharing across tools without vendor lock-in or hosted dependencies.

## Key Features
- Local JSONL memory store for persistent context across agents
- Standard MCP tools for saving, searching, and retrieving memories
- Provider-neutral synthesis modes (client, command, Codex CLI, OpenAI-compatible)
- Cross-harness setup CLI for easy integration with Codex, Claude Code, Cursor, and more
- Soft-delete and import/export capabilities for legacy memory migration

## Why It Matters for RAG Builders
Pathmark eliminates context fragmentation for AI coding agents by providing a unified, local memory layer that persists across tools and sessions.
