## Summary
agent-soul is a Windows-based tool designed to manage memory and identity for AI agents, enabling persistent and shared memory across sessions without relying on external servers. It leverages Git for local data storage and version control, ensuring privacy and self-hosted operation.

## Key Features
- Shared memory between AI agents via Git-backed storage
- Automatic session saving and organization
- Supports multiple AI models (OpenAI, Claude) without third-party data sharing
- Lightweight and runs locally without additional services
- Easy installation and configuration for non-programmers
