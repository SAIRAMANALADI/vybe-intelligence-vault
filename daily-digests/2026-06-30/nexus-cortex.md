## Summary
Nexus Cortex is a headless, multi-provider AI agent harness designed as a library, CLI tool, or stateful server. It orchestrates agents across multiple LLM providers with built-in tools, sub-agents, MCP integration, and session management.

## Key Features
- Supports 11+ LLM providers with 84+ models, enabling seamless switching and routing
- Headless and scriptable by design, embeddable as a library or run as a CLI/server
- Built-in tools including sandboxed artifacts, MCP integration, git/PR tooling, and permission engine
- Stateful agent server with append-only session history and auto-shutdown on idle
- Customizable agent profiles, skills, and commands via user-defined directories

## Why It Matters for RAG Builders
Nexus Cortex provides a flexible, production-ready foundation for building and deploying multi-provider AI agents with minimal overhead, making it essential for RAG and AI stack builders seeking scalability and customization.
