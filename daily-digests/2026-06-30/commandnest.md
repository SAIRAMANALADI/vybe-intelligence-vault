## Summary
CommandNest is a lightweight desktop AI assistant application for Windows that integrates with advanced language models via OpenRouter. It provides a local interface for tasks like coding support, document summarization, and workflow management with global hotkeys and streaming responses.

## Key Features

- Streaming responses for real-time feedback as text generates

- Supports multiple AI providers via OpenRouter for flexibility
