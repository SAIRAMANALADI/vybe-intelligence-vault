## Summary
Oh-My-PM is an AI Agent workflow system designed for Product Managers, leveraging Claude Code plugins and workflow orchestration to automate and enhance product management tasks. It features a 5-layer architecture, 20 professional skills, and 8 specialized subagents for comprehensive product lifecycle management.

## Key Features
- 5-layer architecture covering the full product lifecycle from requirement sensing to validation
- 20 specialized skills and 8 subagents for targeted task automation and expertise
- Scenario-driven PRD generation with competitive benchmarking and industry analysis
- HTML prototype generation for interactive design validation
- Human-AI collaboration modes (Autopilot, Copilot, Manual) for flexible workflows
