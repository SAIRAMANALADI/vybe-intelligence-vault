## Summary
Veto is an MCP server that integrates with major AI CLIs (Claude Code, Codex, Gemini, etc.) to provide a council of 49 specialist agents and 93 tools for local AI development. It emphasizes deterministic expert modules, self-learning routing, and persistent cross-platform memory with zero extra subscription costs.

## Key Features
- 49 specialist agents across 6 domains (Development, Security, Memory, Research, Quality, Workflow) with deterministic expert modules
- 93 MCP tools for session management, code review, CI/CD gates, memory, and decision enforcement
- Self-learning router that auto-tunes tier thresholds based on task outcomes
- Dependency-hallucination guard to prevent slopsquatting attacks
- Compact mode for reduced context overhead and dynamic tool discovery

## Why It Matters for RAG Builders
