## Summary
An AI-powered assistant that automates the creation and management of a football-focused Twitter (X) account by generating context-aware tweet drafts from real-time news sources, delivering them via a Telegram bot for manual review, and refining output based on engagement metrics.

## Key Features
- Real-time news ingestion from 10+ free sources (RSS, Reddit, Google News, API-Football)
- Hybrid tweet drafting with three distinct personas (pundit, fan, analyst) and multiple variants per event
- Telegram bot for draft review, manual posting, and engagement tracking
- Automated learning from engagement metrics to refine writing style and suggest style rules
- 24/7 deployable on Fly.io with optional Xquik posting and automatic database backups

## Why It Matters for RAG Builders
It provides a scalable, automated pipeline for generating and refining AI-driven social media content, reducing manual effort while maintaining user control and adaptability through engagement-based learning.
