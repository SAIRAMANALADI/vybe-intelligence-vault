## Summary
Memory-bank is a Windows-based tool that enables AI assistants to retain long-term context across multiple chat sessions by storing project history, rules, and progress in a structured, human-readable format. It reduces token waste and improves AI performance by maintaining consistent project memory.

## Key Features
- Saves project history across chat sessions to maintain AI context
- Reduces token consumption by avoiding repeated explanations
- Works offline with local file storage for privacy and security
- Human-readable memory files for easy inspection and editing
- Supports automatic recovery and manual memory resets
