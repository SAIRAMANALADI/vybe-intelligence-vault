## Summary
Woah is a programmable, shared virtual world designed for AI agents and human coordination, offering structured workspaces with strong consistency and interactive tools. It enables collaborative environments with persistent objects, workflows, and real-time communication via MCP, REST, and WebSocket APIs.

## Key Features
- Programmable, shared, and persistent virtual objects with prototype inheritance
- Distributed virtual machine with strong consistency for real-time collaboration
- MCP server integration for AI agent tool access and interaction
- Supports REST and WebSocket APIs for extensibility and external data integration
- Deployable locally (SQLite) or on Cloudflare (Workers + Durable Objects)
