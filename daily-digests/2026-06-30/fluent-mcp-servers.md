## Summary
A local Windows application that connects AI agents to Fluent WordPress plugins via 175 specialized tools for CRM, support, project management, community engagement, and affiliate tracking. It bridges AI systems with WordPress data to automate workflows.

## Key Features
- Provides 175 pre-built tools for Fluent WordPress plugins to automate tasks like CRM management, support ticket handling, and project organization
- Local Windows application with no server requirements, ensuring data privacy and security
- Supports multiple WordPress sites via configurable connection profiles
- Integrates with AI agents using the Model Context Protocol (MCP) for seamless automation
- Open-source with no mandatory subscription fees

## Why It Matters for RAG Builders
It enables AI agents to directly interact with WordPress data, automating complex workflows and reducing manual intervention for RAG and AI stack builders.
