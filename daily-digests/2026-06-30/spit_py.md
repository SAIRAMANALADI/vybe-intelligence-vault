## Summary
spit.py is a terminal-based application for interacting with multiple LLMs, managing chats, endpoints, and system prompts with advanced features like tool calling, image chat, and LaTeX rendering. It supports async operations and is designed for productivity in console environments.

## Key Features
- Manages multiple chats, endpoints, and LLM settings simultaneously
- Supports tool calling and async long replies without TUI freeze
- Renders LaTeX math formulas in supported terminals
- Enables chat with images and markdown parsing
- Sandboxed LLM function calls via bubblewrap
