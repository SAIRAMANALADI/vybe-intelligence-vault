## Summary
DuDuClaw is an open-source multi-runtime AI agent platform that unifies Claude, Codex, and Gemini CLI backends into a single, production-ready system. It provides infrastructure for multi-LLM agent orchestration, secure communication channels, memory management, and self-evolution capabilities.

## Key Features
- Unified multi-runtime support for Claude, Codex, and Gemini backends with automatic provider detection
- 7 built-in communication channels (Telegram, LINE, Discord, Slack, WhatsApp, Feishu, WebChat)
- Advanced memory management with temporal memory, reflexion loops, and semantic knowledge graphs
- Production-grade resilience with DLQ, retry policies, circuit breakers, and cost telemetry
- Self-evolution engine (GVU² dual-loop) with MistakeNotebook for continuous improvement

## Why It Matters for RAG Builders
DuDuClaw provides the critical infrastructure layer for building production-grade multi-LLM agent systems, eliminating months of custom development work for RAG and AI stack builders.
