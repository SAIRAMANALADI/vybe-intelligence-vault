## Summary
WorkingRoom is an open-source shared workspace enabling seamless collaboration between teams and AI agents through a unified interface for file management, permissions, and access control.

## Key Features
- Unified workspace for humans and AI agents to collaborate on files
- Granular file access control and permission boundaries
- Human approval workflows for AI-driven changes
- Built-in AI chat interface with context-aware interactions
- Full audit trails and change history for compliance
