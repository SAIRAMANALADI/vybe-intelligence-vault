## Summary
A production-grade AI system that detects financial anomalies in SEC EDGAR filings using a Variational Autoencoder (VAE) combined with RAG and LangGraph. It processes real financial data, flags suspicious patterns, and provides plain-English explanations for anomalies.

## Key Features
- Processes 22M+ rows of SEC financial filings for anomaly detection
- Combines VAE with RAG and LangGraph for explainable AI insights
- Flags real-world anomalies with 94.7% agreement with Isolation Forest baseline
- Provides plain-English explanations for detected anomalies using LLaMA 3.3
- Offers a FastAPI endpoint for real-time anomaly analysis

## Why It Matters for RAG Builders
It enables RAG builders to integrate explainable financial anomaly detection into AI pipelines, enhancing fraud detection and risk assessment capabilities.
