## Summary
A static navigation hub for AI Agent Skills organized by functional categories, enabling browsing, filtering, and statistics. It aggregates skills from multiple community repositories and presents them in a user-friendly interface with search, sorting, and multi-platform tag filtering capabilities.

## Key Features
- Organizes AI Agent Skills by functional categories with real-time filtering
- Supports multi-platform tag-based filtering (e.g., Codex, Claude, Hermes)
- Provides search, sorting, pagination, and grouped view switching
- Includes a dedicated statistics page for aggregated skill data
- Automated data maintenance via GitHub Actions for index and health report generation
