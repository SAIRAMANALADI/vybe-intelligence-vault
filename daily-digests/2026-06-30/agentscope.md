## Summary
AgentScope is a desktop application that visualizes and analyzes changes made by AI agents (e.g., Claude Code) to your codebase, providing a clear diff view, risk assessment, and session management to simplify code review and debugging.

## Key Features
- Interactive diff viewer with syntax highlighting for code changes
- Automated risk assessment (Safe/Review/Danger) for file modifications
- Session-based organization of AI agent interactions
- Multi-language support (Chinese/English) with customizable UI
- Drag-and-drop layout for flexible workspace customization

## Why It Matters for RAG Builders
AgentScope simplifies the review of AI agent-generated code changes, reducing cognitive load and improving debugging efficiency for developers.
