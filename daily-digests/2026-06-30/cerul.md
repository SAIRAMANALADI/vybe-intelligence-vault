## Summary
Cerul is a video search layer designed for AI agents, enabling them to search videos by meaning across speech, visuals, and on-screen text. It provides APIs, SDKs, and CLI tools to integrate video search capabilities into AI workflows.

## Key Features
- Search videos by meaning across speech, visuals, and on-screen text
- Supports MCP, CLI, and SDKs (Python, JavaScript) for AI agent integration
- Provides API playground for testing and code generation
- Offers analytics and feedback mechanisms for search quality
- Deployable via Docker for self-hosting or cloud-based solutions

## Why It Matters for RAG Builders
