## Summary
Clawness is a lightweight Claude Code plugin that automatically injects relevant coding rules into every AI agent session, ensuring compliance with project-specific standards without manual prompting. It combines lexical retrieval, concept expansion, and adversarial review agents to enforce rules, security checks, and output compression in under 1 MB with zero infrastructure dependencies.

## Key Features
- Automatic rule injection for coding standards and conventions based on project context
- Hybrid retrieval engine (BM25 + TF-IDF + RRF) with concept expansion for synonym matching
- Adversarial review sub-agents for security, architecture, and code quality checks
- Session security hardening with access guard and trust ledger to prevent data exfiltration
- Output compression to reduce noise in AI agent responses and preserve context efficiency
