## Summary
hyper-mcp is a fast, secure MCP (Model Context Protocol) server that extends AI application capabilities through WebAssembly plugins. It enables plugin development in any language that compiles to WASM, distributed via OCI registries, and runs in sandboxed environments.

## Key Features
- Plugin development in any WASM-compatible language
- Secure sandboxing with resource limits and memory safety
- OCI registry distribution with cryptographic signature verification
- Cross-platform compatibility (serverless, edge, mobile, IoT)
- Dynamic plugin loading and unloading with fine-grained access control

## Why It Matters for RAG Builders
It provides a secure, extensible framework for integrating AI capabilities into applications via modular WASM plugins, enabling scalable and portable AI tooling.
