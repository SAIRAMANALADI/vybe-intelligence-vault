## Summary
An AI-powered personal study coach built with Google ADK 2.0 that transforms user notes into an adaptive learning experience. It generates quizzes, tracks weak areas, creates personalized revision plans, and sends study reminders, all with enterprise-grade security and zero ambient authority.

## Key Features
- Intelligent quiz generation from user notes using RAG
- LLM-as-Judge evaluation with detailed feedback and weak area tracking
- Personalized 3-day revision planning based on quiz history
- Ambient study reminders via Pub/Sub and background tasks
- Enterprise-grade security with PII redaction, prompt injection defense, and zero ambient authority
