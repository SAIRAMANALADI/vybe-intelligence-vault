## Summary
IssueMe is a pi extension that enables LLM agents to manage GitHub issues through a repository-scoped, agent-friendly interface. It provides structured tools for syncing, caching, and interacting with GitHub Issues while enforcing safety and trust boundaries.

## Key Features
- Repository-scoped GitHub issue operations via structured tools
- Local JSON cache for open issues to reduce API calls and tool output size
- Twenty-eight agent tools for issue, label, milestone, assignee, and project management
- Safety-aware operations with explicit confirmations for destructive actions
- Non-secret configuration UI and project-local skill integration

## Why It Matters for RAG Builders
