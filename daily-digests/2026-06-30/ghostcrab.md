## Summary
GhostCrab is a native mobile and desktop client for the OpenClaw Gateway, an open-source AI agent and LLM orchestration platform. It provides remote administration and configuration capabilities for self-hosted AI infrastructure via iOS, Android, and Mac Catalyst apps.

## Key Features
- Auto-discovery of OpenClaw gateways via mDNS for seamless LAN connections
- Secure configuration editor for `openclaw.json` with validation and diff preview
- Live dashboard displaying gateway health, active models, and capabilities
- Model manager for viewing and swapping configured AI models
- End-to-end encrypted storage of bearer tokens with AES-256-GCM

## Why It Matters for RAG Builders
GhostCrab enables AI engineers to remotely manage and configure their self-hosted AI infrastructure from mobile or desktop devices, streamlining administration of OpenClaw Gateway deployments.
