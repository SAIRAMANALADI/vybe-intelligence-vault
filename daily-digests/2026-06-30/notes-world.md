## Summary
notes-world is a personal productivity dashboard that consolidates notes, tasks, ideas, and reminders into a structured interface with tagging, priorities, and dependencies. It includes an MCP server for AI agent integration, enabling direct interaction with user data via tools like Claude Code.

## Key Features
- Unified dashboard for notes, tasks, ideas, and reminders with tagging and dependencies
- MCP server enabling AI agents (Claude, Cursor) to interact with notes-world data via 20+ tools
- PostgreSQL backend with automated backups (daily, weekly, monthly retention)
- Docker-based deployment with production-ready configurations
- Rate limiting, security headers, and HTTPS support for production use

## Why It Matters for RAG Builders
It provides a structured, AI-integratable workspace for managing and querying personal knowledge, critical for RAG pipelines requiring dynamic, taggable, and agent-accessible data sources.
