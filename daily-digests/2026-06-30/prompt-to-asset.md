## Summary
A Windows desktop application that converts text prompts into professional-grade images such as logos, app icons, favicons, and social media previews using AI image generation models. It simplifies the design process for non-designers by automating image creation and validation.

- Supports 30+ AI image generation models for optimal output matching
- Automated validation ensures generated images are error-free before saving
