## Summary
GrEBI is an HPC pipeline that aggregates biomedical knowledge graphs from multiple sources using ontologies and LLM embeddings, enabling integrative queries across disparate resources. It provides a streamable HTTP MCP endpoint for machine access and powers projects like IMPC and ExposomeKG.

## Key Features
- Aggregates and merges biomedical data from multiple sources into unified knowledge graphs
- Supports LLM embeddings for semantic enrichment and entity resolution
- Provides a streamable HTTP MCP endpoint for real-time queries
- Includes automated E2E tests with snapshot validation for pipeline integrity
- Enables integrative queries across traditionally siloed biomedical resources

## Why It Matters for RAG Builders
