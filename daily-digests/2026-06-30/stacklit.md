## Summary
stacklit is a tool designed to index codebases for AI agents with a single command, enabling users to build a local map of their repository without requiring server setup or complex configurations.

## Key Features

- No server requirements or external setup needed
- Generates a local map of repository structure and dependencies
- Simplifies integration of AI agents with code repositories
- Lightweight and CLI-driven for ease of use
