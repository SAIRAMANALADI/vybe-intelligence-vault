## Summary
TEDI is a lightweight, all-in-one development environment that consolidates eight essential tools (terminal, SSH client, DB browser, editor, AI agent, browser, Git, and workspace manager) into a single window, eliminating the need for constant window switching. Built on Tauri 2 with Rust and a single webview, it prioritizes performance and privacy with a 7-10 MB footprint and no telemetry.

## Key Features
- Integrated terminal multiplexer with pane splitting, tab groups, and shell integration
- Built-in AI agent with multi-provider support (OpenAI, Anthropic, local LM Studio) and project memory
- In-app browser controlled by AI for navigation, interaction, and screenshot capture
- Extension system for runtime-installable tools (e.g., SQL explorer, themes, AI tools)
- Cross-platform support (macOS, Linux, Windows) with minimal footprint (~7-10 MB)

## Why It Matters for RAG Builders
TEDI streamlines AI engineering workflows by unifying critical development tools into a single, lightweight interface, reducing context switching and enabling seamless AI-agent integration for coding and debugging tasks.
