## Summary
A Model Context Protocol (MCP) server that enables AI agents to perform unlimited, real-time Google web searches directly through a Chrome browser via Kimi WebBridge, without API keys or rate limits. It automates search, pagination, and content extraction into clean markdown for agent consumption.

## Key Features
- Unlimited Google web search without API keys or rate limits
- Automated pagination and content extraction into clean markdown
- Multi-level search depth (low, medium, high, crazy) with configurable results
- Seamless integration with 8+ IDEs/CLIs via MCP auto-configuration
- Real-time, no-cache execution with URL-based deduplication

## Why It Matters for RAG Builders
It provides AI agents with direct, unlimited, and real-time access to web search results without API constraints, enabling richer and more accurate RAG pipelines.
