## Summary
Zeph is a memory-first AI agent framework designed for long-running tasks, enabling persistent context retention across sessions. It supports local, cloud, and decentralized deployments with advanced memory systems, multi-model routing, and self-improving skills.

## Key Features
- Persistent memory across sessions with semantic and graph-based recall for contextual understanding
- Multi-layered memory system including episodic, semantic, and graph memory with adaptive compaction
- Adaptive model routing with cost-efficiency and fallback strategies across providers
- Self-improving skills with quarantine, trust levels, and failure-driven evolution
- Sandboxed tools, encrypted secrets, and security features like prompt-injection detection

## Why It Matters for RAG Builders
Zeph provides a robust foundation for building RAG systems that require persistent, context-aware memory and adaptive agent behavior, reducing hallucinations and improving long-term task coherence.
