## Summary
A cognitive framework that transforms AI agents into disciplined senior architects, enforcing evidence-first thinking, uncertainty mapping, and traceable architecture documentation for existing systems or raw ideas before suggesting changes or edits.

## Key Features
- Enforces evidence-first thinking and uncertainty mapping in AI agents
- Supports two operating modes: Existing System Mapping and Idea-to-Architecture
- Generates traceable Markdown and Mermaid architecture maps with SVG artifacts
- Provides right-sized architecture passes (Scan, Focus, Full) for scalable outputs
- Includes reusable templates, rules, and examples for consistent documentation

## Why It Matters for RAG Builders
It ensures AI agents produce reliable, human-trustworthy architecture documentation and handoff notes, reducing risks of unsupported claims and overengineering in RAG systems.
