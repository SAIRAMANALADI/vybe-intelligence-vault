## Summary
h1-brain is a Windows-based tool that bridges AI assistants with HackerOne, enabling non-technical users to automate bug bounty hunting tasks. It acts as a server-side intermediary to connect AI-driven vulnerability analysis with the HackerOne platform.

## Key Features
- Connects AI assistants to HackerOne for automated bug bounty tasks
- No coding required for setup or operation
- Secure local credential storage with user-controlled permissions
- Dashboard for tracking active bugs, submissions, and AI suggestions
- Supports MCP-compatible tools for detailed search and analysis
