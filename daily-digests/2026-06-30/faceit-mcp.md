## Summary
faceit-mcp is a tool that bridges FACEIT gaming statistics with the Claude AI assistant using the Model Context Protocol (MCP). It enables real-time access to CS2 player stats, match history, and Elo ratings directly within Claude, enhancing AI-driven gaming insights without requiring FACEIT account credentials.

## Key Features
- Real-time CS2 match tracking and live stats
- Direct integration with Claude AI via MCP for seamless data retrieval
- Public FACEIT profile data access without requiring login credentials
- Multi-profile support for tracking multiple players
- Automated data updates for accurate and up-to-date statistics
