## Summary
LeanKG is a lightweight tool that builds a local knowledge graph from codebases to provide precise context for AI coding assistants, reducing token waste and improving response accuracy. It optimizes AI interactions by sending only relevant code snippets instead of entire project folders.

## Key Features
- Intelligent project mapping to identify relevant code snippets
- Token-efficient AI context generation for reduced costs
- Local knowledge graph storage for privacy and speed
- Multi-tool support for various AI assistants (Claude, Gemini, etc.)
- Refreshable context maps for up-to-date AI responses

## Why It Matters for RAG Builders
LeanKG directly addresses the token waste problem in AI coding workflows by providing focused, relevant context to AI models, reducing costs and improving accuracy without requiring cloud uploads.
