## Summary
Project Telos provides a local-first MCP workbench for creating, simulating, verifying, and replaying AI workflows with receipts, manifests, and ledgers. It integrates tools for source intake, agent routing, creative engines, and model foundries to ensure inspectable and verifiable AI processes.

## Key Features
- Local-first MCP workbench for AI workflows with stdio and registry support
- Receipt-backed verification for sources, actions, and creative artifacts
- Integrated creative engine with deterministic kernels and measurement layers
- Model foundry for local/open-weight runtimes and self-improving daemons
- Comprehensive CI/CD compatibility and operator UX receipts
