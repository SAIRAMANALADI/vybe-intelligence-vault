## Summary
hara is a TypeScript-based coding agent CLI that operates as a configurable, governed organization of role-agents, enabling task decomposition, multi-provider LLM integration, and multi-platform chat-driven interaction with persistent memory and self-evolution capabilities.

## Key Features
- Role-based agent organization with task routing and governance
- Multi-platform chat gateway (10+ platforms) with two-way image/file support
- Interactive TUI with plan mode, approvals, and parallel task execution
- Persistent memory system with self-evolution and lexical-first search
- Multi-provider LLM support with streaming and vision capabilities

## Why It Matters for RAG Builders
It provides a governed, scalable framework for orchestrating AI agents as an engineering organization, enabling complex task decomposition, multi-provider LLM integration, and persistent memory for RAG systems.
