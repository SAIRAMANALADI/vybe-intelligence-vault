## Summary
nuanua is a personal AI agent framework that enables users to interact with their own AI companion via messaging platforms like Telegram or Slack. It leverages existing Claude Code subscriptions to minimize costs, while providing memory persistence, identity customization, and autonomous self-improvement with safety controls.

## Key Features
- Runs on existing Claude Code subscriptions with no additional API costs
- Persistent memory via Markdown files (3-tier structure: active, semantic, archive)
- Customizable AI identity and personality through guided setup
- Multi-platform support (Telegram, Slack) with seamless switching
- Autonomous self-improvement with user-approved safety gates

## Why It Matters for RAG Builders
It provides a lightweight, cost-effective way to deploy personal AI agents with memory and self-improvement capabilities, reducing reliance on expensive cloud services while maintaining user control.
