## Summary
A hands-on lab for network engineers to build reliable AI agents using MCP, agent skills, and behavioral specifications. It provides a standalone environment with a Nokia SR Linux fabric, MCP tooling, and structured modules for learning agent development and specification-driven workflows.

## Key Features
- Standalone lab environment with Nokia SR Linux fabric via Containerlab
- Two structured modules: converting tools to skills and spec-driven agent development
- Integration with MCP clients (e.g., Claude Code, Cursor, VS Code)
- Automated setup and deployment scripts for rapid environment provisioning
- Behavioral specification templates for predictable agent behavior
