## Summary
oh-my-colab is a methodology and orchestration framework that enhances AI coding agents with persistent memory, disciplined workflows, and team-like coordination. It provides a CLI tool (`ohc`) and multi-platform support to enforce structured development processes, cross-session memory, and parallel agent collaboration.

## Key Features
- Four-layer memory system (SOUL, USER, PROJECT, notepad) for cross-session continuity
- Enforced workflows with keyword-triggered commands (e.g., 'plan this', 'build', 'review')
- Parallel agent team support with five-stage pipeline and automated verification
- Cross-platform compatibility (Claude Code, Cursor, Antigravity, Codex, Gemini)
- Research caching and TDD enforcement to ensure code quality and consistency

## Why It Matters for RAG Builders
It provides the discipline and memory infrastructure that AI coding agents lack, enabling structured, collaborative, and persistent development workflows essential for complex RAG and AI engineering tasks.
