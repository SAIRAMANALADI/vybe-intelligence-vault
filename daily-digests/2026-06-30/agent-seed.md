## Summary
agent-seed is a starter kit for a self-evolving AI assistant that operates using markdown files for input and output. It enables users to set up and interact with AI assistants without requiring deep programming skills or complex configurations, supporting multiple AI engines like Claude Code, Codex, and Devin.

## Key Features
- Uses markdown for clear and manageable AI interactions
- Supports multiple AI engines (Claude Code, Codex, Devin, etc.)
- No programming or complex setup required
- Designed for Windows with minimal system requirements
- Enables self-improvement of the AI assistant through iterative markdown interactions
