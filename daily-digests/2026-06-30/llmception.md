## Summary
llmception is a Windows desktop application that decomposes ambiguous prompts into a decision tree of logical paths, enabling parallel exploration of multiple potential answers. It automates complex reasoning by generating and evaluating branches side-by-side without requiring follow-up questions.

## Key Features
- Converts ambiguous prompts into a visual decision tree for parallel exploration
- Local encryption of API keys with no account or data tracking
- Supports multiple concurrent projects with independent tabs
- Automatic tree depth limiting to maintain system responsiveness
- Exports promising branches as text files for permanent records
