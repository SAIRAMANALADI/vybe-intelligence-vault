## Summary
A remote MCP server enabling AI agents to issue Romanian e-Factura electronic invoices (factura electronica) via the national ANAF/SPV system. It generates UBL 2.1 CIUS-RO XML invoices and uploads them using the merchant's ANAF access token, ensuring stateless, secure, and compliant transactions.

## Key Features
- Generates UBL 2.1 CIUS-RO compliant invoices for Romanian e-Factura system
- Stateless MCP server with no data storage, ensuring privacy and security
- Supports ANAF test and production environments via headers
- Provides tools for invoice creation, status polling, and result download
- Integrates with AI agents via MCP protocol for seamless automation

## Why It Matters for RAG Builders
It enables AI agents to automate compliant Romanian e-Factura invoice issuance, reducing manual effort and ensuring regulatory adherence for businesses operating in Romania.
