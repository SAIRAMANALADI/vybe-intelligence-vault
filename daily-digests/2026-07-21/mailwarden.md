## Summary
mailwarden is a native Gmail MCP server that provides full mailbox control for AI assistants, including unique snooze functionality. It interacts directly with the Gmail API to ensure real-time, accurate mailbox operations without relying on cached snapshots.

## Key Features
- Direct Gmail API integration for live mailbox operations (no cached snapshots)
- Unique snooze functionality with automated resurfacing via dated labels
- Advanced search with live predicate verification to avoid Gmail index false positives
- Full thread retrieval with attachment metadata and body parsing
- Automated snooze sweeping (on-demand, hourly, or continuous)

## Why It Matters for RAG Builders
