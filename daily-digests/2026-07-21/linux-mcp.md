## Summary
A Linux system monitoring server built on the Model Context Protocol (MCP) that provides real-time system information via MCP tools over STDIO transport. It offers comprehensive system diagnostics including CPU, memory, disk, network, processes, Docker, and security metrics.

## Key Features
- Provides real-time system metrics (CPU, memory, disk, network, processes) via MCP tools
- Supports Docker container monitoring and management through MCP-compatible tools
- Includes security auditing features like firewall/SSH/SUID checks and failed login detection
- Offers comprehensive system snapshots combining all tools for holistic diagnostics
- Designed for seamless integration with MCP clients like Claude Desktop or OpenCode

## Why It Matters for RAG Builders
It enables AI agents to dynamically query and monitor Linux systems in real-time, enhancing observability and troubleshooting capabilities for RAG pipelines.
