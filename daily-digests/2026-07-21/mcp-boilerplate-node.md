## Summary
A boilerplate for building Model Context Protocol (MCP) servers in Node.js, providing common utilities, security features, and tooling to streamline MCP server development and deployment.

## Key Features
- Pre-built utilities for MCP server initialization and management
- DNS rebinding protection with configurable allow-lists
- Network interface binding for enhanced security
- Skills submodule for adding modular functionality
- Custom ESLint plugin to enforce MCP-compatible tool parameters

## Why It Matters for RAG Builders
It simplifies the creation of secure and compliant MCP servers in Node.js, reducing boilerplate and enforcing best practices for AI tooling integration.
