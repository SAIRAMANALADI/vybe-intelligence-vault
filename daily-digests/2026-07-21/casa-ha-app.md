## Summary
Casa integrates Claude-powered AI agents into Home Assistant as a Home Assistant app, enabling voice control, Telegram chat, scheduling, and long-term memory for smart home automation. It provides a fleet of agents (primary, voice, and specialists) with secure access to Home Assistant APIs.

## Key Features
- Multi-channel agent interactions (Telegram, voice via Assist, and direct API)
- Specialist subagents with scoped tool permissions for focused tasks
- Long-term memory integration with optional Hindsight server
- Secure secret management via 1Password references
- Cron-style scheduling and timezone-aware automation

## Why It Matters for RAG Builders
Casa enables seamless integration of advanced AI agents into Home Assistant ecosystems, providing secure, multi-modal control and automation for smart homes.
