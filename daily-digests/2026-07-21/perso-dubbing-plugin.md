## Summary
A coding-agent skill plugin that integrates Perso Dubbing's AI-powered video dubbing and subtitle extraction capabilities into coding agents like Claude, Codex, Cursor, and Antigravity. It automates video translation, lip-syncing, and audio separation via the Perso Dubbing API.

## Key Features
- Auto-dubs videos into multiple languages with optional lip-syncing
- Extracts SRT subtitles and translates them via Perso's speech-to-text
- Handles oversized or long media by splitting, processing, and merging automatically
- Supports separation of voice from background audio tracks
- Works across multiple coding agents (Claude, Codex, Cursor, Antigravity) via standardized Agent Skills

## Why It Matters for RAG Builders
It streamlines AI-powered video dubbing and subtitle extraction directly within coding agents, reducing manual effort for multilingual content creation in RAG pipelines.
