## Summary
Chaty is a privacy-focused desktop application that enables 100% offline execution of open-source LLMs and AI agents on local hardware. It combines a chat interface with a local coding agent, RAG knowledge base, vision capabilities, and hands-free voice interaction, all while ensuring no cloud dependency or telemetry.

## Key Features
- 100% offline execution of LLMs with GPU acceleration (Vulkan/Metal)
- Integrated local coding agent with real browser interaction and file editing
- Hybrid RAG knowledge base with OCR for images and strict grounding with citations
- Multi-modal support including vision models, hands-free voice, and design canvas
- Cross-platform desktop app (Windows/macOS) with native performance and hardware optimization

## Why It Matters for RAG Builders
Chaty provides a complete, privacy-preserving local AI stack for developers and users who need offline-capable RAG, coding agents, and multimodal interactions without cloud dependencies.
