## Summary
TangleClaw is a macOS-only AI coding session orchestrator that provides persistent tmux-based sessions for AI agents, ensuring continuity across network drops, device switches, and reconnects. It evolved into a full control plane for AI-assisted development with features like session continuity, methodology enforcement, secure remote access, and a persistent Project Master assistant.

## Key Features
- Persistent AI coding sessions via tmux, surviving network interruptions and device switches
- Structured session wrap with per-session summaries, changelogs, and resume primes for continuity
- Multi-engine support (Claude Code, Codex, Antigravity, Aider, OpenClaw) with per-project routing
- Secure remote access via Caddy ingress with password protection and service tokens
- Project Master assistant for fleet-wide status monitoring and cross-project coordination

## Why It Matters for RAG Builders
TangleClaw ensures AI coding sessions remain uninterrupted and contextually consistent, enabling seamless collaboration and productivity for RAG builders who rely on persistent, recoverable agent interactions.
