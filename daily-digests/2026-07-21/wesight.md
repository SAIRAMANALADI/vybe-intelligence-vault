## Summary
WeSight is an open-source desktop workspace for managing and interacting with local AI coding agents like Claude Code, Codex, and OpenClaw. It provides a unified visual interface for agent setup, chat, tool execution, and runtime monitoring.

## Key Features
- Unified visual workspace for multiple local AI coding agents (Claude Code, Codex, OpenClaw, etc.)
- One-click setup and configuration for agent engines and model providers
- Real-time runtime dashboard tracking tokens, TTFT, TPS, tool latency, and agent steps
- IM Agent Hub for routing tasks to agents via Feishu or other channels
- SkillHub marketplace for discovering, installing, and managing agent skills

## Why It Matters for RAG Builders
WeSight simplifies the orchestration and monitoring of local AI coding agents, reducing setup complexity and providing a centralized workspace for developers building RAG or agent-based systems.
