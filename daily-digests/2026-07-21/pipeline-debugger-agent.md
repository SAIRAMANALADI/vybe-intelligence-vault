## Summary
An AI agent that autonomously diagnoses and fixes failures in ETL data pipelines by analyzing logs, classifying errors, and applying targeted fixes for schema drift while escalating other issues to humans. It demonstrates tool use, memory, and failure recovery in a real-world debugging context.

## Key Features
- Automated failure classification (missing files, schema drift, logic bugs, etc.)
- Safe auto-fix for schema drift with verification and backups
- Long-term memory via ChromaDB for incident tracking and faster diagnosis
- Explicit graph-based agent orchestration with LangGraph
- Comprehensive observability through LangSmith tracing

## Why It Matters for RAG Builders
It provides a practical blueprint for building AI agents that can autonomously debug and recover from failures in critical data pipelines, reducing mean time to resolution (MTTR) and operational overhead.
