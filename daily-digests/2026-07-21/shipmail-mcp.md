## Summary
Shipmail MCP Server is an official Model Context Protocol (MCP) server for Shipmail, a business email provider offering REST API, webhooks, and custom-domain inboxes. It enables MCP-compatible AI agents to interact with Shipmail domains, mailboxes, messages, and threads via streamable HTTP or local stdio transport.

## Key Features
- Official MCP server for Shipmail, enabling AI agents to send, read, and reply to emails via custom-domain mailboxes
- Supports both streamable HTTP (hosted) and local stdio transports for MCP compatibility
- Integrates with Shipmail's REST API, webhooks, and IMAP/SMTP for comprehensive email operations
- Provides a dedicated mailbox for AI agents on custom domains, usable by both agents and humans
- Published as an npm package with active maintenance and clear documentation

## Why It Matters for RAG Builders
It provides AI agents with a dedicated, custom-domain business email inbox that can send, receive, and reply to emails, bridging the gap between agent automation and real-world email workflows.
