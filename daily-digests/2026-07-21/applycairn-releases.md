## Summary
ApplyCairn is a proprietary private career memory tool designed for Codex and Claude Desktop, enabling users to capture work evidence, prepare career cases, and manage job searches with local data control. It emphasizes evidence-backed resumes, accomplishments, and interview preparation without requiring separate model API keys or software fees.

## Key Features
- Private Career Memory workspace for capturing and confirming work evidence
- SHA-256 verified releases for authenticity and integrity
- Integration with Codex and Claude Desktop via plugin marketplace
- Evidence-linked resumes, cover letters, and interview preparation
- Local data control with no mandatory model API keys or software fees
