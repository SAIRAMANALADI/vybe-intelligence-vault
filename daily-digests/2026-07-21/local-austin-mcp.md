## Summary
A Model Context Protocol (MCP) server providing AI agents with real-time, authoritative data about Austin-area properties, civic records, and local services. It integrates 41+ tools to answer property-specific, civic, and real estate queries by pulling from official city, county, and state sources.

## Key Features
- 41+ read-only tools for property, civic, and real estate data in Austin
- Integrates with official city/county/state sources (no API keys required for most tools)
- Composed tools like `austin_property_360` and `austin_relocation` for multi-source queries
- Supports static resources and prompts for reusable AI workflows
- Open-source under Apache 2.0 with active development and community contributions

## Why It Matters for RAG Builders
It provides AI agents with direct, real-time access to authoritative Austin-area data, enabling accurate, context-aware responses for property research, civic queries, and local service recommendations.
