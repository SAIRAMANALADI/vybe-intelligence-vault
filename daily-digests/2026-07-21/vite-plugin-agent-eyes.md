## Summary
A Vite plugin that provides structured runtime logs and debugging capabilities for AI agents, enabling them to read, locate, fix, and verify bugs without prior code inspection. It includes pre-commit risk gates, sanitized auth profiles, and interaction traces for comprehensive debugging.

## Key Features
- Structured runtime logs for API calls, errors, console output, and interactions, cleared on each dev-server restart.
- Pre-commit risk gates with configurable checks (secrets, large files, code smells) to block or warn about problematic commits.
- Sanitized auth profiles and interaction traces to help AI agents reconstruct UI state and debug issues.
- Proxy-level logging for cookies, redirects, and CORS to address network-layer blind spots in fetch requests.
- Automated error screenshots and DOM snapshots for visual and structural debugging of runtime issues.

## Why It Matters for RAG Builders
This plugin enables AI agents to autonomously debug, verify, and fix runtime issues by providing structured logs and pre-commit risk gates, reducing manual intervention and improving development efficiency.
