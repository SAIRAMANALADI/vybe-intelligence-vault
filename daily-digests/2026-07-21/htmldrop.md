## Summary
htmldrop is a service that converts HTML, Markdown, PDF, or image artifacts into shareable, temporary links optimized for AI agents and humans. It provides a simple API, MCP server integration, and a web interface for instant publishing without requiring git or complex setups.

## Key Features
- One-click publishing of HTML/Markdown/PDF/images via API or web UI
- MCP server integration for seamless agent workflows (Claude, Cursor, Codex)
- Temporary artifact links with configurable TTL and optional password protection
- Auto-generated Open Graph preview cards for shared links
- Supports self-hosting with Cloudflare R2 or local filesystem storage

## Why It Matters for RAG Builders
htmldrop simplifies the sharing and persistence of AI-generated artifacts, enabling agents and developers to quickly publish and retrieve content without complex infrastructure.
