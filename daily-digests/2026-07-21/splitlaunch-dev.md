## Summary
SplitLaunch provides package-first A/B testing for customer-owned websites and apps, enabling developers and AI agents to install a package, create URL-based experiments, track conversions, and retrieve performance metrics through an agent-friendly command API.

## Key Features
- Package-first A/B testing installation via `@splitlaunch/ab`
- Agent-friendly command API with structured input/output
- Comprehensive tracking of sessions, conversions, revenue, and contextual data
- Sticky visitor assignment and redirect-based traffic splitting
- Hosted dashboard for account management, API keys, and billing

## Why It Matters for RAG Builders
SplitLaunch enables AI agents to programmatically create, manage, and analyze A/B tests, making it essential for automated experimentation workflows in RAG systems.
