## Summary
MCP-memento is a local-first MCP server that provides AI agents with durable, high-signal memory for repositories, including indexed code context, semantic relationships, fast search, and explicit notes that persist across sessions.

## Key Features
- Local-first MCP server for durable repository memory
- Incremental change detection (filesystem watcher or Git polling)
- Semantic code indexing with language-aware relationships (Go, TS/JS, PHP)
- Explicit note storage and retrieval for repo-scoped memory
- VS Code extension for seamless integration and configuration

## Why It Matters for RAG Builders
MCP-memento enables AI agents to maintain persistent, context-rich memory of repositories, improving RAG accuracy and reducing redundant context retrieval.
