## Summary
An open-source ambient fraud detection agent designed to identify new and emerging fraud patterns by running SQL queries against Metabase and BigQuery. It generates reports and alerts via Slack, leveraging modular skills for deployment, detection, and investigation workflows.

## Key Features
- Modular agent skills for deployment, detection, and investigation workflows
- SQL query templates for known fraud patterns (e.g., email clustering, velocity detection)
- Integration with Metabase and BigQuery for data access and analysis
- Automated daily fraud detection with Slack reporting
- Configurable schema mapping for logical-to-physical database references

## Why It Matters for RAG Builders
It provides a reusable framework for building automated fraud detection systems that integrate with data warehouses and alerting tools, critical for maintaining security in AI-driven platforms.
