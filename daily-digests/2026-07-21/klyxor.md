## Summary
klyxor is an AI-powered coding agent CLI that enables developers to interact with LLMs in Plan/Build modes, delegate tasks to subagents, and manage multi-provider LLM support through a terminal UI with Markdown chat and session persistence.

## Key Features
- Plan/Build modes for read-only and full-access execution
- Subagent delegation with parallel task handling (max depth 2)
- Multi-provider LLM support with dynamic model switching
- Tabbed command palette for sessions, providers, and actions
- Session persistence with token/cost tracking and Markdown export

## Why It Matters for RAG Builders
klyxor streamlines AI-driven coding workflows by providing a structured, multi-agent CLI environment that simplifies LLM interactions and task delegation for developers.
