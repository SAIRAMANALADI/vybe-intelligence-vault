## Summary
Lea is a cross-platform autonomous coding agent that queues and executes tasks headlessly using Claude Code or Codex while you sleep. It tracks usage limits, retries tasks automatically, and provides a menu bar/tray interface for task management.

## Key Features
- Tracks Claude Code usage limits and retries tasks automatically upon reset
- Supports both Claude Code and Codex with isolated, headless execution
- Cross-platform desktop app (macOS menu bar, Windows/Linux windowed)
- Sandboxed execution (Seatbelt on macOS, Docker on Windows/Linux)
- Configurable settings for agents, sandboxing, and task management

## Why It Matters for RAG Builders
Lea enables hands-off, autonomous task execution for AI agents, reducing manual intervention and maximizing productivity during off-hours.
