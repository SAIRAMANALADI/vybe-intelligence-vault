## Summary
NutriGuide AI is a production-ready nutrition chatbot that delivers personalized dietary advice through natural conversation. It combines a LangGraph-based AI agent with RAG, a React frontend, and a Node.js/Express backend to create a full-stack AI-driven application for nutrition guidance.

## Key Features
- Stateful conversation context with session-scoped memory via LangGraph MemorySaver
- Multi-step reasoning agent with intent routing and tool integration (e.g., food logging, USDA API calls)
- RAG pipeline using OpenAI embeddings and Pinecone vector store for nutrition knowledge retrieval
- Full-stack architecture with React frontend, Node.js/Express backend, and TypeScript-based agent
- Comprehensive observability with optional LangSmith tracing and evaluation harness (LLM-as-judge, trajectory matching)

## Why It Matters for RAG Builders
It provides a production-grade reference architecture for building AI agents with RAG, stateful conversations, and full-stack integration, making it essential for developers designing scalable AI-driven applications.
