## Summary
OnIt is an intelligent agent framework designed for task automation and assistance, enabling users to interact with AI models via CLI, web UI, or A2A protocol for multi-agent communication. It integrates with vLLM, OpenRouter, and Ollama for model hosting and leverages MCP tools for web search, file operations, and sandboxed code execution.

## Key Features
- Interactive CLI and web UI for agent interaction with tool access
- Multi-model support via vLLM, OpenRouter, and Ollama
- MCP tool integration for web search, file operations, and sandboxed execution
- A2A protocol support for multi-agent communication and interoperability
- Session persistence and management with tagging and resumption

## Why It Matters for RAG Builders
OnIt simplifies the deployment and orchestration of AI agents, enabling seamless integration with RAG pipelines and multi-agent systems for complex task automation.
