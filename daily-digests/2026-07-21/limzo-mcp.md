## Summary
MCP server providing read-only public Telegram group statistics via the Limzo platform, including leaderboards, activity trends, member levels, and moderation summaries without requiring API keys or accounts.

## Key Features
- Read-only access to public Telegram group statistics via Limzo
- Supports MCP clients (Claude, Cursor, etc.) via stdio or HTTP
- Provides tools for listing groups, fetching group stats, and global network stats
- No API keys or accounts required; leverages existing public data
- Lightweight deployment via npx for quick integration

## Why It Matters for RAG Builders
It enables AI agents to fetch structured public Telegram community data for RAG pipelines without requiring direct API access or complex setup.
