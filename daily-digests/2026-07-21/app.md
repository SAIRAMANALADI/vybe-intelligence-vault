## Summary
One Works is an open-source AI workspace designed to unify agents, tools, adapters, sessions, and local runtime data across multiple platforms like desktop, web, VS Code, and CLI. It enables users to configure AI workflows once and deploy them consistently everywhere.

## Key Features
- Unified AI workspace across desktop, web, VS Code, and CLI
- Extensible plugin architecture for custom AI tools and agents
- Standardized configuration system for consistent AI workflows
- Supports local runtime data and sessions
- Multi-language support with documentation in English and Chinese
