## Summary
Scrumboy is a self-hosted project management and issue-tracking tool that combines lightweight Kanban simplicity with structured workflows, real-time collaboration, and AI agent integrations via MCP. It supports customizable boards, sprints, tags, and multi-language interfaces while offering optional authentication, encryption, and webhook integrations.

## Key Features
- Customizable workflows and sprints with user-defined 'Done' lanes
- Real-time collaboration via SSE-enabled boards and sticky-note walls
- MCP-compatible JSON-RPC API for AI agent interactions
- Multi-language support (23 languages) and PWA for mobile UX
- Optional authentication, encryption, OIDC/SSO, and webhook integrations

## Why It Matters for RAG Builders
Scrumboy provides a flexible, self-hosted project management platform with AI agent integrations, making it ideal for teams seeking customizable workflows and real-time collaboration without vendor lock-in.
