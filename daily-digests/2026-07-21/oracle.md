## Summary
Oracle Assistant is an MCP-powered AI assistant designed for persistent memory, multi-turn conversations, and autonomous actions like code review. It integrates with other coding agents (e.g., Claude Code) and provides tools for web search, knowledge base management, and multi-agent coordination.

## Key Features
- Persistent memory with conversation continuity and token-budgeted history
- Multi-agent coordination with locks, messages, and fencing tokens
- Knowledge base indexing and retrieval (BM25 + semantic search)
- Web search and structured extraction with provider fallbacks
- Soul prompts for customizable AI personalities and skills
