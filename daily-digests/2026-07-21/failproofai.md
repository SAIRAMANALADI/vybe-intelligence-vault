## Summary
FailproofAI is a runtime failure resolution tool for coding agents that hooks into popular agent CLIs (e.g., Claude Code, OpenAI Codex) to detect and block dangerous actions, loops, and secret leaks before they cause incidents. It operates locally with zero latency and provides real-time enforcement and audit capabilities.

## Key Features
- Real-time policy enforcement for coding agents with zero latency
- Supports 15+ agent CLIs including Claude Code, OpenAI Codex, and GitHub Copilot
- 30+ built-in policies for blocking dangerous actions (e.g., force pushes, rm -rf)
- Local audit logging and dashboard for session visibility and policy activity
- Custom policy support via JavaScript/TypeScript for team-specific rules

## Why It Matters for RAG Builders
FailproofAI ensures safe and controlled execution of AI agents by preventing catastrophic failures and security breaches in real-time, making it essential for production-grade RAG and agent systems.
