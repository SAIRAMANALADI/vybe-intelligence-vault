## Summary
Tokenmf CLI (`tmf`) is a command-line tool that enables users to quickly switch and manage LLM providers with a single command, simplifying provider configuration and testing across AI applications.

## Key Features
- Single-command provider switching for any LLM
- Automatic detection of AI app config directories
- Config rollback functionality with `.bak` backups
- Provider latency testing and querying
- Cross-platform filesystem permission handling

## Why It Matters for RAG Builders
It streamlines LLM provider management for AI engineers, reducing setup friction and enabling rapid experimentation with different models.
