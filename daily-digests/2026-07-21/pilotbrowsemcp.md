## Summary
Pilot Browse MCP enables AI agents to control a real Chrome browser via the MCP protocol, allowing autonomous website exploration, manual generation, and reusable workflows. It bridges AI agents with browser interactions for efficient task automation.

## Key Features
- 45+ MCP tools for browser control (DOM operations, network monitoring, tab management)
- Autonomous website exploration with manual generation for token-efficient reuse
- Element marking and workflow recording for guided teaching
- Network API toolkit for request interception, replay, and analysis
- Shadow DOM and contenteditable support for complex web interactions
