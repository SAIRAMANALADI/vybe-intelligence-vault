## Summary
AVE is an open behavioral vulnerability standard for agentic AI components, assigning stable IDs, AIVSS scores, and behavioral fingerprints to potential attack vectors in skill files, MCP servers, and agent plugins. It enables consistent security classification and mapping to frameworks like OWASP MCP Top 10 and MITRE ATLAS.

## Key Features
- Standardized vulnerability records with stable IDs (e.g., AVE-2026-00001)
- OWASP AIVSS v0.8 scoring for severity assessment
- Mapping to OWASP MCP Top 10, MITRE ATLAS, and NIST AI RMF frameworks
- Reference implementation via Bawbel Scanner for detection
- Comprehensive record set (59+) covering prompt injection, tool poisoning, data exfiltration, and more

## Why It Matters for RAG Builders
It provides a critical missing layer for securing agentic AI systems by standardizing behavioral vulnerabilities that traditional software security tools cannot detect.
