## Summary
Cartograph is a local-first code intelligence tool that builds a knowledge graph of repositories to enable precise queries for symbols, callers, impact analysis, and code-health signals. It operates as a CLI, MCP server, and TypeScript library, reducing the need for repeated file scans by agents or developers.

## Key Features
- Builds a local knowledge graph of repositories for structural queries (symbols, callers, impact radius, affected tests)
- Supports multiple storage backends (SQLite, PostgreSQL) and deployment modes (CLI, MCP server, TypeScript library)
- Provides an interactive local viewer for visualizing code graphs, health metrics, and agent traces
- Integrates with AI coding agents via MCP for real-time tool calls and context planning
- Offers optional LLM features (summaries, semantic search) with support for local and cloud backends

## Why It Matters for RAG Builders
Cartograph reduces token waste and latency for RAG/AI stacks by replacing repeated file scans with a local knowledge graph, enabling precise and efficient structural queries for agents.
