## Summary
Agent Mesh enables auditable multi-agent coordination for OpenCode by spawning parallel agents as independent OS processes, facilitating peer-to-peer collaboration with witnessed receipts and quorum ratification. It provides a robust audit trail for tracking agent actions and decisions.

## Key Features
- Spawns parallel agents as independent OS processes for true concurrency
- Provides witnessed receipts and per-recipient acknowledgments for auditability
- Supports quorum-based ratification (councils) for decision-making
- Offers 25 MCP tools for fleet management, messaging, and routing
- Includes CLI and TUI for real-time fleet inspection and monitoring

## Why It Matters for RAG Builders
Agent Mesh is essential for RAG builders who need auditable, multi-agent workflows with peer-to-peer collaboration and decision ratification, ensuring transparency and accountability in agent interactions.
