## Summary
PlugBoot is a portable workspace that enables AI agents (e.g., Claude Code, Gemini CLI) to operate with persistent memory and structured project management. It provides a YAML-based state management system, real-time dashboard, and toolbox registry to scale AI-driven workflows across multiple projects without context loss.

## Key Features
- Persistent workspace with YAML-based state management for AI agents
- Real-time dashboard for monitoring and controlling AI-driven projects
- Toolbox registry to dynamically enable/disable AI skills and agents
- Inbox system for organizing external data into structured pillars
- Cross-project scalability with per-project boards, missions, and toolboxes

## Why It Matters for RAG Builders
PlugBoot eliminates context loss in AI workflows by providing a persistent, structured workspace that enables agents to remember and build upon past work, making it essential for scalable RAG and AI automation systems.
