## Summary
Regression Surgeon is a Cloudflare-native AI agent that investigates UX latency regressions by tracing them through a full-stack application, correlating degraded releases with GitHub evidence, and generating a minimal remediation preview. It demonstrates a multi-step AI agent workflow with immutable evidence and approval-gated operations.

## Key Features
- Automated UX latency regression investigation with five bounded evidence phases
- Immutable GitHub evidence correlation (commits, PRs, blobs) for traceability
- Approval-gated draft PR generation with write-disabled runtime by default
- SQLite-backed Durable Objects for conversation state and D1 for telemetry
- Deterministic local and live deployment modes with credential-free verification

## Why It Matters for RAG Builders
It provides a production-grade blueprint for building AI agents that investigate, trace, and remediate regressions using immutable evidence and controlled workflows.
