## Summary
MCPhantom is a local web dashboard designed for security reconnaissance and exploitation of MCP (Model Context Protocol) endpoints. It enables users to discover exposed resources, tools, and prompts, then interact with them via a security-focused UI while supporting targeted vulnerability testing.

## Key Features
- MCP endpoint enumeration and discovery of resources, tools, and prompts
- Interactive web dashboard for manual and automated security testing
- Modular plugin architecture for extensible vulnerability detection (SQLi, SSRF, IDOR, etc.)
- Smart targeted scanning with parallel execution and live streaming results
- Proof scoring and classification for findings to reduce false positives

## Why It Matters for RAG Builders
MCPhantom provides a specialized toolkit for auditing MCP endpoints, which is critical for securing AI-driven systems that rely on this protocol for context and tool integration.
