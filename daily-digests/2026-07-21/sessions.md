## Summary
sessions is a CLI and MCP-based tool that indexes and enables search across AI coding sessions from multiple tools (Claude Code, Codex, Pi). It provides fuzzy-finding, resumption, agent memory via MCP, and usage reporting for AI workflows.

## Key Features
- Unified search index across multiple AI coding tools (Claude Code, Codex, Pi)
- CLI for fuzzy-finding and resuming past sessions with context-aware commands
- MCP server for agent memory and recall capabilities (e.g., context primers, weekly summaries)
- Token/cost usage reporting with interactive dashboards
- Automated setup and configuration for MCP integration

## Why It Matters for RAG Builders
