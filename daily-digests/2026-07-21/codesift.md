## Summary
CodeSift is a token-efficient code intelligence tool for AI agents that indexes codebases using tree-sitter AST parsing and exposes 150+ MCP tools via CLI or MCP server. It reduces token usage by 61-95% compared to raw grep/read workflows, enabling faster and more cost-effective code navigation for AI-driven development.

## Key Features
- Indexes codebases with tree-sitter AST parsing for precise symbol and structure extraction
- Exposes 150+ MCP tools (55 core + 95 discoverable) for AI agents via CLI or MCP server
- Reduces token usage by 61-95% compared to raw grep/read workflows through incremental indexing and compact output formats
- Supports semantic search, Mermaid diagram generation, and cross-repository queries
- Provides hooks for auto-indexing, wiki generation, and architectural context injection for AI agents

## Why It Matters for RAG Builders
CodeSift drastically reduces token costs and improves efficiency for RAG pipelines by providing structured, symbol-aware code intelligence that AI agents can query with minimal overhead.
