## Summary
A private, offline AI coding agent that transforms local Qwen models (via Ollama) into a tool-using software agent capable of reading, writing, and executing code directly on the user's machine without cloud dependencies or API keys.

## Key Features
- Zero dependencies and no build step, running pure TypeScript via Node.js
- Supports real tool usage (read, write, edit, bash, multi-agent delegation) with permission gating
- Full offline operation with no data egress or API keys required
- Multi-agent collaboration with live subagent panels and resumable sessions
- Battle-tested with 697 automated tests and strict safety controls (file confinement, command blocking)

## Why It Matters for RAG Builders
It enables developers to build private, air-gapped AI coding assistants that operate entirely on local hardware, eliminating cloud costs and data privacy concerns while providing real tool-using agent capabilities.
