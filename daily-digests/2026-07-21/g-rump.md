## Summary
G-Rump is a native macOS coding agentic harness that provides an agent loop, tool system, provider layer, memory, and safety gates for LLMs to perform tasks on a local machine. It functions as a grumpy, opinionated alternative to tools like Claude Code or Aider, with deep macOS integration and cross-session memory.

## Key Features
- Native macOS app with SwiftUI and Keychain integration for secure key storage
- Cross-session memory system with hybrid vector + keyword + recency recall and deliberate forgetting
- 160+ native tools including files, shell, git, Docker, HTTP, OCR/vision, and Apple-native services
- Multi-provider support (Anthropic, OpenAI, Google, OpenRouter, local Ollama) with native wire formats
- Agent loop with parallel tool execution, retries, and configurable modes (Plan, Build, Spec)

## Why It Matters for RAG Builders
G-Rump provides a robust, local-first agent framework with deep macOS integration and cross-session memory, enabling RAG builders to deploy autonomous coding agents with strong security and customization options.
