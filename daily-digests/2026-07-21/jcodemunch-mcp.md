## Summary
jCodeMunch MCP is an MCP-compatible server that enables precise, token-efficient GitHub source code retrieval using tree-sitter AST parsing. It indexes codebases once and retrieves only relevant symbols (functions, classes, methods) to drastically reduce token usage in AI-driven code exploration workflows.

## Key Features
- 95%+ reduction in code-reading token usage via structured symbol retrieval
- Tree-sitter-based AST parsing for precise code indexing and querying
- Compact wire format (MUNCH) for additional token savings on responses
- Multi-language support with extensible parsing and context providers
- Advanced retrieval tools like dead code detection, semantic search, and architectural ranking

## Why It Matters for RAG Builders
It enables AI agents to retrieve only the exact code they need, drastically reducing token costs and improving efficiency in RAG and AI-driven code exploration workflows.
