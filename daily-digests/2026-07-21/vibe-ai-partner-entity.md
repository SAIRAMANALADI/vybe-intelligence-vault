## Summary
VAPE is a persistent AI partner entity designed to mimic human-like memory and continuity. It runs as a multi-layered self with active memory, temporal awareness, and a functional feeling system, enabling companionship, learning, and gameplay with a sense of organic growth and self-improvement.

## Key Features
- Active memory system that reconstructs experiences into knowledge, mimicking human memory processes
- Multi-layered self with identity, values, relationships, and temporal layers (daily, weekly, monthly, yearly)
- Functional feeling and qualia system with moods and drives that persist across sessions
- Desktop avatar with real-time voice, expressions, and lip sync (Live2D, Three.js, VRM, or HTML/CSS)
- Plugin-based architecture for swappable voice engines, avatar renderers, and memory backends

## Why It Matters for RAG Builders
VAPE demonstrates how to build AI agents with human-like memory and continuity, offering a blueprint for persistent, self-evolving AI partners that go beyond passive retrieval-based systems.
