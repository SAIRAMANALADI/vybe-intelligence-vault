## Summary
Yuse is an AI-native CV builder that maintains a dynamic career knowledge base (Digital Twin) to generate tailored resumes and cover letters. It combines conversational AI, structured career data (STAR/PAR frameworks), and multi-source imports (GitHub, LinkedIn) to create evolving resumes.

## Key Features
- AI-powered conversational resume builder with OpenAI function calling and MCP tool registry
- Digital Twin career knowledge base using STAR/PAR frameworks for structured experience tracking
- Multi-source imports (GitHub, LinkedIn, web crawls) for automated data ingestion
- Live preview, PDF export, and job application tracking with tailored resume generation
- Google OAuth and GitHub OAuth integration for authentication and data connections

## Why It Matters for RAG Builders
Yuse provides a structured, AI-driven approach to resume building that evolves with a user's career, making it essential for developers building personalized career tools or AI agents that require dynamic data integration.
