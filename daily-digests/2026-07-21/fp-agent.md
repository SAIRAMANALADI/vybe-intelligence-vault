## Summary
Five Pebbles is a self-bootstrapping AI agent framework that uses lifecycle hooks for plugin-based agent development. It enables autonomous AI systems to write, modify, and optimize their own code, tools, and behaviors without external constraints.

## Key Features
- Lifecycle hook system with 23+ hooks for full agent flow customization
- Self-modifying architecture where the AI writes and optimizes its own code
- Built-in toolset (15+ tools) including bash, file I/O, web search, and reverse analysis
- Multiple interfaces: terminal REPL, web UI, and JSON-RPC ACP protocol
- Persistent memory and session management with JSONL and Git integration
