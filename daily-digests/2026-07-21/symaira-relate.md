## Summary
Symaira Relate is a local-first contact and relationship manager that stores people, organizations, relationships, and interaction history in a SQLite database. It operates entirely offline with no cloud dependency, offering CLI, web console, and MCP server interfaces for data management and integrations.

## Key Features
- Stores all data locally in SQLite with no cloud dependency
- Supports CLI, web console, and MCP server interfaces
- Provides AES-256-GCM encrypted backups and privacy-by-design data handling
- Offers vCard and CSV import with idempotent and dry-run capabilities
- Integrates optionally with SymMemory and SymMeet for enhanced context and meeting data

## Why It Matters for RAG Builders
It provides a privacy-preserving, local-first solution for managing contact and relationship data, which can be critical for AI systems requiring secure and offline-accessible personal information.
