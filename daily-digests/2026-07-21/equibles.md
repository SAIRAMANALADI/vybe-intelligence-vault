## Summary
Equibles is an open-source, self-hosted financial data platform that scrapes, stores, and serves SEC filings, institutional holdings, insider trading, congressional trades, and economic indicators. It exposes this data via an MCP server for AI assistants and includes a web portal for interactive exploration.

## Key Features
- Comprehensive financial data aggregation from multiple authoritative sources (SEC, FINRA, FRED, etc.)
- MCP server for direct AI assistant integration with tools for holdings, insider trading, SEC documents, and more
- Self-hosted deployment with Docker support and optional managed service
- Web portal for interactive data exploration and visualization
- Vector embedding support for semantic search and RAG applications

## Why It Matters for RAG Builders
Equibles provides a critical financial data layer for RAG systems, enabling AI agents to access real-time and historical financial insights with structured, queryable endpoints via MCP.
