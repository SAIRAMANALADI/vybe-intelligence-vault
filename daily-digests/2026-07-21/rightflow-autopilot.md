## Summary
RightFlow Autopilot is an explainable Qwen-powered agent designed to transform ambiguous citizen narratives into validated case facts for social-rights caseworkers. It ensures human-in-the-loop validation before executing deterministic screening tools to identify relevant support pathways without issuing official eligibility decisions.

## Key Features
- Strict fact extraction and validation using Qwen with an allowlist to ensure accuracy
- Human approval checkpoint before consequential tool execution to prevent errors
- Deterministic screening for relevant support pathways (older-person support, home-care, GSS review)
- Comprehensive audit timeline for explainability and traceability
- Multi-environment deployment (Alibaba Cloud Function Compute, Docker/ECS)

## Why It Matters for RAG Builders
