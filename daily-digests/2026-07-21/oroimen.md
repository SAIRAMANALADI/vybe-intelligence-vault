## Summary
Oroimen is a local-first personal AI assistant that prioritizes user privacy by running entirely on local hardware with optional cloud escalation. It supports file-based RAG, memory, and secure prompt injection defenses while allowing explicit opt-in to cloud models like GPT-5.6.

## Key Features
- Local-first execution with optional cloud escalation via explicit opt-in
- Multi-tier embedding and LLM providers (local Ollama, optional edge/cloud tiers)
- Three-layer prompt injection defense (XML escape, tagged boundaries, system rules) validated against public benchmarks
- One-command local setup with Docker Compose and no GPU requirement
- OpenAI-compatible HTTP API and WebUI for seamless integration and file-based RAG

## Why It Matters for RAG Builders
Oroimen provides a privacy-preserving, local-first alternative to cloud-based AI assistants, making it essential for RAG builders who prioritize data security and control without sacrificing functionality.
