## Summary
A Windows desktop application that enables local semantic search for documents without requiring API keys or cloud access. It indexes files locally and integrates with MCP clients for contextual search across notes, reports, contracts, and code files.

## Key Features
- Local semantic search without cloud dependency
- Integration with MCP clients for contextual AI workflows
- Supports multiple file formats (PDF, TXT, Markdown, DOCX, HTML, code files)
- Privacy-focused with no API keys or cloud access required
- Simple setup with folder indexing and real-time updates
