## Summary
tinystruct-mcp is a Java-based Model Context Protocol (MCP) server that enables AI agents to interact with file systems and GitHub operations through modular, annotation-driven tools. It bridges LLMs with external systems for secure and efficient tool integration.

## Key Features
- Modular architecture with Maven for easy expansion and tool isolation
- Annotation-driven tool development with @Action and @Argument for automatic schema generation
- Pre-built tools for Git, GitHub API, and local file system operations
- Extensible design leveraging the tinystruct framework for high-performance Java applications
- Standardized JSON-based communication using org.tinystruct.data.component.Builder

## Why It Matters for RAG Builders
It provides a standardized, modular way for AI agents to securely interact with file systems and version control, essential for building dynamic RAG pipelines.
