## Summary
A private, open-source AI-text checker that runs entirely on the user's machine, offering both a browser-based static web app and an MCP server for AI assistants to detect AI-like writing patterns and suggest improvements without sending data externally.

## Key Features
- Local AI-text detection with confidence scoring
- Grammar and style improvement suggestions
- MCP server integration for AI assistants
- Static web app for browser-based use
- No external data transmission

## Why It Matters for RAG Builders
It provides a privacy-preserving way for AI builders and writers to detect AI-like writing patterns and improve content quality directly on their machines.
