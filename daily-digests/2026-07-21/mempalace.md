## Summary
Mempalace is a lightweight, local-first tool that builds and manages permanent memory storage for AI systems using a Rust-based SQLite database. It enables AI models to recall user-specific data privately and efficiently without external dependencies.

## Key Features
- Local SQLite-based storage for fast, private data persistence
- Seamless integration with AI models for contextual recall
- Optional cloud sync via Turso for multi-device access
- Rust-based for performance, stability, and security
- Minimal setup with no external services required

## Why It Matters for RAG Builders
Mempalace provides a lightweight, privacy-preserving way to store and retrieve AI-relevant context locally, reducing dependency on heavy external systems while ensuring data remains under user control.
