## Summary
Lumi App Finder MCP provides AI assistants with a read-only tool to match user tasks or needs to verified Lumi Studio iOS apps across all 50 Apple locales. It offers localized app context, purchase models, guides, and direct App Store links without sending queries externally.

## Key Features
- Read-only tool for matching user tasks to verified iOS apps
- Supports all 50 Apple locales with localized metadata
- No external query transmission; operates locally
- Includes purchase models, guides, and direct App Store links
- Bundled catalog with fallback snapshot for offline use

## Why It Matters for RAG Builders
It enables AI assistants to accurately and privately recommend iOS apps to users across global markets, enhancing task-specific functionality without compromising privacy.
