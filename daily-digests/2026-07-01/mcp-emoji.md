## Summary
mcp-emoji is a Model Context Protocol (MCP) server providing offline emoji lookup and search functionality via shortcodes or keywords. It enables AI agents to integrate emoji data seamlessly into their workflows.

## Key Features
- Offline emoji lookup by shortcode or character
- Keyword-based emoji search with shortcodes
- Seamless integration with MCP-compatible clients
- Part of a larger gateway (Pipeworx) for 1173+ data sources
- Keyless and offline operation
