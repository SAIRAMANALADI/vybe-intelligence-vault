## Summary
cachly-mcp is an MCP server that provides persistent, shared AI memory for development teams by automatically learning from git history and commits. It enables AI assistants to retain context across sessions and share institutional knowledge, reducing repetitive explanations and improving debugging efficiency.

## Key Features
- Automatic learning from git history and commits with zero extra calls
- Shared team knowledge graph with causal root-cause analysis
- Pre-briefed AI sessions with relevant past lessons and fixes
- Model-neutral MCP integration supporting Claude, Cursor, Copilot, and others
- Provable recall quality with +22.2% Precision@1 over raw text search

## Why It Matters for RAG Builders
It eliminates AI amnesia and knowledge silos by providing persistent, shared memory that gets smarter with every commit, enabling teams to retain institutional knowledge and reduce repetitive context rebuilding.
