## Summary
mmos is a memory-native AI agent architecture designed to run directly from portable storage (USB/SD) for persistent, offline-capable agent interactions. It uses Rust and LMDB to ensure long-term data integrity and seamless continuity across devices.

## Key Features
- Portable agent memory stored on USB/SD cards for lifelong continuity
- Rust-compiled binary with no runtime dependencies for stability
- LMDB-based storage engine for fast, reliable data persistence
- Modular architecture with sub-agents, domain management, and tool calling
- Supports HTTP, MCP, SSH, and Git for flexible integration

## Why It Matters for RAG Builders
mmos enables AI agents to retain long-term memory and personality across devices without relying on cloud services or deprecated software dependencies.
