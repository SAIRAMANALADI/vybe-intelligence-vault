## Summary
Chronicle is a tool for capturing, summarizing, and making searchable your Claude.ai conversation history locally. It converts conversations into structured markdown summaries, organizes them into time-based entries, and exposes them via an MCP server for seamless retrieval and reflection within Claude Desktop.

## Key Features
- Browser extension for exporting Claude.ai conversations as JSON
- Python CLI pipeline for ingesting, summarizing, and organizing conversations into time-based entries
- MCP server for seamless integration with Claude Desktop for search and retrieval
- Local-first architecture ensuring data privacy and security
- Modular design with clear separation of concerns between extension, pipeline, and MCP components

## Why It Matters for RAG Builders
Chronicle enables RAG builders to create a durable, searchable, and locally managed archive of conversational data, enhancing context retention and retrieval for AI systems.
