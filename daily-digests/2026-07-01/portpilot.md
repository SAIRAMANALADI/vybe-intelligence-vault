## Summary
PortPilot is a local-first desktop application for managing and monitoring development servers across multiple projects and branches. It provides a unified dashboard to track, start, stop, and configure local dev servers with features like port reservation, health checks, and AI agent integration.

## Key Features
- Port reservation and health checks for reliable server management
- AI agent integration for natural language control via MCP-compatible assistants
- Branch and worktree awareness for running multiple git branches simultaneously
- Web portal and VS Code extension for flexible access and control
- Conflict resolution and framework auto-detection for seamless setup
