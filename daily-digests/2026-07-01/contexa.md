## Summary
Contexa is an open-source AI-native post-authentication runtime control plane designed to continuously evaluate and constrain authenticated behavior within Spring Boot applications. It provides zero-trust controls, dynamic authorization, and AI-driven runtime decisions to mitigate exploit windows after authentication succeeds.

## Key Features
- AI-driven runtime decision engine with 5-action controls (ALLOW, CHALLENGE, BLOCK, ESCALATE, PENDING_ANALYSIS)
- Dynamic authorization and policy evaluation at request-time
- Integration with Spring Boot 3.x applications via auto-configuration
- Proof-backed security with verification and benchmark artifacts
- Modular architecture with identity, IAM, and core control planes

## Why It Matters for RAG Builders
Contexa addresses the critical gap in post-authentication runtime security by providing AI-native controls that continuously evaluate and constrain authenticated behavior, reducing exploit windows before remediation is complete.
