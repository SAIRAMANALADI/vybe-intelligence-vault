## Summary
Pern is an offline-first, private AI assistant and developer workspace that runs entirely on-device using embedded Llama models (GGUF). It integrates with WhatsApp, Discord, terminal CLI, and email for a unified, local AI experience without cloud dependencies.

## Key Features
- Runs GGUF models locally via embedded llama-server with no cloud dependencies
- Supports multi-platform deployment (Windows, Android) with tailored UIs
- Deep integrations with WhatsApp, Discord, terminal CLI, and email for real-world automation
- Skills learner and memory system for long-term user insights and tool usage tracking
- Unified onboarding for automatic model setup and hardware optimization

## Why It Matters for RAG Builders
Pern enables RAG builders to prototype and deploy fully offline, privacy-preserving AI assistants with deep system integrations, reducing reliance on cloud APIs while maintaining high functionality.
