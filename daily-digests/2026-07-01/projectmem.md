## Summary
ProjectMem is a local-first memory and judgment layer for AI coding agents that captures decisions, failed attempts, and contextual insights to prevent repetition and improve efficiency. It integrates with AI tools via MCP or plain text exports, offering pre-commit warnings, stale-memory detection, and cross-project memory inheritance.

## Key Features
- Captures and stores AI coding decisions, failures, and context in a local, greppable JSONL store
- Provides pre-commit warnings to prevent repeating failed approaches or modifying high-churn files
- Detects and flags stale memories without deletion, ensuring accountability and human oversight
- Supports cross-project memory inheritance and library-specific gotchas for broader context
- Offers MCP server integration for seamless AI tool compatibility (Claude, Cursor, Antigravity, Codex)

## Why It Matters for RAG Builders
It eliminates redundant AI sessions by preserving institutional knowledge, reducing token waste and improving debugging efficiency for RAG and AI stack builders.
