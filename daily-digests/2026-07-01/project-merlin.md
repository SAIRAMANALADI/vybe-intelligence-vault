## Summary
Ghostwheel is a local-first Windows desktop application that integrates a proprietary AI coding agent with on-device LLM inference, eliminating cloud dependency, API costs, and telemetry while providing unlimited usage on local hardware.

## Key Features
- Runs entirely locally on Windows with no cloud dependency
- Integrates with proprietary Merlin Framework for agent orchestration
- Supports hardware acceleration via CUDA and Vulkan
- Sandboxed tooling with command confirmations for security
- Offline capability with 14-day grace token for model updates

## Why It Matters for RAG Builders
Ghostwheel enables RAG builders to deploy local, privacy-preserving AI agents without cloud costs or telemetry, ideal for environments requiring strict data control.
