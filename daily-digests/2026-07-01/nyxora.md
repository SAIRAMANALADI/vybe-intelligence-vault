## Summary
Nyxora is a secure, non-custodial runtime infrastructure for autonomous onchain agents, enabling AI-driven Web3 operations with strict client-side key isolation and zero-trust security. It supports autonomous workflows, DeFi automation, and integrates with major AI providers and Web3 ecosystems.

## Key Features
- Zero-trust, defense-in-depth security architecture with cryptographic approvals and human-in-the-loop validation
- Non-custodial key isolation and client-side BYOK (Bring Your Own Keys) for DeFi and market data providers
- Advanced DeFi automation including swaps, liquidity provision, yield farming, and cross-chain routing via meta-aggregators
- Native Model Context Protocol (MCP) support for secure AI agent integration with tools like Claude Desktop and Cursor
- Real-time portfolio tracking, transaction history, and adaptive slippage protection for secure trading
