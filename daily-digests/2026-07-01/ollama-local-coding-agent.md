## Summary
A private, offline AI coding agent that transforms local Qwen models via Ollama into a tool-using software agent capable of reading, writing, and editing files, executing commands, and performing multi-agent tasks without cloud dependencies or API keys.

## Key Features
- Truly private and offline operation with zero network egress or API keys
- Real tool-using agent with file operations, command execution, and multi-agent delegation
- Zero dependencies and no build step, running directly via Node.js
- Permission-gated actions with file confinement and safety mechanisms
- Resumable sessions, long-term memory, and context compaction for efficient workflows

## Why It Matters for RAG Builders
It enables developers to build and deploy private, autonomous coding agents locally without cloud dependencies, ensuring data privacy and cost efficiency for RAG and AI stack builders.
