## Summary
knitbrain is a local-first MCP server that enhances coding agents with token optimization, a compounding wiki for project memory, and an autonomous closed-loop workflow engine. It integrates seamlessly with agents like Claude Code, Cursor, and Copilot to reduce context window usage while maintaining lossless data integrity.

## Key Features
- Lossless token compression with 46-68% average reduction in tool output size while preserving 100% data fidelity
- Compounding wiki for persistent project knowledge with automated indexing, cross-linking, and session logging
- Closed-loop workflow engine for goal-driven task execution with verify-gated iterations and audit trails
- Tier-routed task classification and agent composition for adaptive workflow scaling
- Live dashboard for real-time optimization metrics, knowledge graph visualization, and activity monitoring
