## Summary
FrootAI is a vendor-neutral, eval-first framework for building and orchestrating composable AI agents and solution plays. It provides a unified ecosystem for infrastructure, platform, and application teams to develop deterministic and reliable GenAI solutions with MCP compatibility and edge-native deployment.

## Key Features
- Vendor-neutral agent deployment across multiple LLM providers (Claude, GPT, Gemini, etc.) without rewriting code
- Eval-first architecture with 638/638 spec conformance and regression-tested quality gates
- Composable solution plays and skills with 100+ pre-built templates for rapid AI development
- Edge-native MCP server with near-zero cold-start via Cloudflare Workers and Durable Objects
- Open-source-first approach with MIT licensing and inspectable code to prevent vendor lock-in

## Why It Matters for RAG Builders
FrootAI provides a critical glue layer for RAG/AI stack builders by enabling vendor-neutral, eval-gated agent orchestration with deterministic outcomes and edge-native performance.
