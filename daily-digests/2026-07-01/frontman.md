## Summary
Frontman is an open-source AI coding agent that integrates with frontend frameworks to enable real-time, browser-based editing of live applications. It allows users to describe changes in plain English while viewing the rendered app, automatically editing source files with hot reload support for Next.js, Astro, and Vite-based projects.

## Key Features
- Real-time DOM and component tree inspection for precise context
- Natural language-driven frontend changes with instant hot reload
- Framework middleware for Next.js, Astro, and Vite (React/Vue/Svelte)
- BYOK (Bring Your Own Key) LLM provider support (Claude, OpenAI, OpenRouter)
- Open-source with Apache 2.0 (client) and AGPL-3.0 (server) licenses

## Why It Matters for RAG Builders
Frontman bridges the gap between AI-assisted coding and visual frontend development, enabling non-developers to make precise changes while preserving engineering workflows and review processes.
