## Summary
Mitii AI Agent is a local-first, self-hosted coding assistant that combines hybrid SQLite memory with Model Context Protocol (MCP) tool integration to deeply understand and modify codebases while protecting token budgets and enforcing safety policies. It operates entirely offline, ensuring full data privacy and control.

## Key Features
- Hybrid workspace indexing with FTS5, vectors, and PageRank for deep codebase understanding
- Plan/Act/Review workflow with structured task decomposition and approval policies
- Built-in safety controls including autonomy presets, approval queues, and command blocking
- Long-term memory via SQLite with hybrid search (FTS5 + vectors) and session logging
- Seamless MCP tool integration for filesystem, memory, and sequential-thinking without external dependencies

## Why It Matters for RAG Builders
Mitii provides a robust, privacy-preserving framework for building AI-powered coding agents that deeply understand codebases while enforcing strict safety and token budget controls, making it essential for RAG/AI stack builders focused on secure, local-first solutions.
