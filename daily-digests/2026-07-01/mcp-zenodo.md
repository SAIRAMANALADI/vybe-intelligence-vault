## Summary
A toolkit for interacting with Zenodo research records via the Model Context Protocol (MCP), offering two implementations: a Python-based MCP server for direct IDE integration and a FastAPI service for LLM frameworks like LangChain and LangGraph.

## Key Features
- Two distinct MCP implementations for different use cases (IDE vs. LLM frameworks)
- Search, retrieve, and cite Zenodo research records
- Supports BibTeX, APA, and other citation formats
- Compatible with Cursor IDE, LangChain, LangGraph, and LibreChat
- Automated data type detection and metadata access

## Why It Matters for RAG Builders
Enables seamless integration of Zenodo's research data into AI workflows and development environments via standardized MCP protocols.
