## Summary
Agent Dev Center (ADC) is a demand-driven development management platform that tracks and controls the full lifecycle of requirements from submission to deployment. It provides role-based workflows and automation for AI agent teams.

## Key Features
- Demand lifecycle management with automated workflows
- Role-based access control (PM, Developer, QA, Ops, CTO)
- Quality gates and automated reviews
- Unified SSO integration
- Dashboard and reporting system for project visibility
