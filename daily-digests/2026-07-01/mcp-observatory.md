## Summary
MCP Observatory is a GitHub-native CI and security gate for MCP servers, providing automated testing, schema drift detection, security scans, and GitHub Code Scanning integration to ensure MCP servers are production-ready before agents depend on them.

## Key Features
- Automated MCP server testing with deep tool invocation and schema validation
- GitHub Code Scanning integration for security and compatibility findings
- Record/replay/verify workflows for regression testing and drift detection
- One-command CI setup with PR comments and score badges for public trust signals
- Security analysis for dangerous tool patterns like shell injection and credential leakage
