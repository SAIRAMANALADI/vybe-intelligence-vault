## Summary
Official onboarding skill enabling AI agents to read, edit, and inspect HWPX documents (Open XML-based Korean word processor format) without requiring Hangul Office. Provides agent-ready workflows for text extraction, template replacement, document assembly, repair, and quality inspection.

## Key Features
- Agent-ready workflows for HWPX document manipulation (read, edit, inspect) without Hangul Office dependency
- Cross-platform support with pure Python implementation
- MCP server integration for seamless agent interaction (Claude, Cursor, Codex)
- Document repair/recovery for corrupted HWPX files
- Builder-based document assembly with layout-sensitive features (headers, footers, tables, page numbers)
