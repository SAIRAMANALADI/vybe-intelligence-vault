## Summary
Official SDK, CLI, and MCP workspace for Sendmux, providing multi-language libraries to interact with Sendmux's email APIs, including sending, mailbox management, and administration capabilities across TypeScript, Python, Go, PHP, Rust, and Ruby.

## Key Features
- Comprehensive SDKs for TypeScript, Python, Go, PHP, Rust, and Ruby with shared and surface-specific packages
- CLI tool for managing Sendmux resources and configurations
- MCP server support for local and hosted environments with OAuth and key-based authentication
- Generated clients from OpenAPI snapshots ensuring API contract consistency
- Modular design with separate packages for sending, mailbox, and management APIs

## Why It Matters for RAG Builders
