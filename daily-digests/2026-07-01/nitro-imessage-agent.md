A Windows-based desktop application that automates iMessage interactions by connecting an AI assistant to your messaging account, enabling intelligent replies, logging, and configurable response behaviors without requiring coding knowledge.

## Key Features

- Real-time message logging and history tracking for review and audit purposes
- Adjustable settings for response speed, active hours, and language tone

- Performance monitoring with metrics on messages processed, response times, and errors
