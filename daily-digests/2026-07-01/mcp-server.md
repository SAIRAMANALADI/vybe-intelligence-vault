This repository provides tool implementations for the PlanetScale MCP server, enabling direct interaction with PlanetScale's database services via the Model Context Protocol (MCP). It focuses on locally maintainable TypeScript tools and shared helper code for MCP functionality.

- Supports local development and validation of MCP server tools
