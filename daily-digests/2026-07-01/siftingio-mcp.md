## Summary
A Model Context Protocol (MCP) server that exposes the SiftingIO market-data SDK as tools for AI assistants, enabling real-time access to live prices, SEC/EDGAR fundamentals, OHLCV bars, 13F holdings, market status, and macroeconomic calendars.

## Key Features
- Provides 36+ tools for accessing live market data, fundamentals, and macroeconomic events via MCP protocol
- Supports both stdio and Streamable HTTP transport for MCP clients
- Includes WebSocket streaming for real-time data with subscription and polling capabilities
- Offers structured output and annotations for machine-readable responses
- Features built-in authentication, logging, and session management for secure deployments

## Why It Matters for RAG Builders
This MCP server enables AI assistants to dynamically fetch real-time financial and market data, enhancing RAG systems with up-to-date, structured information for financial analysis and decision-making.
