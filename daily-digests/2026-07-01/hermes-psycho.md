## Summary
A privacy-first framework for building personalized AI psychology assistants that can be adapted to any domain (e.g., anxiety, self-esteem, relationships). It separates methodology, operational playbooks, and agent personas into modular layers, enabling customization without exposing personal data.

## Key Features
- Three-layer architecture: methodology (knowledge/), operational playbooks (protocols/), and agent persona (hermes/SOUL.md)
- Privacy-by-design with public/private data separation and `.gitignore` enforcement
- Domain-agnostic core with vertical-specific examples (e.g., relationships)
- Automated persona generation from `hermes-profile.yaml`
- Built-in privacy checks and structural validation scripts

## Why It Matters for RAG Builders
It provides a reusable, privacy-preserving template for building domain-specific AI assistants that can be tailored to personal needs without exposing sensitive data.
