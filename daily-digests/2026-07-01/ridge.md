## Summary
Ridge is an MCP server that reverse-engineers software architecture from codebases (Go, TypeScript, Python) and markdown directories into structured graphs. It detects services, dependencies, databases, endpoints, and their relationships, enabling automated architecture validation, drift detection, and diagram generation without manual diagramming.

## Key Features
- Automated architecture graph generation from code and markdown with confidence-scored edges
- Cross-substrate support (Go, TypeScript, Python, markdown) with infrastructure detection (databases, queues, caches)
- Drift detection and narrative explanations for architecture changes between git refs
- 19 MCP tools for architecture validation, dataflow tracing, and improvement recommendations
- Diagram generation in 9 formats (Mermaid, PlantUML, C4, Excalidraw, etc.)
