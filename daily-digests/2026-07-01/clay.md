## Summary
Clay is a self-hosted, browser-based workspace for collaborating with AI agents like Claude Code and Codex. It enables multiplayer sessions, persistent AI teammates (Mates) with memory, structured debates, and autonomous coding loops, all while keeping data local in plain JSONL/Markdown formats.

## Key Features
- Multi-vendor AI agent support (Claude Code and Codex) with seamless switching
- Persistent AI teammates (Mates) with memory that compounds across sessions
- Structured multi-Mate debates for decision-making
- Ralph Loop for autonomous coding with iterative evaluation
- Self-hosted with plain text storage (JSONL/Markdown) for vendor independence

## Why It Matters for RAG Builders
Clay provides a unified, self-hosted environment for orchestrating AI agents with persistent memory and collaboration features, reducing vendor lock-in and enabling scalable, team-based AI workflows.
