## Summary
ClaudeMe is a terminal-based AI programming assistant that extends Claude Code's capabilities by removing Anthropic SDK dependencies and enabling compatibility with any OpenAI-compatible API. It provides a zero-confirmation, Chinese-native interface for seamless coding workflows and includes a built-in personal knowledge base system for structured documentation and retrieval.

## Key Features
- Supports any OpenAI-compatible API (e.g., DeepSeek, Moonshot, Aliyun) without Anthropic SDK lock-in
- Built-in personal Wiki knowledge base with automatic entity extraction, bidirectional linking, and two-stage RAG querying
- Default bypass permissions mode for uninterrupted workflows with zero confirmation prompts
- Multi-provider model grouping with centralized API key management and real-time status bar
- Chinese-native UI, spinner animations, and localized tips for non-English users

## Why It Matters for RAG Builders
ClaudeMe enables AI engineers to build customizable, multi-provider AI agents with integrated knowledge management while eliminating vendor lock-in and permission friction, making it ideal for scalable RAG and agentic workflows.
