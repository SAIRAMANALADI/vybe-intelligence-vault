## Summary
A Mock Data Generator MCP server that provides tools for generating fictional person records and lorem ipsum placeholder text. It is part of the Pipeworx ecosystem, offering offline, keyless data generation for testing and seeding purposes.

## Key Features
- Generates fictional person records with realistic fields (name, email, phone, address, etc.)
- Provides lorem ipsum text generation in words, sentences, or paragraphs
- Operates offline and keyless for easy integration
- Integrates seamlessly with MCP clients like Claude Desktop, Cursor, and Windsurf
- Part of the Pipeworx gateway for broader data source access
