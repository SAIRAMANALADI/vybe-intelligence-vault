## Summary
DrawX MCP Server is a Model Context Protocol (MCP) server that enables AI assistants like Claude, Cursor, and VS Code to generate draw.io diagrams and architecture designs directly from natural language prompts. It acts as a bridge between AI tools and the DrawX API, providing tools for diagram generation, architectural design, and API key verification.

## Key Features
- Integrates with AI assistants (Claude, Cursor, VS Code) via MCP for seamless diagram generation
- Provides three tools: `generate_diagram`, `architect_design`, and `whoami` for workflow automation
- Supports multiple modes (flash, pro, ultra) for balancing speed and quality
- Streamlines architectural design with HLD, LLD, and design doc generation
- Includes API key verification and quota tracking for DrawX API access

## Why It Matters for RAG Builders
