## Summary
DocSentinel is an AI-powered Secure Software Development Lifecycle (SSDLC) platform that automates security assessments across all six phases of software development using intelligent agents orchestrated by LangGraph and powered by LangChain. It reviews documents, identifies risks, compliance gaps, and provides structured remediation suggestions.

## Key Features
- Full lifecycle SSDLC coverage with six dedicated AI agents for each phase (Requirements, Design, Development, Testing, Deployment, Operations)
- Multi-format document parsing (PDF, Word, Excel, PPT, SAST/DAST reports) with unified LLM processing
- RAG-powered knowledge base for consistent policy and compliance assessments across projects
- Stateful agent orchestration using LangGraph with conditional branching and human-in-the-loop review points
- Governance workflows with policy packs, control generation, and readiness scoring (Pallas Lens integration)

## Why It Matters for RAG Builders
DocSentinel streamlines and scales security assessments across the entire software development lifecycle, reducing manual effort and ensuring consistent, auditable compliance for AI-driven development workflows.
