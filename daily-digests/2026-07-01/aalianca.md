## Summary
A Aliança is a model-agnostic, Markdown-based adaptive harness generator for LLMs that provides structure, memory, and process guidance to reduce hallucinations, context loss, and technical debt. It dynamically adapts to project complexity, user expertise, and risk levels while maintaining state on disk.

## Key Features
- Just-in-time instruction loading via a router system to minimize context bloat
- Adaptive persona-based guidance (P0 to P3) for beginners to enterprise teams
- State persistence in disk (memory/ and snapshots/) for cross-session continuity
- Forcing function integration for automatic harness enforcement in tools like Claude Code
- Project-level adaptation (setup, adopt, migration) without restarting from scratch

## Why It Matters for RAG Builders
It provides a structured, model-agnostic framework to standardize LLM interactions, reducing context loss and hallucinations while enabling scalable, adaptive project scaffolding for AI-driven development workflows.
