## Summary
ForgeCat Agent Profiles is an open catalog of cross-platform agent profiles designed to standardize and distribute reusable agent workflows, skills, and configurations for tools like Claude Code, Cursor, and Codex. It provides a centralized repository for installable profiles sourced from public projects, ensuring attribution, license compliance, and platform-specific compatibility.

## Key Features
- Centralized catalog of 174+ agent profiles sourced from public repositories
- Cross-platform compatibility for Claude Code, Cursor, and Codex
- Source-faithful packaging with attribution and license metadata
- CLI tool for searching, installing, and managing profiles
- Curated and tested profiles with install/runtime evidence

## Why It Matters for RAG Builders
It simplifies the discovery, reuse, and standardization of agent workflows across multiple AI coding tools, reducing setup time and ensuring consistency for RAG and AI stack builders.
