## Summary
CodeFRAME is a project delivery system that orchestrates AI agents to handle the full software development lifecycle, from requirements gathering to deployment. It automates planning, task decomposition, execution, verification, and shipping while enforcing quality gates through a closed-loop system.

## Key Features
- AI-guided Socratic requirements discovery and recursive task decomposition
- Agent-agnostic execution with support for multiple coding agents (Claude Code, Codex, etc.)
- PROOF9: a 9-gate evidence-based quality system that captures failures as permanent requirements
- Closed-loop system where production glitches automatically generate new proof obligations
- Radical simplicity with a single CLI binary, SQLite backend, and no daemons or infrastructure

## Why It Matters for RAG Builders
CodeFRAME provides a complete upstream pipeline for AI-driven software development, ensuring robust, verifiable, and continuously improving code delivery by orchestrating agents and enforcing quality gates.
