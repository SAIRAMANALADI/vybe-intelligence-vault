## Summary
A modular MCP (Model Context Protocol) suite designed to extend the functionality of the self-hosted Twenty CRM platform. It provides reusable components and a dedicated CRM segment MCP server for integrating AI-driven workflows and data processing.

## Key Features

- Reusable engine with transport, schema cache, and auth primitives
- Dedicated CRM segment MCP server for data processing
- Self-hosted deployment for data privacy and control
- Designed for AI-driven workflows and integrations
