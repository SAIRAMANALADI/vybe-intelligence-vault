## Summary
Contorium is a local-first system that preserves and reconstructs software project intelligence across AI coding environments by maintaining a shared Project Intelligence Layer (PIL) and Cognitive Interaction Layer (CIL) for querying project history, decisions, and evolution.

## Key Features
- Project Intelligence Layer (PIL) for deterministic storage of project state, intent, decisions, and timeline
- Cognitive Interaction Layer (CIL) for natural language querying of project history and rationale
- Time-travel capabilities to inspect project state at specific points in time
- Integration with multiple AI coding environments (Cursor, Claude Code, VS Code, etc.)
- Optional LLM enhancement for explanations, story generation, and essence compression

## Why It Matters for RAG Builders
Contorium enables AI coding tools to retain and query project context, reducing redundant explanations and improving continuity across sessions.
