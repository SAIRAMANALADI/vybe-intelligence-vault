## Summary
A utility kit that backports Unreal Engine 5.8's Model Context Protocol (MCP) editor toolsets to Unreal Engine 5.7 projects without vendoring proprietary source code. It automates fetching, patching, and integrating UE 5.8 MCP plugins into UE 5.7 projects via sparse Git clones and compatibility patches.

## Key Features
- Automated sparse-fetch of UE 5.8 MCP source code from licensed Epic Games GitHub
- Applies compatibility patches to integrate UE 5.8 plugins into UE 5.7 projects
- Provides 414 UE 5.8 parity sub-tools across 40 toolsets for MCP functionality
- Includes project-specific extensions like enhanced asset search and console command execution
- Validates MCP toolset schema post-installation for functional parity

## Why It Matters for RAG Builders
It enables developers to leverage UE 5.8's MCP toolsets in UE 5.7 projects without waiting for official updates, accelerating AI-driven editor tooling adoption.
