## Summary
Herodotus Cloud UI Vuetify is a modern, enterprise-grade frontend framework built with Vue 3, Vuetify (Material Design 3), and Vite for Dante Cloud's microservices architecture. It supports dynamic menu permissions, modular monorepo design, and flexible deployment as either a microservice or monolithic application.

## Key Features
- Supports dynamic menu permissions and multi-role access control
- Modular monorepo design for shared code between microservice and monolithic deployments
- Built with Vue 3 Composition API and Vuetify Material Design 3 for modern UI
- High-performance tree-shaking and optimized frontend code
- Flexible configuration for single-tenant or multi-tenant environments
