## Summary
Null AI CLI is an open-source command-line tool for autonomous offensive security testing and compliance-readiness assessments. It provides a guided, interactive terminal agent for safe reconnaissance, scanner orchestration, evidence-backed findings, and lightweight compliance mapping against frameworks like OWASP Top 10, PCI DSS, ISO 27001, and NIST CSF.

## Key Features
- Guided interactive assessment with persistent REPL and tab completion
- Scoped single-agent loop with hard boundaries and authorization gates
- Normalization of scanner outputs (Nuclei, Semgrep, Trivy) into unified findings
- Markdown and SARIF report generation for CI/CD integration
- Lightweight compliance mapping to OWASP Top 10, PCI DSS, ISO 27001, and NIST CSF

## Why It Matters for RAG Builders
It provides a reproducible, evidence-backed framework for security assessments and compliance readiness that integrates seamlessly into AI-driven RAG pipelines for automated vulnerability analysis and reporting.
