## Summary
A Model Context Protocol (MCP) server that enables seamless GitLab integration with AI assistants like Claude Code. It provides tools for managing issues, epics, labels, CI/CD pipelines, and project metadata directly within AI workflows.

## Key Features
- Direct GitLab API integration for issue, epic, label, and project management
- CI/CD pipeline monitoring with job log access and trace downloads
- Optimized CLI flags to disable unused tools for token efficiency
- Docker and Homebrew deployment options for cross-platform compatibility
- Comprehensive documentation and troubleshooting guides
