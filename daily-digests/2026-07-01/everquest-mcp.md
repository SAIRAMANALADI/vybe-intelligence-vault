## Summary
A Model Context Protocol (MCP) server providing AI assistants with deep access to EverQuest game data, including spells, items, NPCs, zones, quests, and lore from 12 online databases and local game files. Offers 412 tools for comprehensive game data queries and analysis.

## Key Features
- 412 tools for querying EverQuest data (spells, items, NPCs, zones, quests, factions, etc.)
- Multi-source search across 12 online databases and local game files
- Deep spell analysis with effects, stacking rules, and class comparisons
- Local game data parsing for offline access to 70K+ spells and 1600+ factions
- Patch diff detection to track game data changes over time
