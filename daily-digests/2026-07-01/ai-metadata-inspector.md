## Summary
AI-Metadata-Inspector is a Windows-native tool that extracts hidden metadata, including prompts and model information, from AI-generated images and videos. It integrates directly into the Windows file explorer via a right-click menu for quick access and operates entirely locally.

## Key Features
- Extracts hidden prompts and model metadata from AI-generated images/videos
- Integrates seamlessly into Windows file explorer via right-click menu
- Supports batch processing for multiple files
- Operates entirely locally with no data transmission
- Fast processing with results appearing in under one second
