## Summary
Resume Studio is an AI-native workspace for building, tailoring, reviewing, and rehearsing resumes through conversational editing, visual layout design, JD-aware optimization, and mock interviews. It combines agent-driven resume refinement with a visual layout builder and interview simulation tools.

## Key Features
- Conversational AI editing with tool-calling agents for resume refinement
- Visual layout builder with reusable templates and printable HTML/TeX export
- JD-aware optimization for aligning resumes with job descriptions
- Mock interview workspace with resume/JD-grounded questions and review mode
- Local-first architecture with deterministic testing and regression evaluation
