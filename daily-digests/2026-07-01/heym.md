## Summary
Heym is an AI-native workflow automation platform that enables users to build, visualize, and run intelligent AI workflows without coding. It supports multi-agent orchestration, RAG pipelines, MCP integration, and real-time observability with drag-and-drop node-based workflows.

## Key Features
- Drag-and-drop visual workflow canvas with AI Assistant for natural language workflow creation
- Multi-agent orchestration with sub-agents, tool calling, and parallel execution
- Built-in RAG with vector store integration (Qdrant, PostgreSQL/pgvector) and semantic search
- Full observability with LLM traces, cost tracking, evals, and real-time analytics
- MCP support for agent integration and workflow exposure as MCP servers

## Why It Matters for RAG Builders
Heym provides a critical orchestration layer for RAG builders by enabling multi-agent workflows, real-time observability, and seamless integration with vector databases and MCP servers, all in a self-hostable, production-ready platform.
