## Summary
Beever Atlas automates the creation of a self-maintaining wiki from team conversations on Slack, Discord, Teams, and Mattermost. It distills raw chat logs into structured, deduplicated knowledge with citations, enabling traceable Q&A and browsable wikis for teams.

## Key Features
- Multi-platform chat integration (Slack, Discord, Teams, Mattermost)
- Dual-memory architecture (semantic store + graph store) for hybrid retrieval
- Auto-generated, continuously updated wikis with citations
- MCP server for integration with Claude Code and Cursor
- Smart query router for optimal retrieval strategy per question

## Why It Matters for RAG Builders
Beever Atlas transforms noisy chat logs into structured, traceable knowledge bases, reducing hallucinations and enabling reliable RAG systems with auditable citations.
