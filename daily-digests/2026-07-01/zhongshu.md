## Summary
中书 (Zhongshu) is a desktop-native agent runtime that integrates conversation, coding agents, long-term memory, task tracking, tool calls, and a native UI into a single local runtime. It operates as a persistent desktop overlay rather than a chat window.

## Key Features
- Native desktop overlay with GTK/WebView2/WKWebView for immersive UI
- Multi-LLM routing with DeepSeek Flash/Pro and OpenAI-compatible API support
- Coding agent with architecture analysis, conflict detection, and validation gates
- 500K-1M token long-context management with evidence scoring and compression
- Task tracking with Goal → Task → Step closed-loop and runbook recording

## Why It Matters for RAG Builders
It provides a unified local runtime for AI agents with advanced memory, tooling, and self-evolution capabilities critical for building robust RAG systems.
