## Summary
Auto Browser is an MCP-native browser control plane that provides AI agents and operators with a shared Playwright browser, enabling human-in-the-loop workflows, reusable auth profiles, audit trails, and local-first deployment for authorized browser automation tasks.

## Key Features
- MCP-native browser surface with human takeover via noVNC for real-time intervention
- Reusable named auth profiles to avoid repeated logins and enable session reuse
- Built-in safety rails including approval gates, PII scrubbing, and Witness receipts for tamper-proof audit trails
- Local-first deployment with Docker Compose and Codespaces support for quick setup
- Convergence harness for agent skill induction with verifiable, staged skill candidates

## Why It Matters for RAG Builders
It provides a secure, auditable, and human-in-the-loop browser automation layer essential for RAG pipelines that require real browser interactions, ensuring reliability and compliance in agent workflows.
