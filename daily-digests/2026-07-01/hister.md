## Summary
Hister is a privacy-focused, self-hosted search engine that indexes and enables full-text search over locally visited websites and files. It supports advanced query languages, semantic search, and multi-user environments, making it ideal for personal or community knowledge bases.

## Key Features
- Privacy-focused local indexing of web pages and files
- Advanced query language for precise search results

- Document versioning and faceted filtering for enhanced search
