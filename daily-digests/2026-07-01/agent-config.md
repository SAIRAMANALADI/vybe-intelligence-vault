## Summary
agent-config provides contextual continuity infrastructure for AI agents by ensuring memory, skills, and work context persist across sessions, harnesses, and models. It serves as the reference consumer and proving ground for the entwurf substrate, hardening configurations before promotion to the core system.

## Key Features
- Shared memory layer via andenken for semantically searchable session history and knowledge base access
- Skills Single Source of Truth (SSOT) with unified capabilities across multiple AI harnesses (Claude, GPT, Codex, etc.)
- Session continuity protocol enabling rapid context recovery (~2K tokens vs. 50K+ for full recaps)
- Proving ground for entwurf configurations, ensuring stability before core integration
- Cross-harness alignment with asymmetric coexistence (비대칭 공존) to maintain consistent operator experience

## Why It Matters for RAG Builders
It enables AI agents to retain coherent context across sessions and models, eliminating the need to rebuild memory and skills from scratch every time.
