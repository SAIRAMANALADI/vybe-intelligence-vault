## Summary
Spraay x402 MCP Server provides a full-stack DeFi infrastructure for AI agents, exposing 169 pay-per-call tools via the x402 protocol for onchain payments, batch payouts, swaps, bridging, payroll, invoicing, escrow, and AI model access. It integrates with multiple blockchains including Base, Solana, Ethereum, XRP, and Stellar.

## Key Features
- 169 pay-per-call tools spanning AI inference, DeFi, payments, research, and compute
- Integration with 200+ AI models and decentralized networks like Bittensor
- Supports batch payouts, swaps, bridging, payroll, invoicing, and escrow
- Auto-creates and manages wallets for USDC payments on Base
- Zero-config setup with optional remote URL for wallet-free operation
