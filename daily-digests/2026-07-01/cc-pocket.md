## Summary
CC Pocket enables remote control of AI coding agents (Claude Code or OpenAI Codex) from a mobile or desktop app via a zero-knowledge relay. It allows users to approve tool permissions, stream outputs, and manage sessions from anywhere, with end-to-end encryption ensuring privacy.

## Key Features
- Remote approval of AI agent tool permissions from mobile/desktop
- Real-time streaming of agent outputs and live session management
- End-to-end encrypted communication via a zero-knowledge relay
- Support for both Claude Code and OpenAI Codex agents
- Cross-platform compatibility (iOS, Android, macOS, Windows, Linux)

## Why It Matters for RAG Builders
It provides a secure, remote-controlled interface for managing AI coding agents, enabling developers to approve actions and monitor progress from anywhere while maintaining strict privacy through end-to-end encryption.
