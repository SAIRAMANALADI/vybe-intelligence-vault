## Summary
work-buddy is a local-first personal agent runtime that integrates with Claude Code and Obsidian to organize knowledge work by structuring workflows, preserving context across sessions, and deeply integrating with tools like browsers, calendars, and messaging platforms. It enables AI-assisted coordination of tasks, notes, and projects while keeping data local and user-controlled.

## Key Features
- MCP Gateway for dynamic tool discovery and execution with four core tools (wb_search, wb_run, wb_advance, wb_status)
- Workflow Conductor supporting multi-step DAGs with deterministic code steps and agentic reasoning steps, interleaved for efficiency
- Persistent memory and context management via Hindsight, enabling cross-session continuity
- Deep Obsidian integration with plugin-level access to tasks, projects, and notes
- Human-in-the-loop control with consent-gated operations, notifications, and a live dashboard for observability and steering

## Why It Matters for RAG Builders
It provides a structured runtime for coordinating fragmented knowledge work with AI, reducing manual coordination while preserving user agency and keeping data local.
