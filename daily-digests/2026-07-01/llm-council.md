## Summary
LLM Council is a multi-agent system where multiple LLMs collaboratively answer questions through peer review and synthesis. It operates as a Python library, MCP server, or HTTP API, enabling parallel LLM deliberation for higher-quality responses.

## Key Features
- Parallel LLM deliberation with peer review and ranking
- Configurable council tiers (quick, balanced, high, reasoning)
- Chairman LLM synthesizes final responses for consensus
- Supports multiple gateways (OpenRouter, Requesty, direct providers)
- MCP server integration for Claude Code/Desktop and other MCP clients

## Why It Matters for RAG Builders
It enables RAG builders to generate higher-quality, consensus-driven responses by leveraging multiple LLMs for peer review and synthesis, reducing hallucinations and bias.
