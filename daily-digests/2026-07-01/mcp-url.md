## Summary
mcp-url is a Model Context Protocol (MCP) server for URL parsing and building, enabling AI agents to programmatically interact with URLs. It is part of the Pipeworx ecosystem, which provides access to 1148+ live data sources via an MCP gateway.

## Key Features
- Parses URLs into structured components (protocol, host, path, query, etc.)
- Builds URLs from components with support for query objects
- Parses query strings into key-value objects, handling repeated keys as arrays
- Integrates seamlessly with MCP clients (Claude Desktop, Cursor, Windsurf)
- Part of the Pipeworx gateway for unified access to 1148+ data sources
