## Summary
Tochiro is a macOS desktop application that uses an AI agent network to organize files based on natural language instructions. It analyzes messy folders, creates organization plans, and executes file operations with user approval.

## Key Features
- Natural language file organization with AI agents
- Interactive plan drafting and refinement
- Undo functionality for operations
- Standalone PySide6 GUI for macOS
- Supports multiple LLM providers and API keys
