## Summary
Accreted Intelligence is a local-first MCP Work Model that enables AI agents to compound learning from real-world outcomes, turning repetitive tasks into reusable, predictive paths. It integrates with agents like Claude Code and Cursor to automate workflows while retaining institutional knowledge on your hardware.

## Key Features
- Compounds learning from real outcomes into reusable Work Models
- Predicts optimal paths before task execution using past verified results
- Integrates with existing agents (Claude Code, Cursor, etc.) via MCP
- Local-first architecture with no cloud dependency for data storage
- Structured commitment-to-outcome workflow with receipted actions

## Why It Matters for RAG Builders
It enables AI agents to retain and improve from past actions, reducing redundant reasoning and token costs while building institutional knowledge on your hardware.
