## Summary
An MCP server that provides AI-powered architectural decision analysis and ADR management for AI coding assistants, enabling intelligent code generation, decision tracking, and development workflow automation with deep architectural insights.

## Key Features
- AI-powered architectural analysis with confidence scoring via OpenRouter API
- Tree-sitter AST analysis for semantic code understanding and architectural pattern detection
- Smart Code Linking for AI-powered discovery of code files related to ADRs and decisions
- Knowledge Graph for tracking relationships between ADRs, code implementations, and architectural decisions
- Deployment readiness validation with zero-tolerance test validation and hard blocking
