## Summary
The official C# SDK for the Model Context Protocol (MCP), enabling .NET applications to implement and interact with MCP clients and servers. It provides tools for building, hosting, and integrating MCP-compliant systems with LLMs and enterprise identity flows.

## Key Features
- Supports MCP specification v2026-07-28 with backward compatibility for v2024-11-05
- Provides three NuGet packages for modular adoption (Core, Main, AspNetCore)
- Enables Identity Assertion Authorization Grant (ID-JAG) for enterprise SSO scenarios
- Includes hosting and dependency injection extensions for scalable server/client development
- Offers transport diagnostics and security hardening for robust MCP interactions
