## Summary
Mycelium is a Claude Code harness designed to enforce disciplined discovery and evidence-based decision-making before AI agents begin coding. It guides users through structured questioning to validate assumptions, assess risks, and define the smallest viable steps for building, ensuring alignment with user needs and evidence-backed outcomes.

## Key Features
- Structured discovery process with four core questions (problem, audience, riskiest assumption, smallest test)
- Scalable evidence checks at each decision stage to prevent premature coding
- Plain YAML-based project briefs versioned in Git for transparency and auditability
- Adaptive complexity that scales from solo weekend projects to team products
- Built-in self-auditing mechanisms to correct internal biases and gaps

## Why It Matters for RAG Builders
Mycelium ensures AI agents build the right thing by enforcing rigorous discovery and evidence-based decision-making before coding begins, reducing the risk of wasted effort on misaligned or unnecessary projects.
