## Summary
Do-SOUL Alaya is a local-first memory plane for CLI coding agents, designed to provide cross-session, evidence-gated memory management. It ensures durable, auditable, and reversible memory storage in a SQLite database, prioritizing governance and truth over similarity-based recall.

## Key Features
- Cross-session memory persistence in SQLite with no cloud dependency
- Evidence-gated durability with explicit governance decisions
- Six-phase memory lifecycle (Perception, Governance, Durability, Recall, Receipt, Maintenance)
- Built-in benchmarking for recall accuracy and governance integrity
- MCP and CLI interfaces for agent integration

## Why It Matters for RAG Builders
It provides a disciplined, auditable memory system for CLI agents that prioritizes truth and governance over similarity-based recall, ensuring reliable and traceable long-term memory without external dependencies.
