## Summary
An AI-powered interview simulator that conducts real-time, conversational interviews with voice interaction. It adapts questions based on user responses, detects contradictions, and remembers context to simulate a human-like interviewing experience.

## Key Features
- Real-time voice-based interview with automatic transcription and TTS
- Adaptive questioning that detects contradictions and adjusts difficulty dynamically
- Conversational memory using embeddings and semantic search for context retention
- Dual-mode ATS scoring (resume-only or resume + job description match)
- Client-side feedback PDF generation and session analytics

## Why It Matters for RAG Builders
It provides a conversational AI framework with real-time voice interaction, memory, and adaptive questioning, which is valuable for building interactive AI agents and RAG systems that require dynamic, context-aware dialogue.
