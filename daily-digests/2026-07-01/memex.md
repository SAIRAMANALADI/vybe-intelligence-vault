## Summary
Memex is a Windows desktop application that transforms local file folders into personal wikis, enabling users to organize, search, and link plain text notes without requiring databases or servers. It emphasizes privacy by keeping all data local and portable.

## Key Features
- Converts folders into searchable wikis with automatic indexing
- Supports Markdown formatting and cross-linking between notes
- Operates entirely offline with no data transmission
- Lightweight installer with no external dependencies
- Dark/light mode toggle for user preference

## Why It Matters for RAG Builders
Memex provides a simple, privacy-preserving way to structure and retrieve local knowledge, reducing reliance on cloud-based note-taking tools for AI engineering workflows.
