## Summary
A Dockerized Ubuntu 24.04 desktop environment with XFCE4, pre-installed Hermes Agent (Nous Research), and secure browser automation via Chrome DevTools Protocol (CDP). Provides remote access via NoVNC, VNC, or RDP for real-time monitoring and interaction.

## Key Features
- Pre-installed Hermes Agent with secure CDP-based browser automation
- Multi-arch support (amd64/arm64) with auto-variant selection
- Real-time remote access via NoVNC, VNC, or RDP on a shared desktop session
- Integrated web dashboard for agent management, configuration, and monitoring
- Zero-privilege deployment with loopback-bound CDP and scrypt-hashed authentication

## Why It Matters for RAG Builders
It provides a secure, turnkey environment for deploying and testing Hermes Agent's browser automation capabilities with real-time visibility and multi-protocol remote access.
