## Summary
Sentō is a self-improving AI agent framework that runs 24/7, controlled via Discord, Telegram, Slack, or iMessage. It integrates with Claude Code to automate tasks like coding, Git operations, web browsing, and scheduled jobs while learning and adapting over time.

## Key Features
- 24/7 autonomous operation with self-improvement capabilities
- Multi-platform messaging support (Discord, Telegram, Slack, iMessage)
- Persistent memory (ClawMem) and scheduled tasks (cron jobs)
- Auto-restart and self-healing mechanisms (Guardian + Watchdog)
- Agent-to-agent communication with secure pairing

## Why It Matters for RAG Builders
Sentō provides a robust, self-hosted framework for building and deploying autonomous AI agents that integrate seamlessly with existing workflows, reducing dependency on external APIs and enabling scalable, cost-effective automation.
