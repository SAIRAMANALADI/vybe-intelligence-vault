## Summary
A Model Context Protocol (MCP) server that enables AI assistants like Claude and Cursor to interact with Lightdash, a modern BI tool. It allows programmatic discovery of data, execution of queries, creation and management of charts and dashboards, and resource organization within Lightdash.

## Key Features
- Enables AI assistants to interact with Lightdash via MCP for programmatic data access and visualization
- Supports discovery of data catalogs, tables, and schemas within Lightdash projects
- Provides tools for querying, creating, updating, and deleting charts and dashboards
- Includes authentication support for Lightdash instances behind Google Cloud IAP and Cloudflare Access
- Offers resource organization features like creating and managing spaces for content

## Why It Matters for RAG Builders
It bridges AI assistants with Lightdash, enabling automated data analysis and visualization workflows for RAG systems and AI-driven analytics.
