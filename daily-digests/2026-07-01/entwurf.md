## Summary
entwurf is a garden-citizen dispatch substrate that enables existing agent harnesses (e.g., Claude Code, Codex, Antigravity, pi) to communicate with one another using a shared garden ID without requiring ownership of transcripts, authentication, or runtime. It acts as a thin bridge for peer-to-peer messaging, session spawning, and meta-bridge functionality.

## Key Features
- Enables cross-harness communication via garden IDs without transcript ownership
- Supports live control-socket messaging, spawn-bg resume, and meta-mailbox enqueue
- Provides a narrow tool surface for disciplined agent interactions (e.g., auto-approve mode)
- Includes a Claude-first ACP plugin for integration with pi and other harnesses
- Offers a meta-bridge for native Claude Code sessions to become garden-addressable peers

## Why It Matters for RAG Builders
It simplifies cross-harness communication and orchestration for RAG builders by providing a standardized way for agents to interact without losing autonomy or requiring complex integrations.
