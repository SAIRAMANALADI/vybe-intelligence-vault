## Summary
Siclaw is an open-source AI agent designed for DevOps and SRE teams to perform read-only infrastructure diagnostics. It automates evidence gathering, hypothesis testing, and root-cause analysis through a 4-phase workflow, accessible via terminal, web UI, or chat channels.

## Key Features
- 4-phase investigation workflow (evidence gathering, hypothesis testing, root-cause analysis)
- Investigation memory for continuous learning from past incidents
- Read-only by default to ensure safe diagnostics without environment changes
- Multi-channel access (terminal, web UI, chat platforms like Slack)
- Extensible via MCP for integrating external tools and data sources

## Why It Matters for RAG Builders
Siclaw streamlines infrastructure diagnostics for DevOps and SRE teams by automating complex investigations while maintaining read-only safety, reducing mean time to resolution (MTTR) for incidents.
