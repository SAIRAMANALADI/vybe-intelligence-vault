## Summary
FastEval is a lightweight, developer-friendly tool for evaluating AI agents and coding agents like Claude Code or Codex. It supports both sandboxed (Docker) and direct integration modes, enabling rapid testing and debugging of agent frameworks and plugins with minimal setup time.

## Key Features
- Supports sandboxed (Docker) and direct agent integration modes for flexibility
- Rapid setup with excellent developer experience (DX) and minimal configuration
- Generates readable reports and detailed agent behavior insights for debugging
- Modular agent adapters allow integration with any AI agent framework (AI SDK, LangGraph, etc.)
- Built-in experiment tracking and observability tools for optimization
