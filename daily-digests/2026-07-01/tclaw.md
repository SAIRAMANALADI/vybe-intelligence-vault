## Summary
tclaw is a self-hosted personal AI assistant that directly integrates with the Claude Code CLI, enabling multi-channel communication, agent-managed infrastructure, and OAuth connections without reimplementing core functionality. It adds scheduling, MCP tools, and autonomous work sessions on top of Claude's existing capabilities.

## Key Features
- Direct integration with Claude Code CLI for full feature parity
- Multi-channel communication with per-channel tool permissions and memory
- Agent-managed infrastructure including OAuth, Telegram bots, and scheduling
- Autonomous work sessions for ephemeral, scoped tasks
- Self-modifying capabilities to work on its own codebase

## Why It Matters for RAG Builders
tclaw provides a robust framework for building autonomous AI agents that can manage their own infrastructure, handle multi-channel interactions, and integrate with external tools via MCP, making it essential for RAG builders seeking scalable, self-hosted solutions.
