## Summary
OdooTerminal is a browser extension that provides a terminal-like interface for interacting with Odoo instances (versions 11 to 19) via JSON-RPC. It enables developers to execute commands, manage records, and automate tasks without modifying Odoo's core classes.

## Key Features
- Terminal-like interface for Odoo with command execution via JSON-RPC
- Supports CRUD operations, record management, and advanced scripting (loops, functions, nested calls)
- AI mode for autonomous agent interactions within Odoo
- Cross-browser compatibility (Firefox, Chrome, Edge)
- Custom aliases, preferences, and helper functions for enhanced productivity

## Why It Matters for RAG Builders
It streamlines Odoo development and automation by providing a powerful, non-intrusive terminal interface for developers to interact with Odoo instances directly from their browser.
