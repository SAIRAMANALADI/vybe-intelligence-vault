## Summary
A Vue 3-based documentation rendering engine with Quasar v2 and Vite, designed to transform Markdown into interactive, AI-friendly documentation sites featuring i18n, dark/light mode, and advanced AI integration capabilities.

## Key Features
- AI-optimized Markdown rendering with raw text negotiation for LLMs
- Built-in MCP server for AI assistant integration (Claude, VS Code)
- Multi-language support with i18n and locale-aware features
- Dark/light mode with responsive design and anchor navigation
- Advanced AI crawler detection and sitemap generation for RAG pipelines
