## Summary
A Model Context Protocol (MCP) server that integrates with the Google Play Developer API, enabling AI assistants to deploy, manage, and monitor Android apps directly through the Play Store. It provides tools for app releases, store listings, review management, and analytics.

## Key Features
- Full integration with Google Play Developer API for app deployment, release management, and analytics
- Supports multi-language store listings, tester management, and review responses
- Offers per-request credentials for secure multi-tenant deployments
- Includes read-only mode for safe testing and monitoring
- Provides batch operations for simultaneous deployments across multiple tracks

## Why It Matters for RAG Builders
This tool enables AI assistants to directly interact with the Google Play Store, automating complex app management tasks and integrating seamlessly into AI-driven workflows for Android developers.
