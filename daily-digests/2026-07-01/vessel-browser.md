## Summary
Vessel is an open-source Chromium-based browser designed for persistent web agents, offering durable state management, MCP control, and a human-visible supervisory UI. It bridges the gap between autonomous agents and human oversight, enabling long-running workflows where agents drive while humans audit and intervene.

## Key Features
- Persistent browser state with named sessions, checkpoints, and undo/rollback capabilities
- MCP-compatible agent control with a visible supervisory UI for human oversight
- Structured page visibility, schema inference, and agent-driven highlights for context-aware automation
- Built-in chat assistant, skills library, and research desk for agent-assisted workflows
- Cross-platform support (Linux, macOS, Windows) with AppImage, npm, and source install options

## Why It Matters for RAG Builders
Vessel provides a critical runtime environment for autonomous agents that require a real browser with durable state and human supervisory controls, making it essential for RAG/AI stack builders integrating agent-driven web interactions.
