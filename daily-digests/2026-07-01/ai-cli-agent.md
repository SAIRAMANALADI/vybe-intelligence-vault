## Summary
A privacy-first, local AI desktop agent that wraps Gemma 4 in a modular Python framework, enabling autonomous tool execution and real-time streaming output. Runs entirely offline with no cloud dependencies or telemetry.

## Key Features
- Fully local inference with Ollama and Gemma 4, no cloud APIs required
- Autonomous tool-calling loop with structured function schemas and sandboxed execution
- Persistent RAG vault using ChromaDB for long-term document memory and semantic search
- Dual interface: modern browser-based Web UI with 3D effects and collapsible thinking panels, plus classic terminal CLI
- Real-time streaming output with visible chain-of-thought reasoning and tool execution cards

## Why It Matters for RAG Builders
It provides a fully local, privacy-preserving framework for building autonomous AI agents with tool-calling and RAG capabilities, eliminating cloud dependency while enabling advanced AI workflows.
