## Summary
HermesClaw Zero-Config Sidecar is a lightweight, local vector-memory engine designed as a zero-config sidecar for AI agents like Hermes and OpenClaw. It provides persistent memory storage, fast embeddings, and instant retrieval via a PostgreSQL-backed pgvector database and a live dashboard.

## Key Features
- Zero-config setup with Docker and one-line install for agents
- PostgreSQL + pgvector backend for persistent, scalable memory storage
- Interactive dashboard with timeline, semantic search, and tenant isolation
- Memory Galaxy: 3D interactive visualization of memories with orbital clusters
- MCP server integration for seamless agent tooling (capture, search, delete, review)

## Why It Matters for RAG Builders
It provides a critical, persistent memory layer for AI agents, enabling long-term context retention and semantic retrieval without manual vector DB setup, making it essential for RAG and agent autonomy.
