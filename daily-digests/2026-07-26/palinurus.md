## Summary
Palinurus is a suite of Solana-native WASM plugins for the ZeroClaw AI agent runtime, enabling DePIN devices to attest sensor data back to the Solana blockchain. It bridges physical edge devices with on-chain verifiable attestations, emphasizing custody and security through scoped session keys and multisig controls.

## Key Features
- Solana-native WASM plugins for ZeroClaw AI runtime
- Attestation of physical edge sensor data to Solana blockchain
- Scoped session keys for secure signing with custody controls
- PDA derivation and transaction construction in WASM sandbox
- Planned support for DePIN rewards monitoring and alerts

## Why It Matters for RAG Builders
Palinurus enables secure, verifiable attestation of physical edge data to Solana, bridging DePIN devices with on-chain trust, which is critical for building robust RAG systems that require real-world sensor inputs.
