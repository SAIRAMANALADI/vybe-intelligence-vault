## Summary
Fenrir v2 is an autonomous AI-driven trading bot for Solana that executes multi-tier market strategies, including low-cap Pump.fun launches, mid-cap migrations, and large-cap established tokens. It combines real-time WebSocket monitoring, a pluggable strategy system, and an LLM-based decision engine with a live React dashboard for dynamic control.

## Key Features
- Multi-tier candidate discovery (low/mid/large-cap) with real-time WebSocket and Jupiter scanner
- Direct Pump.fun bonding-curve execution and Jupiter AMM routing with simulate-before-send guard
- Autonomous LLM decision engine (Claude or local vLLM/llama.cpp) with session and historical memory
- Pluggable strategy system (8 built-in strategies) with live configuration and strategy switching
- Risk management tools including Ouroboros dump-recovery detection, market geometry pre-scoring, and global SOL caps
