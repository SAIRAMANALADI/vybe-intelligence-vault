## Summary
LeanKG is a local-first knowledge graph tool that indexes codebases, builds dependency graphs, and exposes an MCP server for AI coding assistants like Cursor and Claude Code. It provides targeted context to AI tools, reducing token usage and improving accuracy without relying on cloud services.

## Key Features
- Local-first knowledge graph for codebases with dependency and call graph tracking
- MCP server integration for seamless AI tool connectivity (Cursor, Claude Code, etc.)
- Semantic search with embeddings and hybrid retrieval-reranking pipelines
- Web UI for visualization, community detection, and microservice call graphs
- Auto-trigger hooks for AI coding sessions and pre-commit risk analysis

## Why It Matters for RAG Builders
LeanKG is essential for RAG builders as it provides a lightweight, local alternative to cloud-based code indexing, enabling AI tools to query precise code context with minimal token overhead while preserving privacy and performance.
