## Summary
A TypeScript starter for autonomous giving agents that evaluate and donate USDC on Base via zooidfund. It scores campaigns on severity, marginal impact, evidence quality, and category fit, then executes donations based on configurable persona rules.

## Key Features
- Configurable persona-based decision-making with explicit scoring criteria (severity, marginal impact, evidence quality, category fit)
- Supports multi-format evidence extraction (text, PDF, images, JSON, CSV, HTML) via zooidfund signed URLs
- Dry-run mode for testing without real donations, with live mode for actual USDC transfers
- Deployable to Railway with persistent state and cron scheduling for automated giving cycles
- Open-source MIT license with detailed customization and troubleshooting documentation
