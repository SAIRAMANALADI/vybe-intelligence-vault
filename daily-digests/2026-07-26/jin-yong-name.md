## Summary
A specialized Agent Skill that generates culturally grounded, practical Chinese names for real-life use by leveraging naming methods inspired by Jin Yong's works. It provides curated name suggestions with explanations, ensuring names are readable, culturally appropriate, and suitable for official and daily contexts.

## Key Features
- Generates 3 curated and 2 backup name suggestions based on Jin Yong's naming principles
- Ensures names are practical, readable, and culturally appropriate for real-life use
- Supports customization by gender preference, surname, desired characters, and avoided characters
- Includes mechanical checks for pronunciation, tone, and cultural references
- Provides one-click installation for popular AI agent tools like Codex, Claude Code, and Cursor

## Why It Matters for RAG Builders
It provides a structured, culturally informed approach to generating authentic and meaningful Chinese names for real-world applications, reducing the complexity of manual naming processes.
