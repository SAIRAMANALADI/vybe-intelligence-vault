## Summary
kenny is a self-hosted remote administration and fleet monitoring tool for Windows PCs, enabling operators to manage and monitor multiple machines via a web dashboard or Claude (MCP). It provides real-time telemetry, remote tool execution, and parental controls with a focus on security and ease of use.

## Key Features
- Real-time telemetry collection and health monitoring for Windows PCs, including disk, memory, Defender, and network metrics.
- Web dashboard with AI-powered copilot (Claude integration) for interactive remote administration and troubleshooting.
- Secure agent-server communication with mutual Ed25519 authentication, token rotation, and confirm-gate for state-changing actions.
- Parental controls including web activity monitoring, filtering, and screen time management.
- Self-updating agent with one-click installer, Windows service integration, and NAT/firewall-friendly outbound WSS connections.

## Why It Matters for RAG Builders
It provides a secure, AI-driven framework for remote administration and fleet monitoring of Windows PCs, reducing manual intervention and enabling proactive issue resolution through automated telemetry and orchestration.
