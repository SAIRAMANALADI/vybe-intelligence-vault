## Summary
Minerva is a voice-based AI companion that maintains a three-layer memory system to provide personalized, context-aware support. It combines structured logging, semantic recall via vector search, and LLM-condensed profiles to deliver empathetic, memory-aware interactions while keeping prompts bounded in size.

## Key Features
- Three-layer memory system (structured log, semantic recall, rolling profile) for scalable context retention
- Voice-to-voice interaction with real-time transcription and speech synthesis
- Personalized profile generation and mantra management for tailored responses
- Postgres + pgvector backend for efficient storage and retrieval of journal entries
- Firebase Auth integration for secure, user-scoped data handling

## Why It Matters for RAG Builders
Minerva demonstrates how to build a memory-augmented AI agent that scales context retention without exploding prompt size, making it a critical reference for RAG systems requiring long-term personalization.
