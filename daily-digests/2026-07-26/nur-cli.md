## Summary
NurCLI is a highly efficient, Rust-based coding agent CLI that minimizes token spend across 60+ AI providers while offering a dense TUI, native vision capabilities, and a hardened sandbox. It provides a full agent stack with tools, knowledge integration, and a plugin marketplace for AI-driven development workflows.

## Key Features
- Multi-provider support (60+ AI models) with OAuth and API key integration
- Native vision tools for image/video analysis (e.g., `look`, `extract_frames`)
- One-shot install with full ecosystem provisioning (Rust, Node.js, Bun, etc.)
- Natural-language skill activation for advanced agent workflows
- Hardened sandbox with atomic writes, retries, and session management
