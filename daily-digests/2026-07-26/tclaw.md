## Summary
tclaw is a self-hosted personal AI assistant that directly integrates with the Claude Code CLI, enabling multi-channel communication, autonomous agent tasks, and infrastructure management without reimplementing core functionality. It adds OAuth connections, scheduling, and 80+ MCP tools on top of native Claude Code capabilities.

## Key Features
- Direct integration with Claude Code CLI for full feature parity
- Multi-channel communication with per-channel tool permissions and memory
- Autonomous work sessions for scheduled tasks and ephemeral deployments
- Self-modifying agent capable of working on its own codebase
- Comprehensive security model with subprocess isolation and encrypted secret storage

## Why It Matters for RAG Builders
tclaw enables AI engineers to build robust, self-hosted agent systems that leverage existing Claude Code capabilities while adding critical infrastructure management and multi-channel support for production-grade applications.
