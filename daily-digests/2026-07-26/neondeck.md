## Summary
Kryct is a hybrid web-based IDE where the UI runs in the browser while code execution, Docker containers, and agent interactions occur on a daemon node. It provides a three-panel interface (agent sidebar, live preview, and file tree) with sandboxed Docker environments for secure execution.

## Key Features
- Browser-based IDE with live preview and file management
- Sandboxed Docker containers for secure code execution with strict resource limits
- Centralized agent proxy that handles provider API keys securely (never exposed to the browser)
- Single-port deployment (web app, REST API, WebSocket, and previews) as a Docker service
- Supports Firebase Auth for user management and optional Stripe billing for tiered access

## Why It Matters for RAG Builders
Kryct provides a secure, scalable environment for running AI agents and code execution in a sandboxed manner, making it essential for RAG builders who need controlled, multi-tenant deployments with strong isolation guarantees.
