## Summary
oura-cli is a terminal-based tool for extracting and analyzing personal health data from Oura Ring devices via the Oura Cloud API. It provides offline-first caching, terminal-friendly reports, and JSON output for scripting or AI agent integration.

## Key Features
- Offline-first caching of Oura Ring data into SQLite for local access without internet
- Terminal-friendly reports with human-readable summaries and JSON output for scripting
- Automated discovery and schema documentation for AI agents and LLM harnesses
- Single 100KB binary with no native dependencies, built on Bun
- Secure token management with file-based storage and strict permissions

## Why It Matters for RAG Builders
It enables AI engineers to integrate personal health data from Oura Rings into RAG systems or agent workflows with minimal setup and maximum offline reliability.
