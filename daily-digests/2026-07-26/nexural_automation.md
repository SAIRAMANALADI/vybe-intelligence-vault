## Summary
Nexural Automation is a local-first research lab for futures strategy validation, providing institutional-grade due diligence pipelines for backtested strategies before live deployment. It includes a Python research engine, MCP server for AI agents, Strategy and Bridge SDKs, and an Automation Academy for safety-focused learning.

## Key Features
- Institutional-grade strategy validation pipeline with deflated Sharpe, Monte Carlo, and walk-forward analysis
- MCP server enabling AI agents to interact with the research workflow via standardized tools
- Strategy and Bridge SDKs for scaffolding multi-platform strategy modules and execution connectors
- Automation Academy for reproducible, safety-focused learning with hash-chained evidence tracking
- Cost modeling for futures trading with configurable stress profiles (normal, elevated, crisis)

## Why It Matters for RAG Builders
It provides a rigorous, local-first validation pipeline that bridges the gap between backtested strategies and safe paper trading, reducing risks of overfitting and unrealistic assumptions in AI-driven trading systems.
