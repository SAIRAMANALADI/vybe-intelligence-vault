## Summary
pain001-mcp is an MCP (Model Context Protocol) server that exposes the ISO 20022 pain.001 payment library as 16 first-class agent tools, enabling AI assistants to generate, validate, and parse standardized payment messages like SEPA credit transfers and direct debits.

## Key Features
- 16 MCP tools for generating and validating ISO 20022 pain.001/pain.008 payment messages
- Supports SEPA SCT, SDD, INST, and cross-border rulebook checks
- Validates IBAN, BIC, and XML against XSD schemas
- Provides async variants for long-running operations
- Includes migration tools for schema version compatibility

## Why It Matters for RAG Builders
It enables AI agents to directly generate, validate, and parse standardized payment messages, bridging the gap between natural language interfaces and financial systems.
