## Summary
Vaelor is a self-hosted MCP server that parses, graphs, and watches codebases to provide AI agents with persistent memory and structural insights beyond simple grep-based discovery. It combines tree-sitter AST parsing, call graphs, semantic search, and incident debugging to enhance AI-driven code analysis and review.

## Key Features
- Persistent call graph with type-aware resolution for 16+ languages
- Hybrid semantic search combining BM25F, embeddings, and graph expansion
- Blast radius and impact analysis for code changes with configurable depth
- Incident debugging via fusion of Prometheus alerts, Jaeger traces, and call graphs
- Per-symbol review learnings persisted and surfaced in future analyses

## Why It Matters for RAG Builders
Vaelor provides AI agents with persistent, structural memory of codebases and incidents, enabling more accurate, context-aware analysis and reducing redundant discovery efforts.
