## Summary
@devcxl/opencode-cabbage is a full-lifecycle development plugin for OpenCode that automates and orchestrates the entire software development process, from requirements gathering and design to coding, testing, review, and release with parallel subagents and automated workflows.

## Key Features
- Covers all development stages: requirements, design, task decomposition, coding, testing, review, and release
- Supports both manual and automatic workflow modes with parallel subagents
- Integrates 9 slash commands, 9 flow skills, and 5 agents for end-to-end automation
- Automated DAG task management and GitHub/Git integration for seamless collaboration
- Provides structured documentation generation and environment validation
