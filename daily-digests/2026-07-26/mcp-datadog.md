## Summary
mcp-datadog is a C#-based Model Context Protocol (MCP) server that integrates Datadog's observability data (logs, metrics, traces, and monitors) into AI workflows, enabling seamless access and analysis for AI assistants and automated systems.

## Key Features
- Provides structured access to Datadog logs, metrics, traces, and monitors via MCP
- Enables AI assistants to query and analyze observability data in real-time
- Cross-platform compatibility (Windows, Linux, macOS)
- Simplifies automation of observability tasks for AI-driven workflows
- User-friendly interface for connecting and querying Datadog data
