## Summary
PAPAI is a proactive AI assistant bot designed for natural language task management across multiple chat platforms (Telegram, Mattermost, Discord, Kontur Talk) and task providers (Kaneo, YouTrack). It enables conversational task operations, memory management, and plugin-based extensibility via MCP servers.

## Key Features
- Natural language task management (create, update, search, delete) across Telegram, Mattermost, Discord, and Kontur Talk
- Integration with task providers Kaneo and YouTrack for full lifecycle task operations
- Memory and memo storage with semantic search capabilities
- Plugin system and MCP server support for extensible tooling
- Proactive AI features including deferred prompts, recurring tasks, and scheduled nudges

## Why It Matters for RAG Builders
PAPAI provides a unified, conversational interface for AI-driven task management across multiple platforms and providers, making it essential for building proactive AI assistants that require robust task automation and memory capabilities.
