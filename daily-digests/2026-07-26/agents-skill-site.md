## Summary
Agents Skill Site provides an organizational governance framework for AI coding workflows, bridging the gap between execution tools (like Cursor or MCP servers) and structured role definitions, skill catalogs, and rule systems. It enables teams to standardize AI-driven development practices through a browsable web interface and an MCP server for AI agents.

## Key Features
- Predefined 8 standard AI coding roles with clear responsibilities and workflows
- 11 skill catalogs with role-skill binding matrices for structured AI task execution
- Three-layer rule system (L0 hard constraints, L1 process rules, L2 scenario rules)
- Dual consumption architecture: static VitePress site for humans and MCP server for AI agents
- Git-based governance asset management enabling iterative improvements and team onboarding

## Why It Matters for RAG Builders
It standardizes AI coding workflows by defining roles, skills, and rules, ensuring consistent and auditable AI-driven development practices across teams.
