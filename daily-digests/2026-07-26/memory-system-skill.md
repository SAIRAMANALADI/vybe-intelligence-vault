## Summary
A filesystem-based cross-session memory system for personal single-machine agents that persists long-term cognition and session records in Markdown. It enforces strict routing, minimal historical retrieval, and lifecycle management to optimize memory usage and privacy.

## Key Features
- Strict routing gate for memory read/write operations with minimal retrieval
- Progressive recall mechanism to fetch only task-relevant historical snippets
- Lifecycle management for long-term cognition, daily sessions, and reference snapshots
- Privacy enforcement with automatic rejection of sensitive data (keys, tokens, IPs)
- Deterministic actions (Search, Read, AppendDaily, Promote, Maintain) for structured memory operations

## Why It Matters for RAG Builders
It provides a privacy-aware, filesystem-based memory system that enables agents to retain and recall task-relevant context across sessions without unnecessary data exposure, optimizing RAG pipelines for efficiency and security.
