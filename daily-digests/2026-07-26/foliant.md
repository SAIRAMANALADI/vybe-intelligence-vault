## Summary
Foliant is a self-hosted MCP server designed as a German-first rule reference for Dungeons & Dragons 5e (2024 edition), providing rule lookups, character sheets, and rule-based tools. It aggregates and indexes rule data from open sources like SRD 5.2.1 and Open5e while excluding proprietary content.

## Key Features
- Self-hosted MCP server for D&D 5e rule lookups and character tools
- Aggregates and indexes open-source rule data (SRD 5.2.1, Open5e) with proper attribution
- Supports German rule text with English terms in parentheses for clarity
- Includes admin CLI for data import, validation, and server management
- Modular architecture with clear separation of code, open data, and proprietary content

## Why It Matters for RAG Builders
It provides a structured, self-hosted rule reference system for D&D 5e that can be adapted for other rulebooks or knowledge bases, offering a template for localized, open-source rule engines in AI applications.
