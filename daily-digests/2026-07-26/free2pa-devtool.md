## Summary
Free2PA is a developer toolkit that provides tamper-evident verification for AI agent control files using cryptographic signing and verification. It ensures files have not been altered and originate from trusted sources within an ad-hoc group, acting as a load gate to prevent unauthorized or modified files from being used by agents.

## Key Features
- Signs and verifies control files with cryptographic receipts to ensure integrity and provenance
- Supports ad-hoc trust groups with local verifier control over trusted publishers
- Provides CLI, MCP, HTTP API, and Node.js load-gate integrations for flexible deployment
- Includes repair functionality to restore signed originals from valid receipts
- Offers optional LLM-based behavioral auditing without overriding cryptographic checks

## Why It Matters for RAG Builders
Free2PA ensures AI agent control files remain tamper-evident and trusted, preventing unauthorized or altered files from influencing agent behavior, which is critical for secure RAG and AI agent deployments.
