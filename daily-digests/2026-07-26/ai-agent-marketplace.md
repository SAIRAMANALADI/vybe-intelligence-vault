## Summary
A comprehensive open-source AI Agent Marketplace that indexes, deploys, and monetizes over 10,000 AI agents across 30+ categories, providing a registry, search engine, and one-key gateway for seamless integration and distribution.

## Key Features
- Centralized registry for 10K+ AI agents with category-based indexing and search capabilities
- OneKey Gateway for unified access to 30+ commercial APIs and agent formats (CLI, MCP, Skills)
- Free subdomain deployment for Python/Node.js agents with traffic tracking and monetization support
- Open-source dataset snapshots on Hugging Face for research and community contributions
- CLI tool (agtm) for agent registration, search, and distribution across platforms like OpenAI and Claude
