## Summary
mcp-open-contracting is an MCP (Model Context Protocol) server providing access to international public procurement data, specifically government tenders. It is part of the Pipeworx gateway, which connects AI agents to over 1334 live data sources.

## Key Features
- Provides structured access to international public procurement data via MCP
- Integrates with AI agents through the Pipeworx gateway
- Supports plain English queries via ask_pipeworx for simplified interactions
- Offers both direct tool access and natural language question handling
- Part of a larger ecosystem with 1334+ live data sources

## Why It Matters for RAG Builders
