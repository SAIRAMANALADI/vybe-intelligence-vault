## Summary
Hive is an MCP-compatible server providing shared, persistent memory for AI agents, enabling durable storage and retrieval of context across conversations. It offers a hosted service with OAuth integration, allowing seamless connectivity for clients like Claude Code, Cursor, and ChatGPT without requiring local setup.

## Key Features
- Shared persistent memory for AI agents with durable storage and retrieval
- MCP-compatible server supporting clients like Claude Code, Cursor, and ChatGPT
- OAuth 2.1 authentication with automatic setup for seamless user experience
- Structured key naming conventions for organized and collision-free memory storage
- Web-based management UI and REST API for memory administration and monitoring

## Why It Matters for RAG Builders
Hive enables AI agents to maintain context and shared knowledge across sessions, critical for building advanced RAG systems that require persistent memory and collaboration.
