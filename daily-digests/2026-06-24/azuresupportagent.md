## Summary
An AI-driven Azure operations workbench that deploys into your Azure subscription, enabling conversational operations, deep investigations with specialist agents, and automated assessments. It reverse-engineers live architectures, tracks changes, and proactively identifies risks while maintaining read-only access by default.

## Key Features
- Conversational multi-session chat with live streaming and reasoning timelines for Azure operations
- Specialist agent 'War Room' for parallel deep investigations into Azure incidents
- Automated Well-Architected assessments with custom controls and framework mappings
- Proactive Support hub with Estate Graph, Change Explorer, and risk-scored telemetry
- One-click Azure deployment with read-only access, approval-gated writes, and full audit logging

## Why It Matters for RAG Builders
It provides an end-to-end AI-driven platform for managing Azure estates, enabling proactive risk detection, automated investigations, and conversational operations while maintaining strict security and tenant isolation.
