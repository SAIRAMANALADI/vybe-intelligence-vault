## Summary
copilot-guardian is an autonomous CI/CD recovery tool that leverages GitHub Copilot CLI to analyze failures, generate risk-stratified patches, and apply fixes automatically while maintaining transparency and governance.

## Key Features
- Multi-hypothesis reasoning for failure analysis
- Risk-stratified patch generation (Conservative, Balanced, Aggressive)
- Automatic application of fixes to workflows
- Detailed logging and governance for transparency
- Cross-platform support (Windows, macOS, Linux)

## Why It Matters for RAG Builders
It reduces CI/CD downtime by autonomously diagnosing and fixing failures, ensuring smoother and more reliable deployment pipelines.
