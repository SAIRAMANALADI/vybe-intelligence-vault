## Summary
AgentSCAD is a full-stack AI-powered CAD workspace that converts natural-language part requests into editable OpenSCAD code, rendered STL/PNG artifacts, and validated manufacturing-ready outputs. It integrates LLM-driven generation with deterministic OpenSCAD rendering and validation pipelines.

## Key Features
- Converts natural-language requests into OpenSCAD code and validated STL/PNG artifacts
- Progressive LLM pipeline with repair only on validation failure
- Deterministic rendering and validation using OpenSCAD and trimesh
- Persistent job history with editable parameters and version control
- Multi-provider LLM routing for generation, repair, and visual feedback

## Why It Matters for RAG Builders
AgentSCAD bridges the gap between AI-driven CAD generation and manufacturing-ready outputs, enabling RAG builders to integrate validated, editable CAD artifacts into AI workflows.
