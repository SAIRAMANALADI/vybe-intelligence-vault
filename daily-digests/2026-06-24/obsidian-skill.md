## Summary
obsidian-skill is a command-line tool that enables users to manage Obsidian notes (read, create, search, organize) without opening the Obsidian app directly, supporting PKM, Zettelkasten, and knowledge base workflows.

## Key Features
- Command-line interface for Obsidian note operations (read, create, search, move)
- Supports Obsidian versions 1.12+ and cross-platform (Windows, macOS, Linux)
- Integration with AI tools like Claude Code for automated note creation
- Zettelkasten and knowledge graph analysis support
- Sync-friendly for cloud-based Obsidian vaults
