## Summary
A Claude Code skill that simulates sleep for AI agents, consolidating session memories into durable long-term storage, integrating learnings, and detaching emotional charge from events. It operates on a file-based agent memory store, adapting to various formats while following a structured sleep cycle process.

## Key Features
- Consolidates session memories into atomic, retrievable long-term storage
- Detaches emotional charge from memories while preserving lessons
- Supports cross-linking of memories to surface patterns and latent connections
- Adapts to different file-based memory store formats
- Follows a structured sleep cycle (NREM and REM stages) for optimal processing
