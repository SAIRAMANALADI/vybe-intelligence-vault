## Summary
Skybridge is a full-stack React framework designed to build type-safe Model Context Protocol (MCP) apps for AI clients like Claude and ChatGPT, enabling rich interactive UI views rendered from MCP servers with seamless integration between user, UI, and model.

## Key Features
- Delightful dev environment with HMR and local emulator for MCP apps
- Write once, run everywhere across MCP clients (Claude, ChatGPT, VSCode)
- Agent-ready tooling with CLI and programmatic APIs for MCP app development
- End-to-end type safety from MCP server tools to React views
- Comprehensive example library for rapid prototyping and learning

## Why It Matters for RAG Builders
Skybridge simplifies the development of interactive MCP apps with React, enabling AI engineers to build rich, type-safe UIs that seamlessly integrate with AI models and MCP servers.
