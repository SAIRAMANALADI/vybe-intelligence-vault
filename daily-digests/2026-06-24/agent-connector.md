## Summary
agent-connector is an SDK and toolkit that enables developers to write a single MCP server and lifecycle hooks once, then deploy it as a connector across 42+ agent CLIs (e.g., Claude Code, Cursor, Copilot, Gemini) via direct installation or marketplace plugins. It simplifies cross-platform agent integration with built-in per-tool token telemetry and a unified configuration system.

## Key Features
- Single definition for MCP server and hooks deployable across 42+ agent CLIs
- Direct installation or marketplace plugin packaging (10+ formats supported)
- Built-in per-tool token telemetry and usage tracking
- Branded CLI creation for connector developers
- Cross-platform support with verified installation across Linux, Windows, and macOS

## Why It Matters for RAG Builders
It eliminates the need to rewrite integrations for each agent CLI, enabling RAG builders to deploy their tools universally with minimal overhead and built-in telemetry.
