## Summary
Wanaku is an MCP (Model Context Protocol) router designed to centralize and manage access to AI-enabled applications, enabling unified routing and resource management for LLM-powered agents through a standardized protocol.

## Key Features
- Centralized routing and resource management for AI agents via MCP
- MCP-to-MCP bridge for gateway or proxy functionality between MCP servers
- Extensive connectivity via 400+ Apache Camel components for integrations
- Secure by default with optional Keycloak-based authentication and authorization
- Kubernetes-native deployment with OpenShift support and multi-namespace organization

## Why It Matters for RAG Builders
It standardizes and simplifies the integration of diverse MCP servers and resources, enabling seamless LLM access to tools and data for RAG systems.
