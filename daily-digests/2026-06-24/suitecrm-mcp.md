## Summary
suitecrm-mcp is an open-source MCP (Model Context Protocol) gateway that securely connects AI agents like Claude Desktop to SuiteCRM instances, enabling full CRUD operations and activity logging via a stateless, scalable architecture with built-in observability.

## Key Features
- 24+ tools for full CRUD operations, activity logging, and bulk operations in SuiteCRM
- Secure OAuth2/OIDC authentication with Auth0/Azure AD integration and revocable API keys
- Stateless architecture with Redis for horizontal scaling and zero-downtime restarts
- Complete observability stack: Prometheus metrics, Grafana dashboards (33 panels), and Loki log aggregation
- Hybrid routing between SuiteCRM v8 GraphQL and legacy v4.1 REST API for 100% feature parity

## Why It Matters for RAG Builders
It enables AI agents to securely and efficiently interact with enterprise CRM data, reducing integration complexity and cost while ensuring full observability and scalability for production environments.
