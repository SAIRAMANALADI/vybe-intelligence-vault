## Summary
A Model Context Protocol (MCP) server that bridges transit data from OneBusAway APIs to AI tools, enabling real-time access to bus stops, routes, arrival times, and vehicle locations for integration into AI-driven applications or dashboards.

## Key Features
- Provides real-time transit data via OneBusAway API
- Integrates with AI tools using the Model Context Protocol (MCP)
- Supports Windows command-line and network-based operations
- Enables access to bus stops, routes, arrival times, and vehicle positions
- Configurable via JSON for seamless AI client integration

## Why It Matters for RAG Builders
