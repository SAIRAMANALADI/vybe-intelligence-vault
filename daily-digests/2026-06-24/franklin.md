## Summary
Franklin Agent is an autonomous AI agent that writes code and autonomously spends money via a USDC wallet to complete tasks. It integrates with 55+ models and paid APIs, using the x402 micropayment protocol to settle costs per action without subscriptions or API keys.

## Key Features
- Autonomous spending via USDC wallet with no subscriptions or API keys required
- Smart Router selects optimal models (55+) based on quality-to-cost ratio
- YOPO (You Only Pay Outcome) pricing model: pay only for delivered work
- Supports trading, code generation, image/video generation, web search, and more
- Deployable via CLI, VS Code extension, or Telegram bot

## Why It Matters for RAG Builders
Franklin Agent introduces wallet-driven autonomy and cost-aware execution, enabling AI agents to perform real-world tasks with financial constraints, a critical advancement for scalable and accountable AI systems.
