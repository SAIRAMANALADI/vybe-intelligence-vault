## Summary
A Model Context Protocol (MCP) client for Vaiz that enables seamless integration between Cursor/Claude IDEs and Vaiz workspaces, allowing AI agents to interact with tasks, projects, and team data programmatically.

## Key Features
- Enables Cursor/Claude IDEs to connect to Vaiz workspaces via MCP for real-time task and project access
- Supports dynamic tool discovery and execution (search, task management, document access)
- Provides programmatic client library for custom integrations
- Includes robust error handling, retries, and caching for reliability
- Offers debug mode for troubleshooting and logging
