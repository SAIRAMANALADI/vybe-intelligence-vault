## Summary
A focused Model Context Protocol (MCP) server for the RunAPI Seedance video generation models, enabling AI agents to create tasks, poll results, and check pricing directly through MCP-compatible hosts like Claude Code, Cursor, and VS Code.

## Key Features
- Provides MCP-compatible access to 6 Seedance video generation models via a single focused server
- Supports task creation, status polling, and pricing checks with minimal setup
- Works seamlessly with popular AI agent IDEs (Claude Code, Cursor, VS Code, etc.)
- Offers both synchronous and asynchronous task execution modes
- Includes agent-ready prompts for natural language task delegation

## Why It Matters for RAG Builders
It simplifies integrating Seedance video generation models into AI agent workflows by providing a standardized MCP interface, reducing setup complexity for RAG builders.
