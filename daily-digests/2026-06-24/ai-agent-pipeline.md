## Summary
A production-ready AI agent pipeline that integrates LangChain for LLM workflows, LangGraph for agent orchestration, and LangSmith for observability. It enables document processing, weather queries, and general Q&A with built-in monitoring, debugging, and deployment-ready workflows.

## Key Features
- Modular architecture decoupling LLM workflows, orchestration, and observability for scalability
- Built-in document processing with PDF extraction, OCR, and vector embeddings for RAG
- LangGraph-based orchestration for complex task splitting, retries, and multi-agent coordination
- Comprehensive observability with LangSmith for tracing, debugging, and performance monitoring
- Pre-built workflows for document Q&A, weather queries, and general AI assistants
