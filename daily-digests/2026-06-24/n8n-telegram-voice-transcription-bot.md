## Summary
This repository provides an n8n-based Telegram bot that converts voice messages into transcribed text, generates summaries, and supports translation and email delivery. It leverages Groq's API for speech-to-text and LLM processing within an automated workflow.

## Key Features
- Converts Telegram voice messages to text using Whisper technology
- Generates smart summaries via Llama models
- Supports multi-language translation
- Automatically delivers transcripts to email via SMTP
- Integrates with n8n for workflow automation

## Why It Matters for RAG Builders
This tool streamlines the conversion of voice notes into actionable text and summaries, reducing manual transcription effort for AI pipeline builders.
