## Summary
docpull is a Python CLI, SDK, and MCP server that converts public web sources into local Markdown, NDJSON, and agent-ready context packs for RAG, offline research, and agent workflows. It operates browser-free by default but supports optional cloud renderers for JS-heavy pages.

## Key Features
- Converts public web sources (docs, blogs, API references) into clean Markdown or NDJSON for LLM/RAG pipelines
- Supports local-first extraction with optional cloud renderers for JS-heavy pages
- Provides CLI, Python SDK, and MCP server interfaces for flexibility
- Includes budget controls to prevent unintended paid API/cloud calls
- Generates auditable artifacts with stable IDs, manifests, and source metadata

## Why It Matters for RAG Builders
It enables RAG builders to reliably convert public web sources into local, auditable context packs without relying on proprietary APIs or hosted services.
