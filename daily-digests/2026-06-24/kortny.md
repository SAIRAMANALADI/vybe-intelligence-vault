## Summary
Kortny is an open-source AI coworker that integrates with Slack to plan, execute, and audit real tasks entirely on self-hosted infrastructure. It writes and runs code in a sandbox, manages costs transparently, and builds long-term memory of team workflows.

## Key Features
- Slack-native AI agent with real-time task execution and audit logging
- Sandboxed code execution for safe, isolated task completion
- Transparent cost tracking and per-task accounting in a built-in dashboard
- Workspace memory and knowledge graph for long-term team context retention
- BYOLLM support with OpenAI, Anthropic, or OpenRouter keys

## Why It Matters for RAG Builders
Kortny provides a self-hosted, transparent alternative to hosted AI coworkers, enabling RAG builders to integrate a fully auditable, cost-controlled agent framework into their infrastructure.
