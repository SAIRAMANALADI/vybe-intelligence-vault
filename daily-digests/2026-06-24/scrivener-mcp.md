## Summary
Scrivener MCP is an MCP server that enables AI assistants like Claude, ChatGPT, and other tools to directly interact with Scrivener projects for document management, analysis, and enhancement. It provides 60+ tools for reading, editing, searching, and analyzing Scrivener manuscripts without manual copy-pasting or exporting.

## Key Features
- Direct interaction with Scrivener projects via MCP-compatible clients (Claude, VS Code, Cursor, etc.)
- 60+ tools for document management, analysis, search, and enhancement
- Semantic search and AI-powered writing analysis (pacing, readability, style)
- Character and plot relationship tracking with persistent memory storage
- Multi-platform support (macOS, Windows, Linux) with Docker and Homebrew deployment options

## Why It Matters for RAG Builders
It bridges the gap between Scrivener's structured writing environment and AI assistants, enabling seamless, automated analysis and editing of manuscripts without manual data transfer.
