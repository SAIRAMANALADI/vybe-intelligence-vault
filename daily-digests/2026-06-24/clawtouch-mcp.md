## Summary
clawtouch-mcp is a USB HID device server that enables MCP-compatible AI agents to control mouse and keyboard inputs. It acts as a bridge between AI systems and hardware peripherals for direct interaction.

- Acts as a bridge between AI systems and hardware peripherals
- Lightweight and designed for real-time input automation
