## Summary
A focused Model Context Protocol (MCP) server for RunAPI's Veo 3.1 video generation models, enabling AI agents to create, poll, and manage video tasks with direct access to 3 endpoints and 2 model variants.

## Key Features
- Provides MCP-compatible tools for Veo 3.1 video tasks (extend, text-to-video, upscale)
- Supports pricing checks and task status polling without full API catalog loading
- Compatible with Claude Code, Codex, Cursor, Windsurf, VS Code, and other MCP hosts
- Lightweight and focused, ideal for agents needing scoped Veo 3.1 access
- Includes agent prompts for natural language task creation and pricing checks

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate Veo 3.1 video generation capabilities with minimal setup, reducing overhead for RAG builders.
