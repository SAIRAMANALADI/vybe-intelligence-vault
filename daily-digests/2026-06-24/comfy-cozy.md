## Summary
Comfy Cozy is an AI-powered co-pilot for ComfyUI that enables users to interact with their workflows using plain English. It automates tasks like loading workflows, swapping models, tweaking parameters, and running generations while maintaining full reversibility and undo capabilities.

## Key Features
- Plain-English interaction with ComfyUI workflows for seamless automation
- 131 MCP tools supporting 5 LLM providers with provider-agnostic architecture
- Reversible delta layers (LIVRPS) enabling full undo stack for all workflow edits
- Built-in vision analysis for output evaluation and parameter optimization
- Multi-worker endpoint pooling with health checks and failover for production use

## Why It Matters for RAG Builders
Comfy Cozy streamlines AI workflow automation by enabling natural language control over complex tools, reducing manual effort and accelerating iteration cycles for RAG and generative AI pipelines.
