## Summary
A Windows application that enables secure sharing of local web pages with ChatGPT via Cloudflare tunnels, allowing AI assistants to analyze authenticated pages while keeping local data private through controlled snapshots.

## Key Features
- Secure Cloudflare tunnel for private local web page exposure
- Snapshot-based content sharing to prevent full page exposure
- Windows installer with desktop shortcut support
- Automatic update checks and version management
- Dashboard for managing shared snapshots and tunnel status

## Why It Matters for RAG Builders
It bridges the gap between private local web content and AI assistants like ChatGPT, enabling secure RAG workflows without exposing sensitive data.
