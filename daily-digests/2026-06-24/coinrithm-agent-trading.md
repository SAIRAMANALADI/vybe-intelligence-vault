## Summary
CoinRithm Agent Trading enables AI agents to paper-trade cryptocurrencies, futures, and prediction markets using a virtual 50,000 mUSD account via a secure API key. It supports model-agnostic agent strategies through the Open Knowledge Format (OKF) and integrates with MCP clients, offering hosted and local deployment options.

## Key Features
- Supports paper trading for spot, futures, and prediction markets with a virtual 50,000 mUSD account
- Model-agnostic agent strategies via Open Knowledge Format (OKF) bundles
- Hosted and local MCP server deployment options for flexibility
- Idempotent trading operations with unique `idempotencyKey` support
- Comprehensive performance tracking, equity curves, and auditable ledgers

## Why It Matters for RAG Builders
It provides a secure, portable, and model-agnostic framework for AI agents to safely test and validate trading strategies before deploying to real markets.
