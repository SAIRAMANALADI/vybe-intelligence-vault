## Summary
J.A.R.V.I.S. is a macOS AI assistant that integrates voice control, screen awareness, browser automation, and multi-device connectivity via AIM. It combines on-device speech recognition, Rust-based vector search, and a plugin system to enable intelligent automation and conversational AI for macOS users.

## Key Features
- Always-on wake word detection with voice control
- Screen awareness and interaction via Claude Vision
- Rust-based sub-millisecond vector search and fuzzy matching
- Plugin system with hot-reload and external package support
- Multi-device connectivity via AIM WebSocket relay
