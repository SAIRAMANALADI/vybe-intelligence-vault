## Summary
WebBrain is an open-source AI browser agent extension for Chrome and Firefox that enables users to interact with web pages, automate browser tasks, and execute multi-step agent workflows using a variety of LLMs. It provides a side-panel chat interface for real-time interaction and task automation.

## Key Features
- Multi-step autonomous agent workflows with configurable step limits (up to 200 steps)
- Supports 15+ LLM providers including local models (llama.cpp, Ollama) and cloud APIs (OpenAI, Anthropic, Google, etc.)
- Real-time page interaction (click, type, scroll, navigate) with Ask/Act modes and safety confirmations
- Smart context management with auto-compaction for large conversations and token-aware summarization
- Extensive toolset for page reading, PDF extraction, screenshots, form filling, CAPTCHA solving, and more

## Why It Matters for RAG Builders
WebBrain provides a critical bridge between LLMs and real-world web interaction, enabling RAG systems to autonomously perform tasks like data extraction, form submission, and navigation, which are essential for building dynamic, real-time AI applications.
