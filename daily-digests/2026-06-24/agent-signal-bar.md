## Summary
Agent-Signal-Bar is a macOS menu bar application that provides real-time visual status indicators for AI agents, using colored lights to show agent activity or errors. It integrates with tools like Claude Code and Codex to display agent health without opening additional windows.

## Key Features
- Real-time status lights (red, green, yellow) for AI agent health
- Customizable light colors and effects (pulse, solid, brightness)
- Supports integration with Claude Code and Codex protocols
- Low memory footprint for minimal system impact
- Multi-language menu bar interface
