## Summary
A command-line tool for managing Mendeley academic reference libraries, enabling automation of citations, BibTeX exports, and research organization. It integrates with AI systems by providing structured research data for agents.

## Key Features
- Automated sync between Mendeley library and local BibTeX files
- Command-line interface for listing, searching, and exporting references
- Secure authentication with Mendeley API
- Batch processing for large citation lists
- Compatibility with AI agents requiring structured research data
