## Summary

- Real-time spiritual readings powered by verified data from RoxyAPI and NASA JPL Horizons
- Embeddable widget for one-line integration on any website with microphone access
- Multi-provider LLM support (Gemini, Claude, GPT) with unified Vercel AI SDK interface
