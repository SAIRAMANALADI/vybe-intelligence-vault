## Summary
MCP-rag-with-Chromadb is a desktop application that simplifies advanced document retrieval using the Model Context Protocol (MCP) server with ChromaDB and LangChain integration. It enables users to manage and query multiple document formats through a user-friendly interface.

## Key Features
- Multi-document format support (PDFs, Word files, etc.)
- Seamless integration with LangChain and ChromaDB for advanced RAG capabilities
- User-friendly desktop interface with built-in help guide
- Cross-platform compatibility (Windows, macOS, Linux)
- Pre-configured search algorithms for efficient data retrieval
