## Summary
BoxLite provides a lightweight compute substrate for running OCI containers inside persistent, hardware-isolated micro-VMs ('Boxes'). It enables stateful, long-running environments for AI agents without requiring cloud infrastructure, supporting multiple languages and deployment modes.

## Key Features
- Hardware-isolated micro-VMs for secure, persistent environments
- Supports OCI containers (Docker images) with state retention across restarts
- Multi-language SDKs (Python, Rust, Node.js, Go, C) and REST API
- Lightweight, embeddable runtime with no daemon or root requirements
- Network policy, secret management, and resource limits for security

## Why It Matters for RAG Builders
BoxLite enables AI agents to run in persistent, isolated environments without cloud dependency, reducing latency and cost while improving security for RAG and agentic workflows.
