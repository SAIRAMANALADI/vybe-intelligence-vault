## Summary
ForgeLab provides a JSON-based intermediate representation (IR) for AI agents to design hardware, mechanical parts, and 3D models, enabling seamless round-trip imports/exports to tools like KiCad, FreeCAD, and Blender without proprietary formats.

## Key Features
- Unified JSON IR for hardware, mechanical CAD, and 3D modeling domains
- Round-trip imports/exports for KiCad, FreeCAD, and glTF
- MCP server for agent integration (stdio/HTTP)
- Token-optimized workflows (patches, projections, file paths)
- Pre-built component library and generation tools

## Why It Matters for RAG Builders
ForgeLab enables AI agents to generate and manipulate real-world hardware and 3D designs without proprietary toolchain lock-in, acting as a universal bridge between AI and design tools.
