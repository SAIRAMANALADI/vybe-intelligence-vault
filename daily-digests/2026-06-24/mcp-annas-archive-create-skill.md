## Summary
A tool that bridges research assistants with Anna's Archive to search, extract, and structure professional research notes into agent-compatible skill files using Google Gemini for methodology analysis.

## Key Features
- Searches Anna's Archive for books and research documents based on keywords
- Downloads and analyzes PDF/EPUB files using Google Gemini to extract core methodologies
- Generates structured `.md` skill files with summary, methodology, and reliability scores
- Integrates seamlessly with Claude Code for AI agent workflows
- Runs locally for privacy, with no external data sharing beyond search queries and document text

## Why It Matters for RAG Builders
It automates the extraction of structured research methodologies from Anna's Archive, enabling AI agents to leverage high-quality, domain-specific knowledge for improved RAG performance.
