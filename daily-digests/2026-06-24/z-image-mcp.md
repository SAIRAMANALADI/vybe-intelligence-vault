## Summary
A focused Model Context Protocol (MCP) server for the Z Image model by RunAPI, enabling AI agents to generate images, poll task statuses, and check pricing through a lightweight, single-model interface.

## Key Features
- Provides MCP-compatible tools for Z Image model access (text_to_image, get_task, check_pricing)
- Supports integration with Claude Code, Codex, Cursor, VS Code, and other MCP hosts
- Lightweight server scoped to a single model (Z Image) for focused AI agent workflows
- Includes pricing checks and task status polling without requiring full RunAPI catalog access
- Ready-to-use examples for multiple IDEs and MCP-compatible hosts

## Why It Matters for RAG Builders
It simplifies AI agent integration with a dedicated MCP server for Z Image, reducing overhead and enabling seamless image generation workflows.
