## Summary
SwiftStreamingMarkdown is an iOS-native Markdown renderer designed for smooth, high-performance streaming of dynamically received text, particularly suited for LLM response UIs. It supports inline and block LaTeX math rendering, inline citations, and highly configurable typography and theming.

## Key Features
- Smooth streaming transitions for dynamically received Markdown text
- Native inline and block LaTeX math rendering with iosMath
- Inline citation UI for source-grounded LLM responses
- Highly configurable typography, theming, and iOS context menus
- Built-in hooks for analytics and interaction tracking

## Why It Matters for RAG Builders
It enables RAG builders to deliver smooth, interactive Markdown-rendered LLM responses in iOS apps with minimal UI stuttering during streaming.
