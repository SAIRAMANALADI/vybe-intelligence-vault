## Summary
Lychee is a local-first desktop application that enables users to run advanced AI models on their own hardware without sending data to external servers. It integrates with Ollama and HuggingFace to provide a user-friendly interface for managing models, agents, and custom setups.

## Key Features
- Local execution of AI models with full data privacy
- Integration with Ollama and HuggingFace for model downloads
- Custom model roles and agent sandbox for testing
- User-friendly web dashboard for model and agent management
- Multi-model pipeline support with load balancing

## Why It Matters for RAG Builders
