## Summary
Pilot is an autonomous AI agent that automates software development tasks by planning, implementing, testing, and opening pull requests for tickets from platforms like GitHub, Linear, Jira, or Asana. It operates as a background agent or via a Telegram bot, reducing manual backlog management.

## Key Features
- Autonomous ticket resolution from GitHub, Linear, Jira, or Asana with minimal human input
- Multi-model routing (Haiku to Opus 4.6) based on task complexity and effort estimation
- Telegram bot integration for natural language task submission and real-time updates
- Autopilot modes (dev/stage/prod) with configurable autonomy levels and cost controls
- Self-review, quality gates, and sequential execution to ensure reliable PR generation

## Why It Matters for RAG Builders
Pilot streamlines the AI-driven development workflow by automating the entire lifecycle of ticket resolution, reducing manual effort and accelerating software delivery for RAG and AI stack builders.
