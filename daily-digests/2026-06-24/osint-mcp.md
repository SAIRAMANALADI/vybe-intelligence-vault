## Summary
A self-hosted OSINT toolkit that provides entity intelligence, event/news intelligence, and social/community intelligence through multiple interfaces including MCP server, AI REPL, CLI, web app, and chat apps via OpenClaw. It bundles 29 investigation tools with keyless-first functionality and AI-driven multi-target analysis.

## Key Features
- 29 OSINT tools covering entity, event/news, and social intelligence domains
- Five interfaces: MCP server, AI REPL, CLI, web UI, and chat apps (WhatsApp/Telegram/Discord)
- Keyless-first design with optional API keys for premium sources
- AI agent integration with Anthropic, DeepSeek, or local Ollama models
- Structured JSON output for all tools and passive-first design to avoid direct target interaction

## Why It Matters for RAG Builders
It provides a unified, self-hosted OSINT toolkit that integrates seamlessly with AI agents via MCP, enabling advanced investigative workflows for security research, journalism, and digital footprint auditing.
