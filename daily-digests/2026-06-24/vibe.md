## Summary
vibe is a cross-platform desktop application for fast, private transcription of audio files using Whisper models and optional OpenAI integration. It prioritizes local processing, user privacy, and a clean UI for efficient transcription workflows across Windows, macOS, and Linux.

## Key Features
- Local-first transcription with Whisper models for privacy and speed
- Optional OpenAI API integration for enhanced accuracy
- Cross-platform support (Windows, macOS, Linux) with native UI
- Multi-format export (TXT, SRT, VTT, JSON) for downstream use
- Real-time progress indicators and keyboard-centric workflow
