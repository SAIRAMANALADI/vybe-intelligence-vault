## Summary
Forge is an open-source AI-powered software lifecycle platform that orchestrates Claude Code workflows across multiple devices while maintaining full control over credentials. It provides a web dashboard for managing projects, configurable pipelines for issue resolution, and real-time job tracking without storing Claude credentials on the server.

## Key Features
- Device pairing and credential isolation (credentials never leave user devices)
- Configurable pipeline engine with stage-based automation and human gating
- Real-time job streaming with full audit trails (stdout, stderr, tool calls, diffs)
- Multi-project and multi-device coordination with organization support
- Extensible architecture supporting custom skills, pipeline stages, and runners
