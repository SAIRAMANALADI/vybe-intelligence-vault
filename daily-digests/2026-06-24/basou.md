## Summary
Basou is a provenance layer for AI development that records, replays, and reasons about AI agent sessions (e.g., Claude Code) by capturing sessions, decisions, approvals, and git snapshots into structured JSONL logs and human-readable markdown files.

## Key Features
- Records AI agent sessions (Claude Code, Codex) into structured JSONL logs for replayability
- Generates human-readable markdown summaries (handoff.md, decisions.md) from event logs
- Supports task-level tracking spanning multiple sessions with reconciliation tools
- Provides a local web UI (`basou view`) for browsing sessions and actions
- Offers a read-only SDK (`@basou/sdk`) for programmatic access to provenance data

## Why It Matters for RAG Builders
Basou provides critical provenance tracking for AI-driven development workflows, enabling reproducibility, auditability, and debugging of AI agent sessions in production or collaborative environments.
