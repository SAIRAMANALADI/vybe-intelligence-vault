## Summary
Serf is a non-interactive coding agent that automates software development tasks by leveraging LLM tool-calling capabilities to read, write, execute commands, and search code iteratively until completion. It supports multiple LLM providers including OpenAI, Anthropic, and Google models.

## Key Features
- Native LLM tool-calling for file operations, command execution, and code search
- Multi-provider support (OpenAI, Anthropic, Google, Ollama, etc.)
- Session persistence and resumption for interrupted workflows
- Serf TUI for terminal-based session management and monitoring
- Serf Hub for web-based multi-session orchestration and collaboration

## Why It Matters for RAG Builders
Serf streamlines AI-driven coding workflows by automating repetitive development tasks through native LLM tool-calling, reducing manual intervention and accelerating project completion.
