## Summary
sbot is an open-source, self-hosted AI agent framework designed for modular composition of agents with independent building blocks like models, memory, tools, and channels. It supports multi-LLM providers, MCP tools, long-term memory, and multi-channel integrations with a built-in web UI for management.

## Key Features
- Modular agent composition with independent model, memory, tool, and channel components
- Support for multiple LLM providers (OpenAI, Anthropic, Google, Ollama, etc.) and MCP tools
- Built-in long-term memory with vector embedding search and conversation compaction
- Multi-channel integrations (Web UI, Slack, Lark, WeChat, REST API, WebSocket, etc.)
- Agent Store for pre-packaged agents and skills with remote installation capabilities

## Why It Matters for RAG Builders
sbot provides a flexible, self-hosted framework for building and orchestrating AI agents with modular components, making it essential for developers who need customizable, vendor-agnostic solutions for RAG and agent-based systems.
