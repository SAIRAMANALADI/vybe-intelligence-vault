## Summary
Genesis Architect is a research-first project scaffolding tool that scans GitHub for real-world failures, bugs, and design pitfalls before generating a production-ready scaffold with built-in mitigations. It automates the analysis of 15-20 similar repositories to identify recurring issues and embeds solutions directly into the project structure.

## Key Features
- Pre-build GitHub issue mining to identify common failures and security risks
- Automated scaffold generation with built-in mitigations for identified pitfalls
- Multi-mode operation: Fast MVP, Professional, Founder, and Development Partner modes
- Natural language routing for intuitive project initiation and auditing
- Continuous integration with quality gates (SonarCloud, Snyk, coverage checks)

## Why It Matters for RAG Builders
Genesis Architect reduces the risk of architectural failures by embedding real-world lessons learned from GitHub issues directly into project scaffolds, saving RAG builders time and preventing common pitfalls before they occur.
