## Summary
fabric-dw provides a Python CLI and MCP server for administering Microsoft Fabric Data Warehouses and SQL Analytics Endpoints, enabling automation and AI-assisted management of data warehouse operations.

## Key Features
- CLI for Microsoft Fabric Data Warehouse administration tasks
- MCP server exposing warehouse operations as tools for AI assistants
- Flexible authentication via Azure Identity and environment variables
- Docker support for containerized deployment
- Security controls for read-only and destructive operations
