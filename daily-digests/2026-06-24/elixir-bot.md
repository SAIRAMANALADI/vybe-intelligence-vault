## Summary
Elixir is a specialized LLM-powered Discord bot designed for the POAP KINGS Clash Royale clan, acting as a channel-native clan agent with event-driven workflows, scoped memory, and GitHub-backed website publishing for poapkings.com.

## Key Features
- Channel-native agent with lane-based Discord routing (e.g., `#river-race`, `#leaders`, `#ask-elixir`)
- Event-sourced reactive engine for signal detection and automated clan operations
- Scoped memory system for public vs. leadership context separation
- GitHub-backed website publishing for dynamic clan data (e.g., `elixirClan.json`, `elixirRoster.json`)
- Recurring activity scheduler with 10+ automated tasks (e.g., war-poll, weekly-recap, promotion-content)
