## Summary
A desktop application that simplifies content summarization by extracting and condensing text from YouTube videos and websites using LangChain and Groq Llama models. It provides a user-friendly interface for generating concise summaries of long-form content.

## Key Features
- YouTube video transcription and summarization
- Website text scraping and condensation
- Map-Reduce LLM summarization for high-quality outputs
- Cross-platform desktop application (Windows, macOS, Linux)
- Configurable summary length and processing speed

## Why It Matters for RAG Builders
It streamlines the extraction and summarization of long-form content from videos and websites, reducing manual effort for RAG pipeline data preprocessing.
