## Summary
AI OSINT Security Analyzer is a Streamlit-based web application that leverages AI models and multi-source threat intelligence to perform autonomous cybersecurity investigations. It integrates with Shodan, VirusTotal, AbuseIPDB, and CVE databases to provide comprehensive threat assessments for websites, IP addresses, and software vulnerabilities.

## Key Features
- AI-powered threat assessment using Cohere's Command A model
- Multi-source data integration (Shodan, VirusTotal, AbuseIPDB, CVE databases)
- User-friendly Streamlit interface for seamless interaction
- Real-time threat intelligence updates
- Open-source contribution and extensibility
