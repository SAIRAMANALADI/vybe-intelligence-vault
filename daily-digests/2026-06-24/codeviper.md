## Summary
CodeViper is a local AI agent with a graphical user interface designed to assist with programming tasks. It integrates with Ollama or cloud-based AI providers to enable code analysis, file editing, git operations, and self-improvement without requiring subscriptions or tracking.

## Key Features
- Graphical interface for code analysis and editing with side-by-side diff views
- Supports multiple AI providers (Ollama, OpenAI, Gemini, Anthropic, etc.) without subscriptions
- Advanced file and project tree navigation with AST-based symbol search
- Built-in git operations, file modification, and command execution
- Self-improvement capabilities and memory management for continuous learning

## Why It Matters for RAG Builders
