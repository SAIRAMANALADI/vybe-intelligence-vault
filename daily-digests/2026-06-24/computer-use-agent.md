## Summary
A Python-based AI agent that automates desktop tasks by capturing screenshots, sending them to an OpenAI-compatible LLM, and executing actions like mouse clicks, keyboard inputs, and window management. Supports Windows, macOS, and Linux with multi-monitor and plugin capabilities.

## Key Features
- Cross-platform desktop automation via screenshots and actions (mouse/keyboard control)
- MCP server integration for direct LLM agent tool access (Claude, Cursor, Zed)
- Plugin system for custom actions (e.g., sending emails, API calls)
- Multi-monitor support with configurable capture modes (SOM, Vision, UITARS)
- HTTP REST API and interactive REPL for task submission and monitoring

## Why It Matters for RAG Builders
It bridges the gap between natural language instructions and desktop automation, enabling AI agents to perform complex, multi-step tasks on any operating system with minimal setup.
