## Summary
Otto is an open-source, multimodal AI coding agent CLI that pairs Anthropic's Claude and OpenAI's Codex on every turn, enabling real-time code review and editing. It supports local-first operation, automatic failover between models, and omnipresent sessions that can be continued via WhatsApp or Telegram.

## Key Features
- Fusion engine pairing Claude and Codex for real-time code review and editing
- Automatic provider failover to prevent session stalls
- Omnipresent sessions supporting terminal, WhatsApp, and Telegram
- Multimodal input handling (images, voice, video, documents)
- Local-first architecture with embedded NATS JetStream and SQLite

## Why It Matters for RAG Builders
Otto enables AI engineering teams to build more reliable and collaborative coding agents by leveraging dual-model fusion and omnipresent session continuity, reducing bottlenecks and improving developer workflows.
