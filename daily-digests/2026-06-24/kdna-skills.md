## Summary
KDNA Skills provides domain cognition capabilities for AI agents by enabling domain detection, axiom application, and improved response accuracy through two core skills: kdna-loader for loading domain-specific knowledge and kdna-create for creating, downloading, or importing KDNA domains.

## Key Features
- Two modular skills (kdna-loader and kdna-create) for domain cognition and knowledge management
- Supports multiple AI agents (GitHub Copilot, Claude Code, OpenCode, Codex) with unified installation
- Four domain creation paths: conversation-based, registry download, URL import, and template scaffolding
- Validates KDNA domains before installation to ensure correctness and consistency
- Apache-2.0 licensed with multilingual documentation (English and Chinese)
