## Summary
Aura Code is an autonomous coding agent that automates AI-assisted engineering workflows using multiple AI agents for design, implementation, testing, and verification. It is model-agnostic and supports providers like Claude, GPT, Gemini, MiMo, and local models via Ollama.

## Key Features
- Multi-agent workflows (Researcher, Coder, Reviewer) with orchestration modes
- Model-agnostic support for major AI providers (Claude, GPT, Gemini, MiMo, Ollama)
- Automated codebase analysis, planning, execution, verification, and reporting
- Built-in testing suite with 1000+ tests and coverage reporting
- Self-improvement tracking and competence scoring (with dashboard integration)

## Why It Matters for RAG Builders
Aura Code streamlines AI-driven software development by automating multi-agent collaboration, reducing manual effort in coding, testing, and verification for RAG and AI stack builders.
