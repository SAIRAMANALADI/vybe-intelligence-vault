## Summary
poly-cloud-mcp is a Model Context Protocol (MCP) server that provides unified tools for managing multi-cloud resources across AWS, Google Cloud, Azure, and DigitalOcean via their respective CLI interfaces. It enables AI assistants to interact with cloud infrastructure programmatically.

## Key Features
- Unified MCP server for AWS, Google Cloud, Azure, and DigitalOcean
- 40+ pre-built tools for resource management (EC2, S3, Lambda, VMs, etc.)
- Local-Agent mode only with `--allow-run` permission for CLI execution
- Security-focused with recommendations for minimal IAM permissions
- Supports systemd service for persistent operation

## Why It Matters for RAG Builders
It enables AI assistants to programmatically manage multi-cloud resources, bridging the gap between AI workflows and cloud infrastructure automation.
