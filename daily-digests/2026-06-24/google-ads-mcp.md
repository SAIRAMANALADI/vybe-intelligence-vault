## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Google Ads accounts via the Google Ads API. It provides secure, two-phase mutation support for ad campaign management with full API coverage and audit logging.

## Key Features
- Full Google Ads v24 API coverage for reads and secure mutations
- Two-phase mutation process requiring AI preview and user confirmation
- Audit logging for all actions with append-only logs for security
- Allowlist-based customer ID access control
- Windows-native executable for easy deployment

## Why It Matters for RAG Builders
It bridges AI assistants with Google Ads accounts securely, enabling AI-driven campaign management while maintaining strict user control and auditability.
