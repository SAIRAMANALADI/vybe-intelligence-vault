## Summary
A Model Context Protocol (MCP) server for arXiv paper search, analysis, and export, enabling AI assistants to discover, summarize, and process academic papers with advanced citation tracking and multi-format data exports.

- Semantic search and discovery of arXiv papers with embeddings
- Citation network analysis and trend tracking
- Multi-format exports (BibTeX, RIS, JSON, CSV, PDF summaries)
- MCP-driven architecture for AI assistant coordination
- REST API and CLI for programmatic access and automation
