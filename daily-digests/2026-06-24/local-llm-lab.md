## Summary
Local-llm-lab is a desktop application designed to help users plan hardware requirements for running local AI models by benchmarking system performance and estimating memory and processing needs for different model sizes.

## Key Features
- Benchmarks system performance to measure tokens per second for local AI workloads
- Estimates memory and processing requirements for small, medium, and large LLM models
- Provides hardware comparison reports to guide purchasing decisions
- Runs offline after initial setup, ensuring no data collection or privacy concerns
- Supports Windows systems with NVIDIA GPUs and unified memory architectures

## Why It Matters for RAG Builders
It helps AI engineers and enthusiasts avoid costly hardware mismatches by accurately predicting local LLM performance before model deployment.
