## Summary
Claudegram is a desktop application that enables users to control their Telegram account via intelligent commands, automating tasks like message management, channel operations, and chat organization while prioritizing data privacy and security.

## Key Features
- Automates Telegram tasks via intelligent commands (120+ tools)
- Uses MTProto protocol for secure, official Telegram API access
- Four-layer safety filters to prevent account suspension or misuse
- Local data processing with no cloud storage of message history
- Pre-built automation scripts for common tasks (e.g., message cleanup, contact organization)
