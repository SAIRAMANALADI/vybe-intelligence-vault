## Summary
SquadCoder is an AI-powered engineering team simulator that orchestrates parallel specialist agents (Architect, Developers, QA, Security, UI/UX) to plan, build, review, and ship features autonomously with zero configuration. It combines persistent memory, semantic codebase indexing, and a CTO-quality gate for end-to-end software development.

## Key Features
- Team Mode with parallel specialist agents (Architect, Devs, QA, Security, UI/UX) for end-to-end feature development
- Persistent memory system for project-specific context retention across sessions
- Semantic codebase indexing for offline, meaning-based code search
- 820+ pre-bundled skills and MCP-native integrations (GitHub, Playwright, web search)
- Local-first, private architecture with zero cloud dependency or telemetry

## Why It Matters for RAG Builders
SquadCoder enables AI-driven software development teams to autonomously plan, build, and ship features in parallel, reducing manual orchestration overhead and accelerating RAG pipeline integration with persistent project memory and semantic search.
