## Summary
AI-Employee is a self-hosted multi-agent AI platform designed for teams requiring compliance, governance, and data isolation. It enables the deployment of specialized agents in isolated Docker containers, each with its own semantic memory, knowledge base, and autonomy rules, facilitating collaboration while maintaining strict data sovereignty.

## Key Features
- Isolated Docker containers for each agent with dedicated resources and workspaces
- Multi-user data isolation with PostgreSQL RLS and per-user knowledge bases
- Autonomy levels (L1-L4) with whitelist-based approval models for governance
- Semantic memory powered by BAAI/bge-m3 embeddings for local, multilingual vector search
- Meeting rooms for multi-agent collaboration and decision-making

## Why It Matters for RAG Builders
AI-Employee provides a compliant, self-hosted framework for deploying and managing specialized AI agents with strict data isolation, making it essential for teams prioritizing governance and sovereignty in their AI stack.
