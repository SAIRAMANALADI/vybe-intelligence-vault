## Summary
The eurostat-mcp-server is a Windows-based application that provides access to European Union statistical data via the Model Context Protocol (MCP). It enables users to query and retrieve datasets on economy, health, demography, trade, and regional NUTS codes directly from the official Eurostat database.

## Key Features
- Provides real-time access to 8,933+ Eurostat datasets
- Supports querying via Model Context Protocol (MCP) for integration with AI tools
- No complex language environment required (standalone Windows executable)
- Covers key domains: economy, health, demography, trade, and regional NUTS data
- Open-source and free to use with no data storage or cost
