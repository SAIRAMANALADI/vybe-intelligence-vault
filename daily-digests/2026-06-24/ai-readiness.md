## Summary
A dependency-free CLI tool that evaluates whether a website is crawlable and understandable by AI search engines like ChatGPT, Perplexity, and Google AI. It provides a score, grade, and actionable fixes for common technical gaps.

## Key Features
- Checks AI crawler access via robots.txt for major AI bots (GPTBot, PerplexityBot, etc.)
- Validates presence and quality of JSON-LD structured data (Organization, FAQPage, Article)
- Evaluates title/meta tags, Open Graph tags, and XML sitemaps for AI readability
- Provides a 0-100 score, letter grade, and specific fixes for failing checks
- Supports MCP server integration for AI assistants and CI/CD pipelines

## Why It Matters for RAG Builders
AI search engines rely on crawlable, well-structured content to cite websites, and this tool ensures your site meets the technical fundamentals for visibility in AI answers.
