## Summary
Linghun is a local-first, evidence-first AI programming terminal that integrates large language models with real projects, tools, permissions, and validation. It bridges AI models to actual codebases, enforces verification, and reduces hallucinations by grounding outputs in evidence, tools, and Git state.

## Key Features
- Evidence-first architecture ensuring outputs are grounded in real file reads, tool results, and Git state to minimize hallucinations
- Built-in verification system distinguishing between PASS, PARTIAL, FAIL, and unvalidated conclusions to reduce rework
- Workflow Matrix for breaking complex tasks into phases, roles, and evidence requirements with durable job tracking
- Local-first execution with strict permission boundaries, supporting Windows, PowerShell, and Chinese paths natively
- AntiCodeBlob system to enforce architectural health, code hygiene, and avoid god files or deep nesting

## Why It Matters for RAG Builders
