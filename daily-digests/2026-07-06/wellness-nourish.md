## Summary
Wellness Nourish is a local-first Model Context Protocol (MCP) server for AI agents that provides nutrition-related tools like food search, barcode lookup, photo-assisted meal estimation, intake logging, and hydration tracking. It operates without OAuth or external token exposure, ensuring privacy by keeping all data on the user's machine.

## Key Features
- Local-first architecture with no OAuth or hosted accounts required
- Supports food search, barcode lookup (text and image), and photo-assisted meal estimation
- Provides intake logging, hydration tracking, and goal management
- Works with popular AI agent clients like Claude, Cursor, and ChatGPT
- Offline mode with bundled fixtures for testing without network access

## Why It Matters for RAG Builders
Wellness Nourish enables AI agents to integrate nutrition tracking and food analysis capabilities while maintaining strict privacy and local data control, making it essential for health-focused AI applications.
