## Summary
A Model Context Protocol (MCP) server that enables AI assistants to control DaVinci Resolve Studio through its official Scripting API, providing full API coverage and workflow helpers for editing, media management, grading, and project lifecycle tasks. Includes an optional advanced offline server for file-level operations and a local control panel for inspection and analysis.

## Key Features
- Full API coverage for DaVinci Resolve Studio via MCP, enabling AI assistants to control editing, media pool, grading, and project management
- Optional advanced offline server for file-level operations (e.g., DRX grade editing, project DB manipulation) with 18 tools
- Local control panel for inspecting Resolve state, running source-safe analysis, and editing analysis output inline
- Source media safety with immutable camera originals and sidecar-based analysis reports
- Automated installer and IDE integration for seamless setup with tools like VS Code, Cursor, and Claude
