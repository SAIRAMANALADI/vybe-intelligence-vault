## Summary
Hecate is a local-first agent operations console and runtime control plane designed to coordinate, supervise, and observe AI agent work. It acts as a central hub for routing model calls, managing projects, approving actions, and collecting evidence while integrating with external agent frameworks and tools.

## Key Features
- Local-first runtime with embedded UI for operator control and visibility
- Model gateway supporting OpenAI-compatible APIs, failover, and usage tracking
- Project coordination with assignments, handoffs, and memory management
- External agent supervision for coding-agent CLIs with approvals and diagnostics
- Comprehensive observability via OpenTelemetry traces, metrics, and route reports

## Why It Matters for RAG Builders
Hecate provides a centralized, operator-controlled layer for coordinating and supervising AI agent work, making it essential for teams managing complex, multi-agent workflows with robust oversight and traceability.
