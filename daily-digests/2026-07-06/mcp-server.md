## Summary
The @opengolfapi/mcp-server provides an open data layer for golf, enabling AI agents to access and contribute to a shared commons of US golf course data, player identities, and tournament management. It supports read operations for course details, weather, and scoring, while enabling write operations for shot logging, event submission, and tournament organization.

## Key Features
- 54+ MCP tools for golf course data, scoring, and tournament management
- OpenShot and Moments standards for shot and event logging
- OpenJoin tokens for seamless tournament onboarding
- OpenGolf ID for portable player identities across apps
- Free read access and optional contributing via API keys

## Why It Matters for RAG Builders
