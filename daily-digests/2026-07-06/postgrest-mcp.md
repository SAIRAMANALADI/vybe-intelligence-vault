## Summary
A lightweight MCP (Model Context Protocol) server for integrating with PostgREST APIs, enabling OAuth2 authentication and streamable HTTP services for Supabase, Neon, and other PostgREST-compatible databases.

## Key Features
- OAuth2 authentication support for secure API access
- Streamable HTTP services for real-time data handling
- Compatibility with Supabase, Neon, and other PostgREST servers
- Self-hosted deployment option via Supabase Functions
- User-friendly configuration for API endpoints and credentials

## Why It Matters for RAG Builders
Simplifies integration with PostgREST-compatible databases for AI applications requiring real-time data access and secure authentication.
