## Summary
MeshVault is a local web-based tool for browsing, previewing, and managing 3D assets directly from the filesystem, including assets within archives. It combines a powerful 3D viewer with AI agent integration for automated asset inspection and manipulation.

## Key Features
- Supports 10+ 3D formats and common archives (ZIP, RAR, etc.) with auto-conversion for legacy FBX files
- AI agent control via self-describing JSON API, MCP server, and embeddable viewer for programmatic asset interaction
- Advanced 3D viewer with PBR rendering, shadows, and navigation modes (orbit, FPV drone)
- Local indexing for cross-folder search, tags, collections, and recent files with persistent settings
- Built-in mesh operations (simplification, normals recomputation) and texture management with smart matching

## Why It Matters for RAG Builders
MeshVault enables AI agents to programmatically inspect, manipulate, and export 3D assets with structured control APIs, making it essential for RAG pipelines requiring 3D model understanding or automated asset processing.
