## Summary
A Model Context Protocol (MCP) server providing 117 read-only tools to interact with Datadog's observability platform across all pillars (logs, APM, metrics, RUM, etc.). Designed to enable AI assistants to query Datadog data without write access, ensuring safety and comprehensive coverage.

## Key Features
- 117 read-only tools covering all Datadog observability pillars (logs, APM, metrics, RUM, etc.)
- Zero write access to prevent accidental or malicious changes
- Comprehensive coverage of Datadog features including SLOs, synthetics, security, and infrastructure
- Easy deployment via npx with Node.js 20+
- High test coverage (90%+) and active maintenance

## Why It Matters for RAG Builders
Provides AI assistants with safe, comprehensive read-only access to Datadog's observability data, enabling advanced troubleshooting and analysis without risking accidental changes.
