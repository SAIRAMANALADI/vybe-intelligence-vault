## Summary
SteamMCP is an MCP server that enables LLM clients to interact with the Steam API, providing tools for retrieving user profiles, game data, achievements, market items, and trading platform activities.

## Key Features
- Provides MCP-compatible tools for Steam API interactions
- Supports user profiles, game stats, achievements, and market data retrieval
- Includes Docker support for easy deployment
- Comprehensive testing suite with unit, integration, and MCP smoke tests
- Structured for easy extension with new tools
