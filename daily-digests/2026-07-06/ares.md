## Summary
ARES is an open-source embodied AI operating system designed to deploy a persistent, continuous intelligence that orchestrates local AI stacks, automates workflows, and interacts through a native AI avatar with memory, drives, and presence across sessions.

## Key Features
- Persistent entity with memory, drives, and presence across sessions
- Web UI with streaming, session management, and password authentication
- Backend selector for Hermes, JROS, or Hybrid mode per conversation
- Character avatar browser with 14 visual personas and dynamic identity selection
- Native macOS app with voice support and animated 3D avatar eyes

## Why It Matters for RAG Builders
ARES provides a unified platform for orchestrating persistent AI agents with advanced memory, multi-model routing, and native avatar interactions, making it essential for building scalable and interactive RAG systems.
