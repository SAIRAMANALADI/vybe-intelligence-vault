## Summary
jor-mcp is an open-source Model Context Protocol (MCP) server designed for journalism organizations to securely integrate AI workflows with WordPress and GitHub repositories. It enables AI agents to search, retrieve, and analyze proprietary newsroom data while maintaining strict access controls.

## Key Features
- WordPress CMS integration for article search and retrieval
- GitHub repository access for research and codebase queries
- Token-based authentication (JWT) for secure data access
- Containerized deployment via Docker for ease of setup
- Comprehensive documentation and replication guides for newsrooms

## Why It Matters for RAG Builders
jor-mcp enables secure, context-aware AI workflows for journalism organizations by bridging LLMs with proprietary newsroom data, ensuring fact-checking and analysis against internal archives.
