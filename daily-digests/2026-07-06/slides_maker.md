## Summary
slide-maker is an AI-powered tool that converts research papers, code repositories, documents, or topics into native, editable PowerPoint presentations (PPTX). It uses a multi-agent system to plan, design, and review slides before delivery, ensuring high-quality, presentation-ready decks with editable text, charts, formulas, and speaker notes.

## Key Features
- Converts papers, repos, or topics into native editable PPTX with real text boxes, charts, and formulas
- Multi-agent system (content-planner, slide-design, critic, arbiter) for structured and reviewed output
- Independent critic review ensures content fidelity and design quality before delivery
- Supports native PowerPoint features like click-build animations, speaker notes, and editable data charts
- Offers a template gallery with pre-designed decks for various use cases (e.g., lab meetings, product intros)

## Why It Matters for RAG Builders
It streamlines the creation of high-quality, editable presentations from raw content, reducing manual effort and ensuring consistency and professionalism for AI engineers and researchers.
