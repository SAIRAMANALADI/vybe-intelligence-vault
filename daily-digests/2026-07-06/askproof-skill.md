## Summary
AskProof-Skill is a desktop application designed to verify the accuracy of AI-generated outputs by checking for logical gaps, unsupported claims, and evidence. It provides actionable reports to help non-engineers validate AI responses without requiring coding knowledge.

## Key Features
- Verifies AI outputs for logical consistency and supported claims
- Provides actionable reports for non-technical users
- Offers built-in prompts to refine AI responses
- Runs locally to ensure data privacy
- Supports chunked verification for long documents
