## Summary
A Model Context Protocol (MCP) server that provides AI assistants with direct access to OpenDART's 83 financial and corporate disclosure APIs, optimized for Korean market data. It includes built-in analyst frameworks for insider signals, accounting risk scoring, and Buffett-style quality checklists, along with HWP/PDF attachment markdown conversion.

## Key Features
- 83 OpenDART APIs compressed into 15 optimized tools for AI assistants
- Built-in Buffett-style quality checklists and insider signal analysis
- Automated XBRL parsing with calculation linkbase validation and markdown conversion
- HWP/PDF attachment extraction and markdown conversion for direct LLM consumption
- Pre-built analyst frameworks for accounting risk scoring and corporate event timelines
