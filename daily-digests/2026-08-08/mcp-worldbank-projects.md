## Summary
A Model Context Protocol (MCP) server providing AI agents with access to World Bank projects and operations data, including tools for searching, retrieving, and filtering projects by country, status, or ID. Part of the Pipeworx gateway ecosystem connecting agents to 1394+ live data sources.

## Key Features
- Keyless access to World Bank project data
- Search projects by free text, country, or status
- Retrieve detailed project records by ID
- List projects by country with filtering options
- Integration with Pipeworx gateway for broader data access
