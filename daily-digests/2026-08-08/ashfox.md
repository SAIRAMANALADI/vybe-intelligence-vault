## Summary
ashfox is an AI-native low-poly asset workbench that enables agents to model, texture, rig, and animate 3D assets directly in a browser or via Blockbench integration. It supports runtime-optimized exports like Bedrock, GeckoLib 5, glTF, and GLB, with a fully local-first and open-source workflow.

## Key Features
- AI-driven 3D asset generation with editable browser workbench
- Blockbench MCP integration for seamless workflows in existing modeling tools
- Runtime-optimized exports for Minecraft Bedrock, GeckoLib 5, glTF, and GLB
- Local-first architecture with no account or cloud dependency required
- Automated validation and preview for generated assets

## Why It Matters for RAG Builders
ashfox bridges the gap between AI-generated 3D assets and game-ready pipelines, enabling RAG builders to automate and validate asset creation for immersive applications.
