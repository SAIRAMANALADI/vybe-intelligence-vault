## Summary
Terva is a modular agent harness packaged as a single static Go binary, providing a hardened core for coding agents with extensible tooling, multiple front-end interfaces, and support for over two dozen model providers. It enables AI-driven coding workflows with built-in permissions, hooks, and connectors for seamless integration.

## Key Features
- Single static Go binary with no external dependencies for core functionality
- Built-in support for 20+ model providers (OpenAI, Anthropic, Google, etc.) and OpenAI-compatible endpoints
- Modular permission system with approval modes (plan/ask/auto-edit/workspace/yolo) and sandboxed workspace
- Multiple front-end interfaces: terminal UI, web control panel, ACP editor integration, and embeddable RPC/SDK
- Extensible via MCP, hooks, extensions, and chat connectors (Telegram/Discord) in any language

## Why It Matters for RAG Builders
Terva provides a unified, production-ready foundation for building and deploying AI agents with robust tooling, permissions, and multi-model support, reducing integration overhead for RAG and AI stack builders.
