## Summary
gkill is a self-hosted lifelogging application that enables users to record, search, and analyze personal life events through structured data entries. It supports diverse record types like text, timestamps, mood tracking, expenses, and file attachments, with AI integration via MCP for advanced analysis.

## Key Features
- Multi-format data recording (text, timestamps, mood, expenses, files, GPS, Git commits, etc.)
- AI-powered analysis via MCP server integration for contextual insights
- Cross-platform support (Windows, Android, Wear OS, server-based PWA)
- Advanced search and aggregation with customizable trend graphs
- Plugin system for importing external data (e.g., ChatGPT/Claude.ai conversations)

## Why It Matters for RAG Builders
