## Summary
DeepSeek-Reasonix is a terminal-based AI coding agent that integrates the DeepSeek model to assist with code generation, debugging, and explanation directly in the command line. It leverages prefix-cache stability for consistent performance and supports tool-use capabilities for terminal automation.

## Key Features
- Prefix-cache stability for long-running sessions without performance degradation
- Direct terminal interaction with tool-use capabilities (file reading, command execution)
- Code generation, debugging, and explanation via natural language prompts
- Clean, modern terminal UI built with Ink
- Supports voice or text commands for hands-free operation
