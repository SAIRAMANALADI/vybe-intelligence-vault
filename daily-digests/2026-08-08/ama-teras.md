## Summary
AMA-teras is a self-evolving desktop AI agent built with Electron, React, and TypeScript. It autonomously plans, implements, debugs, and tests new features based on user requests while ensuring safety through multi-stage validation gates and user approval before integration.

## Key Features
- Autonomous feature generation and integration based on user requests with strict safety controls
- Multi-stage validation pipeline (typecheck → test → smoke) with user approval gates to prevent unintended changes
- 6-tier model orchestration assigning optimal models for planning, execution, review, and escalation
- Isolated development environment (git worktree) for safe code generation and testing
- Free API mode supporting Google Gemini, Groq, and OpenRouter without requiring card registration
