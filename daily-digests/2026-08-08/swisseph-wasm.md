## Summary
A WebAssembly compilation of the Swiss Ephemeris 2.10.03 library, providing high-precision planetary positions, house systems, eclipses, and fixed stars for JavaScript/TypeScript environments. The library is optimized for size (230 KB brotli-compressed) and works without external data files, leveraging the original C implementation for numerical accuracy.

## Key Features
- High-precision planetary position calculations with verified numerical parity against native C builds
- Compact 230 KB brotli-compressed WASM binary with no external data files required
- Cross-platform compatibility (Node.js, browsers, Deno, Bun, edge runtimes)
- Model Context Protocol (MCP) server integration for LLM access to ephemeris data
- Comprehensive API for house systems, eclipses, fixed stars, and derived astrological calculations

## Why It Matters for RAG Builders
It provides a lightweight, high-precision, cross-platform way to integrate astronomical calculations into AI systems without reinventing complex numerical models.
