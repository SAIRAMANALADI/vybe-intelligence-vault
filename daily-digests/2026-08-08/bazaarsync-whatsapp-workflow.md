## Summary
BazaarSync transforms free-text WhatsApp shop messages into structured, queryable transaction records using Claude for parsing, validated via Pydantic, and persisted in a database with a FastAPI REST interface for auditing and dashboard integration.

## Key Features
- Real-time WhatsApp message parsing into structured JSON with confidence scoring
- Pydantic validation for robust data integrity and error handling
- Dual database support (SQLite/PostgreSQL) with zero code changes for production
- Structured JSON logging with request_id correlation for end-to-end traceability
- Unified ingestion pipeline for both WhatsApp webhooks and manual API parsing

## Why It Matters for RAG Builders
It provides a production-ready pipeline to convert unstructured WhatsApp shop messages into structured, queryable data using LLMs, enabling seamless integration with RAG systems for transactional intelligence.
