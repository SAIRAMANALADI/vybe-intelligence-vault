## Summary
MCP server providing UPC/barcode and PLU produce code lookups via Open Food Facts without requiring an API key. It offers three tools for product and produce lookups backed by a 4M+ product database.

## Key Features
- No API key required for Open Food Facts lookups
- Supports UPC/EAN/GTIN barcode lookups (8–14 digits)
- PLU produce code lookup (4–5 digits)
- Product search by name or brand (1–10 results)
- Backed by a 4M+ product database

## Why It Matters for RAG Builders
This MCP server simplifies product and produce lookups for RAG pipelines by providing structured data access to Open Food Facts without API key constraints.
