## Summary
cogmem is a self-improving, verifiable memory layer for AI coding agents that learns from outcomes, models failure modes, and ensures tamper-evident memory storage. It integrates with tools like Claude Code to provide continuous, local-first recall and guardrails for autonomous agent workflows.

## Key Features
- Two-layer memory system (always-loaded directives + semantic recall) with outcome-based refinement
- Tamper-evident verifiable memory using W3C VCs, COSE_Sign1, and SCITT-style transparency logs
- Self-modeling agent guardrails to intercept known failure modes before they occur
- Local semantic recall with fastembed for privacy-preserving, offline operation
- Cross-project progress tracking and project-state modeling for situational continuity

## Why It Matters for RAG Builders
It provides a secure, self-improving memory layer for AI coding agents that ensures verifiable, tamper-resistant recall and continuous learning from outcomes, critical for building reliable and autonomous agent systems.
