## Summary
Memory Platform is a local-first, auditable, and governable long-term memory system for AI agents. It combines a Memory Gateway for memory management and a Model Gateway for model routing, fallback, and cost tracking, enabling AI to retain context across sessions while ensuring data privacy and security.

## Key Features
- Dual-gateway architecture (Memory Gateway + Model Gateway) for clear separation of concerns
- OpenAI-compatible API and MCP support for seamless integration with AI clients
- Five memory sectors (episodic, semantic, procedural, emotional, reflective) with lifecycle management
- Automated memory extraction, validation, and decay mechanisms
- Built-in Web Console for memory governance, knowledge management, and system monitoring

## Why It Matters for RAG Builders
It provides a robust, privacy-preserving framework for AI agents to maintain long-term context and knowledge, essential for building reliable and auditable RAG systems.
