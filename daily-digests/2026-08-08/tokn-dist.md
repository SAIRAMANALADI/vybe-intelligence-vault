## Summary
TOKN is a trust-first agentic coding and reasoning harness distributed as a single static binary with offline licensing, in-place self-updates, and regulated-domain plugins. This repository provides pre-built binaries for easy trial and evaluation.

## Key Features
- Single static binary with no external dependencies
- Offline licensing with 14-day trial (one per machine)
- In-place self-update without reinstallation
- Supports multiple platforms (Windows, macOS, Linux)
- Community and paid tiers for regulated and production use

## Why It Matters for RAG Builders
