## Summary
Kingdee MCP Server enables AI assistants like Claude, Cursor, and Windsurf to interact with Kingdee Cloud Star ERP systems using natural language via the Model Context Protocol (MCP). It provides 87 tools for querying, creating, and auditing ERP documents across 13+ business domains.

## Key Features
- 87 pre-built tools covering 13+ business domains (purchasing, sales, inventory, finance, etc.)
- Natural language processing for ERP operations (query, create, audit, submit)
- Supports 8 MCP-compatible AI clients (Claude, Cursor, Windsurf, etc.)
- Dynamic metadata querying and SQL Server introspection for database exploration
- Asynchronous high-performance design with automatic retries and session management

## Why It Matters for RAG Builders
It bridges AI assistants with enterprise ERP systems, enabling natural language automation for complex business workflows and reducing manual ERP interactions.
