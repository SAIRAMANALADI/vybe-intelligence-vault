## Summary
ragscope is a Windows desktop application designed to enable quick and easy querying of documents using Retrieval-Augmented Generation (RAG). It indexes PDFs, Word documents, and text files, allowing users to ask questions and receive relevant answers without manual searching.

## Key Features
- Indexes and searches PDFs, Word docs, and text files
- Uses ChromaDB for efficient document retrieval
- Integrates Ollama for natural language query understanding
- Tracks and improves answer relevance with MLflow
- Supports offline document search and evaluation

## Why It Matters for RAG Builders
ragscope simplifies document querying for RAG pipelines by providing an offline-capable, user-friendly interface to index and search documents efficiently.
