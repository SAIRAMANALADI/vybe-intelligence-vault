## Summary
A marketing intelligence panel that synchronizes GA4, Google Search Console, and Google Ads data into a local SQLite database, generates daily CMO reports via LLM (Anthropic Opus 4.7), and delivers insights via email, Pushover notifications, and a Chainlit dashboard.

## Key Features
- Automated data pipeline syncing GA4, GSC, and Google Ads into SQLite with idempotent upserts
- Daily CMO reports generated by LLM with week-over-week comparisons and actionable recommendations
- Multi-channel delivery: email (CMO/CEO groups), Pushover alerts, and Chainlit dashboard
- MCP server for Claude Code integration with 12 tools for data querying and report generation
- Threshold-based alerts for CPA, dry spend, and policy issues with Pushover priority=2 notifications

## Why It Matters for RAG Builders
It streamlines marketing data aggregation and AI-driven reporting, reducing manual analysis overhead for RAG builders who need structured, actionable insights from multiple data sources.
