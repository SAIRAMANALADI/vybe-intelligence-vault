## Summary
easyagent provides a local web interface for the full Claude Code coding agent, enabling non-technical users to interact with an AI agent through a visual UI instead of a terminal. It includes security profiles, multi-agent orchestration, and project management while running entirely on the user's machine with their own Claude subscription.

## Key Features
- Full Claude Code agent capabilities with a visual UI for streaming activity, file tree, and diffs
- Three configurable security profiles (Locked/Standard/Open) with OS-level sandboxing and command filtering
- Multi-agent orchestrator for parallel role-based task execution and integration
- Project management dashboard with conversation history and automatic state restoration
- Local-only server with anti-CSRF protection and confinement to a single project folder

## Why It Matters for RAG Builders
It democratizes access to advanced AI coding agents by providing a user-friendly interface without sacrificing the agent's full capabilities, making it ideal for teams or individuals who prefer visual workflows over terminal-based interactions.
