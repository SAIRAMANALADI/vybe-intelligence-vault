## Summary
MatrixOne is an AI-native, cloud-native HTAP (Hybrid Transactional/Analytical Processing) database that combines Git-style version control for data with MySQL compatibility, built-in vector search, and full-text search capabilities. It eliminates the need for multiple databases and ETL pipelines by unifying OLTP, OLAP, and AI workloads in a single system.

## Key Features
- Git-style version control for data with instant snapshots, time travel, branching, and rollback capabilities
- Unified HTAP engine supporting OLTP, OLAP, full-text search, and vector search without data movement or ETL
- Built-in vector search (IVF/HNSW) and full-text search for RAG and semantic search applications
- MySQL compatibility for seamless migration and integration with existing tools and applications
- Cloud-native architecture with storage-compute separation, Kubernetes-native deployment, and elastic scaling

## Why It Matters for RAG Builders
MatrixOne eliminates the complexity of managing multiple databases and ETL pipelines for RAG systems by providing a unified, AI-native HTAP database with built-in vector search and Git-style data versioning.
