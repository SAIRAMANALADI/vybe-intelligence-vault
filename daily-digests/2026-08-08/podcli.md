## Summary
PodCLI is an open-source AI-powered tool for automatically converting long podcast episodes into short, shareable clips with face tracking, burned-in captions, and multi-format support. It operates via CLI, web studio, or MCP server for agent integration.

## Key Features
- Automated transcription with speaker diarization using Whisper or AssemblyAI
- Face tracking and dynamic cropping for speaker-focused clips
- Multi-format output (9:16, 16:9, 1:1) with customizable caption styles
- MCP server integration for agent-driven workflows (e.g., Claude Code)
- AI-powered clip scoring against a knowledge base to avoid duplicate content

## Why It Matters for RAG Builders
PodCLI streamlines the creation of high-quality, shareable podcast clips with minimal manual effort, making it essential for content creators and AI-driven media workflows.
