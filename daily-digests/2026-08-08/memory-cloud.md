## Summary
Kagura Memory Cloud is a self-hosted MCP server that provides adaptive memory for AI agents and teams, going beyond traditional RAG systems. It combines hybrid search, a neural memory graph, and Hebbian learning to create a dynamic knowledge base that improves with use.

## Key Features
- Adaptive memory that strengthens connections between related memories through Hebbian learning
- Hybrid search combining semantic and BM25 keyword search with AI reranking for precision
- Neural memory graph for serendipitous discovery via graph traversal
- Multi-tenant team support with RBAC, workspaces, and context isolation
- 50+ MCP tools including memory management, agent substrate, and sleep maintenance

## Why It Matters for RAG Builders
It provides persistent, adaptive memory for AI agents that evolves with usage, enabling long-term learning and team collaboration beyond static RAG systems.
