## Summary
A Python-based Model Context Protocol (MCP) server that bridges ROS 2 systems with AI tooling, enabling seamless interaction with ROS 2 nodes, topics, services, and actions via stdio transport. Designed for zero-friction integration with AI agents, copilots, and debugging tools.

## Key Features
- Zero-friction stdio-based MCP server for ROS 2 with auto-type discovery and nested field support
- Comprehensive toolset for managing topics, services, actions, and data black box queries
- Dockerized deployment with auto QoS selection and DDS discovery warm-up for stable operation
- Supports AI-powered debugging, natural language data analysis, and real-time robot control
- Extensible with custom prompts and integration guides for VS Code Copilot, Claude Desktop, and Warp

## Why It Matters for RAG Builders
It enables AI agents to directly interact with ROS 2 systems, accelerating robotics development, debugging, and automation through natural language interfaces.
