## Summary
ReaperMCP bridges AI assistants via the Model Context Protocol (MCP) to REAPER, enabling AI-driven music production with 163 tools for composition, mixing, mastering, and real-time control of tracks, MIDI, FX, and audio analysis.

## Key Features
- 163 tools across 25 modules for full REAPER control (transport, tracks, MIDI, FX, mixing, mastering)
- AI-driven composition, mixing, and mastering with 35 professional style profiles
- Vocal chopping pipeline with genre-specific rhythms (chillstep, future bass, trap, etc.)
- File-based Lua IPC bridge for secure, local-only AI-REAPER communication
- Smart plugin detection and automatic FX chain setup for optimal workflow
