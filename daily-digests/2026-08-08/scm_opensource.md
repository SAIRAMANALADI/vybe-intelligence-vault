## Summary
SCM (Sleep-Consolidated Memory) provides lifecycle memory management for AI agents, enabling memory to sleep, consolidate, forget stale noise, handle contradictions, and wake with summaries of changes. It supports local-first, plug-and-play integration with no mandatory cloud dependencies.

## Key Features
- Plug-and-play memory lifecycle management with sleep/consolidation, forgetting, and schema discovery
- Universal five-tool contract (add_memory, search_memory, sleep, wake_summary, forget) across Python, CLI, REST, MCP, JavaScript, and LangChain
- Local-first operation with optional cloud-based LLM integration for advanced features
- Built-in product qualification and reproducibility checks for reliable releases
- Multi-surface access (CLI, Python SDK, REST API, MCP, JavaScript) for seamless integration

## Why It Matters for RAG Builders
SCM enables AI agents to manage dynamic, evolving memory with human-like consolidation and forgetting, reducing noise and improving contextual relevance in RAG systems.
