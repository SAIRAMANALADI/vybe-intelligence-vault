## Summary
Pulse is a self-improving AI agent framework designed for reliability-first orchestration, featuring evaluated skill self-evolution, multi-agent team pipelines, and full self-hosting capabilities with Ollama and SQLite FTS5 by default.

## Key Features
- Reliability-first orchestration with error recovery, exponential backoff, and token budget guardrails
- Evaluated skill self-evolution with golden-task replay, versioning, and rollback capabilities
- Multi-agent team pipelines (Builder→Reviewer→Ship) for complex task decomposition
- Full self-hosting by default (Ollama + SQLite FTS5) with zero cloud dependency
- Plugin sandbox with import isolation, permission whitelisting, and MCP integration

## Why It Matters for RAG Builders
Pulse provides a robust, self-hosted framework for building and deploying reliable, self-improving AI agents with built-in reliability mechanisms and multi-agent orchestration, essential for production-grade RAG systems.
