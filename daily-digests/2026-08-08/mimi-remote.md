## Summary
Mimi Remote is a native iOS/iPadOS SwiftUI client that enables remote control of OpenAI Codex and Claude Code sessions running on a local Mac. It allows users to monitor, steer, and manage AI-driven workflows from their mobile devices without leaving the context of their work.

## Key Features
- Native SwiftUI mobile app for iPhone and iPad with platform-optimized UX
- Direct connection to Mac via Tailscale or local network for secure, low-latency control
- Steer AI sessions remotely: add context, approve actions, interrupt turns, and manage Git
- Structured Codex output with model-generated titles, token usage tracking, and diagnostics
- Multi-Mac profile support with Keychain-backed token management and bounded host capabilities

## Why It Matters for RAG Builders
It enables AI engineers to remotely monitor and control their AI-driven workflows from mobile devices, bridging the gap between desktop operations and mobile convenience without compromising security or context.
