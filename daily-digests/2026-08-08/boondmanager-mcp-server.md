## Summary
A Model Context Protocol (MCP) server for the BoondManager API, enabling AI agents like Claude to interact with BoondManager instances for CRUD operations, structured data retrieval, and workflow automation across 38 domains including CRM, project management, HR, and reporting.

## Key Features
- 180 tools covering 38 BoondManager API domains for comprehensive CRUD operations
- Structured output schemas for reliable entity references and chaining of API calls
- Pre-orchestrated prompts for common workflows (e.g., team synthesis, commercial pipeline, staffing availability)
- Exposed MCP resources for dictionaries (states, types, countries, currencies) to translate codes into human-readable labels
- Docker and npm package support for seamless deployment and integration with AI clients
