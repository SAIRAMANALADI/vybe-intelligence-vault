## Summary
A high-density research pipeline for arXiv and DOI papers, enabling AI agents and humans to search, extract clean Markdown, map citation lineages, and store papers in a hybrid RAG depot. It integrates with FastMCP for agent-native interactions and supports local semantic search via LanceDB.

## Key Features
- Clean Markdown extraction from arXiv experimental HTML
- Hybrid local RAG depot with SQLite FTS5 and LanceDB vectors
- Citation lineage mapping via Semantic Scholar
- DOI resolution with Unpaywall and Crossref for open-access papers
- Agent-native MCP server with bundled tools and prompts

## Why It Matters for RAG Builders
It provides a comprehensive pipeline for ingesting, processing, and retrieving academic papers, making it essential for building robust RAG systems that require high-quality, structured research data.
