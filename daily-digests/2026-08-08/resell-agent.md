## Summary
A resale agent that automates the process of photographing garments or accessories, identifying them, pricing against market comps, and generating polished listings for eBay and Poshmark. It includes optional background removal, attribute extraction, and eBay API integration for publishing listings.

## Key Features
- Automated background removal and image cropping for cleaner input
- Attribute extraction from images using Claude Vision API
- Parallel market comp gathering across multiple platforms (eBay, Poshmark, ThredUp, etc.)
- Draft generation for eBay and Poshmark listings with price comparisons
- eBay API integration for publishing listings (Poshmark is read-only)

## Why It Matters for RAG Builders
It streamlines the resale process by automating pricing, listing generation, and publishing, reducing manual effort for sellers and improving listing quality.
