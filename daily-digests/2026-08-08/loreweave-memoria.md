## Summary
LoreConvo provides cross-surface persistent memory for AI assistants like Claude, enabling seamless context retention across devices, sessions, and time. It transforms ephemeral conversations into a continuous, searchable narrative with encrypted storage and selective recall capabilities.

## Key Features
- Cross-surface persistent memory for AI sessions (desktop, mobile, web, API)
- Encrypted Lore Journal for secure context storage and retrieval
- Selective recall and redaction for privacy control
- Multi-language support with session-specific language retention
- Hybrid integration with both Claude and OpenAI APIs

## Why It Matters for RAG Builders
LoreConvo eliminates the need for AI assistants to restart conversations from scratch, enabling true continuity and productivity for knowledge workers, researchers, and developers.
