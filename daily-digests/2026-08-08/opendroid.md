## Summary
OpenDroid is an open-source autonomous AI agent for Android that executes complex tasks by planning, executing, verifying, and adapting actions without user intervention. It integrates with multiple LLM providers, controls device functions, and includes a multi-tier memory system for persistent context.

## Key Features
- Self-planning and re-evaluation engine for complex task execution
- Multi-tier memory system (working, episodic, semantic, procedural)
- Support for 12 LLM providers with automatic failover
- Full device control via accessibility APIs (system, communication, media, smart home)
- Vision engine for screen analysis and fallback text-scraping

## Why It Matters for RAG Builders
OpenDroid provides a production-ready framework for building autonomous AI agents on Android, enabling advanced task automation and multi-modal interaction for RAG and AI stack builders.
