## Summary
ForkSync automates the synchronization of GitHub forked repositories with upstream changes and resolves merge conflicts using AI agents like Claude Code or OpenCode. It provides a desktop app with a guided workflow, real-time agent terminal, and an HTTP API for programmatic access.

## Key Features
- Automated periodic sync of forked repositories with upstream changes
- AI-powered merge conflict resolution using agents like Claude Code or OpenCode
- Polished desktop app with step-by-step workflow and real-time agent terminal
- Standalone HTTP server for programmatic access and headless operation
- Multi-language support, IDE integration, and post-sync command execution

## Why It Matters for RAG Builders
ForkSync eliminates manual merge conflicts and tedious sync tasks for developers maintaining forked repositories, enabling seamless upstream updates with AI-assisted resolution.
