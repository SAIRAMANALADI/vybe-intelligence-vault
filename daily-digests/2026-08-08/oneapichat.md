## Summary
OneAPIChat is a self-hosted multi-model AI chat platform offering 69 MCP tools, agent sub-agents, resumable streaming, and Chaoxing Learn automation. It provides OpenAI-compatible REST APIs, multi-user support, and browser automation via Playwright.

## Key Features
- 69 built-in MCP tools for search, automation, and document generation
- Multi-agent system with Plan/Agent/YOLO modes for task delegation
- Resumable streaming with SSE and SQLite persistence
- OpenAI-compatible REST API for third-party client integration
- Chaoxing Learn automation with QR login and exam assistance

## Why It Matters for RAG Builders
