## Summary
Vidurai is a local-first AI memory layer that indexes development context for AI tools like Claude, Cursor, and VS Code without uploading source code to third-party vector clouds. It runs as a background service, stores data locally, and serves context via MCP and IPC protocols.

## Key Features
- Local storage of development context (no cloud uploads)
- Integration with VS Code, Cursor, and Claude via MCP/IPC
- Strategic Forgetting (SF-V2) for efficient memory management
- Semantic compression of context for AI tools
- Privacy-focused with PII redaction and offline learning

## Why It Matters for RAG Builders
Vidurai enables AI tools to retain and utilize local development context without compromising privacy, making it essential for secure and efficient RAG implementations.
