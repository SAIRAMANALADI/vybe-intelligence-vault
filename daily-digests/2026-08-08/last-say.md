## Summary
Last Say is a local-first, human-in-the-loop financial review tool that integrates external AI agents (e.g., Claude Code) to process bank statements, classify transactions, and generate audit trails while preserving user control over final decisions.

## Key Features
- Local-first data storage with SQLite for privacy and control
- Integration with external AI agents (bring-your-own-model) for transaction processing
- Human-in-the-loop review with low-confidence prioritization and batch corrections
- Durable rule learning and historical recalibration based on user corrections
- Comprehensive financial reporting (overview, trends, profit/loss, and asset tracking)

## Why It Matters for RAG Builders
It provides a privacy-preserving, auditable framework for AI-assisted financial review that empowers users to retain control while leveraging AI for automation and insight generation.
