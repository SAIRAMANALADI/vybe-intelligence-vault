## Summary
An AI assistant for managing and automating tasks in Yandex KIT (Yandex Marketplace) stores. It allows users to describe desired outcomes in natural language, and the assistant executes and verifies actions like creating promotions, managing catalogs, or attaching documents to products.

## Key Features
- Natural language task execution for Yandex KIT store management
- Automated creation and verification of promotions, discounts, and promo codes
- Catalog auditing and error correction (e.g., missing documents, incorrect prices)
- Document attachment and categorization for products
- Multi-scenario support (operator, catalog doctor, promo launcher, launch checker)
