## Summary
Sortie-dogs is an OpenCode orchestration plugin that transforms open-ended tasks into bounded, validated implementation workflows. It enforces strict write gates, parallel investigation, dedicated implementation, and evidence-backed completion while preserving standard OpenCode agents and settings.

## Key Features
- Opt-in OpenCode plugin for task orchestration with strict write gates
- Parallel investigation with exactly three bounded scouts before implementation
- Dedicated worker model for implementation and remediation with scoped write permissions
- Canonical validation and risk-based review before coordinator-owned completion
- Bounded continuation for long-running tasks with restart recovery

## Why It Matters for RAG Builders
It provides a structured, controlled, and auditable way to manage AI agent workflows, ensuring tasks are completed within defined boundaries and validated against evidence, which is critical for reliable RAG and AI stack operations.
