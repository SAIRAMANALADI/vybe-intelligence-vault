## Summary
FylloCode is a governance layer for AI coding agents that ensures team-wide consistency, traceability, and continuous evolution of project rules. It bridges the gap between agent sessions and persistent project context, preserving decisions, constraints, and lineage for future tasks.

## Key Features
- Unified team-wide coding rules enforced across all agents and sessions via `fyllo-specs` MCP server
- Structured decision documentation and archival for long-term traceability of design choices and rejected alternatives
- Multi-root workspace support enabling up to 16 projects per session with cross-project context injection
- Automated synchronization of task results with existing development systems (e.g., 云效, Jira) to avoid toolchain silos
- Dynamic guidelines evolution through `fyllo-cortex` that continuously updates project knowledge based on real-world usage

## Why It Matters for RAG Builders
FylloCode ensures AI coding agents operate within a persistent, team-aligned governance framework, eliminating context loss between sessions and enabling scalable, auditable collaboration.
