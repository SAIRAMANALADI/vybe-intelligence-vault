## Summary
Bladebro is an agentic browser driver designed for AI agents, providing full control over Chromium with minimal tools, zero runtime dependencies, and advanced features like re-render immunity and delta-first token efficiency.

## Key Features
- Five core tools (act, see, state, run, vision) for comprehensive browser control with minimal complexity
- Re-render immunity via structural fingerprints, ensuring stable element references across DOM mutations
- Delta-first token efficiency, returning only page changes to reduce token usage by 5x compared to competitors
- Batch actions for multi-step workflows in a single MCP call, halting on navigation or errors with context
- Auto-extract and infinite-scroll collect for template-free list extraction and deduplication

## Why It Matters for RAG Builders
Bladebro enables AI agents to interact with dynamic web pages reliably and efficiently, reducing token overhead and eliminating common failures like stale element references.
