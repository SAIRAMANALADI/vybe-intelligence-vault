## Summary
nyxGPT is a local-first, private ChatGPT-style system that operates entirely on a user's machine, leveraging Ollama for LLM inference and offering features like persistent sessions, RAG with Apache Cassandra, and a FastAPI backend with a Next.js web UI. It prioritizes data privacy, extensibility, and production-grade operations tooling.

## Key Features
- Local-only LLM inference via Ollama with no cloud dependency
- Persistent conversation sessions with message editing and regeneration
- Optional RAG integration using Apache Cassandra 5.0 native vector search
- Comprehensive observability stack (Prometheus, Grafana, OpenTelemetry, Jaeger, Loki)
- Production-grade deployment tooling including canary rollouts, health checks, and automated testing

## Why It Matters for RAG Builders
nyxGPT provides a fully local, privacy-preserving alternative to cloud-based LLM systems with enterprise-grade operations tooling, making it ideal for building secure, self-hosted RAG applications.
