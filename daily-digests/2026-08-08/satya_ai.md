## Summary
Satya is an open-source platform that enables AI agents to self-deploy, track tasks, log progress, and build knowledge bases while humans monitor everything in real-time via a Streamlit dashboard. It provides a Python SDK for agent integration and a lightweight, zero-database storage system for audit trails and task management.

## Key Features
- Agent self-deployment and lifecycle management via Python SDK
- Real-time Streamlit dashboard for human observers to monitor agent progress
- Durable append-only audit store with SQLite fallback for compliance
- Truth Source Manager for scraping and curating web content into knowledge bases
- Runtime policy enforcement and PII masking for security and governance

## Why It Matters for RAG Builders
Satya provides a critical bridge between autonomous AI agents and human oversight, enabling real-time accountability and auditability without complex infrastructure, which is essential for scalable and trustworthy RAG systems.
