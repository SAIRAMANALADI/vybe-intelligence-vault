## Summary
Puff is a personality-driven AI agent designed for creative writing and document interaction. It features persistent memory, file system access, and a web-based UI with 7 function-calling tools, enabling personalized and context-aware interactions.

- Persistent memory across sessions using Memory Hub integration

- Built-in rate limiting and sandboxed file operations for security
