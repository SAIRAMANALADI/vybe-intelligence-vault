## Summary
opencode-sandbox provides an isolated Docker-based environment for securely running the opencode AI coding agent, protecting host systems from filesystem access while enabling persistent, cross-platform AI-assisted development with free and premium model options.

## Key Features
- Isolated Docker sandbox restricting AI agent to current project directory only
- Non-root execution with no sudo privileges for enhanced security
- Support for free and premium AI models with token-based pricing
- Persistent configuration and toolchains via Docker volumes
- Cross-platform compatibility (Linux, macOS, Windows WSL2)
