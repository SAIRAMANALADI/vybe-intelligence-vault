## Summary
Stock Sentinel is a US stock market signal system that provides attack/defense timing alerts based on a four-dimensional data-driven framework (AI supply-demand, monetary policy, fiscal policy, and administrative policy). It offers open APIs, MCP server integration, and a public track record for AI/RAG system builders.

## Key Features
- Four-dimensional signal system (AI supply-demand, monetary, fiscal, administrative policies)
- Open REST API and MCP server for AI/RAG system integration
- Public track record and backtest reports for transparency
- Automated cron-based signal synthesis with stale-keep fallback
- Multi-language frontend (7 languages) and AI-generated daily reports

## Why It Matters for RAG Builders
