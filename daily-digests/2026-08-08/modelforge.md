## Summary
ModelForge Medical is a cross-platform clinical workspace that unifies local and cloud AI models for medical professionals, offering a structured interface for clinical decision-support, documentation, and research. It integrates agentic capabilities, patient case management, and medical-specific MCP server integrations while enforcing safety and privacy controls.

## Key Features
- Unified interface for local (Ollama/llama.cpp) and cloud (OpenAI/Anthropic/Gemini) AI models
- Agentic mode with file system and shell command execution (gated by explicit approval)
- Structured clinical response contract enforcing eight-section medical answer format
- Medical-specific MCP server integrations (Graphify, BioMCP, DICOM MCP) with safety filters
- Emergency red-flag detection, allergy/medication conflict warnings, and PHI transmission previews

## Why It Matters for RAG Builders
It provides a specialized, safety-conscious environment for medical professionals to leverage AI for clinical decision-support while maintaining strict privacy and regulatory compliance controls.
