## Summary
Nomic AI provides open and accessible AI infrastructure, including the Nomic Embed family of multilingual text and vision embedding models, the Nomic Atlas platform for interactive 2D data exploration, and the GPT4All ecosystem for local LLM inference. The repository profiles their public APIs, SDKs, and open-source models.

## Key Features
- Hosted multilingual text and vision embedding models (nomic-embed-text-v1.5, nomic-embed-vision-v1.5) with Matryoshka-style configurable dimensions
- Nomic Atlas platform for interactive 2D semantic mapping and unstructured data exploration
- Official Python and TypeScript SDKs for seamless API integration
- GPT4All ecosystem enabling local LLM inference on consumer hardware
- Open-source models and tools with Apache-2.0 and MIT licenses
