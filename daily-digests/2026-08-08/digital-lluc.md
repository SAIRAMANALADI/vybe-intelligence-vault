## Summary
A personal AI agent named 'digital-lluc' that enables first-person voice and text conversations, built with Next.js for the frontend and Pipecat for the conversational pipeline. It integrates STT, LLM, and TTS services to create an interactive digital persona.

## Key Features
- First-person AI agent with customizable persona via YAML profiles
- Supports voice and text interactions with real-time transcript visibility
- Integrates STT (Deepgram), LLM (OpenAI), and TTS (Cartesia) for seamless conversations
- Modular architecture with separate frontend (Next.js) and bot (Pipecat) components
- Daily session caps and authentication via Auth.js (Google/GitHub)
