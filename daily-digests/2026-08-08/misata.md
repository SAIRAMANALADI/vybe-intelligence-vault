## Summary
Misata is a synthetic data generation tool that creates realistic, relational datasets from declarative outcomes (e.g., revenue curves, fraud rates) without requiring real data or machine learning models. It ensures exact conformance to specified constraints and provides provable integrity via an Oracle report.

## Key Features
- Declarative outcome generation: Define desired outcomes (e.g., revenue curves, fraud rates) and generate data that provably matches them with zero error.
- Referential integrity and constraints: Ensures foreign key relationships, rollups, and custom constraints are satisfied in every generated dataset.
- Oracle report: Provides a proof bundle verifying data integrity, reproducibility, and adherence to constraints.
- Mimic mode: Generates synthetic twins of real datasets while preserving distributions and ensuring no verbatim data leakage.
- Multi-modal input: Accepts plain English descriptions, YAML schemas, or existing database schemas for flexible generation.

## Why It Matters for RAG Builders
Misata enables RAG builders to generate high-fidelity, constraint-compliant synthetic datasets for testing, validation, and development without relying on real data or ML models.
