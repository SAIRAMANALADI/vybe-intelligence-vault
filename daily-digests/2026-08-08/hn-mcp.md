## Summary
A Ruby-based MCP (Model Context Protocol) server that bridges AI assistants with Hacker News data, enabling retrieval of stories and comments via standardized MCP tools. Designed as an educational project to demonstrate MCP server architecture.

## Key Features
- Provides MCP-compliant tools for fetching Hacker News stories (top, new, best, etc.) and comments
- Uses fast-mcp Ruby gem for MCP protocol handling and tool routing
- Supports authentication via Bearer token for secure access
- Includes comprehensive testing and linting workflows
- Acts as a bridge between AI assistants and Hacker News API

## Why It Matters for RAG Builders
It enables AI assistants to seamlessly integrate real-time Hacker News data into conversations, enhancing contextual relevance for developers and researchers.
