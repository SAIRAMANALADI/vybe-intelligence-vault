## Summary
RAG Radar is a live tracker that monitors and catalogs new RAG implementations, tools, and patterns from GitHub, updated every 15 minutes using GitHub Actions and the GitHub Search API. It provides a structured feed of discoveries for developers to browse or subscribe to.

## Key Features
- Continuously monitors GitHub for new RAG-related projects and tools
- Auto-updates every 15 minutes via GitHub Actions cron
- Structured feed with categorization by component type (chunking, embedding, retrieval, generation)
- Multi-language support with localized READMEs
- Real-time tracking with provenance and timestamps

## Why It Matters for RAG Builders
It provides an up-to-date, curated feed of RAG implementations and tools, enabling developers to discover and integrate the latest advancements in RAG systems efficiently.
