## Summary
A community-maintained pronunciation dictionary and CLI tool for developer jargon, providing accurate pronunciations with cited sources for 1,848+ technical terms. Includes a Bash CLI, VS Code extension, MCP server, and integrations for AI assistants like Claude Code.

## Key Features
- 1,848+ entries with IPA, audio, and citable sources for developer jargon pronunciations
- Bash CLI with zero dependencies for quick installation and usage
- VS Code extension for real-time pronunciation lookup in code
- MCP server for AI assistant integrations (Claude, Cursor, Continue, etc.)
- Community-driven dictionary with confidence-tagged entries and dispute resolution
