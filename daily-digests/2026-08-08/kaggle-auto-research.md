## Summary
An AI agent-driven framework for automating Kaggle competition research, including EDA, feature engineering, model training, iteration, and safe submission management. Designed to enable reproducible, collaborative workflows between humans and agents.

## Key Features
- Agent-friendly CLI with structured outputs for machine parsing
- Workspace isolation per competition with versioned artifacts
- Safe submission handling with dry-run and budget controls
- Integration with Kaggle API for data, leaderboard, and submissions
- Modular pipeline for research, EDA, feature engineering, and model training
