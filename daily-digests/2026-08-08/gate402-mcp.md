## Summary
MCP server for Gate402, a pay-per-call API platform enabling AI agents to access GPU/CPU compute, LLM inference, web scraping, on-chain data, and trading tools via HTTP 402 (x402/USDC on Base). Provides a free tier and integrates seamlessly with MCP-compatible agent frameworks.

## Key Features
- 17+ MCP-compatible tools for AI agents, including LLM inference, GPU compute, web scraping, and on-chain data retrieval
- Free tier with self-claimed API key and pay-per-call pricing for premium tools
- Integration with agent frameworks (LangChain, CrewAI, LlamaIndex) via MCP adapters
- Supports GPU marketplace with escrow-on-success payments in USDC on Base
- Local tools for token counting, HTML-to-Markdown conversion, and JSON repair without network calls

## Why It Matters for RAG Builders
It provides AI agents with a seamless, pay-per-call toolkit for compute, inference, and data retrieval, reducing setup friction and enabling scalable, cost-efficient agentic workflows.
