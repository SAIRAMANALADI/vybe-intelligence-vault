## Summary
A Claude Code skill that automates the export of an entire Discord server's history into organized HTML and JSON formats, addressing common pitfalls of the underlying DiscordChatExporter tool while handling authentication and output restructuring seamlessly.

## Key Features
- Automated Discord server history export into organized HTML and JSON
- Handles authentication via Playwright MCP without manual DevTools interaction
- Restructures DiscordChatExporter output into human-readable folder/filename format
- Includes thread exports and detailed summary reports
- Surfaces Discord ToS compliance risks and alternatives upfront
