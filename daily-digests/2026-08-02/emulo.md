## Summary
Emulo mines AI coding session logs (Claude Code, Codex, Copilot CLI, etc.) into a personalized 'you.md' profile that AI agents read before tasks, enabling them to emulate the user's work patterns, preferences, and behaviors without explicit rules. It operates locally with optional hosted Pro features for cross-device synchronization.

## Key Features
- Mines raw AI coding session logs to extract implicit user behaviors, preferences, and work patterns without requiring manual rule definition
- Generates a shareable 'you.md' profile card with archetype, top laws, and session stats for AI agents to reference before tasks
- Supports multiple AI agents (Claude, Codex, Cursor, Copilot, OpenClaw, Hermes) via native plugins, adapters, or MCP server
- Operates locally with zero dependencies, ensuring user data privacy and offline functionality
- Offers optional hosted Pro features for encrypted cross-device synchronization and managed pairing without exposing raw session data

## Why It Matters for RAG Builders
Emulo bridges the gap between static AI agent instructions and dynamic, behaviorally accurate personalization by mining real user interactions, enabling agents to emulate authentic work patterns and preferences.
