## Summary
A personal design-inspiration database that captures full-page screenshots, component crops, color palettes, typography, and AI-generated reviews of websites or apps. It integrates with Claude via the Model Context Protocol (MCP) for seamless search and retrieval during design workflows.

## Key Features
- Automated capture of full-page screenshots and component-level details
- AI-generated reviews and analysis of design elements (palettes, typography)
- Seamless integration with Claude via MCP for real-time design inspiration
- SQLite FTS5-powered search for efficient retrieval
- Supports manual CLI operations for adding and searching designs

## Why It Matters for RAG Builders
It streamlines the design process by providing AI-assisted, context-aware access to curated design inspiration directly within the workflow.
