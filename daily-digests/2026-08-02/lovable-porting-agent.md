## Summary
A model-neutral Agent Skill and CLI toolkit designed to migrate Lovable-generated applications to self-controlled infrastructure. It automates inventory, safety checks, and deployment planning while supporting empty/schema-only recreations or authorized database clones.

## Key Features
- Automated inventory of Lovable and Supabase dependencies, migrations, and configurations
- Safety-first deployment planning with approval gates and evidence tracking
- Support for empty/schema-only recreations or authorized database clones
- Model-neutral compatibility with Codex, Claude Code, and other Agent Skills clients
- Hosting and backend selection decoupled for flexible infrastructure choices

## Why It Matters for RAG Builders
It simplifies the complex process of migrating AI-generated applications to self-hosted infrastructure while ensuring safety, compliance, and flexibility for RAG stack builders.
