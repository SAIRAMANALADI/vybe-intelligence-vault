## Summary
A Docker-based runtime harness for Anthropic's Claude Code agentic CLI, providing an isolated, pre-configured environment with multiple interfaces (CLI, HTTP API, MCP server, Telegram bot, and cron scheduler) for seamless integration into AI workflows.

## Key Features
- Pre-installed dev toolchain (minimal or full variants) with passwordless sudo and Docker-in-Docker support
- Multiple runtime interfaces: CLI, HTTP API, MCP server, Telegram bot, and cron scheduler
- OpenAI-compatible API endpoint for seamless integration with existing AI tools
- Persistent sessions and workspace isolation with automatic busy/idle tracking
- Security-hardened container with resource limits, privilege dropping, and read-only filesystems

## Why It Matters for RAG Builders
It provides a standardized, secure, and flexible runtime environment for deploying and integrating Anthropic's Claude Code into AI pipelines, reducing setup overhead and enabling multi-modal agent interactions.
