## Summary
A production-ready Google Workspace MCP server that provides unified access to Gmail, Calendar, Drive, Sheets, Docs, Tasks, People, Forms, and Slides via a single FastMCP package. Supports advanced features like OAuth token encryption, multi-user sessions, and optional integrations with Google Keep, Chat, Meet, and Gemini media tools.

## Key Features
- Unified access to 9+ Google Workspace services (Gmail, Calendar, Drive, Sheets, Docs, etc.) via a single MCP server
- Secure OAuth token encryption with per-user isolation and key rotation support
- FastMCP advanced features including progress updates, sampling, and resources
- Multi-user support with session-aware Streamable HTTP and OIDC authentication
- Optional integrations for Google Keep, Chat, Meet, and Gemini media tools with feature flags

## Why It Matters for RAG Builders
This repository provides a critical bridge for AI systems to interact programmatically with Google Workspace, enabling seamless integration of email, calendar, documents, and collaboration tools into RAG and agent workflows.
