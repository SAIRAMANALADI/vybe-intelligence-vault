## Summary
MCPBridge is a production-grade Model Context Protocol (MCP) server that securely connects AI assistants to PostgreSQL databases, providing robust guardrails for safe querying, schema exploration, and guarded writes with audit logging and anomaly detection.

## Key Features
- Query safety validation with DDL blocking and multi-statement payload prevention
- Two-phase guarded writes with risk assessment and explicit confirmation
- Automatic result limiting for unbounded SELECT queries
- Comprehensive audit logging with anomaly detection and log rotation
- Schema intelligence with cached metadata and relationship maps

## Why It Matters for RAG Builders
MCPBridge provides essential guardrails for AI assistants interacting with databases, ensuring safe, audited, and controlled access to PostgreSQL in production environments.
