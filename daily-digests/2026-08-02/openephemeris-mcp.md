## Summary
OpenEphemeris MCP Server provides typed astrology tools powered by NASA JPL DE440 ephemeris, enabling zero-hallucination calculations for planetary positions, natal charts, and astrological data. It integrates with MCP-compatible clients for real-time astrological analysis and interactive chart visualization.

## Key Features
- Zero-hallucination planetary position calculations using NASA JPL DE440 ephemeris
- Interactive chart visualization with clickable elements for deeper analysis
- Multi-client compatibility via MCP (Claude, Cursor, Windsurf, etc.)
- Tiered tool access with clear credit-based pricing and quota management
- Hosted and self-hosted deployment options with Streamable HTTP support
