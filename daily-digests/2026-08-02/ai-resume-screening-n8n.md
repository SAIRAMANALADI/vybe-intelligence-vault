## Summary
An automated AI-powered resume screening workflow that extracts text from PDF resumes, analyzes them using a local LLM (Ollama with Qwen3:4B), and stores results in Google Sheets while sending Gmail notifications based on screening criteria.

## Key Features
- PDF resume text extraction
- AI-based resume analysis with Qwen3:4B
- Structured JSON output for candidate data
- Automated candidate screening based on skills (Python/FastAPI)
- Google Sheets integration for candidate tracking
