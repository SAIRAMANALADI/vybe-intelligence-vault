## Summary
Delimit provides a governance chain for AI-written code, enabling signed, replayable attestations for every merge or AI-assisted change. It wraps AI coding assistants (e.g., Claude Code, Cursor) to enforce policy gates, record changes, and generate verifiable audit trails without requiring accounts or complex setup.

## Key Features
- Signed, replayable attestations for AI-generated code changes
- Policy-based merge gates (linting, security, breaking changes)
- Cross-model deliberation and consensus for judgment calls
- Context persistence across AI assistants and sessions
- Automated drift detection and PR governance via GitHub Actions

## Why It Matters for RAG Builders
It provides a critical layer of verifiable governance and auditability for AI-assisted code changes, ensuring compliance, reproducibility, and trust in AI-driven development workflows.
