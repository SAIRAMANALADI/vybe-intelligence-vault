## Summary
OpenABCode is a terminal-based coding agent that automatically routes coding tasks to the most suitable LLM provider (OpenAI, Anthropic, Google, or a hosted gateway) based on task classification. It provides an interactive CLI with model selection, session auditing, and extensibility through custom providers and themes.

## Key Features
- Automatic task classification and model routing for optimal LLM selection
- Interactive terminal UI with model selectors, session views, and audit trails
- Support for custom providers, extensions, skills, and prompt templates
- Built-in hosted gateway provider for authentication and API management
- Containerization and sandboxing options for secure execution

## Why It Matters for RAG Builders
OpenABCode streamlines AI-powered coding workflows by dynamically selecting the best model for each task, reducing latency and cost while improving output quality for RAG and agent-based systems.
