## Summary
gemini-faf-mcp is an MCP server that enables Google Gemini to read and utilize a structured YAML file (.faf) containing persistent project context, eliminating the need to re-explain project details across sessions. It auto-detects project stacks and exports context to AI-friendly formats like GEMINI.md.

## Key Features
- Persistent project context via structured .faf YAML files for AI agents
- Auto-detection of project stacks from manifest files (e.g., pyproject.toml, package.json)
- 12 MCP tools for creating, validating, scoring, and exporting project context
- Supports Dart and Flutter projects alongside Python, JavaScript, Rust, and others
- Cloud Run REST API for multi-agent context brokering and badge generation

## Why It Matters for RAG Builders
It eliminates repetitive project onboarding for AI agents by providing a single source of truth for project context, significantly improving RAG accuracy and developer productivity.
