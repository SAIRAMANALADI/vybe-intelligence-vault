## Summary
Arthur MCP is an open-source, self-hostable control plane for building, operating, and governing Model Context Protocol (MCP) servers from APIs, databases, prompts, and internal tools. It simplifies the operational layer around MCP servers, including authentication, rate limiting, logging, and documentation.

## Key Features
- Turns any data source (APIs, databases) into governed MCP servers with full lifecycle management
- Built-in authentication, secrets management, rate limiting, and observability (logs, metrics, tracing)
- Dynamic tool generation from OpenAPI/Postman specs with manual overrides and testing
- Shared prompt library and reusable resources for consistent AI client interactions
- Role-based access control with customizable permissions and audit logging

## Why It Matters for RAG Builders
Arthur MCP provides the critical operational infrastructure to safely and efficiently expose real-world systems as MCP servers, bridging the gap between AI clients and production data sources.
