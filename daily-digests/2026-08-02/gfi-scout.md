## Summary
GFI Scout is an MCP server and CLI tool designed to identify high-quality 'good first issue' opportunities in open-source repositories by scoring issues based on repo health, maintainer responsiveness, and setup complexity. It filters out abandoned or oversubscribed issues, providing actionable insights for beginners.

## Key Features
- Scores issues by likelihood of success using composite metrics (repo health, merge rate, maintainer responsiveness, issue freshness, setup complexity)
- Provides MCP server, CLI, and TUI interfaces for flexible integration with AI agents and terminal workflows
- Parallel GitHub API requests with caching for performance optimization
- Configurable scoring weights via JSON for easy customization without code changes
- Comprehensive documentation and setup guides for MCP client integration

## Why It Matters for RAG Builders
It helps AI agents and developers quickly identify high-quality, beginner-friendly open-source issues, reducing noise and improving contribution success rates.
