## Summary
JAWATA is a compiler-accurate Java analysis and refactoring MCP server that enables AI agents to perform IDE-grade, behavior-preserving code modifications using Eclipse JDT and LTK. It provides 43+ tools for navigation, refactoring, smell detection, and verification, ensuring surgical precision in Java codebases.

## Key Features
- Compiler-accurate code analysis and refactoring using Eclipse JDT and LTK for IDE-grade precision
- Behavior-preserving transformations with undo support via `undoChangeId` for reversible changes
- 43+ MCP tools covering navigation, refactoring, smell detection, dependency management, and compilation verification
- Strict disk sync to ensure every tool call reflects the current workspace state with millisecond staleness detection
- Portable knowledge store in markdown files and H2 database for persistent, cross-client recall of agent lessons

## Why It Matters for RAG Builders
JAWATA enables AI agents to safely and precisely refactor Java codebases with compiler-grade accuracy, eliminating the risks of text-based or heuristic approaches and ensuring verifiable, reversible changes.
