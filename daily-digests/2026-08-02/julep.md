## Summary
Julep is a framework for building durable, composable AI agents using define-by-construction Python flows. It enables crash-resilient, retry-safe agent execution with detailed step-by-step explanations and strict tool access control.

## Key Features
- Define agents as composable, durable dataflows using Python decorators like `@flow` and `@pure`
- Built-in crash resilience, retries, and step-by-step explanations via projections
- Strict tool access control with encrypted secrets and MCP policy enforcement
- CLI for agent discovery, execution, testing, and deployment (`julep ls`, `julep run`, etc.)
- Supports multiple execution backends (Temporal, DBOS) and optional extras for HTTP, MCP, and telemetry

## Why It Matters for RAG Builders
Julep provides a robust foundation for building production-grade AI agents with durability, composability, and strict control over tool access, making it essential for RAG builders seeking reliable, explainable agent systems.
