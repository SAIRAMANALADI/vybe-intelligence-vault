## Summary
An MCP 3.0 server providing NFL-related tools for health monitoring, web content extraction, news fetching, team data, and fantasy football management via REST and MCP protocols. Integrates ESPN, Sleeper, and CBS Sports APIs for real-time sports intelligence.

## Key Features
- 60+ MCP tools for NFL data, fantasy management, and web scraping
- Integration with ESPN, Sleeper, and CBS Sports APIs
- Health monitoring endpoint for server status
- Flexible configuration via environment variables and YAML/JSON files
- Dockerized deployment with hot-reloading support
