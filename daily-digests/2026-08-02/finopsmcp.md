## Summary
nable is a FinOps MCP server designed to integrate with AI agents like Claude and Cursor, enabling cost-aware infrastructure decisions. It provides real-time cost insights across major cloud providers (AWS, Azure, GCP), Kubernetes, and 15+ SaaS/AI services, priced on actual rates rather than list prices.

## Key Features
- Real-time cost queries and anomaly detection across AWS, Azure, GCP, Kubernetes, and 15+ SaaS/AI providers
- Local-first architecture with encrypted credential storage and no data egress
- Agent pre-action cost gate for infrastructure changes (e.g., Terraform, Helm) to prevent overspending
- Automated rightsizing recommendations and remediation PRs for cost savings
- Supports both CLI and AI editor integrations (Claude, Cursor) with zero per-token costs
