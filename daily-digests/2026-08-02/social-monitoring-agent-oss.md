## Summary
A modular agent framework for community management and developer relations, enabling automated social mention monitoring, reply drafting, sentiment tracking, and engagement analytics. Skills are configured via environment variables and designed to integrate with agent harnesses like Warp/Oz.

## Key Features
- Modular agent skills for monitoring, drafting, and reporting across social platforms
- Configurable via environment variables for brand-neutral deployment
- Supports scheduled tasks and direct script execution
- Integrates with Slack, X (Twitter), GitHub, and third-party analytics tools
- Includes sentiment analysis, metrics tracking, and reward-ops workflows

## Why It Matters for RAG Builders
It provides a reusable framework for automating community engagement and sentiment analysis, reducing manual workload for developer relations teams.
