## Summary
Quid is an autonomous personal money agent on the Casper blockchain that advances stablecoin against verified income before payday, repays itself automatically upon receiving wages, and builds an on-chain reputation to reduce future advance costs. It operates as a fully functional agentic system with real on-chain transactions and autonomous decision-making loops.

## Key Features
- Autonomous agent loop: perceive, verify, decide, act, settle
- Real on-chain transactions with autonomous advance issuance and repayment
- On-chain reputation system to reduce future advance costs
- Integration with Plaid for income and balance verification
- Supports real stablecoin (CEP-18 dUSDC) on Casper Testnet

## Why It Matters for RAG Builders
Quid demonstrates a fully autonomous agentic system that integrates real-world financial data with blockchain operations, making it a critical example for builders of agentic AI systems in decentralized finance.
