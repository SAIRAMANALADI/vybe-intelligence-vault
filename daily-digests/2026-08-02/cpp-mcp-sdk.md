## Summary
A C++ SDK for building production-ready Model Context Protocol (MCP) servers and clients with full compliance to MCP 2025-11-25, including Streamable HTTP transport, OAuth 2.1 authorization, and cross-platform support.

## Key Features
- Full MCP 2025-11-25 protocol compliance with tools, resources, prompts, and utilities
- Support for stdio and Streamable HTTP transports with resumable SSE
- OAuth 2.1 + PKCE authorization with RFC9728 discovery and security features
- Cross-platform compatibility (Linux, macOS, Windows) with CI/CD and reproducible builds
- Comprehensive test suite (18K+ lines) including conformance, integration, and security tests

## Why It Matters for RAG Builders
It provides a robust, production-ready C++ foundation for integrating MCP servers and clients into RAG pipelines, enabling secure, high-performance tooling and resource interactions.
