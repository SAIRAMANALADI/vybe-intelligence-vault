## Summary
Deep Analysts provides a middleware stack for LangChain/LangGraph agents, enabling memory management, filesystem access, subagent orchestration, and tool error handling. It integrates with cloud backends and supports modular agent architectures for AI-driven workflows.

## Key Features
- Modular middleware for LangChain/LangGraph agents (memory, skills, filesystem, subagents)
- Support for multiple backends (file-based, cloud sync via Basement API, sandboxed execution)
- Subagent orchestration with task delegation and tool routing
- Tool error handling and patching for dangling tool calls
- Summarization middleware for long-running conversations

## Why It Matters for RAG Builders
Deep Analysts simplifies building robust, modular AI agents with built-in memory, orchestration, and error handling, reducing development overhead for RAG and agent-based systems.
