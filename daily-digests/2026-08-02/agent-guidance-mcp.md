## Summary
Agent Guidance MCP is a Model Context Protocol (MCP) server that provides AI agents with structured guidance, a 168-skill catalog, bounded project context tools, and token optimization to improve coding efficiency and reduce context bloat during AI-driven development tasks.

## Key Features
- 168-skill catalog covering backend, frontend, testing, security, DevOps, and 12+ language ecosystems
- Token optimization engine reducing response size by 40-80% through 8-stage filtering pipeline
- Bounded project context tools (e.g., file tree, search, read, symbols) with smart truncation to 300 lines
- Automated standards and workflow prompts for AI agents to follow production patterns without manual input
- Cross-IDE compatibility with auto-configuration for MCP-compatible clients (Claude, Cursor, VS Code, etc.)

## Why It Matters for RAG Builders
It streamlines AI agent workflows by providing structured guidance, reducing context bloat, and optimizing token usage, making it essential for building efficient RAG and agent-based systems.
