## Summary
nekoro-browser is a lightweight browser automation CLI and MCP server that drives Chrome via a custom extension, preserving login state without requiring a debug port. It enables programmatic interaction with Chrome using a persistent WebSocket connection and provides 45 MCP tools for AI agents.

## Key Features
- Preserves Chrome login state without debug port restrictions
- 45 built-in MCP tools for AI agents (no glue code required)
- Self-healing architecture with runtime-editable helpers
- Persistent WebSocket connection for reliable automation
- Zero third-party dependencies (pure Python stdlib)

## Why It Matters for RAG Builders
It provides a reliable, login-preserving way to automate Chrome for RAG pipelines and AI agents without the overhead of debug ports or heavy frameworks.
