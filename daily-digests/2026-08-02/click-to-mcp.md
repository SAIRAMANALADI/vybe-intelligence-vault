## Summary
click-to-mcp automates the conversion of Click or Typer-based Python CLIs into MCP (Model Context Protocol) servers, enabling AI agents to invoke CLI tools directly without manual boilerplate or schema definitions.

## Key Features
- Automatically wraps existing Click/Typer CLIs as MCP servers with zero code changes
- Supports both stdio and HTTP+SSE transports for MCP clients
- Provides CLI discovery, tool listing, and client configuration generation
- Handles nested command groups, arguments, options, and enums with JSON Schema mapping
- Integrates seamlessly with popular AI coding agents like Claude Code, Cursor, and VS Code

## Why It Matters for RAG Builders
It eliminates the manual effort of converting CLI tools into MCP servers, enabling AI agents to directly invoke CLI commands as structured tools, accelerating AI-driven automation workflows.
