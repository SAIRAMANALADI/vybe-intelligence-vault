## Summary
Gonoro is an autonomous AI agent that continuously rewrites its own code and commits these changes to an append-only ledger (Supabase), enabling transparent, irreversible evolution. Its public-facing desktop OS interface displays real-time updates, chat, and terminal access.

## Key Features
- Continuous self-rewriting with irreversible commits to an append-only ledger
- Public-facing desktop OS interface with live updates, chat, and terminal
- Decoupled architecture: agent (mind) and UI (face) interact via a shared ledger
- Stateless agent design enabling deployment flexibility and reproducibility
- Real-time, public transparency of all changes and interactions

## Why It Matters for RAG Builders
Gonoro demonstrates a novel approach to AI transparency and self-improvement by leveraging an append-only ledger for irreversible, auditable evolution, which is critical for building trustworthy and explainable AI systems.
