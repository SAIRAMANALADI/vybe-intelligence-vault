## Summary
An AI agent that automates federal contract opportunity scanning by driving a real browser to interact with the SAM.gov Contract Opportunities search, extract active solicitations, and report key details like titles, agencies, and deadlines. It includes a bundled offline mock for zero-cost testing and safety mechanisms to prevent accidental spend.

## Key Features
- Zero-dependency Node.js implementation with no external packages
- Offline mock mode for $0 testing with no API keys or accounts
- Safety mechanisms to prevent accidental spend (two-factor consent, cost caps)
- Self-documenting agent loop with provenance tracking and frame-by-frame hashing
- Idempotent execution with hard caps and fail-closed defaults
