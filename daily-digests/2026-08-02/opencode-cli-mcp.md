## Summary
opencode-cli-mcp is an MCP server that wraps the opencode CLI's HTTP API into 22 FastMCP tools, providing session memory, RAG capabilities, and agent orchestration. It includes a FastAPI REST bridge, a Vite/React dashboard, and OpenCode custom tools for extended functionality.

## Key Features
- Eternal session memory with full-text and semantic search across all past interactions via SQLite database
- 22 FastMCP tools (7 primary + 15 legacy aliases) for session management, agent runs, backups, and system diagnostics
- Unified backend with FastAPI REST bridge and MCP endpoint on a single port (10951)
- Vite/React dashboard for interactive session review, agent management, and tool discovery
- OpenCode custom tools for extending opencode's LLM capabilities with MCP fleet management

## Why It Matters for RAG Builders
It provides essential session memory, RAG capabilities, and agent orchestration tools that enable persistent, searchable, and scalable AI workflows for RAG builders.
