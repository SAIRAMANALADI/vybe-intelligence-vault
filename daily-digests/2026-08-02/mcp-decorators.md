## Summary
A TypeScript-native decorator library designed to simplify and accelerate Model Context Protocol (MCP) server and client development by eliminating boilerplate code for request handling, resource serving, notifications, and capabilities registration.

## Key Features
- Class-based declarative structure for MCP servers and clients using decorators
- Automated registration of tools, prompts, resources, and capabilities
- Support for static and dynamic resource URIs with template matching
- Built-in validation using Zod schemas for tool inputs
- Low-level request/notification handlers for advanced routing

## Why It Matters for RAG Builders
It streamlines MCP server and client development by reducing boilerplate, enabling faster integration of tools, resources, and capabilities for RAG systems.
