## Summary
Aetnamem is a local-first Python engine for provenance-aware agent memory and guarded actions, enabling stateful AI agents with auditable, verifiable, and secure memory management. It provides a lightweight SQLite-based memory store, exact-plan guarded actions, and an optional desktop assistant app with Ollama integration.

## Key Features
- Provenance-aware memory with deterministic audit chains using SHA-256 hashing
- Exact-plan guarded actions with HMAC-based approval and verification
- Quarantine and classification of untrusted content with manual promotion
- Cross-platform desktop assistant with Ollama integration for local LLM inference
- Independent verifiers for audit logs and action integrity (no aetnamem code dependency)

## Why It Matters for RAG Builders
Aetnamem provides a critical foundation for building trustworthy, auditable AI agents by ensuring memory provenance and action integrity without relying on external APIs.
