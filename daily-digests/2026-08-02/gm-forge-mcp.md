## Summary
gm-forge-mcp is an MCP server that enables AI assistants to programmatically create, edit, and manage GameMaker Studio projects, including resources like scripts, objects, rooms, sprites, and sounds. It ensures compatibility with the GameMaker IDE by validating changes against official tooling.

## Key Features
- AI-driven project scaffolding and resource creation (scripts, objects, rooms, etc.)
- Cross-platform compatibility with Windows GameMaker integration for validation and compilation
- Comprehensive resource reference tracking for safe renaming and deletion
- Validation via GameMaker's official ProjectTool and Igor compiler
- Extensive testing suite with schema validation and live IDE compatibility checks

## Why It Matters for RAG Builders
