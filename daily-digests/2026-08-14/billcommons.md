## Summary
Bill Commons is an open-source legislative search platform providing comprehensive access to U.S. state and DC bills through a web UI, REST API, and MCP server. It aggregates and normalizes legislative data from all 50 states and DC, enabling public search and analysis without paywalls.

## Key Features
- Comprehensive U.S. state and DC legislative data coverage (209k+ bills)
- Multi-protocol access: web UI, REST API, and MCP server for AI assistants
- Idempotent ingestion pipeline with support for bulk CSV and incremental updates
- Public infrastructure-first design with no paywall on ordinary use
- Modular monorepo architecture with shared data model and utilities
