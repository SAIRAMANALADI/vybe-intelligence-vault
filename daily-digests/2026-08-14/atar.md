## Summary
ATAR is a local-first, open-source terminal-based autonomous AI agent designed for developers and researchers. It executes real-time tool calls, supports multiple AI providers, and emphasizes clarity, verification, and user control without cloud middleware or telemetry.

## Key Features
- Autonomous multi-turn agent loop with streaming tool execution and real-time feedback
- Supports six AI providers (DeepSeek, OpenAI, Anthropic, etc.) with automatic fallback
- Real terminal REPL with slash commands, multiline editing, and persistent status bar
- Built-in research and coding tools (web search, file ops, terminal commands, git, tests)
- Session persistence, memory management, and theme engine for customization

## Why It Matters for RAG Builders
ATAR provides a local, verifiable, and autonomous agent framework that enables developers to build and interact with AI agents directly in their terminal, ensuring transparency and control over tool execution and data.
