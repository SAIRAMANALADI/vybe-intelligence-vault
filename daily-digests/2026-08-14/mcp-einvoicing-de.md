## Summary
A Model Context Protocol (MCP) server in Python for German electronic invoicing (ZUGFeRD 2.x and XRechnung 3.x formats) compliant with EN 16931 and KoSIT standards. Enables AI agents to create, validate, parse, and convert e-invoices for German B2B mandates.

## Key Features
- Generates and validates ZUGFeRD 2.x and XRechnung 3.x invoices compliant with German B2B e-invoicing mandates
- Supports local and cloud-based validation (KoSIT) with Schematron rules
- Provides tools for parsing, converting, and exporting invoices (e.g., DATEV, Peppol)
- Includes tax rule queries for German VAT compliance (e.g., reverse charge, Kleinunternehmer)
- Integrates with AI agents (Claude, Cursor, Kiro) via MCP for automated invoice processing
