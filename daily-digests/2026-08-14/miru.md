## Summary
Miru is an open-source AI companion that runs entirely on your local machine or self-hosted server, featuring a Live2D desktop pet that proactively remembers and interacts with you based on your daily activities. It prioritizes privacy by storing all data locally and using verifiable memory systems.

## Key Features
- Runs entirely on user-controlled hardware (Mac, Android, or self-hosted server)
- Verifiable long-term memory stored in plain Markdown files for transparency
- Proactive companionship with an AttentionEngine that decides when to engage
- Multi-device sync via self-hosted backend with invitation-based pairing
- Screen sensor for contextual understanding without storing screenshots

## Why It Matters for RAG Builders
Miru provides a privacy-preserving, locally-hosted framework for building AI agents that remember and proactively interact with users, reducing reliance on cloud-based memory systems.
