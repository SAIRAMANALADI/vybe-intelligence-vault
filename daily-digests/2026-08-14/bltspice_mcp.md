## Summary
bltspice_mcp is an MCP server that enables LLMs to generate, convert, and simulate LTSpice circuits in real-time. It bridges LLMs with LTSpice by converting netlist files to schematic formats, running simulations, and exporting results to CSV for AI-driven electronics design workflows.

## Key Features
- Converts LTSpice netlist (.net) files to schematic (.asc) format for visualization
- Runs real-time LTSpice simulations directly from LLM tool calls
- Exports simulation results (traces) to CSV for downstream analysis
- Provides MCP-compatible APIs for seamless LLM integration
- Supports both Linux/macOS (via Wine) and Windows environments

## Why It Matters for RAG Builders
It enables AI agents to autonomously design, simulate, and analyze electronic circuits using LTSpice, accelerating prototyping and reducing manual effort in electronics workflows.
