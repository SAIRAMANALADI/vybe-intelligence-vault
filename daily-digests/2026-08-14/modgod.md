## Summary
ModGod is an AI-driven tool that converts plain English Minecraft mod requests into functional datapacks, validated through a series of deterministic checks and deployed dynamically to a Minecraft server. It ensures coexistence with existing mods without requiring server restarts.

## Key Features
- Converts natural language mod requests into working datapacks with user confirmation
- Validates datapacks through static linting, real server reloads, and coexistence checks
- Supports multiple AI providers (Claude, Codex, OpenAI-compatible endpoints)
- Dynamic deployment with uninstall functionality and toggle-based enabling/disabling
- External server attachment mode for integration with existing Minecraft worlds

## Why It Matters for RAG Builders
ModGod streamlines the creation and validation of Minecraft datapacks, reducing manual effort and enabling rapid iteration for AI-driven modding workflows.
