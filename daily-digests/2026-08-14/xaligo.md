## Summary
xaligo is a Diagram-as-Code engine that converts a Vue-style DSL (.xal) into multiple diagram formats, including Excalidraw, SVG, PPTX, XYFlow, and Isoflow-compatible outputs. It enables developers to define architecture and network diagrams programmatically for documentation and visualization purposes.

## Key Features
- Converts Vue-style .xal DSL to multiple diagram formats (Excalidraw, SVG, PPTX, etc.)
- Supports Vuetify-style spacing/grid layouts for structured diagrams
- Includes AWS architecture diagram group tags for cloud infrastructure
- Provides CLI for easy rendering and automation
- Offers comprehensive documentation and sample diagrams

## Why It Matters for RAG Builders
xaligo streamlines the creation and maintenance of architecture diagrams, reducing manual effort and ensuring consistency in documentation for AI and software engineering projects.
