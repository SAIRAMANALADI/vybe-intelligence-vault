## Summary
An MCP server that provides LLMs with a self-hosted, isolated Ubuntu sandbox via Docker containers, enabling code execution, live browser interaction, document creation, and autonomous sub-agents. Designed for multi-user production deployments with per-chat container isolation.

## Key Features
- Isolated Docker workspaces per chat session with full Ubuntu environment
- Live browser streaming via Playwright and CDP for real-time interaction
- 13+ built-in skills for document creation, web scraping, and automation
- Support for autonomous sub-agents (Claude Code, OpenAI Codex, OpenCode)
- Self-hosted, multi-user deployment with Kubernetes-ready architecture

## Why It Matters for RAG Builders
It enables LLMs to interact with live systems, execute code, and generate artifacts in a secure, isolated environment, bridging the gap between AI capabilities and real-world tasks.
