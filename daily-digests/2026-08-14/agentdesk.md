## Summary
AgentDesk is an open-source Windows 11 desktop client for managing and executing AI agents locally, built on the xai-org/grok-build runtime. It provides a bilingual (Simplified Chinese/English) UI, workspace management, and secure local workflows with optional cloud sync capabilities.

## Key Features
- Native Windows 11 shell with WinUI 3 and WebView2 for a modern UI experience
- Rust-based agent runtime isolated via ACP/NDJSON stdio sidecar for security
- Bilingual (Simplified Chinese/English) desktop UI with workspace selection and session management
- Explicit permission requests, native-execution risk gates, and process-tree cleanup for safety
- Optional encrypted self-hosted cloud client for session sync, team policy, and device handoff

## Why It Matters for RAG Builders
AgentDesk provides a secure, local-first framework for building and managing AI agents on Windows, enabling developers to create trusted, offline-capable workflows with explicit permission controls and optional cloud integration.
