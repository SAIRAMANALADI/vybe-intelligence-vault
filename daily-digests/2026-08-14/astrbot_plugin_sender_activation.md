## Summary
This AstrBot plugin enables AI agents to proactively monitor and respond to group chats without explicit @mentions, allowing for limited-time active engagement in discussions. It tracks user arguments, enforces rate limits, and ensures timely interventions based on context changes.

## Key Features
- Limited-time proactive AI engagement in group chats without @mentions
- Continuous tracking of specific users' arguments or discussions
- Configurable heartbeat checks for periodic context reviews
- Rate limiting for high-frequency users to prevent spam
- Integration with AstrBot's native tools and workflows

## Why It Matters for RAG Builders
This plugin enables AI agents to maintain context-aware engagement in discussions without manual triggers, reducing reliance on explicit @mentions and improving real-time responsiveness in RAG systems.
