## Summary
Antigravity Agent Core (AAC) V4.3.5 is a deterministic framework for governing autonomous AI coding agents, ensuring compliance with senior engineering standards through task-driven execution plans, file-backed state recovery, and POSIX mutex locks. It integrates natively with Google Antigravity CLI to enforce guardrails, workflow gates, and human-like collaboration.

## Key Features
- Task-driven execution plans with file-backed state recovery across sessions
- POSIX directory mutex locks for atomic workflow control and anti-TOCTOU protection
- Six consolidated domain skills (code-engineer, system-architect, quality-assurance, devops-manager, security-docs-auditor, system-janitor)
- Humanized senior co-pilot persona with uncompromising technical pushback
- Tier-aware pre-execution gates enforcing granular task validation and branch conventions
