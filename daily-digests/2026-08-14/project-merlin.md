## Summary
Ghostwheel is a local-first Windows desktop application that integrates a proprietary AI coding agent with on-device LLM inference, eliminating cloud dependency, API costs, and telemetry while providing unlimited usage on local hardware.

## Key Features
- Runs entirely locally on Windows with no cloud dependency
- Integrates proprietary Merlin Framework for agent orchestration
- Supports hardware acceleration via CUDA and Vulkan
- Includes built-in boot diagnostics for dependency verification
- Provides sandboxed tooling with command confirmations for safety
