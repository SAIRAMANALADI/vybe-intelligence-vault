## Summary
A command-line interface (CLI) and Model Context Protocol (MCP) server for managing travel plans, including flights, hotels, and activities, with real-time booking capabilities and AI agent integration.

## Key Features
- Unified travel planning CLI for flights, hotels, and activities with real-time booking
- Asynchronous search and selection workflow with polling for options
- Price-gated checkout with `--dry-run` and `--validate` for pre-flight checks
- Built-in MCP server for AI agent integration (Claude, Cursor, etc.)
- Goal-graph-based trip planning with client and traveller management

## Why It Matters for RAG Builders
It provides a robust, CLI-based interface for AI agents to interact with travel booking systems, enabling automated trip planning and real-time booking capabilities.
