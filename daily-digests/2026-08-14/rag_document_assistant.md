## Summary
An end-to-end Retrieval-Augmented Generation (RAG) application that enables users to upload PDF documents, process them into embeddings, and query them via a Streamlit interface. It leverages FAISS for vector search, SentenceTransformers for embeddings, and Groq for LLM-powered answer generation.

## Key Features
- PDF upload and in-browser Q&A with a Streamlit interface
- Local embedding generation using SentenceTransformers and FAISS for vector storage
- Context-grounded answer generation via Groq LLM
- Reusable pipeline for command-line or future API integrations
- Session state support for multi-turn chat experiences

## Why It Matters for RAG Builders
This repository provides a complete, production-ready RAG pipeline that simplifies document ingestion, embedding, and retrieval for AI engineers building context-aware applications.
