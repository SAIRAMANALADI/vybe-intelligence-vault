## Summary
An offline enterprise knowledge agent prototype designed for small to medium businesses, enabling grounded answer generation with citations from a local corpus while enforcing abstention for unsupported queries or sensitive requests. It demonstrates a controlled knowledge workflow with validation, retrieval, and human review gates.

## Key Features
- Local document retrieval with lexical matching for evidence-based answers
- Citation and source attribution for all generated responses
- Abstention mechanism for unsupported or sensitive queries
- Human review flag for low-confidence or policy-violating questions
- Zero external API dependencies, ensuring data privacy and cost efficiency

## Why It Matters for RAG Builders
It provides a practical blueprint for building privacy-preserving, citation-grounded enterprise knowledge agents without relying on external APIs or cloud services.
