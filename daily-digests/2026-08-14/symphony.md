## Summary
Symphony is a terminal-based coding agent harness built around immutable event streams, providing durable session auditing, model orchestration, and a TUI for interactive agent workflows. It uses KurrentDB for event persistence and supports multiple AI providers with secure, hash-verified event envelopes.

## Key Features
- Immutable event streams with KurrentDB for durable session auditing and replayability
- Secure, hash-verified event envelopes with JSON redaction for sensitive data
- Multi-provider support (OpenAI, Anthropic, OpenCode) with provider-neutral completion contracts
- Durable workspace interactions (reads, writes, commands) with approval bridges for safety
- Interactive TUI and CLI runner for session management and agent orchestration

## Why It Matters for RAG Builders
Symphony provides a robust, auditable foundation for AI agent workflows with immutable event streams, ensuring replayability and security critical for RAG and AI stack builders.
