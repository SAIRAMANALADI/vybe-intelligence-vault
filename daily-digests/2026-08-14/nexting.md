## Summary
Nexting is a wearable hardware device (PIN or Ring) that acts as a terminal to dispatch voice commands to your own AI agents (Claude Code, Codex, OpenClaw, or local models) without needing to use a phone or app. It bridges voice input to AI agents via Bluetooth and cloud relay, enabling hands-free task execution.

## Key Features
- Hardware-agnostic agent dispatch via wearable device (PIN or Ring)
- Supports integration with existing AI agents (Claude Code, Codex, OpenClaw, local models)
- Bluetooth and cloud relay for seamless voice-to-agent communication
- Open-source hardware and firmware for DIY builds (Co-Builder Edition)
- Deep iOS integration for calendar, reminders, contacts, and smart home control

## Why It Matters for RAG Builders
Nexting enables hands-free, real-time dispatch of AI agents via wearable hardware, bridging the gap between voice input and agent execution for seamless, context-aware task automation.
