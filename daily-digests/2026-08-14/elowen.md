## Summary
Elowen is a self-hosted, multi-surface AI agent framework that enables persistent, multi-modal interactions across terminal, web, Discord, and WhatsApp. It supports goal-driven tasks, sub-agent delegation, workflow automation, and durable memory, all while maintaining strict data privacy and user control.

## Key Features
- Cross-surface agent interaction (terminal, web, Discord, WhatsApp) with unified state and memory
- Goal-driven task execution with sub-agent delegation and mission-based workflows
- Durable memory and context preservation across sessions and surfaces
- Granular permissions and tool-based autonomy with real-time approval gates
- Self-hosted architecture with SQLite, Node.js daemon, and optional reverse proxy

## Why It Matters for RAG Builders
Elowen provides a robust, self-hosted framework for building persistent, multi-agent AI systems with fine-grained control over permissions, memory, and workflows, making it essential for developers who need trustworthy, scalable AI automation.
