## Summary
A Model Context Protocol (MCP) server that enables searching and retrieving scholarly literature across multiple open and paywalled sources, including arXiv, OpenAlex, Crossref, PubMed, and Semantic Scholar. It provides unified access to paper metadata, references, and citations, even for paywalled journals, via public metadata.

## Key Features
- Unified search across 5 major scholarly sources with a single API
- Retrieves references and citations from paywalled journals using public metadata
- Liveness verification and retraction flagging for papers
- Anonymous opt-out telemetry with strict privacy controls
- Supports DOI, arXiv ID, PMID, OpenAlex ID, and Semantic Scholar ID resolution

## Why It Matters for RAG Builders
It provides essential access to scholarly literature and citation data for RAG pipelines, even when full-text access is restricted, enabling richer and more accurate AI-generated responses.
