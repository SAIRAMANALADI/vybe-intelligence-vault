## Summary
Coddy Agent is a distroless-friendly, general-purpose AI agent framework that runs as a single static Go binary. It supports ReAct loops, filesystem and shell tools, MCP integration, skills, OpenAI-compatible APIs, embedded web UI, Telegram gateway, cron scheduler, long-term memory, and context compaction.

## Key Features
- Single static Go binary with no external dependencies (distroless-ready)
- ReAct loop for autonomous agent behavior with tool execution and reasoning
- Multi-modal support including file attachments and images
- ACP server for IDE and editor integration (Obsidian, VS Code, Zed)
- Long-term memory, context compaction, and persistent sessions

## Why It Matters for RAG Builders
Coddy Agent provides a lightweight, embeddable framework for building autonomous AI agents with multi-modal capabilities and seamless IDE integration, making it ideal for RAG builders seeking modular, production-ready agent architectures.
