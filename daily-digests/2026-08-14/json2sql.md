## Summary
A command-line tool that converts JSON data into SQL INSERT statements, supporting nested structures, multiple SQL dialects (PostgreSQL, MySQL, SQLite), and type inference. It simplifies database seeding, data migrations, and CI/CD pipeline integrations.

## Key Features
- Converts JSON arrays and nested objects into SQL INSERT statements
- Supports PostgreSQL, MySQL, and SQLite dialects
- Automatically flattens nested JSON structures into relational tables
- Zero dependencies beyond Python 3.10+ and Typer for CLI
- Supports stdin/stdout for pipeline integration

## Why It Matters for RAG Builders
It streamlines the conversion of JSON data into structured SQL for database operations, reducing manual effort in migrations, testing, and analytics workflows.
