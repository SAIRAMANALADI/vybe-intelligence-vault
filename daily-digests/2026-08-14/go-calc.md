## Summary
A cross-platform Windows 11-style calculator built with Go and Wails, designed as both a functional calculator and a template for agent-operable desktop applications. It includes a secured REST control plane enabling AI agents to interact with the UI and backend programmatically.

## Key Features
- Windows 11-style calculator with light/dark themes, supporting exact arithmetic via Go's math/big library
- Agent-operable architecture with a secured REST API for UI interaction and direct computation
- Cross-platform support (Windows, Linux, macOS) with prebuilt binaries and detailed installation instructions
- Accessibility tree and structured error responses for reliable AI agent integration
- Reusable template for building other agent-operable desktop apps with Go backend and TypeScript/Vue frontend

## Why It Matters for RAG Builders
It provides a reusable template for building agent-operable desktop applications with a Go backend and TypeScript/Vue frontend, enabling AI agents to interact with the UI and backend programmatically through a secured REST API.
