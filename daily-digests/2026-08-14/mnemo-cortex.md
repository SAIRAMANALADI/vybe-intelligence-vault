## Summary
Mnemo Cortex is an open-source, local-first cognitive coprocessor that provides persistent, active memory for AI agents. It enables cross-agent memory sharing, semantic search, overnight dreaming, and structured fact storage without cloud dependencies.

## Key Features
- Active memory with auto-capture, classification, and consolidation
- Semantic search and deep recall across sessions
- Overnight dreaming for cross-agent knowledge synthesis
- Structured facts with confidence tracking and tiered storage
- USB courier (Cortex Stick) for offline memory sync
