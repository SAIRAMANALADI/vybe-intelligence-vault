## Summary
Octarq is an open-source, self-hosted platform that consolidates domain infrastructure, URL shortening, disposable email routing, DNS management, and AI integration into a single Go binary with an embedded React dashboard. It supports dynamic routing, multi-tenant workspaces, and a built-in MCP server for AI agent interactions.

## Key Features
- Single Go binary with embedded React dashboard and zero dependencies
- Dynamic routing for short links based on geo, device, OS, and language
- Built-in MCP server for AI agent interactions and read-only SQL queries
- Multi-tenant workspaces with RBAC and plugin-first modular architecture
- Email routing via Cloudflare Workers with AI-powered mail summarization

## Why It Matters for RAG Builders
Octarq provides a unified, self-hosted infrastructure for AI stack builders to manage links, emails, and DNS while enabling AI agents to interact with the system via MCP for enhanced automation and data retrieval.
