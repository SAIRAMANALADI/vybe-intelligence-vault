## Summary
A Model Context Protocol (MCP) server that unifies access to US federal regulatory data across the Federal Register, eCFR (codified regulations), and Regulations.gov. It provides tools to search, trace, and retrieve regulatory documents, comments, and codified text through a standardized interface.

## Key Features
- Unified search across Federal Register, eCFR, and Regulations.gov via MCP tools
- Cross-source document tracing (proposal → comments → final → codified text)
- Keyless access for Federal Register and eCFR tools; optional API key for Regulations.gov
- Local mirroring of eCFR for point-in-time CFR text retrieval
- Structured error handling and pluggable authentication/storage backends

## Why It Matters for RAG Builders
It provides a standardized, unified interface to critical US regulatory data sources, enabling AI agents to seamlessly search, trace, and retrieve regulatory documents and comments for RAG applications.
