## Summary
A WordPress plugin that provides structured MCP (Model Context Protocol) tools for WooCommerce stores, enabling AI agents to safely manage products, media, orders, and SEO without direct PHP execution.

## Key Features
- Provides structured, validated MCP tools for WooCommerce management (products, media, orders, SEO)
- Implements strict input validation via JSON Schema for secure AI agent interactions
- Read-only operations by default with opt-in destructive actions (e.g., dry-run mode for media cleanup)
- Modular architecture with dedicated modules for variable products, media, orders, and SEO
- Permission-gated tools requiring WooCommerce management capabilities

## Why It Matters for RAG Builders
It enables AI agents to safely and efficiently manage WooCommerce stores without direct PHP execution, reducing risk and improving reliability for RAG systems.
