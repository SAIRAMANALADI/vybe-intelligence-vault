## Summary
An autonomous AI agent that discovers trending YouTube Shorts, analyzes them using Google Gemini, and generates original AI-powered cartoon images and short videos with Ken Burns zoom effects. The entire process is automated with no manual editing required.

## Key Features
- Autonomous discovery of trending YouTube Shorts via YouTube Data API v3
- Scene-by-scene analysis using Google Gemini for prompt generation
- AI-generated cartoon images via Pollinations AI (Flux model)
- Ken Burns zoom effect video generation using MoviePy
- Modular architecture supporting easy upgrades to paid APIs

## Why It Matters for RAG Builders
It automates end-to-end content creation by transforming trending videos into original AI-generated visuals, reducing manual effort for AI stack builders.
