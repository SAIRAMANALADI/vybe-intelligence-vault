## Summary
AdCopilot is a hosted Model Context Protocol (MCP) server that enables AI agents to interact with Google Ads via natural language, providing 32 read/write tools for campaign management, asset creation, and performance optimization without requiring local setup or developer tokens.

## Key Features
- 32 hosted tools for Google Ads operations (read/write)
- No local setup required—sign in with Google account and use existing MCP clients
- Structural safety: no delete operations exposed, reversible actions only
- Audit trail for every call, including refusals and outcomes
- Supports team collaboration with per-member access control and org-level scoping
