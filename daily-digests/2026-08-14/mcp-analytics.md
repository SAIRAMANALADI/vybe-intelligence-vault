## Summary
MCP Analytics Suite enables AI-powered statistical analysis by allowing users to upload data or connect live sources and commission custom analyses via a team of specialist agents. It generates citable, interactive reports with embedded R source code, supports reruns on fresh data, and integrates seamlessly with MCP clients like Claude and Cursor.

## Key Features
- Natural language interface for commissioning analyses (e.g., regression, forecasting, segmentation)
- Four-tiered analysis depth (Snapshot, JSON, Brief, Deck) with validated statistical methods
- Citable, reproducible reports with embedded R source code and Docker isolation
- Seamless integration with MCP clients (Claude, Cursor, Windsurf) for querying and rerunning analyses
- Secure data handling with OAuth2, encryption, and isolated container processing

## Why It Matters for RAG Builders
MCP Analytics automates the creation of statistically rigorous, citable reports from user data, enabling RAG systems to dynamically generate and validate insights with embedded source code and reproducibility guarantees.
