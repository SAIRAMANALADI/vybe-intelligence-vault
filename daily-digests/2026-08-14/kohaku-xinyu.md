## Summary
XinYu is a local, privacy-bound AI runtime workspace designed for long-running personal agents with durable memory, proactive behavior control, and native QQ/NapCat gateway integration. It provides a reusable reference implementation for inspectable, bounded AI companions operating entirely on a user's machine.

## Key Features
- Local long-running AI agent runtime with Python core
- Native QQ/NapCat gateway for real-time messaging loops
- Durable memory and learning boundaries with privacy safeguards
- Electron/Vite desktop shell for operator control and inspection
