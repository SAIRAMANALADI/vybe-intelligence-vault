## Summary
LeanToken is a local-first tool that optimizes AI coding agents by narrowing repository exploration to relevant files and code ranges, reducing token usage by up to 37.6% compared to traditional methods. It provides a CLI and MCP server for searching code, inspecting structure, reading exact ranges, and exploring Git history.

## Key Features
- Local-first code indexing with explicit token budgets to prevent oversized prompts
- MCP server integration for seamless AI agent workflows
- Precise code search, outline, and read operations with bounded token usage
- Git history exploration and diff tracking for version-aware retrieval
- Receipt-based evidence tracking to avoid redundant token consumption

## Why It Matters for RAG Builders
LeanToken directly reduces AI agent token costs and improves retrieval precision, making it essential for scalable and cost-efficient RAG systems.
