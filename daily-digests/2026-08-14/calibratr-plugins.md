## Summary
A marketplace of Claude Code plugins for recruiting and go-to-market (GTM) tooling, enabling evidence-based candidate sourcing, role-DNA scoring, and verdict calibration. Plugins integrate with public APIs (GitHub, arXiv, Hugging Face, etc.) to verify candidate profiles and provide configurable scoring metrics.

## Key Features
- Evidence-first candidate sourcing with verbatim profile URLs and proof-of-work verification across multiple platforms (GitHub, arXiv, Hugging Face, etc.)
- Configurable project-level settings via `.calibratr/config.json` for customization without code changes
- Role-DNA scoring and verdict calibration for objective candidate evaluation
- Local execution of MCP servers with opt-in public API usage, ensuring privacy and cost control
- Portable skills and MCP connectors for use in claude.ai, Cowork, or any MCP client

## Why It Matters for RAG Builders
It provides a modular, privacy-preserving toolkit for automating and standardizing candidate sourcing and evaluation, critical for building high-quality RAG datasets and AI-driven hiring workflows.
