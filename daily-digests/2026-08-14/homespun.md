## Summary
Homespun enables AI agents to autonomously build and host web applications from a single HTML file and manifest, providing a seamless deployment experience for end-users without requiring installation or build steps.

## Key Features
- AI agents can generate and deploy web apps from a single HTML file
- Automated hosting with no manual build or deploy steps required
- CLI and MCP server for agent integration and control
- Browser SDK for runtime interaction with deployed apps
- Comprehensive documentation and reference guides for all components
