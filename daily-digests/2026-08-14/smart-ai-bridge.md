## Summary
Smart AI Bridge is an MCP server that enables multi-AI orchestration for Claude Code, allowing users to route tasks to any OpenAI-compatible provider, collaborate via a council system, and optimize token usage through intelligent backend selection and file operations.

## Key Features
- Config-driven multi-AI backend management with OpenAI-compatible support
- Smart routing system with 4-tier priority (forced, learned, rules, fallback) and circuit breakers
- Council system for multi-AI consensus with configurable strategies (parallel, sequential, debate, fallback)
- Token-saving file operations with automatic verification and backup/restore capabilities
- Web dashboard for backend and council configuration with real-time health checks
