## Summary
AgentGuard is a zero-dependency Python library designed to prevent runaway AI agents by enforcing hard budget caps, detecting loops, and providing local traces. It integrates seamlessly with popular AI frameworks and APIs to stop costly or infinite agent runs mid-flight.

## Key Features
- Hard budget enforcement with exceptions for spend limits (e.g., BudgetExceeded)
- Loop detection for repetitive or stuck agent behavior (e.g., LoopDetected)
- Local traces (JSONL) for offline debugging and incident analysis
- Zero dependencies with Python 3.9+ compatibility
- Framework-agnostic with integrations for OpenAI, Anthropic, LangChain, LangGraph, and CrewAI

## Why It Matters for RAG Builders
AgentGuard is essential for AI engineers to prevent catastrophic agent runaway costs and infinite loops by enforcing real-time, in-process guardrails without external dependencies.
