## Summary
A Model Context Protocol (MCP) server for deep cryptocurrency research, enabling local and free token analysis with multi-source data aggregation from CoinGecko, DeFiLlama, and web searches. It automates structured reporting, resource management, and status tracking for comprehensive token evaluations.

## Key Features
- Multi-source cryptocurrency data aggregation (CoinGecko, DeFiLlama, web/news searches)
- Structured research plans with status tracking for token analysis
- Automated resource management for storing and referencing search results
- Direct API access to CoinGecko and DeFiLlama without HTML scraping (where possible)
- Integration with Claude Desktop and Cursor via MCP for seamless AI workflows
