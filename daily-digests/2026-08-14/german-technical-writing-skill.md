## Summary
A specialized Agent Skill that enforces canonical German technical writing standards by detecting and correcting English-to-German anglicisms in Jira comments, internal wiki pages, and team chat messages for German-speaking teams. It ensures consistency with a curated lexicon and register rules for technical artifacts.

## Key Features
- Automated detection and correction of ~60 English-to-German anglicisms (e.g., 'brechen' → 'werfen', 'failen' → 'fehlschlagen')
- Enforces canonical technical German lexicon with gender annotations for domains like Git, CI/CD, HTTP, and Architecture
- Artifact-specific register enforcement (Jira tickets, comments, internal wiki pages) with Präsens-Indikativ default and impersonal voice
- Portable across Agent Skills-compatible platforms (Claude Code, Cursor, GitHub Copilot)
- Includes worked examples, anti-pattern catalog, and lexicon references for contributors

## Why It Matters for RAG Builders
It ensures high-quality, culturally appropriate German technical documentation for AI agents interacting with German-speaking teams, reducing errors and improving clarity in collaborative workflows.
