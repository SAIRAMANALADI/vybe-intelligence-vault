## Summary
Entrabot is a Python MCP server that enables AI agents to operate as first-class principals in Microsoft Entra ID, granting them autonomous identities with Teams, Outlook, and Microsoft 365 integration. It automates provisioning, authentication, and licensing for agents, ensuring secure and attributed interactions.

## Key Features
- Provisions autonomous agent identities in Microsoft Entra ID with certificate-backed authentication
- Enables secure Teams, Outlook, and Microsoft 365 file interactions with audit trails
- Supports conditional access, ID protection, and DLP policies for agents
- Provides inbound message push for Claude Code and polling fallback for other MCP clients
- Includes body-first prompt architecture with optional persona layers for security enforcement

## Why It Matters for RAG Builders
Entrabot enables AI agents to operate as secure, auditable principals in Microsoft 365, eliminating human-in-the-loop authentication and ensuring attribution for all actions.
