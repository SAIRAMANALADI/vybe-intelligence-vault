## Summary
Spantail is an open-source work observability platform designed for human-AI collaboration, enabling low-overhead logging of human and AI agent work, unified reporting, and seamless sharing of insights across teams.

## Key Features
- Unified timeline for human and AI agent work with minimal overhead
- Automatic capture of AI coding agent sessions via MCP and CLI
- GitHub integration for logging work directly from issues/PRs
- Customizable Markdown + Liquid report templates for flexible insights
- Keyboard-first web UI and CLI for efficient workflows

## Why It Matters for RAG Builders
Spantail provides a critical layer for tracking and analyzing human-AI collaboration workflows, enabling better observability and reporting for AI engineering teams.
