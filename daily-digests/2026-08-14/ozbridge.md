## Summary
OzBridge is an open-source Model Context Protocol (MCP) server and VS Code extension that enables interoperability with Warp Oz cloud and local agents across multiple IDEs and AI tools, including GitHub Copilot Chat, Claude Code, Cursor, and Codex CLI.

## Key Features
- Exposes Warp Oz tools via MCP for cross-IDE and cross-AI tool compatibility
- VS Code extension with native `@oz` chat participant and agent-native language model tools
- Supports local and cloud Warp Oz agent execution with real-time progress updates
- Configurable workspace settings and context injection for enhanced agent prompts
- Standalone MCP server for non-VS Code environments

## Why It Matters for RAG Builders
OzBridge bridges Warp Oz agents with any MCP-compatible client, enabling seamless AI-driven development workflows across multiple IDEs and tools.
