## Summary
A local, encrypted personal memory engine for AI coding assistants that provides persistent, verbatim recall via vector search and knowledge graph integration. It captures and organizes conversation history automatically, enabling AI assistants to retain context across sessions without cloud dependency.

## Key Features
- Fully local and encrypted memory storage with no telemetry or cloud dependency
- Automatic verbatim capture of every conversation turn with timestamps
- Vector search + knowledge graph for efficient recall and context injection
- Idle-time consolidation to deduplicate, strengthen recall pathways, and prune weak edges
- Cross-platform support (macOS, Linux, Windows beta) with MCP client compatibility

## Why It Matters for RAG Builders
It provides persistent, context-aware memory for AI assistants without relying on external services, enabling true long-term learning and recall for RAG systems.
