## Summary
BJ-Pal is a Beijing short-term activity planning agent that converts natural language requests into structured, time-bound plans with routes, risks, and alternatives. It emphasizes reproducibility, explainability, and recoverability through durable job stores, strict schema validation, and privacy-minimized failure signatures.

## Key Features
- Converts natural language to structured activity plans with time, routes, and alternatives
- Supports durable job persistence with SQLite or PostgreSQL for recoverability
- Implements strict schema validation and constraint-led planning for consistency
- Provides privacy-minimized failure signatures and workload health metrics
- Offers bounded public demo with synthetic data and controlled API surface

## Why It Matters for RAG Builders
BJ-Pal demonstrates a robust, reproducible agent framework for converting unstructured requests into structured, explainable plans with built-in recoverability and privacy controls, critical for RAG/AI stacks requiring reliability and auditability.
