## Summary
Flowproof is a deterministic testing and guardrail framework for AI agents and automation workflows. It records agent interactions once and replays them deterministically in CI with zero LLM calls, ensuring agents only perform intended actions and never cross forbidden boundaries.

## Key Features
- Records agent interactions once and replays them deterministically in CI with zero LLM calls
- Supports containment claims (e.g., network egress restrictions) and behavior claims (e.g., tool call assertions)
- Cross-platform automation for web, desktop, SAP, Citrix, and APIs
- Structured YAML specs for human-readable and agent-writable automation
- Built-in security controls and regression testing for AI agents

## Why It Matters for RAG Builders
Flowproof ensures AI agents and automation workflows behave as intended by providing deterministic, zero-cost regression testing and guardrails, critical for production-grade reliability and security.
