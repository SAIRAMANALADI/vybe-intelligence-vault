## Summary
Laintas CLI is a Linux-native autonomous AI agent that integrates directly into the terminal, enabling natural-language task execution with real PTY-backed command handling. It bridges the gap between traditional shell workflows and AI-driven automation for developers and server operators.

## Key Features
- Real PTY-backed command execution for interactive tools and long-running processes
- Natural-language task planning and iterative feedback loop with structured responses
- Named sub-terminals for persistent workspace sessions and multi-tasking
- Project memory and context management via local storage (`.cli.prop`, `.helpwo`)
- Extensible with custom slash commands, skills, and declarative agent roles

## Why It Matters for RAG Builders
It enables seamless integration of AI-driven automation into Linux terminal workflows, reducing context switching for developers and server operators while preserving native shell behavior.
