## Summary
A self-deploying cross-tool AI harness that synchronizes a canonical agent configuration across multiple AI coding assistants (Claude Code, Codex, Cursor, Devin, Antigravity, etc.) from a single source of truth. It automates detection, generation, deployment, and verification of agent rules, memory protocols, and orchestrator frameworks.

## Key Features
- Self-deploying harness via a single command or manual script execution
- Cross-platform support (Windows, macOS, Linux) with platform-specific adapters
- Five-pillar agent harness architecture (caveman token compression, commander-worker hierarchy, loop engineering, deep memory, sandbox boundaries)
- Anti-link-rot embedded vault for local caching of all configurations and schemas
- Automated detection, verification, and backup of existing configurations

## Why It Matters for RAG Builders
It eliminates configuration drift and maintenance overhead for AI coding assistants by ensuring a single, canonical agent harness is deployed across all supported tools, enabling consistent behavior and reducing setup complexity for RAG and AI stack builders.
