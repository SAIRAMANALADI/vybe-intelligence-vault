## Summary
An MCP server providing a comprehensive Christian scholarship corpus with scripture, patristic texts, original-language data, and semantic search capabilities. It integrates public domain and CC-licensed sources into a single SQLite database with FTS5 search and embeddings for hybrid retrieval.

## Key Features
- Hybrid search combining keyword (BM25) and semantic (embeddings) retrieval across scripture, patristic texts, and classics
- Original-language word studies with Strong's numbers, lemmas, and morphology for Greek/Hebrew/Aramaic
- Cross-reference and citation graph extraction from patristic sources
- Versemap for aligning different Bible versifications (e.g., MT/NA to English)
- Pre-built SQLite database (~230MB) with FTS5 full-text search and embeddings for verse/window/paragraph

## Why It Matters for RAG Builders
Provides a rich, structured corpus of biblical and patristic texts with semantic search and original-language tools, enabling deeper RAG applications in theological and historical research.
