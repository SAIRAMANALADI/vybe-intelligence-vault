## Summary
Mino is a lightweight, self-hosted AI agent framework written in Go, designed to run as a single binary with SQLite for state management. It provides a dashboard, CLI, and extensible tooling for building personal AI assistants with minimal setup.

## Key Features
- Single-binary deployment with SQLite for state management
- Dashboard and CLI for interaction
- Extensible tooling via HTTP extensions and MCP servers
- Built-in tools for file operations, calendar, notes, and web search
- Skill system for saving repeatable workflows as markdown files

## Why It Matters for RAG Builders
Mino simplifies the deployment of personal AI agents with minimal infrastructure, making it ideal for RAG builders seeking a lightweight, self-contained solution.
