## Summary
A VS Code extension that enables users to build interactive, node-based knowledge graphs from research papers and documents. It provides a rich visual editor with KaTeX support, Markdown tables, and HTML export functionality, optimized for AI agent integration and collaborative research workflows.

## Key Features
- Interactive node-based graph editor with rich content support (KaTeX, Markdown tables, images)
- Smart wire routing and overlap-free layout with adaptive spacing
- HTML export for sharing and viewing graphs outside VS Code
- AI agent integration with machine-readable JSON schema and environment documentation
- Advanced search, folding, and generation highlighting for focused analysis

## Why It Matters for RAG Builders
It provides a structured, visual way to organize and analyze research content, making it easier for AI systems to parse and interact with complex document relationships.
