## Summary
MCPC is an SDK for building agentic Model Context Protocol (MCP) servers by composing and customizing existing MCP tools. It enables the creation of portable, interoperable agent systems that can run across MCP clients and collaborate seamlessly.

## Key Features
- Compose and customize MCP tools to build agentic servers with simple text descriptions
- Support for multiple execution modes (agentic, ai_sampling, ai_acp, code_execution, code_execution_sampling)
- Built-in logging, tracing, and OpenTelemetry integration for observability
- Agent Skills support for domain-specific knowledge and on-demand loading
- Portable and interoperable agent systems that work across MCP clients

## Why It Matters for RAG Builders
MCPC simplifies the creation of agentic MCP servers, enabling seamless integration and collaboration of AI agents across tools and platforms, which is critical for building scalable and interoperable RAG systems.
