## Summary
Protodex is a comprehensive index of 18,146+ Model Context Protocol (MCP) servers, enabling users to discover, search, and categorize MCP-compatible tools for AI agents and applications like Claude and Cursor. It provides a browsable directory with metadata, tools, and rankings to help users find battle-tested solutions.

## Key Features
- Indexes 18,146+ MCP servers with weekly updates via automated GitHub scraping
- Searchable directory with 13 categories and 68+ languages
- Individual server pages with metadata, tools, and related servers
- Ranked by GitHub stars for reliability and adoption
- Static site generation for fast, offline-friendly browsing
