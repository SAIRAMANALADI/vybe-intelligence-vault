## Summary
Moldavite is a privacy-first, local-first notes app for macOS that stores notes as plain Markdown files in user-owned directories. It includes an integrated MCP server for AI tool integration, enabling secure, offline access to notes for agents like Claude while keeping all data on the user's machine.

## Key Features
- Stores notes as plain Markdown files in user-owned directories with no account or sync service required
- Integrated MCP server for secure, offline AI tool access (read tools enabled by default, write tools opt-in)
- Supports semantic search with offline embedding models (Apple Silicon only) and full-text keyword search
- Features atomic writes, conflict resolution, note locking with AES-256-GCM encryption, and plugin system with sandboxed execution
- Includes calendar integration (Apple and Google) and wiki-style linking with backlink tracking

## Why It Matters for RAG Builders
Moldavite provides a secure, local-first foundation for RAG systems by enabling AI agents to read and interact with user notes via MCP while ensuring data privacy and offline operation.
