## Summary
A desktop GUI control plane for Grok Build that interfaces with a local Grok agent via the Agent Client Protocol (ACP), providing a user-friendly interface for agent interaction, session management, and local system capabilities without reimplementing the agent itself.

## Key Features
- Streaming transcript with tool cards and per-turn navigation for agent interactions
- Built-in browser pane controlled by the agent via MCP tools (e.g., navigation, screenshots)
- Local system capabilities including terminal, file tree, screen capture, and voice input
- Git worktree isolation for safe agent-driven edits without affecting working copies
- Permission modal for ACP request_permission reverse-requests with configurable modes

## Why It Matters for RAG Builders
It provides a user-friendly desktop interface for interacting with local AI agents, enabling seamless integration of agent capabilities with local system tools and workflows for RAG builders.
