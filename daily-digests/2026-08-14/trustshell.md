## Summary
TrustShell is an open-source toolkit for conducting independent, exploit-validated security reviews of AI agents. It combines static analysis, dynamic red-teaming, and a suite of red-team skills to identify and confirm vulnerabilities such as prompt injection, memory poisoning, and tool abuse in AI systems.

## Key Features
- Autonomous attacker agent for dynamic red-teaming of AI agents with proof-of-exploit markers
- Static analysis engine for candidate vulnerability path identification via AST and compiler APIs
- Nine red-team attack classes (RT-1 to RT-9) as portable skills for AI agents
- MCP server integration enabling toolkit access as native tools for MCP-compatible agents
- Emphasis on empirical validation of vulnerabilities through actual exploits, not just static scans

## Why It Matters for RAG Builders
TrustShell provides a critical layer of empirical security validation for AI agents, ensuring that vulnerabilities like prompt injection and memory poisoning are not just flagged but confirmed through real-world exploits, which is essential for building trustworthy and secure AI systems.
