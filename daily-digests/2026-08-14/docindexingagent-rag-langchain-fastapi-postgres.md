## Summary
A FastAPI-based RAG system integrating Langchain for document indexing and retrieval with PostgreSQL/pgvector or Atlas MongoDB as vector stores. It supports ID-based document management, async operations, and multiple embedding providers for scalable document processing.

## Key Features
- ID-based document management for targeted retrieval
- Supports multiple vector databases (pgvector, Atlas MongoDB)
- Asynchronous API for scalable performance
- Flexible embedding provider integration (OpenAI, Azure, Hugging Face, etc.)
- JWT authentication and environment variable configuration

## Why It Matters for RAG Builders
This repository provides a scalable, modular RAG pipeline with flexible vector store and embedding provider options, essential for building production-grade document retrieval systems.
