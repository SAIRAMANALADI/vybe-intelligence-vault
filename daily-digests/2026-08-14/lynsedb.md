## Summary
LynseDB is a Python-first vector database with a Rust storage and search engine, designed for AI applications requiring scalable retrieval from local prototypes to sharded clusters. It supports dense vectors, metadata filtering, BM25, hybrid search, and domain-aware similarity metrics beyond embeddings.

## Key Features
- Multi-deployment modes: embedded, HTTP service, and sharded cluster with a single Python client API
- Domain-aware similarity metrics for geospatial, binary fingerprints, numeric profiles, and distributions
- Hybrid search combining dense vectors, BM25, and sparse vectors with external reranking support
- Automatic index building (FLAT-IP by default) with support for HNSW, IVF, SPANN, and DiskANN
- Built-in API keys, health checks, metrics, OpenAPI, and production-ready deployment examples

## Why It Matters for RAG Builders
LynseDB provides a seamless transition path from local prototyping to scalable production deployments while supporting advanced retrieval features critical for RAG and AI applications.
