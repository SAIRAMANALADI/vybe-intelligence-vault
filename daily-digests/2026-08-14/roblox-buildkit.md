## Summary
A Roblox Studio plugin and MCP server that enables AI agents to interact with Roblox environments by providing steerable cameras, parametric build primitives, and scene capture tools. It bridges AI agents with Roblox Studio for real-time building, editing, and inspection.

## Key Features
- Steerable camera and viewport capture tools (e.g., `rbx_frame`, `rbx_capture`, `rbx_floor_plan`) for precise scene visualization
- Parametric build primitives (e.g., `rbx_build`, `rbx_room`, `rbx_stairs`) for AI-driven construction
- Scene inspection and editing tools (e.g., `rbx_describe`, `rbx_edit`, `rbx_inspect`) for real-time feedback
- MCP server integration enabling AI agents to control Roblox Studio via standardized protocols
- Optional local mesh generation pipeline for converting AI-generated models into Roblox-compatible assets

## Why It Matters for RAG Builders
It bridges AI agents with Roblox Studio, enabling precise, real-time interaction for building, editing, and capturing scenes, which is critical for automating Roblox content creation workflows.
