## Summary
Phalanx is an autonomous multi-persona QA and security testing agent that dynamically spawns synthetic users to audit applications for functional, security, and UX defects. It combines parallel browser automation, code-aware zero-config analysis, and cost-tiered model orchestration to deliver reproducible bug reports with executable reproduction scripts.

## Key Features
- Dynamic multi-persona parallel testing with 2 to N synthetic users for concurrent interaction and state fuzzing
- Code-aware zero-config analysis using Tree-sitter and embeddings to auto-map API surfaces, roles, and auth models
- Bring-Your-Own-Model (BYOM) cost-tiered orchestration supporting cloud, free-tier, and fully local LLMs
- Unified functional, security, and UX defect detection with CVSS-ranked reports and executable Playwright reproduction scripts
- On-prem/air-gapped deployment capability for compliance-sensitive environments

## Why It Matters for RAG Builders
Phalanx uniquely bridges the gap between AI-driven QA and security testing by enabling autonomous, multi-persona audits with on-prem deployment, reducing pre-ship defects and improving RAG/AI stack reliability.
