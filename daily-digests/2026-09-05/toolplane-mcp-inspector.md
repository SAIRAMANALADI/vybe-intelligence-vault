## Summary
Toolplane MCP Inspector is a developer workstation for inspecting, testing, and debugging Model Context Protocol (MCP) servers. It provides real-time JSON-RPC 2.0 traffic monitoring, OAuth handshake debugging, tool execution analysis, and distributed request tracing in a unified dashboard.

## Key Features
- Real-time JSON-RPC 2.0 traffic capture and inspection with searchable logs
- OAuth handshake debugging with pause/resume/terminate controls
- Tool playground for executing MCP tools with schema validation and response inspection
- Distributed request tracing with span visualization across nodes
- Live SDK connections with CORS proxy support for MCP servers

## Why It Matters for RAG Builders
It provides essential debugging and inspection capabilities for MCP servers, enabling AI engineers to diagnose and optimize tool interactions in RAG pipelines.
