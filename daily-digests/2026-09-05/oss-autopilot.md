## Summary
OSS Autopilot is an AI-powered workflow engine designed to streamline open-source contributions by monitoring PRs, drafting responses, diagnosing CI failures, and discovering new issues. It operates as a Claude Code plugin, MCP server, and standalone CLI with a modular architecture.

## Key Features
- Multi-interface deployment (Claude Code plugin, MCP server, CLI) with shared core logic
- Deterministic core with 3,000+ tests for PR status classification, CI failure analysis, and state management
- Interactive Preact dashboard for real-time PR management and contribution analytics
- Production-grade GitHub API integration with rate limit handling, caching, and fork-based workflow support
- Human-in-the-loop guardrails ensuring no automated actions without explicit approval

## Why It Matters for RAG Builders
OSS Autopilot provides a robust, AI-driven orchestration layer for managing open-source contributions at scale, reducing manual effort and improving contributor efficiency through automation and structured workflows.
