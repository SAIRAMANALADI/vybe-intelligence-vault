## Summary
Tiangang is an AI agent-first SAST (Static Application Security Testing) skill designed to automate security audits for multi-language projects. It orchestrates language-specific scanners (e.g., Bandit for Python, Gosec for Go) alongside universal tools like Semgrep and Trivy, then generates unified Markdown reports from heterogeneous outputs.

## Key Features
- 10+ language-specific scanners (e.g., Bandit, Gosec, Brakeman) for targeted security analysis
- Universal SCA and secret scanning via Trivy, Gitleaks, and Trufflehog
- Four-step automated pipeline: detect languages → install tools → run scans → generate unified reports
- Explicit handling of tool failures and coverage gaps in reports to avoid false positives
- Agent-first design with YAML frontmatter and Markdown workflows for seamless AI agent integration

## Why It Matters for RAG Builders
Tiangang automates and standardizes security audits for AI agents, reducing manual review overhead and ensuring consistent, multi-language vulnerability detection in RAG pipelines.
