## Summary
StashBase transforms local files into searchable context for AI agents by extracting, indexing, and exposing their contents via an MCP server. It supports semantic and keyword search across documents, images, audio, and video, enabling agents to interact with local knowledge bases seamlessly.

## Key Features
- Converts local files (PDFs, DOCX, images, audio, video) into searchable text via OCR, transcription, and extraction
- Provides semantic and keyword search over indexed content with optional local or API-based embeddings
- Exposes a local MCP server for seamless integration with AI agents like Claude and Codex
- Supports bounded file operations (read/write/edit) for sandboxed agent environments
- Includes a built-in agent panel for running and reviewing agent sessions directly within the app

## Why It Matters for RAG Builders
StashBase bridges the gap between local knowledge and AI agents by making unstructured local files searchable and accessible, enabling more accurate and context-aware RAG workflows without requiring cloud uploads.
