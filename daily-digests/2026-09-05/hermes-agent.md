## Summary
Hermes Agent is a self-improving AI agent framework designed for autonomous learning, skill creation, and multi-platform interaction. It supports natural language interfaces, scheduled automations, and cross-session memory with built-in learning loops.

## Key Features
- Built-in learning loop with autonomous skill creation and self-improvement during use
- Multi-platform support (Telegram, Discord, Slack, CLI, etc.) with cross-session memory
- Scheduled automations and parallel subagent delegation for complex workflows
- Research-ready batch trajectory generation and compression for model training
- Low-cost deployment options (serverless, $5 VPS, or GPU clusters) with hibernation support
