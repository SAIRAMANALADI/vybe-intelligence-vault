## Summary
CC Redline is an interactive, in-browser Markdown review tool designed as a Claude Code skill. It enables real-time annotation, editing, and collaboration on Markdown files through a zero-dependency web server with bilingual (English/Chinese) support.

## Key Features
- Interactive Markdown review loop with Raw and Render modes
- Byte-exact text anchoring for precise annotations (blocks, sections, selections, or exact lines)
- Agent-driven workflow with structured JSON submissions and auto-refresh
- Zero runtime dependencies (Node.js ≥ 18 only; front-end libraries vendored)
- Bilingual UI (English/Chinese) switchable at runtime

## Why It Matters for RAG Builders
It streamlines real-time Markdown review and editing workflows for AI agents, enabling precise, text-anchored annotations and seamless integration with Claude Code.
