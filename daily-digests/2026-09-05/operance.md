## Summary
Operance is a debugging simulation platform that immerses users in a realistic cloud engineering environment with a broken CI pipeline, live backend services, and an AI debug coach. It evaluates user performance in debugging scenarios, scoring efficiency, decision-making, and time management for potential hiring or certification purposes.

## Key Features
- Realistic cloud engineering environment with a broken CI pipeline for debugging practice
- AI debug coach powered by Amazon Nova (Bedrock) that provides contextual guidance without giving direct answers
- Automated grading system that evaluates user performance based on time, efficiency, and decision-making
- Screen capture loop to feed real-time context into the AI coach for dynamic feedback
- Scenario-based backend bugs tailored to specific roles (e.g., EC2 validation logic) for targeted training

## Why It Matters for RAG Builders
Operance provides a unique, hands-on platform for evaluating debugging skills and decision-making in cloud engineering scenarios, making it valuable for AI-driven hiring assessments and training programs.
