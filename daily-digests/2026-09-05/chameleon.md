## Summary
Chameleon is an AI code assistant plugin that dynamically enforces repository-specific conventions and patterns during AI-generated code edits. It ensures generated code adheres to team idioms, architectural standards, and existing patterns by injecting real repository artifacts and rules into the AI's context before and after edits.

## Key Features
- Real-time injection of canonical repository files and idioms into AI context before edits
- Automated turn-end review for semantic duplication, correctness, and cross-file consistency
- Deterministic enforcement of team-specific conventions (e.g., HTTP wrappers, date formatters)
- Cross-file dependency and call graph analysis to prevent breaking changes
- Offline-capable comprehension tools (e.g., `get_callers`, `search_codebase`, `get_blast_radius`)

## Why It Matters for RAG Builders
Chameleon bridges the gap between AI-generated code and repository-specific conventions, ensuring generated code is contextually accurate and maintainable without manual rule enforcement.
