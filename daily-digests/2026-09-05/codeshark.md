## Summary
Codex-codeshark is a persistent local AI agent for macOS that leverages the OpenAI Codex CLI to perform project work, automate tasks, and manage durable memories. It integrates with Telegram for remote chat-based interaction and supports scheduled automation, file-based investigations, and project-scoped context management.

## Key Features
- Persistent local agent with project-scoped context and durable memory
- Telegram-based remote chat interface for task delegation and results delivery
- Task-routed execution with risk-gated approval for mutations and external side effects
- Scheduled automation (reminders, heartbeat checks, cron jobs) with ephemeral sessions
- Isolated group analysis and sandboxed non-administrator requests
