## Summary
RelayCode is a terminal-based coding agent designed for cross-file and multi-stage development tasks. It ensures task continuity, evidence-based delivery, and recoverable state management through structured project artifacts and runtime traces.

## Key Features
- Unified runtime for model calls, tool execution, and session state management
- Project-level state persistence with `.mew/` directory for task continuity
- Evidence-based delivery lifecycle driven by structured facts and validations
- Trace and evaluation sidecar for deterministic gatekeeping and debugging
- Permission and isolation controls for safe tool execution and scope management

## Why It Matters for RAG Builders
RelayCode ensures reliable, auditable, and recoverable execution of complex coding tasks, reducing the risk of undetected errors or incomplete deliveries in AI-driven development workflows.
