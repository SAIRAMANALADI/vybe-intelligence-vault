## Summary
mcp-abap-adt is an MCP server that provides AI agents with controlled, full CRUD access to SAP ABAP repositories via ADT, enabling deep analysis, development, and modifications in ECC/S/4HANA and ABAP Cloud systems. It bridges AI workflows with real SAP system data for accurate, system-grounded operations.

## Key Features
- Full CRUD operations for ABAP artifacts (classes, interfaces, programs, CDS views, RAP artifacts, etc.)
- Deep ABAP repository analysis (where-used, dependency mapping, semantic analysis, impact exploration)
- Multi-system support (on-premise ECC/S/4HANA, ABAP Cloud, legacy systems)
- Destination-based authentication (JWT/XSUAA, service keys, RFC)
- Multiple transport protocols (stdio, HTTP, SSE) for MCP client integration

## Why It Matters for RAG Builders
It enables AI agents to interact with live SAP ABAP systems for accurate, system-grounded development and analysis, bridging the gap between AI workflows and enterprise SAP landscapes.
