## Summary
Remote WP is a WordPress plugin that securely connects AI agents (Claude, Gemini, Cursor, Codex) to WordPress sites via a controlled REST API, enabling safe file inspection, code editing, debugging, and SEO optimization without exposing raw server credentials.

## Key Features
- Secure token-based authentication with rate limiting and brute force protection
- Dynamic AI agent skill packs tailored to WordPress stack (WooCommerce, Elementor, etc.)
- Controlled filesystem operations with auto-backups and approval workflows
- Permission profiles (Read Only, Read & Write, Full Access) for granular access control
- Comprehensive audit logging and sensitive file protection (wp-config.php, .env, etc.)

## Why It Matters for RAG Builders
It enables secure, controlled AI-driven WordPress development and maintenance, reducing manual intervention while maintaining strict security and auditability for RAG/AI stack builders.
