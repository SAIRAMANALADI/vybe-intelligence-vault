## Summary
Smara is a local persistent memory system for AI tools that stores project context, notes, and preferences in a vector database, enabling AI assistants like Claude or Cursor to retain memory between sessions without cloud dependency.

## Key Features
- Persistent memory storage for AI tools with local vector database
- Shared context across multiple AI assistants (e.g., Cursor, Claude)
- Automatic updates to memory based on file changes
- Local privacy with no cloud data transmission
- Intelligent retrieval using similarity search for relevant context
