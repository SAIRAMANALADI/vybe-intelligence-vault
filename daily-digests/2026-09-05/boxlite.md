## Summary
BoxLite provides a lightweight, hardware-isolated micro-VM substrate for running OCI-compliant containers as secure, persistent execution environments for AI agents. It supports embedding as a library, standalone CLI usage, or deployment as a multi-tenant cloud service.

## Key Features
- Hardware-isolated micro-VMs for each containerized agent with KVM/Hypervisor.framework support
- Persistent state across agent sessions with QCOW2 disk images and copy-on-write snapshots
- Multi-language SDKs (Python, Node.js, Go, Rust, C) and a REST API for seamless integration
- Fine-grained resource control, egress restrictions, and secret injection for security
- Embeddable library, standalone CLI, or scalable cloud deployment with AWS/GCP support

## Why It Matters for RAG Builders
BoxLite enables secure, persistent, and scalable execution environments for AI agents, bridging the gap between local development and cloud-scale deployments while maintaining strong isolation guarantees.
