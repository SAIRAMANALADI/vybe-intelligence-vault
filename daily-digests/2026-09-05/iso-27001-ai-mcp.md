## Summary
A Model Context Protocol (MCP) server for ISO/IEC 27001:2022 compliance assessment, risk management, and governance of AI systems. It audits ISMS against 93 Annex A controls, performs ISO 27005 risk assessments, generates gap analyses, and bridges to ISO 42001 for AI-specific governance.

## Key Features
- Audits ISMS against all 93 ISO 27001 Annex A controls with compliance status reporting
- Performs ISO 27005 risk assessments tailored for AI systems (e.g., adversarial attacks, model theft)
- Generates prioritized remediation roadmaps and Statement of Applicability (SoA) documents
- Bridges ISO 27001 controls to ISO 42001 for AI-specific governance requirements
- Classifies security incidents with AI-specific categories (e.g., prompt injection, data poisoning)

## Why It Matters for RAG Builders
It provides a structured, automated way to assess and improve AI system compliance with ISO 27001, reducing manual effort and ensuring alignment with international security standards.
