## Summary
WristWise MCP is a remote Model Context Protocol (MCP) server that enables AI assistants to query health data from Android smartwatches via Health Connect. It provides read-only access to sleep, heart rate, and wellness metrics through a privacy-first, OAuth-authenticated API.

## Key Features
- Read-only access to sleep, heart rate, and wellness metrics from smartwatches
- Privacy-first design with no server-side storage of health data
- OAuth 2.1 authentication with PKCE for secure access
- Integration with Android Health Connect for seamless data sync
- Supports dynamic client registration and revocable access tokens

## Why It Matters for RAG Builders
WristWise MCP enables AI assistants to securely and privately access real-time health metrics from smartwatches, enhancing personalized wellness insights without compromising user data.
