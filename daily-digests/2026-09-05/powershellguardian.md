## Summary
PowerShell Guardian is a local security gateway that acts as a controlled bridge between AI assistants (like ChatGPT) and Windows PowerShell automation, ensuring user oversight over sensitive actions while enabling AI-assisted tasks.

## Key Features
- Local-first security gateway with session-based approval for AI commands
- Strict policy enforcement for file deletion, creation, and command execution
- Emergency lock mechanism to immediately revoke AI access
- Audit logging for all approvals, rejections, and state changes
- Device-bound session tokens with configurable whitelists and safety guards

## Why It Matters for RAG Builders
It provides a critical security layer for AI-assisted Windows automation, ensuring human oversight over sensitive operations while enabling safe integration with AI tools like ChatGPT.
