## Summary
Agentic Souls is a document-driven AI workflow system that implements a three-role architecture (Planner, Evaluator, Specialist) to automate software development tasks with strict role boundaries and evidence-driven verification.

## Key Features
- Three-role architecture (Planner, Evaluator, Specialist) with strict boundaries and constraints
- Document-driven workflows defined in Markdown for flexibility and transparency
- Evidence-based verification system requiring independent validation of acceptance criteria
- Predefined workflows for common software development tasks (feature dev, bug fixes, refactoring, etc.)
- Extensible system for adding custom roles, workflows, and skills

## Why It Matters for RAG Builders
Agentic Souls provides a structured, role-based framework for automating AI-driven software development workflows, ensuring accountability, verification, and scalability for RAG and AI engineering stacks.
