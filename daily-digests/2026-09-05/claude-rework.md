## Summary
claude-rework indexes and indexes Claude AI session transcripts to enable fast, low-cost retrieval of past decisions and context, reducing token usage from ~211k to ~2.5k per query. It also facilitates memory migration between machines or accounts via export/import bundles.

## Key Features
- Indexes local Claude AI session transcripts for fast retrieval of past decisions and context
- Reduces token usage per query from ~211k to ~2.5k, saving costs and improving efficiency
- Supports memory migration between machines or accounts via export/import bundles
- Integrates with multiple Claude surfaces (Code, Desktop, Cowork) via hooks or MCP server
- Provides CLI commands for querying, exporting, importing, and managing memory

## Why It Matters for RAG Builders
It enables RAG builders to efficiently retrieve and utilize past context without bloating token usage, reducing costs and improving response relevance.
