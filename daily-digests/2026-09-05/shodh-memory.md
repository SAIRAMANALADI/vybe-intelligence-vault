## Summary
Shodh-Memory is a persistent, offline-first cognitive memory system for AI agents and robots that learns from usage, forgets irrelevant data, and strengthens important memories without relying on LLMs. It supports chat agents, robots (via Zenoh/ROS2), and edge devices with millisecond latency and zero external dependencies.

## Key Features
- Zero LLM calls for memory storage or retrieval, ensuring offline operation and deterministic behavior
- Hebbian learning and exponential decay for adaptive memory strengthening and forgetting
- Local embeddings and NER via ONNX Runtime (MiniLM, GLiNER) for privacy and low latency
- Multi-modal support including chat agents, robots (ROS2/Zenoh), and edge devices
- 51+ MCP tools and REST API for seamless integration with AI workflows and automation

## Why It Matters for RAG Builders
It provides a critical offline, LLM-free memory layer that enables AI agents and robots to retain and retrieve context efficiently without incurring API costs or latency, making it essential for scalable RAG and autonomous systems.
