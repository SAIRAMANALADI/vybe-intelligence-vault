## Summary
A repository providing standardized templates and rules for creating engineering documentation such as ADRs, RFCs, Tech Designs, TDDs, and Postmortems. Designed to be used by AI agents to automate documentation generation.

- AI agent skill file (`SKILL.md`) for automated documentation generation
- Rules for plain English, no jargon, and visual explanations
- Mermaid diagrams and tables for clarity
