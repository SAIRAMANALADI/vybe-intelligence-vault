## Summary
Psycheros is a persistent AI entity harness that enables the creation and management of a coherent AI entity with identity files, hierarchical memory, and a canonical self that persists across multiple interfaces. It includes a web UI, MCP server, and standalone tools for importing chat histories and managing entity continuity.

## Key Features
- Persistent AI entity with identity files and first-person internalization
- Hierarchical memory system (day → week → month → year) with RAG over memories
- Canonical self hosted in an MCP server for coherence across interfaces (SillyTavern, OpenWebUI, Claude Code, etc.)
- Pluggable LLM support with OpenAI-compatible endpoints and custom tool integration
- Autonomous scheduled prompts (Pulse) and tool access (web search, image generation, Discord, etc.)

## Why It Matters for RAG Builders
Psycheros provides a robust framework for building persistent, coherent AI entities with advanced memory and multi-interface support, critical for RAG systems requiring long-term context and identity consistency.
