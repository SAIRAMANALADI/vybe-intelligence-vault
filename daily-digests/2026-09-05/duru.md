## Summary
DURU is an on-premise AI agent designed to run entirely on a user's local PC, enabling secure document-based Q&A, summarization, and analysis without cloud dependency. It supports multiple document formats and provides verifiable answers with direct evidence citations from the source material.

## Key Features
- Runs entirely on local PC with no cloud dependency, ensuring data privacy and security
- Supports multiple document formats (PDF, HWP, DOCX, PPTX, XLSX, TXT) for knowledge base creation
- Provides verifiable answers with direct evidence citations, including page numbers and document references
- Offers five specialized AI agents (e.g., administrative assistant, study partner) with role-specific capabilities
- Enables encrypted knowledge base sharing via portable .durukb files for seamless collaboration

## Why It Matters for RAG Builders
DURU enables secure, offline document-based RAG workflows with verifiable evidence, making it essential for AI stack builders prioritizing data privacy and regulatory compliance.
