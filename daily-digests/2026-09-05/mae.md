## Summary
MAE is an AI-native Lisp machine IDE designed as a programmable development environment where humans and AI act as peer actors using the same Scheme primitives. It combines a Rust core with an embedded R7RS-small runtime, offering collaborative editing, multi-language execution, and deep AI integration.

## Key Features
- AI as peer actor with direct access to editor primitives, eliminating shadow APIs or simulated keystrokes
- Collaborative editing with CRDT sync, WAL persistence, and real-time knowledge base sharing across instances
- Org-mode Babel for executing code blocks in 12 languages with noweb expansion, tangling, and cross-references
- Runtime redefinability via embedded R7RS Scheme, allowing live function redefinition without restart
- Full vi modal editing, LSP/DAP integration, and multi-provider AI support (Claude, OpenAI, Gemini, DeepSeek, Ollama)

## Why It Matters for RAG Builders
MAE provides a unified environment where AI and humans collaborate seamlessly using the same primitives, enabling advanced RAG systems with real-time, structured, and collaborative context management.
