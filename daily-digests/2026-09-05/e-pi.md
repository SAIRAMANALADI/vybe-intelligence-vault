## Summary
E-Pi is a desktop shell for managing Pi sessions, packages, and terminal workflows with a native Electron-based UI. It integrates Pi coding agent sessions, terminal emulation, and package management into a single cohesive application.

## Key Features
- Multi-session parallel Pi agent execution with isolated project-based grouping
- Embedded xterm.js terminal with WebGL acceleration for real-time interaction
- Visual diff rendering for code reviews with git numstat integration
- Skill and package management panels for Pi agent configuration
- Real-time runtime metrics (tokens/sec, usage stats) and agent status indicators

## Why It Matters for RAG Builders
E-Pi provides a unified desktop interface for managing and interacting with Pi coding agents, streamlining workflows for AI engineers and developers.
