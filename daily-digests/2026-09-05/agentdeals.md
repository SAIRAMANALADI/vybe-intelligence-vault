## Summary
AgentDeals is an MCP server that aggregates free tiers, startup credits, and developer tool deals from 1,500+ vendors across 54 categories. It enables AI agents and developers to search, compare, and track infrastructure offers without leaving their workflow.

## Key Features
- Aggregates 1,500+ verified vendor offers across 54 categories with real-time pricing data
- Provides 4 MCP tools (search_deals, plan_stack, compare_vendors, track_changes) for agent integration
- Supports both local (stdio) and remote (HTTP) deployment for flexibility
- Includes REST API endpoints for programmatic access to deals and pricing changes
- Offers eligibility filtering (e.g., accelerator, student, OSS) and category-based search

## Why It Matters for RAG Builders
AgentDeals enables AI agents to dynamically discover and verify current infrastructure deals, ensuring accurate and cost-optimized recommendations for users.
