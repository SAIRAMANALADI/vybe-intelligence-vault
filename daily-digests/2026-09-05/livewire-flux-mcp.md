## Summary
An MCP (Model Context Protocol) server that provides structured access to Livewire Flux Components and Layouts documentation, enabling AI assistants to fetch, search, and retrieve up-to-date Flux UI component and layout references dynamically.

## Key Features
- Fetches real-time Flux component and layout documentation from fluxui.dev
- Supports Pro-tier awareness to flag components requiring paid licenses
- Provides high-performance caching with 24-hour expiration for optimized responses
- Includes tools for listing all Flux components, layouts, and Heroicons
- Integrates seamlessly with Laravel Boost and other AI agent frameworks

## Why It Matters for RAG Builders
It enables AI assistants to dynamically fetch accurate, up-to-date Flux UI documentation and component details, reducing hallucinations and ensuring generated code adheres to official specifications.
