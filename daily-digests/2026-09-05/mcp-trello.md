## Summary
A Python-based MCP (Model Context Protocol) server that exposes Trello operations as tools for AI agents, enabling seamless integration with platforms like Claude Code and OpenCode for project management workflows.

## Key Features
- Exposes Trello operations (create, move, comment, label cards) as MCP tools for AI agents
- Smart fuzzy matching for Trello IDs, lists, labels, and boards to simplify operations
- Supports multi-board operations with optional board_name parameter
- Provides detailed card information including descriptions, deadlines, members, and checklists
- Interactive setup wizard for Trello API credentials and board configuration

## Why It Matters for RAG Builders
It enables AI agents to interact with Trello boards directly, streamlining project management tasks without requiring exact IDs or manual navigation.
