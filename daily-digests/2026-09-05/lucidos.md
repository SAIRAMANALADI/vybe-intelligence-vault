## Summary
Lucidos is a local, event-driven AI OS that enables users to describe, build, run, and automate applications entirely through natural language within a unified workspace. It integrates chat, apps, data, and automations in a persistent interface, running entirely on the user's machine with local data storage.

## Key Features
- Natural language-driven app creation and automation with zero build steps
- Persistent, integrated chat interface alongside workspaces and data
- Local data storage with PostgreSQL event store and git-versioned artifacts
- Supports multiple LLM providers and configurable automation triggers
- Cross-platform deployment with macOS DMG, Linux tarballs, or one-liner install

## Why It Matters for RAG Builders
Lucidos provides a unified, local-first environment for building and automating AI-driven workflows, reducing reliance on external tools and enabling seamless integration of LLMs into daily tasks.
