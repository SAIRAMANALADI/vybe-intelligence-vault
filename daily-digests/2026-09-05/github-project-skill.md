## Summary
This repository provides an Agent Skill for configuring and managing GitHub repositories, focusing on platform-specific features like branch protection, PR workflows, issue hierarchies, auto-merge rules, and merge queues. It standardizes GitHub project setup for AI agents and developers.

- Support for sub-issues, issue hierarchies, and CODEOWNERS setup
