## Summary
MemFusion v2 is a wiki-style memory system for long-term agents that stores memories as structured wiki pages with typed links, retrieves using a hybrid BM25 + dense embedding retriever with RRF fusion, and records orchestration traces with reward labels for future RL training of stopping decisions.

## Key Features
- Wiki-style memory storage with Dimension/Page/Section structure and typed links
- Hybrid retrieval combining BM25 and dense embeddings with RRF fusion for improved recall
- Orchestration traces with reward labels for training stopping decisions via RL
- Semantic expansion for long conversations to widen recall
- AML-compliant API protocol for Add/Search operations with LLM resilience

## Why It Matters for RAG Builders
MemFusion v2 provides a structured, hybrid-retrieval memory system with orchestration traces that enable RL training for stopping decisions, addressing critical gaps in long-term agent memory and decision-making.
