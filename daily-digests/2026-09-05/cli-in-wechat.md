## Summary
cli-in-wechat is a Windows application that bridges WeChat with command-line AI tools via the official iLink Bot API, enabling users to send prompts and receive AI-generated responses directly within WeChat.

## Key Features
- Seamless integration of AI tools (Claude Code, Codex, Gemini, Kimi, OpenCode) with WeChat
- Supports Windows 10/11 with simple installation via .exe or .zip
- Enables prompt sending and response receiving directly in WeChat
- Configurable via settings for API keys, model selection, and working directories
- Includes troubleshooting guides for common setup and runtime issues

## Why It Matters for RAG Builders
It simplifies access to command-line AI tools for users who prefer WeChat as their primary interface, reducing context-switching and improving workflow efficiency.
