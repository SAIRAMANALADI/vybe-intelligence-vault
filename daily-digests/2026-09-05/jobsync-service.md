## Summary
JobSync is an agentic job-search copilot that integrates with MCP clients (Claude Desktop, Claude Code, Cursor) to discover, classify, and sync job postings into Airtable or local markdown files. It is model-agnostic, allowing users to bring their own LLM while handling the backend workflow automation.

## Key Features
- Agentic job discovery and classification using MCP clients
- Syncs jobs to Airtable or local markdown files
- Deterministic tools for filtering, deduplication, and caching
- Model-agnostic design (user provides LLM)
- Supports cron-based automated job scraping

## Why It Matters for RAG Builders
JobSync streamlines job search automation by leveraging MCP clients to handle agentic workflows, reducing manual effort for RAG builders who need structured job data integration.
