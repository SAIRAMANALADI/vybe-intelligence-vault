## Summary
CreatorDistill is a local-first intelligence agent for Douyin (TikTok) creators that distills creator profiles, collections, and content into searchable knowledge, viral patterns, topic assets, and reusable creator personas. It automates content capture, transcription, analysis, and persona generation while prioritizing data integrity and user control.

## Key Features
- Batch capture of creator profiles, works, and collections with JSON evidence layer for auditability
- Dual transcription pipeline (cloud API + local Whisper) with priority routing and failure recovery
- Viral pattern analysis across multiple works to extract hooks, structures, and engagement trends
- Topic generation and reusable creator personas with evidence-based reasoning and citations
- Task persistence with SQLite for state management, logging, and incremental updates

## Why It Matters for RAG Builders
It provides a critical pipeline for transforming raw creator content into structured, searchable, and actionable knowledge assets essential for RAG systems and AI-driven content analysis.
