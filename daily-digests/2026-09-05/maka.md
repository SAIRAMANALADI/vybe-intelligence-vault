## Summary
Apache Maka (Incubating) is a local-first agent workspace designed for real-world AI agent development and execution. It provides a sandboxed runtime environment for agents, records all interactions as recoverable execution facts, and supports multiple interfaces including Desktop, CLI, and TUI.

## Key Features
- Durable execution record of model messages, tool calls, and results stored locally
- Sandboxed tool execution with permission controls and failure classification
- Multi-interface support (Desktop, CLI, TUI) with shared runtime host
- Built-in tools (Read, Write, Edit, Bash, Glob, Grep) with optional computer-use capabilities
- Evaluation framework for reproducible benchmark experiments across agents

## Why It Matters for RAG Builders
Maka provides a critical foundation for building and testing AI agents with robust logging, sandboxing, and evaluation capabilities, ensuring reliable and reproducible agent workflows.
