## Summary
travel-buddy is a travel planning skill for Claude Code and Codex that separates destination selection from itinerary generation, ensuring only bookable plans are produced. It validates real-time data like fares, timetables, and entry rules before generating a self-contained HTML plan with booking links, maps, and a per-person budget, all while keeping data local and avoiding third-party transactions.

## Key Features
- Separates destination selection from itinerary generation to ensure only feasible plans are created
- Validates volatile facts (fares, timetables, entry rules) against live sources before planning
- Generates a self-contained HTML plan with booking links, maps, and a per-person budget with sources
- Enforces hard constraints and gates to prevent half-finished or unverified plans
- Supports incremental replanning and change logging for existing plans

## Why It Matters for RAG Builders
It ensures RAG/AI stack builders can generate reliable, bookable travel plans by validating real-time data and enforcing strict constraints before producing deliverables.
