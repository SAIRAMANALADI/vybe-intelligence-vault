## Summary
LeadMagic Cursor Plugin integrates Cursor IDE with LeadMagic's hosted MCP server for B2B enrichment and GTM research, offering work email validation, company research, job-change signals, and technographic data via OAuth or API-key authentication.

## Key Features
- Hosted MCP server for credit-aware B2B enrichment (35+ tools)
- OAuth and API-key authentication modes for Cursor integration
- Cursor-native packaging with rules, skills, commands, and an enrichment agent
- In-editor documentation via `leadmagic://docs` and prompts for account research
- Supports bulk operations, technographics, and job-change signal detection

## Why It Matters for RAG Builders
It streamlines B2B research and enrichment workflows directly within Cursor, reducing context-switching for AI engineers building RAG pipelines.
