## Summary
DocHarvest (gitbook-downloader) is a local-first documentation compiler that transforms any documentation site into LLM-ready Markdown, vector RAG JSONL, and offline PDFs. It supports 8+ documentation platforms, offers a zero-config CLI, a React-based desktop GUI, and a native FastMCP server for AI agent integration.

## Key Features
- Supports 8+ documentation platforms (GitBook, Docusaurus, ReadTheDocs, etc.) with dedicated parsers for clean markdown extraction
- Four-part output contract: modular Markdown pages, consolidated book.md, llms.txt manifest, and vector RAG JSONL exports
- Native FastMCP v2 server exposing 10+ tools for AI agent integration (Cursor, Claude Code, VS Code, etc.)
- React-based desktop GUI with real-time search, batch exports, and PDF generation
- SQLite FTS5 full-text search engine and process-safe storage with atomic file operations

## Why It Matters for RAG Builders
It streamlines the conversion of raw documentation into clean, LLM-ready formats, eliminating boilerplate and enabling seamless integration into RAG pipelines and AI workflows.
