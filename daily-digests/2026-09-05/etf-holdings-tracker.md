## Summary
TickerTrace provides daily ETF holdings intelligence by scraping, normalizing, and diffing institutional fund disclosures to reveal institutional buying/selling activity and conviction shifts before market open. It offers a free REST API, MCP server integration for AI agents, and a Next.js dashboard for visualization.

## Key Features
- Real-time ETF holdings tracking across 71 funds from 11 providers with daily updates
- REST API (no auth required) and FastMCP server for AI agent integration
- Convolution-scored buy/sell signals, sector flow analysis, and cross-fund divergences
- Next.js dashboard with interactive visualizations and Discord webhook integration
- OpenFIGI-backed CUSIP resolution and automated daily pipeline via GitHub Actions
