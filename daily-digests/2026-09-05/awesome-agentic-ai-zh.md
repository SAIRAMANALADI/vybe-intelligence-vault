## Summary
A trilingual (Traditional Chinese, Simplified Chinese, English) learning roadmap for agentic AI, guiding users from LLM basics to building multi-agent systems with 240+ curated resources, hands-on exercises, and structured learning paths.

## Key Features
- Structured 8-stage learning path from LLM basics to multi-agent systems with 240+ curated resources
- Trilingual documentation (繁體中文 / 简体中文 / English) with full parity
- 23 hands-on illustrative exercises with starter code and dual-path SDK comparisons (Ollama/Anthropic)
- Comprehensive MCP/Skills catalog with 65+ entries for tool integration
- Two distinct learning tracks (Track A: CLI Power User, Track B: Agent Builder) with shared foundational stages
