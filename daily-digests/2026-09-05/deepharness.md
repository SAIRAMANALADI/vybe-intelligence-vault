## Summary
DeepHarness is a lightweight Python framework for composing LLM agents into typed, concurrent workflows. It enables parallel execution of independent branches, conditional routing, and typed state management using dataclasses, all with minimal dependencies.

## Key Features
- Composes LLM agents into typed, concurrent workflows with dataclass-based state management
- Supports parallel execution of independent branches via asyncio and thread offloading
- Single dependency (httpx) for direct REST API communication with multiple LLM providers
- Agents can be nested as tools within other agents for hierarchical task delegation
- Graph-based workflows for fixed, known-shape processes with conditional routing

## Why It Matters for RAG Builders
DeepHarness simplifies the orchestration of LLM agents into scalable, typed workflows with minimal overhead, making it ideal for building modular and maintainable AI systems.
