## Summary
An official onboarding skill for AI agents to read, fill, create, and inspect HWPX (Hangul Word Processor XML) documents using pure Python. Enables natural language-driven document automation without requiring Hangul Office or complex setup.

## Key Features
- Natural language-driven HWPX document manipulation via AI agents
- Pure Python implementation with no dependency on Hangul Office
- Cross-platform support (Windows, macOS, Linux)
- Comprehensive document operations: read, fill forms, create, inspect, and repair
- Integration with MCP servers for seamless agent workflows
