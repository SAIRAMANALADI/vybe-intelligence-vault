## Summary
FinPilot is an open-source, enterprise-ready AI-powered financial analysis platform that replaces traditional finance functions (bookkeeping, budgeting, treasury, tax, reporting, and audit) with a multi-agent system. It enables conversational financial queries, automated report generation, and document-based RAG Q&A with full traceability and auditability.

## Key Features
- Conversational financial analysis with natural language queries translated to SQL
- Deterministic financial modeling (DCF, WACC, LBO, Monte Carlo) with traceable results
- RAG-based document Q&A supporting Excel, PDF, CSV, and DOCX with BM25 + vector + RRF fusion retrieval
- Automated report generation with subscription push and approval workflows
- Enterprise-grade security with ABAC access control, TOTP 2FA, PII masking, and audit logging

## Why It Matters for RAG Builders
FinPilot provides a critical bridge between natural language queries and financial data, enabling RAG systems to perform accurate, auditable financial analysis and reporting with minimal manual intervention.
