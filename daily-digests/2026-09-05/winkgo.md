## Summary
WINK GO is an open-source, cross-platform AI agent workspace that unifies AI conversations, multi-agent collaboration, MCP tools, Skills, local file management, automation, and a desktop widget (灵动岛) into a single application. It enables agents to execute real-world tasks beyond answering questions.

## Key Features
- Unified management of AI agents, models, Skills, MCP tools, and local files in a single interface
- Multi-agent team creation with role-based collaboration and task delegation
- 灵动岛 (desktop widget) for real-time task monitoring, media control, notifications, and quick actions
- Local-first architecture with SQLite and file-based data storage for privacy and offline capability
- Cross-platform support (Windows, macOS, Linux) with prebuilt installers for x64 and ARM64

## Why It Matters for RAG Builders
WINK GO provides a comprehensive, open-source platform for building and managing AI agents with local execution, multi-agent collaboration, and desktop integration, reducing fragmentation in AI agent tooling ecosystems.
