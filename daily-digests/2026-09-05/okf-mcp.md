## Summary
okf-mcp is a project-agnostic Open Knowledge Format (OKF) CLI, graph indexer, and MCP stdio server that processes Markdown files with YAML frontmatter into structured knowledge concepts. It exposes these concepts via CLI commands, MCP resources/tools, and an optional HTTP API for structured search, validation, graph navigation, and proposal-based authoring without requiring a database or hosted service.

## Key Features
- Processes Markdown files with YAML frontmatter into structured OKF concepts
- Exposes concepts via MCP resources/tools and CLI commands for search, validation, and graph navigation
- Supports proposal-based authoring with acceptance/rejection workflows
- Includes an optional HTTP API for read/validation and mutation endpoints
- No database or hosted-service dependency; uses local bundles or remote GitHub bundles

## Why It Matters for RAG Builders
It provides a standardized way to structure, validate, and expose knowledge as a graph for AI agents while enabling collaborative authoring and dynamic updates without heavy infrastructure.
