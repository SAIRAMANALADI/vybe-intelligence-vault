## Summary
Maekon is a local-first desktop agent that captures and organizes local work signals into a focus timeline, next-action candidates, and policy-gated automation paths. Built with Rust and Tauri v2, it provides real-time context monitoring, edge image processing, and a built-in web dashboard for productivity analysis.

## Key Features
- Real-time context monitoring with active window and system resource tracking
- Edge image processing including OCR, delta encoding, and thumbnails
- Policy-gated automation with sandbox isolation and audit logging
- Built-in local web dashboard for focus analytics, timeline, and reports
- Cross-platform support for macOS, Windows, and Linux

## Why It Matters for RAG Builders
Maekon provides a privacy-preserving, local-first approach to capturing and acting on desktop signals, which is critical for building AI systems that respect user data and autonomy while enabling productivity insights.
