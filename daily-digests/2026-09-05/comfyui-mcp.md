## Summary
comfyui-mcp is a local-first, agent-native control plane for ComfyUI that enables LLMs to generate, edit, and manage ComfyUI workflows in natural language. It functions as an MCP server and sidebar agent, supporting image, video, and audio generation across local, remote, or Comfy Cloud deployments.

## Key Features
- Natural language-driven ComfyUI workflow generation and editing via MCP tools
- Supports 38+ MCP tools, 42 AI skills, and 56+ installer packs for model and node management
- Local-first deployment with support for remote, VPS, LAN, and Comfy Cloud environments
- Built-in LLM Arena for benchmarking model performance on real ComfyUI tasks
- Claude Code plugin with slash commands, autonomous agents, and hooks for enhanced workflow control

## Why It Matters for RAG Builders
It provides a unified, agent-native interface to drive ComfyUI workflows across any LLM, enabling seamless integration of AI-generated content into production pipelines without manual intervention.
