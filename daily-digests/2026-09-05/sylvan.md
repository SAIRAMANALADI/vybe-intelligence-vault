## Summary
Sylvan is a code intelligence platform designed for AI agents, enabling precise codebase navigation, dependency analysis, and semantic search through 65+ MCP tools. It indexes codebases into structured databases to minimize token waste and improve agent efficiency.

## Key Features
- 65+ MCP tools for search, analysis, and refactoring with agent-intent naming
- Hybrid search combining full-text and vector similarity for precise results
- Blast radius analysis and dependency graphs to assess code impact
- Multi-repo workspace support with third-party library indexing (pip, npm, cargo, go)
- Live web dashboard with token efficiency tracking and code quality reports

## Why It Matters for RAG Builders
Sylvan drastically reduces token waste and context window usage for AI agents by providing precise, structured access to codebases, making it essential for efficient RAG and agentic workflows.
