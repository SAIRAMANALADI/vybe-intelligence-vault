## Summary
An MCP server that integrates with Canvas LMS to provide 16 curated tools for student workflows (e.g., checking assignments, grades, and deadlines) and a gateway to access all 1,116 Canvas API endpoints dynamically.

## Key Features
- 16 pre-curated tools for common student tasks (e.g., `whats_due`, `my_grades`, `submit_assignment`)
- Gateway tools (`search_canvas_api`, `canvas_request`) to dynamically access all 1,116 Canvas API endpoints
- Secure OAuth token handling with local-only execution to comply with Canvas API policies
- Comprehensive documentation and one-click installers for major AI clients (Cursor, VS Code, LM Studio)
- Built-in error handling for deep thread traversal and pagination security

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with Canvas LMS, automating student workflows and reducing manual data entry while ensuring compliance with Canvas API security policies.
