## Summary
Shotluma is an AI-first, local-first canvas editor designed to create editable iOS App Store screenshot sets directly in the browser. It leverages AI agents to generate real, manipulable designs rather than static images, allowing users to refine and customize every element.

## Key Features
- AI agent generates editable, multi-screen App Store screenshot sets with real canvas elements
- Direct manipulation of text, gradients, shapes, and device mockups post-generation
- Supports multiple AI providers (Moonshot, Google, Qwen, OpenAI, Anthropic, xAI) with user-provided API keys
- Local-first storage in IndexedDB with automatic project saving
- Store-ready export as high-resolution PNGs in a single ZIP file

## Why It Matters for RAG Builders
Shotluma enables RAG builders to generate and refine editable UI assets dynamically, reducing manual design effort and accelerating the creation of store-ready screenshots for AI-powered applications.
