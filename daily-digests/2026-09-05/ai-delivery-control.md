## Summary
A governance framework for AI-assisted Python software delivery that enforces structured workflows, pre-commit AI reviews, and requirement traceability to ensure agents deliver accountable and correct code. It integrates with LLM-based coding agents like Claude Code and Gemini CLI to prevent common pitfalls in AI-driven development.

## Key Features
- Pre-commit AI adversarial review gate with separate evaluator model to block incorrect commits
- Structured session workflows (e.g., feature implementation, bug fixes, architecture) with named phases
- Requirement-to-commit traceability ensuring every change aligns with approved specifications
- Universal and stack-specific skills (e.g., testing, security, performance) for guided agent execution
- Configurable enforcement postures (strict, ratchet, observe) for flexible governance

## Why It Matters for RAG Builders
It provides a critical governance layer for AI-driven software delivery, ensuring agents produce correct, traceable, and high-quality code while preventing common failure modes in autonomous development workflows.
