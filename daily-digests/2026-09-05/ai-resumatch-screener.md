## Summary
An autonomous job-hunting agent that automates job application screening by parsing recruiter emails, scraping job postings, and scoring them against a user's resume using a local LLM. Generates a ranked HTML report of job matches.

## Key Features
- Automates email parsing from Yahoo Mail to extract job postings
- Uses Playwright for authenticated browser scraping of job descriptions
- Scores job matches against a user's resume using a local LLM (Ollama)
- Generates a dated, ranked HTML report with match analysis
- Modular design for easy extension to other job portals
