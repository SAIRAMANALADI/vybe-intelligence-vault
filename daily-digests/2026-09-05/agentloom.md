## Summary
AgentLoom is a framework for designing, running, and inspecting multi-agent AI applications using YAML configurations. It provides a terminal-based Builder (TUI) for conversational agent system design, a Python runtime for execution, and tools for inspecting agent interactions and outputs.

## Key Features
- YAML-defined multi-agent workflows with Supervisor/Worker model
- Terminal-based Builder (TUI) for conversational agent system design and validation
- Python runtime with model routing, concurrency, logging, and checkpointing
- Built-in tools (file, shell, search, Git, MCP) and Skills for extensibility
- Rich inspection capabilities via TUI and Web UI for runs, logs, and artifacts

## Why It Matters for RAG Builders
AgentLoom simplifies the orchestration and inspection of complex multi-agent AI systems, enabling reproducible workflows and deep observability critical for RAG and AI stack builders.
