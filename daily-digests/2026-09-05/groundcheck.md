## Summary
Groundcheck is a factual verification tool for AI agents that checks claims against live sources via MCP, returning verdicts, confidence scores, and citations. It decomposes compound claims, handles stance classification, and provides calibrated confidence guarantees using conformal prediction.

## Key Features
- Real-time claim verification against live sources (e.g., Wikipedia)
- Compound claim decomposition and atom-level verification
- Calibrated confidence scores with conformal prediction guarantees
- Stance classification via ensemble of free-tier LLM providers
- Machine-payable hosting via x402 protocol for monetization

## Why It Matters for RAG Builders
Groundcheck ensures AI agents can verify factual claims with evidence-backed verdicts, reducing hallucinations and improving reliability in RAG pipelines.
