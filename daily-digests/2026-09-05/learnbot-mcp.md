## Summary
An AI chatbot orchestrator designed for language learning and conversational AI, featuring personas, safety-guarded interactions, TTS, a VRM avatar, and structured lessons with deep Japanese/JLPT support. It integrates with MCP clients like Claude Desktop and provides a 12-page webapp for control and monitoring.

## Key Features
- 35+ MCP tools for personas, conversations, lessons, and safety auditing
- Interactive VRM avatar with facial expressions and three.js viewer
- Deep Japanese/JLPT toolset with local SQLite data (no external services required)
- Safety-guarded chat with PII redaction, rate limiting, and full audit logs
- Multi-platform output including TTS, Discord, and Resonite bridges
