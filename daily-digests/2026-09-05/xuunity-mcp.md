## Summary
XUUnity MCP is a lightweight, validation-first Unity Editor automation MCP server designed for safe AI-driven Unity project interactions. It enables local-first Unity Editor automation with compile checks, EditMode/PlayMode test execution, scene validation, and multi-project routing via a stdio MCP server and editor-only Unity package.

## Key Features
- Lightweight Unity MCP server for safe editor automation with compile checks and test execution
- Validation-first approach with bounded scenario validation and request-journal recovery
- Multi-project routing for workstations with multiple Unity projects
- Editor-only Unity package with no player-build footprint by default
- Integration with popular MCP clients like Claude, Cursor, Rider, and Windsurf

## Why It Matters for RAG Builders
It provides a secure, validation-first MCP server for Unity Editor automation, enabling AI agents to safely interact with Unity projects without risking unrestricted editor mutations.
