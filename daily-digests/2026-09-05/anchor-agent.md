## Summary
Anchor Agent is a VS Code extension enabling asynchronous, selection-scoped AI editing with tracked text anchors. It allows MCP-compatible agents to propose edits without direct file modifications, providing a live task-details panel for review and conflict handling.

## Key Features
- Asynchronous, selection-scoped AI editing with tracked text anchors
- MCP-compatible agent integration with read-only tools and automatic dispatch
- Live task-details panel for reviewing, accepting, rejecting, or retrying edits
- Workspace-aware multi-window routing and task persistence
- Configurable conflict handling with rebase/regeneration or three-way merge

## Why It Matters for RAG Builders
It enables seamless, tracked AI-driven code edits in VS Code while maintaining user control and review capabilities, critical for safe and iterative RAG workflows.
