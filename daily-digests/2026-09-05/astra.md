## Summary
Astra is an open-source runtime designed for durable agent workflows across enterprise environments, bridging context assembly, policy governance, and execution within private IT systems. It enables end-to-end traceability and governed actions for long-horizon agent tasks.

## Key Features
- Context Pipeline for governed context assembly with deterministic optimization and provenance tracking
- Durable Work engine with session, run, and task graph management for long-horizon tasks
- Policy-driven execution with provider admission and permission controls
- User Runners for secure, local execution within private enterprise environments
- End-to-end traceability with introspection, explainability, and audit capabilities

## Why It Matters for RAG Builders
