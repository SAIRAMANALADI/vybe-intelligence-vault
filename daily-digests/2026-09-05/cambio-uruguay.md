## Summary
Cambio Uruguay is an open-source platform that provides real-time exchange rate comparisons for multiple currencies across Uruguayan financial institutions, including live buy/sell rates, historical data, and location-based branch maps. It offers a trilingual (ES/EN/PT) web interface, a public API, and an MCP server for AI assistants.

## Key Features
- Live comparison of 40+ Uruguayan financial institutions and exchange rates for 15+ currencies
- Public API with no authentication required for read-only access
- Model Context Protocol (MCP) server for seamless integration with AI assistants
- Trilingual web interface (Spanish, English, Portuguese) with interactive maps and historical charts
- Continuously updated data with branch locators and currency calculators
