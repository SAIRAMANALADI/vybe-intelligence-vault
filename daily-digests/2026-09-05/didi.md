## Summary
Didi is a high-performance, native Model Context Protocol (MCP) server for Godot 4.5+ engineered in C++20, providing direct Godot scene access, live editor state manipulation, and offline fallback capabilities via a standalone executable or GDExtension library.

## Key Features
- Direct Godot scene tree and node manipulation with live editor access
- 93 canonical MCP tools with explicit execution modes and offline fallbacks
- Zero external runtime dependencies with local IPC transport (named pipes/Unix sockets)
- Undo/redo safety via native EditorUndoRedoManager integration
- Live viewport capture, pixel diffs, and visual inspection capabilities

## Why It Matters for RAG Builders
Didi enables AI agents to directly interact with Godot projects for real-time scene editing, debugging, and asset management, bridging the gap between AI workflows and game development.
