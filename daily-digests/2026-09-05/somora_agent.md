## Summary
somora_agent is a local-first server for hosting multiple AI agents with persistent memory, shared long-term wiki curation, and cross-provider LLM compatibility. It enables seamless multi-agent conversations, tool-based interactions, and proactive scheduling via a modular architecture.

## Key Features
- Multi-agent system with distinct personas, memory, and tool access
- Persistent memory across sessions with three-phase consolidation (REM, Deep, Lucid)
- Shared long-term wiki curated by agents (Obsidian integration)
- Cross-provider LLM compatibility (Claude, ChatGPT, local models via OpenAI-compatible endpoints)
- Proactive scheduling (Sentinel) for automated agent tasks and reminders

## Why It Matters for RAG Builders
It provides a robust, local-first framework for orchestrating multiple AI agents with persistent memory and tool integration, critical for building scalable RAG systems with multi-agent workflows.
