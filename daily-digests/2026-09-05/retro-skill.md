## Summary
retro is an LLM-driven plugin for Claude Code that analyzes agent session transcripts to detect friction, classify findings into six destinations, and materialize actionable learnings with explicit user approval. It replaces noisy background hooks with a focused, post-session review process.

## Key Features
- Post-session transcript analysis to detect friction (tool errors, repeated mistakes, convention violations)
- Six destination routes for findings: user-memory, project-rules, skill-update, new-skill, checkpoint, harness-artefact
- Explicit per-proposal approval for all materializations (no silent writes)
- Mechanical pre-pass + LLM enrichment pipeline for accurate classification and token efficiency
- Supports four modes: Sweep, Spotlight, Outcome, and Constitutional Audit for comprehensive session review

## Why It Matters for RAG Builders
It provides a structured way to extract and materialize actionable learnings from agent sessions, reducing noise and improving future agent performance by capturing both friction and reusable knowledge.
