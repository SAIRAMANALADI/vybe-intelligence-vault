## Summary
Cetus transforms existing agent runtimes (e.g., Claude Code, Codex, DeepSeek Harness) into an always-on desktop assistant for macOS. It provides ambient context, scheduling, and a unified interface for managing agent workflows, screen history, and background tasks.

## Key Features
- Global hotkey launcher for instant agent access with screen context (screenshots, selected text, app context)
- Automations for scheduling one-off or recurring agent tasks with background execution
- Screen context history with OCR-based search for recalling past workflows
- Global quick reply for drafting responses without leaving the current app
- Built-in voice dictation and meeting memory with on-device transcription

## Why It Matters for RAG Builders
Cetus bridges the gap between terminal-based agent runtimes and practical desktop workflows by providing ambient context, scheduling, and a unified review interface, making AI agents more usable for everyday tasks.
