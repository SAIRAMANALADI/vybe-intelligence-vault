## Summary
A self-hosted conversational AI agent for private Discord communities that enables natural language interactions with permission-aware server memory, web tools, and optional integrations like wallets and code updates. The agent retains context, enforces permissions, and delivers responses while executing tasks in isolated Kubernetes Jobs.

## Key Features
- Natural language interaction with Discord mentions/replies and retained thread context
- Permission-filtered retrieval of Discord history, attachments, and external data
- Multi-modal tool support including web search, image generation, and document inspection
- Sandboxed code updates via Kubernetes Jobs with GitHub PR publication
- Optional integrations for wallets, games, and Spotify tools with private operator dashboard
