## Summary
Secchi is an open-source command-line tool for exploring, comparing, monitoring, and reporting on package health, adoption, dependencies, and ecosystem signals across multiple programming language registries like PyPI, npm, and crates.io.

## Key Features
- Interactive terminal dashboard for package health and adoption monitoring
- Cross-registry package search and comparison with health scoring
- MCP server for AI agent integrations (e.g., coding assistants)
- JSON, Markdown, and HTML report generation for documentation and automation
- Security advisory integration via OSV.dev for vulnerability tracking

## Why It Matters for RAG Builders
Secchi provides critical package intelligence for RAG builders by enabling automated dependency health checks, cross-ecosystem comparisons, and vulnerability tracking, ensuring AI systems rely on well-maintained and secure dependencies.
