## Summary
An evidence-first agent skill that audits Next.js repositories to generate or rewrite accurate README.md files based on verified source code, configurations, and dependencies. It ensures documentation reflects the actual repository state, avoiding drift from outdated claims.

## Key Features
- Evidence-first auditing prioritizes executable source code and active configurations over unverified README claims.
- Classifies technologies into 6 evidence levels (ACTIVE, CONDITIONAL, IMPORTED, CONFIGURED, INSTALLED, ABSENT) to ensure accuracy.
- Dynamically inspects router architecture, runtime modes, dependencies, data layers, and authentication integrations.
- Supports monorepo scoping (Turborepo, pnpm workspaces) and package-specific audits without cross-contamination.
- Includes a validation script to ensure the skill's own structural hygiene and adherence to guidelines.

## Why It Matters for RAG Builders
It ensures AI and RAG systems interact with accurate, up-to-date documentation by validating repository evidence, reducing hallucinations from outdated or misleading READMEs.
