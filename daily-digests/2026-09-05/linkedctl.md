## Summary
LinkedCtl provides a CLI and MCP server for interacting with the LinkedIn API, enabling OAuth2 authentication, content creation, analytics, and organization management. It supports rich media uploads, drafts, and AI assistant integration via MCP.

## Key Features
- Full OAuth2 CLI and MCP server for LinkedIn API integration
- Rich content creation (posts, comments, reactions) with media support
- Organization management and posting as an organization
- Comprehensive analytics for posts, members, and organizations
- Multi-profile support with YAML-based configuration and environment variable overrides
