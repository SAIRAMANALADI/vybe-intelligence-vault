## Summary
Elffuss Code is a browser-based VS Code-style IDE that integrates an AI agent capable of reading, searching, and editing local projects entirely within the user's browser. It leverages WebGPU for local model inference and the File System Access API to ensure code never leaves the user's machine.

## Key Features
- Full-featured VS Code-like IDE running entirely in the browser with Monaco editor
- AI agent performs real tool-calling (read, search, edit) locally without cloud dependency
- Supports local model inference via WebGPU (Gemma-4, Qwen2.5-0.5B) with optional cloud provider fallback
- Zero install, zero build — runs via vanilla ES modules and static server
- Optional local terminal bridge for executing real commands (node, npm, python) on the user's machine

## Why It Matters for RAG Builders
It enables privacy-preserving, fully local AI-assisted code editing and debugging within a familiar IDE environment, reducing reliance on cloud-based AI services.
