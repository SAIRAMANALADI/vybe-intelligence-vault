## Summary
A research prototype for a 12-agent multi-agent system designed to deliver personalized learning experiences through specialized agent collaboration, event-driven architecture, and self-improvement loops. It serves as the foundation for the production-grade Veritas-Core system.

## Key Features
- 12 specialized agents collaborating via EventBus for task delegation and coordination
- 6-dimensional student profiling and personalized learning path generation
- 6 types of dynamically generated learning resources (notes, mind maps, exercises, code labs, video scripts, reading)
- Self-improvement loop with MetaReflector and ImprovementLoop for continuous agent refinement
- Content safety via 3-tier ReviewGate (static, dynamic, and LLM-based validation)

## Why It Matters for RAG Builders
It demonstrates how multi-agent collaboration can enhance personalized learning workflows, offering a research-backed foundation for building scalable, explainable agent systems in AI engineering.
