## Summary
PromoShot is an open-source rendering engine and CLI tool for creating video content from a declarative JSON project format (.promo). It enables AI agents to author, validate, and render video projects consistently across platforms, including headless environments, using wgpu and ffmpeg.

## Key Features
- Open `.promo` project format for consistent video rendering across platforms
- CLI and MCP server for AI agent integration and automation
- Headless rendering support (Linux without GPU) via wgpu and lavapipe
- Media validation, inspection, and rendering (stills, frames, video, GIF)
- Narration synthesis with provider key management (OpenAI, ElevenLabs, Google)

## Why It Matters for RAG Builders
It provides a standardized, agent-friendly interface for generating video content from structured prompts, enabling seamless integration into RAG pipelines for multimedia output.
