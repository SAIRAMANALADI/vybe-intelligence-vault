## Summary
AgenThink is a step-by-step learning project that builds AI agents from basic chatbots to production-ready systems, covering core concepts like tool use, RAG, memory, planning, and multi-agent collaboration using LangGraph and FastAPI.

## Key Features
- Progressive learning path from chatbot to autonomous agent
- Supports tool calling, RAG, long-term memory, and planning
- Built-in rate limiting, caching, and authentication for production
- Multi-agent workflows with specialized roles (researcher, coder, etc.)
- Streaming responses and conversation memory with SQLite

## Why It Matters for RAG Builders
It provides a structured, hands-on approach to building advanced AI agents with essential RAG and tool-use capabilities, making it invaluable for developers learning agentic systems.
