## Summary
SecNews is a single-user local workstation designed for AI + security practitioners, featuring a three-layer workflow (Data/Judge/Action) and exposing 19 MCP tools for seamless integration with external AI agents like Cursor, Claude Desktop, and Trae.

## Key Features
- Sentinel Terminal three-layer workflow (Data/Judge/Action) for structured workflow automation
- Exposes 19 MCP tools (11 read + 8 write) for zero-config integration with external AI agents
- LLM-wiki-first knowledge base with md files as source of truth and SQLite for indexing
- 14 domain-specific data collectors (security, AI, finance, GitHub, etc.) with pipeline processing
- CodeGarden resource hub for project lifecycle management and AI collaboration
