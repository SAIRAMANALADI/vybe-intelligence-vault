## Summary
An MCP (Model Context Protocol) server for Metacritic that enables searching films, shows, and games, retrieving Metascores and critic reviews with attribution, and browsing rankings without requiring an API key or account.

## Key Features
- Search titles (films, shows, games) with compact results including Metascores
- Retrieve detailed entry information, awards, production details, and critic reviews with publication attribution
- Browse rankings by score, release date, or popularity
- No API key, account, or configuration required
- Built-in caching, rate limiting, and error handling for reliable performance

## Why It Matters for RAG Builders
It provides structured, attributed critic reviews and scores from Metacritic, enabling RAG systems to enrich responses with reliable media metadata and expert opinions without requiring API keys or complex setup.
