## Summary
Omnigent is an open-source meta-harness that provides a unified orchestration layer for multiple AI agents (e.g., Claude Code, Codex, Cursor, Pi) and their environments. It enables seamless swapping of agent harnesses, real-time collaboration, policy enforcement, and sandboxed execution across various cloud providers.

## Key Features
- Unified orchestration layer for multiple AI agents (Claude Code, Codex, Cursor, Pi, etc.) with seamless harness swapping
- Real-time collaboration across devices (terminal, browser, phone) with synchronized sessions and files
- Cloud sandbox integration with providers like Modal, E2B, Databricks, and Kubernetes for disposable execution environments
- Policy-based governance for agent actions, including spend caps, approval workflows, and tool access restrictions
- Cross-platform support (macOS, Linux, Windows/WSL) with native desktop app and CLI for flexible deployment

## Why It Matters for RAG Builders
Omnigent simplifies the integration and management of diverse AI agents and their environments, reducing complexity for RAG builders who need reliable, scalable, and policy-compliant agent orchestration.
