## Summary
Carl is a local-first Rust-based coding agent and open-source agent harness designed for deterministic, secure, and replayable AI-driven coding workflows. It integrates with provider-owned subscriptions (e.g., ChatGPT, Grok) and supports durable sessions, explicit permission boundaries, and local memory management.

## Key Features
- Durable and replayable event-driven architecture with SQLite persistence
- Explicit permission boundaries and single-use approvals for safety
- Provider-owned subscription authentication (OpenAI, Grok) without API key fallbacks
- Local curated memory with scoped isolation and bounded retrieval
- ACP-compatible execution path for integration with clients like Buzz

## Why It Matters for RAG Builders
Carl provides a secure, local-first foundation for building AI coding agents with explicit permission controls and durable session management, critical for RAG systems requiring trustworthy tool integration.
