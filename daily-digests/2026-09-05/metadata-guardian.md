## Summary
An AI-powered autonomous metadata maintenance agent for DataHub that monitors GitHub repositories for schema changes, detects stale metadata using LLMs (Claude/GPT-4o), generates correction proposals, and writes them back to DataHub with optional human review via Slack.

## Key Features
- Autonomous detection of stale metadata in DataHub using LLMs
- GitHub webhook integration for real-time schema change monitoring
- Multi-stage LangGraph agent pipeline with confidence-based routing (auto-approve, Slack review, reject)
- Human-in-the-loop review via Slack Block Kit for low-confidence proposals
- PostgreSQL-backed event tracking, proposal management, and audit logging

## Why It Matters for RAG Builders
It automates metadata maintenance in DataHub by leveraging LLMs to detect and correct stale schema information, reducing manual effort and improving data reliability for AI and analytics pipelines.
