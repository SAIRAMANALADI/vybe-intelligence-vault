## Summary
PactKit is a governance framework enforcing the P.A.C.T. contract between humans and AI agents, ensuring deterministic operations run as code while AI handles creativity. It provides a structured PDCA lifecycle with 9 specialized agents, 10 skills, and 45 CLI subcommands for multi-IDE deployment (Claude Code, OpenCode, Codex CLI).

## Key Features
- Enforces P.A.C.T. governance principles (Prompt, AI, Code, Truth) for AI-agent interactions
- Supports 9 specialized agents and 10 skills for automated workflows (Plan-Act-Check-Done)
- Deploys to 3 major AI coding IDEs (Claude Code, OpenCode, Codex CLI) via `pactkit init`
- Provides 45+ CLI subcommands for deterministic operations (e.g., `pactkit spec-lint`, `pactkit regression`)
- Includes safety mechanisms like tamper guards, protected-branch push gates, and fail-closed rules

## Why It Matters for RAG Builders
