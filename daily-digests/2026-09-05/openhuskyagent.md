## Summary
OpenHuskyAgent is a metadata-driven, Java-based agent runtime platform built with Spring Boot, Spring AI, and LangGraph4j. It enables self-hosted AI agents with streaming output, tool calls, memory, knowledge retrieval, and multi-channel delivery for personal, enterprise, or chatbot use cases.

## Key Features
- Metadata-driven agent compute with dynamic behavior resolution per request
- Supports streaming output, tool calls, approvals, memory, and knowledge retrieval
- Multi-channel delivery including HTTP SSE, Feishu, Telegram, Slack, and TUI
- Modular architecture with layered Java modules, tool providers, and scenes
- Persistent memory, session management, and MCP integration

## Why It Matters for RAG Builders
OpenHuskyAgent provides a flexible, self-hosted framework for building and deploying customizable AI agents with dynamic behavior resolution, making it essential for developers seeking full control over agent logic and integrations.
