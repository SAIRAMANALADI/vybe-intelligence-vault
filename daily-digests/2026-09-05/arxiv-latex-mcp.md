## Summary
An MCP server that enables AI assistants like Claude Desktop to fetch and process arXiv papers directly from their LaTeX source code, improving accuracy in interpreting mathematical equations and notations. It leverages the `arxiv-to-prompt` library to handle downloading and processing.

## Key Features
- Fetches LaTeX source from arXiv for precise equation interpretation
- Provides MCP tools for abstracts, sections, and full paper content
- Supports multiple AI clients (Claude Desktop, Cursor, etc.)
- Lightweight and easy to install via PyPI or MCP extensions
- Enhances RAG pipelines by improving mathematical content accuracy
