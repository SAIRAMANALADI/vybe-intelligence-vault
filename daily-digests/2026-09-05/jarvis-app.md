## Summary
JARVIS is an open-source, self-hosted AI workspace and agent harness that runs entirely on your local machine. It integrates chat, notes, calendar, email, tasks, and automations into a unified system with pluggable AI models and a portable markdown-based memory vault.

## Key Features
- Unified workspace for chats, notes, calendar, email, and tasks with a single memory vault in markdown files
- Supports multiple AI models (Claude, OpenAI-compatible, local models via Ollama or llama.cpp) with per-conversation model selection
- Built-in automations (Daily Brief, tidy-up jobs) and scheduled tasks with output delivery to connected channels
- Remote access via Tailscale with HTTPS and optional authentication (including 2FA) for secure local network exposure
- Self-contained desktop app with bundled Python runtime, automatic updates, and portable data storage

## Why It Matters for RAG Builders
JARVIS provides a fully local, portable, and customizable agent framework that eliminates dependency on cloud services while offering deep integration with markdown-based memory systems essential for RAG pipelines.
