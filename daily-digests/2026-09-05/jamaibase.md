## Summary
JamAI Base is an open-source RAG backend platform that integrates an embedded SQLite database with LanceDB for vector storage, offering managed memory, RAG capabilities, and LLM orchestration through a spreadsheet-like UI and REST API.

## Key Features
- Embedded SQLite and LanceDB integration for vector storage and retrieval
- Declarative paradigm for defining AI workflows without procedural code
- Built-in LLM, embeddings, and reranker orchestration with multi-model support
- Spreadsheet-like UI for dynamic data generation, chatbots, and knowledge tables
- Hybrid search, query rewriting, and adaptive chunking for enhanced RAG performance

## Why It Matters for RAG Builders
It simplifies RAG pipeline construction by providing an all-in-one platform with embedded databases, LLM orchestration, and a user-friendly interface, reducing development time and complexity for AI stack builders.
