## Summary
A ComfyUI sidebar agent panel that integrates autonomous AI agents (Claude or ChatGPT) to dynamically edit workflows, install custom nodes, and manage ComfyUI via natural language commands. Operates on the user's own subscription with no additional API keys or LLM costs.

## Key Features
- Autonomous AI agent embedded in ComfyUI sidebar for real-time graph editing and workflow management
- Supports both Claude and ChatGPT providers with no API keys required (runs on user's subscription)
- Multi-language UI (12 languages) with automatic ComfyUI language alignment and RTL support
- Live-canvas building with undoable edits, one-shot workflow loading, and installer pack integration
- Durable workflow chat history, rewind/rollback, and autonomous install-restart-continue workflows

## Why It Matters for RAG Builders
It provides a seamless, natural language interface for AI agents to dynamically interact with and modify ComfyUI workflows, reducing manual effort and accelerating creative and technical workflows for RAG and AI stack builders.
