## Summary
A CLI tool that converts database schemas into the human-readable Toon format for database design documentation and visualization. It extracts schema metadata, relationships, and examples from multiple database systems (PostgreSQL, SQLite, DuckDB, MySQL/MariaDB, CockroachDB) and outputs structured, annotated definitions.

## Key Features
- Supports multiple database dialects (PostgreSQL, SQLite, DuckDB, MySQL/MariaDB, CockroachDB)
- Extracts tables, columns, constraints, indexes, and comments with type normalization
- Preserves foreign key relationships and generates human-readable Toon format output
- Includes optional sample row extraction for documentation and LLM context
- Provides both CLI and Go API for programmatic schema extraction

## Why It Matters for RAG Builders
It simplifies database schema documentation for AI systems by converting raw database schemas into a structured, human-readable format that can be easily ingested by LLMs for RAG applications.
