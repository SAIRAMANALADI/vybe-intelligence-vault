## Summary
A teaching repository demonstrating how to build a WhatsApp-backed bot using LangGraph. The first iteration implements a simple echo bot that uppercases messages, showcasing core LangGraph concepts like state management and graph execution.

## Key Features
- Demonstrates LangGraph fundamentals with a minimal echo bot implementation
- Modular architecture with clear separation of concerns (state, graph, webhook bridge)
- Step-by-step tutorial for building WhatsApp-integrated AI agents
- Uses Docker for containerized OpenWA gateway and local Python environment
- Showcases state management and graph execution patterns for AI agents
