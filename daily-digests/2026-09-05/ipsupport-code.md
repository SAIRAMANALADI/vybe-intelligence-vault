## Summary
A self-learning local coding agent designed for LM Studio, enabling autonomous task execution via a reason-act-observe loop. It supports local and OpenAI-compatible models, sub-agent delegation, and interactive TUI-based workflows for micro-tasks on your machine.

## Key Features
- Self-learning loop with lesson retention and error recovery
- Supports local models (LM Studio) and any OpenAI-compatible provider
- Sub-agent delegation for parallel task execution across models
- Interactive TUI with plan/auto modes, syntax-highlighted diffs, and live tool streaming
- Permission policies, workspace jails, and budget controls for safety

## Why It Matters for RAG Builders
It provides a lightweight, self-improving agent framework for local LLM tasks, reducing dependency on cloud APIs while enabling autonomous workflows with guardrails.
