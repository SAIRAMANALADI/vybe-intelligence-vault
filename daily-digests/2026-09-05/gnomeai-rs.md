## Summary
GnomeAI-RS is a self-hosted, open-source personal AI agent written in Rust, featuring a terminal-based TUI, web interface, and optional WhatsApp integration. It supports multiple LLM providers, persistent memory, skill management, and secure execution with explicit permissions.

## Key Features
- Native Rust skill system with installable skills from local or Git sources
- Persistent memory engine using SQLite with deduplication and semantic search
- Multi-provider LLM support with configurable access modes (normal/full-access)
- Terminal TUI and web interface with WhatsApp integration for cross-platform access
- Secure execution sandbox with sudo-like permissions and provider-scoped API keys

## Why It Matters for RAG Builders
GnomeAI-RS provides a robust, self-hosted agent framework with advanced memory and skill management, enabling developers to build secure, multi-provider AI assistants with persistent context and fine-grained execution control.
