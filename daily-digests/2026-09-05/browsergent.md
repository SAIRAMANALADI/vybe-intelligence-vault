## Summary
Browsergent is an experimental Chrome extension that provides an AI-powered agent for browser automation, enabling natural-language task execution directly within a Chrome side panel. It integrates with Anthropic-compatible LLMs to reason, generate JavaScript, and interact with web pages autonomously.

## Key Features
- Natural-language task execution with LLM reasoning and JavaScript generation
- Sandboxed JavaScript runtime for secure page interactions
- Multi-provider support for Anthropic, DeepSeek, and compatible APIs
- Interactive trace view for debugging and observing agent actions
- File management and attachment capabilities within the side panel

## Why It Matters for RAG Builders
Browsergent enables AI-driven browser automation with a focus on security and extensibility, making it essential for developers building RAG systems that require real-world web interaction capabilities.
