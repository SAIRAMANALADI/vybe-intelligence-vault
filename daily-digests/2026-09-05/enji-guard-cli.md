## Summary
enji-guard-cli provides a command-line interface (CLI) and Model Context Protocol (MCP) surface for Enji Guard, enabling automated repository audits, findings analysis, and portfolio management without requiring a browser UI. It supports unattended agent workflows, structured JSON output, and Docker-based deployment for centralized credentials.

## Key Features
- Unattended audit execution and findings retrieval via CLI, enabling agent-driven workflows without UI interaction
- Dual surfaces: full-featured CLI for operators and read-only MCP for agents requiring only repository insights
- Structured JSON output for machine-readable results, facilitating integration with AI agents and automation pipelines
- Explicit scope control for batch operations (single repo, project, or all projects) with confirmation prompts to prevent unintended changes
- Docker-based deployment for centralized credential management and runtime isolation, reducing configuration overhead

## Why It Matters for RAG Builders
It enables AI agents to autonomously audit repositories, analyze findings, and prioritize fixes without manual intervention, streamlining RAG pipeline maintenance.
