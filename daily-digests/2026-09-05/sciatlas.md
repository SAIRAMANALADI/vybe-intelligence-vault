## Summary
SciAtlas provides a pip-installable client and CLI for literature-grounded scientific research workflows using a large-scale hosted knowledge graph. It enables graph-aware paper search, automated literature reviews, idea evaluation/generation, and trend analysis with reproducible machine-readable outputs.

## Key Features
- Graph-aware paper search leveraging a large-scale scientific knowledge graph
- Automated literature review, idea evaluation, and trend analysis workflows
- Reproducible machine-readable artifacts (JSON, Markdown, TXT) for downstream tasks
- Editable CLI skills and portable agent skill packs for integration with coding agents
- Hosted API with minimal setup required (pip install + API token)

## Why It Matters for RAG Builders
