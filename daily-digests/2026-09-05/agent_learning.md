## Summary
A bilingual, engineering-first textbook and learning repository for building reliable LLM-based AI agents from scratch, covering foundational concepts, core capabilities, frameworks, multi-agent systems, and production deployment with visual diagrams and interactive demos.

## Key Features
- Structured 23-chapter curriculum covering agent fundamentals to production deployment
- Bilingual content (English and Chinese) with 188 pages per language
- 330+ original SVG diagrams and 5 interactive demos for visual learning
