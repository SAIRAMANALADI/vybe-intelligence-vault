## Summary
A collection of .NET samples demonstrating how to implement and use the Model Context Protocol (MCP) in applications. These samples showcase MCP servers for integrating LLMs with tools like GitHub Copilot, Outlook, and to-do lists, enabling standardized AI context provisioning.

## Key Features
- Provides .NET implementations of MCP servers for real-world integrations (e.g., GitHub Copilot, Outlook, to-do lists)
- Demonstrates standardized AI context provisioning via MCP
- Supports deployment in VS Code, Visual Studio, and Docker
- Includes sample projects for building custom MCP servers
- Open-source with Microsoft Foundry backing
