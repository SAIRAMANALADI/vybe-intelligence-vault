## Summary
Ontology Atlas is a local-first desktop and web application that creates a human-and-agent-readable ontology of a codebase using Markdown files. It enables understanding, reviewing, and managing codebase structure, capabilities, dependencies, and impact through a visual graph and MCP/CLI interfaces.

## Key Features
- Maintains a Markdown-based ontology folder (`atlas/`) inside the repository for human and AI agent collaboration
- Provides a visual graph of codebase capabilities, domains, dependencies, and unknowns
- Offers MCP and CLI interfaces for AI agents to query and update the ontology
- Supports export to standard graph formats (JSON-LD, GraphML) for integration with external tools
- Includes scaffolding for agent skills and procedures within the repository

## Why It Matters for RAG Builders
It bridges the gap between AI agents and human reviewers by providing a structured, reviewable map of a codebase's meaning, dependencies, and impact, ensuring AI-driven changes are aligned with human-approved architecture.
