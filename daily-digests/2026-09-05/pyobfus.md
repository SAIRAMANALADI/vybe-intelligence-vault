## Summary
pyobfus is a modern, AST-based Python code obfuscator designed for AI-assisted debugging and secure deployment. It provides framework-aware presets, reverse stack-trace mapping, and machine-readable JSON CLI outputs for seamless integration with AI coding agents like Claude Code and Cursor.

## Key Features
- AST-based obfuscation with name mangling, string encoding, and control-flow flattening
- Reverse stack-trace mapping for AI-assisted debugging without reversing obfuscation
- Framework-aware presets (FastAPI, Django, Flask, Pydantic, etc.) with built-in exclusions
- Machine-readable JSON CLI outputs with AI-friendly hints for agent integration
- Pro edition features including AES-256 string encryption, anti-debugging, and license embedding
