## Summary
A quantitative AI stock selection framework that simulates debates between Warren Buffett (bear) and Charlie Munger (bull) to generate daily stock reports with multi-dimensional scoring and technical analysis using Elliott Wave, Chan theory, and value metrics.

## Key Features
- Multi-persona AI debate (Buffett vs. Munger) for balanced stock analysis
- Three-dimensional scoring system (company quality 45%, trend 30%, valuation 25%)
- Integration of Elliott Wave, Chan theory, and traditional TA for technical analysis
- Automated daily report generation in Markdown/JSON formats
- Configurable stock pools and industry filters for targeted analysis
