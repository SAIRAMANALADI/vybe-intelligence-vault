## Summary
A Model Context Protocol (MCP) server for PTT (批踢踢實業坊) that enables automated interactions with the PTT platform via MCP-compatible clients. Built on the PyPtt library, it facilitates login, article management, interactions, and financial operations on PTT.

## Key Features
- Enables MCP clients to interact with PTT via standardized protocol
- Supports automated login, article management, and financial operations
- Provides Docker-based deployment for simplified setup
- Offers multi-account management for PTT credentials
- Integrates with PyPtt for robust PTT functionality
