## Summary
phasekit enables structured, unattended refactoring workflows by breaking down large codebase changes into manageable phases, each executed as a separate headless agent session on its own git branch. It enforces commit-level gates, ensures reproducibility, and provides real-time monitoring of progress.

## Key Features
- Phased execution of refactoring tasks with one commit per task and pre-commit gate verification
- Unattended agent sessions with session pinning to avoid usage limits and connection drops
- Real-time dashboard for tracking progress, pace, and remaining work
- Auto-sequencing for unattended execution with model selection and stop conditions
- Cross-platform support with OS-specific mechanisms for notifications and sleep prevention

## Why It Matters for RAG Builders
It transforms chaotic agent-driven refactoring into a structured, reviewable, and reversible process by enforcing commit-level gates and phase isolation.
