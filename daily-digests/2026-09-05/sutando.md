## Summary
Sutando is an autonomous AI agent framework designed to act as a personal assistant that learns user patterns, automates tasks, and evolves over time. It integrates voice, vision, screen interaction, and multi-channel communication (phone, Zoom, Discord, Telegram) to perform real-time tasks and self-improve through autonomous build loops.

## Key Features
- Real-time voice and screen interaction with direct text replacement and task execution
- Multi-channel communication (phone, Zoom, Discord, Telegram, browser) with unified memory and context
- Autonomous build loop that learns user patterns, detects anomalies, and generates its own capabilities
- Cross-machine scalability with self-coordinated setup and task migration
- HMAC-enveloped task integrity and durable delivery core for reliable outbound work
