## Summary
agent-chat-gateway is a middleware solution that bridges AI agents (e.g., Claude Code, OpenCode) with team chat platforms like Rocket.Chat and Mattermost, enabling multi-user access to agents without requiring terminal usage or code modifications.

## Key Features
- Connects AI agents to team chat platforms (Rocket.Chat, Mattermost, Slack, Discord)
- Supports user-aware responses with role-based permissions and human oversight for sensitive actions
- Enables multi-agent collaboration and session continuity across chat rooms
- Includes built-in task scheduling and file attachment handling
- Provides experimental voice gateway support via iOS Shortcuts

## Why It Matters for RAG Builders
It democratizes AI agent access for teams by integrating them directly into existing chat workflows, reducing friction and enabling scalable, role-controlled interactions.
