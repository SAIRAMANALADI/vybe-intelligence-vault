## Summary
Roslyn Workbench MCP is a local stdio MCP server that enables safe, transactional C# code analysis and refactoring using Roslyn. It supports persistent multi-workspace sessions, semantic queries, and source changes managed through transactions with preview, history, and rollback capabilities.

## Key Features
- Local stdio MCP server for Roslyn-powered C# code analysis
- Persistent multi-workspace sessions with semantic queries
- Transactional source changes with preview, history, rollback, and crash recovery
- Bounded agent-facing results and safe transaction boundaries
- Support for Code Actions within transactional workflows

## Why It Matters for RAG Builders
It provides a secure and transactional way to analyze and refactor C# code programmatically, essential for AI agents needing reliable code manipulation capabilities.
