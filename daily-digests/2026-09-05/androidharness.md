## Summary
AndroidHarness is a native Android app that provides a coding agent environment directly on mobile devices, enabling file editing, shell command execution, Git operations, and AI-driven chat interactions without requiring a PC.

## Key Features
- Native Android coding agent with Jetpack Compose UI
- Multi-tool support including file editing, shell commands, Git, and web tools
- Model Context Protocol (MCP) integration for extensibility
- Persistent workspace with sandboxed file access and GitHub authentication
- Real-time chat with streaming responses, tool call tracking, and slash commands

## Why It Matters for RAG Builders
It enables AI-driven coding agents to operate directly on mobile devices, expanding accessibility and flexibility for developers without requiring a PC.
