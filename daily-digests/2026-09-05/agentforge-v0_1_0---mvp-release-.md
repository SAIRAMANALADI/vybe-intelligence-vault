## Summary
AgentForge is a gamified AI agent development platform that simplifies building, managing, and deploying AI agents with an RPG-like interface. It reduces setup time from hours to minutes by offering drag-and-drop agent creation, real-time monitoring, and enterprise-grade features like RBAC and analytics.

## Key Features
- 5-minute agent creation with drag-and-drop templates and RPG-style progression
- Real-time monitoring with 30-second heartbeat checks and 6-factor vitality scoring
- Enterprise-grade security with RBAC (4 roles, 36 permissions), HMAC-SHA256 webhook verification, and data encryption
- Analytics dashboard with 9 API endpoints, AI-powered trend prediction, and multi-format exports (PDF/CSV/JSON)
- PVP arena, skill trees, and automatic agent evolution with 20+ rules and 5 rarity tiers
