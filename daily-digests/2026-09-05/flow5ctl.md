## Summary
flow5ctl is an AI-driven toolkit that enables AI agents to design and analyze low-Reynolds-number aircraft using the flow5 aerodynamic solver. It provides both an MCP server and CLI for high-level aircraft design tasks, abstracting complex XML workflows into human-readable YAML configurations.

## Key Features
- High-level aircraft design abstraction via YAML configurations, eliminating manual XML editing
- MCP server and CLI front-ends for seamless integration with AI agents (e.g., Claude Desktop) and human workflows
- Automated geometry computation, XML generation, and validation for flow5 solver inputs
- Caching of 2D airfoil polars and structured result summaries for AI agent reasoning
- Comprehensive error handling and diagnostics for flow5 solver quirks and edge cases

## Why It Matters for RAG Builders
It bridges the gap between AI agents and specialized aerodynamic solvers like flow5, enabling automated aircraft design workflows for low-Reynolds-number applications such as human-powered aircraft, RC gliders, and small UAVs.
