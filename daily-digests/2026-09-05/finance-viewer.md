## Summary
Finance Viewer is a local-first, human-in-the-loop financial review workspace that integrates external AI agents to process bank statements, classify transactions, and maintain audit trails. Users review and correct AI suggestions, while the system learns from corrections to improve future classifications without exposing sensitive financial data.

## Key Features
- Local-first architecture with SQLite for data storage, ensuring privacy and control over financial data.
- Human-in-the-loop workflow where AI prepares transactions and users review low-confidence or ambiguous entries.
- Rule-based learning system that refines classifications over time based on user corrections and historical data.
- Comprehensive audit trails that track modifications, rule changes, and reasoning for transparency.
- Modular design allowing integration with external AI agents (e.g., Claude Code, Codex) without vendor lock-in.

## Why It Matters for RAG Builders
It provides a privacy-preserving, AI-assisted workflow for financial data processing that bridges the gap between raw transaction data and actionable insights while maintaining human oversight and auditability.
