## Summary
AI Workspace Hub transforms AI agents like Codex, Claude Code, Cursor, and Cline into persistent research workspaces with long-term memory and automated workflows. It enables structured research, hypothesis tracking, and evidence-based decision-making without requiring API keys for core functionality.

## Key Features
- Six out-of-the-box capabilities: wiki ingestion, research drafting, hypothesis tracking, screening, daily monitoring, and podcast summarization
- Core Mode operates without API keys, with optional enhanced features requiring LLM or market data sources
- Persistent research workflows with unique IDs for studies, hypotheses, evidence, and pending actions
- Automated workflows for stock research, hypothesis validation, and daily tracking with structured outputs
- Seamless integration with Obsidian and Markdown-based knowledge management

## Why It Matters for RAG Builders
It provides a structured framework for AI agents to maintain long-term research workflows, reducing context loss and enabling evidence-based decision-making without requiring complex API integrations.
