## Summary
A high-performance MCP server that indexes codebases into a persistent knowledge graph using tree-sitter AST analysis and Hybrid LSP semantic resolution. Enables sub-millisecond structural queries and supports 162 programming languages with zero dependencies, running as a native executable.

## Key Features
- Indexes entire codebases (e.g., Linux kernel) in minutes with sub-millisecond query responses
- Supports 162 programming languages via embedded tree-sitter grammars
- Hybrid LSP semantic resolution for 10+ languages (Python, TypeScript, Java, etc.)
- 15 MCP tools for structural queries, impact analysis, dead code detection, and more
- Built-in 3D graph visualization UI and session coordination daemon for multi-agent support

## Why It Matters for RAG Builders
It drastically reduces token usage and tool calls for RAG systems by replacing file-by-file exploration with a persistent, queryable knowledge graph of codebase structure and semantics.
