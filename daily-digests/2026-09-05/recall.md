## Summary
Recall is a long-term semantic memory system designed as external working memory for AI coding assistants, addressing context window limitations by providing dual-mode retrieval (semantic and episodic) through vector embeddings. It enables persistent memory across sessions without cloud dependencies.

## Key Features
- Dual-mode retrieval (semantic + episodic) for fuzzy and chronological memory access
- Zero cloud dependencies with local storage options (embedded or network mode)
- Multi-project support with Docker-based Qdrant for concurrent project memory
- Automated backups and recovery for production reliability
- Privacy-focused design with explicit memory storage and private tagging

## Why It Matters for RAG Builders
Recall provides a critical solution for AI coding assistants by enabling persistent, context-aware memory across sessions, reducing token overhead and improving decision consistency without relying on cloud services.
