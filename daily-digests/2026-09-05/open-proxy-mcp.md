## Summary
OpenProxy MCP is a Model Context Protocol (MCP) server that provides structured access to Korean corporate disclosures (DART) for AI agents, enabling financial analysis, proxy voting advice, ownership mapping, and risk event tracking for Korean public companies.

## Key Features
- 26 specialized tools for Korean corporate disclosures (e.g., financial metrics, valuation, ownership structure, risk events, proxy voting advice)
- Integration with AI services (Claude, ChatGPT, Perplexity) via MCP for real-time corporate data analysis
- Automated parsing of DART public disclosures (financial statements, meeting agendas, ownership reports, risk events)
- Proxy voting guidance with structured recommendations (FOR/AGAINST/REVIEW) based on Open Proxy Guideline
- Risk monitoring and screening tools for corporate governance events (e.g., major accidents, embezzlement, shareholder disputes)
