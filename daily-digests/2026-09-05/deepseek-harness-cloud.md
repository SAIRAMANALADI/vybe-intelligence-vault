## Summary
DSH Cloud provides a managed cloud platform and self-hostable infrastructure for DeepSeek Harness, enabling account management, model gateways, usage policy enforcement, and team collaboration without distributing upstream model keys to clients. It supports both hosted and self-hosted deployments with a focus on security and operational control.

## Key Features
- Managed cloud and self-hostable platform for DeepSeek Harness with account, team, and policy management
- OpenAI/Anthropic-compatible model gateway with server-side upstream key handling and usage metering
- Support for 20+ models across multiple providers (DeepSeek, OpenAI, Anthropic, Google, etc.) and embeddings
- Flexible deployment options: hosted service, one-command local setup, Docker Compose, or single-container
- Built-in usage tracking, credit ledger, rate limiting, and team-based resource pooling

## Why It Matters for RAG Builders
It provides a critical abstraction layer for managing model access, usage, and security in RAG systems, enabling centralized control over multi-provider models and cost tracking.
