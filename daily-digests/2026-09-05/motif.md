## Summary
Motif is a self-hosted working memory system for AI coding agents that consolidates sessions from tools like Claude Code, Codex, and Cursor into a unified, queryable graph. It enables teams to remember, verify, and act on past decisions while resolving contradictions and automating follow-up actions like draft PRs.

## Key Features
- Consolidates AI coding sessions (Claude Code, Codex, Cursor) into a unified graph for recall and verification
- Self-hosted with no cloud dependency or telemetry, ensuring data privacy
- Automates conflict resolution and draft PR generation to align code with team decisions
- Enables agents to query past sessions directly via MCP for context-aware responses
- Provides a visual 'Weave' graph to map decisions, files, and sessions with confidence scoring

## Why It Matters for RAG Builders
Motif eliminates the fragmentation of AI agent sessions by creating a persistent, queryable memory layer that agents and humans can use to maintain consistency and context across projects and time.
