## Summary
An email-driven agentic system that processes incoming emails via an LLM agent to autonomously manage social connections, introductions, and event lifecycle. It operates without a predefined networking schema, relying instead on freeform memories and emergent behavior derived from system prompts and tools.

## Key Features
- Freeform memory store with pgvector embeddings for semantic recall and social graph construction
- Email-driven agentic engine with emergent behavior (no predefined workflows)
- Structural security model (THE SEAL) to prevent prompt injection and PII leakage
- Postgres-native job queue (Procrastinate) with no external broker dependency
- Privacy-preserving design with PII-stripped gists and opaque person IDs

## Why It Matters for RAG Builders
It demonstrates a novel approach to agentic systems using email as the primary interface, emphasizing privacy-preserving memory management and emergent social graph construction for real-world networking applications.
