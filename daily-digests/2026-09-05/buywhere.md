## Summary
BuyWhere API provides an agent-native product catalog for AI shopping agents, enabling search, comparison, and price tracking across 900,000+ merchants and 300M+ products in the US and Southeast Asia with MCP compatibility.

## Key Features
- BM25-ranked search with hybrid vector similarity for semantic queries
- MCP-compatible tools for seamless AI agent integration (Claude, Cursor, LangChain, CrewAI)
- Real-time deals discovery and affiliate link tracking
- Multi-region coverage (US, Singapore, Malaysia, Indonesia, Thailand, Philippines, Vietnam, Australia, Japan, Korea)
- Rate-limited API with Free, Live, and Partner tiers
