## Summary
Vex is a highly customizable Chromium-based desktop browser built on Electron with an integrated AI agent, privacy tools, and advanced features like Widevine DRM streaming, Tor integration, and pixel-perfect UI rearrangement.

## Key Features
- Built-in AI assistant with cloud, local, and on-device modes (Ollama/WebGPU)
- Widevine DRM support for Netflix, Spotify, and other streaming platforms
- Privacy tools including Tor integration, ad/tracker blocking, and fingerprint protection
- Pixel-perfect UI rearrangement, vertical/horizontal tabs, and split-screen functionality
- Autofill for passwords, 2FA codes, and email verification with encrypted storage

## Why It Matters for RAG Builders
Vex provides a unified platform for developers and users to integrate AI-driven browsing, privacy, and productivity features into a single, customizable browser environment.
