## Summary
Rewind is a personal data aggregation API that synchronizes data from multiple services (e.g., Strava, Last.fm, Plex) into a unified schema and serves it via a REST API with a cross-domain activity feed. It normalizes disparate data sources into a consistent format for easy consumption.

## Key Features
- Unified schema for disparate data sources (music, running, movies, books, events)
- Automated sync with scheduled updates from multiple services
- Type-safe API with end-to-end TypeScript inference and zero codegen
- Full OpenAPI 3.1 spec with interactive Scalar docs
- MCP server support for AI tooling integration

## Why It Matters for RAG Builders
Rewind simplifies the ingestion and normalization of diverse personal data sources, enabling AI systems to access structured, unified datasets for richer context and insights.
