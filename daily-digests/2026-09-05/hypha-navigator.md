## Summary
Hypha Navigator is a Chrome extension that enables AI agents to control an entire browser via Hypha RPC, exposing browser navigation, DOM manipulation, screenshots, and arbitrary JavaScript execution as an HTTP-callable service.

## Key Features
- Exposes browser control (tabs, navigation, screenshots) as an HTTP service for AI agents
- Enables DOM and React tree inspection with arbitrary JavaScript execution, even on strict-CSP pages
- Supports site-specific skill caching for AI agents to learn and reuse interactions
- Provides a self-documenting API with curl examples via `/get_skill_md` endpoint
- Offers CLI tool (`hyd`) for command-line browser control and scripting

## Why It Matters for RAG Builders
It provides a critical bridge for AI agents to interact with and automate web browsers, enabling real-world web-based tasks and data extraction at scale.
