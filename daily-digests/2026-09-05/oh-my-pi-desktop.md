## Summary
A Windows desktop GUI client for the Oh My Pi (omp) coding agent, providing a visual interface to interact with the agent via its RPC protocol. It renders streaming markdown chat, tool-call cards, todos, and sessions without handling authentication or agent logic directly.

## Key Features
- Streaming markdown chat with syntax highlighting and code block copy functionality
- Tool-call cards for real-time visualization of agent tool executions and results
- Session management grouped by project directory with incremental history loading
- Auto-update mechanism via GitHub Releases for seamless client updates
- Mid-turn control features like abort, steer, and follow-up message queuing

## Why It Matters for RAG Builders
It provides a user-friendly graphical interface for interacting with coding agents, enhancing accessibility and usability for developers who prefer GUI over terminal-based interactions.
