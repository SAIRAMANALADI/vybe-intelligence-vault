## Summary
ChengOS is a visual platform for building, running, and deploying AI workflows and agents with a Rust-based backend and React-based frontend. It supports multi-channel chat applications, terminal clients, and local document/RAG processing pipelines.

## Key Features
- Visual workflow editor with React Flow for building AI and automation workflows
- Native MCP support for dynamic tool discovery and integration
- Local document and RAG processing with built-in chunking and retrieval
- Multi-format Skill import and credential isolation for secure execution
- Cross-platform deployment with native, Docker, and terminal client options

## Why It Matters for RAG Builders
ChengOS provides a unified platform for building, testing, and deploying AI workflows and agents, reducing integration complexity for RAG and AI stack builders.
