## Summary
everyharness is an offline-first CLI and TUI tool that automates model harnessing for various AI/ML model types, including LLMs, embeddings, tabular data, vision, diffusion, and more. It detects model types, runs appropriate harnesses, serves HTTP endpoints, and scaffolds plugins for extensibility.

## Key Features
- Auto-detects and runs the correct harness for any model type (LLMs, embeddings, tabular, vision, diffusion, etc.)
- Offline-first operation with hard-blocked outbound calls via `EVERYHARNESS_OFFLINE=1`
- Plugin system for publishing and installing community-driven harnesses, loaders, and detectors
- Textual TUI for interactive model management and CLI/TUI integration
- Agent UI bridge to scaffold local web/GUI wrappers for coding agents (Cursor, Claude, etc.)

## Why It Matters for RAG Builders
It simplifies the integration and deployment of diverse AI models into production pipelines by automating harness selection and providing a unified interface for model execution and plugin extensibility.
