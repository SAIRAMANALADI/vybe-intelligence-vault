## Summary
GZA is a personal software factory that queues coding tasks for background agents to plan, implement, review, and test in parallel, then auto-merge what passes. It orchestrates AI-driven workflows for software development with a focus on automation and collaboration.

## Key Features
- Parallel task execution with concurrency limits and failure backoff
- Plan-review-implement-test lifecycle with auto-merge for approved tasks
- Live multi-task log dashboard (`gza tv`) for real-time monitoring
- Tag-based task grouping and async batch processing (`gza watch`)
- Provider-agnostic LLM integration with support for Claude Code and Codex

## Why It Matters for RAG Builders
GZA streamlines AI-driven software development by automating the end-to-end workflow of coding tasks, reducing manual intervention and accelerating iteration cycles for RAG builders.
