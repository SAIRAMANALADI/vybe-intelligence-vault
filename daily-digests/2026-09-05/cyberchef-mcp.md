## Summary
CyberChef-MCP is an MCP server that exposes GCHQ's CyberChef data manipulation toolkit as executable AI agent tools, enabling AI assistants to perform encryption, encoding, compression, and forensic analysis operations programmatically.

## Key Features
- Exposes 504+ CyberChef operations as MCP tools for AI assistants, including encryption, encoding, and forensic analysis.
- Supports multiple transports (stdio, HTTP, socket) with session management and CORS protection.
- Provides recipe management for saving, organizing, and reusing multi-operation workflows.
- Includes advanced features like batch processing, telemetry, caching, and worker thread offloading for performance.
- Offers tool annotations (read-only, destructive, idempotent hints) and search utilities for AI discovery.

## Why It Matters for RAG Builders
It bridges AI assistants with CyberChef's 504+ data manipulation operations, enabling secure, deterministic, and auditable data processing within RAG pipelines.
