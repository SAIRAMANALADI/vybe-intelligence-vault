## Summary
A Model Context Protocol (MCP) server that bridges Neovim with AI assistants, enabling structured interaction with editor diagnostics, LSP features, and dynamic tooling via stdio or HTTP transport modes.

## Key Features
- Multi-connection support for concurrent Neovim instances
- LSP integration with code actions, hover, and diagnostics
- Structured diagnostic data via MCP resources and URI schemes
- Multi-transport support (stdio and HTTP)
- Dynamic tool system for extensible custom tools
