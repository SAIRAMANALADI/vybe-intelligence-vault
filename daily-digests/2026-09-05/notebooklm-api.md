## Summary
An unofficial Python SDK, CLI, MCP server, and REST API for Google NotebookLM (Gemini Notebook) that enables programmatic automation, agentic RAG, and content generation. It provides reverse-engineered access to NotebookLM's features for AI-driven workflows, including audio/video overviews, slide decks, quizzes, and structured data extraction.

## Key Features
- Unofficial Python SDK for NotebookLM with async support and typed namespaces
- CLI with 50+ subcommands for automation and agent integration
- MCP server for AI agent integration (Claude, Codex, Antigravity)
- Supports audio/video overviews, slide decks, quizzes, and structured data exports
- Dual transport layer (web RPC and Android gRPC) for flexibility

## Why It Matters for RAG Builders
It enables AI engineers to programmatically integrate Google NotebookLM into RAG pipelines for grounded content generation, long-term memory, and agentic workflows with minimal token overhead.
