## Summary
N.O.L.A. is a self-hosted homelab AI assistant that monitors infrastructure, answers questions via Discord, and proactively alerts users via phone calls when critical issues arise. It integrates n8n, Claude, and Discord for workflow automation and AI-driven responses.

## Key Features
- Real-time infrastructure monitoring via Netdata, Prometheus, and UPS status checks
- Natural language interaction through Discord for querying and command execution
- Proactive alerts with optional phone calls for critical events using VAPI and ElevenLabs
- Modular workflows for SSH command execution, LibreNMS integration, and weekly health digests
- Self-hosted and extensible with customizable n8n workflows and tools

## Why It Matters for RAG Builders
N.O.L.A. provides a unified, AI-driven approach to homelab monitoring and automation, reducing manual oversight while enabling proactive incident response through voice and text alerts.
