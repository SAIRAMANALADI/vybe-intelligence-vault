## Summary
Pi Daemon provides a persistent server session for the Pi coding agent, exposing a mobile PWA via secure private or public tunnels. It integrates Tailscale Serve or Cloudflare Tunnel with Access policies to enable remote, authenticated interactions with the agent.

## Key Features
- Persistent Pi coding agent sessions with resumable state
- Mobile PWA interface with command discovery and filtering
- Secure private access via Tailscale Serve or public via Cloudflare Tunnel with exact-email Access policies
- Automated setup with OAuth PKCE or manual API token fallback
- Completion notifications via Web Push for session outcomes

## Why It Matters for RAG Builders
Pi Daemon enables secure, persistent remote access to AI coding agents via mobile or web interfaces, simplifying deployment and management for RAG builders.
