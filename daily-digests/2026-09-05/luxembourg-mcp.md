## Summary
Luxembourg MCP provides keyless Model Context Protocol (MCP) access to 15 Luxembourg public data systems, exposing 21 consistent tools for AI agents to query laws, statistics, mobility, environmental data, and more without API keys or scraping.

## Key Features
- 21 standardized MCP tools covering 15 public data systems in Luxembourg
- No API keys or accounts required for access
- Supports both Stdio and Streamable HTTP transports
- Validates tool arguments and upstream responses for safety
- Preserves source URLs for traceability and compliance

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate and query fragmented Luxembourg public data without authentication barriers, reducing integration overhead for RAG systems.
