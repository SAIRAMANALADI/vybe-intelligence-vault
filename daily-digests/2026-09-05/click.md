## Summary
Click is a Codex plugin that enforces contract-driven execution control for AI coding agents by binding approved intent to observable mutation authority and verifiable evidence. It ensures that software changes adhere to a compact, persistent contract approved by the user, preventing unauthorized modifications and enabling traceable completion.

## Key Features
- Turns software change requests into compact, persistent contracts with user approval
- Enforces mutation authority and evidence integrity at runtime via a state machine
- Separates proposal, approval, and implementation phases to prevent unauthorized changes
- Provides reusable, current-revision evidence for verification and completion
- Supports advisory workflow optimization while maintaining hard runtime guarantees

## Why It Matters for RAG Builders
Click ensures AI coding agents operate within approved boundaries and produce verifiable, traceable outcomes, reducing risks of unauthorized or inconsistent modifications in production environments.
