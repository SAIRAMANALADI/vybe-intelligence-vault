## Summary
VulnClaw is an AI-driven penetration testing CLI tool that automates the entire security testing workflow—from reconnaissance to vulnerability discovery, exploitation, and report generation—using natural language inputs and LLM agents with MCP toolchains.

## Key Features
- Autonomous penetration testing workflow with natural language input
- 13 LLM provider integrations (OpenAI, Anthropic, MiniMax, DeepSeek, etc.)
- MCP toolchain for browser automation, HTTP probing, and traffic analysis
- 50+ specialized security skills (CTF, Web, internal network, reverse engineering)
- Automated report generation with structured Markdown and Python PoC scripts

## Why It Matters for RAG Builders
It enables AI-driven security testing automation, reducing manual effort and accelerating vulnerability discovery for red teams, CTFs, and authorized assessments.
