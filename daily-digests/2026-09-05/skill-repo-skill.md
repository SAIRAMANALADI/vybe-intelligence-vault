## Summary
A standardized repository template and toolkit for creating, validating, and distributing AI agent skills across multiple platforms (Claude Code, Cursor, GitHub Copilot) with reusable CI workflows, split licensing, and packaging conventions.

## Key Features
- Standardized repository layout for AI agent skills with reusable templates
- Validation scripts for structural checks (SKILL.md, licenses, composer.json, plugin.json)
- Reusable GitHub Actions workflows for CI/CD (validation, release, dependency audits)
- Support for multi-channel distribution (Marketplace, Composer, npm, direct download)
- Split licensing (MIT for code, CC-BY-SA-4.0 for content) with compliance checks

## Why It Matters for RAG Builders
It ensures consistency and shippability of AI agent skills across repositories, reducing drift and simplifying CI/CD integration for RAG builders.
