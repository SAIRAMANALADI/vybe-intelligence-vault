## Summary
MCP server providing programmatic access to Contabo's cloud infrastructure API, enabling management of virtual machines, networking, storage, and security resources directly from MCP clients like Cursor or Claude Desktop.

## Key Features
- Full Contabo API coverage including VMs, snapshots, object storage, DNS, and secrets
- Seamless integration with MCP clients like Cursor and Claude Desktop
- Environment-based authentication for secure API access
- Automated tool discovery and resource management
- Active maintenance with recent feature additions and dependency updates

## Why It Matters for RAG Builders
It enables AI agents to directly manage and provision cloud infrastructure via Contabo's API, streamlining deployment workflows for RAG systems.
