## Summary
BrainOS is a SQLite-first cognitive memory core designed for LLM agents, providing a local, auditable memory system in a single SQLite file. It enables working memory, episodes, semantic structures, procedures, decisions, provenance, and bounded retrieval diagnostics for agentic workflows.

## Key Features
- Single SQLite file for all agent memory layers (working, semantic, episodes, procedures, decisions)
- Provenance ledger with chained hashes for auditability
- Bounded retrieval diagnostics and runtime checks
- Python API and local CLI for interaction
- Local-first design with minimal dependencies

## Why It Matters for RAG Builders
BrainOS provides a lightweight, auditable, and local-first memory system essential for building reliable RAG pipelines with agentic workflows.
