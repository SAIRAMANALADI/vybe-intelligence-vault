## Summary
A plugin providing Pine Script v6 validation and reference lookup for coding agents, ensuring generated TradingView scripts are syntactically correct and semantically valid. It integrates with multiple AI coding assistants to validate Pine Script code in real-time.

## Key Features
- Real-time Pine Script v6 validation with 7+ diagnostic checks for common errors like repainting signals, scope violations, and parameter mismatches
- Reference lookup for Pine Script v6 function signatures and overloads, ensuring accurate code generation
- Integration with multiple AI coding assistants (Claude Code, Antigravity, Codex, Kimi) via MCP and plugin systems
- Pre-commit hooks and CI/CD validation to ensure generated Pine Script adheres to TradingView's rules
- Modular skills for indicators, strategies, and validation patterns, reducing hallucination risks in agent-generated code
