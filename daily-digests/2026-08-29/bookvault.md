## Summary
BookVault is a local web application and MCP server that allows users to back up their legally purchased books and audiobooks from litres.ru. It provides a user-friendly interface to browse, select, and download titles in preferred formats, with support for live progress tracking and interruption.

## Key Features
- Backs up legally purchased books and audiobooks from litres.ru with user authentication
- Provides a local web app for browsing, selecting, and downloading titles in preferred formats
- Includes an MCP server for integration with AI assistants like Claude
- Supports live progress tracking and interruption of downloads
- Runs entirely locally with no external data sharing, ensuring privacy

## Why It Matters for RAG Builders
BookVault enables users to legally back up their purchased digital books and audiobooks for personal use, ensuring content accessibility and preservation while maintaining strict privacy and DRM compliance.
