## Summary
A stateless remote MCP server enabling AI agents to create and track Taiwan logistics shipments, including convenience store pickup (超商取貨) and home delivery (宅配), via the ECPay Logistics API. Supports real-time label generation and shipment tracking without storing sensitive data.

## Key Features
- Create 超商取貨 (CVS) and 宅配 (home delivery) shipments via ECPay API
- Real-time shipment tracking with status codes and plain-English hints
- Automated label generation and hosted label URLs for 託運單
- Zero-setup demo mode with fallback to ECPay test credentials
- Stateless design with BYO credentials and no data storage

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate Taiwan-specific logistics workflows, reducing manual intervention and accelerating automated shipping processes for local e-commerce and agent-based systems.
