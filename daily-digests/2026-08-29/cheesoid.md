## Summary
Cheesoid is a framework for deploying persistent AI personas with memory, state management, and a multi-user chat UI. It handles web interfaces, persistent storage, tool execution, and background tasks, enabling agents to perform roles like infrastructure monitoring or project management with secure tool access.

## Key Features
- Persistent memory and state across sessions
- Built-in tools for memory, wiki, tasks, and scheduling
- Secure tool access with credential brokering
- Multi-user chat UI with scrollback and threads
- Idle thoughts for background processing and reflection

## Why It Matters for RAG Builders
Cheesoid enables the creation of persistent, tool-equipped AI agents with memory and state management, critical for building robust RAG systems that require long-term context and secure tool integration.
