## Summary
dbt Sentinel is an AI-powered code reviewer for dbt model files that identifies issues like missing tests, unsafe patterns, performance smells, and hardcoded values, providing structured findings with severity tags and fix suggestions. It integrates seamlessly with GitHub Actions to annotate pull requests with inline comments.

## Key Features
- AI-driven review of dbt SQL models with structured findings tied to specific lines
- GitHub Actions integration for inline PR annotations without additional dashboards
- Supports multiple output formats: human-readable, JSON, and GitHub annotations
- Validates findings against line ranges, rule allowlists, and model context
- Includes eval harness for precision and recall metrics (Recall ≥ 0.80, Precision ≥ 0.85)

## Why It Matters for RAG Builders
It automates critical code review for dbt models, reducing manual effort and improving data pipeline reliability by catching issues early in the development cycle.
