## Summary
Mushi Mushi is an AI-powered debugging tool that provides plain-English diagnoses and paste-ready fixes for bugs in AI-built applications directly within code editors like Cursor and Claude Code. It captures user-reported issues, classifies them, and offers actionable insights without requiring additional LLM API keys or complex monitoring setups.

## Key Features
- Real-time bug diagnosis with plain-English root cause analysis and paste-ready fixes directly in your editor via MCP.
- Supports multiple frameworks (React, Vue, Svelte, Angular, React Native, vanilla JS) with SDKs for seamless integration.
- Self-hostable in under 5 minutes using Docker Compose or Helm, with a free hosted tier available.
- Knowledge graph (Postgres + pgvector) for aggregating and deduplicating bug reports to avoid noise.
- Optional auto-fix agent that opens draft PRs after sandboxed testing, reducing manual debugging time.

## Why It Matters for RAG Builders
Mushi Mushi bridges the gap between AI-generated code and real-world debugging by providing actionable insights and fixes directly in the developer's workflow, significantly reducing the time spent diagnosing silent UX bugs and non-thrown errors.
