## Summary
Vespa is an open-source AI search engine, big-data serving engine, and vector database that combines vector search, text search (BM25), structured filtering, and machine-learned ranking into a single distributed system. It supports hybrid search, tensor inference, and sub-100ms latency at scale, with both self-managed and fully managed cloud offerings.

## Key Features
- Unified search engine combining vector, text, and structured data retrieval
- Native support for tensor inference and machine-learned ranking
- Scalable distributed architecture with sub-100ms latency
- Hybrid search capabilities (BM25 + vector + filters)
- Multi-tenant support and zero-downtime deployments

## Why It Matters for RAG Builders
Vespa is essential for RAG builders because it provides a production-grade, scalable vector database with built-in hybrid search and ML ranking, eliminating the need to stitch together multiple tools for retrieval and ranking.
