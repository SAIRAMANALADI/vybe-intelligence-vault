## Summary
SCAINET Forge is a voice-first desktop application that enables AI agents to build, modify, and manage software projects without requiring manual coding. It provides real-time visibility into agent actions, governance via a 10-Article Constitution, and persistent agent identities for consistent development workflows.

## Key Features
- Voice-first interaction with built-in speech-to-text and text-to-speech
- Real-time audit trail and session replay for every agent action
- 10-Article Constitution for mechanically enforced governance rules
- Persistent agent identities (EGO) with memory for consistent workflows
- Built-in MCP marketplace with 10+ curated servers for extensibility

## Why It Matters for RAG Builders
It democratizes software development by enabling non-developers to build and manage projects via AI agents while ensuring governance, transparency, and auditability for RAG and AI stack builders.
