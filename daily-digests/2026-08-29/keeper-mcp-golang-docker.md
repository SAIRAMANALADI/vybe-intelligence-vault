## Summary
KSM MCP is a Model Context Protocol (MCP) server that securely bridges AI agents with Keeper Secrets Manager (KSM), enabling AI to manage secrets like records, folders, and files while protecting credentials. It enforces user confirmation for sensitive operations and supports Docker, binary, and CLI-based deployments.

## Key Features
- Secure intermediary between AI agents and Keeper Secrets Manager
- Supports secret and folder operations (create, read, update, delete) with user confirmation
- File management within secrets (upload/download)
- Password generation and TOTP code retrieval
- Multiple deployment options (Docker, binary, CLI) with configurable security settings

## Why It Matters for RAG Builders
It enables AI agents to securely interact with sensitive secrets without exposing credentials, bridging the gap between AI capabilities and enterprise security requirements.
