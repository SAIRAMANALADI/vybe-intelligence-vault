## Summary
An AI agent skill that enables intelligent search and recommendation of 10,000+ curated Nano Banana Pro (Gemini image model) prompts for AI assistants like Claude, OpenClaw, and Cursor. It provides semantic search, sample images, and content remix capabilities to generate tailored prompts.

## Key Features
- Semantic search across 10,000+ curated prompts with token-efficient grep
- Content remix mode to personalize prompts based on user-provided content
- Multi-language support with translated descriptions and English prompts
- Twice-daily automated updates from viral community prompts
- Sample images for every prompt to preview results before use

## Why It Matters for RAG Builders
It streamlines AI image prompt discovery and customization, saving time and improving output quality for RAG builders using image generation models.
