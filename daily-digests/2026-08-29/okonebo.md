## Summary
OkoNebo is a self-hosted weather dashboard and local API that aggregates real-time weather data, alerts, forecasts, radar, and environmental metrics into a single Docker service. It supports multi-provider fallback, keyless data sources, and optional authentication for secure access.

## Key Features
- Multi-provider fallback for weather data (NWS, WeatherAPI, Tomorrow.io, etc.) with keyless options
- Comprehensive API endpoints for current conditions, forecasts, alerts, METAR, tides, AQI, and PWS data
- Optional JWT-based authentication with role-based access control and rate limiting
- In-app setup panel for dynamic configuration without restarting the service
- Security-hardened with encrypted settings, non-root Docker container, and XSS mitigations

## Why It Matters for RAG Builders
OkoNebo provides a robust, self-hosted weather data aggregation service with multi-provider fallback, making it essential for AI systems requiring reliable environmental inputs without external API dependency risks.
