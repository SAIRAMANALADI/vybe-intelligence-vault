## Summary
A Claude Desktop extension that integrates Dorar.net's Hadith database, enabling users to search, analyze, and retrieve Hadith texts, isnād chains, Takhrīj, commentaries, and scholarly gradings in both Arabic and English directly within Claude.

## Key Features
- Search Hadith by Arabic text or English translation with high precision
- Retrieve isnād chains, Takhrīj, and commentaries (Sharḥ) for detailed analysis
- Access scholarly gradings of ahadeeth from Dorar.net
- Supports both Arabic and English output with faithful translations
- Seamless integration with Claude Desktop via MCP for real-time research
