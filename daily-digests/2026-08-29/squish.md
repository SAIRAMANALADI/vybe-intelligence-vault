## Summary
Squish is a local-first memory system for AI coding agents that provides persistent, scalable, and cross-agent memory management. It enables agents to retain context, decisions, and preferences across sessions without manual curation or token waste.

## Key Features
- Multi-tier memory system (Recall, Sessions, Remember) with durable and searchable layers
- Auto-capture of agent decisions, constraints, and context with minimal token overhead (50-200 tokens per query)
- Cross-agent compatibility via MCP and HTTP integrations with 15+ supported agents
- Knowledge graph reinforcement and decay-based memory management for relevance
- Local-first deployment with optional cloud sync and team features

## Why It Matters for RAG Builders
Squish eliminates the need for manual context management in AI coding agents by providing persistent, scalable memory that reduces token waste and enables cross-session continuity.
