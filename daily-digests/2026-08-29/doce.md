## Summary
doce is a fully local, zero-config AI coding agent for macOS that runs entirely on the user's machine, leveraging embedded llama.cpp for inference and a local SQLite database for state management. It provides a private, self-hosted alternative to cloud-based coding agents with tool-enabled capabilities.

## Key Features
- Fully local inference with embedded llama.cpp model
- Zero-config setup with automatic hardware-aware model selection
- Tool-enabled agent with file read/write, shell command execution, and iterative plan-and-execute loops
- MCP client integration for extensibility via custom servers
- Local persistence with full-text search across conversations

## Why It Matters for RAG Builders
It provides a privacy-preserving, local-first alternative to cloud-based coding agents, enabling developers to build and interact with AI tools without exposing sensitive code or data.
