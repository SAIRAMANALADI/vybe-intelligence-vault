## Summary
A lightweight Windows bridge that connects Telegram bots to local Claude Code installations, enabling users to send requests via Telegram and receive responses generated by running Claude Code directly on their machine without requiring a server or hosting subscription.

## Key Features
- Runs Claude Code locally on Windows without requiring a server or cloud hosting
- Secure permission-based execution with user approval for sensitive actions
- Portable package with Arabic/English setup guide and no local Node.js installation required
- Stateful session management with local memory for context persistence
- Built-in diagnostics, uninstallation, and configuration tools

## Why It Matters for RAG Builders
It enables secure, local execution of Claude Code via Telegram for AI engineers building RAG systems who need offline or privacy-preserving workflows.
