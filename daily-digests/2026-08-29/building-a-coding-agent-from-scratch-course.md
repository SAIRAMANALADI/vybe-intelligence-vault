## Summary
An open-source course that teaches how to build a coding agent from scratch, focusing on the agent harness rather than the model. It provides a hands-on guide to constructing a headless agent loop, durable runtime, and interactive TUI, with demos and lessons on essential components like sandboxing, observability, and evals.

## Key Features
- Teaches building a coding agent harness from scratch with a 20-line core agent loop
- Supports headless mode and interactive TUI for real-time agent steering
- Includes durable runtime with replays, human-in-the-loop, and parallel agent execution
- Integrates sandboxing (local Docker and remote Modal sandboxes) for safe tool execution
- Provides observability via Opik and evals for benchmarking agent performance

## Why It Matters for RAG Builders
It provides a foundational blueprint for building robust, production-grade coding agents with a focus on harness architecture, durability, and safety, which are critical for RAG systems requiring tool execution and real-world task completion.
