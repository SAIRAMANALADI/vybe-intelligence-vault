## Summary
kxen is a native macOS Apple Silicon coding agent harness that integrates multi-provider models, goal-driven execution, dynamic workflows, and agent teams into a desktop runtime. It combines Tauri 2, Rust, SolidJS, and QuickJS to provide a unified workspace for AI-driven development tasks.

## Key Features
- Native macOS Apple Silicon support with signed and notarized builds
- Multi-provider model and account management with role-based routing
- Persistent session storage, atomic resume, and JSONL/Queue recovery
- Built-in safety approvals, checkpointing, and recoverable deletion
- Integrated local tools (file, shell, web fetch, browser, MCP, LSP) and long-term knowledge management

## Why It Matters for RAG Builders
kxen provides a robust, native desktop runtime for deploying and managing AI agents with multi-provider support, making it essential for developers building agentic workflows on macOS.
