## Summary
A comprehensive series demonstrating enterprise-grade knowledge graph integration using Microsoft GraphRAG and Azure OpenAI. It provides modular implementations for building, querying, and deploying knowledge graphs with MCP servers, agent frameworks, and workflow patterns.

- MCP server integration for dynamic agent-tool communication

- Comprehensive evaluation and monitoring with Azure AI Evaluation and OpenTelemetry
- Production-ready deployment patterns with CI/CD and dependency management via uv
