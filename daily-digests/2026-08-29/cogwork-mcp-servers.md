## Summary
A collection of eight Model Context Protocol (MCP) servers that provide AI agents with real-world tools via thin stdio clients over production REST APIs. These servers enable functionalities like PDF generation, QR/barcode creation, accessibility scanning, image processing, and e-invoice validation.

## Key Features
- Eight specialized MCP servers for AI agents covering diverse use cases (PDF, QR/barcodes, accessibility, images, etc.)
- Thin stdio clients over production REST APIs with free tiers for rapid prototyping
- Deterministic JSON-based input/output for agent-friendly integration
- Validation-first approach with clear error handling for bad inputs
- Production-grade infrastructure with caching, rate limits, and SSRF guards
