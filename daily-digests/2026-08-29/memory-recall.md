## Summary
Memory Recall is a local-first tool that transforms repositories into governed context sources for coding agents like Codex, Claude Code, and Cursor. It provides SQLite-based memory management, read-only MCP servers, and explicit review-gated context handoffs without requiring hosted services or API keys.

## Key Features
- Governed SQLite memory with temporal facts, supersession, and explicit approval/rejection workflows
- Read-only MCP server for local repository context delivery with delta-based cursors to minimize token usage
- Explicit review-gated memory ingestion and handoffs to ensure trust and transparency
- Experimental Rust acceleration for local ingest, graph/search, and static analysis
- Developer-first contract with dry-run previews, confirm-gated writes, and local-only storage

## Why It Matters for RAG Builders
It provides a critical layer for RAG/AI stack builders by enabling local, governed, and review-gated repository context delivery that reduces token waste and ensures trust in agent interactions.
