## Summary
Loopback is an interactive feedback layer that bridges real product usage with coding agents, enabling users to pin feedback on live apps which agents can then fix. It captures functional context like failing requests, console logs, and AI run metadata, and integrates with agents like Claude Code, Codex, and Gemini CLI via MCP.

## Key Features
- One shared SQLite DB for all projects, enabling a unified feedback queue.
- MCP-based integration with multiple coding agents (Claude Code, Codex, Gemini CLI) for seamless workflows.
- Automatic capture of functional context (failing requests, console logs, AI run metadata) for precise debugging.
- Widget-based pinning system for live apps, turning feedback into actionable tasks.
- Verified fixes turn pins green on the page, providing real-time status updates.

## Why It Matters for RAG Builders
Loopback closes the critical gap between real-world app usage and AI agent debugging by providing a unified, agent-agnostic feedback loop that captures rich context and enables seamless collaboration.
