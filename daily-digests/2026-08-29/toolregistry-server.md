## Summary
A Python-based server framework for registering and exposing custom tools via OpenAPI (REST) and MCP (Model Context Protocol) interfaces. It enables seamless integration of Python functions as callable services for AI agents and applications.

## Key Features
- Protocol-agnostic tool registration and execution via OpenAPI and MCP adapters
- Unified configuration system supporting Python modules, MCP servers, and OpenAPI endpoints
- Built-in authentication (Bearer token support) and deployment profiles for security
- High-level `App` class for simplified server orchestration and customization
- CLI-driven deployment with support for config files, profiles, and transport modes

## Why It Matters for RAG Builders
It provides a standardized way to register, expose, and manage custom tools for AI agents, streamlining integration into RAG pipelines and agent frameworks.
