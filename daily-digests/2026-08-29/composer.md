## Summary
winkComposer is a high-performance JavaScript framework for building composable streaming intelligence pipelines, transforming live data streams into actionable insights using neural-network intelligence and small, focused building blocks called nodes.

## Key Features
- Declarative flow language for composing small, focused nodes into pipelines
- Per-asset isolation for fault tolerance and deterministic shutdown
- High-performance processing with benchmarks up to 1.2M messages/second on modern servers
- Built-in adapters for MQTT, CSV, QuestDB, and terminal output
- Interactive browser-based demos and documentation for real-time learning

## Why It Matters for RAG Builders
