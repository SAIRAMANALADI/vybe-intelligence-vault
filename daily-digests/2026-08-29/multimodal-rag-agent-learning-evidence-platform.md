## Summary
A full-stack multimodal RAG and Agent platform designed for learning evidence management, document retrieval, and job preparation. It integrates React frontend, FastAPI backend, PostgreSQL/pgvector database, and LangGraph-based agents to enable hybrid search, durable task processing, and evidence-based responses.

## Key Features
- End-to-end multimodal document ingestion (text, PDF, Office, images, videos) with structured parsing and recursive chunking
- Hybrid retrieval combining BM25 keyword search and pgvector semantic search with RRF/RAG-Fusion ranking
- LangGraph-based agent framework with PAE/ReAct orchestration, memory, approvals, and SSE event streaming
- Durable task processing with PostgreSQL-backed job queues for resilience and recovery
- Evidence-based responses with structured citations, time-stamped video segments, and refusal mechanisms for insufficient evidence

## Why It Matters for RAG Builders
This repository provides a production-ready, open-source stack for building multimodal RAG systems with agentic workflows, durable task processing, and evidence-based responses, critical for enterprise-grade AI applications.
