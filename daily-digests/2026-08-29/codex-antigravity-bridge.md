## Summary
A local MCP bridge that integrates Codex's planning and supervision capabilities with Google Antigravity's execution engine (agy CLI). It enables scoped task delegation, parallel worktrees, and structured collaboration between Codex and Antigravity agents via Model Context Protocol (MCP).

## Key Features
- Local MCP stdio-based communication with Codex and Antigravity CLI
- Four operational modes: normal development, single-task delegation, async independent tasks, and collaborative parallel development
- Scoped task execution with Git worktrees and branch isolation for parallel tasks
- Supervisor mode enforcing user-defined boundaries, acceptance criteria, and verification steps
- Cross-platform support (Windows, macOS, Linux) with ConPTY fallback for terminal output

## Why It Matters for RAG Builders
It bridges Codex's high-level planning with Antigravity's execution engine, enabling structured, scoped, and parallel task delegation for AI-driven development workflows.
