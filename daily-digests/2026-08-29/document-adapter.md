## Summary
A Python library and MCP server that enables LLMs to directly edit DOCX, PPTX, HWPX, and XLSX documents by abstracting office formats into a unified interface. Supports template rendering, cell manipulation, form filling, and MCP tool integration for AI agents.

## Key Features
- Unified API for DOCX, PPTX, HWPX, and XLSX with automatic format detection
- MCP server compatibility for direct integration with Claude Desktop/Code and Anthropic API
- Template rendering with Jinja2 syntax for DOCX and conditional expressions for other formats
- Cell manipulation, form filling, and row/column insertion with support for merged cells and metadata
- Byte-stable HWPX editing and cell size metadata for overflow risk prevention

## Why It Matters for RAG Builders
It enables AI agents to programmatically edit and generate office documents, bridging the gap between LLM capabilities and real-world document workflows.
