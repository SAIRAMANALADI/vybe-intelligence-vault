## Summary
Zoc AI is a local-first agentic coding desktop application powered by llama.cpp, built as a Tauri v2 binary with a bundled FastAPI sidecar for agentic workflows. It combines Rust, Python, and TypeScript in a multi-process architecture for efficient local AI-driven development.

## Key Features
- Local-first architecture with loopback-only agent binding for security
- Multi-process design: Tauri shell (Rust) + FastAPI sidecar (Python) + React frontend
- Automated version stamping and release pipeline with strict quality gates
- Cross-platform support (Linux, macOS, Windows) with per-OS installer generation
- Schema-driven development with Pydantic ↔ TypeScript type synchronization

## Why It Matters for RAG Builders
