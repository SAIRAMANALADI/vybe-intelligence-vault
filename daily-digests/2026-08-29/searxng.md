## Summary
searXNG is a privacy-focused network search server that leverages the SearXNG search engine to provide web search functionality via MCP (Model Context Protocol) technology. It aggregates results from multiple search engines while allowing customization of search parameters like categories, languages, and time ranges.

## Key Features
- Privacy-friendly web search via aggregated engines
- Customizable search parameters (categories, languages, time ranges)
- Supports both stdio and Streamable HTTP transports for MCP clients
- Error handling for unreachable or rate-limited instances
- Configurable instance URL and timeout settings
