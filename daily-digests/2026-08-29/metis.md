## Summary
Metis is a local-first desktop AI agent that integrates models with code, terminals, browsers, and Windows desktop operations to execute tasks from natural language to verifiable results. It provides a structured workflow for planning, execution, observation, and validation with built-in safety and evidence tracking.

## Key Features
- Structured workflow for goal-driven task execution with verifiable outcomes (diff, tests, screenshots, logs)
- Three isolated workspaces (Chat, Cowork, Code) for different task intensities with seamless switching
- Built-in safety controls including permission tiers, credential isolation, and audit trails
- Supports code editing, terminal commands, browser automation, and Windows desktop control
- Local-first architecture with no mandatory accounts, no telemetry, and offline-capable operations

## Why It Matters for RAG Builders
Metis provides a robust, local-first framework for building AI agents that require verifiable execution, multi-tool orchestration, and safety controls, making it essential for RAG/AI stack builders targeting enterprise or production-grade applications.
