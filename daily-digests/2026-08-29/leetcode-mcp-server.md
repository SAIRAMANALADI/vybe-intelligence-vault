## Summary
A Model Context Protocol (MCP) server that provides programmatic access to LeetCode's problems, solutions, user data, and submissions via standardized APIs, supporting both leetcode.com and leetcode.cn platforms.

## Key Features
- Multi-site support for leetcode.com and leetcode.cn
- Dual transport modes (stdio and Streamable HTTP)
- Comprehensive problem and solution retrieval with filtering
- User data access including submissions, progress, and contest rankings
- Authenticated access for private data (notes, progress tracking)

## Why It Matters for RAG Builders
It enables AI agents to dynamically fetch LeetCode problems, solutions, and user data for training, evaluation, or real-time problem-solving assistance.
