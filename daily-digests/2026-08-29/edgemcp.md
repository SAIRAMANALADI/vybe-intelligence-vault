## Summary
EdgeDefense MCP is a local, privacy-focused Model Context Protocol (MCP) server that enables users to analyze and monitor their home network through natural language queries. It provides real-time insights into connected devices, network performance, and security without requiring admin rights or sending data to external servers.

## Key Features
- Local network scanning with plain-English explanations for connected devices and issues
- Real-time network performance metrics (Wi-Fi signal strength, latency, bufferbloat)
- Privacy-first design with no cloud dependencies except for optional speed tests
- Read-only operations with no admin rights required for installation or execution
- Supports OAuth and passphrase-based authentication for remote access

## Why It Matters for RAG Builders
It provides a secure, local-first way to diagnose home network issues using AI-friendly MCP clients, ensuring privacy while enabling natural language interactions for network management.
