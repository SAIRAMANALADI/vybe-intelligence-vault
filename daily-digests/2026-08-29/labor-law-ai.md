## Summary
A specialized AI tool for labor law rights protection that guides users through case input, automatically analyzes violations, calculates compensation, and generates arbitration documents. It supports integration with any OpenAI-compatible LLM provider.

## Key Features
- 8 specialized AI agents for labor law analysis (case analysis, violation detection, compensation calculation, contract review, evidence analysis, document drafting, arbitration guidance, rights protection path)
- Guided user interaction with 3-step process (select issue type, fill form, AI analysis with SSE streaming)
- Built-in legal library with 71 YAML-formatted labor law articles and 10 case examples with 2-gram inverted index
- Modular AI provider adapter allowing seamless switching between DeepSeek, Qwen, GLM, GPT-4o, Ollama, or any OpenAI-compatible API via simple configuration
- Responsive web interface with real-time AI output and structured data extraction

## Why It Matters for RAG Builders
It streamlines labor law dispute resolution by automating legal analysis and document generation, reducing the need for manual legal expertise while improving accessibility for non-lawyers.
