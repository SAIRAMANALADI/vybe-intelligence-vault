## Summary
A VS Code extension that integrates the `pi` coding agent as a chat sidebar via a clean-room implementation. It bridges a React webview with the agent's JSON-lines RPC protocol, enabling streaming conversations, tool calls, and session management within the editor.

## Key Features
- Embeds `pi` coding agent as a VS Code sidebar chat
- Supports streaming conversations, thinking, and tool calls
- Session history browser with workspace context
- Editor-tab chat and HTML export functionality
- Runtime crash recovery and session stats tracking

## Why It Matters for RAG Builders
It provides a seamless, extensible interface for integrating AI coding agents directly into VS Code, enhancing developer productivity with real-time collaboration and session management.
