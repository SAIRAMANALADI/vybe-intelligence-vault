## Summary
Salt Code is an MCP (Model Context Protocol) server that integrates with AI coding assistants to enforce real-time security policies and guardrails, preventing insecure patterns before code reaches production. It provides shift-left security for developers, AppSec teams, and DevSecOps pipelines with minimal setup.

## Key Features
- Enforces 40+ security policies across API, agentic, LLM, and OpenAPI domains in real time
- Seamless integration with 16+ AI coding assistants (Cursor, Claude, VS Code, etc.) via MCP
- No new workflows or infrastructure required—works over HTTP with a single token
- Free tier available with enterprise-grade options for larger teams
- Prevents insecure patterns (e.g., query string auth, PII in URLs) before code is written

## Why It Matters for RAG Builders
Salt Code enables RAG builders to enforce security guardrails directly within AI coding workflows, reducing vulnerabilities and compliance risks before code is generated or deployed.
