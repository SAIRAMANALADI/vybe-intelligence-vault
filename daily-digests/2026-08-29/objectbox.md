## Summary
ObjectBox is a high-performance, offline-first on-device database with built-in data synchronization and vector search capabilities, designed for mobile, IoT, embedded, and edge computing applications. It enables local data processing with cloud sync and supports AI/ML workloads through vector search.

## Key Features
- Built-in vector search for AI/ML workloads
- Offline-first architecture with cloud synchronization
- Low-footprint and high-performance for embedded systems
- Cross-platform support (mobile, IoT, edge)
- Built-in data synchronization for real-time updates
