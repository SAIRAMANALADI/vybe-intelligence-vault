## Summary
HermesBI is an evidence-first data analysis agent built on the Hermes Agent framework, designed to provide transparent, auditable, and reproducible business insights. It binds every conclusion to data versions, SQL queries, results, metric definitions, and verification status, ensuring trustworthy analytics.

## Key Features
- Structured claim verification with data re-computation and contradiction detection
- Persistent task engine with state management, leasing, and recovery mechanisms
- Built-in evaluation suite with 20 fixed test cases and ground truth benchmarks
- Controlled execution environment with read-only SQL protection and Docker isolation
- Failure lab for testing degradation, retries, and recovery scenarios

## Why It Matters for RAG Builders
HermesBI provides a robust framework for building trustworthy, auditable AI-driven data analysis agents, critical for enterprise RAG systems requiring verifiable insights and failure resilience.
