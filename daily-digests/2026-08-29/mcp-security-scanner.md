## Summary
A security scanner for Model Context Protocol (MCP) server configurations that audits for common AI security issues such as overprivileged tools, missing authentication, prompt injection vulnerabilities, and unsafe defaults. It can be integrated into CI/CD pipelines or run via CLI.

## Key Features
- Audits MCP server configurations for overprivileged tools and missing authentication
- Detects prompt injection surface and unsafe transport defaults
- Supports CLI and programmatic usage with SARIF output for GitHub Code Scanning
- Integrates into CI/CD as a security gate with configurable failure thresholds
- Provides risk scoring and detailed findings for remediation

## Why It Matters for RAG Builders
It ensures secure MCP server deployments by identifying critical AI security flaws before they reach production, reducing exposure to prompt injection and overprivileged tool risks.
