## Summary
PythonClaw is a pure-Python reimplementation of OpenClaw, an autonomous AI agent framework featuring memory, RAG, skills, a web dashboard, voice input, daemon mode, and multi-channel support. It emphasizes Pythonic design and provider-agnostic LLM integration.

## Key Features
- Provider-agnostic LLM integration supporting 6+ major providers and OpenAI-compatible APIs
- Hybrid RAG pipeline combining BM25, dense embeddings, RRF fusion, and LLM re-ranking for robust retrieval
- Three-tier skill system with progressive loading and a 13K+ skill marketplace via ClawHub
- Multi-channel support including CLI, web dashboard, Telegram, Discord, and WhatsApp with per-group isolation
- Security-hardened design with zip-slip protection, TLS verification, and loop-breaking for tool execution

## Why It Matters for RAG Builders
PythonClaw provides a Python-native, highly modular agent framework with advanced RAG capabilities and a rich skill ecosystem, making it essential for building scalable, secure, and customizable AI agents.
