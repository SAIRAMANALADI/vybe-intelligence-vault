## Summary
Swees is an open-source AI Agent application for Android that embeds a full Ubuntu 24.04 terminal environment using PRoot technology. It enables AI to execute commands, write code, manage files, and collaborate via multi-agent systems directly on mobile devices without requiring root access.

## Key Features
- Embedded Ubuntu 24.04 terminal via PRoot for full Linux command execution on Android
- Multi-agent collaboration with cross-topic IPC communication and isolated sessions
- Function calling for AI to autonomously execute shell commands, install APKs, and manage files
- Cross-conversation memory with full-text search (FTS4) for persistent context
- Customizable AI provider support (DeepSeek, GLM, or any OpenAI-compatible endpoint)

## Why It Matters for RAG Builders
Swees enables AI agents to perform complex, Linux-based tasks directly on mobile devices, bridging the gap between cloud-based AI and on-device execution for developers and power users.
