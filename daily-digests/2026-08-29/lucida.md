## Summary
Lucida is a CLI and MCP server for generating and editing images and videos using Google's Gemini and Veo models. It provides a statically compiled binary for seamless integration into coding agents and workflows.

## Key Features
- Single static binary with no dependencies, ideal for MCP server use cases
- Supports both image and video generation/editing via Google's Gemini and Veo models
- MCP server integration for coding agents to autonomously generate assets
- Explicit error handling and billing detection to avoid unexpected API costs
- Watermarking and provenance tracking for all generated media

## Why It Matters for RAG Builders
Lucida streamlines AI-generated asset creation for RAG pipelines by providing a lightweight, agent-friendly interface to Google's advanced models.
