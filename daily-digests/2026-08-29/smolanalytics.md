## Summary
smolanalytics is a self-hosted, privacy-first analytics tool that provides AI-powered insights into product and web analytics data. It ensures AI responses match exact computed data through a CI-enforced agreement test, integrates with coding agents via MCP, and offers features like funnels, retention, trends, and cohort analysis.

## Key Features
- AI answers provably match dashboard data via CI-enforced agreement test
- Integrates with coding agents (Claude, Cursor, etc.) over MCP for code-aware queries
- Supports funnels, retention, trends, segmentation, cohorts, and web analytics in one binary
- Privacy-first architecture with cookieless mode, right to erasure, and no third-party data sharing
- One binary deployment with no external dependencies (e.g., Kafka, ClickHouse)
