## Summary
LocalData MCP is an MCP server that provides LLM agents with access to 13+ database types, 20+ file formats, and a comprehensive data science toolkit, exposing 70+ tools for querying, analyzing, and modeling data with memory-bounded streaming capabilities.

## Key Features
- 70+ MCP tools for querying databases, files, and graphs with SQL and structured data support
- Memory-bounded streaming for safe large-dataset processing with configurable limits
- Comprehensive data science toolkit including statistical analysis, regression, clustering, and time series forecasting
- Support for 13+ database types and 20+ file formats (CSV, JSON, Parquet, Excel, etc.)
- Claude Code plugin with 18 skills and 11 agents for automated data workflows

## Why It Matters for RAG Builders
It enables LLM agents to directly interact with diverse data sources and perform advanced analytics, making it essential for building robust RAG systems with real-time data access and processing.
