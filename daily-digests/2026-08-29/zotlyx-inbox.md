## Summary
zotlyx-inbox is a self-hosted, team-focused email management tool that provides a shared inbox with real-time collaboration, AI-assisted reply generation, and secure cloud storage. It enables teams to manage emails collectively while leveraging Cloudflare's infrastructure for data security and scalability.

## Key Features
- Shared inbox with real-time updates for team collaboration
- AI-powered draft generation for faster email responses
- Secure cloud storage via Cloudflare R2 and D1
- Customizable labels, rules, and notifications for workflow adaptation
- Self-hosted deployment on Cloudflare Workers for data control
