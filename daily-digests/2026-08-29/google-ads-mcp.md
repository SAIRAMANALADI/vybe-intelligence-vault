## Summary
A Model Context Protocol (MCP) server that bridges AI assistants (Claude, ChatGPT, Gemini) with the Google Ads API, enabling natural language analysis, management, and optimization of Google Ads campaigns through secure OAuth 2.0 authentication.

## Key Features
- Enables AI assistants to interact with Google Ads via natural language commands
- Provides 10+ stable tools for campaign analysis, reporting, and management
- Roadmap includes 161 tools covering 85% of Google Ads API surface area
- Secure OAuth 2.0 authentication with refresh token support
- Modular architecture supporting extensibility and future tool additions

## Why It Matters for RAG Builders
It simplifies Google Ads management for AI-driven workflows by providing a secure, natural language interface to the Google Ads API, reducing the need for manual dashboard navigation or custom API integrations.
