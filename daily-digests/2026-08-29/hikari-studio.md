## Summary
Hikari Studio is an AI-native visual novel studio that provides a local desktop editor for creating interactive visual novels with block-based scripting, real-time preview, and AI-assisted production workflows. It supports multi-platform game exports and integrates AI agents for automated story editing and debugging.

## Key Features
- Block-based visual scripting for dialogue, scenes, and branching narratives
- AI Agent for automated story editing, conflict detection, and structured patching
- Multi-track production timeline with audio waveforms, keyframes, and ripple editing
- Cross-platform game exports (Web, Windows WebView2, Ren'Py-compatible)
- Real-time preview, debugging, and version control integration
