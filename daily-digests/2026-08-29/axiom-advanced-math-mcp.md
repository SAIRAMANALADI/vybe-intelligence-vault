## Summary
A Model Context Protocol (MCP) server providing advanced mathematical computation for LLMs, combining math.js for numerical evaluation and Giac/Xcas WASM for symbolic computation. It offers verified, exact results for arithmetic, calculus, algebra, linear algebra, and more.

## Key Features
- Single gateway MCP tool (`compute`) for all mathematical operations, routing to math.js or Giac/Xcas based on problem type
- Symbolic computation support for calculus, algebra, linear algebra, and number theory via Giac/Xcas WASM
- Numerical evaluation with math.js for fast arithmetic, trigonometry, and matrices
- Verification tool (`verify`) to independently check mathematical claims or results
- 2D plotting capability (`plot`) to render function graphs as SVG images

## Why It Matters for RAG Builders
It provides verified, exact mathematical results for LLMs, reducing calculation errors and enabling reliable symbolic and numerical computation in AI pipelines.
