## Summary
A Model Context Protocol (MCP) server that enables AI agents like Claude to interact with Oracle EPM Cloud via REST APIs, allowing natural language commands to manage applications, run business rules, export data, and automate workflows like month-end close.

## Key Features
- Enables AI agents to execute Oracle EPM Cloud REST API calls via natural language commands
- Provides tools for managing applications, substitution variables, business rules, and data exports
- Supports both mock and live Oracle EPM environments with configurable authentication
- Includes a one-click desktop extension for easy installation in Claude Desktop
- Automates complex workflows like month-end close through AI-driven orchestration

## Why It Matters for RAG Builders
It bridges the gap between AI agents and Oracle EPM Cloud, enabling seamless automation of financial and operational workflows through natural language.
