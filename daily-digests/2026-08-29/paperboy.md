## Summary
paperboy is an MCP server that integrates with Zotero to deliver research papers to e-readers like Kindle or Kobo. It enables users to search, queue, and send papers directly from Claude, with Zotero serving as the central library and state manager.

## Key Features
- Seamless integration with Zotero for library management and state persistence
- Multi-backend delivery (email for Kindle/PocketBook, Dropbox for Kobo)
- Interactive setup wizard for easy configuration
- Search and recommend papers via OpenAlex, arXiv, and Semantic Scholar
- Queue management with duplicate protection and topical filing

## Why It Matters for RAG Builders
It streamlines the process of delivering research papers to e-readers directly from AI assistants, reducing manual effort and enhancing productivity for researchers.
