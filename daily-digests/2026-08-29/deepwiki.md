## Summary
DeepWiki is a thin Claude Code plugin that integrates Cognition AI's hosted DeepWiki MCP server, enabling agents to query auto-generated documentation for any public GitHub repository without cloning or API keys. It acts as a bridge to remotely index and serve repository documentation for AI-driven analysis.

## Key Features
- One-command installation via 88plug marketplace
- Read-only access to auto-generated documentation for any public GitHub repo
- Exposes MCP tools for querying repository structure, contents, and answering natural-language questions
- No local setup or API keys required—relies on Cognition AI's hosted DeepWiki service
- Seamless integration with AI agents for real-time codebase understanding

## Why It Matters for RAG Builders
DeepWiki enables AI agents to instantly query and understand any public GitHub repository's documentation without manual setup, accelerating RAG pipelines and reducing context-building overhead.
