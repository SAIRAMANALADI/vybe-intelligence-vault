## Summary
Amber is a lifelong-learning agent experiment focused on continual learning with a small transformer (14.4M parameters) designed to learn continuously without forgetting, survive restarts, and maintain bit-identical state across hardware and software changes. It emphasizes measurement-first design with real-time brain visualization and deterministic replay mechanisms.

## Key Features
- Bit-identical replay and checkpointing for state persistence across restarts and hardware changes
- Real-time live brain visualization showing activations and weights during learning
- Curiosity-driven task selection and replay memory for anti-forgetting mechanisms
- Hardware-independent snapshots with atomic writes and checksums
- Composable task grammar with adjustable difficulty for controlled learning experiments

## Why It Matters for RAG Builders
Amber provides a unique, measurement-first framework for building and studying continual learning agents with real-time monitoring and deterministic state management, critical for advancing lifelong learning systems.
