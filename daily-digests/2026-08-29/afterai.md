## Summary
AfterAI is a local-first tool that analyzes AI coding agent logs to estimate token usage and API-equivalent costs, providing transparency into AI resource consumption without requiring accounts or API keys. It generates weekly burn reports and a public leaderboard for fun comparisons.

## Key Features
- Local analysis of AI coding agent logs without network requests by default
- Estimates API-equivalent token costs with transparent pricing models
- Generates weekly burn reports and a public leaderboard for fun comparisons
- Supports custom log paths and multiple output formats (HTML, JSON)
- Privacy-first design with no account or API key requirements

## Why It Matters for RAG Builders
AfterAI provides critical transparency into AI resource consumption, helping developers and teams audit and optimize their AI usage without compromising privacy or requiring external dependencies.
