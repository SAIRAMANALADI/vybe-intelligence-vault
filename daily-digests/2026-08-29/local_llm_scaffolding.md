## Summary
A local-first LLM scaffolding project designed to run on consumer hardware with limited VRAM (16GB) while aiming for performance comparable to Anthropic and OpenAI models. It focuses on web research, memory management, and tool use with a backend-first architecture.

## Key Features
- Local-first execution with privacy constraints
- Web search integration via SearXNG
- Memory management via static `memory.md` file
- Configurable model parameters for hardware optimization
- Bash and tool-use capabilities

## Why It Matters for RAG Builders
Provides a lightweight, local-first agent framework optimized for consumer hardware, enabling private and efficient LLM tool use and web research without cloud dependency.
