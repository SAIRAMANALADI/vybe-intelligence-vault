## Summary
Dashi PPT Skill is an AI agent-powered tool that generates interactive, browser-editable presentations from documents, supporting 12 visual themes, 1020 layouts, and 8576 controls. It enables real-time editing, one-click exports to PPTX/PDF, and seamless integration with AI agents like Claude Code and Codex.

## Key Features
- 12 pre-built visual themes with 1020+ layouts and 8576+ controls for rapid PPT creation
- Real-time in-browser editing with drag-and-drop media replacement and text editing
- One-click export to editable PPTX, PDF, or HTML offline packages
- Seamless integration with AI agents (Claude Code, Codex, 豆包, etc.) for automated generation
- Dynamic control console for adjusting layouts, charts, colors, and animations per page
