## Summary
Santos Website Intelligence API evaluates public websites for agent readiness, measuring discoverability, understandability, trustworthiness, and callability. It provides structured audits via a pay-per-use API using the x402 protocol for USDC payments on Base, with no traditional API keys required.

## Key Features
- Multi-tier audits: Quick, Agent Readiness, and Deep (browser-rendered) with prioritized fixes
- Four-dimensional scoring: Discoverable, Understandable, Trustworthy, and Callable
- Pay-per-use model via x402 protocol with USDC on Base (no traditional API keys)
- MCP server integration for agent tooling and automation
- OpenAPI, llms.txt, and capability manifests for machine-readable discovery

## Why It Matters for RAG Builders
It provides critical insights into website agent-readiness and structured audits, enabling AI systems to evaluate and interact with public websites efficiently and securely.
