## Summary
AIzs is an enterprise-grade AI agent framework built with Spring AI and LangChain4j, offering modular AI applications like an AI love assistant, company policy Q&A, and PDF chat. It supports RAG knowledge bases, tool calling, MCP services, and autonomous agent planning with structured outputs.

## Key Features
- Modular AI applications with specialized agents (e.g., love assistant, policy Q&A)
- Comprehensive tool ecosystem including web search, file operations, and PDF generation
- ReAct-based autonomous planning agent (YuManus) for multi-step task completion
- Hybrid RAG with PgVector for knowledge retrieval and structured output generation
- Full-stack observability, memory persistence, and security features (PII sanitization, prompt injection protection)

## Why It Matters for RAG Builders
AIzs provides a production-ready framework for building scalable, modular AI agents with advanced RAG, tool integration, and autonomous planning capabilities, critical for enterprise AI deployments.
