## Summary
DevOS is a keyboard-driven developer operating system for Windows that consolidates terminal, git, Docker, an AI assistant, and other tools into a single Tauri-based app. It emphasizes offline-first, privacy-focused workflows with modular functionality and explicit user grants for AI tool access.

## Key Features
- Unified command palette integrating terminal, git, Docker, and AI assistant
- AI assistant with project-aware context, tool calling (Claude-only), and hybrid code search (BM25 + embeddings + tree-sitter)
- Explicit two-tier grant system for AI tool access (reads vs. writes/executes)
- Offline-capable local model support via Ollama for fully private workflows
- Read-only modules with clear scope limitations to avoid false expectations

## Why It Matters for RAG Builders
DevOS provides a privacy-focused, offline-capable developer environment that integrates AI tools with essential workflows, reducing context switching while maintaining strict control over data and permissions.
