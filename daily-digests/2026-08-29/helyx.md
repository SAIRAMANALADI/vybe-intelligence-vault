## Summary
Helyx is a Telegram-first MCP server that bridges multiple Claude Code CLI instances with a Telegram bot, enabling multi-project management via forum topics, real-time CLI monitoring, voice transcription, and persistent dual-layer memory for AI agents.

## Key Features
- Multi-session MCP server supporting concurrent Claude Code CLI instances with project-scoped sessions
- Telegram Forum Supergroup integration for project-specific topics with no context bleeding
- Dual-layer memory (short-term and long-term via pgvector) with smart reconciliation and auto-summarization
- Voice transcription (Groq Whisper + local fallback) and image analysis for multimodal interactions
- Real-time CLI progress monitoring, permission forwarding, and web dashboard for observability

## Why It Matters for RAG Builders
Helyx provides a human-in-the-loop interface for MCP-compatible AI agents, enabling seamless task delegation, approval, and monitoring via Telegram while preserving project context and memory.
