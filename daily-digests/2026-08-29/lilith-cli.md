## Summary
Lilith CLI is a terminal-first coding environment combining an interactive agent REPL, a full TUI IDE built on Textual, and orchestration tools for delegating work to sub-agents. It integrates vector memory, LSP, and git operations within a Norse-themed interface.

## Key Features
- Interactive agent REPL for real-time AI collaboration
- Full-featured TUI IDE with file tree, multi-tab editor, and LSP support
- Built-in vector memory store with SQLite backend and semantic chunking
- Agent delegation and workflow orchestration with MCP integration
- Git operations and session persistence for seamless coding workflows
