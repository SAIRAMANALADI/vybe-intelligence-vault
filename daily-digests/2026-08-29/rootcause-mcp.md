## Summary
RootCause MCP is an MCP server that enables AI agents to perform specialist-level medical reasoning, differential diagnosis, and root cause analysis with Bayesian updating, evidence provenance tracking, and audit-grade traceability. It bridges general-purpose LLMs with medical reasoning frameworks through typed MCP tools.

## Key Features
- 27 typed MCP tools for medical reasoning and RCA with structured input/output contracts
- Bayesian differential diagnosis engine with likelihood ratio updating and probability ranking
- Evidence-first architecture with Oxford CEBM and GRADE grading, full provenance tracking, and FHIR compatibility
- HFACS-MES integration for medical error classification and systemic analysis
- Audit-grade chain-of-thought with immutable reasoning chains for legal/regulatory compliance

## Why It Matters for RAG Builders
It provides a structured, auditable framework for AI agents to perform medical reasoning and differential diagnosis, bridging the gap between general-purpose LLMs and specialist-level clinical decision-making.
