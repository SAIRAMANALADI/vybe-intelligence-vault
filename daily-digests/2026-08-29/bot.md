## Summary
AOT Analyzer Bot is a trading signal generator for XAU/USD (gold) that uses ADX regime filters, Hyperliquid data, and a Telegram interface to deliver intraday trading signals with a structured pipeline and lifecycle management.

## Key Features
- Automated intraday signal generation for XAU/USD using Hyperliquid data
- ADX regime filter for trend confirmation and swing level detection
- Telegram bot interface for real-time signal delivery and trade logging
- Lifecycle management for signals with auto-expiry and TP/SL detection
- Web API endpoints for health checks, price queries, and trade logging
