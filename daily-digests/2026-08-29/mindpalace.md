## Summary
A self-learning, always-on personal AI agent that runs on a Claude Max subscription, combining terminal and Discord interfaces with persistent memory and a structured knowledge vault. It autonomously learns from interactions, writes reusable skills, and executes real-world tasks in the background.

## Key Features
- Dual-interface support (terminal + Discord) with shared memory and vault
- Autonomous skill generation from user procedures via an Analyst agent
- Structured knowledge vault for persistent memory and recall
- Background job execution with live step streaming
- Proactive heartbeat for autonomous system monitoring and reporting

## Why It Matters for RAG Builders
It provides a self-hosted, always-on AI agent framework that learns and adapts to personal workflows, reducing dependency on external AI services while enabling persistent, context-aware automation.
