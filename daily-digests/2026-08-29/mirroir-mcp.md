## Summary
mirroir-mcp is an MCP server that enables AI agents to interact with a real iPhone or macOS apps by mirroring the screen, automating taps, swipes, and text input, and providing structured UI context for navigation and automation tasks.

## Key Features
- 33+ tools for screen interaction (tapping, swiping, typing, navigation)
- Multi-backend screen description (Apple Vision OCR, YOLO CoreML, AI Vision Mode)
- Skill authoring and marketplace for reusable automation workflows
- Cross-platform support (iPhone via iPhone Mirroring, macOS apps)
- Zero-config AI vision integration via embedded embacle runtime

## Why It Matters for RAG Builders
It bridges AI agents with real-world device interactions, enabling hands-free automation of mobile apps for testing, workflows, and RAG systems that require dynamic UI context.
