## Summary
A cross-platform command-line interface (CLI) for interacting with OneDrive (Personal) that enables file operations, OAuth authentication, and MCP server integration for AI-driven context access.

## Key Features
- Cross-platform CLI for OneDrive operations (file upload, download, search, etc.)
- OAuth authentication with token persistence for secure access
- MCP server integration for AI context providers (e.g., Claude)
- Supports recursive file operations and full-text search
- Nix flake for reproducible development and deployment

## Why It Matters for RAG Builders
It provides a lightweight, scriptable interface to OneDrive with MCP support, enabling AI systems to securely access and manipulate files for context-aware applications.
