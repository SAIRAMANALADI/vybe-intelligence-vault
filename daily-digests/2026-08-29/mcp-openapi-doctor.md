## Summary
mcp-openapi-doctor transforms OpenAPI and Swagger specifications into safer, agent-ready MCP tools by validating, scoring, and curating API operations while exposing them via a CLI or MCP stdio server.

## Key Features
- Validates and scores OpenAPI/Swagger specs for agent readiness
- Generates MCP tools dynamically from API operations
- Provides CLI and MCP stdio server for tool exposure
- Supports read-only mode for safe tool generation
- Creates advisory fixes and overlays without modifying original specs

## Why It Matters for RAG Builders
It bridges the gap between raw OpenAPI specs and agent-ready MCP tools, ensuring APIs are safe, well-documented, and optimized for AI-driven interactions.
