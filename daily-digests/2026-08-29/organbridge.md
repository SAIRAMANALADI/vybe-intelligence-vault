## Summary
OrganBridge is a full-stack AI-powered organ matching platform that uses TF-IDF and cosine similarity to match donors with recipients based on 15+ compatibility factors, while auditing decisions for bias. It includes role-based dashboards, explainable AI, and future plans for hospital integration and regulatory compliance.

## Key Features
- AI-powered organ matching using TF-IDF and cosine similarity with 15+ compatibility factors
- Role-based dashboards for donors and recipients with custom user models
- Explainable AI (XAI) for match explanations using SHAP
- Bias detection and fairness metrics using Fairlearn
- Responsive UI built with Tailwind CSS and HTMX
