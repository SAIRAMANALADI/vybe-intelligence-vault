## Summary
OpenTulpa is a self-hosted deep agent application that autonomously evaluates and publishes improvements to its own source code while maintaining a stable host controller. It enables continuous self-evolution of AI agents for personalized use cases.

## Key Features
- Self-hosted agent framework with autonomous code evaluation and publishing
- Immutable, content-addressed controller generations for stability
- Support for multiple deployment modes (local, Docker Compose, Railway)
- Trusted-local or hardened (rootful Linux) candidate evaluation with rollback safety
- Content-addressed OCI resolver for dependency management and reproducibility

## Why It Matters for RAG Builders
OpenTulpa enables AI agents to continuously improve their own code for specific use cases, reducing manual intervention and enhancing adaptability in production environments.
