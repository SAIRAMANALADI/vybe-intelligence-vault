## Summary
MDDB is an AI-native document database designed for RAG pipelines and LLM workflows, offering built-in MCP server support, vector search, and document ingestion with auto-conversion to Markdown. It integrates seamlessly with AI agents like Claude and ChatGPT, providing 79 MCP tools for direct interaction.

## Key Features
- Built-in MCP server with 79 tools for AI agent integration
- Supports 79 document formats (PDF, DOCX, HTML, etc.) with auto-conversion to Markdown
- Advanced vector search with 7 index algorithms and quantization options
- Hybrid search combining BM25 keyword and vector similarity
- Multi-protocol APIs (HTTP, gRPC, GraphQL) and real-time events

## Why It Matters for RAG Builders
MDDB provides a unified, AI-native document database with built-in MCP integration, making it essential for RAG pipelines and AI agent workflows requiring persistent, searchable knowledge bases.
