## Summary
A Claude Code Skill that automates academic citation workflows for LaTeX documents by integrating Semantic Scholar API for semantic literature retrieval, multi-dimensional quality assessment (CCF, JCR, CAS rankings, impact factor, H-index), and BibTeX generation with Chinese recommendations.

## Key Features
- Semantic literature search via Semantic Scholar API with context-aware retrieval
- Multi-dimensional quality evaluation (CCF, JCR, CAS rankings, impact factor, H-index)
- DOI-to-BibTeX conversion with validation to prevent false citations
- Structured recommendation reports with Chinese explanations for quick decision-making
- arXiv citation threshold analysis for pre-publication quality assessment

## Why It Matters for RAG Builders
It streamlines academic citation workflows by automating literature search, quality assessment, and BibTeX generation, reducing manual errors and ensuring high-quality references for RAG systems.
