## Summary
OmniMerchant is a Spring Boot 4 + Spring AI 2-based omnichannel ecommerce helpdesk platform designed for cross-border customer service. It provides multi-tenant security, evidence-grade RAG, controlled agent workflows, human handoff, multilingual support, and channel connector integrations with robust observability and evaluation frameworks.

## Key Features
- Evidence-grade RAG with hybrid retrieval (vector + BM25), reranking, and citation constraints for traceable responses
- Multi-tenant fail-closed security with tenant isolation, role-based access control, and audit logging
- Controlled agent workflows with supervisor-worker tool whitelisting, deterministic evaluations, and trace replay for debugging
- Omnichannel support including Shopify integration, enterprise WeChat, and multilingual evidence handling
- Comprehensive observability with SLO tracking, RAG health metrics, agent performance dashboards, and automated eval reports

## Why It Matters for RAG Builders
OmniMerchant provides a production-grade reference architecture for building trustworthy, multi-tenant AI customer service platforms with evidence-grade RAG, agent orchestration, and enterprise-grade security and observability.
