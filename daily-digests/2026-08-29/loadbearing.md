## Summary
LoadBearing is a .NET tool that enforces C# architecture rules through a single specification, generating enforcement checks, documentation, and agent context from one unified model. It ensures architectural boundaries are respected in codebases, CI pipelines, and AI agent workflows.

## Key Features
- Single C# spec enforces architectural rules across CLI, CI, xUnit tests, and agent hooks
- Generates AI-agent context (AGENTS.md, MCP tools) from the same spec
- Supports SARIF output for GitHub code scanning and CI integration
- Provides per-rule documentation and violation reports with exact file:line references
- Enables agent-driven development with real-time rule enforcement via hooks

## Why It Matters for RAG Builders
LoadBearing ensures architectural integrity in AI-driven codebases by enforcing rules programmatically, preventing drift and enabling reliable agent interactions with clear violation feedback.
