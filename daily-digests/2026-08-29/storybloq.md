## Summary
Storybloq provides cross-session context persistence for AI coding by introducing a standardized `.story/` directory structure, CLI tools, and MCP server integration. It enables AI assistants like Claude Code and Codex to retain project state, track tickets, issues, and handovers, and resume work seamlessly across sessions.

## Key Features
- Standardized `.story/` directory for project state tracking (tickets, issues, roadmap, handovers)
- CLI and MCP server for inspecting and mutating project state
- Integration with Claude Code (`/story`) and Codex (`$story`) for session loading and autonomous workflows
- Local Bus protocol for implementer-reviewer coordination with durable review provenance
- Usage-limit auto-resume for interrupted sessions with recovery ledger tracking

## Why It Matters for RAG Builders
It eliminates the statelessness of AI coding sessions by providing structured, persistent context that enables continuous, compounding work and reduces repeated mistakes or relitigated decisions.
