## Summary
Kāhea is a local-first, deterministic API invocation kernel for coding agents that converts OpenAPI descriptions, request captures, and Arazzo workflows into integrity-sealed request plans. It enforces exact capability grants and generates typed observations and content-addressed evidence for safe AI agent interactions.

## Key Features
- Sealed request plans for deterministic API calls without network access during planning
- Strict capability-based invocation with policy enforcement and secret redaction
- Support for OpenAPI, Arazzo, Postman, HAR, and cURL formats
- Conformance fuzzing for API contract validation and replayable evidence
- Integration with MCP clients (Claude Code, OpenAI Codex) and stdio-based servers

## Why It Matters for RAG Builders
Kāhea ensures AI agents interact with APIs safely and deterministically by enforcing exact capability grants and generating verifiable evidence, preventing unsafe or unintended API calls.
