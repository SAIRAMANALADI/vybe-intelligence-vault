## Summary
CrossCode is a free, open-source mobile client for the OpenCode terminal AI coding agent, enabling remote control of a local OpenCode instance via a Cloudflare Tunnel. It provides real-time chat, tool call approvals, and session management from a mobile device.

## Key Features
- Zero-config setup with QR code connection for instant pairing
- Real-time chat and inline diffs with markdown and code block rendering
- Tool call approvals for shell commands, file writes, and API calls
- Session management for running multiple OpenCode instances simultaneously
- File tree browser with syntax highlighting and line numbers

## Why It Matters for RAG Builders
CrossCode enables seamless remote control of AI coding agents from mobile devices, enhancing accessibility and productivity for developers managing local AI workflows.
