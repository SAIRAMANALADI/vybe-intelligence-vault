## Summary
Just Code is a VS Code extension that integrates Anthropic's Claude Agent SDK to provide an agentic chat panel for software development tasks. It enforces a strict scope policy to confine the assistant to code-related activities, ensuring focused and auditable AI-driven coding assistance.

## Key Features
- Scoped agentic chat panel confined to code and technical subjects via auditable policy
- Full toolset integration (Read, Write, Edit, Bash, Grep, etc.) with streaming responses
- Permission prompts and inline diff review for safe file modifications
- Model picker, conversation history, and session checkpoints for iterative development
- Local execution with Anthropic API key or subscription-based authentication

## Why It Matters for RAG Builders
It provides a focused, auditable AI coding assistant within VS Code, reducing risks of off-topic or unintended actions while leveraging Anthropic's agentic capabilities.
