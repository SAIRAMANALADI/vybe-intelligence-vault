## Summary
Mem0Sharp is a standalone .NET 10 implementation of the open-source Mem0 project, providing long-term memory capabilities for AI applications in C#. It offers semantic memory management with replaceable embedding and storage providers, supporting CRUD operations, hybrid retrieval, and advanced memory behaviors like dreaming and personality-shaped memories.

## Key Features
- Pluggable embedding and storage providers (PostgreSQL, Qdrant, SQLite, etc.)
- Hybrid semantic and BM25 retrieval with reranking support
- Advanced memory behaviors (dreaming, random thoughts, personality-shaped memories)
- CRUD operations with persistent history and audit trails
- Deterministic local embeddings and offline development support

## Why It Matters for RAG Builders
Mem0Sharp provides a critical long-term memory layer for AI agents in .NET, enabling persistent, semantic, and behavior-aware memory management essential for RAG systems.
