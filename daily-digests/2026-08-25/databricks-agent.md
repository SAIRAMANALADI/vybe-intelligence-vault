## Summary
A CLI tool and skill set that integrates Claude Code with Databricks, enabling AI-powered analytics engineering through 17 specialized skills and a REST API-driven CLI for Unity Catalog, Delta Live Tables, and Spark SQL operations.

## Key Features
- 17 pre-built Claude Code skills for Databricks workflows (medallion architecture, DLT pipelines, security governance)
- CLI suite for SQL queries, job management, Unity Catalog operations, and pipeline monitoring
- Zero-trust security and governance support (row filters, column masking, GDPR compliance)
- Automated lineage and impact analysis for data assets
- Modular installation with optional UI and MLflow support
