## Summary
An AI agent that automates e-commerce order triage by signing into a real storefront, navigating the live catalog, and reporting key metrics like product counts and price ranges without requiring selectors or scraping rules. It operates via a real browser and can run offline or with minimal cost using Coasty's API.

## Key Features
- Zero external dependencies; runs entirely with Node.js built-ins
- Operates real browsers to interact with live storefronts behind logins
- Self-documenting via captured screenshots and video frames
- Structured safety controls to prevent accidental spend or data exposure
- Modular design with one prompt and one config file per automation

## Why It Matters for RAG Builders
It demonstrates how AI-driven computer-use agents can automate complex, login-protected workflows without brittle scraping rules, reducing maintenance overhead for RAG systems that need real-time data from dynamic interfaces.
