## Summary
A local-first Model Context Protocol (MCP) server that enables AI agents to securely access user-authorized Google Health API v4 data (Fitbit, Pixel Watch, and partners) via OAuth, ensuring tokens never leave the user's machine.

## Key Features
- Local-first OAuth authentication with tokens stored securely on the user's machine
- Supports Google Health API v4 for Fitbit, Pixel Watch, and partner data
- Privacy-focused with structured data redaction (location, identity, and sensitive fields)
- Provides tools for connection status, data inventory, daily/weekly summaries, and privacy audits
- Headless OAuth support for SSH, containers, and WSL environments

## Why It Matters for RAG Builders
It enables AI agents to securely and privately access real-time health data from Google Health API, which is critical for building RAG systems that require accurate, user-authorized health insights without compromising privacy.
