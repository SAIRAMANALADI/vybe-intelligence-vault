## Summary
造浪 (ZaoLang) is a global AI-powered platform for remixing images and short videos, enabling users to create derivative works while preserving attribution and licensing through versioned lineage edges. It intelligently routes generation tasks via an explainable gateway to balance cost and performance.

## Key Features
- Versioned lineage edges for derivative works with inherited attribution and licensing
- Explainable AI gateway routing generation tasks to optimize cost and performance
- Strict frontend/backend separation with PostgreSQL as the single source of truth
- Credit-based generation with pre-reservation and post-success settlement
- Default public view-only licensing with optional remixing permissions
