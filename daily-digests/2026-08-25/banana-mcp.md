## Summary
MCP server that exposes Google's Gemini models for AI image and text generation as tools for Claude Code. Enables terminal-based image/text generation, editing, and batch processing with persistent configuration.

## Key Features
- Single and batch image generation (up to 10 parallel tasks)
- Text generation with vision input support and system instructions
- Image editing via input image + prompt modification
- Persistent settings management via `settings.json`
- Configurable defaults for models, aspect ratios, and output directories

## Why It Matters for RAG Builders
It streamlines AI-powered image and text generation directly within terminal workflows, reducing friction for developers using Claude Code or similar MCP-compatible tools.
