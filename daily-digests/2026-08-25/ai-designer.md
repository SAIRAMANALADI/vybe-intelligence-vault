## Summary
Developerz.ai Designer is a Chrome extension that enables real-time, live DOM/CSS editing of any webpage through an AI agent, allowing users to design and iterate on the actual rendered page before shipping the changes as a PR via MCP to a backend dev agent.

## Key Features
- Real-time live DOM/CSS mutation via AI agent in a Chrome side-panel
- Ephemeral edits that do not persist to the original page
- Structured changeset generation for review and handoff
- MCP-based integration with backend dev agents (ai-dev/developerz.ai) to generate PRs
- BYOK (Bring Your Own Key) for OpenRouter and MCP tokens with encrypted storage

## Why It Matters for RAG Builders
It bridges the gap between visual design and code by enabling AI-driven live edits on real pages and automating PR generation, reducing the manual effort in translating design changes into code.
