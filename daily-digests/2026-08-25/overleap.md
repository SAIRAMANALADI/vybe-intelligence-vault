## Summary
overleap enables real-time bidirectional synchronization between Overleaf projects and local filesystems, allowing users to edit LaTeX documents in their preferred local editor while changes instantly reflect on Overleaf and vice versa. It bridges cloud-based collaboration with local development workflows.

## Key Features
- Real-time bidirectional sync between Overleaf and local files using Overleaf's native WebSocket protocol
- Supports both text files (OT sync) and binary files (REST API upload/download)
- AI-agent friendly with debouncing and content stability checks to prevent corrupted uploads
- Flexible project selection via ID, name, or interactive list
- Automatic detection and handling of local-only files for seamless integration

## Why It Matters for RAG Builders
It enables AI agents to seamlessly write and edit LaTeX documents in real-time while collaborators see changes instantly on Overleaf, bridging local development with cloud collaboration.
