## Summary
mcp-worms is a Model Context Protocol (MCP) server providing keyless access to the World Register of Marine Species (WoRMS) database. It enables AI agents to query marine species data, taxonomic lineages, and common names programmatically.

## Key Features
- Keyless access to WoRMS database for marine species data
- Tools for resolving species names, taxonomic lineages, and common names
- Seamless integration with AI agents via MCP protocol
- Supports plain English queries through ask_pipeworx
- Part of Pipeworx gateway for unified access to 1394+ data sources

## Why It Matters for RAG Builders
It provides critical marine species data for AI agents building RAG systems focused on biodiversity, ecology, or marine research.
