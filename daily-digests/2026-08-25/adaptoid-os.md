## Summary
Adaptoid OS is a framework-agnostic operating system for agentic AI that ensures projects are completed with evidence, proper handoffs, and a defined ship gate. It provides a 'Lite' one-file solution and a 'Core' folder-based system to adapt environments based on user briefs.

## Key Features
- Provides 'Lite' (one-file) and 'Core' (folder-based) deployment options for flexibility
- Enforces a 7-stage SDLC with intent locking and preflight checks to prevent false 'done' states
- Generates evidence and playbooks required for successful project handoffs
- Supports multi-host environments (AGENTS, Claude, Cursor) for seamless integration
- Includes a 'make ship-check' command to verify project readiness

## Why It Matters for RAG Builders
Adaptoid OS ensures agentic AI projects are completed reliably with structured processes and evidence, reducing failures from ad-hoc workflows.
