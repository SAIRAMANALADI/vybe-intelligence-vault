## Summary
Samoyed Work is a desktop AI agent application built with Tauri, React, and Rust, designed for autonomous task execution, document processing, and workspace management. It integrates multiple AI models, supports real-time code diagnostics, and provides a user-friendly interface for managing complex workflows.

## Key Features
- Autonomous AI agent with multi-mode task execution (Plan/Code/Document)
- Real-time code diagnostics via LSP integration
- Multi-format document processing (Word, Excel, PDF, Markdown)
- Granular permission system for file and command operations
- Session management with version history and rollback capabilities
