## Summary
nanoodle-mcp converts saved nanoodle workflow graphs into callable MCP tools for AI agents, enabling direct execution of multi-model media pipelines without middleware. It supports both API key and wallet-based (x402) payment modes for NanoGPT services.

## Key Features
- Converts saved workflow graphs into typed MCP tools with derived input schemas
- Supports both API key and wallet-based (x402) payment modes for NanoGPT services
- Enables direct execution of multi-model media pipelines in MCP-compatible IDEs (Claude, VS Code, Cursor, etc.)
- Handles media inputs (images, audio, video) via file paths or HTTPS URLs, with base64 encoding for local files
- Provides real-time cost tracking per tool call and enforces spend limits in wallet mode

## Why It Matters for RAG Builders
It bridges AI agents with executable media workflows, enabling seamless integration of multi-model pipelines into agentic systems without middleware overhead.
