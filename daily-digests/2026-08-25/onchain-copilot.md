## Summary
An AI agentic mobile app designed for onchain finance on the Robinhood Chain, enabling users to interact with their portfolio and execute trades via natural language commands. The app focuses on safety by requiring explicit user confirmation for all agent-driven actions.

## Key Features
- Natural language command processing for onchain actions
- Explicit user confirmation for all transactions
- Account abstraction via ERC-4337 for smoother UX
- Integration with Zerion and CoinGecko for portfolio data
- Sponsored gas and session keys for agent-driven interactions

## Why It Matters for RAG Builders
It demonstrates a novel approach to secure, agent-driven onchain interactions with explicit user oversight, which is critical for building trust in AI-powered financial applications.
