## Summary
Rune is a lightweight macOS menu bar agent that acts as a graphical host and process manager for Oh My Pi (omp), enabling AI-driven coding tasks without Electron or a local server. It integrates with OpenCode Zen's free deepseek-v4-flash-free model for zero-cost token usage.

## Key Features
- Native macOS menu bar agent with ~2.7MB footprint and no Dock presence
- Seamless integration with Oh My Pi (omp) for AI-driven coding tasks via JSONL over stdin/stdout
- Dual operational modes: Plan (read-only) and Build (autonomous execution) with tool-based security
- Supports real-time file editing, shell commands, Git, LSP, and subagents without requiring user confirmation in Build mode
- Secure keychain storage for OpenCode Zen API keys with automatic environment injection for child processes

## Why It Matters for RAG Builders
Rune provides a lightweight, native macOS host for AI agents, enabling seamless integration with Oh My Pi's tooling ecosystem while minimizing overhead and maximizing autonomy for RAG/AI stack builders.
