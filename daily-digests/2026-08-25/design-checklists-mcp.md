## Summary
An unofficial Model Context Protocol (MCP) server that integrates the public Checklist.design catalogue into Codex and other MCP clients, providing searchable UX/UI design checklists for reference during development. The server operates locally without external API dependencies or write operations, caching checklists for offline use.

## Key Features
- Read-only MCP server for seamless integration with Codex and other MCP clients
- Local caching of 110+ UX/UI design checklists for offline access
- Deterministic search and filtering tools (e.g., `search_checklists`, `get_checklist`)
- Idempotent and non-destructive operations with no external API dependencies
- Supports manual cache refresh and custom cache path configuration

## Why It Matters for RAG Builders
Provides structured, searchable UX/UI design checklists directly within AI development workflows, reducing context-switching and improving design consistency in AI-driven projects.
