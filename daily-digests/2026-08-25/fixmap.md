## Summary
FixMap provides a transparent routing layer for coding agents by generating a contextual map of relevant files, test routes, risk notes, and diagnostics from issues or git diffs. It operates locally without third-party API calls, ensuring privacy and accuracy for developers.

## Key Features
- Generates context files with confidence levels and reasons from issues or git diffs
- Provides test routes tailored to the repository's package manager (npm, pnpm, Yarn, Bun)
- Offers risk mapping to highlight potential high-impact areas
- Supports MCP server mode for direct integration with coding agents like Claude Code or Cursor
- Includes a GitHub Action for automated PR reviews and reporting

## Why It Matters for RAG Builders
FixMap streamlines the critical pre-contextualization phase for coding agents, reducing errors and improving efficiency by providing locally generated, accurate file and test mappings without external API dependencies.
