## Summary
CiteGuard is an open-source tool that acts as a watchdog for retracted and problematic citations in academic research. It checks reference lists, provides nuanced editorial statuses, and allows institutions to monitor their publications for problematic citations using data from Retraction Watch, OpenAlex, and Crossref.

## Key Features
- Conservative editorial status resolution with source attribution and confidence notes
- MCP server integration for AI agents (Claude, Cursor, etc.)
- Institution-wide monitoring via ROR ID
- Web-based reference list checker for manual validation
- Published evaluation harness for precision and recall metrics

## Why It Matters for RAG Builders
CiteGuard ensures AI-powered research systems avoid propagating retracted or problematic citations by providing reliable, open-source validation tools for bibliographic integrity.
