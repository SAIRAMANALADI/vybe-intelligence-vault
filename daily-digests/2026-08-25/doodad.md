## Summary
Doodad is a macOS menu bar window manager designed to be controlled by AI agents via the Model Context Protocol (MCP). It enables dynamic window layout management, workspace saving, and system automation without cloud dependencies or telemetry.

## Key Features
- Dynamic window layout control via AI commands or manual drag-and-drop
- Workspace saving and launching to restore app windows and layouts
- Customizable zones for precise window placement across monitors
- System automation tools like keep-awake, screenshots, and annotations
- Zero-dependency, local-only execution with no telemetry or cloud dependencies

## Why It Matters for RAG Builders
It enables AI agents to programmatically control macOS window layouts and workspaces, bridging the gap between natural language commands and desktop automation.
