## Summary
CodePop is an AI-native code intelligence infrastructure designed to provide precise code context for AI coding assistants like Claude Code and Cursor. It combines hybrid retrieval methods with local embedding models to enhance code search and retrieval efficiency.

## Key Features
- Hybrid retrieval combining vector similarity, symbol matching, BM25 full-text, and call graph for weighted fusion
- Local embedding with sentence-transformers to avoid dependency on external APIs
- Incremental indexing with git webhook support and file hash deduplication
- Built-in MCP Server for seamless integration with AI coding assistants
- Benchmarking tools to quantify retrieval quality and token savings

## Why It Matters for RAG Builders
CodePop significantly enhances RAG pipelines by providing precise, context-aware code retrieval with minimal token overhead, making it essential for AI-driven coding assistants.
