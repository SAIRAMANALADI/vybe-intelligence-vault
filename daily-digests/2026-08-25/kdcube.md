## Summary
KDCube is an open-source, self-hosted production runtime and SDK designed to deploy and manage AI applications and agents. It provides multi-user serving, ordered conversation delivery, streaming, identity management, isolated code execution, cost controls, and deployment capabilities while allowing integration with existing agent frameworks like LangGraph or CrewAI.

## Key Features
- Multi-user conversation serving with ordered delivery and streaming
- Integration with existing agent frameworks (LangGraph, CrewAI, Claude Agent SDK)
- Isolated code execution with configurable isolation profiles (subprocess, Docker, split-Docker)
- Built-in ReAct agent with event-aware timeline and semantic streaming
- Cost controls, budgets, and user identity management with scoped credentials

## Why It Matters for RAG Builders
KDCube provides a production-ready runtime to deploy and manage AI agents and applications at scale while maintaining security, isolation, and cost controls, making it essential for RAG builders who need reliable orchestration.
