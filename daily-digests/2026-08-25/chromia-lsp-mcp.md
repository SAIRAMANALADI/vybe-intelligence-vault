## Summary
An MCP server that bridges the Rell Language Server Protocol (LSP) with AI assistants, enabling programmatic access to code analysis features like hover information, diagnostics, and code completions for Rell codebases.

## Key Features
- Provides hover information, diagnostics, and code completions for Rell code via MCP
- Automatically downloads and manages the Rell LSP server for seamless setup
- Supports real-time subscriptions for diagnostic updates
- Offers resource-based access to LSP features via URI endpoints
- Compatible with multiple MCP clients including Claude, Copilot, and Cursor

## Why It Matters for RAG Builders
It enables AI assistants to perform deep Rell code analysis without built-in LSP support, enhancing RAG pipelines with accurate code context and refactoring capabilities.
