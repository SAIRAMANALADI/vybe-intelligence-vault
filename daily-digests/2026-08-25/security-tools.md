## Summary
GhostCheck is an AI-native security scanner designed to detect vulnerabilities, hallucinated dependencies, and agent misbehavior in AI-generated code before deployment. It acts as a lightweight safety net for AI agents, preventing excessive agency, tool poisoning, and supply chain risks.

## Key Features
- AST-powered secret detection for 50+ providers (Python, JS/TS, Go, Java, Dart)
- Honeypot CLI for detecting unauthorized agent behavior with decoy credentials
- Lethal Trifecta AST detector to identify high-risk code patterns
- Plugin-based architecture for extensible security checks and reporters
- OWASP LLM Top 10 report generation for AI-specific vulnerabilities

## Why It Matters for RAG Builders
GhostCheck is essential for RAG builders as it prevents AI agents from introducing critical security flaws or malicious dependencies during code generation, ensuring safer AI-assisted development pipelines.
