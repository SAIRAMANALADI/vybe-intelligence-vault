## Summary
FreeCADClaude is a FreeCAD workbench addon that integrates a Claude chat panel directly into the FreeCAD interface, enabling users to interact with their 3D models using natural language. It leverages the local Claude Code CLI to perform actions like inspecting geometry, modifying designs, and exporting files without requiring an Anthropic API key.

## Key Features
- Docks a Claude chat panel within FreeCAD for real-time model interaction
- Uses local Claude Code CLI (no API key required) for secure, personal-use automation
- Supports read-only and write operations on FreeCAD documents via curated tools
- Enables mobile annotation via a local web server for on-the-go model adjustments
- Provides undoable transactions for safe Python script execution within FreeCAD

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and CAD software, enabling engineers and designers to leverage natural language for complex 3D modeling tasks while maintaining full control over their local environment.
