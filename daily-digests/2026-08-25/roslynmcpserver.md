## Summary
RoslynMcpServer is a Model Context Protocol (MCP) server that leverages Roslyn to provide AI agents with deep C# code analysis, diagnostics, and refactoring capabilities. Unlike standard file-reading MCPs, it enables precise semantic operations like applying code fixes, finding symbol references, and performing safe refactoring without full rebuilds.

## Key Features
- Semantic C# code analysis via Roslyn without full rebuilds
- Precise diagnostics and built-in code fixes (e.g., add using, implement interface)
- Safe semantic refactoring and symbol reference discovery
- CLI integration for dotnet build, test, and custom commands
- Optimized for AI-driven C# development with Python support
