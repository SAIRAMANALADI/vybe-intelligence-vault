## Summary
A CLI-based code agent powered by large language models, enabling AI-driven code assistance through modular skills and plugins. It supports tool invocation, conversation management, file operations, and user interaction with configurable AI effort levels and multi-language support.

## Key Features
- Modular skill system for extensible AI capabilities (8 built-in skills)
- Plugin architecture for adding custom functionality via ZIP files
- Configurable AI effort levels (/effort command) for balancing speed vs. depth
- Multi-language support (40 languages) with customizable translations
- Built-in security mechanisms (confirmation prompts, file protection via .dpc files)
