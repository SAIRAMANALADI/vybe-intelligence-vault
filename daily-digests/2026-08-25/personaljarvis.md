## Summary
PersonalJarvis is an open-source voice-driven meta-orchestrator that executes tasks on your computer or server, integrating with multiple AI providers for real-time interaction, tool execution, and coding agents. It acts as a unified interface for voice commands, automation, and AI-driven workflows.

## Key Features
- Voice-driven task execution with real-time feedback and multi-tiered AI models (realtime, tool, coding agents)
- Isolated mission-based workflows with critic review for safety and reliability
- Interchangeable AI providers (Gemini, Claude, OpenAI, OpenRouter) with automatic failover
- Knowledge Wiki for persistent memory across sessions and self-configuration capabilities
- Headless server support with browser-based UI and strict security via supply-chain signing

## Why It Matters for RAG Builders
It provides a unified, voice-driven interface to orchestrate AI agents and automate complex tasks, reducing the need for manual intervention and improving productivity for RAG builders.
