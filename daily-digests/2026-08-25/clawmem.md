## Summary
ClawMem is an on-device memory layer designed for AI agents like Claude Code, OpenClaw, and Hermes. It provides retrieval-augmented search, hooks, and an MCP server to enable persistent, local memory for agents without cloud dependencies or API keys.

## Key Features
- Hybrid retrieval architecture combining BM25, vector search, and reranking for high-precision memory surfacing
- Multi-graph traversal (semantic, temporal, causal) via adaptive beam search for contextual relevance
- Self-evolving memory notes with deduplication, contradiction detection, and causal relationship inference
- Cross-agent memory sharing via a shared SQLite vault for Claude Code, OpenClaw, and Hermes agents
- Session-scoped focus topic boosting and structured fact injection for enhanced agent context

## Why It Matters for RAG Builders
ClawMem provides a critical on-device memory layer that enables AI agents to retain context, learn from past interactions, and avoid redundant work without relying on cloud services or API keys.
