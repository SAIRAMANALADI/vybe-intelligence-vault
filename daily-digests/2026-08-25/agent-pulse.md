## Summary
AgentPulse is a cross-platform watchdog tool that monitors AI coding agents like Claude Code or Codex CLI, detects session interruptions, and automatically resumes tasks without manual intervention. It ensures uninterrupted execution of AI-driven coding workflows by handling network issues, rate limits, and crashes.

## Key Features
- Multi-strategy detection engine for AI agent interruptions (process state, session files, keywords, heartbeat timeout)
- Smart dual verification to prevent duplicate resumes (interruption signal + no completion mark)
- Cross-platform silent resume support (macOS, Windows, Linux) with tmux/screen direct injection
- Structured logging, real-time observability, and cost tracking for AI agent usage
- Pluggable adapters for Claude Code, Codex CLI, OpenCode, and custom agents

## Why It Matters for RAG Builders
AgentPulse ensures uninterrupted execution of AI coding workflows, critical for maintaining productivity and reducing manual intervention in automated AI agent environments.
