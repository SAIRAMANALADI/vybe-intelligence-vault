## Summary
mcp-scorecard is a CLI and MCP server tool that audits Model Context Protocol (MCP) servers for agent-readiness by evaluating 10 quality dimensions, providing a 0-100 score with actionable fixes. It supports local, remote, and published MCP servers.

## Key Features
- Comprehensive 10-dimension scoring system (schema validity, tool naming, privacy modes, etc.)
- Supports local, remote, and published MCP servers with zero credentials required
- CI/CD integration via GitHub Action and CLI flags (e.g., --min-score)
- Structured JSON and human-readable Markdown output for integration with other tools
- Self-auditing capability as an MCP server for dynamic agent use

## Why It Matters for RAG Builders
It provides a standardized, automated way to evaluate MCP server quality for RAG/AI stacks, ensuring agent-friendly conventions and reducing integration risks.
