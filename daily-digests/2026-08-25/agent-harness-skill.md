## Summary
Agent Harness Skill is a repository-level infrastructure tool that bootstraps, verifies, and enforces agent-ready environments for AI coding agents. It embeds self-sustaining enforcement mechanisms via CI workflows, git hooks, and conventions to ensure reliability for all contributors.

## Key Features
- Bootstraps repositories to be agent-ready with minimal manual setup
- Enforces consistency through three maturity levels (Basic, Verified, Enforced)
- Uses a 'verify-first' principle to check and correct infrastructure before specialized work
- Supports multiple platforms (GitHub, GitLab, Forgejo/Gitea) and package managers (npm, Composer, pnpm)
- Provides enforcement mechanisms across hard, automatic, and soft layers (CI, hooks, conventions)

## Why It Matters for RAG Builders
It ensures AI agents and human contributors work reliably in any repository by embedding consistent, self-enforcing infrastructure checks and bootstrapping processes.
