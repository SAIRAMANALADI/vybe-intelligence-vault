## Summary
Plank is a macOS-native interactive coding agent built in Rust, leveraging the DeepSeek V4 Flash model via a Metal-backed C engine. It offers a Ratatui TUI, REPL, and headless modes with advanced features like persistent sessions, sub-agents, and Git worktrees.

## Key Features
- Interactive Ratatui TUI with markdown rendering and syntax highlighting
- Persistent sessions with checkpointing and instant KV restore
- Sub-agent delegation with cross-engine support (local/remote models)
- Git worktrees for isolated session environments
- Built-in tools (shell, file read/edit, web) and extensible skill system

## Why It Matters for RAG Builders
Plank provides a robust, locally-executable agent framework with advanced session management and tooling, making it ideal for developers building AI-driven coding assistants or RAG systems requiring persistent, interactive workflows.
