## Summary
HomeLabCMDB is an Ansible-fed, SQLite-backed Configuration Management Database (CMDB) designed for homelabs. It provides a lightweight, offline-capable web UI to track hosts, containers, CVEs, and Tailscale nodes, with query capabilities via an MCP server for LLMs like Claude.

## Key Features
- Agentless inventory collection via Ansible over SSH
- Interactive topology graph for visualizing lab infrastructure
- SQLite-backed single-file database for portability
- MCP server for querying the CMDB via LLMs like Claude
- Integrated Trivy CVE scanning and vulnerability tracking

## Why It Matters for RAG Builders
It provides a lightweight, offline-capable CMDB tailored for homelabs that integrates vulnerability tracking, topology visualization, and LLM-native querying, making it ideal for AI stack builders managing small-scale infrastructure.
