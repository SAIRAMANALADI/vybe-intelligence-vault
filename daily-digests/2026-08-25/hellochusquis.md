## Summary
HelloChusquis is an AI-powered terminal agent with a chat interface, web search, file management, code execution, and multi-provider AI integrations. It supports both CLI and web-based interactions with REST API capabilities.

## Key Features
- Multi-provider AI fallback with 15+ supported models
- Built-in tools for shell commands, code execution, file management, and web search
- Browser automation with human-like interactions and anti-detection stealth mode
- Smart history compression and persistent memory via SQLite
- REST API with rate limiting, SSE streaming, and health endpoints
