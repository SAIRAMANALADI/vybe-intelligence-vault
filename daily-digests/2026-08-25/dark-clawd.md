## Summary
Dark Clawd is a Bloomberg-style terminal intelligence layer and autonomous agent suite for Solana, providing real-time market surveillance, wallet context, AI-driven analysis, and holder operations through a TUI interface and Python-based agent framework.

## Key Features
- Bloomberg-style Terminal UI with real-time market data visualization (price charts, order books, heatmaps)
- Autonomous agent framework (Ralph OODA loop) for AI-driven trading and analysis
- Multi-service integration (Birdeye, Helius, Phoenix, News APIs) for comprehensive market insights
- Wallet context and holder operations with local wallet management
- Modular architecture supporting both TUI and headless/daemon modes
