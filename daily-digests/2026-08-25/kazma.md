## Summary
Kazma is an autonomous AI agent framework featuring a LangGraph-based supervisor, multi-platform orchestration, and Arabic-first design. It supports swarm patterns, human-in-the-loop safety, and encrypted credential storage, enabling secure and scalable agent deployments across Telegram, Discord, Slack, web, and terminal interfaces.

## Key Features
- LangGraph supervisor with ReAct loop and durable checkpointing
- Six swarm orchestration patterns with circuit breakers and self-improvement
- Three-tier human-in-the-loop safety gates for tool execution approval
- AES-256-GCM encrypted secret vault for secure credential storage
- Multi-platform support (Telegram, Discord, Slack, web, terminal)
