## Summary
A monorepo providing tools for interacting with Datadog logs and metrics via the Model Context Protocol (MCP). It includes an MCP server for querying and analyzing Datadog logs, a sample Node.js app for sending local PC metrics/logs to Datadog, and a UI component for visualizing investigations.

## Key Features
- MCP server for Datadog log search, aggregation, and visualization with compact text output for AI models
- Headless investigation mode that stores results server-side to avoid context bloat
- Interactive UI for timeline charts, facet breakdowns, and log table filtering
- Automated message pattern analysis and clustering for log insights
- Self-contained HTML report export and CSV/JSON output for investigations

## Why It Matters for RAG Builders
