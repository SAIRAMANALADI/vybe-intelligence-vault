## Summary
Casa integrates Claude-powered AI agents into Home Assistant as a managed app, enabling natural language control of smart homes via Telegram, voice interfaces, and scheduled automation. It provides a fleet of specialized agents with access to Home Assistant APIs and optional long-term memory.

## Key Features
- Multi-channel agent interactions (Telegram, voice, Assist)
- Specialized subagents with scoped tool permissions
- Long-term memory via Hindsight server
- Secure secret management with 1Password references
- Cron-style scheduling and heartbeat automation
