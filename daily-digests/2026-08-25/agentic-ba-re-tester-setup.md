## Summary
Agentic-BA-RE-Tester-Setup is a framework for Agentic Requirements Engineering (ARE) that automates and enhances requirements gathering, testing, and business analysis using specialized AI agents and skills. It integrates with Azure DevOps, GitHub Copilot, and MCP servers to streamline workflows like test case creation, architecture reviews, and hierarchical RAG generation.

## Key Features
- Specialized AI agents for requirements engineering, testing, business analysis, and enterprise architecture
- Pre-built prompts for automated test case creation, architecture reviews, and business case analysis
- Integration with Azure DevOps, MongoDB, and Playwright for end-to-end workflow automation
- Hierarchical RAG generation for project-specific knowledge graphs
- Modular skill system for domain-specific expertise (IREB, ISTQB, OKR, SHERPA)

## Why It Matters for RAG Builders
It accelerates and standardizes requirements engineering and testing workflows by leveraging AI agents and automation, reducing manual effort while improving accuracy and compliance with industry frameworks.
