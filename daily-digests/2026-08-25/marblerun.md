## Summary
MarbleRun is a Python-based automation framework for orchestrating autonomous LLM agent chains, enabling sequential multi-agent workflows with persistent state management and handoff-based context passing. It supports multi-model LLMs, role-based agent specialization, and local-first execution with zero external dependencies beyond the Claude Code CLI.

## Key Features
- Chain execution with sequential multi-agent loops (worker-reviewer-controller patterns)
- Persistent state management via handoff files, round counters, and status tracking
- Multi-model support with fallback mechanisms and role-based agent specialization
- Zero external dependencies (pure Python stdlib + Claude Code CLI)
- Background execution, Telegram notifications, and pipe mode for single LLM calls

## Why It Matters for RAG Builders
MarbleRun enables RAG builders to create autonomous, multi-agent workflows that chain LLM interactions with persistent state, making it essential for building complex, unattended AI systems.
