## Summary
A production-ready RAG Q&A service leveraging Amazon Bedrock's Titan Embeddings and Converse API for retrieval and generation, with ChromaDB for vector storage. Supports both local and serverless AWS deployments via Lambda and API Gateway, including Terraform IaC for infrastructure provisioning.

## Key Features
- End-to-end RAG pipeline with Titan Embeddings for retrieval and Bedrock Converse API for generation
- Dual deployment options: local FastAPI server or serverless AWS Lambda + API Gateway via Terraform
- ChromaDB vector store with persistence and cold-start seeding for Lambda deployments
- Comprehensive IaC for AWS infrastructure, including IAM policies scoped to Bedrock inference profiles
- Documented troubleshooting for Lambda package size limits and cross-platform dependency builds

## Why It Matters for RAG Builders
This repository provides a production-grade reference implementation for building scalable RAG systems on AWS Bedrock, including critical deployment considerations often overlooked in demos.
