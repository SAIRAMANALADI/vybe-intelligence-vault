## Summary
Observer is a Node.js-based MCP server and skill that enables real-time interaction with video content (e.g., lectures, podcasts, or conference talks) by transcribing, analyzing, and preparing contextual tools for an AI agent. It serves a web player, exposes MCP tools for transcript access, concept preparation, and visual artifact generation, and allows agents to answer questions at exact pause points.

## Key Features
- Single Node process serving both a web player and MCP tools for seamless agent interaction
- Automated transcription (captions or speech recognition) and contextual preparation of concepts, definitions, and visuals
- MCP tools for transcript access, concept management, artifact building, and real-time agent responses at pause points
- Support for interactive charts (ECharts), bespoke visuals (D3), and equations (KaTeX) with theme-aware rendering
- Built-in browser-based TTS and STT (Kyutai Pocket TTS, ONNX Runtime) with multi-provider fallback

## Why It Matters for RAG Builders
Observer enables AI agents to dynamically prepare and respond to video content in real-time, bridging the gap between passive viewing and interactive learning or analysis.
