## Summary
A Roslyn-based MCP server that provides AI agents with deep semantic insights into .NET codebases, including type hierarchies, call graphs, diagnostics, refactoring, and code quality audits. It enables advanced code navigation, analysis, and transformation for AI-driven development workflows.

## Key Features
- 57+ tools for deep .NET code analysis including call graphs, type hierarchies, and DI registrations
- Advanced diagnostics, refactoring, and code fixes with structured edits
- Test intelligence: uncover uncovered symbols, generate test skeletons, and analyze test coverage
- External assembly inspection, IL decompilation, and reflection usage detection
- Project health auditing, complexity metrics, and code quality violation detection
