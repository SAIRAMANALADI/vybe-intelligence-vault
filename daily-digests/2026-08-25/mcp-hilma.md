## Summary
mcp-hilma provides an MCP (Model Context Protocol) server for accessing Finnish government public procurement notices (Hilma data) via a standardized interface. It is part of the Pipeworx ecosystem, which aggregates 1334+ live data sources for AI agents.

## Key Features
- Provides structured access to Finnish public procurement notices via MCP
- Integrates seamlessly with AI agents and MCP clients (Claude, Cursor, etc.)
- Part of a larger gateway (Pipeworx) offering 1334+ data sources
- Supports plain English queries via ask_pipeworx for simplified interaction
- Open-source with MIT license for easy adoption

## Why It Matters for RAG Builders
It enables AI agents to directly query Finnish public procurement data, expanding the scope of RAG applications with real-time, structured government information.
