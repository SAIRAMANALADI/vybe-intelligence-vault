## Summary
A Model Context Protocol (MCP) server that unifies access to 30+ Proto-OKN knowledge graphs, enabling AI assistants to discover, query, and bridge heterogeneous RDF datasets via SPARQL. It supports cross-graph queries, ontology-driven search expansion, and schema visualization for natural-language interactions.

## Key Features
- Unified interface for 30+ Proto-OKN knowledge graphs with a single MCP endpoint
- Cross-graph SPARQL querying and result merging for multi-source insights
- Ontology-driven query expansion (e.g., MONDO, UBERON) to improve recall
- Built-in identifier bridging across graphs (e.g., Ensembl ↔ NCBI Gene)
- Schema visualization and chat transcript generation for explainability

## Why It Matters for RAG Builders
It enables AI assistants to seamlessly query and integrate 30+ heterogeneous knowledge graphs via natural language, drastically reducing the complexity of building RAG systems over structured, interconnected data.
