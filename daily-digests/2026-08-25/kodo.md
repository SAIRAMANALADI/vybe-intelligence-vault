## Summary
kodo is a proprietary tool for building and managing a local library of LLM models from sources like Hugging Face, Ollama, and LM Studio. It provides a Typer CLI and browser-based UI for browsing, pulling, and running models, with support for voice models, vision capabilities, and MCP tool integration.

## Key Features
- Aggregates models from multiple sources (Hugging Face, Ollama, LM Studio) into a single local library
- Supports both chat and voice models with TTS/STT capabilities
- Provides a Typer CLI and browser-based UI for model management and interaction
- Offers OpenAI-compatible API endpoints for serving models and voice functionalities
- Includes project scaffolding for purpose-built assistants with tools and prompts

## Why It Matters for RAG Builders
kodo simplifies the management and deployment of local LLMs, enabling RAG builders to maintain a centralized, configurable library of models with advanced capabilities like voice and vision support.
