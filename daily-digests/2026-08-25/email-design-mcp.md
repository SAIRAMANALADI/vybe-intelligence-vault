## Summary
email-design-mcp is a Windows-based application that simplifies the creation of responsive email templates using AI, MJML, and local MCP server integration. It enables users to generate, customize, and export professional emails without requiring API keys or advanced coding skills.

## Key Features
- AI-powered email content generation via Claude or Cursor without API keys
- Responsive email templates using MJML for cross-device compatibility
- Local MCP server for seamless integration with development workflows
- Brand-aware tools for consistent email design and editing
- Visual editor with live preview for real-time adjustments
