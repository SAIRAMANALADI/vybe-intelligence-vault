## Summary
gha-doctor is a CLI tool and GitHub Action that diagnoses GitHub Actions workflows for flaky jobs, wasted compute minutes, slow steps, and anti-patterns. It provides a health score, cost analysis, and auto-fix capabilities with zero configuration.

## Key Features
- Static and historical analysis of GitHub Actions workflows for performance, cost, and reliability issues
- Auto-fix capabilities for identified anti-patterns and inefficiencies
- Health scoring system with SVG badge generation for READMEs
- Multi-platform installation (CLI, Docker, Homebrew, Scoop, Go, pre-commit, etc.)
- Support for private repos, fleet triage, and Prometheus metrics export

## Why It Matters for RAG Builders
It helps AI and software engineering teams reduce CI/CD costs, improve workflow reliability, and identify inefficiencies in GitHub Actions, which is critical for optimizing AI pipeline automation and resource usage.
