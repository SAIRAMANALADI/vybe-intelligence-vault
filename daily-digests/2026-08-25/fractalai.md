## Summary
FractalAI is a web-based fractal generator leveraging WebGL and regl for real-time, GPU-accelerated fractal visualization. It includes 100+ fractal types, interactive controls, machine learning-powered discovery, and extensive performance optimizations for smooth rendering.

## Key Features
- 100+ fractal types with real-time rendering
- Machine learning-powered fractal discovery and scoring
- Extensive performance optimizations (OffscreenCanvas, Worker-based rendering, adaptive quality)
