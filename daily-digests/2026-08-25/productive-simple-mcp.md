## Summary
A Model Context Protocol (MCP) server that integrates Productive.io into AI workflows, enabling AI assistants to interact with projects, tasks, time entries, comments, and other resources via a standardized interface. Optimized for read operations with optional write capabilities.

## Key Features
- Comprehensive read operations for projects, tasks, time entries, comments, and team members
- Optional guarded write capabilities (create/update/delete) for task management and comments
- LLM-optimized responses with multiple output formats (Hybrid, JSON, TOON) to reduce token consumption
- Efficient filtering, pagination, and search across Productive.io resources
- Time tracking metrics and task history for detailed activity tracking

## Why It Matters for RAG Builders
It enables AI assistants to seamlessly interact with Productive.io, enhancing task automation and project management within AI-driven workflows.
