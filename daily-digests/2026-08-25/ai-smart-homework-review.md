## Summary
A full-stack AI-powered homework grading and teaching assistant platform built with FastAPI, Vue 3, and LangChain. It enables multi-model integration, automated grading, AI teaching assistants, and plagiarism detection for educational workflows.

## Key Features
- Multi-model AI integration (DeepSeek, Qwen, Doubao, etc.) for automated grading and teaching assistance
- LangChain-based AI teaching assistant with real-time SSE streaming and tool-based query execution
- Dual-engine plagiarism detection (text + image) with customizable thresholds and template exclusion
- RBAC-based role management with dynamic menu generation and JWT authentication
- Rich text editing, real-time collaboration, and comprehensive dashboard analytics for administrators, teachers, and students
