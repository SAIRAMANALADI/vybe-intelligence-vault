## Summary
Beaver is an embedded, SQLite-based Python library that provides a local-first, serverless database for managing complex data types like documents, vectors, graphs, and time-series logs with minimal dependencies and high performance.

## Key Features
- Supports key-value dictionaries, persistent lists, and blob storage with TTL and atomic operations
- Includes vector search, full-text search, and fuzzy search capabilities
- Provides a knowledge graph for relationship management and multi-hop traversal
- Features a pub/sub system, time-indexed logs, and event-driven callbacks for real-time workflows
- Ensures thread-safe and multi-process-safe operations with robust inter-process locking

## Why It Matters for RAG Builders
Beaver simplifies local data management for AI applications by offering a lightweight, embedded database with built-in vector search and document storage, reducing the need for external services.
