## Summary
GoodMemory is a durable memory layer for AI products and coding agents that enables persistent user and project memory management. It provides APIs for storing, retrieving, auditing, and deleting memory while integrating with agent frameworks like Codex and Claude Code.

## Key Features
- Durable memory API with `remember`, `recall`, `buildContext`, `feedback`, and `forget` operations
- Local-first storage with SQLite by default and optional Postgres support
- Integration with Codex, Claude Code, and MCP clients via hooks and read-only access
- Auditable memory operations with traceability, export, and deletion controls
- Benchmark-verified performance with transparent, reproducible evaluation metrics

## Why It Matters for RAG Builders
GoodMemory provides a critical memory layer for AI agents and applications, enabling persistent context retention and auditable memory management essential for RAG systems and agent frameworks.
