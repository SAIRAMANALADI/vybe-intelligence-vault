## Summary
Learn Shell is an agent-native teaching OS designed to provide a persistent, structured learning environment for AI agents and humans. It enables AI teachers to create, manage, and track lessons, exercises, flashcards, and live teaching sessions with built-in grading and memory layers accessible via MCP.

## Key Features
- Agent-native teaching OS with MCP integration for AI agents to interact via 50+ tools and resources
- FSRS-scheduled flashcards and graded exercises with real-time feedback
- Persistent memory layer (`get_context`) for AI teachers to resume learning sessions accurately
- Live teaching sessions with turn-based interaction and mid-lesson recovery
- Self-hosted, local-first design with optional cross-device deployment (trust boundary enforced)

## Why It Matters for RAG Builders
Learn Shell provides a structured, persistent, and agent-accessible learning environment that enables AI teachers to maintain context and continuity across sessions, critical for effective RAG and long-term learning relationships.
