## Summary
A Model Context Protocol (MCP) server that enables AI tools like Claude to interact with Follow Up Boss (FUB) CRM via plain English commands. It provides 160 tools covering 100% of the FUB API, including read/write access to contacts, deals, tasks, and communications, with optional safe mode to restrict deletions.

## Key Features
- 160 tools covering 100% of the Follow Up Boss API, including meta tools for help/about
- Safe Mode (default) to restrict deletion operations, with optional Full Access mode
- OAuth persistence across restarts for seamless AI tool connectivity
- Comprehensive read/write capabilities for contacts, deals, tasks, communications, and custom fields
- Self-hosted under Elastic License 2.0, free for personal/business use (no hosted service allowed)

## Why It Matters for RAG Builders
It enables AI-powered real estate agents to directly interact with their CRM data using natural language, streamlining workflows and reducing manual data entry.
