## Summary
A remote MCP server for personal finance management that enables users to log expenses via voice, import bank statements, and track budgets, trends, and net worth across any currency. It provides real-time financial insights through interactive MCP Apps and supports both manual and automated transaction logging.

## Key Features
- Voice and text-based expense logging with receipt photo parsing
- Bulk bank statement imports with idempotent deduplication and reconciliation
- Real-time budget tracking and net worth computation via SQL aggregates
- Multi-currency support with frozen exchange rates at transaction time
- Interactive MCP Apps for dashboards (budgets, trends, accounts) rendered in chat

## Why It Matters for RAG Builders
It provides a seamless, AI-native way to manage personal finances with real-time insights and multi-currency support, reducing manual data entry and improving financial tracking accuracy.
