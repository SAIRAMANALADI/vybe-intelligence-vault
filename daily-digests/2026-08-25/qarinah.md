## Summary
Qarinah is a local-first, evidence-linked context engine designed to enable seamless handoffs between coding agents (e.g., Codex, Claude Code, Cursor) without requiring agents to replay entire project histories. It compiles compact, cited packs of project memory for efficient task continuation.

## Key Features
- Cross-agent project context continuity with 98.71% reduction in repeated context tokens
- Append-only JSONL event ledger with SHA-256 content hashes for verifiable evidence
- Deterministic retrieval via SQLite FTS5 and typed graph relationships
- Consent-gated MCP retrieval and optional governance integration (Maqam)
- Portable Open Knowledge Format (OKF) exports and rebuildable Markdown/JSON views

## Why It Matters for RAG Builders
Qarinah drastically reduces context overhead for RAG/AI stacks by compiling compact, cited packs of project memory, enabling seamless agent handoffs without replaying full histories.
