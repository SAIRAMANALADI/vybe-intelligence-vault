## Summary
An autonomous AI agent that controls a real browser to perform multi-step tasks using local models (via Ollama) or cloud APIs. It dynamically interacts with web pages, handles complex workflows, and integrates with FastAPI for a web-based control panel.

## Key Features
- Dynamic interaction with web pages using accessibility tree snapshots for semantic understanding
- Sub-agent architecture (researcher/operator) for task delegation and isolation
- Security layer for high-risk actions requiring user confirmation
- Persistent browser sessions with profile support for logged-in states
- FastAPI-based web panel for real-time task monitoring and control

## Why It Matters for RAG Builders
It enables AI agents to autonomously perform complex, multi-step web interactions without hardcoded selectors, bridging the gap between LLM planning and real-world browser automation for RAG and AI workflows.
