## Summary
RepoMind is a Retrieval-Augmented Generation (RAG) chatbot designed to answer natural-language questions about any public GitHub repository. It clones the code, chunks it intelligently, embeds it into a local vector database, and provides cited, grounded answers with file and line references, while also generating architecture diagrams on demand.

## Key Features
- Grounded, cited answers with exact file and line references from indexed repositories
- AST-aware chunking for Python files to preserve function/class boundaries
- Auto-generated architecture diagrams from import relationships using Mermaid.js
- Conversational memory for follow-up questions and natural small talk
- Zero-friction deployment with free-tier infrastructure (local embeddings, ChromaDB, Groq LLM)

## Why It Matters for RAG Builders
RepoMind enables AI engineers to build conversational agents that provide accurate, cited answers about codebases without hallucinations, while also offering visual insights into repository architecture.
