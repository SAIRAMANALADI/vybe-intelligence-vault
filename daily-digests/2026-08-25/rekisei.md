## Summary
rekisei is a reusable agent skill designed to automate the editing and compilation of a clean, concise LaTeX resume through conversational AI tools like Claude Code or Codex. It provides a structured workflow for dynamically updating resume content and regenerating a PDF output.

## Key Features
- Agent skill files (`CLAUDE.md`/`AGENTS.md`) for structured resume editing instructions
- Automated LaTeX compilation and PDF regeneration after edits
- Support for dynamic content updates via conversational AI
- Preconfigured LaTeX template with placeholders for personalization
- Cross-platform compatibility with macOS and Unix-like systems
