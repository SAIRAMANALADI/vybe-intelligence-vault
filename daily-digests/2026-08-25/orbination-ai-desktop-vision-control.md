## Summary
Orbination-AI-Desktop-Vision-Control enables AI applications to interact with and control Windows desktops through a native MCP server, offering UI automation, OCR with dark theme support, and batch action sequencing for accessibility and automation tasks.

## Key Features
- Native Windows MCP server for desktop control and automation
- OCR with dark theme support for accurate text recognition
- Window occlusion detection to handle overlapping windows
- Batch action sequencing for multi-step automation workflows
- 45+ built-in tools for UI interaction, text reading, and navigation
