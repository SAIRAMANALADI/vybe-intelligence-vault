## Summary
A live-updating tracker that monitors and compares vector database projects, integrations, and benchmarks, refreshing data every 15 minutes from GitHub and other sources to provide an always-current landscape of the vector DB ecosystem.

## Key Features
- Automated data collection and updates every 15 minutes via GitHub Actions cron
- Structured comparison table covering maturity, integrations, language support, and activity metrics
- Multi-language README support (English, Chinese, Japanese, Korean, Spanish, Portuguese)
- Real-time tracking of 50+ vector database projects with GitHub star counts and update timestamps
- Open-source and community-driven with clear documentation and contribution guidelines

## Why It Matters for RAG Builders
It provides RAG builders with a continuously updated, centralized reference for evaluating and selecting vector databases based on real-time data and integrations.
