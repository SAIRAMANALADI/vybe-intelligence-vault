## Summary
Nova is an autonomous AI agent that discovers trending YouTube Shorts, analyzes them using Google Gemini, and generates original cartoon-style images and videos. It includes a Streamlit-based frontend for visual interaction and pipeline management.

## Key Features
- Automated discovery of trending YouTube Shorts via YouTube Data API v3
- Scene-by-scene video analysis using Google Gemini (gemini-3.5-flash)
- Original cartoon-style image generation via Pollinations AI (Flux model)
- 5-second animated video creation with MoviePy and PIL (Ken Burns effect)
- Streamlit frontend for interactive pipeline execution and result browsing
