## Summary
Pawn is a desktop AI coding agent GUI that combines features from Cursor, ChatGPT, OpenCode, and Claude Desktop into a flexible, open-source application. It enables users to bring their own API keys, install custom plugins, and automate coding tasks with multi-model routing and tool-calling capabilities.

## Key Features
- Tool-calling agent loop with up to 25 rounds per turn for complex tasks
- Multi-model smart routing based on task complexity and cache optimization
- Cross-platform computer use with multimodal eyesight (screenshot integration)
- Claude Code and OpenAI Agents compatibility for skill and plugin integration
- Local SQLite database for project sessions, transcripts, and usage tracking

## Why It Matters for RAG Builders
Pawn provides a flexible, open-source framework for building AI-powered coding agents with customizable tooling and multi-model routing, reducing vendor lock-in for RAG and AI stack builders.
