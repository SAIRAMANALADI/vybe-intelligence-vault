## Summary
MCP Deep Search is an MCP server that enables deep web search across multiple providers like Google, Bing, Brave, and Perplexity. It allows AI agents to perform both simple searches and comprehensive multi-engine research with structured results.

## Key Features
- Supports multiple search providers (Brave, Google, OpenAI, Anthropic, Perplexity, etc.)
- Provides both simple search and comprehensive research tools
- Auto-restart and reliability features for MCP servers
- CLI and MCP client integration for seamless use
- Structured results with configurable parameters (max results, provider selection)

## Why It Matters for RAG Builders
