## Summary
A multimodal RAG system enabling unified search across text, images, and video using Gemini Embedding 2 vectors and Supabase's pgvector. The tool provides a Gradio-based web interface for easy file uploads and semantic queries.

## Key Features
- Unified search across text, images, and video without format conversion
- Leverages Gemini Embedding 2 for high-accuracy vector embeddings
- Supabase with pgvector for scalable vector storage and retrieval
- Gradio-based web interface for intuitive user interaction
- Local deployment with minimal setup required
