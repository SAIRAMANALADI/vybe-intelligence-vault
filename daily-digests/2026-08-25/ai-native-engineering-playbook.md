## Summary
A playbook outlining engineering practices for shipping production software using AI coding agents, distilled from a live multi-tenant B2B SaaS built solo in four months. Focuses on verification, coordination, context management, and judgment to mitigate risks in AI-driven development.

## Key Features
- Living project context dashboard (CLAUDE.md/AGENTS.md) for real-time status updates
- Task-specific worktrees and strict territorial boundaries to prevent parallel agent conflicts
- Hard approval gates for irreversible decisions (money, auth, schema, deploys)
- Adversarial review panels for financial paths to catch subtle bugs
- Model evaluation on real production workloads, not benchmarks

## Why It Matters for RAG Builders
It provides a battle-tested framework for safely scaling AI-driven development while minimizing costly errors in production systems.
