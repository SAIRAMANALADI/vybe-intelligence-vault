## Summary
PyScrappy is an AI-native web scraping toolkit that converts websites into structured, LLM-ready data, usable as a Python library or an MCP server for AI agents. It supports generic scraping, JavaScript rendering, and integrates with AI workflows via MCP or direct tool calls.

## Key Features
- Generic and specialized scrapers for 20+ platforms (Wikipedia, IMDB, stocks, news, etc.)
- MCP server integration for AI agents (Claude, Cursor, local LLMs) to call scrapers as tools
- JavaScript rendering support via Playwright for dynamic content
- Concurrent scraping, proxy support, and rate limiting for robust data collection
- Type-safe design with full type hints and plugin extensibility for custom scrapers

## Why It Matters for RAG Builders
PyScrappy bridges the gap between raw web data and AI-ready structured outputs, enabling seamless integration of web scraping into RAG pipelines and AI agent workflows.
