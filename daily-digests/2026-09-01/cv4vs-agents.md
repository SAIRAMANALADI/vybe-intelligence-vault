## Summary
A Visual Studio extension that integrates Claude Code's CLI into the IDE, providing a rich chat interface, interactive terminal, and exposing Visual Studio's editor, debugger, and build system to AI agents via MCP tools. It enables seamless AI-assisted coding within the Visual Studio environment.

## Key Features
- Dual-pane interface (rich chat and interactive terminal) with shared session storage
- 50+ MCP tools exposing Visual Studio's editor, debugger, diagnostics, and build system to AI agents
- Clickable file references and inline diffs with editable side-by-side comparisons
- Lazy initialization for performance, minimizing resource usage until interaction occurs
- Sub-agent management panel for tracking and controlling multiple concurrent AI agents

## Why It Matters for RAG Builders
It bridges the gap between AI-powered coding assistants and Visual Studio's robust development environment, enabling seamless AI-driven refactoring, debugging, and code navigation directly within the IDE.
