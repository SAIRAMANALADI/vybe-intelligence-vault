## Summary
Design-slop is a desktop application that identifies and removes generic AI-generated web design patterns, such as repetitive layouts, excessive whitespace, and predictable icon usage, to improve UI uniqueness and accessibility. It scans websites for machine-generated design elements and suggests fixes to restore a human touch.

## Key Features
- Scans web pages for AI-generated design patterns
- Provides high-confidence detection of generic layouts
- Suggests accessibility improvements
- Fixes spacing and layout inconsistencies
- Standalone Windows application with no coding dependencies

## Why It Matters for RAG Builders
It helps AI engineers and designers eliminate generic UI patterns that can degrade user experience and accessibility in AI-generated or templated web designs.
