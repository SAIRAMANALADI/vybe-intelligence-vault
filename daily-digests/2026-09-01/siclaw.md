## Summary
Siclaw is an open-source AI agent designed for DevOps and SRE teams to perform read-only infrastructure diagnostics. It automates evidence gathering, hypothesis testing, and root-cause analysis through a 4-phase workflow, enabling teams to investigate issues in plain language via terminal, web UI, or chat channels without altering the environment.

## Key Features
- 4-phase investigation workflow (evidence gathering, hypothesis testing, root-cause analysis)
- Read-only by default with optional recommendations for remediation
- Multi-channel access (terminal, web UI, chat platforms like Slack, Discord)
- Investigation memory and reusable skills for playbook automation
- Agent tracing and integration with observability tools like Langfuse and Phoenix

## Why It Matters for RAG Builders
Siclaw streamlines incident investigation for DevOps and SRE teams by automating deep, read-only diagnostics, reducing mean time to resolution (MTTR) and improving system reliability without risking environment changes.
