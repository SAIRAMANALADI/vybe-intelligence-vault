## Summary
A real-time vessel tracking system leveraging AIS (Automatic Identification System) radio broadcasts to provide live ship positions worldwide. It integrates with the AISStream.io platform to deliver vessel data including position, speed, course, and navigational status.

## Key Features
- Live vessel tracking with position, speed, course, and navigational status
- Bounding box and point-based vessel queries for specific regions
- Coverage verification to distinguish between no data and no coverage
- Integration with MCP clients (Claude Desktop, Cursor, Windsurf) for seamless AI agent access
- Free tier via AISStream.io with BYO API key support

## Why It Matters for RAG Builders
Provides critical real-time maritime data for AI systems requiring geospatial and vessel tracking capabilities, enabling applications in logistics, navigation, and supply chain monitoring.
