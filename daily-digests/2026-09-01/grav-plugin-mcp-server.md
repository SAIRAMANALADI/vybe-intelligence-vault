## Summary
This Grav plugin implements a Model Context Protocol (MCP) server endpoint directly within a Grav CMS site, enabling AI agents and MCP clients to interact with Grav's REST API over Streamable HTTP. It bridges Grav's content and services to external AI tools via OAuth or API key authentication.

## Key Features
- Hosted MCP server endpoint served directly from Grav sites over HTTP
- Supports OAuth 2.1 dynamic client registration for hosted AI connectors (e.g., claude.ai)
- Integrates with Grav's REST API plugin for tool discovery, permissions, and rate limiting
- Provides 49+ MCP tools across 11 domains (pages, media, users, GPM, etc.) and resources/prompts
- Supports both API key and OAuth authentication for CLI/desktop clients (e.g., Claude Code)

## Why It Matters for RAG Builders
This plugin enables seamless integration of Grav CMS with AI agents and MCP clients, allowing dynamic content and tool access for AI-driven workflows without requiring local server setups.
