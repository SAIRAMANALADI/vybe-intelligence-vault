## Summary
Perigon.CLI is a .NET-based development assistant tool that accelerates the creation of web applications using Aspire, ASP.NET Core, and EF Core. It offers CLI, WebUI, and MCP Server interfaces to generate boilerplate code, DTOs, controllers, and client-side services via intelligent code generation and LLM integration.

## Key Features
- Smart code generation for DTOs, repositories, controllers, and client-side services
- Multi-interface support (CLI, WebUI, MCP Server) for flexible developer workflows
- Customizable code generation via Razor templates and project-specific configurations
- Integration with ASP.NET Core, EF Core, and .NET Aspire for modern web development
- Supports TypeScript client generation from OpenAPI/Swagger specs

## Why It Matters for RAG Builders
It significantly reduces boilerplate code and accelerates backend and frontend development for AI and RAG stack builders by automating repetitive tasks and integrating modern tooling.
