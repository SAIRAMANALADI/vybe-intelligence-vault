## Summary
Momoi is a persistent, single-owner personal agent designed for private chat deployments, integrating conversation, memory, tools, scheduled work, and autonomous time into a continuous runtime. It supports QQ (NapCat) and WeChat, uses Anthropic/OpenAI-compatible models, and extends capabilities via MCP.

## Key Features
- Persistent single-owner runtime with continuous memory and identity across time
- Hybrid memory architecture with provenance-aware layers (working context, confirmed memory, Episodes, reflection memory)
- Mandatory recall mechanism for context selection and Episode binding in every owner turn
- Built-in tools and MCP integration for extensible agent capabilities
- Time-aware scheduling with Goals, Heartbeats, and quiet hours for autonomous behavior

## Why It Matters for RAG Builders
Momoi provides a robust framework for building persistent, memory-aware personal agents that can integrate with RAG systems while maintaining long-term context and autonomous capabilities.
