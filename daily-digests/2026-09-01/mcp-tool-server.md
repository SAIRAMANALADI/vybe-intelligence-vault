## Summary
A production-ready Model Context Protocol (MCP) tool server built with FastMCP, FastAPI, and Pydantic v2. It provides a clean scaffold for exposing AI agent-discoverable tools via MCP, featuring three example tools, a REST health endpoint, and 100% test coverage.

## Key Features
- Decoupled tool architecture with standalone `Tool` instances for MCP compatibility and unit-testability
- Business logic isolated from MCP-specific code, ensuring clean separation of concerns
- Multi-stage Docker build for optimized production deployment with minimal runtime footprint
- Dual transport support (HTTP and stdio) for flexible client integration
- 100% test coverage with mocked network dependencies for reliable CI/CD

## Why It Matters for RAG Builders
It provides a production-ready scaffold for exposing AI agent-discoverable tools via the MCP standard, enabling seamless integration with LLM clients and agents.
