## Summary
A Model Context Protocol (MCP) server that provides tools to discover and retrieve details about parkrun events worldwide without requiring API keys or authentication. It enables users to search, filter, and analyze parkrun data globally.

## Key Features
- No API keys or authentication required for access
- Four specialized tools for searching and retrieving parkrun event data
- Global coverage of parkrun events with distance-based sorting
- Provides detailed event information and worldwide statistics
- Lightweight and easy to integrate with Claude Code/Desktop

## Why It Matters for RAG Builders
It simplifies access to structured community event data, which can be valuable for AI applications needing real-world event information without complex API integrations.
