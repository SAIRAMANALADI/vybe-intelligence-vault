## Summary
An MCP (Model Context Protocol) server that provides structured access to ISO 32000 (PDF) specification documents, enabling LLMs to navigate, search, and analyze PDF specifications through well-defined tools and APIs.

## Key Features
- Multi-spec support for up to 17 PDF-related documents (ISO 32000-2, PDF/UA, etc.)
- Structured content extraction (headings, paragraphs, lists, tables, notes)
- Full-text search with section-aware context snippets
- Normative requirements extraction (shall/must/may) per ISO conventions
- Version comparison between PDF 1.7 and PDF 2.0 section structures

## Why It Matters for RAG Builders
It enables LLMs to programmatically access and analyze PDF specifications, which is critical for building accurate RAG systems that require deep understanding of structured technical documentation.
