## Summary
A Model Context Protocol (MCP) server and CLI tool that enables AI assistants to automate Microsoft PowerPoint presentations in real-time via Windows COM interop. It provides 18 tools with ~98 operations for creating, editing, and verifying PowerPoint decks without requiring VBA or PowerPoint object-model expertise.

## Key Features
- Real-time PowerPoint automation via COM interop, ensuring true-fidelity rendering and compatibility
- 18 MCP tools with ~98 operations across 12 domains (slides, shapes, tables, charts, etc.)
- Export-to-verify functionality to generate images of slides for visual validation by AI assistants
- Dual interface support (MCP Server for conversational AI and CLI for scripting/coding agents)
- Persistent CLI sessions via background daemon for seamless workflow automation

## Why It Matters for RAG Builders
It enables AI assistants to programmatically create, edit, and verify PowerPoint presentations with high fidelity, bridging the gap between AI automation and professional presentation workflows.
