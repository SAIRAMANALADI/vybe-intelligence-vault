## Summary
A monorepo that bridges Playwright's deterministic QA with AI-driven browser exploration, enabling persona-based testing and AI-assisted validation of live web products through sealed browser evidence and adaptive execution.

## Key Features
- AI-native QA workflows that extend Playwright's deterministic testing to live products
- Persona-based browser exploration with sealed evidence capture
- Adaptive execution mode for AI-assisted staging validation
- Monorepo structure with modular packages for contracts, runtime, and reporting
- Support for file uploads and variant comparisons in AI-driven testing
