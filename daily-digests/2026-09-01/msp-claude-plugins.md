## Summary
A collection of 33+ vendor-specific MCP plugins designed to supercharge Claude Code for Managed Service Provider (MSP) workflows, enabling seamless integration with PSA, RMM, documentation, security, accounting, CRM, and productivity tools.

## Key Features
- Pre-built plugins for 33+ MSP tools (PSA, RMM, documentation, security, accounting, CRM)
- Hosted gateway for zero-infrastructure setup with OAuth 2.1 + PKCE authentication
- Self-hosted MCP servers for full control over data and infrastructure
- Shared skills for MSP terminology, ticket triage, and cross-vendor incident correlation
- Modular architecture with skills, commands, and MCP servers for extensibility
