## Summary
StockTokenOS is an agent operating system designed for Robinhood Chain Stock Tokens and onchain RWAs, enabling AI agents to list, price, policy-check, and plan swaps for canonical stock tokens. It provides non-custodial, agent-native discovery and hard guardrails for secure trading operations.

## Key Features
- Agent-native discovery via `llms.txt` and capability cards for seamless integration
- Hard guardrails including allowlists, max notional limits, and simulate-first policy checks
- Canonical token registry with correct ERC-8056 semantics and oracle pause awareness
- Monorepo structure with MCP server, policy engine, SDK, and agent skills
- Pre-trade simulation and swap planning tools for secure trading operations

## Why It Matters for RAG Builders
