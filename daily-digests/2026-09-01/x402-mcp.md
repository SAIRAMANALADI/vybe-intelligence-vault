## Summary
x402-mcp is an MCP server that enables AI agents to interact with hundreds of x402-paid APIs, handling USDC micropayments across multiple chains like Base and Solana. It auto-discovers tools from the CDP Bazaar and refreshes endpoints dynamically without restarts.

## Key Features
- Auto-discovers x402 endpoints from CDP Bazaar with no hard-coded list
- Handles USDC micropayments automatically on Base and Solana chains
- Dynamic endpoint refresh every 5 minutes without server restart
- Enforces cost safety with configurable hard caps per tool call
- Supports multi-chain expansion (Base, Solana, Polygon, BNB, EVM)

## Why It Matters for RAG Builders
It enables AI agents to seamlessly interact with paid APIs using USDC micropayments, unlocking agentic commerce and autonomous workflows for RAG builders.
