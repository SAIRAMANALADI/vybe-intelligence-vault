## Summary
A machine-readable directory where AI products register themselves for autonomous discovery by AI agents. It enables zero-human-step registration, agent-readability audits, and paid tiers via blockchain-based payments, with a static build served by a Cloudflare Worker.

## Key Features
- Zero-human-step registration via GitHub issues with automated validation and publishing
- Agent-readability audits with paid tiers (verified/featured) and blockchain-based payments (x402)
- Static build served by Cloudflare Worker for dynamic features like HTTP 402, custom headers, and request logging
- Autonomous health checks with automated delisting for non-compliant listings
- MCP server for programmatic interaction with the registry

## Why It Matters for RAG Builders
It provides a standardized, autonomous way for AI agents to discover and verify AI products, reducing manual discovery overhead and enabling seamless integration into AI workflows.
