## Summary
Chroma is an open-source AI-native embedding database designed to simplify building LLM applications by providing storage, retrieval, and management for vector embeddings, full-text search, and multi-modal retrieval. It supports both self-hosted and managed (Chroma Cloud) deployments with Python and JavaScript/TypeScript SDKs.

## Key Features
- Open-source vector database with Apache 2.0 license
- Supports hybrid search (vector, full-text, metadata, regex)
- Multi-modal retrieval (text, image, audio)
- First-party Python and JavaScript/TypeScript SDKs
- Self-hosted and managed (Chroma Cloud) deployment options
