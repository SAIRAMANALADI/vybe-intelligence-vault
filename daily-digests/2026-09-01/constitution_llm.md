## Summary
A specialized pipeline for predicting political indicators in historical pre-modern polities using LLMs, featuring multi-model support, verification methods, and search augmentation. It processes constitutions, sovereignty, federalism, and other indicators through configurable pipelines and batch processing for large-scale analysis.

## Key Features
- Multi-LLM support (Gemini, GPT, Claude, Bedrock) with configurable models
- Three distinct pipelines: constitution, indicators, and elections with verification options
- Self-consistency and Chain of Verification (CoVe) for improved accuracy
- Search augmentation modes (agentic, forced, Gemini Grounding) for contextual retrieval
- Gemini Batch API integration for cost-efficient large-scale processing with retry logic

## Why It Matters for RAG Builders
It provides a structured, scalable framework for using LLMs to analyze historical political documents, enabling researchers to derive political indicators with verifiable accuracy and contextual grounding.
