## Summary
DocShell provides a document-style interface for the Claude Code CLI, where user inputs and model replies are structured as document paragraphs with tool calls and revisions rendered as margin comments and inline edits. It offers a calm, continuous conversation experience without traditional chat UI elements.

## Key Features
- Document-style UI replacing traditional chat bubbles with paragraphs for input/output
- Tool calls and file edits rendered as collapsible margin comments and inline revisions
- Persistent multi-turn conversations with real Claude Code backend using OAuth login
- Type-ahead queue and interrupt capability for seamless user experience
- Safety handbrake for destructive commands and token-based authentication for network deployments

## Why It Matters for RAG Builders
DocShell reimagines AI coding interfaces by blending seamless interaction with transparent process visibility, making it ideal for developers who prefer document-centric workflows over chat-based AI assistants.
