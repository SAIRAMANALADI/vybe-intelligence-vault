## Summary
Crayon Browser is a desktop browser tailored for AI Agents, offering both standard web browsing and LAN casting capabilities. It leverages Chromium/CEF architecture for cross-platform support, with a focus on agent integration and media casting without bypassing DRM or downloading videos.

## Key Features
- AI Agent-native desktop browser with Chromium/CEF architecture
- LAN casting capabilities for media playback and control
- Modular design with strict separation of concerns (CEF, Cast-SDK, adapters)
- Agent protocol and capability registry for controlled tool access
- Cross-platform support (Windows, macOS, HarmonyOS planned)

## Why It Matters for RAG Builders
It provides a specialized browser interface for AI agents to interact with web content and cast media locally, enabling controlled and secure agent-driven browsing and presentation workflows.
