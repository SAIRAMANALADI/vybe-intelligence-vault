## Summary
Code Tribunal is a multi-agent intent-conformance review engine for AI-generated code that reconciles original tickets against actual implementations to produce merge verdicts, trust scores, and traceability ledgers. It operates via CLI, MCP server, or web demo, enabling automated or human-in-the-loop code review.

## Key Features
- Multi-agent tribunal system (CLERK, ADVOCATE, SURVEYOR, GHOST, DRIFT, WARDEN, ARBITER) for comprehensive code review
- Deterministic trust scoring and traceability ledger for explainable verdicts
- CLI, MCP server, and web demo deployment options for integration into CI/CD or agent workflows
- Fallback model chain (Groq → Cerebras → Gemini) with BYO API keys for flexibility
- Security-sensitive change detection via WARDEN agent recruitment

## Why It Matters for RAG Builders
It provides automated, multi-agent intent-conformance review for AI-generated code, ensuring implementations match original requirements before merge, reducing human review overhead and improving reliability in AI-driven development workflows.
