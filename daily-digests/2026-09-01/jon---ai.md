## Summary
Jon is a modern AI desktop assistant for Windows that integrates multi-provider AI models, system automation, and interactive features like games, voice control, and a portable mini-assistant. It combines a Python/FastAPI backend with an Electron/React/TypeScript frontend and supports local models via Ollama.

## Key Features
- Multi-provider AI integration (Ollama, OpenAI, Anthropic, etc.) with unified interface
- Full system control via voice, text, or automation scripts (file management, media, smart home)
- Mini Jon (desktop overlay) with persistent voice interaction and customizable UI
- Built-in RAG for local document search and knowledge base integration
- Online multiplayer games (ECHO, AETHERIA, Blockwelt) with real-time collaboration
