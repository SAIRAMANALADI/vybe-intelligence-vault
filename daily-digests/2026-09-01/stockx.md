## Summary
Stockx is a full-stack agentic AI platform for supply chain management that integrates Gilhari ORM, ORMCP MCP server, and a Flutter web dashboard. It enables AI agents to interact with a Microsoft SQL Server database via natural language queries, generating interactive UI components without manual API or SQL development.

## Key Features
- Zero-boilerplate ORM microservice (Gilhari) for automatic REST API generation
- ORMCP server exposes database operations as typed MCP tools for AI agents
- Natural language queries generate interactive UI components (Kanban, charts, tables)
- Dual data pathways: manual CRUD via Gilhari REST API and agentic AI queries via MCP
- Supports multiple LLM backends (OpenAI, Google) with environment variable configuration

## Why It Matters for RAG Builders
It demonstrates a production-grade pipeline for seamless database-to-LLM integration, eliminating manual SQL and API development while enabling AI agents to generate dynamic, interactive UIs from natural language queries.
