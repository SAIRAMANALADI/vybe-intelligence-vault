## Summary
Elengenix is an autonomous AI agent framework designed for security research and penetration testing. It autonomously discovers vulnerabilities by reasoning through problems, generating attack trees, selecting tools, and adapting strategies in real-time, mimicking skilled human penetration testers.

## Key Features
- AI-powered reasoning engine with attack tree planning and dynamic re-planning
- Governance layer for safe tool execution (SAFE/PRIVILEGED/DESTRUCTIVE)
- Integration with 120+ security tools and MCP servers for structured thinking
- Cross-session memory using ChromaDB and SQLite for continuous learning
- Pre-flight scanner for actionable findings without AI dependency

## Why It Matters for RAG Builders
