## Summary
HORIZON SHIELD is an MCP server that enables AI agents to verify the fairness of Japanese construction or renovation estimates against open data, returning tamper-evident, Bitcoin-anchored receipts for transparency. It leverages the Japan Construction Cost Database (JCCDB) and OpenTimestamps for verifiable auditing.

## Key Features
- Fair-price range calculation for Japanese construction/renovation jobs using JCCDB data
- Tamper-evident, Bitcoin-anchored receipts for verifiable claims via OpenTimestamps
- Red-flag detection for overcharge tactics in estimates (e.g., lump-sum pricing, high-pressure sales)
- Integration with Google's Agent Payments Protocol (AP2) for verifiable value attestations
- Language-agnostic tools for universal estimate evaluation principles

## Why It Matters for RAG Builders
It provides a critical layer of verifiable transparency for AI agents and users in high-stakes financial decisions like construction estimates, reducing reliance on trust and enabling independent auditing.
