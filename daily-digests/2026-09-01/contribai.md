## Summary
ContribAI is an autonomous AI agent that discovers open-source repositories, analyzes their code for issues, and submits pull requests to improve them. It leverages multi-LLM support, 13-language AST analysis, and automated PR generation to contribute to projects like Worldmonitor and Maigret.

## Key Features
- 13-language AST analysis with 27 progressive skills for security, quality, and performance checks
- Multi-LLM support with smart task routing across providers (Gemini, OpenAI, Anthropic, etc.)
- Autonomous PR generation and submission with CI monitoring and auto-fix capabilities
- Interactive CLI, TUI, and MCP server for integration with tools like Claude Desktop
- Docker and web dashboard for deployment and monitoring

## Why It Matters for RAG Builders
ContribAI automates open-source contributions by analyzing code and submitting PRs, reducing manual effort for AI engineers building RAG systems that rely on high-quality, well-maintained repositories.
