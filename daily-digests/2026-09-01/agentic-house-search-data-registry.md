## Summary
A UK-focused open data registry and live report generator that aggregates 45 government datasets on demographics, crime, property prices, and planning constraints for any postcode. It provides a web interface, an MCP server for AI agents, and a searchable dataset catalog.

## Key Features
- Aggregates 45 open government datasets on UK neighbourhoods (demographics, crime, property prices, planning, etc.)
- Provides a live postcode report generator with AI summary capability (optional)
- Offers an MCP server for AI agents to query UK neighbourhood data programmatically
- Includes a searchable dataset registry with API endpoints, licences, and coverage details
- Enforces transparency by never inventing comparisons or pretending to cover unsupported regions

## Why It Matters for RAG Builders
It provides a critical bridge between raw UK government open data and AI agents, enabling RAG systems to fetch structured, real-time neighbourhood insights for any UK postcode without proprietary APIs.
