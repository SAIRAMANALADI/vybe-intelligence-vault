## Summary
OpenMemory is an AI memory engine exposed as an MCP server that provides structured, schema-driven knowledge storage and retrieval for AI agents. It enables persistent, portable memory across tools with features like entity extraction, deduplication, and hybrid search.

## Key Features
- Hybrid knowledge capture with fast session-based fact storage and batch consolidation
- Entity extraction and knowledge graph construction with relationship tracking
- Hybrid search combining BM25 keyword, structured domain, and entity-graph paths
- Immutable history with fact supersession and full traceability to source events
- MCP resources and tools for seamless integration with AI clients like Claude and Cursor

## Why It Matters for RAG Builders
OpenMemory provides a critical layer for RAG systems by enabling persistent, structured, and portable memory that AI agents can query and update across sessions and tools.
