## Summary
Ronin is a masterless, terminal-native AI coding agent inspired by Claude Code, designed to read, edit, and run code from the terminal with provider-agnostic LLM support. It offers a free, credit-card-free experience on models like Gemini, Cerebras, Groq, and Ollama, while also supporting premium models like Claude.

## Key Features
- Provider-agnostic agent framework supporting free and paid LLM models (Claude, Gemini, Cerebras, Groq, Ollama, etc.)
- Masterless terminal-native interface with real-time diff previews and approval gates for all write operations
- Built-in multi-agent orchestration for parallel task execution across models and roles (researcher, implementer, reviewer, tester)
- Comprehensive security hardening including cost budgeting, path-traversal confinement, and tool-registry gate checks
- Extensive MCP integrations (24+ local servers, remote/hosted, and 200+ plugins) for enhanced functionality

## Why It Matters for RAG Builders
