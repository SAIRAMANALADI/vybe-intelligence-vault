## Summary
GG Framework is a modular TypeScript framework for building LLM-powered applications, featuring a desktop agent (GG Coder) that runs isolated agent instances per project, a CLI tool, and a suite of reusable packages for AI integration, agent orchestration, and model abstraction.

## Key Features
- Isolated agent instances per project with real OS windows and native UI
- Unified streaming API for multiple LLM providers (OAuth and API key support)
- Built-in Autopilot feature for automated code review and iteration
- Language server integration for real-time type checking and error fixing
- MCP support, subagents, and project memory for advanced workflows

## Why It Matters for RAG Builders
It provides a robust, modular foundation for building scalable multi-agent systems with isolated project contexts, essential for RAG pipelines requiring concurrent tool execution and model switching.
