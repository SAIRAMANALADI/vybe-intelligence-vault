## Summary
Aspicio is an open-source TypeScript DXF engine that parses, tessellates, and renders CAD drawings for both human interaction and AI agents. It provides structured data extraction, interactive WebGL viewers, and MCP/HTTP APIs for seamless integration into AI workflows.

## Key Features
- Framework-free `parse → tessellate` pipeline for DXF files
- Interactive WebGL viewer with layer toggles and object snap
- Structured JSON extraction for AI agents (no OCR needed)
- MCP and HTTP APIs for remote access and integration
- Headless rendering for server-side previews and thumbnails

## Why It Matters for RAG Builders
Aspicio bridges the gap between unstructured CAD data and structured AI workflows by providing clean, parseable DXF representations and interactive viewers, enabling precise AI-driven analysis and automation.
