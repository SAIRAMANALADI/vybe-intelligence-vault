## Summary
hikizan is a Claude Code plugin and Agent Skills pack designed to standardize AI agent workflows by providing verb-split, numbered skills for tasks like exploration, code review, design, execution, PR submission, and writing. It balances automation with guardrails to prevent runaway agents while ensuring deterministic outcomes.

## Key Features
- Verb-split core skills (e.g., `tansaku`, `sadoku`, `sekkei`) with numbered procedures and templates for structured task execution
- Three-tier system (standard/guided) to balance autonomy and control via opt-out preambles and deterministic hooks
- Deterministic git hooks (`floors`) to prevent destructive operations, force pushes, and non-draft PRs across supported harnesses
- Standardized PR submission format (`teishutsu`) with 6-section workflow trace for post-task reviewability
- Multi-harness support (Claude Code, Codex, Cursor, OpenCode) with harness-specific installation and tier management

## Why It Matters for RAG Builders
It provides a structured, guardrail-enforced framework for AI agents to execute tasks autonomously while ensuring deterministic outcomes and auditability, critical for scalable RAG and agentic systems.
