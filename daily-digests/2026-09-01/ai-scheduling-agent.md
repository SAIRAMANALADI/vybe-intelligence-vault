## Summary
Kory's AI Scheduling Agent is an email triage and meeting scheduling system that uses a human-in-the-loop approval model. It integrates with Outlook, Anthropic's Claude, and optional Asana for task management, orchestrated via Hermes and Lexi components.

## Key Features
- Human-approved scheduling decisions with full audit logging
- Modular rule-based system for scheduling logic (rules.py)
- Integration with Outlook via Composio for email processing
- Optional Asana task creation for reminders and follow-ups
- Embedded MCP server exposing scheduling tools to Hermes

## Why It Matters for RAG Builders
It provides a structured, rule-driven approach to AI-powered scheduling with human oversight, critical for building reliable agentic systems in enterprise environments.
