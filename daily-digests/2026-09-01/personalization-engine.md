## Summary
A FastAPI microservice that aggregates personalized data and semantic vectors, interfacing with Google Cloud Vertex AI Vector Search and PostgreSQL. It enables dynamic user-specific data retrieval, semantic search, and event-driven memory synchronization for AI-driven applications.

## Key Features
- Dynamic user-specific data aggregation with PostgreSQL
- Native integration with Google Cloud Vertex AI Vector Search for semantic embeddings
- Asynchronous aggregation using thread-pool architecture to avoid blocking
- Event-driven synchronization via webhooks (e.g., Google Cloud Tasks)
- Unified API endpoints for personalized metrics and semantic recommendations
