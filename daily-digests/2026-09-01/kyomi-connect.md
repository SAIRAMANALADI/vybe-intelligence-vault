## Summary
Kyomi Connect is a secure on-premise agent that acts as a bridge between the Kyomi cloud platform and your local data warehouse, enabling encrypted query execution without exposing database credentials to the cloud.

## Key Features
- Secure on-premise execution of database queries with encrypted WebSocket transport
- Supports 9+ database engines with compile-time feature flags for minimal binary size
- JWT-authenticated WebSocket connection with JWKS endpoint verification
- Open-source codebase (Apache 2.0) for security auditing and transparency
- CLI-based setup, configuration, and service management for easy deployment

## Why It Matters for RAG Builders
It enables secure, on-premise query execution for RAG systems without exposing database credentials to cloud services, ensuring compliance and data privacy.
