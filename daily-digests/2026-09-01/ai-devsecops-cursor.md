## Summary
This repository provides a Cursor Agent SDK-based DevSecOps framework with runners (CLI) and shared wiring for dependency management (depbot) and vulnerability scanning (vulnbot) bots. It centralizes policy and skills in target repos while offering reusable templates and GitHub Actions workflows for automation.

## Key Features
- CLI-based runners for dependency and vulnerability bots (depbot, vulnbot)
- Reusable skill templates for target repos to define policies and workflows
- GitHub Actions integration for CI/CD automation
- Local and remote deployment support with configurable models and settings
- Policy-driven PR lifecycle and quarantine rules per target repo
