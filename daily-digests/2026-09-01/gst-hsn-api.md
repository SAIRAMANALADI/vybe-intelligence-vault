## Summary
A specialized API for accurate GST HSN/SAC code lookup, GSTIN validation, and condition-aware GST rate resolution in India. Designed for developers and AI agents with SDKs in Python and JavaScript, and native MCP server support for seamless integration.

## Key Features
- HSN/SAC code lookup with condition-aware GST rate resolution
- GSTIN validation with PAN and state extraction
- Natural language product search for HSN/SAC mapping
- Bulk lookup support (up to 100 items per request)
- Native MCP server for AI agent integration

## Why It Matters for RAG Builders
Provides critical GST tax compliance data for Indian businesses and AI agents, enabling accurate rate lookups and validation without manual intervention.
