## Summary
Ace Memory is a local, persistent memory layer for AI tools that enables context retention across sessions without cloud dependency. It provides a lightweight MCP server and dashboard for storing, searching, and evolving AI memories with feedback-driven weight adjustments.

## Key Features
- 12 MCP tools for memory management (save, search, correct, link, etc.)
- Feedback-driven memory evolution with weight adjustments
- Full-text, append-only memory storage in human-readable JSONL
- Desktop and web dashboards for memory visualization and management
- Zero cloud dependency with 100% local data control

## Why It Matters for RAG Builders
Ace Memory provides a lightweight, local alternative to cloud-based memory solutions, ensuring AI tools retain context without sacrificing data privacy or incurring ongoing costs.
