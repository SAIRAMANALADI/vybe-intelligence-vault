## Summary
A local AI agent skill for analyzing sports trajectory data (FIT/KML files) such as cycling, running, or hiking. It generates insights, visual reports, and exports 3D route stories with PNG/MP4 outputs, all processed locally without additional software installation.

## Key Features
- Automated analysis of FIT/KML sports data with sensor insights (heart rate, cadence, power, etc.)
- Local 3D route visualization and reporting via Ride Relief web interface
- Multi-activity comparative analysis with trend identification
- PNG/H.264 MP4 export for social media sharing with customizable formats
- Privacy-focused local processing with no cloud uploads or persistent data storage

## Why It Matters for RAG Builders
It enables AI agents to locally analyze and visualize sports data, providing actionable insights and shareable outputs without requiring external tools or cloud dependencies.
