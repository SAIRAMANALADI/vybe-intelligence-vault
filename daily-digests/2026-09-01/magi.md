## Summary
Magi is a local-first, model-agnostic desktop AI agent that integrates with your screen and audio input to provide context-aware answers while prioritizing privacy and efficiency. It runs entirely on-device, minimizing passive resource usage and avoiding cloud dependencies unless explicitly configured.

## Key Features
- Agentic vision with on-demand screen capture to minimize token costs
- Hotkey-triggered voice interaction with local speech-to-text (Whisper)
- Automatic model capability tier detection for optimal tool usage
- Cross-platform design with macOS prioritization and Windows/Linux support planned
- Negligible idle resource consumption (RAM/CPU) for always-on operation

## Why It Matters for RAG Builders
Magi enables RAG builders to create privacy-preserving, low-overhead desktop agents that intelligently integrate screen context without incurring unnecessary cloud costs or token waste.
