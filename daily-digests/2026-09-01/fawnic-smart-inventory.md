## Summary
A production-grade inventory, order, and production management system for a leather-goods business, featuring real-time stock synchronization, a Kanban-based production workflow, and an agentic AI stock assistant that triggers alerts and reorder suggestions based on order status changes.

## Key Features
- Atomic stock synchronization with transactional integrity (purchase/sale deletions reverse stock effects)
- Agentic AI stock assistant with tool-calling (4 restricted tools) for real-time stock alerts and reorder suggestions
- Drag-and-drop Kanban board for production order tracking with role-aware authentication
- Live analytics dashboard with KPIs, stock health, and trend analysis
- Modular architecture with Django backend services and React/Vite frontend with typed API client

## Why It Matters for RAG Builders
It provides a robust, production-ready SaaS template for inventory and order management with an integrated AI agent, demonstrating secure tool-calling and real-time stock synchronization critical for RAG builders integrating business logic.
