## Summary
site-use is a deterministic browser automation tool that enables AI agents to interact with Twitter (and potentially other sites) in a human-like manner while extracting structured, meaningful content. It avoids scraping bans by mimicking natural user behavior and minimizes token costs by pre-processing actions into deterministic code.

## Key Features
- Human-like browser interactions (scrolling, mouse movements, pauses) to avoid detection bans
- Deterministic code execution for browsing actions, eliminating token costs during runtime
- Structured output (author, timestamp, engagement metrics, content) instead of raw HTML
- Built-in anti-detection diagnostic suite to verify effectiveness against platform defenses
- Seamless integration with AI agents (Claude Code, OpenClaw) and standalone CLI usage

## Why It Matters for RAG Builders
It enables AI agents to safely and cost-effectively extract high-quality, structured data from Twitter without scraping bans or excessive token usage.
