## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Cisco Modeling Labs (CML) via natural language, automating network lab management, configuration, and monitoring tasks through 51 integrated tools.

## Key Features
- 51 MCP tools for comprehensive CML lab and node management
- Natural language interaction with CML via AI assistants (Claude, Cursor)
- Packet capture (PCAP) and link conditioning for network analysis
- Modular architecture with 51 tools across lab, node, link, and system management
- Support for visual annotations, user/group management, and CLI command execution
