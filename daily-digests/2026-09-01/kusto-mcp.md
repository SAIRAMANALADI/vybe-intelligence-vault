## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Azure Data Explorer (Kusto) clusters using natural language queries, eliminating the need for manual KQL scripting. It bridges AI tools like Claude, Cursor, and Cline with Kusto databases for data analysis and insights.

## Key Features
- Enables AI assistants to query Kusto databases using plain English, removing the need for KQL expertise
- Supports multiple AI tools (Claude, Cursor, Cline, VS Code) with native MCP integration
- Provides secure authentication via Azure CLI with no token storage
- Includes built-in telemetry for usage analytics while maintaining privacy (no query text or sensitive data collected)
- Offers advanced configuration options for response formatting, query limits, and OpenTelemetry integration

## Why It Matters for RAG Builders
It simplifies AI-driven data analysis by allowing AI assistants to directly query Kusto databases without requiring users to write complex KQL queries, accelerating insights and reducing friction for AI-powered analytics.
