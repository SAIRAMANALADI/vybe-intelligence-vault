## Summary
A macOS-based RPA framework for WeChat automation that uses multimodal vision perception and LLM agents to interact with the WeChat GUI as a black box. It enables AI to 'see' the interface, understand conversations, and automate responses without protocol manipulation or database access.

## Key Features
- Vision-based GUI interaction (screenshots + OCR) for WeChat automation without protocol injection
- LLM-driven agent architecture with multi-modal perception (SmartPipeline, VisionPipeline, WeFlowPipeline)
- Memory system with three layers: working memory, session memory, and long-term memory (LLM Wiki + vector DB)
- Data flywheel for automated quality assessment using LLM-as-a-Judge and AB testing
- Structured logging and benchmarking for production-grade reliability and traceability

## Why It Matters for RAG Builders
It provides a robust, vision-based automation framework for integrating LLMs with GUI applications like WeChat, enabling RAG systems to interact with external interfaces without invasive protocol modifications.
