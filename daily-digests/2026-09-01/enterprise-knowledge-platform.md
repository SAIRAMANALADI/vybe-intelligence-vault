## Summary
A self-hosted enterprise search and knowledge management platform that ingests any file type, performs hybrid search (vector + BM25 + graph), and provides local RAG-based Q&A with verifiable citations. It leverages distributed ingestion, persistent indexing, and a rich knowledge graph for comprehensive retrieval.

## Key Features
- Hierarchical semantic chunking with LangChain for structured document processing
- True hybrid retrieval combining vector search (Qdrant), BM25 (Elasticsearch), and GraphRAG (Neo4j)
- Distributed ingestion pipeline with Kafka for scalable parallel processing
- Local LLM Q&A with Ollama and verifiable citations for offline, zero-API-cost operation
- Rich knowledge graph with provenance tracking and semantic clustering

## Why It Matters for RAG Builders
It provides a comprehensive, self-hosted RAG stack with hybrid search, knowledge graph integration, and local LLM capabilities, eliminating API costs and data privacy concerns while enabling verifiable, citation-backed AI responses.
