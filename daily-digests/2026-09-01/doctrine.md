## Summary
Doctrine provides a structured set of 28 software engineering skills grounded in established industry standards (e.g., OWASP, ITIL, IETF RFCs) to enforce discipline across the software development lifecycle. It is delivered as a Claude Code plugin or an MCP server for integration with AI coding assistants.

## Key Features
- 28 standardized skills covering the entire software development lifecycle (e.g., TDD, code review, incident response, domain modeling)
- Skills grounded in primary standards (OWASP, ITIL, ISO, IETF RFCs, BABOK, SBAR) instead of invented conventions
- Two delivery methods: Claude Code plugin for seamless integration or MCP server for cross-platform compatibility
- Structured skill format with defining constraints, phases, and checklists for traceability to source standards
- MCP server implementation in plain Node.js with automated smoke testing for prompt registration
