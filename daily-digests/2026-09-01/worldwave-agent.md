## Summary
Worldwave-Agent is a persistent cognitive entity framework that enables a single AI agent to maintain a unified memory and identity across multiple platforms and restarts. It features self-editing knowledge graphs, temporal memory management, and a spiral cognitive loop for LLM-driven reasoning.

## Key Features
- Persistent cognitive entity with unified identity across platforms and restarts
- Temporal knowledge graph with self-editing capabilities (remember/forget)
- Spiral cognitive loop for 7-phase LLM-driven reasoning (PERCEIVE, RECALL, PLAN, ACT, EVALUATE, LEARN, CONSOLIDATE)
- Decentralized federated learning stack (P2P discovery, gossip, model-weight exchange)
- Cross-platform support (Telegram, Discord, HTTP API, Web UI, CLI, and more)

## Why It Matters for RAG Builders
Worldwave-Agent enables RAG builders to create agents with persistent, self-managed memory and cross-platform identity, eliminating the need for external graph databases and simplifying long-term context retention.
