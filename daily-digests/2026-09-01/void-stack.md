## Summary
Void Stack is a developer toolkit that orchestrates, audits, and analyzes entire development stacks with a single command. It combines a CLI, TUI, desktop app, and MCP server to automate project setup, dependency management, and AI-assisted code analysis using hybrid semantic and structural indexing.

## Key Features
- One-command dev stack orchestration (backend, frontend, database, workers) with auto-detection of frameworks and environments
- Hybrid code indexing combining vector embeddings (BAAI/bge-small-en-v1.5) and Tree-sitter structural graphs for precise AI context
- MCP server with 43+ tools for AI assistants (Claude Desktop/Code) to manage services, analyze code, and audit security autonomously
- Built-in security auditing, code analysis, and technical debt tracking with actionable refactoring insights
- Cross-platform support (Windows, macOS, Linux) with CLI, TUI, desktop GUI, and MCP server interfaces
