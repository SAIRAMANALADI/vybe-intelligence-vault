## Summary
Oh My Second Brain (OMS) is a host-agnostic convention layer that connects existing Obsidian or Markdown vaults to AI tools without altering the vault's plain Markdown structure. It enables structured template management, ontology-driven note organization, and AI-ready indexing while preserving user ownership of data and semantics.

## Key Features
- Preserves plain Markdown vaults without ownership transfer
- Structured template and ontology management via `.oms/` files
- CLI and MCP tools for AI host integration (search, embed, write, link)
- Supports lexical, vector, and HyDE search with explicit model verification
- Dry-run, approval-based migrations and reconciliations for safety

## Why It Matters for RAG Builders
It bridges structured knowledge vaults with AI tools while maintaining user control, enabling reliable RAG pipelines without disrupting existing workflows.
