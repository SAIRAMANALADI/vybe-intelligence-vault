## Summary
An MCP (Model Context Protocol) server providing access to the ASD-STE100 Issue 9 standard, which includes a vocabulary and ruleset for Simplified Technical English. It enables automated compliance checks and technical writing assistance for documentation.

## Key Features
- Provides vocabulary and ruleset lookups for ASD-STE100 Issue 9 standard
- Supports multiple search methods (exact match, regex, similarity matching)
- Integrates with MCP hosts like Claude Desktop and OpenCode
- Supports both stdio and SSE transport modes
- Configurable via environment variables and custom files
