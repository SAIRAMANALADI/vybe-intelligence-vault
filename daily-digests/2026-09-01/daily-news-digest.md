## Summary
An automated daily news digest system that fetches, scores, and deduplicates news from 20 global outlets, generates AI-written summaries in Chinese using DeepSeek, and delivers them via WeChat and Telegram. Runs entirely on GitHub Actions with no server costs.

## Key Features
- Automated news fetching from 20+ global outlets with RSS and full-text scraping
- Multi-layer scoring system for relevance, trust, and freshness with keyword-based ranking
- Deduplication and cross-session tracking to avoid repeating stories
- AI-generated Chinese digests with hallucination guards (3-layer verification)
- Multi-channel delivery (WeChat, Telegram) with failure alerts and optional Telegram fallback
