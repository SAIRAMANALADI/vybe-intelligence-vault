## Summary
CrawlEyes is a comprehensive web scraping and search toolkit designed for AI agents, providing full-text extraction, robust search, semantic reranking, and MCP server capabilities. It enables agents to 'see and read' the web reliably while supporting self-hosted, zero-API-key solutions, particularly optimized for use in restricted networks like mainland China.

## Key Features
- Full-text extraction with noise filtering (~89% reduction) for clean Markdown output
- Robust search with SearXNG (self-hosted) and keyless Tavily fallback for resilience
- Local semantic reranking using fastembed with BAAI/bge-small-zh-v1.5 for improved result relevance
- Standard MCP server exposing search, extraction, and deep research tools for any MCP client
- Deep research mode that decomposes topics, searches, extracts, and synthesizes cited reports

## Why It Matters for RAG Builders
CrawlEyes provides an all-in-one, self-hosted, and China-friendly solution for AI agents to extract, search, and rank web content, eliminating dependency on external APIs and enabling reliable RAG pipelines without API key constraints.
