## Summary
EFF-Monitoring is a security operations collaboration platform centered around built-in AI Agents, designed to streamline the entire lifecycle of security events. It provides log parsing, asset correlation, AI-driven analysis, incident response workflows, experience accumulation, and report generation to enhance security team efficiency.

## Key Features
- Built-in AI Agents for autonomous security event analysis and response planning
- Unified log parsing and asset correlation across heterogeneous security devices
- Collaborative workflows with role-based access (admin, monitor, analyst, disposer, viewer)
- Evidence-driven AI reasoning with structured reflection and experience accumulation
- Customizable templates for reports, Excel exports, CSV, and messaging integrations

## Why It Matters for RAG Builders
