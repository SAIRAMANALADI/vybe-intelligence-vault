## Summary
mcp-testkit is a testing framework designed for Model Context Protocol (MCP) servers, providing expressive matchers, schema validation, fuzz testing, and snapshot support to ensure reliability and correctness in MCP tool development.

## Key Features
- One-line test harness setup for in-memory or stdio MCP server testing
- Custom matchers for tool discovery, result validation, and content checks
- Schema validation to catch issues before production deployment
- Fuzz testing with reproducible seeds for edge-case discovery
- Snapshot testing with deterministic serialization for stable test outputs

## Why It Matters for RAG Builders
It provides a standardized, efficient way to test and validate MCP servers, ensuring reliability and reducing production issues for AI stack builders.
