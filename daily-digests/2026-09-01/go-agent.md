## Summary
A lightweight, interactive AI agent framework written in Go designed for extensibility and integration with LLM services. It provides a modular architecture for building agents with built-in tools, memory systems, and skill discovery.

## Key Features
- Pluggable tool system with built-in Bash, file I/O, and memory tools
- Two-layer memory architecture (chat history and long-term memory)
- Automatic skill discovery from directories
- Customizable reporters for streaming and logging
- Interactive CLI with session persistence
