## Summary
An Obsidian plugin that integrates Claude AI directly into the Obsidian vault, enabling chat, agent mode, artifact generation, and evidence-backed research workflows with local and remote context. Users can interact with Claude via a side panel, manage notes as context, and utilize features like semantic search, interactive HTML artifacts, and an MCP bridge for Claude Code.

## Key Features
- Side-panel chat with streaming responses and Markdown rendering in Obsidian
- Vault-aware semantic search with on-device embedding models and PDF support
- Interactive claude-html artifacts rendered inline or saved as interactive notes
- Agent mode with vault tools for reading, creating, and editing notes (with confirmation dialogs)
- Evidence-backed research workflow with project management, source triage, and claim validation

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and personal knowledge management, enabling seamless RAG workflows directly within a user's note-taking environment.
