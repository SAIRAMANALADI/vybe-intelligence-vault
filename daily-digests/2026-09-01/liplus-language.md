## Summary
Li+ is a requirements specification language designed as code for AI agents, acting as an interactive compiler that governs how AI prioritizes, acts, verifies, and retries tasks until real-world behavior converges with specified requirements. It transforms human dialogue into structured, CI-driven workflows for autonomous software development.

## Key Features
- Layered execution model (Model, Evolution, Task, Operations, Notifications, Adapter) for structured AI workflows
- Dialogue-Driven Development (DiDD) converting human dialogue into executable requirements
- Self-evolving rules with human oversight (Sheepdog Engineering)
- CI-driven verification and self-correction for autonomous issue management and task execution
- Cross-AI and cross-environment compatibility with minimal human intervention

## Why It Matters for RAG Builders
Li+ provides a critical framework for ensuring AI agents execute tasks with consistent priority, verification, and correctness, reducing failures from priority collisions and enabling autonomous, behavior-first software development.
