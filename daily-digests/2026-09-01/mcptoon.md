## Summary
mcptoon is a zero-dependency CLI tool that simplifies cross-agent MCP (Model Context Protocol) management, enabling any AI agent (Claude, Cursor, Codex, etc.) to use configured MCP tools without per-agent setup or restarts. It supports the latest MCP spec and the Agent Plugins 1.0.0 standard, reducing token usage by up to 99.8% through compact tool manifests.

## Key Features
- Supports the latest MCP spec (2026-07-28) with full backward compatibility for older servers
- Agent Plugins 1.0.0 support for cross-vendor plugin installation and management
- Reduces tool listing tokens by up to 99.8% using compact manifests (names only)
- Zero-config cross-agent synchronization with drift detection and merge modes
- Single-entry proxy mode for simplified agent configuration and HTTP-based multi-agent support

## Why It Matters for RAG Builders
mcptoon eliminates the need for per-agent MCP configuration, enabling seamless tool integration across AI agents while drastically reducing token overhead in RAG pipelines.
