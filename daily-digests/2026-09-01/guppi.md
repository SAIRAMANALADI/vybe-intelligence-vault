## Summary
GUPPI is an enterprise-grade agentic sidecar and memory engine designed to enhance AI workflows by providing real-time code navigation, long-term RAG memory, multi-agent task orchestration, and safety guardrails. It integrates seamlessly with existing AI tools via the Model Context Protocol (MCP) and offers a web-based control deck for monitoring and telemetry.

## Key Features
- Programmatic AST symbol indexing and Lossless Semantic Tree (LST) traversal for efficient code navigation
- Long-term decay-ranked RAG memory with subject-relation-object Fact Graph extraction
- Multi-agent DAG task planning with structured session handoff checkpoints
- Pre-flight safety guardrails, secret detection, and non-destructive shadow backups
- Agent precision benchmarking, telemetry logging, and auto-generated unit test suites

## Why It Matters for RAG Builders
GUPPI provides a unified, high-performance infrastructure for RAG builders to integrate advanced agentic workflows, memory management, and safety mechanisms into their AI stacks.
