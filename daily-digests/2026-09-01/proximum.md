## Summary
Proximum is a high-performance, embeddable vector database for Clojure and Java that introduces Git-like versioning and zero-cost branching to vector search. It enables time travel, immutable operations, and reproducible search results, making it ideal for RAG applications and ML experimentation.

## Key Features
- Git-like versioning with time travel and branching for reproducible experiments
- Zero-cost branching enabled by chunked structural sharing and copy-on-write semantics
- High-performance SIMD-accelerated search with competitive recall metrics
- Pure JVM implementation with no native dependencies, ensuring cross-platform compatibility
- Pluggable storage backends (memory, file, S3) and async operations for efficient I/O

## Why It Matters for RAG Builders
Proximum uniquely combines vector search with Git-like versioning, enabling RAG builders to track, branch, and audit embedding experiments while maintaining high performance and reproducibility.
