## Summary
The hana-mcp-server implements the Model Context Protocol (MCP) for SAP HANA and SAP HANA Cloud, enabling AI clients to discover database schemas, execute SQL queries with guardrails, and integrate business/domain metadata for consistent agent interpretations.

## Key Features
- Implements Model Context Protocol (MCP) for SAP HANA and SAP HANA Cloud
- Enables AI clients to discover schemas, run SQL queries with guardrails, and integrate business metadata
- Supports both stdio and HTTP transport for MCP clients (Claude, VS Code, Cursor, etc.)
- Provides 34 tools for schema browsing, SQL execution, structural analysis, and data insights
- Includes configurable limits, logging, and security features (JWT, TLS, DML guardrails)

## Why It Matters for RAG Builders
It bridges SAP HANA databases with AI agents via the MCP standard, enabling secure, structured, and business-context-aware data access for RAG systems.
