## Summary
A software-centric, self-contained bioinformatics skill library designed to standardize bioinformatics tools and workflows. It supports native, Nextflow, and Snakemake implementations, enabling both human engineers and AI agents to execute or orchestrate bioinformatics tasks with minimal external dependencies.

## Key Features
- Dual-source architecture combining official modules (nf-core, snakemake-wrappers) with self-contained native implementations for flexibility and extensibility.
- Zero external network dependency with all dependencies (code, containers, Conda environments, test data) localized within the repository.
- Explicit software version tracking across native, nf-core, and snakemake-wrappers implementations to ensure compatibility and transparency.
- Native support for both CLI execution and JSON-Schema-driven function calling for AI agents, enabling seamless integration into automated workflows.
- Strict containerization standards using Debian slim images with apt-based minimal installations, avoiding default Conda dependencies.

## Why It Matters for RAG Builders
It provides a standardized, self-contained library of bioinformatics tools that AI agents can reliably invoke, reducing integration complexity and ensuring reproducibility in RAG and automated workflows.
