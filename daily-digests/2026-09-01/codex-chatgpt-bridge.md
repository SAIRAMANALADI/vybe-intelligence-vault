## Summary
A bridge tool that enables safe collaboration between Codex and ChatGPT by offloading planning and reasoning to ChatGPT while keeping local execution and verification under Codex control, optimizing token usage and maintaining local security boundaries.

## Key Features
- Offloads heavy planning and reasoning to ChatGPT while Codex handles execution and verification
- Supports multiple routing modes (NORMAL, TOKEN_SAVING, CHATGPT_ARCHITECT) for flexible token optimization
- Local execution remains scoped, re-keyable, and under user control with OAuth-gated access
- Includes a bridge controller for managing tunnel, service, and OAuth token lifecycle
- Provides panic-button functionality to revoke OAuth tokens and re-key access

## Why It Matters for RAG Builders
It enables efficient collaboration between Codex and ChatGPT while maintaining local control and security, reducing token costs and improving workflow efficiency for AI-driven coding tasks.
