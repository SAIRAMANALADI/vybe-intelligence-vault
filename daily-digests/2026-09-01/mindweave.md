## Summary
MindWeave is a terminal-native AI coding agent that operates entirely locally, enabling users to bring their own model API keys for code editing, searching, and execution. It integrates Model Context Protocol (MCP) servers for external tool integration while prioritizing security and model efficiency.

## Key Features
- Fully local execution with BYOK (Bring Your Own Key) model API support
- Model Context Protocol (MCP) server integration for external tools (GitHub, Postgres, etc.)
- Deterministic code intelligence via tree-sitter and language servers
- Session memory with automatic compaction and state summarization
- Per-project governance with rules, skills, and forbidden paths/commands

## Why It Matters for RAG Builders
MindWeave provides a secure, local-first AI coding agent framework with MCP integration, enabling developers to build and deploy AI-driven coding assistants without relying on external servers or sacrificing control over their codebase.
