## Summary
AutoMem MCP is an MCP (Model Context Protocol) client that enables persistent, graph-vector memory for AI assistants across platforms like Claude, Cursor, and GitHub Copilot. It connects AI tools to the AutoMem backend service for durable memory storage and retrieval.

## Key Features
- Persistent memory across AI sessions and platforms with sub-second retrieval
- Graph-vector architecture for associative memory (11 customizable relationship types)
- Cross-platform compatibility with MCP-supported AI tools (Claude, Cursor, GitHub Copilot, etc.)
- Guided setup and configuration wizards for local, hosted, or remote deployments
- Advanced recall features including multi-hop reasoning and ranked retrieval

## Why It Matters for RAG Builders
AutoMem MCP is essential for RAG builders as it provides a robust, persistent memory layer that enables AI assistants to retain context and learn from interactions over time, significantly enhancing the relevance and continuity of AI-driven applications.
