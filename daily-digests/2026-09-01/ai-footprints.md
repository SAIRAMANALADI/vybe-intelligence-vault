## Summary
足迹 AI 是一个智能网页收藏管理工具，利用 AI 自动分析、分类和标记用户收藏的内容，支持跨平台同步、共享协作和 Agent API 接入，帮助用户高效整理和检索知识。

## Key Features
- AI 自动提取摘要、标签和分类，无需手动整理
- 支持共享分类和协作模式（成员可读写或只读）
- 提供浏览器首页集成，便于快速访问知识库
- 支持 Agent API 接入，实现自动化数据管理
- 跨平台同步（PC/手机 H5）
