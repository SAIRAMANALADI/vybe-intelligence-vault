## Summary
A multi-layered AI agent system designed for adaptive learning, integrating Planner→Executor→Writer architecture with Reflexion-based self-validation. It combines RAG hybrid retrieval, tool protocol adaptation, and Feishu document output to create an end-to-end learning and evaluation pipeline.

## Key Features
- Planner→Executor→Writer three-layer agent architecture with ReAct loops and Reflexion self-validation (54% trigger rate)
- Hybrid RAG retrieval combining vector search, knowledge graphs, and paper-based indexing with AST chunking for code
- Feishu document output pipeline for automated knowledge base generation and archiving
- Comprehensive evaluation framework with 134 pytest cases, gold-standard test sets, and MRR metrics
- Multi-protocol tool adaptation (native function calling + ReAct fallback) for compatibility with multiple LLM providers
