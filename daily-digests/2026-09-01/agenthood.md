## Summary
Agenthood provides a society of specialized AI agents (e.g., architect, reviewer, auditor) as plain Markdown skill files that can be integrated into any agent runtime or executed autonomously via a TypeScript CLI. It enforces high standards for software development practices, including commit messages, PR reviews, and system design.

## Key Features
- Predefined set of 19 specialized AI agents with distinct roles and responsibilities
- Agent-agnostic skill files compatible with Claude Code, Copilot, and custom runtimes
- Autonomous execution via TypeScript CLI with support for multiple LLM providers
- Built-in workflow engine, quality gates, and failover mechanisms for reliability
- Comprehensive memory tiers (short-term, long-term, episodic) and RAG capabilities

## Why It Matters for RAG Builders
Agenthood standardizes AI-driven software development practices by providing a reusable, opinionated framework of specialized agents that enforce best practices and improve code quality across projects.
