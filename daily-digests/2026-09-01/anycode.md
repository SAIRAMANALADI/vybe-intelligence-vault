## Summary
anycode is a web-based collaborative code editor and agent integration platform designed for cross-device development, supporting real-time multi-agent workflows, advanced code analysis, and seamless file system integration.

## Key Features
- Ultra-fast custom editor with tree-sitter-based virtual rendering for large codebases
- Multi-language support with advanced syntax highlighting and real-time analysis
- LSP integration for intelligent code completion, diagnostics, and go-to-definition
- ACP integration for seamless AI agent collaboration with tool-call streaming and session management
- Flexible workspace layout with integrated terminal, search, and Git operations
