## Summary
Cherry Studio is a cross-platform desktop client for interacting with multiple LLM providers, offering a unified interface for AI assistants, document processing, and productivity tools. It supports cloud-based and local models, with features like multi-model conversations, file management, and customizable themes.

## Key Features
- Unified access to 300+ pre-configured AI assistants and custom assistant creation
- Supports major cloud LLMs (OpenAI, Gemini, Anthropic) and local models (Ollama, LM Studio)
- Advanced document processing with WebDAV integration, Mermaid chart visualization, and code syntax highlighting
- Cross-platform support (Windows, Mac, Linux) with light/dark themes and transparent window options
- MCP server integration for extensibility and plugin system support

## Why It Matters for RAG Builders
Cherry Studio provides a unified, user-friendly interface for interacting with multiple LLMs and tools, reducing complexity for RAG builders who need a cohesive environment for AI-driven workflows.
