## Summary
Delamain is an MCP server that enables AI agents to perform headless, low-memory Android reverse engineering using JADX, allowing analysis of APK, DEX, and AAB files without manual intervention.

## Key Features
- Headless Android reverse engineering via MCP server
- Low-memory operation for efficient processing
- Supports APK, DEX, and AAB file formats
- Enables AI agents to automate reverse engineering tasks
- Integrates with JADX for decompilation and analysis
