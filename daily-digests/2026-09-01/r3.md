## Summary
r3 is an MCP server providing persistent, local-first memory for AI clients like Claude Desktop, Claude Code, and Cursor. It combines an embedded Redis instance with a local vector index for semantic search, enabling zero-config memory storage and retrieval without external services.

## Key Features
- Zero-config local memory storage with embedded Redis and vectra
- Semantic search via local vector index (no external vector DB required)
- Optional cloud sync with Mem0 for cross-device memory persistence
- Enhanced mode for entity extraction and knowledge graph generation
- Sub-5ms response times for memory operations

## Why It Matters for RAG Builders
r3 enables AI applications to maintain persistent, local-first memory without external dependencies, reducing latency and privacy concerns while simplifying RAG pipeline integration.
