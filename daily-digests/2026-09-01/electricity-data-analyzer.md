## Summary
A Python-based CLI tool that analyzes electricity consumption data by uploading CSV files to MySQL, performing trend analysis with Pandas/NumPy, generating visualizations with Matplotlib, and providing AI-powered insights via the Gemini API for natural-language explanations of usage patterns.

## Key Features
- CSV data ingestion and MySQL storage for electricity usage records
- Trend analysis and peak usage hour detection with Pandas/NumPy
- Automated chart generation for consumption patterns
- Natural-language AI explanations via Gemini API for user queries
- Modular Python architecture for extensibility
