## Summary
A local AI development workbench for Minecraft mod projects that enables AI agents to plan, edit, and validate changes in an isolated staging workspace before applying them. Supports Minecraft 26.1.2, NeoForge 26.1.2.84, and Java 25.

## Key Features
- Isolated staging workspace for AI-generated changes to prevent direct project modification
- Two approval modes: manual review or automated application of changes after validation
- Deterministic validation tied to candidate changes and validator versions
- Bounded retry mechanism for failed executions within approved plans
- Security-focused architecture with strict permission boundaries and audit trails

## Why It Matters for RAG Builders
It provides a secure, auditable pipeline for AI agents to safely modify Minecraft mods without risking direct project corruption, bridging the gap between AI planning and human oversight.
