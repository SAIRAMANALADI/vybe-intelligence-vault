## Summary
Phoenix MCP enables AI agents to securely interact with Home Assistant by providing scoped, least-privilege access through per-token permissions, auditing, and a semantic safety layer (MESA). It integrates directly into Home Assistant with no external dependencies or processes.

## Key Features
- Scoped, least-privilege access for AI agents via per-token permissions
- Built-in semantic safety layer (MESA) for per-entity restrictions
- Auditing and revocable tokens with configurable rate limits
- Supports both built-in and external MCP clients (Claude, Cursor, etc.)
- No cloud dependency; runs entirely within Home Assistant

## Why It Matters for RAG Builders
Phoenix MCP provides a secure, auditable way to grant AI agents controlled access to Home Assistant, reducing security risks while enabling automation.
