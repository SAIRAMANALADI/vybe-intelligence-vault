## Summary
Devo is an open-source, model-neutral coding agent with a desktop app, terminal TUI/CLI, and Rust-based runtime. It enables private, enterprise, and OpenAI-compatible model environments while supporting MCP servers, skills, and local code search for autonomous development workflows.

## Key Features
- Model-neutral provider runtime supporting OpenAI-compatible, Anthropic-compatible, DeepSeek, Qwen, Kimi, and local endpoints
- Cross-platform desktop app and terminal TUI/CLI for unified agent workflows
- Built-in MCP server support for tool integration and semantic code search
- Multi-agent coordination, auditable sessions, and permissioned tool execution
- Plan Mode, parallel tool calls, and long-running task management for complex workflows

## Why It Matters for RAG Builders
Devo provides a flexible, privacy-focused alternative to hosted coding agents, enabling RAG builders to integrate autonomous agents with custom models and tools while maintaining full control over runtime and data.
