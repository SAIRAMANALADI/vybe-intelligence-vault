## Summary
OpenWebCode is a browser-based AI coding workbench that runs locally and enables agents to read, edit, and execute code, commands, and tests directly in the browser. It supports Windows and Linux with robust sandboxing, snapshot management, and multi-model agent orchestration.

## Key Features
- Browser-native AI coding workbench with React UI and Node.js backend
- Advanced sandboxing with platform-specific isolation (Windows Job Object/AppContainer, Linux bubblewrap/Landlock)
- Git and filesystem snapshots with multiple backend support (ZFS, Btrfs, overlayfs, VHDX, qcow2)
- Multi-model agent orchestration with fallback chains, role-based routing, and automatic model switching
- Extensible architecture with Skills, MCP, Hooks, slash commands, and custom agent swarms

## Why It Matters for RAG Builders
It provides a secure, extensible local AI coding environment with robust sandboxing and multi-model support, essential for building reliable RAG systems that require safe code execution and context management.
