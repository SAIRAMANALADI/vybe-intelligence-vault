## Summary
Moodish is a mood-based food planning application that generates personalized meal recommendations based on user mood, budget, dietary needs, and preferences. It supports both personal and group meal planning with conversational AI integration and transparent recommendation traces.

## Key Features
- Personalized mood-based meal recommendations with AI summaries
- Group meal planning with voting, ranking, and manager oversight
- Transparent recommendation trace showing AI prompts, scores, and responses
- Support for dietary restrictions, budget limits, and discovery modes
- Secure cart confirmation before checkout with demo and live modes
