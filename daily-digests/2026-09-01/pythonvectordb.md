## Summary
PythonVectorDB is a lightweight, pure Python vector database designed for efficient storage and similarity search of vector embeddings. It supports Int8 quantization for memory efficiency and offers high query performance with minimal setup complexity.

## Key Features
- Pure Python implementation with no external dependencies
- Int8 quantization for optimized memory usage and performance
- High query throughput (~1100 queries/sec with 50,000 vectors)
- Single-file deployment with no complex configurations
- MIT License for unrestricted use in personal and commercial projects
