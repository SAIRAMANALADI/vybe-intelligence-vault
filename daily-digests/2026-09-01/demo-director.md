## Summary
Demo Director is an MCP server that transforms an AI agent into a product presenter by enabling hands-free recording of keynote-quality demo videos. It combines native macOS screen recording, human-like cursor control, Chrome DevTools integration, and natural voiceover generation to produce polished MP4 videos with narration.

## Key Features
- Native macOS screen recording with full control over resolution and region
- Human-like cursor movement using a Swift CGEvent driver for smooth, realistic interactions
- Chrome DevTools integration for precise UI element targeting and automated navigation
- Natural voiceover generation with Voicebox integration or fallback to macOS `say`
- Automated composition of final narrated MP4 video in a single call

## Why It Matters for RAG Builders
It enables AI agents to autonomously produce high-quality, human-like demo videos, reducing manual effort and improving the presentation of AI-driven applications.
