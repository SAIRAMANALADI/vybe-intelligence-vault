## Summary
Apollo AGI transforms any WhatsApp number into a personal AI agent capable of processing text, voice notes, images, PDFs, and polls. It integrates with Obsidian vaults for contextual knowledge and supports extensible tools via MCP, enabling real-time, secure interactions directly within WhatsApp.

## Key Features
- Native WhatsApp support for text, voice, images, PDFs, and polls with natural balloon replies
- Seamless Obsidian vault integration for contextual knowledge and git sync
- Extensible tooling via MCP and a centralized registry.json for modular functionality
- Real-time progress streaming and user approval for destructive actions
- Dynamic model/mode switching and per-contact message queuing with burst debouncing

## Why It Matters for RAG Builders
Apollo AGI bridges the gap between AI agents and everyday communication tools like WhatsApp, enabling seamless, context-aware interactions without requiring users to adopt new apps or habits.
