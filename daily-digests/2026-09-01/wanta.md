## Summary
Wanta is an open-source foundation for building desktop AI agents with OpenCode, providing a complete runtime, local tools, permission controls, and a cross-platform desktop interface. It enables developers to create production-ready AI agents without rebuilding core infrastructure.

## Key Features
- Pre-built desktop agent runtime with lifecycle management and streaming events
- Local tool integration (files, shell, scripts, web access) with permission controls
- Artifact handling for generated work (spreadsheets, documents, code, images)
- Support for OpenAI-compatible models and OOMOL-hosted models
- Cross-platform Electron packaging with auto-updates

## Why It Matters for RAG Builders
Wanta provides a production-ready foundation for building desktop AI agents, eliminating the need to reinvent core infrastructure like runtime management, permissions, and UI integration.
