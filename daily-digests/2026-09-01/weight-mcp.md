## Summary
weight-mcp is a self-hosted Model Context Protocol (MCP) server that functions as a personal calorie and protein counter, integrating with claude.ai to log meals, track weight, and render interactive dashboards. It supports multi-user management, nutrition database lookups, and optional accountability reporting via Telegram.

## Key Features
- Multi-user support with admin-controlled account registration
- Interactive dashboard rendered directly in claude.ai conversations
- Nutrition database lookups (Open Food Facts, USDA)
- Weight tracking and goal setting with floor/ceiling modes
- Optional daily accountability reports via Telegram
