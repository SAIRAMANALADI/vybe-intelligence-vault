## Summary
pi-code enhances the pi coding agent by extending its capabilities to match Claude Code's feature set. It integrates with existing .claude/ configurations, adds missing features like todos, checkpoints, memory, and web search, and provides a seamless experience for managing rules, commands, skills, and MCP servers.

## Key Features
- Reads and integrates with existing .claude/ configurations (rules, commands, skills, hooks, output styles, MCP servers)
- Adds missing features like persistent todo lists, checkpoints, memory, and web search/fetch
- Supports subagents and plan mode for complex task execution
- Provides project trust gating for secure configuration loading
- Offers extensible architecture with modular extensions for custom functionality
