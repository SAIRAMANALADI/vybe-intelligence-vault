## Summary
Memex is a Windows desktop application that transforms local file systems into personal knowledge wikis. It indexes plain text files and folders, enabling users to organize, search, and link notes without requiring databases or servers.

## Key Features
- Converts folders into searchable wikis with automatic indexing
- Supports Markdown for note formatting and cross-linking
- Operates entirely offline with no data transmission
- Lightweight and portable with minimal system requirements
- Privacy-focused with no tracking or external dependencies

## Why It Matters for RAG Builders
Memex provides a simple, private way to organize and retain knowledge from LLM interactions locally, preventing information loss across sessions.
