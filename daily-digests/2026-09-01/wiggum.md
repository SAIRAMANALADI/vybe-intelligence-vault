## Summary
Wiggum is a self-driving agent loop that automates multi-step software development tasks by turning issue descriptions into structured workplans, implementing them incrementally, verifying changes with project-specific toolchains, and committing results autonomously or under human supervision.

## Key Features
- Structured workplan generation from issue descriptions with phases, tasks, and acceptance criteria
- Incremental implementation with isolated, single-purpose commits
- Automated verification using project-specific toolchains (linters, type checkers, tests)
- Self-healing mechanism for failed verifications with autofix and Claude escalation
- Background execution, supervision, and chaining of workplans
