## Summary
bing-webmaster-mcp provides AI agents with read and write access to Bing Webmaster Tools data, enabling monitoring of site traffic, indexing status, crawl issues, and keyword performance, along with tools for URL submission and IndexNow integration.

## Key Features
- Read access to Bing Webmaster Tools data (traffic, indexing, crawl issues, keywords)
- Two write paths: direct (default) or reviewed (human-approved) for safety
- IndexNow submission support for multi-engine indexing
- Plan-based write operations with audit trails and safety checks
- CLI and MCP server integration for AI agent compatibility

## Why It Matters for RAG Builders
It enables AI agents to safely interact with Bing's search infrastructure for SEO tasks, ensuring controlled write operations and comprehensive site monitoring.
