## Summary
coordinode is a desktop application that unifies graph search, vector search, and full-text search into a single local engine. It enables users to build and query knowledge graphs, perform semantic searches, and manage linked data for AI workflows like GraphRAG.

## Key Features
- Combines graph, vector, and full-text search in a single engine
- Supports OpenCypher-style graph queries for complex traversals
- Uses HNSW indexing for efficient vector search
- Provides MVCC for safe, concurrent data updates
- Runs locally with embedded storage for data privacy

## Why It Matters for RAG Builders
