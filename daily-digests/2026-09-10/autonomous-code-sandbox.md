## Summary
CloudForge AI is an autonomous cloud agent that detects code anomalies, spawns isolated sandboxes (AWS Fargate/Docker), applies AI-generated fixes, validates correctness, and opens pull requests without human intervention. It integrates with multiple LLM backends (Claude, GPT-4, Groq) for proactive code repair and DevOps automation.

## Key Features
- Autonomous detection and fixing of code anomalies, vulnerabilities, and lint errors
- Isolated sandbox validation using AWS Fargate or Docker for zero-risk testing
- Multi-LLM support with intelligent routing for cost and performance optimization
- Automated pull request creation with detailed test evidence and risk assessments
- Real-time dashboard for monitoring sandbox instances, LLM costs, and fix history

## Why It Matters for RAG Builders
It enables fully autonomous, AI-driven DevOps workflows that reduce mean time to resolution for code issues while ensuring zero production impact through sandboxed validation.
