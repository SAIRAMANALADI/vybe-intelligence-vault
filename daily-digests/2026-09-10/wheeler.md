## Summary
Wheeler is a local-first AI workflow tool for scientists that integrates with Claude Code to provide traceable, reproducible research workflows. It uses a knowledge graph to track dependencies between research artifacts (papers, code, data, findings) and ensures all AI-generated results are auditable and connected to their provenance.

## Key Features
- Automated provenance tracking for all research artifacts using W3C PROV-DM standards
- Dynamic knowledge graph for managing dependencies between papers, code, data, and findings
- Local-first execution with no cloud dependency or API keys required
- Slash commands for research workflows (/wh:discuss, /wh:plan, /wh:execute, /wh:write)
- Stability scoring and change propagation to flag outdated results

## Why It Matters for RAG Builders
Wheeler ensures AI-assisted research is auditable and reproducible by embedding provenance tracking into every step of the workflow, addressing a critical gap in credibility for AI-embedded science.
