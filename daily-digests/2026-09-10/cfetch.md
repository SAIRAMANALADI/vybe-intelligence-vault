## Summary
cfetch is a local-first memory and context control system for AI coding agents, enabling durable, cited recall of Markdown knowledge, precise code navigation, and autonomous Obsidian maintenance via a Rust-based MCP server and CLI tools.

## Key Features
- Cited Markdown recall with stable citations for AI agents
- Exact code symbol and line-range navigation via Tree-sitter
- Autonomous Obsidian knowledge graph maintenance and updates
- Multi-machine access with freshness-labeled queries and selective sharing
- Context condensation and token-budgeted answers to optimize RAG inputs

## Why It Matters for RAG Builders
cfetch provides a durable, local-first memory layer for RAG systems, enabling precise context retrieval and autonomous maintenance of knowledge bases, reducing hallucinations and improving agent efficiency.
