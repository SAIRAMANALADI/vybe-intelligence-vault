## Summary
Corely is an AI-native modular ERP kernel designed for freelancer workflows that scales into industry-specific packs (restaurant, hotel, factory) without code forking. It provides a modular monolith architecture with reliability, security, and developer experience primitives for building robust business applications.

## Key Features
- Modular monolith with bounded contexts and clear ownership boundaries to avoid code forking
- AI-native design with tool schemas, auditable tool executions, and idempotent retries
- Reliability primitives including Outbox pattern, background jobs, and CQRS-lite read models
- Security primitives like tenant-aware schemata, RBAC/ABAC guards, and immutable audit logs
- Developer experience with pnpm workspaces, mock server for UI-first workflows, and contract centralization

## Why It Matters for RAG Builders
Corely provides a robust, modular foundation for building AI-native business applications with built-in reliability and security, reducing development time and complexity for RAG/AI stack builders.
