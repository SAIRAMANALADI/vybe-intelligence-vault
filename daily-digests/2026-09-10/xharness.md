## Summary
xharness is a TypeScript-based coding agent harness that autonomously reads, modifies, and validates code via CLI or macOS GUI. It integrates with Anthropic-compatible APIs (e.g., DeepSeek) for streaming model interactions, supports configurable 'thinking' modes, and includes a skill system for extensible automation.

## Key Features
- Autonomous coding loop: read → modify → validate via CLI or GUI
- Configurable 'thinking' modes (none/low/high/max) with Anthropic-compatible API support
- Skill system for extensible automation (SKILL.md files) with project/global scope
- YOLO mode (no sandbox) with explicit risk warnings for direct shell/tool execution
- Built-in tools (Bash, Read, Write, Edit, Grep, Glob) and multi-project/session GUI management

## Why It Matters for RAG Builders
It provides a flexible framework for building autonomous coding agents that can autonomously modify and validate code, reducing manual intervention in AI-driven development workflows.
