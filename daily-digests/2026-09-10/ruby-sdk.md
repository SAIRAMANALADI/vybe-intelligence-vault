## Summary
The official Ruby SDK for the Model Context Protocol (MCP), enabling developers to build and integrate MCP servers and clients in Ruby. It provides tools for JSON-RPC 2.0 message handling, protocol initialization, tool/prompt/resource management, and supports multiple transport protocols like stdio and Streamable HTTP.

## Key Features
- Full implementation of the Model Context Protocol specification for Ruby
- Support for stdio and Streamable HTTP (including SSE) transports
- Tool, prompt, and resource registration and invocation
- Multi-round trip input handling with server-to-client requests (elicitation, sampling, roots)
- Configurable exception reporting and request lifecycle hooks

## Why It Matters for RAG Builders
It provides the essential Ruby tooling to build and integrate MCP-compliant agents and servers, critical for interoperability in AI-driven workflows.
