## Summary
Open Max is a lightweight, high-performance Rust-based agent harness designed for local development workflows. It provides a minimal, configurable terminal interface for running AI agents with full control over endpoints, tools, and context, while streaming tool calls in real-time.

## Key Features
- Single Rust binary (~5 MB) with minimal runtime overhead
- Full control over endpoints, tools, and context with no telemetry
- Highly configurable via local TOML files for tools, skills, and hooks
- Supports multiple model providers (Ollama, OpenRouter, vLLM, etc.) and local MLX on Apple Silicon
- Real-time streaming of tool calls with approval-based mutation control

## Why It Matters for RAG Builders
Open Max provides a lightweight, local-first agent framework that enables developers to build and extend AI-powered workflows without sacrificing control or privacy.
