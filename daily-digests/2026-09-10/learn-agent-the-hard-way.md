## Summary
A hands-on guide to building an AI agent harness from scratch, emphasizing tool design and implementation without relying on frameworks. The repository provides 32 exercises in Go (with Python/JavaScript versions) to construct a production-ready agent with features like tool loops, permissions, memory, and sandboxing.

## Key Features
- Step-by-step exercises to build an agent harness from 60 lines of code to a 5,000-line production system
- Covers core concepts like tool loops, permissions, memory, skills, subagents, and sandboxing
- Supports multiple languages (Go, Python, JavaScript) with real-world validated implementations
- Includes a complete harness with 19 tools, zero third-party dependencies (except LLM APIs), and MCP integration
- Provides a production-grade reference implementation distilled from an open-source agent (octo)

## Why It Matters for RAG Builders
It demystifies agent architecture by teaching how to design and implement tools, which is the core differentiator for building effective RAG systems.
