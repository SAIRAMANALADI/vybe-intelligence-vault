## Summary
Auto-updated index of Model Context Protocol (MCP) servers actively maintained on GitHub, refreshed every 15 minutes via GitHub Actions. Provides real-time discovery, cataloging, and ranking of MCP integrations for AI agents and applications.

## Key Features
- Auto-updates every 15 minutes using GitHub Actions cron jobs
- Real-time discovery of MCP servers via GitHub Search API
- Tracks stars, commits, and release freshness for reliability
- Provides installation commands for each MCP server
- Multi-language support with localized READMEs

## Why It Matters for RAG Builders
It provides a continuously updated, reliable source for discovering and integrating MCP servers into AI agent workflows, reducing manual curation efforts.
