## Summary
HiveMtk is an open-source AI-driven private-domain marketing operating system designed for Chinese market scenarios. It integrates multi-platform social media outreach, ReAct autonomous agents, and zero-data-exfiltration security with local inference, enabling teams to replicate top sales performers' capabilities in a self-hosted environment.

## Key Features
- ReAct autonomous agent with 41+ registered tools for end-to-end marketing workflows (sensing → planning → tool execution → reflection)
- Multi-platform social media integration (Douyin, Kuaishou, Xiaohongshu, Xianyu, TikTok, WeChat, email, Telegram, WhatsApp, SMS) with unified inbox and AI-driven responses
- 100% private deployment with local inference stack (llama.cpp + TEI) ensuring zero data exfiltration and compliance with sensitive industries (finance, healthcare, government)
- Hybrid retrieval-augmented generation (RAG) with 1024-dimensional pgvector HNSW indexing, BM25 keyword search, and bge-reranker-v2-m3 for precise context retrieval
- GEO (Generative Engine Optimization) module for AI search engine content optimization, including keyword distillation, multi-model validation, and schema markup generation

## Why It Matters for RAG Builders
HiveMtk provides a self-hosted, autonomous AI agent framework tailored for private-domain marketing, enabling teams to deploy secure, multi-platform outreach systems without relying on SaaS vendors or exposing sensitive data.
