## Summary
A Model Context Protocol (MCP) server that provides AI assistants with structured guidance on the ReactiveUI ecosystem, including package recommendations, migration strategies, and project scaffolding for cross-platform .NET UI development.

## Key Features
- Provides ecosystem-aware recommendations for ReactiveUI packages and patterns across multiple platforms (WPF, MAUI, Blazor, etc.)
- Offers a guided wizard for multi-endpoint solution planning and on-disk project generation
- Includes migration tools for upgrading legacy ReactiveUI applications to modern patterns
- Delivers catalog resources, prompts, and tools for AI-assisted code review and validation
- Supports source generators, validation strategies, and reactive collection patterns for optimized UI development

## Why It Matters for RAG Builders
This MCP server is essential for AI engineers building RAG systems that generate or review ReactiveUI-based applications, ensuring adherence to modern patterns and ecosystem best practices.
