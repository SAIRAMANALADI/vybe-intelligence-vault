## Summary
xCOMET MCP Server is an unofficial community project that provides AI agents with translation quality evaluation capabilities using Unbabel's xCOMET models. It enables referenceless or reference-based scoring, error detection, and batch processing for machine translation workflows.

## Key Features
- Referenceless and reference-based translation quality scoring (0-1 scale)
- Error detection with severity levels (minor/major/critical) and span identification
- Batch processing for efficient evaluation of multiple translation pairs
- GPU acceleration support for faster inference
- Persistent model loading for optimized performance in long-running sessions

## Why It Matters for RAG Builders
It enables AI agents to autonomously evaluate and improve translation quality, reducing manual review efforts and ensuring high-fidelity outputs in multilingual applications.
