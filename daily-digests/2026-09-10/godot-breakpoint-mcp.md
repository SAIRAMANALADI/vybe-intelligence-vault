## Summary
Breakpoint MCP is an MCP-compatible server that integrates the Godot game engine into an AI assistant's development workflow, enabling real-time debugging, type-checked script authoring, and live game interaction through Godot's native protocols like LSP and DAP.

## Key Features
- Real-time step-debugging for GDScript and C# via Godot's native DAP and LSP
- Type-aware script authoring with completion, diagnostics, and refactoring support
- Secure-by-default tool surface with risk annotations and opt-in privileged tools
- Live game interaction and verification through runtime assertions and screenshots
- Undo-safe editing with full integration of Godot's EditorUndoRedoManager

## Why It Matters for RAG Builders
Breakpoint MCP enables AI assistants to debug live game failures and refactor code using real program state and symbols, bridging the gap between AI-driven development and human developer workflows in Godot.
