## Summary
SageFs is a live F# development engine that provides hot reload, real-time testing, and AI-native agent access for F# projects. It enables sub-500ms feedback loops, hot patching of running applications, and MCP-compatible agent interactions for AI-driven development workflows.

## Key Features
- Sub-500ms feedback on every save with inline results and live test markers
- Hot reload via Harmony runtime patching for instant code updates without rebuilds
- MCP-compatible agent interface for AI-driven code execution and test verification
- Multi-client support (VS Code, Neovim, Visual Studio, web dashboard, MCP clients) sharing a single daemon
- Live testing with gutter markers and coverage visualization for rapid feedback

## Why It Matters for RAG Builders
