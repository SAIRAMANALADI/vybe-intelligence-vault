## Summary
OmniForge is an AI-powered plugin for Claude Code that automates the GitLab merge request lifecycle, including multi-agent adversarial review, automated issue resolution, and MR creation with auto-populated metadata. It streamlines code reviews, reduces manual effort, and ensures consistency in MR quality.

## Key Features
- Multi-agent adversarial review with confidence scoring and cross-correlation
- Automated issue resolution with triage, fixing, and verification
- MR creation with auto-populated title and description from commit history
- Isolated git worktrees for safe, parallel agent execution
- False positive reduction and confidence-based filtering

## Why It Matters for RAG Builders
OmniForge significantly reduces the friction in the merge request lifecycle by automating reviews, fixes, and creation, enabling faster and more reliable code integration.
