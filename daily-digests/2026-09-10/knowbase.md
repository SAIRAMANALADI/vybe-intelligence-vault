## Summary
knowbase is a shared experience repository for AI agents that stores build errors, attempted fixes, and dead ends to prevent redundant troubleshooting. It enables agents to record and recall contextual problem-solving knowledge, including failed attempts and version-specific solutions, to improve future agent interactions.

## Key Features
- Stores failures, attempted fixes, and dead ends to prevent redundant troubleshooting by AI agents
- Implements confidence-based validation with independent reproduction, not popularity
- Provides a strict Knowledge Object (KO) schema with primary sources, discriminators, and depth floors
- Supports automatic integration with multiple AI coding agents via MCP and rule-based hooks
- Enforces idempotent installation, local note-keeping, and manual reporting to maintain privacy

## Why It Matters for RAG Builders
It reduces redundant problem-solving cycles in AI agents by capturing and sharing contextual troubleshooting knowledge, including failed attempts and version-specific fixes, which no search engine can provide.
