## Summary
A Claude Code plugin that integrates with ctlsurf, a hosted system of record for AI coding agents. It enables agents to document decisions, assumptions, and task progress in real-time via structured notebooks and MCP tools, with exportable provenance reports for compliance and review.

## Key Features
- 90+ MCP tools for structured agent interactions (pages, tables, logs, tasks)
- Real-time documentation of agent decisions, assumptions, and trade-offs
- Exportable provenance reports (JSON/PDF) for human review or compliance
- Three built-in skills for session documentation, decision logging, and task management
- Hosted backend (no local server required) with free tier and API key authentication

## Why It Matters for RAG Builders
It provides a critical system of record for AI agents to document their work, enabling auditability, compliance, and knowledge retention in AI-driven development workflows.
