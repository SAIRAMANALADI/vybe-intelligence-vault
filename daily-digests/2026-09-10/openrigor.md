## Summary
OpenRigor is a clean-room, open-source implementation of a persistent AI-agent workspace that enables planning, tool execution in isolated workspaces, progress streaming, disconnection resilience, and inspectable file returns. It serves as a behavioral and architectural equivalent to ClawsGO without copying its code or assets.

## Key Features
- Persistent AI-agent workspace with durable runs and event replay
- Isolated sandboxed tool execution with configurable permissions
- Streaming progress and real-time SSE for user feedback
- Disconnection resilience and interrupt handling
- Inspectable file and artifact delivery with signed URLs

## Why It Matters for RAG Builders
OpenRigor provides a foundational framework for building scalable, persistent, and secure AI agent orchestration systems with durable execution and artifact management.
