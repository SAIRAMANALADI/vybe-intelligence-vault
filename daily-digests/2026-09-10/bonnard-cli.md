## Summary
bonnard-cli is a Windows-based analytics tool that provides a CLI, server, and dashboards for non-technical users to access and visualize data from platforms like BigQuery, Snowflake, and Databricks without requiring programming skills.

## Key Features
- Provides a unified CLI and dashboard interface for data analytics
- Supports integration with BigQuery, Snowflake, and Databricks
- Designed for non-technical users with no coding required
- Includes a local MCP server for data processing and visualization
- Offers semantic layer support for organizing and managing metrics
