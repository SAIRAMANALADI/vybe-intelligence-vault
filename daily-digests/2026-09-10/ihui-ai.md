## Summary
IHUI-AI is an open-source, production-grade AI Agent Platform and LLM Gateway that unifies 176 models via MCP, LangGraph, and A2A protocols. It serves as a multi-tenant AI operating system with row-level security, RAG knowledge base, and an agent marketplace, offering an 8-platform full-stack solution (Web, API, CLI, Desktop, Extension, Mobile, Mini-program, AI-service) from a single monorepo.

## Key Features
- Unifies 176 LLMs via MCP, LangGraph, and A2A protocols for seamless model integration and orchestration
- 8-platform full-stack coverage (Web, API, CLI, Desktop, Extension, Mobile, Mini-program, AI-service) from a single monorepo
- Multi-tenant architecture with row-level security, RAG knowledge base, and agent marketplace for scalable AI applications
- Comprehensive i18n support (5 languages) with automated translation pipelines and parity checks
- Production-ready deployment options (Vercel, Railway, Render, Heroku) with Docker Compose for self-hosting

## Why It Matters for RAG Builders
IHUI-AI provides a unified, production-grade platform for building and deploying AI agents and RAG systems, eliminating the need to integrate disparate tools and frameworks.
