## Summary
Aelix-AI is a self-hosted, auditable agent runtime and extension platform built in pure Python. It enables teams to extend AI agents with plain Python functions, hot-reload extensions, and run them in-process without vendor lock-in or telemetry.

## Key Features
- Pure Python agent runtime with in-process extension execution
- Hot-reloadable extensions without session restarts
- Publisher signing and provenance toolchain for trusted extensions
- Multi-provider support (Anthropic, OpenAI, GitHub Copilot, etc.) with native adapters
- Headless and scriptable modes for CI, pipelines, and evaluation loops

## Why It Matters for RAG Builders
Aelix-AI empowers RAG builders to create auditable, extensible, and self-hosted agent systems that integrate seamlessly with existing Python-based data and ML stacks.
