## Summary
KanseiLink MCP Server is a local-first tool that helps AI agents efficiently discover, evaluate, and compose MCP (Model Context Protocol) services with minimal token usage. It provides a local SQLite database of pre-evaluated services, recipes, and insights to reduce trial-and-error in integrating SaaS APIs and MCP servers.

## Key Features
- Local SQLite database with 11,000+ pre-evaluated services and 200 workflow recipes
- 89-97% token savings by eliminating trial-and-error and redundant API calls
- Unified toolset with 5 core tools (search_services, lookup, report, inspect, analyze) and mode auto-detection
- Privacy-preserving design with PII auto-masking and no telemetry by default
- Auto-invocation skills for popular MCP clients like Claude Code, Cursor, and Zed

## Why It Matters for RAG Builders
KanseiLink drastically reduces token waste and integration friction for AI agents by providing pre-verified service data and recipes, making it essential for RAG/AI stack builders aiming for efficiency and reliability.
