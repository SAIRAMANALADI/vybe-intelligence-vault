## Summary
UIInspect.MCP is a consent-gated NuGet MCP server that provides AI agents with semantic access to Windows desktop applications via UI Automation 3 (UIA3). It enables structured UI inspection and deterministic actions without relying on screenshots or pixel coordinates.

## Key Features
- Semantic access to Windows UI elements via UIA3 without pixel-based automation
- Consent-gated security model with user approval for exact process instances
- Bounded, flattened control-tree snapshots for deterministic element references
- Deterministic actions (click, set value, select, expand/collapse) using opaque element IDs
- Audit logging with redaction of sensitive data (passwords, clipboard, keystrokes)

## Why It Matters for RAG Builders
It enables AI agents to safely and deterministically interact with Windows desktop applications through structured UI automation, eliminating the need for brittle pixel-based or OCR-based approaches.
