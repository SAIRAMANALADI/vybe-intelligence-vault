## Summary
AI Web is a natural language-driven Browser Agent execution platform that processes web automation tasks submitted via text commands. It schedules tasks to distributed Browser Agents running Playwright across multiple browser engines (Chrome, Firefox, WebKit), executes actions, and returns detailed reports with screenshots, actions, and results.

## Key Features
- Natural language task submission without scripting or XPath selectors
- Multi-browser concurrent execution (Chrome, Firefox, WebKit) with slot-based agent allocation
- Detailed traceable reports with screenshots, actions, and execution metrics
- API, Webhook, and CLI interfaces for task submission, monitoring, and callbacks
- Site context management with login state injection and keyword-based site mapping

## Why It Matters for RAG Builders
AI Web provides a reliable, scalable orchestration layer for browser-based AI agents, enabling seamless integration of web automation into RAG pipelines without managing browser infrastructure.
