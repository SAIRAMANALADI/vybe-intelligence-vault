## Summary
Zvec is an open-source, in-process vector database designed for lightweight, high-performance similarity search. It supports dense and sparse vectors, full-text search, and hybrid retrieval, with production-grade durability and scalability.

## Key Features
- Blazing-fast similarity search with support for billions of vectors in milliseconds
- Native full-text search (FTS) with Unicode tokenization and multi-language support
- Hybrid search combining vector similarity, FTS, and structured filters
- Durable storage with write-ahead logging (WAL) for crash recovery
- Multi-language SDKs (Python, Node.js, Go, Rust, Dart/Flutter) and cross-platform support

## Why It Matters for RAG Builders
Zvec provides a lightweight, embeddable vector database essential for RAG systems requiring high-performance similarity search, hybrid retrieval, and minimal setup overhead.
