## Summary
A Claude Skill that integrates the VirtualSMS MCP server to enable AI agents and developers to perform account verification via real SIM-based SMS codes, dedicated number rentals, and matching-country proxies across 2500+ services and 145+ countries.

## Key Features
- Receive one-time SMS codes instantly via WebSocket or polling for batch jobs
- Rent dedicated numbers (1-30 days) or buy verification numbers on demand
- Purchase matching-country proxies (residential, mobile, or datacenter) for IP-number alignment
- Launch private cloud browser sessions for manual signup flows
- Supports 2500+ services and 145+ countries with real SIM-based numbers

## Why It Matters for RAG Builders
It provides a critical account verification layer for AI agents, enabling seamless integration with services that require SMS-based authentication while avoiding VoIP detection.
