## Summary
SendSprint automates the conversion of sprint tasks from Jira, Azure DevOps, or GitHub Issues into draft pull requests with embedded evidence. It acts as an autonomous agent that maps work, delegates code edits to simplicio-cli, collects validation and screenshots, and opens draft PRs for human review.

## Key Features
- Autonomous conversion of sprint tasks into draft PRs with embedded evidence (tests, screenshots)
- Integration with Jira, Azure DevOps, and GitHub Issues for task ingestion
- Delegates code edits to simplicio-cli while retaining control over the delivery loop
- Supports multilingual READMEs and cross-platform documentation
- Modular architecture with clear separation between brain (SendSprint) and hands (simplicio-cli)

## Why It Matters for RAG Builders
It streamlines the sprint-to-delivery pipeline by automating task mapping, code edits, and PR generation, reducing manual intervention and ensuring consistent evidence-backed delivery.
