## Summary
docvet is a Python tool that enforces high-quality docstring standards by checking for presence, completeness, accuracy, rendering compatibility, and visibility of documentation. It integrates with CI/CD, pre-commit hooks, and AI agent workflows to ensure docstrings remain up-to-date and useful for AI-driven code generation and maintenance.

## Key Features
- Multi-layered docstring validation (presence, style, completeness, accuracy, rendering, visibility)
- 20+ enrichment rules covering Args, Returns, Raises, Yields, Warns, Attributes, Examples, and cross-references
- Freshness checks via git diff/blame to detect stale docstrings
- Griffe rendering compatibility for MkDocs
- Pre-commit hooks, GitHub Actions, and MCP/LSP server support for seamless integration

## Why It Matters for RAG Builders
High-quality docstrings are critical for AI agents to generate accurate and maintainable code, and docvet ensures they remain complete, accurate, and compatible with documentation tools.
