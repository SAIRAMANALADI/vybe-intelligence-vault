## Summary
ryu-canvas is a ComfyUI/ElevenLabs-Flows-style node-based canvas for building and executing workflows involving image, video, chat, TTS, STT, upload, and note nodes. It integrates with Ryu's media and agent bridges, persisting boards as Space documents.

## Key Features
- ComfyUI/ElevenLabs-Flows-style node board for building workflows
- Integration with Ryu's media and agent bridges for TTS, STT, image/video processing
- Persistence of boards as Space documents
- Sandboxed companion UI built with React Flow and Vite
- Extensible node kinds mapped to bridge capabilities (media:*, hook:*)

## Why It Matters for RAG Builders
It provides a flexible, node-based UI for building and executing multimodal workflows, essential for RAG pipelines requiring media processing and agent interactions.
