## Summary
This repository demonstrates an integration between Pinecone and Neo4j to analyze and explore Supreme Court cases. It includes data processing scripts, a MongoDB database, and a web-based explorer for visualizing case relationships and embeddings.

## Key Features
- Demonstrates Pinecone-Neoj4 integration for case analysis
- Includes Jupyter notebooks for data processing and embedding generation
- Provides a web-based explorer for visualizing case relationships
- Uses MongoDB for raw data storage
- Supports OpenAI embeddings for enhanced analysis
