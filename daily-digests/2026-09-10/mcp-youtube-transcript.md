## Summary
A Model Context Protocol (MCP) server that retrieves YouTube video transcripts, metadata, and timed transcripts for integration with AI assistants and applications. It supports pagination, multi-language transcripts, and proxy configurations for restricted environments.

## Key Features
- Fetches transcripts for YouTube videos with optional language selection
- Provides timed transcripts with timestamps for precise referencing
- Retrieves video metadata (title, duration, etc.)
- Supports response pagination for long transcripts to avoid token limits
- Configurable proxy support for restricted environments

## Why It Matters for RAG Builders
It enables AI systems to dynamically fetch and process YouTube video content as structured text, enhancing RAG pipelines with real-time, high-quality data from video sources.
