## Summary
Bigfoot's Cave is a browser-based pixel art engine that provides a lightweight editor, REST API, and MCP server for creating, editing, and exporting pixel art assets. It enables both human users and AI agents to collaborate on a shared sprite library with zero dependencies and no build step.

## Key Features
- Zero-dependency, browser-based pixel art editor with a built-in REST API and MCP server for AI agent integration
- Real-time collaboration between humans and AI agents using a shared sprite library (JSON format)
- Supports multiple export formats (PNG, GIF, SVG, CSS, data-URI) with dynamic scaling and spritesheet generation
- Built-in palettes, layers, frames, onion skinning, and mirror drawing for efficient pixel art creation
- Self-contained static site generator for publishing a public gallery with search, tags, and download options

## Why It Matters for RAG Builders
It enables seamless collaboration between AI agents and humans for pixel art creation, streamlining asset generation in AI-driven projects.
