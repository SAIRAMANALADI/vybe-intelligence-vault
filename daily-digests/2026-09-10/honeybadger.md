## Summary
HoneyBadger is a security scanner designed to statically analyze AI assistant runtimes, MCP servers, and skills before installation. It performs static analysis to detect secrets, CVEs, supply chain risks, prompt injection, and capability drift without executing the scanned code.

## Key Features
- Static analysis of AI skills and MCP servers without code execution
- Multi-tiered paranoia levels for configurable security checks
- Detects secrets, CVEs, supply chain risks, and capability drift
- Supports CLI, Docker, and MCP server modes for integration
- Provides NDJSON audit trails and suppression mechanisms for findings

## Why It Matters for RAG Builders
HoneyBadger is essential for RAG builders as it preemptively secures AI assistant runtimes by detecting vulnerabilities and malicious patterns before deployment, ensuring safer and more reliable AI integrations.
