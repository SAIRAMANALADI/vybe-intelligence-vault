## Summary
Plexory Releases is a distribution repository for Plexory, a macOS app that serves as a native marketplace for discovering, installing, and auditing Claude Code MCP servers, skills, hooks, and commands. It provides downloadable artifacts and an auto-updater manifest for cross-platform desktop applications.

## Key Features
- Hosts downloadable artifacts for macOS, Windows, and Linux
- Provides an auto-updater manifest (`latest.json`) for seamless updates
- Supports signed and notarized macOS releases
- Centralized distribution for Plexory's cross-platform desktop app
- First public beta release with multi-platform support
