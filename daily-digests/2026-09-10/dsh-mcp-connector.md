## Summary
A connector and marketplace for managing DeepSeek Harness MCP servers, enabling unified discovery, authorization, and lifecycle management of over 100 MCP connectors with support for OAuth 2.0 PKCE, API keys, stdio/HTTP, and JSON imports.

## Key Features
- Unified marketplace for 100+ MCP connectors with continuous updates via a remote registry
- Supports OAuth 2.0 PKCE, API keys, stdio/HTTP, and JSON import for flexible server integration
- Lifecycle management including health checks, OAuth token refresh, and connection recovery
- Graphical UI for connector discovery, configuration, and tool/prompt discovery
- Security-focused with local credential storage, HTTPS enforcement, and input validation

## Why It Matters for RAG Builders
It simplifies the integration and management of MCP servers for RAG pipelines by providing a centralized, secure, and user-friendly way to discover, configure, and maintain connectors.
