## Summary
A local-first, deterministic personal finance ledger designed for AI agents, enabling secure financial state management with SQLite and validated JSON CLI commands. Compatible with tool-using AI agents like Claude Code and Hermes, it ensures financial integrity by separating conversation from state mutation.

## Key Features
- Local SQLite ledger with integer minor-unit money storage for precision
- Portable Agent Skill compatible with multiple AI harnesses (Claude Code, Hermes, Codex)
- Structured JSON output for reliable agent operation and integration
- Bank-agnostic CSV statement imports with reconciliation support
- Explicit approval workflows for finalizing reports to prevent unauthorized state changes
