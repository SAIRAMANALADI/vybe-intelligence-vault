## Summary
M1K3 is a local AI assistant for Apple Silicon Macs that runs entirely on-device, offering on-device LLM inference, live voice interaction, a personal knowledge graph with RAG, encrypted call transcription, and an MCP server for agent integration. It prioritizes privacy by ensuring no data leaves the device.

## Key Features
- Fully on-device inference with multiple LLM options (Apple Foundation Models, Qwen 3, Gemma 4)
- Live voice interaction with sentence-streamed TTS and on-device STT
- Personal knowledge graph with self-repairing memory and hybrid RAG capabilities
- Encrypted, on-device call transcription and local agent with tool execution
- MCP server integration for seamless AI agent collaboration

## Why It Matters for RAG Builders
M1K3 provides a fully local, privacy-preserving AI stack with RAG and MCP integration, enabling secure, offline-capable agent frameworks for developers building AI systems.
