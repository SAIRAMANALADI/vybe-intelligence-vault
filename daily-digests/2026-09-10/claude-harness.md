## Summary
claude-harness is a production-grade, incident-driven setup for Claude Code that enforces strict guardrails, model routing policies, and zero-dependency tooling to prevent common failures like process kills, secret leaks, and resource overuse. It includes a nightly self-reflection loop that promotes observations into rules based on evidence.

## Key Features
- Incident-born guard hooks that enforce strict policies (e.g., process kill prevention, secret scanning, git tree protection) to prevent real-world failures
- Enforced model routing policy with downward-only delegation and cost-based economics to optimize token usage
- Zero-dependency tools for monitoring, telemetry, and automation (e.g., spend tracking, token auditing, fleet management)
- Nightly self-reflection loop that promotes observations into standing rules based on evidence, ensuring continuous improvement
- Pre-commit and session-level guards that integrate seamlessly with Claude Code's lifecycle events

## Why It Matters for RAG Builders
It provides a battle-tested framework for building robust, self-healing AI agent systems with enforced guardrails and automated policy enforcement, critical for production-grade RAG deployments.
