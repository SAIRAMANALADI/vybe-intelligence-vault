## Summary
Mitsuro is a self-hosted AI workspace that integrates interactive coding, project research, and long-running agent tasks into a unified environment. It supports multiple AI providers, durable task execution via Hive, and cross-platform clients including mobile, web, desktop, terminal, and editor interfaces.

## Key Features
- Unified workspace for coding, research, and agent work with session persistence
- Hive system for durable, background task execution and recovery across restarts
- Multi-platform support (mobile, web, desktop, terminal, editor) with shared server backend
- Explicit tool permissions and provider credential management under user control
- Extensible via skills, plugins, MCP servers, and local extensions

## Why It Matters for RAG Builders
Mitsuro provides a robust, self-hosted framework for building and managing AI agents with durable task execution and multi-provider support, critical for scalable RAG and agentic workflows.
