## Summary
MCP server for DaData providing 31 tools for address validation, company lookup, geocoding, and data cleaning in Russia. Enables local deployment via npx with API keys stored securely, offering both free and paid features for AI and RAG stack integration.

## Key Features
- 31 tools covering addresses, companies, banks, contacts, passports, vehicles, and more
- Local deployment via npx with no external hosting required
- Free tier with 10,000 requests/day and 23 free tools
- Supports Russian and Kazakh company lookups, geocoding, and IP localization
- Strict input validation and security measures (Zod, path traversal protection)

## Why It Matters for RAG Builders
Provides essential local data enrichment and validation tools for RAG pipelines, enabling accurate address, company, and contact resolution in Russian-language contexts.
