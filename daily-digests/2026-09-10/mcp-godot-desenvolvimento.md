## Summary
A MCP server that integrates Godot 4.7 with AI agents (e.g., DeepSeek V4 Pro) via the MCP protocol, enabling natural language-driven game development with 191 tools, 69 modules, and automated verification pipelines.

## Key Features
- 191 tools for Godot game development via natural language prompts
- Automated verification pipeline with 4-stage testing (compile, headless run, screenshot, GUT tests)
- Sandboxed GDScript writing with syntax validation and security checks
- Runtime Bridge for TCP-based Godot interaction and screenshot capture
- ClassDB cache with 1074 Godot classes for fuzzy suggestions and toolset management

## Why It Matters for RAG Builders
It bridges AI agents with Godot's game development workflow, enabling AI-driven game creation and automation for RAG systems.
