## Summary
OpsNest V2 is a server-management application built on the CodexShell desktop shell, enabling users to manage servers and clusters using plain language via an AI Agent. It simplifies SSH server management for beginners without requiring programming or command memorization.

## Key Features
- Plain language server and cluster management via AI Agent
- Preservation of per-server SSH and AI session state
- Parallel server sessions with isolated terminal output and task state
- Support for structured server-command requests with function calling
- Compatibility with systemd, crontab, and rc.local for startup integration

## Why It Matters for RAG Builders
OpsNest V2 simplifies server management for AI-driven workflows by enabling plain language control, reducing the need for manual command execution and technical expertise.
