## Summary
Citadel is a local-first encrypted memory and SQL/vector database designed for AI agents, enabling secure, persistent storage with cryptographic forgetting and hybrid recall mechanisms. It supports embedded SQL, vector search, and integrates with agent frameworks like LangGraph and CrewAI.

## Key Features
- End-to-end encrypted storage with per-page AES-256-CTR + HMAC-SHA256
- Hybrid recall combining embeddings, BM25, and cross-encoder reranking for high-accuracy retrieval
- Cryptographic forgetting at per-atom, per-region, and whole-store granularity
- Full SQL support with vector types, JOINs, CTEs, and advanced query features
- Integrations with LangGraph, CrewAI, and MCP for seamless AI agent memory management

## Why It Matters for RAG Builders
Citadel provides a secure, high-performance foundation for RAG systems requiring encrypted memory, cryptographic erasure, and hybrid retrieval, ensuring data privacy and compliance without sacrificing recall accuracy.
