## Summary
KiCad MCP Pro is an MCP (Model Context Protocol) server that enables AI agents to programmatically interact with KiCad EDA workflows, including schematic design, PCB layout, DRC/ERC validation, DFM checks, and manufacturing export automation.

## Key Features
- Exposes KiCad tools via MCP for AI agent interaction, including schematic, PCB, DRC/ERC, DFM, and manufacturing export automation
- Supports both stdio and Streamable HTTP transports for flexible client integration
- Provides a web dashboard and desktop GUI for monitoring and control
- Includes a capability parity matrix (76.3%) to track supported KiCad programmatic features
- Offers agent plugins and skills for design review, PCB layout, DRC checks, and fabrication output workflows

## Why It Matters for RAG Builders
It bridges AI agents with KiCad EDA workflows, enabling automated schematic and PCB design review, validation, and manufacturing export for AI-driven hardware engineering pipelines.
