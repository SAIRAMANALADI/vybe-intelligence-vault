## Summary
BrainOutside is a self-hosted memory server for AI agents that stores knowledge as a Git repository of markdown files. It provides REST and MCP interfaces for agents to read and interact with the brain, enforces visibility tiers, and requires human approval for all writes via signed git commits.

## Key Features
- Git repository as the brain's storage, ensuring transparency and portability
- Human-gated write path with approval via signed git commits
- REST and MCP interfaces for agent access with enforced visibility tiers
- Lenses and context packs for tailored retrieval scopes
- Built-in chat test bench with source attribution and activity tracking

## Why It Matters for RAG Builders
BrainOutside provides a git-backed, human-gated memory system for AI agents that prioritizes transparency, portability, and trust over traditional vector databases, making it ideal for RAG builders seeking reliable and auditable knowledge storage.
