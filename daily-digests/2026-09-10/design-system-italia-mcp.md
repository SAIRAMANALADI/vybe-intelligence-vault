## Summary
Filo is an unofficial MCP (Model Context Protocol) server that provides AI assistants with structured access to Italy's Design System .italia resources, including Bootstrap Italia components, Dev Kit Italia web components, CSS design tokens, and component guidelines. It enables real-time querying of official design system data for AI-driven development and validation.

## Key Features
- Exposes structured Design System .italia data via MCP tools for AI assistants, including components, markup, props, and tokens
- Provides nightly CI snapshots to ensure data freshness and consistency
- Supports multi-language component queries (Italian and English)
- Includes design tokens with resolved values and dependency chains for customization
- Offers component guidelines, accessibility status, and GitHub issue tracking

## Why It Matters for RAG Builders
It enables AI assistants to query and validate design system components, tokens, and guidelines in real-time, ensuring generated code adheres to official Italian public administration standards.
