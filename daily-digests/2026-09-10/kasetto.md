## Summary
Kasetto is a declarative AI agent environment manager written in Rust, enabling reproducible, version-controlled configuration of skills, MCPs, commands, and instructions across multiple AI agents and machines using a single YAML file.

## Key Features
- Declarative YAML-based configuration for skills, MCPs, commands, and instructions
- Cross-platform support for multiple AI agents (Claude Code, Cursor, Codex, etc.)
- Secrets management with placeholder injection for secure token handling
- Lock file-based reproducibility ensuring consistent environments across teams
- Fast, hash-based diffing to minimize unnecessary sync operations

## Why It Matters for RAG Builders
Kasetto streamlines AI agent environment management by providing a reproducible, version-controlled way to synchronize skills and configurations across teams and machines, reducing drift and simplifying onboarding.
