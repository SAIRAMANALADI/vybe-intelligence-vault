## Summary
SunDash is a self-hosted personal dashboard for NAS devices, cloud servers, and personal computers, serving as a browser home page with multi-user bookmarks, system monitoring, weather, RSS feeds, memos, and an embedded MCP server for AI integration.

## Key Features
- Multi-user bookmark management with drag-and-drop organization and cross-browser sync
- System monitoring, weather, RSS feeds, and memos integrated into a single interface
- Built-in MCP server for AI assistants to manage bookmarks, memos, and system status
- Light/dark themes, i18n support, and customizable wallpapers
- Docker-ready deployment with SQLite backend and optimized caching

## Why It Matters for RAG Builders
SunDash provides a unified, customizable interface for personal data management with AI-friendly MCP integration, making it valuable for users seeking a self-hosted alternative to commercial dashboards while enabling AI-driven automation.
