## Summary
PRISM is a governance-native autonomous agent operating system that orchestrates LLM reasoning, browser automation, terminal virtualization, and multi-agent swarms with cryptographically enforced governance and tri-model cognitive orchestration. It prioritizes accountability, safety, and transparency as foundational architecture rather than bolt-on features.

## Key Features
- Cryptographically enforced governance via 10 Laws with SHA-256 integrity verification at boot and runtime
- Tri-model cognitive orchestration (Spectrum Refraction) with structured aggregation and isolation enforcement
- Full-stack computer use autonomy including browser automation, terminal virtualization, and container sandboxing
- 3-tier policy engine with approval queues, timeouts, and denial paths for high-risk operations
- Advanced model routing and AI-assisted configuration with local model auto-discovery and power-aware strategies

## Why It Matters for RAG Builders
PRISM provides a production-grade, governance-native framework for building trustworthy autonomous agents with cryptographic accountability, making it essential for RAG builders who require both power and safety without trade-offs.
