## Summary
A lightweight single-agent web research system that implements a ReAct loop for iterative tool-based research using DeepSeek V4 Flash and DuckDuckGo Search (DDGS). It enables autonomous web searches and reasoning to answer complex research questions without external frameworks or databases.

## Key Features
- Explicit ReAct loop for iterative reasoning and tool execution
- Dependency-injected model and search interfaces for testability
- Minimalist architecture with no external frameworks (e.g., LangChain)
- Structured execution trace and configurable iteration limits
- CLI-based interface for easy deployment and usage

## Why It Matters for RAG Builders
It provides a clean, framework-agnostic blueprint for building autonomous agent systems that combine reasoning and tool use, critical for advanced RAG pipelines requiring iterative web research.
