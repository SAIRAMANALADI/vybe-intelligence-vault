## Summary
MadCop is a cross-platform, local-first AI agent desktop workstation that enables private, multi-step workflows with any OpenAI-compatible LLM. It runs as a single Electron binary and keeps all data on-device, avoiding cloud lock-in while supporting tool calls, file operations, and 12 workflow modes for complex tasks.

## Key Features
- Cross-platform desktop application (macOS, Windows, Linux) with a single Electron binary
- Supports any OpenAI-compatible LLM endpoint with per-request model selection and routing
- 12 built-in workflow modes (e.g., sequential, parallel, hierarchical, swarm) for orchestrating multi-step tasks
- Model Context Protocol (MCP) bridge for integrating external tools and APIs without forking the codebase
- Persistent workspace integration with directory-aware file operations and local-first data storage

## Why It Matters for RAG Builders
MadCop provides a flexible, local-first framework for building and orchestrating AI agents with multi-step workflows, MCP tool integration, and model routing, making it essential for developers who need privacy, customization, and complex task automation without vendor lock-in.
