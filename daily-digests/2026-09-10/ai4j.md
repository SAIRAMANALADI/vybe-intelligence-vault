## Summary
ai4j is a Java AI Agentic SDK designed for JDK 8+ that provides unified LLM access, tool calling, MCP, A2A, RAG, and agent runtime capabilities. It includes built-in CLI/TUI/ACP tools for coding agents and supports multiple LLM platforms like OpenAI, Anthropic, DashScope, and Ollama.

## Key Features
- Unified LLM access across multiple platforms (OpenAI, Anthropic, DashScope, etc.)
- Built-in RAG (Retrieval-Augmented Generation) support with vector store integrations (Pinecone, Qdrant, Milvus, etc.)
- MCP (Model Context Protocol) and A2A (Agent-to-Agent) protocol support
- Tool calling and agent runtime for building autonomous AI systems
- CLI/TUI/ACP tools for coding agents and rapid prototyping

## Why It Matters for RAG Builders
ai4j provides a comprehensive Java-based framework for building AI agents with RAG capabilities, making it essential for developers integrating agentic workflows in enterprise Java environments.
