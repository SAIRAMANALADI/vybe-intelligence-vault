## Summary
A Model Context Protocol (MCP) server that integrates UniSender's email marketing API, enabling AI agents to manage mailing lists, contacts, campaigns, templates, and statistics programmatically without manual intervention in the UniSender dashboard.

## Key Features
- 10 MCP tools for UniSender API covering lists, contacts, campaigns, templates, and statistics
- Seamless integration with AI agents for automated email workflows
- Supports multiple deployment methods (Claude Desktop, Claude Code, Smithery, Streamable HTTP)
- Includes pre-built skills for common email marketing tasks like sending campaigns and fetching stats
- Lightweight and modular with TypeScript and NPM packaging

## Why It Matters for RAG Builders
It enables AI agents to programmatically manage email marketing workflows, reducing manual effort and integrating email capabilities directly into AI-driven applications.
