## Summary
A CLI and MCP server that provides AI agents and users with programmatic access to Apple Photos libraries, enabling search, metadata retrieval, organization, and export of photos and videos directly from the local macOS Photos app.

## Key Features
- 13 tools for searching, viewing, organizing, and exporting photos/videos from Apple Photos
- Dual-mode CLI and MCP server for scripting and AI agent integration
- Full metadata access including camera details, keywords, and albums
- JSON output with configurable formatting for scripting and parsing
- No backend required; runs entirely on the user's macOS device

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and retrieve accurate, locally stored photo metadata, reducing hallucinations in RAG systems by grounding responses in real user data.
