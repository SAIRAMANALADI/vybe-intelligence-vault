## Summary
A Model Context Protocol (MCP) server that provides AI coding agents with authoritative design-system context, including tokens, patterns, principles, and validation rules from a design-system Git repository.

## Key Features
- Indexes design-system repositories (tokens, patterns, principles, prompts, rules) for AI agent access via MCP
- Supports multiple design-system formats (DTCG JSON, Token Studio exports, Community Markdown, MDX)
- Provides deterministic token resolution, validation, and composition checks for generated UI
- Offers MCP resources for design-system entities (tokens, components, patterns, prompts) and validation endpoints
- Includes CLI tools for CI-friendly validation and SARIF/JSON output for automated pipelines

## Why It Matters for RAG Builders
It bridges the gap between AI-generated UI and design-system compliance by providing real-time, machine-readable design context to agents, ensuring consistency and reducing manual review overhead.
