## Summary
An enterprise-grade Retrieval-Augmented Generation (RAG) system for document search that enables natural language queries over uploaded PDFs and text files, providing conversational AI responses with source attribution and multi-model fallback resilience.

## Key Features
- Production-ready RAG pipeline with FAISS-based vector storage for high-speed semantic retrieval
- Multi-model inference resilience with automatic fallback from Google Gemini to OpenRouter models
- Source-attributed answers with transparent file/page metadata for auditability
- Conversational multi-turn chat interface optimized for natural document exploration
- Clean, premium Streamlit UI with dark-themed UX for professional usability

## Why It Matters for RAG Builders
This repository provides a robust, production-grade RAG framework with multi-model fallback and source attribution, essential for building reliable enterprise document search systems.
