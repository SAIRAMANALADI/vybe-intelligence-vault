## Summary
geo-mcp-servers is a user-friendly desktop application that provides accessible geospatial tools for non-technical users, enabling location searches, route planning, satellite imagery viewing, and integration with GIS platforms like QGIS and ArcGIS through Model Context Protocol (MCP).

## Key Features
- Simplified access to geocoding, routing, and mapping without requiring programming skills
- Integration with industry-standard GIS tools (QGIS, ArcGIS) and commercial mapping services
- Real-time satellite imagery and weather data visualization
- User-friendly interface for exploring Earth data and spatial databases
- Cross-platform desktop application with minimal setup required
