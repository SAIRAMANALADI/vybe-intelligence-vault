## Summary
A Windows-based application for private document search and chat using agentic RAG workflows. It enables users to upload documents, ask questions in natural language, and receive context-aware answers while maintaining data privacy through local processing and Docker-based isolation.

## Key Features
- Hybrid retrieval combining keyword and semantic search for accurate document matching
- Multi-user isolation ensuring private document access per user
- Document versioning and transparency showing sources for answers
- Corrective retrieval mechanism to refine search when initial results are insufficient
- Local processing with Docker-based Qdrant vector database for privacy

## Why It Matters for RAG Builders
It provides a ready-to-use, privacy-focused agentic RAG system for private document QA with advanced retrieval techniques and multi-user support.
