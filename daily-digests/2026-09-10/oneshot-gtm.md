## Summary
oneshot-gtm is an open-source GTM (Go-to-Market) agent designed for technical founders, offering a pay-per-result model with cryptographically signed receipts for every action. It combines a terminal CLI and a local web dashboard over a SQLite ledger to encode founder-led sales playbooks and PMF-aware strategies.

## Key Features
- Pay-per-result pricing with signed receipts for attestable CAC and RoCS metrics
- Terminal CLI and local web dashboard with SQLite-ledger for state management
- Pre-PMF-aware playbooks (e.g., Mom Test, Sean Ellis 40%) with soft-gate checks for scale moves
- BYO LLM key (OpenRouter/OpenAI/Anthropic) and MIT-licensed prompts for transparency
- Founder-to-founder voice discipline, low-volume defaults, and structured first-touch messaging

## Why It Matters for RAG Builders
It provides a transparent, pay-per-result GTM framework with signed receipts that enables RAG builders to audit and optimize their sales motions with verifiable outcome attribution.
