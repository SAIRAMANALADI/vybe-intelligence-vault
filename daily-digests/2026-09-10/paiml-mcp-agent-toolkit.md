## Summary
PMAT (Pragmatic Multi-language Agent Toolkit) is an MCP server and CLI tool that generates AI-ready context for codebases, performs technical debt grading, mutation testing, and repository health scoring. It integrates with AI agents via stdio or HTTP for deterministic code analysis and autonomous workflows.

## Key Features
- Zero-configuration AI context generation for any codebase with deep analysis for LLMs
- Technical debt grading (A+ to F) with 6 orthogonal metrics and repository health scoring (0-289 scale)
- Mutation testing with 85%+ kill rate and semantic search across Git history with RRF fusion
- MCP integration over stdio and HTTP with 20 tools for AI agents (Claude Code, Cline, etc.)
- Autonomous Kaizen continuous improvement with auto-fix and commit workflows

## Why It Matters for RAG Builders
PMAT provides essential tools for AI agents to analyze, grade, and improve codebases autonomously, ensuring high-quality, context-rich outputs for RAG systems and agentic workflows.
