## Summary
Aesora is a lightweight, self-hosted Python framework for building and deploying AI agents with persistent memory, multi-platform messaging gateways, and scoped tool profiles for security and flexibility.

## Key Features
- OpenAI-compatible agent loop with tool calling support
- Persistent memory isolated by platform identity (e.g., Telegram, WhatsApp, webhook)
- Multi-platform messaging gateways (Telegram, WhatsApp, HTTP webhook)
- Scoped tool profiles for security (safe, workspace, full)
- Interactive CLI and one-shot query support

## Why It Matters for RAG Builders
Aesora provides a flexible, self-hosted foundation for building secure AI agents with persistent memory and multi-platform integration, critical for RAG systems requiring user-specific context and tool access.
