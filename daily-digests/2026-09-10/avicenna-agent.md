## Summary
Avicenna is a terminal-based TUI (Text User Interface) tool designed to generate structured, long-form notes in an Obsidian vault. It operates as a deterministic pipeline for note creation, bypassing chatbot-style interactions in favor of a controlled, step-by-step process.

## Key Features
- Two-pane terminal interface for metadata and chat-based note generation
- Deterministic pipeline with PowerShell contract tokens for structured output
- Parallel section generation for efficient note assembly
- MCP (Model Context Protocol) integration for extensibility
- Headless mode for automated note generation without TUI

## Why It Matters for RAG Builders
Avicenna provides a structured, deterministic approach to generating long-form notes in Obsidian, which can be valuable for AI engineers building RAG systems that require well-organized, verifiable content pipelines.
