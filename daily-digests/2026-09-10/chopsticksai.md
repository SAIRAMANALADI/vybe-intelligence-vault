## Summary
chopsticksAI (cs.AI) is a free, open-source AI agent available as a macOS app, web interface, or terminal CLI. It provides a Chromium-based browser, Cursor-style agent window, and offline knowledge base without requiring users to provide OpenRouter or OpenAI API keys.

## Key Features
- Cross-platform availability (macOS, web, terminal CLI)
- Built-in Chromium browser for agent interactions
- Offline knowledge base for on-device AI processing
- No user-side API key requirement for OpenRouter/OpenAI
- MIT licensed for open-source use and modification
