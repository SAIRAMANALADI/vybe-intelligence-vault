## Summary
Lightning Code Index (lci) is a high-performance semantic code search tool that enables sub-millisecond searches over large codebases, reducing context by ~80% compared to traditional grep. It supports 13 programming languages via Tree-sitter parsing and provides MCP server, CLI, HTTP, and Unix-socket interfaces for AI assistants and developers.

## Key Features
- Sub-millisecond semantic code search with ~80% context reduction vs. grep
- Supports 13 languages via Tree-sitter parsing (Go, Python, JavaScript, TypeScript, Rust, C, C++, Java, C#, PHP, Kotlin, Zig, Ruby)
- Provides MCP server, CLI, HTTP, and Unix-socket interfaces for AI assistants and developers
- Includes advanced features like function call hierarchy, definition/reference lookup, and git analysis
- Optimized for performance with lock-free RCU-style reads and parser concurrency

## Why It Matters for RAG Builders
It enables AI assistants to perform fast, semantic code searches and context retrieval, drastically improving the efficiency of RAG pipelines for code-related tasks.
