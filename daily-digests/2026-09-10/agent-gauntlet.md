## Summary
A universal multi-stack verification and actionable diagnostics engine for AI-generated code, enforcing TDD, Clean Architecture, and a three-tier trust model with WASM-based policy enforcement and privilege-separated supervision.

## Key Features
- Multi-stack verification (Python, TypeScript, Rust) with linters, type checkers, unit tests, property tests, and mutation testing
- Three-tier trust model (LOCAL_UNSUPERVISED, LOCAL_SUPERVISED, CI_ATTESTED) with cryptographic attestation
- Privilege-separated local supervisor with WASM policy engine for deterministic, zero-ambient-authority verification
- Actionable diagnostics engine translating raw errors into structured, LLM-consumable remediation hints
- Deterministic FSM-driven AI agent lifecycle with role-based handoffs to prevent context rot

## Why It Matters for RAG Builders
It provides a robust, tamper-proof verification pipeline that ensures AI-generated code meets rigorous standards before deployment, reducing errors and improving reliability in production environments.
