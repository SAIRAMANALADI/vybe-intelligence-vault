## Summary
A Home Assistant integration that embeds a generative AI agent into smart home ecosystems, enabling conversational control, automation creation, camera analysis, and proactive anomaly detection using cloud or local LLMs.

## Key Features
- Conversational control over Home Assistant entities via natural language
- Automation creation from plain English descriptions with YAML generation
- Camera and image analysis with face recognition and anomaly detection
- Long-term semantic memory using pgvector for context retention
- Sentinel anomaly engine for deterministic safety and security alerts

## Why It Matters for RAG Builders
It bridges the gap between generative AI and home automation by enabling natural language control and proactive monitoring, reducing the need for manual configuration and enhancing smart home responsiveness.
