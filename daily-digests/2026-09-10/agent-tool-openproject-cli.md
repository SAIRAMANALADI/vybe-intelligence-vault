## Summary
A Python-based command-line interface for the OpenProject REST API v3, designed to be driven by AI agents or humans. It enables management of work packages, projects, time tracking, comments, and cost reporting directly from the terminal with structured JSON output.

## Key Features
- Agent-ready CLI with structured JSON output and stable exit codes for seamless integration with AI agents like Claude or Cursor
- Discoverable search with plain-language flags, presets, and `--where` expressions to avoid memorizing complex filter JSON
- Multi-format output (JSON, table, markdown) with customizable fields and secure OS keyring credential storage
- Comprehensive OpenProject API v3 coverage including work packages, time entries, cost reporting, and custom field management
- Self-documenting design with built-in guides, help commands, and compatibility across OpenProject versions 13-17

## Why It Matters for RAG Builders
It provides a standardized, agent-friendly interface to OpenProject's API, enabling AI-driven automation for project management workflows like work package tracking, time entry, and cost reporting.
