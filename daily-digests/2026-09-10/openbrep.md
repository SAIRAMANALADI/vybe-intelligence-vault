## Summary
OpenBrep is an AI-powered workbench designed for ArchiCAD power users and GDL developers, enabling AI-assisted creation, modification, debugging, and compilation of GDL scripts into .gsm library parts. It streamlines the traditionally manual GDL development workflow through natural language prompts and visual inputs.

## Key Features
- AI-driven GDL script generation from natural language or images, reducing manual coding effort
- Real-time compilation and validation of GDL scripts into .gsm library parts with ArchiCAD compatibility
- Multi-model LLM support (Claude, GLM, GPT, DeepSeek, Gemini, Ollama) for flexible AI interactions
- HSF (ArchiCAD's native format) project management with versioning, debugging, and parameter tracking
- Desktop application with Tauri for cross-platform deployment and a React-based UI with Monaco editor

## Why It Matters for RAG Builders
OpenBrep accelerates GDL development for ArchiCAD by automating script generation, validation, and compilation, making it essential for architects and developers building parametric library parts with AI assistance.
