## Summary
Kavenegar MCP is a Model Context Protocol (MCP) server that enables AI assistants to send SMS, OTP codes, and manage bulk messaging in Iran via the Kavenegar API. It abstracts gateway integration, allowing seamless communication without manual API coding.

## Key Features
- 8 pre-built tools for SMS, OTP, and bulk messaging operations
- Seamless integration with AI assistants via MCP
- Template-based message sending for OTP and bulk SMS
- Delivery status tracking and account balance monitoring
- Minimal setup with environment variable configuration

## Why It Matters for RAG Builders
It simplifies SMS and OTP delivery in Iran for AI assistants, eliminating the need for custom gateway integration and enabling rapid deployment of messaging features.
