## Summary
A Model Context Protocol (MCP) server that provides tools for interacting with the RenderForm API, enabling automated generation of images, PDFs, screenshots, and videos from templates via MCP-compatible clients.

## Key Features
- Provides MCP tools for RenderForm API operations (image/PDF generation, screenshots, etc.)
- Supports listing, creating, and deleting templates and render results
- Integrates with MCP clients like Claude Desktop, Cursor, and VS Code
- Includes debugging tools (MCP Inspector) for development
- Offers organization usage tracking (credits, uploads, plan)

## Why It Matters for RAG Builders
It enables seamless integration of RenderForm's image and PDF generation capabilities into AI workflows via MCP, simplifying automation for RAG builders.
