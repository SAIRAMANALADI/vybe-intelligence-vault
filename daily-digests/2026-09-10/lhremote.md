## Summary
lhremote is a CLI and MCP server that enables AI assistants to automate LinkedHelper, a LinkedIn outreach tool. It provides programmatic control over LinkedIn campaigns, profile management, messaging, and engagement actions via the Model Context Protocol (MCP).

## Key Features
- MCP server integration for AI assistants (e.g., Claude) to control LinkedHelper programmatically
- Comprehensive LinkedIn outreach automation including campaigns, messaging, and profile engagement
- CLI and MCP tool parity for direct or AI-driven control of LinkedHelper features
- Real-time monitoring of campaigns, budgets, and LinkedIn throttling status
- Profile enrichment, search, and feed intelligence capabilities

## Why It Matters for RAG Builders
It bridges AI assistants with LinkedIn automation tools, enabling seamless integration of outreach workflows into AI-driven pipelines for sales, marketing, and networking tasks.
