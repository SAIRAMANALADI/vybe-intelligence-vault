## Summary
A specialized MCP server and skill set that transforms AI agents into Power BI analytics experts, enabling direct interaction with Power BI Desktop and Service. It provides end-to-end pipelines for data analysis, report generation, and KPIM (Key Performance Indicator Management) processes with built-in data safety policies and template-based report creation.

## Key Features
- 11 specialized tools for Power BI interaction (query, model manipulation, template application, and schema distillation)
- Built-in data safety policies (aggregate-only queries, PII blocklist, audit logging, and dimension limits) to prevent raw data exposure
- End-to-end KPIM analysis process with standardized documentation templates (PROJECT.md, DATA_DICTIONARY.md, METRICS_CALCULATION.md, etc.)
- Template-based report generation with reusable visual kits and blueprints for consistent, professional layouts
- Integration with Microsoft's official Power BI Modeling MCP for complementary modeling tasks

## Why It Matters for RAG Builders
It enables AI agents to autonomously perform Power BI analytics, report generation, and KPIM processes while enforcing data safety and standardization, bridging the gap between natural language queries and enterprise-grade BI workflows.
