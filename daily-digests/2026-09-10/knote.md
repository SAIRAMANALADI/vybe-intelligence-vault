## Summary
Knote is a local-first, cross-platform Markdown editor with a modern block-based WYSIWYG interface and an integrated AI agent that assists with document editing, restructuring, and multi-file workspace management. Users can review and approve AI-generated changes via diff-based workflows.

## Key Features
- Real-time WYSIWYG Markdown editing with block-based interface (Feishu/Notion-style)
- Built-in AI agent for document editing, restructuring, and multi-file workspace management with diff-based review
- Supports PDF/image ingestion, web search, and structured document analysis (desktop version)
- Cross-platform deployment (Windows, Android, web) with bilingual UI (Chinese/English)
- Version history, full-text search, and export to PDF/Word/HTML/Markdown

## Why It Matters for RAG Builders
Knote provides a seamless, local-first environment for AI-assisted document editing and knowledge management, bridging the gap between raw Markdown workflows and intelligent agent collaboration.
