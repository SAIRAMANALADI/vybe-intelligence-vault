## Summary
Rust client library for Dakera AI, a self-hosted memory engine designed for AI agents. It provides Rust-native APIs for storing, recalling, and managing agent memories with advanced search capabilities like vector, BM25, hybrid, and knowledge graph searches.

## Key Features
- Agent memory management with importance scoring and sessions
- Multi-modal search (vector, BM25, hybrid, knowledge graph)
- Built-in text embedding generation (no external API required)
- Dual transport support (HTTP and gRPC) with connection pooling
- T-I-F reliability scoring and entity extraction for memory quality

## Why It Matters for RAG Builders
It provides a high-performance, self-hosted memory engine with advanced search capabilities essential for building reliable and scalable RAG systems with agent memory integration.
