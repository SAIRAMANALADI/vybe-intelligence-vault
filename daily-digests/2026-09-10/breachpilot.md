## Summary
BreachPilot is an autonomous offensive security agent designed for red team operations, covering the full assessment lifecycle from reconnaissance to exploitation, verification, and reporting. It leverages the Model Context Protocol (MCP), Ollama Cloud, and 140+ advisory skills to plan, execute, and audit security assessments under operator supervision.

## Key Features
- Full-cycle autonomous security assessment with adversarial planning and multi-agent orchestration (6 specialist agents)
- Domain-aware reconnaissance with dynamic attack surface expansion and threat intelligence integration
- Target-locked safety model with allowlist enforcement, scope gating, and tamper-evident audit chains
- 140+ advisory skills and 120+ MCP tools covering 15 attack families (e.g., AD, JWT, SSTI, ICS/IoT)
- Evidence-based verification with hypothesis-driven verdicts and MITRE ATT&CK Navigator export for SOC handoff

## Why It Matters for RAG Builders
BreachPilot provides a comprehensive, autonomous framework for red team operations that integrates planning, execution, and verification with robust safety controls, making it essential for AI-driven security testing and adversarial simulation.
