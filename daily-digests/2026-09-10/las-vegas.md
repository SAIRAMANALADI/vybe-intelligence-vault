## Summary
A real-time jackpot game built on Unicity Sphere where humans and autonomous agents compete in recurring rounds using peer-to-peer payments on the Sphere testnet. The system features autonomous agent settlement, commit-reveal fairness, and a machine-readable entry card for agent participation.

## Key Features
- Real peer-to-peer settlement using Unicity Sphere testnet2 with no central fund holding
- Autonomous agent settlement via Cloudflare Worker cron for round locking, winner selection, and payouts
- Commit-reveal fairness mechanism using SHA-256 seed for deterministic winner selection
- Machine-readable agent entry card for programmatic agent participation in rounds
- Hybrid human and agent competition with identical entry and payout flows

## Why It Matters for RAG Builders
Demonstrates real-world autonomous agent settlement and peer-to-peer commerce on a blockchain network, providing a blueprint for agentic systems in decentralized applications.
