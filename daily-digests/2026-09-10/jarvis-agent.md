## Summary
Jarvis is a stateful, proactive personal AI assistant that operates as a background service, communicating over Telegram and executing real-world actions. It features a sandboxed architecture with deterministic behavior, scoped tool activation, and a heartbeat loop for autonomous task execution.

## Key Features
- Proactive heartbeat loop for autonomous task execution and notifications
- Sandboxed tool registry with scoped skill activation to limit blast radius
- Channel-decoupled gateway (e.g., Telegram) for modular communication
- File-based, hot-reloadable memory system with sandboxed access
- Deterministic runtime with bounded state and structured observability
