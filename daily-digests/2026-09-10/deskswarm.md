## Summary
deskswarm is a self-hosted fleet management system that orchestrates multiple AI-controlled Linux desktop environments (XFCE sessions) in Docker containers. It provides a unified dashboard to dispatch natural-language tasks to individual desktops or entire fleets, monitor progress in real-time, and analyze performance metrics.

## Key Features
- Real XFCE desktop sessions in Docker containers, not headless browsers
- Unified dashboard for task dispatch, monitoring, and analytics across multiple desktops
- Dynamic fleet scaling via UI (add/remove machines without editing compose files)
- Live progress tracking with per-step agent actions (screenshot, clicks, typing)
- Software inventory, terminal access, and snapshot provisioning for consistent environments

## Why It Matters for RAG Builders
deskswarm enables scalable, self-hosted AI agent orchestration across real desktop environments, bridging the gap between abstract AI tasks and practical, multi-machine automation with real-time visibility.
