## Summary
HART OS is an AI-native operating system that enables local model inference, peer-to-peer federation, and OpenAI-compatible APIs. It runs on user hardware with no cloud dependency, supports hardware-aware model selection, and allows nodes to federate directly for collaborative intelligence.

## Key Features
- Hardware-aware model selection and VRAM management for optimal performance
- Peer-to-peer federation with no central broker (PeerLink)
- OpenAI-compatible API for seamless integration with existing tools
- Democratized intelligence via federated learning and peer collaboration
- AI-native features including vision-based desktop interaction and copilot integration

## Why It Matters for RAG Builders
HART OS enables truly decentralized, hardware-agnostic AI inference and collaboration, reducing dependency on cloud services while fostering community-driven intelligence aggregation.
