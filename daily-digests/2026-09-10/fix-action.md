## Summary
A GitHub Action that scans a repository for AI-readiness issues, applies minimal fixes, and opens a pull request with the changes. It runs an AI agent locally within the GitHub runner, ensuring source code is never stored externally.

## Key Features
- Scans repositories for AI-readiness issues (e.g., robots.txt, metadata, alt text)
- Applies minimal, low-risk fixes directly in the repository
- Opens a pull request with a detailed AI fix plan and changes
- Runs securely within the GitHub runner with sandboxed file access
- Supports dry-run mode for previewing changes without opening a PR

## Why It Matters for RAG Builders
It automates the process of making repositories AI-ready by fixing common issues and opening PRs, reducing manual effort for developers and improving discoverability for AI systems.
