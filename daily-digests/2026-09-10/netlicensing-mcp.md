## Summary
NetLicensing-MCP is an official Model Context Protocol (MCP) server that enables AI agents to manage software licenses, customers, and entitlements through natural language commands. It provides a conversational interface to interact with Labs64 NetLicensing's REST API without requiring direct API calls or UI interactions.

## Key Features
- Natural language interface for managing licenses, customers, and products via conversational commands
- Full coverage of NetLicensing REST API tools (products, licenses, licensees, tokens, transactions, etc.)
- Built-in audit prompts for account audits, expiry sweeps, anomaly detection, and cleanup workflows
- Security-first design with redaction of sensitive fields, two-step delete confirmations, and demo mode warnings
- Zero-dependency quick start via uvx, pip, or Docker with support for stdio and HTTP transport modes

## Why It Matters for RAG Builders
It enables AI agents to autonomously manage software licensing lifecycles, reducing manual API interactions and streamlining entitlement workflows for RAG and AI stack builders.
