## Summary
Deskwright enables AI agents to interact with a real GNOME Wayland desktop by providing an MCP server and shell extension. It allows agents to launch apps, read widgets, click buttons, type text, and manage windows without screen recording or pixel-based guessing.

## Key Features
- Provides a real GNOME Wayland desktop for AI agents to interact with, avoiding pixel-based guessing
- Supports launching apps, reading widgets, clicking buttons, typing text, and managing windows via AT-SPI
- Offers a headless mode to run agents on a virtual monitor without disrupting the user's workflow
- Includes 33 tools for comprehensive desktop interaction, including OCR, screen recording, and clipboard access
- Integrates with MCP clients like Claude Code, Cursor, and Codex for seamless agent-driven desktop automation

## Why It Matters for RAG Builders
Deskwright bridges the gap for AI agents on Linux by enabling real desktop interaction on Wayland, which is otherwise restricted by security policies.
