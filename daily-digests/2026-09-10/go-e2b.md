## Summary
A Go SDK for interacting with E2B's cloud sandbox API, enabling secure execution of arbitrary code in lightweight microVMs. It provides programmatic control over sandbox lifecycle, filesystem operations, command execution, and networking policies.

## Key Features
- Secure, isolated microVM sandboxes for arbitrary code execution
- Comprehensive filesystem operations (read/write, directory management, watches)
- Command execution with streaming output, stdin/stdout/stderr handling, and process management
- Sandbox lifecycle control (pause/resume, snapshots, forking, timeouts)
- Network policy configuration (allow/deny outbound traffic)

## Why It Matters for RAG Builders
It enables AI/RAG builders to safely execute untrusted code in isolated environments for dynamic data processing, tool integration, or sandboxed execution of custom logic.
