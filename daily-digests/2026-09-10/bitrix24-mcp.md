## Summary
A Model Context Protocol (MCP) server that integrates Bitrix24 CRM, tasks, and contacts with AI assistants via webhooks, enabling natural language interactions without OAuth or custom programming.

## Key Features
- 12 pre-built tools for CRM deals, contacts, tasks, users, files, and messages
- Zero-code setup via Bitrix24 inbound webhooks
- Natural language interactions for CRM and task operations
- Supports filtering, sorting, and CRUD operations for Bitrix24 entities
- Part of the WWmcp ecosystem for AI assistant integrations
