## Summary
An MCP server for Google Tasks that enables AI agents to interact with Google Tasks via the official API, allowing read, create, edit, complete, reorder, and delete operations. It integrates seamlessly with any MCP-compatible client like Claude Code or Desktop.

## Key Features
- Full CRUD operations for Google Tasks via MCP-compatible clients
- Supports OAuth 2.0 authentication with Google Cloud project setup
- Read-only mode available via environment variable
- Handles pagination, due date constraints, and task series protection
- Works with any MCP client (e.g., Claude Code, Claude Desktop)

## Why It Matters for RAG Builders
It enables AI agents to directly interact with Google Tasks, expanding automation and task management capabilities for RAG builders.
