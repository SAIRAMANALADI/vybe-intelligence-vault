## Summary
AI Resume Agent transforms static resumes into interactive AI-powered conversational agents, enabling recruiters to query candidate experience in real-time using natural language. The system combines semantic search, hybrid retrieval (BM25 + vector + cross-encoder re-ranking), and LLM orchestration to deliver evidence-based, citation-backed responses.

## Key Features
- Hybrid search with BM25, vector embeddings, and cross-encoder re-ranking for high-precision retrieval
- Real-time conversational AI agent with citation-backed, hallucination-resistant responses
- Job fit assessment via AI-powered analysis of resume against job descriptions
- Portable .mv2 vector database format for single-file resume deployment
- MCP-compatible server for programmatic integration with AI tools like Claude Desktop

## Why It Matters for RAG Builders
It provides a production-grade reference implementation for building AI agents that interact with personal or organizational knowledge bases, demonstrating advanced RAG techniques and hybrid retrieval architectures.
