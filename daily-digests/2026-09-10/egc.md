## Summary
EGC is a local runtime that provides persistent, auto-intuitive memory and security enforcement for AI coding agents across 20+ tools like Claude Code, Cursor, and Gemini CLI. It enables seamless continuation of work sessions without manual state management or prompting.

## Key Features
- Persistent project-specific memory that auto-loads across sessions without manual input
- EGC Guardian for real-time command validation and file write protection
- Token Crusher to compress shell output by up to 90% before reaching the model
- Global memory sharing across projects and cooperative session management for parallel workflows
- Multi-language support with 63 agents, 230 skills, and 77 commands for specialized AI tasks

## Why It Matters for RAG Builders
EGC eliminates the need for manual session state management in AI-driven development workflows, ensuring continuity and security while reducing token costs and cognitive overhead for developers.
