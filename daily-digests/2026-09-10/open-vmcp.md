## Summary
A lightweight virtual MCP gateway that acts as a single endpoint for multiple MCP servers, providing per-server and per-tool policy enforcement, telemetry logging to Postgres, and a Carbon React dashboard for monitoring and management. Designed as a reference implementation for readability and simplicity.

## Key Features
- Single endpoint aggregating multiple MCP servers with per-server routing
- Per-tool policy enforcement and audit logging to Postgres
- Carbon React dashboard for real-time usage monitoring and server management
- Mock identity and RBAC seam for easy extension to production-grade auth
- Supports SSE and Streamable HTTP transports with transparent adapter logic

## Why It Matters for RAG Builders
It provides a minimal, readable reference implementation for building MCP gateways with telemetry and policy controls, essential for RAG builders integrating multiple MCP servers.
