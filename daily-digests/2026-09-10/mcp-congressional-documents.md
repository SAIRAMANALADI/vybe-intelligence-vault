## Summary
A Model Context Protocol (MCP) server providing full-text search and retrieval over official U.S. Congressional documents, including hearing transcripts, committee reports, and the Congressional Record. It simplifies access to complex government data sources for AI applications.

## Key Features
- Full-text search across hearings, committee reports, and the Congressional Record
- Retrieval of document text with citations and official URLs for grounding
- Support for pagination via offset/next_offset for large documents
- Integration with MCP clients (Claude Desktop, Cursor, Windsurf, etc.)
- Free access via data.gov API key or BYO authentication

## Why It Matters for RAG Builders
It provides structured, citable access to a voluminous and often paraphrased corpus that models frequently hallucinate about, enabling accurate RAG applications with proper grounding.
