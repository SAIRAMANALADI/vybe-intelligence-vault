## Summary
Efecto is a real-time visual design tool that enables AI agents to collaborate with humans on design tasks using MCP tools and design skills. It integrates with popular AI coding environments to provide programmatic control over design elements like layouts, animations, and exports.

## Key Features
- 68 MCP tools for programmatic design control (artboards, layouts, animations, exports)
- 3 AI design skills (Web Design, Social Media, Graphic Design) to teach agents design principles
- Real-time collaboration between AI agents and humans via live design sessions
- Integration with Claude Code, Cursor, Windsurf, Copilot, and other MCP-compatible agents
- Supports JSX + Tailwind CSS for dynamic layout creation

## Why It Matters for RAG Builders
Efecto bridges the gap between AI agents and human designers by providing structured tools and skills for automated, high-quality visual design generation.
