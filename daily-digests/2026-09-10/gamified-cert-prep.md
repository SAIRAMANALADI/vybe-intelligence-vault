## Summary
A VS Code extension that transforms certification exam preparation into a gamified, day-by-day study campaign using AI agents. It automates personalized study planning, teaching, quizzing, and progress tracking, committing all data to a user's Git repository for persistence and version control.

## Key Features
- Personalized exam study plans with domain-weighted daily sessions
- Gamified learning with XP, streaks, levels, badges, and battle passes
- Automated progress tracking and Git repository synchronization
- AI-driven teaching and quiz generation with source citations
- Vendor-agnostic support for any certification exam

## Why It Matters for RAG Builders
It provides a structured, AI-enhanced approach to certification exam preparation with built-in gamification and Git-backed persistence, making it valuable for developers seeking efficient and engaging study methods.
