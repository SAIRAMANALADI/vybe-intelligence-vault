## Summary
Plonk is a macOS window manager designed to be controlled by AI agents via an MCP server. It enables precise window placement, workspace management, and automation through natural language commands or programmatic APIs.

## Key Features
- Precise window placement using zones and workspaces
- AI agent integration via MCP server for programmatic control
- Natural language commands for window and workspace management
- Keep-awake and screenshot capabilities with annotations
- Zero dependencies, no cloud, and no telemetry

## Why It Matters for RAG Builders
Plonk enables AI agents to programmatically control macOS window layouts, making it essential for automating desktop environments in RAG and AI workflows.
