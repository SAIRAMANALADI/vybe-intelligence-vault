## Summary
ainpc-cli provides a command-line interface and MCP server for creating, managing, and interacting with AI-powered NPCs that feature persistent memory, dynamic personalities, and real-time game event integration. It enables coding agents to programmatically control NPCs via 49 MCP tools.

## Key Features
- 49 MCP tools for AI agents to manage NPCs end-to-end
- Persistent memory for NPCs across sessions (names, debts, grudges)
- Dynamic personality generation with traits, moods, and daily schedules
- CLI and MCP server for both local and remote agent integration
- TTS support for NPC voice generation

## Why It Matters for RAG Builders
It enables AI agents to create and manage lifelike NPCs with persistent memory and dynamic personalities, essential for immersive game environments and interactive storytelling.
