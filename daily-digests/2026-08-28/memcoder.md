## Summary
MemCoder is a provider-independent cognition layer for AI agents that transforms verified work into precise, reusable guidance by enforcing evidence-based memory retention. It acts as a trust layer, ensuring only validated outcomes influence future tasks while remaining host-agnostic and local-first.

## Key Features
- Provider-independent core requiring no hosted LLM or API keys
- Evidence-gated memory retention with multi-dimensional validation (relevance, confidence, ownership, validity, environment, provenance)
- Cognitive intervention modes (none, risk, brief, plan) for proportional guidance
- Skill and plan lifecycle with health tracking and bounded execution
- Cross-adapter compatibility (AGY CLI, Python API, MCP, Codex Desktop plugin)

## Why It Matters for RAG Builders
MemCoder ensures AI agents only retain and reuse verified, high-confidence work, reducing hallucinations and improving task consistency in RAG and agentic systems.
