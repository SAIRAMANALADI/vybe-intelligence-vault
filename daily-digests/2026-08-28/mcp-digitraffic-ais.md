## Summary
This repository provides a Model Context Protocol (MCP) server for accessing live vessel positions in Finnish and Baltic waters via Fintraffic's AIS receivers. It offers keyless access to vessel data with tools for querying vessels by location, counting vessels by type, and retrieving vessel details by MMSI.

## Key Features
- Keyless access to live vessel positions in Finnish and Baltic waters
- Tools for querying vessels by radius, area, or MMSI
- Integration with MCP clients (Claude Desktop, Cursor, Windsurf, etc.)
- Supports plain English queries via ask_pipeworx
- Handles gzip-compressed responses for efficiency
