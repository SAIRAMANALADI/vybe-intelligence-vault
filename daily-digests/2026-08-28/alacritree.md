## Summary
Alacritree is a native terminal emulator built on Alacritty that transforms Git worktrees into first-class workspaces, offering ultrafast worktree management, real-time Git status tracking, and MCP-driven agent integration for AI workflows.

## Key Features
- Ultrafast worktree management with one-click shell spawning and AI-config pre-configuration
- Real-time Git status bar with branch and file changes, refreshed in the background
- Built-in MCP server for LLM agent control over workspaces, sessions, and terminal input/output
- Minimalist, Chromium-free terminal with configurable Markdown scratchpads and Delta-powered diffs
- Cross-platform support (Linux, macOS, Windows) with prebuilt binaries and source builds

## Why It Matters for RAG Builders
Alacritree streamlines Git worktree workflows for AI engineers by integrating terminal-based worktree management with MCP-driven agent control, reducing context switching and enabling automated workflows.
