## Summary
A privacy-focused outbound AI voice agent that places real phone calls without revealing the user's identity. It integrates telephony (Vobiz), realtime media (LiveKit Cloud), speech-to-text (Sarvam AI), and reasoning (Grok via OpenRouter) to enable anonymous automated calls with live monitoring and transcripts.

## Key Features
- Anonymous identity masking with configurable public aliases to protect user privacy
- Real PSTN/mobile outbound calls via Vobiz SIP trunk integrated with LiveKit Cloud
- Multilingual voice support with Sarvam AI (Telugu default, English and other Indian languages)
- Live call monitoring dashboard with real-time transcripts and status updates
- Noise-resistant barge-in and auto-hangup features for natural conversation flow

## Why It Matters for RAG Builders
It enables privacy-preserving automated voice interactions for RAG systems by integrating real-time telephony with AI agents while masking user identities.
