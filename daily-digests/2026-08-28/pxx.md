## Summary
pxx is a local-first, async runtime for AI coding agents that operates against self-hosted inference endpoints (Ollama, vLLM, or OpenAI-compatible) without cloud dependencies. It provides a fail-closed safety model, persistent cross-session memory, and MCP interoperability for secure, offline-capable agent workflows.

## Key Features
- Async, event-sourced agent runtime with deterministic safety gates
- Persistent cross-session memory with hybrid BM25 + vector search
- Fail-closed permission model (read-only by default, scoped edits)
- MCP server interoperability for tool integration and memory exposure
- Self-improvement platform with evaluation, calibration, and proposal cycles

## Why It Matters for RAG Builders
pxx enables secure, offline-capable AI coding agents with strict safety controls and persistent memory, making it essential for building reliable, self-hosted RAG and agentic systems.
