## Summary
kis-agent is a Python wrapper for the Korea Investment & Securities (한국투자증권) OpenAPI, providing CLI tools, SDK, and LLM agent integration for real-time stock, futures, and overseas market data. It simplifies API interactions with intelligent caching, type safety, and WebSocket streaming.

## Key Features
- CLI tool for instant stock/futures/overseas market queries with JSON output optimized for LLM parsing
- LLM agent integration via schema introspection and structured JSON responses
- Intelligent caching reducing API calls by 80-95% with 18 RPS rate limiting
- Real-time WebSocket streaming for live market data across KOSPI, KOSDAQ, and 9 international exchanges
- Comprehensive support for domestic/overseas stocks, futures, and options with 96 typed response models

## Why It Matters for RAG Builders
kis-agent simplifies access to Korean financial markets for AI agents by providing a robust, type-safe SDK and CLI tools optimized for LLM integration and real-time data retrieval.
