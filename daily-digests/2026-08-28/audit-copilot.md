## Summary
AI-powered audit copilot for smart contracts that automates vulnerability assessment by orchestrating static detectors, RAG-based knowledge enrichment, and LLM synthesis to generate evidence-backed reports with measurable quality and provenance tracking.

## Key Features
- Hexagonal architecture with interchangeable adapters for static analyzers, vector stores, and LLM providers
- RAG pipeline with hybrid search (dense + BM25, RRF), class filtering, and re-ranking for knowledge enrichment
- Agent orchestrates detectors, RAG, and LLM synthesis to generate reports with severity, explanations, fixes, and citations
- Measurable quality metrics: detector recall, structural faithfulness, cross-model grounding, and cost tracking
- Provenance tracking ensures every finding is traceable to a detector and source, eliminating hallucinations

## Why It Matters for RAG Builders
It provides a robust, measurable framework for automating AI-driven audits with provable quality, reducing manual effort while ensuring traceability and reliability for RAG/AI stack builders.
