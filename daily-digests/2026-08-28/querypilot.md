## Summary
QueryPilot is a Python library and CLI tool designed to ensure the reliability of SQL queries generated by AI agents. It validates, repairs, executes, and regression-tests SQL against real databases, providing measurable correctness, safety, and performance metrics for AI-driven database interactions.

## Key Features
- SQL validation and safety checks (SELECT-only, blocked keywords, Cartesian join detection)
- Automated SQL repair and execution with configurable retry logic
- Regression testing harness with YAML/JSON suite definitions and baseline comparisons
- Audit logging and access control policies (column masking, row filtering)
- Integration with LLM APIs (OpenAI, Anthropic) and MCP servers for agent tool use

## Why It Matters for RAG Builders
QueryPilot ensures AI agents generate reliable, safe, and performant SQL queries by validating, repairing, and regression-testing them against real databases, reducing production failures and improving trust in AI-driven database interactions.
