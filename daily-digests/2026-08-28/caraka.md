## Summary
Caraka is a lightweight transport layer that bridges Telegram chats to coding agents via the Agent Client Protocol (ACP), enabling secure task delegation without reinventing agent capabilities or tooling.

## Key Features
- Secure bridge between Telegram and coding agents using ACP for standardized communication
- Mandatory approval workflows with signed, single-use callbacks to prevent unauthorized actions
- Session management via Telegram topics (tabs) for organized task tracking
- Strict security controls: private chats, allowlists, no open ports, and secret scrubbing
- Audit trail with immutable SQLite storage for compliance and debugging

## Why It Matters for RAG Builders
Caraka enables secure, context-aware task delegation from chat to coding agents without exposing sensitive operations to untrusted environments.
