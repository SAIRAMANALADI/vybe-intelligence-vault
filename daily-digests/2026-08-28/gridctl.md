## Summary
Gridctl is an MCP gateway that aggregates and manages Model Context Protocol (MCP) servers and Agent Skills into a single, declarative YAML configuration. It simplifies the deployment and orchestration of MCP servers, providing a unified endpoint for LLM clients like Claude Desktop.

## Key Features
- Declarative stack management via YAML for MCP servers and skills
- Unified endpoint for LLM clients (Claude, Cursor, VS Code, etc.)
- Built-in skill library with markdown-based prompt authoring
- Cost observability and optimization for MCP tool usage
- Visualization UI for monitoring and managing MCP servers

## Why It Matters for RAG Builders
Gridctl streamlines the integration of diverse MCP servers and skills into a single, manageable endpoint, reducing complexity and improving efficiency for RAG and AI stack builders.
