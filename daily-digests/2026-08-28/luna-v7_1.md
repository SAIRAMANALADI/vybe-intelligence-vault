## Summary
L.U.N.A is an open-source, self-hosted personal AI system designed for a single user, featuring persistent memory, autonomous behavior, voice interaction, and a suite of tools for device and service integration. It operates entirely on private hardware with optional external access via Telegram.

## Key Features
- Persistent memory with three-tier consolidation (working, episodic, semantic) using pgvector and Neo4j for knowledge graph storage
- Autonomous inner life with scheduled wakes, daybook diary, and intention tracking via the medulla daemon
- 199+ integrated tools for web search, email, calendar, image generation, device control, and code workspace management
- Real-time voice interaction with speech-to-text and text-to-speech capabilities
- Modular monorepo design with independently deployable components (luna-chat, memorycore, luna-news-engine, medulla)

## Why It Matters for RAG Builders
L.U.N.A provides a comprehensive, self-hosted framework for building personal AI agents with advanced memory systems and autonomous behavior, critical for developers seeking to create deeply contextual and persistent AI companions.
