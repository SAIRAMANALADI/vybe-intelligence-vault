## Summary
An MCP server providing data-driven tools for engineering leadership, including salary calculators, readiness assessments, benchmarks, and playbooks derived from 3,400+ mentoring sessions with 300+ engineering leaders worldwide.

## Key Features
- Developer and engineering manager salary calculators based on real-world mentoring data
- Team lead readiness assessment with actionable gap analysis
- Engineering leadership benchmarks (sprint completion, roadmap %, manager time per report)
- 1:1 session playbooks for new managers and career transitions
- Mentor/coach/advisor decision tool with role-specific guidance
