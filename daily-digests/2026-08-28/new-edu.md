## Summary
A full-stack online education platform leveraging Spring Boot 3, Vue 3, FastAPI, and LangChain. It integrates video progress tracking, large-file chunked uploads, RAG-based Q&A, AI course recommendations, and idempotent payments with automatic order cancellation.

## Key Features
- Video progress tracking with Redis and RabbitMQ for real-time updates and delayed persistence
- Large-file chunked uploads with OSS multipart API, resumable transfers, and concurrency control
- RAG-based knowledge base with ChromaDB for PDF document ingestion and contextual Q&A
- Idempotent order creation and payments with Redis Lua tokens, SQL CAS, and unique DB constraints
- Automated 30-minute order cancellation via RabbitMQ TTL+DLX and scheduled fallback

## Why It Matters for RAG Builders
It provides a production-grade reference architecture for integrating RAG, AI agents, and real-time processing in a scalable, multi-language system, critical for building robust AI-driven platforms.
