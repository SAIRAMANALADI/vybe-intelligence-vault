## Summary
The Leapd MCP server enables AI agents to build and run businesses autonomously by integrating with the Model Context Protocol (MCP). It connects AI clients like Claude Code or Codex to a Leapd account, allowing agents to launch businesses, deploy landing pages, manage tasks, and execute marketing campaigns directly from an editor.

## Key Features
- Enables AI agents to launch and manage businesses autonomously via MCP clients
- Provides tools for business positioning, landing page deployment, and task management
- Supports real-time task execution and reporting with a morning brief
- Integrates with Stripe for payments and marketing campaigns
- Offers document management for business artifacts like positioning and ICP
