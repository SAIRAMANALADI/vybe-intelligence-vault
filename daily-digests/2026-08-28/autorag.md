## Summary
AutoRAG is a self-evolving librarian agent that transforms raw document collections into curated, actionable knowledge units. It replaces traditional search tools with an intelligent system that reads, synthesizes, and reports back structured answers, improving over time through user feedback and usage patterns.

## Key Features
- Self-evolving memory system that improves retrieval strategies over time based on user feedback and usage patterns
- Pluggable retrieval methods (BM25, vector search, hybrid) with a unified interface for diverse document types
- Support for 10+ external datasources (Slack, Notion, GitHub, Gmail, etc.) with strict security defaults
- Optional Jikji integration for fast local discovery and indexing of documents
- Structured, curated answers with numbered knowledge units instead of raw search results

## Why It Matters for RAG Builders
AutoRAG automates the tedious process of document search and synthesis, enabling RAG systems to deliver precise, context-rich answers while continuously improving their retrieval strategies based on real-world usage.
