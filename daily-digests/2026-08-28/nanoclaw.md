## Summary
nanoclaw is a lightweight Discord AI agent designed to run on a RISC-V LicheeRV Nano board, offering ambient group presence, tool-calling agent loops, image/video generation, web research, and GitHub integration in a single static Go binary.

## Key Features
- Ambient group presence with local willingness scoring (zero API cost for skipped messages)
- DeepSeek tool-calling agent loop with self-review passes for iterative refinement
- Image/video generation via xAI Grok with reference-image editing and async rendering
- GitHub API integration for repo creation, PRs, and code deployment without shell access
- Per-channel conversation history and long-term memory stored on microSD for persistence

## Why It Matters for RAG Builders
It provides a compact, embedded AI agent framework with tool-calling, ambient presence, and multi-modal capabilities, ideal for building lightweight, persistent AI assistants in constrained environments.
