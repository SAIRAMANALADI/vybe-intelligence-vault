## Summary
Klaus is a headless, self-hosted personal AI agent that integrates with WhatsApp and Obsidian to act as a conversational assistant. It reads/writes your Obsidian vault, processes voice notes, images, and documents, and can automate tasks like scheduling reminders or generating reports, all while being extensible via Markdown files.

## Key Features
- Headless WhatsApp-based interaction with no app or dashboard required
- Direct Obsidian vault access for reading/writing notes and managing knowledge
- Extensible via editable Markdown files (agents, snippets, skills) with hot-reload
- Built-in tools for voice transcription, image processing, web search, and scheduling
- Deterministic commands and overrides for fine-grained control over agent behavior

## Why It Matters for RAG Builders
Klaus provides a flexible, self-hosted framework for building personalized AI agents that deeply integrate with your knowledge base and communication tools, enabling seamless automation and extension without vendor lock-in.
