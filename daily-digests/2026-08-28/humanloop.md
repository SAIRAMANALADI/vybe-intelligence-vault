## Summary
Humanloop was an LLM development platform designed for managing prompts, datasets, evaluations, and production observability of LLM applications. It provided collaborative tools for prompt engineering, version control, and multi-provider LLM integration, now archived following its acquisition by Anthropic in 2025.

## Key Features
- Collaborative prompt editor with version control
- Multi-provider LLM integration (OpenAI, Anthropic, Google)
- LLM-as-judge and code-based evaluations
- Full request logging and production observability
- Python and TypeScript SDKs with REST API

## Why It Matters for RAG Builders
It provided a centralized platform for managing and evaluating LLM applications, critical for teams building RAG systems with robust prompt engineering and observability.
