## Summary
A Model Context Protocol (MCP) server that enables AI assistants to fetch real-time financial data from Yahoo Finance using the yfinance library. It provides tools for querying stock information, financial news, analyst data, and generating professional financial charts.

## Key Features
- Comprehensive stock data retrieval including financials, valuation metrics, and trading info
- Analyst consensus data including price targets, estimates, upgrades/downgrades, and recommendations
- Financial news aggregation and sector rankings for market analysis
- Professional chart generation (candlestick, VWAP, volume profile) as WebP images
- Screening tools for stocks, ETFs, and mutual funds with customizable queries

## Why It Matters for RAG Builders
It provides AI assistants with direct access to real-time financial data and professional-grade charting capabilities, essential for building RAG systems that require up-to-date market insights and financial analysis.
