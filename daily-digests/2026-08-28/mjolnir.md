## Summary
Mjolnir is a native Rust terminal client for Agent Client Protocol (ACP) coding agents, enabling multi-agent collaboration with a primary agent and up to 16 parallel subagents. It routes models through locally available ACP adapters, manages sessions, and integrates tooling for efficient code review and execution.

## Key Features
- Primary agent with delegated subagents (up to 16 parallel)
- Stable workflow progress tracking and nested detail views
- Model-first routing with local ACP adapters
- Headless automation and isolated worktree support
- Real-time streaming agent output and tool activity

## Why It Matters for RAG Builders
Mjolnir enables scalable, multi-agent collaboration for RAG pipelines by providing a robust terminal client that orchestrates primary and subagents with model routing and session management.
