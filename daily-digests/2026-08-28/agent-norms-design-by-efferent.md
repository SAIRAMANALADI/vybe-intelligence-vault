## Summary
A human-in-the-loop design methodology for AI-driven development that adapts Test-Driven Development (TDD) with an 'efferent-first' approach, where AI generates code and humans deliberate on critical design decisions. It introduces a structured 'hinge cycle' to guide iterative design and documentation of software features.

## Key Features
- Efferent-first design method prioritizing interface definition before implementation
- Five-step 'hinge cycle' for iterative design decisions (actuation → observation → controls → implementation → naming)
- Automated recording of design dialogues in `loops/` artifact directory
- Human deliberation gates at critical 'load-bearing' decisions (hinges)
- Integration via Git subtree for seamless project inclusion and updates
