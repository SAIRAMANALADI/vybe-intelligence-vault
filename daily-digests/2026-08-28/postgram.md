## Summary
Postgram is a self-hosted productivity and knowledge backend designed for both humans and AI agents. It provides a unified, inspectable corpus for storing and managing notes, documents, tasks, people, projects, interactions, decisions, and agent memory with hybrid search and knowledge graph capabilities.

## Key Features
- Durable storage for typed entities (memory, person, project, task, interaction, document) with visibility controls
- Hybrid BM25 + vector search with asynchronous enrichment and LLM-powered relationship extraction
- Knowledge graph with typed directional edges for contextual relationships between entities
- GTD-style task management, Markdown folder sync, and scoped API-key authentication
- MCP-compatible Streamable HTTP endpoint for agent-native tool access and CLI for human interaction

## Why It Matters for RAG Builders
Postgram provides a critical unified, inspectable, and self-hostable knowledge backend that enables RAG systems to maintain durable, structured, and contextually rich memory while preserving operator control over data and retrieval.
