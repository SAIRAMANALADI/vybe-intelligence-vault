## Summary
spyc is a keyboard-driven, vim-flavored terminal file commander designed to integrate with AI coding agents via a local MCP socket. It provides structured, live access to the user's file selection and workspace, enabling agents to query the current context without manual path sharing.

## Key Features
- Keyboard-driven vim-flavored file commander with git-aware listings
- Local MCP socket for real-time agent workspace access (cursor, picks, staged files, etc.)
- Agent pane integration with support for Claude Code, Codex, Gemini, and others
- Session persistence and multi-tab agent orchestration with activity tracking
- Customizable via TOML config and Lua scripting

## Why It Matters for RAG Builders
spyc bridges the gap between AI coding agents and file navigation by providing structured, live workspace context, eliminating manual path sharing and enabling seamless collaboration.
