## Summary
Wire UI is an AI-native, headless component library providing unstyled, compound components for React, Vue, and SolidJS. It enables zero-CSS styling via data attributes and integrates with AI workflows through machine-readable docs and an MCP server.

## Key Features
- Headless, unstyled components with zero CSS, allowing full styling control via data attributes
- Cross-framework support for React, Vue, and SolidJS
- AI-integrated documentation with `llms.txt` and machine-readable API references
- MCP server for AI-assisted workflows and code generation
- Internationalization support with locale-aware components and Intl formatters

## Why It Matters for RAG Builders
Wire UI enables AI builders to create consistent, customizable UI components without styling constraints, accelerating frontend development for RAG and AI applications.
