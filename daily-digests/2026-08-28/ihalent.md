## Summary
ihalent structures and analyzes Turkish public-tender award notices into structured records, enabling firms to query firm histories, discount distributions, and competition metrics. It transforms unstructured EKAP result notices into queryable analytics for procurement intelligence.

## Key Features
- Structures unstructured EKAP result notices into analyzable JSONL datasets
- Provides CLI and MCP server for querying firm histories, discounts, and competition metrics
- Tracks and reports data gaps (e.g., missing estimates) without inventing data
- Supports aggregation by authority, province, or tender type for comparative analysis
- Includes red-flag detection for procurement anomalies (e.g., single-bid awards, near-estimate pricing)

## Why It Matters for RAG Builders
It enables AI agents to query and reason across Turkish public-tender data, turning unstructured notices into structured analytics for procurement intelligence and audit purposes.
