## Summary
BoBanana 5.0 is a meta-agent long-term orchestration engine designed for cross-session task execution, leveraging programmable state machines and a pluggable skill role-card system. It enables AI-driven development pipelines with domain-agnostic core logic and customizable role cards for technical tasks.

## Key Features
- Programmable state machine for task scheduling and execution flow control
- Pluggable skill role-card system with 59+ pre-defined roles across technical domains
- Cross-session task continuity with context preservation and quality gates
- CL (Client Gate) terminal review mechanism for final validation and scoring
- Integration with Reasonix agent framework for seamless deployment and automation
