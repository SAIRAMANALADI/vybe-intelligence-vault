## Summary
AADA is an AI-powered Security Operations Center (SOC) agent that ingests raw security logs, detects attacks using rule-based and LLM-driven analysis, and recommends or executes remediation actions with human-in-the-loop approval. It combines RAG with cybersecurity knowledge bases for grounded threat analysis and maintains immutable audit logs for all actions.

## Key Features
- Multi-format log ingestion and normalization (JSON, CSV, SSH, auth, web)
- Detection engine with 6 rules (SSH brute force, port scan, etc.) and MITRE ATT&CK mapping
- RAG knowledge base integration (MITRE, OWASP, Sigma, NIST) with ChromaDB and offline fallback
- Structured LLM analysis grounded in retrieved context for actionable insights
- Immutable audit logging, approval workflows, rollback, and guardrails for safe remediation

## Why It Matters for RAG Builders
It provides a critical framework for automating SOC workflows with AI-driven threat detection and human oversight, reducing analyst workload while ensuring safe, auditable remediation actions.
