## Summary
CircuitMuse is a desktop application that combines AI-powered circuit design, real CPU emulation, and embedded code compilation for microcontrollers. It enables users to write, simulate, and debug Arduino C++, MicroPython, and ESP-IDF code with interactive electronic components, all locally without cloud dependency.

## Key Features
- Real CPU emulation for 150+ electronic components with drag-and-drop circuit building
- AI agent integration for natural language circuit design, debugging, and code generation
- Supports Arduino C++, MicroPython, ESP-IDF C, and multiple microcontroller architectures (AVR, RP2040, ESP32, STM32, Raspberry Pi)
- Offline-first desktop application with auto-save, project persistence, and import/export compatibility
- Built-in serial monitor, SPICE analog simulation, and mixed-mode digital/analog circuit analysis

## Why It Matters for RAG Builders
CircuitMuse bridges the gap between AI-driven circuit design and real embedded development by providing a local, interactive environment for simulating and debugging microcontroller code with AI assistance.
