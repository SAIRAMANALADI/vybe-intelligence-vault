## Summary
GroundTruth-MCP is a self-hosted MCP server that provides live documentation, code audits, and best practices for 598+ curated libraries across multiple ecosystems. It dynamically fetches up-to-date docs, resolves dependencies, and audits code for deprecated patterns or security issues.

## Key Features
- Dynamic documentation fetching from multiple sources (llms.txt, GitHub, npm, etc.) with evidence-based validation
- 14 specialized tools for resolving libraries, auditing code, fetching docs, and comparing frameworks
- 107+ audit patterns across 18 categories (security, accessibility, React, Next.js, TypeScript, etc.) with real-time fixes
- SSRF and Unicode-injection hardened with per-tool telemetry and atomic disk caching
- Supports 598+ curated libraries with automatic fallback to npm, PyPI, crates.io, and pkg.go.dev

## Why It Matters for RAG Builders
GroundTruth-MCP eliminates the risk of AI-generated deprecated or insecure code by providing real-time, evidence-backed documentation and audits directly from authoritative sources.
