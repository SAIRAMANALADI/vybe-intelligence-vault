## Summary
EIGAN is an autonomous AI-driven security operations platform that orchestrates vulnerability assessments, penetration testing, and risk analysis. It uses an AI core to plan, execute, and correlate security scans across multiple perspectives (Outside-In and Inside-Out) with adaptive cascading workflows and plugin-based tooling.

## Key Features
- AI-native security agent that plans, executes, and narrates scans with adaptive cascading workflows
- Multi-provider AI support (cloud and local Ollama) with provider registry for extensibility
- Plugin-based architecture for tools and capabilities, enabling seamless integration of new security tools
- Real-time dashboard with WebSocket updates, timeline of AI reasoning, and interactive findings exploration
- Comprehensive risk engine integrating CVSS, EPSS, CISA KEV, and MITRE ATT&CK mapping for prioritized reporting

## Why It Matters for RAG Builders
EIGAN provides an autonomous, AI-driven framework for security assessments that reduces manual effort while ensuring thorough, adaptive, and explainable vulnerability discovery and risk analysis.
