## Summary
This repository provides an n8n community node for integrating Flowera AI agent flows into n8n workflows. It enables users to call Flowera agent responses from within n8n automation pipelines, bridging AI agent capabilities with workflow automation.

## Key Features
- Enables calling Flowera AI agent flows from n8n workflows
- Supports operations like running flows and listing available flows
- Provides credentials management for secure API key integration
- Allows session-based conversation continuity via stable session IDs
- Offers raw response data for debugging and detailed execution tracking

## Why It Matters for RAG Builders
It simplifies the integration of AI agent capabilities into n8n workflows, enabling automated, AI-driven responses within business processes.
