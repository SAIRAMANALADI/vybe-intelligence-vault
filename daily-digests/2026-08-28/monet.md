## Summary
Monet is a desktop application that serves as a unified control center for managing multiple AI coding agents like Claude Code and Codex. It provides a centralized interface for monitoring, interacting with, and automating sessions across different AI engines.

## Key Features
- Unified interface for Claude Code and Codex sessions with real-time monitoring and control
- Parallel session management with horizontal scrolling and live status tracking
- Race mode for broadcasting queries to multiple models/channels for comparison
- Built-in MCP server for AI-driven history search and task scheduling
- Zero telemetry, offline-first design with read-only access to local session files

## Why It Matters for RAG Builders
Monet streamlines the management of multiple AI coding agents, reducing terminal chaos and enabling efficient parallel session monitoring and automation for RAG builders.
