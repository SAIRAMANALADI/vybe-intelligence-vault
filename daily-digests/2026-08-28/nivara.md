## Summary
Nivara AI is an AI-powered medical symptom assessment tool that uses LLMs (Groq/Llama-3) and vision AI for intelligent health insights, urgency triaging, and personalized care recommendations, including hospital proximity searches.

## Key Features
- Intelligent symptom assessment with adaptive follow-up questions using Groq (Llama-3)
- Multi-modal analysis including image-based skin/symptom evaluation
- Urgency triaging with clear indicators for home care, 24-hour visits, or emergencies
- Smart recommendations for specialists, diagnostic tests, and nearest hospitals
- Privacy-focused data handling with AI-generated disclaimers
