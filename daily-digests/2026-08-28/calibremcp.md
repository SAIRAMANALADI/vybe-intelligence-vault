## Summary
CalibreMCP is a FastMCP 3.2-based MCP server that bridges Calibre e-book libraries with AI assistants (e.g., Claude, Cursor) via the Model Context Protocol. It enables AI-assisted search, RAG, and agentic workflows for managing large e-book collections with 21 integrated tools.

## Key Features
- 21 portmanteau tools for natural-language library management (search, export, OCR, viewer)
- Semantic search (LanceDB RAG) and full-text chunk RAG over Calibre metadata
- Calibre plugin for extended metadata editing and AI-assisted queries in the Calibre GUI
- Concurrency-safe, thread-safe DB operations for multi-client access
- Windows-native desktop app (Tauri) and Next.js web dashboard with AI chat and skills

## Why It Matters for RAG Builders
It enables AI assistants to interact with Calibre e-book libraries via MCP, unlocking advanced RAG and agentic workflows for managing large personal book collections.
