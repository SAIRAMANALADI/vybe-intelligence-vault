## Summary
A Model Context Protocol (MCP) server in JavaScript that enables AI agents to interact with Graylog for log analysis, debugging, and monitoring. It provides tools for searching logs, aggregating data, and discovering fields/streams with token-efficient responses.

## Key Features
- JavaScript-based MCP server for seamless AI agent integration
- Tools for searching, analyzing, and retrieving logs with token efficiency
- Multi-instance support for querying multiple Graylog servers
- Discovery features (list_fields, list_streams) to avoid guessing field names
- Detailed error reporting for empty search results (indexing lag, wrong queries, etc.)

## Why It Matters for RAG Builders
It enables AI agents to efficiently query and analyze logs in Graylog, reducing token waste and improving debugging accuracy with structured, actionable insights.
