## Summary
A Codex plugin skill that enables coding agents to generate, validate, and refine editable PowerPoint decks from structured source files. It treats presentations as code, using JSON outlines, style presets, and a QA pipeline to ensure design consistency and quality.

## Key Features
- Editable `.pptx` generation from structured `outline.json` source files
- 13 slide variants (title, section, cards, timeline, KPI, chart, etc.) with strict layout disciplines
- 13 style presets (lab report, investor, board memo, etc.) with palette, typography, and density profiles
- Three-step QA pipeline (geometric, visual, content checks) to catch design regressions
- Workspace mode for iterative decks with readiness diagnostics and automated actions

## Why It Matters for RAG Builders
It ensures AI-generated presentations are not just textually correct but also visually consistent and professional, bridging the gap between raw content and polished deliverables for RAG/AI stack builders.
