## Summary
OS1 is a minimal, open-source voice agent designed for natural, continuous conversations with an AI assistant. It integrates real-time speech-to-text, LLM responses, and text-to-speech in a single interface, prioritizing simplicity and intimacy over complex workflows.

## Key Features
- One-click live voice mode with continuous conversation support
- VAD auto end-of-speech detection for seamless interaction
- Streaming LLM responses with Grok-4.5 and ElevenLabs TTS
- Full-duplex barge-in for interrupting responses
- Local telemetry and SQLite-based usage tracking

## Why It Matters for RAG Builders
OS1 provides a lightweight, local-first framework for building voice-enabled AI agents, reducing the complexity of integrating real-time STT, LLM, and TTS pipelines.
