## Summary
memcp provides persistent memory for AI coding assistants like Claude Code and Codex CLI by automatically storing and indexing session logs in a local SQLite database via MCP. It enables agents to search and retrieve historical context across sessions without cloud dependencies.

## Key Features
- Automatic ingestion of AI coding session logs into a local SQLite database
- Full-text search (FTS5) across past sessions and messages
- MCP server integration for seamless agent tool access
- Support for multiple AI tools (Claude Code, Codex CLI)
- Configurable backfill and incremental ingestion with timestamp filtering

## Why It Matters for RAG Builders
It enables AI agents to retain and retrieve historical context across sessions, eliminating the need to start from scratch and improving continuity in AI-driven workflows.
