## Summary
A Python docstring format and tooling suite emphasizing machine-verifiable normativity, featuring a linter, JSON schema, and MCP server for structured documentation. It enables validation, rendering, and deployment of standardized docstrings for AI and LLM workflows.

## Key Features
- Machine-verifiable docstring format with strict schema enforcement
- CLI tool (`waterlint`) for validation, rendering, and Docker packaging
- MCP server for exposing documentation data to AI agents and tools
- Support for both human-readable HTML and LLM-ready JSON outputs
- Integration with IDEs (VSCode) and syntax highlighting via Pygments
