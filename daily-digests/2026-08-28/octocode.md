## Summary
Octocode is an MCP server that transforms codebases into navigable knowledge graphs for AI agents, enabling semantic search, dependency navigation, and LSP-powered code intelligence. It bridges the gap between raw code and AI understanding by leveraging AST parsing, GraphRAG, and hybrid search.

## Key Features
- Semantic code search with hybrid retrieval (dense + BM25) for high accuracy
- Knowledge graph of code relationships (imports, calls, dependencies) via GraphRAG
- MCP server integration for direct AI agent access to codebase intelligence
- LSP-powered tools (goto-definition, find-references, hover docs) for precise navigation
- AST-based symbol extraction for accurate code structure understanding

## Why It Matters for RAG Builders
Octocode provides AI agents with structural code intelligence, enabling them to navigate and understand codebases beyond flat text retrieval, which is critical for building accurate and context-aware RAG systems.
