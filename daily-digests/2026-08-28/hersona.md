## Summary
hersona is a library and toolkit for defining, composing, and measuring AI agent personas using 346 reusable character attributes across personality, speech, archetype, visual, and hobby categories. It enables consistent character maintenance across conversations and supports export to various LLM frameworks.

## Key Features
- Composable persona attributes (346 templates) across 5 categories for flexible character design
- Deterministic benchmarking tools to measure persona maintenance and injection costs
- CLI, MCP server, and Hermes Agent integration for seamless deployment
- Export formats compatible with OpenAI Assistants, LangChain, and major LLM frameworks
- Conflict detection and intensity control for attribute blending with compatibility matrices

## Why It Matters for RAG Builders
It standardizes and automates persona creation for AI agents, ensuring consistency and reducing the manual effort of crafting system prompts for character-driven applications.
