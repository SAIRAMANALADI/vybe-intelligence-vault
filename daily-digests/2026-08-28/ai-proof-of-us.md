## Summary
AI Proof of Us is an MCP-first protocol enabling humans to generate signed, privacy-preserving receipts for AI-assisted work. It allows agents and developers to create portable, verifiable records of AI tasks, with optional on-chain rewards via the AIPOU token on Base.

## Key Features
- Privacy-preserving signed receipts for AI tasks via MCP server
- Interoperable `workReceiptId` for workflow metadata and audit trails
- Optional on-chain reward claims via AIPOU token on Base
- Replay protection via nonce and receiptId
- Framework-agnostic lifecycle hooks for agent integration

## Why It Matters for RAG Builders
It provides a standardized way to verify and reward human-AI collaborative work, enabling portable, auditable receipts that can be optionally settled on-chain for AI-assisted tasks.
