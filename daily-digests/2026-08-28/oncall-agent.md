## Summary
OnCall Agent is an auditable autonomous incident response system designed for high-frequency, standardized, and low-risk incidents. It automates alert deduplication, evidence aggregation, root cause hypothesis generation, versioned runbook matching, policy approval, remediation drills, recovery validation, rollback, and knowledge candidate deposition in a controlled dry-run mode.

## Key Features
- Hybrid RAG architecture combining BM25 and vector search with reciprocal rank fusion (RRF) for multi-source evidence retrieval
- Eight-stage auditable agent run pipeline with policy gates, approval workflows, and rollback mechanisms
- Versioned runbook execution with dry-run safety mode to prevent production interference
- Real-time alert deduplication and incident fingerprinting for standardized response
- Knowledge candidate generation with human review gates to prevent contamination of production RAG corpora

## Why It Matters for RAG Builders
It provides a secure, auditable framework for automating incident response while maintaining strict safety controls, making it essential for building production-grade RAG systems that require human oversight and policy enforcement.
