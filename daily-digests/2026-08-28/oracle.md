## Summary
Oracle is a local-first, self-evolving multi-agent council that uses specialized agents backed by local Ollama models to debate, research, and refine goals until a consensus gate is met. It integrates persistent memory, knowledge graphs, continuous learning, and organic agent evolution with optional cloud model support.

## Key Features
- Council loop with concurrent Critic and Verifier roles for iterative goal refinement
- Persistent memory and grounding via vector store, Obsidian vault, and document library
- Knowledge graph for entity relations and document structure
- Organic agent evolution with DNA-based fitness scoring and natural selection
- Voice integration for two-way interaction and narration

## Why It Matters for RAG Builders
Oracle provides a framework for building autonomous, self-improving agent systems that can dynamically solve complex goals through debate and consensus, making it valuable for advanced RAG and AI orchestration.
