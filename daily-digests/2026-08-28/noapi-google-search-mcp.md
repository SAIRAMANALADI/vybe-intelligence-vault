## Summary
noapi-google-search-mcp is a local server tool that enables automated Google searches and web page fetching using headless Chromium, eliminating the need for browser interaction or API keys. It runs locally for privacy and speed, supporting Windows, macOS, and Linux.

- Runs as a local server for privacy and low-latency operations
- Supports automated Google searches without API dependencies
- Cross-platform compatibility (Windows, macOS, Linux)
