## Summary
Pie is an open-source AI agent that integrates into the Chrome sidebar, enabling users to perform browser automation tasks through natural language commands. It reads pages, interacts with web elements, and executes multi-step workflows across tabs while supporting BYOK (Bring Your Own Key) for 11+ LLM providers.

## Key Features
- Natural language task execution with browser automation (clicking, typing, scrolling)
- Cross-tab workflow recording and replay for complex tasks
- Support for 11+ LLM providers via BYOK or Pie's subscription service
- Privacy-focused with encrypted API keys and no telemetry collection (except subscription path)
- Reusable Skills for automating repetitive tasks and scheduled execution

## Why It Matters for RAG Builders
Pie enables AI engineers to automate browser-based workflows programmatically, reducing manual intervention and improving efficiency for tasks requiring web interaction.
