## Summary
Cogitorium is a local-first workbench for building and managing agentic workflows with a single Go binary. It enables users to define custom agents, assign models per agent, and enforce wiring rules for controlled delegation, all while providing transparent cost tracking and no telemetry.

## Key Features
- Single binary deployment with embedded UI for local-first agent management
- Per-agent model selection and cost tracking for transparent economics
- Blueprint-based wiring to enforce delegation rules and capabilities
- Agent-forged tools with containerized, network-restricted execution
- Contextverse-backed versioned context with editable prompts and branches

## Why It Matters for RAG Builders
Cogitorium empowers RAG builders to create modular, cost-transparent agentic workflows with fine-grained control over model usage and delegation, reducing black-box dependencies and enabling reproducible, auditable AI systems.
