## Summary
A multi-agent crypto trading system built entirely with Claude Code's agent framework, MCP servers, and markdown-based orchestration. It coordinates 7 specialized AI agents, 95 real-time tools, and self-learning mechanisms to perform market analysis, portfolio management, and autonomous trading without traditional orchestration code.

## Key Features
- 7 coordinated AI agents with specialized roles (market monitoring, technical analysis, news sentiment, risk assessment, portfolio management, learning, and system building)
- 95 MCP tools across 9 servers for real-time market data, technical indicators, and on-chain analytics
- Self-learning mechanism with trade post-mortems, prediction tracking, and pattern library
- Markdown-based orchestration with zero Python code for agent coordination
- Autopilot mode for autonomous trading and market analysis via cron jobs
