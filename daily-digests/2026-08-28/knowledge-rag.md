## Summary
A local RAG (Retrieval-Augmented Generation) MCP server designed for Claude Code, enabling hybrid search (BM25 + semantic vectors + cross-encoder reranking) across 20+ file formats with zero cloud dependency. It indexes 1800+ files in under 3 minutes and provides 13 MCP tools for local knowledge retrieval.

## Key Features
- Hybrid search combining BM25, semantic vectors, and cross-encoder reranking for high-precision retrieval
- Supports 20+ file formats (PDFs, markdown, code, notebooks) with 1800+ files indexed in under 3 minutes
- 13 MCP tools for seamless integration with Claude Code, IDEs, and other MCP-compatible clients
- Enterprise-grade features including SSE/HTTP transport, rate limiting, Prometheus metrics, and bearer auth
- Strict quality gates with 35+ automated checks across 7 pillars (security, stability, memory leak, versatility, scalability, versioning, quality)

## Why It Matters for RAG Builders
It provides a fully local, high-performance RAG orchestrator with hybrid search and MCP integration, eliminating cloud dependencies and API costs for AI stack builders.
