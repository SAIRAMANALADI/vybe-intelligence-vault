## Summary
JanexAgent is an autonomous AI agent framework designed for terminal and multi-platform environments, enabling advanced browser automation, security testing, research, trading analysis, and multi-agent decision-making. It operates in real environments with tool execution, file editing, and CAPTCHA solving capabilities.

## Key Features
- Playwright-powered browser automation with CAPTCHA solving (image, audio, slider, hybrid modes)
- Bug Hunt skill system for CTF, security testing, and reverse engineering
- Advanced research capabilities with social intelligence and multi-source synthesis
- Trading, stocks, crypto, and DeFi analysis tools
- Native multi-agent routing and council-style decision-making
