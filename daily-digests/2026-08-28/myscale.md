## Summary
MyScale is a SQL vector database built on a ClickHouse fork (MyScaleDB), combining high-performance vector search, full-text search, and analytical SQL in a single engine. It exposes a ClickHouse-compatible HTTP interface for SQL-based vector similarity search and database operations.

## Key Features
- SQL-based vector similarity search using distance() function
- Full integration with ClickHouse-compatible HTTP interface (port 8443)
- Supports HNSW and other vector indexing methods
- Combines vector search, full-text search, and analytical SQL
- Open-source core (MyScaleDB) with managed cloud service

## Why It Matters for RAG Builders
MyScale provides a unified SQL interface for vector search and database operations, making it essential for RAG builders who prefer SQL over REST APIs for managing embeddings and retrieval.
