## Summary
OrcaSlicer MCP is an MCP server that enables AI clients like Claude to programmatically control OrcaSlicer, a 3D slicing software. It allows loading models, adjusting settings, slicing, and retrieving detailed print analysis without exposing data outside the local machine.

## Key Features
- Programmatic control of OrcaSlicer via MCP for AI-driven 3D printing workflows
- Real-time settings management (800+ parameters) with physics validation for print feasibility
- Detailed print analysis including time, filament usage, and flow breakdown per feature
- Plate rendering (PNG) for visual inspection of models and toolpaths
- Persistent state and notes storage for session continuity

## Why It Matters for RAG Builders
It bridges AI assistants with OrcaSlicer to automate and optimize 3D printing workflows, enabling precise control and analysis without manual intervention.
