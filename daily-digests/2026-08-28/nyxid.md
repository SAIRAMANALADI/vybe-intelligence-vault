## Summary
NyxID is an open-source Agent Connectivity Gateway that enables AI agents to securely access any API, including public, internal, or localhost services, without exposing raw credentials. It proxies requests, injects credentials automatically, and wraps REST APIs as MCP tools for seamless integration with AI workflows.

## Key Features
- Secure credential injection without exposing raw API keys to AI agents
- NAT traversal to reach localhost or private network services via credential nodes
- Automatic REST API to MCP tool wrapping for seamless AI agent integration
- Per-agent isolation with scoped tokens and RBAC for granular access control
- Supports OIDC/OAuth 2.0 with PKCE and full identity layer for authentication

## Why It Matters for RAG Builders
NyxID is essential for RAG/AI stack builders as it provides a secure, scalable gateway to connect AI agents to any API while eliminating credential exposure risks and simplifying MCP tool integration.
