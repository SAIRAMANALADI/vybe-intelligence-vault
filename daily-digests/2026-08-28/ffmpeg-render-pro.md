## Summary
ffmpeg-render-pro is a Node.js-based parallel video rendering toolkit that leverages FFmpeg for GPU-accelerated, multi-threaded video processing. It includes a CLI, MCP server, and dashboard for real-time monitoring, with features like checkpoint systems, color grading, and cross-platform GPU auto-detection.

## Key Features
- Parallel rendering with worker threads and zero re-encoding for concatenation
- Cross-platform GPU auto-detection (NVENC, VideoToolbox, AMF, VA-API, QSV)
- Live dashboard with real-time progress, FPS chart, and ETA
- Checkpoint system for resuming interrupted renders with 93% overhead reduction
- MCP server with 7 typed tools for AI agent integration (Claude Code compatible)

## Why It Matters for RAG Builders
