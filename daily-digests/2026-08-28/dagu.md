## Summary
Dagu is a lightweight, self-contained workflow orchestrator alternative to Airflow or Cron, featuring a declarative YAML-based DAG definition, a web UI for monitoring, and support for shell commands, Docker, Kubernetes, SSH, and AI agent integration via MCP. It is designed for simplicity and self-hosting with no database dependency.

## Key Features
- Single binary installation with no database dependency, simplifying deployment and reducing operational overhead
- Declarative YAML-based DAG definitions supporting shell commands, Docker, Kubernetes, SSH, and external CLIs
- Built-in MCP server enabling AI agents (e.g., Claude Code, Codex) to manage, monitor, and execute workflows
- Web UI for visual workflow management, logging, retries, approvals, and observability without coding
- Distributed execution with coordinator/worker architecture for scalable and fault-tolerant workflows

## Why It Matters for RAG Builders
Dagu simplifies workflow orchestration for AI stacks by providing a lightweight, self-contained alternative to heavyweight tools like Airflow, with native support for AI agent integration via MCP, making it ideal for teams seeking simplicity and extensibility.
