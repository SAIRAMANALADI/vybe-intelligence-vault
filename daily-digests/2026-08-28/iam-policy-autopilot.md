## Summary
IAM Policy Autopilot is an open-source tool that automates the generation of AWS IAM policies by analyzing application code to identify required permissions. It provides both a CLI and an MCP server for integration with AI coding assistants, enabling faster and more reliable policy creation for AWS applications.

## Key Features
- Static code analysis for AWS SDK calls to generate precise IAM policies
- MCP server integration for AI coding assistants (e.g., Claude, Kiro)
- Supports multiple languages: Python, Go, TypeScript, JavaScript, and Java
- CLI tool for local policy generation and refinement
- Deterministic policy generation with service hints for accuracy

## Why It Matters for RAG Builders
It accelerates secure AWS IAM policy creation for AI-driven development workflows, reducing manual effort and minimizing permission-related debugging delays.
