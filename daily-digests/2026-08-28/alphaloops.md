## Summary
This repository profiles the AlphaLoops FMCSA Carrier Data API, which provides a REST API for accessing comprehensive freight carrier intelligence data, including carrier profiles, authority history, fleet details, inspections, crashes, and risk monitoring. It is a third-party, publicly available API profile maintained by API Evangelist.

## Key Features
- Provides FMCSA motor-carrier intelligence via a public REST API
- Covers carrier profiles, authority history, and insurance data
- Includes VIN-level fleet data and roadside inspection records
- Offers crash data and corporate connection tracking
- Exposes risk and watchlist monitoring capabilities
