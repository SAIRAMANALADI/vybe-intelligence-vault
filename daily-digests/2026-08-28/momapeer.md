## Summary
momapeer is an enterprise-grade AI programming assistant designed for China Mobile's MoMA (Jiu Tian) large model platform, enabling natural language-driven autonomous coding across multiple interfaces including TUI, desktop, HTTP/SSE, and IM bots. It integrates deeply with MoMA's ecosystem and supports MCP plugins for extensibility.

## Key Features
- Deep integration with China Mobile's MoMA platform for 300+ models (e.g., DeepSeek, Qwen, GLM)
- Multi-frontend support (TUI, desktop, HTTP/SSE, IM bots) with a unified core engine
- Built-in CodeGraph engine for local AST-based code indexing and precise symbol tracking
- MCP plugin ecosystem for extensible tool integration and external capabilities
- Advanced safety features including plan mode, evidence-backed execution, and path traversal protection
