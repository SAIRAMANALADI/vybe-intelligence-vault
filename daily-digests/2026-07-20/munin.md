## Summary
Munin is an open-source, headless CRM and customer platform designed for the agentic era, exposing all functionality as MCP tools for AI agents. It unifies CRM, conversations, outreach, CMS, knowledge base, and analytics into a single Postgres schema with a thin dashboard for human oversight.

## Key Features
- Unified MCP tool surface for CRM, conversations, CMS, knowledge base, outreach, and analytics with a single Postgres schema and permission model
- In-process agent runner for real-time conversation handling and background curation tasks using configurable LLM providers
- Hybrid search, version history, and human-in-the-loop review across all modules (e.g., knowledge base, CMS)
- Data portability via symmetric export/import MCP tools and REST endpoints for seamless migration between self-hosted and cloud environments
- Audit logging, webhooks, and delegated token-based access for secure multi-tenant or self-hosted deployments

## Why It Matters for RAG Builders
Munin provides a critical orchestration layer for RAG/AI stacks by exposing unified, auditable, and agent-driven tools across CRM, CMS, and knowledge systems, enabling seamless integration with AI agents while maintaining data consistency and human oversight.
