## Summary
Pop Maker Studio is a native C++ music video and lyric video editor designed for pop artists, enabling local processing of transcription, vocal separation, voice conversion, background removal, and GPU effects without cloud dependencies or Python runtimes.

## Key Features
- Fully local ML pipeline for vocal separation, transcription, and voice conversion using ONNX models without Python dependencies
- Real-time GPU effects engine with GLSL shaders and hot-reloadable effects
- Three-tier video preview system (native libav decode, MJPEG proxy, single-frame still) for efficient scrubbing and rendering
- MCP server integration enabling AI agents to control and automate editing workflows via Unix socket IPC
- Project bin for media management, lyric animation styles, and A/V sync with audio-driven playhead

## Why It Matters for RAG Builders
It provides a fully local, high-performance toolkit for AI-driven music video production, enabling RAG builders to integrate advanced audio-visual processing without cloud dependencies or runtime overhead.
