## Summary
mcp-dockhand is an MCP (Model Context Protocol) server that exposes over 130 Dockhand API endpoints as MCP tools, enabling AI assistants to programmatically manage Docker infrastructure through a standardized interface.

## Key Features
- Exposes 130+ Dockhand API endpoints as MCP tools for Docker infrastructure management
- Supports streamable HTTP transport (MCP Spec 2025-03-26) for real-time operations
- Provides session-based authentication with auto-relogin on 401 errors
- Includes environment filtering for secure multi-host Docker operations
- Offers SSE support for deploy operations (start, stop, restart) with non-root user execution

## Why It Matters for RAG Builders
It bridges AI assistants with Docker infrastructure, enabling seamless programmatic control of containers, stacks, and networks for RAG and AI workflow automation.
