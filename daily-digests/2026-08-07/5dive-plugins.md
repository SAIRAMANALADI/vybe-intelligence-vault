## Summary
A plugin marketplace providing Telegram bot integrations for various AI agent CLIs, enabling users to interact with agents via Telegram messages. Forks and extends Anthropic's official Telegram plugin to support multiple runtimes beyond Claude Code.

## Key Features
- Telegram bot integration for multiple AI agent CLIs (Claude Code, OpenAI Codex, xAI Grok, Google Antigravity, opencode)
- Supports both push-based (Claude Code) and poll-based (MCP) agent communication protocols
- Auto-relay, stop-reply gating, and user-question routing for enhanced control
- Centralized plugin marketplace for easy installation and management
- Cross-runtime parity testing via `test/parity.test.ts` and `generator/`

## Why It Matters for RAG Builders
It enables seamless integration of Telegram bots with diverse AI agent runtimes, expanding accessibility and interactivity for RAG and AI systems.
