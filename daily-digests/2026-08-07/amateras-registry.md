## Summary
A community registry for AMA-teras that enables sharing and discovery of pre-built tool plugins. It allows the AMA-teras application to search for existing plugins before generating new ones, reducing development costs and ensuring safety through a multi-layered verification process.

## Key Features
- Centralized plugin registry for AMA-teras with automated CI validation
- Two-tiered plugin verification (verified/unverified) with human review for promotion
- Automated safety checks (typecheck, tests, smoke tests) before plugin adoption
- Revocation system (revoked.json) for disabling unsafe or problematic plugins
- Contribution workflow via forks and pull requests with DCO compliance
