## Summary
A fully localized Chinese version of OpenWorker, an open-source local AI Agent desktop application, featuring a Chinese GUI and macOS desktop client. It retains all original functionality while translating the interface for Chinese-speaking users.

## Key Features
- Complete Chinese localization of both frontend GUI and Tauri desktop shell
- Supports running as a browser-based app or standalone macOS desktop client
- Detailed installation guides for macOS users without sudo privileges
- Automated build and release pipeline for DMG packages and updates
- Comprehensive documentation including architecture analysis and enterprise customization guides
