## Summary
Error Mom is a self-hosted error tracking system designed for AI coding agents, enabling apps to report crashes to a private dashboard where agents can inspect, diagnose, and fix issues automatically. It eliminates third-party dependencies and integrates seamlessly with tools like Claude Code or Cursor.

## Key Features
- Private error dashboard with write-only keys for secure error reporting
- AI agent integration via CLI and MCP server for automated error resolution
- Automatic error grouping, counting, and regression detection
- Secrets redaction and AI provider failure labeling
- Offline error queuing and retry mechanisms

## Why It Matters for RAG Builders
Error Mom enables AI agents to autonomously detect, diagnose, and resolve application errors, reducing manual debugging overhead and improving reliability for AI-driven development workflows.
