## Summary
OpenRead is a privacy-focused browser extension and CLI tool that enables on-device translation of web pages and PDFs into multiple languages, including Traditional Chinese with Taiwanese-specific vocabulary. It supports both Chrome's built-in translator and local LLMs via Ollama, ensuring no data leaves the user's machine.

## Key Features
- Supports on-device translation of web pages and PDFs without sending data to external servers
- Offers both Chrome's built-in translator and Ollama-based local LLM translation
- Provides bilingual output with original text and translation side-by-side
- Supports Traditional Chinese with Taiwanese-specific vocabulary corrections
- Includes CLI and MCP server for scripted or agent-based translation workflows

## Why It Matters for RAG Builders
It enables secure, private translation of documents and web content for RAG pipelines without exposing sensitive data to external APIs.
