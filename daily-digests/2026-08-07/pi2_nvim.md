## Summary
pi2.nvim is a Neovim plugin that integrates the pi coding agent directly into the editor, enabling in-editor workflows for AI-assisted coding, project-aware prompts, and session management without leaving the editor environment.

## Key Features
- In-editor chat and prompt interface with project-aware context
- Session management with live status overview and navigation
- Diff review and edit application with user confirmation
- Bash command execution directly from prompts
- Image attachment and compression for multi-modal prompts

## Why It Matters for RAG Builders
It streamlines AI-assisted coding workflows by embedding the pi agent directly into Neovim, reducing context switching and enabling seamless integration of AI tools into the development process.
