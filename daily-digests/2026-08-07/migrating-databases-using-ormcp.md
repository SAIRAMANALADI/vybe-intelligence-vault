## Summary
A flight management system demonstrating database migration from Oracle to PostgreSQL using ORMCP and natural language queries. The project showcases AI-driven data transfer via an MCP server, leveraging JDX for ORM and Gilhari for REST microservices.

- AI-powered database migration using natural language queries via MCP
- Object-Relational Mapping (ORM) with JDX for schema and data translation
- Dockerized microservices for Oracle and PostgreSQL databases
- Comprehensive flight management system with 8 core entities and relationships
- Modular architecture supporting custom database connectors and AI agents
