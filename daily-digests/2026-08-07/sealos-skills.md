## Summary
Sealos Skills is a plugin-first skill pack designed to enable AI agents to deploy projects to Sealos Cloud, provision cloud-native databases and object storage, and visualize deployed resources through a local canvas UI. It standardizes AI agent interactions with Sealos Cloud via a unified plugin system compatible with multiple AI tools.

## Key Features
- Unified plugin for deploying projects to Sealos Cloud from AI agents
- Provisions cloud databases (Postgres, Redis, etc.) and S3-compatible object storage
- Local read-only canvas UI for visualizing deployed resources
- Cross-platform compatibility with Codex, Claude Code, Gemini CLI, and Qwen Code
- Automated Dockerfile generation and container image building for deployments

## Why It Matters for RAG Builders
It simplifies AI agent-driven cloud deployments by abstracting Sealos Cloud interactions into reusable skills, enabling seamless integration of databases, storage, and visualization into AI workflows.
