## Summary
mcp-zoom is a Zoom MCP (Model Context Protocol) pack that enables AI agents to interact with Zoom meetings and recordings. It provides tools to list, retrieve, and manage Zoom meetings and cloud recordings for a signed-in user.

## Key Features
- Provides MCP-compatible tools for Zoom meeting and recording management
- Supports listing upcoming, scheduled, and live meetings
- Enables retrieval of detailed meeting information and cloud recordings
- Integrates with Pipeworx gateway for access to 1394+ data sources
- Supports plain English queries via ask_pipeworx for automated tool selection

## Why It Matters for RAG Builders
It enables AI agents to seamlessly interact with Zoom data, enhancing their ability to schedule, retrieve, and analyze meetings and recordings for RAG applications.
