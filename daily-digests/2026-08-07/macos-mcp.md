## Summary
macOS-MCP is a lightweight Model Context Protocol (MCP) server that enables AI agents to interact with macOS systems through native UI automation, file operations, and system control. It bridges LLMs with macOS features like application management, UI interaction, and browser automation without requiring computer vision or specialized models.

## Key Features
- Native macOS integration via Accessibility API for UI automation and control
- Supports multiple transport protocols (stdio, SSE, streamable-http) for flexible client integration
- Comprehensive toolset for file navigation, application control, keyboard/mouse operations, and system operations
- Lightweight and open-source with MIT license, minimal dependencies, and easy setup
- Smart context awareness for detecting application state, menu bars, docks, and system UI elements

## Why It Matters for RAG Builders
It provides essential native macOS automation capabilities for AI agents, enabling seamless integration with LLMs for real-world desktop tasks without requiring computer vision or specialized models.
