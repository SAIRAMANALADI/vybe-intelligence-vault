## Summary
PartReel is an open, machine-verified registry of KiCad electronic component parts, providing verified footprints, symbols, and 3D models (STEP/GLB) with datasheet provenance. It offers a static JSON API, MCP server, and automated quality gates to ensure reliability for both humans and AI agents.

## Key Features
- Machine-verified KiCad footprints, symbols, and 3D models with datasheet provenance
- Static JSON API with no authentication or rate limits for easy integration
- Automated quality gates in CI blocking deployment on failures
- Remote MCP server for seamless AI agent integration
- Community-driven part requests and contributions with automated review

## Why It Matters for RAG Builders
PartReel eliminates the need for AI agents to regenerate unverified PCB parts from scratch, providing a reliable source of machine-verified components with provenance for RAG and automation workflows.
