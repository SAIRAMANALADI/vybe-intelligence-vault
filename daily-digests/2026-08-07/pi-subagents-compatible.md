## Summary
A Pi-native extension providing a Claude-compatible subagent workflow for the Pi platform. It enables dynamic agent delegation, async/parallel task execution, and lightweight TUI-based status monitoring, replacing the original `pi-subagents` workflow with a Pi-integrated implementation.

## Key Features
- Pi-native subagent workflow with dynamic agent loading from configurable directories
- Supports single, async, parallel, and chain-based subagent execution patterns
- Lightweight TUI for real-time status monitoring and inspection of active runs
- Persistent run artifacts with structured metadata and outputs for post-run analysis
- Local configuration overrides for runtime behavior customization

## Why It Matters for RAG Builders
It provides a Pi-integrated, Claude-compatible subagent framework that enables advanced agent delegation and orchestration directly within the Pi ecosystem, reducing dependency on external wrappers.
