## Summary
An AI agent that automates verification of healthcare providers by querying the public NPPES NPI registry, extracting clinician details, and reporting results. It demonstrates computer-use automation by driving a real browser to interact with a live website, capturing the process for transparency.

## Key Features
- Zero-dependency, offline-capable agent with bundled mock for testing
- Automates complex, dynamic web interactions without selectors or scraping rules
- Provides transparent, frame-by-frame capture of agent actions for auditability
- Structured safety mechanisms to prevent accidental spend or PHI exposure
- Idempotent operations with hard cost caps and independent consent requirements
