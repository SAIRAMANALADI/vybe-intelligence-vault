## Summary
A local, read-only IMAP email viewer for macOS and Windows that enables secure, encrypted access to multiple email accounts. It allows agents to filter and summarize emails without modifying or deleting them, providing JSON output for automation while avoiding spam and ads.

## Key Features
- Supports multiple email providers (QQ, Gmail, iCloud, 163, 126, etc.) with IMAPS encryption
- Read-only access with no modifications to emails or metadata
- Local SQLite caching with AES-GCM encrypted text bodies for security
- JSON output for agent-based email summarization and filtering
- Web UI and CLI for manual and automated email inspection

## Why It Matters for RAG Builders
It enables AI agents to securely and efficiently read, filter, and summarize emails without exposing sensitive credentials or modifying mailbox state, making it essential for automated email workflows.
