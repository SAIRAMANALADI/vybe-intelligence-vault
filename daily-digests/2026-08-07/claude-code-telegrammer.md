## Summary
A custom Telegram MCP server and TUI auto-responder that enables autonomous Claude Code agents to operate via Telegram, addressing key limitations of the official plugin with configurable state directories, SQLite message persistence, and robust error handling.

## Key Features
- Configurable state directory for isolated agent instances
- SQLite-based message persistence with full-text search and attachment support
- 10 MCP tools for comprehensive Telegram interaction (reply, react, edit, search, etc.)
- TUI watchdog for auto-recovery from idle or permission prompts
- Robust error handling with PID-based locks and health checks

## Why It Matters for RAG Builders
It enables seamless, autonomous operation of Claude Code agents over Telegram with persistence, error recovery, and scalability, critical for building robust RAG pipelines.
