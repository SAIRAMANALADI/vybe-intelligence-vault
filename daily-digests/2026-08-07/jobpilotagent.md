## Summary
JobPilotAgent is a local Windows application that automates job application processes by matching resumes to job descriptions, generating draft documents, and tracking application progress. It prioritizes human oversight, ensuring users review and approve all outputs before submission.

## Key Features
- Resume-to-job-description matching for tailored applications
- Generates editable DOCX documents with evidence-based claims
- Local SQLite database for private application tracking
- Human approval required at every critical step
- Windows-native installer for easy deployment

## Why It Matters for RAG Builders
It streamlines job application workflows while maintaining strict data privacy, making it valuable for users who need automated yet controlled document generation.
