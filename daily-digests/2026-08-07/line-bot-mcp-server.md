## Summary
A Model Context Protocol (MCP) server implementation that bridges LINE Messaging API with AI agents, enabling seamless integration of LINE Official Accounts for messaging, user profile retrieval, and rich menu management.

## Key Features
- Provides 12 MCP tools for LINE Messaging API integration, including text and flex message broadcasting, user profile retrieval, and rich menu management
- Supports both direct messaging and broadcast capabilities to LINE users
- Offers local development and debugging via MCP Inspector
- Includes Docker support for containerized deployment
- Automates rich menu creation with customizable actions and auto-generated images

## Why It Matters for RAG Builders
It enables AI agents to interact directly with LINE users through a standardized MCP interface, expanding AI capabilities to real-world messaging platforms.
