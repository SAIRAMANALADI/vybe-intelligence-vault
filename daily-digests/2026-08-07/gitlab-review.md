## Summary
@ikko-dev/gitlab-review is a CLI tool that automates AI-driven code reviews for GitLab merge requests and GitHub pull requests, comparing code changes against the author's stated intent in the MR/PR description to flag mismatches and generate deduplicated inline comments.

## Key Features
- Agent-driven code review comparing diffs against MR/PR descriptions to identify intent mismatches
- Supports both GitLab and GitHub platforms with auto-detection
- Generates deduplicated inline comments and MR/PR-level summaries
- Tracks token usage and cost per review run with detailed artifacts
- Modular configuration via CLI flags, environment variables, or config files

## Why It Matters for RAG Builders
It automates high-quality, intent-aware code reviews in CI pipelines, reducing manual effort and improving code consistency while providing actionable feedback to developers.
