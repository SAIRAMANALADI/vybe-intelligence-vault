## Summary
Mokei is a TypeScript toolkit for building, managing, and interacting with Model Context Protocol (MCP) servers and clients. It provides a high-level abstraction for session management, tool calling, and multi-context orchestration, enabling seamless integration with AI model providers like OpenAI, Anthropic, and Ollama.

## Key Features
- Full MCP server and client implementation for protocol compliance
- Multi-context host for managing and namespacing multiple MCP servers
- High-level session management with chat abstraction and tool calling
- Automated agent loop with configurable tool execution and approval
- Real-time monitoring and CLI tools for MCP traffic inspection

## Why It Matters for RAG Builders
Mokei simplifies the integration and orchestration of MCP-compliant tools and servers, making it essential for building scalable and interactive AI applications.
