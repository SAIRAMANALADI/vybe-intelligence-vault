## Summary
Chronis is a Python-based distributed scheduler designed specifically for AI agents and LLM workflows, enabling autonomous scheduling with human-scale timing precision. It supports pluggable storage and locking adapters, timezone awareness, and async-native operation for modern Python environments.

## Key Features
- AI agent-friendly API with minimal configuration for LLM function calling
- Pluggable storage and locking adapters (PostgreSQL, Redis, SQLite, in-memory)
- Human-scale timing with configurable polling intervals for AI workflows
- Distributed execution with no duplicate jobs across containers or processes
- Advanced job management including retries, timeouts, callbacks, and metadata filtering

## Why It Matters for RAG Builders
Chronis enables AI agents to autonomously manage their own schedules and time-based workflows, reducing reliance on external orchestration tools and simplifying integration for RAG and agentic AI systems.
