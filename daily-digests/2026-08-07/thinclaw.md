## Summary
ThinClaw is a self-hosted, privacy-first AI collaborator designed for durable, continuous operation across multiple surfaces. It provides a persistent runtime for memory, routines, tools, and channels, enabling long-term agent identity and context retention.

## Key Features
- Durable agent identity and memory persistence across sessions and surfaces
- Built-in routines, reminders, and background job scheduling with heartbeat monitoring
- Multi-surface access via CLI, TUI, web gateway, and chat channels (Telegram, Discord, Slack, etc.)
- Sandboxed WASM tools and trusted MCP integrations for secure extensibility
- ComfyUI integration for media generation workflows with approval-gated operations

## Why It Matters for RAG Builders
ThinClaw provides a persistent, self-hosted runtime for AI agents that ensures continuity, privacy, and control over memory and tools, making it essential for building robust, production-grade RAG systems.
