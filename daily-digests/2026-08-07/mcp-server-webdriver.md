## Summary
mcp-server-webdriver is an MCP server that enables AI agents to control a real web browser via Selenium WebDriver (Firefox + geckodriver). It bridges the gap between AI assistants and browser automation, allowing agents to navigate, inspect, and interact with web pages programmatically for debugging, testing, and automation tasks.

## Key Features
- Enables AI agents to open, navigate, and interact with web pages via Firefox headlessly or with a real profile
- Provides comprehensive DevTools integration for diagnostics (JS errors, network performance, console output)
- Supports advanced interactions like hover menus, file uploads, session cookie injection, and multi-step form automation
- Offers responsive/mobile testing with viewport resizing and user agent emulation
- Includes session management tools for debugging, testing, and auditing web applications

## Why It Matters for RAG Builders
It eliminates the manual copy-paste loop between browsers and AI assistants, enabling agents to autonomously diagnose, test, and interact with web applications for RAG and AI-driven workflows.
