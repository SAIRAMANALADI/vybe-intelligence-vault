## Summary
Maurice is a local, read-only web explorer for analyzing Claude Code sessions stored in `~/.claude`, providing detailed analytics, cost estimation, and workflow insights by skill, ticket, or branch. It includes an MCP server for programmatic access to session data.

## Key Features
- Interactive dashboard with KPIs, charts, and cost breakdowns by model, skill, or project
- Detailed session explorer with estimated costs, peak context fill, and error tracking
- MCP server for programmatic access to local Claude Code history
- Workflow views pivoted by skill, ticket, or branch with token attribution
- Inline image rendering and prompt-cache rewrite detection for accurate session analysis

## Why It Matters for RAG Builders
Maurice provides critical insights into local AI workflows by analyzing session data, enabling better cost tracking, context window optimization, and workflow efficiency for RAG builders.
