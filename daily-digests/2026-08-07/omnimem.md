## Summary
OmniMem is a five-layer hybrid memory system integrating Ebbinghaus' forgetting curve, FSRS v4 spaced repetition algorithm, and semantic importance analysis for intelligent memory management. It combines multi-dimensional memory strength evaluation with vector-based semantic analysis to optimize knowledge retention and retrieval.

## Key Features
- Five-stage memory lifecycle management (active → consolidating → archived → forgotten)
- FSRS v4 algorithm integration with 85-90% retention prediction accuracy
- Six-dimensional memory strength evaluation (stability, retrievability, difficulty, recency, frequency, semantic importance)
- Semantic importance assessment via vector centerity and knowledge graph analysis
- Interactive HTML dashboard and REST API for memory monitoring and management
