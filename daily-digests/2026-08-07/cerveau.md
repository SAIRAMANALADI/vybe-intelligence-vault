## Summary
Cerveau is a local-first agentic coding harness designed to maximize the efficiency of consumer-grade hardware by leveraging small local MoE models. It integrates a Go-based agent loop with a Svelte control panel and llama.cpp for model serving, emphasizing hardware optimization, structural safety, and failure-aware execution.

## Key Features
- Hardware-aware model execution with expert-split configuration for optimal performance on consumer GPUs
- Structural safety guards enforced in Go, including argument pattern-matching and workspace jailing
- Event-sourced memory system with append-only `events.jsonl` and managed Typesense for recall
- RFX reflexes: declarative capability stack for tool dispatch with fuzz contracts and permission enforcement
- Single-binary deployment with embedded Svelte control panel and runtime introspection of model modalities

## Why It Matters for RAG Builders
Cerveau provides a specialized orchestration layer for local MoE models, addressing their unique failure modes and hardware constraints, enabling efficient agentic coding without cloud dependencies.
