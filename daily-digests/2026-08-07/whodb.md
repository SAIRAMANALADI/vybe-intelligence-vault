## Summary
WhoDB is a lightweight, self-hosted workspace for exploring, editing, and managing databases through a browser-based UI or desktop/CLI applications. It supports a wide range of databases and offers optional AI integration for natural language queries.

## Key Features
- Browser-based database workspace with spreadsheet-style data editing and visualization
- Support for 15+ databases including PostgreSQL, MySQL, MongoDB, Redis, and Elasticsearch
- Interactive schema graph for visualizing table relationships and dependencies
- Optional AI integration for natural language queries via Ollama, OpenAI, Anthropic, or LM Studio
- CLI and MCP server for terminal-based workflows and AI tooling

## Why It Matters for RAG Builders
WhoDB simplifies database exploration and management for AI engineers, enabling seamless integration with RAG pipelines and AI tools through its MCP server and AI provider support.
