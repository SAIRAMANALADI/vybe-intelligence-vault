## Summary
OpenTrip is a collaborative travel planning SaaS that enables users to plan trips together, visualize itineraries on a map, vote on stops, and split expenses. It provides a multi-client API for web and mobile applications with a backend built using Domain-Driven Design and Hexagonal Architecture.

## Key Features
- Real-time collaborative trip planning with shared map visualization
- Multi-client API support for web and mobile applications
- Expense splitting and fair cost distribution among travelers
- Integration with mapping (OSM/Google), lodging (Airbnb), and weather services
- Domain-Driven Design and Hexagonal Architecture for maintainable backend

## Why It Matters for RAG Builders
OpenTrip provides a production-ready template for building collaborative SaaS applications with multi-client support, expense management, and mapping integrations, reducing development time for similar products.
