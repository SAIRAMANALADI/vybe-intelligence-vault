## Summary
A hosted MCP server and REST API providing structured academic conference and journal data for AI agents, including CFP deadlines, rankings (CCF/CORE/QUALIS), acceptance rates, and impact factors. Offers both MCP and REST interfaces with identical payloads for seamless integration.

## Key Features
- Dual MCP and REST interfaces with identical payloads for flexibility in client integration
- Comprehensive academic venue data including CCF, CORE, and QUALIS rankings in a single query
- Incremental sync capability via `updated_since` parameter for efficient data updates
- Free anonymous access with optional API key tier for higher quotas and detailed endpoints
- Pre-built client configurations and examples for popular MCP clients (Claude, Cursor, VS Code, ChatGPT)
