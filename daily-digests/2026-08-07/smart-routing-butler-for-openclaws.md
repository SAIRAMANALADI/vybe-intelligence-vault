## Summary
Smart Routing Butler is a self-hosted, OpenAI-compatible API router designed to intelligently dispatch AI model requests across cloud and local LLMs based on configurable rules. It acts as a local proxy to optimize cost, latency, and quality for AI agents and developer tools.

## Key Features
- OpenAI-compatible local proxy for seamless integration with AI agents and tools
- Multi-layer intelligent routing (L0-L3) with semantic caching and fallback chains
- Visual rule editor and AI-driven rule generation for flexible routing strategies
- Full observability via Next.js dashboard with request logs, token usage, and rule analysis
- 100% self-hosted with AES-256-GCM encrypted API keys for data privacy

## Why It Matters for RAG Builders
It simplifies and optimizes AI model selection for RAG and agent workflows by providing a self-hosted, policy-driven routing layer that balances cost, latency, and quality without exposing data to third parties.
