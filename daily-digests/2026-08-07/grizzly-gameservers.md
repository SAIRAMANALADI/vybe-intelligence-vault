## Summary
A Discord-driven service for automating the deployment and management of game servers on a homelab Kubernetes cluster using Agones. It integrates an LLM-based ops agent (Gary) for automated configuration, monitoring, and self-healing, enabling fully hands-off operation.

## Key Features
- Discord command integration for server lifecycle management
- Automated server deployment and scaling via Agones on Kubernetes
- LLM ops agent (Gary) for dynamic configuration, log analysis, and self-healing
- Cargo workspace with modular crates for bot, supervisor, and control API
