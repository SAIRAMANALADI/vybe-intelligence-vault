## Summary
Pare provides MCP servers that wrap common developer tools (git, npm, Docker, test runners, etc.) to return clean, schema-validated JSON instead of raw terminal text, eliminating fragile CLI parsing for AI agents.

## Key Features
- Schema-validated JSON output for 240+ tools across 28 servers (git, npm, Docker, test runners, etc.)
- Significant token reduction (46-95%) for verbose CLI outputs, improving efficiency in RAG pipelines
- Cross-platform and locale-agnostic structured data, eliminating brittle string parsing
- Modular tool selection via environment variables for fine-grained control
- Integration with MCP clients (Claude, Cursor, VS Code, etc.) for seamless agent workflows

## Why It Matters for RAG Builders
Pare eliminates the fragility of parsing raw CLI output for AI agents by providing structured, schema-validated JSON, ensuring reliable and efficient tool integration in RAG pipelines.
