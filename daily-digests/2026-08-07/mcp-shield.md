## Summary
mcp-shield is a security scanner designed to identify vulnerabilities, prompt injection risks, secrets leaks, and supply chain attacks in Model Context Protocol (MCP) servers. It operates as both a CLI tool and an MCP server, providing detailed security reports for AI engineering workflows.

## Key Features
- 7 specialized security scanners (dependency audit, prompt injection, secrets detection, etc.)
- CLI and MCP server modes for flexible integration
- Concurrent scanning with shared file cache for performance
- Detailed scoring system with PASS/FAIL thresholds for CI/CD pipelines
- Support for terminal, JSON, and Markdown output formats

## Why It Matters for RAG Builders
It proactively secures MCP servers against critical vulnerabilities that could compromise AI agents or downstream systems, ensuring safer AI-driven workflows.
