## Summary
A high-performance Model Context Protocol (MCP) server for Ubiquiti UniFi Dream Machine Pro (UDM Pro/SE) that enables direct local network management via native API keys. It provides 40+ tools for Wi-Fi, VLANs, firewall rules, client control, and system administration with ultra-low latency and 2FA bypass.

## Key Features
- 40+ native MCP tools for full network administration (Wi-Fi, VLANs, firewall, clients, QoS)
- Direct local API key authentication (10–30ms latency, no 2FA or session expiry)
- Privacy-first design with 100% local execution and no cloud telemetry
- Automatic SSL handling for self-signed certificates on local UniFi consoles
- Multi-client support (Claude Desktop, VS Code, Cursor, Windsurf, Antigravity)

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and manage UniFi UDM Pro networks locally, bypassing cloud dependencies and providing real-time network control for RAG systems.
