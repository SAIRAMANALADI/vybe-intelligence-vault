## Summary
Forge by Foundry Labs is an industrial Machine Intelligence MCP server that enables natural language interaction with CNC machines, robots, and other industrial equipment across 18 OEM families. It normalizes telemetry, automates plain-English instructions, and records tamper-evident work records via a hosted MCP over Streamable HTTP.

## Key Features
- Cross-manufacturer telemetry normalization (18 OEM families) into a canonical schema
- Plain-English automation activation and management (30+ tools)
- Tamper-evident work records for auditability and compliance
- Predictive maintenance using TimesFM for failure prediction and fleet health scoring
- Hosted MCP over Streamable HTTP with free tier and metered premium features
