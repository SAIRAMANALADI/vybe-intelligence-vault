## Summary
An unofficial self-hosted Progressive Web App (PWA) client for Anthropic's Claude Code CLI, enabling users to interact with Claude Code from a smartphone via a Tailscale-secured connection. The backend runs on the user's host machine, launching the Claude CLI as a real PTY + tmux subprocess, while the frontend provides a mobile-friendly interface with features like chat, notifications, file previews, and optional desktop screen sharing.

## Key Features
- Multi-session chat with incremental SSE rendering and tab switching
- Background continuation and push notifications for proactive prompts
- Terminal prompt detection with quick-reply buttons and file preview
- Subagent/workflow viewer and conversation forking with hierarchical threading
- Optional desktop screen sharing via Sunshine and moonlight-web-stream

## Why It Matters for RAG Builders
It provides a mobile-friendly, self-hosted interface for Anthropic's Claude Code CLI, enabling developers to interact with AI agents on-the-go while maintaining full control over their data and subscriptions.
