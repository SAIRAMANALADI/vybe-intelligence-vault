## Summary
AIWorkHub is an open-source, local-first control plane for orchestrating multi-model AI coding agents in VS Code and MCP environments. It coordinates tasks across models like Codex, Claude, Copilot, DeepSeek, and GLM with dependency-aware task graphs, durable project memory, and evidence-based review.

## Key Features
- Dependency-aware task orchestration with DAGs for safe multi-model workflows
- Durable project memory and repository-scoped state isolation
- Source Graph for structural code intelligence and bounded context queries
- Manager Context Graph for deterministic evidence tracking and review
- Economic routing of tasks to models based on capability, cost, and quality

## Why It Matters for RAG Builders
AIWorkHub provides a critical orchestration layer for RAG builders by enabling safe, efficient, and evidence-driven multi-model agent workflows in local development environments.
