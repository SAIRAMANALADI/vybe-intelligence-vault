## Summary
A controllable multi-source search MCP server enabling AI agents to query 25+ platforms (Reddit, X, YouTube, Hacker News, GitHub, arXiv, Chinese sources, etc.) with customizable time windows, source selection, and synthesis options. Designed as an open replacement for the closed `last30days` server.

## Key Features
- Parallel multi-source search across 25+ platforms with engagement-based scoring
- Customizable time windows (e.g., 7 days, 180 days) and source selection
- Optional LLM synthesis for concise, cited briefs or raw scored results for agent reasoning
- Supports Chinese platforms (雪球, V2EX, B站, 小宇宙) alongside Western sources
- Polite scraping with rate limiting, retry logic, and credential-based access control

## Why It Matters for RAG Builders
It provides AI agents with a flexible, open-source alternative to closed search MCP servers, enabling controlled, multi-source data retrieval and synthesis for RAG pipelines.
