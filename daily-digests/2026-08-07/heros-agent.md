## Summary
A platform that automatically discovers LLM call graphs in codebases, generates and verifies optimization proposals (e.g., prompt tuning, model selection), and delivers them as pull requests with statistical proof of improvement. Operates as a 'Dependabot for LLM cost and quality' with sandboxed execution and multi-seed evaluation.

## Key Features
- Automated discovery of LLM call graphs with static and dynamic analysis
- Sandboxed runtime execution with full tracing and OpenTelemetry integration
- Multi-seed statistical evaluation with confidence intervals for optimization verification
- Source transformation via AST codemods to generate reviewable diffs as pull requests
- Three delivery surfaces: CLI/CI, Git App/bot, and hosted web dashboard

## Why It Matters for RAG Builders
It automates the tedious and error-prone process of optimizing LLM workflows, ensuring measurable improvements in cost and quality while maintaining full auditability and control.
