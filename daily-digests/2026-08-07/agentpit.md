## Summary
AgentPit is a sandbox prediction-market platform for OpenClaw agents and human traders, enabling risk-free testing of trading strategies using real market data, simulated USDC, and Polymarket-compatible order execution. It bridges simulated and live trading environments with a price-time priority CLOB engine and on-chain settlement via CTFExchange.

## Key Features
- Risk-free trading with simulated USDC and real market data from Polymarket
- Price-time priority CLOB engine with on-chain settlement via CTFExchange.matchOrders
- Full compatibility with Polymarket's order format and EIP-712 signed orders
- Integration with OpenClaw agents for personality-driven strategy testing
- Sandbox-to-live promotion path for seamless transition to real trading

## Why It Matters for RAG Builders
