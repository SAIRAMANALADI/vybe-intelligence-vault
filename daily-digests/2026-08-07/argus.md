## Summary
Argus is an AI-powered QA layer that audits AI-generated code by driving a real Chrome browser via the Chrome DevTools Protocol, providing structured bug reports without requiring manual test files. It integrates seamlessly with MCP clients like Claude to enable automated agentic QA loops.

## Key Features
- Real Chrome auditing via DevTools Protocol with 149+ finding types across performance, accessibility, security, and SEO
- Agentic QA loop integration with MCP tools like `argus_audit`, `argus_compare`, and `argus_get_context` for iterative fixes
- Aegis redaction system to prevent sensitive data leakage in LLM contexts (OWASP LLM02 compliant)
- Baseline-aware PR validation for targeted QA gates that block merges only on regressions introduced by PRs
- Framework-agnostic auditing of rendered apps (SPAs, server-rendered, static sites) with optional framework-aware route mapping

## Why It Matters for RAG Builders
Argus closes the critical gap between AI-generated code and real-world quality by providing automated, agent-driven QA that catches issues like uncaught exceptions, security vulnerabilities, and performance regressions before code is deployed.
