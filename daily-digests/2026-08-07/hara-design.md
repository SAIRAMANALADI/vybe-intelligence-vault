## Summary
hara-design transforms plain language design briefs into interactive, brand-grade HTML prototypes using 150 design systems, previewed live in the browser. It integrates with agent frameworks like hara, Claude Code, or Codex to generate self-contained deliverables for landing pages, dashboards, or app prototypes.

## Key Features
- Generates interactive HTML prototypes from natural language briefs using 150 design systems
- Live-reload preview server for real-time iteration and feedback
- Self-contained deliverables with design tokens and component breakdowns for handoff to frontend agents
- Supports multiple agent frameworks (hara, Claude Code, Codex) via a unified CLI tool
- Includes anti-AI-slop critique and quality checklists to ensure design fidelity

## Why It Matters for RAG Builders
It bridges the gap between AI-generated design briefs and production-ready prototypes by automating the creation of interactive, brand-compliant HTML deliverables for RAG and AI stack builders.
