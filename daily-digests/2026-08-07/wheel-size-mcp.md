## Summary
An official MCP server providing LLM agents with access to vehicle wheel and tire compatibility data via the Wheel Fitment API. Enables queries like OEM specs, rim/tire fitment checks, and plus-size calculations for automotive applications.

## Key Features
- 21 specialized tools for vehicle catalog, fitment search, and classified data retrieval
- Supports both stdio and HTTP transport modes for flexible deployment
- Pre-built prompts for multi-step workflows (e.g., vehicle fitment lookup, product card generation)
- Automated evaluation suite with 89 test questions to validate tool behavior and API interactions
- Strict adherence to API terms of service with user-initiated search tool restrictions
