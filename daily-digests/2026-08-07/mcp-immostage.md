## Summary
A Model Context Protocol (MCP) server that provides AI-powered virtual staging for real estate, enabling photorealistic furniture staging, marketing package generation, and asset downloads for property listings in the DACH market.

## Key Features
- AI-powered virtual staging for empty rooms with photorealistic furniture
- Generates full marketing packages (social media posts, Exposé PDF, property video)
- Seamless integration with MCP clients like Claude Desktop
- Self-service API key generation with free tier and paid plans
- Async job processing with polling for staged image and marketing assets
