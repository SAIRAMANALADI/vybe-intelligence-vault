## Summary
mcp-xero is an MCP (Model Context Protocol) server that provides AI agents with access to Xero accounting data, enabling seamless integration with financial systems. It acts as a gateway to retrieve invoices, contacts, financial reports, and other accounting data from Xero organizations.

## Key Features
- Provides MCP-compliant tools for Xero data access (invoices, contacts, financial reports)
- Supports multi-tenant Xero organizations with tenant discovery
- Enables plain English queries via Pipeworx gateway for automated tool selection
- Includes pagination and filter support for large datasets
- Open-source with MIT license for easy adoption

## Why It Matters for RAG Builders
It bridges AI agents with real-time Xero accounting data, enabling automated financial workflows and bookkeeping tasks.
