## Summary
An n8n workflow that acts as an AI agent for stock portfolio management, reading transaction ledgers, fetching market data, calculating portfolio snapshots, and logging confirmed transactions to Google Sheets via an interactive confirmation protocol.

## Key Features
- Agentic tool selection with OpenAI chat model for conversational context
- Automated portfolio snapshot calculation using end-of-day market data
- Interactive confirmation protocol before logging transactions to Google Sheets
- Built-in calculator for portfolio arithmetic and transaction previews
- Credential-free, portable workflow export with automated validation
