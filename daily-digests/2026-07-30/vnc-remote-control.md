## Summary
A command-line tool for remote control of VNC/RFB servers, enabling text input, key presses, clicks, screenshots, and OCR-based interactions. It operates as a pure client with no footprint on the target machine, making it ideal for automating legacy GUI applications or headless VMs.

## Key Features
- Pure client-side operation with no target-side footprint (no agent, service, or open ports)
- Supports typing, key presses, clicks, screenshots, and OCR-based interactions
- Works with any VNC/RFB server (None or VNC-password security, raw encoding)
- Layout-aware server compatibility (e.g., openvmm) for reliable text input
- OCR integration for screen text detection and click-by-label functionality

## Why It Matters for RAG Builders
Enables AI agents to interact with legacy GUI applications or headless systems via VNC without requiring any software installation on the target machine.
