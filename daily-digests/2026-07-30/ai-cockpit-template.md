## Summary
AI Cockpit is a governance layer for AI-assisted software development that enforces evidence-based review, verification, and auditability of AI-generated changes. It acts as a repository governance boundary to prevent scope drift, unauthorized modifications, and unchecked AI agent actions.

## Key Features
- Scope and boundary enforcement for AI-generated changes to prevent unauthorized file modifications
- Independent verification of changes against declared contracts and intent
- Comprehensive audit trails with change summaries, risk assessments, and verification evidence
- Calibrated trust model enabling human oversight based on reviewable evidence rather than agent confidence
- Integration with popular AI coding tools (Codex, Gemini, Claude, Cursor, Antigravity) for seamless adoption

## Why It Matters for RAG Builders
AI Cockpit provides a critical governance layer for RAG/AI stack builders by ensuring AI-generated changes are bounded, reviewable, and auditable, reducing risks of scope drift and unauthorized modifications in production environments.
