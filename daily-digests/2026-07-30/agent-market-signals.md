## Summary
Boardcheck (agent-market-signals) is an open standard and reference implementation for auditing AI agent marketplaces to detect deceptive practices like fabricated engagement, automated seeding, and unpaid work risks. It provides a dependency-free Python library, CLI tool, and MCP server for real-time vetting of marketplace listings.

## Key Features
- Open standard with stable indicator IDs (AMS-001 to AMS-005) for reproducible checks
- Dependency-free Python implementation usable as a library, CLI, or MCP server
- Public audits of real AI agent marketplaces with reproducible evidence
- Privacy-preserving optional data contribution for improving thresholds
- Machine-readable verdicts (high_risk, caution, clear) with detailed findings

## Why It Matters for RAG Builders
It provides essential tools for RAG/AI stack builders to vet AI agent marketplaces for deceptive practices before deploying agents or relying on marketplace data.
