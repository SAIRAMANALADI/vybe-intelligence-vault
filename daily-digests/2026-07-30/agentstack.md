## Summary
AgentStack provides a local control plane for managing AI agents' MCP tools, enabling centralized configuration, trust-gating, firewalling, and auditing of tool calls across multiple agent CLIs. It simplifies setup, enforces security policies, and ensures reproducibility with a single manifest file.

## Key Features
- Centralized manifest for servers, skills, instructions, and profiles across 13+ agent CLIs
- Trust-gating and firewalling of MCP tool calls with audit logging
- Machine-level and project-level policy enforcement for security
- Central library for reusable skills and servers with content scanning
- Transparent proxy mode for monitoring tool usage and costs

## Why It Matters for RAG Builders
AgentStack streamlines and secures AI agent tooling by providing a unified, reproducible, and auditable control plane for MCP servers and skills across multiple agent CLIs.
