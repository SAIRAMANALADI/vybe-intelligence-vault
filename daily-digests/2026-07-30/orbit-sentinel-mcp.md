## Summary
A Model Context Protocol (MCP) server providing access to Orbit Sentinel's space regulatory filings database, enabling querying of 419,000+ documents from FCC, ITU, UNOOSA, and FAA-AST via MCP-compatible clients like Claude Desktop or Cursor.

## Key Features
- Provides access to 419,000+ space regulatory filings from major global agencies
- Compatible with MCP clients like Claude Desktop, Claude Code, and Cursor
- Supports multiple installation methods (one-click, Homebrew, manual, source build)
- Lightweight implementation (5 Go files) for easy auditing and transparency
- Automated CI/CD pipeline with multi-platform releases
