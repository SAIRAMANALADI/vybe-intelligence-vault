## Summary
Pixara MCP Server provides an MCP-compatible interface to OpenRouter's Image API, enabling LLMs to generate, edit, and transform images using various AI models through standardized tools.

## Key Features
- Direct integration with OpenRouter's Image API for image generation and editing
- Four standardized MCP tools for seamless LLM interaction
- Model catalog browsing with filtering and pagination
- Automatic image decoding and saving to disk with configurable output paths
- Clear error handling for common failure modes like rate limits or invalid parameters

## Why It Matters for RAG Builders
It enables LLMs to dynamically generate and edit images via standardized MCP tools, expanding AI capabilities for applications requiring visual content.
