## Summary
CommandNest is a lightweight desktop AI assistant application for Windows that integrates with external AI models via OpenRouter, enabling users to access AI-powered features like coding support, document summarization, and workflow management directly from their desktop with global hotkeys and streaming responses.

## Key Features
- Global hotkey activation for instant AI access
- Streaming responses mimicking human typing
- Model Context Protocol for local file integration
- Privacy-focused with no external data storage
- Supports multiple AI models via OpenRouter
