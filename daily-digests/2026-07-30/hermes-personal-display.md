## Summary
A local, browser-based companion display for the Hermes Agent that transforms a small screen into an ambient status panel for AI operators. It provides a kiosk UI to visualize agent activity, tool use, health, and state without exposing raw prompts or logs.

## Key Features
- Ambient status panel for Hermes Agent with real-time state visualization (idle, active, degraded, etc.)
- Display-safe state packets and event contracts to prevent leakage of raw prompts or logs
- Character runtime with SVG-based mascot animations and touch/entertainment hooks
- Local kiosk deployment via systemd user services with hardware-agnostic setup
- Privacy-first architecture with loopback defaults, allowlisted events, and fixture-based testing

## Why It Matters for RAG Builders
It provides a privacy-safe, ambient interface for monitoring local AI agents, enabling trust and transparency without exposing sensitive data.
