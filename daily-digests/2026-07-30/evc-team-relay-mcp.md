## Summary
EVC Team Relay MCP is a Model Context Protocol (MCP) server that enables AI agents to read and write to an Obsidian vault via the Team Relay API. It bridges AI tools like Claude Code and Codex CLI with a user's knowledge base for seamless synchronization.

## Key Features
- Provides MCP-compatible tools for AI agents to interact with Obsidian vaults via Team Relay
- Supports real-time synchronization between AI agents and Obsidian using Yjs CRDT
- Offers secure authentication via agent keys or email/password with automatic token management
- Supports both stdio and HTTP transport modes for local and remote deployments
- Includes tools for reading, writing, updating, and deleting files in Obsidian vaults

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and update knowledge bases like Obsidian vaults, enhancing RAG systems with real-time, bidirectional synchronization.
