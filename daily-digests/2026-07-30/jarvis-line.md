## Summary
Jarvis Line provides voice notifications for AI coding agents by converting agent events into concise spoken updates via hook-driven TTS. It routes these updates through a session-aware audio queue, enabling hands-free monitoring of agent progress without constant screen watching.

## Key Features
- Converts agent events into short, spoken status updates for hands-free monitoring
- Session-aware audio queue with stale-job and overlap protection
- Supports multiple TTS engines including Kokoro, system voices, and custom commands
- Provides opt-in attention alerts for permission requests and input requests
- Includes a Preview macOS manager with guided setup and voice controls

## Why It Matters for RAG Builders
Jarvis Line enhances AI agent workflows by providing real-time, audible feedback, reducing the need for constant screen monitoring and improving developer productivity.
