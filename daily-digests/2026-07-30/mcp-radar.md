## Summary
mcp-radar is a static GitHub Pages site that auto-updates a directory and JSON endpoint (`servers.json`) of MCP servers by aggregating data from curated sources and regenerating it daily via GitHub Actions.

## Key Features
- Auto-updates a directory of MCP servers daily via GitHub Actions
- Provides a browsable static site and a consumable JSON endpoint
- Aggregates data from multiple MCP server sources (best-of-mcp-servers, mcp-servers-hub)
- Uses GitHub API with built-in `GITHUB_TOKEN` for efficient and ethical scraping
- Simple deployment via GitHub Pages with minimal setup

## Why It Matters for RAG Builders
It provides a centralized, auto-updated directory of MCP servers that can be consumed by AI agents or tools, simplifying discovery and integration for RAG builders.
