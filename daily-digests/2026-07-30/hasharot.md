## Summary
Hasharot is a self-hosted AI agent framework that bridges Telegram with a full Claude Code agent running locally on your machine. It enables users to control a powerful AI assistant via Telegram, executing commands, editing files, browsing the web, and handling voice interactions while keeping all data private and on-device.

## Key Features
- Full Claude Code agent with tool access (Bash, file I/O, code editing, web browsing) running locally
- Multi-user team workflow with per-user sandboxing, owner approvals, and parallel sessions per Telegram topic
- Voice-to-text and text-to-speech integration for hands-free interaction
- Rich output formatting with MarkdownV2, Telegraph Instant View, and streaming responses
- Paperclip integration for delegating tasks to autonomous agents with two-way Telegram notifications

## Why It Matters for RAG Builders
Hasharot provides a secure, self-hosted way to control a powerful AI agent via Telegram, enabling teams to collaborate on code and tasks without exposing data to third-party APIs.
