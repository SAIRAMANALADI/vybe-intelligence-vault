## Summary
Skill Router G6 is a self-learning skill router for AI agents that dynamically selects the best skills to execute based on user queries. It operates as a model-agnostic MCP server with two modes: harness injection for seamless integration or direct MCP tool calls for flexible deployment.

## Key Features
- 6-stage routing pipeline with ~120ms latency
- Self-learning via Beta posteriors from task outcomes
- 5-layer anti-hallucination defense mechanism
- Model-agnostic MCP server supporting harness injection or direct tool calls
- Handbook-based competence validation and diversity-aware skill selection

## Why It Matters for RAG Builders
It enables AI agents to dynamically select and execute the most relevant skills for user queries while improving over time through self-learning feedback loops.
