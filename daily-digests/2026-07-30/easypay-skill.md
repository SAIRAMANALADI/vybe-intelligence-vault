## Summary
EasyPay AI Skill enables AI agents to process natural language payment commands (e.g., Stripe, crypto, bank transfers) via 21 MCP tools, bridging AI workflows with EasyPay's payment infrastructure. It simplifies integration by providing domain-specific vocabulary and pre-configured tooling for agents like Claude Code, Cursor, Codex, and Gemini CLI.

## Key Features
- 21 pre-configured MCP tools for payment operations (Stripe, crypto, bank transfers)
- Natural language command processing for AI agents (e.g., 'Create a Stripe product for $299/month')
- Seamless integration with Claude Code, Cursor, Codex, and Gemini CLI via one-command installation
- Domain-specific vocabulary and anti-pattern guidance in SKILL.md for AI agents
- Identity controls for secure payout operations (mini-app session required)
