## Summary
CasperGuard is a real-time AI security firewall for autonomous transactions on the Casper Network, designed to approve low-risk transactions and block high-risk ones using x402 micropayments and threshold-based auto-pause mechanisms.

## Key Features
- Real-time AI-driven transaction risk scoring with auto-approval/blocking
- x402 micropayment integration for per-scan fees (0.1 CSPR)
- MCP Server for live blockchain tools accessible to AI agents
- Threshold-based emergency contract pausing for threat mitigation
- GitPaid integration for ETH bounties rewarding open-source contributors

## Why It Matters for RAG Builders
CasperGuard provides a critical security layer for AI agents executing transactions, preventing financial losses from compromised or malicious agents through real-time risk assessment and on-chain enforcement.
