## Summary
bankstatementparser-mcp is an MCP (Model Context Protocol) server that exposes the bankstatementparser library as agent tools for parsing, validating, and summarizing bank statements in formats like ISO 20022 CAMT.053, SWIFT MT940, OFX/QFX, and CSV. It enables AI agents to interact with bank statements directly via MCP clients.

## Key Features
- Exposes bank statement parsing as MCP tools for AI agents
- Supports multiple formats (CAMT.053, MT940, OFX/QFX, CSV)
- Validates and summarizes bank statements with structured JSON output
- Runs as a lightweight MCP server over stdio with zero filesystem sharing
- Integrates seamlessly with MCP clients like Claude Desktop

## Why It Matters for RAG Builders
It enables AI agents to directly parse and analyze bank statements in real-time, enhancing financial data integration and automation in RAG systems.
