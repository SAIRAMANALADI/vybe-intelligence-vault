## Summary
Wenlan is a living personal knowledge library designed for AI-native workflows, enabling AI agents to capture, refine, and distill context into source-cited wiki pages between sessions. It integrates with MCP clients and local daemons to maintain a current, trustworthy knowledge base for long-running agent work.

## Key Features
- Real-time agent capture with source citations and metadata for trustworthiness
- Background distillation of atomic memories into structured wiki pages between sessions
- Hybrid retrieval system combining vector embeddings, full-text search, and graph context
- Git-versioned local storage under `~/.wenlan/` for data ownership and version control
- Cross-platform MCP server supporting Claude Code, Codex, Cursor, and other clients

## Why It Matters for RAG Builders
Wenlan provides a critical infrastructure layer for RAG systems by ensuring long-term, source-backed context retention and retrieval, reducing hallucinations and improving agent consistency across sessions.
