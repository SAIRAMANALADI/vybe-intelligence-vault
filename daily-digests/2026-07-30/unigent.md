## Summary
Unigent is a TypeScript SDK for building stateful, cross-session agent workflows with typed outputs, reusable tools, and session forks. It enables developers to create agent-based applications using ordinary TypeScript while supporting multiple AI backends like Pi, Claude CLI, and Codex CLI.

## Key Features
- Cross-harness and cross-session agent support with typed outputs
- Reusable tools with TypeScript signatures and JSDoc integration
- Session forks and stateful workflows with scoped grouping
- Structured output via Standard Schema validators (e.g., Zod)
- CLI for running and inspecting agent scripts with a TUI trace inspector

## Why It Matters for RAG Builders
Unigent simplifies the development of stateful, multi-agent workflows with typed outputs and reusable tools, making it essential for building scalable AI applications that require structured interactions and session management.
