## Summary
MobileClaw is a mobile-first chat UI designed for OpenClaw and LM Studio, offering a responsive and visually polished interface optimized for local LLM interactions. It provides real-time streaming, tool call execution, and embeddable widget support.

## Key Features
- Real-time streaming with rich markdown rendering (code blocks, tables, lists)
- Live tool execution with inline diffs and smooth animations
- Expandable reasoning blocks for model chain-of-thought visibility
- Embeddable widget mode for seamless integration into any webpage
- LM Studio support for local model interactions without cloud dependency
