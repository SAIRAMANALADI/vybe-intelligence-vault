## Summary
ShibaClaw is a security-first, self-hosted AI agent framework designed to 'just work' out of the box with minimal configuration. It supports 23 providers, 11 chat channels, and includes a built-in WebUI, desktop app, and MCP integration for secure, private agent interactions.

## Key Features
- Built-in WebUI and Windows desktop app for seamless access across devices
- Security layers including CVE audits, prompt-injection wrapping, and SSRF protection
- Native support for 23 providers with official SDKs (no proxy layer required)
- 3-level memory system with proactive learning and auto-compaction
- MCP server integration for tool auto-registration and extensibility
