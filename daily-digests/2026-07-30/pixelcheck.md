## Summary
PixelCheck is an MCP-compatible server that provides AI agents with real-time browser primitives for visual inspection, interaction, and evaluation of web applications. It enables agents to 'see' rendered pages, perform actions, extract structured data, and audit UX across diverse personas and locales.

## Key Features
- Five MCP-compatible primitives (see, act, extract, judge, compare) for AI agents to interact with web UIs
- 18 built-in personas across 15 countries for realistic UX auditing
- Local-first, vendor-agnostic architecture with zero telemetry or SaaS dependency
- AI-powered visual critique and WCAG accessibility auditing via axe-core
- Structured audit reports with screenshots, videos, and multi-dimensional scoring

## Why It Matters for RAG Builders
PixelCheck bridges the gap between AI agents and real-world UI evaluation, enabling autonomous audits of user experience, accessibility, and localization without manual intervention.
