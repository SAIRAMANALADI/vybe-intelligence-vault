## Summary
Extracto is a self-hosted document processing pipeline that converts PDFs and images into structured, retrievable knowledge for RAG systems. It supports multi-model OCR, cloud integrations, and multiple output formats while prioritizing privacy and local control.

## Key Features
- End-to-end document ingestion from PDFs, images, or cloud storage (Dropbox, Google Drive, OneDrive)
- Multi-model OCR support with local or hosted vision models (Ollama, Mistral OCR, OpenAI-compatible)
- Post-processing with LLM-based cleaning and structured output (markdown, JSON, DOCX, etc.)
- Direct integration with vector databases (Chroma, Qdrant, Weaviate, etc.) for RAG pipelines
- Multiple access surfaces: REST API, MCP server, CLI, OpenAI-compatible adapter, and browser UI

## Why It Matters for RAG Builders
Extracto streamlines the critical document-to-RAG pipeline by providing a self-hosted, privacy-focused solution that integrates seamlessly with existing AI stacks and vector databases.
