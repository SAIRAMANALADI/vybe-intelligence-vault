## Summary
Chennai is a hybrid AI agent and terminal user interface for static analysis, data-flow tracing, and AI-assisted code and security review across multiple programming languages and compiled binaries. It integrates multiple static-analysis backends (atom, rusi, golem, dosai, blint) into a single keyboard-driven TUI with an LLM-powered agent for interactive exploration and vulnerability analysis.

## Key Features
- Multi-language static analysis with language-specific backends (atom, rusi, golem, dosai, blint)
- LLM-powered AI agent with grounded tool calls for code exploration and vulnerability analysis
- Interactive terminal UI with REPL-driven querying and command history
- Data-flow analysis with source-to-sink tracing and graph algorithms (PageRank, SCC, etc.)
- Supports binaries, Android APKs, and iOS IPAs with hardening and capability reviews

## Why It Matters for RAG Builders
Chennai provides a unified, AI-assisted interface for deep static analysis and data-flow tracing across languages and binaries, enabling RAG builders to ground LLM responses in precise, structured code insights without leaving the terminal.
