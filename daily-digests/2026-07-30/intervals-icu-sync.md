## Summary
A Python project and MCP server for synchronizing cycling training data with intervals.icu, enabling AI-powered coaching workflows. It fetches activity metrics, analyzes training quality, and allows AI-generated training plans to be uploaded back to intervals.icu.

## Key Features
- Fetches raw activity and wellness data from intervals.icu via API
- Analyzes training quality using Joe Friel's principles (FTP, VO2Max, CTL/ATL, HRV)
- Provides system prompts and coaching logic for AI assistants
- Supports local Python scripts and a hosted MCP server for zero-install setup
- Enables bidirectional synchronization: fetch data, analyze, generate plans, and upload back to intervals.icu

## Why It Matters for RAG Builders
It bridges AI coaching tools with structured training data, enabling automated, data-driven cycling coaching workflows that can be integrated into RAG pipelines for personalized training recommendations.
