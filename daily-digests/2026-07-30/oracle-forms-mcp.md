## Summary
An MCP server that exposes Oracle Forms modules (.fmb, .mmb, .pll, .olb) as structured, queryable content for AI assistants, enabling legacy modernization, reverse engineering, and code review without requiring Oracle Forms Builder.

## Key Features
- Converts binary Oracle Forms modules (.fmb, .pll, etc.) into structured XML and PL/SQL for AI consumption
- Provides tools to inspect blocks, triggers, program units, and raw object XML without Oracle Forms Builder
- Supports fingerprint-based caching for efficient re-indexing and change detection
- Offers both stdio and HTTP transport modes for MCP client integration
- Includes a Docker image for deployment in environments without Oracle Forms tools

## Why It Matters for RAG Builders
It unlocks critical legacy Oracle Forms logic for modern AI tooling, enabling faster modernization, code review, and documentation of decades-old business processes.
