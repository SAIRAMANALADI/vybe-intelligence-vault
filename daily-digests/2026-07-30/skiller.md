## Summary
Skiller is a desktop application that centralizes the installation, management, and synchronization of AI agent skills across 44+ supported agents, including Claude Code, Cursor, and Codex. It provides a unified dashboard for tracking, editing, and propagating skills with project-scoped configurations and marketplace integrations.

## Key Features
- Centralized dashboard for managing skills across 44+ AI agents with real-time visibility
- One-click skill installation and propagation to all supported agents
- Project-scoped skill configurations to avoid global pollution
- Integrated marketplace for discovering and installing community skills
- Auto-update functionality with background version checks and one-click restarts

## Why It Matters for RAG Builders
Skiller eliminates the repetitive and error-prone task of managing skills separately for each AI agent, enabling RAG builders to maintain consistency and efficiency across their agent stack.
