## Summary
A Model Context Protocol (MCP) server for Clockify, enabling natural language control of time tracking, projects, tasks, and clients directly from Claude Code or any MCP-compatible client.

## Key Features
- Enables natural language control of Clockify via MCP-compatible clients like Claude Code
- Supports full CRUD operations for time entries, projects, tasks, tags, and clients
- Provides granular permissions to restrict destructive actions
- Integrates seamlessly with Clockify's free tier and API
- Includes robust security practices for API key handling
