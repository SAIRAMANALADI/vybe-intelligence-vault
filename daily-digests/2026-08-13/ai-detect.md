## Summary
ai-detect is an open-source, local AI text detector that scores writing sentence-by-sentence using a DeBERTa-v3-large model or a lightweight RoBERTa alternative. It runs entirely offline on user hardware, ensuring client confidentiality and reproducibility without API costs or data transmission.

## Key Features
- Local, offline AI text detection with no data transmission or API costs
- Sentence-level scoring with pattern diagnostics and rewrite suggestions
- Supports two models: DeBERTa-v3-large (default) and lightweight RoBERTa-ONNX
- Available as CLI, Python package, and MCP server for integration with AI workflows
- Provides reproducibility with pinned model checkpoints and batch processing

## Why It Matters for RAG Builders
It enables confidential, cost-effective, and reproducible AI text detection for RAG pipelines without relying on third-party hosted services.
