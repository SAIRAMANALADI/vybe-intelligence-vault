## Summary
VidXP is a local-first video search engine that enables users to search videos by dialogue, scenes, and recurring faces. It supports CLI, desktop, Docker, and MCP integrations for AI agents, providing natural language search and inspectable evidence for video content.

## Key Features
- Natural language search for dialogue and scenes within videos
- Actor grouping and face recognition for recurring individuals
- Multiple deployment options: CLI, desktop app, Docker, and MCP server
- Integration with AI agents via MCP for evidence-based responses
- Local-first architecture ensuring data privacy and offline capability

## Why It Matters for RAG Builders
VidXP enables AI agents to search and retrieve evidence from video libraries with natural language queries, reducing token costs and improving contextual understanding for RAG systems.
