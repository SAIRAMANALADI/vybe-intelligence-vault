## Summary
Forge is an AI-powered product development lifecycle (PDLC) automation plugin for Codex that routes user requests (e.g., feature requests, bug fixes) through structured workflows via a hosted MCP server. It enables automated workflows for product development tasks like planning, reviewing, and implementing changes.

## Key Features
- Structured PDLC workflows for AI-driven task routing and execution
- Hosted Forge MCP server for seamless integration with Codex
- Customizable workflows via `forge-workflow` skill for admins
- Lifecycle hooks for session routing, state tracking, and guardrails
- Token usage capture and session feedback integration for observability

## Why It Matters for RAG Builders
Forge enables AI agents to automate and orchestrate complex product development workflows, reducing manual intervention and improving consistency in task execution for RAG builders.
