## Summary
A modular terminal AI agent framework with 35+ specialist agents, 600+ tools, and 20+ AI providers, designed for multi-domain tasks including science, finance, security, and creative workflows. It includes a POSIX-like OS substrate (agent-os), provenance engineering for regulated industries, and orchestration pipelines for multi-agent systems.

## Key Features
- 35+ specialist agents with auto-routing for domain-specific tasks
- 600+ built-in tools spanning code, research, finance, security, and creative workflows
- 20+ AI providers with zero lock-in and offline/local model support
- agent-os: POSIX-like substrate for AI agents with capabilities, namespaces, quotas, audit, and vault
- Built-in MCP server for integration with IDEs and tools like Claude Code, Cursor, and VS Code

## Why It Matters for RAG Builders
It provides a comprehensive, open-source foundation for building and orchestrating AI agents with built-in provenance, security, and multi-provider flexibility, critical for scalable RAG and autonomous systems.
