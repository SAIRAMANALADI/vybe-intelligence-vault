## Summary
loki-auto is a lightweight, zero-dependency browser automation runtime that executes transient LLM tool actions inside a secure Rhai VM sandbox compiled to WebAssembly. It enables serverless, in-browser automation with synchronous DOM interactions, bypassing heavy headless browser overhead.

## Key Features
- Ultra-lightweight, zero-dependency runtime for browser automation
- Secure Rhai VM sandbox compiled to WebAssembly for isolation
- Synchronous DOM interactions with human-like typing delays
- MCP-compliant tool bindings for seamless LLM integration
- Cross-browser support (Chrome/Firefox) with extension-based deployment

## Why It Matters for RAG Builders
It provides a secure, lightweight, and MCP-compliant way to execute browser automation tasks directly in the browser, reducing overhead and enabling seamless LLM-driven interactions.
