## Summary
MendAPI is a tool that proactively monitors upstream API providers for breaking changes, scans codebases to detect impacted files and symbols, and automatically generates fix pull requests to prevent integration failures. It operates entirely locally or in CI, ensuring no code leaves the user's machine.

## Key Features
- Monitors 20+ major API providers for breaking changes via SDK feeds and changelogs
- Locally scans codebases to pinpoint exact files, lines, and symbols impacted by changes
- Generates deterministic, reviewable fix diffs with zero false positives
- Operates entirely offline with no network code in scanner or fixer by default
- Integrates with AI coding agents via MCP for autonomous maintenance

## Why It Matters for RAG Builders
MendAPI ensures AI and RAG stack builders avoid costly integration failures by proactively detecting and fixing upstream API breaking changes before they impact production systems.
