## Summary
A hosted MCP server that provides persistent memory for AI agents, enabling them to learn, forget, and recall context across sessions and tools. It integrates seamlessly with popular AI clients like Claude, Cursor, and VS Code via a single API key.

## Key Features
- Persistent memory storage for AI agents across sessions and tools
- Feedback-based reranking of memories to prioritize useful information
- Recency-based forgetting mechanism to manage memory decay
- Seamless integration with multiple AI clients (Claude, Cursor, VS Code, etc.)
- Hosted service with no infrastructure requirements for users

## Why It Matters for RAG Builders
It enables AI agents to retain and recall context over time, reducing the need for repetitive explanations and improving the coherence of interactions across different tools and sessions.
