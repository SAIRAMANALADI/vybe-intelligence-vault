## Summary
A Dart MCP server and Flutter package enabling AI agents to inspect, interact with, and control running Flutter applications in real-time through a closed feedback loop, including dynamic tool registration and semantic snapshots.

## Key Features
- Enables AI agents to inspect and drive Flutter apps via MCP tools (semantic snapshots, widget tapping, form filling, hot-reload, log reading)
- Supports dynamic tool and resource registration at runtime for Flutter apps
- Provides 30+ MCP tools across inspection, interaction, debug, and lifecycle categories
- Offers cross-platform support (macOS, iOS Simulator, web) with platform-view capture and screenshots
- Integrates with popular AI agents (Claude Code, Cursor, Codex, Intent, Cline) via CLI or marketplace plugins

## Why It Matters for RAG Builders
It bridges the gap between AI agents and Flutter apps, enabling real-time interaction and dynamic tooling for agent-driven development workflows.
