## Summary
Clade is an autonomous coding framework that transforms AI assistants like Claude Code and Codex into self-learning, multi-agent systems. It provides 129 skills, 30 hooks, 36 agents, and a safety guardian to automate coding workflows, quality checks, and self-improvement mechanisms.

## Key Features
- 129 pre-built skills for coding, research, SEO, and automation tasks
- 30 hooks for session context, safety, and quality gates
- Self-learning mechanisms (commit lessons, doc alignment) for continuous improvement
- Native support for Claude Code, Codex, and MCP-compatible editors
- Orchestrator for multi-worker task routing, observability, and quality control
