## Summary
Inquiso is an open-source, cross-browser AI extension that adds a sidebar to browsers, enabling users to interact with web pages through AI-powered chat, summarization, trust assessment, and agent-driven actions. It operates locally with no server telemetry, supports multiple AI providers, and includes a MemoryAgent for learning and automating browser tasks.

## Key Features
- Cross-browser AI sidebar for real-time interaction with web pages
- MemoryAgent for learning, storing, and retrieving browser-specific tasks and preferences locally
- Transparent agent reasoning with live action traces and confirmation gates
- Support for multiple AI providers (local, OpenAI, Anthropic, Google, DashScope)
- Privacy-focused design with no telemetry, encrypted key storage, and prompt-injection defenses

## Why It Matters for RAG Builders
Inquiso provides a local-first, transparent agent framework for browser automation and memory-augmented interactions, making it essential for developers building secure, privacy-preserving AI agents that operate within web environments.
