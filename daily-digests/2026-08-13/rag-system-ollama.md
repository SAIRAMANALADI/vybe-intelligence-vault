## Summary
A high-performance, local Retrieval-Augmented Generation (RAG) system leveraging LangGraph for orchestration, Ollama for local model inference, and Streamlit for a modern UI. Optimized for speed, precision, and efficiency with advanced features like semantic chunking, metadata offloading, and FlashRank reranking.

## Key Features
- Header-aware semantic chunking with structural metadata injection to prevent context contamination
- Reference-based metadata offloading reducing FAISS index RAM usage by over 99%
- FlashRank semantic reranking with ONNX runtime for 2x higher accuracy with minimal latency
- Configurable prompt system externalized in YAML for dynamic model and term handling
- Section-aware citations with interactive badges and sub-second preview tooltips
