## Summary
Fennara Godot AI is a plugin that bridges the Godot game engine with AI assistants via MCP (Model Context Protocol) and an optional in-editor chat dock. It enables AI agents to inspect scenes, scripts, runtime errors, and validate changes in real-time, providing live feedback beyond static project files.

## Key Features
- Exposes Godot-aware tools to external AI apps through MCP for real-time scene inspection, diagnostics, and validation
- Optional in-editor chat dock for direct AI interaction within the Godot editor
- Supports both cloud and local AI providers (e.g., Ollama, LM Studio) for built-in chat functionality
- Provides live runtime feedback including screenshots, logs, and scene tree analysis to agents
- CLI-based installation and update system for seamless integration with Godot projects

## Why It Matters for RAG Builders
Fennara enables AI agents to interact with live Godot projects, providing real-time feedback and validation that surpasses static file analysis, making it essential for AI-driven game development workflows.
