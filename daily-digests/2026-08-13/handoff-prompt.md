## Summary
A structured handoff prompt skill for AI agent sessions that compresses session state into an actionable document for seamless continuation by the next session. It eliminates re-diagnosis, re-reading history, and context loss by producing a detailed, versioned handoff file with commands, repo state, tasks, and verification standards.

## Key Features
- Generates timestamped, structured handoff documents with first commands, repo state, and task lists
- Handles multiple live files with phase ordering and file overlap reconciliation
- Archives completed handoffs to maintain a clean project directory
- Project-agnostic via a reusable template with conventions block
- Supports integration with Vercel Labs Skills CLI for multi-agent environments

## Why It Matters for RAG Builders
It ensures AI agent sessions can seamlessly hand off work without losing critical context or repeating prior efforts, improving efficiency and reducing costs in long-running workflows.
