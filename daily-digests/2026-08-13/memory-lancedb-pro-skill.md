## Summary
memory-lancedb-pro-skill is a Windows-based plugin designed to integrate long-term memory management into OpenClaw and Claude Code, enabling persistent storage and retrieval of AI conversation context beyond single sessions without requiring technical expertise.

## Key Features
- Adds long-term memory support to OpenClaw and Claude Code for persistent context retention
- Seamless Windows integration with no complex configuration required
- Background operation for silent memory management without user intervention
- Supports large volumes of memory data without performance degradation
- Automatic updates via installer replacement while preserving stored memory data
