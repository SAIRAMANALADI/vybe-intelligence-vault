## Summary
Pad is a local-first project management tool designed for developers and AI agents, offering a CLI, web UI, and AI agent integration. It uses SQLite for local storage and supports optional cloud sync via Pad Cloud, enabling seamless collaboration and data portability.

## Key Features
- Local-first project management with SQLite backend and optional cloud sync via Pad Cloud
- Native AI agent integration via `/pad` skill for tools like Claude Code, Cursor, and GitHub Copilot
- CLI-first workflow with powerful commands for task creation, search, and project navigation
- Web UI with real-time updates, keyboard navigation, and rich text editing (Tiptap-based)
- Custom collections, conventions, and playbooks to guide AI agent behavior in project workflows

## Why It Matters for RAG Builders
Pad provides a critical bridge between AI agents and project management by enabling agents to interact with and manage projects natively, fostering seamless collaboration and automation in developer workflows.
