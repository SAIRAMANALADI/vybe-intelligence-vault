## Summary
A browser extension that enables AI-powered control of Chrome and Firefox via natural language commands. It provides a sidebar chat interface to manage tabs, windows, bookmarks, history, downloads, cookies, and more with built-in safety guardrails and extensible tooling.

## Key Features
- Natural language interface for browser control via sidebar chat
- 47+ built-in tools for managing tabs, windows, bookmarks, history, cookies, and more
- Safety guardrails with user confirmation for sensitive operations
- Cross-browser support for Chrome (MV3) and Firefox (MV2)
- Extensible tool system with Expert Mode for advanced capabilities

## Why It Matters for RAG Builders
It enables AI-driven browser automation with a robust, extensible toolset, reducing manual workload for RAG builders integrating browser interactions.
