## Summary
A Pi coding agent extension that enables asynchronous background context compaction to maintain responsiveness during long sessions by precomputing summaries before compaction thresholds are hit.

## Key Features
- Precomputes Pi-compatible compaction summaries in the background to avoid synchronous pauses
- Applies ready summaries only at safe idle boundaries to prevent active turn interruptions
- Preserves Pi's normal compaction behavior while adding async optimization
- Provides status-line visibility for background job progress and readiness
- Supports manual triggers and integrates with Pi's existing compaction flow

## Why It Matters for RAG Builders
It enables uninterrupted, responsive long coding sessions by proactively managing context compaction without disrupting active workflows.
