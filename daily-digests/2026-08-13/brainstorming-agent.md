## Summary
A specialized agent for OpenCode that enables structured brainstorming sessions using 6-3-5 Brainwriting and Rolestorming methodologies. It iteratively generates, refines, and documents ideas while prioritizing them for actionable outcomes.

## Key Features
- Supports two brainstorming methodologies: 6-3-5 Brainwriting and Rolestorming
- Iterative session loop with automatic documentation in Markdown
- Context gathering and thorough questioning for comprehensive ideation
- Prioritization of ideas and synthesis of perspectives
- Configurable LLM provider integration for dynamic responses
