## Summary
AgentCI Guard is a CLI and GitHub Action designed to detect unsafe AI coding-agent usage in CI/CD workflows by identifying high-risk patterns where untrusted GitHub event content could reach an AI agent with privileged access, such as secrets or write permissions.

## Key Features
- Static scanning of GitHub workflows for unsafe AI agent patterns
- Detection of untrusted event content reaching AI agents with privileged access
- Support for CLI and GitHub Action deployment
- SARIF output for integration with GitHub Security tab
- Configurable suppression of findings via inline comments or JSON config

## Why It Matters for RAG Builders
It helps prevent prompt injection attacks in CI/CD pipelines by identifying high-risk AI agent configurations before they can be exploited.
