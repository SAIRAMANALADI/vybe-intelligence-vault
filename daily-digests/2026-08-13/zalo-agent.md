## Summary
zalo-agent is a self-hosted AI agent framework designed to operate within Zalo personal accounts, enabling multi-account management with isolated 'brains' per account. It includes 13 tools, a web dashboard, scheduler, durable memory, and rich-text message formatting, while being LLM provider-agnostic.

## Key Features
- 13 built-in tools including web search, image processing, file creation, scheduling, and memory management
- Web dashboard for real-time monitoring, configuration, and agent management
- Durable memory with rolling summaries and asymmetric privacy rules
- Rich-text message formatting with Zalo-compatible markdown translation
- Scheduler for automated reminders and agent tasks with anti-spam measures

## Why It Matters for RAG Builders
It provides a robust, self-hosted framework for deploying AI agents within Zalo, enabling rich interactions and automation while maintaining full control over data and LLM providers.
