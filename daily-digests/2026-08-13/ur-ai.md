## Summary
UrAI is a production-ready Telegram bot that integrates multiple AI providers with per-user runtime isolation, session-only API key handling, and multilingual support. It enables personalized AI interactions with chat history, voice/audio support, and configurable web search capabilities.

## Key Features
- Multi-provider support (OpenAI, Groq, OpenRouter, etc.) with per-user runtime isolation
- Session-only API key handling with in-memory storage and automatic cleanup
- Built-in chat memory, history navigation, and voice/audio support
- Multilingual interface supporting 11 languages
- Configurable web search modes and persona switching

## Why It Matters for RAG Builders
UrAI provides a robust framework for building privacy-conscious, multi-user AI agents with runtime isolation and flexible provider integration, essential for scalable RAG applications.
