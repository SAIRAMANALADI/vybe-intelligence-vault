## Summary
Casper AI Portfolio Agent is an autonomous AI-driven portfolio management system built for the Casper blockchain. It autonomously reads portfolio holdings, analyzes risk using GPT-4o, executes real Casper 2.0 transactions via x402 micropayments, and rebalances portfolios without human intervention.

## Key Features
- Autonomous portfolio analysis and risk assessment using GPT-4o and heuristic fallback
- Real Casper 2.0 transaction execution via agent wallet or x402 facilitator
- Multi-agent swarm architecture with specialized agents (Portfolio, Risk, Treasury, Oracle, Yield)
- Integration with live RWA data (T-bills, PAXG, ONDO) and DeFi yields
- On-chain storage of AI analysis and rebalancing actions with auditable transaction hashes

## Why It Matters for RAG Builders
This project demonstrates a fully autonomous AI agent capable of executing real blockchain transactions for portfolio management, showcasing the potential of agentic systems in decentralized finance and RWA intelligence.
