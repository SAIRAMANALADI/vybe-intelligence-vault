## Summary
Mocapi is an enterprise-grade Spring Boot framework for building stateless Model Context Protocol (MCP) servers in Java. It provides a modular, annotation-driven approach to define tools, prompts, and resources while supporting observability, security, and GraalVM native-image deployment.

## Key Features
- Full MCP 2026-07-28 protocol support with stateless design and AES-GCM-encrypted request state tokens
- Modular architecture with optional modules for OAuth2, authorization, validation, observability, and GraalVM native-image
- Transport-agnostic handler code supporting Streamable HTTP and stdio transports
- Comprehensive observability via Micrometer, OpenTelemetry, and structured audit logging
- Typed extension SPI for custom interceptors, guards, and parameter resolvers

## Why It Matters for RAG Builders
Mocapi simplifies the development of production-grade MCP servers by providing a robust, modular framework that handles protocol compliance, security, and observability out-of-the-box, reducing boilerplate and accelerating AI integration deployments.
