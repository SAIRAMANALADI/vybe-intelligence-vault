## Summary
VibeUE is an MCP Expansion and AI Editor Toolset for Unreal Engine 5.8+ that enhances the engine's built-in AI capabilities with deep domain-specific tools for terrain, audio, animation, performance profiling, and more. It integrates directly with Unreal's native MCP server and ToolsetRegistry to provide advanced editor functionalities via AI agents.

## Key Features
- Deep integration with Unreal Engine 5.8+'s native MCP server and ToolsetRegistry for AI-driven editor workflows
- Comprehensive performance profiling and debugging tools (frame timing, Unreal Insights capture, CPU/GPU analysis)
- Domain-specific AI services for terrain, audio, animation, FX, UI, and Blueprint authoring
- Lazy-loaded domain skills (AgentSkill) for guided AI workflows and best practices
- Python-first API access to Unreal's editor and domain-specific services

## Why It Matters for RAG Builders
VibeUE bridges critical gaps in Unreal Engine's native AI tooling by providing advanced performance diagnostics and domain-specific AI services, enabling AI agents to build, optimize, and debug game environments more effectively.
