## Summary
Heym is an AI-native workflow automation platform that enables users to build, visualize, and run intelligent AI workflows without coding. It supports drag-and-drop canvas creation, multi-agent orchestration, RAG pipelines, MCP integration, and real-time observability with cost tracking.

## Key Features
- Drag-and-drop workflow editor with AI-assisted node creation
- Multi-agent orchestration with parallel execution and subagents
- Built-in RAG with vector store integration (Qdrant, pgvector)
- Real-time observability with LLM traces, cost tracking, and evals
- MCP support for agent tooling and workflow exposure

## Why It Matters for RAG Builders
Heym provides a critical orchestration layer for RAG builders by enabling seamless integration of agents, tools, and vector stores into unified, deployable workflows with built-in observability and cost tracking.
