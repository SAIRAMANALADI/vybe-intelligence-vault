## Summary
MELRA is an open-source execution system for durable, policy-governed autonomous workflows across files, terminal, browser, memory, and computer use. It provides a modular runtime with MCP, CLI, and SDK interfaces, ensuring verified outcomes through inspectable, hash-linked evidence records.

## Key Features
- Restart-safe bounded workflows with seven node kinds for cross-platform execution
- Encrypted payload storage and exact evidence-based task verification (AES-256-GCM)
- Ten MCP tools for tasks, workflows, and recovery with deterministic validation
- Scoped memory with hybrid ranking, provenance tracking, and redaction
- Hardened Docker images and cross-platform support (macOS, Linux, Windows)

## Why It Matters for RAG Builders
MELRA provides a critical layer for ensuring reliable, policy-governed execution of autonomous workflows, essential for building trustworthy AI systems that require durable, verifiable outcomes.
