## Summary
Loom Engine is an LLM-powered narrative engine and text RPG that enables interactive storytelling through natural language commands. It integrates with various LLM providers to dynamically generate and manage game states, stats, and inventories in real time.

## Key Features
- Natural language-driven interaction with real-time stat and inventory synchronization
- Broad model compatibility (OpenAI, Anthropic, Ollama, and local models)
- Complete stat system with toolchain for dynamic game state updates
- Terminal-native TUI interface with keyboard-driven navigation
- Support for dynamic and static tool calling modes

## Why It Matters for RAG Builders
It provides a flexible framework for building interactive, LLM-driven narrative experiences with real-time state management, valuable for prototyping and deploying AI-powered storytelling applications.
