## Summary
A local-first AI-powered games platform featuring 50+ browser games, 107 OpenSpiel games, and seven advanced AI engines (e.g., Stockfish, KataGo, Edax) for real-time gameplay and analysis. Includes a FastMCP 3.2 server for agent-accessible game APIs and supports desktop, Docker, and PWA deployments.

## Key Features
- Supports 50+ games with real AI engines (e.g., Stockfish, KataGo) for authentic gameplay
- FastMCP 3.2 server exposing 14 tools for agent-driven game analysis and automation
- Local-first architecture with offline PWA support and no cloud dependencies
- Docker and Tauri-based deployments for cross-platform accessibility
- Integrated Japanese learning module with kanji and JLPT drills

## Why It Matters for RAG Builders
This repository provides a comprehensive, agent-accessible platform for integrating classical game AI engines into RAG systems, enabling autonomous agents to analyze, play, and interact with 150+ games programmatically.
