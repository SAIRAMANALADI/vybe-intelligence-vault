## Summary
A 100% offline, privacy-focused RAG system built with Microsoft Foundry Local that processes local documents without internet or cloud API dependencies. It indexes and retrieves answers strictly from provided documents using hybrid semantic chunking and SQLite vector storage.

## Key Features
- 100% offline operation with no cloud dependency
- Hybrid semantic chunking for context-aware document splitting
- SQLite-based vector storage for lightweight, serverless retrieval
- Zero-hallucination design with strict adherence to local document context
- Transparent RAG context visualization in the UI for debugging and trust

## Why It Matters for RAG Builders
It enables secure, offline RAG deployments for organizations with strict data privacy requirements, eliminating cloud dependency while maintaining high retrieval accuracy.
