## Summary
A guarded CLI, JavaScript client, and local MCP server for interacting with the JustHandled Agent Utility Gateway. It provides deterministic preflights, data lookups, and evidence products with strict payment and security safeguards.

## Key Features
- 25 deterministic preflights and evidence products with versioned receipts
- Strict fail-closed security model with pinned gateway, network, and pricing
- Unpaid preview mode for validation before payment
- MCP server integration for AI agent tool discovery and execution
- Dedicated low-balance wallet requirement for all paid operations

## Why It Matters for RAG Builders
It provides a secure, auditable interface for AI agents to interact with blockchain-based utility services while enforcing strict payment and security constraints.
