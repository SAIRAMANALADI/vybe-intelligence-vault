## Summary
Buckley is a tool-first AI agent harness designed for durable repository work, enabling resumable sessions, governed model/tool selection, and multi-surface interactions (TUI, browser, one-shot, ACP, LSP). It integrates Anthropic tool calling, repository instructions, and a shared runtime for consistent AI-driven workflows.

## Key Features
- Resumable sessions with crash recovery for plans, approvals, and artifacts
- Arbiter-governed model and tool selection with role/task-aware filtering
- Multi-surface support: TUI, browser UI, one-shot, ACP, and LSP
- 38 built-in tools plus skills/plugins with SQLite-backed persistence
- Automatic runtime prompt assembly from repository instructions and project context

## Why It Matters for RAG Builders
Buckley provides a robust, governed framework for AI agents to perform complex repository tasks with resumable sessions and multi-surface interactions, critical for scalable RAG and AI-driven development workflows.
