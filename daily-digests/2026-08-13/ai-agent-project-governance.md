## Summary
A local, deterministic governance runtime designed to constrain AI coding agents within defined scopes, enforce test verification, and generate verifiable closure evidence for multi-agent workflows.

## Key Features
- Explicit task scope and protected path enforcement to prevent out-of-bounds changes
- Automated test planning, execution, and verification with structured evidence generation
- Single-writer protection and conflict detection for multi-agent collaboration
- Deterministic closure detection to avoid stale validation reuse
- Local, read-only runtime with explicit safety boundaries and no automatic system modifications
