## Summary
An open-source MCP server and predictive maintenance AI agent that enables LLMs to analyze vibration data, detect machinery faults, and generate diagnostic reports through natural conversation. It provides 37+ specialized MCP endpoints for signal processing, fault detection, and reporting.

## Key Features
- 37+ specialized MCP endpoints for signal lifecycle, spectral analysis, diagnostics, and reporting
- Natural language interaction for vibration diagnostics and report generation
- Integration with Claude Code plugin for guided workflows and autonomous agents
- ISO 20816-3 severity assessment and bearing fault detection
- Support for real-world vibration datasets and equipment manuals

## Why It Matters for RAG Builders
It bridges the gap between raw vibration data and actionable AI-driven diagnostics, enabling RAG systems to perform expert-level condition monitoring without manual coding.
