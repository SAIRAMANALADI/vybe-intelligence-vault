## Summary
A Claude Code plugin for integrating with any Bifrost MCP gateway, enabling plugin registration with lifecycle hooks, skill discovery, agent-driven memory, and MCP tooling. Supports both virtual key authentication and OAuth 2.1 for secure connections.

## Key Features
- Plugin lifecycle hooks for session management and memory injection
- Skill discovery via gateway tool integration and auto-hinting
- Agent-driven memory recall and durable decision logging
- Support for virtual key and OAuth 2.1 authentication
- Multi-surface compatibility (Claude Code CLI, Desktop, and web)

## Why It Matters for RAG Builders
It streamlines the integration of Claude Code with Bifrost MCP gateways, enabling advanced AI agent capabilities like skill discovery and memory management for RAG pipelines.
