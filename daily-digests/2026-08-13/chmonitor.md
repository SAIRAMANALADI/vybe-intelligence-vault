## Summary
chmonitor is an open-source operational advisor for ClickHouse that provides real-time monitoring, AI-driven recommendations, and a natural-language chat interface for database optimization. It helps users analyze query performance, suggest improvements like projections and materialized views, and monitor cluster health across multiple instances.

## Key Features
- Real-time ClickHouse cluster monitoring with 30+ metric charts
- AI-driven recommendations for projections, skip indexes, partition keys, and materialized views
- Natural-language chat interface for querying ClickHouse clusters
- Multi-host support for monitoring multiple ClickHouse instances
- Self-hosted (OSS) or cloud-hosted (SaaS) deployment options
