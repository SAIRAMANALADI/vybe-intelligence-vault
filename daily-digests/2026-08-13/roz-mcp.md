## Summary
roz-mcp is an MCP server that provides C# coding agents with a compiler-accurate view of a solution, enabling precise symbol navigation, blast-radius analysis, and verified semantic edits. It integrates with popular AI clients like Claude Code, Cursor, VS Code Copilot Chat, and Codex CLI to enhance code refactoring and analysis workflows.

## Key Features
- Compiler-accurate symbol navigation and references, including overrides, interface dispatch, and DI registrations
- Semantic rename and edit operations with verified compiler feedback to prevent regressions
- Blast-radius analysis for proposed changes, tagging affected sites as compatible, needing update, or unsafe
- Integration with multiple AI clients (Claude Code, Cursor, VS Code, Codex CLI) via MCP protocol
- Batchable tools for efficient multi-symbol operations and automated workflows

## Why It Matters for RAG Builders
roz-mcp bridges the gap between AI-driven code generation and compiler-verified accuracy, enabling safe and precise refactoring in large, complex C# codebases where traditional text search fails.
