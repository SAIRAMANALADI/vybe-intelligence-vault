## Summary
A Model Context Protocol (MCP) server providing access to Zenodo, CERN's open research data repository, enabling AI agents to search, retrieve, and interact with datasets, software, papers, and other research outputs via a standardized interface.

## Key Features
- Search Zenodo records by query, type, communities, or sort criteria
- Retrieve single records or files by Zenodo ID
- List communities and records within communities
- Seamless integration with AI agents via MCP
- Supports plain English queries through Pipeworx gateway

## Why It Matters for RAG Builders
It enables AI agents to dynamically access and integrate high-quality, open research data from Zenodo, enhancing the depth and accuracy of RAG systems.
