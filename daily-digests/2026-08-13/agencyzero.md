## Summary
AgencyZero is a multi-executable agent platform designed for high-security AI development, featuring a Tauri-based desktop GUI, Rust-based backend crates, and a modular architecture that isolates dependencies per executable. It supports parallel development instances and integrates with MCP and agent proxies for extensibility.

## Key Features
- Modular Rust workspace with isolated crates for each executable, reducing rebuild times
- Tauri-based desktop GUI with SolidJS frontend for a responsive, secure UI
- Hybrid backend architecture allowing Rust and in-memory fixture backends to coexist
- Support for parallel development instances via configurable bundle identifiers
- Comprehensive logging system for debugging and monitoring agent interactions
