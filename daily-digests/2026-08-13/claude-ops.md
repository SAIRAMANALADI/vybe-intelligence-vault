## Summary
claude-ops transforms Claude Code into a comprehensive business operating system by integrating infrastructure monitoring, CI/CD status, unified communication inboxes, autonomous agents, and revenue tracking into a single dashboard. It enables hands-off business operations with AI-driven automation and real-time analytics.

## Key Features
- Unified dashboard for infrastructure health, CI/CD status, and revenue tracking
- Autonomous C-suite agents for hands-off business operations
- Auto-fix subsystem for post-merge build failures with budget caps and safety hooks
- Multi-account Claude Code rotation with AI-brain for optimized performance
- Cross-platform communication inbox (Slack, Telegram, Email, WhatsApp) and voice/video integration

## Why It Matters for RAG Builders
claude-ops provides a centralized AI-driven control plane for managing business operations, reducing manual oversight and enabling scalable automation for RAG and AI stack builders.
