## Summary
Tess Console is a self-hosted operations platform where an AI agent (Tess) autonomously manages marketing, content, SEO, support, and site health for a portfolio of live websites under human oversight. Built with TypeScript/Next.js, it integrates an LLM-driven agent with RBAC, a secrets vault, and modular workers for media processing.

## Key Features
- Role-based human oversight with 3-tier RBAC and kill switches for agent control
- Pluggable LLM providers (Claude, OpenAI, DeepSeek, etc.) with per-tool permissions
- Modular worker services for media processing (video, thumbnails, face restoration)
- Unified inbox, SEO content generation, and social media automation with manual approvals
- Self-hosted analytics, uptime monitoring, and security posture checks

## Why It Matters for RAG Builders
It demonstrates a production-grade, secure, and modular AI agent framework that balances autonomy with human oversight, critical for building trustworthy RAG systems.
