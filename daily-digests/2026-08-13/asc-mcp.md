## Summary
A Model Context Protocol (MCP) server providing full control over App Store Connect via 41 opinionated tools, enabling AI agents to manage app metadata, builds, releases, reviews, and sales without manual portal access. Includes free and Pro tiers with automated workflows and slash commands.

## Key Features
- 41 opinionated tools for App Store Connect management (read/write)
- Free 7-day Pro trial with no credit card required
- Automated preflight checks to catch 40% of common rejection causes
- Integration with AI agents (Claude, Cursor, Windsurf) via MCP
- End-to-end release automation (build, archive, upload, submit, release)
