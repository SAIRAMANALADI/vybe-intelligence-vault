## Summary
This repository provides a drop-in `.windsurfrules` configuration for Windsurf's Cascade agent to integrate with the VirtualSMS MCP server, enabling AI agents to perform account verification via real carrier-issued mobile numbers, rent numbers, buy proxies, and launch cloud browser sessions.

## Key Features
- Drop-in `.windsurfrules` for seamless Windsurf Cascade integration
- Supports 40+ MCP tools for SMS verification, number rentals, and proxies
- Uses real carrier-issued mobile numbers (not VoIP) for higher verification success rates
- Offers both hosted (zero-install) and local (npm-based) deployment options
- Provides account introspection, balance tracking, and refund capabilities

## Why It Matters for RAG Builders
This repository simplifies the integration of real-SIM SMS verification and proxy services into AI agents, ensuring reliable account verification across thousands of services.
