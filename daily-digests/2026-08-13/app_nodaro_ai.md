## Summary
Nodaro is an API-first studio for AI media workflows, enabling users to chain 100+ AI models (image, video, voice, music) into node-based pipelines. It supports execution via visual editor, REST API, SDK, CLI, or MCP, and allows workflows to be published as shareable apps or integrated programmatically.

## Key Features
- Visual node-based editor for building AI media workflows with drag-and-drop functionality
- Supports 100+ AI models across image, video, voice, and music generation
- Portable workflows as JSON for sharing and importing across instances
- Server-side execution engine with BullMQ orchestration for autonomous DAG-based workflows
- Multiple interfaces: REST API, TypeScript SDK, CLI, and MCP server for programmatic control

## Why It Matters for RAG Builders
Nodaro simplifies the orchestration of complex AI media pipelines, enabling RAG builders to integrate and automate multi-step media generation workflows with minimal overhead.
