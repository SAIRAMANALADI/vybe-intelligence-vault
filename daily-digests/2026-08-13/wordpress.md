## Summary
A WordPress plugin that enables remote management of WordPress sites via the Skales desktop app, allowing AI agents to create, edit, and automate content, media, themes, and plugins through a secure REST API.

## Key Features
- Full CRUD operations for posts, pages, media, menus, widgets, and settings via REST API
- Supports Gutenberg block serialization and Elementor Flexbox Container format
- Integrates with SEO plugins (RankMath, Yoast) and WooCommerce for bulk operations
- Secure authentication using Bearer tokens with capability-based access control
- Abilities API integration for WordPress 6.9+ for MCP adapter compatibility

## Why It Matters for RAG Builders
It enables AI agents to programmatically manage WordPress sites, automating content creation, SEO optimization, and e-commerce operations for RAG pipelines.
