## Summary
MCP Lens is a Swagger UI-like web interface for the Model Context Protocol (MCP), enabling developers to explore, test, and debug MCP servers interactively. It provides a dark-themed UI for managing tools, resources, prompts, and execution history.

## Key Features
- Interactive web UI for MCP servers with dark theme support
- Tools, resources, and prompts exploration with live testing
- Request history with performance metrics and replay capability
- Multi-server support with authentication (Bearer tokens)
- Zero-configuration setup with FastMCP instrumentation

## Why It Matters for RAG Builders
MCP Lens simplifies MCP server development by providing an intuitive, browser-based interface for testing and debugging, reducing integration friction for RAG builders.
