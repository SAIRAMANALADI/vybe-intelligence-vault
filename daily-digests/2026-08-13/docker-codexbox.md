## Summary
docker-codexbox provides a Dockerized environment for the OpenAI Codex CLI, offering minimal and full toolchain-loaded images with multiple interaction modes including interactive shell, one-shot execution, API endpoint, MCP server, Telegram bot, and cron scheduler.

## Key Features
- Pre-configured Docker images with Codex and toolchain support (minimal or full variants)
- Multiple interaction modes: interactive shell, one-shot execution, API endpoint, MCP server, Telegram bot, and cron scheduler
- OpenAI-compatible API endpoint for seamless integration with RAG pipelines
- Persistent workspace and authentication via mounted host directories
- Support for structured output with JSON schema enforcement

## Why It Matters for RAG Builders
It simplifies deploying and scaling OpenAI Codex in containerized environments, enabling RAG builders to integrate Codex seamlessly with minimal setup overhead.
