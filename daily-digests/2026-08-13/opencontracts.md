## Summary
OpenContracts is an open-source document intelligence platform that transforms document repositories into programmable citation graphs. It enables human annotation, structured extraction, AI agents, and MCP server integration, all accessible via GraphQL/REST APIs and a React UI.

## Key Features
- Programmable citation graph for document repositories with human and AI annotations
- Multi-surface access via GraphQL/REST APIs, MCP server, and React UI
- Pluggable pipeline for parsing, embedding, and thumbnailing with customizable components
- Structured extraction at scale with LLM-powered fieldsets and Celery workers
- Built-in AI agents for document/corpus-scoped tasks with grounded, cited responses

## Why It Matters for RAG Builders
OpenContracts provides the foundational citation graph substrate that enables AI agents to traverse and reason over document relationships, eliminating hallucinations and enabling collaborative, open-source document intelligence.
