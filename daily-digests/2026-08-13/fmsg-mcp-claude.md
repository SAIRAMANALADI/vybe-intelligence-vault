## Summary
fmsg-mcp-claude is an MCP server that enables Claude users to share and continue sessions as fmsg threads, allowing seamless collaboration and context preservation across agents or users via plain Markdown messages.

## Key Features
- Enables sharing Claude sessions as fmsg threads for external collaboration
- Preserves full conversation context for seamless continuation
- Supports both local and self-hosted fmsg deployments
- Provides session hooks for verbatim sharing in Claude Code
- Redacts sensitive data (API keys, tokens) before sharing

## Why It Matters for RAG Builders
It enables persistent, shareable AI agent sessions that can be resumed or branched by other agents or users, enhancing collaboration and context continuity in RAG systems.
