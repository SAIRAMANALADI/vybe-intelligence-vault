## Summary
A production-ready automation testing framework that integrates AI-powered test maintenance, scheduled CI runs, and Telegram notifications. It combines Playwright for UI testing, Pytest for test execution, and Claude AI agents for automated test fixes and report analysis.

## Key Features
- AI-powered test maintenance with Claude Haiku for automatic test fixes
- AI report analysis using Claude Sonnet for actionable insights sent to Telegram
- Scheduled CI runs via GitHub Actions with daily test execution and notifications
- Dynamic XML-based configuration for environment-agnostic test execution
- Clean architecture with Page Object Model and reusable workflows for UI and API testing
