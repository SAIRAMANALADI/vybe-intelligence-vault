## Summary
IronCore Labs Alloy SDK is a unified Rust-based library that provides encryption tools for application-layer security, including standard, deterministic, and vector encryption. It consolidates functionality from SaaS Shield and Cloaked AI into a single SDK for encrypting structured, unstructured, and vector data across multiple languages.

## Key Features
- Unified encryption for structured, unstructured, and vector data
- Multi-language support (Rust, Python, Java, Kotlin)
- Deterministic and vector encryption for AI/ML applications
- Integration with vector databases for secure embeddings
- Commercial and AGPL licensing options

## Why It Matters for RAG Builders
It provides essential encryption tools for securing AI data, including vectors, ensuring compliance and privacy in RAG and AI systems.
