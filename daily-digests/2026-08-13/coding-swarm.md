## Summary
coding-swarm enables users to deploy teams of AI agents that collaborate to build, test, and maintain software projects without manual coding. It automates multi-agent coordination using Docker containers for isolated operations.

## Key Features
- Runs parallel AI agents in isolated Docker containers for task distribution
- Automates code generation, testing, and maintenance with role-specific agents
- Supports multi-provider AI integration and Git-based version control
- Provides a CLI for managing agent teams and project workflows
- Designed for non-programmers with minimal technical overhead
