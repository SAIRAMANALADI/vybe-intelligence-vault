## Summary
Lowkey enables self-hosted AI coding agents on AWS, supporting multiple agent frameworks like OpenClaw, Claude Code, Codex, and Kiro. It automates deployment via a one-liner installer, offering configurable permission profiles and agent packs for varied use cases.

## Key Features
- One-liner installer for rapid AWS deployment with interactive or non-interactive modes
- Supports multiple agent frameworks (OpenClaw, Claude Code, Codex, Kiro, Hermes, etc.) with configurable permission profiles
- Sandboxed agent options (e.g., NemoClaw in OpenShell) for enhanced security and isolation
- Extensible bootstrap system for customizing agent behavior and integrations (e.g., Telegram, GitHub Actions)
- Telemetry opt-out and strict security practices (e.g., dedicated sandbox AWS accounts, IAM role restrictions)
