## Summary
A job board aggregator that scrapes and normalizes remote-first job postings from non-geographically restrictive platforms, designed to help developers from restricted regions (e.g., Russia, Turkey, Iran) find contract work. It includes a filterable dashboard, an MCP server for AI-assisted job hunting, and beginner-friendly tools for remote work newcomers.

## Key Features
- Scrapes and normalizes job postings from multiple remote-first platforms (WeWorkRemotely, RemoteOK, HN, YC Jobs, Wellfound)
- Interactive filterable dashboard with timezone, hourly range, and entry-level toggles
- MCP server for AI assistants (e.g., Claude Code) to search jobs, score fit, draft cover letters, and track pipelines
- Beginner mode with glossary tooltips, onboarding guides, cover letter templates, and scam detection
- Supports developers from restricted regions (e.g., Russia, Turkey, Iran) who are locked out of mainstream freelance platforms

## Why It Matters for RAG Builders
It provides a critical lifeline for developers in restricted regions to access remote work opportunities and integrates with AI tools for automated job hunting assistance.
