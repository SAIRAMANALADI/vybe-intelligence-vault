## Summary
云笺 (yunjian) is an offline Chinese classical poetry toolkit featuring a local SQLite corpus, search capabilities, AI-generated appreciation, and memorization training. It includes an MCP server for AI assistants to query the local poetry database.

## Key Features
- Local SQLite-based poetry corpus with offline search capabilities using FTS5 trigram indexing
- AI-generated poetry appreciation with optional API key integration (stored securely)
- Memorization training with multiple modes (typing, voice practice) and scoring
- MCP server for direct integration with AI assistants like Claude Desktop
- Strict copyright compliance with public domain sources and clear licensing for all assets

## Why It Matters for RAG Builders
It provides a copyright-safe, offline-first poetry corpus and tools for AI assistants to interact with it, ensuring compliance while enabling rich contextual applications.
