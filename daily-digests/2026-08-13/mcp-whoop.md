## Summary
An MCP (Model Context Protocol) server for WHOOP fitness data, enabling secure read-only access to health metrics like sleep, recovery, workouts, and profile data via OAuth2 authentication and automatic token refresh.

## Key Features
- Read-only WHOOP data access via MCP tools (sleep, recovery, workouts, profile, etc.)
- Secure OAuth2 login with automatic token refresh and scope-gated tool access
- Comprehensive WHOOP v2 API coverage including summaries and snapshots
- Strict environment variable validation and logging sanitization
- Trusted publishing via npm OIDC with provenance attestations

## Why It Matters for RAG Builders
It provides a standardized, secure way to integrate WHOOP health data into AI workflows via the Model Context Protocol, enabling RAG systems to access real-time fitness insights.
