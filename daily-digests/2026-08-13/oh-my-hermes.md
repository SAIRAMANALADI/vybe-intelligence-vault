## Summary
Oh-My-Hermes (OMH) is an orchestration layer for Hermes Agent that adds a professional operating system for AI workflows, enabling structured planning, research, coding, and project memory with explicit evidence boundaries. It enhances Hermes Agent by providing a governed path for capabilities, workflows, and handoffs without replacing the core agent.

## Key Features
- Structured workflows with explicit evidence boundaries and verification gates
- Multi-language operator request classification and routing
- Project memory with review-first lifecycle and recall controls
- 103+ installable workflow skills organized into six capability families
- Quality-aware creation with production and QA guidance for deliverables

## Why It Matters for RAG Builders
OMH provides a critical governance layer for Hermes Agent, enabling structured, evidence-backed AI workflows that are essential for building reliable and auditable RAG systems.
