## Summary
Tokmeter is a comprehensive token usage tracker for AI coding agents that parses local session logs from 16+ AI assistants, aggregates token and cost data by project/model/provider/day, and exposes insights via CLI, TUI, web dashboard, MCP server, and macOS menu-bar daemon. All pricing is resolved locally without network calls except for an optional kosha pricing fetch.

## Key Features
- Parses logs from 16+ AI coding agents (e.g., Claude, Codex, Cursor) into structured token/cost aggregates
- Provides five interfaces: CLI, TUI, web dashboard, MCP server, and macOS menu-bar daemon for real-time monitoring
- Local pricing resolution via @sriinnu/kosha-discovery (20+ providers, 300+ models) with no external network calls required
- Advanced analytics including cache efficiency, burn rate, optimization scores, and cost forecasting
- Supports project aliases, backup/restore, and programmatic consumption via stable JSON contracts

## Why It Matters for RAG Builders
Tokmeter provides critical observability and cost control for AI-driven development workflows by enabling precise tracking of token usage and spending across multiple agents and projects without relying on external services.
