## Summary
extenshi.io is a cross-store catalog and intelligence platform for browser extensions (Chrome, Firefox, Edge) with security analysis, developer tooling, and open research reports. It provides tools for analytics, pre-publish scanning, and multi-store publishing, accessible via CLI and MCP servers.

## Key Features
- Cross-store catalog of 343,000+ browser extensions with security ratings
- Open developer tools (CLI and MCP server) for scanning, publishing, and analytics
- Pre-publish security scanning and store review risk prediction
- Free, no-account-needed web tools for extension safety checks and manifest generation
- Public research reports on extension ecosystem trends and risks (CC BY 4.0)
