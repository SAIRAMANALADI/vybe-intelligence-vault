## Summary
MSL is an AI agent enterprise that operates as a hierarchical workforce of specialized agents led by a human CEO. It manages e-commerce operations (e.g., MercadoLibre) with autonomous decision-making, neural memory, and human-in-the-loop approvals for business mutations.

## Key Features
- Hierarchical agent workforce with CEO oversight and approval gates for all business mutations
- Neural memory (Cortex) for learning and evolutionary feedback based on outcomes
- Modular monorepo architecture with 10+ specialized packages (e.g., @msl/agent, @msl/memory, @msl/mercadolibre)
- Telegram bot for real-time CEO approvals and multi-seller operations
- MCP server with ~40 tools for AI-driven commerce operations and integrations
