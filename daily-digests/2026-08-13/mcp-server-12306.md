## Summary
A Model Context Protocol (MCP) server providing real-time 12306 train ticket query services, including ticket availability, pricing, station search, train routes, and transfer planning. Designed for seamless integration with AI assistants and automation tools.

## Key Features
- Supports six core query capabilities: ticket availability, pricing, station search, train routes, transfer planning, and time utilities
- Dual transport modes: Stdio (local) and Streamable HTTP (remote) with automatic protocol negotiation
- Pre-loaded station database with fuzzy search (Chinese, pinyin, abbreviation, and 3-letter codes)
- Retry mechanisms and session persistence for reliable 12306 API interactions
- Comprehensive documentation and schema for all tools

## Why It Matters for RAG Builders
Provides standardized, real-time access to 12306 train data, enabling AI assistants and automation tools to integrate accurate transportation information seamlessly.
