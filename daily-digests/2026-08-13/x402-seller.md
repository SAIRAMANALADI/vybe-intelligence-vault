## Summary
x402-seller provides rug protection for autonomous trading agents by offering a composite rug score and liquidity-drain detection across multiple chains (EVM and Solana). It integrates static analysis, live simulations, and time-series data to flag risky tokens with evidence-based verdicts.

## Key Features
- Composite rug score combining static analysis and live simulations (EVM + Solana)
- Liquidity-drain detection via self-collected time-series data
- Public self-graded track record with evidence and misses included
- Pay-per-call model in USDC via x402 (no signup or API key required)
- MCP server integration for agent tools with automatic payment
