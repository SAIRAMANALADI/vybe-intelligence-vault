## Summary
Curl is an open-source GitHub pull request reviewer that generates a prioritized summary of correctness and security issues in PR diffs, optimizing for signal over volume. It allows self-hosting with custom model keys for targeted code review.

## Key Features
- Prioritized PR review comments ranked by severity (correctness and security first)
- Noise reduction with a single, actionable summary per PR
- Self-hostable with support for custom LLM model keys
- Open-source under Apache-2.0 license
- Detailed documentation for installation, architecture, and contribution
