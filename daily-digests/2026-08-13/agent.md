## Summary
A fully autonomous local-first AI agent stack built on MCP, LangGraph, and ChromaDB, featuring a 3-tier LLM role system, self-improving memory, 18 meta-tools, and 6 LangGraph workflows. It supports both local LLM inference (via LM Studio) and optional cloud escalation while running entirely on user hardware.

## Key Features
- 3-tier LLM role system with per-role model overrides and automatic fallback chains
- Self-improving memory using ChromaDB with a background 'Sleep & Learn' daemon for autonomous rule distillation
- 18 meta-tools exposing ~130 atomic actions with zero manual wiring via `@meta_tool` and `DISPATCH` registry
- Real TDD autocode workflow with pytest integration, git scoping, and rollback on failure
- Local-first architecture with optional cloud LLM escalation (10 supported providers) and tz-aware scheduling

## Why It Matters for RAG Builders
It provides a robust, local-first framework for building autonomous AI agents with self-improving memory and multi-LLM orchestration, reducing dependency on cloud APIs while enabling scalable, offline-capable workflows.
