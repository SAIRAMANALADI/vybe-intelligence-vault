## Summary
An MCP server that provides AI assistants with direct access to openEHR resources, including archetypes, templates, AQL, terminology, and specifications. It enables assistants to explore, explain, and interact with openEHR workflows through standardized tools and prompts.

## Key Features
- Provides MCP-compliant tools for openEHR archetype, template, AQL, and terminology access
- Supports hosted and local deployment (streamable HTTP and stdio transports)
- Includes guided prompts for multi-step openEHR modeling and review workflows
- Offers curated guides, examples, and type specifications for openEHR development
- Integrates with MCP clients like Claude Desktop, Cursor, and LibreChat

## Why It Matters for RAG Builders
It bridges AI assistants with openEHR ecosystems, enabling seamless access to clinical data standards and workflows for RAG and AI stack builders.
