## Summary
A keyless MCP server that measures social media activity and topic volume across Bluesky, Mastodon, Reddit, and Hacker News. Provides tools for tracking post counts over time and account engagement without requiring authentication.

## Key Features
- Keyless access to social media data across Bluesky, Mastodon, Reddit, and Hacker News
- Post count time-series analysis with bucketed results
- Account activity tracking for Bluesky and Mastodon
- Handles per-network quirks (e.g., Reddit RSS parsing, HN Algolia pagination)
- Integrates with MCP clients like Claude Desktop, Cursor, and Windsurf

## Why It Matters for RAG Builders
It provides essential, keyless social signal data for RAG builders to enrich context with real-time public discourse trends.
