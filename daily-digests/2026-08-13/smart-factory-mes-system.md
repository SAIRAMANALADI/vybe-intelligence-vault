## Summary
A manufacturing execution system (MES) for discrete manufacturing industries, providing end-to-end production workflow management, real-time equipment monitoring, 3D digital twin visualization, and AI-driven quality prediction and assistant capabilities.

## Key Features
- End-to-end production workflow management with 6 microservices for modular scalability
- 3D digital twin visualization using Three.js for real-time equipment state mapping
- High-concurrency device integration via MQTT + Kafka supporting 2000+ concurrent connections
- AI-powered quality prediction with LightGBM/XGBoost models and ONNX deployment support
- Natural language AI assistant with GLM-4 function calling for production task automation

## Why It Matters for RAG Builders
It provides a comprehensive industrial IoT platform with AI integration that can serve as a foundational orchestrator for RAG systems needing real-time manufacturing data and predictive analytics.
