## Summary
JumaBek is a self-extending personal assistant that runs locally on your machine, performs tasks, and dynamically writes new skills when needed. It autonomously compiles missing capabilities inside containers before integrating them into its workflow.

## Key Features
- Dynamic skill generation and compilation inside Docker containers for safety and isolation
- Real-time task execution with sub-agent delegation for complex workflows
- Background jobs and filesystem watching with SQLite-based scheduling
- Secure inbox system for external task submission with token-based authentication
- Live configuration reloading without restarting the agent

## Why It Matters for RAG Builders
JumaBek enables AI agents to autonomously extend their capabilities by writing and compiling new skills on-the-fly, reducing manual intervention and enhancing adaptability for RAG systems.
