## Summary
Engram is a file-first memory protocol for AI agents that enables human-controlled, portable, and Git-native memory management. It stores durable rules, workflows, and project knowledge as plain Markdown files, ensuring privacy, auditability, and vendor-agnostic portability.

## Key Features
- Human-controlled memory approval with A/B/C or yes/audit/cancel workflows
- Git-native storage of Markdown memories for auditability and portability
- Context-optimized memory routing with dependency graphs and sqlite-vec for relevance
- Privacy and security enforcement with PII/secrets scanning before writes
- Profile-based memory isolation for personal, client, or corporate contexts

## Why It Matters for RAG Builders
Engram provides a critical layer for RAG builders by ensuring durable, human-approved, and portable memory storage that prevents context bloat and vendor lock-in while maintaining strict privacy controls.
