## Summary
A helper server for Kotlin Multiplatform projects that indexes and provides fast lookup of Apple framework APIs and symbols from klib files, enabling efficient local symbol searches without external dependencies.

## Key Features
- Builds a local index of klib files for fast symbol searches
- Provides compact information cards for symbols with metadata
- Supports real-time updates to the index as project files change
- Configurable via settings.json for port, refresh rate, and scan paths
- Optimized for Windows with SSD storage recommendations

## Why It Matters for RAG Builders
It enables developers to quickly search and retrieve Apple framework APIs locally, reducing dependency on external documentation and improving Kotlin Multiplatform development workflows.
