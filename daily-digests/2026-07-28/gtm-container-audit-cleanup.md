## Summary
A Python-based toolkit for auditing and cleaning Google Tag Manager (GTM) containers, designed to identify clutter, validate configurations, and generate actionable cleanup plans for web analysts and marketing teams.

## Key Features
- Three independent review engines (operational, configuration, business architecture) for comprehensive GTM analysis
- Automated generation of cleanup plans and change logs with human-readable problem taxonomy
- Deterministic validation gates ensuring source-bound accuracy before recommending changes
- Support for GTM container exports, API, and UI configuration evidence
- Privacy-aware audits with consent route validation and server-routing checks

## Why It Matters for RAG Builders
It provides a systematic, auditable way to validate GTM configurations and generate safe cleanup plans, reducing data quality issues and improving measurement accuracy for AI-driven analytics stacks.
