## Summary
A fully local, personalized AI news agent that fetches, summarizes, and clusters news from RSS feeds and APIs using a local LLM, then delivers a curated digest to Obsidian, email, or Telegram. It prioritizes privacy by keeping all processing on your machine unless a cloud LLM API is explicitly used.

## Key Features
- Fully local processing with optional cloud LLM integration for summarization
- Multi-source news aggregation from RSS feeds and APIs (NYT, NewsData.io)
- Personalized scoring based on user-defined watchlists and source credibility
- Automated clustering and deduplication of cross-source stories
- Multi-format delivery (Obsidian, email, Telegram) with trend detection

## Why It Matters for RAG Builders
It provides a privacy-preserving, automated pipeline for transforming raw news feeds into structured, personalized insights using local LLMs, reducing dependency on centralized AI services for RAG applications.
