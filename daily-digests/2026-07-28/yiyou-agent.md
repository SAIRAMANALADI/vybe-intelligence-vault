## Summary
A lightweight AI agent framework designed for Yiyou Furniture's order management system, offering conversational AI and task automation with a functional architecture and immutable state management.

## Key Features
- Functional immutable state tree for reliable state management and traceability
- Pure reducer-based decision engine ensuring testable and predictable logic
- Unified transport layer supporting CLI, WebSocket, and HTTP interfaces
- Extensible tool registry for dynamic integration of new skills and functions
- High test coverage for core logic, reducing runtime errors
