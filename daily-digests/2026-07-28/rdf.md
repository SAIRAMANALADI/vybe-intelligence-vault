## Summary
RDF is a governance-driven framework for AI coding agents that enforces project conventions, quality gates, and domain expertise through typed agent personas. It acts as a convention layer between humans and AI runtimes like Claude Code or Gemini CLI, ensuring AI-generated code adheres to project-specific rules.

## Key Features
- Governance-as-code model with project-specific rules and quality gates
- Multi-adapter support for Claude Code, Gemini CLI, Codex, and AGENTS.md
- Convention inheritance and hierarchical rule application (project > workspace > profile > core)
- Adversarial quality gates and automated verification checks
- Session lifecycle commands for planning, building, testing, and shipping

## Why It Matters for RAG Builders
RDF provides a structured governance layer that ensures AI agents write code aligned with project-specific conventions and quality standards, reducing technical debt and improving reliability in production environments.
