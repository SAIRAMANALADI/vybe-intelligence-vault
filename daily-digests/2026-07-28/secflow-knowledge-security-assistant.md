## Summary
A native macOS AI security agent that centralizes vulnerability intelligence, knowledge graphs, code auditing, and report generation into a unified desktop workspace. It integrates SwiftUI for the frontend, FastAPI and LangGraph for backend orchestration, and supports offline static analysis for multiple programming languages.

## Key Features
- Native SwiftUI macOS client with unified dashboard for security operations
- LangGraph-based agent workflow for vulnerability Q&A, memory, and context recall
- Multi-language static analysis with AST/CFG/DFG path analysis for Java, Python, Go, C, C++, Rust, and Solidity
- Offline-first vulnerability intelligence aggregation with NVD, GitHub Advisory, and OSV integration
- Structured Chinese vulnerability card generation with fact-protected outputs and encrypted local storage

## Why It Matters for RAG Builders
It provides a unified, privacy-preserving platform for security teams to integrate vulnerability intelligence, code audits, and AI-driven analysis into a single workflow, reducing context switching and improving threat detection efficiency.
