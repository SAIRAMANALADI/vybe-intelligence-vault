## Summary
KoreStack is a local-first AI agent suite that integrates multiple productivity and data tools into a unified, locally-hosted system. It provides an agent interface, document editor, spreadsheet, diagram tool, code editor, data library, and communications hub, all inter-connected and running locally without browser extensions or opaque configurations.

## Key Features
- Unified local-first AI agent suite with multiple integrated tools
- Modular architecture with separate services for agent, data, docs, code, and comms
- Built-in RAG chunk store and reference encyclopedia for data retrieval
- Self-contained deployment with no external dependencies or services
- Inter-service communication and centralized control plane for management

## Why It Matters for RAG Builders
KoreStack provides a cohesive, locally-hosted environment for building and deploying AI agents with integrated productivity tools, making it essential for developers seeking a self-contained RAG and agent development stack.
