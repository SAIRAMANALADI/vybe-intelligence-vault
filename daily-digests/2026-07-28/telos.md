## Summary
Telos is a zero-dependency local workbench for creating, simulating, and replaying AI workflows with durable state and verifiable receipts. It integrates five MCP servers (gather, index, forum, crucible, and telos) into a unified operator map for AI development, verification, and research.

## Key Features
- Unified MCP surface with 69 tools across five flagship servers (gather, index, forum, crucible, telos)
- Deterministic proof packets for agent actions, research claims, visual truths, and build integrity with verifiable receipts
- Nine offline auditing 'doctors' for CI, presentation, accessibility, performance, and compatibility checks
- Creative engine with deterministic kernels, measurement meters, and WebGPU/WebGL rendering
- Native workstation control via Chrome DevTools Protocol and Windows UI Automation for synthetic event handling
