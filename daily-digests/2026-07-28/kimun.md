## Summary
Kimün is a lightweight, terminal-based note-taking application designed for simplicity and powerful search, with optional AI-ready features. It stores notes as plain Markdown files and integrates seamlessly with existing tools like Obsidian or Logseq, offering both a TUI and CLI interface.

## Key Features
- Blazing-fast full-text, structured, and fuzzy search with SQLite indexing
- Optional semantic search and RAG capabilities via a companion server
- Zettelkasten-ready wikilinks and backlink support with interactive previews
- Native Model Context Protocol (MCP) server for AI agent integration
- Dual interfaces: TUI for interactive use and CLI for scripting automation

## Why It Matters for RAG Builders
Kimün provides a fast, local-first note-taking solution with optional AI-powered RAG features, making it ideal for developers who want seamless integration with their terminal workflow and AI tools.
