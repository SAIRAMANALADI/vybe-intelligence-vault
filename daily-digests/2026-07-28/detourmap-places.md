## Summary
Detourmap Places provides an open dataset of 70,343 notable global locations, including coordinates, photos, and Wikipedia articles, sourced from Wikidata. It offers structured data in CSV, GeoJSON, and JSON formats for AI and mapping applications.

- Multiple data formats (CSV, GeoJSON, JSON) for flexibility
- Deterministic selection based on Wikidata properties
- Includes an MCP server for AI assistant integration
