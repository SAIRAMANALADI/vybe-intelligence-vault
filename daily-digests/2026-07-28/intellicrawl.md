## Summary
IntelliCrawl is a web-powered AI research agent that transforms comparison questions into structured reports by discovering, profiling, and validating claims about developer tools using Firecrawl, OpenAI, and LangGraph. It ensures traceability by linking claims to public sources and supports multiple export formats like Markdown, JSON, and CSV.

## Key Features
- Concurrent tool profiling with failure isolation to preserve successful results
- Deterministic and live research modes with configurable caching
- Strict claim validation with source ID normalization and evidence verification
- Multi-format exports (table, Markdown, JSON, CSV) with sanitized data
- Modular provider contracts enabling independent orchestration and testing

## Why It Matters for RAG Builders
IntelliCrawl provides a reliable way to generate auditable, source-backed comparisons of developer tools, reducing hallucination risks in AI-driven research pipelines.
