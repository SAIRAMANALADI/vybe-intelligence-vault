## Summary
Agent-Stack provides a configuration reference and architectural documentation for OpenCode and Oh-My-OpenAgent (OMO), including redacted config files, ADRs, and scripts for managing AI agent workflows, model tiers, and system health. It serves as a settings dump and QoL reference for AI agent development stacks.

## Key Features
- Redacted config files for OpenCode and OMO with placeholder support for personal paths
- Comprehensive documentation including ADRs, architecture decisions, and troubleshooting guides
- Automated scripts for config redacting, health checks, regression testing, and cost reporting
- Support for 2-tier model routing (Go-tier paid and Free-tier shared pools)
- Integrated context-mode tools for memory search, batch execution, and sandboxed code execution
