## Summary
Token Tracker is a local AI agent token consumption tracking and analysis tool for Claude Code and Codex. It provides real-time token usage monitoring, cost analysis, and quota tracking via status bars, CLI dashboards, and sidebars.

## Key Features
- Multi-agent unified tracking for Claude Code and Codex with grouped data sources
- Real-time status bars (official for Claude Code, industry-first faux statusline for Codex)
- Interactive CLI dashboards (daily, weekly, monthly reports) with GitHub-style heatmaps
- Privacy-focused local data storage with no telemetry or external uploads
- Zero-configuration setup with automatic agent detection and theme synchronization
