## Summary
VectorMCP is a Ruby implementation of the Model Context Protocol (MCP) server specification, providing a framework to expose tools, resources, prompts, and security features over streamable HTTP transport. It enables seamless integration of MCP-compliant services into Ruby applications, including Rails support.

## Key Features
- Full MCP 2025-11-25 compliance with streamable HTTP transport and session management
- Class-based and block-based APIs for tool, resource, and prompt registration
- Built-in authentication, authorization, and middleware hooks for security
- Rack and Rails mounting support for seamless integration
- Field anonymization middleware to protect sensitive data in LLM contexts

## Why It Matters for RAG Builders
VectorMCP enables Ruby-based AI applications to integrate with MCP-compliant clients and LLMs, simplifying the orchestration of tools, resources, and prompts while ensuring security and scalability.
