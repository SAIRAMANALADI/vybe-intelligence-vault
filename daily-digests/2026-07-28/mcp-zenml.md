## Summary
This repository implements an MCP (Model Context Protocol) server that bridges ZenML's MLOps and LLMOps pipelines with AI clients like Cursor or Claude Desktop. It enables standardized interaction with ZenML's API for managing ML pipelines, deployments, and artifacts through a unified protocol.

## Key Features
- Exposes ZenML API capabilities as MCP tools for standardized AI client integration
- Supports interactive MCP Apps (experimental) for visualizing pipeline runs and activity charts
- Provides structured tool outputs with schema validation for better machine parsing
- Includes automated smoke testing and issue creation for quality assurance
- Offers Docker and manual setup options with Streamable HTTP transport for MCP Apps

## Why It Matters for RAG Builders
It standardizes access to ZenML's MLOps capabilities for AI agents and clients, enabling seamless integration of ML pipelines and deployments into AI workflows.
