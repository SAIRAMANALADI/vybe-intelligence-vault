## Summary
KubeOpenCode is a Kubernetes-native platform that extends the OpenCode AI agent to enable team and enterprise collaboration by adding governance, shared configurations, scalability, and enterprise infrastructure integration. It deploys AI agents as Kubernetes resources for centralized management and orchestration.

## Key Features
- Kubernetes-native deployment of AI agents as custom resources (Agent, Task)
- Shared agent configurations and governance for teams/enterprises
- Scalable multi-agent orchestration with resource management
- Integration with Kubernetes infrastructure (ConfigMaps, Secrets, ServiceAccounts)
- CLI and UI for agent management and interaction
