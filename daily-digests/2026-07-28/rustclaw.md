## Summary
RustClaw is a lightweight Rust-based framework for running AI agents on Windows desktops with minimal resource usage. It integrates local and remote AI models with platforms like Telegram, Discord, and GitHub for task automation.

## Key Features
- Runs on minimal hardware (512MB RAM, 20MB disk space)
- Supports local (Ollama) and remote (Anthropic) AI models
- Integrates with Telegram, Discord, and GitHub for task automation
- Uses configuration files for secure token management
- Designed for low overhead and scalability

## Why It Matters for RAG Builders
RustClaw enables AI engineers to deploy lightweight, resource-efficient agents directly on user desktops for real-time automation without complex server setups.
