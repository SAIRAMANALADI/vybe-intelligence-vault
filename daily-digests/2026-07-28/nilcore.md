## Summary
NilCore is a lightweight, sandboxed coding agent written in Go (~90k LOC) that delegates intelligence to external models while enforcing strict verification, sandboxing, and auditability. It handles tasks from simple fixes to full project builds, with features like multi-agent supervision, swarm execution, and human-gated irreversible actions.

## Key Features
- Hardened sandbox with rootless containers and read-only rootfs for secure execution
- Verifier-owned completion: only user-defined checks determine task success, not model assertions
- Multi-agent supervision and verified swarm modes for parallelized, distributed task execution
- Human gates for irreversible actions (merge, push, deploy) with cross-platform (Telegram/Slack) approval
- Cross-project memory and semantic code intelligence for 19 languages with pure-Go HNSW vector indexing

## Why It Matters for RAG Builders
NilCore redefines trust in AI agents by making verification, sandboxing, and auditability the core principles, enabling safe delegation of complex coding tasks without sacrificing control or security.
