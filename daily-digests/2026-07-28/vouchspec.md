## Summary
VouchSpec provides a trusted evidence index for exact versions of Agent Skills, ensuring static inspection, cryptographic signing, and immutable verification of public artifacts without execution. It offers a read-only catalog API, signed receipts, and agent-only x402 payment flows for validation services.

## Key Features
- Static inspection of Agent Skills without execution, ensuring safety and reproducibility
- Cryptographic signing (Ed25519) and DSSE v1.0.2 envelopes for tamper-proof evidence
- Read-only catalog API with signed receipts and lifecycle state tracking
- Agent-only x402 payment flows for commercial validation services (0.25 USDC on Base)
- Support for A2A, MCP, and OpenAPI 3.1 for agent integration and discovery

## Why It Matters for RAG Builders
VouchSpec ensures verifiable, tamper-proof evidence for Agent Skills, critical for building trust in AI agent ecosystems and RAG pipelines.
