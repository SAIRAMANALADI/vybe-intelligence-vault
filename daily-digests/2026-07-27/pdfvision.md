## Summary
pdfvision is a CLI and library that enables AI agents to extract text, layout, and rendered page images from PDFs with human-like precision, including warnings for extraction failures and structured outputs for downstream processing.

## Key Features
- Extracts text, layout, and rendered page images in one pass with structured outputs (JSON, Markdown, XML, TOON)
- Provides warnings for extraction failures (e.g., glyph garbage, scanned pages, flattened tables)
- Supports search-and-zoom workflows with bounding boxes for precise region extraction
- Includes Japanese vertical text (tategaki) and ruby support for multilingual PDFs
- Offers a cache-first design for fast repeated reads and first-class remote URL support

## Why It Matters for RAG Builders
It provides AI agents with reliable, structured, and human-like PDF vision, including warnings for extraction failures, enabling more accurate and trustworthy RAG pipelines.
