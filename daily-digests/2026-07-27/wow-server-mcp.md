## Summary
A Model Context Protocol (MCP) server that enables AI clients to manage a standalone World of Warcraft private server via natural language commands. It provides 82 tools for server administration, database operations, and game-world manipulation, supporting any WoW repack with dynamic schema discovery.

## Key Features
- 82 pre-built tools for server, database, and game-world management
- Dynamic schema discovery for any WoW repack expansion
- Secure, scoped database access with validation and WHERE guards
- Full process control (MySQL, authserver, worldserver)
- Natural language interface for complex server operations

## Why It Matters for RAG Builders
It enables AI agents to autonomously manage and modify World of Warcraft private servers, reducing manual administration overhead for developers and server owners.
