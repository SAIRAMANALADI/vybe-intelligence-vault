## Summary
A Model Context Protocol (MCP) server that enables AI coding assistants to programmatically manage Cognigy.AI conversational AI agents via the Cognigy.AI Management API. It provides 132 tools for building, configuring, testing, and operating virtual agents without manual UI interactions.

## Key Features
- 132 MCP tools for comprehensive Cognigy.AI agent management (flows, nodes, intents, NLU, snapshots, packages, etc.)
- Safe-by-default operations with dry-run support for mutating actions
- Async-aware tooling with polling for long-running operations
- Mock-first development environment for testing without Cognigy credentials
- Security-focused design with automatic redaction of sensitive data (API keys, secrets)

## Why It Matters for RAG Builders
It enables AI coding assistants to automate and streamline the management of conversational AI agents, reducing manual effort and accelerating development workflows in Cognigy.AI environments.
