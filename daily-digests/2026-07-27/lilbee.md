## Summary
lilbee is a self-contained local AI stack that runs and manages AI models (chat, embedding, vision, reranking) across all available GPUs while providing a search engine over personal files, code, and web content. It delivers cited answers with exact file and line references, integrates with agents via MCP, and offers TUI, CLI, REST API, and Python library interfaces.

## Key Features
- Runs and manages local AI models (chat, embedding, vision, reranking) across all GPUs with automatic tensor splitting
- Provides a search engine over personal files, code, and web content with exact cited answers and line-level references
- Integrates with agents via MCP for dynamic retrieval and fine-tuning of search settings
- Offers multiple interfaces: TUI, CLI, REST API, Python library, and Obsidian plugin
- Supports 90+ file formats, web crawling, and per-project libraries with no external dependencies

## Why It Matters for RAG Builders
lilbee eliminates the complexity of integrating separate model servers, vector databases, and retrieval pipelines by bundling everything into a single executable that runs entirely locally, making it ideal for RAG builders seeking a streamlined, high-performance solution.
