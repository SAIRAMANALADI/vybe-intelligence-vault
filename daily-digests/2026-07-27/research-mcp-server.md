## Summary
A Model Context Protocol (MCP) server providing 23 specialized research tools for AI agents, enabling web search, content extraction, academic paper discovery, social media scanning, financial data retrieval, and geographic research through a single endpoint with pay-per-call pricing.

## Key Features
- 23 specialized research tools in one MCP server for AI agents
- Supports web search, content extraction, academic papers, social media, financial data, and geographic research
- Pay-per-call pricing ($0.01–$0.03 per successful call) with no charge for errors
- Preset configurations to reduce token overhead and costs
- Integration with major MCP clients (Claude, Cursor, ChatGPT, LangChain, LlamaIndex)

## Why It Matters for RAG Builders
It provides a unified, cost-effective way for AI agents to access diverse research tools, reducing hallucinations and enabling reliable data-driven workflows.
