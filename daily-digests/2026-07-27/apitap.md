## Summary
ApiTap is a CLI, MCP server, and npm library that transforms any website into a machine-readable API without requiring browser automation or manual scraping. It enables AI agents to interact with web services via direct API calls, reducing token costs by 20-100x compared to browser-based approaches.

## Key Features
- Converts any website into a machine-readable API with 6,400+ pre-mapped endpoints across 280+ APIs (e.g., Stripe, GitHub, Slack)
- Supports three methods: import OpenAPI specs, capture live traffic via CDP, or auto-discover APIs without a browser
- Reduces token costs by 20-100x compared to browser automation by replaying APIs directly via fetch()
- Includes an MCP server with 12 tools for seamless integration with AI agents (Claude, Cursor, Windsurf)
- Provides text-mode browsing with built-in decoders for popular sites (Wikipedia, Reddit, YouTube) to extract structured content at a fraction of the token cost

## Why It Matters for RAG Builders
ApiTap eliminates the need for browser automation in AI agents by converting websites into APIs, drastically reducing token costs and enabling direct, reliable interactions with web services.
