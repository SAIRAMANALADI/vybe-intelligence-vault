## Summary
autofill is an AI-powered tool that automates filling out web forms by leveraging a user's profile and documents. It uses an LLM to interpret form fields and populate them based on pre-configured personal data, reducing manual input while ensuring accuracy and privacy.

## Key Features
- AI-driven form autofill with user profile and document integration
- Supports multiple LLM providers (Browser Use, OpenAI, Anthropic, Ollama)
- Persistent browser profile for handling authenticated forms
- Learns from user corrections for improved accuracy over time
- Privacy-focused with optional local-only processing (Ollama)

## Why It Matters for RAG Builders
It streamlines form-filling tasks for AI engineers by automating repetitive interactions with web forms while maintaining user control and privacy.
