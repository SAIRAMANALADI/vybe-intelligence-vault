## Summary
OOPS is a Kubernetes-based Platform-as-a-Service (PaaS) designed to treat both humans and AI Agents as equal first-class operators. It enables application deployment, multi-cluster management, sandboxed command execution, and domain configuration through a unified web UI or programmatic CLI/Skill interface.

## Key Features
- Unified UI and programmatic control for both humans and AI Agents
- Multi-cluster Kubernetes management with role-based access control
- Sandboxed command execution for AI Agents with isolated workspaces
- Real-time build logs, pod monitoring, and live terminal access
- Automated deployment pipelines with rollback and scheduled restarts
