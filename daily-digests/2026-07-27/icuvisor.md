## Summary
icuvisor is an open-source Model Context Protocol (MCP) server that enables AI assistants like Claude and ChatGPT to securely access and interact with training data from intervals.icu. It provides a local-first approach for managing training data with structured, unit-explicit responses and supports hosted mode for clients requiring public HTTPS endpoints.

## Key Features
- Local-first MCP server with OS keychain integration for secure API key management
- Structured, unit-explicit responses with configurable tool profiles (core/compact/full)
- Deterministic fitness projection and annual training plan tools with dry-run safety
- Hosted mode for clients requiring public HTTPS endpoints via OAuth
- Safety-gated destructive operations and explicit metadata for AI assistant guidance

## Why It Matters for RAG Builders
icuvisor bridges the gap between AI assistants and fitness data by providing a secure, structured, and deterministic MCP server that enables accurate RAG applications to analyze training data without hallucinations or data leakage.
