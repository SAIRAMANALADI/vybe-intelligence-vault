## Summary
Gearlynx is a highly accurate cross-platform Atari Lynx emulator written in C++, featuring an embedded MCP server for AI-assisted debugging and tooling. It supports Windows, macOS, Linux, BSD, and RetroArch, with advanced debugging capabilities and hardware emulation.

## Key Features
- Highly accurate Atari Lynx hardware emulation with full commercial and homebrew ROM support
- Embedded MCP server for AI-assisted debugging with tools for memory inspection, breakpoints, and execution control
- Cross-platform support including Windows, macOS, Linux, BSD, and RetroArch
- Advanced debugging features like save states, rewind, disassembly, and hardware status monitoring
- Portable mode, shader chains, and support for modern game controllers

## Why It Matters for RAG Builders
Gearlynx provides a robust emulator with an MCP server, enabling AI agents to interact with legacy hardware systems for debugging, reverse engineering, and automated testing in RAG pipelines.
