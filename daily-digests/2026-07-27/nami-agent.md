## Summary
Nami Agent is a native desktop shell for the Maru personal web platform, wrapping web applets into a standalone offline-capable application. It includes a local AI agent powered by the Google Gemini API for file operations, shell commands, web search, and applet navigation.

## Key Features
- Local AI agent (Nami) with file system and shell command access via Tauri bridges
- Offline-capable operation with direct filesystem access
- Gemini API integration for natural language processing and tool selection
- Wraps Maru web applets into a native desktop shell for offline use
- Supports local API key storage and rotation for rate limit handling

## Why It Matters for RAG Builders
It provides a local, offline-capable AI agent framework with deep system integration, enabling RAG builders to prototype agents with native file and command access without cloud dependencies.
