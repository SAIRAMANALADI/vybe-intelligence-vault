## Summary
A menu-bar system monitor for Apple Silicon Macs with an optional local AI agent powered by Ollama. Offers real-time CPU, temperature, and system metrics alongside an integrated chat interface for AI-driven insights.

## Key Features
- Real-time CPU, temperature, and system metrics in the menu bar
- Optional local AI agent for chat, Discord bot, and automated tasks
- Nine customizable themes and glass UI design
- Zero cloud telemetry with all data stored locally
- Supports Apple Silicon (arm64) only with Homebrew and DMG install options

## Why It Matters for RAG Builders
Provides a lightweight, privacy-focused system monitoring tool for Apple Silicon with optional local AI capabilities, reducing dependency on cloud-based monitoring solutions.
