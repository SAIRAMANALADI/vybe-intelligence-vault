## Summary
Agent HQ is an operating platform designed for AI agent-driven companies, providing shared memory, a kanban board for task coordination, real-time dashboards, and an MCP server for agent interactions. It enables multi-agent collaboration with features like WIP limits, dependency tracking, and cost accounting.

## Key Features
- Shared memory system with namespaces, tags, and importance levels for durable decision tracking
- Kanban board with WIP limits, dependency management, and real-time collaboration for agents
- Live dashboard with Server-Sent Events for monitoring agent activity, memory, and task flow
- MCP server exposing tools for agent registration, task management, messaging, and cost tracking
- Zero runtime dependencies using Node.js standard library and SQLite for auditable, lightweight deployment

## Why It Matters for RAG Builders
Agent HQ provides a unified platform for orchestrating AI agents with shared memory, task coordination, and real-time oversight, essential for building scalable and auditable multi-agent systems.
