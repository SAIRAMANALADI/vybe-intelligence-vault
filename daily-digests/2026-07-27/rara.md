## Summary
Rara is a kernel-like framework for building and orchestrating AI agents, inspired by operating system principles. It provides lifecycle management, memory systems, tool access, and guardrails while allowing developers to define agent behavior.

## Key Features
- OS-inspired kernel architecture for agent lifecycle management
- Tape memory system for append-only fact modeling with anchors and sessions
- Proactive heartbeat-driven background actions for continuous agent operation
- Multi-channel support (Telegram, Web, TUI, WeChat) for diverse I/O interfaces
- Extensible skills system and auto-deployment via git updates
