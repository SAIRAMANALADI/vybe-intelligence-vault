## Summary
immichctrl is a CLI and MCP-compatible adapter for managing self-hosted Immich photo/video libraries. It provides typed, scriptable commands for library inspection, search, curation, and cleanup, while exposing a secure Model Context Protocol (MCP) interface for AI clients to interact with media assets.

## Key Features
- 74 typed MCP tools across 16 domains for comprehensive library control
- CLI and MCP adapter for both operator and AI-driven workflows
- Read-only by default with explicit confirmation for destructive actions
- Advanced features like duplicate detection, memory surfacing, and trash auditing
- Secure and confined uploads with configurable write permissions

## Why It Matters for RAG Builders
It bridges the gap between self-hosted media libraries and AI-driven automation by providing a secure, typed interface for AI clients to manage, search, and curate photo/video assets without manual intervention.
