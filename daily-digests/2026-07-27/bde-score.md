## Summary
BDE Score™ is an open-source, multi-factor quantitative stock scoring system that provides transparent, explainable scores for 74 stocks across US, HK, and A-share markets using five key factors: Momentum, Mean Reversion, Volume, Volatility, and Trend.

## Key Features
- Transparent 5-factor scoring system (0-100) with explainable breakdowns
- Covers 74 stocks across US, HK, and A-share markets
- EU AI Act Article 50 compliant with full audit trails
- Free REST API with optional paid tiers for higher access
- Dual data source failover (FutuOpenD + Sina Finance)
