## Summary
mcp-superset is a Windows-based server that extends Apache Superset with over 128 tools for managing dashboards, datasets, SQL queries, and user access. It integrates the Model Context Protocol (MCP) to bridge machine learning models with data visualization, enabling AI-driven insights within Superset dashboards.

## Key Features
- Extends Apache Superset with 128+ tools for dashboard and chart management
- Integrates Model Context Protocol (MCP) for AI and LLM-driven data insights
- Supports SQL query execution via SQL Lab without coding
- Manages user access and permissions for secure data handling
- Provides a user-friendly Windows installer for easy deployment
