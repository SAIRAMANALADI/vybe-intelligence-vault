## Summary
A full-stack chess platform enabling real-time multiplayer games, LLM-powered AI opponents, and post-game analysis. Features a policy engine for guardrails, an MCP-based agent architecture, and a dedicated admin dashboard for managing AI behavior and game data.

## Key Features
- Real-time multiplayer chess with WebSocket synchronization and game state recovery
- LLM-powered AI opponents with dynamic tool-calling via MCP servers
- Policy engine for guardrails with human-in-the-loop approvals and Redis-based rule management
- Post-game analysis with move-by-move annotations and web search integration
- Admin dashboard for managing policy rules, approvals, and conversation logs
