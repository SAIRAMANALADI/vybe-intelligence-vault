## Summary
Qrawl is a Rust library providing composable web crawling tools for fetching, cleaning, extracting, and processing structured data from web pages efficiently.

## Key Features
- Modular tools for batch operations, fetching, scraping, and data cleaning
- Supports auto and fast fetching strategies for flexibility
- Includes templates for extracting specific data like child URLs and emails
- Built for high performance with Rust's concurrency model
- Lightweight and easy to integrate via Cargo
