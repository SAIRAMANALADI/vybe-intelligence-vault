## Summary
GdbMiBridge provides a .NET-based GDB Machine Interface (MI) client and a full-featured MCP server that exposes 34 debugging tools to AI agents for C/C++ debugging on Linux. It enables AI-driven debugging workflows with breakpoints, watchpoints, stack traces, registers, and configurable state capture.

## Key Features
- 34 MCP tools for AI agents to interact with GDB, including breakpoints, watchpoints, and memory inspection
- Configurable state capture with granular control over registers, call stack, and variables
- Async MI protocol engine with thread-safe session management
- Supports self-contained binary deployment with bundled .NET runtime
- Adapted from Microsoft's MIEngine, ensuring compatibility with GDB 8.0+

## Why It Matters for RAG Builders
It enables AI agents to directly debug C/C++ programs via GDB, bridging the gap between AI-driven development and low-level debugging workflows.
