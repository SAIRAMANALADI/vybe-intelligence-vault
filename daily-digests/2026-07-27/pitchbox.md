## Summary
Pitchbox is a self-hosted, human-in-the-loop outreach agent that automates research and drafting while requiring user approval before sending communications. It integrates with ACP-compatible agent CLIs and provides a dashboard and Chrome extension for real-time monitoring and control.

## Key Features
- Self-hosted deployment with Docker and PostgreSQL
- Human approval workflow for all outgoing communications
- Real-time dashboard and Chrome extension for monitoring and control
- Integration with multiple ACP-compatible agent CLIs for drafting
- Automated research and drafting with manual oversight
