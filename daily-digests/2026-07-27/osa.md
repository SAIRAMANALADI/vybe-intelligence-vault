## Summary
OSA is a local-first, open-source AI agent framework optimized for signal-to-noise ratio in AI communication using Signal Theory. It runs on Elixir/OTP, supports multi-provider LLM routing, and offers autonomous task orchestration with 47 built-in tools.

## Key Features
- Signal Classification for intent-aware routing and tiered LLM dispatch
- Autonomous task orchestration with 14 specialized agent roles
- Multi-provider LLM support (Ollama, Anthropic, OpenAI, OpenRouter, etc.)
- Cross-session memory and learning with SQLite/ETS persistence
- Computer use capabilities for desktop automation (macOS/Linux/Docker/SSH)
