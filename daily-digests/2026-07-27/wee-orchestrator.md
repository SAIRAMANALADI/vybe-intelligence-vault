## Summary
Wee-Orchestrator is a self-hosted multi-agent AI platform that unifies interactions with multiple AI CLI runtimes (e.g., GitHub Copilot, Claude Code, Google Gemini) across Telegram, WebEx, and a web-based UI. It enables dynamic model switching, task scheduling, multi-agent workflows, and persistent session management.

## Key Features
- Unified interface for 5+ AI runtimes and 17+ models with live switching
- Multi-channel support (Telegram, WebEx, Web UI) with real-time streaming
- Built-in task scheduler for recurring AI jobs with natural language input
- Persistent session history with context window management and auto-compaction
- Plugin architecture for extensible skills (e.g., Cisco Meraki, Home Assistant)

## Why It Matters for RAG Builders
Wee-Orchestrator simplifies the integration of multiple AI runtimes and channels into a single platform, reducing operational overhead for RAG builders who need flexible, scalable, and user-friendly AI orchestration.
