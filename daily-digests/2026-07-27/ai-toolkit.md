## Summary
A comprehensive open-source toolkit for Pipefy developers, providing an MCP server with 182 tools, a CLI, a shared GraphQL SDK, and a catalog of agent skill playbooks. It enables AI agents to interact with Pipefy's platform via standardized protocols and workflows.

## Key Features
- MCP server exposing 182 tools across 13 domains for AI agents (Cursor, Claude, etc.)
- Unified CLI (`pipefy`) mirroring MCP capabilities for terminal and automation use
- Shared GraphQL SDK (`pipefy`) for consistent data access and modeling
- Agent skill playbooks in Markdown format for common Pipefy workflows
- Pre-release PyPI packages with automated CI/CD and version pinning support

## Why It Matters for RAG Builders
