## Summary
Vault-Session is a tool for securely exporting and importing browser login sessions (cookies) between devices using AES-256-GCM encryption. It enables seamless session migration across browsers like Chrome, Firefox, and Brave without relying on third-party servers.

## Key Features
- Securely exports browser sessions (cookies) to encrypted files
- Supports cross-browser session migration (Chrome, Firefox, Brave)
- Uses AES-256-GCM encryption for data protection
- No third-party servers involved; data remains local
- Open-source and free to use

## Why It Matters for RAG Builders
It provides a secure, local-first method for migrating browser sessions across devices, reducing friction for users who need consistent logins without compromising privacy.
