## Summary
Mosfet is an LLM-powered agent framework that enables extensibility through Skills, Tools, and MCP Servers. It allows users to dynamically enhance agent capabilities by adding modular components, supporting both hosted and local LLMs.

## Key Features
- Extensible agent architecture with Skills, Tools, and MCP Servers
- Model-agnostic support for hosted or local LLMs (OpenAI, Anthropic, Ollama)
- Interactive terminal chat interface with multi-step tool execution
- Dynamic skill loading and automatic skill recognition during conversations
- Easy installation and cross-platform compatibility
