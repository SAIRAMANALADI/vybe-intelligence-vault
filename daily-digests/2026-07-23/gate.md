## Summary
Gate is a local MCP reverse proxy that securely exposes local MCP servers, agent skills, and system tools to ChatGPT via a single OAuth-protected endpoint. It enables ChatGPT to interact with local resources like shell commands, files, and custom MCP servers without cloud migration.

## Key Features
- Reverse proxy for local MCP servers and tools
- OAuth-protected endpoint for secure access
- Supports shell command execution, file sharing, and agent skills
- Configurable MCP subservers via JSON configuration
- Trusted local catalogue of Agent Skills

## Why It Matters for RAG Builders
Gate bridges local AI tools with ChatGPT, enabling secure and seamless integration of local resources into AI workflows without cloud dependency.
