## Summary
MaterialPilot is a local-first MCP bridge that enables AI agents to interact with Material Maker's procedural material graphs. It provides structured access to inspect, create, edit, validate, and export editable `.ptex` graphs while ensuring atomic operations and deterministic safety.

## Key Features
- 143 typed MCP tools for graph inspection, editing, and export
- Atomic graph mutations with snapshot-first transactions and rollback
- Deterministic validation and security controls (path policies, concurrency checks)
- Live renderer-backed previews and Blender-profile PBR export verification
- Local-first operation with offline fallback for catalog and planning

## Why It Matters for RAG Builders
MaterialPilot enables AI agents to safely and programmatically edit procedural material graphs in Material Maker, preserving editability and parameterization critical for creative workflows.
