## Summary
ThreadDeck for Codex is an open-source Stream Deck Neo plugin that transforms Elgato hardware into a physical dashboard for monitoring and controlling OpenAI Codex Desktop tasks on macOS. It enables live task tracking, effort mode switching, voice dictation, and remote task management without modifying Codex's core files.

## Key Features
- Real-time Codex task monitoring with live status updates (activity, title, queue count, reasoning effort, and completion feedback)
- Hardware-based task switching between local and remote Codex environments via Stream Deck Neo
- Hold-to-dictate functionality for task follow-ups with auto-submission or draft creation
- Dynamic reasoning effort and Fast mode toggling with verified macOS automation
- Bilingual UI (English/Korean) that auto-switches based on Stream Deck's language settings

## Why It Matters for RAG Builders
It provides a local-first, hardware-accelerated interface for Codex task management, reducing reliance on Codex's UI and enabling faster, hands-free workflows for AI engineering tasks.
