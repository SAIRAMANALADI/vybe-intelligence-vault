## Summary
clumsies provides collaborative agent memory infrastructure to manage, distribute, and synchronize rules, workflows, and project context for AI coding agents. It enables teams to share, review, and evolve organizational memory outside agent runtimes while keeping workspaces in sync.

## Key Features
- Managed agent memory storage outside agent runtimes for organizational control
- Cue-driven activation and retrieval of task-relevant memory via MCP surface
- Organization and project-level scoping for shared and local context
- Bundle-based rollout for curated memory sets and workspace initialization
- Agent adapters for runtime hooks and skills (e.g., Codex, Claude Code)

## Why It Matters for RAG Builders
It centralizes and externalizes agent memory, enabling teams to manage, share, and evolve project context and rules systematically, reducing context loss and improving agent consistency.
