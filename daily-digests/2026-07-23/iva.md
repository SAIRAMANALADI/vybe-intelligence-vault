## Summary
Iva is a self-hosted Telegram AI assistant with layered memory that converts conversations into an Obsidian-compatible markdown vault. It transcribes voice notes, processes images, and organizes decisions into searchable, structured memory cards while running entirely on user-owned infrastructure.

## Key Features
- Layered memory system with nightly rollups into structured markdown cards
- Multi-modal input handling (voice, vision, text) with provider-agnostic APIs
- Obsidian-compatible vault export for long-term knowledge retention
- Built-in search with BM25 and optional vector reranking
- Pluggable MCP skills and Google Workspace integration

## Why It Matters for RAG Builders
Iva provides a robust framework for building persistent, self-hosted AI assistants that transform raw conversation data into structured, searchable knowledge vaults essential for RAG pipelines.
