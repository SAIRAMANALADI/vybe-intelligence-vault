## Summary
DPronix is a modular AI coding agent framework deeply optimized for DeepSeek-V4, featuring multi-agent orchestration, tool execution loops, GOAP planning, vector memory, and a Tauri-based desktop interface. It supports reasoning modes, context caching, and plugin systems for extensible AI-driven development workflows.

## Key Features
- DeepSeek-V4 native optimization with reasoning modes and context caching
- GOAP planner and Swarm multi-agent coordination for complex task execution
- 13 built-in tools with Snippet system for safe file edits and versioning
- Tauri desktop interface with system tray and single-instance locking
- Modular architecture with 21 workspace crates for extensibility

## Why It Matters for RAG Builders
DPronix provides a robust, production-ready framework for building AI-powered coding agents with DeepSeek-V4, enabling advanced planning, memory, and orchestration capabilities critical for scalable RAG applications.
