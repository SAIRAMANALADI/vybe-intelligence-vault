## Summary
Memwyre is an open-source, universal memory infrastructure that provides persistent knowledge retrieval for LLMs and AI agents. It securely ingests, structures, and retrieves documents, conversations, and workflows across multiple AI tools and environments.

## Key Features
- Decoupled persistent memory layer for LLMs and AI agents, ensuring context retention across tools
- Asynchronous enrichment pipeline for refining memories into structured, queryable data
- Dynamic context pruning with Ebbinghaus-inspired recency decay to optimize retrieval
- Approval-based inbox flow for reviewing and approving auto-captured memories
- Multi-tenant project containerization with strict scope-based retrieval

## Why It Matters for RAG Builders
Memwyre provides a critical memory infrastructure layer that enables AI agents and LLMs to retain long-term context, improving accuracy and reducing hallucinations in RAG systems.
