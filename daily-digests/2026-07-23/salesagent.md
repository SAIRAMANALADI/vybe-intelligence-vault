## Summary
An autonomous B2B sales AI agent that autonomously researches LinkedIn leads, scores them using a machine learning model, and generates hyper-personalized cold emails in under 45 seconds. It integrates real-time company data, CRM pipeline management, and long-term memory storage.

## Key Features
- Autonomous 5-step pipeline (Research, Score, Draft, Save, Remember) from a single LinkedIn URL
- Real-time tool-calling with LangGraph for dynamic agent workflows
- Machine learning-based lead scoring using Random Forest models
- Persistent memory with SQLite for tracking interactions and context
- Live SSE streaming for real-time agent trace and debugging

## Why It Matters for RAG Builders
This agent framework demonstrates how autonomous AI agents can automate complex, multi-step workflows like B2B sales, reducing manual effort while maintaining high personalization and accuracy.
