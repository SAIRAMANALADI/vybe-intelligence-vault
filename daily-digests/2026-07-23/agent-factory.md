## Summary
agent-factory is a Windows-based desktop application that provides 84 pre-built AI agent prompts and tools across 12 departments and 20 industry-specific playbooks. It enables users to automate tasks, generate content, and leverage LLMs like ChatGPT, Claude, and Gemini without requiring coding skills.

## Key Features
- 84 production-ready AI agent prompts for 12 departments
- 20 industry-specific playbooks (finance, healthcare, retail, etc.)
- Self-expanding library that generates new prompts automatically
- No coding required with a user-friendly Windows interface
- Comprehensive glossary for AI and prompt-engineering terms
