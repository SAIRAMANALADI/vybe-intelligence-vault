oc-mnemoria is a tool designed to provide persistent memory for OpenCode agents, enabling shared memory spaces that retain context across sessions. It leverages a Rust-based engine (mnemoria) to offer seamless memory storage and access for AI agents.

- Shared memory spaces for multi-agent collaboration
