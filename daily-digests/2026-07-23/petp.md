## Summary
PET-P is a Python-based RPA toolkit offering 80+ processors for browser automation, AI/LLM integration (10 providers), databases, SSH, email, and HTTP tasks. It supports configurable pipelines with cron scheduling, runs as a wxPython GUI, headless service, or Docker container, and includes an MCP Tool Server for AI agent integration.

## Key Features
- 80+ processors for browser automation, AI/LLM, databases, SSH, email, and HTTP tasks
- Configurable pipelines with cron scheduling, loops, and conditional branching
- MCP Tool Server (Streamable-HTTP) for seamless AI agent integration
- AI Execution Generator for natural language task flow creation and modification
- Supports 10 LLM providers with built-in error analysis and auto-fix capabilities

## Why It Matters for RAG Builders
PET-P simplifies RAG pipeline automation by providing a unified platform for orchestrating AI tasks, data processing, and external integrations, reducing the need for custom scripting and accelerating AI agent development.
