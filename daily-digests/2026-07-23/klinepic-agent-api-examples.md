## Summary
A Model Context Protocol (MCP) server and API examples for converting broker/exchange trade fills into annotated candlestick review-chart PNGs. It provides tools for validating requests, checking API capabilities, and rendering charts without consuming quota upfront.

## Key Features
- Three MCP tools for capabilities check, preflight validation, and chart rendering
- Supports multiple broker/exchange data formats (CSV templates provided)
- Dockerized deployment with CI verification
- No upfront quota consumption for validation or preflight checks
- Comprehensive documentation and OpenAPI contract

## Why It Matters for RAG Builders
It enables AI agents to generate annotated trading charts from broker fills without upfront quota costs, streamlining post-trade analysis workflows.
