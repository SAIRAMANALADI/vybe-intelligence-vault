## Summary
Agenta is an open-source workspace for building, running, and managing AI agents through natural language chat, enabling teams to automate workflows, collaborate, and deploy agents locally or in the cloud with support for multiple models and harnesses.

## Key Features
- Build agents via natural language chat and share them with teams
- Support for multiple models (OpenAI, Anthropic, Mistral, Ollama, etc.) and harnesses (Claude Code, Pi)
- Background agent execution with scheduling and event triggers
- Comprehensive tracing, usage tracking, and cost monitoring
- Integrations with 1,000+ apps via MCP and Composio

## Why It Matters for RAG Builders
Agenta provides a unified platform for building, testing, and deploying AI agents with robust collaboration and observability features, making it essential for teams scaling agentic workflows.
