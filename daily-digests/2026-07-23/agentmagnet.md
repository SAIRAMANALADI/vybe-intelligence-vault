## Summary
Agent Magnet is a persistent memory layer for AI agents that enables cross-session learning without modifying existing code. It captures behavioral signals, preferences, and corrections to build evolving user profiles that decay appropriately over time.

## Key Features
- Zero-code integration via proxy mode for OpenAI, Anthropic, and Gemini clients
- Multi-layer memory architecture (behavioral, episodic, knowledge) with configurable decay rates
- Cross-user pattern consolidation for improved cold-start performance
- Self-hosted MCP server for local data control or hosted remote MCP option
- SDK for deep integration with custom agent frameworks

## Why It Matters for RAG Builders
Agent Magnet eliminates the need for manual RAG setup or retraining by providing an out-of-the-box persistent memory layer that learns from user behavior and improves AI responses across sessions.
