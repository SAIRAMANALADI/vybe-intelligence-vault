## Summary
A curated marketplace of 40+ portable Agent Skills designed to extend AI coding agents (Claude Code, Cursor, Copilot, etc.) with domain-specific expertise for stacks like TYPO3, PHP, Go, Docker, Jira, and security. Skills are sourced directly from individual repositories and installed dynamically via a central catalog.

## Key Features
- 40+ pre-curated Agent Skills for TYPO3, PHP, Go, Docker, Jira, security, and documentation
- Portable across 30+ AI coding agents (Claude Code, Cursor, Copilot, etc.)
- Dynamic skill installation via a central marketplace catalog
- Multi-language support (English and German)
- Open standard compliance with the Agent Skills specification

## Why It Matters for RAG Builders
It provides a standardized, portable way to extend AI coding agents with domain-specific expertise, reducing setup time and improving consistency across development workflows.
