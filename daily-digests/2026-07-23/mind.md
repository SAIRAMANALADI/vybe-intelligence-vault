## Summary
mind is a local, deterministic memory system for coding agents that stores durable project facts in a weighted concept graph, enabling explainable recall, automatic capture, and privacy-preserving lifecycle management. It operates offline with a single auditable Python file and supports agent-neutral integration via a protocol server.

## Key Features
- Local, offline, and deterministic memory storage with a single-file artifact (`mind.py`).
- Weighted concept graph for storing and retrieving project facts with explainable recall via lexical ranking and spreading activation.
- Automatic capture of durable project decisions while filtering transient or sensitive data.
- Privacy lifecycle controls including `forget`, `redact`, `purge`, and `unlink` operations.
- Agent-neutral protocol server (MCP) for tool integration and cross-session continuity.

## Why It Matters for RAG Builders
It provides a portable, privacy-preserving, and explainable memory layer for AI coding agents, enabling durable project context retention without relying on hosted services.
