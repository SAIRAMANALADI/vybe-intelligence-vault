## Summary
Codex Bridge MCP is a local MCP server that acts as a reliable intermediary between Claude Code and Codex App Server, enabling continuous, stateful task execution for complex development workflows. It ensures task context, progress, and execution state are preserved across multiple interactions.

## Key Features
- Maintains persistent task context across multiple Codex interactions
- Supports task recovery and interruption handling
- Manages approval workflows for high-risk Codex operations
- Tracks task progress, events, and resource usage with SQLite and JSONL
- Provides diff inspection and context compression for long-running tasks

## Why It Matters for RAG Builders
It enables reliable, multi-turn collaboration between AI agents and humans for complex development tasks by preserving state, context, and execution history.
