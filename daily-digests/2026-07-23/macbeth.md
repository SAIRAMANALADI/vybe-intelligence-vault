## Summary
Macbeth automates macOS native applications through the Accessibility API, providing a TypeScript client with Playwright-like patterns for UI interaction, auto-waiting, and screenshot capture. It also includes an MCP server for LLM agents to drive macOS apps via tool calls.

## Key Features
- TypeScript client with chainable locators and auto-waiting for macOS UI elements
- MCP server enabling LLM agents to automate macOS apps via tool calls
- Swift daemon (`macbethd`) for Accessibility API interactions with zero external dependencies
- Built-in screenshot capture using ScreenCaptureKit
- Automatic daemon lifecycle management and permission handling

## Why It Matters for RAG Builders
Macbeth bridges the gap between AI agents and macOS applications, enabling seamless automation and integration for RAG systems requiring native UI interactions.
