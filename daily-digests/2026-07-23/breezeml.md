## Summary
BreezeML is a lightweight, production-aware machine learning workflow layer designed to simplify model training, comparison, explanation, and deployment for students, analysts, and AI agents. It abstracts away boilerplate while ensuring statistically sound practices like leakage-safe preprocessing and reproducible workflows.

## Key Features
- Honest scorecard with SHIP/WARN/STOP verdicts for model evaluation
- Unified Model object with methods for prediction, explanation, export, and deployment
- Agent-native MCP server for AI agents to train, compare, and deploy models
- Zero lock-in export to pure scikit-learn scripts with no BreezeML dependencies
- Built-in conformal prediction for uncertainty quantification in regression/classification

## Why It Matters for RAG Builders
BreezeML streamlines the ML pipeline for RAG builders by reducing boilerplate while ensuring statistically rigorous workflows, making it easier to integrate model training and deployment into AI applications.
