## Summary
A Model Context Protocol (MCP) server for Claude Desktop that converts chemical names or SMILES strings into publication-quality 2D structure drawings, reaction schemes, mechanisms, and spectra. It enables offline rendering of chemical structures using RDKit and integrates with tools like Anki for flashcard generation.

## Key Features
- Converts molecule names or SMILES to PNG/SVG/CDXML structures with RDKit
- Generates reaction schemes, mechanisms, and spectra from input data
- Supports batch processing and interactive in-chat UI with hover/inspect features
- Exports Anki flashcards with embedded structures and spectra for exam prep
- Performs Ph.Eur.-style content validation and titration curve calculations

## Why It Matters for RAG Builders
It streamlines chemical structure visualization and educational content creation for AI-driven chemistry applications, reducing manual effort in generating publication-ready diagrams and flashcards.
