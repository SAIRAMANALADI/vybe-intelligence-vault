## Summary
An idiomatic Elixir SDK for Amp, a Sourcegraph agentic coding assistant. It wraps the Amp CLI to provide streaming JSON output, multi-turn conversations, thread management, MCP server integration, and fine-grained permission control for Elixir/OTP applications.

## Key Features
- Idiomatic Elixir interface for Amp CLI with streaming JSON support
- Multi-turn conversation and thread management for continuous interactions
- Fine-grained permission control for tool access and execution policies
- MCP server integration for extended functionality and tool orchestration
- Lazy enumerable streams for real-time response handling and event processing

## Why It Matters for RAG Builders
It enables Elixir/OTP applications to seamlessly integrate with Amp's agentic coding capabilities, providing structured, permission-controlled, and streamable interactions for AI-driven development workflows.
