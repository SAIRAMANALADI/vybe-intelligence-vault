## Summary
An experimental Model Context Protocol (MCP) server that enables AI assistants to retrieve information about duyet's work, projects, and content from duyet.net. It provides structured access to CVs, blog posts, GitHub activity, and interactive tools for collaboration and messaging.

## Key Features
- Provides structured access to personal and professional information via MCP resources and tools
- Supports deployment on Cloudflare Workers for low-latency global access
- Includes interactive tools for messaging, hiring inquiries, and analytics
- Automatically discoverable resources for seamless AI assistant integration
- Comprehensive API for CVs, blog posts, and GitHub activity

## Why It Matters for RAG Builders
It enables AI assistants to programmatically access and interact with personal or professional data sources, reducing manual browsing and improving contextual understanding for RAG systems.
