## Summary
Diegin-Skill is an AI self-iterative evolution system designed to enable AI agents to learn from mistakes and improve over time, functioning as an 'AI operating system' layer. It integrates with Codex to provide continuous, autonomous error correction, pattern reinforcement, and memory-based learning without external APIs or GPU dependency.

## Key Features
- Eight-principle cognitive framework (e.g., '守三', '攻七', '一二不过三') for structured error handling and reinforcement
- Real-time error detection and correction with a 'three-strike' safety mechanism to prevent repeated mistakes
- Semantic memory engine (Mindol) for storing and retrieving learned patterns and experiences
- Priority-based arbitration system (P0-P5) to resolve conflicts and guide decision-making
- Offline reflection and quarterly falsification to validate stored knowledge and prevent hallucinations

## Why It Matters for RAG Builders
It provides a critical layer for building self-improving AI agents by automating error correction, pattern reinforcement, and memory-driven learning, reducing manual intervention and enhancing reliability in RAG systems.
