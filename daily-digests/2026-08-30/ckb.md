## Summary
CKB (Code Knowledge Backend) transforms codebases into queryable knowledge bases, enabling semantic search, impact analysis, ownership tracking, and security auditing via CLI, API, or AI assistants like Claude Code. It acts as a senior engineer's assistant for navigating and understanding code.

## Key Features
- Semantic code navigation with SCIP indexes for cross-file references and call graphs
- Impact analysis with risk scoring and blast radius detection for safe code changes
- Ownership tracking and reviewer suggestions with drift detection
- Security auditing for secrets, credentials, and sensitive code patterns
- Multi-interface support (CLI, HTTP API, MCP) for AI assistants and CI/CD pipelines

## Why It Matters for RAG Builders
