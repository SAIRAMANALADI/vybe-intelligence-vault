## Summary
SurrealDB is a multi-model database that unifies documents, graphs, vectors, time-series, full-text search, and relational data within a single ACID transaction framework. It exposes a native HTTP REST API and supports SurrealQL, a unified query language for multi-model data access.

## Key Features
- Unified multi-model data storage (documents, graphs, vectors, time-series, full-text search)
- ACID-compliant transactions across all data models
- Native HTTP REST API with SurrealQL query support
- Model Context Protocol (MCP) server for AI agent integration
- Managed cloud hosting with self-hosted open-source option

## Why It Matters for RAG Builders
SurrealDB simplifies RAG pipelines by unifying diverse data types into a single queryable system with AI-native access via MCP, reducing integration complexity.
