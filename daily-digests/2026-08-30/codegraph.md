## Summary
Codegraph is a local CLI and TypeScript library that transforms a source tree into a resolved model of files, symbols, references, and dependencies. It enables agents and humans to query repository structure, analyze impact, and navigate code efficiently with deterministic discovery and structured outputs.

## Key Features
- Resolves cross-file repository maps for deterministic discovery and navigation
- Supports multi-language indexing (TypeScript, Python, Go, Java, etc.) and SQL
- Provides structured outputs (JSON, Mermaid, DOT, SQLite) for automation and integration
- Enables impact analysis, drift detection, and duplicate code identification
- Integrates with agents via MCP and CLI for seamless workflow integration

## Why It Matters for RAG Builders
Codegraph provides the foundational repository map that AI agents need to avoid wasting context on discovery, enabling faster and more accurate code understanding and modification.
