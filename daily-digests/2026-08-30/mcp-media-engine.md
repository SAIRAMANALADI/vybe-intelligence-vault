## Summary
MCP server for MediaEngine that enables AI-powered generation of images, audio, and videos for clients like Claude and Cursor. It provides a unified interface to multiple AI media generation models with specialized tools for different content formats.

## Key Features
- Unified interface for AI-powered image, audio, and video generation
- Specialized tools for hero images, social media graphics, and teaser videos
- Support for multiple quality tiers (Nano Banana, GPT-Image)
- Async job management with polling and status checks
- Seamless integration with MCP clients like Claude and Cursor
