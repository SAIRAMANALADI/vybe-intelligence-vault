## Summary
HelixDB is a graph-vector database built in Rust that unifies graph, vector, key-value, document, and relational data models into a single platform for AI applications. It enables federated access to company data for memory, knowledge graphs, and agent-based systems.

## Key Features
- Unified graph + vector data model with support for KV, documents, and relational data
- Built-in CLI for local and cloud deployment with interactive bootstrapping via `helix chef`
- Multi-language SDKs (Rust, TypeScript, Python, Go) for seamless query integration
- ACID transactions, full-text search, and high availability in managed cloud deployments
- Designed for AI agents with federated access to company data and memory

## Why It Matters for RAG Builders
HelixDB simplifies the RAG stack by consolidating multiple database types into one platform, reducing complexity and enabling seamless integration of graph, vector, and relational data for AI applications.
