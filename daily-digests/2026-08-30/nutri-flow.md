## Summary
Nutri-flow is a full-stack AI dietary analysis system that integrates meal-image upload, food instance segmentation, calorie estimation, and personalized nutrition advice into an asynchronous workflow. It combines Vue/Flutter clients with a decoupled backend featuring service orchestration, queue-based inference, and an agent-driven nutrition workflow.

## Key Features
- Food instance segmentation using Swin-Tiny, BiFPN, and Coordinate Attention with FoodSeg103 nutrition priors for calorie/macro estimation
- LangGraph agent workflow with user memory, nutrition knowledge retrieval, rule-based advice, and LLM-enhanced coaching
- Decoupled microservices architecture with Spring Boot backend, RabbitMQ task queues, and FastAPI segmentation service
- Cross-platform clients (Vue 3 web and Flutter mobile) with upload, visualization, profile, and history features
- Model-version governance, service decoupling, and production-grade deployment with Caddy-managed HTTPS and private networking
