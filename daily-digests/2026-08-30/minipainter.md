## Summary
Minipainter is a local-first paint registry and inventory tool for miniature-painting workflows, enabling AI paint suggestions to prioritize paints users already own. It provides a deterministic catalog, cross-brand color matching, a colored terminal UI, and MCP servers for AI agent integration.

## Key Features
- Deterministic local catalog with 1,607 paints across major brands (Citadel, Army Painter, Vallejo, AK)
- Owned-first paint lookup and cross-brand color matching with RGB-aware search
- Colored terminal UI (TUI) displaying real RGB swatches and OWNED/MISSING status
- MCP servers for Claude Desktop and ChatGPT, enabling AI agent integration
- Self-hosted HTTP server with Docker and PostgreSQL support for scalable deployment

## Why It Matters for RAG Builders
Minipainter enables AI-driven paint suggestions to prioritize paints users already own, solving a critical gap in miniature-painting workflows and improving the accuracy of AI recommendations.
