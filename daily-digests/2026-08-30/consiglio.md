## Summary
Consiglio is a desktop workspace that wraps the Codex CLI to enable persistent, long-running AI tasks beyond terminal sessions. It provides a durable interface for managing conversations, files, providers, and drafts with automatic recovery after crashes or restarts.

## Key Features
- Automatic task recovery and reconnection after app restarts or crashes
- Persistent conversation history, drafts, and Codex thread IDs
- Built-in file browser with text and image previews
- Encrypted credential management for API keys and MCP servers
- Multi-provider support including Codex, Ollama, and remote llama.cpp

## Why It Matters for RAG Builders
Consiglio bridges the gap between transient terminal sessions and durable AI workflows by providing a persistent, user-friendly interface for managing long-running Codex tasks.
