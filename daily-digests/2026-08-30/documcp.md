## Summary
DocuMCP is a documentation server that exposes knowledge bases through the Model Context Protocol (MCP), enabling AI agents to search, read, and manage documentation. It provides structured access to documents via MCP tools, supports OAuth 2.1 authorization, and integrates with external sources like ZIM archives and Git templates.

## Key Features
- MCP-compliant server with 16 tools and 6 prompts for document operations
- OAuth 2.1 authorization server with PKCE and dynamic client registration
- PostgreSQL-backed full-text search and document indexing pipeline
- External integrations with Kiwix ZIM archives and Git templates
- Observability stack with OpenTelemetry, Prometheus metrics, and structured logging

## Why It Matters for RAG Builders
DocuMCP enables AI agents to securely and efficiently access, search, and manage documentation via MCP, making it essential for building scalable RAG systems with structured knowledge retrieval.
