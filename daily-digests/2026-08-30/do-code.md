## Summary
do-code is a local-first, open-source coding agent designed for real-world project work, enabling users to read, modify, and validate code directly in their terminal and Git repositories. It prioritizes user control over models, permissions, sessions, and evaluations without uploading data to external services.

## Key Features
- Local-first execution with full control over models, permissions, and sessions
- Supports multiple AI model providers (domestic and international)
- Built-in evaluation platform for testing and improving agent performance
- Context-aware file references, Git diff, and session recovery
- Security modes (Ask, Auto, Full Access) with checkpoint restoration

## Why It Matters for RAG Builders
It provides a secure, local-first framework for AI-powered coding agents that can be integrated into RAG pipelines for real-time code analysis and modification.
