## Summary
oh-my-matrix is an OpenClaw-native orchestration extension suite designed to transform OpenClaw hosts into sustainable autonomous agent runtime stacks. It provides continuous execution, dynamic multi-agent workflows, and runtime permission policies for long-running AI tasks.

## Key Features
- Autopilot plugin for continuous task execution with goal management, retry logic, stall detection, and evidence tracking
- Dynamic Workflows for AI-generated multi-agent orchestration programs (.prose) with 8 execution modes
- Permission Policy for runtime safety primitives shared across autopilot and workflow subagents
- Modular architecture with npm-published packages (@oh-my-matrix/autopilot, @oh-my-matrix/dynamic-workflows, @oh-my-matrix/permission-policy)
- Comprehensive CI/CD pipeline with multi-gate harness for testing, linting, and type checking
