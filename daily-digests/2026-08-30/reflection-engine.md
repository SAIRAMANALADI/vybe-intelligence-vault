## Summary
Reflection Engine is a downloadable prompt tool that generates a candid, evidence-grounded personal portrait of an AI assistant's memory of a user by analyzing past conversations. It provides structured insights into interests, habits, and interactions without requiring programming or complex setup.

## Key Features
- Generates a structured portrait of an AI's memory of a user based on real conversation data
- Uses evidence-backed insights to avoid assumptions or vague summaries
- Simple copy-and-paste workflow with no installation or coding required
- Privacy-focused as it operates entirely within the user's AI session
- One-time download with reusable prompts for any compatible AI assistant
