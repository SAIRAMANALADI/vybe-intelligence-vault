## Summary
OpenAgent is a modern desktop AI agent client designed for multi-agent delegation, long-term memory, and interactive tool integration. Built with Tauri, SvelteKit, and Rust, it offers a desktop-native experience with advanced features like hybrid memory, sub-agent delegation, and structured interactive prompts.

## Key Features
- Multi-agent architecture with streaming Chat and Flash Agents for specialized tasks
- Hybrid long-term memory system combining SQLite, embeddings, and time decay for cross-session recall
- Interactive AGUI components and HTML previews for rich agent responses
- Tool approval modes and sandboxed workspace for safe file/terminal operations
- Skills system for extensibility via SKILL.md files and MCP-native server integration

## Why It Matters for RAG Builders
OpenAgent provides a robust framework for building and deploying AI agents with advanced memory, delegation, and interactive capabilities, making it essential for developers creating complex RAG systems.
