## Summary
A production-grade, agent-agnostic memory sidecar for AI agents that enhances long-term recall by archiving sessions, managing multi-tier knowledge, and injecting relevant context into future agent interactions without modifying the agent core.

## Key Features
- Agent-agnostic installation via AGENT_HOME with no core modifications
- Multi-tier recall system (hot, warm, cold, curated knowledge layers)
- Operational health monitoring with alerts, dashboards, and OpenMetrics support
- Embedding model selection and semantic recall integration
- Privacy-safe synthetic memory evaluation and governance policy metadata

## Why It Matters for RAG Builders
It provides a robust, installable memory layer for AI agents that preserves context across sessions and projects, enabling durable recall without requiring agent-specific modifications.
