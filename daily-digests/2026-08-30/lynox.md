## Summary
lynox is a self-hosted, source-available AI agent runtime that automates business workflows, research, and monitoring by connecting to APIs, managing knowledge graphs, and executing scheduled tasks. It supports multiple LLMs (Anthropic, Mistral, and OpenAI-compatible endpoints) and provides a web UI, mobile access, and background workers for persistent automation.

## Key Features
- Persistent knowledge graph for long-term memory and entity resolution across workflows
- Background worker for scheduled tasks, URL monitoring, and recurring workflows
- Multi-role agent system (Researcher, Creator, Operator, Collector) with scoped tools
- Interactive CLI installer with Docker Compose scaffolding and web UI deployment
- Security-first design with AES-256 encryption, SSRF protection, and input/output scanning

## Why It Matters for RAG Builders
lynox provides a robust, self-hosted orchestrator for AI agents that can automate complex business workflows while maintaining data privacy and control, making it essential for RAG builders who need persistent, context-aware automation beyond simple retrieval.
