## Summary
A two-way Telegram bridge for Claude Code that enables continuous agent workflows by notifying users on Telegram and blocking execution until a reply is received, including support for images and permission approvals.

## Key Features
- Two-way continuous communication between Claude Code and Telegram with blocking behavior
- Automatic creation of one Telegram topic per project for organized workflows
- Support for sending and receiving images/screenshots for agent context
- Remote permission approvals via Telegram for safer agent execution
- 24/7 daemonized bridge with minimal setup and zero external dependencies

## Why It Matters for RAG Builders
It enables remote oversight and control of AI agents, allowing developers to manage long-running tasks from their phones while maintaining continuous workflows.
