## Summary
Pagehand is a Chrome extension that integrates an AI agent into the browser's side panel, enabling direct interaction with the current tab via the Chrome DevTools Protocol (CDP). It allows users to chat with an AI, read page content, automate browser actions (clicks, form filling, navigation), and inspect network/console activity without requiring external MCP clients or Node processes.

## Key Features
- Self-contained Chrome extension with no external dependencies for CDP access
- Direct integration with Chrome DevTools Protocol for reading and automating browser actions
- Supports multiple LLM providers (OpenAI, Anthropic, OpenAI-compatible APIs) via Vercel AI SDK
- Real-time interaction with the current tab's content, network, and console activity
- Comprehensive testing suite including unit, E2E, and live-LLM tests

## Why It Matters for RAG Builders
Pagehand enables seamless, in-browser AI automation and interaction with web content, reducing the complexity of integrating CDP-based tools into RAG pipelines.
