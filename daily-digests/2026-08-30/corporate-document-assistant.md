## Summary
A full-stack Retrieval-Augmented Generation (RAG) system designed to transform corporate documents into searchable knowledge. It processes PDF, DOCX, or TXT files, generates embeddings, stores them in ChromaDB, and enables natural-language querying through a modern Next.js interface with source citations.

## Key Features
- Supports multi-format document ingestion (PDF, DOCX, TXT)
- Automated text extraction, chunking, and embedding with Sentence Transformers
- Persistent vector storage and semantic search using ChromaDB
- Modern Next.js frontend with responsive design and source citations
- OpenRouter-compatible LLM integration for grounded, verifiable answers

## Why It Matters for RAG Builders
It provides a complete, production-ready pipeline for turning private corporate documents into searchable, source-grounded AI knowledge bases, essential for secure and verifiable enterprise RAG applications.
