## Summary
MetaBot is a multi-platform agent orchestration framework that enables users to control AI coding agents (Claude Code, Kimi Code, Codex CLI) via messaging platforms like Feishu, Telegram, or WeChat. It supports multi-agent collaboration, persistent memory, and automated task execution.

## Key Features
- Supports three leading AI coding agents (Claude Code, Kimi Code, Codex CLI) with native subscription integration
- Multi-agent collaboration via an agent bus with task delegation and runtime agent creation
- Persistent shared knowledge base (MetaMemory) with full-text search and Feishu knowledge base synchronization
- Cross-platform control via Feishu, Telegram, WeChat, and a web UI with real-time streaming and voice assistant capabilities
- Modular architecture with optional skills (MetaSkill) and scheduling (MetaSchedule) for extensibility

## Why It Matters for RAG Builders
MetaBot provides a unified, self-hosted orchestration layer for AI agents across multiple platforms, enabling seamless multi-agent collaboration and persistent memory for RAG systems.
