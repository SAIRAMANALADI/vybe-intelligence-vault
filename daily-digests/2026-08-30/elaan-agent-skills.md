## Summary
Elaan agent skills provides Claude Code-compatible tools and an MCP server for Elaan, a notification infrastructure that delivers events to in-app inboxes, emails, and push notifications. It simplifies the complex process of adding notifications to applications by offering pre-built skills and tools for managing notification types, templates, and delivery.

## Key Features
- Pre-built skills for notification management (e.g., quickstart, contact tokens, triggering notifications)
- MCP server with 26 tools for notification types, templates, brands, and delivery logs
- Fallback to plain HTTP when MCP server is not configured
- Designed for integration with applications via JavaScript SDKs
- Simplifies debugging and troubleshooting of notification delivery

## Why It Matters for RAG Builders
Elaan agent skills streamlines the integration of multi-channel notifications into AI-driven applications, reducing complexity and ensuring reliable delivery across email, in-app, and push channels.
