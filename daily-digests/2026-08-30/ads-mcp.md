## Summary
A remote Model Context Protocol (MCP) server enabling AI assistants to manage, analyze, and optimize ad campaigns across major platforms like Google Ads, Meta Ads, TikTok Ads, and LinkedIn Ads. It provides 400+ tools for campaign creation, performance tracking, keyword research, and automation via OAuth 2.1-secured HTTP transport.

## Key Features
- 400+ tools for multi-platform ad management (Google, Meta, TikTok, LinkedIn, Amazon, ChatGPT)
- Strategy-aware execution with persistent campaign guidance via STRATEGY.md
- Raw data mode for JSON-only outputs for custom dashboards or pipelines
- Multi-account support for agencies managing multiple ad accounts per platform
- Automation features including scheduled briefs, performance monitors, and cross-platform reports

## Why It Matters for RAG Builders
