## Summary
Arcsi Runtime is an experimental, modular AI runtime designed for personal automation, research, and autonomous workflows. It combines Node.js, Python, and optional Android/Termux or Proxmox services into a distributed system that adapts organically to its environment.

## Key Features
- Modular and distributed architecture supporting edge (Android/Termux) and core (Proxmox) instances
- Long-term project context and memory management with multi-project support
- Trace-based reasoning and policy layer for organic adaptation and anomaly detection
- Extensible tool system with sandboxed, reversible, and logged actions (e.g., file I/O, HTTP requests, shell execution)
- Real-world testing-driven evolution with continuous improvement based on daily usage
