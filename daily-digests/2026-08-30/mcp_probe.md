## Summary
mcp_probe is a test harness and conformance checker for MCP (Model Context Protocol) servers, enabling automated validation of server behavior, protocol compliance, and tool/resource/prompt APIs. It supports Dart, Node.js, Python, and compiled binaries via stdio transport.

## Key Features
- McpServerHarness for starting MCP servers, managing timeouts, and ensuring process cleanup
- Conformance checks with severity-based reporting (error, warning, info)
- CLI and GitHub Actions integration for CI/CD pipeline integration
- Expectation helpers (e.g., expectToolExists, expectToolCallSucceeds) for Dart test suites
- Structured JSON output for machine-readable reporting and dashboard integration

## Why It Matters for RAG Builders
It provides essential automated validation for MCP servers, ensuring protocol compliance and reliability, which is critical for building robust RAG systems that rely on standardized server interactions.
