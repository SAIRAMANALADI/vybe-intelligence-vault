## Summary
mcproc is an MCP server that enables AI agents to manage long-running background processes (like dev servers) while providing developers with CLI access for monitoring and control. It bridges the gap between AI-driven workflows and traditional command-line tooling.

## Key Features
- Unified process management for AI agents and developers via MCP and CLI
- Real-time log capture, persistence, and search with regex support
- Project-aware process grouping and cross-environment visibility
- XDG-compliant file organization for logs, config, and runtime data
- Support for version managers (nvm, mise, asdf) and process wait-for-log patterns

## Why It Matters for RAG Builders
It enables AI agents to manage long-running processes reliably while ensuring developers retain full control and visibility, making it essential for production-grade AI-driven development workflows.
