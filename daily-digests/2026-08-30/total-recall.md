## Summary
Total Recall is a cross-session memory plugin for AI coding assistants like Claude Code that mines session transcripts to provide contextual continuity across sessions and projects. It extracts high-signal decisions, corrections, and preferences from local transcripts to inform new sessions without requiring manual curation or cloud uploads.

## Key Features
- Cross-session and cross-CLI memory extraction from local transcripts
- 17 extractors capturing decisions, corrections, goals, and operator profiles
- 26 MCP tools for real-time memory queries and operator context retrieval
- Local-only processing with optional LLM refinement for improved extraction accuracy
- Metrics and health monitoring for usage insights without telemetry

## Why It Matters for RAG Builders
Total Recall eliminates the need for manual memory curation by automatically extracting and reusing high-signal context from past sessions, significantly improving AI coding assistant efficiency and continuity for RAG builders.
