## Summary
mcp-yesterdays-number is a Model Context Protocol (MCP) server that provides a random number aged 24 hours via the StupidAPIs service. It is part of the Pipeworx gateway, enabling AI agents to access over 1394 live data sources through a unified interface.

## Key Features
- Provides a 24-hour aged random number via MCP for smooth data transitions
- Integrates with Pipeworx gateway for access to 1394+ live data sources
- Supports plain English queries via ask_pipeworx for simplified tool invocation
- Lightweight and easy to deploy as an MCP server
- MIT licensed for open-source use

## Why It Matters for RAG Builders
