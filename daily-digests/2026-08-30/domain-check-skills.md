## Summary
A free MCP (Model Context Protocol) server and Claude Skill for checking domain availability across 50+ TLDs with integrated cheapest-registrar pricing. Powered by a multi-source verification engine (RDAP, DNS-over-HTTPS, Fastly) and designed for seamless integration with AI assistants like Claude, Cursor, and ChatGPT.

## Key Features
- Multi-source domain verification (RDAP, DNS-over-HTTPS, Fastly) with high confidence in results
- Integrated cheapest registrar pricing across 6+ registrars for 50+ TLDs
- Seamless integration with AI assistants (Claude, Cursor, ChatGPT, Windsurf) via MCP
- No API key required with generous free tier (60 req/min, 5,000 req/day)
- Supports bulk checks, premium detection, and registrar comparisons

## Why It Matters for RAG Builders
This tool enables AI agents to autonomously check domain availability and pricing, streamlining workflows like brand name brainstorming and domain acquisition without manual intervention.
