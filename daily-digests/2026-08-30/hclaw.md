## Summary
HClaw is a local AI Agent desktop client designed for seamless interaction with AI models and tools through a graphical interface. It enables real-time synchronization with IM channels like WeChat and Feishu, supports dynamic model switching, and prioritizes local data storage for privacy.

## Key Features
- Graphical interface for managing agents, skills, tools, and prompts without editing config files
- Real-time synchronization with WeChat and Feishu for AI assistant integration
- Dynamic switching between multiple AI models (Anthropic, OpenAI, Google, Ollama) during conversations
- 95%+ cache hit rate to optimize token usage and reduce costs
- Local-first data storage with optional IM channel integration for enhanced privacy

## Why It Matters for RAG Builders
HClaw provides a user-friendly, local-first framework for building and managing AI agents, making it ideal for developers and non-technical users seeking a privacy-focused, multi-model agent client.
