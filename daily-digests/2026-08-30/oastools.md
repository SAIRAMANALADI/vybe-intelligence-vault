## Summary
A comprehensive Go-based OpenAPI toolkit for validating, parsing, fixing, converting, diffing, joining, and building OpenAPI specifications (2.0–3.2). It includes 12 packages and a CLI for full OpenAPI lifecycle management with minimal dependencies.

## Key Features
- Full OpenAPI lifecycle support (parse, validate, fix, convert, diff, join, generate, build)
- Minimal dependencies with optimized performance (11–150x faster pre-parsed workflows)
- Supports OpenAPI 2.0–3.2 with full JSON Schema Draft 2020-12 compliance
- Built-in MCP server for LLM agent integration and AI-ready tooling
- Battle-tested with 8,000+ tests and compatibility with major APIs (Stripe, GitHub, Discord)
