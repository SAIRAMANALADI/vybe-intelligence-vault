## Summary
Eli Felse Base is a framework designed to create safer autonomous AI assistants by reversing the traditional LLM-agent interaction model. It uses Python automation to execute commands chosen by the LLM, prioritizing safety and containment while providing a modular foundation for building AI-driven characters and systems.

## Key Features
- Schema-constrained safety: LLM selects from predefined menus to prevent unsafe actions
- Memory system with vector recall and automatic fact consolidation
- Built-in activities (journal, chat, eat, nap, ponder, environment) for autonomous character simulation
- Cost controls including daily token budgets and auto-sleep mechanisms
- Modular architecture supporting easy extension via community modules
