## Summary
A Model Context Protocol (MCP) server that bridges IDA Pro with AI-powered reverse engineering workflows, enabling LLMs to interact with disassembled binaries for automated analysis, decompilation, and code understanding.

## Key Features
- Enables AI models to interact with IDA Pro databases via MCP for automated reverse engineering tasks
- Provides tools for decompilation, variable renaming, type correction, and function analysis
- Supports headless and GUI-based IDA Pro sessions with persistent database workers
- Includes resource endpoints for metadata, segments, entry points, and type information
- Integrates with popular MCP clients like Claude, Codex, and VS Code for seamless workflows

## Why It Matters for RAG Builders
It bridges the gap between AI models and reverse engineering tools, enabling automated and AI-assisted binary analysis workflows essential for security research and malware analysis.
