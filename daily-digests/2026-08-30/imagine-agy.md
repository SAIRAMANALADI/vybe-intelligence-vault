## Summary
A CLI tool and Claude Code skill that enables AI image generation by integrating Google's Antigravity CLI (`agy`). It allows users to generate images directly from the terminal or via natural language prompts in Claude Code, bypassing limitations of the base Antigravity tool.

## Key Features
- Seamless integration with Google's Antigravity CLI for image generation
- Standalone CLI for direct terminal-based image generation
- Claude Code skill for natural language image requests
- Automatic handling of Antigravity CLI permissions and path resolution
- Support for custom aspect ratios, output paths, and models

## Why It Matters for RAG Builders
It bridges the gap between AI coding agents and image generation tools, enabling seamless integration of visual assets into AI-driven workflows.
