## Summary
Talamus is a local-first knowledge compiler that transforms documents, notes, and agent sessions into searchable, citable Markdown concept notes for AI agents. It enables persistent, verifiable memory with bitemporal history and provenance tracking, reducing context waste and improving recall accuracy.

## Key Features
- Bitemporal knowledge storage with version history and valid-time windows for accurate recall
- Source-grounded answers with full provenance and citation support for verifiability
- Ontology induction from evidence with versioned, rule-promoted concepts for semantic clustering
- Consent-aware session capture with audit logging and worth-remembering gate
- Benchmark-driven retrieval quality with 79.7% recall@10 on SciFact and 97.1% hit@10 on cross-language tasks

## Why It Matters for RAG Builders
Talamus eliminates disposable agent memory by providing persistent, citable, and verifiable knowledge storage that significantly improves RAG recall accuracy and reduces context waste.
