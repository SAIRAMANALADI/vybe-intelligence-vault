## Summary
A free, open-source, chapter-wise curriculum for Generative AI, LLMs, Vector Databases, RAG, and Agents, designed to teach from basic concepts to building evaluated agentic RAG systems entirely on a local machine without cloud dependencies.

## Key Features
- Comprehensive, structured curriculum covering LLMs, Vector DBs, RAG, and Agents
- Hands-on labs with runnable Python code for local execution
- Supports local model inference via Ollama or cloud APIs
- Uses ChromaDB for vector storage with no server requirements
- Free, open-source, and MIT/CC BY 4.0 licensed

## Why It Matters for RAG Builders
It provides a practical, hands-on learning path for building RAG and agentic systems locally, reducing cloud costs and setup complexity for AI engineers.
