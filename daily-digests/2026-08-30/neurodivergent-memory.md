## Summary
A Model Context Protocol (MCP) server implementing a neurodivergent-inspired memory system that organizes thoughts into five cognitive districts, uses BM25 semantic ranking for search, and stores memories as a persistent knowledge graph with bidirectional connections.

## Key Features
- Organizes memories into five cognitive districts (logical_analysis, emotional_processing, practical_execution, vigilant_monitoring, creative_synthesis)
- Uses BM25 semantic ranking for efficient search without embeddings or cloud calls
- Supports persistent memory graph with bidirectional connections and JSON snapshots
- Provides tools for storing, retrieving, updating, and searching memories with emotional metadata and epistemic status
- Offers prompts for guided exploration and synthesis of memories

## Why It Matters for RAG Builders
This MCP server provides a structured, neurodivergent-inspired memory system that enhances RAG pipelines by enabling contextual, semantically ranked memory retrieval and persistent knowledge graph storage for AI agents.
