## Summary
Pinvou Agent is an open-source desktop AI agent designed to transform conversations into tangible deliverables by integrating tools, file management, knowledge bases, and reusable workflows into a unified workspace. It supports local and cloud-based models, enabling private or hybrid AI workflows.

## Key Features
- Multi-session workspace with persistent artifacts and tool calls
- Local and cloud model integration with OpenAI-compatible APIs
- Built-in knowledge base with vector retrieval and memory management
- Extensible via MCP servers, CLI connectors, and reusable workflows
- Cross-platform support (Windows, macOS, Linux) with in-app updates

## Why It Matters for RAG Builders
Pinvou Agent provides a robust, extensible framework for building AI agents that deliver real artifacts, making it essential for developers who need more than just chat-based interactions in their RAG or AI stacks.
