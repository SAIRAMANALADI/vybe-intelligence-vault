## Summary
Chrxmaticc Copilot is a free, open-source terminal-based AI assistant that integrates with multiple AI providers, supports voice input/output, Spotify integration, and a plugin system. It offers persistent memory, offline capabilities, and automatic failover between AI providers.

## Key Features
- Dual AI provider support with automatic failover (Pollinations AI → Groq → Offline)
- Voice input/output integration with Google TTS/STT
- Persistent memory for conversation history (JSON-based, no database required)
- Extensible plugin system for custom commands and integrations
- Spotify integration via OAuth for music control and analysis

## Why It Matters for RAG Builders
It provides a lightweight, offline-capable terminal AI assistant with multi-provider failover and plugin extensibility, making it ideal for developers seeking a customizable, no-subscription AI tool.
