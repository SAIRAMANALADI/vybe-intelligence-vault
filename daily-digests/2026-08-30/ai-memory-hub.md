## Summary
ai-memory-hub is a local-first memory backend for AI agents that enables cross-client handoff, shared project context, and deterministic memory storage, retrieval, and context injection via MCP and HTTP APIs. It supports multiple storage backends and embedding models for semantic search and multilingual retrieval.

## Key Features
- Unified memory backend for AI agents via MCP and HTTP APIs
- Supports multiple storage backends (SQLite, PostgreSQL, MongoDB, vector DBs)
- Deterministic capture, ingestion, retrieval, and context injection workflows
- Semantic search and multilingual retrieval with configurable embedding models
- Cross-client handoff and shared project context for agent tools

## Why It Matters for RAG Builders
It provides a critical memory layer for RAG systems, enabling persistent, cross-client context storage and retrieval that enhances agent coherence and long-term memory capabilities.
