## Summary
OntoRamp Graph Query is a hosted MCP server that enables AI agents to query an organization's architecture and governance constraints directly, providing architecture-grounded answers with evidence chains instead of relying on document similarity.

## Key Features
- Query organizational architecture for grounded answers using documented structure
- Surface governance constraints relevant to proposed actions or decisions
- Trace dependencies between systems and components in the architecture
- Provide evidence chains supporting or contradicting architectural claims
- Offer Agentic Readiness Assessment (ARA) for architecture coverage gaps

## Why It Matters for RAG Builders
It enables AI agents to make architecture-aware decisions by querying organizational structure and governance constraints directly, reducing blind actions and improving reliability.
