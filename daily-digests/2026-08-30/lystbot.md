## Summary
LystBot is a smart list and reminder application designed to integrate seamlessly with AI agents, enabling them to manage lists, reminders, and categories via CLI, MCP, or REST API. The app acts as a real-time interface for human users while exposing a clean API for AI-driven automation.

## Key Features
- Real-time list and reminder synchronization across devices and AI agents
- Multi-modal integration via CLI, MCP, and REST API for AI agents (OpenClaw, Claude, Cursor, etc.)
- Natural language parsing for items (e.g., '3x Milk' or '250g Flour') with structured data support
- Cross-platform support (iOS, Android, CLI) with push notifications for human users
- Shareable lists with collaborative editing and category-based organization

## Why It Matters for RAG Builders
