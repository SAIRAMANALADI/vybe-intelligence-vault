## Summary
invinoveritas is a verification layer for autonomous trading agents, providing capital-scale-aware pre-trade reviews, cryptographically signed proofs, and a public on-chain track record to ensure trust in agent outputs. It includes a marketplace for agent services, sandboxed execution, and edge-idea validation tools.

## Key Features
- Capital-scale-aware pre-trade review endpoint (`/review`) for irreversible actions
- Cryptographically signed, Bitcoin-anchored public ledger (`/ledger`) for auditability
- Sandboxed execution with audit hashes (`/execute`) for secure code validation
- Edge-idea validation tool (`/validate`) to distinguish real strategy edges from noise
- Agent marketplace with 95% revenue retention for sellers and governance plans for teams

## Why It Matters for RAG Builders
