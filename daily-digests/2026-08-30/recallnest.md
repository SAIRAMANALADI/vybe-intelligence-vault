## Summary
RecallNest is a local-first memory system that provides a shared memory layer for coding agents like Claude Code, Codex, and Gemini CLI. It uses LanceDB for vector and full-text search to maintain context across sessions, enabling automatic recall and continuity.

## Key Features
- Shared memory layer across multiple coding agents (Claude Code, Codex, Gemini CLI) via LanceDB backend
- Hybrid retrieval pipeline combining vector search, BM25, recency, and knowledge graph traversal for superior context recall
- Philosophy-informed memory behavior including emotion-aware decay, autobiographical narrative structure, and predictive reminders
- Privacy tiers and cascade forgetting for GDPR compliance and memory governance
- Web UI dashboard with interactive knowledge graph visualization and memory health monitoring

## Why It Matters for RAG Builders
RecallNest solves the critical problem of fragmented context in AI coding agents by providing a unified, persistent memory layer that enhances continuity and recall, making it essential for building robust RAG systems.
