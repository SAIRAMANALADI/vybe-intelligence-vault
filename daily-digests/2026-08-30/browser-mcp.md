## Summary
Browser MCP enables AI agents like Claude Code to control a real Chrome browser session, including handling logins, cookies, and CAPTCHAs, where headless tools fail. It provides 34 tools for browser automation, multi-session support, and human-in-the-loop interactions, all running locally with no data leaving the user's machine.

## Key Features
- 34 built-in browser automation tools for navigation, interaction, and data extraction
- Real Chrome browser control with session persistence, cookies, and 2FA handling
- Multi-session support with color-coded tab groups and session isolation
- CAPTCHA solving (reCAPTCHA, hCaptcha, Turnstile) with AI and human fallback
- Provider integrations for token extraction (Stripe, HubSpot, Slack, etc.)

## Why It Matters for RAG Builders
It bridges the gap between AI agents and real-world browser automation, enabling secure, authenticated interactions with websites that require human-like behavior or bypass anti-bot measures.
