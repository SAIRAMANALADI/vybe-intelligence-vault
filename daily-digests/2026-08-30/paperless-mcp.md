## Summary
A Model Context Protocol (MCP) server for Paperless-ngx, enabling LLMs to interact with document management systems via structured tools and APIs. Designed for autonomous AI agents to read, manage, and analyze documents with built-in safety controls.

## Key Features
- Supports both stdio and Streamable HTTP transports for MCP clients
- Structured error handling and server-side pagination for efficient data retrieval
- Read-only mode and configurable destructive operations for safety
- Built-in workflow prompts (e.g., triage_inbox, monthly_review) for common document tasks
- Names and metadata caching to avoid redundant API calls

## Why It Matters for RAG Builders
It bridges LLMs with document management systems, enabling autonomous agents to process, analyze, and organize documents at scale while ensuring safety and efficiency.
