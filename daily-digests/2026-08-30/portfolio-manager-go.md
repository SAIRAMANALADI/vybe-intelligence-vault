## Summary
Portfolio Manager is a personal finance application that values equities, FX, commodities, bonds, and cryptocurrencies in a user's portfolio while leveraging LLMs to generate trading insights. It supports market data fetching, portfolio analytics, and MCP server integration for LLM-driven automation.

## Key Features
- Multi-asset portfolio valuation with real-time market data
- LLM-powered trading insights via Gemini integration
- MCP server for seamless LLM automation and context
- OpenAPI-compliant backend for easy system integration
- Cloud and local backup/restore with Google Drive and Nextcloud support
