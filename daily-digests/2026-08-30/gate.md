## Summary
Gate is a local MCP reverse proxy that securely exposes local MCP servers, agent skills, and system tools to ChatGPT via a single OAuth-protected endpoint. It enables seamless integration of local commands, file sharing, and custom tools with ChatGPT without cloud migration.

## Key Features
- Secure reverse proxy for local MCP servers and tools
- OAuth-protected endpoint for ChatGPT access
- Built-in command guard for safe shell execution
- File sharing via public URLs
- Pluggable destructive-command guards with structured denial reasons

## Why It Matters for RAG Builders
Gate enables secure, local-first integration of MCP servers and tools with ChatGPT, reducing reliance on cloud-based solutions and enhancing privacy for AI-driven workflows.
