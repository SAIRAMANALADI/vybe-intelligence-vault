## Summary
Danmo Work is an open-source, self-hosted AI work agent that enables long-horizon, multi-agent collaboration for tasks like coding, document editing, and automation. It provides a human-AI co-thinking workspace with a pure LLM-driven control loop, supporting multiple interfaces including CLI, TUI, desktop, and IM channels.

## Key Features
- Pure LLM-driven control loop with no hand-maintained graphs or role routers
- Human-AI co-editing for documents, slides, and spreadsheets with AI Diff (Keep/Revert/hunks)
- Turn Log as state for resume, replay, and editing mid-process
- Multi-agent delegation via `delegate_agent` for isolated sub-tasks
- Support for multiple interfaces: CLI, TUI, desktop, and IM channels (WeChat, Feishu, WeCom, QQ)

## Why It Matters for RAG Builders
Danmo Work provides a robust, self-hosted framework for building AI agents that handle complex, long-horizon tasks with human-AI collaboration, making it essential for RAG builders who need durable state management and multi-agent orchestration.
