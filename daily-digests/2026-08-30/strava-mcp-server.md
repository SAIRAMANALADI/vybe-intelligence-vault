## Summary
A Model Context Protocol (MCP) server that bridges Claude AI with Strava's API, enabling direct querying of athlete data, activities, stats, and segments. It simplifies OAuth setup and provides structured tools for seamless integration.

## Key Features
- Seamless Strava API integration with OAuth setup
- 9+ tools for querying athlete data, activities, stats, and segments
- Supports time-series data (heart rate, pace, cadence) for activity analysis
- Works with Claude Code and Claude Desktop for natural language queries
- Automated tool selection based on user questions

## Why It Matters for RAG Builders
It enables AI assistants like Claude to directly interact with personal fitness data, unlocking personalized insights and automation for athletes.
