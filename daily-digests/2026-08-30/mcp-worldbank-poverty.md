## Summary
This repository provides an MCP (Model Context Protocol) server for accessing World Bank Poverty and Inequality Platform (PIP) data, enabling AI agents to query poverty metrics, inequality estimates, and regional aggregations programmatically.

## Key Features
- Provides direct access to World Bank Poverty and Inequality Platform (PIP) data via MCP tools
- Supports querying poverty headcount, Gini index, welfare metrics, and regional aggregations
- Offers metadata and reference tables for country codes, regions, and poverty lines
- Integrates with Pipeworx gateway for broader data source access
- Supports plain English queries via ask_pipeworx for simplified usage

## Why It Matters for RAG Builders
It enables AI agents to programmatically access and analyze critical World Bank poverty and inequality data, enhancing RAG systems with reliable socioeconomic metrics.
