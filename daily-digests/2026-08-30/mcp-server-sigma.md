## Summary
An enterprise-grade Model Context Protocol (MCP) server that provides 155+ tools for automating and integrating with Sigma Computing's cloud analytics platform, enabling AI agents to programmatically manage workbooks, data models, members, teams, and composite workflows.

## Key Features
- 155+ tools covering workbooks, data models, members, teams, connections, and multi-tenant operations
- Composite workflow recipes for atomic multi-step operations (e.g., template deployment and source swapping)
- Read-only mode and safety gates for destructive operations to mitigate risk
- Seamless integration with AI assistants (Claude, GitHub Copilot, VS Code) and IDEs via MCP
- Multi-region support with configurable API endpoints for Sigma Computing
