## Summary
OpenSidebar is an open-source Chrome extension that embeds an autonomous AI agent in the browser's side panel, enabling users to describe tasks in plain English and have the agent perform multi-step actions like clicking, typing, and navigating across tabs autonomously.

## Key Features
- Autonomous agent loop in Chrome side panel with vision-based page perception (screenshots + DOM snapshots)
- 52+ browser tools for clicking, typing, scrolling, file handling, tab management, and structured data extraction
- Planner-executor-verifier architecture for decomposing and validating complex multi-step tasks
- Local personal profile and site-specific skills with encryption and consent-gated sensitive data handling
- Full-fidelity trace viewer for session replay and debugging, with no telemetry or external backend

## Why It Matters for RAG Builders
It provides a practical, open-source framework for building autonomous browser agents that can handle real-world multi-step tasks, reducing the need for manual scripting and enabling seamless integration with RAG systems for dynamic content interaction.
