## Summary
MCP server providing real-time tennis data (scores, players, fixtures, odds, and AI model win-probability) for ATP, WTA, Challenger, and ITF tournaments via the Live Tennis API. Designed for integration with LLM agents like Claude, Cursor, and Zed.

## Key Features
- Provides 12 MCP tools for live tennis data (scores, players, fixtures, odds, and AI model analysis)
- Supports FREE, BASIC, PRO, and ULTRA tiers with tier-aware responses (no 403 errors)
- Offers both stdio and HTTP transport options for MCP clients
- Includes model win-probability and odds tools for PRO and ULTRA plans
- Self-hostable with deployment scripts for HTTP transport

## Why It Matters for RAG Builders
It enables AI agents to fetch real-time tennis data, odds, and AI-driven win probabilities directly, enhancing RAG systems with dynamic sports analytics.
