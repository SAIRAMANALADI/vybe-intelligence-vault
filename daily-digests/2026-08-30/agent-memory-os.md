## Summary
Agent-Memory-OS is a local-first memory system designed for AI-agent teams, enabling shared, team-scoped, and federated memory management with hard ACLs. It uses a single SQLite file for storage and supports private, agent, team, project, and global memory scopes, with optional semantic vector recall and a built-in MCP server.

## Key Features
- Local-first memory with SQLite backend (no external dependencies required)
- Hard ACLs for private, team, project, and global memory scopes with revocation propagation
- Federated sync across nodes with trust model and org structure convergence
- Associative recall (resonance) and Hebbian reinforcement for memory links
- Built-in MCP server, FastAPI Web UI, and optional semantic vector recall

## Why It Matters for RAG Builders
It provides a dependency-light, team-scoped memory system for AI agents that ensures privacy, federation, and hard ACL enforcement, making it ideal for building secure, collaborative AI workflows.
