## Summary
AJ-MCP is a lightweight Java SDK for building Model Context Protocol (MCP) clients and servers. It simplifies integration with AI systems by providing a minimal, dependency-light framework for Java 8+ and Spring Boot 2.x applications.

## Key Features
- Supports Java 8+ and Spring Boot 2.x for broad compatibility
- Zero dependencies aside from Jackson JSON and OKHttp, ensuring minimal footprint
- Provides both client and server SDKs for MCP, simplifying AI system integration
- Comprehensive documentation and examples for quick adoption
- Modular design with separate common, client, and server libraries

## Why It Matters for RAG Builders
AJ-MCP enables Java developers to easily integrate AI systems with their applications using the Model Context Protocol, reducing development time and complexity.
