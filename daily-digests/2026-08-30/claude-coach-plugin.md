## Summary
A deprecated self-improving learning system plugin for Claude Code that detected friction signals during sessions, proposed skill updates, and recorded events for analysis. It has been replaced by a more advanced semantic analysis tool (`retro-skill`).

## Key Features
- Real-time friction signal detection via hooks (corrections, tool failures, tone escalation)
- LLM-assisted generation of actionable learning candidates using Claude Haiku
- Proactive scanning for outdated tools and dependencies via `/coach scan`
- Approval workflow for skill updates with explicit user consent
- Cross-repo learning and promotion of project rules to global rules

## Why It Matters for RAG Builders
It provided a historical foundation for automated skill improvement in AI agents, though now superseded by more advanced semantic analysis tools.
