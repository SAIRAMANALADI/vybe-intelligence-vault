## Summary
Official LangChain integrations for Oracle Cloud Infrastructure (OCI) and Oracle Database, providing native Python and JavaScript/TypeScript components for OCI Generative AI, OCI Data Science, and Oracle AI Vector Search to build AI agents and applications.

## Key Features
- Native LangChain and LangGraph components for OCI Generative AI, OCI Data Science, and Oracle AI Vector Search
- Python and JavaScript/TypeScript support across multiple packages (langchain-oci, langchain-oracledb, langgraph-oracledb)
- OCI Generative AI chat models, embeddings, agents, and guardrails with multimodal support
- Oracle AI Vector Search vector store, hybrid search, document loaders, and in-database embeddings
- LangGraph persistence and durable agent state management with Oracle Database

## Why It Matters for RAG Builders
