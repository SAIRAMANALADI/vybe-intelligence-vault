## Summary
A Model Context Protocol (MCP) server for ConnectWise Automate that enables AI assistants to interact with RMM (Remote Monitoring and Management) tools via a decision tree architecture. It provides structured access to computers, clients, alerts, and scripts for automation and monitoring tasks.

## Key Features
- Decision tree architecture for structured navigation across domains (computers, clients, alerts, scripts)
- Lazy loading of client initialization and domain handlers for performance optimization
- Comprehensive API coverage for managing computers, clients, alerts, and scripts
- Interactive device card rendering in MCP Apps (e.g., Claude Desktop) for enhanced UI
- Support for both integrator and user authentication methods with optional 2FA

## Why It Matters for RAG Builders
This MCP server bridges AI assistants with ConnectWise Automate, enabling secure and structured automation of RMM tasks for IT operations and monitoring workflows.
