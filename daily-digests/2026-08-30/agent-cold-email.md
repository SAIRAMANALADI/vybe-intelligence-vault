## Summary
agent-cold-email provides an agent-native cold-email infrastructure platform designed to be fully operated by coding agents (e.g., Claude Code, Codex) via 17 high-level tools. It enables automated setup of branded domains, mailbox provisioning, campaign sequencing, and reply management without requiring human dashboard interaction.

## Key Features
- 17 high-level tools for end-to-end cold-email operations (setup, warmup, sequencing, replies, metrics)
- Agent-driven workflow with no human dashboard required (optional dashboard configurable via MCP)
- Per-tenant isolation with branded lookalike domains and dedicated mailboxes
- Built-in compliance and guardrails (CAN-SPAM, suppression lists, auto-pause on complaints, daily send caps)
- Free sandboxed demo mode for testing without real vendor spend or deliverability risk

## Why It Matters for RAG Builders
It enables AI agents to autonomously manage cold-email infrastructure, reducing manual setup and ensuring compliance while maintaining high deliverability standards.
