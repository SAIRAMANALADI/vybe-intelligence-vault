## Summary
A Model Context Protocol (MCP) server providing structured, read-only access to the Islam West Africa Collection (IWAC), a digital archive of 12,000+ newspaper articles, 4,700+ authority records, and 1,500+ publications from West African countries. Designed for AI assistants like Claude to query and analyze data efficiently.

## Key Features
- Provides 37 read-only MCP tools across seven IWAC subsets for querying articles, publications, sentiment, and metadata
- Supports both local (Claude Desktop) and hosted (HTTP) deployments with self-contained bundles
- Includes a research skill for structured workflows, French search strategies, and source attribution
- Precomputes Islamic calendar dates for temporal analysis and supports lunar month granularity
- Offers interactive MCP App views for visualizations and structured content output

## Why It Matters for RAG Builders
It enables AI assistants to efficiently query and analyze a rich, domain-specific dataset of West African Islamic materials, enhancing RAG applications with structured, citable, and culturally nuanced data.
