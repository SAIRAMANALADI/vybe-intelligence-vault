## Summary
Enchan CLI is a privacy-first local AI runtime and agent interface optimized for compact 2B models, designed for responsive CPU use on Windows and Apple Silicon macOS. It provides a CLI, Web UI, and agent runtime with local inference, conversation management, and RAG capabilities entirely on-device.

## Key Features
- Privacy-first local inference with no cloud dependency for model processing
- Optimized for compact 2B models (e.g., gemma4:e2b-it-qat) with CPU-friendly runtime
- Built-in RAG capabilities for local document indexing and retrieval
- Interactive CUI and Web UI with animated mascots and multilingual support
- Stable small-model operation via Enchan Attention Screening and conversation compression

## Why It Matters for RAG Builders
Enchan CLI provides a privacy-preserving, local-first runtime for compact AI models with integrated RAG, making it essential for builders who need offline-capable, CPU-optimized AI agents without sacrificing performance or data control.
