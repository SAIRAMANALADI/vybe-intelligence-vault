## Summary
An MCP (Model Context Protocol) server enabling AI assistants to control Ableton Live 11+ via OSC for music production, beat-making, and creative workflows. It bridges AI tools with Ableton's Live Object Model using standard OSC protocols.

## Key Features
- Enables AI assistants (Claude, Cursor) to interact with Ableton Live via MCP
- Supports MIDI track/clip manipulation, tempo control, and device management
- Uses standard OSC protocol for low-latency communication with AbletonOSC
- Includes a Remote Script patch to extend AbletonOSC's browser and preset loading capabilities
- Provides 25+ MCP tools for comprehensive Ableton Live control
