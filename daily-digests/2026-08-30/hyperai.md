## Summary
HyperAI is a full-stack AI assistant that demonstrates production-grade conversational AI architecture with real-time streaming, semantic memory (STM + LTM), and contextual conversation capabilities using Google Gemini, Pinecone, and Socket.IO.

## Key Features
- Dual-memory architecture (STM + LTM) for context-aware responses
- Real-time token-by-token streaming using Socket.IO and Gemini API
- Semantic memory retrieval with Pinecone vector database and Gemini embeddings
- Modular backend design with JWT authentication and bcrypt password hashing
- Chat history, markdown rendering, and responsive UI with dark/light mode
