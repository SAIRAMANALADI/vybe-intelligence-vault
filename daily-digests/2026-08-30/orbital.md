## Summary
Orbital is a persistent local agent that manages AI projects by coordinating multiple sub-agents (e.g., Claude Code, Codex, Gemini) under a single project context. It handles planning, delegation, supervision, and memory retention while enforcing governance policies like budgets, approvals, and audit trails.

## Key Features
- Persistent project memory with structured state (PROJECT_STATE.md, DECISIONS.md, LESSONS.md)
- Interchangeable sub-agent delegation (Claude Code, Codex, Gemini CLI, etc.) under unified context
- Project-level governance (budgets, approvals, audit trails, and autonomy controls)
- Mobile supervision via QR code pairing and cloud relay
- OS-level sandboxing for secure agent execution

## Why It Matters for RAG Builders
Orbital provides a unified, persistent control plane for managing multi-agent workflows in RAG pipelines, ensuring continuity, governance, and scalability without relying on cloud-dependent solutions.
