## Summary
EnvGuard is a security linting tool designed to detect unsafe environment variables, Docker configurations, CI/CD risks, and runtime vulnerabilities before they reach production. It complements secret scanners like Gitleaks by focusing on configuration-level security issues.

## Key Features
- Scans .env files, Docker, Kubernetes, and CI/CD configurations for security risks
- Detects secrets, weak configurations, and unsafe runtime defaults
- Supports CLI, GitHub Actions, SDK, and MCP server integrations
- Provides multiple report formats (terminal, JSON, SARIF, GitHub annotations)
- Offers presets for Node.js, Next.js, Python, and Docker projects

## Why It Matters for RAG Builders
EnvGuard helps RAG builders secure their deployment pipelines by catching configuration-level vulnerabilities early, reducing exposure to runtime exploits and data breaches.
