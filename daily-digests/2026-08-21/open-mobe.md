## Summary
OpenMobe is an Android application that embeds a full Ubuntu container and an AI agent capable of executing tasks like file editing, package installation, and system commands without requiring root access or a nearby computer. It integrates deeply with the phone's hardware (camera, microphone, notifications) and provides a terminal, file explorer, and agent management interface.

## Key Features
- Runs a full Ubuntu container inside an Android app without root access
- AI agents execute real tasks (e.g., cloning repos, installing packages) in the background
- Deep Android hardware integration (camera, microphone, notifications, screen capture)
- Supports multiple AI models (Anthropic, OpenAI, Google, OpenRouter) with free tiers via OpenRouter
- Self-updating APK with granular permissions control for each agent

## Why It Matters for RAG Builders
It enables AI agents to perform real-world tasks on mobile devices with full Linux capabilities, bridging the gap between AI automation and mobile hardware access.
