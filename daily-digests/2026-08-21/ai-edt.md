## Summary
AI-EDT is an MCP server plugin for 1C:EDT that provides AI assistants with structured, semantic access to 1C projects, metadata, and BSL code. It enables AI agents to interact with live EDT services like validation, debugging, and dependency resolution instead of parsing raw files.

## Key Features
- Provides MCP-compatible tools for AI agents to interact with 1C:EDT's semantic model, including code search, metadata editing, and debugging.
- Enables real-time validation of changes using EDT's built-in validators, preventing errors before deployment.
- Supports live debugging sessions, including breakpoints, variable inspection, and profiling within 1C:EDT.
- Facilitates structured metadata creation and modification (e.g., forms, documents, registers) with dry-run previews and dependency checks.
- Integrates with MCP clients (Claude, Cursor, Copilot) via Streamable HTTP, allowing seamless AI-driven development workflows.

## Why It Matters for RAG Builders
AI-EDT bridges the gap between AI assistants and 1C:EDT by providing semantic access to project data, enabling accurate, context-aware code generation, validation, and debugging for 1C:Enterprise development.
