## Summary
A Go library for web content enrichment, enabling fetching, parsing, and extracting structured data from web pages, including article text, schema.org entities, and metadata like images and dates.

## Key Features
- Extracts article text using trafilatura and custom logic
- Parses structured schema.org data (Place, Article, Event, Organization)
- Supports multiple web search providers for context
- Handles HTTP fetching with stealth and SSRF protection
- Provides caching interfaces for future extensibility

## Why It Matters for RAG Builders
It streamlines the process of enriching raw web content with structured metadata, critical for improving RAG pipeline accuracy and context relevance.
