## Summary
AgentSeed is a governance and persona-driven framework that enforces non-negotiable safety constraints and project-specific rules for AI coding tools. It generates platform-specific configuration files, enforces pre-tool-use hooks, and supports pluggable scenario packs for different use cases like coding, novel writing, or agent-building.

## Key Features
- Enforces immutable core safety rules (e.g., no `rm -rf`, no hallucinated credentials) across all platforms
- Pluggable scenario packs for 6+ use cases (coding, novel, paper, conversation, interactive-novel, agent-builder)
- Generates platform-specific configuration files for 15+ tools (Claude Code, Cursor, Copilot, Windsurf, etc.)
- Includes pre-tool-use interceptors to block dangerous operations before execution
- Self-evolution engine to detect and suggest missing capabilities or skills

## Why It Matters for RAG Builders
AgentSeed ensures AI agents operate within strict, project-specific safety constraints while enabling seamless multi-platform synchronization, reducing setup time and mitigating risks in AI-driven workflows.
