## Summary
Endo is a cross-platform shell and scripting language that blends functional programming concepts from F# with traditional command-line interfaces. It enables structured pipelines with typed records, pattern matching, and type inference while maintaining compatibility with familiar shell conventions like redirects and command execution.

## Key Features
- Structured pipelines passing typed records instead of plain text
- F#-inspired functional programming features like pattern matching and algebraic types
- Cross-platform support for Linux, macOS, and Windows
- Bash compatibility for commands, redirects, and logical operators
- Context-aware tab completions informed by the type system

## Why It Matters for RAG Builders
Endo provides a modern, type-safe alternative to traditional shells, enabling more reliable and maintainable scripting and command-line workflows for AI engineering tasks.
