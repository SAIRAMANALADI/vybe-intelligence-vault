## Summary
Feather DB is an embedded, zero-server vector database and living context engine designed for AI-native applications. It combines HNSW-based ANN search, a built-in knowledge graph, adaptive memory decay, and LLM agent connectors in a single-file persistence model.

## Key Features
- Sub-millisecond ANN search via HNSW with persisted graph for fast cold loads (5–25× faster)
- Built-in knowledge graph with typed edges, reverse indexing, and auto-linking by similarity
- Adaptive memory decay and living context for frequently accessed records
- Self-aligned context engine for automatic ingestion, classification, and namespace organization
- Supports multimodal vectors (text, image, audio) with int8 quantization for memory efficiency

## Why It Matters for RAG Builders
Feather DB provides a high-performance, embedded vector database with built-in context management and LLM integration, making it essential for RAG systems requiring dynamic, self-organizing knowledge storage and retrieval.
