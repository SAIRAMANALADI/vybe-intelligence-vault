## Summary
DevAssistant-MCP is a lightweight MCP-based server that bridges AI coding assistants to local development workflows, offering secure file operations, GitHub integration, semantic codebase search, and automated test execution.

## Key Features
- Secure local file operations with project-root validation
- Semantic codebase search and indexing via ChromaDB
- GitHub activity retrieval (commits, issues, user events)
- Automated test execution wrapper for pytest
- MCP-compatible tooling for AI assistant integration

## Why It Matters for RAG Builders
It provides a secure, MCP-compliant bridge for AI assistants to interact with local development environments, enabling semantic search, GitHub integration, and automated testing for RAG pipelines.
