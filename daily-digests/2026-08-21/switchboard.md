## Summary
Switchboard is a local AI sidekick daemon paired with a browser extension that injects a standard provider (`window.claude`) into any website, enabling users to run AI models, tools, and context locally without sharing API keys or data. It acts as a consent broker for AI capabilities, ensuring explicit per-origin permissions for sensitive actions.

## Key Features
- Injects `window.claude` provider into any website for local AI inference and tool use without API keys
- Explicit per-origin consent UI for all sensitive actions (model calls, tool use, storage access)
- Supports local models (Ollama, LM Studio) and on-device TTS/STT (Kyutai Pocket, Whisper)
- Portable context system allowing cross-app sharing of project data and knowledge
- Native app integration via a daemon that brokers AI capabilities for macOS apps

## Why It Matters for RAG Builders
Switchboard enables RAG builders to deploy privacy-preserving, user-owned AI systems that eliminate reliance on third-party APIs while maintaining seamless integration across web and native applications.
