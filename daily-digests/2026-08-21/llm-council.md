## Summary
LLM Council is a multi-LLM deliberation system where multiple LLMs collaboratively answer questions through peer review and synthesis. It functions as a Python library, MCP server, or HTTP API, enabling parallel LLM queries, anonymous peer review, and final synthesis by a chairman LLM for high-quality responses.

## Key Features
- Parallel LLM querying for diverse responses
- Anonymous peer review and ranking among LLMs
- Chairman LLM synthesis for final high-quality answer
- Multiple gateway integrations (OpenRouter, Requesty, Direct)
- Secure API key management via system keychain or environment variables

## Why It Matters for RAG Builders
It enables RAG builders to leverage multiple LLMs for improved answer quality, reliability, and bias reduction through collaborative deliberation and synthesis.
