## Summary
A production-ready Retrieval-Augmented Generation (RAG) medical chatbot that delivers accurate, context-grounded answers to medical queries using trusted clinical documents. It combines FAISS vector search, HuggingFace embeddings, and Groq LLM inference for hallucination-free responses with source citations.

## Key Features
- Grounded RAG with strict medical context retrieval to prevent hallucinations
- High-throughput Groq LLM integration for sub-second response times
- FAISS-based dense vector retrieval with HuggingFace embeddings
- Dockerized and cloud-ready deployment with multi-platform compatibility
- Automated testing and CI/CD pipeline for reliability

## Why It Matters for RAG Builders
It provides a production-ready template for building domain-specific RAG systems in healthcare, demonstrating robust retrieval, citation, and deployment practices essential for AI engineers.
