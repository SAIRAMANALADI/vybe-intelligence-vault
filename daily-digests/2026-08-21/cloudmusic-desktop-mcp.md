## Summary
A local MCP server that enables AI agents to control the official NetEase Cloud Music desktop client on Windows. It integrates with the client's API and protocol to manage playback, queues, volume, and desktop lyrics without replacing the native player.

## Key Features
- Local-only control of NetEase Cloud Music desktop client via MCP
- Search and play music, manage queues, and adjust playback modes
- Supports desktop lyrics and volume control through localhost-bound CDP
- HTTPS-only search and allowlisted client actions for safety
- Compatible with MCP hosts like Codex or Claude Desktop

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate with a popular music client for real-time playback control and state management, enhancing interactive applications.
