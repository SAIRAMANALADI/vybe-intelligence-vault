## Summary
django-db-purge is a Django package that automates database cleanup by deleting expired records based on configurable retention policies. It includes an MCP server for safe, agent-driven record purging with a preview-execute handshake to prevent accidental data loss.

## Key Features
- Configurable retention policies for automated record deletion
- MCP server for AI agent-safe purging with preview-execute handshake
- Built-in safeguards to prevent accidental data loss
- Supports scheduled purging via cron or django-cron
- Customizable model and field selection for retention policies
