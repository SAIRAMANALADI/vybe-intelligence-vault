## Summary
Agenvoy is a local AI agent framework that autonomously builds, tests, and reuses its own tools while enabling multi-agent collaboration. It operates on your machine, handles multi-step workflows, searches local files, and exposes a tool library to other agents via MCP.

## Key Features
- Auto-generates missing tools when needed and saves them for reuse
- Exposes a sandboxed tool library to other MCP-compatible agents (e.g., Claude Code, Codex)
- Supports scheduled local workflows, file search, and long-term memory
- Provides a web dashboard for monitoring and interaction
- Integrates with multiple AI providers and enforces reasoning control

## Why It Matters for RAG Builders
Agenvoy enables RAG builders to create self-sustaining AI agents that dynamically generate and share tools, reducing manual tool development overhead and enhancing multi-agent interoperability.
