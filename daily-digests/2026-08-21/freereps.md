## Summary
FreeReps is a self-hosted health data server that aggregates, stores, and visualizes data from Apple Watch, Oura Ring, and other sources. It provides a web dashboard for configurable correlations, a built-in MCP server for LLM integration, and a Swift-based iOS companion app for seamless HealthKit syncing.

## Key Features
- Aggregates health data from Apple Watch, Oura Ring, and other sources with configurable source priority deduplication
- Provides a web dashboard with freely configurable correlations, trends, and charts for data visualization
- Includes a built-in MCP server for direct LLM integration and AI-driven insights
- Offers a Swift-based iOS companion app for real-time HealthKit syncing and background processing
- Supports TimescaleDB for efficient time-series data storage and querying
