## Summary
Miro Agent is a personalized AI assistant built on top of the Pi Agent framework, designed to organize thoughts, manage tasks, and automate workflows. It offers both a web-based UI (Aurora Glass) and a terminal interface (TUI) for seamless interaction.

## Key Features
- Web and TUI interfaces with Aurora Glass design for immersive UX
- Subagents for parallel/serial task collaboration and Git workflows
- Built-in Git operations (commit, review, release) with automated version bumping
- MCP server integration for extensible tooling (browser, filesystem, etc.)
- Sandboxed command execution and project-based session management

## Why It Matters for RAG Builders
Miro Agent provides a modular, extensible framework for building AI-driven personal assistants with deep Git integration and workflow automation, critical for developers and teams managing complex tasks.
