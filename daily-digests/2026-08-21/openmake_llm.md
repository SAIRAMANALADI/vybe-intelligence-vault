## Summary
OpenMake LLM is a self-hosted, local-first AI workspace that enables users to run open-weight models locally while optionally integrating external BYOK (Bring Your Own Key) providers. It combines vLLM/LiteLLM inference, autonomous agents, MCP tools, and deep research capabilities in a secure, Docker-isolated environment.

## Key Features
- Unified execution path for local and external models via vLLM/LiteLLM with a context-fit safety net
- Role-based model orchestration allowing per-functional-role model assignment (agent, judge, research, etc.)
- Autonomous agent tasks with persistent Docker sandboxes, human-in-the-loop approval, and deliverable generation (PDF, Excel)
- Deep research pipeline with web search, source verification, and cited synthesis
- Built-in MCP tools (22+) with Docker isolation, Discord gateway bot, and multilingual UI support

## Why It Matters for RAG Builders
It provides a comprehensive, self-hosted platform for orchestrating local and external models with advanced agent capabilities, making it essential for RAG builders who need fine-grained control over model routing, security, and autonomous workflows.
