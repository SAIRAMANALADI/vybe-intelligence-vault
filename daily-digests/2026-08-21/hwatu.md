## Summary
Hwatu is a verification browser designed to accelerate AI agent workflows by providing pixel-perfect validation, animation analysis, and live human hand-off capabilities. It replaces traditional browser automation tools with a warm daemon architecture for sub-40ms verification checks.

## Key Features
- Sub-40ms verification checks with a warm daemon architecture
- Pixel-diff scoring with heatmaps and match percentages
- Animation analysis (duration, easing, velocity) and deterministic frame control
- Live human hand-off with state preservation in tiling window managers
- CAPTCHA detection and structured wait/resume for anti-bot challenges

## Why It Matters for RAG Builders
Hwatu eliminates the latency and resource overhead of traditional browser automation tools, enabling AI agents to verify frontend changes instantly while preserving the ability to hand off to humans for manual intervention when needed.
