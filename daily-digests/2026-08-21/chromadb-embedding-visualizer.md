## Summary
A tool that visualizes ChromaDB vector stores as interactive 3D point clouds in the browser, using UMAP for dimensionality reduction and HDBSCAN for clustering. The frontend renders the scene with Three.js, while the backend precomputes embeddings and caches results for performance.

## Key Features
- Interactive 3D visualization of ChromaDB embeddings with Three.js
- Dimensionality reduction using UMAP for preserving local/global structure
- Automatic clustering with HDBSCAN for labeling points
- Precomputation of embeddings for performance (client-side rendering)
- Supports orbit controls and theme switching (light/dark)

## Why It Matters for RAG Builders
It enables RAG builders to visually validate embedding quality and clustering behavior, ensuring embeddings align with expected document relationships before deployment.
