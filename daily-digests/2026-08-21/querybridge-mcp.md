## Summary
A Model Context Protocol (MCP) server that enables Claude Code and other MCP clients to interact with MySQL databases via JSON-RPC over stdio or HTTP. It provides secure, read-only access with SSH tunnel, SSL/TLS, and multi-database support, along with 40 tools for schema introspection, querying, and diagnostics.

## Key Features
- 40 tools for schema introspection, querying, and diagnostics across 9 categories
- Supports SSH tunnels with host-fingerprint pinning and SSL/TLS encryption
- Read-only by default with configurable write access per connection
- Multi-database and multi-connection support with connection pooling
- CLI for managing connections and Docker image for easy deployment

## Why It Matters for RAG Builders
It provides a secure, standardized way for AI agents like Claude Code to interact with MySQL databases, enabling safe and efficient data retrieval and schema analysis without exposing write capabilities by default.
