## Summary
Ed Agent is a mission-swappable AI agent framework designed to drive requirements through a governed lifecycle with human deliberation checkpoints, ensuring trust, intent capture, and quality. It supports multiple domains (code, marketing, contract, finance) and includes features like red teaming, claim grounding, and an inner loop for self-correction.

## Key Features
- Nine-stage governed lifecycle with swappable squads per mission (code, marketing, contract, finance, optimize)
- Two human deliberation checkpoints (FRAME and TRUST) to ensure intent capture and trustworthiness
- Mission-aware red teaming and claim-level grounding (Grounded/Ungrounded/Contradicted) for artifact validation
- Inner loop with four safety mechanisms (severity gate, overshoot rollback, iron-law hard-halts, budget fuse) for self-correcting refinement
- Memory system that learns user preferences and enforces quality disciplines (no AI-tone filler, quantify-or-flag, no blind praise)

## Why It Matters for RAG Builders
Ed Agent provides a structured, trust-focused framework for AI-driven development that ensures human oversight and quality control, making it essential for building reliable RAG systems.
