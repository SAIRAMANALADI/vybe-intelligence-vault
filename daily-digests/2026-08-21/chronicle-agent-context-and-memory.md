## Summary
Chronicle is an event-sourced memory provider and context engine designed for the Hermes Agent, enabling persistent storage of facts, episodes, and references with provenance tracking. It facilitates memory, recall, and context expansion across sessions for AI agents.

## Key Features
- Dual-tier storage for facts and raw events
- Context pinning and focus for targeted recall
- Entity disambiguation and access control (ACL)
- Provenance tracking for all stored data
- Memory-aware context expansion across sessions

## Why It Matters for RAG Builders
Chronicle provides essential memory and context management for AI agents, enabling persistent, provenance-aware recall and expansion critical for advanced RAG systems.
