## Summary
Noted is a local-first desktop application for taking notes in Markdown/HTML with built-in AI capabilities, wikilinks, global search, Git integration, and a local MCP server for agent workflows. It prioritizes user privacy by keeping all data on-device without telemetry or accounts.

## Key Features
- Rich Markdown/HTML editor with TipTap, tables, formulas, and code blocks
- Multi-provider AI integration (OpenAI, Anthropic, Gemini, LM Studio, Ollama, etc.) with inline suggestions and contextual chat
- Local MCP server enabling agent workflows, file-first agent interactions, and enforced runtime engines
- Git integration for version control, commits, pushes, and PRs
- Global full-text search, wikilinks, backlinks, and quick-open navigation

## Why It Matters for RAG Builders
Noted provides a local-first, AI-enhanced note-taking environment with MCP server capabilities, enabling secure, agentic workflows and seamless integration with RAG systems while prioritizing user privacy.
