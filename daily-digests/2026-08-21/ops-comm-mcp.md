## Summary
A local-first Model Context Protocol (MCP) server designed for enterprise operations, enabling automated error triage, incident response, and workflow synchronization across tools like Sentry, Linear, and Slack.

## Key Features
- Parses Sentry error stacktraces and extracts critical details for debugging
- Synchronizes Linear issues with real-time incident data
- Dispatches structured Slack alerts using Block Kit for incident response
- Calculates algorithmic incident severity scores for prioritization
- Generates blameless postmortem reports in Markdown format

## Why It Matters for RAG Builders
It streamlines enterprise incident response by automating error triage and workflow synchronization across critical tools, reducing manual effort and improving response times.
