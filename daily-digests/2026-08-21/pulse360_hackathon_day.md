## Summary
Pulse360 is a full-stack internal 360° performance review platform designed for semi-annual, quarterly, or monthly review cycles. It supports HR administrators, line managers, and employees through an 8-phase lifecycle, integrating AI-driven feedback analysis and reporting.

## Key Features
- 8-phase review cycle with role-specific workflows (HR Admin, Line Manager, Employee)
- AI-powered feedback theme summarization, comment suggestions, and improvement plan generation using GPT-4o
- Department-scoped peer nominations and manager auto-locking for compliance
- Integration with IBM Bob for agentic AI-driven development and MCP tooling for CSV/PDF report generation
- Synthetic employee data seeding with bcrypt-hashed passwords for secure testing

## Why It Matters for RAG Builders
Pulse360 demonstrates how agentic AI platforms like IBM Bob can rapidly prototype and deploy full-stack HR tools with AI-enhanced features, reducing development time while ensuring compliance and scalability.
