## Summary
Lens is a token-efficient code and documentation retrieval tool for AI agents, enabling precise, context-aware searches, symbol outlines, and surgical line reads to minimize token usage during code analysis. It indexes repositories incrementally and provides a zero-dependency CLI and MCP server for seamless integration.

## Key Features
- Token-budgeted search with ranked snippets and transparent token cost reporting
- Symbol outlines and surgical line reads to avoid reading entire files
- Incremental indexing with change detection and re-indexing capabilities
- CLI and MCP server for agent integration with zero external dependencies
- Web explorer for interactive, IDE-style code navigation and analysis

## Why It Matters for RAG Builders
Lens drastically reduces token waste in RAG pipelines by enabling agents to retrieve only the most relevant code snippets or outlines, optimizing both cost and performance for AI-driven code analysis.
