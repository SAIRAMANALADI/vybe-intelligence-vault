## Summary
A Windows-based AI assistant that integrates with Ableton Live to automate audio mixing, mastering, and workflow tasks via voice or text commands. It uses low-latency protocols and the Model Context Protocol (MCP) for real-time control of audio software.

## Key Features
- Real-time control of Ableton Live via voice or text commands
- Automated mixing and mastering with AI-driven suggestions
- Model Context Protocol (MCP) integration for third-party plugin support
- Low-latency TCP/IP communication for instant audio adjustments
- Local processing with optional cloud metadata reporting
