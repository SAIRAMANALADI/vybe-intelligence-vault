## Summary
mind-query is a Windows desktop application that converts plain English questions into database queries for PostgreSQL, MySQL, SQL Server, and MongoDB. It enables users to interact with their data without writing code by leveraging an AI-powered query engine.

## Key Features
- Converts plain English queries into SQL/MQL for multiple databases
- Supports PostgreSQL, MySQL, SQL Server, and MongoDB
- Local execution with encrypted database credentials
- User-friendly chat interface for querying data
- Built-in help guide and query examples

## Why It Matters for RAG Builders
It simplifies data interaction for non-technical users by enabling natural language queries, reducing the need for manual SQL scripting in RAG pipelines.
