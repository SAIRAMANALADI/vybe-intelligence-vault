## Summary
Open Enthrium AI Agent Runtime is a standalone, cross-platform binary that executes AI agents defined in declarative YAML files, enabling local or API-based workflows without requiring cloud dependencies, frameworks, or complex installations.

## Key Features
- Single-binary deployment for Windows, Linux, and macOS with no dependencies
- 2,600+ built-in connectors for databases, APIs, cloud services, and messaging platforms
- Declarative agent definition using YAML with no coding required
- HTTP server mode for integrating agents into external applications
- Self-hosted, no telemetry, and Apache-2.0 licensed for commercial use

## Why It Matters for RAG Builders
It simplifies AI agent deployment by eliminating framework dependencies and enabling local execution of complex workflows with minimal setup.
