## Summary
ai-assist is an intelligent AI assistant for knowledge workers that integrates with Claude, MCP servers, and Agent Skills to provide automated monitoring, interactive querying, and workflow automation. It supports scheduled actions, knowledge graph tracking, and rich terminal-based interactions.

## Key Features
- Interactive TUI with streaming responses and conversation history
- MCP server integration for tool and data access (e.g., Jira, DCI, personal notes)
- Automated monitoring with scheduled actions and notifications
- Knowledge graph for tracking entities and changes over time
- Support for Agent Skills (specialized instructions and scripts) with security sandboxing

## Why It Matters for RAG Builders
ai-assist provides a unified framework for building and deploying AI agents with MCP integration, automated workflows, and knowledge tracking, making it essential for RAG builders who need structured, interactive, and scalable AI assistants.
