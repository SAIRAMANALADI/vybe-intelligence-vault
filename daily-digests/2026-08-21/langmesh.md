## Summary
LangMesh provides an open-source, self-hosted coding agent harness that allows users to run, customize, and extend the agent's system prompt, tools, and guardrails. It operates as a four-layer system with a library, machine loaders, a daemon, and clients, enabling durable sessions and multi-modal interactions.

## Key Features
- Open-source agent harness with customizable system prompts and tools
- Four-layer architecture (library, machine loaders, daemon, clients) for flexibility and durability
- Supports multi-modal interactions (terminal, app, phone) via a unified API
- Permission modes and hooks for fine-grained control over agent behavior
- Self-hosted with native macOS app and optional remote access via Tailscale

## Why It Matters for RAG Builders
LangMesh empowers AI engineers to build and customize agentic systems without vendor lock-in, enabling full control over the harness layer that shapes agent behavior.
