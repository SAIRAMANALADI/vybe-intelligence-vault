## Summary
An MCP server that enables AI assistants to programmatically control Adobe Premiere Pro, providing tools for timeline inspection, clip manipulation, audio loudness normalization, color grading, and export verification with built-in self-checking mechanisms.

## Key Features
- 53+ tools for precise timeline and clip manipulation with verification steps to confirm actions
- Measurement-based color grading and loudness normalization using ITU-R BS.1770 standards
- Self-checking mechanisms that validate operations by reading back values or confirming file existence
- Built-in critique tools to evaluate edit quality against platform-specific norms
- CEP panel integration with atomic file-based communication between MCP server and Premiere

## Why It Matters for RAG Builders
It enables AI assistants to programmatically and accurately control Adobe Premiere Pro for tasks like editing, grading, and export, ensuring verifiable operations critical for automated video workflows.
