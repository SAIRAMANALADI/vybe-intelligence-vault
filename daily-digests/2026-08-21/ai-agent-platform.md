## Summary
An enterprise-grade AI Agent platform built with Spring Boot 3 and LangChain4j, featuring ReAct reasoning loops, multi-path RAG retrieval, semantic caching, and tool invocation frameworks for scalable AI applications.

## Key Features
- ReAct reasoning loop with dead-loop protection and timeout control for robust agent behavior
- Multi-path RAG combining vector search (Milvus), BM25 keyword retrieval, and RRF fusion ranking
- Semantic caching based on embedding cosine similarity to reduce API costs and improve response latency
- Dynamic model switching (DeepSeek, Qwen, Ollama, etc.) with strategy pattern for flexible AI integration
- Tool invocation framework supporting database queries, external API calls, and automatic tool discovery

## Why It Matters for RAG Builders
This framework provides a production-ready foundation for building RAG-powered AI agents with advanced reasoning, retrieval, and tool integration capabilities.
