## Summary
Comrades of War provides a commercial API and agent integration for accessing a curated archive of historical Spanish Call of Duty clan discussions, including 39,309 posts across 5,857 topics from 2010–2015. Agents can search, preview, and purchase citation-ready forum pages via x402 payments on Base.

## Key Features
- Free search and preview of 39,309 curated posts across 32 sections
- Citation-ready JSON/Markdown with authors, dates, and canonical URLs
- x402 payment model for per-page access at $0.10 USDC on Base
- A2A and MCP-compatible discovery and search interfaces
- Exclusion of sensitive/private community data from commercial API

## Why It Matters for RAG Builders
