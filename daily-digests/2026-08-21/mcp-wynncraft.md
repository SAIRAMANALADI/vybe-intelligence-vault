## Summary
A Model Context Protocol (MCP) server providing keyless lookups for Wynncraft, a Minecraft MMO, enabling AI agents to query player stats, guilds, leaderboards, item databases, and news via a gateway. Part of the Pipeworx ecosystem with access to 1394+ live data sources.

## Key Features
- Keyless lookups for Wynncraft data without requiring API keys
- Supports 10+ tools for player, guild, leaderboard, and item queries
- Seamless integration with AI agents via MCP (Claude Desktop, Cursor, Windsurf, etc.)
- Plain English question-answering interface via ask_pipeworx
- Part of a larger gateway providing access to 1394+ live data sources
