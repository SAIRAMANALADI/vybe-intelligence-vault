## Summary
An MCP server that integrates with Immich to automate photo curation, duplicate detection, geographic album creation, and AI-powered gallery publishing. It leverages OpenAI and Claude APIs for advanced analysis and conflict resolution.

## Key Features
- Automated duplicate detection using perceptual hashing and AI
- Geographic album curation based on GPS coordinates
- AI-powered conflict resolution for merging duplicates or albums
- One-click publishing of responsive web galleries
- Multilingual metadata support with 50+ languages

## Why It Matters for RAG Builders
It streamlines photo library organization by automating curation and publishing, reducing manual effort for AI engineers managing large image datasets.
