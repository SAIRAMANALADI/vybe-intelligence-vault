## Summary
OfficeBuddy is a desktop application that automates Microsoft Word and Excel document tasks by interpreting user prompts, applying changes, and verifying results by opening files in Microsoft Office. It ensures accuracy by self-checking modifications and provides local, privacy-focused document processing.

## Key Features
- Automates Word and Excel document editing via user prompts
- Self-verifies changes by opening files in Microsoft Office for accuracy
- Creates backup copies of original files before modifications
- Runs locally with no external data transmission for privacy
- Supports Windows 10/11 with Microsoft Office 2019+
