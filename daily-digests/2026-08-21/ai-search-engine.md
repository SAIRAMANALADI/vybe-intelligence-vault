## Summary
A Windows desktop application that enables semantic search across local documents using AI embeddings and vector databases. It processes files locally to find relevant information based on contextual meaning rather than keyword matching.

## Key Features
- Semantic search over local documents using AI embeddings
- Supports multiple file formats including PDFs and text files
- Processes files locally without uploading data to external servers
- FastAPI backend for efficient document indexing and querying
- User-friendly GUI for Windows with folder selection and search interface
