## Summary
AgentWeb transforms websites into typed, versioned CLI commands that return structured JSON, enabling coding agents to interact with web services without browser automation overhead. It compiles websites into adapters that agents can invoke via HTTP-like requests, reducing context token usage and improving reliability for read/write tasks.

## Key Features
- Converts websites into typed, versioned adapters for agent use
- Supports both read and write operations with explicit confirmation
- Provides CLI and MCP interfaces for seamless agent integration
- Honest coverage tracking with verified, shape-verified, and unverified statuses
- Built-in telemetry and analytics for usage monitoring without data collection

## Why It Matters for RAG Builders
AgentWeb reduces the complexity of web interaction for AI agents by providing pre-mapped, structured endpoints, enabling reliable and token-efficient task execution without browser overhead.
