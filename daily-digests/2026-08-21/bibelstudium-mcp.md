## Summary
A local MCP server providing precise German Bible study tools with access to four freely licensed translations, original language texts (Hebrew/Greek) with full morphology, concordance, cross-references, full-text search, and critical text comparison across eight editions. Operates entirely offline with data stored in a single SQLite database.

## Key Features
- Four freely licensed German Bible translations (Luther 1912, Schlachter 1951, Elberfelder 1871, Menge 1939)
- Original language texts (Hebrew/Byzantine Greek) with full morphology, Strong numbers, and lexicon data
- Full-text search with FTS5, phrase/prefix support, and Umlaut folding
- Critical text comparison across eight Greek editions with variant witness attestation
- Concordance and cross-reference tools with structured output for AI integration
