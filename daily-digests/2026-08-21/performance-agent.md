## Summary
PerformanceAgent is an open-source AI-powered strength and conditioning coach that integrates with terminal-based AI agents (e.g., Claude Code) to provide scientifically grounded training programs. It combines a deterministic sports science engine with an LLM interface to deliver honest, evidence-backed coaching without hallucinations or cloud dependencies.

## Key Features
- Deterministic sports science engine for calculations (feasibility, periodization, load monitoring) with zero LLM involvement in math
- Evidence-backed coaching with verifiable citations from a local corpus (no hallucinations)
- File-based athlete data storage (plain markdown/YAML) for transparency and offline access
- Integration with terminal AI agents (Claude Code, Gemini CLI, etc.) via MCP protocol
- Versioned training programs with audit trails and adaptive recalibration based on athlete logs

## Why It Matters for RAG Builders
It provides a reliable, transparent, and scientifically accurate alternative to LLM-generated fitness advice, ensuring RAG systems can access trustworthy training data without hallucinations or cloud dependencies.
