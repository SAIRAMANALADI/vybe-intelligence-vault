## Summary
Cohere is a modern, multi-tenant issue tracker designed for teams to plan, track, and ship work collaboratively. It combines real-time Kanban boards, AI-powered triage, GitHub integration, and B2B billing in a single Next.js 16 application.

## Key Features
- Real-time Kanban boards with drag-and-drop and fractional sorting
- AI agent for issue drafting, triage, and duplicate detection via vector embeddings
- Multi-tenant workspaces with B2B billing and plan enforcement
- GitHub integration with one-click setup and bidirectional sync
- Keyboard-first workflows with command palette and single-key shortcuts
