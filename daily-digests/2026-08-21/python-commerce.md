## Summary
A comprehensive Python SDK for AgentScore's merchant-side commerce operations, providing identity middleware, payment helpers, 402 challenge builders, MPP discovery, and Stripe multichain support. It simplifies agent commerce integration with pre-built frameworks (FastAPI, Flask, Django, etc.) and compliance tools.

## Key Features
- Pre-built identity middleware for KYC, sanctions, age, and jurisdiction checks across multiple web frameworks
- 402 challenge builders and x402 protocol support for agent-driven payments
- Stripe multichain support with USDC and Tempo MPP helpers
- Discovery and agent-facing manifest builders (e.g., `/skill.md`, `/llms.txt`)
- Neutral result caching for probe-leg and quote operations to optimize performance

## Why It Matters for RAG Builders
It provides a turnkey solution for merchants to integrate agent-driven commerce with robust identity, payment, and compliance tools, reducing development time and ensuring regulatory adherence.
