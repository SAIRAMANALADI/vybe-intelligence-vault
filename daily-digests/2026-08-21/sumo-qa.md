## Summary
sumo-qa is an MCP server and skills library that enforces senior-QA discipline on AI-generated code by mapping risks to tests, planning QA strategies, and providing merge verdicts based on fresh test evidence rather than stale CI results. It integrates with multiple IDEs and AI hosts to automate test planning, TDD scaffolding, and diff reviews.

## Key Features
- Risk-to-test mapping tied to specific files and lines, not vague categories
- Fresh test execution before merge verdicts to avoid reliance on stale CI results
- Iron-Law skill procedures grounded in ISTQB standards for consistent QA discipline
- Multi-host IDE integration (Claude Code, VS Code, JetBrains, etc.) via MCP
- Automated repo mapping and progressive skill loading for efficient processing

## Why It Matters for RAG Builders
It ensures AI-generated code undergoes rigorous, evidence-based QA before deployment, reducing the risk of undetected flaws in production systems.
