## Summary
WEPPY is an MCP server that bridges AI coding agents (Claude, Codex, Cursor, etc.) with Roblox Studio, enabling direct manipulation of game assets, scripts, terrain, and UI through natural language. It supports multi-place synchronization, asset generation/upload, automated playtesting, and real-time dashboard monitoring for AI-driven game development.

## Key Features
- Direct AI control of Roblox Studio via MCP tools for scripts, instances, terrain, lighting, and assets
- Multi-place synchronization across up to five Roblox Studio windows with Studio ID routing
- Automated asset generation, upload via Roblox Open Cloud, and application to game objects
- Real-time dashboard for monitoring AI actions, sync status, and playtest results
- Bidirectional sync between Studio and local project files with VS Code extension support

## Why It Matters for RAG Builders
It enables AI agents to autonomously build, modify, and test Roblox games in real time, reducing manual effort and accelerating game development workflows.
