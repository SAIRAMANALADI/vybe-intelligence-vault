## Summary
MEDHA is a verification-first AI agent harness written in Rust that enforces deny-first policies, OS sandboxing, and tamper-evident event logging. It operates as a single binary with no external dependencies, supporting any model via OpenAI-compatible or native APIs.

## Key Features
- Deny-first policy with human approval gates for all actions
- OS-level sandboxing (macOS Seatbelt, Linux Landlock, Docker/Podman)
- Tamper-evident, hash-chained event logging for auditing and rewinding
- Supports any model via OpenAI-compatible or native APIs (e.g., Ollama, vLLM, Gemini)
- Semantic code intelligence via LSP integration and structured diagnostics

## Why It Matters for RAG Builders
MEDHA ensures trustworthy AI agent execution by enforcing strict validation, sandboxing, and auditable logging, making it essential for building secure and reliable RAG systems.
