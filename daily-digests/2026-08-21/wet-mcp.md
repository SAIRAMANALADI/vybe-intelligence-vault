## Summary
WET-MCP is an open-source Model Context Protocol (MCP) server that provides AI agents with advanced web search, content extraction, and library documentation retrieval capabilities. It operates without requiring API keys by default, leveraging embedded tools like SearXNG and Qwen3 models.

## Key Features
- 5-strategy web scraping with anti-bot evasion and CAPTCHA support
- Multi-source library documentation search with version-aware queries
- Structured content extraction (Markdown, JSON-LD, code blocks) with smart chunking
- Embedded local Qwen3 models for zero-config embedding and reranking
- Cross-machine synchronization via Google Drive for indexed documents

## Why It Matters for RAG Builders
WET-MCP is essential for RAG builders as it provides a robust, API-key-free foundation for web search, content extraction, and documentation retrieval, enabling seamless integration of real-time and static knowledge into AI agents.
