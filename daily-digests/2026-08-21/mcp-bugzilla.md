## Summary
A Model Context Protocol (MCP) server that enables AI models and clients to interact with Bugzilla instances, providing tools for querying bug information, managing comments, attachments, and performing write operations like status updates and bug creation.

## Key Features
- Comprehensive Bugzilla API integration via MCP for querying, updating, and managing bugs
- Supports read operations (bug info, history, comments, attachments) and write operations (status updates, assignments, bug creation)
- Includes utility tools for quicksearch, server info, and direct bug URL construction
- Handles attachments with configurable delivery modes (inline, saved, or auto)
- Provides detailed prompts and summaries for bug comments to aid AI model context

## Why It Matters for RAG Builders
It bridges AI models with Bugzilla instances, enabling automated bug tracking and management workflows for AI engineering teams.
