## Summary
A free, no-auth crypto news API aggregating real-time and historical data from 200+ sources across 42 languages, with 30+ AI endpoints, SDKs, and MCP server support for seamless integration into AI and RAG workflows.

## Key Features
- Aggregates 200+ crypto news sources with no API key or rate limits
- Provides 30+ AI-optimized endpoints for sentiment analysis, summarization, and market insights
- Offers a 662,000+ article historical archive (2017-2025) with full-text search and ticker-based filtering
- Supports 42 languages with automatic translation and international source coverage
- Includes SDKs (Python, TypeScript, Go, React, PHP), MCP server, and embeddable widgets for easy integration
