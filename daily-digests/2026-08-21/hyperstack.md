## Summary
Hyperstack is a disciplined engineering harness that enforces rigorous development practices for AI coding agents by integrating ground-truth documentation, adversarial skills, and programmatic verification to transform generic LLMs into high-precision Senior Engineers.

## Key Features
- Enforces Iron Laws for code quality and design adherence via 22 adversarial skills with 'enforcement teeth'
- Provides 80 deterministic MCP tools for real-time ground-truth documentation and architectural patterns
- Automated SessionStart hook for seamless integration with IDEs and AI agents (Cursor, Windsurf, Claude Code, etc.)
- Docker-based persistent container for environment stability and low-overhead execution
- Programmatic verification and binary compliance checks before task completion
