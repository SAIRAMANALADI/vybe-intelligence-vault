## Summary
ORION OS is a model-agnostic AI operating system that enforces disciplined research and reasoning before any LLM provides an answer. It acts as a drop-in discipline layer, forcing LLMs to research across multiple sources and adapt to user style while preventing hallucinations or premature conclusions.

## Key Features
- Forces LLMs to research across web sources (GitHub, Reddit, X, YouTube, Google, StackOverflow) before answering
- Implements anti-laziness and anti-give-up discipline gates to prevent premature conclusions
- Token-efficient with persistent system prompts and prompt caching for minimal overhead
- Supports persona adaptation and user-style learning over conversations
- Includes educational component (microGPT) for understanding LLM mechanics

## Why It Matters for RAG Builders
ORION OS is essential for RAG/AI stack builders because it enforces rigorous, evidence-based responses from any LLM, eliminating hallucinations and ensuring reliable, research-backed outputs.
