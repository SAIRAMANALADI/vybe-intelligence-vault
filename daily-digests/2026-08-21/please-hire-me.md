## Summary
An autonomous agent that automates job application submissions by filling out real company ATS forms (Greenhouse, Lever, Ashby) using a user's Chrome browser, ensuring accurate and verified submissions while logging every step for transparency.

## Key Features
- Fills out real job applications in the user's Chrome browser with trusted input, avoiding bot detection
- Supports Greenhouse, Lever, and Ashby ATS forms with verified field mapping and submission
- Logs every answer, screenshots submissions, and maintains a detailed audit trail for transparency
- Configurable via `profile.json`, `answers.md`, and `settings.json` for personalized application criteria
- Includes sourcing over JSON APIs to minimize cost and avoid unnecessary browser interactions

## Why It Matters for RAG Builders
It streamlines repetitive job application tasks, ensuring accurate and timely submissions while reducing manual effort for AI engineers and job seekers.
