## Summary
GodotMaker is an autonomous text-to-game pipeline that converts game ideas into playable Godot 4.x projects using AI agents. It automates design, implementation, testing, and asset generation to rapidly prototype 2D games from natural language inputs.

## Key Features
- Converts natural language game ideas into complete Godot projects with source code, scenes, and assets
- Autonomous agent-driven workflow with minimal human intervention required
- Integrates unit testing (gdUnit4) and end-to-end gameplay testing into the generation process
- Local-first approach with source-available framework and generated projects owned by the user
- Supports iterative design-driven refinement of game concepts and mechanics

## Why It Matters for RAG Builders
GodotMaker accelerates the early stages of game development by automating the creation of playable prototypes, enabling faster validation of game ideas and reducing the time spent on manual implementation.
