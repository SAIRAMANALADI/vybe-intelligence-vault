## Summary
A provably-fair MCP server that enables random selection with verifiable integrity using the drand public randomness beacon. It allows AI agents to run giveaways, raffles, or tie-breaks where the outcome is mathematically guaranteed to be fair and independently verifiable.

## Key Features
- Instant provably-fair winner selection using the latest drand round
- Scheduled draws with pre-committed randomness rounds for future verification
- Publicly shareable proof pages for transparency
- SHA-256-based deterministic winner selection algorithm
- No API keys or accounts required; free to use

## Why It Matters for RAG Builders
It provides a critical primitive for AI agents to perform verifiable random selection tasks without relying on trust in the operator, ensuring fairness in applications like giveaways, raffles, or tie-breaks.
