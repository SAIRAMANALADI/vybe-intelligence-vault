## Summary
whoop-copilot is a Python-based tool that integrates WHOOP wearable data with AI agents like Claude Code via the official WHOOP API. It provides real-time recovery, HRV, sleep, and strain metrics to enable data-driven decision-making without scraping or hardcoded advice.

## Key Features
- Official WHOOP API integration via OAuth 2.0 with auto-refreshing tokens
- Zero interpretation of data—feeds raw metrics directly to AI agents for reasoning
- Optional macOS Calendar/Reminders write-back via AppleScript for actionable insights
- Designed as a Claude Skill for seamless integration with Claude Code
- Unit-tested logic for token refresh and data formatting without requiring live API access

## Why It Matters for RAG Builders
It bridges the gap between wearable biometrics and AI agents by providing real, actionable data without scraping or hardcoded logic, enabling more accurate and personalized AI-driven decisions.
