## Summary
Heddle is a policy-and-trust layer for Model Context Protocol (MCP) tool servers that converts declarative YAML configurations into secure, policy-enforced MCP servers with built-in trust tiers, credential brokering, and tamper-evident audit logging.

## Key Features
- Converts YAML configs into validated MCP tool servers with zero boilerplate code
- Enforces trust tiers (T1-T4) with runtime policy checks and automatic violation blocking
- Built-in credential brokering with runtime secret resolution and policy-based access control
- Tamper-evident, hash-chained audit logging with anomaly detection and secret redaction
- Container sandboxing with Docker isolation, image digest pinning, and watchdog enforcement

## Why It Matters for RAG Builders
Heddle provides a secure, declarative way to expose APIs as MCP tools with built-in trust and audit controls, reducing the complexity of building policy-enforced AI agent ecosystems.
