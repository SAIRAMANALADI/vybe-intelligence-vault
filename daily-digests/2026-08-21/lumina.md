## Summary
Lumina is a production-ready multimodal RAG system that enables users to upload PDFs, images, or text, and interact with cited, grounded answers. It combines hybrid retrieval (BM25 + dense embeddings), cross-encoder reranking, and confidence-based refusal with full pipeline tracing and privacy-focused design.

## Key Features
- Hybrid BM25 + dense retrieval with RRF fusion for robust document search
- Cross-encoder reranking and confidence-based refusal to improve answer quality
- Full pipeline tracing with per-stage latency and score metrics for observability
- Privacy-focused design with optional Google sign-in and per-browser session isolation
- Frozen evaluation set with ablation tables to measure component trade-offs transparently

## Why It Matters for RAG Builders
Lumina provides a production-ready, transparent RAG pipeline with rigorous evaluation and privacy controls, making it essential for AI engineers building reliable, measurable, and user-trusted RAG systems.
