## Summary
A toolkit designed to integrate AI-driven engineering governance into existing projects by analyzing project structures (Java backend, React admin, WeChat mini-programs) and generating standardized governance rules, API/data contracts, testing guidelines, and automated checks without modifying business logic.

## Key Features
- Automated generation of `AGENTS.md` and governance rules for AI agents
- Supports Java (Spring Boot), React, and WeChat mini-programs
- Dry-run mode for previewing changes without execution
- Conflict detection and user file protection
- JSON output for CI/CD and AI agent integration

## Why It Matters for RAG Builders
It enables AI agents to understand and adhere to unified engineering rules before modifying code, reducing errors and improving consistency in AI-driven development workflows.
