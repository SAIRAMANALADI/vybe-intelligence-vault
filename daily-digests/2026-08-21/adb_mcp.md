## Summary
adb_mcp is an MCP server that enables AI agents to programmatically control Android emulators and devices via ADB, providing tools for UI interaction, device management, and diagnostics without manual command handling.

## Key Features
- 49+ tools for Android device/emulator control via ADB, including boot, screenshot, UI hierarchy parsing, and input simulation
- Prebuilt binaries for cross-platform deployment (macOS, Linux, Windows) with no Go dependency required
- MCP resources for reusable skills (e.g., driving guides) and structured tool documentation
- Automated handling of ADB quirks (e.g., screenshot downscaling, true-pixel tap coordinates, retry logic for transient failures)
- Support for app lifecycle management, logcat streaming, Gradle builds, and diagnostics

## Why It Matters for RAG Builders
It eliminates manual ADB command complexity for AI agents, enabling reliable Android device automation in RAG workflows.
