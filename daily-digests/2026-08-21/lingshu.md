## Summary
LingShu is a native macOS AI agent that transforms user goals into verified, end-to-end deliverables like editable presentations, documents, and code reports. It supports bring-your-own-model workflows, isolated task execution, and native macOS app control for local artifact generation and verification.

## Key Features
- End-to-end deliverable creation (PPTX, DOCX, PDF, code) from a single goal brief
- Bring-your-own-model support for OpenAI, Anthropic, DeepSeek, MiniMax M3, or custom endpoints
- Isolated worker sessions for parallel task execution and independent verification
- Native macOS app control via Accessibility APIs for real UI interactions and automation
- Local memory, artifact tracking, and human-in-the-loop collaboration for iterative refinement

## Why It Matters for RAG Builders
LingShu provides a critical orchestration layer for RAG/AI stacks by enabling goal-driven, end-to-end deliverable generation with built-in verification and native macOS integration, reducing reliance on manual post-processing.
