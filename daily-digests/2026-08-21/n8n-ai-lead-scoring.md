## Summary
A free n8n workflow that automates lead scoring by evaluating scraped leads against an Ideal Customer Profile (ICP) using an LLM, then logging results to Google Sheets. It integrates with Apify for lead sourcing and supports any OpenAI-compatible API for scoring.

## Key Features
- Automated lead scoring against custom ICP using LLM (1-10 scale with reasoning)
- Seamless integration with Apify for lead sourcing and Google Sheets for logging
- Supports any OpenAI-compatible API endpoint for flexibility in scoring models
- Deduplication and batch capping for efficient processing
- Includes low-score logging to refine ICP tuning and lead quality assessment

## Why It Matters for RAG Builders
It streamlines lead qualification by automating ICP-based scoring, reducing manual effort and improving lead conversion accuracy for AI-driven workflows.
