## Summary
auto-sme is a deterministic AI content pipeline that generates structured documents (e.g., educational units) using Jinja2 templates, LLMs, and QA validation. It produces print-ready PDFs and supports asset generation like SVGs and alignment notes.

## Key Features
- Template-driven content generation with Jinja2 for consistent structure
- LLM integration (OpenAI/Ollama) for filling content placeholders
- Automated QA validation for page counts, vocabulary, and multiple-choice questions
- PDF generation using WeasyPrint for print-ready output
- Docker-ready deployment for one-command pipeline execution

## Why It Matters for RAG Builders
auto-sme streamlines the creation of structured, validated content for RAG systems by automating document generation with deterministic outputs.
