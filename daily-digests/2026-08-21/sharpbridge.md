## Summary
SharpBridge is an MCP (Model Context Protocol) server that enables AI agents to interactively debug .NET programs by translating MCP tool calls into DAP (Debug Adapter Protocol) commands. It supports multi-session debugging, breakpoints, variable inspection, and execution control for .NET applications.

## Key Features
- Multi-session debugging for multiple .NET processes simultaneously
- Launch or attach to .NET processes with validation for .NET assembly targets
- 24 MCP tools for session management, breakpoints, exception handling, and state inspection
- Smart attach and session management with auto-detection of process instances
- Integration with SharpDbg for low-level .NET debugging via ICorDebug

## Why It Matters for RAG Builders
SharpBridge bridges AI agents and .NET debugging, enabling real-time interactive debugging of .NET applications directly from AI workflows, which is critical for AI-driven development and debugging pipelines.
