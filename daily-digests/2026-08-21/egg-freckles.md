## Summary
A novel AI integration project that brings modern frontier models to the 1997 Apple Newton MessagePad via a native NewtonScript client. It enables real-time chat, device tool access, handwriting recognition, and app generation directly on the NewtonOS emulator or hardware.

## Key Features
- Native NewtonScript client enabling real-time chat with frontier models over WiFi using a framed ASCII protocol.
- Device tool integration via MCP, exposing battery, storage, package management, and application state to the AI agent.
- Handwriting recognition bypassing NewtonOS's built-in OCR, allowing sketches in stock Notes to be processed by vision models.
- Agent-driven app generation and deployment, compiling NewtonScript packages, installing them into an emulator, and testing functionality.
- Hardware compatibility with physical MessagePad devices, including staged package installation over WiFi.

## Why It Matters for RAG Builders
It demonstrates how modern AI can be retrofitted onto legacy hardware, pushing the boundaries of what's possible with constrained, vintage systems while providing a unique testbed for agent-driven device interaction.
