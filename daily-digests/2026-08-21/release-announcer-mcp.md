## Summary
An MCP server that automates the generation of release announcement drafts and publish-readiness checklists for GitHub repositories, streamlining the post-release workflow for open-source maintainers.

## Key Features
- Generates multi-platform announcement drafts (X/Twitter, Reddit, GitHub profile README, awesome-list entries, MCP directory listings)
- Provides a publish-readiness checklist with actionable fix suggestions for missing or suboptimal repository metadata
- No API key required; works with any public GitHub repository
- Designed to produce drafts only—never auto-posts, ensuring human review
- Supports both English and Japanese output for international audiences

## Why It Matters for RAG Builders
It reduces the repetitive post-release workload for open-source maintainers by automating the creation of accurate, platform-specific announcement drafts and identifying gaps in repository readiness.
