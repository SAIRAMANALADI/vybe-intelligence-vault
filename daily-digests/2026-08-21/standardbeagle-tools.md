## Summary
A monorepo providing AI coding agent toolkits and UX-focused MCP packages, including plugins for Claude Code and reusable npm libraries for design, accessibility, and frontend tooling.

## Key Features
- Comprehensive AI coding agent plugins (agnt, lci, tools) for Claude Code with browser superpowers and code intelligence
- Reusable npm packages for UX, accessibility, design tokens, typography, and image processing
- Sub-millisecond semantic code search and call-hierarchy analysis via Lightning Code Index (lci)
- Accessibility audits with WCAG 2.2 compliance and axe-core integration
- Modular architecture with shared core utilities and monorepo management via pnpm
