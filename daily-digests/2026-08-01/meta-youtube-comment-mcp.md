## Summary
A production-ready, human-supervised agent workflow for automating and managing comments on Instagram, Facebook, and YouTube. It classifies, triages, drafts, and publishes replies with deterministic guardrails to ensure factual accuracy and safety, operating as both a CLI tool and a zero-dependency MCP server.

## Key Features
- Multi-platform comment collection (Instagram, Facebook, YouTube) with throttling and rate limiting
- Deterministic guardrails (quote mandate, number guard, keyword guard, style enforcement) to prevent factual drift and unsafe outputs
- Human review queue with audit trails for all actions (queue rows, state.json, and lessons ledger)
- Zero-dependency MCP server for seamless integration with AI workflows
- Evaluated classifier and routing system with synthetic-but-realistic test datasets (98.1% accuracy, 0% unsafe auto-publish rate)

## Why It Matters for RAG Builders
