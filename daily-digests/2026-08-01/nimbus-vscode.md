## Summary
A VS Code extension that integrates a local-first AI agent for querying and interacting with a private Nimbus index directly within the editor. It enables chat-based assistance, semantic search, and context-aware actions while maintaining full data privacy.

## Key Features
- Real-time chat with streaming responses in a side panel or built-in Chat view
- Semantic and keyword-based search over a local Nimbus index with live results
- Context-aware actions like @nimbus commands (/explain, /fix, /test) on file selections
- Audit and egress ledgers for tracking agent activity and data transmission locally
- Troubleshooting tools and guided walkthroughs for seamless onboarding

## Why It Matters for RAG Builders
It bridges local AI agents with VS Code workflows, enabling developers to query private knowledge bases directly within their editor while ensuring data privacy and seamless integration.
