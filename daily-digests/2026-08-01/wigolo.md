## Summary
wigolo is a local-first MCP server that provides AI coding agents with a unified, keyless interface for web-related tasks such as search, fetch, crawl, extract, cache, and research. It operates entirely on-device with no API keys or cloud dependencies, ensuring privacy and cost efficiency.

## Key Features
- Multi-engine web search with rank fusion and ML reranking for high-quality results
- Autonomous gather loops with step-by-step planning and synthesis for complex research tasks
- Persistent local cache with hybrid (BM25 + vector) search and change detection
- Structured extraction of data from web pages (tables, JSON-LD, schemas) with custom schema support
- Transparent per-result scoring and live engine telemetry for explainable outputs

## Why It Matters for RAG Builders
wigolo eliminates API key dependencies and cloud costs for RAG pipelines by providing a local, agent-optimized web intelligence layer that integrates seamlessly with MCP-compatible tools.
