## Summary
Provides multi-language clients (Python, TypeScript) and an MCP server for the Katana Manufacturing ERP API, featuring automatic resilience, rate limiting, pagination, and full type safety for seamless integration into AI workflows.

## Key Features
- Multi-language support (Python, TypeScript) with full type safety
- Automatic retries, rate limiting, and smart pagination for robust API interactions
- MCP server for AI assistants (Claude, Cursor) with curated tools and typed cache
- Generated clients from OpenAPI 3.1.0 spec ensuring complete API coverage
- Monorepo structure with shared documentation and ADRs for maintainability
