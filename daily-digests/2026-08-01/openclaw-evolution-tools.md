## Summary
OpenClaw Evolution Tools provides a modular reference for integrating memory, evolution, and learning capabilities into AI agents. It offers three distinct tools—MemOS Local for hierarchical memory, EvoMap Evolver for self-evolution, and a Self-Improving Agent for structured learning—without runtime implementations or cloud dependencies.

## Key Features
- MemOS Local: Hierarchical memory system (L1 traces → L2 strategies → L3 world model) with SQLite storage and zero cloud dependency.
- EvoMap Evolver: GEP-driven self-evolution engine with auditable evolution paths, genes, capsules, and events.
- Self-Improving Agent: Structured learning with 7 trigger conditions, 3-tier knowledge system, and automatic skill extraction.
- Three-tier gate mechanism for memory consolidation (time, quantity, quality thresholds).
- Clear separation of concerns with no runtime implementations, ensuring modular integration with existing systems.
