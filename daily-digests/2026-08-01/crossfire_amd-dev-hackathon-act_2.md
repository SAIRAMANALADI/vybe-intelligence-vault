## Summary
Crossfire is an AI-powered tool that automates the translation of CUDA source code to AMD ROCm for execution on MI300X GPUs. It combines hipify-clang with a Gemma 4 12B model to handle syntax and semantic translation gaps, validates results through compilation and runtime testing, and provides verification badges for migrated code.

## Key Features
- Automated CUDA to ROCm translation with AI-driven semantic repair using Gemma 4 12B
- End-to-end validation pipeline: compile, run, and diff against expected outputs on MI300X
- Web UI and API for interactive and programmatic translation workflows
- Static analysis for CUDA pattern detection and translation planning
- Verification badges and GPU attestation for migrated code

## Why It Matters for RAG Builders
Crossfire streamlines the migration of CUDA code to AMD ROCm, reducing manual effort and enabling AI engineers to leverage AMD GPUs for their workloads with confidence in translation accuracy and performance.
