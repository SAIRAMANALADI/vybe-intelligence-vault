## Summary
BugBuster Code is a model-agnostic AI coding agent that operates via the terminal, enabling developers to connect any LLM (OpenAI, Anthropic, Ollama, etc.) and leverage 22 built-in tools for code interaction, editing, execution, and multimodal inputs like screenshots and voice.

## Key Features
- Supports any LLM provider (OpenAI, Anthropic, Ollama, etc.) with fallback mechanisms
- 22 built-in tools for code interaction, editing, execution, and system control
- Multimodal capabilities including screenshots, voice (STT/TTS), and vision
- Granular security controls with per-tool permissions and path traversal protection
- Self-awareness and context optimization features like speed mirroring and aggressive compaction

## Why It Matters for RAG Builders
BugBuster Code provides a flexible, secure, and extensible framework for integrating LLMs into coding workflows, making it essential for AI-driven development and RAG pipeline builders.
