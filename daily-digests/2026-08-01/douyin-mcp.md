## Summary
A local MCP server that enables AI agents to analyze Douyin creator data by extracting structured creator metrics, video metadata, and transcriptions from public videos. It bridges Douyin's creator analytics with AI-driven insights while prioritizing privacy and compliance.

## Key Features
- Extracts real-time Douyin creator metrics (plays, likes, comments, retention) via Playwright automation
- Generates time-stamped video transcriptions using local ASR (Faster-Whisper) for AI analysis
- Implements incremental sync with selective transcription loading to optimize performance
- Provides transparent data freshness metrics, coverage rates, and quality warnings for reliable AI insights
- Enforces strict local data handling with no cloud dependencies or unauthorized API access

## Why It Matters for RAG Builders
It enables AI agents to perform data-driven content analysis on Douyin creators by combining structured performance metrics with video transcriptions, all while maintaining local processing and compliance.
