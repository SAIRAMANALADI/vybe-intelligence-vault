## Summary
An MCP (Model Context Protocol) server providing AI-native access to Swiss Federal Statistical Office (BFS) data via the STAT-TAB PxWeb API, offering 682 datasets across 21 themes without authentication. Designed for seamless integration with AI agents and tools.

## Key Features
- Provides 682 datasets across 21 themes from the Swiss Federal Statistical Office (BFS) via STAT-TAB PxWeb API
- No authentication required, fully open data under OGD license
- 13 tools including full-text search, commune reference layer, and cross-cantonal comparison
- Dual transport support: stdio for local use and Streamable HTTP for cloud deployment
- Typed Pydantic models for structured output, enabling seamless integration with AI agents

## Why It Matters for RAG Builders
It provides reliable, structured access to Swiss public statistical data, eliminating the need for manual data scraping and enabling accurate RAG applications with real-time, official figures.
