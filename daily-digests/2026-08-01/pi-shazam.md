## Summary
pi-shazam is a codebase awareness toolkit designed for AI coding agents, providing 7 structural analysis tools powered by tree-sitter and LSP to deeply understand any project. It functions as both a native extension for the Pi coding agent and an MCP server for other AI agents.

## Key Features
- 7 structural analysis tools (overview, lookup, impact, verify, changes, format, rename) for deep project understanding
- Supports multiple languages (Python, TypeScript, JavaScript, Go, Rust, Dart, JSON, YAML) with prebuilt tree-sitter grammars
- Available as a native extension for the Pi coding agent and as an MCP server for other AI agents
- Automated post-edit verification, formatting fixes, and blast radius analysis for safe code modifications
- Cross-platform support (Linux, macOS, Windows) with prebuilt binaries for all major architectures
