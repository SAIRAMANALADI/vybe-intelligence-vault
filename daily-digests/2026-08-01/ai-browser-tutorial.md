## Summary
This repository provides a step-by-step tutorial for enabling AI agents to control a Chrome browser via the MCP protocol, allowing them to automate web tasks like browsing Twitter without relying on expensive APIs. It includes VPS and local Mac setups with detailed deployment instructions.
