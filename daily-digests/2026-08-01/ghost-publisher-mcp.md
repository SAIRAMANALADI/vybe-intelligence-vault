## Summary
A local-first MCP server for interacting with Ghost CMS, enabling AI clients to create, edit, and publish drafts, upload images, and trigger static site rebuilds without exposing full admin API functionality.

## Key Features
- Draft-first content creation with optimistic locking for safety
- Local image uploads with strict path validation and size limits
- Batch publishing with preflight checks and deploy hook triggers
- 11 editorial tools focused on publishing workflows (no delete/unpublish risks)
- Integration with AI clients like Codex and Claude for end-to-end content workflows

## Why It Matters for RAG Builders
It enables AI agents to safely and efficiently publish content to Ghost CMS while maintaining draft-first workflows and avoiding full admin API exposure.
