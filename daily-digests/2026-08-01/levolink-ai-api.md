## Summary
Levolink AI API is a proxy service that provides Chinese developers with stable, low-latency access to 500+ global AI models (Claude, GPT, Gemini, DeepSeek, etc.) without requiring a VPN. It offers transparent pricing, multiple backend channels, and OpenAI-compatible endpoints for seamless integration.

## Key Features
- 500+ AI models from top providers (Claude, GPT, Gemini, DeepSeek, etc.) with unified API access
- Transparent pricing with 33+ pricing groups and real-time updates via GitHub Actions
- China-based CDN acceleration for low-latency (40-200ms) access without VPN
- OpenAI-compatible endpoints supporting streaming, Claude Code, and Codex integration
- Pay-as-you-go model with minimum 1 yuan top-up and invoice support
