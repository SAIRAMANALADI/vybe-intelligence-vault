## Summary
cabal-hunter-mcp is an MCP server that provides on-chain Solana token risk detection tools for agents, including rug and cabal detection. It offers two key tools: `check_cabal_risk` for exit-liquidity risk assessment and `trace_funding` for pre-launch funding trace analysis, both leveraging live Solana blockchain data.

## Key Features
- Real-time Solana token risk assessment with `check_cabal_risk` tool
- Pre-launch funding trace analysis via `trace_funding` tool
- Exit-liquidity risk scoring (SAFE | REVIEW | AVOID) with detailed forensic data
- Honeypot detection (freeze authority + Token-2022 traps)
- Coordinated dump and serial-rugger detection with on-chain evidence links

## Why It Matters for RAG Builders
It provides critical pre-trade risk assessment for AI agents interacting with Solana tokens, preventing rug pulls and coordinated dumps by analyzing funding clusters and on-chain behavior before liquidity is deployed.
