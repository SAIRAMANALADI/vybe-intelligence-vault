## Summary
nocap is a terminal-based UI wrapper for Claude Code that provides a plain-English interface for interacting with the AI assistant. It replaces raw JSON tool calls with a readable feed of actions and requires explicit approval for risky operations, enhancing usability and safety.

## Key Features
- Plain-English terminal interface for Claude Code with no jargon
- Real-time plain-English log of all actions taken by Claude
- Explicit approval cards for risky operations (editing/deleting files, shell commands)
- Local generation of insights to avoid extra token costs
- Support for both interactive and non-interactive (scripting/CI) use cases

## Why It Matters for RAG Builders
nocap simplifies the interaction with Claude Code by providing a user-friendly terminal UI that makes AI agent actions transparent and controllable, reducing cognitive load for developers.
