## Summary
slimctx is a zero-dependency, fully-reversible context compression library for AI agents that reduces LLM token usage by up to 94% while preserving byte-exact reversibility. It supports JSON, logs, code, and text compression with deterministic, audit-friendly transformations.

## Key Features
- Zero-dependency, pure Python stdlib implementation for air-gapped environments
- Byte-exact reversibility for all lossy transforms via content-addressed storage
- Query-aware code skeleton compression with relevant bodies preserved
- Log template mining for efficient repeated line collapsing
- Built-in MCP server for seamless integration with agent frameworks

## Why It Matters for RAG Builders
It enables AI engineers to drastically reduce LLM token costs without sacrificing accuracy or auditability, making it ideal for resource-constrained or client-site deployments.
