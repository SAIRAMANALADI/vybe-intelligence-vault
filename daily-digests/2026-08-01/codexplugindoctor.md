## Summary
Codex Plugin Doctor is a local CLI validator for Codex plugin packages, skills, and MCP server bundles that preemptively identifies packaging, metadata, security, and runtime protocol issues before distribution. It ensures plugin integrity through static validation, security checks, and optional runtime probing.

## Key Features
- Static validation for plugin manifests, skills, and MCP server configurations
- Security checks for hard-coded secrets, path traversal risks, and shell command vulnerabilities
- Runtime MCP protocol validation (initialize, tools, resources, prompts)
- Deterministic output formats (JSON, Markdown, badges) and attestation artifacts
- CI/CD integration with GitHub Actions and npm distribution

## Why It Matters for RAG Builders
It ensures Codex plugin packages and MCP servers are secure, well-structured, and compliant before deployment, reducing runtime failures and security risks in AI applications.
