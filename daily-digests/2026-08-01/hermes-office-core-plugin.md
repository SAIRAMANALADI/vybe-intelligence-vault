## Summary
Hermes Office Core Plugin is a local-first Codex plugin enabling natural language interactions with office files (Excel, Word, PowerPoint, PDF) for tasks like creation, review, and scheduling. It ensures file integrity by never overwriting originals and uses a managed OfficeCLI adapter for structured edits while maintaining strict security and session controls.

## Key Features
- Natural language intent classification for office tasks (Excel, Word, PowerPoint, PDF)
- Strict file integrity with non-overwriting outputs stored in a dedicated sibling folder
- Managed OfficeCLI adapter for structured edits with pinned executable verification
- Session-based security with SHA-256 hashing and automatic marker expiration
- SQLite FTS5 metadata indexing with explicit user permission for full-text access

## Why It Matters for RAG Builders
