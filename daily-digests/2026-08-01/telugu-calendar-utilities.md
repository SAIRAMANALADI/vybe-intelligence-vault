## Summary
Provides subscribable Telugu Panchangam calendar feeds in `.ics` format for 22 cities, covering daily Panchangam details, festivals, and auspicious/inauspicious timings. Includes an MCP server for AI assistants to access detailed astrological data programmatically.

## Key Features
- Subscribable `.ics` calendar feeds for 22 cities with daily Panchangam details
- MCP server for AI assistants to programmatically access astrological data
- Supports three calculation systems: Drik Ganita, Surya Siddhanta, and Vakya
- Provides detailed festival tracking, auspicious/inauspicious timings, and sky events
- Automated monthly feed generation via GitHub Actions with zero hosting cost

## Why It Matters for RAG Builders
It enables AI systems to integrate culturally relevant astrological data and calendar events for Telugu-speaking users, enhancing personalization and utility in RAG applications.
