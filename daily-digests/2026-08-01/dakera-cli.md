## Summary
A Rust-based command-line interface (CLI) for managing Dakera AI's self-hosted memory engine, enabling users to inspect, store, recall, and search agent memories, namespaces, and knowledge graphs directly from the terminal.

## Key Features
- Full management of agent memories, namespaces, and sessions via CLI commands
- Semantic and full-text (BM25) search capabilities for efficient memory recall
- Knowledge graph construction and deduplication for structured memory organization
- Multi-platform support with pre-built binaries for macOS, Linux, and Windows
- Advanced configuration via environment variables, config files, and named profiles

## Why It Matters for RAG Builders
It provides a streamlined, developer-friendly interface to manage and query RAG memory systems, essential for AI engineers building and debugging agent memory pipelines.
