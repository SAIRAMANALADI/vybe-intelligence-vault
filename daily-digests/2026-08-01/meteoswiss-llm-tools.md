## Summary
A monorepo providing Swiss weather data tools for AI assistants via two approaches: an MCP server for structured tool access and an agent skill for direct HTTP API calls. It integrates MeteoSwiss Open Data for real-time and forecast weather information, pollen monitoring, and station discovery.

## Key Features
- Provides real-time weather measurements from ~160 Swiss stations updated every 10 minutes
- Offers multi-day forecasts for ~6000 Swiss locations via postal codes, stations, or place names
- Includes pollen monitoring data from ~15 stations across Switzerland
- Supports both MCP server and agent skill deployment models for flexibility
- Hosted service available for instant use without local setup

## Why It Matters for RAG Builders
It enables AI assistants to access high-quality, real-time Swiss weather data with minimal setup, enhancing contextual accuracy for applications in Switzerland.
