## Summary
A stateless Model Context Protocol (MCP) server that provides phase-aware wellness guidance for AI agents, focusing on menstrual cycle tracking without storing sensitive data. It offers nutrition, training, and hydration recommendations tailored to the user's current cycle phase, including PCOS-aware mode support.

## Key Features
- Stateless cycle data processing with no persistence of sensitive information
- PCOS-aware mode for irregular cycles (21-90 days) with capped confidence
- 17 tools for phase estimation, nutrition, training, and hydration recommendations
- Cross-connector support for Apple Health, Garmin, and Fitbit cycle data
- Privacy-first design with opt-in local preferences for non-sensitive data

## Why It Matters for RAG Builders
It enables AI agents to provide personalized, phase-aware wellness guidance without compromising user privacy by avoiding storage of sensitive cycle data.
