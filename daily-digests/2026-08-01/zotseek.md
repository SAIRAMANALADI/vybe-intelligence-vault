## Summary
ZotSeek is a Zotero plugin that enables 100% local, privacy-preserving semantic search for academic papers using AI embeddings. It includes a built-in MCP server for AI agents like Claude Code to interact with Zotero libraries, enabling programmatic search and citation without cloud dependency.

## Key Features
- 100% local semantic search with no data leaving the machine
- Built-in MCP server for AI agents (Claude Code, Codex) to search and cite papers programmatically
- Hybrid search combining AI embeddings with keyword matching for optimal results
- Support for group library indexing and scoped searches
- Selectable local embedding models including multilingual options
