## Summary
EarnSignal is an evidence-first Web3 income engine that discovers and evaluates work opportunities using deterministic safety gates, ranks expected value, and records execution and revenue via a non-betting TxLINE interface called MatchPulse. It operates entirely within Cloudflare Workers and D1, with no transaction signing or fund movement capabilities.

## Key Features
- Hourly opportunity discovery from multiple sources with deterministic safety gates
- Deterministic 0–100 scoring with fixed weights and hard rejection rules
- D1-based persistence for opportunities, executions, ledger entries, and reports
- Workers AI-powered bilingual explanations with budget enforcement
- MatchPulse non-betting TxLINE interface for transparent event replay

## Why It Matters for RAG Builders
EarnSignal provides a transparent, evidence-driven framework for evaluating and ranking Web3 work opportunities, reducing risk for AI agents and builders by enforcing deterministic safety and explicit human checkpoints.
