## Summary
A self-extending LLM agent on Telegram that dynamically generates, reviews, and registers new tools from plain English descriptions. It enables users to expand the agent's capabilities at runtime while enforcing security through forbidden-pattern checks and admin approvals.

## Key Features
- Runtime generation of new tools from plain English descriptions with automated security reviews
- Per-user RBAC with permission-based tool access control
- Four tool dispatch methods: LLM function calling, explicit commands, trigger keywords, and smart-intent detection
- Scheduled jobs and monitors for automated tool execution
- Built-in 30+ pre-configured tools and support for custom domain tools

## Why It Matters for RAG Builders
It enables AI systems to dynamically expand their capabilities at runtime while maintaining security and user-specific access controls, making it essential for adaptive and extensible agent frameworks.
