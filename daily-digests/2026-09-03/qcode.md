## Summary
QCode is a locally-executed, controlled AI coding agent runtime implemented in Go, designed for long-term product viability with built-in governance, observability, and security. It also serves as an executable engineering knowledge book for AI agent development.

## Key Features
- Locally controlled agent execution with runtime governance and policy enforcement
- Unified runtime protocol for main agents and subagents with shared security semantics
- Built-in sandboxing, permission checks, and journaling for auditability
- Executable engineering knowledge book with source code, tests, and failure modes
- Cross-platform support (macOS, Linux, Windows) with platform-specific sandboxing
