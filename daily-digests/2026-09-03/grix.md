## Summary
Grix is a cross-platform collaboration and instant messaging platform designed for interacting with AI agents as seamlessly as with human colleagues. It enables users to add multiple AI agents as contacts, assign tasks, and manage workflows across desktop, mobile, and web environments.

## Key Features
- Unified interface for managing multiple AI agents (e.g., Claude, DeepSeek, Kimi) as contacts
- Cross-platform support (iOS, Android, Windows, macOS, Linux, Web)
- Real-time task assignment, progress tracking, and collaboration with @mention support
- Role-based agent teams with isolated contexts, permissions, and model settings
- Voice model integration for real-time voice interactions and call handling

## Why It Matters for RAG Builders
Grix provides a centralized platform for orchestrating and collaborating with multiple AI agents, enabling seamless task delegation and progress tracking across diverse workflows.
