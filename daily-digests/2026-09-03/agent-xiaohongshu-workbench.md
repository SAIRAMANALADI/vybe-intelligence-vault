## Summary
A local AI agent-based workbench for Xiaohongshu (Little Red Book) content creation that automates hotspot research, content decomposition, original draft generation, brand-aligned image creation, and manual publishing. It leverages Codex CLI for local execution without third-party API integrations or account data hosting.

## Key Features
- Hotspot research with strict engagement filters (likes ≥ 300, collections ≥ 100, or combined ≥ 400)
- Brand-aligned image generation with 6 series variants per content account
- Chinese AI-content detoxification and original draft refinement
- Multi-account isolation with independent positioning, brand roles, and storylines
- Manual publishing confirmation with versioned local outputs

## Why It Matters for RAG Builders
It provides a local, privacy-preserving agent framework for automating and refining AI-generated content workflows tailored to specific brand identities, reducing manual effort in multi-platform content creation.
