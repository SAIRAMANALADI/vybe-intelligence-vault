## Summary
memory-mcp provides persistent, filesystem-backed memory storage for AI agents via the Model Context Protocol (MCP). It enables agents to retain context across sessions without requiring databases, embeddings, or API keys, using lightweight JSON storage and keyword search capabilities.

## Key Features
- Filesystem-backed storage for persistent agent memory without external dependencies
- Five MCP-compatible tools for CRUD operations and keyword search over memories
- Dependency-light implementation using only Python standard library for auditability
- Environment-variable configurable storage path for flexibility
- Ranked search results across content, tags, and keys for efficient retrieval

## Why It Matters for RAG Builders
