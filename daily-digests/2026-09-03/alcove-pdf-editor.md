## Summary
Alcove is a browser-based PDF editor that mimics Adobe Acrobat's interface, enabling users to view, edit, and manage PDF files directly in their web browser without requiring software installation or an internet connection.

## Key Features
- Browser-based PDF editing with no installation required
- Adobe Acrobat-style workspace for familiarity
- Basic text editing, highlighting, and document saving
- Offline functionality after initial download
- Cross-browser compatibility with modern browsers
