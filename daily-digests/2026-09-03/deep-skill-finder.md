## Summary
Deep Skill Finder is a skill discovery and installation tool for AI agents that uses real execution data and community test records to match tasks with verified, high-quality skills. It replaces keyword-based searches with intent-driven, track-record-based ranking to ensure reliable skill selection.

## Key Features
- Multi-channel recall combining skill profiles, community test posts, and real outputs for precise matching
- Ranking based on verified track records and real community test results, not creator claims
- Autonomous workflow loop for continuous improvement of skill recommendations over time
- Natural language task description support with no special syntax required
- Pre-install risk exposure by surfacing known failure points and boundary conditions

## Why It Matters for RAG Builders
It eliminates the guesswork in skill selection for AI agents by leveraging real execution data, ensuring reliable and high-quality skill integration.
