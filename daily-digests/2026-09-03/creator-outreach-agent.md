## Summary
A white-label autonomous TikTok creator outreach pipeline that discovers, qualifies, and emails creators using local LLMs and APIs. It handles outreach, reply classification, and escalation via Telegram, running entirely on a single machine without cloud dependencies.

## Key Features
- Autonomous TikTok creator discovery and qualification using local LLM (Gemma 4 31B)
- Gmail API integration for email outreach and reply monitoring with account rotation
- Telegram-based escalation and operator approvals for edge cases
- White-label configurable via YAML files (brand, templates, scraping rules)
- Offline testing suite with mocked APIs and temporary databases

## Why It Matters for RAG Builders
It demonstrates a production-ready autonomous agent framework for outreach pipelines, combining local LLMs with API integrations and escalation mechanisms, offering a reusable template for AI-driven marketing automation.
