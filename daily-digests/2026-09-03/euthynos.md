## Summary
Euthynos is a local, read-only MCP server that provides AI coding agents with structural evidence about a repository, including call graphs, dependency edges, and impact analysis, without making any LLM or network calls during queries.

## Key Features
- Provides transitive callers, dependencies, and impact analysis from AST and git history
- Zero LLM or network calls during query execution, ensuring local-first operation
- Supports 16 languages via TypeScript compiler API and tree-sitter WASM
- Offers 23 tools for answering structural questions about codebases
- Includes benchmarked performance metrics and transparency in claims

## Why It Matters for RAG Builders
Euthynos enables AI agents to perform accurate, evidence-based code analysis without external dependencies, reducing hallucinations and improving reliability in RAG and agentic workflows.
