## Summary
Caura (formerly MemClaw) is an open-source, governed memory layer for AI agent fleets that enables multi-tenant, multi-agent systems to store, share, and self-improve memory collectively. It supports hybrid search, knowledge graphs, and trust-based governance for secure cross-agent knowledge propagation.

## Key Features
- Governed memory with tenant isolation and PII detection
- Hybrid search combining semantic, keyword, and knowledge graph retrieval
- Trust-based visibility scopes (agent, team, org) for cross-agent knowledge sharing
- Automated memory enrichment with LLM-derived metadata (title, summary, entities)
- Audit logs, agent trust tiers, and fleet-wide self-improving memory

## Why It Matters for RAG Builders
Caura enables RAG builders to create scalable, governed memory systems for AI agent fleets that learn collectively and avoid repeating mistakes, reducing redundant computations and improving response quality.
