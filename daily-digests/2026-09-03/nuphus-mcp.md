## Summary
nuphus-mcp is a lightweight, cross-platform MCP server that enables AI agents to control desktop and browser automation via the Model Context Protocol (MCP). It provides tools for screen capture, window management, mouse/keyboard input, Chrome automation, and local OCR/vision capabilities without requiring API keys for core functionality.

## Key Features
- 36 MCP tools (15 desktop + 21 browser) for comprehensive automation including screenshots, window control, mouse/keyboard input, and Chrome CDP automation
- Local OCR with PaddleOCR and optional YOLO icon detection for pixel-precise vision capabilities
- BYOK (Bring Your Own Key) vision integration with OpenAI-compatible APIs for semantic understanding
- Zero-cost stdio communication with no daemon or network service required
- Cross-platform support (Windows, macOS, Linux) with safety-first annotations and strict-confirm mode for destructive operations

## Why It Matters for RAG Builders
It enables AI agents to interact with and control desktop and browser environments programmatically, bridging the gap between AI reasoning and real-world computer use.
