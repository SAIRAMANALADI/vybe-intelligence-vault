## Summary
Gugo is a self-hosted, local/intranet AI workspace providing a web and Windows desktop application for building and managing AI agents, skills, memory systems, and tools. It supports structured agent interactions, artifact rendering, and MCP integrations with approval gatekeeping for safety.

## Key Features
- Complete AI agent platform with web and Windows desktop interfaces, supporting structured agent interactions and tool calls
- Built-in skill system (12+ skills) with artifact rendering (PPT, Word, Excel, React, HTML) and real-time previews
- Memory and knowledge graph system with entity/relation/observation triples for persistent cross-session context
- Approval gatekeeping and safety controls for high-risk tool execution with pause/resume and parameter modification
- MCP client/server integration with stdio, SSE, and Streamable HTTP, supporting external tool discovery and invocation

## Why It Matters for RAG Builders
Gugo provides a comprehensive, self-hosted agent framework with advanced memory, safety controls, and artifact rendering, making it essential for building production-grade RAG and AI agent systems.
