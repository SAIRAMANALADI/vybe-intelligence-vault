## Summary
Hara is a coding agent CLI that operates as a configurable, governed organization of role-agents, enabling task decomposition, role-based routing, and multi-platform chat integration. It supports multi-provider LLM endpoints, plan-based execution with approvals, and durable memory management for AI-driven development workflows.

## Key Features
- Role-based agent routing with task decomposition into verified DAGs
- Multi-platform chat gateway (10+ platforms) with two-way image support and approval-gated automations
- Real terminal UX with an Ink TUI, plan mode, and scoped approvals
- Durable memory and learning capture with explicit approval workflows
- Multi-provider LLM support (Anthropic, Volcengine, DeepSeek, OpenAI-compatible) with live streaming

## Why It Matters for RAG Builders
Hara provides a governed, multi-agent framework for AI-driven coding tasks with robust approval workflows and memory management, essential for building scalable and auditable RAG systems.
