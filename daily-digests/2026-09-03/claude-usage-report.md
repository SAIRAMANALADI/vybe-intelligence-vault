## Summary
A Windows utility that integrates with Claude Code to provide real-time usage reports after each prompt, including token counts, estimated costs, context window usage, and rate limit status via a stop hook mechanism.

## Key Features
- Per-prompt token usage and cost reporting
- Context window fill level tracking
- Rate limit status monitoring
- Simple, plain-text output for quick review
- Windows-native stop hook integration with Claude Code

## Why It Matters for RAG Builders
It provides immediate visibility into Claude Code usage metrics, helping developers optimize prompts and avoid unexpected costs or rate limits.
