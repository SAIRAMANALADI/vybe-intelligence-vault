## Summary
Opptrix is an open-source, self-hosted investment research workbench that aggregates multi-market financial data (A-shares, US, HK, JP, KR) and enables users to interact with 150+ research tools and 170+ workflow skills via natural language. It delivers structured reports and real-time market insights through a web-based UI.

## Key Features
- Multi-market financial data aggregation (A-shares, US, HK, JP, KR) with real-time and historical insights
- 150+ research tools and 170+ workflow skills for factor screening, backtesting, and portfolio analysis
- Natural language interface for querying and generating structured investment reports
- Self-hosted deployment via Docker or CLI (`opptrix` npm package) for data privacy and control
- Extensible architecture with support for custom skills and third-party data sources

## Why It Matters for RAG Builders
Opptrix provides a critical bridge between raw financial data and actionable insights for AI-driven investment research, enabling RAG systems to access structured, multi-market financial intelligence with minimal latency.
