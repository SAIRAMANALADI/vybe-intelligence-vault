## Summary
CRBRO is an MCP (Model Context Protocol) server that provides persistent long-term memory for AI assistants by simulating a biological neural architecture. It stores, connects, and retrieves knowledge locally using a file-based system with neurons, synapses, and heat scores, ensuring memory persists across sessions without external dependencies.

## Key Features
- Biological neural architecture (cortex, synapses, hippocampus) for organizing knowledge
- Fact-level search with Orama for precise retrieval across large datasets
- Heat scores for automatic relevance tracking based on frequency, recency, and connectivity
- Credential-aware storage with OS keychain integration for security
- Team memory via shareable git-based spaces for collaborative knowledge

## Why It Matters for RAG Builders
CRBRO enables AI assistants to retain and retrieve contextually relevant knowledge across sessions without external dependencies, enhancing continuity and reducing redundant prompts.
