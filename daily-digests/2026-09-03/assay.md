## Summary
Assay is an open framework for evaluating AI artifacts such as skills, MCP servers, agents, and plugins by inspecting their code and optionally running them in a sandboxed environment to generate auditable behavioral reports.

## Key Features
- Static and behavioral evaluation of AI artifacts (skills, MCP servers, agents, plugins)
- Sandboxed execution with real models to judge artifact behavior
- Generates verifiable, auditable reports for trust validation
- Supports offline evaluation by default, with opt-in behavioral testing
- Integrates with registries for reproducible artifact pinning and integrity checks

## Why It Matters for RAG Builders
Assay provides a critical trust layer for AI artifact ecosystems by enabling reproducible behavioral audits, addressing gaps in provenance, reputation, and static analysis that plague current AI supply chains.
