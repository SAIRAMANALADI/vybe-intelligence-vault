## Summary
mcp-zuul is an MCP (Model Context Protocol) server that integrates Zuul CI with AI agents, enabling structured debugging of build failures, log analysis, and pipeline management without manual UI navigation. It provides 47 tools for real-time CI/CD insights, flaky job detection, and automated failure diagnosis.

## Key Features
- Structured failure analysis with task-level details (play, task, host, error, return code)
- Live pipeline awareness with job progress, ETA, and pre-failure alerts
- ML-based log anomaly detection via LogJuicer integration
- Kerberos/SPNEGO authentication support for secure Zuul access
- 47 tools covering builds, logs, pipelines, jobs, and infrastructure with write operations for CI/CD management

## Why It Matters for RAG Builders
mcp-zuul bridges Zuul CI with AI agents, enabling automated, structured debugging of build failures and real-time pipeline insights, reducing manual effort and accelerating CI/CD workflows for RAG builders.
