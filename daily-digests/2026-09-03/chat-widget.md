## Summary
A lightweight, embeddable AI chat web component that integrates seamlessly into any website using a single script tag. It provides a streaming, brand-adaptive chat interface with built-in protocol client support for the smooth-operator WebSocket protocol.

## Key Features
- Self-contained web component with ~19KB gzipped footprint, requiring no React or external CSS
- Brand-adaptive theming with a single primary color for automatic gradient and depth generation
- Streaming chat with typing indicators, source citations, and secure text rendering (no XSS risks)
- Flexible deployment modes: popover launcher or full-page surface, with deferred loader for performance optimization
- Built-in support for visitor identity, pre-chat forms, OTP verification, and voice input/output (optional)

## Why It Matters for RAG Builders
It provides a drop-in, framework-agnostic chat interface that simplifies the integration of AI-powered chat into any website while ensuring performance and security, making it ideal for RAG builders seeking seamless user interaction layers.
