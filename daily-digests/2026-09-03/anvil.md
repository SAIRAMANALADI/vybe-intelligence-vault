## Summary
Anvil is a terminal-native AI workbench that enables users to interact with multiple AI models simultaneously, manage costs transparently, and securely handle credentials without exposing them to models. It supports 35 AI providers, 138 commands, and runs as a single binary across multiple platforms.

## Key Features
- Simultaneous multi-model consultation with divergence detection via `/consult` command
- Real-time cost tracking and budget enforcement before API calls are made
- Secure credential vaulting with AES-256-GCM encryption and Argon2id key derivation
- Team collaboration features including role-based permissions and end-to-end encrypted chat
- Cross-platform deployment with support for macOS, Linux, Windows, and BSD

## Why It Matters for RAG Builders
Anvil provides a critical layer for RAG builders by enabling secure, cost-transparent, and multi-model orchestration while ensuring credentials remain protected and team collaboration is seamless.
