## Summary
OpenBiliClaw is a local-first, open-source cross-platform AI agent that builds a deep psychological profile of the user to proactively discover and recommend personalized content across multiple platforms like Bilibili, Xiaohongshu, Douyin, YouTube, X, Zhihu, and more. It prioritizes user privacy by keeping all data on-device and supports integration with tools like DeepSeek Harness.

## Key Features
- Builds a five-layer psychological profile (events → preferences → insights → traits → soul) to deeply understand user preferences beyond click history
- Proactively explores and recommends content across 12+ platforms (Bilibili, Xiaohongshu, Douyin, YouTube, X, Zhihu, Reddit, etc.) based on user understanding
- 100% local data storage with SQLite, ensuring complete privacy and user control over data
- Supports integration with DeepSeek Harness via a dedicated plugin, enabling AI agents to leverage OpenBiliClaw's tools for content discovery
- Offers multiple interfaces: browser extension, desktop/mobile web, Flutter native apps, and CLI tools for customization

## Why It Matters for RAG Builders
OpenBiliClaw empowers RAG/AI stack builders to create highly personalized, privacy-preserving content discovery agents that understand users deeply and proactively fetch relevant content across platforms.
