## Summary
Excalimate transforms hand-drawn Excalidraw diagrams into animated presentations with keyframe-based effects like opacity fades, position slides, and arrow draw-ons. It includes an MCP server for AI agents to generate and animate diagrams in real-time, supporting exports as MP4, WebM, GIF, or animated SVG.

## Key Features
- Full Excalidraw editor integration for drawing and editing diagrams
- Keyframe animation engine with opacity, position, scale, rotation, and draw effects
- Real-time AI agent integration via MCP server with live preview
- Multi-format exports (MP4, WebM, GIF, animated SVG)
- E2E encrypted sharing with AES-256-GCM

## Why It Matters for RAG Builders
It bridges static diagrams and dynamic AI-generated content, enabling RAG systems to produce animated explanations or visualizations directly from text prompts.
