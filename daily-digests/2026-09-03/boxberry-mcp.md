## Summary
Boxberry MCP is a Model Context Protocol (MCP) server that provides 6 tools for interacting with Boxberry's API, enabling delivery cost calculation, pickup point search, shipment tracking, and postal code validation for Russian logistics. It bridges neural networks with Boxberry's services for seamless integration.

## Key Features
- 6 integrated tools for Boxberry API: cities, pickup points, delivery cost calculation, shipment tracking, postal code validation, and service listing
- Supports both stdio and HTTP transport modes for MCP clients
- Smithery compatibility for containerized deployment
- Pre-built skills for Claude Code integration
- Environment variable configuration for API token and port

## Why It Matters for RAG Builders
It simplifies integration with Boxberry's logistics API for AI agents needing real-time delivery calculations, tracking, and pickup point data in Russia.
