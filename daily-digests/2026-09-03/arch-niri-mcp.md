## Summary
An MCP server that enables AI assistants to inspect, control, and automate Arch Linux, CachyOS, and the Niri Wayland desktop environment through 35+ tools for system management, window control, and hardware interaction.

## Key Features
- 35+ tools for Arch Linux, CachyOS, and Niri DE control via MCP
- Dynamic CLI tool discovery and terminal execution
- Comprehensive Niri DE window, workspace, and layout management
- Hardware and system monitoring (battery, audio, network, brightness)
- Package management integration (pacman, AUR, CachyOS repos)

## Why It Matters for RAG Builders
It provides AI assistants with deep, real-time control over Linux desktop environments and system resources, enabling advanced automation and contextual awareness for RAG systems.
