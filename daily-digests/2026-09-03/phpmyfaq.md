## Summary
phpMyFAQ is an open-source, multilingual FAQ platform designed for modern knowledge management, offering AI-ready search capabilities, flexible content management, and enterprise-grade authentication. It supports multiple databases and search engines, with deployment options for traditional hosting or cloud environments.

## Key Features
- AI-ready search with Elasticsearch/OpenSearch integration
- Multilingual support (40+ languages) with WYSIWYG editing
- Enterprise authentication (LDAP, Active Directory, Entra ID, 2FA)
- Scalable, database-driven architecture with revision history
- Docker-based deployment with modular service profiles
