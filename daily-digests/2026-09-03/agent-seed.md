## Summary
agent-seed is a starter kit for a self-evolving AI assistant that operates using markdown files and supports multiple AI engines like Claude Code, Codex, and Devin. It enables users to set up and interact with an AI personal assistant without requiring deep programming skills or complex setups.

## Key Features
- Self-improving AI assistant using markdown input/output
- Supports multiple AI engines (Claude Code, Codex, Devin, Cursor)
- No programming or complex setup required
- Designed for Windows users with minimal system requirements
- Encourages iterative improvement through user interactions
