## Summary
A product-agnostic orchestrator for multi-channel product promotion that quantifies conversion funnels, self-tunes tactics via bandit algorithms, and enforces compliance through dry-run defaults and fail-closed policies. It delegates scheduling and execution to external tools while centralizing configuration and feedback loops.

## Key Features
- Six-layer conversion funnel tracking with quantified feedback
- Thompson-Sampling bandit for self-tuning promotional tactics
- Dry-run mode by default with fail-closed compliance gates
- Per-channel authorization and platform-agnostic configuration
- Delegated scheduling and execution to external tools (e.g., schedule-reminder)

## Why It Matters for RAG Builders
It provides a structured, compliance-first framework for automating multi-channel product promotion while optimizing conversion funnels through adaptive algorithms, reducing manual intervention and risk of policy violations.
