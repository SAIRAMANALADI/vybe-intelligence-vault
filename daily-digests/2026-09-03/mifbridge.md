## Summary
MifBridge is an MCP server that enables AI agents to programmatically interact with Unreal Engine and Blender, allowing for bidirectional editing, compilation, and rendering workflows. It bridges two DCC tools via a unified interface, providing real-time feedback and error mapping for Blueprints and Blender operations.

## Key Features
- Enables AI agents to compile, edit, and debug Unreal Engine Blueprints with real-time error mapping to nodes and pins
- Provides a full suite of typed, guarded operations for Blender, including modeling, lighting, animation, rendering, and geometry-node authoring
- Supports bidirectional mesh round-trips between Unreal Engine and Blender via a unified MCP interface
- Implements safety gates (read/scratch/full modes) and transaction-based undo for all operations
- Includes parity checks to ensure endpoint-tool synchronization across both backends

## Why It Matters for RAG Builders
MifBridge closes the loop for AI-driven DCC workflows by providing real-time feedback and error mapping, eliminating manual iteration loops and enabling fully automated, closed-loop AI agents for Unreal Engine and Blender.
