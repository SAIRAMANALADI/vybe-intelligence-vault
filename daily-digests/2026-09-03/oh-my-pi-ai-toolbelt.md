## Summary
Oh-My-Pi AI Toolbelt transforms the terminal into an intelligent, agentic workspace with hash-anchored edits, multi-agent collaboration, and LSP integration. It enables automated code refactoring, browser control, and real-time debugging for terminal power users.

## Key Features
- Adaptive subagent network for specialized tasks (code refactoring, debugging, data pipelines)
- Hash-anchored edit engine with cryptographic versioning for immutable audit trails
- Native LSP integration across Python, TypeScript, Rust, and Go for real-time code intelligence
- Headless browser control for web automation and live previews
- Privacy-first local LLM support with multi-provider API fallback logic
