## Summary
Mcode is a desktop GUI for Claude Code built on the Claude Agent SDK, providing a three-pane IDE with session management, real-time streaming, tool approvals, and IDE affordances like file management, Git integration, and a terminal.

## Key Features
- Real-time conversation with structured message rendering and tool approvals
- Multi-session tab management with persistent SQLite storage
- Built-in IDE capabilities: file tree, Git integration, and terminal
- Rich settings for model configuration, appearance, and terminal/Git preferences
- Auto-update via electron-updater and provider abstraction for future agent platforms

## Why It Matters for RAG Builders
Mcode provides a user-friendly interface for interacting with Claude Code, simplifying session management and tool approvals for AI-driven development workflows.
