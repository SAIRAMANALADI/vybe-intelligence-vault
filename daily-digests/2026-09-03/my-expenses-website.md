## Summary
A personal expense management application built with Next.js that combines transaction tracking, AI-powered categorization, bulk imports, and a streaming AI chat assistant in a single full-stack solution.

## Key Features
- AI-powered transaction categorization with FastText and LLM integration
- Bulk imports from credit-card statements with Excel extraction service
- Streaming AI chat assistant for real-time expense queries and insights
- Subscription detection and recurring transaction management
- Comprehensive observability with structured logging, uptime monitoring, and alerting
