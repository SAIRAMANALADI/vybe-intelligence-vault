## Summary
GimpMCP is an MCP server that enables LLMs like Claude Code to interactively control a running GIMP 3.0 instance for image editing, layer manipulation, and advanced GIMP operations via Script-Fu. Edits are visible in real-time as they occur in the GIMP window.

## Key Features
- Real-time GIMP 3.0 control via MCP for LLMs
- 35+ tools for images, layers, selections, and filters
- Support for arbitrary Script-Fu and GEGL operations
- Live visualization of edits in GIMP window
- Cross-platform (Windows/macOS/Linux) with GIMP 3.0+

## Why It Matters for RAG Builders
It bridges LLMs with GIMP for automated, interactive image editing and manipulation, expanding AI-driven creative workflows.
