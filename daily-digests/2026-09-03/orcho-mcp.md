## Summary
orcho-mcp is an MCP (Model Context Protocol) server for Orcho, exposing its runtime to MCP-aware clients like Claude Code or Cursor. It enables AI-driven control of agentic software delivery workflows, allowing clients to start, observe, decide, and inspect runs without log scraping.

## Key Features
- Exposes Orcho's runtime to MCP clients for seamless AI-driven workflow control
- Supports full control loop: act, observe, decide, inspect, and resume runs
- Provides read-only and decision-support tools without spawning pipeline processes
- Offers live progress notifications and structured run lifecycle management
- Includes workspace cleanup tools with confirmation tokens for safe resource reclamation

## Why It Matters for RAG Builders
It enables AI agents to directly control and inspect production-grade agentic software delivery workflows via a standardized protocol, reducing manual intervention and log scraping overhead.
