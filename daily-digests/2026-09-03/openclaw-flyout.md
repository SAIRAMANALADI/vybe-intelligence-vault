## Summary
A pinnable Quickshell side panel for Arch Linux that enables real-time chat with an OpenClaw agent via a local OpenAI-compatible bridge. It integrates seamlessly with desktop environments like Hyprland or KDE-Wayland, offering token-by-token streaming, session management, and terminal hand-off capabilities.

## Key Features
- Pinnable side panel with Super+O toggle for quick access
- Local OpenAI-compatible bridge for streaming agent responses
- Session management with recent-chats drawer and history persistence
- Terminal hand-off capability for seamless workflow transitions
- Shell-agnostic design that survives desktop environment updates

## Why It Matters for RAG Builders
It provides a lightweight, desktop-integrated UI for interacting with local or remote AI agents, enhancing productivity for AI-driven workflows on Linux.
