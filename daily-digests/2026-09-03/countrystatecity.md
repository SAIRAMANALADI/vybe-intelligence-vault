## Summary
Provides a comprehensive, versioned dataset of global location data (countries, states, cities, districts) as an NPM package, MCP server, and hosted REST/GraphQL API. Supports search, reverse geocoding, timezone utilities, and multiple data formats.

## Key Features
- Versioned and immutable location data with stable public IDs for reproducibility
- Multi-format support (JSON, CSV, XML, YAML) and TypeScript type definitions
- MCP server integration for AI assistants like Claude Desktop
- Advanced search with typo tolerance, multilingual support, and ranked results
- Nearest-centre lookup with spatial indexing and timezone utilities

## Why It Matters for RAG Builders
It provides a reliable, versioned, and searchable global location dataset that can enhance RAG systems with accurate geospatial and administrative context for applications requiring precise location data.
