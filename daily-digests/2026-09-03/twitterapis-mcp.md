## Summary
Official Model Context Protocol (MCP) server for twitterapis.com, providing native Twitter/X API tools for AI agents like Claude, Cursor, and Windsurf. Enables read/write operations (search, profiles, timelines, posts, likes, follows) via a stateless MCP server that forwards API calls to twitterapis.com endpoints.

## Key Features
- 51 native tools for Twitter/X API operations (37 reads, 14 writes) including search, profiles, timelines, and social graph interactions
- Seamless integration with MCP clients (Claude, Cursor, Windsurf, VS Code) via npx or direct installation
- Supports both free account reads and authenticated session-based writes (follow, post, like, DM)
- Per-call or session-based authentication for flexible usage patterns
- Paginated endpoints with cursor support for large datasets (e.g., full tweet history)

## Why It Matters for RAG Builders
Provides direct, tool-based access to Twitter/X data for AI agents, enabling real-time social media analysis and interaction without requiring custom API integrations.
