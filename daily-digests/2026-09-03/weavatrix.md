## Summary
Weavatrix is an MCP server that builds dependency graphs for local repositories, enabling AI coding agents to analyze code structure, change impact, and blast radius. It provides 32 tools for graph-based code analysis, health audits, and architecture verification, all while operating locally-first with optional network features.

## Key Features
- Builds dependency graphs for local repositories with support for multiple languages (JS/TS, Rust, Java, Python, Go)
- Provides 32 tools for graph-based analysis, including change impact, transitive dependents, health audits, and architecture verification
- Operates locally-first with optional network features (OSV, hosted sync) controlled via security profiles
- Supports hot-reloading of MCP tool modules and catalog for seamless updates
- Includes bounded-output controls for agent-friendly responses and structured metadata

## Why It Matters for RAG Builders
Weavatrix enables AI coding agents to perform precise, graph-aware refactoring and dependency analysis, reducing blind spots in code changes and improving the reliability of automated code modifications.
