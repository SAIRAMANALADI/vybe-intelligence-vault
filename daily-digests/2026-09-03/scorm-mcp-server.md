## Summary
A Model Context Protocol (MCP) server that converts self-contained HTML, Claude Design bundles, or Teach on Mars content exports into SCORM 2004/1.2 packages for LMS integration. It inlines assets for offline use, injects tracking for completion, progress, and scores, and validates manifests against ADL schemas.

## Key Features
- Converts HTML, Claude Design bundles, or Teach on Mars exports into SCORM packages with 100% offline assets
- Injects runtime for completion, progress, and score tracking with resume support
- Validates manifests against official ADL XSD schemas for SCORM 2004/1.2
- Supports batch processing for multiple courses and Teach on Mars content migration
- Provides CLI, web UI, and MCP tool for seamless integration with AI workflows

## Why It Matters for RAG Builders
It enables AI-generated or web-based learning content to be packaged into SCORM-compliant packages for seamless LMS integration, ensuring offline functionality and standardized tracking.
