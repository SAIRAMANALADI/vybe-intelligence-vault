## Summary
A comprehensive UK property data toolkit that aggregates Land Registry sales, EPC certificates, Rightmove listings, rental yields, stamp duty calculations, planning portal links, and Companies House records. It can be used as a Python library, CLI, HTTP API, or MCP server for real estate and property analysis.

## Key Features
- Aggregates multiple UK property data sources (Land Registry, EPC, Rightmove, Companies House) into a single package
- Supports multiple interfaces: Python library, CLI, HTTP API, and MCP server
- Provides rental yield analysis, stamp duty calculations, and block-level sales grouping
- Includes planning portal lookup and energy performance certificate (EPC) data
- Offers deployment flexibility via Docker and cloud platforms (Fly.io)

## Why It Matters for RAG Builders
It provides a unified, high-quality data pipeline for UK property information, essential for building RAG systems focused on real estate, investment analysis, or property market insights.
