## Summary
pi-go is a terminal-based coding agent built on Google's ADK Go framework, enabling multi-provider LLM interactions with sandboxed tools, interactive TUI, session persistence, and a multi-agent system for AI-driven development workflows.

## Key Features
- Multi-provider LLM support (Claude, GPT, Gemini, Ollama) with configurable roles
- Sandboxed tools for safe file system and shell operations within project directories
- Interactive TUI with Markdown rendering, slash commands, and theming via Bubble Tea v2
- Memory Palace system with 4-layer contextual memory (SQLite, embeddings, knowledge graph)
- Subagent system for process-based multi-agent orchestration and concurrency

## Why It Matters for RAG Builders
pi-go provides a robust, extensible framework for building AI-powered coding agents with persistent memory, multi-agent orchestration, and secure tool execution, critical for advanced RAG and AI-driven development workflows.
