## Summary
OMZ (Oh My ZCode) is a ZCode plugin that ports the orchestration capabilities of oh-my-openagent to enhance multi-agent parallel execution, role specialization, independent review, and interview-based planning in ZCode projects. It operates with zero intrusion by default and offers optional profiles for advanced orchestration, dashboarding, and graph-based workflows.

## Key Features
- Zero-intrusion default behavior: OMZ does not alter ZCode's default chat behavior unless explicitly triggered via commands like `/ulw`, `/team`, or `/hyperplan`.
- Nine specialized sub-agents (e.g., planner, critic, deep coder, reviewer) with distinct roles and tool restrictions for structured workflows.
- Optional profiles for orchestration (MCP coordinator), dashboarding (HTTP/SSE), and graph-based workflows (CodeGraph integration).
- SQLite-backed task scheduling and state management for reliable multi-agent coordination and dependency tracking.
- Comprehensive self-check and validation tools (e.g., `/omz-doctor`, `npm run doctor`) for deployment and runtime verification.

## Why It Matters for RAG Builders
OMZ enables AI engineering teams to build more reliable, parallelized, and review-driven workflows within ZCode by leveraging specialized sub-agents and optional orchestration profiles without disrupting existing workflows.
