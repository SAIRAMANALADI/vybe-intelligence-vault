## Summary
open-zk-kb provides persistent, cross-tool memory for AI agents by storing corrections, preferences, and context in a local Zettelkasten-style knowledge base. It enables agents to retain learned information across sessions and tools, improving consistency and reducing repetitive explanations.

## Key Features
- Persistent agent memory across sessions and tools without cloud dependency
- Hybrid search combining SQLite FTS5 and local vector embeddings for semantic relevance
- Local-first architecture with plain Markdown files for version control and transparency
- Obsidian integration for visualizing and managing knowledge graphs
- Zero-configuration setup with support for multiple AI clients (Claude, Cursor, etc.)

## Why It Matters for RAG Builders
It solves the critical problem of AI agents losing context between sessions by providing a persistent, local memory system that improves agent consistency and reduces repetitive setup overhead.
