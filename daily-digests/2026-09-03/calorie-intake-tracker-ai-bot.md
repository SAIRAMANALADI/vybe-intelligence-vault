## Summary
A privacy-first AI nutrition and calorie tracker for Telegram and Mattermost that enables zero-friction logging of meals via text, voice, photos, or nutrition labels. It leverages OpenAI for interpretation, PostgreSQL for data integrity, and integrates with Open Food Facts, SearxNG, and Browserless for autonomous nutrition extraction.

## Key Features
- Zero-friction meal logging via text, voice, photos, or barcodes
- 100% private and self-hosted with immediate media destruction
- AI reasoning with deterministic Python execution for data integrity
- Multi-frontend support for Telegram and Mattermost with identity linking
- Autonomous tool ecosystem integrating Open Food Facts, SearxNG, and Browserless

## Why It Matters for RAG Builders
It provides a privacy-preserving, AI-enhanced alternative to commercial nutrition trackers, enabling self-hosted, high-integrity calorie logging with minimal user friction.
