## Summary
model-compose is a declarative YAML-based framework for composing, deploying, and scaling AI services like chat APIs, RAG pipelines, and autonomous agents without writing application code. It enables portable, hybrid-first AI workflows that run locally or in production with minimal configuration changes.

## Key Features
- Declarative composition of AI workflows using YAML, eliminating boilerplate code
- Hybrid-first architecture supporting both local and cloud models with seamless integration
- Portable deployment across Docker, native, and distributed environments without re-engineering
- First-class streaming support for tokens, audio, video, and real-time interactions
- Built-in support for 20+ components including models, agents, vector stores, and MCP servers

## Why It Matters for RAG Builders
It simplifies the deployment and scaling of RAG and AI pipelines by abstracting infrastructure complexity into a single YAML file, enabling rapid iteration and hybrid model usage without vendor lock-in.
