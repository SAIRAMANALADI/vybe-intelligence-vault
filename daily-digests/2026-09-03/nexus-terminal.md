## Summary
Nexus Terminal AI is a terminal-based intelligent assistant that enables users to interact with multiple AI models directly from the command line. It provides an interactive interface for model selection, conversation management, and markdown rendering with support for 8 different AI models.

## Key Features
- Interactive arrow-key model selector for 8 AI models
- Full command system with 15+ commands for conversation management
- Markdown rendering with syntax-highlighted code blocks
- Conversation save/export in JSON and Markdown formats
- Session statistics and config persistence
