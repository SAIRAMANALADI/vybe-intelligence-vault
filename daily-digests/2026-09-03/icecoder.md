## Summary
iceCoder is a self-hosted AI coding agent with dual-mode supervision (L1/L2), MCP tool integration, and cross-platform desktop/mobile UI. It supports session checkpoints, multi-model vision capabilities, and a skills library for reusable agent behaviors.

## Key Features
- Dual-mode supervision (L1/L2) with adaptive and strict enforcement for safer agent execution
- Cross-platform desktop and mobile UI with session synchronization
- MCP tool integration and 27+ built-in tools for file, Git, shell, and vision operations
- Session checkpoints, memory management, and skills library for reusable agent behaviors
- Multi-model support with vision capabilities and telemetry for observability

## Why It Matters for RAG Builders
It provides a robust, self-hosted framework for building and managing AI coding agents with advanced supervision, checkpointing, and multi-platform support, critical for production-grade RAG and agent systems.
