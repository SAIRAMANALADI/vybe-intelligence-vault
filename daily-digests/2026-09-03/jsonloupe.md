## Summary
jsonloupe is a local-first, browser-based tool for inspecting, diffing, editing, and querying large or precise JSON documents without backend dependencies. It supports lossless handling of int64 and decimal numbers, semantic diffing, and conversion of nested JSON into linked spreadsheets.

## Key Features
- Lossless handling of int64 and precise decimal numbers without rounding or coercion
- Semantic diffing with identity-based array alignment and field filtering
- Conversion of nested JSON into linked spreadsheets (XLSX/CSV) with customizable mappings
- Built-in JSONPath query language with aggregation and live preview for local execution
- MCP server integration for AI agents to interact with large JSON documents without context limits

## Why It Matters for RAG Builders
It enables RAG builders to handle and process large, precise JSON documents locally without data loss, making it essential for AI agents working with structured data that exceeds context window limits.
