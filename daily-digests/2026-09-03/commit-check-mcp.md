## Summary
commit-check-mcp is a Model Context Protocol (MCP) server that exposes commit-check validations as local MCP tools, enabling AI clients to validate commit messages, branch names, author info, push safety, and repository state programmatically.

## Key Features
- Exposes commit-check validations as MCP tools for seamless integration with AI clients
- Supports validation of commit messages, branch names, author info, and push safety
- Provides structured JSON responses for easy parsing and error handling
- Allows repository-aware validation with configurable paths and overrides
- Integrates with popular MCP clients like Claude, Cursor, and Continue.dev

## Why It Matters for RAG Builders
It enables AI engineering teams to programmatically enforce commit message and repository standards, improving code quality and consistency in AI-driven workflows.
