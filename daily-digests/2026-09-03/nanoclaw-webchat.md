## Summary
nanoclaw-webchat is a local-first, opinionated web-based chat interface for interacting with NanoClaw AI agents. It provides a browser-based UI for multi-agent communication, direct messaging, threading, and file attachments, integrated directly with a running NanoClaw fork.

## Key Features
- Localhost-only or public-authenticated deployment with optional OAuth/OIDC support
- Multi-agent lobby with @mention routing and engaged-agent persistence
- Direct messaging (DMs) and threaded conversations per room
- File attachment support with preview drawer (images, PDFs, code, CSV, markdown)
- MCP server for integration with Cursor and other MCP-compatible tools

## Why It Matters for RAG Builders
It provides a user-friendly, local-first interface for interacting with AI agents, reducing reliance on external SaaS tools and enabling seamless integration with NanoClaw's agent framework.
