## Summary
Helen is an AI-native Domain-Specific Language (DSL) designed for building AI agents with first-class LLM primitives, bilingual (Chinese/English) support, and automatic context management. It integrates deterministic programming constructs with LLM operations, enabling prompt-first agent development with session persistence and multi-agent concurrency.

## Key Features
- Prompt-first agent development with first-class LLM primitives (e.g., `llm act`, `llm if`)
- Automatic 5-layer context compression and working memory management for long conversations
- Built-in TranscriptStore for session persistence, audit, and replay with SQLite/JSONL backends
- Multi-agent concurrency via `spawn`, Channel message queues, and `mailbox_select` primitives
- Bidirectional Python integration (Helen ↔ Python) with type hints, async support, and decorator patterns

## Why It Matters for RAG Builders
Helen provides a unified, prompt-first DSL for AI agent development with automatic context management and bilingual support, reducing complexity for RAG builders who need fine-grained control over agent interactions and session persistence.
