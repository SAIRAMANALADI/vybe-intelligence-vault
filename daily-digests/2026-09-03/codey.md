## Summary
CodeY is a local-first AI work partner that assists users in completing tasks and delivering results through a durable, inspectable, and controlled execution model. It combines a React-based desktop UI with a Rust daemon for agent orchestration, offering cross-platform support and extensible capabilities.

## Key Features
- Durable task execution with state recovery after restarts
- Inspectable workbench for reviewing task progress and artifacts
- Controlled execution with configurable permission and sandbox policies
- Extensible via MCP servers, plugins, and native computer-control tools
- Cross-platform desktop app with TypeScript, Python, and Rust SDKs

## Why It Matters for RAG Builders
CodeY provides a robust, local-first framework for building and orchestrating AI agents with durable execution and fine-grained control, making it essential for developers integrating autonomous agents into production workflows.
