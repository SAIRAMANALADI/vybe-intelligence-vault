## Summary
Hronaut is a persistent, visible Electron browser that provides durable agent workspaces via MCP, enabling agents to maintain isolated browser profiles with persistent tabs, cookies, and sessions. It allows users to monitor, pause, or take over agent work in real-time while preserving state between sessions.

## Key Features
- Persistent browser profiles with isolated workspaces for agents
- Real-time visibility and interaction with agent tasks
- Local Streamable HTTP MCP endpoint for seamless agent integration
- Human-interaction locks and pause capabilities for controlled workflows
- Multi-language support and customizable UI themes

## Why It Matters for RAG Builders
Hronaut enables RAG and AI agents to maintain persistent, isolated browser environments, preserving state and enabling human oversight, which is critical for tasks requiring authentication, debugging, or multi-agent handoffs.
