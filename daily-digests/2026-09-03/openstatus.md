## Summary
OpenStatus is an open-source platform that combines status pages and uptime monitoring into a single tool, enabling users to track service reliability and communicate incidents effectively. It offers both managed and self-hosted deployment options.

## Key Features
- Unified status pages and uptime monitoring with 28 global regions for checks
- Monitoring as code via YAML, CLI, GitHub Actions, and Terraform
- Flat pricing with unlimited members and no per-seat charges
- Self-hostable in a lightweight 8.5MB Docker image
- Integrations with Slack, Discord, PagerDuty, email, and webhooks
