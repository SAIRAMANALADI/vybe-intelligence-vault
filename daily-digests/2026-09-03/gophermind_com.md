## Summary
GopherMind is a lightweight, terminal-based AI coding agent that turns any OpenAI-compatible LLM into a safe, agentic assistant for reading, searching, editing, and executing commands in your repository. It emphasizes hackability, safety, and minimalism with a single Go binary and no cloud lock-in.

## Key Features
- Single Go binary with no dependencies, deployable anywhere
- Safety-first design with path containment, shell deny-lists, and approval gates
- Supports any OpenAI-compatible model (local or hosted) with provider profiles
- Built-in PhaseFlow workflow for structured project planning and execution
- Extensible tooling system with WASM sandboxing and MCP server support

## Why It Matters for RAG Builders
GopherMind provides a minimal, secure, and hackable foundation for building agentic AI workflows in the terminal, reducing complexity for RAG builders while ensuring safety and flexibility.
