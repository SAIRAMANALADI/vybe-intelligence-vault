## Summary
cliwright is a spec-gated CLI factory that automates the generation of production-grade, agent-ready command-line tools for REST APIs. It scaffolds Go-based CLIs with security, CI/CD, and deterministic acceptance gates, ensuring 'done' means provably complete.

## Key Features
- Automated scaffolding of Go + Cobra CLIs for any REST API with full CRUD, pagination, and idempotent retries
- Secure by default with OS keyring integration, secret flag protection, and CSV formula-injection guards
- Agent-ready with MCP server, agent guard, and annotated command permissions (read-only/write/destructive)
- Deterministic acceptance gates via `make verify` ensuring completeness and compliance with the spec
- Cross-tool agent skill deployment (Claude Code, Cursor, Codex) and packaging (Homebrew, Scoop, deb/rpm/apk)

## Why It Matters for RAG Builders
It streamlines the creation of secure, agent-integrated CLIs for REST APIs, reducing manual effort and ensuring production-grade quality through deterministic gates.
