## Summary
vibe-editor is a desktop application that acts as a multi-agent dispatcher for AI coding agents like Claude Code and Codex. It enables users to dynamically recruit teams of agents, manage their interactions in real-time, and visualize their work on an infinite canvas, all within a Tauri-based desktop interface.

## Key Features
- Dynamic team recruitment and management for AI coding agents (Claude Code/Codex)
- Real-time message injection into agent prompts via embedded MCP hub (no polling or latency)
- Infinite canvas mode for spatial organization of agents, files, diffs, and terminals
- Silent auto-updates and session persistence across restarts
- Integrated file tree, git diff viewer, and session history for streamlined review loops

## Why It Matters for RAG Builders
It streamlines multi-agent AI workflows by enabling real-time collaboration and spatial organization, reducing cognitive load for developers managing complex coding tasks.
