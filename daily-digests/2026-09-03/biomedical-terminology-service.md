## Summary
The Biomedical Terminology Service (BTS) is a self-hosted platform that provides a unified API for searching, traversing, mapping, and semantically comparing biomedical concepts across major terminologies and ontologies. It supports REST, GraphQL, FHIR, and MCP interfaces for integration with healthcare, research, and AI systems.

## Key Features
- Unified access to multiple biomedical vocabularies (SNOMED CT, CTV3, HGNC, HPO, MONDO, etc.)
- Semantic similarity and translation between concepts using pluggable methods
- Multiple API interfaces (REST, GraphQL, FHIR, MCP) for diverse integration needs
- Pluggable database backends for document, graph, cache, and vector storage
- Full-text search, auto-complete, and relationship traversal across loaded vocabularies

## Why It Matters for RAG Builders
It provides critical terminology normalization and semantic mapping capabilities essential for accurate and context-aware RAG systems in biomedical domains.
