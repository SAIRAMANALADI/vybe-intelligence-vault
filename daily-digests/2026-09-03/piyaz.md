## Summary
Piyaz is an agentic workspace that enables seamless collaboration between humans and AI coding agents on the same project. It breaks down work into structured tasks with dependencies, tracks progress, and enforces quality through automated reviews before merging.

## Key Features
- Shared task graph with dependencies for structured project decomposition
- Automated review process before code merges to ensure quality
- Support for multiple AI agents (Claude Code, Codex, Cursor, Antigravity) working simultaneously
- Context-aware task execution with pre-loaded plans and decisions
- Self-hosting capability with AGPL-3.0 license for full control

## Why It Matters for RAG Builders
Piyaz streamlines AI-driven software development by ensuring consistent, high-quality collaboration between agents and humans, reducing context loss and improving project scalability.
