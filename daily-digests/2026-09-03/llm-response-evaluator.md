## Summary
A Windows-based desktop application that evaluates and compares LLM responses across five quality dimensions: instruction following, truthfulness, prompt correctness, writing quality, and verbosity. It uses Streamlit for a browser-based UI and runs locally for data privacy.

## Key Features
- Evaluates responses across five key quality dimensions
- User-friendly Streamlit-based interface
- Local execution for data privacy
- Supports side-by-side comparison of multiple responses
- Exports results to CSV for offline analysis

## Why It Matters for RAG Builders
It provides structured, human-in-the-loop evaluation of LLM outputs, enabling better post-training and quality assessment for RAG systems.
