## Summary
Lexigram is a Python framework designed to streamline the development of AI applications by integrating agents, LLMs, RAG, skills, and memory into a cohesive, async-native system. It eliminates the need for extensive glue code and complex configurations, enabling rapid prototyping and scalable deployment.

## Key Features
- Pre-wired integration of agents, LLMs, RAG, skills, and memory with no glue code required
- Async-native backend with built-in web, SQL, cache, auth, queues, and events
- Provider-agnostic LLM clients supporting OpenAI, Anthropic, Groq, and local models
- Contract-first architecture with dependency injection for modular and testable components
- Container-managed lifecycle for simplified deployment and scalability

## Why It Matters for RAG Builders
Lexigram accelerates AI application development by providing a unified, modular framework that reduces boilerplate and simplifies integration of agents, LLMs, and RAG systems.
