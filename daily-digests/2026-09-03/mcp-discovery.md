## Summary
A Rust-based CLI tool for discovering and documenting capabilities of Model Context Protocol (MCP) servers, supporting multiple output formats and automated documentation updates via GitHub Actions.

## Key Features
- Discovers and documents MCP server tools, resources, and capabilities in multiple formats (Markdown, HTML, JSON, plain text)
- Supports automated updates to existing files using marker-based annotations for seamless documentation maintenance
- Offers built-in templates and custom Handlebars template support for flexible output formatting
- Integrates as a GitHub Action for CI/CD workflow automation
- Provides streamable HTTP transport and OAuth authentication for secure MCP server interactions

## Why It Matters for RAG Builders
It streamlines the process of documenting and maintaining MCP server capabilities, reducing manual effort and ensuring up-to-date documentation for AI stack builders.
