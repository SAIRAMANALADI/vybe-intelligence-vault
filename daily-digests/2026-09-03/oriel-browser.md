## Summary
Oriel is a macOS control center that enables AI agents like Codex and Claude Code to interact with a managed Chromium browser (Chrome, Tabbit, or Edge) via a persistent local profile. It simplifies browser automation for AI workflows without requiring terminal setup or separate AI browser installations.

## Key Features
- Native macOS control center for managing AI browser sessions
- Persistent local browser profiles with encrypted login state
- One-click CLI and skill installation for Codex and Claude Code
- Semantic snapshots, task spaces, and navigation for AI agents
- Local daemon with Unix socket for secure agent-browsers communication

## Why It Matters for RAG Builders
Oriel streamlines AI agent interactions with browsers by providing a managed, persistent, and secure environment, reducing setup complexity and enabling seamless integration for RAG and automation workflows.
