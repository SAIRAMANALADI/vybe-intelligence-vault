## Summary
Zeroshot is an open-source multi-agent orchestration engine for autonomous software engineering that implements an executor-verifier loop to ensure code changes are independently validated before approval. It acts as a harness for AI coding agents like Claude Code or OpenAI Codex, separating the agent that writes code from the one that judges it.

## Key Features
- Executor-verifier loop ensures independent validation of code changes by a separate agent
- Supports multiple AI coding agents (Claude Code, OpenAI Codex, Gemini CLI, OpenCode) without storing API keys
- Crash-safe SQLite ledger for persistent state and resumable runs
- Isolation modes (Git worktree, Docker) for safe execution of risky changes
- Automated quality gates and command proofs for reproducible verification

## Why It Matters for RAG Builders
It provides a critical layer of independent verification for AI-driven code changes, ensuring reliability and trust in autonomous software engineering workflows.
