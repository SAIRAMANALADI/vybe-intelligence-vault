## Summary
ADD (AI Device Description) is an open standard enabling IoT devices to self-describe their capabilities, constraints, and safety rules in a lightweight JSON format. It allows AI systems to interact with devices safely and autonomously without prior configuration or cloud dependencies.

## Key Features
- Lightweight JSON-based device self-description with minimal implementation overhead
- Built-in safety and ethical frameworks (autonomy levels, confirmation requirements, and rule validation)
- Protocol-agnostic design allowing integration with any existing device interface
- Decentralized and open standard (CC BY 4.0) with no cloud dependency
- AI-native format designed for reasoning systems to understand device capabilities and constraints directly

## Why It Matters for RAG Builders
ADD enables AI systems to safely and autonomously interact with physical devices by embedding safety, constraints, and context directly into the device's self-description, reducing integration complexity and mitigating risks in AI-driven IoT applications.
