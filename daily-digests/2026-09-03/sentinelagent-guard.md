## Summary
SentinelAgent Guard is a protocol-native firewall designed to protect MCP servers and AI agents from tool poisoning, rug pulls, and data exfiltration. It uses deterministic, rule-based detection (no LLM in the request path) to ensure security for agentic workflows.

## Key Features
- Protocol-native security checks (SHA-256 fingerprinting, Unicode concealment detection)
- Deterministic, zero-AI-cost detection engine with sub-millisecond response times
- Three deployment modes: embeddable SDK, CLI scanner, and sidecar proxy
- 22+ detection checks across 5 layers (protocol, tool integrity, call-time policy, response inspection, audit)
- Open-core model with optional hosted SaaS for teams (detection remains free and local)

## Why It Matters for RAG Builders
It provides critical, protocol-native security for AI agents interacting with MCP servers, preventing malicious tool modifications and data leaks without relying on LLMs or external services.
