## Summary
WB Chronicler transforms WorldBox game save files into Tolkien-style narrative chapters using Claude Code and an Angular-based reader. It automates storytelling from sandbox playthroughs while preserving world state in a local, disk-based chronicle.

## Key Features
- Converts WorldBox save files into structured narrative chapters with Tolkien-inspired prose
- Persists chronicle state locally on disk for deterministic, reproducible storytelling
- Uses Claude Code CLI for dynamic, context-aware narrative generation from game data
- Features a parchment-themed Angular reader with NG-ZORRO for immersive display
- Supports French and English localization with automatic entity tagging and visualization

## Why It Matters for RAG Builders
It bridges game data and narrative generation, enabling automated storytelling pipelines for sandbox game worlds while maintaining data integrity and localization.
