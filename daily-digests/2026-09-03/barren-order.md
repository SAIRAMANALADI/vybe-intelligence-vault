## Summary
BarrenOrder is a multi-agent collaboration framework designed for Feishu (Lark) group chats, enabling multiple Hermes Bots to coordinate tasks via @mentions, supporting workflow orchestration, shared memory, and runtime health checks for robust AI agent interactions.

## Key Features
- Bot-to-bot communication via Feishu @mentions for task delegation
- DAG-based workflow engine with conditional branches, parallel execution, and retry mechanisms
- Four-tier shared memory system (GLOBAL/AGENT/SESSION/WORKFLOW) with TTL expiration and snapshot recovery
- Runtime health checks and intent state machines to prevent process deadlocks
- Standing team runtime with manager-only ingress, approval gates, and health verification

## Why It Matters for RAG Builders
BarrenOrder provides a structured, production-ready framework for orchestrating multi-agent workflows in collaborative environments like Feishu, ensuring reliability and scalability for RAG and AI stack builders.
