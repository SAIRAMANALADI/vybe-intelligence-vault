## Summary
4torm is a multi-agent collaboration framework enabling persistent AI agents to work together across five specialized workspaces: conversations, meetings, workshops, workflows, and automated tasks. It allows agents to be reused across different tasks with configurable models, prompts, tools, and skills.

## Key Features
- Five specialized workspaces (Monsoon, Convection, Cyclone, Tradewind, Tide) for different collaboration modes
- Persistent agent reuse across tasks with configurable models, prompts, tools, and skills
- Built-in tools, skills, and MCP support for extensible agent capabilities
- Visual node-based workflows (Tradewind) and scheduled task automation (Tide)
- Electron-based desktop app with browser and desktop development modes

## Why It Matters for RAG Builders
4torm enables AI engineers to build persistent, reusable agents that collaborate effectively across diverse tasks, reducing redundancy and improving workflow automation in RAG systems.
