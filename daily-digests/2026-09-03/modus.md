## Summary
Modus is an open-source desktop application that provides a local-first workspace for running AI coding agents within real local projects. It enables users to manage agent sessions, interact with models, and execute development workflows entirely offline.

## Key Features
- Local project workspace with agent session management
- Bring-your-own-model provider support for AI agents
- Integrated terminal, browser, and file explorer tools
- Permissioned execution with approval workflows for actions
- Git workflow integration with diffs, commits, and history

## Why It Matters for RAG Builders
Modus provides a self-contained, local-first environment for AI coding agents, reducing dependency on cloud services and enhancing privacy while enabling seamless development workflows.
