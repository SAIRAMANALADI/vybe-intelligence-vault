## Summary
Agent6 is a sandboxed coding agent that executes LLM-generated commands in restricted environments while enabling long-running, state-machine-based workflows. It supports multiple LLM providers, offers persistent transcripts, and provides CLI, TUI, and web interfaces for task management and review.

## Key Features
- Sandboxed command execution with Landlock + seccomp for security
- Editable state machines for long-running, resumable, and replayable tasks
- Multi-interface support (CLI, TUI, web) with persistent transcripts
- Git-integrated workflows with per-step commits and hard limits
- Modular skills system for extending agent capabilities

## Why It Matters for RAG Builders
Agent6 provides a secure, structured framework for deploying LLM agents in production environments with robust sandboxing and state management, critical for building reliable RAG pipelines.
