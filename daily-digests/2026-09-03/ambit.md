## Summary
Ambit is a meta-MCP server that maps, audits, and plans across AI agent environments by modeling capabilities, dependencies, and human attention costs as a capability graph. It enables agents to query their own toolchain, identify missing prerequisites, and propose configuration changes for approval.

## Key Features
- Builds a dynamic capability graph from local configs, MCP servers, and tools to visualize dependencies and system health.
- Acts as a meta-MCP server, allowing agents to query their own toolchain and environment state in real-time.
- Provides CLI and visualizer tools to analyze reachability, blast radius, and frontier capabilities.
- Supports human-in-the-loop approval workflows for applying configuration changes proposed by agents.
- Tracks human attention costs and ROI for setup decisions, enabling data-driven prioritization of improvements.

## Why It Matters for RAG Builders
Ambit provides the missing layer of observability and planning for AI agent environments by mapping capabilities and dependencies, enabling agents to self-diagnose and propose fixes while ensuring human oversight for critical changes.
