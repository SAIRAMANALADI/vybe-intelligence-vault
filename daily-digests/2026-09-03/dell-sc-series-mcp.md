## Summary
A read-only Model Context Protocol (MCP) server that enables AI assistants to diagnose Dell SC Series/Compellent storage arrays via the array's REST API. It provides real-time health, capacity, alerts, and hardware status without requiring Dell Storage Manager.

## Key Features
- Read-only MCP server for Dell SC Series storage arrays
- Direct REST API integration with SCOS 7.x (no DSM required)
- Comprehensive diagnostic tools (health, alerts, capacity, volumes, hardware)
- Thread-safe client with session management and transparent re-login
- Fully mocked test suite for development without a physical array

## Why It Matters for RAG Builders
It enables AI assistants to directly query and diagnose Dell storage arrays, reducing manual oversight and improving proactive maintenance for RAG systems.
