## Summary
This repository provides an AI-powered agent for generating high-converting e-commerce short video scripts tailored for platforms like Qianchuan (千川). It includes a zero-dependency web app for one-click script generation, a Python-based CLI for customization, and a compliance engine to ensure ad and medical regulations are met.

## Key Features
- Zero-dependency web app for instant script generation with pre-built templates and compliance checks
- Python CLI for custom product script generation with multi-format exports (Markdown, JSON, CSV, HTML)
- Built-in compliance engine for ad law and medical category regulations with automatic corrections
- Modular architecture with 19+ real-world high-converting script templates and reusable components
- Supports both template-based and LLM-based generation modes with seed control for reproducibility
