## Summary
ImagineAppWeb is a web-based AI shopping assistant for Best Buy products, enabling conversational product search, comparison, and analysis through an agent loop. It integrates barcode scanning, OCR fallback, and metered usage with a credit ledger for free access.

## Key Features
- Agent loop with model-agnostic tool registry and streaming tool calls over OpenRouter API
- On-device OCR fallback for SKU/UPC extraction from non-barcode sources
- Barcode scanning with support for multiple symbologies and customizable scan actions
- Metered usage with a credit ledger and 72-hour transcript retention for privacy compliance
- Synthetic benchmarking (Best Buy Bench) for cost-to-quality model selection
