## Summary
cc-agents-md enables automatic loading of AGENTS.md files into Claude Code sessions without requiring CLAUDE.md wrappers or symlinks. It integrates seamlessly with monorepos and provides hooks for dynamic context injection during sessions.

## Key Features
- Automatic AGENTS.md file discovery and injection in Claude Code sessions
- Three hooks (SessionStart, UserPromptSubmit, PreCompact) for dynamic context management
- Support for monorepos with depth-adaptive file loading
- Configuration via .agents-md.json or environment variables
- Experimental internal patching for native AGENTS.md support in Claude Code

## Why It Matters for RAG Builders
It eliminates the need for CLAUDE.md wrappers and enables seamless AGENTS.md integration in Claude Code, improving AI assistant context management in complex projects.
