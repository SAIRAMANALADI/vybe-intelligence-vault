## Summary
VibeCodeProtocols (VCP) is a protocol framework designed to guide AI agents (like Claude Code) through structured, test-driven development workflows. It enforces disciplined coding practices by separating planning, implementation, testing, and review phases, ensuring traceability and accountability in AI-driven code changes.

## Key Features
- Enforces a strict RED-GREEN-TRIANGULATE-REFACTOR workflow to prevent 'code first, tests later' anti-patterns
- Provides automated gates (checks) to validate code changes, security baselines, and scope adherence
- Maintains immutable evidence logs (receipts, hashes, and chains) for auditability and traceability
- Supports research-driven development with structured discovery phases and diagnostic tools
- Integrates seamlessly with AI agents (e.g., Claude Code) via local runtime installation and Markdown-based commands

## Why It Matters for RAG Builders
VibeCodeProtocols ensures AI agents follow disciplined, test-driven workflows with built-in traceability and accountability, reducing the risk of undetected errors or untested assumptions in automated code changes.
