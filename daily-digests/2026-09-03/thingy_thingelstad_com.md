## Summary
Thingy is a standalone web application serving as the frontend for Jamie Thingelstad's archive agent, providing a chat interface, authentication, and static content pages. It integrates with the Librarian MCP server for retrieval and conversation management.

## Key Features
- Interactive chat interface with archive agent capabilities via Librarian MCP server
- Static content pages (/about/, /connect/) for documentation and setup
- URL parameter handling for deep linking, authentication, and session management
- Integration with Tinylytics for analytics while preserving privacy in sensitive routes
- Contract-based API validation with Librarian for type safety and compatibility

## Why It Matters for RAG Builders
Thingy provides a user-friendly frontend for interacting with an archive agent, demonstrating how to integrate MCP servers and handle authentication in a static web app, which is valuable for RAG builders seeking practical UI examples.
