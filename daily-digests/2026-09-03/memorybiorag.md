## Summary
MemoryBioRAG is a biomimetic cognitive memory system for AI agents that enables persistent, auditable, and deterministic memory retention between sessions without relying on dense embeddings or GPUs. It combines PPMI+SVD matrix factorization, graph retrofitting, IDF-synonym hybrid retrieval, and sparse distributed memory (SDM) with neurobiologically inspired mechanisms like LTP/LTD, spreading activation, and homeostatic scaling.

## Key Features
- Hybrid retrieval combining PPMI+SVD matrix factorization, IDF-synonym scoring, and graph retrofitting for semantic matching without dense embeddings
- Neurobiologically inspired mechanisms: LTP/LTD, spreading activation, homeostatic scaling, and dopamine-driven reward prediction error (RPE)
- Sparse Distributed Memory (SDM) with 2048-bit vectors for declarative, auditable memory representation
- Autonomous memory consolidation and graph maintenance via 'La Hormiguita' system, including sleep cycles and synaptic pruning
- MCP server integration for seamless agent interaction and zero-dependency deployment

## Why It Matters for RAG Builders
It provides a lightweight, auditable, and neurobiologically grounded alternative to vector-based memory systems for RAG, enabling persistent agent memory without GPU or heavy ML dependencies.
