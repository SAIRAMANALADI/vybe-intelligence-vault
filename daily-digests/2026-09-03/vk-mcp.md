## Summary
A Model Context Protocol (MCP) server for interacting with VKontakte (VK) API, enabling AI agents to publish posts, retrieve wall content, fetch user/group data, send messages, and analyze group statistics programmatically.

## Key Features
- 8 MCP tools for VK API operations (wall posts, user/group info, messages, statistics)
- Supports stdio and Streamable HTTP transport modes
- Exponential backoff retry mechanism for API rate limits
- Integrates with AI agents via MCP for automated VK interactions
- Provides skills for common VK tasks (posting, stats retrieval)

## Why It Matters for RAG Builders
Enables AI agents to seamlessly interact with VKontakte for social media automation, content retrieval, and community management without manual API handling.
