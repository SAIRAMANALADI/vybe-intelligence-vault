## Summary
A Python automation layer built on top of the `python-hwpx` engine to enable document authoring, form filling, and workflow automation for HWPX files (Korean word processor format). It provides a Python API, CLI, and optional MCP server for AI agents to read, edit, inspect, and validate local HWPX documents without requiring Hancom Office or Windows.

## Key Features
- Read, edit, and validate HWPX documents programmatically via Python API or CLI
- Optional MCP server for AI agent integration (e.g., Claude, VS Code, Cursor)
- Form filling with byte-preserving transactions and verification
- Document generation from declarative plans (e.g., official drafts, meeting records)
- Advanced tools for table computation, text search/replace, and document repair

## Why It Matters for RAG Builders
It enables AI agents to safely and programmatically interact with HWPX documents, a critical format in Korean workflows, without requiring proprietary software or complex setups.
