## Summary
A static, self-hostable web interface designed as an unofficial community project for the Hermes Dashboard. It provides a frontend for managing sessions, tools, profiles, and settings while relying on the Dashboard as the source of truth for authentication and data.

## Key Features
- Static, self-hostable web UI with demo mode for evaluation
- Workspace with session browsing, search, and transcript rendering
- Tool execution and approval workflows
- Settings for visual skins, model controls, profiles, and MCP servers
- Installable PWA with resizable file panel and standalone deployment
