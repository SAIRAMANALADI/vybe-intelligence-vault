## Summary
A TypeScript-based coding-agent runtime built on an OpenAI-compatible API, designed to teach the intricate boundaries and mechanics of agent systems through a 26-chapter bilingual tutorial. It implements core agent features like streaming sampling, tool contracts, cancellation, and OS-level sandboxing without relying on third-party agent frameworks.

## Key Features
- Implements a provider-neutral agent runtime with OpenAI-compatible and Anthropic Messages support
- Detailed 26-chapter bilingual tutorial explaining design boundaries and trade-offs
- Includes 141 deterministic tests for runtime behavior verification
- Features OS-level sandboxing (macOS `sandbox-exec`, Linux `bwrap`) for secure shell tool execution
- Supports streaming sampling, cancellation boundaries, tool contracts, approval pauses, and context compaction

## Why It Matters for RAG Builders
It provides a foundational reference for building secure, inspectable agent runtimes with clear boundaries and trade-offs, critical for RAG builders aiming to integrate or extend agent capabilities.
