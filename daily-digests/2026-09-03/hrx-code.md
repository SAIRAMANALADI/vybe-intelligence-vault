## Summary
HRX Code is a terminal-based AI agent that understands, modifies, and validates projects with built-in risk control. It integrates a ReAct loop with tools for code navigation, editing, shell execution, Git operations, and memory persistence, while enforcing multi-layered security policies for safe AI-driven development.

## Key Features
- ReAct loop with pluggable LLM support (Gemini, OpenAI, DeepSeek, Groq, Claude, Ollama, local models)
- Multi-layered security policy with risk classification (green/yellow/red) and single-use authorization
- Code navigation, editing, and execution with line-number precision
- Persistent memory and configurable profiles for personalized interactions
- Built-in protection against SSRF, shell obfuscation, and destructive commands

## Why It Matters for RAG Builders
HRX Code provides a secure, risk-aware framework for AI agents to interact with codebases, making it essential for developers building RAG systems that require safe tool execution and multi-model flexibility.
