## Summary
Book is a provider-agnostic AI coding agent CLI with a rich terminal UI, offering an alternative to tools like Claude Code. It supports interactive and headless modes, persistent sessions, file-based memory, and MCP tool integration for AI-driven development workflows.

## Key Features
- Interactive TUI with print mode for CI/CD pipelines
- Multi-provider support (Anthropic, OpenAI-compatible endpoints)
- File-based auto-memory with approval workflows
- Persistent session management with compaction and rewinding
- MCP tool client with dynamic discovery and permissions
