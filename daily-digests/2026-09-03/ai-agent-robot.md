## Summary
An animated AI desktop assistant that operates as an always-on-top, transparent window with a robot character capable of voice interaction, AI-driven assistance, and system control. It integrates with OpenAI-compatible APIs, local LLMs, and supports multilingual voice commands.

## Key Features
- Animated robot with expressive states (idle, talking, thinking, happy)
- Voice-to-voice interaction with multilingual support (AR/FR/EN)
- OpenAI-compatible API integration for AI brain (GPT-4o, GitHub Copilot, local LLM)
- PC control capabilities (app management, file operations, command execution)
- Always-on-top transparent window with drag-and-drop functionality
