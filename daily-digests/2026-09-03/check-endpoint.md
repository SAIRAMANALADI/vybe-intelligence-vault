## Summary
A live, per-phase HTTP timing probe that measures and visualizes the timing of each stage of an HTTP request (DNS, TCP, TLS, TTFB, body transfer) using pycurl. It provides real-time streaming output, failure markers, and detailed diagnostics for debugging endpoint performance issues.

## Key Features
- Per-phase HTTP timing with live streaming output for real-time diagnostics
- Detailed failure markers for DNS, TCP, TLS, and other phases
- Support for HTTP/2, HTTP/3, and streaming/chunked responses
- Built-in assertions for CI/CD integration and automated alerts
- Prometheus exporter mode for continuous monitoring

## Why It Matters for RAG Builders
It provides granular, client-side evidence of where HTTP request delays or failures occur, enabling precise debugging of endpoint performance issues in RAG or AI systems.
