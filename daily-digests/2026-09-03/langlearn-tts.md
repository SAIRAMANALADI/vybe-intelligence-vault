## Summary
A Claude Desktop extension that integrates text-to-speech (TTS) capabilities into Claude, enabling audio-based language learning. It supports 70+ languages and multiple TTS providers like ElevenLabs, OpenAI TTS, and AWS Polly, allowing users to generate audio flashcards, pronunciation guides, and language lessons.

## Key Features
- Supports 70+ languages with multiple TTS providers (ElevenLabs, OpenAI, AWS Polly)
- Generates audio flashcards, pronunciation guides, and merged audio files
- 28 built-in tutor personas for structured language lessons
- CLI and MCP server for integration with Claude Desktop and other MCP clients
- Adjustable speech rate and voice selection for personalized learning
