## Summary
Continuum Genesis is an MIT reference implementation for task-scoped AI memory, providing a local-first runtime, public shard format, JavaScript SDK, and installable text cockpit. It enables developers to store durable project facts, retrieve only task-relevant context, and pass compact shards to models or workflows.

## Key Features
- Task-scoped context retrieval for compact model inputs
- Local-first runtime with no cloud dependency
- Portable shard format for inspectable memory
- JavaScript SDK and installable PWA cockpit
- Built-in evaluation harness for benchmarking

## Why It Matters for RAG Builders
Continuum Genesis provides a lightweight, auditable way to manage task-specific AI memory outside model sessions, reducing context bloat and improving retrieval precision for RAG systems.
