## Summary
MetaSearchMCP is an open-source metasearch backend designed for MCP, AI agents, and LLM workflows. It aggregates, normalizes, and deduplicates search results from multiple providers into a stable JSON schema, exposing both an HTTP API and an MCP server for seamless integration with agent tooling.

## Key Features
- Concurrent multi-provider search aggregation with provider-level timeout isolation
- Unified JSON schema for normalized results across web, academic, developer, and knowledge sources
- Built-in deduplication and partial-failure handling for robust search workflows
- HTTP API with OpenAPI documentation and MCP server over stdio for agent integration
- Extensive provider support including Google, DuckDuckGo, Wikipedia, GitHub, arXiv, and more

## Why It Matters for RAG Builders
MetaSearchMCP provides a critical orchestration layer for RAG pipelines by unifying disparate search providers into a single, predictable interface, enabling reliable and scalable retrieval for AI agents.
