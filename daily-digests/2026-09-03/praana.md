## Summary
PRAANA is a terminal-based coding agent that dynamically manages context and memory for AI-driven development sessions. It curates adaptive prompts, distills tool outputs, and maintains a local cognitive memory system to improve continuity and efficiency across coding sessions.

## Key Features
- Deterministic context compiler with tiered working memory and token budgets per section
- Cognitive Memory system for cross-session learning retention and retrieval
- Tool-output distillation with artifact storage for efficient prompt assembly
- Session checkpointing and resume functionality for continuity
- Multi-provider LLM support with dynamic model switching

## Why It Matters for RAG Builders
PRAANA addresses critical challenges in RAG systems by dynamically curating context and preserving learnings across sessions, reducing token waste and improving AI-driven development workflows.
