## Summary
A FastMCP 3.2.0+ compliant MCP server providing comprehensive file system operations, Git repository management, and Docker container control with dual transport (stdio + HTTP) support. Includes a React webapp for real-time visualization and 57+ professional tools for AI engineering workflows.

## Key Features
- Dual transport support (stdio + HTTP) with port 10742 for MCP and 10702 for webapp
- Concurrency-safe file operations with atomic writes and proper locking
- Comprehensive Git repository management (clone, commit, branch, status)
- Full Docker container and image lifecycle management
- Enterprise-grade security with path traversal protection and audit trails
