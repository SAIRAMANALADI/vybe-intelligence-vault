## Summary
spaceship-mcp is an MCP server designed to manage domains, DNS settings, contacts, and marketplace listings via the Spaceship API, leveraging AI to simplify technical tasks for non-programmers.

## Key Features
- Domain management (add, update, delete) with AI guidance
- DNS record control (A, AAAA, CNAME, MX) via AI suggestions
- Contact handling for domain registration and transfers
- Marketplace listings for domain sales with offer management
- User-friendly UI requiring no programming knowledge

## Why It Matters for RAG Builders
It provides a streamlined, AI-assisted interface for managing domains and DNS, reducing technical overhead for RAG builders integrating domain-related data.
