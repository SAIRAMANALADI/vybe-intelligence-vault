## Summary
A CakePHP plugin that implements the Model Context Protocol (MCP) to expose CakePHP application functionality to AI assistants and other MCP clients, enabling standardized interactions with tools, resources, and prompts for development workflows.

## Key Features
- Exposes CakePHP application functionality via MCP for AI assistant integration
- Provides built-in tools for system info, database schema exploration, route inspection, and code execution
- Includes advanced documentation search with fuzzy matching and relevance ranking
- Supports custom tools, resources, and prompts via PHP attributes and configuration
- Offers pre-configured prompt workflows for common CakePHP development tasks

## Why It Matters for RAG Builders
It enables AI assistants to interact with CakePHP applications through a standardized protocol, streamlining development workflows and automating complex tasks.
