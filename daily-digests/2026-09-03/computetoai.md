## Summary
A generic simulation engine for financial planning, particularly retirement planning, accessed exclusively via an MCP server for integration with AI agents. It provides a framework for modeling financial flows, time horizons, and effects without a dedicated frontend.

## Key Features
- Generic stock-and-flow simulation engine for financial modeling
- First-class support for retirement planning with liquidity and portfolio analysis
- Integration via MCP server for seamless AI agent interaction
- Monte-Carlo simulation for probabilistic financial outcome evaluation
- Configurable settings via TOML for flexible deployment
