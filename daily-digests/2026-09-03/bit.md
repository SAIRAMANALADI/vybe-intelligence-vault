## Summary
BIT is a desktop application hub for AI agents built with Tauri 2 and React 18, enabling auditable, remotely accessible AI workflows. It allows users to configure multiple AI providers, stream conversations, and enable AI to call local tools, scripts, or self-improve through memory and skills.

## Key Features
- Streaming conversations with SSE and Tauri events, supporting Markdown rendering
- Multi-provider AI configuration (OpenAI, Gemini, Claude) with mutual exclusivity
- Local tool integration and AI-driven script execution for dynamic workflows
- Self-building capabilities via memory and skill tools for continuous improvement
- Built-in audit logs and remote HTTP API access with authentication

## Why It Matters for RAG Builders
BIT provides a unified, auditable platform for AI agents to interact with local tools and self-improve, reducing integration complexity for RAG builders.
