## Summary
A Model Context Protocol (MCP) server for integrating JivoSite's live chat and customer interaction tools with AI assistants. It provides 10 tools and 2 skills to programmatically manage chats, agents, contacts, messages, and webhooks via the JivoSite API.

## Key Features
- 10 MCP tools for managing JivoSite chats, agents, contacts, and messages
- 2 MCP skills for real-time chat and agent statistics
- Supports both stdio and streamable HTTP deployment modes
- Enables automated responses and summaries for customer interactions
- Provides webhook management for event-driven workflows

## Why It Matters for RAG Builders
It enables AI assistants to seamlessly integrate with JivoSite's live chat system, automating customer interactions and data retrieval for RAG pipelines.
