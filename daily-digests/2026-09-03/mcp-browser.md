## Summary
mcp-browser provides a real Chrome browser controlled via the Model Context Protocol (MCP) for agents, with a live co-browsing interface for human oversight. It enables agents to navigate, interact, and extract structured data from web pages while allowing humans to observe or intervene in real-time.

## Key Features
- Full Playwright-driven Chrome browser exposed as MCP tools for agent interaction
- Live co-browsing interface via WebSocket for human oversight and takeover
- Structured element snapshots for agents to read and interact with web content
- File handling via path-based tools to avoid large uploads/downloads
- Portable viewer served directly by the server with no additional hosting required

## Why It Matters for RAG Builders
It bridges the gap between headless browser automation and human-in-the-loop oversight, enabling agents to perform complex web tasks while allowing real-time intervention and debugging.
