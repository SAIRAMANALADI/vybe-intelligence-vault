## Summary
FolioMind is an open-source financial research agent for Windows and macOS that integrates stock tracking, portfolio management, real-time monitoring, and auditable AI-driven conversations. It serves as a unified workspace for financial research with built-in financial Skills and optional data adapters like QVeris.

## Key Features
- Unified workspace for stock tracking, portfolio management, and AI-driven research with auditable conversations
- Real-time market data integration with optional QVeris adapter and support for self-hosted alternatives
- Portfolio risk insights, automated alerts, and trade planning with traceable execution logs
- Cross-platform desktop app (Windows/macOS) with local web debugging support
- Secure credential management, data backup/export, and modular Skill system for extensibility
