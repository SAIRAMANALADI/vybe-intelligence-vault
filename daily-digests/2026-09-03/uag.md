## Summary
The Universal Agent Gateway (UAG) is an MCP server that enables AI agents to interact with Form.io forms by converting Form JSON schemas into AI-readable markdown, facilitating structured data collection from natural language input and autonomous workflow automation.

## Key Features
- Converts Form.io JSON schemas into AI-readable markdown for agent comprehension
- Enables natural language input to generate structured form submissions
- Supports agentic workflows with dynamic context injection
- Integrates with MCP for in-process agentic automation
- Provides tools like `agent_provide_data` for autonomous data generation

## Why It Matters for RAG Builders
UAG bridges the gap between unstructured AI inputs and structured form data, enabling seamless automation of form-based workflows for AI agents.
