## Summary
MemoPilot is a personal AI agent framework that combines ReAct and function calling to create a traceable agent runtime with layered long-term memory, proactive wake-up mechanisms, scheduled tasks, plugins, and MCP integration for autonomous task execution.

## Key Features
- Traceable agent runtime with Phase Pipeline and ReAct loops
- Layered memory system (short-term, Markdown long-term, SQLite vector-based)
- Proactive wake-up and scheduled task execution (at/after/every)
- Extensible via Python plugins, Skills, and MCP servers
- Reliable task coordination with Redis Streams and SQLite transactions

## Why It Matters for RAG Builders
MemoPilot provides a robust, self-hosted framework for building autonomous AI agents with long-term memory and proactive capabilities, essential for RAG systems requiring persistent context and task automation.
