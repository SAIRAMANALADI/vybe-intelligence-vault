## Summary
TMCRA is a self-hosted, full-stack memory infrastructure for AI agents that transforms conversations and application events into durable, attributable evidence. It enables fast retrieval of recent facts and periodic consolidation of long-term semantic relationships while ensuring source traceability for recall operations.

## Key Features
- Durable source evidence with immutable provenance for all recall operations
- Dual-layer memory system (fast for recent facts, slow for semantic consolidation)
- Multi-tenant and scope isolation for secure memory management
- 100% source-traceable recall evidence with Source ID binding
- Benchmark-driven validation with transparent performance reporting

## Why It Matters for RAG Builders
TMCRA provides a critical memory layer for RAG systems by ensuring attributable, traceable, and consolidated evidence retrieval, which is essential for building reliable and auditable AI applications.
