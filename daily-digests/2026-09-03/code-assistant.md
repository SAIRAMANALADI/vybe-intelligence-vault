## Summary
An open-source AI coding agent built in Rust with a native GUI, terminal mode, and MCP/ACP integrations. It autonomously interacts with codebases, performs edits, and keeps users informed through transparent tool execution and real-time streaming.

## Key Features
- Autonomous agent loop for reading, searching, and editing codebases
- Native GUI, terminal, and MCP/ACP server modes for flexible integration
- Transparent tool execution with real-time streaming and smart filtering
- Format-on-save reconciliation to maintain token efficiency
- Support for diverse file types (code, documents, spreadsheets) via automatic conversion to Markdown

## Why It Matters for RAG Builders
