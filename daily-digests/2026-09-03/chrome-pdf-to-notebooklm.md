## Summary
A Chrome extension that converts PDF documents into NotebookLM-compatible notebooks directly within the browser, including generating audio summaries and other artifacts for enhanced review and accessibility.

## Key Features
- One-click PDF to NotebookLM notebook conversion
- Automatic generation of audio summaries for accessibility
- Local processing within Chrome browser (no external servers)
- Supports multi-page PDFs with efficient handling
- Simple drag-and-drop installation and usage
