## Summary
Python SDK for the Roxy API, providing access to astrology, Vedic astrology, tarot, numerology, human design, and other esoteric domains via a unified API. Enables rapid integration of natal charts, horoscopes, compatibility scores, and predictive analytics into Python applications.

## Key Features
- Unified API for 12+ esoteric domains (astrology, tarot, numerology, etc.)
- Sync and async support for all endpoints
- Pre-verified against NASA JPL Horizons for accuracy
- Geolocation support for birth data (latitude, longitude, timezone)
- Interpretations available in eight languages
