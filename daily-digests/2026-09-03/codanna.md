## Summary
Codanna is a local code intelligence tool that provides structured knowledge of codebases to AI assistants, enabling semantic search, relationship tracking, and dependency analysis. It enhances AI coding agents with sub-10ms lookups and supports multiple programming languages.

## Key Features
- Semantic search for code and documentation with natural language queries
- Call graph and dependency tracking for precise code navigation
- Document search and RAG integration for project documentation
- MCP protocol compatibility for seamless AI assistant integration
- Multi-language support (Rust, Python, JavaScript, TypeScript, Java, etc.)
