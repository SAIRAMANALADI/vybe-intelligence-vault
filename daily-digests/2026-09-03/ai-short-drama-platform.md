## Summary
An agent-driven multi-scenario video production pipeline that automates the entire process from content understanding to video creation. It supports four distinct video formats (short dramas, e-commerce showcases, knowledge explainers, and cross-border content) using a unified agent architecture and prompt templates.

## Key Features
- Unified agent architecture supporting 4 distinct video scenarios with scene-specific prompt templates
- React-pattern agents (think→act→observe→respond) with autonomous decision-making and retry logic
- Function calling with 5 tool schemas for dynamic task execution and LLM integration
- Built-in demo pipelines for offline testing and rapid prototyping
- RESTful API with task management, health checks, and multi-modal output generation

## Why It Matters for RAG Builders
