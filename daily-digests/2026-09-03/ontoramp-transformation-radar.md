## Summary
A retired MCP server that provided transformation readiness insights for AI agents by scoring maturity gaps and initiative risks in enterprise transformation programs. Its core functionality has been consolidated into a unified OntoRamp MCP endpoint.

## Key Features
- Domain-by-domain maturity gap scoring against governance baselines
- Initiative-level risk signal detection (stalling, at-risk initiatives)
- Agentic Readiness Assessment (ARA) trigger for low-coverage domains
- Tiered access (Free, Developer, Org) with rate-limited queries
- Hosted remote MCP server with no local installation required

## Why It Matters for RAG Builders
