## Summary
A Russian localization patch for the Hermes Desktop Agent, providing ~99% translation coverage of the UI, settings, and hardcoded strings. It automates the installation and updates of Russian language files for the Hermes Agent desktop application.

## Key Features
- Full Russian translation (~99% coverage) of Hermes Desktop Agent UI and settings
- Automated installation and updates via Bash scripts
- Auto-reapply patches on Hermes Agent updates using macOS LaunchAgent
- Backup and restore functionality for original files
- Supports Hermes Agent v0.19.1+

## Why It Matters for RAG Builders
Provides a turnkey solution for Russian-speaking users to fully localize the Hermes Desktop Agent, enhancing accessibility and usability for non-English speakers in AI engineering workflows.
