## Summary
A lightweight, fast Wikipedia client for the terminal and an MCP server that enables AI assistants to query Wikipedia programmatically. It provides both a CLI and an MCP-compatible server for seamless integration with AI workflows.

## Key Features
- Dual binary delivery: CLI (`wikipedia`) and MCP server (`wikipedia-mcp`)
- Wikimedia REST API client with multi-language support (default: English)
- Interactive TUI mode for terminal exploration
- MCP server with tools for search, summary, page retrieval, and random articles
- No external HTTP dependencies; lightweight and fast

## Why It Matters for RAG Builders
It provides AI agents with direct, structured access to Wikipedia content via MCP, enabling richer context generation for RAG systems without requiring additional scraping or API integration.
