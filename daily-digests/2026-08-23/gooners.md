## Summary
A collection of MCP (Model Context Protocol) servers, AI tools, and agent skills built on go-faster technologies, enabling AI agents to interact with SSH, Grafana, Alertmanager, and other systems via standardized protocols.

## Key Features
- Pre-built MCP servers for SSH, Grafana, Alertmanager, and opencode handoff with Docker support
- Agent skills for JSON encoding, Go refactoring, Linux hardening, and alert writing
- MCP gateway proxy for aggregating and routing tools from multiple upstream servers
- Predefined prompts and resources for AI agents to interact with system state
- OAuth, TLS, and routing support for secure and scalable deployments

## Why It Matters for RAG Builders
It provides essential MCP servers and agent skills that enable AI agents to securely interact with infrastructure, monitoring, and development tools, streamlining automation and observability workflows.
