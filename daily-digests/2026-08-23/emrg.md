## Summary
EMRG is a self-evolving AI programming assistant that autonomously improves itself based on user feedback and external updates. It integrates tool execution, session memory, and a terminal-based TUI to provide a continuously enhancing coding companion.

## Key Features
- Self-improvement via user feedback (/rant) and external updates, driving continuous evolution
- Full tool execution capabilities (bash, file read/write, diff editing, glob, grep)
- Persistent daemon (emrgd) for background LLM loops and tool execution
- Terminal-based TUI with slash commands, session management, and Markdown rendering
- Project and session memory with YAML frontmatter indexing for context retention
