## Summary
Gardener is an LLM-native operating system that stores all data in a searchable SQLite database with FTS5 full-text search. It provides four core primitives (find, get, put, run) for managing knowledge, tasks, and memories, and supports federated indexing of external data sources.

## Key Features
- Single-table FTS5 SQLite database for all data (knowledge, tasks, memories, tools)
- Four core primitives (find, get, put, run) for LLM interaction
- Federated indexing of external data sources (files, SQLite tables, transcripts)
- CLI and lightweight web UI for human interaction
- Memory decay and consolidation mechanisms for dynamic knowledge management

## Why It Matters for RAG Builders
Gardener provides a unified, searchable substrate for LLM agents to store, retrieve, and manage knowledge and tasks, eliminating the need for separate memory or task systems.
