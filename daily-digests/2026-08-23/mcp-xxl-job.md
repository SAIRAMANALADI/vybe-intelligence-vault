## Summary
MCP server that enables AI assistants to directly manage XXL-JOB scheduled tasks via the MCP protocol, providing CRUD operations, execution control, and log monitoring for distributed job scheduling.

## Key Features
- Full lifecycle management of XXL-JOB tasks (create, read, update, delete, start, stop)
- Manual job triggering with custom parameters and executor targeting
- Cron expression preview for future execution times
- Incremental log fetching and pagination for job execution history
- Automatic session management with cookie-based authentication

## Why It Matters for RAG Builders
Enables AI assistants to programmatically manage distributed job scheduling systems like XXL-JOB, bridging the gap between natural language and enterprise task automation.
