## Summary
TokenTracker is a local-first CLI and desktop application that automatically tracks and aggregates token usage across 25+ AI coding tools, providing real-time cost analysis and usage trends through a beautiful dashboard. It requires no cloud account, API keys, or manual setup.

## Key Features
- Auto-detects and tracks token usage across 25+ AI coding tools (Claude Code, Cursor, GitHub Copilot, etc.) with zero manual configuration
- Provides a real-time, local dashboard for usage trends, cost breakdowns, and project attribution without requiring internet access
- Offers native desktop apps for macOS (menu bar + widgets) and Windows (system tray) with embedded servers
- Includes an optional leaderboard for global comparison and a Skills Manager to sync 250+ public skills across multiple AI tools
- Privacy-first design: only token counts and timestamps are tracked; prompts, responses, and file contents are never stored or transmitted

## Why It Matters for RAG Builders
TokenTracker simplifies cost monitoring and optimization for AI-powered development workflows by providing granular, real-time insights into token usage across multiple tools, enabling developers to make informed decisions without manual tracking or privacy concerns.
