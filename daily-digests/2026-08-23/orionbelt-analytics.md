## Summary
OrionBelt Analytics is an ontology-based MCP server that analyzes relational database schemas, generates RDF/OWL ontologies with embedded SQL mappings, and enables relationship-aware Text-to-SQL with automatic fan-trap prevention and GraphRAG for intelligent schema discovery.

## Key Features
- Automated RDF/OWL ontology generation with SQL mapping annotations for 8+ database connectors
- OBQC (Ontology-Based Query Check) for deterministic SQL validation against schema constraints
- GraphRAG integration for semantic schema discovery with up to 12-hop traversal and vector embeddings
- Fan-trap prevention and relationship-aware Text-to-SQL with interactive charting via MCP-UI
- Multi-schema support, workspace persistence, and integration with MCP-compatible AI clients

## Why It Matters for RAG Builders
It provides a critical safety net for RAG/AI stack builders by ensuring SQL correctness through deterministic ontology-based validation, reducing hallucinations and errors in database interactions.
