## Summary
A GitHub Action for installing and verifying AI agent skills in CI pipelines using the RoleCraft CLI. It enables automated testing of agent capabilities and skill integrity during development workflows.

## Key Features
- Integrates RoleCraft CLI into GitHub Actions for CI-based skill verification
- Supports commands like `verify`, `install`, and `doctor` for agent health checks
- Allows specifying RoleCraft versions for consistent testing environments
- Enables dry-run installations to validate skill configurations without deployment
- Provides automated workflows for verifying agent skill integrity on code changes
