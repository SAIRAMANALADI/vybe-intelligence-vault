## Summary
eos-mcp is an MCP server that enables AI assistants to interact with Arista EOS network devices via eAPI. It provides tools for executing show commands, retrieving configurations, pushing changes, and collecting diagnostic data from EOS devices.

## Key Features
- Exposes EOS show commands and running-config retrieval to MCP-compatible AI assistants
- Supports configuration push via configure sessions with commit timers
- Provides batch operations for commands and device facts retrieval
- Includes health checks and daily briefs for device monitoring
- Offers tech-support collection for diagnostics

## Why It Matters for RAG Builders
It bridges AI assistants with Arista EOS devices, enabling automated network operations and diagnostics through a standardized MCP interface.
