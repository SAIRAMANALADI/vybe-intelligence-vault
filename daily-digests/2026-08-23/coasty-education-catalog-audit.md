## Summary
An AI agent that automates university course catalog auditing by driving a real browser to extract subject details like units, prerequisites, and terms offered. It demonstrates computer-use automation with zero dependencies and offline capability, proving its workflow through self-captured video frames.

## Key Features
- Zero-dependency automation with pure Node.js built-ins
- Self-documenting workflow via captured video frames and provenance data
- Structural safety against accidental spend with dual consent and fail-closed defaults
- Cross-institution compatibility through natural language prompts (no selectors or DOM parsing)
- Offline mock mode for testing without API keys or costs
