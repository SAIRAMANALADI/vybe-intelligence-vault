## Summary
flowmux is a GTK4-based terminal application designed for AI agent workflows, offering a multiplexed workspace with integrated terminal emulation, browser control, and desktop notifications. It enables AI agents to interact with the system, control browsers, and receive task-based notifications directly within the terminal environment.

## Key Features
- Multi-pane workspace with terminal and browser tabs for mixed workflows
- In-app WebKitGTK browser controllable via AI agents over IPC sockets
- Native desktop notifications for AI agent lifecycle events (task completion, errors, approvals)
- Embedded Monaco editor for file editing with atomic saves and versioning
- Customizable keybindings, themes, and split-pane layouts for flexible UI

## Why It Matters for RAG Builders
flowmux provides a unified terminal environment where AI agents can seamlessly interact with the system, control browsers, and receive real-time feedback, making it essential for building advanced AI-driven workflows.
