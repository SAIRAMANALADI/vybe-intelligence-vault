## Summary
A web-to-markdown API that converts URLs into clean, structured markdown content for AI agents and automated systems. It leverages trafilatura for reliable extraction and supports self-hosting with blockchain-based payments.

## Key Features
- Single endpoint for URL-to-markdown conversion with JSON response
- Powered by trafilatura for high-quality, clean markdown extraction
- Agent-friendly design with programmatic access and API key authentication
- Blockchain-based payments (USDT/ETH) for API key activation
- Self-hostable on minimal hardware with Cloudflare Tunnel

## Why It Matters for RAG Builders
Provides a reliable, clean, and agent-optimized way to convert web content into markdown for RAG pipelines and AI agents.
