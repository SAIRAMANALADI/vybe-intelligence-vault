## Summary
AURor is an AI-powered CLI tool that performs deep security analysis of Arch Linux AUR PKGBUILD files. It uses an LLM-driven methodology to evaluate sources, generate structured reports, and assess risks like obfuscation, supply chain threats, and privilege escalation.

## Key Features
- Automated PKGBUILD security assessment with 9-step methodology
- Dual input support for local and remote PKGBUILD files
- AI-driven analysis using OpenAI-compatible LLMs
- Shell execution tools for autonomous command execution during assessment
- Markdown report generation with risk verdicts (LOW/MEDIUM/HIGH/CRITICAL)

## Why It Matters for RAG Builders
It provides automated, AI-enhanced security auditing for Arch Linux AUR packages, reducing manual review effort and improving supply chain integrity for RAG systems relying on AUR dependencies.
