## Summary
Meowus is an open-source social media agent that enables local-first planning, scheduling, and publishing of social campaigns via a desktop Electron app and Next.js control panel. It combines AI workflows, browser automation, and persistent user sessions to manage multiple social media accounts securely.

## Key Features
- Local-first social media campaign management with optional cloud integration via SMEPost
- Persistent Chromium browser profiles for secure multi-account handling with session reuse
- AI agent workflow for drafting, generating images, scheduling, and publishing posts across platforms
- Electron-based desktop app and Next.js web console for flexible UI access
- SQLite-backed local database for storing campaigns, schedules, and run history
