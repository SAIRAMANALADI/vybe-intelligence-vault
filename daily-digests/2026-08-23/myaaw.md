## Summary
Myaaw is a modular, single-binary AI agent framework designed to act as a personal assistant with multimodal input/output capabilities, conversation memory, and extensible agent skills. It supports text, voice, and image interactions while integrating with platforms like Telegram, Discord, and CLI.

## Key Features
- Supports text, voice (transcribed), and image input with real-time streaming responses
- Conversation memory and dynamic agent skills via SKILL.md definitions
- Native integration with filesystem, Bash, and Python execution tools
- Single binary deployment with zero external dependencies (SQLite-based)
- Multi-platform support including Telegram, Discord, and CLI interfaces

## Why It Matters for RAG Builders
Myaaw provides a flexible, locally deployable agent framework with multimodal capabilities and extensible skills, making it ideal for building custom AI assistants in RAG stacks.
