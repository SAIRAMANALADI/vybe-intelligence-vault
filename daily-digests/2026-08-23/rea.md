## Summary
REA is a CLI and MCP server designed to enable coding agents to reverse engineer macOS applications, understand their features, and recreate them in custom projects. It provides tools for binary inspection, decompilation, and analysis without requiring source code access.

## Key Features
- CLI and MCP server integration for coding agents to inspect and analyze macOS applications
- 42 built-in tools for binary inspection, decompilation, and feature reconstruction
- Automated setup for Hopper Disassembler and Node.js dependencies
- Supports Swift and Objective-C metadata analysis
- Local-only execution with no hosted analysis service

## Why It Matters for RAG Builders
REA empowers coding agents to autonomously reverse engineer macOS applications, enabling them to understand and recreate features without source code access, which is critical for building custom solutions or interoperable replacements.
