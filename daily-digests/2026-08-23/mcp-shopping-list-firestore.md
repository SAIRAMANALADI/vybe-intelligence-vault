## Summary
A lightweight MCP server backed by Firebase Firestore for managing grocery lists via CRUD operations. It provides tools to list, add, update, and delete items in a structured format.

## Key Features
- CRUD operations for grocery list management
- Firebase Firestore integration for data persistence
- Supports both stdio and HTTP transport modes
- Item format with UUID, name, quantity, and timestamps
- Lightweight and easy to configure
