## Summary
specsmith is a Windows-based toolkit designed to simplify the management of AEE (Agent Execution Environment) agent sessions, execution profiles, and tool setup, including support for FPGA/HDL workflows and LLM providers like Anthropic, OpenAI, and Ollama.

## Key Features
- Centralized management of agent sessions and execution profiles
- Built-in tool installer for FPGA, HDL, and LLM-related tools
- Support for multiple LLM providers (Anthropic, OpenAI, Gemini, Ollama)
- Over 50 CLI commands for automation and control
- Windows-native GUI for ease of use

## Why It Matters for RAG Builders
specsmith streamlines the setup and management of AI agent environments, reducing friction for developers working with constrained or hardware-specific workflows.
