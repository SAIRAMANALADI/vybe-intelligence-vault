## Summary
rust-doctor is a Rust-focused static analysis tool that automatically detects and fixes common Rust code issues, including security vulnerabilities, performance bottlenecks, and anti-patterns. It integrates with Clippy and provides autofix capabilities to streamline code quality improvements.

## Key Features
- Automated detection and autofix of Rust code issues (e.g., hardcoded secrets, deadlocks)
- Workspace parallelism with bounded thread usage to prevent deadlocks
- Reduced false positives via entropy-based secret detection and test code exclusion
- Signed npm artifacts with OIDC-based provenance attestations for supply chain security
- Self-improving through dogfooding and continuous integration hardening
