## Summary
ELY is a self-hosted, GDPR-native AI agent designed for privacy-conscious users and organizations. It runs on local hardware, masks sensitive data before LLM calls, and enforces human-in-the-loop (HITL) approval for irreversible actions, ensuring data sovereignty and compliance.

## Key Features
- Native PII anonymization before LLM calls to protect sensitive data
- Structural human-in-the-loop (HITL) approval for irreversible actions
- Multi-user support with encrypted vaults and per-user memory
- Self-improving agent with autonomous playbook generation and auto-diagnosis
- Multi-channel integration (web, mobile, voice, Telegram, Slack, etc.)

## Why It Matters for RAG Builders
ELY provides a sovereign, privacy-first alternative to cloud-based AI agents, enabling secure and compliant RAG deployments for organizations handling sensitive data.
