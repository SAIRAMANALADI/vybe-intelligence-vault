## Summary
Specky is a CLI toolkit for Spec-Driven Development that enforces a deterministic 10-phase pipeline using 13 specialized agents, 58 MCP tools, 22 prompts, 14 skills, and 16 automation hooks. It transforms raw inputs like meeting transcripts or documents into validated specifications, architecture, and deployable code across multiple AI IDEs.

## Key Features
- 13 specialized agents with defined roles and guardrails for end-to-end development workflows
- 58 MCP tools for validation, generation, and enforcement across the pipeline
- 10-phase enforced pipeline with human review gates (LGTM) for quality control
- Cross-platform CLI for installing agents, prompts, skills, and hooks into AI IDEs (VS Code, Cursor, Claude Code, etc.)
- Enterprise-ready features including compliance frameworks (HIPAA, SOC2, GDPR) and audit trails

## Why It Matters for RAG Builders
Specky provides a structured, deterministic approach to AI-driven development that reduces rework and ensures traceability from specification to deployment, making it essential for building reliable RAG systems.
