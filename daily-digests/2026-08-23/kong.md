## Summary
Kong Gateway is a cloud-native, scalable API and AI gateway that provides high-performance proxying, routing, load balancing, and advanced AI traffic capabilities including multi-LLM support, semantic security, and MCP traffic governance. It serves as a central layer for orchestrating microservices, APIs, and agentic LLM/MCP workflows.

## Key Features
- High-performance proxying and routing for APIs, LLM, and MCP traffic
- Multi-LLM support with universal API routing across providers like OpenAI, Anthropic, and AWS Bedrock
- Advanced AI traffic governance including semantic security, caching, and observability
- Extensible plugin system with 60+ plugins for authentication, rate limiting, transformations, and monitoring
- Native Kubernetes Ingress Controller support and hybrid deployment models for scalability
