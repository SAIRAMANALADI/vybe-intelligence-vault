## Summary
A Model Context Protocol (MCP) server providing full access to Microsoft 365 services (Mail, Calendar, OneDrive, SharePoint, Contacts, Teams) via the Microsoft Graph API. Supports both personal and enterprise accounts with multi-account management and 95+ tools for RAG/AI workflows.

## Key Features
- 95+ tools covering Mail, Calendar, OneDrive, SharePoint, Contacts, and Teams via Microsoft Graph API
- Multi-account support with named profiles and token caching for seamless switching
- Supports both stdio and Streamable HTTP transport modes for single-user and multi-user deployments
- Context-free file uploads via MCP Apps for efficient file handling in RAG workflows
- Security-hardened with encrypted token caches and deletion safeguards

## Why It Matters for RAG Builders
It enables AI agents to directly interact with Microsoft 365 data, unlocking powerful RAG capabilities for enterprise workflows.
