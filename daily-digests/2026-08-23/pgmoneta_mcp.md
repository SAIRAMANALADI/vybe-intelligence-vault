## Summary
pgmoneta MCP is an official Model Context Protocol (MCP) server for pgmoneta, a PostgreSQL backup and restore solution. It enables secure interaction with pgmoneta servers via SCRAM-SHA-256 authentication and supports local LLM integration for offline model execution.

## Key Features
- Official MCP server for pgmoneta with secure authentication
- Supports local LLM models (Ollama, llama.cpp, ramalama) for offline execution
- Provides administration, client, and inspection tools for pgmoneta
- Enables backup, restore, and verification commands via MCP
- Integrates with multiple open-source LLM providers and models

## Why It Matters for RAG Builders
It bridges PostgreSQL backup operations with MCP-compatible AI agents, enabling secure and offline-capable interactions for RAG pipelines.
