## Summary
The eBay MCP server is a local Model Context Protocol (MCP) server that connects AI assistants like Claude, Cursor, and Zed directly to eBay's Sell APIs. It exposes 322 tools covering 100% of eBay's Sell API surface for inventory, orders, marketing, analytics, and developer tooling, enabling AI-driven eBay management.

## Key Features
- Exposes 322 tools covering 100% of eBay's Sell APIs for inventory, orders, marketing, and analytics
- Supports 9 AI clients (Claude, Cursor, Zed, etc.) with auto-configuration and OAuth 2.0 token management
- Local-first and private, running entirely on the user's machine with no cloud relay
- Automatic retry with exponential backoff for rate limits and TypeScript end-to-end type safety
- One-command setup (`npm run setup`) for seamless configuration and OAuth flow

## Why It Matters for RAG Builders
