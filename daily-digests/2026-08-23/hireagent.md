## Summary
HireAgent is an autonomous agentic pipeline that automates the entire job application process for entry-level software engineers. It scrapes job boards, scores roles using LLMs, tailors resumes, and auto-fills ATS forms using vision-verified browser automation, all from a single terminal command.

## Key Features
- Automated job discovery across 8+ job boards with eligibility filtering
- LLM-powered job scoring and resume tailoring with DeepSeek models
- Vision-verified browser automation for ATS form filling and CAPTCHA solving
- Interactive React + FastAPI dashboard for real-time pipeline monitoring
- Multi-stage pipeline orchestration with CLI and API endpoints

## Why It Matters for RAG Builders
It provides a production-grade, end-to-end automation framework for job applications that integrates LLM-driven personalization with resilient browser automation, reducing manual effort while maximizing application success rates.
