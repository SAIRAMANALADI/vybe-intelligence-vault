## Summary
Project64 provides a suite of tools, skills, and an MCP server to enable AI agents to write, debug, and deploy Commodore 64 software using the VICE emulator. It bridges modern AI workflows with retro computing by offering CLI commands and programmatic interfaces for emulation, assembly, and cartridge packaging.

## Key Features
- AI-driven Commodore 64 coding and debugging via VICE emulator
- CLI and MCP server for programmatic agent interaction
- Support for BASIC, 6502 assembly, and cartridge packaging
- Disk image manipulation and validation
- Declarative YAML-based testing framework
