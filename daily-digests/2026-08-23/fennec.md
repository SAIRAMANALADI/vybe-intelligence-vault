## Summary
Fennec is an MCP (Model Context Protocol) server that provides AI agents with real-time, cross-layer observability into development environments, including browsers, terminals, and processes. It bridges the gap between AI and developer tools, enabling agents to diagnose issues without manual copy-pasting.

## Key Features
- Full-stack correlation engine that automatically links browser errors, network issues, and server logs to identify root causes with high confidence scores.
- 130+ MCP tools across 17 categories, including AI-native APIs like `observe()`, `ai_diagnose()`, and `correlate()` for token-efficient AI-agent interactions.
- Lazy Context System delivering information in levels (Pulse, Summary, Detail, Raw) to reduce token usage by up to 200x compared to raw data dumps.
- Zero-dependency browser observation via CDP Observer with optional Playwright integration for full automation (click, type, upload, etc.).
- Security-first design with sandbox mode, permission controls, domain allowlists, and audit logging for safe AI-agent interactions.

## Why It Matters for RAG Builders
Fennec eliminates the manual copy-paste bottleneck between AI agents and developer tools, enabling autonomous, real-time debugging and observability for AI-native development workflows.
