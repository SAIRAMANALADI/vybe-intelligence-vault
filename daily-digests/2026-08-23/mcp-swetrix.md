## Summary
Provides MCP (Model Context Protocol) servers for the Swetrix analytics platform, enabling AI assistants like Claude to query analytics data, track events, and manage projects via the Swetrix API. Includes three specialized packages for statistics, events, and admin operations.

## Key Features
- 34 read-only tools for traffic, performance, errors, funnels, and goals via statistics MCP
- 5 tools for tracking pageviews, custom events, heartbeats, errors, and revenue via events MCP
- 34 tools for managing projects, funnels, annotations, and organizations via admin MCP
- Supports both local (stdio) and remote (Streamable HTTP) deployment modes
- Pre-built Docker images for self-hosting and centralized access

## Why It Matters for RAG Builders
Enables AI assistants to directly interact with analytics and event data, enhancing RAG pipelines with real-time insights and operational control.
