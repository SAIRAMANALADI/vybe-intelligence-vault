## Summary
DIOSCURI is a twin-agent system (CASTOR for Telegram and POLLUX for Discord) designed as community/devrel agents for the AICOM ecosystem. It features a self-syncing knowledge base (MNEMOSYNE), a prompt-injection firewall (AEGIS), and deterministic moderation to handle Q&A and content syndication across platforms.

## Key Features
- Twin-agent architecture (Telegram + Discord) with cross-promotion and language mirroring
- Self-updating knowledge base (MNEMOSYNE) with GitHub sync and poisoned-document filtering
- Ten-layer prompt-injection firewall (AEGIS) with deterministic moderation and hash-chained audit logs
- Tool-less Q&A system with rate limiting, cost guards, and bilingual (EN/RU) defenses
- Cross-platform syndication (Bluesky, Mastodon, dev.to) with manual opt-in for X

## Why It Matters for RAG Builders
DIOSCURI provides a hardened reference implementation for deploying secure, multi-agent community systems with robust injection defenses and moderation, critical for RAG builders integrating public chat interfaces.
