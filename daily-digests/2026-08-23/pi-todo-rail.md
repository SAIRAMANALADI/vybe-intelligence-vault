## Summary
A Pi extension that converts AI model outputs into a persistent, branch-aware Todo list pinned above the editor, enabling shared task management between users and agents without losing context or requiring external tools.

## Key Features
- Converts AI model outputs into actionable Todo tasks automatically
- Branch-aware state management for conversation branches
- Shared plan between user and AI agent with real-time synchronization
- Lightweight UI pinned above the editor with minimal distraction
- Keyboard shortcuts and commands for task manipulation

## Why It Matters for RAG Builders
It bridges the gap between AI-generated plans and executable tasks, ensuring critical insights remain actionable and visible during development workflows.
