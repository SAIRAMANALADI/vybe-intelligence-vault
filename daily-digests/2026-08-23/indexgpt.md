## Summary
IndexGPT is a local AI assistant that enables users to parse, query, and fine-tune models using research PDFs without requiring programming expertise. It supports offline document processing, question answering, and model adaptation via SFT and LoRA.

## Key Features
- Local PDF parsing and question answering with RAG
- Supervised Fine-Tuning (SFT) for custom dataset generation
- LoRA-based model adaptation for efficient training
- Cross-platform desktop application (Windows, macOS, Linux)
- Privacy-preserving offline operation

## Why It Matters for RAG Builders
IndexGPT provides a user-friendly way to build and fine-tune local RAG systems for document-based research without cloud dependency.
