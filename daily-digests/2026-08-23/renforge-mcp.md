## Summary
RenForge is an MCP (Model Context Protocol) server, CLI, and web dashboard designed to interact with Ren'Py visual-novel projects. It enables AI agents or humans to inspect projects, control running games, manage assets, generate translations, and run builds through a unified interface.

## Key Features
- MCP server for AI agent integration with Ren'Py projects
- Live game control and state manipulation (dialogue, variables, input)
- Web dashboard for real-time project inspection and management
- Asset and translation management (orphaned asset detection, translation generation)
- Autopilot mode for automated game testing and label coverage analysis

## Why It Matters for RAG Builders
RenForge bridges AI agents with Ren'Py visual-novel projects, enabling automated testing, state inspection, and dynamic interaction, which is critical for AI-driven game development and debugging workflows.
