## Summary
Voxa enables users to interact with AI agents from any device, with the agent's response delivered via a phone call. It supports self-hosting with an MIT-licensed server and web client, allowing users to run the system independently using their own API keys.

## Key Features
- Enables AI agent interaction from any device with phone call responses
- Supports self-hosting with MIT-licensed components for full control
- Zero-config setup for quick deployment and pairing
- Compatibility with major platforms (macOS, iPhone) and agents (Claude Code)
- Open-source server and web client with proprietary hosted relay for convenience

## Why It Matters for RAG Builders
Voxa bridges the gap between AI agents and user accessibility by delivering responses via phone calls, making it essential for AI systems requiring real-time, cross-device interaction.
