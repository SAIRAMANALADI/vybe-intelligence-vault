## Summary
Onchain Agent is an open-source autonomous AI-powered Web3 platform enabling multi-chain EVM transactions, encrypted wallet management, Uniswap DEX swaps, and real-time blockchain analytics via natural language commands.

## Key Features
- Autonomous AI agent engine supporting OpenAI, Google Gemini, and OpenRouter models
- Multi-chain EVM support (Ethereum, Polygon, Robinhood Chain) with customizable RPC endpoints
- Secure wallet management with AES encryption and password-protected private key export
- Automated token swaps via Uniswap Trading API with smart routing and slip tolerance
- Real-time transaction tracking, event log decoding, and token balance queries via Blockscout

## Why It Matters for RAG Builders
It provides a critical bridge between AI agents and blockchain operations, enabling secure, autonomous execution of multi-chain transactions and DeFi operations for RAG and AI stack builders.
