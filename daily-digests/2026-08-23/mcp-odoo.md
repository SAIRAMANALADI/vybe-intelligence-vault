## Summary
Odoo MCP is a Model Context Protocol (MCP) server that integrates Odoo (any edition or version 16+) with AI agents, enabling secure read/write access to Odoo databases without requiring Odoo-side setup or admin permissions. It bridges Odoo's data with LLMs like Claude, GPT, or Gemini for real-time business workflows.

## Key Features
- 41+ MCP tools for read/write operations, diagnostics, and schema discovery
- Safe write workflow with approval tokens, validation, and human-in-the-loop confirmation
- Multi-instance support with per-instance routing, tokens, and caches
- Field-level ACL for granular access control on reads and writes
- Pre-built workflows for common business tasks (invoicing, month-end close, migration audits)

## Why It Matters for RAG Builders
Odoo MCP enables AI agents to securely interact with Odoo databases in real-time, unlocking automated business workflows and reducing manual scripting for RAG and agent-based systems.
