## Summary
pi-mem provides persistent, structured memory management for AI coding agents like pi, enabling long-term fact storage, daily logging, scratchpad management, and semantic search capabilities. It integrates seamlessly with agent workflows to maintain context and improve decision-making over time.

## Key Features
- Structured memory storage with long-term, daily, and scratchpad files in Markdown format
- Automated context injection of relevant files into agent prompts for continuity
- Semantic search across all memory files with case-insensitive keyword matching
- Configurable via environment variables or JSON file for flexible deployment
- Auto-commit to Git for versioned memory backups and change tracking
