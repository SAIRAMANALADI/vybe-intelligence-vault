## Summary
Parallax is a secure, extensible agent runtime with a CLI interface that proposes actions for validation, authorization, and execution. It supports deterministic permissions, file editing, shell execution, and durable sessions with both fake and OpenAI-compatible model providers.

## Key Features
- Secure agent runtime with deterministic permissions and human approvals
- Typed tool registry with Zod-validated inputs for safety
- Native filesystem and shell execution tools with workspace scoping
- SQLite-based durable session persistence and resume capability
- Support for both fake and OpenAI-compatible model providers (e.g., NVIDIA NIM)

## Why It Matters for RAG Builders
Parallax provides a robust, secure foundation for building and deploying AI agents with built-in safety controls and extensibility, making it essential for RAG and agentic workflow builders.
