## Summary
supervis is a CLI tool that acts as a technical lead between users and Claude Code, using DeepSeek to plan, delegate, and oversee tasks end-to-end. It automates multi-step workflows like project scaffolding, code generation, testing, and deployment without manual intervention.

## Key Features
- AI-driven task planning and delegation using DeepSeek to split work between flash and pro models based on complexity
- Real-time TUI for full transparency into Claude Code's actions (file edits, shell commands, builds)
- Automatic error correction and escalation to higher-tier models when tasks stall or fail
- Configurable cost budgets and model tiering to optimize performance and spending
- Supports project-specific context files (e.g., `.supervis/SUPERVIS.md`) for better task execution

## Why It Matters for RAG Builders
It eliminates the need for manual babysitting of AI agents by automating multi-step workflows, making it essential for AI engineers building autonomous systems.
