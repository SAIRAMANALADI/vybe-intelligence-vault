## Summary
Busabase is a local-first, open-source database and knowledge base designed for reviewing, approving, and merging AI-generated content and business data. It provides an approval-first workflow with change requests, audit trails, and a structured API for AI agents and applications.

## Key Features
- Approval-first workflow for AI-generated changes with human review
- Built-in change requests, comments, and audit trails for transparency
- Local-first architecture with embedded PGlite or external PostgreSQL/S3 storage
- REST API for seamless integration with AI agents and applications
- Multi-platform support (desktop, CLI, Docker, mobile)

## Why It Matters for RAG Builders
Busabase ensures AI-generated data is reviewed and approved before becoming trusted, bridging the gap between AI output and reliable, auditable knowledge bases for RAG systems.
