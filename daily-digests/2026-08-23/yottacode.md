## Summary
yottacode is an autonomous, self-learning AI coding agent that automates complex, multi-step development tasks directly from the terminal. It plans, edits repositories, runs commands, manages Git, and iterates until tasks are complete, with model-agnostic support and built-in memory and security layers.

## Key Features
- Model-agnostic architecture supporting 10+ providers and local models
- Self-learning memory system that improves with usage and retrieves relevant context dynamically
- Built-in security policy with layered approvals, path validation, and deny rules
- Deep GitHub integration for PR/Issue management and end-to-end task automation
- Plan mode, auto mode, and checkpointing for safe and reversible operations
