## Summary
Hover is an open-source Vibe Testing suite that integrates with coding agents (e.g., Claude Code, Cursor) to explore applications, map business flows, and automatically generate deterministic Playwright test suites. The generated tests are owned by the user, run in CI without AI, and ensure record==replay fidelity.

## Key Features
- Automated generation of Playwright test suites from agent-driven browser interactions
- Deterministic test crystallization with record==replay fidelity (no LLM-generated code)
- Guard-first development workflow for test-first coding practices
- VS Code extension for visualizing business flows and test coverage
- Hover Cloud for CI result analysis, drift-vs-bug triage, and regression alerts

## Why It Matters for RAG Builders
Hover enables AI-driven test automation while ensuring deterministic, human-owned test suites that run in CI without AI dependency, bridging the gap between rapid AI-assisted development and reliable regression testing.
