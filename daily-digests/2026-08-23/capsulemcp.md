## Summary
A Model Context Protocol (MCP) server for Capsule CRM that enables natural-language interactions with CRM data (contacts, organizations, opportunities, etc.) via tools like Claude Desktop or Code. It provides 89 tools for reading and writing CRM records, with support for structured filters, batch operations, and OAuth-based hosted deployments.

## Key Features
- 89 tools covering full Capsule CRM resource graph (read/write operations)
- Support for structured filters, saved searches, and batch fetches (up to 50 records per call)
- Two transport modes: stdio for local use and HTTP+OAuth for hosted deployments
- Read-only mode and destructive action confirmations for safety
- MCP tool annotations for read-only and destructive hints to guide client behavior

## Why It Matters for RAG Builders
It bridges CRM data with AI agents via MCP, enabling secure, natural-language interactions with business records for RAG pipelines and automation workflows.
