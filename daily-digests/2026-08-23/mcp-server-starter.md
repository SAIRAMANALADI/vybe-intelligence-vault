## Summary
A TypeScript starter template for building Model Context Protocol (MCP) servers with stdio transport, OIDC npm publishing, and comprehensive CI/CD. It provides a reference implementation for tools, resources, prompts, and testing workflows.

## Key Features
- Pre-configured MCP server with stdio transport and TypeScript strict mode
- Built-in support for tools, resources, and prompts with Zod validation
- OIDC trusted publishing for npm packages
- Comprehensive CI/CD pipeline with security scanning and license compliance
- Example implementations for local testing (MCP Inspector, Claude Desktop)

## Why It Matters for RAG Builders
It accelerates the development of MCP servers by providing a production-ready template with essential patterns for tools, resources, and prompts, reducing setup time for AI engineering teams.
