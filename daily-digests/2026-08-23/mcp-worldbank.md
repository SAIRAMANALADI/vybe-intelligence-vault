## Summary
A Model Context Protocol (MCP) server providing access to the World Bank's Open Data API, offering thousands of development, economic, social, and demographic indicators for global cross-country comparisons. It enables AI agents to query historical and current data for analysis and research.

## Key Features
- Access to 1394+ World Bank development indicators with historical time series data
- Supports plain English queries for AI agents via MCP gateway
- Provides ISO country codes and aggregate group codes for peer comparisons
- Handles data freshness, vintage, and coverage gaps with clear documentation
- Zero-authentication access to fully public World Bank Open Data
