## Summary
claude-nexus enables instant peer discovery and messaging between multiple Claude Code instances across different projects or machines. It acts as a broker daemon that facilitates real-time communication via MCP channels, ensuring reliable message delivery and cross-platform compatibility.

## Key Features
- Instant message delivery via MCP channels with ack-based reliability
- Scoped peer discovery (machine, directory, or repo level)
- Cross-platform support (macOS, Linux, Windows)
- Auto-reaping of dead peers and orphaned servers
- Stable peer identity with optional human-readable names
