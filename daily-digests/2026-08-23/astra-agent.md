## Summary
Astra Agent is a hosted, multi-tenant Distributed Enriched-Persona Agent (D.E.P.A.) that provides authenticated multi-turn conversations, bounded persona and memory context, and delegated task execution via Astra Remote Agents (ARA). It supports development and OpenRouter model adapters, repository inspection, and secure policy enforcement with MariaDB persistence and Qdrant retrieval.

## Key Features
- Hosted multi-tenant architecture with scoped capabilities for authenticated users and ARAs
- Bounded persona and memory context with policy enforcement and audit trails
- Delegated task execution via Astra Remote Agents (ARA) with lease-based operations
- Support for OpenRouter and local model backends with deterministic fallbacks
- MariaDB persistence and Qdrant retrieval for memory and vector storage

## Why It Matters for RAG Builders
Astra Agent provides a robust, secure framework for building distributed AI agents with bounded execution, memory management, and policy enforcement, critical for scalable and accountable RAG systems.
