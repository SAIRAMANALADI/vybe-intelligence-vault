## Summary
NevoFlux Agent is an AI-powered browser assistant with native computer control capabilities, enabling full browser automation, cross-platform desktop interactions, and integration with multiple LLM providers via MCP and OpenAI-compatible APIs.

## Key Features
- Full browser automation with extension-based control (navigation, clicks, form filling, screenshots, JavaScript execution)
- Cross-platform computer control (screenshots, mouse, keyboard) for Linux, macOS, and Windows
- MCP server integration for Claude Code and other MCP-compatible tools
- Extensible WASM-based skill system with host functions for custom functionality
- Headless Docker deployment with OpenAI-compatible API and task management

## Why It Matters for RAG Builders
NevoFlux Agent provides a unified framework for AI agents to interact with both browsers and desktop environments, bridging the gap between digital and physical workflows for RAG systems.
