## Summary
agent-tui is a terminal user interface (TUI) for interacting with AI agents, built on the agent-core framework and leveraging OpenTUI for rendering. It provides a command-line interface for managing and observing AI agent workflows.

## Key Features
- Interactive terminal UI for AI agents with real-time feedback
- Cross-platform support (Windows and Linux x64)
- Built-in agent hooks for automated validation and formatting (e.g., linting, typechecking)
- Customizable keybindings for improved user experience (e.g., Shift+Enter for newlines)
- Early-stage development with active release cycle (v0.0.9 to v0.0.11 in recent weeks)

## Why It Matters for RAG Builders
It provides a streamlined, developer-friendly interface for managing and debugging AI agents directly from the terminal, enhancing productivity in AI engineering workflows.
