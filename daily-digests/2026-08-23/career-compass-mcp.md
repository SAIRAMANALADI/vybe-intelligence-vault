## Summary
Career Compass MCP is an AI-native career co-pilot that integrates with Claude to automate job search tasks, including resume tailoring, application tracking, and interview preparation. It operates locally, storing all user data in YAML files on the user's machine without cloud sync or telemetry.

## Key Features
- Local-first data storage in YAML files with no cloud sync or telemetry
- Automated resume and cover letter tailoring via Claude integration
- Application pipeline tracking with Kanban-style dashboard
- Interview preparation tools including STAR story matching and company research
- Privacy-focused design with all data stored on the user's machine

## Why It Matters for RAG Builders
It enables AI agents like Claude to automate complex career-related tasks while ensuring user data privacy and control.
