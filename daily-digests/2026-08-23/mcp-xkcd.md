## Summary
mcp-xkcd is an MCP (Model Context Protocol) server that wraps the xkcd.com JSON API, providing AI agents with tools to fetch XKCD comics by number, latest release, or randomly. It is part of the Pipeworx gateway, enabling access to 1394+ live data sources for AI applications.

## Key Features
- Provides three MCP tools: get_latest, get_comic, and random_comic for flexible comic retrieval
- Integrates seamlessly with MCP clients like Claude Desktop, Cursor, and Windsurf
- Part of the Pipeworx gateway, offering access to 1394+ live data sources
- Supports plain English queries via ask_pipeworx for automated tool selection
- MIT licensed, ensuring open-source accessibility
