## Summary
Sitemd Flow is a declarative pipeline framework for AI coding agents to build static websites as state machines, enabling predictable, multi-agent collaboration without vendor lock-in. It treats websites as dependency-injected flow graphs with hash-verified artifacts and granular retry logic.

## Key Features
- Declarative flow graphs for AI agents with state machine semantics
- Granular node retry logic with hash-verified artifact caching
- Multi-agent conflict resolution and priority-based execution
- Agent-native CLI and SDKs (Claude, Codex, Gemini, OpenClaw)
- Seamless integration with static hosts (S3, Netlify, Vercel, etc.)

## Why It Matters for RAG Builders
Sitemd Flow enables AI agents to collaboratively build static websites with deterministic pipelines, reducing hallucinations and deployment errors while eliminating vendor lock-in for RAG/AI stack builders.
