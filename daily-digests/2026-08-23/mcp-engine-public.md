## Summary
SemanticOps MCP is an MCP server that enables AI assistants like Claude, Copilot, and ChatGPT to programmatically interact with Power BI Desktop files. It allows reading, modifying, and optimizing Power BI models through natural language, including running DAX queries, managing measures, and handling relationships.

## Key Features
- Programmatic Power BI model interaction via natural language
- DAX query execution and measure management
- User-context calculated columns for advanced analytics
- Field parameter operations for dynamic report slicers
- Portable test bundles for model validation and testing

## Why It Matters for RAG Builders
It bridges AI assistants with Power BI, enabling automated, natural-language-driven analytics and model management for RAG pipelines.
