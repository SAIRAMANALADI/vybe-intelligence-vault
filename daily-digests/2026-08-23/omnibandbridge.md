## Summary
OmniBandBridge (OBB) is a closed-source platform that captures real-time running and walking dynamics from wearables (e.g., Xiaomi Mi Bands, Garmin watches, Atlas footpods) and retransmits the data via open protocols (BLE RSC/TCP) to third-party platforms like Zwift. It fuses sensor data to compute personalized metabolic-power metrics for AI-based workout analysis.

## Key Features
- Real-time capture of running/walking dynamics (cadence, speed, stride, GCT, impact, VO, VR)
- Integration with Xiaomi Mi Bands, Garmin watches, and Atlas footpods
- Fusion of sensor data (HR, treadmill speed/incline) for metabolic-power computation
- Retransmission via BLE RSC/TCP to platforms like Zwift
- Community-driven issue tracking and feature requests

## Why It Matters for RAG Builders
OmniBandBridge enables seamless integration of wearable sensor data into AI-driven workout analysis pipelines, enhancing the accuracy of personalized fitness and performance metrics.
