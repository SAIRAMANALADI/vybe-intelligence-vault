## Summary
UniGrok is a local-first Grok MCP server and gateway that enables multiple IDEs (Cursor, VS Code, Claude, etc.) to share a single Grok agent via Streamable HTTP. It routes requests across xAI's API and Grok CLI subscription planes, tracks costs, and provides a browser-based Control Center for monitoring and management.

## Key Features
- Shared Grok agent across multiple IDEs via Streamable HTTP endpoint
- Dual-plane routing (xAI API and Grok CLI subscription) with per-call cost tracking
- Browser-based Control Center for monitoring, telemetry, and configuration
- OpenAI-compatible local gateway for structured agent harnesses
- Built-in tools for web search, X search, code execution, file handling, and media generation

## Why It Matters for RAG Builders
UniGrok simplifies Grok model integration for AI agents by providing a centralized, cost-tracked gateway that multiple IDEs can share, reducing API key management overhead and enabling seamless multi-tool collaboration.
