## Summary
MCP-CENDOJ provides an MCP server and REST API (FastAPI) to automate and simplify access to Spanish judicial jurisprudence from the CENDOJ database. It bypasses JavaScript-based restrictions using Playwright to scrape, search, and extract text from court rulings and resolutions in JSON format.

## Key Features
- Automated search and retrieval of Spanish court rulings using Playwright to bypass CENDOJ's JavaScript restrictions
- REST API with advanced filtering (query, dates, jurisdiction, ROJ, ECLI, norms, etc.) and PDF text extraction
- MCP server support for Stdio and SSE modes, enabling integration with AI assistants like Claude and Cursor
- Windows compatibility with event loop fixes and automated setup scripts
- Natural language prompt translation for conversational queries over legal documents

## Why It Matters for RAG Builders
It enables AI systems to programmatically access and process Spanish judicial jurisprudence, unlocking structured legal data for RAG applications and legal AI assistants.
