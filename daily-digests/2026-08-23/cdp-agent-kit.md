## Summary
cdp-agent-kit enables AI agents to connect to an existing Chrome browser session via the Chrome DevTools Protocol (CDP), allowing them to leverage existing cookies, logins, and tabs without launching a new headless instance. This eliminates redundant authentication steps and enables persistent, collaborative AI-human browsing workflows.

## Key Features
- Connects to existing Chrome browser sessions, inheriting cookies, logins, and tabs
- Supports 10 built-in tools for navigation, interaction, and data extraction via LLM function calling
- Enables persistent context across multiple AI tasks without restarting the browser
- LLM-agnostic with compatibility for OpenAI, Anthropic, DeepSeek, Gemini, and local models
- Human-AI collaboration within the same browser instance, allowing seamless task handoffs

## Why It Matters for RAG Builders
It eliminates the need for AI agents to rebuild browser sessions from scratch, enabling them to work directly with a user's existing authenticated state for faster, more reliable automation and collaboration.
