## Summary
Patchwork OS is a local-first runtime that acts as a decision layer between AI agents and their actions, enforcing approval workflows for high-risk operations while allowing low-risk tasks to proceed automatically. It includes a YAML-based recipe system, a dashboard for oversight, and an MCP bridge for IDE integration.

## Key Features
- Blast radius-based action classification with automatic approval queues for risky operations
- Worker autonomy system that grants permissions based on track record and risk assessment
- Durable decision receipts and audit trails for explainability and accountability
- 45+ pre-built connectors for services like GitHub, Slack, Gmail, and more
- MCP bridge providing 177 IDE tools for Claude Code and other AI assistants

## Why It Matters for RAG Builders
Patchwork OS ensures safe, auditable AI automation by enforcing human oversight for consequential actions, making it essential for building reliable RAG systems that interact with external tools and services.
