## Summary
GymLogic is a mobile-first PWA for tracking strength training with offline support, progression analytics, and an MCP server enabling AI agents to interact with training data, design programs, and save changes directly to user accounts.

## Key Features
- MCP-native AI agent integration for real-time training data access and program management
- Offline-first PWA with localStorage sync and fingerprint-based deduplication
- Comprehensive exercise library with 360+ entries, muscle group filters, and rich metadata
- Automated PR detection, 1RM estimation, and RIR-based load suggestions
- Personal Access Tokens (PATs) for headless agent authentication and long-lived sessions

## Why It Matters for RAG Builders
It bridges AI agents with personal training data, enabling conversational program design and direct program persistence for RAG/AI stack builders.
