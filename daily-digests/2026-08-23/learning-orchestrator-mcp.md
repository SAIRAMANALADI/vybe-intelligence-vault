## Summary
An open-source Model Context Protocol (MCP) server designed to orchestrate progressive curriculum learning and track skills development using cognitive spacing. It securely interfaces with external AI educational platforms and LMS networks for automated training and assessment.

## Key Features
- Progressive curriculum orchestration with Bloom's Taxonomy alignment
- Cognitive spacing for optimized skills retention and recall
- Secure HMAC-SHA256 handshakes for LMS and AI ecosystem integration
- Stateless, high-performance architecture for scalability
- Modular subject segment support (Robotics, API Security, SEO/AEO)
