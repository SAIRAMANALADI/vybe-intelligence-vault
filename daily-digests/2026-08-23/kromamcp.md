## Summary
Kroma MCP is a stateless, internet-connected Model Context Protocol (MCP) server that provides real-time design inspiration, component discovery, and modern web micro-effects for AI assistants. It dynamically fetches live data from design galleries, component libraries, and code repositories without local storage or caching.

## Key Features
- Stateless operation with zero local storage or caching, ensuring fresh data per request
- Six specialized tools for UI/UX inspiration, component code, shaders, site scraping, and source discovery
- Multi-tenant support via per-request API key resolution for true zero-config deployment
- Dual transport modes: stdio for IDEs and HTTP + SSE for remote hosting
- Graceful error handling with structured, readable responses for AI assistants

## Why It Matters for RAG Builders
Kroma MCP enables AI assistants to dynamically fetch live design and component data, enhancing RAG systems with real-time, high-quality UI/UX insights without requiring local databases or caches.
