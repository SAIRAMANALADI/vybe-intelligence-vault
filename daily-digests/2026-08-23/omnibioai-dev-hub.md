## Summary
OmniBioAI Dev Hub is a production-grade RAG system designed for multi-repository biomedical documentation, architecture search, and developer assistance. It combines FAISS-native vector search, Ollama local embeddings, and FastAPI-based APIs for fully local, OpenAI-independent retrieval and generation.

## Key Features
- FAISS-native vector search with IndexFlatIP for 10-50x faster retrieval
- Incremental per-repo indexing with hash-based deduplication
- Local Ollama embeddings (nomic-embed-text) and LLM inference (llama3)
- Real-time token-level SSE streaming for LLM responses
- Multi-project repository indexing with source attribution and metadata filtering

## Why It Matters for RAG Builders
It provides a fully local, scalable RAG pipeline optimized for biomedical documentation and multi-repo codebases, eliminating OpenAI dependencies while ensuring high-performance retrieval and generation.
