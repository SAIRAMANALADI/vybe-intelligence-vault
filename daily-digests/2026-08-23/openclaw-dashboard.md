## Summary
openclaw-dashboard is a local monitoring tool for managing AI agent fleets, providing real-time analytics on costs, performance, system health, security, and market data through an intuitive web-based interface.

## Key Features
- Real-time cost and performance tracking for AI agent fleets
- Local data storage using SQLite for privacy and offline access
- Intuitive web-based UI with panels for costs, performance, health, security, and market intelligence
- One-click installation and updates via Windows .exe installer
- No cloud dependency, ensuring data remains on-premise
