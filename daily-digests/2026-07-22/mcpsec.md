## Summary
mcpsec is a security scanner and protocol fuzzer designed to identify vulnerabilities in MCP (Model Context Protocol) servers by dynamically testing runtime behavior, static analysis, and fuzzing techniques. It connects to live servers to prove exploitability, uncovering issues like command injection, SSRF, and DoS vulnerabilities.

## Key Features
- Dynamic runtime scanning of MCP servers via stdio/HTTP to detect exploitable vulnerabilities
- Static analysis engine with 3,450+ sink patterns and 149 Semgrep rules for comprehensive code audits
- AI-powered payload generation and taint analysis for advanced threat detection
- Protocol fuzzing with 800+ test cases and evolutionary fuzzing for deep bug discovery
- Automated detection of command injection, SSRF, path traversal, and MCP-specific vulnerabilities

## Why It Matters for RAG Builders
It enables AI stack builders to proactively secure MCP servers against runtime exploits, reducing the risk of AI agents being compromised by malicious inputs or protocol violations.
