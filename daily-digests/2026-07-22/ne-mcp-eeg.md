## Summary
Open-source MCP server enabling AI agents to analyze Neuroelectrics EEG recordings through the Model Context Protocol. It provides tools for signal quality assessment, spectral analysis, and PDF report generation directly from EEG data files.

## Key Features
- Supports multiple EEG file formats (.easy, .nedf, .edf) with transparent normalization
- Per-channel signal quality assessment with configurable thresholds and PASS/FAIL flags
- Spectral analysis including PSD, band powers, peak alpha frequency, and alpha/theta ratios
- Generates branded PDF reports for QC and full analysis with visualizations
- Integrates with MCP-compatible AI assistants (Claude, ChatGPT, Gemini) via stdio or SSE transport

## Why It Matters for RAG Builders
It bridges EEG data with AI agents, enabling seamless integration of brain signal analysis into RAG and agentic workflows without cloud dependencies.
