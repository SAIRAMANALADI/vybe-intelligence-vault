## Summary
DvalinCode is a local-first, policy-bound AI coding agent designed for regulated teams in finance, healthcare, and security-sensitive environments. It enables controllable, transparent, and auditable AI-assisted coding with built-in governance, tamper-evident audit trails, and support for any OpenAI-compatible LLM endpoint.

## Key Features
- Policy-bound agent execution with org-level constraints and tamper-evident audit logs
- Multi-tier approvals (read-only, cowork, and autonomous modes) with inline diff previews
- Support for any OpenAI-compatible LLM (local or cloud) without vendor lock-in
- Built-in secure remediation workflows for scanning and fixing vulnerabilities with SARIF/CodeQL integration
- Zero-dependency binary (~25MB) with cross-platform support (macOS, Windows, Linux)
