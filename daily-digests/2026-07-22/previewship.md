## Summary
PreviewShip is a frontend preview deployment and publishing platform that enables developers and AI agents to deploy static build outputs (React, Vue, Vite, Next, etc.), single HTML/Markdown files, or AI-generated artifacts to fixed, shareable preview URLs in seconds.

## Key Features
- One-click deployment of static build outputs (dist, build, out, public) or single HTML/Markdown files to fixed preview URLs
- Native integration with AI coding agents (Claude Code, Cursor, Windsurf) via MCP server and agent skills
- VS Code/Cursor extension for editor-first workflows and one-click deployments
- Supports password-protected and public publishing with Pro features for enhanced access control
- Programmatic CLI library for integration into CI/CD pipelines and automated workflows

## Why It Matters for RAG Builders
PreviewShip streamlines the deployment of static artifacts and AI-generated content into shareable, fixed URLs, eliminating friction for RAG builders who need to quickly test, share, or integrate frontend outputs and AI artifacts into their workflows.
