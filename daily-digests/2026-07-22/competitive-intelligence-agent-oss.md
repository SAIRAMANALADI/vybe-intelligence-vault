## Summary
A reference implementation of a Product Manager and Competitive Intelligence Agent built on Warp, an AI-powered development environment. It automates tasks like customer feedback analysis, competitive research, pricing projections, PRD drafting, and weekly reporting through modular skills and MCP integrations.

## Key Features
- Modular agent skills for specific PM tasks (e.g., feedback analysis, pricing projections, PRD drafting)
- Integration with 10+ SaaS tools (Google Workspace, Notion, Slack, Metabase, Grain, etc.)
- Automated weekly reporting and sentiment analysis pipelines
- Cloud agent orchestration for P0 issue triage via Warp Oz
- End-to-end deployment guidance with environment variable management
