## Summary
Beckett is a zero-sidecar Model Context Protocol (MCP) server embedded directly in the Godot 4 editor as a GDScript EditorPlugin. It enables AI agents to inspect, author, run, and observe Godot projects in real-time without external processes or bridges.

## Key Features
- Zero-sidecar MCP server embedded in Godot 4 editor with no external dependencies
- Real-time runtime observation: screenshots, live scene tree, node state, performance monitors, and game logs
- Reflection-generic tools (50 in Lite, 80 in Full) that work across GDScript and C# via ClassDB
- Validate-before-write for GDScript (refuses non-compiling code) and C# build checks with structured diagnostics
- AI playtesting in Full edition: drives input, clicks UI/3D, and asserts results autonomously

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and observe Godot projects in real-time, bridging the gap between AI-driven development and game engine workflows without external sidecars.
