## Summary
A Spanish-first MCP (Model Context Protocol) server providing 25 generic financial calculators for use with AI assistants like Claude Desktop or Claude Code. It offers pure computation tools for financial ratios, valuation models, operational metrics, and Chilean tax calculations without external connections or state persistence.

## Key Features
- 25 financial calculation tools including ratios, DuPont, Altman Z-Score, and Piotroski F-Score
- Pure computation with no external connections or state persistence
- Supports CAPM, WACC, DCF, NPV/IRR, and multiples valuation models
- Includes operational tools like break-even analysis, depreciation, and loan amortization
- Parametrizable Chilean tax calculations (IVA, corporate tax, monetary correction)
