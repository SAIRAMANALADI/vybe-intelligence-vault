## Summary
Norma Financial Agent is a unified AI-driven financial decision system that fuses 135 classic investment books into a single thinking framework, combining real-time A-share data, quantitative trading engines, and knowledge graph reasoning to deliver market analysis, stock deep-dives, and portfolio optimization with human-like reasoning.

## Key Features
- Fuses 135 classic investment books into a single coherent thinking system for human-like financial reasoning
- Six-agent debate chamber (Value, Technical, Macro, Behavioral, Quant, Tactical) for collaborative analysis and validation
- Real-time A-share data integration with 28 endpoints and localized Chinese market corrections
- Four-layer architecture (Data, Thinking, Quant, Knowledge) with cross-validation and confidence scoring
- Supports market analysis, stock deep-dives, strategy backtesting, signal scanning, and portfolio optimization
