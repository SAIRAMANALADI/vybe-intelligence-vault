## Summary
WpfVisualTreeMcp is an MCP server that enables AI agents to inspect, debug, and interact with running WPF applications. It provides real-time access to the visual tree, bindings, and UI elements without requiring source code changes, bridging the gap between AI-driven automation and WPF development workflows.

## Key Features
- Real-time visual tree and logical tree navigation for WPF applications
- Automatic detection and reporting of binding errors with detailed diagnostics
- Interactive UI control via clicks, text input, and keyboard shortcuts
- Cross-architecture injection (x64 ↔ x86) for inspecting 32-bit WPF apps from 64-bit servers
- Dual-mode operation: MCP server and standalone CLI for scripting and debugging

## Why It Matters for RAG Builders
It enables AI agents to autonomously debug and interact with WPF applications, reducing manual inspection time and improving automation capabilities for UI-driven workflows.
