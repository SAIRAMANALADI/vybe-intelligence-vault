## Summary
PenglaiAgent is a self-hosted AI Runtime Hub that integrates with Feishu, WeChat, desktop, and terminal interfaces to provide a unified AI assistant experience. It leverages GenericAgent as its core execution engine and offers features like local voice processing, proactive companionship, and multi-layered memory systems.

## Key Features
- Unified AI assistant across Feishu, WeChat, desktop, and terminal with a single runtime hub
- Local voice processing with SenseVoice (speech-to-text + emotion detection) and MOSS-TTS-Nano (text-to-speech)
- Four-layer memory system (index, facts, skills, raw sessions) with time/source/importance signatures
- Built-in proactive companionship with opt-in heartbeat-based interactions and adaptive feedback
- Deterministic safety rails including command/path redline interception, tool-call auditing, and prompt injection prevention

## Why It Matters for RAG Builders
PenglaiAgent simplifies the deployment and management of AI assistants across multiple channels while ensuring local control, privacy, and safety, making it essential for building robust RAG systems.
