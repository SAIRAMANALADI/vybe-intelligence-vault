## Summary
Codex Gateway is a web-based frontend and SSH connection gateway for the official Codex app-server, enabling users to manage remote Codex sessions through a browser without exposing SSH credentials. It acts as a secure intermediary, handling SSH, RPC, and app-server lifecycle management while providing real-time UI updates.

## Key Features
- Secure browser-based access to remote Codex sessions without exposing SSH credentials
- Multi-host SSH connection pooling and lifecycle management for Codex app-servers
- Real-time WebSocket-based event streaming and state synchronization across browser tabs
- Encrypted SQLite storage for user accounts, host configurations, and thread state
- Direct SSH terminal integration for manual environment inspection and debugging

## Why It Matters for RAG Builders
It provides a secure, centralized web interface for managing remote Codex agents, reducing operational complexity and improving accessibility for AI engineering teams.
