## Summary
Capture All is a Chrome Manifest V3 extension that acts as a local-first browser debugging black box for developers and AI Agents. It captures structured browser evidence including user behavior, network requests, console logs, errors, storage changes, and cookies, with visualization and export capabilities.

## Key Features
- Comprehensive browser activity capture (user behavior, network, console, errors, storage, cookies)
- Local storage of evidence in IndexedDB with optional export to JSON, JSONL, HTML, or HAR
- MCP-compatible Bridge for AI Agent control and querying of captured data
- Visual inspection via popup, main panel, and DevTools panel
- Sensitive data redaction and strict local-first architecture

## Why It Matters for RAG Builders
It provides a critical local-first tool for capturing and structuring browser evidence that AI Agents can query via MCP, enabling deeper debugging and analysis of user interactions and application behavior.
