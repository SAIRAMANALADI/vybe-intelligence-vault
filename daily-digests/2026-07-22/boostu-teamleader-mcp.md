## Summary
An open-source Model Context Protocol (MCP) server that exposes the Teamleader Focus CRM API to AI assistants like Claude, enabling natural language management of contacts, deals, invoices, projects, and more through over 100 tools.

## Key Features
- Exposes over 100 tools for Teamleader Focus CRM operations via MCP, including contacts, deals, invoices, quotations, projects, and time tracking.
- Supports natural language interaction with AI assistants like Claude, Cursor, and Windsurf for seamless CRM management.
- Provides OAuth2 authentication with automatic refresh-token rotation and persistence for secure API access.
- Allows selective tool group loading via environment variables to optimize assistant context and performance.
- Offers both self-hosted and managed versions, with the open-source repo enabling local deployment and customization.

## Why It Matters for RAG Builders
It bridges AI assistants with Teamleader Focus CRM, enabling developers and teams to manage their entire CRM workflow through natural language, reducing manual effort and accelerating productivity.
