## Summary
Aletheore is a GitHub-focused toolkit for repository operations, including an evidence-grounded audit CLI, MCP server, live dashboard, and a GitHub Action that posts PR diffs. It provides deterministic scanning for secrets, dependency vulnerabilities, and code conventions.

## Key Features
- Deterministic scanner for secrets, vulnerabilities, and code conventions
- GitHub Action that posts PR diffs with inline annotations and aggregated deltas
- MCP server for interactive querying of repository metadata and dependencies
- Supports multi-language dependency graphs (Python, Go, Rust, Java, Ruby, PHP, C/C++, C#)
- Static API endpoint mapping across 10 frameworks in 6 languages
