## Summary
A multi-agent job application system that automates job searches, CV generation, and application tracking using a YAML-based profile and universal rules. It integrates with coding agents like Claude Code or OpenCode to scrape job listings, rank fit, generate ATS-safe LaTeX CVs, and manage applications locally.

## Key Features
- Automates job scraping from LinkedIn and freehire with deduplication and fit ranking
- Generates ATS-safe 1-page LaTeX CVs from a YAML profile with universal rules
- Integrates with coding agents (Claude Code, OpenCode, etc.) for file and shell access
- Tracks applications locally with CSV or Notion integration for confirmation
- Validates profile data rigorously to prevent hardcoded or placeholder errors

## Why It Matters for RAG Builders
It provides a reusable, agent-agnostic framework for automating job search workflows, reducing manual effort and ensuring consistency in CV generation and application tracking.
