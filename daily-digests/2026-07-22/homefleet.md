## Summary
HomeFleet enables AI coding agents to delegate tasks across multiple local machines, turning a home network into a unified compute fleet. It uses MCP-native tools for seamless integration with existing agents while ensuring all workloads run on local models and LAN-only infrastructure.

## Key Features
- MCP-native tooling for seamless agent integration (list_nodes, delegate_task)
- LAN auto-discovery and Syncthing-style pairing with mutual TLS security
- Capability-aware node management for optimal task delegation
- Git bundle-based workspace synchronization for offline/air-gapped workflows
- Support for local model execution (Ollama, LM Studio, llama.cpp) and command delegation

## Why It Matters for RAG Builders
HomeFleet enables RAG builders to offload compute-intensive tasks to distributed local resources, ensuring privacy, reducing cloud dependency, and leveraging idle hardware for faster, cost-effective AI workflows.
