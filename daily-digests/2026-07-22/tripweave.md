## Summary
TripWeave is a local-first, cross-platform Vlog editor designed for travelers, enabling batch import of photos and videos to generate and edit travel vlogs with AI-assisted templates and hardware-accelerated rendering pipelines.

## Key Features
- Supports Android, Web, Windows, and macOS with a single Flutter codebase
- AI-generated editing templates with ReAct-based agent workflows
- Hardware-accelerated rendering with automatic fallback to software encoding
- Privacy-focused design with optional cloud-free local processing
- GPU-optimized image processing and real-time preview
