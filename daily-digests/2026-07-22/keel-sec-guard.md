## Summary
`keel-sec-guard` is a hybrid security auditing tool that combines deterministic static analysis with Google Gemini's semantic code analysis to detect vulnerabilities, hardcoded secrets, and logic flaws in code changes. It operates locally via CLI or as a GitHub Action in CI/CD pipelines.

## Key Features
- Hybrid security engine combining deterministic SAST with Google Gemini semantic analysis
- Dual execution modes: local CLI and GitHub Action for CI/CD integration
- Zero-cost API usage with free Google AI Studio credentials
- Automated artifact generation with self-gitignored output directories
- Fork-safe execution to prevent secret exfiltration in public repositories

## Why It Matters for RAG Builders
It provides an essential layer of automated security review for AI-driven development workflows, ensuring code changes are audited for vulnerabilities before integration.
