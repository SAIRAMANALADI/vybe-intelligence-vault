## Summary
Ghostvault is a source-available MCP server that enables AI agents to manage browser sessions across any website, including login-gated platforms like Google, GitHub, or banking sites. It provides persistent, anti-detect browser sessions with locked fingerprints, human-like interaction, and provider-agnostic login automation.

## Key Features
- Locked anti-detect fingerprints per account for persistent identity
- Provider-agnostic login automation for any website (built-in + custom providers)
- Human-like interaction with realistic typing, scrolling, and mouse movements
- Persistent sessions with encrypted storage and auto-locking for security
- 42+ MCP tools for session management, scraping, API calls, and automation

## Why It Matters for RAG Builders
Ghostvault enables AI agents to securely and reliably interact with login-gated websites, eliminating manual account management and anti-bot detection challenges for RAG and automation workflows.
