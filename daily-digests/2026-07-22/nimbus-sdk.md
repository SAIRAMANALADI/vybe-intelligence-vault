## Summary
A dependency-free TypeScript SDK for authoring Nimbus MCP (Model Context Protocol) connectors and extensions. It provides types, utilities, and testing tools to build and validate extensions for the Nimbus agent gateway.

## Key Features
- Dependency-free TypeScript contract for MCP connectors
- Provides `NimbusExtensionServer` for extension authoring
- Includes testing utilities like `MockGateway` for connector validation
- Supports HITL (human-in-the-loop) and audit logging
- Semver-stable public surface with strict TypeScript and Biome linting

## Why It Matters for RAG Builders
It enables developers to build and test Nimbus MCP connectors efficiently with a stable, dependency-free TypeScript interface.
