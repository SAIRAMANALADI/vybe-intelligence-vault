## Summary
A Model Context Protocol (MCP) server providing structured access to ReliefWeb's humanitarian data, including reports, disasters, jobs, training, and country profiles. Enables AI agents to query and retrieve real-time humanitarian information via standardized tools and resources.

## Key Features
- 9 specialized tools for querying ReliefWeb's humanitarian datasets (reports, disasters, jobs, training, countries, sources)
- Supports both STDIO and Streamable HTTP transport modes for MCP clients
- Structured filtering, pagination, and sorting for efficient data retrieval
- Agent-friendly output design with explicit context budget control (e.g., body text excluded from search results)
- Built on @cyanheads/mcp-ts-core for declarative tool definitions, unified error handling, and pluggable auth/storage backends

## Why It Matters for RAG Builders
Provides AI agents with direct, structured access to critical humanitarian data from ReliefWeb, enabling real-time crisis response, research, and decision-making in AI-driven applications.
