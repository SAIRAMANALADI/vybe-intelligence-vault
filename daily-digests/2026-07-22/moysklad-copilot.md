## Summary
A Telegram bot acting as a corporate assistant for a small manufacturing company, integrating with the Russian ERP system MoySklad. It automates financial accounting, audits inventory and financial documents using LLM, and manages production tasks via voice or text commands.

## Key Features
- Automates financial operations (payments, receipts) directly in MoySklad without local data duplication
- Two-layer audit system combining deterministic detectors with LLM-based analysis for accounting discrepancies
- Voice and text-driven production task management with LLM-assisted preview and confirmation
- Standardizes and corrects document comments using LLM with human approval before changes
- Incremental and scheduled audits with nightly full scans for continuous compliance
