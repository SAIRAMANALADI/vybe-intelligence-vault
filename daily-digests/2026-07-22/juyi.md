## Summary
句译 (juyi) is a macOS application that provides offline and cloud-based English-to-Chinese translation for selected text via a double-tap Option key shortcut. It defaults to a fully offline Apple system translation engine but allows switching to Volcengine's cloud API for higher accuracy.

## Key Features
- Default 100% offline translation using macOS system framework with ~100ms latency
- Optional cloud translation via Volcengine API for higher accuracy on long sentences
- Pluggable architecture allowing easy addition of new translation engines (e.g., DeepL, Google)
- System-wide hotkey (double-tap Option) for seamless text translation in any app
- Minimal setup with automated installation via AI agents or one-line bootstrap script

## Why It Matters for RAG Builders
It provides a privacy-focused, low-latency translation tool for macOS users, bridging offline and cloud-based translation with a simple hotkey interface, making it ideal for RAG pipelines requiring localized text processing.
