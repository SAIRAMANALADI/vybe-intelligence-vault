## Summary
smartest-tv is a desktop application and Python package that enables users to control smart TVs using natural language commands via terminal or GUI. It supports popular TV brands like LG, Samsung, Roku, and Android TV, allowing users to open apps, play media, adjust volume, and navigate menus without physical remotes.

## Key Features
- Control smart TVs via plain text commands (e.g., 'stv open netflix')
- Supports multiple TV brands (LG, Samsung, Roku, Android TV)
- Available as a Windows desktop app and Python package
- MCP server support for AI agent integration
- Media playback and app launching without remote use
