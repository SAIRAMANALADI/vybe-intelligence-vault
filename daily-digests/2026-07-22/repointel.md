## Summary
RepoIntel is an MCP (Model Context Protocol) server that analyzes local Git repositories to surface risky commits, contributor patterns, and repository health metrics entirely offline. It provides AI assistants with tools to query repository risk profiles for PR reviews, onboarding, and codebase triage.

## Key Features
- 100% offline analysis with zero API keys or cloud uploads
- Deep Git integration for commit history, diff statistics, and contributor patterns
- Instant risk scoring for commits, PRs, and branches
- MCP-native tools for seamless AI assistant integration
- Pre-merge gate for branch comparison and PR risk assessment

## Why It Matters for RAG Builders
It enables AI assistants to perform real-time, offline repository risk analysis, reducing manual review effort and catching critical issues before they merge.
