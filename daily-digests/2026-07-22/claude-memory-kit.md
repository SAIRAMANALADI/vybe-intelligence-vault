## Summary
A starter kit for Claude Code that enables persistent memory across sessions, allowing the AI agent to retain context, decisions, and patterns without manual re-explanation. It automates memory management through structured files, hooks, and audit-driven workflows.

## Key Features
- Automated session handoffs with immutable notes for seamless context retention
- Three enforced memory caps (line count, size, character limit) to prevent bloat
- Stale-reference detection to ensure memory accuracy over time
- Audit-driven memory promotion (patterns to knowledge or rules with user approval)
- Multi-project isolation with per-client folder structures and shared layers

## Why It Matters for RAG Builders
It eliminates the need to re-explain context to AI agents across sessions, significantly improving productivity and consistency in long-running workflows.
