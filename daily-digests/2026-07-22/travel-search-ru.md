## Summary
A lightweight AI agent skill for Russian travel search, enabling agents to query package tours, hotels, flights, and excursions via a Python CLI or MCP server. It integrates with production MCP endpoints to fetch real-time travel data and booking links.

## Key Features
- Supports 7 CLI commands for tours, hotels, flights, and excursions with real-time pricing
- Compatible with 30+ AI agents via agentskills.io and MCP protocol
- Lightweight Python CLI using only standard library (no pip dependencies)
- Production MCP endpoint available for direct agent integration
- Live schema validation via `describe` command for input fields
