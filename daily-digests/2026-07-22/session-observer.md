## Summary
Session Observer is a local-first observability workbench for Codex and Claude Code sessions, transforming scattered JSONL transcripts into a semantic activity stream, searchable session library, token/cost ledger, and runtime health dashboard without uploading sensitive data.

## Key Features
- Semantic activity stream grouping user turns, agent responses, and tool calls into collapsible activities
- Memory-safe JSONL scanning with incremental parsing and bounded event windows for large transcript histories
- Detailed token and cost ledger with attribution by model, workspace, and session
- Runtime health dashboard with RSS, heap, and external memory monitoring
- Local-first privacy model with no external uploads or telemetry

## Why It Matters for RAG Builders
It provides a privacy-preserving, memory-efficient way to analyze and debug local AI agent sessions without external dependencies, making it essential for developers building or debugging RAG pipelines.
