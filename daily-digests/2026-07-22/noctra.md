## Summary
Noctra automates the process of converting Linear tickets into GitHub pull requests using AI agents (Claude Code, OpenAI Codex, GitHub Copilot, or Google Antigravity) while you sleep. It orchestrates isolated worktrees, agent execution, optional multi-model reviews, and PR creation, then moves tickets to 'In Review' status.

## Key Features
- Automates ticket-to-PR conversion with AI agents (Claude, Codex, Copilot, Antigravity)
- Supports isolated git worktrees per ticket for clean, conflict-free implementations
- Optional multi-model review gate (Gemini) for quality assurance before PR creation
- Telegram integration for real-time alerts and control
- Supports multiple deployment methods (local binary, Docker, cloud platforms)

## Why It Matters for RAG Builders
Noctra streamlines the AI-driven development workflow by automating ticket implementation and PR creation, reducing manual effort and accelerating feedback loops for RAG/AI stack builders.
