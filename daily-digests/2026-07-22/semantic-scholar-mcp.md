## Summary
A Model Context Protocol (MCP) server providing 14 typed tools for direct access to Semantic Scholar's academic research APIs, enabling paper search, citation graph traversal, author profiles, and recommendations for AI workflows.

## Key Features
- 14 typed MCP tools for paper search, citation graph traversal, author profiles, and recommendations
- Verifiable supply-chain provenance (SLSA, PEP 740, CycloneDX SBOM) for secure deployments
- Built-in rate limiting, retry logic, and error handling for robust API interactions
- Support for multiple ID formats (DOI, ArXiv, PubMed, etc.) with pre-flight validation
- Streamable HTTP transport for remote MCP client integration

## Why It Matters for RAG Builders
It provides standardized, secure, and feature-rich access to Semantic Scholar's academic data, simplifying RAG pipeline integration with citation graphs and paper metadata.
