## Summary
subagent-mcp is an MCP stdio server that transforms AI coding assistants into managers of local sub-agents, enabling seamless orchestration of tasks across multiple providers like Claude and Codex. It automates delegation, routing, and concurrency control for long-running agentic workflows.

## Key Features
- Turns AI assistants into managers of local sub-agents for scalable task delegation
- Supports multiple providers (Claude, Codex, OpenAI-compatible APIs) with automatic model and effort routing
- Enforces machine-wide concurrency limits and permission gating for sub-agents
- Provides hooks for seamless integration with Claude Code and Codex via MCP
- Includes diagnostic tools (e.g., `subagent-mcp doctor`) for troubleshooting and configuration

## Why It Matters for RAG Builders
It enables AI engineers to build scalable, multi-agent workflows that dynamically delegate tasks across providers while maintaining control over concurrency and permissions.
