## Summary
agentic-workstation is an AI-first, chezmoi-managed workstation baseline that automates the setup of a developer environment with AI skills, MCP servers, agent workflows, and CLI tools in a single command. It integrates seamlessly with popular AI coding tools like Claude Code, Cursor, and GitHub Copilot.

## Key Features
- 52+ pre-built AI skill packs for tools like Jira, GitHub, Figma, and Snowflake
- Pre-configured AI agents for code review, security audits, TDD, and refactoring
- MCP server templates for zero-setup LLM and API integrations
- 60+ CLI commands for workflow automation and diagnostics
- Profile-driven tooling and multi-tool portability via symlinks and adapters

## Why It Matters for RAG Builders
