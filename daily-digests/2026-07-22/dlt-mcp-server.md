## Summary
A plugin for DLT Viewer that exposes DLT log analysis capabilities via the Model Context Protocol (MCP). It enables AI agents and MCP-compatible clients to query, retrieve, and analyze information from DLT log files in real-time.

## Key Features
- Exposes DLT log analysis via MCP for AI agents and clients
- Supports log summarization, search, and message retrieval with pagination
- Provides Markdown report generation with interactive navigation
- Persists report history across sessions and matches against loaded files
- Integrates directly with DLT Viewer for seamless log exploration

## Why It Matters for RAG Builders
It bridges DLT log analysis with MCP-compatible AI agents, enabling structured and interactive retrieval of diagnostic data for AI-driven debugging and monitoring.
