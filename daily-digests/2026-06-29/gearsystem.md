## Summary
Gearsystem is a highly accurate cross-platform emulator for Sega Master System, Game Gear, and SG-1000 systems, written in C++. It includes an embedded Model Context Protocol (MCP) server for AI-assisted debugging and tooling, enabling integration with AI agents like GitHub Copilot and Claude.

## Key Features
- Accurate Z80, VDP, PSG, and FM sound chip emulation
- Embedded MCP server for AI-assisted debugging and hardware inspection
- Cross-platform support (Windows, macOS, Linux, BSD, RetroArch)
- Full-featured debugger with disassembler, breakpoints, and memory inspection
- Agent Skills integration for specialized AI workflows (debugging, romhacking)
