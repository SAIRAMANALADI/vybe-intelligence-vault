## Summary
The i3x2ua repository provides a FastAPI-based gateway that bridges OPC UA industrial protocols to standardized REST and MCP (Model Context Protocol) endpoints. It exposes OPC UA address spaces as JSON-compatible APIs with real-time streaming via Server-Sent Events, enabling seamless integration for AI agents and applications without deep OPC UA expertise.

## Key Features
- Exposes OPC UA address spaces as REST and MCP endpoints with JSON responses
- Supports real-time streaming via Server-Sent Events (SSE) for live data updates
- Provides OpenAPI documentation for standardized API interactions
- Includes MCP tooling for AI agent integration and dynamic discovery
- Supports secure OPC UA connections with configurable encryption and authentication

## Why It Matters for RAG Builders
