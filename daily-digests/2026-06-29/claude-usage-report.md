## Summary
claude-usage-report is a Windows application that tracks and reports Claude Code usage metrics after each prompt, including token consumption, estimated costs, context window usage, and rate limit status. It integrates as a stop hook to provide real-time feedback without requiring external dashboards.

## Key Features
- Per-prompt token usage and cost reporting
- Real-time context window tracking
- Rate limit status monitoring
- Simple, plain-text output for quick review
- Integration via stop hook in Claude Code workflow
