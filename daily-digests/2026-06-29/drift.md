## Summary
drift is a static analysis tool designed to detect code drift in AI-assisted or traditional codebases by identifying architectural violations, pattern fragmentation, near-duplicate code, and AI-generated code inconsistencies. It helps maintain codebase integrity and reduce technical debt.

## Key Features
- Detects pattern fragmentation and architecture violations
- Identifies near-duplicate code blocks (mutant duplicates)
- Flags AI-generated code inconsistencies and style drift
- Provides clear reports with file names, line numbers, and issue types
- Supports pre-merge and post-AI-code-review workflows

## Why It Matters for RAG Builders
