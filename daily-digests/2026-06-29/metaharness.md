## Summary
MetaHarness is a CLI tool that generates custom AI agent harnesses tailored to any repository, enabling developers to create repo-aware agents, MCP servers, and governance policies. It acts as a factory for agent frameworks rather than another framework itself.

## Key Features
- Generates repo-specific AI agent harnesses with MCP servers and governance policies
- Supports multiple agent hosts (Claude Code, OpenAI Codex, Hermes, etc.)
- Includes Darwin Mode for self-improving harnesses and Weight-EFT for model cost reduction
- Provides repo scoring and model routing for cost-efficient AI agent operations
- Allows publishing harnesses as branded npm packages for organizational use

## Why It Matters for RAG Builders
MetaHarness enables RAG builders to create highly specialized, cost-efficient AI agents tailored to their repositories, reducing operational costs and improving agent performance without requiring a custom framework from scratch.
