## Summary
Valmis is a secure, cloud-based AI agent platform designed for workplace automation with a focus on security and isolation. It enables users to build, deploy, and manage AI agents that interact with 100+ business and productivity tools via a proxy system, ensuring credentials and host systems remain protected.

## Key Features
- Secure proxy-based API access for agents, preventing direct credential exposure
- Isolated agent runtime in Docker containers with restricted internet access
- Cross-session memory system using pgvector for semantic search and persistence
- Multi-step workflow automation with triggers (cron, webhooks, events) and conditions
- Support for 100+ integrations including Google Workspace, Slack, Notion, and Salesforce

## Why It Matters for RAG Builders
Valmis provides a secure, production-ready framework for building AI agents that can safely interact with enterprise tools, addressing critical security concerns in RAG and AI agent deployments.
