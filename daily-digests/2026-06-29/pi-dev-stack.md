## Summary
A Raspberry Pi-focused self-hosted developer stack that provides a unified CLI (`homelab`) for deploying AI, automation, monitoring, networking, and media services via Docker Compose. Designed for Raspberry Pi 5 and ARM64 Linux, it includes tools like Ollama, Open WebUI, n8n, Pi-hole, and Plex.

## Key Features
- Single CLI (`homelab`) for managing 20+ services
- MCP server for AI-assisted homelab operations
- Integrated AI runtime with Ollama and Open WebUI
- Network-wide ad blocking with Pi-hole
- Automated backups and state management for safe updates

## Why It Matters for RAG Builders
