## Summary
A marketing intelligence panel for Actio (B2B VoIP) that synchronizes GA4, Google Search Console, and Google Ads data into a local SQLite database, generates daily CMO reports via LLM (Anthropic Opus 4.7), and provides a Chainlit dashboard with alerts and email notifications.

## Key Features
- Automated data synchronization from GA4, GSC, and Google Ads into SQLite with idempotent upserts
- Daily CMO/CEO reports generated by LLM with week-over-week comparisons and actionable recommendations
- Threshold-based alerts (CPA, dry spend, policy issues) sent via Pushover priority=2 notifications
- Chainlit web dashboard with interactive Plotly charts, chat interface, and CSV exports
- MCP server for Claude Code integration with 12 tools for data querying and report generation

## Why It Matters for RAG Builders
It streamlines marketing data aggregation and AI-driven reporting, reducing manual effort for CMOs while enabling real-time insights through automated pipelines and LLM analysis.
