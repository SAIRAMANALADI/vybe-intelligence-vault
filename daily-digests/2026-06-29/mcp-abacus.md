## Summary
mcp-abacus is a type-faithful calculator MCP server designed for AI models to perform precise numeric calculations with explicit precision tracking. It supports multiple numeric modes (fixed-point, floating-point, rational, complex) and provides tools for analysis, equation solving, curve fitting, and calculus operations.

- Built-in tools for analysis, equation solving, curve fitting, and calculus operations
