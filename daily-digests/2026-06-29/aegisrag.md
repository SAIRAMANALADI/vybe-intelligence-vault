## Summary
AegisRAG is a production-grade, enterprise-focused RAG system designed for secure, auditable, and governed knowledge retrieval with tenant-aware access control, hybrid retrieval pipelines, and governed agent tooling. It emphasizes traceability, authorization, and provider-neutral LLM orchestration.

## Key Features
- Multi-tenant access control with RBAC/ACL enforced before retrieval
- Hybrid retrieval pipeline (dense + sparse + graph RAG) with RRF fusion and LLM reranking
- Governed agent tooling with schema, permission, and audit boundaries
- Built-in RAGAS evaluation and pipeline benchmarking for quality and latency tracking
- Provider-neutral architecture supporting swappable LLMs, embeddings, and vector stores

## Why It Matters for RAG Builders
AegisRAG provides a security-first, auditable foundation for RAG systems that require strict access control, traceability, and governance, making it essential for enterprise deployments.
