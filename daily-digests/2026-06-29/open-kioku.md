## Summary
Open Kioku is a local-first code intelligence tool that indexes repositories to provide AI coding agents with structured, evidence-backed context for code editing tasks. It enables agents like Claude, Cursor, and Codex to perform code search, impact analysis, and pre-edit planning without relying on hosted services or embeddings APIs.

## Key Features
- Local repository indexing with SQLite and Tantivy for fast search
- Evidence-backed pre-edit planning with impact analysis and validation targets
- Architecture policy enforcement for dependency and boundary checks
- Cross-project workspace linking for multi-repository contexts
- MCP server integration for seamless AI agent collaboration
