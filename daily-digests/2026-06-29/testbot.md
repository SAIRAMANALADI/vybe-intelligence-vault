## Summary
Skyramp Testbot is an AI-powered GitHub Action that automates test generation, maintenance, and execution for APIs and UIs. It analyzes PR diffs to detect impacted tests, generates new tests (API, E2E, UI), and delivers changes via side PRs or direct commits.

## Key Features
- Smart change detection for impacted tests via PR diff analysis
- Multi-type test generation (API, E2E, UI) with browser recording
- Automated test execution and validation with rich PR reports
- Support for multi-repo analysis and cross-repo test delivery
- Configurable agent selection (Claude, Cursor, Copilot) with BYO API keys

## Why It Matters for RAG Builders
It streamlines test maintenance in CI/CD pipelines by automating test generation and updates, reducing manual effort and improving software reliability for AI and RAG stack builders.
