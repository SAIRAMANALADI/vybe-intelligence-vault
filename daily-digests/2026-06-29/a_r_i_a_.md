## Summary
ARIA is a lean, modular, self-hosted AI assistant designed for individuals seeking control over their AI workflows. It combines a browser-first chat UI with structured memory, recipe-driven automation, LLM-assisted action planning, and secure modular connections to real systems.

## Key Features
- Structured memory with Qdrant for RAG and document recall
- Recipe-driven automation with JSON manifests and a browser-based wizard
- LLM-assisted action planning with bounded execution and guardrails
- Modular connections to systems like SSH, Discord, HTTP APIs, and MQTT
- OpenAI-compatible chat completions endpoint for integration flexibility

## Why It Matters for RAG Builders
ARIA provides a lightweight, extensible framework for building AI agents with memory and automation capabilities, ideal for RAG builders seeking modularity and self-hosted control.
