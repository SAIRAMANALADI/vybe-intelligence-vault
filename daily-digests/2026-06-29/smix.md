## Summary
smix is an AI-native iOS Simulator automation library and CLI written in Rust, designed to drive iOS apps through a typed API optimized for LLM authoring. It provides structured selectors, AI-readable failure messages, and integrates with MCP servers for direct AI tool integration.

## Key Features
- Structured selectors (text, id, role, label) with spatial and visibility resolution
- AI-readable failure messages with edit-distance suggestions and visible-element context
- Multi-language SDK support (Rust, Swift, Kotlin, TypeScript) with 1:1 Playwright-shaped API
- Performance-optimized primitives with hard benchmarks and regression gates
- MCP server integration for direct AI tool interaction (e.g., Claude Code)

## Why It Matters for RAG Builders
It enables AI agents to automate iOS Simulator testing with structured, AI-friendly APIs and failure messages, reducing manual intervention in RAG pipelines.
