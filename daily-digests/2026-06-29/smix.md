## Summary
smix is an AI-native iOS Simulator automation library and CLI written in Rust, designed for LLM-driven test authoring. It provides typed APIs, explicit selectors, AI-readable failure messages, and integrates with MCP servers for direct AI tooling integration like Claude Code.

## Key Features
- Typed Rust API for LLM-friendly test authoring with explicit selectors and AI-readable failure messages
- Cross-platform SDKs (Rust, Swift, TypeScript, Kotlin) with 1:1 Playwright-shaped ergonomics
- Structured selectors (text, id, role, etc.) with spatial and visibility resolution
- MCP server integration for direct AI tooling (e.g., Claude Code) with localhost-only runner port
- Performance-optimized primitives with hard benchmarks and regression gates (up to 46x speedup vs TypeScript)

## Why It Matters for RAG Builders
smix enables AI agents to write and execute iOS Simulator automation tests with minimal friction, reducing manual intervention in test authoring and debugging workflows.
