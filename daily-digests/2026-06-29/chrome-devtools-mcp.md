## Summary
Chrome DevTools for agents (`chrome-devtools-mcp`) is an MCP server that enables AI coding assistants to control and inspect a live Chrome browser, providing deep debugging, performance analysis, and automation capabilities through the Model-Context-Protocol (MCP).

## Key Features
- Full Chrome DevTools integration for AI agents, enabling deep inspection and debugging of browser sessions
- Performance tracing and actionable insights via Chrome DevTools Protocol and CrUX API integration
- Reliable automation using Puppeteer with automatic waiting for action results
- Network request analysis, screenshots, and console message inspection with source-mapped stack traces
- CLI and MCP server modes for flexible integration with popular AI coding assistants

## Why It Matters for RAG Builders
It provides AI agents with direct, programmatic access to Chrome's debugging and automation capabilities, essential for building reliable RAG systems that interact with or analyze web content.
