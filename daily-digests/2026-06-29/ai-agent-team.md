## Summary
AI Agent Team is a modular framework that deploys a 24/7 AI development team (product manager, frontend, backend, QA, DevOps, etc.) as specialized agents. It includes Thread Manager for persistent AI memory, semantic search, and Git-integrated task threads, enabling multi-task parallelization and context recovery.

## Key Features
- Thread Manager for persistent AI memory with semantic search and Git-integrated version control
- Modular agent skills (PM, FE, BE, QA, DevOps, etc.) installable via CLI
- Multi-task parallelization with isolated thread contexts for zero interference
- Built-in skills for changelog generation, soft copyright documentation, and desktop organization
- Offline-first architecture with embedded vector embeddings for semantic search

## Why It Matters for RAG Builders
AI Agent Team provides a scalable, modular framework for building and orchestrating specialized AI agents, essential for automating complex development workflows and maintaining persistent context in RAG systems.
