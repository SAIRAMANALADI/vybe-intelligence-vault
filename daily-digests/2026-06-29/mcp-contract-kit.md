## Summary
A conformance test suite for Model Context Protocol (MCP) servers, validating registry compliance, protocol adherence, and routing correctness. It provides a CLI tool, SDK, and reporting infrastructure to ensure MCP implementations meet the specification.

## Key Features
- Protocol conformance testing (JSON-RPC 2.0, tool discovery, execution)
- Registry validation with YAML schema checks and invariant testing
- Security posture validation (SSRF protection, authentication, input sanitization)
- Multiple report formats (console, JSON, Markdown, HTML)
- Programmatic API and MCP client SDK for CI/CD integration

## Why It Matters for RAG Builders
Ensures MCP server implementations adhere to the specification, critical for maintaining interoperability and reliability in RAG pipelines.
