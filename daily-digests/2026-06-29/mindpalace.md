## Summary
A self-learning, always-on personal AI agent that operates on a Claude Max subscription, combining terminal and Discord interfaces into a unified system. It autonomously learns from interactions, stores knowledge in a structured vault, and executes real-world tasks in the background while adapting to user-specific workflows.

## Key Features
- Dual-interface operation (terminal + Discord) with shared memory and knowledge vault
- Autonomous learning loop that converts procedures into reusable skills and stores facts in a structured vault
- Background job execution with live step streaming and async task handling
- Proactive heartbeat for periodic system reviews and reporting
- Scoped Discord bots with configurable permission fences (read-only, full, or custom tools)

## Why It Matters for RAG Builders
It provides a self-hosted, always-on AI agent framework that autonomously learns and adapts to user workflows, reducing manual configuration and enabling persistent, personalized assistance for RAG and AI stack builders.
