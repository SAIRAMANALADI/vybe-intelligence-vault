## Summary
A modular framework that transforms AI coding agents into self-learning knowledge engines by enabling structured personal knowledge base creation, maintenance, and evolution using local-first NLP and automatic context indexing.

## Key Features
- Modular Markdown instructions for AI agents to build and maintain knowledge bases
- Local-first NLP enrichment with CPU-based processing (no API tokens required)
- Provenance tracking and citation for every fact in the knowledge base
- Auto-update and maintenance via git hooks and smart scheduling
- Supports two modes: Lite (quick codebase indexing) and Full (comprehensive knowledge engine)

## Why It Matters for RAG Builders
It empowers AI agents to autonomously build and evolve structured knowledge bases, reducing manual context management overhead and enabling more accurate, traceable RAG systems.
