## Summary
MeMex-Zero-RAG is a production-ready personal knowledge base system that eliminates traditional RAG dependencies by compiling sources into a structured, interlinked wiki using markdown and git. It enforces zero hallucination through strict citation requirements and supports multi-agent collaboration via MCP servers and git worktrees.

## Key Features
- Compiles sources into a structured wiki without embeddings or vector databases
- Enforces zero hallucination with mandatory citations for every claim
- Supports multi-agent collaboration via MCP servers and git worktrees
- Provides CLI tools for ingestion, search, linting, and graph generation
- Human-in-the-loop conflict resolution with confidence tracking

## Why It Matters for RAG Builders
It redefines knowledge management for RAG builders by eliminating the need for embeddings and vector databases while ensuring accuracy through structured, citable wikis that compound over time.
