## Summary
mcp-server is a Windows-based Model Context Protocol (MCP) server designed to provide persistent memory and context management for AI workflows. It enables AI tools to store, search, and retrieve long-term memory while offering a dashboard for visualization and plugin sandboxing.

## Key Features
- Persistent memory storage for AI agents via MCP
- Semantic search for retrieving related context efficiently
- Dashboard for visualizing and managing stored data
- Plugin sandbox for testing and isolation
- Token-efficient design to reduce redundant context

## Why It Matters for RAG Builders
It provides a lightweight, local solution for AI agents to maintain long-term memory and context, reducing redundant prompts and improving workflow efficiency.
