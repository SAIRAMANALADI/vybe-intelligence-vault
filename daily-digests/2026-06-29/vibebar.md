## Summary
VibeBar is a floating Windows companion tool designed to enhance AI-assisted coding workflows by providing quick access to project context, prompts, security checks, and Cursor Agent integration. It docks to the screen edge and streamlines handoffs between developers and AI assistants.

## Key Features
- Floating toolbar with project context and prompts accessible via one click
- Cursor Agent MCP server for real-time session state sharing without copy-pasting
- Security audit with fix prompts and SARIF/Markdown export
- Project-aware prompt library with secret redaction and token estimation
- Session Hub for tracking prompts, diffs, and audit findings with structured handoffs

## Why It Matters for RAG Builders
VibeBar eliminates context-switching overhead for AI-assisted coding by centralizing project state, prompts, and security checks in a dockable toolbar, directly integrating with tools like Cursor Agent to streamline RAG workflows.
