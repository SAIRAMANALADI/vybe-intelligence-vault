## Summary
Hemiunu is an organization-wide AI Product Agent built on the Claude Agent SDK (TypeScript) that assists product teams by providing grounded answers, prototyping features, and maintaining persistent memory. It offers both CLI and web interfaces, integrates with MCP servers, and gamifies the development process through a 'world map' of landmarks collected with each feature release.

## Key Features
- Grounded answers from local files and MCP servers with permission prompts
- Wireframe to hi-fi prototype generation with React + Tailwind
- Persistent conversations and feature-specific memory stored in PROTOTYPE.md
- Plan-first mode for read-only research and approval-based execution
- Gamified development with a world map of landmarks collected per feature release

## Why It Matters for RAG Builders
Hemiunu streamlines the product development lifecycle by integrating AI-driven research, prototyping, and memory management into a single agent framework, making it essential for teams building AI-powered applications.
