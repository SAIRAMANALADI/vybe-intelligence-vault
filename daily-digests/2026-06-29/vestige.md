## Summary
Vestige is a local-first memory system for AI agents that uses neuroscience-inspired mechanisms to track and reason about decisions, enabling backward causal reach to identify root causes of failures. It operates as a single Rust binary with no cloud dependency, integrating via MCP for real-time agent memory.

## Key Features
- Retroactive Salience Backfill for backward causal reach to root causes of failures
- Prediction-Error Gating to store only novel or surprising information
- FSRS-6 Spaced Repetition for adaptive forgetting and memory decay
- 3D interactive dashboard for real-time memory visualization
- Self-healing duplicate detection and suppression of irrelevant memories

## Why It Matters for RAG Builders
Vestige enables AI agents to remember decisions and their causal relationships, not just surface similar text, making it essential for debugging and long-term agent reliability.
