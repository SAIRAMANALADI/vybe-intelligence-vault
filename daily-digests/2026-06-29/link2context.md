## Summary
Link2Context is an open-source, local-first toolkit that transforms links (articles, social media posts, videos, etc.) into structured, agent-ready context for AI systems. It extracts and standardizes content from platforms like WeChat and Xiaohongshu into JSON/Markdown outputs suitable for knowledge graphs and AI agents.

## Key Features
- Extracts and standardizes content from WeChat and Xiaohongshu links into structured context (JSON/Markdown)
- Supports batch processing and local SQLite storage for knowledge graph integration
- Provides CLI and Python library for local deployment and customization
- Includes media processing (OCR/ASR) via external command adapters
- Offers verification, querying, and graph export capabilities for AI agent pipelines

## Why It Matters for RAG Builders
Link2Context streamlines the conversion of raw links into structured, agent-ready context, enabling RAG systems to ingest and reason over diverse content sources efficiently.
