## Summary
PyWry is a cross-platform Python UI toolkit that enables building interactive desktop, Jupyter, and web applications using a single API. It leverages OS-native webviews (via PyTauri) for desktop apps, FastAPI for web deployment, and integrates with Jupyter via anywidget for seamless notebook experiences.

## Key Features
- Single API for desktop, web, and Jupyter rendering with no code changes
- Native OS webview integration (no Electron/Qt dependencies) via PyTauri
- Pluggable chat widget with support for multiple LLM providers (OpenAI, Anthropic, Magentic, etc.)
- Advanced charting with TradingView Lightweight Charts integration and Plotly support
- Standalone executable generation via PyInstaller with zero configuration

## Why It Matters for RAG Builders
PyWry simplifies the creation of interactive AI-powered UIs by unifying desktop, web, and notebook experiences under one API, making it ideal for RAG builders who need flexible deployment options without sacrificing performance or security.
