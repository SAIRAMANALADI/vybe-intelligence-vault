## Summary
DevBrain is a persistent memory layer for software development that decouples memory (state) from compute (LLM/IDE) by continuously recording file modifications, extracting diffs, and indexing them into a local knowledge graph. It enables AI assistants to retain context across sessions and projects.

## Key Features
- Continuous file modification tracking via background harvester
- Integration with Cognee's local knowledge graph (SQLite + LanceDB + Kuzu)
- CLI and dashboard for monitoring and managing memory state
- Supports multiple AI assistants (Antigravity, Cursor, Claude Code, Copilot Chat)
- Automated context manifest generation for LLM prompts

## Why It Matters for RAG Builders
DevBrain solves the critical problem of AI assistants losing context between sessions by providing a persistent, local-first memory layer that retains and retrieves codebase context for RAG systems.
