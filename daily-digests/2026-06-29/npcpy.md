## Summary
npcpy is a Python library designed for research and development with multimodal language models, agentic AI, and knowledge graphs. It provides primitives for building multi-agent systems, managing contexts, and integrating with local or cloud-based LLM providers.

## Key Features
- Supports local and cloud-based LLM providers for flexible model deployment
- Provides a Context-Agent-Tool data layer for structured agent interactions
- Includes built-in tools for file operations, web search, and code execution
- Enables multi-agent debates and iterative refinement through NPCArray
- Integrates knowledge graph operations for persistent memory and context
