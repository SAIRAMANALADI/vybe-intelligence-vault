## Summary
InkOS is an AI agent system designed for story creation, including novels, scripts, interactive games, and IP content. It supports multiple interaction modes (Studio, TUI, CLI) and features advanced memory management, multi-model routing, and a Play mode for open-world storytelling with persistent state.

## Key Features
- Studio, TUI, and CLI interaction modes for seamless user experience
- InkOS Play for open-world and branching interactive storytelling with persistent state
- Multi-dimensional auditing and anti-AI-detection mechanisms for polished output
- Style analysis and import for consistent narrative voice across chapters
- Configurable LLM routing and deployment flexibility (local, cloud, or hybrid)
