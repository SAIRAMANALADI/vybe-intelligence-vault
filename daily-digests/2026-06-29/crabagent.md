## Summary
CrabAgent is a local-first AI knowledge work platform that seamlessly blends chat and work modes, enabling users to interact with AI for both conversational tasks and real-time document/code editing. It supports multi-modal interactions, project memory, and integrates with external tools like WeChat and ChatGPT subscriptions.

## Key Features
- Dual-mode interface (Chat Mode for conversation, Work Mode for real-time editing and document/code preview)
- Project memory and self-evolving agents that adapt to user preferences and project context
- Integration with ChatGPT subscriptions for direct model access without API keys
- WeChat channel support for mobile interactions and notifications
- Built-in tools for browser automation, scheduled tasks, and snapshot management
