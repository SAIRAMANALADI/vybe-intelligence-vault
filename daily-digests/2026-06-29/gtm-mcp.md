## Summary
gtm-mcp is a self-hosted outreach pipeline for Claude Code that automates B2B cold outreach workflows. It integrates with Apollo for lead discovery, uses Claude for AI-driven classification and personalization, and sends sequences to SmartLead for campaign execution.

## Key Features
- Automated lead discovery via Apollo API
- AI-driven company classification and contact enrichment
- Personalized outreach sequence generation using Claude
- Seamless integration with SmartLead for campaign deployment
- Self-hosted workflow with no LLM calls from the server

## Why It Matters for RAG Builders
