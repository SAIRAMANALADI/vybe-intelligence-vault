## Summary
Yuse is an AI-native CV builder that maintains a dynamic career knowledge base (Digital Twin) to generate, tailor, and export resumes. It leverages conversational AI, structured career storytelling (STAR/PAR), and integrations with GitHub, LinkedIn, and web portfolios to create personalized resumes and cover letters.

## Key Features
- Conversational AI assistant for resume creation and tailoring using OpenAI function calling and MCP registry
- Digital Twin career knowledge base with structured STAR/PAR storytelling for experiences and projects
- Multi-source imports (GitHub, LinkedIn, web portfolios) with OAuth support
- Live preview, reusable section library, themes, and PDF/print export
- Job tracker for applications, tailored CVs, and cover letters with application status management

## Why It Matters for RAG Builders
Yuse provides a structured, AI-driven approach to resume building that ensures accuracy and personalization, reducing manual effort for job seekers while maintaining a dynamic career knowledge base.
