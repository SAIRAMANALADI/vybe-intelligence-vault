## Summary
Safari MCP provides 96 native browser automation tools for AI agents on macOS, enabling direct interaction with the real Safari browser (including logins and sessions) via AppleScript. It eliminates the need for headless browsers like Chrome or Puppeteer, reducing CPU usage by ~60% and improving reliability for automation tasks.

## Key Features
- 96 native automation tools for Safari (navigation, clicks, forms, screenshots, network, storage, accessibility)
- Direct interaction with the real Safari browser, preserving logins, cookies, and sessions (e.g., Gmail, GitHub)
- ~60% less CPU usage than Chrome-based solutions, runs silently in the background
- Element targeting via CSS selectors, visible text, coordinates, or accessibility tree refs for precision
- Framework-compatible (React, Vue, Angular) with tools like `safari_fill` and `safari_react_select_set`

## Why It Matters for RAG Builders
It enables AI agents to interact with real-world websites (including authenticated sessions) without the overhead or detection risks of headless browsers, making it essential for reliable RAG and agent workflows.
