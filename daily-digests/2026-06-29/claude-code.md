## Summary
Claude Code is a terminal-based agentic coding assistant for Windows that enables developers to interact with their codebase using plain language commands. It automates routine tasks, explains code, handles git workflows, and executes small coding jobs directly in the terminal.

## Key Features
- Interactive terminal-based coding assistant with plain language input
- Automates routine coding tasks (e.g., renaming functions, adding comments)
- Integrates with git for version control and commit assistance
- Explains code, errors, and complex logic in clear language
- Designed for Windows with simple setup and execution
