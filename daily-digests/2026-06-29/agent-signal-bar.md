## Summary
Agent Signal Bar is a local-first macOS application that provides visual and auditory feedback for AI agent states via menu bar and floating desktop signal lights. It monitors local AI agents like Codex and Claude Code, displaying their status (idle, thinking, working, blocked, etc.) without requiring cloud services.

## Key Features
- Real-time AI agent state visualization via menu bar and floating desktop signal lights
- Customizable visual and auditory alerts for agent states (idle, thinking, blocked, etc.)
- Local monitoring of Codex and Claude Code agents without cloud dependencies
- Multi-session aggregation with priority-based state display (e.g., blocked > working)
- CLI for script integration and custom agent state updates

## Why It Matters for RAG Builders
It provides immediate, at-a-glance feedback for AI agent states, improving developer productivity and debugging efficiency in local AI workflows.
