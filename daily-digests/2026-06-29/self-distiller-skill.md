## Summary
self-distiller-skill is a Windows application that transforms self-talk into an AI persona for self-reflection, emotion tracking, and cognitive defusion. It supports both text and voice modes, enabling users to interact with their own thoughts in a structured, distanced manner.

## Key Features
- Dual-mode interaction (text and voice) for self-reflection
- Voice cloning to personalize AI responses with the user's own voice
- Structured sessions for daily mirror practice and thought journaling
- Integration with OpenClaw for persona-based chat analysis
- Simple setup and use on Windows with minimal dependencies
