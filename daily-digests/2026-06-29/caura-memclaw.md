## Summary
MemClaw provides governed, shared memory infrastructure for multi-agent AI fleets, enabling agents to store, retrieve, and compound knowledge across interactions. It transforms plain text inputs into structured, searchable, and self-improving memory with governance and trust tiers.

## Key Features
- Multi-tenant and multi-agent memory storage with scoped access control
- Cross-agent knowledge propagation and compounding for continuous learning
- Governance via trust tiers, keystone policies, and audit trails
- Semantic search with LLM-inferred metadata (type, title, summary, tags, weight)
- MCP-native integration for seamless AI agent connectivity

## Why It Matters for RAG Builders
MemClaw enables RAG systems to scale beyond single-agent use cases by providing a governed, shared memory layer that compounds knowledge across an entire fleet of agents, reducing redundancy and improving retrieval efficiency.
