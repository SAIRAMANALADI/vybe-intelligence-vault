## Summary
A locally run Markdown editor for creating ATS-compliant resumes with real-time HTML/CSS rendering and PDF generation. It combines a lightweight frontend with automated workflows for AI-assisted resume personalization and telemetry tracking.

## Key Features
- Locally hosted Markdown editor with real-time HTML/CSS rendering
- ATS-compliant resume generation with customizable layouts
- Automated PDF generation via Gotenberg headless Chrome
- AI-assisted resume personalization using Notion and LLM agents
- Telemetry and feedback pipelines for usage analytics

## Why It Matters for RAG Builders
It provides a lightweight, self-hosted solution for generating ATS-compliant resumes with AI-assisted personalization and PDF rendering, reducing dependency on third-party services.
