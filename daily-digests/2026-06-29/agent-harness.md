## Summary
agent-harness is a Windows desktop tool designed to build, run, and test coding agent workflows locally. It enables users to execute agent tasks, analyze tool calls, and connect to AI services like OpenRouter or Anthropic for learning and experimentation.

- Supports OpenRouter and Anthropic AI services
