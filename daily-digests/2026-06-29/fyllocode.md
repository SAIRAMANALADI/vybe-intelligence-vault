## Summary
FylloCode provides a governance layer for coding agents, enabling teams to enforce consistent rules, maintain traceability, and preserve decision-making context across sessions and agents. It bridges the gap between agent-driven code changes and structured project governance.

## Key Features
- Unified project specifications enforced across all agents and sessions via `fyllo-specs` MCP server
- Structured decision documentation (proposals, design rationale, and lineage) preserved for future reference
- Automated guidelines evolution through `fyllo-cortex` to keep agents aligned with latest project constraints
- Integration with existing dev tools (GitHub, Jira, etc.) to avoid toolchain silos
- Real-time governance during code execution with task boundary enforcement and change tracking

## Why It Matters for RAG Builders
FylloCode ensures AI-driven development maintains traceability, consistency, and team knowledge continuity, which is critical for scalable and auditable RAG systems.
