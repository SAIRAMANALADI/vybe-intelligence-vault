## Summary
Gortex is a high-performance code-intelligence engine that indexes code into a graph structure and exposes it via CLI, MCP Server, and web UI. It supports multi-repository analysis with compiler-grade resolution for 257 languages, enabling AI agents to query only relevant code snippets and reduce token usage by up to 50x.

## Key Features
- Indexes 257 languages with compiler-grade resolution for accurate cross-referencing
- Supports 17 AI coding agents out of the box with zero configuration
- Reduces token usage by up to 50x via graph-native lookups and semantic search
- Provides cross-repo API contract detection and impact analysis for large codebases
- Offers MCP tools, HTTP API, and a force-directed graph visualization UI
