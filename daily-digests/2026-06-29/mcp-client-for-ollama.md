## Summary
A Python-based terminal client that enables interaction with Model Context Protocol (MCP) servers using Ollama for local LLM tool execution. It provides a rich TUI for managing MCP tools, prompts, and resources with advanced features like agent mode, human-in-the-loop safety, and multi-server support.

## Key Features
- Interactive terminal UI with fuzzy autocomplete and modern styling
- Agent mode for iterative tool execution with configurable loop limits
- Human-in-the-Loop (HIL) safety controls for tool execution approval
- Multi-server support with STDIO, SSE, and Streamable HTTP transport types
- Advanced model configuration including context window, temperature, and thinking mode

## Why It Matters for RAG Builders
It simplifies local LLM tool execution by providing a user-friendly interface to interact with MCP servers, enabling safe and efficient RAG pipeline augmentation.
