## Summary
comfyui-workflow-skill converts plain English prompts into ready-to-use ComfyUI workflow JSON files, enabling rapid generation of image, video, audio, 3D, and LLM workflows without manual node assembly.

## Key Features
- Converts plain English prompts into ComfyUI workflow JSON automatically
- Includes 34 built-in templates and 360+ node definitions for diverse tasks
- Supports auto model downloading for seamless setup
- Compatible with multiple model families (SD1.5, SDXL, FLUX, etc.)
- Functions as a skill for AI coding tools like Claude Code and Cursor
