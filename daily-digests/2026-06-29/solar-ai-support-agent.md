## Summary
A Solar AI Support Agent is an AI-powered system designed for initial customer support, lead qualification, and solar pre-analysis for solar energy companies. It handles natural language conversations, geospatial analysis, and integrates with external tools like Chatwoot for seamless lead management.

## Key Features
- Natural language chat for lead qualification and initial support
- Geocoding and solar potential analysis using OpenStreetMap and Overpass API
- Multi-LLM support (OpenAI, Anthropic) with cost tracking and hybrid mode for efficiency
- Admin dashboard for customizing agent instructions and managing knowledge base (RAG)
- Embeddable chat widget for external websites with seamless integration
