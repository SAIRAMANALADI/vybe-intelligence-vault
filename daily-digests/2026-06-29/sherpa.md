## Summary
Sherpa is a natural-language DeFi agent for Base that enables users to execute DeFi operations by typing plain English commands. It parses intents, performs safety checks, and routes transactions through verified Base mainnet contracts.

## Key Features
- Natural language intent parsing for DeFi operations (e.g., 'supply 100 USDC to Aave')
- 7-ring preflight safety pipeline with deterministic checks before transaction execution
- Multi-chain portfolio visibility (Base, Ethereum, Polygon, Optimism, Arbitrum) with read-only support
- Verified Base mainnet contracts with independent security reviews and 0 critical findings
- Automation features like DCA scheduling, auto-repay, and alerts with session-key gated unattended signing

## Why It Matters for RAG Builders
Sherpa provides a secure, audited framework for building natural-language DeFi agents on Base, reducing the complexity of intent parsing and safety checks for RAG/AI stack builders.
