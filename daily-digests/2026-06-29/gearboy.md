## Summary
Gearboy is a cross-platform emulator for Game Boy, Game Boy Color, and Super Game Boy, written in C++. It features an embedded Model Context Protocol (MCP) server for AI-assisted debugging and tooling, enabling integration with AI agents like GitHub Copilot and Claude.

## Key Features
- Accurate cross-platform Game Boy/Color/Super Game Boy emulation
- Embedded MCP server for AI-assisted debugging and tooling
- Full debugger with disassembler, breakpoints, and memory inspection
- Battery-powered RAM save support and save states
- Support for modern game controllers and programmable shaders
