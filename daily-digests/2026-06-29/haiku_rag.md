## Summary
Haiku RAG is an agentic Retrieval-Augmented Generation (RAG) framework built on LanceDB, Pydantic AI, and Docling. It enables multimodal and cross-modal search, vision-capable QA, and complex analytical tasks with citations and session memory.

## Key Features
- Hybrid search (vector + full-text) with Reciprocal Rank Fusion
- Multimodal and cross-modal search with vision-capable QA models
- Complex analytical tasks via sandboxed Python code execution
- Conversational RAG with chat TUI and web application
- Production-grade ingester with async workers, retries, and multiple source adapters

## Why It Matters for RAG Builders
Haiku RAG provides a comprehensive, production-ready framework for building advanced RAG systems with multimodal capabilities and agentic workflows, essential for AI engineers seeking robust document processing and retrieval solutions.
