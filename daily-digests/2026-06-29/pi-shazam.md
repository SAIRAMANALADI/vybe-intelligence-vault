## Summary
pi-shazam is a codebase awareness toolkit for AI coding agents, providing 7 structural analysis tools powered by tree-sitter and LSP to deeply understand any project. It offers native integration with the Pi coding agent and MCP server compatibility for other AI agents.

## Key Features
- 7 structural analysis tools (overview, lookup, impact, verify, changes, format, rename)
- Native extension for Pi coding agent and MCP server support for other agents
- Blast radius analysis for impact assessment before edits
- Post-edit verification with LSP diagnostics and auto-fix formatting
- Cross-file symbol rename with atomic writes
