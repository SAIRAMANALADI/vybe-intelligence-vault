## Summary
apifable is an MCP server designed to help AI agents integrate APIs more smoothly into TypeScript frontend projects by providing API exploration, search, and TypeScript type generation capabilities based on OpenAPI specs.

## Key Features
- AI-ready API context generation for accurate AI agent integration
- OpenAPI 3.0/3.1 spec support with remote/local file handling
- MCP server integration for AI agents like Claude, Cursor, and Windsurf
- Advanced API exploration with keyword search, endpoint filtering, and pagination
- Automatic TypeScript type generation for frontend code
