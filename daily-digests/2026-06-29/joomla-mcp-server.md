## Summary
A Joomla component that exposes a Model Context Protocol (MCP) server over HTTP JSON-RPC, enabling MCP clients like Claude Desktop or Cursor to interact with Joomla content via the site's Web Services API. It provides 49 tools for managing articles, modules, media, languages, templates, and more.

## Key Features
- 49 MCP tools for Joomla content and configuration management
- HTTP JSON-RPC 2.0 endpoint with Bearer token authentication
- Response caching, rate limiting, and JSON Schema validation
- Supports Joomla 4, 5, and 6 with PHP 8.1+
- Health endpoint and configurable security settings

## Why It Matters for RAG Builders
It enables AI agents to directly interact with Joomla content and configurations, streamlining automation and integration for RAG systems managing Joomla-based knowledge bases.
