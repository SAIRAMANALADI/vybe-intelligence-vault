## Summary
Ursus is a local MCP server, CLI tool, and utility for Bear that enables AI applications to interact with Bear notes seamlessly. It provides structured note discovery, safe editing, backups, and automation capabilities for inbox-first workflows.

## Key Features
- Local MCP server for AI app integration with Bear notes
- Structured note discovery with advanced filtering (tags, dates, OCR content)
- Safe note editing with automatic backups and conflict resolution
- CLI and HTTP bridge for automation and remote access
- Template-aware operations to preserve note structure

## Why It Matters for RAG Builders
Ursus bridges Bear with AI workflows by providing a stable, local MCP interface for seamless note discovery, editing, and automation, reducing integration complexity for RAG builders.
