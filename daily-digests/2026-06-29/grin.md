## Summary
GRIN is an autonomous red-team orchestrator designed to autonomously execute penetration testing workflows, including foothold discovery, privilege escalation, lateral movement, and proof capture. It combines AI-driven planning with deterministic exploit closers and a fail-closed authorization spine to ensure controlled, evidence-backed security testing.

## Key Features
- Autonomous engagement planning and execution with multi-agent core (Orchestrator, Executor, Analyst, Medic, Reporter)
- Deterministic exploit closers (credential sweeps, command injection, privilege escalation, lateral movement) bypassing AI uncertainty
- Fail-closed authorization spine enforcing scope, exclusions, and action classes with append-only audit logs
- Self-provisioning Kali + BlackArch containers for tooling, supporting local and remote environments
- Persistent cross-engagement memory (Grin Brain) for learning and playbook reinforcement

## Why It Matters for RAG Builders
GRIN provides a robust framework for automating complex red-team operations while ensuring strict control and evidence collection, making it essential for security teams building AI-driven penetration testing workflows.
