## Summary
xbot is a self-hosted, multi-channel AI agent framework that enables teams to deploy a single AI agent accessible via Feishu, QQ, terminal, or web interfaces. It supports tool execution, sub-agents, and MCP integration while ensuring data privacy by keeping all operations on-premise.

## Key Features
- Multi-channel support (Feishu, QQ, Web, CLI) for seamless team collaboration
- Built-in tools for shell execution, file I/O, web search, scheduling, and Feishu-specific integrations
- Sub-agent and group chat capabilities for parallel task execution and moderated discussions
- Extensible plugin system with skills, MCP servers, and custom tools
- TUI with command palette, themes, and session management for enhanced user experience

## Why It Matters for RAG Builders
xbot enables teams to deploy a unified, self-hosted AI agent across multiple communication channels while maintaining data privacy and leveraging advanced tool execution and multi-agent collaboration.
