## Summary
Talon is a multi-platform agentic AI harness that enables unified AI agent interactions across Telegram, Discord, Microsoft Teams, Terminal, and a cross-platform Flutter-based desktop/mobile companion app. It supports pluggable backends like Claude, Kilo, OpenCode, Codex, and OpenAI Agents, with full MCP tool access and persistent background agents.

## Key Features
- Unified AI agent interactions across multiple platforms (Telegram, Discord, Teams, Terminal, Desktop/Mobile app)
- Pluggable backend support for Claude, Kilo, OpenCode, Codex, and OpenAI Agents with streaming and model fallback
- Full MCP tool access including messaging, media, file system, web fetch, cron jobs, and triggers
- Persistent background agents (Heartbeat, Dream, Goals) for proactive task execution and memory consolidation
- Hot-reloadable plugin system with built-in GitHub, MemPalace, Playwright, and Brave Search integrations
