## Summary
Agentic AI Assistant is an autonomous AI agent that uses multi-step reasoning and tool calling to execute tasks autonomously. It leverages OpenAI's API to plan, select tools, observe outputs, and complete user requests without manual intervention.

## Key Features
- PLAN → TOOL → OBSERVE → OUTPUT workflow for autonomous task execution
- Built-in tools for file system operations (create, read, update, list)
- Real-time weather lookup integration
- Conversation memory for session continuity
- Structured JSON-based responses for interoperability
