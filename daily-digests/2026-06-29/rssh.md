## Summary
RSSH is an AI-powered SSH client designed to act as an operations copilot, enabling users to ask natural language questions about their remote systems and receive AI-generated command proposals with side-effect warnings. All sensitive data is redacted locally before execution, ensuring privacy.

## Key Features
- AI-driven command proposals with side-effect annotations and approval gates
- Cross-platform support (Desktop, Mobile, JetBrains IDEs) with shared SQLite data store
- Local redaction of sensitive data before execution or transmission
- Color-coded terminal blocks for easy output navigation and session recording
- Port forwarding, SFTP, and session management with platform keychain integration

## Why It Matters for RAG Builders
RSSH bridges the gap between natural language queries and secure, controlled remote system management, making it essential for AI-driven operations workflows.
