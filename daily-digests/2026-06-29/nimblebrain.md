## Summary
NimbleBrain is a self-hosted platform for MCP (Model Context Protocol) apps and agent automations, providing an interactive UI, live agent-UI data sync, and multi-agent delegation capabilities. It aggregates tools from connected MCP servers into a unified namespace and supports scheduled runs via cron.

## Key Features
- Unified tool registry aggregating tools from multiple MCP servers into a single namespace
- Interactive UI with live agent-UI data sync and scheduled agent runs
- Multi-agent delegation with skill-driven prompt composition
- Streamable HTTP MCP server endpoint for external MCP client consumption
- Workspace isolation with per-workspace configuration and bundle management

## Why It Matters for RAG Builders
NimbleBrain simplifies the orchestration of MCP-based tools and agents, enabling seamless integration and management of multi-agent systems for RAG pipelines.
