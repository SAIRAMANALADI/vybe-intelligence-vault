## Summary
mini-agent is a perception-driven AI agent framework that continuously observes the environment through shell scripts and shell-based plugins before deciding to act. It uses Markdown files for memory and skills, avoiding traditional databases or vector embeddings, and relies on Claude CLI for decision-making.

## Key Features
- Perception-first architecture with OODA loop (Observe, Orient, Decide, Act)
- File-based memory using Markdown and JSON Lines (human-readable, git-versionable)
- Plugin system where any executable becomes a sense (e.g., Docker health, workspace changes, Telegram inbox)
- Multi-lane parallelism inspired by slime mold for efficient task execution
- Identity and growth via SOUL.md for defining personality and evolving worldview

## Why It Matters for RAG Builders
It offers a transparent, plugin-driven approach to AI agents that prioritizes real-time environmental perception over rigid goal-setting, making it ideal for adaptive, context-aware automation.
