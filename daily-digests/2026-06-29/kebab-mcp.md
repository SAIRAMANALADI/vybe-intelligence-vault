## Summary
Kebab MCP is a self-hosted Model Context Protocol (MCP) server framework that provides a unified endpoint for 97+ pre-built tools across 17 connectors, enabling AI clients like Claude, Cursor, and ChatGPT to interact with multiple services via a single deployment. It emphasizes ease of setup, privacy, and extensibility with custom tools and skills.

## Key Features
- Single endpoint for 97+ tools across 17 connectors (Google Workspace, Slack, Notion, GitHub, etc.)
- Unified dashboard for managing connectors, tools, skills, and logs
- Custom tools via HTTP API integration (OpenAPI specs or REST endpoints)
- Skills composer for creating prompt-powered workflows without code
- Self-hosted with Vercel free tier, Upstash KV for auth and state management

## Why It Matters for RAG Builders
It simplifies the integration of multiple AI tools and services into a single, self-hosted MCP endpoint, reducing complexity and vendor lock-in for RAG builders.
