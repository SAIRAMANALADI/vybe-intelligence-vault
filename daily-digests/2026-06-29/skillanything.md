## Summary
SkillAnything converts existing software into AI-executable skills by recording user interactions and generating bridge files for AI agents like Claude Code or OpenClaw. It enables AI agents to automate tasks in third-party applications without requiring custom code.

## Key Features
- Records user interactions to create AI-executable skills
- Exports skills for integration with Claude Code, OpenClaw, and other agents
- Supports meta-skills for combining multiple automated tasks
- Operates entirely locally with no external data transmission
- Provides troubleshooting and optimization tips for reliable skill creation
