## Summary
Memora MCP is an interactive flashcard application built as an MCP App for Claude Desktop, enabling users to generate, review, and grade flashcards with spaced repetition directly within conversations. It leverages the Model Context Protocol (MCP) to render inline flip-card UIs and persist card data in JSON files.

## Key Features
- Inline flip-card UI for reviewing and grading flashcards with spaced repetition scheduling
- Claude-generated flashcard decks from conversation or user requests, persisted as JSON
- Deck picker for seamless switching between multiple decks
- SM-2-style spaced repetition algorithm for adaptive review scheduling
- Real-time JSON-based deck storage with live updates, no external database required

## Why It Matters for RAG Builders
Memora MCP streamlines the creation and review of flashcards within AI conversations, enhancing knowledge retention and enabling adaptive learning workflows for RAG builders.
