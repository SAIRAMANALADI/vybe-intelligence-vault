## Summary
MCP-Scorecard is a Windows-based tool that evaluates MCP servers for security and trustworthiness by generating a risk score based on surface-level vulnerabilities, configuration issues, and exposure risks. It provides a repeatable, CI-friendly way to assess servers before deployment.

## Key Features
- Generates a risk score for MCP servers based on predefined security checks
- Provides a clear report of findings and high-risk items
- Supports CI/CD integration for automated security gates
- Designed for non-technical users with a simple Windows GUI
- Enables repeatable and consistent server evaluations
