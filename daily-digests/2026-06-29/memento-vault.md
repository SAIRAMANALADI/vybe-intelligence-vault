## Summary
Memento Vault is a persistent knowledge capture system for coding agents that automatically triages, scores, and organizes session transcripts into searchable Zettelkasten notes with epistemic metadata. It supports local and remote deployments, integrates with Claude Code, pi, and MCP-compatible agents, and provides tools for retrieval, consolidation, and knowledge injection.

## Key Features
- Automated session triage and note curation with YAML frontmatter and epistemic metadata
- Native integration with Claude Code, pi, and MCP-compatible agents via hooks or server
- Local and remote vault deployment with sync capabilities across devices
- Background consolidation and retrieval tools (Tenet, Inception) for pattern synthesis
- BM25, semantic, and RRF fusion search with temporal decay and PageRank boost
