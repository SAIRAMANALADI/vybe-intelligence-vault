## Summary
A personal configuration harness for opencode, an AI coding agent, featuring GLM-5.2 via the ZAI gateway, profile-driven MCP management, and Spec-Driven Development (SDD) workflows. Designed for daily use with modular, adaptable setups and adversarial review processes.

## Key Features
- Profile-driven MCP configuration to optimize performance and avoid timeouts
- Spec-Driven Development (SDD) workflow with adversarial review processes
- Modular setup with sanitized templates and private configuration isolation
- Integration with Gentle AI for orchestration and persistent memory (enGram)
- Comprehensive command set for SDD, planning, and goal tracking
