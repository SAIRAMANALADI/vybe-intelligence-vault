## Summary
avatar-pipeline is a desktop application that converts plain English text commands into 3D WebGL animations using local AI processing. It provides a simple interface for generating repeatable 3D motion sequences without requiring a full developer stack.

## Key Features
- Converts text commands into structured 3D motion sequences
- Local AI processing for repeatable and stable results
- Simple Windows desktop setup with no complex developer environment
- Supports Groq API and Llama-3.3 for language handling
- Real-time WebGL preview with Three.js and React Three Fiber

## Why It Matters for RAG Builders
It enables rapid prototyping of AI-driven 3D animations from natural language, simplifying the creation of interactive visual content for AI applications.
