## Summary
Unterm is a cross-platform terminal emulator designed to be controllable by external AI agents via MCP (Model Context Protocol). It provides a JSON-RPC interface for spawning shells, running commands, capturing screenshots, and managing sessions, while keeping AI features external to the terminal itself.

## Key Features
- MCP-controllable terminal via JSON-RPC over TCP with auth-token gating
- Cross-platform support (macOS, Linux, Windows) with GPU-accelerated rendering
- Multi-instance discovery with NATO-phonetic naming and instance metadata storage
- Web-based settings UI and identity profiles for managing developer credentials
- Advanced session recording, screenshots, and proxy auto-detection

## Why It Matters for RAG Builders
Unterm enables AI agents to programmatically control terminal sessions, making it essential for automating workflows, debugging, and integrating terminals into AI-driven development environments.
