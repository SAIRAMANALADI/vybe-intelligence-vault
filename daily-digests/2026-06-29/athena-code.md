## Summary
Athena Code is an open-source terminal AI coding agent that extends OpenCode with persistent local memory, automatic context recall, and cross-session searchable history. It enables durable knowledge retention, frozen session snapshots, and multi-agent orchestration for local coding workflows.

## Key Features
- Persistent AI memory with global and project-scoped storage
- Automatic contextual recall for relevant past sessions
- Frozen session snapshots for deterministic agent context
- Cross-agent session search with SQLite FTS5 indexing
- Native agent tools for memory management and multi-agent workflows

## Why It Matters for RAG Builders
Athena Code enables AI agents to retain durable, searchable context across sessions, reducing redundant instructions and improving continuity in coding workflows.
