## Summary
SoloMD is a local-first markdown editor with a built-in agent surface and MCP endpoint, enabling seamless integration with AI tools like Claude Code and Cursor. It combines a WYSIWYG markdown editor with a knowledge-graph layer, scheduled agent recipes, and a bundled MCP server for direct LLM access to your notes.

## Key Features
- Built-in agent panel for streaming chat-with-vault interactions and inline tool calls
- Bundled MCP server exposing 13 tools (including 5 SoloMD-specific) for direct LLM access to notes
- Knowledge-graph layer with typed relationships, properties inspector, and relationship graph
- Scheduled agent recipes with AutoGit branch sandboxing and replayable traces
- Multi-vault federation via MCP workspace support and 14 AI provider integrations

## Why It Matters for RAG Builders
SoloMD bridges markdown editing with AI agent workflows, enabling RAG builders to create agent-driven note-taking systems with built-in MCP integration and local-first data control.
