## Summary
aex is an agent execution platform that enables the deployment and management of autonomous agents through a TypeScript SDK and CLI. It provides a managed runtime for agent operations with robust tooling and infrastructure support.

## Key Features
- Managed autonomous agent runtime with filesystem, web, and editing tools
- Durable infrastructure with run records, status tracking, and output capture
- Agent composition via skills, files, and remote MCP servers
- Subagent support for typed parent/child lineage and delegation
- Multi-provider model support (Anthropic, OpenAI, DeepSeek, etc.)
