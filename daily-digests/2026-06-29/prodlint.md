## Summary
prodlint is a static analysis tool designed to assess the production readiness of AI-generated or 'vibe-coded' applications. It flags security, reliability, performance, and AI quality issues such as hardcoded secrets, hallucinated imports, missing authentication, and unvalidated server actions with zero configuration and 52 built-in rules.

## Key Features
- 52 built-in rules across security, reliability, performance, and AI quality
- Zero-config operation with support for customization via CLI flags
- Smart detection with AST parsing, framework awareness, and false positive reduction
- Integration with GitHub Actions, SARIF, and MCP for CI/CD and AI tooling
- Scoring system with weighted categories and actionable fix suggestions
