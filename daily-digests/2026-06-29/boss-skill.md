## Summary
boss-skill is a Windows desktop application designed to help users navigate workplace pressures by providing tools for analyzing boss communications, drafting replies, tracking evidence, and looking up labor laws. It offers a lightweight, no-code solution for managing common work-related challenges.

## Key Features
- PUA (Pressure/Abuse) style analysis for boss messages
- Three-tiered reply drafting (soft, firm, hard stop)
- Evidence collection and storage for chats/notes
- Labor law quick lookup in plain language
- Interactive text-based practice game for negotiation scenarios

## Why It Matters for RAG Builders
It provides practical, non-technical tools for workers to analyze and respond to workplace pressures, reducing ambiguity in communication and improving preparedness for difficult conversations.
