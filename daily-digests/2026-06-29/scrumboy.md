## Summary
Scrumboy is a self-hosted project management and issue-tracking solution that combines lightweight Kanban simplicity with structured workflows, real-time collaboration, and MCP-compatible AI agent support. It offers customizable boards, automation via webhooks, and multi-language support.

## Key Features
- MCP-compatible JSON-RPC endpoint for AI agents and MCP clients
- Real-time collaboration with WebSocket-enabled boards
- Customizable workflows, tags, and sprints per project
- Multi-language support (23 languages) and PWA for mobile UX
- Webhook integrations for outbound HTTP automation
