## Summary
A self-hostable MCP server that indexes and serves Rapid7's documentation, product information, blog posts, and resources via Streamable HTTP or SSE endpoints. It enables AI clients to query Rapid7's public knowledge base programmatically.

## Key Features
- Indexes ~2,000 Rapid7 documentation pages and 3,600+ blog posts for full-text search
- Supports Streamable HTTP and SSE endpoints for MCP-compatible AI clients
- Optional API key authentication and rate limiting for secure access
- Automated crawling with cron scheduling to keep content fresh
- Modular configuration for customizing crawl scope and endpoints

## Why It Matters for RAG Builders
It provides a critical bridge for AI systems to programmatically access and query Rapid7's extensive public documentation, enabling more accurate and context-aware RAG implementations.
