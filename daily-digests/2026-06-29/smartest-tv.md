## Summary
smartest-tv is a desktop application and Python package that enables users to control smart TVs using natural language commands from a terminal or GUI. It supports popular TV brands like LG, Samsung, Roku, and Android TV, allowing users to open apps, play media, adjust volume, and navigate menus without a physical remote.

## Key Features
- Control smart TVs via plain text commands (e.g., 'stv open netflix')
- Supports multiple TV brands (LG, Samsung, Roku, Android TV)
- Available as a Windows GUI app or Python CLI package
- Integrates with MCP servers for AI agent-driven control
- Enables media playback, app launching, and volume adjustments
