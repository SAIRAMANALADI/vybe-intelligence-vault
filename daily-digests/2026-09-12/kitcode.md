## Summary
KitCode is a terminal-based AI coding agent that enables file editing, project search, command execution, and tool integration via MCP. It supports multiple LLM providers, persistent sessions, and advanced features like automatic context compaction and file checkpoints.

## Key Features
- Streaming responses with reasoning output and real-time feedback
- File read, create, edit, and search capabilities with approval prompts
- Persistent and resumable sessions with Markdown export and searchable history
- MCP server integration for external tool connectivity and subagents
- Automatic context compaction and file checkpoints for safety and recovery

## Why It Matters for RAG Builders
KitCode streamlines AI-driven coding workflows by providing a terminal-native agent with robust file manipulation, MCP tooling, and session persistence, making it essential for developers building or integrating AI-powered coding assistants.
