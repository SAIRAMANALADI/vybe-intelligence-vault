## Summary
A community-maintained desktop client for the official DeepSeek Harness AI agent framework, providing a localized Windows/macOS interface with enhanced features like desktop pets, themes, plugin markets, and mobile synchronization.

## Key Features
- Official DeepSeek Harness integration with fixed runtime dependencies for stability
- Desktop pet, themes, and plugin market for enhanced user experience
- Mobile synchronization via WebRTC P2P and WSS/443 encrypted fallback
- Agent Teams for collaborative task execution with role-based routing
- Secure updates with Ed25519 signing, SHA-256 verification, and multi-source mirrors
