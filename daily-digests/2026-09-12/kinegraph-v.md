## Summary
KineticGraph-Vectra is a production-ready hybrid RAG system that integrates ChromaDB for vector search, Neo4j for graph reasoning, and LangGraph for orchestration. It combines semantic similarity, relational reasoning, and lexical retrieval with adaptive routing and chunking for optimized performance.

## Key Features
- Decoupled PropertyGraphIndex with ChromaDB and Neo4j for independent scaling and vendor flexibility
- Adaptive routing (ADR-001) and chunking (ADR-002) for optimized query execution and ingestion
- Robust RAGAS evaluation with live failure interception and model-agnostic critic settings
- Semantic-first graph-aware reranking with configurable multi-hop traversal
- Conditional query recovery before fusion to ensure high-quality retrieval results

## Why It Matters for RAG Builders
It provides a scalable, production-ready hybrid RAG framework that uniquely combines vector and graph databases with adaptive orchestration, enabling more accurate and context-aware retrieval for AI applications.
