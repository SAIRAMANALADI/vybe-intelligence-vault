## Summary
A CLI and MCP server for FlowLeap Patent AI, providing terminal-based access to patent search, analytics, and document processing. It integrates with AI agents via MCP and bundled skills for popular development environments.

## Key Features
- Unified CLI and MCP server for patent and literature search across EPO, USPTO, and academic sources
- Agent Skills integration for Claude Code, Codex, Cursor, and Gemini CLI
- OCR and document analysis capabilities for patent-related files
- Structured error handling with human-readable upgrade prompts for subscription issues
- Automated diagnostics and configuration management via `flowleap doctor`

## Why It Matters for RAG Builders
It bridges the gap between AI agents and patent data, enabling seamless integration of patent search and analytics into agent workflows via MCP and standardized skills.
