## Summary
A Model Context Protocol (MCP) channel server that enables interaction with an AI agent via Zalo, a Vietnamese messaging platform. It bridges Zalo group messages to an MCP client session for AI responses using the Zalo Bot API.

## Key Features
- Enables AI agent interaction via Zalo groups using MCP protocol
- Supports access control policies (pairing, allowlist, disabled) for direct messages
- Group message handling requires explicit mentions or replies
- Lightweight server with no public URL or webhook requirements
- Local deployment behind NAT with polling-based updates

## Why It Matters for RAG Builders
It provides a unique bridge for AI agents to interact with users via Zalo, a major messaging platform in Vietnam, expanding accessibility for AI-driven applications in localized contexts.
