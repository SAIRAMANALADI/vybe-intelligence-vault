## Summary
Shotluma is an AI-first, local-first canvas editor for creating editable iOS App Store screenshot sets directly in the browser. It uses an AI agent to generate real, manipulable designs instead of static images, allowing full manual editing and refinement.

## Key Features
- AI agent generates editable, real-time designs instead of static images
- Supports multiple AI providers (OpenAI, Anthropic, Google, Moonshot, etc.) with user-supplied API keys
- Full manual editing of text, gradients, shapes, and device mockups post-generation
- Local-first storage in browser with IndexedDB for project persistence
- Export to store-ready PNGs in exact resolutions as a ZIP file

## Why It Matters for RAG Builders
Shotluma streamlines the creation of editable, AI-generated App Store screenshots, reducing manual design work while preserving full customization for RAG and AI stack builders.
