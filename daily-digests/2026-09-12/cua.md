## Summary
Cua provides an open-source platform for scaling computer-use agents with cross-OS fleets, background drivers, and benchmarks for training, evaluation, and data generation. It enables autonomous task completion across macOS, Windows, Linux, and Android via sandboxes, virtualization, and native input automation.

## Key Features
- Cross-OS agent sandboxes with unified API for Linux, macOS, Windows, and Android
- Background computer-use drivers for native desktop automation without cursor interference
- Cua-Bench for evaluating and training computer-use agents with RL environments
- Lume for high-performance macOS/Linux VM management on Apple Silicon
- Modular architecture with MCP server, CLI, and SDKs for extensibility
