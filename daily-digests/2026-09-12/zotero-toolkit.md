## Summary
A toolkit providing MCP servers, Zotero plugins, and agent skills for reference management and systematic review workflows. It enables integration with Zotero via both web API and desktop app plugins for real-world research tasks.

## Key Features
- MCP server exposing 12 tools for Zotero Web API integration (read/write operations)
- Standalone CLI for direct access to Zotero without AI dependencies
- Zotero plugin (AutoAttach) for offline local file and attachment management
- Safety mechanisms for write operations (trash, version checks, read-only mode)
- Designed for real research workflows like PRISMA record accounting and exclusion logging

## Why It Matters for RAG Builders
