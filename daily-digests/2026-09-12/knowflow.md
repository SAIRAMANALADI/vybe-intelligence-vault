## Summary
KnowFlow is an AI-powered document chat application that enables users to upload PDFs, DOCX files, or URLs and interact with them in real-time using Arabic or English. It leverages Claude Haiku for streaming responses and Supabase for authentication and storage.

## Key Features
- Supports bilingual (Arabic/English) document interaction in the same session
- Real-time streaming responses powered by Claude Haiku
- Multi-format document ingestion (PDF, DOCX, URLs)
- Built-in authentication via Supabase with PRO tier support
- Secure secrets management with pre-commit scans and environment isolation

## Why It Matters for RAG Builders
KnowFlow simplifies building RAG applications with bilingual support and real-time streaming, reducing setup overhead for developers targeting multilingual use cases.
