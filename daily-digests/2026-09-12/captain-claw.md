## Summary
Captain Claw is a self-hosted framework for orchestrating fleets of specialist AI agents with six distinct orchestration modes, a full agentic coding pipeline, and persistent multi-layered memory. It supports model-agnostic workflows, including local LLMs via Ollama, and provides tools for deterministic automation, autonomous cognition, and agentic development.

## Key Features
- Six orchestration modes (Agent Forge, Agent Council, Basna, Vatra, Code, Flight Deck) for diverse problem-solving strategies
- Full agentic coding pipeline with plan → build → independent review → triage → fix loop
- Persistent 6-layer shared memory system (working, semantic, deep, insights, autonomous, self-reflection)
- 31 ready-made specialist agents and 48 built-in tools per agent
- Deterministic Flows DSL for automation with triggers, parallel execution, and error handling

## Why It Matters for RAG Builders
Captain Claw provides a robust, self-hosted foundation for building complex RAG systems with multi-agent collaboration, persistent memory, and deterministic workflows essential for production-grade AI applications.
