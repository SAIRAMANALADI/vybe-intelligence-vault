## Summary
Pattern is an MCP server that validates UI component needs against real-world evidence before agents commit to implementation, reducing errors by catching mismatches early. It integrates with shadcn/ui, 21st.dev, ReUI, Mobbin, and Figma Community to recommend or guide custom builds.

## Key Features
- Validates UI component needs against real components before implementation
- Integrates with shadcn/ui, 21st.dev, ReUI, Mobbin, and Figma Community
- Provides structured recommendations (use existing, custom build, or no candidates)
- Supports per-project decision memory via a judgment ledger
- Handles simple primitives locally to reduce API calls

## Why It Matters for RAG Builders
It prevents agents from making costly UI implementation mistakes by validating component choices against real-world evidence before development begins.
