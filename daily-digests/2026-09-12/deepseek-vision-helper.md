## Summary
A ZCode skill and hook system that enables text-only AI models (e.g., DeepSeek) to process images by automatically recognizing them and injecting structured vision results into the conversation context. Supports batch processing, fallback providers, and automatic updates.

## Key Features
- Automatically injects image recognition results into AI model conversations via hooks
- Supports batch processing of multiple images with progress tracking and fallback providers
- Configurable via JSON with support for environment variables and automatic updates
- Lightweight Python script with minimal dependencies (standard library only)
- Designed for seamless integration with ZCode CLI and compatible with other agent frameworks

## Why It Matters for RAG Builders
It bridges the gap between text-only AI models and multi-modal capabilities by enabling image recognition without requiring model modifications, making it essential for RAG pipelines handling image inputs.
