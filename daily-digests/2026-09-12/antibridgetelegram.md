## Summary
A Telegram bot that remotely controls and monitors the Antigravity IDE, enabling AI agent management, quota tracking, and project operations via Telegram commands. It bridges Telegram chat with Antigravity's Chrome DevTools Protocol (CDP) for seamless remote interaction.

## Key Features
- 2-way chat between Telegram and Antigravity IDE with single-message updates
- Real-time quota monitoring and history tracking for AI models (Claude, Gemini, GPT)
- CDP-based remote control without mouse/keyboard interference
- File system browsing and project management via Telegram commands
- Smart polling and auto-reconnect for stable remote sessions

## Why It Matters for RAG Builders
It enables remote monitoring and management of AI agents in Antigravity IDE, simplifying workflows for developers and operators who need to control AI environments via mobile or chat interfaces.
