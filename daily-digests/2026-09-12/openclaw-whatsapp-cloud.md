## Summary
A production-grade OpenClaw channel plugin that integrates Meta's WhatsApp Business Cloud API with OpenClaw agents, enabling inbound message handling, voice notes, image generation, and agent-driven outbound replies for WhatsApp interactions.

## Key Features
- Inbound webhook handling with Meta signature verification and typing indicators
- Agent-driven outbound replies (text, voice, images) with explicit tool calls
- Voice notes support via Deepgram STT and Cartesia TTS with multilingual strategies
- Image generation via OpenRouter API with reliable delivery
- 150+ tests covering webhook parsing, STT/TTS fallbacks, and delivery routing

## Why It Matters for RAG Builders
It enables seamless WhatsApp integration for AI agents, supporting voice, text, and image interactions in a production-ready, agent-controlled manner.
