## Summary
OpenYak is a local-first AI agent runtime that enables users to run AI agents directly on their desktop for reliable tool-using models. It supports both local and cloud-based models, providing a secure, account-free workspace for file analysis, native app interaction, and web browsing with shared control between the agent and user.

## Key Features
- Local-first agent runtime with no account or telemetry requirements
- Native Computer and Managed Browser workspaces for live interaction and shared control
- Support for local models (Rapid-MLX, Ollama) and 20+ cloud providers (BYOK)
- Ultra Agent Swarm for parallel child-agent tasks with context preservation
- Auto-compression of long conversation threads to maintain relevant context

## Why It Matters for RAG Builders
OpenYak provides a secure, local-first alternative for building AI agents that interact with desktop apps and files, reducing dependency on cloud services while enabling reliable, context-aware tool use for RAG systems.
