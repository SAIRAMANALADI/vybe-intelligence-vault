## Summary
Eridian is a local, read-only desktop application that unifies and visualizes AI coding agent sessions (Claude Code and OpenCode) into a single control room. It provides a searchable, inspectable archive of agent activities, including file changes, commands, subagents, and token usage, with no cloud dependencies or telemetry.

## Key Features
- Unified session timeline for Claude Code and OpenCode with live ingest and offline history support
- Change inspection with diffs, syntax-highlighted file viewer, and git time-travel
- Full-text search across all agent history with FTS5 indexing
- Token/cost and context-fill rollups with daily usage charts
- Durable local archive that survives agent transcript purges

## Why It Matters for RAG Builders
Eridian provides a critical read-only, local-first interface for auditing and reviewing AI agent activities, ensuring transparency and accountability in AI-driven development workflows.
