## Summary
MESA is a durable, tenant- and dataset-isolated memory engine designed for autonomous AI agents, offering structured memory management with optional full cognitive runtime for advanced processing. It supports both v3 lexical-core and v4 full-cognitive modes with provenance tracking, validation, and multi-modal retrieval.

## Key Features
- Durable memory storage with tenant and dataset isolation for multi-agent systems
- Dual runtime support: v3 lexical-core and v4 full-cognitive with validation and projections
- Source provenance and canonical entity modeling for hallucination mitigation
- Ordered SQLite → vector → graph projection pipeline for multi-modal retrieval
- Built-in MCP server for seamless integration with AI assistants like Claude

## Why It Matters for RAG Builders
MESA provides a robust, scalable foundation for RAG systems by ensuring structured, provenance-rich memory management with optional full cognitive processing to minimize hallucinations and improve retrieval accuracy.
