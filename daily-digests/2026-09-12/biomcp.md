## Summary
BioMCP is a CLI binary and MCP server that unifies access to ~30 trusted biomedical data sources (PubMed, ClinVar, ClinicalTrials.gov, etc.) through a single command grammar. It enables seamless cross-entity discovery, local study analytics, and evidence-oriented results for researchers, clinicians, and AI agents.

## Key Features
- Unified CLI and MCP server for ~30 biomedical sources with a single command grammar
- Cross-entity pivoting (e.g., gene → drug → trial) without rebuilding filters
- Local study analytics with native terminal, SVG, and PNG charts for cBioPortal-style datasets
- Gene-set enrichment via g:Profiler and Enrichr-backed sections
- Progressive disclosure with selectable sections and metadata for follow-up commands

## Why It Matters for RAG Builders
BioMCP eliminates the complexity of integrating multiple biomedical APIs by providing a unified, agent-friendly interface for evidence retrieval, making it essential for RAG pipelines requiring biomedical context.
