## Summary
dify-mcp provides a complete MCP server and CLI for Dify, exposing 138 tools across 16 namespaces to enable AI agents to programmatically build, test, and deploy Dify workflows without a browser. It bridges the Dify console API with agent-friendly interfaces for autonomous workflow management.

## Key Features
- 138 tools across 16 namespaces covering full Dify console API functionality
- Dual interface: CLI (`difywf`) and MCP server (stdio) for agent compatibility
- Agent-agnostic design supporting Claude Code, Codex, Gemini CLI, Cursor, and more
- Cookie + CSRF auth handling with auto-refresh and session persistence
- Safety mechanisms: confirm gates, offline validation, dry-run, and audit logging

## Why It Matters for RAG Builders
It enables AI agents to autonomously build, test, and deploy Dify workflows programmatically, eliminating the need for manual browser-based interactions and accelerating AI-driven automation in RAG and agentic systems.
