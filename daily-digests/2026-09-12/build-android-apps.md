## Summary
A plugin that enables AI assistants to build and ship Android apps end-to-end without requiring manual Kotlin, Gradle, or Play Console interaction. It automates scaffolding, state management, signing, and deployment via plain-English commands.

## Key Features
- End-to-end Android app building from a single prompt using plain English commands
- Automated scaffolding, signing, and Play Store deployment with no manual Gradle/Kotlin required
- Resumable build state with per-project `state.json` for session persistence
- 28 modular skills and 5 MCP servers for lifecycle management, diagnostics, and asset generation
- Cold-start setup wizard (`/setup`) for SDK, Play Console, and keystore configuration

## Why It Matters for RAG Builders
It eliminates the complexity of Android development for non-technical users and AI agents, enabling rapid prototyping and deployment of apps directly from AI prompts.
