## Summary
dsh-image-gen is a native AI image generation and editing suite for DeepSeek Harness, enabling conversational image creation, batch generation, multi-model comparison, and local ComfyUI integration. It provides a full workflow from prompt inspiration to gallery management with support for multiple cloud providers and BYOK (Bring Your Own Key) model.

## Key Features
- Conversational image generation and editing with natural language prompts
- Studio batch creation with up to 5 reference images and 4 output variants
- Multi-model side-by-side comparison for prompt optimization
- 500+ curated prompt inspiration library with local caching
- Local ComfyUI workflow integration for private GPU-based generation

## Why It Matters for RAG Builders
