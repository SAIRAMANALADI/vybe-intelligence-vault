## Summary
FLASH CLI is an AI-powered command-line interface that enables users to interact with local or remote Ollama models while executing shell commands directly or through AI assistance. It bridges natural language with shell execution for seamless terminal-based workflows.

## Key Features
- Interactive AI chat with local/remote Ollama models
- Direct shell command execution via AI or manual input
- Configurable backend for switching between local and remote Ollama servers
- Context management with automatic history trimming
- Rich markdown support for AI responses in the terminal
