## Summary
JobPilot is a multi-platform automated job application tool that scrapes job postings from 51job, Liepin, and Zhaopin, scores them using AI (DeepSeek), and automates or assists with applications via a web dashboard. It includes a full pipeline for job collection, evaluation, and monitoring.

## Key Features
- Multi-platform job scraping (51job, Liepin, Zhaopin) with CDP-driven browser automation
- AI-powered resume scoring using DeepSeek API with configurable thresholds
- Automated or manual job application pipeline with daily throttling limits
- Real-time HR interaction monitoring and response suggestions via web dashboard
- Local SQLite database for job storage and progress tracking

## Why It Matters for RAG Builders
JobPilot streamlines the job application process by automating repetitive tasks and leveraging AI for resume scoring, reducing manual effort for job seekers while maintaining compliance with platform policies.
