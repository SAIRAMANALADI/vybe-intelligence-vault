## Summary
Provides verified U.S. regulated-care provider data with source-linked, timestamped records via an MCP server and TypeScript SDK. Enables natural language or function-call queries for AI agents, clinic finders, and diligence teams.

## Key Features
- Real-time access to verified U.S. healthcare provider data from official sources (NPPES, FDA, state boards, LegitScript)
- MCP server integration for seamless AI agent interactions (e.g., Claude, ChatGPT)
- TypeScript SDK for programmatic access with free tier support
- Source-linked compliance signals (LegitScript, state licenses, FDA warnings) with timestamps
- Tiered pricing model with free access to identity fields and paid tiers for advanced data
