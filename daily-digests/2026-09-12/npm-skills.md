## Summary
A Go-based NPM registry client designed for AI agents, developers, and tooling, offering a Go SDK, CLI, MCP server, and Claude Code plugin for querying packages, managing dist-tags, publishing, auditing, and more with support for 8 mirrors and proxy configurations.

## Key Features
- Go SDK with 70+ methods for programmatic NPM registry access
- CLI tool with 26 commands for direct NPM operations
- MCP server exposing 31 tools for AI tool chains
- Claude Code plugin for AI-native integration (auto-discovery and invocation)
- Support for 8 mirrors (including China mirrors) and HTTP/SOCKS5 proxy configurations
