## Summary
pi-chrome enables AI agents to interact with authenticated Chrome profiles through a set of atomic tools for navigation, DOM manipulation, and content extraction. It bridges Pi AI sessions with Chrome via a browser extension and a secure local bridge.

## Key Features
- Progressively discloses atomic tools (25 total) for fine-grained Chrome control, with core tools active by default and advanced profiles enabled at runtime.
- Secure session management with HMAC-based authentication, authorization, and binding to prevent unauthorized access or replay attacks.
- Exhaustive safety model including epoch-based transitions, fail-closed behavior, and durable state persistence to ensure reliable operations.
- Supports interactive DOM manipulation (click, fill, read), navigation, screenshots, and network capture with strict schema validation and error handling.
- Designed for AI agents with explicit target resolution, session-owned tab management, and compatibility with Pi SDK for seamless integration.
