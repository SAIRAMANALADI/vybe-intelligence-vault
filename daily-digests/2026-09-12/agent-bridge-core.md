## Summary
AgentFlow is a self-hosted, protocol-agnostic orchestrator that connects AI coding agents (Claude, Codex, Copilot, Gemini) to external tools, APIs, or human-in-the-loop workflows via a unified, event-driven messaging architecture. It acts as a central nervous system for AI workforce collaboration.

## Key Features
- Multi-protocol routing for AI agents and messaging platforms
- Session awareness and context preservation across platforms
- Pluggable adapters for extensibility (10-line Python files)
- Human-in-the-loop gates for approval workflows
- Event sourcing for auditing and debugging agent decisions

## Why It Matters for RAG Builders
AgentFlow provides a critical orchestration layer for RAG builders by enabling seamless integration of multiple AI agents and external systems, ensuring robust, context-aware, and human-supervised workflows.
