## Summary
GeoLink MCP is a Model Context Protocol (MCP) server that transforms any AI agent into a location expert by providing geocoding, reverse geocoding, place search, routing, distance matrices, and area sweeps. It abstracts complex geospatial operations into agent-friendly tools with structured outputs and error handling.

## Key Features
- Agent-shaped responses with structured, machine-readable outputs and explicit error envelopes for self-correction
- Supports real road travel time calculations (not straight-line distances) for accurate routing and nearest-branch rankings
- Grid-based area sweeps with dry-run mode to estimate API costs and coverage before execution
- Opt-in geometry for routes (polyline or waypoints) to minimize token usage while preserving flexibility
- Built-in caching, deduplication, and normalization for consistent results across language and region variations

## Why It Matters for RAG Builders
It enables AI agents to perform complex geospatial tasks with minimal setup, reducing integration overhead and improving the reliability of location-based decisions in RAG applications.
