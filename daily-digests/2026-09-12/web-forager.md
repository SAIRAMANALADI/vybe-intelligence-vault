## Summary
Web Forager is a search-and-fetch toolkit designed to enable AI agents with practical web research workflows as Agent Skills. It provides tools for web search, news monitoring, page fetching, and synthesis of cited answers for LLM consumption.

## Key Features
- Agent Skills integration for 50+ coding agents (Claude Code, Codex, VS Code, etc.)
- Multi-source web research with DuckDuckGo, direct HTTP fetching, and Jina Reader fallback
- Five specialized skills: deep-research, fact-check, news-monitor, competitive-intel, and tech-advisor
- MCP server support for reusable search/fetch tools in MCP-compatible clients
- Cited answer synthesis with structured output for LLM consumption

## Why It Matters for RAG Builders
It streamlines web research for AI agents by providing modular, agent-agnostic skills that deliver structured, cited outputs essential for RAG pipelines.
