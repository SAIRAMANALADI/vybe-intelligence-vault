## Summary
MCP server for verifying Russian product marking codes via the Chestny Znak (Honest Sign) system. Enables AI agents to check product authenticity, retrieve detailed product info, and query True API endpoints for GTIN and CIS data without manual API access.

## Key Features
- 5 integrated tools for product code verification (DataMatrix, QR, EAN13) without authentication
- True API integration for GTIN and CIS lookups with token-based authorization
- Batch processing support for up to 50 codes with parallelism control
- HTTP server mode for streamlined AI agent integration
- Structured JSON responses with typed schemas for programmatic use

## Why It Matters for RAG Builders
Enables AI agents to programmatically verify Russian product authenticity and compliance with Chestny Znak regulations, reducing manual API access overhead.
