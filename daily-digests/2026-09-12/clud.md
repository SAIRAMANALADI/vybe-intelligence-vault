## Summary
clud is a CLI tool that unifies and orchestrates interactions with multiple AI models (Claude, Codex, DeepSeek, Kimi, OpenRouter) via a single interface, enabling agentic workflows like PR automation, bug grinding, and code refactoring.

## Key Features
- Unified CLI for interacting with multiple AI models (Claude, Codex, DeepSeek, Kimi, OpenRouter)
- Supports agentic workflows like PR automation (`clud do`), bug grinding (`clud grind`), and code refactoring
- Daemon-managed sessions with detachable and resumable workflows
- PTY graphics headers for enhanced terminal output (Sixel support)
- Cross-platform installation (macOS, Linux, Windows) with pre-built binaries

## Why It Matters for RAG Builders
clud simplifies the orchestration of multiple AI models into a single workflow, making it essential for AI engineers building automated agentic systems.
