## Summary
Fastmail Remote is a Cloudflare Workers-based remote MCP server that enables AI assistants (e.g., Claude, Copilot) to interact with Fastmail accounts via the JMAP API. It provides secure OAuth authentication, a CLI for token-efficient operations, and a plugin for OpenClaw, simplifying email, contact, and calendar management for AI workflows.

## Key Features
- Remote MCP server deployment on Cloudflare Workers with Cloudflare Zero Trust authentication
- CLI tool for token-efficient email, contact, and calendar operations (saves 5-7x tokens vs raw MCP)
- OpenClaw plugin with 37+ agent tools for AI workflows
- Secure OAuth 2.0 with PKCE flow and encrypted token storage
- Advanced email threading, memo annotations, and bulk operations

## Why It Matters for RAG Builders
It enables AI assistants and agents to securely interact with Fastmail accounts via MCP, bridging a critical gap for AI-driven email and productivity workflows.
