## Summary
Kuvasz is an open-source, self-hosted uptime and SSL monitoring service with status pages, designed to track website and service availability. It offers a modern UI, REST API, MCP server for AI integration, and supports multiple notification channels and metrics exporters.

## Key Features
- Real-time HTTP(S) and SSL monitoring with 5-second intervals
- MCP server for AI assistant integration and natural language queries
- YAML-based configuration and backup/restore for easy deployment
- Multi-channel notifications (email, Slack, Discord, Telegram, etc.)
- Prometheus and OpenTelemetry metrics exporters for observability
