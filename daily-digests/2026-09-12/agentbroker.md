## Summary
Agent Broker is an MCP server that enables AI agents to interact with small and mid-sized businesses (SMBs) through a unified, compliance-enforced interface. It provides tools for finding, verifying, messaging, scheduling, and transacting with SMBs while enforcing TCPA, GDPR, and other regulatory compliance.

## Key Features
- 23 MCP tools for SMB interactions (find, verify, message, schedule, transact)
- Non-bypassable compliance gate (TCPA/GDPR/CASL/10DLC) with verifiable receipts
- Multi-channel communication (WhatsApp, SMS, email, voice AI)
- Machine-mintable API keys for agent self-service
- Idempotent retries and async operation tracking

## Why It Matters for RAG Builders
It bridges the gap between AI agents and SMBs by providing a compliant, unified interface for real-world transactions and communications, essential for building production-grade RAG systems.
