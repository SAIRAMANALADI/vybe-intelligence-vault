## Summary
Janu XR is an AI-assisted prototype designed to guide first-time XR users through headset setup via conversational guidance, failure tracking, and structured evaluation logs. It includes a FastAPI backend, an Android dashboard for log inspection, and a Unity-based XR experience with a stereoscopic elephant guide for spatial hints.

## Key Features
- Eight-step conversational XR setup guide with detailed failure tracking for critical steps (headset fit, eye calibration, pinch gestures)
- FastAPI backend for session management, evaluation logs, and API-driven guidance
- Android dashboard for inspecting evaluation logs, aggregate insights, and replaying user sessions
- Unity-based XR experience with a stereoscopic elephant guide for spatial hints and state-based animations
- Local fallback mode for headset guidance when API is unavailable, ensuring uninterrupted user experience

## Why It Matters for RAG Builders
Janu XR demonstrates how AI can guide users through complex hardware setup processes with structured feedback and spatial guidance, offering a template for integrating conversational AI into XR workflows.
