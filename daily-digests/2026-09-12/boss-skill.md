## Summary
boss-skill is a Windows desktop application designed to help users navigate workplace pressures by analyzing boss communications, generating appropriate responses, and tracking evidence for labor disputes. It provides tools for PUA detection, reply coaching, labor law lookups, and simulated practice scenarios.

## Key Features
- PUA (Pressure User Agent) message analysis to detect manipulative communication styles
- Three-tiered reply coaching (soft, firm, hard stop) for workplace responses
- Evidence collector for saving chats, notes, and timestamps for dispute resolution
- Labor law quick lookup tool for common workplace regulations
- Text-based simulation game for practicing responses to workplace pressure
