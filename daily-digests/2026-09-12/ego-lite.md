## Summary
ego-lite is a dedicated browser designed for seamless collaboration between users and AI agents, enabling parallel browser automation tasks without disrupting the user's workflow. It provides isolated 'Spaces' for agents to work independently while inheriting the user's browser state, including logins and cookies.

## Key Features
- Dedicated isolated Spaces for each AI agent to prevent workflow collisions
- Inherits user's browser state (logins, cookies, extensions) for seamless integration
- High-quality page snapshots for reliable AI agent interactions
- Parallel multitasking across multiple Spaces within the same browser
- Optimized for faster task completion with fewer tokens compared to CLI-based tools

## Why It Matters for RAG Builders
ego-lite enables AI agents to perform browser automation tasks efficiently while preserving the user's browsing state, reducing setup friction and improving task success rates for RAG systems.
