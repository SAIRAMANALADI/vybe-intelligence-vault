## Summary
An AI agent that automates real-time electricity demand monitoring for the U.S. grid by driving a browser to read and report data from the EIA's Hourly Electric Grid Monitor, then films its own actions. It operates without dependencies, runs offline, and uses a vision model to interact with live dashboards.

## Key Features
- Zero-dependency automation with pure Node.js built-ins
- Runs offline with bundled mock for testing and $0 cost
- Uses vision models to interact with live dashboards without selectors or scraping rules
- Self-documenting with provenance and per-frame hashes for transparency
- Structured safety controls to prevent accidental spend or credential exposure
