## Summary
A local-first browser automation bridge that enables AI agents to control real Chrome/Edge browsers via the Chrome DevTools Protocol (CDP). It allows agents to interact with authenticated sessions while maintaining full privacy and avoiding cloud dependencies.

## Key Features
- Local-only execution with no cloud relay or third-party tokens
- Full CDP access via a Chrome/Edge extension for real browser control
- Supports authenticated sessions (e.g., bank dashboards, internal tools)
- Human-like interaction simulation (mouse movements, typing delays) for anti-detection
- Agent-agnostic with a simple HTTP API for integration with any AI tool

## Why It Matters for RAG Builders
It enables AI agents to interact with real-world web interfaces while preserving user privacy and avoiding SaaS lock-in, making it essential for secure, local-first automation workflows.
