## Summary
webclaw is a fast, local-first toolkit for extracting clean, LLM-ready content from websites. It provides CLI, MCP server, REST API, and SDKs to convert URLs into structured markdown, JSON, or plain text, enabling seamless integration with RAG pipelines and AI agents.

## Key Features
- Local-first extraction with optional cloud fallback for protected sites
- Multiple output formats (markdown, JSON, LLM-optimized text, HTML)
- CLI, MCP server, REST API, and SDKs for Python, TypeScript, and Go
- Built-in crawling, batch processing, and diffing for monitoring changes
- Brand asset extraction (colors, fonts, logos) and structured data conversion

## Why It Matters for RAG Builders
It provides a robust, local-first solution for converting raw web content into clean, structured data essential for RAG pipelines and AI agents.
