## Summary
Loom is a measurement-based production system for Ableton Live, providing a local MCP server with 28 tools that read and write a running Live session. It enables AI-driven music production workflows by generating MIDI variations, project plans, and automations while ensuring data integrity through synthetic fixtures and measured validation.

## Key Features
- 28 integrated tools for AI-driven music production in Ableton Live
- Real-time read/write capabilities via MCP server and control surface
- Validation through synthetic fixtures and measured data (no user data exposed)
- Project planning, MIDI generation, and automation writing with dry-run support
- Modular architecture with optional Ableton Extensions SDK integration

## Why It Matters for RAG Builders
Loom enables AI engineers to build RAG systems that interact with Ableton Live for automated music production, offering a robust framework for generating, validating, and executing production workflows.
