## Summary
CodeCartographer is an evidence-backed software cartography tool that transforms unfamiliar codebases into validated architecture maps, behavioral contracts, defect reports, and reimplementation specifications. It supports interactive, MCP, and drop-in modes for reverse engineering and forward synthesis of software projects.

## Key Features
- Layered analysis pipeline with validation gates between phases (architecture → defects → contracts → protocols → reimplementation spec)
- Three deployment surfaces: Pi extension (recommended), MCP server, and drop-in template for one-off evaluations
- Progressive distillation of codebases into smaller, task-specific artifacts with explicit validation and provenance tracking
- Forward synthesis capability to generate implementation plans from product visions and confirmed specifications
- Security-focused design with sandboxed tool execution and path containment checks

## Why It Matters for RAG Builders
It provides a structured, evidence-backed approach to reverse engineer and plan software projects, ensuring reliability and provenance for RAG/AI stack builders.
