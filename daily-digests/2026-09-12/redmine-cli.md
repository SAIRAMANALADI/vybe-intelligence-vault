## Summary
A command-line interface for Redmine project management that enables interaction with Redmine servers via CLI commands, supporting issue tracking, time logging, and AI agent integrations.

## Key Features
- Full CLI for Redmine operations (issues, time tracking, authentication)
- AI agent integration via Skills and MCP server for automated workflows
- Multi-platform support (Linux, macOS, Windows) with auto-install scripts
- Read-only mode and configurable credential storage for security
- Docker-based E2E testing for Redmine instances
