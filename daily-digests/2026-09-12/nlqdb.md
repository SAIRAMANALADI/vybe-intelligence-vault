## Summary
nlqdb is a natural language query database that enables AI agents to store, retrieve, and analyze data using plain English queries. It bridges the gap between vector-based memory and structured SQL operations, allowing agents to perform complex operations like GROUP BY, JOIN, and aggregations without writing SQL.

## Key Features
- Natural language to SQL translation with high accuracy (BIRD ≥ 0.65, Spider 2.0 ≥ 0.75)
- Multi-engine support (Postgres, MongoDB, Redis, DuckDB, etc.) with automatic workload-based migration
- Real-time analytical memory for AI agents (GROUP BY, JOIN, aggregations)
- Hosted MCP server and CLI for seamless agent integration
- Sub-400ms cached and sub-1.5s cold query performance with visible SQL traces

## Why It Matters for RAG Builders
nlqdb enables AI agents to perform structured, analytical queries over their memory in plain English, bridging the gap between vector recall and SQL operations, which is critical for advanced RAG and agentic workflows.
