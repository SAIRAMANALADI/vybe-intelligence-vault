## Summary
A minimal Python boilerplate for building streaming AI chat applications using FastAPI, LangGraph, and LangChain with OpenAI-compatible models. It provides a static Markdown chat interface, SQLite checkpoint persistence, conversation threads, branching, and message editing capabilities.

## Key Features
- Streaming AI chat with token-by-token response delivery
- SQLite-based checkpoint persistence for conversation threads and branching
- Support for message editing, regeneration, and thread navigation
- FastAPI-based RESTful API with OpenAPI documentation
- Modular agent design with configurable system prompts and model factories

## Why It Matters for RAG Builders
It provides a production-ready foundation for building conversational AI applications with branching, persistence, and streaming, critical for RAG systems requiring dynamic conversation handling.
