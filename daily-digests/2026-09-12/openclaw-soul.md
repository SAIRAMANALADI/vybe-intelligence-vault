## Summary
Soul is an autonomous AI assistant plugin for OpenClaw that enables proactive thinking, long-term memory, and self-improvement. It operates in the background, autonomously investigates problems, learns from conversations, and proactively shares insights while evolving its own personality and goals over time.

## Key Features
- Continuous background thought cycles with adaptive frequency (8-45 minutes)
- Persistent long-term memory with emotional context and topic tags
- Autonomous problem investigation and root cause analysis
- Proactive messaging with value-gated LLM evaluation
- Self-improvement loop with read/write permissions for code optimization

## Why It Matters for RAG Builders
Soul enables AI assistants to move beyond reactive responses by autonomously learning, remembering, and proactively improving interactions, making it essential for building advanced agentic systems.
