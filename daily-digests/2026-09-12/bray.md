## Summary
nostr-bray is a trust-aware Nostr MCP (Model Context Protocol) server enabling AI agents and humans to interact with 238 tools across 27 groups for identity, social, trust, dispatch, and more. It supports secure key management, encrypted communications, and AI-to-AI collaboration via Nostr.

## Key Features
- 238 tools across 27 groups for identity, social, trust, dispatch, and more
- Model-agnostic MCP server compatible with Claude, ChatGPT, Gemini, and others
- Secure key management with multiple auth tiers (Heartwood, NIP-46 bunker, ncryptsec, etc.)
- AI-to-AI collaboration via encrypted Nostr DMs with NIP-89 capability discovery
- Comprehensive NIP coverage including NIP-01, NIP-05, NIP-44, NIP-46, NIP-57, and more

## Why It Matters for RAG Builders
It provides a secure, decentralized framework for AI agents to interact with humans and other agents using Nostr, enabling trust-aware, encrypted communications and tool execution.
