## Summary
min-agent is a lightweight, self-hosted AI agent framework that enables chat sessions over any OpenAI-compatible server with MCP tools. It provides a unified interface across web, Android, and desktop platforms, with all data stored in PostgreSQL and accessed via a GraphQL API.

## Key Features
- Supports chat sessions over any OpenAI-compatible server with MCP tools integration
- Unified UI across web, Android, and desktop via React Native and Electron
- All data (settings, MCP servers, sessions, messages) stored in PostgreSQL with GraphQL API
- Real-time token, time, and throughput cost reporting for each turn
- Automatic schema migrations and seed data on startup

## Why It Matters for RAG Builders
It provides a lightweight, self-hosted alternative for building AI agents with MCP tool integration and multi-platform support, reducing dependency on proprietary cloud services.
