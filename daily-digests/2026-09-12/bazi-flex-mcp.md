## Summary
A Model Context Protocol (MCP) server for Bazi (八字 / Four Pillars) calculations that handles partial birth time data, enabling AI assistants to generate Bazi charts even when the exact birth hour is unknown. Built on the shunshi-bazi-core library with true-solar-time correction.

## Key Features
- Supports full Bazi charting with complete birth time via `getBaziChart` tool
- Handles partial birth time (year/month/day only) with `getBaziChartPartial` tool
- Provides structured Bazi data with true-solar-time correction and enriched metadata
- Offers both stdio and streamable HTTP transport for MCP clients
- Includes advanced features like 空亡 (void) structuring, 流年 (annual luck) tables, and decision metrics

## Why It Matters for RAG Builders
It enables AI assistants to generate accurate Bazi charts even with incomplete birth data, expanding the utility of RAG systems in domains like Chinese metaphysics and personalized advice.
