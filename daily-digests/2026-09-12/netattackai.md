## Summary
NetAttackAI is a Python-based autonomous offensive security tool that leverages local Ollama LLMs to plan and execute authorized security assessments, including reconnaissance, exploit orchestration, and reporting, entirely on the user's machine.

## Key Features
- Multi-agent swarm with 6 specialist agents (recon, vuln, exploit, post-exploit, critic, reflection)
- Policy-driven AI agent loop for adaptive exploit orchestration and vulnerability chaining
- Integration with 100+ attack modules and 130+ advisory methodology skills
- Local-first execution with Ollama LLMs and support for 10+ security tools (Nmap, Metasploit, Impacket, etc.)
- WebUI API for third-party integration and autonomous campaign management with persistent multi-phase workflows

## Why It Matters for RAG Builders
NetAttackAI provides an AI-driven framework for automating complex offensive security operations, enabling RAG builders to integrate autonomous agent-based attack simulations and vulnerability exploitation workflows into their systems.
