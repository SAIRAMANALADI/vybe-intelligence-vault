## Summary
Hermes-CoAgent is a local Windows desktop automation REST API server that enables AI agents to control mouse, keyboard, screen, windows, processes, and browsers through a secure Flask HTTP API. It serves as a bridge between AI orchestration layers and desktop automation tasks.

## Key Features
- Comprehensive desktop control via REST API (mouse, keyboard, screen, windows, processes)
- Browser automation with Playwright and stealth capabilities (anti-detection patches)
- MCP (Model Context Protocol) bridge for integrating AI tools and endpoints
- Secure authentication (Bearer token) and governance policies (allowlists, budgets)
- One-click deployment, self-healing checks, and telemetry-backed strategy selection for UI automation
