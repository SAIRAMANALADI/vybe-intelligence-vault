## Summary
A full-stack AI application combining FastAPI, Vue 3, and LangChain to create a JWT-authenticated AI agent with structured tool-calling capabilities. The backend uses Groq LLMs for decision-making and tool execution, while the frontend provides a transparent chat interface to visualize agent workflows.

## Key Features
- Structured LangChain tool-calling architecture for reliable AI workflows
- JWT-authenticated FastAPI backend with OAuth2 compatibility
- Transparent chat interface displaying agent actions and tool observations
- Integration with Groq LLMs for fast and stable inference
- Extensible tool system with Wikipedia retrieval as a built-in example

## Why It Matters for RAG Builders
