## Summary
A Model Context Protocol (MCP) server for Claude Code that enhances real-time web capabilities by integrating Grok AI search, Tavily high-fidelity scraping, and Firecrawl web screenshots. It supports multi-key failover, cross-source validation, and forced routing of web requests.

## Key Features
- Multi-source cross-validation for web search using Grok AI, Tavily, and Firecrawl
- Grok AI search with fallback to OpenAI-compatible endpoints or local CLI
- Full-text web scraping with Tavily Extract and Firecrawl fallback
- Firecrawl-powered web screenshots with signed PNG URLs
- Multi-key failover and automatic cooldown for API rate limits
