## Summary
Scarf is a native macOS companion app for the Hermes AI agent, providing full visibility into agent activities, sessions, memory, and configurations. It offers multi-window support, remote server management via SSH, and advanced features like model tuning, session exports, and markdown rendering.

## Key Features
- Real-time visibility into Hermes AI agent activities and outputs
- Multi-window support for managing multiple sessions and servers
- Advanced model tuning (compression, reasoning effort, provider exclusions)
- Markdown table rendering and rich text support in chat and editor
- Session exports, memory management, and cron job tracking
