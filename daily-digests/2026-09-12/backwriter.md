## Summary
Backwriter is a Rust-based runtime and core library for structural text manipulation in a workspace, enabling precise file, paragraph, and line addressing without tracking source history or editor state. It provides capabilities like search, view, edit, and apply for current-state text work in AI agent workflows.

## Key Features
- Precise file/paragraph/line addressing with v4 Anddress objects
- Core capabilities: Search, View, Pick, Anchor, Check, Edit, Apply, and Data
- One-shot and session-based editing workflows with receipts
- Cross-platform support (Linux, macOS, Windows) with static builds
- Offline-safe installation and updates with SHA-256 verification

## Why It Matters for RAG Builders
Backwriter enables precise, addressable text manipulation in AI agent workflows, ensuring deterministic and verifiable edits without relying on source history or external state.
