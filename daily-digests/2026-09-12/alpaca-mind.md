## Summary
alpaca-mind deploys a self-evolving AI trading agent on AWS that autonomously trades options and equities via Alpaca, while also generating a dynamic web UI to visualize its decisions and reasoning. The agent schedules its own operations, evolves its strategies, and journals every action for transparency.

## Key Features
- Fully autonomous AI agent that schedules, researches, and executes trades without hardcoded strategies
- Dynamic web UI that continuously rebuilds itself from the agent's journals and transcripts
- Self-auditing system with transparent decision logging and traceable trade reasoning
- Interactive deployment via AI assistants with guided setup and removal protocols
- Built-in safety mechanisms including a kill switch and orders-per-hour limits

## Why It Matters for RAG Builders
It demonstrates how autonomous AI agents can self-evolve, audit their decisions, and generate real-time interfaces for transparency in high-stakes domains like trading.
