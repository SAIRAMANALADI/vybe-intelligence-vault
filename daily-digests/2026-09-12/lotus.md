## Summary
Lotus is a React + Vite-based UI layer designed to provide a transparent, observable interface for interacting with AI agents. It streams live agent reasoning, tool calls, and task progress over Server-Sent Events (SSE), enabling users to monitor and interrupt agent workflows in real time.

## Key Features
- Live event streaming of agent reasoning and tool calls via SSE with smooth token-by-token rendering using `requestAnimationFrame`
- Interactive command palette for quick navigation and agent control (e.g., `Cmd/Ctrl + K`)
- Multi-pane layout for side-by-side session viewing and resizable splits
- Built-in Mermaid diagram rendering with zoom/pan and AI-assisted error correction
- Bilingual (zh-CN/en-US) and theming support with light/dark modes and VDI-safe options

## Why It Matters for RAG Builders
Lotus transforms opaque AI agent interactions into transparent, observable workflows, making it essential for developers building RAG systems that require real-time visibility into agent reasoning and tool usage.
