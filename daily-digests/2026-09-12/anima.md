## Summary
ANIMA Kernel is a zero-dependency cognitive state engine designed to provide durable, inspectable state layers for stateful AI agents. It implements a research-inspired architecture combining temporal context, affect-inspired signals, associative memory, and self-model instrumentation to enable measurable state transitions and behavioral testing.

## Key Features
- Durable state persistence with atomic JSON files for survival across restarts
- Affect-inspired signal vector with nine numeric signals and blending/decay mechanisms
- Associative memory with tag associations, spreading activation, decay, and reconsolidation
- Temporal context tracking including elapsed-time, decaying retention, and heuristic protention
- Integration proxy (Phi) and CQI composite metrics for state observability and ablation testing
