## Summary
Butler v5 is a self-hosted, single-owner personal AI assistant with WeChat integration, CLI/API, tool execution, and durable event-driven architecture. It enables structured LLM interactions, delegation, and persistent memory while maintaining strict control over data and permissions.

## Key Features
- Native WeChat iLink integration for inbound/outbound messaging
- AgentKernel-driven LLM + structured tool execution loop
- Durable event persistence with PostgreSQL Event Store and Outbox
- Sub-agent delegation with transactional outbox and WebSocket push
- Multi-provider LLM support with failover mechanisms

## Why It Matters for RAG Builders
Butler v5 provides a robust, self-contained framework for building personal AI agents with strict data governance and extensible tooling, critical for RAG systems requiring persistent memory and secure delegation.
