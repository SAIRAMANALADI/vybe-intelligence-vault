## Summary
A Retrieval-Augmented Generation (RAG) system built from scratch to teach the fundamentals of retrieval, embeddings, and evaluation. It starts with core logic (chunking, similarity search) before integrating production tools like ChromaDB or FAISS.

## Key Features
- Implements core RAG logic (chunking, embeddings, similarity search) from scratch before using production tools
- Supports multiple LLMs (Groq, Gemini) and vector databases (ChromaDB, FAISS)
- Includes a FastAPI backend and React frontend for end-to-end pipeline
- Designed for educational purposes to deepen understanding of RAG internals
- Evaluates retrieval and generation performance as part of the learning process

## Why It Matters for RAG Builders
