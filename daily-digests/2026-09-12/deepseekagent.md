## Summary
DeepseekAgent is a local-first AI programming agent that executes tasks end-to-end with verifiable, recoverable workflows. It plans, modifies code, runs commands, and validates changes before reporting completion, all while ensuring evidence-based verification and security constraints.

## Key Features
- Recoverable and verifiable task execution with state machine workflows
- 12 specialized agent roles (architect, reviewer, specialist) for dynamic task delegation
- Evidence-based verification (L0-L4) with contract enforcement and audit trails
- Security-first design with permission tiers, sandboxed tools, and immutable evidence
- Persistent runtime state and session recovery across restarts

## Why It Matters for RAG Builders
DeepseekAgent provides a robust framework for building AI-driven agents that require verifiable, secure, and recoverable task execution, critical for production-grade RAG and AI systems.
