## Summary
Cogs is a secure, minimal VM-isolated personal assistant framework designed for embedding Pi, focusing on deterministic repository setup, CI validation, and security contracts. It is currently in Stage 0 feasibility work and lacks production-ready features like sandboxing or secure deployment.

## Key Features
- Minimal and secure design with VM isolation for personal assistants
- Deterministic repository and CI setup for reproducibility
- Security contracts and credential-security requirements documentation
- Native JSONL compatibility and hostile extension/package canaries
- Stage 0 feasibility work with clear acceptance gates and ADRs
