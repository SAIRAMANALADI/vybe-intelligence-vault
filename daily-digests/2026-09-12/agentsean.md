## Summary
Agent Sean is an open-source, self-hosted autonomous SEO engineer that crawls websites, identifies SEO issues via 425 checks, and automatically fixes them in WordPress, Shopify, Git repos, or at the edge. It provides reversible changes with snapshots and one-click reverts, operating 24/7 with no vendor lock-in.

## Key Features
- Autonomous SEO fixes with 425 checks across 25 detector families
- Writes fixes directly into WordPress, Shopify, Git, or edge platforms with reversible diffs
- Local-first architecture with BYOK (Bring Your Own Keys) for LLMs and data
- Weekly crawls, daily data pulls from Search Console/Analytics, and priority-based action ranking
- Strict security model with fail-closed daemon, credential isolation, and red-team tested defenses

## Why It Matters for RAG Builders
Agent Sean bridges the gap between SEO auditing and execution by autonomously fixing issues in source-controlled environments, reducing manual intervention while ensuring reversibility and compliance with search engine policies.
