## Summary
A reference implementation of the Apache Kafka Model Context Protocol (MCP) server (KIP-1318) that enables secure, governed access to Kafka for AI agents. It provides a fail-closed pipeline with enterprise-grade security controls, data protection, and identity isolation.

## Key Features
- Reference implementation of KIP-1318 for Kafka MCP server with fail-closed security pipeline
- Enterprise-grade guardrails including DLP, IFC, rate limiting, and circuit breakers
- 11 MCP tools for Kafka operations (read, write, mutate, and destructive actions)
- Resource cataloging via `kafka://` URIs for topics, clusters, groups, and audit logs
- Identity isolation, approval gates, and scoped access control for AI agents

## Why It Matters for RAG Builders
It provides a secure, governed bridge for AI agents to interact with Kafka without compromising enterprise security or introducing confused deputy risks.
