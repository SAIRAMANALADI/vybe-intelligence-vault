## Summary
Chimera is an open-source, governed AI agent framework that blends multiple AI models for robust decision-making, executes real-world tasks autonomously, and learns from verified outcomes while prioritizing safety and self-hosting capabilities.

## Key Features
- Multi-model consensus for improved accuracy and reduced hallucinations by blending answers from multiple LLMs
- Autonomous task execution with tool usage, planning, and verification, ensuring only verified changes are retained
- Self-learning with fitness gating, where changes are retained only if they pass verified A/B tests and transfer holdouts
- Built-in security layers including opt-in sandboxing, taint tracking, and safety checks to mitigate prompt injection and harmful actions
- Honest benchmarking with confidence intervals, retraction of claims upon replication failures, and transparent reporting

## Why It Matters for RAG Builders
Chimera provides a governed, multi-model approach to AI agents that ensures safer, more reliable, and self-improving automation for RAG and AI stack builders.
