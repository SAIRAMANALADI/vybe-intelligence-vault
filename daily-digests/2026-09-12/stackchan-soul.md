## Summary
A persistent consciousness loop for embodied devices that enables autonomous, curious behavior in desk robots. It runs a long-lived agent session that wakes, thinks, acts, and sleeps based on its inner state (mood, diary) and external inputs, without relying on scripted or timer-driven behavior.

## Key Features
- Persistent agent session with JSONL-based memory persistence and compaction
- Autonomous sleep/wake cycles controlled by the agent's inner state (mood, diary, curiosity)
- Pluggable body architecture supporting any device with minimal HTTP endpoints
- Shared inner state (MOOD.md) between real-time dialog agents and autonomous behavior
- Cost-efficient operation with configurable sleep durations and LLM provider flexibility

## Why It Matters for RAG Builders
It demonstrates how to build truly autonomous AI agents that operate without constant external prompting, making it a valuable reference for RAG builders seeking to create persistent, self-driven systems.
