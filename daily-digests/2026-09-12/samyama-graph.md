## Summary
Samyama Graph is a Rust-native graph-vector database designed for GraphRAG, knowledge graphs, and large-scale analytics. It combines graph traversal, OpenCypher-style querying, vector search, and Redis-compatible access in a single system optimized for billion-edge datasets.

## Key Features
- Supports billion-edge datasets with sub-second query performance on a single machine
- Combines graph traversal, vector search, and Redis-compatible access in one system
- OpenCypher-style querying for familiar graph operations
- Built-in graph algorithms for analytics and relationship discovery
- Dockerized deployment with optional OpenAI embeddings integration

## Why It Matters for RAG Builders
Samyama Graph enables RAG builders to efficiently store, query, and analyze connected data at scale while integrating vector search for semantic retrieval, making it ideal for GraphRAG and knowledge-intensive AI applications.
