## Summary
DeFade SDK is an official JavaScript/TypeScript client for the DeFade API, providing rug pull risk scores and on-chain behavioral forensics for tokens across Solana, Ethereum, Base, and Robinhood Chain. It enables deep analysis of token launches, funding origins, insider networks, and smart-money flows.

## Key Features
- Zero-dependency SDK with Node 18+ support (CJS and ESM)
- Comprehensive token analysis with safety scores and rug pull probabilities
- Multi-chain support (Solana, Ethereum, Base, Robinhood Chain)
- MCP server integration for AI assistants (Claude, ChatGPT)
- Flexible API with escape hatch for unwraped endpoints

## Why It Matters for RAG Builders
It provides critical on-chain behavioral analysis tools for RAG builders to detect rug pulls and token risks beyond static contract scanning.
