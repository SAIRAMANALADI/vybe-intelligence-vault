## Summary
A multi-host agent plugin for Wishket (wishket.com) that enables project search, analysis, and technical profile matching across AI coding assistants like Claude Code, Codex, Antigravity, and Hermes. It includes a Rust-based MCP server for reverse-engineered API interactions and deterministic keyword scoring.

## Key Features
- Multi-host agent plugin supporting Claude Code, Codex, Antigravity, and Hermes
- Rust-based MCP server for reverse-engineered Wishket API interactions
- Deterministic keyword scoring and HTML/JSON-LD parsing for project analysis
- Automated onboarding, profile management, and project scanning workflows
- Sub-agent (`wishket-analyst`) for deep single-project fit analysis

## Why It Matters for RAG Builders
It streamlines technical profile matching and project scouting for AI agents by integrating Wishket's job postings with deterministic analysis, reducing manual effort in finding suitable projects or candidates.
