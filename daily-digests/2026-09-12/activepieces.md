## Summary
Activepieces is an open-source automation platform that serves as a self-hostable alternative to Zapier, enabling users to create AI-driven workflows with a no-code/low-code interface. It supports 280+ integrations (pieces) and extends functionality to MCP servers for LLM interactions.

## Key Features
- Open-source no-code/low-code workflow builder with 280+ integrations (pieces)
- TypeScript-based extensible framework for creating custom pieces and MCP servers
- Supports AI-first automation with native AI pieces and MCP toolkit for LLMs
- Enterprise-ready with self-hosting, branding customization, and human-in-the-loop controls
- Active community with 60% of pieces contributed externally and frequent updates
