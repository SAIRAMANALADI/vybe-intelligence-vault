## Summary
Vespa is an Apache 2.0 open-source serving engine designed for big-data applications, vector search, and recommendation systems. It provides a Document API for CRUD operations, a Search API for querying, and supports real-time hybrid retrieval with ranking expressions.

## Key Features
- Supports vector, full-text, and hybrid search with YQL or structured query JSON
- Document API for CRUD operations with conditional writes and upserts
- Real-time indexing and retrieval with low latency
- Scalable architecture for big-data applications
- Open-source under Apache 2.0 license with a commercial managed offering
