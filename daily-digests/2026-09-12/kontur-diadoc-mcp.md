## Summary
MCP server enabling AI assistants to interact with Kontur.Diadoc, a Russian electronic document interchange (EDI) platform. It provides 12 tools for searching organizations, listing/fetching documents, sending, and signing invoices, acts, and other business documents directly via AI prompts.

## Key Features
- 12 pre-built tools for Diadoc API operations (authentication, document search, sending, signing)
- Cursor-based pagination and ISO timestamp handling for Diadoc API compliance
- Supports both test and production signatures for document signing
- Error handling with exponential backoff and automatic re-authentication
- Environment variable configuration for API credentials and sandbox testing

## Why It Matters for RAG Builders
It bridges AI assistants with Kontur.Diadoc, enabling automated document workflows without manual UI interactions, critical for Russian business process automation.
