## Summary
fiatdock-mcp is an MCP server enabling AI agents to discover, pay, and settle transactions in USDC over the x402 protocol, facilitating non-custodial USDC-to-bank conversions and on-chain data access. It provides a decentralized marketplace for agent-to-agent payments and integrates first-party on-chain Base data with token safety screening.

## Key Features
- Non-custodial USDC ↔ bank ramp with KYC handled by regulated partners
- Pay-per-call model over x402 protocol with automatic settlement to seller wallets
- 18 MCP tools including token price/safety, gas tracking, and marketplace discovery
- Supports both local wallet payments and external signer integration
- Compliance-ready with EU/EEA user restrictions and ownership verification

## Why It Matters for RAG Builders
It enables AI agents to autonomously discover, pay, and settle transactions with other agents or services in a non-custodial, decentralized manner, reducing reliance on traditional payment infrastructure.
