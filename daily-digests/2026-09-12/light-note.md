## Summary
LightNote is a free online workspace for managing bookmarks, notes, and cloud files with built-in AI assistance. It offers cross-device synchronization, unified tagging, and a lightweight, fast user experience.

## Key Features
- Unified workspace for bookmarks, notes, and cloud files with cross-device sync
- Built-in AI assistant for querying and organizing content across modules
- Rich text and Markdown dual-mode editing with real-time switching
- Global search and unified tagging system spanning all content types
- Free online service with mobile and desktop compatibility
