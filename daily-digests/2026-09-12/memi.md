## Summary
Memi is a read-only design engineering audit tool for coding agents that evaluates frontend interfaces for accessibility, hierarchy, state, responsive behavior, and design system consistency without modifying source files. It provides file-anchored evidence and deterministic reruns to verify fixes.

## Key Features
- File-anchored design findings with severity and confidence scores
- Deterministic reruns to verify fixes without source file changes
- Integration with coding agents (Codex, Claude, Cursor, Grok) via MCP or skills
- Supports React, React Native, SwiftUI, and cross-platform workflows
- GitHub Action for pull-request design CI and SARIF annotations

## Why It Matters for RAG Builders
Memi ensures coding agents produce high-quality, accessible, and consistent UI changes by providing rigorous design audits and verification before edits are made.
