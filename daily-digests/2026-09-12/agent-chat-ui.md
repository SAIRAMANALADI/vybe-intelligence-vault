## Summary
A local-first AI programming assistant with a Next.js frontend, persistent task server, and Electron desktop app. Supports multiple AI models, file operations, and secure API key management with AES-256-GCM encryption.

## Key Features
- Supports OpenAI, DeepSeek, Ollama, and OpenAI-compatible APIs
- File system operations (read/write/edit/search) and command execution
- Persistent SQLite-based conversation and task management with replayable SSE
- AES-256-GCM encrypted API key storage with secure logout deletion
- Electron desktop app with bundled SQLite and dynamic port allocation

## Why It Matters for RAG Builders
Provides a secure, local-first agent framework with tool integration and persistent task management, ideal for building AI-powered coding assistants.
