## Summary
A curated collection of 5,000+ public APIs with a CLI tool for discovery, filtering, and exploration. Includes an MCP server for AI-friendly API search and extensible architecture for adding new API sources.

## Key Features
- Comprehensive dataset of 5,000+ public APIs with metadata
- Smart CLI search with filtering by query, category, and authentication type
- MCP server for AI assistants to search APIs via natural language
- Extensible architecture with pluggable fetchers for new API sources
- Multiple output formats (text, JSON) and colored terminal output

## Why It Matters for RAG Builders
Provides a centralized, searchable dataset of public APIs that AI agents can leverage for RAG pipelines, reducing the need to manually curate API documentation.
