## Summary
Jean2 is a modular, server-first AI agent framework that acts as a hub for connecting LLMs, tools, and workflows without baked-in behavior. It enables users to build custom agents by opting into layers like memory, skills, and session search, all managed via files on disk for full transparency and control.

## Key Features
- Opt-in modular architecture with no default system prompts or tools
- Persistent memory and skills stored as files on disk, version-controllable
- Goal Mode for iterative task completion with evaluator feedback loops
- Session search powered by SQLite FTS5 for full-text history retrieval
- MCP integration for dynamic tool and OAuth management

## Why It Matters for RAG Builders
Jean2 provides a transparent, file-based foundation for building customizable AI agents without vendor lock-in, making it ideal for RAG builders who need full control over memory, tools, and workflows.
