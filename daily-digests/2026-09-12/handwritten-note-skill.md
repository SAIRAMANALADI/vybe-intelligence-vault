## Summary
A Claude Code skill that transforms any concept into a visually engaging, handwritten-style explainer note with customizable layouts and brand themes. It automates content structuring and design to produce shareable, single-page visual explainers.

## Key Features
- Automated layout selection based on content type (e.g., flow, cycle, comparison)
- 14 customizable brand themes with distinct visual styles
- Responsive HTML output with dark/light mode support
- Integration with Claude Code for seamless workflow
- Generates shareable artifacts (HTML + screenshots) for documentation

## Why It Matters for RAG Builders
It streamlines the creation of visually appealing, structured explainers for complex AI concepts, making RAG documentation more accessible and engaging for end-users.
