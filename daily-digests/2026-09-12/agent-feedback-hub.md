## Summary
A lightweight, self-hosted feedback widget and MCP server that enables AI coding agents to capture, analyze, and act on real-time developer feedback during code generation sessions. It dynamically adjusts agent behavior based on developer preferences and sentiment, fostering a continuous learning loop for personalized coding assistance.

## Key Features
- Real-time feedback injection for AI agents during code generation sessions
- Multilingual, responsive React-based feedback widget with dark mode support
- Dual AI backend integration (OpenAI, Claude) and local LLM support (Ollama)
- Continuous learning via feedback profiles stored in YAML/JSON for personalized agent behavior
- Mermaid architecture diagrams and detailed API integration documentation

## Why It Matters for RAG Builders
It enables AI coding agents to dynamically adapt to developer preferences in real time, creating a personalized and efficient coding experience that evolves with user feedback.
