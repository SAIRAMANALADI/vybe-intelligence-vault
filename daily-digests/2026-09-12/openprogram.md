## Summary
OpenProgram is a self-programming AI assistant framework that enables users to capture, automate, and refine workflows through agentic programming. It combines deterministic Python code with LLM-driven decision-making to create trustworthy, self-evolving agents with a focus on multi-agent systems and workflow orchestration.

## Key Features
- Agentic Function primitive: Python functions with LLM-driven execution where docstrings define system prompts and arguments define inputs, blending deterministic code with flexible LLM decisions.
- DAG Context for native multi-agent systems: Addressable nodes enable spawn, message passing, forking, and safe file operations via git worktrees, ensuring structured and isolated agent interactions.
- Agentic Workflow with code gates: Python enforces critical steps while LLMs handle judgment, enabling self-evolving agents that edit their own functions and hot-load changes dynamically.
- Event Infrastructure: Unified event bus for subsystems like auth, context, and memory, allowing proactive policies and real-time monitoring of agent activities.
- Built-in browser integration: Multi-page computer use, downloads, and agent-controlled page interactions with persistent state and tool support.

## Why It Matters for RAG Builders
OpenProgram provides a structured yet flexible framework for building trustworthy, self-evolving multi-agent systems that balance deterministic code with LLM-driven decisions, making it essential for RAG builders seeking reliable automation and workflow orchestration.
