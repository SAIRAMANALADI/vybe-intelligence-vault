## Summary
A high-performance Model Context Protocol (MCP) server for the USPTO Patent Trial and Appeal Board (PTAB) Open Data Portal API, enabling token-saving context reduction, hybrid document extraction, and seamless cross-MCP integration for patent lifecycle analysis.

## Key Features
- Token-saving context reduction with 80-99% response size reduction
- Hybrid document extraction pipeline (PyPDF2 → Mistral OCR → Docling)
- Seamless cross-MCP integration with USPTO Patent File Wrapper (PFW) MCP
- User-customizable field sets via YAML for tailored patent data retrieval
- Secure browser downloads with 7-day persistent encrypted links

## Why It Matters for RAG Builders
It provides essential patent lifecycle data and document extraction capabilities for RAG systems, enabling accurate and efficient retrieval of USPTO PTAB documents with minimal token overhead.
