## Summary
Pace is a terminal-based coding agent that provides an interactive TUI for interacting with LLMs, supporting sessions, undo, file operations, and advanced features like subagents, MCP integration, and context compaction.

## Key Features
- Interactive terminal-based TUI with mouse support and keyboard shortcuts
- Supports multiple LLM providers (OpenAI, Anthropic, Fireworks, etc.) with model switching and variants
- Context compaction to manage long conversations efficiently
- Subagents for specialized tasks (e.g., code exploration, review)
- MCP integration for external tool servers and file system access

## Why It Matters for RAG Builders
