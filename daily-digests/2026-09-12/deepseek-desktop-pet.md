## Summary
A desktop AI companion application that integrates with DeepSeek's API to provide an interactive Q-version virtual pet. It features dual-role support, long-term memory, tool calling, and proactive care mechanisms, all rendered via PySide6 for a seamless user experience.

## Key Features
- Dual-role system (V4 Flash and V4 Pro) with independent models and memories
- 15+ integrated tools for system interaction (e.g., weather, reminders, file management)
- Long-term memory system with role-isolated recall and forgetting mechanisms
- Proactive care system with chain-based wake-up and scheduled check-ins
- Live2D and static rendering modes with transparent, draggable UI
