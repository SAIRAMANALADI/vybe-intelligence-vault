## Summary
Cyrene-Agent is a Windows desktop AI companion featuring a Live2D character (Cyrene) from the game Honkai: Star Rail, combining immersive role-playing chat with practical agent capabilities. It integrates memory engines, tool calling, voice interaction, and multi-platform access into a unified desktop experience.

## Key Features
- Live2D character-driven desktop companion with expressive animations and interactions
- CyreneHarness core engine for continuous agent loops with tool calling, state management, and checkpointing
- Multi-modal capabilities including voice interaction, TTS, ASR, and music playback
- Four specialized conversation modes: Chat, Work, Code, and Learn with tool integration
- Personalized memory system with L0/L1/L2 layers and DMAE-based Worldbook for long-term context

## Why It Matters for RAG Builders
