## Summary
MCP server providing real-time intercity bus travel data for Russia, including routes, prices, schedules, and transfers. Offers a remote endpoint and self-hostable solution for AI agents and applications.

## Key Features
- Real-time bus route and price data for 1,000+ cities and 4,500+ routes in Russia
- Tools for direct and transfer route searches with pricing and schedules
- Price-per-km index and regional statistics for budget planning
- MCP Apps UI integration for interactive route cards and departure boards
- Self-hostable with a compact data snapshot and weekly updates

## Why It Matters for RAG Builders
It provides essential real-time bus travel data for Russia, enabling AI agents to plan routes, compare prices, and assist users with accurate, up-to-date transportation options.
