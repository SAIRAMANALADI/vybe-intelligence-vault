## Summary
WeChat Visual Director is an open-source AI-powered tool that automates the layout and visual design of WeChat public account articles. It uses an agent to parse content, plan semantic structure, and generate visually appealing, theme-compatible drafts for publication.

## Key Features
- AI-driven semantic content structuring and layout planning for WeChat articles
- 12 pre-designed themes with consistent visual styles and typography
- Local visual editor for real-time content editing, theme switching, and image review
- Supports AI-generated images for article illustrations and covers (optional)
- Direct export to WeChat drafts or copyable rich text for manual publishing

## Why It Matters for RAG Builders
It streamlines the final mile of AI-generated content delivery by automating visual layout and design, reducing manual effort for WeChat publishers while ensuring professional presentation.
