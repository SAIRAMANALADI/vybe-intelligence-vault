## Summary
An AI agent that automates material property lookups from authoritative databases like NIST by driving a real browser to extract structured data (e.g., substance name, formula, molecular weight, CAS number) based on plain-English prompts. It includes an offline mock for testing and supports live runs with cost controls.

## Key Features
- Zero dependencies and offline-capable mock for local testing
- Structured data extraction from human-facing databases without selectors or scraping rules
- Cost controls and fail-safe mechanisms to prevent accidental spend
- Self-documenting runs with provenance tracking (frames, hashes, and metadata)
- Idempotent execution via derived submit keys to avoid duplicate runs

## Why It Matters for RAG Builders
It demonstrates how AI agents can reliably automate data extraction from complex, human-facing interfaces without brittle scraping rules, making it a blueprint for RAG pipelines needing real-time, accurate data from authoritative sources.
