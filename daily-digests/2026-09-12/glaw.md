## Summary
GLAW is an open-source virtual law firm AI agent system that orchestrates legal matters through an 8-stage pipeline, routing work to specialized departments and producing attorney work-product for licensed review. It includes a paid-agent market (X402) and Conway-style agent survival mechanics.

## Key Features
- Hard-gated 8-stage legal matter pipeline (intake → strategy → structure → draft → adversarial → file → docket → close) with no skipped steps
- 15 departments and 200+ source skills with deterministic routing and zero external dependencies
- X402 payment Worker enabling USDC-based chargeable agent services with Conway-style survival mechanics
- Attorney work-product generation (pleadings, contracts, dossiers) for licensed professional review, not legal advice
- MCP/API intake with adversarial red-teaming, citation verification, and UPL compliance gates

## Why It Matters for RAG Builders
GLAW provides a structured, auditable framework for automating complex legal workflows with multi-agent collaboration, making it essential for AI engineers building compliant, high-stakes agent systems.
