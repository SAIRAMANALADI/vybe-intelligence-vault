## Summary
AegisGov Contract Intelligence MCP provides real-time US government contract data for AI agents via a streamable HTTP server, enabling free searches and paid AI-driven bid analysis without API keys or signups.

## Key Features
- Real-time access to 33,000+ live US federal contract opportunities
- Free search and contract details via MCP-compatible endpoints
- AI-powered bid/no-bid analysis with scoring and risk assessment
- Dual-network USDC payments via x402 protocol (Base/Solana)
- Seamless integration with AI agents like Claude, GPT, and Cursor

## Why It Matters for RAG Builders
It eliminates the complexity of accessing SAM.gov data directly, providing AI agents with structured, real-time government contract intelligence and built-in monetization for advanced analysis.
