## Summary
This repository provides an MCP (Model Context Protocol) server that enables AI assistants to design and generate guitar presets for various hardware modelers like HeadRush Gigboard, Mooer, BOSS Waza Air, Yamaha THR, and Neural DSP Quad Cortex. Users can describe a desired tone, and the tool generates device-specific preset files and setup cards.

## Key Features
- Supports multiple guitar modelers (HeadRush, Mooer, BOSS, Yamaha, Neural DSP) with device-specific preset generation
- AI-driven tone translation from real-world hardware to device models
- Generates preset files (.rig, .mo, .tsl) and human-readable setup cards
- Includes CLI for catalog browsing, translation, and preset design
- Embedded agent guide for signal-chain topology and workflow constraints
