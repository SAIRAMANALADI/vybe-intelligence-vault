## Summary
SEOHEAD Tools is a local-first evidence and audit-automation toolkit for SEO specialists and tool-calling AI agents. It analyzes Screaming Frog crawl exports, adds bounded live and infrastructure checks, and produces structured audits, task backlogs, and reports via CLI and local MCP.

## Key Features
- 42 core CLI/MCP tools and 5 Screaming Frog workflow tools for evidence collection and analysis
- 96-check registry for Screaming Frog export analysis with deterministic checks and structured output
- Local MCP server for tool-calling AI agents with no telemetry or hosted dependencies
- Support for multiple report formats (XLSX, DOCX, CSV, Markdown, JSON) and agent workflow skills
- Bounded live URL, infrastructure, and rendering checks without requiring full crawls

## Why It Matters for RAG Builders
It provides a critical evidence and automation layer for SEO audits, enabling AI agents to efficiently collect, analyze, and structure data from crawls and live checks while preserving uncertainty and missing measurements for accurate interpretation.
