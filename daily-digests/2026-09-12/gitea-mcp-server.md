## Summary
A Model Context Protocol (MCP) server that auto-generates ~400 tools and resources for LLM agents to interact with Gitea and Forgejo instances, enabling seamless integration with version control systems for AI-driven workflows.

## Key Features
- Auto-generates ~400 tools from Gitea/Forgejo API specs for LLM agents
- Supports lazy loading, permission filtering, and tool annotations for optimized agent interactions
- Provides MCP resources for URI-based data access (e.g., `gitea://repos/{owner}/{repo}`)
- Offers HTTP and stdio transport modes with Docker support for flexible deployment
- Includes workflow guides and customizable tool metadata via `mcp_extensions.yaml`

## Why It Matters for RAG Builders
This MCP server enables AI agents to directly interact with Gitea and Forgejo, unlocking automation for repository management, issue tracking, and collaboration workflows within AI-driven pipelines.
