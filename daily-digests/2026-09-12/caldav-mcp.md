## Summary
A Model Context Protocol (MCP) server that integrates iCloud Calendar via CalDAV, enabling AI clients to manage calendar events, alarms, and recurring schedules with native support for multiple reminders and Apple-specific extensions.

## Key Features
- Native support for multiple VALARM reminders per event in iCloud Calendar
- Full CRUD operations for calendar events with ETag-based optimistic concurrency
- Supports timed, all-day, and recurring events with RFC 5545 recurrence rules
- Works with both stdio and Streamable HTTP MCP transports
- Hardened container deployment with read-only filesystem and non-root user

## Why It Matters for RAG Builders
Enables AI clients to interact with iCloud Calendar events and reminders programmatically, expanding RAG capabilities to include time-sensitive data and scheduling automation.
