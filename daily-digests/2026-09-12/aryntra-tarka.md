## Summary
Aryntra Tarka is a local-first autonomous AI agent framework that enables transparent multi-step planning, tool invocation, and streaming responses with persistent conversation history. It abstracts LLM interactions into structured execution plans for better control and observability.

## Key Features
- Autonomous multi-step planning with intent understanding
- Transparent tool execution with a modular registry for extensibility
- Real-time streaming responses via Server-Sent Events (SSE)
- Persistent conversation history using SQLite for state management
- Provider abstraction for LLM and tool integrations (e.g., Ollama)

## Why It Matters for RAG Builders
It provides a structured, transparent framework for building autonomous AI agents that plan, execute tools, and stream responses, making it essential for developers seeking modular and observable agentic systems.
