## Summary
Constellation MCP Server provides AI coding assistants with intelligent access to codebase structure, dependencies, and relationships by extracting and analyzing metadata locally. It securely transmits only structural insights to a cloud-based knowledge graph, enabling rapid queries without exposing source code.

## Key Features
- Local metadata extraction without transmitting source code
- Integration with AI coding assistants via MCP protocol
- Secure cloud-based knowledge graph for rapid queries
- Branch isolation for discrete code intelligence per git branch
- Comprehensive documentation and plugin support

## Why It Matters for RAG Builders
It enables AI coding assistants to understand and query codebases intelligently while preserving privacy by only processing metadata, not raw source code.
