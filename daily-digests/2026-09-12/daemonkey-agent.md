## Summary
Daemonkey is a local-first AI companion daemon that runs on your own machine, designed to remember users, grow alongside them, and extend its own capabilities autonomously. It emphasizes a six-layer memory system, self-healing, and self-upgrading features while ensuring data privacy and user control.

## Key Features
- Six-layer memory system for persistent, context-aware interactions
- Self-healing and self-upgrading architecture with rollback capabilities
- Extensible via Playbooks, MCP servers, custom tools, and external SKILLs
- Closed-loop feedback system for continuous learning and adaptation
- Cross-platform support (Windows, macOS, Linux) with experimental features

## Why It Matters for RAG Builders
Daemonkey provides a privacy-preserving, self-evolving AI companion framework that prioritizes user memory and relationship over generic skills, making it ideal for RAG builders seeking customizable, long-term agent interactions.
