## Summary
Agent Norms Foundation provides a structured artifact framework for organizing agent rules, observations, deferred tasks, and decision logs within a project's `agent/` directory. It establishes conventions like ISO-8601-UTC filenames and purpose-over-category organization to ensure chronological sorting and clarity.

## Key Features
- Defines four core artifact directories: rules, observations, deferred, and log
- Enforces ISO-8601-UTC filenames for chronological sorting and timezone declaration
- Supports project-wide status reports and deferred item tracking
- Integrates via Git subtree for seamless version control and updates
- Encourages purpose-over-category organization for clarity

## Why It Matters for RAG Builders
It provides a standardized way to manage agent artifacts and decision logs, ensuring consistency and traceability in AI agent projects.
