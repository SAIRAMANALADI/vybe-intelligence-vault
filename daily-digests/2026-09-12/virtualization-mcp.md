## Summary
A Model Context Protocol (MCP) server and webapp for managing virtual machines, sandboxes, and development environments across VirtualBox, Hyper-V, and Windows Sandbox. Enables AI assistants like Claude Desktop to spin up, control, and monitor VMs programmatically.

## Key Features
- Multi-hypervisor support (VirtualBox, Hyper-V, Windows Sandbox)
- Programmatic VM lifecycle management (create, start, stop, snapshot, clone)
- Unattended OS installation for Windows VMs
- noVNC-based browser console access for VMs
- Fleet dashboard for monitoring and launching MCP webapps

## Why It Matters for RAG Builders
Enables AI assistants to dynamically provision and manage isolated environments for testing, development, and debugging, bridging the gap between AI workflows and real-world system interactions.
