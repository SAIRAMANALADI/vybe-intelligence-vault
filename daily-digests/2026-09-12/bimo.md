## Summary
Bimo is a proprietary AI chat workspace and agent that enables real-time streaming interactions via a plain JavaScript frontend and Flask backend. It supports multi-modal capabilities including document parsing, vision processing, voice interaction, and image generation, while integrating with Supabase for authentication and storage and NVIDIA for inference.

## Key Features
- Real-time streaming responses via Server-Sent Events with Markdown, code, and KaTeX rendering
- Multi-model routing for chat, vision, image generation, and voice interactions
- Passwordless authentication via Supabase OAuth with ES256 JWT verification
- Document parsing for PDF, DOCX, XLSX, PPTX, and ZIP files
- Server-side cancellation for immediate response halting and resource management
