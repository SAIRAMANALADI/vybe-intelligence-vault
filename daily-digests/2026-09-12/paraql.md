## Summary
ParaQL is a parallel multi-writer relational database that combines libSQL (a SQLite fork with native vector support) and Autobee for deterministic, corruption-resistant writes. It supports encryption, compression, and vector search, enabling P2P SQL-based applications with robust data integrity.

## Key Features
- Native vector data types and similarity search via libSQL
- Deterministic multi-writer synchronization with Autobee
- Built-in encryption (256-bit) and compression (zlib)
- Deterministic oplog for corruption-resistant writes
- Cross-platform support (Android, iOS, macOS, Linux, Windows)

## Why It Matters for RAG Builders
ParaQL enables scalable, secure, and P2P-compatible vector search and relational queries, critical for decentralized AI applications requiring robust data integrity and multi-writer support.
