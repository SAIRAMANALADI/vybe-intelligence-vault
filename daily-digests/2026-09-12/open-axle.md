## Summary
Open Axle is a CLI-based AI agent framework designed for software developers, enabling them to create and customize AI-driven tools for file system operations, network interactions, and domain-specific tasks. It supports integration with OpenAI-compatible endpoints and includes built-in skills for database access, SSH, and API calls.

## Key Features
- Customizable skills via Python decorators and configuration files
- Supports OpenAI-compatible endpoints and deepseek-v4-flash
- Built-in skills for file system, database, SSH, and API operations
- Interactive CLI with commands for skill management and conversation control
- Modular architecture with skill-specific configuration
