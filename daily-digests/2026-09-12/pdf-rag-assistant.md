## Summary
A tool for building PDF Q&A systems using RAG (Retrieval-Augmented Generation) with OpenAI and ChromaDB, enabling fast, local answers from documents like policies, contracts, and resumes.

## Key Features
- Local document processing for privacy and speed
- Integration with OpenAI for LLM-powered answers
- Uses ChromaDB for efficient vector storage and retrieval
- Supports PDFs, contracts, and resumes as input
- Fast, context-aware Q&A from unstructured documents

## Why It Matters for RAG Builders
It provides a practical, local-first approach to building RAG systems for document Q&A, reducing dependency on cloud services while ensuring fast and private responses.
