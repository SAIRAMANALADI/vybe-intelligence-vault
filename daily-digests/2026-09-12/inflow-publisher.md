## Summary
A dependency-free Python CLI and installable Agent Skill for publishing posts, Markdown articles, images, and attachments to an inflow instance. It enables scheduled AI agents to publish content without exposing API keys in prompts or command arguments.

## Key Features
- Publish short posts and full Markdown articles with optional captions
- Upload images and attachments via presigned upload flow
- Create, edit, publish, and soft-delete drafts with optimistic locking
- Preserve API key security by excluding it from prompts and logs
- Retry timeouts and server errors with idempotency key support

## Why It Matters for RAG Builders
It enables AI agents to securely and programmatically publish structured content to inflow instances, streamlining workflow automation for RAG systems.
