## Summary
dvr provides a CLI, Python library, and MCP server to automate Blackmagic Design's DaVinci Resolve, transforming its fragile scripting API into a clean, idempotent, and LLM-friendly interface for editing, color grading, rendering, and delivery workflows.

## Key Features
- Clean, typed Python library and CLI for DaVinci Resolve automation
- MCP server for seamless integration with LLM agents (e.g., Claude, Cursor)
- Idempotent operations (e.g., `ensure`, `apply`) for reliable state management
- Structured JSON output and error decoding to eliminate silent `None` failures
- Declarative specs (YAML) for reproducible project and timeline configurations

## Why It Matters for RAG Builders
It bridges the gap between DaVinci Resolve's fragile scripting API and modern AI-driven automation, enabling reliable, structured, and agent-friendly control over video editing and rendering workflows.
