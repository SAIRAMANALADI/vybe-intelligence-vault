## Summary
A local-first, ambient AI desktop companion that acts as a thought-driven 'pet agent' with multi-provider AI integration, computer use capabilities, and NYC-branded visual design. It combines agentic reasoning with expressive embodiment across desktop, CLI, and TUI surfaces.

## Key Features
- Thought-driven agent loop with explicit reasoning for every action
- Multi-provider AI support (Ollama, OpenAI, Anthropic, etc.) with agent federation
- Computer use capabilities (mouse, keyboard, screen, apps) under permission control
- NYC-branded visual design with expressive, non-generic pet embodiment
- Cross-platform support (desktop, CLI, TUI, mobile) with a single runtime

## Why It Matters for RAG Builders
It provides a unique, local-first agent framework for building expressive, thought-driven AI companions that integrate deeply with user workflows and peripherals.
