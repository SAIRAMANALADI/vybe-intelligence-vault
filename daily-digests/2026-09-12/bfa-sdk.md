## Summary
A framework and SDK implementing the Backend for Agents (BFA) pattern and IRC-A protocol, enabling semantic routing of agents and tools using FAISS-based vector search, secure-by-design boundaries, and standardized abstractions for A2A agents and MCP servers.

## Key Features
- FAISS-based semantic routing for dynamic agent/tool discovery using vector search
- Standardized `BFAAgent` and `BFAMCP` abstractions for A2A agents and MCP servers
- Asymmetric zero-trust security with channel masking and ephemeral tokens
- Multi-provider embedding support (local, OpenAI, mock) for flexible deployment
- Serverless-ready architecture with Mangum adapter and cloud-based embeddings

## Why It Matters for RAG Builders
It provides a standardized, secure, and scalable way to orchestrate and route AI agents and tools using semantic search, reducing integration complexity for RAG and AI systems.
