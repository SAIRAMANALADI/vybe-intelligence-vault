## Summary
SayDo is a conformance testing framework that verifies whether a tool performs exactly as declared in a machine-readable contract. It generates hash-chained, signed receipts for verifiable audits, ensuring tools do not silently deviate from their stated behavior.

## Key Features
- Machine-readable declarations signed by publishers to define tool behavior
- Sandboxed execution with network egress monitoring to detect data leaks
- Hash-chained, signed receipts verifiable offline in a browser without trust assumptions
- Counterfactual testing to distinguish input-dependent from input-independent network calls
- Automated CI integration with GitHub Actions for real-time conformance checks

## Why It Matters for RAG Builders
SayDo provides a critical layer of trust for RAG builders by ensuring tools behave exactly as declared, preventing silent deviations that could compromise system reliability or security.
