## Summary
aeman is a short-term planning system for engineering teams that uses a git repository as its single source of truth. It provides live, collaborative day and team boards with color-coded zones for planned, unplanned, and urgent work, while exposing a REST API and MCP server for AI agent integration.

## Key Features
- Git repository as the single source of truth with no proprietary database
- Live WebSocket updates for real-time collaboration across teams
- Embedded React SPA with a Go-based REST API and MCP server for AI agents
- Color-coded zones (Gray, Green, Yellow, Red) for task prioritization and visibility
- Triage system for long-term planning and debt tracking

## Why It Matters for RAG Builders
aeman enables AI agents to interact with engineering planning data in real-time via MCP, providing a structured and git-backed way to manage tasks, sprints, and unplanned work while ensuring transparency and collaboration.
