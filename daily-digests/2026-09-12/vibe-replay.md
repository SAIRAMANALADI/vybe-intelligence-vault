## Summary
vibe-replay converts AI agent coding sessions (Claude Code, Cursor, Codex, Pi) into interactive, shareable HTML replays with animated playback, insights, and analytics. It enables users to review, share, and learn from AI-assisted development workflows with zero configuration.

## Key Features
- Zero-config generation of self-contained HTML replays from AI sessions
- Cross-platform support for Claude Code, Cursor, Codex, and Pi sessions
- Local dashboard for browsing, searching, and analyzing sessions with heatmaps and cost tracking
- Automatic secret redaction and privacy-preserving data handling
- Claude Code plugin and Agent Skills integration for seamless workflow automation

## Why It Matters for RAG Builders
It provides a critical tool for AI engineering teams to document, share, and analyze AI-assisted coding sessions, enhancing transparency and collaboration in development workflows.
