## Summary
DevIntern automates the conversion of tracker tickets (e.g., Jira, Linear, GitHub Issues) into pull requests using coding agents like Claude Code or Codex, with self-review and unattended automation capabilities.

## Key Features
- Turns tracker tickets into pull requests using any coding agent
- Self-review loop for agents to fix their own diffs before human review
- Supports multiple trackers (Jira, Linear, GitHub Issues, etc.) and agents (Claude, Codex, Cursor)
- Unattended automation with scheduled pickup and crash recovery
- BYOK (Bring Your Own Keys) for billing via existing provider contracts

## Why It Matters for RAG Builders
DevIntern streamlines the integration of AI coding agents into existing workflows, enabling seamless automation of ticket resolution and reducing manual intervention for RAG/AI stack builders.
