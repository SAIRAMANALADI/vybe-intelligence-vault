## Summary
A Model Context Protocol (MCP) server that enables AI tools to analyze local images, clipboard screenshots, or Base64-encoded image data by sending them to compatible VLM (Vision Language Model) APIs. It returns structured analysis results for seamless integration into AI workflows.

## Key Features
- Supports analysis of local image files (JPEG, PNG, BMP, TIFF, WebP)
- Processes clipboard screenshots across Windows, Linux, macOS, and WSL
- Handles Base64-encoded image data for direct API integration
- Zero-dependency single binary with cross-platform compilation support
- Structured JSON-RPC communication for seamless AI tool integration

## Why It Matters for RAG Builders
It simplifies the integration of local image analysis into AI workflows by providing a standardized MCP server that bridges the gap between AI tools and VLM APIs.
