## Summary
Xylem is a local-first multi-agent coordination stack that provides durable memory, decentralized coordination, and a knowledge lifecycle for AI coding agents. It enables agents to remember decisions, avoid conflicts, and leverage a phone as a peer in the agent mesh via Cloudflare Workers.

## Key Features
- Habit layer for automatic agent discipline (memory, coordination, recall)
- Local and remote transports (stdio and Cloudflare Workers) with identical protocols
- Version-aware habit blocks with automatic updates and checks
- Degraded mode support for offline or missing components
- Surgical uninstallation preserving non-Xylem components

## Why It Matters for RAG Builders
Xylem solves critical coordination and memory challenges in multi-agent AI development by embedding discipline into agent workflows, ensuring decisions persist and agents collaborate without conflicts.
