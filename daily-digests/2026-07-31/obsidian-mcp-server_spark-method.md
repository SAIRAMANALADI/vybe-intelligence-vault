## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Obsidian vaults, providing 25 tools for note management, entity graph operations, and vault intelligence across multiple workspaces.

## Key Features
- 25+ Obsidian vault tools including note CRUD, search, and capture operations
- Multi-workspace support with scope-based access control
- Entity graph operations (resolve, query, backlinks, neighbors, timeline)
- Automatic template application for notes and events
- OAuth 2.0 + PKCE authentication for secure AI assistant integration

## Why It Matters for RAG Builders
It bridges AI assistants with Obsidian vaults, enabling structured knowledge management and retrieval for RAG pipelines.
