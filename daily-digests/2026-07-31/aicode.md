## Summary
AiCode is an AI-powered programming tool designed to run on Android devices, featuring an integrated terminal, AI Agent with multi-provider support, and Model Context Protocol (MCP) integration for dynamic tool expansion.

## Key Features
- AI Agent supporting multiple providers (Anthropic, OpenAI) with tool integration for file operations and shell execution
- Built-in terminal with PRoot Alpine Linux container for a full Linux command-line environment
- Model Context Protocol (MCP) client for dynamic tool capability expansion via remote servers
- Git integration and remote workspace synchronization via SFTP/FTP
