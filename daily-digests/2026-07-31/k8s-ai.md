## Summary
A Kubernetes-based GitOps repository for deploying and managing AI workloads, including LLM inference services, model serving infrastructure, and AI application UIs like Open WebUI, ComfyUI, and opencode. It leverages Flux CD for continuous deployment and integrates MCP servers for enhanced AI workflows.

## Key Features
- GitOps-based AI workload deployment with Flux CD for continuous delivery
- Supports multiple LLM inference engines (Ollama, llama.cpp, vLLM, KServe) with GPU acceleration
- Includes AI application UIs (Open WebUI, ComfyUI, opencode) and workflow automation (n8n)
- Integrates MCP servers for Kubernetes, Grafana, GitHub, and other integrations
- Provides persistent storage, backups, and replication for AI workloads
