## Summary
DashClaw is a fail-closed approval layer that intercepts destructive actions from AI coding agents before execution, requiring human approval for high-risk operations. It provides a tamper-evident audit trail, calibrated interruptions, and enforcement verification for unattended agent sessions.

## Key Features
- Fail-closed intercept: blocks destructive tool calls before execution with exit code 2
- Remote and async approval: resolve approvals from CLI, PWA, Telegram, Discord, or web inbox
- Tamper-evident audit: Ed25519-signed receipts and replayable decision ledger with public verification
- Calibrated interruptions: distribution-free controller for false-interruption bounds
- Enforcement liveness probe: synthetic actions verify real-time enforcement integrity

## Why It Matters for RAG Builders
DashClaw provides critical safety and governance for unattended AI agent sessions by intercepting destructive actions before execution, ensuring human oversight and tamper-proof audit trails in RAG and AI stacks.
