## Summary
AgentHook enables AI agents to generate character-consistent user-generated content (UGC) videos and images by creating reusable AI influencers. It provides tools for video/image generation, captioning, and influencer creation via CLI, MCP server, or skills integration.

## Key Features
- Create reusable AI influencers for consistent character portrayal across videos and images
- Multi-format output: videos, images, captions, and transcripts
- Integration options: CLI, MCP server, or skills for agents like Claude Code and Cursor
- Prepaid credits with automatic refunds for failed runs
- Permanent CDN URLs for generated content
