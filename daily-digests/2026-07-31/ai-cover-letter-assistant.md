## Summary
A Streamlit-based AI assistant that generates tailored job application materials like cover letters, follow-up messages, and interview talking points by analyzing a job posting and user's resume. It exports formatted .docx files for professional use.

## Key Features
- Generates tailored cover letters, follow-up messages, and interview talking points from job postings and resumes
- Supports DOCX and text-based PDF resume uploads with extraction and parsing
- Exports professionally formatted .docx cover letters with Times New Roman, 12pt font, and clean layout
- Includes optional fields for skills, certificates, address, and career level to customize outputs
- Provides editable preview before final export to allow user revisions
