## Summary
Mitra is a modular, stateless Model Context Protocol (MCP) server that integrates Clockify, WakaTime, and Azure DevOps, enabling developers and AI assistants to fetch project data, manage work items, and log time entries via a unified workflow.

## Key Features
- Stateless design with credential flexibility (headers or environment variables)
- Auto-discovery integration architecture for easy extensibility
- Supports Clockify, WakaTime, and Azure DevOps out of the box
- Composite workflows for cross-integration tasks (e.g., time logging)
- Local (stdio) and remote (SSE) deployment modes

## Why It Matters for RAG Builders
Mitra provides a unified, extensible interface for AI assistants to interact with project management and time tracking tools, simplifying RAG pipeline integrations with real-world workflows.
