## Summary
Ainu-MCP is a hosted Model Context Protocol (MCP) server that provides unified access to Ainu-language resources, including a glossary editor, corpus search, multi-dictionary lookup, grammar references, morphology tools, and script conversion utilities. It enables LLMs to interactively edit and research Ainu-language content in real-time.

## Key Features
- Hosted Cloudflare Worker MCP server with Streamable-HTTP protocol for seamless LLM integration
- Real-time glossary editing via Google Sheets with GitHub OAuth authentication and optimistic locking
- Comprehensive Ainu corpus search (~195k aligned sentences) and frequency analysis tools
- Multi-dictionary lookup across 11 dictionaries with reverse lookup and substring search
- Script conversion between Latin, Katakana, and Cyrillic with automatic detection

## Why It Matters for RAG Builders
It provides a unified, real-time interface for LLMs to interact with Ainu-language resources, enabling accurate and context-aware generation for under-resourced languages.
