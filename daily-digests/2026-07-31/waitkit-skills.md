## Summary
A specialized AI agent skill for building waitlist signup flows using WaitKit, providing SDK integration, React components, and error handling for production-ready waitlist management.

## Key Features
- Zero-dependency `waitkit` npm package with typed client for SDK integration
- React `useWaitlist` hook with built-in loading and error states
- Raw API fetch-based integration for non-JavaScript projects
- Framework-specific environment variable conventions (Vite, Next.js, Remix, Astro, CRA)
