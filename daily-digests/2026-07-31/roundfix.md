## Summary
Roundfix is a local-first Go CLI that resolves pull request review feedback and executes Spec Task Graphs using local coding agents like Codex, Claude, or OpenCode. It automates feedback resolution, task execution, and commit verification while ensuring clean, verified outcomes with configurable boundaries.

## Key Features
- Resolves CodeRabbit review feedback locally with agent-driven changes and verification
- Executes Spec Task Graphs in isolated worktrees with one commit per verified task
- Supports detached runs for unattended execution and monitoring via `attach` and `events`
- Provides machine readiness diagnostics with `doctor` and lifecycle management with `gc`, `archive`, and `stop`
- Offers interactive TUI for run discovery and live monitoring with color-coded state indicators

## Why It Matters for RAG Builders
Roundfix streamlines AI-assisted engineering workflows by automating review resolution and task execution with local agents, ensuring clean, verified outcomes while reducing manual intervention.
