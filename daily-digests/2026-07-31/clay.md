## Summary
Clay is a self-hosted, multiplayer workspace for Claude Code and Codex that enables real-time collaboration, persistent AI teammates (Mates), and structured decision-making. It serves as a unified dashboard for managing projects, sessions, and AI agents while ensuring vendor neutrality and data ownership.

## Key Features
- Multi-vendor support (Claude Code and Codex) with seamless switching
- Persistent AI teammates (Mates) with memory and roles for long-term collaboration
- Structured debates for decision-making with AI panelists
- Ralph Loop for autonomous coding and iterative task execution
- OS-level isolation and permissions for multi-user environments

## Why It Matters for RAG Builders
Clay provides a vendor-neutral, self-hosted platform for orchestrating AI agents and human collaboration, ensuring data ownership and flexibility for RAG builders.
