## Summary
A plugin-based toolkit for iOS release quality assurance that identifies App Store review risks, repairs XCUITest testability failures, and adds reproducible iOS Simulator checks with evidence-rich artifacts. It bundles three agent skills for privacy compliance, UI testability, and AI-driven simulator validation.

## Key Features
- Automated App Store review risk detection (privacy manifests, entitlements, StoreKit, etc.)
- XCUITest testability repair for element lookup failures and accessibility issues
- Evidence-rich iOS Simulator checks with screenshots, logs, and `.xcresult` artifacts
- Provider-agnostic AI UI checks integrated via GitHub Actions or Python CLI
- Local execution with no repository content uploads, ensuring data privacy

## Why It Matters for RAG Builders
It streamlines iOS release quality control by automating critical compliance and testability checks, reducing manual review effort and improving App Store submission success rates.
