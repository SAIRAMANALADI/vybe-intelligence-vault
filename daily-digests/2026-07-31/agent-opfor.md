## Summary
OPFOR is an open-source adversary emulation tool designed to red-team AI agents, LLM applications, and MCP servers by simulating real-world attacks. It provides multiple interfaces (CLI, browser extension, MCP server, SDK) to test security, safety, and robustness against OWASP and EU AI Act standards.

## Key Features
- Multi-mode execution: CLI, browser extension, MCP server, SDK, and IDE skills for comprehensive testing access.
- Full OWASP coverage: Tests against LLM Top 10, Agentic AI Top 10, MCP Top 10, API Security Top 10, and EU AI Act bias suites.
- Trace-aware testing: Integrates with Langfuse and Netra to evaluate intermediate tool calls, memory, and multi-turn reasoning.
- Autonomous red-teaming: `opfor hunt` runs adaptive multi-agent attack campaigns with no manual config required.
- Reproducible reports: Generates detailed HTML and JSON reports for CI/CD integration and auditability.
