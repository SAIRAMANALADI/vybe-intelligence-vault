## Summary
mcpward is a black-box security and contract testing tool for Model Context Protocol (MCP) servers, designed to detect rug-pulls, tool poisoning, schema drift, and protocol violations before they impact AI agents. It provides deterministic, machine-readable reports for local and CI environments.

## Key Features
- Rug-pull detection via hashed tool descriptions and lockfile snapshots
- Tool-poisoning heuristics for injection patterns and hidden unicode characters
- Drift detection with breaking change classification (schema, annotations, descriptions)
- Behavioral test suites with JSONPath assertions and latency budgets
- Multiple reporters (console, JSON, SARIF, JUnit) for CI integration

## Why It Matters for RAG Builders
mcpward ensures MCP servers remain secure and reliable for AI agents by catching critical issues like schema drift and tool poisoning before they reach production.
