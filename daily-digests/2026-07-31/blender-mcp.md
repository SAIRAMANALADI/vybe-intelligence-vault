## Summary
Blender MCP enables AI-driven 3D modeling and automation in Blender via the Model Context Protocol (MCP). It allows natural language instructions to generate, edit, and export 3D assets, materials, and animations, with optional live GUI feedback and integration with generative AI models.

## Key Features
- Natural language 3D scene creation and editing with Blender
- Headless and live GUI modes for batch and interactive workflows
- 48+ MCP tools for mesh operations, materials, lighting, animation, and exports (GLB, VRM, FBX, USD)
- Integration with generative AI models (Rodin, Tripo, Hunyuan) for mesh generation and refinement
- Webapp dashboard and Tauri-based native app for enhanced usability and monitoring

## Why It Matters for RAG Builders
It bridges AI agents with Blender, enabling automated 3D asset creation and editing for RAG pipelines requiring spatial or visual data.
