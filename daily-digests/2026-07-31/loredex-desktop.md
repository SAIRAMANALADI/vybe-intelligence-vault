## Summary
Loredex Desktop is a native cross-platform application (macOS, Windows, Linux) that provides a user interface for managing and interacting with loredex vaults—plain markdown folders stored in Git. It offers a unified control surface for reading, curating, and synchronizing agent knowledge, including handoffs, contracts, and real-time sync with team repositories.

## Key Features
- Native desktop app for macOS, Windows, and Linux with a unified UI for managing loredex vaults
- In-app MCP server for seamless agent integration and real-time vault access
- Handoff lifecycle management with inbox/outbox lanes, acceptance workflows, and threading
- Zoomable atlas (SVG graph) for visualizing vault structure and relationships
- Live git synchronization with remote repositories and background poller for real-time updates

## Why It Matters for RAG Builders
It provides a centralized, user-friendly interface for managing and interacting with agent knowledge vaults, enabling seamless collaboration and synchronization across teams while integrating with MCP-compatible AI agents.
