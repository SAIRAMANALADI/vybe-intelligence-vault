## Summary
ExpenseFlow Agent is an agentic receipt intelligence and expense automation system that processes receipts via OCR, uses a DeepSeek-powered AI agent to extract structured fields, validate policies, and match corporate card transactions, before automating expense form submissions with Playwright. It supports human-in-the-loop review, audit trails, and fallback rule-based processing.

## Key Features
- OCR-first receipt intake with structured field extraction via DeepSeek agent
- Corporate card transaction matching and policy compliance validation
- Human-in-the-loop review for low-confidence or policy-flagged items
- Playwright-based automated expense form submission with audit trails
- Real-time agent interaction with step-by-step tool execution visibility

## Why It Matters for RAG Builders
It provides a controlled, auditable framework for AI-driven receipt processing and expense automation, bridging OCR, agentic reasoning, and browser-based form submission while ensuring compliance and human oversight.
