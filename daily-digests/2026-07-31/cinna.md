## Summary
Cinna is a customizable Telegram ReAct agent bot built with Go and Eino, designed to handle task-specific workflows like shopping lists and feedback collection. It leverages PostgreSQL for database-backed memory, supports configurable sub-agents, and ensures message privacy through encryption.

## Key Features
- Configurable sub-agents for specialized tasks (e.g., shopping lists, feedback collection)
- PostgreSQL-backed memory with long-term context retention and encryption for privacy
- Telegram long polling (dev) and webhook (prod) support
- Intent classification and action routing for dynamic workflows
- Multi-stage agent graph with modular lambda functions for extensibility

## Why It Matters for RAG Builders
Cinna provides a modular framework for building task-specific ReAct agents with database-backed memory and encryption, making it valuable for developers integrating AI-driven workflows into Telegram or similar platforms.
