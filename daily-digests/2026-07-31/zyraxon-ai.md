## Summary
ZYRAXON-AI is an all-in-one autonomous AI agent framework that provides full computer control for coding, automation, research, and system management. It operates as a desktop app or CLI tool with multi-model support, persistent memory, and self-evolution capabilities.

## Key Features
- Full computer access (file system, commands, web browsing, installations)
- Multi-agent system with Build, Plan, Beast, and General modes
- Persistent SQLite-backed memory across sessions
- Self-evolution tool to install MCP servers dynamically
- Cross-platform desktop app (Windows, macOS, Linux) and CLI support
