## Summary
A monorepo for the R/W Book Club, featuring a public static website built with Eleventy, a private knowledge corpus generated from SQLite data, and Oliver—a Discord agent that interacts with the corpus using Claude. The system includes a members' web app for self-service editing and data management.

## Key Features
- Monorepo structure with website, corpus, and agent components
- SQLite as the source of truth with corpus regeneration from DB
- Oliver, a Discord agent that answers questions using the corpus and Claude
- Members' web app for self-service editing and data management
- Public website with reading journey, statistics, and LLM context files
