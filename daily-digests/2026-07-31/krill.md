## Summary
KRILL is an AI-powered terminal for analyzing and scoring new token launches on the Robinhood Chain (Virtuals Protocol). It provides real-time intelligence for traders by scanning, scoring, and explaining token launches through a lightweight UI and Cloudflare Worker-based API.

## Key Features
- Real-time scanning and scoring of new token launches on Robinhood Chain
- Terminal-based UI for interactive exploration of token data
- Cloudflare Worker API for low-latency on-chain data retrieval
- 31 unit tests ensuring API reliability and correctness
- Static frontend with no framework dependencies for simplicity
