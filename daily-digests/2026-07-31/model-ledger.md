## Summary
model-ledger is a model inventory and governance tool that discovers, tracks, and maps dependencies of deployed models across multiple platforms as an immutable, agent-queryable graph. It records every change as an append-only event log, enabling point-in-time reconstruction and compliance validation.

## Key Features
- Automated discovery of models, heuristics, and ETL pipelines across platforms
- Immutable append-only event log for full history and point-in-time reconstruction
- Automatic dependency graph mapping via typed input/output ports
- Native MCP server for AI agent integration and natural language queries
- Compliance validation against frameworks like SR 11-7, EU AI Act, and NIST AI RMF

## Why It Matters for RAG Builders
It provides a unified, auditable inventory of all models and their dependencies, enabling reliable RAG systems by ensuring data lineage and governance compliance.
