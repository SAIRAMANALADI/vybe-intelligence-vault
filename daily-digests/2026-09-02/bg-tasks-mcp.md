## Summary
bg-tasks-mcp is an MCP server that enables AI agents to manage background processes like dev servers, builds, and tests directly from the conversation, eliminating manual terminal context switching.

## Key Features
- Start, monitor, and stop background processes via AI agent commands
- Multi-window support with owner/takeover lifecycle for seamless collaboration
- Real-time HTTP dashboard for visualizing and managing tasks
- Six MCP tools (bg_start, bg_wait, bg_logs, bg_status, bg_send, bg_kill) and five MCP resources
- Cross-platform compatibility (Windows, Linux, macOS) with platform-specific signal handling

## Why It Matters for RAG Builders
It streamlines AI agent workflows by automating background process management, reducing context switching and improving developer productivity.
