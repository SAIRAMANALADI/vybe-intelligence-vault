## Summary
A Model Context Protocol (MCP) server for managing, organizing, and sharing web resources as structured 'footprints' with cross-device sync, full-text search, and team collaboration features. It provides 21 tools for saving, categorizing, and delivering curated collections of links and notes via AI-friendly APIs.

## Key Features
- Structured 'footprint' records for web links, notes, and ideas with UUIDs, titles, descriptions, and tags
- Cross-device sync and team collaboration via shared categories with read-only or co-edit modes
- Full-text search and batch operations for efficient organization and retrieval
- Auto-registration and token management for seamless AI agent integration
- Magic link delivery for sharing curated collections in a card-based interface
