## Summary
CodexEngine is a self-hosted document intelligence platform that enables users to upload documents, ask questions, and receive answers with source citations. It features a stable retrieval-first research engine (v4) and an experimental workspace agent (v5) that creates and reuses persistent artifacts for enhanced AI assistance.

## Key Features
- Hybrid retrieval combining vector search (pgvector) and BM25 for accurate document search
- Source citations with page and document references for transparency
- Stable v4 retrieval engine and experimental v5 agentic workspace with persistent artifacts
- Provider-agnostic LLM layer with fallback models (Groq, Llama, Qwen)
- FastEmbed ONNX for local embeddings and Google Gemini API as a fallback

## Why It Matters for RAG Builders
CodexEngine provides a robust, self-hosted RAG pipeline with hybrid retrieval and experimental agentic workspaces, making it essential for building advanced, citation-backed AI assistants.
