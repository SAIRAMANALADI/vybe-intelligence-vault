## Summary
Mimi Remote is a native SwiftUI mobile app for iPhone and iPad that acts as a local-first workbench for coding agents running on a user's Mac. It enables remote control of Codex and Claude Code sessions, Git workflows, and file management via a secure Tailscale connection.

## Key Features
- Native SwiftUI interface for iPhone/iPad with dynamic layouts and themes
- Remote control of Codex and Claude Code sessions with approvals and steering
- Git Worktrees management (create, switch, inspect, and cleanup)
- Secure Tailscale-based connection with local credential storage
- Markdown rendering, file references, voice input, and diagnostics

## Why It Matters for RAG Builders
It provides a mobile-first interface for managing and steering local AI coding agents, enabling developers to review, approve, and interact with sessions remotely without exposing backend services to the public internet.
