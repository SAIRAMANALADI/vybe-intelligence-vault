## Summary
Oh My Pi Desktop is a local-first visual workspace that connects durable agent sessions to the Oh My Pi runtime, enabling terminal-grade agent work with a durable desktop interface for managing models, tools, permissions, and long-running tasks.

## Key Features
- Durable agent sessions with status tracking and recovery
- Explicit permission controls for agent autonomy
- Cross-platform desktop app (macOS, Windows, Linux)
- Integration with MCP servers, REST APIs, and local tools
- Headless CLI and server modes for automation

## Why It Matters for RAG Builders
It provides a visual, local-first interface for managing and monitoring AI agent sessions, tools, and models, bridging the gap between terminal-based agent work and user-friendly desktop workflows.
