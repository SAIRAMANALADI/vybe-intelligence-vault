## Summary
Boo is a Python-based Streamlit application that provides a unified interface for interacting with multiple AI providers (OpenAI GPT, Google Gemini, and xAI Grok) to execute multimodal workflows, including text generation, image processing, audio transcription, embeddings, document Q&A, and vector store operations. It is designed for federal data analysis, prompt management, and local analytical operations.

## Key Features
- Unified interface for GPT, Gemini, and Grok with dynamic mode filtering
- Comprehensive multimodal support (text, image, audio, embeddings)
- Document Q&A with SQLite-vec and cosine-similarity fallback
- Local SQLite-backed data management for prompts, chat history, and embeddings
- Deployable via Streamlit, Docker, Databricks, and Azure Container Apps

## Why It Matters for RAG Builders
Boo simplifies the integration of multiple AI providers into a single workflow, making it essential for building scalable, provider-agnostic RAG systems with multimodal capabilities.
