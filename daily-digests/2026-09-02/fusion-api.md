## Summary
Fusion API is a backend chat core that provides authentication, multi-model AI integration, session management, and file-assisted chat capabilities for building conversational AI applications.

## Key Features
- Supports integration with 8+ AI models (DeepSeek, OpenAI, Anthropic, etc.)
- Real-time streaming responses for enhanced user experience
- Comprehensive session history and multi-turn conversation support
- File processing for PDF, Word, and text formats
- Dynamic model configuration and management

## Why It Matters for RAG Builders
It simplifies the integration of multiple AI models and chat capabilities into a single backend, reducing development overhead for RAG builders.
