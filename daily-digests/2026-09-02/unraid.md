## Summary
A monorepo providing MCP servers (Python and Rust) and Unraid OS plugins for managing and querying Unraid servers via GraphQL API. Includes agent integrations for Claude/Codex and supports system operations like Docker/VM management, array control, and telemetry.

## Key Features
- Dual MCP servers (Python and Rust) for Unraid management with GraphQL API integration
- Unraid OS plugins for seamless deployment and plugin-based tooling
- Agent plugins for Claude Code and Codex with zero manual hook configuration
- Supports both read-only queries and mutating actions (Docker/VM lifecycle, array control)
- Modular monorepo structure with automated release management for plugins and servers
