## Summary
MkAgent is an open-source, local-first AI agent workspace designed for desktop, web, and CLI environments. It enables users to build, manage, and execute AI-driven workflows with persistent local workspaces, flexible model integrations, and built-in tools like browsing and document processing.

## Key Features
- Local-first workspaces with persistent sessions and files
- Multi-interface support (Desktop, WebUI, CLI) for flexible access
- Flexible model connections including local Ollama, OpenAI-compatible, and Anthropic-compatible endpoints
- Built-in tools for browsing, document processing, and Markdown/code rendering
- Explicit control over permissions, proxy settings, and multi-language support

## Why It Matters for RAG Builders
MkAgent provides a robust, local-first foundation for building and deploying AI agents with persistent workspaces and flexible model integrations, making it essential for developers seeking control and customization in RAG and agent-based systems.
