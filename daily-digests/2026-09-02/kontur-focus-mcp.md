## Summary
A Model Context Protocol (MCP) server that integrates with Kontur.Focus API to provide AI assistants with tools for checking counterparties by INN, retrieving financial reports, legal standings, and other business intelligence data in Russian corporate registries.

## Key Features
- 8 specialized tools for Russian company data retrieval via INN/OGRN
- Integration with Kontur.Focus API for real-time financial and legal insights
- Supports EGRUL extracts, arbitration cases, bankruptcy status, and licenses
- Designed for seamless AI assistant integration via MCP protocol
- Environment variable configuration for secure API key management
