## Summary
finlight-mcp is an MCP server that provides real-time financial news data to AI agents via a standardized protocol. It connects clients like Claude, ChatGPT, or Cursor to finlight's financial news API, offering searchable articles, sentiment analysis, and entity tagging for market-relevant insights.

## Key Features
- Real-time financial news aggregation with sentiment scoring and confidence metrics
- Entity tagging for companies with tickers, ISINs, and exchange listings
- Searchable articles by ticker, source, country, language, and date range
- OAuth 2.0 authentication with dynamic client registration and PKCE
- Compatibility with major MCP clients (Claude, ChatGPT, Cursor) via HTTP or stdio
