## Summary
Bubo is a self-hosted, agentic AI code review tool that integrates with GitLab MRs and GitHub PRs to provide actionable, inline feedback using any LLM of your choice. It operates outside CI/CD pipelines, ensuring code and review data remain on-premises while offering governance, provenance, and auditable reports.

## Key Features
- Agentic AI-powered code review with customizable LLM integration
- Self-hosted deployment with on-premises data storage
- Inline, actionable feedback threads (no chatbot noise or summaries)
- Governance and provenance via cosign-signed releases and SBOMs
- Metrics and telemetry via OpenTelemetry for monitoring and auditing

## Why It Matters for RAG Builders
Bubo streamlines automated code review with AI, reducing manual effort while ensuring security and compliance for RAG/AI stack builders.
