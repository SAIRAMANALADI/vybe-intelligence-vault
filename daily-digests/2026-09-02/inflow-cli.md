## Summary
InFlow CLI provides a command-line interface and MCP server for agentic payments via the Machine Payments Protocol (MPP) and x402 standards. It enables both human and AI agents to perform payments, deposits, and balance checks through a unified CLI or plugin-based integration with agent hosts like Claude Code or Cursor.

## Key Features
- Supports agentic payments via MPP and x402 standards for AI and human users
- Provides a CLI and MCP server for seamless integration with agent hosts (Claude, Cursor, Codex)
- Monorepo structure with core client library and CLI binary for modularity
- Includes authentication, balance checks, deposit addresses, and payment operations
- Offers plugin-based installation for agent hosts with embedded skills and MCP server

## Why It Matters for RAG Builders
It enables AI agents to perform secure, standardized payments directly from their workflows, bridging the gap between agentic systems and financial protocols.
