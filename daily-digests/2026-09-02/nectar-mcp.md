## Summary
Nectar MCP is a lightweight stdio MCP server that provides focused tools for generating, editing, and managing images and videos using Pollinations' API. It simplifies integration for MCP clients by offering a minimal, specialized interface for creative media tasks.

## Key Features
- Specialized stdio MCP server for Pollinations media generation and editing
- Supports image generation, editing, and video generation with configurable parameters
- Includes model discovery and balance checking tools
- Lightweight and focused, avoiding sprawling feature sets
- Local file output for generated media with configurable directories
