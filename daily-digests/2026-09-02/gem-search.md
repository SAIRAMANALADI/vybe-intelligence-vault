## Summary
gem-search is an agentic web search CLI that leverages Vertex AI's Gemini with Google Search Grounding to autonomously research topics, analyze results, and generate structured reports in Markdown or JSON format. It is designed for both standalone use and integration into AI pipelines via stdin/stdout.

## Key Features
- Autonomous 3-phase research pipeline (survey, deep-dive, verify) for thorough coverage
- Supports Markdown and JSON output formats for flexibility in integration
- Configurable via TOML, environment variables, or CLI flags for easy deployment
- Cross-platform pre-built binaries with Apple notarization for macOS compatibility
- Designed for both standalone use and pipeline integration via stdin/stdout

## Why It Matters for RAG Builders
It provides a reliable, agentic web search mechanism for RAG pipelines, ensuring high-quality, grounded responses by leveraging Google Search Grounding with Gemini.
