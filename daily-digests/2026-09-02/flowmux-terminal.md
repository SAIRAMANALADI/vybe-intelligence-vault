## Summary
FlowMux is a GTK4-based terminal application designed for AI agent workflows, offering integrated browser control, desktop notifications for agent events, and advanced pane management. It enables seamless interaction between AI agents and terminal/browser environments with a focus on developer productivity.

## Key Features
- Integrated WebKitGTK browser pane for agent-driven web interactions (snapshot, click, type, read state) via IPC socket
- Desktop notifications for AI agent lifecycle events (task complete, needs approval, errors) with workspace routing
- Split pane workspace management for mixing terminal and browser tabs with keyboard navigation
- Image viewer supporting PNG, JPEG, WebP, GIF, SVG, and Lottie via ThorVG (optional runtime dependency)
- Agent CLI (`flowmuxctl`) for programmatic control of panes, tabs, and browser operations with JSON output

## Why It Matters for RAG Builders
FlowMux bridges the gap between AI agents and terminal/browser environments, enabling seamless automation and real-time interaction for RAG and agent-based systems.
