## Summary
WasmHatch is a browser-native AI assistant that performs real-time data transformations, document creation, and report generation directly in the user's browser without requiring a server or external storage. It emphasizes transparency, user control, and local-first execution via WebAssembly.

## Key Features
- Runs entirely in the browser with no server-side processing or storage
- Sandboxed execution of data-transform code via QuickJS compiled to WebAssembly
- Real-time, visible changes with one-click undo and diff tracking
- Integrates with Google Docs, Sheets, and Slides for document creation and editing
- Supports both external AI models (Claude/OpenAI) and on-device models

## Why It Matters for RAG Builders
WasmHatch demonstrates how AI agents can execute tasks securely and transparently in the browser, eliminating server dependencies and prioritizing user privacy while enabling powerful local data processing.
