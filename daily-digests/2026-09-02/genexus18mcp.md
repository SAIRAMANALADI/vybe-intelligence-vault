## Summary
GeneXus MCP Server enables AI agents like Claude, Cursor, and other MCP-compatible clients to interact directly with GeneXus 18 Knowledge Bases. It provides read, edit, analyze, and refactor capabilities for GeneXus objects (transactions, procedures, web panels) via the native GeneXus SDK.

## Key Features
- Direct integration with GeneXus 18 Knowledge Bases via native SDK
- Supports 30+ tools for reading, editing, analyzing, and refactoring GeneXus objects
- Auto-configuration for popular AI clients (Claude, Cursor, VS Code, etc.)
- Multi-language support (Spanish, Portuguese, English) with troubleshooting guides
- Corporate-friendly installer with ASR/SmartScreen compatibility

## Why It Matters for RAG Builders
It bridges AI agents with GeneXus 18, enabling automated code analysis, refactoring, and generation within enterprise knowledge bases, reducing manual effort and accelerating development workflows.
