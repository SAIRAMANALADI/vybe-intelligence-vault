## Summary
Synapsen is a homeostatic state engine for AI agents that models biological-like chemical regulation using messenger substances (Botenstoffe) instead of abstract mood strings. It simulates a closed-loop control system where events trigger chemical releases, decay over time, and interact with circadian rhythms to dynamically shape agent behavior.

## Key Features
- Biologically-inspired chemical regulation with named messenger substances (e.g., oxytocin, cortisol) and decay rates
- Closed-loop control system with dynamic equilibrium calculations for long-term stability
- Time-aware modeling including circadian rhythms, fatigue, and habituation effects
- Diagnostic tools (e.g., `doctor`, `why`) for validating profiles and tracing state origins
- Cross-process state sharing via MCP server and persistent storage (JSON/SQLite)

## Why It Matters for RAG Builders
Synapsen provides a scientifically grounded, predictable, and debuggable way to model agent state dynamics over time, enabling more realistic and stable AI behavior in production environments.
