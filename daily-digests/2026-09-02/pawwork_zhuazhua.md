## Summary
Paw Work is a Chrome MV3 extension that enables users to select content on live web pages and transform it into editable office files (spreadsheets, slides, documents, or websites) directly within the browser. It operates as a selection-first agent, returning real, editable files without requiring an account or server.

## Key Features
- Select content on live web pages and describe desired output (e.g., spreadsheets, slides, documents, or websites)
- Returns real, editable files (e.g., Univer spreadsheets, tldraw canvases, HTML sites) directly in the browser
- Sandboxed execution with QuickJS VM and WASM for security; no external code execution or DOM access beyond user selection
- No account or server required; users provide their own model keys (OpenAI-compatible endpoints)
- Supports iterative editing of generated files with live updates in the workspace

## Why It Matters for RAG Builders
It enables RAG builders to transform live web content into structured, editable files directly within the browser, reducing manual data extraction and formatting overhead.
