## Summary
A TypeScript example demonstrating how to build a content-based article recommender using Pinecone's similarity search. It indexes articles with embeddings and retrieves personalized recommendations based on user preferences.

## Key Features
- Demonstrates indexing articles with embeddings using Pinecone
- Implements content-based filtering for personalized recommendations
- Uses Transformers.js for local embedding generation
- Includes batch processing for efficient data ingestion
- Provides CLI for querying recommendations
