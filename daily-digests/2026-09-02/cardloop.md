## Summary
Cardloop is a self-hosted, mobile-first cockpit that transforms a kanban board into an AI agent execution environment. Each card represents a task executed by the official Claude Code engine, enabling autonomous coding, operations, and project management directly from a phone or desktop.

## Key Features
- Kanban-as-a-runtime: Tasks are cards that auto-run Claude agents to completion, with the board serving as the single source of truth.
- Mobile-first PWA: Installable on phones with live SSE streaming, interactive PTY terminal, and touch-optimized UI for remote project management.
- Isolated worktree runs: Each card executes in a clean git worktree with a review gate (Check/Apply/Discard) for safe merges.
- Bring-your-own-Claude: Drives the official Claude Code CLI under your own Anthropic account (API key or personal login), ensuring no SaaS middleman.
- Deferred runs and notifications: Automatically resumes agent runs after rate limits and sends browser/Web Push notifications upon completion.

## Why It Matters for RAG Builders
Cardloop streamlines AI agent workflows by integrating kanban boards with autonomous Claude Code execution, enabling seamless project management from any device while maintaining full control over data and infrastructure.
