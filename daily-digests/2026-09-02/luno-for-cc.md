## Summary
LUNO for CC is a VS Code and Cursor extension that integrates the Claude Code agent into a native editor side panel, enabling streaming chat, multi-file edits, terminal execution with permission gating, and project-specific AI assistance powered by an existing Claude.ai subscription.

## Key Features
- Native side-panel chat with streaming responses and inline diff previews
- Risk-aware approvals with five permission modes (Ask, Edits, Agent, Plan, Bypass)
- Plan-mode review with inline comments and one-click execution
- MCP connectors for integrating remote tools like Linear, Notion, and Sentry
- Skills marketplace for extending agent capabilities via claude-plugins.dev

## Why It Matters for RAG Builders
It bridges the gap between Claude Code's agentic capabilities and popular code editors, enabling seamless AI-assisted development workflows with robust permission controls.
