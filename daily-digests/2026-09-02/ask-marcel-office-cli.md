## Summary
A CLI tool that enables AI agents to interact with Microsoft 365 services (Outlook, OneDrive, SharePoint, Teams, etc.) via a simple, read-only interface. It converts documents, emails, and attachments into clean markdown, simplifies authentication, and provides structured responses tailored for LLM tool-calling workflows.

## Key Features
- One-click authentication via browser sign-in (no Azure app registration required)
- Converts emails, attachments, and files (docx, xlsx, pptx, pdf, etc.) to clean markdown for LLM consumption
- Provides structured, error-repairing responses with hints for self-correction by agents
- Offers 186+ read-only commands across Outlook, OneDrive, SharePoint, Teams, Calendar, Excel, and more
- Supports MCP server mode for seamless integration with AI agents like Claude Code or Cursor

## Why It Matters for RAG Builders
It eliminates the complexity of accessing Microsoft 365 data for AI agents by providing a read-only, markdown-based interface that reduces context window bloat and simplifies tool-calling workflows.
