## Summary
A Vue 3 frontend with Pinia state management and JWT authentication, designed to interact with a FastAPI AI Agent backend. It provides a user interface for AI agent interactions, including agent actions, tool observations, and final answers.

- JWT authentication for secure API access
- Real-time AI agent interaction with tool execution visibility
- Structured display of agent actions, observations, and final answers
- Environment-based API configuration for flexible deployment
