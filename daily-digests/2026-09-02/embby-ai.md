## Summary
Embby AI is a self-improving TypeScript-based agent built on the Mastra framework, enabling real-time web access, file operations, and dynamic skill learning. It leverages Groq's LLM and FastEmbed for embeddings, with a focus on autonomous improvement through user-defined skills.

## Key Features
- Dynamic skill creation and learning via `.md` files for persistent behavior patterns
- Real-time web access with weather, search, and URL fetching tools
- Dual memory system combining semantic recall and observational memory for context retention
- File operations with human approval for safe read/write/edit/delete actions
- Integration with Groq's `gpt-oss-120b` model and FastEmbed for local embeddings

## Why It Matters for RAG Builders
Embby AI provides a robust framework for building self-improving agents with real-time capabilities and adaptive learning, essential for scalable RAG systems requiring dynamic context and persistent memory.
