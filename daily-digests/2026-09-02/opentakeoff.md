## Summary
OpenTakeoff is an open-source measurement engine for construction plans that enables both AI agents and human estimators to perform takeoffs (quantity extraction) with identical geometry and auditable provenance. It provides a Model Context Protocol (MCP) server with 38 tools for agent-driven takeoffs and a browser-based canvas for manual measurement.

## Key Features
- 38 MCP tools for agent-driven takeoffs with explicit scale, method, and provenance tracking
- Browser-based canvas for manual measurement with one-click room detection and CAD hatch support
- Identical geometry and measurement logic for both agent and human workflows
- Provenance tracking for every measurement (scale, method, human corrections, and machine signatures)
- Roll goods and transitions support for flooring takeoffs with waste calculations

## Why It Matters for RAG Builders
It provides the first open-source, auditable takeoff engine that AI agents can natively drive over MCP, enabling reliable quantity extraction for construction bids while generating labeled training data for takeoff models.
