## Summary
OpenOSINT is an AI-powered OSINT (Open-Source Intelligence) agent designed for security researchers and analysts. It provides 19 modular investigation tools accessible via natural language, CLI, REPL, MCP server, or web UI, enabling deterministic and auditable data collection.

## Key Features
- 19 modular OSINT tools (email, username, breach, WHOIS, IP, subdomain, etc.) with AI-driven tool chaining
- Native MCP server integration for seamless use with Claude, Cursor, and Windsurf
- Deterministic and auditable findings with real binary execution (no hallucinations)
- Supports multiple AI backends (Claude, local Ollama, OpenAI-compatible endpoints)
- Web UI, CLI, REPL, and cloud deployment options for accessibility

## Why It Matters for RAG Builders
OpenOSINT provides a secure, auditable, and AI-integrated framework for OSINT investigations, critical for building reliable RAG pipelines that require deterministic data sources and compliance-ready outputs.
