## Summary
agent-soul is a Windows-based tool for managing persistent memory and identity for AI agents, enabling shared memory across sessions and devices without relying on third-party servers. It leverages Git for local data storage and version control, ensuring data privacy and self-hosted operation.

## Key Features
- Shared memory between AI agents without third-party servers
- Persistent session memory stored locally using Git
- Supports multiple AI models (OpenAI, Claude) with no proprietary API lock-in
- Lightweight and easy to install on Windows with no admin rights required
- Full data control with optional configuration via config.json

## Why It Matters for RAG Builders
It provides a privacy-preserving, Git-native way to maintain persistent AI agent memory locally, reducing dependency on external services for RAG and agent frameworks.
