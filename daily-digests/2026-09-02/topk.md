## Summary
TopK is a unified retrieval engine designed for hybrid search, vector search, multi-vector retrieval, and keyword search (BM25) with custom ranking capabilities. It supports managed inference and integrates with object storage for cost-effective, scalable data retrieval.

## Key Features
- Unified API for hybrid, vector, and keyword search
- Supports dense vectors, sparse vectors, and multi-vector embeddings
- Custom ranking with metadata filtering
- Managed inference for AI-native applications
- Scalable object storage backend for cost efficiency

## Why It Matters for RAG Builders
TopK simplifies building advanced RAG systems by unifying retrieval, ranking, and inference in a single scalable engine.
