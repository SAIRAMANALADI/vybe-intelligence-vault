## Summary
MCP server that wraps the ZenMoney personal finance API, exposing tools for syncing, reading, searching, and writing financial data via the Model Context Protocol (MCP). Enables LLM assistants to interact with ZenMoney accounts, transactions, and budgets securely.

## Key Features
- Exposes ZenMoney API tools via MCP over stdio for LLM integration
- Supports sync, read, search, write, and bulk operations for financial data
- Provides prebuilt binaries and source installation options
- Includes pagination and filtering for transactions and accounts
- Offers bulk operation preparation and execution for batch processing

## Why It Matters for RAG Builders
It enables LLMs to securely interact with personal financial data via the ZenMoney API, expanding AI-driven financial analysis and automation capabilities.
