## Summary
md2wechat is a CLI tool that converts Markdown to WeChat official account drafts, supporting advanced typography, cover generation, and AI-assisted workflows. It provides a stable interface for AI agents to automate WeChat content creation and publishing.

## Key Features
- Converts Markdown to WeChat-compatible HTML with 77+ advanced typography scenarios and 56+ layout modules
- Supports AI agents (Claude Code, Codex, Kimi Work, etc.) via JSON discovery for stable automation
- Generates covers and infographics using multiple image providers (Volcengine, OpenAI, MiniMax, etc.)
- Provides structured inspection and readiness checks for draft publishing
- Offers professional API with 48+ themes and enterprise-grade features for teams and automation

## Why It Matters for RAG Builders
It streamlines WeChat content creation and publishing for AI agents, reducing manual effort and enabling automated workflows for large-scale content distribution.
