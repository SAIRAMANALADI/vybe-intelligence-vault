## Summary
CPA-X is an AI-first monitoring and management panel for CLIProxyAPI, designed for deployment and operation by AI agents. It provides health checks, resource monitoring, logs, update management, request statistics, and pricing insights with a focus on safe auto-updates and cross-time-zone reliability.

## Key Features
- AI-first deployment and operation with dedicated guides for agent-based management
- Safe auto-update with SHA-256 verification, atomic replacement, rollback, and exponential backoff for failed updates
- Cross-time-zone reliability with UTC/RFC 3339 APIs and support for split host/container time zones
- Usage and cost insights via incremental log parsing and historical token/cost data preservation
- Flexible deployment options including Linux (systemd), Windows, and Docker with read-only or full-feature modes
