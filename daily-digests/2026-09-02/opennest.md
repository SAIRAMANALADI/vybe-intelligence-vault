## Summary
OpenNest is a desktop application that enables users to manage multiple AI agents (bots) with distinct models, working directories, and persistent conversations, all powered by the bundled Claude Code agent. It allows parallel execution of bots and local storage of conversations for seamless resumption.

## Key Features
- Multi-bot management with independent models and working directories
- Persistent local storage of conversations for seamless resumption
- Parallel execution of multiple bots without interference
- Tauri-based desktop app with Rust backend and React/Vite frontend
- No API keys required; relies solely on Claude Code sign-in

## Why It Matters for RAG Builders
OpenNest simplifies the management and orchestration of multiple AI agents, making it easier to handle complex workflows and persistent sessions for RAG and AI stack builders.
