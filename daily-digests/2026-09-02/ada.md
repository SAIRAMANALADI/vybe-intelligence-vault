## Summary
ada is a terminal-based coding agent that acts as a universal client for AI models, routing requests to multiple providers via a single OpenAI-compatible interface. It supports agentic loops, tools, LSP diagnostics, and a TUI front-end, enabling seamless multi-model and multi-provider interactions.

## Key Features
- Unified OpenAI-compatible interface for 12+ AI providers with zero-code model integration
- Agentic loop with streaming, tool execution, and context compaction for long-running tasks
- Built-in tools (file ops, shell, web search, diagnostics) and 285+ skills for specialized tasks
- TUI and REPL front-ends with permission modes (ask/plan/auto) for granular control
- MCP server integration for external tooling and extensibility via skills and connectors

## Why It Matters for RAG Builders
ada simplifies building AI-powered coding agents by providing a unified, extensible framework that handles multi-provider routing, tooling, and agentic workflows out of the box.
