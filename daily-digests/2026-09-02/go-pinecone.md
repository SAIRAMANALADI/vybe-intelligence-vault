## Summary
The official Go SDK for Pinecone, providing Go bindings for interacting with Pinecone's vector database and admin APIs. It supports gRPC and REST operations for data, control, and admin planes, enabling seamless integration with Pinecone's services.

## Key Features
- gRPC and REST bindings for Pinecone's Data Plane, Control Plane, and Admin API
- Automatic retries with exponential backoff for transient and rate-limited errors
- Support for serverless, pod-based, and integrated indexes
- Admin API client for managing projects, API keys, and service accounts
- Comprehensive error handling and retry policies
