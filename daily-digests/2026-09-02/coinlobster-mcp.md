## Summary
CoinLobster MCP is an MCP server providing live whale trade data across 15 centralized exchanges and on-chain DEX swaps on Ethereum, Base, and Arbitrum. It offers real-time market signals, liquidations, and unusual flow detection for AI agents without requiring an API key for basic access.

## Key Features
- Live whale trades across 15+ exchanges and DEXs with wallet-level granularity
- Smart Money Radar for detecting unusual whale activity in customizable time windows
- Outcome-scored signals with historical performance data for backtesting
- Liquidation monitoring with long/short breakdowns and Hyperliquid whale account tracking
- Market snapshots, funding rates, and squeeze scores for comprehensive risk assessment

## Why It Matters for RAG Builders
