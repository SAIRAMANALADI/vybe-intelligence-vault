## Summary
exomem is a self-hosted MCP server that transforms a user's Markdown or Obsidian vault into a durable, searchable knowledge substrate for AI agents. It enables agents like Claude Code, Codex, and chatbots to interact with local files while preserving sources, proof, history, and review capabilities.

## Key Features
- Turns plain Markdown/Obsidian vaults into searchable knowledge bases for AI agents
- Preserves sources, proof, history, and review capabilities for retrieved content
- Supports hybrid retrieval over large corpora (50k+ notes) with sub-second response times
- Provides MCP tools for seamless integration with agents like Claude Code and Codex
- Offers hooks for automatic knowledge retrieval and context injection during agent sessions

## Why It Matters for RAG Builders
exomem enables AI agents to leverage a user's existing local knowledge base while maintaining full provenance and governance, making it essential for building trustworthy and context-aware RAG systems.
