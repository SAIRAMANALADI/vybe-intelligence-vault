## Summary
MCP server for Prometheus Alertmanager that exposes alert listing and silence management as MCP tools, enabling integration with Model Context Protocol (MCP) clients for observability and incident response workflows.

## Key Features
- List and filter alerts with label matchers, state, or receiver
- Create, retrieve, and delete silences with custom matchers, author, and duration
- Supports Basic Auth and custom headers for authentication
- Available in stdio and SSE modes for MCP client compatibility
- Built-in health checks and comprehensive testing suite

## Why It Matters for RAG Builders
It bridges Prometheus Alertmanager with MCP clients, enabling AI-driven incident response and automated alert handling in RAG workflows.
