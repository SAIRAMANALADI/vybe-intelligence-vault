## Summary
A configurable MCP server that indexes and serves Terraform/Tofu provider documentation from a local Git repository, enabling accurate, context-aware code generation by providing up-to-date provider documentation to AI agents.

## Key Features
- Indexes Terraform provider documentation from local Git repositories
- Serves documentation via MCP for integration with AI agents
- Configurable via YAML and environment variables for flexibility
- Supports multiple Terraform providers (e.g., Google Cloud Platform)
- Provides pre-compiled executables for macOS, Linux, and Windows

## Why It Matters for RAG Builders
It enables AI agents to access the most current Terraform provider documentation, improving the accuracy of code generation for infrastructure-as-code tasks.
