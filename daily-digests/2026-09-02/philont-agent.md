## Summary
Philont is a self-hosted agent runtime designed to make smaller models dependable for long-running tasks by enforcing reliability through explicit mechanisms like persistent pursuits, execution evidence checks, and scoped authorization. It supports multi-step, interruptible workflows with governance features for memory, skills, and autonomy.

## Key Features
- Persistent pursuits with configurable focus areas via `compass.md`
- Execution evidence checks to validate completion claims against tool outputs
- Scoped authorization and permission layers with a 3×4 capability matrix
- Multi-layer persistent memory (timeline, facts, skills) with maturity and decay tracking
- Plan-protocol enforcement for multi-step tasks with deterministic state machines

## Why It Matters for RAG Builders
Philont enables reliable, long-running agent workflows with smaller models by embedding governance, evidence checks, and persistent memory directly into the runtime, reducing reliance on model scale alone.
