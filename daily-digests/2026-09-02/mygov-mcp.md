## Summary
A Malaysia government open-data connector packaged as official plugins for Claude Code and Codex/ChatGPT ecosystems. It includes a dependency-free MCP server (stdlib only) and provides tools for accessing various Malaysian government datasets like weather forecasts, economic indicators, and public transport schedules.

## Key Features
- Dependency-free MCP server using only Python standard library
- Official plugins for Claude Code and Codex/ChatGPT ecosystems
- Access to 7-day weather forecasts, severe weather warnings, and economic datasets
- GTFS static and real-time public transport data for Malaysian transit systems
- No API key required with open CORS and throttled requests (4/min)

## Why It Matters for RAG Builders
It provides structured, no-cost access to Malaysian government datasets, enabling AI agents to integrate real-time public transport, weather, and economic data into RAG pipelines.
