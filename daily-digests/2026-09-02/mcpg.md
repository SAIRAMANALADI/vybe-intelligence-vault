## Summary
MCPg is a production-grade Model Context Protocol (MCP) server for PostgreSQL that enables AI agents to safely inspect, query, operate, and tune PostgreSQL databases. It provides 254 tools for catalog introspection, natural-language SQL, hybrid search, graph queries, and DBA operations, all with strict safety and multi-tenancy support.

## Key Features
- Safe by default with read-only mode, AST validation, and strict input sanitization to prevent SQL injection
- 254 tools covering catalog introspection, query intelligence, hybrid search, graph queries, and DBA operations
- Production-grade features including connection pooling, multi-tenancy, read-replica routing, rate-limiting, and audit trails
- Supports PostgreSQL versions 14–19 with native integration for TimescaleDB, pgvector, PostGIS, and Apache AGE
- Observability built-in with Prometheus metrics, structured audit logs, and OIDC JWT bearer authentication

## Why It Matters for RAG Builders
MCPg is essential for RAG/AI stack builders as it provides a secure, production-ready interface for AI agents to interact with PostgreSQL databases, enabling natural language queries, automated operations, and deep database insights without compromising safety or performance.
