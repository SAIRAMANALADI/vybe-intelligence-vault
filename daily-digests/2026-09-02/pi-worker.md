## Summary
Pi Worker is a CLI tool and coding-agent skill that delegates bounded coding tasks to exact models available through a local Pi installation, enabling parallel execution while enforcing model/provider constraints and reporting task status.

## Key Features
- Delegates tasks to exact Pi models with enforced provider/model selection
- Supports parallel execution of up to three workers with ordered result handling
- Includes safety checks and workspace validation via the `doctor` command
- Provides detailed task status and explanation reporting
- Offers native binaries for macOS, Linux, and Windows (source builds)

## Why It Matters for RAG Builders
Pi Worker enables efficient, parallelized task delegation to specific models in a local Pi setup, reducing quota consumption and improving control over model selection for RAG and AI workflows.
