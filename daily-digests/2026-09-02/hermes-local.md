## Summary
Hermes Local transforms consumer Windows PCs into private AI workstations by providing a native launcher, hardware-aware inference orchestration, and a comprehensive toolset for running, tuning, and benchmarking local AI models without Docker, WSL, or paid APIs.

## Key Features
- Native Windows launcher with TUI and desktop UI for managing local AI workflows
- Hardware-aware inference profiles that optimize CPU/GPU/VRAM usage based on real-time telemetry
- Built-in benchmarking and evidence-based optimization for model performance and stability
- Portable configuration system for models, profiles, and runtime settings without Docker/WSL
- Comprehensive lifecycle management including setup, diagnostics, backup, repair, and rollback

## Why It Matters for RAG Builders
Hermes Local provides a critical Windows-native orchestration layer for local AI, enabling RAG builders to deploy, tune, and benchmark models efficiently on consumer hardware without cloud dependencies or complex containerization.
