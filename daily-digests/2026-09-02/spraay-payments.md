## Summary
spraay-payments is a Windows desktop application designed to simplify multi-chain cryptocurrency payments, enabling users to send batch payments, manage payroll, execute swaps, and generate invoices across supported blockchain networks with an intuitive interface.

## Key Features
- Supports multi-chain batch crypto payments in a single interface
- Enables payroll processing for multiple recipients or contractors
- Facilitates token swaps across supported blockchain networks
- Generates and tracks professional crypto invoices with automatic updates
- Integrates with Spraay x402 gateway for secure and fast transactions
