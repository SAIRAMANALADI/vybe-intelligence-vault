## Summary
AI Desktop Companion is a Python-based desktop application that integrates LLM agents with a PySide6 GUI to create interactive AI companions. It features role-based personality control, long-term memory management, and natural language interaction for personalized AI companionship.

## Key Features
- Role-based AI personality control with configurable system prompts
- Long-term memory management with automatic extraction and retrieval
- Real-time natural language interaction via PySide6 GUI
- Multi-role support with independent configurations and animations
- Visual memory management panel for editing, searching, and reviewing memories
