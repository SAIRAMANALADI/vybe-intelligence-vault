## Summary
Bender is a self-hosted personal AI agent that integrates a markdown wiki, Things-style task manager, and a Telegram assistant into a unified system. It leverages the Claude Agent SDK for core functionality and runs entirely on a user's Claude subscription without requiring additional API keys.

## Key Features
- Unified personal AI agent with wiki, task manager, and Telegram assistant sharing a single session
- Confluence-style markdown wiki with live sync over SSE and automatic link rewriting
- Things-style task management with projects, areas, deadlines, and drag-and-drop UI
- Built-in scheduling engine for recurring tasks and reminders with job memory
- Self-improvement features including long-term memory, background reviewers, and skill curation

## Why It Matters for RAG Builders
