## Summary
Mystical Assistant is a local dashboard that aggregates and manages all active Claude Code sessions across your machine, providing a unified interface to monitor, resume, and interact with sessions regardless of where they were initiated. It handles session limits by seamlessly switching between accounts or providers and offers advanced features like repo mapping, git integration, and multi-surface access via desktop, Telegram, or native CLI.

## Key Features
- Aggregates all active Claude Code sessions across VS Code, terminals, and other editors into a single dashboard
- Handles session limits by automatically switching between accounts or free-agent providers without losing context
- Provides advanced repo mapping and git integration directly within the session interface
- Supports multi-surface access via desktop dashboard, Telegram Mini App, and native CLI
- Zero dependencies on the server side, relying solely on Python standard library and existing local tools

## Why It Matters for RAG Builders
It eliminates the fragmentation of AI agent sessions across tools and machines, enabling seamless continuity and management of AI-driven workflows in local development environments.
