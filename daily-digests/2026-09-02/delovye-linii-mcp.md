## Summary
A Model Context Protocol (MCP) server providing freight cost calculation, order tracking, and logistics management for Delovye Linii (Dellin) in Russia. It abstracts Dellin's API into 6 tools for seamless integration with AI agents and workflows.

## Key Features
- 6 integrated tools for Dellin API (cost calculation, city/terminal lookup, order tracking, order creation, and history retrieval)
- Supports MCP stdio, HTTP, and Smithery deployments for AI agent integration
- Provides Claude Code skills for direct command-line freight calculations
- Environment-based configuration for API keys and endpoints
- MIT licensed with active development and CI/CD pipeline

## Why It Matters for RAG Builders
It simplifies Dellin's freight logistics API into an MCP-compatible toolkit, enabling AI agents to handle real-world shipping tasks without direct API integration complexity.
