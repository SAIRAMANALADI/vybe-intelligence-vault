## Summary
A Model Context Protocol (MCP) server that enables programmatic access to GitHub Copilot models via the official SDK. It allows users to query any supported Copilot model directly from their MCP client without requiring additional API keys.

## Key Features
- Seamless integration with existing GitHub Copilot CLI credentials, eliminating the need for extra API keys
- Supports querying any Copilot model (GPT-5, Codex, Claude Sonnet, etc.) based on subscription access
- Enables file and image attachments (local files or base64 blobs) alongside prompts for richer interactions
- Provides model discovery with context window limits and billing multipliers for better resource management
- Offers streaming progress notifications for real-time response chunks via MCP

## Why It Matters for RAG Builders
It simplifies programmatic access to GitHub Copilot models, enabling AI engineers to integrate Copilot's capabilities directly into their RAG or AI workflows without additional authentication overhead.
