## Summary
A one-shot installer and course materials for replicating the Zorro self-improving agent on a Zo Computer. It provides a zero-cost memory-augmented agent with three layers of memory, token compression, and free local LLMs via an OpenAI-compatible proxy.

## Key Features
- Three-layer memory system (file tree, JSON store, AstraDB hybrid search)
- Token compression reducing CLI output by 80-97%
- OpenAI-compatible proxy for local Ollama LLMs (gemma3)
- One-shot installer for rapid deployment
- Comprehensive course materials for learning and replication

## Why It Matters for RAG Builders
It provides a practical, zero-cost framework for building and deploying self-improving agents with advanced memory and token optimization, critical for scalable AI systems.
