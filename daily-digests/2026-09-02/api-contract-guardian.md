## Summary
API Contract Guardian is a CLI tool that monitors OpenAPI schema differences between git branches, detects breaking changes, generates migration guides, and integrates with CI/CD pipelines to block deployments on contract violations.

## Key Features
- Detects breaking changes in OpenAPI schemas (removed endpoints, type changes, etc.)
- Generates human-readable migration guides in Markdown, JSON, or YAML
- Integrates with CI/CD pipelines to block deployments on violations
- Supports OpenAPI 3.0.x and 3.1.x specifications
- Compares specs between git branches, tags, or commits

## Why It Matters for RAG Builders
It ensures API contracts are preserved during development, preventing production-breaking changes and reducing downtime for RAG/AI stack builders.
