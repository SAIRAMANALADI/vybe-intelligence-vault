## Summary
FrogDB is a memory-first, Redis 8.0-compatible database built in Rust, designed to be faster, safer, and easier to operate than existing solutions. It supports full Redis wire protocol compatibility, clustering, replication, and advanced features like vector search, time series, and probabilistic data structures.

## Key Features
- Full Redis 8.0 compatibility with RESP2/RESP3 support
- Advanced data structures including vector sets, time series, and probabilistic types
- Raft-based clustering and replication with Prometheus/Grafana monitoring
- Extensive testing suite with Jepsen verification and fuzz testing
- Tri-licensed (BSL-1.1, AGPLv3, Commercial) for flexible usage
