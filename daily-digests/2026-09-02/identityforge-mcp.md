## Summary
Identity Forge MCP provides design systems, brand naming, and domain research tools for coding agents via an MCP server and CLI. It enables agents to select, apply, and manage design kits, tokens, and brand assets directly within development workflows.

## Key Features
- 61 MCP tools for design kit discovery, selection, and application
- Automated design system generation with conflict protection for existing files
- Support for multiple token formats (CSS, Tailwind v3/v4, shadcn, DTCG)
- Agent-ready workflows with CLI and plugin integrations for popular IDEs
- Use-case-specific scoring and ranking of design kits for targeted recommendations

## Why It Matters for RAG Builders
It streamlines the integration of design systems into AI-driven development workflows, enabling agents to autonomously apply consistent branding and design tokens to projects.
