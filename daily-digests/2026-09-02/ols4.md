## Summary
OLS4 is a biomedical ontology lookup service providing a single point of access to the latest ontology versions through a website, REST API, and MCP server. It enables efficient querying, search, and retrieval of ontology data for AI and research applications.

## Key Features
- Provides a REST API and MCP server for ontology access and querying
- Uses PostgreSQL with pgvector for vector embeddings and full-text search
- Supports loading and indexing of RDF/OWL ontologies
- Offers a React-based frontend for interactive exploration
- Designed for scalable deployment via Docker and Kubernetes
