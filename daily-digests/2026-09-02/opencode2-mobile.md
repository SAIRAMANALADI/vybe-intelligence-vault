## Summary
A native Expo client for the OpenCode V2 HTTP API, enabling iOS and Android users to connect directly to self-hosted OpenCode servers for agent-based workflows, session management, and encrypted push notifications.

## Key Features
- Native iOS and Android support via Expo SDK 54
- Direct HTTPS or private-network HTTP connections to OpenCode V2 servers
- Session management with active/blocked workflows and paginated transcripts
- Secure credential storage using SecureStore (Basic/Bearer tokens)
- Self-hosted encrypted push notifications for remote attention

## Why It Matters for RAG Builders
It provides a mobile interface for managing agent-based workflows and sessions, bridging OpenCode V2 servers with user devices for real-time collaboration.
