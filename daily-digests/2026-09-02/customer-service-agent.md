## Summary
A production-grade AI customer service agent deployed for a Libyan retail franchise's Facebook page, handling Libyan Arabic responses, product photo recognition, and real-time catalog lookups. The system is self-hosted on a single VPS with minimal external dependencies and includes a bilingual admin dashboard for monitoring and control.

## Key Features
- Automated customer service responses in Libyan Arabic with real-time catalog grounding
- Hybrid product image recognition pipeline with an 8-step matcher and learning loop
- Bilingual (AR/EN) admin command center for monitoring, control, and campaign management
- Production-hardened message flow with burst batching, supersede guards, and output sanitization
- Self-hosted deployment on a single VPS with Docker and Caddy for TLS and media serving
