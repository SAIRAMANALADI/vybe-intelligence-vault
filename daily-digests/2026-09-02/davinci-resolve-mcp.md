## Summary
A Model Context Protocol (MCP) server that enables AI assistants to control DaVinci Resolve Studio through its official Scripting API, providing full API coverage and workflow helpers for editing, media management, rendering, and advanced offline operations. Includes a local control panel for inspecting and managing Resolve state.

## Key Features
- Full API coverage for DaVinci Resolve Studio with 353 granular tools and 36 compound tools
- Local control panel for real-time project inspection and analysis
- Advanced offline server for file-level Resolve project manipulation (e.g., DRX grade editing, conform QC)
- Free edition support via in-app bridge for non-Studio users
- Automated installation and configuration for popular AI coding agents (Claude, VS Code, etc.)

## Why It Matters for RAG Builders
It bridges AI agents with professional video editing workflows, enabling automated post-production tasks and real-time project management for RAG and AI stack builders.
