## Summary
Favorites MCP enables AI agents to safely organize live Chrome/Edge bookmarks via a standard MCP server, with browser-side approvals, private folder isolation, URL redaction, audit trails, and rollback mechanisms. It bridges AI tools to real browser bookmarks without modifying profile files or requiring browser automation.

## Key Features
- Standard MCP interface for AI agents to interact with live browser bookmarks via stdio or WebSocket
- Browser-side approvals and privacy controls (private folders, URL redaction, audit trails)
- Rollback and recovery mechanisms for destructive operations (snapshots, backups, conflict resolution)
- Multi-browser support (Chrome/Edge) with Manifest V3 extensions
- Fine-grained permission policies (disable, batch approval, per-item confirmation, auto-approve)

## Why It Matters for RAG Builders
It provides a secure, user-controlled bridge between AI agents and real browser bookmarks, enabling safe automation without compromising privacy or requiring browser profile modifications.
