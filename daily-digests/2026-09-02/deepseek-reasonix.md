## Summary
DeepSeek-Reasonix is an open-source, MIT-licensed coding agent designed for autonomous, long-running tasks with a focus on stability and user control. It operates as a single Go binary with multiple interfaces (CLI, desktop app, browser, or editor) and supports multi-model configurations, plugin-driven tooling, and cache-aware context management.

## Key Features
- Config-driven multi-model support with OpenAI-compatible endpoints
- Plugin-driven architecture via MCP servers and Extension Protocol
- Cache-aware context maintenance for stable, long-running sessions
- Zero-friction distribution as a single static Go binary
- Cross-platform support (CLI, desktop, browser, editor) with unified engine
