## Summary
A Model Context Protocol (MCP) server providing access to the YGOPRODeck Yu-Gi-Oh! trading card game (TCG) database, enabling AI agents to query card details, search by attributes, and retrieve pricing data via structured tools or natural language interfaces.

## Key Features
- Provides structured tools for searching Yu-Gi-Oh! cards by name, type, attribute, or archetype
- Retrieves full card details including ATK/DEF, attributes, banlist status, and printed sets
- Fetches real-time card prices from TCGplayer, Cardmarket, eBay, and Amazon
- Integrates with Pipeworx MCP gateway for unified access to 1394+ data sources
- Supports natural language queries via the ask_pipeworx interface

## Why It Matters for RAG Builders
It enables AI agents to dynamically fetch and integrate Yu-Gi-Oh! card data into RAG applications, enhancing context-aware responses with accurate and up-to-date game information.
