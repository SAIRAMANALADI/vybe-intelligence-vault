## Summary
HermOS IDE is a local-first desktop code editor with an integrated autonomous AI coding agent. It enables users to edit files, run commands, browse the web, and generate documents entirely offline while supporting multiple AI providers or local models like Ollama.

## Key Features
- 100% local execution with no cloud telemetry or tracking
- Supports multiple AI providers (OpenAI, Anthropic, Ollama, etc.) with encrypted key storage
- Autonomous coding agent for multi-step tasks (read, edit, run, test)
- Integrated terminal, browser preview, and MCP server support for extensibility
- Cross-platform native installers for Windows, macOS, and Linux

## Why It Matters for RAG Builders
HermOS IDE provides a privacy-preserving, offline-capable environment for AI-driven coding tasks, making it ideal for developers who prioritize data security and local control over their AI workflows.
