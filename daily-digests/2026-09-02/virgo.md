## Summary
Virgo is a VS Code extension that integrates AI agents with neural text-to-speech (TTS) to provide audible feedback, reducing reading fatigue during code reviews, architecture planning, and AI-driven tasks. It supports MCP integration for seamless agent communication and offers zero-telemetry privacy compliance.

## Key Features
- Neural TTS integration for high-quality audio output with natural prosody
- MCP server for direct AI agent communication via `say_this_loud` tool
- Zero telemetry and privacy-compliant design with no local storage of content
- Interactive playback controls with real-time document synchronization
- Cross-IDE compatibility (VS Code, Cursor, Antigravity, Cline)

## Why It Matters for RAG Builders
Virgo enhances AI-driven development workflows by enabling hands-free, audible feedback, reducing cognitive load and improving productivity for developers using AI assistants in their IDEs.
