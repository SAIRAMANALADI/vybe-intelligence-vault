## Summary
Decision Anchor SDK provides an external environment for anchoring agent accountability boundaries, recording structural metadata of decisions without evaluating their content. It enables third-party attestation of agent decisions for proof of accountability in transactions or interactions.

## Key Features
- Records structural metadata of agent decisions (timestamps, resolution, accountability scope) without storing decision content
- Enables third-party attestation of agent decisions via external anchoring (proof of accountability)
- Supports multi-party agreements and bilateral decision declarations
- Integrates with x402 payment protocol for DAC (Decision Anchor Cost) settlement
- Provides MCP server and OpenAPI spec for interoperability with AI agents and tools

## Why It Matters for RAG Builders
Decision Anchor provides a critical infrastructure layer for AI agents to prove accountability in external transactions, ensuring trust and verifiability in multi-agent systems.
