## Summary
Dashies Plugin enables AI agents to build, publish, and schedule interactive dashboards that refresh automatically from data warehouses without requiring AI intervention after the initial setup. Dashboards are served at shareable URLs with versioning, access control, and scheduled data updates.

## Key Features
- AI-driven dashboard authoring with structured specs for SQL, columns, and refresh cadence
- Automated publishing to shareable URLs (e.g., your-handle.dashies.ai/slug) with versioning and rollback
- Scheduled refresh without AI intervention, ensuring deterministic and cost-efficient updates
- OAuth 2.1 + PKCE authentication with no API keys required
- Multi-warehouse support (Postgres, BigQuery, Snowflake, Redshift, Databricks, SQL Server)

## Why It Matters for RAG Builders
It bridges AI-generated dashboards with automated, scheduled data refreshes, eliminating the need for manual updates or AI re-runs, making it essential for scalable RAG and AI stack deployments.
