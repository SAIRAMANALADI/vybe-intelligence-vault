## Summary
ScribeDog is an open-source, privacy-focused WYSIWYG Markdown editor with built-in AI capabilities for local and cloud-based text generation, editing, and voice dictation. It enables users to write, format, and refine documents entirely offline while leveraging AI models for rewrites, translations, and agentic tasks.

## Key Features
- True WYSIWYG Markdown editing with distraction-free UI modes
- Agentic AI chat with tool-calling capabilities for multi-file edits and vault-wide operations
- Local AI integration (Ollama, Jan.ai, LM Studio) with optional cloud provider support
- Voice dictation via offline speech recognition (whisper.cpp)
- Automatic version history, linked notes, and customizable system prompts

## Why It Matters for RAG Builders
ScribeDog provides a privacy-first, offline-capable environment for AI-assisted writing and editing, making it ideal for users who need secure, local document processing with agentic AI capabilities.
