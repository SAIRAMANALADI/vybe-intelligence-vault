## Summary
An AI-powered revenue recovery engine designed to diagnose cart abandonment and overdue receivables using deterministic Python logic for execution and decision-making. It integrates with the Gemini API for AI-driven classification while enforcing strict guardrails, audit trails, and live re-check mechanisms.

## Key Features
- AI-driven diagnosis of cart abandonment and overdue receivables with guardrails
- Deterministic Python logic for execution, routing, and decision-making
- Live re-check eligibility rules to prevent stale-state actions
- Immutable audit trail logging for all system actions and decisions
- Concurrency safety via FileLock and idempotency testing
