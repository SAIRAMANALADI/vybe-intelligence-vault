## Summary
Code Brain provides repo-local infrastructure to enhance AI coding agents (Claude Code, Codex CLI, Antigravity) with persistent memory, BM25 code search, MCP tools, and guardrails. It ensures agents operate efficiently within a repository by managing context, hooks, and token-aware tooling.

## Key Features
- Shared project memory and context for multiple AI agents (Claude, Codex, Antigravity)
- BM25/FTS5-based code search with compact context packs to reduce token usage
- Token-aware MCP tools with profiles (usage, core, full) for controlled exposure
- Hook-based guardrails to block destructive operations, secret leaks, and excessive output
- Offline memory consolidation and salience-ranked HOT cache for faster session loads

## Why It Matters for RAG Builders
It provides a unified, repo-local operating layer that ensures AI coding agents operate efficiently with bounded memory, search, and guardrails, reducing token waste and improving reliability.
