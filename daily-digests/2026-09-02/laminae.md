## Summary
Laminae is an open-source Rust SDK designed as a modular layer between raw LLMs and production AI applications, providing guardrails, safety, personality enforcement, and learning capabilities. It has been archived but its core components (Cortex, Glassbox, Ironclad) were absorbed into the Thunder AI-powered multi-agent orchestrator.

## Key Features
- Modular Rust SDK with six independent safety layers (Psyche, Persona, Cortex, Shadow, Ironclad, Glassbox)
- Multi-agent cognitive pipeline (Id, Superego, Ego) for shaping LLM responses without user awareness
- Self-improving learning loop (Cortex) that converts user edits into reusable instructions
- Adversarial red-teaming (Shadow) for automated security auditing of AI outputs
- Process sandboxing (Ironclad) and I/O containment (Glassbox) with hard constraints on execution

## Why It Matters for RAG Builders
Laminae provides critical safety and control layers that bridge raw LLMs to production-ready AI, addressing persistent gaps in security, personality enforcement, and adaptive learning that most AI stacks overlook.
