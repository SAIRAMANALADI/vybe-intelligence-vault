## Summary
Offset Terminal is a terminal-based AI coding agent that implements speculative branching to run multiple AI models in parallel across isolated git worktrees, auto-merging the best-performing solution. It supports 12+ models, integrates LSP and DAP for code intelligence, and offers both free (Lite) and subscription-based (Plus) tiers.

## Key Features
- Speculative Branching: Forks git repositories into isolated worktrees, dispatches competing AI models simultaneously, and auto-merges the best-performing solution based on test suite results.
- Multi-Model Pipeline: Supports a planner → implementer → critic workflow for complex tasks.
- Code Intelligence: Integrates LSP and DAP clients for real-time code analysis, debugging, and symbol resolution.
- Browser Agent: Enables UI testing and interaction via an accessibility tree-based browser interface.
- Persistent Tasks: Supports task planning, implementation, testing, and resumption across sessions.

## Why It Matters for RAG Builders
Offset Terminal revolutionizes AI-driven code generation by introducing speculative branching, enabling parallel model execution and auto-merging of the best solution, significantly reducing hallucination risks and improving reliability for RAG/AI stack builders.
