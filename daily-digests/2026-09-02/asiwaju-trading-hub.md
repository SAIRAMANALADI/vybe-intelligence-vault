## Summary
A forensic-grade multi-agent quant trading ecosystem and zero-trust security middleware for Web3 algorithmic trading. It integrates AI-driven trading agents with a 5-layer security pipeline (AAS SDK) to intercept and validate trade signals before execution on Bitget Spot V2.

## Key Features
- Asiwaju Agent Shield (AAS) SDK: 5-layer zero-trust security pipeline for AI-driven trade execution, including prompt filtering, risk guardrails, re-entrancy locks, replay guards, and cryptographic signing.
- Multi-agent consensus engine (War Room) for AI-driven investment decisions with technical, risk, and on-chain analysis.
- Natural-language-to-code compiler for strategy backtesting and SVG-based equity curve visualization.
- Behavioral risk auditor (Guardian) for psychological bias detection in trading logs.
- Macro news digest (Sentinel) with sentiment analysis and market hype indexing.

## Why It Matters for RAG Builders
It provides a robust, security-first framework for integrating AI agents with real-world trading execution, ensuring safe and auditable algorithmic trading while mitigating risks like prompt injection and replay attacks.
