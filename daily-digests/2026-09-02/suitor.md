## Summary
Suitor is a local-first job-search assistant that helps users build candidate profiles, scan job sources, draft tailored application materials, and track applications using a local SQLite database. It operates entirely on the user's machine with no telemetry or hosted services.

## Key Features
- Local-only job search assistant with no telemetry or hosted services
- Recruiter-style onboarding for building detailed candidate profiles
- Profile-driven job scanning with configurable filters and scoring
- Local SQLite database for tracking applications, interviews, and outcomes
- Resume Studio for maintaining a master resume and drafting tailored materials

## Why It Matters for RAG Builders
Suitor streamlines the job search process by automating profile building, job scanning, and application tracking, reducing manual effort while maintaining privacy and control over data.
