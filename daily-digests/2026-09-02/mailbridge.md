## Summary
mailbridge is an email MCP (Model Context Protocol) server that enables AI agents like Claude, Codex, or Cursor to interact with various mail providers (iCloud, Outlook, Gmail, QQ, 163, IMAP) for full mailbox operations including search, read, draft, send, and bulk export. It operates with zero third-party dependencies and supports both English and Chinese.

## Key Features
- Zero third-party dependencies; runs with Python 3.9+ and no build step
- Supports multiple mail providers including iCloud, Gmail, Outlook, QQ, 163, and custom IMAP servers
- Full mailbox operations: search, read, draft, send, attachments, folders, and bulk export
- Bilingual support (English and Simplified Chinese) for tool descriptions and setup
- Secure credential management with local storage and revocable app passwords/OAuth registrations

## Why It Matters for RAG Builders
mailbridge enables AI agents to perform full email operations across diverse providers, bridging a critical gap for RAG systems needing real-world data access and interaction.
