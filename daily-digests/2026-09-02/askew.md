## Summary
Askew is a Vite plugin that transforms a running React app into a debugging surface for AI agents, enabling real-time inspection and modification of live DOM elements, computed styles, and design tokens without writing to disk until explicitly applied by the user.

## Key Features
- Real-time DOM element selection and inspection with computed cascade analysis
- Runtime design scale measurement (spacing, radius, color frequencies) derived from rendered page
- Held interaction state emulation (hover/focus) for accurate diagnostics
- Three-stage variant staging for live comparison of proposed fixes without disk writes
- Strict security model with controlled file writes, optimistic concurrency, and production build isolation

## Why It Matters for RAG Builders
Askew bridges the gap between AI agent capabilities and real-time UI debugging by providing live, measurable state that no static repo or screenshot can capture, enabling precise and actionable AI-driven design feedback.
