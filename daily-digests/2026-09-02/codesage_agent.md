## Summary
CodeSage is a multi-platform AI agent that enables RAG-based Q&A for YouTube tutorials and local codebases. It offers Chrome extension, desktop, and web interfaces powered by a shared FastAPI backend, supporting auto-translation, file parsing, and source attribution.

## Key Features
- Supports YouTube transcript Q&A with auto-translation for non-English videos
- Enables project codebase Q&A with file-level source attribution
- Multi-platform deployment (Chrome extension, desktop app, web app) with shared backend
- Smart caching of transcripts, embeddings, and FAISS indexes for instant re-querying
- Code-aware chat with syntax-highlighted, copyable responses

## Why It Matters for RAG Builders
CodeSage provides a practical, end-to-end RAG framework for integrating YouTube and codebase Q&A into AI agents with minimal setup.
