## Summary
CyClaw is a secure, offline-first local AI agent that operates as a personal RAG backend, enforcing safety invariants via LangGraph topology and exposing FastAPI and MCP server endpoints for integration with external tools like Claude Desktop.

## Key Features
- Enforces safety invariants via LangGraph topology, not prompts or config flags
- Supports hybrid mode with explicit user confirmation for external LLM fallback (Grok/Anthropic)
- Exposes FastAPI HTTP gateway and MCP server for integration with tools like Claude Desktop
- Includes optional per-user authentication, memory store, and filesystem/SQL/LAN connectors
- Tracks provider costs and enforces governance via audit trails and Numbat forensic streams

## Why It Matters for RAG Builders
CyClaw provides a robust, security-first framework for building trustworthy local RAG systems with enforced safety invariants and governance, critical for AI stack builders prioritizing offline operation and compliance.
