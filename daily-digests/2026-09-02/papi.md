## Summary
PAPI is an MCP-compatible structured project memory layer for AI coding assistants that persists project context (plans, builds, reviews, decisions) across sessions and tools. It enables AI agents to maintain continuity in project execution through a plan-build-review-release loop with hosted memory.

## Key Features
- Persistent project memory across AI sessions and tools via hosted engine
- Plan-build-review-release loop with structured handoffs for AI agents
- Active Decisions tracking with confidence levels and supersede history
- Real-time project dashboard and timeline for human oversight
- MCP toolset for AI assistants (orient, plan, build, review, release, etc.)

## Why It Matters for RAG Builders
PAPI solves the critical problem of AI agents losing project context between sessions by providing persistent, structured memory that enables continuous, coherent project execution.
