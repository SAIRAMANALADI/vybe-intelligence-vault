## Summary
Aethyn Browser MCP is an MCP server that enables AI agents to control a local Chromium browser through residential proxies, allowing runtime selection of country, city, and session identity per task. It supports both Aethyn's default proxies and custom HTTP proxies.

## Key Features
- Runtime per-task geo selection (country/city) for browser sessions
- Sticky identity per task with pinned exit IP
- Supports both Aethyn and custom HTTP proxies
- Tools for navigation, content extraction, and interaction (click, type, snapshot)
- Built-in IP verification to confirm geo targeting

## Why It Matters for RAG Builders
It provides essential runtime control over browser geolocation and session identity for AI agents, enabling accurate data scraping and interaction with country-specific web content.
