## Summary
Gleaph is a graph database optimized for the Internet Computer, combining GQL (Graph Query Language) with LARA, a stable graph storage layout, to enable vector-aware graph search and GraphRAG applications. It supports federated graph shards, prepared queries, and access-control-aware execution.

## Key Features
- GQL-compliant query language for standardized graph operations
- LARA storage model optimized for Internet Computer canisters
- Prepared queries for safe frontend-to-canister execution
- Federated graph shards for horizontal scaling
- Vector-aware graph search integrated with graph traversal

## Why It Matters for RAG Builders
Gleaph uniquely combines graph-native retrieval with vector-aware search and access control, making it essential for building advanced GraphRAG systems that require explainable, context-aware retrieval pipelines.
