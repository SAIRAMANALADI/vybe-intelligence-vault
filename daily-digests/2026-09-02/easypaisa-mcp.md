## Summary
Easypaisa MCP is a TypeScript-based MCP server that enables AI assistants to integrate with Pakistan's Easypaisa mobile wallet for payments, refunds, transaction inquiries, and OTC flows without requiring custom gateway code. It provides 8 tools for seamless financial interactions via AI.

## Key Features
- 8 pre-built tools for Easypaisa payment flows (payments, OTC, refunds, statements)
- HMAC-based credential authentication for secure transactions
- Seamless integration with AI assistants like Claude via MCP
- Supports mobile account, OTC, and standard payment flows
- Transaction status checks and statement retrieval

## Why It Matters for RAG Builders
It simplifies integrating Pakistan's leading mobile wallet into AI workflows, enabling AI assistants to handle real-world financial transactions securely and without custom backend development.
