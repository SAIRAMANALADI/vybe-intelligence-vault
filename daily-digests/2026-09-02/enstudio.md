## Summary
Enpii Studio is an Electron-based desktop IDE that integrates an AI-powered coding assistant with a modular terminal, code editor, Git interface, and browser inspector. It provides a unified workspace for agentic coding with multi-vendor LLM support and advanced terminal features like SSH and command-card timelines.

## Key Features
- AI-powered coding assistant with multi-vendor LLM integration
- Modular terminal with SSH support and command-card timelines
- Built-in code editor with syntax highlighting via CodeMirror 6
- Visual Git interface for staging, committing, and branch management
- Integrated browser inspector for web development workflows
