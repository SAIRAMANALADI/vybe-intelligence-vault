## Summary
Tempa is an agentic automation harness that converts software specifications into fully implemented applications by orchestrating agentic coding CLIs (Claude Code, GitHub Copilot CLI, or OpenAI Codex CLI) to handle clarification, planning, implementation, and QA autonomously. It provides both a web dashboard and CLI for seamless project automation.

## Key Features
- Automates the full software development lifecycle from specification to QA using agentic CLIs
- Supports multiple agentic coding backends (Claude Code, GitHub Copilot CLI, OpenAI Codex CLI) per pipeline stage
- Provides both a web dashboard and CLI for user interaction and control
- Includes a clarification loop to resolve ambiguities in specifications before implementation
- Tracks progress and logs in real-time with resumable workflows
