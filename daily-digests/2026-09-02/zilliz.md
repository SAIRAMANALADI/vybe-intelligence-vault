## Summary
This repository profiles Zilliz Cloud, a managed vector database service built by the Milvus team, offering RESTful APIs for cluster management and vector operations. It serves as a third-party documentation hub for Zilliz's public API surface, including control and data plane endpoints.

## Key Features
- Provides Control Plane API for cluster management (create, modify, suspend)
- Offers Data Plane API for vector operations (collections, search, indexing)
- Supports multiple deployment models: Serverless, Dedicated, and BYOC
- Includes comprehensive API documentation and rate limits
- Integrates with Milvus ecosystem for scalable vector search
