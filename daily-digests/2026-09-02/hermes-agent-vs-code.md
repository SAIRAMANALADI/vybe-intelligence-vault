## Summary
Hermes Agent for VS Code is a VS Code extension that provides a sidebar chat interface with editor-aware context, workspace file references, and slash-based skills. It integrates with the Hermes CLI for AI-powered coding assistance, offering session history, run settings, and streaming output.

## Key Features
- Sidebar chat view with editor-aware context (current file/selection)
- Workspace file search and local file/folder picker via `@` and `+` commands
- Slash-based skill selection and session history with rename/delete
- Streaming assistant output and run settings (approval mode, model, effort)
- Hermes CLI integration for real model backend (e.g., deepseek-v4-flash)
