## Summary
A real-time social media monitoring tool designed to detect content breakouts for brand-creator programs on Warble. It continuously polls post metrics, scores momentum using a state machine, and alerts brands only when sustained growth is confirmed, ensuring trustworthy and auditable detection.

## Key Features
- Continuous polling of Warble API with rate limit compliance (250 req/hr)
- Deterministic state machine for breakout detection requiring sustained growth (4 consecutive qualifying intervals)
- Deduped alerting system to prevent duplicate notifications
- Grounded LLM agent for explainable marketing insights tied to real metrics
- Replay-based debugging to catch silent detector failures in production

## Why It Matters for RAG Builders
It provides a reliable, auditable system for detecting content breakouts in real-time, reducing false positives and ensuring brands are alerted only when sustained momentum is confirmed, which is critical for AI-driven social media strategies.
