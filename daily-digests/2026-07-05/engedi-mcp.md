## Summary
Engedi MCP Server provides a unified MCP interface for accessing 54 REST endpoints across finance, travel, weather, news, commerce, and knowledge domains. It aggregates real-time data from 30+ sources and supports USDC micropayments for premium endpoints via the x402 protocol.

## Key Features
- 54 REST endpoints covering finance, travel, weather, news, commerce, and knowledge
- Aggregates data from 30+ sources (CoinGecko, Yahoo Finance, Google Flights/Hotels, Open-Meteo, etc.)
- Supports USDC micropayments via x402 protocol for premium endpoints
- Unified MCP interface for AI agents to access real-time data
- Automated payment handling for paid endpoints

## Why It Matters for RAG Builders
