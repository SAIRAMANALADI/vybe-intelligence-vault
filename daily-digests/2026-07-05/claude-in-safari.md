## Summary
An open-source Safari extension that enables Claude to interact with and automate browser tasks locally, providing a chat sidebar and per-action safety approvals. It allows users to navigate, click, type, and read web pages using their own Claude Code subscription or Anthropic API key.

## Key Features
- Local execution with no middleman or backend dependencies
- Supports both Claude Code and Anthropic API keys for flexibility
- 33+ tools for navigation, interaction, and automation (e.g., click, type, read_page, screenshot)
- Per-action safety approvals and structured error handling
- Chat sidebar with markdown support and model picker

## Why It Matters for RAG Builders
It enables local, secure browser automation for AI agents like Claude, reducing dependency on proprietary tools and enhancing privacy for RAG stack builders.
