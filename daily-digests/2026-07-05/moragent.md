## Summary
MORAGENT is an MCP plugin for Claude Code that transforms it into a full AI Agent Studio, enabling users to design, learn, and deploy agentic AI projects without writing code. It provides a guided menu, 12 MCP tools, and enforces best practices like reuse, quality gates, and bilingual support (English/Spanish).

## Key Features
- 12 MCP tools for agentic AI project management, including advisors, quality checks, and scaffolding
- Bilingual support (English/Spanish) with persistent language settings
- Guided menu (/moragent) for learning, creating, and operating agent projects
- Orchestration pattern recommendations (pipeline, parallel, orchestrator-workers, evaluator-optimizer, router)
- Workspace scanning and infrastructure analysis to recommend reusing existing agents/skills

## Why It Matters for RAG Builders
MORAGENT streamlines the creation and management of AI agents in Claude Code, reducing setup time and enforcing best practices for multi-agent systems, making it essential for AI stack builders focused on agentic workflows.
