## Summary
Starlight Intelligence System provides a shared, attested memory substrate and open protocol (SIP) for coordinating multiple AI agents across tools like Claude Code, Cursor, and Gemini. It enables persistent, cross-tool knowledge sharing with provenance tracking and governance layers.

## Key Features
- Open Starlight Intelligence Protocol (SIP) for sovereign memory and governance
- Six semantic vaults (Strategic, Technical, Creative, Operational, Wisdom, Horizon) for structured knowledge storage
- Hybrid retrieval with SQLite FTS5 indexing and temporal reasoning for efficient memory access
- MCP server exposing 10+ tools (sis_*) for seamless integration with AI tools like Claude Code and Cursor
- Estate Factory pattern for scalable agent orchestration (Mind + Mesh + Steward layers)
