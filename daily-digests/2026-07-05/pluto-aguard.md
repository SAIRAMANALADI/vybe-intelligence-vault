## Summary
Pluto AgentGuard is a security launch gate for AI agents that tests policies against attack scenarios, simulates risk impact, maps results to an OWASP-inspired control framework, and generates launch evidence. It provides offline, vendor-agnostic security validation for AI agent deployments.

## Key Features
- Static analysis for secrets, misconfigs, and unsafe AI patterns
- Policy coverage testing against 22 attack scenarios across 6 packs
- What-if risk impact simulation before applying policy changes
- OWASP-inspired control coverage reporting (20 controls)
- Launch readiness evidence generation and baseline drift detection

## Why It Matters for RAG Builders
It provides critical pre-deployment security validation for AI agents, ensuring policies are tested against real-world attack scenarios and reducing launch risks.
