## Summary
ORIRO CLI is a free, keyless terminal AI coder that enables users to write, run, and automate code in 100+ languages without requiring paid API keys. It includes features like on-device voice interaction, a deterministic security guardian, multi-agent orchestration, and web inspection tools.

## Key Features
- Free, keyless AI coding with failover across multiple providers
- On-device voice interaction and avatar with TTS/STT capabilities
- Deterministic Guardian V3 security layer blocking malicious tool calls
- ORIRO-Head for keyless structural web inspection and reverse-engineering of live sites into code/specs
- Multi-agent orchestration with MCP connectors and user-extensible skills

## Why It Matters for RAG Builders
