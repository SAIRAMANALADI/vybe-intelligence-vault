## Summary
A deployable Model Context Protocol (MCP) server for MyFitnessPal that enables remote access to nutrition, exercise, and body measurement data via a standardized API. It acts as a bridge between MyFitnessPal's data and AI agents or applications, supporting operations like food diary management, nutrition tracking, and custom food creation.

## Key Features
- Comprehensive MyFitnessPal data access via MCP tools (food diary, exercises, measurements, goals, water intake, and reports)
- Supports remote deployment with OAuth 2.1 and streamable HTTP transport for secure AI agent integration
- Enables custom food creation and management within MyFitnessPal's ecosystem
- Authentication via Firefox profile cookies or JSON cookies file, avoiding password-based logins
- Dockerized deployment with CI/CD for multi-architecture support

## Why It Matters for RAG Builders
It provides a standardized, secure, and extensible way for AI agents to interact with MyFitnessPal's nutrition and fitness data, enabling personalized health and wellness applications.
