## Summary
An autonomous AI agent that automates end-to-end job outreach by scraping job boards, identifying decision-makers, crafting personalized emails, and tracking responses. Built with Claude Code skills and deployed on Oracle Cloud for daily autonomous operation.

## Key Features
- Scrapes job boards (Station F) using Playwright for targeted roles (AI/Backend/Data/MLOps)
- Identifies and verifies decision-makers via multi-source research (team pages, LinkedIn, JSON-LD)
- Generates fully personalized emails (no templates) with opportunity-aware contract asks
- Self-healing architecture with pre-flight checks and health monitoring
- Tracks strategy performance and adapts outreach based on reply rates
