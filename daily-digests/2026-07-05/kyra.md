## Summary
Kyra Agent is a Base-native AI agent console designed to deploy Telegram-native agents with approval-first onchain workflows. It enables read-only AI interactions via Telegram while preparing wallet-approved execution workflows without autonomous fund movement or hidden transactions.

## Key Features
- Telegram-native AI agent deployment with read-only interactions
- Approval-first onchain workflows with wallet-based authorization
- Backend-only sensitive integration handling for security
- Modular agent templates (Operator, Scout, Steward, etc.) with customizable module stacks
- Hardened execution foundation with gated transaction readiness (Phase 7 complete)
