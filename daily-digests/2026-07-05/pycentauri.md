## Summary
A Python-based local-network toolkit for controlling and monitoring Elegoo Centauri Carbon 3D printers (CC1 and CC2 models) without cloud dependency. It provides a unified interface across multiple surfaces: Python library, CLI, MCP server, REST/SSE HTTP server, web dashboard, and RTSP bridge.

## Key Features
- Unified Python library and CLI for CC1 and CC2 printers with auto-detection
- MCP server integration for AI agents to interact with printers
- REST/SSE HTTP server with a built-in web dashboard for real-time monitoring and control
- RTSP bridge for streaming printer webcam feeds to NVR or media systems
- Canvas multi-filament support for CC2 printers with auto-refill and filament detection

## Why It Matters for RAG Builders
It enables AI agents and automation systems to directly interact with and control 3D printers locally, eliminating cloud dependency and expanding the scope of automated manufacturing workflows.
