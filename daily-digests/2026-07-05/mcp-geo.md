## Summary
mcp-geo is an MCP server that tracks AI visibility for brands by measuring citations across major AI engines like ChatGPT, Claude, Perplexity, Gemini, and Google AI Overviews. It enables automated SEO and GEO (Generative Engine Optimization) analysis through MCP-compatible clients like Claude.ai.

## Key Features
- Real-time AI visibility tracking across 5 major AI engines with per-engine breakdowns
- Automated weekly scans via Cloudflare Cron Trigger with configurable refresh frequency
- Six MCP tools for visibility analysis, competitor comparison, and content gap identification
- Self-hosted deployment on Cloudflare Workers with D1 database for data persistence
- Security features like CONNECT_SECRET for OAuth flow control and accurate citation matching

## Why It Matters for RAG Builders
