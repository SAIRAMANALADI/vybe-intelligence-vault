## Summary
Tiro is a local-first reading OS that saves web pages and emails as markdown files, enriches them with AI-generated tags and summaries, and uses Claude Opus 4.6 for cross-document reasoning and deep analysis. It prioritizes data ownership, security, and minimal friction for users.

## Key Features
- Local-first storage of web pages and emails as markdown files with SQLite and ChromaDB backend
- AI enrichment with tags, entities, summaries, and contradictions detection using Claude Opus 4.6
- Password-based authentication with bcrypt hashing and session management
- Atomic ingestion pipeline with rollback on failure and data integrity checks
- Minimal friction UI with full keyboard navigation and responsive design for mobile access

## Why It Matters for RAG Builders
Tiro provides a secure, local-first foundation for managing and enriching documents with AI, enabling RAG builders to integrate structured, enriched data pipelines with minimal cloud dependency.
