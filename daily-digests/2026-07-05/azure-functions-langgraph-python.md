## Summary
A Python library that deploys LangGraph graphs as Azure Functions HTTP endpoints with minimal boilerplate, enabling serverless execution of AI workflows in Azure. It bridges LangGraph's graph-based AI orchestration with Azure Functions' serverless compute model.

## Key Features
- Zero-boilerplate deployment of LangGraph graphs as Azure Functions HTTP endpoints
- Native support for invoke, stream, health, and state endpoints
- Per-graph authentication and route prefix customization
- Persistent storage backends (Azure Blob, Table, PostgreSQL, SQLite, Cosmos DB)
- LangGraph Platform API compatibility for threads, runs, and state management

## Why It Matters for RAG Builders
It enables AI engineers to deploy LangGraph-based RAG systems as serverless Azure Functions, reducing infrastructure overhead and simplifying integration with Azure's ecosystem.
