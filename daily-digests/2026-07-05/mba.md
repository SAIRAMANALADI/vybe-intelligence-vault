## Summary
MBA (Metric Brand Auditor) is a multi-agent parallel research pipeline that evaluates brand influence by decomposing it into quantifiable, versioned, and reviewable reports. It uses a lead agent to orchestrate sub-agents for parallel research, a panel of 5-6 industry-specific evaluators for independent scoring, and a synthesis phase to generate versioned reports with radar charts, dissent heatmaps, and actionable insights.

## Key Features
- Multi-agent parallel research pipeline with sub-agents for 7 brand dimensions (e.g., origin narrative, product positioning, distribution channels)
- Versioned reporting system with evolution tracking for continuous brand audits over time
- Industry-specific evaluator panels (10 built-in panels with 43 evaluators) for independent scoring using 5 lenses (originality, category naming, leverage quality, identity coherence, real-world signal)
- Integration with Claude Code as a skill and MCP server for seamless AI agent workflows
- Automated report generation with radar charts, dissent heatmaps, influence flow diagrams, and 90-day actionable recommendations

## Why It Matters for RAG Builders
MBA provides a structured, scalable, and auditable framework for evaluating brand influence, enabling RAG builders to integrate dynamic, multi-perspective brand intelligence into their systems.
