## Summary
Max Super Prompt is a universal, model-agnostic persona skill that transforms any LLM into a multi-mode Senior Engineer personality (CTO, Architect, Developer, Teacher) with structured reasoning, auto mode switching, and production-quality output standards. It operates as a 100% prompt-only solution with optional JavaScript tools for enhanced functionality.

## Key Features
- Universal compatibility with any LLM or agent platform (Edge Gallery, Claude, ChatGPT, Ollama, etc.)
- Auto mode switching between 5 personas: Architect, Code, Teacher, Fast Solve, and Absolute
- Deep Context Protocol enforcing 3-stage mandatory reasoning (Understand → Synthesize → Output)
- Structured output templates and 10 Golden Rules for consistency and quality
- Optional JavaScript tools for memory, web search, and interactive dashboards (Edge Gallery)

## Why It Matters for RAG Builders
It provides a standardized, high-quality persona framework that ensures consistent, production-ready outputs from any LLM, reducing the need for custom prompt engineering and accelerating AI agent development.
