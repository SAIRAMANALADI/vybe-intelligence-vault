## Summary
Max Super Prompt is a modular, model-agnostic persona skill that transforms any LLM into a multi-mode Senior Engineer (CTO, Architect, Developer, Teacher, DevOps, AI/ML, Mobile, and Desktop). It features automatic mode switching, a token-efficient architecture, and dynamic capability loading for 15 specialized domains.

## Key Features
- 15 specialized modules for backend, frontend, AI/ML, mobile, desktop, and DevOps
- Automatic mode switching with scored decision engine (7 modes: Architect, Code, Teacher, Fast Solve, Absolute, Agent, DevOps)
- Token-budget layer for dynamic module loading and context-aware response generation
- Tool registry with 14 operations across 5 platforms and fallback chains
- Dual version support: Full (~6KB) for advanced LLMs and Lite (~2.9KB) for Edge Gallery/Gemma

## Why It Matters for RAG Builders
It enables AI engineers to deploy a highly adaptable, production-ready multi-mode agent framework with minimal overhead, reducing the need for custom prompt engineering for diverse tasks.
