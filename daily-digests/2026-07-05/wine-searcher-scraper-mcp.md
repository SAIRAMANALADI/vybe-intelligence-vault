## Summary
A Model Context Protocol (MCP) bridge to the Wine-Searcher platform, enabling AI agents to fetch real-time wine pricing, critic scores, and popularity rankings via an Apify Actor. This repository provides client configuration snippets for MCP-compatible AI tools like Claude, Cursor, and Cline.

## Key Features
- Provides structured wine data (pricing, scores, popularity) via MCP for AI agents
- Pay-per-extraction pricing model ($0.025 per wine)
- Client configurations for Claude Desktop, Cursor, and Cline
- Supports LWIN code-based lookups for precise wine identification
- Integrates with Apify for scalable scraping and anti-detection measures

## Why It Matters for RAG Builders
It enables AI agents to fetch real-time, structured wine data directly within MCP-compatible tools, reducing the need for manual data collection and improving RAG pipeline accuracy for wine-related queries.
