## Summary
Pronounce is a developer-focused pronunciation tool that provides accurate pronunciations for 1,790+ technical terms, jargon, and project names, including citations from creators or official sources. It offers a CLI, web interface, VS Code extension, and integrations with AI agents like Claude Code and MCP servers.

## Key Features
- 1,790+ entries with citable sources for pronunciations, including creator clarifications and community consensus
- Multi-platform support: CLI, web app, VS Code extension, and MCP server for AI agents
- Zero dependencies for CLI (Bash-based) with optional TTS engine integration
- Cross-tool integrations (Claude Code, Codex CLI, Kiro, Cursor, Continue, Zed, Cline)
- Interactive quiz, voice search, and real-time pronunciation lookup
