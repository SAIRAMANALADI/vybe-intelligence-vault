## Summary
A multi-purpose MCP server and CLI tool for Botverse, enabling video transcoding, document conversion, and transcription for AI agents and developers. It provides seamless integration with MCP clients and shell environments for media processing tasks.

## Key Features
- MCP server for AI agents to handle video transcoding and document conversion
- CLI tool for shell-based media processing and automation
- Supports multiple formats (MP4, WebM, ProRes, GIF, MP3, DOCX, PDF, HTML, XLSX)
- Speaker-labeled transcription with diarization and AI speaker naming
- No AWS or FFmpeg required; integrates directly with Botverse cloud

## Why It Matters for RAG Builders
It simplifies media processing for RAG pipelines by offloading transcoding and document conversion to a specialized cloud service, reducing infrastructure overhead and improving agent efficiency.
