## Summary
Rara is a kernel for AI agents, providing lifecycle management, memory systems, tool access, and guardrails similar to an operating system kernel. It enables developers to define agent behavior while handling core infrastructure like scheduling and I/O.

## Key Features
- OS-inspired kernel architecture for agent lifecycle management
- Tape memory system for append-only fact modeling with anchors and sessions
- Proactive heartbeat-driven background actions for continuous agent operation
- Multi-channel I/O support (Telegram, Web, TUI, WeChat)
- Extensible skills system and auto-deployment via git updates

## Why It Matters for RAG Builders
Rara provides a robust foundation for building scalable, multi-channel AI agents with built-in memory and lifecycle management, reducing development overhead for RAG stack builders.
