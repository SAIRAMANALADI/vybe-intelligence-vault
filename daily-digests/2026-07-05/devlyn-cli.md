## Summary
devlyn-cli is a context and harness engineering toolkit for Claude Code and other AI agents, enabling structured prompt engineering, agent orchestration, and automated pipelines for tasks like debugging, code review, UI design, and product specification generation.

## Key Features
- Multi-agent skill installation and management for Claude Code, Codex CLI, oh-my-pi, and Pi
- Structured prompt generation and specification creation via `/devlyn:ideate`
- Hands-free coding pipeline with `/devlyn:resolve` for bug fixes, features, and refactors
- Automated benchmarking and pair-mode verification for AI agent performance comparison
- Git-integrated checkpoints and rollback capabilities for safe development workflows

## Why It Matters for RAG Builders
It streamlines AI-driven development workflows by providing a standardized, automated pipeline for agent orchestration, context engineering, and performance benchmarking, reducing manual effort and improving reproducibility.
