## Summary
A Model Context Protocol (MCP) server enabling AI agents to understand and generate images and videos across multiple providers (Gemini, OpenAI, Grok) with support for multimodal reasoning, text-to-image/video, and image-to-image/video operations.

## Key Features
- Multimodal understanding for images and videos with reasoning capabilities
- Cross-provider support (Gemini, OpenAI, Grok) with quality/cost tier options
- Text-to-image, image-to-image, text-to-video, and image-to-video generation
- Leaderboard-ranked model selection with auto-fallback chains
- Dual transport modes (stdio for single-user, HTTP for multi-user) with credential isolation

## Why It Matters for RAG Builders
It provides a unified, multi-provider interface for multimodal AI operations, essential for RAG systems requiring image/video understanding or generation.
