## Summary
ZA is an AI-native travel concierge that transforms unstructured travel requests into optimized, disruption-risk-scored recommendations using a multi-model gateway. It integrates real-time flight tracking, cost/latency monitoring, and proactive disruption alerts while supporting offline operation and cloud deployment.

## Key Features
- Multi-model gateway with fallback chains and cost/latency tracking
- Evidence-weighted disruption risk scoring using real-world data (e.g., late-arriving aircraft, weather, airline reliability)
- Proactive post-purchase monitoring with live ADS-B tracking and alerts
- Points/miles arbitrage for cost-effective travel recommendations
- Offline-capable with deterministic mock providers and full CI/CD security gates

## Why It Matters for RAG Builders
