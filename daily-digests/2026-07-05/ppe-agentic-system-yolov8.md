## Summary
A real-time, web-based deep learning system that monitors construction-site safety compliance using a custom-trained YOLOv8 model and an autonomous safety-supervisor agent. It detects PPE violations in images, videos, and live webcam feeds, escalates incidents, and generates audited reports.

## Key Features
- Custom-trained YOLOv8 model (89.1% mAP) for PPE detection with spatial validation and NMS post-processing
- Autonomous safety-supervisor agent with policy-driven escalation and audited action trails
- Interactive React frontend with real-time analytics, live webcam streams, and one-click PDF incident reports
- Hybrid architecture combining deterministic rules for escalation with LLM-powered analytics and chat assistants
- SQL-backed persistence for incidents, session history, and agent tool calls with full auditability
