## Summary
AgentForge is an open-source infrastructure platform for autonomous AI agents, providing version control, package management, marketplace discovery, and goal-based orchestration. It combines GitHub-like repositories, npm-compatible registries, and a unified search system tailored for AI agents.

## Key Features
- Semantic Diff engine for tracking agent capability evolution
- npm-compatible registry for publishing and installing agent packages
- Goal system enabling autonomous agent task discovery and completion
- Unified search across agents, skills, and capabilities
- Gateway architecture with auth, routing, and intelligent proxying

## Why It Matters for RAG Builders
AgentForge provides the foundational infrastructure to deploy, manage, and scale autonomous AI agents at production level, critical for building robust RAG systems with multi-agent collaboration.
