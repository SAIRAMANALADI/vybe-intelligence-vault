## Summary
AgentFlow is a self-hosted, protocol-agnostic orchestrator that connects AI coding agents (Claude, Codex, Copilot, Gemini) to external tools, APIs, or human workflows via a unified, event-driven messaging architecture. It acts as a central nervous system for agentic code generation, enabling multi-platform collaboration, session awareness, and secure, auditable workflows.

## Key Features
- Multi-protocol routing for AI agents and messaging platforms (Telegram, Discord, Slack, SMS, etc.)
- Session-aware context management across platforms and agents
- Pluggable adapters for extensibility (10-line Python files to add new integrations)
- Human-in-the-loop approval gates for destructive operations
- Event sourcing for auditing, replay, and debugging agent decisions

## Why It Matters for RAG Builders
AgentFlow provides a critical orchestration layer for RAG/AI stacks by enabling seamless integration of multiple AI agents, messaging platforms, and human workflows into a unified, auditable, and secure system.
