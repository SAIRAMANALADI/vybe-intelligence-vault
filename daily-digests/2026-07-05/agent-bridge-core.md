## Summary
AgentFlow is a self-hosted, protocol-agnostic orchestrator that connects AI coding agents (Claude, Codex, Copilot, Gemini) to external tools, APIs, or human workflows via a unified, event-driven messaging architecture. It acts as a central nervous system for AI workforce collaboration, enabling multi-platform routing, session awareness, and human-in-the-loop approvals.

## Key Features
- Multi-protocol routing for AI agents (Claude, Codex, Gemini, etc.) to messaging platforms (Telegram, Discord, Slack) and APIs
- Session awareness and context preservation across platforms and interactions
- Pluggable adapters for custom integrations with minimal code
- Human-in-the-loop approval gates for destructive operations
- Event sourcing for auditing, replay, and debugging agent decisions
