## Summary
Kronos Agent OS (KAOS) is a self-hosted runtime for durable AI agents that provides memory, skills, tool integration, automations, and optional multi-agent coordination. It supports local and cloud-based deployments with a focus on safety, modularity, and extensibility.

## Key Features
- Durable agent runtime with session memory and long-term recall using FTS5, Mem0, and knowledge graphs
- Modular skill packs and dynamic tool integration via MCP and custom tools
- Automations for scheduled jobs, analytics, and competitor monitoring with pluggable data sources
- Optional swarm mode for multi-agent coordination with SQLite-based arbitration
- Local-first safety defaults with configurable capability gates for dynamic tools and MCP servers

## Why It Matters for RAG Builders
KAOS provides a robust, self-hosted foundation for building and deploying durable AI agents with memory, skills, and tool integration, making it essential for developers seeking full control over agent behavior and data.
