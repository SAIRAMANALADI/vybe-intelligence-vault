## Summary
Antigravity Graviton is a deterministic TDD governance harness and memory persistence plugin for the Google Antigravity agentic IDE, designed to prevent 'control-flow hallucinations' by enforcing rigid quality gates, runtime verification, and persistent session state memory.

## Key Features
- Enforces TDD quality gates to prevent uncontrolled agentic behavior
- Zero-trust syntax guard via AST verification to catch errors pre-execution
- Persistent state and fact memory using SQLite for cross-session consistency
- Pre-delivery auditor (Checker Mode) to validate task completion rigorously
- Layout overlap detection for automated media translation pipelines

## Why It Matters for RAG Builders
It ensures AI coding agents adhere to structured, verifiable workflows, reducing errors and improving reliability in agentic IDE environments.
