## Summary
Foggy is a collaborative web application that integrates interactive whiteboards, graph-based boards, and text documents into a single hierarchical project space, enabling seamless workflows from ideation to structured materials for teams.

## Key Features
- Unified project space combining whiteboards, graphs, and text documents for continuous workflows
- Real-time collaborative editing with multiplayer cursors and WebSocket-based sync service
- AI-powered features including board summarization, project structuring, and template generation
- Support for multiple board types (Simple, Graph, Doc) with rich toolsets and embeds
- End-to-end testing with Playwright and modular microservice architecture

## Why It Matters for RAG Builders
Foggy provides a unified, collaborative workspace that reduces context switching for teams, making it essential for AI engineering stacks focused on real-time collaboration and structured ideation workflows.
