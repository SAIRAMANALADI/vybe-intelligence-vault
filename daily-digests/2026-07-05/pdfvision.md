## Summary
pdfvision is a CLI and library that enables AI agents to process PDFs with human-like vision by extracting text, layout, and rendered page images in a single pass. It provides structured outputs, warnings for extraction failures, and supports OCR, search, and visual region detection for reliable PDF understanding.

## Key Features
- Multi-format output (Markdown, JSON, XML, TOON) for LLM compatibility
- Human-like PDF vision with text, layout, and rendered images in one pass
- Silent extraction failure detection with coverage stats and warnings
- OCR support for scanned PDFs with multi-language support
- Visual region detection and search with bounding box outputs for precise zooming

## Why It Matters for RAG Builders
pdfvision eliminates silent PDF extraction failures and provides structured, high-fidelity signals that AI agents need to reliably interpret PDFs, making it essential for RAG pipelines handling document-heavy workloads.
