## Summary
AgentGuard is an AI-powered security tool that combines static analysis rules with GLM-5.2 LLM capabilities to detect, verify, fix, and self-validate security vulnerabilities in Python and JavaScript/TypeScript codebases. It automates the entire security pipeline in a single command.

## Key Features
- Multi-language support (Python, JavaScript/TypeScript) with 150+ built-in rules
- GLM-5.2 LLM integration for false-positive filtering, context-aware fixes, and self-validation
- One-command pipeline: scan → verify → fix → validate
- SARIF and JSON output for CI/CD integration
- Free tier with Pro trial and paid cloud-based fixes

## Why It Matters for RAG Builders
AgentGuard streamlines security workflows by automating vulnerability detection, verification, and fixes using AI, reducing manual effort and false positives for RAG builders integrating secure code practices.
