## Summary
A Model Context Protocol (MCP) server that enables AI agents and LLMs to interact with Bugzilla instances for bug management, comments, attachments, and metadata discovery via secure API integration.

## Key Features
- Enables AI agents to search, view, create, and update bugs in Bugzilla
- Supports secure API key authentication or anonymous read-only access
- Facilitates comment management and file attachments via Base64 strings
- Provides metadata discovery for products, components, and fields
- Offers both npx and manual deployment options for flexibility

## Why It Matters for RAG Builders
It bridges AI agents with Bugzilla, enabling seamless bug lifecycle management and context-aware workflows for AI-driven development and issue resolution.
