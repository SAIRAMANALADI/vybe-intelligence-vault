## Summary
A Docker-based runtime harness for Anthropic's Claude Code agentic CLI, providing isolated, pre-configured environments with multiple interfaces (CLI, HTTP API, MCP server, Telegram bot, and cron scheduler) for seamless integration into AI workflows.

## Key Features
- Multi-modal runtime harness for Claude Code with persistent sessions and automatic resumption
- Supports five distinct interfaces: Interactive CLI, Programmatic CLI, HTTP API, MCP server, and Telegram bot
- Pre-installed dev toolchain (Go, Python, Node.js, Kubernetes, Terraform, databases) or minimal image option
- OpenAI-compatible endpoint for seamless integration with existing AI stacks and LiteLLM
- Workspace isolation, structured logging, skill injection, and resource-hardened container security

## Why It Matters for RAG Builders
It provides a standardized, secure, and flexible runtime environment for Claude Code, enabling AI engineers to integrate agentic coding capabilities into their RAG and AI pipelines with minimal setup overhead.
