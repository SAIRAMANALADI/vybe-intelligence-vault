## Summary
A plugin that enables AI coding assistants to generate native, fully-editable draw.io diagrams from natural language prompts, supporting multi-client integrations like Kiro, Claude, Cursor, and Copilot CLI. It ensures high-quality, editable diagrams with domain-specific physics and validation.

## Key Features
- Generates native draw.io XML diagrams (not Mermaid imports) with fully editable shapes and connectors
- Supports multiple AI coding assistants (Kiro, Claude, Cursor, Copilot CLI, Antigravity) via MCP integration
- Includes domain-specific physics for accurate architecture, engineering, and org chart diagrams
- Auto-validation and error-checking for diagram layout and formatting before presentation
- Round-trip editing for modifying existing `.drawio` files and re-rendering

## Why It Matters for RAG Builders
It bridges the gap between natural language AI prompts and high-fidelity, editable diagram generation, enabling seamless integration of draw.io's native capabilities into AI-driven workflows for architecture, engineering, and documentation tasks.
