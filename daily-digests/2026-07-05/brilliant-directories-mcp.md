## Summary
Official MCP server for Brilliant Directories that enables AI agents to interact with BD sites via a standardized API. Provides tools to manage members, posts, leads, reviews, pages, and other resources exposed by Brilliant Directories' REST API.

## Key Features
- Provides MCP-compatible tools for managing BD site resources (members, posts, pages, etc.)
- Supports both hosted (easy) and self-hosted (advanced) deployment options
- Includes OpenAPI 3.1 specification for resource discovery and validation
- Offers granular API key permissions via BD's Advanced Endpoints
- Automatic updates via npm for self-hosted deployments
