## Summary
This repository provides an official Model Context Protocol (MCP) server for Brilliant Directories, enabling AI agents to interact with BD sites via a standardized API. It allows seamless integration of AI tools with BD resources like members, posts, leads, reviews, and pages through a simple configuration.

## Key Features
- Provides MCP-compatible interface for Brilliant Directories' REST API
- Supports bidirectional data operations (read, create, update, delete) for BD resources
- Offers both hosted (easy) and self-hosted (advanced) deployment options
- Includes detailed setup guides for popular AI clients (Claude, Cursor, Windsurf, etc.)
- Enforces API permission management via Advanced Endpoints toggle
