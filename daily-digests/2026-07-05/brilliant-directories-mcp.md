## Summary
Official MCP server for Brilliant Directories that enables AI agents to interact with a Brilliant Directories site via a standardized API. Provides tools to manage members, posts, leads, reviews, pages, and other resources exposed by the BD REST API.

## Key Features
- Enables AI agents to manage BD site resources (members, posts, pages, etc.) via MCP tools
- Supports both hosted (Easy) and self-hosted (Advanced) deployment options
- Includes OpenAPI 3.1 spec for resource discovery and integration
- Provides granular API key permissions for security and least-privilege access
- Compatible with major AI clients (Claude, Cursor, Windsurf, n8n, etc.)
