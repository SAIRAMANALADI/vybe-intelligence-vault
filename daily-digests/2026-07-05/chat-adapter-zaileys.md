## Summary
A WhatsApp adapter for the Chat SDK that integrates with Zaileys, enabling rich media messaging, native buttons, real message history, polls, and scheduling for AI-driven chat applications.

## Key Features
- Native WhatsApp buttons and cards via Chat SDK integration
- Real message history with durable storage (SQLite, Postgres, Redis, etc.)
- Decrypted poll votes with zero manual bookkeeping
- Scheduled messages with persistence across restarts
- Full Zaileys client access for advanced WhatsApp features (media, reactions, groups, etc.)

## Why It Matters for RAG Builders
This adapter enables AI-driven chat applications to seamlessly integrate WhatsApp with robust features like native buttons, real message history, and polls, expanding the reach and functionality of RAG/AI systems.
