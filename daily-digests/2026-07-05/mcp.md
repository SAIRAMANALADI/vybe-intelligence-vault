## Summary
A Model Context Protocol (MCP) server for GoReleaser that provides AI assistants with tools to validate configurations, detect deprecated options, and access embedded documentation for GoReleaser projects.

## Key Features
- Validates GoReleaser configurations for errors and deprecated options
- Provides detailed prompts to fix deprecated configurations
- Embeds GoReleaser documentation for direct access via MCP
- Supports modernizing configurations with an `update_config` prompt
- Integrates seamlessly with AI assistants via MCP

## Why It Matters for RAG Builders
It enables AI assistants to understand and interact with GoReleaser configurations, streamlining CI/CD pipeline automation for Go projects.
