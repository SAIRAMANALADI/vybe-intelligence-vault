## Summary
Kira is an MCP server that enhances AI agents by capturing and reusing failure knowledge (scars) to prevent repeated mistakes. It provides tools for recording failures, surfacing past errors, and sharing anonymized community knowledge to improve agent performance over time.

## Key Features
- Records agent failures as private 'scars' for future avoidance
- Surfaces past mistakes automatically at session/task start
- Community catalog of shared skills and scars for collaborative learning
- Privacy-first design with local-only personal data and opt-in community telemetry
- MCP-compatible tools for seamless integration with AI agents

## Why It Matters for RAG Builders
Kira prevents AI agents from repeating the same mistakes by capturing and reusing failure knowledge, significantly improving reliability and reducing wasted effort in RAG and AI workflows.
