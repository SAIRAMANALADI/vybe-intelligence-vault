## Summary
podcli is an open-source AI-powered podcast clipper that automates the creation of vertical clips with face tracking, burned-in captions, and viral moment detection. It combines a video processing engine with a content workflow system (PodStack) for end-to-end podcast clip generation and optimization.

## Key Features
- AI-powered viral moment detection with Claude integration and knowledge base context
- Face tracking and smart cropping for vertical clip rendering
- Hardware-accelerated video encoding (multi-platform support)
- End-to-end content workflow with branded titles, descriptions, and thumbnails
- MCP server for seamless integration with Claude Code and AI assistants
