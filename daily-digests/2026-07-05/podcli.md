## Summary
podcli is an open-source AI-powered podcast clipper that automates the creation of vertical video clips with face tracking, burned-in captions, and AI-driven moment detection. It offers a CLI, MCP server, and web UI for processing podcast episodes into publish-ready content packages.

## Key Features
- AI-powered clip suggestion with 4-dimension scoring and multi-cut segments
- Face tracking and smart cropping for vertical video output
- Burned-in captions with multiple style options (branded, hormozi, karaoke, subtle)
- Hardware-accelerated encoding for efficient processing
- MCP server integration for Claude Code/Codex workflows

## Why It Matters for RAG Builders
podcli streamlines the creation of AI-generated podcast clips with advanced video processing and content workflow automation, reducing manual effort for RAG builders who need high-quality, branded video content.
