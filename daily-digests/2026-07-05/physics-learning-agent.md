## Summary
A chat-style study workspace for undergraduate physics that combines conversational tutoring, structured course knowledge, practice problem generation, and personal document retrieval. It integrates multi-provider model access and LangChain-based document indexing to create a physics-aware learning environment.

## Key Features
- Physics-aware conversational tutoring with intent classification and course-specific prompting
- Original practice problem generation with LaTeX export and hidden hints/solutions
- Personal knowledge base with LangChain-based document indexing and local retrieval
- Multi-provider model access (OpenAI, DeepSeek, Qwen, etc.) with BYOK support
- Bilingual response behavior (Chinese/English) with course-aware reference profiles
