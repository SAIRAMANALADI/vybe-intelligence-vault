## Summary
AgentLens is a local-first DevTools stack for tracing, replaying, evaluating, and sharing AI agent runs, multi-agent workflows, tool calls, RAG flows, and MCP-style integrations. It provides deterministic replay, JSON-based evals, static dashboards, and CI artifacts for debugging and regression analysis without cloud dependencies.

## Key Features
- Zero-dependency local tracing of LLM prompts, responses, tool calls, and errors
- Deterministic replay of agent runs without re-executing models
- JSON-based eval rules for cost, latency, safety, and citation checks
- Static dashboards and shareable bundles for PR reviews and incident notes
- GitHub Actions integration for CI/CD regression testing and SARIF reporting

## Why It Matters for RAG Builders
AgentLens provides essential local debugging and CI artifact generation for AI agent pipelines, enabling reproducible failure analysis and regression prevention without cloud dependencies.
