## Summary
An unofficial self-hosted Progressive Web App (PWA) client for Anthropic's Claude Code CLI, enabling users to interact with Claude Code from their smartphones via a Tailscale-secured connection. The backend runs locally on the user's machine, launching the Claude CLI as a PTY + tmux subprocess while adhering to Anthropic's usage policies.

## Key Features
- Multi-session chat with incremental SSE rendering and tab switching
- Background continuation of Claude sessions with delta synchronization
- Web Push notifications for proactive prompts and agent-initiated tasks
- File preview with syntax highlighting for 50+ languages
- Optional desktop screen sharing via Sunshine and moonlight-web-stream

## Why It Matters for RAG Builders
It provides a mobile-friendly interface for interacting with Claude Code, enabling developers to manage AI-driven workflows on-the-go while maintaining self-hosted control and security.
