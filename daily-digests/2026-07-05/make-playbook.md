## Summary
A Claude Code skill that provides structured, stage-specific checklists and diagnostic questions for indie-hackers, inspired by Pieter Levels' *MAKE: The Indie Maker Blueprint*. It transforms startup advice into an interactive, project-specific tool to guide builders through stages like Idea, Build, Launch, Grow, Monetize, Automate, and Exit.

## Key Features
- Structured knowledge base with 7 stage-specific checklists (Idea → Build → Launch → Grow → Monetize → Automate → Exit)
- Diagnostic questions tailored to specific projects, not generic advice
- Per-app tracker template (MAKE.md) for disciplined progress tracking
- Works with Claude Code and other agents supporting markdown-based skills
- Original synthesis of indie-hacker philosophy with actionable workflows
