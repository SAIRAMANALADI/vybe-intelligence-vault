A low-cost, bulk Google Images search API that returns clean, structured JSON for image results, including full-size URLs, thumbnails, and metadata. Designed for batch processing and integration with AI pipelines or MCP-enabled tools.

- Low-cost pricing at $0.10 per 1,000 images
