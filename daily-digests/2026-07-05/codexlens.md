## Summary
CodexLens is a local, read-only macOS menu bar app that provides observability for OpenAI Codex and Claude Code MCP activity. It monitors local session files and processes to display real-time status, repository context, and session details without modifying existing workflows.

## Key Features
- Real-time monitoring of Codex and Claude Code MCP sessions via a compact menu bar UI
- Heuristic-based correlation of session files and processes for accurate status reporting
- Lightweight Git status integration for repository context
- Multilingual UI support (English, Japanese, Chinese)
- Terminal snapshot capability for quick diagnostics
