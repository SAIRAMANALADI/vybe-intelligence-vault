## Summary
Yorishiro Proxy is an AI-first MITM (Man-in-the-Middle) proxy tool designed for AI agents, enabling interception, recording, and replay of network traffic through the Model Context Protocol (MCP). It provides a typed-per-protocol tool surface for AI agents like Claude Code to automate security testing and traffic analysis.

## Key Features
- AI-native MITM proxy with MCP tool surface for automated agent workflows
- Multi-protocol support (HTTP/1.x, HTTP/2, gRPC, WebSocket, Raw TCP, SOCKS5)
- Traffic interception, recording, and replay with per-protocol typed tools
- Embedded Web UI for visual inspection and interactive testing
- AI safety features including PII masking, destructive payload filtering, and rate limiting

## Why It Matters for RAG Builders
Yorishiro Proxy enables AI agents to autonomously intercept, analyze, and replay network traffic, making it essential for building secure, automated AI-driven security testing and debugging workflows.
