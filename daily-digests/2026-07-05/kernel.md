## Summary
A modular terminal AI agent framework with 35+ specialist agents, 600+ tools, and multi-provider support (20+ LLMs). It includes a POSIX-like OS for agents (agent-os), provenance engineering for regulated industries (kbot-finance), and orchestration pipelines (kbot-orchestrator).

## Key Features
- 35+ specialist agents with auto-routing for tasks like coding, research, finance, and security
- 600+ built-in tools spanning files, code, web, research, databases, creative, science, and finance
- POSIX-like OS for agents (agent-os) with capabilities, namespaces, quotas, audit trails, and vaults
- Provenance engineering for regulated industries (kbot-finance) with audit-grade compliance
- Orchestration pipelines (kbot-orchestrator) for multi-step workflows with audit trails
