## Summary
A framework for building autonomous Discord bots with long-term memory, multi-server coordination, and MCP integration, enabling intelligent, context-aware interactions powered by Claude models.

## Key Features
- Reactive and agentic engines for dynamic engagement in Discord channels
- Persistent memory system with episodic sessions, user profiles, and server induction
- Multi-server coordination via a 'Prime' bot for cross-server communication
- MCP integration for tool discovery and execution in agent workflows
- Desktop app and supervisor dashboard for easy deployment and monitoring

## Why It Matters for RAG Builders
It provides a robust foundation for building AI agents that can remember, reason, and act autonomously in Discord, a critical platform for community-driven AI interactions and tool orchestration.
