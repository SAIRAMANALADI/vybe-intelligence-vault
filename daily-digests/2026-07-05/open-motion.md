## Summary
OpenMotion is an AI-native motion design platform that enables conversational, composable, and reusable animation creation. It allows users to design animations directly in web pages and videos, package them as reusable skills, and export them in multiple formats for AI agent integration.

## Key Features
- Conversational motion design with AI agents for intuitive animation creation
- Real-time animation rendering in web pages and video frames
- Export animations as reusable skills for AI agents
- Multi-format export (HTML, CSS, JSON, MP4, GIF, SVG, WebM)
- Fine-grained control over keyframes, easing, and timing

## Why It Matters for RAG Builders
OpenMotion bridges the gap between motion design and AI agent workflows by enabling animations to be created, refined, and reused as transferable skills, enhancing AI-driven creative and interactive applications.
