## Summary
A Playwright plugin that enables AI-first test automation for SAP UI5, Fiori, and S/4HANA applications using deep UI5 runtime awareness and agent-driven test generation and healing.

## Key Features
- Agent-first test generation with plan-generate-heal pipeline for SAP UI5 applications
- Deep SAP UI5 runtime integration for stable, selector-free test automation
- Support for 199+ SAP UI5 control types and Fiori Elements apps
- AI-powered test creation from business process descriptions with IDE and CLI agents
- Built-in OData tracing, authentication, and self-healing test capabilities

## Why It Matters for RAG Builders
It enables reliable, AI-assisted SAP UI5 and Fiori test automation that adapts to UI changes, reducing manual effort and improving test stability for RAG and AI stack builders.
