## Summary
Echo is an AI-powered customer support platform that provides an embeddable chat widget for websites, enabling real-time AI-driven conversations, voice support, and multi-tenant organization management via a centralized dashboard.

## Key Features
- Embeddable chat widget with customizable UI and domain allowlisting
- AI-powered responses using Google Gemini with RAG for contextual accuracy
- Integrated Vapi AI voice assistant for phone-style support
- Real-time conversation management with status tracking and multi-tenant access control
- Plugin system for third-party service integrations and secure credential storage

## Why It Matters for RAG Builders
Echo provides a turnkey solution for building AI-driven customer support systems with embedded chat and voice capabilities, reducing development time for RAG/AI stack builders.
