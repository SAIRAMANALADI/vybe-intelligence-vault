## Summary
Basilisk is an open-source, self-hosted AI security operator that runs as a native GTK4 desktop application on Linux, enabling users to leverage their own LLM (e.g., DeepSeek, Groq) for offensive security tasks, code auditing, and desktop automation while maintaining full control and auditability.

## Key Features
- Native GTK4 desktop app for Linux with full offline operation and no cloud dependency
- Structural safety floor and tamper-evident evidence ledger for auditable security operations
- Integrated offensive security toolchain (recon, scanning, CVE enrichment, exploitation write-ups)
- Multi-provider LLM support with user-controlled API keys (e.g., DeepSeek, Groq)
- Desktop automation, voice control, and MCP integration for extensibility

## Why It Matters for RAG Builders
Basilisk provides a secure, auditable, and self-hosted alternative to cloud-based AI assistants for offensive security tasks, ensuring full control over data, tools, and operations while enabling reproducible and tamper-evident security workflows.
