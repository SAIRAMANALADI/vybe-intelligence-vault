## Summary
A composite MCP server for the Godot Engine that provides 17 AI-assisted tools for game development, enabling direct manipulation of scenes, nodes, scripts, shaders, animations, and other Godot project assets without requiring the editor to run.

## Key Features
- 17 composite tools for direct Godot project manipulation (scenes, nodes, scripts, shaders, animations, physics, UI, etc.)
- Full scene control via text-based `.tscn` parsing without requiring Godot editor to run
- GDScript CRUD operations (create, read, write, attach) for AI-assisted scripting
- Tiered token optimization with compressed tool descriptions and on-demand help
- Supports stdio and HTTP transports with Docker deployment for cross-platform use
