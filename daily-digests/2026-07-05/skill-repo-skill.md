## Summary
A standardized repository template and toolkit for creating, validating, and distributing AI agent skills across multiple platforms (Claude Code, Cursor, GitHub Copilot) with reusable CI workflows, split licensing, and compliance checks.

## Key Features
- Standardized repository layout for AI agent skills with reusable templates
- Validation scripts for structural compliance (SKILL.md, licenses, composer.json, plugin.json)
- Reusable GitHub Actions workflows for CI/CD, release, and validation
- Split licensing (MIT for code, CC-BY-SA-4.0 for content)
- Multi-channel distribution (Marketplace, npx, Composer, npm, Git clone)

## Why It Matters for RAG Builders
It provides a consistent foundation for building and distributing AI agent skills, reducing fragmentation and ensuring compliance with industry standards across multiple platforms.
