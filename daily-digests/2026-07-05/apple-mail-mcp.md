## Summary
An MCP server that provides AI assistants with full access to Apple Mail, enabling natural language interactions for reading, searching, composing, organizing, and analyzing emails. Built with FastMCP, it integrates seamlessly with MCP-compatible clients like Claude Desktop.

## Key Features
- 22+ tools for email management including reading, searching, composing, and organizing emails
- Supports rich HTML draft creation and direct Mail.app integration
- Read-only mode for safe AI interactions with configurable safety limits
- Cross-account email search and analytics with statistics and export capabilities
- Companion skills and plugins for enhanced AI workflows (e.g., Inbox Zero, daily triage)
