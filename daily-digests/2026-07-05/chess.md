## Summary
A full-stack, production-grade chess platform enabling real-time multiplayer games, LLM AI opponents, and post-game analysis. Features a policy engine for guardrails, an MCP-based agent architecture, and a dedicated admin dashboard for managing AI behavior and game data.

## Key Features
- Real-time multiplayer chess with WebSocket-based move broadcasting and game state recovery
- Play against an LLM AI opponent with live move explanations and web search integration for opening theory
- Post-game analysis with move-by-move annotations using web search for critical positions
- Policy engine with dynamic guardrails (blocking, approval, input validation) and Redis-backed live reload
- MCP-powered agent architecture enabling runtime tool discovery and zero-hardcoded server integrations
