## Summary
Cleanor MCP is a zero-auth, hosted Model Context Protocol (MCP) server that provides AI builders with tools for image optimization, storage capacity calculations, image format savings analysis, and QR code generation. It leverages Cleanor Labs' research data for cited, real-world insights.

## Key Features
- Optimizes images (WebP/AVIF/JPEG) with before/after size comparisons via URL input
- Provides cited research data on device storage capacity and image format savings
- Generates dependency-free SVG QR codes from text or URLs
- Zero-auth and hosted, requiring no API keys or signups
- Integrates seamlessly with MCP-compatible clients (Claude, Cursor, VS Code)

## Why It Matters for RAG Builders
Cleanor MCP streamlines image optimization and provides critical storage/format research data, reducing overhead for RAG/AI stacks that handle media or need accurate storage calculations.
