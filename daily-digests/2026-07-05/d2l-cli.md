## Summary
d2l-cli is a read-only Python CLI tool that provides AI agents (e.g., Claude Code, Cursor, Copilot) with direct access to D2L Brightspace course data, including grades, assignments, syllabi, and lecture files. It enables agents to automate academic tasks like planning, grade audits, and study sessions by interfacing with Brightspace's API.

## Key Features
- Read-only access to D2L Brightspace courses via API, ensuring no data modification
- Seamless AI agent integration with pre-built skills and onboarding workflows
- Supports multiple output formats (JSON, Markdown) for machine and AI consumption
- Automatic token refresh and headless server support for long-term usability
- Pre-configured presets for popular schools (e.g., Kennesaw State, Georgia State)
