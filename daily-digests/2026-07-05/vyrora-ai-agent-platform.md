## Summary
Vyrora AI is a lightweight multi-agent platform featuring a FastAPI backend and React frontend, designed for simplicity and production deployment. It uses a keyword-based supervisor to route requests to four specialized agents (Research, Document, Planning, and Presentation) powered by Groq's LLM API.

## Key Features
- Lightweight keyword-based agent router for stateless multi-agent orchestration
- Four specialized agents (Research, Document, Planning, Presentation) with clear scope
- Direct document text extraction and analysis without vector database overhead
- Production-ready deployment on Render (backend) and Vercel (frontend)
- Stateless design with no authentication or persistent storage for simplicity
