## Summary
prompt-shield is a desktop application designed to protect AI systems from prompt injection attacks by using 21 built-in detectors, a vector similarity vault, and self-learning mechanisms to identify and block malicious inputs in real-time.

## Key Features
- 21 built-in detectors for common prompt injection patterns
- Vector similarity vault for detecting evolved or obfuscated threats
- Self-learning mechanism that updates detection rules dynamically
- Three-layer defense (input scanning, behavior analysis, response filtering)
- Community threat intelligence integration for shared protection
