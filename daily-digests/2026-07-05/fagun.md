## Summary
Fagun is a multi-tool MCP server that integrates with AI coding assistants (Claude, Cursor, VS Code, etc.) to provide a real browser environment for automated testing, bug hunting, and user acceptance testing (UAT). It enables AI agents to interact with web applications as real users, identify functional, security, and accessibility issues, and generate detailed reports.

## Key Features
- Integrates with multiple AI tools (Claude, Cursor, VS Code, etc.) via MCP for seamless testing workflows
- Provides real browser emulation with device/network throttling for realistic user scenarios
- Automated UAT with 16-category scorecard (UX, UI, security, accessibility, performance, etc.)
- Fuzz testing for input fields, forms, and edge cases with reproducible bug reporting
- Token-efficient output with optional verbose mode and report generation to disk

## Why It Matters for RAG Builders
Fagun enables AI agents to autonomously test and validate web applications with human-like interactions, reducing manual QA effort and improving product readiness before release.
