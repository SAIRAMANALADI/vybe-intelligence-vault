## Summary
A deterministic Rust-based analytics engine that transforms trading journal CSVs into interactive Obsidian Charts dashboards, paired with an AI coaching layer (Claude Code) for performance interpretation and actionable insights.

## Key Features
- Deterministic Rust analytics engine for trading journal processing
- Auto-generates interactive Obsidian Charts dashboards from CSV data
- AI-powered coaching layer (Claude Code) for performance interpretation
- Supports auto-detection of CSV formats and broker-specific profiles
- Historical comparison and rolling analytics across multiple analyses
