## Summary
mnemo provides a persistent memory layer for AI coding agents (Codex and Claude Code) by integrating with Obsidian vaults. It automates knowledge management, session summarization, and context retention to enhance AI-driven development workflows.

## Key Features
- Persistent memory layer for AI coding agents (Codex/Claude Code) via Obsidian vaults
- Seven skills for knowledge management: save, session, review, ask, connect, health, and setup
- Cross-session continuity with handoff notes and session summaries
- Recency-aware recall with git history integration and stale note detection
- Configurable taxonomy and non-destructive, CLI-first architecture

## Why It Matters for RAG Builders
mnemo bridges the gap between AI agents and persistent knowledge storage, enabling seamless context retention and recall for RAG systems.
