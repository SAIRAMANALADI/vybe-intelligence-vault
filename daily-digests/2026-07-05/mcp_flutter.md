## Summary
A Dart MCP server and Flutter package enabling AI agents to inspect, interact with, and control running Flutter applications in real-time. It provides dynamic tool registration, semantic snapshots, UI interaction, and hot-reload capabilities for closed-loop AI-driven development.

## Key Features
- Real-time inspection of Flutter app state and UI hierarchy via semantic snapshots
- Dynamic registration of custom MCP tools and resources at runtime
- AI agent interaction with Flutter apps (tapping, typing, scrolling, hot-reload)
- Cross-platform support (mobile, web, desktop) with platform-view capture
- Integration with popular AI agents (Claude Code, Cursor, Codex, Cline) via skills

## Why It Matters for RAG Builders
It bridges the gap between AI agents and Flutter apps, enabling real-time interaction and closed-loop development for AI-driven engineering workflows.
