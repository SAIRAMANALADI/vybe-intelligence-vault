## Summary
Agentic Risk Scan is a static security scanner designed to identify vulnerabilities in AI agent workflows, MCP configurations, and committed agent instructions. It detects dangerous repository patterns such as write-capable tokens, untrusted shell interpolation, hidden Unicode prompts, and risky MCP server configurations to secure the AI software supply chain.

## Key Features
- Detects risky AI agent workflows and MCP server configurations
- Supports multiple output formats (SARIF, GitHub annotations, Markdown, HTML)
- Integrates with CI/CD pipelines via GitHub Actions
- Provides baseline comparisons for incremental security improvements
- Offers inventory mode for mapping agent-facing files and configurations

## Why It Matters for RAG Builders
It proactively secures AI agent workflows by identifying critical vulnerabilities in configurations and instructions before they can be exploited in production environments.
