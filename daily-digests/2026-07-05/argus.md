## Summary
Argus is a self-hosted, local-first AI agent workspace designed for autonomous reasoning and tool-use. It integrates advanced RAG, persistent memory, MCP support, multi-provider LLMs, and a streaming web UI with full observability and an evaluation harness.

## Key Features
- Async LangGraph ReAct agent with tool-use capabilities
- Multi-provider LLM support (OpenAI, Ollama, Anthropic, Google Gemini)
- Advanced RAG with hybrid search, RRF, cross-encoder reranking, and query expansion
- Persistent and graph-based memory with Obsidian vault integration
- Built-in evaluation harness and observability dashboard

## Why It Matters for RAG Builders
Argus provides a comprehensive, production-ready framework for building autonomous AI agents with advanced RAG, multi-provider LLM support, and persistent memory, making it essential for RAG/AI stack builders seeking self-hosted solutions.
