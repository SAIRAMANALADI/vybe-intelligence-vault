## Summary
Mio-Chat Backend is the core runtime environment for the Mio-Chat Agent OS, providing a modular and extensible framework for building AI-powered agents with advanced context management, hook-based interception, and real-world environment bridging capabilities.

## Key Features
- Advanced context compression system reducing token usage by 80%+ while preserving critical constraints
- V3 Hooks architecture enabling dynamic interception and modification of agent behavior via AOP principles
- Three-layer plugin system supporting Skills, MCP, and Native Plugins with hot-reload capabilities
- Real-world environment bridging via node-pty and Puppeteer for terminal and browser automation
- Dual-source preset mechanism for static and user-defined configurations with code-as-config support
