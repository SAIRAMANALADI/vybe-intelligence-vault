## Summary
Privateer is a provider-agnostic terminal-based coding agent that allows users to switch between multiple AI providers (OpenRouter, Anthropic, OpenAI, Ollama, NEAR AI) seamlessly. Built on the Vercel AI SDK, it offers vendor-neutral tool-calling, streaming, and extensibility with MCP servers, custom commands, and project memory.

## Key Features
- Seamless switching between multiple AI providers (OpenRouter, Anthropic, OpenAI, Ollama, NEAR AI) with no model lock-in
- Built-in MCP server support for extensibility and custom tool integration
- Zero-data-retention surfacing and enforcement for OpenRouter models
- Private, verifiable inference via NEAR AI's Trusted Execution Environment (TEE)
- Plan mode, checkpoints, sub-agents, and remote approval via mobile app

## Why It Matters for RAG Builders
Privateer enables AI engineers to build flexible, vendor-neutral agentic workflows with seamless provider switching, MCP integration, and privacy-preserving features like zero-data-retention and TEE-based inference.
