## Summary
auto-contrib is an autonomous GitHub contribution agent that fetches issues, maps repository architecture, locates buggy code, and proposes fixes. It pauses for human approval of the exact diff before committing, pushing, and opening a pull request, ensuring safe and precise contributions to open-source projects.

## Key Features
- Autonomous issue fetching and analysis from GitHub repositories
- Human-gated approval for code changes before execution
- Architecture mapping and semantic code search for precise bug localization
- Conventional Commits-compliant pull request generation
- Real-time CI/CD polling and feedback integration

## Why It Matters for RAG Builders
