## Summary
cl-tron-mcp is an MCP server for Common Lisp that enables deep debugging, introspection, and hot code reloading by connecting to a live Swank session. It allows MCP clients or AI agents to inspect objects, evaluate code, manage debugger state, and invoke restarts without restarting the Lisp image.

## Key Features
- Connects to live Swank sessions for real-time debugging and evaluation
- Provides 91 tools across 14 categories for deep introspection and control
- Supports hot code reloading and system reloads without restarting the Lisp image
- Enables debugger state inspection, stack frame analysis, and restart invocation
- Offers both stdio and HTTP transport modes for MCP client compatibility

## Why It Matters for RAG Builders
