## Summary
A Model Context Protocol (MCP) server for Shopify that provides structured, direct access to Shopify store data (products, orders, customers, themes, etc.) for AI assistants like Claude. Enables seamless integration with Shopify's Admin API via a standardized MCP interface.

## Key Features
- 22+ pre-built tools for Shopify store operations (products, orders, customers, themes, metafields)
- Supports both REST and GraphQL Admin API endpoints
- Structured, tool-based access for AI assistants (e.g., Claude)
- Environment-based configuration for secure API token management
- Extensible architecture with clear documentation for adding custom tools

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with Shopify stores, automating e-commerce workflows and reducing manual API integration efforts for RAG builders.
