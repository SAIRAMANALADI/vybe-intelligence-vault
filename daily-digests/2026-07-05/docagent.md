## Summary
DocAgent is a local-first AI-powered desktop application that enables users to generate, read, modify, and convert documents (Word, Excel, PPT, PDF, Markdown) through natural language conversations. It integrates multiple AI models and provides a workspace for document management, version control, and real-time collaboration.

## Key Features
- Multi-turn conversational document operations with real-time streaming of AI thoughts
- Support for multiple AI models (OpenAI, Claude, Gemini, Ollama) with custom API endpoints
- Comprehensive document processing for Word, Excel, PPT, PDF, Markdown, and Python code
- Version history with snapshots, diff comparison, and one-click rollback
- Workspace management with file tree browsing, search, and auto-detection for directory changes

## Why It Matters for RAG Builders
