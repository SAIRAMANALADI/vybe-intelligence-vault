## Summary
DocAgent is a local-first AI-powered desktop application that enables users to generate, read, modify, and convert documents (Word, Excel, PPT, PDF, Markdown) through natural language conversations. It integrates multiple AI models and provides a visual workflow for document processing and version control.

## Key Features
- Multi-turn conversational document operations with real-time streaming of AI thoughts
- Support for multiple AI models (OpenAI, Anthropic, Google, Ollama) with custom API endpoints
- Comprehensive document processing (Word, Excel, PPT, PDF, Markdown) and Python code execution
- Workspace management with file tree browsing, version history, and one-click rollback
- Session management, prompt templates, and cross-platform theme support
