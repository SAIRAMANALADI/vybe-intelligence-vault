## Summary
Promptwright is a login-less desktop and CLI tool that converts natural language prompts or recorded browser interactions into runnable browser automation tests. It supports any OpenAI-compatible model, including local models via Ollama, and generates Gherkin feature files for replayable scenarios.

## Key Features
- Converts natural language prompts into automated browser tests using AI agents
- Records user interactions and generates Gherkin feature files for replay
- Supports any OpenAI-compatible model (local or cloud-based) without vendor lock-in
- Provides both desktop (Electron) and CLI interfaces for flexibility
- Orchestrates specialized agents for browser testing, API testing, and workflow observation

## Why It Matters for RAG Builders
Promptwright streamlines AI-driven browser automation by eliminating vendor lock-in and enabling developers to generate reusable, runnable tests from natural language or recorded sessions.
