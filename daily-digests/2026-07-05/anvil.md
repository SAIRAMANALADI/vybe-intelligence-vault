## Summary
Anvil is a native local-first AI coding studio that provides Cursor and Claude Code parity with a focus on running local models for most coding tasks while optionally escalating to paid API models for review and complex tasks. It operates as a single executable with no browser or Electron dependencies.

## Key Features
- Local-first coding with optional paid model escalation for review and complex tasks
- Built-in frontier-model reviewer that auto-loops fixes until code passes
- Agent mode with tools for files, shell, web search, semantic codebase search, and MCP integration
- Auto copilot routing to select the right model for each task
- Prompt Maker mode to convert vague ideas into detailed build prompts

## Why It Matters for RAG Builders
