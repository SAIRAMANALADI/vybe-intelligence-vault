## Summary
A browser-based AI agent framework leveraging WebGPU for local LLM inference, enabling fully client-side agent execution with persistent memory, custom skills, and MCP server integration. Supports both local and external API modes while prioritizing privacy and sandboxed execution.

## Key Features
- Runs entirely in the browser with WebGPU-accelerated local LLM inference using @mlc-ai/web-llm
- Supports external API mode for OpenAI-compatible models with sandboxed execution
- Persistent memory system stored in IndexedDB with file-based organization
- Customizable skills and MCP server integration via Streamable HTTP
- Sandboxed JavaScript execution in Web Workers with no DOM access

## Why It Matters for RAG Builders
Enables fully private, client-side AI agent execution with persistent memory and tool integration, eliminating backend dependencies while maintaining high performance through WebGPU acceleration.
