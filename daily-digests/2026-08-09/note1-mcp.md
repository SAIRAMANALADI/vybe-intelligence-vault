## Summary
The note1 MCP Server enables AI clients like Claude, ChatGPT, or Cursor to directly query, search, and manage meeting notes, transcripts, and action items from note1.ai, an AI meeting notetaker. It acts as a bridge between MCP clients and note1's API, allowing seamless integration with authenticated user permissions.

## Key Features
- Direct integration with note1.ai meeting data via MCP clients
- Search meetings with AI-powered Deep Search (ranked snippets or cited answers)
- Export speaker-attributed transcripts and summaries in markdown or JSON
- Schedule, update, or cancel recordings for meetings with OAuth or PAT authentication
- Read-only and write tools with client-side confirmation prompts for security

## Why It Matters for RAG Builders
This MCP server enables AI agents to dynamically query and interact with real-time meeting data, enhancing RAG systems with accurate, timestamped, and actionable insights from user meetings.
