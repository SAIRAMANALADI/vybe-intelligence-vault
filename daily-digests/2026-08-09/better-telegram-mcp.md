## Summary
A Model Context Protocol (MCP) server enabling AI agents to interact with Telegram via bot or user-account modes, supporting messages, chats, media, and contacts with dual API support (Bot API and MTProto).

## Key Features
- Dual-mode operation: Bot API for bots and MTProto for user accounts
- 7 tools for comprehensive Telegram interactions (messages, chats, media, contacts, config, help)
- Web-based OTP authentication for user accounts via browser relay
- Multi-user remote support with per-JWT-sub credential isolation
- Security hardened with SSRF protection, path traversal prevention, and error sanitization

## Why It Matters for RAG Builders
Enables AI agents to seamlessly interact with Telegram for real-time messaging, media, and contact management, bridging a critical gap in AI workflows requiring human communication channels.
