## Summary
Auren is an open-source AI command center that bridges natural language commands to multi-tool execution across Gmail, Google Calendar, and GitHub. It plans, reviews, and executes workflows in parallel with a single approval, while maintaining a full audit trail.

## Key Features
- Human-in-the-loop execution with plan review and approval before any action
- Parallel multi-tool execution (Gmail, Calendar, GitHub) with real-time Meet link injection
- Real-time inbox classification using AI (Claude Haiku) via webhooks
- Semantic email search and keyboard-first design for power users
- Comprehensive audit trail and meeting prep automation

## Why It Matters for RAG Builders
Auren streamlines AI-driven workflows by enabling natural language commands to execute multi-tool tasks with human oversight, reducing manual effort while ensuring reliability and transparency.
