## Summary
A MiMoCode enhancement suite providing multi-agent orchestration, intelligent web fetching, AST code search, error recovery, and A/B prompt testing through hooks and skills. Designed to extend MiMoCode's capabilities with specialized agents and automated task delegation.

## Key Features
- 13 pre-built skills for specialized tasks (e.g., orchestrator-routing, council, oracle)
- 6 hooks for event-driven automation (e.g., model-failover, agent-dispatch, json-recovery)
- Intelligent web fetching with caching and metadata extraction (smartfetch tool)
- A/B prompt testing and versioning via centralized prompt registry (agent-prompts.json)
- Execute-verify loops with configurable success criteria for iterative tasks

## Why It Matters for RAG Builders
It provides a robust framework for orchestrating specialized AI agents and tools within MiMoCode, enabling efficient task delegation and automated workflows critical for RAG and AI stack builders.
