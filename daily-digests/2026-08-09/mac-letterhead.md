## Summary
Mac-letterhead is a macOS utility and MCP server that applies professional letterhead templates to PDF and Markdown documents while preserving formatting. It enables drag-and-drop document processing and integrates with AI tools via the Model Context Protocol (MCP).

## Key Features
- Drag-and-drop macOS applications for applying letterhead templates to PDF and Markdown files
- Supports multiple blending strategies (darken, multiply, overlay, transparency) for PDF overlays
- Smart margin detection and adaptive positioning for Markdown-to-PDF conversion
- Dual rendering pipeline with WeasyPrint (preferred) and ReportLab (fallback) for high-quality PDF output
- MCP server integration enabling AI tools like Claude to generate letterheaded documents via natural language commands

## Why It Matters for RAG Builders
Mac-letterhead streamlines the creation of professional, branded documents by automating letterhead application, reducing manual effort and ensuring consistency in AI-generated outputs.
