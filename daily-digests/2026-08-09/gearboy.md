## Summary
Gearboy is a highly accurate, cross-platform emulator for Game Boy, Game Boy Color, and Super Game Boy, written in C++. It includes an embedded Model Context Protocol (MCP) server for AI-assisted debugging and tooling, enabling integration with AI agents like GitHub Copilot and Claude.

## Key Features
- Accurate Game Boy/Game Boy Color/Super Game Boy emulation with support for multiple cartridge types
- Embedded MCP server for AI-assisted debugging and hardware inspection
- Full-featured debugger with disassembler, breakpoints, memory editor, and trace logger
- Cross-platform support (Windows, macOS, Linux, BSD, RetroArch)
- Portable mode, save states, rewind support, and cheat engine integration

## Why It Matters for RAG Builders
Gearboy's MCP server enables AI agents to interactively debug, inspect, and manipulate emulated hardware states, making it valuable for reverse engineering and automated testing in AI-driven workflows.
