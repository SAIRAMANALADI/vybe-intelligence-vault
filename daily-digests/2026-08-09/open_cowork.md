## Summary
Open Cowork is a local-first desktop workspace designed for AI-assisted work, integrating chat, task planning, tool use, file context, and MCP server management into a single Windows application. It enables users to work with local or self-hosted AI models while maintaining persistent context and audit trails.

## Key Features
- Local desktop app with persistent chat sessions and streaming output
- Support for local Ollama models and OpenAI/OpenRouter compatibility
- MCP server management with tool execution and probing
- File and folder context integration for AI tasks
- Task lifecycle with approval states, progress tracking, and audit events

## Why It Matters for RAG Builders
It provides a unified, local-first workspace for AI-assisted work that simplifies context management and tool integration for RAG builders.
