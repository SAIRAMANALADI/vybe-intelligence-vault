## Summary
A Codex plugin that enables Windows-native Codex to execute Linux commands in WSL with strict context preservation, structured results, and reliable cleanup. It bridges Windows and WSL environments for mixed-project workflows without requiring a resident Linux service.

## Key Features
- Structured `wsl_exec` tool for executing Linux commands from Windows-native Codex
- Strict working directory validation and preservation across Windows and WSL
- Structured output handling with separate UTF-8 stdout/stderr streams
- Timeout and cancellation with reliable process group cleanup
- Zero WSL-side setup or resident services required

## Why It Matters for RAG Builders
It enables seamless integration of Linux tooling into Windows-native AI workflows, reducing friction for mixed-environment projects while maintaining reliability and security.
