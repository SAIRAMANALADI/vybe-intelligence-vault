## Summary
Luna Agents is a CLI and API-driven framework providing 45 specialized AI agents and 358 slash commands to automate every stage of the software development lifecycle (SDLC), from planning and design to deployment and monitoring. It integrates with Claude Code and MCP-compatible platforms for seamless AI-powered development workflows.

## Key Features
- 45 specialized AI agents covering all SDLC phases (planning, design, testing, deployment, monitoring)
- 358 slash commands for Claude Code and MCP-compatible platforms
- Graph RAG with community detection for improved code retrieval (30-60% better)
- Self-learning routing via Thompson sampling multi-armed bandit for optimal agent selection
- Parallel agent swarms with race, consensus, and voting strategies for robust workflows

## Why It Matters for RAG Builders
