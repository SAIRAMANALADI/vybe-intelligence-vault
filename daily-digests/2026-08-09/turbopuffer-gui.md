## Summary
A third-party desktop GUI client for Turbopuffer, a vector and full-text search engine, providing an intuitive interface for managing connections, namespaces, documents, and schema design with encrypted API key storage.

## Key Features
- Secure connection management with encrypted API key storage
- Visual namespace and document explorer with advanced filtering
- Schema designer for configuring vector dimensions and full-text search
- Cross-platform support (macOS, Windows, Linux) with pre-built binaries
- Dark/light mode with terminal-inspired UI and security-hardened networking

## Why It Matters for RAG Builders
It provides an accessible, user-friendly interface for managing and querying Turbopuffer vector databases, simplifying RAG pipeline development and data exploration.
