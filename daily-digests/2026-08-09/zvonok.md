## Summary
zvonok enables AI agents to place real outbound phone calls via a SIP trunk, conduct goal-directed conversations using a realtime voice model, and return structured transcripts. It is designed as a self-hosted actuator for agent frameworks like Claude Code or OpenClaw.

## Key Features
- Real-time outbound phone calls via SIP trunk with G.711 audio
- Structured transcript extraction and JSON answer generation
- Mandatory AI disclosure enforcement and callee objection handling
- Spend guardrails (daily caps, concurrency limits, pre-dial cost estimation)
- Idempotent call requests and confirmed number validation

## Why It Matters for RAG Builders
It provides a critical bridge between AI agents and real-world telephony, enabling goal-directed outbound calls with structured data extraction while enforcing strict cost and privacy controls.
