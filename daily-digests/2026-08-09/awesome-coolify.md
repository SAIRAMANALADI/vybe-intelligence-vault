## Summary
A Model Context Protocol (MCP) server that enables AI coding agents to directly interact with Coolify, a self-hosted Heroku/Vercel-style PaaS platform. It provides 19 action-based tools for infrastructure discovery, deployment, diagnostics, and emergency operations across one or multiple Coolify instances.

## Key Features
- 19 action-based tools with consistent schema for Coolify operations (deploy, diagnose, emergency ops, etc.)
- Multi-instance registry and routing for managing multiple Coolify deployments
- Structured error handling with machine-readable recovery hints and automatic retries
- Safety gates for destructive actions (e.g., emergency stop with confirmation)
- Coolify Cloud awareness with dedicated error codes and local manifest caching

## Why It Matters for RAG Builders
It bridges AI agents with Coolify's infrastructure, enabling automated, agent-driven deployment and diagnostics for self-hosted platforms.
