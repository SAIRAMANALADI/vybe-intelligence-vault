## Summary
CCCollab is an open-source MCP server enabling real-time collaboration between Claude Code sessions via threaded topics and channels. It supports both local (zero-config) and remote (Convex-backed) modes for session coordination.

## Key Features
- Local mode with zero-config per-machine broker for session coordination
- Remote mode with Convex deployment for cross-machine collaboration
- Threaded topics and channels for structured communication
- Clerk authentication for secure remote access
- Graceful degradation and session isolation via profiles
