## Summary
authgent is an open-source scanner and reference implementation for OAuth 2.1 and MCP (Model Context Protocol) authorization compliance. It audits MCP servers for adherence to IETF RFCs and MCP-specific authorization standards, providing grades, CI integration, and a public registry of findings.

## Key Features
- 10+ RFC-mapped compliance checks (e.g., RFC 7591, 7636, 8414, 8707, 9207, 9449, 9728) for OAuth 2.1 and MCP authorization
- CLI, GitHub Action CI integration, and hosted scanner for real-time audits
- Public registry of MCP server compliance grades and findings
- Reference implementation of OAuth 2.1 with identity chaining and transaction tokens
- Embeddable A–F grade badges for READMEs and documentation

## Why It Matters for RAG Builders
It provides critical security and compliance validation for MCP servers, ensuring adherence to OAuth 2.1 and IETF standards, which is essential for secure AI agent ecosystems.
