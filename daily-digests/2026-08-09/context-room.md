## Summary
Context Room is a local-first workbench designed to manage and verify the context used by humans and AI agents, ensuring accuracy and reviewability. It provides a unified interface for project documentation, agent instructions, skills, and shared knowledge, with a CLI for agent interactions and a webapp for human review.

## Key Features
- Unified review queue for local files and shared proposals with human-only acceptance decisions
- Agent-first CLI for research, editing, and capabilities discovery without direct write access
- Document graph for visualizing relationships between projects, documents, and shared resources
- Remote QM mode for multi-user shared contexts with strict access controls
- Exact-hash verification for documents to ensure review accuracy and prevent silent changes

## Why It Matters for RAG Builders
Context Room ensures AI agents operate with verified, human-reviewed context, reducing hallucinations and improving reliability in RAG systems.
