## Summary
CLX is a Rust-based extension layer for coding agents that provides intelligent command validation and context persistence. It integrates with Claude Code, Codex CLI, and Cursor to enforce security policies and maintain semantic context for AI-driven development workflows.

## Key Features
- Two-layer command validation (deterministic rules + LLM risk assessment)
- SQLite-based context persistence with vector embeddings and semantic search
- MCP tools for dynamic context recall and session management
- User-adaptive learning for workflow optimization
- Multi-host support (Claude Code, Codex CLI, Cursor) with tailored enforcement

## Why It Matters for RAG Builders
CLX enhances RAG pipelines by enforcing secure command execution and maintaining persistent, semantically searchable context for AI agents, reducing hallucinations and improving workflow reliability.
