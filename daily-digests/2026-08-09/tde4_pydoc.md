## Summary
This repository provides a VS Code extension that exposes the 3DE4 Python API documentation as a VS Code MCP server definition, enabling MCP-capable clients to access Waterloo-style documentation roots via the `wtrl_mcp` server.

## Key Features
- Registers a VS Code MCP server definition for 3DE4 Python API documentation
- Bundles Waterloo-style documentation roots for local access
- Configurable via VS Code settings for server label, command, and config path
- Compatible with MCP clients like Copilot Chat
- Lightweight with no additional docstring generation or validation

## Why It Matters for RAG Builders
It enables MCP-capable AI tools to access and query 3DE4 Python API documentation locally, improving context-aware assistance for developers working with the API.
