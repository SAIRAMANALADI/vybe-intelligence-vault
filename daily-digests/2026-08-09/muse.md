## Summary
Muse is an interview-based content creation tool for Codex that transforms rough ideas, voice notes, and external materials into structured drafts through iterative questioning and refinement, ensuring user voice and factual accuracy are preserved.

## Key Features
- Dual-speed iterative refinement: quickly draft initial content, then deepen through targeted questioning
- Dynamic interviewing: adapts questions based on user responses to uncover key insights
- Local-first storage: saves all drafts, interviews, and assets in Git-managed Markdown files
- Content sovereignty: preserves user voice, facts, and original intent without cloud dependencies
- Channel-specific editing: supports micro-adjustments for platforms like WeChat
