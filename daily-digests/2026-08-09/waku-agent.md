## Summary
Waku-Agent is a local-first personal AI assistant built with a transparent, readable architecture. It demonstrates the core pillars of agent systems: harness, loop, memory, and evaluation/LLM-ops, all implemented in plain Python without hidden frameworks.

## Key Features
- Local-first design with SQLite-based memory storage for full data ownership
- Four-pillar architecture: harness, loop, memory (semantic/episodic/procedural), and eval/LLM-ops
- Transparent agent loop (~95 lines of Python) with no hidden frameworks
- Built-in evaluation harness with deterministic tests and LLM-as-judge
- Interactive dashboard for real-time monitoring of agent behavior and memory

## Why It Matters for RAG Builders
It provides a minimal, readable blueprint for building production-grade agent systems with local-first memory and transparent LLM operations, essential for RAG builders seeking control and auditability.
