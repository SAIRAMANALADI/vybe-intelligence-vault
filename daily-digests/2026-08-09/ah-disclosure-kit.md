## Summary
A Python and MCP toolkit for analyzing A-share and H-share financial disclosures, enabling retrieval, ingestion, and local indexing of annual reports, announcements, and prospectuses for evidence-backed financial analysis.

## Key Features
- Retrieves structured company data from CNINFO and HKEXnews for A-shares and H-shares
- Downloads, validates, and ingests PDFs into searchable local indexes with metadata and SQLite FTS
- Performs deterministic financial calculations (cash flow, ETR, DuPont, ROIC) with conflict detection
- Provides traceable evidence gates for AI-assisted financial analysis with page-level references
- Supports batch processing workflows for scalable disclosure analysis
