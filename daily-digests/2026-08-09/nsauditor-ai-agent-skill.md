## Summary
A knowledge package that enables AI coding agents to understand and utilize NSAuditor AI's MCP tools, schemas, and multi-step security audit workflows. It provides structured guidance for integrating NSAuditor AI's capabilities into various AI agents without manual context setup.

## Key Features
- Provides MCP tool signatures, parameters, and usage guidance for NSAuditor AI
- Includes multi-step security audit workflows (e.g., scan → CVE lookup → remediation report)
- Offers complete data schemas for parsing and presenting security findings
- Supports six major compliance frameworks (SOC 2, HIPAA, NIST CSF, PCI DSS, ISO 27001, CIS Controls)
- Includes 55 scanner plugins with detailed protocols, ports, and capabilities
