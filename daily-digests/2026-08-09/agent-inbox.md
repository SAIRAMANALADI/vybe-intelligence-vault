## Summary
Agent-inbox is a self-hosted tool that acts as a central hub for collecting and managing links and articles for AI agents. It enables users to send web content to a local inbox via browser extensions or mobile devices, which can then be processed by AI tools like Claude or ChatGPT for analysis and task suggestions.

## Key Features
- Centralized hub for collecting and storing web links and articles
- Browser extension and mobile support for seamless link submission
- Compatibility with any MCP client or AI tool (e.g., Claude, ChatGPT)
- Self-hosted deployment ensuring data privacy and control
- Local dashboard for managing and reviewing saved links

## Why It Matters for RAG Builders
Agent-inbox streamlines the process of feeding curated content to AI agents, enhancing RAG pipelines by providing a vendor-neutral, self-hosted solution for link and article management.
