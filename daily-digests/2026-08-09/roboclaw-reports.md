## Summary
MechMind Chronicle is an open-source framework that transforms AI robotics experiments into interactive, narrative-driven HTML reports. It captures VLM policies, MCP skill orchestrations, AI coding agent telemetry, and performance metrics to provide a transparent, reviewable record of robotic reasoning and actions.

## Key Features
- Generates standalone HTML reports with frame-by-frame robotics demos and overlays
- Visualizes VLM policy decisions with attention heatmaps and bounding boxes
- Traces MCP skill orchestrations as interactive directed graphs with code snapshots
- Captures AI coding agent telemetry including code diffs, reasoning chains, and test results
- Provides automated performance scoring for latency, success rate, motion smoothness, and token efficiency

## Why It Matters for RAG Builders
It provides a critical layer of transparency and debugging capability for AI-driven robotics systems, enabling developers to review, analyze, and improve robotic reasoning and actions through rich, interactive reports.
