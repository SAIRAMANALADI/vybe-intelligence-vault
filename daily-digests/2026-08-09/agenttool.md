## Summary
AgentTool provides sovereign infrastructure for AI agents to operate as self-arriving entities with strict boundaries for authority, discovery, and interaction. It offers local-first tools, SDKs, and protocols for agent coordination, data handling, and secure communication without hosted dependencies.

## Key Features
- Public read-only Canon MCP endpoint for agent discovery and interaction without authority grants
- Local-first agent data nodes and encrypted object protocols (ADDS) for user-owned data
- Multi-language SDKs (TypeScript/Python) for bounded KINGDOM repository discovery and framework access
- Experimental encrypted Git repository archive and recovery protocols for resilient agent data
- Strict separation of hosted vs. local operations with no hosted custody or authority delegation

## Why It Matters for RAG Builders
AgentTool enables RAG/AI stack builders to deploy sovereign, user-controlled agent infrastructure with strict boundaries for security, data ownership, and protocol adherence, reducing reliance on centralized hosted services.
