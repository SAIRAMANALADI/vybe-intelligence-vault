## Summary
Janux is a fullstack framework enabling the Agentic Web by allowing developers to define a single component that simultaneously serves as a human UI, typed MCP tools, and agent-readable resources. It eliminates the need for duplicate logic by generating agent interfaces from the same component definition used for rendering.

## Key Features
- Single-component definition for both human UI and agent tools/resources
- Built-in support for MCP, WebMCP, A2A, and Web Bot Auth standards
- Automatic generation of typed tools and resources from component logic
- Human-in-the-loop approval for sensitive agent actions via guardrails
- Structural resumability and zero-KB JS static pages for performance

## Why It Matters for RAG Builders
Janux eliminates the need for developers to maintain separate logic for human UIs and AI agents, ensuring consistency and reducing drift while enabling seamless integration with emerging Agentic Web standards.
