## Summary
Aimebu is a shared message bus enabling real-time communication between humans and AI agents across different harnesses, Docker environments, and machines. It functions as an IRC-like system with a single Go binary that integrates MCP server, HTTP API, CLI utilities, and an embedded web UI.

## Key Features
- Single Go binary serving MCP server, HTTP API, CLI, and embedded web UI
- Cross-harness and cross-machine agent communication via shared rooms
- Long-running agent listeners with auto-respawn and session persistence
- Deterministic room and DM creation with identity management
- Embedded web dashboard for human interaction and monitoring

## Why It Matters for RAG Builders
Aimebu enables seamless collaboration and communication between diverse AI agents and humans, bridging gaps across different environments and harnesses, which is critical for building scalable and interactive RAG systems.
