## Summary
Claw Orchestrator is a runtime and platform for coding agents that transforms CLI-based coding tools (e.g., Claude Code, Codex) into headless, programmable sessions. It enables multi-agent councils, autonomous loops, and deployment of web apps via agent coordination, with a 65-tool API and embedded dashboard.

## Key Features
- Persistent agent sessions with full context and tool control across requests
- Multi-agent councils for parallel, isolated agent collaboration with consensus voting
- Autonomous Planner/Coder/Reviewer loops for iterative development workflows
- Ultraapp deployment: transforms a 5-question interview into a live web app at localhost:19000
- OpenAI-compatible proxy for seamless integration with existing OpenAI SDK clients

## Why It Matters for RAG Builders
Claw Orchestrator provides a unified runtime for coding agents, enabling scalable multi-agent systems, autonomous loops, and rapid web app deployment, which is critical for building advanced RAG and AI agent architectures.
