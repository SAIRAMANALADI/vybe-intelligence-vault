## Summary
A production-grade Python ETL framework with built-in GDPR, CCPA, and HIPAA compliance features. It integrates data governance directly into the ETL pipeline, offering PII masking, tamper-evident audit logging, lineage tracking, and multi-tenant data cataloging without requiring external orchestration services.

## Key Features
- Built-in GDPR, CCPA, and HIPAA compliance with tamper-evident audit logging
- Multi-tenant data catalog with OpenLineage lineage tracking
- PII discovery and pseudonymization with NLP-powered detection
- 41 destination integrations with four verification tiers
- Modular architecture with 7-layer import DAG and 138 Python modules

## Why It Matters for RAG Builders
It provides a governance-first ETL framework that embeds compliance and auditability directly into data pipelines, eliminating the need for bolt-on tools and ensuring regulatory adherence from extraction to loading.
