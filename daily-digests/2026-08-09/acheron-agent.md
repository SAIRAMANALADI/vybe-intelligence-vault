## Summary
Acheron-agent is a Windows desktop AI assistant with personality, memory, and autonomous capabilities. It operates as a full agent system with 7 specialized agents, 40+ built-in tools, and a Plan-Execute-Verify execution loop for complex task handling.

## Key Features
- 7 specialized agents (e.g., scheduler, code reviewer, document processor) with handoff and parallel dispatch capabilities
- 40+ built-in tools for file operations, system commands, web browsing, code execution, and memory management
- Plan-Execute-Verify execution loop with failure retries and parallel task handling
- Semantic memory system with TF-IDF vectorization, decay, and token budget management
- Security framework with L0-L4 risk classification, DPAPI encryption for API keys, and sandboxed tool execution

## Why It Matters for RAG Builders
It provides a robust, multi-agent framework with deep Windows integration and memory management, enabling complex task automation and RAG pipelines with autonomous agents.
