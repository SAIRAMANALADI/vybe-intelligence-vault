## Summary
A Model Context Protocol (MCP) server for Archivist AI, enabling AI assistants like Claude, ChatGPT, and Cursor to connect directly to TTRPG campaign data. It provides read/write access to characters, sessions, locations, factions, items, quests, journals, and more via a standardized API interface.

## Key Features
- Provides MCP-compliant tools for reading/writing TTRPG campaign data (characters, sessions, locations, etc.)
- Supports OAuth and API key authentication with granular write permissions
- Offers direct image upload capabilities with NSFW moderation and quota tracking
- Integrates with major AI assistants (Claude, ChatGPT, Cursor, Notion, Windsurf) via MCP
- Automates publishing to the official MCP Registry on version tags
