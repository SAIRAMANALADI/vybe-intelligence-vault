## Summary
A Retrieval-Augmented Generation (RAG) system that enables users to upload and chat with documents (PDF, DOCX, TXT) using AI-powered question answering. Answers are grounded in document content with source references, and the system supports both API-based and demo-mode retrieval flows.

## Key Features
- Supports multiple document formats (PDF, DOCX, TXT) for upload and processing
- Local embedding generation using ChromaDB and sentence-transformers for vector storage and similarity search
- Source-grounded answers with citations for transparency and accuracy
- Demo mode for testing without API keys, with full RAG pipeline visibility
- Modular agent-based architecture with 55+ unit and integration tests

## Why It Matters for RAG Builders
It provides a complete, modular RAG pipeline with local embeddings and API integration, making it an ideal reference for building document-based AI assistants.
