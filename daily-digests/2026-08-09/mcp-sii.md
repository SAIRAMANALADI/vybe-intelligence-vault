## Summary
mcp-sii is an open-source MCP server that enables AI agents (e.g., Claude) to interact with Chile's Sistema de Facturación Gratuito (SII) for querying issued and received tax documents. It acts as a bridge between AI systems and Chile's tax authority API.

## Key Features
- Enables AI agents to query issued and received tax documents (DTEs) from Chile's SII system
- Supports authentication via digital certificate or credentials
- Provides tools for listing, filtering, and retrieving detailed tax documents
- Validates digital certificates before use to ensure security
- Designed for integration with AI agents like Claude via MCP protocol

## Why It Matters for RAG Builders
It provides AI agents with secure access to Chile's tax authority data, enabling automation of tax document processing for businesses operating in Chile.
