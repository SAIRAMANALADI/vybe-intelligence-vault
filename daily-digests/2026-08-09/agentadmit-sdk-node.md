## Summary
The @agentadmit/sdk Node.js library enables user-mediated authorization for AI agents, allowing developers to integrate scope-based access control into Express and Next.js applications. It acts as a middleware layer for validating agent tokens and enforcing permissions via a hosted introspection service.

## Key Features
- Plug-and-play integration with Express and Next.js for AI agent authorization
- Mandatory hosted introspection for token validation with automatic rate limiting and retry logic
- Support for MCP server integration with scope enforcement and admin panel embedding
- User-mediated consent and presence verification (WebAuthn) for enhanced security
- Real-time security alerts and configurable kill switches for suspicious agent activity

## Why It Matters for RAG Builders
It provides a secure, scalable way to authorize AI agents with user-controlled scopes, reducing prompt injection risks and enabling granular access control for RAG and AI applications.
