## Summary
Moat is a local-first AI engineering guardrail tool designed to prevent AI-generated code from compromising system architecture, security, or compliance. It acts as a 'brake system' for AI agents, ensuring code changes adhere to predefined rules before and after modification.

## Key Features
- Diff-aware auditing for incremental code changes with 2-second scan times
- Layered architecture enforcement (e.g., MVC/DDD) to prevent cross-layer violations
- Zero-telemetry security model ensuring no code or config leaves the local machine
- AI tool configuration scanning (e.g., Claude, Grok, Codex) for sensitive data exposure
- Evidence-based reporting with full traceability for every violation

## Why It Matters for RAG Builders
Moat provides critical guardrails for RAG/AI stack builders by ensuring AI-generated code adheres to architectural and security constraints, preventing catastrophic system failures or data leaks.
