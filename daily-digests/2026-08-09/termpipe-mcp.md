## Summary
TermPipe MCP Server is a FastMCP-based MCP server for Claude Desktop that enables surgical file editing, shell execution, AI debugging, and system automation. It provides dynamic tool registration and hot-reloading capabilities for seamless integration with AI assistants.

## Key Features
- Surgical line-level file editing with delta feedback for precise AI-driven modifications
- Dynamic tool registration and hot-reloading via `reload_tools()` without restarting Claude Desktop
- Shell execution and process management for terminal automation
- AI-powered debugging tools for iFlow and Gemini workflows
- Symlinked tool directories for seamless editing and version control
