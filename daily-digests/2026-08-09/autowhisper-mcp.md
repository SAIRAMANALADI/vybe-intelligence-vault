## Summary
AutoWhisper MCP is a server that exposes AutoWhisper's AI-powered marketing capabilities as an MCP (Model Context Protocol) server, enabling AI clients like Claude Desktop or Cursor to generate, manage, and publish ad creatives across 30+ platforms via natural language instructions.

## Key Features
- Natural language-driven ad creative generation and management
- Multi-platform publishing (30+ platforms) with hands-off automation
- Real-time product feed integration and approval workflows
- Credit-based API with free tier for new users
- Direct actions for content editing, approval, and publishing
