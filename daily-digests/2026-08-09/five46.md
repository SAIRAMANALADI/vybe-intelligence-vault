## Summary
five46 is an autonomous AI testing agent that verifies applications or APIs in real-time during development using your own LLM key. It generates standalone Playwright or Node.js test specs from successful runs, enabling regression testing without vendor lock-in.

## Key Features
- Autonomous AI testing with BYOK (Bring Your Own Key) LLM support
- Generates real, standalone Playwright/.spec.ts or Node.js test scripts from successful runs
- Supports both browser and API testing with session reuse and self-healing selectors
- Root-cause hypotheses for failed assertions and flaky-test detection
- MCP server integration for IDE-embedded AI assistants

## Why It Matters for RAG Builders
It bridges the gap between AI-assisted development and traditional testing by automating real-time verification and generating reusable regression tests without cloud dependencies.
