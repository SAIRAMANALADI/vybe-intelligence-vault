## Summary
A demo and learning platform for conversational AI built with Spring AI and Angular, offering chat, RAG, tool calling, and quality evaluation capabilities with multi-provider LLM support.

## Key Features
- Multi-provider LLM integration (DeepSeek, OpenAI, etc.)
- Advanced RAG with local Ollama embeddings and document upload
- Tool calling support (weather, web search, datetime, etc.)
- LLM-as-a-Judge quality evaluation with Golden Suite regression
- Modular architecture with optional modules (vision, audio, agents, etc.)

## Why It Matters for RAG Builders
This repository provides a comprehensive, production-ready framework for building conversational AI systems with RAG and tool integration, serving as both a learning resource and a reference implementation for AI engineers.
