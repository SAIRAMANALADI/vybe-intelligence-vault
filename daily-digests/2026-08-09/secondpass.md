## Summary
A personal security and architecture review agent that performs static scans, logic/authorization checks, and architecture analysis under a unified Supervisor. It integrates Semgrep, LLM-based reviews, Chroma for curated lesson retrieval, and SQLite for logging human decisions, designed to catch recurring mistakes in codebases.

## Key Features
- Unified Supervisor for Security and Architecture reviews with confidence gating
- Semgrep integration for static analysis and LLM-based logic/authorization checks
- ChromaDB for retrieving curated personal security lessons during reviews
- SQLite for logging human decisions (accept/reject) with audit trails
- CLI, API, MCP, and Vite+React dashboard for flexible interaction

## Why It Matters for RAG Builders
It provides an automated second-pass review system that integrates static analysis, LLM reasoning, and persistent memory to help developers catch and learn from recurring security and architectural issues.
