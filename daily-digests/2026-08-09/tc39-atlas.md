## Summary
TC39 Atlas is a specialized index service for TC39 proposals tailored for Chinese users and AI agents, offering daily synchronization, REST API, and MCP query capabilities for TC39 proposal data.

## Key Features
- Daily synchronization of TC39 proposal data from official sources
- REST API for querying proposals by stage, version, status, and keywords
- MCP Streamable HTTP endpoint for AI agent integration
- OpenAPI/Swagger UI for API documentation and testing
- Input validation using Zod and schema fingerprinting for upstream data integrity

## Why It Matters for RAG Builders
It provides a structured, up-to-date, and queryable dataset of TC39 proposals essential for AI agents and developers building JavaScript/TypeScript tooling.
