## Summary
ClearCover is a local-first tool that translates complex insurance policy clauses into plain language, enabling users to understand policy terms without external advice. It processes files locally, supports multiple LLMs, and offers structured exports while strictly avoiding product recommendations.

## Key Features
- Local-first processing with no third-party data sharing
- Supports multiple LLMs (Claude, OpenAI, Gemini) via API keys or local CLI
- OCR support for scanned policies (eng+chi_sim)
- Structured JSON output for agent integration
- Word export via Pandoc for policy documentation

## Why It Matters for RAG Builders
ClearCover simplifies the extraction and translation of dense insurance policies into plain language, reducing ambiguity for users and enabling safer decision-making without external advice.
