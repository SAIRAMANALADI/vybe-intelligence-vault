## Summary
Roady is a file-based, git-versioned plan-of-record tool for AI coding agents that ensures project specs, plans, and drift detection survive context resets. It provides durable memory, task coordination, and audit trails without requiring AI inference or external services.

## Key Features
- Durable spec and plan storage that survives agent context resets
- Automated drift detection with tamper-evident audit trails
- Task coordination, assignment, and reporting via CLI or notifications
- Nested sub-project support within a single repository
- MCP-native tooling for seamless integration with AI agents

## Why It Matters for RAG Builders
Roady ensures AI agents maintain consistent project context and auditability, eliminating costly context resets and drift in long-running development tasks.
