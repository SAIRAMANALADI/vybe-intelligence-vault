## Summary
CareerDesk is an open-source desktop application that combines a visual job application tracker with an AI-powered assistant to streamline the job search process. It integrates resume analysis, company research, interview preparation, and progress tracking into a unified local tool.

## Key Features
- Visual job application tracker with progress dashboard
- AI-powered resume and JD matching analysis
- Automated company and role research with sourced reports
- Customized interview practice with structured feedback
- Local-first architecture with optional cloud LLM integration
