## Summary
A plugin for Codex and Claude AI agents that enables managed agent workspaces with company/project-specific skills, secure OAuth 2.1 authentication, and a local Git bridge for versioned task execution. It facilitates portable context sharing, checkpointing, and secure secret management across agent runs.

## Key Features
- Managed workspaces for companies, projects, dossiers, and tasks with versioning and access control
- Local Git bridge for safe checkpointing and context persistence without parallel changes loss
- Secure Agent Secrets management via Trelio Vault with one-time issuance to local executables
- Signed runtime packages and declarative Remote MCP integrations for trusted agent operations
- Portable context transfer between agent runs, tasks, and devices with handoff documentation

## Why It Matters for RAG Builders
It provides a secure, versioned, and portable framework for AI agents to work within managed workspaces, ensuring consistency, security, and seamless context transfer across tasks and devices.
