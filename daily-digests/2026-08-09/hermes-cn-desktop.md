## Summary
Hermes Agent CN Desktop is a cross-platform desktop client for the Hermes Agent ecosystem, providing a native UI for interacting with AI agents. Built with Tauri, Rust, React, and TypeScript, it offers a lightweight, production-ready interface for managing agent workflows, models, and integrations.

## Key Features
- Native desktop application for Windows and macOS with Tauri for lightweight deployment
- Integrated Hermes Agent core with runtime management, health checks, and updates
- Comprehensive UI for agent workflows, including chat, streaming, attachments, and MCP tools
- Support for multiple model providers (cloud and local) and platform integrations (e.g., Feishu)
- Production-grade security with REST/WS proxy layer and YOLO mode for controlled risk operations

## Why It Matters for RAG Builders
It provides a polished, native desktop interface for AI agent ecosystems, reducing friction for users who prefer local applications over web-based solutions.
