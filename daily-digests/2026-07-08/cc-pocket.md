## Summary
CC Pocket enables remote control of AI coding agents (Claude Code or OpenAI Codex) from a mobile or desktop device via an end-to-end encrypted relay. It allows users to approve tool permissions, stream outputs, and manage sessions from anywhere, with zero-knowledge infrastructure ensuring privacy.

## Key Features
- Remote approval of AI tool permissions from any device
- Real-time streaming of AI agent outputs and file changes
- End-to-end encrypted communication via a zero-knowledge relay
- Multi-platform support (iOS, Android, macOS, Windows, Linux)
- Session resumption and management across devices

## Why It Matters for RAG Builders
CC Pocket enables secure, remote orchestration of AI coding agents, bridging the gap between local development and mobile accessibility while maintaining end-to-end privacy.
