## Summary
mcp-trendpulse is an MCP server that bridges AI models with Google News RSS feeds and Google Trends, enabling real-time and historical data retrieval, trend analysis, and article summarization for AI-driven applications.

## Key Features
- Real-time and historical Google Trends data retrieval with 5-year weekly interest curves
- Google News integration for fetching articles by keyword, location, or topic
- NLP and LLM-powered article summarization and key concept extraction
- Robust handling of rate limits, session state, and scraping fallbacks
- Cross-platform MCP server deployment with support for Claude, VS Code, Cursor, and ChatGPT
