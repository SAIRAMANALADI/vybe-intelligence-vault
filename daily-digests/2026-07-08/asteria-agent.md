## Summary
Asteria Agent is a local-first AI research assistant that decomposes queries, performs web searches, and generates fully cited reports with real-time streaming. It supports multi-agent workflows, user authentication, and model-agnostic LLM/embedding providers.

## Key Features
- Automated sub-query decomposition and web retrieval with source-backed citations
- LangGraph-based multi-agent orchestration for parallel research and review
- User-specific authentication, history storage, and real-time progress streaming
- Model-agnostic LLM/embedding integration via OpenAI-compatible APIs
- Exportable reports in Markdown, Word, or PDF formats
