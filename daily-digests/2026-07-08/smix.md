## Summary
smix is an AI-native iOS Simulator automation library and CLI written in Rust, designed to drive iOS apps through a typed API optimized for LLM authoring. It provides explicit selectors, AI-readable failure messages, and integrates with Apple-native event injection for reliable automation.

## Key Features
- Typed Rust API for LLM-friendly automation with explicit selectors and AI-readable failure messages
- Multi-language SDK support (Swift, Kotlin, TypeScript) with 1:1 Playwright-shaped ergonomics
- Performance-optimized Rust core with benchmarking and strict performance gates (up to 46x speedup over TypeScript baselines)
- MCP server integration for direct Claude Code interaction
- Structured selector system (text, id, label, role) with compile-time caching and spatial resolution

## Why It Matters for RAG Builders
smix provides a high-performance, AI-native automation framework for iOS Simulator testing that bridges Rust's speed with multi-language SDKs, enabling reliable and scalable RAG pipelines for mobile app testing and interaction.
