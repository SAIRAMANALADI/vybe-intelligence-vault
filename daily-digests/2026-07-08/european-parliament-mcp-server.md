## Summary
A Model Context Protocol (MCP) server providing AI assistants with structured access to European Parliament open datasets, including MEPs, plenary sessions, committees, and legislative documents. It enables AI agents to perform OSINT analytics like MEP influence scoring and coalition analysis via a secure, type-safe TypeScript implementation.

- Complete European Parliament Open Data API v2 coverage with type-safe TypeScript implementation
- ISMS-aligned, GDPR-by-design, and SLSA Level 3 compliant architecture for security and compliance
