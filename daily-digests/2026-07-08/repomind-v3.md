## Summary
REPOMIND v3 is an on-premises coding agent designed for regulated enterprises, leveraging AMD MI300X GPUs for deep reasoning with 256K context. It includes smart routing, cost optimization, tamper-evident auditing, and enforced air-gap compliance for secure, AMD-native AI coding workflows.

## Key Features
- Smart routing with Gemma triage for efficient token usage and AMD MI300X deep reasoning (256K context)
- Enforced air-gap mode for zero-egress compliance in regulated environments
- Tamper-evident audit logging with Ed25519 signing and SHA-256 hash chaining for EU AI Act compliance
- Cost layer with AST skeleton, prompt caching, and confidence cascade for measurable savings
- CUDA-to-ROCm migration agent with 39 rules and kernel-launch rewrites for AMD-native deployment
