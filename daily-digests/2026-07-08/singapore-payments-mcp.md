## Summary
A stateless Model Context Protocol (MCP) server that enables AI agents to accept payments in Singapore via HitPay's hosted checkout, supporting PayNow QR, cards, and other payment methods. It acts as a secure translation layer between AI agents and HitPay's payment infrastructure.

## Key Features
- Stateless translation layer for secure payment processing
- Supports PayNow QR, cards, and other HitPay payment methods
- Zero runtime dependencies and no database required
- MIT licensed and compatible with Node.js ≥ 18
- Streamable HTTP and stateless JSON-RPC endpoint

## Why It Matters for RAG Builders
