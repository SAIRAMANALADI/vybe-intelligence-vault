## Summary
Glasswing is an AI agent framework that streams its reasoning, tool calls, and results in real-time to a browser interface. It integrates tool-calling loops, deterministic grounding checks, and persistent conversation history with optional image input and news retrieval.

## Key Features
- Hand-rolled tool-calling loop with Groq models for native tool integration
- Real-time streaming of agent reasoning, tool calls, and results via SSE
- Deterministic grounding pass to validate answers against retrieved evidence
- Persistent conversation history with image input support and user authentication
- Optional tracing and observability via Langfuse seamlessly integrated

## Why It Matters for RAG Builders
Glasswing provides a transparent, real-time AI agent framework with built-in tool-calling and grounding, making it ideal for building explainable and reliable RAG systems.
