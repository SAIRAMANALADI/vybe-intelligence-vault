## Summary
TickFlow is a reactive command-line engine that transforms TickTick into an automated, state-machine-driven task management system. It enables cross-platform task synchronization, semantic search, workflow automation, and AI-powered task decomposition through a CLI interface and background daemons.

## Key Features
- Reactive task creation with behavioral rules and auto-prioritization
- Semantic search and natural language parsing for task discovery
- AI integration (OpenAI and Claude) for task decomposition and reflection
- Offline-first design with local state graph and automatic cloud sync
- Multi-account management and custom reporting dashboards
