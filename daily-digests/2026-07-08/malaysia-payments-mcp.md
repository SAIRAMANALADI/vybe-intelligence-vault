## Summary
A Model Context Protocol (MCP) server that enables AI agents to accept Malaysian payments via FPX online banking, DuitNow QR/cards, and Billplz bill delivery. It acts as a stateless translation layer between AI agents and the Billplz payment gateway.

## Key Features
- Enables AI agents to accept FPX online banking payments in Malaysia
- Supports DuitNow QR and card payments via Billplz
- Automates bill delivery via email using Billplz
- Provides stateless payment status checks without webhooks
- Integrates seamlessly with AI agents via MCP protocol
