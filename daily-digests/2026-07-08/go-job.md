## Summary
A Go-based MCP server providing 28 tools for job search, resume optimization, career research, and application tracking across multiple platforms like LinkedIn, Greenhouse, Lever, and more. It integrates with LLMs for analysis, matching, and generation tasks to streamline the job hunting process.

## Key Features
- Unified job search across 15+ platforms with advanced filtering (experience, salary, remote type, etc.)
- Resume analysis and optimization with ATS scoring, keyword matching, and tailored cover letter generation
- Career research tools for salary, company, and person analysis with personalized insights
- Application tracking system with SQLite persistence and Telegram notifications
- Modular architecture with pluggable source connectors and LLM integration for dynamic tooling
