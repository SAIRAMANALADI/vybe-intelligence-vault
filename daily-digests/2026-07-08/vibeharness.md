## Summary
VibeHarness is a local AI agent framework that enables users to run offline AI tasks on their Windows machines using the VibeThinker-3B model. It acts as a bridge between the user's computer and a lightweight local LLM, ensuring data privacy and security by processing everything offline.

## Key Features
- Runs entirely offline for data privacy and security
- Supports natural language interactions with the AI model
- Integrates with Ollama for model management
- Lightweight and suitable for low-resource environments
- Enables local file management and coding assistance
