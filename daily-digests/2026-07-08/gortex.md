## Summary
Gortex is a high-performance code-intelligence engine that indexes code into a graph database, enabling AI agents and IDEs to query code context efficiently. It supports 257 languages, multi-repository analysis, and exposes functionality via CLI, MCP Server, and web UI with minimal token overhead.

## Key Features
- Indexes 257 languages with compiler-grade resolution for cross-repo call chains and contracts
- Supports 18+ AI coding agents out-of-the-box with zero-config MCP integration
- Reduces token usage up to 50x via graph-native lookups and semantic search
- Provides a persistent knowledge graph with live editor overlays and speculative execution
- Offers cross-repo API contract detection (HTTP, gRPC, GraphQL, WebSocket, etc.)

## Why It Matters for RAG Builders
Gortex enables RAG/AI stack builders to drastically reduce token usage and context noise by providing graph-based, cross-repo code intelligence with minimal setup and no external dependencies.
