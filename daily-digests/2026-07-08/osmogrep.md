## Summary
OsmoGrep is a Rust-native terminal UI for autonomous AI agents that operates on local Git repositories with structured logging, tool invocation, and streaming execution control. It enables interactive AI-driven code inspection, modification, and testing directly within the terminal.

## Key Features
- Interactive terminal-based AI agent with real-time streaming output
- Tool-driven execution (shell commands, file read/write, search, Git operations)
- Support for voice input via vLLM realtime API and iPhone mic
- Incremental triage workflow for GitHub PRs/issues with auto-generated reports
- Neovim integration for seamless code editing within the terminal UI

## Why It Matters for RAG Builders
OsmoGrep provides a local-first, auditable AI agent framework that bridges the gap between autonomous code execution and developer oversight, making it ideal for RAG builders who need transparent, reversible AI-driven workflows.
