## Summary
weclaw is a Windows desktop application designed to bridge WeChat-based agents (like ClawBot) with AI services such as Claude, Codex, and Gemini, enabling automated chat replies and account management through a user-friendly interface.

## Key Features
- Simplifies connection to WeChat-based AI agents via a desktop GUI
- Supports automated chat replies and account management
- Compatible with Windows 10/11 and requires minimal system resources
- Provides a centralized setup for agent configurations and tokens
- Offers troubleshooting steps for common installation and connectivity issues
