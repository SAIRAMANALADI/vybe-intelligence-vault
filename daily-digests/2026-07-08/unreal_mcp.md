## Summary
A Model Context Protocol (MCP) server that enables AI assistants to control Unreal Engine via a native C++ Automation Bridge plugin. It provides real-time interaction with Unreal Engine's editor, assets, actors, and systems through TypeScript and C++.

## Key Features
- Native C++ Automation Bridge plugin for direct Unreal Engine control
- Dual transport options: Native HTTP/SSE or TypeScript WebSocket bridge
- Comprehensive toolset for asset, actor, level, animation, and sequencer management
- Dynamic type discovery and runtime introspection for Unreal Engine systems
- Security features including capability token authentication and rate limiting

## Why It Matters for RAG Builders
It bridges AI assistants with Unreal Engine, enabling automated content creation, testing, and editing workflows critical for game development and virtual production pipelines.
