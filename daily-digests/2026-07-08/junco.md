## Summary
Junco is a local-first daemon that automates the conversion of Markdown tickets into pull requests by driving a coding agent against OpenAI-compatible inference endpoints. It supports both file-based and GitHub-native ticket workflows with approval gates, offline tolerance, and a fullscreen terminal dashboard.

## Key Features
- Converts Markdown tickets into pull requests via a supervised coding agent
- Supports both file-based and GitHub-native ticket workflows with approval gates
- Local-first design with offline tolerance and durable queuing
- Fullscreen terminal dashboard for monitoring and interaction
- Plug-and-play with OpenAI-compatible inference endpoints

## Why It Matters for RAG Builders
Junco streamlines the RAG pipeline by automating the generation of high-quality pull requests from tickets, reducing manual intervention and accelerating AI-driven development workflows.
