## Summary
CallPilot is an open-source AI phone agent that runs on a Quectel EC20/EG25 4G modem, enabling real-time voice interactions via cloud-based LLMs. It auto-answers calls, places outbound calls, sends/receives SMS, navigates IVR menus, and records/summarizes conversations—all on local hardware with API keys.

## Key Features
- Auto-answers and handles incoming calls with cloud-based real-time voice AI (Qwen Omni, Doubao, or OpenAI Realtime)
- Supports outbound dialing (single or batch with whitelist) and SMS send/receive with DTMF keypad navigation
- Records and summarizes calls locally with latency metrics and real-time transcripts
- Runs on Quectel EC20/EG25 4G modems with cross-platform support (macOS, Windows, Linux)
- Provides a bilingual (EN/中文) desktop UI for live monitoring and configuration
