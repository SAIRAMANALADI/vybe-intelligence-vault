## Summary
KiCad MCP Pro is an MCP (Model Context Protocol) server that enables AI agents to programmatically interact with KiCad EDA workflows, including schematic design, PCB layout, DRC/ERC validation, DFM checks, and manufacturing export automation.

## Key Features
- Exposes KiCad tools via MCP for schematic, PCB, DRC/ERC, DFM, and manufacturing workflows
- Supports both stdio and Streamable HTTP transports for AI agent integration
- Provides a web dashboard and desktop GUI for monitoring and control
- Includes a capability parity matrix tracking 76.3% of KiCad's programmatic surface
- Offers agent skills for design review, DRC checks, PCB layout, and fabrication output

## Why It Matters for RAG Builders
It bridges AI agents with KiCad's EDA tools, enabling automated PCB and schematic workflows critical for AI-driven hardware design and review.
