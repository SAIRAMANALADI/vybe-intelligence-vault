## Summary
canvo is a Windows desktop application that integrates an AI agent, a visual data canvas, and a Linux sandbox into a single platform. It enables users to interact with AI models, organize data visually, and run Linux commands locally without complex setup, emphasizing privacy and local processing.

## Key Features
- Integrated AI agent with support for multiple models (cloud and local)
- Visual data canvas for organizing notes, links, images, and files
- Built-in Linux sandbox for running commands safely on Windows
- Privacy-focused with local data processing and optional cloud AI
- Simple installation and user-friendly interface for non-technical users
