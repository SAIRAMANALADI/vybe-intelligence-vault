## Summary
CiCy Mobile is a cross-platform client for the CiCy agent platform, enabling users to browse agents, chat with them, and join teams via QR code scanning. It supports iOS, Android, web/PWA, and Telegram Mini App through a single Expo-based codebase.

## Key Features
- Single codebase for iOS, Android, web/PWA, and Telegram Mini App
- QR code scanning to join teams and connect to backend servers
- Two-tier history cache for instant agent interaction and background refresh
- Platform-specific optimizations (e.g., WebView vs. iframe for terminal views)
- Automated CI/CD for web, Android, and iOS deployments

## Why It Matters for RAG Builders
It provides a unified, cross-platform interface for interacting with AI agents, simplifying deployment and user access across multiple environments.
