## Summary
A focused Model Context Protocol (MCP) server for the Nano Banana image generation models by RunAPI, enabling AI agents to create, poll, and price image generation tasks across 5 model variants with minimal setup.

## Key Features
- Provides MCP-compatible access to Nano Banana image generation models (5 variants)
- Supports task creation (text-to-image, edit-image) and status polling
- Includes pricing checks without requiring authentication
- Integrates seamlessly with Claude Code, Cursor, VS Code, and other MCP hosts
- Lightweight and scoped to Nano Banana models for focused agent workflows

## Why It Matters for RAG Builders
It simplifies AI agent integration with Nano Banana image models by providing a dedicated MCP server, reducing setup overhead and enabling direct task execution and result polling.
