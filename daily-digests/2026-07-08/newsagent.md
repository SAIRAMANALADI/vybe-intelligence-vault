## Summary
NewsAgent is an AI-powered personal agent that autonomously fetches, ranks, summarizes, and delivers a curated daily news digest to your inbox. It automates the process of aggregating and processing news from multiple sources across AI, finance, business, and marketing.

## Key Features
- Multi-source news fetching via RSS feeds across 4 categories
- AI-powered ranking and summarization using Claude for relevance and conciseness
- Automated daily email delivery with TLDR-style summaries and 'Why it matters' insights
- Customizable sources, categories, and story counts via configuration
- GitHub Actions and cron support for hands-off automation
