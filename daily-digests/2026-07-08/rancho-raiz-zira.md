## Summary
Zira CRM is an autonomous management system for Rancho Raíz, a rural lodge in Barreal, San Juan. It automates website updates, guest inquiries via WhatsApp, and administrative tasks using Google Sheets as a CMS, eliminating the need for manual coding.

## Key Features
- Real-time website updates via Google Sheets without coding
- Automated WhatsApp inquiry routing for guest management
- Admin panel for non-technical users to manage content
- Auto-deployment via GitHub Actions for continuous updates
- SVG-based animated branding (Zira the mountain)
