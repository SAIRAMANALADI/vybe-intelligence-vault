## Summary
Clips Studio is a local-first desktop application that transforms long videos into ready-to-post vertical Shorts entirely on the user's PC. It leverages open-weight AI models to automate video clipping, captioning, and metadata generation without cloud dependencies or fees.

## Key Features
- Multimodal clip detection scoring (0-100) using transcript, audio, visual, and hook analysis
- Speaker-aware face tracking with YOLOv8 and OpenCV for centered 9:16 crops
- Editable burned-in captions with customizable styles and word-level synchronization
- AI edit chat for plain-language re-editing of clips from original video
- GPU-accelerated rendering and transcription with hardware encoder auto-detection

## Why It Matters for RAG Builders
It provides a fully local, customizable pipeline for automating video clipping and editing, reducing reliance on cloud services while offering fine-grained control over AI-driven processes.
