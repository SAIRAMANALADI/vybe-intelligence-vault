## Summary
comfyui-mcp is a local-first MCP server and agent-native control plane for ComfyUI that enables LLMs to generate, edit, and manage ComfyUI workflows, models, and custom nodes via natural language. It supports local, remote, and cloud deployments with 108 MCP tools and 32 AI skills for advanced image, video, and audio generation.

## Key Features
- 108 MCP tools for granular ComfyUI control (workflow authoring, model management, node editing)
- 32 AI skills including model-specific generation guides, troubleshooting, and node authoring
- Local-first deployment with support for remote/VPS/Comfy Cloud via unified configuration
- Built-in autonomous agents (explorer, debugger, optimizer) and hooks for VRAM monitoring and job completion notifications
- Claude Code plugin with slash commands, installer packs, and real-time workflow visualization

## Why It Matters for RAG Builders
It provides a critical bridge between LLMs and ComfyUI, enabling autonomous workflow generation, editing, and model management for RAG/AI pipelines that require image, video, or audio outputs.
