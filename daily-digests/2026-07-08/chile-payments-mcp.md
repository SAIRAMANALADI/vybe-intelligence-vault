## Summary
A remote MCP server that enables AI agents to accept payments in Chile via Mercado Pago's hosted checkout, supporting cards, Mercado Pago wallet, and bank transfers. It acts as a stateless translation layer between AI agents and Mercado Pago, ensuring funds flow directly from buyer to merchant without holding credentials or funds.

## Key Features
- Stateless translation layer for secure payment processing in Chile
- Supports multiple payment methods (cards, Mercado Pago wallet, bank transfer)
- Direct integration with Mercado Pago's hosted checkout
- Zero runtime dependencies and no database required
- Compatible with AI agents via MCP protocol

## Why It Matters for RAG Builders
It enables AI agents to seamlessly accept payments in Chile, expanding their functionality for real-world transactions without requiring direct integration with payment gateways.
