## Summary
A command-line interface (CLI) for interacting with Help Scout's APIs, enabling automation, backup, and AI agent integration. It supports Mailbox API 2.0, Docs API, Beacon utilities, and provides deterministic JSON output for CI/CD pipelines and AI-driven workflows.

## Key Features
- Full coverage of Help Scout's Mailbox API 2.0 and Docs API with CRUD operations
- Deterministic JSON output and exit codes for CI/CD and AI agent compatibility
- MCP server mode for seamless AI agent integration (read-only by default)
- Secure credential storage using OS keychain (no plaintext credentials)
- Full account backup with incremental refresh and attachment handling

## Why It Matters for RAG Builders
It provides a standardized, scriptable interface to Help Scout's APIs, enabling AI agents and CI/CD pipelines to automate customer support workflows without SDK glue.
