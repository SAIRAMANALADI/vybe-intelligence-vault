## Summary
A Model Context Protocol (MCP) server that enables persistent Google Workspace automation, including Google Docs, Sheets, Slides, and Drive operations. It specializes in creating and managing native Google Docs tabs, retrofitting existing documents, and installing per-user automation workflows directly within Google Workspace.

## Key Features
- Creates and manages native Google Docs tabs programmatically via the Google Docs API
- Retrofits existing .docx or Google Docs into tabbed format while preserving complex elements like tables, drawings, and equations
- Installs per-user Workspace automation runtimes for time-driven jobs, reactive automations, and custom menus within Google Docs/Sheets/Slides
- Self-documenting MCP server with 134 tools, workflow choreography, and CI test status verification
- Supports both local (stdio) and remote (HTTP) MCP deployments with multi-tenant cloud support

## Why It Matters for RAG Builders
It enables AI agents like Claude to programmatically interact with and automate Google Workspace documents at scale, preserving native features like tabs that are otherwise lost in standard document formats.
