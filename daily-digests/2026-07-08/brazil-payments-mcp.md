## Summary
A remote MCP server that enables AI agents to accept Pix, credit/debit card, and boleto payments in Brazil via Mercado Pago. It provides stateless payment processing with no fund storage or credential handling.

## Key Features
- Supports Pix, credit/debit cards, and boleto payments in Brazil
- Stateless translation layer with no fund storage or credential handling
- Pull-based payment status checks without requiring webhooks
- Integration with Mercado Pago, the largest payment platform in Latin America
- Designed for AI agents (Claude, ChatGPT, Cursor) to accept payments seamlessly

## Why It Matters for RAG Builders
It enables AI agents to directly accept real-world payments in Brazil, bridging the gap between AI applications and financial transactions.
