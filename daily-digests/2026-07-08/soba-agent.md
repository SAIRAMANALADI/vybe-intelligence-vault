## Summary
SOBA Agent is a local-first engineering agent that autonomously handles coding tasks, verifies work through proof receipts, and maintains project memory. It features an interactive terminal UI, MCP support, and evolvable skills for adaptive task execution.

## Key Features
- Interactive terminal UI for real-time task management
- Project Memory provenance for context retention and traceability
- MCP support for seamless model integration and tooling
- Bounded permissions for secure and controlled agent operations
- Proof receipts and verification for work validation
