## Summary
memi provides a local design intelligence layer for AI coding agents, enabling them to audit, understand, and safely modify real-world shadcn/Tailwind products by extracting interface context, tokens, UX audits, and registry outputs. It bridges the gap between AI agents and product systems with deterministic, evidence-backed insights.

## Key Features
- Extracts tokens, components, screenshots, routes, and Figma context for AI agents
- Provides UX, craft, and diagnostic audits with deterministic, file-backed evidence
- Integrates with shadcn registry, v0, and npm for registry exports and installations
- Supports MCP clients and agent frameworks (Claude Code, Cursor, Codex, Hermes, OpenCode, OpenClaw)
- Enables CI/CD workflows with SARIF annotations, PR-scoped blame, and score-based gating

## Why It Matters for RAG Builders
memi equips AI agents with the missing product-system context needed to safely and accurately modify real-world interfaces, reducing hallucinations and improving design consistency in RAG/AI stacks.
