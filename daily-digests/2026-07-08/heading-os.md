## Summary
HEADING OS is a security-first, sovereign agent operating system designed for executives, integrating research, communications, CRM, content, and operations. It runs on Claude Code but enforces strict engine-data separation, ensuring private data remains exclusively in a user-controlled repository while the engine remains shareable and public.

## Key Features
- Strict engine-data separation enforced by six mechanical layers to prevent data leakage
- Human-gated outbound communication to ensure no unauthorized data transmission
- Security model with automated testing (231 security tests) and runtime checks
- Console-first design with terminal and Claude Code integration for all capabilities
- Modular skills, hooks, and daemons for extensible workflow automation

## Why It Matters for RAG Builders
