## Summary
The Angel OS is a constitutional, AI-native federated operating system where enterprises run sovereign AI guardians (Leo) on owned infrastructure. It combines a daily scripture reader, community platform, and AI-driven tooling for tasks like site building, payments, and publishing, all governed by a transparent economic model.

## Key Features
- Sovereign AI guardians (Leo) running on enterprise-owned infrastructure for privacy and control
- Multi-body architecture (Core, Merlin, Nimue) enabling distributed yet unified AI functionality
- Constitutional governance model with transparent revenue splits and directional fairness principles
- Integrated token economy (Angel Tokens, Karma Coins) for incentivized participation and payouts
- Modular tooling for publishing, commerce, and real-time communication (LiveKit, SIP telephony)
