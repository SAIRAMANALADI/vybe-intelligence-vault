## Summary
A Django-based REST API backend designed to power AI assistants, including a context-restricted portfolio chatbot and a general developer assistant. It integrates with OpenRouter for LLM interactions and emphasizes modularity, containerization, and prompt engineering for precision.

## Key Features
- Modular service architecture with decoupled AI service layers for easy model switching
- Context-aware portfolio AI with strict data-bound responses to prevent hallucinations
- Developer assistant API for code analysis, optimization, and best practice suggestions
- Fully containerized deployment with Docker and Gunicorn for production readiness
- Health check endpoints and structured response formats for API reliability

## Why It Matters for RAG Builders
