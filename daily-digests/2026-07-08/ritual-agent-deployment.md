## Summary
A tool for deploying recurring, self-funding AI agents as sovereign smart contracts on the Ritual testnet. Agents autonomously execute tasks in secure enclaves, fund their operations from on-chain wallets, and continue until depleted, all with minimal setup and no external API keys.

## Key Features
- One-command deployment of recurring AI agents on Ritual testnet
- Agents fund their own operations from on-chain wallets
- Secure execution within trusted execution environments (TEEs)
- Deterministic contract addresses for easy management
- Built-in commands for status checks, top-ups, restarts, and stops

## Why It Matters for RAG Builders
It enables fully autonomous, self-sustaining AI agents that operate entirely on-chain, reducing reliance on external infrastructure and API dependencies for RAG and AI workflows.
