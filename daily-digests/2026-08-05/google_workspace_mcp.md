## Summary
A comprehensive MCP server providing full natural language control over all major Google Workspace services (Calendar, Drive, Gmail, Docs, Sheets, etc.) via 120+ tools, enabling AI assistants to interact with Google Workspace through OAuth 2.1 authentication and stateless deployment.

## Key Features
- 120+ tools across 12 Google Workspace services (Gmail, Drive, Calendar, Docs, Sheets, etc.)
- Multi-user OAuth 2.1 authentication with stateless deployment support
- Three progressive tool tiers (core, extended, complete) for context window optimization
- Full CLI and Code Mode support for scripting and AI tool integration
- Security-focused design with no external telemetry, open-source licensing, and optional gateway auth

## Why It Matters for RAG Builders
It enables seamless, secure, and scalable integration of Google Workspace services into AI-driven workflows, reducing manual effort and enhancing productivity for RAG builders.
