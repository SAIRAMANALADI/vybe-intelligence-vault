## Summary
A sanitized reference implementation of an environmental policy monitoring agent that demonstrates a reusable engineering pattern for monitoring heterogeneous policy sources, extracting structured insights, and generating traceable reports. It separates source acquisition, normalization, and LLM-based analysis while enforcing human review and failure isolation.

## Key Features
- Configurable source registry for heterogeneous policy documents
- Deterministic normalization and deduplication of raw content
- Separation of source collection from LLM-based interpretation
- Structured Markdown reports with traceable claims to source URLs
- Failure isolation and error logging for robust monitoring runs
