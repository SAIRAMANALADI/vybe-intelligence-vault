## Summary
PocMap is an AI-agent-optimized toolkit for discovering CVEs, Proof of Concepts (PoCs), and exploits across multiple sources, including GitHub, Exploit-DB, Metasploit, and Nuclei. It provides a CLI, Python API, and MCP server for integration with AI agents and security workflows.

## Key Features
- Multi-source PoC and exploit discovery (GitHub, Exploit-DB, Metasploit, Nuclei, bug bounty write-ups)
- MCP server with 22 tools for AI agent integration (Claude Desktop, Cursor, etc.)
- CLI and Python API for programmatic access with support for multiple output formats (JSON, SARIF, CSV, etc.)
- Persistent caching and offline mode for reliable operation
- Dependency vulnerability discovery with fix version mapping (supports 50+ ecosystems)

## Why It Matters for RAG Builders
PocMap streamlines vulnerability research and AI agent workflows by providing a unified interface to discover, verify, and assess CVEs and exploits, reducing manual effort and improving response times for security teams.
