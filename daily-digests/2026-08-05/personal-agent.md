## Summary
A local-first daily self-assistant that builds an evidence-backed profile of your skills and projects from GitHub, email, and browser activity, then generates a personalized morning digest, maintains a private website and résumé, and enables chat-based task management via email or WeChat.

## Key Features
- Builds and maintains a git-versioned, evidence-backed profile from daily activity (GitHub, email, browser history)
- Generates a triaged morning digest email with GitHub notifications, research papers, and industry news
- Publishes a personal website and résumé from the profile with deterministic rendering
- Enables chat-based task management via email or WeChat with image understanding support
- Maintains private finance and health ledgers locally with git versioning and encrypted storage

## Why It Matters for RAG Builders
It provides a comprehensive, privacy-focused framework for building personalized AI agents that integrate multi-source activity tracking with automated task management and knowledge synthesis.
