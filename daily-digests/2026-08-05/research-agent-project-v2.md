## Summary
A production-grade LangGraph-based multi-agent research system featuring autonomous planning, durable session memory, and live MCP tool integration for real-world research tasks. It evolves from a hand-written ReAct agent to an explicit, inspectable graph architecture with reusable tools and FastAPI endpoints.

## Key Features
- Explicit graph-based orchestration with LangGraph StateGraph for scalable agent control flow
- Autonomous multi-step planning via a dedicated Planner node before execution
- Durable session persistence with checkpointing for seamless state recovery across requests
- Live MCP tool integration for standardized, pluggable external tool access (e.g., filesystem operations)
- Reusable battle-tested tools (web search, calculation) and FastAPI-compatible REST API

## Why It Matters for RAG Builders
It demonstrates a production-ready agentic architecture with autonomous planning and MCP integration, providing a blueprint for building scalable, inspectable, and tool-agnostic AI research agents.
