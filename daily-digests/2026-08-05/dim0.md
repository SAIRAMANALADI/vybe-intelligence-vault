## Summary
Dim0 is an open-source, real-time collaborative AI canvas that combines notes, mini-apps, and an agent into a single infinite workspace. The agent reads the canvas and writes results back as editable nodes, enabling interactive and persistent AI-driven workflows.

## Key Features
- Infinite canvas with thousands of nodes and nested boards, optimized for performance
- Board-aware AI agent that reads canvas content and writes results back as editable nodes
- Real-time multiplayer collaboration with live cursors and conflict-free sync
- Mini-apps: generate and embed interactive React applications directly on the canvas
- Privacy-first, open-source, and self-hostable with support for multiple AI models

## Why It Matters for RAG Builders
Dim0 unifies AI agents, notes, and interactive tools into a single workspace, enabling seamless, persistent, and collaborative AI-driven workflows that eliminate the fragmentation of traditional chat-based or document-centric AI tools.
