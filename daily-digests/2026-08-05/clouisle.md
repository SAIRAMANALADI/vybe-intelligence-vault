## Summary
Clouisle is an open-source enterprise-grade AI agent platform that combines RAG-powered knowledge management with visual workflow automation. It enables teams to build, deploy, and manage intelligent agents with multi-model LLM support, hybrid search, and robust security features.

## Key Features
- Multi-model LLM support with 24+ providers and OpenAI-compatible endpoints
- Hybrid search (vector + lexical) with reranking and configurable chunking for RAG
- Visual drag-and-drop workflow builder with 15+ node types and versioning
- Enterprise-grade security including RBAC, SSO, TOTP 2FA, and audit logging
- Built-in tools, MCP integration, and sandboxed code execution for agent autonomy

## Why It Matters for RAG Builders
Clouisle provides a unified platform for building production-grade AI agents with RAG capabilities, workflow automation, and enterprise security, making it essential for teams scaling AI applications beyond prototypes.
