## Summary
This repository provides a plugin for Claude Code that integrates local or cloud Ollama models as a secondary engine for tasks like code review, agentic problem-solving, and file modifications. It supports stateless consults, isolated agentic rescues, and full Claude Code sessions powered by Ollama models.

## Key Features
- Seamless integration of Ollama models into Claude Code as a secondary engine for read-only consults or agentic tasks
- Agentic rescue mode with isolated git worktree for safe file modifications and diff reviews
- Full Claude Code session mode (`/ollama:as-claude`) powered by an Ollama model for advanced agentic workflows
- Model management commands (`/ollama:list`, `/ollama:pull`, `/ollama:rm`) with safety confirmations
- Cloud usage tracking for Ollama.com with secure session cookie storage

## Why It Matters for RAG Builders
It enables AI engineers to leverage local or cloud Ollama models directly within Claude Code for enhanced productivity, code review, and agentic task execution without leaving their workflow.
