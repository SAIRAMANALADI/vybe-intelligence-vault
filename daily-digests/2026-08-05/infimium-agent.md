## Summary
Infimium Agent is a self-hosted MCP server that provides AI agents with precise, local context by indexing code, documentation, and dependency graphs. It enables agents to perform semantic searches and retrieve relevant symbols or files without reading entire repositories.

## Key Features
- Semantic code search using tree-sitter and embeddings for intent-based retrieval
- Dependency graph analysis to track symbol definitions and imports
- Local document RAG over markdown, text, HTML, and PDF files
- Allowlisted shell command execution for safe local operations
- Implementation planning tool that drafts context-aware code changes

## Why It Matters for RAG Builders
It enables AI agents to retrieve precise, context-aware code and documentation snippets locally, reducing context bloat and improving accuracy in RAG pipelines.
