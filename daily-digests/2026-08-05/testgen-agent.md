## Summary
TestGen Agent is a Python-based tool that automates the generation of JUnit 4 tests for Java projects using LLMs. It analyzes Java code, extracts methods, generates diverse test cases (normal, boundary, exception, path), compiles and repairs tests, and outputs structured reports.

## Key Features
- Automated discovery of Java methods with full context (FQN, signature, modifiers, parameters, exceptions)
- Multi-provider LLM support for test generation (OpenAI, Anthropic, DeepSeek)
- Self-healing compilation with up to 3 repair attempts per test
- Coverage-guided improvement phase (optional) using JaCoCo
- Structured output (JSON, CSV, console reports) and integration with Maven/Gradle/Ant

## Why It Matters for RAG Builders
It streamlines the creation of comprehensive JUnit tests for Java projects, reducing manual effort and improving code reliability through automated LLM-driven test generation and repair.
