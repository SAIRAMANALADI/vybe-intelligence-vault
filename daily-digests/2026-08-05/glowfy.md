## Summary
Glowfy is an AI-powered skincare assistant that provides research-backed skin analysis, routine building, and product recommendations using dermatological research and a database of 1,900+ products. It operates as a pay-per-call API with structured JSON outputs for agent integration.

## Key Features
- Six specialized endpoints for skin analysis, routine building, and product matching
- Research-backed ingredient safety scoring using published dermatological studies
- Integration with 1,900+ real products from Open Beauty Facts
- Structured JSON outputs for seamless agent integration
- On-chain payments via x402 protocol on X Layer
