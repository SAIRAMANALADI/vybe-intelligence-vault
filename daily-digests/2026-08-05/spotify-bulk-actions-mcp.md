## Summary
A Model Context Protocol (MCP) server enabling bulk Spotify operations such as batch playlist creation, library exports, and large-scale library management with confidence scoring and human-in-the-loop review for uncertain matches.

## Key Features
- Batch search with confidence scoring (HIGH/MEDIUM/LOW) for accurate track matching
- Human-in-the-loop review for uncertain matches via CSV export/import
- Efficient handling of large libraries (500+ songs) with built-in rate limiting
- Library analysis tools (followed artists, saved tracks, unique artist ranking)
- Podcast playlist-focused workflows for importing song lists from show notes

## Why It Matters for RAG Builders
This MCP server streamlines Spotify library management and playlist creation at scale, reducing manual effort for AI-driven music curation and RAG applications.
