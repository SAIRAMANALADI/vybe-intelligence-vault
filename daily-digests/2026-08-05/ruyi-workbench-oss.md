## Summary
如意 Ruyi 是一个 Windows 本地 AI 工作台，支持离线运行、多模型端点切换和多 Agent 协作，面向非程序员和开发者提供安全、可审计的 AI 动手能力，包括文件操作、桌面控制、Office 操作和成本透明的任务执行。

## Key Features
- 支持任意 OpenAI 兼容端点或本地 Claude CLI，实现双引擎对话与跨引擎上下文续接
- 提供 39+3 个原生工具（文件、终端、Git、联网等）和 100 个桌面/Office 操控工具（ACC 可选），支持分级权限与可撤销操作
- 图形化多 Agent 工作流编排（DAG + 质量门），支持 8 套模板、9 种角色和团队模式，支持长任务自主推进与崩溃恢复
- 文件检查点、对话回溯、审计时间线和 5 档权限模式，确保操作可追溯、可撤销和成本透明
- 零 npm 运行时依赖的单文件后端（server.js），离线 zip 解压即用，适合政企内网部署与安全审计

## Why It Matters for RAG Builders
如意 Ruyi 提供了一个安全、可审计且离线优先的本地 AI 工作台，能够让 AI 真正替用户动手完成复杂任务，同时确保操作可撤销和成本透明，是 RAG/AI 栈构建者不可或缺的本地化工具平台。
