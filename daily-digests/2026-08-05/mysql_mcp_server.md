## Summary
A Model Context Protocol (MCP) server that enables secure, structured interaction with MySQL databases for AI applications. It provides a controlled interface for database exploration, schema analysis, and query execution, supporting both local and remote deployments.

## Key Features
- Secure MySQL database interaction via MCP with support for STDIO and SSE transport modes
- Comprehensive schema and table exploration tools (list resources, get schema info, sample data)
- Multi-database mode with cross-database query support using fully qualified names
- Built-in security features including SSL/TLS, SSH tunneling, and identifier validation to prevent SQL injection
- Pre-configured prompts for guided database exploration and table analysis workflows

## Why It Matters for RAG Builders
It provides a secure, standardized way for AI applications to interact with MySQL databases, enabling structured data retrieval and schema analysis critical for RAG pipelines.
