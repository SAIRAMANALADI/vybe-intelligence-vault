## Summary
Latentmachine provides deterministic tools for inferring, verifying, and transforming data through inspectable rules and contracts. It enables users to derive reusable transformation logic from examples, validate data consistency, and trace structural patterns without relying on model calls or server-side processing.

## Key Features
- Infer transformation rules from structured data examples (JSON, CSV, SQL, etc.)
- Verify batch data consistency against inferred rules with detailed diagnostics
- Generate deterministic fingerprints and profiles for dataset tracing
- Local-first architecture with no server-side data processing required
- Supports integration via JavaScript API, CLI, MCP, or HTTP endpoints

## Why It Matters for RAG Builders
Latentmachine enables RAG builders to ensure data consistency and traceability by inferring and verifying transformation rules deterministically, reducing hallucinations and improving data reliability.
