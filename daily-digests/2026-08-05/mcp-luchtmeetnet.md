## Summary
mcp-luchtmeetnet is an MCP (Model Context Protocol) server providing real-time air quality data from the Netherlands' official Luchtmeetnet network (RIVM). It enables AI agents to query live air pollution metrics via a standardized MCP interface.

## Key Features
- Provides access to 1317+ live air quality measurement stations in the Netherlands
- Integrates seamlessly with MCP-compatible AI agents (Claude, Cursor, Windsurf)
- Supports plain English queries via ask_pipeworx for simplified interactions
- Part of the Pipeworx gateway ecosystem for unified data source access
- MIT licensed for open-source adoption

## Why It Matters for RAG Builders
It enables AI agents to fetch real-time, authoritative air quality data from the Netherlands, critical for environmental monitoring and RAG applications requiring up-to-date pollution metrics.
