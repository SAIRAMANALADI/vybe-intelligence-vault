## Summary
A self-hosted VPS node for managing a personal AI identity (sys.md) and structured context files (Vault) that enable AI systems to act on your behalf. Supports single-user and multi-user modes with cryptographic isolation, encryption, and optional decentralized features like on-chain anchoring and an agent marketplace.

## Key Features
- Personal and multi-user (soul) modes with cryptographic isolation
- Structured Vault for context files (health, mind, shopping, etc.) encrypted at rest
- sys.md growth tracking and versioning for AI identity
- Agent marketplace for paid external AI access (Public nodes only)
- On-chain anchoring and maturity scoring via Polygon

## Why It Matters for RAG Builders
It provides a decentralized, self-hosted framework for managing AI identities and context, enabling secure, personalized interactions with AI systems while preserving user control over data.
