## Summary
MATHIR is a memory-augmented tensor hybrid system with intelligent routing, designed as a cognitive memory layer for LLMs. It enables long-term memory persistence, decay-based forgetting, consolidation, and anomaly detection across sessions and agents, supporting multi-agent orchestration via shared memory.

## Key Features
- Tiered memory system (6 tiers: working, episodic, semantic, procedural, immunological, guardrail) with decay, promotion, and consolidation mechanisms
- Multi-agent orchestration via shared memory (God Mode) with dependency-aware task assignment and cycle detection
- Cross-platform and cross-LLM compatibility (Claude, GPT, Gemini, Ollama, etc.) with universal auto-injection mechanisms
- INT8 quantization and cross-encoder reranking for efficient and high-accuracy memory retrieval
- Per-project SQLite-based memory storage with automatic routing and project isolation

## Why It Matters for RAG Builders
MATHIR provides a robust, self-maintaining memory layer for RAG systems, enabling persistent context, anomaly detection, and multi-agent collaboration without requiring manual configuration or external infrastructure.
