## Summary
Stacks Quest is a daily blockchain puzzle game and non-custodial DeFi agent built on Stacks (Bitcoin L2). It combines gamified blockchain data challenges with real-time DeFi operations, including swaps, staking, and portfolio tracking across multiple chains.

## Key Features
- Daily blockchain puzzle game with real-time data (block height, STX price, tx count)
- Non-custodial DeFi agent supporting swaps, staking, and portfolio tracking across Stacks, Base, and Celo
- x402 payment protocol for premium AI tool access (1 USDC per call)
- Multi-language support (EN, FR, ES, ZH, AR, PT) and Wordle-style social sharing
- Smart contract integration with Clarity and EVM compatibility

## Why It Matters for RAG Builders
Stacks Quest provides a unique bridge between gamified blockchain interaction and agentic DeFi operations, offering a practical framework for building AI agents that interact with real-world financial systems on Bitcoin L2.
