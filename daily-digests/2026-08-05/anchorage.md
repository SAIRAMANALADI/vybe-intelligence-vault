## Summary
Anchorage provides an enterprise safety layer for AI agent workflows, built on Mastra to add RBAC, audit logging, policy enforcement, approval management, and Cloudflare-native durable execution as middleware. It ensures secure, multi-tenant workflows with role-based access, policy-driven egress controls, and approval-gated connectors.

## Key Features
- Policy engine for egress, write permissions, and content inspection (PII/secret detection)
- RBAC with 5 roles (admin, builder, operator, reviewer, viewer) and per-workflow scoping
- Approval API and React dashboard for role-checked, audited, and SLA-tracked decisions
- Cloudflare Durable Objects-based workflow runner with tenant isolation and durable execution
- Connector SDK with idempotency, dry-run, rate limits, and approval-gated tools (e.g., Claude Code CLI)

## Why It Matters for RAG Builders
Anchorage provides critical enterprise-grade controls for AI agent workflows, ensuring secure, auditable, and policy-compliant operations essential for production RAG and agent systems.
