## Summary
An MCP server that enables AI agents like Claude to interact with Google Search Console, allowing property management, URL indexing checks, sitemap submissions, and search analytics retrieval via conversational interfaces.

## Key Features
- Real-time interaction with Google Search Console via MCP for AI agents
- Quota-aware indexing and URL inspection with per-property budget tracking
- Diagnostic tools for auth, config, and environment validation
- Search analytics retrieval (clicks, impressions, CTR, position)
- Sitemap submission and status checking
