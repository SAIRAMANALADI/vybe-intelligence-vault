## Summary
HAR Skills is an AI-native toolkit for analyzing HTTP Archive (HAR) files, designed primarily for AI agents but also available as a Go SDK and CLI. It enables parsing, searching, auditing, and transforming HAR files with a focus on automation, security, and performance analysis.

## Key Features
- AI-first HAR file analysis with progressive disclosure documentation (CLAUDE.md)
- 24+ CLI commands and 70+ SDK methods for HAR manipulation and analysis
- Security auditing, performance scoring, and sensitive data redaction
- Support for streaming/lazy parsing, validation, and deterministic exports
- Planned MCP server integration for IDE and desktop agents

## Why It Matters for RAG Builders
HAR Skills enables AI agents to safely and efficiently analyze HTTP traffic captures, reducing noise and enabling structured tool calls for debugging, security audits, and performance optimization.
