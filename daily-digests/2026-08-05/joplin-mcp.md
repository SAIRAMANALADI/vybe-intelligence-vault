## Summary
A FastMCP-based Model Context Protocol (MCP) server for Joplin that enables AI assistants to interact with notes, notebooks, and tags through a standardized interface. It provides 26 optimized tools for comprehensive note management, search, and organization within the Joplin note-taking application.

## Key Features
- 26 optimized tools for note, notebook, and tag management
- Notebook allowlist for granular access control using gitignore-style patterns
- Support for 26 tools including CRUD operations, search, import, and trash management
- Cross-platform installation via pip, uvx, or Docker
- Advanced configuration for permissions, transport modes, and environment variables
