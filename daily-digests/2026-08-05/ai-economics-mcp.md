## Summary
A Model Context Protocol (MCP) server providing 12 calculators for AI economics, enabling clients like Claude or Cursor to estimate costs, energy usage, agent autonomy, and efficiency metrics for AI workloads. It wraps a free, stateless API with no authentication required.

## Key Features
- 12 specialized calculators for AI workload metrics (token cost, agent hour, energy, autonomy, etc.)
- Stateless API with no authentication or rate limits
- Integrates seamlessly with MCP clients like Claude and Cursor
- Provides detailed responses with formulas, interpretations, and citations
- Supports self-hosting via configurable API endpoint

## Why It Matters for RAG Builders
It provides critical economic and efficiency metrics for AI workloads, enabling better cost control, energy optimization, and autonomy validation in RAG and agent-based systems.
