## Summary
Hao Work is a local desktop AI programming workbench built on OpenChamber's UI and desktop shell, integrated with HaoCode as its agent engine. It replaces OpenCode with a local HaoCode compatibility layer while retaining OpenChamber's mature features like sessions, file management, and tool calls.

## Key Features
- Persistent sessions and multi-turn conversations with streaming output
- Built-in tool integration (Read, Write, Edit, Glob, Grep, Bash, Memory, etc.) with permission confirmations
- Compatibility layer for OpenCode API, translating requests to HaoCode SDK calls
- Cross-platform desktop app (macOS, Windows, Linux) with bundled PHP runtime
- Support for Anthropic, OpenAI, DeepSeek, and custom provider configurations

## Why It Matters for RAG Builders
Hao Work provides a self-contained, local-first AI programming agent framework that simplifies deployment and extends OpenChamber's capabilities with HaoCode's agent engine, making it easier to build and run AI-powered coding assistants without external dependencies.
