## Summary
Flaim Fantasy is a fantasy sports analytics platform that connects ESPN, Yahoo, and Sleeper leagues to AI assistants via an MCP server, enabling read-only analysis of real league data. It bridges fantasy sports platforms with AI tools for personalized advice without modifying league settings.

## Key Features
- Unified MCP gateway for ESPN, Yahoo, and Sleeper fantasy league data
- Read-only analysis tools for AI assistants (no roster changes or trades)
- Chrome extension for automated ESPN credential sync
- Historical league data and past season analysis
- Agent skill integration for structured AI behavior in fantasy contexts

## Why It Matters for RAG Builders
Flaim Fantasy enables AI assistants to provide personalized, data-grounded fantasy sports advice by securely connecting to real league data without altering settings, making it essential for AI-driven sports analytics.
