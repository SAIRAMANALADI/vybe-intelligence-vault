## Summary
RTFM is an open-source retrieval layer designed to index and retrieve context from multi-domain project artefacts (code, docs, PDFs, legal texts, research) for AI agents. It provides local, cloud-free, and cost-effective retrieval with progressive disclosure of context to prevent hallucinations.

## Key Features
- Indexes code, docs, PDFs, legal texts, and research with structural parsing and AST-awareness
- Progressive disclosure of context (300 tokens metadata first, then expanded sections)
- Cross-project and cross-session memory with unlimited version history
- MCP-native integration for seamless AI agent workflows
- Supports semantic, full-text, and hybrid search with optional embedding models

## Why It Matters for RAG Builders
RTFM eliminates the retrieval bottleneck in RAG pipelines by providing a local, open-source layer that indexes multi-domain artefacts and delivers surgical context to AI agents, reducing hallucinations and API costs while preserving data privacy.
