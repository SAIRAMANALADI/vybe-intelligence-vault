## Summary
An unofficial oh-my-pi extension that integrates Qoder's browser login and model catalog, providing 15 base models with 22 long-context aliases for AI model serving via Qoder's OpenAI-compatible endpoints.

## Key Features
- Adds Qoder browser login and OAuth flow via PKCE for secure authentication
- Provides 15 base models and 22 long-context aliases (up to 1M tokens) for flexible model selection
- Implements SSE framing repair for accurate token accounting and usage tracking
- Supports high-speed serving mode (`/fast`) for Kimi-K2.7-Code model via metadata injection
- Omits telemetry and sensitive headers to ensure privacy-conscious client behavior

## Why It Matters for RAG Builders
It enables seamless integration of Qoder's model catalog and authentication into oh-my-pi, expanding AI model options for RAG builders with long-context and high-speed serving capabilities.
