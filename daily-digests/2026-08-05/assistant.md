## Summary
Assistant is an AI chief of staff for managing a fleet of Claude Code agents, automating workflows, and reducing daily decision-making overhead. It normalizes inbound events into a deterministic Python pipeline, enforces silent-by-default operations, and learns user rules over time to optimize task execution.

## Key Features
- Normalizes inbound events (email, Slack, GitHub, etc.) into a single deterministic Python pipeline with a WorldEvent abstraction
- Enforces silent-by-default operations with a zero-touch push budget and draft-only outbound actions
- Learns user rules from corrections and confirmations, syncing them across machines via semantic memory
- Manages a fleet of Claude Code agents with bounded workspace caps and automated TODO dispatching
- Provides a morning brief of decisions requiring user attention, optimizing for reduced daily decision overhead

## Why It Matters for RAG Builders
It provides a deterministic, rule-based orchestrator for AI agents that minimizes manual oversight while learning user preferences, making it essential for scaling AI-driven workflows without sacrificing control.
