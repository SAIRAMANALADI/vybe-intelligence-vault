## Summary
A marketplace and plugin system for driving Coherent Gameface UIs (HTML/CSS/JS game interfaces) using AI agents via an MCP server. It provides tools for DOM inspection, JavaScript evaluation, debugging, and automation of game UIs, with skills for understanding Gameface mechanics and troubleshooting common issues.

## Key Features
- Generic MCP server (`gameface-devtools-mcp`) for driving any Coherent Gameface UI via CDP, usable with any MCP client (Claude, Codex, Cursor, etc.)
- Two skills (`gameface` and `gameface-driving`) for agent education on Gameface mechanics and practical UI automation procedures
- Direct DOM inspection, JavaScript evaluation, screenshots, console logging, and breakpoint debugging within game UIs
- Version-gating and feature detection to handle Gameface engine quirks and undocumented behaviors
- Self-contained server bundle with no external dependencies, ensuring offline and version-locked operation

## Why It Matters for RAG Builders
It enables AI agents to programmatically interact with and debug game UIs or any Coherent Gameface-embedded application, bridging the gap between agentic workflows and real-time UI automation.
