## Summary
Veyyon is a terminal-based coding agent designed for inspectable context, controlled mutation, and long-running work. It provides a transparent prompt system, model-native effort controls, explicit state ownership, and secure secret management, enabling precise and auditable AI-driven code modifications.

## Key Features
- Inspectable and customizable prompts with layered context files (AGENTS.md, PROMPT_SECTIONS/)
- Model-native effort controls with visible compaction and fallback policies
- Secure secret management using placeholders and encrypted storage
- Typed workers for concurrent task execution with schema-validated results
- Language Server Protocol (LSP) integration for precise code refactoring

## Why It Matters for RAG Builders
Veyyon enables RAG builders to integrate a transparent, auditable, and secure agent framework for code generation and modification, ensuring controlled mutations and inspectable context for AI-driven workflows.
