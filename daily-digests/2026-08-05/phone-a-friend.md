## Summary
A CLI orchestration layer for AI coding agents that enables delegation, multi-model collaboration, and persistent sessions across multiple backends like Claude, Codex, Gemini, Ollama, and OpenCode.

## Key Features
- Relay mode for one-shot delegation to multiple AI backends (Claude, Codex, Gemini, Ollama, etc.)
- Team mode for iterative multi-backend refinement over multiple rounds
- Agentic mode for persistent multi-agent sessions with @mention routing
- Host parity support for Claude Code, Codex, OpenCode, and others
- Structured output, sessions, job tracking, and review automation

## Why It Matters for RAG Builders
It simplifies orchestrating multiple AI agents and backends for collaborative coding tasks, reducing manual coordination overhead in RAG and AI stack workflows.
