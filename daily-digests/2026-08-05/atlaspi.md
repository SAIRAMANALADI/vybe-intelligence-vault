## Summary
AtlasPI is a structured historical geographic database designed for AI agents, providing queryable historical entities, boundaries, and events from 4500 BCE to 2024 with GeoJSON support, confidence scores, and academic citations.

## Key Features
- Comprehensive historical dataset spanning 6,500 years with 1,006 entities and 643 events
- Structured REST API with 67+ endpoints for querying entities, boundaries, and events
- GeoJSON and CSV export capabilities for integration with mapping tools
- Confidence scoring and academic citations for data transparency and reliability
- Ethical framework enforcing truth, transparency, and bias mitigation in historical data
