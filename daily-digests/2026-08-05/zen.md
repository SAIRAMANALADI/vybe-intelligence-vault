## Summary
Zen is a VSCode extension that integrates AI chat directly into the editor, enabling users to connect to any LLM provider for code-related assistance, file operations, and conversation tracking without leaving the development environment.

## Key Features
- Multi-LLM provider support (DeepSeek, Claude, Gemini, etc.) with seamless switching
- In-editor AI chat with streaming responses and syntax-highlighted code blocks
- File read/edit capabilities with user-approved action buttons and checkpoint tracking
- Conversation history and checkpoint/revert functionality for file modifications
- Easy setup via VSCode Marketplace or VSIX installation

## Why It Matters for RAG Builders
Zen streamlines AI-assisted coding by embedding chat and file operations directly into VSCode, reducing context-switching for developers building RAG systems.
