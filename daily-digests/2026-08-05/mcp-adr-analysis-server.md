## Summary
An MCP server that provides AI-powered architectural decision analysis and ADR (Architectural Decision Record) management for AI assistants like Claude, Cline, and Cursor. It enables intelligent code generation, decision tracking, and development workflow automation with deep architectural insights.

## Key Features
- AI-powered architectural analysis with confidence scoring via OpenRouter API
- Tree-sitter AST analysis for semantic code understanding and architectural pattern extraction
- Smart Code Linking to discover code files related to ADRs and architectural decisions
- Security and compliance features with automatic sensitive content masking
- Test-driven development integration with deployment readiness validation

## Why It Matters for RAG Builders
It enables AI assistants to perform deep architectural analysis and ADR management directly within development workflows, reducing reliance on manual prompts and improving automation for RAG systems.
