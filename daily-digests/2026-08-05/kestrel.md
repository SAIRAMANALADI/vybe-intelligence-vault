## Summary
Kestrel is a local-first AI engineering agent runtime designed for developers seeking memory-native, inspectable, and safe automation. It combines a conversational CLI, structured memory layers, durable task execution, and proactive routines to enable progressive learning without hidden behavioral drift.

## Key Features
- Layered structured memory (Memvid v2) with distinct trust and promotion rules
- Durable task execution with approval gates and rollback capabilities
- Failure-aware execution with evidence-backed learning and strategy changes
- Local workbench for inspecting runs, memory, and learning records
- Extensible via MCP servers, skills, plugins, and channels

## Why It Matters for RAG Builders
Kestrel provides a robust, inspectable foundation for building AI agents that learn safely and retain project knowledge without compromising control or transparency.
