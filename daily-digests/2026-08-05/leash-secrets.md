## Summary
leash-secrets is a real-time secret detection tool designed to catch API keys, tokens, and credentials as AI agents generate code, preventing leaks before they are committed to version control. It integrates directly into AI agent workflows and provides actionable fixes.

## Key Features
- Real-time secret detection during AI agent code generation
- 70+ secret patterns across 11 provider categories (AWS, GCP, Stripe, OpenAI, etc.)
- Integrates with 20+ AI agents (Cursor, Claude Code, Copilot, etc.) via skill files or AGENTS.md
- Provides actionable fixes and risk assessments for detected secrets
- Benchmark corpus with 100% recall and 0% false positives for known patterns

## Why It Matters for RAG Builders
It prevents credential leaks at the point of creation in AI-generated code, reducing security risks before secrets ever reach version control.
