## Summary
TensorCircuit-NG is a next-generation, open-source quantum software framework designed for AI-native quantum programming and automated scientific discovery. It integrates quantum circuit simulation with modern machine learning frameworks (JAX, TensorFlow, PyTorch) to enable high-performance, scalable quantum-classical hybrid workflows, including variational algorithms and tensor network simulations.

## Key Features
- Supports quantum circuit simulation across multiple paradigms (ideal, noisy, stabilizer, qudit, fermionic, analog, symmetric)
- Integrates with JAX, TensorFlow, and PyTorch for automatic differentiation, JIT compilation, and hardware acceleration
- Enables large-scale distributed simulations with multi-GPU and multi-host support
- Provides AI-native workflows with embedded agentic skills for automated research, code generation, and optimization
- Offers seamless quantum hardware access and hybrid CPU/GPU/QPU deployment solutions
