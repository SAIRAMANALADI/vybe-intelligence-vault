## Summary
Ōtori is a local music library manager and player that organizes, plays, and delegates tag management to AI agents while maintaining a strict trust stack for data integrity. It combines a dual-mode UI (Stage for performance, Backstage for management) with agent-native CLI capabilities and provenance-aware tag editing.

## Key Features
- Agent-native CLI with dry-run safety and provenance tracking for tag edits
- Dual-mode UI (Stage for performance, Backstage for management) with live spectrum analysis
- Provenance-first tag system with human-curated field protection and undoable transactions
- Built-in BPM detection and lyrics synchronization with LRCLIB and VocaDB integration
- Cross-platform support (macOS, Linux, Windows) with Tauri-based desktop app
