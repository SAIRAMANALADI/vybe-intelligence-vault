## Summary
Proofborne is a local-first coding agent that generates verifiable proof graphs to validate task completion claims. It ensures completion integrity by binding evidence to runtime state and enabling offline verification without vendor lock-in.

## Key Features
- Task Contracts with runtime-generated Proof Graphs for verifiable completion claims
- Hash-chained event records and SQLite WAL persistence for auditability
- Provider-free offline proof verification and deterministic crash recovery
- Policy-preset routing with fail-closed budget and credential controls
- Hierarchical agent delegation with independent reviewer/adversary gates

## Why It Matters for RAG Builders
Proofborne enables AI engineering teams to build trustworthy, auditable agent workflows by providing verifiable proof of task completion without relying on proprietary or opaque verification systems.
