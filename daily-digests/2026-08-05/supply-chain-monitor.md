## Summary
Supply Chain Monitor is a Windows application that tracks PyPI and npm package releases, analyzes changes between versions using an LLM, and alerts users via Slack when risky updates are detected.

## Key Features
- Monitors PyPI and npm for new package releases
- Compares file changes between versions to detect anomalies
- Uses an LLM to classify changes as benign or malicious
- Sends Slack alerts for suspicious updates
- Runs as a background Windows application

## Why It Matters for RAG Builders
It automates the detection of risky package updates, reducing supply chain attack surfaces for AI and software projects.
