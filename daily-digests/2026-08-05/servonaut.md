## Summary
Servonaut is a terminal-based unified interface (TUI) for managing multiple cloud providers (AWS, Hetzner, OVH) and custom servers with built-in AI assistance, MCP server integration, and advanced monitoring capabilities.

## Key Features
- Unified terminal interface for AWS, Hetzner, OVH, and custom servers
- Built-in AI chat assistant with MCP tool-calling capabilities
- Real-time resource monitoring and log analysis
- Database credential vault with end-to-end encryption
- Proactive monitoring with automated findings and remediation suggestions
