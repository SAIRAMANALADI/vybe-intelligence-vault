## Summary
BloxForge provides a local MCP-compatible interface to safely control Roblox Studio via AI agents, enabling inspection, editing, building, testing, and debugging of Roblox experiences without cloud dependencies.

## Key Features
- Secure localhost-only bridge between MCP clients and Roblox Studio for AI agent control
- Supports inspection, editing, building, testing, and debugging of Roblox experiences
- Integrates with Rojo, Rokit, and Wally for file-backed project management
- Implements plan/apply workflows with confirmation gates and rollback for safety
- Provides tool profiles (core, builder, tester, full, inspector) for granular access control

## Why It Matters for RAG Builders
BloxForge enables AI agents to safely and efficiently interact with Roblox Studio, unlocking automated game development, testing, and debugging workflows for Roblox experiences.
