## Summary
Mineclaw integrates AI agents into Minecraft Paper/Folia servers, enabling models to understand server-authored knowledge, inspect player context, discover skills, compose tools, and request real server actions from public chat. It bridges AI decision-making with in-game operations through a workspace-driven, extensible framework.

## Key Features
- Workspace-driven agent identity and knowledge via AGENTS.md, tools.yml, and skills/*.md
- Real-time Minecraft context access (block inspection, inventory, online players) without modifying the world
- Extensible skills system allowing operators to define server-specific procedures and commands
- Approval-gated command dispatch with explicit outcome semantics for safety
- Folia-native scheduling with streaming Action Bar output for seamless player interaction

## Why It Matters for RAG Builders
