## Summary
AbaPay is a decentralized Web3 payment protocol enabling users to pay real-world utility bills (airtime, electricity, data, etc.) using stablecoins on Celo and Base. It integrates with VTpass for instant fiat settlement and offers an autonomous AI agent (DeAI) for hands-free bill payments via Telegram, WhatsApp, X, and MCP.

## Key Features
- Multi-chain stablecoin payments (USDT, USDC, cUSD) on Celo and Base
- Autonomous AI agent (DeAI) for hands-free bill payments via Telegram/WhatsApp/X/MCP
- ERC-8004 on-chain agent identity for discoverability and trust
- Live VTpass catalogue integration for real-time provider data and dynamic pricing
- Sponsored gas transactions on Base for zero-fee user experience

## Why It Matters for RAG Builders
AbaPay bridges Web3 stablecoins with real-world utility payments, enabling seamless, decentralized financial access for emerging markets while leveraging autonomous AI agents for unattended transactions.
