## Summary
A monorepo hosting a Modular Component Protocol (MCP) application and six independent Australian accounting engines, each with its own distribution, versioning, and release workflow. The MCP server aggregates these engines for local accounting review tasks without sharing runtime dependencies.

## Key Features
- Six independently versioned accounting engines for Australian tax and compliance checks
- MCP application acting as a registry server to aggregate engines via published distributions
- Strict dependency isolation between engines and MCP application to prevent circular imports
- Namespaced releases and automated workflows for each component
- No shared runtime library or combined versioning, ensuring modularity
