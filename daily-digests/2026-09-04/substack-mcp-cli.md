## Summary
A dual-purpose CLI and MCP server for interacting with Substack publications programmatically. It provides 65 tools for managing drafts, posts, analytics, subscribers, and research, enabling AI agents and users to automate and enhance Substack workflows without a public API.

## Key Features
- 65 tools covering drafts, posts, analytics, subscribers, and research
- Dual CLI and MCP server interfaces for flexibility
- Direct interaction with Substack's internal document format
- Automated paywall and embed handling in drafts/posts
- Supports scripting, scheduling, and AI agent integration

## Why It Matters for RAG Builders
It bridges the gap between Substack's lack of a public API and AI-driven workflows, enabling seamless automation and deeper integration for RAG and AI stack builders.
