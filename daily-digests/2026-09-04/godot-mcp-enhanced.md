## Summary
A secure, open-source MCP server for Godot game development that provides 38 MCP tools (210 actions) enabling AI agents to read, write, execute, and validate Godot projects with a three-layer architecture (headless, editor, game bridge) and robust security features.

## Key Features
- Three-layer architecture (headless CLI, editor WebSocket, game bridge TCP) for static editing, real-time debugging, and runtime validation
- 38 MCP tools (210 actions) covering scene/script/UI/animation/physics/audio/testing/export/3D assets with structured workflows
- Robust security system: path whitelisting, binary whitelisting, GDScript injection defense, confirmation tokens, output anti-forgery, and sandboxing
- Engine-level runtime control via Game Bridge for real-time state inspection, input simulation, recording/replay, and frame verification
- Structured AI development loops with validation gates (e.g., `run_and_verify`, `validate_scripts`, `verify_delivery`) for end-to-end testing and delivery

## Why It Matters for RAG Builders
It enables AI agents to safely interact with and control running Godot games, bridging the gap between static file editing and dynamic runtime validation for AI-driven game development workflows.
