## Summary
Lien is a local-first code-intelligence layer for AI agents that provides structural analysis (e.g., dependency impact, complexity metrics) and fast lexical search over codebases. It integrates with AI coding assistants via the Model Context Protocol (MCP) and runs entirely offline without requiring embeddings or external models.

## Key Features
- Structural code analysis (dependency impact, complexity metrics, test associations)
- Fast lexical search (FTS5/BM25) over code, docstrings, and symbol names
- 100% local and private with no external model dependencies
- MCP-compatible integration for AI coding assistants (Cursor, Claude Code, etc.)
- Self-hostable GitHub Action (Lien Review) for PR complexity and bug analysis

## Why It Matters for RAG Builders
Lien provides critical structural and lexical context for AI agents to safely and accurately edit code, eliminating the need for external embeddings while enabling deep codebase understanding.
