## Summary
Source RPC is a TypeScript-based RPC framework designed for peer-to-peer communication across heterogeneous networks (e.g., browsers, Node.js, MQTT devices) using WebSocket and MQTT 5 transports. It enables bidirectional method calls between peers without code generation, using live class instances as contracts.

## Key Features
- Single programming model across WebSocket and MQTT 5 transports
- Class-based contract without code generation or schema files
- Explicit method semantics (query, idempotent-command, non-repeatable-command)
- Built-in tooling for debugging, recording, and replaying RPC calls
- Durable idempotency stores to prevent duplicate command execution

## Why It Matters for RAG Builders
It provides a unified RPC model for complex, multi-transport networks, ensuring reliable and semantically explicit method calls critical for AI-driven systems interacting with physical devices.
