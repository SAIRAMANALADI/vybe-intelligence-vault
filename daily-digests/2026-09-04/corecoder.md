## Summary
CoreCoder is a minimal, open-source Python implementation of a coding agent designed to be fully readable and hackable. It provides a foundational 1,201-line engine that demonstrates how coding agents work, enabling users to fork and extend it for their own purposes.

## Key Features
- Ultra-minimal engine (~1,201 lines of Python) for easy understanding and modification
- End-to-end agent loop with file editing, shell execution, and sub-agent spawning
- Three-tier context compaction for efficient memory management
- Built-in token and cost tracking for transparency
- Interactive REPL and one-shot execution modes for flexibility

## Why It Matters for RAG Builders
CoreCoder provides a transparent, minimal reference for building and understanding coding agents, making it essential for developers who want to learn, fork, or extend agent frameworks without hidden complexity.
