## Summary
An AI agent framework that enhances memory and self-improvement over time by capturing facts, daily logs, and self-reviews in an Obsidian vault. It uses plain markdown files and shell scripts to create a self-editing system that improves with repeated use.

## Key Features
- Captures facts, daily logs, and self-reviews in markdown files for persistent memory
- Self-editing system that refines skills based on repeated lessons
- Uses Obsidian for note-taking and knowledge organization
- Supports episodic, semantic, and working memory through structured vault layout
- Operates without a vector database or hosted service, relying solely on files
