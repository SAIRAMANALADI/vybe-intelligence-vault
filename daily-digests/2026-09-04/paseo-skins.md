## Summary
Paseo Skins provides open-source themes, a browser-based theme builder studio, and a CLI tool for applying custom skins to the Paseo AI application via Chrome DevTools Protocol (CDP). It includes an Agent Skill for seamless theme integration and a macOS CDP theme loader for persistent application.

## Key Features
- Browser-based theme builder studio for real-time preview and customization
- CLI tool for one-click theme application with validation and persistence
- Agent Skill integration for seamless theme switching via AI tools
- Safe CDP-based theme injection with strict localhost binding and validation
- Automated macOS login agent for persistent theme recovery across restarts

It enables AI application developers to customize and deploy themes programmatically, enhancing user experience and personalization in AI-driven tools like Paseo.
