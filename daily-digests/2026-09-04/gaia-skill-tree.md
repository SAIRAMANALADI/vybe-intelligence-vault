## Summary
Gaia Skill Tree is an open-source registry and skill graph for AI agents, enabling developers to author, verify, and attribute skills with a tiered ranking system. It provides a structured 'skill tree' for organizing and fusing agent capabilities, along with a CLI and TUI for skill management and deployment.

## Key Features
- Structured skill tree with tiered ranking (0★ to 6★) based on evidence and mastery
- CLI and TUI for skill scanning, pushing, and management
- Fusion system to combine skills into higher-order capabilities
- Evidence-backed verification with multiple evidence types (arxiv, repo, benchmark, etc.)
- Integration with AI agents via MCP and Skill Heaven plugin for dynamic skill summoning

## Why It Matters for RAG Builders
Gaia Skill Tree provides a decentralized, evidence-based registry for AI agent skills, ensuring attribution and reusability while enabling dynamic skill fusion for advanced agent capabilities.
