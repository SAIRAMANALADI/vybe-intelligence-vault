## Summary
An ElizaOS plugin providing real-time Solana trading intelligence, KOL wallet tracking, and deployer analytics through a TypeScript SDK. It offers low-latency data feeds, on-chain metrics, and event streaming for Solana ecosystem participants.

## Key Features
- Real-time Solana KOL wallet tracking with <3s latency
- Deployer analytics and wallet holdings verification
- Token surge/revival detection with tiered momentum signals
- WebSocket streaming and webhook support for real-time events
- Token locks/vesting, fee shares, and unlocks tracking
