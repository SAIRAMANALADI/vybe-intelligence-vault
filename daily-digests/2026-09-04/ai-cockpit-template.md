## Summary
AI Cockpit is a governance layer for AI-assisted software development that enforces evidence-based review, verification, and auditability of AI-generated changes. It acts as a repository governance boundary for agentic coding tools like Codex, Gemini, and Claude, ensuring calibrated trust between humans and AI agents.

## Key Features
- Enforces scope boundaries and verification requirements for AI-generated changes
- Provides independent validation of changes against declared contracts
- Generates human-readable summaries and audit trails for AI tasks
- Supports calibrated trust through evidence governance and policy enforcement
- Integrates with agentic coding tools (Claude, Codex, Cursor, etc.) without replacing them

## Why It Matters for RAG Builders
AI Cockpit ensures AI-generated code changes are bounded, reviewable, and auditable, reducing risks of unchecked modifications and enabling reliable RAG pipelines for AI stack builders.
