## Summary
codexCLI is a lightweight command-line tool for storing and retrieving frequently used information like notes, commands, or code snippets using simple dot-path navigation. It includes shell completions and an MCP server for integration with AI tools or automation workflows.

- Store and retrieve data using intuitive dot-path navigation
- Shell completions for faster command entry

- Lightweight and no complex setup required
- Local data storage with configurable paths
