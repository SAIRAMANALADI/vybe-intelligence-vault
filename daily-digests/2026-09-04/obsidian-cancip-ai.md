## Summary
Obsidian Cancip AI is a mobile-first AI chat panel for Obsidian that enables agent workflows, vault management, and structured note editing with review-gated actions. It integrates deeply with Obsidian's ecosystem to provide AI-driven automation, memory, and tool execution within the vault.

## Key Features
- Mobile-first AI chat panel with Obsidian integration
- Agent-style tool execution with approval/full-access modes
- Structured vault actions via `cancip-action` JSON tool blocks
- Review-gated note edits with outcome verification and evidence capture
- Long-term memory, skills, and experience harvesting for workflow automation
