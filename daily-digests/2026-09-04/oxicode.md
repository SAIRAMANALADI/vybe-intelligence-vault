## Summary
OxiCode is an experimental Rust-based CLI agent for software engineering, designed as a work-in-progress port of Claude Code. It provides a terminal-based interface with multi-provider LLM support, a robust tooling system, and a multi-layer permission pipeline for secure operations.

## Key Features
- Multi-provider LLM support with extensible provider traits
- 49 built-in tools for file operations, git, bash, and more
- 6-layer permission pipeline for secure command execution
- Ratatui-based TUI with markdown rendering and syntax highlighting
- Session persistence and structured NDJSON output for automation

## Why It Matters for RAG Builders
OxiCode provides a modular, Rust-based agent framework with advanced tooling and permission systems, making it a valuable foundation for building secure, extensible AI-driven CLI tools.
