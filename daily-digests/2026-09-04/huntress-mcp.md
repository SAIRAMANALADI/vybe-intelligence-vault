## Summary
A Model Context Protocol (MCP) server that enables AI assistants to securely access and interact with the Huntress cybersecurity platform's data and operations, providing structured tools for security management and incident response.

## Key Features
- Full MCP protocol compliance for structured AI tool access
- Comprehensive security coverage with CRUD operations for incidents, organizations, and users
- Decision-tree navigation for dynamic domain-specific tool discovery
- Dual transport support (stdio and HTTP Streamable) for flexible deployment
- Built-in rate limiting and secure authentication for Huntress API integration
