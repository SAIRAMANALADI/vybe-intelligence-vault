## Summary
A browser-based 3D modeling editor that enables direct slicing and printing to a Bambu Lab A1 printer over LAN without requiring Bambu Cloud or vendor apps. Includes an optional AI agent for automated part generation and live printer monitoring.

## Key Features
- Browser-based 3D editor with primitive modeling (box, cylinder, prism, sphere, cone, torus, wedge, threads) and boolean operations
- Direct LAN printing to Bambu Lab A1 via FTPS and MQTT without Bambu Cloud dependency
- Optional AI agent for automated part generation with self-checking printability rules
- Live printer status and camera feed relayed over MQTT and custom protocol
- Offline-first design with vendored libraries and local AI model support

## Why It Matters for RAG Builders
It provides an offline-capable, AI-enhanced 3D modeling and direct-printing pipeline for Bambu Lab printers, reducing dependency on vendor ecosystems and enabling automated design workflows.
