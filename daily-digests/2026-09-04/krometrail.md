## Summary
Krometrail is a Rust-based runtime that enables local browser control and temporal visual evidence collection for AI coding agents. It provides a local MCP server for browser lifecycle management, debugging, and temporal artifact generation.

## Key Features
- Local MCP server for browser lifecycle and control tools
- Temporal visual evidence capture and retention (screenshots, snapshots, filmstrips, motion history)
- Browser discovery and validation via `doctor` command
- Durable recording and artifact management with retention policies
- Cross-platform support (Linux, macOS, Windows) with atomic installation and version verification

## Why It Matters for RAG Builders
Krometrail provides essential browser control and temporal debugging capabilities for AI agents, enabling rich, reproducible visual evidence collection during agent interactions.
