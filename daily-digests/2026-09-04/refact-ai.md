## Summary
Refact.ai is an open-source, local-first AI coding assistant and autonomous software-engineering agent that integrates with IDEs (VS Code, JetBrains) to provide chat, code completion, debugging, and autonomous task execution. It leverages RAG over the workspace and supports self-hosting with BYOK model options.

## Key Features
- IDE-integrated chat and code completion with RAG over workspace
- Autonomous agent mode for end-to-end task execution and iteration
- Support for MCP servers and tool registry with confirmation rules
- High performance on SWE-bench Lite (60.0%) and Aider's Polyglot benchmark (93.3%)
- Self-hosting and BYOK model support with BSD-3-Clause licensing

## Why It Matters for RAG Builders
