## Summary
oh-my-dag provides a full-featured harness for AI agents running on the pi coding-agent runtime, featuring a DAG execution engine, self-consolidating memory, cross-model verification, and a suite of 17 skills for structured task orchestration and reliability.

## Key Features
- Typed DAG execution engine with concurrent scheduling and fault boundaries
- Self-consolidating memory system with TTL-based cleanup and validation gates
- Cross-model verifier for plan validation and escalation on failure
- 17 built-in skills including plan mode, edit verification, and MCP routing
- SQLite-backed run recording with artifact-hashed checkpoints for resumable workflows

## Why It Matters for RAG Builders
It provides a robust, model-agnostic framework for orchestrating complex AI workflows with reliability guarantees, making it essential for building production-grade RAG systems.
