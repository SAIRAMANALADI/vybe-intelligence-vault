## Summary
Canonic is a context layer for AI agents that enables accurate and governed data querying by providing semantic definitions, business meaning, and guardrails without modifying the underlying data warehouse. It acts as a bridge between raw database schemas and AI-driven analytics tools.

## Key Features
- Automatically generates and maintains semantic definitions, business knowledge, and contracts from database schemas
- Enforces guardrails to prevent confidently incorrect answers by embedding business rules into queries
- Supports local-first and air-gapped deployments with read-only access to data warehouses
- Integrates with AI agents via MCP (Model Context Protocol) for structured query execution and metadata-rich responses
- Provides deterministic SQL compilation with optional LLM-driven context drafting during setup

## Why It Matters for RAG Builders
Canonic ensures AI agents query data accurately and reliably by embedding business context and governance directly into the query process, eliminating guesswork and reducing errors in RAG pipelines.
