## Summary
Handover MCP provides shared, versioned context for seamless collaboration between humans and AI agents (Claude Code, Codex, Cursor, Gemini CLI) by preserving decisions, files, history, and authorship during work handoffs. It includes a hosted Model Context Protocol server, a dependency-free CLI, and open Agent Skills for reusable workflows.

## Key Features
- Preserves decisions, files, history, and authorship during handoffs between humans and AI agents
- Hosted MCP server with OAuth authentication for secure context sharing
- Dependency-free CLI for terminal-based workflows (handover-sh)
- Open Agent Skills for reusable workflows (publish, resume, review, verify, governance)
- Versioned context with immutable revisions and audit trails

## Why It Matters for RAG Builders
Handover MCP is essential for RAG builders as it enables seamless, versioned context sharing between AI agents and humans, ensuring continuity and preserving critical decision-making history in multi-agent workflows.
