## Summary
JMComic AI is an AI-native assistant for JMComic (禁漫天堂) that integrates with AI agents via MCP (Model Context Protocol) and Skills frameworks. It enables natural language interaction for searching, downloading, and managing adult comics, abstracting complex workflows into AI-friendly tools and scripts.

## Key Features
- Dual integration paths: MCP for tool-based AI interaction and Skills for structured AI documentation and CLI scripts
- Natural language search, filtering, and downloading of comics with real-time progress tracking
- Dynamic configuration management via AI commands or CLI tools
- Support for post-processing (ZIP, PDF, long-image stitching) and comment retrieval
- Task-specific logging and error handling with isolated runtime and download logs

## Why It Matters for RAG Builders
It bridges the gap between AI agents and specialized comic crawling tools, enabling seamless natural language interaction for complex media retrieval tasks in RAG pipelines.
