## Summary
pplx is an unofficial CLI tool for interacting with the Perplexity AI API, enabling users to query, chat, and perform web searches with advanced features like shell completion, MCP integration, and configurable response parameters.

## Key Features
- Interactive chat and query capabilities with the Perplexity API
- Advanced shell completion for commands, flags, and dynamic values (models, domains, etc.)
- MCP integration for enhanced AI model context handling
- Configurable response parameters (temperature, top-k, penalties, etc.)
- Support for YAML configuration files and interactive setup
