## Summary
Belifoa is a high-performance Linear client and Model Context Protocol (MCP) server designed to optimize AI agent interactions with Linear by reducing token bloat, ensuring persistent authentication, and simplifying tool usage for issue management and bulk operations.

## Key Features
- Persistent Personal API Key authentication for Linear, avoiding short-lived OAuth sessions
- 70–80% reduction in prompt token usage via compact JSON, Markdown, and CLI table formatting
- Unified access across CLI, MCP Server, Antigravity Skills, Plugins, and Git Hooks
- Multi-profile and workspace isolation for concurrent agent operations without conflicts
- Built-in benchmarking suite to measure payload optimization and token savings

## Why It Matters for RAG Builders
Belifoa streamlines Linear interactions for AI agents by drastically reducing context window usage and ensuring persistent authentication, making it essential for scalable RAG and agentic AI systems.
