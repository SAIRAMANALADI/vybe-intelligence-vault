## Summary
A desktop application designed to extract precise answers from long documents using a multi-stage RAG pipeline. It processes local files privately, ensuring data security while leveraging machine learning for context-aware query resolution.

## Key Features
- Three-stage processing pipeline (Identification, Extraction, Generation)
- Query-aware routing for efficient document search
- Cross-encoder re-ranking to improve answer accuracy
- Context compression to handle long documents efficiently
- Local file processing with no cloud dependency
