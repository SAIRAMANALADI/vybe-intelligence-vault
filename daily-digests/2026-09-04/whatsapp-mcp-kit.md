## Summary
This repository provides a toolkit to connect WhatsApp to MCP clients like Claude Code, enabling AI assistants to read chats, send messages, and interact with WhatsApp accounts. It simplifies the linking process with patches, a live QR code generator, and detailed documentation.

## Key Features
- Live QR code generation and auto-refreshing page for seamless WhatsApp pairing
- Patches for upstream WhatsApp MCP server to improve functionality (e.g., raw QR output, group name resolution)
- Comprehensive documentation including security considerations, gotchas, and troubleshooting
- Self-contained pairing tool with regression testing and clear exit codes
- Production-tested setup with battle-hardened patches and deployment guidance

## Why It Matters for RAG Builders
This kit simplifies the critical but error-prone process of linking WhatsApp to AI assistants, enabling secure and automated interactions with personal or business chats for RAG and agent-based systems.
