## Summary
PDAgent is a self-hosted Telegram bot that enables remote control of a Windows PC with AI-powered automation, file management, and live desktop streaming. It integrates with Google's Gemini AI for conversational control and supports scheduling, UI automation, and developer workflows without requiring open inbound ports or subscriptions.

## Key Features
- Self-hosted remote PC control via Telegram with no inbound port forwarding
- AI-powered automation using Google Gemini 2.0 Flash for natural language task execution
- Live remote desktop streaming with mouse/keyboard control over secure HTTPS tunnel
- OCR-based UI automation and macro recording for repetitive desktop tasks
- Task scheduling, file management, and developer workflow automation (Claude, VS Code, React Native builds)

## Why It Matters for RAG Builders
PDAgent provides a lightweight, self-hosted alternative to traditional remote desktop tools with AI-driven automation capabilities, making it ideal for developers and power users who need secure, portable remote control of their Windows PCs.
