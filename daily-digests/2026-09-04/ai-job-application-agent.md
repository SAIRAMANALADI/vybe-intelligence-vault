## Summary
An autonomous AI agent that processes a candidate's CV PDF to perform end-to-end analysis, including profile extraction, ATS scoring, career-path analysis, skill-gap detection, interview preparation, and improved CV generation. The system executes a fixed 7-step pipeline with minimal user interaction, combining deterministic processing with structured LLM reasoning.

## Key Features
- Fixed 7-step autonomous pipeline with shared state for context accumulation
- Deterministic ATS scoring combined with LLM-driven career analysis
- Structured Pydantic schemas for validated LLM outputs
- Graceful failure handling and preservation of completed results
- Modular architecture with centralized LLM client and prompts

## Why It Matters for RAG Builders
Demonstrates a robust autonomous agent architecture for multi-step AI workflows, combining deterministic processing with structured LLM reasoning for practical applications like CV analysis and career guidance.
