## Summary
A Claude Code-compatible Agent Skill for automating TYPO3 extension testing, including unit, functional, and E2E tests with Playwright, accessibility checks, and CI/CD integration. Designed to standardize and streamline testing workflows for TYPO3 developers.

## Key Features
- Generates Unit, Functional, and E2E tests for TYPO3 extensions with standardized templates
- Integrates Playwright for browser-based end-to-end testing and axe-core for accessibility compliance
- Supports multi-database testing (SQLite, MySQL, MariaDB, PostgreSQL) via Docker orchestration
- Provides automated infrastructure setup, CI/CD templates, and quality tooling (PHPStan, Rector, php-cs-fixer)
- Offers CSV-based fixture management and assertions for improved test readability and maintainability

## Why It Matters for RAG Builders
It standardizes and automates TYPO3 extension testing workflows, reducing setup time and ensuring consistency across CI/CD pipelines for AI-driven development environments.
