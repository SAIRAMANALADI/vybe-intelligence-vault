## Summary
Latiao is a privacy-focused desktop AI agent for macOS and Windows that autonomously performs local tasks like file operations, shell commands, web searches, and financial data retrieval without cloud dependency. It supports local and cloud LLMs, multi-agent orchestration, and persistent memory.

## Key Features
- Runs entirely on-device with no cloud dependency, ensuring data privacy
- Supports both local (MLX, llama.cpp) and cloud LLMs (OpenAI, DeepSeek, etc.)
- Multi-agent system with specialized sub-agents for tasks like code review and debugging
- Persistent memory with SQLite and TF-IDF semantic search for cross-session context
- Five-level permission system for granular control over agent autonomy

## Why It Matters for RAG Builders
Latiao provides a privacy-preserving, local-first framework for building autonomous AI agents that can execute complex tasks without cloud dependency, making it ideal for RAG builders prioritizing data security and offline functionality.
