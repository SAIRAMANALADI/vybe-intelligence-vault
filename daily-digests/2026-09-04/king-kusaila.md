## Summary
A voice-operated system for Linux that enables hands-free dictation and task execution by integrating speech-to-text with Claude Code. It allows users to issue voice commands, transcribe them, and delegate tasks to an AI agent with full autonomy.

## Key Features
- System-wide voice dictation with hotkey activation (Super+C)
- Voice and text mission execution delegated to Claude Code with background or visible terminal options
- Durable job logging with full mission history and reports in ~/.king-kusaila/jobs/
- Local fallback for speech-to-text using whisper.cpp to reduce API dependency
- GTK layer-shell overlay for visual feedback and Waybar status integration

## Why It Matters for RAG Builders
It bridges the gap between voice input and autonomous AI agent execution, enabling seamless hands-free system control and task automation for RAG builders.
