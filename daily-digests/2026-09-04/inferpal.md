## Summary
Inferpal is an agentic developer assistant for Visual Studio 2026 and VS Code, powered entirely by local LLMs. It enables autonomous coding tasks like file editing, testing, and debugging while maintaining strict local-first execution with approval-gated operations and zero cloud dependencies.

## Key Features
- Agentic loop with 28+ built-in tools for autonomous coding tasks (file editing, testing, debugging)
- Inline ghost-text completions and semantic codebase search with hybrid retrieval (cosine + BM25)
- Approval-gated writes, commands, and debugger-driven test failure analysis with real-time exception capture
- Multi-model toolkit including benchmarks, A/B testing, and a model router for background tasks
- Safety features like catastrophic command denylist, workspace sandboxing, and permission overlays

## Why It Matters for RAG Builders
Inferpal provides a robust, local-first agentic framework for AI-driven coding assistants, enabling safe, autonomous development workflows with deep IDE integration and real-time debugging capabilities.
