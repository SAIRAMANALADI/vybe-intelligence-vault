## Summary
Gloria AI MCP Server is a Model Context Protocol (MCP) server that delivers real-time, curated crypto news to AI agents, including sentiment analysis, category-based recaps, and search functionality. It supports both free and paid tiers with enriched data and ticker summaries.

## Key Features
- Provides real-time curated crypto news with sentiment analysis
- Supports free and paid tiers with enriched data (x402 protocol for payments)
- Offers tools for latest news, recaps, search, and category listings
- Compatible with stdio and streamable HTTP transports
- Integrates with AI agents via Model Context Protocol
