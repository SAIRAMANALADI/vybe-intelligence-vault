## Summary
n8nctrl is a CLI and MCP adapter for operating n8n workflow automation platforms. It provides scriptable read/report commands for workflows, executions, schedules, and credentials, and exposes 40+ tools via MCP for AI agents to triage failures, audit security risks, and manage workflows programmatically.

## Key Features
- 40+ tools for n8n workflow and execution lifecycle management (read/write)
- MCP adapter enabling AI agents to query/operate n8n instances via natural language
- Security-gated write operations with double-gating for credentials
- Automated auditing for deprecated nodes, security risks, and orphaned workflows
- Scriptable CLI for cron, CI, and terminal-based workflow operations

## Why It Matters for RAG Builders
It bridges AI agents with n8n workflow automation platforms, enabling agents to triage failures, audit security, and manage workflows programmatically without leaving their client.
