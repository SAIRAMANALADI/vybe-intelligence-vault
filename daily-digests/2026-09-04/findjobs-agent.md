## Summary
FindJobs-Agent is a full-stack job search assistant that automates job hunting by crawling postings from major tech companies, analyzing them with LLMs, parsing resumes, and conducting AI mock interviews. It integrates a React frontend with a Python backend to streamline the job application process.

## Key Features
- Multi-source job crawling from major tech companies with API and Selenium support
- LLM-driven job analysis for skill extraction, classification, and requirement matching
- Resume parsing and scoring against job postings with match percentage calculation
- AI mock interviews with real-time feedback generated from job descriptions
- SQLite-based persistence for job data and application tracking

## Why It Matters for RAG Builders
