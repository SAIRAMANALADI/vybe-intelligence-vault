## Summary
mails.ai provides an email infrastructure designed specifically for AI agents, offering an inbox with built-in security against prompt injection and cold outreach. It includes SDKs and an MCP server for seamless integration with agent frameworks.

## Key Features
- Agent-owned inbox with real-time inbound email processing and threading
- Built-in prompt injection detection and quarantine with injection_score and quarantined flags
- Cold outreach refusal with 422 error and auto-suspension for high complaint rates
- MCP server and TypeScript/Python SDKs for easy integration with agent frameworks
- Test keys for sandboxed development without sending real emails

## Why It Matters for RAG Builders
