## Summary
VibeGuard is a security scanner and AI agent firewall designed to detect vulnerabilities in AI-generated code, including leaked secrets, SQL injection, prompt injection, and uncapped agent loops. It operates entirely offline with zero telemetry and provides layered protection for AI-coded applications.

## Key Features
- 764 security rules covering secrets, SQLi, XSS, and AI-specific threats
- 82 MCP tools for real-time agent action inspection and blocking
- Local MITM proxy for language-agnostic network-layer security
- AI firewall with regex and semantic classifiers for prompt injection
- Compliance mapping to 10 frameworks (SOC 2, PCI DSS, HIPAA, GDPR, etc.)
