## Summary
AI Portfolio Compass is a local-first portfolio workbench that unifies multi-account, multi-market, and multi-currency holdings into a single dashboard for investment analysis, risk diagnosis, and AI-assisted review. It consolidates real brokerage data (A-shares, US stocks, Hong Kong stocks) and manual imports to provide a holistic view of an investor's portfolio.

## Key Features
- Unified multi-account, multi-market asset aggregation with real-time data freshness tracking
- Position layering (core, mid-term, short-term, options) for context-aware AI analysis
- AI-generated portfolio diagnosis reports with confidence scoring and actionable insights
- Trade review and behavioral analysis with discipline tracking and thesis validation
- Local-first architecture with strict security boundaries (no cloud uploads, no trading execution)

## Why It Matters for RAG Builders
It provides a secure, local-first framework for consolidating fragmented investment data to enable AI-driven portfolio analysis without exposing sensitive account information to external systems.
