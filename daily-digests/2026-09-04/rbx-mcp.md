## Summary
rbx-mcp is a Model Context Protocol (MCP) bridge that enables AI agents to write and execute Lua code live within Roblox Studio, facilitating autonomous iteration and debugging. It combines an MCP server with a local HTTP server and a minimal Studio plugin for seamless integration.

## Key Features
- MCP server exposing Studio actions as tools (e.g., execute_lua, read_studio_state)
- Local HTTP server for direct Lua execution and result retrieval
- Auto-installing Roblox Studio plugin for zero-config setup
- Model-agnostic design supporting Claude, GPT, or any MCP-capable AI host
- Dev mode for managed/corporate environments bypassing MCP restrictions

## Why It Matters for RAG Builders
It enables AI agents to autonomously write, test, and iterate Lua code directly in Roblox Studio, reducing manual intervention and accelerating game development workflows.
