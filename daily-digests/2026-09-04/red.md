## Summary
Red is a Vim-style terminal editor designed for AI-assisted coding, combining modal editing with agent-based workflows. It integrates Tree-sitter, LSP, and optional Codex agents to provide a self-contained, Rust-based editing environment with inline assistance and detachable sessions.

## Key Features
- Vim-style modal editing with full compatibility (Normal, Insert, Visual modes)
- Integrated AI agent support with editor-aware Codex interactions and bounded context
- Detachable sessions for macOS/Linux with retained state across disconnects
- Built-in LSP, Tree-sitter syntax highlighting, and Git integration
- Inline assistance for code review, explanation, and refactoring with undoable edits
