## Summary
A Model Context Protocol (MCP) server that integrates AI assistants like Claude with Things 3 for natural language task management. It enables AI-driven creation, reading, updating, and deletion of tasks, projects, and areas within Things 3 via AppleScript.

## Key Features
- Full CRUD operations for todos, projects, and areas in Things 3
- Natural language task creation and management via AI assistants
- Advanced search, filtering, and tag management capabilities
- Built-in list access (Inbox, Today, Upcoming, Anytime, Someday, Logbook, Trash)
- Robust error handling, logging, and concurrency support with AppleScript integration

## Why It Matters for RAG Builders
It bridges AI assistants with a popular task management app, enabling seamless natural language task automation and management for AI-driven workflows.
