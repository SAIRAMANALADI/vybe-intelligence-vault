## Summary
Gleba is a free, open-source web application designed for professional and amateur gardeners to manage vegetable gardens and orchards. It provides intelligent planning, water management, production tracking, and a 2D garden layout with drag-and-drop functionality.

## Key Features
- Intelligent planning with a step-by-step assistant for beginners, including crop rotations and automated cycles
- Water management with automated irrigation scheduling, urgency prioritization, and consumption tracking
- 2D garden layout with drag-and-drop functionality, realistic dimensions, and physical validation for crop placement
- Comprehensive production tracking with yield estimation, economic valuation, and real-time dashboard statistics
- MCP server integration for AI-driven automation and natural language interaction with garden data
