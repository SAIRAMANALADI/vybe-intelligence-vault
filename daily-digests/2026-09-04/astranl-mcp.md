## Summary
AstraNL MCP Server is a protocol-governed coordination infrastructure that enables AI agents to execute real-world tasks through verified human executors in the Netherlands. It acts as a broker for financial transactions, ensuring funds are held securely and only captured upon task completion verification.

## Key Features
- Verified human executor network in the Netherlands with KvK registry checks
- Secure financial hold-and-capture mechanism via Stripe (destination charge)
- Protocol-governed coordination with canonical truth sources (JSON endpoints)
- Public capabilities for task execution, verification, and coordination
- Compliance with EU-AI-Act, GDPR, and Wwft regulations

## Why It Matters for RAG Builders
AstraNL provides a critical bridge between AI agents and real-world task execution with verified human labor and secure financial transactions, essential for building robust AI orchestration systems.
