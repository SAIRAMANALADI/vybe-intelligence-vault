## Summary
A local-first expense tracking application with an AI agent that supports chat, WhatsApp, and receipt OCR. It features server-side tax calculations, one-way Google Sheets/Drive sync, and a React-based dashboard with generative UI components.

## Key Features
- Server-side tax back-calculation (GST/QST/HST) with strict layering and zero frontend math
- Multi-channel AI agent (web chat and WhatsApp) backed by a single tool-calling service layer
- Idempotent one-way Google Sheets/Drive sync with auto-recovery for deleted rows and ordering drift
- Receipt OCR with support for NVIDIA PaddleOCR, OpenAI vision, and Claude vision
- Generative UI components (charts, tables) rendered dynamically by the AI agent

## Why It Matters for RAG Builders
It demonstrates a robust, multi-channel AI agent framework with server-side business logic, OCR integration, and generative UI, making it a valuable reference for building scalable RAG systems.
