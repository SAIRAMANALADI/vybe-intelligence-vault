## Summary
Lobster0 is a self-hosted, private, and controlled personal AI agent that integrates models, tools, permissions, auditing, and multiple messaging channels into a single local Core. It enables users to interact with a unified agent via TUI, Feishu, Telegram, or Discord while enforcing strict policy, workspace boundaries, and audit trails.

## Key Features
- Unified Core integrating models, tools, permissions, and auditing for a single agent instance
- Multi-channel interaction via TUI, Feishu, Telegram, and Discord with shared runtime
- Strict permission modes (SAFE, SMART, AUTOPILOT, YOLO) for controlled autonomy
- Persistent memory with SQLite-backed state, FTS5 search, and markdown-based truth storage
- Sandboxed tool execution with Docker/Seatbelt, checkpointing, and rollback capabilities

## Why It Matters for RAG Builders
Lobster0 provides a robust, self-contained framework for building secure, auditable, and multi-channel AI agents with persistent memory and strict policy enforcement, critical for RAG stacks requiring controlled autonomy and multi-modal interactions.
