## Summary
Genesis Agent is a self-hosted autonomous coding agent that executes real tasks through a terminal, browser, and skill library, while maintaining persistent memory of work between sessions. It integrates with multiple AI providers and supports both local and cloud-based models.

## Key Features
- Executes real tasks via terminal, browser, and skills instead of just describing them
- Maintains persistent memory of work between sessions for continuity
- Skill library with executable Python Markdown files that grow organically with use
- Supports multiple AI providers (free and paid tiers) with fallback to local models
- Safety mechanisms for command execution, file operations, and browser actions

## Why It Matters for RAG Builders
It provides a robust, self-hosted framework for autonomous coding agents with persistent memory and executable skills, reducing context loss and improving task continuity for RAG/AI stack builders.
