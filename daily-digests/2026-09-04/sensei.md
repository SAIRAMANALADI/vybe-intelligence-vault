## Summary
Sensei is a self-hosted gateway that compresses AI tool prompts before they reach the model, reducing token usage by up to 79% without altering the model's input. It integrates seamlessly with existing AI tools like Claude Code, Cursor, and Aider, and supports local or cloud-based models.

## Key Features
- Reduces token usage by up to 79% through structured compression of logs, JSON, and code
- Seamless integration with existing AI tools via environment variables or MCP
- Local-first architecture with no telemetry, ensuring data privacy
- Supports both cloud-based and local models (e.g., Ollama)
- Provides real-time token savings tracking and detailed statistics

## Why It Matters for RAG Builders
Sensei directly reduces the cost and latency of AI-powered coding tools by compressing prompts without sacrificing model performance, making it essential for RAG builders optimizing for efficiency and budget.
