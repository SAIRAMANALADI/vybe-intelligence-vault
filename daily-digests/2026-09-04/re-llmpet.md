## Summary
RE-LLMPET (Octopus) is a lightweight multi-agent desktop pet built with Tauri 2 and Rust, designed to monitor and interact with coding agents like Claude Code, CodeWhale, Codex, OpenCode, and Aider. It provides real-time status updates, token usage tracking, and permission management while maintaining a low-resource footprint.

## Key Features
- Multi-agent support for 5 coding agents (Claude Code, CodeWhale, Codex, OpenCode, Aider) with real-time status tracking
- Low-resource desktop pet with Tauri 2 and Rust backend for native performance
- Token usage and cost tracking with session-based metrics and JSONL ledger
- Cross-platform compatibility (Windows, macOS, Linux) with platform-specific terminal and window management
- Permission flow management for structured agent interactions and security compliance

## Why It Matters for RAG Builders
It provides a lightweight, cross-platform UI for monitoring and interacting with multiple coding agents, enabling developers to track token usage and agent status without heavy resource overhead.
