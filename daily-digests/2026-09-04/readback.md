## Summary
Readback is a Windows-first tool that enables voice output for Claude Code, reading AI replies aloud via built-in PowerShell audio or third-party TTS providers like Inworld and ElevenLabs. It integrates seamlessly with Claude Code through an MCP server and hooks system.

## Key Features
- Windows-native voice output with zero external dependencies
- Dual TTS provider support (Inworld and ElevenLabs) with GUI switching
- Streaming audio playback with sentence-level splitting for fast response
- Multi-session queueing to handle multiple Claude projects sequentially
- On-demand control panel for real-time voice, speed, and expression tuning

## Why It Matters for RAG Builders
It enhances AI workflows by providing hands-free, auditory feedback for long-running tasks, improving accessibility and multitasking efficiency for developers using Claude Code.
