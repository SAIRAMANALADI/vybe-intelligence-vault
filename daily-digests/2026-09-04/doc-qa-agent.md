## Summary
doc-qa-agent is a lightweight chatbot designed to answer questions from PDF, DOCX, or text files using Sentence-Transformer embeddings for context retrieval and LLM models like OpenAI or Ollama for answer generation. It provides a user-friendly Gradio interface for seamless document-based Q&A interactions.

## Key Features
- Supports multiple document formats (PDF, DOCX, text)
- Uses Sentence-Transformers for contextual embedding retrieval
- Integrates with OpenAI and Ollama for answer generation
- Provides a Gradio-based conversational UI
- Lightweight and easy to deploy

## Why It Matters for RAG Builders
It simplifies building document-based Q&A systems by combining embeddings, LLMs, and a user-friendly interface for rapid RAG pipeline development.
