## Summary
Gondola is a dual-frontend AI companion and self-editing terminal coding harness powered by Venice AI and Pi Agent Core. It combines voice, vision, and coding capabilities with local memory, automations, and MCP integrations for a seamless AI-driven workflow.

## Key Features
- Dual frontend (web companion and terminal harness) with shared agent core
- Voice and vision capabilities with real-time streaming responses
- Semantic search for past conversations with hybrid re-ranking
- Self-editing terminal harness for autonomous code editing and execution
- Local memory, automations, and MCP integrations for extensibility

## Why It Matters for RAG Builders
Gondola provides a unified, local-first agent framework with advanced multimodal and coding capabilities, making it essential for building AI systems that require autonomous interaction and self-improvement.
