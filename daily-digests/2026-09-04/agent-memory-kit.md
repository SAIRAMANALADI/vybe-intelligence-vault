## Summary
Agent Memory Kit enables agents to propose memory entries that are written to plain text files in the user's folder only after explicit approval, ensuring dated, auditable, and client-specific memory management without external databases or vendor silos.

## Key Features
- Agent proposes memory entries with explicit user approval before writing to plain text files
- Dated memory entries with built-in staleness detection and pruning
- Client-specific memory management via `projects/<client>/` directories
- Cross-agent compatibility (Claude Code, Cursor, Codex, Copilot, OpenCode)
- Orchestration and QA layers for multi-agent workflows (opt-in)

## Why It Matters for RAG Builders
It provides a human-controlled, transparent, and auditable memory system for agents that integrates seamlessly into existing workflows without requiring external databases or vendor lock-in.
