## Summary
Nook is a full-stack microservice platform combining instant messaging (1:1/group chats, real-time push, online status, file/image messages) with a private AI assistant per user. It integrates Spring Boot 3.5 microservices, Vue 3 frontend, and features shared long-term memory for AI agents, Stripe subscriptions, and end-to-end production validation.

## Key Features
- Full-stack microservice architecture with Spring Boot 3.5 and Vue 3 SPA
- Real-time IM with 1:1/group chats, WebSocket push, online status, and file/image messaging
- Private AI agent per user with shared long-term memory (agentscope-harness + DeepSeek)
- Stripe-based subscription and payment system with webhook integration
- End-to-end production validation with 161 passing unit tests
