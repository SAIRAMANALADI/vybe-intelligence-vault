## Summary
A Model Context Protocol (MCP) server that enables real-time interaction and management of Jupyter Notebooks for AI agents. It provides tools for notebook operations, cell execution, and multimodal output handling, integrating seamlessly with MCP-compatible clients like Claude Desktop or Cursor.

## Key Features
- Real-time control and monitoring of Jupyter Notebooks via MCP-compatible clients
- Smart cell execution with automatic adjustments for failed runs and multimodal output support
- Context-aware interactions leveraging entire notebook state for AI agents
- Multi-notebook and multi-kernel management with dynamic server connections
- Built-in observability with OpenTelemetry integration for tracing tool calls and kernel executions

## Why It Matters for RAG Builders
This server bridges the gap between AI agents and Jupyter Notebooks, enabling dynamic, real-time execution and management of notebooks for RAG pipelines and agentic workflows.
