## Summary
EDT-MCP is an MCP (Model Context Protocol) server plugin for 1C:EDT that enables AI assistants like Claude, GitHub Copilot, and Cursor to interact with 1C:Enterprise Development Tools (EDT) workspaces. It provides deep integration for code analysis, metadata management, and form inspection within 1C:EDT environments.

## Key Features
- MCP Protocol 2025-11-25 support with streamable HTTP transport and SSE
- Comprehensive 1C:EDT workspace interaction including project validation, error reporting, and metadata refactoring
- Form inspection with PNG screenshots and YAML layout snapshots via native renderer
- Real-time server status bar with interactive controls for AI agent communication
- Tool management system with 67 tools organized into 9 semantic groups for AI assistant control

## Why It Matters for RAG Builders
It bridges 1C:EDT with AI assistants, enabling advanced code analysis and metadata manipulation for 1C:Enterprise development workflows.
