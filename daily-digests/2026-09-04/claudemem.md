## Summary
claudemem provides persistent, searchable memory for AI coding agents, storing notes and session reports as Markdown files with YAML frontmatter. It supports hybrid search (FTS5 keyword + semantic vectors) and cross-machine synchronization via Git, all in a zero-network Go binary.

## Key Features
- Persistent memory storage for AI agents with Markdown-based notes and sessions
- Hybrid search combining FTS5 keyword and semantic vector search
- Zero-network by default with opt-in cloud embedding backends
- Cross-machine synchronization via Git for portable memory
- Human-readable, git-friendly storage with YAML frontmatter

## Why It Matters for RAG Builders
It enables AI coding agents to retain and retrieve context across sessions, improving continuity and reducing redundant explanations in RAG pipelines.
