## Summary
HalalOne is a conversational AI platform that verifies the halal status of products by combining a certified database search with agent-based reasoning, web fallback, and natural-language explanations. It uses a LangGraph agent to dynamically classify intent, search products, and provide grounded answers with citations.

## Key Features
- Agent-based product reasoning with LangGraph state machine for dynamic intent classification, search, and response generation
- Hybrid search pipeline combining keyword, semantic, and web search with fallback mechanisms and grounded citations
- Multi-modal input support including image-based label/ingredient extraction via vision models
- Real-time streaming UI updates with resilient reconnection handling for WebSocket-based chat
- Conversation compaction and typo/filter normalization to improve search accuracy and user experience

## Why It Matters for RAG Builders
HalalOne demonstrates a robust agentic framework for dynamic, multi-tool reasoning in product verification, offering a blueprint for building explainable, grounded AI systems that combine database searches with web fallbacks and user-friendly explanations.
