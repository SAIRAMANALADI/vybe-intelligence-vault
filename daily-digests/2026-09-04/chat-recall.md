## Summary
Chat-Recall unifies AI coding tool transcripts (Claude Code, Gemini CLI, Codex, OpenCode, Cursor, etc.) into a single searchable memory index, enabling agents to recall past work across tools and sessions via 61 MCP tools. It supports self-hosting with Postgres and offers features like secret redaction, temporal knowledge graphs, and cross-tool session recall.

## Key Features
- Unified memory index across multiple AI coding tools (Claude Code, Gemini CLI, Codex, etc.)
- 61 MCP tools for agents to recall past sessions, decisions, and edits without manual explanation
- Secret redaction and security scanning with live/dead credential checks
- Temporal knowledge graph for tracking decisions and tool mentions with validity windows
- Self-hosting support with Docker and Postgres, including optional hosted service

## Why It Matters for RAG Builders
It eliminates the need for manual re-explanation by enabling AI agents to autonomously recall and leverage past work across tools and sessions, significantly improving efficiency and context continuity in RAG pipelines.
