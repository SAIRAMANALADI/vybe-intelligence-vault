## Summary
Kivgraph is a local MCP server that builds a semantic code graph across multiple repositories to provide AI coding agents with cross-repository code intelligence. It answers questions about symbols, dependencies, callers, and change impact using canonical semantic analysis tools like `go/types`, TypeScript checker, and `rust-analyzer`.

## Key Features
- Builds a canonical semantic code graph across multiple repositories using static analysis tools
- Provides eleven read-only tools for querying symbols, dependencies, callers, and change impact
- Supports Go, TypeScript, Rust, Python, and Dart with precise semantic analysis
- Offers a 3D viewer (`kivgraph ui`) for visualizing the published graph
- Includes benchmarked performance improvements over traditional search tools like `grep`

## Why It Matters for RAG Builders
Kivgraph enables AI coding agents to perform deep, semantic cross-repository code analysis, improving accuracy and reducing token costs for RAG systems by providing precise, context-aware answers about code relationships and dependencies.
