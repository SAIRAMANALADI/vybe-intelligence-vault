## Summary
Gearsystem is a highly accurate cross-platform emulator for Sega Master System, Game Gear, and SG-1000 systems, written in C++. It includes an embedded Model Context Protocol (MCP) server for AI-assisted debugging and tooling, enabling integration with AI agents like GitHub Copilot and Claude.

## Key Features
- Accurate Z80, VDP, PSG, and FM sound chip emulation for Sega Master System/Game Gear/SG-1000
- Embedded MCP server for AI-assisted debugging with tools for memory inspection, breakpoints, and hardware status
- Cross-platform support (Windows, macOS, Linux, BSD, RetroArch) with portable mode and modern controller support
- Advanced debugging features including disassembler, trace logger, VRAM viewer, and save state management
- Agent Skills integration for AI assistants to perform debugging, reverse engineering, and ROM hacking tasks
