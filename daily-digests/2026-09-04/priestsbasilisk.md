## Summary
Priest's Basilisk is an autonomous penetration-testing agent that transforms an LLM into a fully functional offensive security tool. It runs locally on Linux, executes real exploits, and verifies each attack autonomously without external dependencies.

## Key Features
- Fully autonomous penetration testing with no per-command approval in 'Unleash' mode
- Proves every exploit with deterministic payloads and verification markers (e.g., database dumps, tokens)
- Hard safety floor with irreversible commands (e.g., disk wipes) blocked in two independent places
- Tamper-evident evidence ledger for all executed commands and results
- Supports black-box testing with no target source required, achieving 87/113 on OWASP Juice Shop

## Why It Matters for RAG Builders
It demonstrates how LLMs can autonomously execute and verify complex security exploits, proving the feasibility of AI-driven offensive security tools while maintaining local execution and safety controls.
