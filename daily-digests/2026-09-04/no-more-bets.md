## Summary
An autonomous AI agent that researches football matches, places bets using its own bankroll, and reflects on outcomes with full transparency. It integrates match intelligence, structured research, and a daily pipeline for data preparation, betting, and reflection.

## Key Features
- Autonomous daily pipeline for match research, betting, and reflection with full transparency
- Structured match briefs and paper research slips for consistency checks
- Semantic search using PostgreSQL with pgvector for hybrid retrieval of match data
- Exposure of football data via Model Context Protocol (MCP) for AI clients
- Public session logs and reasoning for every decision and tool call

## Why It Matters for RAG Builders
It demonstrates a transparent, autonomous AI agent framework that integrates research, decision-making, and reflection, which is valuable for building trustworthy and explainable AI systems in decision-critical domains.
