## Summary
AC0 AI plugins provide pre-configured MCP servers and skills for coding agents to interact with external services like Sauna Guide and GospelChannel. These plugins bundle remote Streamable HTTP servers with agent skills to enable specialized functionality without requiring authentication.

## Key Features
- Pre-configured MCP servers for Sauna Guide and GospelChannel
- Skills bundled with each plugin for agent guidance
- No authentication required for hosted services
- Supports multiple agent frameworks (Claude Code, Codex, Cline)
- Published in the official MCP Registry

## Why It Matters for RAG Builders
It simplifies integration of specialized services into coding agents via standardized MCP plugins, reducing setup overhead for developers.
