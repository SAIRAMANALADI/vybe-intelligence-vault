## Summary
Fraise is an in-memory memory database designed for AI agents, enabling them to store and retrieve knowledge using a simple query language (FQL). It supports hybrid retrieval (full-text, graph, and optional vector search) with temporal ranking and sub-millisecond recall.

## Key Features
- Simple FQL query language with only two verbs: `remember` and `recall`
- Hybrid retrieval combining full-text, graph, and vector search in a single query
- Temporal ranking prioritizes recent memories by default
- Sub-millisecond recall and low-millisecond write performance
- No infrastructure required—runs as a single binary with optional Docker deployment

## Why It Matters for RAG Builders
Fraise provides a lightweight, agent-friendly memory system that simplifies knowledge storage and retrieval for RAG pipelines, reducing infrastructure overhead while enabling fast, hybrid search capabilities.
