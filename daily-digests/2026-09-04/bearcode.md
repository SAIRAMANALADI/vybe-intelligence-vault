## Summary
BearCode is an open-source, self-hosted desktop agent manager for macOS that enables users to run AI agents (Claude, GPT, Gemini, OpenRouter, or local Ollama) against project folders with full inspectability and control. It provides a file-based `.agents/` spine for rules, skills, workflows, and hooks, with sandboxed tool execution and a reviewable diff workflow.

## Key Features
- File-based `.agents/` spine for rules, skills, workflows, and hooks with full inspectability
- Multi-provider model support (Anthropic, OpenAI, Google, OpenRouter, Ollama) with live diffs and cost tracking
- Per-project macOS Seatbelt sandboxing for secure tool execution and environment isolation
- Git worktree mode for isolating risky agent changes with built-in merge and conflict resolution
- Plugin system with git-marketplace bundles for extensibility and MCP connector management

## Why It Matters for RAG Builders
BearCode provides a fully inspectable, self-hosted alternative to closed agent managers like Google Antigravity, enabling AI engineers to control the runtime, runtime logic, and security model while integrating with their own infrastructure.
