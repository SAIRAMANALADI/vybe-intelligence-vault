## Summary
A command-line tool and Python library for interacting with Apple iCloud Keychain (Passwords) directly from the terminal, enabling secure password and one-time code management, scripting, and AI agent integrations.

## Key Features
- Securely read, save, and update Apple iCloud Keychain passwords and one-time codes from the terminal
- Agent-ready with bundled Claude skill and MCP server for AI integrations
- Zero-setup pairing with automatic background daemon management
- Scriptable output formats (JSON, TSV, table) with clipboard integration and auto-clearing
- Zero-knowledge security model: no servers, telemetry, or plaintext logging

## Why It Matters for RAG Builders
It provides secure, agent-ready access to Apple iCloud Keychain passwords and OTPs, enabling AI systems to interact with sensitive credentials without exposing plaintext secrets.
