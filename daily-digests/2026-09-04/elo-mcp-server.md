## Summary
A Model Context Protocol (MCP) server that provides read-only access to the ELO Digital Office document management system, exposing tools for search, metadata retrieval, document content extraction, and project-folder lookups for LLM agents and AI systems.

## Key Features
- Read-only access to ELO Digital Office via MCP tools
- Search across documents and folders with scoped or archive-wide queries
- Document content extraction (PDF, Word, email formats)
- Project-folder resolution and metadata retrieval
- Supports both stdio and HTTP transport for MCP clients

## Why It Matters for RAG Builders
It enables LLM agents and AI systems to securely and efficiently query enterprise document management systems like ELO Digital Office, enhancing RAG pipelines with structured access to archival data.
