## Summary
hubd is a project tracker designed for teams of humans and AI agents, using plain files (markdown and JSONL) as a shared workspace. It acts as a coordination layer for managing tasks, queues, and project states without requiring AI capabilities itself.

## Key Features
- Shared workspace using plain markdown and JSONL files for human and AI agent collaboration
- Task queues and kanban boards managed via file-based state (no AI processing)
- MCP server (hubd) and CLI (hub) for seamless integration with agents and humans
- Structured journaling and reporting with append-only logs for auditability
- Multi-tenant support via HTTP MCP and token-gated access

## Why It Matters for RAG Builders
hubd provides a lightweight, file-based coordination layer that enables seamless collaboration between humans and AI agents without adding AI overhead, making it ideal for RAG builders who need structured task and state management.
