## Summary
CodeFRAME is a project delivery system that orchestrates AI coding agents to handle the entire software development lifecycle, from requirements gathering to deployment. It focuses on the 'edges' of the pipeline—thinking, proving, and shipping—while delegating actual code writing to specialized agents like Claude Code or Codex.

## Key Features
- AI-guided Socratic requirements discovery and recursive decomposition for task generation
- Agent-agnostic execution with support for multiple coding agents (Claude Code, Codex, etc.)
- PROOF9: a 9-gate evidence-based quality system that enforces permanent requirements and compounds over time
- Closed-loop system where production glitches become new proof obligations enforced in future builds
- Radical simplicity with a single CLI binary, SQLite backend, and no daemons or infrastructure

## Why It Matters for RAG Builders
It provides a complete, agent-agnostic pipeline for turning ideas into verified, deployed code, ensuring quality and reducing manual oversight in AI-driven software development.
