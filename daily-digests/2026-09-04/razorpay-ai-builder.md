## Summary
MediaOS is an autonomous AI agent designed for Indian merchant growth, automating buyer research, campaign deployment, and payment collection via Razorpay. It enforces strict policy-gated audits for every financial transaction, ensuring explainability, bounded spending, and graceful failure handling.

## Key Features
- Automated buyer research using 6 Bright Data providers for competitor and intent analysis
- Deterministic policy engine enforcing INR spending caps, rate limits, and AP2-style mandates for every financial action
- Razorpay Test Mode integration for secure, audited payment collection with HMAC-verified webhooks
- Agent-readable product catalog with dynamic checkout session creation and upsell/cross-sell capabilities
- Comprehensive append-only audit trail tracking every money action with reasons, evidence, and outcomes

## Why It Matters for RAG Builders
It provides a production-grade blueprint for building policy-gated, auditable autonomous agents that handle financial transactions, critical for RAG/AI stacks requiring strict compliance and explainability.
