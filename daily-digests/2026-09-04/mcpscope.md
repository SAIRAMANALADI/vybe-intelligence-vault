## Summary
mcpscope is a local-first workbench designed to develop, inspect, and benchmark MCP servers against local or remote LLM providers like LM Studio, Ollama, or OpenRouter. It provides a shared workspace with a Web UI for humans and a CLI/MCP interface for coding agents, enabling collaborative iteration on MCP server design and evaluation.

## Key Features
- Unified workspace for humans and agents with Web UI, CLI, and MCP interface
- Embeddable TypeScript engine (`mcpscope-engine`) for building MCP-powered apps
- Detailed session inspection with per-token attribution and reasoning traces
- Statistical benchmarking of MCP servers across models with pass@k metrics
- Zero-setup companion MCP servers and local LLM provider support (LM Studio, Ollama, OpenRouter)

## Why It Matters for RAG Builders
mcpscope enables iterative, collaborative development and benchmarking of MCP servers, bridging the gap between human oversight and agent-driven automation for building high-quality, efficient LLM tools.
