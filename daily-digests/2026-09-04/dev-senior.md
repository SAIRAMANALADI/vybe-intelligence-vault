## Summary
A dual-agent AI system deployed internally to enhance productivity for technical teams and business managers. It includes a Dev Senior agent for coding, debugging, and architecture tasks, and a Business Manager agent for marketing, SEO, and CRM operations, all integrated with vector memory, observability, and automation tools.

## Key Features
- Dual-agent architecture with specialized capabilities (Dev Senior for technical tasks, Business Manager for business operations)
- Shared vector memory (Qdrant) for cross-agent context retention and collaboration
- Real-time streaming responses via SSE for frontend and integrations
- Automated quality evaluation and drift detection using LLM-as-judge
- Seamless integrations with Slack, Teams, n8n, and MCP for workflow automation
