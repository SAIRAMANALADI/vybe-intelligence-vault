## Summary
AgentHydra is a local dashboard that consolidates AI coding sessions (Claude Code, Codex, OpenCode) into a single browser tab, enabling unified management of isolated instances, session history, and task queues without replacing existing AI clients.

## Key Features
- Unified dashboard for Claude Code, Codex, and OpenCode sessions with real-time tailing and filtering
- Queue-based task scheduling with rate-limit-aware resuming and isolated instance management
- Support for multiple isolated AI instances (Claude Desktop, Codex Desktop/CLI) with dedicated profiles
- MCP-native API for agent-driven control of sessions, queues, and instance managers
- Local-first architecture with no cloud dependency, telemetry, or external data sharing

## Why It Matters for RAG Builders
AgentHydra simplifies the orchestration of multiple AI coding sessions and providers into a single interface, making it essential for RAG builders who need unified session visibility and task scheduling without cloud dependencies.
