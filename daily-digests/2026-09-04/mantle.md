## Summary
Mantle is an agent-native headless CMS designed for AI agents to author content via structured YAML manifests, with a runtime that handles schema validation, authentication, rendering, and MCP integration. It enables non-coders to leverage AI for content-driven web services while abstracting complex backend operations.

## Key Features
- Agent-authored content via YAML manifests with locked-grammar validation
- Runtime handles schema validation, authentication, rendering, and MCP endpoints
- Modular plugin system for extending functionality (e.g., marketplace capabilities)
- Supports multi-provider authentication (GitHub, Google, Apple, email-OTP)
- Static `.md` mirrors for agent-friendly content crawling without auth

## Why It Matters for RAG Builders
Mantle enables AI agents to safely and efficiently author content-driven web services by abstracting complex backend operations, making it essential for RAG builders who need structured, agent-friendly content pipelines.
