## Summary
A comprehensive multi-provider AI starter kit designed to streamline AI-assisted development across providers like Claude, Codex, Grok, Kimi, and Hermes. It bundles skills, MCP servers, plugins, and offline tools, with optional deep integration for Skyrim SE/AE modding stacks.

## Key Features
- Pre-configured skills for 5 major AI providers (Claude, Codex, Grok, Kimi, Hermes)
- Includes MCP servers for code graph memory, context compression (Headroom), and browser/scraping tools
- Optional Skyrim SE/AE modding stack integration (houseCARL, Spooky, Forge)
- Automated installer with offline and online update options
- High-signal AI preamble for truth-seeking and corrective agent behavior

## Why It Matters for RAG Builders
It provides a turnkey foundation for AI engineers to rapidly deploy multi-provider AI systems with pre-configured tools, reducing setup time and ensuring consistency across workflows.
