## Summary
MSP (Model Shell Protocol) defines an application-owned operating environment for AI agents, providing a runtime that transforms app data, permissions, and capabilities into shell-like commands, files, and streams. It enables agents to operate within a controlled, composable workspace rather than raw system shells or isolated tool calls.

## Key Features
- Defines a shell-like runtime for AI agents within applications, replacing raw system shell access with app-controlled commands and workspaces.
- Enables composable workflows through pipes, redirection, and command substitution, leveraging decades of shell scripting conventions.
- Implements policy-based permission control and audit trails for secure, traceable agent operations.
- Provides platform adapters for iOS, macOS, Android, Windows, and web, ensuring cross-platform compatibility.
- Validated in production environments like ReadOS and Readex, demonstrating real-world applicability for agent-native applications.

## Why It Matters for RAG Builders
MSP provides the foundational runtime for AI agents to operate within secure, composable, and auditable application environments, bridging the gap between raw tool calls and full OS access.
