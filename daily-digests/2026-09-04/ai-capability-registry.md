## Summary
A curated registry of AI capabilities including skills, MCP servers, workflows, and role prompts designed to enable secure and scalable multi-agent development. It organizes capabilities from trusted upstream sources for runtime routing and static agent configuration.

## Key Features
- Centralized registry of 9 trusted skill providers and 169 MCP servers for secure multi-agent setups
- Dynamic runtime routing and static agent configuration generation for CLI tools like Codex, Claude Code, and Kilo
- Versioned infrastructure for capabilities with explicit Git tracking of enabled features
- Token-efficient agent prompts with staged execution and quality gates to reduce context usage
- Supports workflow-first agent setups with role-mediated skills and MCP routing

## Why It Matters for RAG Builders
It provides a scalable, versioned foundation for organizing and deploying AI capabilities across multi-agent systems, reducing duplication and improving security.
