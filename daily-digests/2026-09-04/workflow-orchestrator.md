## Summary
A natural language pipeline orchestrator for Claude Code that enables seamless workflow automation through intent detection and structured stage routing. It facilitates multi-role review, plan rework, and cross-domain ideation mapping, with a focus on human-in-the-loop decision points and graceful degradation.

## Key Features
- Natural language intent detection and pipeline routing without slash commands
- Structured stage handoff contracts for enforced workflow discipline
- Four-role parallel plan review (User Advocate, Architect, Risk Hunter, Pragmatist)
- Plan rework and lightweight re-review for iterative refinement
- Graceful fallback to manual mode when downstream skills are missing
