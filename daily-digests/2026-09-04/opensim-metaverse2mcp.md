## Summary
A LibreMetaverse-based OpenSim bot that exposes avatar actions as MCP tools over Streamable HTTP, enabling AI agents to interact with OpenSimulator and Second Life grids programmatically via a standardized Model Context Protocol interface.

## Key Features
- Exposes OpenSim avatar actions (movement, inventory, prims, scripts) as MCP tools for AI invocation
- Streamable HTTP transport for MCP with configurable endpoints and authentication
- Integrates with Opencode for IM conversation routing and session management
- Supports environment variable and CLI configuration with override precedence
- Provides policy-driven inventory offer management with persistence and auto-save

## Why It Matters for RAG Builders
It enables AI agents to programmatically control and interact with OpenSimulator and Second Life virtual worlds through a standardized MCP interface, expanding AI capabilities in metaverse applications.
