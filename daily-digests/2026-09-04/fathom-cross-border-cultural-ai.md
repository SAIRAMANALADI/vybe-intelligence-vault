## Summary
Fathom is an AI-powered tool that generates scene-specific cultural playbooks for cross-border business interactions, leveraging 594 verified cultural rules and real-time web enrichment to provide tailored guidance, dialogue simulations, and risk assessments for 40+ countries.

## Key Features
- Scene-specific cultural playbook generation from user input
- AI-powered dialogue simulation with cultural scoring
- Integration of 594 verified cultural rules and structured databases
- Real-time web enrichment via Tavily API for industry context
- Multi-agent AI pipeline for parallel analysis and fallback
