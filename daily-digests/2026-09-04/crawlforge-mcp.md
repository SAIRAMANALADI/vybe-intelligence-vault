## Summary
CrawlForge MCP is an MCP-native server providing 29 tools for web scraping, crawling, deep research, and autonomous extraction. It enables AI assistants like Claude and Cursor to fetch, process, and structure web content with support for local LLMs (Ollama) and cloud-based models.

## Key Features
- 29 MCP-native tools for web scraping, crawling, and deep research
- Supports local LLM extraction via Ollama with no API costs
- Autonomous agent for natural-language-driven research without URLs
- Structured output (Markdown, JSON) and screenshot capture
- Security-hardened with SSRF protection, fail-closed backend, and credit gating

## Why It Matters for RAG Builders
It provides essential, MCP-integrated tools for AI assistants to autonomously fetch, process, and structure web data, reducing manual effort and enabling scalable RAG pipelines.
