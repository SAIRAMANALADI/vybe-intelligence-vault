## Summary
Py Agent is a lightweight Python orchestration framework that combines a C++ backend (llama-server) with Python tooling for efficient local and cloud-based LLM interactions. It supports multi-turn chat, codebase indexing, autonomous task execution, and integrates with IDEs, TUIs, and web interfaces for developer workflows.

## Key Features
- Zero-daemon lightweight execution with minimal resource usage
- Multi-modal support for local and cloud LLMs (GGUF, Qwen, DeepSeek, etc.)
- Stateful IPython kernel harness for in-memory Python actions and sub-agent delegation
- Advanced codebase graph indexing and relational memory with sqlite-vec vector RAG
- Cross-platform IDE (PyCode), TUI, and web interfaces for seamless developer workflows

## Why It Matters for RAG Builders
Py Agent provides a robust, modular framework for building and deploying AI agents with integrated tooling, memory systems, and multi-modal LLM support, making it essential for developers constructing advanced RAG and agentic workflows.
