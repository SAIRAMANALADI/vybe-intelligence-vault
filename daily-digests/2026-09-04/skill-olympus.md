## Summary
Skill Olympus is a persistent product team harness for coding agents that enables planning, building, inspecting, testing, documenting, and remembering across sessions without replacing native CLI workers. It integrates with multiple AI CLIs (Claude Code, Codex CLI, Antigravity CLI, Grok Build) to provide a unified workflow for software development tasks.

## Key Features
- Zero-interaction full pipeline (design → build → inspect → test → ship) via `/zeus` command
- Cross-CLI persistent memory and resumable handoffs using `mnemo`
- Automated testing and repair with `/minos` for Playwright scenarios
- Evidence-backed final reports ensuring code matches intent via `/argos`
- Source-only skill modules for extensibility without CLI dependency

## Why It Matters for RAG Builders
Skill Olympus provides a unified, persistent, and production-ready workflow for AI coding agents, eliminating manual handoffs and ensuring verifiable, repeatable software delivery across sessions.
