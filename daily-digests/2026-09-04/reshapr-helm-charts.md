## Summary
This repository provides Helm charts for deploying reShapr components on Kubernetes, enabling the transformation of REST/GraphQL/gRPC APIs into LLM-friendly tools via the Model Context Protocol (MCP). It includes separate charts for the control plane, proxy, UI, and Kubernetes controllers.

## Key Features
- Modular Helm charts for control plane, proxy, UI, and controllers
- Supports Kubernetes ≥ 1.25 and Helm ≥ 3.8
- Enables MCP server for converting APIs into LLM tools
- Includes cert-manager integration for TLS and admission webhooks
- Provides OCI artifact distribution for secure chart delivery

## Why It Matters for RAG Builders
It simplifies the deployment of MCP-compatible API orchestration tools in Kubernetes, critical for RAG builders integrating multiple data sources.
