## Summary
Mango Office MCP provides an MCP (Model Context Protocol) server for integrating Mango Office cloud telephony services with AI assistants. It enables AI-driven call management, user statistics, recordings, and SMS via a standardized API interface.

## Key Features
- 8 MCP tools for call history, user management, and SMS via Mango Office API
- Pre-built skills for daily call reports and statistics summaries
- HMAC-SHA256 authentication for secure API requests
- Supports multiple deployment methods (Claude, VS Code, HTTP)
- Part of the WWmcp ecosystem for AI assistant integrations

## Why It Matters for RAG Builders
It bridges AI assistants with cloud telephony, enabling automated call management and real-time insights for businesses using Mango Office.
