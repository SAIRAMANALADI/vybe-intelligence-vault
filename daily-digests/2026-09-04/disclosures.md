## Summary
A TypeScript library and Model Context Protocol (MCP) server providing free, open-source access to corporate disclosure data from global official sources like SEC EDGAR, GLEIF, UK Companies House, and others. It standardizes jurisdiction-agnostic tools for resolving companies, retrieving filings, financials, insider data, and ownership chains.

## Key Features
- Standardized jurisdiction-agnostic tools for corporate disclosure research (e.g., CompanyResolve, CompanyFilings, CompanyFinancials)
- Supports nine data sources across seven jurisdictions (US, UK, EU, KR, JP, CN, IN) with consistent tool schemas
- Provides TypeScript library and MCP server for seamless integration into AI workflows
- Honest handling of unsupported jurisdictions or missing data (explicit errors instead of empty results)
- Caching support for large reference archives (e.g., OpenDART, EDINET) to optimize performance

## Why It Matters for RAG Builders
It provides standardized, open-source access to critical corporate disclosure data essential for building accurate and comprehensive RAG systems focused on financial research, ownership, and compliance.
