## Summary
Oryven is an open-source, on-device AI desk agent that enables local AI interactions, computer control, and code execution via Ollama. It prioritizes privacy by keeping all operations local while offering optional cloud API integrations.

## Key Features
- Local AI interactions via Ollama with no account required
- Computer control capabilities including shell, files, apps, and git operations
- Privacy-first design with optional cloud API integrations
- Cross-platform support for macOS, Windows, and Linux
- Built-in safety gates for destructive actions and managed browser automation
