## Summary
mcp-irail provides real-time Belgian rail (SNCB/NMBS) data via the iRail API through the Pipeworx MCP gateway, enabling AI agents to query live train schedules, delays, and station information. It is part of a broader MCP gateway ecosystem connecting agents to over 1325 live data sources.

## Key Features
- Real-time Belgian rail data access via iRail API
- Integration with Pipeworx MCP gateway for 1325+ data sources
- Supports plain English queries via ask_pipeworx
- Compatible with MCP clients like Claude Desktop, Cursor, and Windsurf
- MIT licensed for open-source use
