## Summary
mema-twin is a personal work twin that extracts reusable work preferences (style, structure, wording) into dimension-tagged memories, compiles them into versioned persona prompts per work type, and injects these prompts into agents before they start a task to ensure outputs align with user preferences.

## Key Features
- Extracts and tags work preferences (style, structure, wording) into structured memories
- Compiles versioned persona prompts per work type (34 work types, 10 audiences, 9 purposes)
- Integrates with mema for preference storage and governance
- Supports task lifecycle management (start, review, resume, close)
- Provides audit trails for task execution and prompt versions

## Why It Matters for RAG Builders
It enables AI agents to dynamically adapt to user-specific work preferences, ensuring outputs are consistently aligned with individual style and requirements.
