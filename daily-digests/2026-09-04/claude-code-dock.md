## Summary
A Docker-based solution to run Anthropic's Claude Code persistently on a 24/7 server, enabling remote access and session persistence across devices without manual intervention. It leverages tmux for session management and Docker for containerized execution.

## Key Features
- Persistent 24/7 Claude Code sessions in Docker containers
- Remote control access from any device via Claude.ai
- Multi-project support with isolated sessions per project
- Security-focused design with no exposed ports or root access
- Cross-platform compatibility (Linux, Unraid, NAS, Raspberry Pi)

## Why It Matters for RAG Builders
It enables AI engineers to maintain persistent, remotely accessible Claude Code sessions on servers, eliminating the need for local terminal dependency and enhancing workflow flexibility.
