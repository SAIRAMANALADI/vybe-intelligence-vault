## Summary
Atelier is a headless pixel-art studio that enables AI agents to create, edit, and export layered, animated, game-ready art via MCP (Model Context Protocol). It provides agents with visual feedback loops, allowing them to 'see' their work and iteratively refine it.

## Key Features
- Headless pixel-art editor with layers, frames, and animations
- Agent-friendly visual feedback via `doc_look` tool for iterative refinement
- Game-ready output formats (spritesheets, GIFs, texture atlases, Tiled tilesets)
- Fully deterministic and offline-capable (no API keys or telemetry)
- Replayable art recipes (JSONL journals) for reproducibility

## Why It Matters for RAG Builders
Atelier bridges the gap between AI-generated art and game-ready assets by providing agents with visual feedback loops, enabling iterative refinement and deterministic, offline workflows essential for production environments.
