## Summary
A collection of practical Model Context Protocol (MCP) servers designed to integrate with AI clients like Claude and Cursor. These servers enable local-first automation for tasks such as time tracking, expense management, invoice generation, spreadsheet manipulation, and price monitoring, with optional hosted endpoints for remote access.

## Key Features
- Six specialized MCP servers for time tracking, expense management, invoicing, spreadsheet manipulation, price tracking, and an all-in-one office suite
- Local-first operation with optional hosted endpoints for remote access
- Free tier with Pro unlocks for advanced features via one-time payment
- Comprehensive validation including unit tests, adversarial reviews, and user testing
- Detailed documentation, demos, and guides for quick integration with AI clients
