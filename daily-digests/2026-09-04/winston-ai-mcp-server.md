## Summary
Winston AI MCP Server provides a Model Context Protocol (MCP) interface for Winston AI's AI detection, plagiarism detection, and text comparison services. It enables seamless integration of Winston AI's capabilities into MCP-compatible clients like IDEs and AI tools.

## Key Features
- AI text detection with confidence scoring and sentence-level analysis
- AI image detection with metadata and watermark verification
- Plagiarism detection via internet-wide scanning and source identification
- Text comparison with similarity scoring and bidirectional analysis
- MCP server integration for IDEs and AI tools

## Why It Matters for RAG Builders
It enables AI engineering teams to integrate advanced AI detection and plagiarism tools directly into their workflows via MCP, enhancing content verification and reliability in RAG pipelines.
