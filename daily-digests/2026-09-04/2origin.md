## Summary
Benxiang (本象) is an AI-native persistent object representation layer that preserves the origin structure of digital artifacts (objects, relations, states, constraints, and provenance) and compiles task-specific projections for AI models. It enables AI to interact with structured, verifiable world states rather than flattened projections like documents or screenshots.

## Key Features
- Preserves origin structure of digital artifacts with stable IDs, relations, payloads, states, constraints, and provenance
- Compiles task-specific projections for AI models on demand, avoiding context explosion
- Enables AI to write back semantic transactions validated by a deterministic compiler
- Supports domain-specific adapters (CAD, legal, memory) with minimal code changes (4 lines in adapters)
- Includes a language-neutral conformance test suite (68 vectors) and two independent implementations (JavaScript and Python)

## Why It Matters for RAG Builders
It provides a structured, verifiable foundation for AI systems to interact with persistent world states, solving critical issues like context explosion and lack of stable memory in current AI workflows.
