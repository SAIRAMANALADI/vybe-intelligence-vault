## Summary
CKS Studio is an interactive visual workspace for the Canonical Knowledge Structure (CKS) ecosystem, providing a React-based single-page application to explore knowledge graphs, inspect inference chains, review CRDT forks, monitor agent pipelines, and chat with an LLM via MCP-connected backends.

## Key Features
- Interactive graph exploration with zoom, pan, and drill-down capabilities
- Inference chain inspector for tracing dependencies and reasoning paths
- CRDT fork diff viewer for comparing conflicting object versions
- Built-in AI chat panel with tool-calling capabilities for graph manipulation
- Real-time agent observability and control panel for managing background processes

## Why It Matters for RAG Builders
CKS Studio provides a human-centric interface to visualize, manage, and interact with knowledge graphs and agent pipelines, bridging the gap between LLM tooling and human oversight in RAG systems.
