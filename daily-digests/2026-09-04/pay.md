## Summary
@agent-score/pay is a universal CLI tool enabling AI agents and shell-based LLM tools to make payments across multiple blockchain rails (x402, MPP) with a single command. It preserves request bodies end-to-end while keeping private keys secure, supporting Base, Tempo, and Solana networks.

## Key Features
- Single CLI command for payments across Base (x402), Tempo, and Solana (MPP) rails
- End-to-end request body preservation with private key security (no key exposure)
- Structured output formats (JSON, YAML, TOON, Markdown) for agent/LLM consumption
- Idempotency support via X-Idempotency-Key headers for retry safety
- MCP server mode for seamless integration with LLM agents like Claude Code and Cursor

## Why It Matters for RAG Builders
It bridges the critical gap for AI agents needing to execute payments autonomously across blockchain rails while maintaining security and structured data handling, essential for real-world RAG and agentic workflows.
