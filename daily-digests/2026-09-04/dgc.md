## Summary
DGC is an interactive terminal-based coding agent CLI that connects to any local or cloud-based LLM endpoint (e.g., Ollama, OpenAI, Groq) and enables autonomous or semi-autonomous coding tasks with advanced permission controls, multi-agent fleets, and session persistence.

## Key Features
- Multi-agent fleet management with isolated worktrees and concurrent task execution
- Advanced permission modes (default, acceptEdits, plan, auto) with fine-grained rules
- Session persistence, rewind, and durable checkpoints for exact state restoration
- Built-in skills (16+) and adaptive tool catalog for dynamic workflows
- Plan mode for read-only research and goal-based task automation

## Why It Matters for RAG Builders
DGC provides a flexible, local-first agent framework for RAG builders to integrate autonomous or semi-autonomous coding agents with customizable permission controls and multi-agent orchestration.
