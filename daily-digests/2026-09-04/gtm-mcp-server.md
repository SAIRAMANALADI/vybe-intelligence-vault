## Summary
The GTM MCP Server is an AI-native interface for Google Tag Manager (GTM) that enables natural language management of GTM containers, tags, triggers, and configurations through the Model Context Protocol (MCP). It allows AI assistants like Claude, ChatGPT, and Gemini to interact with GTM via OAuth 2.1 or service accounts.

## Key Features
- Natural language interaction with GTM containers via AI assistants (Claude, ChatGPT, Gemini, etc.)
- Full support for tag, trigger, and container operations including creation, auditing, and publishing
- Server-side GTM container management with client and transformation support
- Community template gallery integration for importing pre-built GTM templates
- Self-hosting capabilities with service account mode and Docker support

## Why It Matters for RAG Builders
It enables AI-driven automation and natural language control over Google Tag Manager, reducing manual configuration efforts and accelerating tracking implementation for AI and RAG stack builders.
