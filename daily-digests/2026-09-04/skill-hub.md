## Summary
Skill-hub is a Chinese-language agent skill library designed for AI programming tools like Codex, Claude Code, and Antigravity. It provides reusable SKILL.md templates, AI workflows, and prompt templates organized into 70+ skills across domains such as agent engineering, data retrieval, media content, and business industries.

## Key Features
- 70+ reusable AI agent skills categorized by domain (e.g., agent engineering, data retrieval, media content)
- Structured SKILL.md templates with frontmatter for AI tool compatibility
- Machine-readable and human-friendly indexing (by-name, by-domain, skills-lock.json)
- Privacy-aware design with placeholder tokens for sensitive data
- Sync scripts for local and repository-based skill management
