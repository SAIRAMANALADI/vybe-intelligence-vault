## Summary
A verification discipline for AI agents that introduces a protocol to prevent false completion claims by requiring explicit evidence before marking tasks as done. It provides a claim taxonomy, ten failure modes, and a methodology to catch unverified outputs in agentic workflows.

## Key Features
- Protocol to enforce verification before task completion claims
- Taxonomy of claim types mapped to verification commands and traps
- Ten documented failure modes with real-world examples and mitigations
- Works with any agent framework without requiring hooks or API keys
- Plain Markdown-based methodology for easy adoption

## Why It Matters for RAG Builders
It provides a critical discipline to prevent false completion claims in AI agents, reducing wasted time and errors in agentic workflows by enforcing verification before marking tasks as done.
