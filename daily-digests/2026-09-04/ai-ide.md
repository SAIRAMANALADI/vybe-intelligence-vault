## Summary
Lumen is a modern, minimalist AI-powered IDE built on Cloudflare Workers, integrating Workers AI for real-time code assistance, GitHub OAuth for repository access, and a VS Code-like Monaco editor for a seamless development experience.

## Key Features
- Real-time AI-powered code assistance via Workers AI with streaming support
- VS Code-like Monaco editor with multi-tab support and dirty indicators
- Seamless GitHub integration via OAuth or PAT for repository access and commits
- Custom UI with dark/light themes, collapsible panels, and mobile-friendly design
- Serverless deployment on Cloudflare Workers with minimal setup complexity

## Why It Matters for RAG Builders
