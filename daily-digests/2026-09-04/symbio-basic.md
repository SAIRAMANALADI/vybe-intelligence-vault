## Summary
Symbio Basic is a desktop AI companion application that integrates with AI providers or Hermes to create a 3D VRM avatar living on your desktop. It enables voice conversations, screen vision, persistent memory, and autonomous agent behavior with tool integration, fostering a symbiotic partnership between human and AI.

## Key Features
- 3D VRM avatar with lip sync, emotions, and 35+ animations
- Screen vision and auto-screenshot capabilities for contextual awareness
- Persistent memory using PostgreSQL, Neo4j, and SQLite
- Autonomous agent mode via Hermes with tool integration (terminal, web search, file access)
- Voice conversations with OpenAI or Google Gemini TTS (42 voices total)

## Why It Matters for RAG Builders
Symbio Basic bridges the gap between AI agents and human interaction by providing a tangible, persistent desktop presence with memory and autonomy, enabling deeper, more natural partnerships for RAG and AI stack builders.
