## Summary
protoAgent is a lean, A2A-native agent framework built on LangGraph, designed for extensibility via git-URL plugins. It provides a modular core for running single agents or orchestrating fleets, with built-in support for A2A, OpenAI-compatible APIs, and local-first deployment.

## Key Features
- A2A-compliant JSON-RPC server with SSE streaming and lifecycle management
- Extensible plugin system for adding tools, skills, and subagents via git URLs
- Built-in knowledge store with optional hybrid embeddings and RRF fusion
- Unified delegate registry for routing tasks to other agents or endpoints (A2A/OpenAI/ACP)
- Comprehensive observability with Langfuse tracing, Prometheus metrics, and audit logging

## Why It Matters for RAG Builders
protoAgent simplifies building and scaling A2A-native agents with a modular, plugin-driven architecture, reducing boilerplate and enabling rapid customization for RAG and AI workflows.
