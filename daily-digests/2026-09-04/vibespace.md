## Summary
VibeSpace is a backend-agnostic web workspace for managing multiple concurrent coding agent CLI sessions (e.g., Claude Code, Codex) from a browser. It provides a tiling window manager, structured chat view, file explorer, and code editor with persistence, multi-session support, and remote host integration.

## Key Features
- Backend-agnostic adapter system supporting Claude Code, Codex, and custom backends
- Dual-mode sessions (Terminal TUI and structured Chat View) with persistence via dtach
- Tiling window manager with virtual desktops, tab groups, and multi-client layout sync
- File explorer, code editor, and embedded browser with cross-host file access
- Session management, goals, interactive permissions, and real-time collaboration features

## Why It Matters for RAG Builders
VibeSpace streamlines the management of multiple coding agent sessions in a unified, persistent workspace, making it essential for developers and teams building AI-driven workflows.
