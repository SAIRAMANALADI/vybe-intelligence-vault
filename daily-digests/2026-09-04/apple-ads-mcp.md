## Summary
Apple Ads MCP is a local-first Model Context Protocol (MCP) server that provides typed tools for interacting with the Apple Ads Platform API v1. It enables secure, read-only or gated write operations for managing App Store advertising accounts, campaigns, keywords, and creatives directly from MCP clients like Codex or Claude.

## Key Features
- Typed tools for Apple Ads Platform API v1 integration via MCP
- Read-only by default with explicit write gates (receipt-based)
- Supports campaign, ad group, keyword, and creative operations
- Local credential storage and privacy-preserving design
- Cross-platform support (macOS, Linux, Windows) with multiple installation methods

## Why It Matters for RAG Builders
It provides secure, typed access to Apple Ads data for AI agents, enabling safe campaign audits and optimization without exposing raw API credentials or billing PII.
