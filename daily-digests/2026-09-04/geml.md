## Summary
GEML (General Expressive Markup Language) is an agent-native markup format and protocol designed for both humans and AI agents to collaboratively read and write structured documents with deterministic block-level operations. It enables precise, low-token context reads and writes while maintaining human readability and single-source-of-truth modularity.

## Key Features
- Deterministic AST-level operations for precise block-level reads/writes
- Minimal token overhead by addressing only target blocks (not entire files)
- Single-source-of-truth modular references with dynamic embeds
- Strict validation and rollback capabilities via `.gemlhistory` sidecar
- Human-readable plain text with machine-operable structural metadata

## Why It Matters for RAG Builders
GEML enables RAG builders to reduce context bloat and token costs while ensuring deterministic, version-controlled document operations for AI-agent collaboration.
