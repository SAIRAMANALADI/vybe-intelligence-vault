## Summary
A production-ready starter kit for deploying generative AI infrastructure on Amazon EKS, enabling teams to self-host LLMs, vector databases, AI agents, and observability tools with a single CLI command. It simplifies the setup of GPU-accelerated inference platforms, AI gateways, and workflow automation on Kubernetes.

## Key Features
- Single CLI command for deploying AI infrastructure on Amazon EKS
- Pre-configured support for multiple LLM serving engines (vLLM, SGLang, Ollama)
- Integrated vector databases (Qdrant, Chroma, Milvus) and embedding models (TEI)
- Built-in observability with Langfuse and Phoenix for monitoring AI workloads
- NVIDIA Dynamo platform integration for optimized LLM inference and GPU acceleration

## Why It Matters for RAG Builders
This starter kit provides a turnkey solution for deploying self-hosted generative AI workloads on Kubernetes, reducing setup time and complexity for RAG/AI stack builders.
