## Summary
Auto-RepoFlow is a privacy-first repository evidence scanner and change control plane that audits engineering artifacts, connects design, code, tests, and CI evidence, and generates structured handoff packets for AI assistants or coding agents without running repository scripts or editing files.

## Key Features
- Zero-config CLI for scanning repositories and generating structured fix packets
- Privacy-safe snapshots with automatic cleanup and SHA-256 manifest validation
- Support for JavaScript/TypeScript repositories with multiple output formats (human, JSON, agent-md, agent-json)
- Reproducible known-gap precision/recall scoring for benchmarking
- Provider-neutral local AI linking with Mock or loopback-only Ollama integration

## Why It Matters for RAG Builders
It provides a critical privacy-first pipeline for auditing and structuring repository evidence, enabling reliable RAG systems to consume clean, validated, and anonymized data without exposing sensitive information.
