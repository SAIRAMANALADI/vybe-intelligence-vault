## Summary
FlowGate is a typed document pipeline and review gate system designed to enforce accountability in autonomous AI agent workflows. It ensures agents must prove their work through structured artifacts and human (or agent) approval before tasks are considered complete.

## Key Features
- Typed document pipeline with auto-numbering and chaining (Requirement → Task → Task Report → Approval)
- Review gates with approval/rejection workflows and full rejection history tracking
- Remote worker API with scoped Bearer tokens and dry-run validation
- Continuous (unmanned) work with auto-advancement through workflow stages
- Multi-database support (SQLite, MySQL, PostgreSQL) with 86 ordered migrations per backend

## Why It Matters for RAG Builders
FlowGate ensures AI agents cannot claim task completion without verifiable evidence, bridging the gap between agent claims and actual accountability in RAG and AI stacks.
