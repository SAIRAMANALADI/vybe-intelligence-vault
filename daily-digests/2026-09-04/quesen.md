## Summary
Quesen is a deterministic AI decision engine designed as a trust filter for autonomous agents, particularly in financial risk evaluation. It provides a public developer portal with documentation, SDKs, and integration guides for its MCP-compatible, non-public engine that evaluates agent actions for capital-related risks.

## Key Features
- Deterministic decision-making with reproducible outputs for the same inputs
- MCP-compatible server for seamless integration with AI agents and tools
- Agent Settlement Protocol (ASP/1.0) compliance for standardized risk evaluation
- Multi-language SDKs (Python, JavaScript/TypeScript) and framework wrappers (LangChain, CrewAI, AutoGen)
- Live production endpoints with health checks, versioning, and OpenAPI documentation
