## Summary
BoardUI is a React design system tailored for agentic interfaces, providing both UI components and application blocks for AI products. It includes a working AI chat app as its homepage, deployable with a single API key, and offers components as source files for customization.

## Key Features
- 62+ free UI components and application blocks for agentic interfaces
- Source-based installation via CLI or MCP server for AI agents
- Built-in AI chat app deployable with a single API key
- Accessible by default with React Aria and Tailwind CSS v4
- Visual language consistency with 400+ semantic tokens and light/dark modes

## Why It Matters for RAG Builders
BoardUI accelerates the development of agentic interfaces by providing a comprehensive, customizable React design system with AI-native components, reducing time-to-market for AI product builders.
