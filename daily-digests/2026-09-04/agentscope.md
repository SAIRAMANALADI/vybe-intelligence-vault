## Summary
AgentScope is a prototype AI agent black-box tool designed to help product teams diagnose why an agent run failed, create safe new attempts from the failure point, and validate fixes using execution evidence. It provides both a product narrative layer for stakeholders and a technical evidence layer for detailed debugging.

## Key Features
- Visualizes agent execution paths and failure points with interactive traces
- Enables safe forking of failed runs to create new attempts without overwriting original evidence
- Generates bilingual product recap summaries with verifiable technical evidence links
- Supports deterministic recorded-only demos for quick onboarding without external dependencies
- Provides advanced workbench for deep technical inspection of inputs, outputs, and artifacts

## Why It Matters for RAG Builders
It provides critical debugging and validation capabilities for AI agent teams to systematically diagnose failures and verify fixes, reducing time-to-resolution and improving agent reliability.
