## Summary
An extended Model Context Protocol (MCP) server for WhatsApp that provides a comprehensive toolset for messaging, media handling, group management, presence tracking, and real-time webhooks. It builds upon prior forks to offer 26 default tools, including reactions, message editing, polls, and newsletters, with a focus on agent-friendly API design and session reliability.

## Key Features
- 26 default MCP tools covering messaging, media, group management, and presence tracking
- Real-time webhook system for incoming messages with filtering and HMAC security
- Session reliability features including automatic reconnection and SQLite WAL mode for data persistence
- Curated toolsets for lean or full agent context, with granular control over exposed tools
- Web UI for QR code pairing, webhook management, and chat/contact monitoring

## Why It Matters for RAG Builders
It provides a robust, agent-ready interface for WhatsApp integration, enabling AI systems to interact with messaging, media, and group features while ensuring session reliability and real-time event handling.
