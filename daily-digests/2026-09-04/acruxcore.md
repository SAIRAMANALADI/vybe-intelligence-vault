## Summary
AcruxCore is an open-source platform for managing prompts, AI gateways, tracing, tool catalogs, and evaluations, designed to streamline the development and deployment of LLM-based products. It provides a unified interface for versioning prompts, executing tools, routing AI requests, and analyzing traces.

## Key Features
- Versioned prompt management with Jinja2-style templating and diffing
- AI gateway with routing, caching, retries, and multi-provider support
- Automatic tracing for every request with tool spans included
- Persistent, versioned tool catalog for reuse across prompts and agents
- Built-in evaluation framework for comparing prompt and session performance

## Why It Matters for RAG Builders
AcruxCore simplifies the end-to-end workflow for RAG builders by unifying prompt management, AI gateway routing, and evaluation into a single self-hostable platform.
