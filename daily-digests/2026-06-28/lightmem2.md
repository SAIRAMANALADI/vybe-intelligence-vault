## Summary
LightMem2 is a modular framework designed for long-running LLM agents, focusing on memory and context management to reduce input tokens and operational costs. It provides a lightweight runtime for shared-session workloads, integrating with hosts like OpenClaw, Codex, and Claude Code.

## Key Features
- Modular framework for long-running agent memory and context management
- Significant reduction in input tokens (up to 95.7%) and operational costs (up to 87.0%)
- Supports multiple host integrations (OpenClaw, Codex, Claude Code)
- Runtime components for stabilization, reduction, and lifecycle-aware eviction
- Built-in visual inspector for runtime state monitoring
