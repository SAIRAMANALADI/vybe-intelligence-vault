## Summary
Lythéa is a fully local AI assistant with neuro-inspired memory, an observable agent (Taëlys), and contrastive activation steering (CAA). It runs in-process using Hugging Face Transformers, enabling direct access to model internals for memory consolidation, steering, and latent state manipulation without external inference servers.

## Key Features
- Neuro-inspired multi-stage memory system (SDM, MHN, KG, procedural, working memory) with consolidation phases
- Observable agent Taëlys with Thinker/Worker/Critic roles, sandboxed code execution, and blackboard coordination
- Contrastive Activation Addition (CAA) for real-time behavioral steering via residual vector injection
- Optional cascade to remote models (e.g., Gemini) for draft-then-refine workflows while maintaining local control
- In-process execution with direct access to model hooks, hidden states, and latent states for fine-grained control

## Why It Matters for RAG Builders
Lythéa provides a unique framework for building AI agents with fine-grained control over memory, reasoning, and behavior through direct model manipulation, making it essential for researchers and engineers focused on neuro-symbolic and memory-augmented architectures.
