## Summary
cursor-browser-bridge enables remote control of Cursor IDE's built-in browser from MCP clients like Claude Code or Codex over SSH. It allows navigation, interaction, and screenshot capture without leaving the Cursor IDE environment.

## Key Features
- Remote browser control via SSH from MCP clients
- Seamless interaction with Cursor IDE's browser
- Screenshot capture for debugging and review
- Cross-platform support (Windows, macOS, Linux)
- Simple GUI for SSH connection setup

## Why It Matters for RAG Builders
