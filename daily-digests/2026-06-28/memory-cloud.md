## Summary
Kagura Memory Cloud is a self-hosted MCP server that provides adaptive memory for AI agents and teams, going beyond traditional RAG by implementing a neural memory graph with Hebbian learning. It enables persistent, searchable, and team-shareable memory with hybrid search and AI reranking capabilities.

## Key Features
- Neural memory graph with Hebbian learning for organic relationship building between memories
- Hybrid search combining semantic (OpenAI/Ollama) and BM25 keyword search with AI reranking
- 45 MCP tools for memory, agent substrate, neural edges, contexts, and more
- Team-ready with workspaces, RBAC, and context isolation
- 5-layer LLM Knowledge Base implementation (ingest, compile, index, query, enhance)

## Why It Matters for RAG Builders
It provides a persistent, adaptive memory layer for AI agents and teams that evolves with usage, enabling deeper contextual understanding and serendipitous discovery beyond static RAG systems.
