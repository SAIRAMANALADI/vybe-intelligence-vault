## Summary
A Vite plugin that provides runtime observability and self-healing telemetry for AI agents and human developers. It captures structured logs, API calls, errors, interactions, and DOM snapshots to enable AI-driven debugging, validation, and automated workflows like pre-commit checks.

## Key Features
- Structured runtime logging for API calls, errors, console output, and interactions with aggregation and deduplication
- Automatic DOM snapshots and error screenshots for visual debugging and agent-driven issue reproduction
- Pre-commit risk guardrails to block sensitive data, large files, or code smells before submission
- Login state tracking and interaction tracing to help AI agents understand user context and reproduce workflows
- Proxy layer for local cookie handling and network request logging, including Set-Cookie and CORS metadata

## Why It Matters for RAG Builders
It provides AI agents with the runtime visibility they need to self-debug, validate fixes, and automate workflows, while also acting as a critical safety net for human developers during development and pre-commit stages.
