## Summary
Clutch is an autonomous AI agent that transforms unstructured brain-dumps into prioritized, time-blocked plans with multi-step reasoning and autonomous actions. It includes features like emergency triage, energy-aware scheduling, and real-time agent activity tracking.

## Key Features
- Multi-step function-calling loop with Google Gemini for autonomous task decomposition and prioritization
- Clutch Mode for emergency triage with real-time spoken rescue plans via Cloud Text-to-Speech
- Energy-aware scheduling that aligns deep work with peak focus periods
- Integration with Google Calendar for syncing time-blocked plans
- Live Agent Activity feed tracking autonomous actions and reasoning
