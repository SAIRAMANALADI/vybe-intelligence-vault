## Summary
browser-mcp is an MCP server for unified browser automation and bookmark management across Chrome, Firefox, Edge, and Brave. It provides tools for page navigation, element interaction, screenshots, and advanced bookmark operations with a React-based web dashboard for monitoring and control.

## Key Features
- Unified MCP server for browser automation (Playwright + CDP + CLI) across Chrome, Firefox, Edge, and Brave
- Comprehensive bookmark management with CRUD, search, sync, deduplication, and tagging (Firefox-focused)
- React webapp dashboard for real-time monitoring and interaction
- Workflow tools for automated browsing tasks (e.g., morning briefings, multi-step agentic browsing)
- Direct browser storage access (SQLite for Firefox, JSON for Chromium) with cross-browser sync capabilities
