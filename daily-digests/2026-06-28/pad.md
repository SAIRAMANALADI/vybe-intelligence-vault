## Summary
Pad is a local-first project management tool designed for developers and AI agents, offering a CLI, web UI, and AI agent skill. It runs entirely on the user's machine with SQLite backend, enabling offline functionality and data ownership.

## Key Features
- Local-first architecture with SQLite backend, ensuring data privacy and offline functionality
- AI agent skill integration via `/pad` commands for natural language project management
- Interactive knowledge graph for visualizing project dependencies and relationships
- Customizable collections, conventions, and playbooks to adapt to any workflow
- Multi-platform support including CLI, web UI, and MCP server for desktop AI tools

## Why It Matters for RAG Builders
Pad bridges the gap between traditional project management and AI-driven workflows by providing a local, agent-friendly platform that enhances productivity for developers and AI tools alike.
