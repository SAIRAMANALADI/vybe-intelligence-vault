## Summary
The hermes-browser-extension is a browser-side panel tool that bridges web content to a local Hermes Agent, enabling private, direct data transfer from websites to a user's machine without third-party servers. It facilitates seamless integration between web browsing and local AI agent processing.

## Key Features
- Side panel for direct agent interaction within the browser
- Local data transfer without cloud processing for privacy
- Context sharing of URLs and text snippets with one click
- Compatibility with Chrome and Edge browsers
- Real-time sync between browser content and local agent
