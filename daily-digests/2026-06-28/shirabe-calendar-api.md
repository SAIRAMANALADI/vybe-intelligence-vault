## Summary
Shirabe Calendar API is an AI-native REST API providing Japanese calendar data with astronomical precision, including rokuyo, rekichu, kanshi, 24 solar terms, and purpose-specific auspicious-day judgments. It is designed for seamless integration with AI frameworks like GPTs, Claude Tool Use, and LangChain.

## Key Features
- Provides Japanese calendar data (rokuyo, rekichu, kanshi, 24 solar terms) with astronomical precision
- Includes 8 categories of purpose-specific auspicious-day judgments with scores (e.g., wedding, funeral, moving)
- OpenAPI 3.1 compliant with AI framework integration (GPTs, Claude Tool Use, LangChain)
- Supports range queries, best-day rankings, and filtering by rokuyo/rekichu
- Automated billing via Stripe and edge deployment on Cloudflare Workers
