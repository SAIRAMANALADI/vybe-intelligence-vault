## Summary
HexClaw Desktop is an enterprise-grade, privacy-focused AI Agent desktop client built with Tauri and Vue 3. It integrates local and cloud-based LLMs, RAG, MCP tools, and multi-platform IM channels into a unified native application with zero cloud dependency.

## Key Features
- Unified AI Agent interface with multi-model support (OpenAI, DeepSeek, Ollama, etc.) and streaming responses
- Built-in RAG system for document retrieval and knowledge base integration with semantic search
- MCP (Model Context Protocol) tool integration for extensible AI capabilities
- Enterprise-grade security with prompt injection detection, PII filtering, and RBAC permissions
- Cross-platform native desktop app (macOS, Windows, Linux) with offline-first architecture

## Why It Matters for RAG Builders
It provides a privacy-preserving, feature-rich desktop interface for AI Agent orchestration, RAG, and MCP tool integration, bridging the gap between local and cloud-based AI workflows.
