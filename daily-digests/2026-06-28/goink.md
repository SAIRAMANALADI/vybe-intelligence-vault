## Summary
Goink is a desktop AI writing system designed for long-form novel creation, featuring structured memory tracking, real-time agent decision-making, and built-in semantic search. It automates narrative consistency checks, character state maintenance, and plot progression while providing a visual interface for managing story arcs, locations, and reader cognition.

## Key Features
- Structured memory tracking for characters, plot arcs, foreshadowing, and world-building with directed graphs and hierarchical relationships
- Real-time agent decision-making with 31+ tools for autonomous narrative maintenance and consistency checks
- Local semantic search engine using ONNX Runtime and sqlite-vec for finding contextually relevant passages across large documents
- Skill system with three-layer priority (builtin/user/novel) and three trigger modes (auto/manual/always) for customizable writing workflows
- Built-in Git version control with automatic commits and diff previews for all edits, ensuring traceability and rollback capability
