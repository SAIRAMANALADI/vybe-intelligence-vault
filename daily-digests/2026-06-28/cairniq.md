## Summary
CairnIQ is a local-first AI-powered console for personal financial market research, portfolio monitoring, and risk-aware decision support. It integrates multi-agent AI reasoning with real-time financial data feeds and automated valuation tools.

## Key Features
- Multi-agent AI reasoning engine for financial queries and market analysis
- Real-time integration with brokerage APIs (Alpaca, Questrade) and CSV-based portfolio tracking
- Automated fundamental and technical analysis (P/E, RSI, MACD, etc.)
- Local-first architecture with zero-trust data handling and BYOK support
- Guided setup and interactive configuration for LLM and financial data providers
