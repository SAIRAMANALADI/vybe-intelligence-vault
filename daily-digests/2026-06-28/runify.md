## Summary
Runify is a lightweight, white-box multi-agent platform designed for transparent, visual orchestration of AI workflows with high-precision knowledge retrieval and enterprise-grade permissions. It offers out-of-the-box desktop installation with minimal resource requirements (200MB) and supports seamless integration into third-party systems.

## Key Features
- Drag-and-drop visual editor for multi-agent workflows with DAG-based execution engine
- High-precision knowledge retrieval with built-in Lucene search and rich text editor
- Enterprise-grade RBAC permissions and unified conversation management
- Cross-platform desktop installation (macOS/Windows) with minimal resource footprint
- Low-cost integration via API/Webhook and support for multiple data sources (PostgreSQL, MySQL, Redis)
