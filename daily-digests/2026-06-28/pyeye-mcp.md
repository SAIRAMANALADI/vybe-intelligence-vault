## Summary
PyEye is an extensible MCP (Model Context Protocol) server that provides intelligent Python code analysis, navigation, and understanding capabilities for AI assistants like Claude. It enables semantic code navigation, dependency analysis, and multi-project support with a focus on performance and extensibility.

## Key Features
- Semantic code navigation with Jedi for symbol resolution, definitions, and references
- Multi-project and namespace package support for analyzing complex Python ecosystems
- Extensible plugin system for framework-specific analyzers (Pydantic, Django, Flask)
- Performance-optimized with intelligent caching, LRU eviction, and metrics tracking
- Flexible configuration via files, environment variables, or auto-discovery
