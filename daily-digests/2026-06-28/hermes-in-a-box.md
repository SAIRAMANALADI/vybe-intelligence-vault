## Summary
A Docker-based deployment of the Hermes Agent by NousResearch, enabling self-hosted AI agents with web search, headless browser automation, memory, and skills via Telegram bot or Open WebUI. Designed for minimal setup and persistence within the repo folder.

## Key Features
- Zero-install deployment via Docker (no GPU or heavy dependencies required)
- Dual interface support: Telegram bot and Open WebUI for seamless access
- Persistent memory, skills, and sessions stored in-repo for portability
- Built-in SearXNG for self-hosted web search and headless browser automation
- Provider-agnostic model support (free tiers, local Ollama, or paid APIs)

## Why It Matters for RAG Builders
It provides a turnkey, self-hosted AI agent framework with built-in tools and persistence, reducing setup complexity for RAG builders who need reliable, portable agent deployments.
