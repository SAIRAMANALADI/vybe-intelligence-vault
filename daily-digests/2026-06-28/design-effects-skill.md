## Summary
An agent-ready skill repository that provides AI agents with guidelines and code snippets for applying design effects, animations, and visual FX in UI and branding contexts. It includes decision rules, minimal code examples, and color integration guidance for various effect categories.

## Key Features
- Predefined decision guide for selecting design effects based on context and performance
- Minimal code snippets for quick integration of effects like animated backgrounds, text animations, and 3D UI
- Color pairing guidance integrated with a companion color-combo-skill repository
- Live examples with no build step required for immediate visualization
- Modular structure covering liquid/glass effects, shader gradients, and motion patterns

## Why It Matters for RAG Builders
This repository provides AI agents with structured, reusable knowledge for generating visually compelling UI elements, reducing the need for manual design decisions in RAG pipelines.
