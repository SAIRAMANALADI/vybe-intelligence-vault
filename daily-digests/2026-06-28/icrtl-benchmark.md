## Summary
ICRTL-Benchmark is an open-source collection of industrial-level Verilog RTL design challenges sourced from the National Taiwan Integrated Circuit Design Contest and handcrafted problems. It provides comprehensive specifications, testbenches, and reference implementations for evaluating PPA (Power, Performance, Area) optimization in hardware design.

## Key Features
- Industrial-level Verilog RTL design challenges with real-world complexity
- Comprehensive specifications and reference implementations for each problem
- Support for both open-source (Yosys, Icarus Verilog) and commercial (VCS, DC, PT) tool flows
- Evaluation framework for PPA (Power, Performance, Area) optimization
- 10 diverse challenges covering algorithms like convolution, Huffman coding, and systolic arrays

## Why It Matters for RAG Builders
It provides a standardized benchmark for evaluating AI/ML models and tools in hardware design, particularly for RTL code generation and optimization tasks.
