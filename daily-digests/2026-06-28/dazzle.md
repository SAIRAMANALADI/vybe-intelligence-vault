## Summary
Dazzle is a declarative framework for building SaaS applications where the business logic is defined in a structured DSL and executed directly at runtime. It serves as a semantic substrate optimized for AI-collaborative software development, emphasizing static validation, compliance, and anti-pattern prevention.

## Key Features
- DSL as the single source of truth for business logic, API, tests, and compliance evidence
- Three-layer prior correction system to prevent corpus-driven anti-patterns in AI-generated code
- Built-in RBAC with provable scope rules and mechanical proofs for compliance audits
- No code generation; runtime executes the IR directly for zero drift between design and execution
- Automated compliance evidence generation for frameworks like SOC 2 and ISO 27001

## Why It Matters for RAG Builders
Dazzle provides a structured, AI-resistant substrate for SaaS development that enforces semantic correctness, compliance, and anti-pattern prevention, making it essential for building robust, auditable, and AI-collaborative applications.
