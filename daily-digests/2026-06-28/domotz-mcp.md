## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Domotz network monitoring and management platforms. It provides tools for monitoring devices, managing alerts, and accessing network metrics through a standardized MCP interface.

## Key Features
- Enables AI assistants to monitor and manage network devices via Domotz API
- Supports multiple domains: Agents, Alerts, Devices, Metrics, Network, and Power
- Compatible with MCP-compatible AI systems like Claude
- Configurable via environment variables and Docker deployment
- Provides structured access to network topology and performance metrics

## Why It Matters for RAG Builders
It bridges AI assistants with real-time network monitoring data, enabling automated troubleshooting and proactive infrastructure management for RAG systems.
