## Summary
One Works is an open-source AI workspace that provides a unified environment for configuring and running AI workflows across desktop, web, VS Code, and CLI using extensible plugins and a standardized configuration system.

## Key Features
- Cross-platform AI workflow execution (desktop, web, VS Code, CLI)
- Extensible plugin architecture for agents, tools, and adapters
- Standardized configuration system for consistent AI workflows
- Local runtime data management and session handling
- Pre-built installers for macOS, Windows, and Linux
