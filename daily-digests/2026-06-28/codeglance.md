## Summary
CodeGlance is a self-hostable, MCP-native tool designed to generate prioritized onboarding maps for repositories, highlighting architecture hotspots and key files for both humans and AI agents. It provides scriptable, CI-ready insights in JSON, table, or SARIF formats to streamline AI stack integration.

## Key Features
- Generates prioritized onboarding maps for repositories with architecture and hotspot analysis
- Supports multiple output formats (JSON, table, SARIF) for machine and human readability
- MCP-native for seamless integration with AI agents and tools like Claude Desktop or Cursor
- CI-ready with exit codes and SARIF support for automated gatekeeping
- Polyglot ports available in Python, JavaScript, Go, and Rust

## Why It Matters for RAG Builders
