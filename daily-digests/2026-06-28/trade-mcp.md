## Summary
A high-performance Model Context Protocol (MCP) server providing real-time global stock market data, technical indicators, financials, news feeds, and AI-driven insights. It bridges AI hosts with market data sources and includes a Python sandbox for data analysis.

## Key Features
- 28+ tools for real-time stock quotes, historical data, and market summaries
- Supports US, Indian, and global markets with NSE, BSE, and forex data
- Integrates AI-driven sentiment analysis, trade signals, and portfolio insights
- Includes a Python sandbox for dynamic data analysis with pandas, numpy, and matplotlib
- Dual-transport layer (stdio and HTTP/SSE) for seamless AI host integration
