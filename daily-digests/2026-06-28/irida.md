## Summary
Irida is a local-first personal agent framework that provides a unified interface for interacting with AI engines, supporting both the Cursor SDK and Anthropic Claude Agent SDK. It offers a CLI/TUI, memory management, cron automation, gateway integrations (Telegram/webhook), and browser automation via MCP servers.

## Key Features
- Dual-engine support (Cursor SDK or Anthropic Claude Agent SDK) with runtime switching
- Comprehensive CLI/TUI with session management, slash commands, and memory operations
- Built-in cron automation with topic delegates and digest scheduling
- Gateway integrations for Telegram and webhooks with stable session handling
- Memory system with full-text search, semantic search (pgvector), and encrypted secure notes
