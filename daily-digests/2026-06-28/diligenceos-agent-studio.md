## Summary
DiligenceOS Agent Studio is a full-stack AI agent workspace designed for investment, procurement, and partnership due diligence. It automates the creation of evidence-backed risk memos through a deterministic agent loop with guardrails, approval gates, and audit traces.

## Key Features
- Evidence retrieval with citations from a seeded data-room corpus
- Deterministic agent loop with state management, tool calls, and validation
- Human-in-the-loop approval routing for high-risk cases
- Policy guardrails to prevent fabrication, bypass, and destructive actions
- Operational telemetry, metrics, and regression evals for reliability

## Why It Matters for RAG Builders
It provides a production-grade template for building secure, auditable, and human-approved AI agent workflows in regulated domains like finance and procurement.
