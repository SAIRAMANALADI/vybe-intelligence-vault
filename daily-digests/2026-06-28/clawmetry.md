## Summary
ClawMetry is a real-time observability and monitoring tool for AI agent runtimes, providing a unified dashboard to track, visualize, and manage agent activity, token usage, costs, and security across 12+ agent frameworks and SDKs.

## Key Features
- Unified dashboard for 12+ AI agent runtimes with auto-detection and runtime switching
- Real-time flow visualization of agent interactions and tool calls
- Token and cost tracking with detailed breakdowns and budget alerts
- OpenTelemetry integration for vendor-neutral trace export and ingestion
- Security features including approvals for risky actions and audit logging

## Why It Matters for RAG Builders
