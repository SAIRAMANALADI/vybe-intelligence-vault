## Summary
llamator-mcp-server is a tool designed to automate red teaming workflows for Large Language Models (LLMs), enabling users to identify vulnerabilities and analyze LLM behavior under attack scenarios without requiring deep technical expertise.

- Identifies vulnerabilities and generates detailed reports
- User-friendly interface for non-technical users
- Supports asynchronous job handling for scalability
- Seamless integration with LLMs via MCP server
