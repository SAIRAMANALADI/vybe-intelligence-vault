## Summary
FORKFUZZ is a mainnet-fork invariant fuzzer that replays smart contracts against live blockchain state to identify protocol invariants before deployment. It enables self-hostable, CI-ready security testing with polyglot support and MCP-native integration for AI-driven workflows.

## Key Features
- Replays contracts against live mainnet state to detect invariant violations
- Self-hostable and CI-ready with deterministic output for reproducibility
- Supports polyglot ports (Python, JavaScript, Go, Rust)
- MCP-native integration for AI agent workflows
- Outputs in JSON, table, or SARIF formats for seamless integration

## Why It Matters for RAG Builders
It enables pre-deployment security validation of smart contracts against real-world blockchain state, reducing risks of exploits in production environments.
