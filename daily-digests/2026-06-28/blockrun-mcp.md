## Summary
BlockRun MCP is a Model Context Protocol (MCP) server that provides real-time data access for AI agents, enabling live market data, research, social media insights, and AI model interactions without requiring API keys. It operates on a pay-per-call model using USDC micropayments.

## Key Features
- Integrates with 66+ LLMs via MCP for real-time model access with per-token billing
- Provides live market data from Polymarket, Kalshi, Binance, and others with sub-cent query costs
- Enables neural web search, X/Twitter scraping, and academic paper retrieval via Exa and Grok Live Search
- Supports AI-generated content (images, videos, music, speech) with pay-per-use pricing
- Offers on-chain data, DEX prices, and DeFi analytics via Surf and DefiLlama

## Why It Matters for RAG Builders
BlockRun MCP streamlines AI agent workflows by providing a unified, pay-per-call interface for real-time data, reducing the complexity of integrating multiple APIs and enabling cost-efficient, scalable AI applications.
