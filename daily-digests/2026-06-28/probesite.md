## Summary
PROBESITE is a synthetic monitoring tool that performs uptime and latency checks using Playwright, exporting results to Prometheus for observability. It supports self-hosting, CI integration, and AI agent interoperability via MCP.

## Key Features
- Runs synthetic uptime and latency checks via Playwright
- Exports metrics to Prometheus for real-time monitoring
- Supports CI/CD integration with exit codes and SARIF output
- MCP-native for AI agent interoperability (Claude, Cursor, etc.)
- Self-hostable and polyglot-ready (Python, JS, Go, Rust ports)
