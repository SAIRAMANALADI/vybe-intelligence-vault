## Summary
Hecate is a local-first AI operations console designed to coordinate, supervise, and orchestrate AI-driven workflows. It provides a unified interface for model routing, task execution, external agent supervision, project management, and observability, all running locally with optional cloud integrations.

## Key Features
- Unified model gateway with failover, rate limiting, and usage tracking for OpenAI-compatible and Anthropic-shaped APIs
- Task runtime with queued execution, approval gates, retries, and artifact management
- Project orchestration with durable identity, context management, and memory promotion
- External agent supervision for coding agents (e.g., Claude Code, Cursor Agent) with diagnostics and Git diff review
- Comprehensive observability via OpenTelemetry traces, metrics, and route reports

## Why It Matters for RAG Builders
Hecate provides a critical layer for coordinating and supervising AI-driven workflows, ensuring reliability, traceability, and control in RAG and agent-based systems.
