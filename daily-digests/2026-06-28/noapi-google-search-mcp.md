## Summary
noapi-google-search-mcp is a local tool that enables automated Google searches and web page fetching using headless Chromium, running as a background server without requiring API keys or manual browser interaction.

## Key Features
- Uses headless Chromium for accurate page rendering and fetching
- Runs as a local server for privacy and speed
- No API keys or external dependencies required
- Cross-platform support (Windows, macOS, Linux)
- Enables real-time Google search integration for LLMs
