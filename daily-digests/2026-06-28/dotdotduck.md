## Summary
dotdotduck is an embedded AI SDK that transforms existing websites into AI-native interfaces by integrating DOM-grounded agents, command palettes, and inline AI tools directly into the page. It enables users to interact with AI through familiar gestures like keyboard shortcuts, voice, and long-presses without relying on external chatbot widgets.

## Key Features
- DOM-grounded autonomous WebAgent that reads and operates the visible page without a sidebar chatbot
- Unified command palette (Ctrl/⌘+K) for all AI features, custom commands, and host integrations
- Inline AI for text selection with streaming actions like translation, grammar fixes, and summarization
- Proactive AI that triggers contextual offers based on user behavior (e.g., scroll depth, dwell time)
- Built-in dashboard for behavioral analytics and LLM performance tracking with structured event streams

## Why It Matters for RAG Builders
It enables seamless integration of AI capabilities directly into existing web applications, reducing the need for external tools and improving user engagement through intuitive, context-aware interactions.
