## Summary
Jawcode is a Bun-native coding-agent harness that orchestrates AI-driven software development workflows using an IPABCD (Interview, Plan, Audit, Build, Check, Done) pipeline. It supports 46 providers and 3,600+ models, enabling structured, human-in-the-loop or human-on-the-loop agent execution with parallel subagents and adversarial verification.

## Key Features
- IPABCD workflow with explicit stage gates for Interview, Plan, Audit, Build, Check, and Done
- Support for 46 providers and 3,600+ models with dynamic model switching
- Parallel subagent system with correction de-anchoring and prompt-cache-aware architecture
- Human-in-the-loop (HITL) and human-on-the-loop (HOTL) control modes for flexible oversight
- 40+ built-in tools including AST-aware code search, browser automation, and adversarial review

## Why It Matters for RAG Builders
Jawcode provides a structured, auditable, and scalable framework for AI-driven software development, making it essential for RAG builders who need reliable, multi-stage agent workflows with human oversight and verification.
