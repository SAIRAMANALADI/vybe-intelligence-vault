## Summary
VibeHarness is a local AI agent framework that enables users to run offline AI tasks on their Windows machines using the VibeThinker-3B model. It acts as a bridge between the user's computer and local AI, prioritizing privacy and offline functionality.

## Key Features
- Runs entirely offline for data privacy and security
- Supports natural language interactions with the AI agent
- Integrates with Ollama for model management
- Handles tasks like text summarization, coding assistance, and translation
- No internet required after initial setup
