## Summary
claude-ops transforms Claude Code into a comprehensive business operating system, providing real-time infrastructure monitoring, CI/CD status, unified inbox, autonomous agent workflows, and revenue analytics. It integrates with Stripe, AWS, Shopify, and marketing tools to deliver a unified dashboard and automation layer.

## Key Features
- Real-time infrastructure health monitoring (ECS, RDS, Redis) with visual dashboards
- Autonomous PR merge pipeline with auto-fix capabilities for CI/CD failures
- Unified inbox aggregating Slack, Telegram, Gmail, and WhatsApp messages
- Revenue tracking via Stripe, RevenueCat, and AWS with comparative analytics
- Voice and video integration (Twilio, Zoom, FaceTime, Bland AI) for C-suite communication
