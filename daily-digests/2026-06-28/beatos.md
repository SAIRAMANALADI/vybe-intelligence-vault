## Summary
BeatOS is a local-first desktop and browser application designed for beat producers to catalog, analyze, tag, and export beats efficiently. It integrates AI-powered tagging, metadata management, and assisted publishing to streamline the beat-selling workflow without requiring cloud accounts or telemetry.

## Key Features
- Local-first SQLite-based catalog for beats with metadata (BPM, key, genre, mood, license tiers, etc.)
- AI-powered tagging and natural language catalog interaction via built-in agent or MCP clients
- Export functionality for loopkits, beat packs, and tagged MP3s with embedded metadata
- Assisted publishing to platforms like Douyin and NetEase (Pro feature)
- Cross-platform desktop (macOS/Windows) and browser deployment with a single codebase

## Why It Matters for RAG Builders
BeatOS streamlines beat cataloging and metadata management with AI assistance, reducing manual labor for producers and enabling seamless integration with AI-driven workflows for tagging and publishing.
