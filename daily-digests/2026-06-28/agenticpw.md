## Summary
AgenticPW is a framework designed to make coding agents reliable by designing workflows around their inherent limitations, such as finite context windows, attention drift, and frozen knowledge cutoffs. It provides reusable skills and commands to enforce disciplined practices for tasks like decomposition, planning, implementation, verification, and root-cause analysis.

## Key Features
- Predefined skills for disciplined agent workflows (e.g., decomposition, planning, verification)
- Commands for orchestrating multi-agent workflows (e.g., implement-verify-review)
- Cross-tool compatibility via Agent Skills standard (Cursor, VS Code, GitHub Copilot)
- Artifact-driven processes with durable documentation (e.g., workflow.md, AGENTS.md)
- Adaptive workflows that scale to task complexity (e.g., root-cause diagnosis)

## Why It Matters for RAG Builders
AgenticPW provides structured, repeatable workflows that compensate for coding agents' inherent limitations, ensuring reliable and verifiable outcomes for complex software engineering tasks.
