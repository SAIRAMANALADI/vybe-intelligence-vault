## Summary
Gini Agent is a personal AI agent framework designed to manage, execute, and remember multi-step tasks while providing interactive, in-context controls for user approvals, secrets, and decisions. It acts as a runtime gateway with persistent state, supporting multiple clients (web, CLI, mobile) and integrating with various LLM providers.

## Key Features
- Single Bun runtime gateway managing state, tools, memory, and jobs for all clients
- In-chat interactive controls for secrets, approvals, and confirmations without detours
- Multi-provider LLM support (OpenAI, Anthropic, Bedrock, Azure, Local, etc.)
- Persistent chat, runs, tasks, and audit trails with embedded memory and reranking
- Cross-platform clients (web, CLI, mobile) with synchronized runtime tunnels

## Why It Matters for RAG Builders
Gini Agent provides a robust runtime and interaction surface for building AI agents that require persistent state, user approvals, and multi-step task execution, making it essential for RAG/AI stack builders focused on production-ready agent systems.
