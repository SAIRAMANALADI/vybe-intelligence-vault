## Summary
Lemon is a macOS menu-bar application that orchestrates Claude Code sessions directly from issue trackers like Linear or GitHub. It automates worktree management, context provisioning, and session execution while using an on-device Gemma 4 model for routine confirmations, ensuring minimal human intervention.

## Key Features
- Triggers Claude Code sessions from issue labels (🍋) in Linear or GitHub
- Manages git worktrees and context provisioning for isolated sessions
- Uses on-device Gemma 4 model (via SwiftLM/MLX) for routine confirmations and triage
- Provides two human gates (plan approval and result review) before PR creation
- Supports recursive mode via MCP server for advanced session control and querying

## Why It Matters for RAG Builders
Lemon streamlines the integration of Claude Code with issue trackers by automating workflows and reducing manual overhead, making it essential for developers who want to leverage AI agents without sacrificing control or privacy.
