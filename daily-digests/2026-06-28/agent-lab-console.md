## Summary
Agent Lab Console is a portfolio-grade AI agent engineering console that demonstrates a deterministic agent loop with tool permissions, guardrails, dry-run external writes, trace persistence, and runtime metrics. It provides a polished React dashboard for monitoring and auditing agent workflows.

## Key Features
- Deterministic observe-decide-act-validate agent loop with structured traces
- Tool catalog with read/write-dry-run permission labels and guardrails for destructive operations
- JSON trace persistence for replay and audit review
- Runtime metrics and operational scorecard APIs for monitoring
- React UI for task entry, trace timeline, risk status, and trace download

## Why It Matters for RAG Builders
It provides a critical engineering layer for building auditable, safe, and reviewable AI agents with deterministic workflows and trace persistence.
