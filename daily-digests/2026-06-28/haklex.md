## Summary
Haklex is an AI-agent-native rich text editor ecosystem built on Lexical, enabling human-AI collaboration through structured editing, static rendering, and server-side parsing. It provides a unified schema for AI writing assistance, LiteXML serialization, and modular plugin architecture.

## Key Features
- Built-in AI writing agent with LiteXML serialization and diff review overlay
- Bidirectional Lexical JSON ↔ XML serialization for LLM-friendly document I/O
- Static/Edit split architecture for optimized tree-shaking and SSR
- Modular plugin system with slash menus, toolbars, and block handles
- Server-side parsing via headless node registry for backend document processing

## Why It Matters for RAG Builders
Haklex provides a critical bridge between human editing and AI processing, enabling seamless integration of AI agents into rich text workflows with structured document handling and serialization optimized for LLM interactions.
