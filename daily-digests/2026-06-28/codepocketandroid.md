## Summary
CodePocketAndroid is an Android client designed to control OpenCode, a local AI agent framework, from a mobile device. It enables users to interact with OpenCode's agent capabilities, manage sessions, and stream responses in real-time via WebSocket.

## Key Features
- Real-time streaming responses via WebSocket for OpenCode Agent
- Session management (create, switch, delete, browse) with local persistence using Room database
- Markdown rendering for AI responses including code blocks and tables
- DeepSeek model integration for read-only model display
- Cross-platform compatibility with Debian/Ubuntu backend and Android frontend

## Why It Matters for RAG Builders
It enables mobile control of local AI agents, bridging Android devices with local AI frameworks like OpenCode for seamless AI interaction on-the-go.
