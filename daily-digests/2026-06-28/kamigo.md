## Summary
Kamigo is an AI-powered Solana wallet that enables users to manage, grow, and automate their Solana assets using plain English commands. It integrates with Kamino yield vaults, QuickNode RPC, and Supabase for real-time automation and portfolio tracking.

## Key Features
- Plain English command execution for wallet actions (sending, swapping, yield farming)
- Real-time automation via QuickNode webhooks and Supabase Realtime
- AI-driven intent understanding with Mistral 7B for natural language processing
- Portfolio tracking with Kamino yield vaults and Solana balance monitoring
- User-defined triggers for balance alerts, scheduled actions, and yield thresholds

## Why It Matters for RAG Builders
