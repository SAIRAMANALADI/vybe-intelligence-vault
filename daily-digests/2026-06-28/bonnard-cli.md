## Summary
bonnard-cli is a Windows-based analytics tool that provides a no-code CLI, server, and dashboards for accessing and visualizing data from modern analytics platforms like BigQuery, Snowflake, and Databricks without requiring programming skills.

## Key Features
- No-code analytics access via CLI and dashboards
- Supports major data platforms (BigQuery, Snowflake, Databricks)
- Local MCP server for data management and visualization
- Semantic layer for organizing and querying data
- Windows-native installer and GUI dashboard
