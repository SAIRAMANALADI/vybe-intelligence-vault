## Summary
Vulos is a self-hostable, web-native operating system that runs on local hardware or cloud servers, providing a full desktop experience via a React-based shell and Go backend. It supports native Linux GUI apps, AI-powered features, and local-first storage with peer-to-peer sync.

## Key Features
- React-based window manager with virtual desktops, dock, and bundled apps
- On-demand WebRTC streaming of native Linux GUI apps with GPU acceleration
- Built-in LLM gateway (`airouter`) with local vector store for retrieval
- Passwordless authentication via WebAuthn/FIDO2 passkeys and QR/phone approval
- Leaderless CRDT sync and local-first storage with SQLite and S3/Restic backups

## Why It Matters for RAG Builders
Vulos provides a unified, self-hostable platform for AI-driven desktop environments with native app streaming and local-first data control, making it essential for builders seeking privacy-focused, customizable OS solutions.
