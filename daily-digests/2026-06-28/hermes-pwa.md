## Summary
A community-built unofficial mobile Progressive Web App (PWA) plugin for the Hermes Agent Dashboard that enables users to interact with their Hermes AI agent directly from their phone. It integrates seamlessly as a plugin, providing chat, approvals, activity tracking, and system monitoring without requiring separate hosting or authentication.

## Key Features
- Seamless integration as a Hermes Dashboard plugin with no additional hosting or authentication required
- Real-time chat streaming with the Hermes agent directly from a mobile device
- In-app approvals and activity monitoring for high-impact agent actions
- Installable PWA for iOS Safari and Android Chrome, accessible from the home screen
- Privacy-focused design with no telemetry, no third-party trackers, and reuse of existing Dashboard session

## Why It Matters for RAG Builders
It provides a convenient, privacy-preserving mobile interface for interacting with Hermes agents, eliminating the need for separate apps or complex setups while maintaining security and ease of use.
