## Summary
A specialized pipeline for predicting political indicators in historical polities using LLMs with advanced verification methods like self-consistency, Chain of Verification, and web search augmentation. It supports multiple LLM providers and offers configurable prompt modes, search strategies, and batch processing for cost efficiency.

## Key Features
- Multi-LLM support with configurable providers (Gemini, OpenAI, Anthropic, AWS Bedrock)
- Advanced verification methods: self-consistency, Chain of Verification (CoVe), and cross-model validation
- Flexible prompt modes: single, multiple, and sequential for tailored inference strategies
- Web search augmentation with tiered forced search or agentic tool calling
- Gemini Batch API integration for 50% cost savings and server-side parallel processing
