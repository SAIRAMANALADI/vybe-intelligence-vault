## Summary
prx is a CLI tool and monorepo for managing agent-run work units through signed, content-addressed pipelines that drive work to merged PRs. It leverages capability-scoped agents and verifies git writes against their owners, ensuring secure and auditable workflows.

## Key Features
- Signed, content-addressed pipeline for work units ensuring auditability and integrity
- Capability-scoped agents with verified git writes against owner identities
- Multi-platform binary distribution via GitHub releases, Homebrew, and Nix flakes
- Monorepo structure with workspace-internal libraries and npm publishing for public packages
- Automated governance and documentation generation via JSON-LD and community templates

## Why It Matters for RAG Builders
