## Summary
CSVLENS is a fast, CLI-based utility for profiling, cleaning, and analyzing large CSV and Parquet files. It provides prioritized findings, supports multiple output formats, and integrates seamlessly with AI stacks, CI pipelines, and MCP servers.

## Key Features
- Detects CSV dialects and profiles column types/stats
- Cleans data by trimming, deduplicating, and filling nulls
- Supports JSON, table, and SARIF output formats
- MCP-native for AI agent integration
- CI-ready with exit codes and fail-on-severity flags

CSVLENS streamlines data quality checks and cleaning for RAG pipelines, ensuring high-quality datasets are ingested efficiently.
