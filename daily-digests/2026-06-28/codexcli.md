## Summary
codexCLI is a lightweight command-line tool for storing, organizing, and retrieving frequently used data such as notes, commands, or code snippets using simple dot-path navigation. It supports shell completions and integrates with AI tools via an MCP server for automation and enhanced workflows.

## Key Features
- Store and retrieve data using intuitive dot-path navigation
- Shell completions for faster command input
- Optional MCP server for AI tool integration and automation
- Lightweight and no complex setup required
- Local data storage with configurable paths
