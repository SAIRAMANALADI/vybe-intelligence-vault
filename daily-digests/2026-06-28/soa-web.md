## Summary
SoA-Web is a browser-native terminal UI that streams real PTY sessions over WebSocket, eliminating Electron dependencies. It reimagines the desktop 'Son of Anton' as a web-based terminal with server-side PTY management and WebSocket communication.

## Key Features
- Browser-native terminal UI with no Electron dependencies
- Real-time PTY session streaming over WebSocket
- Multi-tenant isolation with configurable auth (shared, open, none)
- Cloudflare Tunnel integration for mobile/remote access
- Supports split-deploy (Vercel SPA + self-hosted backend)

## Why It Matters for RAG Builders
SoA-Web provides a lightweight, Electron-free alternative for deploying terminal UIs in web environments, enabling secure, real-time shell access without complex desktop packaging.
