## Summary
OASiS is an open-source Model Context Protocol (MCP) server that bridges AI coding agents with eight independent finite element method (FEM) solvers, enabling verified multi-physics simulations, cross-solver coupling, and solver development through a unified protocol.

## Key Features
- Connects AI agents to 8 independent FEM solvers via MCP protocol for seamless simulation operations
- Supports cross-solver coupling and domain decomposition with 20 solver pair combinations
- Provides 26 cross-backend collation topics with 45+ pitfalls to guide solver selection and usage
- Enables solver development by allowing AI agents to browse, modify, and rebuild solver source code
- Includes 400+ passing tests and 24 end-to-end stress tests for reliability and validation
