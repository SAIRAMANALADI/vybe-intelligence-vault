## Summary
A lightweight MCP (Model Context Protocol) server that simplifies integration with PostgREST APIs, enabling OAuth2 authentication and streamable HTTP services for Supabase, Neon, and other PostgREST-compatible databases.

## Key Features
- OAuth2 authentication for secure API access
- Streamable HTTP services for real-time data handling
- Compatibility with Supabase and Neon Postgres
- Self-hosted deployment option
- User-friendly configuration for PostgREST server connections
