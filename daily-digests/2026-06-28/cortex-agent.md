## Summary
Cortex Agent is a production-ready AI research agent that classifies user queries, performs real-time web searches, scrapes and synthesizes content, and returns structured responses using local Llama3 models via Ollama. It features intelligent query handling, structured data extraction, and a modern glassmorphic UI.

## Key Features
- Intelligent query classification for product vs. conceptual queries
- Real-time Google search scraping with BeautifulSoup and automated redirect cleaning
- Local Llama3-based synthesis with strict JSON output validation
- Structured product comparison matrices and general concept synthesis
- Modern glassmorphic UI with responsive design and visual citations

## Why It Matters for RAG Builders
Cortex Agent provides a robust, local-first framework for building AI agents that perform real-time research, structured synthesis, and dynamic UI rendering, reducing dependency on external APIs while enabling customizable RAG pipelines.
