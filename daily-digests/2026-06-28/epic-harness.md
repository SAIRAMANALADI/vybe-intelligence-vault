## Summary
Epic Harness is a self-evolving AI coding agent harness that consolidates 30+ commands into 3 core commands and 26 auto-trigger skills, enabling autonomous pipelines from specification to PR while learning from failures to improve future sessions.

## Key Features
- Autonomous pipeline from spec to PR with minimal user input (/orbit command)
- 26 auto-trigger skills that adapt based on context (e.g., TDD, debugging, security checks)
- Self-evolving engine that analyzes failures and generates new skills for future sessions
- Real-time web dashboard with 10 screens for metrics, pipeline status, and evolution tracking
- Multi-language support (11 languages) and integration with Claude Code, Codex, Cursor, and other AI tools
