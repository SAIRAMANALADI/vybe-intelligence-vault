## Summary
OneBrain is an AI operating system layer built on Obsidian that provides persistent memory, structured knowledge vaults, and 29+ pre-built skills for AI agents. It integrates with existing AI harnesses (e.g., Claude Code, Gemini CLI) to extend their capabilities with personal calibration, continuity, and local-first data ownership.

## Key Features
- Persistent memory system with four-tier knowledge hierarchy (Working, Episodic, Semantic, Knowledge)
- 29+ pre-built skills for AI agents (e.g., /braindump, /research, /distill, /learn)
- Bidirectional co-evolution loop between human and AI for continuous improvement
- Harness-agnostic architecture supporting Claude Code, Gemini CLI, OpenAI Codex, Qwen, and custom LLMs
- Automatic session saving and checkpointing for reliability and continuity

## Why It Matters for RAG Builders
OneBrain enables AI agents to retain context and personalization across sessions and harnesses, eliminating the need for repetitive setup and ensuring consistent, evolving interactions with local data ownership.
