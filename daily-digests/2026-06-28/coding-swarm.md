## Summary
coding-swarm is a framework that enables teams of AI agents to collaborate on software development tasks, including coding, testing, and maintenance, without requiring manual coding. It automates project management by orchestrating specialized agents in isolated Docker containers.

## Key Features
- Runs parallel AI agents in isolated Docker containers for task coordination
- Supports automated code generation, testing, and maintenance
- Uses specialized agents (Coder, Tester, Maintainer) for role-based collaboration
- Provides a simple CLI for controlling agent teams and project status
- Integrates with multiple AI providers and supports git for version control
