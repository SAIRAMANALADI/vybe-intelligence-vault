## Summary
An unofficial Robinhood API mapping, CLI, and MCP server enabling terminal or agent-driven control of real Robinhood accounts with live reads and gated writes. It provides a comprehensive toolkit for trading, portfolio management, options strategies, and account automation.

## Key Features
- Comprehensive Robinhood API mapping with 300+ brokerage/account routes and verified endpoints
- Dual CLI and MCP server for human and agent-driven account control with identical functionality
- Live reads with dry-run gated writes for safety, including pending-duplicate dedup and ref_id idempotency
- Full options strategy support including chains, Greeks, multi-leg spreads, rolling, and selling
- Integrated memory and research system (ball-knowledge.md, trading-log.md) for agentic decision-making loops

## Why It Matters for RAG Builders
It enables secure, agent-driven automation of real trading accounts with live market access and gated execution, bridging the gap between research and actionable trades.
