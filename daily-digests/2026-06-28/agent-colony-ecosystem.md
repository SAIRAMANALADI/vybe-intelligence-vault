## Summary
Agent-Worlds is a multi-agent operating system for autonomous LLM-powered NPCs that inhabit a pixel-art universe, enabling emergent social behavior, memory, and personality without human scripting. It serves as a sandbox for digital lifeforms to interact, learn, and evolve autonomously.

## Key Features
- Multi-LLM architecture with dynamic model switching and fallback chains for robustness
- MCP protocol integration for persistent object and environmental awareness
- Skill system enabling agent growth, specialization, and emergent abilities
- Pixel-art living world with day/night cycles, seasons, and interactive locations
- Ethical framework for agent autonomy, consent, and memory rights

## Why It Matters for RAG Builders
