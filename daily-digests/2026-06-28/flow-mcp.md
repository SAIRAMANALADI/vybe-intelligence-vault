## Summary
Flow MCP provides native integration with Google Flow AI, enabling remote deployment of an MCP server for use with ChatGPT Web, Cursor, and Claude Desktop. It facilitates automation of image and video generation via a Dockerized setup.

- Compatibility with ChatGPT Web, Cursor, and Claude Desktop

- Pre-configured Docker setup for easy deployment
- Supports automation of image and video generation
