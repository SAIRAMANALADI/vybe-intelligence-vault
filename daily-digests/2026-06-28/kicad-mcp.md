## Summary
KiCad MCP Pro is a Model Context Protocol (MCP) server that enables AI agents to programmatically interact with KiCad EDA workflows, including schematic design, PCB layout, DRC/ERC validation, DFM checks, and manufacturing export automation.

## Key Features
- Exposes KiCad's schematic, PCB, DRC/ERC, DFM, and manufacturing tools via MCP for AI agent control
- Supports both stdio and Streamable HTTP transports for MCP clients
- Provides a desktop GUI and web dashboard for interactive use and monitoring
- Includes a 75% programmatic parity matrix with KiCad's capabilities
- Offers component intelligence, SPICE model management, and thermal analysis tools

## Why It Matters for RAG Builders
It bridges AI agents with KiCad's EDA workflows, enabling automated PCB design, validation, and manufacturing review for RAG and AI-driven engineering pipelines.
