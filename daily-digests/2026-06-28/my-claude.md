## Summary
my-claude is an all-in-one agent harness for Claude Code that dynamically orchestrates 200+ agents, 200+ skills, and 87 rules to automate task execution without manual configuration. It features a meta-orchestrator called Boss that discovers, classifies, matches, and delegates tasks to the most suitable specialist agents or skills.

## Key Features
- Dynamic runtime discovery and classification of agents, skills, and MCP tools
- Priority-based task routing with 4-tier matching system (P1-P4)
- Built-in 3-phase sprint workflow (Design → Execute → Review) for end-to-end feature implementation
- Integration with 8+ open-source agent frameworks and 200+ pre-built agents
- Multi-language support with internationalized READMEs and behavioral guidelines

## Why It Matters for RAG Builders
It provides a unified, zero-configuration framework for orchestrating hundreds of specialized agents and skills, drastically reducing the complexity of building and deploying AI-driven workflows for RAG and agentic systems.
