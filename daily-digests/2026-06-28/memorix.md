## Summary
memorix is a desktop application that enables persistent memory sharing for AI coding assistants, allowing users to maintain project context across tools like Cursor, Claude Code, and Copilot without repeating explanations. It acts as a bridge using the Model Context Protocol (MCP) to sync memories seamlessly.

## Key Features
- Cross-tool memory synchronization across AI coding assistants
- Automatic and persistent context retention for projects
- Multi-platform support (Windows, macOS, Linux)
- Lightweight and secure local data storage
- Seamless integration with popular AI tools like Cursor, Copilot, and Claude Code

## Why It Matters for RAG Builders
memorix eliminates the need to re-explain project details to AI coding assistants, significantly improving workflow efficiency and context retention for developers.
