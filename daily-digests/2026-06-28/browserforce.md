## Summary
BrowserForce enables AI agents to interact with a user's existing Chrome browser in real-time, providing controlled access to live sessions, logins, and cookies without requiring credential sharing. It supports both autonomous and manual browsing modes while prioritizing security through URL locking, read-only access, and auto-cleanup.

## Key Features
- Direct integration with a user's existing Chrome browser, inheriting all sessions and logins without credential extraction
- Supports both autonomous (Auto mode) and controlled (Manual mode) browsing for AI agents
- Full Playwright API support for advanced browser interactions and automation
- Security features including URL locking, read-only mode, block navigation, and auto-cleanup
- Compatible with OpenClaw, Claude, and any MCP-compatible agent via a dedicated MCP server

## Why It Matters for RAG Builders
BrowserForce eliminates the need for agents to handle credentials or isolated browser profiles, enabling secure, real-time web interaction with existing user sessions while maintaining full control over access and security.
