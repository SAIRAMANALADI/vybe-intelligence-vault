## Summary
my-codex is an all-in-one agent harness for OpenAI Codex CLI that provides a meta-orchestration layer (Boss) to dynamically discover, classify, match, and delegate tasks to 330+ pre-built agents and 200+ skills. It automates task routing with zero configuration, enabling seamless multi-agent collaboration and structured workflow execution.

## Key Features
- Dynamic runtime discovery of 330+ agents and 200+ skills via Boss meta-orchestrator
- Priority-based task routing with 4-phase delegation (P1-P4) for optimal agent matching
- Structured 3-phase sprint workflow (Design, Execute, Review) for end-to-end feature implementation
- Multi-model routing (o3 high, o3 medium, o4-mini) for task complexity alignment
- Weekly upstream sync and auto-discovery of new agents/skills with zero manual configuration

## Why It Matters for RAG Builders
It provides a turnkey orchestration layer for RAG/AI stacks by enabling dynamic, zero-config multi-agent collaboration and task delegation, drastically reducing integration overhead for complex workflows.
