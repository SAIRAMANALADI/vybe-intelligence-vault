## Summary
Hermes Starter is a clean, public-safe GitHub template designed to help users build a private Hermes Agent workspace from scratch. It provides a structured folder model for separating knowledge, operations, credentials, backups, and reusable instructions while ensuring no real secrets or private data are exposed.

## Key Features
- Public-safe GitHub template for Hermes Agent workspaces
- Structured folder model separating knowledge, operations, secrets, and recovery
- Detailed documentation on workspace hygiene, tool setup, and agent roles
- Placeholder-based examples for private configurations without exposing real data
- GitHub workflows for automated hygiene checks

## Why It Matters for RAG Builders
