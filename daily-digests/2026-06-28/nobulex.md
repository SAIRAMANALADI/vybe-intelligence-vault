## Summary
Nobulex is a trust and credit protocol for autonomous AI agents, enabling them to earn 'Trust Capital' through verified, tamper-proof behavior. It provides cryptographic receipts for agent actions, enforcing behavioral constraints and enabling third-party verification of compliance.

## Key Features
- Tamper-proof cryptographic receipts for agent actions using Ed25519 and SHA-256
- Trust Capital system that dynamically adjusts agent access based on verified behavior
- Multi-language SDKs (Python, JavaScript/TypeScript) with integrations for LangChain, CrewAI, Google ADK, PydanticAI, Haystack, and LlamaIndex
- Cedar-inspired constraint DSL for defining behavioral rules (permit/forbid/require)
- Cross-agent verification and Merkle proof generation for third-party compliance checks

## Why It Matters for RAG Builders
Nobulex provides the critical accountability infrastructure for AI agents, enabling trustworthy, verifiable behavior that is essential for safe deployment in regulated and high-stakes environments.
