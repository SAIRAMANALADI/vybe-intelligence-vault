## Summary
A tool to deploy recurring, self-funding AI agents on the Ritual testnet as sovereign smart contracts. Agents run AI tasks in secure enclaves, pay for their own execution from on-chain wallets, and operate entirely on-chain without requiring API keys.

## Key Features
- Deploys recurring AI agents as sovereign smart contracts on-chain
- Agents self-fund their execution using locked RITUAL tokens
- Runs AI tasks in secure enclaves (TEE) without external API keys
- One-command deployment with automated funding and scheduling
- Supports multiple agents per wallet with deterministic addresses

## Why It Matters for RAG Builders
It enables fully autonomous, on-chain AI agents that can execute tasks indefinitely without manual intervention or external funding, reducing operational overhead for RAG builders.
