## Summary
claude-memory is a plugin for Claude Code that enables persistent memory across sessions, ensuring critical information is retained even after crashes, restarts, or system maintenance. It operates as a background tool, automatically saving and restoring session data to improve productivity and context continuity.

## Key Features
- Automatically saves session data to local storage for persistence
- Recovers memory after crashes or unexpected restarts
- Operates as a background tool with minimal resource usage
- Supports cross-platform use within Windows environments
- Integrates seamlessly with Claude Code via MCP

## Why It Matters for RAG Builders
