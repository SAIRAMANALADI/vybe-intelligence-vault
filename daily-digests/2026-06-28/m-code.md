## Summary
Meyatu Code is a desktop autonomous AI coding agent built with Tauri 2 and React, enabling code reading, writing, execution, remote server operations via SSH, web research, and self-configuring automation without requiring built-in models.

## Key Features
- Multi-provider LLM support (OpenAI, Anthropic, Gemini, custom APIs) with API key stored in system keychain
- Advanced agent tools including code editing, Git/GitHub operations, semantic code retrieval, and MCP integration
- Native desktop performance with Tauri 2 + Rust backend, ensuring low resource usage and high efficiency
- SSH remote execution and web research capabilities as first-class features, enabling remote operations and information gathering
- Self-evolving automation with parallel sub-agents, global cross-project knowledge retention, and permission-controlled operations

## Why It Matters for RAG Builders
It provides a privacy-focused, high-performance desktop agent framework for AI-driven coding, automation, and remote operations, reducing reliance on cloud-based solutions.
