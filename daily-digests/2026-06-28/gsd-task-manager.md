## Summary
A privacy-first task manager leveraging the Eisenhower Matrix to help users prioritize tasks by urgency and importance. It operates entirely in the browser with optional cloud sync via PocketBase, offering advanced features like task dependencies, recurring tasks, and comprehensive analytics.

## Key Features
- Privacy-first task management with local storage (IndexedDB) and optional self-hosted cloud sync
- Eisenhower Matrix for prioritizing tasks by urgency and importance across four quadrants
- Advanced task features including dependencies, recurring tasks, subtasks, and batch operations
- Comprehensive analytics dashboard with completion metrics, quadrant distribution, and trend analysis
- PWA support with offline functionality, smart notifications, and keyboard shortcuts

## Why It Matters for RAG Builders
It provides a structured, privacy-focused framework for task prioritization and management, which can be integrated into AI workflows for better productivity tracking and automation.
