## Summary
A self-hosted personal AI butler for managing multiple projects via WeChat or CLI, featuring delegated agents, layered memory, and optional MCP extensions for coding and content tasks.

## Key Features
- Self-hosted WeChat gateway for natural language and slash command interactions
- Delegated task execution to specialized agents (development, content, review)
- Layered memory system (Owner profile, project memory, vector retrieval, ingest persistence)
- Project isolation with permission controls and human confirmation gates
- Optional MCP extensions for GitHub, Todoist, Firecrawl, and MarkItDown

## Why It Matters for RAG Builders
