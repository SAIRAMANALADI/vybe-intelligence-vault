## Summary
A Model Context Protocol (MCP) server that analyzes Java classes by scanning Maven dependencies, decompiling .class files, and providing detailed class structure information to LLMs for accurate code generation and analysis.

## Key Features
- Scans Maven project dependencies to build a class-to-JAR mapping index
- Decompiles .class files to Java source using CFR (included)
- Analyzes class structure, methods, fields, and inheritance relationships
- Provides intelligent caching for decompiled results to improve performance
- Integrates seamlessly with LLMs via MCP protocol for accurate code generation

## Why It Matters for RAG Builders
This tool bridges the gap between LLMs and Java dependencies by providing real-time decompilation and analysis of third-party libraries, eliminating hallucinations and improving code generation accuracy for AI-driven development workflows.
