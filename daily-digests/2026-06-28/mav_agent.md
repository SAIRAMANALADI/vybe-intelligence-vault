## Summary
A specialized AI agent that automates the purchase of Hungarian train tickets via Telegram using natural language processing and browser automation. It interprets user requests, searches for trains, and guides users through booking with confirmation steps.

## Key Features
- Natural language processing for Hungarian ticket requests via Grok API
- Stateful conversation flow with SQLite persistence
- Playwright-based browser automation for ticket booking
- Isolated payment credential handling
- Step-by-step user confirmation before transactions
