## Summary
t2000 is an open-source agentic stack for stablecoins on the Sui blockchain, enabling AI agents and developers to manage wallets, execute payments, and orchestrate financial flows programmatically. It provides a non-custodial, gasless infrastructure for USDC and USDsui transactions, API payments, and MCP server integration for LLM clients.

## Key Features
- Non-custodial Agent Wallet with gasless USDC/USDsui transactions
- Agent Payments via x402 protocol for API monetization without keys
- TypeScript SDK (`@t2000/sdk`) for programmatic wallet and payment control
- MCP server integration for LLM clients (Claude, Cursor, Windsurf)
- Built-in spending limits and transaction simulation for security
