## Summary
OpenCode Telegram Bot is a secure Telegram client for the OpenCode CLI that enables remote AI coding task execution, session management, and monitoring directly from a mobile device while keeping all operations local to the user's machine.

## Key Features
- Remote coding via Telegram with real-time session tracking
- Session management, model switching, and agent mode control
- Scheduled tasks for automated AI coding workflows
- Multi-language support (7 languages) and voice/audio prompt handling
- Secure local-first architecture with user ID whitelisting

## Why It Matters for RAG Builders
It enables AI engineers to remotely monitor and control local AI coding sessions via Telegram, bridging the gap between desktop AI tools and mobile accessibility without exposing APIs or open ports.
