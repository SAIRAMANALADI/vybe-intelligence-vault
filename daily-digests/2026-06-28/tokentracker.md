## Summary
TokenTracker is a local-first CLI and desktop application that automatically tracks and aggregates token usage across 25+ AI coding tools, providing real-time cost analysis and usage trends via a beautiful dashboard. It requires no cloud account, API keys, or manual setup.

## Key Features
- Auto-detects and tracks token usage across 25+ AI coding tools with zero manual configuration
- Provides a real-time, local dashboard for usage trends, cost breakdowns, and model analysis
- Supports native desktop apps for macOS (menu bar + widgets) and Windows (system tray)
- Offers optional cloud sync for cross-device usage aggregation and a global leaderboard
- Includes a skills manager for browsing and syncing 250+ public skills across multiple AI platforms

## Why It Matters for RAG Builders
TokenTracker helps AI engineers and developers monitor and optimize their AI tool usage costs locally, reducing cloud dependency and improving transparency in token consumption.
