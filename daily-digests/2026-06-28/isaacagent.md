## Summary
IsaacAgent is an AI-powered desktop agent designed to assist with Lua mod development for The Binding of Isaac: Repentance. It provides a Cursor/OpenCode-like experience with Isaac-specific tools, knowledge bases, and workflows to streamline mod creation.

## Key Features
- Chat-driven mod development with streaming responses and tool-calling for file operations, scaffolding, diagnostics, and API lookups
- Built-in Isaac API knowledge base (74 vanilla + 130+ REPENTOGON callbacks, classes, enums) and semantic search over 470+ embedded docs
- Multi-provider LLM support (OpenAI-compatible, Ollama) with encrypted credential storage and persistent chat history
- 15 specialized agent tools for file operations, XML validation, log parsing, and Isaac-specific workflows (e.g., item creation, debugging)
- Project-aware sandboxing, live log monitoring, visual diff viewer, and template-based project scaffolding

## Why It Matters for RAG Builders
IsaacAgent provides a specialized AI-driven workflow for Lua mod development in a niche but active game modding community, reducing the barrier to entry for complex modding tasks through integrated RAG and tool orchestration.
