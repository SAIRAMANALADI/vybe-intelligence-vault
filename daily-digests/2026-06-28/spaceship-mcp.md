## Summary
spaceship-mcp is an MCP server designed to simplify domain, DNS, contact, and marketplace management for the Spaceship API using AI automation. It provides a user-friendly interface for non-technical users to handle complex domain operations with AI guidance.

## Key Features
- AI-guided domain and DNS management with no programming required
- Secure handling of domain contacts and marketplace listings
- Cross-platform support for Windows, macOS, and Linux
- Encrypted API communications and secure credential storage
- Automated workflows for common domain operations
