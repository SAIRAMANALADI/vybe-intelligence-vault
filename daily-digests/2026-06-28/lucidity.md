## Summary
Lucidity is a personal assistant application that integrates with existing AI services to manage tasks, projects, and notes locally. It uniquely enables agent-mediated communication between users' assistants, allowing async, permission-graded interactions without direct messaging.

## Key Features
- Local-first task and project management with offline-first sync
- Agent-mediated communication between users' assistants with trust gradients
- Integration with existing AI services (Claude, ChatGPT) via MCP server
- Markdown-based notes vault with filesystem-native operations
- Cross-platform support (mobile, web, desktop) with Tauri/Electron

## Why It Matters for RAG Builders
Lucidity enables secure, async, and permission-controlled agent-to-agent communication, making it essential for building decentralized, user-owned AI ecosystems.
