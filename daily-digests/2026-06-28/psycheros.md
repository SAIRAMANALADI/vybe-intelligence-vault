## Summary
Psycheros is a persistent AI entity harness that enables a single AI entity to maintain a coherent identity, memory hierarchy, and knowledge graph across multiple interfaces. It includes a web UI, MCP server, and standalone tools for importing chat histories and managing entity persistence.

## Key Features
- Persistent AI entity with identity files and first-person voice consistency
- Hierarchical memory system (daily → weekly → monthly → yearly consolidation)
- Knowledge graph for tracking entities, places, and relationships
- MCP server (`entity-core`) enabling cross-interface coherence and tool access
- Pluggable LLM support with OpenAI-compatible endpoints and custom tools

## Why It Matters for RAG Builders
Psycheros provides a robust framework for building persistent, coherent AI entities with advanced memory and identity management, essential for RAG systems requiring long-term context retention and multi-interface deployment.
