## Summary
SWARM is a research framework for measuring emergent failures in multi-agent AI systems, focusing on systemic risks that arise from agent interactions rather than individual agent behavior. It provides tools to quantify and analyze risks like deception, coordination failures, and governance gaps in heterogeneous agent ecosystems.

## Key Features
- Interaction-level safety metrics (e.g., illusion delta, quality gaps)
- Reproducible multi-agent safety benchmarks with soft-label metrics
- Governance experiment framework (audits, staking, sanctions)
- Autoresearch-style experimental loops for parameter optimization
- CLI and interactive notebooks for rapid prototyping and analysis

## Why It Matters for RAG Builders
SWARM enables RAG builders to stress-test multi-agent systems for emergent risks and governance gaps before deployment, ensuring robustness in real-world heterogeneous agent ecosystems.
