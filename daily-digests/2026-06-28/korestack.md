## Summary
KoreStack is a local-first AI agent suite that integrates multiple productivity and data tools into a unified, browser-based interface. It enables users to interact with an AI agent, manage documents, spreadsheets, diagrams, code, and data feeds entirely offline without external dependencies.

## Key Features
- Unified local-first AI agent with integrated tools (document editor, spreadsheet, diagram tool, code editor, etc.)
- Modular architecture with separate services for data, communication, and task management
- Built-in RAG capabilities for document and knowledge base retrieval
- No browser extensions or external services required; runs entirely locally
- Centralized control plane for managing all services and their states

## Why It Matters for RAG Builders
KoreStack provides a cohesive, offline-capable AI agent framework with built-in RAG and productivity tools, reducing integration overhead for developers building local AI applications.
