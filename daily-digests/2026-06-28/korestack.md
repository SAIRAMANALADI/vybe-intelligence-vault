## Summary
KoreStack is a local-first AI agent suite that integrates multiple productivity and data tools into a unified, locally hosted system. It provides an agent interface, document editor, spreadsheet, diagram tool, code editor, data library, and communications hub, all running locally without browser extensions or opaque configurations.

## Key Features
- Unified local-first AI agent with integrated tools (document editor, spreadsheet, diagram tool, code editor)
- Modular service architecture with a control plane for managing all components
- Built-in RAG chunk store and data library for document and reference management
- No browser extensions or external dependencies required
- Self-contained workspace with structured and unstructured data separation

## Why It Matters for RAG Builders
KoreStack provides a cohesive local-first environment for AI agents to interact with productivity tools, making it essential for builders who need an integrated, self-hosted AI stack without external dependencies.
