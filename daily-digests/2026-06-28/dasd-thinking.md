## Summary
DASD-Thinking is a tool designed for enhanced reasoning in large language models (LLMs) using Distribution-Aligned Sequence Distillation (DASD) to improve long-chain-of-thought (Long-CoT) reasoning capabilities. It provides pre-trained checkpoints and a user-friendly interface for deploying reasoning-enhanced models.

## Key Features
- Implements Distribution-Aligned Sequence Distillation (DASD) for superior Long-CoT reasoning
- Provides pre-trained checkpoints (4B and 30B models) for enhanced reasoning
- Cross-platform support (Windows, macOS, Linux)
- User-friendly installation and offline usage capability
- Community-driven support and troubleshooting
