# Prompt Engineering

## What It Is

Prompt Engineering is the practice of structuring text inputs to Large Language Models to maximize generation quality, target specific schemas, and enforce reasoning boundaries.

## Why It Matters

Well-engineered prompts reduce downstream parsing failures, control costs through instruction efficiency, and unlock complex cognitive behaviors in smaller models.

## Core Topics

- Few-Shot and Zero-Shot In-Context Learning
- Chain of Thought (CoT) and ReAct Patterns
- Structured Generation via JSON Schema Enforcements
- Prompt Injection Vulnerabilities and Securing Inputs
