# Framer Motion

## What It Is

Framer Motion is a production-ready motion library for React that simplifies building physics-based layout animations and state transitions.

## Why It Matters

It enables smooth micro-interactions, exit/entry animations, layout transformations, and gesture recognitions that feel premium.

## Core Topics

- AnimatePresence and Entry/Exit Lifecycles
- Layout Animations and Shared Layout Transitions (layoutId)
- Gesture Controls (Drag, Hover, Tap, Scroll)
- Spring Physics vs Tween Configurations
