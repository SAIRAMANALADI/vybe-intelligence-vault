# GSAP

## What It Is

GreenSock Animation Platform (GSAP) is an ultra-high-performance HTML5 animation library that animates anything JavaScript can touch.

## Why It Matters

GSAP provides precise timeline sequencing, complex scroll-triggered choreographies, and superior performance for non-React websites.

## Core Topics

- Timelines and Tweens (to, from, fromTo, stagger)
- ScrollTrigger Choreography and Scrubbing Actions
- Text Manipulations (SplitText) and SVG Animations
- GSAP Contexts and Memory Cleanups in Modern Frameworks
