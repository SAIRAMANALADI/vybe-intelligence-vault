# Vector Databases

## What It Is

Specialized database management systems designed to store, index, and query high-dimensional vector embeddings efficiently.

## Why It Matters

Vector databases form the retrieval core of semantic search, recommendation engines, and long-term memory for AI agents.

## Core Topics

- Vector Embeddings and Similarity Metrics (Cosine, L2, Dot Product)
- Approximate Nearest Neighbor (ANN) Indexing (HNSW, IVF)
- Sparse vs Dense Retrieval Vectors
- Metadata Filtering and Hybrid Search Execution
