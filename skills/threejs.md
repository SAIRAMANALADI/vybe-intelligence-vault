# Three.js & WebGL

## What It Is

Three.js is a lightweight, cross-browser JavaScript library and application programming interface used to create and display animated 3D computer graphics in a web browser using WebGL.

## Why It Matters

It enables immersive, interactive 3D visualizations, interactive landing pages, games, and hardware-accelerated interfaces directly on the web without plugins.

## Core Topics

- WebGL Contexts, Renderers, and Canvas Layouts
- Scene, Cameras (Perspective vs Orthographic), and Lights
- Geometries, Materials, Textures, and Custom Shaders
- Matrix Transformations and Render Loops (requestAnimationFrame)
- React Three Fiber (R3F) Declarative Composition
