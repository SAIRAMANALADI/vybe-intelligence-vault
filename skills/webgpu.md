# WebGPU

## What It Is

WebGPU is a future-facing web API providing low-level, high-performance access to physical graphics processor units for rendering and general-purpose compute.

## Why It Matters

WebGPU unlocks hardware-accelerated compute shaders, local model execution (e.g. Transformers.js), and significantly lower overhead than WebGL.

## Core Topics

- WebGPU Adapter, Device, and Queue Architecture
- WGSL (WebGPU Shading Language) Syntax and Structs
- Render Pipelines, Compute Pipelines, and Bind Groups
- GPU Buffers and Memory Allocation Strategies
