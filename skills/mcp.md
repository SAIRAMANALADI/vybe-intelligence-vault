# Model Context Protocol (MCP)

## What It Is

The Model Context Protocol (MCP) is an open standard designed by Anthropic to enable secure, standardized data sharing and tool discovery between AI models and local or remote data sources.

## Why It Matters

MCP provides a unified way for LLMs to securely interact with file systems, databases, APIs, and dev tools without custom, ad-hoc integrations for every vendor.

## Core Topics

- MCP Server and Client Architecture
- Transport Protocols (SSE and stdio)
- Context Sharing (Prompts, Resources, Tools)
- Securing MCP Tools and Server Sandboxing
