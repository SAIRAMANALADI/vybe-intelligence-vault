# RAG

## What It Is

Retrieval-Augmented Generation (RAG) is an architectural pattern that optimizes the output of a Large Language Model by querying authoritative, external knowledge sources before generating responses.

## Why It Matters

RAG is crucial for mitigating hallucinations, grounding model responses in private or real-time data, and reducing costly API retraining requirements.

## Core Topics

- Semantic Search and Embedding Models
- Chunking Strategies and Document Parsing
- Hybrid Search and Dense/Sparse Retrieval
- RAG Evaluation Metrics (ROUGE, BLEU, Ragas)
- Hierarchical and Agentic Retrieval Patterns
