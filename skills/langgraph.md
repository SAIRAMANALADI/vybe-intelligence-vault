# LangGraph

## What It Is

LangGraph is a framework for building stateful, multi-actor applications with LLMs, enabling the design of cyclic agent workflows and complex execution trees.

## Why It Matters

Cyclic execution, agent collaboration networks, and deterministic routing paths are required to construct robust autonomous software agents.

## Core Topics

- State Graphs and Cyclic Workflows
- Multi-Agent Collaboration Architectures
- Human-in-the-loop State Interruption
- Persistence and Time-Travel Debugging
