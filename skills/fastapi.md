# FastAPI

## What It Is

FastAPI is a modern, fast (high-performance), web framework for building APIs with Python based on standard Python type hints.

## Why It Matters

It provides rapid API development speed, automatic OpenAPI documentation, asynchronous execution out of the box, and strict type safety.

## Core Topics

- Asynchronous Python (async/await)
- Pydantic Data Serialization and Verification
- OAuth2 and JWT Authentication Pipelines
- Dependency Injection Systems
