# React Three Fiber

## What It Is

React Three Fiber is a React renderer for Three.js. It allows developers to declare Three.js scenes using reusable, state-driven React components.

## Why It Matters

It brings React's declarative composition model, state bindings, hooks lifecycle, and package ecosystems directly to high-performance WebGL graphics.

## Core Topics

- Declarative Scene Composition and Canvas Component
- State Sharing via React Context and Hooks (useFrame, useThree)
- Performance Optimization (useLoader, Suspense, Preloading)
- Drei Helper Library (OrbitControls, Stage, KeyboardControls)
