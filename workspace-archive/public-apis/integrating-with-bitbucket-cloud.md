## Summary

- **Integration Options**: Bitbucket Cloud supports app integration via **Forge** (recommended for secure, scalable apps), **REST API** (for automation/scripting), or **Bitbucket Pipelines pipes** (for CI/CD integrations).

- **Forge-Specific Features**: Only Forge apps can implement **custom merge checks**, **dynamic pipeline providers**, and **project settings menu pages**, leveraging OAuth 2.0 for authentication and managed APIs for secure data access.

- **Security & Distribution**: Apps use
