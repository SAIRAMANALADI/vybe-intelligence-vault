## Summary

- **API Endpoint**: Single REST API (`POST /v1/audio/speech`) for TTS generation with configurable `voice_id`, `audio_format`, and `model` (e.g., `simba-3.2`).
- **Voice Cloning**: Supports cloning from 10-30s samples, with cloned voices usable across all supported languages and models.
- **Advanced Features**: Streaming (20k chars/request), SSML control (pitch/rate/emotion), speech marks (word-level timestamps), and multilingual support (30+ languages via `simba-multilingual`).
