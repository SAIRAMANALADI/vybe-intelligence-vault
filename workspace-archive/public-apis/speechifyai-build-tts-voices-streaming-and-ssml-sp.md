## Summary

- **API Integration**: Single REST API endpoint (`/v1/audio/speech`) supports TTS generation, voice cloning (10-30s sample), streaming (20k chars/request), and SSML control (pitch, rate, emotions, speech marks).
- **Model Support**: Four models (`simba-3.2`, `simba-3.0`, `simba-multilingual`, `simba-english`) with varying language coverage (English + 30+ languages) and features (e.g., `simba-3.2` optimized for low TTFB).
- **SDKs & Integrations**: Official Python/TypeScript SDKs; supports LiveKi
