## Summary

- **API Integration**: Single REST API endpoint (`/v1/audio/speech`) supports TTS generation with configurable `voice_id`, `audio_format` (e.g., MP3), and model selection (e.g., `simba-3.2`); requires `Authorization: Bearer` header with API key.

- **Advanced Features**: Supports real-time streaming (20k chars/request), voice cloning (10-30s sample), SSML for prosody control (pitch, rate, emotions), and speech marks for word-level timestamps.

- **Model/Language Matrix**: Offers multilingual mod
