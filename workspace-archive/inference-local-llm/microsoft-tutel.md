## Summary

- **Optimized MoE Library**: Tutel is a high-performance Mixture-of-Experts (MoE) library optimized for FP8/NVFP4/MXFP4 quantization, supporting models like GptOSS, DeepSeek, Kimi-K2, and Qwen3.
- **Key Features**: Implements efficient expert parallelism, dynamic routing, and memory optimizations for large-scale LLM training/inference.
- **Integration**: Designed for PyTorch, enabling seamless integration with modern MoE-based architectures and frameworks.
