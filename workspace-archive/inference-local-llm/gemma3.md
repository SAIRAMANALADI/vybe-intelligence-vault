## Summary

- **Model Architecture & Capabilities**: Google's Gemma 3 is a multimodal (text + vision) model family built on Gemini technology, supporting 128K context windows and 140+ languages, with parameter sizes ranging from 270M to 27B; quantization-aware training (QAT) reduces memory usage by 3x while maintaining BF16-level quality.

- **Performance Benchmarks**: Achieves strong results across reasoning (e.g., 85.6 HellaSwag for 27B), multilingual tasks (e.g., 74.3 MGSM for 27B), and multimodal tasks
