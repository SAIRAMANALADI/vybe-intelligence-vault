## Summary

- **New `crypto.Hash` template function** added to Hugo, supporting MD5, SHA1, SHA256 (default), SHA384, and SHA512 algorithms for hex-encoded checksum generation.
- **Integration with SRI hashing** enabled via `encoding.HexDecode` and `encoding.Base64Encode` for constructing Subresource Integrity (SRI) hashes from strings.
- **Documentation updates** include three new pages (`crypto.Hash`, `encoding.HexDecode`, `encoding.HexEncode`) with Go HTML template examples and usage instructions.
