## Summary

- **Milvus Lite** is a lightweight, embeddable version of Milvus designed for local development, supporting Ubuntu/MacOS environments for small-scale vector search applications.
- **API Compatibility**: Shares the same API as Milvus Standalone/Distributed but with limited features (e.g., no partitions, users/roles, or advanced indexing beyond FLAT).
- **Data Migration**: Supports exporting data via `milvus-lite dump` for seamless transition to Milvus Standalone, Distributed, or Zilliz Cloud.
