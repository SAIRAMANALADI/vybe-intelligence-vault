## Summary

- **Purpose & Scope**: The Vertex AI SDK for Python (`google-cloud-aiplatform`) automates data ingestion, model training, and predictions on the Gemini Enterprise Agent Platform, offering higher-level abstraction than the granular Gemini Enterprise Agent Platform Python client library.
- **Installation & Auth**: Install via `pip install --upgrade google-cloud-aiplatform`; authenticate locally with `gcloud auth application-default login` (Cloud Shell exempt) or federated identity for external IdP
