## Summary

- **MicroVM-based isolation**: Docker Sandboxes enforce strict runtime isolation via microVMs (e.g., SEV-SNP/TEE), locking down network/filesystem access per agent session, extending container-like isolation to AI agents.

- **Policy-driven governance**: Docker AI Governance enforces identity-bound policies (e.g., OPA/Rego), verifies signed images (SLSA L3, Cosign), and provides zero-setup audit trails for MCP/server interactions.

- **OCI-compliant, zero-lock-in stack**: Leverages existing OCI
