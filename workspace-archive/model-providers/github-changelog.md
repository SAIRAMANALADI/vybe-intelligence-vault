## Summary

- **Deprecation Announcement**: GitHub deprecated **Gemini 2.5 Pro** and **Gemini 3 Flash** models effective **July 31, 2026**, removing them from available options in GitHub Copilot.
- **Impact on Copilot**: Users relying on these models will need to transition to alternative supported models or features within GitHub Copilot.
- **GitHub Changelog Reference**: The deprecation is documented in GitHub’s official changelog under the [Copilot label](https://github.blog/changelog/2026/?label=copilot
