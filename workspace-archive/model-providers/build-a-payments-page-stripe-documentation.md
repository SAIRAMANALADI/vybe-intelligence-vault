## Summary

- **Checkout Sessions API** supports three UI options: **Full Page** (hosted/embedded), **Embedded Form**, and **Elements**, all using the same API but differing in hosting, customization, and complexity.
- **Full Page** mode provides the most built-in features (e.g., tax, billing, dynamic payment methods, order summary) with low maintenance, while **Elements** offers full CSS customization but lacks order summary and tax support.
- **Dynamic updates** (e.g., modifying checkout flow in real-time
