## Recommended Learning Path

1. **Perform semantic chunking based on semantic boundaries**
2. **Index documents in a local vector database such as LanceDB or Qdrant**
3. **Implement a dense-sparse hybrid retriever and query with reranking layers**
4. **Connect documents using GraphRAG relationships to capture complex entities**
