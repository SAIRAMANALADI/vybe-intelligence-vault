## Summary

- **Jetpack SceneCore** is an Android XR SDK for building and manipulating 3D scene graphs with support for ARCore integration, currently in **1.0.0-beta02** (as of August 12, 2026).
- **Key APIs** include `androidx.xr.scenecore` for scene graph management, `Entity` as the base class for all entities, and experimental/test APIs for spatial audio, GLTF models, and custom mesh rendering.
- **Recent changes** include renamed APIs (e.g., `AnchorEntity` → `AnchorSpace`), deprecated `ExrImage` in favo
