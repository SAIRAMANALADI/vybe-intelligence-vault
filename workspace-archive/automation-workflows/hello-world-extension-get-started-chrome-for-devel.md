## Summary

- **Manifest V3 Structure**: Chrome extensions require a `manifest.json` (V3) in the root directory, defining metadata (e.g., `"action"` for popup/toolbar icon) and permissions; changes to the manifest necessitate a full extension reload.
- **Development Workflow**: Load unpacked extensions via `chrome://extensions` (Developer Mode), debug popups via right-click → *Inspect*, and use `console.log` in `popup.js`; errors trigger an *Errors* button for diagnostics.
