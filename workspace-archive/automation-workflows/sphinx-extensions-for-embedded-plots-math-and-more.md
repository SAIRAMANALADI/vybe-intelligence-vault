## Summary

- **Sphinx Extension Integration**: Custom Sphinx extensions (e.g., `matplotlib.sphinxext.plot_directive`, `IPython.sphinxext.ipython_directive`) enable embedded plots, IPython session syntax highlighting, and math rendering in documentation via `conf.py` configuration.

- **Math Rendering Support**: Supports inline/display math via `sphinx.ext.mathjax`, `sphinx.ext.pngmath`, or `matplotlib.sphinxext.mathmpl`, with LaTeX-style syntax for equations.
