## Summary

- **Protocol Core**: MCP is an open protocol using JSON-RPC 2.0 for standardized communication between LLM hosts, clients, and servers, enabling contextual data sharing, tool exposure, and composable workflows.

- **Key Features**: Servers provide resources, prompts, and tools; clients support elicitation. Additional utilities include configuration, progress tracking, cancellation, and error reporting.

- **Security Principles**: Enforces explicit user consent for data access and tool invocation
