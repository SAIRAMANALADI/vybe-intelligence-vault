## Summary

- **Prerequisites**: Android Studio (latest), API level 23+ (Marshmallow), AndroidX Jetpack, `compileSdkVersion` 28+, Google Play services on device/emulator.

- **Option 1 (Firebase Console)**: Create Firebase project → Register Android app via package name → Download `google-services.json` → Add to `app/` directory → Integrate Firebase SDK via Gradle (`google-services` plugin).

- **Option 2 (Android Studio Assistant)**: Use built-in Firebase Assistant (may require additional SDK/plugin setup)

## Use Cases

- Local cron scheduling
- n8n pipeline setups
- OS task automations
