## Summary

- **GitHub CLI (`gh`)**: A free, open-source tool integrating GitHub workflows directly into the terminal, supporting commands like `gh issue list`, `gh pr status`, `gh release create`, and custom aliases (`gh alias set`).
- **Cross-platform installation**: Available via package managers (Homebrew, WinGet, apt, dnf, zypper) or direct downloads (`.deb`, `.rpm`, `.msi`, `.zip`, `.tar.gz`) for macOS, Windows, and Linux.
- **Enterprise & scripting support**: Compatible with GitHub Enterprise Server
