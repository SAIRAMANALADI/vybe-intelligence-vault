## Summary

- **Spaces** are ML demo hosting platforms on Hugging Face Hub, supporting Python (Gradio/Streamlit), Docker, and static HTML/JS deployments with GPU acceleration options.

- **Key features** include dependency management, GitHub Actions integration, disk/storage quotas, custom domains, OAuth, and MCP/agent tool compatibility.

- **Advanced configurations** support ZeroGPU, Dev Mode, API endpoints, embedded Spaces, and hardware-specific optimizations (e.g., Trainium/Inferentia).
