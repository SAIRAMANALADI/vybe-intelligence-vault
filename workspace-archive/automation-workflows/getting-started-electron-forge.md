## Summary

- **Electron Forge** is an all-in-one tool for packaging, distributing, and building Electron apps with built-in support for code signing, installers, and artifact publishing via a modular plugin system.
- **Packaging limitations**: Requires `node_modules` on disk; does not support Yarn PnP or symlinked dependencies—use `nodeLinker: node-modules` (Yarn ≥2) or `node-linker=hoisted` (pnpm) to ensure compatibility.
- **Templates & workflows**: Provides first-party templates (e.g., `webpack`, `vite`
