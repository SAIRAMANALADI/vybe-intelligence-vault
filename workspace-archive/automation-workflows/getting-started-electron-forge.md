## Summary

- **Electron Forge** is an all-in-one tool for packaging and distributing Electron applications, integrating build pipelines, code signing, installers, and artifact publishing via a modular plugin system.
- **Packaging limitations** include naive module resolution (no symlinks/PnP support); requires `node_modules` on disk and specific Yarn/pnpm configurations (`nodeLinker: node-modules` or `node-linker=hoisted`).
- **Templates** (e.g., `webpack`, `vite`) streamline project initialization with mo
