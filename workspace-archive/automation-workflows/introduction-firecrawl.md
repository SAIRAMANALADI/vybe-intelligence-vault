## Summary

- **Multi-format Web Scraping**: Firecrawl supports extracting web content in markdown, HTML, structured JSON, or raw links via a single API call, handling dynamic content and JavaScript rendering.
- **Web Search Integration**: Combines search and scraping into one workflow, returning full-page content (web, images, news) from search results with optional LLM-ready formatting.
- **Agent & CLI Support**: Provides a CLI tool for direct interaction (`npx firecrawl-cli@latest init --all --browser`)
