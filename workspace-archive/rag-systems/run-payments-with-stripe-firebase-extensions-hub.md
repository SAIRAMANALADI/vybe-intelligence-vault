## Summary

- **Ownership Transfer**: The Firestore Stripe Payments extension has been officially transferred from Stripe to Invertase for maintenance and updates.
- **Migration Required**: Users must uninstall the Stripe-maintained extension (`stripe/firestore-stripe-payments@0.3.4`) and install the Invertase version (`invertase/firestore-stripe-payments`) instead.
- **Technical Scope**: The extension synchronizes Stripe payments (one-time & subscriptions) with Firebase Authentication and Cloud Firestore,
