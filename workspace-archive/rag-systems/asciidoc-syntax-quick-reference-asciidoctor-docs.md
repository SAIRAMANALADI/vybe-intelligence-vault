## Summary

- AsciiDoc paragraphs are defined by one or more consecutive lines of text, with line breaks ignored; a blank line separates paragraphs.
- Text formatting in AsciiDoc supports constrained (`*bold*`, `_italic_`, `` `monospace` ``) and unconstrained (`**C**R**U**D`) syntax, along with `#highlight#`, `[.underline]#underline#`, and `[.line-through]#strikethrough#`.
- Cross-references use `xref:target.adoc#anchor[text]` syntax, while inline anchors are defined with `[[id]]` or `[#id]#text#`; document
