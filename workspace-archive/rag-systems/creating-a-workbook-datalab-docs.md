## Summary

- **Workbook Creation Methods**: DataLab workbooks (data projects) can be created via:
  - **Empty workbook** (via "New workbook" button)
  - **Templates** (pre-written code for common tasks)
  - **Datasets** (pre-loaded data + sample code)
  - **GitHub repositories** (via "Import from GitHub" in Code view)
  - **Copying existing workbooks** (via File > Make a Copy)

- **Personal vs. Group Workbooks**:
  - **Personal workbooks**: Default location, configurable via account selector; support publi
