## Summary

- **CSS `text-wrap: balance`** is an experimental property in Chrome Canary that automatically balances text lines (up to 4 lines) to prevent single words from appearing alone on a line, improving visual consistency.
- **Implementation** requires setting `text-wrap: balance` on the target element (e.g., `.c-hero__title { text-wrap: balance; }`), but does not alter the element’s `max-width` or container dimensions.
- **Use cases** include headlines, card titles, tooltips, modals, and FAQs, though
