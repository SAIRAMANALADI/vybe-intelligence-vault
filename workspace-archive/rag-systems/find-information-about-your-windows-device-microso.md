## Summary

- **Device Identification**: Retrieve device name and model via `Settings > System > About` or `ms-settings:about`, with model displayed directly below the device name.
- **Windows Version & Specifications**: Access Windows edition/version and device specs (processor, RAM, 32/64-bit) under `Settings > System > About` or `ms-settings:about`.
- **Storage Analysis**: View storage details via `Settings > System > Storage` or `ms-settings:storagerecommendations`, with additional drive metrics availab
