## Summary

- **GFM Specification**: GitHub Flavored Markdown (GFM) is a strict superset of CommonMark, defining syntax/semantics for GitHub.com and GitHub Enterprise, with extensions for unsupported CommonMark features.

- **Parsing Rules**: GFM resolves ambiguities in original Markdown (e.g., list indentation, blank lines before block quotes/headings) via a formal spec, ensuring consistent behavior across implementations.

- **Post-Processing**: GitHub applies additional sanitization/processing to GFM-con
