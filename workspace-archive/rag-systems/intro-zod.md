## Summary

- **TypeScript-first schema validation**: Zod provides a TypeScript-first approach to runtime validation with static type inference, enabling compile-time type safety and runtime validation through declarative schema definitions.

- **Core characteristics**: Zero external dependencies, 2KB gzipped bundle size, immutable API design, cross-platform compatibility (Node.js/browsers), and built-in JSON Schema conversion.

- **Requirements & ecosystem**: Requires TypeScript v5.5+ with `strict` mode en
