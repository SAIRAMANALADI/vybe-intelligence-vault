## Summary

- Deleting a file via **Docs/Sheets/Slides/Vids** home screen moves it to **Drive Trash**, retaining it until permanent deletion; collaborators retain access if the deleter is not the owner.
- **Owners** must transfer ownership before deletion to preserve shared access; otherwise, all collaborators lose access permanently.
- Alternative deletion methods include **File > Move to trash** (within the file) or **Drive > File name > Remove**.
