## Summary

- **Core Functionality**: `beamer` is a LaTeX class for creating presentations with support for both PostScript and direct PDF output, leveraging the `pgf` graphics system for visual effects.
- **Frame & Slide Management**: Content is structured within `frame` environments, with multi-slide frames supported via incremental overlays; includes optional short title/authors/institute parameters.
