## Summary

- **Modality-Aware Routing**: UniversalRAG dynamically selects modality-specific corpora for retrieval to mitigate the *modality gap*, where unified embedding spaces favor same-modality retrieval, improving cross-modal knowledge integration.

- **Multi-Granularity Retrieval**: The framework organizes each modality into hierarchical granularity levels, enabling adaptive retrieval tailored to query complexity and scope, enhancing precision across diverse tasks.
