## Summary

- **Modality-aware retrieval**: Introduces a routing mechanism to dynamically select modality-specific corpora, mitigating modality gaps in unified embedding spaces and improving retrieval relevance for heterogeneous queries.

- **Multi-granularity indexing**: Organizes each modality into hierarchical granularity levels, enabling adaptive retrieval granularity based on query complexity and scope.

- **Performance validation**: Demonstrates superiority over modality-specific and unified baselines
