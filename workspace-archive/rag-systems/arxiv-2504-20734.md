## Summary

- **Modality-Aware Routing**: UniversalRAG introduces a dynamic routing mechanism to select the most relevant modality-specific corpus for retrieval, addressing the *modality gap* problem where unified representation spaces favor same-modality retrieval, validated theoretically and empirically.

- **Multi-Granularity Retrieval**: The framework organizes corpora into hierarchical granularity levels (e.g., document → paragraph → sentence) to optimize retrieval granularity based on query complexity
