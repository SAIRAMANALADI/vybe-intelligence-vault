## Summary

- **Core Project**: `mem0` is an open-source Python-based universal memory layer for AI agents, enabling long-term memory integration with frameworks like LangChain, CrewAI, and AutoGen.

- **Key Repositories**:
  - `mem0-chrome-extension`: TypeScript-based extension providing long-term memory for LLMs (ChatGPT, Claude, etc.).
  - `memory-benchmarks`: Python suite for evaluating memory-augmented LLM systems (Apache-2.0 licensed).

- **Additional Tools**:
  - `mem0-mcp`: Python-based MCP server f
