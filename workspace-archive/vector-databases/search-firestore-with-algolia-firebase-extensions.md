## Summary

- **Functionality**: Indexes Firestore documents in a specified collection to Algolia for full-text, semantic, and vector search, syncing updates/deletions in real-time using Cloud Functions.
- **Requirements**: Requires a Firestore database, Algolia account, and Firebase Blaze plan; billed for Firestore, Cloud Functions, and Algolia usage.
- **Configuration**: Uses document IDs as Algolia object IDs and indexes only configured fields; initial sync occurs on install/reconfiguration.

## Use Cases

- Semantic search store
- Document embedding indices
- Memory vector caches
