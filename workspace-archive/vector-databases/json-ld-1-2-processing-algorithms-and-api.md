## Summary

- Defines JSON-LD 1.2 processing algorithms (expansion, compaction, flattening, RDF serialization/deserialization) and an API for programmatic transformations of JSON-LD documents, superseding JSON-LD 1.0/1.1 specifications.

- Operates on JSON-LD internal representation (maps, arrays, primitives) with APIs handling serialization/deserialization between concrete formats and internal structures.

- Introduces `@preserve` keyword for framing and enforces `json-ld-1.2` processing mode by default, r
