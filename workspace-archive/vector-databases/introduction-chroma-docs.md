## Summary

- **Multi-modal vector database**: Stores embeddings with metadata for text, images, audio, and other modalities, supporting dense, sparse, and hybrid vector search with full-text/regex filtering.
- **Flexible embedding integration**: Compatible with any embedding model (OpenAI, Cohere, Hugging Face, etc.) and offers metadata filtering at query time.
- **Open-source deployment**: Apache 2.0-licensed, deployable locally, self-hosted, or via managed Chroma Cloud with zero-ops scaling.

## Use Cases

- Semantic search store
- Document embedding indices
- Memory vector caches
