## Summary

- **On-device GenAI APIs**: ML Kit's GenAI APIs leverage **Gemini Nano** via **AICore** for local execution, enabling offline functionality, reduced latency, and improved privacy by processing data entirely on-device.
- **Supported Features & APIs**: Includes **Summarization**, **Proofreading**, **Rewriting**, **Image Description**, **Speech Recognition**, and **Prompt-based text generation**, with both **streaming** (incremental responses) and **non-streaming** (batch responses) modes.
