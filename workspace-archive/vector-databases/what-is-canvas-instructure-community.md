## Summary

- **Core Functionality**: Canvas is an open-source, web-based LMS enabling institutions to manage digital learning, with mobile access via dedicated apps (Canvas Teacher, Student, Parent) for iOS/Android.
- **Key Features**: Supports course content creation (Assignments, Discussions, Quizzes, Modules), analytics (Canvas Analytics, Data Services), assessment tools (SpeedGrader, rubrics, peer reviews), and integrations via LTI tools (Canvas App Center).
