## Summary

- Python HTTP library leveraging `urllib3` for automatic HTTP/1.1 keep-alive, connection pooling, and session management with cookie persistence.
- Supports advanced features including multipart file uploads, streaming downloads, chunked requests, SSL verification, proxies, and multiple authentication schemes (Basic, Digest, OAuth).
- Compatible with Python 3.10+ and PyPy, with a structured API for request/response handling, custom headers, timeouts, and event hooks.
