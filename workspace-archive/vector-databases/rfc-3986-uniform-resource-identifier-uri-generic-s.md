## Summary

- **URI Syntax Standardization**: RFC 3986 defines the generic syntax for Uniform Resource Identifiers (URIs), superseding prior RFCs (2396, 1808, 2732) and updating RFC 1738, establishing a unified framework for URI parsing, resolution, and comparison.

- **URI Components and Structure**: Specifies URI structure with components: `scheme://authority/path?query#fragment`, where `authority` includes optional user info, host, and port, and defines reserved, unreserved, and percent-encoded character
