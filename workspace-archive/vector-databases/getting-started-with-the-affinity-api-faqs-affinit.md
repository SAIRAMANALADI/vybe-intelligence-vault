## Summary

- **Affinity API Versions**: API V1 (Basic/Bearer Auth) remains available but receives no new investment; API V2 (Bearer Auth only) introduces a new platform with improved performance, OpenAPI spec, and an evolving feature set, though it lacks full parity with V1.
- **Access & Permissions**: API access (V1/V2) is restricted to **Scale**, **Advanced**, or **Enterprise** tiers; API key creation requires **Admin** or **Enterprise Admin** permissions, with role-based restrictions enforceable by Ente
