## Summary

- **Milvus Lite**: Lightweight, embeddable Python library (`pymilvus`) for local vector database operations, supporting rapid prototyping and development without external dependencies.
- **Vector Search & Metadata Filtering**: Enables semantic search via vector similarity (e.g., COSINE metric) and supports scalar field filtering (e.g., `subject == 'biology'`) for hybrid queries.
- **Deployment Flexibility**: Supports Milvus Lite (local file storage), Docker/Kubernetes (production), and seamless
