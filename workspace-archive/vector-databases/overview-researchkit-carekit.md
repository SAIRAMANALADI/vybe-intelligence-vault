## Summary

- **ResearchKit**: Open-source iOS framework enabling large-scale, remote health research via customizable modules for consent, surveys, and active evaluations (e.g., hearing/vision tasks), facilitating real-world data collection beyond traditional lab settings.

- **CareKit**: Open-source iOS framework designed for patient-centric care apps, integrating modules for symptom tracking, care plans, and patient-provider communication to improve adherence and outcomes outside clinical environments.

- Semantic search store
