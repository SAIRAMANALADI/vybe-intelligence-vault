## Summary

- **MDX**: A markdown-based format enabling JSX/React components within markdown files, leveraging the `unified`/`remark` ecosystem for extensible parsing and transformation.
- **Integration**: Supports React and Vue, allowing dynamic content composition via embedded components while maintaining markdown’s readability.
- **Tooling**: Provides a compiler (`@mdx-js/mdx`) to convert MDX to JavaScript/React/Vue components, with plugins for custom AST transformations and advanced use cases.
