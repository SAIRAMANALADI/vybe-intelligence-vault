## Summary

- **MediaPipe**: Prebuilt APIs for on-device AI tasks (e.g., background blur, face mesh, object detection) via Google's cross-platform ML stack.
- **LiteRT**: Hardware-accelerated runtime for deploying custom models (PyTorch, JAX, TensorFlow, Keras) across Android, iOS, Web, and embedded devices.
- **LiteRT-LM**: SDK enabling cross-platform execution of lightweight LLMs (e.g., for Chrome, Chromebooks, Pixel devices) with hardware optimization.
