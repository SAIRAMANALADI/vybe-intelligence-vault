## Summary

- **Checkly CLI** enables Infrastructure-as-Code (IaC) monitoring by embedding checks directly in repositories, allowing real infrastructure testing and deployment alongside application code.

- **Checkly MCP Server** provides runtime monitoring capabilities, enabling inspection of failed checks, asset retrieval, AI-driven analysis (e.g., Rocky AI), and automated re-execution of checks.

- **Integration Workflow**: CLI writes/tests monitoring, while MCP server handles live failure investigation
