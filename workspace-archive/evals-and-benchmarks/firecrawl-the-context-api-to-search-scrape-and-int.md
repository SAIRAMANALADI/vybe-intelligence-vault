## Summary

- **Real-time Monitoring**: Firecrawl's `/monitor` feature provides always-on search, pinging agents instantly when target URLs come online, enabling immediate data ingestion and interaction.

- **Multi-format Extraction**: Supports structured outputs (JSON, Markdown) and screenshots, with token-efficient parsing (93% fewer tokens) by excluding non-essential elements like navigation and ads.

- **Agent Integration**: Open-source SDK (Python/Node.js) and MCP/CLI support enable seamless connection
