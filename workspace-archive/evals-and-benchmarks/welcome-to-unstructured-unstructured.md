## Summary

- **Unstructured** converts unstructured/semi-structured data (e.g., documents) into structured, AI-ready formats (JSON, HTML, Markdown, text) with high performance and relevance.

- **Three core products**:
  - **Transform**: Local file parsing via APIs for AI agents/chatbots.
  - **Foundation**: Remote file indexing for fast retrieval in agentic workflows.
  - **Pipelines**: ETL pipelines (no-code or API-based) for DB/vector store integration.
