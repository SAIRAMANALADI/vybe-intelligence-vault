## Summary

- **Agent Architecture**: Speechify Agents provide a real-time voice interaction system via the Speechify API, enabling AI-driven conversations with reusable definitions including prompts, voices, tools, and evaluation criteria.
- **Core Features**: Supports low-latency real-time audio processing, tool integration (backend, device execution, MCP servers, or built-ins like `end_call`), transcript persistence with timestamps, and post-call LLM-graded evaluations.
