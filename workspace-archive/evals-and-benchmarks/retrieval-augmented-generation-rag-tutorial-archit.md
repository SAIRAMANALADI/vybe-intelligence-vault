## Summary

- **RAG Architecture**: Combines retrieval (vector/hybrid search), reranking (cross-encoder models), and LLM generation, with optional web search integration for dynamic knowledge augmentation.

- **Production Pipeline**: Ingestion (chunking, embedding, indexing) + Query (rewriting, retrieval, reranking, generation, logging/evaluation) with critical focus on reranking and evaluation for quality/cost trade-offs.

- **Advanced Techniques**: Supports multi-stage retrieval (DeepSearch), graph-based
