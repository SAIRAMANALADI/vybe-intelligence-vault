## Summary

- **Open-source vector database** storing both data objects and their vector embeddings, enabling semantic search via vector similarity rather than keyword matching.
- **Core capabilities** include semantic/hybrid search, retrieval-augmented generation (RAG) support, and agent-driven workflows for AI-native applications.
- **Deployment options** range from local (Docker/Embedded) to cloud-native (Weaviate Cloud, Kubernetes) with optional high availability and zero-downtime updates.
