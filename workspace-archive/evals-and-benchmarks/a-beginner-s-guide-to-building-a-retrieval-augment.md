## Summary

- **RAG Architecture**: Combines retrieval (e.g., Jaccard similarity) and generation (e.g., LLM) to enhance LLM outputs with external data, reducing hallucinations and enabling dynamic knowledge updates without retraining.

- **Core Components**: Requires a document corpus, user query, and similarity measure (e.g., Jaccard) to fetch relevant context, which is then passed to an LLM for response generation.
