## Summary

- **Gradual Typing Framework**: Python's type system supports **static, dynamic, and gradual typing**, enabling flexible type enforcement with explicit annotations while maintaining runtime flexibility via type erasure and materialization.

- **Structural & Nominal Typing**: Supports **structural subtyping (protocols)** and **nominal subtyping (class inheritance)**, with variance rules (covariant/contravariant/invariant) for generics like `TypeVar`, `ParamSpec`, and `TypeVarTuple`.
