## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source) with optional CUDA-accelerated PyTorch; editable installs available for development.

- **Core Functionality**: Provides `SentenceTransformer` (bi-encoder), `CrossEncoder` (cross-attention for re-ranking), and `SparseEncoder` (lexical/sparse retrieval) with modular architectures for custom model creation.

- **Advanced Features**: Includes semantic search, clustering, paraphrase mining, quantization
