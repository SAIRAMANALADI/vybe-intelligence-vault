# Evals and Benchmarks

Evaluation tools and benchmarks for LLMs, RAG systems, agents, prompts, hallucinations, and SWE tasks.

## Why It Matters

Rigorous evaluations protect against regressions in model behavior, prompt drift, and agent logic.
