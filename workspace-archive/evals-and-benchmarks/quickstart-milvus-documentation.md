## Summary

*   Milvus is an open-source vector database designed for AI applications, facilitating high-performance similarity search and Retrieval Augmented Generation (RAG) by storing and querying high-dimensional vector embeddings.
*   It offers flexible deployment options including an embedded Milvus Lite (via `pymilvus`), Docker, and Kubernetes, all exposing a unified API for vector CRUD operations and advanced search functionalities.
