## Summary

- **CaMeL** introduces a protective system layer around LLMs to mitigate prompt injection attacks by explicitly separating control and data flows from trusted queries, preventing untrusted data from altering program execution.
- Implements **capability-based security policies** to restrict unauthorized data exfiltration during tool calls, enforcing strict access controls on private data.
