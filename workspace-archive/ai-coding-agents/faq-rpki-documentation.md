## Summary

- **RPKI Overview**: RPKI (Resource Public Key Infrastructure) is an IETF-developed cryptographic framework to validate BGP route origins by binding IP prefixes to AS numbers via cryptographically signed Route Origin Authorizations (ROAs), mitigating route hijacks and leaks.

- **ROA Validation Mechanics**: RPKI uses X.509 PKI to issue ROAs, where each ROA specifies an AS authorized to originate a prefix with a defined maximum prefix length, enabling cryptographic validation of BGP announcements
