## Summary

- **Local & Cloud Deployment**: Ollama enables execution of open-source LLMs locally or via cloud instances (US, EU, SG), supporting offline operation for sensitive workloads.

- **CLI/API Integration**: Provides a CLI (`ollama`) for agent launches (e.g., Claude Code, OpenCode) and API-driven integration with editors/frameworks (e.g., VS Code, LangChain).

- **Open Model Ecosystem**: Hosts trending models (e.g., `glm-5.2`, `deepseek-v4-flash`) with open weights, permissive licensing, and no data
