## Summary

- **Agent Skills**: Universal Pinecone skills library enabling agentic IDEs (e.g., GitHub Copilot, Codex) to interact with Pinecone via standardized skills.
- **Airbyte Integration**: Enables ETL pipelines from 300+ data sources (databases, SaaS, warehouses) into Pinecone for vector search and RAG workflows.
- **LangChain Integration**: Provides a framework for chaining LLM-based workflows with Pinecone’s vector database for advanced retrieval and reasoning tasks.
