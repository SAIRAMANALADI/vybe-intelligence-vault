# Agent Instructions

Repository instruction files and coding-agent rule formats such as AGENTS.md, CLAUDE.md, cursor rules, and copilot instructions.

## Why It Matters

Structured repository instruction files (CLAUDE.md, Cursor rules) are critical for grounding coding agents in local design conventions and preventing hallucinations.
