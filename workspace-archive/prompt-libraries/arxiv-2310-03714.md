## Summary

- **DSPy Programming Model**: Introduces a declarative framework for constructing LM pipelines as parameterized computational graphs, abstracting LM calls into modules that can learn optimal prompting, fine-tuning, and reasoning strategies via demonstrations.

- **Self-Optimizing Compiler**: Implements a compiler that automatically optimizes DSPy pipelines to maximize user-defined metrics, enabling self-improving LM workflows without manual prompt engineering.
