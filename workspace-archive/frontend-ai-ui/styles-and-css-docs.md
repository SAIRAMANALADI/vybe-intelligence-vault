## Summary

- Astro supports scoped styles via `<style>` tags with automatic scoping (e.g., `h1 {}` compiles to unique selectors), preventing style leakage while preserving specificity boundaries.
- CSS can be imported via ESM (supports `.css`, `.scss`, `.styl`, etc.), npm packages (with `vite.ssr.noExternal` config for SSR), or loaded statically via `<link>` in `/public`.
