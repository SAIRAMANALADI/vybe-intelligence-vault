## Summary

- JavaScript's lexical analysis converts raw source text into atomic tokens (identifiers, keywords, literals, operators) while discarding insignificant whitespace, comments, and line terminators, with the latter influencing automatic semicolon insertion.

- Identifiers in JavaScript follow Unicode standards (ID_Start/ID_Continue categories), allowing non-ASCII characters (e.g., U+200C/ZWNJ, U+200D/ZWJ) post-first character, and must exclude numeric starts.

- Comments in JavaScript include `//`
