## Summary

- **Incremental Parsing Engine**: Tree-sitter is a parser generator and incremental parsing library written in C11, designed to generate concrete syntax trees (CSTs) for source files and efficiently update them in real-time during edits, enabling sub-10ms parsing latency for typical editor workloads.

- **Multi-Language Ecosystem**: Supports official bindings for C#, Go, Haskell, Java (JDK 22+), JavaScript (Node.js/Wasm), Kotlin, Python, Rust, Swift, and Zig, with additional third-party bindings
