## Categories Needing More Coverage

These categories have very low resource counts in the current vault run and require additional signal detection and manual/automated indexing.

### Agent Instructions
- **Why this category matters**: Standardized instructions like `.cursorrules`, `CLAUDE.md`, or custom agent prompts govern how LLMs interact with codebases and execute tasks. Having a rich repository of these instructions helps developers build highly optimized system behaviors.
- **What to collect next**: High-quality `.cursorrules` files, custom system instruction guides, framework-specific rule sheets, and developer guidelines for AI agents.
- **Suggested search terms / files**:
  - `AGENTS.md`
  - `CLAUDE.md`
  - `GEMINI.md`
  - `cursor rules`
  - `windsurf rules`
  - `copilot-instructions.md`

### Public APIs
- **Why this category matters**: Modern AI applications and agent tools rely heavily on external REST/GraphQL APIs, especially those with minimal authentication friction.
- **What to collect next**: Public developer API lists, free/no-auth AI tool APIs, open endpoints, and public-interest data feeds suitable for agent integration.
- **Suggested search terms / files**:
  - public API directories
  - free APIs
  - AI app APIs
  - developer APIs
  - no-auth APIs

### Prompt Libraries
- **Why this category matters**: Well-structured prompts are the foundation of effective LLM orchestration. Standard libraries of system, coding, and role-play prompts help prevent LLM drift.
- **What to collect next**: Production-grade system prompts, developer template libraries, and specialized agent prompt templates.
- **Suggested search terms / files**:
  - system prompts
  - coding prompts
  - agent prompts
  - prompt templates

### Jobs Market
- **Why this category matters**: Tracking job descriptions (JDs) for AI and LLM roles gives insights into industry trends, required skills, and technology adoption signals.
- **What to collect next**: Representative job descriptions, core competency checklists, and hiring trends for AI/LLM engineering positions.
- **Suggested search terms / files**:
  - AI engineer JD
  - RAG engineer JD
  - agent engineer JD
  - LLMOps roles
  - AI frontend roles
