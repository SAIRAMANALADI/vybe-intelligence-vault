# Use for Agent Projects

This guide explains how to use the Vybe Intelligence Vault to plan agent-based systems, select orchestration frameworks, and build workflows.

## Selecting Agent Orchestration

To choose the right agent framework:
- Navigate to `workspace-archive/agent-frameworks/README.md` to see the top matched agent libraries.
- Review `maps/agent-stack-map.md` to understand loops, state graphs, and memory patterns.
- Check `learning-paths/7-day-agent-builder.md` for a week-long implementation plan.

## Example Prompt

Use this prompt to compare frameworks for a production workflow:

```text
Use this vault to compare LangGraph, CrewAI, and AutoGen for a production agent workflow.
```
