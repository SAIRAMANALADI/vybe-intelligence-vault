# Use for Startup Ideas

This guide explains how to use the Vybe Intelligence Vault to find, validate, and build AI-powered micro-SaaS startups.

## Finding Startup Projects

To explore startup and MVP concepts:
- Navigate to `workspace-archive/startup-builder/README.md` to see the top matched startup frameworks and tools.
- Review `build-ideas/startup-mvp-projects.md` and `build-ideas/ai-saas-projects.md` for pre-defined project models.
- Check `learning-paths/7-day-ai-saas-builder.md` for a 7-day startup launching program.

## Example Prompt

Use this prompt to find SaaS opportunities:

```text
Use this vault to find AI SaaS project ideas using RAG, agents, and automation.
```
