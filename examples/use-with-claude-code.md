# Use with Claude Code

This guide explains how to use the Vybe Intelligence Vault with Claude Code (Anthropic's command-line AI coding agent).

## Reading Vault Files in Claude Code

Claude Code can analyze local file structures and run commands:
- Start Claude Code in the vault directory.
- Ask Claude to search for specific files, keywords, or tags.
- Claude can automatically parse files, read metadata, and generate configurations.

## Example Prompts

Here is a prompt template you can use:

```text
Find all files in workspace-archive/rag-systems/ that mention 'hybrid search' and compile a list of their titles and source URLs.
```
