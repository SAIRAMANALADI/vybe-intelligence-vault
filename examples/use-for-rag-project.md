# Use for RAG Projects

This guide explains how to use the Vybe Intelligence Vault to find vector retrieval ideas, select technologies, and implement a RAG project.

## Finding RAG Ideas

To explore RAG resources:
- Navigate to `workspace-archive/rag-systems/README.md` to see the top matched RAG resources.
- Review `build-ideas/rag-projects.md` for pre-defined project templates.
- Check `learning-paths/7-day-rag-builder.md` for a structured weekly curriculum.

## Example Prompt

Use this prompt to outline a RAG project:

```text
Use this vault to find the best RAG project ideas and create a 7-day build plan.
```
