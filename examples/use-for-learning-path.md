# Use for Learning Paths

This guide explains how to use the Vybe Intelligence Vault to structure your developer learning, master new stacks, and complete portfolio projects.

## Choosing a Path

To select a study plan:
- Navigate to `learning-paths/README.md` to see the available 7-day programs.
- Choose a track such as `7-day-ai-engineering.md` or `7-day-mcp-builder.md`.
- Follow the day-by-day objectives to build a working project by Day 7.

## Example Prompt

Use this prompt to organize a custom study path:

```text
Help me choose a 7-day learning path from the vault. I want to build a local Model Context Protocol server that queries system APIs. Output the plan day-by-day.
```
