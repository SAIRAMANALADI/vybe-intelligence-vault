# 3D Web Dev Map

## Overview
Modern WebGL, WebGPU, and 3D animations for creative creative interfaces.

## Core Concepts
Scene graphs, camera constraints, shaders, layout grids, animations.

## Key Tools and Frameworks
Three.js, React Three Fiber (R3F), GSAP, WebGPU, Spline.
