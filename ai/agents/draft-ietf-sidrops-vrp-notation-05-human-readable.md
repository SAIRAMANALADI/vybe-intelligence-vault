# draft-ietf-sidrops-vrp-notation-05 - Human Readable Validate ROA Payload Notation

## Summary

- **Purpose**: Defines a human-readable ABNF-based notation for Validated ROA Payloads (VRPs) per [RFC6811](https://datatracker.ietf.org/doc/html/rfc6811) to standardize RPKI tooling and documentation output.
- **Syntax**: Notation format is `vrp-prefix separator origin-asn`, where `vrp-prefix` supports IPv4/IPv6 CIDR (with optional max-length) and `origin-asn` is an AS number in `AS<decimal>` format (e.g., `192.0.2.0/24 => AS65000`).
- **Scope**: Informational RFC; implementations may adopt or extend this notation for RPKI CA CLI/configuration and interoperability.
