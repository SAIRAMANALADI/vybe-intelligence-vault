# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub workflows directly into the terminal, enabling CLI-based interaction with issues, PRs, releases, and repository metadata without context switching.

- **Core commands** include `gh issue list`, `gh pr status/checkout/create/checks`, `gh release create`, `gh repo view`, and `gh alias set`, with Copilot CLI (`gh copilot`) providing AI-assisted task automation and repository-specific instructions.

- **Cross-platform support** via package managers (Homebrew, WinGet, `apt`/`dnf`/`zypper`) or direct downloads (`.deb`/`.rpm`/`.zip`/`.msi`/`.tar.gz`), with enterprise compatibility for GitHub Enterprise Server.
