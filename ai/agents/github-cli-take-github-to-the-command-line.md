# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** integrates GitHub workflows directly into the terminal, supporting commands like `gh issue list`, `gh pr status`, `gh pr checkout`, `gh pr create`, `gh pr checks`, `gh release create`, `gh repo view`, and `gh alias set` for streamlined repository management.
- **Installation** is cross-platform via package managers (`brew install gh` for macOS, `winget` for Windows, `apt`/`dnf`/`zypper` for Linux) or direct binary downloads (`.deb`, `.rpm`, `.msi`, `.zip`, `.tar.gz`).
- **Enterprise compatibility** is supported, enabling connections to GitHub Enterprise Server alongside GitHub.com, with scripting via API and custom aliasing for workflow automation.
