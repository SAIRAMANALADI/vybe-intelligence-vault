# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub functionality directly into the terminal, enabling operations like `issue list`, `pr status`, `pr checkout`, `pr create`, `release create`, and `repo view` without leaving the command line.
- **Supports scripting and customization** via GitHub API calls and aliasing (e.g., `gh alias set bugs 'issue list --label="bugs"'`), while also providing enterprise compatibility with GitHub Enterprise Server.
- **Installation methods** include package managers (Homebrew, WinGet, `apt`, `dnf`, `zypper`) and direct downloads (`.deb`, `.rpm`, `.tar.gz`, binaries/MSI), with `brew install gh` as the macOS example.
