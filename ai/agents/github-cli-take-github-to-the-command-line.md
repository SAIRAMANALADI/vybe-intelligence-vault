# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub workflows directly into the terminal, enabling CLI-based interaction with repositories, issues, pull requests, releases, and checks.
- **Key commands** include `gh copilot` (AI-assisted task automation), `gh issue list` (filterable issue listing), `gh pr status` (PR status overview), `gh pr checkout` (local PR branch switching), `gh pr create` (interactive PR creation), `gh pr checks` (CI/CD status verification), `gh release create` (release management), and `gh repo view` (repository metadata display).
- **Installation** is supported via package managers (e.g., `brew install gh` for macOS, `winget` for Windows) or direct downloads (`.deb`, `.rpm`, `.tar.gz`, binaries/MSI), with enterprise compatibility via GitHub Enterprise Server configuration.
