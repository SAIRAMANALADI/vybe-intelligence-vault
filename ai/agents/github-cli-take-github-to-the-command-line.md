# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub workflows directly into the terminal, supporting commands like `gh issue list`, `gh pr status`, `gh pr checkout`, `gh pr create`, `gh release create`, and `gh repo view` for streamlined repository management.

- **Installation** is cross-platform via package managers (Homebrew, WinGet, `apt`, `dnf`, `zypper`) or direct downloads (`.deb`, `.rpm`, `.zip`, `.msi`, `.tar.gz`), with `brew install gh` as the macOS default.

- **Advanced features** include GitHub Copilot CLI integration, custom aliases (e.g., `gh alias set bugs 'issue list --label="bugs"'`), API scripting, and GitHub Enterprise Server support for end-to-end workflow automation.
