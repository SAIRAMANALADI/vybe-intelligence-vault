# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** integrates GitHub workflows directly into the terminal, enabling operations like `gh issue list`, `gh pr status`, `gh pr checkout`, `gh pr create`, `gh pr checks`, `gh release create`, `gh repo view`, and `gh alias set` without leaving the command line.
- **Cross-platform installation** is supported via package managers (`brew install gh` for macOS, `winget` for Windows, `apt`, `dnf`, and `zypper` for Linux) or direct binary downloads (`.deb`, `.rpm`, `.tar.gz`, `.msi`, `.zip`).
- **Extensible functionality** includes GitHub Copilot CLI integration, custom aliases, and GitHub Enterprise Server compatibility for scripting and automating GitHub workflows.
