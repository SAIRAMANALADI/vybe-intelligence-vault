# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub workflows directly into the terminal, supporting commands like `gh issue list`, `gh pr status`, `gh pr create`, and `gh release create` for streamlined repository management.

- **Installation** is supported across platforms via package managers (`brew install gh` for macOS, `winget` for Windows, `apt`/`dnf`/`zypper` for Linux) or direct binary downloads (`.deb`, `.rpm`, `.zip`, `.msi`, `.tar.gz`).

- **Advanced features** include GitHub Copilot CLI integration, custom aliases (e.g., `gh alias set bugs 'issue list --label="bugs"'`), GitHub Enterprise Server compatibility, and API scripting for automation.
