# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub functionality directly into the terminal, supporting commands like `gh issue list`, `gh pr status`, `gh release create`, and custom aliases (e.g., `gh alias set bugs 'issue list --label="bugs"'`).

- **Cross-platform installation** is supported via package managers (Homebrew, WinGet, `apt`, `dnf`, `zypper`) or direct downloads (`.deb`, `.rpm`, `.msi`, `.zip`, `.tar.gz`) for macOS, Windows, and Linux.

- **Enterprise compatibility** is enabled through GitHub Enterprise Server integration, allowing scripting via the GitHub API and customization of workflows (e.g., Copilot CLI for AI-driven task automation).
