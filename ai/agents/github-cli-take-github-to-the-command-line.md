# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub workflows directly into the terminal, enabling operations like issue/PR management (`gh issue list`, `gh pr status`), repository viewing (`gh repo view`), and release creation (`gh release create`) without leaving the command line.
- **Supports multi-platform installation** via package managers (Homebrew, WinGet, `apt`, `dnf`, `zypper`) or direct downloads (`.deb`, `.rpm`, `.zip`, `.msi`, `.tar.gz`), with version `2.96.0` as the latest stable release.
- **Extensible features** include GitHub Copilot CLI integration, custom aliases (`gh alias set`), API scripting, and GitHub Enterprise Server compatibility for enterprise workflows.
