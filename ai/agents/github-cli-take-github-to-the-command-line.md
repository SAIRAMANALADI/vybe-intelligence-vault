# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** is a free, open-source tool that integrates GitHub functionality directly into the terminal, supporting commands like `gh issue list`, `gh pr status`, `gh pr checkout`, `gh pr create`, `gh pr checks`, `gh release create`, `gh repo view`, and `gh alias set` for workflow automation.

- **Cross-platform installation** is supported via package managers (`brew install gh` for macOS, `winget` for Windows, `apt`, `dnf`, or `zypper` for Linux) or direct binary downloads (`.deb`, `.rpm`, `.tar.gz`, `.msi`, `.zip`).

- **Enterprise compatibility** is enabled through GitHub Enterprise Server integration, and advanced features include GitHub Copilot CLI for AI-assisted tasks, custom command aliases, and API scripting for extended automation.
