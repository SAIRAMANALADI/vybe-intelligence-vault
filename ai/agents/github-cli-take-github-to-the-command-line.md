# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** provides a command-line interface to interact with GitHub repositories, enabling operations like issue management (`gh issue list`), pull request handling (`gh pr status/checkout/create/checks`), and release creation (`gh release create`) directly from the terminal.

- **Installation** is supported across multiple platforms via package managers (e.g., `brew install gh` for macOS, `winget` for Windows) or direct downloads (`.deb`, `.rpm`, `.msi`, `.zip`, `.tar.gz`) from GitHub releases.

- **Advanced features** include GitHub Copilot CLI integration, custom command aliases (e.g., `gh alias set bugs 'issue list --label="bugs"'`), API scripting capabilities, and compatibility with GitHub Enterprise Server.
