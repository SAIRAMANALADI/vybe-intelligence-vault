# GitHub CLI | Take GitHub to the command line

## Summary

- **GitHub CLI (`gh`)** integrates GitHub workflows directly into the terminal, supporting commands like `gh issue list`, `gh pr status`, `gh pr checkout`, `gh pr create`, `gh pr checks`, `gh release create`, and `gh repo view` for streamlined repository management.
- **Installation** is cross-platform via package managers (e.g., `brew install gh` for macOS, `winget` for Windows, `apt`/`dnf`/`zypper` for Linux) or direct binary downloads for Linux/macOS/Windows.
- **Customization** includes aliasing (e.g., `gh alias set bugs 'issue list --label="bugs"'`) and API scripting, with enterprise support for GitHub Enterprise Server and Copilot CLI integration for AI-assisted workflows.
