# Cline - AI Coding, Open Source and Uncompromised

## Summary

- **Multi-Model Agent Runtime**: Open-source agent framework supporting 10+ LLM providers (Claude, GPT, Gemini, local Ollama/LM Studio) with no vendor lock-in, enabling cross-platform IDE/terminal/SDK integration via CLI, VS Code extension, JetBrains plugin, or SDK embed.

- **Plan-and-Act Workflow**: Implements a Plan mode for strategy alignment followed by Act mode for execution, with linter-aware multi-file edits, bash command execution, and one-click undo, while supporting .clinerules for custom coding standards and MCP plugins for tool integration.

- **Enterprise Features**: Supports multi-agent teams, scheduled cron jobs, and CI/CD pipeline integration (GitHub Actions, GitLab), with Slack/Linear/Discord connectors and 8M+ installs across macOS/Windows/Linux.
