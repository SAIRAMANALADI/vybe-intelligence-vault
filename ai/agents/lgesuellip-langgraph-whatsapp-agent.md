# lgesuellip/langgraph-whatsapp-agent

## Summary

- **Framework Integration**: Template for deploying AI agents on WhatsApp using **LangGraph** (graph-based workflows) and **Twilio** (WhatsApp API integration) in Python.

- **Multi-Modal Processing**: Supports text and image inputs, enabling agents to handle both message content and attachments via WhatsApp.

- **Platform & Extensibility**: Runs on **LangGraph Platform**, integrates with **MCP (Model Context Protocol)**, and allows custom graph-based agent logic for dynamic interactions.
