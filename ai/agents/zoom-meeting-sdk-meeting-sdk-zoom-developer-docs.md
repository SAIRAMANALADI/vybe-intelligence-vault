# Zoom Meeting SDK - Meeting SDK - Zoom Developer Docs

## Summary

- **Authorization Requirements**: Starting March 2, 2026, apps joining external meetings must use ZAK, OBF tokens, or RTMS for authorization; SDK JWT is required for secure credential transmission during meeting/webinar joins.
- **Platform Support & UI Customization**: Supports Android, iOS, macOS, Windows, Web, Electron, Linux, Unreal, and React Native; offers default/native UI for mobile/desktop and client/component views for web integration.
- **Raw Data Access & Compliance**: Provides direct access to raw video/audio data on native platforms for advanced use cases; enforces minimum SDK versions, Zoom’s license model, and network connectivity requirements.
