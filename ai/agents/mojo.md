# Mojo

## Summary

- **Language Design**: Mojo combines Python-like syntax with Rust-like memory safety and Zig-like compile-time metaprogramming, targeting high-performance AI/GPU systems via static typing and compilation.

- **GPU & Python Interop**: Enables vendor-agnostic GPU kernel programming in the same language as CPU code, with seamless Python interoperability for incremental performance optimization.

- **Open-Source Roadmap**: Standard library is open-source; compiler planned for 2026, with phased evolution from kernel programming (Phase 1) to systems programming (Phase 2) and dynamic OOP (Phase 3).
