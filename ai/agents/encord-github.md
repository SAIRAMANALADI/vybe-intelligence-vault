# Encord · GitHub

## Summary

- **Encord Python API Client**: Provides programmatic access to Encord's platform for AI data annotation and model training, supporting automated workflows via `encord-client-python` (Apache-2.0 license).

- **AI Agent Framework**: `encord-agents` enables deployment of autonomous agents for tasks like automated data labeling, QA, and workflow orchestration within Encord's ecosystem.

- **Multimodal AI Datasets & Models**: Hosts datasets like **E-MM1** (100M cross-modal connections) and models like **ebind** (5-way embedding for text, audio, image, video, and 3D point clouds).
