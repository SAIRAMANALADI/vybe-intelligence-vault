# Overview | Netlify Docs

## Summary

- **Agent Runners**: Enables AI-driven project creation/updates directly from the Netlify dashboard without local setup, integrating with tools like Claude Code or Codex via agent setup guides.
- **AI Gateway**: Provides seamless access to popular AI models within projects via Netlify’s infrastructure, eliminating manual API key management.
- **MCP Server & Prerendering**: Supports context-sharing for AI tools via the Netlify MCP Server and ensures SPA content accessibility to AI crawlers using the Prerender extension.
