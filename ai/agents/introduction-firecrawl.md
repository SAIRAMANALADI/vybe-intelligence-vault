# Introduction | Firecrawl

## Summary

- **API Capabilities**: Firecrawl provides a unified API for web search, scraping, and interaction, supporting outputs in markdown, HTML, JSON, and screenshots, with built-in handling of proxies, anti-bot measures, and JavaScript rendering.

- **CLI & SDK Integration**: The Firecrawl CLI is installed via `npx -y firecrawl-cli@latest init --all --browser`, and SDKs (Python, Node.js) are available for direct API access, including MCP server support for AI tool integration.

- **Core Features**:
  - **Search**: Web search with full-page content extraction (`/v2/search` endpoint).
  - **Scrape**: URL content extraction in multiple formats (`/v2/scrape` endpoint).
  - **Interact**: Post-scrape interaction (e.g., form filling, dynamic content extraction).
