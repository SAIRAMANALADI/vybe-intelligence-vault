# Introduction | Firecrawl

## Summary

- **Multi-format scraping**: Extracts web content in markdown, HTML, or structured JSON via a single API call, handling dynamic and JavaScript-rendered pages.

- **Web search integration**: Combines search and scraping, returning full page content (including images/news) directly from search results in one call.

- **Agent-ready output**: Provides LLM-optimized data (markdown, JSON, screenshots) with built-in anti-bot bypass, proxies, and MCP server support for AI tool integration.
