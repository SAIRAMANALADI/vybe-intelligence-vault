# OpenAI · GitHub

## Summary

- **OpenAI's official GitHub organization** (`openai`) manages verified repositories including `openai-cookbook`, `whisper`, `evals`, and SDKs (`openai-python`, `openai-node`, `openai-java`, `openai-ruby`) for API integration across multiple languages.

- **Key technical projects** include:
  - `whisper`: Large-scale weakly supervised speech recognition model (Python).
  - `evals`: Framework for evaluating LLMs and LLM systems with open-source benchmarks.
  - `tiktoken`: Fast BPE tokenizer optimized for OpenAI's tokenization schemes.

- **Additional tools** like `codex` (Rust-based coding agent), `codex-security` (TypeScript SDK for vulnerability detection), and `tart` (Swift-based macOS/Linux VM automation for CI) are actively maintained under Apache-2.0 or MIT licenses.
