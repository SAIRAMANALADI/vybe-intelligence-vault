# OpenAI · GitHub

## Summary

- **OpenAI's GitHub organization** hosts 261+ repositories, including flagship projects like `whisper` (speech recognition), `evals` (LLM benchmarking), and `codex` (terminal-based coding agent), with primary development in Python, TypeScript, and Rust.

- **Official SDKs** are maintained for multiple languages (`openai-python`, `openai-node`, `openai-ruby`, `openai-dotnet`) alongside tools like `tiktoken` (BPE tokenization) and `terraform-provider-openai` for infrastructure-as-code integration.

- **Multi-agent frameworks** (`openai-agents-python`, `openai-agents-js`) and **API wrappers** (e.g., `openai-cookbook`) provide reference implementations for advanced LLM workflows and integration patterns.
