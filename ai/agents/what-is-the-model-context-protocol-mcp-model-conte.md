# What is the Model Context Protocol (MCP)? - Model Context Protocol

## Summary

- **Standardized Integration**: MCP is an open-source protocol enabling standardized, bidirectional connectivity between AI applications (e.g., Claude, ChatGPT) and external systems (data sources, tools, workflows) via a unified interface, analogous to USB-C for AI.

- **Cross-Ecosystem Compatibility**: Supports broad integration across clients (e.g., VS Code, Cursor) and servers, allowing AI agents to access heterogeneous resources (e.g., Google Calendar, Notion, databases) and perform tasks (e.g., 3D design, data analysis) with reduced development overhead.

- **Developer & User Benefits**: Reduces integration complexity for developers, enhances AI agent capabilities via ecosystem access, and improves end-user experience by enabling personalized, data-driven interactions and automated workflows.
