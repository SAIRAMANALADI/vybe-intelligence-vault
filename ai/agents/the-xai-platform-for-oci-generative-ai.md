# The xAI Platform for OCI Generative AI

## Summary

- **Model Offerings**: xAI platform provides access to Grok 3 and Grok 3 Mini for enterprise tasks (e.g., data extraction, coding, summarization), with Grok 3 Mini optimized for lightweight, logic-based tasks and Grok 4.3 featuring a 1M-token context window and December 2025 knowledge cutoff.

- **Advanced Multi-Agent Capabilities**: Grok 4.20 Multi-Agent enables real-time orchestration of specialized agents for multi-step research, integrating web search, data analysis, and synthesis for comprehensive, sourced outputs.

- **Deprecated Models**: Legacy models (e.g., Grok 4 Fast, Grok 3 Mini Fast) were deprecated but included reasoning variants, agentic tool-calling, and reduced hallucinations (e.g., Grok 4.1 Fast with 2M-token context window).
