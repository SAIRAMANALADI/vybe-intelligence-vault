# Documentation for Visual Studio Code

## Summary

- **AI Agents Integration**: VS Code supports autonomous AI agents for task automation, with options to run locally, in the background, or in the cloud, and supports multiple AI providers; sessions are tracked within the editor.

- **AI Optimization & Debugging**: Includes tools for optimizing AI agent cost/performance, browser-based AI agents for application validation/debugging, and prompt caching diagnostics via the Cache Explorer.

- **Enterprise & Customization**: Supports enterprise configurations (policies, extensions, AI customization) and allows project-specific AI tailoring via custom instructions, skills, and MCP server integration.
