# Documentation for Visual Studio Code

## Summary

- **AI Agents Integration**: VS Code supports autonomous AI agents for task automation, with local/cloud execution, multi-provider support, and session tracking via the [Agents documentation](https://code.visualstudio.com/docs/agents/overview).

- **Enterprise & Customization**: Features enterprise policies, AI model customization, and MCP server integration for tailored workflows, detailed in the [Enterprise](https://code.visualstudio.com/docs/enterprise/overview) and [Agent Customization](https://code.visualstudio.com/docs/agent-customization/overview) docs.

- **Remote & Debugging Tools**: Supports SSH, Dev Containers, WSL, and integrated browser-based debugging/validation, with remote execution and port forwarding capabilities per the [Remote](https://code.visualstudio.com/docs/remote/remote-overview) and [Debugging](https://code.visualstudio.com/docs/debugtest/debugging) docs.
