# Ollama

## Summary

- **Local & Cloud Execution**: Ollama enables running open-source models both locally and in cloud regions (US, EU, Singapore) via CLI/API, supporting offline deployment for critical workflows.

- **Data Privacy & Open Weights**: User data is never used for training; models run privately with open-source weights (GitHub) and support disconnected operation.

- **Agent & Tool Integration**: Supports launching agents (e.g., Claude Code, OpenCode) and integrates with frameworks via API, with trending models like GLM-5.2 and DeepSeek-V4-Flash.
