# Welcome to Unstructured! - Unstructured

## Summary

- **Unstructured** converts unstructured/semi-structured documents into structured, AI-ready data at scale with high performance and relevance.
- **Three core products**:
  - **Transform**: Local file parsing (JSON/HTML/Markdown/text) for AI tools/agents via local APIs.
  - **Foundation**: Remote file/data processing for searchable knowledge layers in AI workflows.
  - **Pipelines**: ETL for remote files/data (no-code or Python/REST API) to deliver parsed content to DBs/vector stores for SQL, analytics, and AI searches.
- **Support**: Technical support via [Requesting support](https://docs.unstructured.io/support/request); sales inquiries to [sales@unstructured.io](mailto:sales@unstructured.io).
