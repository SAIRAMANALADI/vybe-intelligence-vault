# Werkzeug · PyPI

## Summary

- **WSGI Utility Library**: Werkzeug is a comprehensive WSGI web application library providing utilities for request/response handling, routing, HTTP utilities, and a threaded development server, with no enforced dependencies.

- **Key Features**: Includes an interactive debugger, full-featured request/response objects, URL routing with variable capture, HTTP utilities (e.g., caching, cookies), and a test client for HTTP request simulation.

- **Technical Specifications**: Licensed under BSD-3-Clause, requires Python ≥3.9, and is maintained by the Pallets Projects; latest stable release is 3.1.8 (Apr 2, 2026).
