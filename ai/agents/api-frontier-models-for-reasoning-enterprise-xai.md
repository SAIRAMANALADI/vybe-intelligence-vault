# API: Frontier Models for Reasoning & Enterprise | xAI

## Summary

- **Unified API for Multi-Modal AI**: xAI’s Grok API supports text, voice, vision, and file-based reasoning (PDFs, spreadsheets, etc.) with a single interface, compatible with OpenAI/Anthropic SDKs for rapid deployment.

- **Frontier Models & Pricing**:
  - `grok-4.3`: 1M-token context, $1.25 (input)/$2.50 (output) per 1M tokens, excels in non-hallucination and agentic tool-calling.
  - `grok-build-0.1`: 256k-token context, $1.00/$2.00 per 1M tokens, optimized for agentic coding.

- **Cloud Integration & Real-Time Capabilities**:
  - Deployable on Azure AI Foundry, Oracle OCI, and Google Cloud Vertex.
  - Real-time voice ($0.05/min), TTS ($15/1M chars), STT ($0.10–$0.20/hr), and image/video generation (e.g., $0.05/img for 1K resolution).
