# continuedev/continue

## Summary

- **Open-source AI coding agent**: Continue is an autonomous coding assistant built with TypeScript, enabling AI-driven code generation, debugging, and refactoring via CLI and IDE integrations.

- **Modular architecture**: Supports extensible plugins for custom models, tools, and workflows, facilitating integration with local/remote LLMs (e.g., GitHub Models, Ollama) and IDEs (VS Code, JetBrains).

- **Multi-platform CLI**: Provides a command-line interface (`continue`) for real-time code analysis, context-aware suggestions, and project-wide automation with Git-aware diff handling.
