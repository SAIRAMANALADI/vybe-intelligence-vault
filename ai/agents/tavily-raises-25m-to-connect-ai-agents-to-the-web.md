# Tavily raises $25M to connect AI agents to the web | TechCrunch

## Summary

- **AI agents in enterprise settings require internet access with policy-compliant web search capabilities** to automate tasks like fraud detection (finance) or customer data gathering (sales), avoiding risks of ungoverned LLM outputs.

- **Tavily** (founded by Rotem Weiss, ex-GPT Researcher) provides enterprise-grade web search tools for AI agents, enabling structured data extraction from public/private sources while ensuring compliance, with backing from Insight Partners ($25M total funding).

- **Competitive landscape** includes Exa (raised $17M), Firecrawl, and OpenAI/Perplexity, all offering search connectivity layers for AI agents, but Tavily targets enterprise-specific governance and scalability.
