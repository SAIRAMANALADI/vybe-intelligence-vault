# idosal/git-mcp

## Summary

- **Purpose**: GitMCP is an open-source, remote MCP server designed to mitigate code hallucinations by providing structured access to GitHub repositories for AI agents and LLMs.
- **Technical Stack**: Implemented in TypeScript, it supports agentic workflows (e.g., Claude, Copilot, Cursor) via the MCP protocol for seamless GitHub project integration.
- **Features**: Enables real-time repository interaction (read/write) with fine-grained control, reducing dependency on error-prone LLM-generated code.
