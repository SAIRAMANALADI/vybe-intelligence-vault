# idosal/git-mcp

## Summary

- **Purpose**: GitMCP is an open-source, remote MCP server designed to mitigate "code hallucinations" by providing structured, real-time access to GitHub repositories for AI agents and LLMs.
- **Functionality**: Acts as a bridge between AI tools (e.g., Claude, Copilot, Cursor) and GitHub projects, enabling secure, agentic interactions with repositories via the MCP protocol.
- **Technical Stack**: Implemented in TypeScript, supports remote deployment, and integrates with GitHub’s API for repository operations (read/write, diffs, commits).
