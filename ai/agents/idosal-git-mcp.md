# idosal/git-mcp

## Summary

- **Purpose**: GitMCP is an open-source, remote MCP server designed to mitigate "code hallucinations" by providing accurate, real-time GitHub repository data to AI agents and LLMs.
- **Functionality**: Acts as a bridge between AI tools (e.g., Claude, Copilot, Cursor) and GitHub projects, enabling secure, agentic interactions with repositories via the MCP protocol.
- **Technical Stack**: Built in TypeScript, supports remote deployment, and integrates with GitHub for version control, issue tracking, and code retrieval.
