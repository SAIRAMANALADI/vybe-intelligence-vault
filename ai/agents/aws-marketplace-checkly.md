# AWS Marketplace: Checkly

## Summary

- **Synthetic Monitoring & MaC**: Checkly provides **synthetic monitoring** for web apps/APIs with **Monitoring-as-Code (MaC)** via Playwright, Terraform, or CLI, enabling infrastructure-as-code (IaC) workflows for reliability engineering.

- **Pricing & Contracts**: AWS Marketplace offers **1/12/24/36-month contracts** with credits-based pricing (e.g., $2,500/month for 2,500 check run credits + $25K/year platform fee), with up to **96% savings** for longer commitments.

- **Deployment & Integrations**: SaaS-based, **deployed on AWS**, with **real-time alerts** (Slack, email, webhooks) and **Playwright-based browser checks** for end-to-end validation, CI/CD integration, and performance tracking.
