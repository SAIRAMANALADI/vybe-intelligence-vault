# Werkzeug — Werkzeug Documentation (3.1.x)

## Summary

- **WSGI-compliant web framework**: Werkzeug is a modular WSGI utility library providing low-level tools for request/response handling, routing, and middleware without enforcing dependencies on template engines or databases.

- **Core components**: Includes `Request`/`Response` wrappers, URL routing with dynamic rule matching, HTTP utilities (header parsing, cookies, form data), and debugging/testing tools like `TestClient` and `run_simple()`.

- **Deployment flexibility**: Supports production deployment via WSGI servers (Gunicorn, uWSGI, Waitress) and includes middleware for proxy handling (`ProxyFix`), static file serving, and request inspection.
