# Zabbix Cloud Images and Appliances

## Summary

- Zabbix provides enterprise-grade, open-source monitoring solutions with distributed and web-based capabilities, including auto-discovery for IT infrastructure.

- Official Zabbix appliances are available on major cloud platforms (AWS, Azure, GCP, DigitalOcean) and are supported by Zabbix SIA.

- Additional monitoring plugins for Zabbix Agent 2 are hosted in `/zabbix-agent2-plugins/sources/` (e.g., Ceph, MongoDB, NVIDIA GPU, PostgreSQL).
