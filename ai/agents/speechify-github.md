# Speechify · GitHub

## Summary

- **Meta-Voicebox**: Speechify's generative AI model for speech, enabling cross-task generalization with state-of-the-art performance (GitHub: [SpeechifyInc/Meta-voicebox](https://github.com/SpeechifyInc/Meta-voicebox)).

- **SDKs & Libraries**: Provides TypeScript/Python SDKs (e.g., `speechify-api-sdk-typescript`, `speechify-api-sdk-python`) and tools like `string-tracker` for transparent string manipulation.

- **Open-Source Tools**: Hosts repositories for PDF linearization (`olmocr`), speculative decoding (`SpecForge`), and text extraction (`textract`), many forked from upstream projects (e.g., AllenAI, SGLang).
