# Speechify · GitHub

## Summary

- **Meta-Voicebox**: Speechify's open-source implementation of Meta's generative AI model for speech, enabling cross-task generalization with state-of-the-art performance (GitHub: [SpeechifyInc/Meta-voicebox](https://github.com/SpeechifyInc/Meta-voicebox)).

- **AI API SDKs**: Legacy TypeScript SDKs for Speechify's AI API, including `speechify-ai-legacy-sdks` (archived) and `ai-api-examples` for official usage demonstrations (GitHub: [SpeechifyInc/speechify-ai-legacy-sdks](https://github.com/SpeechifyInc/speechify-ai-legacy-sdks), [SpeechifyInc/ai-api-examples](https://github.com/SpeechifyInc/ai-api-examples)).

- **Toolchain & Libraries**: Open-source utilities such as `olmocr` (PDF linearization for LLM training), `piper-phonemize` (C++ text-to-phoneme conversion), and `uppy` (JavaScript file uploader) (GitHub: [SpeechifyInc/olmocr](https://github.com/SpeechifyInc/olmocr), [SpeechifyInc/piper-phonemize](https://github.com/SpeechifyInc/piper-phonemize), [SpeechifyInc/uppy](https://github.com/SpeechifyInc/uppy)).
