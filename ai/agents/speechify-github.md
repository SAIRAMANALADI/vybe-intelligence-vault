# Speechify · GitHub

## Summary

- **Meta-Voicebox**: First generative AI speech model by Speechify, enabling cross-task generalization with state-of-the-art performance (GitHub: [SpeechifyInc/Meta-voicebox](https://github.com/SpeechifyInc/Meta-voicebox)).

- **AI API SDKs**: Multi-language SDKs (TypeScript, Python) for Speechify's AI API, facilitating speech-to-text and text-to-speech integration (e.g., [speechify-api-sdk-typescript](https://github.com/SpeechifyInc/speechify-api-sdk-typescript)).

- **Open-Source Tools**: Libraries like `olmocr` (PDF linearization for LLM training) and `SpecForge` (speculative decoding model training) under Apache-2.0/MIT licenses (e.g., [olmocr](https://github.com/SpeechifyInc/olmocr)).
