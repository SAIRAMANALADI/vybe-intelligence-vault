# Speechify · GitHub

## Summary

- **Meta-Voicebox**: Speechify's generative AI model for speech, enabling cross-task generalization with state-of-the-art performance (GitHub: [SpeechifyInc/Meta-voicebox](https://github.com/SpeechifyInc/Meta-voicebox)).

- **SDKs & Libraries**: Provides TypeScript/Python SDKs (`speechify-api-sdk-typescript`, `speechify-api-sdk-python`) and tools like `string-tracker` for transparent string operations and index mapping.

- **Legacy & Auxiliary Tools**: Maintains legacy AI SDKs (`speechify-ai-legacy-sdks`) and auxiliary projects like `olmocr` (PDF linearization for LLM training) and `SpecForge` (speculative decoding model training).
