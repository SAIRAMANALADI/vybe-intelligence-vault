# Data tools | resources.data.gov

## Summary

- **DCAT-US 3.0**: A standardized metadata schema for U.S. federal data catalogs, defining structured fields for datasets, distributions, catalogs, and supporting classes (e.g., agents, constraints) to ensure interoperability and compliance with Project Open Data Metadata Schema.

- **CKAN (Comprehensive Knowledge Archive Network)**: An open-source data management system used by Data.gov and Inventory.data.gov to publish, share, and discover datasets via RESTful APIs, supporting metadata schemas (e.g., DCAT-US) and geospatial formats (e.g., GeoJSON).

- **CSV-to-API & Database-to-API Tools**: Dynamic tools that convert static CSVs or databases into RESTful APIs, supporting JSON/XML/HTML output formats, enabling programmatic access to structured data without custom backend development.
