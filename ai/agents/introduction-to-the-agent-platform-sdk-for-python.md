# Introduction to the Agent Platform SDK for Python | Gemini Enterprise Agent Platform | Google Cloud Documentation

## Summary

- **Purpose & Scope**: The Vertex AI SDK for Python (`google-cloud-aiplatform`) automates data ingestion, model training, and predictions on the Gemini Enterprise Agent Platform, offering higher-level abstraction than the granular Gemini Enterprise Agent Platform Python client library.
- **Installation & Auth**: Install via `pip install --upgrade google-cloud-aiplatform`; authenticate locally with `gcloud auth application-default login` (Cloud Shell exempt) or federated identity for external IdPs.
- **Dual Usage**: Supports co-use with the lower-level Gemini Enterprise Agent Platform Python client library (`google.cloud.aiplatform.gapic`/`aiplatform_v1`) for advanced workflows requiring finer control.
