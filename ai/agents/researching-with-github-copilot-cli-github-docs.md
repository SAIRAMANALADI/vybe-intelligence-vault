# Researching with GitHub Copilot CLI - GitHub Docs

## Summary

- `/research` command in GitHub Copilot CLI activates a specialized agent that performs deep research by aggregating data from local codebases, GitHub repositories, and the web, producing a comprehensive Markdown report with citations and a CLI summary.

- Reports are stored in session-specific directories (`~/.copilot/session-state/SESSION-ID/research/`) and can be shared via GitHub gists or saved as local files using `/share gist research` or `/share file research [PATH]`.

- The research agent uses a fixed AI model (non-configurable via `/model`) and adapts response format based on query type: step-by-step guidance (process), narrative explanations (conceptual), or technical deep-dives (architecture diagrams, code examples).
