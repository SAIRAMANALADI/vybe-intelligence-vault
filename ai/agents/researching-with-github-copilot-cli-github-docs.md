# Researching with GitHub Copilot CLI - GitHub Docs

## Summary

- GitHub Copilot CLI's `/research` command deploys a specialized agent to perform deep, multi-source investigations (codebase, GitHub repos, web) and generates a comprehensive, Markdown-formatted report with citations, architecture diagrams, and code snippets.
- Reports are session-specific, stored in `~/.copilot/session-state/SESSION-ID/research/`, and can be shared via GitHub gists or local files using `/share gist research` or `/share file research [PATH]`.
- The agent autonomously adapts response format based on query type (process, conceptual, or technical deep-dive) and prioritizes internal/private implementations when applicable, but is not designed for code modifications or time-sensitive interactions.
