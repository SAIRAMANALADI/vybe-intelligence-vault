## Summary

- **Vercel** provides agentic infrastructure for deploying and scaling applications and AI agents, with core tools like **Next.js** (React framework), **Turborepo** (Rust-based build system for JS/TS), and **AI SDK** (TypeScript library for AI-powered apps).

- Key open-source projects include **SWR** (React hooks for data fetching), **Satori** (HTML/CSS to SVG conversion), and **Workflow SDK** (TypeScript framework for durable, observable AI agents).

- The organization maintains a verified domain (`vercel.com`) and sponsors critical dependencies, with top languages including **TypeScript**, **JavaScript**, **Go**, and **Rust**.
