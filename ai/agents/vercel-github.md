# Vercel · GitHub

## Summary

- **Core Products**: Vercel provides agentic infrastructure with key open-source projects including **Next.js** (React framework), **Turborepo** (Rust-based build system for JS/TS), and **AI SDK** (TypeScript toolkit for AI-powered apps/agents).

- **Developer Tools**: Hosts critical SDKs/libraries like **SWR** (React hooks for data fetching), **Commerce** (Next.js e-commerce framework), and **Workflow** (TypeScript SDK for durable, observable apps/AI agents).

- **Compute & Automation**: Offers specialized tools such as **Sandbox** (ephemeral compute for untrusted code) and **Eve** (framework for building AI agents), alongside **Chat** (unified TypeScript SDK for cross-platform chatbots).
