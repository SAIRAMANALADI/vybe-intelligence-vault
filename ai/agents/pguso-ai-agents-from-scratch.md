# pguso/ai-agents-from-scratch

## Summary

- **Educational Repository**: Provides a hands-on tutorial to build AI agents from scratch using local LLMs, emphasizing transparency by avoiding black-box models and focusing on core concepts like function calling, memory management, and ReAct (Reasoning and Acting) patterns.

- **Technical Implementation**: Utilizes **JavaScript** with **node-llama-cpp** for local LLM integration, demonstrating practical agent architectures (e.g., React-agent) while avoiding cloud dependencies for full control over agent behavior and logic.

- **Key Features**: Covers agent orchestration patterns (e.g., ReAct), memory systems, and function-calling workflows, with a focus on Node.js ecosystems and modular, reproducible agent designs. Last updated in **2026-08-05**.
