# pguso/ai-agents-from-scratch

## Summary

- **Educational repository** for building AI agents from scratch using **JavaScript**, focusing on **local LLMs** (via `node-llama-cpp`) to avoid black-box dependencies.
- Implements **function calling**, **memory management**, and **ReAct (Reasoning and Acting) patterns** for agentic workflows.
- Provides a **step-by-step tutorial** for constructing agents with **Node.js**, emphasizing transparency and real-world applicability.
