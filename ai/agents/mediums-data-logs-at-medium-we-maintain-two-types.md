# Medium’s Data Logs. At Medium, we maintain two types of… | by Medium | Medium Policy

## Summary

- **Server logs** capture HTTP requests with fields including IP address, timestamp, HTTP method/path/status, response size, referrer, user agent, internal transaction ID, and host; retained for ≤30 days before deletion.
- **Event logs** track user interactions (e.g., clicks, scrolls) with anonymized metadata such as user ID, event type, timestamps, device client, and post/collection identifiers; retained indefinitely.
- Server logs include raw request data with potential user identifiers, while event logs exclude PII (e.g., IP, email) but retain Medium-generated user IDs and behavioral metadata.
