# Mem0 - AI Memory Layer for your Agents & Apps | Persistent Context

## Summary

- **Persistent Memory Infrastructure**: Drop-in solution enabling AI agents/apps to retain context across sessions without pipeline modifications, reducing redundant context and token costs while improving response latency.

- **Memory Compression Engine**: Automatically condenses chat history into compact, retrievable memories via single-pass hierarchical distillation and multi-signal retrieval, benchmarked on LoCoMo, LongMemEval, and BEAM.

- **Enterprise-Grade Security & Compliance**: SOC 2 Type 1 and HIPAA-compliant with BYOK, zero-trust, portable deployment (Kubernetes/private cloud/air-gapped), and full audibility for governance and observability.
