# NousResearch/hermes-agent

## Summary

- **Multi-Model Agent Framework**: Hermes-Agent is a Python-based AI agent system supporting integration with Anthropic, OpenAI, and other LLM providers, enabling dynamic switching and multi-model orchestration for complex tasks.

- **Tool-Agnostic Execution**: Supports execution via `claude-code`, `codex`, and custom tools, with built-in support for `clawdbot` and `moltbot` for code generation, analysis, and automation workflows.

- **Extensible & Scalable**: Designed for modularity with community-driven tooling (`hermes-agent`, `Nous-Research` ecosystem), facilitating continuous growth through plugin-based architecture and collaborative development.
