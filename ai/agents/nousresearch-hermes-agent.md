# NousResearch/hermes-agent

## Summary

- **Multi-LLM Compatibility**: Hermes-Agent supports integration with various LLMs (e.g., Anthropic, OpenAI, Codex) via modular API connectors, enabling dynamic switching between models for task-specific optimization.

- **Self-Improving Architecture**: Implements a feedback-driven loop where the agent autonomously refines its performance using performance metrics and user feedback, enhancing long-term task execution.

- **Tool-Agnostic Execution**: Executes tasks across heterogeneous environments (e.g., shell, Python, web APIs) via a plugin-based tooling system, abstracting low-level interactions for seamless cross-platform operation.
