# The FHIR collaboration platform - SIMPLIFIER.NET

## Summary

- **FHIR Profile Repository**: Simplifier.net hosts **9,113+ FHIR projects**, **40,843+ profiles**, and **397,452+ resources**, supporting FHIR versions **R5, R4B, R4, and STU3**, with tools like **FHIR Validator, FQL, FSH, and YAMLGen** for validation and modeling.

- **Canonical Pinning & AI Integration**: The **2026.3 release** introduces **canonical reference pinning** for reproducible packages, .NET 10 migration, and **AI-powered FHIR validation** via Firely Terminal for automated workflows.

- **Global FHIR Implementations**: Showcases include **Basisprofil DE (R4), Israel Core, UK Core R4, and eRezept**, with **16,666+ ImplementationGuides** and **47,155+ ValueSets** available for interoperability.
