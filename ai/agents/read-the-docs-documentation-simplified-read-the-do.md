# Read the Docs: documentation simplified — Read the Docs user documentation

## Summary

- **Automated Documentation Hosting**: Read the Docs integrates with Git workflows to automatically build and host documentation for every code push, ensuring synchronization between code and docs while supporting multi-version hosting (e.g., v1.0, v2.0) via Git branches/tags.

- **Reproducible Builds & Configuration**: Projects use a `.readthedocs.yaml` configuration file for reproducible builds, with support for environment variables, custom domains, and CDN caching to optimize performance and reliability.

- **Advanced Features**: Supports localization, subprojects, SSO, private documentation sharing, traffic/security analytics, and a public REST API for integration with CI/CD pipelines or third-party tools.
