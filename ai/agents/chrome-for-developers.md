# Chrome for Developers

## Summary

- **Chrome 151 Beta & 150 Stable** introduce CSS gap decorations, WebSocket bfcache disconnect handling, and `Intl.Locale` variants, with beta features previewed [here](https://developer.chrome.com/blog/chrome-151-beta) and stable updates [here](https://developer.chrome.com/release-notes/150).

- **Chrome DevTools & AI Integration** provide real-time debugging, performance profiling, and AI-powered features (e.g., `auto_awesome`), alongside tools like Puppeteer and ChromeDriver for automated testing and development workflows.

- **Web Platform & Extensions** support Baseline standards, Web App capabilities (e.g., widgets, payments), and Chrome Extension development, with resources available at [web.dev](https://web.dev/) and [Chrome Extensions docs](https://developer.chrome.com/docs/extensions).
