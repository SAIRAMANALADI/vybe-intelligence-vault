# Chrome for Developers

## Summary

- **Chrome 152 beta** introduces new features preview, including AI-driven capabilities via [`auto_awesome`](https://developer.chrome.com/docs/ai) and enhanced Web App Features via [`widgets`](https://developer.chrome.com/docs/capabilities).
- **Chrome DevTools** enables real-time debugging, performance analysis, and source editing directly in the browser, while **Puppeteer** (`data_object`) provides automated Chromium control for testing and scraping.
- **Core Web Vitals** (`display_settings`) and **Declarative Shadow DOM slot assignment** in Chrome 151 stable optimize rendering performance and UI composability.
