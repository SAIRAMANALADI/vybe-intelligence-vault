# Qwen3: Think Deeper, Act Faster | Qwen

## Summary

- **Hybrid Reasoning Architecture**: Qwen3 implements a dual-mode system with *Thinking Mode* (step-by-step reasoning) and *Non-Thinking Mode* (fast responses), enabling scalable computational budget control for tasks requiring variable depth of reasoning.

- **Multilingual & Scalable MoE Models**: Supports **119 languages/dialects** and offers open-weight MoE models (e.g., **Qwen3-235B-A22B** with 22B activated/235B total params) alongside dense variants (0.6B–32B), optimized for cost-efficiency via selective parameter activation.

- **Enhanced Agentic & Pre/Post-Training**: Features improved **MCP support**, **long-context handling** (up to 128K tokens), and a **4-stage post-training pipeline** (CoT cold start → RL → mode fusion → general RL) for hybrid reasoning, with pre-training on **36T tokens** (4K→32K context expansion).
