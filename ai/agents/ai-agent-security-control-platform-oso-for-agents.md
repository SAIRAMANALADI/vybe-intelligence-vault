# AI Agent Security & Control Platform | Oso for Agents

## Summary

- **Agent Discovery & Enforcement**: Oso provides visibility into all AI agents (laptops, browsers, terminals) to identify and shut down unsanctioned agents, ensuring compliance with internal policies.

- **Real-Time Monitoring & Detection**: Logs and monitors all approved AI agent activity (prompts, tool calls, responses) with built-in detection for rule violations, PII leakage, API key exposure, and high-velocity behavior.

- **Policy-Based Controls & Reporting**: Enforces granular access controls via customizable rules (e.g., blocking MCP servers, restricting delete operations) and generates audit-ready compliance reports for incident investigation.
