# Styles in Compose | Jetpack Compose | Android Developers

## Summary

- **Styles API** in Jetpack Compose provides a new, `@Experimental` paradigm for styling UI elements, replacing traditional modifier-based approaches with a more flexible, declarative system inspired by CSS, improving performance by avoiding recompositions during the Composition phase.

- **Core concepts** include `Style` (interface defining UI appearance), `StyleScope` (receiver for styling properties), and `StyleState` (manages conditional styling based on component states like `isPressed` or `isEnabled`).

- **Performance benefits** include reduced recompositions (styles execute in Draw/Layout phases), simplified component APIs via a single `Style` parameter, and built-in animations for state transitions without manual `animateColorAsState` calls.
