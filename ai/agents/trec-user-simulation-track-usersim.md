# TREC User Simulation Track | UserSim

## Summary

- **Objective**: Establishes a standardized framework for validating user simulators in interactive search evaluation, addressing the lack of trust and adoption in current methods.
- **Tasks**: Focuses on two key tasks—turn-level next utterance prediction and session-level end-to-end conversation generation—using provided conversational agents and API for simulator development.
- **Timeline**: Key milestones include track announcement (Dec 2025), training data collection (May-Jun 2026), API availability (Jul 2026), submissions (Sep 2026), and results presentation at TREC (Nov 2026).
