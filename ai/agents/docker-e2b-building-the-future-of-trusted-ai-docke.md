# Docker + E2B: Building the Future of Trusted AI | Docker

## Summary

- **Integration of E2B Sandboxes with Docker MCP Catalog**: Docker now provides secure, cloud-based sandboxes via E2B, enabling AI agents to execute code in isolated environments while granting direct access to 200+ curated MCP tools (e.g., GitHub, Perplexity, Browserbase) through Docker’s MCP Gateway, ensuring both safety and performance.

- **Standardized Secure Tool Access**: Docker’s MCP Catalog and Gateway automate the auditing and validation of MCP servers for exploits/malicious behavior, reducing manual security overhead and enabling developers to integrate real-world tools into agents without compromising trust or speed.

- **Foundation for Trusted AI Stacks**: The partnership aims to establish a secure foundation for AI development, mirroring containerization’s standardization of application deployment, by providing verifiable, governed access to tools and environments for AI agents in production.
