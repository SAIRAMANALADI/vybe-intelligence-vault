# The Hugo CMS for visual page building | CloudCannon

## Summary

- **Git-integrated CMS**: CloudCannon enables branch-based editing/publishing for Hugo sites, allowing content teams to work on branches, preview changes on staging sites, and merge via Git without conflicts with local Hugo environments.

- **Visual editing with real-time previews**: Editors can update content visually via CloudCannon’s WYSIWYG interface, with changes reflected instantly in previews that match the live site’s rendering, including structured data and meta tags.

- **Performance & scalability**: Hugo’s static architecture ensures fast, scalable sites; CloudCannon maintains this by automating scaling under traffic spikes while eliminating backend maintenance overhead for developers.
