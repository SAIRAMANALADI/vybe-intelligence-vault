# GitHub for Atlassian | Atlassian Marketplace

## Summary

- **Unified Data Integration**: Connects GitHub (Cloud/Enterprise) with Atlassian apps via a single connector, syncing development activity (PRs, commits, vulnerabilities) to Atlassian’s Teamwork Graph for cross-app visibility and real-time updates via webhooks.

- **Automation & Workflow Optimization**: Enables Smart Commits for Jira issue transitions, time tracking, and comments; supports two-way sync to maintain consistent context between Jira and GitHub, reducing manual effort.

- **Developer Efficiency Tools**: Enhances searchability of development context across Atlassian apps (e.g., Rovo Search/Chat) and allows branch creation directly from Jira, streamlining collaboration and SDLC tracking.
