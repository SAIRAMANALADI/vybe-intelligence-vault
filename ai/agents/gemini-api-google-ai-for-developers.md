# Gemini API | Google AI for Developers

## Summary

- **Interactions API** is the primary interface for accessing Gemini models (e.g., `gemini-3.6-flash`) and supports multimodal input/output, enabling text generation, image analysis, and conversational agents.

- **Model Suite**: Includes state-of-the-art models like `Gemini 3.1 Pro` (multimodal reasoning), `Gemini 3.6 Flash` (cost-efficient frontier performance), `Nano Banana 2/Pro` (image generation/editing), and `Veo 3.1` (video generation with native audio).

- **Capabilities**: Supports structured outputs (JSON), long-context processing (millions of tokens), function calling for agentic workflows, real-time voice agents (`Live API`), and built-in tools (e.g., Google Search, Code Execution).
