# Gemini API | Google AI for Developers

## Summary

- **Gemini 3.7 Flash** is Google's latest high-performance model optimized for complex coding, agentic workflows, and multi-step execution, replacing legacy `generateContent` APIs with the new **Interactions API** for stateful conversation management.

- Supports **multimodal inputs** (text, images, video, audio) with specialized models like **Nano Banana** (image generation), **Veo 3.1** (video generation), and **Gemini 3.5 Transcribe** (low-latency speech-to-text).

- Provides **structured outputs**, **function calling**, **long-context processing** (millions of tokens), and **real-time streaming** via the Interactions API, with SDKs for Python, JavaScript, Java, and REST.
