# Framer: AI design agent

## Summary

- **AI-Powered Design Agents**: Native agents integrate directly into the canvas for real-time, in-place generation, refinement, and editing of designs, UI components, and interactions while maintaining full user control and editability.

- **Unified CMS & Code Automation**: Agents manage, sync, and publish CMS content directly from the design canvas, and convert high-level prompts into production-ready code (e.g., custom effects, complex interactions) via integration with external IDEs (Cursor, Claude Code, Codex).

- **Cross-Platform AI Orchestration**: Enables external AI agents (Slack, GitHub, terminal) to trigger design, CMS, and deployment actions, with real-time performance optimization (LCP: 1.1s, INP: 95ms, CLS: 0.01) and native WordPress migration via REST API integration.
