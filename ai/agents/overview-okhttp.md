# Overview - OkHttp

## Summary

- **Protocol & Performance Optimizations**: Supports HTTP/2 (multiplexing over single socket), connection pooling, transparent GZIP compression, and response caching to minimize latency and bandwidth usage.
- **Robust Network Handling**: Implements automatic retry with alternate IP addresses, modern TLS (1.3, ALPN, certificate pinning), and fallback mechanisms for degraded network conditions.
- **Strict RFC Compliance**: Follows HTTP/1.1, HTTP/2, RFC 9110-9113 specs, avoids non-standard configurations, and enforces immutable request/response APIs with synchronous/asynchronous execution.
