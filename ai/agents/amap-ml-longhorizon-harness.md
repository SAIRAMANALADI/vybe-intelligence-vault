# AMAP-ML/LongHorizon-Harness

## Summary

- **Long-horizon agent execution framework** enabling AI agents to interact with desktop apps and CLI for extended durations while maintaining task state and ensuring reliable progress on complex workflows.

- **Key features**: fresh-context execution, durable verified state, independent auditing, recoverable progress, and native integration with Claude Code, Codex, and OpenClaw agents.

- **Technical stack**: Python-based repository with support for GUI/CLI automation, loop engineering, and plugin-based extensions for long-horizon agent operations.
