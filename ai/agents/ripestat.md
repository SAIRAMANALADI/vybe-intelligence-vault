# RIPEstat

## Summary

- **IP Addresses**: Unique numerical labels assigned to devices on a network, enabling communication via Internet Protocol (e.g., IPv4: `192.0.2.1`, IPv6: `2001:0db8::1`).
- **ASNs (Autonomous System Numbers)**: Globally unique identifiers (e.g., `AS15169` for Google) assigned to networks for routing efficiency in BGP (Border Gateway Protocol).
- **Hostnames & Country Codes**: Hostnames (e.g., `www.example.com`) resolve to IPs via DNS; country codes (e.g., `US`, `DE`) map to geolocation via ISO 3166-1 or IP geolocation databases.
