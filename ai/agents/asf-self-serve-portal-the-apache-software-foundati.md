# ASF Self-serve Portal - The Apache Software Foundation

## Summary

- **Self-service portal** for Apache Software Foundation (ASF) projects, committers, and contributors to autonomously manage infrastructure resources (Jira projects, Git repos, mailing lists, Confluence spaces) without direct Infrastructure team intervention.

- **Role-based access control** with distinct service tiers:
  - *PMC/PPMC*: Create/manage Jira projects, Git repos, mailing lists, and Confluence spaces.
  - *Committers*: Edit ASF identity, reset passwords, and use OTP calculator.
  - *Contributors*: Request/reactivate Jira/Confluence accounts.

- **OAuth-authenticated workflows** with continuous feature expansion; undocumented requests can be filed via INFRA Jira tickets or suggested to `users@infra.apache.org`.
