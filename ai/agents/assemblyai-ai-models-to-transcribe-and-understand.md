# AssemblyAI | AI models to transcribe and understand speech

## Summary

- **Multi-modal Speech APIs**: AssemblyAI offers pre-recorded, real-time, and sync speech-to-text APIs (e.g., `Universal-3.5 Pro`, `Universal-Streaming`) with support for 99 languages, natural language prompting, and low-latency streaming (e.g., `continuous_partials=True` in Python SDK).

- **Voice Agent & Understanding APIs**: Provides production-ready voice agents with built-in turn detection/interruption handling and speech understanding features (e.g., speaker ID, sentiment, summaries) via a single API call.

- **Enterprise-Grade Infrastructure**: Scalable, globally redundant Voice AI infrastructure processing 2M+ audio hours/day with enterprise uptime, no concurrency limits, and an LLM Gateway for model routing/failover.
