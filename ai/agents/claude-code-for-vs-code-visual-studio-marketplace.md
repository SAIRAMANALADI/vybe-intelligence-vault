# Claude Code for VS Code - Visual Studio Marketplace

## Summary

- **Integration & Features**: VS Code extension enabling direct access to Anthropic's Claude models (Pro/Max/Team/Enterprise or pay-as-you-go) with autonomous codebase exploration, real-time editor integration, and terminal command execution under user permission.

- **Agentic Capabilities**: Supports subagents, custom slash commands, and MCP (Model Context Protocol) for advanced workflows, with some configurations requiring CLI access; includes a toggle (`Claude Code: Use Terminal`) to revert to terminal-based interaction.

- **Requirements & Compatibility**: Requires VS Code v1.98.0+; provides documentation at [code.claude.com/docs/en/vs-code](https://code.claude.com/docs/en/vs-code) for setup and usage.
