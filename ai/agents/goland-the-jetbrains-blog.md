# GoLand - The JetBrains Blog

## Summary

- **GoLand 2026.2** introduces a new **Go Optimization tool window**, integrating **profiling, escape analysis**, and performance monitoring to streamline Go application optimization with minimal manual effort.

- **Escape Analysis** in GoLand 2026.2 enables **stack vs. heap allocation inspection**, allowing developers to identify and optimize memory usage patterns directly within the IDE.

- **GoLand 2026.1** adds **guided syntax updates for Go 1.26**, including automated refactoring for `errors.AsType` and `new()` pointer syntax, while expanding AI-assisted coding capabilities via **Junie and Claude Code integration**.
