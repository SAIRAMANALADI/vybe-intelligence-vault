# GitHub Copilot CLI · GitHub

## Summary

- **Multi-Model & Parallel Execution**: GitHub Copilot CLI supports `/model` switching and `/fleet` parallelization, enabling concurrent execution across multiple AI models (e.g., Anthropic, Google, OpenAI) for distributed task processing.

- **Agentic Workflow Integration**: Native `/mcp` support enables direct GitHub issue/PR interaction, `/plan` to PR automation, and `/resume` for session persistence, bridging CLI and IDE workflows (VS Code) with memory-aware state retention.

- **Customizable & Governed Autonomy**: Extensible via `/agent` and `/skills` (AGENTS.md), supports MCP server plugins, and enforces org-level policies (branch protections, Copilot Business/Enterprise settings) while requiring explicit approval for file/command changes.
