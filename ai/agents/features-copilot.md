# GitHub Copilot CLI · GitHub

## Summary

- **Multi-Agent Workflows**: Copilot CLI enables parallelized subagent execution via `/fleet`, allowing concurrent task processing with `/model` switching across providers (Anthropic, Google, OpenAI). Supports multi-agent collaboration with full control over applied changes.

- **Terminal-to-IDE Integration**: Operates natively in terminal with `/plan` → `/autopilot` modes, maintaining session persistence and context. Integrates with VS Code via CLI terminal/Chat panel, enabling seamless transition from shell-based planning to IDE-based refinement.

- **Governance & Customization**: Inherits GitHub Copilot’s org-level security/compliance policies. Supports MCP server integrations, custom skills (via `AGENTS.md`), and explicit approval for file/command execution, ensuring controlled autonomous workflows.
