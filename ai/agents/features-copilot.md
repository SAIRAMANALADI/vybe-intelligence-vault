# GitHub Copilot CLI · GitHub

## Summary

- **Multi-Agent Workflows**: Copilot CLI supports parallelized subagents via `/fleet`, enabling concurrent task execution across multiple models (e.g., Anthropic, Google, OpenAI) with `/model` switching, and multi-agent collaboration for decision convergence.

- **GitHub-Native Integration**: Built on GitHub’s `/mcp` protocol, it natively interacts with issues, PRs, branches, and labels, inheriting organization policies (branch protections, required checks) while allowing `/plan`-to-PR automation with explicit user approval for changes.

- **Session Persistence & Extensibility**: Maintains persistent chat history and context across sessions via `/resume`, supports custom agent behavior via `AGENTS.md` and `/skills`, and integrates with MCP servers for extended functionality, all while operating within terminal-native workflows.
