# GitHub Copilot CLI · GitHub

## Summary

- **Multi-Agent Parallel Execution**: Copilot CLI supports `/fleet` for parallelized subagent execution across multiple models (e.g., Anthropic, Google, OpenAI), enabling concurrent task processing with `/model` switching and decision convergence.

- **GitHub-Native MCP Integration**: Built on GitHub’s Model Context Protocol (MCP), the CLI interacts directly with issues, PRs, branches, and labels, enabling native workflows like `/plan` → `/delegate` → PR creation with branch protections and org policies enforced.

- **Session Persistence & Autopilot**: Maintains persistent chat history and state via `/resume`, supports Shift+Tab autopilot mode for autonomous task progression, and integrates with VS Code for IDE refinement, all while requiring explicit approval for file/command execution.
