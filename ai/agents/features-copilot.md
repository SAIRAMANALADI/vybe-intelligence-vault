# GitHub Copilot CLI · GitHub

## Summary

- **Multi-Agent Workflows**: Copilot CLI enables parallelized task execution via `/fleet`, allowing subagents to work concurrently on the same task with convergence to a decision-ready result, while maintaining user control over applied changes.

- **GitHub-Native Integration**: Built on GitHub’s native Model Context Protocol (MCP), it interacts directly with issues, pull requests, and branches, inheriting organizational policies (e.g., branch protections) and enabling seamless transitions from `/plan` to merged PRs.

- **Model & Session Management**: Supports dynamic model switching via `/model`, persistent session context with `/resume`, and custom agent behavior via `AGENTS.md` and `/skills`, while ensuring security compliance through inherited Copilot governance policies.
