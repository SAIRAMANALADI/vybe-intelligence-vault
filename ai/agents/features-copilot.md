# GitHub Copilot CLI · GitHub

## Summary

- **Multi-Model & Parallel Execution**: Supports `/model` switching and `/fleet` for parallelized subagent execution across multiple foundation models (Anthropic, Google, OpenAI) within a single task.

- **GitHub-Native Agentic Workflow**: Integrates natively with GitHub via `/mcp` for direct issue/PR management, branch creation, and PR generation, inheriting org policies (branch protections, governance) automatically.

- **Session Persistence & Autopilot**: Maintains chat history and context across sessions; `/plan` mode enables multi-agent task outlining, while `/autopilot` executes autonomously with explicit user approval for file/command changes.
