# Copyright Help Center - Legal Help

## Summary

- Google enforces copyright via DMCA compliance, providing a [legal troubleshooter](https://support.google.com/legal/troubleshooter/1114905) for streamlined removal requests and designating a DMCA Agent (dmca-agent@google.com) for formal submissions.
- Copyright infringement handling includes repeat offender policies, as outlined in Google’s [repeat infringement guidelines](https://support.google.com/legal/answer/11625144).
- Google’s [Copyright Help Center](https://support.google.com/legal) offers technical resources on core concepts like fair use ([FAQ](https://support.google.com/legal/answer/4558992)) and copyright fundamentals ([basics](https://support.google.com/legal/answer/3463239)).
