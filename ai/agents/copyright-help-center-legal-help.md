# Copyright Help Center - Legal Help

## Summary

- Google enforces copyright via DMCA compliance, providing a [legal troubleshooter](https://support.google.com/legal/troubleshooter/1114905) for structured removal requests and a designated DMCA Agent (`dmca-agent@google.com`) for formal submissions.
- Copyright infringement handling includes repeat offender policies, as outlined in Google’s [repeat infringement guidelines](https://support.google.com/legal/answer/11625144).
- Key resources include definitions of copyright ([link](https://support.google.com/legal/answer/3463239)), fair use ([link](https://support.google.com/legal/answer/4558992)), and FAQs ([link](https://support.google.com/legal/answer/4558836)).
