# Copyright Help Center - Legal Help

## Summary

- Google enforces copyright via DMCA compliance, providing tools like a [legal troubleshooter](https://support.google.com/legal/troubleshooter/1114905) for removal requests and designating a DMCA Agent (`dmca-agent@google.com`) for formal submissions.
- Google’s copyright framework includes definitions for **copyright** ([support link](https://support.google.com/legal/answer/3463239)), **fair use** ([support link](https://support.google.com/legal/answer/4558992)), and policies for handling repeat infringement ([support link](https://support.google.com/legal/answer/11625144)).
- Copyright-related FAQs and enforcement details are centralized in Google’s [Copyright Help Center](https://support.google.com/legal/troubleshooter/1114905), with additional resources for YouTube-specific policies via the [YouTube Copyright Center](http://www.youtube.com/yt/copyright/).
