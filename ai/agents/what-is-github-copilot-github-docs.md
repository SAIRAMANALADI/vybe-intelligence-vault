# What is GitHub Copilot? - GitHub Docs

## Summary

- **AI-Powered Coding Assistant**: GitHub Copilot integrates with IDEs, GitHub Mobile, and CLI to provide real-time code suggestions, command-line assistance, and contextual chat-based support, enhancing developer productivity by automating repetitive coding tasks.

- **Multi-Platform & Enterprise Features**: Supports agent-driven development via the GitHub Copilot app, enforces geographic data residency for enterprises, and enables PR description generation, research, and automated code changes with pull request creation.

- **Access Models**: Offers tiered access (Free, Pro, Pro+, Max) with eligibility for students/teachers/open-source maintainers; organizations require enterprise accounts or direct Sales team contact for Copilot Business/Enterprise licensing.
