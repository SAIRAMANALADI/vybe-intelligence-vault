# Structured outputs | Gemini API | Google AI for Developers

## Summary

- **Structured Outputs via JSON Schema**: The Interactions API supports structured outputs where responses adhere to a provided JSON Schema, enabling predictable, type-safe results for tasks like data extraction, classification, and agentic workflows. SDKs (Python/Pydantic, JavaScript/Zod) simplify schema definition.

- **Conditional & Recursive Schemas**: Supports `anyOf` for conditional outputs (e.g., spam vs. non-spam moderation) and recursive structures (e.g., organization charts) via self-referential models, enhancing flexibility in response formatting.

- **Multi-Language Integration**: Enables structured output generation across Python (Pydantic), JavaScript (Zod), and REST API, with examples demonstrating schema validation and parsing for consistent data extraction.
