# Hugging Face · GitHub

## Summary

- **Core Libraries**: Hugging Face maintains key open-source libraries including `transformers` (SOTA ML frameworks for text/vision/audio/multimodal models), `diffusers` (diffusion models for generative tasks), `datasets` (large-scale AI-ready datasets), and `peft` (parameter-efficient fine-tuning).

- **Optimization & Deployment**: Tools like `accelerate` (PyTorch acceleration across devices/distributed setups) and `optimum` (hardware-optimized inference/training for Transformers/Diffusers) enable scalable model deployment with features like automatic mixed precision (FP8) and FSDP/DeepSpeed support.

- **Infrastructure & Ecosystem**: The `huggingface_hub` Python client and Rust-based `xet-core` facilitate model/dataset sharing, while `pytorch-image-models` provides a comprehensive collection of PyTorch vision backbones (e.g., ViT, ResNet, ConvNeXt) with pretrained weights and training scripts.
