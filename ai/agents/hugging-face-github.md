# Hugging Face · GitHub

## Summary

- **Hugging Face** is an AI organization developing core ML frameworks like `transformers` (SOTA model definitions for text/vision/audio/multimodal tasks), `diffusers` (diffusion models for generative AI), and `datasets` (largest hub of ready-to-use AI datasets with efficient data tools).

- **Key repositories** include `peft` (Parameter-Efficient Fine-Tuning), `accelerate` (PyTorch training/inference acceleration with FP8/FSDP/DeepSpeed support), and `optimum` (hardware-optimized inference/training for Transformers/Diffusers).

- **Additional tools** span `lerobot` (end-to-end robotics AI), `OpenEnv` (RL post-training environments), and `huggingface.js` (JavaScript/TypeScript SDK for HF APIs).
