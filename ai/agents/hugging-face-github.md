# Hugging Face · GitHub

## Summary

- **Hugging Face** maintains core AI libraries: `transformers` (SOTA ML frameworks for text/vision/audio/multimodal models), `diffusers` (diffusion models for generative tasks), and `datasets` (largest hub of ready-to-use AI datasets with optimized tools).

- **Key optimization tools**: `peft` (Parameter-Efficient Fine-Tuning), `accelerate` (PyTorch acceleration for distributed training/inference with FP8/FSDP/DeepSpeed), and `optimum` (hardware-optimized inference/training for Transformers/Diffusers).

- **Infrastructure & ecosystem**: `tokenizers` (Rust-based high-performance tokenizers), `huggingface_hub` (official CLI/Python client for model/dataset hosting), and `lerobot` (end-to-end robotics learning framework).
