# Hugging Face · GitHub

## Summary

- **Core Libraries**: Hugging Face maintains industry-standard open-source libraries like `transformers` (SOTA ML frameworks for text/vision/audio/multimodal), `diffusers` (diffusion models for generative AI), and `datasets` (largest hub of ready-to-use AI datasets with optimized tools).

- **Optimization & Fine-Tuning**: Key repositories include `accelerate` (PyTorch training/inference acceleration), `peft` (parameter-efficient fine-tuning), and `optimum` (hardware-optimized inference/training for Transformers/Diffusers).

- **Domain-Specific Tools**: Specialized projects like `lerobot` (robotics AI), `speech-to-speech` (local voice agents), and `tau` (minimalist coding agent) demonstrate domain-specific AI applications.
