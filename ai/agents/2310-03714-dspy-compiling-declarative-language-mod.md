# [2310.03714] DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines

## Summary

- **Declarative Programming Model**: DSPy introduces a programming model that abstracts language model (LM) pipelines as text transformation graphs, enabling declarative module invocations and parameterization for systematic optimization of prompting, fine-tuning, and reasoning techniques.

- **Self-Improving Pipeline Compiler**: The framework includes a compiler that optimizes DSPy pipelines to maximize specified metrics, allowing succinct programs to self-bootstrap high-performance LM pipelines (e.g., outperforming few-shot prompting by 25-65% on GPT-3.5 and llama2-13b-chat).

- **Cross-Model Competitiveness**: DSPy-compiled pipelines on smaller open models (e.g., 770M-parameter T5, llama2-13b-chat) achieve parity with expert-written prompt chains for proprietary models like GPT-3.5, demonstrating efficiency and scalability.
