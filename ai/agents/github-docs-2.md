# docs/content/github-cli/github-cli/github-cli-telemetry.md at main · github/docs · GitHub

## Summary

- {% data variables.product.prodname_cli %} collects pseudonymous telemetry to improve product development, prioritizing features based on real-world usage patterns (e.g., subcommand adoption, flag usage).
- Telemetry is disabled when targeting {% data variables.product.prodname_ghe_server %} or when authenticated with a {% data variables.product.prodname_ghe_server %} host; users can opt out via `GH_TELEMETRY=false` or `gh config set telemetry disabled`.
- Telemetry payloads include structured JSON with event types (e.g., `skill_install`, `command_invocation`) and dimensions (e.g., OS, architecture, repo visibility), logged to stderr in debug mode (`GH_TELEMETRY=log`).
