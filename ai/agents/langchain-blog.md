# LangChain Blog

## Summary

- **Stripe's Kai AI Agent**: Built on LangChain's Deep Agents framework, Kai operates company-wide, integrating multi-tool workflows (e.g., code execution, API calls) with LangGraph for stateful orchestration and LangSmith for observability/evals.

- **LangSmith LLM Gateway**: Introduces runtime controls (e.g., model switching, rate limiting, input/output sanitization) for production agents, enabling governance, cost optimization, and compliance without code changes.

- **Deep Agents v0.7**: Adds tool abstraction layers, improved state management, and benchmarking tools (e.g., ReviewBench) for evaluating agent performance in tasks like code review and long-form research.
