# LangChain Blog

## Summary

- **Voice Agent Evaluation Framework**: Introduces a tripartite evaluation system for voice agents—**execution** (latency, error rates), **outcomes** (task completion, accuracy), and **experience** (user satisfaction metrics)—to ensure holistic performance assessment in production environments.

- **LangSmith LLM Gateway**: Provides **runtime controls** for production agents, enabling dynamic policy enforcement (e.g., rate limiting, model switching, fallback mechanisms) without code modifications, enhancing reliability and compliance in agentic systems.

- **Deep Agents v0.7 Release**: Adds **multi-agent orchestration** with hierarchical task delegation, **stateful memory** for persistent context, and **benchmarking tools** (e.g., IssueBench) to standardize agent evaluation across complex workflows.
