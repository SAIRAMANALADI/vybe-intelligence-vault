# AgentOps-AI/agentops

## Summary

- **Multi-framework integration**: Python SDK (`agentops`) supports monitoring and cost tracking for AI agents across frameworks including CrewAI, LangChain, Autogen, OpenAI Agents SDK, AG2, and CamelAI, with LLM compatibility for Anthropic, Groq, Mistral, Ollama, OpenAI, and others.

- **Core features**: Provides real-time monitoring, LLM cost estimation, benchmarking, and evaluation metrics for agentic workflows, enabling performance analysis and optimization.

- **Technical stack**: Lightweight Python-based SDK with minimal overhead, designed for seamless integration into existing agent pipelines and frameworks via modular hooks and APIs.
