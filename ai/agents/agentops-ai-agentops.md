# AgentOps-AI/agentops

## Summary

- **Comprehensive AI Agent Monitoring SDK**: Python-based SDK for real-time monitoring, cost tracking, and benchmarking of AI agents, supporting integration with major LMs (OpenAI, Anthropic, Mistral, Groq) and agent frameworks (CrewAI, LangChain, AutoGen, OpenAI Agents SDK, AG2, CamelAI, Agno, Ollama).

- **Multi-Faceted Agent Evaluation**: Enables performance evaluation via standardized metrics (`evals`), cost estimation (token/usage-based), and logging of agent interactions, facilitating debugging and optimization across heterogeneous agent ecosystems.

- **Production-Ready Tooling**: Supports deployment-ready features like session recording, latency tracking, and framework-agnostic instrumentation, with last update (July 2026) ensuring compatibility with modern AI agent architectures and SDKs.
