# WorkOS MCP: Manage your WorkOS account from any AI agent — WorkOS

## Summary

- **Remote MCP Server Integration**: WorkOS launches a remote MCP server enabling AI agents to manage WorkOS accounts with the same permissions as dashboard logins, eliminating manual UI navigation for configuration tasks.

- **Discover-Execute Tool Design**: The MCP server uses four tools (`whoami`, `list_operations`, `query`, `mutate`) to expose hundreds of WorkOS operations while optimizing LLM context usage, avoiding per-endpoint tool proliferation.

- **Security & Access Controls**: The server excludes sensitive operations (e.g., credential minting, billing) and enforces team-level access policies via dashboard toggles (Enable, Allow production access, Allow write access) for granular risk management.
