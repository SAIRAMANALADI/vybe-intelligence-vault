# B. SPDX license expressions - SPDX Specification 3.0.1

## Summary

- **SPDX 3.0.1 Core Model**: Defines foundational classes (`Element`, `Relationship`, `Agent`, `Artifact`, etc.), properties (e.g., `spdxId`, `created`, `externalRef`), and vocabularies (e.g., `RelationshipType`, `HashAlgorithm`) for structured software bill of materials (SBOM) and license compliance metadata.

- **Software Artifact Extensions**: Introduces software-specific classes (`Package`, `File`, `Snippet`, `Sbom`) with properties like `downloadLocation`, `packageUrl`, and `byteRange`, enabling precise tracking of software components and their relationships.

- **Security Vulnerability Support**: Integrates vulnerability assessment classes (`VexVulnAssessmentRelationship`, `CvssV3VulnAssessmentRelationship`, etc.) and standardized vocabularies to encode security advisories (e.g., VEX statuses, CVSS scores) within SBOMs.
