# B. SPDX license expressions - SPDX Specification 3.0.1

## Summary

- **SPDX 3.0.1 Core Model**: Defines 30+ classes (e.g., `SpdxDocument`, `Package`, `Relationship`) and 60+ properties (e.g., `spdxId`, `verifiedUsing`, `externalRef`) for structured software bill of materials (SBOM) and artifact metadata representation.

- **Software & Security Extensions**: Introduces software-specific classes (`File`, `Snippet`, `Sbom`) with properties like `byteRange`/`lineRange` and security-focused classes (`VexVulnAssessmentRelationship`, `CvssV3VulnAssessmentRelationship`) for vulnerability assessment integration.

- **Vocabularies & Serializations**: Standardizes controlled vocabularies (e.g., `HashAlgorithm`, `SoftwarePurpose`) and supports multiple serialization formats (JSON, YAML, RDF/XML) per the `Model and serializations` section.
