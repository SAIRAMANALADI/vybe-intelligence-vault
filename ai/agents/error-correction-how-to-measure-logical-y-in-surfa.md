# error correction - How to measure logical Y in Surface code? - Quantum Computing Stack Exchange

## Summary

- **Logical Y measurement in surface code requires topological manipulation of twist defects**—specifically, fusing diagonally opposite twists to transition between X/Z and Y basis measurement configurations.

- **Fault-tolerant implementation involves domain wall circuit operations**, where half the patch is measured in one basis while the other half is not, enabling Y-basis readout without transversal operations.

- **In simulation contexts (e.g., Gidney’s "Magic State Cultivation")**, logical Y can be measured directly via Pauli product observables (e.g., `iXZ`) due to the absence of hardware noise, bypassing the need for topological deformations.
