# Release policy - Docs by LangChain

## Summary

- **Semantic Versioning & API Stability**:
  - LangChain/LangGraph follow semantic versioning (semver) post v1.0, with breaking changes restricted to major versions (`X.0.0`), minor versions (`0.X.0`) adding features non-disruptively, and patches (`0.0.X`) for bug/security fixes.
  - Deprecated APIs persist through minor versions, with removal only in major releases; migration guidance provided.

- **Release Cadence & LTS Policies**:
  - LangChain minor releases frequent (weeks), patches multiple/week; LangGraph minor releases every 1-2 months, major every 6-12 months.
  - LTS: LangChain v1.0 ACTIVE until v2.0, then MAINTENANCE for ≥1 year; legacy v0.3 supported until Dec 2026.

- **Deep Agents Pre-1.0 & Compatibility**:
  - Deep Agents (`deepagents`) pre-v1.0: minor releases may break APIs; experimental/alpha features subject to significant change.
  - Python ≥3.10 required; breaking changes (e.g., Python version updates) only in major releases.
