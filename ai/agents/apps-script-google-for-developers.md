# Apps Script | Google for Developers

## Summary

- **Cloud-based JavaScript platform**: Apps Script is a serverless, cloud-based JavaScript runtime integrated with Google Drive, enabling automation and integration across Google Workspace products.

- **Key capabilities**: Supports automations (via menus, triggers, or schedules), custom Google Sheets functions, add-ons (extending Workspace apps), and AI-powered features (e.g., Vertex AI, Gemini Enterprise, ADK/A2A agents).

- **Development & deployment**: Provides REST API for programmatic script management, release notes for updates, and resources (samples, codelabs) for building AI-driven Workspace solutions (e.g., Gmail analyzers, Travel Concierge agents).
