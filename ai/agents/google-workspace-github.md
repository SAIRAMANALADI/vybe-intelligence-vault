# Google Workspace · GitHub

## Summary

- **Google Workspace CLI**: A unified Rust-based CLI tool dynamically built from Google Discovery Service, enabling interactions with Drive, Gmail, Calendar, Sheets, Docs, Chat, and Admin APIs, with integrated AI agent capabilities.

- **Multi-Language Sample Repositories**: Hosts official samples in Python (`python-samples`), JavaScript (`apps-script-samples`), Go (`go-samples`), and other languages, licensed under Apache-2.0, demonstrating API usage across Google Workspace services.

- **Specialized API Samples**: Includes repositories like `meet-media-api-samples` (C++) for real-time Google Meet media access and `google-docs-hast` (TypeScript) for converting Google Docs JSON to HTML abstract syntax trees.
