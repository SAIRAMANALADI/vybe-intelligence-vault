# Apache SpamAssassin: Welcome

## Summary

- **Multi-layered spam detection**: Apache SpamAssassin employs heuristic, statistical (Bayesian filtering), DNS blocklists, and collaborative filtering techniques to classify emails, with a scoring framework to evaluate spam likelihood.

- **Modular and extensible**: Uses plain-text rule configuration (`.cf` files) and plugins (e.g., Redirector in v4.0.2) for easy customization, supporting integration with email systems like Postfix, Sendmail, and Procmail via `Mail::SpamAssassin` API.

- **Active development and security focus**: Latest stable release (v4.0.2, Aug 2025) ensures Perl 5.42 compatibility and addresses CVEs (e.g., CVE-2020-1946 in v3.4.5), with no further updates planned for the 3.4.x branch.
