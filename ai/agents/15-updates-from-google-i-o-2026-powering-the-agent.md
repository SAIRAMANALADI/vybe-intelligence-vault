# 15 updates from Google I﻿/﻿O 2026: Powering the agentic web with new capabilities, tools, and features in Chrome | Blog

## Summary

- **WebMCP Standard**: Introduces an open web standard enabling structured tool exposure (e.g., JavaScript functions, HTML forms) for browser-based agents, allowing direct API interactions for complex tasks like travel itinerary generation. Experimental origin trial begins in Chrome 149, with Gemini in Chrome integration planned.

- **HTML-in-Canvas & View Transitions**: New APIs (`HTML-in-Canvas`, `element-scoped view transitions`) enable high-fidelity, app-like UIs by integrating DOM elements into canvas (WebGL/WebGPU) and declarative transitions for layered animations. Origin trial available for `HTML-in-Canvas`; `element-scoped view transitions` live in Chrome 147.

- **Built-in AI & Auto Browse**: Expands Chrome’s AI toolkit with stable `Prompt API` (multimodal inputs, structured JSON) and ultra-efficient `Gemma 197M` model. `Auto browse` automates multi-step tasks (e.g., parking booking) across desktop/Android, while `Nano Banana` enables on-device image transformations.
