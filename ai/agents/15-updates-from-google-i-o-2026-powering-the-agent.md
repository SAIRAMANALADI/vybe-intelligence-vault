# 15 updates from Google I﻿/﻿O 2026: Powering the agentic web with new capabilities, tools, and features in Chrome | Blog

## Summary

- **WebMCP Standard**: Introduces an open web standard enabling structured tool exposure (e.g., JavaScript functions, HTML forms) for browser-based agents, allowing direct API interactions (e.g., travel itinerary generation) with precision. Origin trial starts in Chrome 149, with Gemini integration planned.

- **Built-in AI Suite Expansion**: Adds stable Prompt API (Gemini Nano with multimodal/structured outputs) and ultra-efficient Gemma 197M model for on-device AI tasks (e.g., Trip.com’s travel summaries), eliminating server dependencies and token costs.

- **HTML-in-Canvas & Declarative APIs**: New APIs (HTML-in-Canvas, element-scoped view transitions) enable high-fidelity, app-like UIs with native DOM integration and declarative performance optimizations (e.g., Soft Navigations for SPAs, Declarative Partial Updates).
