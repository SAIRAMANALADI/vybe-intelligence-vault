## Summary

- **Server-Side Evaluation**: Enforces server-only flag evaluation (no client-side spinners) with precomputed, context-aware decisions for consistent A/B testing and controlled rollouts.
- **Declarative API**: Simple `flags.ts` configuration (e.g., `flag({ key: 'example-flag', decide() { return Math.random() > 0.5; } })`) and framework-specific hooks (Next.js `flags/next`, SvelteKit `flags/sveltekit`).
