# uber/ADR

## Summary

- **Purpose & Scope**: ADR (Agent Detection & Response) is an enterprise-grade security framework for AI agents, providing observability, security benchmarking, and real-time threat detection, with production deployment at Uber.

- **Core Features**:
  - **Threat Detection**: Mitigates risks like prompt injection, adversarial attacks, and unauthorized agent actions via runtime monitoring.
  - **Benchmarking**: Evaluates AI agent security posture against standardized benchmarks (e.g., LLM-specific threats) using Python-based tooling.

- **Technical Stack & Integration**:
  - Built in Python with support for MCP (Model Context Protocol) and compatibility with agents/tools like Claude, Codex, and Cursor.
  - Enables security auditing of agent workflows, MCP servers, and LLM interactions in enterprise environments.
