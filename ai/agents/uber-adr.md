# uber/ADR

## Summary

- **Purpose**: ADR (Agent Defense Runtime) secures enterprise AI agents via observability, security benchmarking, and real-time threat detection, deployed at Uber.
- **Technical Stack**: Python-based, integrates with MCP (Model Context Protocol) and supports security evaluation against prompt injection, LLM vulnerabilities, and agent-specific threats.
- **Features**: Provides benchmarking for AI agents, threat detection mechanisms, and runtime security monitoring for frameworks like Claude, Codex, and Cursor.
