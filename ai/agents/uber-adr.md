# uber/ADR

## Summary

- **Purpose**: ADR (Agent Detection & Response) framework secures enterprise AI agents via observability, security benchmarking, and threat detection, with production deployment at Uber.
- **Technical Scope**: Implements defenses against prompt injection, LLM-specific threats, and Model Context Protocol (MCP) vulnerabilities; supports agents built with tools like Claude, Codex, and Cursor.
- **Implementation**: Python-based toolkit providing security benchmarks, threat detection mechanisms, and observability features for AI agent ecosystems.
