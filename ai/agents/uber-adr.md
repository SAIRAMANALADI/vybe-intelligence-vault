# uber/ADR

## Summary

- **Purpose & Scope**: ADR (Agent Defense Runtime) is an enterprise-grade security framework for AI agents, providing observability, security benchmarking, and threat detection mechanisms to mitigate risks like prompt injection and adversarial attacks in production environments (e.g., Uber's deployments).

- **Technical Architecture**: Implemented in Python, ADR integrates with LLM frameworks (e.g., Claude, Codex) and protocols (e.g., MCP/Model Context Protocol) to enforce security policies, monitor agent behavior, and benchmark against known attack vectors.

- **Deployment & Features**: Supports threat detection for AI agents (e.g., via prompt injection defenses) and includes benchmarking tools to evaluate agent resilience, with active maintenance and updates as of 2026-09-02.
