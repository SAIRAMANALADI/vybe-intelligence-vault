# Agent Infrastructure for TypeScript

## Summary

- **Prisma ORM** provides schema-first TypeScript database access with auto-generated, type-safe clients, compile-time validation, and IDE autocomplete for CRUD operations.

- **Prisma Postgres** offers managed PostgreSQL with built-in connection pooling, optimized for modern deployments and seamless integration with Prisma ORM and Compute.

- **Prisma Compute** enables deployment of long-lived TypeScript applications (e.g., APIs, AI agents) as containerized processes near the database, reducing serverless constraints and eliminating infrastructure stitching.
