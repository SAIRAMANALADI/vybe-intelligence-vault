# Docker Model Runner | Docker Docs

## Summary

- **Multi-Engine AI Model Serving**: Supports `llama.cpp` (GGUF, all platforms), `vLLM` (Safetensors, NVIDIA GPUs/Linux), and `Diffusers` (Stable Diffusion, NVIDIA GPUs) for inference, with OpenAI/Ollama-compatible APIs for integration.
- **Registry & Model Management**: Pulls models from Docker Hub, OCI-compliant registries, or Hugging Face; caches locally; and packages GGUF/Safetensors as OCI Artifacts for registry publishing.
- **Security & Isolation**: Runs inference engines in containers (Linux) or sandboxed environments (macOS/Windows); API lacks authentication, exposing endpoints to local Docker networks.
