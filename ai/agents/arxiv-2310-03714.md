# [2310.03714] DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines

## Summary

- **DSPy Programming Model**: Introduces a declarative framework for constructing LM pipelines as parameterized text transformation graphs, abstracting LM calls into modular, optimizable components (e.g., prompting, fine-tuning, reasoning) without hard-coded prompt templates.

- **Self-Optimizing Compiler**: Implements a compiler that automatically optimizes DSPy pipelines by learning optimal module configurations (e.g., via demonstrations) to maximize task-specific metrics, enabling rapid adaptation (e.g., 25–65% performance gains over few-shot prompting in minutes).

- **Empirical Validation**: Demonstrates competitive performance against expert-designed pipelines across tasks (e.g., math reasoning, multi-hop retrieval) using both proprietary (GPT-3.5) and open (llama2-13b, T5-770M) LMs, with compiled DSPy programs outperforming baselines by up to 46% and 40%, respectively.
