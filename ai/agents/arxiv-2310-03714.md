# [2310.03714] DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines

## Summary

- **DSPy Programming Model**: Introduces a declarative framework where language model (LM) pipelines are represented as parameterized computational graphs, enabling systematic optimization of LM calls through prompting, fine-tuning, and augmentation without hard-coded prompt templates.

- **Self-Improving Pipeline Compiler**: Features a compiler that automatically optimizes DSPy pipelines by learning from demonstrations, achieving performance gains of >25% (GPT-3.5) and >65% (llama2-13b-chat) over standard few-shot prompting, and outperforming expert-designed pipelines by up to 46%.

- **Cross-Model Competitiveness**: Demonstrates that DSPy-compiled pipelines on smaller open-source LMs (e.g., 770M-parameter T5, llama2-13b-chat) can match or exceed proprietary GPT-3.5-based approaches with expert-written prompt chains, highlighting scalability and efficiency.
