# Durable Execution Solutions | Temporal

## Summary

- **Durable Execution Layer**: Temporal provides a fault-tolerant runtime that automatically captures and restores workflow state, ensuring seamless recovery from failures (e.g., crashes, API timeouts) without manual intervention or lost progress.

- **SDK Integration**: Native SDKs (Python, TypeScript, Java, etc.) enable writing business logic in preferred languages while abstracting reliability concerns (retries, state persistence, task queues) via Activities and Workflows.

- **Enterprise-Grade Patterns**: Supports long-running workflows (e.g., AI agent loops, order fulfillment) with built-in compensating transactions (Saga), visibility tools, and integrations (Google ADK, OpenAI Agents SDK) for scalable, observable systems.
