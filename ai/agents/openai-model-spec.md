# model_spec/CHANGELOG.md at main · openai/model_spec · GitHub

## Summary

- **Under-18 Safety Mode** introduced (v2025.12.18), adding age-specific safety rules for users aged 13-17, alongside tightened honesty guidelines and restrictions on tracking user engagement metrics unless aligned with genuine value.
- **Chain of Command** updated (v2025.10.27) to allow implicit delegation of authority to tool outputs (e.g., AGENTS.md instructions) and expanded self-harm policies to include delusions/mania, with new "respect real-world ties" guidance.
- **Root Authority** redefined (v2025.09.12) with Root > System precedence, added agent-specific principles (scope autonomy, side-effect control), and enforced **No Other Objectives** while transitioning to **Safe Completions** for policy-compliant responses.
