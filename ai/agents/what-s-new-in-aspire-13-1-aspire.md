# What's new in Aspire 13.1 | Aspire

## Summary

- **MCP Integration**: New `aspire agent init` command and MCP tools (`list_integrations`, `get_integration_docs`, `list_apphosts`, `select_apphost`) enable AI coding agents to interact with Aspire applications, including dashboard resource state queries and log inspection.

- **CLI Enhancements**: Channel persistence via `aspire update --self`, automatic instance detection in `aspire run`, and `--skip-path` installation option improve developer workflow and configuration flexibility.

- **Azure & Container Improvements**: Renamed `AddAzureManagedRedis` (breaking change from `AddAzureRedisEnterprise`), standardized multi-language Azure connection properties, and new `ContainerRegistryResource` for general-purpose registries with experimental deployment pipeline `push` step.
