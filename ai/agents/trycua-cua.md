# trycua/cua

## Summary

- **Multi-OS Sandboxing Framework**: Provides isolated, reproducible environments for macOS, Linux, and Windows to safely train and evaluate AI agents capable of full desktop control via containerization and virtualization (e.g., Apple's Virtualization Framework, Windows Sandbox).

- **Agent SDK & Benchmarks**: Includes a Software Development Kit (SDK) for building Computer-Use Agents (CUAs) and standardized benchmarks to assess agent performance in desktop automation tasks across different operating systems.

- **Open-Source Toolchain**: Integrates Swift (macOS), Lume (cross-platform), and Manus (agent framework) with Hacktoberfest support, enabling community-driven development for desktop automation, virtualization, and AI agent orchestration.
