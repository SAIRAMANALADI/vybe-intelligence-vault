# trycua/cua

## Summary

- **Cross-platform agent infrastructure**: Provides sandboxed environments, SDKs, and benchmarks for training/evaluating AI agents capable of full desktop control on macOS, Linux, and Windows via containerization and virtualization (e.g., Windows Sandbox, Apple Virtualization Framework).

- **Modular tooling**: Includes `lume` (agent framework) and `manus` (agent runtime) with Swift-based macOS support, enabling agent development, testing, and deployment across heterogeneous desktop OS environments.

- **Benchmarking & automation**: Offers standardized tasks for evaluating agent performance in desktop automation, with active community contributions (Hacktoberfest) and last update (July 2026) ensuring ongoing compatibility with modern OS APIs.
