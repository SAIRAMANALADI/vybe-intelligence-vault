# GitHub Docs

## Summary

- GitHub supports **secure authentication** via SSH, tokens, and passwords, with detailed docs on [SSH setup](https://docs.github.com/en/authentication/connecting-to-github-with-ssh) and [authentication methods](https://docs.github.com/en/authentication).

- **Collaborative workflows** are enabled through [pull requests](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests), [GitHub Actions](https://docs.github.com/en/actions) for CI/CD, and [Codespaces](https://docs.github.com/en/codespaces) for cloud-based development.

- **Security and code quality** are enforced via [CodeQL](https://codeql.github.com/docs) for vulnerability analysis, [secret scanning](https://docs.github.com/en/code-security/how-tos/secure-your-secrets), and [supply chain security](https://docs.github.com/en/code-security/how-tos/secure-your-supply-chain).
