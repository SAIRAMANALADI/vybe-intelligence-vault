# GitHub Docs

## Summary

- **GitHub Core Functionality**: GitHub integrates Git (open-source VCS) with cloud-based collaboration tools, enabling repository creation, version control, and distributed development workflows via SSH authentication and HTTPS remoting.

- **CI/CD & Automation**: Supports end-to-end DevOps pipelines through GitHub Actions for workflow automation, GitHub Packages for artifact management, and GitHub Pages for static site hosting.

- **Security & Developer Tools**: Provides CodeQL for static analysis, GitHub Copilot for AI-assisted coding, and REST/GraphQL APIs for programmatic access to repositories, webhooks, and enterprise-scale security controls.
