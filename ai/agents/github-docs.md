# GitHub Docs

## Summary

- **Core GitHub Services**: GitHub provides version control via Git, secure remote repository hosting, and collaborative tools like Pull Requests, GitHub Actions (CI/CD), and Codespaces for cloud-based development environments.
- **Security & Compliance**: Supports secure authentication (SSH, tokens), secret management, vulnerability scanning (CodeQL), supply chain security, and enterprise-scale security policies.
- **Developer & API Ecosystem**: Offers REST/GraphQL APIs, Webhooks for automation, GitHub CLI for CLI-based workflows, and integrations with third-party tools like npm and Electron.
