# LangSmith Evaluation - Docs by LangChain

## Summary

- **Offline Evaluation**: Pre-deployment testing on curated datasets using evaluators (human, code, LLM-as-judge, pairwise) to benchmark performance, catch regressions, and validate fixes via experiments and analysis.

- **Online Evaluation**: Real-time production monitoring of live user interactions using automated evaluators (safety, format, quality heuristics, reference-free LLM-as-judge) with configurable sampling rates for anomaly detection and feedback loop integration.

- **Workflow Integration**: Structured process for both evaluation types—offline involves dataset creation, evaluator definition, experiment execution, and result analysis; online includes deployment, evaluator configuration, real-time monitoring, and feedback-driven dataset updates.
