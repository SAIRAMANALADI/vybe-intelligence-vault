# OpenTelemetry

## Summary

- **Unified Observability Framework**: OpenTelemetry provides a single set of APIs, SDKs, and tools to capture distributed traces, metrics, and logs from cloud-native applications, consolidating observability signals (traces, metrics, logs, baggage) with shared context propagation for end-to-end correlation.

- **Vendor-Neutral & Multi-Language Support**: Instrument applications once using OpenTelemetry APIs/SDKs (12+ languages) and export telemetry to any backend (e.g., Jaeger, Prometheus) without vendor lock-in; supports auto-instrumentation and 200+ collector components for scalable data processing.

- **CNCF-Graduated & Production-Ready**: Backed by the Cloud Native Computing Foundation (CNCF), OpenTelemetry offers stable APIs, open specifications (OTLP), and is deployed in production by major enterprises (e.g., eBay, GitHub, Shopify), ensuring long-term stability and community-driven evolution.
