# OpenTelemetry

## Summary

- **Unified Observability Framework**: OpenTelemetry provides a single set of APIs, SDKs, and tools to capture distributed traces, metrics, and logs from cloud-native applications, consolidating observability signals (traces, metrics, logs, baggage) with shared context propagation across service boundaries.

- **Vendor-Neutral & Multi-Language Support**: Instrument applications once using OpenTelemetry APIs/SDKs (12+ languages) and export telemetry to any backend (Jaeger, Prometheus, commercial vendors) without vendor lock-in; supports auto-instrumentation and 200+ collector components for scalable data processing.

- **CNCF-Graduated & Production-Ready**: Backed by the CNCF with stable, open specifications (OTLP) and governance; deployed in production by major organizations (e.g., eBay, GitHub, Shopify) with zero-code instrumentation and hybrid/multi-cloud deployment flexibility.
