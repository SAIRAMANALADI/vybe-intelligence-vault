# OpenTelemetry

## Summary

- **Unified Observability Framework**: OpenTelemetry provides a single set of APIs, libraries, and collector services to capture distributed traces, metrics, and logs from cloud-native applications, consolidating observability signals under a vendor-neutral standard.

- **Multi-Language & Zero-Code Instrumentation**: Supports 12+ languages (e.g., Java, Python, Go) with native SDKs and auto-instrumentation agents, enabling zero-code integration for popular frameworks while ensuring context propagation across service boundaries.

- **Open Specifications & Scalable Deployment**: Built on CNCF-governed, open specifications (e.g., OTLP) with 200+ collector components, supporting hybrid/multi-cloud deployments and seamless backend switching without code changes.
