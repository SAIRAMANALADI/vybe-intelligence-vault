# LangChain: Observe, Evaluate, and Deploy Reliable AI Agents

## Summary

- **Multi-framework observability**: LangSmith provides native tracing for popular agent frameworks (e.g., LangChain, LangGraph) and OpenTelemetry, with SDKs in Python, TypeScript, Go, and Java, enabling structured debugging via step-by-step execution timelines and AI-driven insights.

- **Automated evaluation & deployment**: Supports reusable LLM-as-judge evals, human feedback calibration, and scalable agent deployment with durable checkpointing, async collaboration, and native protocol support (A2A & MCP) for fault-tolerant, distributed runtimes.

- **Enterprise-grade agent orchestration**: Fleet enables autonomous task execution across tools via plain-language prompts, with BYOM (Bring Your Own Model) support, MCP server extensibility, and integrated LangSmith tracing for iterative improvement based on user feedback.
