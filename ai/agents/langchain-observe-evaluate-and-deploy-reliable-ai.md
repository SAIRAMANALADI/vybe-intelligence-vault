# LangChain: Observe, Evaluate, and Deploy Reliable AI Agents

## Summary

- **Multi-framework observability**: LangSmith provides native tracing for popular agent frameworks (e.g., LangChain, LangGraph) and OpenTelemetry, with SDKs in Python, TypeScript, Go, and Java; supports message threading for multi-turn interactions and AI-driven analytics for trace pattern detection.

- **Automated evaluation & deployment**: Enables LLM-as-judge and multi-turn evaluations with human feedback calibration; supports online/offline scoring; deploys agents via a fault-tolerant runtime with durable checkpointing, async concurrency, and native A2A/MCP protocol support.

- **Enterprise agent orchestration**: Fleet allows low-code agent creation with BYOM (Bring Your Own Model) support, MCP server integration, and LangSmith-integrated tracing; scales via distributed runtimes for agent swarms with enterprise-grade security and admin controls.
