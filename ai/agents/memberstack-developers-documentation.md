# Memberstack Developers Documentation

## Summary

- **DOM Package**: Pre-built client-side components for authentication, member management, and gated content integration via JavaScript/TypeScript.

- **Admin Node Package & REST API**: Server-side tools for secure member/plan/data management using secret keys (Node SDK) or HTTP endpoints (REST API) with bearer token authentication.

- **MCP Server**: Enables AI agents (e.g., Claude, Cursor) to safely access Memberstack data via structured, language-agnostic interfaces.
