# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Agent Framework**: SpeechifyAI Agents provides a reusable definition system combining prompt, voice, tools, and evaluation criteria, enabling real-time voice interactions via web or phone with low-latency speech-to-speech pipelines.

- **Tool Integration & Evaluation**: Agents support dynamic tool integration (backend calls, device execution, MCP servers) with real-time transcripts, tool traces, and post-call LLM-graded evaluations for structured data extraction.

- **Deployment & Workflow**: Agents are deployed via `POST /v1/agents/{id}/conversations`, returning a session token/URL for browser/SDK connection; no-code console workflows and webhook-based post-call monitoring are supported.
