# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Agent Framework**: SpeechifyAI Agents provides a reusable definition system combining prompt, voice, tools, and evaluation criteria for real-time voice interactions via `POST /v1/agents/{id}/conversations`, returning a short-lived token/URL for session initiation.

- **Core Features**: Supports low-latency real-time audio processing, tool integration (backend APIs, device execution, MCP servers, built-ins like `end_call`), persistent transcripts with tool traces, and post-call LLM-graded evaluations.

- **Use Cases & Deployment**: Enables inbound/outbound support, IVR replacement, and structured data collection; deployable via no-code console or API with Speechify voices (excluding cloned/personal voices) and webhook-based lifecycle monitoring.
