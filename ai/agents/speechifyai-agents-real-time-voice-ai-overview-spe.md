# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Real-time voice agents**: Deployable via `POST /v1/agents/{id}/conversations`, enabling low-latency bidirectional audio streams with integrated tools (e.g., `end_call`, `transfer_to_number`) and persistent transcripts with timestamps and tool traces.

- **Agent configuration**: Defined by reusable components—prompt, voice (from curated `GET /v1/agents/voices` catalog), tools (backend, device, MCP), and post-call LLM-graded evaluations—supporting inbound/outbound use cases (support, IVR replacement).

- **No-code & SDK integration**: Console-based agent setup (prompt, voice, knowledge, phone number) with SDK/browser session initiation via short-lived tokens; webhook support for post-call events and full API reference for `/v1/agents` endpoints.
