# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Agent Definition**: Configurable entity with prompt, voice, tools, and evaluation criteria, enabling real-time voice interactions via web/phone, provisioned via `POST /v1/agents/{id}/conversations` with a short-lived token for session initiation.

- **Core Features**: Low-latency real-time pipeline with Speechify voices (excluding cloned/personal voices), tool integration (backend calls, device execution, MCP servers, built-ins like `end_call`), and persistent transcripts with tool traces and post-call LLM-graded evaluations.

- **Use Cases & Workflow**: Supports inbound/outbound support, IVR replacement, and structured data collection; no-code console available for agent configuration, with API-driven lifecycle management and webhook notifications for conversation completion.
