# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Agent Architecture**: Speechify Agents are defined by reusable configurations including prompt, voice, tools, and evaluation criteria, enabling real-time voice interactions via `POST /v1/agents/{id}/conversations` with low-latency speech-to-speech pipelines.

- **Tool Integration**: Supports dynamic tool invocation (backend APIs, device code execution, MCP servers) with built-ins like `end_call` and `transfer_to_number`, while transcripts and tool traces are persisted per turn.

- **Deployment & Evaluation**: Provides no-code console workflows for agent creation, supports IVR replacement and outbound follow-ups, and includes post-call LLM-graded evaluations with structured data extraction via webhooks.
