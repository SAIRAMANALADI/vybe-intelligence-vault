# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Agent Framework**: SpeechifyAI Agents enables real-time voice interactions via a reusable agent definition (prompt, voice, tools, evaluation criteria) accessible over web/phone, with API endpoints (`POST /v1/agents/{id}/conversations`) provisioning low-latency sessions and returning session tokens/URLs for client SDKs.

- **Core Features**: Supports curated Speechify voices (excluding cloned/personal voices), persistent transcripts with timestamps/tool traces, post-call LLM-graded evaluations, and tool integrations (backend calls, device execution, MCP servers, built-ins like `end_call`).

- **Use Cases & Workflow**: Designed for inbound/outbound support, IVR replacement, and structured data collection; offers no-code console configuration with webhook support for conversation completion events and full API reference for schema management.
