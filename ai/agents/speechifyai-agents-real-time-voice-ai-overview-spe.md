# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Realtime Voice Pipeline**: Agents use a low-latency realtime pipeline via `POST /v1/agents/{id}/conversations` to enable speech-in, agent-response, and speech-out interactions, with audio/transcripts/tool calls streamed over a provisioned session.

- **Agent Definition & Tools**: Agents are reusable configurations (prompt, voice, tools) supporting backend integration, device-side code execution, MCP server connections, and built-ins (e.g., `end_call`, `transfer_to_number`), with transcripts and LLM-graded evaluations persisted post-call.

- **Use Cases & Deployment**: Enables inbound/outbound support, IVR replacement, and no-code deployment via console (prompt, voice, knowledge, phone number) with version-pinned API stability (check changelog for updates).
