# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Agent Architecture**: SpeechifyAI Agents enable real-time voice interactions via a reusable definition combining prompt, voice, tools, and evaluation criteria, accessible via web/phone with low-latency speech-to-speech processing (`POST /v1/agents/{id}/conversations`).

- **Core Features**: Supports curated Speechify voices (excluding cloned/personal), tool integrations (backend, device code, MCP servers, built-ins like `end_call`), persistent transcripts with timestamps/tool traces, and post-call LLM-graded evaluations.

- **Use Cases & Workflow**: Designed for inbound/outbound support, IVR replacement, and structured data collection; offers no-code console deployment with webhook-based lifecycle event notifications and full API reference for `/v1/agents` endpoints.
