# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Real-time voice agents**: SpeechifyAI Agents enables low-latency, real-time voice interactions via `POST /v1/agents/{id}/conversations`, provisioning sessions with natural voices (`GET /v1/agents/voices`) and tool integrations (e.g., `end_call`, `transfer_to_number`).

- **Structured workflows**: Agents combine prompts, voices, tools (backend, device, MCP), and post-call evaluations (LLM-graded criteria, structured data extraction) with persisted transcripts and tool traces.

- **Use cases & deployment**: Supports inbound/outbound support, IVR replacement, and no-code console setup; API endpoints (`/v1/agents`, `/v1/agents/conversations`) require pinned versions due to beta-stage schema changes.
