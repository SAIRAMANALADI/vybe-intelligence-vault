# SpeechifyAI Agents: Real-Time Voice AI Overview | SpeechifyAI API

## Summary

- **Agent Architecture**: Agents are reusable definitions combining prompt, voice, tools, and evaluation criteria, enabling real-time voice interactions via `POST /v1/agents/{id}/conversations` with low-latency speech-in/speech-out pipelines and persistent transcripts with tool traces.

- **Tool Integration**: Supports backend calls, device-side code execution, MCP server connections, and built-ins (`end_call`, `transfer_to_number`), with structured post-call evaluations and LLM-graded criteria.

- **Deployment Options**: Available via API for programmatic control or no-code in the Speechify console, supporting inbound/outbound support, IVR replacement, and phone number routing with webhook-based post-conversation notifications.
