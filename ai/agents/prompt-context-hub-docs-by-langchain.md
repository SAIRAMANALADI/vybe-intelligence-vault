# Prompt & Context Hub - Docs by LangChain

## Summary

- **Versioned Prompt Management**: Enables non-engineering domain experts to create, update, and version-control prompts (message templates) and retrieval contexts via UI/SDK, decoupling prompt changes from application code deployment.

- **Context Hub for Agent/Skill Bundles**: Supports versioned, environment-promoted bundles of instructions/tools defining agent skills or full workflows, with features like tagging, webhooks, and SDK-based repo management (push/pull/delete).

- **Integrated Testing & Deployment**: Provides a Playground for prompt testing with custom endpoints, AI-assisted optimization, and MCP integration for real-time updates across tools (e.g., VSCode), with observability and evaluation in cloud/hybrid/self-hosted LangSmith instances.
