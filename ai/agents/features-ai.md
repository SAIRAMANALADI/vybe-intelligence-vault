# GitHub Copilot app · GitHub

## Summary

- **Agent-Driven Development Environment**: GitHub Copilot app provides a native desktop experience for agent-driven development across macOS, Windows, and Linux, integrating with GitHub issues, PRs, and prompts to enable parallel workflows with isolated sessions, built-in validation (diffs, browser preview, terminal checks), and direct PR merging.

- **Design & Automation Integration**: Includes **Impeccable** (open-source design skill) with 23 commands (e.g., `/critique`, `/typeset`) for design system enforcement, and supports automated workflows via scheduled tasks (e.g., "Morning triage") with customizable prompts and one-click skill deployment.

- **Multi-Plan Pricing & Extensibility**: Free tier offers 2K completions/month; Pro ($10/user) adds unlimited completions, model selection, and 3rd-party agents; Pro+ ($39) includes premium models (e.g., Opus) and audit logs; Max ($100) offers priority access and 2.9x usage vs. Pro+. Supports MCP servers, custom skills, and external data integration for tool extensibility.
