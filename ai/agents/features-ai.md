# GitHub Copilot app · GitHub

## Summary

- **Multi-platform agent-driven development**: GitHub Copilot app provides a native desktop experience for agent-driven workflows on macOS, Windows, and Linux, supporting parallel sessions across issues, PRs, and prompts with isolated workspaces for branches, files, and conversations.

- **Built-in validation and automation**: Features include in-app diff inspection, terminal checks, PR merging, and scheduled workflows (e.g., "Morning triage") with automated execution; integrates design skills (e.g., Impeccable) for automated critiques, typography fixes, and layout adjustments.

- **Customizable agent extensions**: Supports native GitHub context integration, custom MCP servers/plugins, and one-click deployment of repo-specific skills; pricing tiers range from Free ($0) to Max ($100/month), with Pro+ ($39) and Max offering premium models and higher usage credits.
