# GitHub Copilot app · GitHub

## Summary

- **Native agent-driven development**: GitHub Copilot app provides a desktop experience for agent workflows, natively integrated with GitHub (issues, PRs, repos), supporting macOS, Windows, and Linux across all Copilot plans or custom API keys.

- **Isolated, multi-session workflows**: Enables parallel agent sessions with isolated workspaces (branches, files, conversations), built-in validation (diffs, in-app previews, terminal checks), and automated workflows (scheduled tasks, custom skills via MCP servers).

- **Tiered pricing with agent features**: Free tier includes 2K completions/month; Pro ($10/user) adds unlimited completions, cloud agents, and third-party integrations; Pro+ ($39) includes premium models (e.g., Opus) and audit logs; Max ($100) offers priority access and 2.9x Pro+ usage.
