# GitHub Copilot app · GitHub

## Summary

- **Native agent-driven development**: GitHub Copilot app integrates agent workflows directly into GitHub, supporting macOS, Windows, and Linux, with sessions isolated per task and deep context from issues, PRs, and code.
- **Built-in design and automation**: Includes Impeccable (open-source design skill) with 23 commands (e.g., `/critique`, `/polish`) and supports automated workflows via scheduled tasks or custom skills.
- **Tiered pricing model**: Offers Free ($0, 2K completions/month), Pro ($10/user, unlimited completions), Pro+ ($39/user, premium models), and Max ($100/user, high-volume workflows with priority access).
