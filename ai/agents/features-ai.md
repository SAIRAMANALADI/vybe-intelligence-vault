# GitHub Copilot app · GitHub

## Summary

- **Agent-Driven Development**: GitHub Copilot app provides a native desktop experience for agent-driven development, supporting macOS, Windows, and Linux, with sessions isolated per task (issues, PRs, or prompts) and built-in validation (diffs, in-app browser, terminal checks, PR merges).

- **Design & Automation Integration**: Includes **Impeccable** (open-source design skill) with 23 commands (e.g., `/critique`, `/polish`) for design system enforcement, and supports automated workflows (scheduled, repeatable tasks) with custom skills/MCP server integration for extended functionality.

- **Multi-Tier Pricing & Model Access**:
  - **Free**: 2K completions/month, CLI, and app access.
  - **Pro ($10)**: Unlimited completions, Cloud agent, 3rd-party agents (Claude/Codex), and model selection.
  - **Pro+ ($39)**: Premium models (e.g., Opus), audit logs, 4x Pro usage.
  - **Max ($100)**: Priority access, 2.9x Pro+ usage, $200 credits/month.
