# GitHub Copilot app · GitHub

## Summary

- **Native Agent-Driven Development**: GitHub Copilot app is a desktop tool for agent-driven development, natively integrated with GitHub, supporting macOS, Windows, and Linux across all Copilot plans.

- **Isolated, Parallel Workflows**: Supports multiple isolated sessions per task (issues, PRs, prompts) with built-in validation (diffs, terminal checks, PR merging) and automated workflows (scheduled, repeatable tasks).

- **Extensible & Customizable**: Integrates native GitHub context, supports custom MCP servers/plugins/skills, and offers design tools (e.g., Impeccable skill) with tiered pricing ($0–$100/user/month) for varying agent workflow demands.
