# GitHub Copilot app · GitHub

## Summary

- **Native Agent-Driven Development**: GitHub Copilot app provides a desktop experience for agent-driven development, natively integrated with GitHub, supporting macOS, Windows, and Linux across all Copilot plans or custom API keys.

- **Isolated Multi-Session Workflows**: Enables parallel workflows with isolated sessions per task (issues, PRs, or prompts), featuring built-in validation (diffs, in-app browser previews, terminal checks) and automated workflows (e.g., scheduled issue triage).

- **Extensible & Customizable**: Supports native GitHub context integration, custom skills/plugins (e.g., Impeccable design toolkit), and external data via MCP servers; pricing tiers range from Free ($0) to Max ($100/month) with varying feature access and usage limits.
