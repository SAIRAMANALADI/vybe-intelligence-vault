# GitHub Copilot app · GitHub

## Summary

- **Native Agent-Driven Development**: GitHub Copilot app integrates agent-driven workflows directly into GitHub, supporting macOS, Windows, and Linux, with session isolation, built-in validation (diffs, in-app browser, terminal checks), and PR merging capabilities.

- **Design & Customization**: Includes Impeccable (open-source design skill) with 23 commands (e.g., `/critique`, `/typeset`) for design system enforcement; supports custom MCP servers, plugins, and skills for extended functionality.

- **Pricing Tiers**: Free tier (2K completions/month), Pro ($10/user/month with unlimited completions), Pro+ ($39/user/month with premium models), and Max ($100/user/month for high-volume workflows with priority access).
