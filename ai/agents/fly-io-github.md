# fly.io · GitHub

## Summary

- **Fly.io** is a cloud computing platform operated by **superfly**, offering managed services for deploying and scaling applications, with verified domain control (`fly.io`) and GitHub organization (`superfly`).

- Core open-source tools include:
  - **`flyctl`** (Go): CLI for managing Fly.io services.
  - **`litefs`** (Go): FUSE-based distributed SQLite replication system for clustered environments.

- Additional projects: **`corrosion`** (Rust, gossip-based service discovery), **`cr-sqlite`** (Rust, convergent replicated SQLite), and **Sprites** (Python/TypeScript SDKs for remote development environments).
