# ChatVertexAI integration - Docs by LangChain

## Summary

- **Deprecation Notice**: `ChatVertexAI` is deprecated and will be replaced by `ChatGoogleGenerativeAI`; migration guide is available in [langchain-google discussion #1422](https://github.com/langchain-ai/langchain-google/discussions/1422).

- **Model Support**: Vertex AI integration supports foundational models (e.g., `gemini-2.5-pro`, `gemini-2.5-flash`) with features including tool calling, structured output, multimodal inputs (image/audio/video), token-level streaming, async, and token usage metrics.

- **Setup & Tools**: Requires `langchain-google-vertexai` package; authentication via `GOOGLE_APPLICATION_CREDENTIALS` or gcloud. Built-in tools include Google search (v2.0.11+) and code execution (v2.0.25+).
