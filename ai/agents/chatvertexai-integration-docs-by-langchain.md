# ChatVertexAI integration - Docs by LangChain

## Summary

- **Deprecation Notice**: The `ChatVertexAI` integration is deprecated and will be replaced by `ChatGoogleGenerativeAI`; migration guide is available [here](https://github.com/langchain-ai/langchain-google/discussions/1422).
- **Model Support**: Vertex AI integrates with Google Cloud’s foundational models (e.g., `gemini-2.5-pro`, `gemini-2.5-flash`) via the `langchain-google-vertexai` package, supporting tool calling, structured output, multimodal inputs, and token-level streaming.
- **Authentication & Setup**: Requires Google Cloud credentials (via `GOOGLE_APPLICATION_CREDENTIALS` or gcloud) and installation of `langchain-google-vertexai`; built-in tools include Google Search and code execution.
