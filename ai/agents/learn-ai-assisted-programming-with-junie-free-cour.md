# Learn AI-Assisted Programming With Junie: Free Courses From JetBrains Academy and Nebius - The JetBrains Blog

## Summary

- **JetBrains Academy & Nebius collaboration**: Free AI-assisted programming courses featuring **Junie**, a smart coding agent integrated into JetBrains IDEs, and Nebius' AI cloud expertise for hands-on AI workflow training.

- **Two structured courses**:
  - *Coding With Junie*: Practical AI agent usage for project development, debugging, and testing in JetBrains IDEs.
  - *AI Agents as Your Team*: Deep dive into AI agent architecture, risk mitigation (e.g., hallucinations), and productivity optimization.

- **10-course AI-Assisted Programming series**: Covers AI-enhanced development stages (coding, DevOps, automation) with 25 hands-on tasks, 1 capstone project (~20 hours), targeting developers, junior engineers, and team leads.
