# Copilot CLI sessions in Visual Studio Code

## Summary

- **Copilot CLI Sessions**: Background agent sessions in VS Code run autonomously via Copilot CLI, managed through the Chat view; support multi-repository workspaces, custom agents, and deep research via `/research` command.
- **Isolation Modes**: Copilot CLI supports **Worktree** (Git worktree-based, auto-approved changes) and **Folder** (direct workspace changes, configurable permissions) isolation for task execution.
- **Permissions & Approvals**: Worktree isolation enforces **Bypass Approvals**, while Folder isolation allows **Default Approvals**, **Bypass Approvals**, or **Autopilot** modes for tool execution.
