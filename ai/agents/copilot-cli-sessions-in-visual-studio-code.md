# Copilot CLI sessions in Visual Studio Code

## Summary

- **Copilot CLI Sessions**: VS Code supports autonomous background agent sessions via GitHub Copilot CLI, managed through the Chat view; sessions run locally, persist outside VS Code, and support parallel execution for independent tasks.

- **Isolation Modes**: Copilot CLI offers **Worktree** (Git worktree-based isolation for safe, separate changes) and **Folder** (direct workspace modifications) isolation, with permission levels auto-adjusted (Bypass Approvals for Worktree, configurable for Folder).

- **Permissions & Features**: Supports slash commands (`/research`, `/compact`, etc.), GitHub auth integration, and experimental **Assisted permissions**; Worktree mode enforces auto-approvals, while Folder mode allows Default/Bypass/Autopilot levels.
