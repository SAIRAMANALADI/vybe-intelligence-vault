# Google Safe Browsing | Google for Developers

## Summary

- **Purpose**: Safe Browsing is a Google service that enables client applications to verify URLs against Google's continuously updated lists of unsafe web resources, including phishing, deceptive sites, malware, and unwanted software.
- **Functionality**: Provides APIs to check pages against threat-specific lists, warn users before clicking malicious links, and block users from posting links to known infected pages.
- **Usage Restrictions**: Safe Browsing API is non-commercial; commercial use requires the Web Risk API (Google Cloud). Multiple API versions and references (v4, v5, REST, RPC, OHTTP) are available for integration.
