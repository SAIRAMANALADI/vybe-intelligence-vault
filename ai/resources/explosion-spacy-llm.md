# explosion/spacy-llm

## Summary

- **Integration Framework**: Provides a structured pipeline for integrating large language models (LLMs) like GPT-3/4, Llama, Cohere, and others into spaCy NLP workflows via modular components (e.g., `spacy-llm`).
- **Prompt Engineering & Customization**: Enables dynamic prompt templating, few-shot learning, and model-specific configurations (e.g., OpenAI, Anthropic, Falcon) for tasks like NER, text classification, and entity linking.
- **Extensible Architecture**: Supports custom model backends, serialization of prompts/responses, and compatibility with spaCy’s `Language` class for seamless integration into existing NLP pipelines.
