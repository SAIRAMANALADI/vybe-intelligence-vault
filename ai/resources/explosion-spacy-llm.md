# explosion/spacy-llm

## Summary

- **LLM Integration Framework**: Provides a structured pipeline for integrating large language models (LLMs) like GPT-3/4, Llama, Cohere, and others into spaCy's NLP workflows for tasks such as named-entity recognition (NER) and text classification.

- **Prompt Engineering & Customization**: Supports dynamic prompt templating, few-shot learning, and model-specific configurations (e.g., OpenAI, Anthropic, Hugging Face) to optimize LLM performance within spaCy pipelines.

- **Modular & Extensible**: Designed for scalability, enabling users to chain LLMs with spaCy components, customize inference logic, and deploy hybrid NLP systems combining traditional rule-based/statistical methods with LLMs.
