# Home – DVC

## Summary

- **lakeFS**: Scalable data version control (DVC) infrastructure for enterprise AI/data engineering teams, supporting petabyte-scale multimodal object stores and data lakes with Git-like operations.

- **DVC (Data Version Control)**: Lightweight Git extension for individual data scientists, enabling versioned data science workflows with minimal overhead and seamless integration into local development.

- **Unified Platform**: Merger of lakeFS and DVC under a single ecosystem, combining enterprise-grade scalability with developer-friendly Git extensions for data/AI workflows.
