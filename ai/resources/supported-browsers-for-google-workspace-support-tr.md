# Supported browsers for Google Workspace | Support & troubleshooting | Google Workspace Help

## Summary

- **Supported Browsers**: Google Workspace officially supports the latest version of Chrome and the current/previous versions of Firefox, Safari, and Microsoft Edge, with Chrome offering full feature compatibility and support.
- **Browser Requirements**: JavaScript and cookies must be enabled in the browser; unsupported browsers may restrict features like calendar updates, offline access, and proper display of Docs editors.
- **Mobile & Virtual Environments**: Native Google Workspace mobile apps are recommended for mobile devices; virtualized browsers (e.g., Citrix, VMware) may lack full functionality.
