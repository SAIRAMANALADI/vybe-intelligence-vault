# Blended TROPOMI+GOSAT Satellite Data Product for Atmospheric Methane - Registry of Open Data on AWS

## Summary

- **Dataset**: Blended TROPOMI+GOSAT satellite retrievals of atmospheric methane (30 Apr 2018–present), updated monthly, hosted on AWS S3 (`arn:aws:s3:::blended-tropomi-gosat-methane`, `us-west-2`).
- **Access**: No restrictions; cite Balasus et al. (2023) and contact `nicholasbalasus@g.harvard.edu` for publication use.
- **Resources**: NetCDF files; AWS CLI access via `aws s3 ls --no-sign-request s3://blended-tropomi-gosat-methane/`; tutorials and publications available (e.g., DOI: [10.5194/amt-16-3787-2023](https://doi.org/10.5194/amt-16-3787-2023)).
