# OSTIF Has Completed A Security Audit of wasmCloud! – OSTIF.org

## Summary

- **Audit Scope**: Trail of Bits conducted a 6-engineer-week security audit of wasmCloud, focusing on sandboxing capabilities, user privilege limitations, and potential exploitation vectors (e.g., crashes, hacks) via manual code review, fuzzing, and RPC signing analysis.

- **Findings & Resolution**: Identified 2 low-severity (data validation/error reporting), 2 informational, and 1 undetermined finding; all resolved post-audit. No high/critical issues detected, with code maturity assessed via traffic-light protocol.

- **Technical Context**: Audit validated wasmCloud’s security posture amid Elixir-to-Rust migration, emphasizing secure data handling and error reporting. Collaboration involved Trail of Bits, Cosmonic, and CNCF sponsorship.
