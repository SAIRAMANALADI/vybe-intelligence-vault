# Aseprite - Docs

## Summary

- **Aseprite** is a specialized 2D pixel-art animation tool supporting retro-style graphics (8-bit/16-bit) with features like onion skinning, layers, and frame manipulation for game development.
- **Core workflows** include sprite creation/editing, animation (frame/timeline management), tilemap support, and export options (sprite sheets, CLI-based batch processing).
- **Customization & integration** are enabled via scripting (Lua API), extensions, CLI tools, and configurable preferences/keyboard shortcuts for optimized workflows.
