# transform.HTMLToMarkdown

## Summary

- **Functionality**: Converts HTML input to Markdown using the `html-to-markdown` Go package, introduced in Hugo v0.151.0.
- **Plugins**: Uses `Base`, `CommonMark`, and `Table` plugins for core conversion, CommonMark compliance, and GitHub Flavored Markdown table support, respectively.
- **Usage**: Applied via `{{ .Content | transform.HTMLToMarkdown | safeHTML }}`; marked experimental with potential API changes.
