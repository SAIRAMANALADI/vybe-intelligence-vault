# JSON Lines

## Summary

- **Encoding & BOM**: Files must use UTF-8 encoding; byte order mark (U+FEFF) is explicitly forbidden per RFC 8259.
- **Line Structure**: Each line must contain a valid JSON value (objects, arrays, primitives), with `'\n'` as the line terminator (supports `'\r\n'` due to JSON whitespace rules).
- **File Conventions**: Recommended extensions `.jsonl`, `.jsonl.gz`, or `.jsonl.bz2`; MIME type `application/jsonl` is proposed but not standardized.
