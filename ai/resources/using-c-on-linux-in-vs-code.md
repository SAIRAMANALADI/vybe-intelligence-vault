# Using C++ on Linux in VS Code

## Summary

- **C++ Development Setup**: VS Code supports C++ development on Linux via GCC (G++) and GDB, requiring installation of `build-essential` and `gdb` packages for compilation and debugging.
- **Workspace Configuration**: VS Code uses `.vscode` folder for project-specific settings, including `tasks.json` (build tasks), `launch.json` (debug configurations), and `c_cpp_properties.json` (IntelliSense and compiler paths).
- **Source Code Execution**: C++ programs are compiled, debugged, and executed directly within VS Code, with IntelliSense providing real-time code analysis and debugging tools enabling step-through execution and watch expressions.
