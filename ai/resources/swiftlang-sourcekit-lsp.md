# sourcekit-lsp/Documentation/Editor Integration.md at main · swiftlang/sourcekit-lsp · GitHub

## Summary

- **BBEdit**: LSP support integrated in v14.0+; auto-detects `sourcekit-lsp` via `$PATH` or `xcrun`, with manual configuration available if needed.
- **Sublime Text**: Requires `LSP`, `LSP-SourceKit`, and `Swift-Next` packages; enable via command palette (`LSP: Enable Language Server Globally/Project`).
- **SourceKit-LSP Client Dev Notes**: Must buffer stdout stream to parse LSP packets; avoid sandboxed environments; provide system environment variables; open document before sending requests.
