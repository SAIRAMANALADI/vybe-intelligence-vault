# Kubectl Cheatsheet - Collabnix

## Summary

- **Installation**: `kubectl` is installed via package managers (`apt` for Debian/Ubuntu, `yum` for CentOS/RHEL) using Kubernetes' official repositories, with commands including `sudo apt-get install -y kubectl` or `yum install -y kubectl`.

- **Core Syntax & Commands**: Follows `kubectl [command] [TYPE] [NAME] [flags]` structure; essential commands include `kubectl get pods`, `kubectl describe pod <name>`, `kubectl logs <pod>`, and `kubectl delete pod <name>`.

- **Advanced Operations**: Supports deployment scaling (`kubectl scale deployment <name> --replicas=N`), autoscaling (`kubectl autoscale deployment <name> --min=X --max=Y --cpu-percent=Z`), and RBAC checks (`kubectl auth can-i create pods`).
