# Privacy - Apple

## Summary

- **Safari's Privacy Features**: Blocks third-party cookies, employs on-device ML for tracking prevention, removes URL trackers in Private Browsing, hides IP from trackers, and restricts extension access to browsing data by default.
- **Apple Intelligence Privacy Model**: Uses on-device processing via Apple Silicon for local data handling and Private Cloud Compute for complex tasks, ensuring user data is never stored or accessible to Apple, verified by independent experts.
- **App-Level Privacy Controls**: Apps like Health, Wallet, Maps, Photos, Messages, Siri, and News use on-device processing, random identifiers, and strict encryption to minimize data exposure, while features like Private Browsing, Passkeys, and App Tracking Transparency further enhance user control.
