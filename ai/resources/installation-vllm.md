# Installation - vLLM

## Summary

- **Multi-Architecture Support**: vLLM supports GPU (NVIDIA CUDA, AMD ROCm, Intel XPU, Apple Silicon via vLLM-Metal), CPU (Intel/AMD x86, ARM AArch64, Apple Silicon, IBM Z S390X), and third-party hardware plugins via the Hardware-Pluggable RFC system.

- **Hardware Plugins**: Third-party hardware compatibility is managed externally via plugins adhering to the Hardware-Pluggable RFC, with a full list available on the [vLLM website](https://vllm.ai/#compatibility).

- **Community Integration**: New hardware integration requires contacting vLLM via [Slack](https://slack.vllm.ai/) or [Email](https://docs.vllm.ai/cdn-cgi/l/email-protection#284b474444494a475a495c414746685e444445064941).
