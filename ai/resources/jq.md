# jq

## Summary

- **Portable C-based JSON processor** with zero runtime dependencies, enabling single-binary deployment across compatible systems via `scp` or similar methods.

- **Version 1.8.2** released on 20 June 2026, featuring updates and fixes documented in the [release notes](https://github.com/jqlang/jq/releases/tag/jq-1.8.2).

- **Functionality** analogous to `sed`/`awk` for JSON, enabling slicing, filtering, mapping, and transformation of structured data with concise, expressive queries.
