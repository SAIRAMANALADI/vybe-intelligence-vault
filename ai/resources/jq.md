# jq

## Summary

- **Lightweight JSON processor**: `jq` is a portable C-based tool with zero runtime dependencies, enabling single-binary deployment across compatible systems (e.g., via `scp`).

- **Functionality**: Functions as a JSON-aware `sed`, supporting data slicing, filtering, mapping, and transformation with concise, expressive syntax.

- **Releases**: Latest stable version is `1.8.2` (June 2026), with prior versions addressing security (e.g., CVE-2023-50246) and introducing features like streaming parsing (v1.5).
