# jq

## Summary

- **Portable JSON processor**: `jq` is a lightweight, dependency-free command-line tool written in portable C, enabling direct binary transfer across compatible systems for JSON manipulation.

- **Functional JSON transformations**: Provides a concise DSL for filtering, mapping, and restructuring JSON data with syntax akin to `sed`/`awk`, supporting complex operations like array/object destructuring and streaming parsing.

- **Cross-platform availability**: Precompiled binaries for major platforms (Linux/AMD64/ARM64, macOS/Intel/Apple Silicon, Windows/AMD64) and versions, with recent releases (1.8.2 as of June 2026) including security fixes and feature updates.
