# jq

## Summary

- **jq** is a lightweight, portable C-based command-line JSON processor with zero runtime dependencies, enabling single-binary deployment across compatible systems.
- Supports structured JSON data manipulation (filtering, mapping, transformation) via a concise syntax, analogous to `sed`/`awk` for text.
- Latest stable release **jq 1.8.2** (June 2026) includes platform-specific binaries (Linux/AMD64, ARM64, macOS, Windows) and is available via GitHub releases.
