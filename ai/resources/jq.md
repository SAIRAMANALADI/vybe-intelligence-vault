# jq

## Summary

- **Portable C-based JSON processor** with zero runtime dependencies, enabling single-binary deployment across compatible systems (e.g., via `scp`).
- **jq 1.8.2** (released 20 June 2026) introduces latest features/fixes; binaries available for Linux (AMD64/ARM64), macOS (Apple Silicon/Intel), and Windows (AMD64).
- **Functionality akin to `sed` for JSON**, supporting slicing, filtering, mapping, and transformation with concise syntax; supports streaming parsing, modules, and error handling (e.g., `try/catch`).
