## Summary

- **Installation**: VLT client is installed globally via `npm i -g vlt` or `pnpm i -g vlt`, supporting Node.js v20 or v22.
- **CLI Commands**: Provides extended package management capabilities including authentication, configuration, dependency selectors, and security/malware detection.
- **Monorepo Support**: Manages workspaces within a VLT monorepo, enabling scalable and efficient dependency handling.
