# Anaconda Documentation - Anaconda

## Summary

- **Anaconda Distribution**: Comprehensive Python/R data science platform with pre-installed libraries (NumPy, pandas, scikit-learn, TensorFlow, PyTorch) and package management via `conda`, supporting Windows, macOS, and Linux.

- **Miniconda**: Lightweight version of Anaconda with only `conda`, Python, and essential dependencies, enabling custom environment creation without bundled packages.

- **Anaconda Navigator**: GUI tool for managing environments, packages, and projects, integrating with JupyterLab, VS Code, and IDEs for streamlined data science workflows.
