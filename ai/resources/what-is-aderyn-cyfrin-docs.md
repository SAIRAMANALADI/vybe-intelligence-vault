# What is Aderyn? | Cyfrin Docs

## Summary

- **Static Analyzer**: Rust-based Solidity smart contract static analyzer for vulnerability detection in Solidity codebases, featuring built-in and custom detectors.
- **CLI & Integration**: Offers a high-performance CLI with customizable analysis scopes, output formats (Markdown/JSON), and CI/CD pipeline compatibility.
- **Use Cases**: Supports pre-audit analysis, automated CI testing, custom security checks, and competitive audit filtering via known-issue detection.
