# Bazel

## Summary

- **Build System**: Bazel is an open-source, multi-language, multi-platform build system optimized for speed, correctness, and scalability, supporting Java, C++, Go, Android, iOS, and more, with advanced caching, parallel execution, and dependency analysis.

- **Extensibility & Scalability**: Features a domain-specific extension language for adding new languages/platforms, and scales from startups to enterprises, handling monorepos and distributed CI systems efficiently.

- **Industry Adoption**: Used by Google, Stripe, Dropbox, and others for mission-critical infrastructure, with ongoing development tracked via public roadmaps, release notes, and community updates.
