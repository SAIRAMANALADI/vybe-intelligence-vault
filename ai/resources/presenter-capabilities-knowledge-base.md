# Presenter Capabilities | Knowledge Base

## Summary

- **Studio Control & Layout Management**: BigMarker's Studio allows presenters to control production/design, manage multiple cameras/mics, rearrange presenter views, and use scenes for branded event layouts, including spotlight/pin features and HD screen sharing.

- **Presenter Permissions & Engagement Tools**: Customizable presenter permissions regulate camera/mic/content sharing; features include pre-loaded content, polls/Q&A, private chats, co-browsing, and sticky notes for moderation and attendee interaction.

- **Content Delivery & Technical Features**: Supports direct Keynote/PowerPoint sharing (with animations/notes), YouTube/HD video embedding, secondary camera sharing, and integrations (e.g., Slack) while offering troubleshooting for performance optimization (e.g., camera count adjustments).
