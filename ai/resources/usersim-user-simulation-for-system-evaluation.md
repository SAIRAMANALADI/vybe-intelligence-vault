# UserSim - User Simulation for System Evaluation

## Summary

- **Monograph**: A 261-page *Foundations and Trends in Information Retrieval* (FnTIR) publication by Balog & Zhai (2024) reviewing user simulation frameworks, models, and algorithms for evaluating search engines, recommender systems, and conversational assistants ([arXiv](https://arxiv.org/abs/2306.08550), [DOI](https://doi.org/10.1561/1500000098)).

- **Toolkits & Tutorials**: Open-source frameworks and step-by-step guides for building/evaluating user simulation models in IR, recommender systems, and dialogue systems, with code examples and integration guides ([Toolkits](https://usersim.ai/toolkits), [Tutorials](https://usersim.ai/tutorials)).

- **Community & Events**: Interdisciplinary hub (IR, dialogue systems, ML, economics) hosting workshops, conferences, and curated bibliographies on user simulation research ([Community](https://groups.google.com/g/usersim), [Bibliography](https://usersim.ai/bibliography), [Events](https://usersim.ai/events)).
