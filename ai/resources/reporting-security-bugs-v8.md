# Reporting security bugs · V8

## Summary

- V8 security bugs are reported via Chromium’s [Security Bug template](https://bugs.chromium.org/p/chromium/issues/entry?template=Security%20Bug) under the component **Blink>JavaScript**.
- Follow [Chromium’s security reporting guidelines](https://www.chromium.org/Home/chromium-security/reporting-security-bugs) before filing a bug.
- V8 adheres to [Chromium’s Security Process](https://www.chromium.org/Home/chromium-security) for vulnerability handling.
