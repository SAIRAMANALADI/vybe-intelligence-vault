# firebase_remote_config - Dart API docs

## Summary

- Flutter plugin providing Firebase Remote Config API integration for dynamic app configuration without app updates.
- Supports real-time parameter updates, conditional targeting, and A/B testing via Firebase console.
- Enables fetching and activating remote parameters with type-safe accessors (`getString`, `getInt`, `getDouble`, `getBool`).
