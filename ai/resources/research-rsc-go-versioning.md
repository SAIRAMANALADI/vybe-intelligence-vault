# research!rsc: Go & Versioning

## Summary

- **vgo Proposal**: Introduced semantic import versioning and minimal version selection (MVS) to address Go dependency management, later formalized in the Go Modules proposal (accepted May 2018).
- **Versioned Imports**: Modules use `module/path vN` syntax (e.g., `example.com/mod v2.0.0`) to enforce explicit versioning and avoid breaking changes.
- **Reproducible Builds**: MVS ensures deterministic dependency resolution by selecting the minimal compatible versions, enabling verifiable and reproducible builds.
