# The NPDB - Home Page

## Summary

- **NPDB Services**: The National Practitioner Data Bank (NPDB) offers self-querying, report access, and response mechanisms for healthcare professionals via personal accounts, with updates enabling single sign-in for Self-Query and Report Response services.

- **Data Updates**: The NPDB Public Use Data File (PUF) and Data Analysis Tool (DAT) were updated to include records from September 1, 1990, to March 31, 2026, with new subset downloads by Record Type and Profession Group.

- **Organizational Access**: Healthcare organizations can register with the NPDB, update administrator details, submit queries/reports, and access the NPDB Guidebook for reporting and eligibility policies.
