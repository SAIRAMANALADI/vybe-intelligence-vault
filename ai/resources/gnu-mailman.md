# GNU Mailman

## Summary

- **GNU Mailman** is a free, Python-based mailing list manager with integrated web administration, archiving, bounce processing, content filtering, digest delivery, and spam filtering.
- **Mailman 3.3.10 (Tom Sawyer)** is the current stable release (as of Oct 1, 2024), with Mailman 2.1.39 as the legacy stable (Dec 13, 2021).
- **Core components** include Mailman Suite, Mailman Core, Postorius, Mailman Client, Hyperkitty, and Mailman 2.1, hosted on GitLab and ReadTheDocs.
