# GEOFON Program at GFZ

## Summary

- **GEOFON** is a **CoreTrustSeal-certified** seismic data repository operated by the **GFZ Helmholtz Centre for Geosciences**, providing **real-time earthquake monitoring** and **seismic waveform data** via the **GE** network code.

- The platform offers **automated rapid earthquake information** (e.g., magnitude, location, time) and **interactive access** through forums, Mastodon, Bluesky, and Telegram for alerts and discussions.

- It supports **SeisComP software** (developed with gempa GmbH) for seismic data processing and provides **open waveform archives** and **contribution pathways** for global seismic network integration.
