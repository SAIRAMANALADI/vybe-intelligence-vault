# Running the Notebook — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- Launch Jupyter Notebook server via CLI: `jupyter notebook` (default: `http://localhost:8888`).
- Customize server behavior with flags: `--port 9999`, `--no-browser`, or open specific notebooks: `jupyter notebook notebook.ipynb`.
- Execute notebooks programmatically: `jupyter execute notebook.ipynb` (suppress errors with `--allow-errors`).
