# Getting started with Visual Studio

## Summary

- **Visual Studio IDE Core Features**: Integrates graphical designers, compilers, IntelliSense, source control (Git/GitHub), and extensibility via workloads/components for C++, .NET, JavaScript/TypeScript, Python, and Node.js development.
- **Multi-Language & Framework Support**: Provides native tooling for C++ (console/desktop apps, drivers), .NET (C#/F#/VB for desktop/web/mobile/IoT), Python (data science/desktop/web), and Node.js (Express/React) with step-by-step tutorials for project creation and debugging.
- **AI & DevOps Integration**: GitHub Copilot offers AI-driven code suggestions/chat; built-in Git/GitHub tools simplify version control; supports Azure DevOps for CI/CD pipelines and enterprise-grade features in Professional/Enterprise editions.
