# Build a payments page | Stripe Documentation

## Summary

- **Checkout Sessions API** supports three UI options: **Full Page** (hosted/embedded), **Embedded Form**, and **Elements**, each with varying levels of customization and built-in features (e.g., tax, billing, dynamic payment methods).

- **Full Page** mode (recommended) includes a complete order summary with subtotals, cross-sells, discounts, and promo codes, while **Elements** offers full CSS customization but lacks an order summary.

- **Managed Payments** automates tax/VAT compliance in 80+ countries, and **Adaptive Pricing** allows local currency pricing; subscriptions, future payments, and post-payment customization are supported via the API.
