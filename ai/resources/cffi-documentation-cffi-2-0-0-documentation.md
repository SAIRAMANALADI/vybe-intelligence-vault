# CFFI documentation — CFFI 2.0.0 documentation

## Summary

- **CFFI Overview**: Python library enabling direct interaction with C code via C-like declarations, supporting both ABI (dynamic) and API (static) modes for binding external libraries or compiling inline C definitions.

- **Core Functionality**: Provides `ffi` and `lib` objects for calling C functions, handling pointers/structures/arrays, variadic functions, and callbacks, with thread-safety and Python 3 compatibility.

- **Module Preparation & Distribution**: Uses `ffibuilder` to declare types/functions (`cdef`), load libraries (`dlopen`), compile out-of-line modules (`compile`), and embed C code (`verify`), with support for cross-module inclusion and debugging.
