# Lighthouse | Chrome for Developers

## Summary

- **Lighthouse** is a web auditing tool supporting performance, accessibility, PWA, SEO, and best practices audits for any web page (public or authenticated).
- **Execution modes** include PageSpeed Insights, Chrome DevTools, CLI, or Node.js module, generating actionable reports with references for fixes.
- **Audit categories** cover performance optimization, accessibility compliance, code best practices, and SEO ranking factors.
