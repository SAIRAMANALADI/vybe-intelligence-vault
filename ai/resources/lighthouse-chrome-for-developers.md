# Lighthouse | Chrome for Developers

## Summary

- **Lighthouse** is a web auditing tool supporting performance, accessibility, PWA, and SEO audits for any web page (public or authenticated).
- **Execution modes** include PageSpeed Insights, Chrome DevTools, CLI, and Node.js module, generating actionable reports with fix references for failing audits.
- **Audit categories** cover Performance (load speed), Accessibility (inclusive navigation), Best Practices (code health), and SEO (search ranking optimization).
