# <mark> HTML mark text element - HTML | MDN

## Summary

- **Semantic Purpose**: The `<mark>` element highlights text for relevance or reference, not importance (unlike `<strong>`), typically used for search matches or quoted text of special interest.
- **Browser Support**: Universally supported since July 2015 across all major browsers, with no tag omission requirements (both opening/closing tags mandatory).
- **Accessibility Limitation**: Screen readers do not announce `<mark>` by default; ARIA roles or CSS pseudo-elements (`::before`/`::after`) with `content` property are required for explicit announcement.
