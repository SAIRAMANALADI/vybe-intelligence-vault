# declarative-shadow-dom/README.md at master · mfreed7/declarative-shadow-dom · GitHub

## Summary

- **Declarative Shadow DOM (DSD)** enables defining Shadow DOM directly in HTML markup via `<template shadowroot>` or `<template shadowrootmode>`, eliminating the need for JavaScript `attachShadow()` calls.

- **Standardized in WHATWG HTML spec** with syntax `<template shadowroot="open|closed">` for shadow root mode declaration, supporting serialization and hydration at parse time.

- **Behavioral differences** include closed shadow roots (encapsulated DOM) and integration with existing `<template>` elements, though serialization requires explicit mode specification (`shadowrootmode`).
