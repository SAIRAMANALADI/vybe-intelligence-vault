# SciPy India · GitHub

## Summary

- SciPy India is a multidisciplinary community and annual conference focused on the scientific Python ecosystem, hosting repositories for community calls, proposal reviews, conferences, workshops, and archives.
- The community provides platforms for proposing talks/sessions, engaging via Zulip chat, and accessing resources through their website and FOSS United chapter.
- SciPy India maintains a Code of Conduct with reporting mechanisms and is active on social media platforms including LinkedIn, Mastodon, Bluesky, and Instagram.
