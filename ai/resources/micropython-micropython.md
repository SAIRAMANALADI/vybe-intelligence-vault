# micropython/micropython

## Summary

- **Implementation**: MicroPython is a highly optimized Python 3.x interpreter written in C, designed for microcontrollers and constrained systems with minimal memory footprint (~256kB flash, ~16kB RAM).
- **Hardware Support**: Supports a wide range of architectures (ARM Cortex-M, ESP32, RISC-V, etc.) via portable HAL and platform-specific optimizations.
- **Features**: Includes a subset of Python standard library, efficient garbage collection, and a compact bytecode interpreter for real-time execution.
