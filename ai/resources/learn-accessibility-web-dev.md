# Learn Accessibility | web.dev

## Summary

- **Semantic HTML & ARIA**: Use semantic HTML elements (e.g., `<nav>`, `<button>`) and ARIA roles (`role="navigation"`) appropriately to enhance accessibility; avoid ARIA when native HTML suffices.
- **WCAG Compliance**: Measure accessibility via WCAG 2.1/2.2 guidelines, focusing on contrast ratios (≥4.5:1 for text), keyboard operability, and screen reader compatibility.
- **Testing Frameworks**: Implement automated tools (e.g., axe-core, Lighthouse) alongside manual testing with assistive tech (e.g., NVDA, JAWS) and user testing with disabled participants.
