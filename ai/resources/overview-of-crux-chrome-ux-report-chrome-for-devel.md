# Overview of CrUX | Chrome UX Report | Chrome for Developers

## Summary

- **Dataset Source**: CrUX aggregates real-world Chrome user experience data from globally distributed browsers, filtered by [user eligibility criteria](https://developer.chrome.com/docs/crux/methodology#user-eligibility).

- **Core Web Vitals Integration**: Represents all user-centric [Core Web Vitals metrics](https://web.dev/articles/vitals) via structured [dimensions](https://developer.chrome.com/docs/crux/methodology/dimensions) and [metrics](https://developer.chrome.com/docs/crux/methodology/metrics).

- **Eligibility & Public Access**: Data is publicly available via Google tools/third-party integrations but requires [origin/page eligibility](https://developer.chrome.com/docs/crux/methodology#origin-eligibility) (publicly discoverable + statistically significant traffic). Used in [Google Search ranking](https://developers.google.com/search/docs/advanced/experience/page-experience).
