# Version

## Summary

- Returns a `versions.Version` object representing the Hugo site's version, derived from project configuration.
- Provides methods `IsDefault` (bool) to check if it's the default version and `Name` (string) to retrieve the version name (lowercased config key).
- Introduced in Hugo v0.153.0.
