# Version

## Summary

- **Returns Version Object**: `SITE.Version` retrieves a `versions.Version` object representing the Hugo version configured in the project.
- **Key Methods**:
  - `IsDefault` (`bool`): Checks if the version is the default.
  - `Name` (`string`): Returns the lowercased version key from the project configuration.
- **Introduced in v0.153.0**: Feature added in Hugo release `v0.153.0`.
