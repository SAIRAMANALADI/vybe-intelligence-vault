# Hypertext Transfer Protocol (HTTP) Authentication Scheme Registry

## Summary

- **HTTP Authentication Schemes Registry**: Maintained by IANA under IETF Review, includes schemes like Basic (RFC7617), Bearer (RFC6750), Digest (RFC7616), and Mutual (RFC8120), with registration details and references.
- **Mutual Authentication Algorithms**: Defined in RFC8120, includes ISO-11770-4 KAM3 algorithms (e.g., `iso-kam3-dl-2048-sha256`) with 2048/4096-bit DL and 256/521-bit EC variants, managed via Expert Review.
- **Special Cases**: `Negotiate` scheme (RFC4559) violates HTTP semantics/syntax, while `HOBA` (RFC7486) supports both server and proxy authentication contexts.
