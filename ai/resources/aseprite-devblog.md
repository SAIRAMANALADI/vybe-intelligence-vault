# Aseprite Devblog

## Summary

- **License Change (2016)**: Aseprite transitioned from GPLv2 to a custom EULA starting v1.1.8, allowing personal modification but prohibiting redistribution.
- **Skia Integration Challenges (2018)**: Static Skia library usage with C++ exceptions caused macOS porting issues due to RTTI conflicts.
- **Forward Compatibility (2016)**: v1.1.6 introduced forward compatibility to load v1.2 `.aseprite` files with layer groups, converting them to older format with warnings.
