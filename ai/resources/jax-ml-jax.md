# jax-ml/jax

## Summary

- **Automatic Differentiation & High-Performance Computing**: JAX provides composable transformations for Python+NumPy programs, enabling automatic differentiation (via `grad`), vectorization (`vmap`), and Just-In-Time (JIT) compilation to GPU/TPU for accelerated numerical computations.

- **Functional Array Programming**: Implements a functional programming paradigm for numerical computing, where operations return new arrays rather than modifying in-place, ensuring referential transparency and facilitating optimizations like JIT compilation.

- **Hardware Acceleration & Ecosystem Integration**: Supports seamless execution on accelerators (GPUs/TPUs) via XLA, with additional transformations like parallelization (`pmap`) and automatic batching (`batch_transform`), while maintaining compatibility with NumPy’s API for broad usability.
