# <hex-color> CSS type - CSS | MDN

## Summary

- **Hexadecimal Color Syntax**: CSS supports hex color notation (`#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA`) for sRGB colors, where `R`, `G`, `B` (and optional `A`) are case-insensitive hexadecimal values (`0`–`ff`/`00`–`ff`), with single-digit values duplicated (e.g., `#f09` = `#ff0099`).

- **Alpha Channel Support**: The optional 4th or 8th hex pair (`A`/`AA`) defines transparency (`00`–`ff`), where `00` is fully transparent and `ff` is fully opaque (e.g., `#f09a` = `#ff0099aa`).

- **Cross-Browser Compatibility**: The feature is baseline-supported across modern browsers since July 2015, per CSS Color Module Level 4 specifications.
