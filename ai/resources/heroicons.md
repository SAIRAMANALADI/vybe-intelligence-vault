# Heroicons

## Summary

- **Icon Set**: Heroicons is a collection of free, MIT-licensed icons provided by the makers of Tailwind CSS, available in three sizes: `Outline` (24x24, 1.5px stroke), `Mini` (20x20, 1.5px stroke), and `Micro` (16x16, 1.5px stroke).

- **Design & Usage**: Icons are designed for scalability and clarity, supporting both solid and outline styles, and are optimized for web use with consistent stroke widths and alignment.

- **Integration**: Icons are available for direct use in web projects, with support for customization via Tailwind CSS classes, and can be accessed via [heroicons.com](https://heroicons.com) or integrated directly into codebases.
