# Install Tuba on Linux | Snap Store

## Summary

- **Tuba** is a GNOME-based Fediverse client snap package (v0.10.3) supporting decentralized platforms (Mastodon, GoToSocial, Akkoma) under **GPL-3.0**, maintained by Evangelos "GeopJr" Paterakis.
- Distributed via **Snap Store** with CLI installation (`sudo snap install tuba`) and multi-arch support (x86_64, ARM) for Linux distributions (Ubuntu ≥16.04, Debian, Fedora, Arch, etc.).
- Source-available at [GitHub](https://github.com/GeopJr/Tuba), with community engagement via Matrix (`#tuba:gnome.org`) and issue tracking on GitHub.
