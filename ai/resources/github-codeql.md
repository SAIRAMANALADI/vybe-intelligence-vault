# github/codeql

## Summary

- **CodeQL Framework**: A semantic code analysis engine enabling security researchers to write custom queries (in QL) for vulnerability detection across multiple languages (e.g., C/C++, Java, Python, JavaScript).
- **GitHub Integration**: Powers GitHub Advanced Security’s code scanning, providing automated security analysis directly within GitHub repositories via pre-built and community-contributed queries.
- **Extensible Query Library**: Includes a curated set of security queries (e.g., for OWASP Top 10, CWE) and supports custom query development for tailored vulnerability assessment.
