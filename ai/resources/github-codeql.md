# github/codeql

## Summary

- **CodeQL Framework**: A semantic code analysis engine enabling security researchers to write custom queries for vulnerability detection across multiple programming languages using declarative logic (Datalog-based).

- **GitHub Integration**: Powers GitHub Advanced Security’s code scanning, providing automated security analysis directly within GitHub repositories via pre-built and custom queries.

- **Extensible Query Library**: Includes a comprehensive set of security queries (e.g., CWE, OWASP Top 10) and supports community contributions, enabling continuous improvement and adaptation to emerging threats.
