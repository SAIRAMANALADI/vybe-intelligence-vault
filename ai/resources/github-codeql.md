# github/codeql

## Summary

- **CodeQL Framework**: A semantic code analysis engine enabling security researchers to write custom queries (in QL) for vulnerability detection across multiple languages (e.g., C/C++, Java, Python, JavaScript).

- **GitHub Integration**: Powers GitHub Advanced Security’s code scanning, providing automated security analysis directly within GitHub repositories and CI/CD pipelines.

- **Open-Source Ecosystem**: Hosts a public library of security queries (e.g., GitHub Security Lab) and supports extensibility via custom QL libraries for proprietary or domain-specific analysis.
