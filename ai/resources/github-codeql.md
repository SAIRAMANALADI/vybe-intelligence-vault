# github/codeql

## Summary

- **CodeQL Framework**: A semantic code analysis engine enabling security researchers to write custom queries (in QL) for vulnerability detection across multiple languages (e.g., C/C++, Java, Python, JavaScript) by modeling code as a relational database.

- **GitHub Integration**: Powers GitHub Advanced Security’s code scanning, automating vulnerability detection in repositories via pre-built and custom QL queries, with support for Codespaces and CI/CD pipelines.

- **Open-Source Ecosystem**: Hosts a public library of 3,000+ QL queries (e.g., Semmle-QL) and enables community contributions, facilitating collaborative security research and continuous query updates.
