# github/codeql

## Summary

- **CodeQL Framework**: A semantic code analysis engine enabling security researchers to write custom queries (in CodeQL) for vulnerability detection across multiple languages (e.g., C/C++, Java, Python, JavaScript).
- **GitHub Integration**: Powers GitHub Advanced Security’s code scanning, automating security analysis in CI/CD pipelines and enabling GitHub Security Lab’s vulnerability research.
- **Extensible Queries & Libraries**: Open-source repository containing 3,000+ predefined security queries and reusable libraries for detecting OWASP Top 10, CWE, and custom security patterns.
