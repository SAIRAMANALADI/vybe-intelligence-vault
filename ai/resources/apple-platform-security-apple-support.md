# Apple Platform Security - Apple Support

## Summary

- **Hardware Security**: Apple integrates security features directly into its silicon (e.g., M-series chips), including the Secure Enclave, biometric authentication (Face ID, Touch ID, Optic ID), and hardware-level protections like microphone/camera disconnects and on-screen indicators for active sensors.

- **System Security**: Implements secure boot chains (memory-safe iBoot), signed system volumes, and protections against unauthorized firmware modifications (e.g., Startup Security Utility, System Integrity Protection) across iOS, macOS, and watchOS.

- **Encryption & Data Protection**: Uses AES-256 encryption by default (FileVault, Data Protection classes), quantum-resistant cryptography, and hardware-backed key management (Secure Enclave, Sealed Key Protection) to safeguard user data, including remote wipe capabilities.
