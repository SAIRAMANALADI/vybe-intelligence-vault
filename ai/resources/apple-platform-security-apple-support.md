# Apple Platform Security - Apple Support

## Summary

- **Hardware Security**: Apple integrates security features directly into its silicon (e.g., M-series chips), including the Secure Enclave, biometric authentication (Face ID, Touch ID, Optic ID), and hardware-level protections like microphone/camera disconnects and firmware safeguards.

- **System Security**: Implements secure boot (with memory-safe iBoot), signed system volumes, and Lockdown Mode; supports Intel-based and Apple silicon Macs with distinct boot processes, firmware password protection, and System Integrity Protection (SIP).

- **Encryption & Data Protection**: Uses AES-256 encryption, Data Protection classes, FileVault for volume encryption, and quantum-resistant cryptography; enforces passcode policies, keybags for key management, and runtime process protections for app security.
