# Apple Platform Security - Apple Support

## Summary

- **Hardware Root of Trust**: Apple devices integrate security directly into silicon (e.g., M-series chips, Secure Enclave) to enforce secure boot, cryptographic operations, and biometric authentication (Face ID, Touch ID, Optic ID) with hardware-level protections like microphone/camera disconnects.

- **Multi-Layered System Security**: Implements signed system volumes, memory-safe boot components (iBoot), Secure Boot chains, and runtime protections (e.g., System Integrity Protection, BlastDoor for Messages) to prevent unauthorized code execution and tampering across iOS, macOS, and watchOS.

- **End-to-End Data Protection**: Uses AES-256 encryption (with Data Protection classes), FileVault for full-disk encryption, and quantum-resistant cryptography, alongside key management via Secure Enclave and hardware-accelerated cryptographic operations to safeguard user data at rest and in transit.
