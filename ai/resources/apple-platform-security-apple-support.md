# Apple Platform Security - Apple Support

## Summary

- **Hardware Security**: Apple integrates security into silicon (e.g., M-series chips) with features like the Secure Enclave, biometric authentication (Face ID, Touch ID, Optic ID), and hardware-level protections (e.g., microphone/camera disconnect, Express Cards with power reserve).

- **System Security**: Implements secure boot (memory-safe iBoot), signed system volumes, and Lockdown Mode; supports Intel-based and Apple silicon Macs with distinct boot processes, firmware protections, and peripheral security (e.g., Rosetta 2, Direct Memory Access protections).

- **Encryption & Data Protection**: Uses AES-256 encryption (including quantum-secure cryptography), FileVault for volume encryption, and Data Protection classes with keybags; enforces passcode policies and app-level access controls to safeguard user data.
