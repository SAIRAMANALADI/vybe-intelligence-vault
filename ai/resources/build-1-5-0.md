# build - 1.5.0

## Summary

- **Purpose**: A minimal, standards-compliant Python packaging build frontend that invokes build backends (per `pyproject.toml`) to generate distribution packages (sdist/wheel) without dependency or environment management.

- **Key Features**:
  - Supports `--config-json` for nested backend configuration.
  - Ensures consistent outputs across compliant frontends (unlike `flit build`).
  - Lightweight dependencies for restricted environments.

- **Differentiators**:
  - Standalone tool (vs. `pip`/`hatch`/`flit` integration).
  - Equivalent to `python -m build --installer=uv` but with broader installer compatibility.
  - Not a multi-platform wheel builder (unlike `cibuildwheel`).
