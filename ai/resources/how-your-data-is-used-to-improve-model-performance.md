# How your data is used to improve model performance | OpenAI Help Center

## Summary

- **Training Opt-In/Opt-Out**: Users can enable/disable model training via privacy portal; opt-out excludes new conversations from training, while feedback submissions (thumbs up/down) may still be used for training even if opted out.

- **Business vs. Individual Services**: Business-tier services (ChatGPT Business/Enterprise, API) default to no training; opt-in is required for data sharing, whereas individual services (ChatGPT, Codex) allow training by default unless explicitly disabled.

- **Data Processing & Retention**: Training data undergoes anonymization to remove personal information; support conversations and feedback (when opted in) are retained to improve model efficiency and user-specific performance.
