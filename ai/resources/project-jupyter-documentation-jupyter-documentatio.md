# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: A modular, extensible framework centered around interactive computing via computational notebooks, supporting code execution, rich visualizations, and narrative documentation in a single document format.

- **Core components**: Includes JupyterLab (advanced IDE-like interface), Jupyter Notebook (simplified interface), kernels (e.g., IPython, IRkernel), and tools for notebook lifecycle management (e.g., `nbconvert`, `nbformat`, `nbclient`).

- **Sub-projects and standards**: Encompasses JupyterHub (multi-user deployment), widgets (`ipywidgets`), AI integration (`jupyter-ai`), and messaging protocols (`jupyter-client`), with specifications like `nbformat` for notebook structure and `jupyter-server` for backend services.
