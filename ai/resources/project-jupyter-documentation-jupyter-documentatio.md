# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: A modular, extensible framework centered on interactive computing via computational notebooks (e.g., Jupyter Notebook, JupyterLab), supporting code execution, rich visualizations, and narrative documentation in a single document format.

- **Sub-projects & kernels**: Encompasses UI tools (e.g., JupyterLite, Voilà), server/client architectures (e.g., JupyterHub, nbformat), and language kernels (e.g., IPython, IRkernel, Xeus), enabling cross-language interoperability and scalable deployments.

- **Deployment & extensions**: Supports containerized environments (Docker Stacks), cloud/cluster integration (Kubernetes, Enterprise Gateway), and AI-driven tools (e.g., jupyter-ai), with modular APIs for custom extensions and community-driven development.
