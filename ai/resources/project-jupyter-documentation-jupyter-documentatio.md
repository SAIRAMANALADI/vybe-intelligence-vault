# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: A modular, extensible framework centered around interactive computing with computational notebooks, supporting code execution, rich visualizations, and narrative documentation via tools like Jupyter Notebook and JupyterLab.

- **Sub-projects and kernels**: Encompasses UI tools (e.g., JupyterLite, Voilà), deployment systems (e.g., JupyterHub, Kubernetes spawner), notebook utilities (e.g., nbconvert, nbformat), and multi-language kernels (e.g., IPython, IRkernel, Xeus).

- **Architecture and standards**: Defined by protocols like `jupyter-client` (messaging), file formats (`nbformat`), and server components (`jupyter-server`), enabling interoperability and customization across the ecosystem.
