# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: A modular, extensible framework centered around interactive computing, primarily using computational notebooks (e.g., Jupyter Notebook, JupyterLab) that integrate code, visualizations, and narrative text in a single document.

- **Core sub-projects**: Includes user interfaces (JupyterLab, nbclassic), execution/conversion tools (nbclient, nbconvert), kernels (IPython, IRkernel, IJulia), and deployment solutions (JupyterHub, Docker Stacks), all adhering to the Jupyter Messaging Protocol (`jupyter-client`).

- **Architecture & standards**: Defined by `nbformat` (notebook schema), `jupyter-core` (base utilities), and `jupyter-server` (server-client interactions), enabling interoperability across kernels, extensions, and third-party integrations.
