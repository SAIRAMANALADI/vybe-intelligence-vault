# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: A modular, extensible framework for interactive computing, centered around computational notebooks (e.g., Jupyter Notebook, JupyterLab) that integrate code, visualizations, and rich text in a single document format (`.ipynb`).

- **Sub-projects and kernels**: Comprises standalone tools (e.g., `nbconvert`, `nbformat`, `JupyterHub`) and language-specific kernels (e.g., IPython, IRkernel, IJulia) enabling multi-language support via the Jupyter Messaging Protocol (`jupyter-client`).

- **Deployment and extensibility**: Supports scalable deployments (e.g., Docker Stacks, Kubernetes via `KubeSpawner`) and customization through widgets (`ipywidgets`), AI integrations (`jupyter-ai`), and third-party extensions for collaborative, reproducible workflows.
