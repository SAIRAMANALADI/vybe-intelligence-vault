# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: A modular, extensible framework for interactive computing, centered around computational notebooks (e.g., Jupyter Notebook, JupyterLab) that integrate code, visualizations, and narrative text in a single document.

- **Key sub-projects**: Includes user interfaces (JupyterLab, nbconvert), kernels (IPython, IRkernel), deployment tools (JupyterHub, Docker Stacks), and specialized libraries (nbgrader, ipywidgets) for execution, conversion, and collaboration.

- **Architecture**: Based on the Jupyter Messaging Protocol (`jupyter-client`), with a standardized notebook format (`nbformat`) and modular components (e.g., `jupyter-server`, `jupyter-core`) enabling scalable, multi-language interactive workflows.
