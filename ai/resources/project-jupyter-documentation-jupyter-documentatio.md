# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: A modular framework centered on interactive computing via computational notebooks, supporting code execution, rich visualizations, and narrative text in a single document; includes core tools like Jupyter Notebook, JupyterLab, and JupyterHub, alongside standards like `nbformat` and messaging protocols (`jupyter-client`).

- **Sub-projects and extensions**: Encompasses user interfaces (e.g., JupyterLite, Voilà), kernels (e.g., IPython, IRkernel, Xeus), deployment tools (e.g., Docker Stacks, Kubernetes Spawners), and AI integrations (e.g., `jupyter-ai`); designed for extensibility via custom kernels, widgets (`ipywidgets`), and server-side components.

- **Community and governance**: Operates as an open-source project under NumFocus, with structured contributions (developer/ documentation guides), community events, and resources (Discourse forum, mailing lists); emphasizes accessibility, sustainability, and collaborative development.
