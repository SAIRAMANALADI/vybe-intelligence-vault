# Project Jupyter Documentation — Jupyter Documentation 4.1.1 alpha documentation

## Summary

- **Jupyter ecosystem**: Project Jupyter is a modular umbrella project comprising tools like Jupyter Notebook (lightweight) and JupyterLab (feature-rich, extensible IDE) for interactive computing via computational notebooks, which integrate code, visualizations, and rich media in a shareable document format.

- **Sub-projects and kernels**: Core components include nbformat (notebook format), jupyter-client (messaging protocol), and language-specific kernels (e.g., IPython, IRkernel, IJulia), alongside deployment tools like JupyterHub (multi-user server) and Docker/Kubernetes integrations for scalable environments.

- **Documentation and community**: The project provides extensive technical documentation (e.g., architecture, APIs) and supports contributions via GitHub, with resources for installation, configuration, and advanced use cases, alongside community-driven initiatives for accessibility and AI integration (e.g., jupyter-ai).
