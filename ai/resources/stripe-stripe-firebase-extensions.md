# stripe-firebase-extensions/firestore-stripe-payments at master · invertase/stripe-firebase-extensions · GitHub

## Summary

- **Integration & Sync**: Firebase extension syncs Stripe payments (one-time/subscriptions) with Firebase Authentication, storing customer/subscription data in Cloud Firestore and managing access via custom claims.
- **Webhook & Event Handling**: Processes Stripe webhook events (e.g., `invoice.payment_succeeded`) to update Firestore and Firebase Auth claims, ensuring real-time subscription status synchronization.
- **Mobile & Web Support**: Enables Stripe Checkout (web), mobile payment sheets (Android/iOS/React Native), and Stripe Customer Portal, with Firestore-stripe-payments SDK for client-side operations.
