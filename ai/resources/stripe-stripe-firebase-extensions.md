# stripe-firebase-extensions/firestore-stripe-payments at master · invertase/stripe-firebase-extensions · GitHub

## Summary

- **Integration Scope**: Enables real-time synchronization of Stripe payments (one-time & subscriptions) with Firebase Authentication for access control, supporting web (Stripe Checkout), Android/iOS (Payment Sheet), and React Native.
- **Firestore & Auth Sync**: Automatically syncs Stripe customer/subscription data with Cloud Firestore and Firebase Auth custom claims, with configurable webhook handling for events like `invoice.payment_succeeded`.
- **Backend Functions**: Deploys Cloud Functions (`createCustomer`, `handleWebhookEvents`, `onUserDeleted`, etc.) to manage Stripe operations, requiring a restricted Stripe API key and Firestore/Auth pre-setup.
