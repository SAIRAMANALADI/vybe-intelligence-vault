# Dovecot | The Secure IMAP server

## Summary

- **Performance & Compatibility**: Dovecot is a high-performance IMAP server supporting standard mailbox formats (mbox, Maildir) with transparent indexing for optimal speed and full compatibility.

- **Security & Extensibility**: Designed with security-first principles, Dovecot supports flexible authentication mechanisms, self-healing index repairs, and plugin-based extensibility (e.g., Lua scripting, quota/ACL via plugins).

- **Cluster & Standards Compliance**: Compatible with clustered filesystems (excluding NFS without workarounds), supports SMTP auth integration with Postfix/Exim, and adheres strictly to IMAP standards while providing client bug workarounds.
