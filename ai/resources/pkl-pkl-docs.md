# Pkl :: Pkl Docs

## Summary

- **Multi-format configuration generation**: Pkl allows defining configuration in a single `.pkl` file and exporting to JSON, YAML, Property Lists, Java Properties, and other formats via built-in renderers.

- **Statically-typed, validated configuration**: Supports type constraints (e.g., `UInt16(this > 1000)`), validation, and IDE integration (IntelliJ, VS Code, Neovim) with error detection before deployment.

- **Cross-language code generation**: Compiles Pkl modules into typed configuration classes for Java, Kotlin, Swift, and Go, enabling runtime-safe application configuration.
