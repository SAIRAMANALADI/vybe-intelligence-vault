# Misc: Support | Nitric Documentation

## Summary

- **Bug Reporting**: Report issues via [GitHub Issues](https://github.com/nitrictech/nitric/issues) or use the main repo for unclear cases; include detailed reproduction steps, expected vs. actual behavior, and environment specifics (CLI version, OS, dependencies, cloud provider versions).
- **Reproduction Requirements**: Provide a minimal, standalone GitHub repository or detailed logs (`.nitric` folder) and steps to reproduce the bug for efficient debugging.
- **Best Practices**: Use the [Bug Report Template](https://github.com/nitrictech/nitric/issues/new?assignees=&labels=bug&projects=&template=1.bug.md) and include `.nitric` logs, environment details (e.g., `nitric version`), and clear bug descriptions with screenshots if applicable.
