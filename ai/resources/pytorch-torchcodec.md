# pytorch/torchcodec

## Summary

- **Media I/O Library**: `torchcodec` provides PyTorch-native tools for decoding and encoding media (audio/video) using optimized C++ backends (e.g., FFmpeg) with Python bindings.
- **GPU Acceleration**: Supports hardware-accelerated decoding (e.g., NVIDIA NVDEC, AMD AMF) and encoding via CUDA/cuDNN, enabling end-to-end GPU pipelines.
- **Differentiable Operations**: Includes differentiable resampling and color space conversions for integration with PyTorch autograd for training/inference workflows.
