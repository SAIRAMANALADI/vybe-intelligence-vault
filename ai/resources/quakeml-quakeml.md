# QuakeML - QuakeML

## Summary

- **QuakeML** is an open, modular XML-based standard for seismological data representation, designed for extensibility to cover waveform data, macroseismic information, and other advanced seismological fields.

- **Version 1.2** is the stable release, widely adopted in FDSN web services and supported by global data centers, while **QuakeML 2.0** introduces new thematic packages (e.g., waveform, macroseismic, strong motion) under active development.

- **Collaborative development** occurs via a distributed team, with version 2.0 undergoing a Request for Comments (RfC) process for select sub-packages, accessible via [quake.ethz.ch/quakeml](https://quake.ethz.ch/quakeml).
