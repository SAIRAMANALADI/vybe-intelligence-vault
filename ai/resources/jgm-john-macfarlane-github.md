## Summary

- **Syntax & Parsing Libraries**: Develops `texmath` (LaTeX→MathML conversion), `skylighting` (syntax highlighting), and `commonmark-hs` (CommonMark parser), all in Haskell.
- **CommonMark Spec Leadership**: Leads the [CommonMark spec](https://github.com/commonmark/commonmark-spec) and its C reference implementation (`cmark`), with 5.1k+ and 2k+ stars respectively.
