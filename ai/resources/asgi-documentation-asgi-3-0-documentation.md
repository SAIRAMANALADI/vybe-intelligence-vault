# ASGI Documentation — ASGI 3.0 documentation

## Summary

- **Purpose & Compatibility**: ASGI (Asynchronous Server Gateway Interface) extends WSGI to support both synchronous and asynchronous Python web applications, providing a standardized interface between async-capable servers, frameworks, and apps with WSGI backward compatibility.

- **Core Components**: Defines specifications for message formats (HTTP, WebSocket, lifespan events) and supports extensions for additional functionality, enabling interoperability across implementations.

- **Ecosystem & Development**: Facilitated by the `asgiref` reference implementation (hosted on GitHub), with multiple server/framework integrations available and ongoing community-driven development.
