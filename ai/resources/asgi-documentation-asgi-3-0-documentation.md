# ASGI Documentation — ASGI 3.0 documentation

## Summary

- **Purpose & Compatibility**: ASGI (Asynchronous Server Gateway Interface) extends WSGI to support both synchronous and asynchronous Python web applications, providing backward compatibility with WSGI via `asgiref` while enabling async-capable servers, frameworks, and apps.

- **Core Specifications**: Defines a standardized interface for async-capable Python web servers, including protocols for HTTP, WebSocket, and lifespan events, ensuring interoperability across implementations.

- **Ecosystem & Development**: Hosted on [asgiref GitHub](https://github.com/django/asgiref), ASGI includes implementations like Django Channels, Uvicorn, and Daphne, with ongoing contributions and discussions in the community.
