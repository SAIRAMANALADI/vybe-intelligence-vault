# The official repository for Dart and Flutter packages.

## Summary

- **`geolocator`**: Cross-platform (iOS/Android) Flutter plugin for GPS-based geolocation services, providing standardized APIs for location retrieval and monitoring.
- **`chopper`**: HTTP client generator for Dart/Flutter using source generation (`source_gen`), analogous to Retrofit for Java, enabling type-safe REST API interactions.
- **`isolated_object`**: Dart/Flutter utility that wraps objects in dedicated isolates to offload timer/event-loop-driven operations (e.g., progress spinners) from the main event loop.
