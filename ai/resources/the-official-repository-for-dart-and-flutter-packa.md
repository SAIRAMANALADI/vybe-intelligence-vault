# The official repository for Dart and Flutter packages.

## Summary

- **`path_provider`**: Flutter plugin providing cross-platform access to common filesystem locations (e.g., temp/data dirs) via platform-specific APIs (NSFileManager on iOS, Java File on Android).

- **`flutter_bloc`**: Implements BLoC (Business Logic Component) pattern with reactive state management, offering `BlocBuilder`, `BlocProvider`, and other widgets for declarative UI updates based on state changes.

- **`win32`**: Dart FFI-based library enabling direct Windows API calls (e.g., Win32, COM) for low-level system interactions, eliminating native dependencies while maintaining cross-platform compatibility.
