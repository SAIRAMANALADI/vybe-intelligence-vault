# PageSpeed Insights

## Summary

- **Performance Analysis Tool**: Google's PageSpeed Insights evaluates web page performance on mobile and desktop devices using Lighthouse audits, providing metrics like First Contentful Paint (FCP) and Largest Contentful Paint (LCP).

- **Scoring Mechanism**: Scores (0-100) are derived from Core Web Vitals (CWV) and other performance best practices, with recommendations categorized by optimization impact (High, Medium, Low).

- **API & Integration**: Offers a RESTful API (`https://www.googleapis.com/pagespeedonline/v5/runPagespeed`) for automated audits, supporting custom parameters (e.g., `strategy=mobile/desktop`, `category=performance/accessibility`).
