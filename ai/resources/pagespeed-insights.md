# PageSpeed Insights

## Summary

- **Performance Analysis Tool**: Google's PageSpeed Insights evaluates web page performance on mobile and desktop, providing optimization suggestions based on Core Web Vitals and other metrics.

- **API Integration**: The tool offers a RESTful API (`https://www.googleapis.com/pagespeedonline/v5/runPagespeed`) for automated performance audits, returning structured JSON data with metrics like Largest Contentful Paint (LCP) and Cumulative Layout Shift (CLS).

- **Scoring & Recommendations**: Generates a performance score (0-100) with actionable recommendations (e.g., image optimization, JavaScript minification) to improve page load speed and user experience.
