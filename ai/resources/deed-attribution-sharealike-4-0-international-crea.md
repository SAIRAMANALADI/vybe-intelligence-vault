## Summary

- A **canonical URL** is a standardized, preferred URL for a webpage, specified using the `<link rel="canonical">` HTML element or HTTP header to prevent duplicate content issues.
- It consolidates ranking signals (e.g., backlinks, PageRank) to a single URL, improving SEO by directing search engines to the authoritative version of a page.
- Commonly used in dynamic sites (e.g., e-commerce, CMS) to manage parameters, session IDs, or syndicated content, ensuring search engines index the correct version.
