## Summary

- A **Canonical URL** is a web page's preferred, standardized URL defined using the `<link rel="canonical">` HTML element or HTTP header to prevent duplicate content issues.
- It consolidates ranking signals (e.g., backlinks, traffic) to a single URL, improving SEO by directing search engines to the authoritative version of a page.
- Improper canonicalization (e.g., incorrect self-referencing or conflicting signals) can lead to indexing errors, crawl budget waste, or diluted page authority.
