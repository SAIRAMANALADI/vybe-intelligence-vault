# Streamdown

## Summary

- **Markdown Renderer for AI Streaming**: Streamdown is a highly interactive, customizable Markdown renderer optimized for streaming AI-generated content, featuring built-in typography, streaming carets, animations, and plugins.

- **Security & Customization**: Implements security hardening to block unauthorized images/links, link safety modals, and supports full customization via components, styling, and tree-shakeable plugins.

- **Rich Feature Set**: Supports LaTeX math (KaTeX), Mermaid diagrams, CJK text, Shiki-powered syntax highlighting, GitHub Flavored Markdown (GFM), and interactive code blocks with copy/download functionality.
