# CodeQL - Visual Studio Marketplace

## Summary

- **Core Functionality**: The extension integrates CodeQL into VS Code, enabling static analysis via query execution on source code databases, with data flow visualization for security triage and IntelliSense support for query development.

- **Setup & Dependencies**: Requires VS Code ≥1.39; automates CodeQL CLI access by default but allows manual CLI configuration; recommends cloning the [starter workspace](https://github.com/github/vscode-codeql-starter) for preconfigured libraries/queries.

- **Workflow Integration**: Supports importing GitHub-sourced databases, running queries via CLI, and viewing results in the CodeQL Query Results view; includes keyboard navigation and error diagnostics for query execution.
