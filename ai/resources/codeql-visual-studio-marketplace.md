# CodeQL - Visual Studio Marketplace

## Summary

- **Integration & Features**: The CodeQL VS Code extension enables static analysis via CodeQL queries on source code databases, providing IntelliSense for query development, data flow visualization for security triage, and access to GitHub's open-source security query repository.

- **Setup & Workflow**: Requires VS Code ≥1.39; automates CodeQL CLI management (or allows manual CLI configuration), supports database imports from GitHub, and executes queries via CLI with results displayed in a dedicated view.

- **Telemetry & Licensing**: Collects opt-in usage metrics (retaining IP/installation IDs for 30 days, anonymous data for 180 days); licensed under MIT, with CodeQL usage subject to GitHub's terms.
