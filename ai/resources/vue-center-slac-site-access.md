# VUE Center | SLAC Site Access

## Summary

- **Guest Authorization**: All guests must obtain prior authorization via SLAC Guest Gateway before on-site or virtual access; roles include **Visitors** (meetings/tours) and **Users** (research/contracted services).
- **REAL ID Requirement**: Mandatory REAL ID-compliant ID enforcement begins **May 7, 2025**; acceptable forms listed on [REAL ID at SLAC](https://vue.slac.stanford.edu/useful-information/real-id-slac).
- **Operational Hours**: Badging (Mon–Fri, 6am–5pm), User Check-in (6:30am–3:30pm), and Security Operations (24/7); contact details provided for each service.
