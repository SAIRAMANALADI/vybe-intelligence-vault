# Licenses List - Creative Commons

## Summary

- **CC License Versions**: Supports multiple versions (4.0, 3.0, 2.5, 2.1, 2.0, 1.0) with localized legal codes and deeds for jurisdictions worldwide (e.g., 4.0 International, 3.0 Unported, 2.0 Generic).

- **License Variants**: Provides six core license types (`by`, `by-nc`, `by-nc-nd`, `by-nc-sa`, `by-nd`, `by-sa`) across all versions, enabling granular control over attribution, commercial use, derivatives, and share-alike conditions.

- **Multilingual Support**: Offers legally vetted translations of license deeds and codes in 40+ languages (e.g., Bahasa Indonesia, Basque, Danish, German) for 4.0 International licenses, ensuring global applicability.
