# Licenses List - Creative Commons

## Summary

- **CC License Versions**: Supports multiple versions (4.0, 3.0, 2.5, 2.1, 2.0, 1.0) with jurisdiction-specific adaptations (e.g., "Unported," country-specific variants like "3.0 Australia").
- **License Variants**: Provides six core license types (`by`, `by-nc`, `by-nc-nd`, `by-nc-sa`, `by-nd`, `by-sa`) under each version, each with localized "Deed" and "Legal Code" translations for international compliance.
- **Structured Accessibility**: Legal tools are organized by version and language (e.g., Bahasa Indonesia, Deutsch, English) with direct links to machine-readable "Deed" summaries and full "Legal Code" documents for each variant.
