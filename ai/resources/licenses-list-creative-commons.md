# Licenses List - Creative Commons

## Summary

- **Multi-version licensing framework**: Creative Commons provides legally enforceable licenses (versions 1.0 to 4.0) with jurisdiction-specific adaptations (e.g., 3.0 Unported, 3.0 Australia) and standardized international variants (e.g., 4.0 International) to accommodate diverse legal systems.

- **Modular license structure**: Each license variant (e.g., `by`, `by-nc-nd`, `by-sa`) combines core elements (attribution, non-commercial use, derivatives, share-alike) with language-specific translations (e.g., Bahasa Indonesia, Deutsch) and jurisdiction-specific legal codes.

- **Free legal tools with global reach**: All CC licenses are freely available, with 4.0 International offering 39+ language translations and jurisdiction-specific adaptations to ensure enforceability across 100+ jurisdictions.
