# Licenses List - Creative Commons

## Summary

- **Multi-Version License Support**: Creative Commons provides licenses in multiple versions (1.0, 2.0, 2.1, 2.5, 3.0, 4.0) with jurisdiction-specific adaptations (e.g., 3.0 Unported, 3.0 Germany, 4.0 International) to accommodate varying legal frameworks globally.

- **Modular License Structure**: Each version includes modular license types (e.g., `by`, `by-nc`, `by-nc-nd`, `by-nc-sa`, `by-nd`, `by-sa`) allowing creators to select permissions for attribution, non-commercial use, derivatives, and share-alike conditions.

- **Localized Legal Tools**: CC 4.0 International offers localized "Deed" (human-readable) and "Legal Code" (legally binding) translations in 40+ languages (e.g., Bahasa Indonesia, Basque, Danish, German, Estonian) to ensure enforceability across jurisdictions.
