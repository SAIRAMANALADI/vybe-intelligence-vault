# Licenses List - Creative Commons

## Summary

- **Multi-Version Licensing Framework**: CC provides licenses across versions (1.0 to 4.0) with localized adaptations (e.g., 4.0 International, 3.0 Unported) and jurisdiction-specific variants (e.g., 3.0 Australia, 3.0 Germany), enabling legal interoperability under diverse copyright regimes.

- **Modular License Structure**: Each license variant (e.g., `by`, `by-nc-nd`, `by-sa`) combines core conditions (Attribution, NonCommercial, NoDerivatives, ShareAlike) with language-specific legal code and human-readable deeds for enforceability.

- **Global Standardization Effort**: CC 4.0 International offers 6 license types in 40+ languages, with machine-readable metadata (e.g., `legalcode.*`) and localized deeds to harmonize open content licensing across jurisdictions.
