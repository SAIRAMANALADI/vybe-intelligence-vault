# Licenses List - Creative Commons

## Summary

- **CC License Versions**: Supports multiple versions (4.0, 3.0, 2.5, 2.1, 2.0, 1.0) with localized variants for jurisdictions (e.g., 3.0 Unported, 3.0 Australia, 4.0 International).
- **License Variants**: Provides six core license types (`by`, `by-nc`, `by-nc-nd`, `by-nc-sa`, `by-nd`, `by-sa`) across all versions and languages.
- **Localized Legal Tools**: Offers language-specific deed and legal code translations (e.g., Bahasa Indonesia, Basque, Danish, German) for CC 4.0 licenses.
