# Firestore | Firebase

## Summary

- **Firestore Enterprise Edition (Native mode)**: Introduces enhanced scalability, performance, and advanced features like MongoDB compatibility via dedicated SDKs and APIs for enterprise-grade workloads.
- **Data Model & Querying**: Supports hierarchical document-collection structures with nested objects, expressive multi-filter queries, real-time updates, and offline caching with automatic sync upon reconnection.
- **Security & Integration**: Enforces access control via Firebase Authentication + Security Rules (mobile/web) or IAM (server-side), integrates with Google Cloud services (e.g., Cloud Run), and offers SDKs for iOS, Android, Web, and server languages (Node.js, Java, Python, etc.).
