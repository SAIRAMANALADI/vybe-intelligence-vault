# Firestore | Firebase

## Summary

- **Firestore Enterprise Edition (Native Mode)**: Introduces enhanced scalability, performance, and MongoDB compatibility via a dedicated API, with support for existing MongoDB drivers, tools, and integrations.
- **Core Capabilities**: Supports hierarchical document/collection data model, expressive queries (multi-filter, sorting), real-time updates via synchronization, offline caching with automatic sync, and ACID transactions with strong consistency.
- **Multi-Platform & Security**: Direct client access via native SDKs (iOS, Android, Web, Flutter, C++, Unity, Node.js, Java, Python, Go) with security enforced via Firebase Auth/Cloud Firestore Rules (mobile/web) or IAM (server-side).
