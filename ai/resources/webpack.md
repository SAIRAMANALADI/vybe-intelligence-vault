# webpack

## Summary

- **Core Functionality**: Webpack is a static module bundler that processes application dependencies (`.js`, `.css`, `.scss`, `.hbs`, etc.) into optimized static assets (`.js`, `.png`, `.jpg`, etc.) by resolving and bundling them into one or more output files (e.g., `bundle.js`).

- **Configuration & Execution**: Bundling is configured via `webpack.config.js`, specifying `entry` (input file) and `output` (destination path/filename); execution runs via CLI command `webpack`, generating the bundled output (e.g., `dist/bundle.js`).

- **ESM & CJS Support**: Webpack supports both ES Modules (`import/export`) and CommonJS (`require/module.exports`) syntax, enabling modular JavaScript development with dependency management and tree-shaking for optimized builds.
