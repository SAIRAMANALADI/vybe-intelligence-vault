# Cygwin/X

## Summary

- **Porting & Licensing**: Cygwin/X ports the X Window System to Windows via Cygwin's UNIX-like API, minimizing porting effort; licensed under MIT/X11, with Cygwin's GPL exception allowing linkage to Open Source-compliant programs.

- **X Server Configuration**: Default X server (v1.17+) disables TCP/IP listening, accepting only local Unix domain socket connections; requires manual TCP enablement if needed (see FAQ).

- **Installation & Documentation**: Installed via `setup-x86_64.exe`; includes X server, libraries, and clients (e.g., xterm, xclock). User's Guide covers setup, while general X tool docs (e.g., `setxkbmap`) must be referenced externally.
