# Lmod: A New Environment Module System — Lmod 9.2.4 documentation

## Summary

- **Lmod** is a Lua-based environment module system designed to dynamically manage user environments via modulefiles, supporting hierarchical `MODULEPATH` resolution and clean package loading/unloading across multiple shells (bash, zsh, fish, etc.).

- **Key Features**: Supports TCL-to-Lua conversion, dependency management, hidden/forbidden modules via regex, and integrates with build systems (e.g., EasyBuild) while offering performance optimizations like spider caching and load storm mitigation.

- **Architecture**: Uses a modular design with components like `FrameStk` (reversible state engine), `MT` (Module Table), and `varT` (Variable Table), with deep-dive documentation on internal resolution (e.g., `MName` object path traversal) and regression testing frameworks.
