# Trust Legal Provisions (TLP) – IETF Trust

## Summary

- **Purpose & Formation**: The IETF Trust (est. Dec 15, 2005) holds, maintains, and licenses IP used in IETF standards processes to advance Internet-related science/technology per [RFC 5378](http://www.rfc-editor.org/rfc/rfc5378.txt).

- **Licensing Framework**: Standardized licenses for IETF contributions/documents are defined in [Corrected TLP 5.0](https://trustee.ietf.org/documents/trust-legal-provisions/tlp-5/), with restrictions/limitations outlined for downstream use.

- **Governance & Archive**: Discussion occurs via `tlp-interest@ietf.org`; legacy versions (e.g., Code Components 1.0–3.0) are archived with versioned effective/obsolete dates.
