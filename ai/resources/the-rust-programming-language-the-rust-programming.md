## Summary

- Rust 1.90.0+ with `edition = "2024"` in *Cargo.toml* enforces Rust 2024 Edition idioms, requiring explicit edition configuration for projects.

- Rust documentation is accessible via `rustup doc --book` (offline) or online at [doc.rust-lang.org/book](https://doc.rust-lang.org/book/), with community translations available.

- The Rust Book is published in print/e-book by No Starch Press and offers an interactive learning alternative with quizzes, visualizations, and more.
