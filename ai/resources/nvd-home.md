# NVD - Home

## Summary

- **NVD Overview**: U.S. government repository for SCAP-based vulnerability management data, including security checklists, software flaws, product names, and impact metrics, enabling automation of vulnerability management and compliance.

- **CVSS v4.0 Support**: NVD now supports CVSS v4.0 for vulnerability scoring, alongside v3.x and v2.0 calculators, enhancing granularity in risk assessment.

- **API v2.0**: NVD provides updated APIs (v2.0) for programmatic access to vulnerability and product data, requiring an API key for requests.
