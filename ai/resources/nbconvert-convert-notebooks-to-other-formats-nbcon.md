# nbconvert: Convert Notebooks to other formats — nbconvert 7.17.1 documentation

## Summary

- **Purpose**: `nbconvert` converts Jupyter `.ipynb` notebooks into static formats (HTML, LaTeX, PDF, Markdown, reStructuredText) via CLI (`jupyter nbconvert ...`) or Python API (`import nbconvert`), enabling cross-format sharing, publishing, and automation (e.g., batch processing or "Download as" feature in Jupyter).
- **Architecture**: Modular pipeline with core classes (`NbConvertApp`, `Exporters`, `Preprocessors`, `Writers`, `Postprocessors`) and extensible exporters/templates for custom output formats (e.g., slides via `dejavu` or syntax highlighting customization).
- **Advanced Features**: Supports notebook execution (CLI/Python API), cell filtering (tags/Regex), LaTeX citations, Chromium-based PDF generation, and custom exporter registration (entry points or direct implementation) for tailored conversion workflows.
