# Back up or import your blog - Blogger Help

## Summary

- **Backup via Google Takeout**: Access [Google Takeout](http://www.blogger.com/go/takeout) with admin rights, select the target blog, and download the backup file containing posts, pages, and comments in `.atom` or `.xml` format.
- **Theme Backup**: Navigate to **Theme** > **Backup** in Blogger’s left menu, then download the theme file via the dropdown arrow next to **CUSTOMIZE**.
- **Import Content**: Upload the `feed.atom` or `.xml` file from the backup to the target blog via **Settings** > **Import Content**, with optional auto-publish toggle.
