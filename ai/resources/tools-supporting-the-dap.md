# Tools supporting the DAP

## Summary

- **Protocol Definition**: Debug Adapter Protocol (DAP) is a **JSON-based communication protocol** enabling standardized interaction between development tools (IDEs) and debug adapters, decoupling language-specific debugging logic from UI/UX.

- **Client-Server Architecture**: DAP operates as a **client-server model** where IDEs (clients) send requests (e.g., `initialize`, `launch`, `breakpoint`) and debug adapters (servers) respond with capabilities, execution control, and debug data via structured JSON messages.

- **Tooling Ecosystem**: Supports **multiple IDEs** (VS Code, IntelliJ, Emacs, Vim, etc.) and **language runtimes** (Python, Java, C++, etc.) via adapters, with extensible SDKs for custom implementations and protocol specifications hosted at [microsoft.github.io/debug-adapter-protocol](https://microsoft.github.io/debug-adapter-protocol/).
