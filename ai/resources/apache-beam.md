## Summary

- **Repository Fork & Setup**: Fork the [Apache Beam GitHub repository](https://github.com/apache/beam) and copy the [case study MD template](https://github.com/apache/beam/tree/master/website/CASE_STUDY_TEMPLATE.md) to the `case-studies` folder, naming it `YOUR_CASE_STUDY_NAME.md`.

- **Metadata & Assets**: Populate the MD file with required metadata (e.g., `title`, `name`, `publishDate`) and add assets (logo, images) to `/static/images/case-study/company-name/` and `/static/images/logos/powered-by/`.

- **Homepage Integration**: Add a new entry to `quotes.yaml` with fields (`text`, `logoUrl`, `linkUrl`) to display a case study card on the Apache Beam homepage, then submit a PR to the `apache/beam` repository.
