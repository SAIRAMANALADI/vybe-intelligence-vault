# apache/beam

## Summary

- **Unified Model**: Apache Beam provides a single programming model for both batch and streaming data processing, enabling consistent development across diverse data processing workloads.

- **Multi-Language Support**: Supports Java, Python, Go, and SQL via SDKs, allowing cross-language pipelines while maintaining portability across execution engines (e.g., Flink, Spark, Google Dataflow).

- **Portable Execution**: Enables pipeline execution on multiple backends (e.g., Apache Flink, Apache Spark, Google Cloud Dataflow) via runners, abstracting infrastructure dependencies for scalable, fault-tolerant processing.
