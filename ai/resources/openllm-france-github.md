# OpenLLM-France · GitHub

## Summary

- **Objective**: OpenLLM-France aims to collaboratively develop open-source AI LLM models, covering data collection/cleaning, pretraining, and instruction model alignment.

- **Licensing Compliance**: Ensures open-source compliance per OSI standards by providing training corpus, model weights, and training algorithms under non-restrictive open licenses via [Hugging Face](https://huggingface.co/OpenLLM-France).

- **Resources**: Hosts software tools for data curation, pretraining, and alignment in this [GitHub repository](https://github.com/OpenLLM-France), linked to the associated [Hugging Face space](https://huggingface.co/OpenLLM-France).
