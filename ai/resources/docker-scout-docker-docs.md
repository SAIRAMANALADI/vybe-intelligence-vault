# Docker Scout | Docker Docs

## Summary

- **Vulnerability Detection**: Docker Scout analyzes container images by decomposing them into layers and software packages, then cross-referencing them against a continuously updated vulnerability database to identify security weaknesses in the software supply chain.

- **SBOM Generation & Matching**: Generates a Software Bill of Materials (SBOM) inventory of image components, which is matched against known vulnerabilities to proactively highlight security risks in containerized environments.

- **Multi-Interface Integration**: Operates as a standalone service accessible via Docker Hub, CLI, and the Docker Scout Dashboard, with additional integrations for CI/CD pipelines, registries, and third-party tools to enforce supply chain security policies.
