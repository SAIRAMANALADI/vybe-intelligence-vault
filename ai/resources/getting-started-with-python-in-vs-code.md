# Getting Started with Python in VS Code

## Summary

- **VS Code Python Extension**: Provides IntelliSense, debugging, and language support for Python, but does not include the Python interpreter itself.
- **Python Interpreter Setup**: Requires separate installation (e.g., via `python.org`, Homebrew, or Anaconda) and must be configured in VS Code for execution.
- **Cross-Platform Configuration**: Installation paths and dependencies vary by OS (Windows, macOS, Linux) and may require additional tools like `pip` or environment managers (e.g., virtualenv).
