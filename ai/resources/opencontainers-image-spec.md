# image-spec/manifest.md at main · opencontainers/image-spec · GitHub

## Summary

- **Content-addressable images**: OCI Image Manifest enables content-addressable images by hashing the image's configuration to generate a unique ID for the image and its components, ensuring integrity and traceability.
- **Multi-architecture support**: The specification supports multi-architecture images via an "image index" (fat manifest) that references platform-specific image manifests, enabling cross-platform compatibility.
- **Media type and descriptor structure**: The manifest (`application/vnd.oci.image.manifest.v1+json`) includes required fields like `schemaVersion`, `config` (descriptor), and `layers` (array of descriptors), with strict media type compliance for portability and interoperability.
