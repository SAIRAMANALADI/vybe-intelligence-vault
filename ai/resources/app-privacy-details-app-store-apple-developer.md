# App Privacy Details - App Store - Apple Developer

## Summary

- **Mandatory Disclosure Requirements**: Developers must declare all data types collected by their app or third-party partners (e.g., analytics, SDKs) in App Store Connect, including data used for app functionality, unless it meets strict optional disclosure criteria (e.g., not linked to user identity, not used for tracking/advertising, or collected in rare, optional user scenarios).

- **Tracking Definition & Exclusions**: Tracking involves linking app-collected data (e.g., user/device IDs) with third-party data for targeted advertising or sharing with data brokers; exceptions include on-device processing, fraud detection, or consumer reporting agency use cases.

- **Data Linkage & De-identification**: Data is considered linked to a user unless anonymized/de-identified *before* collection (e.g., stripping identifiers) or post-collection protections prevent re-linkage; personal data under privacy laws is inherently linked.
