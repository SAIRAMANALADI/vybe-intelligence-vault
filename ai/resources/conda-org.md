# conda.org

## Summary

- **Multi-language, cross-platform package management**: Conda provides a language-agnostic, multi-platform ecosystem for managing applications and libraries across C, C++, Java, Rust, Go, and more, supporting major platforms including macOS, Windows, Linux, ARM, PowerPC, and Apple Silicon.

- **Collaborative open-source ecosystem**: Supported by organizations like conda, conda-forge, mamba, and conda-incubator, the ecosystem includes tools for native lockfiles, CLI optimizations, and v1 recipe builds, with recent releases (e.g., conda 26.3.x) introducing solver improvements and conda-pypi integration.

- **Standardized, community-driven development**: The conda ecosystem has adopted voted standards (CEPs) and operates under NumFOCUS sponsorship, with infrastructure support from Anaconda, Netlify, and Zulip, and developer backing from entities like Quansight Labs, QuantStack, and QuantCo.
