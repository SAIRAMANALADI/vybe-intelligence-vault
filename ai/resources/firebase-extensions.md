# Firebase Extensions

## Summary

- **Pre-packaged Backend Logic**: Firebase Extensions deploy serverless, event-driven functions (via Cloud Functions for Firebase) packaged as reusable solutions, triggered by Firebase/Google Cloud events (e.g., Firestore writes, HTTPS requests) or third-party integrations (e.g., BigQuery, Mailchimp).

- **Isolated, Configurable Deployments**: Each extension instance uses a dedicated `extension.yaml` file to define required APIs, permissions, and resources, with isolated service accounts and auto-scaled backend infrastructure; instances are configurable (e.g., Firestore paths, API keys) and reusable across projects.

- **Zero-Maintenance Automation**: Extensions handle backend scaling, security (least-privilege access via service accounts), and lifecycle management (install/update/uninstall via Firebase CLI/console), eliminating manual server provisioning and credential management.
