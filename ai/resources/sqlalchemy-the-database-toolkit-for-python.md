# SQLAlchemy - The Database Toolkit for Python

## Summary

- **Dual Architecture**: SQLAlchemy combines a **Core** (for SQL expression language, connection pooling, and schema management) with an **ORM** layer (for Python object-relational mapping), enabling both raw SQL control and high-level abstraction.

- **Dialect Support**: Supports **10+ database backends** (PostgreSQL, MySQL, SQLite, Oracle, etc.) via modular dialects, ensuring cross-platform SQL generation and optimized query execution.

- **Enterprise Patterns**: Implements **unit-of-work**, **identity map**, and **lazy/eager loading** patterns natively, optimizing performance and consistency for large-scale applications.
