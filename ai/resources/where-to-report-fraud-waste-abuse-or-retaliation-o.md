# Where to report fraud, waste, abuse, or retaliation | Oversight.gov

## Summary

- **Fraud, Waste, or Abuse Reporting**: Report wrongdoing related to federal agencies, programs, contracts, or grants via the [Oversight.gov hotline](https://www.oversight.gov/where-report-fraud-waste-abuse-or-retaliation#oversight-hotline-form).
- **Retaliation Complaints**: File whistleblower complaints for retaliation via the [Oversight.gov whistleblower form](https://www.oversight.gov/where-report-fraud-waste-abuse-or-retaliation#oversight-whistleblower-form).
- **Agency-Specific Reporting**: Locate the appropriate Inspector General (IG) or oversight entity for targeted complaints using Oversight.gov’s directory.
