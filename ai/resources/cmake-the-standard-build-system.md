# CMake: The Standard Build System

## Summary

- **Cross-platform build system abstraction**: CMake generates native build files (e.g., Makefiles, Visual Studio projects, Ninja) from a single set of platform-agnostic configuration files, enabling builds across Android, iOS, HPC, and desktop environments.

- **Target-centric dependency management**: Modern CMake models builds as interdependent targets (libraries, executables, custom commands), enforcing correct build order and transitive link dependencies while minimizing rebuilds via accurate dependency tracking (including Fortran/C++ modules).

- **Integrated toolchain ecosystem**: Includes CPack for cross-platform packaging, CTest for parallelized cross-platform testing (with CDash integration), system introspection via cache variables, and Debug Adapter Protocol support for IDE debugging.
