# Get started with Remote Config personalization | Firebase Remote Config

## Summary

- **Instrumentation Requirements**: App must integrate Firebase Analytics (enabled via Firebase Console) and Remote Config SDK (≥ iOS 7.5.0, Android 20.0.3/Firebase BoM 26.4.0, C++ 7.1.1, Unity 7.1.0) to log user events (e.g., objective-completion events) for personalization optimization.

- **Personalization Configuration**: In Firebase Console, define Remote Config parameter alternatives (matching parameter data type) with a selected objective (prebuilt or custom Analytics event), aggregation method (COUNT/SUM), optional secondary metrics, and targeting conditions (≥10K users, ≥1K outcomes/week for optimal performance).

- **Deployment & Monitoring**: Personalized experiences deploy within hours but require up to 14 days for system learning; performance is monitored via **Remote Config** or **Personalizations** pages in Firebase Console, with results interpretable via [dedicated documentation](https://firebase.google.com/docs/remote-config/personalization/about#understand-personalization-results).
