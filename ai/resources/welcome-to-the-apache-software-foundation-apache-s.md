# Welcome to The Apache Software Foundation | Apache Software Foundation

## Summary

- **Scale & Scope**: The Apache Software Foundation (ASF) hosts **290+ open-source projects** across domains like **data, cloud, search, IoT, and geospatial**, with **1300+ software releases** and **10,000+ committers** contributing globally.

- **Incubation & Governance**: ASF’s **Incubator program** supports **1000+ members** and **incubating projects** (e.g., **OzHera, XTable, OpenServerless**), providing neutral governance, tools, and community-driven development frameworks.

- **Community & Events**: ASF fosters **contributor diversity** (code, docs, ideas) and hosts **high-impact events** like **Flink Forward 2026** (stream processing) and **Iceberg Summit 2026** (data architecture), alongside a **monthly newsletter** and **podcast series** (e.g., Apache Polaris, Geode).
