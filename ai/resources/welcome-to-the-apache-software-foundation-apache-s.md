# Welcome to The Apache Software Foundation | Apache Software Foundation

## Summary

- **Scale & Governance**: The Apache Software Foundation (ASF) hosts **290+ top-level projects**, **1300+ software releases**, and **10,000+ committers**, operating as a **501(c)(3) nonprofit** with **1,190+ members** and corporate sponsors.
- **Diverse Ecosystem**: Projects span **data, cloud, search, IoT, geospatial, and financial tech**, including **PLC4X (industrial IoT), RocketMQ (messaging), Ignite (in-memory computing), and DataFusion (analytics)**.
- **Community-Driven Development**: Follows **"community over code"** principles, offering **incubation programs** for new projects (e.g., **Seata, GraphAr, Amoro**) and hosting global events like **Community Over Code** (Beijing, Glasgow, Sydney).
