# How to choose your Baseline target | Articles | web.dev

## Summary

- **Baseline Targets**: Two types exist—*moving targets* (e.g., Baseline Widely/Newly available) that evolve with browser updates, and *fixed targets* (e.g., Baseline 2023) that remain static by calendar year for predictability.
- **Data-Driven Selection**: Use tools like [Google Analytics Baseline Checker](https://baseline-checker.chrome.dev/) or [`baseline-browser-mapping`](https://github.com/web-platform-dx/baseline-browser-mapping) to map real user data to Baseline targets, ensuring compatibility decisions align with audience support.
- **Feature Handling**: Features outside a chosen Baseline target can be categorized as *enhancement*, *additive*, or *critical*; polyfills or progressive enhancement may be applied based on failure impact, with tools like Can I Use or RUMvision providing granular support insights.
