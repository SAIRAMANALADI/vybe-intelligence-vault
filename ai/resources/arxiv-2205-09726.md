# [2205.09726] RankGen: Improving Text Generation with Large Ranking Models

## Summary

- **RankGen**: A 1.2B-parameter encoder model trained via contrastive learning to score text generations given a prefix, mapping prefixes closer to ground-truth continuations and farther from negatives (random document sequences or LM-generated sequences).
- **Integration**: Deployed as a scoring function in beam search for any pretrained LM (345M–11B parameters), outperforming nucleus, top-*k*, typical sampling, and other decoding methods (e.g., 85.0 vs. 77.3 MAUVE) with 74.5% human preference over nucleus sampling.
- **Performance**: Improves relevance to prefixes and enhances continuity/coherence; released as open-source with model checkpoints, code, and human preference data for reproducibility.
