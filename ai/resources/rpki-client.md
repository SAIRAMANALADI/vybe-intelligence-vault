# rpki-client

## Summary

- **Functionality**: `rpki-client` v9.8 validates BGP announcements by querying the global RPKI repository system, outputting validated ROA payloads and BGPsec Router keys in formats compatible with OpenBGPD, BIRD, CSV, or JSON.

- **Development & Licensing**: Primarily developed by OpenBSD Project contributors under the ISC license, with a portable version maintained separately and released periodically.

- **Security Role**: Implements RFC 6480 and RFC 6811 to secure global Internet routing by validating untrusted network inputs via RPKI and BGP Prefix Origin Validation.
