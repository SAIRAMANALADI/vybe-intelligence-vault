# EditPad® Pro: Text Editor for Windows

## Summary

- **Cross-Platform & Language Support**: EditPad Pro supports 64-bit/32-bit Windows (XP–11), Unicode, and syntax highlighting for 30+ languages (e.g., C/C++, Python, JavaScript, SQL, XML), with configurable preferences for user workflows.

- **Advanced Editing Features**: Includes hexadecimal mode, portable editor support, regex-based search/replace, macro automation across files, and line-break conversion (Windows/UNIX/Mac), alongside clipboard management and configurable two-key shortcuts.

- **Commercial & Trial Availability**: Priced at $59.95 with a 100% satisfaction guarantee, offering a free trial download; praised in user testimonials for reliability and feature depth compared to competitors like TextPad and UltraEdit.
