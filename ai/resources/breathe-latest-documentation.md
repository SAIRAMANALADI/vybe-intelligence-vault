# Breathe 'latest' documentation

## Summary

- **Bridge between Sphinx and Doxygen**: Breathe integrates Doxygen's XML output into Sphinx documentation, enabling autodoc-like features for non-Python languages via Sphinx directives.
- **Directive-based integration**: Supports high/low-level directives (e.g., `.. doxygenclass::`) to reference entire projects, classes, or functions, with multi-project support via named/path-based configuration.
- **Doxygen XML dependency**: Requires `GENERATE_XML = YES` in Doxygen config; Sphinx extension registered via `extensions = ["breathe"]` in `conf.py`.
