# Skia

## Summary

- **Cross-platform 2D graphics engine**: Skia provides a unified API for rendering 2D graphics across diverse hardware/software platforms, powering major products like Chrome, Android, and Flutter.
- **Hardware-accelerated rendering**: Supports GPU acceleration via OpenGL, Vulkan, Metal, and Direct3D, while maintaining software fallback paths for compatibility.
- **Modular architecture**: Composed of core libraries (e.g., `SkCanvas`, `SkPaint`) with pluggable backends, enabling customization for specific use cases (e.g., PDF generation, SVG support).
