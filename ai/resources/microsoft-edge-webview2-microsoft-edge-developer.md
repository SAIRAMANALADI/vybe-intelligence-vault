# Microsoft Edge WebView2 | Microsoft Edge Developer

## Summary

- **Chromium-based WebView**: Embeds modern Microsoft Edge (Chromium) rendering engine in native apps for HTML/CSS/JS execution with full compatibility.

- **Dual Distribution Models**: Supports evergreen (auto-updating) and fixed-version (static) runtime deployment for compatibility vs. security trade-offs.

- **Native Integration**: Enables controlled access to native OS APIs via WebView2, allowing secure bridging between web and native code.
