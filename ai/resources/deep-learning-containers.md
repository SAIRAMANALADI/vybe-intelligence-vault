# Deep Learning Containers

## Summary

- **Pre-configured Docker images** optimized for AI/ML workloads, including frameworks like vLLM, PyTorch, and Ray, with dependencies and optimized libraries pre-installed.

- **No-cost base images** provided by AWS, with costs only incurred for underlying compute resources (EC2, EKS, SageMaker, etc.), and regularly tested for performance and security patches.

- **Multi-use support** covering LLM serving (vLLM/SGLang), multimodal models (vLLM-Omni), distributed training (PyTorch with EFA/NCCL), and custom image building via lightweight base images (CUDA + Python on Amazon Linux 2023).
