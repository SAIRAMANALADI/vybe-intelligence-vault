# Help - Authy | Authy

## Summary

- **Account Reset**: Authy provides an account reset option for users unable to access old devices or install Authy on new ones via [Reset account](https://authy.com/phones/reset/).

- **Phone Number Update**: Users can change their registered phone number for 2FA/Authy if no longer accessible or changed via [Change number](https://authy.com/phones/change/).

- **Account Deletion**: Authy allows permanent deletion of user accounts and associated data via [Delete account](https://authy.com/account/delete/).
