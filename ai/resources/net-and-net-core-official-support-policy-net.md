# .NET and .NET Core official support policy | .NET

## Summary

- **Support Lifecycle & Cadence**: .NET follows an annual major release cycle (November) with even-numbered releases (e.g., .NET 8, 10) as LTS (3-year support) and odd-numbered (e.g., .NET 9) as STS (2-year support), governed by Microsoft’s Modern Lifecycle Policy.
- **Servicing Policies**: Updates are cumulative, released monthly on "Patch Tuesday," and include security/non-security fixes; LTS transitions to maintenance (security-only) in final 6 months before EOL, aligned with Patch Tuesday dates.
- **OS & Deployment Support**: Cross-platform OS support is detailed in [.NET Supported OS Policy](https://github.com/dotnet/core/blob/main/os-lifecycle-policy.md); Framework-Dependent Deployments (FDD) on Windows auto-patch via Microsoft Update, while Self-Contained Deployments (SCD) require manual updates.
