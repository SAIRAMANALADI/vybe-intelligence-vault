# Build websites for R packages • pkgdown

## Summary

- **Purpose & Functionality**: `pkgdown` automates R package website generation, converting `README.md`, `man/` documentation, and vignettes into a static site; `build_site()` previews locally, while GitHub Actions enables automated deployment.

- **Bootstrap 5 Upgrade**: `pkgdown` 2.0.0 migrates from Bootstrap 3 to 5, requiring explicit opt-in via `_pkgdown.yml` (`template: bootstrap: 5`) to avoid breaking customizations.

- **Adoption & Examples**: Used by >12,000 packages (e.g., `bayesplot`, `valr`, `mkin`), with source repositories providing templates for customization and best practices.
