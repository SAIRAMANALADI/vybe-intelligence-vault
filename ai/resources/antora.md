# Antora

## Summary

- **Multi-repository aggregation**: Antora retrieves and aggregates AsciiDoc documentation from one or more Git repositories (local, remote, private, or public), supporting versioning via branches and ignoring non-published branches, enabling decentralized content management.

- **Playbook-driven orchestration**: Uses a declarative YAML playbook to define site assembly rules (content sources, versions, UI, routes), executed via CLI for consistent, reproducible documentation site generation with support for local uncommitted changes and multi-environment publishing.

- **Cross-referenced, UI-agnostic architecture**: Decouples content from filesystem paths/URLs via AsciiDoc-based navigation and cross-references, while enabling hot-swappable UIs (stored in separate repos) and extensibility via Asciidoctor’s extension API for custom syntax/output transformations.
