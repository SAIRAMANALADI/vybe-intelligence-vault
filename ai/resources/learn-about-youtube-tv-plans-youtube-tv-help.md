# Learn about YouTube TV Plans - YouTube TV Help

## Summary

- **Plan Variability**: YouTube TV offers multiple tiered plans (e.g., Sports, Entertainment, News, Family) with modular combinations (e.g., Sports + News + Family), but custom channel selection is not supported; all plans inherit the main plan’s features (DVR, Multiview, Family Sharing) except channel availability.
- **Plan Switching Mechanics**: Users can switch plans mid-cycle with prorated credits applied to the new plan’s billing date; downgrades may remove DVR content for unavailable channels, but a 21-day window exists to restore access if re-subscribed to the channel genre.
- **Availability Constraints**: Plan options depend on billing provider (carrier/ISP/Google Play), with some tiers unavailable through partners; direct billing via YouTube TV’s homepage provides full plan access, and promotional pricing is lost upon plan changes.
