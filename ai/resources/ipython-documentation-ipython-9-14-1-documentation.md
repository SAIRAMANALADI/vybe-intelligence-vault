# IPython Documentation — IPython 9.14.1 documentation

## Summary

- **Interactive Python Shell & Jupyter Kernel**: Provides an enhanced interactive Python shell with comprehensive object introspection, persistent input history, and caching of output results, alongside a Jupyter kernel enabling Python code execution in Jupyter notebooks and other interactive frontends.

- **Advanced Features**: Includes real multi-line editing via `prompt_toolkit`, syntax highlighting, magic commands for environment control, extensible tab completion, session logging/reloading, and integrated access to `pdb` debugger and Python profiler.

- **Rich Display & Widgets**: Supports rich display of HTML, images, LaTeX, sound, and video, with interactive widgets via `ipywidgets` when used with compatible frontends.
