## Summary

- **Definition**: A canonical URL is a specific URL designated as the preferred version among multiple URLs that display identical or similar content, helping to consolidate ranking signals and avoid duplicate content issues.
- **Purpose**: Implements `<link rel="canonical">` tags or HTTP headers to signal search engines which URL should be indexed and ranked, preventing dilution of SEO value across duplicate pages.
- **Implementation**: Can be set via HTML meta tags, HTTP headers, or server-side configurations (e.g., `.htaccess`, CMS plugins) to enforce canonicalization.
