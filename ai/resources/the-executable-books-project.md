# The Executable Books Project

## Summary

- **Jupyter Book**: CLI tool for generating publication-quality books/documents from computational content (Jupyter ecosystem), enabling executable narratives via integration with Jupyter tools.

- **MyST Markdown**: Extensible, semantic markdown dialect optimized for scientific/computational narratives, supporting executable content and interoperability with Jupyter tools.

- **Ecosystem**: Open-source suite including tools for authoring, publishing, and rendering computational narratives, with community-driven development (e.g., MyST-JS for JavaScript integration).
