# YouTube | Google for Developers

## Summary

- **YouTube IFrame Player API** enables embedded video playback with customizable parameters for web apps, while platform-specific SDKs (iOS) support native integration.

- **YouTube Data API v3** allows programmatic access to search, upload, playlist management, and other core YouTube functionalities via REST endpoints and client libraries.

- **YouTube Analytics & Reporting API** provides channel/video performance metrics, while **Subscribe Button** and **Live Streaming API** facilitate user subscriptions and broadcast management.
