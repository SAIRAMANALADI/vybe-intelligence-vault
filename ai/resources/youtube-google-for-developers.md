# YouTube | Google for Developers

## Summary

- **YouTube IFrame API**: Embed and customize YouTube video playback with parameters, supporting web (`IFrame`), iOS (`iOS YouTube Helper`), and player configuration via [Player Parameters](https://developers.google.com/youtube/player_parameters).

- **YouTube Data API v3**: Enables search, uploads, playlist management, and user interactions via RESTful endpoints; includes [reference docs](https://developers.google.com/youtube/v3/docs), [code samples](https://developers.google.com/youtube/v3/code_samples), and [getting-started guide](https://developers.google.com/youtube/v3/getting-started).

- **Analytics & Live Streaming APIs**: Retrieve channel/video performance via [YouTube Reporting API](https://developers.google.com/youtube/reporting) and manage live broadcasts with the [Live Streaming API](https://developers.google.com/youtube/v3/live/getting-started), including scheduling and stream ingestion.
