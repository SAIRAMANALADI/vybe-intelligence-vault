# YouTube | Google for Developers

## Summary

- **YouTube IFrame API**: Embed and customize YouTube video playback in apps with parameters for controls, autoplay, and events via `YT.Player` and `onStateChange` callbacks.

- **YouTube Data API v3**: Enables search, uploads, playlist management, and channel operations via REST endpoints (`videos.insert`, `playlists.list`) with OAuth 2.0 authentication.

- **YouTube Analytics API**: Retrieves channel/video metrics (views, likes) and generates reports via batch jobs (`jobs.create`) with quota-limited quotaUser parameter.
