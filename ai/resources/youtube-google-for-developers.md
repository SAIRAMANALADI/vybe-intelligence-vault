# YouTube | Google for Developers

## Summary

- **YouTube IFrame API**: Enables embedded video playback with customizable parameters for web apps via [IFrame](https://developers.google.com/youtube/iframe_api_reference), iOS via [YouTube Helper](https://developers.google.com/youtube/v3/guides/ios_youtube_helper), and supports [player parameters](https://developers.google.com/youtube/player_parameters) for fine-grained control.

- **YouTube Data API v3**: Facilitates programmatic access to YouTube features, including video search, uploads, playlist management, and user interactions via [REST endpoints](https://developers.google.com/youtube/v3/docs) with [code samples](https://developers.google.com/youtube/v3/code_samples).

- **YouTube Analytics & Live Streaming APIs**: Provides [reporting tools](https://developers.google.com/youtube/reporting) for channel/video performance metrics and enables [live broadcast scheduling/management](https://developers.google.com/youtube/v3/live/getting-started) with [live streaming API](https://developers.google.com/youtube/v3/live).
