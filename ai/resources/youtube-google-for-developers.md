# YouTube | Google for Developers

## Summary

- **YouTube IFrame API**: Enables embedded video playback with customizable parameters for web apps via `<iframe>` or platform-specific SDKs (iOS/Android).
- **YouTube Data API v3**: Provides endpoints for searching content, managing playlists, uploading videos, and user interactions with OAuth 2.0 integration.
- **Analytics & Live Streaming APIs**: Reporting API tracks user engagement; Live Streaming API schedules broadcasts and manages video streams with real-time ingestion.
