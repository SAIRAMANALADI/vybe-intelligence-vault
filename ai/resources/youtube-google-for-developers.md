# YouTube | Google for Developers

## Summary

- **YouTube IFrame Player API** enables embedded video playback with customizable parameters for web apps, while iOS helper simplifies integration for mobile applications.

- **YouTube Data API v3** supports search, uploads, playlist management, and other core functionalities via RESTful endpoints with comprehensive documentation and code samples.

- **YouTube Reporting API** provides analytics on channel/video performance, **Subscribe Button API** facilitates one-click subscriptions, and **Live Streaming API** allows broadcast scheduling and stream management.
