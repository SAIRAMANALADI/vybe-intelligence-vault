# YouTube | Google for Developers

## Summary

- **YouTube IFrame API**: Embed and customize YouTube video playback with parameters for control (e.g., autoplay, loop, controls) across web, iOS, and Android via the [IFrame API](https://developers.google.com/youtube/iframe_api_reference), [iOS helper](https://developers.google.com/youtube/v3/guides/ios_youtube_helper), and [player parameters](https://developers.google.com/youtube/player_parameters).

- **YouTube Data API v3**: Enable programmatic interactions with YouTube content, including search, uploads, playlist management, and user interactions via the [Data API v3](https://developers.google.com/youtube/v3/getting-started) with endpoints documented in the [reference](https://developers.google.com/youtube/v3/docs) and [code samples](https://developers.google.com/youtube/v3/code_samples).

- **YouTube Analytics & Live Streaming APIs**: Retrieve channel/video performance metrics via the [Analytics API](https://developers.google.com/youtube/reporting) and manage live broadcasts using the [Live Streaming API](https://developers.google.com/youtube/v3/live/getting-started), including scheduling and stream configuration.
