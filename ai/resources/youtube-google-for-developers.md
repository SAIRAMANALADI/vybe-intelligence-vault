# YouTube | Google for Developers

## Summary

- **YouTube IFrame API**: Enables embedded video playback with customizable parameters for web apps via `iframe` integration, iOS helper library, and configurable player settings.

- **YouTube Data API v3**: Facilitates programmatic access to YouTube features (search, uploads, playlist management) with endpoints documented in the [v3 reference](https://developers.google.com/youtube/v3/docs) and sample implementations.

- **Analytics & Live Streaming APIs**: Provides reporting tools for user interaction metrics ([YouTube Reporting API](https://developers.google.com/youtube/reporting)) and live broadcast management ([Live Streaming API](https://developers.google.com/youtube/v3/live/getting-started)).
