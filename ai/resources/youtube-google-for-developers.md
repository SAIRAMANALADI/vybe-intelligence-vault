# YouTube | Google for Developers

## Summary

- **YouTube IFrame API** enables embedded video playback with customizable parameters for web apps, while **iOS helper** provides native integration for Apple devices.
- **YouTube Data API v3** allows programmatic access to search, upload, playlist management, and other core YouTube functionalities via RESTful endpoints.
- **Analytics & Reporting API** provides channel/video performance metrics, **Subscribe Button** enables one-click channel subscriptions, and **Live Streaming API** supports broadcast scheduling and stream management.
