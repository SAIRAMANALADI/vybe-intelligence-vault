# YouTube | Google for Developers

## Summary

- **YouTube IFrame API**: Enables embedded video playback with customizable parameters for web apps via [IFrame](https://developers.google.com/youtube/iframe_api_reference), [iOS](https://developers.google.com/youtube/v3/guides/ios_youtube_helper), and [player configurations](https://developers.google.com/youtube/player_parameters).

- **YouTube Data API v3**: Facilitates programmatic access for video search, uploads, playlist management, and user interactions via [REST endpoints](https://developers.google.com/youtube/v3/docs) and [code samples](https://developers.google.com/youtube/v3/code_samples).

- **YouTube Analytics & Live Streaming APIs**: Provides [reporting tools](https://developers.google.com/youtube/reporting) for user engagement metrics and [live streaming capabilities](https://developers.google.com/youtube/v3/live/getting-started) for broadcast scheduling and stream management.
