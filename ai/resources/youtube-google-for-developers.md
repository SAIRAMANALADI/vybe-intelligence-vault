# YouTube | Google for Developers

## Summary

- **YouTube IFrame API** enables embedded video playback with customizable parameters for web apps ([docs](https://developers.google.com/youtube/iframe_api_reference)), while **iOS helper** provides native integration ([guide](https://developers.google.com/youtube/v3/guides/ios_youtube_helper)).

- **YouTube Data API v3** supports search, uploads, playlist management, and other core functionalities via REST endpoints ([reference](https://developers.google.com/youtube/v3/docs)).

- **YouTube Analytics API** provides channel/video performance metrics, and **Live Streaming API** allows broadcast scheduling and stream management ([reporting](https://developers.google.com/youtube/reporting), [live docs](https://developers.google.com/youtube/v3/live/getting-started)).
