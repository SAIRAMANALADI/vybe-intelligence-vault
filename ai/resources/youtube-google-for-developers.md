# YouTube | Google for Developers

## Summary

- **YouTube IFrame Player API** enables embedded video playback with customizable parameters for web apps, while **iOS helper** provides native integration for mobile applications.

- **YouTube Data API v3** supports advanced functionalities including video search, uploads, playlist management, and user interactions via structured REST endpoints and code samples.

- **YouTube Analytics & Reporting API** provides channel/video performance metrics, **Subscribe Button API** facilitates one-click channel subscriptions, and **Live Streaming API** allows scheduling and managing live broadcasts.
