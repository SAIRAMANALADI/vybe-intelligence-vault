# mkdocs/docs/user-guide/README.md at master · mkdocs/mkdocs · GitHub

## Summary

- **Installation**: MkDocs is installed via Python's package manager (`pip install mkdocs`), requiring Python 3.6+ and generating static HTML documentation from Markdown files.

- **Configuration**: Projects are configured via `mkdocs.yml`, defining site metadata, theme selection (`theme:`), navigation structure (`nav:`), and Markdown extensions for syntax processing.

- **Deployment**: Static site generation (`mkdocs build`) outputs files to `/site`, deployable to platforms like GitHub Pages, Netlify, or S3 via CLI (`mkdocs gh-deploy`).
