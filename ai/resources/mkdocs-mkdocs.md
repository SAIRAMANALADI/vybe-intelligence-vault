# mkdocs/docs/user-guide/README.md at master · mkdocs/mkdocs · GitHub

## Summary

- **Installation**: MkDocs is installed via Python's package manager (`pip install mkdocs`), requiring Python 3.6+ and a `mkdocs.yml` configuration file for project setup.

- **Documentation Workflow**: Content is written in Markdown (`.md` files) within a `docs` directory, with themes (e.g., `mkdocs`, `readthedocs`) configurable via `mkdocs.yml` for static site generation.

- **Deployment & CLI**: Built docs are deployed via `mkdocs gh-deploy` (GitHub Pages) or `mkdocs build` for local/remote hosting; CLI commands include `serve` (local preview) and `build` (HTML output).
