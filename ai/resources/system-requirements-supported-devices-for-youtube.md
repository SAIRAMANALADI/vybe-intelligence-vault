# System requirements & supported devices for YouTube - YouTube Help

## Summary

- **Browser & OS Requirements**: Latest versions of Chrome, Firefox, or Safari; Windows 7+, macOS 10.7+, or Ubuntu 10+; 1+ Mbps internet for premium content (5+ Mbps for 1080p, 20+ Mbps for 4K UHD).
- **Supported Devices**: Smart TVs (Samsung 2017+, LG 2016+, Roku, Sony/Sharp/Hisense select models), streaming devices (Fire TV, Apple TV 4K, Chromecast), game consoles (PS4/PS5, Xbox One/Series X|S), and mobile (Android 6.0+, iOS 12+).
- **Playback Limitations**: HD/UHD playback unavailable on most browsers except Safari; Primetime Channels restricted to select devices (e.g., no purchase on Apple TV/Xbox/Panasonic TVs).
