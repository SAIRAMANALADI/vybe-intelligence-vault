# Learn about the Android Device Configuration Service - Android Help

## Summary

- **Data Collection Scope**: Android Device Configuration Service collects device identifiers (IMEI, MEID, ESN, serial number, Android ID, MAC addresses), device attributes (hardware type, model, CPU, screen specs, memory, locale), OS/security versions (build fingerprint, Android version, security patch level), and network data (SIM details, IP address, connection timestamps, HTTP response codes).

- **Data Utilization**: Data is used for software/update validation (e.g., security patch levels), app compatibility (e.g., screen layout for Google Play), fraud detection (device identifiers for suspicious logins), and network optimization (anonymized connectivity metrics).

- **Data Retention & Access**: Data is retained only as the latest copy, replaced periodically; deletion occurs after account sign-out/inactivity. Users can export their data via Google Takeout (limited to account-associated devices).
