# Cap'n Proto: Installation

## Summary

- **Compiler & OS Requirements**: Cap’n Proto requires C++14-compatible compilers (GCC 7.0+, Clang 6.0+, or MSVC 2019+) and supports Android, Linux, macOS, Windows (MinGW-w64/Visual C++).

- **Installation Methods**: Supports Unix (tarball, package managers, Git), Windows (release ZIP, Git), and requires `autotools` for Git builds; Windows users need Visual Studio 2019+ or CMake for C++ integration.

- **Core Components**: Installs `capnp` tool, `libcapnp`, `libcapnpc`, and `libkj`; Windows builds include precompiled `.exe` tools and require `-I` flag for schema imports.
