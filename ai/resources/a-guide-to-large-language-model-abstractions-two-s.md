# A Guide to Large Language Model Abstractions - Two Sigma

## Summary

- **Semantic Types Framework**: Proposes a shift from traditional computer-centric data types (e.g., `int`, `float`) to human-centric semantic types (e.g., `Age`, `Temperature`) that encode domain-specific meaning, enabling richer data interpretation and interoperability.

- **Type Inference & Validation**: Introduces a system for inferring semantic types from raw data (e.g., detecting `DateOfBirth` from numeric timestamps) and validating them against domain constraints (e.g., `Age` must be positive), reducing manual annotation overhead.

- **Integration with Data Pipelines**: Demonstrates how semantic types can be embedded into data pipelines (e.g., Spark, Pandas) to automate transformations, improve query accuracy, and facilitate cross-domain data integration without sacrificing performance.
