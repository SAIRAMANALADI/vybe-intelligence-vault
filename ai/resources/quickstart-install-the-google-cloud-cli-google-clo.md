# Quickstart: Install the Google Cloud CLI | Google Cloud SDK | Google Cloud Documentation

## Summary

- **Prerequisites**: Requires Python 3.10–3.14 (Linux x86_64 package includes bundled interpreter); valid Google Cloud account with billing enabled and appropriate IAM roles (`roles/resourcemanager.projectCreator` for project creation).
- **Installation Methods**:
  - **Linux**: Download platform-specific `.tar.gz` (e.g., `google-cloud-cli-linux-x86_64.tar.gz`), extract, and run `./google-cloud-sdk/install.sh`; Debian/Ubuntu uses `apt-get install google-cloud-cli` after adding Google’s repo and GPG key.
  - **Red Hat/Fedora/CentOS**: Add YUM/DNF repo via `/etc/yum.repos.d/google-cloud-sdk.repo`, install `libxcrypt-compat.x86_64`, then `dnf install google-cloud-cli`.
- **Post-Installation**: Optional components (e.g., `google-cloud-cli-app-engine-java`) can be installed separately; downgrades via `apt-get install google-cloud-cli=VERSION` (last 10 versions supported).
