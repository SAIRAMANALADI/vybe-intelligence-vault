# James Shore: Continuous Integration on a Dollar a Day

## Summary

- **Low-cost CI setup**: Use an old development machine, automate builds/tests via scripts (e.g., batch files), and enforce team agreement to maintain a *always-buildable* codebase via frequent check-ins (2+ daily, ideally hourly).
- **Rubber chicken protocol**: Implement a physical token (rubber chicken) to serialize check-ins, ensuring no parallel commits disrupt integration; bell rings post-successful build to signal team-wide validation.
- **Key advantages over CruiseControl**: Eliminates broken builds via immediate feedback, enforces fast builds (<10 min), and integrates environmental checks (e.g., installer/package validation) to catch integration issues early.
