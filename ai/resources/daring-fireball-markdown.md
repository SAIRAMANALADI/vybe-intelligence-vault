# Daring Fireball: Markdown

## Summary

- **Markdown** is a lightweight markup language with a Perl-based tool for converting plain text to structurally valid HTML, designed for readability and inspired by plain text email conventions.
- **Requirements** include Perl 5.6.0+ and the `Digest::MD5` module; it supports integration with platforms like Movable Type, Blosxom, and BBEdit via plugin installation.
- **Configuration** allows switching between XHTML and HTML4 output via command-line flags (`--html4tags`) or Movable Type template tags (`MTMarkdownOptions`).
