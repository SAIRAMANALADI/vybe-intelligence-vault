# Set up Apple Watch for a family member - Apple Support

## Summary

- **Family Setup Requirements**: Requires Apple Watch Series 4/SE (cellular) with watchOS 7+, paired via iPhone 6s+ (iOS 14+); both accounts must have 2FA enabled and belong to a Family Sharing group.
- **Limited Feature Support**: Cellular plan optional but required for some features; unavailable features include ECG, Sleep, Medications, Shortcuts, and international roaming.
- **Managed Configuration**: Post-setup management via Apple Watch app (e.g., Screen Time, Ask to Buy, shared contacts); restricted to 13+ for HR notifications, 18+ for HRV/Fall Detection.
