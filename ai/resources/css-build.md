# css.Build

## Summary

- **Functionality**: `css.Build` bundles, transforms, and minifies CSS resources using `evanw/esbuild`, replacing `@import` statements recursively, applying vendor prefixes, and generating source maps.
- **Options**: Supports configuration via `externals`, `loaders`, `mainFields`, `minify`, `sourceMap`, `sourcesContent`, `target`, `targetPath`, and `vars` for granular control over bundling, minification, and browser compatibility.
- **Usage**: Processes CSS from `assets` directory or Node packages, with support for media queries, feature queries, and cascade layers in `@import` statements, and injects CSS variables via `hugo:vars`.
