# css.Build

## Summary

- **Functionality**: `css.Build` bundles, transforms, and minifies CSS resources using `evanw/esbuild`, replacing `@import` statements recursively, applying vendor prefixes, and generating source maps (external/inline/linked/none).
- **Options**: Supports fine-tuning via options like `externals`, `loaders`, `minify`, `sourceMap`, `target`, `vars`, and `targetPath` for advanced CSS processing and compatibility.
- **Usage**: Processes local assets or Node packages, embeds resources (e.g., images as `dataurl`), and integrates with Hugo’s asset pipeline for development/production workflows.
