# css.Build

## Summary

- **Functionality**: `css.Build` bundles, transforms, and minifies CSS resources using the `evanw/esbuild` backend, replacing `@import` statements, applying vendor prefixes, and generating source maps (v0.158.0+).
- **Options**: Supports advanced configurations like `externals`, `loaders`, `target`, `minify`, `sourceMap`, `vars` (for CSS variables), and `targetPath` to control bundling, compatibility, and output.
- **Usage**: Processes local assets or Node packages, resolving paths relative to `assets/` or `package.json` entry points, with conditional minification and fingerprinting for production.
