# css.Build

## Summary

- **Core Functionality**: `css.Build` bundles, transforms, and minifies CSS resources using [`evanw/esbuild`](https://github.com/evanw/esbuild), resolving `@import` statements, applying vendor prefixes, and generating source maps (e.g., `sourceMap: "linked"`).

- **Configuration Options**: Supports fine-grained control via options like `externals`, `loaders`, `minify`, `target`, `vars`, and `targetPath` to exclude files, define loaders, minify output, set browser targets, inject CSS variables, and customize output paths.

- **Usage Patterns**: References assets via bare/relative/root-relative paths or Node packages (e.g., `@import "bootstrap"`), with Hugo resolving paths from the `assets` directory or `package.json` entry points.
