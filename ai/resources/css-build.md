# css.Build

## Summary

- **Functionality**: `css.Build` bundles, transforms, and minifies CSS resources using `evanw/esbuild`, replacing `@import` statements recursively, applying vendor prefixes, and generating source maps (external, inline, or linked).
- **Options**: Supports fine-tuning via `externals`, `loaders`, `mainFields`, `minify`, `sourceMap`, `sourcesContent`, `target`, `targetPath`, and `vars` (for injecting CSS variables dynamically).
- **Usage**: Processes assets from `assets/` or Node packages, resolving paths relative to the current file or root; outputs bundled CSS to `publishDir` with optional fingerprinting and SRI hashing.
