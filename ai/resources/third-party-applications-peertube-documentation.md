# Third party applications | PeerTube documentation

## Summary

- **Browser Extensions**: PeerTube Companion (Firefox) redirects YouTube videos to PeerTube instances if available.
- **Mobile Clients**: Multiple Android (e.g., NewPipe, Grayjay) and iOS (Official PeerTube app) clients support PeerTube streaming and features like livestreaming.
- **CLI & Automation Tools**: Scripts like `Prismedia` (Python) automate video uploads to PeerTube/YouTube, while `YouTube2PeerTube` mirrors YouTube channels to PeerTube.
