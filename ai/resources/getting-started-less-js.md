# Getting started | Less.js

## Summary

- **LESS** is a backward-compatible CSS preprocessor that extends CSS with dynamic behavior like variables, mixins, nesting, operations, and functions while maintaining CSS syntax compatibility.
- **Core Features**: Supports variables (`@var: value`), mixins (`.mixin()`), nested rules (selector inheritance), arithmetic operations (`+`, `-`, `*`, `/`), color functions, and `@media` bubbling for responsive design.
- **Advanced Capabilities**: Includes namespaces (`#bundle.mixin()`), maps (`#map[key]`), lazy loading (variable scoping), and escaped strings (`~"value"`) for dynamic CSS generation.
