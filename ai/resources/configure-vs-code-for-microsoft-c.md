# Configure VS Code for Microsoft C++

## Summary

- **Microsoft C++ (MSVC) Toolset Integration**: VS Code supports Microsoft's MSVC compiler toolset for C++ development on Windows, requiring installation via Visual Studio Installer or standalone Build Tools for VS 2022, with verification via `cl.exe` in the Developer Command Prompt.

- **C/C++ Extension for VS Code**: The [ms-vscode.cpptools](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools) extension provides IntelliSense, debugging, and code navigation for C/C++ projects, essential for configuring build tasks and debugging sessions.

- **Debugging & Build Configuration**: VS Code supports customizable debugging via `launch.json` and build tasks via `tasks.json`, enabling step-through debugging, watch expressions, and C++-specific configurations for MSVC, GCC, or Clang toolchains.
