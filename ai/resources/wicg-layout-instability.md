# WICG/layout-instability

## Summary

- **Proposal Objective**: Defines a metric for *Layout Instability* to quantify unexpected shifts in DOM elements during page load or runtime, enabling performance monitoring of visual stability.
- **Core Metric**: Introduces *Impact Fraction* (IF) as a ratio of the area of shifted elements to the total viewport area, normalized over a time window to assess cumulative instability.
- **Implementation**: Specifies a JavaScript API (`layoutShift` events) to report instability scores, with thresholds for user-perceived disruption (e.g., CLS in Core Web Vitals).
