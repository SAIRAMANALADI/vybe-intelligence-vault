# microsoft/playwright

## Summary

- **Cross-Browser Automation**: Playwright provides a unified API to automate Chromium, Firefox, and WebKit, enabling consistent end-to-end testing across modern browsers.

- **Multi-Language Support**: Primarily written in TypeScript, it also supports JavaScript, Python, and .NET, facilitating integration into diverse tech stacks.

- **Advanced Features**: Supports headless/headed modes, network mocking, mobile emulation, and Electron app testing, with built-in auto-waiting and retry mechanisms for robust test execution.
