# unified · GitHub

## Summary

- **unified** is a modular ecosystem of 500+ open-source packages for parsing, transforming, and serializing structured content (ASTs) across formats like Markdown, HTML, XML, and JavaScript.

- The core [`unified`](https://github.com/unifiedjs/unified) package provides the foundational API for inspecting and manipulating content via plugin-based pipelines.

- Supports cross-format interoperability and includes governance, contribution guidelines, and sponsorship mechanisms via [unifiedjs.com](https://unifiedjs.com) and related repositories.
