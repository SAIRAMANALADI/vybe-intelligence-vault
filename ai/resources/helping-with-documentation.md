# Helping with documentation

## Summary

- Python's documentation relies on community contributions for maintenance, including writing, editing, and proofreading, with detailed guidelines available in the [Documenting Python](https://devguide.python.org/documentation/start-documenting/#documenting) section.
- Documentation issues (typos, unclear content, missing docs) are tracked on GitHub, where contributors can claim tasks, submit PRs, and follow the [pull request workflow](https://devguide.python.org/getting-started/pull-request-lifecycle/#pullrequest).
- Proofreading involves reviewing sections for errors (e.g., outdated Python 3 references), filing granular issues, and optionally joining the [@python/proofreaders](https://github.com/orgs/python/teams/proofreaders) team for technical writing support.
