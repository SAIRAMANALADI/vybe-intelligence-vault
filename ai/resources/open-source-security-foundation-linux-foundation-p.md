# Open Source Security Foundation – Linux Foundation Projects

## Summary

- **OpenSSF Technical Initiatives**: Projects like **GUAC** (Graphical Understanding of Artifact Composition) provide directed insights into software supply chain security, while **SLSA** (Supply-chain Levels for Software Artifacts) enforces artifact integrity across supply chains.

- **Working Groups & Policy Focus**: Active groups include **AI/ML Security** (secure AI usage and AI-driven security improvements), **Global Cyber Policy** (addressing international regulations like the EU Cyber Resilience Act), and **Vulnerability Disclosures** (advancing OSS vulnerability reporting standards).

- **Community & Training Programs**: OpenSSF offers **free secure coding training** via certificate programs, **security guides** for OSS projects, and collaborative platforms (Slack, GitHub) to engage developers and security engineers in securing open source ecosystems.
