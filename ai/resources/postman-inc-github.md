# Postman Inc. · GitHub

## Summary

- **Postman's Open Philosophy**: Emphasizes transparency with roadmaps, issue tracking, and support for major API specifications (e.g., OpenAPI, GraphQL), driven by feedback from a 17M+ developer community.

- **Core Open-Source Projects**:
  - **Newman**: CLI tool for executing and testing Postman Collections.
  - **Postman Runtime**: Core engine for executing API requests, scripts, and tests.
  - **Code Generators**: Converts Postman collections into executable code across 20+ languages.

- **Contribution & Resources**:
  - Community-driven development via GitHub (feature requests/issues).
  - Documentation, tutorials, and release notes available via [learning.postman.com](https://learning.postman.com/) and [GitHub](https://github.com/postmanlabs).
