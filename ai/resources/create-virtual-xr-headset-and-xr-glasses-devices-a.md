# Create virtual XR headset and XR glasses devices | Android XR for Jetpack XR SDK | Android Developers

## Summary

- **Android XR SDK Developer Preview 4** introduces emulator support for testing XR apps on **XR headsets** (fully-immersive) and **XR glasses** (optical passthrough with wide FOV) via specialized Android Virtual Devices (AVDs) in Android Studio.

- **System requirements** mandate macOS 13.3+ (Apple Silicon M1+) or Windows 11+ (Intel 9th-gen+/AMD Ryzen 1000+/NVIDIA GeForce 10+/AMD Radeon RX 5000+), with **16GB+ RAM**, **8GB+ VRAM**, and **VMX CPU extensions enabled** (Windows).

- **AVD creation** requires Android Studio Canary build, with **Preview API system images** for XR glasses and configurable images for XR headsets, initiated via **Device Manager > Add Virtual Device > XR**.
