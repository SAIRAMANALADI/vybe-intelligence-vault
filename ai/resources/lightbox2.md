# Lightbox2

## Summary

- **Lightbox2** is a jQuery-based modal image viewer requiring jQuery 1.7+ (slim build unsupported) with dependencies on `lightbox.css` and image assets from `/dist/images`.
- **Core Features**: Supports single images and sets via `data-lightbox` attributes, with optional captions (`data-title`) and alt text (`data-alt`); includes accessibility support (`role="dialog"`, `aria-modal`, focus trapping).
- **API & Customization**: Provides programmatic control via `open()`, `close()`, `next()`, `prev()`, and `destroy()` methods; configurable via CSS custom properties and JavaScript options (e.g., `fadeDuration`, `wrapAround`, `maxWidth`).
