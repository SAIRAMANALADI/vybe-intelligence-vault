# Welcome to Python.org

## Summary

- Python 3 supports **arithmetic operations** (`+`, `-`, `*`, `/`, `//`, `**`) with intuitive syntax, including true division (`/`) and floor division (`//`), as well as **list comprehensions** for concise transformations (e.g., `[fruit.upper() for fruit in fruits]`).

- Python provides **built-in compound data types** like lists (indexable, sliceable, and manipulable) and supports **control flow statements** (`if`, `for`, `while`, `range`), with functions enabling optional, keyword, and arbitrary arguments for extensible programming.

- Python’s **standard library** spans domains including **AI/ML** (PyTorch, TensorFlow), **scientific computing** (SciPy, Pandas), **web development** (Django, FastAPI), and **system administration** (Ansible, Salt), with the **Python Software Foundation (PSF)** promoting its growth and community diversity.
