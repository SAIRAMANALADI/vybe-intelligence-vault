# Mobile Application Security Assessment | App Defense Alliance

## Summary

- **MASA Transition**: MASA is migrating to the new [App Defense Alliance (ADA)](https://www.appdefensealliance.org/) platform; interim certification requires adherence to the [Mobile App Profile specs](https://github.com/appdefensealliance/ASA-WG/blob/v1.0/Mobile%20App%20Profile/Mobile%20App%20Specification.md).
- **OWASP MASVS/MASTG Compliance**: Apps undergo independent validation against [OWASP MASVS Level 1](https://github.com/appdefensealliance-dev/ASA/blob/main/MobileAppSecurityAssessment/MobileSecurityGuide.md) criteria via Google Authorized Labs, with results displayed in Google Play’s Data Safety section.
- **Scope & Limitations**: MASA provides transparency into security architecture but does not guarantee complete safety; developers retain full responsibility for accurate Data Safety declarations.
