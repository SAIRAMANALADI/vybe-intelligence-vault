# get-source-code

## Summary

- **Source Access**: Launchpad provides direct access to project source code via `bzr` (Bazaar) or `git` repositories, with public/private access controls based on project permissions.

- **Branch Workflow**: Developers clone branches locally (`bzr branch lp:project-name`), modify files, and push changes back to Launchpad using `bzr push` (or `git` equivalents) after authentication.

- **Build Dependencies**: Projects often require `build-essential` and language-specific tools (e.g., `python3-dev`, `libfoo-dev`) resolved via `apt` or `pip`, with build instructions typically in `debian/control` or `setup.py`.
