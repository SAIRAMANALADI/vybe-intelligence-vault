# Supabase · GitHub

## Summary

- **Open-source Postgres platform**: Supabase provides a dedicated Postgres database with extensions, real-time capabilities via WebSockets, and RESTful APIs for database management (e.g., `postgres-meta`).

- **Multi-language SDKs**: Offers client libraries in TypeScript, Swift, Dart, Go, and Rust for database queries, real-time subscriptions, file handling, and RPC function invocation.

- **Infrastructure tools**: Includes a CLI for migrations/local deployment, Terraform provider for IaC, and Rust-based CDC pipelines (`etl`) for real-time data streaming.
