# Supabase · GitHub

## Summary

- Supabase provides an open-source **Postgres-based development platform** with realtime capabilities via WebSockets, supporting web, mobile, and AI applications.
- Core components include: unmodified Postgres with extensions (`postgres`), realtime event broadcasting (`realtime`), and a RESTful Postgres management API (`postgres-meta`).
- Client libraries are available (e.g., `supabase-js`, `supabase-swift`, `supabase-flutter`) for database queries, authentication, and edge function invocation.
