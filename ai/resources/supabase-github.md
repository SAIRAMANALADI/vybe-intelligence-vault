# Supabase · GitHub

## Summary

- **Postgres-Centric Platform**: Supabase provides a dedicated PostgreSQL database with extensions, enabling real-time capabilities via WebSockets (Elixir-based `realtime` service) and RESTful management tools (`postgres-meta`).

- **Open-Source Ecosystem**: Core components (e.g., `supabase-js`, `auth`, `postgres`) are open-source under permissive licenses (Apache-2.0/MIT), with active development in TypeScript, Go, and Rust for SDKs, authentication, and CDC pipelines.

- **Developer Tooling**: Includes a CLI for migrations, local development, and edge function deployment, alongside a database package registry (`dbdev`) and real-time ETL pipelines (`etl`) for streaming Postgres changes.
