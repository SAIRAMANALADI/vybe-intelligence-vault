# Get started with Sourcetree | Sourcetree | Atlassian Documentation

## Summary

- **SourceTree** is a GUI client for **Git** and **Mercurial** version control systems, simplifying repository management via a visual interface.

- **Core workflows** include **cloning, committing, pushing, pulling, branching, and merging**, with dedicated guides for Git (e.g., `git pull`, `git commit -m`) and Mercurial (e.g., `hg push`, `hg merge`).

- **Interface components** (e.g., file status panels, commit graphs, diff viewers) enable **real-time tracking of changes**, **staging hunks**, and **resolving conflicts** without CLI commands.
