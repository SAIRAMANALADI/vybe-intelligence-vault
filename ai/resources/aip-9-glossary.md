# AIP-9: Glossary

## Summary

- **API Glossary (AIP-9)**: Defines standardized terminology for Google APIs, including `API`, `API backend`, `API consumer`, `API frontend`, `API method`, `API producer`, `API service`, and `API service endpoint` to ensure consistency across AIPs.
- **Declarative Clients**: Describes Infrastructure-as-Code (IaC) clients (e.g., Terraform) that manage API resources by comparing desired state with server-side attributes, abstracting imperative actions like create/update/delete.
- **Network API vs. Google API**: Distinguishes `Network API` (cross-computer, HTTP-based APIs) from `Google API` (hosted on `googleapis.com`), excluding client libraries and SDKs.
