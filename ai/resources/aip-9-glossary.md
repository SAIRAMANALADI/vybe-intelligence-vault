# AIP-9: Glossary

## Summary

- **API Terminology Standardization**: Defines consistent terminology for Google API Improvement Proposals (AIPs), including `API`, `API backend`, `API consumer`, `API producer`, `API service`, and `API method` to ensure uniformity across documentation and implementations.

- **API Service Architecture**: Distinguishes between `API frontend` (handles load balancing/authentication) and `API backend` (implements business logic), which may run independently or co-located within a single process.

- **Client and User Definitions**: Differentiates between `Client` (programs/tools interacting with APIs) and `User` (human end-users), while introducing `Declarative Clients` (e.g., Terraform) for Infrastructure-as-Code (IaC) operations.
