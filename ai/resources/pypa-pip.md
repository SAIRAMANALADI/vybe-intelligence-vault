# pypa/pip

## Summary

- **Core Functionality**: `pip` is the default package manager for Python, enabling installation, upgrade, and removal of Python packages from PyPI and other repositories via CLI commands (e.g., `pip install`, `pip uninstall`).

- **Dependency Resolution**: Uses a SAT solver (via `pip`'s resolver or `resolvelib`) to handle complex dependency graphs, ensuring compatible package versions while avoiding conflicts.

- **Wheel & Egg Support**: Supports installation from both source distributions (`.tar.gz`) and pre-built wheels (`.whl`), optimizing performance by skipping compilation when possible.
