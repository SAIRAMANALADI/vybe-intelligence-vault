# pypa/pip

## Summary

- **Primary Function**: `pip` is the default package installer for Python, enabling installation, management, and removal of Python packages from PyPI and other repositories via CLI commands (e.g., `pip install`, `pip uninstall`).

- **Core Architecture**: Written in Python, `pip` relies on `setuptools` for package metadata parsing and `wheel` for binary distribution support, with dependency resolution handled by `pkg_resources` and `packaging` libraries.

- **Key Features**: Supports virtual environments, editable installs (`pip install -e`), constraint files, and PEP 517/518 for modern build system integration, while maintaining backward compatibility with legacy `setup.py`-based packages.
