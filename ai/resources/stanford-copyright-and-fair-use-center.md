# Stanford Copyright and Fair Use Center

## Summary

- **Fair Use Framework for OER**: Provides a structured, four-factor analysis (purpose, nature, amount, effect) to guide educators in legally incorporating third-party copyrighted materials into OER without permission, emphasizing transformative use cases like criticism, commentary, or education.

- **Key Best Practices**: Recommends prioritizing transformative uses (e.g., adapting materials for pedagogical goals), minimizing risk by using only necessary portions, and documenting fair use decisions to demonstrate compliance with copyright law.

- **Educator-Specific Guidance**: Addresses common OER scenarios (e.g., remixing, adapting, or sharing materials) while clarifying that nonprofit educational purposes and open licensing (e.g., CC BY) strengthen fair use claims, but commercial use may require additional scrutiny.
