# Support - Documentation

## Summary

- **Status Monitoring**: Real-time service status for Maven Central and OSSRH is available via [status.maven.org](https://status.maven.org/), [Sonatype Ops Twitter](https://twitter.com/sonatype_ops), and the [Advanced Guide](https://central.sonatype.org/central-status/) for infrastructure disruptions.

- **Producer Support**: Contact [central-support@sonatype.com](mailto:central-support@sonatype.com) for publishing issues, namespace registration errors, credential resets, or token revocation (PGP keys handled via signed file verification).

- **Consumer Support**: Central support assists with access failures, content mismatches, or search issues via [central-support@sonatype.com](mailto:central-support@sonatype.com), excluding third-party sites like mvnrepository.com.
