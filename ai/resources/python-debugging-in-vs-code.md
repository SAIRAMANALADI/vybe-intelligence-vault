# Python debugging in VS Code

## Summary

- VS Code's Python extension integrates the **Python Debugger extension** (debugpy) for debugging Python applications, supporting scripts, web apps, and remote processes with core features like breakpoints and variable inspection.

- Debug configurations are defined in `launch.json` within a `.vscode` folder, initialized via the **Run** view or command palette, with predefined templates (e.g., **Python File**) for common debugging scenarios.

- Python-specific debugging includes **remote debugging**, **app-type-specific configurations** (e.g., Flask/Django), and **troubleshooting** via VS Code’s debugging UI and debugpy’s `launch.json` properties.
