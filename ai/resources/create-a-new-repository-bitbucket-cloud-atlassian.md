# Create a new repository | Bitbucket Cloud | Atlassian Support

## Summary

- **Repository Ownership & Access**: A Bitbucket repository can belong to a user account or workspace, with deletion permissions restricted to the owner or workspace admin; access levels (private/public) determine visibility and are set during creation.

- **Repository Limits & Structure**: Each repository has a 2 GB size limit (recommended ≤1 GB), and a project may consist of multiple repositories across accounts or a single repository.

- **Creation & Initialization**: Repositories are created empty via Bitbucket’s UI, with options to include a README; the owner can later clone it locally for updates and collaboration.
