# MediaWiki

## Summary

- **Core Functionality**: MediaWiki is an open-source, PHP-based wiki platform powering Wikipedia and tens of thousands of other websites, enabling collaborative knowledge management with multilingual support, extensibility via extensions, and version-controlled page history.

- **Technical Architecture**: Supports MySQL/MariaDB, PostgreSQL, and SQLite databases, with a modular extension system for custom functionality (e.g., semantic annotations, authentication integrations) and a caching layer (Memcached/Redis) for performance optimization.

- **Deployment & Maintenance**: Provides automated update pipelines (e.g., 1.45.x releases), security patches, and hosting options; includes developer tools (API, CLI scripts) for debugging, localization, and integration with Wikimedia’s ecosystem (e.g., Wikidata, Abstract Wikipedia).
