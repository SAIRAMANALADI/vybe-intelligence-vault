# MediaWiki

## Summary

- **MediaWiki** is an open-source, PHP-based wiki platform used by tens of thousands of websites, including Wikipedia, supporting multilingual localization, extensibility via extensions, and version control via `git`.

- **Core features** include page versioning, namespace management, user access control (via `User::getRights()`), and a parser framework for wikitext-to-HTML conversion (handled by `Parser.php`).

- **Deployment** requires a LAMP/LEMP stack with MySQL/MariaDB, supports caching via Redis/Memcached, and provides API endpoints (`api.php`) for programmatic access and automation.
