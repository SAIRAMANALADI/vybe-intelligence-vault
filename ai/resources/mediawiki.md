# MediaWiki

## Summary

- **MediaWiki** is a **free, open-source wiki software platform** written in PHP, used by tens of thousands of websites, including Wikipedia, supporting multilingual localization, extensibility via extensions, and customization.

- **Core features** include **collaborative editing, version control, permission management, and API-driven integration**, with active community support for troubleshooting, development, and contributions.

- **Deployment options** range from **self-hosted installations** (with dependencies like MySQL/MariaDB, PostgreSQL, or SQLite) to **managed hosting services**, with regular maintenance/security releases (e.g., 1.45.x branch) and developer documentation for customization.
