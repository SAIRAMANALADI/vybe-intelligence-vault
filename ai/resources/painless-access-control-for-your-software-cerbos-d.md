# Painless access control for your software :: Cerbos // Documentation

## Summary

- **Policy-as-Code**: Cerbos enables context-aware access control via YAML-based policies, decoupled from application code, deployable via GitOps, and evaluated dynamically via API calls to the Policy Decision Point (PDP).

- **Language-Agnostic Authorization**: Provides a stateless, containerized PDP with REST/gRPC endpoints, supporting x86-64/ARM64, GitOps workflows, and sidecar deployment for microservices, ensuring consistent policy enforcement across polyglot environments.

- **Performance & Observability**: Optimized for low-latency gRPC, stateless design, and comprehensive integrations (metrics, tracing), with policy updates applied without restarts and audit trails maintained via version-controlled YAML policies.
