# random (latest version) | IBM Quantum Documentation

## Summary

- **`random_circuit`**: Generates a random quantum circuit with configurable parameters (`num_qubits`, `depth`, `max_operands`, `measure`, `conditional`, `reset`, `seed`, `num_operand_distribution`), selecting gates from `qiskit.circuit.library.standard_gates` and supporting variable-width operations (1-4 qubits).

- **`random_circuit_from_graph`**: Constructs a random circuit respecting a specified interaction graph (qubit coupling constraints), enforcing minimum 2Q gate counts per edge (`min_2q_gate_per_edge`) and allowing weighted edge selection; supports 1Q/2Q gate insertion with probabilistic conditional/reset operations.

- **`random_clifford_circuit`**: Produces a pseudo-random Clifford circuit with exact gate count (`num_gates`) using Clifford gates (e.g., Pauli, CNOT, T), sampling from a user-defined subset or the full Clifford gate set in `qiskit.circuit.library.standard_gates`.
