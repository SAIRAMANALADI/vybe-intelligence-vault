# About PageSpeed Insights | Google for Developers

## Summary

- **PageSpeed Insights (PSI)** evaluates web page performance using **lab data (Lighthouse)** for controlled diagnostics and **real-world data (CrUX)** for user experience metrics (FCP, LCP, CLS, INP, TTFB), with thresholds categorizing performance as Good/Needs Improvement/Poor.
- **Core Web Vitals (LCP, CLS, INP)** are assessed at the 75th percentile to ensure robustness across device/network conditions, with aggregation passing only if all metrics meet "Good" thresholds.
- **Lab diagnostics** score Performance, Accessibility, Best Practices, and SEO via Lighthouse (90+ = good), while field data relies on CrUX (28-day trailing window) and may lack granularity for new/low-traffic pages.
