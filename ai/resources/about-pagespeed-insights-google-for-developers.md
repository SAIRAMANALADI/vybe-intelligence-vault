# About PageSpeed Insights | Google for Developers

## Summary

- **PageSpeed Insights (PSI)** evaluates web page performance using **lab data (Lighthouse)** and **real-world data (CrUX)**, measuring metrics like FCP, LCP, CLS, INP, and TTFB, with categorization into *Good/Needs Improvement/Poor* based on predefined thresholds.

- **Core Web Vitals (LCP, CLS, INP)** are aggregated at page/origin levels, requiring 75th percentile values to meet *Good* thresholds for passing assessment; insufficient data for any metric invalidates the evaluation.

- **Lab diagnostics** via Lighthouse simulate mid-tier mobile (4G) and desktop (wired) conditions, scoring Performance/Accessibility/SEO/Best Practices (90+ = good), while field data (CrUX) updates daily with 28-day trailing metrics, contrasting lab’s controlled environment with real-world variability.
