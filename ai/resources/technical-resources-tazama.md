# Technical Resources - Tazama

## Summary

- **Source Code & Documentation**: All Tazama source code and documentation are hosted on [GitHub](https://github.com/tazama-lf), including the [Full-Stack-Docker-Tazama repository](https://github.com/tazama-lf/Full-Stack-Docker-Tazama) for containerized deployment.

- **Deployment Access**: Public repositories allow basic containerized deployment with pre-compiled rule processors, while full multi-typology configurations with private rule processors require "member" access due to fraud detection mechanism protection.

- **Community & Support**: Tazama provides Slack for technical discussions ([slack.tazama.org](https://slack.tazama.org/)), with private rule processors restricted to vetted organizations to prevent reverse engineering.
