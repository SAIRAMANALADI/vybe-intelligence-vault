# snapd in Launchpad

## Summary

- **snapd** is a system daemon written primarily in **Go** (with some C components) that manages **snap packages**, enabling universal Linux application distribution across cloud, server, desktop, and IoT environments.

- It provides core functionality for **installing, configuring, refreshing, and removing** snaps, with support for cross-distribution compatibility and security isolation via snap confinement mechanisms.

- The project is licensed under **GNU GPL v3**, maintained by the **Snappy Developers** team, and hosted on **Launchpad** with active development tracked in the `trunk` series.
