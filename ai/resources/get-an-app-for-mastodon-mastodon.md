# Get an app for Mastodon - Mastodon

## Summary

- **Official Mastodon mobile apps** are available for iOS (`org.joinmastodon.android`) and Android, providing native client support for the platform.
- **Mastodon’s open API** enables third-party app development, with well-documented endpoints for client-server interactions (see [docs.joinmastodon.org/client/intro](https://docs.joinmastodon.org/client/intro/)).
- **Progressive Web App (PWA) support** allows desktop/mobile browser access with optional home screen installation and push notifications.
