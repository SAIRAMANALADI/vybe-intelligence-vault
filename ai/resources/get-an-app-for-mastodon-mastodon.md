# Get an app for Mastodon - Mastodon

## Summary

- **Official Mastodon apps** are available for iOS (`org.joinmastodon.android`) and Android, providing native mobile experiences with features like reblogging and polls.
- **Mastodon's API** is open-source, well-documented, and supports third-party app development via RESTful endpoints (e.g., `docs.joinmastodon.org/client/intro/`).
- **Third-party clients** span platforms (Android/iOS/Web), including open-source options (e.g., Tusky, Fedilab) and paid apps (e.g., Ivory, Mona), with progressive web app support for browser-based access.
