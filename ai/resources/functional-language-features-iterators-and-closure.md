# Functional Language Features: Iterators and Closures - The Rust Programming Language

## Summary

- **Closures**: Rust supports first-class functions (closures) that can be stored in variables, passed as arguments, or returned from functions, enabling functional-style programming patterns.

- **Iterators**: Rust provides iterator traits (`Iterator`, `IntoIterator`) and adaptors (`map`, `filter`, `fold`) for lazy, chainable sequence processing with zero-cost abstractions.

- **Performance**: Closures and iterators in Rust are optimized via LLVM, avoiding runtime overhead while maintaining expressiveness and idiomatic code.
