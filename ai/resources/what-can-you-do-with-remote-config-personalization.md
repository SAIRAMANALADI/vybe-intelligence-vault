# What can you do with Remote Config personalization? | Firebase Remote Config

## Summary

- **Remote Config Personalization** optimizes Firebase Analytics events with meaningful parameters to tailor app experiences, requiring ≥10,000 users and ≥1,000 weekly triggering events for optimal performance.
- **Ad Revenue Optimization** uses `ad_impression` events with `currency`/`value` parameters to dynamically select mini-games (e.g., `tictactoe`, `word_scramble`) via Remote Config parameter `minigame`, maximizing revenue while monitoring user engagement.
- **Use Cases** include ad placement optimization (`ad_placement` values: `top-left`, `bottom`, etc.), ad frequency tuning (`ad_display_freq_in_min` values: `2`, `10`, `50`), and difficulty selection (`level_difficulty` values: `easy` to `impossible`) with objectives like `user_engagement` or `in_app_purchase`.
