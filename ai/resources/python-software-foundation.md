# Python Software Foundation

## Summary

- **Grants Program**: In 2024, the PSF allocated **$655,000 USD** to **257 grantees** across **61 countries**, supporting Python-related projects, education, and community initiatives.

- **Infrastructure & Services**: Maintains critical Python ecosystem infrastructure including **python.org**, **PyPI**, **Python Documentation**, and security protocols (e.g., mitigated API authentication bypass for download metadata).

- **PyCon US & Community Support**: Produces **PyCon US**, the largest annual Python conference, with **$384,000 USD in travel grants** awarded to **254 attendees** in 2025, alongside strategic planning (e.g., **PSF Strategic Plan 2026**) and diversity initiatives.
