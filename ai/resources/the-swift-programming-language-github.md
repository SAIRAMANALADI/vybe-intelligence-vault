# The Swift Programming Language · GitHub

## Summary

- **Language Overview**: Swift is a statically-typed, compiled programming language designed for performance and safety, supporting multi-paradigm (OOP, functional, protocol-oriented) with modern syntax.
- **Cross-Platform Runtime**: Compiles to native code on macOS, Linux, Windows, and embedded systems, with LLVM-based toolchain for optimization and ABI stability.
- **Open-Source Ecosystem**: Hosted on GitHub with core components (compiler, Swift Package Manager) under Apache 2.0 license; contributions via evolution proposals, bug reports, or code patches.
