# How to contact Customer Support – Support | DataCamp

## Summary

- **Authentication-based support**: Existing DataCamp users can access 24/7 support via in-app login (`support=true` parameter in `app.datacamp.com`).
- **Non-user support**: Unregistered users can request help via [support.datacamp.com](https://support.datacamp.com/hc/en-us/articles/360021185634-How-to-contact-Customer-Support).
- **Specialized contact paths**: Sales inquiries via [business demo page](https://www.datacamp.com/business/demo), media queries via `media@datacamp.com`, and instructor support via [instructor-support.datacamp.com](https://instructor-support.datacamp.com/en/).
