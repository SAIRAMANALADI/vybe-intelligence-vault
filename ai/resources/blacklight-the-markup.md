# Blacklight – The Markup

## Summary

- **Privacy Scanning Tool**: Blacklight scans websites in real-time to detect user-tracking technologies, including ad trackers, third-party cookies, session-monitoring scripts, keystroke logging, and data sharing with major platforms (Facebook, TikTok, Twitter/X, Google Analytics).

- **Detection Mechanisms**: Uses advanced techniques to identify tracking that evades cookie blockers and browser fingerprinting, providing granular insights into invisible browser identification and cross-site tracking.

- **Open-Source CLI Tool**: Blacklight Query enables batch scanning of websites for privacy-invasive technologies via a command-line interface, facilitating large-scale audits of user-tracking practices.
