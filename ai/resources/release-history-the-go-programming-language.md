# Release History - The Go Programming Language

## Summary

- **Go 1.26.0** (Feb 2026) introduced major updates with subsequent minor revisions (`1.26.1`–`1.26.4`) focusing on security patches (e.g., `crypto/x509`, `html/template`, `net/url`) and bug fixes across compiler, runtime, and core packages (`go` command, `os`, `reflect`).

- **Go 1.25.0** (Aug 2025) and its 11 minor revisions (`1.25.1`–`1.25.11`) included critical security fixes (e.g., `crypto/tls`, `net/http`, `crypto/x509`) and performance/bug corrections in linker, runtime, and standard library components (`archive/tar`, `go/types`, `syscall`).

- **Go 1.24.0** (Feb 2025) and its 13 minor revisions (`1.24.1`–`1.24.13`) addressed security vulnerabilities (e.g., `crypto/x509`, `net/http`, `os`) and resolved issues in compiler, runtime, and toolchain (`go` command, `debug/pe`, `sync/atomic`).
