# Open Hugo Sponsorship Slot

## Summary

- **Sponsorship Benefits**: Up to 3 corporate sponsors receive logo banners with links on [gohugo.io](https://gohugo.io) homepage/footer and [themes.gohugo.io](https://themes.gohugo.io), plus GitHub repository banner in [Hugo’s main repo](https://github.com/gohugoio/hugo#banner-sponsors).

- **Open Slot**: Only 1 sponsorship slot remains available for corporate entities.

- **Contact**: Interested parties should email [bjorn.erik.pedersen@gmail.com](mailto:bjorn.erik.pedersen@gmail.com) for inquiries.
