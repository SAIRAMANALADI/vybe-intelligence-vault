# Install Docker Engine | Docker Docs

## Summary

- Docker Engine (CE) is installable on multiple Linux platforms (x86_64, arm64, arm, ppc64le, s390x) via distribution-specific packages (e.g., CentOS, Debian, Ubuntu) or static binaries for unsupported distributions.
- Release channels for Docker Engine include **stable** (production-ready) and **test** (pre-release, experimental features with potential breaking changes).
- Commercial use of Docker Engine in enterprises (>250 employees or >$10M revenue) requires a paid Docker subscription, while the open-source version is licensed under Apache 2.0.
