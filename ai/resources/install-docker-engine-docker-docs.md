# Install Docker Engine | Docker Docs

## Summary

- Docker Engine (CE) is installable on multiple platforms (x86_64, arm64, armv7, ppc64le, s390x) with OS-specific guides for CentOS, Debian, Fedora, RHEL, Ubuntu, and Raspberry Pi OS, alongside statically linked binaries for manual installation.
- Docker Engine offers **stable** (production-ready) and **test** (pre-release) update channels, with backward-compatible patch releases but experimental features in the test channel.
- Commercial use of Docker Engine via Docker Desktop requires a paid subscription for enterprises exceeding 250 employees or $10M revenue; otherwise, it is licensed under Apache 2.0. Security vulnerabilities must be reported privately to `security@docker.com`.
