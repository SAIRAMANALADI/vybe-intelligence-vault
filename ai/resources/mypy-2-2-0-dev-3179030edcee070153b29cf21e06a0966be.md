# mypy 2.2.0+dev.3179030edcee070153b29cf21e06a0966beb088c documentation

## Summary

- **Static type checking**: Mypy is a static type checker for Python that enforces type correctness via PEP 484 type hints without requiring code execution, enabling early bug detection in variable/function usage.

- **Gradual typing & type system**: Supports gradual adoption of static typing with features like type inference, generics, union types, structural subtyping (protocols), and callable types, while maintaining compatibility with dynamic typing.

- **Advanced type constructs**: Implements complex type systems including `TypedDict`, `Literal` types, `NoReturn`, `NewType`, function overloading, and variance control for generic types, with runtime-safe handling via stub files and forward references.
