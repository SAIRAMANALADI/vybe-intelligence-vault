# gitiles - Git at Google

## Summary

- **Gitiles Overview**: A lightweight, JGit-based Git repository browser with no access controls, write support, or JavaScript dependencies; renders Markdown files (`*.md`) into HTML for documentation.
- **Configuration & Dependencies**: Uses a `gitiles.config` file for settings; recent updates include Jetty 12.1.10 (via `jetty-ee8` adapter), JGit (`c46df0c50`), Bazel 9.1.0, and protobuf-java 4.33.4.
- **Development & Bug Tracking**: Contributions follow the [Developer Guide](https://gerrit.googlesource.com/gitiles/+/HEAD/Documentation/developer-guide.md); bugs are tracked via [Gerrit’s issue tracker](https://issues.gerritcodereview.com/issues?q=status:open%20componentid:1370019).
