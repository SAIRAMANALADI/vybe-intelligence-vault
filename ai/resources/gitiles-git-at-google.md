# gitiles - Git at Google

## Summary

- **Gitiles**: A lightweight, read-only Git repository browser built on JGit, with no access controls, write access, or JavaScript dependencies, focusing on simplicity and Markdown rendering for documentation.

- **Configuration & Extensibility**: Uses a Git-style `gitiles.config` file for settings; supports Markdown rendering via `*.md` files and provides developer/contributor documentation for customization.

- **Dependencies & Updates**: Recent commits show updates to Jetty (12.1.10), JGit, Bazel (9.1.0), protobuf-java (4.33.4), and migration to Bazel modules, indicating active maintenance and dependency management.
