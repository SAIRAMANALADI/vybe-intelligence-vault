# gitiles - Git at Google

## Summary

- **Gitiles** is a lightweight, read-only Git repository browser built on **JGit**, with no built-in access controls or write functionality, prioritizing simplicity over advanced features.
- Supports automatic rendering of **Markdown (`*.md`)** files into HTML for documentation, with configuration managed via a **`gitiles.config`** file.
- Recent updates include **Jetty 12.1.10** (with `javax.servlet` preservation), **Bazel 9.1.0** migration, and **JGit/protobuf-java** version bumps for compatibility with Gerrit.
