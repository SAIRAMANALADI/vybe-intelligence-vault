# gitiles - Git at Google

## Summary

- **Lightweight Git repository browser** built on JGit with minimal dependencies, no access controls, and no JavaScript, prioritizing simplicity over feature complexity.

- **Markdown rendering support** for `*.md` files, configurable via `markdown.frontmatter` option to strip YAML front matter, with documentation available in the [Markdown docs](https://gerrit.googlesource.com/gitiles/+/HEAD/Documentation/markdown.md).

- **Configurable via `gitiles.config`** (git-style configuration file) and extensible through a [Developer Guide](https://gerrit.googlesource.com/gitiles/+/HEAD/Documentation/developer-guide.md), with bugs tracked in [Gerrit’s issue tracker](https://issues.gerritcodereview.com/issues?q=status:open%20componentid:1370019&s=created_time:desc).
