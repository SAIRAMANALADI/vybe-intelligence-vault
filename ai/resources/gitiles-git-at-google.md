# gitiles - Git at Google

## Summary

- **Gitiles** is a lightweight, JGit-based repository browser for Git with no write access, access controls, or JavaScript dependencies, prioritizing simplicity.
- **Markdown rendering** is natively supported via `*.md` files, with configuration options like `markdown.frontmatter` for YAML front matter stripping.
- **Configuration** is managed via a `gitiles.config` file, and development/contributions follow the [Developer Guide](https://gerrit.googlesource.com/gitiles/+/HEAD/Documentation/developer-guide.md).
