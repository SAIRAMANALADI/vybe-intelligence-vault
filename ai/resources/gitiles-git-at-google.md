# gitiles - Git at Google

## Summary

- **Gitiles** is a lightweight, read-only Git repository browser built on **JGit**, prioritizing simplicity with no access controls, write operations, or JavaScript dependencies.
- Supports **Markdown rendering** (`*.md` → HTML) and is configurable via a **`gitiles.config`** file, adhering to Git-style syntax.
- **Dependencies** are managed via **Bazel** (e.g., v9.1.0) and **Jetty** (e1e8 adapter), with recent updates to **JGit** (e.g., `c89601f`).
