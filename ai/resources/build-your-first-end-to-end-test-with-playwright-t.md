# Build your first end-to-end test with Playwright - Training | Microsoft Learn

## Summary

- **Playwright Testing Framework**: Enables end-to-end testing of web applications with cross-browser support (Chromium, Firefox, WebKit), auto-waiting, and network mocking capabilities.

- **VS Code Integration**: Provides debugging, test execution, and test recording directly within Visual Studio Code via the Playwright extension.

- **Project Structure**: Tests are configured via `playwright.config.ts`, written in TypeScript/JavaScript, and executed using `npm test` with reports generated via `playwright show-report`.
