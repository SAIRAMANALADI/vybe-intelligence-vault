# Static Typing with Python — typing documentation

## Summary

- Python's static typing system is formally specified, covering type annotations, generics, protocols, literals, overloads, and type narrowing, with historical/deprecated features documented separately.
- The ecosystem includes conformance-tested type checkers (mypy, pyright, pyrefly), IDE integrations (PyCharm, VSCode/Pylance), and tooling for stub integration (autotyping, merge-pyi) and linting (ruff, flake8-pyi).
- Type system evolution is governed by PEPs, with community support via GitHub discussions, Gitter, and a dedicated mailing list for typing-sig.
