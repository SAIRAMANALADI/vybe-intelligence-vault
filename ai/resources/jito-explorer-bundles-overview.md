# Jito Explorer | Bundles Overview

## Summary

- **Bundle Tracking**: Real-time monitoring of Jito bundles, displaying asset count, tipper identity, validator tip amounts, and timestamp via a sortable table interface.

- **Dynamic Loading**: Utilizes animated loading icons (e.g., `three-dots-dark.svg`) for asynchronous data fetching, ensuring smooth UI transitions during API calls.

- **Sorting & Filtering**: Supports sorting by tip size (`sortBy=Tip`) to prioritize high-value bundles, with a "View All" link for expanded dataset exploration.
