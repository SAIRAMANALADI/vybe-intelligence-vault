# microsoft/pyright

## Summary

- **Static Type Checker**: Pyright is a static type checker for Python, enabling early detection of type-related errors without execution.
- **Language Server Protocol (LSP) Support**: Implements LSP for integration with IDEs (e.g., VS Code) for real-time type checking and autocompletion.
- **Performance Optimized**: Uses a fast type inference engine and incremental analysis to minimize overhead during large-scale Python project analysis.
