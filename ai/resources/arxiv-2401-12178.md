# [2401.12178] In-Context Learning for Extreme Multi-Label Classification

## Summary

- **Proposed Framework**: Introduces a three-step program (`Infer--Retrieve--Rank`) combining language models (LMs) and retrievers to address extreme multi-label classification (XMC) with thousands of classes, avoiding the infeasibility of full-class demonstration in prompts.

- **Implementation & Optimization**: Uses the `DSPy` programming model for declarative in-context system design and optimizes it via `DSPy` optimizers using only tens of few-shot examples, achieving state-of-the-art results on HOUSE, TECH, and TECHWOLF benchmarks without fine-tuning.

- **Generalization & Efficiency**: Demonstrates competitive performance on BioDEX (a distinct benchmark) while requiring no fine-tuning, minimal prompt engineering, and only tens of labeled examples, with publicly available code at [github.com/KarelDO/xmc.dspy](https://github.com/KarelDO/xmc.dspy).
