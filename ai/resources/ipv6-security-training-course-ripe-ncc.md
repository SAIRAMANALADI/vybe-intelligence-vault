# IPv6 Security Training Course - RIPE NCC

## Summary

- **Target Audience & Prerequisites**: Advanced IPv6 security course restricted to RIPE NCC members, requiring prior IPv6 networking/security knowledge (equivalent to RIPE NCC's Basic IPv6 or Fundamentals courses) and CLI/command-line tool proficiency.

- **Course Focus**: Covers IPv6 protocol security (headers, addressing), associated protocols (ICMPv6, NDP, DHCPv6), internet-wide threats (DDoS, transition mechanisms), and security solutions (filtering, tools), excluding IPv6 basics/routing.

- **Learning Outcomes**: Enables identification of IPv6 security threats, application of packet filtering, understanding of protocol-related risks, and mitigation of internet-wide IPv6 threats (e.g., DDoS via transition mechanisms).
