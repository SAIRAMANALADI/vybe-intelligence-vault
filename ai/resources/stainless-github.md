# Stainless · GitHub

## Summary

- **Multi-language SDK Generation**: Stainless produces SDKs in TypeScript, Python, Go, Java, and Kotlin, with official packages for APIs like OpenAI, Modern Treasury, Anthropic, and Mux.
- **GitHub Integration**: SDKs are auto-generated from OpenAPI specs via a [GitHub Action](https://github.com/marketplace/actions/stainless-upload-openapi-specification) and kept updated via a [GitHub App](https://github.com/marketplace/stainless-app) that submits Release PRs.
- **Hosted Workflow**: SDK generation is managed through Stainless’ platform ([app.stainlessapi.com/signup](https://app.stainlessapi.com/signup)), enabling automated CI/CD for SDK maintenance.
