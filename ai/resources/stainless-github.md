# Stainless · GitHub

## Summary

- **Multi-Language SDK Generation**: Stainless produces official SDKs for TypeScript (npm), Python (PyPI), Go, Java (Maven), and Kotlin (Maven), supporting APIs like OpenAI, Modern Treasury, Anthropic, and Cloudflare.
- **GitHub Integration Workflow**: SDKs are auto-generated from OpenAPI specs via a [GitHub Action](https://github.com/marketplace/actions/stainless-upload-openapi-specification) for continuous updates, with Release PRs managed by a [GitHub App](https://github.com/marketplace/stainless-app).
- **Production-Ready Tooling**: Requires OpenAPI specs pushed to GitHub; SDKs are versioned and maintained in dedicated repos (e.g., `openai-node`, `modern-treasury-python`).
