# Stainless · GitHub

## Summary

- **Multi-language SDK Generation**: Stainless produces client SDKs in TypeScript (npm), Python (PyPI), Go, Java (Maven), and Kotlin (Maven) for APIs like OpenAI, Modern Treasury, Anthropic, and others, automating boilerplate code generation.
- **GitHub Integration Workflow**: Users upload OpenAPI specs via a [GitHub Action](https://github.com/marketplace/actions/stainless-upload-openapi-specification) and install a [GitHub App](https://github.com/marketplace/stainless-app) to auto-generate and update SDKs via Release PRs.
- **Production-Ready SDKs**: Generated SDKs (e.g., `openai-node`, `modern-treasury-python`, `orb-go`) are versioned, maintained, and hosted on official repositories, ensuring compatibility with upstream API changes.
