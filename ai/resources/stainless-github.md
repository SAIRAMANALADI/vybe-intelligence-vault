# Stainless · GitHub

## Summary

- **Multi-language SDK Generation**: Stainless produces SDKs in TypeScript, Python, Go, Java, and Kotlin, with official packages for APIs like OpenAI, Modern Treasury, Anthropic, and Mux, available via npm, PyPI, and Maven repositories.

- **GitHub Integration Workflow**: SDK generation is triggered by pushing OpenAPI specs to GitHub, automated via a [GitHub Action](https://github.com/marketplace/actions/stainless-upload-openapi-specification), with updates managed through a [GitHub App](https://github.com/marketplace/stainless-app) for Release PRs.

- **Automated SDK Maintenance**: The platform ensures SDKs stay synchronized with API changes by auto-generating and updating client libraries in production repos, reducing manual maintenance overhead.
