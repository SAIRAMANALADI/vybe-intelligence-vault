# Stainless · GitHub

## Summary

- **Multi-language SDK Generation**: Stainless produces officially maintained SDKs in TypeScript (npm), Python (PyPI), Go, Java (Maven), and Kotlin (Maven) for APIs like OpenAI, Modern Treasury, Anthropic, and others, ensuring type-safe client libraries across ecosystems.

- **Automated CI/CD Integration**: SDK updates are triggered via GitHub Actions (e.g., `stainless-upload-openapi-specification`) for OpenAPI spec changes, with Release PRs auto-generated by a GitHub App to synchronize SDKs with upstream API updates.

- **Enterprise-Grade Tooling**: Requires Stainless account signup, GitHub repo setup, and GitHub App installation for production SDKs, enabling seamless versioning, dependency management, and cross-repository synchronization.
