# Stainless · GitHub

## Summary

- **Multi-language SDK Generation**: Stainless produces SDKs in TypeScript, Python, Go, Java, and Kotlin, with official libraries for APIs like OpenAI, Modern Treasury, Anthropic, and Cloudflare.
- **GitHub Integration Workflow**: Users can automate OpenAPI spec updates via a [GitHub Action](https://github.com/marketplace/actions/stainless-upload-openapi-specification) and maintain SDKs with a [GitHub App](https://github.com/marketplace/stainless-app) for Release PRs.
- **Maven & npm Distribution**: Java/Kotlin SDKs are distributed via Maven, while TypeScript/Python SDKs are published on npm/PyPI, ensuring standardized package management across ecosystems.
