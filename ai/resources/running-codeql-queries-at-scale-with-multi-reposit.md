# Running CodeQL queries at scale with multi-repository variant analysis - GitHub Docs

## Summary

- **Multi-repository variant analysis (MRVA)** enables running CodeQL queries on up to 1,000 GitHub repositories from VS Code, requiring a controller repository with at least one commit for orchestration.
- **Controller repository setup** mandates GitHub code scanning (CodeQL) enabled; public repos suffice for public repositories, while private repos are required for private/internal analysis, with GitHub Actions billing applying beyond free limits.
- **Results exploration** includes real-time monitoring via the "Variant Analysis Results" view, detailed per-repository analysis, and export options (secret gist or Markdown), with custom repository lists managed in `databases.json`.
