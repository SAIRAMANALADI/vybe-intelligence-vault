# Install WSL with a single command now available in Windows 10 version 2004 and higher - Windows Command Line

## Summary

- **Simplified WSL Installation**: `wsl.exe --install` command now backported to Windows 10 (v2004+) enabling automatic enabling of WSL features, installation of Ubuntu by default, and latest WSL Linux kernel update with a single command and system restart.

- **Distribution Management**: `wsl --list --online` lists available Linux distributions; `wsl --install -d <DistroName>` installs specified distro (first-time or additional); `wsl --update` and `wsl --update rollback` manage kernel updates; `wsl --status` displays WSL configuration details.

- **Update Requirement**: KB5004296 update enables these commands; obtain via Windows Update (Settings > Update & Security > Check for Updates) or manually install from Microsoft Support link.
