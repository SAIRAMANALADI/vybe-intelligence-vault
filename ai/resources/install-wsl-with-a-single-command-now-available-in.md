# Install WSL with a single command now available in Windows 10 version 2004 and higher - Windows Command Line

## Summary

- **Simplified WSL Installation**: `wsl.exe --install` command automates enabling WSL features, installing Ubuntu by default, and updating the WSL Linux kernel on Windows 10 version 2004+ via KB5004296.
- **Distribution Management**: Use `wsl --list --online` to list available distributions and `wsl --install -d <DistroName>` to install additional or alternative distributions.
- **WSL Maintenance Commands**: `wsl --update` for kernel updates, `wsl --update rollback` for reverting, and `wsl --status` for configuration details.
