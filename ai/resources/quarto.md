# Quarto

## Summary

- **Multi-Language Support**: Quarto enables dynamic document generation using Python, R, Julia, and Observable JS, supporting execution via engines like `knitr`, `julia`, `jupyter`, and native Observable JS for interactive data visualization.

- **Cross-Format Publishing**: Supports reproducible output in HTML, PDF, MS Word, ePub, and more, with Pandoc markdown for equations, citations, cross-references, and advanced layout features.

- **Integration & Extensibility**: Works with Jupyter notebooks, VS Code, RStudio, and Positron; includes extensions for interactive elements (Shiny, htmlwidgets, Jupyter Widgets) and supports publishing to platforms like Posit Connect and Confluence.
