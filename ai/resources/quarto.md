# Quarto

## Summary

- **Multi-language, Reproducible Publishing**: Quarto supports dynamic document generation using Python, R, Julia, and Observable, enabling reproducible outputs in HTML, PDF, MS Word, ePub, and more via Pandoc markdown with advanced features like equations, citations, cross-references, and figure panels.

- **Unified Workflow & Extensibility**: Integrates with Jupyter notebooks, traditional markdown editors, and tools like VS Code/RStudio; supports extensions and interactivity via Jupyter Widgets, htmlwidgets, Observable JS, and Shiny for interactive data exploration.

- **Publication & Collaboration**: Enables multi-format publishing (articles, books, websites, dashboards) to platforms like Posit Connect and Confluence; supports static and dynamic content with reactive execution models for data-driven storytelling.
