# godotengine/godot

## Summary

- **Multi-platform 2D/3D Game Engine**: Open-source C++ framework supporting cross-platform game development with native Vulkan, OpenGL ES, and Direct3D 12 backends.
- **Modular Architecture**: Features a scene system with node-based composition, GDScript (Python-like), C# 12, and VisualScript (deprecated) for scripting, alongside a custom memory management system.
- **Extensible Pipeline**: Integrates a custom 3D renderer with physically based rendering (PBR), real-time global illumination (SDFGI), and a 2D engine with batching; supports plugins, custom modules, and editor tooling via C++/GDNative.
