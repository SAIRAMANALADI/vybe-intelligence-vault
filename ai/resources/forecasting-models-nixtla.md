# Forecasting Models - Nixtla

## Summary

- **Model Diversity**: NeuralForecast supports 30+ models across architectures (e.g., Transformer, RNN, MLP, CNN, GNN, KAN, LLM) with both univariate and multivariate variants, including specialized frameworks like `HINT` for hierarchical reconciliation.

- **Automated Optimization**: Auto* versions (e.g., `AutoNBEATS`, `AutoLSTM`) auto-tune hyperparameters via grid/random/Bayesian search, selecting the best-performing model for validation sets.

- **Exogenous & Forecasting Modes**: Models support exogenous variables (past/future/static) and primarily use direct forecasting (multi-step output), with recursive options (e.g., `GRU`, `LSTM`) for computationally efficient single-step predictions.
