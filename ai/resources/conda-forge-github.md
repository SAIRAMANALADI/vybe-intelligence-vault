# conda-forge · GitHub

## Summary

- **`conda-forge`** is a community-driven conda package distribution with curated recipes, build infrastructure, and governance policies.

- **Key repositories**:
  - `staged-recipes`: New package submissions.
  - `feedstocks`: Monorepo of all feedstocks (submodules).
  - `conda-forge-bot`: Backend infrastructure for automation.

- **Supporting repos**:
  - `conda-forge.github.io`: Documentation and issue tracking.
  - `conda-forge-pinning-feedstock`: Global dependency pinnings.
  - `conda-smithy`: Tool for managing feedstocks.
