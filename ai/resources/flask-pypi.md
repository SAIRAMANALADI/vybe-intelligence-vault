# Flask · PyPI

## Summary

- **Framework Core**: Flask 3.1.3 is a lightweight WSGI web application framework built atop Werkzeug (WSGI toolkit) and Jinja (templating engine), enabling rapid development of scalable web applications with minimal enforced dependencies.

- **Technical Specifications**: Requires Python ≥3.9, licensed under BSD-3-Clause, and supports optional extras (`async`, `dotenv`) for asynchronous operations and environment variable management.

- **Release & Ecosystem**: Latest stable release (v3.1.3, Feb 2026) with a long-term support history; maintained by Pallets Projects, featuring community-driven extensions and a typed codebase for enhanced IDE support.
