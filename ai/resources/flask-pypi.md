# Flask · PyPI

## Summary

- **WSGI-compliant lightweight framework** built atop Werkzeug (WSGI toolkit) and Jinja2 templating engine, enabling scalable web application development with minimal boilerplate.

- **Python 3.9+ requirement** with BSD-3-Clause license; supports async (`async` extra) and environment variable management (`dotenv` extra) via community extensions.

- **Latest stable release (3.1.3, Feb 2026)** under active maintenance by Pallets Projects, with PyPI-verified metadata and OS-independent compatibility.
