# [2303.15343] Sigmoid Loss for Language Image Pre-Training

## Summary

- **Sigmoid Loss for Language-Image Pre-training (SigLIP)**: Proposes a pairwise sigmoid loss that eliminates the need for softmax normalization in contrastive learning, operating solely on image-text pairs without requiring global pairwise similarity normalization.
- **Performance & Efficiency**: Achieves 84.5% ImageNet zero-shot accuracy with SigLiT model trained on 4 TPUv4 chips in 2 days; enables scaling batch sizes while maintaining performance, with diminishing returns observed beyond 32k batch size.
- **Batch Size Impact Study**: Disentangles batch size from loss computation, enabling analysis of negative-to-positive ratio and example vs. pair importance; extreme batch sizes (up to 1M) show minimal gains compared to 32k.
