# Introduction — xeus documentation

## Summary

- **C++ framework** for implementing Jupyter Kernel protocol-compliant kernels, abstracting protocol handling to focus on interpreter logic.
- **Modular server architecture** with `xserver_zmq` for ZeroMQ-based communication and customizable components (e.g., history manager, logger).
- **BSD-3-Clause licensed**, supporting multiple language kernels (e.g., Python, R, Lua) via projects like `xeus-python` and `xeus-cling`.
