# vgo - Git at Google

## Summary

- **Obsolete Repository**: The `vgo` repository is marked obsolete, with all features merged into the main Go toolchain (Go 1.11+), retaining historical significance only.
- **Version-Aware `go` Command**: The standalone `vgo` implementation provided module support for Go 1.10 toolchains, behaving as if `GO111MODULE=on` by default and disabling `go vet` during `go test` for Go 1.10.
- **Installation & Contribution**: Installed via `go get -u golang.org/x/vgo`; bugs should be reported to the main Go issue tracker with `x/vgo:` prefix.
