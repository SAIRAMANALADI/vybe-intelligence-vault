# How to use Baseline in your project | Google Codelabs

## Summary

- **Baseline Integration**: Baseline provides Browserslist queries to define browser support targets (e.g., `baseline widely available` or `baseline 2016`) in toolchains like webpack, enabling automatic polyfill and transform adjustments based on interoperability data.
- **Downstream Browser Support**: Baseline queries can extend support to downstream browsers (e.g., Opera, Samsung Internet) using `with downstream`, expanding the core browser set (Chrome, Firefox, Safari, Edge) to include Chromium-derived engines.
- **Linting and Tooling**: Baseline integrates with linters (ESLint, Stylelint) via plugins like `@eslint/css` and `stylelint-plugin-use-baseline`, enforcing compliance with Baseline targets (e.g., `widely available`) during development.
