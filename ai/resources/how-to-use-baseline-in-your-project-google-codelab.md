# How to use Baseline in your project | Google Codelabs

## Summary

- **Baseline Integration**: Configure Browserslist queries in `package.json` (e.g., `"browserslist": "baseline widely available"`) to align project toolchains with interoperable web features, replacing manual version-based targeting.
- **Target Impact**: Baseline targets (e.g., `widely available` vs. fixed years like `2016`) significantly alter build outputs—polyfills, vendor prefixes, and bundle sizes—via tools like `core-js` and `autoprefixer`.
- **Extended Support**: Use `with downstream` in Browserslist queries (e.g., `"baseline widely available with downstream"`) to include Chromium-derived browsers (e.g., Opera, Samsung Internet) in compatibility checks.
