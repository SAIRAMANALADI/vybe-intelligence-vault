# Performance panel: Analyze your website's performance | Chrome DevTools | Chrome for Developers

## Summary

- **Core Web Vitals Monitoring**: The Performance panel in Chrome DevTools provides real-time tracking of **LCP (Largest Contentful Paint)**, **CLS (Cumulative Layout Shift)**, and **INP (Interaction to Next Paint)**, enabling immediate assessment of Core Web Vitals metrics with live scoring (Good/Needs Improvement/Bad).

- **Field Data Integration & Environment Emulation**: Fetches **Chrome UX Report (CrUX) field data** for comparison with local metrics, while allowing environment emulation (CPU/network throttling, viewport settings) to align testing conditions with real-world user experiences.

- **Advanced Profiling & Optimization Tools**: Supports **runtime/load performance recording**, **AI-assisted bottleneck analysis**, and **detailed report breakdowns** (flame charts, memory metrics, CSS selector stats) to identify and resolve performance inefficiencies.
