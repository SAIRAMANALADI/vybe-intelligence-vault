# Performance panel: Analyze your website's performance | Chrome DevTools | Chrome for Developers

## Summary

- **Core Web Vitals Monitoring**: Chrome DevTools' Performance panel provides real-time tracking of **LCP (Largest Contentful Paint)**, **CLS (Cumulative Layout Shift)**, and **INP (Interaction to Next Paint)** metrics, offering live scoring (Good/Needs Improvement/Bad) to assess Core Web Vitals compliance.
- **Field Data Integration**: Enables comparison of local performance metrics with **real-world Chrome UX Report data**, including advanced configuration options for mapping development/production environments and throttling CPU/network to simulate user conditions.
- **Advanced Profiling & Analysis**: Supports **runtime/load performance recording**, **CPU/network throttling**, **garbage collection forcing**, and **screenshot capture**; includes **Performance Insights** for actionable optimization guidance and detailed flame chart analysis for bottleneck identification.
