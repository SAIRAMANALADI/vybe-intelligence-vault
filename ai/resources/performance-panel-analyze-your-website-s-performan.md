# Performance panel: Analyze your website's performance | Chrome DevTools | Chrome for Developers

## Summary

- **Real-time Core Web Vitals Monitoring**: The Performance panel in Chrome DevTools provides live tracking of **LCP**, **CLS**, and **INP** metrics, offering immediate scoring (Good/Needs Improvement/Poor) to assess real-user experience under current network/device conditions.

- **Field Data Integration & Environment Emulation**: Supports fetching **Chrome UX Report (CrUX)** field data for direct comparison with local metrics, alongside configurable throttling (CPU/network) and viewport emulation to align test conditions with real-world user environments.

- **Advanced Profiling & Analysis Tools**: Enables **runtime/load performance recording**, **flame chart visualization**, **memory tracking**, and **CSS selector performance analysis**, with options to disable JS samples or enable advanced paint instrumentation for deeper debugging.
