# Performance panel: Analyze your website's performance | Chrome DevTools | Chrome for Developers

## Summary

- **Real-time Core Web Vitals Monitoring**: The Performance panel in Chrome DevTools provides live tracking of **LCP (Largest Contentful Paint)**, **CLS (Cumulative Layout Shift)**, and **INP (Interaction to Next Paint)**, offering immediate scoring (Good/Needs Improvement/Poor) to assess real-user experience metrics.

- **Field Data Comparison & Environment Throttling**: Enables fetching and comparison of **Chrome UX Report field data** with local metrics, while allowing configuration of **CPU/network throttling** and **viewport emulation** to align test conditions with real-world user environments.

- **Advanced Performance Profiling & AI Assistance**: Supports recording **runtime/load performance profiles**, with options like **screenshots, garbage collection forcing, and CSS/JS sampling**; includes **AI-powered bottleneck analysis** for actionable optimization insights.
