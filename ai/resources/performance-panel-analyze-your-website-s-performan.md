# Performance panel: Analyze your website's performance | Chrome DevTools | Chrome for Developers

## Summary

- **Core Web Vitals Monitoring**: The Performance panel captures real-time **LCP**, **CLS**, and **INP** metrics, providing live scores (good/needs improvement/bad) and detailed breakdowns via tooltips, enabling immediate performance assessment.
- **Field Data Integration & Environment Simulation**: Fetches **Chrome UX Report** field data for direct comparison with local metrics, while offering throttling (CPU/network) and viewport emulation to align testing conditions with real-world user environments.
- **Advanced Profiling & Analysis Tools**: Supports recording runtime/load performance profiles with configurable capture settings (e.g., JS sampling, CSS selector stats, garbage collection), and provides actionable insights via the **Performance Insights** panel for optimization.
