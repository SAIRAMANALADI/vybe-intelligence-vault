# OWASP - Wikipedia

## Summary

- **Non-profit organization**: OWASP is a 501(c)(3) non-profit founded in 2001 (US) and 2011 (Belgium), led by The OWASP Foundation with ~13,000 volunteer members, focused on web/IoT/application security via open-source resources.

- **Key resources**: Publishes critical standards like OWASP Top 10 (annual top security risks), ASVS (verification standard), SAMM (maturity model), and tools like ZAP (penetration testing) and WebGoat (insecure web app for training).

- **Expanding scope**: Launched OWASP Gen AI Security Project (2023) to address LLM risks, offers professional certifications (e.g., Top 10, ASVS), and maintains projects like API Security and AI Maturity Assessment.
