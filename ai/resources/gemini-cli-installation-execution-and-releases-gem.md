# Gemini CLI installation, execution, and releases | Gemini CLI

## Summary

- **System Requirements**: Supports macOS 15+, Windows 11 24H2+, Ubuntu 20.04+; requires Node.js 20.0.0+; "Casual" usage needs 4GB+ RAM, "Power" usage needs 16GB+ RAM; must run in supported [Gemini Code Assist locations](https://developers.google.com/gemini-code-assist/resources/available-locations#americas).
- **Installation Methods**: Available via `npm install -g @google/gemini-cli`, Homebrew (`brew install gemini-cli`), MacPorts (`sudo port install gemini-cli`), or Anaconda (`conda create -n gemini_env -c conda-forge nodejs && npm install -g @google/gemini-cli`).
- **Release Channels**: Three channels—**Stable** (weekly, `latest` tag), **Preview** (weekly, `preview` tag), and **Nightly** (daily, `nightly` tag); Stable is default, Preview/ Nightly for testing unreleased features.
