# JupyterHub · GitHub

## Summary

- **Core Architecture**: JupyterHub is a multi-user server for Jupyter notebooks, enabling scalable, centralized management of Jupyter instances with Python-based authentication and spawning mechanisms.

- **Kubernetes Integration**: `zero-to-jupyterhub-k8s` provides Helm charts for deploying JupyterHub on Kubernetes, supporting dynamic user pod spawning via `kubespawner` and configurable proxy routing via `configurable-http-proxy`.

- **Authentication & Deployment**: `oauthenticator` integrates OAuth providers for user authentication, while `the-littlest-jupyterhub` offers a lightweight single-server deployment for small-scale use cases.
