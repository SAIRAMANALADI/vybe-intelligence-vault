# Kotlin 2.4.0 Released - The JetBrains Blog

## Summary

- **Language & Compiler**: Kotlin 2.4.0 introduces stable context parameters, explicit backing fields, enhanced annotation use-site targets, and more consistent inline function behavior in `.klib` compilation.

- **Multiplatform Support**: Adds Java 26 support in Kotlin/JVM, Swift package dependencies in Kotlin/Native, WebAssembly Component Model support in Kotlin/Wasm, and ES2015 feature inlining in Kotlin/JS.

- **Tooling & Build Systems**: Gradle 9.5.0 compatibility, automatic Java/JVM target version alignment in Maven, and stabilized UUID API with sorted order checks in the standard library.
