# Node.js — Run JavaScript Everywhere

## Summary

- **Cross-platform runtime**: Node.js is an open-source JavaScript runtime enabling server-side execution, CLI tools, and web app development via a non-blocking, event-driven architecture.

- **Core modules**: Provides built-in modules (`http`, `fs`, `crypto`, `stream`, `worker_threads`) for tasks like HTTP server creation, file hashing (SHA-1), stream pipelines (compression), and multi-threading.

- **Testing framework**: Includes native `node:test` and `node:assert` for unit testing, with examples demonstrating synchronous/asynchronous test cases and error handling.
