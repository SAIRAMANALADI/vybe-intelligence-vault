# Node.js — Run JavaScript Everywhere

## Summary

- **Node.js** is a cross-platform JavaScript runtime enabling server-side, CLI, and script execution with non-blocking I/O and event-driven architecture.
- **Core modules** (`http`, `crypto`, `fs`, `stream`, `worker_threads`) provide native APIs for HTTP servers, file hashing, streams, and multi-threading.
- **ES Modules** (`import/export`) are supported by default (e.g., `.mjs` files), facilitating modular code execution via `node <file.mjs>`.
