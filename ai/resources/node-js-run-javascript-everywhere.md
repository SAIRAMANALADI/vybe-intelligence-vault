# Node.js — Run JavaScript Everywhere

## Summary

- **Node.js** is a cross-platform JavaScript runtime enabling server-side, CLI, and script execution via Chrome's V8 engine.
- **Core capabilities** include HTTP server creation, file I/O, stream pipelines, and multi-threading via worker threads.
- **Example HTTP server** demonstrates non-blocking I/O with `createServer()`, listening on port 3000 and responding with plaintext.
