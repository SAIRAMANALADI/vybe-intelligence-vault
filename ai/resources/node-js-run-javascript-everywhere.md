# Node.js — Run JavaScript Everywhere

## Summary

- **Cross-platform JS runtime**: Node.js is an open-source JavaScript runtime enabling server-side execution of JS, supporting server, CLI tool, and script development across platforms.
- **Core capabilities**: Includes HTTP server creation, file I/O (e.g., reading/hashing), stream pipelines, multi-threading support, and test execution via built-in/third-party tools.
- **Example HTTP server**: Demonstrates minimal `node:http` server setup with `createServer()`, handling requests/responses via `res.writeHead()` and `res.end()`, listening on `127.0.0.1:3000`.
