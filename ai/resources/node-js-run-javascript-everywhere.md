# Node.js — Run JavaScript Everywhere

## Summary

- **Runtime Environment**: Node.js is an open-source, cross-platform JavaScript runtime enabling server-side execution of JS, facilitating development of servers, web apps, CLI tools, and scripts.

- **Core Modules**: Includes built-in modules (`http`, `assert`, `test`, `crypto`, `fs`, `stream`, `worker_threads`) for HTTP server creation, testing, file hashing, stream pipelines, and multi-threading.

- **Execution Examples**: Demonstrates practical use cases via ES modules (`.mjs` files), including HTTP server setup, test assertions, SHA-1 file hashing, gzip compression via streams, and worker thread communication.
