# Node.js — Run JavaScript Everywhere

## Summary

- Node.js is a cross-platform JavaScript runtime enabling server-side execution of JS code for building servers, web apps, CLI tools, and scripts.
- Provides core modules like `http` for creating HTTP servers (e.g., minimal server listening on `127.0.0.1:3000` via `server.listen()`).
- Supports advanced features including file I/O, streams, worker threads, and testing frameworks for scalable backend development.
