# Node.js — Run JavaScript Everywhere

## Summary

- **Cross-platform JS runtime**: Node.js is an open-source JavaScript runtime enabling server-side execution, CLI tool development, and script automation across platforms.

- **Core HTTP server implementation**: Uses `node:http` module to create a low-level HTTP server (e.g., `createServer()`) with customizable request/response handling.

- **Asynchronous I/O with streams**: Supports non-blocking I/O operations (e.g., file hashing, streams) and multi-threading via worker threads for concurrent task execution.
