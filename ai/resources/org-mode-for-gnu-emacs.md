# Org mode for GNU Emacs

## Summary

- **Plain-text syntax**: Org mode is a structured plain-text format in GNU Emacs, combining versatility with simplicity for tasks like note-taking, literate programming, and project management via hierarchical headings, metadata, and folding.

- **Literate programming & Babel**: Supports live code execution within buffers via Org Babel, enabling notebook-like workflows with multi-language source blocks (`#+begin_src`), results caching (`#+RESULTS`), and cross-referencing.

- **Ecosystem & extensibility**: Maintained as a Git-based project with community-driven documentation (Worg), third-party tools (e.g., mobile apps, parsers), and integrations in starter kits (Doom, Spacemacs) while tracking development via Savannah/Git mirrors.
