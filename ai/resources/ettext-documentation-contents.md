# EtText: Documentation: Contents

## Summary

- **EtText** is a lightweight markup language designed for converting plain text to HTML, supporting features like lists, sidebars, and links while avoiding HTML collision via escaping mechanisms.

- **Core Modules**: Includes `Text::EtText::EtText2HTML` (text-to-HTML conversion), `Text::EtText::HTML2EtText` (HTML-to-text conversion), and `Text::EtText::LinkGlossary` (link management), with additional utilities like `Text::EtText::DefaultGlossary`.

- **CLI Tools**: Provides `ettext2html(1)` and `ethtml2text(1)` for command-line conversion, alongside manual pages and documentation for integration into larger systems like **WebMake**.
