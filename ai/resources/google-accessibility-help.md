# Google Accessibility Help

## Summary

- **Multi-platform Accessibility Support**: Google provides structured accessibility resources across Android, Chrome, Drive/Docs, Calendar/Gmail, Meet, Chromebook/Pixel devices, and YouTube, including screen reader integration (e.g., TalkBack), live captioning, braille display compatibility, and keyboard shortcuts for diverse user needs.

- **Specialized Accessibility Features**: Key tools include Sound Amplifier (audio enhancement), Switch Access (alternative input), Live Caption (real-time media captioning), and ASL specialist support, alongside community-driven solutions like Be My Eyes for visual assistance.

- **Cross-Product Accessibility Tools**: Google implements universal features such as text-to-speech (e.g., "Hear text read aloud"), zoom/magnification, caption management, and Morse code input across products like Search, Maps, Photos, and Nest Hub, ensuring consistency in assistive technology integration.
