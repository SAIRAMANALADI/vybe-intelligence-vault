# C/C++ for Visual Studio Code

## Summary

- **C/C++ Extension**: Microsoft's official C/C++ extension (`ms-vscode.cpptools`) provides cross-platform development support (Windows/Linux/macOS) with syntax highlighting, IntelliSense, and error checking for `*.cpp` files.

- **Compiler Dependency**: VS Code relies on external compilers (e.g., GCC, Clang, MSVC) and debuggers; the extension does not bundle these tools. Users must install them separately or configure existing toolchains via `%PATH` (Windows) or `$PATH` (Linux/macOS).

- **Environment Setup**: Tutorials guide users through installing compilers (e.g., MinGW-w64 via MSYS2 on Windows, GCC on Linux) and validating installations via `g++ --version` or `clang --version` to ensure compatibility with VS Code's C/C++ workflow.
