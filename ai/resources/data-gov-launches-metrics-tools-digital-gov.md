# Data.gov launches metrics tools | Digital.gov

## Summary

- **Metrics Dashboard Launch**: Data.gov introduced a [metrics dashboard](http://Data.gov/metrics) providing detailed analytics on dataset interactions, including pageviews, file downloads, and outbound link clicks, with monthly updates for all 300,000+ datasets across 300+ government organizations.

- **Key Features**: The dashboard offers public visibility, dataset pageviews beyond the 2-week "recent views" limit, file download tracking, outbound link click metrics, downloadable reports (CSV/JSON), and harvest source data (frequency, last update).

- **Organization-Specific Insights**: Users can filter metrics by organization (e.g., U.S. Census Bureau) to view top datasets, downloads, and outbound links, with additional harvest source metadata and downloadable reports.
