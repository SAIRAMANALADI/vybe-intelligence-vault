# An Introduction to Latex

## Summary

- **Document Typesetting**: Guide for typesetting mathematical papers using LaTeX2e (TeX) on Harvard Mathematics Department's Sun workstations, covering previewing, printing, and file management.

- **Text & Math Modes**: Detailed instructions on LaTeX commands for text formatting (e.g., environments, theorems, lists) and mathematical notation (e.g., equations, matrices, special symbols, bracketing).

- **Document Workflow**: Covers large file handling, compilation checks, viewing/printing output, and inclusion of graphics (e.g., Xfig, PostScript) for comprehensive document preparation.
