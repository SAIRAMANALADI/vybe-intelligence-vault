# Fused Location Provider API | Google for Developers

## Summary

- **Battery-Optimized Location API**: The Fused Location Provider (FLP) API in Google Play services intelligently combines multiple sensor signals (GPS, Wi-Fi, etc.) to provide accurate location data while optimizing battery consumption.

- **Simplified Location Management**: FLP abstracts underlying location technologies, allowing developers to specify quality-of-service (QoS) requirements (e.g., high accuracy vs. power efficiency) without manually managing signal sources.

- **Key Features**:
  - Retrieves **last known location** for initial positioning.
  - Automatically adjusts **location settings** based on QoS needs.
  - Delivers **periodic location updates** (with velocity/direction) via callbacks.
