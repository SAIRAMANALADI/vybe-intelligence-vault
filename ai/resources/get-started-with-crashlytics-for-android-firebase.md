# Get started with Crashlytics for Android | Firebase Crashlytics

## Summary

- **Setup Requirements**: Minimum versions for Gradle (8.0), Android Gradle plugin (8.1.0), and Google services plugin (4.4.1); Google Analytics recommended for breadcrumb logs.
- **Integration Steps**: Add Firebase Crashlytics SDK (via BoM or direct versions) and plugin to Gradle files, then force a test crash to verify setup.
- **Post-Setup**: Use Firebase console to monitor crashes/ANRs; optional integrations include Google Play filtering, BigQuery exports, or Android Studio’s App Quality Insights.
