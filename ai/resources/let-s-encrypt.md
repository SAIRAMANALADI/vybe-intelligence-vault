# Let's Encrypt

## Summary

- **Merkle Tree Certificates**: Let's Encrypt is transitioning to post-quantum cryptography via Merkle Tree Certificates to future-proof TLS certificates against quantum computing threats.

- **ACME Renewal Information (ARI)**: ARI enhances certificate renewal automation, improving scalability and reliability for millions of domains (e.g., Shopify’s use case).

- **Free TLS Automation**: Let's Encrypt provides free, automated TLS certificates via ACME protocol, enabling HTTPS for over 700M websites through domain validation.
