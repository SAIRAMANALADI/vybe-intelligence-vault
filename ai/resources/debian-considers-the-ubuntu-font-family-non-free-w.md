# Debian considers the Ubuntu font family "non-free". Why? - Open Source Stack Exchange

## Summary

- **Ubuntu Font License (UFL) §2.3** mandates that modified versions not "substantially changed" must retain the "Ubuntu" name while adding distinguishing elements, conflicting with Debian's interpretation of DFSG's naming freedom.
- **Debian's rejection** stems from the UFL's prescriptive naming requirements, which Debian argues impose unnecessary restrictions beyond DFSG-compliant licenses like SIL OFL.
- **Fedora and Debian both classify UFL as non-free**, though Fedora cites different objections; this highlights broader concerns about "crayon licenses" even when drafted by legal professionals.
