# Releases · docker/scout-cli · GitHub

## Summary

- **v1.24.0**: Introduces local Scout Health Scores in `docker scout policy`, `quickview`, and `compare`; fixes `--only-base`/`--ignore-base` CVEs classification for provenance-identified base images; updates dependencies (ORAS, Sigstore, OpenTelemetry, go-git, pgx).

- **v1.23.0**: Prevents empty VEX documents from breaking scans; enables HTTP(S) Rego policy sources via `--policy-file`; improves SBOM fetching and policy evaluation performance.

- **v1.20.4**: Adds JSON output for `docker scout compare`; includes image config field changes; fixes Docker Desktop proxy detection in WSL2; updates dependencies.
