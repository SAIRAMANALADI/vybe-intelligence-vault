# hashicorp/terraform

## Summary

- **Declarative Infrastructure as Code (IaC)**: Terraform converts APIs into declarative configuration files (HCL), enabling infrastructure provisioning, modification, and versioning via code.

- **Graph-Based Execution**: Uses a dependency graph to model infrastructure relationships, ensuring predictable and safe changes by resolving execution order and parallelizing operations.

- **Multi-Cloud & Team Collaboration**: Supports multiple cloud providers via plugins; configurations are shareable, reviewable, and version-controlled for team-based infrastructure management.
