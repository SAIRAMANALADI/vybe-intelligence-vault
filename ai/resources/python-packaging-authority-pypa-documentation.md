# Python Packaging Authority — PyPA documentation

## Summary

- **PyPA Overview**: The Python Packaging Authority (PyPA) is a working group maintaining core Python packaging tools, including `pip` for PyPI interactions, and publishes the [Python Packaging User Guide](https://packaging.python.org) as the authoritative resource for packaging, publishing, and installing Python projects.

- **Key Projects & Resources**: PyPA hosts projects on [GitHub](https://github.com/pypa), discusses issues on [discuss.python.org](https://discuss.python.org/c/packaging), and maintains key projects like `setuptools`, `wheel`, and `twine`; documentation includes specifications, roadmaps, and a [key projects list](https://packaging.python.org/en/latest/key_projects/#pypa-projects).

- **Community & Governance**: PyPA operates under the Python Software Foundation (PSF), follows a [Code of Conduct](https://www.pypa.io/en/latest/code-of-conduct/), and provides pathways for user support, contributions, and membership; documentation is licensed under PSF-2.0 and Zero-Clause BSD.
