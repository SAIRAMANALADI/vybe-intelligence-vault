# Python Packaging Authority — PyPA documentation

## Summary

- **PyPA** is a working group maintaining core Python packaging tools (e.g., `pip`, PyPI) for packaging, sharing, and installing Python software.
- Publishes the **Python Packaging User Guide**, the authoritative resource for Python packaging standards and third-party integrations (e.g., `conda-forge`).
- Hosts projects on **GitHub** and manages discussions via the **Packaging category** on `discuss.python.org`.
