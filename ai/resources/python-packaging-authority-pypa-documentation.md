# Python Packaging Authority — PyPA documentation

## Summary

- **PyPA Overview**: The Python Packaging Authority (PyPA) is a working group that develops and maintains core Python packaging tools (e.g., `pip`, `setuptools`, `twine`) for packaging, distributing, and installing Python software via repositories like PyPI.

- **Documentation & Governance**: PyPA maintains the [Python Packaging User Guide](https://packaging.python.org), the authoritative resource for Python packaging best practices, and hosts projects on [GitHub](https://github.com/pypa) with governance via [discuss.python.org](https://discuss.python.org/c/packaging).

- **Key Projects & Specifications**: PyPA oversees critical projects (e.g., `pip`, `virtualenv`) and publishes specifications (e.g., [PEP 517](https://peps.python.org/pep-0517/), [PEP 518](https://peps.python.org/pep-0518/)), with a public roadmap and member-driven development.
