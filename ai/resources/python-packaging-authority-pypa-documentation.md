# Python Packaging Authority — PyPA documentation

## Summary

- **PyPA Overview**: The Python Packaging Authority (PyPA) is a working group maintaining core Python packaging tools (e.g., `pip`, `setuptools`) for packaging, distributing, and installing Python software via indices like PyPI.

- **Documentation & Governance**: PyPA publishes the [Python Packaging User Guide](https://packaging.python.org) (authoritative resource for Python packaging) and hosts projects on [GitHub](https://github.com/pypa), with governance discussions on [discuss.python.org](https://discuss.python.org/c/packaging).

- **Key Resources**: PyPA provides specifications ([PEP-based](https://www.pypa.io/en/latest/specifications/)), roadmaps, and community resources (e.g., [conda-forge](https://conda-forge.org/) integration) under the [Python Software Foundation License](https://www.python.org/psf/license/).
