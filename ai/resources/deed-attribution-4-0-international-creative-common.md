## Summary

- **Definition**: A canonical URL is the preferred version of a web page that search engines should index and display in search results, specified using the `<link rel="canonical">` tag or HTTP header.
- **Purpose**: Prevents duplicate content issues by consolidating ranking signals (e.g., link equity) to a single, authoritative URL.
- **Implementation**: Declared in HTML (`<head>` section) or via server-side HTTP headers, with syntax: `<link rel="canonical" href="https://example.com/preferred-page" />`.
