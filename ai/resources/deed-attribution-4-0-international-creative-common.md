## Summary

- A **Canonical URL** is a specific URL designated as the preferred version of a webpage to prevent duplicate content issues in search engine indexing.
- It is implemented using the `<link rel="canonical">` tag in the HTML `<head>` section or via HTTP headers to signal to search engines the authoritative source.
- Proper canonicalization consolidates ranking signals (e.g., link equity) to the specified URL, improving SEO performance and avoiding dilution of search visibility.
