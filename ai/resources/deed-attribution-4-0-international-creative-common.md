## Summary

- A **Canonical URL** is a specific URL designated as the preferred version of a webpage to prevent duplicate content issues in search engine indexing.
- It is defined using the `<link rel="canonical">` tag in the HTML `<head>` section or via HTTP headers to consolidate ranking signals for identical or similar content.
- Search engines (e.g., Google) use canonical URLs to determine the primary source of content, avoiding dilution of SEO value across mirrored or syndicated pages.
