## Summary

- **Definition**: A canonical URL is a specific URL chosen by a website owner as the preferred version among multiple pages with similar or duplicate content.
- **Purpose**: It helps prevent duplicate content issues in search engine indexing by specifying the "canonical" or "main" version of a webpage.
- **Implementation**: Declared using the `<link rel="canonical">` tag in the HTML `<head>` section or via HTTP headers, ensuring search engines consolidate ranking signals to the canonical URL.
