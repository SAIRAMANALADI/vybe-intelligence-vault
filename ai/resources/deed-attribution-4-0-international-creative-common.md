## Summary

- A **Canonical URL** is a web page's preferred, standardized URL that search engines use to consolidate duplicate or similar content under a single, authoritative link.
- Implemented via the `<link rel="canonical">` HTML tag or HTTP header, it prevents SEO dilution by specifying the primary version of a page when multiple URLs serve identical or near-identical content.
- Critical for mitigating issues like session IDs, tracking parameters, or pagination, ensuring link equity and indexing efficiency are preserved.
