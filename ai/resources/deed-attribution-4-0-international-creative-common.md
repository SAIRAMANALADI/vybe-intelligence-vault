# Deed - Attribution 4.0 International - Creative Commons

## Summary

- A **canonical URL** is a URL that serves as the preferred or authoritative version of a webpage to prevent duplicate content issues in search engine indexing.
- It is specified using the `<link rel="canonical">` tag in the HTML `<head>` section or via the `rel=canonical` HTTP header.
- Canonical URLs consolidate ranking signals (e.g., link equity) to a single URL, improving SEO performance by avoiding dilution across multiple duplicate pages.
