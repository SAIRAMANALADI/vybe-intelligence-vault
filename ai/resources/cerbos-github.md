# Cerbos · GitHub

## Summary

- **Policy-driven Authorization Engine**: Cerbos is an open-source, horizontally scalable authorization layer that enforces fine-grained access control policies (written in a declarative DSL) at runtime, decoupling authorization logic from application code.

- **High-Performance Policy Evaluation**: Implements a gRPC-based microservice architecture with optimized policy compilation (to Go) and caching (e.g., Redis) to achieve sub-millisecond policy evaluation latency, supporting thousands of requests per second.

- **Multi-Context Policy Enforcement**: Supports dynamic policy evaluation across multiple contexts (e.g., user roles, resource attributes, hierarchical relationships) with real-time policy updates via Git-based workflows or REST APIs, ensuring consistency without downtime.
