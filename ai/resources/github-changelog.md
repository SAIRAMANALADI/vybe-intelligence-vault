# GitHub Changelog

## Summary

- **Repository-Level Metrics**: GitHub Copilot now provides granular, repository-specific usage analytics, enabling administrators to track AI-assisted code generation, completions, and suggestions per repo.
- **Enterprise Integration**: Metrics are exposed via GitHub’s enterprise management APIs, allowing automated aggregation and reporting for large-scale deployments.
- **Access Control**: Usage data is scoped to repository permissions, ensuring visibility only for authorized users with appropriate access levels.
