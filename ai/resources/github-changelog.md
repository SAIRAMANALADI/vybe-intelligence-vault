# GitHub Changelog

## Summary

- **GitHub Copilot CLI in GitHub Actions** now authenticates via **OIDC tokens** instead of personal access tokens (PATs), eliminating PAT dependency for secure workflows.
- **Seamless integration** with GitHub Actions' built-in identity federation, enabling **short-lived, scoped credentials** for Copilot CLI operations.
- **Enhanced security posture** by removing PAT exposure risks while maintaining **fine-grained access control** through GitHub's native IAM policies.
