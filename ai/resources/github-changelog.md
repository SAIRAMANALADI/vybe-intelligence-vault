# GitHub Changelog

## Summary

- **Merge Tracking Enhancement**: Enterprise and organization reports now include tracking of total merges segmented by adoption phase (e.g., pilot, full adoption), enabling granular analysis of GitHub adoption trends.
- **API/CLI Integration**: New endpoints expose merge metrics programmatically, allowing automation of adoption phase reporting via GitHub’s GraphQL API or CLI tools.
- **Phase-Specific Metrics**: Reports distinguish between merges in different adoption phases (e.g., pilot vs. enterprise-wide), providing actionable insights for enterprise management tools and Copilot deployments.
