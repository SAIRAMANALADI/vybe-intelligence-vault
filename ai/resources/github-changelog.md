# GitHub Changelog

## Summary

- **Preventive Account Protection**: npm introduces mandatory 2FA for high-impact accounts (e.g., maintainers of critical packages) to mitigate supply chain attacks via credential theft.

- **Automated Risk Detection**: Enhanced monitoring flags suspicious activities (e.g., sudden package ownership changes) and triggers account locks or reviews.

- **Enforcement via Package Scope**: High-impact accounts must verify identity via government-issued IDs or domain-validated emails to publish under critical scopes (e.g., `@types`, `@angular`).
