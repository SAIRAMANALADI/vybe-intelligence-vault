# GitHub Changelog

## Summary

- **Repository-level metrics**: GitHub Copilot now provides granular, repository-specific usage analytics (e.g., suggestions accepted/rejected, latency, and token consumption) for enterprise and organization admins via the GitHub API or UI.
- **Enterprise management integration**: Metrics are exposed through existing enterprise management tools (e.g., audit logs, security dashboards) with role-based access control (RBAC) for compliance and cost tracking.
- **API-first approach**: Usage data is accessible via REST/GraphQL endpoints (`/repos/{owner}/{repo}/copilot/usage`) with support for real-time streaming via webhooks for automation.
