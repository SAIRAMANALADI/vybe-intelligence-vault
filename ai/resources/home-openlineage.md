# Home | OpenLineage

## Summary

- **OpenLineage** is an open framework providing a standardized API for collecting and analyzing data lineage metadata, enabling tracking of datasets, jobs, and runs to diagnose issues and assess change impacts.

- **Core components** include an open lineage data standard, a metadata repository reference implementation (Marquez), SDKs for multiple languages, and integrations with pipeline tools like schedulers and SQL engines.

- **Deployment flexibility** supports both simple (single consumer) and complex (multi-consumer) setups, with community-driven development via GitHub, Slack, and monthly Technical Steering Committee meetings.
