# crypto.Hash

## Summary

- **Hashing Function**: The `crypto.Hash` function in Hugo supports multiple cryptographic hash algorithms (`md5`, `sha1`, `sha256`, `sha384`, `sha512`), defaulting to `sha256` if unspecified, and returns the checksum as a hexadecimal string.
- **Usage Syntax**: Can be called as `crypto.Hash [ALGORITHM] INPUT` or piped (`| crypto.Hash [ALGORITHM]`), with the algorithm optional.
- **SRI Integration**: Supports Subresource Integrity (SRI) by combining with `encoding.HexDecode` and `encoding.Base64Encode` to generate SRI-compatible hashes from strings.
