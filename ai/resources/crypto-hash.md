# crypto.Hash

## Summary

- `crypto.Hash` computes cryptographic checksums of input strings using specified algorithms (`md5`, `sha1`, `sha256`, `sha384`, `sha512`), defaulting to `sha256` if omitted.
- Supports integration with SRI (Subresource Integrity) via `encoding.HexDecode` and `encoding.Base64Encode` for hashed outputs.
- Returns checksums as hexadecimal strings, e.g., `{{ crypto.Hash "sha256" "Hello world" }} → 64ec88ca00b268e5ba1a35678a1b5316d212f4f366b2477232534a8aeca37f3c`.
