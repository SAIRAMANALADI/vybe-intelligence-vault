# crypto.Hash

## Summary

- **Functionality**: Hashes input using specified algorithm (`md5`, `sha1`, `sha256` (default), `sha384`, or `sha512`) and returns hex-encoded checksum.
- **Syntax**: `crypto.Hash [ALGORITHM] INPUT` or piped input (`"Hello world" | crypto.Hash "sha256"`).
- **SRI Integration**: Supports Subresource Integrity (SRI) via `crypto.Hash` combined with `encoding.HexDecode` and `encoding.Base64Encode` for constructing SRI hashes.
