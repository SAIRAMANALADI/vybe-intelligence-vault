# crypto.Hash

## Summary

- **Hashing Function**: `crypto.Hash` computes checksums using algorithms like `md5`, `sha1`, `sha256` (default), `sha384`, or `sha512` on input strings, returning hex-encoded results.
- **Default Algorithm**: If no algorithm is specified, `sha256` is used automatically.
- **SRI Integration**: Supports Subresource Integrity (SRI) by combining with `encoding.HexDecode` and `encoding.Base64Encode` to generate integrity hashes (e.g., `sha256-<base64-encoded-hash>`).
