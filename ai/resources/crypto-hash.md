# crypto.Hash

## Summary

- **Hashing Function**: `crypto.Hash` computes checksums of input strings using cryptographic algorithms (`md5`, `sha1`, `sha256` (default), `sha384`, or `sha512`), returning the result as a hexadecimal string.
- **Default Algorithm**: If no algorithm is specified, `sha256` is used by default for hashing operations.
- **SRI Integration**: Supports Subresource Integrity (SRI) by combining with `encoding.HexDecode` and `encoding.Base64Encode` to generate SRI-compatible hashes from strings.
