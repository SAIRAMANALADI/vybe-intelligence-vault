# crypto.Hash

## Summary

- **Hashing Function**: `crypto.Hash` computes checksums for input strings using specified cryptographic algorithms (`md5`, `sha1`, `sha256` (default), `sha384`, or `sha512`), returning the result as a hexadecimal string.
- **Algorithm Flexibility**: Supports multiple hashing algorithms with `sha256` as the default if unspecified, enabling compatibility with Subresource Integrity (SRI) standards.
- **Encoding Integration**: Can be combined with `encoding.HexDecode` and `encoding.Base64Encode` to generate SRI hashes from strings for secure resource fingerprinting.
