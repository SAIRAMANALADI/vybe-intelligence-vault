# crypto.Hash

## Summary

- `crypto.Hash` computes cryptographic checksums of input strings using specified algorithms (`md5`, `sha1`, `sha256` (default), `sha384`, or `sha512`), returning the result as a hexadecimal string.
- Default algorithm is `sha256` if none is specified; outputs match Subresource Integrity (SRI) hash formats for fingerprinted resources.
- Supports chaining with `encoding.HexDecode` and `encoding.Base64Encode` to generate SRI-compatible hashes (e.g., `sha256-<base64-encoded-hash>`).
