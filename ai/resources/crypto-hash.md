# crypto.Hash

## Summary

- **Hashing Function**: The `crypto.Hash` function in Hugo supports multiple algorithms (`md5`, `sha1`, `sha256` (default), `sha384`, `sha512`) to generate hexadecimal-encoded checksums from input strings.

- **Default Behavior**: If no algorithm is specified, `sha256` is used by default for hashing operations.

- **SRI Integration**: The output can be combined with `encoding.HexDecode` and `encoding.Base64Encode` to construct Subresource Integrity (SRI) hashes for fingerprinted resources.
