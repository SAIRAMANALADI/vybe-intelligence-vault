# crypto.Hash

## Summary

- **Hashing Function**: `crypto.Hash` computes cryptographic checksums of input strings using algorithms like `md5`, `sha1`, `sha256` (default), `sha384`, or `sha512`, returning the result as a hexadecimal string.
- **Default Algorithm**: If no algorithm is specified, `sha256` is used automatically for hashing.
- **SRI Integration**: Can be combined with `encoding.HexDecode` and `encoding.Base64Encode` to generate Subresource Integrity (SRI) hashes for resources.
