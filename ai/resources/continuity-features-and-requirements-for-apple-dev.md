# Continuity features and requirements for Apple devices - Apple Support

## Summary

- **Continuity Features**: Apple devices support seamless integration via features like AirDrop, Handoff, Universal Clipboard, and Universal Control, requiring specific OS versions (e.g., iOS 16+, macOS Ventura 13+, watchOS 3+).
- **Hardware/OS Requirements**: Continuity Camera (iPhone/iPad as webcam) needs iOS 16+/iPadOS 17+ and macOS Ventura 13+/tvOS 17+; Auto Unlock requires watchOS 6+ and macOS High Sierra 10.13+ on 2013+ Macs.
- **Advanced Integrations**: iPhone Mirroring (iOS 18+/macOS Sequoia 15+) enables secure iPhone interaction from Mac; Mac Virtual Display (visionOS/macOS Sonoma 15+) turns Apple Vision Pro into a 4K Mac display.
