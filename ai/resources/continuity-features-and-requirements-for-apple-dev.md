# Continuity features and requirements for Apple devices - Apple Support

## Summary

- **AirDrop**: Wireless data transfer between Apple devices requires Wi-Fi/Bluetooth; supported on iPhone 5+, iPad 4th gen+, Mac 2012+, Apple Vision Pro, and Apple Watch (all models).

- **Continuity Camera**: iPhone XR+ (iOS 16+) or iPad Pro/Air/mini (iPadOS 17+) can function as webcams for Mac (macOS Ventura+) or Apple TV (tvOS 17+), enabling Center Stage/Reactions on select models.

- **Universal Control**: Enables cross-device input (keyboard/mouse/trackpad) between Mac (macOS Monterey+) and iPad (iPadOS 15.4+), supporting up to 2 devices simultaneously.
