# Releases · github/codeql-cli-binaries · GitHub

## Summary

- **Git Integration Enhancement**: CodeQL v2.25.6 introduces support for SHA-256 Git repositories, enabling retrieval of configuration/queries and metadata inference when the `git` executable is available.

- **JDK & Dependency Updates**: OpenJDK runtime upgraded to Eclipse Temurin 21.0.11 in v2.25.6, and Jackson library updated to 2.18.6 (addressing CVE GHSA-72hv-8253-57qq) in v2.25.0.

- **Extractor Script Control**: Added `--working-dir` flag to `codeql database finalize` (v2.25.3) for customizing extractor pre-finalize script execution directory, improving flexibility in database creation workflows.
