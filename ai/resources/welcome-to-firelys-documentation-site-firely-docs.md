## Summary

- **Firely Product Suite**: Includes Simplifier (FHIR profile registry), Forge (FHIR profile editor), Firely Server (FHIR server), Firely .NET SDK (open-source FHIR library), and Firely Terminal (CLI FHIR tool).

- **FHIR Version Support Matrix**: Products support FHIR R5 (5.0.0), R4B (4.3.0), R4 (4.0.1), STU3 (3.0.2), with some supporting DSTU2 or R6 (preview).

- **SDK & Validator Dependencies**: Firely .NET SDK versions (e.g., 6.1.1, 5.13.3) and validators (e.g., Firely Validator 3.1.0) are core dependencies for Firely products, with version-specific compatibility.
