# yarnpkg/berry

## Summary

- **Modern JavaScript Package Manager**: Yarn Berry (v2+) is a complete rewrite in TypeScript, replacing the legacy architecture with a **Plug'n'Play (PnP)** system for zero-install dependency resolution, eliminating `node_modules` and improving performance via **virtual symlinks** and **hardened mode** for security.

- **Core Architecture**: Implements a **deterministic dependency resolver** with **constraints-based versioning**, **workspaces v2**, and **protocols** (e.g., `node-modules`, `pnp`) for flexible dependency management while ensuring **hermetic builds** via **immutable installs**.

- **Advanced Features**: Supports **selective version resolutions**, **offline mirror caching**, **portable workspaces**, and **interactive CLI tools** (e.g., `yarn why`, `yarn explain`), with **zero-overhead** compatibility via **compatibility layer** for legacy packages.
