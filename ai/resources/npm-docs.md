# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and dependencies; includes commands like `npm install`, `npm publish`, and `npm audit` for security checks.
- **Registry & Packages**: Centralized repository for JavaScript packages with versioning, dependency resolution, and metadata via `package.json`; supports scoped packages (e.g., `@scope/package`).
- **Security & Policies**: Enforces policies for package publishing (e.g., 2FA, provenance), threat mitigation (e.g., supply chain attacks), and organizational access controls.
