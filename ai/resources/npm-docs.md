# npm Docs

## Summary

- **npm CLI**: Command-line interface for interacting with the npm registry, enabling package installation, version management, and script execution via commands like `npm install`, `npm publish`, and `npm run`.
- **Package Management**: Supports modular JavaScript distribution via `package.json`, enabling dependency resolution, semantic versioning (`^`, `~`), and lifecycle hooks (`preinstall`, `postpublish`).
- **Security & Policies**: Enforces registry policies (e.g., package ownership, 2FA), mitigates supply-chain threats (e.g., typosquatting, dependency confusion), and integrates with tools like `npm audit` for vulnerability scanning.
