# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm packages, including installation (`npm install`), versioning (`npm version`), and publishing (`npm publish`) via registry interactions.
- **Package Registry**: Centralized repository for JavaScript packages with metadata (e.g., `package.json`) enabling dependency resolution, versioning, and semantic versioning (`^`, `~`, `*`).
- **Security Policies**: Enforces access controls via organizations, threat mitigation strategies (e.g., 2FA, package signing), and compliance policies for package publishing and consumption.
