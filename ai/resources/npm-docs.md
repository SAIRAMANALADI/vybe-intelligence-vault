# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and dependencies; includes commands like `npm install`, `npm publish`, and `npm audit` for security checks.
- **Registry & Packages**: Centralized repository for JavaScript packages with versioning, dependency resolution, and metadata (e.g., `package.json` specifications).
- **Security & Policies**: Enforces access controls (via organizations), threat mitigation (e.g., dependency scanning), and compliance rules for package publishing and usage.
