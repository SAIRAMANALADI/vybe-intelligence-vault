# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing Node.js packages, including installation (`npm install`), versioning (`npm version`), and publishing (`npm publish`).

- **Package Registry**: Centralized repository for Node.js packages (`npmjs.com`), supporting dependency resolution via `package.json` with semantic versioning (`^`, `~`, `*`).

- **Security Policies**: Enforces package signing, vulnerability scanning (`npm audit`), and access control via organizations, with threat mitigation for supply-chain attacks (e.g., typosquatting).
