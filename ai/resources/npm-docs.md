# npm Docs

## Summary

- **npm Registry & CLI**: Centralized package registry for JavaScript with a command-line interface (CLI) for package management, dependency resolution, and script execution.
- **Package Management**: Supports semantic versioning, dependency trees, and lifecycle scripts (e.g., `preinstall`, `postpublish`) for modular JavaScript/Node.js development.
- **Security & Policies**: Enforces registry policies (e.g., package ownership, 2FA), threat mitigation (e.g., dependency hijacking), and integrates with CI/CD pipelines for secure deployments.
