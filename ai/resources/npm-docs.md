# npm Docs

## Summary

- **npm CLI Architecture**: The npm Command Line Interface (CLI) is built on Node.js, utilizing its module system for package management, with core commands like `install`, `publish`, and `run` interacting directly with the npm registry via RESTful APIs.
- **Package Registry Protocol**: npm registry operates over HTTPS, using semantic versioning (semver) for dependency resolution, with package metadata (e.g., `package.json`) stored in a CouchDB backend for distributed access and replication.
- **Security & Threat Mitigations**: npm enforces package signing (via npm CLI + GPG), two-factor authentication (2FA) for publishers, and automated vulnerability scanning (e.g., `npm audit`) to mitigate supply-chain attacks like typosquatting or malicious dependencies.
