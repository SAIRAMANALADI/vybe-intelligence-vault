# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and dependencies via commands like `npm install`, `npm publish`, and `npm config`.

- **Security & Policies**: Enforces registry access controls, package signing (via `npm audit` and `npm ci`), and threat mitigation (e.g., dependency confusion attacks).
