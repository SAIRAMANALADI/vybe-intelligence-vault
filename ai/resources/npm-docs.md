# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and modules with commands like `npm install`, `npm publish`, and `npm audit`.
- **Registry & Packages**: Centralized repository for JavaScript packages with metadata, versioning, and dependency resolution via `package.json`.
- **Security & Policies**: Enforces policies (e.g., 2FA, scope restrictions) and mitigates threats (e.g., dependency confusion, malicious packages) via `npm audit` and registry safeguards.
