# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm packages, including installation (`npm install`), versioning (`npm version`), and publishing (`npm publish`) via a JavaScript-based registry.
- **Package Management**: Supports dependency resolution via `package.json`, semantic versioning (semver), and lifecycle scripts (`preinstall`, `postpublish`).
- **Security & Policies**: Enforces registry access controls, package signing (via npm provenance), and threat mitigation (e.g., dependency confusion attacks).
