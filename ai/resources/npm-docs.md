# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing Node.js packages, including installation (`npm install`), dependency management, and script execution via `package.json`.
- **Package Registry**: Centralized repository for Node.js packages (`npmjs.com`), enabling versioning, dependency resolution, and publishing via `npm publish`.
- **Security Policies**: Enforces access controls (e.g., `npm audit`, 2FA) and threat mitigations (e.g., package signing, scope restrictions) to mitigate supply-chain risks.
