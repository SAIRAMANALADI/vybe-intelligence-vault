# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm packages, including installation (`npm install`), versioning (`npm version`), and publishing (`npm publish`) with full registry interaction.

- **Packages & Modules**: npm packages are modular JavaScript/Node.js libraries with a `package.json` manifest defining dependencies, scripts, and metadata; modules are reusable code units within packages.

- **Threats & Mitigations**: npm enforces security policies (e.g., package signing, vulnerability scanning) and provides tools like `npm audit` to detect and remediate supply-chain risks (e.g., malicious dependencies).
