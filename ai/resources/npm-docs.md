# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and modules, enabling dependency installation, version control, and script execution via `package.json`.
- **Package Management**: Supports semantic versioning (`semver`) for dependency resolution, with features like `npm install`, `npm update`, and `npm audit` for security vulnerability checks.
- **Registry & Security**: Public registry (`registry.npmjs.org`) hosts over 2 million packages; policies enforce package ownership, publishing restrictions, and threat mitigation (e.g., 2FA, scope restrictions).
