# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and dependencies via `npm` commands (e.g., `install`, `publish`, `run`).
- **Package Management**: Supports semantic versioning (`semver`) for dependency resolution, lifecycle scripts (`preinstall`, `postpublish`), and scoped packages (`@scope/pkg`).
- **Security Policies**: Enforces registry policies (e.g., package ownership, 2FA), threat mitigations (e.g., malware scanning), and integration with CI/CD pipelines.
