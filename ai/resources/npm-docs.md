# npm Docs

## Summary

- **npm CLI**: Command-line interface for interacting with the npm registry, enabling package installation, version management, and script execution via commands like `npm install`, `npm update`, and `npm run`.

- **Registry & Packages**: Centralized repository for JavaScript packages/modules, supporting dependency resolution, semantic versioning, and scoped packages (e.g., `@scope/package`) for access control and organization.

- **Security & Policies**: Enforces policies via npm CLI flags (`--save-exact`), registry access controls, and threat mitigations (e.g., 2FA, package signing) to mitigate supply-chain risks like typosquatting or malicious dependencies.
