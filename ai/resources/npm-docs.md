# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and modules, including installation, versioning, and dependency resolution via `package.json`.

- **Package Registry**: Centralized repository for Node.js packages, supporting semantic versioning, scoped packages, and metadata (e.g., `README`, `LICENSE`) for distribution.

- **Security & Policies**: Enforces access control (via organizations), threat mitigation (e.g., dependency scanning), and compliance policies for package publishing and usage.
