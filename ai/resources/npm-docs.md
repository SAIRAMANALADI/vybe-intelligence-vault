# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing Node.js packages, including installation (`npm install`), versioning (`npm version`), and publishing (`npm publish`) via registry interactions.

- **Package Registry**: Centralized repository for Node.js packages (public/private), enforcing semantic versioning (semver) and dependency resolution via `package.json` manifest.

- **Security Policies**: Enforces integrity via checksums (SHA-512), package signing (provenance), and threat mitigation (e.g., dependency confusion, typosquatting) with automated scans and manual reviews.
