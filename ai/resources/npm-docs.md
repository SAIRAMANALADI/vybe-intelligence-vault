# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registry interactions, package installations, and project dependencies via commands like `npm install`, `npm publish`, and `npm audit`.
- **Package Management**: Supports semantic versioning (`semver`) for dependency resolution, lifecycle scripts (e.g., `preinstall`, `postpublish`), and scoped packages (`@scope/package`) for namespace isolation.
- **Security & Policies**: Enforces registry policies (e.g., 2FA, package provenance), threat mitigation (e.g., supply chain attacks via `npm audit fix`), and integration with CI/CD pipelines for automated dependency checks.
