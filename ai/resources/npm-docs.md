# npm Docs

## Summary

- **npm CLI**: Command-line interface for interacting with the npm registry, enabling package installation, version management, and script execution via commands like `npm install`, `npm publish`, and `npm run`.

- **Package Ecosystem**: npm registry hosts over 2 million packages, supporting modular development via `package.json` for dependency resolution, versioning, and lifecycle scripts.

- **Security & Policies**: Enforces access control via organizations, integrates threat mitigation strategies (e.g., 2FA, package signing), and adheres to policies for publishing, licensing, and vulnerability reporting.
