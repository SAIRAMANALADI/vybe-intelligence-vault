# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing Node.js packages, including `npm install`, `npm publish`, and dependency resolution via `package.json`.
- **Registry & Packages**: Centralized repository for Node.js modules with versioning, dependency management, and semantic versioning (semver) support.
- **Security & Policies**: Enforces package signing, access control, and threat mitigation (e.g., supply chain attacks, unauthorized publishing) via npm’s policies.
