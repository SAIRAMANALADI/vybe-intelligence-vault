# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm packages, including installation (`npm install`), versioning (`npm version`), and publishing (`npm publish`).
- **Package Registry**: Centralized repository for Node.js packages, supporting dependency resolution via `package.json` and semantic versioning (semver).
- **Security Policies**: Enforces registry policies (e.g., package ownership, 2FA) and mitigates threats like typosquatting via scoped packages and integrity checks.
