# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and dependencies via commands like `npm install`, `npm publish`, and `npm audit`.
- **Package Management**: Supports modular JavaScript distribution via `package.json` for dependency resolution, versioning, and lifecycle scripts (e.g., `preinstall`, `postpublish`).
- **Security & Policies**: Enforces registry policies (e.g., 2FA, scope restrictions) and provides threat mitigation tools like `npm audit` for vulnerability scanning and dependency analysis.
