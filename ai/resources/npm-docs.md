# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing Node.js packages, including installation (`npm install`), dependency management (`package.json`), and script execution (`npm run`).
- **Package Registry**: Centralized repository for Node.js packages (`npmjs.com`), enabling versioning, publishing (`npm publish`), and dependency resolution via semantic versioning (`^`, `~`).
- **Security & Policies**: Enforces registry policies (e.g., 2FA, package ownership), threat mitigation (e.g., `npm audit` for vulnerabilities), and organizational controls (e.g., scoped packages `@org/pkg`).
