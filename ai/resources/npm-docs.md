# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing Node.js packages, including installation (`npm install`), dependency management (`package.json`), and script execution (`npm run`).

- **Registry & Packages**: Centralized repository for Node.js modules with versioning, dependency resolution, and semantic versioning (semver) support for package publishing (`npm publish`) and consumption.

- **Security & Policies**: Enforces registry policies (e.g., package ownership, 2FA), mitigates supply-chain threats (e.g., typosquatting, malicious dependencies), and integrates with vulnerability scanners (e.g., `npm audit`).
