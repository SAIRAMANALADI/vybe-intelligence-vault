# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing Node.js packages, including installation (`npm install`), versioning (`npm version`), and publishing (`npm publish`) with registry interactions via HTTPS.
- **Registry & Packages**: Centralized package repository (`registry.npmjs.org`) supporting semantic versioning, dependency resolution, and lifecycle scripts (`preinstall`, `postpublish`).
- **Security & Policies**: Enforces package signing, access controls (scopes, tokens), and threat mitigations (e.g., dependency confusion, malicious code detection) via npm’s audit and policy frameworks.
