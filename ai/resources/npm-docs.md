# npm Docs

## Summary

- **npm CLI**: Command-line interface for managing npm registries, packages, and modules, enabling dependency installation, version control, and script execution via `package.json`.
- **Package Registry**: Centralized repository for JavaScript packages, supporting versioning, dependency resolution, and metadata management (e.g., `npm publish`, `npm install`).
- **Security Policies**: Defines threat mitigations (e.g., package signing, scope restrictions) and organizational controls (e.g., two-factor authentication, access tokens) to mitigate supply-chain risks.
