# WordPress Developer Resources | Developer.WordPress.org

## Summary

- **Core Platform**: WordPress is an open-source CMS with a modular architecture, supporting themes, plugins, and block-based editing via Gutenberg; latest API changes documented in [WordPress 7.0](https://developer.wordpress.org/reference/since/7.0.0/).

- **Developer Ecosystem**: Provides REST API, WP-CLI, coding standards, and a block editor SDK; contributors can engage via [Make WordPress](https://make.wordpress.org/) for core/docs/plugin/theme development.

- **Resources & Community**: Hosts official docs, developer blog, WordPress Playground (browser-based WP), and multimedia content (WordPress.tv, Openverse); social channels include X, Mastodon, and YouTube for updates.
