# Bootstrap · The most popular HTML, CSS, and JS library in the world.

## Summary

- **Bootstrap v5.3.8** supports modular Sass customization, enabling selective import of components, variables, maps, functions, and mixins for optimized builds.
- **CSS Variables** in Bootstrap 5 allow runtime theme adjustments (e.g., colors, fonts) via scoped `:root` variables (e.g., `--bs-body-font-family`) without recompilation.
- **JavaScript plugins** (e.g., modals, tooltips) are jQuery-free, using HTML `data` attributes for declarative initialization and modular imports for granular control.
