# Firebase Extensions

## Summary

- **Deprecation Timeline**: Firebase Extensions will be deprecated and shut down on **March 31, 2027**, with key management features unavailable post-deprecation; migration tools and guidance will be released in **September 2026**.

- **Technical Architecture**: Extensions are **pre-packaged Cloud Functions** triggered by Firebase/Google Cloud events (e.g., Firestore writes, HTTPS requests), defined via an `extension.yaml` file specifying APIs, roles, resources, and parameters.

- **Isolation & Scalability**: Extensions run in isolated backend environments with **least-privilege service accounts**, auto-scaling resources while avoiding client-side exposure or manual server management.
