# Firebase Extensions

## Summary

- **Deprecation Timeline**: Firebase Extensions will be deprecated on **March 31, 2027**, with key management features disabled; existing extensions will continue running. Migration tools and guidance will be released in **September 2026**.

- **Technical Architecture**: Extensions use `extension.yaml` to define APIs, access roles, resources, and parameters, executing via isolated Cloud Functions with dedicated service accounts for security and scalability.

- **Lifecycle Management**: Extensions can be installed, reconfigured, updated, or uninstalled via Firebase CLI/console, with each instance having unique configurations and provisioned resources.
