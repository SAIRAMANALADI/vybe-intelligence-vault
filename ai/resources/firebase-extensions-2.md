# Firebase Extensions

## Summary

- Firebase Extensions will be deprecated and fully shut down on **March 31, 2027**, with key management features unavailable after this date, though pre-installed extensions will continue running.
- Extensions are pre-packaged backend solutions triggered by events (e.g., Firestore writes, HTTPS requests) and defined via an `extension.yaml` file specifying APIs, roles, resources, and parameters.
- Each extension instance operates with isolated service accounts, configurable parameters, and zero maintenance overhead, scaling automatically via Cloud Functions for Firebase.
