# chrome-extensions-samples/api-samples/userScripts at main · GoogleChrome/chrome-extensions-samples · GitHub

## Summary

- The `chrome.userScripts` API enables JavaScript injection into web pages via Chrome extensions, requiring developer mode to be enabled.
- Supports injecting both external files and arbitrary code dynamically via the `chrome.userScripts.update()` method.
- Extension triggers script injection upon user interaction (e.g., clicking the action icon) and updates registrations when options change.
