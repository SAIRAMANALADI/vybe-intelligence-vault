# Issues | Google Issue Tracker | Google for Developers

## Summary

- Google Issue Tracker organizes issues into components, each with a dedicated details page for tracking activity, comments, and updates, requiring fields like **Component**, **Title**, **Priority**, and **Type** for new issues.
- Issues are categorized by **Type** (e.g., Bug, Feature Request, Vulnerability) and prioritized via **Priority** levels (P0–P4), with **Status** tracking resolution (e.g., New, In Progress, Fixed).
- Edit levels (**Closing**, **Major**, **Minor**, **Silent**) control visibility in history and email notifications, while **Access Limits** restrict visibility/commenting to explicitly listed identities.
