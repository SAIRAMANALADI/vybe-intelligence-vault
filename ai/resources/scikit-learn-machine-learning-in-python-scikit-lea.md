# scikit-learn: machine learning in Python — scikit-learn 0.16.1 documentation

## Summary

- **Modular Design**: scikit-learn is built on NumPy, SciPy, and matplotlib, offering a consistent, unified API for machine learning tasks (e.g., classification, regression, clustering) with minimal dependencies.

- **Algorithmic Breadth**: Implements a wide range of supervised/unsupervised algorithms (e.g., SVM, Random Forests, k-means) with optimized Cython/C++ backends for performance.

- **Tooling Integration**: Provides utilities for model selection (e.g., GridSearchCV), preprocessing (e.g., StandardScaler), and evaluation (e.g., cross-validation metrics) with seamless interoperability.
