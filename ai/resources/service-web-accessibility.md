## Summary

- **Web Accessibility Services**: Cornell's Custom Web and Application Development offers evaluation, remediation, and support for web accessibility compliance (e.g., WCAG, Section 508).
- **Tools & Requests**: Includes SiteImprove integration, accessibility audits, remediation requests, and general support via Cornell’s TDX portal.
