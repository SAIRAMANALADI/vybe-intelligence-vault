# webm/libwebp - Git at Google

## Summary

- **Repository**: `libwebp` is an open-source WebP image codec library hosted on [Chromium's Gitiles](https://chromium.googlesource.com/webm/libwebp/), with branches (e.g., `main`, `0.5.1`) and tags (e.g., `v1.6.0`, `webp-rfc9649`) for version control.

- **Functionality**: Provides encoding/decoding tools (`cwebp`, `dwebp`) and APIs for WebP image compression/decompression, supporting both static and animated images under the WebM project license (with additional PATENTS grant).

- **Development**: Includes build/documentation (`building.md`, `tools.md`, `api.md`), contribution guidelines (`CONTRIBUTING.md`), and issue tracking via WebM Project’s tracker for bugs/security reports.
