# webm/libwebp - Git at Google

## Summary

- **Repository**: `libwebp` is an open-source WebP image codec library hosted on Google's Gitiles, part of the WebM project, with branches (e.g., `main`, `0.5.1`) and tags (e.g., `v1.6.0`, `webp-rfc9649`) for version control.

- **Functionality**: Provides encoding/decoding tools (`cwebp`, `dwebp`) and APIs for WebP image format support, including DSP optimizations (e.g., AVX2, typo fixes in constants like `85627`).

- **Licensing & Contributions**: Released under WebM project license (see `COPYING`/`PATENTS`), with contributions via patches to the [issue tracker](https://issues.webmproject.org) and community engagement via `webp-discuss@webmproject.org`.
