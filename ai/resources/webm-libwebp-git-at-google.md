# webm/libwebp - Git at Google

## Summary

- **Repository**: `libwebp` is a WebP image codec library hosted on [Chromium Googlesource](https://chromium.googlesource.com/webm/libwebp), with branches (e.g., `main`, `0.5.1`) and tags (e.g., `v1.6.0`, `webp-rfc9649`) for version control.

- **Functionality**: Provides encoding/decoding tools (`cwebp`, `dwebp`) and APIs for WebP image compression/decompression, supporting both static and animated images under the WebM project license.

- **Development**: Includes build documentation, contribution guidelines (`CONTRIBUTING.md`), and an issue tracker ([WebM Project](https://issues.webmproject.org)) for bug reports and patches.
