# webm/libwebp - Git at Google

## Summary

- **Repository**: `libwebp` is a WebP image codec library hosted on Chromium's Git repository, supporting branches (e.g., `main`, `0.5.1`) and tags (e.g., `v1.6.0`, `webp-rfc9649`) for versioned releases.

- **Functionality**: Provides encoding/decoding tools (`cwebp`, `dwebp`) and APIs for WebP image compression/decompression, with additional utilities in the `examples/` directory for image/animation processing.

- **Licensing & Contributions**: Released under the WebM project license (with a PATENTS file for IP rights), accepting patches via the [issue tracker](https://issues.webmproject.org/) and [CONTRIBUTING.md](https://chromium.googlesource.com/webm/libwebp/+/HEAD/CONTRIBUTING.md).
