# webm/libwebp - Git at Google

## Summary

- **Library & Tools**: `libwebp` provides a C library for encoding/decoding WebP images, along with CLI tools `cwebp` (compression) and `dwebp` (decompression).
- **Branches/Tags**: Hosted on Chromium Gitiles with active branches (e.g., `main`, `0.5.1`) and tagged releases (e.g., `v1.6.0`, `webp-rfc9649`).
- **Build & APIs**: Supports cross-platform builds (see `building.md`), exposes APIs (see `api.md`), and includes example tools in `examples/` for encoding/decoding animations and metadata extraction.
