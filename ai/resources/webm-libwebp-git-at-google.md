# webm/libwebp - Git at Google

## Summary

- **Repository Overview**: `libwebp` is an open-source WebP image codec library (v1.6.0) hosted on Chromium's Gitiles, providing encoding/decoding tools (`cwebp`, `dwebp`) and APIs under the same license as the WebM project.
- **Branches/Tags**: Supports multiple stable branches (e.g., `0.5.1`) and tagged releases (e.g., `v1.6.0`, `webp-rfc9649`), with active development in `main` and frequent sanitizer/bugfix commits (e.g., SSE2 optimizations, reverted CLI defaults).
- **Build/Usage**: Requires building from source (see `doc/building.md`), with tools/examples in `examples/` for encoding/decoding, and APIs documented in `doc/api.md`; contributions via Gerrit and issue tracking via WebM project tracker.
