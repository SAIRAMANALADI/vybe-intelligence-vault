# webm/libwebp - Git at Google

## Summary

- **Repository Overview**: `libwebp` is a WebP image codec library hosted on Chromium's Git server, providing encoding/decoding tools (`cwebp`/`dwebp`) and APIs for WebP format support under the WebM project license.
- **Branches/Tags**: Mainline development (`main`) and stable releases (e.g., `v1.6.0`, `v0.5.1`) are available, with additional tags like `webp-rfc9649` for RFC compliance.
- **Build & Contribution**: Requires building via documented steps; contributions accepted via patches to the issue tracker or email (`webp-discuss@webmproject.org`).
