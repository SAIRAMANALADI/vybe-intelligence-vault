# webm/libwebp - Git at Google

## Summary

- **Repository**: `libwebp` is a WebP image codec library hosted on Chromium's Googlesource, with branches (e.g., `main`, `0.5.1`) and tags (e.g., `v1.6.0`, `webp-rfc9649`) for versioning.

- **Functionality**: Provides encoding/decoding tools (`cwebp`, `dwebp`) and APIs for WebP image compression/decompression, supporting both static and animated images.

- **Licensing & Contributions**: Released under WebM project license (see `COPYING`/`PATENTS`), with bug tracking via WebM issue tracker and contribution guidelines in `CONTRIBUTING.md`.
