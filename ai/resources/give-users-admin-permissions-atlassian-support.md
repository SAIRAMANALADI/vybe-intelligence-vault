# Give users admin permissions | Atlassian Support

## Summary

- **Admin Role Assignment**: Admin roles (app admin, user access admin, site admin, organization admin) are granted via Atlassian Administration > Directory > Users, with granular permissions tied to specific apps or sites; app admins cannot access Atlassian Administration.

- **Group-Based Delegation**: Default admin groups (`-admins-`, `-user-access-admins-`, `org-admins`/`site-admins`) auto-assign roles when users are granted app access; renaming groups is supported but requires manual updates.

- **Permission Verification**: Post-assignment, user profiles in Atlassian Administration reflect updated roles; inconsistencies may require backend checks or Atlassian support escalation due to conflicting permissions.
