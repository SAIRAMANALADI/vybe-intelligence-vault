# CommonMark Spec

## Summary

- **Specification Overview**: CommonMark is a formal specification for Markdown, maintained by John MacFarlane under CC BY-SA 4.0, with the latest stable version (0.31.2) released on 2024-01-28.

- **Versioning & Resources**: The spec includes a changelog, JSON test cases for each version (e.g., `spec.json`), and a discussion forum for community input.

- **Tooling & Accessibility**: Provides an interactive "dingus" for live Markdown rendering, a GitHub repository for contributions, and historical version archives dating back to 0.5 (2014-10-25).
