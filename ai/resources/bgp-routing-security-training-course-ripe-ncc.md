# BGP Routing Security Training Course - RIPE NCC

## Summary

- **BGP Security Course Overview**: One-day RIPE NCC training restricted to members, covering BGP vulnerabilities, threats (e.g., route leaks, hijacks), and mitigation techniques (e.g., RPKI, IRR, route filtering) with hands-on exercises.
- **Prerequisites**: Requires CLI proficiency, TCP/IP/IP routing knowledge, BGP protocol expertise (attributes, communities, relationships), and CIDR understanding.
- **Key Learning Goals**: Master BGP incident prevention (session security, filtering), IRR/RPKI deployment (ROA creation, origin validation), and future-proofing BGP against evolving threats.
