# Privacy and Data Collection Policy | Linagora

## Summary

- **Data Processing Principles**: LINAGORA adheres to GDPR principles including purpose limitation, data minimization, limited retention, and integrity/confidentiality; personal data is processed strictly for specified purposes, minimized to necessary scope, retained only as long as required, and secured against unauthorized access or loss.

- **Data Collection & Usage**: Collects minimal personal data (e.g., name, email, messages) for service functionality, with consent assumed for essential processing; non-essential data (e.g., statistical/cookie data) requires explicit consent and is processed via Matomo Analytics for site improvement and misuse detection.

- **Retention & Compliance**: Retains personal data for a maximum of 13 months post-collection, with deletion/anonymization upon purpose fulfillment or request; users can request corrections/deletion via `dpo@linagora.com` and file complaints with CNIL (France).
