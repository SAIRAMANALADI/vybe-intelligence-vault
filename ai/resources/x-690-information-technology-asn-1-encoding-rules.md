# X.690 : Information technology - ASN.1 encoding rules: Specification of Basic Encoding Rules (BER), Canonical Encoding R

## Summary

- **X.690** defines **Basic Encoding Rules (BER)**, **Canonical Encoding Rules (CER)**, and **Distinguished Encoding Rules (DER)** for ASN.1 data serialization, ensuring standardized binary encoding of structured data.

- **Current standard (2021)** aligns with **ISO/IEC 8825-1:2021**, replacing prior versions (e.g., 2015, 2008) and includes **Errata 1 (2021)** for corrections.

- **Superseded versions** (e.g., 2015, 2008, 2002) and amendments (e.g., EXTENDED-XER, time type support) are archived, reflecting iterative refinements in encoding rules.
