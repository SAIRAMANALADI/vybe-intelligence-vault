# Vimwiki by vimwiki

## Summary

- **Multi-syntax support**: Vimwiki supports three markup syntaxes (Vimwiki's native, Markdown, MediaWiki), with features like inter-page linking, HTML export, and tag-based navigation.
- **Key bindings & commands**: Default mappings include `ww` (open index), `` (follow/create link), and commands like `:Vimwiki2HTML` for page/HTML conversion.
- **Prerequisites & installation**: Requires `nocompatible`, `filetype plugin on`, and `syntax on` in `.vimrc`; installable via plugin managers (e.g., Vim-Plug, Pathogen) or manual extraction.
