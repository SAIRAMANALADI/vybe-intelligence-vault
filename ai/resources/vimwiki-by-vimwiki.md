# Vimwiki by vimwiki

## Summary

- **Multi-syntax support**: Vimwiki supports three markup syntaxes (Vimwiki, Markdown, MediaWiki), enables HTML export, and provides inter-file linking, tagging, and search functionality.
- **Structured editing**: Supports indented lists (bulleted/numbered), auto-formatted tables, and quick manipulation of list items via Vim keybindings.
- **Integration & workflow**: Default keybindings (`ww`, `Enter`, `Backspace`) enable rapid navigation between wiki pages, while commands like `:Vimwiki2HTML` facilitate content conversion. Requires `nocompatible`, `filetype plugin on`, and `syntax on` in `.vimrc`.
