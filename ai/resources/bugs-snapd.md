# Bugs : snapd

## Summary

- **User directory handling**: `/etc/adduser.conf` lacks default configuration for `extra_users`, causing permission-related issues in snapd-managed environments.
- **AppArmor and mount namespace issues**: Multiple bugs (e.g., `#1818241`, `#1828354`) report failures in AppArmor profile unloading and incorrect mount event propagation, leading to security and stability problems.
- **Snap refresh and dependency conflicts**: Bugs like `#1594330` and `#1654362` highlight failures in snap refresh logic and gadget snap configuration updates, causing inconsistent system states.
