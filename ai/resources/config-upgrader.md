# Config upgrader

## Summary

- **Tool Purpose**: Converts Dovecot 2.3 Community Edition configurations to Dovecot 2.4 Community Edition, supporting specific config files (e.g., `dovecot.conf`, `dovecot-auth-sql.conf.ext`).
- **Limitations**: Not 100% accurate; manual verification required. Unsupported configurations may fail. Dovecot 2.3 Pro users must contact Open-Xchange for migration.
- **Support & Warranty**: Issues reportable to `dovecot-ce@dovecot.org`; tool provided "as-is" with no explicit warranty (Open-Xchange GmbH, 2025).
