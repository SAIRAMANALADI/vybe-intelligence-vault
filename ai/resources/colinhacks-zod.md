# colinhacks/zod

## Summary

- **TypeScript-first schema validation**: Zod provides a TypeScript-centric approach to runtime and compile-time schema validation, enabling seamless integration with TypeScript's static type system.

- **Static type inference**: Schemas defined in Zod automatically infer corresponding TypeScript types, eliminating manual type definitions and ensuring type safety across validation boundaries.

- **Comprehensive validation ecosystem**: Supports complex validation scenarios (e.g., unions, discriminated unions, custom refinements) while maintaining performance and developer ergonomics.
