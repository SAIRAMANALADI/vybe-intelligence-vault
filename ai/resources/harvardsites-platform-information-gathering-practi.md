# HarvardSites Platform Information Gathering Practices Statement | Harvard Web Publishing

## Summary

- **Third-Party Monitoring Tools**: Utilizes tools like New Relic, Splunk, and Google Analytics to collect performance metrics (e.g., server response time, page load speed, database performance) for Drupal/WordPress-based platforms, enabling troubleshooting and optimization.

- **IP-Based Diagnostics**: IP addresses are logged to identify heavily used site sections and Harvard network traffic patterns, linked to performance metrics but not to personally identifiable information (PII).

- **Site-Specific Variability**: Individual HarvardSites may implement additional data collection practices governed by their own privacy policies, distinct from the platform-wide technical monitoring described.
