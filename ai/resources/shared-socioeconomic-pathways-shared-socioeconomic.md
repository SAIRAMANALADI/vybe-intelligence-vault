# Shared Socioeconomic Pathways | Shared Socioeconomic Pathways | Scenario Explorer hosted by IIASA

## Summary

- **SSPs**: Five narrative-based scenarios (SSP1-SSP5) quantifying societal, economic, and demographic trajectories to 2100, spanning high-to-low challenges for adaptation and mitigation.
- **IAM Quantifications**: Integrated Assessment Models (IAMs) translate SSP narratives into quantitative projections (e.g., carbon intensity, GDP) via the IIASA SSP database (v2, 2018).
- **Extensions**: SSP-Extensions expand drivers to include unmodeled socio-economic dimensions (e.g., inequality, governance) via the IIASA SSP-Extensions Explorer.
