# Introduction - Affinity Developer Documentation

## Summary

- **RESTful API v2**: Provides a modern, RESTful interface for internal apps, automated workflows, third-party integrations, and tech stack connectivity, replacing the legacy v1 API.

- **Partial Feature Parity**: API v2 is not yet fully equivalent to v1; ongoing development aims to match all v1 functionality over time.

- **License Restriction**: Affinity APIs are available only on select license types; consult support or your Customer Success Manager for eligibility.
