# AppIndicator and KStatusNotifierItem Support - GNOME Shell Extensions

## Summary

- **Purpose**: Adds AppIndicator, KStatusNotifierItem, and legacy Tray icon support to GNOME Shell via a GNOME Shell extension, enabling compatibility with applications relying on these legacy systems.

- **Technical Details**:
  - Maintained by [3v1n0](https://extensions.gnome.org/accounts/profile/3v1n0) with **2,989,708 downloads**.
  - Supports GNOME Shell versions **3.6 to 50** (as of latest versions).
  - Hosted on [GitHub](https://github.com/ubuntu/gnome-shell-extension-appindicator).

- **Versioning & Compatibility**:
  - Latest active versions (e.g., **64**, **63**) support GNOME Shell **45–50**.
  - Rejected/older versions (e.g., **62**, **55**) may lack updates or fail validation.
