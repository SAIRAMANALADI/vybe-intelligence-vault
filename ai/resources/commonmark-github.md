# CommonMark · GitHub

## Summary

- **CommonMark Spec**: A formal specification for Markdown with reference implementations in C and JavaScript, maintained in the [`commonmark-spec`](https://github.com/commonmark/commonmark-spec) repository (Python-based).
- **Multi-Language Libraries**: Provides parsing and rendering libraries for CommonMark in multiple languages, including [`cmark`](https://github.com/commonmark/cmark) (C), [`commonmark-java`](https://github.com/commonmark/commonmark-java) (Java), and [`commonmark.js`](https://github.com/commonmark/commonmark.js) (JavaScript).
- **Official Resources**: Hosts official documentation, tutorials, and web implementations via [`commonmark-web`](https://github.com/commonmark/commonmark-web) and [`commonmark-spec-web`](https://github.com/commonmark/commonmark-spec-web) (HTML-based).
