# Browse in Incognito mode - Computer - Google Chrome Help

## Summary

- **Session Isolation**: Chrome's Incognito mode creates a separate browsing session that terminates upon closing all Incognito windows, temporarily storing cookies/site data only for the session duration before purging them.
- **Data Retention Exclusions**: Bookmarks, downloaded files, and reading list items persist post-session, while third-party cookies are blocked by default (configurable per-site).
- **Privacy Limitations**: Incognito mode does not obscure user activity from websites, network administrators, or Google services, which may still collect and share data for advertising purposes.
