# Browse in Incognito mode - Computer - Google Chrome Help

## Summary

- **Session Isolation**: Incognito mode in Chrome initiates a separate browsing session that terminates upon closing all Incognito windows, temporarily storing cookies and site data only for the session duration before deletion.
- **Data Retention Exclusions**: While browsing data is purged post-session, bookmarks, downloads, and reading list items persist across regular and Incognito sessions.
- **Third-Party Cookie Blocking**: Incognito mode defaults to blocking third-party cookies, requiring explicit temporary allowance for sites dependent on them, enhancing privacy against cross-site tracking.
