# Create and manage a merge proposal - Launchpad manual

## Summary

- **Merge Proposal Workflow**: Initiate via Launchpad's `Propose for merging into another branch` link on your branch's overview page; notifies target branch owners and reviewers, with statuses like `Work in progress`, `Needs review`, `Approved`, or `Rejected` governed by reviewer permissions.

- **Code Review Process**: Open to all Launchpad users; involves threaded discussions, voting (e.g., `+1`, `-1`, `UI` tags), and email-based participation with commands like `review approve`, `review disapprove`, or `merge approved` (signed via GPG/DKIM for status changes).

- **Email Command Interface**: Commands must start with a space; supports review (`approve`, `disapprove`, `needs-fixing`), merge (`approved`, `rejected`), and reviewer additions (`reviewer <username>`), with implicit `review approve` for `merge approved` unless overridden.
