# The Cygwin-Apps homepage

## Summary

- **Git Access & Cloning**: Projects are hosted in `cygwin-apps` git repositories, accessible via `git://cygwin.com/git/cygwin-apps/project.git`; commit access uses SSH (`ssh://username@cygwin.com/git/cygwin-apps/project.git`).

- **Core Utilities**: Includes `cygport` (package building tool), `setup` (Cygwin installer/updater), `rebase` (DLL rebasing), `csih` (service installation helper), and `cygrunsrv` (Windows service wrapper for Unix daemons).

- **Key Projects**: `base-cygwin` (initial setup), `base-files` (system configs), `calm` (server-side packaging maintenance), `editrights` (privilege management), and `windows-default-manifest` (mandatory executable manifest for Windows 8.1+).
