# Comprehensive Data Protection | Atlassian

## Summary

- **Multi-layered security framework**: Implements detections program, secure software development lifecycle (SSDLC), external penetration testing, and zero-trust IAM via Atlassian Guard (SSO/MFA, privileged access management).
- **Enterprise-grade compliance & resilience**: Holds certifications (SOC 2, ISO 27001, PCI DSS, FedRAMP) with redundant AWS-hosted infrastructure, cross-AZ failover, and defined SLAs for high availability.
- **Granular data protection controls**: Provides backup/restore, delayed deletion, site resurrection, DPA/FAQs for data processing, and privacy policy transparency with user-managed access policies.
