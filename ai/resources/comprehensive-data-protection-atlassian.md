# Comprehensive Data Protection | Atlassian

## Summary

- **Security & Compliance**: Atlassian employs a layered security approach with SOC 2, ISO 27001, PCI DSS, and FedRAMP certifications, alongside secure SDLC, penetration testing, and zero-trust IAM via Atlassian Guard for SSO/MFA enforcement.

- **Data Protection & Resilience**: Data is hosted on AWS with cross-AZ redundancy, automated backups, delayed deletion, and failover capabilities; privacy controls include DPAs, GDPR-aligned processing, and transparent user data management.

- **Risk & Incident Response**: Proactive measures include a vulnerability detection program, security advisories, vendor risk questionnaires, and enterprise-grade recovery tools (e.g., site resurrection, backup/restore manager).
