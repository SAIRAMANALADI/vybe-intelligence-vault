# Comprehensive Data Protection | Atlassian

## Summary

- **Security & Compliance**: Atlassian employs a layered security approach including SOC 2 Type II, ISO 27001, PCI DSS, and FedRAMP certifications, alongside secure software development practices, external penetration testing, and a zero-trust IAM framework via Atlassian Guard.

- **Data Protection & Recovery**: Cloud infrastructure hosted on AWS with multi-zone redundancy, automated backups, delayed deletion, and failover capabilities; adheres to strict privacy policies (GDPR, CCPA) with transparent data processing controls.

- **Resilience & Monitoring**: Proactive security measures such as Atlassian’s Detections Program, vendor risk assessments, and real-time security advisories; maintains a 99.9% SLA for cloud services with continuous compliance monitoring.
