# Create incoming webhooks with Workflows for Microsoft Teams | Microsoft Support

## Summary

- **Incoming webhooks** in Microsoft Teams enable external applications to post content to chats/channels via HTTP POST requests, supporting automation and notifications workflows.

- **Authentication types** for webhook triggers include: unauthenticated (anyone), tenant-wide (any user in org), or specific users (restricted access).

- **Workflow setup** involves selecting a trigger (`When a Teams webhook request is received`), defining the target (chat/channel), and configuring actions (e.g., `Post card in chat or channel`) with an auto-generated HTTP POST URL for external integrations.
