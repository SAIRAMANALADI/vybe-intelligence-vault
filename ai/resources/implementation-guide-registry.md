# Implementation Guide Registry

## Summary

- **FHIR Specification**: A platform specification defining capabilities and ecosystem for healthcare interoperability, enabling diverse solutions through structured data exchange standards.
- **Implementation Guides**: Community-driven extensions (e.g., national standards, vendor consortiums) that define specific use cases for FHIR capabilities in targeted data exchanges or problem-solving scenarios.
- **Registry & Hosting**: Centralized registry ([hl7.org/fhir/registry](http://hl7.org/fhir/registry)) catalogs implementation guides, with submission process ([Adding an Implementation Guide](http://www.fhir.org/guides/submit.html)) for community contributions.
