# The Apache Software Foundation · GitHub

## Summary

- **Non-profit OSS stewardship**: ASF, a 501(c)(3) nonprofit, hosts hundreds of open-source projects under the Apache License 2.0, emphasizing community-driven development over code-centric governance.

- **Security compliance**: ASF projects adhere to a structured [vulnerability handling process](https://apache.org/security/#vulnerability-handling) for coordinated disclosure and mitigation.

- **GitHub-hosted repositories**: ASF maintains a GitHub organization where project codebases are publicly accessible, ensuring transparency and collaborative contributions.
