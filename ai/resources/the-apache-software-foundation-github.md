# The Apache Software Foundation · GitHub

## Summary

- **Non-profit Governance**: ASF is a 501(c)(3) nonprofit providing infrastructure and legal support for hundreds of open-source projects under the "community over code" principle.

- **Licensing & Repositories**: All projects in this GitHub organization are released under the Apache License 2.0, with code hosted in ASF-managed repositories.

- **Security Compliance**: ASF enforces a structured [vulnerability handling process](https://apache.org/security/#vulnerability-handling) for all projects.
