# The Linux man-pages project

## Summary

- **Scope**: The Linux *man-pages* project documents Linux kernel and C library (primarily GNU C Library/glibc) interfaces used by user-space programs, including variations in other Linux C libraries where documented.

- **Resources**: Provides Git repository ([git](https://git.kernel.org/pub/scm/docs/man-pages/)), conventions guide ([PDF](https://www.alejandro-colomar.es/share/dist/man-pages/git/HEAD/man-pages-HEAD.pdf#man-pages.7)), mailing list, archives, releases ([mirrors](https://mirrors.edge.kernel.org/pub/linux/docs/man-pages/)), and online documentation ([man7.org](https://man7.org/linux/man-pages/index.html)).

- **Maintenance**: Includes project maintenance guidelines ([link](https://www.kernel.org/doc/man-pages/maintaining.html)) and a list of missing pages ([link](https://www.kernel.org/doc/man-pages/missing_pages.html)).
