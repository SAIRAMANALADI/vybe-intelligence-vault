# The Linux man-pages project

## Summary

- Official documentation repository for Linux kernel and C library (glibc) user-space interfaces, with supplementary notes on variations in other Linux C libraries.
- Maintained via Git (kernel.org) with release artifacts hosted on mirrors.edge.kernel.org, including PDF manuals and online HTML pages.
- Project governance includes maintenance guidelines, a list of missing pages, and community resources (mailing list, archives, contributing guidelines).
