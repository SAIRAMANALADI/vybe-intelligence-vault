# The Linux man-pages project

## Summary

- **Scope**: Documents Linux kernel and C library (primarily GNU C Library/glibc) interfaces used by user-space programs, including variations in other Linux C libraries where known.
- **Resources**: Provides Git repository, README, contributing guidelines, man-page conventions (PDF), mailing list, archives, release tarballs, a book, and online man-page access via [man7.org](https://man7.org/linux/man-pages/index.html).
- **Maintenance**: Includes dedicated pages for project maintenance ([link](https://www.kernel.org/doc/man-pages/maintaining.html)) and tracking missing man pages ([link](https://www.kernel.org/doc/man-pages/missing_pages.html)).
