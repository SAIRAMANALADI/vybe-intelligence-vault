# The Linux man-pages project

## Summary

- **Scope**: Documents Linux kernel and C library (primarily GNU C Library/glibc) interfaces used by user-space programs, including variations in other Linux C libraries where known.

- **Resources**: Maintained via [Git](https://git.kernel.org/pub/scm/docs/man-pages/), with conventions outlined in [man-pages(7)](https://www.alejandro-colomar.es/share/dist/man-pages/git/HEAD/man-pages-HEAD.pdf#man-pages.7), and releases hosted at [kernel.org](https://mirrors.edge.kernel.org/pub/linux/docs/man-pages/).

- **Access**: Available online at [man7.org](https://man7.org/linux/man-pages/index.html), with archives at [lore.kernel.org](https://lore.kernel.org/linux-man/) and a [book](https://mirrors.edge.kernel.org/pub/linux/docs/man-pages/book/) version.
