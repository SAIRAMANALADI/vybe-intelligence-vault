# NLNOG - Netherlands Network Operator Group

## Summary

- **NLNOG Foundation** is a Dutch non-profit organization facilitating the Dutch and global Internet engineering community through events, cooperation projects (e.g., NLNOG RING), and tool development for network debugging and BGP analysis.
- **Key Tools & Services**: Maintains critical infrastructure tools including [NLNOG RING](https://ring.nlnog.net/) (global debugging network), [NLNOG Looking Glass](https://lg.ring.nlnog.net/) (large-scale BGP monitoring), [IRR Explorer](https://irrexplorer.nlnog.net/), and [BGP Filter Guide](https://bgpfilterguide.nlnog.net/).
- **Community & Events**: Hosts annual **NLNOG Day** (next in 2026) with a call for presentations, fosters collaboration via mailing lists, IRC, Discord, and supports entry-level to advanced network professionals through inclusive, English-language technical conferences.
