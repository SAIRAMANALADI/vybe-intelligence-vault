## Summary

- **Monolithic Backend Architecture**: Sentry's core is a monolithic backend service powering all operations, requiring detailed understanding for contributions.
- **Multi-Component Services**: Sentry operates with auxiliary services (e.g., ingestion, SDKs, integrations) running alongside the monolith, each with distinct technical requirements.
- **Self-Hosting & Dockerized Deployment**: Sentry supports self-hosted deployments via a Dockerfile, enabling custom server configurations with defined system dependencies.
