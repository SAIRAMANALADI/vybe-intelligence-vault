# Use pkgdown — use_pkgdown • usethis

## Summary

- `use_pkgdown()` generates a `_pkgdown.yml` config file and updates `.Rbuildignore`/`.gitignore` to exclude non-essential files from package checks and version control.
- `use_pkgdown_github_pages()` automates GitHub Pages deployment by invoking `use_pkgdown()`, setting up a `gh-pages` branch via `use_github_pages()`, and configuring a GitHub Action for CI/CD publishing.
- Special GitHub organizations (e.g., tidyverse, r-lib) receive tailored URL handling and pkgdown template integration in the automated workflow.
