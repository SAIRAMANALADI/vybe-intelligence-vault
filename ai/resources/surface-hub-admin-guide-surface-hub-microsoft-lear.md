# Surface Hub admin guide - Surface Hub | Microsoft Learn

## Summary

- **Surface Hub** integrates an interactive whiteboard, meeting platform, and collaborative computing device into a single system, optimized for hybrid work environments.

- **Deployment & Management** supports Windows Autopilot for zero-touch provisioning, MDM integration for centralized control, and coordinated meetings via Teams Rooms configuration.

- **Development & Troubleshooting** provides tools for app testing (Visual Studio), log collection for diagnostics, and firmware/driver lifecycle management for Surface Hub hardware.
