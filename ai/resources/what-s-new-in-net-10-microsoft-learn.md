# What's new in .NET 10 | Microsoft Learn

## Summary

- **Runtime Optimizations**: .NET 10 introduces JIT inlining, method devirtualization, stack allocations, AVX10.2 support, NativeAOT enhancements, improved struct argument code generation, and enhanced loop inversion for performance gains.

- **Library & Cryptography Updates**: New APIs in cryptography (post-quantum ML-DSA, HashML-DSA, AES KeyWrap), globalization, numerics, and JSON serialization (disallowing duplicates, `PipeReader` support). Networking adds `WebSocketStream` and TLS 1.3 for macOS; process management includes Windows process group support.

- **SDK & Language Features**: SDK adds `Microsoft.Testing.Platform` in `dotnet test`, CLI command standardization, and native container image generation for console apps. C# 14 introduces field-backed properties, `nameof` for unbound generics, first-class `Span` conversions, and user-defined compound assignment operators.
