# Python environments in VS Code

## Summary

- **Multi-language IDE Support**: VS Code provides built-in language support for 20+ languages (e.g., JavaScript, Python, C++, Java, Rust, Go) with dedicated extensions for enhanced features like debugging, linting, and IntelliSense.

- **Python Environment Management**: The Python Environments extension integrates `venv`, `conda`, `pyenv`, `poetry`, and `pipenv` into VS Code’s UI, enabling environment creation, package management, and interpreter switching without manual configuration.

- **Automated Discovery & Configuration**: The Python Environment Tool (PET) Rust binary scans the system for environments (e.g., via `PATH` or known install paths) and refreshes via the Command Palette or UI, with customizable workspace search paths for `.venv` or other patterns.
