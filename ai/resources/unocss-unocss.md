# unocss/unocss

## Summary

- **On-demand Atomic CSS Engine**: Unocss generates atomic CSS utilities dynamically at build time, eliminating pre-defined class lists and enabling instant, flexible styling without runtime overhead.

- **Framework-Agnostic Plugin System**: Supports integrations with Vite, Webpack, and other tools via plugins, while offering first-class support for frameworks like React, Vue, and Svelte through optimized presets.

- **High-Performance & Extensible**: Utilizes Just-in-Time (JIT) compilation for near-zero runtime cost, with a modular architecture allowing custom configurations, themes, and rules via TypeScript-based APIs.
