# HTMLTemplateElement: shadowRootMode property - Web APIs | MDN

## Summary

- **Property Introduction**: `shadowRootMode` is a property of `HTMLTemplateElement` introduced in Feb 2024, reflecting the `shadowrootmode` attribute value for declarative Shadow DOM.
- **Browser Support**: Fully supported in modern browsers (post-Feb 2024), with limited or no support in older versions/devices.
- **Purpose**: Enables declarative Shadow DOM by controlling the mode (`open`/`closed`) of the ShadowRoot created from the `<template>` element.
