# [2411.04368] Measuring short-form factuality in large language models

## Summary

- Introduces **SimpleQA**, an adversarially constructed benchmark for evaluating short-form factuality in LLMs, designed to have unambiguous single-answer questions for precise grading (correct/incorrect/not attempted).
- Benchmark prioritizes **challenge and confidence calibration**, with questions curated to be difficult (e.g., against GPT-4 responses) while enabling models to abstain when uncertain, testing "knowing what they know."
- Provides an open-source evaluation framework ([GitHub](https://github.com/openai/simple-evals)) for standardized, reproducible assessment of factual accuracy in frontier models.
