# [2411.04368] Measuring short-form factuality in large language models

## Summary

- Introduces **SimpleQA**, an adversarially constructed benchmark for evaluating short-form factuality in LLMs, designed to be challenging and unambiguous with single, indisputable answers per question.
- Implements a **grading system** where model responses are classified as correct, incorrect, or not attempted, enabling assessment of "knowing what they know" via confidence-based abstention.
- Provides an open-source, scalable evaluation framework via [GitHub](https://github.com/openai/simple-evals) to track factual accuracy across future LLM generations.
