# Web preferences - Opera Help

## Summary

- **Autofill Configuration**: Opera's Autofill feature supports saving and auto-filling passwords, payment methods, and addresses via `Settings > Advanced > Privacy & security > Autofill`. Users can add, edit, or remove entries, with HTTPS-secured sites retaining permissions.

- **Privacy & Security Controls**: Opera allows granular management of site permissions (camera, microphone, location, MIDI, etc.) via `Settings > Advanced > Privacy & security > Site settings`. Default behavior blocks third-party cookies, requires explicit consent for privileged access (e.g., geolocation), and supports HTTPS-locked permission persistence.

- **Password Manager & Data Handling**: Opera’s Password Manager (`Settings > Advanced > Privacy & security > Passwords`) syncs credentials across devices, supports CSV import/export, and offers advanced controls like auto-login, "Clear on Exit," and bulk data deletion. Passwords are stored securely but require manual deletion of exported CSV files for security.
