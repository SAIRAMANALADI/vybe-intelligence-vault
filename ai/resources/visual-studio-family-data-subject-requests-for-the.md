# Visual Studio Family Data Subject Requests for the GDPR and CCPA - Microsoft GDPR | Microsoft Learn

## Summary

- **Data Collection & Processing Scope**: Microsoft collects customer data (transactional/interactional) and system-generated logs (up to 18 months retention) for Visual Studio/VS Mac (pre-Dec 2024) and extensions; logs may contain identifiable info (e.g., usernames). VS Code logs are excluded if unauthenticated.

- **DSR Mechanisms**: Controllers can export/delete data via:
  - Azure Data Subject Requests (for Entra/MSA-backed accounts).
  - Microsoft Privacy Response Center (for standalone MSA accounts).
  - Account closure deletes identifiable data; anonymized logs persist ≤18 months.

- **Third-Party & Feedback Tools**: Non-Microsoft tools (e.g., extensions, NuGet.org, ASP.NET) require direct requests to their providers. Feedback tools (SurveyMonkey/Usabilla/Qualtrics) have distinct retention/deletion policies (e.g., SurveyMonkey: 28-day external deletion, 18-month internal retention).
