## Summary

- **SHA-256 transition improvements**: Git 2.55 introduces optimizations for SHA-256 hashing, including faster object parsing and reduced memory usage during repository operations, enhancing performance for large-scale repositories.

- **Enhanced `git maintenance` scheduling**: The `git maintenance` command now supports more granular scheduling options (e.g., `--schedule=<frequency>`) and improved background process management for tasks like `gc` and `commit-graph`.

- **New `git restore` options**: Added `--staged` and `--worktree` flags to `git restore` for more precise control over staged vs. working directory file restoration, reducing unintended overwrites.
