# temporalio/temporal

## Summary

- **Distributed Workflow Engine**: Temporal is an open-source, scalable, and fault-tolerant workflow orchestration platform written in Go, enabling durable execution of long-running processes and stateful workflows across distributed systems.

- **Core Components**: Includes a Temporal Server (frontend, history, matching, and worker services), SDKs for workflow definition (Go, Java, Python, etc.), and a persistence layer (default: Cassandra, PostgreSQL, MySQL) for workflow state management.

- **Key Features**: Supports cron-like scheduling, retries, timeouts, event-driven workflows, and temporal.io's proprietary "Temporal Sharding" for horizontal scalability and high availability in microservices architectures.
