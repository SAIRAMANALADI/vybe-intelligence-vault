# Marquez Project | Marquez Project

## Summary

- **OpenLineage-compatible metadata server**: Marquez provides a real-time metadata collection endpoint via an OpenLineage-compatible API, enabling integration with tools like Apache Airflow, Spark, Flink, dbt, and Dagster for job metadata ingestion.

- **Unified visual lineage graph**: The web UI renders a dependency graph of jobs, datasets, and their interconnections, allowing users to trace lineage, inspect execution details, and analyze performance metrics across pipelines.

- **Flexible Lineage API**: The REST API enables programmatic querying of metadata for automation tasks (e.g., backfills, root cause analysis) by traversing dependency trees and enriching data catalogs or quality systems.
