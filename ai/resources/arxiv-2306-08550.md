# [2306.08550] User Simulation for Evaluating Information Access Systems

## Summary

- **User simulation** is proposed as a solution to evaluate information access systems (e.g., search engines, recommender systems, conversational assistants) by modeling user behavior to assess system effectiveness in interactive task completion.

- The paper systematically reviews **user simulation frameworks**, including general design principles, evaluation methodologies, and domain-specific models (e.g., search engines, recommender systems, dialogue systems) with interdisciplinary connections to machine learning and economics.

- Future research directions emphasize **scalable, realistic user simulation** for evaluating interactive intelligent systems, extending beyond traditional evaluation metrics to address variability in user preferences and behaviors.
