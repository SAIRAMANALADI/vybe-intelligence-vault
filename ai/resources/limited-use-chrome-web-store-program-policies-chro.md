# Limited Use | Chrome Web Store - Program Policies | Chrome for Developers

## Summary

- **Data Usage Constraints**: Extensions must limit data collection, use, and transmission to only what is necessary for the disclosed single purpose, including operational needs like security and performance, and must comply with applicable privacy laws.
- **Third-Party Transfers**: User data may only be shared with third parties if required for the extension’s purpose, legal compliance, fraud prevention, or in case of a merger/acquisition with explicit user consent.
- **Prohibited Practices**: Extensions are banned from using data for personalized ads, credit scoring, or selling to brokers; human access to raw data requires explicit user consent, anonymization, security needs, or legal obligations.
