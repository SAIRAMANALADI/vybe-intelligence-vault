# Simple unification-based type inference for GADTs - Microsoft Research

## Summary

- **GADTs Extension**: Generalized Algebraic Data Types (GADTs) extend traditional algebraic data types with more expressive power, enabling type-safe, domain-specific abstractions in languages like Haskell and ML.

- **Type Inference Challenge**: GADTs complicate type inference due to their expressive power, requiring programmer-supplied type annotations to simplify the inference process, which is otherwise difficult to automate.

- **Wobbly Types Innovation**: Introduces *wobbly types* as a declarative mechanism to represent uncertainty in type inference, addressing the incremental nature of inference algorithms and enabling more robust type checking for GADTs.
