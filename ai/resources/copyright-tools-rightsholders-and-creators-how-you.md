# Copyright Tools: Rightsholders and Creators - How YouTube Works

## Summary

- **Webform**: Global tool (80+ languages) enabling rightsholders to submit copyright removal requests via a streamlined interface, with optional automated reupload prevention for flagged content.

- **Copyright Match Tool**: Automated system for creators/rightsholders to detect near-duplicate videos; notifies users of potential infringement for manual review and takedown requests.

- **Content ID**: Advanced system for major rightsholders (e.g., studios/labels) to pre-configure rules (block/monetize/track) for matched content, handling high-volume reposting scenarios.
