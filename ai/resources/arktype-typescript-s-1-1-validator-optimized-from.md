# ArkType: TypeScript's 1:1 validator, optimized from editor to runtime

## Summary

- **Performance**: Achieves **20x faster runtime** than Zod and **2,000x faster** than Yup, with **14ns validation** (Node v23.6.1), while maintaining near-instant editor feedback without plugins or build steps.

- **Type System**: Uses **set theory-based introspection** for runtime type relationships (e.g., `User.extends("object")`), with **optimized schema normalization** (e.g., discriminated unions) and **TypeScript-like type syntax** for concise, readable definitions.

- **Error Handling**: Provides **deeply customizable error messages** with defaults, exposing validation failures via `type.errors` (e.g., `out.summary` for detailed feedback) while ensuring **half-length definitions** and **twice-as-readable errors** compared to TypeScript.
