# GoogleChrome/web-vitals

## Summary

- **Core Web Vitals Metrics**: The repository provides JavaScript libraries to measure and report on key performance indicators (KPIs) like Largest Contentful Paint (LCP), First Input Delay (FID), and Cumulative Layout Shift (CLS), which are critical for assessing user experience and site health.

- **API & Tooling**: Includes `web-vitals.js` for direct metric measurement and `attribution-build.js` for debugging performance issues by attributing shifts or delays to specific DOM elements or network requests.

- **Integration & Compliance**: Supports modern web standards (e.g., `PerformanceObserver` API) and provides guidance for integrating metrics into analytics tools (e.g., Google Analytics) to monitor and optimize site performance.
