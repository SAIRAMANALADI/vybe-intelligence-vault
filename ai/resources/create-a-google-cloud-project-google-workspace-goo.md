# Create a Google Cloud project | Google Workspace | Google for Developers

## Summary

- A **Google Cloud project** is mandatory for accessing Google Workspace APIs and developing Workspace add-ons/apps, serving as the foundation for managing APIs, billing, permissions, and collaborators.
- Projects can be created via the **Google Cloud console** (UI) or **gcloud CLI**, with the latter requiring a `PROJECT_ID` parameter (e.g., `gcloud projects create PROJECT_ID`).
- **Billing must be enabled** for certain Workspace APIs/features, configurable via the Cloud console or `gcloud billing projects link PROJECT_ID --billing-account=BILLING_ACCOUNT_ID`.
