# BibTeX - TeX Users Group

## Summary

- **Purpose & Functionality**: BibTeX processes `.bib` (bibliography database) and `.bst` (style file) inputs to generate a formatted `.bbl` (bibliography) file for TeX/LaTeX documents, maintaining independence from formatting rules.

- **Distribution & Maintenance**: Distributed via TeX Live and other collections, BibTeX is compiled as part of Web2C in TeX Live; original source is maintained in a Subversion repository under TeX Live.

- **Resources & Support**: Includes original documentation (`btxdoc`, `btxhak`), a dedicated mailing list (`biblio@tug.org`), and tools like Nelson Beebe’s BibNet project for bibliographies and BibTeX utilities.
