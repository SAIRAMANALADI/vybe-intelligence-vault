# Web Accessibility Assistance – Cornell University Library

## Summary

- **Compliance & Policy**: Cornell University Library adheres to [University Policy 5.12 Web Accessibility Standards](https://policy.cornell.edu/policy-library/web-accessibility-standards) to ensure equal access to library services and collections.
- **Accommodation Services**: Provides reasonable assistance for accessing library resources, with advance notice required for some services; contact [libaccessibility@cornell.edu](mailto:libaccessibility@cornell.edu) for accommodations.
- **Readability Widget**: Implements the [Readability Widget](https://www.lib.ncsu.edu/accessibility/readability-widget) by NC State University Libraries to enhance readability for users, with feedback directed to [libaccessibility@cornell.edu](mailto:libaccessibility@cornell.edu).
