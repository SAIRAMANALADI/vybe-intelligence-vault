# Use the debugger

## Summary

- **Debugger Features**: DevTools provides a source-level debugger with breakpoints, stepping (in/over/out), variable inspection, call stack analysis, and console output for stdout/stderr.
- **Breakpoint Management**: Breakpoints are set/cleared by clicking the line number margin; exceptions can be toggled to break on unhandled or all exceptions.
- **Execution Control**: Hot restart clears breakpoints; stepping resumes execution, while variable fields and `toString()` results are inspectable via the Variables area.
