# Installation — JupyterLab 4.6.0 documentation

## Summary

- JupyterLab can be installed via `conda` (`conda install -c conda-forge jupyterlab`), `mamba` (`mamba install -c conda-forge jupyterlab`), `uv` (`uv tool install jupyterlab --with pip`), `pip` (`pip install jupyterlab`), `pipenv` (`pipenv install jupyterlab`), or Docker (using `-e JUPYTER_ENABLE_LAB=yes` flag in the container).

- Proxy/firewall restrictions may require configuring `HTTP_PROXY`/`HTTPS_PROXY` environment variables or disabling SSL verification (`conda config --set ssl_verify False`, `npm set strict-ssl False`) for installations to succeed.

- JupyterLab supports modern browsers (Firefox, Chrome, Safari, Edge) and can integrate with JupyterHub or Jupyverse (a FastAPI-based alternative to `jupyter-server`).
