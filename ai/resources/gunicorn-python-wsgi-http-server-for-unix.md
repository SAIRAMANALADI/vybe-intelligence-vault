# Gunicorn - Python WSGI HTTP Server for UNIX

## Summary

- **Pre-fork Worker Model**: Gunicorn employs a pre-fork worker model to handle traffic spikes efficiently, ensuring stable performance under load with minimal overhead.
- **Multi-Worker Types**: Supports sync, async (Gevent/Eventlet), threaded, and ASGI workers, enabling optimization for I/O-bound workloads or async frameworks like FastAPI/Starlette.
- **WSGI/ASGI Compatibility**: Compatible with any WSGI or ASGI framework (Django, Flask, FastAPI, etc.) without code changes, offering lightweight deployment from containers to bare metal.
