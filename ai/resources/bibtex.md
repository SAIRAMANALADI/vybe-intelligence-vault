# bibtex

## Summary

- **Protocol Definition**: WebFinger (RFC 7033) is an HTTP-based protocol for discovering metadata about entities (e.g., people) via URIs that may not function as direct locators (e.g., `acct:` or `mailto:` URIs).

- **Discovery Mechanism**: Uses standard HTTP `GET` requests to resolve a target URI (e.g., `https://example.com/.well-known/webfinger?resource=acct:user@example.com`) and returns JSON-formatted metadata about the entity.

- **Use Cases**: Enables discovery of profile data, service endpoints (e.g., ActivityPub, OAuth), or other linked resources, facilitating decentralized identity and interoperability across web services.
