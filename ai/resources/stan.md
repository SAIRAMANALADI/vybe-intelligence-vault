# Stan

## Summary

- **Bayesian Inference Engine**: Stan implements Hamiltonian Monte Carlo (HMC) and its variant, the No-U-Turn Sampler (NUTS), for efficient posterior sampling in Bayesian hierarchical models, supporting continuous, discrete, and multivariate distributions.

- **Multi-Language Interfaces**: Provides official interfaces (PyStan, RStan, CmdStan, Stan.jl) and supports integration with Python, R, Julia, and Unix shells, enabling cross-platform deployment on laptops, HPC clusters, or cloud environments.

- **Probabilistic Programming Language**: Stan’s domain-specific language (DSL) allows declarative specification of Bayesian models with automatic differentiation for gradient-based inference, including support for censored data, missing data, and custom likelihoods.
