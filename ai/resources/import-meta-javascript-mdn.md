# import.meta - JavaScript | MDN

## Summary

- **`import.meta`** is a meta-property in JavaScript modules that provides context-specific metadata, primarily exposing the module's URL via the `url` property (e.g., `import.meta.url` returns the full module URL, including query/hash parameters).
- The `import.meta.resolve` method resolves a module specifier to a URL relative to the current module, enabling dynamic module resolution (e.g., `import.meta.resolve('./module.js')`).
- `import.meta` is only available in ES modules (not in CommonJS or non-module scripts) and is a syntax-level feature (not a property accessor), throwing a syntax error if used outside module contexts.
