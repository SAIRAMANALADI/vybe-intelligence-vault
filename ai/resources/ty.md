# ty

## Summary

- **Performance**: Rust-based `ty` achieves 10x–100x speedup over `mypy` and `Pyright` in type checking benchmarks (e.g., Home Assistant project without caching).
- **Features**: Supports advanced type system capabilities (intersection types, type narrowing, reachability analysis) and fine-grained incremental analysis for IDE responsiveness.
- **Integration**: Provides a language server with rich diagnostics, editor support (VS Code, PyCharm, Neovim), and configurable rule levels with suppression mechanisms.
