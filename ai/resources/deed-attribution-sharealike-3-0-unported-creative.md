## Summary

- A **Canonical URL** is a tag (`<link rel="canonical">`) used to specify the preferred version of a webpage to search engines, preventing duplicate content issues.
- It consolidates ranking signals (e.g., link equity) to a single URL, improving SEO by avoiding dilution across multiple versions (e.g., HTTP/HTTPS, www/non-www, or parameterized URLs).
- Implemented in the `<head>` section of HTML or via HTTP headers, it signals to crawlers which URL should be indexed and ranked.
