# Aseprite - Docs - Cli

## Summary

- **CLI Export & Conversion**: Aseprite's CLI (`aseprite.exe`) supports batch processing for sprite sheet generation, image conversion, and texture+JSON export via options like `--batch`, `--save-as`, `--sheet`, and `--data` for metadata (JSON/Hash-Array formats).

- **Advanced Sprite Sheet Customization**: Supports packed/grid-based sprite sheets (`--sheet-type packed/rows/columns`), layer/tag/slice splitting (`--split-layers`, `--split-tags`, `--split-slices`), and fine-tuning via `--trim`, `--extrude`, `--border-padding`, and `--shape-padding`.

- **Color & Dithering Control**: Enables color mode conversion (`--color-mode rgb/grayscale/indexed`) with configurable dithering algorithms (`--dithering-algorithm ordered/old`) and matrices (`--dithering-matrix bayer8x8`), critical for indexed palette optimization.
