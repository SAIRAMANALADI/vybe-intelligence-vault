# docker/extensions-sdk

## Summary

- **Purpose**: Provides a framework for developing Docker Desktop extensions, enabling integration of third-party tools and services into the Docker Desktop UI.
- **Architecture**: Utilizes a client-server model with a TypeScript-based frontend and Go-based backend for extension development and communication with Docker Desktop.
- **Key Features**: Supports extension lifecycle management, UI rendering via webviews, and secure communication with Docker Desktop via the Extensions API.
