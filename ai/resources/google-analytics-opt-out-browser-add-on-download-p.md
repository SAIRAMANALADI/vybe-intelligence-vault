# Google Analytics Opt-out Browser Add-on Download Page

## Summary

- **Purpose**: The Google Analytics Opt-out Browser Add-on prevents website visitors' data from being collected by Google Analytics (analytics.js, gtag.js) when installed in supported browsers (Chrome, Safari, Firefox, Edge).

- **Compatibility**: Requires JavaScript execution; unsupported for unsupported browsers (despite listed support for Chrome, Safari, Firefox, Edge).

- **Installation**: Users must download and install the add-on to opt out; functionality depends on proper loading/execution in the browser.
