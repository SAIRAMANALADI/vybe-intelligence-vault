# New CSS functional pseudo-class selectors :is() and :where() | Articles | web.dev

## Summary

- **`:is()` and `:where()` Pseudo-Classes**: Simplify complex selector lists by matching any selector in a comma-separated list (e.g., `:is(h1,h2,h3,h4,h5,h6) > b`), reducing redundancy and improving maintainability.

- **Key Differences**:
  - `:is()` has **specificity equal to its most specific argument** (inherits specificity from the matched selector).
  - `:where()` has **zero specificity**, making it ideal for resets or base styles without affecting cascade weight.

- **Browser Support**: Widely supported in modern browsers (Chrome/Edge 88+, Firefox 78+, Safari 14+), enabling progressive enhancement in CSS selector logic.
