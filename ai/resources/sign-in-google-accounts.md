# Sign in - Google Accounts

## Summary

- **Authentication Flow**: Utilizes Google's WebLiteSignIn service for session management, with parameters like `flowEntry=ServiceLogin`, `flowName=WebLiteSignIn`, and `continue` URL for post-authentication redirection.

- **Recovery Mechanism**: Provides a `usernamerecovery` endpoint (`wallet.google.com/signin/usernamerecovery`) for account recovery, linked via `continue` parameter to resume the session after recovery.

- **Session Isolation**: Supports private browsing via `Guest mode` (referenced via `signin_privatebrowsing`) to prevent cross-session tracking, with a `Learn more` link to Google’s support documentation.
