# Listen to WasmAssembly podcast | Deezer

## Summary

- **Multi-language Wasm Integration**: Episodes cover integration of WebAssembly (Wasm) with Scala.js, Kotlin/Wasm, Dart/Flutter, and asm.js via Emscripten, highlighting cross-compilation and runtime interoperability challenges.

- **Wasm Standardization & Ecosystem**: Discussions include W3C standardization efforts (e.g., CG/WG meetings), WASI (WebAssembly System Interface) evolution, and Bytecode Alliance initiatives for portable, secure runtime environments.

- **Wasm Applications & Tooling**: Covers practical use cases like in-browser scientific computing (Quadratic), WebGPU integration, serverless frameworks (Fermyon Spin), and security tools (Arcjet), alongside emerging features like JS Promise Integration and WasmGC.
