# The Linux Kernel documentation — The Linux Kernel documentation

## Summary

- **Kernel Development & Contribution**: Provides structured documentation for kernel development processes, patch submission, community interaction, and maintainer guidelines via [Development process](https://docs.kernel.org/process/development-process.html), [Submitting patches](https://docs.kernel.org/process/submitting-patches.html), and [Maintainer handbook](https://docs.kernel.org/maintainer/index.html).

- **Core & Driver APIs**: Encompasses internal kernel APIs including [Core API](https://docs.kernel.org/core-api/index.html), [Driver APIs](https://docs.kernel.org/driver-api/index.html), subsystem interfaces, and synchronization primitives documented in [Locking](https://docs.kernel.org/locking/index.html).

- **Architecture & Tooling Support**: Covers architecture-specific documentation (e.g., [x86](https://docs.kernel.org/arch/x86/index.html), [ARM64](https://docs.kernel.org/arch/arm64/index.html)) and development tooling such as [Tracing](https://docs.kernel.org/trace/index.html), [Fault injection](https://docs.kernel.org/fault-injection/index.html), and [Rust](https://docs.kernel.org/rust/index.html) integration.
