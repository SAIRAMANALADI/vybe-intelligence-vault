# 7. Simple statements — Python 3.14.6 documentation

## Summary

- **Simple Statements**: Python's simple statements (e.g., `assert`, `del`, `return`, `import`) are single-line constructs executed sequentially, with syntax defined in `simple_stmt` grammar; multiple statements can be separated by semicolons.

- **Assignment Mechanics**: Assignment binds names to objects recursively, handling targets like identifiers, attributes, subscriptions, or slices; mutable objects (e.g., lists, dicts) use `__setitem__` for item assignment, while starred targets (`*target`) unpack iterables per [PEP 3132](https://peps.python.org/pep-3132/).

- **Augmented Assignments**: Combine operations and assignments (e.g., `+=`, `*=`) with in-place modification where possible; left-hand side is evaluated first, and the operation is atomic (e.g., `a[i] += f(x)` evaluates `a[i]` before `f(x)`).
