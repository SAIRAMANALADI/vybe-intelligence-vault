# Google Analytics opt-out browser add-on - Analytics Help

## Summary

- **Functionality**: The Google Analytics opt-out browser add-on blocks the execution of Google Analytics JavaScript libraries (`gtag.js`, `analytics.js`) on visited websites, preventing data transmission to Google Analytics servers.
- **Scope Limitation**: The add-on only disables Google Analytics tracking; it does not affect other analytics tools or prevent websites from collecting data via alternative methods (e.g., server logs, other scripts).
- **Implementation**: The add-on is browser-specific (e.g., Chrome extension) and operates client-side, intercepting requests to Google Analytics endpoints (`www.google-analytics.com`, `analytics.google.com`).
