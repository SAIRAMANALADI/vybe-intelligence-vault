# Google Analytics opt-out browser add-on - Analytics Help

## Summary

- **Purpose**: The Google Analytics opt-out browser add-on blocks the transmission of user data to Google Analytics by preventing the execution of `gtag.js` or `analytics.js` tracking scripts.
- **Scope**: The add-on only disables Google Analytics tracking; it does not affect other analytics tools or prevent data collection by the website itself.
- **Installation**: Available as a Chrome extension ([link](https://chromewebstore.google.com/detail/google-analytics-opt-out/fllaojicojecljbmefodhfapmkghcbnh)), it intercepts and blocks GA JavaScript before data is sent to Google's servers.
