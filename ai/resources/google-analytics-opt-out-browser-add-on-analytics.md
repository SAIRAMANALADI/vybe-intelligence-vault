# Google Analytics opt-out browser add-on - Analytics Help

## Summary

- **Functionality**: The add-on blocks Google Analytics JavaScript (`gtag.js`, `analytics.js`) from transmitting user visit data to Google Analytics servers.
- **Scope**: Prevents data sharing with Google Analytics only; does not affect other analytics tools or data collection by website owners.
- **Limitations**: Does not interfere with data transmission to the website itself or alternative web analytics services.
