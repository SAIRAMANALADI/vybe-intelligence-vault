# Google Analytics opt-out browser add-on - Analytics Help

## Summary

- **Purpose**: The Google Analytics opt-out browser add-on blocks the `gtag.js` and `analytics.js` JavaScript trackers from transmitting user visit data to Google Analytics.
- **Scope**: Prevents data sharing with Google Analytics only; does not affect other analytics tools or data collection by the website itself.
- **Installation**: Available as a browser extension (e.g., Chrome Web Store) to disable Google Analytics tracking for the user.
