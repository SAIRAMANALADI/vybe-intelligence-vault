# GNOME Development

## Summary

- **GNOME Human Interface Guidelines (HIG)**: Provides design principles, resources, and conventions for developing consistent and user-friendly GNOME applications.

- **GNOME Builder**: An integrated development environment (IDE) optimized for GNOME app development, with native support for GTK, Flatpak, and GNOME-specific tools.

- **Flatpak**: A sandboxed, cross-distribution app format for Linux, ensuring secure and consistent application distribution across different Linux distributions.
