# Chrome Extensions | Chrome for Developers

## Summary

- **Chrome Extensions AI Integration**: Chrome Extensions now support the **Prompt API** for AI-driven interactions, with AI-powered samples and an **Early Preview Program** for built-in AI features, including a **Built-in AI Challenge** for developers.

- **Key API Updates in Chrome 153/148**: **Default pinning for extensions** (Chrome 153) and the **transition to the `browser` namespace** (Chrome 148) for improved cross-browser compatibility, alongside expanded **Developer Dashboard roles** and **Structured Clone support** for extension messaging.

- **Core Extension Capabilities**: Extensions can **customize UI** (side panels, themes, override pages), **modify browser behavior** (tabs, bookmarks, downloads), and **alter web content** (inject scripts, observe navigation, manage cookies) via dedicated APIs.
