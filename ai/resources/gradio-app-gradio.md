# gradio-app/gradio

## Summary

- **Gradio** is an open-source Python library for rapidly building and deploying interactive **machine learning (ML) and data science applications** with minimal code, supporting **UI components, data visualization, and model deployment**.
- Enables **real-time interaction** with ML models via web interfaces, compatible with **Jupyter notebooks** and standalone apps, with built-in support for **deep learning frameworks** (e.g., TensorFlow, PyTorch).
- Provides **deployment tools** for sharing apps via public links or integrating into larger systems, with a growing ecosystem of **pre-built components** for common ML workflows.
