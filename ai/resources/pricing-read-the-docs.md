# Pricing - Read the Docs

## Summary

- **Plan Tiers & Pricing**: Basic ($50/month) offers 2 concurrent builds, Advanced ($150/month) includes 4 builds and 5 custom domains, Pro ($250/month) supports 6 builds and 15 custom domains with extended analytics (90 days) and faster support (1 business day).

- **Authentication & Security**: Basic/Advanced plans support SSO via GitHub/GitLab, while Pro adds Google SSO; all plans include authentication auditing (30-90 days) and private repository support.

- **Enterprise Features**: Custom pricing ($10k+/year) includes SAML SSO, dedicated builders, advanced audit tracking, and an SLA; all plans share core features like automatic builds, versioning, and CDN hosting.
