# djot

## Summary

- **Syntax Enhancements**: Djot improves upon CommonMark by simplifying syntax complexity while adding features like definition lists, footnotes, tables, inline formatting (insert, delete, highlight, superscript, subscript), math, smart punctuation, and generic containers for block/inline/raw content.

- **Multi-Language Support**: Implemented in JavaScript, Lua, Prolog, Rust, Go, and PHP, with the official JavaScript parser being stable; minor syntax changes may occur before finalization.

- **Conversion Tools**: Supports conversion to/from GitHub-Flavored Markdown (GFM) via Pandoc, enabling interoperability with formats like DOCX using `djot` and `pandoc` CLI tools.
