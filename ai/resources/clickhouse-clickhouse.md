# ClickHouse/ClickHouse

## Summary

- **Real-time OLAP DBMS**: ClickHouse is an open-source, column-oriented DBMS optimized for real-time analytical processing (OLAP) with sub-second query latency on petabyte-scale datasets.
- **MPP & Distributed Architecture**: Supports massively parallel processing (MPP) and horizontal scaling via sharding/replication, enabling distributed query execution across clusters with fault tolerance.
- **Multi-language & Hybrid Engine Support**: Implemented in C++ with Rust-based components (e.g., `clickhouse-rs` driver), supports SQL with extensions for embedded analytics, and integrates with lakehouse architectures (e.g., Iceberg, Hudi).
