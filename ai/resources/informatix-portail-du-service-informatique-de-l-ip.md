# Informatix, portail du service informatique de l'IPGP

## Summary

- **Webmail & Intranet**: IPGP provides institutional email access via `webmail.ipgp.fr` and an internal documentation portal at `www-info.ipgp.fr`.

- **Resource Management Systems**: Includes tools for booking rooms (`resa/salles/`), equipment (`resa/equip/`), and vehicles (`resa/vehic/`), alongside a seminar management system (`seminaires.ipgp.fr`).

- **Collaborative & Technical Services**: Features include file transfer (`dl.ipgp.fr`), SVN repositories (`svn.ipgp.fr`), leave management (`fw.ipgp.fr` for IPGP, `agate-tempo.cnrs.fr` for CNRS), and a competency database (`www-info.ipgp.fr/competences`).
