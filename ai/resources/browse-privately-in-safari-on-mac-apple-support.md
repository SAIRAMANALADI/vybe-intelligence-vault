# Browse privately in Safari on Mac - Apple Support

## Summary

- **Safari Private Browsing**: Enables isolated, non-persistent browsing sessions where cookies, history, and AutoFill data are not saved; prevents cross-tab tracking and iCloud synchronization of open tabs.
- **Advanced Tracking Protection**: Default in Private Browsing, blocks fingerprinting techniques and removes tracking parameters from URLs; can be enabled globally via Safari settings.
- **Private Window Configuration**: Can be set as default via `Safari > Settings > General > "Safari opens with: A new private window"`; requires `Close windows when quitting an application` in macOS settings if unavailable.
