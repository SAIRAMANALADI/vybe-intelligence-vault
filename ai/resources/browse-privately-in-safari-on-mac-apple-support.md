# Browse privately in Safari on Mac - Apple Support

## Summary

- **Private Browsing Isolation**: Safari's private windows isolate browsing sessions between tabs, preventing cross-tab tracking and storing no AutoFill, webpage, or download history; iCloud tab sync is disabled for private sessions.
- **Advanced Tracking Protection**: Private Browsing enables "Use advanced tracking and fingerprinting protection" by default, blocking connections to data collection companies and stripping tracking parameters from URLs.
- **Persistent Private Mode Configuration**: Users can set Safari to always open with a private window via Safari > Settings > General > "Safari opens with" > "A new private window," requiring additional system settings adjustments if not initially available.
