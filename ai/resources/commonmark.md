# CommonMark

## Summary

- **CommonMark** is a standardized, unambiguous specification for Markdown, addressing inconsistencies in the original Markdown.pl implementation and divergent implementations across platforms.
- **Key components** include a formal syntax specification ([spec.commonmark.org](https://spec.commonmark.org/)) and a validation test suite to ensure interoperability across implementations.
- **Adoption** includes major platforms like GitHub, GitLab, Reddit, and Stack Overflow, with reference implementations available in multiple programming languages.
