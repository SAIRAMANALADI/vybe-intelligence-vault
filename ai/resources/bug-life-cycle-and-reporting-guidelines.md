# Bug Life Cycle and Reporting Guidelines

## Summary

- Bug reporting requires a Google Account; Chromium bugs are filed via [Chromium Issue Tracker](https://issues.chromium.org/new), while Chromium OS bugs use the `ChromeOS` custom field.
- Bug lifecycle stages: **New** → **Unconfirmed** → **Assigned** → **In Progress (Accepted)** → **Fixed** → **Verified**, with delays between fix and release channel propagation.
- Hotlists (`Unconfirmed`, `Available`) and status fields (e.g., `Assigned`, `Fixed`) are used for triage and prioritization, with detailed guidelines in [Triage Best Practices](https://www.chromium.org/for-testers/bug-reporting-guidelines/triage-best-practices).
