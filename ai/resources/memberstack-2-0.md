# Memberstack 2.0

## Summary

- **Memberstack Webflow Integration**: Requires installing the Memberstack package in Webflow, creating a signup form, and configuring default/plan-specific redirects for authentication flows.

- **Plan & Pricing Logic**: Supports tiered pricing with plan-specific redirects (signup/login/logout) and custom fields/metadata via JSON for member data management.

- **Developer Packages**: Provides DOM, Webflow, and Admin packages for frontend integration, server-side JWT/webhook verification, and membership feature implementation.
