# Baseline | web.dev

## Summary

- **Baseline Definition & Governance**: Originated by Chrome, now maintained by the WebDX Community Group; defines interoperable web features via two stages: *Newly available* (all core browsers support) and *Widely available* (30 months post-interoperability).

- **Core Browser Set & Compatibility**: Baseline relies on support across Chrome, Edge, Firefox, and Safari (desktop/Android/iOS); tools like Browserslist, ESLint, and Chrome DevTools integrate Baseline data for linting, debugging, and feature adoption.

- **Tooling & Adoption**: Includes Baseline Alerts (Web Platform Status dashboard), Netlify/VS Code extensions, GA-integrated Baseline Checker, and monthly digests; case studies (e.g., Target, Cybozu) demonstrate reduced browser compatibility overhead.
