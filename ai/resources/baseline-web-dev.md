# Baseline | web.dev

## Summary

- **Baseline Definition & Governance**: Originated by Chrome team, now maintained by the WebDX Community Group; defines interoperable web features via two stages: *Newly available* (all core browsers support) and *Widely available* (30 months post-interoperability).

- **Core Browser Set & Adoption Tools**: Supported by Chrome, Edge, Firefox, and Safari; integrated into tools like Chrome DevTools (CSS properties), ESLint (CSS linting), Browserslist (queries), and VS Code; includes alerts and dashboards (e.g., WebStatus.dev) for tracking adoption.

- **Target-Based Workflow & Case Studies**: Features grouped into yearly *Baseline targets* for project planning; real-world adoption demonstrated by companies like Target (modernization) and Cybozu (reduced overhead), with polyfill guidance provided for transitional use.
