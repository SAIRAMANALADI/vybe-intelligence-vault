# Status change of HTTP experiments to Historic

## Summary

- **Status Change**: RFCs 2169, 2296, 2310, 2660, 2774, and 8164 moved to **Historic** status due to lack of widespread adoption.
- **Document Details**: Approved by IESG on 2021-12-06; responsible AD: Francesca Palombini; no telechat date scheduled.
- **Experimental RFCs**: Includes HTTP-related experiments like URN resolution (RFC2169), RVSA/1.0 (RFC2296), Safe Response Header (RFC2310), S-HTTP (RFC2660), HTTP Extension Framework (RFC2774), and Opportunistic Security for HTTP/2 (RFC8164).
