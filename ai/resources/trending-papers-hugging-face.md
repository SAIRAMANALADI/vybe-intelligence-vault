# Trending Papers - Hugging Face

## Summary

- Introduces **Reference Sliding Window Attention (RSWA)** to mitigate quadratic memory growth in long-sequence OCR by restricting attention to a fixed-size sliding window around reference tokens.

- Enables **multi-page transcription in a single forward pass** by decoupling memory usage from sequence length, addressing the bottleneck in traditional OCR models.

- Achieves **constant memory complexity** (O(1) per token) via selective attention mechanisms, outperforming prior OCR systems in both efficiency and scalability.
