# Miniconda - Anaconda

## Summary

- Miniconda is a lightweight, open-source distribution of Python and conda, bundling only essential packages (conda, Python, and their dependencies) with optional expansion via `conda install` from Anaconda’s repositories or third-party channels (e.g., conda-forge, bioconda).

- Installers for the latest Miniconda (including Python 3.13) are available at [anaconda.com/download](https://www.anaconda.com/download), with hashes and legacy versions archived separately.

- Installation guides cover OS-specific (Windows/macOS/Linux) methods (GUI/CLI), while advanced options include silent installs, multi-user setups, and legacy OS support.
