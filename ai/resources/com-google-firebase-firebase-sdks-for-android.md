# com.google.firebase | Firebase SDKs for Android

## Summary

- **KTX Module Deprecation**: As of July 2025, Firebase has deprecated new versions of KTX modules and removed them from the Firebase Android BoM (v34.0.0), advising migration to KTX APIs from main modules.
- **Core Classes**: Key Firebase SDK entry points include `FirebaseApp` (primary access point), `FirebaseOptions` (configurable options), and `Timestamp` (timezone-agnostic timestamp representation).
- **Exceptions & Extensions**: Firebase SDK exposes `FirebaseNetworkException` (network failures) and `FirebaseTooManyRequestsException` (rate-limiting), with extension functions/properties for app initialization (`Firebase.initialize`) and access (`Firebase.app`, `Firebase.options`).
