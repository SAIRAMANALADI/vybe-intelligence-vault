# Aseprite by David Capello, Igara Studio

## Summary

- **Cross-platform sprite editor** supporting Windows, macOS, and Linux with signed builds (`.exe`, `.dmg`, `.AppImage`, `.deb`) and portable `.zip` distribution.
- **Advanced pixel-art animation toolkit** featuring layers/frames separation, RGBA/Indexed/Grayscale color modes, GIF/PNG/ICO export, onion skinning, RotSprite rotation, and CLI integration.
- **Commercial features** include lifetime updates up to v1.9, Steam key, priority email support, and sprite sheet import/export with tagged frame support (v1.1+).
