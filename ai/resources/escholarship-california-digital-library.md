# eScholarship – California Digital Library

## Summary

- **Open Access Repository**: UC's institutional repository hosting >300K publications with >100M item views, supporting global open access dissemination of UC scholars' research.
- **Dual Services**: Provides both a publishing platform for UC-affiliated journals and a repository for preprints, postprints, and datasets.
- **Technical Infrastructure**: Managed by a team including senior software developers, technical team manager, and publication management system coordinator, ensuring robust platform maintenance and development.
