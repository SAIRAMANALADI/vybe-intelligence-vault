# walkable.lol

## Summary

- **Web-based Tool**: Walkable.lol is an interactive web application that visualizes and analyzes walkable routes in real-time using geospatial data.
- **Routing Engine**: Utilizes OpenStreetMap (OSM) data and routing algorithms (e.g., Dijkstra’s or A*) to compute pedestrian paths with metrics like distance, elevation, and estimated time.
- **Visualization & API**: Provides a dynamic map interface with customizable overlays (e.g., terrain, accessibility) and offers an API for integration with third-party applications.
