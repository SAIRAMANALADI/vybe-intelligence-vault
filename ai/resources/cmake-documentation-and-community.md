# CMake Documentation and Community

## Summary

- **Documentation Access**: Official CMake reference docs available in HTML (latest: [cmake.org/cmake/help/latest](https://cmake.org/cmake/help/latest/)), QtHelp format, and archived versions (pre-3.0: `cmake(1)`, `ctest(1)`, `cpack(1)` docs from 2.6–2.8.12).
- **Community Platforms**: Active Discourse forum ([discourse.cmake.org](https://discourse.cmake.org/)) for Q&A, open wiki ([gitlab.kitware.com/cmake/community](https://gitlab.kitware.com/cmake/community/-/wikis/home)) for contributions, and issue tracker ([gitlab.kitware.com/cmake/cmake/-/issues](https://gitlab.kitware.com/cmake/cmake/-/issues)) for bug reports.
- **Development & CI**: Open-source contributions via GitLab ([cmake/cmake](https://gitlab.kitware.com/cmake/cmake)), CI builder participation ([testing.rst](https://gitlab.kitware.com/cmake/cmake/blob/master/Help/dev/testing.rst)), and CDash for build/test aggregation ([open.cdash.org](https://open.cdash.org/index.php?project=CMake)).
