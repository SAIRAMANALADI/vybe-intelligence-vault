# Debezium

## Summary

- **Open-source CDC platform**: Debezium is an Apache-licensed (ASL 2.0) distributed change data capture (CDC) system that captures row-level changes (inserts, updates, deletes) from databases in real-time, ensuring durability and low-latency event streaming.

- **Fault-tolerant event processing**: Tracks database changes in commit order, guarantees exactly-once delivery, and maintains event order even during failures or service restarts, enabling downstream systems to stay synchronized without data loss.

- **Scalable architecture**: Designed for high throughput and low latency, Debezium decouples change processing from application logic, allowing external services to react to database changes (e.g., cache updates, search index refreshes) without modifying the source applications.
