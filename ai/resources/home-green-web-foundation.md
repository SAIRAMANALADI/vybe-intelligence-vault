# Home - Green Web Foundation

## Summary

- **Mission & Tools**: The Green Web Foundation (GWF) tracks and promotes green energy usage in internet infrastructure, aiming for a fossil-free internet by 2030. Key tools include the **Green Web Dataset** (API-accessible public dataset to verify green energy claims), **CO2.js** (open-source JS library for estimating digital carbon emissions), and **carbon.txt** (machine-readable sustainability metadata standard).

- **Services & Advocacy**: GWF offers **verification for green hosting providers**, **training/workshops** (e.g., estimating digital carbon emissions, AI environmental impacts), and publishes reports like *State of the Fossil-Free Internet* (focused on "Dirty Data Centres" in 2026). Additional initiatives include *Branch Magazine* (sustainable digital media) and the *Green Screen Coalition* (climate justice + digital rights).

- **Open-Source & Collaboration**: GWF operates open-source projects (e.g., carbon.txt API validation) with public GitHub repos for contributions. Supported by organizations like Mozilla Foundation and Ford Foundation, GWF accepts technical, financial, and collaborative contributions to advance digital sustainability.
