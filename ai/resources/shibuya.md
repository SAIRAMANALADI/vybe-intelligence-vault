# Shibuya

## Summary

- **Modern Sphinx Theme**: Shibuya is a responsive, visually appealing theme for Sphinx documentation, supporting Jupyter extensions like `nbsphinx` for enhanced AI/ML documentation workflows.

- **Multi-Mode Customization**: Features light/dark mode toggle, customizable Radix-based color schemes, and multiple layout options (landing, single-page, three-column) for flexible documentation structuring.

- **Jupyter & Python Ecosystem Integration**: Optimized CSS/UI for Jupyter-related extensions and used by projects like `sentry-python`, `Authlib`, and `joserfc` for API documentation and OAuth/OIDC implementations.
