# stanfordnlp/dspy

## Summary

- **Programmatic LM Optimization**: DSPy introduces a framework for programmatically defining and optimizing language model (LM) pipelines, shifting from ad-hoc prompting to structured, declarative programming with automatic parameter tuning.

- **Modular Pipeline Design**: The framework provides composable modules (e.g., `Predict`, `Retrieve`, `ChainOfThought`) that encapsulate LM calls, enabling end-to-end optimization of multi-stage workflows via teleprompters.

- **Automated Prompt & Weight Optimization**: DSPy automates prompt engineering and weight tuning (e.g., via `BootstrapFewShot` or `MIPROv2`) using gradient-free optimization, improving performance without manual intervention.
