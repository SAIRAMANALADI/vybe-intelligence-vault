# stanfordnlp/dspy

## Summary

- **Programmatic LLM Optimization**: DSPy introduces a framework for *programming* language models (LMs) rather than relying on manual prompt engineering, enabling structured, modular, and reproducible LM pipelines via Pythonic abstractions.

- **Modular Components & Compilation**: The framework decomposes LM tasks into composable modules (e.g., `Signature`, `Module`) and employs a *compiler* to automatically optimize prompts, weights, and logic for downstream performance without manual tuning.

- **Extensible & Scalable**: Supports integration with multiple LM backends (e.g., Hugging Face, OpenAI) and provides tools for evaluation, telemetry, and adaptive learning, facilitating scalable deployment in production environments.
