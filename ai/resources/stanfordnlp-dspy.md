# stanfordnlp/dspy

## Summary

- **DSPy Framework**: A Python-based framework designed to program language models (LMs) rather than relying solely on prompting, enabling structured, modular, and reproducible LM pipelines.

- **Key Features**: Introduces declarative modules (e.g., `Predict`, `Retrieve`) and automatic optimization of LM programs via teleprompters, decoupling logic from LM-specific details.

- **Optimization Pipeline**: Uses gradient-free optimization (e.g., Bayesian methods) to refine prompts and weights, improving performance without manual tuning.
