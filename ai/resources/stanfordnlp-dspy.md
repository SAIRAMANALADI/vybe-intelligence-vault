# stanfordnlp/dspy

## Summary

- **DSPy Framework**: Enables programmatic control over language models (LMs) via modular, declarative components (e.g., `Module`, `Signature`) instead of ad-hoc prompting, optimizing LM behavior through compilation.
- **Key Abstractions**: Introduces `Predict`, `Retrieve`, and `ChainOfThought` modules with teleprompters (e.g., `BootstrapFewShot`) to automate prompt optimization and task-specific LM tuning.
- **Python Implementation**: Provides a Pythonic API for LM integration, supporting both local (e.g., HuggingFace) and API-based (e.g., OpenAI) models with structured input/output handling via `dspy.Signature`.
