# stanfordnlp/dspy

## Summary

- **Programmatic LM Framework**: DSPy abstracts language model (LM) interactions into modular, declarative Python classes, replacing ad-hoc prompting with structured, reproducible pipelines.

- **Optimized Compilation**: Implements *teleprompters*—optimizers that automatically tune LM prompts and weights via few-shot learning, RL, or other strategies, reducing manual prompt engineering.

- **Modular Components**: Provides composable modules (e.g., `Predict`, `Retrieve`, `ChainOfThought`) with built-in support for caching, logging, and evaluation, enabling scalable LM program development.
