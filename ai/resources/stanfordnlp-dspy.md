# stanfordnlp/dspy

## Summary

- **Programmatic LM Optimization**: DSPy introduces a framework that shifts from manual prompt engineering to programmatic optimization of language models, enabling automatic generation and tuning of prompts and weights for improved performance.

- **Modular Pipeline Design**: The framework supports modular pipelines where each component (e.g., retrieval, generation) can be independently optimized using teleprompters, allowing for end-to-end differentiable or heuristic optimization.

- **Pythonic Abstraction**: DSPy abstracts LM interactions via Python classes (e.g., `Signature`, `Module`), enabling developers to define tasks declaratively while the framework handles underlying prompt synthesis, caching, and execution.
