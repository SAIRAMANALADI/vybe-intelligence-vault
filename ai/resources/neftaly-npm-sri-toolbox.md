# neftaly/npm-sri-toolbox

## Summary

- **Purpose**: Provides Subresource Integrity (SRI) tools for verifying the integrity of JavaScript packages via cryptographic hashes (SHA-256/384/512).
- **Functionality**: Generates and validates SRI hashes for npm packages, ensuring secure CDN/CDN-less resource loading.
- **Implementation**: JavaScript-based CLI/npm tool with automated hash generation and verification against package registries.
