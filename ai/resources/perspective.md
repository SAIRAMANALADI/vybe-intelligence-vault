# Perspective

## Summary

- **High-performance engine**: Perspective features a C++-based streaming query engine compiled to WebAssembly and Python, supporting read/write/streaming for Apache Arrow with a columnar expression language derived from ExprTK.

- **Framework-agnostic UI**: Implements a Custom Element-based UI, deployable either in-browser via WebAssembly or server-side via WebSocket (Python/Node), with JupyterLab integration via a Python client library.

- **Scalable data handling**: Enables efficient handling of large datasets through virtualized rendering (consuming only necessary data) and supports streaming via Apache Arrow, with desktop-like performance in browsers.
