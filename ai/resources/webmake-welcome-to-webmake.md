# WebMake: Welcome to WebMake

## Summary

- **Static Site Generation**: WebMake is a Perl-based static site generator that produces portable HTML sites deployable via FTP without requiring server-side scripting, using dependency-aware regeneration to optimize build efficiency.

- **Content & Template Integration**: Supports embedded Perl for dynamic content, metadata-driven index generation, and user-defined tags, with extensible plugins via a Perl-based API for custom functionality.

- **Advanced Features**: Includes on-the-fly content conversion (e.g., plain text to HTML via `Text::EtText`), web-based editing via `webmake.cgi`, CVS integration for replication/versioning, and non-HTML output support.
