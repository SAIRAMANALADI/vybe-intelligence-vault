## Summary

- **SourceHut Hosting**: The [Org mode project](https://orgmode.org) is hosted on SourceHut (`sr.ht`), providing Git repositories, issue tracking, and mailing lists (e.g., `~bzg/org`, `org-build-failures`).

- **Mirror & CI Integration**: The `org-mode` repository is a 3-hour-sync mirror of the [official GNU Savannah Git repo](https://git.savannah.gnu.org/cgit/emacs/org-mode.git/), with additional `.builds/` for daily test execution and failure reporting via mailing lists.

- **Multi-Repo Structure**: Includes mirrored/auxiliary repos (`worg`, `orgweb`, `org-contrib`, `org-mode-tests`) for documentation, website files, contributed packages, and test suite automation via SourceHut builds.
