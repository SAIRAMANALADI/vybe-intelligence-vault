# Model Context Protocol · GitHub

## Summary

- **Standardized Integration Protocol**: MCP defines a vendor-neutral, open protocol for bidirectional communication between LLM applications and external data sources/tools, enabling standardized context sharing and tool invocation.
- **Multi-Language SDK Support**: Provides official SDKs (TypeScript, Python, Java, Kotlin, C#, Go, PHP, Ruby, Rust, Swift) and sample implementations to facilitate protocol adoption across diverse programming environments.
- **Open Governance & Extensibility**: Hosted under The Linux Foundation with community-driven development, including maintained servers and authorization extensions for scalable, extensible AI workflow integrations.
