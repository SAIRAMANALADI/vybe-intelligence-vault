# Firebase · GitHub

## Summary

- Firebase provides official SDKs for Android (Kotlin), iOS (Swift), Web (TypeScript), Unity (C#), and C++ with open-source quickstart repositories (e.g., `quickstart-android`, `quickstart-ios`, `quickstart-js`).

- Core Firebase repositories include `firebase-ios-sdk` (Apache-2.0, 6.6k+ stars), `firebase-functions` (MIT, TypeScript), and `functions-samples` (Apache-2.0, 12.2k+ stars) for Cloud Functions use cases.

- Firebase maintains additional tools like `SpecsTesting` (Ruby) and `SpecsReleasing` (Ruby) for SDK testing/release automation, alongside community-driven samples (e.g., `friendlyeats-web`).
