# Firebase · GitHub

## Summary

- **Multi-platform SDKs**: Firebase provides official SDKs for Android (Kotlin/Java), iOS (Swift/Objective-C), Web (TypeScript/JavaScript), Unity (C#), and C++, enabling cross-platform app development with consistent APIs.

- **Cloud Functions & Samples**: The `functions-samples` repository (12.2k+ stars) demonstrates Cloud Functions for Firebase use cases, while `firebase-tools` (4.4k+ stars) offers CLI utilities for deployment and management.

- **Comprehensive Quickstarts**: Firebase maintains platform-specific quickstart repositories (e.g., `quickstart-android`, `quickstart-ios`, `quickstart-js`) with Apache-2.0 licensed samples for authentication, Firestore, Realtime Database, and other core services.
