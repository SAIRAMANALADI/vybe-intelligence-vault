# Firebase · GitHub

## Summary

- **Multi-platform SDKs**: Firebase provides official SDKs for Android (Kotlin/Java), iOS (Swift/Obj-C), Web (TypeScript/JavaScript), Unity (C#), and C++, with open-source repositories like [`firebase-ios-sdk`](https://github.com/firebase/firebase-ios-sdk) and [`quickstart-android`](https://github.com/firebase/quickstart-android) demonstrating platform-specific implementations.

- **Cloud Functions & Samples**: The [`functions-samples`](https://github.com/firebase/functions-samples) repository (12.2k stars) showcases Cloud Functions for Firebase use cases, while [`friendlyeats-android`](https://github.com/firebase/friendlyeats-android) and [`friendlyeats-web`](https://github.com/firebase/friendlyeats-web) provide Firestore codelabs for Android and Web.

- **Licensing & Maintenance**: Firebase repositories are licensed under Apache-2.0, with active maintenance (e.g., [`firebase-ios-sdk`](https://github.com/firebase/firebase-ios-sdk) updated June 2026) and community contributions (e.g., 1.7k forks for iOS SDK).
