# Firebase · GitHub

## Summary

- **Multi-platform SDK**: Firebase provides official SDKs for Android (Kotlin/Java), iOS (Swift/Obj-C), Web (TypeScript/JavaScript), Unity (C#), and C++, enabling cross-platform app development with unified APIs for Authentication, Realtime Database, Firestore, Cloud Functions, and more.

- **Open-source repositories**: Firebase maintains 100+ public GitHub repositories, including core SDKs (e.g., `firebase-ios-sdk` with 6.6k+ stars), quickstart samples (Android/iOS/Web/Unity/C++), and Cloud Functions use-case demos (`functions-samples` with 12.2k+ stars), all licensed under Apache-2.0.

- **Developer tooling**: Provides CLI tools (e.g., `firebase-tools`), testing frameworks (e.g., `quickstart-testing`), and snippets (e.g., `snippets-android`, `snippets-web`) for streamlined integration, debugging, and deployment workflows across Firebase services.
