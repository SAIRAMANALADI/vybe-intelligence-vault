# Firebase · GitHub

## Summary

- Firebase provides official SDKs for Android (Kotlin/Java), iOS (Swift/Obj-C), Web (TypeScript/JavaScript), Unity (C#), and C++ with dedicated quickstart repositories for each platform.

- Key repositories include `firebase-tools` (CLI), `firebase-js-sdk` (JavaScript SDK), `firebase-ios-sdk` (Apple platforms), and `functions-samples` (Cloud Functions use cases).

- Firebase’s open-source ecosystem includes testing samples (`quickstart-testing`), platform-specific snippets (`snippets-android`, `snippets-web`), and high-starred utility projects like `functions-samples` (12.2k stars).
