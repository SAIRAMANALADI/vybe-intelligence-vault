# Firebase · GitHub

## Summary

- Firebase provides official SDKs and quickstart samples for Android (Kotlin), iOS (Swift), Web (TypeScript), Unity (C#), and C++ (C++), with repositories like `quickstart-android`, `quickstart-ios`, `quickstart-js`, `quickstart-unity`, and `quickstart-cpp` hosting reference implementations.

- The `firebase-ios-sdk` repository (C++) is the primary SDK for Apple platforms, while `functions-samples` (JavaScript) demonstrates Cloud Functions for Firebase use cases, both under Apache-2.0 license.

- Additional repositories like `snippets-android` (Java), `snippets-web` (JavaScript), and `snippets-node` (JavaScript) provide platform-specific code snippets for Firebase documentation.
