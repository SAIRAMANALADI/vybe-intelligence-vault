# googleapis/nodejs-firestore

## Summary

- **TypeScript-based Node.js SDK** for Google Cloud Firestore, a horizontally scalable NoSQL document database optimized for high performance and automatic scaling.
- **Core features** include real-time data synchronization, ACID transactions, and offline data support with seamless cloud synchronization.
- **Integration capabilities** support batch operations, composite indexes, and serverless architectures via Firestore's REST/gRPC APIs.
