# Flutter · GitHub

## Summary

- **Framework & Engine**: Flutter is an open-source UI toolkit with a single codebase for mobile, web, desktop, and embedded apps, primarily funded by Google and built with a cross-platform rendering engine (now integrated into the main `flutter/flutter` repository under `/engine`).

- **Core Repositories**:
  - `flutter/flutter`: Main framework, engine, and CLI tool.
  - `flutter/devtools`: Performance profiling, inspector, and debugger utilities.
  - `flutter/packages`/`core-packages`: Official Dart packages (e.g., `camera`, `webview_flutter`, `animations`).

- **Tooling & Ecosystem**:
  - IDE plugins (e.g., `flutter-intellij` for IntelliJ).
  - Sample apps (`flutter/samples`), test suites (`flutter/tests`), and documentation (`flutter/website`).
