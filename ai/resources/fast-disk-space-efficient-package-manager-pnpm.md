# Fast, disk space efficient package manager | pnpm

## Summary

- **Optimized Dependency Resolution**: Uses a strict, non-flat `node_modules` structure with hard links to avoid duplication, reducing disk space usage by up to **70%** compared to npm/yarn while ensuring deterministic installs.
- **Monorepo & Workspace Support**: Native **workspace protocol** (`pnpm-workspace.yaml`) enables efficient dependency management across multi-package repositories with **parallel task execution** and **isolated dependency trees**.
- **Security & Performance Enhancements**: Implements **minimum release age** for dependency updates and **disables postinstall scripts by default**, mitigating supply chain risks while achieving **~40% faster CI/CD pipelines** via parallelized operations.
