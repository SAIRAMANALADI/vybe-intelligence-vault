# The Compass REST API

## Summary

- **Compass Operations API** provides RESTful endpoints for integrating Compass operations with external systems, supporting automation of workflows and processes via structured domains (e.g., alerts, schedules, teams).

- **Authentication** uses basic auth, with access controlled by **Global** (Admin/User) or **Team** (Admin/Member) roles, requiring valid API tokens and appropriate permissions for operations.

- **API Structure** follows a consistent URL format (`https://api.atlassian.com/compass/cloud/{cloudId}/ops/v1/{domain}`), enforces pagination (offset/size), and supports ISO 8601 date formats with optional resource expansion via `expand` query parameters.
