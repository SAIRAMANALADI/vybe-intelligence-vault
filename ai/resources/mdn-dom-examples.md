# dom-examples/service-worker/simple-service-worker at main · mdn/dom-examples · GitHub

## Summary

- **Service Worker Registration**: Demonstrates basic Service Worker lifecycle (install, activate, fetch events) via `simple-service-worker.js` to cache static assets (e.g., `index.html`, CSS/JS files) for offline use.
- **Local Execution Requirements**: Requires Node.js (managed via `nvm`/`nvm-windows`) and a local server (`lite-server`) to avoid CORS issues during Service Worker registration.
- **Debugging Paths**: Service Worker registration fails if paths (e.g., `scope` or script location) are misconfigured; paths must be relative to the served directory (root in this case).
