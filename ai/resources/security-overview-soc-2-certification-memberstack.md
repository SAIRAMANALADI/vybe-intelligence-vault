# Security Overview & SOC 2 Certification – Memberstack 2.0

## Summary

- **SOC 2 Compliance**: Memberstack holds SOC 2 certification, verified via a comprehensive report covering infrastructure, software, security processes, incident management, and data backup/recovery controls (Trust Services Criteria: Security, Availability, Processing Integrity, Confidentiality, Privacy).
- **Data Protection Measures**: Member data is encrypted in transit (HTTPS) and at rest; payment processing is delegated to Stripe (PCI Level 1), ensuring credit card data never touches Memberstack servers; offsite backups are maintained.
- **Security Protocols**: Enforces HTTPS site-wide, employs JavaScript/CSS-based content gating (non-sensitive data recommended), and adheres to responsible disclosure via `support@memberstack.com` for security vulnerabilities.
