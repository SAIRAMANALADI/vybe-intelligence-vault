# 6. Modules — Python 3.14.7 documentation

## Summary

- **Module System**: Python modules are `.py` files containing definitions and statements, imported via `import` statements; module names are stored in `__name__` and can be executed as scripts with `__name__ == "__main__"`.

- **Import Mechanics**: Modules are cached in `__pycache__` as `.pyc` files for faster loading; `sys.path` defines search order (script dir, `PYTHONPATH`, default paths), and `from module import *` imports all non-underscore names.

- **Execution & Optimization**: Modules can initialize with executable statements, and `importlib.reload()` forces re-import; optimization flags (`-O`, `-OO`) strip asserts and docstrings, reducing `.pyc` size without performance gains.
