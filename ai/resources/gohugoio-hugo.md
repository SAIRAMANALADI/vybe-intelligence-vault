# Release v0.164.0 · gohugoio/hugo · GitHub

## Summary

- **Syntax Highlighting Enhancements**: Introduced dark/light mode pairs in Chroma highlighter styles via new flags in `hugo gen chromastyles` command; added `markup.rst.syntaxHighlight` configuration option for RST syntax highlighting.

- **New Template Functions & Features**: Added `encoding.HexEncode`, `encoding.HexDecode`, and `crypto.Hash` template functions; introduced Pandoc citation support; improved `.Render` method to support sub-paths in layouts.

- **Performance & Deprecation Fixes**: Resolved performance regression from v0.128.0; deprecated `resources.PostProcess` in favor of `templates.Defer`; upgraded dependencies (e.g., Chroma, Go modules) and optimized `hugio.hasBytesWriter` for speed.
