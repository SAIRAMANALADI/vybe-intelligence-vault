# Release v0.164.0 · gohugoio/hugo · GitHub

## Summary

- **Syntax Highlighting & Template Enhancements**: Introduced Chroma dark/light mode pairs for syntax highlighting, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and `markup.rst.syntaxHighlight` configuration option. Added Pandoc citation support and sub-path support in layouts for `Page.Render`.

- **Performance & Deprecations**: Fixed a performance regression introduced in v0.128.0, deprecated `resources.PostProcess` in favor of `templates.Defer`, and improved `hugio.hasBytesWriter` speed.

- **Dependency Updates & Bug Fixes**: Updated dependencies (e.g., `github.com/JohannesKaufmann/html-to-markdown/v2`, `golang.org/x/tools`), added case-insensitive template name lookup, and improved error handling for missing templates in `.Render`.
