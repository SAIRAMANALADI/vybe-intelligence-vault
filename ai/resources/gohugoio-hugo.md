# Release v0.165.0 · gohugoio/hugo · GitHub

## Summary

- **New CSS Features**: Introduced `css.ChromaStyles` template function and `importContext` option for `css.Build`, `js.Build`, `css.Sass`, and `css.PostCSS`, enabling dynamic CSS generation with light/dark mode support and resolvable resource imports.

- **Bug Fixes & Improvements**: Resolved resource transformation chaining issues, server static file detection for deleted files, and MacOS atomic save panics; added `Data.Artifacts` support to CSS/JS builds and improved Asciidoctor TOC parsing.

- **Dependency Updates**: Upgraded Go to 1.26.5, esbuild to 0.28.2, and multiple libraries (e.g., `github.com/tdewolff/minify/v2`, `golang.org/x/tools`) for security and performance enhancements.
