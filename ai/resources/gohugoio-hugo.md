# Release v0.164.0 · gohugoio/hugo · GitHub

## Summary

- **Syntax Highlighting & Template Enhancements**: Introduced dark/light mode pairs in Chroma highlighter styles, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and `markup.rst.syntaxHighlight` option for RST markup support.

- **Performance & Deprecation Fixes**: Addressed a performance regression from v0.128.0, deprecated `resources.PostProcess` in favor of `templates.Defer`, and improved template name lookup case-insensitivity.

- **Pandoc & Layout Support**: Added Pandoc citation support and enabled sub-paths in layouts for `Page.Render`, alongside dependency updates (e.g., Go modules, Chroma, esbuild).
