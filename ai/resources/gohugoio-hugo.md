# Release v0.165.0 · gohugoio/hugo · GitHub

## Summary

- **New `css.ChromaStyles` template function** introduced, enabling generation of Chroma-based CSS stylesheets with configurable `targetPath`, `style`, `mode` (light/dark), and class-specific options (`classDark`, `classLight`).

- **`importContext` option** added to `css.Build`, `js.Build`, `css.Sass`, and `css.PostCSS`, allowing resolution of resources (e.g., `resources.FromString`) in CSS `@import` statements for modular asset management.

- **Bug fixes and improvements** include resumed chained resource transformations, static file detection fixes, removal of TailwindCSS from default security allowlist, and dependency updates (e.g., Go 1.26.5, esbuild 0.28.2).
