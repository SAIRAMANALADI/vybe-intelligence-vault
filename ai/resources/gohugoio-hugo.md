# Release v0.164.0 · gohugoio/hugo · GitHub

## Summary

- **Syntax Highlighting & Template Enhancements**: Introduced dark/light mode pairs for Chroma highlighter styles, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and `markup.rst.syntaxHighlight` configuration option. Added Pandoc citation support and sub-path support in layouts for `Page.Render`.

- **Performance & Deprecation Fixes**: Resolved a performance regression from v0.128.0, deprecated `resources.PostProcess` in favor of `templates.Defer`, and improved `hugio` `hasBytesWriter` efficiency.

- **Dependency Updates**: Upgraded core dependencies (e.g., `esbuild` v0.28.0→v0.28.1, `golang.org/x/tools` v0.45.0→v0.47.0) and added Chroma dark/light mode support via dependency changes.
