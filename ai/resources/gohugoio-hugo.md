# Release v0.165.0 · gohugoio/hugo · GitHub

## Summary

- **New CSS/JS Features**: Introduced `css.ChromaStyles` template function for generating Chroma-based CSS stylesheets with light/dark mode support, and added `importContext` option to `css.Build`, `js.Build`, `css.Sass`, and `css.PostCSS` for resolving resources in `@import` statements.

- **Bug Fixes & Improvements**: Fixed resource transformation chaining, static file detection, server errors on file deletion, and panic issues; improved chained resource transformations, dropped symlinks in parent directories, and added `Data.Artifacts` to `css.Build` and `js.Build`.

- **Dependency Updates**: Upgraded multiple dependencies including Go 1.26.5, `github.com/bep/imagemeta` to v1.0.0, `esbuild` to v0.28.2, and various other libraries (e.g., `goldmark`, `minify`, `kin-openapi`).
