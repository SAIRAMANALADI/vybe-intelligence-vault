# Release v0.164.0 · gohugoio/hugo · GitHub

## Summary

- **Syntax Highlighting & Template Enhancements**: Introduced dark/light mode pairs for Chroma highlighter styles, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and Pandoc citation support. Added `markup.rst.syntaxHighlight` configuration option and sub-path support in `Page.Render` layouts.

- **Performance & Deprecation Fixes**: Addressed a performance regression introduced in v0.128.0, deprecated `resources.PostProcess` in favor of `templates.Defer`, and improved `hugio` performance via `hasBytesWriter` optimizations.

- **Dependency Updates**: Upgraded core dependencies including `github.com/evanw/esbuild` (v0.28.0 → v0.28.1), `golang.org/x/tools` (v0.45.0 → v0.47.0), and added Chroma dark/light mode support via dependency bumps.
