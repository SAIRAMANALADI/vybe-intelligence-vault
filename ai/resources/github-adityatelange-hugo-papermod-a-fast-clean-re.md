# GitHub - adityatelange/hugo-PaperMod: A fast, clean, responsive Hugo theme. · GitHub

## Summary

- **Hugo-PaperMod** is a high-performance, responsive Hugo theme featuring an integrated asset pipeline with fingerprinting, bundling, and minification via Hugo's native tools.
- **Key features** include three layout modes (Regular, Home-Info, Profile), automatic light/dark theme switching, multilingual support, client-side Fuse.js search, and SEO optimization (Open Graph, Twitter Cards, Schema.org).
- **Performance-optimized** with near-perfect Pagespeed Insights scores, Chroma syntax highlighting, zero JS build dependencies, and responsive image support.
