# Install ArcGIS Documentation Center (Individual user) | ArcGIS Documentation Center Help

## Summary

- ArcGIS Documentation Center can be installed via `.exe` or `.msi` installers, launching an interactive GUI-based setup process.
- Installation supports per-machine (requires admin rights) or per-user contexts, with default paths varying accordingly (`Program Files\ArcGIS\DocumentationCenter` or `Users\<user>\AppData\Local\Programs\ArcGIS\DocumentationCenter`).
- Post-installation, the application must be configured, documentation sets downloaded, and manual cleanup of residual folders (`settings`/`root`) may be required during uninstallation.
