# Black Forest Labs · GitHub

## Summary

- **FLUX Model Ecosystem**: Black Forest Labs maintains official inference repositories for FLUX models (e.g., `flux`, `flux2`) under Apache-2.0 license, with Python-based implementations and high community adoption (e.g., `flux` repo has 25.7k+ stars).

- **Tooling & Integration**: Provides MCP servers (`flux-mcp`), ComfyUI nodes (`bfl-comfy-nodes`), and TypeScript/JavaScript SDKs (`skills`) for FLUX model integration and workflow automation.

- **Research & Extensions**: Hosts advanced projects like `Self-Flow` (ICML'26) for self-supervised flow matching, and maintains a Python client (`blackforest`) for their cloud platform.
