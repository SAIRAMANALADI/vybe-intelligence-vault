# SDKs | Firecrawl

## Summary

- **Multi-language SDKs**: Firecrawl provides official SDKs for Python, Node.js, Go, Java, Ruby, Rust, .NET, PHP, and Elixir, each offering idiomatic helpers for API interaction, authentication, polling, and error handling.
- **CLI Support**: Includes a command-line interface (CLI) for direct execution of Firecrawl operations without HTTP request management.
- **Async & Sync Support**: Python and Rust SDKs support both synchronous and asynchronous operations, while others are language-specific (e.g., Node.js for TypeScript, Java for JVM).
