# LibCST — LibCST documentation

## Summary

- **CST Parsing**: Parses Python 3.0–3.13 source into a Concrete Syntax Tree (CST) preserving all formatting (comments, whitespace, parentheses), enabling precise refactoring and linting.
- **Visitor/Transformer Framework**: Provides `CSTVisitor` and `CSTTransformer` for traversing/modifying CST nodes, with helpers like `RemoveFromParent` and `updated_node` for safe tree manipulation.
- **Metadata & Matchers**: Supports metadata providers for contextual analysis (e.g., scope tracking) and declarative matchers for targeted node selection in codemods.
