# CRAN: Package tikzDevice

## Summary

- Converts R plotting commands into LaTeX/TikZ-compatible code blocks, enabling mathematical notation and arbitrary LaTeX insertion in plot text via the `tikzDevice` R package.
- Requires R (≥ 2.14.0), `pgf` (≥ 2.00), and depends on packages like `filehash` (≥ 2.3) and `png`; compiled with system requirements for `pgf` and licensed under GPL-2 | GPL-3.
- Supports reverse dependencies (e.g., `BayesSUR`, `ggtikz`) and provides cross-platform binaries (Windows, macOS) for R versions 4.5–4.7.
