# JSON functions | BigQuery | Google Cloud Documentation

## Summary

- **JSON Extraction Functions**: BigQuery supports standard (`JSON_QUERY`, `JSON_VALUE`, `JSON_QUERY_ARRAY`, `JSON_VALUE_ARRAY`) and legacy (`JSON_EXTRACT`, `JSON_EXTRACT_SCALAR`, etc.) extractors for retrieving JSON data, with legacy functions deprecated in favor of standard ones.
- **JSON Conversion Functions**: Includes strict (`BOOL`, `FLOAT64`, `INT64`, `STRING`) and lax (`LAX_BOOL`, `LAX_FLOAT64`, etc.) converters for JSON-to-SQL value transformations, along with `PARSE_JSON` and `TO_JSON` for bidirectional conversions.
- **JSON Manipulation Functions**: Provides constructors (`JSON_ARRAY`, `JSON_OBJECT`), mutators (`JSON_SET`, `JSON_REMOVE`), accessors (`JSON_KEYS`, `JSON_TYPE`), and transformers (`JSON_FLATTEN`) for creating, modifying, and analyzing JSON structures.
