# JSON functions | BigQuery | Google Cloud Documentation

## Summary

- **JSON Extraction Functions**: BigQuery supports `JSON_QUERY`, `JSON_VALUE`, `JSON_QUERY_ARRAY`, and `JSON_VALUE_ARRAY` for extracting JSON data, with legacy alternatives (`JSON_EXTRACT`, `JSON_EXTRACT_SCALAR`, etc.) deprecated in favor of the standard functions.
- **JSON Conversion Functions**: Includes strict (`BOOL`, `FLOAT64`, `INT64`, `STRING`) and lax (`LAX_BOOL`, `LAX_FLOAT64`, etc.) converters for JSON-to-SQL value transformations, along with `PARSE_JSON` and `TO_JSON` for bidirectional conversions.
- **JSON Manipulation Functions**: Provides mutators (`JSON_SET`, `JSON_REMOVE`), constructors (`JSON_ARRAY`, `JSON_OBJECT`), and accessors (`JSON_KEYS`, `JSON_TYPE`) for dynamic JSON data manipulation and schema introspection.
