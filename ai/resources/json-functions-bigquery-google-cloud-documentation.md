# JSON functions | BigQuery | Google Cloud Documentation

## Summary

- **JSON Extraction Functions**: BigQuery supports `JSON_QUERY`, `JSON_VALUE`, `JSON_QUERY_ARRAY`, and `JSON_VALUE_ARRAY` for extracting JSON data, with legacy alternatives (`JSON_EXTRACT`, `JSON_EXTRACT_SCALAR`, etc.) deprecated in favor of the standard functions.
- **JSON Conversion & Construction**: Functions like `PARSE_JSON`, `TO_JSON`, `BOOL`, `FLOAT64`, `INT64`, `JSON_ARRAY`, and `JSON_OBJECT` enable conversion between SQL and JSON formats, with strict (`BOOL`, `FLOAT64`, etc.) and lax (`LAX_BOOL`, etc.) type conversion modes.
- **JSON Mutation & Access**: BigQuery provides mutators (`JSON_SET`, `JSON_REMOVE`, `JSON_ARRAY_APPEND`), accessors (`JSON_KEYS`, `JSON_TYPE`), and transformers (`JSON_FLATTEN`) to modify, inspect, and restructure JSON data directly within queries.
