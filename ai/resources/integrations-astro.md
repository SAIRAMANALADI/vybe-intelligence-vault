# Integrations | Astro

## Summary

- **Astro 6 + Remark Plugin Integration**: Provides a plugin for Astro 6 that transforms Markdown into 42 distinct callout types with support for 4 themes, CSS layers, and design tokens.
- **Advanced Features**: Includes type allow/blocklists, default collapse behavior, multi-syntax support, icon sprite, minimal theme CSS, dev warnings, config validation, and per-type ARIA roles with `sr-only` icons.
- **Technical Optimizations**: Exposes `CLASSES` constants for styling, supports icon sprites for performance, and includes weekly download metrics (~4.2K).
