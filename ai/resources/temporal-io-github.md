# temporal.io · GitHub

## Summary

- **Durable Execution Abstraction**: Temporal provides an open-source platform for durable execution, preserving complete application state to automatically recover from crashes, service outages, and hardware failures by migrating execution to another machine.

- **Simplified Development & Infrastructure**: Eliminates custom code for timers, event sourcing, retries, timeouts, and state checkpointing, while removing the need for queues, pub/sub systems, and schedulers, accelerating reliable system development.

- **Multi-Language SDK Support**: Offers SDKs in Go, Java, TypeScript, Python, .NET, Ruby, Rust, PHP, and CLI tools, enabling developers to build resilient, distributed applications across multiple programming languages.
