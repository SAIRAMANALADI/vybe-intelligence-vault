# python/mypy

## Summary

- **Purpose**: Optional static type checker for Python, enabling early detection of type-related errors through static analysis without requiring changes to runtime behavior.
- **Key Features**: Supports gradual typing, integrates with Python’s type hints (PEP 484), and enforces type safety across large codebases via a standalone linter.
- **Ecosystem Impact**: Widely adopted in Python projects for improving code maintainability; integrates with tools like `mypy-extensions`, `typing-extensions`, and CI pipelines.
