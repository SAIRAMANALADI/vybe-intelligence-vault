# RFC 6234: US Secure Hash Algorithms (SHA and SHA-based HMAC and HKDF) | RFC Editor

## Summary

- **RFC 6234** updates **RFC 4634**, obsoleting it while also updating **RFC 3174** (SHA-1), providing standardized implementations of **SHA-224, SHA-256, SHA-384, SHA-512**, along with **HMAC** and **HKDF** based on these algorithms.

- **Core technical sections** define bit/word operations, message padding (per FIPS 180-2), initialization/processing for SHA variants, and cryptographic constants/functions required for hash computation and key derivation.

- **Reference implementation** includes C code for SHA algorithms (`sha1.c`, `sha224-256.c`, `sha384-512.c`), HMAC, HKDF, and test drivers, supporting arbitrary-length input bit strings with standardized ASN.1 OIDs for algorithm identification.
