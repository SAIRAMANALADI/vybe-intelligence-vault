# ArcGIS Pro license levels | ArcGIS Pro documentation

## Summary

- **License Tiers**: ArcGIS Pro offers three license levels—Basic (Creator user type), Standard (Professional user type), and Advanced (Professional Plus user type)—with Standard/Advanced unlocking specialized functionality.
- **Core Functional Differences**: Standard/Advanced licenses are required for advanced data management (e.g., enterprise geodatabase schema modifications, topology validation), network editing (utility/trace/parcel fabrics), and imagery/remote sensing tasks (e.g., ortho mapping, elevation data generation).
- **Specialized Tools**: Advanced licenses enable high-end analytics (graph analytics, flood simulation, interactive object detection) and schema modifications (e.g., parcel fabric adjustments, network publishing).
