# CSS Modules | Vue Loader

## Summary

- **SFC Integration**: Vue Loader compiles Vue Single-File Components (SFCs) by processing `<template>`, `<script>`, and `<style>` blocks, enabling modular Vue.js development with webpack.

- **CSS Modules Support**: Enables modular CSS via `css-loader` with `modules: true`, injecting locally scoped class names into components as `$style` computed properties for dynamic class binding.

- **Hot Reload & Pre-Processors**: Supports HMR for Vue components and integrates with pre-processors (e.g., Sass, Less) while allowing asset URL handling and custom block processing for extended functionality.
