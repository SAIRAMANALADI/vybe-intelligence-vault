# castorini/pyserini

## Summary

- **Python-based IR Toolkit**: Pyserini provides a Python interface for reproducible information retrieval (IR) research, supporting both sparse (e.g., BM25) and dense (e.g., FAISS-indexed) retrieval methods.

- **Modular Architecture**: Integrates with Lucene for indexing and retrieval, while offering Python bindings for efficient search operations, including pre-built indexes for common IR datasets (e.g., MS MARCO, Wikipedia).

- **Reproducibility Focus**: Includes pre-configured pipelines and scripts to ensure consistent experimental setups, with support for hybrid retrieval (combining sparse and dense methods) and integration with PyTorch for deep learning-based IR models.
