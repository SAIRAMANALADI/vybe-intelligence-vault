# Quick Start - Soup Sieve

## Summary

- **CSS Selector Engine**: Soup Sieve is a CSS selector library for Beautiful Soup 4, implementing selectors from CSS level 1 to level 4 drafts, replacing Beautiful Soup's built-in `select` feature since version 4.7.0.
- **API & Functionality**: Provides direct API access (`select`, `select_one`, `closest`, `filter`, `match`, `comments`) with support for complex selectors, multi-line definitions, and comments, enabling advanced HTML/XML parsing.
- **Optimization & Caching**: Supports pre-compiled selectors for repeated use, with built-in caching (`purge()`) for performance optimization.
