# GitHub Pages | Websites for you and your projects, hosted directly from your GitHub repository. Just edit, push, and you

## Summary

- GitHub Pages hosts static websites directly from a GitHub repository, requiring only a push to deploy changes; one user/org site (`username.github.io`) and unlimited project sites are supported.
- Sites can be initialized via CLI (`git clone`, `git push`) or GitHub Desktop, with content served from the `main` branch after enabling GitHub Pages in repository settings.
- Themes can be applied via GitHub’s theme chooser or built from scratch; Jekyll enables Markdown-based blogging, and custom domains are configured via a `CNAME` file.
