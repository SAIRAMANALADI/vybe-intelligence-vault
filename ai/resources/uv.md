# uv

## Summary

- **Performance**: Rust-based implementation achieves **10-100x faster** dependency resolution/installation than `pip`, with sub-millisecond resolution times (e.g., 0.33ms for lockfile generation).
- **Unified Toolchain**: Replaces `pip`, `poetry`, `pipx`, `virtualenv`, etc., supporting **project management**, **script dependencies**, **tool execution** (`uvx`), and **Python version pinning** via a single binary.
- **Efficiency & Compatibility**: Uses a **global cache** for deduplication, supports **Cargo-style workspaces**, and provides a **pip-compatible CLI** (`uv pip`) while remaining installable without Rust/Python via `curl` or `pip`.
