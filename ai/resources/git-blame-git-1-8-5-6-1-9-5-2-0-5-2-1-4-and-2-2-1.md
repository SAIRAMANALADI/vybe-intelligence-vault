# Git Blame: Git 1.8.5.6, 1.9.5, 2.0.5, 2.1.4 and 2.2.1 and thanking friends in Mercurial land

## Summary

- **Case-Insensitive Filesystem Bypass**: Git's protection against committing `.git/` directory files was bypassed on case-insensitive filesystems (e.g., Windows, macOS) via permutations like `.Git/` or `.GIT/`, allowing malicious repository overrides.

- **Unicode Normalization Exploit**: HFS+ (macOS) treats certain Unicode ignorable characters (e.g., `\u200c`) as equivalent, enabling commits like `.g\u200cit/config` to overwrite `.git/config` during checkout.

- **Multi-Implementation Fixes**: Vulnerability (CVE-2014-9390) was patched across Git (v1.8.5.6, v1.9.5, v2.0.5, v2.1.4, v2.2.1), libgit2, JGit, and platform-specific ports (e.g., Git for Windows, Xcode) to prevent repository corruption via malicious paths.
