# ML Kit | Google for Developers

## Summary

- **On-device ML Processing**: ML Kit performs all computations locally on mobile devices, enabling real-time use cases (e.g., camera input processing), offline functionality, and enhanced privacy for sensitive data.

- **Prebuilt GenAI & Vision APIs**: Offers ready-to-use APIs for generative AI tasks (summarization, proofreading, rewriting) and vision-based features (barcode scanning, face/mesh detection, text recognition, object tracking).

- **Cross-Platform & Language Support**: Supports both iOS and Android with APIs for natural language processing (58 languages) and advanced features like selfie segmentation, pose detection, and document scanning.
