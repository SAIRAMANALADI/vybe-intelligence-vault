# Welcome to the Planetary Data System

## Summary

- **PDS Infrastructure**: NASA's Planetary Data System (PDS) will undergo a scheduled downtime for Search API upgrades on **June 16, 2026**, from 1 PM PDT, with an expected few-hour completion window.
- **PDS Beta Release**: A newly redesigned **beta version of the PDS website** (https://pds.mcp.nasa.gov/portal/) was launched, offering an integrated user experience for planetary science data access, tools, and documentation.
- **PDS Operational Framework**: PDS is a long-term NASA archive for planetary mission data, managed by planetary scientists, with peer-reviewed, documented datasets accessible via discipline-specific online catalogs and free tools under **TSPA classification**.
