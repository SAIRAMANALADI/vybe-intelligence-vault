# Turn on Match Dynamic Range or Match Frame Rate on your Apple TV - Apple Support

## Summary

- **Dynamic Range Matching**: Apple TV 4K can auto-match output dynamic range to source content via `Settings > Video and Audio > Match Content > Match Dynamic Range`, optimizing HDR/SDR output but may cause brief display blanking/flickering during format switching.

- **Frame Rate Matching**: Supports auto-matching refresh rates (24/25/30/50/60fps) via `Match Frame Rate`, including NTSC/PAL region-specific adaptations (e.g., 29.97fps), with frame rate doubling for smoother UI transitions when available.

- **Unverified Format Testing**: If auto-detection fails, manually verify supported formats under `Unverified Formats` in `Match Content` settings, running a display test to confirm compatibility before enabling.
