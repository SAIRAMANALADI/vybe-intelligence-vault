# requests · PyPI

## Summary

- **Python HTTP Library**: `requests` 2.34.2 is a high-level HTTP library for Python, supporting HTTP/1.1, connection pooling, keep-alive, and TLS/SSL verification with ~300M weekly downloads and 4M+ dependent repositories.

- **Dependencies & Compatibility**: Requires Python ≥3.10, supports CPython and PyPy, and offers optional extras (`security`, `socks`, `use-chardet-on-py3`) under the Apache-2.0 license.

- **Key Features**: Supports sessions, authentication, streaming downloads, SOCKS proxies, multipart uploads, and automatic content decompression/decoding with `.netrc` integration.
