# getsentry/sentry-go

## Summary

- **Official Go SDK for Sentry**: Provides Go integration with Sentry's error monitoring and crash reporting platform (`sentry.io`), enabling Go applications to capture and report errors, panics, and logs.

- **Key Features**: Supports error tracking, panic recovery, breadcrumbs, context enrichment, and custom performance monitoring with minimal overhead.

- **Integration & Extensibility**: Designed for production use with configurable transports, async event processing, and middleware support (e.g., HTTP handlers, Gin, Echo).
