# IPGP/EPOS Volcano Activity Reports Web Service | IPGP Data Center Web Services

## Summary

- **Web Service**: Provides volcano activity reports metadata in EPOS JSON format via HTTP-GET, defaulting to the most recent report if no parameters are specified.

- **Query Parameters**: Supports filtering by `start_time`, `end_time` (YYYY-MM-DD), `agency` (e.g., OVSM, OVSG, OVPF), `volcano` (French/ISO/ICAO names), `type` (e.g., VONA, weekly, eruption), and `language` (ISO 639-1 code).

- **Version & Specs**: Current version is `1.0` (released 08/11/2018), with detailed service specifications available in [IPGP_volcano-reports_specifications.pdf](http://volobsis.ipgp.fr/docs/IPGP_volcano-reports_specifications.pdf).
