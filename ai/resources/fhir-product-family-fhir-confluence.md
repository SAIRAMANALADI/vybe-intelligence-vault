# FHIR Product Family - FHIR - Confluence

## Summary

- **FHIR Community & Governance**: Centralized hub for HL7 FHIR community resources, including governance groups (FMG, MnM), IP rules, trademark policies, and community engagement via Connectathons and chat.fhir.org.

- **Implementation & Tooling**: Provides FHIR validator, IG publishing requirements, transformation tools (R2-R3/R3-R4), testing platforms, and open-source implementations for developers and implementers.

- **Specification & Development**: Hosts FHIR core specification (R4), maturity model, continuous integration builds, resource authoring guidelines, and IG publishing workflows for specification developers.
