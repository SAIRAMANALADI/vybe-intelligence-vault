# Relay Search

## Summary

- **Tor Metrics Portal**: Centralized platform providing real-time and historical data on Tor network performance, including user statistics, relay/server counts, bandwidth usage, and onion service activity.

- **Relay Search Tool**: Web-based service requiring JavaScript (disabled in Tor Browser's Safest mode) to query and visualize Tor relay metadata, facilitating network analysis and diagnostics.
