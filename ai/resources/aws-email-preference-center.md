# AWS Email Preference Center

## Summary

- **Unsubscribe Mechanism**: AWS provides a dedicated form to unsubscribe from all marketing emails, accessible via [AWS Marketing Preferences](https://pages.awscloud.com/email/manage).
- **Transactional Emails Retained**: Unsubscribing only removes marketing emails; transactional emails (e.g., service-related notifications) remain unaffected.
- **Reason Tracking**: Optional form fields capture unsubscription reasons (e.g., email irrelevance, preference changes) for AWS marketing optimization.
