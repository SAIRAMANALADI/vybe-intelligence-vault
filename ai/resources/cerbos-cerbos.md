# cerbos/cerbos

## Summary

- **Policy-Driven Authorization Engine**: Cerbos implements a language-agnostic, context-aware access control system using declarative policies (written in a custom DSL) to enforce fine-grained permissions on application resources at runtime.

- **Scalable & Distributed Architecture**: Built in Go, it supports horizontal scaling via Kubernetes-native deployment, enabling high-throughput policy evaluation with low latency for distributed systems.

- **Integration-Friendly & Extensible**: Provides SDKs and APIs for seamless integration with applications (e.g., REST/gRPC), supports custom attribute resolvers, and allows policy hot-reloading without downtime.
