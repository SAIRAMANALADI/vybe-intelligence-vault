# babelmark3 | Compare Markdown Implementations

## Summary

- **Cross-Implementation Markdown Comparison Tool**: Babelmark III enables side-by-side comparison of Markdown parsing outputs across 20+ implementations (e.g., CommonMark, GitHub Flavored Markdown, Pandoc) to identify inconsistencies in syntax handling.

- **Normalization & Conversion Utility**: Supports normalization of Markdown to a canonical form and conversion of `CTRL+ENTER` line breaks to standard Markdown line endings (e.g., `\n` or `\n\n`).

- **Open-Source & Feedback-Driven**: Hosted under MIT License (2016) by Alexandre Mutel, with an issue tracker for community-driven improvements and bug reporting.
