# Gravitee Documentation

## Summary

- **Open-source event-native API management platform** supporting both synchronous and asynchronous APIs across the entire lifecycle (design, deploy, manage, secure).

- **Modular product suite** including API Management, Access Management (IAM), Kubernetes Operator, Alert Engine, and API Designer with no-code OpenAPI compliance.

- **Key features**: Gravitee Kafka Gateway for event streaming, Developer Portal for API cataloging, and Streaming Proxy for real-time data exposure with federation capabilities.
