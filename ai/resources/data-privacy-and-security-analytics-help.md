# Data privacy and security - Analytics Help

## Summary

- **Data Privacy & Security Controls**: Google Analytics (GA4/UA) provides granular privacy controls including user consent management, data redaction, behavioral modeling for consent mode, and opt-out browser add-ons to comply with regional regulations (EU/UK/Switzerland) and HIPAA.
- **Data Processing & Retention**: Features include IP masking (UA), data retention policies (configurable up to 14 months), automated data-deletion requests, and adherence to ISO 27001 certification for secure data handling.
- **PII & Compliance Safeguards**: Best practices enforce avoidance of Personally Identifiable Information (PII) transmission, policy-based data sharing settings, and transparency against fingerprinting/locally shared objects (LSOs).
