# Stylus | An expressive, robust, feature-rich CSS language built for Node.js

## Summary

- **Purpose**: Born as a Node.js-specific web framework in 2010 by TJ Holowaychuk to optimize server-side JavaScript development.
- **Key Features**: Lightweight, modular, and designed for high performance with middleware support and RESTful routing.
- **Impact**: Laid groundwork for modern Node.js backend frameworks, influencing Express.js and Koa.
