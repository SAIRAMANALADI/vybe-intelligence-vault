# Overview (egeria 6.1-SNAPSHOT API)

## Summary

- **Apache Atlas Integration**: Packages provide connectors for Apache Atlas, including REST API interfaces (`org.odpi.openmetadata.adapters.connectors.apacheatlas.resource`), glossary term publishing (`org.odpi.openmetadata.adapters.connectors.apacheatlas.integration`), and control mechanisms (`org.odpi.openmetadata.adapters.connectors.apacheatlas.controls`).

- **Kafka & File Connectors**: Includes Kafka topic cataloging (`org.odpi.openmetadata.adapters.connectors.apachekafka.integration`) and file/directory resource connectors (`org.odpi.openmetadata.adapters.connectors.datastore.basicfile`, `org.odpi.openmetadata.adapters.connectors.datastore.csvfile`, `org.odpi.openmetadata.adapters.connectors.datastore.datafolder`).

- **Governance & Integration Services**: Features governance action services for provisioning, remediation, verification, and watchdog monitoring (`org.odpi.openmetadata.adapters.connectors.governanceactions.*`), along with basic file integration connectors (`org.odpi.openmetadata.adapters.connectors.integration.basicfiles`) and CSV lineage importer (`org.odpi.openmetadata.adapters.connectors.integration.csvlineageimporter`).
