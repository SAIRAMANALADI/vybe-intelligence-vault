# Connections Overview | Twilio

## Summary

- **Unified Data Collection**: Segment's Connections aggregates event data from multiple sources (mobile apps, websites, servers) via a single API, enriching it with contextual data from cloud apps (CRM, payment systems, databases) to create a comprehensive customer profile.

- **Source & Destination Architecture**: Each data source (website/app/server) requires a dedicated Source with a unique write key; Destinations (e.g., Google Analytics, data warehouses) are enabled via an abstraction layer, eliminating per-tool integration code by translating data formats automatically.

- **Warehouse & Reverse ETL**: Warehouses store structured, bulk-loaded data from Sources, with schema auto-adjustment; Reverse ETL enables pushing data from warehouses back to Destinations, extending warehouse data utility.
