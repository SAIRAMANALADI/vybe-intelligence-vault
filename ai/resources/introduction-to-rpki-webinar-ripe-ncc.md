# Introduction to RPKI Webinar - RIPE NCC

## Summary

- **RPKI Overview**: Webinar introduces RPKI to secure BGP routing by addressing vulnerabilities like route hijacking and misconfigurations through cryptographic validation of IP prefix ownership.
- **Implementation Models**: Covers two RPKI deployment approaches—hosted (RPKI repository managed by a Regional Internet Registry) and delegated (local RPKI repository management)—with guidance for selection based on operational needs.
- **Validation & Goals**: Explains RPKI’s role in validating BGP announcements via Route Origin Authorizations (ROAs), enabling network operators to filter invalid routes and mitigate BGP security threats.
