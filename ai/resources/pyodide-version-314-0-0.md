# Pyodide — Version 314.0.2

## Summary

- **Port of CPython to WebAssembly**: Pyodide compiles CPython to WebAssembly via Emscripten, enabling Python execution in browsers/Node.js with full access to Web APIs.
- **Package Support & FFI**: Supports pure Python wheels from PyPI and many C/C++/Rust extension packages (e.g., NumPy, pandas). Features a robust JS↔Python FFI for seamless interoperability, including error handling and async/await.
- **Micropip & Deployment**: Uses `micropip` for package installation in-browser; can be deployed via hosted distributions, self-hosted releases, or bundlers. Includes tools for package maintainers (`pyodide-build`) and contributors.
