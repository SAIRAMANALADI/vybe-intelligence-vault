# Pyodide — Version 314.0.0

## Summary

- **Port of CPython to WebAssembly**: Pyodide is a CPython distribution compiled to WebAssembly via Emscripten, enabling Python execution in browsers and Node.js.

- **Python-JavaScript Interoperability**: Provides a robust FFI for seamless mixing of Python and JavaScript, including error handling, async/await, and full access to Web APIs when running in a browser.

- **Package Support**: Supports pure Python wheels from PyPI and many C/C++/Rust extension packages (e.g., NumPy, pandas, SciPy) via `micropip`, with additional tools for package integration and development.
