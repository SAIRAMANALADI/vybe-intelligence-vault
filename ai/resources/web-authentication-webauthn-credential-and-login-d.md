# Web Authentication (WebAuthn) Credential and Login Demo

## Summary

- **WebAuthn Standard**: Enables web applications to create and use strong, attested, scoped, public key-based credentials for user authentication via hardware authenticators, adhering to the [W3C WebAuthn specification](https://www.w3.org/TR/webauthn/).

- **Credential Lifecycle**: Involves registration (generating `rawId` and public key), authentication (using `rawId`), and user presence verification (via biometric or physical interaction with the authenticator).

- **Browser Support & Integration**: Supported in modern browsers (Firefox, Chrome, Edge) but requires explicit user interaction; Auth0 provides a framework to integrate WebAuthn as a second-factor authentication method.
