# BuddyPress Developer Resources | Your best buddies ever to help you code.

## Summary

- **WordPress Core Development**: Official resources include [Trac](https://core.trac.wordpress.org) for issue tracking and [Developer Blog](https://make.wordpress.org) for updates, with documentation hosted on [WordPress Codex](https://codex.wordpress.org/).

- **bbPress & BuddyPress**: Both projects provide [Trac](https://bbpress.trac.wordpress.org) and [Developer Blogs](https://bbpdevel.wordpress.com) for development tracking, alongside [Codex](https://codex.bbpress.org/) and [support forums](https://bbpress.org/forums/).

- **BuddyPress REST API & Contribution**: Includes a [REST API reference](https://developer.buddypress.org/bp-rest-api/), [Trac](https://buddypress.trac.wordpress.org) for contributions, and [developer resources](https://developer.buddypress.org/reference).
