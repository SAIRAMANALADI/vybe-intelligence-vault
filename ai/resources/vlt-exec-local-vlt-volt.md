# vlt exec-local | vlt /vōlt/

## Summary

- Executes arbitrary commands with locally installed packages prioritized in `PATH` via `vlt exec-local [command]` or `vlt xl [command]`
- Spawns a shell in the current directory with local package bins first in `PATH` if no command is provided
- VLT configurations must precede the command; all subsequent arguments are passed directly to the executed process
