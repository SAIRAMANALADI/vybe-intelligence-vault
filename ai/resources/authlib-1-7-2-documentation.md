# Authlib 1.7.2 documentation

## Summary

- **Purpose**: Authlib is a Python library for building OAuth 1.0/2.0 and OpenID Connect (OIDC) servers/clients, supporting low-level spec implementations and high-level framework integrations.

- **Compatibility**: Requires Python 3.10+, with modules for OAuth/OIDC flows, JOSE (JWS/JWE/JWT/JWK), and provider/client implementations.

- **Features**: Includes client/server support for OAuth 1.0/2.0, OIDC, and cryptographic operations (JOSE), with active community maintenance and security-focused updates.
