# Wikitech

## Summary

- **Wikitech** is a technical documentation wiki for Wikimedia's infrastructure and services, requiring a **Wikimedia unified account (SUL)** with confirmed email for editing, unlike most other Wikimedia wikis.

- **Wikimedia Cloud Services (WMCS)** provides tools and services for technical contributors, including **Toolforge** (hosting for bots/webservices), **Data Services** (PAWS, Quarry, Superset), and **Cloud VPS** (OpenStack-based cloud computing infrastructure).

- **Wikimedia production** infrastructure powers live WMF websites, maintained by Site Reliability Engineering, including **MediaWiki deployments**, **data centers**, **CDN**, and **Data Platform** for data discovery and usage.
