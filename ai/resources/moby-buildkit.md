# Releases · moby/buildkit · GitHub

## Summary

- **Dockerfile Frontend Update**: BuildKit v0.32.0 integrates Dockerfile frontend v1.26.0, introducing OCI artifact descriptor support for attestations by default (fallback to `oci-artifacts=false` for non-OCI-compliant registries).

- **Performance & Security Enhancements**: Bolt database optimizations, Runc runtime update to v1.4.3, OCI mediatype adoption for remote cache backends, and Windows SBOM scanner support.

- **Tracing & Dependency Updates**: Deprecation of legacy OTEL variables (`OTEL_TRACE_PARENT`, `OTEL_TRACE_STATE`), improved SSH port handling, and major dependency upgrades (e.g., `go.etcd.io/bbolt` v1.5.0, `golang.org/x/sys` v0.47.0).
