# Add data to Cloud Firestore | Firebase

## Summary

- **Cloud Firestore Enterprise Edition in Native Mode** is now available, offering enhanced performance, scalability, and advanced features for enterprise-grade applications.

- **Data Operations** in Cloud Firestore include:
  - **Set**: Explicitly define document data with a specified ID.
  - **Add**: Automatically generate a document ID and insert data.
  - **Update**: Modify existing document fields without overwriting the entire document.

- **Initialization** requires:
  - A configured Firestore database.
  - Authentication via security rules (web/mobile) or IAM (server/REST).
  - SDK-specific setup (e.g., `getFirestore(app)` in Web, `Firestore.firestore()` in Swift).
