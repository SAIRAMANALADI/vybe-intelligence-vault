# spotify/annoy

## Summary

- **Optimized ANN Library**: Implements **Approximate Nearest Neighbor (ANN)** search using **random projection trees** (via **Locality-Sensitive Hashing (LSH)**) for high-dimensional data, prioritizing **memory efficiency** and **fast disk I/O** via mmap.

- **Multi-Language Support**: Core C++ backend with **Python bindings** (via `pybind11`), plus **Go** and **Lua** interfaces; supports **saving/loading** index structures to/from disk for persistence.

- **Scalability & Performance**: Designed for **low-latency** queries with **O(log n)** search time complexity; optimized for **large-scale datasets** (millions/billions of vectors) while minimizing RAM footprint.
