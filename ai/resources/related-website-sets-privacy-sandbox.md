# Related Website Sets | Privacy Sandbox

## Summary

- **Deprecation Status**: Google has halted submissions for **Related Website Sets (RWS)**, formerly First-Party Sets, as part of the Privacy Sandbox phase-out, per the [Update on Plans for Privacy Sandbox Technologies](https://privacysandbox.com/news/update-on-plans-for-privacy-sandbox-technologies).
- **Functionality**: RWS allowed cross-site cookie access for declared domain relationships (e.g., `brandx.com`, `fly-brandx.com`) via a primary domain and member domains, enabling shared identity/use cases (e.g., SSO, cart persistence) without third-party cookies.
- **Technical Scope**: RWS submissions are no longer accepted; Chrome’s [IP Protection](http://developer.chrome.com/protections/ip-protection) may still use RWS domain relationships for context determination on the [Masked Domain List](https://github.com/GoogleChrome/ip-protection/blob/master/Masked-Domain-List.md).
