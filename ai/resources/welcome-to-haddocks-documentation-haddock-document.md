# Welcome to Haddock’s documentation! — Haddock documentation

## Summary

- **Haddock** is an automated documentation generator for Haskell source code, parsing annotations to produce structured API documentation.

- **Key features** include support for literate/pre-processed source, incremental mode, and fine-grained control over declaration documentation via markup syntax.

- **Error handling** includes specific parsing diagnostics for malformed Haddock comments (e.g., `‘-- | xxx’` or `‘-- $ xxx’` syntax errors).
