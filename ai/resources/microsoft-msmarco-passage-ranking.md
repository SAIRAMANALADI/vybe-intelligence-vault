# microsoft/MSMARCO-Passage-Ranking

## Summary

- **Task Definition**: Rerank top-1000 BM25-retrieved passages for a given query to maximize the rank of the most relevant passage, evaluated using **Mean Reciprocal Rank (MRR)**.

- **Dataset Characteristics**: MS MARCO Passage Ranking is a large-scale dataset for machine reading comprehension, question answering, and passage ranking, with human-labeled relevance labels missing for some passages.

- **Evaluation Metric**: Performance is measured via **MRR**, emphasizing the rank of the first correct passage in the reranked list.
