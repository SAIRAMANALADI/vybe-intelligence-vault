# mypy 2.1.0 documentation

## Summary

- **Static type checking**: Mypy is a static type checker for Python that enforces type hints (per [PEP 484](https://peps.python.org/pep-0484/)) to detect type-related errors without executing the code, contrasting with Python's dynamic runtime checks.

- **Gradual typing & type system features**: Supports gradual adoption of static typing with type inference, generics, union types, structural subtyping (protocols), and advanced constructs like `TypedDict`, `Literal` types, and `NoReturn`.

- **Configuration & runtime compatibility**: Provides strict mode, stub file support, and runtime-safe type hints (e.g., `typing.TYPE_CHECKING`, `PEP 563`), while allowing dynamic typing fallback and handling edge cases like metaclasses and import cycles.
