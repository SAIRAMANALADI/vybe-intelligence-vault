# mypy 2.1.0 documentation

## Summary

- **Static Type Checking**: Mypy is a static type checker for Python that validates type hints (PEP 484) without executing code, catching type-related errors early by analyzing variable and function usage against declared types.

- **Gradual Typing & Compatibility**: Supports gradual adoption of static typing in dynamic Python codebases, with backward compatibility maintained where possible, though major version bumps may occur for breaking changes.

- **Advanced Type System Features**: Implements type inference, generics, union types, structural subtyping (protocols), callable types, and supports stub files (`.pyi`) for type definitions in untyped libraries.
