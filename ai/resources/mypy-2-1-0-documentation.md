# mypy 2.1.0 documentation

## Summary

- **Static Type Checking**: Mypy is a static type checker for Python that enforces type correctness via type hints (PEP 484) without executing code, catching errors pre-runtime (e.g., `str` vs `int` operations).

- **Gradual Typing & Compatibility**: Supports incremental adoption of static typing in dynamic Python codebases, with structural subtyping, generics, unions, and type inference while maintaining runtime compatibility via annotations-as-comments.

- **Advanced Type System**: Implements PEP 544 protocols, TypedDict, literal types, `NoReturn`, `NewType`, and variance-aware generics, with tools for narrowing types (`TypeIs`, `isinstance`), stub files, and metaclass support.
