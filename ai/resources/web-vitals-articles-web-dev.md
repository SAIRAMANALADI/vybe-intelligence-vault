# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals Metrics**: Three stable metrics define user experience: **LCP** (≤2.5s for loading performance), **INP** (≤200ms for interactivity), and **CLS** (≤0.1 for visual stability), measured at the **75th percentile** across mobile/desktop devices.

- **Lifecycle & Evolution**: Metrics progress through **experimental → pending → stable** phases; INP replaced FID in 2024 after validation, with updates communicated via changelogs and documentation.

- **Measurement Tools**: Field data via **CrUX** (Chrome UX Report), **PageSpeed Insights**, and **Search Console**; lab tools like **Lighthouse** (using TBT proxy for INP) and **Chrome DevTools** enable pre-release optimization.
