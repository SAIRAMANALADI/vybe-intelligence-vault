# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals Metrics & Thresholds**: Largest Contentful Paint (LCP) ≤2.5s, Interaction to Next Paint (INP) ≤200ms, and Cumulative Layout Shift (CLS) ≤0.1, measured at the 75th percentile across mobile/desktop for field data validation.

- **Lifecycle & Evolution**: Metrics progress through experimental → pending → stable phases; INP replaced FID in 2024 as a stable Core Web Vital after lifecycle validation.

- **Measurement Tools**: Field tools (CrUX, PageSpeed Insights, Search Console) and lab tools (Chrome DevTools, Lighthouse) support Core Web Vitals; JavaScript library `web-vitals` enables direct metric tracking via standard web APIs.
