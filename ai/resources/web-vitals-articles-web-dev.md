# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals (CWV)**: Three stable metrics—LCP (<2.5s), INP (<200ms), and CLS (<0.1)—quantify user experience (loading, interactivity, visual stability), measured at the 75th percentile across mobile/desktop.

- **Lifecycle & Tools**: CWV metrics evolve through experimental/pending/stable phases; Google’s tools (CrUX, PageSpeed Insights, Search Console) and the `web-vitals` JavaScript library enable field/lab measurement and reporting.

- **Optimization Guides**: Targeted resources (e.g., [Optimize LCP](https://web.dev/articles/optimize-lcp)) provide actionable strategies; lab tools (Lighthouse, DevTools) proxy INP via TBT, while field data is critical for accurate diagnosis.
