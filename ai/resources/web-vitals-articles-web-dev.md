# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals Metrics & Thresholds**: Three stable metrics define Core Web Vitals: **LCP** (≤2.5s for loading performance), **INP** (≤200ms for interactivity), and **CLS** (≤0.1 for visual stability), measured at the **75th percentile** across mobile/desktop devices.

- **Lifecycle & Evolution**: Core Web Vitals progress through experimental → pending → stable phases; **INP replaced FID** in 2024, while LCP and CLS remain stable, with annual updates possible.

- **Measurement Tools**: Field tools (CrUX, PageSpeed Insights, Search Console) and lab tools (Chrome DevTools, Lighthouse) assess Core Web Vitals; JavaScript library [`web-vitals`](https://github.com/GoogleChrome/web-vitals) enables custom RUM implementation.
