# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals Metrics & Thresholds**: Defined by Google, Core Web Vitals include Largest Contentful Paint (LCP ≤ 2.5s), Interaction to Next Paint (INP ≤ 200ms), and Cumulative Layout Shift (CLS ≤ 0.1), measured at the 75th percentile across mobile/desktop for field data accuracy.

- **Lifecycle & Evolution**: Metrics progress through experimental → pending → stable phases; INP replaced FID in 2024 after validation, with updates communicated via official docs/changelogs and limited to annual changes for stable metrics.

- **Measurement Tools & Implementation**: Field tools (CrUX, PageSpeed Insights, Search Console) and lab tools (Chrome DevTools, Lighthouse) support Core Web Vitals; JavaScript library `web-vitals` enables real-user monitoring (RUM) via standard APIs, while lab metrics like TBT proxy INP for pre-release testing.
