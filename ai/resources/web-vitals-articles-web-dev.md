# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals Metrics & Thresholds**: Three stable metrics define Core Web Vitals—**LCP** (<2.5s), **INP** (<200ms), and **CLS** (<0.1)—measured at the 75th percentile across mobile/desktop for field data compliance.

- **Lifecycle & Evolution**: Metrics progress through **experimental → pending → stable** phases; **INP** replaced **FID** in 2024, with annual updates possible for stable metrics based on real-world testing.

- **Measurement Tools**: Field data via **CrUX**, **PageSpeed Insights**, and **Search Console**; lab tools like **Lighthouse** (TBT proxy for INP) and **Chrome DevTools**; JavaScript implementation via the [web-vitals](https://github.com/GoogleChrome/web-vitals) library.
