# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals (CWV)**: Three stable metrics—LCP (<2.5s), INP (<200ms), and CLS (<0.1)—quantify user experience (loading, interactivity, visual stability) and are measured at the **75th percentile** across mobile/desktop via Google tools (CrUX, PSI, Search Console).

- **Lifecycle & Evolution**: CWV metrics progress through experimental → pending → stable phases; INP replaced FID in 2024, with annual updates possible for stable metrics based on real-world feedback and technical validation.

- **Measurement Tools**: Field data via CrUX/PSI/DevTools; lab tools (Lighthouse/DevTools) proxy INP via TBT; JavaScript library `web-vitals` enables custom RUM for granular diagnostics and regression tracking.
