# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals Metrics & Thresholds**: Largest Contentful Paint (LCP) ≤ 2.5s, Interaction to Next Paint (INP) ≤ 200ms, and Cumulative Layout Shift (CLS) ≤ 0.1, measured at the 75th percentile across mobile/desktop devices.

- **Lifecycle Phases**: Core Web Vitals metrics progress through experimental, pending, and stable phases, with INP transitioning from experimental to stable in 2024, replacing FID.

- **Measurement Tools**: Field tools (CrUX, PageSpeed Insights, Search Console) and lab tools (Chrome DevTools, Lighthouse) assess Core Web Vitals, while the `web-vitals` JavaScript library enables real-user monitoring via standard web APIs.
