# Web Vitals | Articles | web.dev

## Summary

- **Core Web Vitals Metrics**: Defined by Google as essential user-centric performance metrics, currently consisting of **Largest Contentful Paint (LCP)** (<2.5s), **Interaction to Next Paint (INP)** (<200ms), and **Cumulative Layout Shift (CLS)** (<0.1), measured at the **75th percentile** across mobile/desktop for field data.

- **Lifecycle & Evolution**: Metrics progress through **experimental → pending → stable** phases; INP replaced FID in 2024 after validation, with updates communicated via changelogs and documentation.

- **Measurement Tools**: Field data via **CrUX**, **PageSpeed Insights**, and **Search Console**; lab tools like **Lighthouse** (TBT proxy for INP) and **Chrome DevTools**; JavaScript implementation via the [`web-vitals`](https://github.com/GoogleChrome/web-vitals) library for real-user monitoring (RUM).
