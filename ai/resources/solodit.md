# Solodit

## Summary

- **Aggregation & Categorization**: Solodit consolidates >20,000 vulnerability reports from top audit platforms (e.g., CodeHawks, Code4rena, Sherlock), enabling searchable, categorized access for security researchers and developers.

- **Advanced Features**: Supports filtering by protocol, vulnerability type, severity, and includes community ratings, personal note-taking, and leaderboards to track top researchers.

- **Community-Driven Tools**: Provides vulnerability tagging, note management, and aggregated leaderboards, with functionality to submit new findings and rate existing ones for collaborative research.
