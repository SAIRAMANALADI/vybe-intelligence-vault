# build · PyPI

## Summary

- **Python Build Frontend**: `build` is a minimal, correct Python build frontend compliant with PEP 517/518, enabling isolated builds of Python packages into source distributions (SDist) and wheels via `python -m build` or `pyproject-build`.

- **Dependencies & Extras**: Requires Python ≥3.10, supports extras `keyring`, `uv` (for faster virtualenv creation), and `virtualenv`; integrates with tools like `pipx`, `uv`, `cibuildwheel`, and `conda-forge`.

- **CLI & Configuration**: Supports granular control via flags (`--sdist`, `--wheel`, `--metadata`, `--installer=uv/pip`, `--no-isolation`), PEP 517 `-C` config settings, and JSON-based configuration (`--config-json`), with output directed to `dist/` by default.
