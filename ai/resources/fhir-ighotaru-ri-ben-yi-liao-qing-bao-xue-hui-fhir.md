# FHIR IGポータル – 日本医療情報学会FHIR日本実装検討WGが策定に関わったHL7 FHIR®仕様・規格のポータルサイトです。

## Summary

- **FHIR Implementation Guides (IGs):**
  - **HS037/HS038/HS039:** Specify HL7 FHIR v1.x profiles for eCheckup, eReferral, and eDischargeSummary documents (PDFs: v1.7.0/v1.12, IGs integrated into CLINS-IG).
  - **CLINS-IG v1.12:** Consolidates 2 documents + 6 data types for EHR sharing, requiring **JP FHIR Terminology v2.x** (Ver.2.2601.0).
  - **HS036:** Prescription data FHIR spec (v1.0.2) remains incompatible with 3-document/6-data standards.

- **Terminology Dependencies:**
  - **JP FHIR Terminology v2.x** (202606) is mandatory for CLINS-IG v1.12+ (supports Ver.1.13.0-pre).
  - **JFAGY v2026.5.31:** Manages allergen codes as a supplementary FHIR terminology resource.

- **Validation & Compatibility:**
  - **FHIR JP CORE v1.1.2** is deprecated for CLINS validation; use **v1.1.2-clins** per CLINS IG.
  - All specs align with HL7 FHIR standards but require domain-specific (JP) extensions for local compliance.
