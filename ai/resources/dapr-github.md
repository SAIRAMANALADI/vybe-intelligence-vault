## Summary

- **Portable runtime**: Dapr is a vendor-neutral, event-driven runtime designed for building distributed applications across cloud and edge environments.

- **Component-based architecture**: Provides standardized APIs for common distributed system patterns (e.g., pub/sub, state management, bindings) via reusable components.

- **Sidecar pattern**: Implements application logic via lightweight sidecar processes (Dapr runtime) that abstract infrastructure concerns from application code.
