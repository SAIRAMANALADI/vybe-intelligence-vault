# CTAN: Package latexdiff

## Summary

- **Purpose**: `latexdiff` is a Perl script that visually marks significant differences between two LaTeX files using LaTeX packages (e.g., `color`), including changes in non-visible text (e.g., formatting commands).

- **Functionality**: Includes `latexrevise` for automated revision (accept/reject all changes) and supports manual editing of the difference file for selective changes.

- **Metadata**: Version `2026-01-02`, licensed under GPLv3, maintained by Frederik Tilmann, and included in TeX Live and MiKTeX distributions.
