# DocBook.org

## Summary

- **DocBook**: An XML vocabulary optimized for hardware/software documentation, continuously developed since the mid-1990s, now maintained independently after OASIS Technical Committee closure (Sept. 2024).
- **Resources**: Hosts schemas, stylesheets (HTML/paged media transforms), and documentation at [docbook.org](https://www.docbook.org/), with an archived legacy version available.
- **Community**: Post-TC closure, development is driven by community input (e.g., DocBook V.next features) via the [mailing lists](https://www.docbook.org/lists/).
