# Find & control your Web & App Activity - Computer - Google Search Help

## Summary

- **Web & App Activity** logs data from Google services (e.g., Assistant, TV, Store) and associated metadata (language, device type, location, IP) to personalize recommendations and improve services, with options to toggle or delete this data via [My Activity](https://myactivity.google.com/myactivity).

- Enabling **Web & App Activity** includes Chrome history, Android diagnostics, and Assistant voice/audio recordings (if explicitly enabled), while disabling it allows selective deletion of stored activity or full opt-out with data removal.

- Activity persists even when offline and may influence personalized ads/search results; users can mitigate this via Incognito mode or granular controls in [Personalization settings](https://myaccount.google.com/activitycontrols/search).
