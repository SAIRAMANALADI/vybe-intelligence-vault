# tree-sitter · GitHub

## Summary

- **Incremental Parsing Engine**: Tree-sitter is an incremental parsing library and parser generator that builds and updates concrete syntax trees (CSTs) for source files efficiently, enabling real-time parsing during text editor edits.

- **Multi-Language Support & Performance**: Designed to parse any programming language with a runtime written in pure C, it achieves keystroke-level parsing speed while remaining dependency-free for embedding in applications.

- **Robustness & Bindings**: Supports parsing even with syntax errors and provides bindings for Rust, WASM, and a CLI tool, with community-maintained grammars available for various languages.
