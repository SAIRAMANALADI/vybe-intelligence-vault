# Release Notes | PageSpeed Insights | Google for Developers

## Summary

- **Analysis Engine & Data Sources**: PageSpeed Insights (PSI) uses Lighthouse for lab analysis and integrates field data from the Chrome User Experience Report (CrUX), with API/UI updates introducing new metrics (e.g., INP, TTFB) and CPU throttling adjustments for mobile TBT scoring.

- **Versioning & Breaking Changes**: PSI API v5 is current (v1-v4 deprecated), with Lighthouse versions updated independently, causing occasional breaking API changes (e.g., PWA category removal in v12.0, INP metric stabilization in v13.0).

- **UI/UX & Feature Updates**: Shareable analysis links (30-day snapshots) were introduced in March 2023, with UI improvements including parallel field/lab data loading, redirect resolution, and expanded Lighthouse categories (Accessibility, Best Practices, SEO) in lab data.
