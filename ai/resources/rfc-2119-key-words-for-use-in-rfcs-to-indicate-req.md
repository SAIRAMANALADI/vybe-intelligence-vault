# RFC 2119 - Key words for use in RFCs to Indicate Requirement Levels

## Summary

- **RFC 2119 defines standardized requirement levels** (`MUST`, `SHOULD`, `MAY`, etc.) for IETF specifications to ensure unambiguous interpretation of protocol requirements and options.

- **Imperatives are strictly defined**: `MUST`/`MUST NOT` (absolute requirements/prohibitions), `SHOULD`/`SHOULD NOT` (recommendations with exceptions), and `MAY`/`OPTIONAL` (implementation choices with interoperability constraints).

- **Security implications must be explicitly addressed** in RFCs using these terms, as non-compliance may introduce subtle vulnerabilities requiring detailed documentation.
