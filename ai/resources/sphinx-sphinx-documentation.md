# Sphinx — Sphinx documentation

## Summary

- **Documentation Generation**: Sphinx supports authoring in reStructuredText or MyST Markdown, enabling structured technical documents with tables, code blocks, math notations, and cross-references across projects via `intersphinx`.
- **Multi-Format Output**: Generates documentation in HTML, LaTeX (PDF), ePub, Texinfo, and other formats using configurable builders and LaTeX customization via `latex_elements` and `sphinxsetup`.
- **Extensible & Automated**: Provides extension mechanisms for custom functionality (e.g., API docs via `autodoc`), supports Python/C++ domains, and offers theme customization (built-in/third-party) and internationalization (i18n).
