# Sphinx — Sphinx documentation

## Summary

- **Documentation Generation**: Sphinx converts reStructuredText or MyST Markdown into structured technical documents, supporting cross-references, tables, code blocks, mathematical notations, and multi-format outputs (HTML, LaTeX/PDF, ePub, Texinfo).

- **Extensibility & Automation**: Supports API documentation generation (Python, C++, etc.) via `autodoc`, with robust extension mechanisms for custom functionality (e.g., diagrams, testing) and inter-project referencing (`intersphinx`).

- **Internationalization & Theming**: Enables multilingual documentation (i18n) and offers extensive HTML theme customization (built-in/third-party) with programmatic configuration for LaTeX/PDF output.
