# RAIVNLab/MRL

## Summary

- **Matryoshka Representation Learning (MRL)**: Implements hierarchical, nested representation learning where inner layers capture compressed feature subsets while outer layers retain full-dimensional representations, enabling scalable trade-offs between performance and compute.

- **Jupyter Notebook Implementation**: Repository contains executable notebooks demonstrating MRL across vision (e.g., ResNet, ViT) and NLP tasks, with modular APIs for custom embedding nesting depths and loss functions.

- **Dynamic Dimensionality Adaptation**: Supports adaptive inference by selecting optimal embedding dimensions at runtime without retraining, optimizing throughput/accuracy trade-offs for deployment constraints.
