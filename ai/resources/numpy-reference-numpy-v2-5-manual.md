# NumPy reference — NumPy v2.5 Manual

## Summary

- **Core Data Structures**: NumPy's primary data structure is the `ndarray`, an N-dimensional array with support for scalars, custom data types (`dtype`), and masked arrays for handling missing data.

- **Computational Routines**: Provides optimized routines for array creation, manipulation, mathematical operations (including linear algebra and FFT), bitwise operations, and random sampling, all implemented as universal functions (`ufuncs`) for vectorized computations.

- **APIs and Extensibility**: Offers a Python API with typing support and a C API for low-level operations, including memory management, SIMD optimizations, and thread safety, enabling integration with external libraries and performance-critical applications.
