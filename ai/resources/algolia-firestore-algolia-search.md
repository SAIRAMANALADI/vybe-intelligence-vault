# GitHub - algolia/firestore-algolia-search at 6af4b6de9301f25718743af54105d37ebd0606f1 · GitHub

## Summary

- **Sync Mechanism**: Firestore extension indexes specified collection/subcollection fields to Algolia, syncing CRUD operations (create/update/delete) in real-time using Firestore document triggers and Cloud Functions.
- **Configuration & Data Handling**: Supports custom field indexing, alternative `objectID` mapping (e.g., document path), and optional data transformation via a callable Cloud Function before Algolia ingestion.
- **Prerequisites & Billing**: Requires Firestore (Blaze plan) and Algolia accounts; costs include Firestore/Cloud Functions usage and Algolia’s pricing tiers.
