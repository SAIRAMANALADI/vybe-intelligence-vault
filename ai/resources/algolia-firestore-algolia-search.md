# GitHub - algolia/firestore-algolia-search at 36c6ebd00e6a2b43cdc6103ee2f54a5a0d8c56fe · GitHub

## Summary

- **Sync Mechanism**: Firestore extension indexes specified collection/subcollection fields to Algolia, syncing real-time changes (create/update/delete) using Firestore document triggers, with document ID mapped to Algolia object ID by default.

- **Configuration & Permissions**: Requires Algolia app ID, restricted API key (with `addObject`, `deleteObject`, etc.), and optional field selection; supports alternative ObjectID via document property or path, necessitating index reset to avoid duplicates.

- **Transform & Deployment**: Experimental transform function (HTTPS callable) can preprocess data; deployed via Firebase CLI (`firebase ext:install algolia/firestore-algolia-search`) with Blaze plan requirement and billing for Firestore/Cloud Functions/Algolia usage.
