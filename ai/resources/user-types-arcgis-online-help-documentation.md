# User types—ArcGIS Online Help | Documentation

## Summary

- **User Type Assignment**: User types in ArcGIS Online are assigned upon invitation, determining privileges via default/custom roles and granting access to specific apps (e.g., Viewer, Contributor, Mobile Worker, Creator, Professional, Professional Plus).

- **Role-Specific Capabilities**:
  - **Viewer/Contributor/Mobile Worker**: Limited to viewing/editing shared data (no creation/analysis/sharing).
  - **Creator/Professional/Professional Plus**: Advanced map creation, analysis (e.g., ArcGIS Pro Basic/Standard/Advanced), collaboration, and administrative functions.

- **App Licensing**: Optional add-on licenses (e.g., ArcGIS Business Analyst) can be assigned to users with Creator/Professional/Professional Plus types for extended functionality.
