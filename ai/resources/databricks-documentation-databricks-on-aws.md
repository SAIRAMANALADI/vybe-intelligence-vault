# Databricks documentation | Databricks on AWS

## Summary

- **Databricks Data Intelligence Platform** on AWS provides a unified Lakehouse environment for collaborative data analytics and AI workloads, integrating structured and unstructured data management with governance via Unity Catalog.

- **Core Capabilities** include ETL/data engineering pipelines, MLflow-based AI/ML model development/deployment, SQL-based data warehousing, and OLTP databases (Lakebase) with PostgreSQL compatibility.

- **Administrative & Security Features** encompass workspace/user management, security compliance controls, data lineage tracking, and API/SDK-based extensibility for custom integrations.
