# Canvas Dev & Friends - Instructure Tech Blog

## Summary

- **Canvas API & Developer Keys**: Official API documentation at [api.instructure.com](https://api.instructure.com) with guides for OAuth2 flow and developer key acquisition; production use requires institutional admin approval.
- **LTI & App Integration**: Official LTI docs ([IMS Global](http://www.imsglobal.org/activity/learning-tools-interoperability)) supplemented by [EduAppCenter](https://www.eduappcenter.com/docs/basics/index); LTI apps must be submitted via [EduAppCenter](https://www.eduappcenter.com/) for review.
