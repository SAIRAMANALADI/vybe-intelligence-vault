# UnoCSS: The instant on-demand Atomic CSS engine

## Summary

- **Preset-Driven Architecture**: All functionalities are implemented as modular presets, eliminating core utilities and enabling full customization via configuration.
- **Minimalist Initialization**: System starts with no default utilities, requiring explicit preset selection for any functionality.
- **Extensible Design**: New features are added solely by defining and integrating additional presets without modifying the underlying framework.
