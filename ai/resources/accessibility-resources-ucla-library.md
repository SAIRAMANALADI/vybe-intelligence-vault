# Accessibility Resources | UCLA Library

## Summary

- **ADA Compliance & Accessibility Services**: UCLA Library ensures ADA compliance, providing accessible materials, programs, and services for users with disabilities, with priority access to specialized workstations and software (e.g., macOS Sonoma 14 Accessibility Features, Kurzweil 3000).

- **Assistive Technology & Equipment**: Dedicated accessible computers with adaptive peripherals (e.g., ALMA keyboard, trackball mouse, Magic Trackpad) are available in select libraries (Biomedical, SEL/Boelter, Powell, etc.), loanable with Bruincard/Library Card; staff assist with inaccessible resources.

- **Material Retrieval & Support Services**: Staff retrieve materials from stacks (with next-day availability if paged), offer proxy borrower cards, photocopy services (U.S. copyright-compliant), and assistive carts in specific libraries (Biomedical, Music, YRL, SEL).
