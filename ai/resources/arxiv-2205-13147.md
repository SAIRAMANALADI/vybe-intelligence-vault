# [2205.13147] Matryoshka Representation Learning

## Summary

- **Matryoshka Representation Learning (MRL)** introduces a coarse-to-fine embedding framework that encodes information hierarchically, enabling a single embedding to adapt to varying computational constraints without additional inference costs.

- **Empirical results** demonstrate up to **14x smaller embedding sizes** for ImageNet-1K classification at equivalent accuracy, **14x speed-ups** for large-scale retrieval, and **2% accuracy improvements** in long-tail few-shot classification while maintaining robustness across modalities (vision, vision-language, language).

- **MRL generalizes seamlessly** to web-scale datasets (ImageNet, JFT) and architectures (ViT, ResNet, ALIGN, BERT), requiring minimal modifications to existing pipelines and offering open-sourced code and pretrained models.
