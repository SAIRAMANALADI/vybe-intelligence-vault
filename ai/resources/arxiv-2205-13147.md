# [2205.13147] Matryoshka Representation Learning

## Summary

- Introduces **Matryoshka Representation Learning (MRL)**, a method to encode coarse-to-fine hierarchical representations within a single embedding, enabling adaptive granularity for downstream tasks without additional inference costs.
- Achieves **up to 14x smaller embedding sizes** for ImageNet-1K classification while maintaining accuracy, **14x speed-ups** for large-scale retrieval, and **2% accuracy improvements** for long-tail few-shot classification, with robustness comparable to original representations.
- Validated across **multiple modalities (vision, vision+language, language)** and architectures (ViT, ResNet, ALIGN, BERT) on large-scale datasets (ImageNet, JFT), with open-sourced code and pretrained models.
