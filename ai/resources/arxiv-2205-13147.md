# [2205.13147] Matryoshka Representation Learning

## Summary

- **Matryoshka Representation Learning (MRL)** introduces a coarse-to-fine embedding structure that enables adaptive representation granularity for downstream tasks without additional inference costs.
- Achieves **up to 14x embedding size reduction** (ImageNet-1K) at equal accuracy, **14x speed-ups** for large-scale retrieval, and **2% accuracy gains** in long-tail few-shot classification while maintaining robustness.
- Validated across **multiple modalities (vision, vision-language, language)** and architectures (ViT, ResNet, ALIGN, BERT) on web-scale datasets (ImageNet, JFT), with open-sourced code and pretrained models.
