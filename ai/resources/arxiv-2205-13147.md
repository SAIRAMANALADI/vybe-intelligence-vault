# [2205.13147] Matryoshka Representation Learning

## Summary

- **Matryoshka Representation Learning (MRL)** introduces a coarse-to-fine embedding framework that encodes multi-granularity representations within a single embedding vector, enabling adaptive downstream task performance without additional inference costs.

- **Empirical improvements** include up to **14x smaller embedding sizes** for ImageNet-1K classification at equal accuracy, **14x speed-ups** for large-scale retrieval, and **2% accuracy gains** in long-tail few-shot classification while maintaining robustness across modalities (vision, vision+language, language).

- **Scalability** demonstrated on web-scale datasets (ImageNet, JFT) with minimal modifications to existing pipelines, supporting architectures like ViT, ResNet, ALIGN, and BERT, and open-sourced at [RAIVNLab/MRL](https://github.com/RAIVNLab/MRL).
