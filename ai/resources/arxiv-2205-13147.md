# [2205.13147] Matryoshka Representation Learning

## Summary

- **Matryoshka Representation Learning (MRL)** introduces a coarse-to-fine embedding framework that encodes multi-granularity representations within a single embedding vector, enabling adaptive downstream task performance under varying computational constraints without additional inference costs.

- **Empirical results** demonstrate MRL achieves up to **14x smaller embedding sizes** for ImageNet-1K classification at equivalent accuracy, **14x real-world speed-ups** for large-scale retrieval (ImageNet-1K/4K), and **2% accuracy improvements** in long-tail few-shot classification while maintaining robustness.

- **Generalizability** is validated across modalities (vision, vision-language, language) and architectures (ViT, ResNet, ALIGN, BERT) on web-scale datasets (ImageNet, JFT), with open-sourced code and pretrained models available.
