# Main Page « WordPress Codex

## Summary

- **Core Platform**: WordPress is an open-source CMS built on PHP/MySQL, offering a plugin architecture (`Plugin API`) and theme system (`Theme Development`) with the Gutenberg block editor for content creation.

- **Ecosystem**: Hosts 60K+ plugins (extensible via hooks/actions/filters) and 10K+ themes (child themes supported), with resources like `developer.wordpress.org` for API docs and `learn.wordpress.org` for structured training.

- **Community & Governance**: Operated by the WordPress Foundation, with contributions via `make.wordpress.org`, multilingual support (50+ languages), and enterprise-focused initiatives (`Five for the Future`).
