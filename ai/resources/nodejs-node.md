# node/CONTRIBUTING.md at main · nodejs/node · GitHub

## Summary

- **Governance & Contributions**: Node.js operates under an open governance model where significant contributors gain Collaborator status and commit-access; all contributions (code, docs, infrastructure) are valued regardless of size.
- **Pull Request Process**: PRs are the primary mechanism for changes, requiring adherence to dependency policies, local environment setup, and a structured review process; unauthorized automation interactions are subject to moderation.
- **Legal Compliance**: Contributors must certify origin/licensing via the Developer's Certificate of Origin 1.1, ensuring contributions are properly licensed and documented for public redistribution.
