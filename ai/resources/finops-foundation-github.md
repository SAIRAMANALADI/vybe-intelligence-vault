# FinOps Foundation · GitHub

## Summary

- **FinOps Foundation** is a community-driven organization focused on developing and standardizing FinOps best practices, tools, and frameworks for cloud financial management.

- **Key repositories** include:
  - [`framework`](https://github.com/finopsfoundation/framework): HTML-based FinOps best practices and guidelines.
  - [`focus_validator`](https://github.com/finopsfoundation/focus_validator): Python-based validator for FOCUS (FinOps Open Cost and Usage Specification) datasets.
  - [`focus_converters`](https://github.com/finopsfoundation/focus_converters): Jupyter Notebook-based tools for converting cloud cost data into FOCUS-compliant formats.

- **Licensing and governance**:
  - Most repositories use **MIT** or **Apache-2.0** licenses.
  - The [`tac`](https://github.com/finopsfoundation/tac) repository governs technical oversight and community decisions.
