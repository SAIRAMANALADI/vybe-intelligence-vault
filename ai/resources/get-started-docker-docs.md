# Get started | Docker Docs

## Summary

- **Installation & Setup**: Docker provides platform-specific installation paths ([Get Docker](https://docs.docker.com/get-started/get-docker/)) to deploy the Docker Engine, enabling container runtime environments.

- **Core Concepts**: Docker’s architecture revolves around containers (isolated, lightweight environments) and images (immutable templates), abstracted via the Docker CLI and daemon (`dockerd`).

- **Learning Resources**: Docker offers structured guides ([Introduction](https://docs.docker.com/get-started/introduction/), [Concepts](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-a-container/), [Workshop](https://docs.docker.com/get-started/workshop/)) to master containerization workflows and best practices.
