# Docker Hub | Docker Docs

## Summary

- **Registry & Integration**: Docker Hub is a global container registry for storing, managing, and sharing Docker images, integrating with CI/CD tools to streamline deployment and distribution workflows.

- **Key Features**: Supports unlimited public/private repositories, webhooks for automation, GitHub/Bitbucket integrations, concurrent/automated builds, and curated trusted content via high-quality, secure images.

- **Access & Management**: Provides a web UI, [REST API](https://docs.docker.com/reference/api/hub/latest/), and experimental [CLI](https://github.com/docker/hub-tool#readme) for repository/library management, organization administration, and usage tracking.
