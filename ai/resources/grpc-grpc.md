# grpc/grpc

## Summary

- **Multi-language RPC framework**: gRPC is a high-performance, open-source universal RPC framework developed by Google, supporting C++, Python, Ruby, Objective-C, PHP, and C# with protocol buffers (protobuf) as the Interface Definition Language (IDL).

- **Core components**: Implements HTTP/2 for transport, protocol buffers for serialization, and features client-side and server-side streaming, bidirectional streaming, and pluggable authentication mechanisms.

- **Cross-platform compatibility**: Supports Linux, Windows, macOS, and mobile platforms (Android/iOS), with auto-generated client/server code for efficient cross-language communication and integration.
