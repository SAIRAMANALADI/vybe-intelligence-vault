# nvm-sh/nvm

## Summary

- **POSIX-compliant bash script** for managing multiple active Node.js versions, enabling seamless switching between versions via environment variables.
- **Key features**: Supports `.nvmrc` files for version specification, integrates with shells (bash/zsh), and provides commands for installation (`nvm install`), switching (`nvm use`), and listing (`nvm ls`) Node.js versions.
- **Compatibility**: Designed for POSIX systems, ensuring broad Unix-like environment support (e.g., Linux, macOS, WSL).
