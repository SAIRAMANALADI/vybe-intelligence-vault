# Using C++ and WSL in VS Code

## Summary

- **Language Support**: VS Code provides extensive language-specific tooling via extensions for JavaScript, TypeScript, Python, Java, C++, C#, PHP, Go, Rust, Ruby, Swift, and more, including debugging, linting, formatting, and IntelliSense.
- **WSL Integration**: VS Code supports remote development in Windows Subsystem for Linux (WSL), enabling compilation (GCC/g++), debugging (GDB), and execution directly within a Linux environment while maintaining Windows-based editing.
- **Project-Specific Workflows**: Detailed guides exist for configuring build systems (e.g., CMake for C++), managing environments (Python virtual environments), and deploying applications (Node.js, Python, Java) with integrated tooling for testing, refactoring, and performance profiling.
