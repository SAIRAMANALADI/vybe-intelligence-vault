# Overview of Extract | Developer Documentation

## Summary

- **Input Refinement**: User prompt (`user_prompt`) explicitly instructs LlamaParse to extract only line-item prices and the total from a receipt, overriding default parsing behavior.

- **Output Filtering**: Post-processing filters discard non-essential data (e.g., vendor names, dates), retaining only structured numerical values for line items and the grand total.

- **Prompt-Driven Parsing**: Demonstrates dynamic adjustment of LlamaParse’s output schema via instruction, enabling task-specific extraction without retraining the underlying model.
