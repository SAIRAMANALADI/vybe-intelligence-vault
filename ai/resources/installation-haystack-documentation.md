# Installation | Haystack Documentation

## Summary

- Haystack v2.30 supports installation via `pip`, `uv`, or `conda`, with commands:
  - `pip install haystack-ai`
  - `uv pip install haystack-ai` or `uv add haystack-ai`
  - `conda install conda-forge::haystack-ai`

- Optional dependencies are excluded by default; missing dependencies trigger explicit errors (e.g., `ImportError` for `pypdf`) with installation instructions.

- Contribution requires adherence to [Contributor Guidelines](https://github.com/deepset-ai/haystack/blob/main/CONTRIBUTING.md) and setup per [development environment instructions](https://github.com/deepset-ai/haystack/blob/main/CONTRIBUTING.md#setting-up-your-development-environment).
