## Summary

- Servlet container intercepts HTTP request and forwards it to target servlet via internal dispatch mechanism
- Request/response objects remain the same instance during forward (no new network call)
- Uses `RequestDispatcher.forward(ServletRequest, ServletResponse)` method with same request URI
