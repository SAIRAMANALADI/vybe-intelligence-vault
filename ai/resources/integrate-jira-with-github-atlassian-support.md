# Integrate Jira with GitHub | Atlassian Support

## Summary

- **Integration Setup**: Enables linking GitHub Cloud repositories to Jira Cloud via Atlassian's native integration, facilitating synchronization of branches, commits, and pull requests with Jira work items.

- **Work Item Association**: Automatically or manually links GitHub activities (e.g., commits, PRs) to Jira issues using issue keys (e.g., `PROJ-123`) embedded in commit messages or PR descriptions.

- **Real-Time Sync**: Provides bidirectional visibility where GitHub actions (e.g., PR merges) update Jira issue statuses, and Jira workflows reflect GitHub branch/PR states, enhancing traceability across development and project management.
