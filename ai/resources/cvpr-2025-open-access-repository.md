# CVPR 2025 Open Access Repository

## Summary

- **VideoICL Framework**: Proposes a confidence-based iterative in-context learning (ICL) method for out-of-distribution (OOD) video understanding, addressing context length limitations in Video LMMs via similarity-based example selection and iterative refinement.

- **Key Mechanisms**: Implements a two-step process—(1) selecting and ranking relevant examples by similarity, and (2) iteratively refining responses if confidence is low—without fine-tuning, improving OOD performance on benchmarks.

- **Performance & Validation**: Demonstrates significant gains in domain-specific OOD scenarios, validated across multiple benchmarks, with supplementary materials (PDF, supp, arXiv) and IEEE Xplore proceedings available.
