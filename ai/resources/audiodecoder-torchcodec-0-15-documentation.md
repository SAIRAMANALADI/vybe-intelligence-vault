# AudioDecoder — TorchCodec 0.15 Documentation

## Summary

- Decodes single-stream audio from files (e.g., MP3, WAV, MP4) or raw encoded data (bytes/Tensor), returning float samples normalized to `[-1, 1]`.
- Supports dynamic resampling (`sample_rate`) and channel selection (`num_channels`), with optional `stream_index` for multi-stream sources.
- Provides methods `get_all_samples()` for full decoding and `get_samples_played_in_range(start, stop)` for partial decoding within a time window.
