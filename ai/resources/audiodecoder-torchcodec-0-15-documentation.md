# AudioDecoder — TorchCodec 0.15 Documentation

## Summary

- Decodes single-stream audio from files (e.g., MP3, WAV, MP4) or raw encoded data (bytes/Tensor), returning float samples normalized to [-1, 1].
- Supports dynamic resampling (`sample_rate`) and channel selection (`num_channels`), defaulting to source properties if unspecified.
- Provides methods `get_all_samples()` and `get_samples_played_in_range(start_seconds, stop_seconds)` for flexible audio extraction.
