# Frederik Braun: A CDN that can not XSS you: Using Subresource Integrity

## Summary

- **Subresource Integrity (SRI)** is a W3C standard enabling cryptographic verification of third-party JavaScript/CSS integrity via `integrity` attribute in HTML tags, preventing unauthorized modifications during transit or at the CDN.
- **Implementation requires CORS support** (`crossorigin` attribute) as browsers must fetch external resources in a manner permitting integrity checks; CDNs must explicitly enable CORS headers.
- **Tooling exists for automation** (e.g., `sri-toolbox`, Ember.js/Broccoli plugins) and **browser support is expanding** (Firefox/Chrome) with polyfill options for legacy systems.
