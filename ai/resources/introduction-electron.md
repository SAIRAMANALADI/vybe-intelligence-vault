# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron embeds Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop applications to run natively on Windows, macOS, and Linux without native development experience.

- **Electron Fiddle**: A sandbox tool for prototyping and testing Electron APIs, integrating with documentation via "Open in Fiddle" buttons to load examples directly into the tool.

- **Documentation structure**: Organized into categories (Tutorial, Processes, Best Practices, Examples, Distribution, Testing/Debugging, References, Contributing) providing end-to-end guides, references, and community support via Discord and GitHub issue tracking.
