# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron combines Chromium (for rendering) and Node.js (for native APIs) into a single binary, enabling JavaScript/HTML/CSS-based cross-platform desktop apps without native development.

- **Electron Fiddle**: A sandbox tool for prototyping and testing Electron APIs, integrating with documentation via "Open in Fiddle" buttons to auto-load code examples.

- **Core app structure**: A minimal Electron app consists of `main.js` (process management), `preload.js` (bridge between renderer and Node.js), and `index.html` (UI), with `app.whenReady()` initializing the `BrowserWindow`.
