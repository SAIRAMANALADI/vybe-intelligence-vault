# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron combines Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop apps that run on Windows, macOS, and Linux without native development requirements.

- **Electron Fiddle**: A sandbox tool for prototyping and testing Electron APIs, integrating with documentation via "Open in Fiddle" buttons to load examples directly into the app.

- **Documentation structure**: Covers end-to-end tutorials, process management, best practices, distribution, debugging, and contribution guides, with community support via Discord and GitHub issue tracking.
