# Introduction | Electron

## Summary

- **Electron** is a cross-platform desktop application framework that combines **Chromium** (for rendering) and **Node.js** (for backend APIs) into a single binary, enabling JavaScript/HTML/CSS-based desktop app development without native code.

- **Electron Fiddle** is an official sandbox tool for prototyping and testing Electron APIs, integrating with documentation via "Open in Fiddle" buttons to load examples directly into the app.

- **Official Electron docs** are structured into categories (e.g., *Tutorial*, *Best Practices*, *Distribution*) covering development, debugging, and deployment workflows, with community support via Discord and GitHub issues.
