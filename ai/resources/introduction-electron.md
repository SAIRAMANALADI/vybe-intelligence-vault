# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron integrates Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop applications that run natively on Windows, macOS, and Linux without requiring native development expertise.

- **Core architecture**: Electron apps consist of a main process (Node.js-based, managing lifecycle events like `app.whenReady()`) and a renderer process (Chromium-based, loading `index.html` via `BrowserWindow`), with optional preload scripts for controlled IPC.

- **Development ecosystem**: Electron provides official documentation (tutorials, API references, best practices), an interactive sandbox tool (Electron Fiddle) for prototyping, and community resources (Discord, GitHub issue tracker) for debugging and collaboration.
