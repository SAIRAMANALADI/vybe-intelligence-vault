# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron embeds Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop apps that run on Windows, macOS, and Linux without native development.

- **Core components**: Electron apps consist of a main process (`main.js`) managing windows, a preload script (`preload.js`) bridging Node.js APIs to the renderer, and an HTML file (`index.html`) defining the UI.

- **Development tools**: Electron Fiddle provides a sandboxed environment for prototyping and testing APIs, with direct integration into official documentation via "Open in Fiddle" buttons.
