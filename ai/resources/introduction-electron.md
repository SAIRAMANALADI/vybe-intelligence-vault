# Introduction | Electron

## Summary

- **Cross-platform desktop app framework**: Electron combines Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop apps that run on Windows, macOS, and Linux without native development dependencies.

- **Core components**: Electron apps consist of a main process (`main.js`) managing app lifecycle via `app` module, a renderer process (`index.html`) for UI, and a preload script (`preload.js`) bridging secure IPC between them.

- **Development ecosystem**: Electron provides official docs (tutorials, API refs, best practices), Electron Fiddle for sandboxed prototyping, and community resources (Discord, GitHub issues) for debugging and contributions.
