# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron embeds Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop apps that run on Windows, macOS, and Linux without native development.

- **Core components**: Electron apps consist of a main process (`main.js`) managing app lifecycle via `BrowserWindow`, a preload script (`preload.js`) for secure IPC, and a renderer process (`index.html`) for UI rendering.

- **Development ecosystem**: Electron provides official docs (tutorials, APIs, best practices), Electron Fiddle for prototyping, and community resources (Discord, GitHub issues) for debugging and contributions.
