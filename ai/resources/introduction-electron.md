# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron integrates Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop applications that run natively on Windows, macOS, and Linux without requiring platform-specific development.

- **Core components**: Electron apps consist of a main process (`main.js`) managing lifecycle events (e.g., `app.whenReady()`), a renderer process (`index.html`) for UI, and a preload script (`preload.js`) for secure IPC between Node.js and the renderer.

- **Development ecosystem**: Electron provides official documentation (tutorials, API references, best practices), a sandboxed prototyping tool (`Electron Fiddle`), and community resources (Discord, GitHub issues) for debugging and collaboration.
