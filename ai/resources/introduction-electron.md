# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron combines Chromium (for rendering) and Node.js (for native APIs) into a single binary, enabling JavaScript/HTML/CSS-based desktop apps that run on Windows, macOS, and Linux without native development.

- **Core components**: Electron apps consist of a main process (`main.js`) managing app lifecycle and windows, a renderer process (`index.html`) for UI, and a preload script (`preload.js`) bridging secure IPC between them.

- **Development tools**: Electron Fiddle provides an interactive sandbox for prototyping and testing APIs, with direct integration into documentation via "Open in Fiddle" buttons for seamless experimentation.
