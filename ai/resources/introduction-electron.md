# Introduction | Electron

## Summary

- **Electron** is a cross-platform desktop application framework that integrates **Chromium** (for rendering) and **Node.js** (for backend APIs) into a single binary, enabling JavaScript/HTML/CSS-based desktop apps without native development.

- **Electron Fiddle** is an official sandbox tool for prototyping and testing Electron APIs, featuring direct integration with documentation via "Open in Fiddle" buttons to load examples without manual setup.

- **Official Electron docs** are structured into categories (Tutorial, Processes, Best Practices, Distribution, etc.), with resources for debugging, testing, and community support (Discord, GitHub issues).
