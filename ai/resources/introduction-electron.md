# Introduction | Electron

## Summary

- Electron integrates Chromium and Node.js into a single binary, enabling cross-platform desktop app development using JavaScript, HTML, and CSS without native development experience.

- The framework provides structured documentation including tutorials, API references, best practices, and debugging guides, alongside tools like Electron Fiddle for prototyping and API experimentation.

- Electron apps consist of a main process (`main.js`), preload script (`preload.js`), and renderer process (`index.html`), with process isolation and inter-process communication managed via Electron's APIs.
