# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron embeds Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop applications that run natively on Windows, macOS, and Linux without requiring native development expertise.

- **Core components**: Electron apps consist of a main process (`main.js`) managing app lifecycle and windows, a preload script (`preload.js`) bridging Node.js APIs to the renderer, and HTML/CSS-based UI (`index.html`) rendered via Chromium.

- **Development ecosystem**: Electron provides official tutorials, API docs, and tools like Electron Fiddle (a sandbox IDE) for prototyping, with community support via Discord and issue tracking on GitHub for debugging and contributions.
