# Introduction | Electron

## Summary

- **Framework Architecture**: Electron combines Chromium for rendering and Node.js for native APIs into a single binary, enabling cross-platform desktop apps using JavaScript, HTML, and CSS without native development.

- **Core Components**: The `main.js` orchestrates app lifecycle (e.g., window creation via `BrowserWindow`), `preload.js` bridges secure Node.js APIs to the renderer, and `index.html` defines the UI.

- **Development Tools**: Electron Fiddle provides a sandboxed environment for prototyping and API experimentation, with direct integration into documentation via "Open in Fiddle" buttons for seamless code execution.
