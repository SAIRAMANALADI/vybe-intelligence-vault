# Introduction | Electron

## Summary

- **Electron** is a cross-platform desktop app framework that bundles **Chromium** and **Node.js** into a single binary, enabling JavaScript/HTML/CSS-based development without native dependencies.
- **Electron Fiddle** is a sandbox tool for prototyping and testing Electron APIs, integrating with documentation via "Open in Fiddle" buttons for seamless example execution.
- Official Electron docs include **tutorials**, **API references**, **best practices**, and **distribution guides**, with community support via Discord and GitHub issue tracking.
