# Introduction | Electron

## Summary

- **Framework Architecture**: Electron integrates Chromium and Node.js into a single binary, enabling cross-platform desktop app development (Windows/macOS/Linux) using JavaScript, HTML, and CSS without native code requirements.

- **Core Components**: Electron apps consist of a `main.js` (Node.js process managing app lifecycle), `preload.js` (bridge for secure IPC between renderer and Node.js), and `index.html` (UI rendered via embedded Chromium).

- **Development Tools**: Electron Fiddle provides a sandboxed environment for prototyping and testing APIs directly from documentation, while official docs cover tutorials, debugging, distribution, and best practices for app development.
