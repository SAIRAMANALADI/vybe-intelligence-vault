# Introduction | Electron

## Summary

- **Cross-platform desktop apps**: Electron combines Chromium and Node.js into a single binary, enabling JavaScript/HTML/CSS-based desktop apps that run on Windows, macOS, and Linux without native development.

- **Core components**: Electron apps consist of `main.js` (process management via `app` and `BrowserWindow`), `preload.js` (bridge between Node.js and renderer), and `index.html` (UI rendering with embedded Chromium).

- **Documentation structure**: Official docs include tutorials, process references, best practices, examples, distribution guides, debugging tools, and contribution instructions, with community support via Discord and GitHub issues.
