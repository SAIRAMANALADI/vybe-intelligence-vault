# encoding.HexEncode

## Summary

- Converts input string to hexadecimal representation via `encoding.HexEncode` function.
- Syntax: `encoding.HexEncode INPUT`; returns a `string` type.
- Example: `{{ "Hello world" | encoding.HexEncode }}` outputs `48656c6c6f20776f726c64`.
