# encoding.HexEncode

## Summary

- `encoding.HexEncode` converts a given input string into its hexadecimal representation.
- Syntax: `encoding.HexEncode INPUT`; returns a `string`.
- Example: `{{ "Hello world" | encoding.HexEncode }}` outputs `48656c6c6f20776f726c64`.
