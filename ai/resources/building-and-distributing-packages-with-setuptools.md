# Building and Distributing Packages with Setuptools - setuptools 82.0.1 documentation

## Summary

- **Enhanced Python Packaging**: `setuptools` extends `distutils` to support complex package dependencies, C/C++ extensions, and advanced distribution formats like Python Eggs while maintaining backward compatibility with standard `distutils` packages.

- **Automated Distribution Features**: Automatically includes all packages/files in source distributions without manual `MANIFEST.in` management, supports Cython compilation transparently, and enables development mode (`pip install -e .`) for editable installs.

- **Modern Configuration & Compatibility**: Supports PEP 420 namespace packages via `find_namespace_packages()`, allows `setup.cfg`-only projects (PEP 517/518), and provides a `read_configuration()` API for parsing metadata/options from `setup.cfg` programmatically.
