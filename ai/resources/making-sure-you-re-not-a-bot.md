# Making sure you're not a bot!

## Summary

- **Anubis implements a Proof-of-Work (PoW) mechanism** similar to Hashcash to mitigate aggressive AI-driven web scraping, imposing computational overhead primarily at scale to deter mass requests while minimally impacting legitimate users.

- **The system prioritizes headless browser detection** (e.g., via font rendering analysis) to reduce reliance on PoW challenges, aiming to serve the challenge only to high-risk automated clients rather than all users.

- **Requires modern JavaScript execution** for PoW computation and challenge resolution, with JShelter or similar plugins needing to be disabled; a no-JS fallback is under development due to evolving circumvention tactics by AI scrapers.
