# Making sure you're not a bot!

## Summary

- **Proof-of-Work Mechanism**: Anubis implements a Hashcash-inspired proof-of-work (PoW) scheme to mitigate aggressive web scraping by requiring computational effort, making large-scale scraping economically prohibitive while minimally impacting legitimate users.

- **Headless Browser Detection**: The system is designed as a temporary measure until advanced fingerprinting techniques (e.g., font rendering analysis) can reliably distinguish headless browsers from legitimate users, reducing reliance on PoW challenges.

- **JavaScript Dependency**: Anubis mandates modern JavaScript execution (disabling plugins like JShelter may block access), as AI scrapers have necessitated this shift to enforce challenges, with a future no-JS solution still in development.
