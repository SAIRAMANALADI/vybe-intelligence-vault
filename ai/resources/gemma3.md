# gemma3

## Summary

- **Model Architecture & Capabilities**: Google's Gemma 3 is a multimodal (text + vision) model family built on Gemini technology, supporting 128K context windows and 140+ languages, with parameter sizes ranging from 270M to 27B; quantization-aware training (QAT) reduces memory usage by 3x while maintaining BF16-level quality.

- **Performance Benchmarks**: Achieves strong results across reasoning (e.g., 85.6 HellaSwag for 27B), multilingual tasks (e.g., 74.3 MGSM for 27B), and multimodal tasks (e.g., 116 COCOcap for 27B), with scalable performance across parameter sizes.

- **Deployment & Integration**: Requires Ollama 0.6+, supports CLI/cURL/Python/JS APIs, and offers optimized variants (e.g., `gemma3:27b-cloud` for low usage) with documented evaluation metrics and model tags for versioning.
