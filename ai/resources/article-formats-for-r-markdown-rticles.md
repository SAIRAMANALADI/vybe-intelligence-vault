# Article Formats for R Markdown • rticles

## Summary

- **Package Overview**: `rticles` is an R Markdown LaTeX template package providing community-maintained journal/conference-specific formats for academic publishing, with CRAN (`install.packages("rticles")`) and GitHub (`pak::pak("rstudio/rticles")`) installation options.

- **Template Ecosystem**: Supports 40+ templates (e.g., `jss_article()`, `elsevier_article()`, `acm_article()`) via `rmarkdown::draft("filename.Rmd", template = "jss", package = "rticles")`, with LaTeX templates ensuring submission-standard compliance while allowing markdown/R code integration.

- **Contribution Workflow**: New templates require a GitHub PR with a pandoc `.tex` template (see prior PRs for examples), following the [PR template](https://pkgs.rstudio.com/rticles/PULL_REQUEST_TEMPLATE.html) and adhering to the [Contributor Code of Conduct](https://pkgs.rstudio.com/rticles/CODE_OF_CONDUCT.html).
