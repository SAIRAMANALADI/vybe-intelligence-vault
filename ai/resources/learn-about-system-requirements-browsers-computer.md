# Learn about system requirements & browsers - Computer - Google Drive Help

## Summary

- **Browser & OS Requirements**: Google Docs, Sheets, Slides, Vids, and Forms require **JavaScript and cookies enabled**, with support for the **two most recent browser versions** (other browsers may lack full feature compatibility).

- **Drive for Desktop Compatibility**:
  - **Windows**: 64-bit (Win 10+) or ARM64 (Win 11+), requires **Microsoft WebView2** (auto-installed if missing).
  - **Mac**: macOS Ventura 13.0+; **Linux** unsupported (use web version).

- **File System & Feature Limitations**:
  - Supports **APFS/HFS+ (macOS)** and **NTFS (Windows)**; excludes **SMB/NFS network volumes**.
  - **FAT32 cache limit**: 4GB max file size; **32-bit Windows and beta OSes unsupported**.
