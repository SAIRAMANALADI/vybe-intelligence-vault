# Learn about system requirements & browsers - Computer - Google Drive Help

## Summary

- **Browser Requirements**: Google Docs, Sheets, Slides, Vids, and Forms require **cookies and JavaScript enabled**, and support **only the two most recent browser versions** (other browsers may lack full feature compatibility).

- **Drive for Desktop OS Support**: Compatible with **Windows 10/11 (64-bit/ARM64) with WebView2**, **macOS Ventura 13.0+**, but **unsupported on Linux, 32-bit Windows, and beta OS versions**.

- **File System & Cache Limitations**: Supports **APFS, HFS+, NTFS** for local caching but **excludes network volumes (SMB/NFS)**; FAT32 virtual drive imposes a **4GB file size limit**. Real-time Office editing requires **Office 2010+**.
