# ipython/ipyparallel

## Summary

- **Interactive Parallel Computing Framework**: Provides a Python-based infrastructure for parallel execution of code across multiple engines, enabling interactive distributed computing with Jupyter.

- **Multi-Language Engine Support**: Supports execution of Python code in parallel across multiple engines, with optional integration for other languages (e.g., C++, Fortran) via MPI.

- **Real-Time Communication & Task Management**: Facilitates synchronous/asynchronous task submission, result retrieval, and direct engine-to-engine communication via a hub-and-spoke architecture.
