# SeisComP seismological software

## Summary

- **SeisComP** is a seismological software suite for real-time data acquisition, processing, distribution, and interactive analysis, developed collaboratively by the **GEOFON Program** at **GFZ Helmholtz Centre for Geosciences** and **gempa GmbH**.

- The software is **open-source** (AGPL-licensed) with **source code available on GitHub**, supporting **Linux-based deployment** via pre-built packages, source compilation, or add-on extensions for enhanced functionality.

- **Citable reference**: Helmholtz Centre Potsdam GFZ German Research Centre for Geosciences & gempa GmbH (2008). *The SeisComP seismological software package*. GFZ Data Services. [doi:10.5880/GFZ.2.4.2020.003](http://dx.doi.org/10.5880/GFZ.2.4.2020.003).
