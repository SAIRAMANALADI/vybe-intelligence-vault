# Version Control with Subversion

## Summary

- **Apache Subversion (SVN) Documentation**: The book *"Version Control with Subversion"* is an open-source, free resource written by SVN developers, covering SVN 1.7 in its stable release and SVN 1.8 in nightly builds, available in HTML/PDF formats.
- **Multi-Format Access**: The book is distributed in multiple formats (HTML single-page/multi-page, PDF) and DocBook XML sources, with stable links for completed versions (1.7) and development snapshots for nightly builds (1.8).
- **Internationalization & Contribution**: The book has been translated into multiple languages (e.g., German, Japanese, Chinese), and contributions/errata reporting are managed via a ticket system on SourceForge.
