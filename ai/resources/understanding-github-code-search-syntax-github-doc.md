# Understanding GitHub Code Search syntax - GitHub Docs

## Summary

- GitHub code search supports **exact string matching** via quoted strings (e.g., `"sparse index"`), with escape sequences `\"` for quotes and `\\` for backslashes.
- **Boolean operations** (`AND`, `OR`, `NOT`) and **parentheses** enable complex queries (e.g., `(language:ruby OR language:python) AND NOT path:"/tests/"`).
- **Qualifiers** (`repo:`, `language:`, `path:`, `symbol:`, etc.) refine searches by repository, file path, language, or symbol definitions (e.g., `language:go symbol:WithContext`).
