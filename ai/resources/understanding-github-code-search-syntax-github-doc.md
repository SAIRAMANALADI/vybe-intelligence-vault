# Understanding GitHub Code Search syntax - GitHub Docs

## Summary

- GitHub code search supports **exact string matching** via quoted strings (`"sparse index"`), with escape sequences for quotes (`\"`) and backslashes (`\\`).
- **Boolean operations** (`AND`, `OR`, `NOT`) and **parentheses** enable complex queries (e.g., `(language:ruby OR language:python) AND NOT path:"/tests/"`).
- **Qualifiers** (`repo:`, `language:`, `path:`, `symbol:`) refine searches; `path:` supports glob patterns (`*.txt`, `/src/**/*.js`) and regex (`/(^|\/)README\.md$/`).
