# Understanding GitHub Code Search syntax - GitHub Docs

## Summary

- GitHub code search supports **boolean operations** (`AND`, `OR`, `NOT`), **exact string matching** (via quotes), and **regex** (enclosed in `/`), with default `AND` behavior for space-separated terms.
- **Qualifiers** (`repo:`, `language:`, `path:`, `org:`, `license:`, `symbol:`) enable targeted searches (e.g., `language:python path:/src/**/*.py`).
- **Escape sequences** (`\"`, `\\`) handle literal quotes/backslashes; glob patterns (`*`, `?`, `**`) refine path-based searches.
