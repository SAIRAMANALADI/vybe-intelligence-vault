# chrome.scripting | API | Chrome for Developers

## Summary

- **API Overview**: `chrome.scripting` API (Chrome 88+, Manifest V3) enables dynamic JavaScript/CSS injection into web pages, supporting runtime decisions unlike static content scripts.
- **Injection Targets**: Supports injection into specific tabs (`tabId`), all frames (`allFrames`), or individual frames (`frameIds`), with results returned per-frame (main frame first).
- **Execution Modes**: Supports file-based (`files`) or function-based (`func`) injection, with arguments (`args`) for functions, and handles promises for async operations (e.g., `injectImmediately` for pre-load execution).
