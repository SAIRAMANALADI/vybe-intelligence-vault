# Introduction | Documentation | Poetry - Python dependency management and packaging made easy

## Summary

- **Requirements**: Poetry requires **Python 3.10+** and is cross-platform (Linux, macOS, Windows).
- **Installation Methods**:
  - **pipx (recommended)**: Isolates Poetry in a virtual environment (`pipx install poetry`).
  - **Official installer**: Installs Poetry in a user-specific directory (`curl -sSL https://install.python-poetry.org | python3 -`).
  - **Manual (advanced)**: Uses `venv` and `pip` for full control (`python3 -m venv $VENV_PATH && $VENV_PATH/bin/pip install poetry`).
- **Tab Completion Setup**:
  - **Bash**: `poetry completions bash >> ~/.bash_completion` (auto-loaded) or lazy-loaded via `~/.local/share/bash-completion/completions/poetry`.
  - **Fish**: `poetry completions fish > ~/.config/fish/completions/poetry.fish`.
  - **Zsh**: `poetry completions zsh > ~/.zfunc/_poetry` + `fpath+=~/.zfunc` in `~/.zshrc`.
