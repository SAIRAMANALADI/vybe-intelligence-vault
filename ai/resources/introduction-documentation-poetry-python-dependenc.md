# Introduction | Documentation | Poetry - Python dependency management and packaging made easy

## Summary

- **Requirements**: Poetry requires **Python 3.10+** and is designed to work cross-platform (Linux, macOS, Windows).
- **Installation Methods**: Supports installation via `pipx` (isolated global CLI), official installer (self-managed venv), or manual `pip`/`venv` (advanced).
- **Tab Completion**: Generates completion scripts for Bash, Fish, and Zsh via `poetry completions [shell] > [path]`, with additional setup required for Zsh (e.g., `fpath` modification).
