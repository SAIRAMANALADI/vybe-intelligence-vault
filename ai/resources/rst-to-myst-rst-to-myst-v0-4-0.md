# RST-to-MyST — RST-to-MyST: v0.4.0

## Summary

- **Purpose**: Converts ReStructuredText (RST) to MyST Markdown for compatibility with `myst-parser`.
- **Installation**: Requires `pip install "rst-to-myst[sphinx]"`; recommended to use `pipx` for isolated environments.
- **Usage**: Converts RST files via CLI (`rst2myst convert docs/**/*.rst`) with optional YAML-based configuration for Sphinx extensions and parsing rules.
