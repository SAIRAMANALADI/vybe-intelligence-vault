# [2406.11695] Optimizing Instructions and Demonstrations for Multi-Stage Language Model Programs

## Summary

- **MIPRO algorithm**: Introduces a meta-optimization framework for multi-stage LM programs by factorizing prompt optimization into instruction and demonstration tuning, achieving up to **13% accuracy improvement** over baselines using Llama-3-8B.

- **Prompt optimization strategies**: Combines **program/data-aware instruction proposals**, a **stochastic mini-batch surrogate evaluation**, and **iterative refinement** to navigate credit assignment across modular LM calls without module-level labels or gradients.

- **DSPy framework**: Released as an open-source toolkit implementing MIPRO, enabling end-to-end optimization of LM programs via declarative pipelines and task-grounded prompt engineering.
