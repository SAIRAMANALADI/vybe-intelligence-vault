# [2406.11695] Optimizing Instructions and Demonstrations for Multi-Stage Language Model Programs

## Summary

- **MIPRO Algorithm**: Introduces a novel meta-optimization framework (MIPRO) to optimize free-form instructions and few-shot demonstrations for multi-stage Language Model (LM) programs without requiring module-level labels or gradients, improving performance by up to **13% accuracy** on diverse tasks using Llama-3-8B.

- **Three Key Strategies**:
  1. **Program- and data-aware instruction proposals** to generate task-grounded instructions.
  2. **Stochastic mini-batch evaluation** to approximate downstream metrics via a surrogate model.
  3. **Iterative refinement** of LM-generated proposals through meta-optimization.

- **Open-Source Release**: The algorithm and benchmark are implemented in **DSPy**, enabling reproducibility and further research in LM program optimization.
