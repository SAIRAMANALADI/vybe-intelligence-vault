# [2406.11695] Optimizing Instructions and Demonstrations for Multi-Stage Language Model Programs

## Summary

- **MIPRO Algorithm**: Introduces a novel algorithm for optimizing multi-stage language model (LM) programs by jointly refining free-form instructions and few-shot demonstrations across modules without requiring module-level labels or gradients, achieving up to 13% accuracy improvement over baselines using Llama-3-8B.

- **Optimization Strategies**: Implements program- and data-aware techniques for instruction proposal, a stochastic mini-batch evaluation function to model the downstream objective, and meta-optimization to iteratively refine LM-generated proposals over time.

- **Benchmarking & Release**: Evaluates performance on seven diverse LM programs, outperforming baseline optimizers in five cases, with the optimizer and benchmark released as part of the DSPy framework ([dspy.ai](http://dspy.ai)).
