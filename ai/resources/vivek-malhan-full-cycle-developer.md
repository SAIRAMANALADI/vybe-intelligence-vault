# Vivek Malhan — Full Cycle Developer

## Summary

- **Lightweight React toast library**: Zero dependencies, minimal bundle impact (~2KB), optimized for performance with efficient DOM updates via React's reconciliation.
- **Accessibility & Customization**: Implements ARIA roles (`alert`, `status`) for screen readers, keyboard navigation support, and highly configurable via props (duration, position, animations).
- **Developer Experience**: Simple API (`<ToastContainer />` + `toast()` method), TypeScript support, and modular design for easy integration with SSR/Next.js.
