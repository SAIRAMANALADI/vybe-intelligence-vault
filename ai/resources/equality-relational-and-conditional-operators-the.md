# Equality, Relational, and Conditional Operators (The Java™ Tutorials > Learning the Java Language > Language Basics)

## Summary

- Java equality (`==`, `!=`) and relational (`>`, `<`, `>=`, `<=`) operators compare primitive values or object references, with `==` checking reference equality unless overridden (e.g., `String` pool).
- Conditional operators `&&` (AND) and `||` (OR) exhibit short-circuit evaluation, skipping the second operand if the first determines the result; the ternary operator `?:` acts as `if-else` shorthand.
- The `instanceof` operator checks runtime type compatibility (class/subclass/interface), returning `false` for `null` references.
