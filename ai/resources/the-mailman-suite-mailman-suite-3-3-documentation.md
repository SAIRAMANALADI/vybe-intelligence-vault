# The Mailman Suite — Mailman Suite 3.3 documentation

## Summary

- **Mailman Suite Architecture**: Comprises 5 core projects—Mailman Core (list management), Postorius (web UI), Hyperkitty (archiver), Mailmanclient (REST API bindings), and Django-mailman3 (Django utilities)—licensed under GPLv3+ and copyrighted by the FSF.

- **Installation & Configuration**: Requires pre-installation checks (e.g., Mailman 2.1 migration paths), Django setup for admin interfaces, and modular configuration of Core (MTA, REST API, templates), Web UI (Postorius/Hyperkitty), and task queues (Celery).

- **Migration & Contribution**: Provides structured migration guides from Mailman 2.1 (password handling, upgrade strategies) and contributor workflows (i18n via Weblate, GitLab-based development, testing frameworks).
