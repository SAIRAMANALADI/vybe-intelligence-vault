# GnuTLS

## Summary

- **Protocol & API Support**: GnuTLS implements SSL 3.0, TLS 1.0–1.3, and DTLS 1.0–1.2 with a C API for secure communications, X.509/PKCS#12 parsing, and cryptographic operations.

- **Cryptographic & Hardware Acceleration**: Supports AES, Camellia, RSA, ECC, SRP, PSK, and hardware acceleration via AES-NI, VIA Padlock, `/dev/crypto`, PKCS#11, TPM, and HSMs.

- **License & Releases**: Core library under LGPLv2.1+, with frequent security/bug-fix releases (e.g., 3.8.13 addressing 13 CVEs) and cross-platform compatibility (Unix/Windows).
