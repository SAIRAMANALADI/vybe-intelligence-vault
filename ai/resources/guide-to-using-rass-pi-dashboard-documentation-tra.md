# Guide to Using RASS & PI Dashboard | Documentation & Training

## Summary

- **RASS Access Points**: Primary login portals for Cornell's Research Administration Support System (RASS) include Sponsored Projects (`https://rass.cornell.edu/sr`), IRB (`https://rass.cornell.edu/irb`), COI (`https://rass.cornell.edu/coi`), IACUC (`https://cornell.esirius.cayuse.com/`), IBC (`https://rass.cornell.edu/ibc`), Vet Care EMR (`https://rass.cornell.edu/vc`), and PI Dashboard (`https://pidash.cornell.edu`).

- **Support & Training Channels**: RASS-related queries are directed to `rass@research.cornell.edu`, while PI Dashboard issues go to `pidash@cornell.edu`. RASS office hours (Tue/Thu, 1:00–2:00 PM ET) via Zoom (`https://cornell.zoom.us/j/94107632069`) and 1:1 sessions (schedulable via Outlook) provide structured assistance.

- **Additional Research Tools**: Cornell offers supplementary resources including financial tracking (`http://radash.cornell.edu/`, `http://webfin2.cornell.edu/`), compliance portals (IACUC, COI, IBC), and metrics dashboards (`https://metrics.research.cornell.edu/`), accessible via direct links or the RASS framework.
