# Opt-Out Tools — AdChoices in Canada

## Summary

- **Opt-Out Tools**: AdChoices provides tools (WebChoices, AppChoices, Token Tool) to opt out of interest-based advertising from registered companies, preserving user data control without blocking all ads.
- **Browser & Mobile Support**: WebChoices (browser-based) and AppChoices (mobile) allow granular opt-outs per browser/OS, while Protect My Choices plugins retain opt-out preferences despite cookie deletions.
- **Browser-Level Controls**: Major browsers (Chrome, Firefox, Safari, etc.) offer native cookie/privacy controls to block or limit tracking, complementing AdChoices' tools for broader privacy management.
