# [2207.03522] TF-GNN: Graph Neural Networks in TensorFlow

## Summary

- **TF-GNN** is a scalable, production-grade library for Graph Neural Networks (GNNs) built on TensorFlow, designed to handle heterogeneous graph data structures common in real-world applications.
- Implements a **Keras-based message-passing API** for GNNs, with support for graph sampling and distributed training to optimize performance on large-scale graphs.
- Open-sourced by Google, enabling low-code adoption for developers while supporting advanced research use cases in machine learning and graph-based systems.
