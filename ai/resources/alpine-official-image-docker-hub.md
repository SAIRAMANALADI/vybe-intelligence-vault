# alpine - Official Image | Docker Hub

## Summary

- **Minimalist Base Image**: Alpine Linux-based Docker image with musl libc and BusyBox, weighing only **5 MB**, optimized for lightweight containerized applications.

- **Multi-Architecture Support**: Available for **x86, ARM (v6/v7/v8), i386, PPC64LE, RISC-V64, and s390x**, ensuring broad compatibility across platforms.

- **Efficient Package Management**: Uses `apk` (Alpine Package Keeper) for a **complete package repository**, enabling smaller image sizes (e.g., 36.8 MB for `alpine:3.14` + `mysql-client`) compared to larger distributions like Ubuntu (145 MB).
