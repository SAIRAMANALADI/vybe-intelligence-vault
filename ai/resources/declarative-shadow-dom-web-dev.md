# Declarative Shadow DOM | web.dev

## Summary

- **Declarative Shadow DOM (DSD)**: Standardized web feature (WHATWG) enabling native shadow DOM encapsulation via HTML `<template>` elements with `shadowrootmode` attribute, replacing deprecated `shadowroot` syntax; fully supported in Chrome 124+ and all major browsers as of August 2024.

- **Browser Support Timeline**: Chrome/Edge (v111+), Firefox (v123+), Safari (v16.4+); DSD was initially Chrome-only (v90+) but achieved cross-browser parity after 2023 spec updates and standardization.

- **Technical Implementation**: DSD allows declarative shadow tree construction during HTML parsing (no JavaScript required), improving performance and SEO by reducing manual `attachShadow()` calls while maintaining encapsulation via scoped styles and DOM partitioning.
