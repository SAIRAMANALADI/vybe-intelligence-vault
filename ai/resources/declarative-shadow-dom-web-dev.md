# Declarative Shadow DOM | web.dev

## Summary

- **Declarative Shadow DOM (DSD)** introduced as a standardized web platform feature (WHATWG HTML spec) with `shadowrootmode` attribute replacing deprecated `shadowroot`, fully standardized in Chrome 124 and marked **Baseline Newly Available** as of August 5, 2024.

- **Cross-browser support** achieved across Chrome 111+, Edge 111+, Firefox 123+, and Safari 16.4+, enabling consistent declarative encapsulation of Shadow DOM via `<template shadowrootmode="...">` syntax.

- **Specification evolution** included a 2023 rename (`shadowroot` → `shadowrootmode`) and structural updates, with prior Chrome support (v90+) retroactively aligned to the finalized standard.
