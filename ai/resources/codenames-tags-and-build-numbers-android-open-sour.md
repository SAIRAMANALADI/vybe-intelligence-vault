# Codenames, tags, and build numbers | Android Open Source Project

## Summary

- **AOSP Release Schedule**: Starting 2026, AOSP source code will be published bi-annually (Q2/Q4) to align with the trunk stable development model, using the `android-latest-release` manifest branch for builds/contributions.

- **Android Version Mapping**: Codename `Android17` (API level 37) is the latest, with quarterly releases (e.g., `26Q2` for 2026 Q2), while prior versions (e.g., `Android15` API 35) follow structured tagging (e.g., `android-15.0.0_r36`).

- **Build Artifacts & Security**: Build IDs (e.g., `CP2A.260605.016`) include platform version, branch, and security patch dates; factory/OTA images and drivers for Pixel devices are available via Google’s developer portals.
