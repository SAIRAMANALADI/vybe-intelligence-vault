# Codenames, tags, and build numbers | Android Open Source Project

## Summary

- **AOSP Release Cadence**: Starting 2026, AOSP source code will be published bi-annually (Q2/Q4) under the `android-latest-release` manifest branch, aligning with the trunk-stable development model for ecosystem stability.

- **Android Version Mapping**: API levels and NDK releases are strictly versioned (e.g., Android17 = API 37, Android16 = API 36), with quarterly releases (e.g., 26Q2 for Android17) and device-specific binary paths (e.g., Pixel 5 - `redfin`).

- **Build Tagging & Security Patches**: Each release is tagged (e.g., `android-17.0.0_r1`) with a build ID (e.g., `CP2A.260605.016`) and includes a security patch level (e.g., `2026-06-05`), enabling precise source and binary tracking.
