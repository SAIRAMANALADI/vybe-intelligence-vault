# Herramienta para el uso responsable de IA en las Administraciones Públicas | LAB

## Summary

- **Metodología escalable por riesgo**: Implementa niveles de supervisión proporcionales al impacto potencial, con 40 controles para proyectos básicos y hasta 161 para sistemas complejos (ej: evaluación automatizada de ayudas sociales).

- **Herramienta automatizada**: Proporciona un framework guiado paso a paso para evaluar conformidad con normativas de protección de datos en IA, adaptándose a la complejidad del sistema.

- **Enfoque práctico**: Incluye ejemplos específicos como chatbots para consultas ciudadanas (baja complejidad) vs. sistemas de decisión algorítmica con datos sensibles (alta complejidad), con requisitos como supervisión humana y evaluación de sesgos.
