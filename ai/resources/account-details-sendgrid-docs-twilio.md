# Account Details | SendGrid Docs | Twilio

## Summary

- **Account Management**: SendGrid accounts allow editing of personal info (name, email, phone), SendGrid credentials (username/password), and account details (time zone, Parent ID, Account ID, Account Friendly Name) via the SendGrid Console; Twilio Login users must update these in the Twilio Console.
- **Company Details**: Company name, billing address (Address 1/2, City, State, Country, ZIP), and website URL can be modified in the **Your Company** section of the SendGrid Console.
- **Password Requirements**: SendGrid account passwords must be 16-128 characters, exclude repeating sequences of 3+ characters, avoid username/email info, and exclude non-ASCII characters. Changing the username immediately disrupts API/SMTP Relay calls.
