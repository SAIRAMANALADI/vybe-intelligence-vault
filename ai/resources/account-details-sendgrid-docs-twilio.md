# Account Details | SendGrid Docs | Twilio

## Summary

- **Account Management**: SendGrid accounts allow editing of personal info (name, email, phone), SendGrid credentials (username/password), and account details (time zone, Parent/Account IDs) via the SendGrid Console; Twilio Login users must use the [Twilio Console](https://console.twilio.com) for such changes.

- **Company Information**: Users can update company details (name, billing address, website) in the **Your Company** section, with changes requiring confirmation via the SendGrid UI.

- **Security Constraints**: SendGrid password requirements enforce 16–128 characters, no 3+ repeating chars, no username/email inclusion, and no non-ASCII characters; changing the username disrupts API/SMTP Relay access until updated.
