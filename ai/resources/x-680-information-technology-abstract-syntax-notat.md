# X.680 : Information technology - Abstract Syntax Notation One (ASN.1): Specification of basic notation

## Summary

- **ITU-T X.680 (2021)** defines the **Abstract Syntax Notation One (ASN.1) basic notation** for specifying abstract data types and values, standardized as **ISO/IEC 8824-1:2021**, with encoding rules covered in companion standards (e.g., X.693).

- **Key components include** module definitions, type assignments, value assignments, and extensibility mechanisms, with **latest amendments** (e.g., 2021) introducing updates like **XML value notation** and **PER encoding instructions**.

- **Superseded versions** (e.g., 1994–2015) were progressively updated, with **corrigenda and amendments** addressing errors, semantic model refinements, and alignment with ISO/IEC identifiers (e.g., **9834-1** for OID notation).
