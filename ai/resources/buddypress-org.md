# BuddyPress.org

## Summary

- **Open-source social networking platform** built on WordPress, offering extensible user profiles, customizable visibility levels, and common field types for enhanced user data management.

- **Core features** include activity streams (sitewide/group-specific), friendship connections, private messaging, group-based micro-communities, and smart notification systems with read/unread tracking.

- **Modular architecture** supports third-party plugins (e.g., BuddyPress Template Pack) and integrates with WordPress core (e.g., 10.0.0+ compatibility) via trac/forums for development and support.
