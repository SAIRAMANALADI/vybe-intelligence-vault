# NIST Chemistry WebBook

## Summary

- **Comprehensive Thermochemical & Spectroscopic Database**: NIST Chemistry WebBook (SRD 69) provides curated thermochemical, thermophysical, ion energetics, and spectroscopic data (e.g., IR, UV/Vis, THz spectra) compiled from authoritative sources, including evaluated datasets for gas-phase ion thermochemistry and organometallic compounds.

- **Search & Analytical Tools**: Supports formula, name, CAS, structure, and property-based searches (e.g., ion energetics, vibrational energies) with specialized tools like the **Thermophysical Properties of Fluid Systems** calculator and **Group Additivity Estimates** for gas-phase thermodynamic properties.

- **Data Sources & Limitations**: Compiled by NIST under the Standard Reference Data Program with contributions from global experts (e.g., Glushko Thermocenter, IUPAC), but includes a disclaimer stating no warranties for data accuracy or liability for errors/omissions.
