# Welcome - Opera Security Team

## Summary

- **Security Features**: Opera browsers implement security measures such as built-in ad-blockers, fraud and malware protection, and cryptojacking blockers; Opera Mini for basic phones uses server-side compression to reduce data usage and potential attack surfaces.

- **Reporting Mechanisms**: Security issues can be reported via Opera’s public/private Bug Bounty programs or directly through their [Vulnerability Policy](https://security.opera.com/policy/) submission portal; out-of-scope issues are also accepted.

- **Fraud & Malicious Activity Reporting**: Suspicious activity related to Opera products is reported via the [Report Fraud](https://security.opera.com/report-fraud/) page, separate from technical vulnerability submissions.
