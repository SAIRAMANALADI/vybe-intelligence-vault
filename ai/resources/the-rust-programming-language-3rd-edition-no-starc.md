# The Rust Programming Language, 3rd Edition | No Starch Press

## Summary

- **Rust 2024 Edition**: The book is based on Rust's 2024 Edition, incorporating modern Rust idioms, tooling, and async programming support.
- **Core Concepts**: Covers ownership, lifetimes, traits, concurrency, error handling, and pattern matching with practical examples.
- **Projects & Tooling**: Includes chapters on Cargo, testing, documentation, and three real-world projects (guessing game, CLI tool, multithreaded server).
