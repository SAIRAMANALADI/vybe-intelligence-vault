# sentry-python 2.63.0 documentation

## Summary

- **Core Functionality**: The `sentry-python` SDK provides error tracking, logging, and performance monitoring for Python applications by capturing exceptions, events, and performance data, then reporting them to Sentry's platform.

- **Integration Support**: Supports extensive integrations with frameworks (e.g., Django, Flask, FastAPI), logging libraries (e.g., `logging`), and async/await patterns (e.g., `asyncio`), enabling seamless error monitoring across diverse Python environments.

- **Configuration & Customization**: Offers granular control via environment variables and programmatic APIs (e.g., `init()`, `capture_exception()`), allowing fine-tuning of event processing, transport mechanisms, and error grouping.
