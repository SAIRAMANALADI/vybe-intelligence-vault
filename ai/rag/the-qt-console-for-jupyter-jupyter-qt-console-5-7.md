# The Qt Console for Jupyter — Jupyter Qt Console 5.7.2 documentation

## Summary

- **Lightweight GUI Terminal Alternative**: Jupyter Qt Console is a terminal-like GUI application leveraging Qt for enhanced features such as inline figures, multi-line editing with syntax highlighting, and graphical calltips, while supporting any Jupyter kernel.

- **Multi-Process & Kernel Management**: Operates via a two-process ZMQ model enabling non-blocking input during execution, kernel restart (`Ctrl-.`) even during blocking operations, and heartbeat-based crash detection; supports multiple frontends connecting to a single kernel via `--existing` flag with JSON connection files.

- **Security & Networking**: Defaults to localhost-only kernel binding for security; supports external IP binding (`--ip`) with unencrypted message transmission (HMAC-signed) and SSH tunneling for secure remote access, including manual port forwarding configurations.
