# RxDB - JavaScript Database

## Summary

- **Local-First NoSQL Database**: RxDB is a client-side JavaScript NoSQL database enabling zero-latency offline queries, real-time sync with any backend (via prebuilt plugins for GraphQL, Firebase, MongoDB, etc., or custom HTTP endpoints), and full offline functionality without backend dependency.

- **Replication & Conflict Handling**: Implements a sync engine supporting bidirectional real-time replication with conflict resolution, CRDTs, and middleware; supports schema migrations, encryption, and attachments for robust offline-first applications.

- **Cross-Platform & Scalable**: Runs in all JavaScript runtimes (browser, Node.js, React Native, etc.), uses modular storage adapters (IndexedDB, SQLite, etc.), and is adopted by enterprises for high-scale offline apps with tens of thousands of documents.
