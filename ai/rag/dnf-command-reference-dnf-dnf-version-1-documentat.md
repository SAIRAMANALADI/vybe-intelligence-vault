# DNF Command Reference — DNF @DNF_VERSION@-1 documentation

## Summary

- **DNF Overview**: Successor to YUM, maintains CLI compatibility while providing a strict API for extensions/plugins; supports modularity, transaction history, and fine-grained package filtering (e.g., NEVRA, globs, modular exclusion).

- **Core Commands**: Includes `install`, `remove`, `upgrade`, `repoquery`, `module`, `history`, and `autoremove`, with transactional rollback via `history undo`; supports advisory filtering (`--advisory`, `--cve`, `--bz`) and dependency resolution (`--allowerasing`).

- **Metadata & Configuration**: Supports IPv4/IPv6 resolution (`-4`, `-6`), cache-only mode (`-C`), and strict version pinning (`--best`); configuration via `/etc/dnf/dnf.conf` with modular repo overrides and transaction JSON storage for reproducibility.
