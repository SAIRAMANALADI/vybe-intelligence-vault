# Supabase | The Open Source Firebase Alternative

## Summary

- **PostgreSQL Core**: Supabase provides a full PostgreSQL database with 100% portability, built-in Row-Level Security (RLS), and extensibility for seamless integration with existing workflows.

- **Unified Backend Services**: Offers integrated solutions for authentication (with RLS), real-time data synchronization, serverless Edge Functions, scalable storage, vector embeddings for ML models, and instant RESTful Data APIs.

- **Developer Experience**: Enables rapid prototyping with production-ready templates (e.g., Next.js, Stripe subscriptions) and tools like SQL/Table editors, while supporting frameworks like React, Flutter, and Expo for cross-platform development.
