# RAG Techniques: Zero to Hero — A Complete Guide | martinuke0's Blog

## Summary

- **Core RAG pipeline**: Retriever (vector/lexical) → vector store → LLM generator; optional reranker, query rewriting, caching, and orchestration layers; retrieval augments LLM context for factual grounding and freshness.

- **Chunking & embeddings**: Structure-aware chunking preserves coherence; semantic/LLM-based chunking improves retrieval precision; domain-fine-tuned embeddings outperform off-the-shelf models; hybrid (BM25 + vector) search mitigates lexical vs. semantic gaps.

- **Multi-stage retrieval & reasoning**: Two-stage retrieval (first-stage ANN + second-stage cross-encoder reranking) balances speed/precision; multi-hop/iterative retrieval and GraphRAG enable complex reasoning; context distillation condenses retrieved evidence to reduce hallucinations.
