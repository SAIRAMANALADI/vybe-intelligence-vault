# RAG Techniques: Zero to Hero — A Complete Guide | martinuke0's Blog

## Summary

- **RAG Architecture**: Combines a retriever (vector/lexical) with a generator LLM, where retrieved context conditions generation to improve factuality and reduce hallucinations; core components include embeddings, vector stores, rerankers, and orchestration layers.

- **Chunking & Embeddings**: Text segmentation strategies (fixed-size, overlap, semantic, structure-aware) directly impact retrieval quality; embeddings should be domain-fine-tuned, normalized, and balanced for dimensionality/latency, with hybrid retrieval (BM25 + vector) improving precision/recall.

- **Advanced Techniques**: Multi-hop retrieval, iterative reasoning, and GraphRAG enable complex queries; context distillation (LLM-based summarization) and reranking (cross-encoders) optimize relevance while operational concerns include latency, cost, and evaluation metrics (nDCG, hallucination rate).
