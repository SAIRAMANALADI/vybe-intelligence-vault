# Index - FHIR v4.0.1

## Summary

- **FHIR R4 (v4.0.1)** is a mixed normative/STU standard for healthcare data exchange, published by HL7, with technical corrections released on Oct 30, 2019, superseded by FHIR R5 (v5.0.0).

- **Modular architecture** defines five levels: (1) Foundation (data types, XML/JSON), (2) Implementation support (security, conformance, terminology), (3) Administration (Patient, Practitioner, etc.), (4) Clinical data (Observation, Medication, Diagnostics), and (5) Clinical reasoning (Measure, PlanDefinition).

- **Exchange mechanisms** include RESTful APIs, messaging, documents, and services, with conformance enforced via StructureDefinition, CapabilityStatement, and ImplementationGuide artifacts.
