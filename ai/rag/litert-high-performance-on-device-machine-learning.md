# LiteRT: High-Performance On-Device Machine Learning Framework | Google AI Edge | Google for Developers

## Summary

- **LiteRT** is Google's next-gen on-device ML/GenAI framework, successor to TensorFlow Lite, optimized for cross-platform deployment (Android, Desktop, Web) with hardware acceleration (CPU/GPU/NPU) and low-latency execution.
- Supports **multi-framework conversion** (PyTorch, JAX, TensorFlow → `.tflite`) with post-training quantization and provides **CompiledModel API** for automated hardware selection and async execution.
- Offers **pre-trained GenAI models** (e.g., Gemma), sample apps, and tools like **LiteRT-LM** for deploying language models on wearables/browsers, with community resources on GitHub and Hugging Face.
