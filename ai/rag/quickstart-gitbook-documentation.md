# Quickstart | GitBook Documentation

## Summary

- GitBook supports **branch-based editing** via either a **WYSIWYG visual editor** or a **docs-as-code workflow** (Markdown + Git sync with GitHub/GitLab), enabling real-time previews and change requests before merging updates.
- Documentation sites can be **published instantly** with a default `*.gitbook.io` URL or customized with **domain/subdirectory mappings**, requiring DNS configuration with propagation delays up to 48 hours.
- Advanced features include **team collaboration** (permissions/roles), **visibility controls** (share links/authenticated access), **auto-translations**, and **third-party integrations** for extended functionality.
