# microsoft/rag-time

## Summary

- **RAG Implementation Framework**: Provides a structured 5-week learning path for mastering Retrieval-Augmented Generation (RAG) using Jupyter Notebooks, covering hybrid search (vector + keyword), indexing techniques (HNSW, scalar/binarization quantization), and integration with Azure OpenAI services.

- **Advanced RAG Techniques**: Demonstrates multimodal RAG, Matryoshka Representation Learning for dynamic embedding dimensionality, and responsible AI practices for LLM deployment in production environments.

- **Tooling & Optimization**: Focuses on scalable RAG pipelines using Visual Studio Code, with optimizations for vector search (FAISS/ANN), binary quantization for memory efficiency, and hybrid retrieval strategies for improved accuracy.
