# Introduction - NLNOG RING

## Summary

- **Participation Requirements**: Open to network operators with BGP routers in the Default Free Zone/IXPs, their own ASN/IP prefixes, router configuration rights, and community involvement; approval is discretionary and judged by perceived value.

- **Machine Specifications**: Clean Ubuntu 22.04 (amd64) server with a globally reachable IPv6 address, no packet filtering, full sudo access for Ring-Admins, and optional hardware/VM deployment (no containers); minimal suggested specs: 1 core, 2GB RAM, 20GB disk, 10Mbit NIC.

- **Management & Abuse Policy**: Centralized Ansible management for updates/user management; owners can install additional software; zero-tolerance policy for abuse, resulting in permanent exclusion after a single incident.
