# The Hugo CMS for visual page building | CloudCannon

## Summary

- **Git-Integrated Visual CMS**: CloudCannon integrates with Hugo’s Git workflow, enabling non-technical editors to modify content via a visual interface while preserving full developer control over themes, layouts, and shortcodes through branch-based editing and automated staging previews.

- **Real-Time Static Optimization**: Leverages Hugo’s static site generation for sub-100ms load times and enterprise scalability, with built-in meta tags, structured data, and automated performance tuning (e.g., Lighthouse scores improved from 14 to 90+ in case studies).

- **Markdown-Centric No-Lock-In Architecture**: Maintains vendor neutrality by storing all content in markdown within Git repositories, ensuring themes and configurations remain portable while enabling visual editing via configurable collections and reusable components.
