# Learn Java - Dev.java

## Summary

- **JDK Setup & Execution**: Java Development Kit (JDK) setup enables compilation (`javac`) and execution (`java`) of Java applications; IDEs like VS Code, IntelliJ IDEA, and Eclipse provide integrated tooling for project management, debugging, and Maven/Gradle support.
- **Core Language Features**: Java supports OOP (classes, interfaces, inheritance), functional programming (lambdas, streams), generics, records (immutable data), annotations, and pattern matching (e.g., `instanceof` enhancements in JDK 21+).
- **JVM & Tooling**: JDK includes monitoring (JFR, Flight Recorder), garbage collection tuning, modularity (`jlink` for custom runtime images), security tools (policy management), and debugging utilities (e.g., `jdb`, `jhsdb`).
