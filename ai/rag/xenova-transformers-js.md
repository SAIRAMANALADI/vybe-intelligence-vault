# xenova/transformers.js

## Summary

- **Browser-based ML Inference**: Enables running 🤗 Transformers models directly in the browser using JavaScript, eliminating the need for server-side processing.

- **Modular & Extensible**: Provides a lightweight, modular JavaScript library with support for 100+ models (e.g., BERT, Whisper, Stable Diffusion) via ONNX runtime.
