# The NPDB - Health Care Organizations Sign In

## Summary

- **Authentication Requirements**: NPDB enforces multi-factor authentication (MFA) via DBID/User ID or one-time password (OTP) sent to a registered phone; HHS users authenticate via AMS.
- **Identity Verification Mandate**: Users must verify identity using SSN/ITIN or a valid passport via ID.me, with only one verified ID.me account permitted.
- **Compliance & Monitoring**: System access is restricted to authorized entities under 45 CFR 60.18, with monitoring for Privacy Act compliance (5 USC 552a) and potential civil penalties for violations.
