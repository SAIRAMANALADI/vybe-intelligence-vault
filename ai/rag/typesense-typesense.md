# typesense/typesense

## Summary

- **High-Performance Search Engine**: Typesense is an open-source, in-memory fuzzy search engine written in C++, optimized for speed and typo tolerance, serving as an alternative to Algolia, Pinecone, and ElasticSearch.
- **Feature-Rich Capabilities**: Supports full-text search, geosearch, faceting, synonyms, vector search, and semantic similarity search, enabling advanced merchandising and instant search experiences.
- **Scalable & Enterprise-Ready**: Designed for high performance with low-latency responses, suitable for large-scale deployments and real-time search applications.
