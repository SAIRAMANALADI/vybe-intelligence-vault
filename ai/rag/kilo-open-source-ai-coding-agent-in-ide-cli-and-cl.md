# Kilo – Open Source AI Coding Agent in IDE, CLI and Cloud

## Summary

- **Unified AI Agent Control**: Centralized management of local/cloud agents across VS Code, JetBrains, CLI, and cloud environments with parallel isolated worktrees and IDE/CLI session support.

- **Zero-Markup Model Routing**: Supports 500+ models (frontier, open-weight, or BYOK) with no inference markup, enabling cost-effective routing via Auto Model modes (Efficient, Frontier, Balanced, Free).

- **Open-Source Transparency**: MIT-licensed codebase allows self-hosting, prompt/context inspection, and auditability, with no silent model switching or vendor lock-in.
