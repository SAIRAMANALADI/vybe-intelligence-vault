# stripe/stripe-react-native

## Summary

- **Library Purpose**: Provides React Native bindings for Stripe's payment processing SDK, enabling native integration of Stripe's payment features in mobile apps.
- **Key Features**: Supports core Stripe functionalities like card payments, Apple Pay, Google Pay, and 3D Secure authentication within React Native applications.
- **Technical Stack**: Written in TypeScript, leveraging native modules for iOS (`StripeReactNative`) and Android (`com.stripe.android:stripe-android`) to ensure platform-specific performance and compliance.
