# Home - OpenSearch

## Summary

- **OpenSearch Core** is a distributed search and analytics engine built on Apache Lucene, providing full-text search, aggregations, and analytics capabilities with a RESTful API.
- **OpenSearch Vector Engine** enables high-performance vector search and similarity matching, optimized for AI/ML workloads including generative AI and semantic search.
- **OpenSearch Data Prepper** is a server-side data processor for ETL pipelines, supporting transformation, enrichment, and aggregation of structured/unstructured data for downstream analytics.
