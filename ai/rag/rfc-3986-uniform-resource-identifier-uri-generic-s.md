# RFC 3986 - Uniform Resource Identifier (URI): Generic Syntax

## Summary

- **URI Syntax Standardization**: RFC 3986 defines the generic syntax for Uniform Resource Identifiers (URIs), superseding prior RFCs (2396, 1808, 2732) and updating RFC 1738, establishing a unified framework for URI parsing, resolution, and comparison.

- **URI Components and Structure**: Specifies URI structure with components: `scheme://authority/path?query#fragment`, where `authority` includes optional user info, host, and port, and defines reserved, unreserved, and percent-encoded characters for safe URI representation.

- **Resolution, Normalization, and Security**: Details URI reference resolution (relative/absolute), normalization rules for equivalence, and security considerations (e.g., malicious URI construction, sensitive data exposure, semantic attacks) to ensure reliable and secure URI usage.
