# Retrieval Augmented Generation (RAG) with Deep Agents - Docs by LangChain

## Summary

- **RAG Patterns in Deep Agents**: Supports skills-guided retrieval, rubric-checked grounding, todo-driven investigation, and retrieve-offload-delegate workflows using custom retrieval tools, filesystem backends, subagents, skills, and grading rubrics for dynamic orchestration of retrieval, analysis, and synthesis.

- **Indexing & Retrieval Pipeline**: Converts LangChain documentation into embeddings via document loading, text splitting, embeddings model selection (e.g., OpenAI), and storage in a VectorStore for efficient semantic similarity search during query-time retrieval.

- **Retrieve-Offload-Delegate Workflow**: Retrieves relevant document chunks, offloads them to filesystem storage, and delegates analysis to subagents for parallel processing, ensuring orchestrator context remains clean while enabling grounded, citation-backed responses.
