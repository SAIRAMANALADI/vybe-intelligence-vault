# labring/sealos

## Summary

- **Sealos** is a TypeScript-based tool for deploying GitHub projects or AI-generated code as Kubernetes applications, with automated operations for continuous uptime.

- **Core Features**: Supports HA Kubernetes clusters via `kubeadm`, leverages `IPVS` for load balancing, and includes `container`/`Docker` integration for seamless deployment.

- **Multi-Language Support**: Written in TypeScript with Go (`golang`) components, enabling cross-platform compatibility and extensibility for cloud-native workflows.
