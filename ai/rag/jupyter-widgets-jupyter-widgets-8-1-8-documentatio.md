# Jupyter Widgets — Jupyter Widgets 8.1.8 documentation

## Summary

- **Core Functionality**: Jupyter Widgets (`ipywidgets`) provide interactive browser controls for Jupyter notebooks, including form controls (sliders, checkboxes, text inputs), container controls (tabs, accordions, layouts), and advanced controls (maps, 2D/3D visualizations, datagrids) via a Python kernel interface.

- **Framework Components**: The system consists of a kernel-side package (`ipywidgets`) for widget logic and browser extensions (`jupyterlab-widgets`, `widgetsnbextension`) for frontend rendering, enabling cross-platform compatibility (JupyterLab, Notebook, and embeddable HTML interfaces).

- **Extensibility & Ecosystem**: While `ipywidgets` includes lightweight core controls, the framework supports custom widget development (e.g., Material/Vue-based) and maintains a community-driven wiki listing kernels/frontends with Jupyter Widgets support.
