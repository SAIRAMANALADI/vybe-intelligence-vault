# Report abuse or legal issue - Google Groups Help

## Summary

- **Reporting Mechanism**: Users can report hateful/violent content, shared personal info, or regulated goods/services at group/conversation/message levels via Google Groups UI, triggering an investigation with optional follow-up for additional details.

- **Illegal Activity Reporting**: Illicit content can be reported via Google’s dedicated [legal troubleshooter](https://support.google.com/legal/troubleshooter/1114905), with no unsubscription from groups upon reporting.

- **Minor Image Restrictions**: Guardians/minors can request image-sharing restrictions via [Google’s removal tool](https://support.google.com/groups/troubleshooter/6080141), separate from abuse reporting workflows.
