# How We Use n8n to Build and Control AI Agents – Keeping Business in Focus | beezwax blog

## Summary

- **n8n as Orchestration Layer**: Uses n8n (self-hosted via Docker Compose with PostgreSQL, Redis, and Caddy) to manage LLM orchestration, tool routing, authentication, and workflow execution, enabling business-focused AI agent integration without third-party dependencies.

- **Modular Tool Integration**: Implements tool composition via dedicated n8n nodes (e.g., Wrike, GitHub, FileMaker) with natural-language descriptions and authentication, allowing LLMs to dynamically select and chain tools for tasks like Slack-based query resolution.

- **Workflow Patterns & CI/CD**: Leverages session memory (Buffer Window), swappable LLM models (OpenAI/Anthropic via OpenRouter), and GitOps deployment (version-controlled workflow JSON files with CI/CD) for scalable, debuggable, and maintainable AI agent automation.
