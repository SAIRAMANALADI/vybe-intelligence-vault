# pinecone-io/pinecone-claude-code-plugin

## Summary

- **Purpose**: Official Pinecone marketplace plugin for **Claude Code**, enabling hybrid, semantic, and retrieval-augmented search via **MCP (Model Context Protocol)** integration.
