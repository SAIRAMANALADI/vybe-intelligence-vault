# Infra Standard

## Summary

- **Conformance & Terminology**: Normative content uses RFC 2119 keywords (case-insensitive per Infra's willful RFC 8174 violation), while non-normative text employs softer terms (e.g., "encouraged"). Terminology clarifies inclusive "or" logic and defines "user agent" vs. "implementation."

- **Privacy & Tracking Vectors**: Specifications must minimize fingerprinting/tracking risks (e.g., via stateful mechanisms like cookies or HSTS). Features enabling tracking are explicitly marked, though some (e.g., font detection) inherently leak data.

- **Algorithm Specifications**: Algorithms are declared with verb phrases, parameters, and return types (or omitted for void returns). Input limits are discouraged to avoid constraining implementations, though user agents may impose implementation-defined constraints (e.g., stack depth or bitmap dimensions).
