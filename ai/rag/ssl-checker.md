# SSL Checker

## Summary

- Validates SSL/TLS certificate installation, issuer trust, and Subject Alternative Name (SAN) coverage for public endpoints.
- Audits protocol versions (e.g., TLS 1.0/1.1/1.2/1.3) and cipher suites, flagging deprecated or weak configurations (e.g., BEAST, POODLE, Heartbleed).
- Checks certificate expiry, intermediate chain completeness, and response headers (e.g., HSTS) to ensure compliance and security posture.
