# What is a Container? | Docker

## Summary

- **Container Definition & Isolation**: Docker containers package applications with all dependencies (code, runtime, libraries, settings) into lightweight, isolated units that run uniformly across environments by sharing the host OS kernel via Docker Engine, ensuring consistency between development, staging, and production.

- **Performance & Portability**: Containers are more efficient than VMs (typically tens of MBs vs. GBs) due to OS-level virtualization, enabling higher server density, faster deployment, and seamless portability across Linux/Windows, data centers, clouds, and serverless frameworks.

- **Industry Standardization**: Docker pioneered container standardization via OCI (runc) and CNCF (containerd), driving adoption across cloud providers and open-source ecosystems, while maintaining backward compatibility and interoperability.
