# Verba: Building an Open Source, Modular RAG Application | Weaviate

## Summary

- **Modular RAG Pipeline**: Verba decomposes RAG into five customizable modules—`ReaderManager` (data ingestion), `ChunkerManager` (document splitting), `EmbeddingManager` (vectorization), `RetrieveManager` (query retrieval), and `GenerationManager` (answer synthesis)—enabling flexible integration of new components or algorithms.

- **Source Transparency & UX**: Implements real-time chunk-level source attribution in the UI, allowing users to inspect highlighted text segments and original documents directly, while providing autocompletion via BM25 keyword search for query formulation.

- **CRUD Data Management**: Offers a web-based ingestion interface for drag-and-drop document uploads (supporting PDFs, text, Excel, etc.) and a dedicated documents page for full lifecycle control (create/read/update/delete) over stored data in Weaviate.
