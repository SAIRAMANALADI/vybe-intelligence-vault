# Verba: Building an Open Source, Modular RAG Application | Weaviate

## Summary

- **Modular RAG Pipeline**: Verba decomposes RAG into five customizable stages—`ReaderManager` (data ingestion), `ChunkerManager` (document splitting), `EmbeddingManager` (vectorization via Weaviate), `RetrieveManager` (context retrieval), and `GenerationManager` (LLM response synthesis)—enabling plug-and-play component swapping for extensibility.

- **Source Transparency & CRUD UI**: Implements in-UI chunk-level source attribution with direct document access, alongside full CRUD functionality for data management (upload/delete/modify) via a web interface, ensuring traceability and data control without scripting.

- **Autocompletion & Status Monitoring**: Integrates Weaviate’s BM25-based query autocompletion for user guidance and provides a status page for real-time system health, active features, and version tracking, prioritizing usability and operational clarity.
