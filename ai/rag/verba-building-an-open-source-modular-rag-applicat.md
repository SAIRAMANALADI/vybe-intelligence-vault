# Verba: Building an Open Source, Modular RAG Application | Weaviate

## Summary

- **Modular RAG Pipeline**: Verba decomposes RAG into five customizable stages—`ReaderManager` (data ingestion), `ChunkerManager` (text splitting), `EmbeddingManager` (vectorization via Weaviate), `RetrieveManager` (contextual retrieval), and `GenerationManager` (LLM-based response synthesis)—enabling plug-and-play components for extensibility.

- **Source-Aware UI**: Implements transparent provenance by highlighting retrieved text chunks and linking them to original documents, addressing hallucination risks and enabling user verification of generated answers.

- **CRUD Data Management**: Provides a web-based interface for document ingestion, deletion, and status monitoring, abstracting complex pipeline configurations while supporting default configurations for non-technical users.
