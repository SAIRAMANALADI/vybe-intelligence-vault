# Verba: Building an Open Source, Modular RAG Application | Weaviate

## Summary

- **Modular RAG Pipeline**: Verba decomposes RAG into five customizable stages—`ReaderManager` (data ingestion), `ChunkerManager` (document splitting), `EmbeddingManager` (vectorization via Weaviate), `RetrieveManager` (context retrieval), and `GenerationManager` (LLM response synthesis)—each with pluggable components for extensibility.

- **Source Transparency & Autocompletion**: Implements real-time chunk-level source attribution with highlighted text segments and integrates BM25-based autocompletion to guide user queries, ensuring traceability and reducing hallucinations via explicit provenance.

- **CRUD Data Management**: Provides a web UI for direct document ingestion/deletion (supporting PDFs, text, Excel, etc.) with centralized status monitoring, balancing out-of-the-box usability and customization via modular defaults.
