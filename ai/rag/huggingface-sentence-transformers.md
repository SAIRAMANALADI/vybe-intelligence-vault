# sentence-transformers/docs/cross_encoder/pretrained_models.md at main · huggingface/sentence-transformers · GitHub

## Summary

- **Cross-Encoder Models**: Pre-trained models available via Hugging Face for tasks like reranking, semantic similarity, and NLI; require input pairs and output scores (0-1 with Sigmoid activation), with variants optimized for MS MARCO, SQuAD, STSbenchmark, Quora, and NLI datasets, including multimodal support (e.g., images).

- **Performance Benchmarks**: MS MARCO models (e.g., `ms-marco-MiniLM-L6-v2`) achieve high NDCG@10 (74.30) and MRR@10 (39.01), while NLI models (e.g., `nli-deberta-v3-base`) reach 90.04% accuracy on MNLI mismatched sets; STSbenchmark models (e.g., `stsb-roberta-large`) achieve 91.47% test performance.

- **Community & Multimodal Models**: Community models (e.g., `BAAI/bge-reranker-base`, `jinaai/jina-reranker-v1-turbo-en`) and multimodal rerankers (e.g., `Qwen3-VL-Reranker-8B`) extend functionality to non-text inputs (images/video/audio) and multilingual tasks, with usage examples available in Sentence-Transformers documentation.
