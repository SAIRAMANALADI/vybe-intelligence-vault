# Welcome To CircuitPython | Welcome to CircuitPython! | Adafruit Learning System

## Summary

- **CircuitPython** is a derivative of **MicroPython**, optimized for microcontrollers with a focus on **ease of use** and **beginner accessibility**, featuring a **REPL (Read-Eval-Print Loop)** for interactive development.
- **Installation** involves flashing the CircuitPython firmware onto supported boards (e.g., **Adafruit Circuit Playground Express**, **Feather M0 Express**), which then exposes a **USB mass storage device (CIRCUITPY)** for code deployment and configuration.
- **Development workflow** includes editing Python scripts directly on the **CIRCUITPY drive**, leveraging **pre-installed libraries** for hardware abstraction, and debugging via **serial console/REPL** for real-time interaction.
