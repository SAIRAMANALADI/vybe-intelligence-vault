# Google DeepMind · GitHub

## Summary

- **AlphaFold 3**: Open-source inference pipeline for protein structure prediction, leveraging deep learning to model molecular interactions with improved accuracy over AlphaFold 2.

- **MuJoCo Ecosystem**: Multi-Joint dynamics with Contact physics simulator (C++) with GPU-accelerated derivatives (`mujoco_warp`, `mujoco_playground`) and curated model collections (`mujoco_menagerie`) for robotics and reinforcement learning.

- **JAX-Based Libraries**: `dm-haiku` (neural network library) and `jax_privacy` (privacy-preserving ML algorithms) exemplify DeepMind’s focus on scalable, hardware-optimized differentiable computing for AI research.
