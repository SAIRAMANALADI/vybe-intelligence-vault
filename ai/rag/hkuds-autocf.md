# HKUDS/AutoCF

## Summary

- **Automated Self-Supervised Learning (SSL) Framework**: Introduces AutoCF, an automated SSL framework for recommender systems that dynamically selects augmentation strategies and contrastive learning tasks to optimize performance without manual tuning.

- **Collaborative Filtering Integration**: Combines SSL with collaborative filtering (CF) to leverage unlabeled data, enhancing recommendation quality by mitigating sparsity and cold-start issues in sparse datasets.

- **Hyperparameter Optimization**: Implements a reinforcement learning-based controller to automate hyperparameter selection (e.g., augmentation strength, contrastive loss weights) for end-to-end optimization of CF models.
