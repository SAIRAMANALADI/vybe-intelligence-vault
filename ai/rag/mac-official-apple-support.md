# Mac - Official Apple Support

## Summary

- **macOS Upgrade & Maintenance**: Supports upgrading to macOS Tahoe 26 via [Apple Support](https://support.apple.com/en-us/122727) and enabling automatic updates; macOS Recovery allows reinstallation without data loss ([guide](https://support.apple.com/en-us/102655)).

- **Data Backup & Migration**: Time Machine enables automated backups to external storage ([guide](https://support.apple.com/en-us/104984)), while Migration Assistant transfers documents, apps, and settings to new Macs ([steps](https://support.apple.com/en-us/102613)).

- **Repair & Support Workflows**: Apple’s My Support portal checks coverage status ([link](https://mysupport.apple.com/)); certified repair options and initiation via [Apple’s repair tool](https://getsupport.apple.com/?caller=pspprm&SG=SG001).
