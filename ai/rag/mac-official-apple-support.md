# Mac - Official Apple Support

## Summary

- **macOS Upgrade & Recovery**: Supports upgrading to macOS Tahoe 26 via macOS Recovery for OS reinstallation without data loss, with automated update mechanisms via System Settings.
- **AppleCare & Service Programs**: Provides Apple-certified repair options, including accidental damage coverage (drops/spills) and service programs like the Mac mini No Power Issue recall and 15-inch MacBook Pro Battery Recall.
- **Migration & Setup Utilities**: Facilitates seamless data transfer to new Macs using Migration Assistant and initial device setup via Setup Assistant for laptops (MacBook Air/Pro/Neo) and desktops (Mac mini/Studio/Pro/iMac).
