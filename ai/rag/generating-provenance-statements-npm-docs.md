# Generating provenance statements | npm Docs

## Summary

- Provenance statements in npm are cryptographically signed metadata artifacts generated during package publishing, enabling verification of package authenticity, integrity, and build provenance via SLSA (Supply-chain Levels for Software Artifacts) compliance.

- Trusted publishing leverages OIDC (OpenID Connect) to bind npm package publishing to CI/CD workflow identities, eliminating long-lived API tokens and enforcing ephemeral, scoped credentials.

- ECDSA-based registry signatures (P-256 curve) are used to sign npm registry metadata, allowing clients to verify package integrity and authenticity against registry-provided public keys.
