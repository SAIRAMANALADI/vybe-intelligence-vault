# User interface

## Summary

- **UI Layout & Customization**: VS Code's interface consists of an **Editor** (main editing area), **Primary/Secondary Side Bars** (views like Explorer/Chat), **Status Bar** (project/file info), **Activity Bar** (view switching), and **Panel** (debug/terminal/output). Supports **side-by-side editing** (vert/horiz splits), **floating windows**, and **modal editors** (e.g., Settings, Extensions) with configurable behavior via `workbench.editor.useModal`.

- **Navigation & Scoping Tools**: Features **Minimap** (code outline for quick navigation), **Sticky Scroll** (displays nested scope headers at top of editor), and **Breadcrumbs** (hierarchical file navigation). Supports **editor groups** (stacks of open files) and **split-in-group** mode (`⌘K ⇧⌘\`) for dual-pane editing without new groups.

- **Accessibility & Configuration**: Includes **keyboard shortcuts** (`⌘P` Quick Open, `⌘\` split editor), **settings sync** (cross-device config), **themes/profiles** (UI customization), and **accessibility** (voice interactions). Settings like `editor.minimap.side`, `editor.stickyScroll.enabled`, and `workbench.editor.openSideBySideDirection` control behavior.
