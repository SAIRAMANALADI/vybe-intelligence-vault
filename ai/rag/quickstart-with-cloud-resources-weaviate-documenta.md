# Quickstart: With Cloud resources | Weaviate Documentation

## Summary

- **Setup & Authentication**: Deploy a free Weaviate Cloud cluster via [console](https://console.weaviate.cloud), retrieve `WEAVIATE_URL` and `WEAVIATE_API_KEY`, and install a client library (Python/JS/Go/Java) using `pip install -U "weaviate-client[agents]"` or equivalent.

- **Collection Creation & Data Ingestion**: Define a collection (e.g., `Movie`) with `text2vec_weaviate()` vectorizer, then ingest data objects (e.g., movie titles/descriptions) via `client.collections.create()` and `data.ingest()`.

- **Generative RAG Integration**: Configure generative models (e.g., Anthropic’s `claude-haiku-4-5`) in collection schema for RAG workflows, enabling natural language query responses.
