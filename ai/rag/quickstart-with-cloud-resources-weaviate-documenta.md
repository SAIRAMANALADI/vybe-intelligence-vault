# Quickstart: With Cloud resources | Weaviate Documentation

## Summary

- **Collection Setup**: Create a Weaviate collection (e.g., `Movie`) with vectorization enabled using the `text2vec-weaviate` module, enabling automatic embedding generation for imported data objects via the Weaviate Embeddings service.

- **Data Ingestion**: Insert objects (e.g., movies with `title`, `description`, `genre`) into the collection using client libraries (Python/JS/Go/Java), where each object is automatically vectorized during ingestion.

- **Generative Integration**: Configure the collection with a generative model (e.g., Anthropic's `claude-haiku-4-5`) for RAG workflows, enabling natural language query responses leveraging the vectorized data.
