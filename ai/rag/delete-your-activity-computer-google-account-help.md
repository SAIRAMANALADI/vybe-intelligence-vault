# Delete your activity - Computer - Google Account Help

## Summary

- **Activity Deletion Workflow**: Users can delete Google activity via [myactivity.google.com](https://myactivity.google.com) with options to remove all data ("All time"), specific items, or filtered subsets (by date/product) via UI controls (e.g., calendar, search filters).
- **Automated & Cross-Platform Deletion**: Activity can be auto-deleted based on timeframes (e.g., 3 months/18 months/36 months) via "Data & privacy" settings, with residual data (e.g., location/IP) retained for 30 days; browser-specific activity (e.g., Chrome history) requires separate deletion.
- **Retention & Legal Constraints**: Deleted activity undergoes staged removal (visibility → storage systems), but certain data may persist for legal/business requirements; Incognito mode or disabling history settings (e.g., "Web & App Activity") can temporarily prevent logging.
