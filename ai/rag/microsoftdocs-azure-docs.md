# azure-docs/articles/security/fundamentals/overview.md at main · MicrosoftDocs/azure-docs · GitHub

## Summary

- **Defense-in-Depth Security**: Azure employs a multilayered security approach across physical datacenters, compute, storage, networking, applications, and identity, ensuring protection even if one layer is compromised. Includes built-in protections like Azure DDoS Protection, default encryption at rest, Microsoft Entra ID for identity security, and continuous threat detection.

- **Shared Responsibility Model**: Microsoft secures the underlying Azure infrastructure (physical datacenters, hardware, host OS), while customers are responsible for securing data, applications, identities, and access management. Responsibilities vary by deployment model (IaaS, PaaS, SaaS).

- **Advanced Compute Security**: Azure offers Trusted Launch (Secure Boot, vTPM, boot integrity monitoring), Azure Confidential Computing (hardware-based memory encryption via AMD SEV-SNP, Intel TDX, or SGX), antimalware via Microsoft Defender for Servers, Azure Key Vault for HSM-backed key management, and VM disk encryption options (encryption at host, confidential disk encryption, or customer-managed keys).
