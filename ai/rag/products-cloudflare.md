# Products | Cloudflare

## Summary

- **Compute & Serverless**: Cloudflare offers global serverless functions via **Workers**, stateful compute with **Durable Objects**, and secure execution environments (**Sandboxes**), enabling scalable, low-latency application deployment across 330+ cities without cold starts.

- **Storage & Databases**: Provides **R2** (egress-free storage), **KV** (ultra-fast key-value), **D1** (serverless SQL), **Hyperdrive** (global database acceleration), and **Vectorize** (vector database for AI), supporting persistent caching, message queuing (**Queues**), and Git-native artifact storage (**Artifacts**).

- **Security & Zero Trust**: Features **DDoS Protection**, **WAF**, **Bot Management**, and **Turnstile** (CAPTCHA alternative), alongside **SASE/Zero Trust** solutions like **Access** (identity-aware private resource access), **Gateway** (web filtering), and **Browser Isolation**, with **API Shield** for API security and monitoring.
