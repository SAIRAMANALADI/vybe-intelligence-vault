# What is Cloud Computing? - Cloud Computing Services, Benefits, and Types - AWS

## Summary

- **On-demand IT Resources**: AWS delivers IT resources (compute, storage, databases) over the internet with pay-as-you-go pricing, eliminating the need for physical data centers and servers.

- **Core Cloud Models**: AWS supports three primary cloud computing models—Infrastructure as a Service (IaaS) for flexible IT control, Platform as a Service (PaaS) for managed application deployment, and Software as a Service (SaaS) for fully managed end-user applications.

- **Global Scalability & AI/ML Integration**: AWS enables global deployment in minutes via its distributed infrastructure, while offering AI/ML services for real-time analytics, chatbots, and predictive modeling with scalable, secure, and cost-efficient infrastructure.
