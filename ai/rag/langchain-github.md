# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide modular components and integrations for LLM application development, while LangGraph/LangGraph.js enable graph-based agent orchestration; Deep Agents/Deep Agents.js support hierarchical agent planning with filesystem access.

- **Commercial & OSS Extensions**: LangSmith offers production-grade LLM application monitoring, while tools like `dcode`, Open SWE, MCP Adapters, Agent Protocol, and OpenWiki extend functionality for coding, tool integration, and knowledge management.

- **Ecosystem Resources**: Unified documentation, community forums, and free courses (LangChain Academy) support development and adoption of LangChain’s agent engineering platform.
