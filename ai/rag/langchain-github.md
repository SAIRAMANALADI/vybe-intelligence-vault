# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications; LangGraph/LangGraph.js enable building LLM agents as graph-based workflows; Deep Agents/Deep Agents.js support agent planning, subagent delegation, and filesystem interactions.

- **Commercial & OSS Extensions**: LangSmith offers a platform for developing and monitoring production-grade LLM applications; Deep Agents Code and Open SWE provide open-source terminal-based and asynchronous coding agents; MCP Adapters and Agent Protocol standardize MCP tool compatibility and framework-agnostic agent APIs.

- **Documentation & Community**: Unified documentation (docs.langchain.com) covers all LangChain projects; community forum (forum.langchain.com) facilitates discussions; LangChain Academy provides free courses on LangChain libraries and products.
