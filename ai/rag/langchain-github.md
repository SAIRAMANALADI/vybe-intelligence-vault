# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications; LangGraph/LangGraph.js enable building LLM agents as graphs; Deep Agents/Deep Agents.js facilitate agentic workflows with planning, subagents, and filesystem access.

- **Commercial & OSS Extensions**: LangSmith offers a platform for production-grade LLM application development and monitoring; MCP Adapters bridge MCP tools with LangChain/LangGraph; Agent Protocol standardizes framework-agnostic APIs for serving LLM agents.

- **Developer Tools**: Deep Agents Code (`dcode`) and Open SWE are open-source coding agents; OpenWiki generates and maintains codebase/personal memory wikis via CLI; unified documentation and community resources (forum, academy) support learning and integration.
