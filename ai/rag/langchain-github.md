# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable LLM application components and integrations; LangGraph/LangGraph.js enable agent construction via graph-based workflows; Deep Agents/Deep Agents.js support hierarchical agent planning, subagent delegation, and filesystem interactions.
- **Commercial & OSS Extensions**: LangSmith offers production-grade LLM application development/monitoring; Deep Agents Code and Open SWE provide terminal-based and asynchronous coding agents; MCP Adapters and Agent Protocol standardize MCP tool integration and framework-agnostic agent APIs.
- **Learning Resources**: Unified documentation at docs.langchain.com; community forum and LangChain Academy for structured, free training on LangChain ecosystem tools.
