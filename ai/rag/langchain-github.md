# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications; LangGraph/LangGraph.js enable building LLM agents as graphs; Deep Agents/Deep Agents.js support agent planning, subagents, and file system interactions.

- **Commercial & OSS Extensions**: LangSmith offers a platform for production-grade LLM application development and monitoring; MCP Adapters bridge MCP tools with LangChain/LangGraph; Agent Protocol standardizes framework-agnostic APIs for serving LLM agents.

- **Specialized Tools**: Deep Agents Code (`dcode`) and Open SWE are terminal-based coding agents; OpenWiki generates and maintains codebase wikis via CLI; unified documentation and community resources are available at [docs.langchain.com](https://docs.langchain.com).
