# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as computational graphs for complex workflows.

- **Agent Frameworks**: Deep Agents/Deep Agents.js support planning, subagent delegation, and filesystem interactions for advanced task execution, with commercial monitoring via LangSmith.

- **OSS Extensions**: Includes MCP Adapters for tool compatibility, Agent Protocol for framework-agnostic agent APIs, and specialized agents like `dcode` (terminal-based) and OpenWiki (codebase/wiki maintenance).
