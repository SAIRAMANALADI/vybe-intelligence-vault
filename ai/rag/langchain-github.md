# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as graphs; Deep Agents/Deep Agents.js support planning, subagents, and file system interactions for complex tasks.

- **Commercial & OSS Extensions**: LangSmith offers a platform for production-grade LLM application development and monitoring; extensions like Deep Agents Code (`dcode`), Open SWE, MCP Adapters, Agent Protocol, and OpenWiki provide CLI-based coding agents, async coding workflows, MCP tool compatibility, framework-agnostic agent APIs, and codebase/wiki generation tools.

- **Documentation & Community**: Unified documentation for LangChain projects is available at [docs.langchain.com](https://docs.langchain.com/), supported by a community forum and free courses via LangChain Academy.
