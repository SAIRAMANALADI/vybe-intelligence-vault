# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for building LLM applications, while LangGraph/LangGraph.js enable constructing LLM agents as graph-based workflows. Deep Agents/Deep Agents.js extend functionality with planning, subagent delegation, and filesystem interaction.

- **Commercial & OSS Extensions**: LangSmith offers a platform for deploying and monitoring production-grade LLM applications. OSS tools like Deep Agents Code, Open SWE, MCP Adapters, and Agent Protocol provide coding agents, async workflows, MCP tool compatibility, and standardized agent APIs.

- **Documentation & Community**: Unified documentation covers LangChain projects, with a community forum for discussions and LangChain Academy offering free courses on LangChain libraries and products.
