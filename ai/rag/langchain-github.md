# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as graphs; Deep Agents/Deep Agents.js support complex agent workflows with planning, subagents, and filesystem access.

- **Commercial & OSS Extensions**: LangSmith offers a platform for production-grade LLM application development and monitoring; OSS tools like Deep Agents Code, Open SWE, MCP Adapters, and Agent Protocol extend functionality for coding agents, tool compatibility, and framework-agnostic agent APIs.

- **Learning Resources**: Unified documentation, a community forum, and LangChain Academy provide structured learning for LangChain’s libraries and products.
