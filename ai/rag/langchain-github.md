# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as graphs; Deep Agents/Deep Agents.js support agent planning, subagent usage, and file system interactions for complex tasks.

- **Commercial & Extensible Tools**: LangSmith offers a platform for developing and monitoring production-grade LLM applications, with OSS extensions like Deep Agents Code (terminal-based coding agent), Open SWE (asynchronous coding agent), and MCP Adapters (MCP tool compatibility).

- **Standardization & Resources**: Agent Protocol defines framework-agnostic APIs for serving LLM agents in production, supported by unified documentation, a community forum, and free courses via LangChain Academy.
