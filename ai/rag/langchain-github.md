# LangChain · GitHub

## Summary

- **Core Libraries**: `LangChain`/`LangChain.js` provide reusable LLM application components and integrations; `LangGraph`/`LangGraph.js` enable agent construction via graph-based workflows; `Deep Agents`/`Deep Agents.js` support hierarchical planning, subagent delegation, and filesystem interactions for complex tasks.

- **Commercial & OSS Extensions**: `LangSmith` offers a production-grade platform for building and monitoring LLM applications; `Deep Agents Code` (`dcode`) and `Open SWE` are terminal-based/open-source coding agents; `MCP Adapters` bridge MCP tools with LangChain/LangGraph, while `Agent Protocol` standardizes framework-agnostic APIs for serving LLM agents.

- **Additional Tools**: `OpenWiki` generates/maintains codebase and personal memory wikis via CLI; unified documentation and community resources (forum, academy) are available at [docs.langchain.com](https://docs.langchain.com/).
