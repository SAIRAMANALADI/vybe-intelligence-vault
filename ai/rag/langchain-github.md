# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications; LangGraph/LangGraph.js enable building LLM agents as graphs; Deep Agents/Deep Agents.js support agent planning, subagents, and file system interactions.

- **Commercial & OSS Extensions**: LangSmith offers a platform for building/monitoring production-grade LLM apps; MCP Adapters and Agent Protocol standardize MCP tool compatibility and framework-agnostic agent APIs; OpenWiki and Deep Agents Code (dcode) provide CLI-based agents for codebase/wiki generation and coding tasks.

- **Learning Resources**: Unified documentation ([docs.langchain.com](https://docs.langchain.com/)), community forum, and LangChain Academy offer structured courses for LangChain libraries and products.
