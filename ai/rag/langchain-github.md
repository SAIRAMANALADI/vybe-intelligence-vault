# LangChain · GitHub

## Summary

- **Core Libraries**: `LangChain`/`LangChain.js` provide reusable components and integrations for LLM applications; `LangGraph`/`LangGraph.js` enable building LLM agents as computational graphs; `Deep Agents`/`Deep Agents.js` support agentic workflows with planning, subagents, and filesystem access.

- **Commercial & OSS Extensions**: `LangSmith` offers a platform for developing and monitoring production-grade LLM applications; `Deep Agents Code` and `Open SWE` provide open-source terminal-based coding agents; `MCP Adapters` and `Agent Protocol` standardize tool integration and framework-agnostic agent APIs.

- **Documentation & Community**: Unified documentation for LangChain projects via [docs.langchain.com](https://docs.langchain.com/); community forum ([forum.langchain.com](https://forum.langchain.com/)) for discussions; free courses available at [LangChain Academy](https://academy.langchain.com/).
