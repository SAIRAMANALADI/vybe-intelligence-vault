# LangChain · GitHub

## Summary

- **Core Libraries**: `LangChain`/`LangChain.js` provide reusable components and integrations for LLM applications, while `LangGraph`/`LangGraph.js` enable building LLM agents as graphs; `Deep Agents`/`Deep Agents.js` support planning, subagents, and file system interactions.

- **Commercial & OSS Extensions**: `LangSmith` offers a platform for production-grade LLM app development/monitoring; OSS tools like `Deep Agents Code` (terminal-based coding agent), `Open SWE` (asynchronous coding agent), and `MCP Adapters` bridge MCP tools with LangChain/LangGraph.

- **Standardization & Documentation**: `Agent Protocol` defines framework-agnostic APIs for serving LLM agents; unified docs, community forums, and free courses via `LangChain Academy` support learning and adoption.
