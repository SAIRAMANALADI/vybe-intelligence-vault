# LangChain · GitHub

## Summary

- **Core OSS Libraries**: LangChain/LangChain.js provide reusable components and LLM integrations; LangGraph/LangGraph.js enable agent construction via graph-based workflows; Deep Agents/Deep Agents.js support hierarchical agent planning with filesystem access.

- **Commercial Platform**: LangSmith offers production-grade monitoring and deployment for LLM applications.

- **OSS Extensions/Apps**: Includes terminal-based coding agents (`dcode`, Open SWE), MCP compatibility adapters, framework-agnostic agent APIs (`Agent Protocol`), and CLI tools for codebase/wiki generation (`OpenWiki`).
