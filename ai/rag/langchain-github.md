# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM application development; LangGraph/LangGraph.js enable building LLM agents as computational graphs; Deep Agents/Deep Agents.js support agentic workflows with planning, subagent delegation, and filesystem interactions.

- **Commercial & OSS Extensions**: LangSmith offers a production-grade platform for building and monitoring LLM applications; MCP Adapters bridge Model Context Protocol tools with LangChain/LangGraph; Agent Protocol standardizes framework-agnostic APIs for serving LLM agents in production.

- **Developer Tools**: Deep Agents Code (`dcode`) and Open SWE provide terminal-based and asynchronous coding agents; OpenWiki generates and maintains codebase wikis via CLI; unified documentation and community resources (forum, academy) support ecosystem adoption.
