# LangChain · GitHub

## Summary

- **Core Libraries**: `LangChain`/`LangChain.js` provide reusable LLM application components and integrations; `LangGraph`/`LangGraph.js` enable graph-based agent construction; `Deep Agents`/`Deep Agents.js` support hierarchical agent planning with filesystem access.

- **Commercial & OSS Extensions**: `LangSmith` offers production-grade LLM application monitoring; `Deep Agents Code` (`dcode`) and `Open SWE` are terminal-based coding agents; `MCP Adapters` and `Agent Protocol` standardize tool integration and framework-agnostic agent APIs.

- **Specialized Tools**: `OpenWiki` generates/maintains codebase and memory wikis via CLI; unified documentation and community resources (forum, academy) support ecosystem adoption.
