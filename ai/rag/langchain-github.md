# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as computational graphs; Deep Agents/Deep Agents.js support hierarchical agent planning and file system interactions.

- **Commercial & OSS Extensions**: LangSmith offers a production-grade platform for building/monitoring LLM apps; extensions like Deep Agents Code and Open SWE provide terminal-based coding agents, MCP Adapters bridge MCP tools with LangChain, and the Agent Protocol standardizes framework-agnostic APIs for serving LLM agents.

- **Documentation & Community**: Unified documentation (source: [langchain-ai/docs](https://github.com/langchain-ai/docs)) covers all projects; community forum and free LangChain Academy courses provide additional support and learning resources.
