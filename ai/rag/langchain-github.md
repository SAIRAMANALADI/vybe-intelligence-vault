# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as graph structures; Deep Agents/Deep Agents.js support agent planning, subagent delegation, and file system interactions for complex tasks.

- **Commercial Platform**: LangSmith offers a production-grade platform for building, monitoring, and managing LLM applications at scale.

- **OSS Extensions & Tools**: Includes MCP Adapters for MCP tool compatibility, Agent Protocol for framework-agnostic agent APIs, and specialized agents like `dcode` (terminal-based coding agent) and `OpenWiki` (CLI agent for codebase/wiki maintenance).
