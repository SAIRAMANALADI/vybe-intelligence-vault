# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as computational graphs with stateful workflows.
- **Agent Frameworks**: Deep Agents/Deep Agents.js support advanced agent capabilities including planning, subagent delegation, and filesystem interactions for complex task execution.
- **Commercial & OSS Extensions**: LangSmith offers production-grade monitoring for LLM applications, while tools like `dcode`, Open SWE, and MCP Adapters provide specialized agent implementations and protocol standardization (Agent Protocol) for framework-agnostic agent deployment.
