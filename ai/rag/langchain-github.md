# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM application development, while LangGraph/LangGraph.js enable building LLM agents as computational graphs. Deep Agents/Deep Agents.js support advanced agent capabilities like planning, subagent delegation, and file system interactions.

- **Commercial Platform**: LangSmith offers a production-grade environment for building, monitoring, and maintaining LLM applications at scale.

- **OSS Extensions**: Includes Deep Agents Code (terminal-based coding agent), Open SWE (asynchronous coding agent), MCP Adapters (MCP tool compatibility), and Agent Protocol (standardized framework-agnostic APIs for serving LLM agents).
