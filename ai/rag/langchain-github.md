# LangChain · GitHub

## Summary

- **Core Libraries**: LangChain/LangChain.js provide reusable components and integrations for LLM applications, while LangGraph/LangGraph.js enable building LLM agents as computational graphs; Deep Agents/Deep Agents.js support agentic workflows with planning, subagent delegation, and filesystem interactions.

- **Commercial & OSS Extensions**: LangSmith offers a production-grade platform for building/monitoring LLM applications; extensions like `dcode` (terminal-based coding agent), Open SWE (asynchronous coding agent), MCP Adapters (MCP tool compatibility), Agent Protocol (standardized agent APIs), and OpenWiki (codebase/wiki maintenance CLI) expand functionality.

- **Ecosystem Tools**: Unified documentation (via LangChain Academy and docs.langchain.com) and community forums (forum.langchain.com) support development, while the Agent Protocol codifies framework-agnostic APIs for deploying LLM agents in production.
