# volcengine/OpenViking

## Summary

- **Context Database for AI Agents**: OpenViking provides an open-source, file system-based context database (`context-engine`) for AI agents (e.g., OpenClaw), unifying memory, resources, and skills management via hierarchical context delivery and self-evolution mechanisms.

- **File System Paradigm**: Implements a filesystem-like abstraction to structure and deliver agent context (skills, memory, resources) hierarchically, enabling modular and scalable context engineering for agentic RAG and LLM workflows.

- **Python-Based Implementation**: Built in Python, OpenViking integrates with agent frameworks (e.g., OpenClaw) and supports RAG, memory management, and skill orchestration, with active development (last updated June 2026).
