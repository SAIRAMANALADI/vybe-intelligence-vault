# [2303.17580] HuggingGPT: Solving AI Tasks with ChatGPT and its Friends in Hugging Face

## Summary

- **Framework**: HuggingGPT integrates ChatGPT as a controller to orchestrate specialized AI models from Hugging Face via natural language, enabling multi-modal task decomposition and execution.

- **Pipeline**: The system performs task planning, model selection based on functional descriptions, subtask execution using selected models, and result aggregation to solve complex AI tasks across domains.

- **Capabilities**: Demonstrates proficiency in language, vision, speech, and cross-domain tasks by leveraging ChatGPT’s reasoning and Hugging Face’s diverse model repository.
