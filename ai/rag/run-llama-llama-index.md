# run-llama/llama_index

## Summary

- **Framework**: LlamaIndex is a Python-based framework designed for building document agents and OCR (Optical Character Recognition) pipelines, enabling structured extraction and processing of unstructured data.

- **Core Features**: Supports **RAG (Retrieval-Augmented Generation)**, **vector databases**, **multi-agent orchestration**, and **fine-tuning workflows**, facilitating scalable LLM (Large Language Model) applications.

- **Ecosystem Integration**: Provides tools for **data ingestion**, **indexing**, and **agent-based automation**, with compatibility across frameworks like LangChain and Hugging Face.
