# Skilljar Academy

## Summary

- **Skilljar Academy** provides role-based eLearning paths (e.g., Program Owner, Content Creator, Developer) with modular courses covering foundational, dashboard, and advanced customization topics.
- **Gainsight integration courses** focus on centralized customer data management via **Customer 360** (unified customer data) and **Timeline** (interaction tracking), with additional modules on **Text Analytics** and **Salesforce integration** for real-time training data sync.
- **Interactive and certification resources** include hands-on labs (e.g., adding multi-content types to lessons), scheduled report automation, and Japanese-language courses for **Customer Community Analytics** and **Digital Journey optimization**.
