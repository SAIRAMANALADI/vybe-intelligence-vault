# RFC 7033: WebFinger | RFC Editor

## Summary

- **Protocol Definition**: WebFinger is an HTTP-based protocol (RFC 7033) for discovering metadata about internet entities (e.g., people, services) identified by URIs, returning a JSON Resource Descriptor (JRD) with structured data (subject, aliases, properties, links).

- **JRD Structure**: The response format (JRD) includes mandatory `subject` (target URI), optional `aliases` (alternate identifiers), `properties` (key-value metadata), and `links` (relation types with `rel`, `href`, `type`, and `titles` fields).

- **Security & IANA Compliance**: Mandates CORS for cross-origin access, defines abuse mitigation, and requires IANA registration for link relation types/properties, ensuring standardized, secure, and extensible deployment.
