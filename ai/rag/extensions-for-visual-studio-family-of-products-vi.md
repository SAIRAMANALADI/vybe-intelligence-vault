# Extensions for Visual Studio family of products | Visual Studio Marketplace

## Summary

- **Marketplace Platform**: Visual Studio Code (VSCode) Marketplace serves as a centralized repository for extensions, themes, and other VSCode-compatible tools developed by Microsoft and third parties.
- **Authentication & Access Control**: Users must sign in via Microsoft’s identity platform (`app.vssps.visualstudio.com`) to publish, update, or download extensions, leveraging OAuth2-based authentication.
- **Compliance & Legal Frameworks**: The platform enforces Microsoft’s [Terms of Use](https://aka.ms/vsmarketplace-ToU), [Privacy Policy](https://go.microsoft.com/fwlink/?LinkID=521839), and [California Privacy Rights](https://aka.ms/YourCaliforniaPrivacyChoices) for data handling and user consent.
