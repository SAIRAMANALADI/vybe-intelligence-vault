# Project GraphRAG - Microsoft Research

## Summary

- **GraphRAG Architecture**: Combines text extraction, network analysis, and LLM prompting into an end-to-end system for structured text understanding, leveraging knowledge graphs derived from LLMs to enhance retrieval-augmented generation (RAG).

- **Dynamic Query Optimization**: Introduces methods like auto-tuning and dynamic community selection to adaptively balance local and global search strategies, improving query-focused summarization and reducing hallucinations in multi-step workflows.

- **Tooling & Ecosystem**: Released as open-source (e.g., LazyGraphRAG) and integrated into Microsoft Discovery, with benchmarks (BenchmarkQED) and provenance tools (VeriTrail) to validate RAG system performance and trace knowledge sources.
