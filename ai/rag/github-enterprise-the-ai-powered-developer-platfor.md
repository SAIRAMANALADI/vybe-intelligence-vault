# GitHub Enterprise · The AI-powered developer platform for the agent-ready enterprise · GitHub

## Summary

- **Integrated Security & Compliance**: GitHub Enterprise embeds security into the SDLC with automated scanning (CodeQL, secret/dependency checks) via GitHub Advanced Security, enforces non-overridable policies, and supports flexible data residency for compliance.

- **AI-Powered Development**: Leverages GitHub Copilot for agent-driven coding, AI-assisted vulnerability remediation, and centralized agent management to accelerate innovation while maintaining governance.

- **Scalable Governance & Ecosystem**: Enables multi-org management with custom roles/teams, enforces policies across repositories, and integrates with 180M+ developers via GitHub Marketplace for CI/CD, packages, and third-party tools.
