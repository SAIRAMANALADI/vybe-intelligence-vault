# GitHub Enterprise · The AI-powered developer platform for the agent-ready enterprise · GitHub

## Summary

- **Integrated Security Workflow**: GitHub Enterprise embeds automated, developer-first security tools (e.g., GitHub Advanced Security) for native code, secret, and dependency scanning, with features like CodeQL for vulnerability detection and Copilot Autofix for remediation within the CI/CD pipeline.

- **AI-Powered Development & Governance**: Leverages GitHub Copilot for AI-driven code completion and problem-solving, while providing centralized governance via custom roles, teams, and non-overridable policies (e.g., rulesets) across repositories for scalable enterprise control.

- **Flexible Deployment & Compliance**: Offers both cloud-based (GitHub Enterprise Cloud with optional data residency) and self-hosted (GitHub Enterprise Server) options, with enterprise-grade encryption (AES-256 at rest, HTTPS in transit), audit logs, and compliance features (e.g., LDAP/SAML integration) to meet regulatory requirements.
