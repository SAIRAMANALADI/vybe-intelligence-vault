# Desktop for developers | Ubuntu

## Summary

- **Long-Term Support (LTS) & Extended Security**: Ubuntu Desktop offers LTS releases every 2 years with 5 years of standard support, extendable to 15 years via Ubuntu Pro Desktop subscription; includes Kernel Livepatch to minimize reboots and FIPS 140-3/CIS hardening for enterprise-grade security.

- **Hardware/Software Ecosystem & AI/ML Optimization**: Pre-installed with latest toolchains (Python, Rust, Go, etc.), supports NVIDIA GPU-accelerated data science stacks (TensorFlow, PyTorch, OpenCV), and certified for OEM hardware (Dell, Lenovo, HP) with strategic partnerships for component compatibility.

- **Enterprise & Developer Tooling**: Ubuntu Pro provides Active Directory/LDAP integration, estate monitoring (Landscape), and optional 24/7 support; Snap Store offers 7,000+ apps, while development tools include VS Code, IntelliJ, GitKraken, and Blender.
