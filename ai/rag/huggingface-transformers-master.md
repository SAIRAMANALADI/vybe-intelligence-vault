# RAG · Hugging Face

## Summary

- **Hugging Face Transformers Library**: Provides a unified API for over 100+ pre-trained models (e.g., BERT, T5, LLaMA, Mistral) with support for text, vision, and multimodal tasks, including MoE (Mixture of Experts) variants like Mixtral and Qwen2MoE.

- **Modular Architecture**: Implements base classes for models (`PreTrainedModel`), tokenizers (`PreTrainedTokenizer`), and pipelines (`Pipeline`), enabling seamless integration with PyTorch/TensorFlow and optimized inference via ONNX/TensorRT.

- **Advanced Features**: Supports parameter-efficient fine-tuning (PEFT), quantization (bitsandbytes), distributed training, and hardware acceleration (e.g., AWS Trainium, Google TPUs) with dedicated APIs for chat, generation, and embeddings.
