# Code customization overview | Gemini for Google Cloud | Google Cloud Documentation

## Summary

- **Code Customization in Gemini Code Assist Enterprise** enables IDE-based code suggestions aligned with an organization's private repositories by indexing codebases (updated every 24 hours) and integrating with VS Code, IntelliJ, Cloud Workstations, and Cloud Shell Editor.

- **Security & Access Controls** enforce single-tenant storage, administrative access restrictions (IAM permissions, `.aiexclude` files), and prohibit model training on private code, with support for GitHub/GitLab/Bitbucket repositories (excluding GitHub Enterprise Cloud IP restrictions).

- **Limitations** include a cap of 20,000 repositories per index, support for 11 languages (e.g., Python, Java, Rust), and regional restrictions to `us-central1`, `europe-west1`, and `asia-southeast1`.
