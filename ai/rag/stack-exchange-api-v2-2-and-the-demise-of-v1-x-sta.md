# Stack Exchange API V2.2 - and the demise of V1.x - Stack Overflow

## Summary

- **API V2.2 Release**: Introduced new features including question/answer creation, voting, editing, deleting, flagging, and improved OAuth UI for mobile; fully documented and frozen as of February 10, 2014.

- **API V1.x Deprecation**: V1.0 and V1.1 of the Stack Exchange API will be permanently shut down on May 12, 2014, after nearly four years of service (released in 2010).

- **Excluded Functionality**: Feed API remains unpolished, user creation is deemed too sensitive for public stability, and non-OAuth login methods are excluded for security reasons.
