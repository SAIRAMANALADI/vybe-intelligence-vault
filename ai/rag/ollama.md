# Ollama

## Summary

- **Cross-platform CLI tool**: Ollama provides a unified command-line interface for interacting with open-source large language models (LLMs), enabling local deployment and inference without cloud dependencies.

- **PowerShell-native installation**: Windows users can install Ollama via a single PowerShell command (`irm https://ollama.com/install.ps1 | iex`), leveraging native scripting for seamless setup.

- **Model agnostic**: Supports deployment of various open-source LLMs (e.g., Llama 2, Mistral) with optimized local inference, prioritizing privacy and offline functionality.
