# Introduction to Azure security | Microsoft Learn

## Summary

- **Defense-in-Depth Security**: Azure implements a multi-layered security model spanning physical datacenters, compute, storage, networking, applications, and identity, ensuring redundancy if one layer is compromised.

- **Built-in Platform Security**: Azure provides default protections including DDoS mitigation, encryption-at-rest (e.g., Azure Storage, SQL Database), identity management via Microsoft Entra ID, and continuous threat detection with regulatory compliance coverage.

- **Shared Responsibility & Advanced Services**: Security is a joint effort—Microsoft secures infrastructure (IaaS/PaaS/SaaS layers), while customers manage data, identities, and access. Azure offers advanced services like **Trusted Launch** (Secure Boot, vTPM), **Confidential Computing** (AMD SEV-SNP, Intel TDX, SGX), and **Azure Key Vault** for HSM-backed key management.
