# Microsoft Academic Graph - Microsoft Research

## Summary

- **Graph Structure**: Heterogeneous graph containing ~86M publications, citation relationships, authors, institutions, journals, conferences, and fields of study, updated bi-weekly until Dec 31, 2021.

- **Access Methods**:
  - **MAG on Azure Storage**: Full graph access via automated bi-weekly uploads to private Azure Storage for analytics/research.
  - **Academic Knowledge API**: REST-based, rate-limited free API via Cognitive Services Labs.
  - **MAKES**: Deployable private instance of the API on Azure with no rate limits and scalable hardware.

- **Retirement & Citation**: Microsoft Academic (website/APIs) retired Dec 31, 2021; research using MAG must cite [Sinha et al., WWW ’15](http://dx.doi.org/10.1145/2740908.2742839).
