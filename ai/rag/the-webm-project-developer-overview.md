# The WebM Project | Developer Overview

## Summary

- **WebM Project Repositories**: Hosts open-source projects including `libvpx` (VP8/VP9 codec SDK), `libwebm` (WebM file parser), and `webm-tools` (alpha-channel, encryption, streaming tools), all managed via Git and Chromium Gerrit for code reviews and contributions.

- **Codec & Container Specifications**: Provides technical documentation for VP8/VP9 bitstream formats (RFC 6386), WebM container structure, VP9 levels/decoder testing, and encryption standards, enabling interoperable implementation and validation.

- **Development Workflow**: Requires Unix-like environments (e.g., Cygwin/MSYS) for Windows builds, with continuous integration via Jenkins, strict patch submission guidelines, and community engagement through mailing lists (e.g., `codec-devel`).
