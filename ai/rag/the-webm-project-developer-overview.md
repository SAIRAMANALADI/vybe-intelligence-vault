# The WebM Project | Developer Overview

## Summary

- **Core Components**: WebM Project provides open-source repositories including `libvpx` (VP8/VP9 codec SDK), `libwebm` (WebM file parser), and `webm-tools` (alpha-channel, encryption, and streaming tools), all hosted on Chromium's Gerrit for version control and code reviews.

- **Codec & Container Specifications**: Supports VP8 (RFC 6386) and VP9 codecs with detailed bitstream formats, container specifications (EBML-based), and encryption standards for secure media streaming and playback.

- **Development Workflow**: Uses Git for version control with continuous integration via Jenkins; contributors must follow patch submission, code review, and build prerequisites (e.g., Cygwin/MSYS for Windows) outlined in the project’s technical documentation.
