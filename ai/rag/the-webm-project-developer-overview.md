# The WebM Project | Developer Overview

## Summary

- **WebM Project Repositories**: Hosts open-source projects including `libvpx` (VP8/VP9 codec SDK), `libwebm` (WebM file parser), and `webm-tools` (alpha-channel, encryption, streaming tools), all managed via Git and Google's Gerrit for code reviews and patch submissions.

- **Codec & Container Specifications**: Provides technical documentation for VP8/VP9 bitstream formats, WebM container structure, encryption schemes, and RTP payload formats (e.g., RFC 6386, ISO Media File Format bindings).

- **Build & Contribution Workflow**: Requires Unix-like environments (Cygwin/MSYS) for Windows builds; contributors must follow patch submission, code review, and CI (Jenkins) processes outlined in the project’s contribution guidelines.
