# Configure security settings—ArcGIS Online Help | Documentation

## Summary

- **Security Configuration**: ArcGIS Online security settings are managed via the **Organization > Settings > Security** panel, allowing configuration of policies (access/permissions, sharing/search), sign-in methods (SAML, OpenID Connect, social logins), MFA, certificates/keys, and trusted servers.

- **Authentication & Access Control**: Supports **anonymous access**, **enterprise logins (SAML/OIDC)**, and **social logins**, with configurable password policies (length/complexity/expiry) and lockout thresholds (default: 5 failed attempts → 15-minute lockout).

- **Certificate Management**: Enables **self-signed or CA-signed certificate generation/upload** for SAML request signing/assertion encryption, with beta support for self-signed certs requiring disabling of beta-blocking settings.
