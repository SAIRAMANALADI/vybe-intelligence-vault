# Learning Center | Cloudflare

## Summary

- **DDoS Attacks**: Distributed denial-of-service (DDoS) attacks involve a coordinated network of compromised machines overwhelming a target system with traffic, rendering it inaccessible to legitimate users by exploiting bandwidth or resource limitations.

- **CDNs**: Content Delivery Networks (CDNs) utilize geographically distributed edge servers to cache and deliver static/dynamic content, reducing latency, improving load times, and enhancing reliability via techniques like Anycast routing and caching strategies.

- **DNS**: The Domain Name System (DNS) functions as a hierarchical, decentralized naming system translating human-readable domain names (e.g., `example.com`) into machine-identifiable IP addresses, enabling internet communication while being susceptible to attacks like cache poisoning and fast flux.
