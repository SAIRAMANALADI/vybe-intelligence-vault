# Learning Center | Cloudflare

## Summary

- **DDoS Attacks**: Distributed denial-of-service (DDoS) attacks involve coordinated networks of computers overwhelming a target's access point to disrupt legitimate service access, with variants including application-layer attacks and those targeting cryptocurrency infrastructure.

- **CDN Architecture**: Content Delivery Networks (CDNs) utilize distributed servers to cache and deliver web content efficiently, improving latency and reliability via techniques like Anycast routing and dynamic/static content caching.

- **Zero Trust & SASE Models**: Zero Trust enforces strict identity verification for all access requests, while Secure Access Service Edge (SASE) integrates SD-WAN with cloud-native security services (e.g., ZTNA, SWG) to secure distributed enterprise networks.
