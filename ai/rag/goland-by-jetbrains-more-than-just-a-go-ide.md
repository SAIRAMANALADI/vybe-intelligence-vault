# GoLand by JetBrains: More than just a Go IDE

## Summary

- **Pre-configured IDE**: GoLand provides an out-of-the-box setup with built-in support for Go, JavaScript, TypeScript, Python, Docker, Kubernetes (k8s), Terraform, Git, and database tools, eliminating the need for manual extension installation and configuration.

- **Language & Tool Integration**: Supports core languages (Go, JavaScript, TypeScript, Python) alongside DevOps and infrastructure tools (Docker, Kubernetes, Terraform) and version control (Git), enabling streamlined development workflows.

- **Customizable Flexibility**: Offers default configurations for immediate productivity while allowing deep customization for advanced users requiring tailored development environments.
