# Welcome to Snowflake Documentation | Snowflake Documentation

## Summary

- Snowflake's architecture leverages a hybrid of shared-disk and shared-nothing models, with data stored in cloud storage and compute resources decoupled, enabling independent scaling of storage and compute layers.

- Supports structured, semi-structured (VARIANT, OBJECT, ARRAY), and unstructured data (via directory tables and REST API), with specialized functions for querying and processing JSON, Parquet, Avro, and other formats.

- Provides Time Travel (configurable data recovery up to 90 days), Fail-safe (7-day recovery), and zero-copy cloning for data protection and rapid deployment, alongside features like streams, tasks, and multi-cluster warehouses for data pipelines and performance optimization.
