# Index - FHIR v6.0.0-ballot4

## Summary

- **FHIR R6 CI-Build**: Continuous Integration build of FHIR (HL7 standard for healthcare data exchange), currently in ballot phase (R6), with core specification version `6.0.0-ballot4` (generated 2026-06-23).
- **Modular Structure**: Organized into 5 levels—foundation (data types, XML/JSON/RDF), implementation support (security, conformance, terminology), healthcare administration (patient, practitioner), clinical modules (medications, diagnostics, workflow), and clinical reasoning (medication definitions, measures).
- **Artifact Ecosystem**: Includes resource types (e.g., `Patient`, `Observation`), extensions, profiles, search parameters, and implementation guides; supports REST API, messaging, and terminologies (CodeSystem, ValueSet) with open CC0 licensing.
