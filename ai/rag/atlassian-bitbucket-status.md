# Atlassian Bitbucket Status

## Summary

- **Incident Notification System**: Organization admins can subscribe to **System Health** notifications in Atlassian Administration to receive personalized incident alerts affecting their organization via email, SMS, Slack, or webhook integrations.

- **Operational Status Dashboard**: Bitbucket provides a real-time **status page** (status.bitbucket.org) displaying system uptime metrics (99.92% over 90 days), incident history, and component-specific operational states (e.g., API, Git via SSH/HTTPS, Pipelines).

- **Multi-Channel Incident Tracking**: Supports **email, SMS (global), Slack, and webhook** notifications for incident creation, updates, resolutions, and maintenance events, with historical data accessible via Atom/RSS feeds.
