# The latest on DevSecOps - The GitHub Blog

## Summary

- **Traceability Integration**: GitHub and JFrog integration enables end-to-end traceability from code commits to production artifacts via GitHub Actions workflows and JFrog Artifactory/Xray, ensuring immutable linkage between source and build outputs.

- **Automated Security Scanning**: The integration automates vulnerability scanning (e.g., CVE detection) and policy enforcement in Artifactory, blocking non-compliant artifacts before deployment while maintaining audit trails in GitHub.

- **Unified Workflow**: Leverages GitHub Actions to trigger JFrog CLI commands (e.g., `jf rt upload`, `jf audit`) within CI/CD pipelines, eliminating tool-switching and reducing manual errors in artifact promotion workflows.
