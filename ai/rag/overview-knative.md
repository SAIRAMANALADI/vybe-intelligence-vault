# Overview - Knative

## Summary

- **Knative Serving**: Kubernetes-native HTTP-triggered autoscaling runtime with CRDs (Services, Routes, Configurations, Revisions) for stateless workloads, enabling automatic scaling (including scale-to-zero), traffic splitting (blue-green/canary), and GPU/ML inference support via pod resource requests.

- **Knative Eventing**: CloudEvents-compliant event mesh using loosely coupled components (Sources, Brokers, Triggers, Sinks) for asynchronous event routing, supporting decoupled producers/consumers and multi-language event processing.

- **Knative Functions**: Developer-centric framework simplifying serverless function deployment by abstracting Kubernetes complexity, enabling local builds/tests and portable stateless functions via standardized containerization.
