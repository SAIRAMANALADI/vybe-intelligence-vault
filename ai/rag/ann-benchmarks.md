# ANN-Benchmarks

## Summary

- **Benchmarking Framework**: ANN-Benchmarks evaluates approximate nearest neighbor (ANN) search algorithms across diverse datasets and distance metrics (Angular, Euclidean, Hamming, Jaccard), reporting performance via **Recall vs. Queries per second** trade-offs, with interactive plots for detailed metrics (e.g., index size, build time).

- **Evaluated Algorithms**: Includes **30+ ANN methods** (e.g., FAISS-IVF, HNSW, Annoy, ScaNN, DiskANN) benchmarked on standardized datasets like *glove-100-angular*, *fashion-mnist-784-euclidean*, and *sift-128-euclidean*, with results aggregated per algorithm for cross-dataset comparison.

- **Open-Source & Extensible**: Hosted on [GitHub](https://github.com/erikbern/ann-benchmarks), the project allows contributions via pull requests to add new algorithms/datasets, with maintainers (Aumueller, Bernhardsson, Faitfull) facilitating community-driven benchmarking improvements.
