# llms.txt directory - Find llms.txt files across the web

## Summary

- **Standardized LLM Metadata**: The `llms.txt` standard (derived from [llmstxt.org](https://llmstxt.org)) provides a structured format for websites to publish machine-readable metadata, enabling LLMs to discover and interact with web content efficiently.

- **Global Adoption & Token Metrics**: The directory ([llmstxt.site](https://llmstxt.site/)) aggregates `llms.txt` files across ~60 domains, with token counts ranging from 0 (e.g., hotel sites) to 306,542 (e.g., Attain Loans), and some sites offering extended `llms-full.txt` variants.

- **Submission & Validation Workflow**: Users can submit their site’s `llms.txt` via [llmstxt.site/submit](https://llmstxt.site/submit), with validation ensuring compliance to the standard (e.g., correct path `/llms.txt` or `/a/llms`).
