# SentenceTransformer — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (pip, conda, uv, source), editable installs, and PyTorch with CUDA; includes migration guides for version updates (e.g., v5.x to v5.4+) with changes like renamed parameters (`max_length` → `max_seq_length`) and API adjustments.

- **Sentence Transformer Capabilities**: Enables computing embeddings, semantic textual similarity, semantic search (symmetric/asymmetric), clustering (k-Means, agglomerative), paraphrase mining, and multimodal applications (image/text, audio/video); supports quantization (binary, int8) and efficiency optimizations (PyTorch, ONNX, OpenVINO).

- **Training & Evaluation**: Provides structured training pipelines with components (model, dataset, loss, evaluator, trainer), supports multi-dataset training, and integrates MTEB for standardized evaluation; includes pre-trained models for semantic search, multilingual, and scientific similarity tasks.
