# SentenceTransformer — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with optional CUDA-accelerated PyTorch; migration guides cover breaking changes across major versions (v2.x→v5.4+), including renamed parameters (`max_length`→`max_seq_length`) and API updates.

- **Sentence Transformer Capabilities**: Enables embedding generation, semantic similarity, semantic search (symmetric/asymmetric), retrieve-re-rank pipelines, clustering (k-means, agglomerative), paraphrase mining, and multimodal (image/text) applications; supports quantization (binary/int8) and efficiency optimizations (ONNX, OpenVINO).

- **Training & Evaluation**: Provides modular training components (model, dataset, loss, evaluator) with multi-dataset support; includes MTEB benchmark evaluation, pre-trained models (multilingual, scientific, INSTRUCTOR), and custom model creation from Transformers architectures.
