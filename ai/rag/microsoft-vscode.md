# microsoft/vscode

## Summary

- **Core Architecture**: Electron-based cross-platform code editor with TypeScript for frontend and C++/TypeScript for backend services, leveraging Chromium for rendering.

- **Key Features**: Built-in debugging, IntelliSense, Git integration, and extensibility via a rich extension API (Language Server Protocol support).

- **Performance Optimizations**: Utilizes a multi-process architecture (main, renderer, and extension host processes) with Web Workers for background tasks to ensure responsiveness.
