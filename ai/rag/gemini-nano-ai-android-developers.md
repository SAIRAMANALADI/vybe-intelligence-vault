# Gemini Nano | AI | Android Developers

## Summary

- **On-device AI with Gemini Nano**: Runs via Android's AICore system service, enabling low-latency, offline generative AI while ensuring privacy by processing data locally and adhering to Private Compute Core principles.
- **ML Kit GenAI APIs**: High-level interfaces leveraging Gemini Nano for tasks like text generation, summarization, proofreading, rewriting, image description, and speech recognition, all executed on-device via AICore.
- **AICore Architecture**: Isolated system module with restricted internet access (via Private Compute Services), hardware-accelerated inference, built-in safety filters, and request isolation to protect user data and ensure secure, cost-efficient AI model deployment.
