# Gemini Nano | AI | Android Developers

## Summary

- **On-device AI with Gemini Nano**: Runs via Android's AICore system service for low-latency, offline generative AI tasks (text, summarization, proofreading, etc.) while ensuring privacy by processing data locally without cloud dependency.
- **ML Kit GenAI APIs Integration**: Provides high-level interfaces for tasks like text generation, image description, and speech recognition, built atop AICore to leverage hardware acceleration and safety filters.
- **AICore Architecture & Privacy**: Isolates AI processing via restricted package binding and indirect internet access (via Private Compute Services), ensures no data retention, and manages model updates/weights securely on-device.
