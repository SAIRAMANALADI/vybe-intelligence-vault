# Gemini Nano | AI | Android Developers

## Summary

- **On-device AI with Gemini Nano**: Runs via Android's AICore system service, enabling low-latency, offline generative AI tasks (e.g., text generation, summarization, proofreading) while prioritizing privacy by processing data locally without cloud dependency.
- **ML Kit GenAI APIs Integration**: Provides high-level interfaces for tasks like text generation, image description, and speech recognition, leveraging AICore’s hardware acceleration and safety filters for secure, efficient on-device inference.
- **AICore Architecture & Privacy**: Isolates AI processing via restricted package binding, indirect internet access (via Private Compute Services), and request-level isolation, ensuring no data retention while managing model updates and hardware acceleration.
