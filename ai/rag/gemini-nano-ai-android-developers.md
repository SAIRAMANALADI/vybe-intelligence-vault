# Gemini Nano | AI | Android Developers

## Summary

- **On-device AI with Gemini Nano**: Leverages Android's AICore system service for low-latency, offline generative AI via the Gemini Nano foundation model, ensuring privacy and cost efficiency by processing data locally without cloud dependency.

- **ML Kit GenAI APIs**: Provides high-level interfaces for tasks like text generation, summarization, proofreading, and image description, built on AICore for secure, on-device execution while adhering to [ML Kit GenAI API Additional Terms](https://developers.google.com/ml-kit/genai-terms).

- **AICore Architecture & Privacy**: Isolates AI processing via restricted package binding and indirect internet access (via Private Compute Services), enforces safety filters, and ensures no data retention, aligning with [Private Compute Core](https://arxiv.org/abs/2209.10317) principles for secure, hardware-accelerated inference.
