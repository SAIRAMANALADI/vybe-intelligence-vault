# Changelog - Docs by LangChain

## Summary

- **DeepAgents v1.9.0-alpha.0**: Introduces async subagents for non-blocking background tasks (requires LangSmith Deployment) and **BackendProtocolV2** with structured `Result` objects, multi-modal file support (`Uint8Array` via `readRaw()`), simplified method names (e.g., `ls` instead of `lsInfo`), and backward compatibility via `adaptBackendProtocol`.

- **LangGraph v1.1.0**: Adds **StateSchema** with Standard JSON Schema support (Zod 4, Valibot, etc.), new primitives (`ReducedValue`, `UntrackedValue`, `MessagesValue`), and type helpers (`GraphNode`, `ConditionalEdgeRouter`) for schema-first state definitions and external function typing.

- **LangChain v1.2.0–v1.3.0**: Introduces provider-specific server-side tools (file search, web search, code interpreter, etc.), structured output `strict` mode, content moderation, and model profiles for feature/capability exposure. Other packages (e.g., `@langchain/ollama`, `@langchain/mongodb`) add native structured outputs, hybrid search, and LLM caching.
