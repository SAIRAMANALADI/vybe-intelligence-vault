# Changelog - Docs by LangChain

## Summary

- **`deepagents` v1.9.0-alpha.0**: Introduces async subagents for non-blocking background tasks (requires LangSmith Deployment) and **BackendProtocolV2** with structured `Result` objects (e.g., `ReadResult`, `LsResult`), multi-modal file support via `Uint8Array` for binary content, and simplified method names (e.g., `ls` instead of `lsInfo`).

- **`@langchain/langgraph` v1.1.0**: Adds **StateSchema** for schema-first graph state definition with Standard JSON Schema support (compatible with Zod 4, Valibot, etc.), new primitives like `ReducedValue` (custom reducers), `UntrackedValue` (transient state), and `MessagesValue` (prebuilt chat message reducer), plus type utilities (`GraphNode`, `ConditionalEdgeRouter`).

- **LangChain v1.2.0–v1.3.0**: Introduces **provider-specific server-side tools** (e.g., file search, web search, code interpreter in `@langchain/openai`), **content moderation** for OpenAI/Athropic, **native structured outputs** in `@langchain/ollama`, and **model profiles** for feature/capability exposure via `.profile` getter.
