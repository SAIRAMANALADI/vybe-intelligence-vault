# Changelog - Docs by LangChain

## Summary

- **`deepagents` v0.7.0a6**: Introduced a new `delete` filesystem tool with backend-agnostic deletion handling, `write_file` now overwrites existing files (use `edit_file` for targeted changes), and added structured system prompt configuration via `SystemPromptConfig` for customizable prompts.

- **`langgraph` v1.2.0**: Added `DeltaChannel` (beta) for incremental state storage, per-node timeouts/error handlers, and a new event streaming API (`version="v3"`) with typed, per-channel projections for improved performance and control.

- **`deepagents` v0.6.0**: Introduced `CodeInterpreterMiddleware` (experimental) for code execution, `ContextHubBackend` for versioned filesystem storage via LangSmith Hub, and harness profiles for automatic model-specific configurations.
