# Changelog - Docs by LangChain

## Summary

- **`deepagents` v0.6.0**: Introduces experimental `CodeInterpreterMiddleware` for scoped QuickJS runtime-based code execution and tool calling; adds `DeltaChannel` (beta) for incremental checkpoint storage to reduce overhead in long-running threads; introduces `HarnessProfile` for per-provider/model configuration bundles and `ContextHubBackend` for versioned agent file storage via LangSmith Hub.

- **`langgraph` v1.2.0**: Adds per-node timeouts, error handlers, and graceful shutdown for node execution; introduces `DeltaChannel` (beta) to store only incremental deltas for large-growing channels; introduces new event streaming API (`version="v3"`) with typed, per-channel projections and content-block-centric streaming.

- **`langchain` v1.3.0 & `langgraph` v1.2.0**: Both releases add support for `version="v3"` in `stream_events`/`astream_events`, enabling enhanced event streaming with typed projections and per-channel granularity for improved debugging and state management.
