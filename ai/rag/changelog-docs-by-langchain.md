# Changelog - Docs by LangChain

## Summary

- **`deepagents` v0.6.0**: Introduces experimental `CodeInterpreterMiddleware` for scoped QuickJS runtime-based code execution and tool calling; adopts `DeltaChannel` (beta) for incremental state checkpointing to optimize storage in long-running threads; adds `HarnessProfile` for provider/model-specific configurations and `ContextHubBackend` for versioned agent file storage via LangSmith Hub.

- **`langgraph` v1.2.0**: Adds `DeltaChannel` (beta) for delta-based state storage, per-node timeouts/error handlers for fault tolerance, and a new `version="v3"` streaming API with typed, per-channel projections; introduces graceful shutdown via `RunControl` for resumable checkpoints.

- **`langchain` v1.3.0**: Supports `version="v3"` in `stream_events`/`astream_events` for enhanced event streaming across agents, aligning with updates in `deepagents` and `langgraph` for improved state and event handling.
