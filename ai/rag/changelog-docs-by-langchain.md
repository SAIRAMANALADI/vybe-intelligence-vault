# Changelog - Docs by LangChain

## Summary

- **DeepAgents v0.7.0a6**: Introduced `delete` filesystem tool (with backend-specific visibility), `write_file` now overwrites existing files (use `edit_file` for targeted changes), middleware override support via `.name` matching, filesystem tool allowlisting in `FilesystemMiddleware`, and structured system prompt configuration via `SystemPromptConfig`.

- **LangGraph v1.2.0**: Added `DeltaChannel` (beta) for incremental state storage, per-node timeouts (`run_timeout`, `idle_timeout`), node-level error handlers for recovery, graceful shutdown via `RunControl`, and a new v3 event streaming API with typed, per-channel projections.

- **LangChain v1.3.0**: Added support for `version="v3"` in `stream_events`/`astream_events` for agents, enabling enhanced event streaming capabilities across the framework.
