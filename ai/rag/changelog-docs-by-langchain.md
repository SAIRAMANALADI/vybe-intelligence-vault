# Changelog - Docs by LangChain

## Summary

- **DeepAgents v0.7.0a6**: Introduced a new `delete` filesystem tool (with backend-agnostic fallback), `write_file` now overwrites existing files (use `edit_file` for targeted changes), added middleware override support via `.name` matching, and introduced `SystemPromptConfig` for structured system prompt configuration.

- **LangGraph v1.2.0**: Added `DeltaChannel` (beta) for incremental delta storage in checkpoints, per-node timeouts (`run_timeout`, `idle_timeout`) and error handlers for fault tolerance, and a new event streaming API (`version="v3"`) with typed, per-channel projections.

- **LangChain v1.3.0**: Added support for `version="v3"` in `stream_events`/`astream_events` for agents, enabling enhanced event streaming capabilities.
