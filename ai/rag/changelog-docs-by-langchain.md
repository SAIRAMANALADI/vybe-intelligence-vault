# Changelog - Docs by LangChain

## Summary

- **DeepAgents v0.7.0a6**: Introduced a new `delete` filesystem tool with recursive directory support, `write_file` now overwrites existing files, and added middleware override capabilities for system-prompt customization and filesystem tool restrictions.
- **LangGraph v1.2.0**: Added `DeltaChannel` for incremental checkpoint storage, per-node timeouts/error handlers, and a new v3 event streaming API with typed, per-channel projections for improved efficiency in long-running threads.
- **LangChain v1.3.0**: Unified `version="v3"` support for `stream_events`/`astream_events` across agents, enabling content-block-centric streaming with typed projections and enhanced fault tolerance.
