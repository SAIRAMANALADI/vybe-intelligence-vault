# Changelog - Docs by LangChain

## Summary

- **DeepAgents v0.7.0a6**: Introduced a new `delete` filesystem tool with backend-agnostic deletion handling, `write_file` now overwrites existing files, added middleware override support via `.name` matching, filesystem tool allowlisting in `FilesystemMiddleware`, and structured system prompt configuration via `SystemPromptConfig`.

- **LangGraph v1.2.0**: Added `DeltaChannel` (beta) for incremental state storage, per-node timeouts (`run_timeout`, `idle_timeout`) and error handlers, graceful shutdown via `RunControl`, and a new event streaming API (`version="v3"`) with typed, per-channel projections.

- **LangChain v1.3.0**: Added support for `version="v3"` in `stream_events`/`astream_events` for event streaming across agents, with structured output and checkpoint optimizations.
