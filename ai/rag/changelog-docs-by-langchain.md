# Changelog - Docs by LangChain

## Summary

- **DeepAgents v1.9.0-alpha.0**: Introduces async subagents for non-blocking background tasks (requires LangSmith Deployment) and **BackendProtocolV2** with structured `Result` objects, multi-modal file support via `Uint8Array`, simplified method names, and backward compatibility via `adaptBackendProtocol`.

- **LangGraph v1.1.0**: Adds **StateSchema** for schema-first graph state definitions using Standard JSON Schema (Zod 4, Valibot, etc.), introduces `ReducedValue`, `UntrackedValue`, and `MessagesValue` primitives, and exports type utilities (`GraphNode`, `ConditionalEdgeRouter`) for external function typing.

- **LangChain v1.2.0–v1.3.0**: Adds structured output `strict` mode, provider-specific server-side tools (file/web search, code interpreter, image generation, etc.) for OpenAI/Anthropic, model profiles for feature detection, retry/moderation middleware, and updates across `@langchain/community`, `@langchain/xai`, `@langchain/tavily`, and `@langchain/mongodb` (e.g., LLM cache, hybrid search, Tavily research endpoint).
