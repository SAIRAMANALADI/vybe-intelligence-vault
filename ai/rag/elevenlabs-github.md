# ElevenLabs · GitHub

## Summary

- **Primary SDKs**: Official client libraries for ElevenLabs API include Python (`elevenlabs-python`, 3.1k stars), JavaScript/Node (`elevenlabs-js`, 439 stars), Kotlin (`elevenlabs-android`), and Swift (`elevenlabs-swift-sdk`), all MIT-licensed.

- **MCP & Tooling**: Provides a Model Context Protocol (MCP) server (`elevenlabs-mcp`, 1.5k stars) and CLI tools for voice agent interaction, facilitating multimodal AI integration.

- **UI & Extensions**: `ui` repository offers a component library built on `shadcn/ui` for rapid multimodal agent development, while `packages` provides an Agents SDK for TypeScript.
