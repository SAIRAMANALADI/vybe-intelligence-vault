# run-llama/ParseBench

## Summary

- **Purpose**: ParseBench is a document parsing benchmark designed to evaluate AI agents' performance in parsing diverse document types (e.g., PDFs, tables, OCR-extracted text) using metrics tailored for document-AI tasks.

- **Scope**: Includes evaluation frameworks for vision-language models (VLMs), LLM-based parsers (e.g., LlamaIndex), and OCR pipelines, with a focus on table extraction, layout analysis, and structured data recovery.

- **Technical Stack**: Implemented in Python, leveraging libraries for PDF parsing (e.g., PyMuPDF), OCR (e.g., Tesseract), and ML-driven parsing (e.g., LlamaIndex), with standardized metrics for reproducibility.
