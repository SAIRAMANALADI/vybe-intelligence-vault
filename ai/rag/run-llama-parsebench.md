# run-llama/ParseBench

## Summary

- **Purpose**: ParseBench is a specialized benchmarking framework designed to evaluate the performance of AI agents in document parsing tasks, including PDF parsing, OCR, and table extraction.

- **Key Features**: Supports evaluation of vision-language models (VLMs) and LLMs for structured document understanding, with metrics for accuracy, robustness, and efficiency across diverse document types.

- **Integration**: Compatible with LlamaIndex, enabling seamless testing of document parsing pipelines and retrieval-augmented generation (RAG) workflows in Python-based AI agent systems.
