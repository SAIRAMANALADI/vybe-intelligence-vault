# run-llama/ParseBench

## Summary

*   `ParseBench` is a Python-based benchmark suite for evaluating AI agents' document parsing proficiency, specifically targeting OCR, PDF parsing, and table extraction.
*   It provides a standardized framework for assessing the performance of LLMs and VLMs in complex document understanding tasks.
*   The benchmark facilitates comparative analysis of document AI techniques, including those integrated with LlamaIndex, across diverse parsing challenges.
