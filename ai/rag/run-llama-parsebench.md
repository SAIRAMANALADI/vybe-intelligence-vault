# run-llama/ParseBench

## Summary

- **Benchmark Suite**: ParseBench provides a standardized evaluation framework for document parsing tasks, including PDF parsing, OCR, and table extraction, designed for AI agents and LLMs.

- **Multi-Modal Evaluation**: Supports vision-language models (VLMs) and integrates OCR-based parsing, enabling comparative analysis across different parsing techniques (e.g., text-based vs. image-based extraction).

- **LlamaIndex Integration**: Optimized for LlamaIndex, facilitating seamless benchmarking of document parsing pipelines with structured evaluation metrics for real-world document AI applications.
