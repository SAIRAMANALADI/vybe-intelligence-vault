# run-llama/ParseBench

## Summary

- **Benchmark Suite**: ParseBench provides a standardized evaluation framework for document parsing AI agents, covering tasks like OCR, PDF parsing, and table extraction.

- **Multi-Modal Evaluation**: Supports both text-based and vision-language models (VLMs) for comprehensive assessment of parsing performance across different document types.

- **Integration-Friendly**: Designed for compatibility with LlamaIndex, enabling seamless benchmarking within existing AI agent workflows and pipelines.
