# pgf-tikz Info Page

## Summary

- **Mailing List**: `pgf-tikz` is a mailing list for PGF/TikZ discussions, hosted at [tug.org](https://tug.org/mailman/listinfo/pgf-tikz), with archives available at [pipermail](https://tug.org/pipermail/pgf-tikz/).
- **Subscription & Management**: Users can subscribe, unsubscribe, or modify settings via the [administrative interface](https://tug.org/mailman/admin/pgf-tikz) (authorization required), with list mail optionally batched in daily digests.
- **Technical Stack**: The list is powered by **Mailman 2.1.30**, uses **Python** for backend operations, and adheres to **GNU** licensing standards.
