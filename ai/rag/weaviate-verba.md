# weaviate/Verba

## Summary

- **RAG Implementation**: Verba is a Retrieval Augmented Generation (RAG) chatbot built on Weaviate, enabling dynamic retrieval of contextually relevant data during inference to enhance response generation.

- **Weaviate Integration**: Leverages Weaviate’s vector database for efficient storage, indexing, and retrieval of embeddings, supporting hybrid search (vector + keyword) and modular query pipelines.

- **Python-Based Architecture**: Entirely developed in Python, with modular components for document ingestion, embedding generation, retrieval, and LLM interaction, facilitating extensibility and customization.
