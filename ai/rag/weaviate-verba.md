# GitHub - weaviate/Verba: Retrieval Augmented Generation (RAG) chatbot powered by Weaviate · GitHub

## Summary

- **Discontinued Project**: Verba (Golden RAGtriever) is no longer in active development; the repository is archived with no future updates, bug fixes, or security patches.
- **Multi-Provider RAG Framework**: Supported LLM providers (Ollama, HuggingFace, Cohere, Anthropic, OpenAI, Groq, Novita AI) and embedding models (Weaviate, SentenceTransformers, Cohere, VoyageAI) with hybrid search, filtering, and customizable metadata.
- **Deployment Options**: Installable via `pip`, buildable from source, or deployable via Docker; requires Python 3.10–3.12 and environment variables for API keys (e.g., `OPENAI_API_KEY`, `WEAVIATE_API_KEY_VERBA`).
