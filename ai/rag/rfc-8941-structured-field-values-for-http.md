# RFC 8941 - Structured Field Values for HTTP

## Summary

- **RFC 8941** defines a standardized set of data types and algorithms for HTTP structured fields (headers/trailers), enabling safer and more consistent parsing/serialization than traditional HTTP field values.

- **Core structured types** include lists (with inner lists/parameters), dictionaries, and typed items (integers, decimals, strings, tokens, byte sequences, booleans) with strict serialization/parsing rules.

- **Security and extensibility** are addressed via IANA considerations, strict processing requirements, and explicit guidance for defining new structured fields while mitigating parsing ambiguities.
