# Gemini Code Assist overview | Google for Developers

## Summary

- **Gemini Code Assist** leverages the **Gemini 2.5 model** to provide AI-powered coding assistance across the software development lifecycle, available in **free, Standard, and Enterprise editions** with varying features and integrations.
- **Standard/Enterprise editions** support **IDE-based code generation, debugging, and conversational assistance** (VS Code, JetBrains, Android Studio) with **source citations**, while Enterprise adds **private codebase customization** and **Google Cloud service integrations** (e.g., Apigee, BigQuery, Firebase).
- **Output validation is required** due to early-stage limitations (e.g., plausible but incorrect responses), with **IP indemnification** and **enterprise-grade security** (VPC-SC, Private Google Access) in higher-tier editions.
