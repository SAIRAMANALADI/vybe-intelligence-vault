# Gemini Code Assist overview | Google for Developers

## Summary

- **Gemini Code Assist** leverages the **Gemini 2.5 model** to provide AI-powered assistance across the software development lifecycle, available in **free, Standard, and Enterprise editions** with varying features and integrations.
- **Standard/Enterprise editions** support **IDE-based code generation, debugging, and conversational assistance** (VS Code, JetBrains, Android Studio) with **source citations**, while Enterprise adds **private codebase customization** and broader **Google Cloud integrations** (Apigee, BigQuery, Firebase, etc.).
- **Output validation is required** due to early-stage risks of incorrect or non-factual responses, with **IP indemnification** and **VPC-SC support** for Enterprise users.
