# Gemini Code Assist overview | Google for Developers

## Summary

- **Gemini Code Assist** leverages the **Gemini 2.5 model** to provide AI-powered coding assistance across the **software development lifecycle (SDLC)**, available in **Free, Standard, and Enterprise editions** with varying features and integrations.
- **Standard/Enterprise editions** offer **IDE-based code generation, conversational assistance, and source citations**, while **Enterprise adds private codebase customization, extended Google Cloud integrations (e.g., Apigee, BigQuery, Firebase), and enterprise-grade security/compliance**.
- **Output validation is required** due to early-stage inaccuracies, with **IP indemnification, VPC-SC support, and agentic chat (multi-step task automation)** included in higher-tier editions.
