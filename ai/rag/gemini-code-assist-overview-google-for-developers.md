# Gemini Code Assist overview | Google for Developers

## Summary

- **Gemini Code Assist** leverages the **Gemini 2.5 model** to provide AI-powered coding assistance across the software development lifecycle, available in **free, Standard, and Enterprise editions** with varying features and integrations.
- **Standard/Enterprise editions** offer **IDE-based code generation, debugging, and conversational assistance** (VS Code, JetBrains, Android Studio), with **Enterprise** adding **private codebase customization, extended Google Cloud integrations** (Apigee, BigQuery, Firebase), and **enterprise-grade security/compliance**.
- **Key limitations**: Output requires validation due to potential inaccuracies; **source citations** are provided for transparency, and **IP indemnification** is included for Enterprise users.
