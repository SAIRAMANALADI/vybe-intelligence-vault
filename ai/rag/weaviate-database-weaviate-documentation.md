# Weaviate Database | Weaviate Documentation

## Summary

- **Open-source vector database**: Weaviate stores both data objects and their vector embeddings, enabling semantic search, hybrid search, and retrieval-augmented generation (RAG) workflows by comparing vector similarities rather than relying on keyword matching.

- **Multi-deployment options**: Supports evaluation and production deployments via Weaviate Cloud (managed), Docker (local), Kubernetes (scalable), and Embedded Weaviate (Python/JS/TS), with optional high availability and zero-downtime updates.

- **AI-native ecosystem**: Includes managed services like Query Agent (agentic search), Weaviate Embeddings (inference), and integrations with third-party model providers, alongside tools for AI-assisted coding (Vibe coding) and persistent memory (Engram).
