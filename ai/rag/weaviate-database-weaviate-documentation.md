# Weaviate Database | Weaviate Documentation

## Summary

- **Open-source vector database**: Weaviate stores both data objects and their vector embeddings, enabling semantic search, hybrid search, and retrieval-augmented generation (RAG) workflows by comparing vector similarity rather than keyword matching.

- **Multi-deployment options**: Supports evaluation, development, and production deployments via Weaviate Cloud (managed), Docker (local), Kubernetes (scalable), and Embedded (Python/JS/TS) modes with optional high availability and zero-downtime updates.

- **Ecosystem integration**: Includes Weaviate Cloud, Query Agent, managed embeddings, external model providers, and AI-assisted coding tools (e.g., MCP server) for building cloud-native AI-powered applications.
