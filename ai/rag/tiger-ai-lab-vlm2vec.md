# TIGER-AI-Lab/VLM2Vec

## Summary

- **Repository Contents**: Hosts code for three research works: *VLM2Vec / MMEB* (ICLR 2025), *VLM2Vec-V2 / MMEB-V2* (TMLR 2026), and *MMEB-V3* (COLM 2026), focusing on multimodal embedding benchmarks and contrastive learning.

- **Technical Scope**: Implements frameworks for **visual-language model (VLM) embeddings**, supporting tasks like **image retrieval**, **video retrieval**, and **visual document retrieval**, with contrastive learning and representation learning methodologies.

- **Benchmark Suite**: Provides **MMEB (Multimodal Embedding Benchmark)**, including **MMEB-V2** and **MMEB-V3**, for evaluating VLMs across multimodal retrieval and embedding tasks.
