# TIGER-AI-Lab/VLM2Vec

## Summary

- **Multi-modal Benchmark Suite (MMEB)**: Repository hosts three benchmark frameworks—VLM2Vec (ICLR 2025), VLM2Vec-V2 (TMLR 2026), and MMEB-V3 (COLM 2026)—for evaluating Vision-Language Models (VLMs) across tasks like image retrieval, video retrieval, and visual document retrieval.

- **Contrastive Learning & Embeddings**: Implements contrastive learning techniques to generate high-dimensional embeddings for multi-modal data, enabling efficient retrieval and representation learning in RAG (Retrieval-Augmented Generation) pipelines.

- **Python-Based Toolkit**: Provides a modular Python codebase with tools for benchmarking VLMs, supporting multimodal tasks including visual document retrieval and cross-modal alignment.
