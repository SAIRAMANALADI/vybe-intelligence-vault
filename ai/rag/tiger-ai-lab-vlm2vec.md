# TIGER-AI-Lab/VLM2Vec

## Summary

- **Multi-Version VLM Embedding Benchmarks**: Hosts three evolving benchmarks—VLM2Vec/MMEB (ICLR 2025), VLM2Vec-V2/MMEB-V2 (TMLR 2026), and MMEB-V3 (COLM 2026)—for evaluating Vision-Language Model (VLM) embeddings across tasks like image/video/document retrieval and multimodal representation learning.

- **Contrastive Learning Framework**: Implements contrastive learning techniques to generate high-quality multimodal embeddings, enabling zero-shot and fine-tuned evaluation across diverse retrieval and RAG (Retrieval-Augmented Generation) tasks.

- **Python-Based Toolkit**: Provides a modular Python repository with tools for embedding generation, benchmarking, and evaluation, supporting multimodal tasks including visual document retrieval and cross-modal alignment.
