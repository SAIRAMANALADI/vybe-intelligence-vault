# TIGER-AI-Lab/VLM2Vec

## Summary

- **Multi-modal Benchmarking Suite**: Repository hosts code for VLM2Vec (ICLR 2025), VLM2Vec-V2 (TMLR 2026), and MMEB-V3 (COLM 2026), providing benchmarks (MMEB, MMEB-V2, MMEB-V3) for evaluating Vision-Language Model (VLM) embeddings across tasks like image/video/document retrieval and multimodal RAG.

- **Contrastive Learning Framework**: Implements contrastive learning for training VLMs to generate high-quality embeddings, supporting tasks such as visual, video, and document retrieval, with a focus on representation learning for multimodal data.

- **Python-Based Toolkit**: Repository is implemented in Python, offering modular code for benchmarking, embedding generation, and evaluation, with dependencies and updates managed for reproducibility (last updated 2026-08-05).
