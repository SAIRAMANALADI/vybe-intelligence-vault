# TIGER-AI-Lab/VLM2Vec

## Summary

- **Benchmark Suite**: Provides implementations and benchmarks for VLM2Vec (ICLR 2025), VLM2Vec-V2 (TMLR 2026), and MMEB-V3 (COLM 2026), focusing on multimodal representation learning and evaluation across tasks like image/video/document retrieval and RAG.

- **Technical Focus**: Implements contrastive learning and embedding models for multimodal tasks, including visual-language models (VLMs) optimized for zero-shot and fine-tuned evaluation frameworks.

- **Codebase**: Python-based repository with tools for benchmarking multimodal embeddings (MMEB), supporting tasks like image retrieval, video retrieval, and visual document retrieval.
