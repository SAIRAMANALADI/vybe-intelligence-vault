# HKUDS/AnyGraph

## Summary

- **Framework Overview**: AnyGraph introduces a **Graph Foundation Model (GFM)** designed for **universal graph learning**, leveraging large-scale pre-training on diverse graph datasets to generalize across tasks (e.g., node classification, link prediction, graph classification) without task-specific fine-tuning.

- **Architectural Innovation**: Implements a **modular graph transformer** with **adaptive graph tokenization**, enabling dynamic handling of heterogeneous graphs (e.g., attributed, dynamic, or multi-modal) via learnable graph-level and node-level embeddings.

- **Scalability & Efficiency**: Optimized for **large-scale graph data** with **distributed training** support, incorporating techniques like **gradient checkpointing** and **mixed-precision training** to reduce memory overhead while maintaining performance.
