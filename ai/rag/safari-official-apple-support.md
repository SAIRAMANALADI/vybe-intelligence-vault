# Safari - Official Apple Support

## Summary

- **Safari Updates & Troubleshooting**: Safari updates are platform-agnostic (Mac, iPhone, iPad, Apple Vision Pro) and require manual installation via system updates; unresolved loading issues may stem from corrupted caches, DNS conflicts, or extension interference, requiring diagnostic steps like resetting network settings or disabling extensions.

- **Privacy & Tracking Mitigation**: Safari enforces Intelligent Tracking Prevention (ITP) to block cross-site tracking, provides a Privacy Report for blocked trackers, and allows granular cookie management (whitelist/blacklist) via `Settings > Safari > Advanced > Website Data` on iOS/macOS.

- **Security Hardening**: Phishing protection is enabled by default, with warnings for suspicious sites; users can enforce stricter security via `Settings > Safari > Advanced > Fraudulent Site Warnings` (iOS) or `Safari > Preferences > Security` (macOS), while clearing browsing data (history, cookies, cache) is configurable via `Settings > Safari > Clear History and Website Data`.
