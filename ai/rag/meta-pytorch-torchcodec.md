# meta-pytorch/torchcodec

## Summary

- **Purpose**: `torchcodec` is a PyTorch library for media decoding and encoding, enabling seamless integration of audio/video processing within PyTorch workflows.
- **Key Features**: Supports efficient media I/O operations with GPU acceleration, leveraging PyTorch's tensor-based computation for end-to-end media pipeline optimization.
- **Installation**: Requires PyTorch (>=2.0) and can be installed via `pip install torchcodec` or built from source for custom configurations.
