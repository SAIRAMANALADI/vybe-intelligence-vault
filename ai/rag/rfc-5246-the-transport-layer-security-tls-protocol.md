# RFC 5246: The Transport Layer Security (TLS) Protocol Version 1.2 | RFC Editor

## Summary

- **TLS 1.2 Specification**: Defines the protocol's version 1.2, replacing TLS 1.1 (RFC 4346), TLS 1.1 extensions (RFC 4366), and AES cipher suites (RFC 3268), with major updates including improved cryptographic hash functions (SHA-256) and enhanced cipher suite negotiation.

- **Handshake & Record Protocols**: Specifies the TLS Record Protocol (Section 6) for payload protection (stream, CBC, AEAD ciphers) and the Handshake Protocol (Section 7) for authentication/key exchange (RSA, Diffie-Hellman, ECDHE), including mandatory cipher suites (e.g., AES-GCM, ChaCha20-Poly1305).

- **Security & Compatibility**: Introduces security enhancements (e.g., explicit IVs, session hash extensions) and backward compatibility mechanisms (e.g., version rollback prevention), while obsoleting SSL 2.0/3.0 and RC4 cipher suites. Updated by 12 RFCs (e.g., RFC 5746, RFC 7465) and later superseded by TLS 1.3 (RFC 8446).
