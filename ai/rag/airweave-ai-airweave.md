# airweave-ai/airweave

## Summary

- **Context Retrieval Layer**: Open-source Python SDK (`airweave-ai/airweave`) designed as a middleware for AI agents to dynamically fetch, index, and retrieve relevant context from enterprise data sources (e.g., databases, APIs, unstructured documents) via semantic search and retrieval-augmented generation (RAG).

- **Enterprise Data Integration**: Supports 100+ data connectors (SQL/NoSQL, cloud storage, SaaS APIs) with pluggable architecture, enabling real-time or batch ingestion of structured/unstructured data for low-latency retrieval during LLM inference.

- **Search & API Layer**: Exposes REST/gRPC APIs for hybrid search (keyword + vector embeddings), caching, and metadata filtering, optimized for high-throughput agent workflows with sub-second response times.
