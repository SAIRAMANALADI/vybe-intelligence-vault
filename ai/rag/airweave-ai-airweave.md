# airweave-ai/airweave

## Summary

- **Open-source context retrieval layer**: Airweave provides a Python-based SDK for AI agents to dynamically fetch and integrate relevant context from enterprise data sources, enhancing retrieval-augmented generation (RAG) workflows.

- **Enterprise data connectors**: Supports integration with structured/unstructured data (SQL, NoSQL, APIs, files) via modular connectors, enabling semantic search and real-time context augmentation for LLMs.

- **API-first design**: Exposes a RESTful API for programmatic context retrieval, optimized for low-latency semantic search and scalable across distributed AI agent infrastructures.
