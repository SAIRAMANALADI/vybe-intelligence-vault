## Summary

- **OAuth Integration Simplification**: Pipes abstracts OAuth flows, token refresh logic, and credential storage, enabling seamless third-party integrations (e.g., GitHub, Slack, Google) without manual OAuth management.
- **Provider Configuration**: Providers are configured via the WorkOS Dashboard, with support for custom OAuth credentials (client ID/secret, scopes, redirect URIs) and a pre-built Pipes Widget for user-facing authorization flows.
- **Access Token Management**: Backend endpoints (`getAccessToken`) retrieve and refresh access tokens on behalf of users, handling scope validation and reauthorization prompts for expired/invalid tokens.
