# [1907.12748] Influence Flowers of Academic Entities

## Summary

- **Visual Metaphor**: Introduces the *Influence Flower*, an ego-centric graph visualizing bidirectional influence between academic entities (e.g., researchers, papers, institutions) using petal-based styling to encode influence strength and directionality.

- **Data & Implementation**: Leverages Microsoft Academic Graph (212M authors, 176M publications, 1.2B citations) to construct an interactive *Influence Map* web app, enabling dynamic queries and temporal comparisons of influence patterns.

- **Applications**: Demonstrates use cases including researcher career trajectories, delayed-recognition papers, institutional interdisciplinarity, and cross-platform influence (e.g., academic vs. Twitter activities) via case studies.
