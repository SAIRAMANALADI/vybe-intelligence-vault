# Cloudflare Developer Docs | Cloudflare Docs

## Summary

- **Serverless Compute & AI**: Cloudflare enables global deployment of serverless functions, full-stack apps, and AI inference via Workers, Containers, Durable Objects, and Workers AI—eliminating server management, cold starts, and GPU provisioning (`npm create cloudflare@latest my-app`, `npx wrangler ai models`).

- **Unified Data & Media Pipelines**: Provides globally distributed SQL (D1), key-value (KV), object storage (R2), and media optimization (Images/Stream) with direct Worker integration, supporting window functions, DISTINCT, and set operations in R2 SQL.

- **Security & Performance Stack**: Integrates WAF, Turnstile, post-quantum tunnels (Cloudflare Tunnel), and CDN acceleration with caching, Brotli compression, and HTTP/3, while offering unified network routing (Mesh) and real-time analytics via Web Analytics.
