# Cloudflare Developer Docs | Cloudflare Docs

## Summary

- **Serverless Compute & Deployment**: Cloudflare enables deployment of serverless functions and full-stack apps via single commands (e.g., `npm create cloudflare@latest my-app`) with no server management, cold starts, or region complexity, leveraging Workers, Containers, Durable Objects, Queues, and Flagship.

- **Unified AI & Database Infrastructure**: Workers AI provides global AI inference with unified model access and billing via Workers AI and AI Gateway; Hyperdrive offers general availability for MySQL connections from Workers, while D1, R2, KV, and Vectorize enable globally distributed SQL, key-value, and vector databases with no connection management overhead.

- **Security & Performance Stack**: Cloudflare’s security suite includes WAF, SSL/TLS, Turnstile (CAPTCHA alternative), Tunnel (post-quantum encrypted tunnels), Access (quantum-safe identity-first access), and Gateway (secure web gateway); performance optimizations feature CDN caching, Brotli compression, HTTP/3, image optimization, and real-time analytics via Web Analytics.
