# How Klarna's AI assistant redefined customer support at scale for 85 million active users

## Summary

- **Multi-agent architecture**: Klarna’s AI assistant leverages LangGraph’s controllable agent framework to dynamically route requests and handle diverse tasks (payments, refunds, escalations), reducing latency by **80%** and operational costs while improving reliability.

- **Context-aware prompt optimization**: Klarna implemented LangSmith’s dynamic prompt tailoring to ensure contextually relevant responses, cutting token costs and latency while enabling meta-prompting for iterative prompt refinement based on user feedback.

- **Test-driven observability & automation**: Using LangSmith, Klarna achieved **70% automation** of repetitive support tasks, improved root-cause identification for rejections, and validated agent performance via step-by-step LLM evaluations, reducing escalations and accelerating query resolution.
