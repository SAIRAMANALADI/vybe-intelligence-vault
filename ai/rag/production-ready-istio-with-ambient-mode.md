# Production-Ready Istio with Ambient Mode

## Summary

- **Ambient Mesh Architecture**: Eliminates sidecars via `ztunnel` for L4 traffic management, enabling mTLS encryption in minutes with zero code changes, while maintaining L4 telemetry and 100% traffic encryption.

- **Scalability & Performance**: Supports 100M pods across 2,000 clusters with <100ms propagation latency, handling 2K pod changes/sec at ~10% CPU usage (control plane deployable on a Raspberry Pi).

- **Cost Efficiency**: Reduces operational costs by 30-50% (e.g., $50/pod/year vs. $500/pod/year for sidecar-based meshes) by eliminating sidecar overhead and enabling zero-app-restart deployments.
