# Glossary

## Summary

- **Hugo Glossary**: Defines core terms like *action* (template execution), *archetype* (content template), *argument* (input to functions/methods), and *array* (fixed-length ordered elements with support for nested structures).

- **Page Bundles & Context**: *Branch bundles* (top-level directories with `_index.md`) and *leaf bundles* (content directories with associated resources) structure content; *context* (`.`) in templates refers to the current data structure during iteration or execution.

- **Build & Deployment**: *Build* generates static files (HTML, assets) in `public/`; *CI/CD* automates deployment (e.g., GitHub Pages, Netlify); *environment* modes (`development`/`production`) control asset handling and template logic.
