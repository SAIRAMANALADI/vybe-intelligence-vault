# Dear PyGui’s Documentation — Dear PyGui documentation

## Summary

- **GPU-Accelerated GUI Framework**: Dear PyGui (DPG) is a dynamic, cross-platform GUI toolkit leveraging GPU acceleration via Dear ImGui, supporting traditional elements (buttons, menus) and advanced features like dynamic plots, tables, and drawings.

- **Modular Architecture**: DPG employs a tag-based item system for creation/configuration, supports container hierarchies (stacks, slots), and provides callback/event handling for interactive interfaces.

- **Extensive Tooling**: Includes specialized modules (node editor, debugger, file selectors), rendering APIs, theming, and live demos (`show_demo`) for rapid prototyping and complex UI development.
