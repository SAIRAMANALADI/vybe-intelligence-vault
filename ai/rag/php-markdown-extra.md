# PHP Markdown Extra

## Summary

- **Extended HTML Support**: Markdown Extra relaxes Markdown's strict block-level HTML separation rules, allowing indented block elements (up to 3 spaces) and proper Markdown formatting inside HTML blocks via the `markdown="1"` or `markdown="block"` attribute.

- **Fenced Code Blocks & Special Attributes**: Introduces tilde (`~`) or backtick (`` ` ``) delimited code blocks for non-indented syntax highlighting, with support for language classes (e.g., `.html`) and custom attributes via `{#id .class}` syntax on headers, links, and images.

- **Structured Data Features**: Adds tables (with alignment via colons), definition lists (multi-term/definition support), and footnotes (with block-level content and back-references), extending Markdown beyond basic text formatting.
