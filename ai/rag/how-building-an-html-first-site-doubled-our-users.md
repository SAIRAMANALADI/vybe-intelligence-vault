# How building an HTML-first site doubled our users overnight

## Summary

- **HTML-first progressive enhancement**: Built an Astro-based form with minimal JavaScript (via web components) ensuring functionality without JS, prioritizing accessibility (WCAG AA) and compatibility with outdated browsers/poor connections.

- **Backend-driven form state**: Each form step was a separate page with server-side validation and storage (including file uploads), enabling resumable sessions and preventing data loss even after a month.

- **Lightweight validation system**: Developed a 1KB HTML web component (`validation-enhancer`) that enhances native browser validation with ARIA support, falling back gracefully to default validation or backend checks.
