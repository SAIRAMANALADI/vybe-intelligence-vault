# cockroachdb/cockroach

## Summary

- **Cloud-native distributed SQL database**: CockroachDB is a distributed SQL database built for high availability, horizontal scalability, and precise data placement control, leveraging a shared-nothing architecture.

- **Go-based implementation**: The core database engine and tooling are implemented in Go, ensuring performance, concurrency support, and cross-platform compatibility.

- **ACID-compliant with Raft consensus**: Provides strong consistency via Raft-based replication, supporting multi-region deployments and automatic failover while maintaining SQL compatibility.
