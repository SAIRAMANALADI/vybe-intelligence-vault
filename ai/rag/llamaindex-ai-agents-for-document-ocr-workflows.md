# LlamaIndex | AI Agents for Document OCR + Workflows

## Summary

- **Agentic OCR Pipeline**: LlamaParse employs Vision-Language Model (VLM)-powered agents for layout-aware document parsing, featuring task-specific experts (e.g., text, charts, tables), auto-correction loops for error detection/fixing, and semantic understanding to convert complex layouts into LLM-ready structured outputs.

- **Enterprise-Grade Features**: Supports 50+ unstructured file types (including handwritten text, multi-page tables, and embedded images), schema-based LLM extraction, logical document splitting, automated classification, and a high-performance chunking/embedding pipeline optimized for RAG applications with enterprise-grade security (HIPAA/GDPR/SOC2 compliant).

- **Scalability & Deployment Options**: Offers 10,000 free credits/month (~1000 pages), 1B+ documents processed, 99.9% uptime, and flexible deployment (cloud or VPC) with dedicated support/SLAs, enabling multi-step document agents and replacement of legacy IDP systems across industries like finance, healthcare, and manufacturing.
