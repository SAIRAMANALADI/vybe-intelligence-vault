# LlamaIndex | AI Agents for Document OCR + Workflows

## Summary

- **Agentic OCR Pipeline**: LlamaParse employs Vision-Language Model (VLM)-powered agents for layout-aware document parsing, combining semantic understanding, specialized expert routing (text/charts/tables/handwriting), and recursive auto-correction loops to achieve high accuracy on complex, multi-modal documents.

- **Structured Extraction & Deployment**: Supports schema-based structured extraction without training, document classification via natural-language rules, and enterprise-grade chunking/embedding for RAG applications; offers 10,000 free credits/month (~1,000 pages) and scalable cloud/VPC deployment options.

- **Benchmark Performance**: Outperforms proprietary VLM, commercial IDP, and open-source OCR in overall parsing accuracy, particularly excelling in table/chart extraction; supports 50+ unstructured file types, including handwritten notes and embedded images, with 99.9% uptime and enterprise-grade security (HIPAA/GDPR/SOC2 compliant).
