# LlamaIndex | AI Agents for Document OCR + Workflows

## Summary

- **Agentic OCR Pipeline**: LlamaParse employs a Vision-Language Model (VLM)-powered agentic stack for layout-aware document parsing, featuring specialized experts for text, charts, tables, and handwritten content, with auto-correction loops for recursive error detection and correction.

- **Structured Extraction & Benchmark Performance**: Supports schema-based, LLM-powered extraction of structured insights from 50+ unstructured file types (e.g., PDFs, Office docs) and demonstrates superior performance in parsing accuracy, particularly for charts and tables, compared to proprietary VLM and commercial IDP solutions.

- **Enterprise-Grade Features**: Offers 10,000 free credits/month (~1000 pages), 99.9% uptime, HIPAA/GDPR/SOC2 compliance, flexible deployment (cloud or VPC), and dedicated SLAs, enabling scalable, secure document automation for industries like finance, healthcare, and manufacturing.
