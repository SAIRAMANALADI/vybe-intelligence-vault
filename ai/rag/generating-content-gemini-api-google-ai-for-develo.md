# Generating content | Gemini API | Google AI for Developers

## Summary

- **API Availability**: The Interactions API is now generally available, recommended for accessing latest features/models via `POST https://generativelanguage.googleapis.com/v1beta/{model=models/*}:generateContent`.

- **Multi-Modal Generation**: Supports text, vision (images), audio, video, PDF, and code execution via `GenerateContentRequest` with structured `contents[]` and optional `tools[]` (e.g., `Function`, `codeExecution`).

- **Request Configuration**: Allows fine-tuning via `generationConfig`, `safetySettings[]`, `systemInstruction`, and `toolConfig`; supports caching (`cachedContent`) and service tier selection (`serviceTier`).
