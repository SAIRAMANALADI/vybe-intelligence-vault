## Summary

- **Unified RAG Framework**: Provides a Python-based, end-to-end pipeline for enterprise Retrieval-Augmented Generation (RAG) using small, specialized models optimized for efficiency (e.g., ONNX, OpenVINO, llama.cpp).

- **Multi-Model Support**: Integrates diverse inference backends (e.g., Llama, OpenVINO, ONNX Runtime) and supports structured parsing for unstructured data (PDFs, docs, web content) via modular components.

- **Agentic Workflows**: Enables autonomous agent systems with retrieval, reasoning, and tool-use capabilities, leveraging lightweight models for low-latency, scalable deployments in production environments.
