# llmware-ai/llmware

## Summary

- **Unified RAG Framework**: Provides a Python-based framework for building enterprise-grade Retrieval-Augmented Generation (RAG) pipelines using small, specialized models (e.g., ONNX, OpenVINO, llama.cpp) optimized for performance and efficiency.

- **Multi-Model & Tool Integration**: Supports integration with generative AI tools, agents, and lightweight LLMs, enabling modular deployment of parsing, retrieval, and generation components in production environments.

- **Enterprise Optimization**: Focuses on low-latency, high-throughput inference with hardware acceleration (CPU/GPU) and optimized model formats, designed for scalable, cost-effective deployment in enterprise settings.
