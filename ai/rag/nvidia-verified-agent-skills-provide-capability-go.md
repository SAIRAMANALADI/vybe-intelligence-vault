# NVIDIA-Verified Agent Skills Provide Capability Governance for AI Agents | NVIDIA Technical Blog

## Summary

- **NVIDIA-verified agent skills** are portable instruction sets for AI agents, providing transparency, provenance, security scanning, and cryptographic signing via machine-readable **skill cards** detailing ownership, dependencies, limitations, and verification status.

- **Verification pipeline** includes automated/human reviews, risk scanning (via **SkillSpector**), evaluation metrics, cryptographic signing (`skill.oms.sig`), and daily catalog synchronization, ensuring skills meet security and quality standards before deployment.

- **Cryptographic signing** ensures verifiable integrity/authenticity of skills post-download, while **skill cards** centralize trust metadata (e.g., dependencies, risks) for pre-deployment assessment across enterprise and coding environments.
