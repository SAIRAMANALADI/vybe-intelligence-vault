# DataChain | AI Data at Scale - Curate, Enrich, and Version Datasets

## Summary

- **Cost Efficiency**: DataChain reduces AI compute spend by **10,000×** via reusable cached computations (e.g., LLM annotations, embeddings) instead of recomputing from raw files ($0.0001 for summaries vs. $100 for full recompute).

- **Reproducibility & Speed**: Every dataset includes **source code, inputs, author, timestamp, and lineage**, enabling one-line Python reruns of 6-month-old experiments, reducing time-to-result from **weeks to minutes**.

- **Architecture**: Implements a **C·A·S·T** (Container·Asset·Sense·Task) framework over unstructured data (e.g., videos, logs), enabling distributed Python pipelines with **async I/O, checkpoints, and BYOC compute** while keeping raw files in native cloud storage.
