## Summary

- **Autonomous AI Agent Framework**: OpenClaw-inspired system built entirely in n8n, featuring adaptive RAG-powered memory, MCP-based Skills integration, and Expert Agents with delegated sub-agent capabilities for hierarchical task execution.

- **Proactive Task & Media Management**: Supports proactive task scheduling, media understanding, and self-hosted deployment via a single setup script, enabling end-to-end autonomous operation.

- **Tech Stack & Integrations**: Primarily Shell-based, with dependencies on Crawl4AI, SearXNG, Supabase, and MCP templates; designed for modularity and extensibility in AI agent workflows.
