# freddy-schuetz/n8n-claw

## Summary

- **OpenClaw-inspired autonomous AI agent** implemented entirely in **n8n**, leveraging **adaptive RAG-powered memory** for dynamic context retention and retrieval.
- **Multi-agent architecture** with **delegated sub-agents**, **MCP-based Skills templates**, and **proactive task management**, supporting **media understanding** and **self-hosted deployment** via a single setup script.
- **Integrated toolchain** combining **Crawl4AI** for scraping, **SearXNG** for search, and **Supabase** for storage, with **Shell** as the primary scripting language.
