# Firebase Authentication

## Summary

- **Backend Authentication Service**: Firebase Authentication provides backend services, SDKs, and UI libraries for user authentication via passwords, phone numbers, and federated identity providers (Google, Facebook, Twitter, etc.), integrating with Firebase services and industry standards like OAuth 2.0/OpenID Connect.

- **FirebaseUI vs. SDK Integration**: FirebaseUI offers a drop-in auth solution with pre-built UI flows for email/password, phone, and federated sign-ins, while the Firebase Authentication SDK enables manual integration of one or more sign-in methods with custom UI implementation.

- **Identity Platform Upgrade**: Upgrading to Firebase Authentication with Identity Platform unlocks enterprise features (multi-factor auth, SAML/OpenID Connect support, blocking functions, audit logging, multi-tenancy) with tiered usage limits (3,000 DAUs for Spark, 50,000 MAUs free tier for Blaze).
