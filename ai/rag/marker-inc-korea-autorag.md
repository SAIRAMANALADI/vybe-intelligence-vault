# Marker-Inc-Korea/AutoRAG

## Summary

- **AutoML-Driven RAG Optimization**: AutoRAG automates the evaluation and optimization of Retrieval-Augmented Generation (RAG) pipelines using AutoML-style techniques, dynamically selecting and tuning components (e.g., embeddings, retrievers, LLMs) for performance and cost efficiency.

- **Comprehensive RAG Benchmarking**: Provides built-in tools for analyzing and benchmarking RAG systems across metrics like retrieval quality, generation coherence, and end-to-end latency, supporting structured comparisons against custom or public datasets.

- **Modular Python Framework**: Implements a flexible, Python-based pipeline for document parsing, retrieval, and generation, with support for custom modules (e.g., document loaders, vector stores, LLMs) and integration with popular libraries (e.g., LangChain, LlamaIndex).
