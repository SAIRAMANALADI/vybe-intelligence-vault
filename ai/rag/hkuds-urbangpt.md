# HKUDS/UrbanGPT

## Summary

- Introduces **UrbanGPT**, a spatio-temporal Large Language Model (LLM) for urban computing tasks, leveraging instruction-tuning on pre-trained models to handle complex urban data patterns.

- Implements a **multi-modal framework** combining textual, spatial, and temporal data representations to enable zero-shot/few-shot predictions for urban phenomena (e.g., traffic, pollution, demand forecasting).

- Achieves state-of-the-art performance on **urban prediction benchmarks** by integrating domain-specific pre-training with LLM adaptability, optimizing for both accuracy and computational efficiency.
