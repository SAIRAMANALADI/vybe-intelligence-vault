# CSS Text Module Level 4

## Summary

- **Scope & Coverage**: Defines CSS typesetting controls (case transformation, whitespace collapsing, text wrapping, line breaking, hyphenation, alignment, spacing, indentation) replacing CSS2 Chapter 16, with test coverage in `wpt/css/css-text/` and related subdirectories.
- **Module Dependencies**: Depends on CSS Text Decoration Module (Level 3) for text decorations (underlines, emphasis marks, shadows) and CSS Writing Modes Module (Level 4) for bidirectional/vertical text handling.
- **Language Handling**: Requires explicit language tagging (`content-language`) for typographic behavior (line breaking, hyphenation, justification), with unknown languages defaulting to no language-specific tailoring.
