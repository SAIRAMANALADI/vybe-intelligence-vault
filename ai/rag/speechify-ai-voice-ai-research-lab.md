# SpeechifyAI - Voice AI Research Lab

## Summary

- **Simba 3.2 TTS Model**: Streaming-native architecture with sub-100ms latency, outperforming competitors on the [Artificial Analysis TTS leaderboard](https://artificialanalysis.ai/text-to-speech/leaderboard/selected-voice?top-models=true) while remaining cost-effective; features refined emotional control via SSML prosody and a curated multilingual voice set.

- **Zero-Shot Voice Cloning & Emotion Synthesis**: Enables cloning of speaker identity (timbre, cadence, micro-expressions) from ≥10s reference audio; supports granular emotional expression (neutral, happy, sad, etc.) via prosodic modeling, not just pitch/speed adjustments.

- **Multilingual & API Integration**: Native-quality synthesis across 30+ locales with locale-specific voices; single API (`/v1/audio/speech`) supports streaming, voice cloning, and emotion control via minimal code (e.g., `curl` example with JSON payload).
