# SpeechifyAI - Voice AI Research Lab

## Summary

- **Simba 3.2 TTS Model**: Streaming-native architecture achieving <100ms latency, outperforming competitors on [Artificial Analysis TTS leaderboard](https://artificialanalysis.ai/text-to-speech/leaderboard/selected-voice?top-models=true) with fine-grained emotional control (SSML prosody) and curated voice set across expanding languages.

- **Zero-Shot Voice Cloning & Emotion Control**: Clones speaker identity (timbre, cadence, micro-expressions) from ≥10s reference audio; enables nuanced emotional synthesis (neutral, happy, sad, excited, calm) via prosody-level modeling, not just pitch/speed adjustments.

- **Multilingual & API Integration**: Supports 30+ locales with native-quality voices, handles mixed-language input; single API (`/v1/audio/speech`) provides streaming, voice cloning, and emotion control via minimal code (e.g., `curl` example).
