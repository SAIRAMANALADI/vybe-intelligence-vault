# SpeechifyAI - Voice AI Research Lab

## Summary

- **Simba 3.2 TTS Model**: Streaming-native architecture with sub-100ms latency, outperforming competitors on the [Artificial Analysis TTS leaderboard](https://artificialanalysis.ai/text-to-speech/leaderboard/selected-voice?top-models=true) at lower cost; features fine-grained emotional control (neutral, happy, sad, excited, calm) via SSML prosody and curated voice sets.

- **Zero-Shot Voice Cloning & Multilingual Synthesis**: Clones speaker identity (timbre, cadence, micro-expressions) from ≥10s reference audio; supports native-quality speech synthesis across 30+ locales with locale-specific voices and automatic mixed-language input handling.

- **Unified API Integration**: Single API endpoint (`/v1/audio/speech`) for streaming, voice cloning, and emotion control; example curl command demonstrates minimal-code implementation with support for custom voices (`voice_id`) and audio formats (e.g., MP3).
