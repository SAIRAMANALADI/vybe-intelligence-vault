# Keras: Deep Learning for humans

## Summary

- **Multi-backend compatibility**: Keras 3 enables cross-framework execution on JAX, TensorFlow, PyTorch, or OpenVINO (inference-only), allowing dynamic backend selection for optimal performance without code changes, while maintaining full API parity across backends.

- **Unified `keras.ops` namespace**: Provides a framework-agnostic API for NumPy-like operations and neural network-specific functions (e.g., `ops.softmax`, `ops.conv`), enabling single-codebase custom layers, models, and metrics that work seamlessly across JAX, TensorFlow, and PyTorch.

- **Stateless API and distribution support**: Introduces stateless methods (`stateless_call`, `stateless_apply`) for functional programming compatibility with JAX, and a new `keras.distribution` API (JAX-first) for scalable model/data parallelism, decoupling model definition from sharding configurations.
