# Keras: Deep Learning for humans

## Summary

- **Multi-Backend Architecture**: Keras 3 supports JAX, TensorFlow, and PyTorch, enabling seamless model portability and leveraging backend-specific optimizations while maintaining a unified API.
- **Functional & Subclassing APIs**: Provides both high-level functional API for rapid prototyping (e.g., `keras.Model`, `layers`) and low-level subclassing for custom layer/model implementation (e.g., `Layer.call()`).
- **KerasHub Integration**: Offers pre-trained models (Gemma, Llama3, Stable Diffusion 3) with multi-backend support, enabling inference/training across JAX, TensorFlow, and PyTorch via a unified interface.
