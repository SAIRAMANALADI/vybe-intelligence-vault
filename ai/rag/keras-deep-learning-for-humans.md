# Keras: Deep Learning for humans

## Summary

- **Multi-Backend Architecture**: Keras 3.0 enables cross-framework compatibility with JAX, TensorFlow, PyTorch, and OpenVINO (inference-only), allowing seamless switching between backends without code changes while optimizing performance dynamically.

- **Unified API & Stateless Components**: Introduces a stateless API (`stateless_call()`, `stateless_apply()`, etc.) for layers, models, metrics, and optimizers, enabling functional programming and JAX integration, while maintaining full Keras API support across all backends.

- **Advanced Distribution & Data Pipeline Support**: Features a new `keras.distribution` API for large-scale model/data parallelism (JAX-first, with TensorFlow/PyTorch support planned) and supports heterogeneous data pipelines (`tf.data.Dataset`, PyTorch `DataLoader`, NumPy/Pandas) across all backends.
