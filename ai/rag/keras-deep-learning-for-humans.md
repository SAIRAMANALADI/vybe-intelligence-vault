# Keras: Deep Learning for humans

## Summary

- **Multi-Backend Support**: Keras 3 enables cross-framework compatibility with JAX, TensorFlow, PyTorch, and OpenVINO (inference-only), allowing dynamic backend selection for optimal performance without code changes.

- **Unified API & Stateless Operations**: Implements a full Keras API across backends with stateless methods (`stateless_call()`, `stateless_apply()`) for functional programming, ensuring consistent numerics and seamless integration with low-level workflows.

- **Advanced Distribution & Pretrained Models**: Introduces a new `keras.distribution` API for model/data parallelism (JAX-first, TensorFlow/PyTorch support pending) and supports 40+ pretrained models (e.g., BERT, StableDiffusion) via KerasCV/Hub across all backends.
