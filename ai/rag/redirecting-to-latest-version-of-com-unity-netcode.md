# Redirecting to latest version of com.unity.netcode

## Summary

- **Netcode for GameObjects (NGO) v6.6**: Unity's high-level networking solution for multiplayer games, built on top of the Transport Layer (com.unity.transport), enabling client-server and peer-to-peer architectures with deterministic or rollback netcode.

- **Key Features**:
  - **NetworkObject & NetworkBehaviour**: Core components for synchronizing game state across clients.
  - **Client-Side Prediction & Lag Compensation**: Mitigates latency issues via client-side simulation and server reconciliation.
  - **RPC (Remote Procedure Calls)**: Supports synchronous and asynchronous method invocation across networked entities.

- **Performance Optimizations**:
  - **Delta Compression**: Reduces bandwidth by transmitting only changed state.
  - **Network Profiler**: Integrated tooling for latency, packet loss, and bandwidth analysis.
  - **Burst & Jobs System Integration**: Leverages Unity's DOTS for efficient ECS-based networking.
