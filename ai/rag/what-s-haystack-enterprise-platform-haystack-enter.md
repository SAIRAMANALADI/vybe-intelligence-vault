# What's Haystack Enterprise Platform? | Haystack Enterprise Platform Documentation

## Summary

- **Data Processing Pipeline**: Supports automated ingestion, OCR, and preprocessing of multi-format documents (PDFs, Office, images) via built-in converters and preprocessors, with configurable indexing for chunking and storage in a document store for retrieval.

- **Modular AI Agent & RAG Framework**: Enables construction of multi-component pipelines (retrievers, rankers, generators) for AI agents and advanced RAG systems, with visual Pipeline Builder for dynamic component/model swapping and enterprise-grade tool integration.

- **Observability & Deployment**: Provides model-agnostic LLM/embedding provider integration, observability via Langfuse/Weave, REST API for lifecycle management, and built-in monitoring dashboards for performance tracking and user behavior analytics.
