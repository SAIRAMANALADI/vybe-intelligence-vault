# What's Haystack Enterprise Platform? | Haystack Enterprise Platform Documentation

## Summary

- **Data Ingestion & Indexing**: Supports automated conversion/OCR for multi-format files (PDFs, Office, images) into searchable, chunked content stored in document stores for fast retrieval via configurable indexes.

- **Modular AI Pipeline Construction**: Enables drag-and-drop assembly of RAG pipelines and AI agents using interchangeable components (retrievers, rankers, generators) with model-agnostic LLM/embedding provider integration and real-time switching for performance optimization.

- **End-to-End Lifecycle Management**: Provides REST API for automation, built-in monitoring/logs, third-party observability integrations (Langfuse, Weave), and prototype sharing with feedback collection before production deployment.
