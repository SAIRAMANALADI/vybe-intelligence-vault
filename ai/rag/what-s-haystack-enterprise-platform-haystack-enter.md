# What's Haystack Enterprise Platform? | Haystack Enterprise Platform Documentation

## Summary

- **Data Processing Pipeline**: Supports automated ingestion, OCR, and preprocessing of diverse file formats (PDFs, Office docs, images) via built-in converters, transforming raw data into structured, searchable content stored in optimized document stores for retrieval.

- **Modular AI Agent & RAG Framework**: Enables construction of multi-component pipelines (retrievers, rankers, generators) with visual Pipeline Builder, supporting both enterprise-grade agents (multi-step reasoning/tools) and advanced RAG systems grounded in proprietary documents.

- **Model-Agnostic Observability & Deployment**: Integrates with third-party LLMs/embeddings, tracing tools (Langfuse, Weights & Biases), and REST APIs for lifecycle management, allowing A/B testing, performance monitoring, and prototype sharing via branded links before production deployment.
