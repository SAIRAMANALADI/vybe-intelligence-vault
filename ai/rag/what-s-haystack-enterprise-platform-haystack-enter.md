# What's Haystack Enterprise Platform? | Haystack Enterprise Platform Documentation

## Summary

- **Unified AI Development & Deployment**: Haystack Enterprise Platform supports end-to-end lifecycle management for AI applications, from prototyping to production-scale deployment, with integrated data processing, model selection, evaluation, and monitoring.

- **Modular RAG & Agentic Pipelines**: Enables construction of advanced retrieval-augmented generation (RAG) systems and AI agents via configurable pipelines (retrievers, rankers, generators) with visual Pipeline Builder and dynamic model/component switching.

- **Observability & API-Driven Control**: Provides model-agnostic integration with multiple LLM/embedding providers, observability tools (Langfuse, Weights & Biases), REST API for automation, and built-in performance dashboards/logs for full pipeline visibility.
