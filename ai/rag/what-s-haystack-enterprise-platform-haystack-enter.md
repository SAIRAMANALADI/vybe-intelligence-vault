# What's Haystack Enterprise Platform? | Haystack Enterprise Platform Documentation

## Summary

- **Data Ingestion & Indexing**: Supports automated conversion and preprocessing of diverse file formats (PDFs, Office docs, images) via built-in OCR and document conversion tools, storing cleaned, chunked data in optimized document stores for fast retrieval.

- **Modular AI Pipeline Construction**: Enables drag-and-drop assembly of RAG pipelines and AI agents using interchangeable components (retrievers, rankers, generators) with model-agnostic LLM/embedding provider integration and real-time switching for performance tuning.

- **Enterprise-Grade Observability & Deployment**: Provides REST API for programmatic control, built-in performance dashboards/logs, third-party tracing integrations (Langfuse, Weights & Biases), and prototype sharing with branded feedback collection before production deployment.
