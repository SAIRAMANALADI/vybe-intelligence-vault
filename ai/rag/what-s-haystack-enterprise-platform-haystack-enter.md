# What's Haystack Enterprise Platform? | Haystack Enterprise Platform Documentation

## Summary

- **Data Processing & Indexing**: Supports automated ingestion, OCR, and preprocessing for diverse file formats (PDFs, Office docs, images) via built-in converters, enabling chunked, searchable content storage in document stores for efficient retrieval.

- **Modular AI Pipeline Construction**: Enables drag-and-drop assembly of RAG pipelines and AI agents using interchangeable components (retrievers, rankers, generators) with model-agnostic LLM/embedding provider integration for iterative optimization.

- **Enterprise-Grade Observability & Deployment**: Offers REST API-driven automation, prototype sharing with branding, and integrations with Langfuse/Weave for tracing/debugging, alongside built-in logs and performance dashboards for full lifecycle monitoring.
