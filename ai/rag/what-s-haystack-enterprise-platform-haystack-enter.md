# What's Haystack Enterprise Platform? | Haystack Enterprise Platform Documentation

## Summary

- **Unified AI Application Lifecycle Management**: Haystack Enterprise Platform supports end-to-end development, from prototyping to large-scale production deployment, with tools for data ingestion, model selection, evaluation, and monitoring.

- **Modular RAG & Agent Pipelines**: Enables construction of advanced retrieval-augmented generation (RAG) systems and AI agents using configurable components (retrievers, rankers, generators) with support for multi-step reasoning and tool integration.

- **Model-Agnostic Observability & Deployment**: Supports seamless switching between LLM/embedding providers, integrates with observability tools (e.g., Langfuse, Weights & Biases), and offers REST API-driven deployment with built-in logging and performance dashboards.
