# prometheus-eval/BiGGen-Bench at main · prometheus-eval/prometheus-eval · GitHub

## Summary

- **Benchmark Scope**: BiGGen-Bench evaluates LLMs across **9 capabilities** with **77 tasks** and **765 unique instances**, using a **1-5 scoring rubric** tailored to task-specific criteria for nuanced performance assessment.

- **Architecture & Workflow**: Supports **three inference modes** (API, base, chat) via scripts (`run_api_inference.py`, `run_base_inference.py`, `run_chat_inference.py`) and evaluates responses using `prometheus-eval` models, with results compiled via `run_response_eval.py` and `make_table.py`.

- **Customization & Deployment**: Enables **parameter tuning** (e.g., `tensor_parallel_size`, `quantization`) and **capability filtering** (e.g., reasoning, multilingual) via modular scripts, with all resources (code, data, models) publicly available on Hugging Face.
