# Snowflake Documentation

## Summary

- **Multi-cloud, multi-region architecture**: Snowflake operates as a **true SaaS cloud data platform** with **separate compute/storage layers**, supporting **AWS, Azure, and GCP** with **zero-copy cloning, Time Travel (up to 90 days), and failover/failback** across regions.

- **Declarative Sharing & Native Apps**: **Declarative Sharing (preview)** enables **provider-consumer data product monetization** via the **Snowflake Native App Framework**, integrating **notebooks for data visualization** and **release channels** for versioned deployments.

- **Streaming & Iceberg Integration**: **Snowpipe Streaming (preview)** introduces **throughput-based pricing** with **optimized performance**; **Apache Iceberg™ table support** extends **Search Optimization & Query Acceleration Services**, while **triggered tasks** now handle **streams on directory tables/data shares**.
