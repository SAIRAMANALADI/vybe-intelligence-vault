# Four features of the Assistant API you aren't using - but should | Pinecone

## Summary

- **Chat API with Structured Citations**: Enables real-time or batched streaming of chat responses with structured citations containing metadata (file names, URLs, timestamps, page numbers) for customizable display (e.g., footnotes, sidebars) while maintaining privacy via selective citation inclusion.

- **Custom Instructions for Role-Based Responses**: Allows dynamic tailoring of assistant behavior (e.g., legal expert, customer support) via system prompts, enforcing tone, content focus, compliance policies, and response formatting for domain-specific use cases.

- **Metadata Filtering for Scoped Retrieval**: Supports fine-grained filtering of ingested files using metadata (e.g., date ranges, author, access levels) to restrict retrieval scope, enabling role-based access control and categorical/boolean/numerical range filtering for precise data access.
