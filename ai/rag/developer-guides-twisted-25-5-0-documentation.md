# Developer Guides — Twisted 25.5.0 documentation

## Summary

- **Event-driven networking framework**: Twisted provides a non-blocking I/O system with a reactor pattern for handling asynchronous events, supporting protocols like TCP, UDP, SSL, and process management via `twisted.internet`.

- **Deferred-based concurrency**: Uses `Deferred` objects for managing callbacks/promises, enabling efficient asynchronous programming with thread integration (`twisted.internet.threads`) and scheduling (`twisted.internet.task`).

- **Pluggable architecture**: Features a component system (`twisted.python.components`), authentication framework (`twisted.cred`), and plugin system (`twisted.plugin`) for modular, reusable, and extensible application design.
