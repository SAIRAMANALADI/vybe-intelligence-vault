# Fast and reliable end-to-end testing for modern web apps | Playwright

## Summary

- **Playwright Test**: Full-featured test runner supporting auto-waiting, assertions, tracing, and parallel execution across Chromium, Firefox, and WebKit with zero flakiness via web-first assertions and resilient locators (`getByRole`, `getByLabel`, etc.).

- **Playwright MCP**: MCP server providing AI agents structured accessibility snapshots (roles, names, refs) for deterministic browser interaction, enabling full control via standard tool calls in VS Code, Cursor, and other MCP clients.

- **Playwright CLI**: Token-efficient CLI designed for coding agents (e.g., Claude Code, GitHub Copilot) with installable skills, session monitoring dashboards, and cross-browser automation without large context overhead.
