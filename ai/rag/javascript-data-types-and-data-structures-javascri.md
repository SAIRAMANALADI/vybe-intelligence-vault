# JavaScript data types and data structures - JavaScript | MDN

## Summary

- **Dynamic & Weak Typing**: JavaScript is dynamically and weakly typed; variables can hold any type and implicit type coercion occurs during operations (e.g., `42 + "1"` → `"421"`), though certain conversions (e.g., `Symbol`, `BigInt`) are restricted.

- **Primitive Types**: JavaScript has 7 primitive types (`null`, `undefined`, `boolean`, `number`, `bigint`, `string`, `symbol`), all immutable except `Object`; `typeof null` incorrectly returns `"object"`, requiring explicit `null` checks.

- **Number Representation**: Numbers are 64-bit IEEE 754 doubles with safe integer range `-(2^53 - 1)` to `2^53 - 1`; `NaN` is the only value not equal to itself, and `BigInt` supports arbitrary-precision integers (e.g., `9007199254740991n`).
