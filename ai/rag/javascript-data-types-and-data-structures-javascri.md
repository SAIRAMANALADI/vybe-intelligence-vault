# JavaScript data types and data structures - JavaScript | MDN

## Summary

- JavaScript employs **dynamic and weak typing**, enabling variable type reassignment and implicit type coercion (e.g., `42 + "1" → "421"`), though conversions involving `Symbol` and `BigInt` are restricted.
- **Primitive values** (`null`, `undefined`, `Boolean`, `Number`, `BigInt`, `String`, `Symbol`) are immutable, with `typeof null` erroneously returning `"object"`; wrapper objects (e.g., `Number`, `String`) provide methods but auto-wrap primitives on property access.
- **Number type** is a 64-bit IEEE 754 double-precision format with safe integer range `-(2^53 - 1)` to `2^53 - 1`; `NaN` is the only value unequal to itself, and `BigInt` extends integer precision beyond `Number.MAX_SAFE_INTEGER`.
