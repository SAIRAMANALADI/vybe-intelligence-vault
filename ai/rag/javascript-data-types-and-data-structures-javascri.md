# JavaScript data types and data structures - JavaScript | MDN

## Summary

- JavaScript is a **dynamically and weakly typed** language, allowing variables to hold any type and performing **implicit type coercion** (e.g., `42 + "1"` → `"421"`), though certain conversions (e.g., `Symbol`/`BigInt`) are restricted.

- **Primitive values** (immutable, except `Object`) include `null`, `undefined`, `Boolean`, `Number`, `BigInt`, `String`, and `Symbol`; `typeof null` incorrectly returns `"object"`, requiring explicit checks (`=== null`).

- **Number type** is a 64-bit IEEE 754 double-precision float with safe integer range `-(2^53 - 1)` to `2^53 - 1`; `NaN` is the only value unequal to itself, and bitwise ops convert numbers to 32-bit integers. **BigInt** extends integer precision beyond `Number.MAX_SAFE_INTEGER`.
