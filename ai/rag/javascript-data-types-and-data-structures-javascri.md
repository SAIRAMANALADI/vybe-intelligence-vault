# JavaScript data types and data structures - JavaScript | MDN

## Summary

- **Dynamic & Weak Typing**: JavaScript uses dynamic typing (variables can hold any type) and weak typing (implicit type coercion during operations), enabling flexible but potentially error-prone type handling (e.g., `42 + "1"` → `"421"`).

- **Primitive Types**: JavaScript has 7 primitive types (`null`, `undefined`, `boolean`, `number`, `bigint`, `string`, `symbol`), all immutable except `Object`; `typeof null` incorrectly returns `"object"`, requiring explicit `null` checks.

- **Number Representation**: Numbers are IEEE 754 double-precision floats with safe integer range `-(2^53-1)` to `2^53-1`; `NaN` is the only value not equal to itself, and `BigInt` extends integer precision beyond `Number.MAX_SAFE_INTEGER`.
