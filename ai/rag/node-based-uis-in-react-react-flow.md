# Node-Based UIs in React - React Flow

## Summary

- **Core Features**: React Flow is an MIT-licensed, open-source React library (`@xyflow/react`) for building interactive node-based editors/diagrams with built-in support for dragging, zooming, panning, multi-selection, and dynamic node/edge manipulation.

- **Customization & Integration**: Nodes are React components with Tailwind/CSS compatibility; advanced UI elements include Background, Minimap, Controls, Panel, NodeToolbar, and NodeResizer for enhanced interactivity.

- **Adoption & Ecosystem**: Used by companies like Stripe, Zapier, and Typeform for applications ranging from ML tools to survey logic; maintained by xyflow, with frequent updates (e.g., v12.11.1) and complementary libraries like Svelte Flow.
