# Docusaurus 3.10 | Docusaurus

## Summary

- **Docusaurus 3.10** is the final v3.x release, introducing **v4 future flags** (`future.v4.*`) to incrementally adopt breaking changes like `siteStorageNamespacing`, `fasterByDefault`, and `mdx1CompatDisabledByDefault`.

- **Security enhancements** include **npm Trusted Publishing** for verifiable releases, a **daily security workflow** scanning for malicious dependencies, and **pnpm config recommendations** (`blockExoticSubdeps`, `strictDepBuilds`, `minimumReleaseAge`) to mitigate supply chain risks.

- **Performance/strictness updates**: **Docusaurus Faster** (now stable) enables Rspack/SWC optimizations; **strict MDX** enforces native syntax (e.g., `:::type[Title]` over `:::type Title`), and **VCS API** experimental support improves Git history handling via `gitEagerVcs` for large sites.
