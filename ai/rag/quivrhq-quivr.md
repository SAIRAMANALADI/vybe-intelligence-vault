# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: QuivrHQ/quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed to simplify GenAI integration into applications, supporting any LLM (e.g., GPT4, Groq, Llama) and vector stores (e.g., PGVector, Faiss), with customizable pipelines for diverse data formats and workflows.

- **Multi-Platform Compatibility**: The framework offers flexible deployment options, including Docker support, and integrates seamlessly with existing products via APIs, supporting Python (backend) and TypeScript/JavaScript (frontend with React) for full-stack development.

- **Privacy & Security Focus**: Prioritizes data privacy and security, enabling private deployments with PostgreSQL, and supports open-source alternatives to proprietary models, ensuring compliance and control over sensitive information.
