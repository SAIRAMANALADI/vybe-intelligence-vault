# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: QuivrHQ/quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, abstracting RAG complexities while enabling customization for LLMs (e.g., GPT4, Groq, Llama) and vector stores (e.g., PGVector, Faiss).

- **Multi-Platform Compatibility**: Supports any file type, integrates with Docker, and offers flexible deployment options (Python backend, React/TypeScript frontend) with APIs for OpenAI/Groq/Llama models and PostgreSQL for storage.

- **Privacy & Security Focus**: Prioritizes data privacy with configurable security measures, supports local LLM deployment, and includes built-in Dockerized setup for isolated, scalable GenAI workflows.
