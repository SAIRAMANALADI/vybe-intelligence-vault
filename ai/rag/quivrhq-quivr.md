# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: Quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, supporting customization for LLM (e.g., GPT4, Groq, Llama) and vector stores (e.g., PGVector, Faiss) with minimal setup overhead.

- **Multi-Format & Multi-Platform Support**: Enables integration with any file type, offers flexible deployment via Docker, and provides both frontend (React/TypeScript) and backend (Python) components, ensuring compatibility with diverse tech stacks.

- **Privacy & Security Focus**: Prioritizes data privacy with PostgreSQL support, secure API handling, and customizable security configurations, while offering a lightweight, scalable architecture for production-grade applications.
