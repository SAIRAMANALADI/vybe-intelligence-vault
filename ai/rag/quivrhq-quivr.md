# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: QuivrHQ/quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration in applications, supporting customization across LLMs (e.g., GPT4, Groq, Llama), vector stores (e.g., PGVector, Faiss), and file types.

- **Multi-Platform Compatibility**: Built in Python with frontend support for React/TypeScript, it offers Docker deployment, RESTful API access, and compatibility with databases (PostgreSQL) and vector stores, enabling flexible integration into existing products.

- **Privacy & Security Focus**: Emphasizes data privacy and security, supporting local LLM deployment and customizable workflows while providing tools for building chatbots, APIs, and frontend interfaces with minimal RAG overhead.
