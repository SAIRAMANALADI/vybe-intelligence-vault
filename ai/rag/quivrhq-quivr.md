# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: QuivrHQ/quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, supporting any LLM (e.g., GPT4, Groq, Llama) and vector stores (e.g., PGVector, Faiss), with customizable pipelines for diverse file types and workflows.

- **Multi-Backend Compatibility**: Provides flexible backend support for LLMs (OpenAI, Groq, etc.) and vector databases (PostgreSQL/PGVector, Faiss), enabling deployment across varied infrastructures while prioritizing privacy and security.

- **Full-Stack Integration**: Offers a React-based frontend, Dockerized deployment, and RESTful API, with TypeScript/JavaScript support for frontend customization, ensuring easy integration into existing products.
