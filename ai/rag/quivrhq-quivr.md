# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: QuivrHQ/quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, abstracting RAG complexities while enabling customization for diverse use cases.

- **Multi-LLM & Vectorstore Support**: Compatible with any LLM (e.g., GPT4, Groq, Llama) and vector databases (e.g., PGVector, Faiss), supporting flexible file ingestion and storage configurations.

- **Full-Stack Deployment**: Python-based backend with React frontend, Dockerized for deployment, and supports integration with PostgreSQL, security, and privacy features for scalable, production-ready GenAI applications.
