# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: QuivrHQ/quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, supporting customization for LLM (e.g., GPT4, Groq, Llama) and vector stores (e.g., PGVector, Faiss) with flexible file ingestion.

- **Multi-Platform Compatibility**: The project supports any LLM backend, vector database, and file types, with easy integration into existing products via API, Docker, and frontend components (React, TypeScript, HTML/JavaScript).

- **Privacy & Security Focus**: Built with PostgreSQL for data persistence, emphasizing privacy and security while offering modular deployment options for scalable, production-ready GenAI applications.
