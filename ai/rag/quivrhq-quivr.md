# QuivrHQ/quivr

## Summary

- **Modular RAG Framework**: QuivrHQ/quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, supporting customization for any LLM (e.g., GPT4, Groq, Llama) and vector store (e.g., PGVector, Faiss), with support for arbitrary file types.

- **Multi-Backend Compatibility**: The framework provides flexible integration options, including APIs, Docker, and frontend components (React/TypeScript), while ensuring compatibility with major LLMs (OpenAI, Groq) and databases (PostgreSQL).

- **Privacy & Security Focus**: Emphasizes data privacy and security, enabling self-hosted deployments with customizable configurations for sensitive use cases.
