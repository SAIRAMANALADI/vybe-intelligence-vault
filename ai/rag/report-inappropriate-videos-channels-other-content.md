# Report inappropriate videos, channels & other content on YouTube - Computer - YouTube Help

## Summary

- Reported YouTube content undergoes manual review per [Community Guidelines](https://youtube.com/t/community_guidelines), with violations removed or age-restricted; non-violative content remains unaffected regardless of report volume.
- Reporting workflows vary by content type (videos, Shorts, channels, comments, Community Posts, live chat, ads), but all follow structured submission via UI flags with optional detail fields for contextual evidence.
- Legal/privacy complaints bypass standard reporting, requiring submission via dedicated [privacy complaint process](https://support.google.com/youtube/answer/2801895) or [legal issue form](https://support.google.com/youtube/answer/2802027#legal_reporting), with California users optionally reporting while signed out.
