# Fraud & Risk - Stytch Docs

## Summary

- **Fraud Prevention**: Device Fingerprinting API detects and blocks advanced attacks (credential stuffing, brute-force, phishing, ATO) and abuse (free trials, toll fraud) via unique device identifiers and bot protection (invisible CAPTCHA).
- **User Authentication & Control**: Enables device-based friction adjustments (trusted/unrecognized devices), account bans, seat sharing prevention, and IP-geo restrictions for access control.
- **Protected Auth Integration**: Seamlessly combines with Stytch’s SDKs to detect fraud (e.g., credential stuffing) without code changes, leveraging decisioning logic and enforcement mechanisms.
