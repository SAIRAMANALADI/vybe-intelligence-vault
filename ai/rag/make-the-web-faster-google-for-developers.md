# Make the Web Faster | Google for Developers

## Summary

- **PageSpeed Tools**: Google provides online tools like [PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights) for analyzing and optimizing website performance, offering actionable suggestions to improve speed. Additionally, open-source [PageSpeed Modules](https://developers.google.com/speed/pagespeed/module) for Apache/Nginx automate resource optimization on servers.

- **Infrastructure Leveraging**: Google Public DNS enhances browsing speed/security, while [hosted libraries](https://developers.google.com/speed/libraries) offload popular open-source JavaScript frameworks (e.g., jQuery) via Google’s CDN to reduce latency.

- **Performance Standards & Best Practices**: Google promotes modern protocols (e.g., [WebP](https://developers.google.com/speed/webp)) and publishes [performance guidelines](https://developers.google.com/speed/docs/best-practices/rules_intro) for implementing web optimizations like caching, compression, and critical rendering path improvements.
