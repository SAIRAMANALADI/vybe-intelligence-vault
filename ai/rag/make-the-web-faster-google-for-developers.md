# Make the Web Faster | Google for Developers

## Summary

- **PageSpeed Tools**: Google's [PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights) provides performance scores and optimization suggestions for websites, while the [PageSpeed Modules](https://developers.google.com/speed/pagespeed/module) (open-source) automate resource optimization on Apache/Nginx servers.

- **Infrastructure Leveraging**: [Google Public DNS](https://developers.google.com/speed/public-dns) enhances browsing speed/security, and [hosted libraries](https://developers.google.com/speed/libraries) offload popular open-source JS libraries via Google's CDN.

- **Performance Standards & Best Practices**: Google promotes modern protocols like [WebP](https://developers.google.com/speed/webp) and provides [performance best practices](https://developers.google.com/speed/docs/best-practices/rules_intro) for web optimizations.
