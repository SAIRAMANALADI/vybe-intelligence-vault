# Make the Web Faster | Google for Developers

## Summary

- **PageSpeed Tools**: Google offers online analysis via [PageSpeed Insights](https://developers.google.com/speed/pagespeed/insights) (scores + optimization suggestions) and server-side optimization via open-source [PageSpeed Modules](https://developers.google.com/speed/pagespeed/module) for Apache/Nginx.

- **Infrastructure Leveraging**: Improve browsing speed/security with [Google Public DNS](https://developers.google.com/speed/public-dns) and accelerate JS delivery by offloading popular open-source libraries via [Google's CDN](https://developers.google.com/speed/libraries).

- **Performance Standards & Protocols**: Google contributes to modern web performance via [WebP](https://developers.google.com/speed/webp) and provides [best-practice guidelines](https://developers.google.com/speed/docs/best-practices/rules_intro) for optimization.
