# Open Source | Sysdig

## Summary

- **Cloud-Native Runtime Security**: Falco is an open-source runtime security tool designed for cloud-native environments, providing threat detection and anomaly monitoring for containers, Kubernetes, and hosts.

- **Sysdig Origin & CNCF Contribution**: Developed by Sysdig and later contributed to the Cloud Native Computing Foundation (CNCF), Falco leverages kernel-level instrumentation (eBPF, syscalls) for real-time detection of suspicious activity.

- **Rule-Based Detection Engine**: Uses customizable YAML rules to define policies for detecting abnormal behavior (e.g., unexpected shell processes, privilege escalations) and integrates with SIEMs/alerting systems via outputs like gRPC, JSON, or CloudWatch.
