# Dapr - Distributed Application Runtime

## Summary

- **Decoupled Microservices Architecture**: Dapr provides APIs for service invocation, state management, pub/sub, workflows, and agentic AI, abstracting infrastructure dependencies (e.g., message brokers, databases) via a component model, enabling portable and flexible distributed applications.

- **Built-in Cross-Cutting Concerns**: Integrates security (mTLS, policy-based access control), observability (OpenTelemetry/Zipkin tracing), and resiliency (retries, circuit breakers) out-of-the-box, reducing boilerplate code and accelerating production readiness.

- **Multi-Environment Deployment**: Supports Kubernetes and self-hosted environments (VMs/physical machines) across clouds/edge, with incremental adoption capabilities for existing architectures while maintaining backward compatibility.
