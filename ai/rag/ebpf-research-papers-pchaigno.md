# eBPF Research Papers | pchaigno

## Summary

- **PeeR (OSDI'26)**: Introduces `sched_ext` and cooperative preemption at helper calls to make BPF programs schedulable and preemptable, improving latency-critical eBPF application performance.

- **BPF-DB (SIGMOD'25)**: Proposes an in-kernel DBMS in eBPF with ACID properties, enabling transactional database management directly within the kernel.

- **VEP (NSDI'25)**: Implements a two-stage verification toolchain using proof-carrying code with C source annotations, enhancing eBPF programmability and safety.
