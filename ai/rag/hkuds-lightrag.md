# HKUDS/LightRAG

## Summary

- **LightRAG Framework**: Introduces a lightweight, efficient Retrieval-Augmented Generation (RAG) system optimized for speed and simplicity, leveraging minimal computational overhead while maintaining high performance in document-grounded generation tasks.

- **Graph-Based Retrieval**: Implements a graph-augmented retrieval mechanism to enhance contextual relevance by dynamically constructing and querying knowledge graphs from input documents, improving retrieval precision over traditional vector-based methods.

- **Modular Architecture**: Designed with plug-and-play components (e.g., Docling for document parsing, MinerU for preprocessing) and supports integration with LLMs (e.g., GPT) via a streamlined API, enabling rapid deployment and scalability.
