# HKUDS/LightRAG

## Summary

- **LightRAG Framework**: Introduces a lightweight, efficient Retrieval-Augmented Generation (RAG) system optimized for speed and simplicity, leveraging graph-based retrieval and generation techniques to enhance LLM performance.

- **Key Innovations**: Implements a **multi-granularity retrieval** mechanism (node, edge, and subgraph-level) with **adaptive query routing** to dynamically select the most relevant knowledge context, reducing latency while maintaining accuracy.

- **Performance Metrics**: Achieves **~3-5x faster inference** compared to traditional RAG pipelines (e.g., GraphRAG) with **minimal memory overhead**, demonstrated on benchmarks like MMLU, HotpotQA, and TriviaQA.
