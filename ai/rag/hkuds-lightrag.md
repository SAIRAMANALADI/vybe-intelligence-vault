# HKUDS/LightRAG

## Summary

- **Efficient RAG Framework**: LightRAG introduces a simplified and accelerated retrieval-augmented generation (RAG) pipeline optimized for speed and performance, leveraging lightweight indexing and retrieval mechanisms to reduce latency while maintaining high accuracy.

- **Graph-Based Retrieval**: Implements a graph-augmented retrieval strategy, dynamically constructing and querying knowledge graphs to enhance contextual relevance and mitigate hallucinations in LLM outputs.

- **Scalable & Modular Design**: Built in Python with modular components for easy integration, supporting both dense and sparse retrieval methods, and designed for seamless deployment across various LLM backends.
