# HKUDS/LightRAG

## Summary

- **LightRAG Architecture**: Introduces a lightweight, modular RAG framework optimized for speed and simplicity, leveraging dynamic graph-based retrieval to enhance LLM context integration without heavy computational overhead.

- **Key Innovations**:
  - **Hierarchical Retrieval**: Combines coarse-to-fine retrieval strategies to balance latency and accuracy.
  - **Adaptive Chunking**: Dynamically adjusts text segmentation granularity based on query complexity and corpus structure.

- **Performance Metrics**:
  - Achieves **~5-10x faster inference** than traditional RAG pipelines (e.g., GraphRAG) while maintaining competitive accuracy on EMNLP 2025 benchmarks.
  - Supports **multi-modal retrieval** (text/graph) with minimal latency degradation.
