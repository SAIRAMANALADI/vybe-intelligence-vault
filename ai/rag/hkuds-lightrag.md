# HKUDS/LightRAG

## Summary

- **LightRAG Framework**: Introduces a lightweight, efficient Retrieval-Augmented Generation (RAG) system optimized for speed and simplicity, leveraging Python for implementation.

- **Key Innovations**: Employs advanced techniques like document chunking, graph-based retrieval, and hybrid search (semantic + keyword) to enhance retrieval accuracy and generation quality while minimizing computational overhead.

- **Integration & Compatibility**: Supports modular integration with frameworks like Docling, GraphRAG, and Ragas, and includes tools for document parsing (e.g., MinerU) and evaluation, ensuring adaptability across diverse RAG pipelines.
