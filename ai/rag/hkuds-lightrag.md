# HKUDS/LightRAG

## Summary

- **LightRAG Framework**: Introduces a lightweight, fast Retrieval-Augmented Generation (RAG) system optimized for efficiency, leveraging simple yet effective retrieval mechanisms to enhance LLM performance without excessive computational overhead.

- **Graph-Based Retrieval**: Implements a graph-augmented retrieval strategy to dynamically construct context graphs, enabling more precise and context-aware knowledge extraction compared to traditional vector-based RAG methods.

- **Performance Metrics**: Achieves significant speedups (e.g., 2-5x faster inference) and reduced memory usage while maintaining competitive accuracy, as validated on EMNLP 2025 benchmarks across diverse datasets.
