# HKUDS/LightRAG

## Summary

- **LightRAG Framework**: Introduces a lightweight, fast Retrieval-Augmented Generation (RAG) system optimized for efficiency while maintaining high performance in LLM-based applications, as presented at EMNLP 2025.

- **Graph-Based Retrieval**: Leverages knowledge graphs to enhance retrieval precision and contextual relevance, enabling structured and scalable data augmentation for generative models.

- **Python Implementation**: Provides an open-source Python library with modular components for seamless integration with large language models (LLMs), supporting GPT-4 and other GenAI frameworks.
