# HKUDS/LightRAG

## Summary

- **LightRAG Framework**: Introduces a lightweight, efficient Retrieval-Augmented Generation (RAG) system optimized for speed and simplicity, leveraging minimal computational overhead while maintaining high performance in knowledge-intensive tasks.

- **Graph-Based Retrieval**: Implements a graph-structured retrieval mechanism to dynamically extract and synthesize relevant context from documents, improving retrieval accuracy and reducing latency compared to traditional vector-based RAG methods.

- **Modular Architecture**: Designed with a plug-and-play structure, enabling seamless integration with existing LLM pipelines and supporting multi-modal inputs (e.g., text, tables) via integration with tools like Docling and MinerU.
