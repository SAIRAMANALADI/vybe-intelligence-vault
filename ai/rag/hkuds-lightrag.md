# HKUDS/LightRAG

## Summary

- **LightRAG Framework**: Introduces a lightweight, efficient Retrieval-Augmented Generation (RAG) system optimized for speed and simplicity, leveraging minimal architectural overhead while maintaining high performance in downstream tasks.

- **Graph-Based Retrieval**: Implements a graph-augmented retrieval mechanism to dynamically construct context graphs, enabling efficient multi-hop reasoning and reducing dependency on static, pre-built knowledge bases.

- **Benchmark Performance**: Achieves state-of-the-art results on EMNLP2025 benchmarks with significant improvements in latency (up to 5x faster) and memory efficiency compared to traditional RAG and GraphRAG baselines.
