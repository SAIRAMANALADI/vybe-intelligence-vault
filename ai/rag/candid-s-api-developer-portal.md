# Candid's API Developer Portal

## Summary

- **API Version 4 Update**: Enhanced Essentials and Premier APIs now provide richer nonprofit data (1.6M+ orgs) with improved search relevancy, financials, IRS compliance validation, and advanced filtering capabilities.

- **Specialized APIs**: Includes Charity Check (IRS compliance validation), Nonprofit Eligibility (Apple Pay donation compliance), Grants API (comprehensive funding data), Demographics API (equity-focused metrics), Taxonomy GraphQL API (PCS taxonomy integration), News API (real-time sector news), and PDF API (structured nonprofit profiles).

- **Datasets**: Offers bulk datasets (`Candid_nonprofits`, `Candid_grants`, `Candid_demographics`) for legal verification, funding trend analysis, and demographic research.
