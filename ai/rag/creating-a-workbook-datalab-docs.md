# Creating a workbook | DataLab Docs

## Summary

- **Workbook Creation Methods**: DataLab workbooks (data projects) can be created via:
  - **Empty workbook** (via "New workbook" button)
  - **Templates** (pre-written code for common tasks)
  - **Datasets** (pre-loaded data + sample code)
  - **GitHub repositories** (via "Import from GitHub" in Code view)
  - **Copying existing workbooks** (via File > Make a Copy)

- **Personal vs. Group Workbooks**:
  - **Personal workbooks**: Default location, configurable via account selector; support public sharing, environment variables, and database connections.
  - **Group workbooks**: Created under group spaces; shared with all group members; inherit group-level environment variables and database connections.

- **Quick Access & URL-Based Workbook Creation**:
  - Direct access via `ws.new` URL opens an empty, ready-to-use workbook.
  - **Create Copy Link** feature generates reusable URLs for duplicating workbooks (useful for education or collaboration).
