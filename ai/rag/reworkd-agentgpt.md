# reworkd/AgentGPT

## Summary

- **Browser-based autonomous AI agent deployment**: Enables users to assemble, configure, and deploy autonomous AI agents directly in the browser using TypeScript, leveraging frameworks like Next.js and LangChain.

- **Integration with LLM APIs**: Supports OpenAI's GPT models and other LLM APIs (e.g., BabyAGI) for agent reasoning and task execution, with modular configuration for customization.

- **T3 Stack & modern tooling**: Built on the T3 Stack (TypeScript, Tailwind, tRPC, Next.js) with dependencies like LangChain for agent orchestration and OpenAI for LLM interactions.
