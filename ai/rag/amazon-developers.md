# Amazon Developers

## Summary

- **Amazon Developer Services** provides SDKs, APIs, and tools for building apps and experiences across **Alexa, Fire TV, Fire tablets, Ring, AWS, and automotive platforms**, with dedicated consoles for development and debugging.

- **AI-Powered Developer Tools** leverage **Amazon Devices Builder Tools** to enhance AI coding assistants (e.g., Claude Code, Cursor) with **onboarding, performance debugging, and crash analytics** for Amazon-supported devices.

- **Key services include**:
  - **Alexa Skills Kit** for voice interactions,
  - **Amazon Appstore** for Fire TV/tablet apps,
  - **AWS Dev Center** for cloud-based development,
  - **Ring Developer APIs** for IoT data processing,
  - **Just Walk Out (JWO) APIs** for retail automation.
