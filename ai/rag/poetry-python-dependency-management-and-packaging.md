# Poetry - Python dependency management and packaging made easy

## Summary

- **Dependency Management**: Poetry uses `pyproject.toml` (PEP 621) for dependency specification, supporting version constraints (PEP 440) and semantic versioning, with resolvers optimized for deterministic builds.

- **Isolated Environments**: Enforces project-specific virtual environments (configurable) to isolate dependencies from the global Python installation, ensuring reproducibility.

- **CLI & Packaging**: Provides an intuitive CLI (`poetry add`, `poetry build`, `poetry publish`) for dependency resolution, source distribution/wheel packaging, and PyPI/private repository publishing.
