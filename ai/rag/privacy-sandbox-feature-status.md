# Privacy Sandbox feature status

## Summary

- **Chrome Deprecations**: Attribution Reporting, Private Aggregation, Protected Audience, Related Website Sets, Shared Storage, Topics, and several mitigations (e.g., IP Protection, Partitioned Popins, Private Proofs) are scheduled for deprecation/removal; CHIPS, FedCM, Fenced Frames, Storage Access, and User-Agent reduction remain supported.
- **Android Deprecations**: Attribution Reporting, On-device Personalization, Protected App Signals, Protected Audience, SDK Runtime, and Topics APIs are all slated for phaseout.
- **Discontinued Features**: Fenced Storage Read, Probabilistic Reveal Tokens, Script Blocking, and several experimental APIs (e.g., Private Proofs) will not launch or are being discontinued.
