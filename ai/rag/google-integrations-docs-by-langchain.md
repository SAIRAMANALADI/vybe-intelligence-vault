# Google integrations - Docs by LangChain

## Summary

- **Unified SDK for Google Generative AI**: The `langchain-google-genai` package (v4.0.0+) consolidates access to **Gemini Developer API** and **Vertex AI** via the `google-genai` SDK, supporting chat models, LLMs, and embeddings; legacy `langchain-google-vertexai` remains for Vertex AI-specific features (e.g., Model Garden, Vector Search).

- **Vertex AI Platform Services**: The `langchain-google-vertexai` package enables access to **Model Garden** (Llama, Mistral, Anthropic), **evaluation services**, **vision models**, and specialized tools like **Vertex AI Vector Search**, **Document AI**, and **BigQuery** integrations.

- **Third-Party & Google Product Integrations**: Supports **Google Drive**, **Google Search**, **Gmail API**, and **MCP toolbox** for database interactions (Cloud SQL, AlloyDB), alongside deprecated but functional legacy interfaces (e.g., `ChatVertexAI`, `VertexAIEmbeddings`).
