# embeddings-benchmark/mteb

## Summary

- **MTEB Framework**: A Python-based benchmarking tool for evaluating text embeddings across diverse tasks (e.g., retrieval, clustering, classification) and languages/modalities, integrating 58 datasets and 11 task categories.

- **Multimodal & Multilingual Support**: Evaluates embeddings for both text and multimodal inputs (e.g., image-text pairs) with a focus on low-resource languages, leveraging Sentence-BERT (SBERT) and neural search models.

- **State-of-the-Art Metrics**: Provides standardized evaluation protocols for 15+ embedding models (e.g., `sentence-transformers`, `OpenCLIP`) with reproducible leaderboards and task-specific metrics (e.g., STS, bitext mining).
