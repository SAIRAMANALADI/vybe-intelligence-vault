# embeddings-benchmark/mteb

## Summary

- **MTEB Framework**: A Python-based benchmarking tool for evaluating text embeddings across diverse tasks (e.g., retrieval, clustering, classification) and languages/modalities, supporting 58 datasets and 11 task categories.
- **Multimodal & Multilingual Support**: Evaluates embeddings for both text and multimodal inputs, with specialized tracks for low-resource languages and cross-lingual tasks.
- **Integration with Sentence Transformers**: Compatible with `sentence-transformers` models (e.g., SBERT), enabling standardized comparison of state-of-the-art embedding models via a unified API.
