# embeddings-benchmark/mteb

## Summary

- **Benchmark Suite**: MTEB (Massive Text Embedding Benchmark) provides a standardized framework for evaluating text embeddings across diverse tasks including retrieval, clustering, classification, and reranking, supporting multilingual and multimodal evaluation.
- **Task Coverage**: Supports 58 datasets across 11 task categories (e.g., STS, bitext mining, semantic search) with modular design for extensibility to new tasks and languages.
- **Integration**: Compatible with Sentence-Transformers (`sentence-transformers`) and optimized for low-resource NLP, enabling benchmarking of models like SBERT and neural search systems.
