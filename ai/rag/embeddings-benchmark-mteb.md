# embeddings-benchmark/mteb

## Summary

- **Benchmark Suite**: MTEB (Massive Text Embedding Benchmark) provides a standardized framework for evaluating text embeddings across diverse tasks (e.g., retrieval, classification, clustering) and languages/modalities, integrating 58 datasets and 11 task categories.

- **Multilingual & Multimodal Support**: Supports evaluation across 100+ languages and multiple modalities (text, image-text), with specialized tasks for low-resource NLP and cross-lingual applications.

- **Modular & Extensible**: Implemented in Python, MTEB integrates with libraries like Sentence-Transformers (SBERT) and supports custom task/model additions, enabling reproducible SOTA comparisons for embedding models.
