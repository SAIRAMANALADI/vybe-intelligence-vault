# Cinemachine package | Cinemachine | 3.1.7

## Summary

- **Modular Camera Control Suite**: Cinemachine provides procedural modules for real-time camera tracking, composition, blending, and shot transitions, eliminating manual scripting and dynamic adjustments for changes in scene elements (e.g., animations, terrain, or GameObject movements).

- **Genre-Agnostic & Scalable**: Supports real-time camera control across genres (FPS, 2D, RTS, etc.) with unlimited shots per scene, leveraging modular architecture for complex behaviors and dynamic adaptation to gameplay changes.

- **Unity Ecosystem Integration**: Designed to complement Unity tools like Timeline, animation, and post-processing, with extensibility via custom scripts or modules for enhanced camera behavior.
