# Welcome to Suga - Suga Docs

## Summary

- **Visual Infrastructure as Code (IaC)**: Suga provides a canvas-based interface for designing, configuring, and deploying infrastructure with explicit component connections, combining rapid iteration speed with version-controlled IaC discipline, enabling reproducible environments and zero-downtime deployments in under 10 seconds.

- **Full Deployment Lifecycle Management**: Every infrastructure change is tracked with audit trails (author, timestamp, commit message), enabling instant rollbacks to prior states, environment forking for isolated testing, and automated HTTPS with zero-downtime updates by default.

- **Simplified Complexity for Teams**: Designed for teams prioritizing speed and traceability, Suga eliminates YAML complexity while maintaining IaC benefits, supporting rapid iteration cycles and multi-environment reproducibility (dev/staging/production) without manual console operations.
