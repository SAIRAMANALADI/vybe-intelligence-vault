# Haystack | Haystack

## Summary

- **Modular AI Orchestration**: Haystack provides a transparent, modular framework for building production-grade AI agents with full visibility into retrieval, reasoning, memory, and tool integration, supporting components like OpenAI, Hugging Face, and vector databases (Weaviate, Pinecone) without vendor lock-in.

- **Enterprise-Scale Deployment**: Supports cloud-agnostic, Kubernetes-ready pipelines with built-in reliability, observability, and serializable workflows, enabling seamless transition from prototype to production with unified tooling for testing and deployment.

- **Multi-Modal & Agentic Capabilities**: Enables advanced RAG pipelines, AI agents with standardized tool calling, multimodal processing (text, image, audio), and conversational AI with Jinja-2 templating for flexible content generation workflows.
