# Haystack | Haystack

## Summary

- **Modular AI Orchestration**: Haystack provides a transparent, open-source framework for building production-ready AI agents, RAG systems, and multimodal applications with modular components for retrieval, reasoning, memory, and tool integration.

- **Cross-Platform & Vendor-Neutral**: Supports seamless integration with LLM providers (OpenAI, Anthropic, Mistral, etc.) and vector databases (Weaviate, Pinecone, Elasticsearch) while ensuring cloud-agnostic deployment via Kubernetes-ready pipelines with built-in observability.

- **Enterprise-Grade Scalability**: Offers enterprise support, a visual pipeline designer, and scalable deployment options (cloud/on-prem) with features like secure access controls, auditability, and hybrid retrieval strategies for advanced RAG and agentic workflows.
