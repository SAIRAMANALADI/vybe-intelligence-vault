# supabase-community/vercel-ai-chatbot

## Summary

- **Architecture**: Next.js-based AI chatbot integrating Supabase for backend services (PostgreSQL, Auth, Vector embeddings) and Vercel AI SDK for LLM interactions.
- **Key Features**: Real-time chat with AI models (e.g., OpenAI, Anthropic), Supabase Edge Functions for serverless logic, and RAG (Retrieval-Augmented Generation) via Supabase's pgvector extension.
- **Deployment**: Optimized for Vercel with Supabase integration for auth, database, and vector storage, supporting scalable AI-driven conversations.
