# eBPF - Introduction, Tutorials & Community Resources

## Summary

- **Kernel Programmability**: eBPF enables safe, near-native execution of verified programs in the kernel via JIT compilation, allowing dynamic modification of kernel functionality without restarts or patches.

- **Multi-Domain Adoption**: Major organizations (Google, Netflix, Meta, Cloudflare) leverage eBPF for high-performance networking, security auditing, observability, and load balancing at scale.

- **Core Capabilities**: Provides in-kernel aggregation of metrics, protocol parsing, tracepoint attachment, and socket-level security monitoring while ensuring safety through verification and privileged execution.
