# Binaries · openssl/openssl Wiki · GitHub

## Summary

- **OpenSSL Binary Distributions**: Third-party pre-compiled OpenSSL binaries available for Windows, Linux, macOS, Android, Solaris, and NonStop systems, with support for legacy and modern versions (e.g., OpenSSL 3.0 via WebAssembly, FIPS 140-3 validated builds).

- **Deprecation of Engines**: OpenSSL 4.0 will remove engine support, transitioning to providers (e.g., `wolfProvider`, `CryptoComply FIPS 140-3 Provider`) for cryptographic module integration.

- **Hardware Acceleration Engines**: Third-party engines like Intel QAT, ATECCX08, and GOST provide hardware-backed cryptographic acceleration and FIPS-certified operations (e.g., quantum-safe algorithms via ISARA Radiate).
