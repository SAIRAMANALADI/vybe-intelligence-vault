# Learning to reason with LLMs | OpenAI

## Summary

- **Reinforcement Learning for Reasoning**: OpenAI o1 employs a large-scale RL algorithm to optimize chain-of-thought reasoning, improving performance with both train-time and test-time compute scaling, achieving 89th percentile on Codeforces, top 500 AIME qualifier, and PhD-level accuracy on GPQA.

- **Benchmark Superiority**: o1 surpasses GPT-4o across 54/57 MMLU subcategories, scores 78.2% on MMMU (vision-capable), and outperforms human PhD experts on GPQA Diamond, with 93% AIME 2024 accuracy via consensus re-ranking.

- **Chain-of-Thought (CoT) Mechanism**: o1 generates structured, step-by-step reasoning traces (e.g., cipher decoding) via RL-driven CoT, enabling error correction, strategy refinement, and decomposition of complex problems, unlike GPT-4o’s direct responses.
