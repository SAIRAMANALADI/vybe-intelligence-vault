# Home | Cloud | Zilliz Cloud Developer Hub

## Summary

- **Managed Milvus Service**: Zilliz Cloud offers a fully managed Milvus vector database service, enabling simplified deployment, scaling, and security for vector search applications with support for approximate nearest neighbor (ANN) searches.

- **Data Integration & Processing**: Supports external storage integrations (AWS S3, GCP, Azure) via external volumes, enabling in-place data access without copying; supports Parquet, Lance, Iceberg, and Vortex file formats for external collections with sub-second metadata/index refreshes.

- **Deployment & Operational Features**: Provides free, serverless, and dedicated cluster plans; includes backup/restore (manual/scheduled), cross-region backup copies, migration from external sources (Pinecone, MongoDB, etc.), and fine-grained access control with private networking options.
