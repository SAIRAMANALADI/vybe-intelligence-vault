# How Podium optimized agent behavior and reduced engineering intervention by 90% with LangSmith

## Summary

- **LangSmith Integration**: Podium leveraged LangSmith for LLM observability, enabling trace logging, dataset curation, and performance evaluation across their AI Employee agent lifecycle, reducing debugging complexity from 20-30 LLM calls per interaction to structured, traceable workflows.

- **Model Optimization via Distillation**: Podium distilled outputs from a larger model into a smaller, fine-tuned model using LangSmith traces enriched with metadata (e.g., customer profiles, business types), achieving a 7.5% F1 score improvement (91.7% → 98.6%) and surpassing their 98% quality threshold.

- **90% Reduction in Engineering Intervention**: By granting Technical Product Specialists (TPS) access to LangSmith’s traces and playground, Podium enabled non-engineering teams to troubleshoot agent behavior (e.g., misaligned responses) via prompt/content adjustments, cutting engineering support requests by 90% and accelerating issue resolution.
