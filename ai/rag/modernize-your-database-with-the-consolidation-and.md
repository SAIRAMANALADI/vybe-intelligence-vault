# Modernize your database with the consolidation and retirement of Azure Database Migration tools - Microsoft SQL Server B

## Summary

- **Consolidation of Azure Database Migration Tools**: Microsoft is consolidating its Azure Database Migration Service (DMS) and Azure SQL Migration extension for Azure Data Studio into a unified, streamlined migration experience, reducing tool fragmentation and simplifying the migration process for SQL Server and other database workloads to Azure.

- **Retirement of Legacy Tools**: The standalone Azure Database Migration Service (DMS) portal and the Azure SQL Migration extension for Azure Data Studio will be retired on **November 15, 2024**, with migration capabilities fully integrated into the new unified Azure SQL Migration extension.

- **Unified Migration Workflow**: The new Azure SQL Migration extension (v1.0+) consolidates assessment, schema conversion, and data migration into a single workflow, supporting offline and online migrations with enhanced performance, security, and governance controls.
