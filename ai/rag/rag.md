# RAG

## Summary

- **Development Data Release**: TREC RAG 2026 provides development topics (RAG25 and ResearchRubrics TSV files), RAG25 nuggets (`rag25-dev-nuggets.jsonl`), UMBRELA relevance judgments (`rag25-dev-umbrela-qrels`), and ResearchRubrics evaluation rubrics (`research-rubrics-dev-rubrics.jsonl`) for pre-evaluation testing.

- **Track Tasks & Corpus**: Two tasks—Retrieval (R) and Retrieval-Augmented Generation (RAG)—are defined, using NVIDIA’s ClimbMix-400b corpus accessible via Pyserini REST API or custom retrieval systems.

- **Timeline & Participation**: Test topics release July 6, 2026; submission deadline August 7, 2026; results returned TBD. Registration via Evalbase, Google Groups, Discord, and SIGIR Slack required for participation.
