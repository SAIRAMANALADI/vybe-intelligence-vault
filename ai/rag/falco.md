# Falco

## Summary

- **Runtime Security Tool**: Falco provides real-time runtime security monitoring across hosts, containers, Kubernetes, and cloud environments by analyzing Linux kernel events and other data sources using custom rules and plugins.
- **eBPF-Powered Detection**: Leverages eBPF to monitor system activity for abnormal behavior, enabling detection of malicious activity, compliance violations, and zero-day threats with minimal overhead.
- **Multi-System Integration**: Supports forwarding alerts in JSON format to 50+ third-party SIEMs and data lakes, with out-of-the-box rules and Helm-based Kubernetes deployment for seamless integration.
