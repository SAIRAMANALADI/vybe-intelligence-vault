# Browse InPrivate in Microsoft Edge - Microsoft Support

## Summary

- **InPrivate Mode**: Microsoft Edge's InPrivate browsing prevents local storage of browsing history, cookies, site data, and form entries, enhancing privacy while allowing downloads and favorites retention.
- **Data Handling**: InPrivate tabs/windows do not save temporary internet files, history, or cookies to the device after session termination.
- **Activation**: In Edge, InPrivate windows are initiated via **Settings and More** > **New InPrivate window**.
