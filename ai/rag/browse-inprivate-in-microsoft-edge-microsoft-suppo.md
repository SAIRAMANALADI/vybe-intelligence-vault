# Browse InPrivate in Microsoft Edge - Microsoft Support

## Summary

- **Data Exclusion**: InPrivate mode in Microsoft Edge prevents local storage of browsing history, cookies, site data, and form entries, enhancing privacy by limiting local tracking.
- **Persistent Features**: Downloads and favorites are retained even when using InPrivate browsing, balancing privacy with usability.
- **Activation**: InPrivate windows/tabs are initiated via **Settings and More** > **New InPrivate window** in Microsoft Edge.
