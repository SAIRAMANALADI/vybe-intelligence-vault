# JSON-LD - JSON for Linked Data

## Summary

- **JSON-LD** is a W3C standard for Linked Data serialization using JSON, enabling interoperable, machine-readable data across the web via `@context`, `@id`, and `@type` constructs.
- **Ecosystem Extensions**: Supports YAML-LD (human-friendly authoring) and CBOR-LD (binary compression for constrained environments), with implementations in multiple languages (JavaScript, Python, Java, Rust, etc.).
- **Tooling & Specifications**: Includes a [playground](https://json-ld.org/playground/) for validation, conformance test suites, and active W3C working groups (Community Group & JSON-LD WG) for ongoing development and standardization.
