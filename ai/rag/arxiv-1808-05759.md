# [1808.05759] Read + Verify: Machine Reading Comprehension with Unanswerable Questions

## Summary

- **Proposed a read-then-verify system** combining a neural reader (for answer extraction and no-answer probability prediction) with an answer verifier (to validate entailment of predicted answers by input snippets), achieving **74.2 F1 on SQuAD 2.0** (state-of-the-art at submission).

- **Introduced two auxiliary losses** to improve answer extraction and no-answer detection, alongside **three verifier architectures** (e.g., entailment-based verification) to enhance unanswerable question handling.

- **Addressed limitations of prior methods** by explicitly validating answerability via entailment checks, rather than solely relying on no-answer probability predictions.
