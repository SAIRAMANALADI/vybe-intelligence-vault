# [2510.08847] What Is Your Agent's GPA? A Framework for Evaluating Agent Goal-Plan-Action Alignment

## Summary

- Introduces **Agent GPA**, a factorized evaluation framework using LLM judges to assess **Goal-Plan-Action (GPA) alignment** in AI agents, decomposing failures at critical intersections.

- Validated across **three benchmarks** (multi-agent research, single coding agent, enterprise data-agent) with **95% error coverage** and **86% localization accuracy**, outperforming manual prompting (76-86% error coverage).

- Uses **automated prompt optimization** and **evolutionary refinement** to improve judge consistency by **38%**, enabling scalable, domain-agnostic agent evaluation.
