# Intro | Zod

## Summary

- **TypeScript-first schema validation**: Zod provides a TypeScript-native schema validation library with static type inference, enabling runtime validation and compile-time type safety for data structures from primitives to complex nested objects.

- **Minimalist & immutable core**: The library has zero external dependencies, a 2KB gzipped core bundle, and an immutable API where methods return new instances, ensuring predictable state transitions.

- **Ecosystem & integrations**: Supports JSON Schema conversion, works in Node.js/browsers, and integrates with tools like tRPC, React Hook Form, and Zod MCP server; requires TypeScript 5.5+ with `strict` mode enabled.
