# Metrics - Ragas

## Summary

- **Metric Design Principles**: Ragas metrics are structured around four core principles—**faithfulness**, **answer relevance**, **context precision**, and **context recall**—to evaluate RAG pipelines holistically, ensuring alignment with factual accuracy and contextual relevance.

- **Available Metrics**: The framework includes **Faithfulness** (measures hallucination via entailment), **Answer Relevance** (assesses response alignment with input), **Context Precision** (evaluates retrieved context quality), and **Context Recall** (gauges context sufficiency for answers).

- **Implementation**: Metrics leverage **LLM-as-a-judge** paradigms with fine-tuned prompts and proprietary models (e.g., `ragas-llm`) for scalable, automated evaluation of RAG system performance.
