# Security Policy · nodejs/node · GitHub

## Summary

- Security bugs in Node.js must be reported via [HackerOne](https://hackerone.com/nodejs) with initial acknowledgment within 5 days and detailed response within 10 days; escalation to `security@lists.openjsf.org` is possible if no response is received within 6 or 14 business days.

- Vulnerabilities are validated across all supported Node.js versions, with fixes prepared privately before a coordinated public disclosure (embargo typically 72 hours post-CVE issuance) and announcement via security mailing list, nodejs.org, and blog within 6 hours of disclosure.

- Node.js threat model excludes vulnerabilities requiring OS compromise or affecting experimental platforms/features behind compile-time/V8 flags; eligible vulnerabilities must impact untrusted input processing (e.g., HTTP APIs, TLS validation) or cause asymmetric DoS under documented criteria.
