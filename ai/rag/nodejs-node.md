# node/SECURITY.md at main · nodejs/node · GitHub

## Summary

- Security bugs in Node.js must be reported via [HackerOne](https://hackerone.com/nodejs) with acknowledgment within 5 days and updates within 10 days; escalation to `security@lists.openjsf.org` is possible if no response is received within 6 business days or 14 days post-acknowledgment.
- Node.js follows a structured disclosure policy: validated vulnerabilities are fixed across supported versions, assigned a CVE, and disclosed after a 72-hour embargo (adjustable for severity), with advisories published on the Node.js blog within 6 hours of mailing list notification.
- Vulnerabilities must align with Node.js’s threat model (e.g., untrusted network data, DoS via asymmetric resource consumption) and exclude experimental features/platforms (Tier 3), compile-time/V8 flags, or trusted elements (OS, developer infrastructure).
