# pguso/rag-from-scratch

## Summary

- **Educational RAG Pipeline**: Implements Retrieval-Augmented Generation (RAG) from scratch using JavaScript, focusing on local LLMs (via `node-llama-cpp`) to eliminate black-box dependencies and provide hands-on understanding of embeddings, vector search, retrieval, and context-augmented generation.

- **Modular Architecture**: Demonstrates a complete RAG workflow, including document ingestion, embedding generation (e.g., with `sentence-transformers`), vector storage (e.g., FAISS or similar), retrieval mechanisms, and prompt augmentation for LLMs.

- **Agent Integration**: Extends the pipeline to AI agents, enabling dynamic interaction with the RAG system for tasks like chatbots, leveraging Node.js for scalability and real-time processing.
