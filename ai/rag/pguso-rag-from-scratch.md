# pguso/rag-from-scratch

## Summary

- **Educational RAG Implementation**: Provides a step-by-step guide to building a Retrieval-Augmented Generation (RAG) system from scratch using local LLMs (via `node-llama-cpp`), emphasizing transparency by avoiding black-box components.

- **Core Technical Components**: Implements and explains key RAG pipeline stages—embeddings generation, vector search (likely using cosine similarity or similar), retrieval augmentation, and context-augmented generation—entirely in JavaScript/Node.js.

- **Practical Focus**: Designed as a tutorial for developers to gain hands-on understanding of RAG mechanics, with a chatbot use case, and includes modern tooling like AI agents (`ai-agents`) and Node.js integration.
