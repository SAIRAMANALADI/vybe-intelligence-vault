# Simon Willison: Prompt injection

## Summary

- **Prompt injection** is a class of security vulnerabilities in LLM-based systems where malicious input manipulates model behavior to bypass intended constraints (e.g., overriding system prompts via user-supplied text).

- **Multi-modal attacks** extend prompt injection to vision-language models (e.g., GPT-4V), where adversarial images or embedded text can subvert model outputs, enabling data exfiltration or arbitrary command execution.

- **Mitigation strategies remain unresolved**; techniques like delimiters, dual-LLM patterns, or additional AI layers fail to fully prevent attacks, with current defenses limited to awareness and architectural constraints.
