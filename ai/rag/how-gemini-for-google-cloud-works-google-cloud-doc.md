# How Gemini for Google Cloud works | Google Cloud Documentation

## Summary

- **Training Data & Context Integration**: Gemini for Google Cloud LLMs are trained on public code, Google Cloud-specific materials, and other technical datasets, with contextual user data (e.g., project ID, organization ID) dynamically included for responses but not persisted or used for model training.

- **Source Attribution & Code Customization**: Direct quotes from web pages or code repositories are cited with URLs or applicable licenses; Gemini Code Assist allows context-aware code generation from local/private codebases while enabling controls to disable cited-source matches.

- **Indemnification & Security**: Covered under [Generative AI Indemnified Services](https://cloud.google.com/terms/generative-ai-indemnified-services), with security controls for private code access (e.g., [Gemini Code Assist](https://cloud.google.com/gemini/docs/codeassist/overview)) documented in [security guides](https://cloud.google.com/gemini/docs/codeassist/security-privacy-compliance).
