# Use the Azure OpenAI Responses API - Microsoft Foundry | Microsoft Learn

## Summary

- **Azure OpenAI Responses API** enables stateful, multi-turn interactions by unifying chat completions and Assistants API features, with dynamic tool loading via `tool search` and support for the `computer-use-preview` model.

- **Prerequisites** include a deployed Azure OpenAI model, authentication (API key or Microsoft Entra ID), and client libraries (Python, .NET, JavaScript/TypeScript, Java), with REST examples requiring `AZURE_OPENAI_API_KEY` or `AZURE_OPENAI_AUTH_TOKEN`.

- **Supported regions/models** span 30+ regions (e.g., `eastus`, `westeurope`) and models (e.g., `gpt-5.6-sol`, `gpt-4o`, `o3-mini`), with regional/model-specific availability; known limitations include PDF input issues and streaming performance in background mode.
