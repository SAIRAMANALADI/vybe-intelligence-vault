# YouTube Researcher Program Application - YouTube Help

## Summary

- **Application Requirements**: Form requires details on research, institution, API Client, and current/proposed YouTube API usage, with data processed under [Privacy Policy](https://policies.google.com/privacy) and [Researcher Program Policies](https://research.youtube/policies/).

- **Institutional Validation**: Mandates organization name selection from a pre-approved list (e.g., universities, research institutes) and requires an actively monitored institutional email for communications.

- **Quota & Updates**: Applicants must declare if their research has changed since the last submission (e.g., proposal updates, publication timelines) and specify whether they are new or existing participants requiring additional quota.
