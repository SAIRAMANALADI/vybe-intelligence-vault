# vllm-project/vllm

## Summary

- **Architecture & Efficiency**: vLLM implements **PagedAttention**, a memory optimization technique that reduces KV cache fragmentation, enabling high-throughput LLM inference with minimal memory overhead.
- **Hardware & Framework Support**: Optimized for **NVIDIA CUDA**, **AMD ROCm**, and **Google TPU**, leveraging **PyTorch** for multi-GPU/TPU scaling, with native support for **MoE (Mixture of Experts)** models like **DeepSeek-V3** and **Qwen3**.
- **Serving & Compatibility**: Provides a **unified serving engine** for **OpenAI-compatible APIs**, supporting models such as **Llama**, **GPT-OSS**, and **Kimi**, with **continuous batching** for dynamic request handling.
