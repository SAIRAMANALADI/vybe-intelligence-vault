# Integrations - Pinecone Docs

## Summary

- **Agent Skills & IDE Plugins**: Pinecone provides a universal skills library for agentic IDEs (GitHub Copilot, Codex) and official plugins for Cursor and Claude Code, enabling MCP tools, slash commands, and enhanced AI-driven workflows.
- **Data Integration & ETL**: Integrations like Airbyte, Apify, Aryn, and Datavolo enable seamless ingestion, transformation, and loading of structured/unstructured data (web scraping, documents, SaaS) into Pinecone for RAG and semantic search.
- **Model & Infrastructure Synergy**: Pinecone integrates with LLM providers (Cohere, Hugging Face, Jina) and cloud services (AWS Bedrock, SageMaker, GCP Marketplace) to deploy scalable GenAI applications, while observability tools (Datadog, HoneyHive) monitor performance and execution traces.
