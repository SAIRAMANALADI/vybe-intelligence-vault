# Firebase Products

## Summary

- **AI Integration**: Firebase AI Logic enables direct integration of Google's Gemini API into client apps via SDKs (Kotlin, Swift, JavaScript, Dart) for AI-powered features.

- **Database & Storage**: Supports PostgreSQL (via SQL Connect) and NoSQL (Firestore, Realtime Database) databases, with Cloud Storage for user-generated content and serverless logic via Cloud Functions.

- **Security & Deployment**: App Check secures backend resources via attestation, Authentication simplifies multi-provider user sign-in, and App Hosting/Hosting enable scalable, low-friction web app deployments with global CDN support.
