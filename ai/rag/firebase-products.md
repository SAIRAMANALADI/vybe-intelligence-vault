# Firebase Products

## Summary

- **AI Integration**: Firebase provides SDKs (Kotlin, Swift, JavaScript, Dart) to integrate Google's Gemini API directly into client apps for AI-powered features, alongside on-device ML model deployment via Firebase ML.

- **Database & Storage**: Offers globally scalable NoSQL (Firestore, Realtime Database) and relational (SQL Connect for Cloud SQL PostgreSQL) databases, with Cloud Storage for user-generated content, all backed by Google Cloud.

- **Security & Hosting**: Includes App Check for abuse protection, Authentication for multi-provider user sign-in, and Hosting/App Hosting for static/dynamic web apps with global CDN-backed deployments and GitHub-integrated CI/CD.
