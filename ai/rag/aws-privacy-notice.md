# AWS Privacy Notice

## Summary

- **Data Collection Scope**: AWS collects personal information via user-provided data, automatic interactions (e.g., cookies, logs), and third-party sources to operate, improve, and personalize AWS Offerings, excluding customer-managed content under AWS accounts.

- **Data Sharing & Security**: AWS shares personal data only for specified purposes (e.g., third-party transactions, fraud prevention) with affiliates/contractors under strict confidentiality; data is encrypted, secured per PCI DSS, and stored across multiple jurisdictions with compliance programs (e.g., AWS Cloud Security).

- **User Controls & Retention**: Users can access/update/delete account data via AWS Management Console; opt-out options exist for communications, advertising, and cookies; data retention aligns with legal obligations and stated purposes, with deletion per applicable law.
