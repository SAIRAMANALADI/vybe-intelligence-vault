# Introduction - Chroma Docs

## Summary

- **Unified Data Infrastructure**: Chroma is an open-source AI data platform supporting storage of embeddings with metadata, multi-modal retrieval (text, images, audio), and hybrid search (dense, sparse, hybrid) with any embedding model (OpenAI, Cohere, Hugging Face, etc.).

- **Advanced Query Capabilities**: Enables full-text/regex search, metadata filtering at query time, and agentic search with iterative refinement, alongside AST-aware code indexing for coding agents.

- **Deployment Flexibility**: Licensed under Apache 2.0, Chroma supports self-hosting, local deployment, or managed serverless via Chroma Cloud, with zero-ops scalability.
