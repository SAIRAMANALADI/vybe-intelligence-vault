# Introduction - Chroma Docs

## Summary

- **Multi-modal & metadata-aware vector DB**: Stores embeddings (dense/sparse) with structured metadata, enabling retrieval across text, images, and other modalities while supporting hybrid search and full-text/regex filtering.

- **Flexible embedding & search integration**: Supports any embedding model (e.g., OpenAI, Hugging Face) and provides dense, sparse, and hybrid vector search, alongside metadata filtering and AST-aware code indexing for retrieval.

- **Deployment options**: Open-source (Apache 2.0) with self-hosting, local, or managed cloud (Chroma Cloud) deployment, including serverless and scalable zero-ops configurations.
