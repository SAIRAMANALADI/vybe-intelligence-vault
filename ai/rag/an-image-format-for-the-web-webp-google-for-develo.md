# An image format for the Web | WebP | Google for Developers

## Summary

- **Compression Efficiency**: WebP achieves 26% smaller lossless images than PNGs and 25-34% smaller lossy images than JPEGs at equivalent quality, with both modes supporting transparency (lossless at 22% additional bytes).
- **Technical Implementation**: Uses predictive coding (VP8/VP8L) for lossy/lossless compression, reconstructing pixels via neighboring blocks or local palettes, and stores data in a RIFF-based container.
- **Cross-Platform Support**: Natively supported in major browsers (Chrome, Safari, Firefox, Edge, Opera) and tools/libraries, with reference implementations (`libwebp`, `cwebp`, `dwebp`) available for conversion and manipulation.
