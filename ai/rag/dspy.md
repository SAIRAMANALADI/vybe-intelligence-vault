# DSPy

## Summary

- **ReActV2 Module & LM/BaseLM Improvements**: DSPy 3.3.0b1 introduces an updated `ReActV2` module for enhanced reasoning and tool integration, alongside optimizations to the base `LM` and `BaseLM` classes for improved performance and modularity.

- **Structured Task Definition via Signatures**: Tasks are defined using typed `Signature` classes (inputs/outputs) instead of manual prompts, enabling portable, maintainable, and optimizable programs with support for multimodal fields (e.g., images) and reusable modules.

- **Automated Optimization with GEPA**: The `GEPA` optimizer compiles programs against a user-defined metric (e.g., F1 score), tuning prompts automatically to improve quality (e.g., from 62% to 89% accuracy) and reducing costs via model migration (e.g., 550× cost reduction in Shopify’s use case).
