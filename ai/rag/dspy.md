# DSPy

## Summary

- **ReActV2 Module & LM/BaseLM Improvements**: DSPy 3.3.0b1 introduces an enhanced `ReActV2` module for improved reasoning and tool integration, alongside optimizations to the base `LM` and `BaseLM` classes for better performance and modularity.

- **Structured Task Definition via Signatures**: Tasks are defined using typed `Signature` classes (inputs/outputs) instead of prompts, enabling portable, maintainable, and optimizable programs with reusable primitives like `Predict`, `ChainOfThought`, and `ReAct`.

- **Automated Optimization & Multimodal Support**: The `GEPA` optimizer compiles programs against metrics (e.g., semantic F1) to auto-tune performance, while DSPy now supports multimodal tasks via `Image` field types in signatures, enabling end-to-end vision-language workflows.
