# Change your default apps for features on iPhone and iPad - Apple Support

## Summary

- **Default App Customization**: iOS/iPadOS allows users to change default apps for web browsing, email, messaging, navigation, and other features via **Settings > Apps > Default Apps**, with regional availability for app installation (EU/Japan), call filtering (EEA, UK, etc.), and contactless apps (specific regions).
- **Regional-Specific Defaults**: In the **EU and Japan**, users may be prompted to select default browsers (EU) or search engines (Japan) via choice screens; these settings can be modified later through **Settings > Apps > Safari** or default app settings.
- **Limited Default App Support**: Some features (e.g., call filtering, contactless apps) are restricted to specific regions, and certain apps (e.g., Passwords & Codes) may require additional on-screen steps post-selection; unsupported features require developer contact.
