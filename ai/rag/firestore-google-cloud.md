# Firestore | Google Cloud

## Summary

- **MongoDB Compatibility & Wire Protocol Support**: Firestore provides MongoDB wire-compatible API, enabling seamless migration of existing MongoDB applications with full driver and ecosystem integration, including support for BSON/JSON document structures.

- **Multi-Region Replication & ACID Transactions**: Offers automatic multi-region replication with strong consistency and 99.999% SLA availability, supporting ACID-compliant multi-document transactions and serverless scaling without manual sharding.

- **Gen AI & Vector Search Integration**: Native support for vector similarity search, LangChain/LlamaIndex integrations, and MCP Toolbox for building RAG architectures, enabling scalable generative AI applications with embeddings and contextual data storage.
