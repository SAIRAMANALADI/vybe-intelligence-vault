# Run Payments with Stripe | Firebase Extensions Hub

## Summary

- **Ownership Transfer**: The Stripe Firestore extension has been officially transferred to Invertase for maintenance, as documented in [GitHub issue #524](https://github.com/invertase/stripe-firebase-extensions/issues/524).
- **Key Functionality**: The extension integrates Stripe payments with Firebase Authentication and Cloud Firestore, enabling one-time payments via Stripe Checkout and subscription management with sync to Firestore and custom claims for access control.
- **Technical Requirements**: Requires Firebase Authentication, Cloud Firestore, and a Stripe restricted API key with specific permissions; billing applies for Firestore, Cloud Functions, and Stripe services.
