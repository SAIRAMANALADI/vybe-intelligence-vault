# Run Payments with Stripe | Firebase Extensions Hub

## Summary

- **Extension Transfer**: The Stripe Firestore extension has been officially transferred to Invertase for maintenance, with migration recommended from `stripe/firestore-stripe-payments` to `invertase/firestore-stripe-payments` ([issue #524](https://github.com/invertase/stripe-firebase-extensions/issues/524)).

- **Functionality**: Enables one-time payments (Stripe Checkout) and recurring subscriptions, syncing payment status with Firebase Authentication (via custom claims) and Cloud Firestore for access control.

- **Dependencies & Billing**: Requires Cloud Firestore, Firebase Authentication, and a restricted Stripe API key; incurs costs for Firebase services (Firestore, Functions, Secret Manager, Auth), Stripe Payments/Billing, and optional Eventarc fees. Firebase project must be on the Blaze (pay-as-you-go) plan.
