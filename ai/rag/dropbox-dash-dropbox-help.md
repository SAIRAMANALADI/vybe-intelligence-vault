# Dropbox Dash - Dropbox Help

## Summary

- **Dropbox Dash** is a unified search and organization tool enabling cross-application file discovery, Stacks-based content grouping, and AI-driven summarization/question-answering across integrated SaaS platforms (e.g., Google Drive, Slack, Salesforce).

- **Protect and Control** module provides admin-level security enforcement, including policy-based access management, CSV export of activity logs, inherited permissions error resolution, and shared link oversight via a centralized dashboard.

- **Deployment & Integration** supports team-wide managed client/extension deployment, system-specific requirements (desktop/mobile), and 50+ third-party app connectors (e.g., Microsoft 365, Notion, Zoom) with service account recommendations for enterprise SaaS integrations.
