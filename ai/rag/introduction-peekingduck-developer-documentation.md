# Introduction — PeekingDuck developer documentation

## Summary

- **Open-source Python framework** for modular Computer Vision (CV) inference, leveraging Python's duck typing for flexible node interactions.

- **Pre-built SOTA CV models** (YOLO, pose estimation, tracking, etc.) with support for custom node integration and pipeline construction.

- **Six node types** (`input`, `augment`, `model`, `dabble`, `draw`, `output`) enabling sequential processing chains for real-time CV applications.
