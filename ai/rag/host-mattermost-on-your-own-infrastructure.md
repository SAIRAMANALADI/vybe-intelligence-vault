# Host Mattermost on Your Own Infrastructure

## Summary

- **Mattermost Entry Edition** (v11.8.1, released June 17, 2026) provides a free, limited-use version of Enterprise Advanced for technical evaluation, with full access unlockable via license upload.

- **Production Deployment Options**:
  - Kubernetes-based via Mattermost Operator (supports local/cloud storage and databases).
  - Cloud platforms: Azure (native integration), Oracle Cloud (OKE).
  - Linux distributions: Ubuntu (.deb packages), RHEL/CentOS (config guide), or generic 64-bit Linux (tarball).

- **Evaluation/Development Deployment**:
  - Docker containers for non-production use (no high availability support).
  - Desktop/mobile apps available for Windows, macOS, Linux, and mobile platforms (iOS/Android).
