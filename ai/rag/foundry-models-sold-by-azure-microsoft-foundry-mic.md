# Foundry Models sold by Azure - Microsoft Foundry | Microsoft Learn

## Summary

- **Model Categories & Hosting**: Foundry Models sold by Azure include Azure OpenAI models and selected third-party models, hosted and operated by Azure under the Foundry Models service, billed via Azure subscription with Microsoft SLAs and support.

- **Key Model Series & Capabilities**:
  - **GPT-5.6 Series** (`gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`): 1M+ context window, 128K max output tokens, supports reasoning, structured outputs, computer use, and multimodal inputs (text/images).
  - **GPT-5.5/5.4 Series**: High-context models (1M+ window) with reasoning, Responses API, structured outputs, and computer use; tiered quotas apply (e.g., Tier 5/6 for `gpt-5.5`).

- **Deployment & Regional Availability**: Models are deployed globally with region-specific availability; consult [Region availability for Foundry Models](https://learn.microsoft.com/en-us/azure/ai-services/openai/concepts/models-sold-directly-by-azure-region-availability) for deployment category mappings and government-specific options (Azure Government).
