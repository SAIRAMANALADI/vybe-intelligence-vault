# capnproto/capnproto

## Summary

- **Cap'n Proto**: A high-performance binary serialization and RPC framework optimized for low-latency, zero-copy data interchange, leveraging schema-driven code generation for efficient memory access patterns.

- **C++ Core Library**: Provides the foundational implementation of Cap'n Proto's serialization format and RPC system, including tools for schema compilation (`capnp`) and runtime support for message parsing/construction.

- **Zero-Copy Design**: Messages are represented as contiguous memory blocks with direct pointer dereferencing, eliminating serialization/deserialization overhead and enabling efficient cross-process or network communication.
