# Installation — MPI for Python 4.1.2 documentation

## Summary

- **Wheel Packages**: mpi4py provides pre-built binary wheels for Linux, macOS, and Windows, supporting multiple MPI implementations (MPICH, Open MPI, Intel MPI, etc.) and Python versions (CPython, PyPy), distributed via PyPI and installable via `pip install mpi4py`.

- **Conda Integration**: mpi4py is available on conda-forge with pre-built packages for MPICH, Open MPI, Intel MPI, and Microsoft MPI, enabling straightforward installation via `conda install -c conda-forge mpi4py <mpi_impl>`.

- **Source Installation**: mpi4py can be built from source using `pip install --no-binary=mpi4py mpi4py`, requiring a C compiler and a working MPI implementation with development headers.
