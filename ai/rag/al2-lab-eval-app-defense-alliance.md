# AL2 - Lab Eval | App Defense Alliance

## Summary

- **Assessment Workflow**: MASA AL2 lab evaluates public Play Store apps via human analysis using specialized tools, providing remediation feedback to developers; completion involves a validation report sent to Google for security badge eligibility (2-3 week process).

- **Developer Remediation**: If vulnerabilities are found, developers receive a test report with remediation steps and have 60 days to address issues before re-evaluation.

- **Badge Integration**: Upon validation, developers enable the "Independent Security Review" badge in Google Play Console’s Data Safety section by answering a specific question, with listings added to the [ADA Directory](https://appdefensealliance.dev/directory).
