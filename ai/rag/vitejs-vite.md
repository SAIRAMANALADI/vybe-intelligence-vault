## Summary

- **ESM-based Dev Server**: Leverages native ES modules for near-instantaneous server start and Hot Module Replacement (HMR), eliminating bundling overhead during development.

- **Optimized Production Builds**: Uses Rollup under the hood for efficient production bundling, with advanced features like code-splitting, tree-shaking, and pre-configured output formats.
