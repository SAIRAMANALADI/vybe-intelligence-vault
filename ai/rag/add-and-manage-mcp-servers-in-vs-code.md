# Add and manage MCP servers in VS Code

## Summary

- **MCP Integration**: Visual Studio Code supports the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) for connecting AI models to external tools/services (e.g., file ops, databases, APIs) via MCP servers, enabling tools, resources, prompts, and interactive apps in chat.

- **MCP Server Management**: MCP servers can be installed via the Extensions view (`@mcp` search), configured in `mcp.json` (workspace/user profile), or managed centrally; trust policies and security checks are enforced for local servers running arbitrary code.

- **Configuration & Execution**: MCP servers are defined in `mcp.json` (supports HTTP/local commands) with IntelliSense support; execution scope (local/remote) is configurable via workspace/remote settings or Dev Containers (`devcontainer.json`).
