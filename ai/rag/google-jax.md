# google/jax

## Summary

- **Automatic Differentiation & High-Performance Computing**: JAX provides composable transformations for Python+NumPy programs, enabling automatic differentiation (`grad`), vectorization (`vmap`), Just-In-Time compilation (`jit`) to GPU/TPU, and parallelization (`pmap`), leveraging XLA for optimized execution.

- **Functional Array Operations**: Implements a pure functional programming model for numerical computing, treating arrays as immutable objects and using functional transformations (e.g., `lax` operations) to ensure reproducibility and thread safety.

- **Hardware Acceleration & Ecosystem Integration**: Supports GPU/TPU acceleration via XLA, integrates with NumPy APIs for familiarity, and enables distributed computing (`shard_map`) while maintaining compatibility with Python’s scientific computing stack (e.g., TensorFlow, PyTorch via interoperability).
