# Firebase Remote Config

## Summary

- **Dynamic Configuration**: Firebase Remote Config enables server-side updates to app behavior/appearance without client app updates via parameter overrides, supporting feature flags, seasonal themes, and server-side logic via client/server SDKs.

- **Targeted & Personalized Delivery**: Supports segmentation (app version, language, GA audiences) and personalization (ML-driven A/B testing) to optimize user engagement, with rollout controls and control groups for gradual feature deployment.

- **Technical Constraints**: Enforces limits (3000 params/template, 300 versions, 24 concurrent A/B experiments/rollouts) and prohibits sensitive data storage; real-time updates via client libraries minimize polling overhead.
