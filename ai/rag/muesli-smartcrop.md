# muesli/smartcrop

## Summary

- **Algorithm**: Implements a saliency-based image cropping algorithm to identify visually important regions using edge and face detection, combined with entropy analysis for optimal crop selection.
- **Implementation**: Written in Go, leveraging OpenCV (via Go bindings) for image processing and feature extraction, with configurable parameters for crop aspect ratios and minimum saliency thresholds.
- **Optimization**: Uses a sliding window approach to evaluate potential crops, prioritizing regions with high saliency scores while ensuring adherence to specified dimensions and aspect ratios.
