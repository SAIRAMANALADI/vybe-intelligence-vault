# Cartography and Imaging Sciences Discipline Node

## Summary

- **PDS Imaging Node Services**: Curates NASA's planetary image archives (past/present/future missions), providing digital image collections, ancillary data, search tools, and cartographic expertise for terrestrial bodies (including icy satellites). Supports orbital/landed camera data processing, remote sensing (UV to RADAR), and geospatial analysis.

- **Atlas v4 Transition**: New Atlas (v4) replaces Atlas 3 with an upgraded, user-friendly search interface and [Archive Explorer](https://pds-imaging.jpl.nasa.gov/tools/atlas/archive-explorer). All datasets are now accessible via Atlas v4; legacy Atlas 3 will be decommissioned. Cloud migration may alter some links, but data availability is maintained.

- **Recent Data Releases**: Latest releases include MRO (Release #77), Juno (Release #34), Mars 2020 (Release #15), Mars Odyssey (#95), MSL (#41), and LRO (#65). New Photojournal features improved search and NASA-wide web modernization. USGS services restored; MSL data now available in PDS4 format.
