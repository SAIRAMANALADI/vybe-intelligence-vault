# gainsight-px-rest-API documentation

## Summary

- **Base URLs & Endpoints**: API endpoints are structured with base URLs per data center (US: `https://api.aptrinsic.com/v1`, EU: `https://api-eu.aptrinsic.com/v1`, US2: `https://api-us2.aptrinsic.com/v1`), supporting CRUD operations on entities (Users, Accounts, Events) and custom event management.

- **Authentication**: Access requires an `X-APTRINSIC-API-KEY` header, with API keys generated via Gainsight PX admin UI under *Administration > REST API*, supporting Read/Write/Production Launch permissions.

- **Data Format & Errors**: All requests/responses are JSON-encoded (UTF-8), with errors returned as JSON containing error codes and details.
