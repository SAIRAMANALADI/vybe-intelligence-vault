# Azure-Samples/aisearch-openai-rag-audio

## Summary

- **Implementation of VoiceRAG Pattern**: Demonstrates an interactive voice generative AI system using Retrieval-Augmented Generation (RAG) with Azure AI Search and Azure OpenAI's `gpt-4o-realtime-preview` model for real-time audio processing.

- **Technical Stack**: Built in Python, leveraging Azure AI Search for vector-based retrieval and Azure OpenAI for generative AI capabilities, enabling low-latency, context-aware voice interactions.

- **Deployment & Scalability**: Uses Azure Developer CLI (azd) templates for infrastructure-as-code deployment, supporting vector search and scalable RAG workflows for generative AI applications.
