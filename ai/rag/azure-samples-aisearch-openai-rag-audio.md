## Summary

- Implements **VoiceRAG pattern** using **Azure AI Search** and **gpt-4o-realtime-preview** for interactive voice generative AI.
- Leverages **RAG (Retrieval-Augmented Generation)** with vector embeddings for real-time audio-based retrieval and response generation.
- Built as a **Python-based** template using **Azure Developer CLI (azd)** for deployment and management.
