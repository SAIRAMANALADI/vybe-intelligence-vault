# Azure-Samples/aisearch-openai-rag-audio

## Summary

- **VoiceRAG Implementation**: Demonstrates an interactive voice generative AI system using **Retrieval-Augmented Generation (RAG)** with **Azure AI Search** and **Azure OpenAI's `gpt-4o-realtime-preview`** model for real-time audio processing.

- **Architecture**: Combines **vector database search** (Azure AI Search) with **OpenAI's gpt-4o-realtime-preview** to enable dynamic, context-aware voice responses in Python.

- **Deployment**: Uses **Azure Developer CLI (azd)** templates for infrastructure-as-code (IaC) deployment, simplifying setup of Azure resources (AI Search, OpenAI, etc.).
