# Build cross-platform desktop apps with JavaScript, HTML, and CSS | Electron

## Summary

- **Runtime Architecture**: Electron integrates Chromium for rendering and Node.js for backend APIs, enabling cross-platform desktop apps via a single JavaScript/TypeScript codebase.

- **Security & Maintenance**: Releases synchronize with Chromium updates for immediate security patches, while npm integration allows extensibility via native add-ons or frontend frameworks (React, Vue, Angular, etc.).

- **Distribution & Tooling**: Supports platform-specific installers (DMG, MSI, RPM), app store deployment (Mac/Windows/Linux), and crash reporting via `crashReporter`, with Electron Forge simplifying build/publishing workflows.
