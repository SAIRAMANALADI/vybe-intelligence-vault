# Build cross-platform desktop apps with JavaScript, HTML, and CSS | Electron

## Summary

- **Runtime Architecture**: Electron combines Chromium's rendering engine with Node.js, enabling cross-platform desktop applications using JavaScript, HTML, and CSS while maintaining native OS integration via main process APIs.

- **Security & Maintenance**: Releases are synchronized with Chromium updates for immediate security patches, and the open-source project under the OpenJS Foundation ensures community-driven stability and extensibility.

- **Tooling & Distribution**: Supports automated updates (via `autoUpdater`), platform-specific installers (DMG/MSI/RPM), app store distribution (Mac/Windows/Linux), and integrates with modern frontend frameworks (React, Vue, Angular) and build tools (Webpack, TypeScript).
