# semantic-conventions-genai/docs/gen-ai at main · open-telemetry/semantic-conventions-genai · GitHub

## Summary

- Defines OpenTelemetry semantic conventions for Generative AI (GenAI) across **events** (inputs/outputs), **exceptions**, **metrics**, **model spans**, and **agent spans** to standardize telemetry data collection.

- Provides **technology-specific conventions** for major GenAI systems, including Anthropic, Azure AI Inference, AWS Bedrock, and OpenAI.

- Includes supplementary conventions for the **Model Context Protocol (MCP)** to extend telemetry coverage for context-aware AI workflows.
