# TracecatHQ/tracecat

## Summary

- **Platform Architecture**: Tracecat is an open-source, event-driven security automation platform built with Python (FastAPI backend), Next.js (frontend), and leverages **Temporal.io** for workflow orchestration, **Pydantic** for data validation, and **OpenAPI** for API specification.

- **Core Features**: Supports low-code automation, AI agent integration via **LLM** interfaces, real-time monitoring, and security-focused workflows with **Pydantic** schema enforcement and **FastAPI** for high-performance API endpoints.

- **Technical Stack**: Uses **Temporal.io** for durable workflow execution, integrates with security tools via standardized APIs, and provides a scalable, modular design for team-based security automation and AI-driven incident response.
