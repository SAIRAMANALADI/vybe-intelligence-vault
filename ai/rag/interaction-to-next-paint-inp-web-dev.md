# Interaction to Next Paint (INP) | web.dev

## Summary

- **INP Metric Definition**: Interaction to Next Paint (INP) is a stable Core Web Vital metric assessing page responsiveness by measuring the latency of all click, tap, and keyboard interactions, reporting the longest interaction (excluding outliers) to reflect real user experience.
- **INP Calculation & Thresholds**: INP is derived from the 75th percentile of interactions, ignoring the worst 1/50th of interactions for pages with high interaction counts; thresholds are <200ms (good), 200–500ms (needs improvement), >500ms (poor).
- **Interaction Latency Components**: INP latency includes input delay (time until event handlers run), processing duration (event handler execution), and presentation delay (time until next frame is painted), with JavaScript, CSS, or browser controls driving interactivity.
