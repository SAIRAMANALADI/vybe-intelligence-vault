# microsoft/ai-agents-for-beginners

## Summary

- **Curriculum Structure**: 18 structured lessons in Jupyter Notebooks covering foundational to advanced concepts in building AI agents, including agentic RAG, multi-agent systems, and integration with frameworks like AutoGen and Semantic Kernel.

- **Technical Focus**: Emphasizes practical implementation of agentic AI patterns (e.g., tool use, planning, memory) using Microsoft’s Foundry framework, with hands-on exercises for local deployment and scalability.

- **Tooling & Integration**: Demonstrates agent development with Microsoft’s Foundry SDK, local LLM execution, and compatibility with generative AI models, including semantic kernel orchestration and multi-agent collaboration workflows.
