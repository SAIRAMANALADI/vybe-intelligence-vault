# microsoft/ai-agents-for-beginners

## Summary

- **Educational Repository**: Provides 18 structured lessons to introduce AI agent development, covering foundational to advanced concepts in agentic AI, including frameworks like AutoGen and Semantic Kernel.
- **Technical Stack**: Primarily uses Jupyter Notebooks, with integration of Microsoft’s Foundry for local agentic RAG (Retrieval-Augmented Generation) and generative AI workflows.
- **Key Topics**: Focuses on agentic AI, agentic RAG, AI agent frameworks, and Microsoft-specific tools (Foundry, Semantic Kernel) for building autonomous agents.
