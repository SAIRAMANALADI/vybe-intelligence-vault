# neondatabase/neon

## Summary

- **Architecture**: Separates PostgreSQL compute and storage layers to enable autoscaling, branching (via logical replication), and "scale-to-zero" compute nodes for cost efficiency.
- **Implementation**: Written in Rust, leveraging PostgreSQL’s extensibility (e.g., `pg_` components) and custom storage engine for ephemeral compute instances.
- **Features**: Supports branchable databases (via WAL shipping), serverless APIs, and multi-tenant isolation with shared storage backend (e.g., S3-compatible object storage).
