# Pinecone Assistant - Pinecone Docs

## Summary

- **Service Overview**: Pinecone Assistant enables rapid deployment of production-grade chat/agent applications with proprietary data integration via vector database and LLM grounding, supporting both Python and Node.js SDKs.

- **Core Workflow**: Three-step process—(1) create assistant with custom instructions/metadata, (2) upload/process documents (auto-chunked/embedded), (3) query via chat API returning JSON/text streams with citations and token usage metrics.

- **Advanced Features**: Supports response evaluation (alignment/correctness metrics), context snippet retrieval, and performance optimization via metadata filtering/custom instructions for RAG/agentic workflows.
