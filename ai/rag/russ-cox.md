# Russ Cox

## Summary

- **Go Programming Language**: Primary contributor to [The Go Programming Language](http://golang.org/), an open-source statically typed, compiled language designed for simplicity, concurrency, and systems programming.
- **Plan 9 OS Contributions**: Key developer for [Plan 9 from Bell Labs](http://plan9.bell-labs.com/plan9), a distributed, Unix-like operating system emphasizing simplicity, modularity, and per-process namespaces; also maintains [Plan 9 from User Space](http://swtch.com/plan9port) (Plan 9 on Unix).
- **Research Focus**: Published work on lightweight sandboxing ([Vx32](https://swtch.com/~rsc/papers/vx32-usenix2008.pdf)), decentralized network coordinates ([Vivaldi](http://www.pdos.lcs.mit.edu/papers/vivaldi:sigcomm/paper.pdf)), and extensible compilers ([Xoc](https://swtch.com/~rsc/papers/xoc-asplos2008.pdf)).
