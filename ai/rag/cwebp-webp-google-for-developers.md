# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr, with advanced options for quality tuning (`-q`, `-lossless`, `-near_lossless`), method control (`-m`, `-z`), and alpha channel handling (`-alpha_q`, `-alpha_method`).
- Supports image manipulation (cropping via `-crop`, resizing via `-resize`) and fine-tuning compression via spatial noise shaping (`-sns`), deblocking filter strength (`-f`), and sharpness (`-sharpness`), with multi-threading (`-mt`) and memory optimization (`-low_memory`).
- Output control includes specifying filenames (`-o`), suppressing output (`-quiet`), and logging metrics like PSNR (`-print_psnr`) or SSIM (`-print_ssim`), with additional options for metadata handling (`-metadata`) and raw Y'CbCr input (`-s`).
