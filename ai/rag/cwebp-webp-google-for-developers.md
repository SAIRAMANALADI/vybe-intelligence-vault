# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression from formats like PNG, JPEG, and TIFF, with fine-grained control via options such as `-q` (quality, 0-100), `-lossless`, `-preset` (e.g., "photo", "icon"), and `-m` (method, 0-6 for speed/quality trade-offs).
- Supports advanced features including cropping (`-crop`), resizing (`-resize`), multi-threading (`-mt`), and noise shaping (`-sns`), with additional lossy-specific controls like `-size` (target byte size), `-psnr` (target PSNR), and `-f` (deblocking filter strength, 0-100).
- Includes metadata handling (`-metadata`), alpha channel options (`-alpha_q`, `-alpha_method`), and logging flags (`-v`, `-print_ssim`), while raw Y'CbCr input (`-s`) and assembly optimizations (`-noasm`) are supported for specialized use cases.
