# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr, with advanced encoding options such as quality (`-q`), lossless mode (`-lossless`), and multi-threading (`-mt`).
- Supports image manipulation (cropping via `-crop`, resizing via `-resize`) and fine-tuning compression with parameters like deblocking filter strength (`-f`), sharpness (`-sharpness`), and spatial noise shaping (`-sns`).
- Output control includes specifying filenames (`-o`), suppressing output (`-quiet`), and logging metrics (PSNR via `-print_psnr`, SSIM via `-print_ssim`), with additional options for raw Y'CbCr input (`-s`) and metadata handling (`-metadata`).
