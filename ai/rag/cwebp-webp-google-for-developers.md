# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr, with advanced options for quality (`-q`), lossless mode (`-lossless`), and presets (`-preset`).
- Supports image manipulation (cropping via `-crop`, resizing via `-resize`) and fine-tuning compression (e.g., filter strength `-f`, sharpness `-sharpness`, noise shaping `-sns`) with multi-threading (`-mt`) and memory optimization (`-low_memory`).
- Output control includes specifying filenames (`-o`), suppressing logs (`-quiet`), and advanced encoding metrics (PSNR via `-print_psnr`, SSIM via `-print_ssim`), with raw Y'CbCr input support (`-s width height`).
