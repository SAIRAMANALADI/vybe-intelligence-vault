# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression from formats like PNG, JPEG, and TIFF, supporting quality control (`-q`), lossless mode (`-lossless`), and presets (`-preset photo/icon`).
- Advanced features include spatial noise shaping (`-sns`), deblocking filter strength (`-f`), multi-threading (`-mt`), and image manipulation options like cropping (`-crop`) and resizing (`-resize`).
- Supports fine-tuning via PSNR targeting (`-psnr`), size constraints (`-size`), and metadata preservation (`-metadata exif,icc,xmp`), with logging options (`-v`, `-quiet`) for performance/debugging.
