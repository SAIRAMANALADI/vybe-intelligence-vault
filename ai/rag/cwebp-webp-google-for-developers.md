# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr, with advanced options for quality tuning (`-q`), lossless mode (`-lossless`), and method control (`-m`).
- Supports image manipulation (cropping `-crop`, resizing `-resize`) and fine-tuning via deblocking (`-f`), sharpness (`-sharpness`), noise shaping (`-sns`), and multi-threading (`-mt`).
- Output control includes specifying output file (`-o`), suppressing output (`-quiet`), and metadata handling (`-metadata`), with additional options for raw Y'CbCr input (`-s`) and alpha channel processing.
