# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression from formats like PNG, JPEG, or TIFF, with fine-grained control via options such as `-q` (quality), `-lossless`, `-preset`, `-f` (filter strength), and `-sns` (spatial noise shaping).
- Supports image manipulation (cropping via `-crop`, resizing via `-resize`) and advanced encoding tweaks (e.g., `-mt` for multi-threading, `-sharp_yuv` for RGB→YUV conversion, `-partition_limit` for bit allocation control).
- Output and performance are configurable via `-o` (output file/stdout), `-quiet` (suppress logs), `-v` (verbose), and metadata handling (`-metadata` for EXIF/ICC/XMP).
