# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr, with advanced options for quality control (`-q`, `-lossless`, `-near_lossless`), method tuning (`-m`, `-z`), and metadata handling (`-metadata`).
- Supports image manipulation via `-crop`, `-resize`, and alpha channel operations (`-alpha_q`, `-alpha_filter`, `-noalpha`), along with fine-tuning filters (`-f`, `-sharpness`, `-sns`) and multi-threading (`-mt`).
- Output control includes `-o` (file output), `-quiet` (suppress logs), and logging metrics (`-print_psnr`, `-print_ssim`), with raw Y'CbCr input via `-s width height` and assembly optimization toggling (`-noasm`).
