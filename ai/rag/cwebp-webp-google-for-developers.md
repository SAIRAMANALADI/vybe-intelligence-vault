# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr samples (excluding animated PNG/WebP).
- Key options include `-q` (quality, 0-100), `-lossless` (lossless mode), `-preset` (predefined settings), `-crop`/`resize` (spatial manipulation), and advanced tuning flags like `-f` (deblocking filter), `-sns` (noise shaping), and `-mt` (multi-threading).
- Output control is managed via `-o` (output file/stdout), `-quiet` (suppress logs), and logging metrics like `-print_psnr`/`-print_ssim`; additional flags enable raw input (`-s`), alpha handling (`-alpha_method`), and metadata preservation (`-metadata`).
