# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr samples (excluding animated files).
- Key compression controls include `-q` (quality, 0-100), `-lossless` (lossless mode), `-preset` (predefined settings like "photo" or "icon"), and advanced tuning options like `-f` (deblocking filter strength) and `-sns` (spatial noise shaping).
- Additional features include image manipulation (`-crop`, `-resize`), multi-threading (`-mt`), metadata handling (`-metadata`), and fine-tuning via lossy-specific options (`-size`, `-psnr`, `-partition_limit`).
