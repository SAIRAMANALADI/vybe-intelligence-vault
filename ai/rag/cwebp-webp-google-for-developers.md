# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for converting PNG, JPEG, TIFF, or raw Y'CbCr images to WebP format, supporting both lossy and lossless compression with fine-grained control via options like `-q` (quality), `-lossless`, `-m` (method), and `-z` (compression level).
- Advanced features include spatial noise shaping (`-sns`), deblocking filter strength (`-f`), cropping (`-crop`), resizing (`-resize`), multi-threading (`-mt`), and metadata preservation (`-metadata`).
- Additional options allow for PSNR/SSIM reporting (`-print_psnr`, `-print_ssim`), progress tracking (`-progress`), and raw Y'CbCr input (`-s`), with logging controls (`-quiet`, `-v`) for debugging.
