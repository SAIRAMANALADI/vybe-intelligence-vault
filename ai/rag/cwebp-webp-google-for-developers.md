# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a command-line tool for lossy/lossless WebP image compression, supporting input formats like PNG, JPEG, TIFF, and raw Y'CbCr, with advanced options for quality control (`-q`), lossless mode (`-lossless`), and method tuning (`-m`, `-z`).
- Supports basic image manipulation (`-crop`, `-resize`) and fine-tuning via advanced flags (`-f` for deblocking, `-sns` for noise shaping, `-sharpness` for filtering) with multi-threading (`-mt`) and memory optimization (`-low_memory`).
- Output control includes specifying filenames (`-o`), suppressing output (`-quiet`), and logging metrics (`-print_psnr`, `-print_ssim`), with additional options for raw Y'CbCr input (`-s`) and metadata handling (`-metadata`).
