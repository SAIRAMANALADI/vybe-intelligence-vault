# cwebp | WebP | Google for Developers

## Summary

- `cwebp` is a CLI tool for lossy/lossless WebP image compression from formats like PNG, JPEG, or TIFF, with fine-grained control via options such as `-q` (quality, 0-100), `-lossless`, `-preset` (e.g., `photo`, `icon`), and `-m` (method, 0-6).
- Supports image manipulation (cropping with `-crop`, resizing with `-resize`) and advanced encoding tweaks like deblocking filter strength (`-f`), noise shaping (`-sns`), and multi-threading (`-mt`).
- Output and performance are configurable via `-o` (output file/stdout), `-size` (target file size), `-pass` (encoding passes), and logging controls (`-quiet`, `-v`, `-print_psnr`).
