# Android is Compose-first | Jetpack Compose | Android Developers

## Summary

- **Jetpack Compose** is Android's modern, declarative UI toolkit replacing the legacy View system, offering dynamic data binding, rich graphics, and animations with native performance and adaptive layouts across devices.

- **Legacy View-based libraries** (e.g., `RecyclerView`, `ConstraintLayout`, `Fragment`) and tools (e.g., Navigation Editor, Layout Editor) are now in **maintenance mode**, receiving only critical fixes while new development focuses exclusively on Compose.

- **Compose-first development** means all new Android Studio tools, documentation, and libraries prioritize Jetpack Compose, with interop APIs available for gradual migration; samples and guidance are being updated to reflect this shift.
