# Documentation Overview - TACC HPC Documentation

## Summary

- **TACC Account Management**: Requires Multi-Factor Authentication (MFA) setup via authentication apps or SMS; deactivated accounts must be reactivated via the TACC Accounts Portal; login issues often stem from improper SSH configuration or VSCode integration.

- **File System & Job Conduct**: Avoid running jobs on login nodes; adhere to scratch file system purge policies (e.g., `/scratch1` auto-deletion after 90 days); limit I/O activity and use `rsync`/`Globus` for large data transfers to prevent system stress.

- **HPC Resource Specifications**: Frontera’s Cascade Lake nodes (CLX) feature 56-core Xeon Platinum 8280 processors; GPU nodes include NVIDIA V100 (32GB) and A100 (40GB) options; Corral supports object storage with HIPAA-PHI compliance and quotas enforced per project.
