# Coverage.py — Coverage.py 7.14.3 documentation

## Summary

- **Purpose & Functionality**: Coverage.py is a Python tool for measuring code coverage by tracking executed code paths and identifying untested segments, primarily used to assess test suite effectiveness.
- **Supported Environments**: Compatible with Python 3.10–3.15 (including free-threading) and PyPy3 3.10/3.11, with enterprise support via Tidelift for commercial-grade usage.
- **Key Features**: Supports line/branch coverage, multi-format reporting (text/HTML/XML/LCOV/JSON), dynamic context tracking, SQLite-based data storage, and integration with test runners like pytest.
