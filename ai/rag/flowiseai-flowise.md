## Summary

- **Visual AI Agent Builder**: Open-source, low/no-code TypeScript framework for constructing AI agents and multi-agent systems with drag-and-drop workflows, leveraging LangChain and React for modular agentic architectures.

- **Multi-Model & Tool Integration**: Supports OpenAI, RAG, and custom LLM integrations with built-in connectors for vector databases, APIs, and external tools, enabling dynamic agent-environment interactions.
