# FlowiseAI/Flowise

## Summary

- **Visual AI Agent Builder**: Open-source, low/no-code TypeScript framework for constructing AI agents and multi-agent systems with drag-and-drop workflows, leveraging LangChain and React for modular agentic workflows.

- **Multi-Model & Tool Integration**: Supports OpenAI, RAG, and custom LLM integrations with built-in connectors for databases, APIs, and external tools, enabling dynamic agent interactions and workflow automation.

- **Self-Hosted & Scalable**: Deployable via Docker/Node.js with real-time monitoring, supports TypeScript/JavaScript agent development, and scales for enterprise-grade multi-agent orchestration.
