# FlowiseAI/Flowise

## Summary

- **FlowiseAI/Flowise**: Open-source, low/no-code TypeScript framework for building AI agents and workflows with visual drag-and-drop interface, leveraging LangChain and React for modular agentic AI development.

- **Key Features**: Supports multi-agent systems, RAG (Retrieval-Augmented Generation), OpenAI integrations, and agentic workflow automation with JavaScript/TypeScript-based custom nodes and APIs.

- **Architecture**: Built on Node.js with TypeScript, enabling rapid prototyping of AI agents via visual editor while supporting extensibility through custom components and integrations with LLMs and tools.
