# FlowiseAI/Flowise

## Summary

- **Low-code/No-code Platform**: FlowiseAI enables visual construction of AI agents and workflows using a React-based UI, abstracting complex AI integrations (e.g., LangChain, OpenAI) for non-technical users while supporting customization via TypeScript/JavaScript.

- **Multi-Agent & Workflow Automation**: Supports agentic AI systems with modular components for RAG (Retrieval-Augmented Generation), chatbots, and multi-agent collaborations, enabling dynamic, automated decision-making pipelines.

- **Extensible Architecture**: Built in TypeScript with pluggable integrations (e.g., LLMs, vector databases), Flowise allows developers to extend functionality via custom nodes, APIs, and third-party service connectors.
