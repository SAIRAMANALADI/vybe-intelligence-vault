# FlowiseAI/Flowise

## Summary

- **Visual AI Agent Builder**: Open-source, low/no-code TypeScript framework for constructing AI agents and workflows via drag-and-drop interface, leveraging LangChain and React for modular agentic systems.

- **Multi-Model & Tool Integration**: Supports LLMs (e.g., OpenAI, HuggingFace), RAG pipelines, and multi-agent orchestration with pre-built connectors for APIs, databases, and third-party services.

- **Deployment & Scalability**: Dockerized for cross-platform execution; enables rapid prototyping and production deployment of agentic workflows with built-in monitoring and extensibility via custom nodes.
