# Find information about your Windows device | Microsoft Support

## Summary

- **Device Identification**: Device name and model can be retrieved via `ms-settings:about` or **Settings > System > About**; model details appear under the device name.
- **Windows Version & Specs**: Edition, version, and OS architecture (32/64-bit) are listed under **Windows specifications** in **Settings > System > About**; processor and RAM details are in **Device specifications**.
- **Storage Overview**: Total and used storage per drive can be accessed via `ms-settings:storagerecommendations` or **Settings > System > Storage**; multi-drive details require **Advanced storage settings**.
