# eosphoros-ai/DB-GPT

## Summary

- **Agentic AI Data Assistant**: DB-GPT is an open-source framework designed to act as an autonomous agentic AI assistant for database interactions, enabling next-gen AI + Data products with minimal human intervention.

- **Multi-Model & RAG Integration**: Supports integration with multiple LLMs (e.g., GPT-4, DeepSeek, Vicuna) and employs Retrieval-Augmented Generation (RAG) for secure, private, and context-aware database querying without exposing raw data externally.

- **Security & Extensibility**: Implements role-based access control (RBAC) and encryption for database security, while offering modular architecture for custom agentic workflows, pluggable LLMs, and support for structured/unstructured data processing.
