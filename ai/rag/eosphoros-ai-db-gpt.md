# eosphoros-ai/DB-GPT

## Summary

- **Agentic AI Framework**: DB-GPT is an open-source framework designed as an agentic AI data assistant, enabling autonomous interaction with databases using LLMs (e.g., GPT-4, DeepSeek, Vicuna) for next-gen AI + Data applications.

- **Privacy & Security Focus**: Supports private, secure data processing with RAG (Retrieval-Augmented Generation) integration, ensuring sensitive database queries remain isolated from public cloud dependencies.

- **Multi-LLM & Plugin Ecosystem**: Compatible with multiple LLMs (GPT-4, DeepSeek, etc.), includes plugin support (e.g., BGI), and is optimized for hacktoberfest contributions, facilitating extensibility for database agents.
