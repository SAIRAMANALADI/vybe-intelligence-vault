# Training Overview — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with optional PyTorch CUDA support for GPU acceleration.

- **Core Functionality**: Provides `SentenceTransformer` (bi-encoder), `CrossEncoder` (cross-attention), and `SparseEncoder` for embedding generation, semantic search, clustering, and retrieval-re-ranking pipelines.

- **Training & Optimization**: Includes fine-tuning frameworks with modular components (model, dataset, loss, evaluator), supports quantization (binary/int8), and multi-GPU inference for efficiency.
