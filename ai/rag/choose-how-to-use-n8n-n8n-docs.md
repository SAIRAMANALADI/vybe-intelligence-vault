# Choose how to use n8n | n8n Docs

## Summary

- **Deployment Options**: n8n offers two primary deployment models: **n8n Cloud** (fully-managed, no setup required) and **Self-hosted** (requires infrastructure management), each with distinct plans/editions (e.g., Cloud: Starter/Pro/Enterprise; Self-hosted: Community/Registered Community/Business/Enterprise).

- **Feature Availability**: Core features are available in all plans, but advanced capabilities (e.g., SSO, environments, multi-main mode, external secrets) require paid plans/editions; Community edition is free but limited.

- **Use Case Alignment**: Cloud is ideal for quick setup, managed infrastructure, and non-technical users, while self-hosted suits custom deployments, full control, and cost-free options (Community edition).
