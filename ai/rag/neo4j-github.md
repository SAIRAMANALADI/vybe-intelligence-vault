# Neo4j · GitHub

## Summary

- **Neo4j Core Engine**: Open-source graph database implemented in Java (`neo4j/neo4j`), supporting ACID transactions, Cypher query language, and native graph storage with 16.9k stars and 2.7k forks.

- **Multi-Language Driver Ecosystem**: Provides Bolt protocol drivers for Java (`neo4j-java-driver`), JavaScript (`neo4j-javascript-driver`), Python (`neo4j-python-driver`), and Scala (`neo4j-spark-connector`) for seamless graph database integration.

- **Graph Data Science & OGM Libraries**: Includes `graph-data-science` (Java-based graph algorithms) and `neo4j-ogm` (Java Object-Graph Mapping) with Apache-2.0 licensing, supporting advanced analytics and ORM-style interactions.
