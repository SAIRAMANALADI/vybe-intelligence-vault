# Neo4j · GitHub

## Summary

- **Neo4j** is a graph database management system with core Java-based implementation, providing native graph storage and processing via the Cypher query language.

- **Key repositories** include the main `neo4j` database engine, `graph-data-science` (graph algorithms library), and language-specific Bolt drivers (Java, JavaScript, Python) for database connectivity.

- **Additional tools** encompass the Neo4j Object-Graph Mapping (OGM) library, APOC (standard procedures library), and connectors for AWS Glue and Google Dataflow.
