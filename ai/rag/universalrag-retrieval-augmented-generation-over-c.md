# UniversalRAG: Retrieval-Augmented Generation over Corpora of Diverse Modalities and Granularities

## Summary

- **UniversalRAG Framework**: Introduces an any-to-any retrieval-augmented generation (RAG) system that dynamically retrieves and integrates knowledge from heterogeneous, multi-modal sources (e.g., text, images, videos) with varying granularities, addressing limitations of single-modality or unified-corpus approaches.

- **Modality-Aware Routing**: Mitigates the *modality gap* problem by using dynamic routing to select the most relevant modality-specific corpus for retrieval, avoiding suboptimal performance from forcing all modalities into a single representation space; theoretical analysis supports its effectiveness.

- **Granularity-Level Organization**: Structures each modality into multiple granularity tiers (e.g., document vs. paragraph vs. sentence) to enable fine-grained retrieval tailored to query complexity, validated across 10 benchmarks where UniversalRAG outperforms modality-specific and unified baselines.
