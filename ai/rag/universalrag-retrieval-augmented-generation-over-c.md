# UniversalRAG: Retrieval-Augmented Generation over Corpora of Diverse Modalities and Granularities

## Summary

- **UniversalRAG Framework**: Introduces an any-to-any RAG system that retrieves and integrates knowledge from heterogeneous sources with diverse modalities (e.g., text, images, videos) and granularities, addressing limitations of single-modality RAG approaches.

- **Modality-Aware Routing**: Implements dynamic routing to select the most relevant modality-specific corpus for retrieval, mitigating the *modality gap* issue where retrieval favors items from the same modality as the query, supported by theoretical analysis.

- **Granularity-Based Retrieval**: Organizes each modality into multiple granularity levels to enable fine-tuned retrieval tailored to query complexity and scope, validated across 10 benchmarks where UniversalRAG outperforms modality-specific and unified baselines.
