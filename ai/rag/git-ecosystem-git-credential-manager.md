# git-ecosystem/git-credential-manager

## Summary

- **Cross-platform credential management**: Provides secure storage and retrieval of Git credentials across Windows, macOS, and Linux, supporting multiple authentication methods (OAuth, PAT, SSH keys) for seamless integration with Git hosting services.

- **Multi-service authentication**: Facilitates authentication with GitHub, Azure Repos, Bitbucket, GitLab, and other platforms via Azure Active Directory (AAD) and other identity providers, reducing manual credential input.

- **CLI and GUI integration**: Operates as a Git credential helper (`git credential-manager`) with optional GUI workflows for interactive authentication, caching credentials securely in system-native stores (e.g., Windows Credential Manager, macOS Keychain).
