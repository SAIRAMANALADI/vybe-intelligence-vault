# beam-cloud/beta9

## Summary

- **Ultrafast Serverless GPU Inference**: Enables high-performance, low-latency GPU-based inference for ML models (e.g., LLMs) via a serverless architecture, leveraging CUDA for acceleration.

- **Sandboxed Execution & Background Jobs**: Provides isolated, ephemeral environments for secure code execution (sandboxes) and supports long-running background tasks (e.g., fine-tuning, batch processing).

- **Self-Hosted FaaS/PaaS Platform**: Built in Go, integrates with CloudRun for autoscaling, supports distributed computing, and offers self-hosted deployment for GPU workloads (e.g., generative AI, LLM inference).
