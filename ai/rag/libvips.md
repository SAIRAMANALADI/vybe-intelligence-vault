# libvips

## Summary

- **Demand-driven, horizontally threaded** image processing library optimized for speed and low memory usage, supporting **300+ operations** (arithmetic, convolution, color, resampling, etc.) across **8-bit to 128-bit numeric types** and **any number of bands**.
- **Extensive format support** (JPEG, PNG, WebP, HEIC, AVIF, TIFF, PDF, SVG, DICOM via ImageMagick/GraphicsMagick) with **bindings for C, C++, CLI, Ruby, Python, PHP, .NET, Go, Lua, Crystal, Elixir, Java, and Nim**.
- **Actively maintained** with CI/CD pipelines, OSS Fuzz integration, and pre-compiled binaries for Windows/macOS/Linux; used in production by **Mastodon, sharp (Node.js), imgproxy, and MediaWiki**.
