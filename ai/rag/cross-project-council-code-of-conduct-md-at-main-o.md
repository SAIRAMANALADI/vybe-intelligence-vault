# cross-project-council/CODE_OF_CONDUCT.md at main · openjs-foundation/cross-project-council · GitHub

## Summary

- **Reporting Mechanism**: Incident reports for OpenJS projects are managed either by project-specific contacts (e.g., `code-of-conduct@amp.dev` for AMP) or escalated to the OpenJS Foundation's Code of Conduct Team (`coc@openjsf.org`) for unresolved conflicts, cross-project issues, or emergencies.
- **Code of Conduct Enforcement**: Violations are addressed via a 4-tier ladder: (1) private warnings, (2) temporary activity restrictions, (3) temporary suspension, or (4) permanent bans, with repair actions (e.g., apologies, reflection) tailored to incident severity.
- **Scope & Confidentiality**: The Code of Conduct applies to all community spaces and official representations, with investigations handled confidentially under GDPR-compliant policies, exempting shared incident details from confidentiality restrictions.
