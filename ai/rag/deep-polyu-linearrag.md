# DEEP-PolyU/LinearRAG

## Summary

- **Linear Graph Retrieval Augmented Generation (LinearRAG)**: Introduces a novel RAG framework leveraging linear graph structures for efficient retrieval in large-scale corpora, optimizing LLM performance by reducing computational overhead while maintaining retrieval accuracy.

- **Scalable Graph Construction**: Implements a linear-time graph construction algorithm that transforms unstructured text corpora into a graph-based index, enabling efficient subgraph retrieval and dynamic updates without full graph recomputation.

- **Performance Benchmarks**: Demonstrates state-of-the-art results on retrieval and generation tasks, achieving up to 3.2x speedup in inference time and 15% improvement in answer correctness compared to traditional RAG baselines on large-scale datasets.
