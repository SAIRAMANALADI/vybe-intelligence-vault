# android Git repositories - Git at Google

## Summary

- **Git Repository Hosting**: Android's official Git repositories are hosted at `https://android.googlesource.com/`, providing version-controlled access to AOSP (Android Open Source Project) and related projects, including device-specific kernels, hardware support, and accessory frameworks.

- **Device-Specific Branches & Kernels**: Repository list includes device-specific directories (e.g., `/device/google/bluejay/`, `/device/google/bluejay-kernel/`) with per-device Linux kernel branches (e.g., `5.10`, `6.1`) and SELinux policy configurations, enabling hardware-specific Android builds and security policies.

- **Code Review & Access Control**: Gerrit-based code review at `https://android-review.googlesource.com/` with OAuth2 authentication (`https://accounts.google.com/o/oauth2/auth`) for secure access, password generation, and revocation, ensuring controlled contributions to AOSP and related projects.
