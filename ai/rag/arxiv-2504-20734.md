# [2504.20734] UniversalRAG: Retrieval-Augmented Generation over Corpora of Diverse Modalities and Granularities

## Summary

- **Modality-Aware Routing**: UniversalRAG introduces a dynamic routing mechanism to select the most relevant modality-specific corpus (e.g., text, images, videos) for retrieval, mitigating the "modality gap" problem where unified embedding spaces favor same-modality retrieval.

- **Multi-Granularity Retrieval**: The framework organizes corpora into hierarchical granularity levels (e.g., document → paragraph → sentence), enabling fine-grained retrieval tailored to query complexity and scope.

- **Performance Validation**: Evaluated on 10 benchmarks across modalities, UniversalRAG outperforms both modality-specific and unified RAG baselines, demonstrating robustness in heterogeneous knowledge integration.
