# 🧑‍🍳 Cookbook | Haystack

## Summary

- **Agentic RAG Integration**: Demonstrates advanced RAG pipelines leveraging agents for dynamic query decomposition, structured metadata enrichment, and hybrid retrieval (dense/sparse embeddings) using tools like FastEmbed, Qdrant, and HyDE for improved accuracy.
- **Multimodal & Cross-Domain Workflows**: Showcases multimodal text generation, OpenStreetMap integration for itinerary planning, and domain-aware agents (e.g., UI/UX reviewers) with custom tooling, retry/fallback mechanisms, and MCP (Model Context Protocol) for tool orchestration.
- **Observability & Deployment**: Covers RAG evaluation frameworks (RAGAS, DeepEval, Prometheus 2), AI guardrails for safety moderation, and scalable deployment patterns using vLLM/NVIDIA NIMs, with observability via Arize Phoenix for tracing and performance monitoring.
