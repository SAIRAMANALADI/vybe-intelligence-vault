# Quickstart — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with optional CUDA-enabled PyTorch for GPU acceleration.
- **Model Types & Applications**: Provides `SentenceTransformer` (bi-encoders), `CrossEncoder` (cross-encoders), and `SparseEncoder` for tasks like semantic search, clustering, paraphrase mining, and multimodal (text/image/audio) embeddings.
- **Training & Optimization**: Includes modular training pipelines with configurable loss functions, evaluators, and optimizations (PyTorch/ONNX/OpenVINO) for efficiency; supports multi-dataset training and deprecated workflows.
