# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool for extracting AI-ready structured data (HTML, JSON, Markdown) from PDFs, supporting OCR for scanned documents and accessibility compliance (PDF/UA, WCAG).

- **Advanced Document Processing**: Features include bounding box detection, table extraction, tagged PDF support, and conversion to accessible formats for AI/ML pipelines (RAG applications).

- **Automation & Integration**: Enables automated PDF accessibility remediation with output formats optimized for downstream AI tasks, including bounding box annotations and OCR recognition.
