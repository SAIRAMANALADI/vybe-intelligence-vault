# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF parser** designed for AI-ready data extraction, supporting accessibility compliance (PDF/UA, WCAG) via OCR, bounding-box analysis, and tagged PDF processing.
- **Multi-format output** generation (HTML, JSON, Markdown) with table detection, structured data extraction, and document layout preservation for downstream AI/ML applications.
- **Open-source tool** optimized for automation in document accessibility workflows, integrating with RAG pipelines and supporting OCR recognition for scanned or non-text PDFs.
