# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed for AI-ready data extraction from PDFs, supporting accessibility compliance (PDF/UA, WCAG) and automated tagging.
- **Multi-format Output**: Converts PDFs to HTML, JSON, Markdown, or bounding-box annotations, with OCR support for scanned documents and structured table extraction.
- **AI Integration**: Enables RAG pipelines via extracted metadata, bounding boxes, and semantic content; optimized for document parsing in AI/ML workflows.
