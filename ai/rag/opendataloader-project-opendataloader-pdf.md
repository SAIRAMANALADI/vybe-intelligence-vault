# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool (`opendataloader-pdf`) designed to extract and convert PDF content into AI-ready formats (HTML, JSON, Markdown) with support for accessibility standards (PDF/UA, WCAG).

- **Advanced Features**: Supports OCR for scanned PDFs, structured table extraction, bounding-box detection, and tagged PDF parsing for semantic document analysis.

- **Integration & Compliance**: Enables automation of PDF accessibility workflows, supports RAG pipelines, and aligns with EAA (European Accessibility Act) requirements.
