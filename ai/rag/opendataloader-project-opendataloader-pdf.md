# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed for AI-ready data extraction from PDFs, supporting accessibility compliance (e.g., PDF/UA) and automation of document processing workflows.

- **Multi-format Output**: Converts PDF content into structured formats (HTML, JSON, Markdown) with OCR support for scanned documents, including table extraction and bounding-box annotations.

- **AI & RAG Integration**: Enables tagged PDF parsing for retrieval-augmented generation (RAG) applications, optimizing document accessibility for AI-driven systems.
