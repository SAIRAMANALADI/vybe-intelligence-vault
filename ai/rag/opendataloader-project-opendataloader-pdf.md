# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool (`opendataloader-pdf`) for extracting AI-ready structured data from PDFs, supporting formats like HTML, JSON, Markdown, and bounding-box annotations.

- **Accessibility & OCR Features**: Implements PDF/UA standards, OCR recognition, and tagged-PDF parsing to automate document accessibility and table extraction.

- **Integration & Output**: Supports RAG pipelines, converts PDFs to accessible formats (e.g., HTML/JSON), and handles OCR for non-textual content. Last updated Aug 2026.
