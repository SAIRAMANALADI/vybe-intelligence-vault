# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed to automate PDF accessibility and extraction into AI-ready formats (HTML, JSON, Markdown) with OCR support for scanned documents.
- **Tagged PDF & UA Compliance**: Supports structured PDF parsing (Tagged PDF, PDF/UA) with bounding-box detection for tables, text, and layout elements.
- **AI Integration & RAG**: Enables document parsing for Retrieval-Augmented Generation (RAG) pipelines, optimizing PDF data for AI/ML workflows.
