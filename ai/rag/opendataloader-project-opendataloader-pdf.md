# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed to automate PDF accessibility and extraction, supporting formats like HTML, JSON, Markdown, and tagged PDFs for AI-ready data processing.

- **OCR & Bounding Box Support**: Integrates OCR recognition and bounding-box detection for extracting structured content (e.g., tables, text blocks) from scanned or complex PDFs.

- **Accessibility & Compliance**: Ensures PDF/UA and WCAG (EAA) compliance, enabling automated remediation for screen readers and assistive technologies.
