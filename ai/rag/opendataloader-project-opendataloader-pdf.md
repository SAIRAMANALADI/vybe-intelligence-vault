# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF parser** designed for AI-ready data extraction, supporting accessibility compliance (PDF/UA, WCAG) and automated tagging for structured content.
- **Multi-format output** including HTML, JSON, Markdown, with OCR support for scanned/non-textual PDFs and bounding-box detection for layout analysis.
- **Enterprise features** such as table extraction, RAG (Retrieval-Augmented Generation) compatibility, and integration with document processing pipelines.
