# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF parser** designed for AI-ready data extraction, supporting accessibility standards (e.g., PDF/UA, WCAG) and structured formats (HTML, JSON, Markdown).
- **Advanced features** include OCR for scanned PDFs, bounding-box detection, table extraction, and tagged-PDF support for semantic document parsing.
- **Open-source tool** with 28.9K+ stars, enabling automated PDF-to-accessible-data conversion for AI/RAG pipelines and document processing workflows.
