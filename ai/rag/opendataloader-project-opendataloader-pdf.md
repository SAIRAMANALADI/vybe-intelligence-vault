# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool for extracting AI-ready data from PDFs, supporting accessibility (a11y, PDF/UA) and structured formats (HTML, JSON, Markdown).

- **Advanced Features**: Includes OCR, bounding-box detection, table extraction, and tagged-PDF support for high-fidelity document parsing.

- **Integration-Ready**: Designed for RAG pipelines and AI applications, with automated accessibility compliance and multi-format output.
