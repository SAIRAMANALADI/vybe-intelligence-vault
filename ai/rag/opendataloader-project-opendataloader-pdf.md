# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed to extract and convert PDF content (text, tables, bounding boxes) into AI-ready formats (HTML, JSON, Markdown) with OCR support for inaccessible documents.
- **Accessibility & Compliance Focus**: Supports PDF/UA, WCAG, and EAA standards for automated PDF accessibility remediation, including tagged PDF processing and structured data extraction.
- **Multi-format Output & Integration**: Outputs structured data (JSON/HTML) for downstream AI applications (RAG pipelines) and supports table extraction, bounding box annotations, and OCR-based text recognition.
