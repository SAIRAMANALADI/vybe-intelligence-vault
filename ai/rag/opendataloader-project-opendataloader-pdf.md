# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed to extract and convert PDF content into AI-ready formats (HTML, JSON, Markdown) with OCR support for accessibility and structured data extraction.

- **Accessibility & Tagged PDF Support**: Implements PDF/UA and tagged PDF standards for enhanced document accessibility, including bounding box detection and table extraction.

- **AI Integration & RAG Compatibility**: Outputs structured data (e.g., bounding boxes, tables) optimized for Retrieval-Augmented Generation (RAG) pipelines and AI-driven document processing.
