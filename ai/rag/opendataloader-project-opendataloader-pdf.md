# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed to convert PDFs into AI-ready formats (HTML, JSON, Markdown) with OCR support for accessibility and structured data extraction.
- **Key Features**: Supports tagged PDFs, bounding box detection, table extraction, and compliance with PDF/UA and WCAG (a11y) standards for accessibility automation.
- **Integration-Ready**: Outputs structured data (JSON/HTML) for RAG pipelines, with 28K+ GitHub stars and active maintenance (last updated Aug 2026).
