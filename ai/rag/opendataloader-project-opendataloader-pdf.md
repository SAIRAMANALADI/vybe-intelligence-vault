# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool for converting PDFs into AI-ready formats (HTML, JSON, Markdown) with OCR support for accessibility compliance (PDF/UA, WCAG).

- **Advanced Document Processing**: Extracts structured data including text, tables, bounding boxes, and tagged content for RAG (Retrieval-Augmented Generation) pipelines.

- **Accessibility & Automation**: Supports PDF accessibility standards (EAA, Section 508) via automated tagging, OCR recognition, and conversion to machine-readable formats.
