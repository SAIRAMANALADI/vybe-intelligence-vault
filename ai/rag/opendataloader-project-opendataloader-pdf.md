# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed for AI-ready data extraction from PDFs, supporting accessibility (a11y) and compliance with PDF/UA standards.
- **Multi-format Output**: Converts PDFs to HTML, JSON, Markdown, and other formats, with OCR support for scanned documents and structured extraction of tables/bounding boxes.
- **AI Integration**: Enables automation of document parsing for RAG (Retrieval-Augmented Generation) pipelines, optimizing PDF accessibility and data extraction workflows.
