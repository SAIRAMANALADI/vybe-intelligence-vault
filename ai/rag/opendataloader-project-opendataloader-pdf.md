# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF parser** designed for AI-ready data extraction, supporting accessibility standards (PDF/UA, WCAG) and automated tagging for structured content.
- **Multi-format output** (HTML, JSON, Markdown) with OCR support for scanned/untagged PDFs, including bounding-box detection for tables and layout preservation.
- **Open-source tool** optimized for RAG pipelines, document parsing, and accessibility compliance (a11y, EAA), with features for tagged PDF conversion and table extraction.
