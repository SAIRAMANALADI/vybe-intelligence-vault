# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool (`opendataloader-pdf`) designed for AI-ready data extraction from PDFs, supporting accessibility compliance (e.g., PDF/UA, WCAG) and automated tagging for structured content.

- **Multi-format Output & OCR Support**: Converts PDFs to HTML, JSON, Markdown, or bounding-box annotations; includes OCR for scanned/untagged PDFs and table extraction for structured data.

- **AI Integration & Accessibility Features**: Enables RAG (Retrieval-Augmented Generation) pipelines; supports bounding-box labeling, tagged-PDF processing, and accessibility enhancements (e.g., alt-text, semantic structure).
