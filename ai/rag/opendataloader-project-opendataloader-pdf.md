# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed to extract and convert PDF content (text, tables, structure) into AI-ready formats (HTML, JSON, Markdown) with OCR support for scanned documents.
- **Accessibility & Compliance**: Supports PDF/UA, tagged PDFs, and automated accessibility checks for WCAG/EAA compliance, including bounding-box detection for precise element extraction.
- **Integration-Ready**: Outputs structured data (JSON/HTML) for RAG pipelines, with modular support for tables, OCR recognition, and conversion to Markdown/HTML for downstream AI applications.
