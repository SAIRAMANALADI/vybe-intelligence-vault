# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool for extracting AI-ready structured data (HTML, JSON, Markdown) from PDFs, supporting accessibility standards (PDF/UA, WCAG) and tagged PDFs.

- **OCR & Layout Analysis**: Implements OCR for scanned/non-text PDFs, with bounding-box detection for tables, text blocks, and structural elements for precise extraction.

- **AI & RAG Integration**: Outputs data optimized for Retrieval-Augmented Generation (RAG) pipelines, enabling automated document accessibility and downstream AI applications.
