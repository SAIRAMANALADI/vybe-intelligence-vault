# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed for AI-ready data extraction from PDFs, supporting accessibility compliance (e.g., PDF/UA) and automated tagging for screen readers.
- **Multi-format Output**: Converts PDF content into structured formats (HTML, JSON, Markdown) with OCR support for scanned documents and bounding-box detection for tables/figures.
- **AI Integration**: Enables RAG (Retrieval-Augmented Generation) pipelines by extracting clean, structured text and metadata from tagged or untagged PDFs.
