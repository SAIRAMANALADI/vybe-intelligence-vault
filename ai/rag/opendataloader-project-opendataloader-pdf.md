# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool (`opendataloader-pdf`) designed for AI-ready data extraction from PDFs, supporting accessibility automation and conversion to formats like HTML, JSON, and Markdown.

- **OCR & Structured Extraction**: Implements OCR recognition for scanned PDFs, extracts tables, bounding boxes, and tagged PDFs (PDF/UA compliant) for enhanced document parsing.

- **AI Integration & Accessibility**: Supports Rag (Retrieval-Augmented Generation) workflows, improves PDF accessibility (`a11y`), and enables structured data output for AI applications.
