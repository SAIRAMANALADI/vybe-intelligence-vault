# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool (`opendataloader-pdf`) designed for AI-ready PDF data extraction, supporting accessibility compliance (PDF/UA, WCAG) and automated tagging.
- **Multi-format Output**: Converts PDFs to structured formats (HTML, JSON, Markdown) with OCR support for scanned/untagged PDFs, preserving layout, tables, and bounding boxes.
- **AI Integration Ready**: Optimized for RAG pipelines, with bounding box metadata and table extraction for downstream NLP/ML tasks. Supports tagged PDFs, OCR recognition, and accessibility remediation.
