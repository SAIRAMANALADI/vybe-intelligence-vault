# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed for AI-ready data extraction from PDFs, supporting accessibility compliance (e.g., PDF/UA) and automated tagging for structured content parsing.

- **Multi-format Output & OCR**: Converts PDFs to HTML, JSON, Markdown, or bounding-box annotations; includes OCR for scanned/non-textual content, enabling accessibility and downstream AI/ML applications.

- **Advanced Features**: Supports table extraction, tagged PDF processing, and integration with RAG pipelines; optimized for document parsing workflows in AI/ML contexts.
