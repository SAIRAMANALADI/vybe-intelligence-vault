# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF parser** designed for AI-ready data extraction, supporting accessibility standards (PDF/UA, WCAG) and automated tagging for structured content.
- **Multi-format output** with support for HTML, JSON, Markdown, and bounding-box annotations; includes OCR for scanned PDFs and table extraction for complex layouts.
- **Open-source tool** optimized for RAG pipelines, document parsing, and accessibility compliance (a11y, EAA), with active community maintenance (27.6k+ stars, 2.6k+ forks).
