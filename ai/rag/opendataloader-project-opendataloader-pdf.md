# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed for AI-ready data extraction from PDFs, supporting accessibility automation and conversion to formats like HTML, JSON, and Markdown.

- **Advanced Features**: Supports OCR, table extraction, bounding-box detection, and tagged/UA-compliant PDF processing for structured data output.

- **Integration & Compliance**: Compatible with RAG pipelines, includes PDF/UA and EAA compliance, and enables accessibility via OCR and document parsing.
