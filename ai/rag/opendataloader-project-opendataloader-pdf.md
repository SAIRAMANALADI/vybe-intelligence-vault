# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed for AI-ready PDF data extraction, supporting accessibility (a11y) and compliance with PDF/UA standards for tagged PDFs.
- **Multi-format Output**: Converts PDFs to HTML, JSON, Markdown, or bounding-box annotated formats, with OCR support for scanned documents.
- **AI & RAG Integration**: Enables automated document parsing for retrieval-augmented generation (RAG) pipelines, including table extraction and accessibility automation.
