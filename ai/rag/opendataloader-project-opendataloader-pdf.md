# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool (`opendataloader-pdf`) for automated PDF accessibility conversion, supporting formats like HTML, JSON, Markdown, and tagged PDFs for AI-ready data extraction.

- **OCR & Structured Extraction**: Implements OCR recognition (bounding-box, table extraction) and adheres to PDF/UA standards for accessibility, enabling compliant document parsing for AI/RAG workflows.

- **Multi-format Output**: Converts PDFs to structured formats (HTML, JSON, Markdown) while preserving document semantics, supporting AI pipelines and accessibility (a11y) compliance.
