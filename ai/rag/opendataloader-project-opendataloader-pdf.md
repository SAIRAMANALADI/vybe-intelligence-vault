# opendataloader-project/opendataloader-pdf

## Summary

- **Java-based PDF Parser**: Open-source tool designed to convert PDFs into AI-ready formats (HTML, JSON, Markdown) with OCR support for accessibility (PDF/UA, WCAG) and structured data extraction (bounding boxes, tables, tagged content).

- **Automated Accessibility & Document Parsing**: Implements OCR recognition and document layout analysis to generate tagged PDFs, enabling AI models (e.g., RAG pipelines) to process unstructured PDF content efficiently.

- **Multi-Format Output & Compliance**: Supports conversion to HTML/JSON/Markdown while ensuring compliance with accessibility standards (PDF/UA, WCAG) and enterprise accessibility (EAA) requirements.
