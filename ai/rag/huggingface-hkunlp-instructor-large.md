# hkunlp/instructor-large · Hugging Face

## Summary

- **Instruction-Finetuned Text Embeddings (Instructor)**: Introduces a unified framework to generate task-specific text embeddings by incorporating natural language task descriptions (instructions) during fine-tuning, enabling a single embedding model to handle diverse tasks (e.g., classification, retrieval, clustering).

- **Task-Specific Embedding Optimization**: Demonstrates that adding task-specific instructions during training (e.g., "Represent the sentence for retrieval: ") significantly improves embedding performance across 70+ datasets, outperforming prior state-of-the-art models without task-specific fine-tuning.

- **Scalability & Generalization**: Shows that the approach generalizes well to unseen tasks and languages, with minimal performance degradation, and can be efficiently adapted to new tasks via instruction-based prompting without additional fine-tuning.
