# stanford-oval/storm

## Summary

- **LLM-Powered Knowledge Curation**: STORM autonomously researches topics by querying search engines and synthesizing retrieved information into a structured, full-length report with inline citations using large language models (LLMs).

- **Agentic RAG Framework**: Implements an agentic retrieval-augmented generation (RAG) pipeline with iterative query refinement, multi-source retrieval, and hierarchical report generation, optimized for deep research tasks.

- **EMNLP 2024 Contribution**: Presented as a novel system for automated knowledge curation, integrating retrieval, synthesis, and citation attribution with a focus on factual accuracy and coherence in generated reports.
