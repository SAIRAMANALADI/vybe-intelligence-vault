# stanford-oval/storm

## Summary

- **LLM-Powered Research Agent**: STORM autonomously researches a given topic by querying search engines, retrieving and synthesizing information, and generating a structured, citation-backed report using large language models (LLMs).

- **Multi-Stage Pipeline**: Implements a retrieval-augmented generation (RAG) framework with iterative query refinement, evidence retrieval, and hierarchical report generation, optimized for deep research tasks (e.g., EMNLP 2024/NAACL contributions).

- **Python-Based System**: Built in Python with modular components for agentic RAG, knowledge curation, and report generation, supporting extensibility for custom datasets and retrieval strategies.
