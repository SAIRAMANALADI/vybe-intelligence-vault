# DVC (deprecated) - Visual Studio Marketplace

## Summary

- **Deprecation & Migration**: The VS Code DVC extension is deprecated in favor of *DVC by lakeFS*, which will receive future updates; users are advised to uninstall the current extension and migrate to the new one.

- **Core Functionality**: Integrates ML experiment tracking, visualization, and data versioning directly in VS Code, leveraging Git for reproducibility and supporting real-time metric tracking without external databases.

- **Configuration & Integration**: Supports custom DVC binary paths (`dvc.dvcPath`), Python interpreter selection (`dvc.pythonPath`), and integrates with Microsoft’s Python extension; provides telemetry and debugging via the Output panel.
