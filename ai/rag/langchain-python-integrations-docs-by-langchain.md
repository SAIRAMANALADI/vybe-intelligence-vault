# LangChain Python integrations - Docs by LangChain

## Summary

- LangChain provides **1000+ integrations** across AI models, tools, document loaders, and vector stores via dedicated `langchain-<provider>` packages, enabling consistent API usage across providers (e.g., OpenAI, Anthropic, Google) with minimal code changes.

- **Popular providers** include OpenAI (`langchain-openai`), Google (Vertex AI/`langchain-google-vertexai`), Anthropic (`langchain-anthropic`), AWS (`langchain-aws`), and Ollama (`langchain-ollama`), each offering Python/JS/TS SDKs for seamless model integration.

- **Component-specific integrations** cover chat/embedding models, vector stores (e.g., Pinecone, Chroma, Weaviate), middleware, checkpointers, and toolkits, with additional support for databases (MongoDB, Redis) and specialized services (Tavily, Perplexity).
