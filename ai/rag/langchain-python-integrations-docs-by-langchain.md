# LangChain Python integrations - Docs by LangChain

## Summary

- **Extensive Ecosystem**: LangChain provides 1000+ integrations across chat/embedding models, tools, document loaders, and vector stores via dedicated `langchain-` packages (e.g., `langchain-openai`, `langchain-google-vertexai`), enabling consistent API usage across providers.

- **Provider Abstraction**: Supports major AI providers (OpenAI, Anthropic, Google, AWS, MistralAI, etc.) with standardized interfaces for chat models, embeddings, and vector stores, allowing seamless provider swapping without code changes.

- **Cross-Language Support**: Most integrations offer Python (`langchain-*` packages) and JavaScript/TypeScript (`@langchain/*` packages) compatibility, with some exceptions (e.g., `langchain-nvidia-ai-endpoints`, `langchain-openrouter`).
