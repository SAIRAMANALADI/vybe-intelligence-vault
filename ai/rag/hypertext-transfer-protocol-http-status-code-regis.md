# Hypertext Transfer Protocol (HTTP) Status Code Registry

## Summary

- **HTTP status codes are standardized responses grouped into 5 classes (1xx-5xx)**, defined by RFC9110, with registration via IETF Review; unassigned ranges (e.g., 105-199, 209-225) are reserved for future use.
- **Key status codes include**:
  - **100 (Continue)**, **101 (Switching Protocols)**, **200 (OK)**, **201 (Created)**, **301 (Moved Permanently)**, **404 (Not Found)**, **500 (Internal Server Error)**.
  - **Temporary assignments**: **104 (Upload Resumption Supported)** (expires 2026-11-13).
- **Obsolete/Unused codes**: **306 (Unused)**, **418 (Unused)**, **510 (Not Extended, obsoleted)**; **511 (Network Authentication Required)** is the latest assigned code (RFC6585).
