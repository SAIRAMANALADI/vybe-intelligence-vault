# Code Llama: Open Foundation Models for Code | Research - AI at Meta

## Summary

- **Model Architecture & Variants**: Code Llama is a family of LLMs for code based on Llama 2, with variants including foundation models (7B, 13B, 34B), Python-specialized models, and instruction-following models, all trained on 16k-token sequences with support for up to 100k tokens.

- **Performance Benchmarks**: Achieves state-of-the-art results among open models, scoring **53% on HumanEval** and **55% on MBPP**, with the 7B Python variant outperforming Llama 2 70B on these benchmarks and leading on **MultiPL-E**.

- **Licensing & Capabilities**: Released under a permissive license for research and commercial use; supports **infilling** (7B/13B variants), **zero-shot instruction following**, and **long-context processing** (up to 100k tokens).
