# Stainless - Stainless Docs Platform

## Summary

- **Dynamic API Documentation Sync**: Automatically synchronizes REST API, SDK, and narrative docs with the actual API state, eliminating manual updates and ensuring consistency across all documentation layers.

- **AI-Agent & Developer-Optimized Structure**: Implements AI-powered hybrid search and Markdown integration, enabling seamless digestion by AI agents while maintaining developer-friendly usability with minimal client-side JS and SEO/search optimization.

- **Extensible Astro-Based Framework**: Built on Astro for high-performance, content-driven sites with TypeScript-first customization via server-side actions, middleware, and integrations; supports theming (CSS variables, Tailwind/SASS/LESS) and multi-framework components (React, Svelte, Vue, etc.).
