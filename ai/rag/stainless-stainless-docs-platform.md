# Stainless - Stainless Docs Platform

## Summary

- **Dynamic API Documentation Sync**: REST API, SDK, and narrative docs automatically stay synchronized with the actual API, ensuring consistency across all documentation layers.

- **AI-Agent Optimized & Hybrid Search**: Implements AI-powered hybrid search and integrates with AI tools, enabling AI agents to efficiently digest and retrieve documentation while supporting light/dark modes and SEO optimization.

- **Extensible Astro-Based Framework**: Built on Astro for high-performance, content-driven websites with TypeScript-first customization at every layer (locals, server-side actions, middleware, and integration hooks), supporting Tailwind/SASS/LESS styling and deployment flexibility across any infrastructure.
