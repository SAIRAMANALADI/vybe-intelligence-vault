# Stainless - Stainless Docs Platform

## Summary

- **Dynamic, synchronized documentation**: REST API, SDK, and narrative docs auto-sync with the actual API, ensuring consistency; built on Astro for full customization and multi-platform deployment.

- **AI agent & developer-friendly features**: Supports AI-powered hybrid search, Markdown copying, and integration with tools like `llms.txt`; optimized for SEO, performance (minimal client-side JS), and light/dark modes.

- **Extensible & framework-agnostic**: Customizable via TypeScript-first Astro integrations, supports React/Svelte/Vue/etc., and allows branding via CSS variables or Tailwind/SASS/LESS; deployable on Stainless or self-hosted infrastructure.
