# Stainless - Stainless Docs Platform

## Summary

- **Dynamic API Documentation Sync**: REST API, SDK, and narrative docs automatically stay in sync with the actual API, eliminating manual updates and ensuring consistency across all documentation layers.

- **AI-Optimized Hybrid Search**: Implements AI-powered hybrid search (semantic + keyword-based) with integration support for tools like `llms.txt`, enabling AI agents to efficiently parse and retrieve documentation.

- **Astro-Based Extensibility**: Built on Astro for high-performance, content-driven sites with TypeScript-first customization via server-side actions, middleware, and integration hooks, supporting frameworks like React, Svelte, and Vue.
