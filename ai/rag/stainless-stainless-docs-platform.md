# Stainless - Stainless Docs Platform

## Summary

- **Dynamic, AI-Optimized Documentation**: Automatically synchronizes REST API, SDK, and narrative docs with real-time API changes; structured for both developer usability and AI agent digestion via hybrid search and Markdown integration.

- **Extensible Astro-Based Architecture**: Built on Astro for high-performance, content-driven sites with full customization via TypeScript-first integrations, middleware, and hooks; supports SSR/SSG and any frontend framework (React, Svelte, Vue, etc.).

- **Performance & Branding**: Minimal client-side JS, SEO/search optimization, and lightweight theming via CSS variables or Tailwind/SASS/LESS; deployable on Stainless’s Cloudflare-backed hosting or self-hosted infrastructure.
