# Stainless - Stainless Docs Platform

## Summary

- **Dynamic API Documentation Sync**: REST API, SDK, and narrative docs automatically stay synchronized with the actual API, ensuring real-time accuracy without manual updates.

- **AI-Optimized & Developer-Friendly**: Supports AI agents via structured, digestible content while providing hybrid search, Markdown integration, and seamless AI tool compatibility (e.g., LLM-friendly `llms.txt`).

- **Astro-Based Customization**: Built on Astro for high-performance, extensible docs with full UI/UX control via TypeScript-first customization, framework-agnostic components (React, Vue, Svelte, etc.), and deployable anywhere (Stainless-hosted or self-hosted).
