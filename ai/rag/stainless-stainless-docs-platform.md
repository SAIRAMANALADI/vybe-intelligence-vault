# Stainless - Stainless Docs Platform

## Summary

- **Dynamic API Documentation Sync**: REST API, SDK, and narrative docs automatically stay synchronized with the actual API implementation, ensuring consistency across all documentation layers.

- **AI-Agent & Developer-Friendly Features**: Docs are optimized for AI agents (e.g., structured Markdown, `llms.txt` support) and developers (e.g., hybrid AI-powered search, light/dark modes, minimal client-side JS).

- **Extensible Astro-Based Framework**: Built on Astro for high-performance, content-driven sites with full customization via TypeScript-first integrations, framework-agnostic components (React, Svelte, Vue, etc.), and flexible deployment options (Stainless-hosted or self-hosted).
