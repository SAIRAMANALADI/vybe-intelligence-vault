# Stainless - Stainless Docs Platform

## Summary

- **Dynamic API Documentation Sync**: REST API, SDK, and narrative docs automatically stay in sync with the actual API using Astro-based dynamic docs, enabling AI agents to digest content while keeping developer-facing docs current.

- **AI-Powered Hybrid Search & Integration**: Features AI-driven hybrid search for improved discoverability and seamless integration with AI tools, enhancing developer productivity and AI agent accessibility.

- **Extensible & Customizable Framework**: Built on Astro for high-performance, content-driven sites with TypeScript-first customization (via server-side actions, middleware, or integrations), support for multiple UI frameworks (React, Svelte, Vue, etc.), and flexible deployment options (Stainless-hosted or self-hosted).
