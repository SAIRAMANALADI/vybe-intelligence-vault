# Stainless - Stainless Docs Platform

## Summary

- **Dynamic, AI-Optimized Documentation**: REST API, SDK, and narrative docs auto-sync with the actual API, designed for both developer usability and AI agent digestion, built on Astro for full customization and deployment flexibility.

- **Extensible & Customizable Architecture**: TypeScript-first customization at all layers (render context, server-side actions, middleware, and integration hooks), supporting Astro integrations, Tailwind/SASS/LESS styling, and multi-theme support (light/dark modes).

- **Framework-Agnostic Deployment**: Astro-based sites enable SSR/SSG, support React/Svelte/Vue/Solid/Preact, and allow hosting on Stainless’s Cloudflare-backed infrastructure or self-managed environments.
