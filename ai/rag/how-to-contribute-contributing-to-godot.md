# How to contribute — Contributing to Godot

## Summary

- **Contribution Pathways**: Godot accepts contributions via fundraising, feedback, development participation, ecosystem contributions, and community support, with structured teams for 2D/3D, animation, rendering, scripting (GDScript/GDExtension), platforms (Android/Web/Windows/Linux), and more.

- **Issue Reporting & Bisecting**: Detailed issue reports require version/system details, reproduction steps, and minimal reproduction projects (MRP); regression bisecting leverages Git's `bisect` command with official builds for efficiency.

- **Pull Request Workflow**: PRs must adhere to one-change-at-a-time contributions, clear explanations, and copyright compliance; review involves validating problems, testing for regressions, and code review, with compiled builds available via GitHub Actions.
