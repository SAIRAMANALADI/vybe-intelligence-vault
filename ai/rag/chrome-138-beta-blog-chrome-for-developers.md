# Chrome 138 beta | Blog | Chrome for Developers

## Summary

- **CSS Enhancements**: Introduces `stretch` sizing keyword for dynamic element sizing, sign-related functions (`abs()`, `sign()`), OS-level font scale exposure via CSS `env` variable, sibling indexing functions (`sibling-index()`, `sibling-count()`), `progress()` functional notation for interpolation, and Viewport Segments Enumeration API for foldable devices.

- **Web APIs & AI Integration**: Adds Video Frame orientation metadata support in WebCodecs, Crash Reporting API fields (`is_top_level`, `visibility_state`), `<`/`>` attribute escaping for XSS mitigation, Integrity Policy for scripts, predictable storage quotas, `pushsubscriptionchange` event for resubscription, and AI-powered APIs (Summarizer, Language Detector, Translator). Also introduces Web Serial over Bluetooth on Android and web app scope extensions.

- **Deprecations & Security**: Deprecates asynchronous range removal in Media Source Extensions and removes SwiftShader fallback for WebGL due to security and performance risks.
