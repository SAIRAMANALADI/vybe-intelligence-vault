# CSS text-wrap: balance | CSS and UI | Chrome for Developers

## Summary

- **CSS `text-wrap: balance`** is a new CSS Text Level 4 property enabling balanced line breaks in multi-line text blocks, mimicking traditional typographic hand-authoring techniques for improved visual harmony.

- **Browser Support**: Currently supported in Chrome/Edge 114+, Firefox 121+, and Safari 17.5+, with progressive enhancement for older versions.

- **Implementation**: Applied via `text-wrap: balance` in CSS, this property optimizes readability by distributing white space evenly across lines, particularly beneficial for headings and short text blocks.
