# RFC 6838 - Media Type Specifications and Registration Procedures

## Summary

- **Media Type Registration Framework**: RFC 6838 defines the procedures for specifying and registering media types (e.g., `text/plain`, `image/png`) for use in protocols like HTTP and MIME, replacing RFC 4288 and updated by RFC 9694.

- **Registration Trees**: Media types are organized into registration trees (Standards, Vendor, Personal/Vanity, and Unregistered `x.`), each with distinct naming conventions and requirements for registration.

- **Structured Registration Process**: New media types require community review, submission to IANA, and compliance with functional, naming, security, and parameter requirements before approval, with templates and change procedures outlined in Sections 5–6.
