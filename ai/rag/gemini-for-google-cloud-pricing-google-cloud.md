# Gemini for Google Cloud pricing | Google Cloud

## Summary

- **Gemini Code Assist Editions & Pricing**:
  - **Standard**: $0.031232877/hour (monthly) or $0.026027397/hour (12-month commitment), includes IDE-focused AI code assistance, local codebase awareness, database development tools, and enterprise-grade security.
  - **Enterprise**: $0.073972603/hour (monthly) or $0.061643836/hour (12-month commitment), adds code customization, integrations with Apigee/Application Integration, and advanced Cloud Assist features.

- **Gemini Cloud Assist Features**:
  - **Enterprise-only**: Natural Language Design, Infrastructure as Code, Investigations, Support Handoff, Database Troubleshooting, and Database Optimization.
  - **Free for all Google Cloud users**: Cost optimization in FinOps/Cloud Hub, Console Chat, Flow Analyzer, Cloud Observability, Storage Insights, and IAM Assistance.

- **Gemini in BigQuery Pricing**:
  - Core features (SQL/Python code assist, Data Canvas, Data Preparation) are free across all editions (Standard, Enterprise, Enterprise Plus, On-demand compute).
  - Advanced context features (Data Insights, Automated Metadata Generation) are restricted to Enterprise/Enterprise Plus/On-demand compute tiers.
