# Firestore Vector Store | Developer Documentation

## Summary

- **Efficient similarity search**: Faiss (Facebook AI Similarity Search) is a library for efficient similarity search and clustering of dense vectors, optimized for large-scale datasets with billions of entries.
- **GPU/CPU acceleration**: Supports both CPU and GPU acceleration, leveraging SIMD instructions, multi-threading, and approximate nearest neighbor (ANN) algorithms (e.g., IVF, HNSW, PQ) to reduce computational overhead.
- **Modular design**: Provides modular components for indexing (e.g., `IndexFlat`, `IndexIVFFlat`), querying, and distance computations (e.g., L2, inner product), with Python/C++ APIs for integration.
