# What is DataLab? | DataLab Docs

## Summary

- **AI-Powered Data Notebook**: Integrates generative AI for natural language querying ("chat with your data"), includes a full-featured IDE for code review/execution, and auto-generates shareable reports from analyses.

- **Cloud-Based Environment**: Provides pre-configured R/Python environments with SQL support, common DS packages, and seamless external database connectivity (via SQL cells with dataframe output).

- **Collaboration & AI Tools**: Enables real-time multi-user editing/commenting, features an AI Assistant for code generation/debugging, and offers no-code chart creation for rapid visualization.
