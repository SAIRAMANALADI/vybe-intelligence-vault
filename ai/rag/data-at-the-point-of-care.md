# Data at the Point of Care

## Summary

- **Purpose**: Data at the Point of Care (DPC) provides Original Medicare claims data to providers in structured FHIR format, enabling a comprehensive view of patients' medical history across care settings (e.g., hospitals, urgent care) to improve care coordination and reduce paperwork.
- **Implementation**: DPC operates via a sandbox (synthetic data) and production environment, requiring Health IT teams to integrate the API into existing clinical workflows; it leverages HL7 FHIR standards for interoperability.
- **Related APIs**: DPC is one of several CMS FHIR-based APIs (e.g., BCDA, Blue Button 2.0, AB2D) enabling access to Medicare claims data for purposes like population analytics, beneficiary data sharing, and prescription drug monitoring.
