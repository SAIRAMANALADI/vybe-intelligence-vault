# Google Play Android Developer API | Google Play Developer API | Google for Developers

## Summary

- **API Workflow**: Enables Android developers to manage Google Play accounts via a structured workflow: create an `Edit`, apply changes (e.g., APKs, bundles, metadata), then `commit` or `validate` the edit.
- **Key REST Resources**: Core endpoints include `/edits` (CRUD operations), `/edits.apks` (APK uploads), `/edits.bundles` (AAB uploads), `/edits.listings` (store metadata), and `/edits.tracks` (release management).
- **Advanced Features**: Supports deobfuscation files (`/edits.deobfuscationfiles`), expansion files (`/edits.expansionfiles`), country availability (`/edits.countryavailability`), and app recovery (`/apprecovery`) for targeted rollbacks.
