# Zilliz · GitHub

## Summary

- **Milvus Ecosystem**: Zilliz maintains core projects like `knowhere` (C++ vector search engine integrating FAISS, HNSW, DiskANN), `attu` (GUI for Milvus), and `milvus-operator` (Kubernetes operator for Milvus deployments).

- **AI/Vector Database Tools**: Open-source benchmarks (`VectorDBBench`), data transformation utilities (`vts`), and backup solutions (`milvus-backup`) are provided for enterprise-grade vector database operations.

- **AI Integration Libraries**: Projects like `deep-searcher` (Python-based deep research tool), `memsearch` (persistent memory layer for AI agents), and `zilliz-plugin` (natural language interface for Zilliz Cloud) enhance LLM application workflows.
