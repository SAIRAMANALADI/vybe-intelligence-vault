# Zilliz · GitHub

## Summary

- **Zilliz** is a vector database provider specializing in enterprise-grade AI and LLM applications, with a cloud platform at [zilliz.com/cloud](https://zilliz.com/cloud).

- **Key open-source projects** include:
  - **VectorDBBench**: Benchmarking tool for vector databases (Python).
  - **knowhere**: C++-based vector search engine integrating FAISS, HNSW, and DiskANN.
  - **attu**: GUI for Milvus with 3k+ GitHub stars (Shell).

- **Additional tools** span distributed systems (e.g., **woodpecker** for WAL storage in Go) and AI integration (e.g., **claude-context** for code search with 12.2k stars in TypeScript).
