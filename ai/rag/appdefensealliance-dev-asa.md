# ASA/MobileAppSecurityAssessment/MobileSecurityGuide.md at main · appdefensealliance-dev/ASA · GitHub

## Summary

- **Data Storage & Privacy (V2)**: Sensitive data (PII, credentials, keys) must use system credential storage (MSTG-STORAGE-1), avoid external storage (MSTG-STORAGE-2), and exclude logs (MSTG-STORAGE-3); keyboard cache disabled for sensitive inputs (MSTG-STORAGE-5), no UI leakage (MSTG-STORAGE-7), and user education on data handling (MSTG-STORAGE-12).

- **Cryptography (V3)**: Prohibits hardcoded symmetric keys (MSTG-CRYPTO-1), mandates proven cryptographic primitives (MSTG-CRYPTO-2), enforces algorithm suitability (MSTG-CRYPTO-3), bans deprecated algorithms (MSTG-CRYPTO-4), prohibits key reuse (MSTG-CRYPTO-5), and requires secure RNG for random values (MSTG-CRYPTO-6).

- **Authentication & Network Security (V4/V5)**: Remote services require secure authentication (MSTG-AUTH-1), stateful sessions use random IDs (MSTG-AUTH-2), stateless tokens must be securely signed (MSTG-AUTH-3), sessions terminate on logout (MSTG-AUTH-4), enforces password policies (MSTG-AUTH-5), rate-limits credential attempts (MSTG-AUTH-6), and enforces session timeouts (MSTG-AUTH-7); all network traffic must use TLS with validated certificates (MSTG-NETWORK-1/2/3).
