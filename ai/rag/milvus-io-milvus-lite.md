# milvus-io/milvus-lite

## Summary

- **Lightweight Milvus Implementation**: Milvus-lite is a simplified, single-process version of Milvus designed for local development and testing, reducing operational overhead compared to full Milvus deployments.

- **Python-Based & Standalone**: Written in Python, it operates as a standalone server (default port: `19530`) with no dependency on etcd, MinIO, or Pulsar, simplifying setup for local vector database use cases.

- **Data Migration Support**: Provides tools to migrate data from Milvus-lite to full Milvus deployments, ensuring compatibility and seamless transition between the lightweight and production versions.
