# The GNU Operating System and the Free Software Movement

## Summary

- **GNU Operating System**: A Unix-like OS composed of GNU packages and third-party free software, designed to ensure user freedom by avoiding proprietary software; typically paired with the Linux kernel (GNU/Linux) but also supports the GNU Hurd kernel.

- **Free Software Foundation (FSF) Principles**: Advocates for four essential freedoms in software: (0) running programs for any purpose, (1) studying/modifying source code, (2) redistributing copies, and (3) distributing modified versions; emphasizes ethical use over cost.

- **GNU High-Priority Projects**: Includes long-term initiatives like GNU Hurd (microkernel), maintenance of core packages (e.g., Bison, Aspell), and tools like `InklingReader` for Wacom device support, with active calls for community contributions.
