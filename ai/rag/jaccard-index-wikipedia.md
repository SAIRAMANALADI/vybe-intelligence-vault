# Jaccard index - Wikipedia

## Summary

- **Definition**: The Jaccard index (J(A,B)) quantifies similarity between finite non-empty sets A and B as the ratio of intersection size to union size: J(A,B) = |A ∩ B| / |A ∪ B|, ranging from 0 (disjoint sets) to 1 (identical sets).
- **Generalization**: Extends to multisets (bags) via J(A,B) = |A ∩ B| / (|A| + |B|), with a maximum value of 0.5, and to measures (e.g., probability measures) as Jμ(A,B) = μ(A ∩ B) / μ(A ∪ B).
- **Distance Metric**: The Jaccard distance, dJ(A,B) = 1 - J(A,B), serves as a metric for dissimilarity, computed as |A ∪ B| - |A ∩ B| / |A ∪ B|, enabling clustering and multidimensional scaling applications.
