# rpm-software-management/dnf

## Summary

- **Architecture**: DNF is a modern package manager for RPM-based Linux distributions, built on **libdnf** (C++) and **libsolv** (C) for dependency resolution, replacing the legacy YUM (Python-based) with improved performance and modularity.
- **Language & Dependencies**: Primarily written in **Python**, it leverages **libdnf** (core library) and **libsolv** (SAT solver) for efficient transaction handling and dependency management.
- **Compatibility & Ecosystem**: Designed as the successor to YUM, it integrates with RPM packages and supports modular repositories, with active development tracked under the **rpm-software-management** organization.
