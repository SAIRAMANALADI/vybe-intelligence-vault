# algolia/firestore-algolia-search

## Summary

- **Purpose**: Enables real-time synchronization between Firestore and Algolia search indices for efficient full-text search capabilities.
- **Implementation**: Uses Firestore triggers (e.g., `onWrite`, `onUpdate`) to automatically update Algolia indices via Cloud Functions.
- **Tech Stack**: TypeScript-based, leveraging Firebase Admin SDK for Firestore operations and Algolia’s JavaScript client for indexing.
