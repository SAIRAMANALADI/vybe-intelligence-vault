# weaviate-io/blog/2024-03-07-verba-open-source-rag-app/index.mdx at main · weaviate/weaviate-io · GitHub

## Summary

- **Modular RAG Architecture**: Verba decomposes RAG into five customizable modules—`ReaderManager` (data ingestion), `ChunkerManager` (text segmentation), `EmbeddingManager` (vectorization), `RetrieveManager` (query processing), and `GenerationManager` (response synthesis)—enabling pipeline flexibility and extensibility for evolving use cases.

- **User-Centric UI/UX**: Implements a chat-based interface with autocompletion (via Weaviate’s BM25) and transparent source attribution (highlighted document chunks), alongside drag-and-drop document ingestion and CRUD data management to democratize RAG without requiring technical expertise.

- **Vector Database Integration**: Leverages Weaviate for hybrid/vector search to ensure accurate, low-latency retrieval, while a dedicated Status Page provides real-time system diagnostics (uptime, features, versioning) to enhance operational transparency.
