# NumFOCUS: A Nonprofit Supporting Open Code for Better Science

## Summary

- **NumFOCUS** sponsors 50+ open-source scientific computing projects, including **pandas**, **Jupyter**, **Matplotlib**, **Dask**, and **scikit-learn**, enabling large-scale data analysis, visualization, and machine learning workflows.

- **Key industry adopters** (e.g., Netflix, NASA) leverage these tools for high-performance computing, with libraries like **Julia**, **Astropy**, and **FEniCS** addressing domain-specific challenges in simulation, astronomy, and numerical analysis.

- **Sponsorship ecosystem** includes corporate partners (e.g., Bloomberg, Microsoft, NVIDIA) and foundations (e.g., Sloan, Moore), funding development via grants, infrastructure (e.g., **conda-forge**), and community-driven initiatives like **QuansciCon**.
