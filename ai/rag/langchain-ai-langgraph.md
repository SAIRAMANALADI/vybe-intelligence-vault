# langchain-ai/langgraph

## Summary

- **Framework**: LangGraph is a Python-based open-source framework designed for building resilient AI agents, supporting multi-agent systems, and integrating with LLMs like OpenAI, Gemini, and ChatGPT.

- **Key Features**: Leverages Pydantic for data validation, supports RAG (Retrieval-Augmented Generation), and enables enterprise-grade agent orchestration with fault tolerance and scalability.

- **Ecosystem**: Part of the LangChain ecosystem, facilitating generative AI workflows, deep agent integration, and hybrid AI-agent applications.
