# langchain-ai/langgraph

## Summary

- **Framework for resilient AI agents**: LangGraph is a Python-based framework designed to build robust, multi-agent systems with resilient execution, leveraging Pydantic for structured data validation and integration with LLM providers (e.g., OpenAI, Gemini).

- **Stateful, graph-based workflows**: Enables orchestration of complex agent interactions via directed graphs, supporting conditional logic, parallel execution, and persistent state management for enterprise-grade AI applications.

- **Enterprise-ready features**: Includes built-in support for RAG, multi-agent collaboration, and tool integration, with active development (last updated Aug 2026) and a large open-source community (38k+ stars).
