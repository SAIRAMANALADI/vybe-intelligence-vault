# langchain-ai/langgraph

## Summary

- **Framework for resilient agent orchestration**: LangGraph provides a Python-based framework for building, managing, and scaling multi-agent systems with fault tolerance and stateful workflows.

- **Stateful, graph-based execution**: Agents operate within a graph structure where nodes represent tasks and edges define execution paths, enabling complex, conditional, and parallel agent interactions.

- **Integration with LLM ecosystems**: Supports OpenAI, Gemini, and other LLMs via LangChain, with Pydantic-based schema validation for structured outputs and enterprise-grade RAG capabilities.
