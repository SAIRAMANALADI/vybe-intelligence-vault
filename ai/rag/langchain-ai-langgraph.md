# langchain-ai/langgraph

## Summary

- **Framework for resilient AI agents**: LangGraph provides a Python-based framework for building, managing, and orchestrating resilient multi-agent systems, integrating with LLMs (e.g., OpenAI, Gemini) and tools like RAG.
- **Stateful, graph-based workflows**: Implements a graph-based architecture (via Pydantic) to define complex agent interactions, tool usage, and error handling, enabling robust, enterprise-grade agentic systems.
- **Enterprise-ready features**: Supports multi-agent collaboration, deep integration with LangChain ecosystem, and scalability for generative AI applications in production environments.
