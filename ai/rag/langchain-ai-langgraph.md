# langchain-ai/langgraph

## Summary

- **Framework for resilient AI agents**: LangGraph is a Python-based framework designed to build and manage resilient AI agents, supporting multi-agent systems, enterprise-grade deployments, and integration with LLMs (e.g., OpenAI, Gemini).

- **Stateful, graph-based orchestration**: Utilizes a graph-based architecture (via Pydantic) for agent workflows, enabling structured, stateful multi-step reasoning and tool usage with fault tolerance.

- **Enterprise and RAG integration**: Supports Retrieval-Augmented Generation (RAG), deep agent orchestration, and scalable deployments for enterprise use cases, with active development (last updated Aug 2026).
