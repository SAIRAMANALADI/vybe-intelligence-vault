# langchain-ai/langgraph

## Summary

- **Framework for resilient AI agents**: LangGraph provides a Python-based framework for building, deploying, and managing resilient AI agents with support for multi-agent systems, enterprise integrations, and generative AI workflows.

- **Core components**: Built on Pydantic for data validation, integrates with LangChain for LLM orchestration, and supports OpenAI, Gemini, and other major AI models for flexible agent development.

- **Key features**: Enables stateful, multi-agent collaboration with persistent memory, fault tolerance, and RAG (Retrieval-Augmented Generation) capabilities for enterprise-grade agentic systems.
