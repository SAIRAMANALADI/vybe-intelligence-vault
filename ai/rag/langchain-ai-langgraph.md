# langchain-ai/langgraph

## Summary

- **Framework for resilient AI agents**: LangGraph is a Python-based framework designed for building robust, multi-agent systems with resilience, leveraging Pydantic for data validation and structured workflows.

- **Integration with major LLMs and tools**: Supports OpenAI, ChatGPT, Gemini, and other generative AI models, enabling enterprise-grade agent orchestration with RAG (Retrieval-Augmented Generation) and deep agent capabilities.

- **Modular and scalable architecture**: Built on LangChain, it enables complex agent interactions, state management, and parallel execution, optimized for enterprise deployments and open-source contributions.
