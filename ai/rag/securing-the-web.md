# Securing the Web

## Summary

- **Mandate for Secure Communication**: The W3C TAG asserts that the Web platform must prioritize secure communication by default, favoring `https://` over `http://` to ensure authentication, integrity, and confidentiality, with exceptions like `localhost`.

- **TLS End-to-End Integrity**: TLS must remain uncompromised to preserve trust, as weakened or modified encryption (e.g., MITM proxies) undermines Web security, despite legitimate use cases like network policy enforcement.

- **Barriers to HTTPS Adoption**: Key challenges include PKI trustworthiness (e.g., Certificate Transparency), performance overhead (mitigated by TLS 1.3 and optimizations like OCSP stapling), and transition issues (e.g., mixed content, shared caching limitations).
