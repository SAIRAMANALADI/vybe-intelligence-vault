# Global Infrastructure - AWS

## Summary

- **Global Reach & Scalability**: AWS operates **39 Regions** with **123 Availability Zones (AZs)**, plus **750+ CloudFront POPs**, **45 Local Zones**, and **33 Wavelength Zones**, enabling low-latency, high-performance deployments across **7 continents** with planned expansions in **Saudi Arabia, Chile, New Zealand, Taiwan, and Australia**.

- **High Availability & Resilience**: Each AWS Region consists of **≥3 physically isolated AZs**, interconnected via **~20M km of fiber**, ensuring **<99.99% SLA** for fault tolerance, with **Local Zones** and **Wavelength** extending infrastructure to edge locations for latency-sensitive workloads.

- **Diverse Deployment Models**: Supports **hybrid/cloud/edge** via **Outposts (on-premises)**, **Dedicated Local Zones (regulatory compliance)**, **CloudFront (CDN)**, and **Wavelength (5G-integrated)**, optimized for AI/ML workloads with **AI-driven power efficiency** in data centers.
