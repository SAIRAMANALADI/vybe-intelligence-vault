# Global Infrastructure - AWS

## Summary

- **Global Reach & Scale**: AWS operates **39 Regions** with **123 Availability Zones (AZs)**, plus **750+ CloudFront POPs**, **45 Local Zones**, and **33 Wavelength Zones**, enabling low-latency, high-performance deployments across **7 continents** with planned expansions in **Saudi Arabia, Chile, New Zealand, Taiwan, and Australia**.

- **Resilient & Secure Architecture**: Each **Region** consists of **≥3 isolated AZs**, ensuring **high availability (99.99%)** and fault tolerance. AWS leverages **20M+ km of fiber optic backbone**, including **subsea cables**, for optimized data transfer, reduced latency, and enhanced security via **dedicated hardware (e.g., Nitro System)** and **encryption at rest/transit**.

- **Hybrid & Edge Compute Solutions**: Supports **on-premises (Outposts), edge (Local Zones), telco-integrated (Wavelength), and sovereign cloud (Dedicated Local Zones)** deployments, enabling **consistent hybrid/multi-cloud** experiences while meeting **data residency, latency, and regulatory** requirements.
