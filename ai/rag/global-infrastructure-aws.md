# Global Infrastructure - AWS

## Summary

- **Global Reach & Scale**: AWS operates **39 Regions** with **123 Availability Zones (AZs)**, plus **750+ CloudFront POPs** and **45 Local Zones/Wavelength Zones**, enabling low-latency, high-performance deployments across **6 continents** with plans for expansion in **Saudi Arabia, Chile, New Zealand, and Taiwan**.

- **Resilient & Secure Architecture**: Each **Region** contains **≥3 isolated AZs**, ensuring **high availability (99.99%)** and fault tolerance. AWS leverages **20M+ km of fiber optic cabling** (terrestrial/subsea) for optimized data transfer, latency reduction, and enhanced security via **dedicated hardware, encryption, and compliance certifications**.

- **Diverse Infrastructure Offerings**: Supports **hybrid/multi-cloud** via **Outposts (on-premises)**, **Local Zones (edge compute)**, **Dedicated Local Zones (regulatory compliance)**, and **Wavelength (5G integration)**, enabling workload deployment across **cloud, edge, and telco environments**.
