# Global Infrastructure - AWS

## Summary

- **Global Footprint**: AWS operates **39 Regions** with **123 Availability Zones (AZs)**, plus **750+ CloudFront POPs** and **45 Local Zones/Wavelength Zones**, enabling low-latency, high-performance deployments across **7 continents**.
- **Resilience & Security**: Each Region contains **≥3 isolated AZs**, ensuring **99.99% uptime** via redundant, physically separate data centers with **~20M km of fiber optic backbone** for optimized latency and fault tolerance.
- **Edge & Hybrid Solutions**: Supports **Local Zones, Dedicated Local Zones, Outposts, Wavelength**, and **CloudFront** for edge computing, hybrid deployments, and regulatory compliance, with **AI-driven power optimization** for sustainability.
