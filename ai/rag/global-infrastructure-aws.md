# Global Infrastructure - AWS

## Summary

- **Scale & Coverage**: AWS operates **39 Regions** with **123 Availability Zones (AZs)**, plus **750+ CloudFront POPs** and **45 Local Zones**, enabling low-latency global deployments with planned expansions in Saudi Arabia, Chile, New Zealand, and Taiwan.

- **Resilience & Security**: Each Region contains **≥3 isolated AZs**, ensuring high availability and fault tolerance, while AWS’s **20M km fiber network** optimizes latency and performance for global workloads.

- **Hybrid & Edge Solutions**: Supports **Outposts (on-prem), Wavelength (telco edge), Local Zones (regional edge)**, and **Dedicated Local Zones** for compliance, enabling consistent hybrid, edge, and sovereign cloud deployments.
