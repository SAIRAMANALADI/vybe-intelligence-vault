# Global Infrastructure - AWS

## Summary

- **Global Footprint**: AWS operates **39 Regions** with **123 Availability Zones (AZs)**, plus **750+ CloudFront POPs** and **45 Local Zones**, enabling low-latency deployments across **7 continents**.
- **High Availability & Resilience**: Each Region contains **≥3 isolated AZs**, interconnected via **~20M km of fiber**, ensuring **sub-10ms latency** and **99.99% uptime** for critical workloads.
- **Edge & Hybrid Extensions**: Supports **Wavelength Zones** (5G integration), **Outposts** (on-premises AWS), and **Dedicated Local Zones** for regulatory compliance, expanding deployment flexibility.
