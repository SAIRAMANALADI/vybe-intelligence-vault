# Global Infrastructure - AWS

## Summary

- **Global Reach & Scale**: AWS operates **39 geographic regions** with **123 Availability Zones (AZs)**, plus **750+ CloudFront POPs**, **45 Local Zones**, and **33 Wavelength Zones**, enabling low-latency, high-performance deployments across **6 continents** with ongoing expansions (e.g., Chile, Saudi Arabia, New Zealand).

- **Resilient & Secure Architecture**: Each region comprises **≥3 physically isolated AZs**, interconnected via **~20M km of fiber**, ensuring **high availability (99.99%)**, fault tolerance, and compliance with global security standards (e.g., SOC, ISO, FedRAMP).

- **Hybrid & Edge Compute Offerings**: Supports **on-premises (Outposts), edge (Local Zones), telco-integrated (Wavelength), and sovereign deployments (Dedicated Local Zones)**, enabling consistent hybrid/multi-cloud architectures with **sub-10ms latency** for latency-sensitive workloads.
