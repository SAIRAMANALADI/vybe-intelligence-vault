# bangoc123/retrieval-backend-with-rag

## Summary

- **Vietnamese RAG Implementation**: Demonstrates best practices for building a Retrieval-Augmented Generation (RAG) system optimized for Vietnamese language processing, including text preprocessing, embedding models, and retrieval strategies tailored to Vietnamese corpora.

- **Modular Python Architecture**: Features a structured backend with components for document ingestion, vector storage (e.g., FAISS/Weaviate), retrieval pipelines, and LLM integration (e.g., ViT5, PhoBERT) for Vietnamese-specific tasks.

- **Evaluation & Deployment**: Includes scripts for benchmarking retrieval accuracy (e.g., MRR, Hit Rate) and deploying the RAG system as a FastAPI service with Vietnamese language support.
