# Training Arguments — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with optional PyTorch CUDA support; includes migration guides for major version updates (e.g., v5.x→v5.4+ with renamed parameters like `max_length`→`max_seq_length`).

- **Sentence Transformer Capabilities**: Enables semantic textual similarity, semantic search (symmetric/asymmetric), clustering (k-means, agglomerative), paraphrase mining, and multimodal applications (image/text, audio/video); supports embedding quantization (binary/int8) and efficiency optimizations (ONNX, OpenVINO).

- **Training & Evaluation**: Provides structured training pipelines with components (model, dataset, loss, evaluator, trainer) for fine-tuning; includes MTEB evaluation framework, multi-dataset training, and pre-trained models spanning multilingual, scientific, and INSTRUCTOR variants.
