# Git - Installing Git

## Summary

- **Git** is a distributed version control system (DVCS) with core features including branching, merging, and commit history tracking, optimized for performance and data integrity via SHA-1 hashing.
- **Official documentation** provides multilingual resources (e.g., Pro Git book in 20+ languages) and tools for CLI, GUI, hosting (e.g., GitHub/GitLab), and integration with IDEs (VS Code, IntelliJ).
- **Internals** rely on a content-addressable object model (blobs, trees, commits) with packfiles for efficient storage, and support for advanced workflows (rebasing, submodules) and third-party libraries (Libgit2, JGit).
