# GitHub Flavored Markdown Spec

## Summary

- **GFM Specification**: GitHub Flavored Markdown (GFM) is a strict superset of CommonMark, with extensions for features like tables, task lists, and strikethrough, while maintaining strict parsing rules for security and consistency.

- **Parsing Rules**: GFM defines unambiguous syntax rules for blocks (e.g., headings, code blocks) and inlines (e.g., links, emphasis), resolving ambiguities in CommonMark via a two-phase parsing strategy (block structure → inline structure).

- **Character Handling**: GFM treats lines as sequences of Unicode code points, with strict definitions for whitespace, line endings, and blank lines, ensuring consistent rendering across implementations.
