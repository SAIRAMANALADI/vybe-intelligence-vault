# GitHub Flavored Markdown Spec

## Summary

- **GFM Specification**: GitHub Flavored Markdown (GFM) is a strict superset of CommonMark, with extensions for features like tables, task lists, and strikethrough, while maintaining compatibility with CommonMark's core syntax.

- **Parsing Phases**: GFM parsing occurs in two phases—Phase 1 structures blocks (e.g., headings, lists, code blocks) and Phase 2 processes inlines (e.g., links, emphasis, code spans)—as defined in the formal spec.

- **Security & Post-Processing**: GitHub performs additional sanitization and post-processing after GFM-to-HTML conversion to ensure security and consistency, despite GFM's strict syntax rules.
