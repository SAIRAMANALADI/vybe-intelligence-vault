# GitHub Flavored Markdown Spec

## Summary

- **GFM Specification**: GitHub Flavored Markdown (GFM) is a strict superset of CommonMark, with extensions for features like tables, task lists, and strikethrough, formally defined in this spec to ensure unambiguous parsing and rendering.

- **Parsing Phases**: GFM parsing occurs in two phases—Phase 1 resolves block structure (e.g., headings, lists, code blocks), while Phase 2 processes inline elements (e.g., links, emphasis, code spans) within those blocks.

- **Unicode & Whitespace Handling**: All Unicode code points are treated as valid characters, with whitespace defined as sequences of spaces (`U+0020`), tabs (`U+0009`), or Unicode `Zs` category characters, ensuring consistent cross-platform rendering.
