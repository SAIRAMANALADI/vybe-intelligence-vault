# LangChain Blog

## Summary

- **Prompt Caching in Deep Agents**: Introduces a mechanism to cache and reuse intermediate computations in LLM-based agents, reducing redundant token processing and improving inference efficiency by up to 100x in specific workloads.

- **Model Neutrality vs. Cloud Neutrality**: Argues that model neutrality (ability to switch LLMs without vendor lock-in) is more critical than cloud neutrality, as it enables architectural flexibility and mitigates risks of model obsolescence or performance degradation.

- **LangSmith Engine for Agent Observability**: Releases a new trace judging system in LangSmith that leverages Fireworks' low-cost inference to provide scalable, real-time evaluation of agent traces, enabling cost-effective monitoring of agent behavior and performance.
