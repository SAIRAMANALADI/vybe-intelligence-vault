# The WebM Project | Software License

## Summary

- **WebM Project**: Open-source, royalty-free multimedia container format (WebM) and video codec (VP8/VP9) developed by Google, designed for efficient web streaming with support for lossy and lossless compression.

- **Licensing**: Distributed under a BSD-style license with an additional IP rights grant, permitting redistribution and modification with attribution, while disclaiming warranties and limiting liability.

- **Technical Specifications**: Includes VP9 bitstream format, WebM container structure, encryption standards, and RTP payload drafts (e.g., RFC 6386 for VP8), with SDKs and encoder parameter documentation available for implementation.
