# 3. An Informal Introduction to Python — Python 3.14.6 documentation

## Summary

- **Numeric Operations**: Python supports arithmetic operations (`+`, `-`, `*`, `/`, `//`, `%`, `**`) with automatic type conversion between `int` and `float`; division (`/`) always returns a float, while floor division (`//`) and modulus (`%`) return integers.
- **String Handling**: Strings (`str`) are immutable sequences supporting indexing (positive/negative), slicing, concatenation (`+`), repetition (`*`), and raw strings (`r'...'`) to disable escape sequences; triple-quoted strings (`'''...'''` or `"""..."""`) preserve line breaks.
- **Interactive Features**: The interpreter stores the last printed expression in `_` for reuse, and comments (`#`) are ignored during execution but clarify code; undefined variable access raises `NameError`.
