# GDAL — GDAL documentation

## Summary

- **GDAL** is an open-source (MIT license) translator library and toolset for geospatial raster and vector data formats, providing a unified abstract data model for all supported formats while offering command-line utilities for data translation and processing.

- **Supports extensive format compatibility** with 150+ raster drivers (e.g., GeoTIFF, JPEG2000, NetCDF) and 80+ vector drivers (e.g., Shapefile, GML, GeoJSON), enabling cross-format geospatial data manipulation.

- **Actively maintained by OSGeo** with version 3.13.1 released in 2026, featuring cloud-optimized formats (e.g., COG), API access for programmatic use, and integration with tools like QGIS and PostGIS.
