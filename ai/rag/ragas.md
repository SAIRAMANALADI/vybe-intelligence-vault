# Ragas

## Summary

- **LLM-Driven Evaluation Framework**: Ragas replaces traditional metrics with LLM-based evaluation metrics, enabling systematic and scalable assessment of LLM applications through continuous improvement loops.

- **Experiments-First Workflow**: Provides an `experiments` module for consistent evaluation of changes, integrating dataset management, result tracking, and support for frameworks like LangChain and LlamaIndex.

- **Customizable Metrics & Integration**: Supports creation of custom metrics via decorators and offers a library of pre-built metrics, with easy integration into existing workflows for rapid deployment and iteration.
