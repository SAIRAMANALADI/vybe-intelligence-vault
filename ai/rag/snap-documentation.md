# Snap documentation

## Summary

- **Unified packaging system**: Snaps are self-contained, cross-platform application packages managed by `snapd`, which handles installation, confinement, and updates, ensuring consistent deployment across diverse Linux distributions and hardware architectures.

- **Security via confinement**: Snaps employ Linux security mechanisms (e.g., AppArmor, seccomp) with configurable confinement models (strict/classic) and interface-based permission control to isolate applications and restrict resource access.

- **Transactional updates & delta optimization**: Snap employs transactional updates with channel/track-based versioning, revision tracking, and delta compression to minimize bandwidth usage during refreshes, ensuring atomic rollbacks and efficient storage utilization.
