# Chromium Docs - Chrome Security FAQ

## Summary

- **Security Bug Reporting & Rewards**: Chromium's security vulnerabilities are reported via a restricted process; valid bugs may qualify for rewards under the Chrome Vulnerability Rewards Program, while security bugs remain hidden in the issue tracker to prevent exploitation.
- **Threat Model Boundaries**: Chromium’s threat model excludes timing attacks, OS security boundary breaches by Chrome components, and physically-local or compromised machine attacks, focusing instead on web-based and UI spoofing risks.
- **Non-Security Issues**: Privacy violations, XSS filter bypasses, DoS attacks, and null pointer dereferences are explicitly excluded from Chromium’s security bug classification, with specific exceptions for file type handling and enterprise policy bypasses.
