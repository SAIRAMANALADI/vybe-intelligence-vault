# Send and update your data - Algolia

## Summary

- **Indexing Methods**: Data can be indexed via no-code solutions (Dashboard, Crawler, CLI, or ecommerce integrations) or programmatically using API clients, web frameworks, or the Search API.

- **Batch Processing & Updates**: Records should be batched (~10MB or 1,000–10,000 records) for optimal performance; updates require unique `objectID` and can be incremental or real-time based on content freshness needs.

- **Concurrency & Security**: Use versioning/optimistic locking for consistency in concurrent environments; security filters restrict user access to data, and API keys with scoped permissions are required for authentication.
