# The RPKI Observatory | The RPKI Observatory

## Summary

- **Purpose**: The RPKI Observatory analyzes RPKI deployment, identifies common configuration issues, and provides actionable metrics to improve routing security against BGP hijacking and misconfigurations.
- **Methodology**: Uses a local RPKI validator (RIPE NCC) consuming data from RIPE RIS, with additional queries to RIPEstat for AS names and country codes, operating modules independently for specific analyses.
- **Audience**: Targets BGP network operators, NOG communities, IXPs, RIRs, and researchers interested in RPKI, routing security, and Internet measurements.
