# Quickstart - Pinecone Docs

## Summary

- **Pinecone Quickstart Workflow**: Uses `Pinecone` SDK v9+ with integrated embedding (`create_index_for_model`), `upsert_records` for vector storage, and `search()` with reranking (`bge-reranker-v2-m3`) for retrieval; requires `api_key` and 5s delay for index consistency.

- **Setup Requirements**: Mandatory Pinecone account + API key (Starter/Builder/Standard plans); supports AI coding tools (Claude/Cursor) via plugins or direct SDK integration (Python/JS/Java/Go).

- **Data Modeling Options**: Two index types—records (dense/sparse vectors) for semantic search or documents (BM25 + Lucene) for hybrid keyword/phrase retrieval; choose during index creation.
