# Conda Documentation — conda-docs documentation

## Summary

- Conda is a cross-language package, dependency, and environment management system supporting any programming language.

- Installation options include Miniconda (Anaconda-maintained, preconfigured for Anaconda Repository) and Miniforge (conda-forge-maintained, preconfigured for conda-forge channel), available for multiple architectures and installable via native installers or Homebrew.

- Key conda tools include `conda build` (package building), `conda lock` (reproducible lock files), `constructor` (OS-specific installers), and `conda pack` (environment archiving).
