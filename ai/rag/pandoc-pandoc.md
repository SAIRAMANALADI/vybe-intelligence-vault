# pandoc • pandoc

## Summary

- **Pandoc Version Management**: R package enabling installation, management, and activation of multiple Pandoc versions (including nightly builds) in isolated directories, with caching for efficiency; supports version-specific operations and external Pandoc binaries (e.g., RStudio, system PATH).

- **Direct Pandoc CLI Interaction**: Provides low-level functions (`pandoc_run()`, `pandoc_convert()`) to execute Pandoc commands directly, bypassing `rmarkdown` layers for debugging or iterative testing; includes format conversion from text/files with version control.

- **Version Metadata & Utility Functions**: Includes tools to retrieve Pandoc version info (`pandoc_version()`), check availability (`pandoc_available()`), list supported extensions (`pandoc_list_extensions()`), and manage active versions across R Markdown workflows (`pandoc_activate()`, `with_pandoc_version()`).
