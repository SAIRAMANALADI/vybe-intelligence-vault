# 🌦️ Docs | Open-Meteo.com

## Summary

- **Multi-Model Integration**: API aggregates high-resolution weather models (e.g., ECMWF IFS 9km, NOAA GFS 0.11°, DWD ICON 2-11km) from 16 national providers, offering seamless forecasts up to 16 days with automatic model selection based on resolution and geographic coverage.

- **Granular Temporal & Spatial Data**: Supports hourly (default), 15-minutely (Central Europe/North America), and daily weather variables, including pressure-level data (1000-30 hPa), soil moisture (0-81 cm), and solar radiation metrics (GHI, DNI, GTI) with adjustable units (Celsius, km/h, mm).

- **Historical & Specialized APIs**: Provides historical forecasts, ensemble means, marine/air quality data, and climate change projections via dedicated endpoints (e.g., `/historical-weather-api`, `/marine-weather-api`), with data stitching to avoid gaps between model updates.
