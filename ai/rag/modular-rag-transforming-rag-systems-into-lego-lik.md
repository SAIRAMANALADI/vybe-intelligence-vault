# Modular RAG: Transforming RAG Systems into LEGO-like Reconfigurable Frameworks

## Summary

- **Modular RAG Framework**: Proposes a three-tier architecture (modules, sub-modules, operators) to decompose RAG systems into reconfigurable components, enabling flexible orchestration beyond linear "retrieve-then-generate" paradigms.

- **RAG Flow Patterns**: Defines six typical flow patterns (linear, conditional, branching, looping, etc.) and introduces routing/scheduling mechanisms to handle complex workflows, addressing challenges in heterogeneous data integration and system maintainability.

- **Operator-Level Granularity**: Employs fine-grained operators as computational graph nodes, allowing modular composition of RAG systems (e.g., query rewriting, reranking, iterative retrieval) while ensuring scalability and interpretability.
