# CodeQL documentation

## Summary

- **CodeQL** treats code as data, enabling vulnerability detection via declarative queries (QL) to identify and eradicate variants of security flaws systematically.
- **Supported ecosystems**: Analyzes multiple languages/frameworks (e.g., C/C++, Java, Python, JavaScript) with evolving coverage; consult [supported languages](https://codeql.github.com/codeql-overview/supported-languages-and-frameworks/) for current compatibility.
- **Tooling & resources**: Includes CLI, VS Code extension, and open-source repository ([GitHub/codeql](https://github.com/github/codeql)) for query development, with QL language reference and standard libraries documented for advanced analysis.
