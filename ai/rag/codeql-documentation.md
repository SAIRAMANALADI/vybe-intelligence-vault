# CodeQL documentation

## Summary

- **CodeQL Overview**: CodeQL treats code as data, enabling vulnerability detection via structured queries; supported languages/frameworks include C/C++, C#, Go, Java, JavaScript/TypeScript, Python, and Ruby (latest release details [here](https://codeql.github.com/codeql-overview/supported-languages-and-frameworks/)).
- **Query Development & Execution**: Queries are written in QL (a Datalog-derived language) with standard libraries for predicates/modules; execution supported via CLI or VS Code extension, with CWEs coverage documented [here](https://codeql.github.com/codeql-query-help/codeql-cwe-coverage/).
- **Resources & Contributions**: Official CLI releases, VS Code extension, and open-source repository ([GitHub](https://github.com/github/codeql)) available; QL language reference and standard libraries provide technical documentation for advanced query development.
