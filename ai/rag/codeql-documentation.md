## Summary

- CodeQL treats code as data, enabling vulnerability detection via structured queries, with results sharable across teams to eliminate recurring issues.
- Supports multiple languages/frameworks (e.g., C/C++, Java, Python, JavaScript) with detailed [coverage of CWEs](https://codeql.github.com/codeql-query-help/codeql-cwe-coverage/) and regular updates via [change logs](https://codeql.github.com/codeql-overview/codeql-changelog/).
- Provides tooling (CLI, VS Code extension) and documentation for query writing ([QL reference](https://codeql.github.com/ql-language-reference)), execution, and contributions via the [CodeQL repository](https://github.com/github/codeql).
