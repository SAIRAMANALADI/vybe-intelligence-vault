# CodeQL documentation

## Summary

- **CodeQL** treats code as data, enabling vulnerability detection via structured queries and collaborative sharing of detection logic.
- **Supported languages/frameworks** (latest release) include C/C++, C#, Go, Java, JavaScript/TypeScript, Python, and Ruby, with detailed [coverage of CWEs](https://codeql.github.com/codeql-query-help/codeql-cwe-coverage/).
- **Resources** include the [CodeQL CLI](https://github.com/github/codeql-cli-binaries/releases), [VS Code extension](https://marketplace.visualstudio.com/items?itemName=GitHub.vscode-codeql), and [reference docs](https://codeql.github.com/ql-language-reference) for QL, standard libraries, and query execution.
