# CodeQL documentation

## Summary

- **CodeQL Overview**: Enables querying code as data to identify and eradicate vulnerabilities; supports multiple languages, libraries, and frameworks (see [supported list](https://codeql.github.com/codeql-overview/supported-languages-and-frameworks/)).

- **Query Development & Execution**: Provides tools for writing (via [puzzles](https://codeql.github.com/writing-codeql-queries)), running, and sharing CodeQL queries; includes CLI, VS Code extension, and [standard libraries](https://codeql.github.com/codeql-standard-libraries).

- **Documentation & Coverage**: Offers detailed references (QL language, [query help](https://codeql.github.com/codeql-query-help)), system requirements, and [CWE coverage](https://codeql.github.com/codeql-query-help/codeql-cwe-coverage) for vulnerability analysis.
