# CodeQL documentation

## Summary

- **CodeQL** treats code as data, enabling vulnerability detection via structured queries to identify and eliminate variants of security flaws across codebases.
- Supports **multiple languages/frameworks** (e.g., C/C++, Java, Python, JavaScript) with detailed [coverage of CWEs](https://codeql.github.com/codeql-query-help/codeql-cwe-coverage/) and regular updates via [change logs](https://codeql.github.com/codeql-overview/codeql-changelog/).
- Provides **tools/extensions** (CLI, VS Code plugin) and **documentation** (QL language reference, standard libraries, query help) for writing, running, and sharing custom security queries.
