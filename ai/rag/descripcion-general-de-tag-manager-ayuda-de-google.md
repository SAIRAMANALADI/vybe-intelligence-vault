# Descripción general de Tag Manager - Ayuda de Google Tag Manager

## Summary

- **Tag Manager (GTM)** es un sistema de gestión de etiquetas (TMS) que centraliza la implementación y actualización de *etiquetas* (códigos de seguimiento) en sitios web o aplicaciones móviles mediante un fragmento de código único, eliminando la necesidad de modificaciones manuales en el código fuente.

- **Estructura técnica**: Utiliza *contenedores* (grupos de etiquetas, activadores y variables) para gestionar configuraciones; los *activadores* definen condiciones de disparo (ej: eventos de clic o vistas de página), mientras que las *variables* parametrizan datos dinámicos (ej: IDs de seguimiento o valores de eventos).

- **Migración y escalabilidad**: Permite migrar etiquetas existentes (Google Ads, Analytics, Floodlight, etc.) a GTM sin obligatoriedad de hacerlo en una sola acción; soporta múltiples sitios/aplicaciones bajo una cuenta, aunque se recomienda una cuenta por organización para evitar redundancias.
