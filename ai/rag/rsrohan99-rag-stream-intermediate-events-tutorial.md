# rsrohan99/rag-stream-intermediate-events-tutorial

## Summary

- **Intermediate Event Streaming**: Demonstrates how to stream intermediate LlamaIndex RAG events (e.g., node parsing, retrieval, synthesis) via Server-Sent Events (SSE) to the Vercel AI SDK for real-time client-side updates.

- **Integration Architecture**: Utilizes LlamaIndex's event system to capture granular RAG pipeline stages (e.g., `retrieve`, `synthesize`) and pipes them through a Node.js server to the Vercel AI SDK client using SSE.

- **Technical Stack**: TypeScript-based implementation with LlamaIndex for RAG, Vercel AI SDK for client-side event handling, and SSE for unidirectional, low-latency event transmission.
