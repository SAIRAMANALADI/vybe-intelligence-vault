# GraalVM

## Summary

- **Monthly Feature Releases**: Starting with version 25.1, GraalVM introduces monthly feature releases alongside stable CPU releases to accelerate innovation delivery.

- **Native Image Benefits**: GraalVM's Native Image feature produces executables with low memory/CPU usage, reduced attack surface, instant startup, and compact packaging, ideal for containers and microservices.

- **Framework & Cloud Integration**: GraalVM is supported by major frameworks (Spring Boot, Micronaut, Helidon, Quarkus) and cloud platforms (AWS, Azure, GCP, Oracle Cloud), enabling optimized deployments.
