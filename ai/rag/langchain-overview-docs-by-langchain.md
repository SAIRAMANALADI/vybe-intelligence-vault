# LangChain overview - Docs by LangChain

## Summary

- **Agent Harness**: `create_agent` provides a minimal, configurable harness for composing agents from models (OpenAI, Anthropic, Google, etc.), tools, prompts, and middleware, enabling tailored agent behavior for specific use cases.

- **Multi-Framework Support**: LangChain agents are built on LangGraph, inheriting durable execution, human-in-the-loop support, and persistence, while offering alternatives like Deep Agents (batteries-included) and LangGraph (low-level orchestration) for advanced workflows.

- **Observability & Debugging**: LangSmith integrates with agents for tracing, debugging, and evaluating agent behavior via execution data, including tool calls, state transitions, and latency metrics.
