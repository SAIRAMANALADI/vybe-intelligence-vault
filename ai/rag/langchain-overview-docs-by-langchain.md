# LangChain overview - Docs by LangChain

## Summary

- **Agent Composition**: LangChain's `create_agent` provides a minimal, configurable harness combining model, tools, prompt, and middleware, enabling custom agent construction for specific use cases with support for multiple LLM providers (OpenAI, Anthropic, Google, etc.).

- **Framework Integration**: Agents are built on LangGraph, inheriting durable execution, human-in-the-loop support, and persistence, while LangSmith enables tracing, debugging, and evaluation of agent workflows.

- **Standardized Interface & Debugging**: Offers a unified model interface across providers for portability and minimal code changes, with LangSmith providing observability via trace inspection, tool call analysis, and performance metrics.
