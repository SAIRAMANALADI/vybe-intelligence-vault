# LangChain overview - Docs by LangChain

## Summary

- **Agent Composition**: `create_agent` provides a minimal, configurable harness combining model, tools, prompt, and middleware, enabling custom agent construction for specific use cases with support for multiple LLM providers (OpenAI, Anthropic, Google, etc.).

- **Framework Integration**: LangChain agents are built on LangGraph, inheriting durable execution, human-in-the-loop support, and persistence, while LangSmith offers tracing, debugging, and evaluation capabilities for agent behavior and performance.

- **Modular Architecture**: Supports a standard model interface for seamless switching across providers, and a highly configurable harness allowing incremental addition of capabilities (e.g., guardrails, retries) via middleware.
