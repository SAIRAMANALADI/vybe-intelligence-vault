# LangChain overview - Docs by LangChain

## Summary

- **Agent Harness Composition**: LangChain's `create_agent` provides a minimal, highly configurable harness for composing agents from model, tools, prompt, and middleware, supporting multiple providers (OpenAI, Anthropic, Google, etc.).

- **Multi-Framework Support**: Agents can be built using `create_agent` (customizable harness), Deep Agents (batteries-included with features like context compression), or LangGraph (low-level orchestration for deterministic/agentic workflows), with observability via LangSmith.

- **Standardized Interface & Debugging**: LangChain offers a unified interface for chat models/embeddings across providers, incremental harness customization via middleware, and debugging through LangSmith for tracing, tool calls, state transitions, and performance metrics.
