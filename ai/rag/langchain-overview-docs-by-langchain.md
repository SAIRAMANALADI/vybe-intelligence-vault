# LangChain overview - Docs by LangChain

## Summary

- **Modular Agent Harness**: LangChain's `create_agent` provides a minimal, configurable harness combining model, tools, prompt, and middleware, enabling custom agent composition for specific use cases.
- **Multi-Provider Compatibility**: Supports standardized interfaces for chat models and embeddings across providers (OpenAI, Anthropic, Google, etc.), ensuring portability and minimal code changes when switching models.
- **LangGraph Integration & Observability**: Agents leverage LangGraph for durable execution and human-in-the-loop support, with LangSmith enabling trace debugging, tool call inspection, and performance evaluation.
