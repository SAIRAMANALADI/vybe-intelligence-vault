# LangChain overview - Docs by LangChain

## Summary

- **Agent Composition**: `create_agent` in LangChain provides a minimal, configurable harness combining model, tools, prompt, and middleware into a single agent interface, supporting providers like OpenAI, Anthropic, Google, and others.

- **Orchestration Framework**: LangChain agents are built on LangGraph, enabling durable execution, human-in-the-loop support, persistence, and advanced workflows combining deterministic and agentic processes.

- **Observability & Debugging**: LangSmith integrates with agents for tracing, debugging, and evaluating tool calls, state transitions, and latency, with automated issue detection via LangSmith Engine.
