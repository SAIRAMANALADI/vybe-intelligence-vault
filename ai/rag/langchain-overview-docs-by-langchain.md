# LangChain overview - Docs by LangChain

## Summary

- **Modular Agent Harness**: `create_agent` provides a minimal, configurable harness combining model, tools, prompt, and middleware, enabling custom agent composition for specific use cases while supporting multiple LLM providers (OpenAI, Anthropic, Google, etc.).

- **LangGraph Foundation**: LangChain agents are built on LangGraph, inheriting features like durable execution, human-in-the-loop support, persistence, and deterministic workflow integration for advanced orchestration.

- **Observability & Debugging**: LangSmith integrates with agents for tracing, debugging, and evaluating agent behavior, providing insights into traces, tool calls, state transitions, and latency to optimize performance and reliability.
