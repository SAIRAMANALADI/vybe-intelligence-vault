# LangChain overview - Docs by LangChain

## Summary

- **Agent Composition**: `create_agent` provides a minimal, configurable harness for composing agents from model, tools, prompt, and middleware, supporting multiple providers (OpenAI, Anthropic, Google, etc.).
- **Framework Integration**: LangChain agents are built on LangGraph, enabling durable execution, human-in-the-loop support, and persistence, with optional debugging via LangSmith for traces and evaluations.
- **Modularity & Portability**: Supports a standard model interface across providers, allowing minimal code changes for switching models, and incremental capability addition through middleware.
