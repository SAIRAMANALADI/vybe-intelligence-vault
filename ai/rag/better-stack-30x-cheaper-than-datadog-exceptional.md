- **Unified telemetry integration** via MCP server for LLM workflows, enabling no-code instrumentation of clusters with eBPF/OpenTelemetry, real-time service mapping, and AI-driven incident correlation (e.g., smart merging, post-mortems, and Linear ticket suggestions).

- **Advanced observability features** including Apdex/RED metrics, Playwright-based transaction checks, SQL/PromQL querying over HTTP/MCP, and direct S3 log storage with drag-and-drop dashboards for ad-hoc analysis and visualization.
