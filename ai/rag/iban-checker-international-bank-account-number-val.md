# IBAN Checker: International Bank Account Number validation

## Summary

- **IBAN Suite** supports 97 countries (37 SEPA) with format, check digit, and length validations using ISO 13616-1:2007 and MOD 97 (ISO 7064) algorithms; includes domestic validation for 36 countries and branch-level data for 40 countries.

- **API Access** provides REST & SOAP WSDL endpoints for IBAN validation, BIC lookup, and bank account verification (e.g., UK/Ireland via SortWare), enabling integration with CRM/ERP systems.

- **Additional Services** include BIC validation (licensed from SWIFT), SEPA Instant (TIPS) detection, and non-IBAN validation for 196 countries (e.g., US, Japan) via Bank Suite.
