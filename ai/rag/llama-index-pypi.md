# llama-index · PyPI

## Summary

- **Framework Purpose**: LlamaIndex v0.14.23 is an open-source Python framework (MIT License) designed as an interface between LLMs and structured/unstructured data, enabling RAG workflows and agentic applications with modular integrations.

- **Installation & Modularity**: Available via `pip install llama-index` (starter package) or `llama-index-core` (minimal core with 300+ LlamaHub integrations for LLMs, embeddings, and vector stores), supporting Python 3.10+.

- **LlamaParse Integration**: Standalone enterprise document agent platform (LlamaParse) for agentic OCR, structured extraction, and RAG pipelines, with API access for parsing 130+ document formats and deploying document agents.
