# llama-index · PyPI

## Summary

- **Framework Purpose**: LlamaIndex v0.14.23 is an open-source Python framework (MIT-licensed) designed as an interface between LLMs and structured/unstructured data, enabling **Retrieval-Augmented Generation (RAG)** workflows with modular integrations for LLMs, embeddings, and vector stores.

- **Dual Installation Modes**: Supports two Python package structures:
  - **Starter Package**: `llama-index` (bundles core + curated integrations).
  - **Customized Core**: `llama-index-core` (minimal core) with 300+ LlamaHub plugins for extensibility (e.g., `from llama_index.core.llms import LLM` vs. `from llama_index.llms.openai import OpenAI`).

- **LlamaParse Ecosystem**: Standalone enterprise-grade document agent platform (OCR, parsing, structured extraction, RAG) with API-driven workflows (`Parse`, `Extract`, `Index`, `Agents`), requiring Python ≥3.10 and <4.0.
