# llama-index · PyPI

## Summary

- **Framework Purpose**: LlamaIndex v0.14.23 is an open-source Python framework designed as an interface between LLMs and structured/unstructured data, enabling agentic applications with core modules for parsing, indexing, and retrieval.

- **Installation & Structure**: Available via `pip install llama-index` (starter package) or `llama-index-core` (modular core), supporting 300+ integrations via LlamaHub for LLM/embedding/vector store customization with Python ≥3.10 and <4.0.

- **Enterprise Features**: Includes LlamaParse (document agent platform) with OCR, structured extraction (`Extract`), RAG pipelines (`Index`), and agentic workflows (`LlamaAgents`), deployable standalone or integrated with the core framework.
