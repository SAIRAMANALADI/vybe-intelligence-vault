## Summary

- **Locale & Parameter Negotiation**: Defines abstract operations like `CanonicalizeLocaleList`, `ResolveLocale`, and `FilterLocales` for locale resolution, Unicode extension handling (`UnicodeExtensionComponents`), and option coercion (`GetOption`, `GetNumberOption`).

- **Collator Objects**: Specifies `Intl.Collator` constructor behavior, internal slots (e.g., `[[CollatorCompare]]`), and prototype methods (`resolvedOptions`, `compare` with `CompareStrings` implementation).

- **ECMAScript Internationalization API**: Covers constructor properties (`Intl.Collator`, `Intl.DateTimeFormat`, etc.), value properties (`Intl.%Symbol.toStringTag%`), and function properties (`Intl.getCanonicalLocales`, `Intl.supportedValuesOf`).
