# Get started with Firestore Standard edition | Firebase

## Summary

- **Firestore Enterprise Edition (Native Mode)**: Introduces advanced features like **pipelines, enhanced scalability, and improved performance** for high-throughput workloads, now available in Native mode for production-grade deployments.
- **Multi-Platform SDK Support**: Cloud Firestore provides **native SDKs for Android, iOS, Web, and server-side libraries** (C#, Go, Java, Node.js, PHP, Python, Ruby) with **direct client access** when paired with Security Rules and Firebase Authentication.
- **Local Emulator Suite**: Enables **offline prototyping/testing** via the Firestore emulator, allowing developers to simulate database interactions without deploying live services, reducing costs and accelerating development cycles.
