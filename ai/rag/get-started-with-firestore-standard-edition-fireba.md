# Get started with Firestore Standard edition | Firebase

## Summary

- **Firestore Enterprise Edition (Native Mode)**: New enterprise-grade offering with advanced features for high-scale, production workloads, including enhanced performance, security, and integration with Google Cloud's enterprise ecosystem.

- **Multi-Platform SDK Support**: Provides client libraries for **Android, iOS, Web, C#, Go, Java, Node.js, PHP, Python, and Ruby**, enabling direct serverless client access via Security Rules and Firebase Authentication, or privileged server-side access for backend services.

- **Local Emulator Suite Integration**: Supports **Firebase Local Emulator Suite** for offline prototyping/testing, allowing developers to simulate Firestore operations, security rules, and project resources locally before deployment.
