# Get started with Firestore Standard edition | Firebase

## Summary

- **Multi-Platform SDK Support**: Cloud Firestore provides SDKs for mobile (Android, iOS) and web, enabling serverless architectures via direct client-to-database connections, alongside server-side libraries (C#, Go, Java, Node.js, PHP, Python, Ruby) for privileged access.
- **Security Rules & Modes**: Firestore supports two initial security rule modes—**Test mode** (read/write access for rapid prototyping) and **Production mode** (denies mobile/web access, allowing only authenticated server clients).
- **Local Emulator Suite**: Firestore integrates with the Firebase Local Emulator Suite for offline prototyping/testing, enabling emulated database interactions and security rules without live deployments.
