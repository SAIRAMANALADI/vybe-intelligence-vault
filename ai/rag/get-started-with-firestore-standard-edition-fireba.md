# Get started with Firestore Standard edition | Firebase

## Summary

- **Firestore Enterprise Edition (Native Mode)**: New enterprise-grade offering with advanced features like data pipelines, enhanced scalability, and improved performance for large-scale applications.

- **Multi-Platform SDK Support**: Provides client libraries for Android, iOS, Web, and server-side languages (C#, Go, Java, Node.js, PHP, Python, Ruby) with direct client-server integration via Firestore Security Rules and Firebase Authentication.

- **Local Emulator Suite Integration**: Enables offline prototyping/testing with a Firestore emulator, allowing developers to simulate database interactions, security rules, and project resources locally before deployment.
