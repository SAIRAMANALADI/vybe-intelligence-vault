# Nitric Cloud-Native Framework | Get Infrastructure from Code | Nitric

## Summary

- **Deployment & Observability**: Enables sub-10-second application deployments with visual infrastructure canvas, real-time observability, and built-in security; supports frameworks like Django, Node, and Laravel.

- **Infrastructure-as-Code (IaC)**: Allows defining cloud resources directly in application code (JavaScript, Python, Go, Dart) for deployment across AWS, GCP, or Azure.

- **Open-Source Backend Framework**: Provides a declarative SDK (`@nitric/sdk`) for defining APIs and storage (e.g., `bucket("notes")`) with fine-grained access control in code.
