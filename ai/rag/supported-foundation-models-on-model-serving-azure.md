# Supported foundation models on Model Serving - Azure Databricks | Microsoft Learn

## Summary

- **Model Serving Options**: Azure Databricks supports four deployment models for foundation models: **Pay-per-token** (experimentation), **AI Functions** (batch inference), **Provisioned Throughput** (production), and **External Models** (e.g., OpenAI, Anthropic), all routed through **Unity AI Gateway** for governance.

- **Supported Databricks-Hosted Models**: Key models include **Claude 5/4.6/4.5**, **Llama 4 Maverick (preview)**, **Llama 3.3/3.2/3.1**, **Gemma 3 12B**, **Qwen3 122B/80B**, and **GTE/BGE embeddings**, with regional availability constraints (e.g., `australiaeast` supports more models than `australiacentral`).

- **Deprecations & Retirements**: **Claude Sonnet 4**, **Claude 3.7 Sonnet**, and **Llama 3.1 405B** are deprecated/retired; replacements include **Claude Sonnet 5**, **Llama 4 Maverick**, and **Qwen3 variants**, with migration guidance available in [Deprecated and retired models](https://learn.microsoft.com/azure/databricks/machine-learning/retired-models-policy).
