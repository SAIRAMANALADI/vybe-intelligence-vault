# PyPy

## Summary

- **Performance:** PyPy employs a Just-In-Time (JIT) compiler, achieving ~3x speedup over CPython 3.11 by dynamically optimizing hot code paths during execution.

- **Memory Efficiency:** Implements advanced garbage collection (GC) techniques, reducing memory footprint for large-scale Python applications (e.g., hundreds of MBs) compared to CPython.

- **Compatibility & Extensibility:** Fully compatible with CPython, supports CFFI/cppyy for C/C++ integration, and maintains compatibility with major libraries (NumPy, Django) via a c-extension layer, while offering Stackless Python for micro-threaded concurrency.
