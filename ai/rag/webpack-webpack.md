# Releases · webpack/webpack · GitHub

## Summary

- **Patch v5.108.1**: Fixes invalid property access for escaped namespace imports with multi-character mangled export names (`#21280`) and adds frames to `ProfilingPlugin` `TracingStartedInBrowser` event for Chrome DevTools trace loading (`#21269`).

- **Minor v5.108.0**: Introduces ES module detection via top-level `await`/`import.meta`, adds `bun`/`deno` target support, enhances CommonJS reexports, CSS/HTML module improvements, and introduces `universal` target preset with ESM output and multi-platform support.

- **Patch v5.107.2**: Includes optimizations like skipping re-parsing inlined entry modules (`#21167`), extending `avoidEntryIife` fast path (`#21173`), and reusing binary deserialize dispatch tables for cache restoration (`#21175`).
