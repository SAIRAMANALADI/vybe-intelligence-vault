# Docker: Accelerated Container Application Development

## Summary

- **MicroVM-based Isolation**: Docker Sandboxes leverage MicroVMs (e.g., SEV-SNP, TEE) to provide hardware-enforced isolation for agent sessions, locking down network and filesystem access at runtime while extending cloud-grade security to local development.

- **Unified Governance & Hardened Components**: Docker AI Governance enforces identity-bound policies (e.g., Rego-based checks) and audit trails, while Docker Hardened Images (SLSA Level 3, signed, and continuously patched) mitigate supply chain risks without requiring per-machine setup.

- **OCI-Compliant, Zero-Lock-In Stack**: Agents run on existing Docker infrastructure (OCI images/registries/CI) with no ecosystem migration, enabling local-to-cloud scalability while maintaining open standards for portability and compliance.
