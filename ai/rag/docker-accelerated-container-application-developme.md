# Docker: Accelerated Container Application Development

## Summary

- **MicroVM-based isolation**: Docker Sandboxes use MicroVMs (e.g., SEV-SNP) to provide hardware-enforced isolation for agent sessions, locking down network and filesystem access at runtime while extending cloud-grade security to local development.

- **Policy-driven governance & verification**: Docker AI Governance enforces identity-bound policies (e.g., Rego-based checks) and verifies components (e.g., SLSA Level 3, Cosign signatures) before runtime, ensuring least-privilege execution and audit-ready logs.

- **OCI-compliant, zero-lock-in stack**: Agents run on existing Docker infrastructure (images, registries, CI) without ecosystem changes, leveraging open standards for portability across environments (laptop to cloud).
