# Docker: Accelerated Container Application Development

## Summary

- **MicroVM-based isolation**: Docker Sandboxes leverage microVMs (e.g., SEV-SNP, TEE) to provide hardware-enforced isolation for agent sessions, with network/filesystem access locked down at runtime for secure execution.

- **Policy-driven governance & audit**: Docker AI Governance enforces identity-bound policies (e.g., Rego-based rules), verifies signed images (SLSA Level 3, Cosign), and maintains immutable audit logs for compliance without per-machine setup.

- **Zero-lock-in, OCI-compliant stack**: Agents run on existing Docker infrastructure (images, registries, CI) with no ecosystem migration, leveraging open standards (OCI) for portability across environments (local to cloud).
