# Extensible Markup Language (XML) 1.0 (Fifth Edition)

## Summary

- **XML 1.0 Fifth Edition (2008)**: A subset of SGML standardized by W3C, incorporating errata from the Fourth Edition to relax restrictions on element/attribute names, enabling broader compatibility with XML 1.1 features while maintaining backward compatibility.

- **Core Specifications**: Defines XML documents as storage units (entities) containing parsed/unparsed data, with markup encoding logical/physical structure; mandates XML processor behavior for parsing and providing structured data to applications.

- **Design Principles**: Optimized for web interoperability, minimal optional features, and human readability; relies on Unicode (ISO/IEC 10646) for character encoding and BCP 47 for language tags, ensuring formal, concise, and widely implementable syntax.
