# RAG Tutorial 2025: Complete Course Notes — Part 1 | by Pragati Mehra | Medium

## Summary

- **RAG Fundamentals**: Combines LLMs with retrieval systems to fetch external data (documents, databases) for accurate responses without overloading LLM context windows, critical for enterprise-scale applications (e.g., 1M+ tokens).

- **Vector Embeddings & Pipeline**: Chunks documents into fixed-token segments (e.g., 1,000 tokens), converts them into high-dimensional vectors (e.g., 3,072D for OpenAI’s `text-embedding-3-large`), and stores them in vector DBs (e.g., Pinecone, FAISS) for semantic similarity matching.

- **Retrieval & Generation Workflow**: User queries are embedded and matched against stored vectors to retrieve top-*k* relevant chunks, which are then fed to the LLM for contextual answer generation, separating embedding-based retrieval from final text processing.
