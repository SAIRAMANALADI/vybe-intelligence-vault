# RAG Tutorial 2025: Complete Course Notes — Part 1 | by Pragati Mehra | Medium

## Summary

- **RAG Architecture**: RAG combines LLMs with retrieval systems to fetch external information (e.g., documents, databases) for context, avoiding prompt overload by limiting input to relevant chunks rather than entire datasets.

- **Embedding & Vector Databases**: Text is converted into high-dimensional vector embeddings (e.g., 3,072 dimensions for OpenAI’s `text-embedding-3-large`) using specialized models, stored in vector databases (e.g., Pinecone, FAISS) for semantic similarity search during retrieval.

- **Pipeline Workflow**: The system splits into (1) **Injection Pipeline** (chunking documents → embedding → storing in vector DB) and (2) **Retrieval Pipeline** (query embedding → similarity search → top-*k* chunks → LLM generation of final answer).
