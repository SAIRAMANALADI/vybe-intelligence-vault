# RAG Tutorial 2025: Complete Course Notes — Part 1 | by Pragati Mehra | Medium

## Summary

- **RAG Architecture**: Combines LLMs with retrieval systems to fetch external information (e.g., documents, databases) for context, avoiding prompt overload by limiting input to relevant chunks (e.g., 1,000 tokens per chunk) rather than entire datasets (e.g., 10M tokens).

- **Embedding Pipeline**: Chunks are converted into high-dimensional vector embeddings (e.g., OpenAI’s 3,072-dimension vectors) using specialized models, enabling semantic similarity search in vector databases (e.g., Pinecone, Weaviate) to retrieve top-*k* relevant passages for LLM input.

- **Two-Part Workflow**: Injection pipeline ingests and embeds data (chunking → embedding → storage), while retrieval pipeline processes user queries (embedding → similarity matching → top-*k* retrieval → LLM generation) to produce accurate, context-aware responses.
