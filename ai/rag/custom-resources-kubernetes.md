# Custom Resources | Kubernetes

## Summary

- **Custom Resources (CRs)**: Extensions of the Kubernetes API that store structured data, enabling declarative management of custom objects via `kubectl`; can be dynamically registered and managed independently of the cluster lifecycle.

- **CustomResourceDefinitions (CRDs)**: Simplest method to add CRs without programming; defines new resource types with schemas, handled by the Kubernetes API server, but lacks advanced API features like custom storage or validation beyond OpenAPI v3.0.

- **API Aggregation**: Enables custom API servers for advanced CRs, offering features like custom validation, defaulting, multi-versioning, and storage layer control; requires programming and ongoing maintenance but provides greater flexibility than CRDs.
