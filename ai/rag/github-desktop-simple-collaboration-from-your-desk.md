# GitHub Desktop | Simple collaboration from your desktop · GitHub

## Summary

- **Visual Git Workflow Management**: GitHub Desktop provides a GUI for Git operations, enabling users to review code changes via diff tools, manage commit history through drag-and-drop (e.g., cherry-picking, squashing, or reordering), and stash uncommitted changes without branching.

- **Commit History Manipulation**: Supports in-place commit adjustments (e.g., amending messages, reverting changes, or reverting entire commits) directly from the UI, streamlining local codebase maintenance without CLI commands.

- **Cross-Platform Collaboration**: Designed for both novice and expert users, it integrates with GitHub’s ecosystem, facilitating seamless collaboration while abstracting low-level Git complexities for improved developer productivity.
