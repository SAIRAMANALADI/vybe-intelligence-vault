# GitHub Desktop | Simple collaboration from your desktop · GitHub

## Summary

- **GUI-based Git workflow simplification**: Provides an intuitive drag-and-drop interface for commit management (cherry-picking, squashing, reordering) and branch operations, abstracting low-level Git commands while maintaining full functionality.

- **Enhanced diff and stash capabilities**: Offers side-by-side visual diffs with multiple display options (e.g., split, unified, word-level) and supports stashing uncommitted changes for temporary work-in-progress storage without branching.

- **Commit history manipulation**: Enables in-place commit amendments (message edits, file additions) and one-click reversions to prior states, with GitHub integration for direct remote operations (e.g., "View on GitHub").
