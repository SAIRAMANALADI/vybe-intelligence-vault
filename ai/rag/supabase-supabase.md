# supabase/supabase

## Summary

- **Postgres-Centric Platform**: Supabase provides a dedicated PostgreSQL database with extensions like `pgvector` (for vector embeddings), `PostGIS` (geospatial), and `pg_net` (HTTP requests), enabling AI, geospatial, and real-time applications.

- **Backend-as-a-Service (BaaS)**: Integrates PostgREST for auto-generated REST APIs, Supabase Auth for OAuth2/OIDC authentication, and Realtime for WebSocket-based subscriptions, reducing backend boilerplate.

- **Ecosystem & Tooling**: Supports TypeScript/Deno, Next.js examples, and AI workflows via vector embeddings, while offering Firebase-like developer experience with PostgreSQL's robustness.
