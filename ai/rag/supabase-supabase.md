# supabase/supabase

## Summary

- **PostgreSQL-Based Platform**: Supabase provides a dedicated PostgreSQL database with built-in tools for real-time subscriptions, authentication (OAuth2, JWT), and RESTful API generation via PostgREST.

- **AI & Vector Capabilities**: Supports pgvector for vector embeddings, enabling AI/ML applications, and includes PostGIS for geospatial data operations.

- **Ecosystem Integration**: Offers client libraries (TypeScript/Deno) for seamless integration with frameworks like Next.js, Firebase alternatives, and real-time WebSocket-based subscriptions.
