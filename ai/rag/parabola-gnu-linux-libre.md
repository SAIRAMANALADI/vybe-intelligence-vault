# Parabola GNU/Linux-libre

## Summary

- **100% Free Software Compliance**: Parabola GNU/Linux-libre is a fully free OS distribution adhering to the GNU FSDG, ensuring all software components are freely available, modifiable, and redistributable; packages are built from source in clean chroots with networking disabled to replace non-free components from Arch Linux.

- **Arch-Based with Manual Intervention Requirements**: Derived from Arch Linux, it supports armv7h, i686, and x86_64 architectures but requires manual intervention for critical updates (e.g., `iptables-legacy` transition, `dovecot` config migration, OpenRC runlevel adjustments, and `zabbix` shared user account consolidation).

- **Community-Driven Development & Infrastructure**: Operates as a community-driven project with resources for bug tracking, forums, IRC, and mailing lists; maintains a mirror network, package differences reports, and supports libre hardware vendors (Olimex, Vikings) and hosting (1984).
