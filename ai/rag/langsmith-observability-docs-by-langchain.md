# LangSmith Observability - Docs by LangChain

## Summary

- **LangSmith Observability** provides end-to-end visibility into LLM applications, enabling tracing, debugging, and performance monitoring across frameworks like OpenAI, Anthropic, and CrewAI via [available integrations](https://docs.langchain.com/langsmith/integrations).

- **Core features** include automated failure detection (LangSmith Engine), trace filtering/exporting, dashboard-based performance monitoring, and feedback collection via inline annotation or queues.

- **Deployment options** span cloud, hybrid, or self-hosted setups, with all tiers supporting observability, evaluation, prompt engineering, and deployment (see [Usage and billing](https://docs.langchain.com/langsmith/usage-and-billing)).
