# LangSmith Observability - Docs by LangChain

## Summary

- **LangSmith Observability** provides end-to-end visibility into LLM applications, supporting frameworks like OpenAI, Anthropic, CrewAI, and Vercel AI SDK via [available integrations](https://docs.langchain.com/langsmith/integrations).

- **Key features** include trace visualization, performance monitoring via dashboards/alerts, automated issue detection via **Engine**, and user feedback collection through annotation queues.

- **Setup options** include cloud/hybrid/self-hosted deployments with observability, evaluation, prompt engineering, and deployment capabilities; requires API key generation post-account creation ([smith.langchain.com](https://smith.langchain.com)).
