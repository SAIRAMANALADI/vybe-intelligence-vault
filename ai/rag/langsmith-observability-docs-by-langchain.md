# LangSmith Observability - Docs by LangChain

## Summary

- **LangSmith Observability** provides end-to-end visibility into LLM applications, including individual traces, production metrics, and debugging capabilities across frameworks like OpenAI, Anthropic, and CrewAI.

- **Key workflows** include setting up tracing via API keys/SDK, viewing/filtering traces, monitoring performance with dashboards/alerts, automating workflows (webhooks/evaluations), and collecting feedback via inline annotation.

- **Advanced features** include LangSmith Engine for automated failure detection/root cause analysis, multi-deployment options (cloud/hybrid/self-hosted), and MCP integration for real-time IDE/editor support.
