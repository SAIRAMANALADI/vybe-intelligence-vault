# LangSmith Observability - Docs by LangChain

## Summary

- **LangSmith Observability** provides end-to-end visibility into LLM applications, enabling tracing, debugging, and performance monitoring across frameworks like OpenAI, Anthropic, and CrewAI via [available integrations](https://docs.langchain.com/langsmith/integrations).
- **Core features** include trace filtering/exporting, automated failure detection via **LangSmith Engine**, performance dashboards, alerting, and user feedback collection through queues or inline annotations.
- **Setup options** include cloud, hybrid, or self-hosted LangSmith instances, with no-credit-card-required sign-up at [smith.langchain.com](https://smith.langchain.com) and API key configuration for tracing instrumentation.
