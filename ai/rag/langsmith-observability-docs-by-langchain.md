# LangSmith Observability - Docs by LangChain

## Summary

- **LangSmith Observability** provides end-to-end visibility into LLM applications, including individual traces, production metrics, and performance monitoring across frameworks like OpenAI, Anthropic, and CrewAI via [available integrations](https://docs.langchain.com/langsmith/integrations).

- **Key workflows** include: (1) **Tracing setup** via environment variables/SDK, (2) **failure detection** with LangSmith Engine for root-cause analysis, and (3) **automation** via rules, webhooks, and evaluations to monitor quality and resolve issues.

- **Deployment options** include cloud, hybrid, or self-hosted LangSmith instances, supporting observability, evaluation, prompt engineering, and deployment with trace pricing/retention details available in [Usage and billing](https://docs.langchain.com/langsmith/usage-and-billing).
