# LangSmith Observability - Docs by LangChain

## Summary

- **LangSmith Observability** provides end-to-end monitoring of LLM applications, including individual trace analysis, production-wide performance metrics, and debugging capabilities across frameworks like OpenAI, Anthropic, and CrewAI via [available integrations](https://docs.langchain.com/langsmith/integrations).

- **Key workflows** include setting up tracing via API keys, instrumenting applications (e.g., RAG pipelines), viewing/filtering traces, monitoring performance with dashboards/alerts, configuring automations (webhooks, evaluations), and collecting feedback via inline annotations or queues.

- **Advanced features** include **LangSmith Engine** for automated failure detection and root-cause diagnosis, self-hosted/cloud/hybrid deployment options, and MCP integration for real-time documentation access in tools like VSCode.
