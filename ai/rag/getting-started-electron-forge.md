# Getting Started | Electron Forge

## Summary

- **Electron Forge** is a unified toolkit for packaging, distributing, and publishing Electron applications, integrating features like code signing, installer generation, and artifact publishing via a modular plugin system.
- **Packaging limitations** include reliance on `node_modules` (excluding symlinks/Yarn PnP), requiring Yarn ≥2 users to set `nodeLinker: node-modules` and pnpm users to configure `node-linker=hoisted` in `.npmrc`.
- **Initialization & build pipeline** supports templates (e.g., `webpack`, `vite`) via `create-electron-app`, with distributables generated via `make` and published via `publish`, configurable through `forge.config.js`.
