# Getting Started | Electron Forge

## Summary

- **Electron Forge** is an all-in-one toolkit for packaging, distributing, and publishing Electron applications, integrating features like code signing, installer generation, and artifact publishing via a modular Plugin API.
- **Packaging limitations** include reliance on `node_modules` (incompatible with Yarn PnP or symlinked dependencies) and requires specific configurations (`nodeLinker: node-modules` for Yarn ≥2, `node-linker=hoisted` for pnpm).
- **Templates** (`webpack`, `vite`, etc.) provide pre-configured build pipelines with dev servers, while advanced workflows are supported via custom `Makers`, `Publishers`, and lifecycle hooks in `forge.config.js`.
