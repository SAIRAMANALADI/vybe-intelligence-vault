# Getting Started | Electron Forge

## Summary

- **Electron Forge** integrates a modular build pipeline for Electron apps, supporting code signing, installer generation, and artifact publishing via **Plugins**, **Makers**, and **Publishers**.
- **Packaging limitations**: Requires `node_modules` on disk; incompatible with Yarn PnP and symlinked dependencies; Yarn ≥2 must use `node-linker: node-modules`, pnpm must set `node-linker=hoisted` in `.npmrc`.
- **Templates & CLI**: Supports initialization via `create-electron-app` with first-party templates (`webpack`, `vite`, etc.), and distributables are generated via `make` while publishing is handled via `publish` with configurable backends (e.g., GitHub).
