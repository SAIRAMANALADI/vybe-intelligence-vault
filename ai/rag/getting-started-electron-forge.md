# Getting Started | Electron Forge

## Summary

- **Electron Forge** provides a unified build pipeline for Electron apps, including packaging, code signing, installer generation, and artifact publishing, with extensibility via [Plugins](https://electronforge.io/config/plugins), [Makers](https://electronforge.io/config/makers), and [Publishers](https://electronforge.io/config/publishers).

- **Dependencies must be installed in `node_modules`** (not symlinked or Yarn PnP) for packaging; Yarn ≥2 requires `nodeLinker: node-modules`, and pnpm requires `node-linker=hoisted` in `.npmrc`.

- **Templates (`webpack`, `vite`, etc.)** simplify initialization with modern tooling (e.g., bundlers, dev servers), while `forge.config.js` enables advanced customization (e.g., plugins, debugging, custom makers/publishers).
