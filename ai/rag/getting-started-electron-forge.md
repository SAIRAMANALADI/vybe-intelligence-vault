# Getting Started | Electron Forge

## Summary

- **Electron Forge** provides a unified build pipeline for Electron apps, integrating code signing, installers, and artifact publishing; supports customization via **Plugin API**, **Makers**, and **Publishers** for advanced workflows.
- **Packaging limitations**: Requires `node_modules` on disk; incompatible with Yarn PnP and symlinked dependencies; requires `nodeLinker: node-modules` (Yarn ≥2) or `node-linker=hoisted` (pnpm) configurations.
- **Initialization & templates**: Uses `create-electron-app` for project scaffolding; supports first-party templates (`webpack`, `vite`, etc.) with built-in bundling and dev servers; custom templates can be authored via Forge’s template system.
