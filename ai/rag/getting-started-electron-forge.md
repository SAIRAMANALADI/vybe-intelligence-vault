# Getting Started | Electron Forge

## Summary

- **Electron Forge** is a unified toolkit for packaging, distributing, and publishing Electron applications, integrating build pipelines, code signing, installers, and artifact publishing with extensible [Plugin API](https://electronforge.io/config/plugins), [Makers](https://electronforge.io/config/makers), and [Publishers](https://electronforge.io/config/publishers).

- **Packaging constraints**: Requires `node_modules` on disk; does not support Yarn PnP or symlinked dependencies—use `nodeLinker: node-modules` (Yarn ≥2) or `node-linker=hoisted` (pnpm) in `.npmrc`.

- **Initialization & templates**: Use `npx create-electron-app@latest` with optional `--template=[webpack|webpack-typescript|vite|vite-typescript]`; templates integrate modern bundlers (Webpack/Vite) and dev servers for production builds.
