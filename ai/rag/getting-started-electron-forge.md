# Getting Started | Electron Forge

## Summary

- **Electron Forge** is a unified toolkit for Electron app packaging/distribution, integrating build pipelines, code signing, installers, and artifact publishing via a modular **Plugin API**, **Makers**, and **Publishers** for extensibility.
- **Packaging constraints**: Requires `node_modules` on disk; incompatible with Yarn PnP and symlinked dependencies; Yarn ≥2 must use `nodeLinker: node-modules`, pnpm requires `node-linker=hoisted` in `.npmrc`.
- **Initialization & templates**: Projects scaffolded via `create-electron-app` with optional first-party templates (`webpack`, `vite`, etc.), supporting modern JS tooling; distributables generated via `make`, published via `publish` with configurable **Makers**/**Publishers**.
