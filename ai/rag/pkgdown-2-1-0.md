# pkgdown 2.1.0

## Summary

- **Bootstrap 3 Deprecation**: Support for Bootstrap 3 has been officially deprecated in favor of Bootstrap 5, with removal of deprecated `document` argument in `build_site()` and `build_reference()` functions, and deprecation warnings for `autolink_html()` and `preview_page()`.

- **Quarto Vignette Support & Light/Dark Mode Toggle**: New support for Quarto vignettes in `build_article()`/`build_articles()`, and introduction of a light/dark mode switch via `template.light-switch: true` in `_pkgdown.yml`, with math rendering options (`mathml`, `mathjax`, `katex`).

- **Accessibility & Developer Enhancements**: Improved accessibility with alt-text warnings for images, direct linking to function arguments in `build_reference()`, lifecycle badges in reference index, removal of external CDN dependencies, and better YAML validation with clearer error messages.
