# Use Agent Mode - Visual Studio (Windows) | Microsoft Learn

## Summary

- **Autonomous Task Execution**: GitHub Copilot agent mode in Visual Studio autonomously performs high-level tasks via natural language prompts, iteratively executing code edits, terminal commands, and tool invocations while monitoring outcomes (e.g., build results, test failures) until the goal is achieved or further input is required.

- **Tool Integration & Hierarchical Navigation**: Supports built-in, MCP, and custom tools (e.g., `find_symbol`, `get_symbol_call_hierarchy`, `get_symbol_class_hierarchy`) for cross-project symbol resolution, C++ call/class hierarchy traversal, and task-specific agent skills, with user-controlled tool approvals and configuration.

- **Multi-Level Edit Management**: Provides granular control over code changes via cumulative/individual diff reviews, selective keep/undo per file or chunk, and checkpoint-based rollback, with future support for multi-file summary diff views in VS 2026 v18.6.
