# [2004.09813] Making Monolingual Sentence Embeddings Multilingual using Knowledge Distillation

## Summary

- **Knowledge Distillation Method**: Extends monolingual sentence embedding models to multilingual by training a new system to map translated sentences to the same vector space as original sentences using the original model's embeddings as a teacher signal.

- **Efficiency & Scalability**: Requires fewer training samples per new language, ensures desired vector space properties, and reduces hardware requirements compared to traditional multilingual embedding training methods.

- **Empirical Validation**: Demonstrated effectiveness across 50+ languages from diverse families, with publicly available code supporting extension to over 400 languages.
