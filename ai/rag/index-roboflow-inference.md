# Index - Roboflow Inference

## Summary

- **Model Types**: Supports object detection (bounding boxes), instance segmentation (shape/size/location), single/multi-label classification, semantic segmentation (pixel-level class labels), keypoint detection (skeletons), depth estimation, OCR (text extraction), barcode/QR detection, and various vision-language models (e.g., Anthropic Claude, Google Gemini, OpenAI, Florence-2, Qwen-VL).

- **Visualization Tools**: Provides bounding box, polygon, mask, heatmap, and keypoint visualizations; includes transformations like blurring, pixelation, color overlays, and dynamic/static cropping; supports model comparison and trace/path overlays for tracking.

- **Workflow Components**: Includes logic filters (e.g., confidence thresholds, overlap checks), data storage sinks (e.g., Roboflow datasets, S3, SQL), notifications (Slack, SMS/email), and classical CV tools (e.g., SIFT, template matching, morphological transformations).
