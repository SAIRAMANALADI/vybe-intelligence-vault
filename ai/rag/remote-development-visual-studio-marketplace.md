# Remote Development - Visual Studio Marketplace

## Summary

- **Extension Pack Functionality**: Enables remote development by opening folders in containers, remote machines (via SSH or VS Code Tunnels), or WSL, leveraging VS Code's full feature set without requiring source code on the local machine.

- **Supported Components**: Includes four extensions—Remote-SSH (Linux/Windows/macOS), Remote-Tunnels (alternative to SSH), Dev Containers (Docker-based toolchains), and WSL (Linux-powered Windows development)—with specific OS/architecture support (x86_64, ARMv7/8, Alpine Linux, etc.).

- **Installation Requirements**: Requires VS Code, Docker (for containers), WSL2 (Windows), OpenSSH (for SSH), and user/group permissions (e.g., `docker` group membership); telemetry is opt-in and limited to command execution data.
