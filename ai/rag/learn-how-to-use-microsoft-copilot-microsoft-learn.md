# Learn how to use Microsoft Copilot | Microsoft Learn

## Summary

- **Integration with Microsoft 365**: Microsoft 365 Copilot is an AI-powered assistant integrated into Microsoft 365 apps (e.g., Word, Excel, PowerPoint, Outlook) to enhance productivity by automating tasks, generating content, and providing contextual insights.

- **Context-Aware AI**: Leverages large language models (LLMs) and Microsoft Graph data (emails, documents, meetings) to deliver personalized, context-aware responses and actions within the user’s workflow.

- **Enterprise Security & Compliance**: Built on Microsoft’s security, privacy, and compliance frameworks (e.g., Zero Trust, GDPR), ensuring data protection while enabling AI-driven collaboration across organizations.
