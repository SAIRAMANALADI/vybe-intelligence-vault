# Project Fugu API Showcase | Capabilities | Chrome for Developers

## Summary

- **Project Fugu API Showcase**: A curated collection of web apps demonstrating experimental APIs developed under Project Fugu, enabling advanced web capabilities (e.g., file system access, Bluetooth, NFC).
- **Key APIs Demonstrated**: Includes 40+ APIs such as Async Clipboard, WebHID, WebUSB, File System Access, and WebGPU, showcasing high-privilege web features.
- **Submission & Resources**: Developers can submit their own Fugu-powered apps via a Google Form; detailed documentation is available on the [Capabilities](https://developer.chrome.com/docs/capabilities) landing page.
