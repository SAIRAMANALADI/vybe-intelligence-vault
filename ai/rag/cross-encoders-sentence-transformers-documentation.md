# Cross-Encoders — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`pip`, `conda`, `uv`, source) with optional CUDA-enabled PyTorch for GPU acceleration; includes editable installs for development.

- **Core Functionality**: Provides `SentenceTransformer`, `CrossEncoder`, `SparseEncoder`, and `Multi-Vector Encoder` architectures for embedding generation, semantic similarity, and retrieval tasks with modular customization options.

- **Advanced Features**: Includes quantization (binary/int8), multi-GPU inference, MTEB evaluation framework, and support for multimodal (image/text, audio/video) and multilingual models with pre-trained checkpoints.
