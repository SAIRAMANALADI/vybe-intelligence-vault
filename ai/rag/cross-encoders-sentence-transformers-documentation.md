# Cross-Encoders — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with PyTorch CUDA support; includes migration guides for major version updates (v2.x→v5.x) with changes in import paths, parameter renaming (e.g., `max_length`→`max_seq_length`), and API deprecations.

- **Sentence Transformer Functionality**: Enables computing embeddings, semantic textual similarity, semantic search (symmetric/asymmetric), clustering (k-Means, agglomerative), paraphrase mining, and multimodal (image/text) applications; supports quantization (binary/int8) and efficiency optimizations (ONNX, OpenVINO).

- **Training & Evaluation**: Provides modular training components (model, dataset, loss, evaluator) with pre-trained models for semantic search, multilingual, and multimodal tasks; integrates MTEB for standardized evaluation and leaderboard submissions.
