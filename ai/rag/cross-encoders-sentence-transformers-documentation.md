# Cross-Encoders — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with optional PyTorch CUDA support; includes migration guides for major version updates (v2.x→v5.x) with API changes (e.g., `CrossEncoder.max_length` → `max_seq_length`, `tokenizer` → `processing_class`).

- **Sentence Transformer Capabilities**: Enables computing embeddings, semantic textual similarity, semantic search (symmetric/asymmetric), clustering (k-Means, agglomerative), paraphrase mining, and multimodal (text/image/audio) applications; supports quantization (binary/int8) and custom model creation via modular architecture.

- **Training & Evaluation**: Provides training components (model, dataset, loss, evaluator) with MTEB benchmark integration; includes pre-trained models for semantic search, multilingual, multimodal, and scientific domains; supports speed optimization via PyTorch, ONNX, and OpenVINO.
