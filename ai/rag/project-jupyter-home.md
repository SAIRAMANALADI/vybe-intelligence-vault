# Project Jupyter | Home

## Summary

- **JupyterLab** is a modular, extensible web-based IDE supporting notebooks, code, and data with flexible workspace configurations (single/multi-document) for scientific computing and ML workflows.

- **Jupyter Notebook** is a document-centric, web-based interface for creating/sharing computational documents with support for 40+ languages, rich interactive outputs (HTML, LaTeX, etc.), and big data integration (Spark, pandas, TensorFlow).

- **JupyterHub** enables centralized, scalable deployments (Docker/Kubernetes) with pluggable authentication (PAM/OAuth), multi-user access, and data-adjacent deployment for unified software/data management.
