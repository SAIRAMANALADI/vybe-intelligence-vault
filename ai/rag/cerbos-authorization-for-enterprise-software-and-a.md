# Cerbos: Authorization for Enterprise Software and AI

## Summary

- **Fine-grained, contextual authorization engine**: Enforces runtime policy decisions (RBAC, ABAC, ReBAC, PBAC) across applications, APIs, workloads, and AI agents with event-time and admin-time policy evaluation, supporting cloud, on-prem, and air-gapped deployments.

- **Real-time access governance for AI/ML systems**: Provides MCP server security, RAG authorization, and AI gateway governance with instant revocation capabilities, ensuring non-human identities (AI agents, service accounts) adhere to least-privilege access.

- **Compliance-ready audit infrastructure**: Generates immutable, structured logs for every access decision (SOC 2, ISO 27001, HIPAA, GDPR, FedRAMP, etc.), enabling forensic auditing and centralized policy lineage tracking across distributed systems.
