# huggingface/text-embeddings-inference

## Summary

- **High-performance Rust framework** optimized for low-latency text embeddings inference, leveraging hardware acceleration (e.g., AVX-512, CUDA) for scalable throughput.
- **Supports major embedding models** (e.g., SentenceTransformers, BERT variants) with dynamic batching and automatic precision (FP16/INT8) for efficiency.
- **Integrates with Hugging Face ecosystem** via optimized `text-embeddings-inference` (TEI) server, offering REST/gRPC APIs and compatibility with `sentence-transformers` pipelines.
