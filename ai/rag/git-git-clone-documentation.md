# Git - git-clone Documentation

## Summary

- **Git** is a distributed version control system (DVCS) using SHA-1 hashes for object integrity, supporting both local and remote repository operations via protocols like HTTPS, SSH, and Git-native.

- **Core commands** include `clone`, `commit`, `merge`, `rebase`, `push`, and `pull`, with additional tools for debugging (`bisect`, `blame`), patching (`cherry-pick`, `format-patch`), and repository administration (`gc`, `fsck`).

- **Plumbing vs. Porcelain**: Git distinguishes between low-level "plumbing" commands (e.g., `cat-file`, `hash-object`) for scripting and high-level "porcelain" commands (e.g., `add`, `status`) for user workflows, with comprehensive documentation available in localized versions.
