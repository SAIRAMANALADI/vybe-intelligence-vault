## Summary

- **Core RAG Architecture**: Combines retrieval (dense/sparse embeddings via vector DBs like Supabase) and generation (LLMs) with chunking strategies (e.g., semantic, fixed-size) for contextual augmentation, implemented via frameworks like LangChain.

- **Production Optimization**: Focuses on embedding model selection (e.g., `text-embedding-3-large`), hybrid retrieval (BM25 + vector search), caching (e.g., Redis), and latency reduction via Cloudflare Workers for edge deployment.

- **Monitoring & Scaling**: Integrates Sentry for observability, enforces token cost limits (e.g., 8K context window), and employs load balancing across multiple LLM instances with multi-modal RAG support for images/PDFs.
