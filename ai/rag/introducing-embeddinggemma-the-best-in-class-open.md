# Introducing EmbeddingGemma: The Best-in-Class Open Model for On-Device Embeddings - Google Developers Blog

## Summary

- **Performance & Efficiency**: EmbeddingGemma is a 308M-parameter open embedding model optimized for on-device AI, delivering best-in-class performance (top-ranked under 500M on MTEB) with <200MB RAM usage via quantization-aware training (QAT) and Matryoshka representation learning (MRL) for flexible dimensional output (768 to 128).

- **On-Device & Offline Capabilities**: Designed for mobile/edge deployment, it supports 2K token context windows, <15ms inference latency (EdgeTPU, 256 tokens), and integrates with tools like sentence-transformers, Llama.cpp, and Transformers.js for offline RAG, semantic search, and privacy-centric applications.

- **Multilingual & Tooling Support**: Trained on 100+ languages, it outperforms larger models in multilingual tasks and is compatible with frameworks (e.g., Ollama, LiteRT, Weaviate) and Gemma 3n for mobile-first pipelines, with model weights available on Hugging Face, Kaggle, and Vertex AI.
