# CiscoDevNet/grpc-getting-started

## Summary

- **gRPC Implementation on Cisco IOS XR**: Provides a step-by-step guide for enabling gRPC services on Cisco IOS XR devices, including configuration of gRPC server, authentication, and TLS setup.
- **Protocol Buffers (protobuf) Integration**: Demonstrates the use of Protocol Buffers for defining data models and generating client/server stubs for gRPC communication with Cisco IOS XR.
- **YANG Model Utilization**: Includes examples of leveraging YANG models for structured data modeling and interaction with Cisco IOS XR's native data models via gRPC.
