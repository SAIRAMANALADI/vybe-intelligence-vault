# The /llms.txt file – llms-txt

## Summary

- **Purpose & Structure**: `/llms.txt` is a standardized markdown file (located at `/llms.txt` or subpaths) designed to provide LLM-friendly, concise, and structured information about a website, addressing context window limitations by linking to curated markdown versions of key pages (e.g., `page.html.md`).
- **Format Specification**: The file must include an H1 project name, an optional summary blockquote, optional detailed sections, and H2-delimited file lists with `[name](url): notes` entries; an "Optional" section allows non-critical links to be skipped for brevity.
- **Integration & Tools**: Supports programmatic parsing (e.g., `llms_txt2ctx` CLI) and integrates with frameworks (VitePress, Docusaurus) and CMS (Drupal); complements `robots.txt` and `sitemap.xml` by providing curated, inference-time context for LLMs.
