# Resemble AI Deepfake Detector - Chrome Web Store

## Summary

- **Detection Engine**: Uses Resemble AI's proprietary detection technology to analyze images, videos, and audio for AI-generated content, providing instant verdicts (Authentic, AI Generated, or Uncertain) with confidence scores and breakdowns.

- **Technical Features**: Supports frame-by-frame video analysis, audio waveform and segment analysis, image heatmap visualization, and C2PA content credentials display; integrates via browser extension with a one-click scan functionality.

- **Limitations & Requirements**: Free beta version allows 4 scans/day; requires a Resemble AI account; supports formats like PNG, JPEG, MP4, WAV, and more across web platforms.
