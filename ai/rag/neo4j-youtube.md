# Neo4j - YouTube

## Summary

- **Platform Architecture**: YouTube operates as a distributed system leveraging Google's infrastructure, utilizing technologies like Bigtable, MapReduce, and Colossus for scalable storage and processing of petabytes of video data.

- **Content Delivery Network (CDN)**: Employs a multi-tiered CDN with edge caching (using Google's global network) to optimize latency and throughput for video streaming, supporting adaptive bitrate protocols (e.g., DASH, HLS).

- **Recommendation Engine**: Utilizes deep learning models (e.g., neural collaborative filtering, transformers) trained on user interaction data (watch time, likes, shares) to personalize content recommendations, with real-time updates via Apache Beam and TensorFlow.
