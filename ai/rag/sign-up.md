# Sign up

## Summary

- **OAuth 2.0 Integration**: Supports Google, Microsoft, and GitHub OAuth for third-party authentication via WorkOS, with OAuth flows redirecting to `login.llamaindex.ai` and callback handling at `api.cloud.llamaindex.ai`.

- **Session Management**: Uses `authorization_session_id` (e.g., `01KWPZ19A9Y1N8EXW3P86CN9JD`) to track and validate user sessions during authentication.

- **Regional Endpoints**: Provides region-specific login endpoints (`login.llamaindex.ai` for global, `login.eu.llamaindex.ai` for EU) with identical OAuth configurations.
