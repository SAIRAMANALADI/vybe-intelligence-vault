# Contributing guide — Zulip 12.0-dev+git documentation

## Summary

- **Architecture**: Zulip uses a hybrid Django (Python) and Tornado (async) backend, with nginx for reverse proxying, PostgreSQL for data storage, Redis for caching, RabbitMQ for message queuing, and Supervisor for process management.

- **Release Lifecycle**: Server versions follow semantic versioning with stable releases (e.g., 12.x, 13.x) and Git-based development builds; client apps (mobile, desktop, terminal) have independent but compatible release cycles.

- **Dependencies & Compatibility**: Requires Python 3.7+, PostgreSQL 12+, Redis 5+, and supports OS-level dependencies via Docker; API bindings (Python, JavaScript, etc.) ensure cross-platform integration.
