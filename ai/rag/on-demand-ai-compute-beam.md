# On-Demand AI Compute | Beam

## Summary

- **Multi-Cloud GPU Runtime**: Beam provides a unified AI runtime across AWS, GCP, Azure, and other clouds with sub-second cold starts (0.0s via memory snapshots) and massive parallelism, enabling 35× faster container boot times compared to traditional methods (e.g., Kubernetes + EC2).

- **Stateful Sandboxes & Autoscaling**: Supports persistent, stateful sandboxes with GPU/CPU flexibility, Docker-in-Docker execution, and snapshot-based branching for concurrent isolated runs. Includes durable task queues with retries, callbacks, and autoscaling (e.g., `QueueDepthAutoscaler` for dynamic scaling).

- **Hardware-Agnostic Deployment**: Enables seamless hardware switching (e.g., H100 to A10G) via Python SDK, local debugging mirroring production, and integration with CI/CD (GitHub Actions). Supports custom inference (vLLM, Whisper), training (Gemma fine-tuning), and web apps (Streamlit/Gradio).
