# Daring Fireball: Markdown Syntax Documentation

## Summary

- **Markdown Syntax Design**: Prioritizes human readability by using punctuation characters resembling their semantic meaning (e.g., `*` for emphasis, `#` for headers) and is inspired by plain-text email conventions, ensuring plain-text documents remain publishable without visual markup clutter.

- **Inline HTML & Escaping**: Supports inline HTML for unsupported elements (e.g., `<table>`) without additional delimiters, while automatically escaping `<` and `&` in prose (e.g., `AT&T` → `AT&T`) but preserving them in code spans/blocks for syntax fidelity.

- **Block Elements & Lists**: Implements email-style blockquotes (`>`) and supports two header styles (Setext underlined `=`/`-` and Atx hash-prefixed `#`), with ordered/unordered lists using interchangeable markers (`*`, `+`, `-`, `1.`) and optional lazy numbering (output ignores source numbering).
