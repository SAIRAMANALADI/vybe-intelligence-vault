# Vespa Demos

## Summary

- **Video Search Demo**: Demonstrates Vespa's multimodal search capabilities by enabling semantic search across video content using advanced embeddings and retrieval techniques.

- **Reverse Image Search Demo**: Scales to 1.28M images using DINOv2 embeddings and binary quantization in Vespa, comparing rank profiles (binary HNSW, binary+float rerank, full-precision float) for recall vs. storage tradeoffs.

- **Personalized E-Commerce Search Demo**: Features a 3M-product catalog with real-time persona-based reranking via click interactions, blending Vespa rank profiles and optional LightGBM second-phase GBDT reranking.
