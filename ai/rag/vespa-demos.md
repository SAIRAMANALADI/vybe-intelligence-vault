# Vespa Demos

## Summary

- **Video Search Demo**: Demonstrates Vespa's multimodal semantic search capabilities for video content, enabling retrieval of relevant videos based on semantic queries.
- **Reverse Image Search Demo**: Scales to 1.28M images using DINOv2 embeddings and binary quantization in Vespa, with three rank profiles (binary HNSW, binary+float rerank, full-precision float) for recall vs. storage tradeoff analysis.
- **Personalized E-Commerce Search Demo**: Features a 3M-product catalog with real-time persona-based reranking via Vespa's global-phase blending and optional LightGBM second-phase GBDT rerank, supporting typo-tolerant fuzzy retrieval.
