# Vespa Demos

## Summary

- **Video Search**: Demonstrates Vespa's multimodal semantic search capabilities by enabling vector-based retrieval across video content using advanced embeddings and hybrid ranking.
- **Reverse Image Search**: Scales to 1.28M images using DINOv2 embeddings and binary quantization in Vespa, with comparative ranking profiles (binary HNSW, hybrid, and full-precision float) to evaluate recall-storage tradeoffs.
- **Personalized E-Commerce Search**: Real-time personalized ranking over a 3M-product catalog using dynamic persona vectors and LightGBM reranking, with typo-tolerant fuzzy retrieval fallback for misspelled queries.
