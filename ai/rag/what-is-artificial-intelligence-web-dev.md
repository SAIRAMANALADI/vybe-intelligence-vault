# What is artificial intelligence? | web.dev

## Summary

- **AI Fundamentals**: AI encompasses non-human programs/models leveraging machine learning (ML) to perform tasks like problem-solving, creativity, and generative content creation (e.g., LLMs, SLMs, foundation models) via training on curated datasets and inference on new data.

- **AI Deployment Models**: AI inference occurs either client-side (browser-based, e.g., Transformers.js, TensorFlow.js) for low-latency/privacy or server-side (cloud-based, e.g., Gemini) for high-capacity tasks; hybrid models combine both approaches for scalability.

- **Key Challenges**: AI adoption faces issues like data quality/recency, ethical biases (e.g., MST Scale mitigation), security/privacy risks (third-party exposure), and requires techniques like RLHF/LoRA for model tuning to align with specific use cases.
