# rfc6480.html

## Summary

- **RPKI Architecture**: Defines a hierarchical X.509-based PKI (RPKI) to cryptographically attest IP address/AS number allocations, leveraging RFC 3779 extensions and RFC 5280 profiles for resource certificates and CRLs.

- **Signed Objects & Repositories**: Introduces Route Origination Authorizations (ROAs) (RFC 6482) and manifests (RFC 6486) as CMS-signed objects (RFC 5652), stored in a distributed repository system for BGP route validation.

- **Trust Model & Operations**: Uses trust anchors at IANA/RIRs, enabling resource holders (ISPs/LIRs) to issue subordinate certificates/ROAs without identity verification, simplifying CA roles while ensuring prefix-to-AS authorization for BGP filtering.
