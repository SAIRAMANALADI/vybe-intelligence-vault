# Project Summaries - Python Packaging User Guide

## Summary

- **`bandersnatch`**: PyPI mirroring client (PEP 517-compliant) enabling local PyPI replicas for reduced CDN load and faster dependency resolution, supporting local storage or AWS S3 backends.
- **`distlib`**: Low-level Python packaging library implementing legacy and modern PEPs (e.g., dependency resolution, metadata parsing) with fallback behaviors for pre-standard packages.
- **`packaging`**: Core utility library used by `pip`/`setuptools` for parsing version specifiers, markers, and requirements per PyPA interoperability standards, enforcing strict compliance for modern packages.
