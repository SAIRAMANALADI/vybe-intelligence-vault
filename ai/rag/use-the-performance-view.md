# Use the Performance view

## Summary

- **Performance Analysis**: Flutter's DevTools Performance view provides UI/raster thread frame timing analysis (60/120 FPS targets) to diagnose jank, with color-coded bars for UI (Dart VM) and raster (GPU) workloads, including shader compilation tracking (marked in dark red).
- **Advanced Debugging**: Supports enhanced tracing (widget builds, layouts, paints), layer-specific debugging (clip/opacity/physical shape toggles), and frame analysis hints to identify expensive operations contributing to slow frames.
- **Data Export/Import**: Allows exporting performance snapshots for offline analysis and importing previously exported files via drag-and-drop, with support for timeline event tracing (including custom `dart:developer` events).
