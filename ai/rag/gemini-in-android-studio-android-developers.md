# Gemini in Android Studio - Android Developers

## Summary

- **Agentic AI Integration**: Gemini in Android Studio provides an agentic AI assistant for Android development, enabling multi-stage task automation (e.g., unit test generation, UI alterations, bug fixes) via **Agent Mode**, which formulates execution plans across project files and iteratively refines changes based on developer feedback.

- **Multimodal & Context-Aware Features**: Supports **image-based UI prototyping** (converting wireframes/mockups to working code) and **context-aware assistance** (e.g., crash analytics via App Quality Insights, Compose UI previews, and Gradle build error resolution), all while maintaining data privacy via configurable `.aiexclude` files.

- **Enterprise-Grade Offerings**: **Gemini Code Assist** extends core features with IP indemnification, VPC-SC compliance, and customized code suggestions from Git repositories, available in **Standard ($19/user/month)** and **Enterprise ($45/user/month)** tiers, including access to advanced tools like Firebase, BigQuery, and Colab Enterprise.
