# Welcome to Just Great Software

## Summary

- **PowerGREP**: A high-performance grep tool supporting Perl-compatible regex (PCRE) for searching/replacing text/binary files (e.g., source code, logs) with features like Unicode support, complex replacements, and large file handling.

- **RegexBuddy/RegexMagic**: RegexBuddy enables creation, analysis, and testing of regex patterns with code integration, while RegexMagic simplifies regex generation via pattern-based GUI for common data types (e.g., emails, URLs) across multiple regex flavors.

- **EditPad Pro/Lite**: EditPad Lite is a lightweight Unicode-compliant text editor with essential features (e.g., regex search, tabbed interface), while EditPad Pro adds advanced capabilities (e.g., 4GB+ file support, syntax highlighting, FTP/SFTP, hex mode, project management).
