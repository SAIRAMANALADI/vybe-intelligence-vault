# semantic-mediawiki.org

## Summary

- **Extension to MediaWiki**: Semantic MediaWiki (SMW) is an open-source extension for MediaWiki (the software behind Wikipedia) that enables structured data storage and querying within wiki pages, transforming it into a knowledge management system.

- **Semantic Web Integration**: SMW supports seamless data export and publication via the Semantic Web, allowing interoperability with other systems through standardized formats like RDF.

- **Versioning & Community**: SMW follows a structured release cycle (e.g., v7.0.0 as of June 2026) with active development tracked on GitHub, supported by a community-driven ecosystem of extensions and documentation.
