# GitHub Features · GitHub

## Summary

- **GitHub Copilot & AI Integration**: Provides inline code suggestions (whole lines/functions) via AI, with advanced features like Copilot Chat for AI-driven development assistance and Copilot Autofix for automated vulnerability remediation in supported languages (JavaScript, TypeScript, Java, Python).

- **Automation & CI/CD Pipeline**: GitHub Actions enables workflow automation (build, test, deploy) with preconfigured templates, while GitHub-hosted/self-hosted runners support scalable execution across multiple OS/architectures (Linux, macOS, Windows, ARM, GPU).

- **Security & Supply Chain Protection**: GitHub Advanced Security (GHAS) integrates code scanning (CodeQL), secret scanning, Dependabot for vulnerability alerts/updates, and dependency graph visualization to proactively detect/fix vulnerabilities and manage supply chain risks.
