# GitHub Features · GitHub

## Summary

- **GitHub Copilot** integrates AI-driven code suggestions directly into editors, enabling real-time generation of entire functions or lines of code, while **Copilot Chat** provides an interactive AI assistant for debugging, documentation, and code explanations.

- **GitHub Advanced Security (GHAS)** offers automated vulnerability detection via **CodeQL** and **secret scanning**, with **Copilot Autofix** resolving 90% of alerts in supported languages (JavaScript, TypeScript, Java, Python) and **security campaigns** addressing up to 1,000 alerts simultaneously.

- **GitHub Actions** enables end-to-end CI/CD automation with **preconfigured workflow templates**, **self-hosted runners** for custom environments, and **workflow visualization** for real-time tracking, while **GitHub Projects** provides agile project management with customizable boards, milestones, and dependency insights.
