# GitHub Features · GitHub

## Summary

- **GitHub Copilot**: AI-powered code completion and generation, providing whole-line or function-level suggestions directly in the editor, with additional capabilities like Copilot Chat for AI-driven code review and debugging.

- **GitHub Advanced Security (GHAS)**: Integrated suite for application security, including CodeQL-based code scanning, secret scanning, Dependabot for dependency management, and AI-driven autofixes (GitHub Copilot Autofix) to remediate 90% of alert types in supported languages.

- **GitHub Actions & CI/CD**: End-to-end automation platform with hosted and self-hosted runners, workflow visualization, and preconfigured templates; supports complex pipelines for building, testing, and deploying software with thousands of community actions via GitHub Marketplace.
