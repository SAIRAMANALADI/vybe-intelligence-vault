# GitHub Features · GitHub

## Summary

- **GitHub Copilot & AI Integration**: Provides in-editor code suggestions, AI-powered code review (Copilot Autofix), and automated vulnerability remediation for 90% of alert types in supported languages (JavaScript, TypeScript, Java, Python).

- **CI/CD & Automation**: GitHub Actions enables workflow automation (build, test, deploy) with 10,000+ pre-built actions; supports self-hosted and GitHub-hosted runners (Linux, macOS, Windows, ARM, GPU) for scalable execution.

- **Security & Supply Chain**: GitHub Advanced Security (GHAS) integrates code scanning (CodeQL), secret scanning, Dependabot for dependency updates, and dependency graph for vulnerability tracking across repositories.
