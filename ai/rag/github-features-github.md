# GitHub Features · GitHub

## Summary

- **AI-Powered Development**: GitHub Copilot provides inline code suggestions (whole lines/functions) and AI-driven code reviews, while Copilot Autofix automates remediation of 90% of security alerts in supported languages (JavaScript, TypeScript, Java, Python).

- **CI/CD & Automation**: GitHub Actions enables workflow automation (build/test/deploy) with 10,000+ community actions, while GitHub-hosted runners support multi-OS/architectures (Linux, Windows, macOS, ARM, GPU) and self-hosted runners offer customizable environments.

- **Security & Compliance**: GitHub Advanced Security (GHAS) integrates code scanning (CodeQL), secret scanning, Dependabot for dependency updates, and security campaigns to bulk-fix vulnerabilities, with dependency graphs and advisories for supply chain risk management.
