# GitHub Features · GitHub

## Summary

- **GitHub Copilot**: AI-powered code completion and generation, providing whole-line or function-level suggestions directly in the editor, with additional capabilities like AI-driven code review and autofix for security vulnerabilities in supported languages (JavaScript, TypeScript, Java, Python).

- **GitHub Advanced Security (GHAS)**: Integrated security suite featuring CodeQL-based static analysis, secret scanning (including AI-enhanced detection), Dependabot for dependency vulnerability management, and automated remediation via GitHub Copilot Autofix for 90% of alert types.

- **GitHub Actions & CI/CD**: Native automation platform with GitHub-hosted runners (Linux, macOS, Windows, ARM, GPU) and self-hosted runner support, enabling workflow orchestration, package management (GitHub Packages), and preconfigured templates for standardized deployment pipelines.
