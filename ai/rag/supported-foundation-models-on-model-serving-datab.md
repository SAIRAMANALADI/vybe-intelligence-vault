# Supported foundation models on Model Serving | Databricks on AWS

## Summary

- **Databricks Model Serving** supports four deployment modes for foundation models: **pay-per-token** (experimental), **AI Functions** (batch inference), **provisioned throughput** (production), and **external models** (e.g., OpenAI, Anthropic) via Unity AI Gateway for governance.

- **Deprecated models** include `Meta-Llama-3.1-405B-Instruct` (retired May 15, 2026), `Gemini 2.5 Flash/Pro`, `Claude Sonnet 4`, and `Claude 3.7 Sonnet`, with replacements like `databricks-gpt-5-*` and `databricks-claude-sonnet-5` available.

- **Region-specific model availability**: `ap-northeast-1` supports models like `databricks-gpt-5-*`, `databricks-gemini-3-*`, `databricks-claude-*`, and `databricks-llama-4-maverick`, with full lists defined per region in Databricks documentation.
