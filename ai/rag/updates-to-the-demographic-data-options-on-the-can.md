# Updates to the demographic data options on the Candid profile

## Summary

- **Updated Race/Ethnicity Categories**: Added *Middle Eastern/North African* and *Native Hawaiian/Pacific Islander* as new options, while refining labels (e.g., *Asian/Asian American*, *Black/African American*, *Native American/American Indian/Alaska Native/Indigenous*) to align with federal standards (e.g., 1997 OMB guidelines and 2023 proposed updates).

- **Data Collection Implications**: Initial underreporting expected for new categories; misclassification may occur for prior responses (e.g., Pacific Islanders previously grouped under *Asian/Asian American*), requiring updates to profiles for accuracy.

- **Guiding Principles**: Changes prioritize nonprofit efficiency (minimizing redundant data collection), maximize participation via simplified categories, and ensure interoperability with existing standards (e.g., U.S. Census, American Community Survey) to support equitable sector-wide analysis.
