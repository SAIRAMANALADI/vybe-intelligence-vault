# [2407.10930] Fine-Tuning and Prompt Optimization: Two Great Steps that Work Better Together

## Summary

- **Combined Optimization Framework**: Proposes an alternating optimization strategy for modular NLP pipelines (e.g., RAG) that jointly optimizes language model (LM) weights and prompt templates, enabling self-improvement without intermediate labels or gradient flow.

- **Performance Gains**: Demonstrates up to **60% improvement** over weight-only optimization and **6% over prompt-only optimization** across tasks (multi-hop QA, math reasoning, classification) using models like Mistral-7B and Llama variants.

- **Implementation & Release**: Introduces the **BetterTogether optimizer** in DSPy, enabling end-to-end pipeline optimization via alternating weight and prompt tuning.
