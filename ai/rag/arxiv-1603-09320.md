# [1603.09320] Efficient and robust approximate nearest neighbor search using Hierarchical Navigable Small World graphs

## Summary

- **Hierarchical Navigable Small World (HNSW) graphs**: Proposes a multi-layer graph structure where each layer is a proximity graph of nested subsets, with random layer inclusion probability decaying exponentially, enabling logarithmic search complexity by leveraging scale separation.

- **Performance optimization**: Introduces a heuristic for neighbor selection in proximity graphs, significantly improving performance at high recall and for clustered data, outperforming prior state-of-the-art vector-only approaches.

- **Distributed implementation potential**: Leverages similarity to skip lists for straightforward balanced distributed implementation, enhancing scalability and robustness in metric space search.
