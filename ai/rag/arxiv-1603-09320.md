# [1603.09320] Efficient and robust approximate nearest neighbor search using Hierarchical Navigable Small World graphs

## Summary

- **Hierarchical Navigable Small World (HNSW) graphs**: Introduce a multi-layer graph structure where each layer is a proximity graph of nested subsets, with random layer assignment following an exponentially decaying probability distribution, enabling logarithmic complexity search by leveraging scale separation.

- **Search optimization**: Starts from the top layer and traverses downward, utilizing heuristic neighbor selection to significantly improve performance, especially for high recall and clustered data, outperforming traditional NSW and other state-of-the-art vector-only approaches.

- **Distributed implementation**: The algorithm's similarity to skip lists facilitates straightforward balanced distributed implementations, enhancing scalability and robustness in large-scale metric space search scenarios.
