# [2004.04906] Dense Passage Retrieval for Open-Domain Question Answering

## Summary

- Introduces a **dual-encoder dense retrieval framework** for open-domain QA, replacing traditional sparse retrieval (e.g., BM25/TF-IDF) with learned dense embeddings from a small set of question-passage pairs.

- Demonstrates **9%-19% absolute improvement** in top-20 passage retrieval accuracy over Lucene-BM25 across multiple open-domain QA datasets, enabling state-of-the-art end-to-end QA performance.

- Uses a **simple contrastive training objective** to optimize passage retrieval, where queries and relevant passages are embedded into a shared latent space for efficient nearest-neighbor search.
