# Microsoft Entra ID (Formerly Azure AD) | Microsoft Security

## Summary

- **Zero Trust-based IAM**: Microsoft Entra ID implements risk-based conditional access policies with strong authentication (MFA, passwordless, SSO) to secure access to cloud/on-prem resources while integrating natively with security solutions for adaptive threat prevention.

- **AI-Driven Identity Protection**: Leverages Security Copilot and machine learning to detect authentication anomalies, track access changes, and enforce least-privilege access via Privileged Identity Management (PIM) and risk-based policies.

- **Multi-Tiered Licensing**: Offers **P1** ($6/user/month) for core IAM (SSO, MFA, reporting) and **P2** ($9/user/month) for advanced features (Entra ID Protection, PIM, access reviews), with bundled options like Microsoft 365 Business Premium including Entra ID P1.
