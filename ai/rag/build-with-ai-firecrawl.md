# Build with AI | Firecrawl

## Summary

- **Authentication**: Firecrawl provides API keys via dashboard/CLI or WorkOS ID-JAG for supported platforms; keyless access is rate-limited and intended as a fallback.

- **Core Tools**: Five primary tools (`search`, `scrape`, `crawl`, `map`, `interact`) map to CLI commands and REST API endpoints for web data extraction and interaction.

- **Skill Segments**: Three installable skill categories—CLI (live web work), Build (app integration), and Workflows (repeatable deliverables)—enable autonomous agent operations via `npx firecrawl-cli@latest init --all`.
