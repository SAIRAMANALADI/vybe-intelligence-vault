# Introducing LangSmith Context Hub

## Summary

- **Centralized Context Management**: LangSmith Context Hub provides a dedicated platform for storing, versioning, and collaborating on agent context files (e.g., `AGENTS.md`, skills, policies) outside traditional code repositories, enabling non-engineering stakeholders to contribute efficiently.

- **Versioning & Environment Tagging**: Supports version control, rollback capabilities, and environment-specific tagging (`dev`, `staging`, `prod`) to ensure agents deploy with the correct contextual data across different environments.

- **Open Memory Standard Collaboration**: LangChain is partnering with Elastic, MongoDB, Pinecone, and Redis to develop an open standard for agent memory, defining interfaces, metadata, and retrieval semantics for portable, versioned procedural memory (e.g., skills, policies) across frameworks.
