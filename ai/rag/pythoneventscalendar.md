# PythonEventsCalendar

## Summary

- **Archival Status**: Python wiki archived due to low usage and resource strain from bots/crawlers/LLM traffic; edits discouraged; preserved as-is; current info at [python.org](https://www.python.org/); changes via `infrastructure@python.org`.

- **Python Events Calendar System**: Two Google Calendar feeds: *Python Events Calendar* (conferences, 100+ attendees) and *Python User Group Calendar* (local meetups, 30+ attendees); iCal/RSS feeds deprecated; submissions via `events@python.org` with 4+ weeks notice; bulk submissions as `.ics` files.

- **Calendar Team & Guidelines**: Admin team (e.g., Marc-Andre Lemburg) and editors; events must focus on Python (conferences, sprints, tracks); online events capped at 2 weeks; hybrid events allowed; no CFP/registration deadlines; HTML links required in descriptions.
