# GitHub Docs

## Summary

- **GitHub Core Functionality**: GitHub leverages Git for version control, supports SSH for secure remote access, and enables repository creation/management for collaborative code storage and versioning.
- **Collaboration & Automation**: Pull requests facilitate code review and merging, GitHub Actions automates CI/CD workflows, and GitHub Copilot integrates AI-driven code suggestions directly into IDEs.
- **Security & APIs**: GitHub provides tools for securing secrets, detecting vulnerabilities (e.g., CodeQL), and offers REST/GraphQL APIs for programmatic access to repositories and metadata.
