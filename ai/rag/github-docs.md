# GitHub Docs

## Summary

- **GitHub Core Functionality**: GitHub relies on Git (open-source VCS) for local version control, supports SSH for secure remote connections, and enables repository creation/management for collaborative code storage and versioning.

- **Collaboration & Automation**: Pull requests facilitate code review and merging, while GitHub Actions automates CI/CD workflows, and GitHub Copilot provides AI-driven code suggestions in supported IDEs.

- **Security & Extensibility**: GitHub enforces secure authentication (SSH, tokens), includes CodeQL for vulnerability analysis, and offers REST/GraphQL APIs, webhooks, and integrations for custom workflows.
