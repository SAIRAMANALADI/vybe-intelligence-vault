# Installing Packages - Python Packaging User Guide

## Summary

- Python package installation requires `pip` (Python's package installer) and a compatible Python version (≥3.3) verified via `python3 --version` (Unix/macOS) or `py --version` (Windows).

- Virtual environments (`venv` or `virtualenv`) isolate dependencies per project, preventing conflicts; activation commands vary by OS (`source tutorial_env/bin/activate` for Unix/macOS, `tutorial_env\Scripts\activate` for Windows).

- `pip install <package>` fetches from PyPI, with wheels preferred over source distributions for faster installation; version specifiers (e.g., `==1.4`, `>=1,<2`) control installation targets.
