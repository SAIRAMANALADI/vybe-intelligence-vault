# portal.md

## Summary

- **FHIR Implementation Guide (IG) v1.12.0**: Specifies the technical framework for **2-document and 6-information** creation and transmission in Japan's electronic medical record (EMR) sharing services, leveraging HL7 FHIR R4 for interoperability.

- **Structured Data Exchange**: Defines standardized FHIR profiles for clinical documents (e.g., **Shared Care Plan, Discharge Summary**) and key data elements (e.g., **medications, allergies, lab results**) to ensure semantic consistency across healthcare providers.

- **Version Compatibility**: Maintains backward compatibility with prior IG versions while introducing updates (e.g., 2026.02.16 release) to align with evolving FHIR standards and national EMR requirements. Full version history accessible via [JPFHIR IG repository](https://jpfhir.jp/fhir/clins/igv1/all-igs.html).
