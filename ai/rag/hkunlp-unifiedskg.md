# HKUNLP/UnifiedSKG

## Summary

- **UnifiedSKG Framework**: Introduces a unified, multi-task learning approach for structured knowledge grounding (SKG) tasks, leveraging language models (LMs) to handle diverse SKG tasks (e.g., data-to-text, fact-verification, QA) via a single model architecture.

- **Prompt-Based Learning**: Implements prompt-learning techniques to transform structured knowledge (e.g., tables, graphs) into natural language prompts, enabling LMs to generalize across heterogeneous SKG tasks without task-specific fine-tuning.

- **Open-Source Implementation**: Provides a PyTorch-based repository with HuggingFace integration, supporting 21 datasets across 8 SKG tasks, and includes tools for multi-task training, evaluation, and prompt-based inference.
