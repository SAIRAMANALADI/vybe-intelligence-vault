# Is BGP safe yet? · Cloudflare

## Summary

- **BGP Security Vulnerability**: BGP lacks built-in security, enabling route hijacking and major Internet disruptions (e.g., Verizon/Sprint incidents) due to its reliance on trust-based path selection.

- **RPKI Adoption Progress**: RPKI (Resource Public Key Infrastructure) provides cryptographic route origin validation; adoption is accelerating among Tier-1 ISPs (e.g., Lumen/AS3356, Verizon/AS701) and cloud providers (e.g., AWS/AS16509, Google), with 31+ major operators now filtering RPKI-invalid prefixes.

- **Deployment Status**: As of 2026, key operators like Deutsche Telekom/AS3320, Bell Canada/AS577, and Sparkle/AS6762 enforce RPKI Origin Validation (ROV), significantly reducing BGP hijacking risks globally.
