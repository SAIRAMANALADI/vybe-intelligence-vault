# Boost Your Search With The Crispy Mixedbread Rerank Models

## Summary

- **Model Family**: Mixedbread releases three open-source Apache 2.0-licensed rerank models (`mxbai-rerank-xsmall-v1`, `mxbai-rerank-base-v1`, `mxbai-rerank-large-v1`) trained on real-world search queries and LLM-ranked results, optimized for semantic relevance in two-stage retrieval pipelines.

- **Performance Benchmarks**: Models achieve SOTA results on BEIR subsets (e.g., NDCG@10, Accuracy@3), outperforming lexical and embedding-based baselines (e.g., `mxbai-rerank-large-v1` at 74.9% Accuracy vs. 70.9% for `cohere-embed-v3`).

- **Integration & Use Case**: Designed for plug-and-play integration with existing keyword-based search systems (Elasticsearch, Solr) via a single API call or local hosting, enhancing relevance without infrastructure overhaul.
