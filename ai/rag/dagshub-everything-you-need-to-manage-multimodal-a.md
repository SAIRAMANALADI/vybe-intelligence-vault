# DagsHub: Everything you need to manage multimodal AI

## Summary

- **Unified AI Data & Model Management**: Platform supports multimodal dataset curation/annotation, experiment tracking (MLflow-compatible), and model versioning/deployment with data lineage, enabling end-to-end AI workflow orchestration.

- **Scalable Infrastructure**: Offers tiered plans (Individual/Team/Enterprise) with storage limits (20GB–1TB), petabyte-scale data management, RBAC, SSO/LDAP/OIDC, and on-premise/VPC deployments for high-security environments.

- **MLOps Integrations**: Native compatibility with cloud storage, CI/CD/CT pipelines, interactive notebooks, and auto-labeling tools (Label Studio), facilitating seamless integration into existing ML frameworks and MLOps toolchains.
