# Package index | Firebase

## Summary

- **KTX Module Deprecation**: As of July 2025, Firebase has deprecated KTX modules for Android libraries and removed them from Firebase Android BoM (v34.0.0); developers must migrate to KTX APIs from main modules per [Firebase's Kotlin migration guide](https://firebase.google.com/docs/android/kotlin-migration).

- **Core Firebase Packages**: Active packages include `firebase-auth`, `firebase-firestore`, `firebase-functions`, `firebase-messaging`, and `firebase-storage`, each providing SDKs for authentication, database operations, cloud functions, push notifications, and file storage, respectively.

- **Deprecated & Replaced Modules**: Firebase has deprecated `firebase.dynamiclinks`, `firebase.iid`, and ML-related packages (e.g., `firebase.ml.*`); ML services are now consolidated under `firebase-ai` and `firebase-vertexai` (replaced by Firebase AI Logic).
