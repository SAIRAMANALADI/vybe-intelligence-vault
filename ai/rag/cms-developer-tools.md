# CMS Developer Tools

## Summary

- **FHIR-based APIs**: CMS provides multiple FHIR-compliant APIs (e.g., AB2D, BCDA, Blue Button 2.0) for accessing Medicare claims data, enabling interoperability for PDPs, ACOs, and beneficiaries to retrieve structured Part A/B/D claims.
- **Policy & Compliance Tools**: The **Interoperability and Patient Access Proposed Rule** and **Design System** framework support FHIR-based data exchange, Section 508 compliance, and standardized healthcare application development.
- **Data & Analytics Resources**: CMS offers public datasets (e.g., Data.CMS.gov, Data.Medicaid.gov) and APIs (e.g., Finder, Marketplace, PPL) for healthcare plan pricing, provider data, and quality metrics.
