# langchain-ai/rag-from-scratch

## Summary

- **Implementation**: Jupyter Notebook-based repository demonstrating Retrieval-Augmented Generation (RAG) from scratch using LangChain, covering vector stores, embeddings, and LLM integration.
- **Components**: Includes modular components for document ingestion, chunking, vectorization (e.g., FAISS/Chroma), retrieval, and prompt augmentation for LLM inference.
- **Educational Focus**: Designed to teach core RAG principles, including indexing pipelines, similarity search, and end-to-end pipeline orchestration without relying on high-level abstractions.
