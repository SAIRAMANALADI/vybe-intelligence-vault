# yarnpkg/berry

## Summary

- **Modern JavaScript Package Manager**: Yarn Berry (v2+) is a complete rewrite in TypeScript, featuring a Plug'n'Play (PnP) system for zero-install dependency resolution, deterministic installs via `yarn.lock` v2, and improved performance via caching and parallel operations.

- **Core Architecture**: Implements a modular plugin system with a virtual filesystem (`@yarnpkg/fslib`) and a zero-overhead dependency resolver, replacing traditional `node_modules` with `.yarn/cache` and `.yarn/unplugged` for native/non-PnP packages.

- **Advanced Features**: Supports constrained versions (via `resolutions`), workspaces with isolated dependency graphs, and first-class TypeScript integration; leverages `yarn-deduplicate` for lockfile optimization and `yarn-upgrade-all` for bulk updates.
