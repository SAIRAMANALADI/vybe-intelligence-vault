# Atlassian Status

## Summary

- **Centralized Status Hub**: Atlassian provides a unified status page hub aggregating real-time operational status for all products/services (e.g., Jira, Confluence, Bitbucket) via dedicated subdomains (e.g., `*.status.atlassian.com`).

- **Incident Notification System**: Users can subscribe to email/SMS alerts for incident updates (creation/resolution) via reCAPTCHA-protected forms, with OTP verification for security.

- **Operational Transparency**: The status page displays a global "All Systems Operational" state with historical incident logs (e.g., past 30 days) and RSS/Atom feeds for automated monitoring.
