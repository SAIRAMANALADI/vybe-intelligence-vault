# Selectors Level 4

## Summary

- **Selector Definition**: A selector is a boolean predicate evaluating tree elements (e.g., DOM nodes) to determine if they match specified criteria, used in functions like `element.matches()` and `document.querySelectorAll()`.

- **Selector Levels & Scope**: Selectors Level 4 extends prior levels (CSS1, CSS2.1, Selectors Level 3), replacing and expanding CSS selector definitions while excluding pseudo-elements (defined in separate modules).

- **Core Selector Syntax**: Basic selectors include universal (`*`), type (`E`), negation (`:not()`), and matching pseudo-classes (`:is()`, `:where()`), enabling complex element filtering and structural representation.
