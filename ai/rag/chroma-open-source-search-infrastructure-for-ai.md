# Chroma - open-source search infrastructure for AI

## Summary

- **Multi-modal search engine**: ChromaDB supports vector, full-text, regex, and metadata search with sparse (BM25/SPLADE) and dense embeddings, optimized for low-latency queries (p50: 20ms warm, 650ms cold) over billions of records via object storage tiering.

- **Serverless, auto-scaling architecture**: Built on Apache 2.0 with BYOC (Bring Your Own Cloud) support, offering SOC 2 Type II compliance, multi-region replication, and zero-ops management via intelligent caching (hot/SSD) and automatic data tiering (S3/GCS).

- **Enterprise-grade features**: Supports 1M collections/database, 5M records/collection, 30MB/s write throughput, and customer-managed encryption keys (CMEK), with dedicated clusters for custom workloads and POCs.
