# Aseprite - Docs - Basics

## Summary

- **Sprite Composition**: Aseprite sprites are structured as a grid of *cels* (frame-layer intersections), where each cel contains pixel data editable independently; frames (horizontal timeline axis) define animation sequences, and layers (vertical stack) enable compositing of multiple graphic elements.

- **Core Workflow**: The primary workflow involves creating a sprite (`File > New`), drawing with the pencil tool (`B` key), saving in `.aseprite` format (preserves layers/frames), and exporting as `.gif`, `.png` sequences, or sprite sheets via `File > Export`.

- **Efficiency Shortcuts**: Aseprite supports keyboard-driven workflows, including zoom control (`1`-`6` keys), tool switching (`B` for pencil, `M` for marquee), color sampling (`Alt+click`), panning (`Space+Drag`), and timeline toggling (`Tab`).
