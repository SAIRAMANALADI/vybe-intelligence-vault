# Virtual Classroom Software | BigBlueButton

## Summary

- **Core Architecture**: BigBlueButton is an open-source virtual classroom platform built on a microservices architecture with real-time communication via WebRTC, integrating with major LMS platforms (Canvas, Moodle, Sakai, etc.) and supporting 65+ languages.

- **Key Differentiators**: Features AI-powered smart slides, live learning analytics, multi-user whiteboards, breakout rooms, and built-in polling/assessment tools, enabling evidence-based teaching and student performance tracking.

- **Deployment & Scalability**: Supports self-hosted server installations (via Docker/Kubernetes) and commercial hosting, with documented APIs for customization and integrations (e.g., PeerTube support for French Ministry of Education).
