# Milvus | High-Performance Vector Database Built for Scale

## Summary

- **Milvus** is an open-source vector database optimized for GenAI applications, supporting high-speed similarity searches and scaling to tens of billions of vectors with minimal performance degradation.
- **Deployment flexibility** includes Milvus Lite (lightweight, library-based), Standalone (single-machine production), Distributed (enterprise-scale), and Zilliz Cloud (fully managed SaaS/BYOC).
- **Key features** include metadata filtering, hybrid search, multi-vector support, and seamless integration with AI frameworks like LangChain, LlamaIndex, and Hugging Face.
