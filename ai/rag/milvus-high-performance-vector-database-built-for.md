# Milvus | High-Performance Vector Database Built for Scale

## Summary

- **Milvus Architecture**: Supports lake-native vector search with S3-based storage in v3.0, enabling horizontal scaling to tens of billions of vectors while maintaining low-latency retrieval via a distributed architecture.
- **Deployment Flexibility**: Offers Milvus Lite (embedded), Standalone (single-node), Distributed (multi-node), and fully managed Zilliz Cloud (serverless/dedicated) options for varying scalability and operational needs.
- **Integration & Use Cases**: Natively integrates with AI frameworks (LangChain, LlamaIndex, Hugging Face) and supports multimodal, hybrid, and graph-based RAG workflows, validated by enterprise adoption (e.g., Salesforce, NVIDIA, IBM).
