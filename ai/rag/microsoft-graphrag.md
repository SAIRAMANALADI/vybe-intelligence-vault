# microsoft/graphrag

## Summary

- **Modular Graph-Based RAG Framework**: Implements a graph-based Retrieval-Augmented Generation (RAG) system in Python, enabling structured knowledge extraction and reasoning over unstructured data via graph-based indexing and retrieval.

- **Multi-Stage Pipeline**: Integrates hierarchical entity, relationship, and community extraction with LLM-powered summarization and query resolution, optimizing context retrieval for large-scale datasets.

- **Scalable & Extensible**: Designed for modularity, supporting custom graph algorithms, LLM backends (e.g., GPT-4), and distributed processing for enterprise-scale knowledge graph applications.
