# Data Storage Finder | Research Data Management Service Group

## Summary

- **Tool Overview**: Cornell Data Services provides a vetted **Data Storage Finder** tool to help users identify supported storage solutions at Cornell, including a specialized **WCMC storage wizard** for Weill Cornell Medicine affiliates.

- **Selection Criteria**: Users input data characteristics via a questionnaire, then select storage services for comparison, with results filtered based on compatibility with their needs.

- **Feedback & Reuse**: The tool includes a **feedback mechanism** and offers the underlying **Finder Tool code** for reuse under no restrictions, provided with no warranty or maintenance obligations.
