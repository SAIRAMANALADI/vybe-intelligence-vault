# Neural network (machine learning) - Wikipedia

## Summary

- **Architecture**: Neural networks are computational models consisting of interconnected nodes (neurons) organized in layers (input, hidden, output), with weighted connections enabling parallel distributed processing for pattern recognition and function approximation.

- **Biological Inspiration**: Modeled after simplified biological neural networks, where artificial neurons aggregate inputs via activation functions (e.g., ReLU, sigmoid) to produce outputs, emulating synaptic transmission and plasticity.

- **Applications**: Primarily used in machine learning for tasks like classification, regression, and feature extraction, leveraging backpropagation for supervised training and gradient descent optimization to minimize loss functions.
