# run-llama/LlamaIndexTS

## Summary

- **LlamaIndexTS**: TypeScript-based data framework for LLM applications, optimized for server-side solutions with Node.js integration.
- **Key Features**: Supports embeddings, agent-based workflows, and compatibility with LLMs (e.g., Llama3, OpenAI, Groq) via modular connectors.
- **Ecosystem**: Integrates with React, JavaScript, and modern AI tooling (e.g., Claude AI) while providing CLI tools (`create-llama`) for rapid setup.
