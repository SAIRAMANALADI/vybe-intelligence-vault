# Moby

## Summary

- **Framework Architecture**: Moby is an open framework by Docker for assembling specialized container systems from modular, containerized components (OS, runtime, orchestration, networking, storage, security, etc.) using a "lego set" approach.

- **Tooling & Assemblies**: Provides tools to compile components into runnable artifacts across platforms (bare metal, VMs, executables) and includes reference assemblies for rapid customization or inspiration.

- **Runtime & Use Cases**: Uses `containerd` as the default runtime; recommended for system engineers, hackers, and open-source developers, but not for application developers or enterprise users seeking ready-to-use platforms.
