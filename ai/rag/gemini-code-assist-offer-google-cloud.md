# Gemini Code Assist Offer | Google Cloud

## Summary

- **Gemini Code Assist Standard** provides AI-driven code generation/transformation, contextual best practices via chatbot, and enterprise-grade security with IP protection and data privacy measures across Firebase, Databases, and Colab Enterprise.

- **Gemini Code Assist Enterprise** extends Standard features with organization-specific code customization based on internal libraries and deeper integrations with BigQuery, Apigee, and Application Integration.

- **Licensing & Compliance**: Standard includes seat-based access to core features; Enterprise adds advanced integrations, with both offering Generative AI indemnification and adherence to enterprise security policies.
