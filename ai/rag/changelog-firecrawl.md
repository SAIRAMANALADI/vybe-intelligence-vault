# Changelog | Firecrawl

## Summary

- **Enhanced `/search` Accuracy**: Firecrawl `/search` now returns the most relevant excerpts (paragraphs, lists, tables) using a custom relevance model, achieving **94.7% accuracy on SimpleQA** while using **10x fewer tokens** than processing full pages.

- **Firecrawl Research Index**: A specialized index for AI/ML research with **state-of-the-art recall (53.3%) on arXivQA**, outperforming competitors by **18%**, and includes **3M+ arXiv papers + GitHub artifacts** (issues, PRs, READMEs), refreshed daily.

- **New `/parse` Endpoint**: Converts **PDFs, Word docs, spreadsheets (up to 50MB)** into clean, structured Markdown/JSON using a **Rust-based engine (up to 5x faster)**, with **zero data retention** support for sensitive documents.
