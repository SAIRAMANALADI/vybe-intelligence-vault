# Changelog | Firecrawl

## Summary

- **Web-scale `/monitor`**: Always-on web search with configurable `queries` and `goal` parameters, delivering real-time alerts via webhook/email when new matching content appears, replacing DIY monitoring stacks with a single endpoint.
- **Firecrawl Research Index**: A specialized index for AI/ML research with 3M+ arXiv papers and GitHub artifacts (issues, PRs, READMEs), achieving 53.3% recall on arXivQA (18% higher than competitors) and enabling claim verification against full-text sources.
- **`/parse` endpoint**: Rust-based document parsing (PDFs, Word, spreadsheets) with up to 5x speed improvement, structured output (Markdown/JSON), and zero-data retention support for sensitive documents.
