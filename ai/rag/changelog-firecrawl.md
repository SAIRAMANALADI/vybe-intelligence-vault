# Changelog | Firecrawl

## Summary

- **Enhanced `/search` accuracy**: Custom relevance model scores excerpts (paragraphs, lists, tables) against queries, achieving **94.7% accuracy on SimpleQA** while reducing tokens by **10x** compared to full-page processing, with no API changes required.

- **Firecrawl Research Index**: Specialized index for AI/ML research with **53.3% recall on arXivQA** (18% higher than competitors), integrating **3M+ arXiv papers** and GitHub artifacts (issues, PRs, READMEs), enabling claim verification and code retrieval with state-of-the-art performance.

- **`/parse` endpoint**: Rust-based engine converts **PDFs, Word docs, spreadsheets (up to 50MB)** into clean Markdown/JSON/summaries **up to 5x faster**, with **Lockdown Mode** for cache-only, zero-data-retention scraping and new **Question/Highlights formats** reducing tokens by **100x** per call.
