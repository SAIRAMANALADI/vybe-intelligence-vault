# Changelog | Firecrawl

## Summary

- **Always-on web monitoring**: `/monitor` continuously scans the entire web for user-defined queries and goals, alerting via webhook or email when new matching content is detected, with tunable recall/precision via `queries` and `goal` parameters.
- **Structured document parsing**: `/parse` endpoint converts PDFs, Word docs, and spreadsheets (≤50MB) into clean Markdown/JSON/summaries using a Rust-based engine (up to 5x faster), with zero data retention support in enterprise plans.
- **Browser automation via `/interact`**: Enables agents to scrape pages then execute dynamic actions (clicks, form fills, navigation) in live browser sessions, persisting across calls with reusable profiles and natural language or Playwright/Bash control.
