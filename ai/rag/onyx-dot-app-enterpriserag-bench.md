# onyx-dot-app/EnterpriseRAG-Bench

## Summary

- **Purpose**: Provides a benchmarking framework and synthetic dataset for evaluating Retrieval-Augmented Generation (RAG) systems on proprietary enterprise documents, enabling standardized performance assessment of LLM-based QA and semantic search pipelines.

- **Dataset Features**: Includes synthetically generated enterprise documents and QA pairs, designed to simulate real-world internal knowledge bases for testing retrieval accuracy, contextual relevance, and generative response quality in RAG workflows.

- **Evaluation Scope**: Supports metrics for semantic search, information retrieval, and LLM response fidelity, with Python-based tooling for reproducibility and comparative analysis across enterprise RAG implementations.
