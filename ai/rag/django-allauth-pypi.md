# django-allauth · PyPI

## Summary

- **Purpose & Scope**: `django-allauth` is a production-stable Django package (v65.18.0) integrating authentication, registration, account management, and third-party (social) authentication with support for OAuth 1.0/2.0, OpenID Connect, SAML 2.0, and custom protocols (e.g., Telegram).

- **Key Features**: Supports multiple authentication schemes (local/email/username), mandatory email verification, rate limiting, account enumeration prevention, and enterprise-grade SAML 2.0 integration; highly customizable via adapter pattern and configurable via Django admin or settings.

- **Technical Requirements**: Requires Python ≥3.10, compatible with Django 4.2–6.0; provides extras for headless, MFA, OpenID, SAML, Steam, and social account management; MIT-licensed with commercial support available.
