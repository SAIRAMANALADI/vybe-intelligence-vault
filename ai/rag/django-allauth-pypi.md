# django-allauth · PyPI

## Summary

- **Django Integration**: `django-allauth` v65.18.0 is a production-stable Django package (MIT License) requiring Python ≥3.10, supporting Django 4.2–6.0, providing integrated local/social authentication, account management, and verification flows via adapter-based customization.

- **Authentication Features**: Supports local (username/email) and social (OAuth 1.0/2.0, OpenID Connect, SAML 2.0, Telegram) auth, with rate limiting, account enumeration prevention, and MFA via extras (`mfa`, `saml`, `openid`, etc.).

- **Enterprise & Security**: Battle-tested since 2010, includes SAML 2.0 for B2B, configurable via Django admin/sites framework, and supports headless/API-first setups (`headless`, `idp-oidc` extras).
