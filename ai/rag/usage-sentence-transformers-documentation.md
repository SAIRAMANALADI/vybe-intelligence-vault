# Usage — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with optional PyTorch CUDA support; includes migration guides for major version updates (e.g., v5.x → v5.4+) with API changes like renamed parameters (`max_length` → `max_seq_length`) and deprecated features.

- **Sentence Transformer Functionality**: Enables computing embeddings, semantic textual similarity, semantic search (symmetric/asymmetric), clustering (k-Means, agglomerative), paraphrase mining, and multimodal applications (image/text, audio/video); supports efficiency optimizations via PyTorch, ONNX, and OpenVINO.

- **Training & Evaluation**: Provides structured training pipelines with components (model, dataset, loss, evaluator, trainer) for fine-tuning; includes pre-trained models (multilingual, multimodal, scientific) and MTEB-based evaluation with leaderboard submission support.
