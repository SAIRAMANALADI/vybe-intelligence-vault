# [2005.11401] Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

## Summary

- **RAG Architecture**: Introduces retrieval-augmented generation (RAG) models combining a pre-trained seq2seq model (parametric memory) with a dense vector index of Wikipedia (non-parametric memory) accessed via a neural retriever, enabling dynamic knowledge integration for language generation tasks.

- **Two RAG Formulations**: Proposes two variants—one using the same retrieved passages for the entire sequence and another allowing per-token passage retrieval—both fine-tuned on knowledge-intensive NLP tasks to outperform parametric-only models and task-specific retrieve-and-extract architectures.

- **Performance Gains**: Achieves state-of-the-art results on three open-domain QA tasks and demonstrates improved specificity, diversity, and factuality in generated language compared to state-of-the-art parametric seq2seq baselines.
