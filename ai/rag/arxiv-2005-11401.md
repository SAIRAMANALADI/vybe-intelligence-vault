# [2005.11401] Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

## Summary

- **RAG Architecture**: Introduces retrieval-augmented generation (RAG) models combining a pre-trained seq2seq model (parametric memory) with a dense vector index of Wikipedia (non-parametric memory) accessed via a pre-trained neural retriever, enabling dynamic knowledge integration.

- **Two RAG Variants**: Proposes two fine-tuning formulations—one using the same retrieved passages across the entire generated sequence (RAG-Sequence) and another allowing different passages per token (RAG-Token)—both outperforming parametric-only models on knowledge-intensive NLP tasks.

- **Performance & Advantages**: Achieves state-of-the-art results on three open-domain QA benchmarks, generating more specific, diverse, and factual language than parametric seq2seq baselines while enabling provenance tracking and dynamic knowledge updates.
