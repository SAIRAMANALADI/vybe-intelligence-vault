# [2512.05411] A Systematic Framework for Enterprise Knowledge Retrieval: Leveraging LLM-Generated Metadata to Enhance RAG

## Summary

- **Metadata enrichment pipeline**: Proposes a structured method using LLMs to dynamically generate metadata for document segments, improving semantic representations and retrieval accuracy in RAG systems via a 3×3 experimental matrix evaluating chunking strategies (semantic, recursive, naive) and embedding techniques (content-only, TF-IDF weighted, prefix-fusion).

- **Performance benchmarks**: Metadata-enriched approaches outperform content-only baselines, with recursive chunking + TF-IDF weighted embeddings achieving 82.5% precision, and naive chunking + prefix-fusion yielding NDCG of 0.813; all configurations maintain sub-30 ms P95 latency.

- **Validation methodology**: Uses cross-encoder reranking for silver-standard ground truth generation and Bonferroni-corrected paired t-tests for statistical significance, confirming metadata enrichment enhances vector space organization and retrieval effectiveness in enterprise RAG deployments.
