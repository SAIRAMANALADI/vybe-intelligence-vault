# weaviate/weaviate

## Summary

- **Hybrid Architecture**: Weaviate combines object storage with vector embeddings, enabling both structured filtering (SQL-like queries) and vector similarity search (ANN/HNSW) in a single system, optimized for cloud-native scalability and fault tolerance.

- **Multi-Modal & Generative Search**: Supports hybrid search (vector + BM25), generative search (RAG pipelines), and multi-modal retrieval (text, images, etc.) via gRPC APIs, with built-in modules for neural search and semantic retrieval.

- **Performance & Scalability**: Implements HNSW for approximate nearest neighbor search, sharding for horizontal scaling, and optimized indexing for low-latency queries, while offering MLOps integrations (e.g., model caching, batch processing).
