# weaviate/weaviate

## Summary

- **Hybrid Vector & Structured Data Storage**: Weaviate combines object storage with vector embeddings, enabling both vector similarity search (via HNSW) and structured filtering in a single system, optimized for cloud-native scalability and fault tolerance.

- **Multi-Modal & ML-Optimized Search**: Supports approximate nearest neighbor (ANN) search, hybrid search (vector + BM25), and generative search, with gRPC APIs for integration with ML pipelines, recommender systems, and semantic search engines.

- **Go-Based, Cloud-Native Architecture**: Implemented in Go for performance, with native support for HNSW indexing, distributed deployments, and integrations across vector search, image search, and neural retrieval workflows.
