# weaviate/weaviate

## Summary

- **Hybrid Vector & Structured Storage**: Weaviate integrates object storage with vector embeddings, enabling combined vector search and structured filtering while maintaining cloud-native fault tolerance and scalability.

- **HNSW & gRPC Backbone**: Implements Hierarchical Navigable Small World (HNSW) for approximate nearest-neighbor search and leverages gRPC for high-performance, cross-language communication.

- **MLOps & Semantic Search**: Supports generative search, hybrid search (vector + BM25), and integrates with ML pipelines for neural search, recommender systems, and image/semantic search applications.
