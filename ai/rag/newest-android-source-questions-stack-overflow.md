# Newest 'android-source' Questions - Stack Overflow

## Summary

- **Android 11 Quick Settings Media Colorization Source**: The media session colorization logic for Android 11+ is not explicitly documented in the same location as prior versions (8.0–10), requiring deeper AOSP source inspection in `frameworks/base` or `packages/SystemUI`.

- **AOSP Custom Build Optimization**: Compiling AOSP modules (e.g., `SystemUI`) with `mmm` triggers test compilation by default; skipping tests requires explicit flags (e.g., `skip-tests=true` in `Android.mk` or `Android.bp`).

- **AAOS vs. AOSP for Automotive**: AAOS (Android Automotive OS) is preferred over AOSP for vehicle diagnostic apps due to built-in automotive HALs, Cuttlefish virtualization support, and OBD-II/CAN integration frameworks.
