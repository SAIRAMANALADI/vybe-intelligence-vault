# Introduction | WordPress Playground

## Summary

- **WordPress Playground** is a browser-based, client-side WordPress environment running in WebAssembly, enabling zero-setup experimentation without authentication or persistent backend dependencies.

- **Documentation is structured across four hubs**: Core docs (intro/guides), Blueprints (JSON-based instance configuration), Developer APIs (programmatic control via JavaScript/npm), and API Reference (exposed endpoints).

- **AI integration support** includes an `llms.txt` index for machine-readable capabilities, an `npm`-installable `wp-playground` skill for AI agents, and a dedicated `AGENTS.md` guide for AI-driven contributions.
