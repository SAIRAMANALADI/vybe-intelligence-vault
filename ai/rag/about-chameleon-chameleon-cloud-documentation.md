# About Chameleon — Chameleon Cloud Documentation

## Summary

- **Bare-metal and virtualized infrastructure**: Provides full hardware control via bare-metal instances (Intel/AMD/ARM, GPUs, FPGAs) and traditional KVM VMs, with high-performance networking (InfiniBand, 25/100GbE) and storage options (NVMe, shared filesystems).

- **Reproducible experimental environments**: Supports resource isolation via reservations, custom disk images, power/performance monitoring, and multi-site deployments (FABRIC integration) for distributed experiments.

- **Collaboration and sharing tools**: Features Trovi for experiment packaging/sharing, JupyterHub for interactive analysis, and CLI/GUI interfaces, alongside object storage (Swift) and advanced networking (Layer-2 VLANs, multi-site routing).
