# qdrant/docs/roadmap/README.md at dev · qdrant/qdrant · GitHub

## Summary

- **Compatibility & Upgrades**: Maintain backward compatibility for at least one minor version; introduce automatic version tracking between server and client; plan eventual migration from RocksDB with data migration during upgrades.

- **Scalability & Storage**: Enhance read/write segregation with read-only nodes, incremental snapshots, and multi-region replication; introduce S3 as a storage backend for vectors and payloads.

- **Performance & Features**: Implement incremental HNSW indexing for faster updates; add built-in TTL support for automatic data expiration; introduce server-side embedding inference and advanced text filtering (phrase queries, logical operators, stemmers, stopwords).
