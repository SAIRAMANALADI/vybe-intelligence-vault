# Performance features reference | Chrome DevTools | Chrome for Developers

## Summary

- **Live Metrics Screen**: Displays real-time Core Web Vitals (LCP, CLS, INP) with CrUX field data comparison, LCP element highlighting, CLS cluster/INP type details, interaction/layout shift history, and environment-based throttling presets.
- **Performance Recording Features**: Supports runtime/load performance recording with screenshots, forced garbage collection, JS sample toggling, network/CPU throttling, CSS selector stats, and advanced paint instrumentation via Capture Settings.
- **Analysis & Navigation**: Provides actionable Lighthouse-based insights (LCP/INP subparts, third-party scripts), keyboard shortcuts (A/D/W/S for panning/zooming), timeline selection, and breadcrumb navigation for detailed trace inspection.
