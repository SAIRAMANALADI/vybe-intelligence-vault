# Azure-Samples/chat-with-your-data-solution-accelerator

## Summary

- **Architecture**: Implements Retrieval-Augmented Generation (RAG) pattern using **Azure AI Search** for vector-based retrieval and **Azure OpenAI** for LLM-powered chat/Q&A, deployed on Azure.
- **Key Components**: Includes **Python-based** solution with **AZD templates** for deployment, integrating best practices for enterprise-grade RAG workflows (e.g., chunking, indexing, prompt engineering).
- **Features**: Supports **ChatGPT-style interactions** and **Q&A systems**, with preconfigured pipelines for data ingestion, retrieval, and response generation optimized for Azure OpenAI models.
