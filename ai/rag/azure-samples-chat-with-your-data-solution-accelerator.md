# Azure-Samples/chat-with-your-data-solution-accelerator

## Summary

- **Architecture**: Implements **Retrieval-Augmented Generation (RAG)** pattern on Azure using **Azure AI Search** for retrieval and **Azure OpenAI** LLMs for generative responses, enabling ChatGPT-style and Q&A interactions.

- **Key Components**: Includes **Python-based** solution with **AZD templates**, leveraging **Azure OpenAI embeddings** and **vector search** for contextual retrieval, adhering to best practices for scalability and performance.

- **Deployment & Features**: Provides **pre-configured Azure resources** (e.g., search, OpenAI, storage) via ARM/Bicep, supports **semantic ranking**, **hybrid search**, and **authentication**, optimized for enterprise-grade RAG workflows.
