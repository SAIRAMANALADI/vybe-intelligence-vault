## Summary

- **Architecture**: Implements Retrieval-Augmented Generation (RAG) pattern on Azure using **Azure AI Search** for retrieval and **Azure OpenAI** LLMs for chat/Q&A, following best practices for production-grade RAG systems.

- **Key Components**: Includes **Python-based** implementation with **AZD templates** for deployment, integrating Azure services (AI Search, OpenAI) for end-to-end RAG workflows (indexing, retrieval, generation).
