# Azure-Samples/chat-with-your-data-solution-accelerator

## Summary

- **Architecture**: Implements Retrieval-Augmented Generation (RAG) pattern in Azure using **Azure AI Search** for retrieval and **Azure OpenAI** LLMs for generating ChatGPT-style/Q&A responses, following best practices for production-grade deployments.

- **Key Components**: Includes **Python-based** solution with **AZD templates** for deployment, integrating Azure services (AI Search, OpenAI) and supporting common requirements like data ingestion, indexing, and retrieval optimization.

- **Purpose**: Accelerator template designed to simplify building enterprise-grade RAG solutions in Azure, with pre-configured infrastructure, retrieval pipelines, and chat interfaces for rapid deployment and scalability.
