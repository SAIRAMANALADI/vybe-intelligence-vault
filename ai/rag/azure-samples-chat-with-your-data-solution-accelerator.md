# Azure-Samples/chat-with-your-data-solution-accelerator

## Summary

- **Architecture**: Implements a **Retrieval-Augmented Generation (RAG)** pattern using **Azure AI Search** for retrieval and **Azure OpenAI** for LLM-powered chat/Q&A, deployed entirely in Azure.

- **Key Components**: Includes **Azure AI Search** for vector/keyword retrieval, **Azure OpenAI Service** for LLM inference, and **Azure Developer CLI (azd)** templates for infrastructure-as-code deployment.

- **Features**: Provides production-ready patterns for **document ingestion, chunking, embedding, retrieval, and LLM prompting**, adhering to Azure best practices for scalability and security.
