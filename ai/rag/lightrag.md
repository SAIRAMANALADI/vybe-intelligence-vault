# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG constructs a knowledge graph by extracting entities and relationships from text chunks using LLM-based functions (`R(·)` for extraction, `P(·)` for key-value profiling, and `D(·)` for deduplication), enabling multi-hop subgraph queries for global context understanding.

- **Dual-Level Retrieval Paradigm**: Implements low-level retrieval for entity-specific queries and high-level retrieval for abstract/conceptual queries, combining graph traversal with vector representations to improve precision and contextual relevance.

- **Incremental Knowledge Adaptation**: Uses a graph-merging algorithm to efficiently update the knowledge base with new data without full reprocessing, reducing computational overhead while maintaining retrieval accuracy in dynamic environments.
