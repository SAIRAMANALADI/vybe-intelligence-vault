# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity and relationship extraction from segmented text chunks, constructing a deduplicated knowledge graph with key-value pairs for efficient retrieval, replacing traditional flat embeddings and chunk traversal methods.

- **Dual-Level Retrieval Paradigm**: Combines low-level (entity-specific) and high-level (abstract/theme-based) retrieval strategies, leveraging graph structures to aggregate multi-hop subgraph insights for improved contextual relevance and query handling.

- **Incremental Knowledge Adaptation**: Implements an incremental update algorithm to merge new graph data without full reprocessing, reducing computational overhead while maintaining retrieval accuracy in dynamic environments.
