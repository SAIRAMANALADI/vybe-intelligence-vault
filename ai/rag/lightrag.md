# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity/relationship extraction (R(·)), key-value profiling (P(·)) for efficient retrieval, and deduplication (D(·)) to optimize graph operations, enabling multi-hop subgraph queries for global context understanding.

- **Dual-Level Retrieval Paradigm**: Combines low-level (specific entity/attribute retrieval) and high-level (abstract/theme-based aggregation) retrieval strategies, leveraging graph structures and vector representations for precise, context-aware responses.

- **Incremental Knowledge Adaptation**: Uses a merge-based incremental update algorithm to efficiently integrate new data into the existing graph without full reprocessing, reducing computational overhead while maintaining retrieval accuracy in dynamic environments.
