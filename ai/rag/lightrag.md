# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity/relationship extraction from segmented text, constructs a deduplicated knowledge graph, and generates key-value pairs for nodes/edges to enable efficient retrieval via graph and vector representations.

- **Dual-Level Retrieval Paradigm**: Combines low-level (entity-specific) and high-level (abstract/theme-based) retrieval strategies, leveraging graph traversal and vector similarity to address both precise and conceptual queries.

- **Incremental Adaptation & Cost Efficiency**: Implements an incremental update algorithm for seamless knowledge base expansion without full reprocessing, reducing computational overhead while maintaining retrieval accuracy and response relevance.
