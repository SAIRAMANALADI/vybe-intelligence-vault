# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity/relationship extraction and deduplication to construct a knowledge graph, where nodes (entities) and edges (relations) are profiled into key-value pairs for efficient retrieval, replacing flat embeddings with structured, multi-hop subgraph queries.

- **Dual-Level Retrieval Paradigm**: Combines low-level (entity-specific) and high-level (abstract/theme-based) retrieval via graph traversal and vectorized indexing, enabling precise answers for detailed queries while aggregating broader context for conceptual ones.

- **Incremental Knowledge Adaptation**: Uses a graph-merging algorithm to update the knowledge base without full reprocessing, reducing computational overhead while preserving historical data integrity and ensuring timely responses to evolving data.
