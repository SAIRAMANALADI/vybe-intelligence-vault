# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG constructs a knowledge graph by extracting entities and relationships from text chunks using LLMs, then indexing them as key-value pairs (entities as keys, relations as multi-key phrases) with deduplication to optimize graph operations and retrieval efficiency.

- **Dual-Level Retrieval Paradigm**: Implements low-level retrieval for entity-specific queries and high-level retrieval for abstract/conceptual queries, combining graph traversal with vector representations to improve contextual relevance and response accuracy.

- **Incremental Knowledge Adaptation**: Uses an incremental update algorithm to merge new data into the existing graph without full reprocessing, reducing computational overhead while maintaining seamless integration of evolving knowledge bases.
