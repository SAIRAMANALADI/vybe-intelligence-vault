# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity/relationship extraction (nodes/edges) from segmented text, generating key-value pairs for efficient retrieval, with deduplication to optimize graph operations and reduce overhead.

- **Dual-Level Retrieval**: Combines low-level (entity-specific) and high-level (abstract/theme-based) retrieval via graph traversal and vector representations, enabling precise and comprehensive query handling while improving response relevance.

- **Incremental Knowledge Updates**: Uses an incremental update algorithm to merge new graph data with existing structures without full reprocessing, reducing computational overhead while maintaining retrieval accuracy in dynamic environments.
