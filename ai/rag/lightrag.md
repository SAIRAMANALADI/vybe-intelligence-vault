# LightRAG

## Summary

*   LightRAG employs a graph-enhanced indexing paradigm, utilizing LLMs to extract entities and relationships from segmented documents, generating a comprehensive knowledge graph with LLM-profiled key-value pairs for efficient, precise retrieval and deduplication.
*   It features a dual-level retrieval system that generates both specific (low-level, entity-focused) and abstract (high-level, thematic) query keys, enabling comprehensive information retrieval from granular document chunks and complex inter-dependencies.
*   The framework incorporates an incremental update algorithm for its knowledge base, allowing new data to be seamlessly integrated by merging newly indexed graph structures with existing ones, thereby reducing computational overhead and maintaining system responsiveness.
