# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG constructs a knowledge graph by extracting entities and relationships from text chunks using LLMs, enabling multi-hop subgraph queries for comprehensive information retrieval and efficient key-value pair indexing for precise entity/relation lookups.

- **Dual-Level Retrieval**: Implements low-level (specific entity/relation retrieval) and high-level (abstract theme/summary retrieval) paradigms, leveraging graph structures and vector representations to balance depth and breadth in query responses.

- **Incremental Knowledge Updates**: Employs a graph-based incremental update algorithm to seamlessly integrate new data without full reprocessing, reducing computational overhead while preserving historical context and ensuring timely, accurate responses.
