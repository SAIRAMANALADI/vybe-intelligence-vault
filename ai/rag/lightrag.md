# LightRAG

## Summary

*   LightRAG integrates graph structures into RAG by segmenting documents, leveraging LLMs for entity/relationship extraction, generating key-value profiles for graph nodes/edges, and deduplicating to form a comprehensive knowledge graph for enhanced contextual understanding.
*   It employs a dual-level retrieval paradigm, combining low-level (specific entity/attribute) and high-level (abstract topic/theme) strategies, which utilize both graph traversal and vector representations to address diverse query types effectively.
*   The system features an incremental update algorithm for its knowledge base, enabling efficient integration of new data by merging new graph structures without full reprocessing, thereby reducing computational overhead and ensuring timely adaptation.
