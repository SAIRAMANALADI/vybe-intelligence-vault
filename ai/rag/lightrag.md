# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity/relationship extraction from segmented text, constructs a deduplicated knowledge graph, and generates key-value pairs (index keys + contextual snippets) for efficient retrieval, replacing flat embedding/chunk-based methods.

- **Dual-Level Retrieval**: Implements low-level (entity-specific) and high-level (abstract/theme-based) retrieval via graph traversal and vector representations, enabling precise and comprehensive query handling while maintaining contextual relevance.

- **Incremental Adaptation**: Uses an incremental update algorithm to merge new graph data without full reprocessing, reducing computational overhead while preserving historical knowledge integrity for dynamic data environments.
