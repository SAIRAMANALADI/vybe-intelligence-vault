# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity/relationship extraction (nodes/edges) from text chunks, generating key-value pairs for efficient retrieval, with deduplication optimizing graph operations for faster, more accurate data processing.

- **Dual-Level Retrieval Paradigm**: Combines low-level (specific entity/attribute retrieval) and high-level (abstract, multi-hop thematic retrieval) strategies, leveraging graph structures and vector representations to improve contextual relevance and response efficiency.

- **Incremental Knowledge Adaptation**: Implements an incremental update algorithm that merges new graph data into existing structures without full reprocessing, reducing computational overhead while maintaining retrieval accuracy in dynamic environments.
