# LightRAG

## Summary

- **Graph-Enhanced Indexing**: LightRAG employs LLM-driven entity/relationship extraction from segmented text chunks, constructs a knowledge graph, and generates key-value pairs for efficient retrieval, reducing graph overhead via deduplication while enabling multi-hop subgraph queries for global context.

- **Dual-Level Retrieval Paradigm**: Combines low-level (entity/attribute-specific) and high-level (abstract/theme-based) retrieval strategies, leveraging graph structures and vector representations to optimize precision and contextual relevance for diverse query types.

- **Incremental Knowledge Adaptation**: Implements an incremental update algorithm that merges new graph data into the existing knowledge base without full reprocessing, reducing computational overhead while maintaining retrieval accuracy in dynamic environments.
