# zai-org/Open-AutoGLM

## Summary

- **Open-AutoGLM Framework**: A Python-based open-source framework designed for phone-use agents, enabling AI-driven automation of mobile device interactions with a modular architecture for extensibility.

- **Agent Model Integration**: Provides a pre-trained phone agent model (`AutoGLM`) optimized for tasks like call handling, SMS processing, and app navigation, leveraging large language models (LLMs) for contextual decision-making.

- **Deployment & Scalability**: Supports deployment on edge devices (e.g., smartphones) with lightweight inference engines; includes APIs for custom agent development and benchmarking tools for performance evaluation.
