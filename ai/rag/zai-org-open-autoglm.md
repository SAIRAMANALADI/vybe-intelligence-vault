# zai-org/Open-AutoGLM

## Summary

- **Open-AutoGLM Framework**: A Python-based open-source framework designed for autonomous phone agent models, enabling AI-driven interactions with mobile devices (e.g., calls, messages, app navigation) via a modular architecture.

- **Agent Model Integration**: Implements a phone-use agent system leveraging large language models (LLMs) to interpret user intent, execute multi-step tasks (e.g., dialing, scheduling), and handle dynamic environments (e.g., UI changes) with minimal human intervention.

- **Scalability & Customization**: Supports extensibility via plugin-based components (e.g., speech recognition, API integrations) and is optimized for real-world deployment, with benchmarks and tools for evaluating performance across diverse phone-use scenarios.
