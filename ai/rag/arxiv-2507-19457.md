# [2507.19457] GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning

## Summary

- **GEPA (Genetic-Pareto)** introduces a prompt optimization framework leveraging natural language reflection to iteratively diagnose, update, and combine LLM prompts via trial-and-error, outperforming RL-based methods like GRPO with fewer rollouts.
- **Empirical results** show GEPA achieves **6% average and up to 20% higher performance** than GRPO across six tasks while using **up to 35x fewer rollouts**, and exceeds the prompt optimizer MIPROv2 by **>10%** (e.g., **+12% accuracy on AIME-2025**).
- **Design features** include Pareto frontier-based prompt combination, interpretable natural language feedback loops, and demonstrated efficacy as an inference-time search strategy for code optimization.
