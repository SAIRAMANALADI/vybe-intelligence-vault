# [2507.19457] GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning

## Summary

- **GEPA (Genetic-Pareto)** introduces a prompt optimization framework leveraging natural language reflection to iteratively diagnose, update, and combine LLM prompts, outperforming traditional RL methods like GRPO by **6% on average** and up to **20%** while requiring **up to 35x fewer rollouts**.

- **Pareto frontier optimization** enables GEPA to synthesize complementary prompt improvements from multiple trials, achieving **>10% gains over MIPROv2** (e.g., **+12% accuracy on AIME-2025**) and demonstrating efficacy in inference-time code optimization.

- **Reflective evolution mechanism** replaces sparse scalar rewards with interpretable natural language feedback, allowing GEPA to rapidly distill high-level rules from minimal rollouts (e.g., 3–4 trials) across six diverse tasks.
