# [2507.19457] GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning

## Summary

- **GEPA (Genetic-Pareto)** introduces a prompt optimization framework leveraging natural language reflection to iteratively diagnose, propose, and test prompt updates via trial-and-error, outperforming traditional RL methods like GRPO.

- **Empirical results** show GEPA achieves **6% average improvement** over GRPO (up to **20%**) while using **35x fewer rollouts**, and surpasses MIPROv2 by **>10%** (e.g., **+12% accuracy on AIME-2025**).

- **Key innovation**: GEPA combines **Pareto frontier sampling** with **reflective prompt evolution**, enabling efficient inference-time search and code optimization without dense reward signals.
