# Welcome to LlamaIndex 🦙 ! | Developer Documentation

## Summary

- **Abstraction**: Simplifies complex systems by modeling classes/objects with essential attributes/methods, hiding implementation details.
- **Encapsulation**: Bundles data/operations within a unit (e.g., class) while restricting direct access via access modifiers (e.g., `private`).
- **Polymorphism**: Enables dynamic method resolution via inheritance/interfaces, allowing objects of different classes to be treated uniformly (e.g., method overriding).
