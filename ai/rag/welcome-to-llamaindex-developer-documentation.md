# Welcome to LlamaIndex 🦙 ! | Developer Documentation

## Summary

- **Abstraction**: Simplifying complex systems by modeling classes/objects to represent real-world entities, hiding unnecessary details while exposing essential features.
- **Encapsulation**: Bundling data (attributes) and methods (functions) into a single unit (class) while restricting direct access to some components via access modifiers (e.g., `private`, `protected`).
- **Polymorphism**: Enabling objects of different classes to be treated as objects of a common superclass, facilitating dynamic method resolution (e.g., method overriding, interfaces).
