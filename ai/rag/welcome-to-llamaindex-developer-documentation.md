## Summary

- **Abstraction**: Simplifying complex systems by modeling classes/objects to represent real-world entities, hiding unnecessary details while exposing essential functionalities.
- **Encapsulation**: Bundling data (attributes) and methods (functions) within a class, restricting direct access to some components to prevent unintended interference and misuse.
- **Inheritance**: Mechanism enabling new classes (derived) to acquire properties and behaviors (methods) from existing classes (base), promoting code reusability and hierarchical relationships.
