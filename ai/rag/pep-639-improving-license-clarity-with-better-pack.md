# PEP 639 – Improving License Clarity with Better Package Metadata | peps.python.org

## Summary

- **SPDX Adoption**: Mandates adoption of [SPDX license expression syntax](https://spdx.dev/ids/) for unambiguous license declaration in Python packages, replacing ambiguous classifiers and the `License` field in Core Metadata (v2.4).

- **New Metadata Fields**: Introduces `License-Expression` (SPDX string) and `License-File` (path to license text) in Core Metadata, deprecating the legacy `License` field and Trove classifiers for improved precision.

- **License File Inclusion**: Standardizes inclusion of full license texts in source/binary distributions and installed projects via the `License-File` field, with paths relative to a defined root license directory.
