# Rspamd - Open Source Email Security

## Summary

- **Performance & Architecture**: C-based event-driven engine with Lua scripting, achieving ~100 msg/sec/core throughput, outperforming competitors in speed and scalability.
- **AI/ML Integration**: Supports OpenAI/Ollama GPT plugins for intelligent spam assessment, neural network embeddings, and multiclass Bayes classifier for adaptive filtering.
- **Enterprise Features**: Premium Console offers LLM-assisted rule authoring, ClickHouse/Elasticsearch analytics, antivirus integration, and per-user customization with Redis caching.
