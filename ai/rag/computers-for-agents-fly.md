# Computers for agents · Fly

## Summary

- **Hardware-isolated Linux Sprites**: Dedicated VMs for agents with persistent, object-storage-backed filesystems (up to 100GB), automatic checkpointing, and zero-cost idle states. Supports untrusted code execution in disposable VMs with egress control.

- **Orchestrated Connectivity**: Centralized credential management via Sprites Connectors—configure once, reuse across agents with granular permissions and auto-rotating keys. No tokens stored on Sprites; all external API calls routed through an API gateway.

- **Scalable Infrastructure**: Multi-region deployment with <1s boot time, 500ms deployments, and 99.9% uptime SLA. Enables seamless scaling from prototypes to production without architectural changes, using consistent primitives (e.g., HTTPS endpoints for agent-built apps).
