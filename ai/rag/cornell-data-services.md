# Cornell Data Services

## Summary

- **Code Reusability & Citation**: Use Cornell’s [checklist for reusable code](https://data.research.cornell.edu/data-management/planning/checklist-for-reusable-code/) to ensure code is well-documented, version-controlled, and portable; generate a `CITATION.cff` file via [cffinit](https://cffinit.com/) for citation metadata.

- **Archival & DOI Assignment**: Archive GitHub repositories on [Zenodo](https://zenodo.org/) to obtain a DOI for citable, preserved code, following [3-step guidance](https://data.research.cornell.edu/2026/06/09/3-steps-to-citable-archived-code-with-a-doi/).

- **NSF DMSP Compliance**: NSF’s Data Management and Sharing Plan (DMSP) now requires a webform submission via Research.gov (effective April 27, 2026), replacing PDF-based plans per [NSF DMSP update](https://data.research.cornell.edu/2026/04/20/nsf-dmsp-requirement-update/).
