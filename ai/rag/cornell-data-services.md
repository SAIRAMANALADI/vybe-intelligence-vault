# Cornell Data Services

## Summary

- **Code Reusability & Preservation**: Cornell’s *checklist for reusable code* emphasizes documentation, portability, and version control; archiving citable code requires a `CITATION.cff` file and DOI assignment via Zenodo or similar repositories.

- **Data Management & Sharing Compliance**: Cornell’s *Data Storage Finder* and *eCommons* support FAIR principles, federal requirements, and metadata standardization for reproducible research and long-term preservation.

- **Archival Best Practices**: *File formats for preservation* and *preparing tabular data* guides ensure data integrity; Zenodo’s Cornell Research Data Community and eCommons provide persistent storage and DOI-based citation mechanisms.
