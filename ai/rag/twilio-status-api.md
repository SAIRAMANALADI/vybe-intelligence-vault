# Twilio Status - API

## Summary

- **Twilio Status API** provides programmatic access to real-time system status, incidents, and scheduled maintenance via endpoints like `/summary.json`, `/status.json`, and `/components.json`, returning structured JSON with component states (e.g., `partial_outage`, `major_outage`) and incident metadata.

- **Notification Subscriptions** support multi-channel alerts (email, SMS, Slack, webhooks) for incident updates, with endpoints for subscriber management (`/subscribers`) and incident-specific subscriptions (`/incident-subscribers`).

- **Component Grouping** allows hierarchical status aggregation (e.g., API, Management Portal) with status indicators (`operational`, `degraded_performance`, `partial_outage`, `major_outage`) and timestamped updates for monitoring and debugging.
