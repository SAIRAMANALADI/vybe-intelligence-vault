# RxDB | Works With Supabase

## Summary

- **Local-First Database**: RxDB is a client-side JavaScript database enabling real-time, reactive data storage and querying directly in the browser, mobile, or desktop apps without server dependency.

- **Supabase Integration**: The RxDB Supabase plugin synchronizes local RxDB instances with Supabase’s managed Postgres, supporting real-time updates, auth, and row-level security while handling conflict resolution automatically.

- **Offline-First Sync**: Enables seamless offline/online data synchronization, ensuring UI reactivity and consistent state across devices via Supabase’s real-time and replication capabilities.
