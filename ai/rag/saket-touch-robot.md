# saket/touch-robot

## Summary

- **Purpose**: Provides interactive screenshot testing utilities for Jetpack Compose UI using Paparazzi, enabling precise control over touch interactions in automated UI tests.

- **Key Components**: Implements a `TouchRobot` DSL for simulating gestures (e.g., clicks, swipes) and integrates with Paparazzi for deterministic screenshot comparisons.

- **Technical Stack**: Built in Kotlin, leveraging Compose UI’s testing APIs and Paparazzi’s rendering engine for cross-platform screenshot validation.
