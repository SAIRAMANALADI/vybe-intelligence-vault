# zilliztech/claude-context

## Summary

- **Code Search MCP**: Implements a **Model Context Protocol (MCP)** server in TypeScript for **Claude Code**, enabling semantic search across entire codebases via embeddings (powered by **Voyage AI**).
- **Agentic RAG Pipeline**: Uses **Merkle trees** for efficient code indexing and retrieval, integrating with **vector databases** (e.g., Milvus/Zilliz) for scalable **semantic search** and **RAG** workflows.
- **Multi-IDE/Editor Support**: Designed for **Claude Code**, **Cursor**, **VSCode**, and **Gemini CLI**, with Node.js runtime and TypeScript-based tooling for extensibility.
