# langgenius/dify

## Summary

- **Agentic Workflow Platform**: Open-source, production-ready framework in TypeScript/Python for developing agentic workflows with LLM integration (OpenAI, GPT-4, Gemini), RAG, and MCP support, enabling low/no-code automation and orchestration.

- **Multi-Model & Tooling Support**: Supports 100+ LLMs (including OpenAI, Anthropic, Mistral), vector databases (e.g., Chroma, Weaviate), and APIs for building AI agents with retrieval, tool-use, and MCP integration.

- **Deployment & Scalability**: Built on Next.js for frontend, FastAPI for backend, with Docker/Kubernetes support for scalable, cloud-agnostic deployment; includes built-in monitoring, logging, and CI/CD integration.
