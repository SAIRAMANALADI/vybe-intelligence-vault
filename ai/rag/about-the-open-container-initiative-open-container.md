# About the Open Container Initiative - Open Container Initiative

## Summary

- **OCI Specifications**: Defines three key standards—Runtime Specification (filesystem bundle execution), Image Specification (OCI Image creation with manifest, layer serialization, and configuration), and Distribution Specification (standardized API for container image distribution, v1.0 released May 2020).

- **OCI Image Structure**: Comprises an image manifest (metadata, dependencies, content-addressable layers), image configuration (runtime parameters like command, arguments, environment variables), and filesystem layers (serialized archives unpacked to form the runnable filesystem).

- **Governance & Implementation**: Open governance structure under the Linux Foundation; Docker donated runC and container format as foundational components; supports standardized container UX (e.g., `docker run`/`rkt run` commands).
