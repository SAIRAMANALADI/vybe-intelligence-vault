# IAAR-Shanghai/CRUD_RAG

## Summary

- **Benchmark Overview**: CRUD-RAG is a Chinese-language benchmark designed to evaluate Retrieval-Augmented Generation (RAG) systems for Large Language Models (LLMs), focusing on comprehensive performance metrics across retrieval and generation tasks.

- **Technical Scope**: The benchmark includes structured (CRUD) and unstructured (RAG) evaluation dimensions, assessing LLMs' capabilities in Chinese context understanding, retrieval precision, and response generation quality.

- **Implementation**: The repository provides a Python-based framework for benchmarking, including datasets, evaluation scripts, and baseline models to facilitate reproducible research in Chinese RAG systems.
