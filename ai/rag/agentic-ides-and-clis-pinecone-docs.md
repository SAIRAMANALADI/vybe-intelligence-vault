# Agentic IDEs and CLIs - Pinecone Docs

## Summary

- **MCP Integration**: Pinecone offers an official MCP server enabling natural language-driven vector database operations (index management, semantic search, RAG workflows) across agentic IDEs (Claude Code, Cursor) and CLIs via standardized tools and slash commands.

- **Multi-Tool Support**: Provides dedicated plugins/extensions for IDEs (Claude Code, Cursor, Gemini CLI) and a universal skills library for GitHub Copilot/Codex, alongside a standalone CLI (`pc`) for direct terminal-based index/namespace/record management.

- **Skill Set**: Core capabilities include `quickstart`, `query`, `assistant` (document Q&A with citations), `full-text-search`, `n8n` integration, and low-level MCP tools for index operations (listing, creation, upsert, search, reranking) via the Pinecone MCP server.
