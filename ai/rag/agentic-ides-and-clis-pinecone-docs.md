# Agentic IDEs and CLIs - Pinecone Docs

## Summary

- **Pinecone MCP Server & CLI**: Provides Model Context Protocol (MCP) server for index management, semantic search, and RAG workflows, alongside a terminal-accessible CLI (`pc`) for direct index/namespace/record operations without agent dependency.

- **Agentic IDE/CLI Integrations**: Official plugins/extensions for Claude Code, Gemini CLI, Cursor, GitHub Copilot, and Codex, enabling natural language-driven vector DB operations via Pinecone’s "skills" library (e.g., `query`, `assistant`, `full-text-search`).

- **Skill Set & Setup**: Includes MCP tools for index listing/creation, vector upsert/search, reranking, and prebuilt skills (e.g., `quickstart`, `n8n` workflows), requiring a Pinecone API key for all tools.
