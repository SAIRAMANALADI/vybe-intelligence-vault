# Agentic IDEs and CLIs - Pinecone Docs

## Summary

- **Pinecone MCP Server**: Enables natural language interaction with Pinecone vector databases via Model Context Protocol (MCP), supporting index management, semantic search, and RAG application development across agentic IDEs/CLIs.

- **Tool Integration Matrix**: Provides official plugins/extensions for Claude Code (`claude plugin install pinecone`), Gemini CLI (`gemini extensions install ...`), Cursor (`/add-plugin pinecone`), and a universal Agent Skills library (`npx skills add pinecone-io/skills`), all requiring a Pinecone API key.

- **Core Skills & CLI**: Includes skills for quickstart, querying (`query`), Assistant-based Q&A (`assistant`), full-text search (FTS), and a dedicated `pc` CLI for direct terminal operations (e.g., `brew install pinecone-io/tap/pinecone`).
