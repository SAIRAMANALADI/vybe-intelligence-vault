# Cloud-Optimized Geospatial Formats Guide

## Summary

- **Cloud-optimized geospatial formats** enable efficient subsetting and parallelized access to large datasets via metadata-addressable chunks, reducing latency and enabling scalable, on-the-fly processing without full file downloads.

- **Key characteristics** include: 1) metadata stored in a consistent, single-read location, 2) addressable data blocks for partial reads, and 3) compatibility with cloud object storage for infinite scalability and cost-effective access.

- **Common formats** include Cloud-Optimized GeoTIFFs, Zarr, COPC (compressed LAS), GeoParquet, FlatGeobuf, and PMTiles, each optimized for specific geospatial data types (raster, vector, point clouds) with community-driven tools and libraries for generation/testing.
