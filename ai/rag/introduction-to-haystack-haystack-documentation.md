# Introduction to Haystack | Haystack Documentation

## Summary

- **Modular AI Orchestration Framework**: Haystack v2.30 is an open-source framework for building production-ready AI agents, RAG applications, and multimodal search systems using reusable, customizable components (e.g., LLMs, document stores, agents, tools) with integrations from providers like OpenAI, Google, Anthropic, and Hugging Face.

- **Core Architecture**: The framework relies on a component-pipeline model, enabling scalable pipelines for autonomous agents, multimodal apps, and RAG systems, with enterprise-grade support via Haystack Enterprise for deployment, governance, and scaling.

- **Community & Extensibility**: Supported by an active developer community, Haystack offers enterprise tools (e.g., data management, testing, governance) through its Enterprise Platform and Starter packages for production-grade AI development.
