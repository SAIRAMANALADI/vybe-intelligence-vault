# Introduction to Haystack | Haystack Documentation

## Summary

- **Modular AI Orchestration Framework**: Haystack is an open-source framework for building production-ready AI agents, RAG applications, and multimodal search systems using reusable, task-specific components with support for integrating technologies from providers like OpenAI, Google, Anthropic, and Hugging Face.

- **Core Architecture**: The framework is built on components, pipelines, Document Stores, Agents, Tools, and extensive integrations, enabling scalable LLM-based application development with modular customization.

- **Enterprise Extensions**: Offers enterprise-grade support (Haystack Enterprise Starter) and a platform for managing data, pipelines, testing, and governance at scale (Haystack Enterprise Platform).
