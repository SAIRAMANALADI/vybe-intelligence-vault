# Observability and monitoring | Google Cloud Documentation

## Summary

- **Google Cloud Observability Suite**: Provides integrated monitoring, logging, tracing, profiling, and debugging for applications and systems running on Google Cloud and hybrid/multi-cloud environments via services like Cloud Monitoring, Cloud Logging, Cloud Trace, Error Reporting, and Cloud Profiler.

- **Managed Prometheus & Telemetry Collection**: Google Cloud Managed Service for Prometheus enables Prometheus metric collection for workloads, while instrumentation libraries and the Ops Agent facilitate telemetry collection from applications and Compute Engine instances.

- **Cost & Security Optimization**: Includes best practices for managing Cloud Logging costs, leveraging Audit Logs for security insights, and using synthetic monitoring for proactive issue detection, alongside training paths for DevOps/SRE roles.
