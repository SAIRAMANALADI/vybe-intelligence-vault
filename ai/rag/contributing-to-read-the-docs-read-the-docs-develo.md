# Contributing to Read the Docs — Read the Docs developer documentation

## Summary

- **Contribution Pathways**: Read the Docs accepts contributions in development, documentation, and translations, with structured pathways including "Good First Issue" and "Sprintable" labels for incremental onboarding.

- **Issue Triaging Framework**: Mandatory two-phase triage process—initial categorization (Bug, Feature, Improvement, etc.) followed by prioritization using labels like *High Priority* and *Needed: more information*—ensuring systematic issue resolution.

- **Infrastructure & Localization**: Supports AWS temporary credentials integration, server-side search (Elasticsearch), and Transifex-based i18n workflows, with dedicated guides for database migrations and front-end development.
