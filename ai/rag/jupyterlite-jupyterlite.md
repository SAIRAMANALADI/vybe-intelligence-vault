# jupyterlite/jupyterlite

## Summary

- **WebAssembly (Wasm)-based Jupyter**: Runs entirely in-browser using Pyodide (Python compiled to Wasm) for kernel execution, eliminating server dependencies.
- **TypeScript Implementation**: Built with TypeScript, leveraging modern web technologies (e.g., Service Workers, ESM) for lightweight, offline-capable deployment.
- **JupyterLab Extension**: Extends JupyterLab functionality with a "lite" mode, enabling static site generation (SSG) for portable, shareable notebook environments.
