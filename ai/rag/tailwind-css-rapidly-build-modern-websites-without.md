# Tailwind CSS - Rapidly build modern websites without ever leaving your HTML.

## Summary

- **Utility-First Framework**: Tailwind CSS provides low-level utility classes (e.g., `flex`, `pt-4`, `text-center`) that enable rapid, in-HTML styling without writing custom CSS.

- **Advanced Features**: Supports responsive design via breakpoint prefixes (`sm:`, `md:`), dark mode (`dark:`), CSS variables (`@theme`), P3 color gamut, logical properties (`ltr`, `rtl`), container queries, gradients, and 3D transforms.

- **Optimized Performance**: Automatically purges unused CSS in production, resulting in minimal bundle sizes (typically <10kB), and includes tools like cascade layers (`@layer`) and transition utilities for fine-grained control.
