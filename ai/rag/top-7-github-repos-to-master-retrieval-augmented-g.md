# Top 7 GitHub Repos to Master Retrieval-Augmented Generation

## Summary

- **LangChain** provides a modular Python/JS/TS framework for end-to-end RAG pipelines, integrating embeddings (OpenAI/HuggingFace), vector stores (FAISS), and LLM chains (RetrievalQA) with pluggable document loaders and text splitters.

- **RAG-Techniques** (10k+ GitHub stars) offers battle-tested implementations of retrieval strategies (e.g., parent-child chunking, hybrid search), embedding optimization, and evaluation metrics for production-grade RAG systems.

- **Minimalist RAG repos** (e.g., `llamaindex`, `fastRAG`) focus on low-latency pipelines with optimized retrieval (BM25/dense retrieval) and generation (quantized LLMs), demonstrating trade-offs between performance and resource usage.
