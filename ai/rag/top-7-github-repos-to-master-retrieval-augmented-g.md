# Top 7 GitHub Repos to Master Retrieval-Augmented Generation

## Summary

- **LangChain** provides a modular Python/JS/TS framework for end-to-end RAG pipelines, including document ingestion, chunking, vector storage (FAISS/others), and retrieval-augmented LLM chains with OpenAI/Hugging Face integrations.

- **RAG-Techniques** repository (10k+ GitHub stars) offers battle-tested implementations of advanced RAG patterns (e.g., parent-child chunking, hybrid search, query rewriting) with empirical evaluations of embedding models and retrieval strategies.

- **Minimalist RAG repos** (e.g., `simple-rag`, `fastRAG`) demonstrate low-overhead pipelines optimized for production, highlighting critical failure modes like embedding drift, chunking granularity, and latency trade-offs in retrieval-augmented generation.
