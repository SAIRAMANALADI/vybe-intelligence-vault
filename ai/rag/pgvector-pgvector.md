# pgvector/pgvector

## Summary

- **Purpose**: Extends PostgreSQL with vector similarity search capabilities via an open-source extension, enabling efficient approximate nearest neighbor (ANN) search for high-dimensional vectors.
- **Implementation**: Written in C, integrates with PostgreSQL’s indexing and query execution systems, supporting vector storage, indexing (e.g., HNSW, IVFFlat), and similarity metrics (e.g., L2, cosine, inner product).
- **Features**: Supports exact and approximate search, custom functions for distance calculations, and compatibility with existing PostgreSQL tooling and extensions.
