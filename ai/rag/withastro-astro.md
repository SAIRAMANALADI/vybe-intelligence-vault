# withastro/astro

## Summary

- **Astro Framework**: A modern web framework designed for content-driven websites, leveraging a hybrid architecture combining static site generation (SSG), server-side rendering (SSR), and client-side interactivity via "islands" architecture for optimized performance.

- **Multi-Runtime Support**: Executes across Node.js (server), browser (client), and edge networks, enabling universal deployment with minimal configuration overhead.

- **Component-Based Architecture**: Supports UI components from React, Vue, Svelte, and others, rendered to static HTML at build time while preserving interactivity where needed.
