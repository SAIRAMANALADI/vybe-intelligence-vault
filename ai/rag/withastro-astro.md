# withastro/astro

## Summary

- **Astro Framework**: A modern, content-driven web framework optimized for building static and hybrid websites with minimal client-side JavaScript, leveraging an "islands" architecture for performance.
- **Multi-Runtime Support**: Enables universal rendering by supporting server-side (Node.js), static site generation (SSG), and client-side hydration for hybrid applications.
- **Component-Based Architecture**: Supports UI components (React, Vue, Svelte, etc.) rendered to static HTML at build time, with partial hydration for interactivity.
