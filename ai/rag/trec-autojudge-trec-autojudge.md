# TREC AutoJudge ← TREC AutoJudge

## Summary

- **Task Definition**: AutoJudge aims to predict system evaluation scores and generate leaderboards for TREC tracks using LLM-as-a-Judge approaches, with meta-evaluation against manual relevance labels to assess biases, vulnerabilities, and guardrails.

- **Pilot Data & Evaluation**: Participants use anonymized runs from TREC 2025 tracks (BioGen, DRAGUN, RAG, RAGTIME), predicting leaderboards and optional artifacts (qrels, nuggets, rationales), evaluated via Kendall’s tau against official leaderboards.

- **Tools & Submission**: Starterkit and GitHub repos (auto-judge-starter-kit, auto-judge-evaluate) facilitate development; submissions accepted via files or TIRA, with an evaluation service available upon request.
