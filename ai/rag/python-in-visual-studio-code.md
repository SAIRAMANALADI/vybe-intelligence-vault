# Python in Visual Studio Code

## Summary

- **Multi-Language Support**: VS Code provides built-in language support and IntelliSense for 20+ languages (e.g., Python, JavaScript, C++, TypeScript, Go) via dedicated extensions, enabling syntax highlighting, code navigation, and refactoring.

- **Python-Specific Features**: The Microsoft Python extension enables linting, debugging, unit testing, and environment switching (including virtual/conda environments), with AI-enhanced autocompletion and Jupyter notebook integration.

- **Cross-Platform Development**: Supports debugging, IntelliSense, and build tools across platforms (Windows, macOS, Linux) with WSL integration, CMake for C++, and framework-specific tooling (e.g., Django, React, Spring Boot).
