# New embedding models and API updates | OpenAI

## Summary

- **New Embedding Models**: Introduced `text-embedding-3-small` (5x cheaper than `text-embedding-ada-002`, 62.3% avg. MTEB score) and `text-embedding-3-large` (3072-dim embeddings, 64.6% avg. MTEB score, $0.00013/1k tokens) with native support for dynamic dimensionality reduction via `dimensions` parameter.

- **Model Updates & Pricing Reductions**: Launched `gpt-3.5-turbo-0125` (50% cheaper input, 25% cheaper output) and `gpt-4-0125-preview` (improved code generation, UTF-8 bug fix); deprecated `text-embedding-ada-002` pricing reduced to $0.00002/1k tokens.

- **API Management Enhancements**: Added granular API key permissions and per-key usage tracking in the dashboard, enabling role-based access control and cost attribution at the feature/team/project level.
