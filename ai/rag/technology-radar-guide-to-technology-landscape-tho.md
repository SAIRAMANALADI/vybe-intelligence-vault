# Technology Radar | Guide to technology landscape | Thoughtworks

## Summary

- **Semantic diffusion in AI-driven development**: Evolving terminology (e.g., "spec-driven development," "harness engineering") lacks standardized definitions, complicating evaluation of new AI tools and methodologies amid rapid innovation cycles.

- **Permission management for agentic systems**: AI agents require broad system access but lack robust safeguards against threats like prompt injection, inconsistent behavior, and unintended exfiltration, necessitating zero-trust architectures and modular agent pipelines.

- **Harness engineering for coding agents**: Emerging controls (e.g., Agent Skills, spec-driven frameworks like GitHub Spec-Kit) combine feedforward (pre-execution guidance) and feedback (post-execution correction) mechanisms to mitigate risks of unsupervised agent operations.
