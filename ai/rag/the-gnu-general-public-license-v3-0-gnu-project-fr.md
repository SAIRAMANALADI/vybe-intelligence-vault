# The GNU General Public License v3.0 - GNU Project - Free Software Foundation

## Summary

- **Copyleft License**: The GNU GPLv3 is a copyleft license ensuring software and works remain free by mandating derivative works to also be licensed under GPLv3, preserving user freedoms to share and modify.

- **Anti-Circumvention & Anti-Tivoization**: Section 3 prohibits treating GPL-covered works as part of technological measures under anti-circumvention laws (e.g., DMCA), and Section 6 restricts restrictions on user modification of hardware ("Tivoization").

- **Source Code & Corresponding Source**: Sections 1 and 6 require distribution of complete source code (or "Corresponding Source") for modified or conveyed works, including build scripts and dependencies, to ensure user control and modifiability.
