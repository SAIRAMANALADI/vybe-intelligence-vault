# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces Chroma dark/light mode syntax highlighting pairs, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), RST markup syntax highlighting support, Pandoc citation integration, and sub-path layout support in `Page.Render`.

- **Performance regression fix** from v0.128.0 addressed, improving build times for larger sites, alongside deprecation of `resources.PostProcess` in favor of `templates.Defer`.

- **Dependency updates** include Go toolchain upgrades (x/tools v0.45.0→v0.47.0, x/net v0.55.0→v0.56.0) and Chroma v0.18.0 for enhanced syntax highlighting.
