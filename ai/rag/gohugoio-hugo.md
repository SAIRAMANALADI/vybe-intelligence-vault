# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces dark/light mode pairs for Chroma highlighter styles, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and Pandoc citation support, alongside a performance regression fix for larger sites.

- **Deprecations & Fixes**: Resources.PostProcess is deprecated in favor of `templates.Defer`, and a performance regression introduced in v0.128.0 affecting build times is resolved.

- **Dependencies**: Updated Go modules (`x/tools`, `x/image`, `x/net`, `x/mod`) and libraries (`esbuild`, `Chroma`, `go-toml/v2`, `kin-openapi`).
