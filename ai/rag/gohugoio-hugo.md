# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces dark/light mode pairs for Chroma highlighter styles, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and Pandoc citation support, alongside a performance regression fix from v0.128.0.

- **Deprecations & Enhancements**: Resources.PostProcess is deprecated in favor of `templates.Defer`, markup RST syntax highlighting is configurable, and template name lookup is now case-insensitive.

- **Performance & Dependencies**: Optimized `hasBytesWriter` in `hugio`, updated Go toolchain dependencies (e.g., `x/tools` v0.45.0→v0.47.0), and added Chroma dark/light mode support.
