# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces Chroma dark/light mode syntax highlighting pairs, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), Pandoc citation support, and fixes a performance regression from v0.128.0 affecting large sites.

- **Deprecations & Changes**: Resources.PostProcess is deprecated in favor of `templates.Defer`; added `markup.rst.syntaxHighlight` option; improved template name lookup case-insensitivity; and added sub-path support in layouts for `Page.Render`.

- **Performance & Dependencies**: Optimized `hasBytesWriter` in `hugio`; updated Go toolchain dependencies (e.g., `x/tools` v0.45.0→v0.47.0); and upgraded Chroma for enhanced syntax highlighting.
