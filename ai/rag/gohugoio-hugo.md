# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces Chroma dark/light mode syntax highlighting pairs, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and Pandoc citation support; also fixes a performance regression from v0.128.0.

- **Deprecations & Fixes**: Resources.PostProcess deprecated in favor of `templates.Defer`; `markup.rst.syntaxHighlight` option added; sub-path support in layouts for `Page.Render`.

- **Performance & Dependencies**: Optimized `hasBytesWriter`; upgraded dependencies (e.g., `esbuild` v0.28.1, `Chroma` for dual-mode support); case-insensitive template name lookup.
