# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces Chroma highlighter dark/light mode pairs, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and Pandoc citation support, alongside sub-path support in `Page.Render` layouts.

- **Performance regression fix** from v0.128.0 addressed, improving build times for larger sites, with deprecated `resources.PostProcess` replaced by `templates.Defer`.

- **Dependency updates** include Go module bumps (e.g., `golang.org/x/tools` v0.45.0→v0.47.0) and Chroma dark/light mode support via `github.com/alecthomas/chroma`.
