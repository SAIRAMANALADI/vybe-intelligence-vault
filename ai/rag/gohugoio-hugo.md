# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.163.3** introduces:
  - Escaped language identifiers in default code block rendering (`markup/highlight`).
  - Preservation of non-ASCII whitespace post-summary divider (`parser/pageparser`).
  - Support for `babel/postcss` config variants in resource processing (`resources`).

- **Hugo v0.163.2** resolves:
  - `ERR_ACCESS_DENIED` errors in Node.js resolver.
  - Standardized behavior for missing external converters (`markup`).

- **Hugo v0.163.1** patches security vulnerabilities:
  - Upgraded `golang.org/x/image` to v0.42.0 (CVE mitigation).
  - Normalized IPv4 host encodings in HTTP URL validation.
  - Removed symlink handling in `os.*` functions to prevent traversal attacks.
