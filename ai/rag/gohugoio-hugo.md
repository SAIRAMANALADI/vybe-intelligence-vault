# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces dark/light mode pairs for Chroma syntax highlighting styles, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and Pandoc citation support, along with performance regression fixes for large sites.

- **Deprecations & Fixes**: Resources.PostProcess is deprecated in favor of `templates.Defer`, and a performance regression from v0.128.0 affecting build times in larger sites has been resolved.

- **Enhancements**: Added `markup.rst.syntaxHighlight` option, sub-path support in `.Render` layouts, case-insensitive template name lookup, and optimized `hugio.hasBytesWriter` for faster builds.
