# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.163.3** (2026-06-18): Fixes include escaping language identifiers in default code block rendering (`markup/highlight`), preserving non-ASCII whitespace after summary dividers (`parser/pageparser`), and adding support for `babel/postcss` config variants (`resources`). Also resolves a regression causing page/section name collisions (`hugolib`).

- **Hugo v0.163.2** (2026-06-15): Addresses `ERR_ACCESS_DENIED` in Node's resolver and standardizes behavior for missing external converters (`markup`), improving error handling and compatibility.

- **Hugo v0.163.0** (2026-06-08): Introduces AVIF image handling improvements (default quality reduced to 60, added `hint` for YUV420/YUV444 chroma subsampling), deprecates `Imaging.Compression`, and removes deprecated `baseUrl` in JS config. Also drops support for Go versions older than the latest.
