# Releases · gohugoio/hugo · GitHub

## Summary

- **Hugo v0.164.0** introduces dark/light mode pairs for Chroma highlighter styles, new template functions (`encoding.HexEncode`, `encoding.HexDecode`, `crypto.Hash`), and Pandoc citation support, alongside a performance regression fix from v0.128.0.

- **Deprecations & Enhancements**: `resources.PostProcess` is deprecated in favor of `templates.Defer`; `markup.rst.syntaxHighlight` option added; sub-paths now supported in layouts passed to `.Render`.

- **Performance & Dependencies**: Optimized `hasBytesWriter` in `hugio`; updated Go toolchain (`x/tools`, `x/net`, `x/mod`) and libraries (e.g., `esbuild`, `Chroma`).
