# langchain-ai/langchain

## Summary

- **Framework**: Open-source Python library (`langchain`) for building AI agents, supporting LLMs (OpenAI, Anthropic, Gemini), multi-agent systems, and enterprise-grade workflows.
- **Key Components**: Integrates with `LangGraph` for stateful, multi-actor workflows, `Pydantic` for structured outputs, and supports RAG, enterprise tooling, and TypeScript interoperability.
- **Ecosystem**: Extensive tooling for generative AI, including deepagents, enterprise integrations, and compatibility with ChatGPT, OpenAI, and other LLM providers.
