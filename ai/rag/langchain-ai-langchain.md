# langchain-ai/langchain

## Summary

- **Multi-Language LLM Framework**: Python-based open-source framework supporting integration with OpenAI, Anthropic, Gemini, and other LLMs, enabling generative AI applications via modular components (e.g., RAG, multi-agent systems).

- **Agent & Workflow Orchestration**: Provides `LangGraph` for building stateful, multi-agent systems with Pydantic-based structured outputs, supporting enterprise-grade workflows and tool integration (e.g., chatbots, enterprise automation).

- **Extensible Tooling**: Supports TypeScript (via `@langchain/langgraph`) and Python, with libraries for document processing (RAG), enterprise tooling, and deep customization for AI agent engineering.
