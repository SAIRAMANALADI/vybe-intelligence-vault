# About building integrations - GitHub Docs

## Summary

- **Integration Types**: GitHub integrations extend functionality via GitHub Apps (server/device-hosted), GitHub Actions workflows (event-triggered), or custom actions (workflow-executable code).

- **API & Webhooks**: Integrations interact with GitHub using REST/GraphQL APIs for data operations and webhooks to receive real-time event notifications.

- **Publishing & AI**: GitHub Apps/custom actions can be published to GitHub Marketplace; AI-powered integrations can leverage GitHub's free AI model prototyping tools.
