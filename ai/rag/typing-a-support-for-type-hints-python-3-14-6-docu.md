## Summary

- **Type Aliases & NewType**: The `typing` module supports type aliases via `type` statements (Python 3.12+) or assignments (backward-compatible), enabling simplification of complex type signatures. `NewType` creates distinct subtypes for logical error prevention, enforced only by static type checkers, with minimal runtime overhead.

- **Callable Annotation**: Functions/callables are annotated using `collections.abc.Callable` (or deprecated `typing.Callable`), specifying argument types and return types. Supports variadic arguments via `Protocol` classes with `__call__()` for complex signatures (e.g., keyword-only parameters).

- **Type System Specification**: The module provides runtime support for type hints (PEP 484), with the canonical type system specification hosted separately. Type hints are not enforced at runtime but are used by static type checkers, IDEs, and linters for static analysis.
