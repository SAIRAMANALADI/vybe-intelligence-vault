# Free Software Directory

## Summary

- **Free Software Definition**: Free software prioritizes user liberties (run, copy, distribute, study, modify, improve) over cost, adhering to the GNU GPL and FSDG compliance for ethical and technical standards.

- **Free Software Directory (FSD)**: A collaborative catalog by the FSF listing 17,156+ free software entries, including GNU packages, high-priority projects, and replacements for nonfree systems (e.g., GNU/Linux, Replicant).

- **Community & Development**: FSD offers IRC meetings (Libera.chat) for technical review, volunteer-driven submissions, and categorized listings (e.g., desktop, development, security tools) to foster open-source contributions.
