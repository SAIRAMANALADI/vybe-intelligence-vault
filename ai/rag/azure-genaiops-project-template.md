# Azure/GenAIOps-project-template

## Summary

- **Purpose**: Provides a Bicep-based infrastructure-as-code (IaC) template for deploying a **Generative AI Ops (GenAIOps) RAG (Retrieval-Augmented Generation) pipeline** on Azure.
- **Key Components**: Includes modular Bicep templates for provisioning Azure resources (e.g., **Azure OpenAI, Cognitive Search, Key Vault, and Container Instances**) to support RAG workflows.
- **Deployment**: Enables automated, scalable GenAIOps environments with **CI/CD-ready configurations** for RAG model fine-tuning and inference pipelines.
