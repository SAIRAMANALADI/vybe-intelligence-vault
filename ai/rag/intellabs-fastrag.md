# IntelLabs/fastRAG

## Summary

- **Framework Overview**: FastRAG is an efficient, Python-based framework for **Retrieval-Augmented Generation (RAG)** optimized for low-latency, high-throughput applications, supporting **multi-modal** inputs (text, images) and **knowledge graphs** for enhanced context retrieval.
- **Core Components**: Integrates **ColBERT** for dense retrieval, **sentence-transformers** for semantic search, and **diffusion models** for generative tasks, with built-in support for **transformer-based LLMs** and **summarization** pipelines.
- **Benchmarking & Scalability**: Provides **standardized benchmarks** for RAG systems, optimized for **semantic search**, **QA**, and **information retrieval**, with hardware-aware optimizations for Intel architectures.
