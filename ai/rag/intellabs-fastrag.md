# IntelLabs/fastRAG

## Summary

- **Framework Overview**: `fastRAG` is an efficient Python-based framework for **Retrieval-Augmented Generation (RAG)**, integrating **multi-modal** and **knowledge-intensive** tasks (e.g., QA, summarization, semantic search) with **transformers**, **ColBERT**, and **sentence-transformers** for optimized retrieval and generation.

- **Key Features**:
  - Supports **diffusion models** for generative tasks, **knowledge graphs** for structured retrieval, and **benchmarking** for performance evaluation.
  - Leverages **Intel-optimized** components (e.g., oneAPI, OpenVINO) for **low-latency** and **high-throughput** inference.
  - Modular design enables **custom pipelines** for **information retrieval**, **re-ranking**, and **LLM-based generation**.

- **Technical Stack**:
  - **Core**: PyTorch, HuggingFace Transformers, FAISS/Annoy for vector search.
  - **Optimizations**: Intel’s **oneDNN**, **SYCL**, and **AVX-512** for hardware acceleration.
  - **Deployment**: Compatible with **CPU/GPU** (including Intel discrete GPUs) and cloud environments.
