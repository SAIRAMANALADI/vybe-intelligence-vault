# IntelLabs/fastRAG

## Summary

- **Framework Overview**: FastRAG is an efficient, modular framework for Retrieval-Augmented Generation (RAG) optimized for low-latency, high-throughput applications, supporting multi-modal inputs (text, images) and leveraging Intel hardware accelerations (e.g., GPUs, CPUs via oneDNN).

- **Core Components**:
  - **Retrieval**: Integrates state-of-the-art dense (e.g., Sentence Transformers, ColBERT) and sparse (e.g., BM25) retrieval methods with support for knowledge graphs and hybrid search.
  - **Generation**: Supports decoder-only LLMs (e.g., HuggingFace Transformers) with optimized inference via Intel’s Neural Compressor and diffusion models for multi-modal outputs.

- **Benchmarking & Deployment**: Includes built-in evaluation tools for RAG pipelines (e.g., QA, summarization) with performance metrics; designed for scalable deployment in cloud/edge environments using Docker and Kubernetes.
