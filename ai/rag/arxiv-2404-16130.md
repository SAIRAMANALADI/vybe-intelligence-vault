# [2404.16130] From Local to Global: A Graph RAG Approach to Query-Focused Summarization

## Summary

- **GraphRAG Architecture**: Introduces a two-stage graph-based LLM indexing method—first constructing an entity knowledge graph from documents, then pre-generating community summaries for entity clusters to enable scalable query-focused summarization.

- **Global Sensemaking**: Addresses limitations of traditional RAG by aggregating partial responses from community summaries into a final, comprehensive answer for large-scale corpus-level queries (e.g., identifying main themes in 1M+ token datasets).

- **Performance Gains**: Demonstrates substantial improvements over conventional RAG baselines in both answer comprehensiveness and diversity for global questions, validated on datasets in the 1M token range.
