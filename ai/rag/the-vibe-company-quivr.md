# The-Vibe-Company/quivr

## Summary

- **Modular RAG Framework**: Quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, supporting customization for LLMs (e.g., GPT4, Groq, Llama) and vector stores (e.g., PGVector, Faiss), with support for any file type.

- **Multi-Backend Compatibility**: Provides flexible backend integration with any LLM provider and vector database, enabling developers to tailor the system to their infrastructure needs while maintaining compatibility with existing products.

- **Full-Stack Deployment**: Includes Dockerized setup for backend (Python) and frontend (React/TypeScript), supporting PostgreSQL for storage, and offers API-driven architecture for secure, privacy-focused RAG implementations.
