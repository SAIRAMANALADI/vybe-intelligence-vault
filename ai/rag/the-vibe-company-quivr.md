# The-Vibe-Company/quivr

## Summary

- **Modular RAG Framework**: Quivr is an opinionated Retrieval-Augmented Generation (RAG) framework designed for seamless GenAI integration into applications, supporting customization for LLMs (e.g., GPT4, Groq, Llama) and vector stores (e.g., PGVector, Faiss) with flexible file ingestion.

- **Multi-Platform Compatibility**: Supports any LLM and vector database backend, with Dockerized deployment options, and integrates via REST APIs, React-based frontend, and TypeScript/JavaScript clients for cross-platform compatibility.

- **Privacy & Security Focus**: Emphasizes secure data handling with PostgreSQL support, privacy-first architecture, and modular design for easy integration into existing products without vendor lock-in.
