# Welcome! — Jupyter Server documentation

## Summary

- **Core Backend Replacement**: Jupyter Server replaces the Tornado Web Server in Jupyter Notebook, providing core services, APIs, and REST endpoints for Jupyter web applications, including a [Swagger-documented API](https://petstore.swagger.io/?url=https://raw.githubusercontent.com/jupyter-server/jupyter_server/main/jupyter_server/services/api/api.yaml).

- **Extension Framework**: Enables development of Jupyter Server extensions (e.g., JupyterLab, Resource Usage, Scheduler) that leverage its framework and services for custom applications and integrations.

- **Multi-Persona Documentation**: Provides targeted technical documentation for users, operators, developers, and contributors, covering architecture, REST API, extension development, security, and deployment configurations.
