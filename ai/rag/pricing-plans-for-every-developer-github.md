# Pricing · Plans for every developer · GitHub

## Summary

- **GitHub Free Tier**: Unlimited public/private repositories, Dependabot security updates, 2,000 CI/CD minutes/month, 500MB package storage, and community support.

- **GitHub Team Plan**: Adds GitHub Codespaces access ($0.18/hr compute, $0.07/GB storage), repository rules, multi-reviewer PRs, draft PRs, code owners, required reviewers, 3,000 CI/CD minutes/month, and 2GB package storage.

- **GitHub Enterprise Plan**: Includes Team features plus data residency, Enterprise Managed Users via IdP, SCIM provisioning, enterprise account management, environment protection rules, SOC1/SOC2 compliance, FedRAMP Tailored ATO, SAML SSO, advanced auditing, GitHub Connect, 50,000 CI/CD minutes/month, and 50GB package storage.
