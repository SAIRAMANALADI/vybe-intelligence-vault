# Pricing · Plans for every developer · GitHub

## Summary

- **GitHub Free Tier**: Unlimited public/private repositories, Dependabot security updates, 2,000 CI/CD minutes/month, 500MB package storage, and community support.

- **GitHub Team Plan ($4/user/month)**: Adds Codespaces access ($0.18/hr compute, $0.07/GB storage), repository rules, multi-reviewer PRs, draft PRs, code owners, required reviewers, Pages/Wikis, 3,000 CI/CD minutes/month, 2GB package storage, and web-based support.

- **GitHub Enterprise Plan ($21/user/month)**: Includes all Team features plus data residency, Enterprise Managed Users via IdP, SCIM provisioning, enterprise account management, environment protection rules, repository rule insights, Audit Log API, SOC1/2 compliance, FedRAMP ATO, SAML SSO, advanced auditing, GitHub Connect, 50,000 CI/CD minutes/month, and 50GB package storage.
