# Pricing · Plans for every developer · GitHub

## Summary

- **GitHub Free Tier**: Unlimited public/private repositories, Dependabot security updates, 2,000 CI/CD minutes/month, 500MB Packages storage, Issues & Projects, and community support.

- **GitHub Team Plan**: Adds GitHub Codespaces access ($0.18/hr compute, $0.07/GB storage), repository rules, multi-reviewer PRs, draft PRs, code owners, required reviewers, Pages/Wikis, 3,000 CI/CD minutes/month, 2GB Packages storage, and web-based support.

- **GitHub Enterprise Plan**: Includes Team features plus data residency, Enterprise Managed Users via IdP, SCIM provisioning, multi-org management, environment protection rules, repository rules with insights, Audit Log API, SOC1/SOC2 compliance, FedRAMP Tailored ATO, SAML SSO, advanced auditing, GitHub Connect, 50,000 CI/CD minutes/month, 50GB Packages storage, and premium support add-ons.
