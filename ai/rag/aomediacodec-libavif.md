# aomediacodec/libavif

## Summary

- **Purpose**: C-based library for encoding and decoding AVIF (AV1 Image File Format) files, leveraging the AV1 codec for high-efficiency compression.
- **Key Features**: Supports both lossy and lossless encoding/decoding, with integration for libaom (AOMedia's AV1 encoder/decoder) and optional support for other AV1 implementations.
- **Dependencies**: Requires libaom for core AV1 functionality; additional dependencies may include libyuv, libsharpyuv, and zlib for auxiliary features.
