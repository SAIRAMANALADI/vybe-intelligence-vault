# vndee/local-assistant-examples

## Summary

- **Purpose**: Demonstrates building a locally runnable ChatPDF application using Python, integrating LangChain, LLMs, Ollama, and RAG for document processing and querying.

- **Key Components**:
  - **LangChain**: Orchestrates LLM workflows.
  - **Ollama**: Local LLM inference engine.
  - **RAG (Retrieval-Augmented Generation)**: Enables context-aware responses from PDF documents.

- **Technical Stack**:
  - **Language**: Python.
