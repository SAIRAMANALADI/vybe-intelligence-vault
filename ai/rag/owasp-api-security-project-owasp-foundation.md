# OWASP API Security Project | OWASP Foundation

## Summary

- **OWASP API Security Top 10 2023** introduces 10 critical API vulnerabilities, including **Broken Object Level Authorization (API1:2023)**, where APIs expose endpoints handling object IDs without proper access control, enabling unauthorized data access.
- **Key risks** include **Broken Authentication (API2:2023)**, where flawed auth mechanisms allow token compromise or identity theft, and **Server-Side Request Forgery (API7:2023)**, where APIs fetch unvalidated URIs, enabling attackers to coerce requests to unintended destinations.
- **Project structure** includes a **2023 stable release** (June 2023), **multilingual translations** (e.g., French, Persian, Portuguese), and **planned initiatives** like `crAPI` (intentionally vulnerable API project) and a **GraphQL Cheat Sheet** (released October 2020).
