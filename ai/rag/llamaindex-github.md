# LlamaIndex · GitHub

## Summary

- **LlamaParse Cloud Services**: Offers three cloud-based products—`Parse` (SOTA Agentic OCR for document processing), `Extract` (structured data extraction), and a `Platform Documentation` suite for integration and workflow management.

- **Open-Source Tooling**: Provides `LiteParse` (lightweight OCR), `LlamaAgents` (modular agent framework), and `LlamaIndex (Python)` (core indexing/retrieval library) with comprehensive documentation for local deployment and customization.

- **Community & Support**: Maintains active engagement via Twitter (`@llama_index`), LinkedIn, and YouTube for updates, tutorials, and community-driven enhancements.
