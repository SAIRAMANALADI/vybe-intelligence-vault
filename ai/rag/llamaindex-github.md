# LlamaIndex · GitHub

## Summary

- **LlamaParse Cloud Services**: Provides SOTA agentic OCR via `Parse` for document ingestion, `Extract` for structured data extraction, and a unified `Platform Documentation` for integration and deployment workflows.

- **Open-Source Tooling**: Offers `LiteParse` for lightweight parsing, `LlamaAgents` for agentic workflow orchestration, and the core `LlamaIndex (Python)` framework for building RAG and document processing pipelines.

- **Community & Documentation**: Maintains active support via [X (Twitter)](https://twitter.com/llama_index), [LinkedIn](https://www.linkedin.com/company/llamaindex), and [YouTube](https://www.youtube.com/@llamaindex), with comprehensive docs for all tools.
