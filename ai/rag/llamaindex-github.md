# LlamaIndex · GitHub

## Summary

- **LlamaParse Cloud Services**: Provides **SOTA (State-of-the-Art) Agentic OCR** via cloud APIs (`Parse`, `Extract`) for document processing workflows, enabling high-accuracy extraction and structured data generation from unstructured documents.

- **Open-Source Ecosystem**: Includes **LiteParse** (lightweight OCR), **LlamaAgents** (modular agent framework), and **LlamaIndex (Python)** (comprehensive data framework) with full documentation for local/custom deployments.

- **Multi-Platform Integration**: Supports **X (Twitter), LinkedIn, and YouTube** for community engagement, alongside GitHub repositories for core tools and documentation.
