# Vector Embeddings Explained | Weaviate

## Summary

- **Vector embeddings** are fixed-length arrays of real numbers (typically 100-4000 dimensions) generated by ML models to numerically represent semantic meaning of data objects (text, images, audio, etc.), enabling similarity-based search via geometric proximity in vector space.

- **Semantic search workflow**: Embeddings are computed for both database objects and queries using the same model, then indexed for efficient retrieval; search quality depends on model performance, while speed relies on vector database optimization and distance metric selection (e.g., cosine similarity, Euclidean distance).

- **Model evolution**: Early word2vec/GloVe embeddings were context-agnostic, while modern transformer-based models (BERT, CLIP) generate context-aware embeddings, capturing polysemy and cross-modal relationships (e.g., aligning text/image vectors), though requiring significantly more compute/memory.
