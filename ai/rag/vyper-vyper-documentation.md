# Vyper - Vyper documentation

## Summary

- **Language Design**: Vyper is a Pythonic, contract-oriented language for EVM, prioritizing security, auditability, and simplicity by enforcing strong typing, bounds/overflow checks, and decidable gas consumption via static analysis.
- **Restricted Features**: Explicitly avoids modifiers, inheritance, overloading (function/operator), inline assembly, recursion, and infinite loops to prevent misleading code and ensure predictable execution flow.
- **State Management**: Enforces pure functions (no state modification) and composition-based code reuse, requiring explicit syntactic marking of state-modifying dependencies for improved readability and safety.
