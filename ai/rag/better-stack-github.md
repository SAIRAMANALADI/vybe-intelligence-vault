# Better Stack · GitHub

## Summary

- **Observability Platform**: Better Stack provides a unified observability suite for logs, metrics, and traces, enabling faster software delivery through structured telemetry and real-time monitoring.

- **eBPF-Based Kubernetes Integration**: The `collector` and `collector-helm-chart` repositories leverage eBPF for low-overhead instrumentation of Kubernetes/Docker clusters, collecting logs, metrics, and OpenTelemetry traces without code modifications.

- **Terraform & Cloud Providers**: Offers Terraform providers (`terraform-provider-logtail`, `terraform-provider-better-uptime`) and cloud-native integrations (AWS, Azure, GCP) for automated infrastructure-as-code deployments and log forwarding pipelines.
