# Run Milvus Lite Locally | Milvus Documentation

## Summary

- **Milvus Lite**: Lightweight, local vector database embedded in Python applications via `pymilvus`, supporting core vector search with persistence, CRUD operations, and hybrid search; ideal for edge devices, Jupyter Notebooks, or small-scale AI workflows.

- **Limited Feature Set**: Restricted to `FLAT` index type, lacks partition/role/alias support, enforces `Strong` consistency, and omits advanced features like dynamic sharding or partition keys.

- **Seamless Migration**: Data from Milvus Lite can be exported via `milvus-lite dump` and imported into Milvus Standalone/Distributed or Zilliz Cloud, ensuring compatibility across deployment scales.
