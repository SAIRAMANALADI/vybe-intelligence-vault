# GitHub Secret Protection · GitHub

## Summary

- **Real-time Secret Detection & Prevention**: GitHub Secret Protection continuously monitors repositories, proactively blocking secret leaks (e.g., API keys, tokens) during pushes via **push protection**, leveraging **~150 service provider integrations** for rapid credential revocation and low false positives.

- **Multi-Context Secret Scanning**: Detects secrets in **code, issues, discussions, and PRs** using metadata-driven prioritization (e.g., validity checks, public leak alerts) and **GitHub Copilot** for advanced pattern recognition beyond traditional detectors.

- **Policy Enforcement & Risk Assessment**: Enables **delegated bypass approvals**, standardized compliance configurations, and **one-click risk assessments** to evaluate exposure across repositories, powered by a **global security partnership** (e.g., AWS, Google Cloud, OpenAI).
