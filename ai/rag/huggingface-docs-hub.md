# Spaces · Hugging Face

## Summary

- **Hosting & Deployment**: Hugging Face Spaces enables hosting ML demo applications directly on user/organization profiles with built-in support for Gradio SDK, Docker, and static HTML/JavaScript, including GPU/accelerated hardware upgrades.

- **Multi-SDK Support**: Supports Gradio (Python), Docker (arbitrary Dockerfiles), and static web apps (HTML/JS), with additional features like Dev Mode, disk/storage management, and custom domain integration.

- **Collaboration & Integration**: Facilitates ML portfolio showcasing, collaborative projects, and embeddable demos; includes GitHub Actions integration, OAuth/Sign-In, and API endpoints for MCP servers/agent tools.
