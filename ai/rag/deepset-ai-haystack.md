# deepset-ai/haystack · Discussions · GitHub

## Summary

- **Haystack** is an open-source framework by **deepset-ai** for building **RAG (Retrieval-Augmented Generation)** pipelines, with **26.2k GitHub stars** and **3k forks**, supporting modular components for document processing, retrieval, and LLM integration.

- **Haystack 3.0** was launched in **July 2026**, introducing new features for **agentic LLM systems**, including **runtime security guards (AgentShield)**, **diagnostics engines**, and **async execution bridges** for sandboxed pipelines.

- Active community discussions focus on **debugging retrieval failures**, **measuring hallucination rates**, and **managing production-grade agentic workflows**, with tools like **DoclingConverter** and **MCPToolset** for enhanced pipeline control.
