# Golioth IoT Infrastructure as Code

## Summary

- **Firmware & Connectivity**: Golioth provides a flexible firmware SDK for microcontroller integration, supporting Wi-Fi, Cellular, Ethernet, Thread, and Bluetooth (including cloud connectivity via intelligent gateways) with a single firmware deployment across heterogeneous devices.

- **AI Orchestration & Data Routing**: Enables hybrid AI at the edge and cloud with built-in orchestration for inference, real-time model updates, and YAML-configurable data pipelines to route raw device data to AWS, Azure, GCP, or custom APIs with on-the-fly transformations.

- **Device Management & Cost Efficiency**: Offers real-time fleet monitoring, bulk operations, remote diagnostics, and flexible device cohorts via a unified console/API, with unlimited device management and pay-per-storage/stream pricing model.
