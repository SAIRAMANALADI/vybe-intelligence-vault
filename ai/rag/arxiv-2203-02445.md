# [2203.02445] SFPN: Synthetic FPN for Object Detection

## Summary

- **SFPN Architecture**: Introduces synthetic layers between original FPN layers to mitigate down-scaling gaps (e.g., stride-2 convolutions/pooling), improving multi-scale feature fusion for lightweight CNNs.
- **Performance Gains**: Demonstrates superior Average Precision (AP) scores compared to both large backbones (VGG16, ResNet50) and lightweight models (MobileNetV2) in object detection tasks.
- **Key Insight**: Addresses FPN’s limitation in smooth feature fusion due to abrupt resolution reduction, enhancing accuracy for small/medium objects in lightweight architectures.
