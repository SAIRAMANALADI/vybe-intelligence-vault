# Adafruit Learning System

## Summary

- **CircuitPython** is a Python dialect optimized for microcontrollers and single-board computers (e.g., Raspberry Pi), enabling hardware control via high-level scripting.

- **Adafruit's storage-focused guides** cover SD/MicroSD card breakouts (SPI/I2C), FRAM, EEPROM, and QSPI DIP modules, detailing pinouts, protocols, and integration for embedded systems.

- **New projects** include NeoPixel goggles (BLE-enabled), RP2350-based video feedback systems, and WLED 16 for addressable LED matrix control, leveraging CircuitPython for rapid prototyping.
