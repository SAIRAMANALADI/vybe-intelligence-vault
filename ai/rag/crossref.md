# Crossref

## Summary

- **Crossref Infrastructure**: Operates open infrastructure linking research objects, entities, and actions, supporting >25,000 members across 167 countries and handling 2.1 billion monthly API queries to enable global research communication.

- **Metadata & DOI Services**: Provides metadata exchange, DOI registration (via PubPub), and tools like Crossmark, Similarity Check, and Metadata Plus; deprecating co-access in favor of multiple resolution service by 2026.

- **Community & Governance**: Offers membership programs (e.g., Global Equitable Membership), service provider accreditation, working groups, and governance via a board of directors, alongside documentation and API learning resources.
