# LlamaIndex Chat UI

## Summary

- **React Component Library**: Provides a React-based UI framework for building advanced chat interfaces in LLM applications, compatible with modern frontend stacks.

- **Prebuilt Demos**: Includes specialized chat interfaces (e.g., Simple Chat, LaTeX, Mermaid Diagram) showcasing dynamic content rendering and interactive features.

- **Installation Options**: Supports integration via Shadcn CLI (`npx shadcn@latest add https://ui.llamaindex.ai/r/chat.json`) or direct npm installation (`npm install @llamaindex/chat-ui`).
