# [2605.13880] PREPING: Building Agent Memory without Tasks

## Summary

- **Proposer-Guided Memory Construction**: Introduces *PREPING*, a framework where a **Proposer** generates synthetic tasks conditioned on a structured *proposer memory* state, a **Solver** executes them, and a **Validator** filters trajectories for memory insertion while providing feedback to refine future proposals.

- **Pre-Task Memory Efficiency**: Demonstrates that **pre-task procedural memory** can be built using self-generated synthetic practice alone, avoiding cold-start gaps in new environments; achieves competitive performance with lower deployment costs ($2.99\times$ on AppWorld, $2.23\times$ on BFCL v3) compared to online memory construction.

- **Key Mechanisms for Memory Quality**: Improvements stem from **proposer-side control** over task feasibility, redundancy, and coverage, combined with **selective memory updates**—synthetic volume alone is insufficient without these constraints.
