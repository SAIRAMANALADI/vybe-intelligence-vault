# [2605.13880] PREPING: Building Agent Memory without Tasks

## Summary

- **Preping Framework**: Introduces a proposer-guided memory construction method where a *Proposer* generates synthetic tasks based on a structured *proposer memory* state, a *Solver* executes them, and a *Validator* filters trajectories for memory insertion while providing feedback to refine future proposals.

- **Cold-Start Mitigation**: Addresses the agent's cold-start problem by enabling pre-task memory construction using self-generated synthetic practice, avoiding reliance on curated demonstrations or post-deployment interactions, while ensuring feasibility, redundancy control, and coverage via proposer-side control.

- **Performance & Efficiency**: Demonstrates substantial improvements over no-memory baselines and competitive performance with playbook-based methods, achieving **2.99× lower deployment cost** on AppWorld and **2.23× lower cost** on BFCL v3 compared to online memory construction, with benefits attributed to selective memory updates and proposer-guided task generation.
