# MicroPython - Python for microcontrollers

## Summary

- **Implementation**: MicroPython is a compact, C99-implemented Python 3 compiler/runtime optimized for microcontrollers, requiring only **256k code space** and **16k RAM**, while supporting advanced features like arbitrary-precision integers, closures, generators, and exception handling.

- **Hardware Integration**: The **pyboard** (STM32F405RG, 168 MHz Cortex-M4) includes **1MB flash, 192KB RAM**, GPIO, ADC/DAC, accelerometer, RTC, and USB/SD card support, with MicroPython’s `machine` module enabling low-level hardware control.

- **Robust Design**: Features **99.2% core code coverage**, **150µs boot-to-script time**, **mark-sweep garbage collection**, **64-bit NaN boxing**, **cross-compilation**, and **inline assembly** (Thumb/Xtensa), with full MIT-licensed open-source availability.
