# Quickstart | Milvus Documentation

## Summary

- **Milvus Lite**: Lightweight, embeddable Python library (`pymilvus`) enabling local vector database operations with minimal setup, storing data in a single file (e.g., `milvus_demo.db`), ideal for prototyping or small-scale AI applications.

- **Vector Search & Metadata Filtering**: Supports high-dimensional vector similarity search (e.g., COSINE distance) with optional scalar field filtering (e.g., `subject == 'biology'`) for hybrid queries, optimizing precision in AI-driven semantic search tasks.

- **Deployment Flexibility**: Offers seamless transition paths between Milvus Lite (local), Docker (standalone), and Kubernetes (scalable), with identical APIs across modes, ensuring consistency for production-grade deployments.
