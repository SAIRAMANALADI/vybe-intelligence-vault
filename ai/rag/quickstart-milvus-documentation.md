# Quickstart | Milvus Documentation

## Summary

- **Milvus Lite**: Lightweight, embeddable vector database (`pymilvus`) for local Python applications, storing data in a single file (e.g., `milvus_demo.db`), enabling quick setup without Docker/Kubernetes.

- **Vector Search & Metadata Filtering**: Supports semantic search via vector embeddings (e.g., cosine similarity) and scalar field filtering (e.g., `subject == 'biology'`) for hybrid queries, with optional indexing for performance optimization.

- **Multi-Mode Deployment**: Offers local (Lite), Docker, and Kubernetes deployments; client code remains consistent across modes, with migration tools available for transitioning data from Lite to production environments.
