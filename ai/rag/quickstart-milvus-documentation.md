# Quickstart | Milvus Documentation

## Summary

- **Milvus Lite**: A lightweight, embeddable Python library (`pymilvus`) enabling local vector database operations with minimal setup, storing data in a single file (e.g., `milvus_demo.db`), ideal for prototyping or small-scale AI applications.
- **Vector Search & Metadata Filtering**: Supports semantic search via vector embeddings (e.g., cosine similarity) and scalar field filtering (e.g., `subject == 'biology'`) for precise data retrieval, with optional indexing for performance optimization in large datasets.
- **Deployment Flexibility**: Offers multiple deployment modes (Lite, Docker, Kubernetes) with a unified API, allowing seamless migration from local testing to production-scale vector databases while maintaining consistent client-side code.
