# Systolic array - Wikipedia

## Summary

- **Parallel architecture**: Systolic arrays are tightly coupled networks of identical data processing units (DPUs) where each node computes partial results from upstream inputs, stores them, and forwards results downstream, enabling massively parallel computations (e.g., matrix multiplication, convolution) without external memory access during operations.

- **Synchronous data flow**: Nodes operate synchronously, triggered by incoming data streams, contrasting with Von Neumann architectures; data counters replace program counters, enabling data-driven parallelism and eliminating sequential bottlenecks (e.g., Amdahl’s Law limitations).

- **Classification ambiguity**: Officially labeled MISD under Flynn’s taxonomy, systolic arrays defy strict categorization—SIMD (independent inputs), MIMD (merged data streams), and SISD (single data) classifications fail due to dynamic data transformation and vectorized inputs, making their taxonomy contentious.
