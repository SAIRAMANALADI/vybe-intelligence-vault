# Built-in AI | AI on Chrome | Chrome for Developers

## Summary

- **Built-in AI in Chrome**: Chrome integrates **Gemini Nano** as a browser-managed foundation model, enabling web apps to perform AI tasks via dedicated APIs (e.g., summarization, translation, rewriting) without external dependencies.
- **Key APIs & Polyfills**: Chrome provides APIs like **Proofreader, Writer, Rewriter, Translator, Language Detector, Summarizer, and Prompt API**, with polyfills (e.g., `Prompt API polyfill`) for cross-browser compatibility and hybrid cloud/on-device workflows (e.g., Firebase AI Logic).
- **Best Practices & Debugging**: Chrome supports **model caching, streaming LLM responses, and session management** (e.g., compacting via Summarizer API), while offering tools like **debugging pages for Gemini Nano prompts** and guidance on model download UX and lifecycle management.
