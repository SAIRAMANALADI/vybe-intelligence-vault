# Built-in AI | AI on Chrome | Chrome for Developers

## Summary

- **Built-in AI APIs**: Chrome provides browser-managed AI models (e.g., Gemini Nano) via APIs for tasks like text summarization, translation, proofreading, and language detection, enabling client-side AI inference without external dependencies.
- **Hybrid AI Workloads**: Supports hybrid approaches combining on-device AI (via APIs like `Prompt`, `Writer`, `Rewriter`) with cloud fallbacks (e.g., Firebase AI Logic) for scalability and reliability.
- **Performance & UX Optimization**: Chrome offers best practices for caching models, streaming LLM responses, and managing model lifecycle (downloads, updates, user notifications) to ensure efficient, user-friendly AI integrations.
