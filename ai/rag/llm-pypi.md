# llm · PyPI

## Summary

- **Purpose & Scope**: CLI utility and Python library (`llm 0.31.1`) enabling interaction with LLMs (OpenAI, Anthropic, Gemini, Meta Llama) via APIs or local execution, supporting structured data extraction, embeddings, and tool integration.

- **Technical Requirements**: Python ≥3.10; Apache-2.0 license; supports plugins (e.g., `llm-ollama`, `llm-gemini`) for extended functionality (e.g., local model execution, embeddings).

- **Core Features**: CLI commands (`llm "prompt"`, `llm chat`), SQLite logging, schema-based structured output, multi-modal input (text/images), and tool execution for model-agent interactions.
