# TiTiler

## Summary

- **Dynamic Tiling Framework**: Built on FastAPI and GDAL/Rasterio, TiTiler provides a modular Python-based framework for generating dynamic web tiles from geospatial datasets (COG, STAC, Zarr/NetCDF, MosaicJSON).

- **Multi-Format & Projection Support**: Supports JPEG/JP2/PNG/WEBP/GTIFF/NumpyTile output formats, multiple projections via `morecantile` (TileMatrixSets), and OGC-compliant WMTS/Tiles API endpoints.

- **Modular Architecture**: Split into namespace packages (`titiler.core`, `titiler.xarray`, `titiler.mosaic`, etc.), enabling extensible tiling for COG, STAC, Zarr, and MosaicJSON with Docker/K8s deployment options.
