# Pandoc - index

## Summary

- **Universal document converter**: Pandoc supports **bidirectional conversion** between 40+ formats, including Markdown, LaTeX, HTML, EPUB, Word (docx), PowerPoint, and PDF (via LaTeX/other engines), with additional support for niche formats like JATS, Typst, and MediaWiki markup.

- **Advanced markup & automation**: Supports **LaTeX math, citations, and bibliography generation** (BibTeX, CSL JSON/YAML) with 1000+ citation styles, alongside **Markdown extensions** (tables, footnotes, syntax-highlighted code blocks, smart typography) and **custom Lua-based readers/writers**.

- **Modular architecture**: Written in Haskell, Pandoc provides a **library with format-specific modules** for extensibility, a **CLI tool**, and **customization via templates/filters**, with all features under the GPL license (2006–2025, John MacFarlane).
