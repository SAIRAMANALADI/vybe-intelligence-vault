# Pandoc - index

## Summary

- **Universal document converter**: Pandoc supports bidirectional conversion between 30+ markup, document, and data formats, including Markdown (CommonMark/GitHub-flavored), LaTeX, HTML5, EPUB, Word (docx), Jupyter notebooks (ipynb), and PDF (via LaTeX/XeLaTeX or external tools like `wkhtmltopdf`).

- **Advanced features**: Supports LaTeX math, automatic citations/bibliographies (BibTeX/BibLaTeX/CSL), syntax-highlighted code blocks, and custom Lua-based readers/writers for proprietary formats.

- **Architecture**: Implemented as a Haskell library with a CLI, modular by format, and extensible via templates/filters; licensed under GPLv2.
