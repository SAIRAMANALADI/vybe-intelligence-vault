# Pandoc - index

## Summary

- **Universal document converter** supporting bidirectional conversion between 30+ markup, markup-like, and word processor formats (e.g., Markdown ↔ LaTeX ↔ EPUB ↔ docx ↔ Jupyter notebooks) via a modular Haskell library and CLI.

- **Advanced markup extensions** including metadata, footnotes, tables, LaTeX math (with MathJAX/MathML rendering), smart typography, and syntax-highlighted code blocks, with optional strict Markdown compatibility.

- **Automated citations & bibliography system** via CSL styles, supporting BibTeX/BibLaTeX/CSL JSON/YAML inputs, with cross-format citation rendering and dynamic bibliography generation.
