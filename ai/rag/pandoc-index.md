# Pandoc - index

## Summary

- **Broad Format Conversion**: Pandoc supports bidirectional conversion between 40+ markup, document, and data formats, including Markdown, LaTeX, HTML, EPUB, Word (docx), Jupyter notebooks, and custom Lua-based readers/writers.

- **Advanced Markdown Features**: Supports extensions like metadata, footnotes, tables, syntax-highlighted code blocks, LaTeX math (rendered via MathJax/MathML/Unicode), and automatic citations/bibliographies with CSL styles.

- **Extensible Architecture**: Modular Haskell library with CLI interface; supports custom filters, templates, and PDF generation via multiple backends (e.g., `pdflatex`, `wkhtmltopdf`, `weasyprint`).
