# Pandoc - index

## Summary

- **Universal document converter**: Pandoc supports bidirectional conversion between 40+ markup formats (Markdown, LaTeX, HTML, EPUB, DocBook, etc.), including lightweight markup (CommonMark, reStructuredText), word processors (docx, ODT), slide shows (PowerPoint, reveal.js), and ebook formats (EPUB 2/3).

- **Advanced features**: Supports LaTeX math rendering (via MathJax/MathML), automatic citations/bibliographies (CSL styles), and custom Lua-based readers/writers for extensibility.

- **Multi-format toolchain**: Includes a Haskell library and CLI tool with modular format support; PDF output via multiple backends (LaTeX, wkhtmltopdf, WeasyPrint, etc.).
