# RAG Techniques, Beginner to Advanced: Practical Patterns, Code, and Resources | martinuke0's Blog

## Summary

- **Minimal RAG Pipeline**: Combines dense embeddings (sentence-transformers), vector search (FAISS), and an LLM (Flan-T5) for retrieval-augmented generation, with optional sparse retrieval (BM25) for hybrid setups.

- **Core RAG Components**: Retriever (dense/sparse), generator (LLM), embeddings (normalized vectors), chunking (400–1000 tokens with overlap), and reranking (cross-encoder models like monoT5/bge-reranker) for precision optimization.

- **Advanced Techniques**: Multi-hop retrieval, GraphRAG (knowledge graphs), hybrid retrieval (sparse + dense), query expansion (HyDE/multi-query), and context compression for latency/cost efficiency in production systems.
