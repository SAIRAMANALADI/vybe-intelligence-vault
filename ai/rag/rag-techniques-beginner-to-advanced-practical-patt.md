# RAG Techniques, Beginner to Advanced: Practical Patterns, Code, and Resources | martinuke0's Blog

## Summary

- **Minimal RAG Pipeline**: Combines dense embeddings (sentence-transformers), FAISS for vector search, and a seq2seq LLM (e.g., Flan-T5) for generation; supports optional sparse retrieval (BM25) for hybrid setups.

- **Core RAG Components**: Retriever (dense/sparse), generator (LLM), embeddings (normalized vectors), chunking (400–1000 tokens with overlap), reranking (cross-encoders like monoT5), and hybrid retrieval (BM25 + vector search).

- **Advanced Techniques**: Multi-hop retrieval, GraphRAG (knowledge graphs), multi-vector retrievers, context compression, agentic RAG (tool integration), and safety mechanisms for grounded, citation-backed responses.
