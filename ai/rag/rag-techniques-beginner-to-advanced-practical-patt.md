# RAG Techniques, Beginner to Advanced: Practical Patterns, Code, and Resources | martinuke0's Blog

## Summary

- **Minimal RAG Pipeline**: Combines dense embeddings (sentence-transformers), vector search (FAISS), and an LLM (e.g., Flan-T5) for retrieval-augmented generation; supports optional sparse retrieval (BM25) for hybrid setups.

- **Core Components**: Retriever (dense/sparse), generator (LLM), embeddings (normalized vectors), chunking (400–1000 tokens with overlap), reranker (cross-encoder), and hybrid retrieval (sparse + dense fusion).

- **Advanced Techniques**: Multi-hop retrieval, GraphRAG (knowledge graphs), multi-vector retrievers, context compression, agentic RAG (tool integration), and safety grounding mechanisms for production-grade RAG systems.
