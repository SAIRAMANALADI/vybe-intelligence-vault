# Terraform | HashiCorp Developer

## Summary

- **Terraform Overview**: Infrastructure as Code (IaC) tool enabling safe, efficient building, changing, and versioning of infrastructure across low-level (compute, storage, networking) and high-level (DNS, SaaS) components.

- **Key Features**: Supports multi-cloud provisioning (AWS, Azure, GCP, etc.), collaborative workflows via HCP Terraform, and integrates with tools like Packer for golden image pipelines and GitHub Actions for CI/CD-driven environments.

- **Certifications & Resources**: Offers structured tutorials for Terraform Associate (004) and Professional certifications, alongside best practices guides (style conventions, adoption phases) and hands-on sandboxes for experimentation.
