# Getting Started with Roboflow

## Summary

- **Roboflow MCP Server** enables AI coding agents (e.g., Claude Code, Cursor) to automate computer vision workflows via a single hosted endpoint (`mcp.roboflow.com`) without SDK installation, supporting dataset creation, training, deployment, and integration with 250K+ pre-trained models from Roboflow Universe.

- **Traditional Model Builder** follows a manual pipeline: dataset upload (COCO JSON, 40+ formats), annotation (bounding boxes/polygons via Roboflow Annotate), preprocessing/augmentation, train-test-validation splits (customizable), and model training/evaluation for object detection use cases.

- **Deployment Options**: Models can be deployed via hosted API or on-device using **Roboflow Inference**, with post-training workflow assembly for production pipelines; Roboflow Label Assist (AI-assisted labeling) and Smart Polygon tools optimize annotation efficiency.
