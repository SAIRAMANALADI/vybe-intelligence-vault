# Learning Tools Interoperability | 1EdTech

## Summary

- **LTI 1.3** introduces OAuth2 and JSON Web Tokens (JWT) via the 1EdTech Security Framework, replacing legacy OAuth1-based authentication for improved security in LMS-tool integration.
- **LTI Advantage** extends LTI 1.3 with three core services: **Assignment and Grade Services (AGS)** for gradebook integration, **Names and Role Provisioning Services (NRPS)** for role-based access control, and **Deep Linking (DL)** for embedding external content directly into LMS workflows.
- **Certification & Diagnostics** are enforced via [BUILD.1EDTECH.ORG](http://build.1edtech.org) and the **LTI Advantage Certification Suite**, ensuring compliance with interoperability standards for secure, scalable deployments.
