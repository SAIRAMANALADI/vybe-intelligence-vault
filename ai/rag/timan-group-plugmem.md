# TIMAN-group/PlugMem

## Summary

- **Plug-and-play long-term memory integration**: Enables LLM agents to dynamically store, retrieve, and utilize long-term contextual memory via a modular architecture, enhancing agent coherence and task performance over extended interactions.

- **Memory retrieval optimization**: Implements advanced retrieval-augmented generation (RAG) techniques with dynamic memory pruning and hierarchical indexing to balance relevance and computational efficiency in long-term memory access.

- **Agent-memory interaction framework**: Provides a Python-based API for seamless integration of memory modules into LLM agent pipelines, supporting customizable memory policies and real-time updates for adaptive agent behavior.
