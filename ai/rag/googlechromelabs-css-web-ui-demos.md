# css-web-ui-demos/html-in-canvas/awesome-html-in-canvas.md at main · GoogleChromeLabs/css-web-ui-demos · GitHub

## Summary

- **HTML-in-Canvas** enables rendering interactive HTML content within `<canvas>` elements via the [HTML-in-Canvas API](https://developer.chrome.com/blog/html-in-canvas), leveraging WebGL/WebGPU for GPU acceleration.
- **Framework Integration**: Libraries like Three.js, PlayCanvas, and PixiJS support HTML-in-Canvas via `HTMLTexture`/`HTMLSource` for embedding DOM elements in 2D/3D scenes (e.g., [Three.js HTMLTexture](https://goo.gle/HIC-threejs)).
- **Ecosystem Demos**: Third-party examples include interactive forms (e.g., [Duck Hunt TODO](https://x.com/wesbos/status/2041594973674483851)), shader-driven transitions ([Compiz Web](https://compiz-web.vercel.app/)), and physics-based UI ([HTML cloth](https://arrival.space/htmlcanvas)).
