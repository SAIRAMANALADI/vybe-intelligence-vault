# Discover AWS Official Knowledge Center Articles | AWS re:Post

## Summary

- **S3 Replication Issues**: Common causes for S3 object replication failures include missing IAM permissions, misconfigured bucket policies, or incorrect replication configuration settings (e.g., missing `replication configuration` XML or incorrect `Role` ARN).

- **EC2 Connection Failures**: SSH/Session Manager connection issues often stem from misconfigured security groups, missing IAM roles for SSM, or incorrect key pair associations (e.g., `ec2-instance-connect` or `ssm:StartSession` permissions).

- **WAF Rate-Based Rule Misconfiguration**: AWS WAF rate-based rules may fail to block traffic due to incorrect threshold values, improper scope (e.g., regional vs. global), or misconfigured custom aggregation keys (e.g., `IP` vs. `HTTP header` matching).
