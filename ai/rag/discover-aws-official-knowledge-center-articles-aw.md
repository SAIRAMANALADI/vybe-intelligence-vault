# Discover AWS Official Knowledge Center Articles | AWS re:Post

## Summary

- **S3 Replication Failures**: Verify S3 bucket replication configuration includes correct IAM roles, destination bucket permissions, and replication rules; check CloudTrail logs for `ReplicationTimeControl` and `ReplicationStatus` events to diagnose misconfigurations or missing permissions.

- **EC2 SSH Connection Errors**: Resolve "Connection refused" or "Permission denied" errors by validating security group rules (TCP 22), NACL configurations, instance OS-level SSH daemon status (`sshd`), and key pair associations; use Session Manager as an alternative if SSH fails.

- **Lambda Deployment Size Limits**: Address deployment package size errors by optimizing dependencies, using Lambda Layers, or splitting functions; ensure deployment package (ZIP) adheres to AWS Lambda’s 50MB (direct upload) or 250MB (via S3) limits.
