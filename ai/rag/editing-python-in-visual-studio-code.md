# Editing Python in Visual Studio Code

## Summary

- **IntelliSense & Autocomplete**: VS Code's Python extension leverages [Pylance](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-pylance) (based on [Pyright](https://github.com/microsoft/pyright)) for static type checking and lazy type inferencing, providing AI-enhanced completions via [IntelliCode](https://go.microsoft.com/fwlink/?linkid=2006060). Features include auto-import suggestions (`python.analysis.autoImportCompletions`) and custom path resolution (`python.analysis.extraPaths`).

- **Code Navigation & Refactoring**: Supports advanced navigation (e.g., "Go to Definition," "Peek Definition") and refactoring tools (e.g., symbol renaming, extract method) with configurable settings for performance tuning (e.g., `python.analysis.typeCheckingMode`).

- **Debugging & Tooling Integration**: Provides built-in debugging (launch configurations, breakpoints), linting/formatting (via `pylint`, `autopep8`, `black`), and environment management (e.g., `python.analysis.extraPaths`, `python.testing.pytestEnabled`). Supports Jupyter notebooks (`python.jupyter.executeInKernel`) and containerized workflows.
