# Editing Python in Visual Studio Code

## Summary

- **IntelliSense & Autocomplete**: VS Code's Python extension leverages **Pylance** (based on Pyright) for static type checking and lazy type inference, providing high-performance IntelliSense with `.pyi` stub support. Auto-imports can be enabled via `python.analysis.autoImportCompletions` for seamless module imports.

- **Custom Analysis Paths**: IntelliSense can be extended to non-standard package locations using `python.analysis.extraPaths` in `settings.json`, enabling type checking for custom environments (e.g., Google App Engine paths).

- **AI-Augmented Completions**: **IntelliCode** integrates AI-driven contextual autocompletions, optimizing suggestions based on code context, while general IntelliSense behavior can be fine-tuned via Python extension settings for performance vs. feature trade-offs.
