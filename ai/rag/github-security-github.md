# GitHub Security · GitHub

## Summary

- **GitHub Advanced Security (GHAS)** integrates static analysis, AI-driven remediation, and vulnerability management directly into developer workflows to address security debt proactively.

- **Secret Protection** blocks accidental secret exposure in commits via push protection, while **Code Security** leverages static analysis (e.g., CodeQL) and AI suggestions to detect and fix vulnerabilities (e.g., XSS, SSRF) in real time.

- **Supply Chain Security** mitigates open-source risks through dependency tracking, automated updates, and build attestation, supported by the **GitHub Security Lab** and **Security Advisory Database** for CVE and advisory coverage.
