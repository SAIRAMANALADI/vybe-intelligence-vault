# Robustness testing pipeline for NLP with Microsoft CheckList | by AI Singapore | AI Singapore TechBytes | Medium

## Summary

- **CheckList Methodology**: A black-box NLP robustness testing framework from Microsoft, evaluating models via **Minimum Function Tests (MFT)**, **Invariance (INV)**, and **Directional Expectation (DIR)** tests to assess specific linguistic capabilities rather than aggregate metrics.

- **Pipeline Integration**: Implemented as a **DVC-based CI/CD pipeline** (GitLab) with automated reporting via **CML**, enabling versioned test artifacts, incremental execution, and Git-embedded result visualization in merge requests.

- **Deployment & Analysis**: Containerized **Voila-based interactive dashboards** deployed on Kubernetes for post-run result exploration, providing detailed test failure analysis and perturbed input examples for model improvement.
