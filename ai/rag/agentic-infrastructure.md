# Agentic Infrastructure - Vercel

## Summary

- **Agentic Infrastructure**: Enables autonomous deployment of apps and agents via Vercel's API, CLI, MCP, and Skills, leveraging sandboxed VMs with durable backends and multi-model support for automated error handling, planning, and PR generation.

- **Scalable Deployment Features**: Supports zero-to-millions scaling with global delivery, serverless functions, and WAF integration, demonstrated by platforms like Zapier handling 100M+ monthly visits.

- **Multi-Tenant Platform Hosting**: Provides tenant isolation, domain management, custom SSL, and preview URLs, as used by Mintlify for 20K+ companies' documentation, alongside frameworks like **Eve** for durable agent development and **Passport** for identity-secured deployments.
