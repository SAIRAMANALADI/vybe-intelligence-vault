# How to Create and Manage API Keys - Affinity Help Center

## Summary

- **API Key Lifecycle Management**: Process includes creation (with mandatory name/description), secure secret storage (single-display), and immediate revocation with audit trail visibility in Manage Apps interface.

- **Permission & Security Constraints**: Requires "Generate API Key" or "Manage All API Keys" permissions; enforces single active key per user until M4 release; auto-revokes keys for deactivated users.

- **Best Practices for Operational Hygiene**: Enforces quarterly key reviews, 90-day inactivity-based revocation, structured naming conventions, and detailed descriptions (purpose, owner, systems, frequency) for traceability and compliance.
