# Hugging Face integrations - Docs by LangChain

## Summary

- **Chat Models**: `ChatHuggingFace` class enables direct integration with Hugging Face chat models via LangChain, supporting both Hugging Face LLM classes and direct usage.

- **LLMs**: `HuggingFaceEndpoint` runs open-source models via serverless Inference Providers or dedicated Inference Endpoints, while `HuggingFacePipeline` executes models locally using the `transformers` library.

- **Embedding Models**: Supports local (`HuggingFaceEmbeddings`), endpoint-based (`HuggingFaceEndpointEmbeddings`), and self-hosted TEI deployments for Sentence Transformers, with BGE models requiring `normalize_embeddings=True` for optimal performance.
