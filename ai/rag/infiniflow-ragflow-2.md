# infiniflow/ragflow

## Summary

- **Hybrid RAG-Plus-Agent Architecture**: RAGFlow integrates advanced Retrieval-Augmented Generation (RAG) with autonomous agent capabilities, enabling dynamic context engineering for LLMs by combining structured retrieval with agentic workflows for superior contextual grounding.

- **Multi-Stage Context Optimization**: Implements a layered context management pipeline (document parsing, chunking, indexing, and retrieval) with adaptive reranking and agent-driven query refinement to enhance LLM response accuracy and relevance.

- **Scalable, Go-Based Implementation**: Built in Go for high-performance parallel processing, supporting distributed retrieval, real-time agent orchestration, and extensible plugin architecture for custom knowledge compilation and retrieval strategies.
