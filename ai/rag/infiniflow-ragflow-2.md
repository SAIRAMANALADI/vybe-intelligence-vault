# infiniflow/ragflow

## Summary

- **Hybrid RAG-Agent Architecture**: RAGFlow integrates advanced Retrieval-Augmented Generation (RAG) with agentic workflows to enhance LLM context handling via dynamic retrieval, reasoning, and tool-use capabilities.

- **Multi-Modal Context Engine**: Supports structured/unstructured data ingestion (PDFs, docs, web) with adaptive chunking, semantic indexing, and agent-driven query refinement for optimized LLM prompt construction.

- **Scalable Go-Based Implementation**: Built in Go for high-performance parallel processing, with modular pipelines for document parsing, vector search (via FAISS/Annoy), and agent orchestration (e.g., ReAct-style decision loops).
