# infiniflow/ragflow

## Summary

- **Hybrid RAG-Plus-Agent Architecture**: RAGFlow integrates advanced Retrieval-Augmented Generation (RAG) with agentic workflows to dynamically optimize context retrieval and LLM interaction, enhancing factual grounding and adaptive reasoning.

- **Multi-Modal Context Engine**: Supports structured/unstructured data (PDFs, docs, images) with built-in OCR, chunking, and semantic indexing, enabling unified knowledge compilation for heterogeneous inputs.

- **Scalable Go-Based Deployment**: Optimized for high-throughput production environments with modular design, supporting distributed retrieval, caching, and real-time context updates via REST/gRPC APIs.
