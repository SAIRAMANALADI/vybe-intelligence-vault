# infiniflow/ragflow

## Summary

- **Hybrid RAG-Agent Architecture**: RAGFlow integrates advanced Retrieval-Augmented Generation (RAG) with Agent-based workflows, enabling dynamic context engineering for LLMs by combining retrieval mechanisms with autonomous agent capabilities for superior contextual grounding.

- **Multi-Modal Context Engine**: Supports structured/unstructured data processing (e.g., PDFs, tables, images) via a modular pipeline, leveraging context engineering techniques to optimize LLM input quality and retrieval precision.

- **Scalable Go-Based Implementation**: Built in Go for high-performance parallel processing, with modular components for knowledge compilation, retrieval, and agent orchestration, facilitating deployment in large-scale production environments.
