# infiniflow/ragflow

## Summary

- **Hybrid RAG-Plus-Agent Architecture**: RAGFlow integrates advanced Retrieval-Augmented Generation (RAG) with autonomous agent capabilities, enabling dynamic context engineering for LLMs by combining retrieval-based augmentation with agent-driven reasoning and tool interaction.

- **Multi-Stage Context Optimization**: The system employs a layered context management pipeline, including knowledge compilation, retrieval refinement, and agentic search, to dynamically curate and structure context for superior LLM performance in complex, multi-turn interactions.

- **Scalable, Go-Based Implementation**: Built in Go for high-performance concurrency and efficiency, RAGFlow supports distributed deployment, modular plugin integration (e.g., custom retrievers, agents), and extensible APIs for enterprise-grade RAG applications.
