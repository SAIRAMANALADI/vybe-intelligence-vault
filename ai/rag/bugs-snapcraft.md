# Bugs : Snapcraft

## Summary

- **Critical Bug #1921397**: Snapcraft fails to build snaps when the Snap Store is unavailable, causing complete build failure due to dependency on external store services.

- **High Bug #1615242**: The `etcd` tree plugin causes excessive resource usage in Snapcraft, leading to system instability during snap packaging.

- **High Bug #1663002**: The `organize` and `stage` keywords in `snapcraft.yaml` incorrectly handle file conflict detection, resulting in improper file staging and potential snap corruption.
