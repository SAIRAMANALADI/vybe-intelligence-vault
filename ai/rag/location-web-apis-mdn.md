# Location - Web APIs | MDN

## Summary

- The `Location` interface represents the URL of a document or window, with changes reflected in the associated object; accessible via `Document.location` or `Window.location`.
- Key properties include `href`, `protocol`, `host`, `hostname`, `port`, `pathname`, `search`, `hash`, and `origin`, enabling URL manipulation and inspection.
- Methods such as `assign()`, `reload()`, `replace()`, and `toString()` provide navigation and URL string retrieval functionality, with `replace()` omitting history entry creation.
