# Claude Code Plugin - Pinecone Docs

## Summary

- **Integration & Features**: Official Pinecone plugin for Claude Code enabling vector search, RAG workflows, and MCP server integration with slash commands (`/pinecone:query`, `/pinecone:assistant`) and natural language index management.
- **Prerequisites & Setup**: Requires Pinecone API key, Node.js (with `npx` in `PATH`), `uv` for assistant commands, and optional Pinecone CLI; installation involves exporting `PINECONE_API_KEY` and running `claude plugin install pinecone`.
- **MCP Tools & Skills**: Provides MCP server tools (e.g., `list-indexes`, `search-records`, `cascading-search`) and skills (e.g., `/pinecone:quickstart`, `/pinecone:full-text-search`) for index operations, semantic search, and assistant creation.
