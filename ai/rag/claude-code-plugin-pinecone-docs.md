# Claude Code Plugin - Pinecone Docs

## Summary

- **Plugin Integration**: Official Pinecone plugin for Claude Code enabling vector search, RAG, and MCP server integration for direct Pinecone operations via natural language commands and slash commands (`/pinecone:*`).

- **MCP Tools**: Provides tools like `search-docs`, `list-indexes`, `describe-index`, `upsert-records`, `search-records`, and `cascading-search` for managing indexes, querying data, and performing advanced operations.

- **Prerequisites & Setup**: Requires Pinecone API key, Node.js (with `npx` in `PATH`), `uv` for assistant commands, and Pinecone CLI (optional). Installation involves setting API key, installing plugin (`claude plugin install pinecone`), and restarting Claude Code.
