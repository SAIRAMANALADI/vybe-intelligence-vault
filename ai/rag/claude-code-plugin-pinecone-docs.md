# Claude Code Plugin - Pinecone Docs

## Summary

- **Integration & Features**: Official Pinecone plugin for Claude Code enabling vector search, RAG, and AI workloads via MCP server, slash commands (`/pinecone:query`, `/pinecone:assistant`), and natural language index/query operations.
- **Prerequisites & Setup**: Requires Pinecone API key, Node.js (`npx` in `PATH`), `uv` for assistant commands, and optional Pinecone CLI; installation involves exporting `PINECONE_API_KEY`, installing via `claude plugin install pinecone`, and restarting Claude Code.
- **MCP Tools & Skills**: Provides MCP tools (`search-docs`, `list-indexes`, `upsert-records`, `cascading-search`) and skills (`/pinecone:quickstart`, `/pinecone:full-text-search`, `/pinecone:n8n`) for index management, semantic/full-text search, and workflow automation.
