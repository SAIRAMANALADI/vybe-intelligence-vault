# Claude Code Plugin - Pinecone Docs

## Summary

- **Integration & Features**: Pinecone plugin for Claude Code enables vector search, RAG, and AI workloads via MCP server, slash commands (`/pinecone:*`), and natural language-driven index management, semantic/full-text search, and assistant creation.
- **MCP Tools**: Provides tools like `search-docs`, `list-indexes`, `upsert-records`, `search-records`, `cascading-search`, and `rerank-documents` for direct Pinecone operations and metadata filtering.
- **Prerequisites & Setup**: Requires Pinecone API key, Node.js (`npx` in `PATH`), `uv`, and optional Pinecone CLI; installed via `claude plugin install pinecone` and activated after restarting Claude Code.
