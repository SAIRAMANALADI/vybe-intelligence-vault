# vespa-engine/vespa

## Summary

- **Vespa** is an AI-driven search platform and vector database, enabling real-time vector search, machine learning model serving, and recommendation systems with low-latency tensor operations.
- **Core architecture** is built in Java, supporting hybrid search (lexical, semantic, and vector-based) with a scalable, distributed server design for handling big data workloads.
- **Key features** include native tensor support, RAG (Retrieval-Augmented Generation) integration, and optimized vector search for high-dimensional data, with last updated performance enhancements in 2026.
