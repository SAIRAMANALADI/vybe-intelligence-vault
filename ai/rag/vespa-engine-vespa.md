# vespa-engine/vespa

## Summary

- **Vespa** is an AI-driven search platform and vector database implemented in Java, supporting **real-time vector search**, **machine learning**, and **retrieval-augmented generation (RAG)** workflows.
- Features **tensor-based computations**, **horizontal scalability**, and **low-latency serving** for applications like recommendation systems and large-scale search engines.
- Supports **hybrid search** (combining lexical and vector search), **structured data indexing**, and **dynamic model updates** with a distributed architecture.
