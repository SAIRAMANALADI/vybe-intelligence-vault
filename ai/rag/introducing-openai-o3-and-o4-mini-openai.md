# Introducing OpenAI o3 and o4-mini | OpenAI

## Summary

- **Scaled RL and Tool Integration**: OpenAI o3 and o4-mini leverage scaled reinforcement learning (RL) with tool-use training, achieving >20% reduction in major errors vs. o1 on complex tasks; o3 demonstrates SOTA performance on Codeforces, SWE-bench, and MMMU, while o4-mini excels in math (99.5% AIME 2025 pass@1 with Python interpreter).

- **Multimodal Reasoning**: Models now "think with images," integrating visual inputs (e.g., diagrams, whiteboards) into chain-of-thought reasoning via multimodal RL, enabling state-of-the-art visual perception and dynamic image manipulation (e.g., rotation, transformation) for complex problem-solving.

- **Agentic Workflows**: Both models autonomously chain tools (web search, Python execution, image generation) to solve multi-step queries (e.g., forecasting energy usage) in <1 minute, adapting dynamically to intermediate results and leveraging memory for personalized, conversational outputs.
