# containerd – An industry-standard container runtime with an emphasis on simplicity, robustness and portability

## Summary

- **OCI-Compliant Container Runtime**: Implements OCI Image and Runtime Specs, managing full container lifecycle (image handling, execution, supervision) via runC integration, with support for multi-tenant CAS storage and network namespace management.

- **Cross-Platform Daemon**: Available as a Linux/Windows daemon, providing low-level storage, networking, and container lifecycle operations while supporting OCI-compliant image push/pull and network interface primitives.

- **CNCF-Graduated Project**: Officially graduated under CNCF (since 2019), adopted by major platforms (e.g., Docker, Kubernetes, AWS Fargate/ECS, Azure AKS) and integrated into ecosystems like Cloud Foundry, Firecracker, and Kata Containers.
