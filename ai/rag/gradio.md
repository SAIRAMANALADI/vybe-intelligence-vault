# Gradio

## Summary

- **Gradio 6** introduces enhanced UI components, improved performance, and new deployment options, including native support for **Model Context Protocol (MCP)** integration and **Hugging Face Spaces** hosting.

- **40+ pre-built components** (e.g., `ImageSlider`, `AnnotatedImage`, `Chatbot`, `Model3D`) enable rapid prototyping of ML/web apps with **zero frontend (JS/CSS) expertise**, supporting **audio, video, 3D, dataframes, and more**.

- **One-line deployment** via `demo.launch(share=True)` for instant sharing or **Hugging Face Spaces** for scalable, permanent hosting with auto-scaling and CI/CD integration.
