# Gradio

## Summary

- **Gradio 6** introduces rapid ML app development with **40+ pre-built components** (e.g., `ImageSlider`, `AnnotatedImage`, `Chatbot`) for inputs/outputs like audio, video, 3D models, and dataframes, eliminating frontend dependencies.

- **Zero-config deployment** via `demo.launch(share=True)` generates public URLs instantly, while **Hugging Face Spaces** offers permanent, auto-scaled hosting with one-click deployment.

- **Python-native workflow** (`pip install gradio`) abstracts JavaScript/CSS, enabling **prototyping to production** in minutes (e.g., `gr.Interface(fn=greet, inputs="text", outputs="text")`).
