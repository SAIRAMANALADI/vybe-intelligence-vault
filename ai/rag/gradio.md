# Gradio

## Summary

- **Gradio 6.0** introduces rapid ML app development with **40+ pre-built components** (e.g., `ImageSlider`, `AnnotatedImage`, `Chatbot`) for handling diverse data types (images, audio, video, 3D, dataframes) via Python, eliminating frontend (JS/CSS) requirements.

- **Deployment & Scalability**: Supports **permanent hosting** on Hugging Face Spaces (auto-scaling, always-online) and **instant sharing** via public URLs (`demo.launch(share=True)`), enabling real-time AI trials and client demos.

- **Performance & Integration**: Optimized for **low-latency prototyping** (single-command install, minimal Python code) and **Javascript client** support, facilitating hybrid Python/HTML frontends for advanced UIs.
