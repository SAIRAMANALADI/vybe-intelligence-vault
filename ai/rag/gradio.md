# Gradio

## Summary

- **Gradio 6** introduces enhanced UI components, improved performance, and new deployment options, including **permanent hosting on Hugging Face Spaces** with auto-scaling and persistent URLs.

- **40+ pre-built components** support multi-modal data (Images, Audio, Video, 3D, Dataframes, JSON) with minimal Python code, eliminating frontend (JS/CSS) requirements.

- **Instant sharing** via `demo.launch(share=True)` generates public links for local demos, while **HF Spaces integration** enables scalable, production-ready deployments with one-click hosting.
