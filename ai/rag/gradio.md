# Gradio

## Summary

- **Gradio 6 Release**: Introduces new features and improvements for building and deploying ML web interfaces with enhanced performance and expanded component library (40+ input/output types including 3D, audio, video, and annotated images).

- **Rapid Prototyping & Deployment**: Enables zero-JS/CSS frontend development with one-command installation (`pip install gradio`) and instant local/remote sharing via `demo.launch(share=True)` or Hugging Face Spaces integration.

- **Extensible UI Components**: Supports dynamic, production-ready UIs with built-in components (e.g., `Chatbot`, `AnnotatedImage`, `FileExplorer`) and seamless integration with Python ML pipelines, demonstrated by real-world use cases like clinical AI trials and LLM interfaces.
