# Gradio

## Summary

- **Gradio 6** introduces new features and improvements, including enhanced component support and streamlined deployment workflows, as detailed in the [official documentation](https://gradio.app/docs/gradio).

- **MCP Birthday Hackathon Winners** showcased innovative applications built with Gradio, demonstrating its versatility in rapid ML prototyping and deployment, with winners listed [here](https://gradio.app/mcp-birthday-winners).

- **Gradio’s core functionality** enables Python-based ML app development with 40+ pre-built components (e.g., `ImageSlider`, `Chatbot`, `AnnotatedImage`) for inputs/outputs like images, audio, and 3D models, deployable via `demo.launch(share=True)` or Hugging Face Spaces.
