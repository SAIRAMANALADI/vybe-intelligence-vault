# Reranker API

## Summary

- **Architecture**: Jina Reranker v3 introduces a novel *last but not late interaction* architecture with 0.6B parameters, optimizing multilingual document reranking via sub-document/sub-query granularity.

- **Capabilities**: Supports multilingual retrieval (100+ languages), function-calling, code search, and structured data (e.g., tables) with a 6x speedup over v1 (v2) and SOTA performance on long documents/code tasks.

- **Deployment**: Available via API (free tier) or CSPs (AWS/Azure) with truncation (`top_n`, `truncate`) for handling token limits and dynamic document ranking.
