# GitHub recognized as a Leader by 2026 Gartner® Magic Quadrant™ for Enterprise AI Coding Agents · GitHub

## Summary

- **Gartner 2025 Magic Quadrant** positions GitHub as a **Leader** in AI Code Assistants, achieving highest ratings in both **Ability to Execute** and **Completeness of Vision**, second consecutive year.

- **GitHub Copilot integration** centralizes AI-powered development via **Agent Mode** and **GitHub Enterprise Cloud**, addressing challenges like tool sprawl and fragmented governance while enabling scalable AI adoption.

- **Gartner predicts** 90% of enterprise software engineers will use AI code assistants by **2028**, up from <14% in early 2024, underscoring GitHub’s strategic alignment with industry trends.
