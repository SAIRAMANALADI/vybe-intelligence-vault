# GitHub recognized as a Leader by 2026 Gartner® Magic Quadrant™ for Enterprise AI Coding Agents · GitHub

## Summary

- **Gartner 2025 Magic Quadrant** ranks GitHub as a **Leader** in AI Code Assistants, achieving highest marks in **Ability to Execute** and **Completeness of Vision**, alongside Amazon and Cognition (Windsurf).

- **Enterprise AI adoption forecast**: Gartner predicts **90% of enterprise software engineers** will use AI code assistants by **2028**, up from **<14% in early 2024**, driven by GitHub Copilot integration and Agent Mode capabilities.

- **GitHub’s strategic approach** centralizes development on **GitHub Enterprise Cloud**, addressing challenges like **tool sprawl** and **fragmented governance** while enabling secure, scalable AI adoption.
