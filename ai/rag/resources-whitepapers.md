# GitHub recognized as a Leader by 2026 Gartner® Magic Quadrant™ for Enterprise AI Coding Agents · GitHub

## Summary

- **Gartner 2025 Magic Quadrant** positions GitHub as a **Leader** in AI Code Assistants, achieving the highest ratings in both *Ability to Execute* and *Completeness of Vision* for the second consecutive year.
- **GitHub’s AI strategy** integrates **GitHub Copilot** into core workflows, introduces **Agent Mode**, and centralizes development on **GitHub Enterprise Cloud**, addressing challenges like tool sprawl and fragmented governance.
- **Market projection** by Gartner indicates **90% of enterprise software engineers** will use AI code assistants by **2028**, up from **<14% in early 2024**, with GitHub positioned as a key enabler for scalable AI adoption.
