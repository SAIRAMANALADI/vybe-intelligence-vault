# Deep Agents overview - Docs by LangChain

## Summary

- **Execution Environment**: Supports tools (custom functions/APIs), Model Context Protocol (MCP), virtual filesystem (pluggable backends: in-memory, disk, LangGraph store), filesystem permissions (declarative access control), sandboxed code execution (shell/JS interpreter), and streaming (typed event streams for real-time monitoring).

- **Context Management**: Integrates skills, memory, summarization, context offloading, and prompt caching for efficient long-term task handling and dynamic knowledge retrieval.

- **Delegation & Steering**: Enables task planning, subagent spawning (isolated context windows), and human-in-the-loop approval/interrupts for controlled agent behavior. Built on LangGraph runtime for durable execution and observability.
