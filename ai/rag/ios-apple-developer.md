# iOS - Apple Developer

## Summary

- **Apple Intelligence Integration**: iOS 27 introduces Apple Intelligence, leveraging next-gen Apple Foundation Models for on-device and Private Cloud Compute AI, enabling multimodal reasoning (text + images), real-time adaptive intelligence via Dynamic Profiles, and seamless app integration through App Intents for Siri/AI-driven actions.

- **Unified Platform Design & GPU Optimization**: New Liquid Glass design system ensures consistency across Apple platforms, while Metal framework enables low-overhead GPU control for visually rich games, including real-time ML inference in shaders and performance boosts via MetalFX upscaling.

- **Passkeys & Live Activities**: Passkeys replace passwords with phishing-resistant, cross-device authentication, while Live Activities provide glanceable, interactive Lock Screen/Dynamic Island updates for real-time app status (e.g., weather, sports scores) beyond traditional notifications.
