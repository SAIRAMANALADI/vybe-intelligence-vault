# Postorius - Web UI for GNU Mailman — Postorius 1.3.13 documentation

## Summary

- **Purpose & License**: Postorius is a Django-based web UI for GNU Mailman, licensed under GNU LGPL v3, enabling management of mailing lists via a web interface.
- **Technical Requirements**: Requires Python 3.9+, Django 4.2+, and GNU Mailman 3.3.10+ for compatibility and functionality.
- **Development Origin**: Initially developed by Anna Senarclens de Grancy and Benedict Stein during Google Summer of Code 2010 and 2011.
