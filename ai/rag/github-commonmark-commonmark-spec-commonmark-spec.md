# GitHub - commonmark/commonmark-spec: CommonMark spec, with reference implementations in C and JavaScript · GitHub

## Summary

- **Specification & Implementations**: CommonMark provides a standardized Markdown syntax with a [formal spec](https://spec.commonmark.org/) and BSD-licensed reference implementations in C (`cmark`) and JavaScript (`commonmark.js`), alongside third-party libraries in multiple languages.

- **Testing & Tooling**: The spec includes >500 embedded conformance tests, executable via `python3 test/spec_tests.py --program $PROG`; tools generate HTML/PDF from `spec.txt` using `lcmark` and `xelatex`.

- **Key Deviations from Original Markdown**: Allows backslash-escaping any punctuation, introduces alternative hard line break syntax (`\`), unifies link title quoting, and enforces strict list/item separation rules (e.g., bullet/number changes start new lists).
