# [2406.14497] CodeRAG-Bench: Can Retrieval Augment Code Generation?

## Summary

- **Benchmark Design**: Introduces *CodeRAG-Bench*, a comprehensive benchmark with three code generation task categories (basic programming, open-domain, repository-level) and five external context sources (competition solutions, tutorials, library docs, StackOverflow, GitHub) to evaluate retrieval-augmented code generation (RAG).

- **Performance Analysis**: Top models show notable improvements in code generation when retrieving high-quality contexts, but face challenges with low lexical overlap retrievals and limited context integration, highlighting gaps in current RAG methods for code.

- **Key Limitations**: Current retrievers struggle to fetch useful contexts, and generators fail to improve with constrained context lengths or advanced context integration, underscoring the need for advanced code-oriented RAG techniques.
