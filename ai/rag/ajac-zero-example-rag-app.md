# ajac-zero/example-rag-app

## Summary

- **Multi-Provider LLM Integration**: Uses LiteLLM to support 100+ LLM providers with unified API calls, enabling seamless switching between models (e.g., OpenAI, Anthropic, Mistral) via environment variables.

- **Observability & Monitoring**: Implements Langfuse for full LLM observability, tracking token usage, latency, and model performance metrics in real-time for debugging and optimization.

- **Enterprise-Grade Reliability**: Dockerized deployment with TypeScript strict typing, 100% test coverage, and CI/CD-ready structure for scalable, production-grade RAG applications.
