## Summary

- **Core ML Types**: Supervised (labeled data for prediction/classification), Unsupervised (pattern discovery in unlabeled data), and Reinforcement Learning (trial-and-error optimization via reward maximization).

- **Unsupervised Techniques**: Covers clustering (K-Means, DBSCAN), dimensionality reduction (PCA, t-SNE), and association rule mining (Apriori, FP-Growth) for pattern extraction and feature simplification.
