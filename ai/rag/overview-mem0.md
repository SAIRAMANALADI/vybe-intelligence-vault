# Overview - Mem0

## Summary

- **Managed Memory Engine**: Mem0 provides a fully managed, production-ready memory layer for AI agents, handling scaling, security, and enrichment without requiring infrastructure setup (e.g., vector databases or LLM configuration).

- **Key Features**: Supports personalized replies via persistent memories, enterprise controls (audit logs, governance), and advanced capabilities like webhooks, multimodal support, and custom categories—all with minimal code integration.

- **Operational Workflows**: Offers structured paths for launching workspaces, integrating AI clients (e.g., MCP, LangChain), managing memory operations (CRUD, metadata filters), and monitoring via a dashboard, with optional self-hosting comparison.
