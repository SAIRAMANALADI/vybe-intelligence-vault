# omoindrot/tensorflow-triplet-loss

## Summary

- **Implementation**: Provides TensorFlow code for triplet loss, a metric learning loss function used to train embeddings by minimizing the distance between an anchor and a positive sample while maximizing the distance between the anchor and a negative sample.

- **Online Triplet Mining**: Supports online triplet mining, dynamically selecting hard triplets during training to improve convergence and performance without precomputing triplets.

- **Modular Design**: Offers a reusable and modular implementation, allowing integration with custom TensorFlow models for tasks like face recognition, image retrieval, or clustering.
