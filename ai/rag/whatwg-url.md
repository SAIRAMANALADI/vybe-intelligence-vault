# whatwg/url

## Summary

- Defines the URL Standard, specifying parsing, serialization, and validation of URLs in web browsers and other contexts.
- Implements algorithms for URL components (scheme, authority, path, query, fragment) and their interactions (e.g., relative URL resolution).
- Maintains compatibility with RFC 3986 while incorporating WHATWG-specific extensions and modern web requirements.
