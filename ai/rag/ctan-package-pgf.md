# CTAN: Package pgf

## Summary

- **Platform-agnostic vector graphics package** for TeX, supporting both PostScript and PDF output via drivers like pdfTeX and dvips, with compatibility across plain TeX, LaTeX, and ConTeXt.
- **Syntax layers**: Core PGF engine with a user-friendly TikZ frontend, offering functionality comparable to pstricks and the standard TeX picture environment.
- **Version 3.1.11a (2025-08-29)**, licensed under GPL-2, LPPL-1.3c, and FDL, maintained by Christian Feuersänger, Henri Menke, and the PGF/TikZ team, with source available at [CTAN](https://ctan.org/pkg/pgf).
