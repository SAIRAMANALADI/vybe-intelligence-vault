# YouTube | Google for Developers

## Summary

- **Embedded Player Integration**: Utilize the [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference) for direct video playback within applications, with support for iOS via the [YouTube Helper library](https://developers.google.com/youtube/v3/guides/ios_youtube_helper) and customizable playback parameters.

- **Data API for Content Management**: Leverage the [YouTube Data API v3](https://developers.google.com/youtube/v3/getting-started) to enable search, video uploads, playlist management, and other core functionalities with endpoints documented in the [reference guide](https://developers.google.com/youtube/v3/docs).

- **Analytics & Live Features**: Access [YouTube Reporting API](https://developers.google.com/youtube/reporting) for user interaction analytics and the [Live Streaming API](https://developers.google.com/youtube/v3/live/getting-started) to schedule broadcasts and manage video streams.
