# onyx-dot-app/onyx

## Summary

- **Multi-LLM Compatibility**: Open-source AI chat platform (`onyx`) supporting integration with any LLM (e.g., ChatGPT, open-source models) via standardized APIs, enabling flexible model switching and hybrid inference workflows.

- **Enterprise-Grade RAG & Vector Search**: Implements Retrieval-Augmented Generation (RAG) with vector-based similarity search (e.g., FAISS, Weaviate) for contextual information retrieval, optimized for large-scale document indexing and low-latency query processing.

- **Modular Architecture**: Built with Python backend and Next.js frontend, featuring pluggable components for chat UI, enterprise search, and self-hosted deployment, with support for custom tooling and API gateways for scalable Gen-AI workflows.
