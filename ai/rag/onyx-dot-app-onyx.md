# onyx-dot-app/onyx

## Summary

- **Multi-LLM Integration**: Supports seamless interaction with any Large Language Model (LLM) via a unified API, enabling cross-model compatibility and dynamic switching between providers (e.g., OpenAI, Anthropic, local models).

- **Enterprise-Grade RAG & Vector Search**: Implements Retrieval-Augmented Generation (RAG) with optimized vector search (e.g., FAISS, Pinecone) for low-latency, high-accuracy semantic retrieval across proprietary and public datasets.

- **Modular Next.js Frontend**: Features a customizable React-based UI (Next.js) with pluggable components for chat, enterprise search, and admin dashboards, supporting self-hosted deployments with Docker/Kubernetes.
