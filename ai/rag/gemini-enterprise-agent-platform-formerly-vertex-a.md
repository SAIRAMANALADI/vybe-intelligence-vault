# Gemini Enterprise Agent Platform (formerly Vertex AI) | Google Cloud

## Summary

- **Unified Agent Development & Governance**: Google Cloud's Gemini Enterprise Agent Platform provides a single environment for building, scaling, governing, and optimizing enterprise-grade AI agents with full-stack developer flexibility and enterprise data integration.

- **Multi-Model & Tooling Support**: Supports 200+ models (Gemini 3.5, Claude, Gemma) with customization via tuning options, Model Garden for discovery/testing, and Model Evaluation for objective performance benchmarking.

- **MLOps & Workflow Automation**: Offers integrated MLOps tools (Model Registry, Feature Store, Pipelines, Monitoring) with Colab Enterprise/Workbench notebooks, BigQuery-native workflows, and Antigravity for orchestrating multi-agent workflows (e.g., code generation, asset creation).
