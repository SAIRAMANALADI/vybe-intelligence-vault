# Privacy Help Center - Policies Help

## Summary

- **Data Access & Control Tools**: Google provides centralized interfaces like [My Activity](https://myactivity.google.com/myactivity), [Google Dashboard](https://myaccount.google.com/dashboard), and [Takeout Tool](https://takeout.google.com) to review, manage, delete, or download user data across services (e.g., searches, location history, YouTube activity, purchases).

- **Account Security & Recovery**: Users can secure compromised accounts via [Security Checkup](https://myaccount.google.com/security-checkup), recover access through [account recovery](http://g.co/recover), or report unauthorized activity; Workspace accounts follow separate [Google Workspace support](https://support.google.com/a/answer/1047213) protocols.

- **Legal & Automated Data Management**: Google offers streamlined processes for content removal requests (e.g., [legal troubleshooter](https://support.google.com/legal/troubleshooter/1114905)) and automated deletion controls (e.g., [auto-delete for Location History](https://support.google.com/accounts/answer/465#auto-delete)), with retention policies outlined in their [data retention policy](https://policies.google.com/technologies/retention).
