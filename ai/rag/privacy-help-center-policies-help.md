# Privacy Help Center - Policies Help

## Summary

- **Account Security & Recovery**: Google provides structured processes for account recovery (e.g., [Gmail/Account recovery](https://support.google.com/accounts/answer/7682439)) and compromised account mitigation via [Security Checkup](https://myaccount.google.com/security-checkup), including forensic tools to audit suspicious activity and enforce access controls.

- **Data Access & Deletion Controls**: Users can manage data via [Google Takeout](https://takeout.google.com) (export), [My Activity](https://myactivity.google.com/myactivity) (review/control), and granular deletion tools (e.g., [auto-delete](https://support.google.com/accounts/answer/465#auto-delete) for Location History), with retention policies defined in [Google’s retention policy](https://policies.google.com/technologies/retention).

- **Privacy & Ad Personalization**: Users control ad targeting via [My Ad Center](https://myadcenter.google.com) (opt-in/opt-out of interest-based ads), while [Activity Controls](https://myaccount.google.com/activitycontrols) and [Google Dashboard](https://myaccount.google.com/dashboard) centralize consent management for Web & App Activity, Location History, and YouTube watch/search history.
