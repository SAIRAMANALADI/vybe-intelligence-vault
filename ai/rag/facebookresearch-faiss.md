# facebookresearch/faiss

## Summary

- **Core Functionality**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, leveraging approximate nearest neighbor (ANN) techniques to handle large-scale datasets.

- **Key Features**: Supports indexing methods like IVF (Inverted File), PQ (Product Quantization), and HNSW (Hierarchical Navigable Small World) for fast vector retrieval with configurable trade-offs between accuracy and speed.

- **Performance**: Designed for scalability, FAISS enables billion-scale vector searches on a single GPU or CPU, with Python bindings (`faiss-gpu`/`faiss-cpu`) for integration into ML pipelines.
