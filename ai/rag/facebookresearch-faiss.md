# facebookresearch/faiss

## Summary

- **Purpose**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, leveraging approximate nearest neighbor (ANN) techniques to handle large-scale datasets.
- **Key Features**: Supports exact and approximate search, GPU acceleration, and hierarchical clustering (e.g., IVF, PQ, HNSW) for scalable vector indexing and retrieval.
- **Performance**: Designed for high throughput and low latency, with bindings for Python and integration with deep learning frameworks (e.g., PyTorch).
