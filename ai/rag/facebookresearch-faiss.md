# facebookresearch/faiss

## Summary

- **Purpose**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, leveraging approximate nearest neighbor (ANN) techniques to handle large-scale datasets.
- **Key Features**: Supports both exact and approximate nearest neighbor search, GPU acceleration, and hierarchical clustering (e.g., IVF, PQ, HNSW) for scalability in high-dimensional spaces.
- **Performance**: Designed for low-latency retrieval with optimizations like SIMD instructions, multi-threading, and memory-efficient indexing (e.g., inverted file structures).
