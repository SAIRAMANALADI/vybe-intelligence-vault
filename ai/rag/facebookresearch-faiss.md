# facebookresearch/faiss

## Summary

- **Core Functionality**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, leveraging approximate nearest neighbor (ANN) techniques to handle large-scale datasets.

- **Key Features**: Supports both exact and approximate nearest neighbor search, GPU acceleration via CUDA, and hierarchical clustering (e.g., IVF, PQ, HNSW) for scalability, with Python bindings for ease of integration.

- **Performance**: Designed for high throughput and low latency, FAISS is widely used in production systems for tasks like semantic search, recommendation systems, and large-scale image/video retrieval.
