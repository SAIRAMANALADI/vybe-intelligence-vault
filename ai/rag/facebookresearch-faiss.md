# facebookresearch/faiss

## Summary

- **Purpose**: FAISS is an optimized C++ library for efficient similarity search and clustering of dense vectors, leveraging approximate nearest neighbor (ANN) techniques to handle large-scale datasets.
- **Key Features**: Supports exact and approximate search via indexing structures (e.g., IVF, HNSW, PQ) with GPU acceleration (CUDA) and multi-threading (OpenMP).
- **Applications**: Enables scalable vector similarity search for tasks like recommendation systems, image retrieval, and NLP embeddings, with bindings for Python and other languages.
