# facebookresearch/faiss

## Summary

- **Core Functionality**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, leveraging approximate nearest neighbor (ANN) techniques to handle large-scale datasets.

- **Key Features**: Supports exact and approximate nearest neighbor search, GPU acceleration, and clustering (e.g., IVF, PQ, HNSW) with interfaces for Python/C++.

- **Performance**: Designed for high scalability and speed, reducing memory footprint via techniques like product quantization (PQ) and inverted file indexes (IVF).
