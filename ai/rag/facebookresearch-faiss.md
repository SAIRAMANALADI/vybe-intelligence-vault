# facebookresearch/faiss

## Summary

- **Purpose**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, particularly for large-scale datasets.
- **Key Features**: Implements approximate nearest neighbor search (ANN) with support for L2 and inner product distances, GPU acceleration, and modular indexing structures (e.g., IVF, PQ, HNSW).
- **Performance**: Designed for scalability, leveraging SIMD instructions, multi-threading, and hierarchical indexing to reduce memory overhead and query latency.
