# facebookresearch/faiss

## Summary

- **Efficient similarity search**: FAISS implements optimized algorithms for approximate nearest neighbor search in high-dimensional spaces, leveraging techniques like IVF (Inverted File Index), PQ (Product Quantization), and HNSW (Hierarchical Navigable Small World) for sub-linear time complexity.

- **Clustering support**: Includes k-means and other clustering algorithms tailored for large-scale vector datasets, enabling dimensionality reduction and data partitioning with minimal memory overhead.

- **C++ core with Python bindings**: Provides a high-performance C++ backend with a Python interface (`faiss` module), supporting GPU acceleration via CUDA and optimized for large-scale datasets (billions of vectors).
