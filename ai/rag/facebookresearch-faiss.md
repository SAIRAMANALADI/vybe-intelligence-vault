# facebookresearch/faiss

## Summary

- **Purpose**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, leveraging approximate nearest neighbor (ANN) techniques to handle large-scale datasets.
- **Key Features**: Supports index types (e.g., IVF, HNSW, PQ) for trade-offs between accuracy, speed, and memory; integrates with GPU acceleration via CUDA; and provides Python bindings for accessibility.
- **Performance**: Designed for high scalability, enabling billion-scale vector search with sub-linear time complexity through optimized indexing and quantization methods.
