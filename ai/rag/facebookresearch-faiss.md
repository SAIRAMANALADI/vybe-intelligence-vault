# facebookresearch/faiss

## Summary

- **Optimized similarity search**: FAISS provides highly efficient algorithms for searching dense vectors in high-dimensional spaces, leveraging techniques like **IVF (Inverted File Index)** and **HNSW (Hierarchical Navigable Small World)** for approximate nearest neighbor (ANN) search with sub-linear time complexity.

- **Clustering & quantization**: Implements **k-means clustering** and **PQ (Product Quantization)** for dimensionality reduction and memory-efficient vector storage, enabling scalable clustering and search operations on large datasets.

- **GPU & CPU support**: Supports both **GPU-accelerated** (via CUDA) and **CPU-based** implementations, with bindings for Python (`faiss-gpu`/`faiss-cpu` packages) and C++ APIs for integration into production systems.
