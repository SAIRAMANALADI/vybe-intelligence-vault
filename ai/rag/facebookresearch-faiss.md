# facebookresearch/faiss

## Summary

- **Purpose**: FAISS (Facebook AI Similarity Search) is a C++ library optimized for efficient similarity search and clustering of dense vectors, leveraging advanced indexing techniques to handle large-scale vector datasets.

- **Key Features**: Supports exact and approximate nearest neighbor search via optimized indexing structures (e.g., IVF, HNSW, PQ) and GPU acceleration, enabling sub-linear time complexity for high-dimensional data.

- **Applications**: Widely used in recommendation systems, image retrieval, NLP embeddings, and large-scale machine learning pipelines requiring scalable vector similarity operations.
