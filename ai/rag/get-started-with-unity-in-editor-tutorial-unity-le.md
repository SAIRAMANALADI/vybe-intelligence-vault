# Get Started with Unity: In-Editor Tutorial - Unity Learn

## Summary

- **Unity's in-Editor tutorial** leverages an interactive, guided template within Unity Hub (v6.3+) to teach foundational game development concepts directly in the Editor, covering primary windows, GameObject manipulation, and basic game mechanics (e.g., character control, UI, audio, animation, and VFX).

- **Project setup** requires launching Unity Hub, selecting the "Learning" tab, and creating a new project using the "Get Started with Unity" template, which auto-loads a pre-configured scene with step-by-step instructions and callouts for hands-on learning.

- **Post-tutorial workflow** includes optional sharing of the completed project via Unity Play, where users can submit screenshots, a playable link, and metadata (title, description) publicly or privately for community review and feedback.
