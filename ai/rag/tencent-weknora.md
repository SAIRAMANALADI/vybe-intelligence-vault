# Tencent/WeKnora

## Summary

- **Multi-Model RAG & Agent Framework**: WeKnora transforms raw documents into a **queryable RAG system**, an **autonomous reasoning agent**, and a **self-maintaining Wiki** via Go-based pipelines, supporting **multi-model embeddings** (e.g., OpenAI, Ollama) and **vector search** for semantic retrieval.

- **Modular Architecture**: Implements **multi-tenant** support, **reranking**, and **evaluation** modules for scalable knowledge base management, with **semantic search** and **question-answering** capabilities via embeddings and LLM integration.

- **Self-Sustaining Wiki**: Features **automated knowledge maintenance** (e.g., document ingestion, updates) and **agentic workflows** for dynamic content generation, leveraging **Go** for high-performance backend operations.
