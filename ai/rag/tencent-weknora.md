# Tencent/WeKnora

## Summary

- **Multi-Model RAG & Agent Framework**: WeKnora converts raw documents into a queryable Retrieval-Augmented Generation (RAG) system, supports autonomous reasoning agents, and maintains a self-updating Wiki, all in Go with multi-tenant and multi-model capabilities.

- **Vector & Semantic Search Pipeline**: Implements embeddings, reranking, and vector/semantic search for efficient knowledge retrieval, supporting models like Ollama and OpenAI APIs.

- **Scalable Knowledge Base**: Designed for generative AI applications with evaluation tools, chatbot integration, and semantic search, optimized for high-performance vector operations.
