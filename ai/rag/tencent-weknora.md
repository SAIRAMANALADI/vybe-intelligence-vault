# Tencent/WeKnora

## Summary

- **Multi-Model RAG & Agent Framework**: WeKnora transforms raw documents into a queryable Retrieval-Augmented Generation (RAG) system, an autonomous reasoning agent, and a self-maintaining Wiki, supporting multimodal and multi-tenant architectures.
- **Technical Stack**: Implemented in Go, it integrates embeddings, vector search, reranking, and semantic search, with compatibility for OpenAI and Ollama models for LLM inference.
- **Features**: Supports evaluation pipelines, chatbot interfaces, and knowledge base management, enabling dynamic document processing and real-time query resolution.
