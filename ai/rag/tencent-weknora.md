# Tencent/WeKnora

## Summary

- **Multi-modal RAG & Agent Framework**: WeKnora transforms raw documents into a queryable Retrieval-Augmented Generation (RAG) system, supports autonomous reasoning agents, and maintains a self-updating Wiki, all in Go.

- **Scalable Vector & Semantic Search**: Implements vector search, embeddings, reranking, and semantic search with support for multi-tenancy, multi-model LLMs (Ollama/OpenAI), and cross-platform compatibility.

- **Enterprise-Grade Features**: Includes chatbot integration, knowledge base management, generative AI evaluation tools, and modular architecture for extensibility in production environments.
