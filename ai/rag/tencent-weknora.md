# Tencent/WeKnora

## Summary

- **Multi-modal LLM Knowledge Platform**: Converts raw documents into queryable RAG (Retrieval-Augmented Generation), autonomous reasoning agents, and self-maintaining Wiki systems with support for multimodal inputs and outputs.

- **Go-Based Architecture**: Implements a high-performance, multi-tenant backend in Go with vector search, embeddings, reranking, and semantic search capabilities for scalable knowledge retrieval.

- **Integration & Tooling**: Supports OpenAI and Ollama models, provides evaluation frameworks, and includes features for multi-model management, agentic workflows, and semantic Wiki maintenance.
