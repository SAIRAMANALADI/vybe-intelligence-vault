# Tencent/WeKnora

## Summary

- **Multi-modal RAG & Agent Framework**: WeKnora transforms raw documents into a **queryable Retrieval-Augmented Generation (RAG)** system, an **autonomous reasoning agent**, and a **self-maintaining Wiki** using Go, supporting **multi-tenancy** and **multi-model** LLM integration (e.g., Ollama, OpenAI).

- **Advanced Retrieval & Evaluation**: Implements **semantic search**, **vector search**, **embeddings**, and **reranking** for high-precision document retrieval, with built-in **evaluation** tools for performance benchmarking.

- **Scalable Knowledge Infrastructure**: Designed for **generative AI** and **question-answering** workflows, featuring **semantic indexing**, **multi-tenant support**, and **Wiki-like self-updating** capabilities for dynamic knowledge management.
