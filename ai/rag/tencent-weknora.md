# Tencent/WeKnora

## Summary

- **Multi-modal LLM Knowledge Platform**: Converts raw documents into a queryable RAG (Retrieval-Augmented Generation) system, autonomous reasoning agent, and self-maintaining Wiki using Go, supporting multi-tenancy, OpenAI/Ollama APIs, and semantic/vector search.

- **Core Features**: Implements embeddings, reranking, and evaluation pipelines for generative AI, enabling multimodal knowledge base construction, chatbot integration, and question-answering workflows.

- **Technical Stack**: Leverages Golang for backend scalability, supports vector databases for embeddings, and integrates with LLM frameworks (OpenAI, Ollama) for reasoning and Wiki self-maintenance.
