# Tencent/WeKnora

## Summary

- **Modular LLM Knowledge Platform**: Implements a Go-based system for converting raw documents into queryable RAG (Retrieval-Augmented Generation), autonomous reasoning agents, and self-maintaining Wiki capabilities with multi-tenant support.

- **Advanced Retrieval & Reasoning**: Integrates embeddings, vector search, reranking, and semantic search with OpenAI/Ollama LLM backends to enable high-precision question-answering and agentic workflows.

- **Scalable Infrastructure**: Designed for production-grade deployment with DSH-plugin compatibility, evaluation tools, and a vectorized knowledge base architecture optimized for generative AI applications.
