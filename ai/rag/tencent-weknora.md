# Tencent/WeKnora

## Summary

- **Multi-functional LLM Platform**: Converts raw documents into a queryable Retrieval-Augmented Generation (RAG) system, an autonomous reasoning agent, and a self-maintaining Wiki, supporting both OpenAI and Ollama models.

- **Technical Stack**: Implements Go-based backend with vector search, embeddings, reranking, semantic search, and multi-tenant support for scalable knowledge management.

- **Features**: Enables multimodal interactions, question-answering, and agentic workflows with evaluation and semantic indexing capabilities.
