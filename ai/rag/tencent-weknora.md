# Tencent/WeKnora

## Summary

- **Multi-Model RAG & Agent Framework**: Implements a Go-based platform for converting raw documents into a queryable Retrieval-Augmented Generation (RAG) system, an autonomous reasoning agent, and a self-maintaining Wiki, supporting multi-tenancy and multi-model integrations (e.g., Ollama, OpenAI).

- **Advanced Retrieval & Evaluation**: Integrates embeddings, vector search, reranking, and semantic search for efficient document retrieval, with built-in evaluation tools for assessing LLM performance in question-answering tasks.

- **Scalable Knowledge Base Management**: Features a self-updating Wiki system and supports multi-tenant architectures, enabling dynamic knowledge base maintenance and collaborative editing.
