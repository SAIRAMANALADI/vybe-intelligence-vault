# Tencent/WeKnora

## Summary

- **Multi-modal RAG & Agentic Workflow**: WeKnora converts raw documents into a queryable Retrieval-Augmented Generation (RAG) system, an autonomous reasoning agent, and a self-maintaining Wiki, supporting multimodal inputs (e.g., text, embeddings) and enabling multi-tenant deployments.

- **Go-Based Vector & Semantic Search**: Implements vector search, reranking, and semantic search via Go, integrating with models like Ollama and OpenAI, while supporting embeddings, LLM APIs, and evaluation frameworks for generative AI applications.

- **Scalable Knowledge Infrastructure**: Designed for high scalability with multi-tenant support, enabling Wiki-style self-maintenance, question-answering, and knowledge base management across diverse LLMs and retrieval systems.
