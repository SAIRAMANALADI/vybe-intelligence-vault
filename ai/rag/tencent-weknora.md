# Tencent/WeKnora

## Summary

- **Multi-Model LLM Platform**: Open-source Go-based system enabling conversion of raw documents into a queryable Retrieval-Augmented Generation (RAG) pipeline, autonomous reasoning agent, and self-maintaining Wiki via embeddings, vector search, and reranking.

- **Agentic & Multi-Tenant Capabilities**: Supports agentic workflows, multi-model LLM integration (Ollama, OpenAI), and multi-tenant knowledge base management with semantic search and question-answering functionalities.

- **Evaluation & Scalability**: Provides evaluation tools for generative AI, supports multimodal models, and scales via semantic/vector search with last update as of August 2026.
