# Tencent/WeKnora

## Summary

- **Multi-functional LLM Platform**: Converts raw documents into a queryable RAG system, autonomous reasoning agent, and self-maintaining Wiki, supporting multimodal and multi-tenant operations.

- **Technical Stack**: Implemented in Go, integrates embeddings, vector search, reranking, and semantic search; supports OpenAI, Ollama, and multi-model LLM interactions.

- **Features**: Includes chatbot capabilities, knowledge base management, evaluation tools, and supports generative AI workflows with robust RAG and Wiki functionalities.
