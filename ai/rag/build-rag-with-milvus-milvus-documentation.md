# Build RAG with Milvus | Milvus Documentation

## Summary

- **Milvus RAG Pipeline**: Combines retrieval (via Milvus vector search) with generative models (e.g., OpenAI's LLM) to augment responses with retrieved context, enabling accurate, context-aware text generation.

- **Vector Database Integration**: Uses Milvus to store and query embeddings (e.g., OpenAI `text-embedding-3-small`) with metrics like inner product (IP) for semantic similarity, enabling efficient retrieval of top-*k* relevant documents.

- **Dynamic Schema & Hybrid Storage**: Supports dynamic fields (e.g., `text`) in addition to schema-defined fields, with data stored in persistent storage (e.g., S3/MinIO) and metadata in etcd, ensuring scalability and consistency.
