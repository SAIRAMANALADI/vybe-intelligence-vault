# MongoDB Vector Search | MongoDB

## Summary

- **Hybrid Search Integration**: MongoDB now supports hybrid search combining traditional keyword-based and vector search in a single workflow, available in both Enterprise Advanced and Community Edition.

- **Automated Embedding & Reranking**: Native automated embedding generation (powered by Voyage AI) and reranking models are integrated directly into MongoDB Atlas, reducing pipeline complexity and improving retrieval accuracy without external dependencies.

- **Scalable, Unified Architecture**: Vector search operates natively alongside operational data in MongoDB’s distributed architecture, enabling independent scaling of vector workloads with enterprise-grade security, high availability, and hybrid query capabilities (e.g., metadata filters, geospatial search).
