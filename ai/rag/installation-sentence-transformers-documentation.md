# Installation — Sentence Transformers documentation

## Summary

- **Installation & Setup**: Supports multiple installation methods (`uv`, `pip`, `conda`, source, editable) with optional CUDA-accelerated PyTorch for GPU compatibility.

- **Model Types & Usage**: Implements three core architectures—`SentenceTransformer` (bi-encoder for embeddings), `CrossEncoder` (fine-grained scoring), and `SparseEncoder`—with optimized workflows for semantic search, clustering, and retrieval/re-ranking.

- **Training & Evaluation**: Provides modular training pipelines with configurable components (loss functions, datasets, evaluators) and supports efficiency optimizations (ONNX, OpenVINO) alongside MTEB benchmarking for standardized evaluation.
