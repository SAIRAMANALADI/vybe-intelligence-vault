# CircuitPython

## Summary

- **Interpreted Python for Microcontrollers**: CircuitPython is a derivative of MicroPython, enabling direct execution of Python scripts on low-cost microcontroller boards without compilation, leveraging an on-device interpreter for immediate feedback via REPL and serial console.

- **Hardware-Agnostic Library Support**: Over 500+ CircuitPython libraries (compatible with CPython via Blinka) abstract hardware interactions, enabling cross-platform development across 600+ supported microcontroller boards and single-board computers (e.g., Raspberry Pi).

- **Plug-and-Play Development Workflow**: Code is stored as editable files on the device’s filesystem, allowing real-time modifications without additional tooling; supports USB, WiFi, and Bluetooth for code deployment and debugging.
