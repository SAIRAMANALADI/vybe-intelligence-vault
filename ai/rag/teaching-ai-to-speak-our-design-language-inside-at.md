# Teaching AI to speak our design language - Inside Atlassian

## Summary

- **Structured Content Schema**: Developed lightweight, machine-readable schemas (TypeScript-based) for components, icons, tokens, and guidelines, capturing usage, props, accessibility, and code examples to ensure consistency across documentation, Figma, and code repositories.

- **Performance Gains**: Structured content improved AI task accuracy by **52%**, reduced errors by **11%**, increased speed by **34%**, and cut token usage (**16%**) and tool calls (**26%**), enabling faster, more reliable UI generation.

- **Self-Healing Documentation**: Implemented automated tooling to sync structured content with code updates, preventing drift and ensuring AI agents and developers always access the latest, validated design system references.
