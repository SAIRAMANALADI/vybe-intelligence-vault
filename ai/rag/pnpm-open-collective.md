# pnpm - Open Collective

## Summary

- **Efficient Dependency Management**: `pnpm` is a fast, disk-space-efficient package manager for JavaScript/Node.js that uses a content-addressable store to avoid redundant downloads and disk usage by hard-linking dependencies.
- **Content-Addressable Storage**: Implements a shared dependency model where packages are stored once in a global store and linked to project `node_modules`, reducing installation time and storage overhead compared to `npm`/`yarn`.
- **Performance & Compatibility**: Supports Node.js 14+, offers up to 33% faster installs than `npm`/`yarn`, and maintains compatibility with `npm`/`yarn` lockfiles while optimizing for monorepo workflows.
