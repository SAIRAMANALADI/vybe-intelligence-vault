# Deep Agents Code - Docs by LangChain

## Summary

- **Multi-Provider LLM Integration**: Supports dynamic switching between any tool-calling LLM (e.g., OpenAI, Anthropic, Google) mid-session via `/model` or CLI flags (`--model`), with persistent memory and configurable skills for context retention.

- **Sandboxed Execution & Human-in-the-Loop Controls**: Executes shell commands locally or in remote sandboxes (e.g., LangSmith, E2B) with approval gates for destructive operations (`write_file`, `edit_file`, `execute`), and supports non-interactive mode with allowlisted commands (`-S recommended/all`).

- **Observability & Task Management**: Integrates with LangSmith for tracing agent operations, supports task decomposition with subagents, and enforces goals/rubrics for measurable outcomes, including async task delegation and conversation offloading for token efficiency.
