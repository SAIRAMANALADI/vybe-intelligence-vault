## Summary

- **Modular Agent Framework**: `dcode` is an open-source coding agent built on the Deep Agents SDK, supporting dynamic switching between LLM providers/models while maintaining persistent memory for cross-session context retention.

- **Advanced Execution Controls**: Features remote sandboxes, human-in-the-loop approvals for sensitive operations, and configurable skills for behavior customization, with MCP tool integration for external functionality.

- **Observability & Scalability**: Supports tracing via LangSmith, parallel task delegation via subagents, context compaction for memory efficiency, and goal/rubric-based task validation for measurable outcomes.
