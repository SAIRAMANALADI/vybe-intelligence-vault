# Deep Agents Code - Docs by LangChain

## Summary

- **Open-source coding agent** built on the Deep Agents SDK, compatible with any LLM, enabling provider/model switching, persistent memory for cross-session context, and customizable skills/approval controls for code execution.

- **Key capabilities** include remote sandboxes, goal/rubric definitions, subagent delegation, MCP tool integration, tracing via LangSmith, and human-in-the-loop approval for sensitive operations.

- **Installation** via `curl -LsSf https://langch.in/dcode | bash` launches an interactive session; supports configuration via `config.toml`, environment variables, and MCP for real-time tool integration.
