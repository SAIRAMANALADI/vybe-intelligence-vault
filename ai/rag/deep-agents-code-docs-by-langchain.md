# Deep Agents Code - Docs by LangChain

## Summary

- **Modular Agent Framework**: Open-source coding agent (`dcode`) built on Deep Agents SDK, enabling model-agnostic LLM integration with persistent memory, customizable skills, and execution control via approval gates.

- **Advanced Execution Features**: Supports remote sandboxes, subagent delegation for parallel tasks, MCP tool integration, and LangSmith tracing for observability, alongside context compaction and human-in-the-loop approvals for sensitive operations.

- **Configurable Workflows**: Enables goal/rubric definition for measurable task completion, skill extensions via custom instructions, and seamless setup via CLI (`dcode`) or MCP-enabled IDEs (VSCode, Claude) with persistent session memory.
