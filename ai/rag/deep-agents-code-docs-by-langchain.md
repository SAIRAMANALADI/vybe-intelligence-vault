# Deep Agents Code - Docs by LangChain

## Summary

- **Modular Agent Framework**: Open-source `dcode` coding agent built on Deep Agents SDK, enabling LLM-agnostic execution with persistent memory, customizable skills, and configurable approval gates for tool usage.

- **Advanced Execution Features**: Supports remote sandboxes, subagents for parallel task delegation, MCP tool integration, and LangSmith tracing for observability, alongside context compaction and human-in-the-loop controls.

- **Configurable Workflows**: Enables goal/rubric definition for measurable outcomes, skill extensions via custom instructions, and seamless setup via CLI (`curl -LsSf https://langch.in/dcode | bash`) with credentials/configurable via `config.toml`.
