# Deep Agents Code - Docs by LangChain

## Summary

- **Modular Agent Framework**: Open-source coding agent (`dcode`) built on Deep Agents SDK, supporting multi-model LLM integration, persistent memory for cross-session context, and customizable skills via configurable hooks and `config.toml`.

- **Advanced Execution Controls**: Features remote sandboxes, human-in-the-loop approvals for sensitive operations, subagent delegation for parallel task execution, and MCP tool integration for external tool loading.

- **Observability & Optimization**: Implements context compaction for message summarization, tracing via LangSmith for debugging, and goal/rubric-based task evaluation for measurable performance tracking.
