# Deep Agents Code - Docs by LangChain

## Summary

- **Modular Architecture**: Deep Agents Code (`dcode`) is an open-source coding agent built on the Deep Agents SDK, supporting LLM-agnostic execution with persistent memory, customizable skills, and configurable approval controls for code execution.

- **Core Capabilities**: Features remote sandboxes, goal/rubric-based task evaluation, subagent delegation, MCP tool integration, context compaction, human-in-the-loop approvals, and LangSmith tracing for observability and debugging.

- **Deployment & Extensibility**: Installs via `curl` command, supports interactive/non-interactive modes, and allows configuration via `config.toml`, environment variables, and MCP for IDE integration (VSCode, Claude).
