# Deep Agents Code - Docs by LangChain

## Summary

- **Modular Agent Framework**: `dcode` is an open-source coding agent built on the Deep Agents SDK, supporting LLM-agnostic model switching, persistent memory for cross-session context, and customizable skills for behavior shaping.

- **Execution Controls & Extensibility**: Features remote sandboxes, human-in-the-loop approvals for sensitive operations, MCP tool integration, and tracing via LangSmith for debugging/observability.

- **Advanced Workflow Features**: Supports goals/rubrics for task validation, subagents for parallel delegation, context compaction for memory efficiency, and configurable hooks via `config.toml`/environment variables.
