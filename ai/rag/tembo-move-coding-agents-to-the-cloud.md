# Tembo - Move coding agents to the cloud

## Summary

- **Multi-model agent orchestration**: Supports dynamic switching between frontier LLMs (e.g., Anthropic, Codex, Claude Code) via an agentic harness, enabling optimal model-task pairing without vendor lock-in.

- **Isolated cloud execution environments**: Each agent runs in a dedicated cloud VM with preloaded repo context, dependencies, and tools, ensuring reproducible, sandboxed execution across AWS/GCP/Azure.

- **Unified control plane with SOC 2 compliance**: Provides centralized deployment, observability, and governance (SSO/RBAC) with optional self-hosting for end-to-end secure agent operations.
