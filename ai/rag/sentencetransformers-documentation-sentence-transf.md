## Summary

- **Installation & Setup**: Supports multiple installation methods (`pip`, `conda`, `uv`, source) with optional CUDA-enabled PyTorch for GPU acceleration; includes editable installs for development.

- **Model Types & Usage**: Implements three core architectures—**Sentence Transformers** (bi-encoders for embeddings), **Cross Encoders** (fine-grained scoring), and **Sparse Encoders**—with applications in semantic search, clustering, and retrieval-re-ranking pipelines.
