# NSF SAGE: Data Services: Nodes: DMC: Software: Complete List of Software Downloads

## Summary

- **NSF SAGE** manages and distributes geoscience data including ground motion, atmospheric, infrasonic, magnetotelluric, strain, hydrological, and hydroacoustic datasets, with ingestion, curation, and access tools via [IRIS DMC](https://ds.iris.edu/ds/nodes/dmc/).

- **Instrumentation support** includes permanent networks (e.g., Global Seismographic Network) and portable systems (seismic, polar, magnetotelluric), with open data policies and community engagement via workshops, best practices, and collaborations (e.g., Greenland, Central Asia).

- **Software ecosystem** provides tools like **Antelope** (seismic analysis), **evalresp** (SEED response evaluation), **IRIS-WS** (Java API for DMC data access), and **irisFetch.m** (Matlab data retrieval), supporting multi-platform (Linux, Mac, Windows) and multi-language (C, Java, Matlab) workflows.
