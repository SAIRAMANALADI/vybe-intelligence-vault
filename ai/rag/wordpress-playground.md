# WordPress Playground

## Summary

- **Instant WordPress Execution**: WordPress Playground enables zero-setup WordPress execution in any environment (browser, Node.js, mobile, VS Code) via a single-click install, leveraging WebAssembly (PHP-WASM) for client-side PHP processing without a traditional host.

- **Multi-Environment Development & Testing**: Supports block theme development in-browser, GitHub PR previews, cross-version PHP/WordPress testing, and private sandbox cloning, with integration hooks for OpenAI, CLI tools, and GitHub Actions.

- **Embeddable & Deployable Platform**: Provides an `<iframe>`-embeddable demo system for interactive product showcases, native app deployment (iOS/Android), and blueprint-based site generation for rapid, reproducible WordPress deployments.
