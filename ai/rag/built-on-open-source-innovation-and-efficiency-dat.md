# Built on Open Source: Innovation and Efficiency | Databricks

## Summary

- **Apache Spark**: Unified engine for distributed data processing, handling batch/streaming workloads across data engineering, science, and ML with in-memory computation for high performance.

- **Delta Lake & Apache Iceberg**: Open table formats enabling ACID transactions, schema evolution, and time travel on cloud storage (S3, ADLS, GCS, HDFS) for lakehouse architectures.

- **MLflow & Unity Catalog**: MLflow manages the ML lifecycle (experimentation, deployment), while Unity Catalog provides a universal governance layer for data/AI assets across multi-cloud environments.
