# vibrantlabsai/ragas

## Summary

- **Ragas**: Python-based framework for evaluating LLM applications, focusing on RAG pipelines with 12+ metrics (e.g., faithfulness, answer relevance, context precision).
- **Key Features**: Modular design for custom metric integration, supports both reference-free and reference-based evaluations, integrates with LangChain and TruLens.
- **Use Case**: Designed for production-grade LLM evaluation in MLOps pipelines, with CLI and API support for automated testing and benchmarking.
