# ragas/docs/concepts/metrics/index.md at main · vibrantlabsai/ragas · GitHub

## Summary

- **Ragas Metrics Framework**: Modular system for evaluating RAG pipelines, comprising metrics for answer correctness, faithfulness, context relevance, and more, designed for extensibility and customization.

- **Core Metrics**: Includes `faithfulness`, `answer_relevancy`, `context_relevancy`, `context_recall`, and `context_precision`, each leveraging LLM-based evaluation or retrieval-specific scoring (e.g., cosine similarity for context relevance).

- **Evaluation Workflow**: Metrics are computed post-pipeline execution, with inputs like ground truth, retrieved context, and generated answers; supports both single-turn and multi-turn RAG evaluations via standardized interfaces.
