# milvus-io/milvus

## Summary

- **High-performance, cloud-native vector database**: Optimized for scalable Approximate Nearest Neighbor (ANN) search with support for distributed architectures, leveraging Go for high concurrency and low-latency operations.
- **Multi-algorithm compatibility**: Integrates with FAISS, HNSW, and DiskANN for diverse vector similarity search workloads, enabling efficient similarity, image, and embedding-based retrieval.
- **LLM and RAG-ready**: Designed for embedding storage/databases, supporting vector similarity, nearest-neighbor search, and integration with large language models (LLMs) for retrieval-augmented generation (RAG) applications.
