# milvus-io/milvus

## Summary

- **High-performance, cloud-native vector database**: Milvus is optimized for scalable approximate nearest neighbor (ANN) search, leveraging distributed architectures and cloud-native principles for efficient vector similarity search.
- **Supports multiple indexing algorithms**: Integrates with FAISS, HNSW, DiskANN, and others, enabling flexible and high-speed vector similarity computations for large-scale datasets.
- **Built in Go with multi-language SDKs**: Core system implemented in Go, with client libraries (e.g., Python, Java) for seamless integration into AI/ML pipelines, RAG systems, and embedding-based applications.
