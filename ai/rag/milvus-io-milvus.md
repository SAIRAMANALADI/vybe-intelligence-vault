# milvus-io/milvus

## Summary

- **Scalable Vector ANN Search Engine**: Milvus is a cloud-native, distributed vector database optimized for high-performance approximate nearest neighbor (ANN) search, supporting billion-scale datasets with sub-millisecond latency.
- **Hybrid Indexing & Multi-Algorithm Support**: Integrates multiple indexing algorithms (e.g., HNSW, DiskANN, FAISS) and supports hybrid search (vector + scalar filtering) for flexible and efficient similarity retrieval.
- **Production-Grade Infrastructure**: Built in Go with cloud-native features (scalability, fault tolerance), designed for LLMs, RAG, and embedding-based applications requiring low-latency vector similarity search.
