# milvus-io/milvus

## Summary

- **Scalable Vector ANN Search Engine**: Milvus is a cloud-native, distributed vector database optimized for high-performance Approximate Nearest Neighbor (ANN) search, supporting billion-scale datasets with sub-millisecond latency.

- **Hybrid Indexing & Multi-Model Support**: Integrates algorithms like HNSW, DiskANN, and FAISS, enabling hybrid indexing (vector + scalar filtering) and compatibility with embeddings from LLMs, images, and other modalities.

- **Go-Based Architecture**: Built in Go for concurrency and efficiency, with modular components for storage (etcd, MinIO/S3), query (Proxy, QueryNode), and indexing (IndexNode), designed for cloud-native deployments (K8s, Helm).
