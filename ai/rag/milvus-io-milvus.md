# milvus-io/milvus

## Summary

- **Scalable Vector ANN Search Engine**: Milvus is a cloud-native, distributed vector database optimized for high-performance approximate nearest neighbor (ANN) search, supporting billion-scale datasets with sub-millisecond latency.
- **Hybrid Indexing & Query Support**: Implements multiple indexing algorithms (HNSW, DiskANN, FAISS) and query modes (vector similarity, boolean filtering) for flexible and efficient similarity search across diverse use cases.
- **Go-Based Architecture**: Built in Go for performance and concurrency, with modular components (storage, index, query) enabling horizontal scaling and integration with LLM/RAG pipelines.
