# milvus-io/milvus

## Summary

- **High-performance vector database**: Milvus is a cloud-native, distributed vector database optimized for **approximate nearest neighbor (ANN)** search, supporting scalable vector similarity search with sub-linear time complexity.
- **Multi-algorithm support**: Integrates **HNSW, DiskANN, FAISS**, and other indexing engines for diverse vector search workloads, including **LLM embeddings, image search, and RAG applications**.
- **Go-based architecture**: Built in **Go** with cloud-native design (Kubernetes, microservices) for horizontal scalability, fault tolerance, and low-latency vector operations.
