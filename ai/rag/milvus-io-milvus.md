# milvus-io/milvus

## Summary

- **Scalable Vector ANN Search**: Milvus is a cloud-native, distributed vector database optimized for high-performance Approximate Nearest Neighbor (ANN) search, supporting billion-scale datasets with low latency.
- **Multi-Algorithm Support**: Integrates multiple indexing algorithms (e.g., HNSW, DiskANN, FAISS) and similarity metrics (e.g., L2, IP, COSINE) for flexible and efficient vector similarity search.
- **RAG & LLM Integration**: Designed for retrieval-augmented generation (RAG) and large language model (LLM) applications, enabling fast embedding storage, retrieval, and similarity-based querying.
