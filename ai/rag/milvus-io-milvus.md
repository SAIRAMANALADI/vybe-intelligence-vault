# milvus-io/milvus

## Summary

- **Cloud-native, distributed vector database** optimized for **scalable approximate nearest neighbor (ANN) search**, supporting **billions of high-dimensional vectors** with low latency.
- **Integrates multiple ANN algorithms** (e.g., HNSW, DiskANN, FAISS) and **supports hybrid search** (vector + scalar filtering) via **Go-based microservices architecture**.
- **Designed for LLM/RAG workflows**, offering **cloud-native deployment** (Kubernetes), **disk-based storage**, and **GPU acceleration** for real-time similarity search.
