# milvus-io/milvus

## Summary

- **High-Performance Vector Database**: Milvus is a cloud-native, distributed vector database optimized for scalable approximate nearest neighbor (ANN) search, supporting billion-scale datasets with low latency.

- **Multi-Algorithm Support**: Integrates multiple indexing algorithms (e.g., HNSW, DiskANN, FAISS) and similarity metrics (e.g., L2, IP, COSINE) for flexible and efficient vector similarity search.

- **AI/ML Integration**: Designed for embedding-based applications (e.g., RAG, LLM, image search) with support for structured data filtering and horizontal scalability via distributed architecture.
