# milvus-io/milvus

## Summary

- **Scalable Vector ANN Search Engine**: Milvus is a cloud-native, distributed vector database optimized for high-performance approximate nearest neighbor (ANN) search, supporting billion-scale datasets with sub-millisecond latency.
- **Multi-Model Indexing & Search**: Implements advanced indexing algorithms (e.g., HNSW, DiskANN, FAISS) and supports hybrid search (vector + scalar filtering) for embedding similarity, LLM, and RAG applications.
- **Go-Based Architecture**: Built in Go for concurrency and efficiency, with modular design for cloud-native deployment, disk-based storage, and compatibility with embedding models (e.g., image, text).
