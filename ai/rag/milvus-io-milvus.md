# milvus-io/milvus

## Summary

- **High-performance, cloud-native vector database**: Milvus is optimized for scalable Approximate Nearest Neighbor (ANN) search, leveraging distributed architectures and efficient indexing (e.g., HNSW, DiskANN, FAISS) to handle large-scale vector embeddings with low latency.
- **Multi-model compatibility**: Supports diverse vector search applications (e.g., image search, LLM embeddings, RAG) via pluggable similarity metrics (e.g., Euclidean, cosine) and embedding storage backends.
- **Go-based distributed system**: Implemented in Go for concurrency and performance, with modular components (e.g., storage, query, index) enabling horizontal scaling and fault tolerance in cloud-native environments.
