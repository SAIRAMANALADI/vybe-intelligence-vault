# milvus-io/milvus

## Summary

- **Scalable Vector ANN Search**: Milvus is a cloud-native, distributed vector database optimized for high-performance Approximate Nearest Neighbor (ANN) search, supporting billion-scale datasets with low latency.
- **Multi-Index & Hybrid Search**: Implements multiple indexing algorithms (e.g., HNSW, DiskANN, FAISS) and supports hybrid search (vector + scalar filtering) for flexible similarity retrieval.
- **Go-Based & Production-Ready**: Built in Go for performance and concurrency, with features like RAG integration, embedding similarity search, and compatibility with LLM workflows.
