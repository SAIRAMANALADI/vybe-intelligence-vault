# milvus-io/milvus

## Summary

- **High-performance, cloud-native vector database**: Milvus is optimized for scalable Approximate Nearest Neighbor (ANN) search, leveraging distributed architectures and efficient indexing (e.g., HNSW, DiskANN, FAISS) to handle large-scale vector embeddings with low latency.
- **Multi-model compatibility**: Supports diverse vector similarity search applications, including image retrieval, LLM-based RAG systems, and embedding similarity tasks, via a unified API for vector storage and querying.
- **Go-based distributed system**: Built in Go for performance and concurrency, with modular components for scalability, disk-based storage (DiskANN), and integration with GPU-accelerated libraries (e.g., FAISS) for enhanced ANN search efficiency.
