# milvus-io/milvus

## Summary

- **High-performance, cloud-native vector database**: Milvus is optimized for scalable Approximate Nearest Neighbor (ANN) search, leveraging advanced indexing structures like HNSW, DiskANN, and FAISS for efficient vector similarity search in distributed environments.

- **Go-based distributed architecture**: Built in Go, Milvus supports horizontal scaling, fault tolerance, and cloud-native deployment (Kubernetes-compatible), with support for hybrid storage (memory/disk) and GPU acceleration for large-scale vector operations.

- **Multi-modal embedding and retrieval**: Integrates with LLM frameworks (e.g., RAG) for embedding generation, supports diverse vector similarity metrics (e.g., L2, IP), and provides APIs for image search, semantic retrieval, and real-time vector database operations.
