# milvus-io/milvus

## Summary

- **High-performance, cloud-native vector database**: Milvus is optimized for scalable Approximate Nearest Neighbor (ANN) search, leveraging distributed architectures and cloud-native principles for efficient vector similarity search.
- **Supports multiple indexing algorithms**: Implements advanced indexing methods like HNSW, DiskANN, and FAISS for fast vector retrieval, catering to diverse use cases (e.g., image search, RAG, LLM embeddings).
- **Go-based, distributed system**: Built in Go for performance and scalability, with support for distributed deployments, disk-based storage, and integration with embedding models for similarity-based queries.
