# Versent partners with 6pillars.ai for AWS WAFR automation - techpartner.news

## Summary

- **Partnership Overview**: Versent, an MSP, partnered with 6pillars.ai to automate AWS Well-Architected Framework Reviews (WAFR) using 6pillars.ai's AUTOMATE+ platform, ensuring continuous compliance with standards like ISO 27001 and SOC 2.

- **Automation & Compliance**: The integration enables real-time security and compliance measures via AWS-integrated automation, code-scanning, and runbooks, facilitating "shift-left" security and "Protect-Right" infrastructure guardrails.

- **AWS Mandate & Framework**: AWS requires WAFR automation; the Well-Architected Framework provides best practices for designing and operating secure, efficient, and cost-effective cloud systems.
