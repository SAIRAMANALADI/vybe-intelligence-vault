# ASA-WG/Mobile App Profile/Mobile App Specification.md at v1.0 · appdefensealliance/ASA-WG · GitHub

## Summary

- **Foundation & Framework**: Leverages OWASP MASVS as baseline, with ADA-specific testable requirements and acceptance criteria; emphasizes automation for security assessments and certification.

- **Assurance Levels**: Defines two assessment tiers—AL1 (developer-provided evidence review) and AL2 (lab-driven direct application evaluation)—with clear scope for tooling and evidence collection.

- **Technical Controls**: Mandates secure storage, cryptography, authentication, network security, IPC/WebView/UI safety, dependency hygiene, input validation, anti-tampering, and privacy controls across Android/iOS platforms.
