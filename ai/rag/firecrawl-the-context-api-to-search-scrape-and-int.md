# Firecrawl - The context API to search, scrape, and interact with the web at scale. 🔥

## Summary

- **Web Data Infrastructure**: Firecrawl provides a context API for AI agents to search, scrape, and interact with the web at scale, supporting structured outputs (Markdown, JSON, screenshots) and real-time interactions (clicks, navigation, typing) with 96% web coverage, including JavaScript-heavy pages.

- **Performance & Efficiency**: Achieves P95 latency of 3.4s with 93% fewer input tokens by excluding non-essential content (navbars, footers, ads), optimized for real-time agents and token-efficient LLM processing.

- **Open-Source & Agent Integration**: Open-source core (163.6K GitHub stars) with SDKs (Python, Node.js) and MCP/CLI support for seamless integration with AI agents (e.g., Cursor, Claude Code) via one-command setup (`npx -y firecrawl-cli@latest init --all --browser`).
