# Firecrawl - The context API to search, scrape, and interact with the web at scale. 🔥

## Summary

- **Web Data Infrastructure**: Firecrawl provides a context API for searching, scraping, and interacting with the web at scale, supporting structured outputs (JSON, Markdown) and screenshots, with 96% coverage including JS-heavy pages.

- **Performance & Efficiency**: Achieves P95 latency of 3.4s, token efficiency (93% fewer input tokens), and open-source development with 164K GitHub stars, enabling real-time agent interactions.

- **Agent Integration & Use Cases**: Supports AI agents via MCP/Skills CLI, offers deep research, lead enrichment, and onboarding workflows, with partnerships (e.g., Wikipedia) and enterprise adoption (Shopify, Canva, Zapier).
