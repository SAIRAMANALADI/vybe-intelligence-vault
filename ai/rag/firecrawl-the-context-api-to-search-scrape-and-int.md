# Firecrawl - The context API to search, scrape, and interact with the web at scale. 🔥

## Summary

- **Core Functionality**: Firecrawl provides an open-source API for AI agents to **search**, **scrape**, and **interact** with web content at scale, returning structured data (Markdown/JSON) and screenshots with 96% coverage, including JS-heavy pages.

- **Performance Metrics**: Achieves **P95 latency of 3.4s** with **93% fewer input tokens** (clean markdown output) and supports **real-time interactions** (clicks, navigation, form filling) via a unified API.

- **Integration & Use Cases**: Supports **Python/Node.js/CLI** with MCP/Skills integration for AI agents; validated by **150K+ companies** (e.g., Shopify, Zapier, Replit) for tasks like **lead enrichment**, **deep research**, and **AI chat augmentation**.
