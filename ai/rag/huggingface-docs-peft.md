# PEFT · Hugging Face

## Summary

- **Parameter-Efficient Fine-Tuning (PEFT)**: A Hugging Face library enabling efficient adaptation of large pretrained models by fine-tuning only a small subset of parameters, reducing computational/storage costs while maintaining performance comparable to full fine-tuning.

- **Integration & Methods**: PEFT integrates with Transformers, Diffusers, and Accelerate libraries, supporting diverse adaptation techniques (e.g., LoRA, adapters, soft prompting) via modular frameworks and reference implementations for arbitrary model weight modifications.

- **Hardware Accessibility**: Designed to make training/inference of LLMs feasible on consumer hardware by minimizing parameter updates, with support for distributed training (DeepSpeed, FSDP), quantization, and memory-efficient techniques.
