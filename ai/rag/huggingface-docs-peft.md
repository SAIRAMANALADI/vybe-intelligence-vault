# PEFT · Hugging Face

## Summary

- **Parameter-Efficient Fine-Tuning (PEFT)**: A library enabling efficient adaptation of large pretrained models by fine-tuning only a small subset of parameters, reducing computational/storage costs while maintaining performance comparable to full fine-tuning.

- **Integration & Methods**: Supports integration with Transformers, Diffusers, and Accelerate; provides a framework for arbitrary model adaptation methods (e.g., weight modification, layer wrapping, KV-cache manipulation) and includes implementations of methods like LoRA, AdaLoRA, and prefix tuning.

- **Hardware Accessibility**: Designed to make training and inference of LLMs feasible on consumer hardware by minimizing resource requirements through selective parameter updates.
