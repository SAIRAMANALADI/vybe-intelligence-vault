# [2005.11401] Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks

## Summary

- **RAG Architecture**: Proposes retrieval-augmented generation (RAG) models combining a pre-trained seq2seq model (parametric memory) with a dense vector index of Wikipedia (non-parametric memory) accessed via a pre-trained neural retriever, enabling dynamic knowledge integration during generation.

- **Two RAG Variants**: Introduces two formulations—one using fixed retrieved passages for the entire sequence and another allowing per-token retrieval—demonstrating improved performance on knowledge-intensive tasks like open-domain QA.

- **Performance Gains**: Achieves state-of-the-art results on three open-domain QA benchmarks, outperforming both parametric-only seq2seq models and task-specific retrieve-and-extract architectures, while generating more specific, diverse, and factual language.
