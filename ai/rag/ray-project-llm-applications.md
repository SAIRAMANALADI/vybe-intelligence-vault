# ray-project/llm-applications

## Summary

- **RAG Pipeline Integration**: Demonstrates production-grade Retrieval-Augmented Generation (RAG) workflows using Ray for distributed serving, with modules for vector DB indexing (e.g., FAISS/Weaviate) and LLM inference (e.g., Llama2, OpenAI API).
- **Fine-Tuning & Optimization**: Includes notebooks for fine-tuning LLMs (e.g., LoRA, QLoRA) and optimizing serving performance via Ray’s actor-based parallelism and dynamic batching.
- **Deployment Toolkit**: Provides end-to-end deployment templates for scalable LLM services, covering pre-processing, retrieval, generation, and post-processing with Anyscale-compatible integrations.
