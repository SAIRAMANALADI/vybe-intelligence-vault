# [2209.10317] Android Private Compute Core Architecture

## Summary

- **Isolated Execution Environment**: Android's Private Compute Core (PCC) is a secure, isolated environment within the OS, introduced in Android 12, designed to process ambient and OS-level data while maintaining strict separation from apps and untrusted system components.

- **Private Compute Services (PCS)**: PCC hosts updatable, closed-source ML features that communicate with servers via PCS to receive model updates and contribute to federated learning, ensuring user data remains unexposed to servers or apps.

- **Security & Isolation Mechanisms**: PCC leverages OS-level isolation (e.g., SELinux policies, hardware-backed keystores) to enforce constraints, preventing unauthorized data exfiltration while enabling on-device ML feature improvements.
