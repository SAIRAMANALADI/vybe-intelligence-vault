# pathwaycom/llm-app

## Summary

- **Cloud-native RAG & AI pipelines**: Pre-configured templates for Retrieval-Augmented Generation (RAG), AI workflows, and enterprise search, optimized for Docker deployment and real-time data synchronization with SharePoint, Google Drive, S3, Kafka, PostgreSQL, and live APIs.

- **Multi-source data integration**: Supports live data ingestion from 10+ sources (e.g., SharePoint, S3, Kafka) with vector database indexing and real-time updates, enabling up-to-date LLM responses without manual refreshes.

- **Security & compliance focus**: Includes LLM security best practices, local LLM deployment options (via Hugging Face), and LLMops tooling for prompt management, retrieval optimization, and enterprise-grade vector search capabilities.
