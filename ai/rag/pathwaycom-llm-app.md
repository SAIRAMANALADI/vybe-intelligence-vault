# pathwaycom/llm-app

## Summary

- **Cloud-native RAG & AI pipelines**: Pre-configured templates for Retrieval-Augmented Generation (RAG), AI workflows, and enterprise search, supporting real-time data synchronization with SharePoint, Google Drive, S3, Kafka, PostgreSQL, and REST APIs.

- **Docker-optimized & scalable**: Containerized (🐳) deployment with live data integration, enabling modular, reproducible AI/ML pipelines for production-grade applications.

- **Multi-LLM & vector DB support**: Compatible with Hugging Face, OpenAI, and local LLMs, featuring built-in vector databases/indexes for efficient retrieval and prompting in secure (llm-security) LLMops workflows.
