# pathwaycom/llm-app

## Summary

- **Purpose**: Provides pre-configured cloud templates for **Retrieval-Augmented Generation (RAG)**, AI pipelines, and enterprise search with **real-time data synchronization** from SharePoint, Google Drive, S3, Kafka, PostgreSQL, and APIs.
- **Technical Stack**: Docker-friendly, uses **Jupyter Notebooks**, integrates with **Hugging Face**, **OpenAI**, and **Pathway**, with support for **vector databases**, **LLM prompting**, and **LLM security**.
- **Features**: Supports **LLMOps**, **local LLM deployment**, **real-time data ingestion**, and **vector indexing**, optimized for scalable enterprise use cases.
