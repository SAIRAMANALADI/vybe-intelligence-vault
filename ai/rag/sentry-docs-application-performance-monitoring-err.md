# Sentry Docs | Application Performance Monitoring & Error Tracking Software

## Summary

- **Distributed Tracing & Error Monitoring**: Sentry provides end-to-end distributed tracing and error monitoring across systems/services, enabling identification and debugging of performance issues and errors via features like Error Monitoring, Tracing, Session Replay, and Logs.

- **AI-Powered Debugging & Autofix**: Integrates AI-driven tools like [Seer](https://docs.sentry.io/product/ai-in-sentry/seer/) for AI-powered debugging, autogenerated fixes, and code review automation, leveraging application data within Sentry for contextual insights.

- **Multi-Platform SDKs & AI Integration**: Supports extensive platform-specific SDKs (e.g., JavaScript, Python, Android, Unity) and enables AI coding assistant integration via [Skills](https://docs.sentry.io/ai/agent-skills/) and [MCP server](https://mcp.sentry.dev) for monitoring AI features.
