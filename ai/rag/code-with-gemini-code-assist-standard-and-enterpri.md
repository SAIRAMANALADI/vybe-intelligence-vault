# Code with Gemini Code Assist Standard and Enterprise | Gemini for Google Cloud | Google Cloud Documentation

## Summary

- **Deprecation & Migration**: Google's Gemini Code Assist IDE Extensions and CLI for individual tiers (Gemini Code Assist, Google AI Pro/Ultra) are deprecated as of June 18, 2026, with users directed to migrate to the unified **Antigravity** platform and **Antigravity CLI** for continued support.

- **Core Functionality**: Gemini Code Assist provides AI-powered code generation, completions, and transformations in supported IDEs (VS Code, IntelliJ, JetBrains) via natural language prompts (`/generate`, `/fix`, `/doc`, `/simplify`) or comments, with changes previewed in diff views before acceptance.

- **Advanced Features**: Supports **Next Edit Predictions** (preview) for multi-location code suggestions, **code customization** (Enterprise) for organization-specific private codebase integration, and inline completions with configurable shortcuts; conflicts may arise with other plugins using overlapping APIs.
