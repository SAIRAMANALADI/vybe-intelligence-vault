# Vite 7.0 is out! | Vite

## Summary

- **Rolldown Integration**: Vite 7 introduces `rolldown-vite`, a Rust-based next-gen bundler (Rolldown) replacing the default Vite bundler, offering significant build time improvements, particularly for larger projects. Rolldown will become the default bundler in future releases.

- **Node.js & Browser Target Updates**: Requires Node.js 20.19+ or 22.12+ (dropping Node.js 18), enabling ESM-only distribution. Default browser target shifts to `'baseline-widely-available'`, updating minimum versions (e.g., Chrome 107, Firefox 104, Safari 16.0).

- **Environment API & Vitest Support**: Experimental Environment API gains a `buildApp` hook for coordinated environment builds. Vite 7 is compatible with Vitest 3.2, enhancing testing workflows.
