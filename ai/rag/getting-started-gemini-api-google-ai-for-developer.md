# Getting started | Gemini API | Google AI for Developers

## Summary

- **Interactions API Availability**: The [Interactions API](https://ai.google.dev/gemini-api/docs/interactions-overview) is now generally available via Python, JavaScript SDKs, and REST, replacing the legacy `generateContent` API for latest features and models.

- **Stateful vs. Stateless Multi-Turn**: Supports two conversation modes—**stateful** (server-managed history via `previous_interaction_id`) for optimized caching and **stateless** (client-managed history with `store=false`) requiring manual step preservation.

- **Multimodal Input Handling**: Native support for images, audio, video, and documents in a single request, with base64-encoded local media or URI-based remote assets (e.g., `image/jpeg`, `audio/mp3`).
