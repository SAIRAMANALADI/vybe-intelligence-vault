# Eric and Wendy Schmidt to fund space telescope, three ground-based observatories

## Summary

- **Lazuli Space Telescope**: 3-meter aperture, coronagraph-equipped space telescope with rapid slewing capability for exoplanet imaging/atmospheric spectroscopy and transient event detection; designed for 3-year development cycle with launch targeted for 2028, leveraging modern GPU-based processing (e.g., Nvidia Orin cluster) and costing "hundreds of millions" of dollars.

- **Ground-Based Facilities**:
  - **Argus Array**: >1,000 small telescopes forming an 8m-class optical imager with continuous all-sky monitoring (1Hz cadence in some regions), generating up to 7.8 PB/night via GPU processing; optimized for gravitational wave counterpart and supernova detection.
  - **LFAST**: Scalable spectroscopic array using fiber-fed subarrays (20x30" telescopes each) with planned 30m-class equivalent collecting area; targets exoplanet biosignatures and supernovae.
  - **DSA**: 1,650-dish radio array in Nevada using uncooled receivers for real-time imaging ("radio camera") with reduced data processing overhead.

- **Operational Model**: Open-data, merit-based access for all facilities; Schmidt Sciences funds full construction/operation (no reserved time), with plans to de-risk projects for potential future public co-funding—contrasting with NASA/NSF paradigms by prioritizing rapid deployment over technology maturation.
