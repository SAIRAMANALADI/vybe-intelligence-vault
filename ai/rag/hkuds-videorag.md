# HKUDS/VideoRAG

## Summary

- **VideoRAG Framework**: Introduces a Retrieval-Augmented Generation (RAG) system enabling LLMs to process and interact with long videos via multi-modal embeddings and retrieval mechanisms.

- **Key Features**: Supports long-video understanding through hierarchical chunking, multi-modal fusion (visual + audio + text), and dynamic retrieval for context-aware responses.

- **Technical Stack**: Implemented in Python with PyTorch, leveraging pre-trained vision-language models (e.g., CLIP, BLIP) and optimized for scalability with GPU acceleration.
