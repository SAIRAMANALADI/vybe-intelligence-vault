# HKUDS/VideoRAG

## Summary

- **VideoRAG Framework**: Introduces a Retrieval-Augmented Generation (RAG) system enabling LLMs to process and answer queries about long-form videos by integrating multi-modal embeddings and hierarchical retrieval mechanisms.

- **Multi-Modal Architecture**: Combines vision-language models (e.g., CLIP) with LLMs (e.g., LLaMA) to extract and align visual, audio, and textual features for comprehensive video understanding.

- **Efficient Retrieval**: Implements chunk-based indexing and dynamic retrieval strategies to handle long-duration videos, reducing computational overhead while maintaining contextual relevance.
