# HKUDS/VideoRAG

## Summary

- **VideoRAG Framework**: Introduces a Retrieval-Augmented Generation (RAG) system for long-video understanding, enabling LLMs to process and interact with video content via multi-modal inputs (video, text, or audio).

- **Technical Implementation**: Leverages Python with PyTorch/TensorFlow, integrating vision-language models (e.g., CLIP, BLIP) and LLMs (e.g., LLaMA, Vicuna) to segment, embed, and retrieve video frames/chunks for context-aware generation.

- **Key Features**: Supports hierarchical retrieval (frame → shot → scene), dynamic chunking, and cross-modal alignment, optimizing for scalability (tested on 100+ hour videos) and real-time interaction.
