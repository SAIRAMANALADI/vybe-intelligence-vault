# Textile Markup Language Documentation

## Summary

- **Textile Syntax**: A lightweight markup language using shorthand syntax (e.g., `*strong*`, `_emphasis_`, `h1.` for headings) to generate HTML, supporting block-level (paragraphs, lists, tables) and inline formatting (bold, italics, superscript/subscript) with modifiers for alignment, padding, and CSS classes/IDs.

- **Block & Inline Processing**: Text blocks are separated by blank lines, with block signatures (e.g., `p.`, `bc.`, `bq.`) defining formatting; inline formatting uses paired symbols (e.g., `**bold**`, `^superscript^`) and can be combined (e.g., `***~~deleted bold emphasized text~~***`).

- **Automatic Conversions & Special Elements**: Converts plain text to typographic elements (e.g., `"quotes"` → “quotes”, `--` → —) and symbols (e.g., `(tm)` → ™); supports lists (bulleted, numbered, definition), tables, footnotes, links, and images with dedicated syntax.
