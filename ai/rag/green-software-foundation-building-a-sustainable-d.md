# Green Software Foundation — Building a Sustainable Digital Future

## Summary

- **Industry Collaboration**: The Green Software Foundation (GSF) is a global consortium uniting tech giants (e.g., Google, Microsoft, IBM), financial institutions (e.g., Goldman Sachs, UBS), and academic/research entities (e.g., MIT, Chalmers University) to collaboratively address sustainability challenges in software development and deployment.

- **Standardization & Open-Source Development**: GSF drives the creation of open standards and frameworks (e.g., Software Carbon Intensity [SCI] specification) to quantify and reduce digital carbon emissions, enabling cross-organizational alignment and scalable solutions.

- **Membership-Driven Ecosystem**: Membership includes 100+ organizations across sectors, fostering shared tooling (e.g., Carbon-Aware SDK), best practices, and policy advocacy to decarbonize digital infrastructure collectively.
