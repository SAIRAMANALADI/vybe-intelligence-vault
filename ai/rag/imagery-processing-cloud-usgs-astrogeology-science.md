# Imagery Processing Cloud - USGS Astrogeology Science Center - Process NASA Images of Moon, Mars, Jupiter, Saturn. . .

## Summary

- **MAP Processing Pipeline**: Enables on-demand map projection, clipping, band algebra (Fx functions), and format conversion (ISIS, PDS3, GeoTIFF, JPEG, PNG) for planetary image mosaics, supporting downstream analysis in GIS/remote sensing tools (e.g., ArcMAP, ENVI, JMARS).

- **Toolchain Integration**: Leverages **ISIS 3+** for planetary image processing, **GDAL** for format conversion (ISIS→GeoTIFF/JPEG/PNG), and **PDS3** standards for archival compliance; Astropedia provides curated mosaics for input.

- **Workflow Automation**: Users submit processing requests via email with parameters (projection, resolution, format); outputs are delivered asynchronously, enabling batch processing for large-scale planetary datasets.
