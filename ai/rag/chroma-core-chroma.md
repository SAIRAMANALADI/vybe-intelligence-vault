# chroma-core/chroma

## Summary

- **Rust-based vector database**: Chroma is a high-performance, open-source vector database optimized for AI workloads, enabling efficient storage and retrieval of embeddings for similarity search and machine learning applications.

- **AI-native search infrastructure**: Provides specialized search capabilities for AI agents, including metadata filtering, hybrid search (vector + keyword), and integration with LLMs for context-aware retrieval.

- **Scalable and embeddable**: Designed for horizontal scalability with a client-server architecture, supporting both in-memory and persistent storage modes for deployment flexibility in production environments.
