# Firebase | Google's Mobile and Web App Development Platform

## Summary

- **Cross-platform SDKs**: Firebase provides unified SDKs for iOS, Android, Web, Flutter, Unity, and C++ to streamline multi-platform app development and deployment.

- **AI/ML Integration**: Offers managed services like **Firebase AI Logic**, **Agent Skills**, and **Generative AI** (e.g., Gemini) for embedding AI-powered features (e.g., logic automation, agent assistance) into apps with Google Cloud-backed infrastructure.

- **Modular Ecosystem**: Includes **Build** (e.g., App Hosting, Firestore, Authentication), **Run** (e.g., Crashlytics, Remote Config, A/B Testing), and **Extensions** (e.g., Stripe payments, Algolia search) for scalable, extensible app lifecycle management.
