# Neon — Postgres backends for apps and agents

## Summary

- **Lakebase Postgres**: Serverless PostgreSQL database with compute-storage separation, enabling dynamic autoscaling of CPU/memory/storage and instant branching via copy-on-write snapshots for isolated development/testing environments.

- **Managed Better Auth**: Built-in authentication system with user/session management natively integrated into Postgres, eliminating external auth service dependencies while supporting HIPAA/SOC2 compliance.

- **AI Gateway & Databricks Integration**: Unified API for LLM access with usage-based billing, powered by Databricks, alongside S3-compatible object storage and long-running serverless functions with no execution timeouts.
