# Neon — Postgres backends for apps and agents

## Summary

- **Lakebase Postgres**: Serverless PostgreSQL with compute-storage separation, enabling dynamic autoscaling of CPU/memory/storage and instant branching via copy-on-write snapshots for isolated development/testing environments.

- **Managed Better Auth**: Built-in authentication system with user/session management directly in Postgres, eliminating external auth service dependencies while supporting HIPAA/SOC2 compliance and SSO integration.

- **AI Gateway & Object Storage**: Unified API for LLM model access (powered by Databricks) and S3-compatible blob storage with project-level branching, enabling scalable AI-driven applications with consistent data lineage.
