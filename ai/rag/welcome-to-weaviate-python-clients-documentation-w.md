# Welcome to Weaviate Python Client’s documentation! — Weaviate Python Client 4.22.0 documentation

## Summary

- **Client Overview**: The Weaviate Python Client v4 is an AI-native vector database client for Python 3.8+, replacing the deprecated v3 client. It provides synchronous (`WeaviateClient`) and asynchronous (`WeaviateAsyncClient`) interfaces for interacting with Weaviate.
- **Installation & Agents**: Installed via `pip install -U weaviate-client`, with optional agent support (`[agents]`) requiring a Weaviate Cloud (WCD) instance for LLM-related tasks like querying, transformation, and personalization.
- **API & Support**: Includes detailed API references (e.g., `WeaviateClient`, `WeaviateAsyncClient`, exceptions, and agents like `QueryAgent`). Support channels include a community forum, StackOverflow, and GitHub issues.
