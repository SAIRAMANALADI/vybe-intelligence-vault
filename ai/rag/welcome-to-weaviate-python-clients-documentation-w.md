# Welcome to Weaviate Python Client’s documentation! — Weaviate Python Client 4.22.0 documentation

## Summary

- **Python Client v4** is the current major version for Weaviate, replacing the deprecated v3; supports Python 3.8+ and integrates with Weaviate’s AI-native vector database.
- **Optional Agents Support** (`[agents]` extra) enables agentic services (e.g., QueryAgent, TransformationAgent) for LLM tasks, requiring a Weaviate Cloud (WCD) instance.
- **API Reference** includes `WeaviateClient`/`WeaviateAsyncClient` classes, exception handling, and agent modules (e.g., `QueryAgent`) for structured interactions with Weaviate.
