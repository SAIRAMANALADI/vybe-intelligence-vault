# [2410.22375] Rethinking Code Refinement: Learning to Judge Code Efficiency

## Summary

- Proposes a code language model trained to **judge code efficiency** by classifying superior versions or predicting relative improvement between two code snippets, addressing inefficiencies in LLM-generated code refinements.

- Validates method across **multiple programming languages and refinement steps**, demonstrating robust performance in distinguishing more efficient code variants without exhaustive runtime comparisons.

- Introduces a **novel efficiency-judging framework** that bypasses costly execution-based evaluation, leveraging learned models to optimize code refinement pipelines.
