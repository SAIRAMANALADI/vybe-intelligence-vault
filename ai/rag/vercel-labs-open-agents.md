# vercel-labs/open-agents

## Summary

- **Purpose**: Provides a TypeScript-based open-source template for constructing cloud-based AI agents with background processing capabilities.

- **Key Features**: Supports multi-agent architectures, integrates with Vercel’s serverless functions, and includes pre-configured tooling for agent orchestration.

- **Technical Stack**: Built on Next.js (App Router), TypeScript, and leverages Vercel’s AI SDK for agent runtime and deployment.
