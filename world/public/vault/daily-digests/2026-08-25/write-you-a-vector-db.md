## Summary
Write You a Vector Database is a Rust-first educational course that teaches how to build an in-memory vector database from scratch, integrating vector search algorithms with SQL via DataFusion. It covers IVFFlat, NSW, HNSW, and benchmarking for recall and latency.

## Key Features
- Step-by-step Rust implementation of vector search algorithms (IVFFlat, NSW, HNSW)
- Integration with SQL via DataFusion for query planning and execution
- Comprehensive benchmarking for recall and latency comparisons
- Includes starter code, tests, and reference implementations
- Focus on exposing algorithms and evaluation contracts for SQL vector search

## Why It Matters for RAG Builders
It provides deep insights into the internals of vector databases and their integration with SQL, essential for building optimized RAG systems.
