## Summary
Vibe MCP is an MCP server that enables AI agents to control a user's real, logged-in Chrome browser via a secure relay or direct DevTools Protocol connection. It allows multi-agent collaboration on a single browser instance, even when agents run on remote machines without inbound ports.

## Key Features
- Enables AI agents to control a user's real Chrome browser with logged-in sessions
- Supports multi-agent collaboration on a single browser instance via a relay
- Works with agents on remote machines without requiring inbound ports
- Offers both relay-based and direct DevTools Protocol (CDP) modes for flexibility
- Secure authentication via UUID or relay URL, treated as a password

## Why It Matters for RAG Builders
It bridges the gap between AI agents and real-world browser interactions, enabling secure, multi-agent control of a user's actual browser sessions for tasks requiring real-time web access.
