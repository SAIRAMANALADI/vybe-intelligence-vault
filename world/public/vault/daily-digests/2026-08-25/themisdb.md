## Summary
ThemisDB is a high-performance multi-model database engine with native AI/LLM integration, supporting relational, graph, vector, document, geospatial, and time-series storage in a single system. It is designed for distributed environments with ACID transactions, RAG pipelines, and enterprise-grade security features.

## Key Features
- Supports 6 data models (relational, graph, vector, document, geospatial, time-series) in a single engine
- Native AI/LLM integration with embedded inference (llama.cpp, ONNX) and RAG pipeline support
- Distributed architecture with Raft consensus, sharding, and auto-failover for high availability
- Enterprise-grade security with AES-256 encryption, RLS, Zero-Trust policies, and HSM/Vault integration
- Hybrid search combining BM25 and vector retrieval with RRF ranking for advanced RAG applications

## Why It Matters for RAG Builders
ThemisDB is essential for RAG builders as it provides a unified, high-performance multi-model database with native AI/LLM capabilities, enabling seamless integration of vector search, hybrid retrieval, and distributed transaction support for scalable AI applications.
