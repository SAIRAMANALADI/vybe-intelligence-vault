## Summary
TripStar is a multi-agent travel planning system built with Spring Boot 4 and Spring AI Alibaba, enabling AI-driven itinerary generation with real-time data from Xiaohongshu (Little Red Book), Amap, and weather services. It supports autonomous planning and note-based planning with multimodal understanding.

## Key Features
- Dual-mode planning: autonomous and note-based itinerary generation with Xiaohongshu content integration
- StateGraph-driven agent workflow with Spring AI Alibaba for orchestration and conditional logic
- Real-time data integration from Amap (POI, weather, hotels, restaurants) and Xiaohongshu (travel notes, images)
- Multimodal understanding of travel notes using vision models to extract structured itinerary data
- AI Trace logging for debugging agent decisions, tool calls, and structured output parsing

## Why It Matters for RAG Builders
This framework demonstrates a production-ready multi-agent system for AI-driven travel planning, showcasing advanced orchestration, multimodal data processing, and real-time API integrations critical for building scalable RAG applications.
