## Summary
A Model Context Protocol (MCP) server that provides traditional Chinese divination services, including Bazi (八字) analysis, Liu Yao (六爻) divination, fortune-telling, name evaluation, and a programmer-themed almanac. It generates visually rich, ink-wash style HTML reports with zero external dependencies beyond the MCP SDK.

## Key Features
- Six divination tools: Bazi, Liu Yao, fortune-telling, name evaluation, naming, and programmer almanac
- Generates visually distinct ink-wash style HTML reports with traditional Chinese aesthetics
- Zero external dependencies (only MCP SDK)
- Supports integration with Claude Code, Codex, OpenCode, Cursor, Windsurf, and other MCP-compatible tools
- Programmer-focused humor in the almanac tool for team engagement
