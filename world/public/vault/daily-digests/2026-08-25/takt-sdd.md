## Summary
takt-sdd is a Spec-Driven Development (SDD) workflow automation tool that uses takt's state-machine-based workflows to manage AI agent execution paths. It enables deterministic, declarative control over AI-driven development workflows from requirements to implementation and validation.

## Key Features
- Declarative workflow control using YAML-based state machines for deterministic AI agent execution paths
- Faceted prompting system separating concerns into reusable components (Persona, Policy, Instruction, Knowledge, Output Contract)
- Multi-stage validation gates for requirements, design, and implementation to detect issues early
- Loop detection and supervisory control to prevent unproductive repetitive patterns in AI workflows
- Provider-agnostic workflow execution supporting multiple AI providers like Claude and Codex

## Why It Matters for RAG Builders
It provides a structured, deterministic framework for orchestrating AI-driven development workflows, ensuring consistency and reliability in AI agent execution paths critical for RAG and AI stack builders.
