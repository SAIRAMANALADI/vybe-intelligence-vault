## Summary
UXON AI provides a Claude skills-style agent playbook, MCP server, and CRO API for automating post-click marketing workflows. It enables programmatic landing page creation, A/B testing, conversion tracking, and agency operations through a unified API and MCP connector.

## Key Features
- Programmatic landing page creation and management via API or MCP
- Cross-domain A/B testing and split-testing with first-party attribution
- Conversion tracking and CRO reporting with GTM/GA4/Meta integration
- Agent-friendly command playbook (SKILLS.md) for guided workflows
- Agency operations automation for onboarding, reporting, and optimization

## Why It Matters for RAG Builders
UXON AI streamlines post-click marketing automation for RAG builders by providing a unified API and MCP server to programmatically manage landing pages, A/B tests, and conversions without manual intervention.
