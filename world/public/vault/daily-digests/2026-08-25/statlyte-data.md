## Summary
statlyte provides real-time pricing, context windows, and identifiers for major LLM APIs, eliminating the need to hardcode stale model data. It dynamically fetches and caches pricing information from vendor pages, ensuring accuracy and reducing manual maintenance overhead.

## Key Features
- Fetches live pricing from 8 major LLM providers (Anthropic, OpenAI, Google, etc.) every 3 hours
- Zero dependencies and MIT licensed for easy integration
- Includes bundled snapshot fallback for offline reliability
- Provides tools like `scheduledChanges()` to alert about upcoming price increases
- Offers MCP server integration for AI agents to access current pricing data

## Why It Matters for RAG Builders
It ensures RAG/AI stack builders avoid costly inaccuracies by using up-to-date LLM pricing data instead of hardcoded or stale figures.
