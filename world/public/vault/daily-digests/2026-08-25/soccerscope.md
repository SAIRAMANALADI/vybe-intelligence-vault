## Summary
SoccerScope is a multilingual RAG AI agent designed to scout viral World Cup 2026 football (soccer) videos across multiple countries, analyze fan comments, and generate ready-to-use reports, social media drafts, or shareable web pages in English or Japanese. It integrates with MongoDB Atlas for vector search and leverages the Google Agent Development Kit with Gemini models for real-time content processing.

## Key Features
- Multilingual RAG agent for viral sports video discovery and analysis
- Integration with MongoDB Atlas for vector search and real-time data processing
- Automated daily data ingestion pipeline for YouTube videos and comments
- Generates reports, social media drafts, or web pages in English or Japanese
- Uses Google ADK and Gemini models for structured agent workflows and embeddings

## Why It Matters for RAG Builders
