## Summary
A project-centric CLI agent for DeepSeek that operates as a tool within a workspace, enabling adaptive reasoning, resumable sessions, memory management, and safe tool execution for coding and analysis tasks in WSL environments.

## Key Features
- Adaptive task execution modes (simple, standard, large, deep) with configurable round limits and effort tiers
- Resumable sessions with checkpointing and state persistence for long-running tasks
- Structured context building with bounded input/output handling and automatic compaction
- Memory lifecycle management with reflection, corrections, and lessons learned
- Safe tool execution with permission controls, concurrency-safe operations, and circuit breakers for failures

## Why It Matters for RAG Builders
It provides a robust, project-centric agent framework with adaptive reasoning and resumable sessions, essential for automating complex coding and analysis tasks in AI engineering workflows.
