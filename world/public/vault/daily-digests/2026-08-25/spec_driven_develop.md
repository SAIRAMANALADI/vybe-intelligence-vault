## Summary
Spec-Driven Develop provides an architecture-first workflow plugin for AI coding agents, enabling spec-driven development through Markdown-based skills. It automates large-scale software changes with task decomposition, GitHub Issue/PR tracking, and adaptive control, while supporting structured problem analysis and findings-first code reviews.

## Key Features
- Automates full development pipeline for large-scale tasks with 6-phase workflow (analysis, decomposition, tracking, execution, and archiving)
- Supports GitHub-native task tracking with Issues, Milestones, Labels, and batch PRs for dependency-aware delivery
- Includes adaptive control inspired by engineering cybernetics to correct plan drift during execution
- Provides structured deep-discussion workflow (Deep Discuss) for problem analysis and solution design
- Offers findings-first code review workflow (Review SPD) for uncommitted changes, date-range commits, and branch/PR diffs
