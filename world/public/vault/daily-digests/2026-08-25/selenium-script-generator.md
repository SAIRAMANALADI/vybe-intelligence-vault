## Summary
This repository provides an AI agent that converts plain-English test scenarios into runnable Selenium (Python) tests following the Page Object Model, explicit waits, and meaningful assertions. It enforces coding standards via a linter to ensure high-quality test generation.

## Key Features
- Converts plain-English test scenarios into executable Selenium Python scripts
- Enforces Page Object Model for maintainable test structure
- Uses explicit waits (WebDriverWait) to avoid flaky tests
- Includes a linter to validate generated code against house rules
- Supports offline mode for basic scenario parsing without API dependencies

It ensures generated test code adheres to senior QA standards, reducing flakiness and improving maintainability in automated testing pipelines.
