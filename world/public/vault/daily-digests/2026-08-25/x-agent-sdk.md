## Summary
x-agent-sdk is an unofficial TypeScript client and MCP server for interacting with X (Twitter)'s private GraphQL API using session cookies. It enables programmatic access to posting, reading, and engaging with tweets without OAuth, while also providing an MCP-compatible interface for AI agents.

## Key Features
- Dual-mode operation: TypeScript library or MCP server for AI agents
- Cookie-based authentication bypassing OAuth and paid APIs
- Automatic generation of `x-client-transaction-id` headers to avoid rate-limiting
- Multi-account support via environment variables or `X_ACCOUNTS` JSON configuration
- Built-in MCP server with 25+ tools for AI agents, including posting, searching, and engagement actions

## Why It Matters for RAG Builders
It provides a critical bridge for AI agents to interact with X (Twitter) programmatically without relying on unstable or restricted public APIs, enabling real-time social media integration for RAG and agentic workflows.
