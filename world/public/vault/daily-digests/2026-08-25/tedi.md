## Summary
TEDI (Terminal Director) is a lightweight, Tauri-based desktop application that consolidates eight essential developer tools—terminal, SSH client, DB browser, code editor, AI agent, browser, Git, and workspace manager—into a single window to eliminate context switching. It prioritizes performance, privacy, and extensibility with no Electron dependency, no telemetry, and support for local AI models.

## Key Features
- Unified workspace with terminal multiplexer, SSH client, and Git integration
- Built-in AI agent supporting 10+ providers and local models (LM Studio, Ollama, etc.)
- In-app AI-driven browser for automated navigation, testing, and debugging
- Extension system for runtime-installable tools (e.g., SQL explorer, Discord Rich Presence)
- Privacy-focused with no telemetry, OS keychain integration, and offline AI support

## Why It Matters for RAG Builders
TEDI streamlines developer workflows by consolidating critical tools into a single, lightweight window while offering robust AI integration, making it ideal for AI engineering teams seeking efficiency and extensibility.
