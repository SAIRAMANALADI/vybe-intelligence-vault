## Summary
A bidirectional Model Context Protocol (MCP) integration server for Strands Agents, enabling agents to act as both MCP servers and clients. It facilitates communication between Strands agents and external tools, clients, or other agents via HTTP, stdio, or SSE protocols.

## Key Features
- Bidirectional MCP server and client capabilities for Strands Agents
- Supports multiple transport protocols (HTTP, stdio, SSE)
- Enables remote tool invocation and agent access
- CLI for local and proxy mode deployment
- Stateless mode for multi-node scalability

## Why It Matters for RAG Builders
It bridges Strands Agents with external tools and clients via MCP, enabling seamless integration and interoperability in AI agent ecosystems.
