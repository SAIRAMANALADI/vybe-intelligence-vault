## Summary
A TypeScript-based CLI tool that automates the creation of production-ready, SEO-optimized HTML pages using AI agents. It performs SERP research, content drafting, on-page SEO optimization, and generates structured artifacts for review and deployment.

## Key Features
- End-to-end SEO page creation from a single website URL input
- SERP and competitor research integration for evidence-backed content
- Structured artifact generation (SEO briefs, outlines, drafts, QA reports)
- Local HTML preview for immediate review and adaptation
- Support for multiple AI coding agents (Codex, Gemini CLI, Antigravity)

## Why It Matters for RAG Builders
It streamlines the creation of high-quality, research-backed SEO content, reducing manual effort and ensuring alignment with search intent and business context for RAG builders.
