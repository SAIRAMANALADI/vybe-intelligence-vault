## Summary
A Model Context Protocol (MCP) server that enables task-specific AI sub-agents defined in Markdown files to be executed across any MCP-compatible tool, such as Cursor, Claude Desktop, or Windsurf. It bridges the gap between Claude Code's sub-agent workflows and other AI tools by providing portable agent definitions and execution capabilities.

## Key Features
- Portable sub-agent definitions in Markdown files for reuse across tools
- Support for multiple execution engines (Cursor, Claude Code, Codex, Gemini CLI, Grok Build, GLM)
- Session management and error handling for robust agent execution
- Customizable permission levels (read-only, safe-edit, yolo) for security
- Cross-platform compatibility with absolute path requirements for agent directories

## Why It Matters for RAG Builders
It enables AI engineers to standardize and reuse sub-agent workflows across diverse MCP-compatible tools, reducing setup overhead and improving consistency in AI-driven development tasks.
