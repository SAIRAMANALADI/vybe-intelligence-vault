## Summary
A Model Context Protocol (MCP) server that integrates the Travelpayouts API to enable AI assistants like Claude to perform flight and hotel searches, price comparisons, and travel-related lookups via 13 specialized tools.

## Key Features
- 13 specialized tools for flight and hotel searches via Travelpayouts API
- Supports flexible date pricing, price calendars, and direct route filtering
- Includes airport, airline, and city lookup utilities
- Handles rate limiting with exponential backoff retries
- Designed for seamless integration with AI assistants like Claude

## Why It Matters for RAG Builders
It enables AI assistants to perform real-time travel searches and bookings, enhancing user experience in AI-driven travel planning applications.
