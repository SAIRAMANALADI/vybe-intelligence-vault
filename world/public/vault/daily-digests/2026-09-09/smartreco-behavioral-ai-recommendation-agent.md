## Summary
SmartReco is an agentic AI recommendation platform that observes user behavior to dynamically generate personalized course recommendations using a dual-write vector database (ChromaDB) and NVIDIA Llama 3.1 70B LLM. It combines real-time RAG, behavioral analytics, and automated email digests for an interactive learning experience.

## Key Features
- Dual-write vector database (ChromaDB + SQLite) for real-time semantic retrieval and metadata synchronization
- NVIDIA Llama 3.1 70B-powered universal AI assistant with RAG-grounded responses for course recommendations and technical guidance
- Non-blocking client-side behavioral event tracking (page views, dwell time, hovers) with silent batch transmission
- LangGraph agentic workflow engine for multi-node reasoning, query expansion, and recommendation synthesis
- Proactive email digests and 6-digit Gmail OTP verification for secure user onboarding

## Why It Matters for RAG Builders
SmartReco provides a production-ready agentic framework for building behavior-driven recommendation systems with RAG, making it essential for AI engineers focused on personalized learning and dynamic content delivery.
