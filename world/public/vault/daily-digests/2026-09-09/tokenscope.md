## Summary
tokenscope is a local, read-only CLI tool that analyzes AI-coding session logs (e.g., Claude Code) to break down costs into model output, re-sent context, and cache operations. It provides actionable insights to optimize token usage and reduce unexpected bills.

## Key Features
- Parses and attributes AI session costs (output, cache read/write, fresh input)
- Provides per-turn context size tracking and peak/average metrics
- Generates shareable summaries (Markdown/SVG) for privacy-safe reporting
- Offers an MCP server for AI agent integration (e.g., Claude Desktop)
- Supports custom pricing overrides and model-specific cost calculations

## Why It Matters for RAG Builders
It helps AI engineers and developers identify hidden costs in agentic coding sessions by revealing where tokens are wasted, enabling optimization and significant cost reduction.
