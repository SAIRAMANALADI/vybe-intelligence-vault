## Summary
wheel-hub is an MCP server and CLI tool that helps AI coding agents and developers search, evaluate, and adopt open-source solutions before reinventing the wheel. It scores repositories based on popularity, momentum, maintenance, and trust, providing adopt/adapt/inspect/avoid verdicts.

## Key Features
- Search GitHub for existing solutions to specific problems or features
- Score repositories on popularity, momentum, maintenance, and trust (0-100 scale)
- Provide clear verdicts (adopt/adapt/inspect/avoid) for evaluated repositories
- MCP server integration for AI coding agents like Claude Code and Cursor
- CLI tool for human developers to perform one-off searches or evaluations

## Why It Matters for RAG Builders
It reduces redundant development effort by enabling AI agents and developers to discover and evaluate existing open-source solutions before building new ones.
