## Summary
Thane is an autonomous AI agent designed to understand and act on home automation data, such as sensors and device states, by learning routines, preferences, and context through natural conversation. It integrates with Home Assistant and runs locally on user hardware, prioritizing privacy and cost-efficiency.

## Key Features
- Autonomous discovery and action on home automation devices without pre-configuration
- Persistent memory for learned preferences and routines across restarts
- Privacy-first architecture with all data stored locally in SQLite
- Multi-model routing to optimize cost and performance (local vs. cloud models)
- Single binary deployment with optional containerization for ease of use

## Why It Matters for RAG Builders
Thane provides a privacy-preserving, autonomous agent framework for home automation that reduces reliance on cloud services while enabling advanced AI-driven interactions with smart devices.
