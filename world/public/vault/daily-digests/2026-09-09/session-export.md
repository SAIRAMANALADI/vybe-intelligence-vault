## Summary
UniSessions is an SDK-first AI CLI session converter that enables seamless migration of AI coding sessions between multiple platforms (Codex, Claude Code, Pi, OpenCode, Devin, Factory, Windsurf) with trace export capabilities for HuggingFace and fine-tuning.

## Key Features
- Supports 42 conversion directions between 7 major AI coding agents
- Trace export in 3 formats (HuggingFace STS, OpenAI, ShareGPT) for model training
- Built-in MCP chat recall server for cross-session agent memory
- Bulk export and parallel processing for efficiency
- SDK-first design enabling custom integrations beyond CLI/MCP

## Why It Matters for RAG Builders
UniSessions eliminates vendor lock-in for AI coding sessions and enables cross-platform knowledge retention, critical for building unified AI agent workflows and fine-tuning datasets.
