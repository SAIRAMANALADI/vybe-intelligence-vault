## Summary
Token Optimizer is an MCP server that processes and condenses verbose build, test, and log outputs into compact, actionable insights for AI coding agents. It integrates with local and remote LLM providers to deliver verdicts, triage results, and targeted excerpts without exposing raw logs.

## Key Features
- Converts verbose logs into compact, actionable results for AI agents
- Supports multiple LLM providers (gateway token, OpenRouter key, local LLM)
- Integrates with popular coding agents (Cursor, Codex, Antigravity, Claude)
- Automated tool discovery and MCP registration with client support
- Local analytics dashboard for multi-workspace log analysis

## Why It Matters for RAG Builders
Token Optimizer reduces token consumption and improves efficiency for AI agents by summarizing verbose logs into actionable insights, making it essential for scalable RAG and AI-driven development workflows.
