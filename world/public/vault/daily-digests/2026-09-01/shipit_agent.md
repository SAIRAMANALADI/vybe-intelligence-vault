## Summary
SHIPIT Agent is a production-grade Python runtime for building tool-using AI agents with a consistent API across major LLM providers. It offers built-in tools, MCP support, memory, permissions, RAG, and multi-agent orchestration.

## Key Features
- Provider-agnostic LLM support with 100+ models via LiteLLM
- Built-in 40+ tools and 17 SaaS connectors (GitHub, Slack, Jira, etc.)
- Rule-based permission engine, prompt caching, and structured streaming events
- Hybrid RAG with auto-cited sources and pluggable backends (Chroma, Qdrant, pgvector)
- Deep multi-agent orchestration with Supervisor/Worker, GoalAgent, and ReflectiveAgent

## Why It Matters for RAG Builders
SHIPIT Agent provides a unified, production-ready runtime for AI agents with built-in tools, RAG, and multi-agent orchestration, enabling rapid development and deployment across any LLM provider.
