## Summary
A Model Context Protocol (MCP) server that provides AI agents with full control over a Threads profile via Meta's Threads API. Enables posting, reading replies, managing content, and analyzing engagement metrics through 30 tools with automated token refresh.

## Key Features
- 30 tools for Threads profile management including posting, replies, and insights
- Automated 60-day token refresh and OAuth flow
- Supports publishing, deleting, and reply management with safety confirmations
- Provides engagement metrics (views, likes, replies) for performance analysis
- Compatible with Claude Code, Desktop, Cursor, Windsurf, VS Code, and other MCP clients

## Why It Matters for RAG Builders
Enables AI agents to programmatically interact with Threads profiles, automating content management and engagement analysis for social media workflows.
