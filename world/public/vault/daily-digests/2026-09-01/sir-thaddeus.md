## Summary
Sir Thaddeus is a local-first AI assistant for Windows that enables users to run private, offline models while maintaining full control over sensitive actions, memory, and tools. It emphasizes transparency, deterministic capabilities, and evidence-based workflows without telemetry or external dependencies.

## Key Features
- Local model integration with LM Studio, Ollama, or custom OpenAI-compatible endpoints
- Granular permission controls for tools (Off, Ask, Always) with per-tool overrides
- Durable memory, Markdown wiki, and threaded chat with source citations
- Evidence-backed workflows with inspectable traces, diagnostics, and audit logs
- Benchmarking suite for measuring model and harness performance without hidden telemetry

## Why It Matters for RAG Builders
It provides a transparent, user-controlled framework for evaluating and deploying local AI models with deterministic tooling and evidence-based workflows, critical for building trustworthy RAG systems.
