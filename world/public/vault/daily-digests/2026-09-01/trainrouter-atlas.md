## Summary
TrainRouter Atlas is an open dataset of 744 legendary train routes spanning 118 countries, featuring hand-traced geometries, key facts, and structured metadata in CSV, JSON, and GeoJSON formats. It also includes an MCP server for AI assistant integration.

## Key Features
- Comprehensive dataset of 744 legendary train routes with structured metadata
- Hand-traced geometries in GeoJSON format for visualization and analysis
- Multiple data formats (CSV, JSON, GeoJSON) for flexibility
- MCP server integration for AI assistant access
- CC BY 4.0 licensed for free use with attribution
