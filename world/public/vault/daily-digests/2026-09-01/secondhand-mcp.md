## Summary
A Model Context Protocol (MCP) server that enables AI assistants to search secondhand marketplaces like Facebook Marketplace, eBay, Depop, and Poshmark. It provides detailed listing information, including photos, descriptions, and seller data, with support for filtering by price, category, condition, and more.

## Key Features
- Supports multiple secondhand marketplaces (Facebook, eBay, Depop, Poshmark) with unified search and filtering
- Provides detailed listing information including photos, descriptions, and seller data
- Integrates with MCP-compatible clients like Claude Desktop and Cursor
- Offers a hosted cloud version for quick setup without local installation
- Supports advanced filtering (price, condition, size, color, category) and sorting options

## Why It Matters for RAG Builders
It enables AI assistants to fetch real-time, structured data from secondhand marketplaces, enhancing their ability to assist users with buying or selling used items.
