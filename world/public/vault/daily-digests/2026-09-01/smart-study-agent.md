## Summary
SmartStudy Agent is an adaptive AI study assistant that personalizes learning by maintaining a persistent belief state about a student's knowledge. It uses reinforcement learning policies, FSRS spaced repetition, and LLM-generated quizzes to dynamically adjust study materials based on user performance and learning trajectory.

## Key Features
- OPEAA loop (Observe, Plan, Act, Evaluate, Adapt) for dynamic learning optimization
- FSRS-based spaced repetition scheduler for memory retention
- Q-learning and LinUCB policies for adaptive study recommendations
- Multi-modal input support (PDF, TXT, MD, DOCX, PPTX, VTT, SRT)
- Claude API and MCP server integration for AI-driven study coaching

## Why It Matters for RAG Builders
SmartStudy Agent provides a lightweight, modular framework for building adaptive AI study assistants that can integrate with RAG pipelines to personalize learning experiences based on user knowledge states.
