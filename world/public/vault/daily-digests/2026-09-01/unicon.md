## Summary
Unicon is a lightweight icon library browser and CLI tool that allows developers to search, copy, and bundle icons from 9+ popular icon sets without installing unnecessary dependencies. It provides direct integration with AI coding assistants and supports multiple output formats.

## Key Features
- Search and browse 20,000+ icons across 9+ libraries with natural language queries
- Copy icons in React, SVG, Vue, Svelte, or JSON formats with zero dependencies
- Bundle multiple icons by category or query for bulk exports
- Direct integration with AI coding assistants via MCP server and CLI skills
- Self-hostable instance with Vercel deployment support
