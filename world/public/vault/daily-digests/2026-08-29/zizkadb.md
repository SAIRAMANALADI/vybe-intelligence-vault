## Summary
ZizkaDB is an operational database designed for AI agents to audit, trace decisions, and detect behavioral drift. It enables causal lineage tracking, time-travel debugging, and semantic search over agent interactions, available as open-source self-hosted or managed cloud service.

## Key Features
- Causal lineage tracking with `db.why()` to trace decisions and tool calls
- Time-travel debugging via `db.at()` to reconstruct state at any point
- Semantic search and drift baselines for detecting anomalies in agent behavior
- Multi-format SDKs (Python, TypeScript) and MCP integration for seamless adoption
- Open-source self-hosting or managed cloud deployment with scalable event logging
