## Summary
Synorive is a local-first multimodal search and research platform that enables semantic retrieval across documents, code, images, videos, and web archives while actively hunting for counter-evidence and fact-checking claims. It integrates with Claude Code via 24 MCP tools for agent-assisted verification and operates fully offline with optional cloud inference switches.

## Key Features
- Semantic and keyword search across documents, code, images, videos, and web archives with sub-second latency
- Active counter-evidence hunting and fact-checking via multi-engine web search and academic sources
- 24 MCP tools for Claude Code to automate retrieval and verification tasks
- Fully offline operation with optional cloud inference switches for privacy control
- Cross-modal retrieval (e.g., find images by description or locate video timestamps from frames)

## Why It Matters for RAG Builders
Synorive provides a privacy-preserving, multimodal RAG pipeline with built-in fact-checking and agent integration, making it essential for building trustworthy AI systems that require verified, verbatim-sourced responses.
