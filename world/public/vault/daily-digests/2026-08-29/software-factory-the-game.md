## Summary
A browser-based incremental game that simulates software delivery systems, focusing on systems thinking in backlog management, process optimization, and scaling challenges. Players alter delivery loops with people, agents, and processes while navigating random events and balancing technical debt.

## Key Features
- Deterministic game engine with seeded RNG and save/resume functionality
- Hand-editable content via JSON schemas for decisions, challenges, and projects
- Static bundle deployment with no runtime dependencies
- Automated testing and balance probes for content validation
- LocalStorage persistence with autosave and reset functionality
