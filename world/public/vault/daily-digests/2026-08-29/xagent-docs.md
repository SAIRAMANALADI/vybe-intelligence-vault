## Summary
xAgent Docs is the official documentation portal for xAgent, a multi-user intelligent workspace portal. It provides user guides, developer references, and architecture details, built with Docusaurus, TypeScript, and MDX for structured content delivery.

- Local search functionality via @easyops-cn/docusaurus-search-local
- Multi-format content structure (docs, architecture, reference)
