## Summary
scomp-link is an end-to-end machine learning toolkit that automates the entire ML workflow, from data profiling and preprocessing to model training, validation, explainability, monitoring, and deployment. It offers both a full-featured CLI and a Python API for programmatic use, enabling zero-code and customizable ML pipelines.

## Key Features
- Automated end-to-end ML workflow with 26 CLI commands and Python API
- Comprehensive data preprocessing and feature engineering with Polars backend
- Built-in model selection, hyperparameter tuning, and validation (Optuna, Halving Grid Search)
- Advanced explainability tools (SHAP, LIME) and fairness metrics
- Interactive HTML reporting, drift detection, and model monitoring
