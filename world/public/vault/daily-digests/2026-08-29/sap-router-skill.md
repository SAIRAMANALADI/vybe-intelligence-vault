## Summary
A VS Code-integrated SAP orchestration tool that enables natural language interactions with SAP systems (ABAP, BTP, Fiori, etc.) without requiring SAP GUI. It dynamically routes tasks through ADT, GUI, or RFC, learns from execution, and automates complex workflows like material creation, transport management, and ABAP development.

## Key Features
- Dynamic routing engine prioritizing ADT, GUI, or RFC paths based on task complexity and system availability
- Self-learning mechanism that adapts routing decisions based on historical performance and success rates
- 85 pre-built skills covering ABAP, BTP, Fiori, CAP, and SAP integrations for end-to-end workflow automation
- 8-stage spec-to-transport pipeline with peer reviews, static analysis, and transport gate validation
- 42 MCP servers enabling modular interactions with SAP systems, including ADT, GUI automation, and RFC dispatch

## Why It Matters for RAG Builders
It bridges the gap between natural language AI and enterprise SAP systems, enabling RAG builders to automate complex SAP workflows without manual SAP GUI interactions.
