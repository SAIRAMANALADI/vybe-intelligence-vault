## Summary
WeaveFlow is a graph-based runtime for building, executing, and inspecting LLM agents in Go, emphasizing explicit graph definitions, deterministic execution, and runtime inspection capabilities.

## Key Features
- Declarative graph DSL for defining agent workflows with explicit state bindings
- Deterministic runtime with checkpointing, resuming, and replaying of agent runs
- Built-in nodes for LLM calls, tool use, planning, memory, routing, and human approval
- Structured event emission and artifact persistence for debugging and inspection
- Local-first development with a debug server and web UI for runtime monitoring

## Why It Matters for RAG Builders
WeaveFlow provides a robust, explicit, and inspectable foundation for building production-grade LLM agents, addressing runtime transparency and control challenges in agent frameworks.
