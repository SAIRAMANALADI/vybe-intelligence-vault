## Summary
Sero is a local-first desktop workspace designed as a unified shell for AI agents, integrating chat, terminals, visual browser, plugins, and persistent project memory into a single interface. It leverages the Pi coding agent to enable agent-assisted software development workflows with runtime isolation and self-building plugins.

## Key Features
- Unified desktop shell combining chat, terminals, browser, and file explorer for agent workflows
- Integrated visual browser for UI inspection and agent reasoning
- Self-building plugins enabling dynamic tool and UI extension via the agent
- Persistent project memory preserving context across agent sessions
- Runtime-backed workspaces with Apple Container, Docker, or host execution modes

## Why It Matters for RAG Builders
Sero provides a cohesive local-first environment where AI agents can interact with tools, UIs, and runtime states seamlessly, reducing context switching and enabling more sophisticated agent-assisted development workflows.
