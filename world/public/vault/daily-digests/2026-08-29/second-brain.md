## Summary
Second Brain is a local, queryable knowledge base and note vault that combines hybrid search (full-text + vector) with an entity-graph layer for AI agents. It stores and retrieves documents, transcripts, and notes from sources like Gmail, Slack, and Markdown files using Postgres with pgvector, enabling efficient context retrieval for AI assistants.

## Key Features
- Hybrid search combining full-text and vector embeddings for precise retrieval
- Entity-graph layer (GraphRAG) for thematic and relational insights across notes
- Pre-extracted, quote-stripped document storage to minimize token usage in AI contexts
- Built-in MCP server for seamless integration with AI assistants like Claude
- Proactive features like automated digests, resurfacing, and multi-hop query answering

## Why It Matters for RAG Builders
It provides a local, efficient, and agent-ready knowledge base that drastically reduces token costs for RAG systems while enabling deep, contextual retrieval and synthesis across diverse data sources.
