## Summary
Sanctuary is a security framework that wraps AI agents to enforce network-level egress control, cryptographic identity, and tamper-evident audit trails. It operates as a firewall and control panel, ensuring agents cannot bypass security policies even under prompt injection attacks, while maintaining data portability and operator custody.

## Key Features
- Kernel-level egress enforcement on macOS and Linux, blocking unauthorized network access even under prompt injection attacks
- Cryptographic identity and encrypted state managed solely by the operator, with no vendor access to keys or data
- Tamper-evident audit trails with portable, readable logs and external verification capabilities
- One-command integration with popular AI agents (Claude Code, Cursor, Hermes, etc.) via MCP protocol
- Data portability and operator-controlled recovery flows, ensuring no vendor lock-in

## Why It Matters for RAG Builders
Sanctuary provides critical security and sovereignty guarantees for RAG/AI stacks by enforcing operator-controlled egress policies and tamper-evident auditing, preventing unauthorized data exfiltration even from compromised agents.
