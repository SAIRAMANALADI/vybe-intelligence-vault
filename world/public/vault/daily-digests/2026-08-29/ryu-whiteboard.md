## Summary
ryu-whiteboard is an Excalidraw-based whiteboard application integrated as a companion app within the Ryu ecosystem. It enables users to draw freely, persist boards as Space documents, and import Mermaid diagrams for enhanced collaboration and documentation.

## Key Features
- Interactive whiteboard with Excalidraw for freeform drawing and diagram creation
- Persistence of boards as Space documents within the Ryu ecosystem
- Mermaid-to-Excalidraw diagram import for seamless integration of structured diagrams
- Self-contained companion UI bundle for easy deployment and integration
- Cross-platform support via prebuilt binaries for macOS, Windows, and Linux

## Why It Matters for RAG Builders
It provides a collaborative, persistent whiteboard interface that can enhance RAG pipelines by enabling visual documentation and diagram integration alongside text-based data.
