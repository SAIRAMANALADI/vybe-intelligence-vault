## Summary
Workflow Blueprint is a Next.js-based task-planning workspace with board-based task management, subtasks, recurring work, and notes. It features a first-class agent-access layer with per-user scoped API tokens, a full read/write REST API, and an in-repo MCP server for headless AI agent operations.

## Key Features
- Per-user scoped API tokens with granular write scopes for AI agents
- In-repo MCP server for headless agent operations
- Full read/write REST API with OpenAPI contract validation
- Multi-agent development workflow with PR-level guardrails (Verifier rules)
- Recurring task automation via Vercel Cron jobs

## Why It Matters for RAG Builders
It provides a production-grade template for building AI agent-accessible task management systems with strict scope control, API contracts, and multi-agent development workflows.
