## Summary
YantrikDB is a cognitive memory engine for AI agents that actively manages memory through consolidation, forgetting, and contradiction detection, rather than passively storing it. It reduces token usage by up to 99.9% compared to file-based memory while improving recall precision as data grows.

## Key Features
- Temporal memory decay with configurable half-life for automatic forgetting of stale data
- Consolidation of similar memories to reduce redundancy and improve recall precision
- Automatic contradiction detection between stored memories for factual consistency
- Proactive triggers surfacing important or decaying memories without agent prompting
- Derived personality traits and procedural memory for adaptive agent behavior

## Why It Matters for RAG Builders
YantrikDB solves the core memory bottleneck in RAG systems by actively managing memory instead of just storing it, enabling scalable, efficient, and contextually aware AI agents.
