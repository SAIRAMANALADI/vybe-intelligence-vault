## Summary
Totem is a standalone builder for creating pixel-art mascot logos from a given subject, deployed as a managed agent on ZooWork with a custom web frontend. It enables users to iteratively refine designs through multi-turn conversations and provides a tutorial for non-coders to build similar agents.

## Key Features
- Creates 32x32 pixel mascot logos from user input with iterative refinement
- Multi-turn conversational interface for design adjustments
- Supports English/Chinese language switching and dark/light/system theme
- Self-contained deployment per builder with isolated Cloudflare resources
- Provides a tutorial for non-coders to build similar agents

## Why It Matters for RAG Builders
Totem demonstrates how to build and deploy a specialized AI agent for creative tasks with isolated infrastructure per user, offering a template for scalable agent frameworks in RAG systems.
