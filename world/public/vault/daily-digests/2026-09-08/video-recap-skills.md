## Summary
A Claude Code plugin that transforms videos into narrated recap clips using Xiaomi MiMo's ASR, VLM, and TTS APIs. It automates video understanding, script generation, voiceover synthesis, and assembly into a polished output with subtitles, optionally exporting editable drafts for further refinement in tools like CapCut or Jianying.

## Key Features
- End-to-end video-to-recap pipeline with minimal local dependencies (only FFmpeg required)
- Multi-stage processing: scene detection, ASR, VLM analysis, script generation, TTS voiceover, and assembly
- Supports both automated recap generation and manual refinement via editable drafts (e.g., Jianying)
- Optional material library for reusing analyzed video segments across projects
- Cross-platform compatibility (macOS, Linux, Windows) and integration with multiple AI agent frameworks (Claude Code, Codex, OpenClaw)

## Why It Matters for RAG Builders
It streamlines the creation of AI-generated video recaps by automating complex multi-modal workflows, reducing manual effort while maintaining high-quality outputs for RAG pipelines or content repurposing.
