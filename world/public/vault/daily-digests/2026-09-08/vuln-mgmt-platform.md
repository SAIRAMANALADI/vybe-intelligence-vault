## Summary
A full-stack vulnerability management platform driven by AI agents (e.g., Codex, Claude Code) designed for security teams. It provides a complete business system workflow including authentication, vulnerability tracking, status workflows, and data dashboards with plans to integrate LLM-generated summaries and fixes.

## Key Features
- Role-based access control (reporter, auditor, admin) with JWT authentication
- Vulnerability lifecycle management with customizable workflows (open → confirmed → fixing → fixed → closed)
- Data visualization dashboard with severity/status statistics and CSV export
- Dockerized deployment with GitHub Actions CI for automated testing
- AI Agent integration roadmap for automated vulnerability summarization and fix recommendations
