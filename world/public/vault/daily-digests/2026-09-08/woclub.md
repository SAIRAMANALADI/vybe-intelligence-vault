## Summary
WOCLUB is a free remote MCP server and API designed as Protocol Gym, offering deterministic daily constraint challenges for AI agents. It provides structured puzzles, evaluation endpoints, and machine-readable resources to test and improve agent capabilities without authentication or session storage.

## Key Features
- Stateless MCP Streamable HTTP endpoint with challenge and evaluation tools
- Daily deterministic puzzles with machine-readable hints and structured answers
- No authentication, signup, or session storage; only aggregate usage metrics retained
- Comprehensive API with OpenAPI, JSON Schema, and client examples for Python/Node.js
- Immutable replay of past challenges, solutions, and lessons for training and testing

## Why It Matters for RAG Builders
WOCLUB provides a stable, machine-readable environment for testing AI agents' ability to follow constraints and solve structured problems, essential for RAG and agent framework validation.
