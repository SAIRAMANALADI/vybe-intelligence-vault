## Summary
Somm is an MCP server that acts as a model advisor for AI agents, fetching available models from OpenCode, OpenRouter, and Kimi subscriptions, cross-referencing benchmarks and pricing, and recommending optimal models for specific agent roles with detailed reasoning.

## Key Features
- Auto-detects and configures API keys via interactive setup wizard
- Cross-references model benchmarks and pricing from multiple providers
- Recommends optimal models per agent role with detailed reasoning
- Supports multi-provider integration (OpenCode, OpenRouter, Kimi)
- Validates configurations and estimates monthly costs by agent

## Why It Matters for RAG Builders
It streamlines model selection for AI agents by leveraging real-time benchmarks and pricing, ensuring optimal performance and cost efficiency in RAG and agent-based systems.
