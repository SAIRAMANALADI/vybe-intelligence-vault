## Summary
Zakar is an open-source personal AI memory platform that enables long-term memory sharing across multiple AI tools (e.g., Claude, ChatGPT) via a unified Postgres database with pgvector. It combines hybrid retrieval (vector + keyword search), an MCP server, REST API, and a CLI for seamless memory capture and retrieval.

## Key Features
- Hybrid memory retrieval combining vector search, full-text search, and recency boosting for high-precision results
- MCP server integration enabling memory access across AI tools like Claude Code and ChatGPT
- REST API with Bearer auth for compatibility with custom GPTs, scripts, and cron jobs
- Data flywheel for continuous improvement via logged search results and user feedback
- Built-in CLI, dashboard, and migration tools for Obsidian, ChatGPT, and Apple Notes

## Why It Matters for RAG Builders
Zakar provides a critical infrastructure layer for RAG systems by enabling consistent, long-term memory sharing across AI tools, reducing hallucinations and improving contextual relevance through hybrid retrieval and user feedback loops.
