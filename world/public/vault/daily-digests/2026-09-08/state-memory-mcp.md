## Summary
@putervision/state-memory-mcp is a zero-infrastructure, deterministic MCP server that provides AI agents with a structured, persistent graph for tracking workflow state, including tasks, decisions, artifacts, and their semantic relationships. It enables long-term project coherence, dependency management, and architectural decision auditing across agent sessions.

## Key Features
- Zero-infrastructure, deterministic state tracking with SQLite persistence
- 81+ MCP tools for task, decision, and artifact management with semantic relationships
- Interactive 3D HTML visualizer for project state graphs
- Event-sourced audit trail with session tracking and provenance
- Git branch-aware state filtering and multi-agent collaboration via blackboard store

## Why It Matters for RAG Builders
It provides a structured, persistent state engine for AI agents, eliminating context bloat and enabling deterministic, efficient workflow tracking and multi-agent coordination.
