## Summary
WildEdge Python SDK provides non-intrusive monitoring for ML inference pipelines, tracking latency, tokens, errors, and model metadata for both on-device and remote models. It supports automatic instrumentation via CLI or manual SDK integration for custom tracing.

## Key Features
- Non-intrusive instrumentation via CLI or SDK for zero-code changes in user applications
- Supports 10+ on-device ML frameworks (e.g., Transformers, PyTorch, TensorFlow) and remote LLM APIs (OpenAI, Anthropic)
- Tracks latency, tokens, errors, and model metadata with optional raw input/output attachments
- Offline persistence with automatic replay for resilience and reliability
- CLI tooling for validation (e.g., `wildedge doctor`) and environment configuration

## Why It Matters for RAG Builders
It provides essential observability for ML inference pipelines, enabling RAG builders to monitor performance, debug issues, and ensure reliability without modifying application code.
