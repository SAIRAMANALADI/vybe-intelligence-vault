## Summary
Workpane is a plugin-first desktop workspace that integrates terminals, code editors, browsers, AI agents, and local development services into a single unified interface. It leverages a modular architecture where every feature is a runtime-discovered plugin, with all data persisted in SQLite for seamless session recovery.

## Key Features
- Plugin-first architecture with runtime discovery and SQLite persistence
- Integrated terminal workspaces with native PTY support and multi-pane layouts
- Embedded code editor with language server protocol and EditorConfig support
- Built-in browser with persistent tabs and bookmark management
- AI task management with customizable agents, tools, and scheduling

## Why It Matters for RAG Builders
Workpane provides a unified, plugin-driven desktop environment that simplifies multi-tool workflows for AI and development tasks, making it easier to manage terminals, code, browsers, and AI agents in a single interface.
