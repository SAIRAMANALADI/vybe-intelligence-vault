## Summary
A specialized AI agent designed to guide users through the entire mathematical modeling process using a three-role framework: Bloom's taxonomy-based learning, Socratic questioning, and a four-stage P-M-A-D (Problem-Model-Algorithm-Debug) modeling workflow. It focuses on method guidance without direct solutions or code writing.

## Key Features
- Three integrated roles: Bloom's taxonomy learning, Socratic exploration, and P-M-A-D modeling guidance
- Covers optimization, dynamics, stochastic, uncertainty, and big data modeling methods
- Predefined fallback strategies for user resistance, input errors, and boundary conditions
- Unified questioning templates for 10+ common modeling pitfalls and ambiguities
- Strict adherence to method guidance without direct problem-solving or code generation

## Why It Matters for RAG Builders
It provides a structured, agent-driven approach to guide users through complex mathematical modeling workflows, reducing cognitive load and improving learning outcomes for AI-driven problem-solving.
