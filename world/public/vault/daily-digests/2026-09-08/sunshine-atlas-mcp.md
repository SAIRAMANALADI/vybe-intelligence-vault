## Summary
A remote, read-only Model Context Protocol (MCP) server that provides climate and sunshine data for 3,833 destinations worldwide. It offers tools to find sunny destinations, retrieve climate details, and compare locations based on sunshine scores, temperatures, and other metrics.

## Key Features
- Provides monthly sunshine scores, temperatures, rainfall, and sea temperatures for 3,833 destinations
- Offers tools to find sunny destinations, get climate details, and compare locations
- Stateless and self-hostable with a single Node.js file
- Data sourced from NASA POWER, Open-Meteo Marine, and other open datasets
- Live endpoint available with no key or signup required

## Why It Matters for RAG Builders
It provides structured, high-quality climate data for RAG systems to answer travel and weather-related queries with attribution and citable sources.
