## Summary
A non-custodial, proof-carrying cashier workflow for Solana Pay that enables merchants to accept payments without holding private keys or running custody services. It uses immutable offers, dual-RPC witness validation, and tamper-evident receipts for secure, automated reconciliation.

## Key Features
- Immutable Solana Pay offers with expiring timestamps and SHA-256 `offerHash` values
- Dual-RPC witness validation for settlement verification on public networks
- Tamper-evident proof bundles with Ed25519 issuer attestations
- Owner-gated refund workflow with unsigned refund URLs
- Atomic JSON invoice state persistence and deterministic offline demo mode

## Why It Matters for RAG Builders
It provides a secure, non-custodial framework for Solana Pay cashier workflows, reducing merchant risk while ensuring tamper-evident payment validation for RAG and AI stack builders.
