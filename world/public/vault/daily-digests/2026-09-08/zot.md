## Summary
zot is a lightweight, Go-based coding agent harness designed to orchestrate AI providers and tools for code generation and editing tasks. It supports over 30 providers, offers interactive TUI, CLI, and JSON run modes, and includes features like persistent instructions, extensions, and OAuth authentication flows.

## Key Features
- Supports 30+ AI providers (Anthropic, OpenAI, Google, GitHub Copilot, etc.) with built-in authentication and token refresh
- Lightweight static binary with one-liner installation across macOS, Linux, and Windows
- Interactive TUI, CLI, and JSON run modes for flexible interaction
- Persistent instructions via AGENTS.md and SYSTEM.md for customizable agent behavior
- Extensions system for adding tools and functionality in any language via JSON-RPC

## Why It Matters for RAG Builders
zot simplifies the orchestration of multiple AI providers and tools, making it essential for building scalable and customizable coding agents in RAG pipelines.
