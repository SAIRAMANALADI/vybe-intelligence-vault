## Summary
WeftCut is a cross-platform desktop video editor designed with AI agents as first-class citizens, exposing its full editing toolset via an MCP server for real-time agent-driven timeline manipulation. It combines a professional NLE timeline with agent-native workflows, enabling agents to edit, restyle, and manage video projects dynamically while maintaining human oversight.

## Key Features
- Agent-native editing via MCP server with real-time timeline updates
- Full-featured NLE timeline with A/B-roll, keyframes, and groups
- Fast preview and export using Rust decode engine and PixiJS/WebCodecs
- Parameterized animated overlays (Motifs) for titles and effects
- Agent mode for long-running batch edits with checkpointing and undo

## Why It Matters for RAG Builders
It enables AI agents to directly manipulate video projects in real time, bridging the gap between agentic workflows and professional editing tools for seamless human-AI collaboration.
