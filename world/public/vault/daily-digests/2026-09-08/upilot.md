## Summary
upilot is an open-source Unity Editor automation bridge and MCP server that enables AI agents (e.g., Codex, Claude, Cursor) to inspect, control, and diagnose Unity Editor via a local MCP server. It includes optional UIFlow for YAML-driven UI automation and supports extensive Unity Editor operations through 113+ MCP tools.

## Key Features
- Exposes Unity Editor capabilities via MCP Streamable HTTP for AI agents
- Supports 113+ MCP tools covering compilation, scene management, GameObject operations, diagnostics, and more
- Optional UIFlow for YAML-driven UI automation in Unity EditorWindow
- Python MCP server with WebSocket connection to Unity Editor bridge
- Agent skill integration for Codex, Claude, Cursor, and other MCP clients

## Why It Matters for RAG Builders
It enables AI agents to directly interact with and automate Unity Editor workflows, bridging the gap between AI-driven development and Unity's ecosystem.
