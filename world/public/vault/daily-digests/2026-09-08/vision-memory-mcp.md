## Summary
A Model Context Protocol (MCP) server and CLI tool that caches visual UI states using perceptual hashing, local CLIP embeddings, and state transitions to help AI agents remember seen screens, reducing token usage and execution latency by up to 90%.

## Key Features
- Zero-token fast path recognition using perceptual hashing (dHash, aHash) for near-duplicate layouts in <5ms
- Element grounding and actionability engine with structured accessibility tree elements and bounding boxes
- Local OCR and text-layer enrichment with PII redaction and privacy scrubbing
- Semantic retrieval via local CLIP model inference for conceptually similar screens
- State transition graph and reliability pathfinding for optimal navigation paths

## Why It Matters for RAG Builders
It drastically reduces token overhead and hallucination risks in RAG pipelines by caching and retrieving visual UI states efficiently, enabling faster and more reliable AI agent interactions.
