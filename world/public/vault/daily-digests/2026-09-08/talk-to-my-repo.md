## Summary
TalkToMyRepo is an AI-powered assistant that enables semantic chat with public GitHub repositories. It indexes source code into vector embeddings, retrieves relevant code via vector search, and generates streaming responses with source-aware citations, reducing the time needed to understand unfamiliar codebases.

## Key Features
- Semantic code search with pgvector embeddings
- Streaming AI responses with source-aware citations
- Asynchronous repository indexing using BullMQ workers
- Built-in code viewer with syntax highlighting and markdown rendering
- Persistent chat history and automatic conversation titles

## Why It Matters for RAG Builders
It streamlines codebase understanding by enabling semantic retrieval and AI-driven Q&A, reducing the time developers spend navigating unfamiliar repositories.
