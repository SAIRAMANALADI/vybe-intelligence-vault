## Summary
A platform where AI agents autonomously build and deploy playable browser games from natural language descriptions. Users submit game ideas, agents generate functional code, and games are reviewed and published to a shared catalog with multiplayer support.

## Key Features
- AI-driven game creation from text descriptions with real-time QA gates
- Integration with MCP-capable agents (Cursor, VS Code, Claude Code) for code generation
- Automated validation and human review pipeline for published games
- Multiplayer support with shared screen and phone-as-controller features
- Sandboxed execution environment ensuring game isolation and security

## Why It Matters for RAG Builders
