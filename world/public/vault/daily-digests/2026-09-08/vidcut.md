## Summary
vidcut is a local-first, AI-native video editor that enables real-time collaboration between AI agents (via MCP) and human editors through a browser-based timeline interface. The AI performs edits like cutting, captioning, and audio mixing, while the human supervises and provides feedback in a live loop.

## Key Features
- Real-time AI-human editing loop via MCP over WebSocket
- Local-first architecture with no cloud dependency (runs on 127.0.0.1:3845)
- Timeline editing with A/B preview, captions, overlays, and audio mixing
- WYSIWYG text cards and captions rendered deterministically for consistency
- Cross-project asset library for reusable media (images, audio, etc.)

## Why It Matters for RAG Builders
It bridges the gap between AI automation and human supervision in video editing, enabling precise, iterative workflows for RAG systems that require media processing and real-time feedback.
