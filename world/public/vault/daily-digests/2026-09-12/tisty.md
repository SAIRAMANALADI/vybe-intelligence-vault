## Summary
Tisty is a local-first productivity tool for Windows and macOS that manages notes, documents, and tasks using plain Markdown files stored on the user's disk. It emphasizes archiving completed work as a searchable record of progress, with no accounts, subscriptions, or telemetry.

## Key Features
- 100% local storage with plain Markdown files for data portability and auditability
- Archives completed tasks with full context (steps, notes, attachments) for future reference
- Eisenhower matrix for task prioritization and organization
- MCP integration for assistant-driven task management without cloud dependency
- Cross-platform support (Windows and macOS) with native performance

## Why It Matters for RAG Builders
Tisty provides a privacy-focused, local-first alternative for task and document management that preserves work history in a searchable format, ideal for AI-assisted workflows requiring structured, offline data.
