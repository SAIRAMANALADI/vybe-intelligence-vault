## Summary
The Steel MCP Server provides an interface for AI agents to interact with a managed Chromium browser via the Model Context Protocol (MCP). It enables reading web pages, taking screenshots, filling forms, and handling interactive sessions, with support for both cloud-hosted and self-hosted deployments.

## Key Features
- Interactive browser sessions for AI agents to navigate, click, and fill forms
- Stateless scraping tools for reading pages as markdown or HTML without sessions
- Screenshot and PDF generation with inline previews and download links
- Session diagnostics and replay for debugging or handoffs
- Support for both cloud-hosted and self-hosted Steel browser deployments

## Why It Matters for RAG Builders
It enables AI agents to interact with dynamic web content, bypassing limitations of plain HTTP requests for RAG pipelines.
