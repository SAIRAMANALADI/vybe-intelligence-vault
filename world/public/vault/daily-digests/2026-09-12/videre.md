## Summary
A local-first media library toolkit that provides deduplication, semantic search, face detection, and reporting capabilities using a single SQLite database for image and video files.

## Key Features
- Hashes and stores media files in a SQLite database for fast access and deduplication
- Supports semantic search via SigLIP embeddings and text queries
- Detects and clusters faces for person-based search and labeling
- Generates interactive HTML reports with drill-down galleries and live metadata
- Background watch mode for continuous updates and freshness

## Why It Matters for RAG Builders
It provides a robust, local-first pipeline for organizing, deduplicating, and searching media libraries, which is essential for maintaining clean datasets for RAG systems.
