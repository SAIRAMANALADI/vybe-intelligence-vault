## Summary
swift-claw is a pure-Swift daemon that deploys a private Telegram bot as a personal AI assistant, running on local hardware with durable memory, proactive scheduling, and strict security policies. It integrates with any OpenAI-compatible LLM while keeping all data and operations confined to the user's machine.

## Key Features
- Private Telegram bot with real-time messaging and voice note transcription
- Durable memory system with SQLite and Markdown-based workspace files
- Proactive scheduling and heartbeat with quiet hour support
- Strict security model with approval workflows for sensitive actions
- Sandboxed code execution and SSRF-protected tool calls

## Why It Matters for RAG Builders
It provides a privacy-preserving, locally-hosted agent framework that integrates seamlessly with LLMs while enforcing strict security and approval workflows, making it ideal for RAG builders prioritizing data control and user safety.
