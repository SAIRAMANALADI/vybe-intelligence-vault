## Summary
Xavier is a high-performance, Rust-based runtime for AI agents that provides fast vector memory storage, hierarchical context graphs, and semantic relationships using SQLite-backed storage. It supports HTTP REST, CLI, and Model Context Protocol (MCP) interfaces for seamless integration into AI workflows.

## Key Features
- Sub-millisecond contextual recall with SQLite-backed storage
- Hybrid vector + keyword search (BM25 + sqlite-vec)
- Multi-modal interfaces: HTTP REST, CLI, and MCP (HTTP+SSE & Stdio)
- Hierarchical context graphs and dynamic zone weighting for active work contexts
- P2P mesh network for decentralized synchronization and offline queue fallback

## Why It Matters for RAG Builders
Xavier provides a high-performance, local-first vector memory and context runtime essential for building autonomous AI agents with sub-millisecond recall and seamless integration into RAG pipelines.
