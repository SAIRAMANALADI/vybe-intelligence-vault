## Summary
The Telos Customer Validator is an AI-powered tool designed to validate startup ideas by simulating adversarial customer roleplay and conducting mock interviews with 13 distinct personas. It enforces a validation score threshold before allowing code development, ensuring founders refine their hypotheses based on real customer pain points.

## Key Features
- Adversarial customer roleplay with 13 personas to challenge assumptions
- Validation scoring system (0-10) based on emotional pain, willingness to pay, and market size
- Concierge onboarding with Socratic questioning to refine startup hypotheses
- Multilingual and multicultural adaptation for global customer insights
- Real-time sentiment analysis and feature prioritization matrix

## Why It Matters for RAG Builders
It prevents founders from building products nobody wants by enforcing rigorous customer validation before code development begins.
