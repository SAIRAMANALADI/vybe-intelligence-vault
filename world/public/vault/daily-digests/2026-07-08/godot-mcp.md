## Summary
Godot-MCP integrates the Godot game engine with the Model Context Protocol (MCP) to enable AI agents to inspect, edit, and automate game development tasks directly within the Godot Editor. It provides 39 built-in tools for scene management, node manipulation, resource handling, and script editing.

## Key Features
- 39 built-in MCP tools for Godot Editor operations (scene, node, resource, and script management)
- Supports both C# and GDScript for script editing and automation
- Cloud or self-hosted MCP server connectivity via ai-game.dev or custom endpoints
- Visual feedback integration with screenshot capture for AI inspection
- CLI tool (godot-cli) for streamlined installation, setup, and project scaffolding

## Why It Matters for RAG Builders
It bridges AI agents with the Godot Editor, enabling seamless automation of game development tasks and reducing manual effort in scene and script management.
