## Summary
A modular, privacy-first local AI agent that wraps a customized Gemma 4 model with autonomous tool-calling, real-time streaming, and a persistent RAG vault for long-term document memory. Supports both a modern browser-based Web UI and a classic terminal interface.

## Key Features
- Fully local inference with Ollama and Gemma 4, no cloud dependencies for core functionality
- Persistent RAG vault with ChromaDB for long-term document memory and retrieval
- Autonomous tool-calling loop with real-time streaming output and thinking visibility
- Dual interface: modern Web UI with 3D effects and collapsible thinking panels, plus terminal CLI
- Privacy-focused design with optional OAuth integrations for Google Calendar and Tasks

## Why It Matters for RAG Builders
It provides a privacy-first, fully local framework for building autonomous AI agents with tool-calling and RAG capabilities, eliminating cloud dependencies while enabling real-time, context-aware interactions.
