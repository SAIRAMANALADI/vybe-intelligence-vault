## Summary
A Python-based API wrapper for bulk Google Images searches that returns structured JSON results. It enables developers to fetch image data (URLs, dimensions, thumbnails, source domains) efficiently and at low cost via Apify's platform.

## Key Features
- Bulk image search with support for multiple queries in a single run
- Structured JSON output with full-size image URLs, thumbnails, and metadata
- Localization by country (`gl`) and language (`hl`) for targeted results
- Low-cost pricing ($0.0001 per image) with no setup or per-run fees
- MCP-ready for AI agent integration and tool use in LLMs

## Why It Matters for RAG Builders
Provides a cost-effective and structured way to fetch large volumes of image data for AI pipelines, RAG systems, or data analysis without manual scraping or complex setup.
