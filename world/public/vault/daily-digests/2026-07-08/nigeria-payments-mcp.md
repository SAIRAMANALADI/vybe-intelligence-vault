## Summary
A remote MCP server that enables AI agents to accept payments in Nigeria via Paystack's hosted checkout, supporting cards, bank transfers, USSD, and mobile money. It acts as a stateless translation layer between AI agents and Paystack, ensuring funds flow directly from buyer to merchant without holding credentials or funds.

## Key Features
- Stateless translation layer for seamless Paystack integration
- Supports multiple payment methods (cards, bank transfer, USSD, mobile money)
- Direct fund flow from buyer to merchant via Paystack
- Zero runtime dependencies and MIT licensed
- Streamable HTTP and JSON-RPC compliant MCP endpoint

## Why It Matters for RAG Builders
It simplifies integrating Nigerian payment acceptance into AI agents by abstracting Paystack's complexity into a standardized MCP server.
