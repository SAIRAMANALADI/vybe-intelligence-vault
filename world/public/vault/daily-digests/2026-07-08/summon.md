## Summary
Summon is a human-in-the-loop sign-off agent that integrates with Telegram to enable real-time human approval or rejection for autonomous AI agents. It acts as a bridge between on-chain AI agents and human oversight, ensuring secure and timely decision-making for high-stakes transactions.

## Key Features
- Instant Telegram notifications for agent requests requiring human approval
- Secure sign-off with authorized Telegram users only
- Seamless integration with the Constellation A2A ecosystem for on-chain agent hiring
- Active state recovery to prevent lost approvals on startup
- Dynamic payout wallet routing for earned USDC fees
