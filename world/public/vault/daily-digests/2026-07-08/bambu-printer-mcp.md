## Summary
A Model Context Protocol (MCP) server for controlling Bambu Lab 3D printers, enabling STL/3MF file handling, slicing integration with BambuStudio, and direct printer control via MQTT for automation and workflow integration.

## Key Features
- MCP server for Bambu Lab printer control and automation
- STL and 3MF file handling with BambuStudio integration
- MQTT-based printer communication for real-time status updates
- Direct printer command execution and job management
- Windows-native setup with simple installation process
