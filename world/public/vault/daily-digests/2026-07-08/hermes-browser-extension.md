## Summary
A browser extension that connects web pages to local AI agents via a side panel, enabling private data transfer and real-time interaction with the Hermes Agent running on the user's machine.

## Key Features
- Side panel integration for seamless agent access within the browser
- Local data transfer to ensure privacy and security
- Context sharing of URLs and text snippets with one click
- Compatibility with Chrome and Edge browsers
- Real-time sync between browser content and local agent

## Why It Matters for RAG Builders
