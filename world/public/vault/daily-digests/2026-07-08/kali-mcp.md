## Summary
kali-mcp enables AI assistants to interact with Kali Linux tools via a Docker container, providing a safe, isolated environment for security testing and automation. It bridges AI workflows with command-line security tools, allowing seamless execution of tasks like port scanning and service checks.

## Key Features
- Runs Kali Linux tools in an isolated Docker container for safe execution
- Integrates with MCP-compatible AI assistants for automated security tasks
- Supports common security tools like nmap, service checks, and network discovery

- Enables repeatable security workflows without full Kali VM installation
