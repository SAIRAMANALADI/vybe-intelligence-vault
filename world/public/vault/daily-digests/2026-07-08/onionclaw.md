## Summary
OnionClaw provides AI agents with full Tor network access and dark web data through a zero-config OpenClaw skill or standalone tool. It enables autonomous OSINT, threat intelligence, and security research by integrating Tor routing, dark web search engines, and LLM-powered analysis.

## Key Features
- Full Tor network access via SOCKS proxy with identity rotation
- Integration with 18 dark web search engines for comprehensive coverage
- Four LLM analysis modes for synthesizing scraped data
- Standalone CLI tools and OpenClaw skill for seamless agent integration
- Automated pipeline for end-to-end dark web investigations
