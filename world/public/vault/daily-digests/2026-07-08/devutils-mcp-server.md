## Summary
A Model Context Protocol (MCP) server providing 36 essential developer utilities for AI assistants, including hashing, encoding, UUID generation, JWT decoding, JSON formatting, and network tools. All tools run locally with no external API dependencies.

## Key Features
- 36+ pre-built developer tools (hashing, encoding, UUID generation, JWT decoding, JSON formatting, etc.)
- Zero external API dependencies—all tools run locally for reliability and security
- Multi-client compatibility (Claude, Cursor, VS Code Copilot, Windsurf, Docker MCP Toolkit)
- Docker-ready with multi-stage builds for minimal attack surface
- Strict input validation and human-readable outputs for AI-friendly tool usage

## Why It Matters for RAG Builders
