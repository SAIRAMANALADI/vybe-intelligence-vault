## Summary
A CLI tool that converts Markdown to WeChat official account HTML, automates publishing workflows, and provides AI Agent integration for content creation, layout customization, and multi-account management.

## Key Features

- Supports AI Agent workflows via JSON discovery commands for stable CLI integration
- Enables automated content generation, cover creation, and infographic production
- Provides readiness checks and validation for draft publishing
- Offers multi-account management and WeChat API fixed egress for enterprise use
