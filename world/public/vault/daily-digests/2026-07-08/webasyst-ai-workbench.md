## Summary
Webasyst Tapestry is an AI-driven orchestrator that automates the creation, customization, and deployment of Webasyst applications, themes, and plugins using natural language instructions. It bridges AI with the Webasyst ecosystem to generate production-ready components without manual boilerplate coding.

## Key Features
- Intent-to-app pipeline converting natural language into Webasyst components
- Semantic theme generation with brand guideline adherence
- Multi-model AI routing for optimized cost and quality
- Live preview generation for real-time component validation
- Automated documentation synthesis for generated components
