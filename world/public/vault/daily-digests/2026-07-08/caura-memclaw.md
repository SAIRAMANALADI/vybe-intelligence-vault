## Summary
MemClaw is an open-source, governed memory system designed for multi-tenant AI agent fleets. It enables agents to store, share, and improve memory collectively, reducing repetition and accelerating learning across the fleet.

## Key Features
- Multi-tenant and multi-agent memory sharing with scoped access control
- Governed memory with trust tiers, keystone policies, and audit trails
- Self-improving retrieval via cross-agent outcome propagation and weight adjustments
- MCP-native integration for seamless agent-to-memory communication
- Performance optimized for latency (23ms p50 search) and token efficiency

## Why It Matters for RAG Builders
MemClaw enables AI agent fleets to collectively learn and improve, reducing redundant work and accelerating problem-solving through governed, shared memory.
