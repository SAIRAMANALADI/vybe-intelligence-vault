## Summary
context-doctor is a diagnostic tool designed to visualize and analyze the usage of the OpenClaw context window, providing insights through terminal output, PNG images, and JSON files. It helps users monitor token usage, file health, and available space in real-time.

## Key Features
- Real-time visualization of OpenClaw context window usage via terminal, PNG, or JSON outputs
- Supports multiple output formats (text, images, structured data) for flexible analysis
- No installation required; runs as a standalone executable on Windows
- Lightweight tool with minimal system requirements (2GB disk space, 4GB RAM recommended)
- Enables comparison of context usage over time through saved outputs

## Why It Matters for RAG Builders
It provides critical insights into context window utilization, helping RAG builders optimize token allocation and debug conversation health efficiently.
