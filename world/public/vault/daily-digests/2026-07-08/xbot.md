## Summary
xbot is a self-hosted, multi-channel AI agent framework that enables teams to deploy a single AI agent accessible via Feishu, QQ, terminal, or web. It supports tool execution, sub-agents, and MCP integration while ensuring data privacy by keeping all interactions on-premise.

## Key Features
- Multi-channel support (Feishu, QQ, Web, CLI) for seamless team collaboration
- Extensible tool system with built-in and custom tools (shell, file I/O, web search, scheduling)
- Sub-agent and group chat capabilities for parallel task execution and moderated discussions
- MCP integration for enhanced context and plugin support
- Self-hosted deployment with data privacy and configurable LLM subscriptions

## Why It Matters for RAG Builders
xbot enables teams to deploy a unified, self-hosted AI agent across multiple communication channels while maintaining data privacy and extensibility, making it essential for scalable, collaborative AI workflows.
