## Summary
Flux Flow is an autonomous terminal-based AI agent built with Node.js and Ink, offering a React-like interactive CLI experience. It combines a dual-model architecture with IDE integration, multimodal input, and agentic tooling to act as a conversational partner or autonomous developer for coding tasks.

## Key Features
- Dual-model architecture with primary agent and background 'Janitor' model for memory and summarization
- IDE companion with real-time error detection, live status telemetry, and clickable terminal links
- Multimodal input support for images and PDFs with high-fidelity context retention
- Transaction-based file snapshots for instant rollback and fearless refactoring
- Customizable autonomous subagent system with 10+ built-in tools and configurable autonomy levels
