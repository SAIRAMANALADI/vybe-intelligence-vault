## Summary
A WordPress plugin that extends the WordPress MCP Adapter to expose Elementor data, widgets, and page design tools as MCP-compatible tools. It enables AI agents to programmatically create, edit, and manage WordPress and Elementor page designs, content, and settings.

## Key Features
- 130+ MCP-compatible tools for Elementor and WordPress management
- Supports Elementor widgets, templates, and dynamic content
- Extends beyond Elementor to include WordPress content, settings, plugins, themes, media, users, and database management
- Security and performance diagnostics with actionable reports
- Pro features include AI widget builder, brand kits, and theme builder

## Why It Matters for RAG Builders
It bridges WordPress and Elementor with AI agents via MCP, enabling programmatic page design and content management for RAG builders.
