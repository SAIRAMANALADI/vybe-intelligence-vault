## Summary
VoiceMode enables natural voice conversations with AI agents like Claude Code, allowing hands-free and eyes-free interaction through local or cloud-based speech services. It integrates seamlessly with MCP-capable agents for real-time voice-based debugging, coding, and task execution.

## Key Features
- Natural voice conversation with AI agents like Claude Code
- Supports both local (offline) and cloud-based speech services
- Low-latency smart silence detection for real-time interaction
- Cross-platform compatibility (Linux, macOS, Windows, NixOS)
- Privacy-focused with optional local speech processing

## Why It Matters for RAG Builders
