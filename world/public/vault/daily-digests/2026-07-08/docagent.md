## Summary
DocAgent is a local-first AI-powered desktop application that enables users to generate, read, modify, and convert documents (Word, Excel, PPT, PDF, Markdown) through natural language conversations. It integrates multiple AI models and provides a visual workspace for document processing and version control.

## Key Features
- Multi-turn conversational document operations with real-time streaming of AI thoughts
- Support for Word, Excel, PPT, PDF, Markdown, and Python code with sandboxed execution
- Version history with snapshots, retention policies, and one-click rollback
- Workspace management with file tree browsing, search, and auto-detection of directory changes
- Prompt templates with custom variables and category-based organization

## Why It Matters for RAG Builders
