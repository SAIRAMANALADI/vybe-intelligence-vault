## Summary
planwiki-app is a Windows desktop application that converts Product Requirements Documents (PRDs) into actionable tasks, Linear issues, or Trello boards using AI. It streamlines the transition from planning to execution for product teams and indie hackers.

## Key Features
- Converts PRDs into structured tasks, issues, or boards automatically
- Integrates with Linear and Trello for direct task creation
- Supports self-hosted deployment for data privacy
- Uses AI agents for PRD parsing and task generation
- Provides a clean, user-friendly interface for planning and execution

## Why It Matters for RAG Builders
It bridges the gap between high-level planning and execution by automating task generation from PRDs, saving time and reducing manual effort for product teams.
