## Summary
LVIS App is an extensible Electron-based desktop workspace designed for AI agent interactions, plugin workflows, local indexing, and managed marketplace extensions. It serves as a host for LVIS chat, tool execution, and plugin-based retrieval systems.

## Key Features
- Extensible plugin runtime with dynamic loading and lifecycle management
- Hybrid retrieval system fusing local BM25/vector and cloud adapter results
- Managed marketplace for first-party plugin installation and updates
- Overlay-triggered conversation proposals with user approval workflows
- Cross-platform desktop app with macOS, Linux, and Windows installer support

## Why It Matters for RAG Builders
It provides a robust, extensible desktop host for AI agents and RAG systems, enabling seamless integration of plugins, local indexing, and hybrid retrieval for enhanced AI workflows.
