## Summary
Oski is an open-source AI agent framework designed for controlled, self-evolving AI operations within teams. It enables agents to learn, use tools, and grow capabilities over time while enforcing safety, auditability, and human review for critical actions.

## Key Features
- Draft-first execution with human review for live actions
- Durable behavioral memory via plain-text `instructions.md`
- Hard cost controls with daily USD caps and model pricing tiers
- Reviewable capability growth through scaffolded TypeScript tools
- Scoped file access and sandboxed tool execution

## Why It Matters for RAG Builders
Oski provides a reference architecture for building safe, auditable, and self-improving AI agents that can operate within real business workflows while maintaining human oversight and control.
