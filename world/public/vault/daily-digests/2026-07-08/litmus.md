## Summary
Litmus is an on-chain AI quality gate agent that evaluates deliverables (e.g., code, writing) against predefined rubrics, assigning deterministic scores (0-100) and providing cryptographically signed attestations. It acts as an automated, impartial grader in autonomous agent economies, ensuring only high-quality work passes quality gates.

## Key Features
- Objective grading with deterministic scores (0-100) using a two-model tribunal for stability
- On-chain attestation of grades via cryptographic signing for immutability and verifiability
- Active rejection of subpar work and mismatched rubrics to prevent agent hang-ups
- Dynamic payout routing for grading fees and support for state recovery on container restarts
- Integration with CROO Constellation A2A graph for high-traffic agent interactions

## Why It Matters for RAG Builders
Litmus provides a critical primitive for ensuring output quality in autonomous agent ecosystems by offering verifiable, on-chain grading-as-a-service, which is essential for building trust and reliability in AI-driven workflows.
