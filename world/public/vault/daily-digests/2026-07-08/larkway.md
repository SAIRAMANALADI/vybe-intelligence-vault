## Summary
Larkway transforms a Claude Code or Codex subscription into a Feishu (Lark) agent that team members can @-mention to query or interact with their codebase in real-time. It bridges Feishu threads to a local coding agent, enabling contextual Q&A, task automation, and workflow execution without exposing APIs or secrets.

## Key Features
- Feishu-to-agent WebSocket bridge for real-time messaging and session continuity
- Supports multiple bots per bridge with isolated workspaces and permissions
- Integrates with Claude Code or Codex for code execution and task automation
- Session-based memory for follow-up interactions and context retention
- Task handle synchronization for Feishu topics to manage agent lifecycle

## Why It Matters for RAG Builders
Larkway enables teams to deploy a secure, persistent AI agent directly integrated with their Feishu workspace, allowing anyone to query or interact with their codebase without exposing APIs or compromising security.
