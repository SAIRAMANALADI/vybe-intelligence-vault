## Summary
Regenerator 2000 is a modern, interactive 6502 disassembler designed for Commodore 8-bit machines, offering both a keyboard-driven TUI for manual analysis and an MCP server for programmatic AI-driven disassembly. It supports a wide range of file formats and provides advanced features like automated analysis, binary unpacking, and export to multiple assemblers.

## Key Features
- Interactive TUI with keyboard-driven navigation and editing
- MCP server for AI-driven programmatic disassembly and analysis
- Support for multiple Commodore file formats (PRG, CRT, D64, etc.)
- Binary unpacker for compressed C64 programs with cycle-accurate emulation
- Export to multiple assemblers (64tass, ACME, Kick Assembler, ca65)

## Why It Matters for RAG Builders
It enables AI-driven reverse engineering and disassembly of 6502 binaries, particularly for retro computing applications, by providing both manual and automated analysis workflows.
