## Summary
Official MCP server for Brilliant Directories that enables AI agents to interact with BD sites via a standardized API. Provides tools to manage members, posts, leads, reviews, pages, and other resources exposed by Brilliant Directories' REST API.

## Key Features
- Full access to Brilliant Directories resources (members, posts, leads, reviews, pages, etc.) via MCP tools
- Two deployment modes: Easy (hosted MCP) and Advanced (self-hosted with Node.js)
- Comprehensive API key permission management for granular access control
- OpenAPI 3.1 spec included for tool discovery and integration
- Cross-platform support for major AI clients (Claude, Cursor, Windsurf, OpenAI, n8n, etc.)

## Why It Matters for RAG Builders
It bridges Brilliant Directories' proprietary API with AI agents, enabling seamless automation and integration for directory management tasks.
