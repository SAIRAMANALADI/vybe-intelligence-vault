## Summary
adaptive-cards-mcp is a Windows-based MCP server that simplifies the creation, validation, and optimization of Adaptive Cards for Microsoft Teams, Outlook, Copilot, and other MCP-aware AI tools. It provides 9 specialized tools to streamline card development without requiring deep technical setup.

## Key Features
- 9 specialized tools for Adaptive Card creation, validation, and optimization
- Windows-friendly desktop application with simple setup
- Supports MCP-aware AI clients like Copilot Studio, Cursor, and VS Code
- Generates, checks, and fixes Adaptive Cards from plain English prompts
- Optimizes card layouts for Teams, Outlook, Copilot, and ChatGPT

## Why It Matters for RAG Builders
