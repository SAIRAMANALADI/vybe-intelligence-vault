## Summary
PowerSkills is a Windows automation toolkit that enables non-programmers to control applications like Outlook and Edge using PowerShell scripts and structured JSON commands. It simplifies repetitive tasks through predefined automation workflows.

## Key Features
- Pre-built PowerShell scripts for Outlook, Edge, and desktop automation
- Structured JSON configuration files for customizable task definitions
- No coding required—edits made via simple text editors
- COM automation for seamless integration with Windows apps
- Logging and activity tracking for monitoring automation tasks
