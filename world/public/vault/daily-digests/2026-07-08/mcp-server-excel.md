## Summary
A Model Context Protocol (MCP) server and CLI tool for automating Microsoft Excel via natural language commands. It enables AI assistants (e.g., GitHub Copilot, Claude) to interact with Excel's native COM API for tasks like Power Query, DAX, VBA, PivotTables, and data transformations.

## Key Features
- 26 specialized tools with 232 operations for Excel automation (Power Query, DAX, VBA, PivotTables, Charts, etc.)
- Uses Excel's native COM API for 100% safety and compatibility, avoiding file corruption risks
- Supports both MCP Server (for conversational AI) and CLI (for scripting/coding agents) interfaces
- Real-time Excel interaction with live progress feedback in the status bar
- LLM-tested quality with automated validation using pytest-skill-engineering
