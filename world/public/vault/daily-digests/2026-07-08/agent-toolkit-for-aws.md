## Summary
A Windows-based toolkit that enables AI agents to interact with AWS services through a local bridge, translating agent requests into AWS-compatible commands while enforcing security standards and eliminating manual scripting.

## Key Features
- Bridges AI agent requests to AWS services via a local server
- Simplifies AWS resource management without manual scripting
- Enforces AWS security standards through IAM permissions
- Supports Model Context Protocol (MCP) for AI agent compatibility
- Provides a Windows installer for easy setup
