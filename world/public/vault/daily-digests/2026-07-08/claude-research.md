## Summary
claude-research is a Windows-based VS Code extension and template for AI-assisted academic research, enabling users to conduct literature reviews, manage citations, draft papers, export to LaTeX, and create presentations with Reveal.js. It integrates with Claude Code for AI-powered writing and research workflows.

## Key Features
- AI-powered research workflow with Claude Code integration
- Literature review and citation management system
- LaTeX export for publication-ready documents
- Reveal.js-based presentation creation
- Structured VS Code workspace for research projects
