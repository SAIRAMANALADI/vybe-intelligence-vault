## Summary
CR Pulse EYBL Tracker is a Next.js-based web application designed to track and display basketball player and team statistics for the Nike EYBL/EYCL leagues. It provides real-time player metrics and team leaderboards sourced from the Cerebro Sports public API.

## Key Features
- Real-time player statistics tracking (PPG, RPG, APG, etc.)
- Team leaderboards for multiple elite basketball programs
- Integration with Cerebro Sports public API for data sourcing
- Responsive Next.js frontend for seamless user experience
- Simple local setup with npm commands
