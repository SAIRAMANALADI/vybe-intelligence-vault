## Summary
Mnemosyne Core is a persistent memory system for AI assistants that enables long-term personality consistency, contextual awareness, and layered memory storage across sessions. It transforms ephemeral interactions into enduring digital relationships with multi-layered memory architecture.

## Key Features
- Layered memory architecture with ephemeral, working, personality, user profile, and temporal layers
- SOUL.md and USER.md configuration for personality and user preference persistence
- Multi-platform integration with OpenAI, Claude, local LLMs, and web/CLI interfaces
- Adaptive memory consolidation with intelligent forgetting and emotional weighting
- Privacy-first design with local storage, selective cloud sync, and compliance-ready data handling
