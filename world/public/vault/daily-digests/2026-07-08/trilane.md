## Summary
TriLane is an autonomous gray-box security auditing tool that provides a structured, multi-stage audit workflow for web applications and APIs. It uses a visible attack-surface state and evidence-backed findings to guide security assessments.

## Key Features
- Six semantic audit lanes covering identity/auth, injection, ingress/files/SSRF, business logic, config/secrets/crypto, and edge coverage
- Attack-surface graph construction before deep auditing
- Safe and Lab modes for controlled security testing
- Deduplication of findings with severity, evidence, and code paths
- Desktop GUI with state tracking and transcript archiving

## Why It Matters for RAG Builders
TriLane provides a structured, auditable framework for AI-driven security testing, ensuring findings are evidence-backed and reproducible.
