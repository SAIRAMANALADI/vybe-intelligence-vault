## Summary
An interactive AI coding assistant that operates in terminal or web browser, enabling natural language-driven file operations, shell commands, and tool execution via free cloud APIs or local models. It supports MCP and LSP for extensibility and deep code understanding.

## Key Features
- Supports 13+ AI providers (free and paid) with auto-fallback on rate limits
- Full offline capability via local models (Ollama, LM Studio, Llama.cpp)
- Built-in MCP and LSP support for extensibility and deep code analysis
- Interactive CLI and web UI with session management and persistence
- Safety features like whitelisted shell commands and loop detection

## Why It Matters for RAG Builders
It provides a free, extensible, and offline-capable AI agent framework for coding tasks, reducing dependency on paid cloud APIs while enabling deep integration with development tools.
