## Summary
Adeu is a Model Context Protocol (MCP) server and SDK that translates Microsoft Word DOCX files into LLM-friendly Markdown with CriticMarkup, enabling AI agents to edit documents non-destructively while preserving formatting and structure. It acts as a Virtual DOM for Word, allowing safe two-way edits via tracked changes.

## Key Features
- Translates DOCX to LLM-friendly Markdown with CriticMarkup for semantic editing
- Preserves formatting, fonts, and layout during AI-driven edits via tracked changes
- Supports Python and Node.js implementations with MCP server and SDKs
- Integrates with LangChain, n8n, and Claude Code for agent workflows
- Provides live MS Word integration for real-time document editing

## Why It Matters for RAG Builders
Adeu enables AI agents to safely and efficiently edit Microsoft Word documents without corrupting formatting or structure, making it essential for legal, business, and document-intensive workflows.
