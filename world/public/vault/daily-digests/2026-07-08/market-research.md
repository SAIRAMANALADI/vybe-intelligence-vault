## Summary
A methodology and skill package for AI agents to perform evidence-driven market research, transforming vague requests into structured, citation-backed reports with blind spot transparency. Designed for the Hermes Agent framework.

## Key Features
- Structured research workflow with quality gates at each step
- Evidence mapping and confidence labeling (Fact/Inference/Judgment/Recommendation)
- Automated Markdown and HTML report generation with dark-mode styling
- Blind spot documentation for unanswerable questions
- Built-in evaluation suite with 7 test cases covering common failure modes

## Why It Matters for RAG Builders
It provides a repeatable, evidence-first framework for AI agents to generate reliable, citation-backed market research reports, reducing hallucinations and improving decision support quality.
