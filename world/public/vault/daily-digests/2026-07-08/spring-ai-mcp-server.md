## Summary
This repository implements an MCP (Model Context Protocol) server using Spring AI 2.0.0-M6, enabling AI agents like Claude Desktop to interact with and manage tasks stored in a PostgreSQL database. It provides controlled task-management capabilities while deliberately excluding destructive operations from AI reach.

## Key Features
- Exposes task-management tools via MCP for AI agent interaction
- Integrates with PostgreSQL for persistent task storage
- Uses Spring AI 2.0.0-M6 for AI-driven task operations
- Restricts destructive operations (e.g., delete) from AI reachability
- Enables real-time task management for AI agents like Claude Desktop

## Why It Matters for RAG Builders
It bridges AI agents with structured task management in PostgreSQL, enabling secure and controlled AI-driven workflow automation.
