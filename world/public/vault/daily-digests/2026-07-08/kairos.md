## Summary
Kairos is a self-hosted uptime and availability monitoring tool built with Spring Boot that checks HTTP services, Docker images, and TCP endpoints for reachability. It provides a status dashboard, Prometheus metrics, and supports multi-protocol monitoring with configurable intervals and parallelism.

## Key Features
- Multi-protocol monitoring (HTTP, TCP, Docker images) with configurable intervals and parallelism
- Interactive status dashboard with latency tracking, outage history, and Prometheus metrics
- Resource discovery for Docker images and support for multiple authentication methods
- Built-in Model Context Protocol (MCP) server for AI assistant integration
- Flexible notifications via Email, Discord, Webhooks, and GitLab Incident Management

## Why It Matters for RAG Builders
Kairos provides essential uptime monitoring and observability for AI infrastructure, enabling proactive issue detection and resolution in RAG/AI stacks.
