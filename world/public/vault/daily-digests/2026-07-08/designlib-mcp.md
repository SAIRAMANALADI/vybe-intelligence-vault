## Summary
A hand-curated MCP server providing design tokens, patterns, and references for AI coding agents to ensure non-hallucinated, consistent UI design choices. Serves as a reliable source of truth for design systems, palettes, typography, and UI components.

## Key Features
- Hand-curated, non-hallucinated design tokens and patterns for AI agents
- MCP-native server for seamless integration with AI coding tools like Claude Code
- Role-mapped design elements (palettes, fonts, icons) with ready-to-use code snippets
- Read-only, telemetry-free, and hosted deployment option for zero-config usage
- Supports 27 tools for querying styles, palettes, fonts, domains, and UI components

## Why It Matters for RAG Builders
It eliminates hallucinated design choices in AI-generated UIs by providing a curated, agent-ready source of truth for design tokens and patterns.
