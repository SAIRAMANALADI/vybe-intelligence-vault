## Summary
AE-agent is a Windows-based AI assistant designed to integrate with Adobe After Effects, enabling users to connect their own AI API endpoints to automate and assist with tasks inside After Effects. It acts as a local helper tool for planning animations, generating prompts, and organizing project workflows.

## Key Features
- Connects to custom AI API endpoints for task automation
- Integrates directly with Adobe After Effects for local workflows
- Supports planning and generating animation prompts
- Maintains user control over AI models and endpoints
- Designed for Windows users with simple installation
