## Summary
MyAgens is a self-hosted, personal AI fleet manager that runs on your local machine, enabling interaction via Telegram or a private web dashboard. It coordinates autonomous Claude Code agents for file operations, code execution, and service monitoring with built-in security and approval workflows.

## Key Features
- Runs autonomous Claude Code agents locally with full file and system access
- Dual interaction modes: Telegram and private web dashboard
- Built-in approval workflows for risky actions (write, edit, command execution)
- AES-256 encrypted vault for secrets and audit logs
- Modular agent hierarchy (Atlas coordinator + specialized Leads)

## Why It Matters for RAG Builders
MyAgens provides a secure, self-hosted framework for deploying autonomous AI agents that can perform real-world tasks while maintaining strict user control and privacy, making it ideal for privacy-conscious AI engineering stacks.
