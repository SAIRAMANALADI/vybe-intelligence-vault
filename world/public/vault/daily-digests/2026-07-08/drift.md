## Summary
drift is a static analysis tool designed to detect architectural and structural code drift in AI-assisted codebases, helping developers identify pattern fragmentation, architecture violations, and near-duplicate code before they cause technical debt.

## Key Features
- Detects pattern fragmentation in repeated code blocks
- Identifies architecture violations and unintended dependencies
- Finds near-duplicate code (mutant duplicates) that may cause bugs
- Provides clear signals for AI-generated code drift
- Generates actionable reports with file names, line numbers, and warnings
