## Summary
Aming Claw is a local-first governance layer for AI-coded development that pushes structured context to AI agents instead of relying on them to fetch their own context. It enforces role-based contracts, verification gates, and evidence tracking to keep agents aligned with project goals and constraints.

## Key Features
- Push-based context delivery to AI agents via runtime contracts and gates
- Event-sourced timeline for tracking agent actions and evidence
- Role-based governance with observer, worker, and QA roles
- Parallel work support with bounded worker lanes and merge queues
- Local dashboard for monitoring activity, backlog, graph state, and review queues

## Why It Matters for RAG Builders
It provides a critical governance layer for AI agents by pushing structured context and verification gates, ensuring agents operate within defined boundaries and reducing drift in multi-agent workflows.
