## Summary
Cuba-Memorys is an MCP server that provides persistent, neuroscience-inspired long-term memory for AI agents using a knowledge graph, adaptive decay algorithms, and anti-hallucination grounding. It enables AI coding assistants to retain and retrieve context across sessions with mathematically rigorous methods.

## Key Features
- FSRS-6 adaptive decay for realistic memory retention and recall
- Knowledge graph with typed relations and community detection (Leiden)
- 4-signal RRF fusion search with entropy-routed adaptive ranking
- Anti-hallucination verification via stored knowledge triangulation
- Dual-Strength memory model (Bjork 1992) for independent storage and retrieval tracking

## Why It Matters for RAG Builders
Cuba-Memorys enables AI agents to retain and contextualize information across sessions, reducing hallucinations and improving decision-making by grounding responses in persistent, structured memory.
