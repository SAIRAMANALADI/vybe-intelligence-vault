## Summary
MDMA extends Markdown with interactive components (forms, buttons, tables, approval gates, etc.) defined in fenced code blocks, enabling AI-generated applications that render structured, actionable UIs directly from Markdown documents.

## Key Features
- Extends Markdown with interactive components via fenced `mdma` blocks (forms, buttons, tables, approval gates, etc.)
- Provides React renderer (`@mobile-reality/mdma-renderer-react`) for seamless UI integration
- Includes validation, state management, and customization hooks for dynamic document rendering
- Offers system prompts (`@mobile-reality/mdma-prompt-pack`) for LLM-based generation of MDMA documents
- Supports lightweight chart rendering with optional custom renderers (e.g., Recharts)

## Why It Matters for RAG Builders
MDMA enables AI systems to generate structured, interactive UIs directly from Markdown, eliminating the need for custom UI development per use case and streamlining RAG application workflows.
