## Summary
Wingman is an open-source MCP server that provides AI assistants like Claude with a persistent, interactive plan panel for task management, rendered inline in chat and synced across devices via local SQLite or a hosted cloud service.

## Key Features
- Interactive plan panel rendered inline in chat with drag-and-drop reordering
- Persistent task tracking across conversation restarts using local SQLite or hosted Postgres
- Multi-device sync via Wingman Cloud (hosted service) for seamless plan access
- Support for task statuses: pending, in-progress, done, and blocked
- Markdown export and in-panel task operations (rename, delete, clear, run)

## Why It Matters for RAG Builders
Wingman enhances AI-driven workflows by providing a persistent, interactive task management system that bridges the gap between AI planning and human execution, ensuring continuity and collaboration across sessions and devices.
