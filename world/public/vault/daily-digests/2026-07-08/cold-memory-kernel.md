## Summary
A repository focused on designing a memory and governance architecture for AI agents, particularly for the Hermes Agent. It introduces a four-layer memory system (Hot, Cold, Config, Runtime) and emphasizes evidence-driven decision-making through hypotheses and proposals.

## Key Features
- Four-layer memory system (Hot, Cold, Config, Runtime) for structured knowledge management
- Tool Gating and Provider Health Score for dynamic routing and performance optimization
- Hypothesis-driven architecture with a lifecycle from Idea to Validated
- Capability Registry (AP-001) for scalable agent capability expansion
- Governance model with constraints, hypotheses, backlog, and proposals
