## Summary
VibeSpace is a backend-agnostic web workspace designed for managing multiple concurrent coding agent CLI sessions (e.g., Claude Code, Codex) through a browser-based interface. It provides a tiling window manager, structured chat view, file explorer, and code editor, with persistence and multi-session support.

## Key Features
- Backend-agnostic adapter system supporting Claude Code, Codex, and custom backends
- Dual-mode sessions (Terminal and Chat) with persistence via dtach
- Tiling window manager with virtual desktops, tab groups, and multi-client layout sync
- Structured chat view with tool visualization, interactive permissions, and goals tracking
- File explorer, code editor, and cross-host session management with remote storage support

## Why It Matters for RAG Builders
VibeSpace streamlines the management of multiple coding agent sessions in a single, persistent workspace, making it essential for AI engineers building complex agent-based workflows.
