## Summary
Accountant24 is a local-first AI agent for personal finance that allows users to track spending, import bank statements and receipts, and query financial data using natural language. All data is stored as plain text files on the user's machine and versioned with git.

## Key Features
- Natural language spending logging and transaction categorization
- Automated import of bank statements and receipts with text extraction
- Built-in git versioning for all financial data changes
- Support for both cloud and local LLM providers (e.g., Ollama)
- Persistent memory for user-defined rules and budget tracking

## Why It Matters for RAG Builders
It demonstrates how AI agents can automate complex, rule-bound tasks like personal finance while ensuring data privacy and auditability through local storage and version control.
