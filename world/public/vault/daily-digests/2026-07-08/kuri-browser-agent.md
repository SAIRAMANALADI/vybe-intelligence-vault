## Summary
A lightweight, token-efficient browser automation extension for Gemini CLI and Claude Code, powered by the Kuri engine and Model Context Protocol (MCP). It enables web navigation, scraping, and form-filling with stealth features and device presets.

## Key Features
- Lightweight and token-efficient browser automation using Kuri's `@eN` accessibility system
- Seamless integration with Gemini CLI and Claude Code via MCP bridge
- Built-in stealth features to bypass bot detection
- Device presets for easy switching between mobile and desktop environments
- Automatic cleanup of Chromium processes to prevent leaks

## Why It Matters for RAG Builders
It provides a critical bridge for AI agents to interact with the web efficiently, reducing token usage and enabling stealthy, high-fidelity browsing for RAG pipelines.
