## Summary
A Model Context Protocol (MCP) server that provides typed, structured access to GitHub's API for managing repositories, issues, pull requests, branches, releases, and repository governance rules. Enables AI agents to interact with GitHub programmatically.

## Key Features
- Typed MCP tools for structured GitHub API interactions
- Comprehensive repository management (create, fork, update, delete)
- Advanced search capabilities (repositories, code, issues, PRs, users)
- Atomic multi-file commits and file updates with SHA validation
- Repository governance enforcement (branch protection, rulesets, PR reviews)

## Why It Matters for RAG Builders
Provides AI agents with a standardized, typed interface to GitHub's API, enabling seamless integration for repository management, issue tracking, and code search in RAG pipelines.
