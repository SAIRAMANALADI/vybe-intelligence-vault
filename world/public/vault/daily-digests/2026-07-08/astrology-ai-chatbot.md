## Summary
An open-source AI astrology chatbot that integrates real astrological calculations (Western, Vedic, tarot, numerology, etc.) via RoxyAPI's remote MCP tools, avoiding LLM hallucinations. It supports multi-LLM providers, auto-discovers tools, and deploys in 30 minutes with a space-themed UI.

## Key Features
- Real astrological calculations via RoxyAPI's verified tools (no hallucinations)
- Auto-discovered MCP tools for 11 spiritual domains (Western/Vedic astrology, tarot, numerology, etc.)
- Multi-LLM support (Gemini, Claude, GPT) with unified Vercel AI SDK interface
- Space-themed UI with streaming responses and markdown formatting
- Deployable in 30 minutes with Vercel or local setup
