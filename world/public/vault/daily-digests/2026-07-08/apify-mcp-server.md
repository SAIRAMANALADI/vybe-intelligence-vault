## Summary
The Apify MCP Server bridges AI agents with the Apify platform, enabling dynamic discovery and execution of thousands of web scraping, crawling, and automation tools (Actors) via the Model Context Protocol (MCP). It supports structured data extraction from social media, search engines, maps, and e-commerce sites, with built-in agentic payment solutions like x402 and Skyfire.

## Key Features
- Dynamic discovery and execution of 8,000+ Apify Actors as MCP tools with auto-generated input schemas
- Supports agentic payments via x402 (USDC on Base) and Skyfire (PAY tokens) for frictionless Actor run funding
- Hosted server (mcp.apify.com) with OAuth support for seamless integration with clients like Claude.ai and VS Code
- Streamable HTTP transport for reliable MCP client-server communication
- Telemetry and structured output for monitoring and debugging AI agent workflows
