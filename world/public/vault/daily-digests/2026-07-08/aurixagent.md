## Summary
AURIX Agent is a terminal-native autonomous AI workspace that executes real-world tasks like browser automation, code editing, bug hunting, and research. It operates in your environment with over 40 tools and 280+ skills, supporting multi-agent workflows and integrations with messaging platforms.

## Key Features
- Stealth browser automation with CAPTCHA/verification solving (image, audio, slider challenges)
- Bug Hunt skill system for CTF, security testing, and reverse engineering
- Social and deep research capabilities across platforms (Reddit, X, YouTube, etc.)
