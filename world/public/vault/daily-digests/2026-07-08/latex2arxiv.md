## Summary
latex2arxiv automates the preparation and submission of LaTeX papers to arXiv by cleaning projects, catching common submission errors, and generating upload guides. It supports terminal, browser extension, MCP, GitHub Action, and VS Code workflows.

## Key Features
- One-command cleaning and validation of LaTeX projects for arXiv submission
- Pre-flight checks to catch arXiv-specific rejection errors (e.g., shell-escape packages, missing .bbl files)
- Generates step-by-step upload guides with metadata extraction
- Supports multiple interfaces: terminal, VS Code, Chrome extension, MCP, and GitHub Actions
- Customizable cleanup rules via YAML config for project-specific needs

## Why It Matters for RAG Builders
It streamlines arXiv submissions by automating error-prone cleanup and validation, reducing rejections and saving researchers critical time.
