## Summary
A research-focused personal AI assistant implementing a biologically-inspired cognitive architecture with persistent memory, local LLM inference, and agentic orchestration. Designed for educational and experimental exploration of autonomous AI systems.

## Key Features
- 7-stage pre-LLM gateway pipeline (security, governance, intent classification, context assembly, budget management)
- Seshat memory protocol with episodic-to-semantic promotion pipeline using Neo4j
- Single-brain architecture with Qwen3.5-35B as sole reasoning center and no role-switching
- Delegation and expansion strategies with structured handoffs and concurrent sub-agent execution
- Homeostasis loop (Brainstem) for system monitoring, consolidation, and adaptive behavior

## Why It Matters for RAG Builders
It provides a research-grade framework for building and studying agentic AI systems with persistent memory and local LLM inference, critical for advancing autonomous AI architectures.
