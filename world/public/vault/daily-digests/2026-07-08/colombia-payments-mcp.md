## Summary
A remote MCP server that enables AI agents to accept payments in Colombia via Mercado Pago's hosted checkout, supporting PSE, Nequi, cards, and Efecty cash. It acts as a stateless translation layer between AI agents and payment processors.

## Key Features
- Stateless payment processing with no credential storage or fund holding
- Supports multiple Colombian payment methods (PSE, Nequi, cards, Efecty)
- Hosted checkout integration via Mercado Pago
- Streamable HTTP and JSON-RPC interface for AI agents
- Test and production modes with Mercado Pago access tokens

## Why It Matters for RAG Builders
