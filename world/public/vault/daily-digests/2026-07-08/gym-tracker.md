## Summary
Gym Coach is an AI-powered personal trainer agent integrated with Telegram, enabling users to interact via chat to receive personalized workout plans and real-time guidance through a Mini App. The system uses an MCP server to connect agents (like Hermes) to a FastAPI backend and Postgres database, automating workout creation, tracking, and adaptation based on user feedback.

## Key Features
- AI-driven workout planning and adaptation via natural language in Telegram
- Real-time exercise tracking and feedback through a visual Mini App
- Multi-user support with automatic user identification via Telegram InitData
- MCP server enabling agent-agnostic integration with AI assistants like Hermes or Claude
- Modular architecture with FastAPI backend, static frontend, and PostgreSQL database

## Why It Matters for RAG Builders
It provides a scalable, agent-agnostic framework for building AI-powered personal trainers that can dynamically adapt workouts and interact with users in real-time through familiar interfaces like Telegram.
