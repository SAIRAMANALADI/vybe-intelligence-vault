## Summary
A remote MCP server that enables AI agents to accept payments in the Netherlands via Mollie's hosted checkout, supporting iDEAL, cards, Bancontact, and other payment methods. It acts as a stateless translation layer between buyers and merchants without holding funds or storing credentials.

## Key Features
- Stateless translation layer for secure payment processing
- Supports multiple Dutch payment methods (iDEAL, cards, Bancontact)
- Integrates with Mollie's hosted checkout for direct fund flow
- Zero runtime dependencies and minimal configuration
- Compatible with major AI agents (Claude, ChatGPT, Cursor)

## Why It Matters for RAG Builders
