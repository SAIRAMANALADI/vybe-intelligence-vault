## Summary
Cambio Uruguay is an open-source platform that provides real-time comparison of buy/sell exchange rates for multiple currencies across Uruguayan financial institutions. It offers a live rate comparator, historical charts, currency calculators, and a map of exchange houses, all accessible via a trilingual interface.

## Key Features
- Live comparison of 40+ Uruguayan exchange houses and banks for 14+ currencies
- Trilingual support (Spanish, English, Portuguese)
- Public API with no authentication required
- Model Context Protocol (MCP) server for AI assistants
- Interactive map and historical rate charts

## Why It Matters for RAG Builders
Cambio Uruguay provides critical real-time financial data for Uruguay, enabling AI systems to integrate accurate and up-to-date exchange rate information for RAG applications.
