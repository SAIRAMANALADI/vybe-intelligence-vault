## Summary
AgentShield is a security observability layer for AI-powered coding agents that monitors, mitigates, and audits agent guard surface vulnerabilities using hash-anchored permission chains and sandbox intent inference. It acts as a firewall between agent actions and production environments, providing cryptographic audit trails and real-time threat detection.

## Key Features
- Hash-anchored permission chains for tamper-proof audit trails using SHA-3
- Sandbox intent inference with behavioral ML models to predict and block risky commands
- Multi-agent support for Claude Code, Codex, Gemini CLI, and Cursor with granular permission controls
- Real-time threat dashboard with cryptographic ledger and rollback capabilities
- Natural language rule creation via LLM integration (OpenAI, Claude API) for policy definition

## Why It Matters for RAG Builders
AgentShield provides critical security oversight for AI coding agents, preventing catastrophic automation errors and ensuring compliance with auditable, cryptographic proof of every agent action.
