## Summary
Harness is a unified family of AI applications that enables users to control local coding agents (Claude Code, Codex, or Harness Code) via a native iPhone app over Tailscale. It bridges local AI workflows with mobile accessibility, ensuring private, zero-middleman interactions while supporting BYOK (Bring Your Own Key) models.

## Key Features
- Native iPhone app for controlling local AI coding agents (Claude Code, Codex, Harness Code) over Tailscale
- Private, zero-middleman architecture with BYOK model support (340+ via OpenRouter or local Ollama)
- Real-time streaming of agent outputs, markdown rendering, and tool approval workflows with push notifications
- Server-driven model catalog and path-scoped file previews with security denylists
- Cross-device synchronization (iOS, web, desktop) for seamless AI workflows
