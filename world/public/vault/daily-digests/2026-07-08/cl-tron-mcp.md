## Summary
cl-tron-mcp is an MCP server for Common Lisp that integrates with Swank to enable deep debugging, introspection, hot code reloading, and live session management for AI agents and tools. It bridges Common Lisp environments with MCP clients for agentic programming workflows.

## Key Features
- Deep debugger integration with Swank for stack inspection and local variable analysis
- Hot code reloading and live session management without restarting the Lisp image
- 91+ tools across 14 categories for code evaluation, profiling, and system management
- Supports both SBCL and ECL with stdio or HTTP transport modes
- Seamless integration with MCP clients like Cursor, Copilot, or custom AI agents

## Why It Matters for RAG Builders
It enables AI agents to interactively debug, inspect, and modify Common Lisp code in real-time, bridging the gap between agentic workflows and Lisp's dynamic development environment.
