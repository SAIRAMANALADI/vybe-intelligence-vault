## Summary
BridgeBot is an AI-powered Discord support agent that integrates with LLMs, ParadeDB BM25 for knowledge retrieval, and external APIs to automate server support tasks. It supports multi-tenant architectures and provides analytics for conversations.

## Key Features
- AI-powered Discord support agent with LLM integration
- ParadeDB BM25 for relevance-based knowledge retrieval with MongoDB fallback
- Multi-tenant architecture with APP_MODE deployment options
- External API access for chat and analytics
- Conversation analytics dashboard for monitoring and insights
