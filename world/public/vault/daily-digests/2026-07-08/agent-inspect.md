## Summary
agent-inspect is a TypeScript library and CLI tool for tracing, inspecting, and safely sharing AI agent execution runs locally. It converts agent interactions into structured execution trees without requiring cloud uploads or hosted dashboards, enabling local debugging, CI integration, and safe artifact sharing.

## Key Features
- Converts AI agent runs into readable local execution trees with tool calls, LLM steps, retries, and failures
- Supports multiple frameworks (Vercel AI SDK, OpenAI Agents, LangChain) via adapters
- Provides CLI for inspecting, reporting, diffing, and redacting traces locally
- Enables CI integration with failure checks and artifact generation
- Offers deterministic redaction profiles for safe sharing of traces

## Why It Matters for RAG Builders
It provides a lightweight, local-first solution for debugging, analyzing, and sharing AI agent executions without cloud dependencies, making it essential for developers building and iterating on agentic systems.
