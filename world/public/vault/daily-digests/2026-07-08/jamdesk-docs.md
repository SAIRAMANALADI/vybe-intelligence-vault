## Summary
This repository contains the source files for the Jamdesk documentation platform, demonstrating how to build and deploy documentation sites from MDX files. It serves as both a guide and a working example for Jamdesk users, showcasing features like AI chat, OpenAPI integration, and custom domains.

## Key Features
- MDX-based documentation with hot reload for local development
- Built-in AI chat with RAG and MCP server integration
- Automatic llms.txt generation and OpenAPI spec support
- Customizable themes, branding, and deployment options
- Integrated analytics and custom domain support
