## Summary
NSForge is an MCP server that transforms conceptual goals into verifiable, traceable mathematical formulas through deterministic symbolic derivation with full provenance tracking. It bridges AI-driven planning with rigorous symbolic computation, ensuring every step is recorded and verifiable.

## Key Features
- Deterministic formula derivation with full provenance tracking for every step
- Integration with SymPy-MCP for symbolic computation and verification
- Autonomous task orchestration via Derivation Task Spec (DTS) for multi-path exploration
- 10-gate verification harness ensuring correctness and completeness of derivations
- Reification ladder for climbing from concepts to executable, provenance-bound code

## Why It Matters for RAG Builders
NSForge provides a critical layer of verifiable symbolic computation and provenance tracking for RAG systems, ensuring AI-generated formulas are mathematically sound and traceable.
