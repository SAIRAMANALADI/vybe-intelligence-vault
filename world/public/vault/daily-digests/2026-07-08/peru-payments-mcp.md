## Summary
A remote MCP server that enables AI agents to accept payments in Peru via Mercado Pago's hosted checkout, supporting Yape, PagoEfectivo, cards, and Mercado Pago wallet. It acts as a stateless translation layer between AI agents and payment processors.

## Key Features
- Stateless translation layer for secure payment processing in Peru
- Supports multiple payment methods (Yape, PagoEfectivo, cards, Mercado Pago wallet)
- Zero runtime dependencies and no database required
- MIT licensed and compatible with Node.js ≥ 18
- Provides tools for creating payment links and querying payment status

## Why It Matters for RAG Builders
It enables AI agents to seamlessly accept payments in Peru without handling sensitive financial data, reducing compliance and security burdens for RAG builders.
