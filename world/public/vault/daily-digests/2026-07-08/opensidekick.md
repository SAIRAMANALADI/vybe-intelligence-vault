## Summary
OpenSidekick is an open-source MIT-licensed Chrome extension that provides an AI agent in the browser's side panel, capable of reading and acting on web pages using any LLM provider (local or cloud-based). It enables autonomous browser control, multi-tab navigation, and workflow automation while keeping API keys and data private within the user's browser.

## Key Features
- Side-panel chat with page-aware agentic capabilities (click, type, navigate, etc.)
- Multi-provider support (OpenRouter, OpenAI, Anthropic, Gemini, Groq, Ollama, LM Studio)
- Vision mode for multimodal models and developer tools for debugging
- Safety layers including approval modes, prompt-injection flagging, and sensitive-site protections
- Workflow recording, scheduled tasks, and MCP tool server integration

## Why It Matters for RAG Builders
OpenSidekick provides a fully open-source, privacy-preserving alternative to vendor-locked browser agents, enabling RAG builders to integrate autonomous web interaction capabilities without sacrificing control over data or model choice.
