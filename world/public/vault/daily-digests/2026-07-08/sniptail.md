## Summary
Sniptail is an omnichannel bot that enables teams to interact with codebases via Slack, Discord, or Telegram, executing coding agent jobs against approved repositories and posting back reports or merge requests. It bridges non-technical users with AI coding agents for repo analysis and automated changes.

## Key Features
- Supports Slack, Discord, and Telegram for multi-platform accessibility
- Runs coding agent jobs (Codex, Copilot, OpenCode, ACP) against configured repositories
- Enables interactive agent sessions in chat threads with follow-up prompts
- Queues and tracks jobs for structured requests (ASK, PLAN, EXPLORE, etc.)
- Posts back reports, completion messages, or merge requests (PR/MR) to the originating channel

## Why It Matters for RAG Builders
Sniptail enables non-technical teams to safely interact with and modify codebases using trusted AI agents, reducing dependency on manual code reviews and accelerating development workflows.
