## Summary
A Cursor plugin wrapper for the devutils-mcp-server, providing 36 local developer utilities (hashing, encoding, UUID, JWT, JSON, network, text) via the Model Context Protocol (MCP) with zero API keys required.

## Key Features
- 36 local developer utilities (hashing, encoding, UUID, JWT, JSON, network, text) with zero API keys
- Seamless integration with Cursor and Claude Code via MCP
- Supports direct server usage for any MCP client
- Privacy-focused: all tools run locally with no data sent externally
- Easy installation via Cursor Marketplace or GitHub
