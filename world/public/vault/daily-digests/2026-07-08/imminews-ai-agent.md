## Summary
An automated AI agent that monitors European immigration, investment, and visa regulation news using Google's Gemini AI. It generates professional social media drafts (Twitter/LinkedIn) and delivers them via Telegram notifications.

## Key Features
- Automated news monitoring via Google News RSS with rotating keywords
- Gemini AI-powered analysis for generating optimized social media drafts
- Telegram notifications with HTML-formatted content delivery
- Cloud-native deployment via GitHub Actions with 24/7 autonomy
- Deduplication system to prevent duplicate news article processing
