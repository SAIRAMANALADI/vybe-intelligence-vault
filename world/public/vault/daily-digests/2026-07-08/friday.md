## Summary
Ares is a terminal-first personal AI assistant with local memory, project context awareness, and 68+ integrated tools for file operations, web search, code execution, and device bridges. It supports voice mode, cron scheduling, and an Electron desktop client with a WebSocket backend.

## Key Features
- 68+ built-in tools for file, web, code, and device operations with OpenAI function calling format
- SQLite-based memory with vector and keyword search, deduplication, and automatic extraction
- Project context discovery from files like AGENTS.md, CLAUDE.md, and README.md
- Voice mode with local STT/TTS fallback and optional Sarvam AI integration
- Cron scheduling, desktop client (Electron + React), and WebSocket backend

## Why It Matters for RAG Builders
Ares provides a robust, local-first agent framework with deep tool integration and memory management, making it ideal for building RAG systems that require persistent context and multi-modal tool usage.
