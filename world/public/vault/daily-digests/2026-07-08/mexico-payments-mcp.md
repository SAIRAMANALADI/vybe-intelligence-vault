## Summary
A remote Model Context Protocol (MCP) server that enables AI agents to accept payments in Mexico via Mercado Pago's hosted checkout, supporting OXXO vouchers, SPEI transfers, cards, and Mercado Pago wallets. It acts as a stateless translation layer without storing funds or credentials.

## Key Features
- Stateless translation layer for payment processing in Mexico
- Supports multiple payment methods (OXXO, SPEI, cards, Mercado Pago wallet)
- Hosted checkout integration via Mercado Pago
- Zero runtime dependencies and no database
- Compatible with AI agents (Claude, ChatGPT, Cursor) via MCP

## Why It Matters for RAG Builders
It enables AI agents to seamlessly accept payments in Mexico, expanding their functionality for real-world transactions without requiring direct integration with Mercado Pago.
