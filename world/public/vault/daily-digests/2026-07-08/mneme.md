## Summary
Mneme HQ is an architectural governance layer for AI-assisted development that enforces project-specific architectural decisions during LLM calls to prevent drift and ensure consistency with prior engineering choices. It uses a deterministic retriever to inject structured decision records into prompts and validates outputs against governance rules.

## Key Features
- Structured project memory for storing architectural decisions in JSON format
- Deterministic retriever that selects relevant decisions for any given task
- Pre-flight enforcer that flags violations before LLM generates output
- Reproducible benchmark suite for regression testing and integrity validation
- Integration with IDEs, agent frameworks, and CI pipelines for governance enforcement
