## Summary
RouteMIDI is a multi-platform command-line tool for routing, filtering, and transforming MIDI messages between input and output ports. It enables flexible MIDI patchbay functionality with support for JavaScript scripting and an MCP server for programmatic control, making it ideal for MIDI processing workflows.

## Key Features
- Multi-platform MIDI port routing with filtering and transformation capabilities
- JavaScript scripting for custom message processing
- Built-in Model Context Protocol (MCP) server for AI and script integration
- Extensive MIDI message manipulation (channels, notes, CC, RPN, NRPN, etc.)
- Pre-built binaries and Homebrew package for easy installation

## Why It Matters for RAG Builders
RouteMIDI enables precise MIDI message routing and transformation, which is essential for integrating MIDI devices and synthesizers into AI-driven music or audio workflows.
