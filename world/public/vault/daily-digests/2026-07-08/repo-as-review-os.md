## Summary
GitLearnOS (formerly Repo-as-Review-OS) is a GitHub-native operating system designed to transform AI from a one-off chat partner into a long-term study assistant by structuring learning traces, review records, and knowledge hierarchies directly in a user's repository.

## Key Features
- Structured learning state management via GitHub repositories
- Goal-driven workflow with source grounding, knowledge gaps, and practice sets
- Spaced repetition and automated review scheduling
- Agent handoff and runtime alignment between AI tools and GitHub
- Lightweight static/dynamic personalization layers for adaptive tutoring

## Why It Matters for RAG Builders
It provides a durable, inspectable workspace for AI agents to continuously manage and improve personalized learning processes directly in GitHub.
