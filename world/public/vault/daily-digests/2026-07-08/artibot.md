## Summary
Artibot is a cognitive orchestration OS for Claude Code that enables hierarchical memory, RLVR self-learning, and multi-platform agent teams. It provides full Agent Teams orchestration with 28 specialized agents, 114 domain skills, and 73 slash commands for TDD, code review, security audits, and marketing workflows.

## Key Features
- Dual-process cognitive architecture (System 1/2) for intelligent task routing
- Native Agent Teams API integration for true team orchestration with P2P communication
- RLVR-based lifelong learning with automatic knowledge transfer between systems
- 73 slash commands and 28 specialized agents for TDD, security, and marketing workflows
- Cross-platform compatibility with adapters for Claude Code, Gemini CLI, and OpenAI Codex
