## Summary
thClaws is a native-Rust AI agent harness that provides a sovereign, multi-surface workspace for coding, automation, and coordination. It operates as a single binary across desktop GUI, CLI, headless, and webapp modes, supporting multi-provider LLMs and built-in tools for media generation, scheduling, and memory management.

## Key Features
- Single-binary deployment across GUI, CLI, headless, and webapp modes
- Multi-provider LLM support with dynamic model switching and OpenRouter Fusion for multi-model consensus
- Built-in media generation tools (text-to-image, image-to-image, text-to-video, image-to-video) with live galleries
- Agent orchestration with subagents, concurrent side-channels, and multi-process Agent Teams
- Knowledge management system (KMS) with grep-based indexing and session memory via `/dream`

## Why It Matters for RAG Builders
thClaws provides a sovereign, multi-surface agent framework with built-in tools and MCP integration, enabling developers to build, deploy, and scale AI agents without vendor lock-in or cloud dependency.
