## Summary
Paca is a self-hosted, open-source project management platform designed for AI-native collaboration, enabling humans and AI agents to work together as equal teammates within Scrum teams. It replaces tools like Jira or Trello with a lightweight, fully customizable alternative focused on real-time collaboration and extensibility via plugins.

## Key Features
- Unified Scrumban board for humans and AI agents to collaborate in real time
- In-app AI chat for project planning and task management in plain English
- Fully customizable via configuration files and WASM-based plugin system
- MCP server for integrating any AI agent with structured access to workspace data
- Activity diff and revert for tracking and undoing changes to tasks and documents

## Why It Matters for RAG Builders
Paca enables AI agents to participate as first-class teammates in agile workflows, bridging the gap between human and machine collaboration in project management.
