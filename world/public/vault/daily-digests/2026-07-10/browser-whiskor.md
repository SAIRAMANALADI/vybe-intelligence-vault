## Summary
browser-whiskor is a Chrome/Firefox extension paired with an MCP server that enables AI agents to perceive and navigate browser states with framework-aware insights, DOM structure, pixel-precise text coordinates, network traffic, and a semantic state graph for UI navigation.

## Key Features
- Framework-aware state inspection (React, Vue, Angular, Svelte, etc.) including component trees, hooks, stores, and router state
- Pixel-precise text coordinates and OCR-style text extraction for UI elements
- Semantic state graph with auto-generated labels, tags, and navigation paths between recorded UI states
- Network traffic monitoring, console logs, and accessibility tree analysis
- Integration with MCP for AI agent communication and HTTP/WebSocket APIs for cache and configuration

## Why It Matters for RAG Builders
It provides AI agents with deep, structured browser perception and state navigation capabilities, enabling more accurate and context-aware interactions with web applications.
