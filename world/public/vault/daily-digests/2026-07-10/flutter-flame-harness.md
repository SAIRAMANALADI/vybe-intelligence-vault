## Summary
A Claude Code plugin that automates the end-to-end development of Flutter/Flame games, from initial idea to App Store deployment. It orchestrates a structured pipeline including research, planning, design, contract negotiation, and a generator-evaluator build loop with QA gates.

## Key Features
- End-to-end game development pipeline from idea to store submission
- Generator-evaluator build loop with strict QA gates
- Automated AdMob integration, build, and store submission
- Multi-phase skill-based orchestration (research, plan, design, contract, build, deploy)
- Built-in security and credential management with strict .gitignore policies

## Why It Matters for RAG Builders
It streamlines the entire Flutter/Flame game development lifecycle, reducing manual effort and ensuring high-quality, deployable outputs through automated QA and deployment pipelines.
