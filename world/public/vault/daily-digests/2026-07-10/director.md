## Summary
Director is a local-first MCP (Model Context Protocol) playbook manager for AI agents, enabling the creation, sharing, and integration of portable skill sets (playbooks) via MCP tools, prompts, and configuration. It simplifies agent integration with 1-click setup for popular clients like Claude, Cursor, and VSCode.

## Key Features
- Portable playbooks for AI agents with MCP tools, prompts, and configuration
- 1-click integration with popular AI clients (Claude, Cursor, VSCode)
- Local-first architecture with 30-second setup and unified OAuth
- Tool filtering, observability, and strong isolation for MCP management
- TypeScript SDK for programmatic control and extensibility

## Why It Matters for RAG Builders
Director streamlines the integration and management of MCP-based skills for AI agents, reducing setup complexity and enabling portable, shareable playbooks essential for scalable RAG systems.
