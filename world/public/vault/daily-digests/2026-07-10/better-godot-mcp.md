## Summary
A composite MCP server for the Godot Engine that provides 17 AI-assisted tools for game development, enabling direct manipulation of scene files, GDScript, shaders, animations, and more without requiring the Godot editor to be running.

## Key Features
- 17 composite tools for scene, node, script, shader, animation, and physics management
- Direct `.tscn` file parsing and modification without Godot editor
- GDScript CRUD operations (create, read, write, attach)
- Token-tiered tool descriptions for optimized AI interactions
- Supports stdio and HTTP transports with Docker deployment

## Why It Matters for RAG Builders
It enables AI agents to programmatically interact with and modify Godot projects, streamlining AI-assisted game development workflows.
