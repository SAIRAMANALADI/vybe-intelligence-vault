## Summary
Breakpoint MCP is an MCP-compatible server that integrates the Godot game engine into an AI assistant's development workflow, enabling real-time scene authoring, GDScript development with type-aware diagnostics, live debugging, and game execution within a single inner loop.

## Key Features
- 242 tools and 5 MCP resources for comprehensive Godot interaction, including scene/node/resource CRUD, live debugging, and runtime control.
- Integration with Godot's built-in LSP and DAP for type-aware GDScript development, diagnostics, and real-time debugging.
- Undo-safe editing with full `EditorUndoRedoManager` support, ensuring changes can be reverted.
- Headless CLI for running Godot projects, exports, and tests without a GUI.
- Runtime bridge for live game interaction, including property manipulation, input injection, and frame capture.

## Why It Matters for RAG Builders
Breakpoint MCP bridges the gap between AI assistants and game development by enabling real-time, interactive collaboration with the Godot engine, reducing manual effort in scene authoring, debugging, and testing.
