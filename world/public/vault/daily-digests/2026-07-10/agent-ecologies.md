## Summary
Agent-Worlds is a multi-agent operating system for creating autonomous LLM-powered NPCs that inhabit a persistent 2D pixel-art world. It enables AI characters to live autonomously with memory, skills, social dynamics, and emergent behaviors, serving as a sandbox for AI research and game development.

## Key Features
- Autonomous agent cycles with daily routines and needs
- Multi-LLM architecture with MCP protocol integration
- Persistent memory and skill learning systems
- Pixel-art 2D world with real-time visualization
- Social relationship dynamics and emergent narratives

## Why It Matters for RAG Builders
It provides a framework for building and studying autonomous AI agents in persistent environments, enabling emergent behaviors and interactions that are critical for advanced RAG and AI system development.
