## Summary
CodeFRAME is a project delivery system that orchestrates AI agents to handle the full software development lifecycle, from requirements gathering to deployment. It automates upstream pipeline tasks like Socratic requirements discovery and recursive decomposition, while enforcing quality gates and proof obligations to ensure reliable software delivery.

## Key Features
- Socratic requirements gathering and recursive task decomposition for AI agents
- PROOF9 quality system with 9 verification gates and closed-loop quality compounding
- Agent-agnostic execution supporting Claude Code, Codex, OpenCode, Kilocode, and built-in ReAct agent
- Radical simplicity with a single CLI binary, SQLite backend, and no daemons or infrastructure
- Automated verification, self-correction, stall detection, and human-in-the-loop blocker resolution

## Why It Matters for RAG Builders
CodeFRAME bridges the gap between AI coding agents and reliable software delivery by automating upstream pipeline tasks and enforcing quality gates, ensuring AI-generated code meets production standards.
