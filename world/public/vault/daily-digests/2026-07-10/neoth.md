## Summary
NEOTH is a local-first personal AI system designed to act as a loyal, private assistant with verifiable memory, consent-gated tools, and a signed audit trail. It integrates multi-tier memory, role-bound brain paths, and a WASM plugin sandbox to support daily life, coding, and autonomous workflows while prioritizing user privacy and control.

## Key Features
- Five-tier memory system (episode, profile, ground truth, consolidated, long-term) with external vault integration
- Consent-gated tools, plugins, and autonomous actions with signed audit logs (WAL)
- Role-bound brain paths for fast answers, reasoning, and verification
- Babel-Index collapse prediction for self-diagnosis and early warning
- Multi-channel support (GUI, CLI, Telegram, Slack, Discord, etc.) and private mesh networking
