## Summary
OrgX MCP provides shared organizational memory for AI agents (Claude, ChatGPT, Cursor) to remember decisions, artifacts, tasks, and project context. It enables agents to recall past work, track initiative health, delegate tasks, and render interactive workflows via MCP-compatible clients.

## Key Features
- Shared memory for AI agents to recall decisions, artifacts, and tasks across sessions
- Initiative health tracking with blockers, milestones, and activity pulses
- Task delegation and specialist agent spawning with approval workflows
- Interactive MCP Apps-compatible widgets for real-time workflow rendering
- OAuth 2.1 dynamic client registration and PKCE for secure agent authentication

## Why It Matters for RAG Builders
OrgX MCP is essential for RAG builders as it provides a centralized, persistent organizational memory layer that enables AI agents to retain context, track decisions, and execute workflows across sessions, significantly enhancing long-term reasoning and task continuity.
