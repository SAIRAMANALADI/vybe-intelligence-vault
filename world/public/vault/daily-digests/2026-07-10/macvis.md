## Summary
MacVis is a local-first, open-source AI agent for macOS that provides full system access, multi-provider model routing, and MCP integrations. It operates entirely on the user's machine with no backend or telemetry, offering persistent memory, project management, and a secure sandboxed environment.

## Key Features
- Multi-provider model routing with fallback chain (Claude, GPT, Gemini, Ollama, etc.)
- Full system access via 35+ native tools (bash, filesystem, web search, OCR, etc.)
- Persistent memory and project management with automatic workspace organization
- Secure sandboxing, approval gates, and telemetry-free operation
- MCP integrations for GitHub, Vercel, Supabase, and more

## Why It Matters for RAG Builders
MacVis enables developers to build and deploy secure, local-first AI agents on macOS with multi-provider flexibility and full system integration, reducing reliance on cloud-based solutions.
