## Summary
Uni-CLI is a universal computer-control platform for agents, enabling intent-driven execution across websites, browsers, desktop apps, local tools, and agent protocols. It acts as an agent control plane that governs software actions, returns evidence receipts, and supports self-repair for complex tasks.

## Key Features
- Unified intent-to-action loop for agents across diverse substrates (web, desktop, CLI, MCP, ACP)
- Governed execution with policy profiles (open, confirm, locked) for safe operations
- AgentEnvelope v2 returns structured evidence, context, and retryability for diagnostics
- Self-repair mechanism via `unicli delivery` for diagnosing and repairing failed paths
- Discoverable operations via `unicli search` and `unicli do` for dynamic intent resolution

## Why It Matters for RAG Builders
Uni-CLI provides the critical control surface for agents to safely and reliably interact with real software environments, bridging the gap between agent intent and governed execution across multiple substrates.
