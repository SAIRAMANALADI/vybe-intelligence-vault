## Summary
A Model Context Protocol (MCP) server enabling AI agents to interact with IMAP/SMTP email systems, supporting multi-account management, auto-discovery, and composite tools for reading, sending, and organizing emails with attachments.

## Key Features
- Multi-account email management (Gmail, Outlook, Yahoo, etc.) with auto-discovery
- Composite tools for 21+ actions (search, read, send, reply, organize, attachments)
- HTTP multi-user mode with OAuth 2.1 and per-JWT-sub credential storage
- App Password support for providers without OAuth setup
- Tiered token optimization and MCP Resources for efficient AI agent interactions

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate email workflows, enhancing automation and productivity for tasks requiring email interactions.
