## Summary
model-compose is a declarative YAML-based runtime for composing, deploying, and scaling AI systems including agents, RAG pipelines, and MCP servers. It enables hybrid AI workflows by integrating local models and cloud APIs without vendor lock-in, inspired by docker-compose's simplicity.

## Key Features
- Declarative AI system composition via YAML with no application code required
- Hybrid-first architecture enabling seamless switching between local models and cloud APIs
- 20+ reusable components including models, agents, vector stores, HTTP clients, and MCP servers
- Portable deployment across native, Docker, and distributed environments with a single configuration
- Built-in support for real-time streaming, human-in-the-loop workflows, and distributed execution

## Why It Matters for RAG Builders
It eliminates vendor lock-in for RAG builders by enabling portable, hybrid AI workflows that can run anywhere with a single YAML configuration.
