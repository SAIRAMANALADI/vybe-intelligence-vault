## Summary
mcp-probe-kit is an MCP (Model Context Protocol) server toolkit designed to provide AI agents with deep contextual understanding of projects through 30 structured tools, covering the entire development lifecycle from requirements to release. It enables context-aware orchestration, code analysis, memory retrieval, and UI/UX utilities for AI-driven development workflows.

## Key Features
- 30 structured tools covering the full development lifecycle (requirements, design, development, quality, release)
- Context-aware orchestration with delegated task execution and progress tracking
- Integrated memory system using Qdrant for semantic search and reusable asset storage
- Code graph bridge (GitNexus) for impact analysis and dependency mapping
- Quality constraints engine enforcing coding standards, UI/UX rules, and anti-laziness templates

## Why It Matters for RAG Builders
It provides essential context orchestration and memory tools that enable AI agents to understand, plan, and execute complex development tasks with structured precision, reducing hallucinations and improving reliability in RAG pipelines.
