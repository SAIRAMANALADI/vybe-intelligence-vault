## Summary
Abu is a locally-run AI desktop assistant inspired by Claude Code's Cowork mode, enabling autonomous task execution, file operations, and multi-agent workflows with privacy-first design. It supports natural language interaction, built-in skills, and integrations with multiple AI providers and tools.

## Key Features
- Autonomous task execution with planning and tool invocation
- Multi-agent parallel execution (up to 5 agents)
- Built-in 28+ skills with self-evolving capabilities
- Privacy-safe local data processing with sandboxing
- Cross-platform IM bot integration (Lark, DingTalk, Slack, etc.)

## Why It Matters for RAG Builders
Abu provides a robust, locally-run framework for building autonomous AI agents that can handle complex, multi-step tasks while ensuring privacy and user control, making it ideal for RAG builders seeking to integrate agentic workflows.
