## Summary
A project template for Loop Engineering, an AI-agent-assisted development methodology that implements a Work → Learn → Improve cycle to continuously enhance agent performance through structured knowledge extraction and skill reuse.

## Key Features
- Predefined agent skills for Work → Learn → Improve cycle
- Integration with agentskills.io for standardized skill definitions
- Built-in CI/CD workflows for validation and testing
- Support for multiple AI agents (Hermes, Opencode, Claude, etc.)
- Automated project bootstrapping and task management

## Why It Matters for RAG Builders
