## Summary
CodeContext is a cross-platform C# CLI tool and MCP server that converts codebases into structured text for LLM consumption, enabling efficient prompt engineering and agentic coding workflows. It intelligently filters irrelevant files, optimizes token usage, and integrates with MCP-compatible agents like Claude Code.

## Key Features
- Hierarchical project structure visualization with intelligent filtering
- Token budget optimization and relevance-based file selection for MCP agents
- Git-aware filtering and binary file detection
- Multiple output formats (text and JSON) with dynamic context generation
- Cross-platform CLI and MCP server integration for agentic workflows

## Why It Matters for RAG Builders
