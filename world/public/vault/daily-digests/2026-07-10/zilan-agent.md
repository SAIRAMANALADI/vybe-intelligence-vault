## Summary
A dual-track Buddhist AI agent framework designed for LLM-based reasoning and retrieval, combining a lightweight skill mode for daily practice with an agent mode for deep Agama corpus analysis, Buddhist logic chains, and cross-domain research.

## Key Features
- Dual-mode operation (Skill/Agent) for flexible interaction depth
- Specialized retrieval from Agama corpus with stable citations
- Built-in Buddhist logic engines (因明, 摄类学, Hetuvidya)
- Cross-platform compatibility (Claude Code, OpenAI API, Volcengine, etc.)
- Rigorous validation and regression testing for reasoning contracts

## Why It Matters for RAG Builders
Provides a structured, validated framework for integrating Buddhist reasoning and retrieval into LLM-based AI systems, enabling domain-specific logic and corpus-driven responses.
