## Summary
Covel is an agentic AI-powered role-playing game (RPG) framework where every game mechanic is implemented as a customizable plugin. It enables dynamic world-building, multi-agent NPC interactions, and persistent memory across sessions, with support for both visual novel (stage mode) and text-based storytelling.

## Key Features
- Modular plugin architecture for customizing game mechanics and NPC behaviors
- Multi-agent turn system with parallel processing for world state, memory, and NPC relationships
- Visual novel (stage mode) and text-based storytelling with dynamic scene generation
- Support for multiple LLM providers (OpenAI, Anthropic, DeepSeek, Qwen) with local-first SQLite storage
- Built-in tools for creating custom worlds and plugins via AI-assisted workflows

## Why It Matters for RAG Builders
It provides a flexible framework for building agentic AI-driven narratives with customizable mechanics, making it valuable for developers creating interactive storytelling or RPG experiences.
