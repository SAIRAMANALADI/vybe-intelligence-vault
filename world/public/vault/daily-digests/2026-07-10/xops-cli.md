## Summary
XOps CLI is a modern Go-based command-line toolkit for server management and automation, integrating Model Context Protocol (MCP) for AI-driven infrastructure interactions. It combines SSH management, batch execution, declarative playbooks, and encrypted asset management into a single cross-platform binary.

## Key Features
- Native MCP server for secure AI-Agent infrastructure interactions with risk assessment and policy controls
- Enhanced SSH with TUI, jump host support, and automatic sudo elevation
- Declarative YAML playbooks for idempotent task orchestration with concurrency and error handling
- Encrypted asset management for hosts, credentials, and tags with AES-encrypted storage
- Cross-platform firewall management (firewalld, ufw, iptables, nftables) and network tools

## Why It Matters for RAG Builders
XOps CLI bridges the gap between AI assistants and real infrastructure by providing a secure, MCP-native interface for automated server management, reducing manual operations and enabling AI-driven DevOps workflows.
