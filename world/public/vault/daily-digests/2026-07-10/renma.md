## Summary
Renma is an opinionated toolkit for managing reusable, human-curated context assets in Git for LLM-era software teams. It provides deterministic governance, ownership, and validation layers to organize agent-consumable knowledge, ensuring consistency and safety in AI-driven workflows.

## Key Features
- Catalogs and validates reusable context assets (skills, domain knowledge, tool guidance) in Git
- Provides deterministic diagnostics for ownership, lifecycle state, and dependencies
- Generates dependency graphs, trust graphs, and readiness reports for repository health
- Supports Repository Context BOM (Bill of Materials) for reviewable manifests
- Emits structured JSON output for CI/CD and downstream tooling integration

## Why It Matters for RAG Builders
Renma ensures agent-consumable knowledge is organized, owned, and validated in Git, reducing duplication and drift while enabling safer and more consistent AI-driven workflows.
