## Summary
Orbit is a lifecycle-marketing operating system for Claude Desktop that provides 60+ battle-tested protocols and 80+ tools for email marketing, segmentation, deliverability, and compliance. It functions as an MCP extension, offering production-ready workflows for lifecycle operators.

## Key Features
- 60+ pre-built lifecycle marketing protocols for rapid deployment
- 80+ integrated tools for email build, QA, and automation (MJML, Braze, Stripo)
- Deliverability and compliance checks (SPF/DKIM/DMARC, GDPR audits)
- Segmentation and experimentation maths (RFM scoring, A/B testing, LTV)
- Figma import, Notion export, and brand voice consistency tools
