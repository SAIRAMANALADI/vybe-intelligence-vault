## Summary
Neko Core is a local-first, extensible terminal agent built in TypeScript and Bun that acts as a general-purpose AI assistant for coding, browsing, and system automation. It supports provider-agnostic LLM integration, offline operation, and pluggable skills via MCP and custom modules.

## Key Features
- Pluggable skills and tools for domain-specific tasks (e.g., purchasing, browser automation)
- Provider-agnostic LLM integration with support for OpenAI-compatible endpoints and local models
- Full-featured terminal UI with live markdown rendering, hardware-accelerated scrolling, and session persistence
- Self-improving memory system with durable facts, learned workflows, and playbook refinement
- Secure, offline-capable operation with configurable permission modes and auto-update functionality

## Why It Matters for RAG Builders
Neko Core provides a flexible, local-first framework for building and extending AI agents that can automate complex workflows beyond coding, making it essential for developers seeking customizable, provider-agnostic agent architectures.
