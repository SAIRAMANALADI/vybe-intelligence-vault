## Summary
CrabAgent is a local-first AI knowledge work platform that seamlessly blends conversational AI with a live workspace for document editing, coding, and task execution. It operates in two adaptive modes—Chat and Work—switching automatically based on user needs, and integrates with email, WeChat, and ChatGPT subscriptions for a unified workflow.

## Key Features
- Dual-mode interface (Chat/Work) with automatic switching based on task context
- Live workspace with document preview, code editor, and prototype builder
- Project memory and self-evolving agents that retain context across sessions
- Integration with email, WeChat, and ChatGPT subscriptions for seamless task delegation
- Multi-modal support for images, Office documents, and browser automation

## Why It Matters for RAG Builders
CrabAgent bridges the gap between conversational AI and practical task execution, enabling RAG builders to deploy agents that not only retrieve information but also act on it in real-time workspaces.
