## Summary
SkillDepot is an open marketplace for AI Agent skills tailored to cross-border e-commerce use cases, enabling users to discover, share, and download pre-built agent skills for platforms like Alibaba International, Amazon, Shopify, and WordPress.

## Key Features
- Open marketplace for discovering and sharing AI agent skills
- Pre-built skills for major e-commerce platforms (Alibaba, Amazon, Shopify, WordPress)
- One-click integration of skills into AI workflows
- Developer and user reputation system with leaderboards
- Docker-based deployment with PostgreSQL for scalability

## Why It Matters for RAG Builders
It provides a centralized hub for AI agent skills tailored to cross-border e-commerce, accelerating workflow automation and reducing development time for sellers and developers.
