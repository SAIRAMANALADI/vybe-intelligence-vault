## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with Home Assistant, providing deep control over smart home automation, entity management, and system administration through a structured toolset.

## Key Features
- 40 specialized tools for Home Assistant entity, automation, and system management
- Hybrid architecture combining WebSocket and REST APIs for optimal performance
- Full CRUD operations for automations, scripts, scenes, and helpers
- Advanced system analysis including dependency tracking and config validation
- Fine-grained access control with read-only mode, whitelist, and blacklist filtering
