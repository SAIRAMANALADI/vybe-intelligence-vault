## Summary
Symbiont is an open-core company operating system designed for hybrid teams of humans and AI agents, addressing ten key asymmetries between humans and agents. It provides a registry, MCP server, and A2A agent discovery to enable seamless coordination and integration.

## Key Features
- Registry API for publishing and querying `agents.json` specifications
- MCP server for hybrid human-agent interactions
- A2A agent card for discovery and coordination
- Ten facilities addressing asymmetries between humans and agents
- Open-core model with free foundation and paid managed services
