## Summary
SDD-RIPER Light is a lightweight, context-first LLM task automation toolkit designed to make model-driven work observable, recoverable, reviewable, and safe. It provides a set of controls and skills for managing AI agent execution, checkpoints, validation, and handoffs in coding and documentation tasks.

## Key Features
- Lightweight harness for AI agent task execution with minimal overhead
- Four complementary skills for different use cases (execution control, code indexing, handoffs, and recovery)
- Strict workflow rules: restate goals, create specs, require approval, validate outcomes, and reverse sync
- Support for both low-risk daily tasks and high-risk audit-ready workflows
- Project memory and knowledge management with clear boundaries between layers

## Why It Matters for RAG Builders
It provides a structured, safe, and observable way to integrate strong AI coding agents into workflows while maintaining human oversight and control.
