## Summary
Mylo is a terminal-based agent built with Langchain and Textual for analyzing GitHub and GitLab repositories. It helps developers discover and analyze codebases, libraries, and repositories to solve problems or find suitable solutions for projects.

## Key Features
- Supports multiple LLM providers (OpenAI, Anthropic, Google, Groq, Huggingface, Ollama) with customizable model profiles and memory limits
- Finds and analyzes repositories and libraries from GitHub and GitLab with file structure and content retrieval
- Deep file analysis using AST for 16 programming languages (Python, JavaScript, Rust, etc.)
- Interactive TUI with token usage tracking and inline command execution
- Configurable system prompts and local stateless command execution

## Why It Matters for RAG Builders
Mylo streamlines repository and library discovery for RAG builders by enabling automated codebase analysis and retrieval, reducing manual effort in curating high-quality data sources.
