## Summary
WorldWave-Agent is a persistent cognitive entity framework that enables a single agent to maintain a unified memory and identity across multiple platforms and restarts. It features self-editing knowledge graphs, temporal memory management, and a spiral cognitive loop for autonomous reasoning.

## Key Features
- Persistent cognitive entity with unified identity across platforms and restarts
- Temporal knowledge graph with self-editing capabilities (remember/forget)
- Spiral cognitive loop for autonomous reasoning and decision-making
- Decentralized federated learning stack for P2P model weight exchange
- Multi-platform support (Telegram, Discord, HTTP API, Web UI, etc.)

## Why It Matters for RAG Builders
