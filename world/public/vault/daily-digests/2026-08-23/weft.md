## Summary
Weft is a coordination and verification protocol for autonomous software agents, acting as an execution ledger where evidence-based verification replaces human code review. It enables multi-agent collaboration, certified change landings, and git-compatible import/export workflows.

## Key Features
- Certified change landings via evidence-based verification gates
- CRDT-powered content model for conflict-free concurrent edits
- MCP server integration for seamless agent interaction
- Git import/export bridge for compatibility with existing workflows
- Capability-based permissions with revocable, scoped, and expiring credentials
