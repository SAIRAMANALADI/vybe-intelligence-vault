## Summary
TenderAPI MCP server exposes French (BOAMP) and EU (TED) public procurement data as MCP tools for AI agents like Claude Desktop, Cursor, and Continue. It provides a hosted server for quick access and a local Python-based server for full functionality with tiered access.

## Key Features
- Exposes TenderAPI (BOAMP + TED) as MCP tools for AI agents
- Hosted server option for quick, keyless access (30 calls/day)
- Local server with full toolset and tiered access (Free, Starter, Pro)
- Supports search, retrieval, and alert profiles for procurement data
- Daily data refresh for BOAMP (France) and TED (EU) since 2015

## Why It Matters for RAG Builders
It enables AI agents to dynamically fetch and analyze public procurement data, enhancing decision-making and research capabilities for procurement professionals and analysts.
