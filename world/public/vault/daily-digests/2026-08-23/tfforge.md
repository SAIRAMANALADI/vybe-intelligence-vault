## Summary
tfforge is an AI agent that autonomously builds, validates, secures, and auto-corrects Terraform infrastructure code while enforcing policy-as-code safety guards to prevent destructive actions. It operates via a from-scratch agent loop on the Anthropic Messages API, integrating security scanning, cost tracking, and audit logging for reliable DevOps automation.

## Key Features
- Autonomous Terraform code generation, validation, and auto-correction with security scanning
- Policy-as-code guardrails that block destructive actions (e.g., destroy on production) and enforce least-privilege IAM
- Deterministic plan parsing with human-readable output and cost tracking for LLMOps
- CI mode for deterministic security scanning without LLM dependency or API keys
- Audit logging and budget enforcement for cost and action tracking

## Why It Matters for RAG Builders
It provides a production-ready blueprint for building trustworthy AI agents that can autonomously manage infrastructure while enforcing strict safety and governance controls, addressing critical DevOps and security challenges in AI-driven automation.
