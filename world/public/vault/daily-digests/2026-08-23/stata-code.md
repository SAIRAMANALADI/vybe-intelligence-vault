## Summary
stata-code is an MIT-licensed agent-native bridge that enables LLM agents, Jupyter notebooks, and VS Code to drive Stata programmatically. It provides a unified Python core with structured result schemas, cross-stack validation, and agent-friendly error handling for empirical research workflows like DiD, IV, RDD, and publication-ready tables.

## Key Features
- Unified result schema for Stata outputs (errors, logs, graphs) with typed responses for agents
- Multi-frontend support: MCP server, Jupyter kernel, VS Code extension, and Python library
- Agent-native error recovery with structured suggestions and fix-and-rerun loops
- Cross-stack validation via StatsPAI for robustness checks (Cunningham method)
- Pre-built econometric workflows (DiD, IV, RDD, esttab) with recipe libraries

## Why It Matters for RAG Builders
It bridges Stata, a critical tool in empirical research, with modern AI workflows, enabling agents to automate complex econometric analyses while ensuring result reliability through structured schemas and cross-validation.
