## Summary
TrueNeverStory is an AI-powered interactive narrative engine that enables users to write stories by playing as characters in a living world. It uses a state-first architecture where every NPC remembers actions, outcomes are deterministic, and the story evolves based on player choices or autonomous simulation.

## Key Features
- State-First architecture with deterministic outcomes and persistent NPC memory
- Six specialized AI agents (Dramaturg, Validator, Stylist, Actor, Censor, Chronicler) for narrative generation and validation
- MCP integration for Bible patterns, Gutenberg styles, and Wikipedia-based fact-checking
- Hybrid memory system combining SQLite FTS5, vector embeddings (BGE-M3 + Faiss), and semantic search for efficient RAG
- Multi-world support with isolated execution, cross-world communication, and real-time streaming via WebSocket/SSE

## Why It Matters for RAG Builders
TrueNeverStory provides a robust framework for building AI-driven interactive narratives with deterministic state management and multi-agent collaboration, making it essential for developers creating immersive storytelling applications.
