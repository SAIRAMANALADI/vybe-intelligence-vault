## Summary
Worldwave is a persistent cognitive entity framework that enables AI agents to maintain memory and identity across sessions, platforms, and time. It provides cross-platform continuity, self-editing knowledge graphs, and a state machine for persistent agent behavior.

## Key Features
- Persistent cognitive entity with memory surviving restarts and platform changes
- Temporal knowledge graph with fact supersession (not deletion) for accurate context
- Cross-platform identity resolver mapping all platform IDs to a single entity_id
- 7-phase spiral cognitive loop (PERCEIVE → RECALL → PLAN → ACT → EVALUATE → LEARN → CONSOLIDATE)
- Self-editing memory via remember()/forget() methods for agent-managed knowledge

## Why It Matters for RAG Builders
Worldwave enables AI agents to maintain coherent, persistent identities and memories across sessions and platforms, solving a critical gap in RAG systems that lose context between interactions.
