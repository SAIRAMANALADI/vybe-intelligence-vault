## Summary
The Expert is a model and effort router for Claude that optimizes API costs by dynamically selecting the right-sized model and effort level for each query. It learns from user ratings to improve routing decisions and provides transparency into savings versus always using the top-tier model.

## Key Features
- Dynamic model and effort selection based on query complexity
- Learns from user ratings to refine routing decisions
- Savings ledger to track cost reductions vs. always using top-tier models
- Multiple editions (React, web, terminal) for different use cases
- Transparency panel showing reasoning behind routing choices

## Why It Matters for RAG Builders
It helps AI stack builders reduce Claude API costs by intelligently routing queries to the most cost-effective model without sacrificing answer quality.
