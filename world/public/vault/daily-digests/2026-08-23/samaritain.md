## Summary
Samaritain is a rebranded fork of the Hermes Agent by Nous Research, offering a self-improving AI agent with a built-in learning loop, autonomous skill creation, and cross-platform conversation continuity. It supports multiple LLM providers, scheduled automations, and runs on diverse infrastructures from $5 VPS to serverless setups.

## Key Features
- Built-in learning loop with autonomous skill creation and self-improvement during use
- Cross-platform conversation continuity across CLI, Telegram, Discord, Slack, WhatsApp, Signal, and Email
- God's eye memory graph for entity-relation knowledge storage and queryable recall
- Scheduled automations and delegated parallel subagents for multi-step workflows
- Supports multiple LLM providers with API-key fallback and Nous Portal integration

## Why It Matters for RAG Builders
Samaritain provides a robust, self-improving agent framework with built-in memory and learning capabilities, making it essential for RAG builders seeking autonomous, multi-platform AI systems.
