## Summary
The Toolpack SDK is a TypeScript library for building production-grade AI agents with 100+ built-in tools, support for 8 AI providers, and a persistent cognitive layer. It enables real-time streaming, multimodal inputs, and seamless integration with RAG workflows.

## Key Features
- Unified API for 8+ AI providers with dynamic model discovery and tool calling support
- 100+ built-in tools across 15 categories (filesystem, coding, Git, Kubernetes, etc.)
- Real-time streaming, multimodal inputs (text/image), and embeddings for RAG applications
- Workflow engine with plan-direct execution, parallel tool orchestration, and human-in-the-loop confirmation
- First-class MCP client/server support for bridging external tools and exposing Toolpack as an MCP server

## Why It Matters for RAG Builders
Toolpack SDK simplifies building production AI agents with built-in tools and multi-provider support, reducing integration complexity for RAG builders.
