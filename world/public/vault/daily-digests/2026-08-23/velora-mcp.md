## Summary
Velora is a hosted Model Context Protocol (MCP) server providing a unified commerce toolkit for Argentina, enabling AI agents to handle real AFIP invoicing, MercadoPago payments, logistics, catalog management, WhatsApp messaging, and more through a single authenticated endpoint.

## Key Features
- Real-time AFIP electronic invoicing with CAE issuance (Factura A/B/C + Consumidor Final)
- Unified commerce toolkit including payments, logistics, catalog, messaging, and reporting
- Single authenticated endpoint for AI agents via MCP (Model Context Protocol)
- Sandbox and production modes with clear maturity indicators for each tool
- Per-tenant isolation and HMAC/OAuth 2.1 authentication

## Why It Matters for RAG Builders
Velora simplifies integrating Argentine commerce operations into AI agents by abstracting complex tax and payment APIs behind a single, standardized MCP endpoint, reducing development overhead for RAG builders.
