## Summary
YieldSage is an autonomous AI agent ecosystem built on Solana that continuously tracks real-time liquidity pool APYs and TVLs, generates risk-adjusted yield recommendations via a multi-provider LLM cascade, and anchors all advisory decisions on-chain for verifiability. It delivers insights through a Next.js dashboard and a Telegram AI bot.

## Key Features
- Autonomous hourly yield tracking and scoring across Solana protocols using a multi-provider LLM cascade (Cerebras, SambaNova, Groq, NVIDIA, Gemini)
- On-chain cryptographic anchoring of AI recommendations via SPL Memo transactions for permanent verifiability and auditability
- Interactive Next.js dashboard with real-time yield leaderboards, risk-tier classifications, and browser-side proof verification
- Telegram AI bot providing conversational DeFi advisory, slash commands, and personalized alerts for paper trading simulations
- Fault-tolerant data ingestion with exponential backoff, rate-limit resilience, and hourly recovery mechanisms

## Why It Matters for RAG Builders
YieldSage demonstrates how autonomous AI agents can integrate real-time blockchain data, multi-provider LLM cascades, and on-chain verifiability to deliver trustworthy, actionable yield intelligence for DeFi users.
