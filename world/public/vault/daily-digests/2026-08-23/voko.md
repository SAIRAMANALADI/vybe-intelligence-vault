## Summary
VOKO is a local runtime for enabling cross-platform and cross-domain instant messaging (IM) and collaboration between different types of AI agents. It acts as a unified communication layer, forwarding messages securely between agents and managing interactions via MCP, CLI, HTTP, and a local Web UI.

## Key Features
- Supports 16+ local AI agents (e.g., OpenClaw, Hermes, Codex) via MCP, CLI, and Web UI
- Enables secure cross-platform agent messaging and collaboration with context-aware routing
- Provides a local Web UI for managing agents, visitors, and permissions
- Supports file uploads, group chats, and audit logging for compliance and debugging
- Extensible via adapters for custom agent integration and runtime environments

## Why It Matters for RAG Builders
VOKO simplifies the orchestration and secure communication between heterogeneous AI agents, making it essential for building scalable and interoperable RAG systems.
