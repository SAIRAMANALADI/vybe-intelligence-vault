## Summary
Sesori provides a mobile interface to control and monitor AI coding assistants like OpenCode, Codex, and Cursor from a smartphone. It pairs with a local Bridge CLI that securely connects the phone to the AI tools running on a user's machine.

## Key Features
- Mobile cockpit for AI coding sessions (OpenCode, Codex, Cursor)
- End-to-end encrypted communication between phone and local machine
- Real-time notifications and session monitoring
- Plugin-based architecture for adding new AI assistants
- Cross-platform support (iOS, Android, macOS, Linux, Windows)

## Why It Matters for RAG Builders
Sesori enables developers to remotely manage and interact with AI coding assistants, bridging the gap between mobile convenience and local AI tooling.
