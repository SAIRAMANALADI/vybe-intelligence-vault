## Summary
A Model Context Protocol (MCP) server that provides direct access to the shadcn/ui v4 component registry, enabling AI assistants like Claude Code to fetch, search, and reference component and block source code without leaving the terminal.

## Key Features
- Direct access to shadcn/ui v4 component and block source code
- Search functionality for components and blocks by keyword
- 1-hour in-memory cache to reduce GitHub API calls
- Integration with Claude Code via MCP protocol
- Supports listing, fetching, and referencing UI components and blocks

## Why It Matters for RAG Builders
It enables AI assistants to dynamically fetch and reference shadcn/ui components and blocks, streamlining UI development workflows within the terminal.
