## Summary
Selat is an open-source gateway that centralizes OAuth authentication and token management for AI agents, allowing them to interact with multiple tools (e.g., GitHub, Jira) using a single credential. It provides a unified API and MCP interface for seamless tool integration.

## Key Features
- Single credential for multiple tools, reducing OAuth complexity
- Unified API and MCP interface for REST and agent runtime compatibility
- Standardized error codes for predictable agent behavior
- Secure token storage with AES-256-GCM encryption
- Conformance suite for provider adapter validation
