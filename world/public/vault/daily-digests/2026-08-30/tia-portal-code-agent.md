## Summary
A local AI-assisted engineering interface for Siemens TIA Portal that integrates contextual Add-In actions with interchangeable coding-agent runtimes via the Model Context Protocol (MCP), enabling engineers to explain, review, and propose changes to PLC project objects in a read-only workflow.

## Key Features
- Contextual AI actions (explain, review, propose changes) for TIA Portal objects
- Interchangeable agent runtime support (Mimo, OpenCode, Claude Code)
- Model Context Protocol (MCP) integration for external tooling
- Local Bridge API for task management and runtime supervision
- Read-only workflow with safety-focused design and loopback binding

## Why It Matters for RAG Builders
It bridges Siemens TIA Portal with AI agent runtimes via MCP, enabling secure, contextual PLC engineering workflows that can be integrated into RAG pipelines for industrial automation.
