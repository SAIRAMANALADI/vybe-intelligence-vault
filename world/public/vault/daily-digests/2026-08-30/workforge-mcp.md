## Summary
WorkForge is a secure MCP (Model Context Protocol) gateway that enables ChatGPT to interact with a Windows workstation, allowing it to inspect files, understand Git state, make guarded edits, read images, and run supervised PowerShell commands. It bridges the gap between AI and local development environments for practical task execution.

## Key Features
- Secure file and Git state inspection by AI agents
- Guarded file edits using SHA-256 checksums to prevent stale overwrites
- Supervised PowerShell command execution with lifecycle management
- Local image inspection for UI and asset analysis
- Minimal installation with automatic prerequisite handling

## Why It Matters for RAG Builders
WorkForge enables AI agents to directly interact with and modify local development environments, reducing manual copy-paste workflows and accelerating debugging, documentation, and project management tasks.
