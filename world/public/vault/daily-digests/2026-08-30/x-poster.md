## Summary
x-poster is an OpenClaw skill that automates Twitter (X) posting by drafting posts about your open source work three times a day and publishing only upon receiving a 'ship' approval via Telegram. It ensures cadence and engagement while maintaining human oversight.

## Key Features
- Drafts posts about open source work using GitHub data and Hacker News API
- Requires explicit 'ship' approval via Telegram before publishing
- Supports both X API and browser-based posting
- Enforces strict voice and style rules to maintain authenticity
- Runs locally with no external API costs
