## Summary
TaskForge is an open-source AI Agent OS designed for solo entrepreneurs, offering a dual-mode LLM execution environment (local or remote), a workflow DSL for agent orchestration, and a Tauri-based desktop interface. It supports 12+ agent roles, PDCA pipelines, and A2A protocol integration.

## Key Features
- Dual-mode LLM execution (local Ollama or remote SaaS API)
- 12+ pre-built agent roles with PDCA pipeline support
- Workflow DSL for defining complex agent interactions (parallel, pipeline, phase, loop, etc.)
- Tauri-based desktop app with zero-config local/remote mode switching
- Template market with 5 example templates (finance, CRM, content, office, review)

## Why It Matters for RAG Builders
TaskForge provides a flexible, local-first agent framework with a powerful DSL for building and orchestrating AI agents, making it essential for developers seeking modular and scalable AI workflows.
