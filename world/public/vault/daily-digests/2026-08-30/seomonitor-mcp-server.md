## Summary
Official Model Context Protocol (MCP) server for SEOmonitor, enabling MCP-compatible clients like Claude, ChatGPT, or Gemini CLI to connect to SEO data including rank tracking, AI visibility, keyword research, organic traffic, and forecasts via a hosted or locally run server.

## Key Features
- 49 read-only tools for SEO data retrieval (rank tracking, AI Overviews, keyword research, traffic, forecasts)
- Hosted server (no install required) or local stdio/HTTP deployment options
- Rate-limited API access (60 requests/minute per key) with burst handling
- Supports Claude, ChatGPT, Gemini CLI, and any MCP-compatible client
- Environment variable configuration for customization (timeout, log level, transport mode)

## Why It Matters for RAG Builders
It provides a standardized MCP interface to seamlessly integrate SEOmonitor's rich data into AI workflows for RAG applications, enabling real-time SEO insights and automation.
