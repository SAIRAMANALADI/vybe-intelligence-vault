## Summary
A terminal-first, self-hosted AI gateway that unifies models, agents, knowledge, and tools into a single governed execution path. It provides a credential-free local-first runtime with an 8-tool MCP server for Codex integration and a disposable Docker demo for safe evaluation.

## Key Features
- Credential-free local-first runtime with deterministic fake provider for safe evaluation
- 8-tool MCP server for seamless integration with Codex and other stdio clients
- Governed execution path for models, agents, knowledge, and tools with explicit opt-in for real providers
- Disposable Docker demo for one-command evaluation without cloning the repository
- Terminal CLI and HTTP API for direct interaction and observability

## Why It Matters for RAG Builders
It provides a unified, governed control plane for AI systems that prioritizes human authority and safe evaluation, making it essential for building reliable RAG pipelines.
