## Summary
Unity-MCP is an AI-powered game development assistant that integrates Model Context Protocol (MCP) with Unity Editor and Runtime, enabling AI agents to automate workflows, generate code, and interact with games in real-time. It supports multiple AI clients like Claude, Cursor, and GitHub Copilot for dynamic game development and debugging.

## Key Features
- Enables AI agents to interact with Unity Editor and Runtime via MCP for code generation and debugging
- Supports 70+ built-in tools for asset management, scene operations, and game object manipulation
- Works in compiled games for real-time AI debugging and player-AI interaction
- Extensible with custom tools and supports multiple AI clients (Claude, Cursor, GitHub Copilot, etc.)
- Provides CLI and Unity package installer for easy setup and deployment
