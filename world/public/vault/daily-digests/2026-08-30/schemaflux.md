## Summary
SchemaFlux is a Go library that provides a fluent API for typed LLM operations, enabling structured extraction, transformation, validation, and reasoning with centralized handling of retries, logging, metrics, and cost tracking.

## Key Features
- Fluent builder API for LLM operations with centralized retry, logging, and cost tracking
- Structured output contracts for typed data extraction and transformation
- Comprehensive set of LLM operations including extraction, summarization, validation, and reasoning
- Built-in testing utilities with fake provider for unit testing without network calls
- Stable public API with snapshot tests ensuring backward compatibility

## Why It Matters for RAG Builders
SchemaFlux simplifies integrating LLMs into Go applications by providing a type-safe, fluent interface that centralizes operational concerns like retries and cost tracking, making it essential for AI engineering stacks.
