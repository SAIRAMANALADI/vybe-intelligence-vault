## Summary
Specularis AI Visibility Audit is an MCP server that enables free AI visibility audits for websites, checking if major AI engines (ChatGPT, Claude, Perplexity) can discover and cite them. It provides instant snapshots or detailed PDF reports scoring AI accessibility across five pillars.

## Key Features
- Instant AI visibility snapshot for any website via MCP client
- Detailed 0–100 scored PDF report with 5-pillar analysis (AI crawler access, structured data, content signals, off-site presence, live AI-answer visibility)
- Remote MCP server deployment (no local installation required)
- Integration with Claude, ChatGPT, and other MCP clients
- Free tier with optional strategy call booking

## Why It Matters for RAG Builders
It helps RAG builders ensure their data sources are discoverable and citable by major AI engines, improving retrieval accuracy and visibility.
