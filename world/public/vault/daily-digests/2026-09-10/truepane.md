## Summary
Truepane is a browser-based tool for generating App Store and Google Play screenshots with procedural device frames, parametric backgrounds, and optional AI-driven styling. It renders everything client-side using HTML5 Canvas, ensuring no external dependencies or licensing risks.

## Key Features
- Procedural device frames rendered directly on canvas for crisp, scalable screenshots without licensing risks
- Parametric backgrounds with seeded shapes for reproducible, tasteful designs
- Optional AI prompt-to-style conversion via Groq API for automated styling
- MCP server for AI agent integration, enabling automated screenshot generation workflows
- Local-first architecture with no external uploads, ensuring data privacy and zero egress costs

## Why It Matters for RAG Builders
Truepane streamlines App Store and Google Play screenshot generation with a local-first, AI-assisted workflow, reducing manual effort and licensing overhead for developers and AI agents.
