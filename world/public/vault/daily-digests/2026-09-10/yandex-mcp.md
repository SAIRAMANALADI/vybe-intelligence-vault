## Summary
A monorepo of MCP servers providing AI assistants with unified access to Yandex APIs for Russian and CIS market analysis, including Search, Wordstat, Webmaster, Metrika, and Direct. Designed for keyword research, search analytics, site monitoring, web traffic insights, and ad campaign management.

## Key Features
- Unified interface for five Yandex APIs (Search, Wordstat, Webmaster, Metrika, Direct)
- Claude Code plugin for seamless integration and updates
- 92 tools across all packages for comprehensive market analysis
- Environment variable management for secure credential handling
- Built-in OAuth flow for Webmaster and Metrika authentication

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with Yandex's ecosystem for Russian market data, enhancing RAG systems with localized search, analytics, and advertising insights.
