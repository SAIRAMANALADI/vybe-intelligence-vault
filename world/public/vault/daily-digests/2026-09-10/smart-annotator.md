## Summary
Smart-Annotator is a Windows desktop application designed to streamline the bulk annotation and revision of AI-generated documents. It allows users to add notes, corrections, and structural labels to large sets of text files, then sync these changes with an AI provider to generate improved versions in a single pass.

## Key Features
- Bulk import and annotation of AI-generated text files (Markdown/plain text)
- Real-time local editing with automatic saving and backup versioning
- Direct integration with major AI providers (e.g., Claude, ChatGPT) for revision sync
- Side-by-side comparison of original and revised documents
- Offline-first workflow with local data storage and optional cloud-free operation

## Why It Matters for RAG Builders
Smart-Annotator streamlines the iterative refinement of AI-generated content, reducing manual editing overhead and ensuring consistency across large document sets for RAG pipelines.
