## Summary
Workflow Skill Router V2 is a runtime-aware planning and routing layer for Codex that selects the smallest verifiable execution path for agent tasks while preserving user authority. It separates installed metadata from runtime capabilities, supports explicit skill locking, and enables personal routing profiles for deterministic task execution.

## Key Features
- Runtime capability discovery for installed metadata, host exposure, and policy eligibility
- Personal and workspace routing profiles with deterministic precedence rules
- Explicit skill locking and consent boundaries for user-controlled task execution
- Support for single, phased, and managed-goal task routing strategies
- MCP tool integration with twelve typed tools for planning, validation, and execution

## Why It Matters for RAG Builders
It enables AI agents to execute tasks with minimal verifiable paths while ensuring user authority and runtime capability alignment, critical for reliable and auditable RAG systems.
