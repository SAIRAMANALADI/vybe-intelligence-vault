## Summary
trueline-mcp is an MCP plugin designed to enhance AI coding agents by providing hash-verified file editing and targeted reads, reducing token usage and preventing silent code corruption. It integrates with platforms like Claude Code, Gemini CLI, and VS Code Copilot to optimize file interactions.

## Key Features
- Hash-verified file editing to prevent silent corruption
- Targeted reads via AST-based outlines to reduce token usage
- Semantic diffs for structural changes instead of raw line diffs
- Platform-specific hooks for high agent compliance (~98%)
- Atomic batching of multiple edits for efficiency

## Why It Matters for RAG Builders
It significantly reduces token waste and prevents code corruption in AI-driven file editing workflows, making it essential for efficient and reliable RAG/AI stack operations.
