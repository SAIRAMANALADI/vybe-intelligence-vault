## Summary
A Model Context Protocol (MCP) server that enables AI assistants to perform web searches via DuckDuckGo and extract clean, readable content from web pages. It supports parallel processing, memory optimization, and rate limiting for reliable operation.

## Key Features
- Privacy-focused web search via DuckDuckGo integration
- Parallel content extraction from multiple URLs
- Memory optimization and rate limiting to prevent API blocks
- Robust error handling and structured output for AI assistants
- Seamless integration with MCP clients like Claude Desktop and Cursor

## Why It Matters for RAG Builders
It enables AI assistants to dynamically fetch and process web content, enhancing RAG systems with real-time, up-to-date information from the internet.
