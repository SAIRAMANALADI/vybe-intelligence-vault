## Summary
A Solana Agent Kit plugin for MadeOnSol that provides real-time Solana KOL intelligence, deployer analytics, and trading signals. It enables tracking of KOL wallets, deployer reputation, token surges, and on-chain wallet holdings with low-latency data feeds.

## Key Features
- Real-time tracking of 1,069+ KOL wallets with <3s latency
- Deployer reputation scoring and historical analysis (as-of-date)
- Token surge and revival detection with pre-confirmation signals
- Webhook and WebSocket streaming for live event notifications
- On-chain wallet holdings and token lock/vesting analytics
