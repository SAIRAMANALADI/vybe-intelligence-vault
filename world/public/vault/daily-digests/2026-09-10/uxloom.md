## Summary
UXLoom is an AI-native design validation tool that acts as a critic layer for UI/UX workflows, identifying missing states, accessibility issues, and design gaps before development begins. It models user journeys as state machines and ensures completeness through deterministic validation.

## Key Features
- Critiques AI-generated UI designs for missing states (error, loading, empty) and dead ends
- Validates WCAG contrast, touch target sizes, and localization text expansion
- Agent-native via MCP server (works with Claude Code, Codex, and other MCP clients)
- Deterministic validation with 100% precision/recall on seeded defect catalogs
- CI-ready CLI and project file format for versioned design-as-data workflows

## Why It Matters for RAG Builders
It ensures AI-generated UIs are complete and accessible before development, reducing costly fixes and improving user experience.
