## Summary
codebase-memory-mcp is a high-performance MCP server that indexes entire codebases into a persistent knowledge graph using tree-sitter AST analysis and hybrid LSP semantic resolution. It enables sub-millisecond structural queries, architecture intelligence, and cross-service linking for AI coding agents with zero dependencies and a single static binary.

## Key Features
- Indexes 158 languages with tree-sitter AST analysis and hybrid LSP semantic resolution for accurate call graphs
- Sub-millisecond structural queries and 120x fewer tokens compared to file-by-file exploration
- Plug-and-play integration with 11+ coding agents and built-in graph visualization UI

## Why It Matters for RAG Builders
It provides a high-performance, dependency-free way to index and query entire codebases for RAG systems, drastically reducing token usage and enabling precise architectural insights.
