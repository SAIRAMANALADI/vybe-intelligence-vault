## Summary
GPT Researcher is an open-source deep research agent that autonomously conducts comprehensive research on any given task using web and local documents. It generates detailed, factual reports with citations and supports customization for domain-specific research needs.

## Key Features
- Parallelized agent workflow for efficient research with citations
- Supports both web and local document research (PDF, CSV, Word, etc.)
- Deep Research mode for recursive, tree-like topic exploration with configurable depth
