## Summary
deepworm is a lightweight AI-powered research assistant that enables deep research tasks using multiple LLM providers (OpenAI, Google Gemini, Anthropic Claude, Ollama) and web search via DuckDuckGo. It offers both a CLI and Python API for seamless integration without requiring paid services or complex frameworks.

## Key Features
- Supports multiple LLM providers (OpenAI, Gemini, Claude, Ollama) for flexibility
- Integrates DuckDuckGo for free web search and data synthesis
- Available as a Windows executable and Python package for easy deployment
- No dependency on paid APIs by default (uses Ollama + DuckDuckGo)
- Command-line and Python API for automation and scripting
