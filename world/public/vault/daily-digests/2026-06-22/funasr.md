## Summary
FunASR is an industrial-grade, end-to-end speech recognition toolkit offering 170x real-time performance, support for 50+ languages, and advanced features like speaker diarization, emotion detection, and streaming. It provides OpenAI-compatible APIs and integrates seamlessly with AI agents and LLM-based ASR models.

## Key Features
- Ultra-fast ASR with 170x real-time performance and CPU compatibility
- Built-in speaker diarization, emotion detection, and punctuation for structured output
- OpenAI-compatible API and agent integration (MCP, LangChain) for seamless AI stack integration

## Why It Matters for RAG Builders
FunASR provides a high-performance, self-hosted alternative to cloud ASR services with advanced features critical for building robust RAG pipelines that require real-time, multilingual, and speaker-aware speech processing.
