## Summary
A Rust-based command-line interface (CLI) for interacting with Polymarket, enabling users to browse markets, place orders, manage positions, and interact with on-chain contracts directly from the terminal.

## Key Features
- Browse and search Polymarket markets from the terminal
- Place buy/sell orders and manage positions
- Interact with Polymarket blockchain contracts
- Wallet management and import functionality
- Cross-platform support (Windows-focused)
