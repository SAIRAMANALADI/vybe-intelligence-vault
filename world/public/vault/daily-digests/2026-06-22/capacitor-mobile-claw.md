## Summary
capacitor-mobile-claw is an on-device AI agent engine designed to run AI tasks locally on mobile devices using Capacitor, Node.js, and the Claude language model. It enables offline file management, code execution, and AI-driven automation without cloud dependency.

## Key Features
- Runs AI agents entirely on-device for privacy and low latency
- Embedded Node.js worker for local code execution and scripting
- Supports file management, Git integration, and extensible device tools
- Cross-platform compatibility with Android and iOS via Capacitor
- Claude LLM integration for natural language understanding and task automation

## Why It Matters for RAG Builders
It enables AI agents to operate entirely offline on mobile devices, reducing cloud dependency and enhancing privacy for RAG builders targeting mobile applications.
