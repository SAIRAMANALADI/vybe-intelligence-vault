## Summary
E2B provides an open-source infrastructure for running AI-generated code in secure, isolated cloud sandboxes with JavaScript and Python SDKs. It enables safe code execution, debugging, and tool integration for AI agents and applications.

## Key Features

- Multi-language SDKs (Python, JavaScript/TypeScript) for seamless integration
- Support for self-hosting on AWS, GCP, and Linux machines
