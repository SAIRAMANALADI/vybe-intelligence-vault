## Summary
A local-first multi-agent platform that enables users to automate tasks on their Windows PC without relying on external services. It supports orchestrating multiple AI agents, managing skills, and self-hosted workflows with Docker and Caddy for containerization and reverse proxy.

## Key Features
- Runs multiple AI agents locally on Windows without external dependencies
- Supports dynamic skill management for customizable agent capabilities
- Self-hosted with data privacy and no third-party API reliance by default
- Includes Docker and Caddy for containerization and reverse proxy management
- User-friendly GUI with logging and real-time agent monitoring
