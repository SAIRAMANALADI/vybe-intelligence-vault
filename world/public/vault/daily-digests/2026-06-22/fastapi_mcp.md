## Summary
FastAPI-MCP is a library that converts FastAPI endpoints into Model Context Protocol (MCP) tools, enabling seamless integration of FastAPI applications with MCP-compatible clients while preserving authentication, schemas, and documentation.

## Key Features
- Native FastAPI integration with zero/minimal configuration required
- Preserves request/response schemas and Swagger documentation
- Supports multiple transport protocols (HTTP, SSE) with stateful session management

## Why It Matters for RAG Builders
It bridges FastAPI applications with MCP ecosystems, enabling AI agents to directly interact with existing APIs while maintaining security and schema integrity.
