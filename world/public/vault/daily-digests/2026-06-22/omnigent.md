## Summary
Omnigent is an open-source AI agent framework and meta-harness designed to orchestrate multiple AI agents (e.g., Claude Code, Codex, Cursor, Pi) with a unified interface. It enables seamless collaboration, policy enforcement, and real-time session synchronization across devices and cloud sandboxes.

## Key Features
- Unified orchestration layer for multiple AI agent harnesses (Claude Code, Codex, Cursor, Pi, custom agents)
- Real-time collaboration and session synchronization across devices and platforms
- Cloud sandboxing with providers like Modal, Daytona, and Islo for disposable agent environments
- Policy-based governance for risk mitigation, spend control, and tool access restrictions
- Pluggable agent SDKs and support for multiple model providers (API keys, subscriptions, gateways)
