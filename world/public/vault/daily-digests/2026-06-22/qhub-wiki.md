## Summary
QHub-Wiki is a self-hosted AI-powered knowledge base for SMBs that integrates WikiJS with Qdrant vector search, enabling instant AI-driven answers via a custom Chrome extension. It simplifies deployment with a single Ansible script and eliminates SaaS costs by allowing users to own their data.

## Key Features
- Unified AI-driven search across scattered operational knowledge using WikiJS and Qdrant
- Single Ansible deployment for simplified setup and maintenance
- Custom Chrome extension for in-browser AI queries with LLM API integration

## Why It Matters for RAG Builders
QHub-Wiki streamlines the integration of vector search and AI-powered retrieval for RAG systems, reducing SaaS dependency while enabling scalable, self-hosted knowledge management.
