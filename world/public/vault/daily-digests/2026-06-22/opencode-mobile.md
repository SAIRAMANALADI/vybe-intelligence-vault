## Summary
OpenCode Mobile is an open-source Android client for the opencode AI coding agent, enabling users to manage AI-assisted coding sessions from their mobile devices. It connects to self-hosted opencode servers via local networks, tunnels, or Tailscale.

## Key Features
- Multi-server connection management for opencode instances
- Biometric unlock for secure access
- Real-time streaming chat with diff viewer
- Tool call approval workflow for AI agent actions
- Secure credential storage using Android Keystore

## Why It Matters for RAG Builders
It enables AI engineers to interact with their coding agents on-the-go, extending the accessibility of AI-driven development workflows beyond desktop environments.
