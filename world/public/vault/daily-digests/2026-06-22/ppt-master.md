## Summary
PPT Master is an AI-powered tool that generates natively editable PowerPoint (PPTX) presentations from any document, preserving native shapes, animations, and speaker notes for further customization in PowerPoint.

## Key Features
- Generates fully editable PPTX files with native PowerPoint elements (shapes, charts, animations)
- Supports speaker notes conversion to audio narration and custom template adherence
- Integrates with multiple AI models and IDEs (Claude Code, Cursor, VS Code Copilot)

## Why It Matters for RAG Builders
It streamlines the creation of high-quality, editable presentations from documents, reducing manual effort while preserving full PowerPoint compatibility for further refinement.
