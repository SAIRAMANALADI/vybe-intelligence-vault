## Summary
Vanta is a local, self-hosted AI agent runtime featuring a Rust-based safety kernel that enforces security boundaries and a TypeScript agent layer for goal-aware execution. It integrates LLM providers, tools, and autonomous workflows while ensuring every action is risk-classified and gated through a tamper-evident audit chain.

## Key Features
- Rust-based safety kernel enforces risk classification and approval gates for every action
- Goal-aware execution with dependency graph and ledger for context-aware decision-making
- Provider-agnostic LLM integration (OpenAI, Anthropic, Ollama, etc.) with local fine-tuning via LoRA
- Multi-backend execution (local, sandbox, Docker, SSH, $5 VPS) with data residency control
- Comprehensive tooling for code editing, browser automation, voice input, scheduling, and autonomous research

## Why It Matters for RAG Builders
Vanta provides a robust, self-hosted framework for building secure, goal-aware AI agents with enforced safety boundaries, making it essential for developers prioritizing control, privacy, and autonomous workflows in RAG systems.
