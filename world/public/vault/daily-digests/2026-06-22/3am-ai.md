## Summary
3am-AI is a self-learning, local AI assistant for Windows that improves over time by observing user behavior while maintaining strict privacy. It runs entirely offline, using lightweight LLMs and clustering to organize information and adapt to personal workflows.

## Key Features
- Runs entirely offline with no cloud dependency
- Self-improving AI that learns from user interactions
- Uses lightweight local LLMs (llama-cpp) for efficiency
- Privacy-first design with all data stored locally
- Adaptive memory system with clustering for context retention
