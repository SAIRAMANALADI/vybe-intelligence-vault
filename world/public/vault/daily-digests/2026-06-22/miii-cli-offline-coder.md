## Summary
AgentMIII is a fully autonomous, local-first terminal-based AI coding agent that enables offline, privacy-preserving code generation and modification using local models (e.g., Ollama) or cloud APIs (OpenAI, Claude). It replicates the UX of tools like Claude Code while ensuring zero cloud dependency and maximum data privacy.

## Key Features
- Autonomous task execution with multi-step reasoning and file modifications
- Ollama-native integration for fully offline, zero-cost model inference
- Multi-provider flexibility (Ollama, OpenAI, Claude) with seamless switching
- Context-aware project understanding with automatic file scanning and diff previews
- Responsive terminal UI with streaming responses and approval workflows
