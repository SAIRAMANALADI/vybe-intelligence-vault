## Summary
A Node-RED package that bridges the Model Context Protocol (MCP) with Node-RED, enabling AI agents to interact with external tools and data sources through a low-code visual interface. It supports autonomous agent loops, MCP tool integration, and compatibility with any MCP server or LLM provider.

## Key Features
- Seamless integration of MCP servers with Node-RED workflows for AI agent automation
- Supports autonomous agent loops with configurable reasoning and tool discovery
- Compatible with any MCP server (Streamable HTTP/SSE) and LLM provider (OpenAI-compatible)
- Production-ready features including error handling, status indicators, and configurable timeouts
- Zero lock-in with Apache-2.0 license and fully local deployment options

## Why It Matters for RAG Builders
It enables AI engineers to build and deploy autonomous AI agents visually within Node-RED, bridging the gap between industrial automation and AI-driven decision-making with minimal coding effort.
