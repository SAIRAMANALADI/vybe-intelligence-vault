## Summary
Mia Agent is a configurable, unobtrusive personal AI assistant designed to grow with the user. It operates as a terminal-based agent with a minimal UI, supporting multi-turn interactions, memory management, and tool integration for filesystem and web operations.

## Key Features
- Minimal terminal UI with full markdown rendering
- Multi-turn agent loop with session and prompt history
- Agent memory management for user and context retention
- OpenAI-compatible API access for LLM integration
- Tool-based execution with gated permissions for safety
