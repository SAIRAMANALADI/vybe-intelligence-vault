## Summary
Skales is a local-first AI desktop agent that operates natively on Windows, macOS, Linux, and Android, enabling users to set autonomous goals, automate tasks, and collaborate with AI without requiring Docker, terminals, or complex setups. It integrates with 15+ AI providers, supports offline operation with Ollama, and offers features like code editing, workflow automation, and multi-agent organizations.

## Key Features
- One-click install with native desktop support across major operating systems
- Autonomous goal execution with background task completion and memory retention
- Integrated code editing and debugging with real-time diffs and undo support
- Multi-agent organizations and team collaboration with role-based delegation
- Support for 15+ AI providers, offline operation via Ollama, and BYOK (Bring Your Own Key)
