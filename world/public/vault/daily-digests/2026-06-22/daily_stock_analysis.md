## Summary
An AI-powered multi-market stock analysis system that aggregates real-time market data, news, and technical indicators to generate daily decision dashboards and automated push notifications for A-shares, Hong Kong stocks, US stocks, Japanese stocks, and Korean stocks.

## Key Features
- Multi-market stock analysis (A-shares, HK, US, JP, KR) with real-time data aggregation and AI-generated decision dashboards
- Automated push notifications via enterprise WeChat, Feishu, Telegram, Discord, Slack, or email
- Agent-based strategy querying for technical analysis (e.g., moving averages, wave theory) and multi-round stock analysis

## Why It Matters for RAG Builders
Provides a robust, automated pipeline for real-time stock analysis and reporting, reducing manual effort for AI-driven financial decision-making.
