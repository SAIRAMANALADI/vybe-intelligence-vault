## Summary
A QQ bot bridge that connects official QQ WebSocket API to local AI agents (Codex, Claude Code, AGY/Gemini) for direct messaging without third-party clients. Enables multi-turn conversations, session memory, and emergency process control via QQ commands.

## Key Features
- Direct QQ-to-AI-agent connection via official WebSocket API, avoiding third-party clients
- Supports Codex, Claude Code, and AGY (Gemini) agents with independent session management
- Emergency kill commands (/stop, /kill) for immediate process termination
- Native multi-turn conversation memory with user-specific context isolation
- Zero relay server architecture ensuring data privacy and compliance

## Why It Matters for RAG Builders
It enables seamless integration of QQ messaging with local AI agents for private, secure, and compliant AI-driven interactions without relying on third-party intermediaries.
