## Summary
three.ws is an open-source, browser-native platform for creating, deploying, and embedding 3D AI agents. It enables users to generate textured 3D models from prompts or images, embed agents as web components, and register them on-chain with LLM-driven brains and autonomous capabilities.

## Key Features
- Browser-native 3D model rendering with WebGL 2.0 and GLB/glTF support
- Text, image, and sketch-to-3D generation via Forge with auto-rigging and retouching
- LLM-driven agent runtime with real-time emotion and morph-target blending
- On-chain identity via ERC-8004 (EVM) or Metaplex Core (Solana) with signed action history
- Embeddable web component (<agent-3d>) and widget system for cross-platform distribution

## Why It Matters for RAG Builders
It bridges the gap between 3D content creation and AI agent deployment, enabling seamless integration of lifelike avatars with autonomous capabilities for RAG and interactive AI systems.
