## Summary
Capitaine is a git-native repo-agent that operates as an autonomous, repository-based intelligence system. It reads its own state, reasons about actions, and executes file operations through a heartbeat cycle, while maintaining auditable logs of its reasoning and improvements.

## Key Features
- Heartbeat-driven autonomous operation with self-directed task execution
- Git-native state awareness and memory via commit history
- Self-improvement through code edits, refactoring, and documentation updates
- Auditable reasoning logs for every action taken
- Fleet coordination via shared conventions and pull requests

## Why It Matters for RAG Builders
