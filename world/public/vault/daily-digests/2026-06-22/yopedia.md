## Summary
yopedia is a self-evolving, agent-driven wiki platform designed for both human and AI agent collaboration, where knowledge accumulates and updates dynamically rather than relying on RAG. It is built entirely by autonomous agents using a structured pipeline of specialized agents that communicate via GitHub Issues.

## Key Features
- Fully autonomous agent-driven development pipeline with specialized roles (Research, PM, Office Hour, Build, Review, Architect)
- Dual-surface wiki for humans (Markdown) and agents (structured claims, embeddings, fact triples)
- Self-healing agent system with automated reverts, issue triage, and quality enforcement
- Accumulates knowledge over time with provenance tracking, contradiction reconciliation, and staleness decay
- Supports multiple LLM providers (Anthropic, OpenAI, Google, Ollama) with environment-based auto-detection

## Why It Matters for RAG Builders
It demonstrates how autonomous agents can collaboratively build and maintain complex systems, offering a blueprint for future AI-driven software development and knowledge management.
