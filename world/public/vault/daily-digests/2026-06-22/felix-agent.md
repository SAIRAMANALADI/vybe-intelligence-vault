## Summary
Felix Agent is a persistent AI agent framework that wraps LLM backends (Codex, OpenCode, or Claude Code) and routes messages from communication platforms like Mattermost, Discord, or Slack through skill-gated interactions. It includes a live React-based owner console for monitoring, approvals, and management.

## Key Features
- Wraps multiple LLM backends (Codex, OpenCode, Claude Code) with a unified interface
- Routes messages from Mattermost, Discord, or Slack through skill-gated turns
- Live React-based owner console for real-time monitoring, approvals, and management
- Persistent sessions with runtime data persistence across restarts
- Modular skill system with dynamic approval workflows

## Why It Matters for RAG Builders
Felix Agent simplifies building AI agents that interact with users across multiple platforms while enforcing controlled, skill-gated responses, making it essential for scalable AI-driven communication systems.
