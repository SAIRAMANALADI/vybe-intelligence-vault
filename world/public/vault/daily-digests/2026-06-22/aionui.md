## Summary
AionUi is a free, open-source coworking platform for AI agents that enables users to collaborate with AI assistants directly on their computers for tasks like file operations, automation, and multi-agent coordination. It supports 30+ AI models and integrates with popular CLI agents like Claude Code and Codex.

## Key Features
- Built-in AI agent with zero setup required, supporting file read/write, web search, and image generation
- Multi-agent mode with auto-detection of CLI agents (Claude Code, Codex, etc.) and unified interface
- Team mode for coordinated multi-agent collaboration with parallel execution and shared workspace

## Why It Matters for RAG Builders
AionUi provides a unified, cross-platform interface for interacting with AI agents, making it easier to integrate and manage multi-agent workflows for document automation and complex tasks.
