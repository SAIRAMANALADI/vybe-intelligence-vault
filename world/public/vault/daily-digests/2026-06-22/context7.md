## Summary
Context7 is a platform that provides up-to-date, version-specific code documentation and examples for libraries directly within AI coding agents' prompts, eliminating hallucinations and outdated information in LLM responses.

## Key Features
- Fetches up-to-date, version-specific documentation directly into AI prompts
- Supports both CLI + Skills and MCP server modes for seamless integration with coding agents
- Multi-language support with 15+ localized documentation guides

## Why It Matters for RAG Builders
