## Summary
Prostor is an open-source Russian-language AI agent with a closed-loop learning system that autonomously creates, improves, and retains skills from experience. It supports multi-platform deployment, integrates with 200+ LLM providers, and includes advanced optimizations like HashLine for ultra-fast string matching.

## Key Features
- Closed-loop learning system that creates and improves skills autonomously from user interactions
- HashLine technology for ultra-fast string matching (up to 4700x speedup over fuzzy matching)
- Multi-platform deployment (CLI, Telegram, Discord, WhatsApp, Signal) with unified gateway
- Support for 200+ LLM providers with dynamic model switching via `prostor model` command
- Built-in automation scheduler, persistent memory, and tool delegation for parallel task execution
