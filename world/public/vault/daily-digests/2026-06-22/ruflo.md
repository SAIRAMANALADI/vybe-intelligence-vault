## Summary
Ruflo is an agent meta-harness designed to orchestrate, coordinate, and enhance multi-agent systems for Claude Code and Codex. It provides a comprehensive framework for deploying intelligent swarms, managing memory, enabling self-learning, and integrating RAG systems with enterprise-grade security and federation capabilities.

## Key Features
- Provides a meta-harness for orchestrating 100+ specialized agents with coordinated swarms and self-learning memory
- Enables federated communication between agents across machines with enterprise security guardrails
- Integrates seamlessly with Claude Code and Codex via plugins, MCP server, and hooks for enhanced agent capabilities
