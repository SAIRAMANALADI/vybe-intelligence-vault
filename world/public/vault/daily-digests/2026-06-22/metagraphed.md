## Summary
Metagraphed is a registry and operational layer for Bittensor subnets, providing machine-readable APIs, health checks, and schemas for subnet discovery and integration. It bridges the gap between protocol-level metagraph data and builder-facing tools, enabling AI agents and developers to interact with subnets programmatically.

## Key Features
- Centralized registry of Bittensor subnet APIs, health status, and schemas for easy discovery and integration
- Machine-readable OpenAPI and JSON Schema contracts for programmatic access and client generation
- MCP server for AI agent-native interaction with subnet APIs and tools
- REST and GraphQL APIs for querying subnet metadata, health, and endpoints
- Automated data refresh pipeline with deterministic artifacts and provenance

## Why It Matters for RAG Builders
It provides a critical bridge for AI agents and developers to discover, validate, and interact with Bittensor subnet APIs, accelerating RAG and AI workflow integrations.
