## Summary
NestRS is a modular Rust framework designed for building scalable backend applications with native performance. It provides a structured approach to backend development using dependency injection, modular architecture, and support for multiple transport layers like HTTP, GraphQL, WebSockets, and more.

## Key Features
- Modular architecture with dependency injection (IoC container)
- Support for multiple transport layers (HTTP, GraphQL, WebSockets, MCP, queues)
- Built-in CLI for scaffolding and task automation
- Reference implementation (demo workspace) showcasing real-world usage
- Unified layer pool for guards, pipes, interceptors, and filters
