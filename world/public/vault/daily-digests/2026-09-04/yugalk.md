## Summary
YuGalk is a lightweight desktop AI agent application that integrates LLM conversations, tool invocation, local inference, and an extensible skills/plugin system. It supports both local GGUF models via llama.cpp and any OpenAI-compatible cloud endpoints, prioritizing agent capabilities like tool use, long tasks, and context memory.

## Key Features
- Real-time tool invocation and long-task execution with model-native function calling support
- Seamless integration of local GGUF models (llama.cpp) and OpenAI-compatible cloud endpoints
- Bundled runtimes (Node.js, Python, Git, Playwright) for out-of-the-box functionality
- Multi-workspace isolation for conversations, project memory, and notes
- Skills system and MCP bridge for zero-code plugin integration

## Why It Matters for RAG Builders
YuGalk provides a flexible, extensible desktop framework for building AI agents with tool-use capabilities, bridging local and cloud models while simplifying deployment for RAG and AI stack builders.
