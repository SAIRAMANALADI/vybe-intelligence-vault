## Summary
Toto-Wolff is a persistent AI governance framework for Claude Code that enforces structured, multi-model deliberation for architectural decisions, pre-execution safety checks, and release gatekeeping. It records all decisions in a local Markdown vault for future sessions and integrates with Obsidian for knowledge management.

## Key Features
- Three-tier AI council (Haiku, Sonnet, Opus) for structured deliberation and rulings recorded in Markdown vaults
- P10 pre-execution planning with deterministic confidence scoring based on past decisions
- Cabinet release gate with three independent Opus agents (Garry Tan, Feynman, Karpathy) for unanimous approval
- Safety Car adversarial stress testing and DRS deterministic boundary hooks for execution safety
- Seamless Obsidian integration and CLI tools for vault management, synthesis, and upgrades

## Why It Matters for RAG Builders
It provides a persistent, auditable framework for AI-driven architectural decisions and safety checks, ensuring consistency and accountability across sessions while integrating with existing knowledge management systems.
