## Summary
A lightweight, local-first YAML workflow runner designed for the phantom-mesh ecosystem. It enables declarative automation with blocks like fetch, filter, LLM-summarize, and approval gates, running fully offline with deterministic outputs or integrating with AI agents via MCP.

## Key Features
- Declarative YAML-based workflow definition with 9 native blocks (e.g., HTTP fetch, LLM summarization, regex filtering)
- Fully offline execution with deterministic JSON artifacts and optional approval gates for side effects
- Seamless integration with phantom-mesh via MCP for AI agent-driven workflows
- Structured run artifacts, state/event stores, and templating with `${...}` syntax
- Built-in validation, dry-run, and strict mode for reliable automation

## Why It Matters for RAG Builders
It provides a lightweight, local-first alternative to heavyweight workflow engines, enabling reproducible AI-native automation with approval gating and mesh integration for RAG builders.
