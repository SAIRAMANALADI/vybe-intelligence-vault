## Summary
X-agent is a desktop coding agent designed for Godot 4 game development, enabling real-time code editing, scene execution, and step-by-step rollback within the same session. It integrates deeply with the Godot editor via RPC, supports Shadow Git checkpoints for reliable undo operations, and offers constrained session modes for different workflows.

## Key Features
- Deep Godot editor integration via RPC for real-time scene management and execution
- Shadow Git checkpoints enabling reliable rollback to any step without affecting manual edits
- Four session modes (Agent, Ask, Plan, Goal) with hard constraints for different workflows
- Design session type with constrained write operations to a dedicated directory and preloaded design skills
- Diff preview and structured tooling for Godot projects (linting, resource management, debugging)

## Why It Matters for RAG Builders
X-agent uniquely bridges AI agents with Godot game development workflows, enabling precise, real-time code and scene modifications while preserving edit history through Shadow Git, making it essential for AI-driven game development pipelines.
