## Summary
Zelyq is an open-source AI-powered agent framework that transforms natural language prompts into fully functional applications, including frontend, backend, and infrastructure components. It emphasizes engineering rigor, verification, and transparency, ensuring builds are correct, secure, and production-ready.

## Key Features
- Verifies builds automatically using typechecking and live previews before marking tasks as complete
- Plans and designs architectures before writing code, with explicit tradeoff explanations
- Supports multiple runtime environments (local, containerized, remote) with interchangeable drivers
- Includes specialized agents for design, DevOps, security/QA, and cinematic engineering
- Provides full audit logs, snapshots, and one-click reverts for every change
