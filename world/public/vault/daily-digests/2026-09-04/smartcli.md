## Summary
SmartCLI is a Python toolkit enabling AI agents to drive, perceive, and render terminal programs with high fidelity. It uses a pluggable PTY backend and pyte-based screen model to interact with real terminal applications like lazygit, vim, or htop, ensuring accurate perception and control.

## Key Features
- Drives real terminal programs (e.g., lazygit, vim) with precise keystroke control and screen perception using a pyte cell model
- Perceives terminal state via structured screen models (not byte streams) for accurate interaction feedback
- Includes a pluggable PTY backend supporting Windows (ConPTY) and POSIX systems
- Provides MCP-compatible tools for seamless integration with AI agent frameworks
- Offers a visual effects engine (cmd-art) and TUI widget library (tui-ui) for rendering terminal UIs

## Why It Matters for RAG Builders
SmartCLI enables AI agents to accurately interact with real terminal applications, bridging the gap between structured automation and unstructured terminal environments for RAG and agentic workflows.
