## Summary
TextForge AI is a pretext plugin and knowledge layer that enables large language models like Claude and GPT-4 to perform DOM-free text measurement, layout optimization, and spatial reasoning with pixel-perfect precision. It provides MCP tools for calculating text dimensions, detecting overlaps, and generating layout-aware content without browser dependencies.

## Key Features
- DOM-free text measurement engine with sub-pixel accuracy
- MCP tools for spatial text reasoning (e.g., TextWidthEstimator, LayoutOptimizer)
- Multi-API support for OpenAI and Claude with seamless integration
- Multilingual and Unicode-aware text processing (120+ languages)
- Responsive layout intelligence for dynamic container adaptation

## Why It Matters for RAG Builders
TextForge AI bridges the gap between linguistic and visual layout design, enabling AI models to generate pixel-perfect text layouts without browser dependencies, critical for professional-grade AI-driven design and content generation.
