## Summary
sync-worktrees automates Git worktree management by creating a directory per branch, keeping them in sync with remote branches, and exposing an MCP server for AI assistants to inspect and manage the workspace. It eliminates manual stashing, re-cloning, and directory hunting for developers and AI tools.

## Key Features
- Automated Git worktree creation and synchronization with remote branches
- Interactive TUI for managing worktrees and branches
- MCP server integration enabling AI assistants to inspect and operate worktrees
- Support for both worktree and clone modes for flexible repository management
- Configurable filtering, lifecycle management, and divergence detection

## Why It Matters for RAG Builders
It standardizes and automates Git worktree management, making AI assistants' understanding of the workspace consistent with the developer's, reducing context switching and improving productivity.
