## Summary
UnPeeragogy is a dual-column knowledge base that contrasts Peeragogy's collaborative learning theory with real-world operational friction, power dynamics, and failure patterns. It provides an evidence-based protocol for collecting and challenging research, alongside an MCP server to expose these tensions to AI systems.

## Key Features
- Dual-column reading experience contrasting theory vs. operational reality with independent scrolling
- Evidence Protocol with 8 taxonomy types and structured discussion templates for provenance tracking
- Agente Perturbatore MCP server exposing failure vectors, tension indices, and friction injection tools
- Interactive knowledge graph (3D force-directed) and full-text search across content
- CC0-licensed public domain content with AI-native distillation (LLMs.txt)

## Why It Matters for RAG Builders
It provides a structured framework to expose and analyze the gaps between collaborative learning theory and real-world operational challenges, enabling AI systems to better understand and navigate human coordination failures.
