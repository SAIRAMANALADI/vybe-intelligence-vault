## Summary
Timothy is a self-hosted personal AI assistant that integrates chat, cost tracking, task management, and agent-based workflows. It runs on local hardware and supports multiple LLM providers, enabling users to maintain full control over their data and infrastructure.

## Key Features
- Multi-provider LLM gateway with runtime configuration and hot reload
- Event-sourced sessions for crash-resistant conversation replay
- Long-term memory with hybrid pgvector retrieval and strict token budgeting
- Cost accounting with ledger-based pricing and usage dashboards
- Missions framework for long-running agent tasks with sandboxes and budgets

## Why It Matters for RAG Builders
Timothy provides a robust, self-hosted framework for building and deploying AI agents with built-in cost tracking, memory management, and multi-provider LLM support, making it essential for developers prioritizing privacy and control in AI workflows.
