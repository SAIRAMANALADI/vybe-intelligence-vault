## Summary
OmniRouter is an enterprise-grade WhatsApp orchestrator that automates customer support by triaging requests using LLMs, retrieving context via RAG, and escalating unresolvable queries to human agents. It ensures high scalability, sub-second latency, and strict data privacy.

## Key Features
- Intelligent triage of WhatsApp messages using OpenAI-powered intent recognition
- Privacy-first PII masking before LLM exposure to ensure data security
- Context-aware RAG pipeline with Qdrant for semantic knowledge retrieval
- Seamless human handoff for unresolvable queries with Redis session management
- Deep analytics and monitoring via Prometheus and Langfuse for traceability

## Why It Matters for RAG Builders
It provides a scalable, privacy-compliant framework for automating WhatsApp customer support with AI-driven triage and RAG, reducing operational overhead while ensuring high-quality responses.
