## Summary
Truss is a local-first, provider-neutral runtime for coding agents, offering a reusable runtime, MCP adapters, CLI, terminal UI, VS Code client, and desktop app. It enables local model integration with Ollama, LM Studio, and other OpenAI-compatible servers.

## Key Features
- Provider-neutral runtime supporting Ollama, LM Studio, and OpenAI-compatible servers
- Modular architecture with reusable npm packages for CLI, TUI, and VS Code extension
- Full-featured terminal UI with file browsing, editor, and agent chat
- VS Code extension for seamless agent integration within the IDE
- Desktop app with installers for Windows and Linux

## Why It Matters for RAG Builders
Truss provides a unified, local-first runtime for coding agents that simplifies integration with diverse model providers and tools, making it essential for AI engineers building agentic systems.
