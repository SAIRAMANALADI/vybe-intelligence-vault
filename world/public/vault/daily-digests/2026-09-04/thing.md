## Summary
Thing is an agent harness built from first principles, designed to demystify how agent loops function by implementing core functionality manually rather than relying on framework abstractions. It enables self-modification and tool integration through a bootstrapping process.

## Key Features
- Hand-written agent harness with minimal framework dependencies
- Self-modification capability by uploading and editing its own source code
- Tool integration via human-in-the-loop uploads (e.g., bash tool)
- Decision documentation through Architecture Decision Records (ADRs)
- Bootstrapping process to build core functionality incrementally
