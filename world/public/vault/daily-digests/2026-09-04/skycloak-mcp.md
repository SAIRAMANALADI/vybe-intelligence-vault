## Summary
A Model Context Protocol (MCP) server for Skycloak, a managed Keycloak service, enabling programmatic management of Keycloak clusters, realms, applications, SSO, and users from any MCP-compatible client like Claude Desktop or Cursor.

## Key Features
- 129 MCP tools for managing Keycloak clusters, realms, applications, and users with fine-grained read/write permissions
- OAuth 2.0 and API key authentication with automatic token renewal and scope-based tool gating
- Supports local stdio, hosted HTTP, and CI/CD deployments with environment variable overrides
- Includes 8 pre-built prompts and 4 operational skills for common Keycloak tasks like SSO rollout and upgrade readiness
- Destructive operations require explicit confirmation and are rate-limited per workspace plan

## Why It Matters for RAG Builders
It provides a standardized, secure, and scalable way to integrate Keycloak management into AI workflows via MCP, enabling automated SSO, identity, and access control operations for RAG and agent systems.
