## Summary
A Model Context Protocol (MCP) server that integrates Slack with AI agents by leveraging browser session tokens, enabling seamless access to Slack data without OAuth or app registration. It provides 21 tools for reading, writing, and managing Slack conversations, users, and workflows.

## Key Features
- No OAuth or app registration required—uses existing browser session tokens
- 21 tools for reading, writing, and managing Slack data (e.g., messages, threads, users)
- Supports multiple AI clients (Claude, Cursor, Copilot, Windsurf, Gemini CLI, Codex CLI)
- Workspace profiles for running multiple Slack accounts side-by-side
- Keychain-only credential storage option for enhanced security

## Why It Matters for RAG Builders
It enables AI agents to directly interact with Slack data without administrative overhead, streamlining workflows for developers and teams.
