## Summary
A zero-dependency JavaScript/TypeScript SDK designed for frontend and Node.js developers to fetch real-time and historical stock market data (A-shares, H-shares, US stocks, and mutual funds) without requiring Python or backend services. It includes CLI tools, MCP server integration, and built-in technical indicators for AI and RAG applications.

## Key Features
- Zero-dependency, lightweight package supporting both browser and Node.js environments with ESM/CJS exports
- Comprehensive stock market data coverage (A-shares, H-shares, US stocks, mutual funds) including real-time quotes, historical K-lines, and minute-level data
- Built-in technical indicators (MA, MACD, RSI, KDJ, etc.) and signal detection for AI-driven analysis
- CLI tools and MCP server for direct integration with AI tools (e.g., Cursor, Claude) for real-time stock data queries
- Subpath exports for pure computation modules (indicators, signals, symbols) to optimize bundle size

## Why It Matters for RAG Builders
It enables AI and RAG builders to integrate real-time financial data seamlessly into their applications without backend dependencies, accelerating development and reducing infrastructure complexity.
