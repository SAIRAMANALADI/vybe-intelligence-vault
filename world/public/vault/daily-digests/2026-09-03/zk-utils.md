## Summary
zk-utils is an MCP (Model Context Protocol) server designed for managing zk note collections, enabling search, creation, and link analysis of notes. It integrates with the zk command-line tool to provide structured note management capabilities for AI-driven workflows.

## Key Features
- MCP-compliant server for zk note operations (search, create, link analysis)
- Automatic reindexing of notes to ensure freshness before queries
- Supports outbound/inbound link tracking and related note suggestions
- Docker and uvx deployment options for flexibility
- Environment variable configuration for note directory path
