## Summary
Veloce is an async-first, ASGI-native Python web framework that unifies route definitions with HTTP endpoints, OpenAPI operations, and MCP tools in a single codebase. It eliminates external dependencies by providing a radix-tree router, dependency injection, Pydantic validation, and built-in middleware from scratch.

## Key Features
- Async-first handlers with transparent sync support via thread-pool execution
- Radix-tree routing with typed path converters (int, float, uuid, datetime, etc.)
- Built-in OpenAPI 3.1 schema generation with Swagger UI and ReDoc
- Typed dependency injection including yield-style dependencies with teardown
- Unified route definitions that drive HTTP endpoints, OpenAPI operations, and MCP tools

## Why It Matters for RAG Builders
Veloce simplifies building AI-native web services by providing a single framework that integrates HTTP, OpenAPI, and MCP tools, reducing boilerplate and improving developer productivity for RAG and agent-based systems.
