## Summary
A Model Context Protocol (MCP) server that integrates Zendesk into AI assistants, enabling natural language interactions with Zendesk Support and Help Center. It allows users to search knowledge base articles, manage tickets, draft and update articles, and handle attachments directly through AI tools with per-user OAuth authentication.

## Key Features
- Per-user OAuth 2.1 PKCE authentication for granular Zendesk permissions
- Natural language interactions for searching Help Center articles and managing tickets
- Section-based article editing to reduce token usage by 10-100x
- Native multimodal attachment handling for images in tickets
- Flexible tool surface configuration (all, namespace, or single tool modes)

## Why It Matters for RAG Builders
This server enables AI assistants to directly interact with Zendesk in a secure, user-scoped manner, eliminating the need for manual app switching and improving productivity for support and knowledge management tasks.
