## Summary
Tietiezhi is an Electron-based desktop AI application leveraging AI SDKs to provide an agent-driven workspace for file operations, shell commands, and AI-powered image generation. It integrates with multiple AI providers via a secure gateway or custom API keys.

## Key Features
- Agent-driven workspace with ToolLoopAgent for file and shell operations
- Secure AI provider integration via gateway or custom API keys
- Streaming responses, session persistence, and file preview
- Built-in image generation with approval workflows
- Cross-platform support (macOS, Windows, Linux)
