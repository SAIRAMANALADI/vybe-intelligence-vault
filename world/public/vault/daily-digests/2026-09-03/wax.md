## Summary
Wax is a local-first shared memory layer for AI agents, enabling persistent, single-file storage optimized for Apple Silicon. It supports vector search, photo/video RAG, and cross-device synchronization via iCloud or AirDrop, eliminating the need for hosted vector databases.

## Key Features
- Single-file memory store (`.wax`) for persistence and portability
- Sub-millisecond RAG with vector search and hybrid retrieval modes
- Cross-device synchronization via iCloud Drive or AirDrop
- Embeddable Swift engine for on-device RAG in iOS/macOS apps
- MCP server integration for shared agent memory across tools like Claude, Cursor, and Codex

## Why It Matters for RAG Builders
Wax provides a lightweight, portable, and high-performance memory layer that eliminates dependency on hosted vector databases, making it ideal for local-first RAG systems.
