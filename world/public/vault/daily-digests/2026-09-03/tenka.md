## Summary
TENKA is a local-first Python voice agent for Windows that listens, thinks, remembers, and acts on the desktop without requiring code changes for new app or service integrations. It evolves by learning from user behavior and stores data in a knowledge graph backed by SQLite and FAISS.

## Key Features
- Real-time voice interaction with wake-word or push-to-talk
- Dynamic desktop automation across browser, native apps, and vision fallback tiers
- Persistent knowledge graph for memory and context retention
- Swappable personalities with self-reflective trait evolution
- Multi-provider LLM routing with free-tier fallback to Ollama

## Why It Matters for RAG Builders
TENKA provides a modular, runtime-adaptive framework for building personal voice agents that can integrate with any desktop application or service without code changes, making it ideal for RAG builders seeking flexible, evolving automation capabilities.
