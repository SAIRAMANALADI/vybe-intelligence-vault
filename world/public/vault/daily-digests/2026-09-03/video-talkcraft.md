## Summary
video-talkcraft is an AI agent skill that transforms voiceover scripts and audio into polished explainer videos with synchronized motion graphics. It automates word-level voiceover alignment, dynamic text animations, camera movements, and quality checks using Remotion for rendering.

## Key Features
- Word-level voiceover synchronization with sub-200ms accuracy using ASR models
- 78 pre-built motion recipe cards with self-contained Remotion source code and HTML previews
- Anti-PPT camera system with seven layers to prevent static frames and ensure cinematic flow
- Three-tier quality assurance pipeline including static frame detection, audio cue verification, and frame-level review
- Integration with Claude Code/Codex as an installable skill for automated video production

## Why It Matters for RAG Builders
It streamlines the creation of high-quality, dynamic explainer videos from voiceovers, reducing manual effort and ensuring professional motion design consistency for AI-driven content pipelines.
