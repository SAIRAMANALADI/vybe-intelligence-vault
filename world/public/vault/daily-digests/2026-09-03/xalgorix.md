## Summary
Xalgorix is an open-source, self-hosted AI penetration testing platform that autonomously discovers and proves vulnerabilities using an LLM-driven agent and an independent verifier. It combines offensive security tooling with a 22-phase methodology to deliver exploit-verified findings with audit-ready reports.

## Key Features
- Autonomous LLM-driven pentesting with a 22-phase methodology
- Independent verifier re-exploits findings to ensure proof of impact
- Self-hosted and private with support for multiple LLM providers
- Pre-installed offensive security toolset (nmap, nuclei, httpx, etc.)
- Audit-ready PDF reports with CVSS scoring and remediation guidance

## Why It Matters for RAG Builders
Xalgorix automates and verifies security testing, reducing false positives and manual triage while ensuring exploit-verified findings for critical systems.
