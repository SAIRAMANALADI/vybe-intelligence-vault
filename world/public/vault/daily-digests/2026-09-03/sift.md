## Summary
Sift is an AI-powered research synthesis engine that automates the retrieval, verification, and synthesis of web information with built-in source reliability scoring. It dynamically adjusts search depth and routes queries through a tiered source hierarchy to deliver accurate, context-rich answers.

## Key Features
- Automatic depth selection for queries (quick answer to deep research)
- Tiered source hierarchy (internal knowledge, web search, semantic providers)
- Cross-source agreement scoring for reliability evaluation
- Dynamic content-density checks to optimize retrieval
- OCAS architecture coherence via skill.json configuration

## Why It Matters for RAG Builders
Sift streamlines high-quality data retrieval and synthesis for RAG pipelines, ensuring accurate and reliable information sources while reducing manual curation overhead.
