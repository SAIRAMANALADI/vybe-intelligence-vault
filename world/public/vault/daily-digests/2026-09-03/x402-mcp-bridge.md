## Summary
The @hpp-io/x402-mcp-bridge enables autonomous USDC.e payments for AI agents (e.g., Claude, Cursor) via the x402 protocol, allowing discovery and pay-per-call execution of services without API keys or manual signing. It acts as an MCP bridge and CLI tool for seamless agent-to-service transactions.

## Key Features
- Enables autonomous agent payments over x402 without API keys or manual signing
- Supports discovery and pay-per-call execution of services within a spend cap
- Provides CLI and MCP bridge for seamless integration with AI agents
- Offers wallet management and funding via USDC.e (gasless)
- Supports multiple network modes (Sepolia, Mainnet) and Safe (governance) mode

## Why It Matters for RAG Builders
