## Summary
Wayland Core is a self-evolving, terminal-first AI agent engine written in Rust that dynamically combines multiple rival models to solve complex problems, rewrites its own prompts for continuous improvement, and operates securely with sandboxed execution and MCP-native interoperability.

## Key Features
- Dynamic council of rival models for cross-audited answers and consensus-based decision making
- Self-evolution via prompt rewriting and scoring against an eval harness to retain only winning strategies
- Provider-neutral core with 23 built-in providers and customizable compatibility layers for seamless integration
- Secure execution with OS-native sandboxing, egress gating, and keyring-backed credential management
- Orchestration capabilities supporting Spawn, Swarm, Mesh, and Fleet topologies with enforced caps and isolation

## Why It Matters for RAG Builders
Wayland Core enables RAG builders to deploy self-improving, multi-model agents that dynamically adapt to user needs while maintaining strict security and interoperability standards.
