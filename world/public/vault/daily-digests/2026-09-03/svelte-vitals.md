## Summary
A static code-health checker for SvelteKit projects that evaluates SEO, performance, correctness, security, and architecture from source code without requiring a browser or headless Chrome. It provides a Health score and supports multiple reporters for different use cases.

## Key Features
- Multi-category scoring (SEO, Performance, Correctness, Security, Architecture) with a weighted Health score
- Multiple reporters (console, JSON, agent, SARIF, GitHub) for diverse output formats
- GitHub integration with PR annotations and SARIF upload for security alerts
- Live dashboard for real-time project analysis during development
- MCP server for AI agent tool integration (analyze and explain_rule tools)

## Why It Matters for RAG Builders
It provides automated, source-based code health analysis for SvelteKit projects, enabling AI-driven remediation and continuous improvement in AI engineering workflows.
