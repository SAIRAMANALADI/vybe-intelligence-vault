## Summary
TemperForge is a multi-agent AI development workbench designed to enforce coding standards and improve AI agent performance through a closed-loop system. It enables agents like Claude Code or Cursor to write code that meets team-specific standards and continuously learns from experience.

- Agent-agnostic persona and skill library for major AI agents
- Continuously growing memory system with experience records

- Health checks and automated setup for multi-agent environments
