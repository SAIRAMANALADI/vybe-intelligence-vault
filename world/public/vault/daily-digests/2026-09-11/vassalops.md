## Summary
VassalOps is a local-first desktop agent for Windows that combines a pywebview-based control panel with LangGraph planning, Ollama for local inference, and pyautogui for automation. It requires human approval before executing any mouse or keyboard macros, ensuring safety and privacy for enterprise data.

## Key Features
- Local-first architecture with Ollama for offline inference
- Human approval gate for all automation actions
- LangGraph-based planning and structured action execution
- Desktop OCR and clipboard context capture for planning
- Macro learning and replay with duty scheduling

## Why It Matters for RAG Builders
VassalOps provides a privacy-preserving, human-approved framework for automating desktop tasks using local AI, making it essential for RAG builders who need safe, auditable, and offline-capable agentic workflows.
