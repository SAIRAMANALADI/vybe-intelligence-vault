## Summary
xProof provides an accountability layer for AI agents by anchoring reasoning and planned actions on-chain before execution, ensuring immutable proof-of-output verification via MultiversX. It enables agents to prove decisions (WHY) and intentions (WHAT) prior to action, with post-execution results also recorded for a full 4W audit trail.

## Key Features
- Pre-execution proof anchoring for AI agent decisions and reasoning
- Post-execution result verification for full audit trails
- No API key required; uses x402 for pay-per-call transactions
- Integration via MCP, Python SDK, and OpenClaw/Hermes
- Immutable on-chain storage on MultiversX for tamper-proof records

## Why It Matters for RAG Builders
xProof ensures trust and transparency in AI agent actions by providing verifiable, on-chain proof of reasoning and outcomes, critical for RAG systems requiring auditability and accountability.
