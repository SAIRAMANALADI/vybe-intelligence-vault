## Summary
Yomi is an open-source LINE MCP server that enables AI agents like Claude to interact with personal LINE accounts directly. It reads, replies, sends images, and searches conversations while decrypting end-to-end encrypted messages locally without requiring a bot account or official API.

## Key Features
- Direct LINE account integration without bot accounts or official API
- End-to-end encrypted message decryption for local processing
- MCP server exposing tools for reading, replying, sending images, and searching conversations
- Local SQLite-based search index for efficient conversation retrieval
- Insight tool for analyzing conversation patterns and relationships

## Why It Matters for RAG Builders
Yomi enables AI agents to securely and locally interact with LINE conversations, bridging the gap between personal messaging and AI-driven automation without compromising end-to-end encryption.
