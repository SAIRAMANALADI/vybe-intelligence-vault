## Summary
An MCP (Model Context Protocol) server that provides AI assistants with access to Steam Storefront metadata, user tags, genres, categories, and review sentiment without requiring a Steam API key. Enables searching games, retrieving store details, and analyzing reviews via standardized MCP tools.

## Key Features
- No API key or Steam account required for access to public Steam Storefront data
- In-memory caching (1 hour) for performance optimization and rate limit protection
- Standardized MCP tools for seamless integration with AI assistants
- Retrieves user-defined tags, genres, categories, and review sentiment
- Supports real-time and cached queries for game metadata and reviews

## Why It Matters for RAG Builders
It enables AI assistants to dynamically fetch and analyze Steam game data, enhancing context-aware responses for gaming-related queries without requiring external API keys or complex setup.
