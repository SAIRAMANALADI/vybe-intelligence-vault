## Summary
Skales is a local-first AI agent that runs on your computer, providing multi-step task automation, code editing, and file management without requiring cloud dependencies or complex setup. It supports cross-platform deployment and integrates with 15+ AI providers or operates fully offline.

## Key Features
- Hand-and-close-lid task execution with autonomous goal completion and progress persistence
- Integrated code editor with inline diffs, undo, and multi-repo support
- Cross-device control via mobile apps (Android/iOS) and desktop pairing
- Built-in memory system and migration tools from other AI agents
- Support for 15+ AI providers or fully offline operation with Ollama

## Why It Matters for RAG Builders
Skales provides a privacy-preserving, local-first alternative to cloud-based AI agents, enabling secure multi-step automation and code editing without complex infrastructure.
