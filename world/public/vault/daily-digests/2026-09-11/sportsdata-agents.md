## Summary
A modular agentic platform that transforms sports data into customizable trading desks, analytics teams, or fantasy systems using 32+ specialized LLM agents over a shared data backbone. It supports live odds ingestion, arbitrage detection, backtesting, and policy-controlled betting across multiple bookmakers.

## Key Features
- 32+ specialized LLM agents for sports data tasks (trading, analytics, fantasy, racing)
- Live odds ingestion from 10+ bookmakers and 2 prediction markets with automated discovery
- Policy-controlled betting with defaults to paper trading and strict compliance checks
- Deterministic event resolution and cross-book price aggregation for arbitrage opportunities
- Backtesting with CLV (Closing Line Value) and golden metric evaluation against baselines

## Why It Matters for RAG Builders
It provides a modular, agent-driven framework for building custom sports data applications with built-in arbitrage detection, backtesting, and policy-controlled automation, reducing development time for RAG/AI stack builders.
