## Summary
XOps CLI is a Go-based, cross-platform tool for secure remote host management, offering SSH, batch execution, playbook orchestration, and MCP integration to enable AI agents to safely operate servers within defined boundaries.

## Key Features
- Built-in Model Context Protocol (MCP) server for secure AI agent integration with risk assessment and policy controls
- Unified host asset management with encrypted credential storage and CSV import/export
- Declarative playbook orchestration with YAML-based task definitions and concurrency control
- Enhanced SSH with TUI, jump host support, and sudo elevation modes
- Batch execution, file transfer (SCP/SFTP), and firewall management across multiple hosts

## Why It Matters for RAG Builders
It bridges the gap between AI agents and secure remote server operations by providing a controlled environment for AI-driven automation with built-in safety and audit mechanisms.
