## Summary
Dignite Vault Extract is a channel layer for Intelligent Document Processing (IDP) that converts scans, photos, PDFs, Office files, and digital-born documents into structured Markdown and metadata. It acts as a middleware to feed downstream RAG platforms, business systems, and AI clients via REST, EventBus, MCP server, or Webhook (planned).

## Key Features
- Multi-format document ingestion (scans, PDFs, Office files, digital-born docs)
- OCR providers (Vision LLM, PaddleOCR, Azure Document Intelligence) with configurable options
- Structured Markdown output with system metadata and field extraction
- Multi-tenancy support for downstream consumers
- Flexible egress via REST, EventBus, MCP server, or Webhook (planned)

## Why It Matters for RAG Builders
It provides a critical middleware layer to transform unstructured documents into structured, AI-ready data for RAG pipelines, eliminating the need for custom IDP integrations in downstream systems.
