## Summary
A fully open-source API service for fetching WeChat public account articles, generating RSS feeds, and enabling AI client integration via MCP. It includes anti-censorship mechanisms, proxy rotation, and markdown export for knowledge management tools.

## Key Features
- RSS feed generation for WeChat public accounts with full article content and images
- MCP server for direct AI client integration (Claude, Cursor, etc.) to search, subscribe, and read articles
- Anti-censorship system with SOCKS5 proxy rotation and Chrome TLS fingerprinting
- Markdown export with YAML frontmatter for Obsidian/Logseq integration
- Webhook notifications for login expiration and verification events

## Why It Matters for RAG Builders
It provides a critical bridge for AI systems to access and process WeChat public account content at scale while bypassing censorship, enabling richer context for RAG applications.
