## Summary
WebOperator is an AI-powered browser automation agent and MCP server for Chrome that enables goal-driven task execution via plain English commands. It combines a Chrome extension with a local or cloud LLM backend to automate multi-step workflows, schedule recurring tasks, and expose browser capabilities as MCP tools for external agents.

## Key Features
- Goal-driven browser automation via plain English commands with a plan-act-verify loop
- Exposes 10 MCP tools for external agents to control Chrome/Chromium tabs programmatically
- Supports local (Ollama/MLX) and cloud LLMs (Anthropic, OpenAI, etc.) with tool calling
- Schedules recurring tasks (hourly/daily/weekly) with full audit trails and history
- Handles CAPTCHAs, dynamic pages, and multi-tab workflows with structured snapshots

## Why It Matters for RAG Builders
It bridges AI agents with real-world browser interactions, enabling autonomous task execution, data extraction, and multi-step workflows critical for RAG pipelines that require dynamic web content processing.
