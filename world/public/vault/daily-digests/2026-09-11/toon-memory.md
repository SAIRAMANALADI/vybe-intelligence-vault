## Summary
toon-memory is an MCP (Model Context Protocol) memory server that provides persistent, token-efficient memory for AI coding agents, enabling them to remember decisions, patterns, and bugs across sessions without relying on LLMs or external servers.

## Key Features
- 13 MCP tools for full memory management, including recall, remember, forget, and session coordination
- Token-efficient memory storage and recall with 22% fewer tokens than JSON, using TOON format and graph-based subgraph expansion
- Supports 15+ AI coding agents (e.g., VS Code, Claude Code, Cursor, Continue) with auto-configuration and hooks
- BM25 + centrality ranking for precise memory recall, with per-hop decay and auto-tagging from project dependencies
- Built-in encryption, auto-archiving, TTL-based expiration, and memory diff tools for versioned context tracking

## Why It Matters for RAG Builders
It enables AI coding agents to retain critical project context across sessions without token bloat, drastically improving consistency and reducing redundant explanations in RAG pipelines.
