## Summary
seite is an AI-native static site generator that leverages Claude Code as its primary interface, enabling AI agents to manage, build, and deploy websites directly. It bridges traditional static site generation with modern AI tooling through MCP server integration and LLM-optimized output formats.

## Key Features
- AI-driven content generation and management via `seite agent` with full site context
- Built-in MCP server exposing site resources and tools for AI tools
- Multi-audience output: optimized HTML for browsers, markdown for LLMs, and structured data for AI tools
- Multi-language and multi-collection support with presets for posts, docs, changelogs, and more
- Automated deployment pipelines with guided setup for GitHub Pages, Cloudflare Pages, and Netlify

## Why It Matters for RAG Builders
seite enables AI agents to directly manage and deploy static websites, reducing manual effort and integrating seamlessly with existing AI workflows like Claude Code.
