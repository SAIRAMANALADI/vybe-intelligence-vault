## Summary
ChunkHound is a local-first codebase intelligence tool that extracts architectural patterns, institutional knowledge, and semantic relationships from codebases using advanced parsing and research-backed algorithms. It integrates with MCP clients for AI-assisted code analysis without cloud dependencies.

## Key Features
- cAST algorithm for research-backed semantic code chunking
- Multi-hop semantic search for discovering interconnected code relationships
- Real-time indexing with automatic file watching and smart diffs
- 32+ language support via Tree-sitter and custom parsers
- MCP integration for seamless AI client compatibility (Claude, VS Code, Cursor, etc.)

## Why It Matters for RAG Builders
ChunkHound bridges the gap between raw code and AI understanding by providing structured, semantic insights into large codebases, enabling more accurate and context-aware RAG systems for developers.
