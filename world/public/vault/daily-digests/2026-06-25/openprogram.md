## Summary
OpenProgram is an open-source agent harness framework that enables building and orchestrating agentic workflows in Python. It bridges deterministic code execution with LLM-driven reasoning, allowing developers to define control flows while delegating judgment tasks to LLMs, supporting any LLM provider and platform.

## Key Features
- Python-driven control flow with LLM-driven reasoning for balanced execution
- Automatic DAG-based context threading across nested LLM calls
- Cross-platform support (macOS, Linux, Windows) with native installation
- Modular harness system for plug-and-play agent workflows (GUI, Research, Wiki, etc.)
- Self-evolving workflows where agents can build, run, and improve their own tools

## Why It Matters for RAG Builders
OpenProgram provides a critical framework for building reliable, scalable agentic workflows that combine deterministic control with LLM flexibility, essential for RAG builders seeking robust multi-agent orchestration.
