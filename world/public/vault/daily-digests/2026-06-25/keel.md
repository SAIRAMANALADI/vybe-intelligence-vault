## Summary
Keel is an AI-powered behavioral trading coach that analyzes a trader's Bitget trade history to identify personal failure patterns and intercepts emotionally driven trades in real time before execution, reducing losses from behavioral biases.

## Key Features
- Behavioral fingerprinting using AI (Qwen) to analyze 90 days of trade history and identify personal bias patterns with severity scores
- Real-time order monitoring with WebSocket and REST polling to intercept trades before execution
- Intervention overlay with countdown, personal stats, and counterfactual PnL calculation for overridden trades
- Weekly behavioral reports with improvement scores, discipline streaks, and pattern trends
- MCP server integration for Bitget Agent Hub to expose Keel tools for automated trading agents

## Why It Matters for RAG Builders
Keel directly addresses the critical gap in AI-driven trading by intercepting emotionally biased trades before execution, reducing losses for retail traders and enhancing the reliability of automated trading systems.
