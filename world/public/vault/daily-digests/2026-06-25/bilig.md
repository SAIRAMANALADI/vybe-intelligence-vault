## Summary
Bilig provides a headless runtime for executing and verifying Excel workbook logic in Node.js environments. It enables programmatic editing of cells, recalculation of formulas, and readback of outputs without requiring desktop spreadsheet applications.

## Key Features
- Programmatic editing and recalculation of Excel workbooks in Node.js
- Formula readback and verification for AI agents and services
- Support for XLSX file analysis, including stale cached values and compatibility risks
- GitHub Actions integration for CI workflows with XLSX fixtures
- Modular packages (@bilig/workpaper, @bilig/headless, @bilig/xlsx-formula-recalc) for flexible integration

## Why It Matters for RAG Builders
Bilig enables AI agents and services to programmatically validate and manipulate Excel workbooks, ensuring formula accuracy and reducing reliance on manual spreadsheet tools for RAG pipelines.
