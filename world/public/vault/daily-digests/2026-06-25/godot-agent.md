## Summary
godot-agent (`gda`) is a CLI, Skill, and MCP server that provides structured, machine-readable control over the Godot Engine for AI agents and automation. It enables headless scene/script/export automation and live runtime control of running Godot games via a daemon.

## Key Features
- Headless and live operation modes for Godot Engine control
- Structured JSON output and schema validation for AI agent compatibility
- CLI, Skill, and MCP server interfaces for flexible integration
- Real-time runtime scene tree inspection, input simulation, and performance monitoring
- Projectless and editorless operation for CI/CD and scripting

## Why It Matters for RAG Builders
It bridges the gap between AI agents and Godot Engine by providing structured, machine-readable control and real-time feedback, enabling seamless automation and debugging for game development workflows.
