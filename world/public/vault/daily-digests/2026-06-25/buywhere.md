## Summary
BuyWhere provides an agent-native product catalog API that enables AI agents to search, compare, and track prices across 40+ retailers in Southeast Asia, the US, Australia, Japan, and Korea. It supports BM25-ranked search, structured price comparisons, deals discovery, and affiliate link tracking with MCP compatibility.

## Key Features
- BM25-ranked product search across 40+ retailers
- Structured price comparison and deals discovery
- MCP-compatible tools for AI agents (Claude, Cursor, LangChain, CrewAI)
- Multi-region retailer coverage (Southeast Asia, US, Australia, Japan, Korea)
- Rate-limited API with free, live, and partner tiers

## Why It Matters for RAG Builders
