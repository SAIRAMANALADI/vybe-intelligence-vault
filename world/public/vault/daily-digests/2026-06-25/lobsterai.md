## Summary
LobsterAI is a desktop-grade, open-source AI agent framework developed by NetEase Youdao that acts as a 24/7 office assistant. It integrates with real work environments (files, terminal, browser) to execute tasks like data analysis, document generation, and automation, while enabling remote control via multiple IM platforms.

## Key Features
- Executes real-world tasks directly in local environments (files, terminal, browser) with user approval gating
- Supports custom agents, skills, and MCP servers for extensibility
- Enables remote control via WeChat, Feishu, DingTalk, Telegram, and other IM platforms
- Persistent memory and scheduled tasks for long-term productivity automation
- Cross-platform support (macOS, Windows) with bundled Python runtime for Windows
