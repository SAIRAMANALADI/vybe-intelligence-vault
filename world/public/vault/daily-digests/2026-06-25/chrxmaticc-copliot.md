## Summary
Chrxmaticc Copilot is a free, open-source terminal-based AI assistant designed for coding, shaders, and general conversation. It supports dual AI providers with automatic failover, voice input/output, Spotify integration, a plugin system, and persistent memory—all running locally without subscriptions.

## Key Features
- Dual AI provider failover (Pollinations → Groq → Offline)
- Voice input/output with Google TTS/STT integration
- Spotify control via OAuth with no data storage
- Plugin system for extensibility (drop-in .js files)
- Persistent memory with local JSON storage

## Why It Matters for RAG Builders
It provides a lightweight, local-first agent framework with voice and plugin capabilities, reducing dependency on cloud-based AI services for terminal workflows.
