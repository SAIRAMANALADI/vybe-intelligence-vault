## Summary
A terminal-native finance toolkit designed for AI agents to gather structured, evidence-based financial data with audit trails. It provides CLI commands for real-time prices, market sessions, historical data, crypto market structure, prediction-market sentiment, and guarded signed trading workflows.

## Key Features
- Real-time and historical financial data retrieval with structured JSON output
- Support for equities, crypto, and prediction markets with provider-specific capabilities
- Guarded signed trading workflows with risk checks, intent files, and audit logs
- Runtime-discoverable commands and skills for AI agent guidance
- Terminal-native TUI for interactive market analysis and monitoring

## Why It Matters for RAG Builders
It provides AI agents with a reliable, auditable, and structured way to gather financial data and execute trades, reducing reliance on stale or unverified sources.
