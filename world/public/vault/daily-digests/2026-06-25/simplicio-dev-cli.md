## Summary
A CLI tool that transforms one-line natural language tasks into verified code changes by generating diffs, tests, and evidence with a six-layer contract. It acts as the execution layer for the Simplicio ecosystem, ensuring high accuracy in code modifications across multiple LLM providers.

## Key Features
- Six-layer contract for structured task execution and verification
- Automated diff generation, testing, and evidence collection
- Multi-provider LLM support (OpenAI, Anthropic, DeepSeek, etc.)
- Benchmarking and performance validation against real codebases
- Idempotent auto-installation and skill integration for tools like Claude Code

## Why It Matters for RAG Builders
It provides a reliable, automated bridge between natural language prompts and verified code changes, significantly improving the accuracy and trustworthiness of AI-driven software modifications.
