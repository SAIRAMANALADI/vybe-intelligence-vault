## Summary
Unstract is an open-source platform that uses LLMs to extract structured JSON from unstructured documents like PDFs, images, and scans. It enables teams to define extraction schemas via natural language prompts and deploy as APIs or ETL pipelines for seamless data integration.

## Key Features
- Prompt Studio for defining extraction schemas with natural language prompts
- REST API for document processing and JSON output
- ETL pipeline for automated document processing and data warehousing
- Multi-provider LLM and vector DB integrations (OpenAI, Anthropic, Qdrant, etc.)
- MCP Server and n8n Node for AI agent and workflow integrations

## Why It Matters for RAG Builders
Unstract simplifies the extraction of structured data from unstructured documents, reducing development time and enabling seamless integration with RAG pipelines and AI workflows.
