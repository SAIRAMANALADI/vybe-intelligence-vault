## Summary
Zeno Mobile Runner (ZMR) is a mobile UI automation tool designed for AI coding agents, CI pipelines, and traceable product evidence. It provides a control plane for agents to interact with mobile apps, capture UI state, execute actions, and generate replayable traces without embedding an LLM.

## Key Features
- Semantic UI state capture and stable selectors for AI reasoning
- Deterministic JSON-based scenario replay for CI pipelines
- Multi-protocol support (MCP, JSON-RPC, CLI) for agent integration
- Cross-platform compatibility (Android, iOS, React Native, Flutter, Expo)
- Replayable trace viewer with screenshots, UI trees, and reports

## Why It Matters for RAG Builders
Zeno Mobile Runner enables AI agents to reliably interact with mobile apps and generate verifiable evidence, bridging the gap between agent-driven development and production-ready testing.
