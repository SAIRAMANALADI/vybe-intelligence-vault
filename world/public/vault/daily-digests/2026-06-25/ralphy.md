## Summary
Ralphy is an autonomous GitHub issue backlog manager that plans, codes, commits, and closes issues overnight using AI agents like Claude Code, Codex, or OpenCode. It ensures safe, manual review by committing changes to a local branch without pushing or opening PRs.

## Key Features
- Autonomous issue handling: plans, codes, commits, and closes issues based on trusted labels
- Multi-agent support: integrates with Claude Code, Codex, or OpenCode for execution
- Knowledge caching: accumulates and consolidates environment facts for future runs
- Safety mechanisms: enforces clean working trees, time budgets, and manual review before merging
- Split planning and execution: allows separate agents for planning and coding phases

## Why It Matters for RAG Builders
Ralphy automates repetitive coding tasks by leveraging AI agents, reducing manual effort while ensuring safe, reviewable changes for RAG and AI stack builders.
