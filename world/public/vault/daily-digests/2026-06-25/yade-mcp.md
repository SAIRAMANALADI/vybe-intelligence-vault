## Summary
yade-mcp is an MCP server that bridges AI agents with YADE, an open-source discrete element method (DEM) engine, enabling natural language interaction with simulations. It allows agents to execute, monitor, and debug YADE scripts dynamically while maintaining session context.

## Key Features
- Enables AI agents to interact with YADE simulations via natural language commands
- Supports real-time execution, monitoring, and debugging of YADE scripts
- Manages long-running background tasks with automatic error handling and recovery
- Maintains session context across agent interactions for seamless continuity
- Provides live shell access to running simulations for dynamic inspection and adjustments

## Why It Matters for RAG Builders
It bridges the gap between AI agents and specialized simulation tools like YADE, enabling autonomous execution and debugging of complex DEM simulations through natural language.
