## Summary
inner-coordinates automates desktop application interactions by capturing and replaying mouse clicks and sequences based on visual coordinates, enabling users to build workflows without requiring application-specific APIs or code.

## Key Features
- Captures and stores visual coordinates of UI elements for automation
- Builds and runs workflows by sequencing saved coordinates
- Operates locally with no external data storage for privacy
- Supports Windows 10/11 with minimal system requirements
- Troubleshooting tools for screen resolution and window management
