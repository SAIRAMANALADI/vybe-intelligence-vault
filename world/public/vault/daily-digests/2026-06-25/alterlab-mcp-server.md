## Summary
AlterLab MCP Server is a toolkit that enables AI agents like Claude, Cursor, and Windsurf to scrape websites, extract structured data, and capture screenshots with built-in anti-bot bypass capabilities. It automates tiered scraping methods to handle anti-bot protection, JavaScript rendering, and proxy rotation efficiently.

## Key Features
- Automated anti-bot bypass with tiered scraping (curl, HTTP, stealth, light JS, full browser)
- Structured data extraction using pre-built profiles (products, articles, job postings, etc.) or custom schemas
- Authenticated scraping via stored sessions or inline cookies for access to gated content
- Cost estimation tool to predict scraping expenses before execution
- Screenshot and PDF capture with full-page rendering and OCR support
