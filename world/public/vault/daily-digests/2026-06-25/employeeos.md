## Summary
EmployeeOS is an open-source 'Company Brain' that automates business analysis, planning, and reporting by hiring AI employees to monitor, learn, and generate actionable insights locally. It operates autonomously, providing hourly, daily, and weekly updates without manual intervention.

## Key Features
- Autonomous AI employees (Marketing, Sales, Support, Finance, HR) analyzing domains in parallel for problems and opportunities
- Local SQLite storage with optional cloud AI provider integration (Anthropic, OpenAI, Ollama, etc.)
- Hourly/daily/weekly automated reporting with health scoring and executive reviews
- Customizable skills system via Markdown files for domain-specific behaviors
- Multi-channel notifications (Telegram, Email) and web dashboard with real-time terminal

## Why It Matters for RAG Builders
It provides a self-hosted, autonomous system for continuous business analysis and planning, reducing manual oversight while leveraging AI for actionable insights.
