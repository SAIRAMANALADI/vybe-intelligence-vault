## Summary
Jarvis is a self-hosted, autonomous AI desktop agent for Linux that combines a web frontend with real desktop control via VNC, multi-LLM support, and WhatsApp integration. It automates tasks, manages knowledge bases, and enables multi-agent collaboration with enterprise-grade security.

## Key Features
- Real-time VNC split-view desktop control with live agent interaction
- Multi-LLM support with native and prompt-based tool calling
- Modular skill system compatible with OpenClaw ecosystem
- Enterprise-grade security with LDAP/AD, 2FA, and granular permissions
- Multi-user chat, WhatsApp delegation, and knowledge base with ChromaDB vector search

## Why It Matters for RAG Builders
Jarvis provides a comprehensive, self-hosted framework for building autonomous AI agents that can interact with desktop environments, manage knowledge bases, and integrate with external services, making it essential for RAG/AI stack builders seeking end-to-end automation capabilities.
