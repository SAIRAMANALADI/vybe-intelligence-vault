## Summary
orbiqd-briefkit is a local-first application designed to simplify coding workflows by enabling users to run multiple coding agents (e.g., Claude Code, Codex, Gemini) from a single interface without requiring API keys. It provides execution tracking, conversation resuming, and MCP server integration for seamless tool connectivity.

## Key Features
- Runs multiple coding agents (Claude Code, Codex, Gemini) locally without API keys
- MCP server integration for tool connectivity and extensibility
- Execution tracking and history for session management
- Resume conversations from previous sessions
- Cross-platform support (Windows, macOS, Linux)
