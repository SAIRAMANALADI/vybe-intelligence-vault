## Summary
A toolkit providing Alibaba Cloud agent plugins, skills, and MCP configurations to enable AI coding agents to build, deploy, and operate applications on Alibaba Cloud. It includes SDK interaction tools, infrastructure-as-code workflows, and telemetry for debugging and optimization.

## Key Features
- Provides MCP servers for Alibaba Cloud OpenAPI SDK code generation and infrastructure operations
- Enables spec-driven workflows for planning, Terraform codegen, validation, and execution via IaC Service
- Includes telemetry and tracing for debugging and performance optimization
- Supports multiple AI coding agents (Claude Code, Codex, QoderWork) with one-command installation
- Offers local and remote telemetry visualization tools for audit and troubleshooting

## Why It Matters for RAG Builders
It simplifies the integration of Alibaba Cloud services into AI agent workflows, enabling seamless infrastructure deployment and operation for RAG and AI applications.
