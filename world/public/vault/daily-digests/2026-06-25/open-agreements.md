## Summary
OpenAgreements is a toolkit for filling standard legal agreement templates and generating signable DOCX files. It provides 40+ templates across NDAs, cloud service agreements, employment docs, and financing documents, integrated with AI coding agents like Claude Code and Cursor via MCP or CLI workflows.

## Key Features
- 40+ pre-built legal templates (NDAs, SAFEs, employment agreements, etc.)
- MCP server for seamless integration with AI coding agents (Claude Code, Cursor, Gemini CLI)
- BM25-based search for template discovery and dynamic filling
- Supports DOCX output with validation and licensing context
- Multi-language support (English, Spanish, Chinese, Portuguese, German)

## Why It Matters for RAG Builders
