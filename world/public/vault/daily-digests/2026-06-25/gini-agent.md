## Summary
Gini Agent is a personal AI agent framework that serves as a centralized runtime for managing conversations, tasks, memory, skills, and tools. It provides a persistent state system, multi-provider support, and a unified API contract for various clients like web, CLI, and mobile apps.

## Key Features
- Centralized runtime managing conversations, tasks, approvals, memory, and tools
- Multi-provider support including OpenAI, Anthropic, AWS Bedrock, Azure, and local models
- Persistent memory with embeddings, reranking, and speech-to-text capabilities
- Parallel instances with isolated state, ports, and logs
- CLI, web, and mobile clients interacting with a unified API contract

## Why It Matters for RAG Builders
Gini Agent provides a robust, stateful runtime for AI agents that simplifies multi-provider integration and persistent memory management, essential for building advanced RAG systems.
