## Summary
Comfy Cozy is an AI-powered co-pilot for ComfyUI that enables users to interact with their workflows using plain English. It automates tasks like loading workflows, swapping models, tweaking parameters, running generations, and analyzing outputs while maintaining full reversibility and undo capabilities.

## Key Features
- Plain-English interaction with ComfyUI workflows without manual JSON editing
- 131 MCP tools across 5 LLM providers with seamless provider/model swapping
- Reversible delta layers (LIVRPS) enabling full undo stack for all changes
- Persistent learning from user interactions to bias toward successful workflows
- Native sidebar integration, standalone CLI, and MCP agent modes for flexible deployment

## Why It Matters for RAG Builders
It streamlines AI workflow automation by enabling natural language control over complex ComfyUI pipelines, reducing manual effort and accelerating iteration for RAG and generative AI applications.
