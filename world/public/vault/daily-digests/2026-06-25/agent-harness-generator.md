## Summary
A CLI tool that generates customizable AI agent harnesses for local or cloud-based deployment, enabling non-developers to build, train, and manage AI agents with built-in memory, learning loops, and sandboxed execution environments.

## Key Features
- Pre-built scaffolding for agent projects with customizable identities and folder structures
- Local memory systems with persistent storage for agent learning and recall
- Automated learning loops for self-improvement and performance tracking
- Sandboxed execution environment (RVM) to isolate agents from host system files
- Modular design supporting MCP server integrations and adjustable learning parameters

## Why It Matters for RAG Builders
It simplifies the creation of secure, self-learning AI agents with built-in memory and sandboxing, reducing development overhead for RAG and AI stack builders.
