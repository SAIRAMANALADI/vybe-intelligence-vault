## Summary
A full-stack AI agent toolbox for automated content creation and A/B testing, generating script variants, thumbnails, and statistically validating optimal combinations for platforms like YouTube.

## Key Features
- Generates 3 script variants optimized for retention using LLMs
- Automatically creates 3 thumbnail visuals via AI services
- Conducts A/B tests with 95% confidence intervals for CTR validation
- Supports hybrid local/cloud AI models (Ollama, Groq, Pollinations.ai)
- Production-ready with SQLite/PostgreSQL and Railway/AWS deployment options
