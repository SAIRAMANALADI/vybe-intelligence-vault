## Summary
pi-web provides an instant web UI for custom AI agents built with the pi SDK, enabling streaming chat interfaces with tool calls, attachments, and provider customization. It auto-loads agents from directories or git repos and serves them as web services with minimal setup.

## Key Features
- Dual-mode agent loading (custom SDK or general pi CLI) with unified RPC protocol
- Streaming chat UI with text, thinking, and tool call rendering via SSE
- Pluggable attachment system supporting image/file uploads and LLM vision integration
- Custom provider support for OpenAI-compatible gateways with dynamic model selection
- Layered, modular architecture with decoupled frontend/backend packages for easy embedding

## Why It Matters for RAG Builders
pi-web simplifies the deployment of interactive AI agents by providing a ready-to-use web interface with streaming capabilities, tool integration, and attachment handling, reducing development time for RAG builders.
