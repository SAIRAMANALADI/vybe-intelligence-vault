## Summary
Panguard AI is an open-source, on-device security platform for AI agents that scans skills against 650+ ATR rules, monitors runtime behavior, and provides a local dashboard for threat detection and management. It operates entirely offline with no telemetry by default.

## Key Features
- Pre-install skill scanning against 650+ ATR rules with SARIF export for CI integration
- Real-time runtime monitoring and blocking of malicious tool calls across multiple AI agent platforms
- Local dashboard for threat visualization, quarantine actions, and audit-ready evidence
- ATR standard compliance with Sigma/YARA rule migration tools for broader threat intelligence
- 100% free, MIT-licensed, and operates entirely offline with no telemetry by default

## Why It Matters for RAG Builders
It provides essential runtime and pre-install security for AI agents, ensuring malicious skills or behaviors are detected and blocked before causing harm, while maintaining strict privacy through on-device operation.
