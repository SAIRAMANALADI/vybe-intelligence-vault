## Summary
Conduit is a lightweight MCP server designed to bridge Unity Engine with AI coding agents, enabling seamless interaction without disrupting development workflows. It provides a minimal, robust interface for agents to query and manipulate Unity projects.

## Key Features
- Robust connectivity for AI agents, handling crashes, restarts, and multiple instances
- Context-efficient toolset to minimize token usage and context window strain
- Simple one-package installation with an editor configuration wizard
- Cross-editor support (Codex, Cursor, Claude Code, etc.) via stdio or HTTP transport
- Built-in tools for scene management, code execution, asset manipulation, and profiler access

## Why It Matters for RAG Builders
Conduit enables AI agents to safely and efficiently interact with Unity projects, streamlining game development workflows and reducing manual intervention.
