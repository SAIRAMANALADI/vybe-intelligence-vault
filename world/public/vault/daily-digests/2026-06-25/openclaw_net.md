## Summary
OpenClaw.NET is a NativeAOT-friendly AI agent runtime and gateway for .NET, enabling local or self-hosted agent systems with explicit diagnostics, tooling, and OpenAI-compatible interfaces. It supports governed agent workflows, passive governance ledgers, and integration with Microsoft Agent Framework and MCP.

## Key Features
- NativeAOT-friendly runtime for high-performance .NET agent workloads
- OpenAI-compatible HTTP surfaces and MCP integration for interoperability
- Passive governance ledgers and evidence bundles for auditable agent actions
- 75 native tools and 9 channel adapters (Telegram, Slack, Discord, etc.)
- Plan-Execute-Verify mode for high-risk tool execution with verification

## Why It Matters for RAG Builders
OpenClaw.NET provides a robust, self-hosted .NET-native framework for building governed AI agents with explicit diagnostics and tooling, critical for enterprise-grade RAG and agent systems.
