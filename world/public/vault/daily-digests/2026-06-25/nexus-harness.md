## Summary
Nexus Harness is a Go backend-focused engineering harness that transforms AI-generated code into a repeatable, verifiable, and resumable workflow. It integrates with AI coding tools like Claude Code and Cursor to enforce structured development processes, quality gates, and state recovery.

## Key Features
- Dual-agent independent review to prevent bias in code evaluation
- TDD-driven development with strict red-green-refactor gates
- Cross-session state persistence via workspace/context files
- AIWeave docs integration for bidirectional code-documentation contracts
- Six predefined workflow entry points for structured project progression
