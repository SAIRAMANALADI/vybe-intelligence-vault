## Summary
OrbiAds provides a hosted Model Context Protocol (MCP) server and Python CLI for integrating Google Ad Manager (GAM) with AI assistants like Claude, ChatGPT, and Gemini. It enables natural language interactions for ad operations, inventory management, forecasting, and reporting without manual API scripting.

## Key Features
- Hosted MCP endpoint for seamless AI assistant integration (Claude, ChatGPT, Gemini)
- Python CLI for terminal and CI/CD workflows with structured commands
- Comprehensive GAM API coverage for campaigns, inventory, creatives, and reporting
- Safety guardrails with plan-confirm-execute workflows to prevent unintended changes
- Multi-platform support including MCP registries (Glama, MCP.so) and direct agent plugins

## Why It Matters for RAG Builders
It bridges the gap between AI assistants and Google Ad Manager, enabling AI-driven ad operations with minimal setup and maximum safety.
