## Summary
A CLI and MCP server for Tuning Engines, enabling domain-specific fine-tuning of open-source LLMs (e.g., Qwen, Llama, DeepSeek) on code repositories and other data sources. It provides governed AI workflows, RBAC policies, and integration with orchestration frameworks like LangGraph and Temporal.

## Key Features
- Domain-specific fine-tuning of open-source LLMs (3B–72B parameters) using QLoRA and Axolotl
- Specialized agents (Cody for autocomplete, SIERA for bug-fix) with synthetic data generation
- CLI and MCP server for seamless integration with AI assistants (Claude, VS Code, Cursor)
- Governed AI runtime with RBAC, traffic policies, approval workflows, and usage tracking
- Unified OpenAI-compatible API for routing inference, model management, and orchestration

## Why It Matters for RAG Builders
It simplifies domain-specific fine-tuning and governed orchestration of LLMs, enabling RAG builders to deploy specialized, high-performance models with minimal infrastructure overhead.
