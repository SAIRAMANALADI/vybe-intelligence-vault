## Summary
Memory Crystal provides persistent memory infrastructure for AI agents, enabling long-term context retention across sessions. It captures conversations, extracts durable knowledge, and injects relevant context into AI responses automatically.

## Key Features
- Dual-layer memory system (STM for recent context, LTM for permanent knowledge)
- Knowledge graph for contextual relationships between memories
- 24+ MCP tools for memory operations (recall, remember, forget, search, etc.)
- Knowledge bases for immutable reference data and documentation
- Adaptive recall modes (General, Decision, Project, People, Workflow, Conversation)

## Why It Matters for RAG Builders
Memory Crystal eliminates the need for AI agents to relearn context between sessions, enabling true persistent memory and informed decision-making across long-running interactions.
