## Summary
Sipher is a REST API and OpenClaw-compatible skill that enables autonomous agents to perform private transactions across 17 blockchains. It provides stealth addresses, hidden amounts via Pedersen commitments, and compliance viewing keys to shield agent transactions from surveillance and MEV attacks.

## Key Features
- Generates stealth addresses for unlinkable transactions
- Hides transaction amounts using Pedersen commitments
- Supports 17 blockchains with client SDKs
- Provides compliance viewing keys for selective disclosure
- Offers REST API and OpenClaw skill integration for autonomous agents

## Why It Matters for RAG Builders
