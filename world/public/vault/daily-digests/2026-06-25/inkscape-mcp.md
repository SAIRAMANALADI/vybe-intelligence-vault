## Summary
A Model Context Protocol (MCP) server for Inkscape that enables AI agents to interact with Inkscape's CLI for vector graphics manipulation, analysis, and automation. Built on FastMCP 3.2.0+ and designed for agentic workflows.

## Key Features
- Provides portmanteau tools (inkscape_file, inkscape_vector, inkscape_analysis, inkscape_system) for agent-driven Inkscape operations
- Supports agentic workflows with structured tooling and sampling capabilities
- Industrial-grade quality stack with Ruff, Biome, and automated security audits
- Comprehensive documentation including installation, usage, and architecture guides
- Planned integration with other MCP servers (Blender, GIMP, Unity) for cross-platform workflows

## Why It Matters for RAG Builders
It enables AI agents to programmatically control Inkscape for vector graphics tasks, bridging the gap between AI-driven design and traditional vector editing workflows.
