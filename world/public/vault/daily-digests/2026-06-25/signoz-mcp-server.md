## Summary
A Model Context Protocol (MCP) server that enables AI assistants and LLMs to interact with SigNoz observability data, allowing natural language queries for metrics, traces, logs, alerts, dashboards, and services.

## Key Features
- Seamless integration with SigNoz for observability data access
- Supports natural language queries for metrics, traces, logs, and alerts
- Available as a hosted MCP server or self-hosted binary/Docker deployment
- Provides tools for listing, querying, and managing dashboards, alerts, and services
- Supports both HTTP and stdio transport modes for MCP clients

## Why It Matters for RAG Builders
It bridges AI assistants with SigNoz observability data, enabling developers to query and analyze system metrics, logs, and traces using natural language for faster debugging and insights.
