## Summary
A local-first AI agent runtime with a modern terminal UI, supporting pluggable LLM providers and JSON-based tool execution. It enables safe, approval-based file editing and multi-step tool use for local AI workflows.

## Key Features
- Pluggable LLM provider support (OpenAI and compatible APIs)
- Modern Textual-based terminal UI with model switching
- Approval-based file editing with diff review
- JSON-based tool execution for strict control
- Multi-step tool use with runtime state management

## Why It Matters for RAG Builders
It provides a modular, local-first framework for building AI agents with safe tool execution and approval workflows, critical for RAG systems requiring controlled file interactions.
