## Summary
A read-only Model Context Protocol (MCP) server providing structured access to public EverQuest Legends data sources, including the EQL Wiki, official news, YouTube videos, and press assets. It enables AI systems to fetch and query curated EverQuest Legends content without authentication or private API access.

## Key Features
- Read-only access to EverQuest Legends public sources (wiki, news, YouTube, press assets)
- Structured tools for searching, fetching, and extracting content (e.g., `eql_wiki_search`, `eql_official_news`)
- Optional `yt-dlp` integration for YouTube video captions with secure, verified downloads
- Era-aware content filtering for pre-Kunark launch data
- Zero authentication or private API dependencies
