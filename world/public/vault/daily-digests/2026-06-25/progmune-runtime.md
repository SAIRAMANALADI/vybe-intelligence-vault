## Summary
Progmune is a protocol runtime that enforces security constraints on AI-generated code by validating adherence to protocol state machines, preventing authentication bypasses, resource leaks, and lifecycle violations during code generation.

## Key Features
- Real-time protocol state machine validation for AI-generated code
- Detection of authentication bypasses, resource leaks, and lifecycle violations
- MCP-compatible tooling for integration with AI coding assistants
- Local static analysis for program truth extraction (IR)
- Audit trail with full state transition logging for compliance and debugging

## Why It Matters for RAG Builders
Progmune ensures AI-generated code adheres to critical security protocols, reducing vulnerabilities that traditional SAST tools miss by validating behavior rather than syntax.
