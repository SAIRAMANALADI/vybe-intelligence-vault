## Summary
A structured framework cataloging 28 AI agent design patterns across a 7×6 cognitive function × execution topology matrix, each with runnable code and verified production examples. Serves as a companion to the book 'Designing AI Agents' and an arXiv paper, providing a vocabulary for building scalable agent architectures.

## Key Features
- 28 runnable agent design patterns organized in a 7×6 matrix (cognitive function × execution topology)
- Verified engineering slices from 8+ production harnesses (Claude Code, Aider, OpenHands, etc.)
- Bilingual documentation (English/Chinese) with pattern-specific READMEs and examples
- Companion to the book 'Designing AI Agents' (Manning) and arXiv paper (2605.13850)
- Includes pattern selection methodology, composition guidelines, and real-world case studies

## Why It Matters for RAG Builders
Provides a structured vocabulary and coordinate system for selecting and composing agent design patterns, enabling scalable and maintainable AI agent architectures in production environments.
