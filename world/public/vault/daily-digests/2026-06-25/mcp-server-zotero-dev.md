## Summary
An MCP server that enables AI assistants to interact with Zotero for plugin development, testing, and debugging. It provides tools for UI inspection, JavaScript execution, build integration, and debugging via the Model Context Protocol.

## Key Features
- 28+ tools for UI inspection, DOM analysis, and screenshots
- JavaScript execution in Zotero's privileged context
- Integration with zotero-plugin-scaffold for hot reload and build tools
- Real-time log streaming and error console access
- Read-only SQLite database access for debugging
