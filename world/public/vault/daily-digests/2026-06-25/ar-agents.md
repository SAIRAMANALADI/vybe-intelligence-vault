## Summary
Open infrastructure for Argentina's AI-operated corporations (sociedades de IA), providing 36 npm packages and 235 typed tools for identity, payments, invoicing, banking, and government filings. Includes governance RFCs, forensic audit logs, and compliance tools for Argentine regulations.

## Key Features
- 36 npm packages with 235 typed tools for Argentine business operations
- Governance layer with 6 RFCs and forensic audit logs for sociedades de IA
- Deep Mercado Pago integration with 89 tools for payments, subscriptions, and webhooks
- Pluggable state adapters (Vercel KV, InMemory) with OpenTelemetry instrumentation
- Compliance tools for AFIP/ARCA, CUIT validation, and electronic invoicing
