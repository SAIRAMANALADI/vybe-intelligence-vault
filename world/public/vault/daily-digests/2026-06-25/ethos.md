## Summary
Ethos is a TypeScript-based AI agent framework that enables the creation of specialized agents with distinct identities and capabilities, rather than generic multi-purpose chatbots. It supports multi-channel interactions (CLI, Telegram, Discord, Slack, Email) and emphasizes personality-driven architecture for consistent behavior across platforms.

## Key Features
- Specialized agent personalities (engineer, researcher, reviewer, coach, operator) with distinct identities and capabilities
- Multi-channel support (CLI, Telegram, Discord, Slack, Email) with consistent behavior and memory across platforms
- Structured memory system (MEMORY.md, USER.md) for durable knowledge retention and team coordination
- Extensible plugin system for skills, tools, and providers with declarative contracts
- Production-ready deployment with PM2, log rotation, and security best practices

## Why It Matters for RAG Builders
Ethos enables AI engineers to build specialized, personality-driven agents that maintain consistent behavior and memory across multiple platforms, reducing the need for generic multi-purpose chatbots in RAG and AI workflows.
