## Summary
BAW (Black And White) is a 100% from-scratch AI agent platform featuring an adversarial Angel/Devil court system for debating every agent action before execution. It emphasizes zero vendor lock-in, self-evolution, multi-model fusion, and cost transparency, with built-in tools for Telegram bot integration and autonomous system management.

## Key Features
- Angel/Devil adversarial court system for pre-execution debate and validation of every agent action
- Self-evolution with 4-phase learning (behavior tracking, health monitoring, auto-fix, pattern optimization)
- Multi-model fusion with protocol-agnostic LLM support and per-task model routing
- Built-in Telegram bot integration with voice STT, auto-media delivery, and multi-platform support
- Cost transparency with token-level cost tracking and plan-based endpoint selection to avoid lock-in

## Why It Matters for RAG Builders
BAW provides a vendor-agnostic, adversarial framework for building robust, self-improving AI agents with built-in cost transparency and execution guardrails, reducing hallucinations and vendor dependency risks in RAG pipelines.
