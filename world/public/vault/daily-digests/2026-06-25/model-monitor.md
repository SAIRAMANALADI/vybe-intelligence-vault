## Summary
A comprehensive model API monitoring tool that tracks real-time traffic, costs, and performance across multiple LLM providers with advanced analytics, alerts, and visualization capabilities.

## Key Features
- Multi-protocol adapter for OpenAI, DeepSeek, OpenRouter, and MiMo APIs
- Real-time monitoring of API traffic, latency, and error rates with streaming support
- Cost tracking and forecasting with per-model and per-key granularity
- Threshold-based alerts via Webhook (Slack, Feishu, etc.) and optimization recommendations
- Dual-mode operation: HTTP proxy or mitmproxy sniffing with macOS native GUI integration

## Why It Matters for RAG Builders
Essential for AI engineers to monitor, optimize, and debug LLM API usage in production environments while controlling costs and ensuring reliability.
