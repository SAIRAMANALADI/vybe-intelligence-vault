## Summary
FolderMCP transforms any directory into a secure Model Context Protocol (MCP) server, automatically discovering and serving tools from Python, TypeScript, OpenAPI, shell scripts, and documents as MCP resources or tools without requiring SDK integration or boilerplate code.

## Key Features
- Automatic discovery and introspection of tools/resources from multiple formats (Python, TS/JS, OpenAPI, shell, documents, images)
- Secure-by-default execution with sandboxing, timeouts, and secret redaction
- NAS and shared drive compatibility with auto-detection and split storage
- Built-in review, approval, and audit logging for production-ready workflows
- One-command client integration (Claude, VS Code, Cursor) and deployment options (Docker, Cloud Run)

## Why It Matters for RAG Builders
FolderMCP eliminates the complexity of integrating diverse tools and documents into AI workflows by providing a secure, zero-config MCP server that works seamlessly with existing files and directories.
