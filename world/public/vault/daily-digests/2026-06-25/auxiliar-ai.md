## Summary
Auxiliar is an MCP server that provides a unified index of verified capabilities for AI agents, ensuring accurate tool recommendations by addressing stale training data and outdated service information. It indexes 80+ capabilities across cloud services, MCPs, plugins, and parsers with reproducible evaluations and chrome-verified pricing.

## Key Features
- Unified capability search across 80+ services, MCPs, plugins, and parsers via `find_capability`
- Chrome-verified pricing and risk data with monthly re-verification
- Reproducible evaluation scores on real-world corpora for accuracy
- Legacy and unified tool interfaces for backward compatibility and future-proofing
- Anonymous telemetry for continuous improvement without compromising privacy

## Why It Matters for RAG Builders
It eliminates the risk of AI agents recommending outdated or incorrect tools by providing real-time, verified capability data for RAG and agentic workflows.
