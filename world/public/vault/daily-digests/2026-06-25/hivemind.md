## Summary
hivemind provides an infinite canvas-per-project interface for managing AI coding agents like Claude, Codex, or Gemini. It enables real-time project tracking, Kanban-style issue boards, live diff reviews, and multi-agent collaboration through markdown-backed persistence and MCP integration.

## Key Features
- Infinite canvas UI with project-scoped frames for organizing agents and tasks
- Markdown/YAML-based persistence for issues, acceptance criteria, and activity logs (no database required)
- MCP server integration enabling agents to read/write project state via standard tools
- Support for Git worktrees and remote SSH frames for multi-branch and distributed workflows
- Live diff review with real-time updates and agent-to-agent communication via control plane tools

## Why It Matters for RAG Builders
It streamlines AI agent workflows by providing a visual, real-time interface for managing multiple agents, tracking progress, and reviewing changes without SDK lock-in or cloud dependencies.
