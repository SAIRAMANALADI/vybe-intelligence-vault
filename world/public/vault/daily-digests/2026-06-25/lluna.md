## Summary
LLuna is a desktop application designed to enable non-technical users to leverage autonomous AI agents for research while prioritizing security and integrity. It provides a user-friendly interface for interacting with local small language models (SLMs) and integrates with the Model Context Protocol (MCP) for consistent AI behavior.

## Key Features
- Integrity enforcement for secure AI research
- Support for local SLMs (4B to 8B parameters)
- Model Context Protocol (MCP) integration for consistent behavior
- User-friendly interface for non-technical users
- Cross-platform compatibility (Windows, macOS, Linux)
