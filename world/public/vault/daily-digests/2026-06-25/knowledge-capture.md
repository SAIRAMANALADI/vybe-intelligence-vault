## Summary
Automatically captures and organizes AI agent session logs (e.g., zcode, Claude Code) into an Obsidian vault as draft notes, then provides a visual kanban report for reviewing and promoting valuable insights into permanent knowledge base entries.

## Key Features
- Automatic capture of AI agent session logs into Obsidian drafts without manual input
- Visual kanban report for reviewing and organizing drafts before promotion to permanent notes
- Multi-tool support (zcode, Claude Code, Codex, etc.) via modular adapters
- Incremental deduplication to avoid reprocessing the same logs
- Safety mechanisms like atomic staging commits and write-allowlists to protect the knowledge base

## Why It Matters for RAG Builders
It bridges the gap between ephemeral AI agent interactions and persistent knowledge bases by automating the capture and organization of valuable insights, ensuring no hard-won knowledge is lost.
