## Summary
Symaira Vault is a secure, terminal-first password manager written in Go, using age encryption for robust security. It integrates with AI agents via an MCP server and supports features like TOTP, clipboard auto-clear, autotype, and multi-user vaults.

## Key Features
- Modern age encryption with X25519 and ChaCha20-Poly1305 for secure secret storage
- Built-in MCP server for AI agent integration with scoped token management
- Cross-platform support including autotype, clipboard auto-clear, and TOTP generation
- Git integration for automatic commits and sync, enabling versioned vaults
- Multi-user vaults via age recipients and secure secret execution with environment variable injection

## Why It Matters for RAG Builders
