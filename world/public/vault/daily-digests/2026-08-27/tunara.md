## Summary
Tunara is a lightweight, AI-native terminal for macOS that combines a real PTY with a smart sidebar for session management, agent detection, and a read-only Git diff review rail. It prioritizes speed, simplicity, and local-first workflows without telemetry or cloud dependencies.

## Key Features
- Real PTY terminal with xterm.js and WebGL rendering for smooth performance
- Smart sidebar grouping sessions by working directory with agent detection for 12 CLI tools
- Read-only Git diff review rail with syntax highlighting and external editor integration
- Lightweight (30 MB) with near-instant startup and no telemetry or cloud dependencies
- Session persistence, split panes, command palette, and macOS-native UI

## Why It Matters for RAG Builders
