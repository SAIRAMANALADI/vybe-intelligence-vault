## Summary
subspace-api is an Express-based RESTful API and stateless Model Context Protocol (MCP) server that provides integrated tools for real-time data retrieval, including weather, stock quotes, DC Metro schedules, flight tracking, and Discord activities. It supports OAuth 2.0 authentication and is designed for both self-hosting and use via hosted services.

## Key Features
- Stateless MCP server over HTTP with OAuth 2.0 bearer token security
- Integrated tools for weather, stock quotes, DC Metro schedules, and flight tracking
- Support for TRMNL plugins (e-ink display integration)
- Keycloak-compatible authentication for secure resource access
- Modular architecture with Docker and environment variable configuration

## Why It Matters for RAG Builders
It provides a secure, modular MCP server framework with pre-built tools for real-time data integration, reducing development time for RAG systems requiring live data sources.
