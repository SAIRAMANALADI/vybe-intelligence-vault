## Summary
A web-based skill editor companion for the Ryu AI agent framework that enables users to author, edit, and manage agent skills via a markdown-based interface with front-matter fields, autosave, and version history. It operates as a sandboxed UI component integrated into the Ryu desktop app or standalone via prebuilt binaries.

## Key Features
- Front-matter field management for skill metadata (name, description, tools, etc.)
- Markdown-based skill body editor with live preview
- Debounced autosave with server-backed undoable version history
- Sandboxed companion UI deployable as a single-file HTML bundle
- Cross-platform desktop app integration via Ryu's companion system

## Why It Matters for RAG Builders
It provides a user-friendly interface for creating and managing agent skills in markdown format, which is essential for customizing and extending AI agents in the Ryu framework.
