## Summary
SDL-MCP is a policy-centered context budget layer for coding agents that indexes repositories into symbol graphs, enabling compact, high-signal context retrieval. It supports controlled escalation from symbols to source code, reducing token usage and improving agent workflows.

## Key Features
- Symbol graph indexing for compact metadata and relationships
- Controlled context escalation via Iris Gate Ladder (cards, skeletons, hot paths)
- Live indexing and delta packs for tracking changes and blast radius
- Policy-driven governance for source window access and execution controls
- Multi-mode tool surface (flat, gateway, code mode) for client flexibility

## Why It Matters for RAG Builders
SDL-MCP enables AI coding agents to work with minimal, high-signal context by indexing repositories into symbol graphs, reducing token waste and improving precision in retrieval and execution.
