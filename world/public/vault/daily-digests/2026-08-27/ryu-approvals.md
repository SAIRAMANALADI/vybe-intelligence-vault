## Summary
ryu-approvals is a human-in-the-loop approval inbox for the Ryu AI agent framework, where agent-proposed actions, edits, and fixes await user approval or rejection before execution. It serves as a companion UI for managing a queue of pending tasks within the Ryu ecosystem.

## Key Features
- Approval queue for agent actions with accept/reject functionality
- Integration with Ryu's Core for handling approvals, quests, and notifications
- Prebuilt single-file companion UI for easy deployment
- Capability grants for `approvals:crud` and `quests:crud`
- Sandboxed environment with no direct backend dependencies

## Why It Matters for RAG Builders
It provides a critical human oversight layer for AI agent workflows, ensuring safe and controlled execution of agent-proposed changes in RAG and AI systems.
