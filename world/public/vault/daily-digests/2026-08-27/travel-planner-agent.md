## Summary
A Streamlit-based AI travel planner that generates structured day-trip itineraries for Korean cities using LLMs, geocoding, and interactive mapping. It parses LLM outputs into Pydantic schemas, enriches destinations with live data via Tavily and Kakao APIs, and visualizes routes on Folium maps.

## Key Features
- Structured LLM output parsing using Pydantic schemas for consistent itinerary data
- Interactive Folium maps with animated AntPath routes and geocoded markers
- Live enrichment of destinations with Tavily search and Kakao image APIs
- User-friendly Streamlit interface for region selection and itinerary customization
- Session state management for preserving user selections and generated plans
