## Summary
Zerolinear's Zeline is an open-source, agentic AI framework designed for building autonomous AI agents with flexible model, provider, and infrastructure integration. It supports multi-platform gateways (Telegram, WhatsApp, HTTP webhook) and provides tool profiles for controlled access.

## Key Features
- OpenAI-compatible agent loop with tool calling and multi-step workflows
- Support for multiple providers (OpenAI, OpenRouter, vLLM, Ollama) and OpenAI-compatible endpoints
- Persistent memory isolated by platform identity (Telegram, WhatsApp, webhook)
- Multi-platform gateways (Telegram, WhatsApp, HTTP webhook) with scoped tool profiles (safe, workspace, full)
- Interactive CLI, one-shot queries, and authenticated local webhook for integration

## Why It Matters for RAG Builders
