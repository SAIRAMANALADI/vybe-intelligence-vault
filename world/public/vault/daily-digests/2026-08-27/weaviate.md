## Summary
Weaviate is an open-source, AI-native vector database designed for semantic search and AI-powered applications. It stores data as vector embeddings alongside structured properties, enabling fast similarity search using HNSW or flat indexes, and supports automatic vectorization via configurable modules.

## Key Features
- Supports vector and scalar data storage with automatic vectorization via modules
- Fast similarity search using HNSW or flat indexes
- Multi-tenancy and enterprise features like authentication, authorization, and replication
- GraphQL and REST APIs for seamless integration
- Scalable deployment with Docker and Kubernetes support
