## Summary
ryu-workflows is a petgraph-based DAG automation toolkit for building multi-node workflows with triggers, durable execution, and a natural-language workflow builder. It provides a React Flow canvas for visual DAG editing and integrates with Ryu's core engine for orchestration.

## Key Features
- Petgraph-based DAG automation for building multi-node workflows
- Durable execution engine with fallback support
- Natural-language workflow builder for intuitive design
- React Flow canvas for visual DAG editing and CRUD operations
- Extensible trigger backends (schedule, webhook, Composio)

## Why It Matters for RAG Builders
It provides a robust, visual, and extensible framework for building and managing complex workflows essential for RAG pipelines and AI agent orchestration.
