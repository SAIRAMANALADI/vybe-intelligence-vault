## Summary
UTR_RAG is a documentation repository that organizes the communication protocol for Takaya's UTR-S201 series devices to facilitate AI-assisted implementation, review, and verification through pair programming. It provides structured guides, command references, and implementation guardrails for developers working with UHF RFID reader-writer devices.

## Key Features
- Structured documentation for UTR-S201 communication protocol with AI pair programming in mind
- Command master lists and response classification matrices for easy reference
- Implementation guardrails and context guides for USB/COM and LAN/TCP connections
- Verification status tracking for real-device command execution
- Release process and scope documentation to ensure proper usage
