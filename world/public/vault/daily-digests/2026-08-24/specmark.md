## Summary
Specmark is a spec-driven change management skill for AI agents that provides a seven-stage workflow (explore, clarify, propose, analyze, apply, converge, archive) to streamline software development changes through structured documentation and automated artifact generation.

## Key Features
- Seven-stage spec-driven workflow with optional linear progression and phase skipping for simple changes
- Automated generation of proposal, design, and tasks artifacts in a single step via the `propose` command
- Cross-product consistency checking with the `analyze` command to validate proposal, design, and tasks alignment
- Delta spec generation for long-term changes, ensuring traceability and requirement validation
- Mermaid.js flowcharts for visualizing workflows, execution chains, and collaboration links

## Why It Matters for RAG Builders
Specmark streamlines AI-driven software development by enforcing structured, spec-compliant change workflows, reducing ambiguity and improving traceability for RAG systems.
