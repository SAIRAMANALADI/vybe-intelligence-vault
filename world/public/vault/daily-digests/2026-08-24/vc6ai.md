## Summary
A minimalist AI agent framework written in C for legacy Windows systems (XP/2003) that interacts with LLMs via OpenRouter and executes commands through cmd.exe. It emphasizes simplicity with a single tool (command execution) and low resource usage.

## Key Features
- Runs on legacy Windows systems (XP/2003) with minimal dependencies
- Single tool: executes commands via cmd.exe
- Lightweight (~1100 lines of C) with no complex scaffolding
- Supports model switching and session management via slash commands
- Designed for low-resource environments with prompt caching support

## Why It Matters for RAG Builders
It demonstrates that modern LLMs can effectively use shell commands without custom tooling, reducing complexity and costs for AI agent deployments in constrained environments.
