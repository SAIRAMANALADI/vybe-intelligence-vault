## Summary
phantom-enterprise is an on-premises enterprise connector suite for the phantom-mesh ecosystem, enabling secure, privacy-first integration with LDAP/SSO, VPN-aware routing, and on-premises tools like GitLab/Gitea, Confluence/Jira, and MES/ERP systems. It ensures data never leaves the local environment while supporting Apple Silicon high availability (HA) deployments.

## Key Features
- Privacy-preserving enterprise data integration without cloud dependency
- VPN-aware routing for secure on-premises connectivity
- Pre-built connectors for GitLab/Gitea, Confluence/Jira, MES/ERP, and LDAP/SSO
- Deterministic synthetic Q&A and knowledge lookup scenarios for testing
- Apple Silicon HA support for local deployments
