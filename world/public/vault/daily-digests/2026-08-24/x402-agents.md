## Summary
Beacon is a search engine and discovery platform for open-source AI agents, indexing over 3,800 agents from frameworks like CrewAI, LangChain, and AutoGen. It ranks agents by GitHub traction (stars and activity) and provides tools for searching, verifying, and integrating agents into workflows.

## Key Features
- Indexes 3,800+ open-source AI agents across multiple frameworks
- Ranks agents by GitHub traction (stars + activity)
- Provides an MCP server for direct integration with AI assistants
- Offers a live portal for searching agents by capability
- Includes SDKs for auto-registering agents (CrewAI, LangChain, AutoGen)

## Why It Matters for RAG Builders
Beacon streamlines the discovery and verification of reusable AI agents, reducing manual effort for RAG builders and enabling faster integration of high-quality agents into AI systems.
