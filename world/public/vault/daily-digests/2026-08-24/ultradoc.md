## Summary
Ultradoc is a zero-dependency CLI and MCP server that enables ultra-precise, citation-backed answers about any open-source project by retrieving evidence directly from the project's source code, issues, PRs, docs, and the web. It ensures answers are grounded in retrieved snippets, not LLM memory, and verifies citations mechanically.

## Key Features
- Retrieves evidence from code, issues, PRs, docs, and the web for ultra-precise answers
- Mechanically verifies citations to ensure grounding and prevent hallucinations
- Supports deterministic (ripgrep + symbol index) and optional semantic (vector search) retrieval tiers
- Zero dependencies and keyless operation for offline/local use
- Provides MCP server integration for structured tool-based agent interactions

## Why It Matters for RAG Builders
