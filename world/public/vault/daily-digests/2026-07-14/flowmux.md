## Summary
FlowMux is a GTK4-based terminal application designed for AI agent workflows, offering a multiplexer interface with integrated browser control, desktop notifications for AI agents, and advanced pane management. It enables seamless interaction between AI agents and system resources like terminals and browsers.

## Key Features
- Integrated terminal and browser panes with keyboard navigation and split-screen support
- Direct browser control via WebKitGTK for AI agents to interact with web pages (snapshot, click, type, read state)
- AI agent lifecycle notifications (task complete, needs approval, errors) as desktop alerts with workspace routing
- Image and Markdown viewer with support for multiple formats (PNG, JPEG, WebP, GIF, SVG, Lottie, Markdown)
- Agent CLI and IPC socket for programmatic control and integration with tools like Claude Code, Codex, and OpenCode

## Why It Matters for RAG Builders
FlowMux streamlines AI agent workflows by providing a unified terminal and browser interface with programmatic control, essential for building and debugging RAG systems that require real-time interaction with both terminal and web environments.
