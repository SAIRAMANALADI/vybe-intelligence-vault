## Summary
A production-grade MCP server and CLI tool that provides AI agents with 50+ tools for reading, writing, diffing, redacting, healing, and cryptographically attesting Excel (.xlsx) files via a hosted API. It bridges the gap between spreadsheet complexity and LLM reliability by preserving engine complexity server-side while offering seamless integration with popular AI development environments.

## Key Features
- 50+ MCP tools for comprehensive .xlsx file operations (read, write, diff, redact, heal, and convert)
- Server-side formula evaluation with HyperFormula (~390 Excel functions) for accurate LLM reasoning
- Cryptographic attestation and verification (stamps and receipts) for data integrity and provenance tracking
- Healer tools for diagnosing and repairing broken external references, links, and Power Query connections
- Seamless integration with popular AI development environments (Claude Code, Cursor, Codex, Continue, Zed, Windsurf)
