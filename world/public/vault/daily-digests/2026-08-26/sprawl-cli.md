## Summary
Sprawl CLI is a local-first tool that provides filesystem sandboxing, universal IDE binding, and GitOps-based governance for AI coding agents. It ensures secure containment, telemetry-free operation, and centralized rule management for developer workstations.

## Key Features
- Filesystem sandboxing with directory-locked MCP servers to prevent path traversal
- Universal IDE binding for Cursor, VS Code, IntelliJ, Claude, and other agents
- GitOps-based rule synchronization with drift detection
- Stealth isolation ensuring agents operate under unmodifiable constraints
- Zero cloud dependency with 100% local execution and no telemetry
