## Summary
MCP server providing full-text search and metadata retrieval for Czech university theses from theses.cz, including PDF downloads and authenticated access to restricted content. It bridges the national thesis registry with individual university repositories.

## Key Features
- Full-text search over 1M+ Czech theses with advanced query operators (AND, OR, phrase)
- Metadata retrieval including abstracts, keywords, supervisors, and defense dates
- PDF and document download from university repositories with fallback mechanisms
- Authenticated access via session cookies for restricted theses
- Self-testing tool to validate parser selectors against known records

## Why It Matters for RAG Builders
It enables AI systems to access and process a large corpus of Czech academic theses for RAG applications, including metadata and full-text content.
