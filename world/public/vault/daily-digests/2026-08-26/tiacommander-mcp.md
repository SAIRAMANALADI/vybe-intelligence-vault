## Summary
TiaCommander is an MCP server that bridges Siemens TIA Portal with AI assistants via the Openness API, enabling AI-assisted PLC programming, project management, and real-time PLC data access. It supports multi-Portal environments and provides 18 tools with 205 actions for comprehensive Siemens PLC project lifecycle management.

## Key Features
- Real-time PLC data access (live data blocks, tag tables, CPU diagnostics)
- Multi-Portal support (V17–V20) with automatic version detection
- 18 tools and 205 actions covering full project lifecycle (programming, debugging, deployment)
- AI client integration (Claude, VS Code, Cursor, Windsurf, etc.) via MCP protocol
- Portable deployment with no installer or registry changes

## Why It Matters for RAG Builders
It enables AI assistants to directly interact with Siemens TIA Portal for automated PLC programming and diagnostics, significantly accelerating industrial automation workflows.
