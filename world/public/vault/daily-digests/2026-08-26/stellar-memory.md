## Summary
A persistent memory layer for Stellar and Soroban projects that scans repositories, links source code to on-chain contracts, and stores the results as a knowledge graph for both human and AI agent querying. It detects code-on-chain drift, storage durability issues, and provides deterministic insights for AI-driven development.

## Key Features
- Persistent memory layer for Soroban/Stellar projects that tracks code-on-chain drift by comparing Wasm hashes and deployed contracts.
- Automated knowledge graph generation linking contracts, storage keys, cross-contract calls, and on-chain state for AI agent querying.
- Detects critical Soroban-specific issues like storage TTL expiration, upgradeability, and authority requirements.
- MCP server integration for AI agents to query project context, storage layout, and contract interactions without file access.
- Deterministic Markdown-based vault for human-readable documentation and git diffing, with machine-generated and human-written sections.

## Why It Matters for RAG Builders
It provides essential on-chain context and deterministic insights for AI agents building or auditing Soroban contracts, eliminating guesswork in code analysis.
