## Summary
Yachiyo Claw is an open-source Android-first AI chat, on-device agent, and Live2D real-time interaction application. It combines multi-model conversations, device control via Agent, local model inference, and interactive 3D avatar experiences in a single mobile app.

## Key Features
- Android-native AI chat with multi-model support (cloud/local) and unified conversation history
- On-device Agent with device control (Root/Shizuku/Accessibility), Skills, and MCP integration
- Live2D real-time avatar interaction with voice input/output, camera integration, and emotion synchronization
- Local model inference via LiteRT-LM and llama.cpp with GPU/Vulkan acceleration and performance optimization
- Vibe Coding environment with PRoot-based Linux sandbox for Python/Node.js development and tool execution

## Why It Matters for RAG Builders
It provides a unified mobile platform for AI-driven agents, local LLM inference, and interactive 3D avatars, enabling seamless on-device AI experiences without relying solely on cloud services.
