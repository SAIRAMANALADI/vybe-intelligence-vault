## Summary
Shingou Skills provides MCP tools and a skill package to integrate the Shingou news-sentiment API into AI agents like Claude. It enables agents to fetch sentiment data, historical sentiment, events, and symbols via standardized MCP interfaces, with support for both remote and local deployments.

## Key Features
- MCP tools for direct API access (get_sentiment, get_sentiment_history, get_events, get_symbols)
- Pre-built skill package for Claude Code and claude.ai integration
- Packaged stdio server for local process deployment with zero dependencies
- Free tier support with 1,000 requests/day and 30/min burst quota
- Honest framing of sentiment data with age disclosure and reconstructed history buckets
