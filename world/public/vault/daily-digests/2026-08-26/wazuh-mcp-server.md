## Summary
A Model Context Protocol (MCP) server that enables natural language interaction with Wazuh SIEM for security operations, threat hunting, and compliance checks. It bridges LLMs with Wazuh's API to query alerts, run active responses, and generate security reports in real-time.

## Key Features
- 55+ pre-built security tools for Wazuh (alerts, agents, vulnerabilities, active response, compliance checks)
- Dual-era MCP protocol support (2026-07-28 + legacy) for compatibility with modern and traditional clients
- Enterprise-grade security with RBAC, audit logging, input validation, and rate limiting
- Supports both cloud and fully air-gapped local LLMs (Ollama, Open WebUI) for data sovereignty
- Production-hardened with multi-cluster support, fail-closed RBAC, and container security

## Why It Matters for RAG Builders
It enables AI-driven security operations by allowing LLMs to interact with Wazuh SIEM in natural language, accelerating threat detection, incident response, and compliance workflows while maintaining enterprise-grade security and flexibility.
