## Summary
The RoxyAPI .NET SDK provides a fully typed client library for accessing astrology, Vedic astrology, numerology, tarot, and other esoteric APIs through a single unified interface. It simplifies integration with RoxyAPI's multi-domain services for AI agents, apps, and backend systems.

## Key Features
- Unified SDK for 12+ esoteric domains (astrology, tarot, numerology, etc.) behind a single API key
- Fully typed C# client with auto-generated models from OpenAPI spec
- Supports .NET 8+, .NET Framework 4.6.1+, Unity, and Mono
- Geocoding and timezone handling for accurate chart calculations
- Verified against NASA JPL Horizons for astronomical accuracy
