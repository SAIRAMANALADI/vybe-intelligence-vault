## Summary
Templiqx is an AI-native template engine written in Rust that enables teams to define reusable, type-safe AI interactions via YAML contracts. It compiles these contracts into validated model requests, checks outputs against schemas, and generates fingerprints for testing and tracing.

## Key Features
- Typed YAML contracts for AI interactions with input/output schemas
- Validation of inputs, references, and outputs against explicit schemas
- Deterministic execution with fingerprints for testing and tracing
- Provider-neutral compilation to model requests without vendor lock-in
- Reusable packages for cross-product AI behavior portability

## Why It Matters for RAG Builders
Templiqx enables AI engineering teams to standardize and reuse AI interactions across products while ensuring type safety, validation, and traceability, reducing errors and improving maintainability in RAG pipelines.
