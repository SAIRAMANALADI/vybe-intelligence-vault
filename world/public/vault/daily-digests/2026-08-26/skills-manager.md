## Summary
A Windows-first PowerShell-based manager for aggregating, curating, and synchronizing AI agent skills from multiple sources into unified workspaces for Claude, Codex, Gemini, and Trae. It consolidates skills, MCP servers, and rules while enforcing deterministic outputs and policy-driven governance.

## Key Features
- Unified workspace for skills aggregation from multiple upstream sources (vendors, imports, overrides)
- Deterministic build and sync pipeline with atomic writes and rollback support
- MCP server management and synchronization across local AI CLI tools (Claude, Codex, Gemini, Trae)
- Rule-based governance for skills and capabilities with advisory-first enforcement
- Portable package generation for new-machine migrations and reproducible deployments

## Why It Matters for RAG Builders
It streamlines the management of AI agent skills and MCP servers across multiple local AI tools, reducing manual configuration overhead and ensuring consistency in multi-agent environments.
