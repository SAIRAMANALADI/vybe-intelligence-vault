## Summary
Supraconscious Avatar AI is a full-stack SaaS platform for guided self-inquiry and reflection, combining a Next.js web app, Flutter mobile client, Express-based MCP server, and PostgreSQL backend. It features policy-first RAG, admin-curated GraphRAG foundations, prompt governance, and LangSmith-ready observability for structured journaling and behavioral insights.

## Key Features
- Policy-first RAG with admin-curated source governance and provenance tracking
- Admin-controlled GraphRAG foundations for structured reasoning and ontology review
- LangSmith-ready observability with metadata-only tracing for privacy compliance
- Modular architecture with separate web, admin, MCP, and mobile clients
- Feature-flagged GraphRAG runtime and MCP tool integration for external AI clients

## Why It Matters for RAG Builders
It provides a robust, governance-first RAG and GraphRAG framework for AI-driven journaling and self-inquiry platforms, ensuring traceability, privacy, and admin-controlled content curation.
