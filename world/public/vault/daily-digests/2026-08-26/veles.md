## Summary
Veles is a minimal CLI agent framework designed to maintain compounding project memory across sessions, enabling AI agents to become more useful over time by accumulating insights, rules, and curated knowledge. It supports pluggable content layouts, provider-agnostic routing, and modular extensions like skills and modules.

## Key Features
- Compounding memory system that accumulates insights and rules across sessions for persistent project context
- Pluggable content layouts (Karpathy-style wiki, flat notes, bare) with customizable structures via TOML
- Provider-agnostic routing supporting OpenRouter, Anthropic, OpenAI, Gemini, Ollama, llamacpp, and CLI-based providers
- Skills and modules system for reusable prompt-blocks and extensible functionality with deduplication
- Local-first, sandboxed architecture with no telemetry or cloud sync, featuring trust ladder prompts for sensitive operations

## Why It Matters for RAG Builders
Veles enables RAG builders to create agents that retain and leverage long-term project-specific knowledge, reducing context re-explanation and improving decision-making over time.
