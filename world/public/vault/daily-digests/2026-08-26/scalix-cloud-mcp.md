## Summary
The Scalix Cloud MCP Server is an official Model Context Protocol (MCP) server for Scalix World, an AI-native neocloud platform. It enables agents to operate the entire platform remotely via a single API key, providing access to 55 tools across 18 domains including databases, compute, storage, AI inference, and billing.

## Key Features
- Single API key access to 55 tools across 18 domains (databases, compute, storage, AI, billing, etc.)
- Provision and manage Postgres-compatible databases with scale-to-zero and branching for migrations
- Deploy container services and serverless functions in isolated microVMs
- Built-in guardrails for consequential actions requiring human approval
- Integrated observability, metrics, and spend controls for cost-aware agent decisions

## Why It Matters for RAG Builders
It enables AI agents to autonomously manage and orchestrate full-stack cloud infrastructure, reducing manual intervention and accelerating AI-native application deployment.
