## Summary
The Button Heist is a Swift-based framework that enables programmatic control of iOS apps through the accessibility interface, allowing both humans and AI agents to interact with apps using semantic actions like activation, text input, and verification. It provides a unified language for automation, testing, and agent-driven interactions.

## Key Features
- Programmatic iOS app control via accessibility contracts, enabling semantic actions like activation and text input
- Unified language for automation, testing, and AI agents through MCP and CLI tools
- Receipt-based evidence system for durable, auditable outcomes of interactions
- Support for both synchronous and asynchronous test execution with receipt recording
- Live session debugging and interaction via TCP/IP server for real-time agent or human probing

## Why It Matters for RAG Builders
It provides a standardized, semantic way to interact with iOS apps programmatically, bridging the gap between human testing, automated testing, and AI-driven agents while ensuring verifiable outcomes through receipts.
