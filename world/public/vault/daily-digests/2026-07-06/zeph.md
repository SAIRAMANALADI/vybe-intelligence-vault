## Summary
Zeph is a memory-first AI agent framework designed for long-running tasks, enabling persistent context retention across sessions. It supports local, cloud, and decentralized model providers while emphasizing safety, efficiency, and adaptive routing.

## Key Features
- Persistent memory across sessions with semantic and graph-based recall
- Adaptive multi-model routing for cost and performance optimization
- Self-learning skills with failure-driven evolution and trust-based isolation
- Sandboxed tool execution and encrypted secrets management
- Support for local, cloud, and decentralized (TEE) model providers
