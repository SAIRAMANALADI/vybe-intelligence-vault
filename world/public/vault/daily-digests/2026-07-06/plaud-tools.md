## Summary
Plaud-tools is a Python CLI and MCP server that integrates Plaud recordings with AI assistants like Claude, enabling natural language querying, transcription, summarization, and management of meeting recordings directly within an AI workflow.

## Key Features
- Natural language querying of Plaud recordings via AI assistants
- Automated transcription and summarization of audio files
- Cross-platform installation (Windows, macOS, Linux) with auto-updates
- CLI and MCP server for seamless AI assistant integration
- Folder and recording management (rename, move, trash, merge)

## Why It Matters for RAG Builders
It bridges Plaud recordings with AI assistants, enabling RAG systems to dynamically query and process meeting data for enhanced context-aware responses.
