## Summary
ForgeCat Agent Profiles is an open catalog of cross-platform agent profiles designed to standardize and simplify the discovery, installation, and reuse of agent workflows across coding tools like Claude Code, Cursor, and Codex. It curates and packages profiles from various sources into installable, platform-aware packages.

## Key Features
- Centralized catalog of 183+ agent profiles sourced from public repositories and curated for quality
- Cross-platform compatibility with installable profiles for Claude Code, Cursor, and Codex
- Source-faithful packaging with attribution, license metadata, and upstream behavior preserved
- CLI tool (`forgecat`) for searching, installing, and managing profiles
- Reviewable platform evidence with tested platforms marked after real install/runtime checks

## Why It Matters for RAG Builders
It streamlines the reuse of vetted agent workflows across multiple coding tools, reducing setup time and ensuring consistency for RAG and AI stack builders.
