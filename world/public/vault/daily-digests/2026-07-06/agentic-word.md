## Summary
A native desktop document editor combining AI-driven writing assistance, git-like version control, real-time collaboration, and a plugin ecosystem. Designed for writers and developers needing intelligent document composition with full revision history and extensibility.

## Key Features
- AI-powered writing with inline suggestions and multi-agent support (Writer, Reviewer, Researcher)
- Git-like version control with branches, merges, conflict detection, and DAG graph visualization
- Real-time collaboration via Yjs CRDT over WebSocket with shared cursors and presence awareness
- Extensible plugin system with sandboxed runtime, lifecycle hooks, and built-in marketplace
- Multi-format document export/import (DOCX, HTML, Markdown, PDF, EPUB) with formatting preservation
