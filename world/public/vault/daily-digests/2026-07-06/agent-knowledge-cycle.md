## Summary
Agent Knowledge Cycle (AKC) is a six-phase framework for persistent AI agents that converts repeated agent experiences into reusable knowledge (skills, rules, and documentation) under human oversight. It ensures agent behavior remains aligned with evolving operator intent while optimizing human attention as the scarce resource.

## Key Features
- Six-phase cycle (Research, Extract, Curate, Promote, Measure, Maintain) for persistent agent knowledge growth
- Structured human approval gates to prevent harness drift and maintain intent alignment
- Dependency-free reference implementation in Python for minimal setup
- Comprehensive ADR (Architecture Decision Record) documentation for transparency and extensibility
- Modular design allowing incremental adoption and scaffold dissolution over time

## Why It Matters for RAG Builders
AKC provides a systematic approach to manage agent knowledge growth and intent alignment, addressing the critical challenge of harness drift in long-running AI systems.
