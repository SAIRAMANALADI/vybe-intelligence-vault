## Summary
Reqly is an API testing toolkit designed for AI agents, enabling zero-human-pipeline workflows from codebase analysis to CI deployment. It provides MCP server, CLI, and web UI interfaces for building, running, and exporting API collections and flows as plain YAML files.

## Key Features
- MCP server for seamless AI agent integration with 30+ tools for API testing and automation
- Plain YAML collections stored in `.reqly/` for git-native, human-readable API definitions
- Zero-human-pipeline workflow: agents read code, build collections, write flows, and export CI configurations automatically
- Auto-capture of inbound/outbound traffic and webhooks for effortless collection generation
- Local-first architecture with no cloud dependency, ensuring privacy and offline functionality

## Why It Matters for RAG Builders
Reqly enables AI agents to autonomously build, test, and deploy API workflows, eliminating manual effort and accelerating CI/CD integration for RAG and AI stack builders.
