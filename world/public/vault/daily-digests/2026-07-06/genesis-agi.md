## Summary
GENesis-AGI is a personal AGI system designed to autonomously learn, remember, and act without constant user input. It integrates Claude Code as its reasoning engine and provides a full cognitive architecture with memory, self-learning, and earned autonomy features.

## Key Features
- Autonomous cognitive cycle with dual-ego architecture for decision-making and action execution
- 4-layer memory system (essential knowledge, proactive recall, deep search, knowledge pipeline) with hybrid retrieval
- Earned autonomy system that grants and revokes trust based on demonstrated competence
- 60+ built-in tools for browser automation, outreach, research, and infrastructure monitoring
- Closed-loop learning with outcome classification, causal attribution, and procedure extraction
