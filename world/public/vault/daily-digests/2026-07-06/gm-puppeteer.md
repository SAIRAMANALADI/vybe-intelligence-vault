## Summary
GM-Puppeteer is an MCP server that enables AI assistants to fully control Foundry Virtual Tabletop (VTT) v14 as a Game Master, automating tasks like encounter building, token management, and journal updates without requiring additional modules. It supports both local and Forge-hosted worlds and integrates with Pathfinder 2e and D&D 5e systems.

## Key Features
- Full GM control over Foundry VTT via MCP with no additional modules required
- System-agnostic core tools plus specialized suites for Pathfinder 2e and D&D 5e
- Automated encounter building, token management, and journal updates
- Supports both local LAN and Forge-hosted Foundry worlds
- Headless or visible Chromium browser integration for reliable UI interaction

## Why It Matters for RAG Builders
