## Summary
A cross-platform CLI skill for Obsidian that transforms a static vault into a self-maintaining, AI-first second brain across six platforms (Claude Code, Codex, Gemini, OpenCode, Hermes, and Pi). It rewrites existing notes instead of appending, resolves contradictions automatically, and runs scheduled agents to synthesize patterns and maintain vault health.

## Key Features
- 44+ commands for research, synthesis, and vault maintenance
- Self-rewriting notes that update existing pages instead of appending new ones
- Automatic contradiction resolution via scheduled agents
- Hybrid semantic search (local + hybrid) for improved retrieval
- Cross-platform support (Claude Code, Codex, Gemini, OpenCode, Hermes, Pi)

## Why It Matters for RAG Builders
It enables RAG builders to create a dynamic, self-updating knowledge base that evolves with new information while maintaining consistency and reducing manual curation overhead.
