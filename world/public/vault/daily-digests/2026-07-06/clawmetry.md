## Summary
ClawMetry is a real-time observability and monitoring tool for AI agent runtimes, providing a unified dashboard to track, visualize, and manage agent workflows, token usage, costs, and security across 12+ agent frameworks and SDKs.

## Key Features
- Unified dashboard for 12+ AI agent runtimes with auto-detection and runtime switching
- Real-time flow visualization of agent messages, tools, and brain activity
- Token and cost tracking with breakdowns by model, session, and source
- Security features including approvals for risky actions and alerting for budget caps
- OpenTelemetry integration for vendor-neutral trace export to external systems

## Why It Matters for RAG Builders
ClawMetry provides essential observability and cost tracking for AI agent deployments, enabling developers to monitor, debug, and optimize agent workflows in real-time while ensuring security and compliance.
