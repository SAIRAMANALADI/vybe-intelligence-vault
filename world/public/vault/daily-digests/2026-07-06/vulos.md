## Summary
Vulos is a self-hostable, web-native operating system that runs on local hardware or cloud servers, offering a full desktop experience via a React-based shell. It combines a window manager, bundled apps, AI-powered features, and secure peer-to-peer sync in a single Go binary with an embedded frontend.

## Key Features
- React-based window manager with virtual desktops and a dock, running in any browser
- On-demand streaming of native Linux GUI apps via WebRTC with GPU acceleration
- Built-in AI router (`airouter`) with local vector store for retrieval and LLM brokering
- Passwordless authentication using WebAuthn/FIDO2 passkeys and QR/phone approval
- Leaderless CRDT-based sync and encrypted local-first storage with SQLite and S3/Restic backup

## Why It Matters for RAG Builders
Vulos provides a unified platform for deploying and managing AI-powered desktop environments with built-in retrieval, streaming, and secure sync, making it essential for building scalable, self-hosted AI stacks.
