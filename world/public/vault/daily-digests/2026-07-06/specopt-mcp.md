## Summary
specopt-mcp is a DSPy-powered optimization framework that exposes 9 MCP tools for prompt and code optimization via the Model Context Protocol. It supports both an MCP server for direct tool invocation and a LangChain agent for dynamic skill discovery and autonomous tool selection.

## Key Features
- 9 MCP tools for prompt/code optimization, dataset generation, and validation
- Dual-mode operation: MCP server and LangChain agent with dynamic skill discovery
- Pluggable skill architecture with support for LM Studio, Ollama, and Lemonade
- Multi-stage evaluation pipeline with LLM-as-judge curation and deterministic checks
- Synthetic dataset generation, blind QA verification, and artifact cleanup utilities

## Why It Matters for RAG Builders
It provides essential tools for automating and optimizing prompts and code, reducing manual tuning effort and improving AI agent performance in RAG systems.
