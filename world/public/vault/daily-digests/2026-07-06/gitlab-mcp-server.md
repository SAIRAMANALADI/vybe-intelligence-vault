## Summary
A Model Context Protocol (MCP) server that enables AI assistants to interact with GitLab in plain language, providing 1000+ tools over the full GitLab REST and GraphQL APIs for tasks like merge request reviews, pipeline management, and issue tracking.

## Key Features
- 1000+ GitLab tools exposed via MCP for AI assistants to perform actions like merge requests, pipelines, and issue management
- Dynamic tool surface with low token footprint (2 tools by default) while supporting full GitLab API coverage
- Multi-client support (Claude, VS Code, Cursor, LM Studio, Kiro) with one-click install and guided setup
- Safe by design with read-only mode, dry-run preview, and TLS options for self-hosted GitLab
- Proven reliability with 99.5% success rate across thousands of operations in automated evaluations

## Why It Matters for RAG Builders
It bridges AI assistants with GitLab, enabling seamless automation of DevOps workflows through natural language, reducing manual API interactions for RAG and AI stack builders.
