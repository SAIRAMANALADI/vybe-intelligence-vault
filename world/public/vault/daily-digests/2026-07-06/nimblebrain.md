## Summary
NimbleBrain is a self-hosted platform for MCP (Model Context Protocol) apps and agent automations, providing an interactive UI, scheduled agent runs, and multi-agent delegation. It aggregates tools from connected MCP servers into a unified namespace and exposes them via a Streamable HTTP MCP server endpoint.

## Key Features
- Unified tool registry aggregating tools from multiple MCP servers into a single namespace
- Interactive UI with live agent-UI data sync and scheduled agent runs
- Multi-agent delegation with skill-driven prompt composition
- Streamable HTTP MCP server endpoint for external client consumption
- Workspace isolation with per-workspace configuration and bundle management

## Why It Matters for RAG Builders
NimbleBrain simplifies the integration of MCP-based tools and agents into RAG systems by providing a unified, self-hosted platform with built-in orchestration, scheduling, and multi-agent capabilities.
