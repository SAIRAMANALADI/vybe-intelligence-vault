## Summary
Akana is a self-hosted AI assistant server that runs locally with user-chosen models, offering encrypted memory, credential vaults, and swappable LLM providers. It includes review-gated persistent memory, wake-word voice control, and capability packs for browser/desktop automation.

## Key Features
- Swappable LLM providers (Claude, Cursor, Gemini, OpenAI, Ollama) with unified UI
- Review-gated persistent memory with staging inbox for user approval
- Encrypted credential vault with audit logging for secrets
- Wake-word voice control with custom-trained model and local/offline options
- Capability packs for browser and desktop automation via Playwright

## Why It Matters for RAG Builders
Akana provides a privacy-focused, self-hosted agent framework with review-gated memory and encrypted credentials, enabling secure and customizable AI assistants without cloud dependency.
