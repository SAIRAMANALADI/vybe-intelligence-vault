## Summary
ASKII is a VS Code extension that integrates AI-powered code assistance with playful elements like kaomoji and humorous comments, supporting multiple AI providers for inline code explanations, edits, and agentic tasks like file management and browser automation.

## Key Features
- Multi-platform AI provider support (Ollama, Copilot, LM Studio, OpenAI, Anthropic, opencode Go, ASKII Cloud)
- Inline code explanations with humorous or helpful kaomoji comments
- Agentic workspace tools (Do, Edit, Control, Browse) for file management and browser automation
- Wiki RAG for indexing and injecting documentation or codebase context into AI responses
- Code auto-completion with Copilot-style ghost text and commit message generation

## Why It Matters for RAG Builders
It bridges playful AI assistance with practical RAG workflows, enabling developers to integrate contextual AI support directly into their coding environment with minimal setup.
