## Summary
GigaCode is a GPU-accelerated tool for embedding codebases, enabling semantic search, code navigation, quality analysis, and safe editing for AI agents. It provides 67 agent-discoverable capabilities across 8 categories, optimized for integration into AI agent workflows.

## Key Features
- GPU-accelerated code embedding and search with sub-millisecond latency
- Safe read-write-commit workflow for code editing without direct disk writes
- 67 agent-discoverable tools across 8 categories (analysis, editing, security, etc.)
- Support for OpenAI, Anthropic, MCP, and Ollama tool schema exports
- AST-based chunking for precise codebase indexing and navigation
