## Summary
A desktop application that converts text prompts into professional-grade images such as logos, app icons, favicons, and social media previews using AI image generation models. It simplifies the design process for users without technical or artistic expertise.

## Key Features
- Converts text prompts into multiple asset types (logos, icons, favicons, etc.)
- Supports 30+ AI image generation models for optimal output
- Validates generated images for errors before saving
- Integrates with development tools like Cursor and Claude Code
- Offers adjustable dimensions and settings for customization
