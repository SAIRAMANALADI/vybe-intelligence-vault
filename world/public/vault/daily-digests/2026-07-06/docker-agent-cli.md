## Summary
Docker Agent CLI is an LLM-powered command-line interface that enables natural-language orchestration of Docker infrastructure using the ReAct pattern and MCP plugins. It replaces manual Docker Compose configuration with conversational infrastructure management.

## Key Features
- Natural-language Docker infrastructure management via LLM agent
- ReAct pattern for planning and execution with approval workflows
- Modular MCP plugin architecture for extensible infrastructure support
- Two-phase mutation contract (propose, approve, commit, rollback)
- Interactive REPL with slash commands and keyboard shortcuts

## Why It Matters for RAG Builders
It simplifies Docker infrastructure management by enabling natural-language orchestration, reducing the need for manual YAML configuration and streamlining AI-driven infrastructure deployment.
