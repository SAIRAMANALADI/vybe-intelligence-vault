## Summary
AgentFlow is a self-hosted, protocol-agnostic orchestrator that bridges AI coding agents (Claude, Codex, Copilot, Gemini) with external tools, APIs, and human workflows via a unified, event-driven architecture. It acts as a central nervous system for AI workforce collaboration.

## Key Features
- Multi-protocol routing for AI agents and messaging platforms (Telegram, Discord, Slack, SMS)
- Session awareness and context preservation across platforms
- Pluggable adapters for extensibility (10-line Python files for new integrations)
- Human-in-the-loop gates for approval on destructive operations
- Event sourcing for auditing, debugging, and replaying agent interactions

## Why It Matters for RAG Builders
AgentFlow provides a critical orchestration layer for RAG/AI stacks by unifying multi-agent workflows, enabling seamless collaboration between agents, tools, and human oversight in a secure, event-driven architecture.
