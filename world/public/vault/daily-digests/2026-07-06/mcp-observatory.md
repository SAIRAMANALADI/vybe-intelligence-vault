## Summary
MCP Observatory is a tool for validating and auditing Model Context Protocol (MCP) servers to assess their security, reliability, and trustworthiness before deployment in sensitive or mission-critical AI environments. It generates portable trust receipts, risk graphs, and SARIF evidence for CI/CD pipelines.

## Key Features
- Portable MCP trust receipts for reproducible evidence
- Risk graph mapping for agent toolchain validation
- GitHub Code Scanning SARIF output for security gates
- NSA-MCP profile for sensitive environment controls
- One-command CI setup with `setup-ci --all`

## Why It Matters for RAG Builders
It provides critical validation and security auditing for MCP servers, ensuring safe deployment in AI systems where agent dependencies must be rigorously tested.
