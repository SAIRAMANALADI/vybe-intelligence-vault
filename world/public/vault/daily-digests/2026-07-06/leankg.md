## Summary
LeanKG is a lightweight tool that builds a local knowledge graph from codebases to provide precise context for AI coding assistants, reducing token waste and improving response accuracy. It scans project structures, identifies relevant snippets, and stores them in a local graph for efficient AI interactions.

## Key Features
- Intelligent project mapping to identify relevant code snippets
- Local knowledge graph storage for privacy and efficiency
- Token optimization by reducing unnecessary data transmission
- Multi-tool support for various AI assistants (Claude, Gemini, etc.)
- One-time scan with incremental updates for project changes

## Why It Matters for RAG Builders
LeanKG directly addresses the token waste and inefficiency in AI coding workflows by providing focused, relevant context, making it essential for cost-conscious and performance-driven RAG builders.
