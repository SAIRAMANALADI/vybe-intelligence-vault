## Summary
A Tauri-powered terminal aggregator with multi-workspace support and built-in AI agent integration, enabling users to manage multiple project terminals, AI agents (Claude Code, Codex), file browsers, and Git tools in a single cross-platform desktop app.

## Key Features
- Multi-workspace terminal management with drag-and-drop reordering and detachable windows
- Built-in AI agents (Claude Code and Codex) with configurable permission modes and session management
- Integrated file browser, Git viewer, snippet manager, and markdown preview with live updates
- Semantic code navigation via cx integration to optimize AI agent context usage
- Cross-platform support (Windows, macOS, Linux) with mobile app compatibility

## Why It Matters for RAG Builders
It provides a unified interface for managing AI agents and terminals, streamlining development workflows by integrating essential tools into a single desktop application.
