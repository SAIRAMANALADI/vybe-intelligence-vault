## Summary
A fully-functional blackjack game demonstrating SignalWire AI Agents with integrated web serving, real-time WebRTC video calling, and event-driven architecture. The project showcases a single-service architecture where the AI agent handles both API and web client interactions while managing complex stateless game logic.

## Key Features
- Single-process architecture serving both API and web client
- Real-time WebRTC video calling integration for immersive gameplay
- Structured step-based conversation flow for game mechanics
- Stateless game state management with centralized logic
- Production-ready security features (SSL, basic auth, rate limiting)
