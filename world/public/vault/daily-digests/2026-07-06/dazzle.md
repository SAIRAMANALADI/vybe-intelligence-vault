## Summary
Dazzle is a declarative framework for building SaaS applications designed for AI-collaborative development. It models business logic in structured DSL files, enabling direct execution without code generation, and provides compliance, RBAC, and audit capabilities optimized for regulated environments.

## Key Features
- Declarative DSL for modeling business logic as the single source of truth
- No code generation; runtime executes DSL directly for zero drift
- Built-in compliance evidence generation (SOC 2, ISO 27001)
- Provable RBAC with SMT solver-backed policy validation
- Anti-Turing design with static inspection and linting

## Why It Matters for RAG Builders
Dazzle provides a structured, AI-friendly substrate for building auditable and compliant SaaS applications, reducing drift and enabling safer LLM-driven development.
