## Summary
t2000 is an open-source agentic stack for stablecoins on the Sui blockchain, enabling AI agents to hold wallets, execute payments, manage identities, and orchestrate financial flows. It provides a suite of tools including Agent Wallet, Agent Payments, Agent ID, Agent Commerce, and Agent SDK for seamless integration into AI workflows.

## Key Features
- Agent Wallet for gasless USDC/USDsui transactions and API payments via x402 protocol
- Agent ID for on-chain agent identity and reputation management
- Agent Commerce for selling AI agent services with escrow and auto-refunds
- Agent SDK providing a unified TypeScript interface for wallet, payments, and swaps
- Non-custodial design with spending limits, transaction simulation, and gasless operations
