## Summary
Aloha is an AI agent designed to interact with and manage Home Assistant through natural language. It provides 76 tools for entity control, automation management, and configuration editing, along with a curated library of skills and MCP tool access for advanced users.

## Key Features
- 76 built-in Home Assistant tools for entity control, automation management, and configuration editing
- Curated library of Home Assistant skills for real-world tasks like motion lighting setup and automation debugging
- Bidirectional MCP support for integrating with external AI clients and tools
- Multi-provider AI compatibility (Claude, OpenAI, Ollama, etc.) with user-provided API keys
- Safety-first approach with diff-based approval for all configuration changes

## Why It Matters for RAG Builders
Aloha bridges the gap between AI agents and smart home automation, enabling natural language control of Home Assistant while maintaining safety and extensibility for RAG and AI stack builders.
