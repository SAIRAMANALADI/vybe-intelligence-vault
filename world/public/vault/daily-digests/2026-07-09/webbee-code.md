## Summary
Webbee is a cloud-based coding agent that operates in the terminal, enabling users to interact with their local files and connected apps via plain English commands. It separates the model (proposing actions) from the kernel (deciding and executing) while keeping sensitive operations under user control.

## Key Features
- Cloud-based agent with local terminal interaction
- Model-kernel separation for safety and control
- Multi-mode operation (default, plan, autopilot)
- Marathon mode for long-running tasks with pause/resume
- Supports connected apps (mail, notes, tasks) via Imperal Cloud

## Why It Matters for RAG Builders
Webbee enables secure, cloud-powered coding automation with user-controlled decision-making, reducing local resource overhead while maintaining privacy for sensitive operations.
