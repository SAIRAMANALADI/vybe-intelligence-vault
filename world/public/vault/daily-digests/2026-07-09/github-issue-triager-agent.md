## Summary
A production-grade AI agent that automates GitHub issue triaging using LangGraph, RAG (ChromaDB), and Groq's Llama 3.3 70B model. It classifies, prioritizes, detects duplicates, suggests fixes, generates PR descriptions, and drafts GitHub replies grounded in repository code.

## Key Features
- 7-node LangGraph workflow for structured issue analysis and triaging
- Real-time WebSocket streaming for progress tracking and user feedback
- Per-repo ChromaDB collections for secure and isolated semantic search
- Auto-labeling and direct GitHub reply posting via API integration
- Feedback loop with PostgreSQL persistence for continuous improvement

## Why It Matters for RAG Builders
It streamlines GitHub issue management by automating triage, reducing manual effort, and improving response quality for AI engineering teams.
