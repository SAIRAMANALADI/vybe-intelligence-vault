## Summary
A production-grade framework that standardizes and orchestrates the entire AI-driven Software Development Life Cycle (SDLC) for coding agents using modular, policy-driven skills and a centralized rule system.

## Key Features
- Centralized policy architecture (`AI_RULES.md`) enforcing consistent agent behavior across all tasks
- Modular skill library with 19+ pre-built workflow skills for AI coding agents
- Feature-centric workflow with unique Feature IDs tracked from discovery to deployment
- Global CLI wrapper (`aiwf`) for seamless framework integration and management
- Workspace permission modes (Sandbox, Full Access, Unrestricted) with granular approval gates

## Why It Matters for RAG Builders
It provides a structured, policy-driven framework to standardize and automate AI agent workflows, ensuring consistency, quality, and traceability across the entire SDLC for RAG and AI stack builders.
