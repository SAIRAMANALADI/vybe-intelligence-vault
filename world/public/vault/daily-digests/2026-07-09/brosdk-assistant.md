## Summary
Brosdk Assistant is a Chrome side-panel AI assistant that integrates a Rust-based Native Messaging host with a WXT + React Chrome extension for local AI interactions. It enables MCP tool integration and scoped workspace access for AI-driven tasks.

## Key Features
- Chrome side-panel assistant with AI capabilities
- Rust Native Messaging host for secure local communication
- MCP tool integration for extended functionality
- Scoped workspace access for file operations
- Cross-platform Windows packaging and deployment
