## Summary
npcpy is a Python library designed for research and development with multimodal language models, agentic AI, and knowledge graphs. It provides primitives for building multi-agent systems, context engineering, and tool integration with support for both local and cloud-based LLM providers.

## Key Features
- Multi-agent system support with NPC and NPCArray classes for parallel and iterative debates
- Built-in tool integration (sh, python, edit_file, web_search, etc.) for agentic workflows
- Knowledge graph lifecycle management (initialization, evolution, sleep/dream cycles)
- Support for local (Ollama, Llama.cpp, LM Studio) and cloud-based LLM providers (Minimax, LiteLLM)
- CodingAgent for auto-executing code blocks from LLM responses
