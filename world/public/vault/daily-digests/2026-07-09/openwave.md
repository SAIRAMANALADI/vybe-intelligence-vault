## Summary
OpenWave is an open-source, local-first agent runtime built in Rust that enables multi-agent task execution, file interaction, and tool integration on a user's machine. It prioritizes privacy, model-agnosticism, and user ownership of data and compute.

## Key Features
- Local-first execution with user-owned data and compute
- Multi-agent task planning and parallel execution in sandboxes
- Model Context Protocol (MCP) support for tool integration
- Configurable with user-provided API keys for LLMs and embeddings
- Modular Rust-based architecture with clear crate separation

## Why It Matters for RAG Builders
OpenWave provides a privacy-preserving, local-first alternative to cloud-based agentic systems, enabling developers to build and deploy AI agents that operate entirely on user-controlled infrastructure.
