## Summary
hevy-mcp is an MCP server implementation that interfaces with the Hevy fitness tracking API, enabling AI assistants to access, manage, and update workout data, routines, and exercise templates for users with a Hevy PRO subscription.

## Key Features
- Enables AI assistants (e.g., Claude, Cursor) to interact with Hevy fitness data via MCP
- Supports CRUD operations for workouts, routines, exercise templates, and folders
- Includes in-memory caching for exercise templates to reduce API latency
- Provides type-safe API interactions using Zod and Kubb-generated clients
- Offers observability via Sentry for error tracking and diagnostics

## Why It Matters for RAG Builders
It bridges AI assistants with fitness data, enabling AI-powered workout planning, analysis, and automation for users of the Hevy fitness app.
