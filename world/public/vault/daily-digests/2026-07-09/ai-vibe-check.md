## Summary
AI-Vibe-Check is a desktop application that tracks developer well-being by analyzing posts from Hacker News and Reddit to generate a daily 'Developer Anxiety Score' and mood trends. It provides visual data representation and self-updating features for convenience.

## Key Features
- Daily Developer Anxiety Score calculation based on social media data
- Self-updating dashboard with visual trends and charts
- Automated data fetching from Hacker News and Reddit
- Cross-platform support (Windows, macOS, Linux)
- Community-driven feedback and troubleshooting
