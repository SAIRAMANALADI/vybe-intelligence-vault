## Summary
Max is a universal AI skill framework that transforms any LLM into a multi-role engineering team via a modular, model-agnostic system prompt. It dynamically selects from 8 output modes (e.g., Architect, Code, DevOps) and includes Arabic dialect support, a decision engine, and tool registry for cross-platform integration.

## Key Features
- 8 dynamic output modes (Architect, Code, DevOps, etc.) with auto-selection via decision engine
- Modular architecture with on-demand capability loading (8 domains: backend, AI, security, etc.)
- Arabic dialect support (5 dialects) with auto-detection and bilingual output
- Universal tool registry (14 operations × 7 platforms) with fallback chains
- Token-budget aware module selection and 4-layer context prioritization for zero-conflict responses

## Why It Matters for RAG Builders
Max provides a production-grade, model-agnostic framework to turn any LLM into a specialized AI agent, drastically reducing prompt engineering overhead for RAG builders.
