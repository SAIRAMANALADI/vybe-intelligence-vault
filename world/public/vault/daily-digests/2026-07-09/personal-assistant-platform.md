## Summary
A self-learning AI personal assistant platform built with Next.js, Elysia, and Mastra, featuring native streaming, web search integration, and vector-based memory (RAG) for continuous knowledge retention and improvement.

## Key Features
- Native AI streaming with typewriter effect via ReadableStream for real-time, buffer-free message transmission
- Self-learning memory system that extracts and summarizes critical information from web searches into a PostgreSQL vector database
- Integrated Tavily web search with accordion UI for displaying search results in the frontend
- Modular message editing, copying, and branching for dynamic conversation management
- Modern, responsive UI with glassmorphism design, dark/light themes, and syntax-highlighted code blocks

## Why It Matters for RAG Builders
It provides a modular, self-learning AI assistant framework with built-in RAG capabilities, enabling continuous knowledge retention and dynamic interaction for RAG/AI stack builders.
