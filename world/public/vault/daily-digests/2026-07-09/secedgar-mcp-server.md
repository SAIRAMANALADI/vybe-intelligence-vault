## Summary
A Model Context Protocol (MCP) server that enables querying SEC EDGAR filings, XBRL financials, and company data via tools, resources, and prompts. It provides structured access to SEC submissions, insider transactions, institutional holdings, and financial concepts with SQL analytics over DuckDB-backed dataframes.

## Key Features
- Query SEC EDGAR filings, XBRL financials, and company data via MCP tools and resources
- Full-text search across all EDGAR documents since 1993 with filtering and pagination
- SQL analytics over DuckDB-backed dataframes for advanced financial analysis
- Support for insider transactions, institutional holdings, and financial concept discovery
- Streamable HTTP and STDIO transport with Docker and npm package distribution
