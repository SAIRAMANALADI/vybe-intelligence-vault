## Summary
The Litmus MCP Server is an official Model Context Protocol (MCP) server that enables LLMs and AI systems to interact with Litmus Edge for device configuration, monitoring, and management. It bridges AI workflows with industrial IoT infrastructure via standardized MCP tools and resources.

## Key Features
- Enables LLMs to interact with Litmus Edge for device configuration and monitoring via MCP tools
- Supports multiple MCP transports (HTTP, SSE, STDIO) for compatibility with various clients
- Includes a built-in web UI for natural language interaction and configuration management
- Exposes live Litmus documentation as MCP resources for dynamic context injection
- Provides persistent configuration via volume mounts for Docker deployments
