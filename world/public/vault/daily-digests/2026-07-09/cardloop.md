## Summary
Cardloop is a self-hosted, mobile-first cockpit that turns a kanban board into an autonomous agent execution environment. Each card in the board represents a task executed by the official Claude Code engine, with results streamed live to a PWA accessible from any device.

## Key Features
- Mobile-first PWA for agent control and monitoring from any device
- Direct integration with official Claude Code engine using user's own Anthropic account
- Kanban board where each card auto-executes as a Claude agent task with isolated git worktrees
- Live streaming of agent actions, diffs, and results with review gates (Check/Apply/Discard)
- Deferred runs with auto-resume on rate limits and production-grade error handling

## Why It Matters for RAG Builders
Cardloop enables seamless, mobile-accessible orchestration of autonomous AI agents directly from a kanban board, bridging the gap between task management and agent execution in a self-hosted, secure environment.
