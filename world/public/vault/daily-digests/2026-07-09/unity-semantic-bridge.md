## Summary
Unity Semantic Bridge (USB) is a subagent for Unity Editor that enables AI coding tools (e.g., Antigravity, Cursor, Claude) to query and understand Unity scenes efficiently, reducing tool calls. It also includes an experimental Unity Agent for automating gameplay testing using LLMs like Gemini.

## Key Features
- Enables AI tools to query and interact with Unity scenes via MCP server
- Reduces tool calls by providing efficient scene understanding
- Experimental Unity Agent for automated gameplay testing using LLMs
- Supports dynamic dependency management via `uv`
- Integrates with popular AI coding tools (Antigravity, Cursor, Claude)
