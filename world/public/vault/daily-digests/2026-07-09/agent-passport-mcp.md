## Summary
Agent Passport System MCP is an enforcement and accountability layer for AI agents, providing identity management, delegation, governance, and signed receipts as modular tools. It enables secure agent interactions through cryptographic attestations, policy enforcement, and multi-layered protocol support.

## Key Features
- 150+ modular MCP tools for identity, delegation, governance, and enforcement
- Ed25519-based cryptographic attestations and receipts for accountability
- Multi-profile support (essential, full, and specialized profiles)
- ProxyGateway for two-phase execution with replay protection
- Intent Network for agent-mediated matching and collaboration

## Why It Matters for RAG Builders
It provides a critical enforcement and accountability layer for AI agents, ensuring secure, auditable, and policy-compliant interactions in multi-agent systems.
