## Summary
Dali is a Model Context Protocol (MCP) server that scores and enhances AI generation prompts before execution, preventing wasted tokens and credits. It provides model-specific guidance for video and image generation across platforms like Veo 3, Seedance, Kling, and Flux, ensuring optimal prompt quality.

## Key Features
- Pre-generation prompt scoring (0-100 scale) with model-specific rubrics to predict generation success
- Automated prompt enhancement using structured rewrite briefs tailored to each AI model's requirements
- Real-time community benchmarking and pattern tracking to improve prompt quality over time
- Support for 14+ AI models across video and image generation platforms with platform-specific guidance
- Integration with MCP clients (Claude, Cursor, Windsurf) and self-hosting capabilities

## Why It Matters for RAG Builders
Dali eliminates wasted AI generation costs by scoring and optimizing prompts before execution, ensuring higher-quality outputs and reducing unnecessary token consumption for RAG and AI stack builders.
