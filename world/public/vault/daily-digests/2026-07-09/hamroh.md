## Summary
hamroh is a framework for deploying a persistent, self-learning AI assistant on Telegram that operates with full user control, memory persistence, and extensibility via MCP tools. It enables users to own and customize their AI companion for personal, team, or automation use cases.

## Key Features
- Persistent AI assistant with file-based memory that survives restarts
- Extensible via MCP tools for integrating APIs, databases, and custom logic
- Self-reflection and rule-learning capabilities with user approval
- Scheduled task execution and background subagents for automation
- Full user ownership of data, memory, and configuration

## Why It Matters for RAG Builders
It provides a self-hosted, customizable AI agent framework that empowers users to build and control their own persistent AI companions without third-party dependencies.
