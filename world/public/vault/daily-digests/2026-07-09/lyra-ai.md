## Summary
Lyra is a personal AI agent designed to manage work, life, and household coordination via Telegram, Notion, and Google services. It automates tasks, syncs shared databases, and provides contextual reminders for multiple users while running 24/7 on a cloud VPS.

## Key Features
- Four-tier model routing for cost and performance optimization (Tier 0 Python scripts, MiniMax M2.7, Claude Haiku 4.5, Claude Sonnet 4.6)
- Shared Notion databases with access control for household coordination and task management
- 24/7 autonomous operation with self-healing infrastructure (systemd, health checks, auto-restart)
- Bidirectional GitHub sync for self-modifying agent with audit trail
- Multi-service integration (Gmail, Google Calendar, RSS, web search) with deterministic CRUD bypass for efficiency

## Why It Matters for RAG Builders
Lyra demonstrates a production-grade, resilient AI agent framework with multi-user coordination, Notion integration, and cost-efficient model routing, serving as a blueprint for scalable personal AI systems.
