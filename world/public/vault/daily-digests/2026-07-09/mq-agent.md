## Summary
mq-agent is a terminal-native AI agent orchestrator designed for the MQ ecosystem, enabling controlled, traceable, and safe terminal workflows with explicit planning, tool routing, verification, memory, and safety gates. It acts as a central orchestrator for AI-driven tasks like repository audits, release readiness checks, and CI failure diagnostics.

## Key Features
- Explicit planning, execution, verification, and safety layers for AI workflows
- Support for read-only, suggest, execute, and dangerous safety modes
- Integration with mq-mcp (Model Context Protocol) for tool routing and review
- Built-in repository intelligence tools (e.g., README scoring, publish checks)
- Persistent memory and session state management for context-aware operations

## Why It Matters for RAG Builders
mq-agent provides a structured, safety-first framework for deploying AI agents in terminal environments, ensuring traceability and control over automated workflows critical for RAG and AI stack builders.
