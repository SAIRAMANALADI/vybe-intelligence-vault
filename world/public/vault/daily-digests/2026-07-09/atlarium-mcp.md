## Summary
Atlarium Habitat Database MCP is a public read-only Model Context Protocol (MCP) server providing structured access to aquarium, marine tank, terrarium, and paludarium habitat data. It exposes 39 tools for species research, diagnostics, product selection, fertilization planning, and habitat advisory without requiring authentication or write access.

## Key Features
- 39 read-only tools for species, plants, products, and diagnostics
- Streamable HTTP transport with no authentication required
- Guided prompts for species search, compatibility, and habitat planning
- Public widget for ChatGPT Apps-compatible hosts
- Supports unit conversions, fertilization calculations, and tank planning

## Why It Matters for RAG Builders
It provides AI agents with structured, real-world habitat data and advisory tools essential for building accurate RAG systems in aquarium, marine, and terrarium domains.
