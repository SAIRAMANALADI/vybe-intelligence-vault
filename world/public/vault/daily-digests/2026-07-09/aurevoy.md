## Summary
Aurevoy is a local-first personal AI agent that autonomously plans and executes tasks based on high-level goals, such as code editing, file management, web research, and image analysis. It integrates with local workspaces and supports multimodal inputs while prioritizing user data privacy.

## Key Features
- Autonomous task planning and execution based on high-level goals
- Local execution with user-provided API keys for model flexibility
- Multimodal support for images, files, and code analysis
- Precision file editing with undo and context branching capabilities
- Built-in web search and project workspace organization
