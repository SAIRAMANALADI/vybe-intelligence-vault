## Summary
YACT is a minimal, responsive CLI-based tool designed to assist developers with LLM-powered coding tasks. It emphasizes transparency, reactivity, and prompt stuffing over RAG, enabling developers to explicitly control file access and API interactions for cost-efficient, fast responses.

## Key Features
- Reactive coding assistant with explicit file control via prompt stuffing
- Supports multi-step workflows (Question/Plan/Act modes)
- Minimal context management with conversation history tracking
- Works with smaller LLMs (down to 7B parameters) for cost efficiency
- Safe mode for reviewing generated code before applying changes

## Why It Matters for RAG Builders
YACT provides a lightweight, transparent alternative to RAG-heavy coding agents, reducing API costs and latency while giving developers precise control over file access and generation.
