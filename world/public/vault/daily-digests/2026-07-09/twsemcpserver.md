## Summary
A Model Context Protocol (MCP) server designed for Taiwan Stock Exchange (TWSE) data analysis, providing real-time stock information, financial statements, ESG data, and trend analysis through standardized APIs and tools.

## Key Features
- Integrates multiple Taiwan financial data sources (TWSE, TPEx, TAIFEX) for comprehensive stock analysis
- Supports real-time and historical stock data, financial statements, and ESG metrics
- Provides tools for technical, fundamental, and quantitative analysis of Taiwanese stocks
- Offers Docker and local deployment options for flexibility
- Includes pagination and filtering for large datasets to optimize AI client interactions
