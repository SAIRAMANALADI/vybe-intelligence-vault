## Summary
flowgraf-mcp is a Model Context Protocol (MCP) stdio proxy that enables AI agents to create, edit, and retrieve clean, auto-laid-out architecture diagrams via a hosted service. It converts text descriptions into editable diagrams and returns SVG outputs or live canvas links without requiring API keys or LLM costs.

## Key Features
- Converts text descriptions into auto-laid-out architecture diagrams
- Provides live, editable canvas links (SVG + Mermaid output)
- Supports dynamic diagram editing via AI agent commands
- No API key or LLM cost required for diagram generation
- Compatible with MCP clients like Claude Code and Cursor

## Why It Matters for RAG Builders
It streamlines the creation and iteration of architecture diagrams for AI agents, reducing manual effort and enabling seamless integration into RAG workflows.
