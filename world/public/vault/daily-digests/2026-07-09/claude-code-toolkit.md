## Summary
The Claude Code Toolkit provides a production-ready workflow for bootstrapping projects with an opinionated agent team, slash commands, auto-triggered skills, and MCP permissions in one command. It supports multiple language variants and enforces workflow best practices.

## Key Features
- Six pre-configured template variants for .NET, Java, Python, Rust+Tauri, .NET MAUI, and general use cases
- 7–8 specialized agents per variant (architect, coder, tester, etc.) with language-specific hooks
- 23 user-level slash commands for daily workflow automation (/build, /test, /commit, etc.)
- 11 auto-triggering skills that adapt to project needs (debugging, refactoring, etc.)
- Pre-wired MCP permissions for Git, GitHub, databases, and language-specific tools
