## Summary
A ComfyUI sidebar panel that integrates an autonomous AI agent (Claude or ChatGPT) to drive canvas edits, workflow automation, and node management in real-time. Operates on the user's existing subscription without requiring API keys or additional LLM costs.

## Key Features
- Real-time AI-driven canvas edits with undoable actions via Ctrl+Z
- Supports both Claude and ChatGPT providers with full feature parity
- One-click installation via ComfyUI Manager or git clone
- Autonomous workflow loading and node management with cost awareness
- Live activity tracking, multi-tab support, and session rollback capabilities

## Why It Matters for RAG Builders
It provides a seamless, subscription-based AI agent interface for ComfyUI that enables natural language-driven workflow automation and real-time canvas editing, reducing manual setup and operational overhead for RAG builders.
