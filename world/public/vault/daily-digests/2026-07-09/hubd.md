## Summary
hubd is a project tracker designed for teams of humans and AI agents, using plain files (markdown and JSONL) to coordinate work without proprietary formats. It acts as a shared headquarters for managing tasks, queues, projects, and resources, ensuring agents and humans collaborate seamlessly.

## Key Features
- Shared workspace using plain markdown/JSONL files for human and AI agent collaboration
- Task queues with blocking wait for agents, ensuring efficient work distribution
- Structured reporting with prefix-tagged lines (DECIDE, FACT, COMM, NEXT, DONE) for clear project updates
- Typed wikilink relationships for resources and projects, enabling a unified graph view
- MCP server and CLI for seamless integration with AI agents and human workflows

## Why It Matters for RAG Builders
It provides a decentralized, file-based coordination layer for AI agents and humans, eliminating the need for proprietary project management tools while ensuring transparency and compatibility across different systems.
