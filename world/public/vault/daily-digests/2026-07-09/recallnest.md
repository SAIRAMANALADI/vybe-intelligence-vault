## Summary
RecallNest is a local-first shared memory layer for coding agents like Claude Code, Codex, and Gemini CLI, enabling context persistence and reuse across sessions. It leverages LanceDB for vector and full-text search, providing hybrid retrieval, session continuity, and knowledge graph capabilities.

## Key Features
- Shared memory layer for multiple coding agents with automatic context recall
- Hybrid retrieval combining vector search, BM25, and knowledge graph traversal
- Session continuity with checkpointing and resumption across windows
- Philosophy-informed memory evolution with decay, ethics, and narrative structure
- Web UI with dashboard, search workbench, and interactive knowledge graph visualization

## Why It Matters for RAG Builders
RecallNest is essential for RAG builders as it provides a unified, persistent memory layer that enables coding agents to retain and reuse context across sessions, significantly improving the coherence and efficiency of AI-driven development workflows.
