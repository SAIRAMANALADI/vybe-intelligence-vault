## Summary
FMCL is a modern Minecraft launcher built with CustomTkinter, offering comprehensive game management features including version control, mod loader support (Forge/Fabric/NeoForge/Quilt), mod and modpack management, server hosting, P2P networking, AI assistant integration, and performance monitoring.

## Key Features
- Supports 8 mod loaders (Forge, Fabric, NeoForge, Quilt, etc.) with version isolation
- Integrated AI Agent for natural language control and tool execution (33 tools, 50-turn loops)
- Built-in BMCLAPI mirror for accelerated downloads in China
- Comprehensive mod and modpack management via Modrinth and CurseForge APIs
- Advanced features like P2P networking, performance monitoring, dynamic themes, and achievement system
