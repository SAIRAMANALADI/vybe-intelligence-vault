## Summary
A Model Context Protocol (MCP) server that enables AI coding agents to inspect, automate, and debug WebViews or web pages without requiring a remote-debugging port. It bridges WebViews to MCP clients via a lightweight JavaScript injection (`target.js`) for real-time interaction.

## Key Features
- Enables AI agents to inspect and control WebViews without opening a browser tab
- Supports snapshots, screenshots, DOM interaction, and console/network debugging
- Works with Safari, iOS WebView, Lark Web App, and other embedded web environments
- Lightweight `target.js` injection for seamless WebView integration
- Compatible with major MCP clients like Claude Code, Cursor, and Copilot

## Why It Matters for RAG Builders
It bridges the gap between AI agents and WebViews, enabling real-time debugging and automation for embedded web applications, which is critical for RAG systems interacting with dynamic web content.
