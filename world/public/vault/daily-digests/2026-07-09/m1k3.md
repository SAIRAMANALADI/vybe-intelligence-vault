## Summary
M1K3 is a native AI companion for Apple Silicon Macs that runs entirely on-device, offering local LLM inference, live voice interaction, a personal knowledge graph with RAG, encrypted call transcription, and an MCP server for agent integration. It prioritizes privacy by ensuring no data leaves the user's machine.

## Key Features
- Runs entirely on Apple Silicon Macs with no cloud dependency
- Local LLM inference using MLX and Apple Foundation Models
- Personal knowledge graph with hybrid RAG for document and memory retrieval
- Live voice interaction with on-device speech-to-text and neural TTS
- MCP server for exposing local capabilities to external agents like Claude

## Why It Matters for RAG Builders
M1K3 provides a fully local, privacy-preserving AI stack with RAG and agent capabilities, making it essential for builders who require offline, secure, and customizable AI solutions.
