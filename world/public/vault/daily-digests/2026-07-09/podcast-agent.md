## Summary
An autonomous agent for publishing podcasts that automates multicam video rendering, transcript-driven editing, asset generation, and multi-platform distribution (audio host and YouTube) with strict phase-gated verification, including lip-sync checks.

## Key Features
- Autonomous podcast publishing pipeline with phase-gated automation
- Multicam video rendering with frame-exact assembly and zero cumulative drift
- Hard lip-sync verification gate (GCC-PHAT, EBU R37 compliant) to ensure audio-video sync
- Transcript-driven automated editing and asset generation (thumbnails, chapters)
- Multi-platform distribution to audio hosts (Fireside) and YouTube via APIs
