## Summary
An MCP (Model Context Protocol) server for The Movie Database (TMDB) that enables search and retrieval of movies, TV shows, and people, along with IMDb, Rotten Tomatoes, and Metacritic ratings via OMDb integration. Designed to work with any MCP-compatible client for natural language queries.

## Key Features
- Search and retrieve movies, TV shows, and people via TMDB API
- Integrated IMDb, Rotten Tomatoes, and Metacritic ratings (optional OMDb API key)
- Supports natural language queries through MCP clients
- Localization support via TMDB_LANGUAGE and TMDB_REGION
- Comprehensive toolset for media discovery, recommendations, and details

## Why It Matters for RAG Builders
It provides structured, real-time access to movie and TV metadata with ratings, enabling AI agents to enrich RAG responses with accurate and up-to-date media information.
