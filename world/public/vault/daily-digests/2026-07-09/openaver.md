## Summary
OpenAver is a free, open-source desktop GUI application designed to scrape, manage, and organize JAV (Japanese Adult Video) metadata. It provides a cover-wall browser for navigating collections by cover art, tags, and actress profiles, with built-in scraping from 8 sources and optional Metatube federation for 30+ providers. It also offers AI-operable REST APIs and exports NFO + cover art to Jellyfin, Emby, or Kodi.

## Key Features
- 8 built-in scraping sources (JavBus, Jav321, JavDB, DMM, D2Pass, HEYZO, FC2, AVSOX) with optional Metatube federation for 30+ additional providers
- Cover-wall browser with tag-based navigation, actress profile cards, and cross-language alias support for actresses
- AI-operable REST API with capabilities manifest for seamless integration with AI agents (Claude Code, Cursor, Perplexity, etc.)
- Exports NFO + cover art (poster/fanart) to Jellyfin, Emby, or Kodi for media center integration
- 100% local operation with no cloud uploads or telemetry, supporting Windows and macOS (Apple Silicon)

## Why It Matters for RAG Builders
OpenAver streamlines JAV metadata management and collection browsing with a user-friendly GUI and AI-ready APIs, making it essential for developers building RAG pipelines that require structured, scraped metadata from niche or fragmented sources.
