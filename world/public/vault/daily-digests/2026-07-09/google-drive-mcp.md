## Summary
A Model Context Protocol (MCP) server that enables secure integration with Google Drive, Docs, Sheets, Slides, and Calendar, allowing MCP clients like Claude Desktop to manage files and calendar events through a standardized interface.

## Key Features
- Multi-format Google Workspace integration (Docs, Sheets, Slides, Calendar)
- Secure OAuth 2.0 authentication with automatic token refresh
- Advanced file management (create, update, delete, search, organize)
- MCP Resource Protocol for standardized file access
- Docker and CLI support for flexible deployment

## Why It Matters for RAG Builders
It provides a standardized, secure way to integrate Google Workspace with AI workflows, enabling automated document and calendar management for RAG and agent-based systems.
