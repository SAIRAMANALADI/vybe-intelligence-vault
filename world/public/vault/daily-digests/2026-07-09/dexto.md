## Summary
Dexto is an open agent harness that turns LLMs into reliable, stateful agents with orchestration, memory, and tool integration. It includes a production-ready coding agent and supports multi-agent systems, MCP integration, and deployment across local, cloud, or hybrid environments.

## Key Features
- Configuration-driven agent definition via YAML for easy customization and model/tool swapping
- Built-in session management, memory, and persistent context across restarts
- Support for 50+ LLMs with mid-conversation model switching and local model execution
- MCP integration for connecting to 30+ tools (filesystem, browser, APIs, etc.)
- Multi-agent orchestration with sub-agent spawning and unified approval flows

## Why It Matters for RAG Builders
Dexto provides the critical orchestration layer for building scalable, reliable, and customizable AI agents, making it essential for RAG/AI stack builders who need robust agentic workflows.
