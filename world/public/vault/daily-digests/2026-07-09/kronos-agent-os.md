## Summary
Kronos Agent OS (KAOS) is a self-hosted runtime for durable AI agents that integrates memory, skills, MCP tools, automations, and optional sub-agent coordination. It provides a local-first, conservative runtime with a dashboard control room for monitoring and managing agent workflows.

## Key Features
- Durable agent runtime with session history and long-term memory (FTS5, Mem0, knowledge graph)
- Modular skill packs and dynamic tool execution with sandboxing
- MCP tool gateway for integrating external tools and services
- Automations and scheduled jobs for digests, monitoring, and analytics
- Dashboard control room for real-time monitoring and system status

## Why It Matters for RAG Builders
KAOS provides a robust, self-hosted framework for building and managing durable AI agents with built-in memory, tool integration, and multi-agent coordination, reducing reliance on proprietary agent platforms.
