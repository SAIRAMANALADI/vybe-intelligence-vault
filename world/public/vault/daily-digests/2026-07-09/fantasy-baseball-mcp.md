## Summary
A local-first MCP (Model Context Protocol) plugin for managing Yahoo Fantasy Baseball teams via natural language interactions in Claude Desktop or Codex. It integrates Statcast, FanGraphs, and MLB Stats API to provide AI-driven roster analysis, free-agent scouting, and matchup insights without hosting user data.

## Key Features
- Natural language interaction for roster management (e.g., 'fantasy show roster', 'who should I add')
- Integration with Statcast, FanGraphs, and MLB Stats API for advanced player analytics
- Local execution with Yahoo credentials stored on user's machine (no hosting)
- Browser-based workaround for lineup moves due to deprecated Yahoo API write scope
- Caching of leaderboard data for one hour to optimize performance

## Why It Matters for RAG Builders
It enables AI-driven, data-rich fantasy sports management through natural language, demonstrating how MCP can integrate multiple APIs for real-world applications in a privacy-preserving way.
