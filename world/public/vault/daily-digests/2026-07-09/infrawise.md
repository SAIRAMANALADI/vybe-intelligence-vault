## Summary
Infrawise is a deterministic infrastructure intelligence layer for AI coding assistants, statically analyzing cloud infrastructure, databases, and codebases to expose context via MCP. It enables AI tools like Claude Code to understand actual infrastructure details (e.g., DynamoDB GSIs, PostgreSQL indexes) instead of guessing from source files alone.

## Key Features
- Static analysis of AWS services, databases, and codebases to extract infrastructure context
- Exposes infrastructure details via MCP for AI tools like Claude Code and Cursor
- Provides 21+ MCP tools for querying tables, indexes, queues, APIs, and more
- Detects high-severity issues (e.g., full table scans, missing indexes) with actionable recommendations
- Supports CI/CD integration via `infrawise check` for blocking findings

## Why It Matters for RAG Builders
Infrawise eliminates guesswork in AI-assisted infrastructure development by providing deterministic context, reducing the risk of production incidents and improving code quality.
