## Summary
CarryMem is a lightweight, zero-dependency AI memory system that stores user preferences, decisions, and corrections to provide consistent AI interactions across tools, models, and devices. It enables portable, encrypted AI identity files for seamless cross-platform and cross-tool memory transfer.

## Key Features
- Portable AI identity storage with encrypted .carry files for cross-device and cross-tool memory transfer
- Zero-dependency core with optional semantic search and encryption modules
- Academically validated preference injection accuracy (83.0% PrefEval benchmark, ICLR 2025 Oral)
- Rule-based memory classification (88% without LLM calls) for high-speed, low-cost recall
- Seamless integration with Cursor, Claude Code, ChatGPT, and other MCP-compatible tools

## Why It Matters for RAG Builders
CarryMem eliminates repetitive AI onboarding by providing persistent, portable memory that works across tools and models, significantly improving RAG and agent-based workflows with minimal setup overhead.
