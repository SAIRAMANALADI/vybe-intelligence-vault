## Summary
A Dockerized Telegram bot powered by Claude Code, enabling users to deploy a single-container bot instance with pre-configured security, permissions, and operational tooling. Supports both standard and Playwright variants for UI rendering and screenshot capture.

## Key Features
- Single-container deployment with pre-baked security rules and permissions
- Pre-configured `.workspace` for memory, rules, and events management
- Built-in `bot-doctor` and healthcheck tools for operational monitoring
- Support for Playwright variant for UI rendering and screenshot capture
- Auto Mode with classifier-gated permissions for safe headless operation

## Why It Matters for RAG Builders
It simplifies the deployment of secure, production-ready Claude Code-powered Telegram bots with minimal setup, making it ideal for AI engineers building automated agent workflows.
