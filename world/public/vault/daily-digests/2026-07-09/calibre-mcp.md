## Summary
A Model Context Protocol (MCP) server that bridges Calibre ebook libraries with AI assistants like Claude, enabling semantic search, metadata curation, and safe read/write operations across entire libraries or individual books.

## Key Features
- Multilingual semantic search (English + Russian verified) with hybrid vector + keyword retrieval
- 16 tools covering full read/write operations, including bulk edits, metadata recovery, and duplicate detection
- Safe-by-default architecture with preview-first writes and explicit confirmation for destructive actions
- Opt-in semantic indexing with cross-encoder reranking for high-precision results
- Companion skills for distilling books or topics into structured knowledge artifacts

## Why It Matters for RAG Builders
It enables AI assistants to interact with Calibre ebook libraries using natural language, unlocking advanced retrieval and curation capabilities essential for building sophisticated RAG systems with document-rich contexts.
