## Summary
KnowFlow is a bilingual (Arabic/English) AI agent that enables real-time document interaction by allowing users to upload PDFs, DOCX files, or paste URLs and ask questions in either language. It streams responses using Claude Haiku without requiring local setup.

## Key Features
- Supports Arabic (RTL) and English in the same session
- Real-time streaming responses via Claude Haiku
- Multi-format document ingestion (PDF, DOCX, URLs)
- Built-in authentication and usage limits with Supabase
- Strict secrets management with pre-commit scanning

## Why It Matters for RAG Builders
KnowFlow provides a ready-to-use bilingual agent framework for document Q&A, reducing setup time for RAG builders targeting multilingual use cases.
