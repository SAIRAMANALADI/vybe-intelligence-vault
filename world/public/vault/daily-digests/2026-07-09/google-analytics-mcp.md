## Summary
A Model Context Protocol (MCP) server that enables AI agents and copilots to directly access and analyze Google Analytics 4 (GA4) data with built-in schema discovery, metric auto-aliasing, and server-side aggregation for seamless integration with tools like Claude, ChatGPT, and VS Code.

## Key Features
- Autonomous self-healing for schema and query errors
- Metric auto-aliasing to prevent common query failures
- Server-side aggregation for non-time-series queries
- Multi-platform support (Claude, ChatGPT, Cursor, VS Code, etc.)
- Built-in telemetry with privacy controls and opt-out options

## Why It Matters for RAG Builders
It bridges AI agents with real-time GA4 data, enabling autonomous analysis and reducing manual data wrangling for RAG pipelines.
