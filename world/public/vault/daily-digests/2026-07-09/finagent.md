## Summary
FinAgent is a local-first AI agent designed to analyze bank statements by allowing users to upload PDF or CSV files and query their financial data in plain language. All processing occurs on the user's machine with zero telemetry.

## Key Features
- Local processing of financial data with no external telemetry
- Natural language querying over bank statements with streaming responses
- Automatic categorization of transactions with LLM fallback and caching
- Text-to-SQL engine for querying transaction data with safety constraints
- Multi-language UI (English/Russian) and light/dark theme support

## Why It Matters for RAG Builders
FinAgent provides a privacy-preserving, local-first solution for financial data analysis, enabling secure and customizable AI-driven insights without relying on cloud services.
