## Summary
CodeAlta is a terminal-based workspace designed for agentic coding, providing a unified interface for model provider setup, project navigation, prompt management, and durable agent sessions. It enables developers to interact with AI models directly from the terminal while supporting local plugins and extensible workflows.

## Key Features
- Keyboard-first terminal workspace with tabs, prompt editor, and project sidebar
- Provider-neutral model setup supporting multiple APIs and endpoints
- Durable agent sessions with project-scoped history and conversation management
- Context-aware prompts with reusable profiles, file attachments, and GitHub issue integration
- Trusted local extension points via plugins and in-session tools

## Why It Matters for RAG Builders
