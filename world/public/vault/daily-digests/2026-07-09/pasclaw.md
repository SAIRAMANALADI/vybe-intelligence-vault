## Summary
PasClaw is an ultra-lightweight personal AI agent framework written in Delphi Object Pascal, offering a command-line assistant, MCP integration, HTTP gateway, and OpenAI-compatible API. It supports tool calling, scheduled tasks, skills, and channel integrations with a focus on portability and performance.

## Key Features
- Ultra-lightweight native binary (~4-5 MB) with minimal runtime dependencies
- Multi-provider LLM support with fallback chains and auto-routing for cost optimization
- Built-in tools for filesystem, web search, memory, sessions, and code execution with sandboxing
- MCP integration (stdio and HTTP) with progressive tool disclosure and registry support
- HTTP gateway with OpenAI-compatible API and embedded web UI for easy interaction

## Why It Matters for RAG Builders
PasClaw provides a portable, high-performance agent framework in Object Pascal that simplifies integration of AI capabilities into existing Delphi or Free Pascal applications while supporting modern AI workflows like MCP and tool calling.
