## Summary
OpenScience is an open-source AI workbench that automates the entire scientific research loop, from literature review to hypothesis generation, code execution, experiments, and write-ups. It acts as a collaborative agent system for domains like machine learning, biology, physics, and chemistry.

## Key Features
- End-to-end research automation: literature review, hypothesis, code execution, experiments, and write-ups in one session
- Specialized research agents (biology, physics, ML) with sub-agents for critique and literature review
- 290+ built-in skills including training, evaluation, dataset work, and cloud compute integration
- Direct access to 30+ scientific databases (UniProt, PDB, arXiv, etc.) as tools for agents
- Browser-based workspace with file tree, editor, terminal, and inline rendering for scientific artifacts
