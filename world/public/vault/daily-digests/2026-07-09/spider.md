## Summary
Spider is a high-performance, concurrency-first web crawler and scraper written in Rust, designed for scalability from single scripts to distributed fleets. It supports both local execution and managed cloud infrastructure, with built-in proxies, anti-bot evasion, and JavaScript rendering capabilities.

## Key Features
- Concurrency-first design with streaming page delivery for high throughput
- Built-in JavaScript rendering with optional headless Chrome for dynamic content
- Supports both local execution and managed cloud infrastructure (Spider Cloud)
- Built-in proxies, retries, rate limiting, and stealth features to bypass anti-bot systems
- Multi-language support via Rust library, CLI, Node.js, Python, and MCP server

## Why It Matters for RAG Builders
Spider provides a robust, scalable foundation for ingesting web data into RAG pipelines, enabling reliable and high-throughput data collection from both static and dynamic websites.
