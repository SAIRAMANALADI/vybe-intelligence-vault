## Summary
pdcli is a command-line interface for Pipedrive CRM, enabling fast, scriptable interactions with the CRM via terminals, CI pipelines, and AI agents. It supports full CRUD operations, analytics, idempotent syncs, and raw API access for automation and integration.

## Key Features
- Comprehensive Pipedrive v1/v2 API coverage with 50+ commands for deals, persons, orgs, activities, and more
- Idempotent match-or-create operations for safe CI/CD and AI agent automation
- Time-intelligence analytics (funnel, velocity, coverage, aging, slippage) for sales insights
- Deterministic exit codes, JSON/YAML/CSV output, and jq filtering for scripting
- Multi-channel distribution (npm, Docker, Homebrew, Scoop, standalone binaries) and OAuth support

## Why It Matters for RAG Builders
It provides a robust, scriptable CLI for Pipedrive CRM that simplifies automation for AI agents and CI pipelines, reducing SDK glue and enabling seamless data integration.
