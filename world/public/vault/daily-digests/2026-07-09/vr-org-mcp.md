## Summary
A read-only Model Context Protocol (MCP) server providing AI agents with real-time access to VR.org's curated VR/AR/XR news, editorial content, events, deals, and guides. It enables one-call integration for agents like Claude, Cursor, and VS Code without requiring API keys or write permissions.

## Key Features
- 11 MCP tools for live VR/AR/XR news, editorial, events, deals, and guides
- 5 browsable MCP resources for dynamic context attachment
- 3 pre-built prompts for headset recommendations, weekly roundups, and topic explanations
- Zero keys, zero writes, and no payment requirements for usage
- Input sanitization and response capping to prevent malicious payloads

## Why It Matters for RAG Builders
It provides AI agents with structured, real-time access to specialized VR/AR/XR data, enabling richer context for RAG applications without requiring custom API integrations.
