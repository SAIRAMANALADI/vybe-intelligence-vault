## Summary
Contentrain AI is a Git-native content governance tool that helps teams extract, structure, and manage hardcoded UI text, documentation, and structured content from codebases. It enables agents to normalize content, enforce schemas, and facilitate human review through Git workflows, producing portable JSON and Markdown outputs for multi-platform consumption.

## Key Features
- Git-native content management with review branches and PR workflows
- MCP engine with 19 tools for agent integration (Claude Code, Cursor, etc.)
- Normalize flow to extract hardcoded strings and convert them into structured content
- Framework-agnostic output (JSON/Markdown) compatible with 20+ stacks
- Local Serve UI for content browsing, validation, and review

## Why It Matters for RAG Builders
It provides a critical governance layer for RAG builders to standardize and manage content sources, ensuring clean, reviewable, and portable data inputs for AI systems.
