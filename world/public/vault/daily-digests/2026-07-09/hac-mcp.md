## Summary
A Model Context Protocol (MCP) server that enables AI assistants (e.g., Claude) to interact programmatically with SAP Commerce Cloud's Hybris Administration Console (HAC). It automates FlexibleSearch queries, ImpEx imports, Groovy script execution, and system administration tasks across multiple environments with fine-grained permissions.

## Key Features
- Multi-environment HAC access with fine-grained permission controls
- Automated FlexibleSearch, ImpEx, and Groovy script execution
- Web UI for environment management and real-time activity monitoring
- Trigram-based fuzzy type search with caching for SAP Commerce types
- Error recovery and validation for FlexibleSearch and ImpEx operations

## Why It Matters for RAG Builders
It bridges AI assistants with SAP Commerce Cloud's HAC, enabling secure and automated administration tasks that reduce manual intervention and accelerate development workflows.
