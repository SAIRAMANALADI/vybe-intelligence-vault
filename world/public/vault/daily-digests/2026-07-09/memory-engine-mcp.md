## Summary
A living memory system for AI assistants that combines SQLite with the Model Context Protocol (MCP) to provide dynamic, decaying, and evolving memory storage. It integrates hybrid ranking, semantic search, auto-bonding, and session management for real-time knowledge retention and retrieval.

## Key Features
- Hybrid ranking system combining FTS, semantic similarity, confidence, recency, and weight for recall
- Auto-bonding engine to dynamically create relationships between atoms using rules and embeddings
- Session watcher with two-tier lifecycle for real-time ingestion and permanent digests
- Organic decay and learning engine to identify gaps, contradictions, and weak atoms
- Local embeddings via Ollama for private, offline semantic search

## Why It Matters for RAG Builders
It provides a dynamic, evolving memory system for AI assistants that goes beyond static knowledge storage, enabling continuous learning and context-aware recall critical for advanced RAG applications.
