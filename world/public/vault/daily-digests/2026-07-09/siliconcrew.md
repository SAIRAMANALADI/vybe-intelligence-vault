## Summary
SiliconCrew is an autonomous LLM agent framework that transforms natural language specifications into synthesizable RTL, self-checking testbenches, and GDSII layouts for digital hardware design. It integrates verification, debugging, and synthesis workflows with real-time UI and MCP protocol support.

## Key Features
- Autonomous RTL generation from natural language specifications with structured YAML inputs
- End-to-end verification loop including linting, simulation, waveform debugging, and iterative fixes
- Synthesis to GDSII via OpenROAD targeting SkyWater 130nm PDK
- Dual interface support: Next.js web app with real-time streaming and MCP server for IDE integration
- Benchmark performance of 65% pass rate on CVDP (NVIDIA's hardware design benchmark)

## Why It Matters for RAG Builders
SiliconCrew demonstrates how LLM agents can autonomously bridge the gap between high-level specifications and low-level hardware implementation, enabling rapid prototyping and iteration in digital design workflows.
