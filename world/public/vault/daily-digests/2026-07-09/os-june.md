## Summary
June is an open-source, privacy-focused AI workspace for macOS that provides local chat, voice dictation, meeting notes, and an agentic assistant. It prioritizes data privacy by running entirely on-device with optional secure cloud routing for model inference.

## Key Features
- Local-first AI workspace with on-device processing and optional secure cloud routing
- Privacy-focused features like zero data retention, TEE-attested model inference, and verifiable builds
- Multi-modal capabilities including chat, voice dictation, meeting notes, and image generation
- Sandboxed local agent with user-approved actions and extensible skills via MCP servers
- Open-source, MIT-licensed, and cryptographically verifiable for transparency

## Why It Matters for RAG Builders
June provides a privacy-first alternative to cloud-based AI tools, enabling RAG builders to integrate secure, local-first AI workflows with verifiable trust guarantees.
