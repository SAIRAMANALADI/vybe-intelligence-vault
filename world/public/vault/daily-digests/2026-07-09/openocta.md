## Summary
OpenOcta is an open-source enterprise-grade AI Agent platform delivered as a single Go binary with an embedded frontend. It provides a unified runtime and control plane for AI-driven automation, workflow orchestration, and integration with business systems, APIs, and custom tools.

## Key Features
- Single binary deployment with embedded frontend (Go 1.24+ binary)
- Unified control plane for AI agents, workflows, and automation
- Supports HTTP/WebSocket APIs, CLI, and Webhooks for external integration
- Built-in MCP (Model Context Protocol) tool integration and custom skill support
- Cross-platform compatibility (Linux, macOS, Windows) with desktop installer (.dmg)
