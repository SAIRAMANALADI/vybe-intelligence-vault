## Summary
An on-device AI agent for Android that processes natural language requests, plans tasks, and executes actions locally without requiring an internet connection. It features a drag-and-drop pipeline editor for customizable workflows and supports local LLM inference via LiteRT-LM.

## Key Features
- Local LLM inference with LiteRT-LM and optional NPU/GPU acceleration
- Drag-and-drop pipeline editor with 14 node types and auto-layout
- Support for image attachments and on-device image understanding
- Voice input transcription with local multimodal models
- Privacy-preserving local usage statistics and telemetry

## Why It Matters for RAG Builders
It enables fully autonomous, privacy-focused AI agents on Android devices with customizable pipelines and local LLM inference, reducing reliance on cloud services for AI tasks.
