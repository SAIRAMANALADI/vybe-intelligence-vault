## Summary
Casper is a web client for the Kiro CLI, enabling persistent server-side execution of long-running agent tasks. It replays missed interactions upon reconnection, providing a seamless user experience for AI agent workflows.

## Key Features
- Persistent server-side agent sessions with automatic replay on reconnection
- Rich rendering support for Markdown, Mermaid diagrams, and syntax-highlighted code
- Per-session model and agent customization with observability metrics
- Progressive Web App (PWA) with auto-reconnect and installable UI
- Secure session management with configurable TTL and token-based authentication

## Why It Matters for RAG Builders
Casper enables seamless, persistent interaction with AI agents by maintaining server-side sessions and replaying missed interactions, critical for building robust RAG systems with long-running workflows.
