## Summary
Project Tango is a local-first Model Context Protocol (MCP) server that provides LLM agents with structured access to e-commerce data, including products, inventory, orders, and sales analytics. It ships with a mock dataset for zero-configuration use and supports swapping in live APIs like Shopify or Stripe via a clean DataProvider interface.

## Key Features
- Local-first MCP server with zero infrastructure cost
- Mock dataset for instant setup and testing
- Clean DataProvider interface for seamless API integration
- Six pre-built tools for product, inventory, and sales analytics
- Strict input validation and security-first design

## Why It Matters for RAG Builders
Project Tango enables AI agents to interact with e-commerce data in a structured, secure, and local-first manner, reducing deployment friction and enhancing RAG pipeline reliability.
