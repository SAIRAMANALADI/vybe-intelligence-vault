## Summary
Nexus-KB is an open-source reference architecture for building a secure Retrieval-Augmented Generation (RAG) and Knowledge Graph (KG) platform. It integrates document ingestion, hybrid retrieval, audit trails, RBAC, and MCP-compatible tools for enterprise knowledge management.

## Key Features
- Enterprise-grade RAG and Knowledge Graph engine with governed workflows
- Multi-format document ingestion (PDF, DOCX, XLSX, PPTX, CSV, HTML, Markdown) with async FIFO queue
- Hybrid retrieval combining vector search, metadata filters, lexical reranking, and graph context
- Workspace-scoped RBAC with fail-closed policies and two-tier human review gates
- MCP-compatible tools (Confluence connector, knowledge server, and graph explorer) for AI agent integration

## Why It Matters for RAG Builders
Nexus-KB provides a production-grade reference architecture for secure, auditable, and graph-aware RAG systems, critical for enterprise AI deployments requiring governance and scalability.
