## Summary
Lucidity is a personal AI assistant that manages tasks, projects, and notes locally while enabling agent-mediated communication between users' assistants. It integrates with existing AI subscriptions and emphasizes local-first, privacy-preserving workflows.

## Key Features
- Local-first task and project management with offline-first sync
- Agent-mediated communication between users' assistants with trust gradients
- Integration with existing AI subscriptions via MCP server
- Markdown-based notes vault with filesystem-native access
- Self-hostable with free and Pro tiers

## Why It Matters for RAG Builders
Lucidity enables secure, agent-mediated collaboration between users while keeping data local, making it essential for privacy-focused AI workflows and distributed agent ecosystems.
