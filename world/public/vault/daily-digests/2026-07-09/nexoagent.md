## Summary
Nexo Agent is a local-first AI agent desktop app and web console that integrates multi-session chat, model orchestration, persistent memory, local knowledge, scheduled tasks, and a shared browser session into a unified workspace. It supports both desktop and browser interfaces with shared sessions and state.

## Key Features
- Multi-session chat with streaming responses, conversation history, and tool-call traces
- OpenAI/Anthropic-compatible model orchestration via LangChain
- Built-in tools for shell commands, model sub-calls, scheduled tasks, memory recall, and shared browser operations
- AI Browser with DOM-first target resolution, CDP input events, and high-privilege scripting
- Persistent memory (daily, dream, script) in SQLite with embedding-backed recall and local Markdown knowledge base

## Why It Matters for RAG Builders
Nexo Agent provides a comprehensive local-first framework for building and deploying AI agents with persistent memory, multi-modal tooling, and shared browser automation, reducing integration overhead for RAG and AI stack builders.
