## Summary
IssueMe is a pi extension that enables LLM agents to manage GitHub issues natively through structured tools, syncing issues to a local JSON cache for efficient context retrieval and safe mutation operations.

## Key Features
- Repository-scoped GitHub issue management with 28+ agent tools for CRUD operations, labels, milestones, and Projects v2 integration
- Local JSON cache of open issues for efficient agent context retrieval without oversized tool outputs
- Safety-aware operations with explicit confirmations for destructive actions and bounded GitHub API requests
- Non-secret configuration UI and project-local skill integration for custom workflows
- Native GitHub API usage (REST/GraphQL) without CLI dependencies or shell execution

## Why It Matters for RAG Builders
IssueMe provides a secure, structured interface for LLM agents to interact with GitHub issues, enabling automated issue management workflows while maintaining safety and efficiency in AI-driven development pipelines.
