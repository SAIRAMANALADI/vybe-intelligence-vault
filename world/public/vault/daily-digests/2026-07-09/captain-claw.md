## Summary
Captain Claw is a self-hosted framework for orchestrating fleets of specialist AI agents with six distinct orchestration modes, a full agentic coding pipeline, and deterministic automation via Flows. It supports multi-model integration, persistent memory, and a shared virtual file system for collaborative agent workflows.

## Key Features
- Six orchestration modes (Agent Forge, Agent Council, Basna, Vatra, Code, Flight Deck) for diverse workflows
- Full agentic coding pipeline with plan → approval → build → independent review → triage → fix loop
- Persistent shared memory layers (6 tiers) and virtual file system for cross-session collaboration
- Quality Profiles and Run-Cost Accounting for cost transparency and model optimization
- 31 ready-made specialist archetypes and 48 built-in tools per agent

## Why It Matters for RAG Builders
Captain Claw provides a robust, self-hosted platform for building and managing complex multi-agent AI systems, enabling scalable, deterministic, and cost-transparent agentic workflows essential for production-grade RAG applications.
