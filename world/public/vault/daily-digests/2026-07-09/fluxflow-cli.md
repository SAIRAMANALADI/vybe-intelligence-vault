## Summary
Flux Flow is an autonomous terminal-based AI agent built with Node.js and Ink, offering a React-powered CLI interface for interactive coding, file management, and document generation. It supports multiple AI providers and integrates with VS Code for enhanced IDE collaboration.

## Key Features
- Multi-provider AI model support (Google GenAI, DeepSeek, OpenRouter, NVIDIA)
- VS Code extension with real-time error detection and fixes
- Autonomous project alignment via project-specific instructions (Agent.md, Skills.md)
- Dual-model architecture with primary agent and background 'Janitor' model
- Transaction-based file snapshots for instant rollback and codebase time travel

## Why It Matters for RAG Builders
Flux Flow provides a highly interactive, autonomous AI agent framework that bridges terminal and IDE workflows, enabling seamless code generation, debugging, and document engineering for RAG builders.
