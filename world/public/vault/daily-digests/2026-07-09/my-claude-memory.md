## Summary
A hierarchical memory management system for AI programming assistants that enables cross-session, cross-project, and cross-machine persistence of project and personal knowledge. Implemented in pure Bash with zero external dependencies, it structures memories into four layers (L1-L4) for efficient retrieval and context injection.

## Key Features
- Four-layer memory model (L1-L4) for structured knowledge storage and retrieval
- Pure Bash implementation with zero external dependencies (Python optional for compatibility)
- Incremental synchronization using SHA-256 hashing to track file changes
- Cross-platform support (Linux, macOS, Windows via Git Bash/WSL)
- Automatic AI-driven content condensation (L3) with YAML frontmatter metadata
