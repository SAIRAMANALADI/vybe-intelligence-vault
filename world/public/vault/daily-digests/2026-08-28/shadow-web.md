## Summary
Shadow Web is a Python SDK and MCP toolkit designed to compress and extract structured data from web pages, particularly those with Shadow DOM, for AI agents. It reduces token usage by up to 99% while preserving interactive elements, tables, forms, and lists in clean JSON format.

## Key Features
- Shadow DOM flattening for AI agents without browser limitations
- Up to 99% token reduction from raw HTML via compression and selective extraction
- SchemaSnap for parsing tables, forms, and lists into clean JSON structures
- Standalone agent loop (`shadow-web exec`) for one-command browsing tasks
- Security surface scanning for forms, headers, and cookies (non-pentest)

## Why It Matters for RAG Builders
Shadow Web enables AI agents to efficiently process web pages by drastically reducing token costs while preserving critical interactive elements and structured data, making it essential for RAG pipelines that rely on web content.
