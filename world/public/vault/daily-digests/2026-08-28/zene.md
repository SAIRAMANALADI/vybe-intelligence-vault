## Summary
Zene is a self-healing AI coding engine that provides a cloud-based console for managing AI agents, with a Rust-based `zene` binary implementing the Agent Client Protocol (ACP) for local and cloud-based agent interactions. It supports multi-user control, GitHub integration, and sandboxed execution environments.

## Key Features
- Cloud Console UI for managing AI agents and workers with real-time ACP support
- Sandboxed execution environments with configurable profiles (workspace, read-only, strict, custom)
- Agent Client Protocol (ACP) binary for local and cloud-based agent interactions
- Multi-provider LLM support (OpenAI, Anthropic) with BYOK (Bring Your Own Keys) configuration
- Hooks and lifecycle management for pre/post tool execution with JSON-based stdin/stdout communication

## Why It Matters for RAG Builders
Zene provides a robust framework for building and deploying AI agents with sandboxed execution, multi-provider LLM support, and cloud-based management, making it essential for RAG builders who need secure, scalable, and configurable agent systems.
