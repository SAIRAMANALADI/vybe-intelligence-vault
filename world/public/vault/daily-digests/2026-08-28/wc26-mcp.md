## Summary
A Model Context Protocol (MCP) server providing comprehensive, static World Cup 2026 data for AI assistants and clients. Offers 18 tools for matches, teams, venues, city guides, fan zones, visa info, and more, with zero external API dependencies.

## Key Features
- 18 specialized tools for World Cup 2026 data (matches, teams, venues, etc.)
- Zero external API dependencies; all data bundled with the package
- Works with major MCP clients (Claude, ChatGPT, Cursor, Windsurf, Telegram)
- Supports timezone conversion and localized queries
- Includes fan zones, visa info, injuries, odds, and historical matchups
