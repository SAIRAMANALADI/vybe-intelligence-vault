## Summary
skill-fuse is a tool that consolidates overlapping AI agent commands (e.g., Claude Code slash commands, Cursor rules, or Windsurf cascades) into a single unified command to reduce context overhead and misfires. It merges multiple SKILL.md files into one composable skill for AI coding agents.

## Key Features
- Merges overlapping AI agent commands (e.g., /shape + /audit) into a single unified command
- Reduces prompt budget and token usage by deduplicating system prompts
- Works with multiple AI agents (Claude Code, Cursor, Windsurf, Codex, Gemini CLI)
- Zero-dependency design using only Bash and Markdown
- Generates human-readable fused SKILL.md files for review and sharing

## Why It Matters for RAG Builders
It streamlines AI agent workflows by eliminating command clutter and reducing prompt bloat, making AI tools more efficient and user-friendly for developers.
