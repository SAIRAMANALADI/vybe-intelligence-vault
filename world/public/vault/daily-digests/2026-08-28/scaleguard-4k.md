## Summary
ScaleGuard-4K is a high-resolution image restoration agent that intelligently controls multi-scale super-resolution by evaluating quality gains, cross-scale consistency, and observation fidelity at each step. It prevents hallucinations and structural drift in recursive generative upscaling by enforcing deterministic decision gates.

## Key Features
- Three-gate decision system (quality gain, cross-scale consistency, observation fidelity) for controlled upscaling
- Explicit scale state management with rollback/stop/continue logic
- Integration with 4KAgent and Chain-of-Zoom for hybrid restoration and generative upscaling
- Deterministic threshold calibration and reproducibility via SHA-256 binding
- CPU/mock-verified pipeline with strict contract enforcement and evidence tracking
