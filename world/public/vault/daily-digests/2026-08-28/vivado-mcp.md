## Summary
A lean MCP server enabling AI agents like Claude Code and Cursor to safely drive local Xilinx Vivado installations. It provides 30 curated tools, 8 evidence-driven workflows, and supports GUI, Tcl, and attach session modes for FPGA development workflows.

## Key Features
- 30 curated MCP tools covering synthesis, implementation, timing analysis, and bitstream generation
- 8 evidence-driven workflows for structured FPGA development processes
- Three session modes: GUI, Tcl, and attach for flexible integration
- Structured diagnostics including critical warning parsing with Chinese repair suggestions
- Offline introspection tools (parse_xpr, parse_bit_header, parse_ltx) for CI/CD pipelines

## Why It Matters for RAG Builders
It bridges AI agents with local FPGA toolchains, enabling automated and intelligent hardware design workflows while reducing manual intervention and token overhead.
