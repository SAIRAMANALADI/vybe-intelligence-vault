## Summary
Wisp Science is an open-source, local-first desktop AI research assistant and scientific computing workbench. It integrates OpenAI-compatible and Anthropic models with persistent Python/R environments, MCP servers for bioinformatics databases, and cross-platform desktop or headless CLI functionality.

## Key Features
- Persistent Python/R runtime environments across local, SSH, WSL, and GPU compute
- Bundled Model Context Protocol (MCP) servers for ~80 bioinformatics databases
- Reusable Agent Skills (SKILL.md) with 29 pre-built science workflows
- Cross-platform desktop app (Windows/macOS/Linux) or headless CLI
- Project synchronization, encrypted snapshots, and ACP agent integration

## Why It Matters for RAG Builders
Wisp Science provides a unified, local-first platform for AI-driven scientific research, enabling seamless integration of models, tools, and data pipelines while ensuring reproducibility and cross-platform compatibility.
