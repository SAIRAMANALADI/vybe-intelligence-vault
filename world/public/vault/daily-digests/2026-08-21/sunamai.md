## Summary
Sunam is an open-source AI programming assistant that runs entirely in the browser, providing an isolated development environment with terminal, file system, and service preview capabilities via WebContainer. It communicates with LLMs through OpenAI-compatible Chat Completions API and supports structured agent workflows, multi-session isolation, and real-time file operations.

## Key Features
- Browser-native AI agent with terminal, file system, and service preview in a single interface
- Supports OpenAI-compatible Chat Completions API with configurable endpoints and models
- Agent Core v2 with structured tool scheduling, multi-session/container isolation, and real-time validation
- Built-in file operations (upload, edit, move, preview) and versioned local data storage
- Multi-language UI (Chinese, English, Japanese) and PWA support for offline access

## Why It Matters for RAG Builders
Sunam enables developers to build and test AI-driven coding workflows entirely in the browser, reducing setup complexity while providing a secure, isolated environment for agent-based development.
