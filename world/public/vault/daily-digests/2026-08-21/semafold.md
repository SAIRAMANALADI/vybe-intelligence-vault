## Summary
semafold is a Windows-native tool for compressing vectors using TurboQuant codecs, enabling efficient storage and retrieval of embeddings, KV-cache, and other vector data with significant size reduction while maintaining performance.

## Key Features
- Compresses vectors using TurboQuant codecs for 10x smaller storage
- Supports pure NumPy core for CPU execution on Windows
- Optional GPU acceleration via PyTorch CUDA, MPS, or MLX
- Optimized for embeddings, retrieval, and KV-cache workflows
- Lightweight and easy to deploy on Windows systems
