## Summary
SwarmMesh provides a shared context and memory layer for parallel AI agents, enabling independent processes to read and write state over a simple HTTP/WebSocket protocol. It supports interoperability between Python and Node.js agents without requiring shared filesystems or processes.

## Key Features
- Documented HTTP/WebSocket protocol for cross-language agent communication
- Dual Python and Node.js implementations with identical behavior and interoperability
- Real-time state updates via WebSocket events for reactive agent behavior
- Pluggable storage backends (in-memory or SQLite) with persistence support
- Honest keyword-based memory search using Okapi BM25 with extensible ranking backends

## Why It Matters for RAG Builders
SwarmMesh eliminates redundant work and coordination overhead in multi-agent systems by providing a lightweight, shared state layer that any HTTP-capable agent can use.
