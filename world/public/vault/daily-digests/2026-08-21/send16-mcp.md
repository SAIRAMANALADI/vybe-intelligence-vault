## Summary
A Model Context Protocol (MCP) server for Send16 that provides AI agents with 79 tools to send emails, manage contacts, automations, and deliverability features. It includes a zero-DNS sandbox sender for immediate email delivery without domain setup.

## Key Features
- 79 tools for email, contacts, automations, and webhooks via MCP
- Zero-DNS sandbox sender for immediate email delivery
- Supports Claude, Cursor, and other MCP clients
- Self-hostable via Docker or npx for local/remote use
- Multi-tenant HTTP mode for serving multiple users

## Why It Matters for RAG Builders
It enables AI agents to seamlessly integrate email functionality into workflows without complex setup, accelerating RAG and agent-based applications.
