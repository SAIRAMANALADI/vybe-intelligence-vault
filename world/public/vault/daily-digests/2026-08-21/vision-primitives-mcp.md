## Summary
A lightweight MCP server that bridges text-only LLMs with vision capabilities, enabling 30+ tools for object localization, OCR, UI parsing, anomaly scanning, and computer control. Supports multiple VLM backends (MiMo, Qwen2.5-VL) and prioritizes high generalization with pluggable accelerators.

## Key Features
- 30+ MCP tools for vision tasks (localization, OCR, UI parsing, anomaly scanning)
- Pluggable VLM backends (MiMo, Qwen2.5-VL, GLM-4v-flash) with fallback mechanisms
- Programmatic image cropping/zooming for high-precision text and object detection
- Computer control tools (screen capture, mouse/keyboard automation) for GUI interaction
- ZeroBench benchmarking workflow for evaluating vision reasoning capabilities

## Why It Matters for RAG Builders
It enables text-only LLMs to perform complex vision tasks without specialized grounding models, bridging the gap between pure text and multimodal AI systems.
