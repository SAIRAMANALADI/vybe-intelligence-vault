## Summary
YUZU is a voice journaling app backend that records raw, unedited speech as immutable records. It provides API routes for Next.js, Supabase migrations, and an MCP server to support the iOS-native voice journaling application.

## Key Features
- Records raw, unedited voice input as immutable records
- Provides Next.js API routes for backend functionality
- Integrates Supabase for database and migration management
- Includes an MCP server for extended functionality
- Designed for iOS-native app integration
