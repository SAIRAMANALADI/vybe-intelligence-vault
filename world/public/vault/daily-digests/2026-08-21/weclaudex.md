## Summary
WeClaudex bridges WeChat with local Claude Code and Codex agents, enabling remote task execution, multi-modal input handling, and resumable sessions directly from a mobile device. It provides secure workspace isolation, persistent task queues, and explicit artifact delivery controls.

## Key Features
- Dual-agent support (Claude Code and Codex) with native session resumption across restarts
- Multi-modal input handling (text, images, files, voice, video) with persistent context
- Secure workspace isolation with configurable access modes (read-only, workspace, full)
- Durable task queues with at-least-once delivery and explicit retry mechanisms
- Explicit artifact delivery via `/send` command to prevent unintended file exposure

## Why It Matters for RAG Builders
WeClaudex enables secure, remote control of local AI coding agents through WeChat, bridging mobile convenience with desktop development workflows while maintaining strict security and session persistence.
