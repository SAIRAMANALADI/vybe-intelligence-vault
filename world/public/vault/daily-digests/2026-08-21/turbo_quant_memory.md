## Summary
Turbo Quant Memory is a local-first MCP server that provides persistent, structured memory and knowledge graph capabilities for AI coding agents, reducing token usage by up to 60% while enabling long-term context retention and structured associations between code, decisions, and tasks.

## Key Features
- Hybrid BM25 + vector search for efficient retrieval with RRF fusion
- Dynamic knowledge graph with aging, unlinking, and auto-diagnostics for stale context detection
- Tiered memory architecture (durable, episodic, reference) to filter noise
- Secrets vault for secure, project-scoped storage of sensitive data
- Multilingual support with opt-in language-specific stemmers and Unicode-aware tokenization

## Why It Matters for RAG Builders
Turbo Quant Memory is essential for RAG builders because it provides a persistent, structured, and cost-efficient memory layer that enables AI agents to retain long-term context, reducing token waste and improving decision-making without manual re-explanation.
