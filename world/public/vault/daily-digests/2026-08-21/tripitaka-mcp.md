## Summary
An MCP server providing AI agents with access to the Pāli Tipiṭaka (Buddhist canon) for searching, citing, and comparing translations across languages. Offers hybrid search, semantic analysis, and dictionary lookups for academic and research use.

## Key Features
- Full Tipiṭaka coverage (~444K segments) with hybrid search (keyword + semantic via RRF)
- Cross-language translation comparison and Pāli word analysis with dictionary lookups
- Dual transport support (SSE and Streamable HTTP per MCP spec)
- Hosted and local deployment options with privacy-conscious design
- Ready-to-use tools for AI agents (e.g., Claude) with deep-linking to source verification

## Why It Matters for RAG Builders
It enables AI agents to accurately search, cite, and analyze Buddhist canonical texts with semantic precision, bridging language gaps and providing verifiable sources for RAG applications.
