## Summary
A Model Context Protocol (MCP) server that generates skill manifests from GitHub repositories and recommends repository-specific AI agent skills. It supports both stdio and HTTP runtime modes for seamless integration into AI workflows.

## Key Features
- Generates skill manifests from GitHub skills directories with recursive or non-recursive scanning
- Provides MCP tools for fetching manifests, downloading skills, and suggesting capabilities
- Supports both stdio and HTTP runtime modes for flexible deployment
- Includes security scanning via NVIDIA SkillSpector for risk assessment
- Offers prebuilt official and community skill manifests for immediate use

## Why It Matters for RAG Builders
It streamlines the discovery and integration of AI agent skills from GitHub repositories, enabling RAG builders to enhance agent capabilities with minimal setup.
