## Summary
A web-based tool that converts SQL CREATE TABLE statements and DBML code into Chen model ER diagrams. It operates entirely in the browser, requiring no login or payment, and offers features like drag-and-drop node adjustment, smart layout optimization, and generation history tracking.

## Key Features
- Pure frontend tool with no backend dependencies or login requirements
- Supports both SQL CREATE TABLE and DBML input formats
- Interactive ER diagram generation with drag-and-drop node adjustment
- Smart layout optimization for complex diagrams
- Generation history with local storage persistence via IndexedDB

## Why It Matters for RAG Builders
It provides a free, open-source alternative for converting SQL/DBML to visually appealing ER diagrams without requiring login or payment, streamlining database design workflows for AI engineers.
