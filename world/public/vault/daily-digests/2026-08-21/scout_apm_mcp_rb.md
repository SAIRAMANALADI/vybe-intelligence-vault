## Summary
A Ruby gem providing a ScoutAPM API client and MCP (Model Context Protocol) server tools for fetching traces, endpoints, metrics, errors, and insights. It integrates with MCP-compatible clients like Cursor IDE and Claude Desktop for AI-driven observability and debugging.

## Key Features
- Full-featured ScoutAPM API client for fetching traces, metrics, errors, and insights
- MCP server integration for seamless use with Cursor IDE, Claude Desktop, and other MCP-enabled tools
- Secure API key management via environment variables or 1Password integration
- Comprehensive error handling and custom exception classes for robust debugging
- Helper methods for URL parsing, time formatting, and data extraction

## Why It Matters for RAG Builders
This gem enables AI-driven observability and debugging by exposing ScoutAPM data via the MCP protocol, allowing AI assistants to interactively query and analyze application performance metrics.
