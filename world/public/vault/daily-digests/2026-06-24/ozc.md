## Summary
OZC provides a decentralized, user-controlled trust layer for AI systems by allowing individuals to allocate finite resources (OZC tokens) to information sources they deem trustworthy. It leverages blockchain-based market dynamics to visualize collective convictions and filter AI inputs transparently.

## Key Features
- Decentralized trust scoring for URLs and claims via OZC token allocations
- Bonding curve mechanism to reward early adopters and penalize late backers
- Integration options via Python SDK, REST API, MCP server, and CLI tools
- On-chain visibility of collective convictions (totalBacked metric per entry)
- Local devnet and Base Mainnet deployment support for flexibility

## Why It Matters for RAG Builders
OZC empowers AI builders to decentralize trust decisions, ensuring AI systems prioritize user-vetted information over centralized authority biases.
