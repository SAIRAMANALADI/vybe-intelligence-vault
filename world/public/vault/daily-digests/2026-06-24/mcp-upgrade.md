## Summary
mcp-upgrade is a Windows-based tool designed to automate the update process for Model Context Protocol (MCP) servers used by AI coding assistants. It scans, updates, and maintains AI tools to ensure security, performance, and compatibility across platforms like Cursor, Windsurf, and Claude.

## Key Features
- Automated scanning and updating of MCP servers
- Cross-platform support for major AI coding clients (Cursor, Windsurf, Claude)
- Backup and restore functionality for configuration files
- Automatic scan toggle and update notifications
- One-click update process for all installed tools
