## Summary
A CLI tool that transforms any LLM into an autonomous GUI automation agent, enabling it to perform desktop tasks like clicking, typing, and verifying results through iterative visual grounding and action execution.

## Key Features
- Iterative zoom-based GUI element grounding for precise coordinate prediction
- Multi-source perception pipeline (YOLO detection, OCR, visual memory templates)
- Visual memory system for caching and reusing UI component templates
- Agent loop with observe-verify-plan-dispatch phases for full task automation
- Cross-platform support (macOS, Windows, Linux) with platform-specific optimizations

## Why It Matters for RAG Builders
It enables LLMs to autonomously interact with desktop environments, bridging the gap between natural language and GUI operations for real-world automation tasks.
