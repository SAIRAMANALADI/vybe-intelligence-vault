## Summary
A JetBrains Rider plugin that extends the built-in MCP Server to provide Unity Editor control tools for coding agents. Enables remote execution of Unity tests, editor scripts, compilation checks, and play mode control without per-project MCP server setup.

## Key Features
- Zero-configuration Unity Editor control via MCP tools for coding agents
- Supports running Unity tests (Edit/Play Mode), editor scripts, and play mode operations
- Integrates with JetBrains Rider's built-in MCP Server for seamless agent workflows
- Handles domain reloads and transient states to prevent MCP transport failures
- Provides detailed test execution results and compilation diagnostics

## Why It Matters for RAG Builders
It enables coding agents to directly interact with Unity Editor for testing and automation, reducing manual setup and accelerating AI-driven Unity development workflows.
