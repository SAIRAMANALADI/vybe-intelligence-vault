## Summary
A Model Context Protocol (MCP) server that enables AI agents to query and analyze FCC broadband data for U.S. census blocks, providing internet coverage, provider availability, and speed details. It acts as a bridge between AI systems and official FCC records.

## Key Features
- Queries FCC broadband data via MCP for real-time coverage analysis
- Supports precise location-based searches (addresses or census blocks)
- Provides provider availability and speed details for any U.S. region
- Local execution ensures privacy with no data tracking or storage
- Integrates seamlessly with AI agents for contextual RAG applications

## Why It Matters for RAG Builders
