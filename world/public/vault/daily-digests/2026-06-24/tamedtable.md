## Summary
TamedTable is a CLI and web-based ETL tool that transforms CSV data using natural language commands. Users input a CSV file and describe transformations like 'normalize phone numbers' or 'drop duplicate emails,' and the system generates a JSON spec that the runtime applies to the data.

## Key Features
- Natural language-driven data transformations via CLI or web UI
- JSON spec generation for reproducible ETL workflows
- Supports batch and interactive modes with configurable LLM models
- Browser-based web app with no server-side processing
- Comprehensive testing with cassette-based replay for offline validation

## Why It Matters for RAG Builders
TamedTable simplifies data transformation workflows by enabling non-technical users to manipulate CSV data using natural language, reducing the need for manual scripting or complex ETL pipelines.
