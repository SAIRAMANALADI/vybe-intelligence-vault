## Summary
Wicek is a lightweight Node.js application that transforms a Discord bot into a task-focused AI assistant using the Claude Agent SDK. It replaces a complex Kubernetes operator with a minimal, maintainable solution for Discord-based AI interactions.

## Key Features
- Discord integration with DMs, @mentions, and threaded conversations
- Claude Agent SDK for streaming AI responses with tool use and thinking blocks
- Browser automation via headless Chrome for screenshots and web interactions
- Cron jobs for scheduled prompts and GitOps-defined updates
- Custom subagents for specialized tasks like ETF analysis and infrastructure ops

## Why It Matters for RAG Builders
Wicek demonstrates how to integrate a high-performance AI agent (Claude Code) into a lightweight, maintainable Discord bot framework, offering a lean alternative to bloated multi-feature platforms for focused use cases.
