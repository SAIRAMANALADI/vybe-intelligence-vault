## Summary
statelessagent is a privacy-focused desktop application that enables local-first AI interactions without storing chat history between sessions. It allows users to run AI models offline, leveraging local files for context while ensuring complete data privacy.

## Key Features
- Runs entirely offline with no cloud dependency
- Clears all session data upon app closure for privacy
- Supports multiple local AI models without API keys
- Integrates with local files for contextual responses
- Single-file download with minimal setup required
