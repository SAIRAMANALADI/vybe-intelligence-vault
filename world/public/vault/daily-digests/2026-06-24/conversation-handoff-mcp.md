## Summary
MCP server enabling seamless transfer of conversation context between AI chats or different projects within the same AI. It preserves full conversation history, supports tagging, merging, and interactive UI for managing handoffs.

## Key Features
- Auto-connect and auto-reconnection for seamless MCP client integration
- Tagging and search functionality for structured handoff discovery
- Memory-based storage with FIFO cleanup for lightweight operation
- Interactive MCP Apps UI for browsing and managing handoffs
- Support for merging multiple handoffs into unified context

## Why It Matters for RAG Builders
It enables AI workflows to maintain continuity across sessions and projects by preserving full conversation context without manual copy-paste.
