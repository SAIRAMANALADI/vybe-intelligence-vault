## Summary
A TypeScript-based client that bridges official Spanish weather data from the AEMET OpenData API to local AI tools via a Model Context Protocol (MCP) server. It provides real-time weather conditions, forecasts, and radar maps for integration into AI assistants like Claude or Cursor.

## Key Features
- Fetches real-time Spanish weather data from official AEMET sources
- Provides a local MCP server for seamless AI tool integration
- Supports caching to reduce API load and improve performance
- Runs locally with no third-party tracking or data collection
- Offers radar maps, forecasts, and current conditions for any Spanish region

## Why It Matters for RAG Builders
It enables AI tools to access real-time, high-quality Spanish weather data locally, enhancing contextual accuracy for applications requiring meteorological insights.
