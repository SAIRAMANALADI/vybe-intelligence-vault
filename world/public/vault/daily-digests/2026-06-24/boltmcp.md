## Summary
BoltMCP is a Kubernetes-native tool designed to simplify the installation and management of MCP (Model Context Protocol) servers using Helm charts. It enables seamless integration of MCP servers with AI workflows via Claude Code or manual installation.

## Key Features
- Single-command Helm chart installation for MCP servers on Kubernetes
- Integration with Claude Code for guided installation and management
- Support for manual installation via web-based installer
- Access key management for secure MCP server deployment
- Simplified lifecycle management (install, update, uninstall)

## Why It Matters for RAG Builders
BoltMCP streamlines the deployment of MCP servers, which are critical for enhancing AI models with external tools and data sources in RAG systems.
