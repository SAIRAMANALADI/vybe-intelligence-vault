## Summary
A Windows desktop application that converts static slide images into fully editable PowerPoint (.pptx/.ppt) files, enabling users to modify text, shapes, and images locally without requiring original presentation files.

## Key Features
- Batch processing of multiple slide images into a single editable presentation
- Preserves original slide aspect ratio and layout during conversion
- Local OCR-based text extraction for direct editing in PowerPoint
- Supports .pptx and .ppt export formats
- No internet connection or cloud upload required for processing
