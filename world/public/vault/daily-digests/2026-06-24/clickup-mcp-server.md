## Summary
A high-performance Model Context Protocol (MCP) server that enables AI agents and workflows to interact with ClickUp's project management features, including tasks, comments, time tracking, docs, and workspace management via natural language.

## Key Features
- Full CRUD operations for tasks, comments, docs, and workspace hierarchies (spaces, folders, lists)
- Hybrid authentication with OAuth 2.1 and API key support for secure multi-tenant access
- Intelligent fuzzy search across tasks, lists, and custom fields with automatic resolution
- Time tracking, goals/OKRs, and task templates for streamlined workflows
- Multi-account support and seamless workspace switching mid-conversation

## Why It Matters for RAG Builders
It bridges AI agents with ClickUp's project management capabilities, enabling seamless task automation and natural language interactions for RAG and agentic workflows.
