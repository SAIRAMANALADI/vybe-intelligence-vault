## Summary
Alvus is a lightweight local proxy tool written in Go that rotates AI API keys to prevent rate limits and service blocks during AI agent tasks. It acts as a bridge between AI coding assistants and AI providers, managing key rotation seamlessly in the background.

## Key Features
- Rotates AI API keys automatically to avoid rate limits
- Acts as a local proxy for AI coding assistants (Aider, Cline, Cursor, etc.)
- Zero-dependency design with minimal resource consumption
- Supports any AI provider following standard communication rules
- Lightweight and fast with no complex setup required

## Why It Matters for RAG Builders
