## Summary
Principles Disciple is a local, agent-first governance and feedback layer for AI agents, designed to turn repeated agent failures, risky actions, and workflow mismatches into structured principles, decision logs, and owner-controlled guardrails. It operates as a runtime adapter layer, currently integrated with OpenClaw and planned for Codex CLI, enabling maintainer-reviewed behavior alignment without hard-coding to a single agent tool.

## Key Features
- Runtime adapter layer for multi-agent integration (OpenClaw, Codex CLI planned)
- Workspace guardrails blocking risky edits until principles are reviewed and approved
- Pain-signal capture and structured evidence collection for agent behavior improvement
- Replay-based review workflow for validating and activating new principles or rules
- Local console for observing agent health, evolution activity, and decision logs

## Why It Matters for RAG Builders
It provides a critical local-first governance layer for AI agents, enabling maintainer-controlled alignment and reversible behavior changes without sacrificing agent autonomy.
