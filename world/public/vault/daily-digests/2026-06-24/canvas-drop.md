## Summary
canvas-drop is a self-hosted platform for deploying and sharing small web tools ('canvases') within an organization. It enables AI-built artifacts to be instantly deployed behind SSO with unguessable URLs, versioned storage, and a rich API for agents and automation.

## Key Features
- Instant deployment of canvases via drag-and-drop, API, or agent tools with unguessable URLs
- Five zero-config backend primitives: KV, files, AI, identity, and realtime communication
- Versioned, content-addressed storage with rollback and staged uploads for efficiency
- Agent-first workflows with MCP server, deploy API, and installable skills for automation
- Rich sharing ladder (private, team, org-wide) with auth delegation and admin governance

## Why It Matters for RAG Builders
It bridges the gap between AI-generated tools and secure, self-hosted deployment, enabling organizations to operationalize AI artifacts without vendor lock-in or security risks.
