## Summary
Wick is a Go-based framework and runtime for building internal tools, AI agents, and hosting LLM-powered assistants (Claude/Codex/Gemini) as Slack, Telegram, or web agents. It enables AI-assisted development by scaffolding real Go code for tools, jobs, and connectors, while also providing a binary for running LLM agents without coding.

## Key Features
- AI-assisted Go code scaffolding for tools, jobs, and connectors with real-time UI and runtime configuration
- Pre-built binary for deploying LLM agents (Claude/Codex/Gemini) as Slack, Telegram, or web assistants with no coding required
- Command Gate for secure Bash command execution with multi-mode approval (interactive, session-based, or always)
- Modular architecture supporting tools, jobs, connectors, and agents with MCP integration for LLM access
- Self-update mechanism with admin UI for version management and system monitoring

## Why It Matters for RAG Builders
Wick bridges the gap between AI-assisted development and agent deployment, enabling RAG builders to rapidly scaffold and deploy secure, audited AI tools and agents while maintaining full code ownership and control.
