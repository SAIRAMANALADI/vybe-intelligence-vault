## Summary
Cagecheck is a security tool designed to test and verify the effectiveness of sandbox environments by simulating escape attempts and checking for vulnerabilities in isolation boundaries like containers, VMs, and namespaces.

## Key Features
- Simulates sandbox escape attempts to test isolation boundaries
- Supports Windows 10/11 with administrator privileges
- Provides clear pass/fail/warning results for sandbox effectiveness
- Runs locally without requiring cloud services
- Includes best practices for regular security validation
