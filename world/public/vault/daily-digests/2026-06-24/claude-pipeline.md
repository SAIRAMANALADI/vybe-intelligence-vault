## Summary
claude-pipeline is a portable, no-code application for automating multi-agent task workflows, enabling users to orchestrate skills, agents, hooks, and quality checks without deep technical knowledge or complex setup.

## Key Features
- Pre-built agent skills for common tasks (e.g., file management, data processing)
- Visual pipeline configuration with drag-and-drop agent linking
- Quality gates to validate outputs and halt workflows on errors
- Cross-platform support (Windows/Linux) with minimal setup
- Hooks for triggering actions based on events (e.g., file updates)
