## Summary
A Claude Code plugin that automates the review of user interfaces against Apple's Human Interface Guidelines (HIG) for iOS, iPadOS, macOS, watchOS, tvOS, and visionOS projects. It provides actionable feedback to ensure native-like design consistency and accessibility compliance.

## Key Features
- Automated reviews of interface files for Apple HIG compliance
- Accessibility checks for text size, color contrast, and touch targets
- Platform-specific validation modes (visionOS, watchOS, macOS, etc.)
- SwiftUI code validation with real-time issue detection
- Design token support for consistent styling

## Why It Matters for RAG Builders
It streamlines the process of ensuring UI designs adhere to Apple's standards, reducing manual review time and improving consistency for cross-platform Apple applications.
