## Summary
ClaudeUsageBar is a macOS menu bar application that monitors and displays your remaining Claude AI Pro message limits locally, preventing unexpected interruptions by alerting you when you approach or exceed your usage threshold.

## Key Features
- Real-time tracking of Claude AI Pro message limits directly in the macOS menu bar
- Visual color-coded alerts (green, yellow, red) for remaining capacity
- Local execution with no data sent to external servers, ensuring privacy
- Automatic refresh every 5 minutes to keep usage data current
- Customizable alert thresholds for personalized monitoring

## Why It Matters for RAG Builders
It provides a critical local monitoring solution for developers using Claude AI Pro to avoid unexpected rate limit interruptions during workflows.
