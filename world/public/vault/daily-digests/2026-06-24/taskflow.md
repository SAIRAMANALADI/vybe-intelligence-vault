## Summary
taskflow is a desktop application designed to simplify and accelerate document processing tasks such as summarization, classification, and named entity recognition using advanced AI models. It emphasizes cost-efficiency and high-speed processing for large volumes of documents.

## Key Features
- Cost-effective document processing at $0.0005 per document
- Handles over 100,000 documents per hour with high speed
- User-friendly interface requiring no technical expertise
- Supports multiple processing options (summarization, classification, NER)
- Cross-platform compatibility (Windows, macOS, Linux)
