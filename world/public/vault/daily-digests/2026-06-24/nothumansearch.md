## Summary
Not Human Search is a specialized search engine that indexes and ranks websites based on their agentic readiness for AI systems, using machine-readable signals like llms.txt, OpenAPI, and MCP servers. It provides an API and MCP server for AI agents to discover and interact with agent-friendly sites.

## Key Features
- Ranks sites by agentic readiness (7 signals including llms.txt, OpenAPI, MCP servers)
- Provides MCP server for direct integration with AI agents (Claude, etc.)
- Offers HTTP API for programmatic search and site submission
- Continuously refreshes index via daily recrawl and weekly auto-discovery
- Includes live scoring tool to evaluate any URL's agent-friendliness

## Why It Matters for RAG Builders
It enables AI agents to efficiently discover and interact with agent-friendly websites, reducing reliance on human-like browsing and improving automation capabilities.
