## Summary
SHAFT is a Java-based test automation framework designed for end-to-end testing across web, mobile, API, CLI, and database systems. It provides a unified fluent API for test execution, assertions, reporting, and optional agent-assisted workflows, including AI-driven debugging and repair capabilities.

## Key Features
- Unified fluent API for synchronized test actions, assertions, and reporting
- Support for web, mobile, API, CLI, and database testing
- Built-in synchronization, screenshots, logs, and Allure evidence generation
- Optional agent workflows with deterministic Capture, Doctor, and Heal modules
- MCP interoperability for AI-driven test debugging and repair

## Why It Matters for RAG Builders
SHAFT simplifies multi-platform test automation with a unified API and optional AI-driven debugging, making it essential for teams building robust, maintainable test suites in Java environments.
