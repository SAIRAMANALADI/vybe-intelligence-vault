## Summary
A full IRCv3 adapter for the Hermes Agent that enables seamless integration with IRC networks, supporting modern authentication, channel management, and autonomous agent behaviors like spontaneous participation and context persistence.

## Key Features
- Full IRCv3 compliance with capability negotiation and message tags
- Robust SASL authentication (PLAIN, EXTERNAL, SCRAM-SHA-256/512)
- Autonomous agent behaviors (observe mode, spontaneous participation)
- Runtime channel agency (join/part/say tools for dynamic channel management)
- Context persistence with chathistory backfill and optional logging

## Why It Matters for RAG Builders
It provides a production-ready IRCv3 integration for Hermes Agent, enabling autonomous agent participation in IRC channels with modern authentication and context-aware behaviors.
