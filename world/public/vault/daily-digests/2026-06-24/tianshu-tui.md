## Summary
Rivet is a terminal-based coding agent that optimizes LLM interactions using prefix-cache techniques, multi-provider support, and subagent orchestration. It features a streaming TUI, goal-driven autonomy, and cross-session knowledge persistence for efficient AI-driven development workflows.

## Key Features

- Multi-provider adaptive routing with 6 supported LLM APIs
- Subagent orchestration with typed work orders and batch dispatch
- Goal-driven auto-continue for autonomous task execution
- Cross-session knowledge persistence and MCP integration
