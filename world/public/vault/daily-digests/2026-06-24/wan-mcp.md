## Summary
A Model Context Protocol (MCP) server providing focused access to RunAPI's Wan model line for AI agents, enabling image and video generation tasks, result polling, and pricing checks across 18 model variants.

## Key Features
- Direct integration with RunAPI's Wan model line via MCP for AI agents
- Supports 6 endpoints and 18 model variants for image/video generation
- Tools for task creation, status polling, and pricing checks
- Compatible with MCP hosts like Claude Code, Cursor, VS Code, and Windsurf
- Lightweight alternative to the full RunAPI MCP server for Wan-specific use cases

## Why It Matters for RAG Builders
It provides a streamlined MCP server for Wan-specific AI agent tasks, reducing overhead and enabling focused integrations for image and video generation workflows.
