## Summary
A Claude Code plugin that transforms instances into 24/7 autonomous AI assistants (hermits) capable of self-improvement, task orchestration, and proactive behavior. It enables persistent, cost-efficient, and observable AI agents that operate within user-defined guardrails and integrate with external channels like Discord or Telegram.

## Key Features
- Turns Claude Code sessions into persistent, 24/7 AI assistants with built-in self-management and state preservation
- Integrates with Discord, Telegram, or native channels for real-time notifications and bidirectional interaction
- Implements a learning loop that identifies inefficiencies, proposes fixes, and asks for user approval before applying changes
- Supports routines, watches, and heartbeat mechanisms for proactive task execution and idle-time optimization
- Provides cost tracking, observability tools, and guardrails to ensure safe and measurable autonomous operation
