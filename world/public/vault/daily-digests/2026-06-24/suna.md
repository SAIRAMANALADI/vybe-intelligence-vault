## Summary
Suna is a lightweight, local-first terminal AI agent and agent runtime designed for coding, research, automation, and developer workflows. It operates via a TUI interface with a local daemon handling model calls, tool execution, memory, and security policies.

## Key Features
- Dynamic model routing with Subtask delegation for optimal task execution
- Smart Mode Guard for contextual safety reviews before high-risk actions
- Lightweight memory system that adapts to user preferences over time
- Built-in local tools for file operations, HTTP requests, and command execution
- Modular architecture separating TUI, daemon, and agent logic for scalability

## Why It Matters for RAG Builders
Suna provides a robust, local-first framework for building AI agents with dynamic model routing, contextual safety, and developer-focused tooling, making it ideal for RAG stacks requiring secure, adaptable automation.
