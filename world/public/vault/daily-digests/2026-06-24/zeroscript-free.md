## Summary
ZeroScript-Free is a free browser extension that integrates with AI chat platforms (DeepSeek, Gemini, Kimi, GLM) to enable AI-driven automation in Roblox Studio. It acts as a bridge between AI agents and Roblox Studio, allowing users to control scripting, asset generation, and game development without writing code or using terminals.

## Key Features
- AI-driven Roblox Studio control via browser chat interfaces
- Supports multiple AI providers (DeepSeek, Gemini, Kimi, GLM)
- Reads/edits scripts, runs Luau code, and generates assets directly in Roblox Studio
- Project memory feature to retain context across sessions
- Integrated chat bar for seamless AI interaction without terminal or API keys

## Why It Matters for RAG Builders
It enables AI-powered automation for Roblox game development, reducing manual scripting effort and accelerating prototyping for AI stack builders.
