## Summary
UE-MCP is an MCP (Model Context Protocol) server that provides AI assistants with deep read/write access to Unreal Engine via 21 tool categories and 569+ actions, enabling natural language control over Blueprints, materials, levels, assets, animation, VFX, and more through a TypeScript/Node.js bridge and C++ plugin.

## Key Features
- 21 tool categories with 569+ actions for Unreal Engine manipulation
- YAML flow engine for multi-step workflows and custom tasks
- C++ bridge plugin for direct Unreal Editor integration
- Automated setup and configuration via CLI
- Comprehensive documentation and demo projects
