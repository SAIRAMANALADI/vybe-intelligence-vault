## Summary
Metagit CLI is a command-line tool that provides situational awareness across multiple Git repositories by capturing cross-repository relationships, dependencies, and project knowledge in version-controlled manifests. It helps developers, SREs, and AI agents manage multi-repo projects efficiently.

## Key Features
- Cross-repository dependency tracking and visualization
- Version-controlled project manifests (.metagit.yml)
- Agent skills integration (OpenClaw, Hermes, Claude Code)
- Context session management for AI agents (MCP support)
- Incremental workspace event feeds for real-time updates

## Why It Matters for RAG Builders
Metagit CLI streamlines multi-repo project management for AI agents by providing structured, version-controlled context and dependency tracking, reducing cognitive load and improving workflow efficiency.
