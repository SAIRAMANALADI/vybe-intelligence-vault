## Summary
A Claude Code/AI Agent skill that converts AI-generated Markdown documents into polished Word (.docx) files with full support for Mermaid diagrams, ASCII art, tables, and code blocks. It automates the final step of transforming AI outputs into production-ready documents for platforms like Feishu, DingTalk, or Tencent Docs.

## Key Features
- Automated conversion of AI-generated Markdown to Word with zero manual intervention
- Supports Mermaid diagrams, ASCII art, tables, and code blocks with high fidelity
- Integrates seamlessly with Claude Code via a dedicated skill for one-click execution
- Fixes common formatting issues (tables, lists, code blocks) that break Pandoc or Feishu CLI
- Generates production-ready Word documents compatible with Feishu, DingTalk, and Tencent Docs
