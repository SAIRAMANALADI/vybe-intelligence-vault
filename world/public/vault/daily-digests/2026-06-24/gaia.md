## Summary
Gaia is an AI agent framework that autonomously builds and manages specialist subagents ('souls') to handle tasks, improving over time with usage. It supports multi-platform interaction via Telegram, WhatsApp, or terminal, and integrates memory and long-running job execution.

## Key Features
- Autonomous subagent ('soul') creation and management for task specialization
- Persistent memory for user and task context retention over time
- Multi-platform support (Telegram, WhatsApp, terminal)
- Long-running job execution with background processing
- Modular architecture with pluggable connectors and integrations
