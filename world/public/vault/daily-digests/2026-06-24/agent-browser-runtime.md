## Summary
agent-browser-runtime provides a managed environment for AI agents to run browser automation tasks with isolated Chrome sessions, persistent profiles, and tab groups. It enables secure, separate browser environments for agents while allowing human intervention for complex tasks like logins or CAPTCHAs.

## Key Features
- Isolated Chrome browser profiles for each agent to prevent interference
- Tab group management for organizing agent tasks
- Live monitoring and control of agent browser sessions
- Human handoff for handling logins, CAPTCHAs, or 2FA
- Automatic update checks and session persistence

## Why It Matters for RAG Builders
It provides a stable, isolated environment for AI agents to perform reliable browser automation without disrupting personal browsing or other agents.
