## Summary
ElBot is a lightweight, token-efficient Agent/Chatbot framework written in Go, designed to minimize operational and context costs while maintaining extensibility. It supports chat, tool calling, long-term task scheduling, persistent sessions, and event-driven automation for personal assistants and orchestratable bots.

## Key Features
- Ultra-lightweight Go implementation with <10ms startup time and ~30MB memory usage
- Token-efficient tool discovery and context compaction to reduce overhead
- Dual chat/work modes for cost-effective and complex task handling
- Extensible Hook system for custom logic at key event points
- Elnis event perception system for external signal integration

## Why It Matters for RAG Builders
ElBot provides a cost-efficient, extensible framework for building AI agents with minimal context overhead and robust event-driven automation capabilities.
