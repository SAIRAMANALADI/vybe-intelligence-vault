## Summary
A local MCP server that converts text or code into academic-quality flowcharts using Graphviz, designed to integrate with the Claude AI assistant for visualizing workflows, processes, or complex ideas directly on the user's machine.

## Key Features
- Converts text or code into academic-quality flowcharts using Graphviz
- Integrates with Claude AI via Model Context Protocol (MCP) for seamless diagram generation
- Runs locally for enhanced speed, privacy, and offline capability
- Supports SVG output for high-quality, scalable diagrams
- Configurable styles and layouts via simple text-based configuration

## Why It Matters for RAG Builders
It enables AI-driven workflows to generate visual diagrams dynamically, improving clarity and documentation for complex processes in RAG applications.
