## Summary
Team Agent is a multi-agent runtime that enables parallel execution of autonomous agents (teammates) under a lead agent, all orchestrated through natural language commands in a single CLI session. It extends tools like Claude Code, Codex CLI, or Copilot CLI to allow collaborative, persistent teamwork without manual configuration.

## Key Features
- Natural language team building and management (no config files required)
- Persistent teammate roles with individual memory and direct communication
- Parallel execution of tasks across multiple CLIs (Claude, Codex, Copilot)
- State preservation for seamless continuation of work across sessions
- Lead agent handles orchestration and escalation, reducing user oversight

## Why It Matters for RAG Builders
It enables scalable, parallel multi-agent collaboration for complex AI-driven workflows, reducing manual oversight and accelerating project completion.
