## Summary
Galadriel is a self-hosted AI agent that combines a memory palace (verbatim, semantically searchable local storage) with self-modification capabilities, enabling it to remember past actions, edit its own code, and improve autonomously. It integrates with Anthropic's Claude API and includes tools for memory retrieval, ambient reflection, and lifecycle management.

## Key Features
- Verbatim, semantically searchable memory storage with zero API cost for retrieval
- Self-modification discipline enabling the agent to edit its own code and restart
- Ambient reflection and scheduled thinking loops for continuous learning
- One-shot wake capability to resume across process restarts
- Integration with MemPalace for structured knowledge graph and temporal reasoning

## Why It Matters for RAG Builders
Galadriel demonstrates how combining persistent memory with self-modification can create agents that autonomously improve over time, reducing human oversight and enabling continuous learning loops.
