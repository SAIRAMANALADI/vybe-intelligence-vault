## Summary
Socratic is a GitHub Learning Lab repository designed to automate knowledge synthesis for vertical LLM agents by converting unstructured data into structured, domain-specific knowledge bases. It leverages interactive GitHub issues and pull requests to guide users through learning and knowledge organization.

## Key Features
- Automates conversion of unstructured data into structured knowledge bases
- Uses GitHub issues and PRs for interactive learning and knowledge organization
- Integrates with reveal.js for presentation and visualization
- Designed for vertical LLM agents to enhance domain-specific knowledge
- Leverages GitHub's collaborative tools for knowledge sharing

## Why It Matters for RAG Builders
