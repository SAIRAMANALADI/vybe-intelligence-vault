## Summary
A structured repository of agent-readable skill files for the Internet Computer (ICP) ecosystem, designed to prevent AI hallucinations by providing machine-consumable instructions for IC capabilities. Skills are self-contained markdown files with YAML frontmatter, covering prerequisites, pitfalls, implementation, and deployment steps.

## Key Features
- Structured, machine-readable skill files in markdown with YAML frontmatter for agent consumption
- Comprehensive sections including prerequisites, common pitfalls, implementation code, and deployment steps
- SHA-256 content hashing for change detection and differential sync of skills
- Built-in evaluation framework with LLM-as-judge scoring to validate agent outputs
- Community and DFINITY-maintained skills with a standardized discovery index

## Why It Matters for RAG Builders
