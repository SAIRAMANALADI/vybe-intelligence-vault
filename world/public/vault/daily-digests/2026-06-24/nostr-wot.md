## Summary
nostr-wot is a Web of Trust (WoT) framework for the Nostr protocol that enables trust-based filtering and identity verification through social connections. It provides tools for querying social graph distances between public keys, including a browser extension and an oracle API for server-side lookups.

## Key Features
- Social graph distance queries between Nostr public keys
- Browser extension for client-side trust verification
- Oracle API for server-side lookups and integrations
- Open-source and MIT licensed
- User-friendly interface for exploring trust relationships

## Why It Matters for RAG Builders
It enables trust-based filtering and spam reduction in Nostr applications by leveraging social connections, which is critical for building reliable AI-driven RAG systems on decentralized networks.
