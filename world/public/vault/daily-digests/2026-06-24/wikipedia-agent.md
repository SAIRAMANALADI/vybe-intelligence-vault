## Summary
wikipedia-agent is a local, offline tool for querying and reading Wikipedia articles without an internet connection. It leverages ZIM archives and vector embeddings to enable semantic search and full-text retrieval on modest hardware, prioritizing privacy and efficiency.

## Key Features
- Offline Wikipedia access via ZIM archives with no data transmission
- Semantic search using vector embeddings for contextual query understanding
- Hardware-efficient design for low-memory and low-power devices
- Local indexing and management of ZIM files for customizable knowledge bases
- Privacy-preserving architecture with no telemetry or external data sharing
