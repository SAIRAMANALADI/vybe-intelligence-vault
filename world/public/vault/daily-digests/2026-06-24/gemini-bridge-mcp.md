## Summary
A Model Context Protocol (MCP) server that bridges Google's free Gemini CLI and web UI to provide AI-powered tools like Q&A, web search, code analysis, image/video generation, and structured data extraction without requiring an API key.

## Key Features
- API-key-free access to Google Gemini via CLI and web UI
- Supports 15+ tools including web search, deep research, code analysis, and structured output
- Enables image and video generation via Nano Banana and Veo
- Configurable tool presets for tailored functionality
- Integrates seamlessly with MCP clients like Claude Code

## Why It Matters for RAG Builders
It eliminates the need for paid API keys while providing a comprehensive suite of AI tools for RAG pipelines and agent frameworks through a standardized MCP interface.
