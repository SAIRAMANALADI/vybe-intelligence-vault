## Summary
TaijiOS is an evidence-first reliability runtime for AI agents that converts agent runs into auditable evidence for verification, retry, recovery, and review. It enforces strict boundary definitions and system-state abstractions inspired by the I Ching to ensure robust, self-healing agent operations.

## Key Features
- Event-driven core with structured evidence chains for every agent run
- I Ching-inspired state machine for system behavior and boundary enforcement
- Multi-layer reliability mechanisms including circuit breakers, failover, and safe click execution
- Ising model-based heartbeat engine for dynamic system state tracking and adaptation
- Modular architecture with FastAPI gateway, agent system, and learning/rollback frameworks

## Why It Matters for RAG Builders
TaijiOS provides a critical framework for building auditable, self-healing AI agents by enforcing evidence-first principles and boundary-aware state management, essential for production-grade RAG systems.
