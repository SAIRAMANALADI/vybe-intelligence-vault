## Summary
OCTO Web is a TypeScript/React-based web and desktop (Electron) client for the OCTO messaging platform, enabling human-AI agent collaboration with a single codebase. It serves as the front-end interface for interacting with AI agents (Lobsters) and managing conversations across browser and PC environments.

## Key Features
- Single codebase for web and desktop (Electron) builds with platform-specific optimizations
- First-class AI agent conversation UX (streaming replies, tool-call previews, agent identity chips)
- Bilingual support (English and Simplified Chinese) with enforced i18n in CI
- Real-time messaging via REST + WebSocket integration with `octo-server`
- Modular architecture with clear separation of concerns (pages, components, store, API)

## Why It Matters for RAG Builders
It provides a unified, production-ready UI for interacting with AI agents and managing conversations, critical for building human-AI collaboration platforms in RAG systems.
