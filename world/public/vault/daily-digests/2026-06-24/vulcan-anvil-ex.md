## Summary
Vulcan-Anvil Ex is a governance and trust layer framework that ensures AI agents adhere to requirements, design, testing, and traceability workflows during long-term projects. It transforms AI-generated code into explainable, auditable outputs with structured documentation and validation gates.

## Key Features
- Multi-profile support (PoC, Product, Audit) for varying governance needs
- Structured 5-Gate workflow (requirements, design, testing, QA, release)
- Built-in traceability from goals to code and artifacts
- Dashboard for real-time project status and artifact review
- Adapter system for cross-LLM compatibility (Codex, Claude, Gemini/Agy)

## Why It Matters for RAG Builders
It provides the critical governance layer that turns AI-generated code into auditable, traceable, and production-ready outputs essential for regulated or high-stakes AI engineering projects.
