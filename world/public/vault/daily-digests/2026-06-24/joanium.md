## Summary
Joanium is a local-first AI desktop assistant that runs entirely on your machine, enabling multi-model chat, scheduled automations, background agents, and real integrations with tools like GitHub, Gmail, and Slack without relying on cloud services.

## Key Features
- Runs entirely offline with support for Ollama and LM Studio models
- Background agents for scheduled automations (e.g., GitHub issue summaries, PR reviews)
- Multi-model support (10+ providers including GPT, Claude, Mistral, Grok)
- Real integrations with tools like GitHub, Gmail, Google Drive, and Slack
- MCP support for extensibility with custom servers and skills

## Why It Matters for RAG Builders
Joanium provides a fully local, privacy-preserving alternative to cloud-based AI agents, enabling developers to build and deploy autonomous systems that operate entirely on user-controlled hardware.
