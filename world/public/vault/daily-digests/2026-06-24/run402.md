## Summary
Run402 provides AI agents with an integrated Postgres database, REST API, authentication, content-addressed storage, static site hosting, and serverless functions, all provisioned via a single API call and paid with x402 USDC on Base. It simplifies agent workflows by offering SDKs, CLI tools, and MCP server interfaces for seamless integration.

## Key Features
- Provision Postgres databases, REST APIs, and storage with a single API call or CLI command
- Integrated MCP server for seamless agent interaction and tooling
- Content-addressed asset storage with SRI (Subresource Integrity) for secure static site hosting
- Dark-by-default table exposure with declarative manifest policies to prevent accidental data leaks
- Incremental deployments with client-side hashing to minimize bandwidth and speed up updates
