## Summary
metagraphed is a Windows-based desktop application that provides a user-friendly dashboard for monitoring Bittensor subnet health, metadata, and schema information. It simplifies network oversight by offering real-time insights into subnet status, registry data, and public interfaces without requiring technical expertise.

## Key Features
- Real-time subnet health tracking with visual indicators
- Schema registry access for subnet data structures
- Automatic updates of network metadata every 60 seconds
- Simple dashboard for performance stats without command-line complexity
- Local execution ensuring no private key exposure or data storage
