## Summary
librecrawl-mcp is a self-hosted SEO auditing tool that bridges websites with the Claude AI interface, enabling deep technical SEO audits without monthly subscriptions. It performs full-scale web crawling, identifies technical issues, and integrates directly with Claude via the Model Context Protocol.

## Key Features
- Performs unlimited technical SEO audits without per-crawl fees
- Integrates with Claude AI via Model Context Protocol for seamless data analysis
- Identifies crawl errors, broken links, redirect chains, and missing meta tags
- Runs locally for data privacy and unlimited page crawling
- Provides nineteen specialized tools for comprehensive site auditing
