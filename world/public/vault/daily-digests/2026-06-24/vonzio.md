## Summary
vonzio is a self-hosted AI agent runtime that enables users to deploy isolated agent containers per conversation, embed chat interfaces into any product via a drop-in widget, and bring their own LLM models. It provides a full dashboard, MCP tooling, and integrations for secure, scalable agent workflows.

## Key Features
- Isolated Docker containers per conversation with bind-mounted workspaces
- Embeddable chat widget via a single `<script>` tag for seamless integration into any product
- Bring-your-own-model support for Anthropic, Ollama Cloud, OpenAI-compatible endpoints, and more
- MCP-native tooling with built-in and custom MCP servers for extended functionality
- Playbooks for scheduled or webhook-triggered agent chains with budget caps and success criteria

## Why It Matters for RAG Builders
vonzio enables AI engineers to deploy production-grade, self-hosted agent systems with strong isolation and embeddable interfaces, reducing reliance on third-party services while maintaining flexibility and control.
