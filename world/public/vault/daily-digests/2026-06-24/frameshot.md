## Summary
Frameshot is an MCP server that enables AI agents to render and visually inspect UI components (React, Vue, Svelte, etc.) with real dependencies, Tailwind styling, and CSS Modules directly in terminals or AI chats. It eliminates the need for Storybook or manual screenshots by providing live previews, diffing, and accessibility audits.

## Key Features
- Real-time component rendering with full Vite dependency resolution and Tailwind support
- Live watch mode for AI agents to see changes instantly after file saves
- GitHub Action integration for automated PR diff screenshots (free Chromatic alternative)
- Comprehensive toolset including accessibility audits, responsive rendering, and pixel diffing
- Terminal-native inline image display for seamless AI agent workflows

## Why It Matters for RAG Builders
Frameshot bridges the gap between AI agents and UI development by enabling real-time visual feedback loops, reducing manual review cycles and improving the reliability of AI-driven UI generation and refactoring.
