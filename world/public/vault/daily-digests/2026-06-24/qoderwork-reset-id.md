## Summary
A utility tool designed to reset the local device identifier for QoderWork CN (a desktop AI agent) and QoderCN (a code editor), allowing the application to treat the current device as a new device without deleting files or losing account information.

## Key Features
- Resets local device identifiers (e.g., installation_id, machine-id) for QoderWork CN and QoderCN
- Preserves account authentication files and data
- Cross-platform support for macOS and Windows
- No file deletion or account loss
- Simple script-based execution
