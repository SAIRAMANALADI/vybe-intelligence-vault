## Summary
ievoide is a self-evolving, customizable desktop IDE built on the Claude Agent SDK. It enables users to describe desired features or fixes, which the agent then implements by modifying its own source code, with git serving as a safety net for rollbacks and versioning.

## Key Features
- Self-evolution capability allowing the IDE to modify its own source code autonomously
- Built-in git-based version control and rollback for safety
- Parallel chat sessions with multi-model support
- Portable single-folder deployment with cross-platform compatibility
- Rich document viewers (PDF, Markdown, Mermaid) and attachment support
