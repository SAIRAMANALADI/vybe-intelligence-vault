## Summary
OpenLore is a local-first, deterministic intelligence graph for AI coding agents that eliminates repetitive file reads by maintaining a persistent architectural memory. It unifies code, infrastructure, and architectural decisions into a single governance runtime with safety-gated updates.

## Key Features
- Persistent architectural memory with one-time static analysis for AI agents
- Deterministic and local-first graph with ~430µs p50 query latency
- Unified graph spanning code, infrastructure-as-code, and architectural decisions
- Context freshness tracking with epistemic lease for stale data detection
- Safety-gated governance with pre-commit hooks and drift detection

## Why It Matters for RAG Builders
It eliminates redundant file reads for AI agents by providing a persistent, deterministic knowledge graph that unifies code, infrastructure, and architectural decisions, reducing round-trips and improving accuracy in large codebases.
