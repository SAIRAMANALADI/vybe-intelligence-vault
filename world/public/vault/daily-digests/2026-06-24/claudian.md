## Summary
Claudian is an Obsidian plugin that integrates AI agents into the note-taking app to enhance productivity by automating tasks, generating code, and organizing data. It leverages external AI models like Claude and Codex to assist with research, drafting, and summarization directly within the user's vault.

## Key Features
- Seamless integration with Obsidian for AI-assisted note management
- Supports Claude and Codex models for code generation and debugging
- Model Context Protocol (MCP) for local file and tool interaction
- DeepSeek routing for alternative AI model compatibility
- Privacy-focused with local API key storage and selective data sharing
