## Summary
Embody is a TouchDesigner extension that enables AI-driven creation, externalization, and version control of TouchDesigner networks. It includes an MCP server (Envoy) for programmatic interaction and a human-readable YAML-based network format (TDN) for diffing and restoration.

## Key Features
- Envoy MCP server for AI-driven TouchDesigner network manipulation (create, wire, parameterize, debug)
- TDN (TouchDesigner Network) format for human-readable, diffable YAML exports of entire networks
- Automatic restoration of externalized operators from disk on project open
- Git-integrated diffing and status tracking for externalized files
- Comprehensive testing suite with 1,693 tests across 72 suites

## Why It Matters for RAG Builders
Embody bridges the gap between AI-assisted development and real-time creative tools by enabling LLMs to directly manipulate TouchDesigner networks, making it essential for AI-driven generative media workflows.
