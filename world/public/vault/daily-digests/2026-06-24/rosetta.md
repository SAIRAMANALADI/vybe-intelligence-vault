## Summary
Rosetta is a meta-prompting and context engineering framework designed to enhance AI coding agents by providing structured context, guardrails, and centralized instructions management. It enables agents to operate with deep project understanding, enforce safe behavior, and follow human-in-the-loop workflows for reliable and consistent code generation.

## Key Features
- Structured context management for AI agents including rules, skills, workflows, and sub-agents
- Enforced guardrails for safe behavior, risk assessment, and sensitive data handling
- Human-in-the-loop workflows with approval gates at critical decision points
- Request classification into 12 workflow types for tailored agent responses
- Reverse-engineering of project architecture, tech stack, and business context for deep understanding
