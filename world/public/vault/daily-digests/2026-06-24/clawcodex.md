## Summary
ClawCodex is a production-oriented Python rebuild of Claude Code, offering a CLI agent for agentic coding with multi-LLM provider support, dynamic workflows, and DeepSeek prompt-cache optimization for cost-efficient long sessions.

## Key Features
- Production-grade CLI agent with streaming REPL and tool-calling loop
- DeepSeek prompt-cache integration reducing token costs by ~230x for long sessions
- Dynamic workflow engine supporting parallel agents, pipelines, and phase-based execution
- Multi-LLM provider support (DeepSeek, Z.ai, Claude, etc.) for flexible cost-performance tradeoffs
- Markdown-driven skill system for extensible agent behaviors and slash commands

## Why It Matters for RAG Builders
ClawCodex provides a cost-efficient, production-ready agent framework for AI engineering teams to build and deploy scalable coding agents with multi-LLM flexibility and advanced workflow orchestration.
