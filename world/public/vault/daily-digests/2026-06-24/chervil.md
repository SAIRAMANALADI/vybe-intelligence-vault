## Summary
Chervil is an agentic, conversational web browser that replaces traditional browsing with an AI assistant named Sprig. It composes live web search results into self-contained, interactive pages tailored to user queries, blending synthesized content with direct access to live websites when needed.

## Key Features
- Composes live web search results into interactive, cited pages tailored to user queries
- Supports agentic web actions with safety gates for operating real websites
- Pluggable AI providers (Claude, Grok, Gemini, OpenAI, Azure, Ollama) with local offline support
- Deep Dive research pipeline for long, cited reports with disinformation vetting
- Persistent Spaces for topic workspaces, scheduled agents, and cross-device synchronization

## Why It Matters for RAG Builders
Chervil transforms raw web data into structured, interactive knowledge assets, enabling RAG systems to generate richer, more accurate, and dynamically updated responses by grounding outputs in live web sources.
