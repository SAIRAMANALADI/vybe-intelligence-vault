## Summary
A desktop application that automates the search and download of academic papers by querying Scopus, fetching open-access PDFs via Unpaywall, and optionally falling back to Sci-Hub for restricted papers. Designed for researchers and students without requiring programming knowledge.

## Key Features
- Search academic papers by keywords or DOI using Scopus database
- Download open-access papers directly from Unpaywall
- Optional fallback to Sci-Hub for restricted papers
- Simple GUI for non-technical users
- Saves papers in PDF format to a local directory
