## Summary
RimSage is an MCP server that enables AI agents to search and browse RimWorld source code, including Defs and C# definitions, for integration into agent workflows. It provides tools for semantic and structural code analysis tailored to RimWorld modding.

## Key Features
- Semantic search across RimWorld source code and Defs
- Read and analyze C# type/method definitions
- Supports both online and self-hosted deployment
- Integration with AI agents via MCP protocol
- Builds and indexes RimWorld source for fast retrieval

## Why It Matters for RAG Builders
