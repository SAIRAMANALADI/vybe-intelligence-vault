## Summary
A Python-based MCP server that fetches and analyzes Jenkins console logs from multiple Jenkins instances, enabling error snippet extraction, build metadata retrieval, and multi-server support for CI/CD log analysis.

## Key Features
- Multi-Jenkins instance support for centralized log analysis
- Automated extraction of error snippets and build metadata
- User-friendly interface for querying Jenkins logs
- Configurable JSON-based setup for Jenkins server credentials
- Lightweight and easy to deploy with minimal dependencies
