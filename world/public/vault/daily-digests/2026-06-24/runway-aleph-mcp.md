## Summary
A focused Model Context Protocol (MCP) server for RunAPI's Runway Aleph model, enabling AI agents to create video generation tasks, poll results, and check pricing through a single, lightweight endpoint.

## Key Features
- Provides MCP-compatible tools for video generation tasks via Runway Aleph
- Supports task creation, status polling, and pricing checks
- Lightweight and focused on a single model endpoint for efficiency
- Compatible with major AI agent hosts like Claude Code, Cursor, and VS Code
- Includes agent prompts for natural language task execution
