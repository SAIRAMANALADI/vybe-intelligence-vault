## Summary
A multi-tenant SaaS platform for private credit portfolio management, operated entirely via a conversational AI agent on WhatsApp. It enables contract registration, payment tracking, automated reminders, and native PIX integration, with a full web dashboard for administrative control.

## Key Features
- AI-powered WhatsApp agent for natural language contract and payment management
- Multi-tenant architecture with Row Level Security (RLS) for data isolation
- Automated reminders and follow-ups via Cloud Scheduler
- Native PIX payment integration with QR code generation
- Hybrid NLU pipeline with regex and Gemini AI fallback for high-accuracy intent classification

## Why It Matters for RAG Builders
It demonstrates a real-world SaaS architecture integrating AI agents, multi-tenancy, and payment systems, providing a blueprint for scalable conversational finance applications.
