## Summary
A desktop application that analyzes GitHub repositories by collecting multi-source data to generate structured reports on project quality, activity, community health, and risks without requiring technical expertise.

## Key Features
- Multi-source data collection from GitHub repositories (commits, issues, PRs, contributors)
- Generates structured, visual reports covering project quality, activity, and risks
- No technical setup required—runs as a standalone desktop application
- Supports cross-platform deployment (Windows, macOS, Linux)
- Exports reports in PDF or text format for offline sharing
