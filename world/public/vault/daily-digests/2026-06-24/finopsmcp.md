## Summary
nable is an open-source, local-first FinOps MCP server that connects to cloud and SaaS billing data, enabling users to query costs, identify waste, and generate fixes directly within AI editors like Claude or Cursor. It runs entirely on the user's machine, ensuring credentials and data never leave local control.

## Key Features
- Local-first architecture with encrypted credential storage in OS keychain
- Multi-cloud and SaaS support (AWS, Azure, GCP, Datadog, Snowflake, etc.)
- AI-native integration with editors like Claude, Cursor, and VS Code
- Automated waste detection and rightsizing recommendations with verification
- Interactive dashboard for team collaboration and cost tracking

## Why It Matters for RAG Builders
nable empowers AI engineers to integrate real-time cost optimization into their workflows, reducing cloud waste and improving budget transparency without exposing sensitive billing data to external services.
