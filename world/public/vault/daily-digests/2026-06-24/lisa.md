## Summary
LISA is an advanced AI agent framework that combines multiple open-source agent capabilities into a single, autonomous system with a unique 'self' identity, desires, and heartbeat-driven autonomous actions. It includes a pixel-art GUI, multi-provider LLM support, and an orchestrator for other coding agents.

## Key Features
- Soul-driven agent with unique identity, desires, and heartbeat for autonomous actions
- Supports 20+ LLM providers (Anthropic, OpenAI, Gemini, Ollama, etc.) and coding plans for subscription-based usage
- Orchestrator for other coding agents (Claude Code, Codex, Aider, etc.) with real-time monitoring and control
- Pixel-art GUI with live mood updates and six IM channel integrations (Telegram, Discord, Slack, etc.)
- Journaling, memory persistence, and autonomous reflection ('REVE') when user is away

## Why It Matters for RAG Builders
LISA provides a unique framework for building self-motivated, autonomous AI agents with persistent identity and desires, making it valuable for developers creating advanced agentic systems beyond static chatbots.
