## Summary
The Webasyst MCP Toolkit is an AI-powered automation suite that integrates the Model Context Protocol (MCP) with the Webasyst framework to enable intelligent app generation, plugin development, theme composition, and UI auditing. It bridges human intent with machine execution using AI models like OpenAI and Claude.

## Key Features
- AI-powered app and plugin generation with natural language prompts
- Real-time code generation and hot reload for Webasyst instances
- Automated UI auditing for accessibility, performance, and responsiveness
- Multilingual support with AI-driven localization for 48 languages
- Hybrid AI integration allowing seamless switching between OpenAI and Claude
