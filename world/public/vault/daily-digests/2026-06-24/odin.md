## Summary
Odin is an autonomous execution agent designed to perform real-world infrastructure and DevOps tasks directly from Discord, including incident response, deployments, code reviews, and scheduled operations across 70 integrated tools. It bridges AI advice with actionable execution, combining multi-LLM support, persistent memory, and a web-based management UI.

## Key Features
- Executes real infrastructure tasks (SSH, Docker, Kubernetes, Terraform) directly from chat or scheduled commands
- Supports multi-LLM backends (Codex, Kimi, Ollama) with runtime switching and OAuth/device flow authentication
- Autonomous loops, sub-agents, and scheduled workflows with validation and audit trails
- Persistent memory, knowledge base with vector/FTS5 search, and trajectory logging for context retention
- Web UI with 19 pages for monitoring, configuration, and real-time tool execution oversight

## Why It Matters for RAG Builders
Odin bridges the gap between AI-generated advice and real-world execution, enabling RAG systems to autonomously perform infrastructure tasks while maintaining auditability and safety.
