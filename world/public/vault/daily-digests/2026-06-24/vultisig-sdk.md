## Summary
The Vultisig SDK provides a self-custodial multi-chain wallet solution for AI agents and developers, enabling secure cross-chain transactions, swaps, and portfolio management without seed phrases. It leverages MPC (Multi-Party Computation) security and supports 40+ blockchains with human-readable operations.

## Key Features
- Supports 40+ blockchains with human-readable transaction amounts and portfolio tracking
- MPC security with no seed phrases or single points of failure (2-of-2 or N-of-M threshold signing)
- Built-in cross-chain swaps via THORChain, 1inch, KyberSwap, and LiFi with automatic routing
- Dry-run mode for sends and swaps to preview fees and outputs before execution
- Programmatic SDK and CLI for AI agents, bots, and applications with TypeScript support

## Why It Matters for RAG Builders
