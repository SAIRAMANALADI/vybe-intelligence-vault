## Summary
CreatorWeave is a local-first, browser-native AI platform designed for creation, knowledge workflows, and multi-agent orchestration. It enables users to interact with files, code, and data directly in the browser while leveraging AI agents for tasks like code analysis, data visualization, and multi-step creative workflows.

## Key Features
- Multi-agent collaboration with configurable roles and coordination modes
- Local file access via browser File System Access API with explicit permissions
- Built-in code intelligence tools (30+ functions) for analysis and manipulation
- Python integration (Pyodide) for in-browser data analysis and visualization
- Privacy-first architecture with all processing occurring locally
