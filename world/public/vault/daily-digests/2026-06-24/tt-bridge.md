## Summary
TT Bridge is a browser automation tool that enables AI agents (e.g., Claude Code) to directly control and interact with Chrome browsers without repeated authentication or permission prompts. It bridges AI workflows with real-time browser actions like navigation, data extraction, form filling, and automation.

## Key Features
- Direct browser control via CLI or AI agents without manual setup
- Supports real-time navigation, evaluation, and interaction (clicks, form filling)
- Isolated workspace mode for background automation without disrupting user sessions
- Structured JSON output for programmatic use cases
- Cross-platform compatibility with Chrome and Node.js

## Why It Matters for RAG Builders
TT Bridge eliminates friction for AI agents to interact with live web pages, enabling seamless RAG pipelines that require real-time data extraction or dynamic web interactions.
