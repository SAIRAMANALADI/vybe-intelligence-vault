## Summary
AEGIS is a self-hostable, local-first agent workbench that provides a unified runtime for terminal, browser dashboard, desktop app, API clients, automation, and MCP. It enables auditable, multi-surface agent operations with shared state, memory, and tooling across all interfaces.

## Key Features
- Unified runtime for terminal, dashboard, desktop, API, and MCP with shared state and memory
- Built-in registry for multiple LLM providers (Anthropic, OpenAI, Groq, etc.) with OAuth and API-key support
- Comprehensive toolset including file, shell, browser, LSP, GitHub, MCP, and automation tools
- Local-first architecture with state stored in `~/.aegis` or `$AEGIS_HOME`
- Advanced automation features like cron, kanban, evals, traces, and cost optimization

## Why It Matters for RAG Builders
AEGIS provides a production-ready, auditable foundation for building and deploying multi-surface agent systems with consistent behavior and shared state across all interfaces.
