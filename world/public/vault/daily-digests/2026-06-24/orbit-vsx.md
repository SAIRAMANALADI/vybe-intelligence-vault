## Summary
Orbit is a VS Code extension that integrates MCP health monitoring, debug session history, and A2A agent discovery directly into the editor's Activity Bar. It enables developers to monitor companion agent services, record debugging sessions, and explore A2A agents without leaving VS Code.

## Key Features
- Health Monitor for tracking MCP server status, latency, and uptime via a companion HTTP service
- Debug Recorder for capturing and searching terminal commands and debugging sessions
- A2A Explorer for browsing agent cards, validating agent-card.json files, and scaffolding agents
- MCP Explorer for reviewing MCP connection status in a dedicated tree view
- Seamless integration with VS Code settings and secret storage for secure token management

## Why It Matters for RAG Builders
Orbit streamlines the development workflow for AI engineers by centralizing MCP and A2A agent monitoring within VS Code, reducing context switching and improving productivity.
