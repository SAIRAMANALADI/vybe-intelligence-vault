## Summary
PocketAgent is a HarmonyOS-based agentic phone interface that converts natural language requests into native A2UI task surfaces and executes real, query-only actions through provider adapters. It operates locally by default, integrating with OpenAI-compatible models and device-side tools.

## Key Features
- Native A2UI surface runtime with ArkUI renderer and catalog validation
- Real-time query-only tool adapters for travel, food, and social actions
- Device-local model integration with OpenAI-compatible endpoints
- Provider configuration for live data sources (flights, trains, food, etc.)
- Strict permission and error handling for security and truthfulness

## Why It Matters for RAG Builders
PocketAgent demonstrates how to build a device-local agentic interface with native A2UI surfaces and real query-only tool adapters, offering a blueprint for AI-driven mobile applications.
