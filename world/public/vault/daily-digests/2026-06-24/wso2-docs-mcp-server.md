## Summary
A production-ready Model Context Protocol (MCP) server that enables AI assistants to perform semantic search over WSO2 documentation via RAG. It supports multiple ingestion methods, including direct GitHub integration and web crawling, with local or cloud-based embeddings.

## Key Features
- Dual ingestion engine: GitHub-native and web crawl fallback for comprehensive WSO2 docs coverage
- Local and cloud embedding support (Ollama, HuggingFace ONNX, OpenAI, Google Gemini, Voyage AI)
- Optimized for performance with hardware acceleration (Apple Silicon, NVIDIA GPU, ARM NEON SIMD)
- Seamless integration with AI clients (Claude Desktop, Claude Code, Cursor, VS Code)
- Automated model downloads and caching for zero-config local embeddings

## Why It Matters for RAG Builders
It provides a turnkey solution for AI assistants to access and query WSO2 documentation with semantic search, reducing hallucinations and improving accuracy in RAG pipelines.
