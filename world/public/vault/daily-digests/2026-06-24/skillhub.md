## Summary
SkillHub is an enterprise-grade, self-hosted registry for publishing, discovering, and managing reusable agent skills across organizations. It provides a private, governed platform for teams to share and version skill packages with RBAC, audit logging, and multi-language support.

## Key Features
- Self-hosted deployment with full data sovereignty behind firewalls
- Skill publishing with semantic versioning, namespaces, and RBAC governance
- Full-text search, filtering, and social features (stars, ratings, downloads)
- Pluggable storage (local filesystem, S3/MinIO) and multi-language support
- CLI-first workflow with REST API compatibility and Kubernetes deployment

## Why It Matters for RAG Builders
SkillHub enables RAG builders to standardize and share reusable agent skills across teams while maintaining strict governance and data control.
