## Summary
A Windows-based tool for securely supervising local AI coding agents like Claude Code, Codex, and Kimi Code by logging actions, requesting permissions for sensitive tasks, and ensuring workspace safety through local monitoring and control.

- Permission-based control for sensitive operations (e.g., file deletions)
- Multi-agent support with individual tabbed dashboards for monitoring
- Local-only processing to ensure data privacy and security
- Configurable sensitivity settings to balance monitoring and usability
