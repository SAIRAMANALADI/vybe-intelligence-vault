## Summary
A Model Context Protocol (MCP) server that provides 14 tools to query and analyze US federal spending data from USAspending.gov, including awards, recipients, agencies, and geographic spending analytics via STDIO or HTTP.

## Key Features
- Provides 14 tools to access USAspending.gov data via MCP (STDIO or HTTP)
- Supports award discovery, recipient profiles, agency data, and spending analytics
- Includes geographic, category, and time-based spending breakdowns
- Offers disaster/emergency spending tracking and federal account details
- Features autocomplete for valid filter codes (NAICS, PSC, CFDA, etc.)
