## Summary
An intelligent job hunting assistant that scrapes real-time job listings, analyzes CVs for skill and JD match scoring, and provides a smart dashboard for filtering and tracking applications. Built with Python, Streamlit, and ML techniques.

## Key Features
- Live job scraping from multiple platforms (Naukri, Indeed, Remotive, Arbeitnow)
- CV intelligence with PDF/DOCX upload and skill extraction
- AI-powered JD match scoring using TF-IDF and Cosine Similarity
- Auto-refresh engine for hourly job updates
- Smart dashboard with filtering by role, location, and match score

## Why It Matters for RAG Builders
It streamlines job application processes by automating CV-job matching, saving time and improving application relevance for AI engineers and job seekers.
