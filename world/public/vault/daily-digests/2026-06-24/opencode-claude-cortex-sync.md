## Summary
A zero-configuration orchestrator that enables seamless switching between multiple AI providers (Claude, GPT-4, Gemini, etc.) within OpenCode, handling authentication, routing, and cost optimization automatically. It acts as a universal bridge to eliminate manual API management and provider-specific setup.

## Key Features
- Automated provider detection and authentication with zero manual setup
- Intelligent routing engine optimizing for cost, speed, or capability
- Hardware-encrypted credential vault with audit trails
- Parallel request multiplexing across providers
- Real-time usage analytics and health monitoring dashboard

## Why It Matters for RAG Builders
It eliminates the complexity of managing multiple AI provider integrations, enabling RAG builders to dynamically switch providers without rewriting workflows or handling API key sprawl.
