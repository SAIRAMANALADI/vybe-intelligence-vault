## Summary
mcp-audit is a desktop application designed to track and analyze token usage for MCP (Model Context Protocol) servers like Claude Code, Codex CLI, and Gemini CLI in real time. It helps developers monitor and optimize their token consumption to avoid unexpected spikes and context bloat.

## Key Features
- Real-time token usage tracking across MCP servers
- Usage analytics to identify spikes and inefficiencies
- User-friendly interface for easy navigation and configuration
- Compatibility with major MCP-supported tools (Claude Code, Codex CLI, Gemini CLI)
- Lightweight with minimal system requirements
