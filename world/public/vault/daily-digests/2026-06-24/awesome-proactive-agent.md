## Summary
A curated research map and benchmark repository for proactive agents—AI systems that infer latent user needs, decide when to intervene, and initiate assistance before explicit commands. It aggregates foundational papers, benchmarks, and tools spanning dialogue, GUI, mobile, IDE, and embodied agents.

## Key Features
- Curated list of 100+ papers on proactive agents across domains (dialogue, GUI, mobile, IDE, embodied)
- Includes benchmarks like ProAgentBench, KnowU-Bench, and π-Bench for evaluating proactivity
- Provides structured tags (e.g., 'Intent Inference', 'Intervention Timing', 'Trust') for easy navigation
- Features decision cards for each paper summarizing proactivity signals, evaluation, and limitations
- Open to community contributions with PRs welcome and a clear tagging system
