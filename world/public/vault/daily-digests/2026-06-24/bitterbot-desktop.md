## Summary
Bitterbot Desktop is a local-first personal AI agent with persistent biological memory, a dream engine for self-improvement, and a P2P skills economy. It runs locally on macOS, Linux, and Windows, enabling users to interact via a web-based control UI or terminal commands.

## Key Features
- Persistent biological memory system with decay and consolidation based on computational neuroscience principles
- Dream Engine for autonomous self-improvement through specialized dream cycles (replay, mutation, extrapolation, etc.)
- P2P skills economy enabling agents to trade learned capabilities for USDC
- Proactive recall and evolving identity constrained by immutable safety axioms (GENOME.md)
- Real-time hormonal system modulating agent behavior (dopamine, cortisol, oxytocin)
