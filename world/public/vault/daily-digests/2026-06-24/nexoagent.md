## Summary
NexoAgent is a local-first AI Agent desktop application and web console that integrates conversation, multi-model orchestration, tool calling, persistent memory, local knowledge bases, skill systems, scheduled tasks, and channel integrations into a unified workspace for personal assistants, development collaboration, and team-internal agent scenarios.

## Key Features
- Multi-session chat with persistent history and SQLite-backed memory
- Unified desktop (Electron) and web console with shared backend and state
- Built-in tool ecosystem including web search, HTTP requests, shell commands, and file operations
- Persistent memory system with daily, dream, and script memory types using embeddings
- Local knowledge base management with Markdown file retrieval and context injection

## Why It Matters for RAG Builders
NexoAgent provides a comprehensive local-first framework for building and deploying AI agents with integrated tooling, memory, and multi-modal capabilities, reducing complexity for RAG and AI stack builders.
