## Summary
PhoenixQA is a self-healing test automation framework designed to autonomously repair fragile frontend tests when selectors break due to UI changes. It uses LLMs (Ollama or Anthropic) to analyze failures, propose fixes, and apply them in either safe or autonomous modes while logging decisions for continuous improvement.

## Key Features
- Autonomous repair of broken selectors with LLM intervention
- Context collection including DOM snapshots, screenshots, and logs
- Safe Mode for human review and Autonomous Mode for automated fixes
- Self-training loop that improves healing decisions over time
- Chaos App benchmark for testing resilience against UI mutations

## Why It Matters for RAG Builders
PhoenixQA reduces frontend test maintenance overhead by autonomously repairing broken tests, ensuring CI/CD pipelines remain stable despite frequent UI changes.
