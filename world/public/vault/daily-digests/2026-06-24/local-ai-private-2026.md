## Summary
A Windows-native tool that enables users to run private AI models entirely offline, ensuring data privacy by processing all computations locally without cloud dependency. It supports multiple LLMs and integrates a web-based interface for seamless interaction.

## Key Features
- Runs entirely offline with no internet dependency after initial setup
- Supports multiple open-source models (DeepSeek, Qwen, Llama, Gemma)
- Built-in Open-WebUI for browser-based interaction
- Portable design for easy model and settings transfer between Windows machines
- Integrated Whisper for voice input capabilities
