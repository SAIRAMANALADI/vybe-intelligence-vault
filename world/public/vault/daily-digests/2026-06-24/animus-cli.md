## Summary
Animus CLI is a Rust-based orchestrator for autonomous AI agent teams, enabling solo founders and small teams to manage multiple projects in parallel using YAML-defined workflows. It coordinates coding agents (Claude, Codex, etc.) to execute tasks, generate PRs, and maintain code quality without replacing existing tools.

## Key Features
- Parallel execution of 80+ agents across 16 projects with worktrees and quality gates
- Plugin-based architecture for providers, subjects, transports, and workflow runners
- Local-first operation with no external code exposure
- MCP server integration for dynamic tool discovery and agent routing
- Daemonized scheduling with health checks and structured event streams

## Why It Matters for RAG Builders
Animus CLI enables RAG builders to orchestrate multiple AI agents efficiently, reducing manual coordination overhead and accelerating autonomous workflow execution for complex projects.
