## Summary
SUZENT is an open-source, local-first AI agent framework designed for digital sovereignty, enabling users to own their agent's memory, intelligence, and runtime. It supports multi-model providers, portable skills, and explicit governance while ensuring continuity across deployments.

## Key Features
- Ownership of agent identity, memory, and runtime under user control
- Replaceable model providers with explicit permission governance
- Portable skills and configuration via Markdown-based Grimoires
- Docker-based sandboxing for secure tool execution
- Continuity through GitHub Sync and local-first design

## Why It Matters for RAG Builders
SUZENT empowers RAG builders to create sovereign, portable AI agents with full control over memory, tools, and governance, ensuring long-term continuity and adaptability.
