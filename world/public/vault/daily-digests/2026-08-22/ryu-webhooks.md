## Summary
ryu-webhooks provides a webhook endpoint registry and observability interface for inbound webhooks in the Ryu ecosystem. It exposes resolved public URLs, secret management, last-delivery timestamps, and ingress backend status through a companion UI integrated into the Ryu desktop app.

## Key Features
- Displays resolved public webhook URLs for external integrations
- Tracks secret presence and last-delivery timestamps per endpoint
- Integrates as a companion UI within the Ryu desktop app
- No dedicated backend; relies on Ryu Core for webhook management
- Prebuilt single-file HTML bundle for easy deployment

## Why It Matters for RAG Builders
It provides essential observability and management for webhook endpoints, simplifying integration and monitoring for RAG and AI workflows.
