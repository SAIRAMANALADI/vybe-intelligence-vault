## Summary
Tiny Agent is a lightweight, educational AI agent framework designed to teach the core principles of building AI agents from scratch. It starts with a simple LLM call and progressively adds capabilities like memory, planning, tool usage, and RAG, all while avoiding heavy frameworks for clarity.

## Key Features
- Progressive learning path with tagged versions (v0.1 to v0.7) covering LLM calls, streaming, multi-turn chat, RAG, tool calling, and ReAct loops
- Zero heavy framework dependencies, focusing on minimal code for maximum clarity and learning
- Modular architecture with decoupled components (LLM, vector store, tools, memory) for easy extension
- Single-process backend with integrated frontend for simplified local development and debugging
- Structured output support and visualization of agent decision-making processes

## Why It Matters for RAG Builders
It provides a hands-on, code-first approach to understanding AI agent architectures, making it ideal for developers who want to learn the fundamentals without the complexity of enterprise frameworks.
