## Summary
YantrikDB MCP Server provides persistent, structured, and queryable memory for AI agents via an MCP-compatible interface. It enables semantic recall, knowledge graph operations, contradiction detection, and procedural learning, supporting both local and distributed deployments.

## Key Features
- 19 built-in tools for memory management (remember, recall, forget, correct, think, etc.)
- Supports local SQLite, HTTP cluster, and SSE server deployment modes
- Semantic search with configurable embedders (64-dim bundled, 384-dim ONNX, 256-dim multilingual)
- Knowledge graph operations for relational memory and conflict resolution
- Time-travel recall for historical memory queries and audit trails

## Why It Matters for RAG Builders
