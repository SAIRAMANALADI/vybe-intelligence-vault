## Summary
StreamsHub MCP provides Model Context Protocol (MCP) servers that enable AI assistants to interact with Kubernetes-based streaming infrastructure, such as Strimzi-managed Kafka clusters. It exposes live cluster state and diagnostic tools via MCP-compatible clients for real-time troubleshooting and automation.

## Key Features
- Exposes live Kubernetes cluster state as structured MCP resources for AI assistants
- Provides real-time resource subscriptions and notifications for dynamic infrastructure updates
- Supports prompt templates for guided, step-by-step troubleshooting workflows
- Enables dynamic autocomplete for Kubernetes resources (namespaces, clusters, topics)
- Integrates with MCP-compatible clients like Claude Code, VS Code, and Copilot

## Why It Matters for RAG Builders
It bridges AI assistants with live Kubernetes infrastructure, enabling real-time diagnostics and automation for streaming platforms like Kafka.
