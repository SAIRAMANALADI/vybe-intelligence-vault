## Summary
Synapse CLI is a local-first terminal-based coding agent that maintains persistent project memory and enables seamless switching between LLM providers while enforcing strict tool isolation and safety boundaries. It connects to OpenAI/Anthropic-compatible endpoints and fails closed when secure execution environments are unavailable.

## Key Features
- Persistent project memory with local file-based storage (e.g., AGENTS.md, MEMORY.md)
- Multi-provider support with OpenAI/Anthropic-compatible endpoints and configurable routing
- Strict tool isolation via Bubblewrap/Docker sandboxing with fail-closed safety
- Interactive Ink REPL with Vim editing and resumable sessions
- Audit logging, runtime schema validation, and MCP client integration

## Why It Matters for RAG Builders
Synapse CLI enables RAG builders to maintain consistent project context across model switches while enforcing strict, inspectable tool boundaries critical for production-grade AI systems.
