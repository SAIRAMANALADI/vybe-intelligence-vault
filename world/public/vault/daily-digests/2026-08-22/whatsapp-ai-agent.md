## Summary
A WhatsApp AI agent system that integrates with Evolution API and OpenAI to process messages, store conversation history, and generate contextual responses. It automatically identifies users, retrieves conversation context, and ensures persistent storage for accurate AI-driven interactions.

## Key Features
- Seamless WhatsApp integration via Evolution API for message processing
- Automatic user identification and conversation history retrieval
- Persistent storage of chat history using SQLite for context-aware responses
- Structured logging system for debugging and monitoring
- OpenAI-powered response generation with contextual accuracy
