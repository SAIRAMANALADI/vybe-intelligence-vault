## Summary
ToolsConnector is a Python library that provides a unified interface to connect with 77+ APIs and 1,578 actions, enabling seamless integration for AI agents, Python applications, and MCP servers with minimal glue code.

## Key Features
- Unified interface for 77+ connectors and 1,578 actions with a single Python API
- Supports AI agent integrations (OpenAI, Anthropic, Gemini) with zero code changes
- One-line MCP server creation for Claude Desktop, Cursor, or other MCP clients
- Type-safe operations with Pydantic V2 models and JSON Schema generation
- Async-first design with circuit breakers, timeout budgets, and dry-run mode
