## Summary
Saraswati Agent is a local, stateful roleplay chat client designed for long-form narrative generation with layered memory, hybrid RAG, and structured world state management. It enables users to create, manage, and interact with complex storytelling scenarios while preserving context and enabling auditable tool execution.

## Key Features
- Layered memory system with RAG and optional reranking for context retrieval
- Structured world state tracking (items, values, NPCs, timelines, and relationships)
- LangGraph-based agent orchestration with SQLite checkpoints and conditional workflows
- SillyTavern JSON/PNG character card and lorebook import/export compatibility
- Built-in context debugging, token budget management, and auditable tool execution

## Why It Matters for RAG Builders
Saraswati Agent provides a robust framework for building AI-driven storytelling applications with advanced memory, state management, and hybrid RAG capabilities, essential for narrative AI and long-context interactions.
