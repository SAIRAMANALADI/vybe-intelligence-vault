## Summary
Taste builds personalized recommendation models by extracting and analyzing real-world consumption signals from email and calendar data, such as food delivery, travel bookings, and shopping receipts. It enriches venue entities, deduplicates signals, and applies decaying half-life models to prioritize recent behavior.

## Key Features
- Extracts consumption signals from email and calendar data (e.g., DoorDash, Instacart, OpenTable)
- Deduplicates and enriches venue entities using Google Maps API
- Applies configurable decaying half-life models to prune stale signals
- Supports dietary restriction filtering and new place recommendations
- Integrates OAuth for secure API access (Gmail, Spotify, Google Calendar)

## Why It Matters for RAG Builders
Taste provides a critical layer for RAG systems by grounding recommendations in real user behavior, enabling more accurate and personalized AI-driven suggestions.
