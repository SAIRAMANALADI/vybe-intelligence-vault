## Summary
A Model Context Protocol (MCP) server that integrates with the SecurityScorecard API to provide security risk analysis, asset discovery, and issue triage tools for MCP-compatible clients like Claude, Cursor, and VS Code.

## Key Features
- Provides 9 specialized tools for security risk analysis, asset discovery, and issue triage via MCP
- Hybrid semantic and keyword search across 507 SecurityScorecard API endpoints
- Supports three response modes (minimal, standard, detailed) for token efficiency
- Includes rate limiting, caching, and debugging capabilities
- Community-built and open-source with MIT license

## Why It Matters for RAG Builders
It enables seamless integration of SecurityScorecard's security risk data into AI workflows via MCP, empowering RAG builders to enhance security-aware applications with real-time threat intelligence.
