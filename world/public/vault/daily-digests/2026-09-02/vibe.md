## Summary
VIBE is an extensible benchmarking framework for approximate nearest neighbor search methods (vector indexes) using modern embedding datasets. It provides a standardized way to evaluate and compare state-of-the-art vector search algorithms across diverse datasets and hardware configurations.

## Key Features
- Comprehensive collection of state-of-the-art vector search algorithms
- Support for in-distribution and out-of-distribution datasets
- Quantized dataset support (8-bit integer and binary precision)
- Hardware-aware benchmarking (CPU, GPU, HPC with Slurm/NUMA)
- Extensible framework for adding new algorithms and datasets

## Why It Matters for RAG Builders
VIBE provides a critical standardized benchmarking tool for evaluating and selecting optimal vector indexes for RAG systems, ensuring performance and scalability under realistic workloads.
