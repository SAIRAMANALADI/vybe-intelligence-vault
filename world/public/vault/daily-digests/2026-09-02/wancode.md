## Summary
WanCode is a multi-model desktop AI coding agent that provides secure Chat and full-power Code surfaces for software development tasks. It supports multiple AI providers like Zhipu GLM and DeepSeek, and is built with Tauri 2, React, TypeScript, and Rust.

## Key Features
- Dual-mode surfaces (Chat and Code) with strict isolation policies
- Support for multiple AI providers (Zhipu GLM, DeepSeek, OpenAI-compatible endpoints)
- Advanced session management with checkpoint rewind and approval controls
- Built-in developer tools (Git integration, terminal, file browser, MCP)
- Reproducible Rust-based agent runtime with audited vendor manifest

## Why It Matters for RAG Builders
WanCode provides a secure, multi-model desktop environment for AI-driven coding tasks, enabling developers to leverage different AI providers while maintaining strict policy enforcement and toolchain access.
