## Summary
SimpleERP is a lightweight open-source ERP system designed for home-care agencies, enabling workforce planning, customer management, and intervention scheduling with real-time notifications and validation workflows.

## Key Features
- Quoting and validation workflow for care services with manager approval
- Automated workforce planning using CP-SAT solver for optimal route scheduling
- Real-time notifications via SSE and RabbitMQ for live updates
- Observability stack with Prometheus, Grafana, Loki, and OpenTelemetry
- Multi-role access control (administrators, managers, assistants) with role-specific views

## Why It Matters for RAG Builders
It provides a robust, production-ready orchestration layer for AI-driven workforce and intervention planning in healthcare, critical for building scalable RAG systems in service-based industries.
