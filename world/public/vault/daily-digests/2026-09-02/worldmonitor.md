## Summary
World Monitor is a real-time global intelligence dashboard that aggregates AI-powered news, geopolitical monitoring, and infrastructure tracking into a unified situational awareness interface. It offers multi-variant deployments (world, tech, finance, commodity, happy, energy) with desktop and web access, supporting local AI inference via Ollama.

## Key Features
- AI-synthesized news aggregation with curated feeds across global and regional categories
- Dual map engine with 3D globe (globe.gl) and WebGL flat map (deck.gl) for geospatial visualization
- Country Instability Index (CII) v8 scores with live updates for 31 Tier-1 countries
- Multi-language UI support with RTL language compatibility and native-language feeds
- Programmatic access via MCP server, REST API, CLI, and SDKs (Python, Ruby, Go)

## Why It Matters for RAG Builders
World Monitor provides a unified, real-time interface for aggregating and visualizing global intelligence data, making it essential for AI engineers building RAG systems that require up-to-date geopolitical, financial, and infrastructure insights.
