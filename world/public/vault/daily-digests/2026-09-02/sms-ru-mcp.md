## Summary
A Model Context Protocol (MCP) server for integrating SMS.RU's API into AI assistants, enabling SMS sending, status checks, balance inquiries, and sender management without direct API coding. Designed for seamless integration with LLM workflows.

## Key Features
- 5 MCP tools for SMS.RU API: send SMS, check status, get balance, calculate cost, and list senders
- Zero-code integration with AI assistants (Claude, VS Code, etc.)
- Pre-configured skills for Claude Code (e.g., `/send-sms`, `/check-balance`)
- Supports HTTP streaming for broader tooling compatibility
- Lightweight and modular with MIT licensing

## Why It Matters for RAG Builders
Enables AI assistants to directly interact with SMS services for real-world notifications and automation without requiring custom API integrations.
