## Summary
ThreeBrowser Studio is a persistent WebGPU authoring runtime for AI models like Codex and ChatGPT, enabling live scene creation and animation with a native viewport. It integrates with MCP for structured editing and provides a deterministic authoring pipeline for Three.js projects.

## Key Features
- Live WebGPU viewport for real-time scene authoring and review
- Nine MCP tools for scene inspection, validation, rendering, and animation playback
- Deterministic Action/keyframe animation and timeline-driven Ocean displacement
- Atomic changesets, undo/redo, and project recovery with named saves
- Strict separation of authoring kernel and runtime for lean dependency management

## Why It Matters for RAG Builders
It provides a specialized runtime and MCP tooling for AI-driven Three.js scene authoring, enabling seamless integration of AI models into the creative process with persistent visual feedback.
