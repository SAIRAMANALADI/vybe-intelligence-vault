## Summary
sktime-mcp is an MCP (Model Context Protocol) server that exposes sktime's estimator registry and semantics to LLMs, enabling programmatic discovery, reasoning, composition, and execution of time-series workflows without manual code analysis or heuristics.

## Key Features
- Registry-first semantic engine for sktime estimators and pipelines
- Zero-install deployment via uvx or Docker
- Supports discovery, instantiation, fitting, and execution of sktime workflows
- Handles data loading, transformation, and persistence through MCP tools
- Configurable via environment variables for logging, job management, and auto-formatting

## Why It Matters for RAG Builders
It bridges the gap between LLMs and sktime's time-series capabilities, enabling safe, programmatic execution of complex forecasting and classification workflows without manual code analysis.
