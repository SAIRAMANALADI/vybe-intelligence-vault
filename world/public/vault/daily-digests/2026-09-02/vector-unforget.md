## Summary
VectorUnforget is a Python engine designed to enforce GDPR compliance (Right to be Forgotten) in vector databases used for RAG architectures. It provides cascading PII erasure, name variant matching, and cryptographic audit trails for compliance audits.

## Key Features
- Multi-vector DB support via adapter pattern (ChromaDB, Qdrant, extensible to others)
- Cascading PII erasure to purge secondary and orphaned entries
- Name variant and alias engine for accurate PII matching
- Cryptographic SHA-256 audit trail for compliance documentation
- Extensible architecture for enterprise vector stores

## Why It Matters for RAG Builders
It ensures GDPR compliance in RAG systems by automating the right-to-be-forgotten process, reducing legal risks and manual effort for data deletion.
