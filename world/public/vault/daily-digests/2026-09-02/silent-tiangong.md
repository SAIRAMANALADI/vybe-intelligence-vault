## Summary
Silent-Tiangong is a Rust-based desktop AI automation hub designed for personal workflows, enabling agents to perform tasks like reading files, executing commands, browsing the web, and collaborating via multi-agent systems. It supports embedded browsers, mobile control via IM platforms, and long-term memory with DeepSeek V4 integration.

## Key Features
- Desktop AI agent with embedded browser for human-AI collaboration
- Multi-agent system with sub-agent recruitment and file locking
- DeepSeek V4 integration with structured tool calls and KV cache optimization
- Modular plugin system supporting WASM, TypeScript, and UI plugins
- Mobile control via IM platforms (Feishu, WeChat, QQ) and scheduled tasks

## Why It Matters for RAG Builders
It provides a unified framework for building and orchestrating AI agents with advanced capabilities like multi-agent collaboration, embedded browser interaction, and plugin extensibility, critical for complex RAG and automation workflows.
