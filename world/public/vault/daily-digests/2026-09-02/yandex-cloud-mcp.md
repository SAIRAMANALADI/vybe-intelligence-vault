## Summary
A Model Context Protocol (MCP) server for Yandex Cloud that enables natural language interaction with cloud resources, including virtual machines, object storage buckets, and serverless functions. It provides 8 tools to manage and query Yandex Cloud services programmatically.

## Key Features
- Natural language interaction with Yandex Cloud resources via MCP-compatible clients
- 8 tools for managing VMs, Object Storage, and Serverless Functions
- Seamless integration with Claude Desktop, Code, and VS Code/Cursor
- Real-time status checks for cloud operations
- Lightweight and easy to deploy with minimal setup

## Why It Matters for RAG Builders
It simplifies cloud resource management for AI agents and developers by enabling natural language control over Yandex Cloud services, reducing reliance on manual CLI or console operations.
