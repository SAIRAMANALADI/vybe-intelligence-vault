## Summary
Sigma Code is a cross-platform client (desktop, web, mobile) for coding agents, serving as a downstream fork of T3 Code with a first-party Sigma provider integrated via the Agent Client Protocol (ACP). It enables users to interact with coding agents using various model providers, including ChatGPT, without requiring direct API key management.

## Key Features
- Cross-platform support (desktop, web, mobile) for coding agents
- Integration with Sigma Runtime and ACP for agent communication
- Built-in ChatGPT subscription support without requiring OPENAI_API_KEY
- Modular provider support (Codex, Claude, Cursor, Grok, OpenCode)
- Automatic updates via Sigma Runtime release channel

## Why It Matters for RAG Builders
Sigma Code provides a unified, user-friendly interface for interacting with coding agents across multiple providers, reducing friction for AI engineering teams building agent-based workflows.
