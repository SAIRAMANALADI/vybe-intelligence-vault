## Summary
小墨（Xiaomo）是一个基于Spring AI构建的金融领域多用户AI Agent平台，支持自然语言投研、资产分析、用户管理与一键Docker部署。平台集成多源金融数据工具、深度分析工作流和用户持仓诊断功能，专注于Agent架构设计与工程化实践。

## Key Features
- 基于Spring AI的Tool Calling与Agent调用治理，支持工具重复检测、轮次控制与信息增益分析
- Router Tool架构将40+金融API封装为8个领域级工具，降低LLM工具选择复杂度
- 深度分析工作流采用React响应式编程，支持多角色辩论、风险评估与运行时取消
- 多用户平台化设计，包含用户认证、数据隔离、Token配额与管理员后台
- SSE流式交互架构，实时展示Agent任务执行状态与生成过程
