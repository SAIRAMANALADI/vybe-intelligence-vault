## Summary
Phosphor is a macOS terminal application that consolidates SSH, Docker management, server monitoring, SFTP, and key management into a single interface over one SSH connection per host. It also exposes an MCP server for secure AI agent access to servers with granular permissions and audit logging.

## Key Features
- Consolidates shell, Docker, metrics, SFTP, and key management over a single SSH connection per host
- Exposes an MCP server for secure AI agent access with granular permissions and audit logging
- Supports biometric unlocking (Touch ID) and secure key storage in Keychain/Secure Enclave
- Provides real-time metrics, container management, and `authorized_keys` editing with atomic writes
- Includes provisioning recipes for server setup and enforces strict security policies (e.g., deny-lists, rate-limiting)

## Why It Matters for RAG Builders
It simplifies secure server management and AI agent access by consolidating tools and enforcing strict security policies, reducing operational overhead and risk for RAG/AI stack builders.
