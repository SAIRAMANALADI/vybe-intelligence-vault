## Summary
plangy transforms plain-text implementation plans (e.g., plan.md) into interactive, live-reloading visual diagrams, task progress bars, file maps, and charts directly in the browser. It bridges the gap between AI-generated plans and human readability, enabling early detection of plan errors before code is written.

## Key Features
- Converts markdown plans into interactive flow diagrams, task progress bars, and file maps with live-reload functionality.
- Supports Mermaid.js diagrams, markdown tables, and syntax-highlighted code blocks for rich visual representation.
- Works offline with no API keys or network dependencies, ensuring privacy and deterministic parsing.
- Integrates seamlessly with AI agents (Claude Code, Codex, Cursor, Gemini) via CLI or custom slash commands.
- Enables in-browser editing of task statuses and exports updated plans without modifying the original markdown file.

## Why It Matters for RAG Builders
plangy enhances AI-driven development workflows by making AI-generated plans visually scannable, reducing miscommunication and errors before code implementation begins.
