## Summary
ae-framework is an agent-neutral assurance control plane for agent-driven SDLC that standardizes specifications, verification evidence, policy gates, and release judgments to ensure trust in changes produced by coding agents, humans, CI jobs, or formal tools. It decouples agent choice from assurance logic, enabling consistent judgment artifacts across replaceable producers.

## Key Features
- Agent-neutral assurance control plane with Context Pack, policy gates, and release judgments
- Structured assurance model integrating property/MBT/conformance verification with change evidence
- Spec & Verification Kit supporting formal runners (Alloy, TLA+, SMT, Lean4, etc.) with unified summaries
- Ready-to-run GitHub Actions for PR verification, nightly tests, and Slack alerts
- Producer integration guidance for Claude Code, Codex, Copilot, Gemini, humans, and CI jobs

## Why It Matters for RAG Builders
It provides a critical layer for ensuring trust and consistency in AI-driven software development by standardizing assurance artifacts across diverse producers, making it essential for RAG/AI stack builders focused on reliability and governance.
