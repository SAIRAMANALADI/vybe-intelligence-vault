## Summary
An open-source Model Context Protocol (MCP) server that enables natural language interaction with Zooza, a class management platform for activity businesses. It allows AI assistants like Claude or ChatGPT to perform scheduling, attendance tracking, and class management via conversational commands without requiring manual dashboard access.

## Key Features
- 19 MCP tools for scheduling, attendance, and class management with explicit confirmation for write operations
- Multi-language and multi-region support (Slovak, Czech, German, English, etc.) with terminology negotiation
- Stateless hosted MCP server (mcp.zooza.app) requiring no local setup or API keys
- Guided workflow skills (e.g., class-management, business-model-validator) for complex operations
- GDPR-compliant with regional data routing (EU, UK, US, Asia) and OAuth 2.0 authentication

## Why It Matters for RAG Builders
It bridges AI assistants with specialized class management systems, enabling hands-free, conversational control over scheduling and attendance for activity businesses.
