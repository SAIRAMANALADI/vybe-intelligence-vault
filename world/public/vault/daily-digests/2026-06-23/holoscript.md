## Summary
HoloScript is a no-code platform for building games, apps, and AI agent workflows by describing intent in readable `.holo`, `.hsplus`, or `.hs` files. It compiles these files into platform-specific code (e.g., browser, robotics, services) while keeping data and ownership in the user's control.

## Key Features
- Describe intent in human-readable `.holo`/`.hsplus`/`.hs` files and compile to multiple targets (web, robotics, services, etc.)
- MCP server integration for AI agent workflows with typed tools, permissions, and live inventory checks
- Six-layer open platform architecture (OS Core to Marketplace) enabling modular and extensible development
- Supports traits for production concerns like payments, compliance, observability, and AI/ML orchestration
- Live editor, playground, and CLI tools for rapid prototyping and deployment without vendor lock-in

## Why It Matters for RAG Builders
HoloScript enables RAG builders to create portable, agent-interoperable systems that compile to multiple platforms while maintaining semantic clarity and avoiding vendor lock-in.
