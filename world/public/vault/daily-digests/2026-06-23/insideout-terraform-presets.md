## Summary
A library of standardized, tested Terraform modules designed for composing cloud infrastructure stacks. These presets are modular, cloud-agnostic, and optimized for integration with the InsideOut platform to streamline infrastructure deployment and management.

## Key Features
- Pre-tested Terraform modules for AWS and GCP with standardized best practices
- Modular and composable design for dynamic infrastructure generation
- Integration with InsideOut platform for AI-powered infrastructure design
- Automated generation of TypeScript schemas and metadata for downstream consumers
- Support for standalone Terraform module usage outside the InsideOut ecosystem
