## Summary
Bo-Sol HR Agent automates interview scheduling for HR teams using an LLM-driven agent powered by Anthropic Claude. It handles the entire loop from sending invites to calendar-confirmed bookings without human intervention.

## Key Features
- Autonomous interview scheduling from invite to confirmation
- Multi-tenant HR backend with tenant isolation
- Resume parsing and AI candidate scoring
- State machine for candidate pipeline management
- Decoupled Flask web app and FastAPI agent service
