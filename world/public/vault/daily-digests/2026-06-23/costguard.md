## Summary
CostGuard is a tool designed to audit repositories and cloud providers for CI and infrastructure cost leaks. It identifies redundant CI triggers, missing timeouts, and orphaned resources, offering fixes to reduce cloud spend by 60-80% in typical cases.

## Key Features
- Static audit of CI workflows for redundant triggers, missing timeouts, and concurrency issues without requiring credentials
- Live billing reconciliation for 13+ cloud providers to detect orphaned and over-provisioned resources
- Dry-run and in-repo fixes for CI workflows to reduce costs safely
- Zero-build, zero-npm plugin integration for AI coding agents (Claude Code, Codex, Cursor, etc.)
- Read-only, opt-in provider access with no mutating API calls

## Why It Matters for RAG Builders
CostGuard directly reduces cloud spend by identifying and fixing inefficiencies in CI and infrastructure, making it essential for AI engineering teams managing multiple projects and providers.
