## Summary
AuroraCoder is an autonomous AI coding agent that operates within a Docker sandbox, executing real-world tasks like reading/writing code, running commands, and managing GUI applications via a VNC desktop. It leverages advanced models like DeepSeek V4 Pro and supports GPU acceleration for PyTorch and vLLM workflows.

## Key Features
- Mutable tool responses for living state management, eliminating stale context and reducing token waste
- Strict validation and auto-correction for code edits to prevent cascading errors
- Multi-instance mode for running parallel isolated agents
- Built-in VNC desktop for GUI application support within the sandbox
- GPU-accelerated workflows with PyTorch and vLLM for high-performance inference
