## Summary
Auto-updated index of Model Context Protocol (MCP) servers actively maintained on GitHub, refreshed every 15 minutes via GitHub Actions. Provides real-time discovery, cataloging, and ranking of MCP servers with freshness metrics like stars, commits, and releases.

## Key Features
- Automated 15-minute refresh cycle using GitHub Actions cron jobs
- Real-time tracking of MCP server activity (stars, commits, releases)
- Multi-language support with categorized server listings
- Direct installation links for verified MCP servers
- Health-check integration with mcp-doctor for local MCP server diagnostics

## Why It Matters for RAG Builders
Provides a continuously updated, real-time index of actively maintained MCP servers, enabling AI engineers to discover and integrate the latest tools for RAG and agent-based systems without manual curation.
