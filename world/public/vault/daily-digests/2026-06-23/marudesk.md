## Summary
MaruDesk is a desktop AI development environment that integrates a real Chromium browser, DevTools, code editor, terminal, and multi-provider AI agent into a unified workspace. It enables agents to interact with live applications, verify fixes in real-time, and automate complex workflows through a task graph system.

## Key Features
- Real-time runtime-aware tools (DOM inspection, console error handling, network monitoring)
- Task graph system for organizing agent workflows and transient instruments
- Multi-provider AI agent support with fallback chains and OAuth integration
- Built-in Chrome DevTools with custom panels and live debugging capabilities
- Automated verification loops (screenshots, web vitals, exception capture)

## Why It Matters for RAG Builders
MaruDesk bridges the gap between source-only AI tools and real-world application debugging by enabling agents to interact with live systems, verify fixes, and automate complex workflows in a unified workspace.
