## Summary
An MCP (Model Context Protocol) server that reduces AI coding agent token usage by 80-99% by parsing codebases into a queryable knowledge graph, providing persistent memory, and enabling smart context retrieval for agents like Claude, Cursor, and Copilot.

## Key Features
- Parses entire codebase into a queryable graph of functions, classes, and relationships for 99% token reduction
- Provides 41 MCP tools including smart search, dependency tracing, and persistent memory across sessions
- Supports real-time sync via file watcher and progressive loading to minimize token waste
- Includes CLI and auto-configuration for popular AI agents (Claude, Cursor, Copilot, Windsurf, etc.)
- Offers self-evolving memory with decay-based retention and project-specific rule learning

## Why It Matters for RAG Builders
It drastically reduces token consumption in AI coding workflows by providing persistent, queryable context, making AI agents far more efficient and cost-effective for large codebases.
