## Summary
GlobalRoot is an autonomous local AI agent designed to run entirely on a user's computer, enabling offline task execution, system command management, and file operations while prioritizing data privacy. It integrates with Telegram for remote control and uses local AI models for secure, internet-independent operations.

- Incorporates a dual-pass AI process to enhance command accuracy and reliability
