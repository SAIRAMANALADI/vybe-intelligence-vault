## Summary
CyberStrike is an open-source AI agent designed for offensive security, enabling automated penetration testing through a terminal-based interface. It transforms any LLM (e.g., Claude, GPT) into an autonomous red team agent with 13+ specialized agents and 120+ OWASP test cases, supporting 15+ providers and remote tool execution.

## Key Features
- 13+ specialized security agents (web, mobile, cloud, network) following OWASP, CIS, and MITRE ATT&CK frameworks
- Intelligence layer for LLM normalization, context guarding, and tool orchestration across 15+ providers
- HackBrowser for autonomous or manual browser-based vulnerability scanning with multi-credential support
- Remote tool execution via Bolt for distributed attack surface testing
- Methodology engine for structured attack prioritization and coverage tracking

## Why It Matters for RAG Builders
