## Summary
A cross-platform desktop AI agent platform that enables users to design, build, and execute AI workflows through natural language chat. Built with Wails v2, React, and Go, it offers a visual flow designer with 17 node types for complex workflows, multi-model AI support, and zero-setup deployment.

## Key Features
- Chat-to-build workflows: Describe desired workflows in natural language to auto-generate and execute flows.
- Visual flow designer with 17 node types for complex logic, batch processing, and multimodal AI tasks.
- Multi-model support: Integrates 28+ AI providers (OpenAI, Claude, Gemini, DeepSeek) with unified interface.
- Zero-setup deployment: Desktop mode auto-configures SQLite and admin account; web mode runs as a server.
- App export/import: Share workflows as ZIP packages for one-click reuse across the community.

## Why It Matters for RAG Builders
It simplifies AI workflow orchestration by enabling no-code flow creation and execution, reducing context bloat in long conversations and improving task accuracy through focused node-based processing.
