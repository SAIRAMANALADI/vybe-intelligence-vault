## Summary
A curated catalog and installer for multi-agent skills, providing deterministic reinstallation, cross-agent synchronization, and scenario-based profiles for AI agents like Claude, Codex, and Gemini. It bridges discovery tools with reproducible skill bundles without re-hosting third-party content.

## Key Features
- Curated manifest of 120+ installable public skills with source and trust scores
- Scenario-based profiles (e.g., `core-meta`, `development-core`, `writing-blog`) for targeted skill sets
- Cross-platform one-click installer with dry-run support for multiple AI agents (Claude, Codex, Gemini, Qwen, CodeBuddy)
- Post-install validation and sanitization of `SKILL.md` frontmatter to ensure compatibility
- Dynamic ranking integration with Context7 and skills.sh for up-to-date skill discovery

## Why It Matters for RAG Builders
It provides a reliable, reproducible way to deploy and synchronize curated skill sets across multiple AI agents, reducing setup friction and ensuring consistency in multi-agent environments.
