## Summary
LMcode is a Chinese-focused local AI agent assistant designed for coding, file editing, research, and system automation. It operates entirely locally, ensuring data privacy while providing autonomous multi-agent task execution, memory persistence, and cross-platform CLI/TUI interactions.

## Key Features
- Autonomous goal-driven task execution with multi-round iteration and budget controls
- Wolfpack mode for parallel multi-agent collaboration with built-in coder, explorer, planner, verifier, and writer agents
- Permanent memory system with semantic tagging and vector retrieval for cross-session context retention
- Fine-grained permission engine with read/write/execute controls and sensitive file protection
- Thinking mode with adjustable intensity levels and streamed reasoning output
