## Summary
MoAI-ADK is a high-performance, single-binary Go-based agentic development kit for Claude Code, enabling AI-driven software development with TDD/DDD methodologies, autonomous agent orchestration, and quality gates across 16 programming languages.

## Key Features
- Single-binary Go implementation with zero dependencies for instant cross-platform execution (~5ms startup)
- 8 retained AI agents + 30 template-managed skills with autonomous TDD/DDD workflows and quality gates
- Harness Engineering paradigm for AI agent environment design (self-verify loops, context maps, session persistence)
- Automated methodology selection (TDD for new projects, DDD for existing low-coverage projects) with 16-language support
- Built-in quality enforcement (/simplify) and scale-out execution (/batch) for large-scale parallel agent tasks

## Why It Matters for RAG Builders
MoAI-ADK provides a production-grade framework for AI-driven software development, enabling RAG builders to integrate autonomous agent orchestration, quality-controlled workflows, and multi-language support into their stacks with minimal overhead.
