## Summary
The Vultisig SDK is a self-custodial multi-chain wallet framework designed for AI agents and developers, enabling secure cross-chain transactions, swaps, and portfolio management without seed phrases. It leverages MPC (Multi-Party Computation) security and supports 40+ blockchains.

## Key Features
- MPC-based key management with no seed phrases or single points of failure
- Cross-chain swaps via THORChain, 1inch, KyberSwap, and LiFi with automatic routing
- Programmatic SDK and CLI for AI agents and developers with TypeScript support
- Dry-run mode for transaction and swap previews to estimate fees and outputs
- Portfolio tracking with real-time balances and fiat prices across 40+ blockchains

## Why It Matters for RAG Builders
It provides a secure, self-custodial foundation for AI agents and applications to handle multi-chain transactions and swaps without exposing private keys, reducing security risks in RAG and AI workflows.
