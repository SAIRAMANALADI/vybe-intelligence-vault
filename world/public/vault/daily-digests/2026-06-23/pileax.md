## Summary
PileaX is a local-first AI knowledge base platform that combines AI chat, smart note-taking, and e-book management into a unified system. It enables users to build and optimize a personal knowledge base with AI agent technologies while ensuring full data control through offline and web deployments.

## Key Features
- Unified AI-powered chat assistant for knowledge retrieval and task execution
- Modern Notion-style editor for smart note-taking and organization
- AI-enhanced e-book reader with support for multiple formats (EPUB, MOBI, PDF)
- Cross-platform desktop and web deployment with Docker support
- Offline-first architecture ensuring full data control and privacy
