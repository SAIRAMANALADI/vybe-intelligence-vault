## Summary
NasTech Agent is a self-improving AI agent framework that autonomously creates, improves, and persists skills from experience. It supports multi-platform deployment, integrates with 200+ LLM providers, and offers a terminal UI, messaging gateway, and scheduled automations.

## Key Features
- Autonomous skill creation and self-improvement from experience
- Multi-platform deployment (CLI, Telegram, Discord, Slack, etc.)
- Built-in learning loop with persistent memory and cross-session recall
- Supports 200+ LLM providers with no vendor lock-in
- Scheduled automations and parallel subagent delegation
