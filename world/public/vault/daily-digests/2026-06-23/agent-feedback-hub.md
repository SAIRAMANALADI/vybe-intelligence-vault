## Summary
A lightweight, self-hosted feedback widget paired with an MCP server that enables AI coding agents to capture, analyze, and act on developer feedback in real time, fostering continuous learning and personalized code generation.

## Key Features
- Real-time feedback injection for AI agents during code generation sessions
- Multilingual, responsive React-based feedback widget with dark mode support
- Dual AI backend integration (OpenAI, Claude) and local LLM support (Ollama)
- Continuous learning via feedback profile storage and dynamic style adaptation
- Mermaid.js architecture diagrams and detailed API integration documentation

## Why It Matters for RAG Builders
It enables AI coding agents to dynamically adapt to developer preferences in real time, creating a personalized and efficient coding collaboration experience.
