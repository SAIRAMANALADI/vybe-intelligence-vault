## Summary
A governance layer for AI coding agents that provides role-specific profiles, skills, rules, and workflows to standardize agent behavior across tools like Claude Code, Cursor, and Copilot. It enables surgical configuration management and pack-scoped installations for reliable, vendor-agnostic AI team members.

## Key Features
- Six role-shaped entry paths (developer, founder, content creator, agency, finance, ops) with tailored command sets and skills
- Surgical uninstall and pack-scoped install to avoid polluting shared host configs
- Portability guard ensuring compatibility across any project or AI provider
- End-to-end workflows (Discovery, Implementation, Review, Delivery) with predefined command sequences
- CI-enforced source confidentiality and audit-disciplined state management for replayability

## Why It Matters for RAG Builders
It standardizes AI agent behavior across tools and roles, enabling reliable, vendor-agnostic workflows for RAG and AI stack builders.
