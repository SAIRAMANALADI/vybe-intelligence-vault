## Summary
ChatLab is an open-source desktop application designed to analyze and extract insights from social conversation histories using AI agents and a flexible SQL engine. It supports multiple platforms like WhatsApp, Discord, and Telegram, enabling users to explore patterns, ask questions, and visualize chat data locally.

## Key Features
- Stream parsing and multi-worker processing for handling large chat histories (million-message scale)
- Local-first architecture with optional cloud integration for privacy
- Agent + Function Calling workflows with 24+ tools for dynamic data analysis
- Cross-platform normalization of chat data into a unified model
- Insight-rich visualizations including trends, time patterns, and interaction rankings

## Why It Matters for RAG Builders
