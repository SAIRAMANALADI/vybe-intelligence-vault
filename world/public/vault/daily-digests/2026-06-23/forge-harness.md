## Summary
forge-harness is a meta-harness for Claude Code projects designed to raise the quality floor and accelerate development by enforcing adversarial governance gates, persistent project tracking, and cross-session learning. It structures projects into a portable hub with persistent context and skills that compound across sessions.

## Key Features
- Persistent project context via `tracks/` directories for resumable sessions across projects
- Adversarial and phantom governance gates (`fh-gate`) for post-generation code validation
- Cross-project knowledge accumulation and skill sharing through a central hub
- Four-axis quality gate (backward, adversarial, forward, record) for comprehensive validation
- Automated agent dispatch and orchestration for Claude Code and sidecar models

## Why It Matters for RAG Builders
It provides a structured, repeatable framework for enforcing quality gates and accelerating AI-driven development workflows, ensuring consistent governance and compounding improvements across projects.
