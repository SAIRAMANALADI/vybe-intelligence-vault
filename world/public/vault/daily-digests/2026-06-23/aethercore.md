## Summary
aethercore is a lightweight, fast-starting AI agent framework designed for distributed and edge computing environments. It operates in two modes (Pico and full mesh) and leverages Rust sandboxing for security while maintaining a minimal footprint under 10MB.

## Key Features
- Ultra-fast startup (<50ms) with minimal resource usage (<10MB)
- Dual operational modes: Pico (simple tasks) and full mesh (distributed AI)
- Rust-based sandboxing for enhanced security and stability
- Cross-platform compatibility (Windows-focused, but extensible)
- Open-source with straightforward setup and configuration
