## Summary
MEM BOT is an agentic Telegram chatbot with long-term memory, reminders, voice support, and model-callable tools. It features a bounded context memory system, configurable skills, and an admin web panel for managing interactions and data.

## Key Features
- Bounded long-term memory with structured dialogue history and personal/global facts
- Configurable skills and domains for domain-specific behavior and tools
- Model Context Protocol (MCP) integration for extensible tool usage
- Telegram channel support with voice input/output and streaming drafts
- Admin web panel for monitoring, configuration, and data inspection

## Why It Matters for RAG Builders
MEM BOT provides a robust framework for building agentic chatbots with advanced memory, tool integration, and multi-channel support, essential for RAG systems requiring persistent context and proactive interactions.
