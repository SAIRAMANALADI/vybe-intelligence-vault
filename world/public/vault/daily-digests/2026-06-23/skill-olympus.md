## Summary
Skill Olympus is a production-grade agent harness and loop-engineering stack for Claude Code, Codex CLI, and Gemini CLI, enabling autonomous SaaS development through a pantheon of 12 specialized agents. It automates the entire pipeline from design to deployment with zero human intervention.

## Key Features
- Zero-interaction full SaaS pipeline automation via `/zeus` command
- Cross-CLI persistent memory (`mnemo`) for session continuity across tools
- Autonomous loop-engineering with verification gates (`/chronos`, `/minos`, `/argos`)
- 12 specialized agents (e.g., `/zephermine`, `/clio`, `/poseidon`) for distinct roles in development
- Pre-launch quality gates, rollback playbooks, and decision records for production readiness
