## Summary
Charles-mcp is a Model Context Protocol (MCP) server that bridges Charles Proxy with AI agents, enabling real-time and historical traffic analysis, structured summarization, and reverse engineering workflows for API traffic inspection and manipulation.

## Key Features
- Real-time and historical traffic capture with structured summarization for AI agents
- Reverse engineering toolchain for authentication, signature analysis, and replay workflows
- Agent-friendly tool contracts with summary-first output to optimize token usage
- Seamless integration with MCP clients (Claude, Cursor, etc.) via uvx for zero-setup deployment
- Live and history analysis with drill-down capabilities for detailed traffic inspection

## Why It Matters for RAG Builders
It enables AI agents to dynamically analyze, inspect, and manipulate API traffic in real-time, bridging the gap between raw proxy data and structured, actionable insights for reverse engineering and debugging workflows.
