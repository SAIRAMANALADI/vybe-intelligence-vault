## Summary
OrionBelt Semantic Layer (OBSL) is an open-source semantic sidecar that injects governed business semantics into AI, analytics, and data systems without requiring architectural changes. It compiles declarative YAML models into optimized SQL, semantic context, KPIs, and data quality rules across multiple database dialects.

## Key Features
- Declarative YAML-based semantic modeling for dimensions, measures, and metrics
- Multi-dialect SQL compilation (BigQuery, PostgreSQL, Snowflake, ClickHouse, etc.)
- PostgreSQL wire and Arrow Flight SQL protocol support for BI tool integration
- Data quality rules and KPI definitions embedded in semantic models
- Unified authentication and API-key management across all surfaces

## Why It Matters for RAG Builders
It enables AI and analytics systems to query data using business concepts instead of raw schemas, ensuring governed, reproducible, and dialect-aware SQL generation for RAG and agentic AI workflows.
