## Summary
The Oak Open Curriculum Ecosystem transforms Oak National Academy's open curriculum into AI-native infrastructure, enabling AI assistants like ChatGPT and Claude to interact with curriculum data via the Model Context Protocol (MCP). It provides reusable tools, SDKs, and frameworks for building curriculum-aware applications and agentic engineering practices.

## Key Features
- MCP server for AI assistants to interact with Oak's curriculum data
- TypeScript SDK generated from OpenAPI schema for typed curriculum access
- Hybrid semantic search for curriculum resources using Elasticsearch
- Openly documented agentic engineering framework for AI-first development
- Reusable sector components for building curriculum-aware applications

## Why It Matters for RAG Builders
