## Summary
voicebridge enables hands-free, two-way voice interactions with coding agents (Claude, Codex, Antigravity, Ollama) directly from a phone browser, eliminating third-party voice services like ElevenLabs. It streams speech-to-text and text-to-speech locally or via Web Speech API, with sessions managed over Tailscale HTTPS.

## Key Features
- Multi-agent support (Claude, Codex, Antigravity, Ollama) with session management
- Browser-based voice interaction via Web Speech API (no cloud voice costs)
- Streaming text-to-speech and speech-to-text with real-time barge-in capability
- Private network exposure via Tailscale HTTPS for secure, local-first communication
- Optional fully-local speech-to-text using Whisper for privacy

## Why It Matters for RAG Builders
It provides a seamless, private, and cost-effective way to interact with coding agents via voice, reducing dependency on external voice services while maintaining real-time responsiveness.
