## Summary
xstitch is a Windows-based tool designed to manage and preserve AI memory across multiple AI coding assistants and platforms, enabling seamless context handoffs without repeating work or losing track of decisions and warnings.

## Key Features
- Enables memory sharing across nine+ AI tools for smooth handoffs
- Saves decisions, warnings, and errors in lightweight files for quick retrieval
- Zero dependencies required, runs natively on Windows
- Uses BM25 search for efficient retrieval of past context
- Supports easy setup and integration with popular AI coding assistants

## Why It Matters for RAG Builders
xstitch ensures AI agents and developers retain critical context when switching tools, reducing redundant work and improving productivity in complex AI workflows.
