## Summary
An AI-powered cybersecurity agent that analyzes PCAP captures and network logs using Isolation Forest for anomaly detection, then generates structured threat reports with CVE context and mitigations via an OpenAI tool-calling loop.

## Key Features
- Unsupervised anomaly detection using Isolation Forest on PCAP and network logs
- OpenAI tool-calling loop for grounded threat explanations and mitigations
- Structured threat reports with CVE context and MITRE ATT&CK mappings
- Bounded agent design ensuring human review before any action
- Support for interactive chat mode and sample data generation

## Why It Matters for RAG Builders
Provides a practical, unsupervised approach to detecting network anomalies and generating actionable threat intelligence, bridging raw data analysis with human-readable security insights.
