## Summary
PDF-QA-RAG-System is a Streamlit-based application that enables users to upload PDF documents and query them using a Retrieval-Augmented Generation (RAG) pipeline. It leverages LangChain for processing, Ollama for response generation, and Chroma for vector storage and retrieval to deliver contextually accurate answers.

## Key Features
- Context-based answers from uploaded PDFs using RAG
- User-friendly Streamlit interface for seamless interaction
- Supports multiple PDF uploads for comprehensive querying
- Efficient document retrieval and generation with LangChain and Chroma
- Cross-platform compatibility with pre-built installers

## Why It Matters for RAG Builders
It provides a ready-to-use RAG pipeline for extracting insights from PDFs, reducing development time for AI engineers building document-based question-answering systems.
