## Summary
A CLI tool that integrates CometChat's chat, voice, and video calling capabilities into web and mobile projects (React, React Native, Angular, Android, Flutter, iOS) via AI coding agents like Claude Code or Cursor. It automates framework detection, project setup, and code generation tailored to the user's existing project structure.

## Key Features
- AI-first project setup with framework detection (React, Angular, Android, etc.)
- Automated generation of production-ready integration code tailored to existing projects
- Supports chat, voice, and video calling with Visual Builder for UI customization
- Works with 50+ AI coding agents (Claude Code, Cursor, VS Code Copilot, etc.)
- CLI-driven onboarding, app provisioning, and diagnostics without browser round-trips
