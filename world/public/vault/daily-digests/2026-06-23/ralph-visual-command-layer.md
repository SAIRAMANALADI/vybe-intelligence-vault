## Summary
Ralph Desktop Studio is a visual AI task orchestrator that transforms fragmented AI workflows into a spatial, iterative canvas for brainstorming, prompt refinement, and task automation. It enables users to visually design, refine, and execute AI-driven creative and coding tasks with real-time iteration and multilingual support.

## Key Features
- Visual brainstorming canvas with drag-and-drop prompt nodes and color-coded organization
- Prompt refinement engine using evolutionary algorithms for iterative improvement
- Task automation through branching logic, loops, and conditional execution
- Multilingual prompt support across 40+ languages with idiomatic preservation
- Cross-platform UI with responsive design for desktop, tablet, and mobile
