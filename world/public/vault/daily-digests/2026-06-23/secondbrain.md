## Summary
SecondBrain provides persistent memory for LLM agents, enabling seamless context retention across sessions and models. It automates context capture, archiving, and retrieval, eliminating manual re-briefing and enabling cross-LLM continuity.

## Key Features
- Automated context capture and archiving during LLM sessions without manual intervention
- Cross-LLM continuity enabling seamless switching between models (Claude, Gemini, Codex, etc.)
- Git repository archaeology for reconstructing project history into structured archives
- Visualization via Obsidian with knowledge graphs and full-text search
- Multi-language support (EN, FR, ES, DE, RU) with automatic language detection

## Why It Matters for RAG Builders
It eliminates the need for manual re-briefing between LLM sessions, drastically improving productivity and reducing token costs while enabling true cross-model continuity for RAG and AI workflows.
