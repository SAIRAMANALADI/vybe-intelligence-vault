## Summary
A high-performance, asynchronous Rust SDK for building Model Context Protocol (MCP) servers and clients. It provides protocol implementation, transport layers, and procedural macros to simplify MCP development while supporting the latest protocol specifications.

## Key Features
- Full implementation of the latest MCP protocol (2025-11-25) with backward compatibility
- Supports multiple transports: Stdio, Streamable HTTP, and SSE
- Procedural macros for tool and resource definitions, reducing boilerplate
- Built-in OAuth authentication for both servers and clients
- Framework-agnostic HTTP server integrations (Axum, Actix) and BYO-server support

## Why It Matters for RAG Builders
This SDK is essential for RAG/AI stack builders who need a robust, high-performance Rust-based solution to implement MCP servers and clients, enabling seamless integration with AI agents and tools.
