## Summary
BrowserKing is a browser automation tool designed to enable LLMs to interact with web pages by clicking, typing, scrolling, reading content, taking screenshots, and replaying workflows. It bridges the gap between AI models and real-time web interactions.

## Key Features
- Enables LLMs to control web browsers programmatically
- Supports multiple automation libraries (Selenium/Playwright)
- Allows capturing screenshots and reading page content
- Facilitates replaying recorded browser workflows
- Integrates with any LLM provider for dynamic interactions
