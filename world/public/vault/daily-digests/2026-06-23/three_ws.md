## Summary
three.ws is an open-source, browser-native 3D AI agent platform that enables users to generate, render, embody, register, and embed 3D AI agents. It supports text-to-3D, image-to-3D, and sketch-to-3D model creation, and integrates LLM-driven agent runtimes with on-chain identity for autonomous, embeddable agents.

## Key Features
- Browser-native 3D model rendering with WebGL 2.0 and glTF/GLB support
- Text, image, and sketch-to-3D model generation with auto-rigging and texturing
- LLM-driven agent runtime with real-time emotion expression and tool execution
- On-chain identity via ERC-8004 (EVM) and Metaplex Core (Solana) for permanent agent ownership
- Embeddable web component for seamless integration into any webpage

## Why It Matters for RAG Builders
It bridges the gap between 3D AI agents and real-world deployment by providing a full-stack, browser-native platform for generating, embodying, and embedding autonomous agents with on-chain identity and LLM integration.
