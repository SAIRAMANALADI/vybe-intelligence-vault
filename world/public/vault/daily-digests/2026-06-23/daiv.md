## Summary
DAIV is an open-source async software engineering agent that integrates with GitLab and GitHub to automate routine tasks like issue resolution, pull request management, and code reviews directly within your existing workflow via webhooks.

## Key Features
- Issue-to-code automation with plan approval workflows
- Pull request assistant for reviewer feedback and CI repair
- Slash commands and custom skills for extensibility
- MCP endpoint for AI coding assistant integration
- Scheduled jobs for recurring maintenance tasks
