## Summary
A Japanese business intelligence system that aggregates and verifies public corporate data from three government sources (gBizINFO, J-Grants, and 国税庁) into a unified MCP server, API, and dashboard for AI-native due diligence and financial analysis.

## Key Features
- Three-source authority chain for verifiable Japanese company data (gBizINFO, J-Grants, 国税庁)
- Native MCP server and Claude/OpenAI plugin for real-time AI queries
- RESTful API and WebSocket event stream for dynamic data access
- Multi-language support (Japanese, English, Chinese) with automatic detection
- Citable responses with source URLs and timestamps for AI-generated outputs

## Why It Matters for RAG Builders
It provides a single, auditable source of truth for Japanese corporate and grant data, enabling AI systems to generate verifiable financial intelligence without manual scraping or data fragmentation.
