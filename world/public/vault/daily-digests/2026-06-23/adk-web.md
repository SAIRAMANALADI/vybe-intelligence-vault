## Summary
adk-web is a user-friendly desktop application designed to simplify the development and debugging of agents using the Agent Development Kit (ADK). It provides a visual interface for managing projects, debugging performance issues, and analyzing agent behavior.

## Key Features
- Visual agent project management with a clean, intuitive interface
- Integrated debugging tools for identifying and resolving agent performance issues
- Performance analytics with visual reports for monitoring agent behavior
- Cross-platform support for Windows, macOS, and Linux
- Seamless integration with the Google ecosystem for agent development
