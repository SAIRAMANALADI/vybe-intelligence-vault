## Summary
MCPJam Inspector is a comprehensive development and debugging platform for MCP servers, MCP apps, and ChatGPT apps. It provides tools for inspecting JSON-RPC messages, debugging OAuth flows, running evaluations, and managing MCP server interactions through a web app, desktop client, or CLI.

## Key Features
- Full JSON-RPC message inspection and tracing for MCP servers and apps
- Multi-model chat with trace visibility for tool calls and context
- Guided OAuth debugging with support for multiple protocol versions
- Automated evals and regression testing across LLMs with metrics tracking
- CLI and SDK for programmatic testing, CI/CD integration, and custom workflows
