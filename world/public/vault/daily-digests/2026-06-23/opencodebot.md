## Summary
opencodebot is a Telegram bot designed as a companion to OpenCodez, mirroring its sessions into Telegram forum topics for interactive control and monitoring. It simplifies prompt management, tool execution, and session tracking via a chat interface while maintaining OpenCodez as the primary workspace.

## Key Features
- Telegram forum topic mirroring for OpenCodez sessions
- In-memory prompt queue with status and delete commands
- Rich assistant message formatting and tool quote expansion
- Support for attachments and multipart prompt buffering
- Optional WireGuard helper for private remote access to OpenCodez UI

## Why It Matters for RAG Builders
It bridges OpenCodez sessions into a conversational interface, enabling real-time AI workflow management and monitoring via Telegram for developers and operators.
