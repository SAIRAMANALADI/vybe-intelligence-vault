## Summary
A collection of open-source AI bots designed to run on Lark (飞书) for automating workflows across seven key scenarios, including brainstorming, project planning, daily assistance, creative prompt generation, sentiment monitoring, news aggregation, and end-to-end content creation.

## Key Features
- Seven specialized AI bots covering brainstorming, planning, content creation, sentiment monitoring, and more, all shareable via Lark chat interface
- AgentLoop-based multi-agent collaboration with role specialization (e.g., five AI roles for brainstorming with distinct responsibilities)
- Modular architecture with shared core modules (LLM calls, Lark API, AgentLoop, skill systems) for scalability and maintainability
- Local Studio workstation (Streamlit app) for offline use without requiring Lark integration
- Automated cross-bot workflows (e.g., brainstorming conclusions triggering content creation or project planning)

## Why It Matters for RAG Builders
It provides a modular, multi-agent framework for automating complex workflows in Lark, reducing manual effort while maintaining security and scalability for RAG and AI stack builders.
