## Summary
boss-cli is a Windows command-line tool for interacting with BOSS 直聘, a Chinese job search platform. It enables users to search jobs, view recommendations, apply to positions, and manage applications directly from the terminal using a reverse-engineered API.

## Key Features
- Search job listings via command-line with keywords
- View personalized job recommendations based on user profile
- Apply to jobs directly using job IDs
- Track and manage applied jobs through a simple interface
- Secure local storage of BOSS 直聘 credentials
