## Summary
MCM-ICM-Agent is a local command-line agent designed to assist with MCM/ICM mathematical modeling competitions by providing an integrated knowledge base and retrieval system. It includes a prebuilt vector database of 451 Outstanding papers (2004–2025) with structured teardowns and reusable paradigms.

## Key Features
- Prebuilt ChromaDB vector index for 451 Outstanding MCM/ICM papers (2004–2025) with structured teardowns and patterns
- Zero-dependency browsing of JSON metadata and structured content
- Semantic retrieval via Voyage API embeddings with prebuilt vector DB (410M)
- Command-line interface for querying, building, and managing the knowledge base
- Modular design allowing custom embedding models and rebuilds from raw markdown

## Why It Matters for RAG Builders
Provides a specialized, high-quality vector database and retrieval system tailored for MCM/ICM mathematical modeling competitions, enabling AI agents to leverage expert-curated knowledge for problem-solving and analysis.
