## Summary
This repository serves as the official Homebrew Cask tap and distribution channel for Knotpad, a note-first project management application for developers. It hosts compiled release installers, update metadata, and installation scripts for macOS, Windows, and Linux.

## Key Features
- Official Homebrew Cask tap for Knotpad installation and updates
- Cross-platform support (macOS, Windows, Linux)
- Auto-updater powered by Tauri for seamless version updates
- Standalone installers (.dmg, .msi, .AppImage) for manual installation
- GitHub-based release and update metadata management
