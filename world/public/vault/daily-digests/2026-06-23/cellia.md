## Summary
CelliA is a fully autonomous tech media platform that auto-updates 5 times daily by scraping and summarizing content from tech communities (e.g., Hacker News, Reddit) using LLMs. It generates concise articles and includes a built-in Lofi Radio for an enhanced reading experience.

## Key Features
- Fully automated content generation and publishing pipeline with zero human maintenance
- Multi-API fallback system (Groq → Mistral AI → Google Gemini) for resilience against rate limits
- Targeted scraping from 20+ high-quality tech sources (Hacker News, Reddit, blogs)
- Built-in Lofi Radio with persistent state and backup streams for ambient reading
- Free deployment using GitHub Pages and GitHub Actions Secrets for secure API key management
