## Summary
AgentSecurityLens (ASL) is a security intelligence MCP that enables autonomous agents to evaluate risks before installing or enabling tools, MCPs, skills, or other components. It provides machine-readable risk assessments, safer alternatives, and enforceable decision contracts to mitigate security threats in agent workflows.

## Key Features
- Pre-install component risk evaluation with machine-readable decisions
- Public security intelligence index for fallback assessments
- Enforceable decision contracts (allow, avoid, ask_user, allow_with_restrictions)
- Local fallback mode with curated baseline intelligence
- Privacy-preserving API for public component metadata only

## Why It Matters for RAG Builders
It provides critical pre-install security checks for autonomous agents, reducing exposure to malicious or risky tools while enabling safer automation workflows.
