## Summary
SOAT is an open-source infrastructure framework for building production-ready AI agents, providing a self-hostable Node.js server with IAM, vector search, conversational memory, agent orchestration, and MCP support. It abstracts away repetitive infrastructure tasks to accelerate AI application development.

## Key Features
- Unified IAM system with JWT, API keys, and policy-based access control
- PostgreSQL-backed vector search for documents, memories, and knowledge
- Multi-agent workflows with tool-calling and reasoning loops
- Declarative agent formations for reproducible deployments
- Native MCP server integration for seamless AI runtime compatibility

## Why It Matters for RAG Builders
SOAT eliminates the need to rebuild foundational AI infrastructure by providing a single, self-hostable server that handles identity, storage, orchestration, and observability, enabling developers to focus on building agentic applications rather than infrastructure.
