## Summary
The Stall is a pay-per-call AI data tool platform offering 210+ MCP-compatible capabilities accessible via x402 (USDC on Base) or Stripe prepaid credits. It provides real-time data across domains like crypto, equities, weather, and on-chain analytics without requiring subscriptions or API keys.

## Key Features
- 210+ pay-per-call AI data tools with no subscriptions or API keys required
- Dual payment rails: x402 (USDC on Base) and Stripe prepaid credits

- Covers diverse domains: crypto, equities, weather, on-chain analytics, and government data
- Live endpoint with structured catalog and real-time pricing
