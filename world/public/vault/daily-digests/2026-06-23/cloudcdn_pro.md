## Summary
CloudCDN is a multi-tenant, AI-native CDN platform built on Cloudflare Workers and Pages, offering sub-100ms TTFB across 300+ PoPs. It provides agent-controllable features via MCP, WCAG-AA accessibility, and a passkey-protected dashboard, all deployable as a self-hosted solution.

## Key Features
- Multi-tenant zone management with isolated cache tags and per-asset analytics
- AI-powered image transformations (alt-text, smart-crop, moderation) and semantic search
- Agent-controllable via MCP server with 42 tools and 6 resources for AI-driven CDN management
- WCAG-AA accessible, light/dark themed dashboard with passkey authentication
- Immutable 90-day audit logs, quota-resilient AI endpoints, and 100% test coverage

## Why It Matters for RAG Builders
CloudCDN provides a self-hostable, AI-native CDN with agent-driven control and edge analytics, enabling RAG builders to deploy scalable, accessible, and high-performance content delivery with minimal latency.
