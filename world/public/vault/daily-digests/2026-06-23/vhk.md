## Summary
VHK (Vibe Harness Kit) is a Korean-language CLI tool designed to standardize and manage AI coding sessions by anchoring goals, evidence, context, and rules across multiple AI agents and tools. It ensures consistency, verification, and seamless handoffs in AI-driven development workflows.

## Key Features
- Unified rule synchronization across AI agents (Cursor, Claude, Windsurf, etc.) via `RULES.md` and `vhk sync`
- Evidence-based trust loops with `verify`, `review`, `preflight`, and `testmap` for rigorous validation
- Goal-driven workflow with `goals/*.md` and `HARD_STOP` enforcement for blocking repetitive failures
- Memory and pattern learning system (`memory.json`, `pattern detect`, `evolve`) to capture and reuse project insights
- MCP integration with 30+ tools for seamless interaction with AI agents and local development environments

## Why It Matters for RAG Builders
VHK ensures AI coding sessions remain consistent, verifiable, and context-aware, reducing errors and improving productivity for RAG and AI stack builders.
