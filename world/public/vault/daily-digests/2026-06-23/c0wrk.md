## Summary
c0wrk is an early-stage desktop AI research and development agent designed for complex tasks, featuring a DAG-based planner, security policies, and multi-modal tool integration. It combines a React/TypeScript frontend with a Go backend and supports advanced features like sub-agent spawning, hybrid code search, and configurable LLM providers.

## Key Features
- ReAct-style step execution with DAG planner, router, and reflector for adaptive task handling
- Hybrid code search combining vector embeddings (ONNX Runtime) and BM25 with Reciprocal Rank Fusion
- Configurable security policies for tool execution, including LLM judge for risk assessment
- Sub-agent spawning for parallel or delegated task execution within sessions
- Cross-platform desktop UI with chat, execution panels, workspace tree, and terminal integration

## Why It Matters for RAG Builders
