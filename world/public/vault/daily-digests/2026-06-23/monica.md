## Summary
Monica is a modular .NET infrastructure framework designed for C# AI-era backends, combining typed DDD ProjectUnits, composable modules, built-in dashboards, and bundled agent skills to ensure observability and maintainability as systems grow.

## Key Features
- Composable infrastructure modules with standardized registration via `Mo.Add*()` pattern
- Typed DDD ProjectUnits for AI-guided backend development and maintainability
- Built-in operational dashboards (JobScheduler, Configuration, AI, etc.) with Blazor UI
- Bundled agent skills for Monica-aware AI assistants to generate compliant code
- Global configuration and module-specific options with precedence rules

## Why It Matters for RAG Builders
Monica provides a structured, AI-friendly foundation for building scalable .NET backends with observability and maintainability, reducing brittleness in AI-generated code.
