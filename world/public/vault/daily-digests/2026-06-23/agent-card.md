## Summary
A structured identity card for AI agents that provides machine-readable discovery of agent capabilities, trust signals, and protocol-level interfaces. Supports both the reflectt `agent-identity-kit` spec and the A2A protocol, enabling interoperability between autonomous agents.

## Key Features
- Dual-format identity cards (reflectt v1 and A2A 1.0) for trust and protocol discovery
- Machine-readable `.well-known/agent.json` and `agent-card.json` files for standardized agent discovery
- Human and LLM-friendly companion files (`AGENT.md`, `llms.txt`) for context
- Validation script (`agent-validate.py`) for schema compliance
- Compatibility documentation for field mappings between specs

## Why It Matters for RAG Builders
It standardizes how AI agents expose their identity, capabilities, and trustworthiness, enabling seamless interoperability and discovery in RAG and multi-agent systems.
