## Summary
flyto-core is an open-source automation engine designed for debuggable, replayable workflows with built-in tracing and evidence snapshots. It enables step-by-step execution, breakpoint debugging, and context-preserving replays, reducing the complexity of automating browser, API, and file operations.

## Key Features
- Structured execution trace with per-step timing, input/output, and status
- Replay workflows from any step with preserved context
- 467+ pre-built modules for browser, API, file, and data operations
- MCP-native integration for AI agent tooling (Claude, Cursor, Windsurf)
- Breakpoints, evidence snapshots, and data lineage tracking

## Why It Matters for RAG Builders
It provides a robust, debuggable foundation for orchestrating AI agent workflows with built-in replayability and traceability, critical for debugging complex automation tasks.
