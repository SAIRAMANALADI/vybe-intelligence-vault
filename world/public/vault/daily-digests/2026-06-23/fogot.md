## Summary
Fogot Engine is a fork of Godot Engine 4.7 that integrates an AI assistant panel directly into the 2D game editor. It combines a C++ WebView host with a React-based frontend to provide intelligent assistance for game development tasks like GDScript editing, sprite processing, and animation generation.

## Key Features
- AI assistant panel integrated into Godot Editor for real-time game development assistance
- Hybrid architecture with C++ WebView host and React frontend for seamless interaction
- Extensive toolset for file operations, scene management, and image processing via AI RPC calls
- Multi-agent orchestration and streaming LLM conversations for dynamic task execution
- Cross-platform support for macOS and Windows with planned Linux compatibility

## Why It Matters for RAG Builders
It bridges AI capabilities directly into a game engine editor, enabling developers to leverage intelligent assistants for complex game development tasks without leaving the workflow.
