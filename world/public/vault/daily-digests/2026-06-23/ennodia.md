## Summary
Ennodia is a local MCP server enabling AI agents to collaborate by requesting assistance from other agents during task execution. It routes requests, executes tools, tracks progress, and synthesizes results from multiple agents for improved reliability.

## Key Features
- Enables real-time collaboration between AI agents via MCP protocol
- Plans and routes requests to the most suitable agent or tool
- Tracks task status, logs, and failures with detailed monitoring
- Compares multiple outputs to synthesize a final answer
- Supports cancellation, retries, and explicit task control

## Why It Matters for RAG Builders
Ennodia enables robust, multi-agent collaboration for RAG systems, improving reliability by distributing tasks and validating outputs across multiple agents.
