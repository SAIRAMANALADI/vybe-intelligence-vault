## Summary
Wukong is a Rust-based personal AI assistant inspired by the Chinese mythological Monkey King, featuring persistent memory, multi-role agent orchestration, and session isolation. It integrates recall, routing, execution, and memory retention into a unified CLI workflow for continuous, context-aware interactions.

## Key Features
- Four-pillar architecture (Memory, Gateway, Orchestrator, CLI) for modular AI agent execution
- Persistent memory layer with SQLite + FTS5 for context-aware recall and scope isolation
- Multi-role collaboration chains (Explorer, Oracle, Librarian, Fixer, Designer) with skill routing
- Unified CLI (`wukong`) integrating recall, routing, execution, and memory retention in a single workflow
- Docker and Binary deployment modes with environment-aware configuration and permission management

## Why It Matters for RAG Builders
Wukong provides a structured framework for building RAG systems with persistent memory, multi-agent collaboration, and session isolation, enabling context-aware AI assistants that retain long-term context across interactions.
