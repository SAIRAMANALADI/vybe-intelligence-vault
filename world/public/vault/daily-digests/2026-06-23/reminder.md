## Summary
A natural-language reminder secretary that schedules Telegram notifications for events described in Chinese or English. It stores structured event data in a Git-syncable workspace and integrates with OpenClaw for cron-based reminders.

## Key Features
- Parses natural-language event descriptions in Chinese and English
- Stores events in a structured, Git-syncable YAML file
- Schedules Telegram reminders via OpenClaw cron with customizable lead times
- Supports timezone configuration and upcoming event queries
- Integrates seamlessly with the OpenClaw ecosystem

## Why It Matters for RAG Builders
It provides a lightweight, natural-language way to schedule and track reminders across devices, enhancing personal productivity for AI stack builders.
