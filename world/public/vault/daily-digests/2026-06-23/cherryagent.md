## Summary
CherryAgent is a self-hosted AI agent platform designed for personal automation, running on budget VPS (~$10/month). It enables users to control and automate tasks via Telegram, with configurable system access and tiered model routing to optimize costs.

## Key Features
- Tiered model routing for cost optimization (Groq → DeepSeek → Gemini → Claude)
- Modular monorepo architecture with core, tools, and API packages
- Telegram-based control interface with natural language and photo inputs
- Integrated food logging with Fitbit sync and OpenFoodFacts barcode lookup
- Budget tracking with envelope-based expense management

## Why It Matters for RAG Builders
CherryAgent provides a cost-effective, self-hosted framework for building personalized AI agents with configurable tool access and multi-model routing, ideal for developers seeking budget-conscious automation solutions.
