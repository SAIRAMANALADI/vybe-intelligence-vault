## Summary
Maskin is an open-source workspace where AI agents autonomously execute product development workflows. Humans define direction while agents handle insights, bets, tasks, and feedback loops through a unified API-driven system.

## Key Features
- Unified object model for insights, bets, and tasks with shared schema and relationships
- Container-based agent execution using Docker for ephemeral environments
- Event-sourced activity logging for audit trails and real-time updates via PG NOTIFY
- API-first design with identical endpoints for UI and agent interactions
- Modular monorepo with Turborepo for parallel builds and dependency-aware caching

## Why It Matters for RAG Builders
Maskin provides a standardized platform for orchestrating AI agents in product development workflows, enabling seamless integration of human direction and autonomous execution through a unified API.
