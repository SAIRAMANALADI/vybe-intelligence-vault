## Summary
A Model Context Protocol (MCP) server for Chrome Enterprise Premium (CEP) that exposes Chrome's security, DLP, and management capabilities as tools for AI agents. It enables natural-language interaction with Chrome Enterprise environments for configuration, monitoring, and policy enforcement.

## Key Features
- Exposes Chrome Enterprise Premium tools (DLP, security, licensing, telemetry) via MCP for AI agents
- Supports OAuth authentication with Google Workspace admin accounts
- Provides health checks, optimization prompts, and expert-mode interactions
- Enables programmatic management of Chrome policies, extensions, and connectors
- Includes built-in documentation and troubleshooting guides for administrators

## Why It Matters for RAG Builders
It bridges Chrome Enterprise Premium's enterprise-grade security and management features with AI agents, enabling secure, natural-language-driven automation for large-scale browser fleet management.
