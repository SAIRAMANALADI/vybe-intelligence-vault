## Summary
PiClaw packages the Pi Coding Agent into a self-hosted AI workspace with a streaming web UI, persistent state, multi-provider LLM support, and a built-in toolset for agent-first workflows. It simplifies AI agent deployment by consolidating chat, editor, terminal, and automation into a single application.

## Key Features
- Unified web UI with chat, editor, terminal, and automation tools
- Persistent SQLite-backed state for messages, media, and tasks
- Multi-provider LLM support with custom OpenAI-compatible endpoints
- Built-in toolset including code editing, file viewers, and automation scripts
- Optional authentication (TOTP/passkeys) and cross-instance interoperability

## Why It Matters for RAG Builders
PiClaw simplifies the deployment of stateful AI agents by consolidating multiple tools and services into a single self-hosted workspace, reducing integration overhead for RAG builders.
