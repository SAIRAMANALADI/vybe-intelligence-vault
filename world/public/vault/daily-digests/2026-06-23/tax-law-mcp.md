## Summary
tax-law-mcp is a local Windows application that provides access to Japanese tax law documents, including official notices and rulings sourced from the e-Gov API and tax authority websites. It serves as a standalone server with a web-based interface for browsing and searching tax laws offline.

## Key Features
- Provides offline access to Japanese tax law documents and official notices
- Automatically fetches updates from e-Gov API and tax authority sources
- User-friendly web interface for searching and browsing tax laws
- Supports offline browsing with cached data after initial setup
- Configurable settings for language, update frequency, and data storage
