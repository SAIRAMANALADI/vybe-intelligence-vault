## Summary
Unity MCP enables AI assistants to control the Unity Editor via the Model Context Protocol (MCP), allowing scene manipulation, playtesting, and automation with significant token savings through batch operations.

## Key Features
- Control Unity Editor directly from AI assistants (Claude, Codex, etc.) via MCP for scene CRUD, animation, VFX, and playtesting.
- Token optimization with batch operations reducing 80-95% of tokens compared to individual calls.
- In-Unity chat interface with typed context chips, per-turn undo, and domain-reload safety.
- PlayTest DSL for scripting complex test scenarios with assertions and snapshots.
- Extensible plugin system allowing custom tool registration with zero cross-imports.
