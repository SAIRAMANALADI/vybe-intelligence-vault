## Summary
pinescript-ai is a desktop application that automates the generation of PineScript code for TradingView indicators and strategies using AI. It supports multiple AI providers, runs locally for privacy, and includes built-in validation and real-time editing features.

## Key Features
- Multi-provider AI integration (OpenAI, Anthropic, Google, Ollama)
- Three-layer code validation for accuracy and reliability
- Real-time PineScript code generation and editing
- Local execution ensuring API key privacy
- Built-in syntax highlighting and error detection
