## Summary
ForkTTY is a Linux-native multi-agent terminal that provides isolated workspaces for coding agents, a programmable local Unix socket API, and first-class git worktree integration. It combines GTK4/libadwaita with embedded Ghostty terminals for a native terminal experience and supports agent-agnostic automation.

## Key Features
- Isolated workspaces for coding agents with native git worktree support
- Programmable local Unix socket API for agent-agnostic automation
- Embedded Ghostty terminals with GTK4/libadwaita UI for native Linux experience
- Prompt-aware notifications and session management with quake mode support
- Agent-agnostic CLI and socket commands for workflow orchestration

## Why It Matters for RAG Builders
