## Summary
An AI-native MCP server for JavaScript reverse engineering that enables AI coding assistants to debug, analyze, and reverse-engineer web JavaScript behavior with advanced tooling for breakpoints, network analysis, and anti-detection mechanisms.

## Key Features
- AI-first tooling designed for agent decision-making with granular control over breakpoints, network requests, and script analysis
- Advanced anti-detection mechanisms (Patchright protocol layer and CloakBrowser binary patches) to bypass anti-bot systems
- Comprehensive debugging workflow including script source extraction, breakpoint management, and network/WebSocket analysis
- State replay and cookie/fingerprint management for reproducing and debugging complex workflows
- Seamless integration with AI coding assistants (Claude, Cursor, Copilot) via MCP protocol
