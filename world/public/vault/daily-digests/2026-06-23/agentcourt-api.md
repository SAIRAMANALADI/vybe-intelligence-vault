## Summary
AgentCourt is a policy-driven, deterministic dispute resolution API for AI agent commerce. It enables automated, non-custodial rulings on agent transactions by evaluating evidence against predefined policy rules, ensuring fast (<500ms) and explainable outcomes without escrow.

## Key Features
- 7 policy templates with 39 deterministic rules covering disputes like freelance delivery, SLA monitoring, and API quality
- Sub-500ms ruling generation with high confidence and explainable reasoning
- x402-native payment integration ($0.05/dispute in USDC on Base) for per-call monetization
- Zero-dependency SDKs (Python, JavaScript/TypeScript) and MCP server for seamless integration with AI agents and tools
- Non-custodial design with no escrow, focusing on reputation and enforcement outcomes

## Why It Matters for RAG Builders
AgentCourt provides the critical missing layer for AI agent commerce by enabling automated, fair, and fast dispute resolution without escrow, ensuring trust and scalability in agent-to-agent transactions.
