## Summary
seerai is an AI-powered research assistant plugin for Zotero 9 that integrates chat, semantic search, RAG, and agentic workflows directly into the Zotero interface. It enables contextual conversations with research papers, federated scholarly search, structured data extraction, and multimodal analysis while maintaining privacy through local-first design.

## Key Features
- AI-powered chat with contextual paper analysis and streaming responses
- Federated scholarly search across 11 providers with AI query refinement
- Agentic chat with 148+ skills library and tool-use capabilities
- Structured data extraction into comparative tables with AI-generated columns
- Built-in workspace with file management, Git integration, and cloud storage

## Why It Matters for RAG Builders
It streamlines AI-assisted research workflows by integrating RAG, agentic tools, and semantic search directly into Zotero, making it essential for researchers building evidence-based AI systems.
