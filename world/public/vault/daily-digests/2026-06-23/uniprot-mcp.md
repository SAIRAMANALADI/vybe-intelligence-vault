## Summary
A Model Context Protocol (MCP) server for the UniProt protein knowledgebase that provides 41 tools across 8 families, with per-query provenance verification via SHA-256 hashes, release pinning, and offline replay capabilities. It enables auditable, traceable, and verifiable access to UniProt data for regulated environments.

## Key Features
- 41 tools across 8 families for UniProt data access
- Per-query provenance verification with SHA-256 hashes and release pinning
- Offline replay capability for historical data verification
- Pre-registered benchmark with SHA-256 commitments for reproducibility
- Comprehensive error handling and input validation

## Why It Matters for RAG Builders
It provides a critical auditable and verifiable layer for RAG systems accessing UniProt data, ensuring regulatory compliance and long-term data integrity in biomedical applications.
