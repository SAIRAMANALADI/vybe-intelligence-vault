## Summary
apcore-mcp-python is a zero-code MCP server and OpenAI tools bridge for apcore-based projects, enabling automatic exposure of existing modules as MCP tools or OpenAI-compatible tools without modifying the original project code.

## Key Features
- Zero-code integration with existing apcore projects; no modifications required to original code
- Automatic discovery and exposure of modules as MCP tools or OpenAI-compatible tools
- Supports multiple transports (stdio, streamable-http, SSE) and client configurations (Claude, Cursor, etc.)
- Built-in Tool Explorer UI for interactive testing and debugging
- Supports JWT authentication, observability metrics, and async task bridging

## Why It Matters for RAG Builders
It enables seamless integration of existing apcore-based modules into AI workflows as MCP tools or OpenAI-compatible tools without requiring code changes, accelerating RAG and agent system development.
