## Summary
iterate is a self-evolving coding agent written in Go that autonomously improves its own codebase by reading issues, planning changes, implementing fixes, and committing them if tests pass. It operates on a 12-hour cycle, evolving without human intervention.

## Key Features
- Autonomous 12-hour evolution cycle with planning, implementation, and communication phases
- Self-hosted agent that reads its own codebase, issues, and journal for improvement decisions
- Integrated REPL for interactive debugging, testing, and manual control
- Modular architecture with skill files and GitHub Actions workflows for automation
- Supports multiple LLM providers (Anthropic, OpenAI, Gemini, Groq) for flexibility
