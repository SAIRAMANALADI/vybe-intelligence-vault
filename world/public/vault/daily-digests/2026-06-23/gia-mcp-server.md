## Summary
gia-mcp-server is a middleware that bridges Claude Desktop/Code with the GIA governance engine using the Model Context Protocol (MCP). It ensures AI agents comply with enterprise governance rules, audits actions, and enforces policies for secure and compliant AI operations.

## Key Features
- Enables secure communication between Claude AI and GIA governance engine via MCP
- Enforces enterprise compliance rules and audits AI agent actions
- Provides human-in-the-loop oversight for AI operations
- Supports Windows platforms with minimal setup requirements
- Logs and status monitoring for connection and governance enforcement
