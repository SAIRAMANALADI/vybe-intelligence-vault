## Summary
skillpm is a lightweight package manager designed to manage Agent Skills as npm packages, enabling dependency management, versioning, and sharing of modular AI agent capabilities. It integrates with npm's ecosystem to streamline skill installation, configuration, and agent wiring.

## Key Features
- Enables publishing, installing, and versioning of Agent Skills as npm packages
- Supports dependency management via standard npm workflows
- Automates wiring skills into agent directories (Claude, Cursor, VS Code, etc.)
- Provides MCP server configuration and management
- Supports monorepo workspaces for local skill development

## Why It Matters for RAG Builders
skillpm standardizes the management of modular AI agent skills, reducing duplication and enabling reusable, composable capabilities for RAG and AI stack builders.
