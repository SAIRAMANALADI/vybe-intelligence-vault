## Summary
TextForge AI is a pretext plugin and knowledge layer that enables large language models (LLMs) to perform DOM-free text measurement, layout optimization, and spatial reasoning with pixel-perfect precision. It provides MCP tools and APIs for developers to integrate advanced typography control and text geometry analysis into AI-native applications.

## Key Features
- DOM-free text measurement engine with sub-pixel accuracy
- MCP tools for spatial text reasoning (e.g., TextWidthEstimator, LayoutOptimizer)
- Multi-API support for OpenAI and Claude LLMs
- Multilingual and Unicode 16.0 compliance with RTL and vertical text support
- Responsive layout intelligence for dynamic container adaptation
