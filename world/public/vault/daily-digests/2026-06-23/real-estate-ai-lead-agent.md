## Summary
A production-ready WhatsApp AI lead agent that qualifies real estate leads, maintains contextual conversations, syncs to CRM systems like HubSpot, and automates follow-ups with multi-tenant isolation, fault recovery, and observability features.

## Key Features
- Real-time WhatsApp lead qualification with contextual conversation handling
- RAG-powered context injection using FAISS for semantic search and lead extraction
- Multi-tenant isolation with API key-based authentication and role-based access
- Automated follow-up scheduling with APScheduler and dead-letter queue (DLQ) fault recovery
- Prometheus observability with Grafana dashboards for monitoring and alerting

## Why It Matters for RAG Builders
It provides a turnkey, production-grade AI agent framework for real-time lead qualification and CRM integration, reducing development time for RAG builders by offering pre-built components for WhatsApp interactions, fault tolerance, and observability.
