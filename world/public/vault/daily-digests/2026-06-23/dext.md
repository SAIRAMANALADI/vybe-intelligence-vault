## Summary
Dext Framework is a modern full-stack development ecosystem for Delphi, integrating Dependency Injection, ORM, Web Pipeline, and Testing into a high-performance native architecture. It bridges the gap between Delphi and modern platforms like .NET Core by providing functional parity with ASP.NET Core and Entity Framework Core while leveraging native compilation for zero cold starts and minimal memory footprint.

## Key Features
- Native Delphi full-stack framework with integrated DI, ORM, and web pipeline
- Zero-code REST API generation from domain entities with OpenAPI/Swagger support
- Native Model Context Protocol (MCP) server integration for AI agent tooling
- Design-time VCL compatibility via TEntityDataSet for RAD productivity
- High-performance async processing with fluent task pipelines and cancellation tokens

## Why It Matters for RAG Builders
Dext provides a native Delphi alternative to modern .NET stacks, enabling legacy modernization without rewrites while offering AI-ready MCP integration for enterprise systems.
