## Summary
Acorn is a self-hosted AI agent backend designed for a single owner and their devices, enabling secure, durable, and persistent AI agent operations with local control over state and memory.

## Key Features
- Single-owner self-hosted backend with authenticated API and device pairing
- File-backed long-term memory with local semantic retrieval using FAISS
- Persistent runs, events, and workspace checkpoints with durable state
- Android mobile app for inbox, threads, runs, approvals, and settings
- Linux release tarballs with bundled native search libraries and systemd integration

## Why It Matters for RAG Builders
Acorn provides a robust, self-contained framework for building and managing persistent AI agents with local control, making it essential for developers prioritizing privacy and autonomy in AI deployments.
