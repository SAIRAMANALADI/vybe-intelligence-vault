## Summary
Exobrain Harness is a self-hosted personal automation system that integrates voice recordings, handwritten notes, tasks, calendar, health data, and messaging into a unified knowledge vault. Powered by Claude Code, it automates information capture, synthesis, and actionable outputs across multiple platforms and services.

## Key Features
- Unified information capture from voice, handwriting, messages, calendar, and health data
- Automated processing and routing via launchd and scheduled tasks
- Integration with Obsidian for knowledge vaulting and Things 3 for task management
- Extensible skill system with 50+ pre-built skills for automation and research
- Cross-platform synchronization and cross-session memory continuity

## Why It Matters for RAG Builders
