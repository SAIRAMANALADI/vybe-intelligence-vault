## Summary
Obol is a decentralized platform that enables real-time, on-chain micropayments for musicians per listen, eliminating intermediaries and delayed payouts. It offers both an x402 pay-per-play HTTP gate and an autonomous agent for self-hosted music libraries, settling payments in USDC via Arc and Circle.

## Key Features
- x402 HTTP payment gate for real-time USDC settlements per listen
- Autonomous payment agent with LLM-based artist disambiguation
- On-chain transaction verification with public receipts
- Self-hosted music library integration via Subsonic/Navidrome
- Spend controls including rate limits and daily caps
