## Summary
OpenPetAgent is a native macOS desktop AI companion platform featuring swappable pet avatars, GPU-powered falling-sand physics for snow/rain, desktop awareness, and LLM integration. It supports multiple pet types (Orb, Slime, Shimeji, Live2D) and integrates with external agents like Claude Code and Codex.

## Key Features
- Pluggable pet renderer system supporting multiple avatar types (Orb, Slime, Shimeji, Live2D, sprites)
- GPU-accelerated falling-sand physics for dynamic snow/rain effects with real-time weather integration
- Desktop awareness via AX APIs for context-aware LLM interactions (e.g., knowing active apps/windows)
- External agent sensing (Claude Code/Codex) for emotion-driven pet behavior without invasive hooks
- Multi-provider LLM support with runtime switching and streaming SSE for chat interactions

## Why It Matters for RAG Builders
