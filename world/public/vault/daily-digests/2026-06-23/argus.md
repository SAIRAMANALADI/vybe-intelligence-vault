## Summary
ARGUS-3 is a wallet-native, security-hardened personal agent designed as the demand-side reference client for the AICOM agent economy. It integrates a MCP security firewall (WARDEN), native USDC settlement via AIMarket, and autonomous offline operation, prioritizing user security and cost efficiency.

## Key Features
- WARDEN MCP firewall with LUMEN reputation scoring for real-time threat detection and tool-pinning to prevent drift or rug-pulls.
- Native USDC settlement via AIMarket for consumer/provider interactions, with crypto disabled by default for autonomy.
- Token-frugal design with hard budget governors, live token meters, and multi-tier model routing to minimize costs.
- Multi-provider support (Anthropic-native, OpenAI-compatible, local Ollama) for flexible model selection and offline operation.
- Agent Arena gamification system for XP, streaks, badges, and shareable Flex Cards to incentivize real ecosystem activity.

## Why It Matters for RAG Builders
ARGUS-3 provides a secure, autonomous, and cost-efficient framework for building and deploying personal agents that can operate both online and offline while participating in a real two-sided agent economy.
