## Summary
FlowCore is a lightweight, Rust-powered real-time stream processing engine designed for efficient event-time processing, tumbling windows, and late-event handling. It includes a modern React dashboard for live data visualization and stream configuration.

## Key Features

- Tumbling windows for interval-based data analysis
- Late-event detection with watermarks
- Checkpointing for fault tolerance and recovery
- Modern React-based dashboard for real-time visualization
