## Summary
Vault-for-LLM is a local-first memory system for AI agents that transforms project notes, decisions, and agent-written content into a portable SQLite database. It enables agents to search, cite, and reuse project knowledge while maintaining source transparency and governance.

## Key Features
- Portable SQLite-based memory storage with agent-friendly retrieval tools
- Governance metadata (scope, sensitivity, expiry) for controlled access
- Obsidian import/export bridge for existing note systems
- Optional Supabase sync for multi-machine or hosted agent collaboration
- Built-in automation for memory maintenance, candidate review, and policy-driven cleanup

## Why It Matters for RAG Builders
It provides a critical local-first memory layer that ensures AI agents can reliably reuse project knowledge without losing context or violating governance policies, bridging the gap between raw notes and reliable RAG systems.
