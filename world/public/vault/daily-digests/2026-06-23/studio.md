## Summary
Deco CMS Studio is an open-source, TypeScript-first control plane for managing AI agents, tools, and projects with built-in observability and multi-tenancy support. It enables hiring agents, connecting tools via MCP, and organizing workflows into projects with adaptive UIs.

## Key Features
- Agent hiring and composition with tracked skills and cost attribution
- One-click OAuth connections to tools (GitHub, Slack, Postgres, etc.) via MCP
- Projects with adaptive UIs that evolve based on included agents and tools
- Comprehensive observability with token spend, latency, and error tracking
- Virtual MCPs for composing and exposing governed toolsets as new endpoints

## Why It Matters for RAG Builders
Deco CMS Studio provides a unified platform to orchestrate, monitor, and scale AI agents and tools, making it essential for building robust RAG systems with multi-agent collaboration and cost control.
