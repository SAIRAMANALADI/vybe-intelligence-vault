## Summary
Nunopi is an AI-powered local-first code learning tool designed for vibe coders, providing line-by-line code explanations, token dictionaries, and concept notes to help users understand code they generate quickly. It bridges the gap between rapid prototyping and comprehension through AI agents and local processing.

## Key Features
- Line-by-line code explanations for rapid understanding
- Token dictionary for quick reference of common terms (e.g., useState, props)
- Concept notes generated in beginner-friendly language
- Support for multiple AI providers (local and remote)
- Local fallback mode for offline use
