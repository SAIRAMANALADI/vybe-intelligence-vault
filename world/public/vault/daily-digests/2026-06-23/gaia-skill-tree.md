## Summary
Gaia is an open, evidence-backed skill graph and registry for AI agents, enabling developers to claim, rank, and fuse agent capabilities into a structured skill tree. It serves as a public record for AI agent developers to cite capability claims with verifiable evidence.

## Key Features
- Structured skill tree with tiered ranking (Basic, Extra, Ultimate) using a star system (0★–6★)
- Evidence-backed promotion system with Trust Magnitude scoring and G7 Trust Taxonomy RFC compliance
- CLI and TUI for skill discovery, scanning, and installation
- MCP server integration for seamless agent-to-agent skill sharing
- Public trust ledger and badges for verifiable capability claims

## Why It Matters for RAG Builders
It provides a standardized, evidence-backed way to track, rank, and share AI agent capabilities, enabling developers to build on proven skills and foster trust in AI systems.
