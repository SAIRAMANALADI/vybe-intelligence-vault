## Summary
tidal-cli is a command-line interface tool that wraps the Tidal API v2, enabling users to search, manage, and play music directly from the terminal without a browser. It supports JSON output for automation and integrates with AI agents and MCP servers.

## Key Features
- Full Tidal API v2 integration for search, playback, and library management
- JSON output for all commands, enabling seamless AI agent automation
- MCP server support for Claude Desktop and MCP-compatible clients
- Supports OAuth authentication and auto-refreshing tokens for non-interactive use
- 111 tests covering core functionality, ensuring reliability

## Why It Matters for RAG Builders
tidal-cli provides a robust, scriptable interface to Tidal's music catalog and playback features, making it essential for AI agents and automation workflows that require dynamic music discovery and management.
