## Summary
Geargrafx is a highly accurate, cross-platform emulator for TurboGrafx-16, PC Engine, SuperGrafx, and PCE CD-ROM² systems, written in C++. It includes an embedded MCP server for AI-assisted debugging and tooling, enabling integration with AI agents like GitHub Copilot and Claude.

## Key Features
- Accurate emulation of TurboGrafx-16, PC Engine, SuperGrafx, and PCE CD-ROM² systems
- Embedded MCP server for AI-assisted debugging and tooling
- Cross-platform support (Windows, macOS, Linux, BSD, RetroArch)
- Full-featured debugger with disassembler, breakpoints, and memory inspection
- Support for save states, rewind, and hardware inspection tools
