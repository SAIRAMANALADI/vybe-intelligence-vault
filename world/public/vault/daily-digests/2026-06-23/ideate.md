## Summary
Ideate is a local-first macOS desktop application that serves as a unified workspace for tracking ideas, linked repositories as worktrees, context files, external resources, and AI agent sessions. It enables seamless cross-repo agent collaboration via MCP tool calls and inline reviews.

## Key Features
- Per-idea worktrees for linked repositories, enabling shared branch collaboration without stash juggling
- Built-in MCP server for agent integration, allowing natural language-driven session management and tool calls
- Inline diff and markdown review workflows with real-time agent feedback and inline responses
- Unified dashboard for managing ideas, sessions, and resources with a sleep inhibitor for long-running tasks
- Extensible resource linking for external systems (docs, issue trackers, CI, etc.) with a pluggable registry

## Why It Matters for RAG Builders
Ideate streamlines AI agent collaboration by unifying idea tracking, code worktrees, and inline reviews into a single workspace, reducing context switching and enabling seamless multi-repo agent workflows.
