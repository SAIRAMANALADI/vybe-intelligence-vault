## Summary
ai-cortex is a local-first project knowledge substrate for coding agents that provides durable project context, session continuity, and explicit memory storage without modifying the target repository. It enables agents to recall past decisions, gotchas, and conventions across sessions.

## Key Features
- Project mapping and structural indexing of repositories (imports, call graphs, file ranking)
- Session continuity with captured agent interactions for cross-session recall
- Explicit memory system for storing decisions, gotchas, patterns, and conventions
- MCP-compatible tooling for integration with agents like Claude, Cursor, and OpenHands
- Interactive 3D graph visualization for inspecting code structure and memory relationships

## Why It Matters for RAG Builders
It enables coding agents to retain and recall project-specific knowledge across sessions, reducing repetitive explanations and improving consistency in agent-driven development workflows.
