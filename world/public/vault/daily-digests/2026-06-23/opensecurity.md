## Summary
OpenSecurity is an AI-driven multi-domain security analysis agent platform that enables LLMs to autonomously perform end-to-end security tasks, including binary, mobile, web, and AI security analysis. It orchestrates tools like IDA Pro, Frida, and apktool to produce verifiable reports without manual intervention.

## Key Features
- End-to-end autonomous security analysis with LLM-driven orchestration
- Multi-domain coverage: binary, mobile, web, and AI security analysis
- Self-evolution engine for continuous improvement and knowledge base expansion
- Modular architecture with clear separation of AI, tool, and knowledge layers
- Headless tool execution for reproducibility (e.g., IDA Pro in CLI mode)
