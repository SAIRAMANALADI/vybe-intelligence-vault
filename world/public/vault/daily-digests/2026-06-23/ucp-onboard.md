## Summary
ucp-onboard is a Windows-based tool that automates merchant onboarding to the Universal Commerce Protocol (UCP) using AI agents. It guides users through auditing store data, building merchant profiles, managing product catalogs, configuring checkout, and validating compliance with UCP standards.

## Key Features
- AI-driven audit tool for store data completeness and structure
- Profile builder for merchant business information and compliance
- Catalog manager with bulk upload support for products
- Checkout configuration for payment and delivery options
- Validation check to ensure UCP compliance before going live

## Why It Matters for RAG Builders
It simplifies and accelerates merchant onboarding to UCP-compliant systems, reducing manual effort and errors for e-commerce integrations.
