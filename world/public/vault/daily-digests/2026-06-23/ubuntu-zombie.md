## Summary
Ubuntu Zombie transforms an Ubuntu Desktop LTS machine into a self-managing system by adding a private, root-capable AI Systems Administrator account. Users can interact via a local chat interface to diagnose, configure, repair, and operate the machine, with all actions audit-logged for transparency.

## Key Features
- Private AI chat interface for system administration tasks
- Audit logging for all privileged actions
- Key-only SSH access with root disabled by default
- Support for local LLM discovery (LM Studio, Ollama, etc.)
- Idempotent installer with rollback capabilities

## Why It Matters for RAG Builders
Ubuntu Zombie enables secure, auditable AI-driven system administration for Ubuntu machines, reducing manual intervention while maintaining full operator control and transparency.
