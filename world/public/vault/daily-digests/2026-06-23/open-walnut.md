## Summary
Open Walnut is a self-hosted, local-first AI butler that integrates Claude Code sessions, task management, and a persistent memory system into a unified web UI. It automates project organization, note-taking, and AI-driven workflows while ensuring data privacy and user control.

## Key Features
- Real-time Claude Code session management with a web UI, including multi-session monitoring and model switching
- 4-layer task hierarchy with a 7-phase lifecycle and natural language task creation
- Self-organizing memory system with auto-distillation, temporal decay, and hybrid search (BM25 + vector)
- Obsidian-style notes vault with PARA organization and local indexing for semantic search
- 30+ AI agent tools for automation, cron jobs, and remote session orchestration

## Why It Matters for RAG Builders
Open Walnut provides a unified, self-hosted platform for managing AI workflows, tasks, and knowledge, reducing context fragmentation and enabling persistent, searchable memory for RAG systems.
