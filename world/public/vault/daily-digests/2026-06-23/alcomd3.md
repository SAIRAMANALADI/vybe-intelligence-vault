## Summary
ALCOMD3 is a standalone desktop tool for managing VRChat projects and VPM packages, offering project workflows, repository management, and optional local MCP integration. It provides a Material Design 3 interface, customizable themes, and Windows installer support.

## Key Features
- VRChat project and VPM package management with a Material Design 3 interface
- Customizable themes, branding, and installer names for Windows releases
- VPM repository and package operations with progress tracking and cancellation
- Optional local MCP bridge for AI-agent visibility and project/repository/package tools
- Automated release workflows with signing, verification, and artifact generation

## Why It Matters for RAG Builders
ALCOMD3 simplifies VRChat project and package management, making it easier for AI agents to interact with VRChat ecosystems through its MCP integration and structured workflows.
