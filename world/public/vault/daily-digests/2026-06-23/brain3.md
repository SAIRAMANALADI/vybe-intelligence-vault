## Summary
Brain3 is a local markdown vault that integrates with AI assistants like Claude or ChatGPT via the MCP protocol, enabling users to store, retrieve, and manage notes directly within their AI workflows. It provides a terminal UI for vault administration and supports voice dictation for hands-free note-taking.

## Key Features
- Seamless integration with AI assistants (Claude, ChatGPT) via MCP for direct vault access
- Terminal UI for vault administration and note management
- Local markdown storage for privacy and portability
- Voice dictation support for hands-free note-taking
- Cloudflare Tunnel integration for secure remote access

## Why It Matters for RAG Builders
Brain3 enables AI assistants to directly access and utilize a user's local markdown vault, enhancing context retention and workflow continuity without vendor lock-in.
