## Summary
A Model Context Protocol (MCP) server providing deterministic equity-compensation tax calculations for incentive stock options (ISO), non-qualified stock options (NSO), restricted stock units (RSU), and related financial planning tools. Validated against IRS and state tax codes with over 1,000 automated tests.

## Key Features
- Multi-year ISO exercise optimization under AMT with credit recovery
- Federal + 50-state + DC tax code coverage for ISO, NSO, RSU, and QSBS
- Protective put and zero-cost collar pricing via Black-Scholes
- Single-stock concentration risk analysis with hedging strategies
- Keyless, drop-in integration with major agent frameworks (LangChain, LlamaIndex, CrewAI)

## Why It Matters for RAG Builders
Provides verifiable, deterministic tax calculations for equity compensation that LLMs cannot reliably compute, enabling accurate financial planning in AI agents.
