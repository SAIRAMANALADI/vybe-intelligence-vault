## Summary
A CLI tool that generates print-ready QR codes from text or URLs using the `qrencode` library. Supports multiple output formats (PNG, SVG, terminal) with customizable size, margin, and error correction levels.

## Key Features
- Supports multiple output formats: PNG, SVG, UTF8 (terminal), and ANSI
- Customizable module size, margin, and error correction levels
- No additional dependencies required (uses pre-installed `qrencode`)
- Part of the OpenClaw skill ecosystem for modular AI tooling
- Lightweight and fast execution for quick QR code generation
