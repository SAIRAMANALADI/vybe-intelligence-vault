## Summary
HemmaBo MCP Server enables AI agents to discover, verify, and interact with host-owned vacation rental booking systems using the Vacation Rental Protocol (VRP). It facilitates direct booking workflows without central gatekeepers, ensuring trust through Ed25519/JWKS signed offers and live availability data.

## Key Features
- Discover host-owned vacation rental properties via agent-traversal and VRP metadata
- Verify signed stay offers using Ed25519/JWKS and VRP standards
- Fetch real-time availability, pricing, and direct booking URLs from host domains
- Support for authenticated fallback booking tools in non-VRP deployments
- Interoperability with agent-commerce protocols (UCP, ACP, AP2) for payment authorization

## Why It Matters for RAG Builders
HemmaBo enables AI agents to trust and facilitate direct bookings on host-owned domains, eliminating central gatekeepers and ensuring verifiable, transparent transactions for vacation rentals.
