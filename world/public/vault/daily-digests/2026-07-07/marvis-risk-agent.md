## Summary
MARVIS-Agent V2 is a local-first credit-risk agent workbench designed for end-to-end workflows in model validation, data processing, feature analysis, strategy development, and portfolio monitoring. - Task-level agent workbench with human-in-the-loop confirmation gates
- Plugin/Tool/Workflow runtime for governed capability packs
