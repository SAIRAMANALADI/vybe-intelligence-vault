## Summary
FlowGate is a typed document pipeline and review gate system designed to enforce accountability in AI agent workflows. It ensures agents cannot claim task completion without verifiable proof by requiring structured artifacts (requirements, tasks, reports) to pass through human or automated review gates before acceptance.

## Key Features
- Structured document pipeline with typed artifacts (requirements, tasks, reports, conversations)
- Review gates for approval, rejection, or revision requests with full history tracking
- Remote worker API with scoped Bearer tokens and dry-run validation
- Continuous (unmanned) work chains with auto-advancement and pause points
- Real-time updates via Server-Sent Events and notification feeds

## Why It Matters for RAG Builders
FlowGate provides a critical accountability layer for AI agent workflows by enforcing verifiable proof of work before task completion, reducing the risk of unverified or incorrect outputs in automated pipelines.
