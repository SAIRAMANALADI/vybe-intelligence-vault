## Summary
Milo is a Python framework that transforms a single typed function into a CLI command, an MCP tool, and an AI-readable discovery entry. It enables dual-mode command execution (interactive for humans and structured for AI agents) with built-in schema validation, streaming progress, and terminal UI capabilities.

## Key Features
- Single function definition generates CLI, MCP tool, and AI discovery entry automatically
- Dual-mode execution: interactive for humans and structured JSON for AI agents
- Built-in schema constraints with `Annotated` and JSON Schema generation
- Streaming progress notifications for real-time MCP client updates
- Elm Architecture-inspired state management with sagas and reducers

## Why It Matters for RAG Builders
Milo enables AI agents to seamlessly discover and interact with CLI tools via MCP, bridging the gap between human-friendly interfaces and machine-readable functionality.
