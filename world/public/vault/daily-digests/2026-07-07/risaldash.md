## Summary
RisalDash is a C++ library for ESP32/ESP8266 that generates real-time, offline-first web dashboards with minimal code. It abstracts away front-end development by dynamically creating HTML, CSS, and JavaScript from simple C++ declarations, enabling embedded systems to serve interactive UIs directly.

## Key Features
- Zero front-end code required: generates HTML/CSS/JS dynamically from C++ declarations.
- Offline-first with captive portal for Wi-Fi setup and NVS-persisted credentials.
- 26+ widget types (gauges, charts, sliders, toggles, etc.) with live WebSocket updates.
- Multi-page layouts with iOS-style status bar, theme/language settings, and RTL support.
- Integrations for MCP, MQTT, Prometheus, OTA updates, and Home Assistant auto-discovery.

## Why It Matters for RAG Builders
RisalDash simplifies the creation of interactive, real-time UIs for embedded systems, reducing development time from hundreds of lines of front-end code to a few C++ declarations, making it ideal for AI-driven IoT applications.
