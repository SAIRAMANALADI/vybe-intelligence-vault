## Summary
TrendRadar is an AI-driven public opinion and trend monitoring tool that aggregates news from multiple platforms, filters content based on user-defined keywords or AI-powered interests, and delivers personalized alerts via 10+ channels including WeChat, Feishu, Telegram, and email. It supports RSS subscriptions, AI-powered translation, and MCP integration for natural language analysis.

## Key Features
- AI-powered news filtering using user-defined interests or keywords to personalize content delivery
- Multi-platform aggregation (RSS, news APIs, and social media) with real-time updates
- 10+ notification channels including WeChat, Feishu, Telegram, email, and Slack
- MCP integration enabling AI-driven natural language analysis and trend prediction
- Docker and GitHub Pages deployment with automated CI/CD pipelines
