## Summary
GPT‑Админ is a self-hosted MCP hub that acts as an intermediary between AI assistants and infrastructure, enabling any AI (e.g., ChatGPT, Claude, DeepSeek) to control servers, run commands, and manage tools via three adapters. It supports real-time execution, subagents, and integrates with MCP-compatible tools.

## Key Features
- Unified MCP hub for any AI assistant (ChatGPT, Claude, DeepSeek, etc.)
- Three adapters for seamless AI integration (OpenAI Action, MCP remote SSE, Browser extension)
- Real-time command execution with state validation and output reporting
- Supports server administration, code execution, log analysis, and web search via MCP tools
- Self-hosted with no cloud dependency, ensuring data privacy and control
