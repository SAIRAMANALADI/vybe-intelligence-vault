## Summary
logoloom is a Windows-native desktop application that enables users to generate logos and brand kits from simple prompts, exporting clean SVG files and additional assets like favicons. It integrates with MCP tools for local, private workflows, ideal for quick brand asset creation without web-based design tools.

## Key Features
- Generates logos from short prompts or brand names
- Exports clean SVG files and additional assets (favicons, icons, etc.)
- Runs locally on Windows for privacy and control
- Integrates with MCP-ready tools for automated workflows
- Supports creation of full brand kits from a single design

## Why It Matters for RAG Builders
It provides a fast, local, and private way to generate and manage brand assets, which is critical for AI-driven workflows requiring clean, reusable vector graphics.
