## Summary
DecTell AI is a Windows-based desktop application that enables non-technical users to upload business datasets, clean and analyze data, build predictive models, test what-if scenarios, and query data in plain language to derive actionable insights for decision-making.

## Key Features
- One-click data cleaning and preprocessing for messy datasets
- Automated exploratory data analysis with trend and pattern detection
- Built-in machine learning for forecasting and predictive modeling
- Interactive what-if scenario testing to simulate business changes
- Plain language question answering for intuitive data exploration

## Why It Matters for RAG Builders
DecTell AI democratizes data analysis and predictive modeling for non-technical users, enabling faster decision-making without requiring coding or advanced data science skills.
