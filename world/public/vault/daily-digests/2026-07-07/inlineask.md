## Summary
InlineAsk is a browser extension that enables users to select any text on a webpage and instantly ask AI questions about it without leaving the page, eliminating context switching and saving time during research or reading.

## Key Features
- Select any text on any webpage and ask AI questions instantly without switching tabs
- Supports multiple AI providers (OpenAI, Claude, Qwen, MiniMax, local models)
- Streaming responses with real-time word-by-word output
- Privacy-focused: data is sent directly to your API, no third-party storage
- Multi-turn conversations and draggable UI with keyboard shortcuts

## Why It Matters for RAG Builders
InlineAsk drastically reduces context switching for RAG builders by enabling instant, in-place AI queries on any webpage, improving workflow efficiency during research and documentation review.
