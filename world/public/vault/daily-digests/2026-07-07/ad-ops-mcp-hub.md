AdSynthesis Engine is an MCP (Model Context Protocol) server that unifies AI command interfaces with cross-platform ad operations, enabling natural language management of Google Ads, Meta Ads, GA4, TikTok Ads, and LinkedIn Ads with human-in-the-loop safety controls.

## Key Features
- Unified natural language interface for 300+ ad operations across 5 major platforms
- Human-in-the-loop safety protocol for all write operations

- Cross-platform performance synthesis and unified reporting
