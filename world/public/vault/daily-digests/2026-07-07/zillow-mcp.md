## Summary
Zillow MCP is a Model Context Protocol (MCP) server that provides live Zillow property data, Zestimates, and listings to AI agents and assistants. It enables seamless integration of U.S. real estate data into AI workflows via a hosted REST + MCP endpoint.

## Key Features
- Provides 4 MCP tools for property lookup by address or ZPID, Zestimates, and listing search
- Supports 160M+ U.S. properties with 300+ fields per home
- Free tier available with 100 credits and no credit card required
- OAuth 2.1 and API key authentication options for seamless integration
- Compatible with major AI clients (Claude, ChatGPT, Cursor, VS Code, Hermes Agent, OpenClaw, etc.)

## Why It Matters for RAG Builders
It enables AI agents to fetch real-time Zillow property data directly, enhancing RAG systems with accurate, up-to-date real estate information for applications like property valuation, market analysis, and investment insights.
