## Summary
lazy-tool is a local-first tool discovery and routing utility for MCP (Model Context Protocol) setups. It indexes local tools, enables search-before-invoke workflows, and reduces prompt bloat by trimming tool lists for AI agents.

## Key Features
- Local-first tool indexing and storage using SQLite
- Search-before-invoke flow to reduce prompt noise
- Multiple interfaces: CLI, TUI, and Web UI
- Vector search for improved tool matching
- Tool routing for efficient agent task delegation

## Why It Matters for RAG Builders
It streamlines local tool discovery for AI agents, reducing prompt bloat and improving routing efficiency in MCP-based workflows.
