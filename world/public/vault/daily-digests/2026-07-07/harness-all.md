## Summary
A modular multi-agent framework family designed for AI-powered product development, consisting of independent domain-specialized agents (e.g., product management, software engineering) that collaborate via structured contract documents. Each framework operates autonomously but can integrate for cross-domain workflows.

## Key Features
- Independent yet interoperable agent frameworks (e.g., harness-pm for product management, harness-engineering for software delivery)
- Structured contract documents for seamless handoffs between frameworks, ensuring persistent project knowledge and domain expertise
- Self-contained memory systems (e.g., `knowledge-base.md`, `progress.md`) for cross-session context restoration
- Domain-specific exploration modes and routing fields to tailor agent behavior to specific tasks
- Built-in quality gates, circuit breakers, and evidence-based completion tracking to enforce engineering discipline
