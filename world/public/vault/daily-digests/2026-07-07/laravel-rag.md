## Summary
laravel-rag is a Laravel-based application designed to simplify running local Retrieval-Augmented Generation (RAG) workflows. It enables users to ingest, index, and search their own files or data using vector and hybrid search methods, with support for agentic retrieval and streaming responses.

## Key Features
- Supports multiple vector storage backends (PostgreSQL with pgvector, SQLite with sqlite-vec)
- Hybrid search combining keyword and vector retrieval
- Agentic retrieval for complex queries
- Streaming responses for real-time AI interactions
- Built-in evaluation tools for search quality assessment

## Why It Matters for RAG Builders
It provides a turnkey local RAG solution with flexible storage options, making it ideal for developers who need a self-hosted, Windows-friendly system to integrate AI-powered document search into their workflows.
