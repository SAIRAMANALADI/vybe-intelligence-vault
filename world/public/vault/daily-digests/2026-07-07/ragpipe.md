## Summary
ragpipe is a Python tool designed to simplify the creation of retrieval-augmented generation (RAG) pipelines by providing three core functions: ingest(), query(), and pipe(). It enables users to process files, Git repositories, and web pages into vector data for search and chat workflows with minimal setup.

## Key Features
- Simplified RAG pipeline construction with three core functions (ingest, query, pipe)
- Supports multiple content sources (files, Git repos, web pages)
- Compatible with both local (Ollama, Qdrant) and hosted (OpenAI, Pinecone) models/databases
- CLI and YAML configuration for easy setup and repeatable workflows
- Designed for Windows users with minimal manual configuration required

## Why It Matters for RAG Builders
ragpipe reduces the complexity of building RAG pipelines by providing a streamlined, configurable workflow for ingesting, querying, and managing vector data, making it essential for developers seeking rapid deployment of AI-powered search systems.
