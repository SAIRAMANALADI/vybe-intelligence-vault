## Summary
work-buddy is a local-first personal-agent runtime designed for knowledge workers, built on Claude Code and Obsidian. It provides structured workflows, persistent memory, and deep integrations with tools like Obsidian, Chrome, and Telegram to automate and coordinate fragmented work states.

## Key Features
- MCP Gateway for dynamic tool discovery and execution
- Workflow Conductor with multi-step DAGs and deterministic vs. agentic step interleaving
- Persistent memory via Hindsight for cross-session context retention
- Deep Obsidian integration for native task and note management
- Human-in-the-loop control with dashboard, notifications, and approvals

## Why It Matters for RAG Builders
It provides a structured runtime for coordinating fragmented knowledge work states, enabling AI agents to operate efficiently with persistent context and deterministic workflows while preserving user agency.
