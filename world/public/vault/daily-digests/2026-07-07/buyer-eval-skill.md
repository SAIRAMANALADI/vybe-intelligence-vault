## Summary
buyer-eval-skill is a Windows-based tool designed to help B2B teams systematically evaluate software vendors by guiding structured conversations, scoring responses based on evidence, and maintaining shared notes for buying teams.

## Key Features
- Domain-expert questions to test vendor understanding of business needs
- Simulated vendor AI agent conversations for claim verification
- Evidence-based scoring system for defensible vendor comparisons
- Shared note-taking for collaborative buying teams
- Structured workflow from vague claims to clear checks

## Why It Matters for RAG Builders
It provides a repeatable framework for validating vendor claims and reducing bias in B2B software purchasing decisions.
