## Summary
CareerMate is an AI-powered agent workbench designed for job-seeking workflows, integrating resume management, job matching, interview training, market insights, and conversational agents into a unified platform with multi-agent orchestration and RAG capabilities.

## Key Features
- Unified authentication and user isolation with JWT and Auth Gateway integration
- Multi-agent system with Supervisor + ReAct pattern for job-seeking workflows
- RAGForge integration for job description search, interview assistance, and resume synchronization
- SSE-based streaming agent conversations with session recovery and traceability
- Comprehensive deployment templates for Kubernetes, systemd, and Nginx

## Why It Matters for RAG Builders
CareerMate provides a production-ready framework for building AI agents tailored to job-seeking workflows, combining multi-agent orchestration, RAG, and observability in a single platform.
