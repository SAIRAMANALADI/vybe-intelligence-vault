## Summary
Tula is an open-source local application designed to consolidate and organize personal health data into a single interface, enabling users to review, analyze, and manage health records from wearables, lab reports, genomics, EHR/FHIR, and medical imaging. It transforms raw health data into structured insights for better patient awareness and decision-making.

## Key Features
- Consolidates health data from multiple sources (wearables, lab reports, genomics, EHR/FHIR, imaging) into a single interface
- Supports FHIR and EHR data standards for interoperability
- Enables trend analysis and comparison of health metrics over time
- Designed for local, private use with no cloud dependency
- Facilitates second-opinion reviews by organizing patient records
