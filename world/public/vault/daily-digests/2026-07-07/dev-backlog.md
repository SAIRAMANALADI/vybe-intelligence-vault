## Summary
dev-backlog provides a local sprint execution hub that synchronizes GitHub Issues with a structured Markdown sprint file, enabling AI agents (Claude Code, Codex) and humans to collaborate on a shared execution plan without new servers or hidden state.

## Key Features
- Synchronizes GitHub Issues with a local sprint file for AI agents and humans to read and update
- Supports explicit sync via GitHub CLI without hidden state or new servers
- Provides thin local task mirrors to reduce API round trips for AI agents
- Includes helper scripts for sprint initialization, status checks, and closure
- Enables delegated work tracking with visible in-flight states ([~]) and PR handoffs

## Why It Matters for RAG Builders
It bridges GitHub Issues with AI agent workflows by providing a single shared execution file, reducing context fragmentation and improving collaboration for RAG/AI stack builders.
