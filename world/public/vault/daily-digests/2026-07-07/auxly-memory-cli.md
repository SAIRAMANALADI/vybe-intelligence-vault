## Summary
Auxly is a local-first, file-based memory layer for AI agents that enables shared context across tools like Claude, Codex, and Copilot using plain Markdown files on your machine. It provides a unified, auditable, and versionable memory vault with encryption, access control, and real-time collaboration over SSH.

## Key Features
- Single shared memory vault in plain Markdown files for all AI agents
- Local-first, no cloud dependency, and vendor-neutral design
- Vault encryption at rest with age X25519 and keychain integration
- Real-time collaboration over SSH with one-command pairing
- Built-in memory review, fact decay, contradiction sweeps, and trust auto-tuning

## Why It Matters for RAG Builders
Auxly eliminates fragmented agent memory by providing a unified, auditable, and locally controlled context layer that all AI tools can read from and write to, ensuring consistency and reducing redundant explanations.
