## Summary
PortForge is an AI-powered React portfolio builder that enables developers to generate a production-ready, personalized portfolio website in minutes by answering 10-15 questions via an AI coding agent. It eliminates manual setup, drag-and-drop complexity, and generic templates.

## Key Features
- AI-driven portfolio generation via conversational setup (10-15 questions)
- 8 customizable content sections (Hero, About, Experience, Skills, Projects, Blog, Awards, Education)
- 3 visual styles (Minimal, Bold, Terminal) with 7 color presets and dark/light mode
- LinkedIn auto-import and one-command deployment to GitHub Pages, Netlify, or Vercel
- SEO-optimized with Open Graph, Twitter Cards, JSON-LD, sitemap.xml, and robots.txt

## Why It Matters for RAG Builders
PortForge accelerates the creation of personalized, production-ready portfolios for developers, reducing setup time from weeks to minutes while leveraging AI agents for hands-free customization.
