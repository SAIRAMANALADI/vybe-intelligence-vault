## Summary
A Windows-based desktop application that performs automated security audits on Solidity smart contracts, identifying vulnerabilities like reentrancy and integer overflows, and generating detailed reports for developers and investors.

## Key Features
- Automated detection of common Solidity vulnerabilities (reentrancy, integer overflows, access control issues)
- Local-first analysis ensuring code privacy and no server-side storage
- Detailed PDF report generation for investors and development teams
- User-friendly dashboard with line-level code highlighting and fix recommendations
- Standalone Windows application with offline functionality
