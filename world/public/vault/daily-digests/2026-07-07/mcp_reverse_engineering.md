## Summary
mcp_reverse_engineering is a Windows-based tool designed to simplify file inspection and reverse engineering tasks by providing a unified interface for common utilities like strings, hexdump, and objdump. It streamlines the analysis of executables, libraries, and unknown files with built-in safety checks and guided workflows.

## Key Features
- Unified interface for multiple reverse engineering tools (strings, hexdump, objdump, etc.)
- Built-in filesystem isolation and input validation for safer analysis
- Guided workflows for inspecting executables, DLLs, archives, and unknown files
- Supports common file types including .exe, .dll, .zip, and packed binaries
- Includes timeout and safety checks to prevent unintended system modifications
