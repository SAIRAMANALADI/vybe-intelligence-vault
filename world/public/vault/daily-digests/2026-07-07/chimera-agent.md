## Summary
Chimera is an open-source AI agent framework that combines multiple AI models to solve complex tasks, remembers interactions for continuous improvement, and safely executes actions with built-in verification and rollback mechanisms. It supports multi-model reasoning, long-term memory, and deployment as a 24/7 service.

## Key Features
- Blends multiple AI models for more accurate responses using a judge-synthesizer pipeline
- Autonomously plans, executes, and verifies tasks with rollback on failure
- Long-term memory and skill learning for continuous improvement
- Supports deployment as a 24/7 service with multi-platform chat bot integrations
- Built-in safety checks, sandboxed code execution, and audit logging

## Why It Matters for RAG Builders
Chimera provides a robust, open-source framework for building self-improving AI agents that can reliably execute complex tasks, blend model outputs for accuracy, and maintain long-term memory—critical for scalable RAG and autonomous AI systems.
