## Summary
Code-Graph-RAG is a graph-based Retrieval-Augmented Generation (RAG) system designed to analyze multi-language codebases, build comprehensive knowledge graphs, and enable natural language querying of codebase structure, relationships, and editing capabilities.

## Key Features
- Multi-language codebase parsing and analysis using Tree-sitter
- Knowledge graph storage and querying via Memgraph for code structure and relationships
- Natural language to Cypher translation for querying codebases
- AST-based surgical code editing and replacement with visual diff previews
- Support for cloud, local, and OpenAI models for AI functionalities

## Why It Matters for RAG Builders
It provides a powerful, language-agnostic way to index, query, and edit codebases using knowledge graphs, making it essential for RAG builders who need deep code understanding and interaction.
