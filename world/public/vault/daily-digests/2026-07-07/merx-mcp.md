## Summary
merx-mcp is a Windows-based MCP server that enables AI agents to interact with the TRON blockchain by providing tools for token transfers, resource management, and transaction simulation. It simplifies TRON operations for AI-driven workflows with minimal manual setup.

- 55+ tools for TRON blockchain operations (transfers, swaps, balance checks)
- MCP server integration for AI agents to execute TRON tasks
- Transaction simulation to validate actions before execution
- Energy and bandwidth resource management for optimized operations
- Simple config-based setup with wallet and RPC endpoint configuration
