## Summary
knitbrain is a local-first MCP server that provides state management, optimization, and enforcement for agent loops, ensuring reliability by preventing agents from lying, running away, or going broke. It integrates with major agent platforms via hooks and offers lossless context compression and persistent project memory.

## Key Features
- Enforces verify-gated loops with real exit codes to prevent agent deception
- Lossless context compression (~46% average reduction) with byte-exact recall
- Persistent project memory and knowledge graph for cross-session learning
- Multi-platform hook system for enforcement (Claude Code, Cursor, VS Code, etc.)
- Honest session receipts and real-time token optimization metrics

## Why It Matters for RAG Builders
It provides the critical substrate for building reliable, self-correcting agent loops with verifiable outcomes and persistent project memory, eliminating common failure modes in RAG and agentic systems.
