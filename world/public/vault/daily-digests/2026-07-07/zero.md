## Summary
Zero is a local terminal-based AI coding agent that allows users to inspect repositories, edit files, run commands, and manage durable sessions with configurable permissions and model providers. It supports both interactive TUI and headless execution modes.

## Key Features
- Interactive TUI with model/provider pickers, slash commands, and live rendering
- Headless execution mode for scripting and CI/CD integration
- Fine-grained permission control for file writes, shell commands, and network access
- Support for 25+ model providers including OpenAI, Anthropic, Ollama, and local models
- Durable local sessions with resumable, searchable, and forking capabilities

## Why It Matters for RAG Builders
Zero provides a secure, local-first alternative to cloud-based coding agents, enabling developers to automate tasks with AI while maintaining full control over permissions and data privacy.
