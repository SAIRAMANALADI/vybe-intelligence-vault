## Summary
Prospec is a Progressive Spec-Driven Development (SDD) toolkit for AI coding agents, enabling structured workflows through slash-command Skills, AI Knowledge, and a CLI for project bootstrap and regeneration. It enforces repeatable workflows like story → plan → tasks → implement → review → verify → archive.

## Key Features
- Slash-command Skills for AI agents (Claude Code, Copilot, Codex) to drive structured workflows
- AI Knowledge base for progressive, version-controlled project memory and context management
- Multi-platform standalone binaries for deployment without Node.js dependencies
- Progressive disclosure to optimize token usage in AI contexts (70-80% savings)
- Automated workflow enforcement with stages like story, plan, tasks, implement, review, verify, and archive
