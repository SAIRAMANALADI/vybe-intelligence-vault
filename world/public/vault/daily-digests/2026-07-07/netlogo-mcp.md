## Summary
NetLogo-MCP is an MCP (Model Context Protocol) server that enables AI assistants to create, run, and analyze agent-based models in NetLogo through natural language conversation. It bridges AI workflows with NetLogo's simulation capabilities, allowing users to generate models, run experiments, and export results without manual coding or GUI interaction.

## Key Features
- Natural language model creation with widgets (sliders, buttons, monitors)
- Run simulations and collect tick-by-tick data as markdown tables
- Support for BehaviorSpace parameter sweeps and CoMSES Net model integration
- Lazy JVM startup and GUI/headless mode options
- Built-in references for NetLogo primitives and programming guides
