## Summary
claude-code-boss-mode is a decision-layer tool that integrates with Claude Code to enforce stricter planning, scope-cutting, and risk assessment before coding begins. It provides structured reviews from CEO, Engineering Manager (EM), and Product Manager (PM) perspectives to improve decision-making and reduce scope creep.

## Key Features
- Three-tiered review system (CEO, EM, PM) for comprehensive task evaluation
- Pre-coding plan inspection to cut weak or overbuilt features
- Pull request review with stricter filters to reduce risk
- Blunt feedback mode (/boss-roast) for direct critique of weak thinking
- Local Windows-based execution with simple setup and folder structure
