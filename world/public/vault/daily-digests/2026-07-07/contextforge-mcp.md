## Summary
ContextForge MCP is an open-source Model Context Protocol (MCP) server that enables persistent, searchable memory for AI coding assistants like Claude, Cursor, and GitHub Copilot. It integrates with GitHub, supports team collaboration, and provides semantic search capabilities for long-term project knowledge.

## Key Features
- Persistent memory across AI coding sessions for tools like Claude, Cursor, and Copilot
- Semantic search for retrieving knowledge by meaning, not keywords
- GitHub integration with automatic syncing of commits and PRs
- Team collaboration features including shared projects and issue tracking
- Multi-session coordination with session presence and heartbeat management

## Why It Matters for RAG Builders
It enables AI agents to retain and leverage long-term project context, drastically improving RAG systems by providing persistent, searchable memory across sessions and tools.
