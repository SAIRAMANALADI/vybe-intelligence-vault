## Summary
SAVILE is a local-first engine designed to standardize, version, and distribute AI agent prompts and skills as portable artifacts. It acts as a centralized 'Single Source of Truth' for agent logic, enabling forkable, Git-native workflows and seamless integration with tools like Vercel Skills and the Model Context Protocol (MCP).

## Key Features
- Git-native versioning and forking of agent logic for collaborative development
- Universal export to Vercel Labs SKILL.md format for cross-platform compatibility
- Dynamic MCP server for real-time IDE integration (e.g., Cursor, Claude Desktop)
- Strict functional naming conventions for agent personas to avoid 'prompt drift'
- Bootstrap, import, create, update, and export workflows for streamlined lifecycle management

## Why It Matters for RAG Builders
SAVILE eliminates prompt drift and vendor lock-in by centralizing agent logic in a portable, version-controlled format, enabling scalable and reproducible AI agent deployments.
