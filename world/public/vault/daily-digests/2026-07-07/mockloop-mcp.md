## Summary
MockLoop MCP is an AI-native API testing platform built on the Model Context Protocol (MCP). It provides AI-driven test generation, automated execution, and intelligent analysis for API testing workflows, featuring 30+ MCP tools, 5 AI prompts, and 15 scenario packs for comprehensive testing.

## Key Features
- AI-driven test scenario generation with 5 specialized MCP prompts
- 30+ MCP tools for automated testing, analysis, and workflow management
- Dual-port architecture for conflict-free API and admin interface deployment
- Enterprise-grade audit logging and compliance tracking
- Stateful context management with GlobalContext and AgentContext
