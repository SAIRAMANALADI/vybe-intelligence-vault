## Summary
nslookup-mcp is a Windows application that simplifies DNS record lookups, propagation checks, and certificate monitoring using nslookup.io as a data source. It provides a user-friendly interface for DNS-related tasks and supports MCP server integration for programmatic access.

## Key Features
- Performs DNS record lookups (A, AAAA, MX, TXT, NS)
- Checks DNS propagation status after changes
- Monitors SSL/TLS certificate validity
- Acts as an MCP server for programmatic DNS queries
- Provides clean, readable output for easy analysis

## Why It Matters for RAG Builders
It simplifies DNS-related tasks for AI stack builders by providing a reliable, programmatic way to verify domain configurations and certificate statuses.
