## Summary
Mainframe is an AI-native development environment designed to orchestrate and manage AI coding agents through a unified interface. It provides a desktop and mobile client to interact with a headless daemon that supervises agent sessions, projects, and tasks.

## Key Features
- Unified interface for managing multiple AI coding agents (Claude, Codex, etc.)
- Headless daemon with HTTP/WebSocket API for remote and local orchestration
- Multi-project session management with cross-project context switching
- In-app file editing, sandbox previews, and task management (kanban board)
- Extensible plugin system for adding UI panels, databases, and AI adapters

## Why It Matters for RAG Builders
Mainframe streamlines AI agent orchestration by centralizing management, enabling seamless multi-project workflows, and providing a scalable API-first architecture for RAG and AI stack builders.
