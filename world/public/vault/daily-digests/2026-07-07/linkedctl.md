## Summary
LinkedCtl provides a CLI and MCP server for interacting with the LinkedIn API, enabling OAuth2 authentication, content posting, analytics, and AI assistant integration. It supports rich media uploads, organization-level operations, and direct token management for LinkedIn automation and RAG workflows.

## Key Features
- OAuth2 authentication and direct token management for LinkedIn API access
- CLI and MCP server for AI assistant integration (Claude, Cursor, etc.)
- Rich content posting (text, images, video, documents, polls, carousels)
- Organization-level operations (posting, analytics, reactions)
- Post, comment, reaction, and analytics management with profile support

## Why It Matters for RAG Builders
LinkedCtl enables seamless LinkedIn API integration for RAG builders, allowing AI assistants to automate content creation, analytics, and interactions while maintaining secure OAuth2 authentication.
