## Summary
A self-hosted AI agent for private Discord servers that enables natural language interactions via `@ai` mentions, with permission-aware memory over indexed Discord history, tool integration (web search, image generation, code updates), and isolated Kubernetes sandbox execution for safe code modifications.

## Key Features
- Natural language `@ai <request>` interaction with Discord bot
- Permission-aware retrieval and indexing of Discord server history
- Integration with web search, image generation, and Spotify tools
- Isolated Kubernetes sandbox for safe code-update PR generation
- Persistent per-channel conversation context and private skills storage

## Why It Matters for RAG Builders
It provides a self-hosted, permission-aware AI agent framework for Discord communities that combines natural language interaction with secure, isolated code generation and tool execution, reducing reliance on third-party hosted solutions.
