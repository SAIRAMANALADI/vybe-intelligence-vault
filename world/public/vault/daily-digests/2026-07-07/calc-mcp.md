## Summary
Calc MCP is a Model Context Protocol (MCP) server that provides 21 deterministic tools for mathematical calculations, cryptographic operations, date/time handling, encoding/decoding, and data validation. It addresses AI limitations like hallucinated calculations and unreliable randomness by offering secure, local computation.

## Key Features
- 21 specialized tools for math, hashing, encoding, date/time, and validation
- Deterministic and secure local computation with no external data exposure
- Integration with MCP-compatible clients (Claude, VS Code, Cursor, etc.)
- Supports Docker deployment for containerized environments
- Comprehensive documentation and examples for all tools

## Why It Matters for RAG Builders
It provides reliable, local alternatives to AI's unreliable calculations and randomness, ensuring accuracy and security for RAG and AI stack builders.
