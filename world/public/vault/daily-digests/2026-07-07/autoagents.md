## Summary
autoagents is a multi-tenant autonomous assistant framework enabling users to interact with a personal AI agent via email and WhatsApp. The agent processes multimodal inputs (text, images, PDFs, audio, video), performs RAG-based private document searches, schedules tasks, and acts on behalf of users with explicit confirmation gates.

## Key Features
- Multi-channel agent interaction via email and WhatsApp with multimodal input support (text, images, PDFs, audio, video)
- Per-tenant private RAG document store with Vertex RAG Engine for context-aware responses
- Long-term memory via ADK Memory Bank and Firestore for persistent user context across sessions
- Explicit user consent gates for web search and bulk actions to ensure safety and compliance
- Third-party interaction handling with a 3-hour reply window and automatic closure notifications

## Why It Matters for RAG Builders
autoagents provides a production-ready framework for building secure, multi-tenant autonomous agents with multimodal capabilities and private RAG integration, critical for scalable AI assistants in enterprise and consumer applications.
