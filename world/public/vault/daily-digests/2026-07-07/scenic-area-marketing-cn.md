## Summary
A production-grade, fully automated scenic tourism marketing system built on the OpenClaw AI Agent framework. It autonomously collects data from 8+ platforms, generates competitive intelligence reports, and pushes insights to Feishu while archiving insights into an Obsidian knowledge graph.

## Key Features
- 24/7 autonomous operation with 30+ days of continuous runtime without human intervention
- Multi-platform data collection (Douyin, Xiaohongshu, Weibo, Baidu, Feishu Bitable) with automated fallbacks
- Structured competitive intelligence reports with decision-grade insights pushed to Feishu group chats
- Obsidian knowledge graph for archiving and knowledge curation with 3-layer abstraction (Concepts/Entities/Sources)
- Weekly accuracy evaluation and error pattern analysis for continuous improvement
