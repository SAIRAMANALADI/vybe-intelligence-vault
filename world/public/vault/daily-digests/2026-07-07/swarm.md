## Summary
SwarmAttacker is a multi-methodology swarm penetration testing agent built with LangGraph, designed to deploy multiple attack agents in parallel across OWASP categories and vulnerability-specific specialists. It aggregates results to enhance autonomous LLM-based penetration testing workflows.

## Key Features
- Parallel deployment of multiple attack agents (OWASP categories, vulnerability specialists, custom chains)
- Real-time aggregation of results with detailed logging and artifacts (nodes.jsonl, terminal_events.jsonl, summary.md)
- Provider-agnostic LLM integration (Anthropic, OpenAI, OpenRouter, ChatGPT Plus/Pro)
- Modular architecture with planner-executor split for scalable penetration testing
- Built-in loop detection and benchmarking for iterative agent improvement

## Why It Matters for RAG Builders
SwarmAttacker enables autonomous, parallelized penetration testing workflows that can significantly reduce time-to-discovery for vulnerabilities while leveraging multiple attack methodologies simultaneously.
