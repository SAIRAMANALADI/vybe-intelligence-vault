## Summary
aex is an agent execution platform that enables the deployment and management of autonomous agents via a TypeScript SDK and CLI. It provides a managed runtime for agent operations, including shell access, file editing, web interactions, and multi-agent delegation.

## Key Features
- Managed autonomous agent runs with filesystem, shell, and web access
- Durable infrastructure with run records, status tracking, and idempotency
- Agent composition via skills, files, and remote MCP servers
- Subagent support for typed parent/child delegation and output handoff
- Multi-model provider support (Anthropic, OpenAI, Gemini, Mistral, etc.)

## Why It Matters for RAG Builders
aex simplifies the deployment and orchestration of autonomous agents, making it essential for AI engineers building scalable agentic systems.
