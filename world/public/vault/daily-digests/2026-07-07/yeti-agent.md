## Summary
yeti-agent is a Windows desktop application that automates browser tasks using AI agents via the Chrome DevTools Protocol (CDP). It enables users to perform repeatable web interactions like form filling, data extraction, and login automation without coding, leveraging AI models from providers like OpenAI, Anthropic, or Gemini.

## Key Features
- Runs AI-driven browser tasks 24/7 without constant user input
- Uses Chrome DevTools Protocol (CDP) for precise browser control
- Supports multiple AI providers (OpenAI, Anthropic, Gemini)
- Designed for non-technical users with a simple GUI workflow
- Enables scheduled or repeatable web interactions like form filling and data scraping
