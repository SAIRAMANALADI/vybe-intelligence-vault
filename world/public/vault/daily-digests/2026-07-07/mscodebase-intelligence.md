## Summary
MSCodebase Intelligence is an AI-powered semantic code search and analysis tool designed as a Zed IDE extension. It provides advanced code search, call graph analysis, project memory, and multi-bucket RAG capabilities for developers.

## Key Features
- Unified semantic code search with multiple modes (fast, quality, deep, context, ask)
- Multi-bucket RAG with LanceDB and BM25 for hybrid retrieval
- Project memory and call graph analysis for impact assessment
- 43 MCP tools including structural search, cross-repo search, and self-diagnostics
- Clean Architecture with DI container and 391+ automated tests
