## Summary
Telos is a reverse-design learning engine that constructs dependency graphs for mastery goals, diagnoses learner gaps, and schedules personalized review sessions. It combines a local-first product with an AI-driven learning engine to create adaptive study plans.

## Key Features
- Reverse-design learning: builds dependency graphs from mastery goals
- Diagnosis-first approach: identifies learner gaps before teaching
- FSRS-based review scheduling for long-term retention
- Local-first Community Edition with BYOK model support
- Modular architecture with Python engine and Next.js UI

## Why It Matters for RAG Builders
Telos provides a structured framework for adaptive learning and knowledge tracing, enabling AI systems to personalize education paths and optimize retention through dependency-aware scheduling.
