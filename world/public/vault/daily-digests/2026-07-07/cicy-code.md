## Summary
cicy-code is a local-first multi-agent development workspace that integrates tmux workers, WebTTY terminals, React-based UI, an AI gateway, and a skill marketplace into a single binary distributed via npm. It enables orchestration and interaction with coding agents (e.g., Claude, Codex) in a unified environment.

## Key Features
- Unified workspace for running, orchestrating, and chatting with coding agents in tmux
- Integrated WebTTY terminal and React-based UI for seamless interaction
- AI gateway supporting multiple providers (Claude, Codex, OpenCode, etc.)
- Skill marketplace for installing, managing, and publishing agent skills
- Single-binary distribution via npm with platform-specific optional dependencies

## Why It Matters for RAG Builders
It provides a cohesive local-first environment for orchestrating and managing AI agents, reducing complexity for developers building RAG or agent-based systems.
