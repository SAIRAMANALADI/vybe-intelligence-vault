## Summary
A modular agentic platform that transforms sports data into customizable analytics and decision-support tools for trading, fantasy sports, racing, and coaching. It combines a team of 27 specialized LLM agents with a shared data backbone to gather, analyze, and model sports data, while ensuring grounded, audited, and budgeted operations.

## Key Features
- Composable team of 27 specialized agents (product and ops) for sports data analysis, modeling, and advisory tasks
- Cross-bookmaker data ingestion from 10+ providers and 2 prediction markets with automated discovery and normalization
- Deterministic event resolution and cross-book arbitrage detection with grounded, audited, and budgeted operations
- Modular design enabling custom workspaces (trading, fantasy, racing, coaching) without privileged modules
- Desktop app deployment model with CLI, REPL, and web UI, supporting BYO model keys and local data storage

## Why It Matters for RAG Builders
It provides a reusable framework for building specialized agent teams over live sports data, enabling RAG builders to integrate structured, multi-agent workflows for real-time analytics and decision support.
