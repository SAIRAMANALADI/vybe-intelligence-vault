## Summary
A Windows-based CLI tool designed to migrate an entire Supabase project (including database schema, data, auth users, storage files, and edge functions) from one project to another in a single operation, simplifying project duplication or backup tasks.

## Key Features
- One-command migration of Supabase projects
- Copies database schema, table data, auth users, storage files, and edge functions
- Windows-native executable for ease of use
- Supports project duplication, backups, and staging copies
- Handles large datasets with configurable options

## Why It Matters for RAG Builders
It simplifies the process of moving Supabase projects, reducing manual effort and ensuring consistency when duplicating or backing up projects for development, staging, or production environments.
