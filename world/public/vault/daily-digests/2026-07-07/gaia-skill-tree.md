## Summary
Gaia is an open-source registry and skill graph for AI agents that verifies and tracks capabilities through a public ledger of code-execution runs, license checks, and security audits. It enables developers to claim, fuse, and validate agent skills with evidence-backed trust metrics.

## Key Features
- Public ledger of verified AI agent skills with evidence grades and trust metrics
- Tiered skill graph (Basic, Extra, Ultimate) with fusion capabilities
- CLI and TUI for skill scanning, installation, and management
- MCP server integration for agent interoperability
- Static JSON API for programmatic access to skill data

## Why It Matters for RAG Builders
Gaia provides a standardized, evidence-backed way to track and verify AI agent capabilities, enabling trust and interoperability in RAG and agentic systems.
