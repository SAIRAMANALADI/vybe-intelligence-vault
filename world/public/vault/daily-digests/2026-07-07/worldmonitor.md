## Summary
World Monitor is a real-time global intelligence dashboard that aggregates and synthesizes AI-powered news, geopolitical monitoring, and infrastructure tracking into a unified situational awareness interface with multiple specialized variants.

## Key Features
- 500+ curated news feeds across 15 categories with AI synthesis into briefs
- Dual map engine with 3D globe and WebGL flat map supporting 56 layer types
- Country Instability Index (CII) for 31 Tier-1 countries with server-authoritative scoring
- Multi-language support (25 languages) with native-language feeds and RTL support
- Programmatic access via MCP server, REST API, CLI, and SDKs (Python, Ruby, Go)

## Why It Matters for RAG Builders
World Monitor provides a unified, real-time situational awareness interface that integrates AI-powered news synthesis and geopolitical tracking, making it essential for AI engineers building RAG systems that require up-to-date global intelligence.
