## Summary
pxml is a structured XML-based DSL and compiler designed to streamline AI-driven code generation for web applications. It enables developers to define application architecture in XML, manage modifications via a manifest, and leverage AI for local self-healing repairs with minimal context.

## Key Features
- Structured XML DSL for defining application architecture and flows
- AI-driven code generation with minimal prompt engineering
- Self-healing bug repairs with targeted fixes and regression prevention
- Multi-provider LLM support (Anthropic, OpenAI, Ollama)
- Built-in validation, testing, and token usage tracking

## Why It Matters for RAG Builders
pxml enables precise, structured AI-driven code generation and maintenance, reducing prompt ambiguity and improving reliability for RAG and AI engineering workflows.
