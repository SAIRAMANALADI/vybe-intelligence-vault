## Summary
SANBA is a voice-based multi-agent system designed to enhance requirements elicitation through natural, real-time conversations between humans and AI agents. It leverages speech-to-speech interactions, multi-agent collaboration, and multimodal analysis to refine and document requirements iteratively.

## Key Features
- Natural voice-based interviews with low-latency speech-to-speech interactions using Gemini Live and LiveKit
- Multi-agent architecture with specialized sub-agents for non-functional requirements, scope prioritization, and contradiction detection
- Multimodal analysis (text, images, video) to identify gaps and inconsistencies in requirements
- Automated documentation and issue generation from structured requirements stored in Firestore and Elasticsearch
- DevOps-optimized deployment on Cloud Run with Terraform, CI/CD, and observability stacks

## Why It Matters for RAG Builders
It bridges the critical gap in AI-driven development by automating and enhancing the human-AI collaboration required for precise requirements elicitation, reducing bottlenecks in the software development lifecycle.
