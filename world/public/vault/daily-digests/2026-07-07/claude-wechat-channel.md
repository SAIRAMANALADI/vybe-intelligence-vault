## Summary
This repository provides a Windows application that integrates Claude Code with WeChat, enabling users to send and receive messages with Claude Code directly through WeChat without opening a separate tool. It simplifies the workflow by bridging two platforms into a unified chat experience.

- Windows desktop application with simple setup and minimal configuration
