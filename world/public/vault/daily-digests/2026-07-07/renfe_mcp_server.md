## Summary
A Python-based MCP server that provides real-time access to Spanish Renfe train schedules, live pricing, and GTFS data via a custom DWR scraper. Simplifies travel planning by fetching and displaying up-to-date train information.

## Key Features
- Real-time Spanish Renfe train schedules and live pricing
- Custom DWR scraper for direct data fetching from Renfe
- GTFS data integration for structured schedule access
- User-friendly interface for searching trains by route and date
- Cross-platform support (Windows, macOS, Linux)
