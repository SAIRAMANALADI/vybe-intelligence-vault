## Summary
@humanspeak/svelte-markdown is a secure, high-performance markdown and HTML renderer for Svelte 5 with TypeScript support, designed specifically for streaming AI agent output while ensuring XSS safety and accessibility compliance.

## Key Features
- Secure HTML parsing with XSS defaults and protocol allowlist
- Full markdown syntax support with TypeScript strict typing
- LLM streaming mode with incremental rendering (~1.6ms avg per update)
- Customizable component rendering system with inline snippet overrides
- WCAG 2.1 accessibility compliance and GitHub-style header slugs

## Why It Matters for RAG Builders
It enables safe, efficient rendering of AI agent output (markdown + HTML) in Svelte applications while mitigating security risks and supporting real-time streaming updates.
