## Summary
Sulla Desktop is a free, desktop-native autonomous AI agent that runs locally on your machine, offering persistent memory, calendar integration, and sandboxed Docker workspaces. It features a subconscious agent system for just-in-time thinking, observational memory, and context window management to optimize LLM interactions.

## Key Features
- Subconscious agent system for just-in-time memory recall and lightweight agent operation
- Observational memory that captures and distills conversation context into identity files
- Sandboxed Docker-based environment for secure, isolated agent execution
- Context window management with staleness scoring to optimize LLM performance
- Cross-platform support (macOS, Windows, Linux) with one-command installation
