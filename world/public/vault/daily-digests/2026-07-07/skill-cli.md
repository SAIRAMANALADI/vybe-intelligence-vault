## Summary
skill-cli is a cross-agent skill manager for AI coding agents that centralizes skills in a single global store, keeping agent directories clean while enabling flexible activation and triggering of skills across multiple platforms and agents like Claude Code, Codex, and Gemini.

## Key Features
- Centralized skill store (~/.skill-cli/store) to avoid duplication across agent directories
- Three-layer activation system (installed, enabled globally, enabled per project) with allow/deny rules
- Cross-agent support for Claude Code, Codex, Cursor, and Gemini with bootstrap integration
- Universal skill installation from GitHub, GitLab, git URLs, local paths, or npm packages
- Pull-based skill triggering via CLI commands or agent shortcuts (e.g., /X)

## Why It Matters for RAG Builders
It simplifies skill management for AI agents by centralizing and organizing skills, reducing clutter in agent directories and enabling seamless cross-agent compatibility.
