## Summary
A unified video editing control skill that enables AI programming agents (e.g., Codex CLI, Claude Code) to manipulate JianYing/CapCut and Adobe Premiere Pro through CLI, MCP, HTTP API, or direct Python integration. It abstracts video editing operations into a consistent interface for agent-driven workflows.

## Key Features
- Dual backend support for JianYing/CapCut (draft file manipulation) and Adobe Premiere Pro (pymiere integration)
- Four integration modes: CLI, MCP Server, HTTP API, and pure documentation
- Context-aware project state retrieval to prevent destructive edits
- Atomic writes and automatic backups for draft file safety
- Cross-platform compatibility (Windows + macOS) with 6 major AI agent integrations
