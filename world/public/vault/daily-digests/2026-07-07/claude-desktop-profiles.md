## Summary
A utility for managing multiple isolated Claude Desktop sessions on Windows, enabling separate accounts, chat histories, and settings without manual sign-in/out. It acts as a profile manager for the official Claude Desktop client.

## Key Features
- Creates isolated environments for multiple Claude Desktop sessions
- Separates login credentials, chat history, and settings per profile
- Supports launching multiple profiles simultaneously
- Local-only storage with no data collection
- Easy profile creation and management via a GUI
