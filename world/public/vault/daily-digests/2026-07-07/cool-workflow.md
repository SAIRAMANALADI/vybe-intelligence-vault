## Summary
Cool Workflow (CW) is a CLI and MCP tool that transforms AI agent runs into durable, inspectable, and verifiable workflows. It records, verifies, and reports agent actions with evidence-based citations, ensuring transparency and tamper-evidence for high-stakes AI-driven tasks.

## Key Features
- Durable, inspectable workflows with signed ledgers for tamper-evidence
- Evidence-gated decisions with every claim cited to source files
- Multi-agent topologies (map-reduce, debate, judge-panel) for parallel execution
- Deterministic, local replay of workflows with plain JSON artifacts
- Vendor-neutral design with fail-closed drift checks and no model API calls

## Why It Matters for RAG Builders
It provides a critical layer of transparency and verifiability for AI agent workflows, ensuring that outputs are traceable, tamper-evident, and reproducible for RAG and AI stack builders.
