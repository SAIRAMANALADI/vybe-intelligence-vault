## Summary
Kide is a Kotlin Multiplatform (KMP) library that provides a strict MVI (Model–View–Intent) architecture with optional Clean Architecture integration, designed specifically for AI-assisted development. It targets Android, iOS, and JVM (desktop) platforms and integrates with modern UI frameworks like Compose Multiplatform, Navigation 3, Decompose, and Voyager.

## Key Features
- First AI-agent native MVI architecture with embedded MCP server for real-time debugging and intent dispatching
- Guaranteed lossless intent queues, deterministic synchronous reductions, and exactly-once side-effect delivery
- Pure Kotlin Multiplatform with 100% logic sharing across Android, iOS, and JVM (desktop)
- Optional Clean Architecture scaffolding for domain-driven design and modularity
- Modern Compose Navigation integration with type-safe ScreenNavKey and back-stack persistence

## Why It Matters for RAG Builders
Kide enables AI agents to directly debug, test, and interact with running applications, making it essential for teams leveraging AI-assisted development in their RAG and AI stack workflows.
