## Summary
gws-os is a Windows-based tool that integrates Google Workspace (Gmail, Calendar, Drive) into a unified interface with a memory system to track trust, relevance, and patterns over time. It is designed for learning-first workflows and multi-account management, particularly for users of Claude Code.

## Key Features
- Unified interface for Gmail, Calendar, and Drive across multiple Google accounts
- Memory system using CAR Protocol to track trust, relevance, and patterns
- Built-in relevance scoring and pattern detection for prioritizing content
- Designed for integration with Claude Code workflows
- Local-first learning flow with persistent memory data
