## Summary
CodeFlowMu Open Dev Team Edition is a local AI agent orchestration tool that simulates a coordinated development team (PM, DEV, OPS, QA) to collaborate on projects via a shared workspace. It enables task decomposition, code generation, testing, and deployment through a file-based protocol.

## Key Features
- Fixed PM/DEV/OPS/QA agent team for structured project collaboration
- File-based protocol for agent communication and task execution
- Local-first deployment with a web-based control panel
- Git integration for version control and contribution tracking
- Public skills library and task templates for reusable workflows

## Why It Matters for RAG Builders
It provides a structured, local-first framework for orchestrating multiple AI agents to collaboratively develop and deploy software, reducing coordination overhead for RAG and AI stack builders.
