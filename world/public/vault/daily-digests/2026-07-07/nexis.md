## Summary
Nexis is an open-source, AI-native terminal and developer environment built on Tauri 2, Rust, and React 19. It combines a lightweight terminal emulator, full-featured code editor, file explorer, source control, and AI agent capabilities into a single cross-platform application.

## Key Features
- Multi-tab terminal with native PTY support for zsh, bash, pwsh, fish, and cmd
- Full-featured code editor with AI-powered autocomplete, diff approval, and LSP/DAP support
- Integrated AI agents with 12+ providers (OpenAI, Anthropic, Ollama, etc.) and offline options
- ML Lab for training and deploying small models locally with live visualization
- Git integration with AI-assisted commit messages, PR descriptions, and conflict resolution

## Why It Matters for RAG Builders
Nexis provides a unified, AI-enhanced developer environment that streamlines workflows by integrating terminal, editor, AI agents, and ML tools into a single cross-platform application.
