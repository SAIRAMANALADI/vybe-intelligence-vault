## Summary
Starizzi is a cross-platform desktop application that serves as a multi-agent gateway for running, orchestrating, and interacting with various open-source AI agents like OpenClaw, Hermes, AutoGPT, Dify, CrewAI, and n8n through a sleek glassmorphic UI. It leverages IzziAPI for unified model access and supports messaging channels like Telegram and Zalo.

## Key Features
- Unified interface for managing multiple AI agents (OpenClaw, Hermes, AutoGPT, etc.) with parallel chat support
- One-click setup and configuration via Express mode or custom setup with Docker integration
- IzziAPI smart routing for 200+ models (GPT, Claude, Gemini) with cost tracking and budget alerts
- Built-in marketplace for discovering, installing, and managing agent extensions (.ocx files)
- Cross-platform support for Windows and macOS with auto-update functionality

## Why It Matters for RAG Builders
It simplifies the deployment and management of multiple AI agents in a single desktop environment, reducing complexity for RAG builders who need orchestration and unified access to models.
