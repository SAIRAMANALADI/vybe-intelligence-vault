## Summary
Cyrene-Agent is a desktop Live2D smart companion built with Electron and TypeScript, featuring the Cyrene character from Honkai: Star Rail. It combines emotional interaction, personalized memory engines, and multi-modal AI capabilities into a cohesive desktop application.

## Key Features
- Live2D desktop companion with emotional synchronization and natural animations
- Personalized memory engine with L0/L1/L2 tiers and conflict resolution
- Multi-modal AI integration (TTS, ASR, vision, RAG)
- Modular skill system and tool delegation for agent automation
- Cross-platform desktop application with tray integration and window management

## Why It Matters for RAG Builders
Cyrene-Agent demonstrates a production-ready desktop agent framework integrating memory, multi-modal interaction, and RAG, serving as a reference for building emotionally intelligent AI companions.
