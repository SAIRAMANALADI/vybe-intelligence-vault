## Summary
CR Pulse EYBL Tracker is a Next.js-based web application that provides real-time basketball player and team statistics for the Nike EYBL/EYCL leagues. It tracks performance metrics like PPG, RPG, and FG% using data from the Cerebro Sports public widget API.

## Key Features
- Player performance tracking with detailed stats (PPG, RPG, APG, etc.)
- Team leaderboards for top Nike EYBL/EYCL teams
- Integration with Cerebro Sports public widget API for data sourcing
- Responsive Next.js frontend for real-time data display
- Local development and production build scripts
