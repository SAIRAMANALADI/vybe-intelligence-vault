## Summary
n2-arachne is a Windows desktop application designed to streamline AI context assembly by filtering and organizing large sets of files and notes into focused, noise-free inputs for AI tools and agents. It helps manage context windows efficiently for LLM workflows and AI coding assistants.

## Key Features
- Scans and maps project structures to identify key files
- Filters out irrelevant data to reduce noise in AI inputs
- Supports dependency-aware context assembly
- Local storage for project data and cached indexes
- Exports clean, focused context packages for AI tools
