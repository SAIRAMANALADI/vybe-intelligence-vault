## Summary
rocketplaneIO is a self-hosted AI Site Reliability Engineering (SRE) platform for Kubernetes that autonomously investigates and fixes issues using an LLM-powered copilot. It combines zero-instrumentation eBPF observability with guardrailed, reversible actions to safely resolve incidents while maintaining full audit trails.

## Key Features
- Autonomous incident investigation using LLM with evidence-based root cause analysis
- Guardrailed, reversible action pipelines with risk-based approval tiers
- Zero-instrumentation eBPF observability for HTTP/gRPC/SQL/Redis/Kafka traces
- Self-verifying actions with automatic rollback on failure
- Embedded PromQL engine and full Kubernetes inventory integration
