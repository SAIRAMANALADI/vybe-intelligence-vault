## Summary
TeLLMphone is a local MCP server enabling coding agents to communicate directly with each other, facilitating multi-turn conversations, second opinions, and persistent agent-to-agent interactions without manual copy-pasting.

## Key Features
- Enables direct agent-to-agent calls via MCP for real-time collaboration
- Supports persistent conversations with voicemail functionality for offline agents
- Provides personality-based system prompts for tailored agent interactions
- Includes built-in personalities and write-permission controls for security
- Lightweight switchboard architecture with no daemon, using shared state under ~/.tellmphone/

## Why It Matters for RAG Builders
TeLLMphone streamlines multi-agent workflows by automating agent communication, reducing manual intervention and enabling seamless second opinions or collaborative problem-solving in AI-driven development.
