## Summary
mcp-webgate is a Windows application designed to provide clean, noise-free web search results for AI agents via the Model Context Protocol (MCP). It acts as an intermediary to filter and trim web content, preventing context flooding in AI prompts.

## Key Features
- Acts as an MCP server for web search integration with AI agents
- Filters and trims web search results to reduce context noise
- Supports multiple search backends like Brave Search and SearxNG
- Lightweight and easy to set up on Windows
- Designed to minimize prompt bloat in AI applications

## Why It Matters for RAG Builders
It enables AI agents to perform web searches without overwhelming their context windows by providing clean, trimmed results.
