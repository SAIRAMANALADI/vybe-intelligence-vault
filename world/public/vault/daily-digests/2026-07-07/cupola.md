## Summary
Cupola is a standalone web frontend for browsing VGI (Vector Gateway Interface) database catalogs. It connects to any VGI HTTP server, providing a navigable catalog browser with an embedded SQL shell, pivot tables, and an AI data analysis agent.

## Key Features
- Interactive catalog browser with searchable navigation and detail panels
- Embedded DuckDB-WASM SQL shell with xterm.js terminal and session persistence
- Claude-powered AI agent for data analysis and SQL execution
- Pivot tables and data grids via Perspective library
- Deep linking and OAuth/PKCE support for secure authentication

## Why It Matters for RAG Builders
Cupola provides a unified, interactive interface for exploring and querying VGI databases with built-in AI assistance, streamlining data analysis workflows for RAG builders.
