## Summary
SanctionPay is an AI-powered autonomous compliance agent that screens crypto wallets, entities, and individuals against international sanction lists (OFAC SDN, UN Security Council, EU Consolidated) using the Casper Network. It combines x402 micropayments, Claude AI analysis, and immutable on-chain record-keeping for compliance infrastructure.

## Key Features
- Autonomous sanction screening against multiple global lists (OFAC, UN, EU)
- x402 micropayment integration for autonomous transactions on Casper Network
- AI-powered compliance analysis via Claude API for risk scoring and recommendations
- Immutable on-chain recording of screening results using Odra smart contracts
- Dual deployment options: Docker for simplicity or native for flexibility

## Why It Matters for RAG Builders
