## Summary
Reina is a desktop application that enables users to create and manage multi-agent AI teams for task automation, coding projects, and workflow organization. It allows users to connect their own AI models and expand agent capabilities via a skill marketplace without requiring programming knowledge.

## Key Features
- Multi-agent team coordination for parallel task execution
- Skill marketplace for expanding agent capabilities without coding

- Local execution of tasks with optional cloud model integration
- Goal-based task automation with agent-driven planning
