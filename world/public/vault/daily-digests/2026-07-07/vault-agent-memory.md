## Summary
Vault Agent Memory provides a governed, local-first memory layer for AI agents, enabling shared, reviewable, and auditable memory management across multiple agents. It focuses on memory governance rather than raw retrieval or storage, ensuring agents share only reviewed, current, and trustworthy information.

## Key Features
- Governed memory lifecycle with candidate review, promotion, and rollback capabilities
- Local-first storage with SQLite and Markdown for zero-dependency operation
- Daily memory reports for human review of uncertain or high-risk memories
- Multi-agent support via MCP integration for shared memory vaults
- Temporal boundaries and expiry to ensure agents surface current information

## Why It Matters for RAG Builders
It provides a critical governance layer for AI agents, ensuring shared memory is reviewed, auditable, and current, which is essential for reliable and trustworthy multi-agent systems.
