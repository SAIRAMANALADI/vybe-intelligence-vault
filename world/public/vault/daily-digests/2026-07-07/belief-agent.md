## Summary
A Kotlin-based agent framework that explicitly models uncertainty using a Belief State over competing hypotheses, enabling probabilistic reasoning and confidence-gated decision-making for AI agents.

## Key Features
- Explicit modeling of uncertainty via Belief State over discrete hypotheses
- Bayesian updating of hypothesis probabilities based on evidence
- Confidence-threshold gates for irreversible actions
- Deterministic CLI demos for testing agent behavior
- HexSlice architecture with strict process gates (build, test, coverage, arch-check)

## Why It Matters for RAG Builders
It provides a robust framework for AI agents to handle uncertainty and make trustworthy decisions by modeling competing hypotheses and enforcing confidence thresholds before action.
