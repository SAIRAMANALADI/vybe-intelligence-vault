## Summary
A Windows-based bridge plugin that connects WeChat messages to Claude Code sessions via the ClawBot ilink API, enabling users to manage WeChat conversations directly within Claude Code without switching between applications.

## Key Features
- Real-time message bridging between WeChat and Claude Code
- Windows-native setup with minimal configuration
- Uses ClawBot ilink API for secure message routing
- Supports one-window workflow for chat and coding tasks
- Includes troubleshooting and logging for stability
