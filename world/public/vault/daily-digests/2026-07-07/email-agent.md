## Summary
An AI-powered email automation agent that integrates with Gmail via IMAP to read, categorize, and draft professional replies using LLaMA 3.3. It provides a React-based dashboard for reviewing, editing, and approving drafts before sending via SMTP, all without requiring Google Cloud.

## Key Features
- IMAP-based Gmail integration without Google Cloud dependency
- AI-driven email categorization and draft reply generation using LLaMA 3.3 via Groq API
- React dashboard for reviewing, editing, and approving drafts before sending
- Automated background processing with APScheduler (5-minute intervals)
- Local logging to CSV and in-memory state management for persistence

## Why It Matters for RAG Builders
It streamlines email triage and response generation, reducing manual effort for AI engineers and developers managing high-volume inboxes.
