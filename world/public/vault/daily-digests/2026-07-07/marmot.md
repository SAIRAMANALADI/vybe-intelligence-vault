## Summary
Marmot is an open-source data catalog designed to simplify data discovery and metadata management for teams and AI tools. It enables cataloging of tables, topics, queues, APIs, and dashboards while exposing certified context via MCP, API, and UI for AI agent integration.

## Key Features
- Single-binary deployment with intuitive UI for rapid setup
- Full-text and structured search across all data assets with metadata filters
- Interactive lineage tracing for data flow analysis and impact assessment
- Rich metadata storage and team collaboration features (ownership, glossaries)
- AI-ready exposure of certified context via MCP, API, and UI

## Why It Matters for RAG Builders
Marmot provides a lightweight, open-source way to expose certified metadata and context to AI agents, eliminating the need for complex enterprise catalogs while ensuring AI tools have accurate, real-time data insights.
