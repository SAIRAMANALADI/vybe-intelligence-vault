## Summary
Folio is a local-first markdown vault and AI agent platform designed for long-term memory retention and strategic planning. It enables users to maintain a persistent, markdown-based knowledge base that a locally-running AI agent (Hermes) can interact with, ensuring privacy and continuity across sessions.

## Key Features
- Persistent markdown-based knowledge base with YAML frontmatter for structured data
- Local AI agent (Hermes) integration for real-time context-aware interactions
- Campaign and timeline management with kanban and gantt visualizations
- Mail processing pipeline with domain-specific actionability tagging
- Setup wizard and demo vaults for quick onboarding and testing

## Why It Matters for RAG Builders
Folio enables RAG builders to create persistent, locally-managed knowledge bases that AI agents can continuously reference, eliminating session-based memory loss and ensuring privacy-sensitive long-term context retention.
