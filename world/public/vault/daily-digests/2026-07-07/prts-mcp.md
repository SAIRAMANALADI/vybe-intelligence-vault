## Summary
A Model Context Protocol (MCP) server providing live access to Arknights game data, lore, and fan-created content via the PRTS Wiki API and auto-synced game data. Supports both Python (stdio) and TypeScript (HTTP) implementations for integration with MCP-compatible AI clients.

## Key Features
- Dual-language support (English/Chinese) for Arknights game data and lore
- 23+ MCP tools for querying operators, enemies, stages, items, and story content
- Auto-syncing of game data from PRTS Wiki and ArknightsGameData repositories
- Support for both Python (stdio) and TypeScript (HTTP/Bun) implementations
- Structured and human-readable output channels for MCP clients

## Why It Matters for RAG Builders
It enables AI agents to dynamically retrieve and integrate Arknights game lore, operator data, and story content for enhanced contextual understanding and creative applications.
