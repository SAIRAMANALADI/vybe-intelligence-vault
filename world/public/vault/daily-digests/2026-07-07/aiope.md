## Summary
AIOPE is an Android AI assistant with 46 tools, real-time voice interaction, a Linux terminal, browser automation, and dynamic UI rendering. It supports multi-agent orchestration, remote server management via SSH, and connects to any OpenAI-compatible API through a self-hosted gateway.

## Key Features
- 46 integrated tools for system, communication, web, location, AI, and remote servers
- Real-time voice interaction with full tool access via Google Gemini Live API
- Dynamic native UI rendering with 30+ Compose components for interactive workflows
- Multi-agent orchestration with DAG pipelines, timers, and monitoring
- Self-hosted gateway for model routing, rate limiting, and API key management

## Why It Matters for RAG Builders
