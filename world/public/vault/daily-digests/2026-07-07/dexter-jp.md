## Summary
Dexter JP is an autonomous AI research agent specialized for Japanese stocks that autonomously plans, executes, and verifies multi-source financial analysis, generating structured reports from user queries. It integrates EDINET DB and J-Quants data sources to perform financial comparisons, risk assessments, and DCF valuations without human intervention.

## Key Features
- Autonomous multi-step financial analysis with self-generated plans and verification steps
- Integration with EDINET DB (financial statements, risk factors) and J-Quants (stock prices)
- Meta-tool routing system for dynamic API selection and parallel execution
- Structured report generation with comparative analysis and conclusions
- Multi-channel deployment (Slack, Discord, LINE) with session memory and context compression
