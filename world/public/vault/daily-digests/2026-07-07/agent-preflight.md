## Summary
agent-preflight is a Windows-based pre-deployment tool designed to audit AI coding agents for security vulnerabilities, code structure issues, and common mistakes before public release. It performs local scans to identify security gaps, login problems, payment errors, and database misconfigurations without sending code externally.

## Key Features
- Identifies hidden API keys and secrets in code
- Validates authentication and login system security
- Scans database configurations for privacy risks
- Provides plain-language explanations for fixes
- Runs entirely offline without code transmission

## Why It Matters for RAG Builders
It ensures AI-generated code is secure and production-ready by catching critical vulnerabilities before deployment, reducing risk of breaches or failures in live environments.
