## Summary
ZapTrace is an AI-native, verification-first EDA kernel that transforms natural language or structured intent into manufacturable PCB designs with embedded proof packs. It automates schematic synthesis, ERC/DRC validation, placement, routing, and manufacturing exports while providing auditable evidence for every design decision.

## Key Features
- Programmatic PCB design via Python SDK and CLI
- 93 MCP tools for AI agent integration
- Embedded ERC/DRC validation with KiCad oracle integration
- Automated placement, routing, and manufacturing export pipelines
- Auditable proof packs for design decisions and verification evidence

## Why It Matters for RAG Builders
ZapTrace bridges the gap between AI-generated intent and manufacturable electronics by providing a verification-first EDA kernel that automates and audits the entire PCB design process, making it essential for AI-driven hardware development workflows.
