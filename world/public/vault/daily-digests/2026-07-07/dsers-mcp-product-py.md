## Summary
A Python-based MCP server designed to streamline DSers product import workflows, enabling AI agents or MCP clients to interact with DSers and Shopify for dropshipping automation. It acts as a local bridge for product data handling and import tasks.

## Key Features
- Local MCP server for DSers product import workflows
- Supports Shopify and DSers API integrations
- Uses Model Context Protocol for AI agent connectivity
- Designed for dropshipping automation and bulk variant edits
- Runs locally with stdio-based connections
