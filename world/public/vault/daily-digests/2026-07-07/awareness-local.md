## Summary
Awareness-Local provides persistent, local memory storage for AI agents using Markdown files and SQLite, enabling offline context retention and hybrid search capabilities. It integrates with MCP-compatible tools like Claude Code and Cursor to enhance agent workflows.

## Key Features
- Stores agent memory in local Markdown files for easy readability and backup
- Uses hybrid search (FTS5 + embeddings) for fast and semantic retrieval
- Integrates with AI tools via MCP for seamless context sharing
- Runs entirely offline after initial setup, ensuring data privacy
- Provides a web dashboard for manual memory management and review

## Why It Matters for RAG Builders
It enables AI agents to retain persistent, local context without cloud dependencies, improving privacy and reducing latency for RAG systems.
