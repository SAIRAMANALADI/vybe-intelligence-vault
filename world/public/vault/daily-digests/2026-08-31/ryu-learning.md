## Summary
ryu-learning is a continual-learning loop for the Ryu AI system that converts chats and runs into reusable skills, gated by an approval inbox and tracked via an experience log. It integrates tightly with Ryu's core subsystems to enable skill synthesis and refinement.

## Key Features
- Converts conversations into reusable skills with human approval gating
- Tracks learning progress via an experience log stored in SQLite
- Integrates with Ryu's core subsystems (conversation store, skills registry, approvals inbox)
- Provides a companion UI for interacting with the learning loop
- Supports both binary and crate-based installation for flexibility

## Why It Matters for RAG Builders
It enables AI systems to autonomously improve and adapt by converting interactions into reusable skills while maintaining human oversight through approval gating.
