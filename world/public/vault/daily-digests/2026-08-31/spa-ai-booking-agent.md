## Summary
A luxury spa booking and concierge automation platform powered by AI and N8N workflows. It integrates real-time booking management, intelligent FAQ handling, and guest automation with a modern React 19 frontend and TanStack Start backend.

## Key Features
- AI-powered chatbot for bookings and FAQs with real-time responses
- N8N-based workflow automation for booking management, confirmations, and reminders
- Modern React 19 frontend with TanStack Start for SSR and routing
- Integration with multiple LLM models (OpenAI, Claude) and vector databases for semantic search
- Responsive UI with Tailwind CSS v4 and TypeScript for type-safe development
