## Summary
Votura MCP Server provides an API to search and retrieve AI-powered audio tours and points of interest by city or coordinates. It enables integration with tools like Claude Desktop and Cursor for seamless access to narrated walking, cycling, and driving tours with multilingual support.

## Key Features
- Search audio tours by city, coordinates, or transport type (walking, cycling, driving)
- Retrieve detailed tour information including stops, duration, and deep links
- Find points of interest filtered by category and proximity
- Multilingual support for tours and search queries
- Zero-authentication MCP server with direct URL integration

## Why It Matters for RAG Builders
It enables AI agents to dynamically fetch and integrate real-world audio tours and points of interest into applications, enhancing travel and exploration use cases.
