## Summary
A specialized MCP (Model Context Protocol) server designed for Taiwanese cybersecurity community reporting and terminology management. It automates the collection of security news from 32 international and local sources, generates weekly reports, and maintains a curated glossary of 471 security terms.

## Key Features
- Automated collection of security news from 32 sources (RSS, NVD, CISA KEV)
- Two-phase reporting architecture: raw data collection via GitHub Actions and intelligent report generation via Claude Code
- Integrated terminology library with 471 terms and approval workflows
- Support for historical report generation and health checks for RSS sources
- LINE Notify integration for automated report distribution

## Why It Matters for RAG Builders
It provides a structured pipeline for automating cybersecurity news aggregation and terminology extraction, reducing manual effort in RAG data preprocessing for security-focused AI applications.
