## Summary
TNL Intelligence provides open-source developer tools for The Neural Ledger's intelligence API, offering structured, source-linked global event intelligence for AI agents and quantitative research systems. It serves as an evidence and research layer, not a trading system or price source.

## Key Features
- TypeScript and Python SDKs for seamless integration with AI systems
- CLI and MCP server for local and remote access to intelligence data
- Evidence-first research orchestration with cited results and web UI
- Hosted gateway with OAuth, tenant policy, and quota management
- Webhook contracts and verification helpers for real-time event delivery

## Why It Matters for RAG Builders
