## Summary
WP OPS is a CLI tool and MCP server for WordPress operations, offering automated deployments, backups, security scanning, monitoring, and content workflows. It integrates with Trellis and Bedrock workflows, providing a unified interface for managing WordPress sites through manifest-driven scripts and Ansible playbooks.

## Key Features
- Unified CLI for WordPress operations with auto-discovery of commands from manifests and scripts
- MCP server integration for direct tool invocation in AI clients like Claude
- Automated backups, security scanning, and monitoring for WordPress sites
- Interactive command picker with shell completion and guided prompts
- Project-aware environment detection for Trellis and Bedrock workflows

## Why It Matters for RAG Builders
