## Summary
SeekerCraft is an AI-driven Minecraft bot implemented in Rust that autonomously survives, crafts, and defeats the Ender Dragon using a structured LLM toolset and the Azalea protocol client. It explores AI agent development and 'vibe coding' methodologies.

## Key Features
- 44 LLM tools for perception, crafting, mining, and survival actions
- Structured task system with 23 tiered objectives (wood → netherite → Ender Dragon)
- Real protocol client integration via Azalea (no mods or screenshots)
- Spatial WorldMemory for chunk-indexed game state tracking with TTL forgetting
- Autopilot mode for autonomous development loops and anomaly triage
