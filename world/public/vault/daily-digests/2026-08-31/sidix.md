## Summary
SIDIX is a free, open-source, self-hosted AI agent framework designed for self-learning, self-evolving, and autonomous operation without vendor API dependencies. It integrates a local LLM (Qwen2.5-7B with LoRA) and a distributed knowledge-preservation architecture inspired by a 1,400-year-old Islamic epistemological system (IHOS).

## Key Features
- Self-learning and self-evolving AI agent with continuous learning via LoRA and rehearsal buffers
- Distributed knowledge-preservation architecture (Proof-of-Hifdz) for integrity and fault tolerance
- Multi-agent system with 5 persona-based cognitive styles (UTZ, ABOO, OOMAR, ALEY, AYMAN)
- Proactive agentic behavior with ReAct loops, meta-cognition, and boundary/context awareness
- Open-source, MIT-licensed, and designed for self-hosting with no vendor API dependencies

## Why It Matters for RAG Builders
SIDIX provides a censorship-resistant, failure-proof AI agent framework with a novel distributed knowledge-preservation mechanism, enabling trustworthy, self-hosted AI systems that evolve autonomously without corporate oversight.
