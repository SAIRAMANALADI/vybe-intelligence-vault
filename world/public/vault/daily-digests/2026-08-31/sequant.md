## Summary
Sequant is an AI coding agent orchestrator that automates the end-to-end resolution of GitHub issues, enforcing a structured spec-exec-qa pipeline with isolated git worktrees and quality gates. It stops at the human merge gate, ensuring only review-ready PRs are created.

## Key Features
- Structured spec-exec-qa pipeline with isolated git worktrees for each issue
- Automated quality gates including type safety, security scans, and test validation
- Integration with Claude Code and Aider as AI agents
- MCP server for enhanced workflow automation and tooling
- Batch triage and execution with dependency-aware ordering

## Why It Matters for RAG Builders
Sequant ensures AI-generated code is rigorously validated and review-ready before merging, eliminating manual workflow overhead and reducing risks of untested or low-quality code in production.
