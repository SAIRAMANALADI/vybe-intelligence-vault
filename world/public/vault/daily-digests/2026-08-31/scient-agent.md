## Summary
ScientFactory/scient-agent is an open-source AI coding agent derived from OpenCode, designed to assist developers with coding tasks, code exploration, and multistep development workflows through specialized agents.

## Key Features
- Built-in agents for different tasks (build, plan, general) with role-specific permissions
- Cross-platform support (macOS, Windows, Linux) with multiple installation methods
- Terminal and desktop app interfaces for flexible usage
- Read-only agent mode for safe code exploration and analysis
- Extensible architecture with support for custom agents and workflows
