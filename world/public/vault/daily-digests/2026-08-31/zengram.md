## Summary
Zengram provides a shared memory system for multi-agent AI systems, enabling cross-machine and cross-session memory sharing with typed memory (events, facts, statuses, decisions) and unified storage in PostgreSQL with pgvector for semantic search. It supports multi-path retrieval, credential scrubbing, and MCP server integration.

## Key Features
- Typed memory system (events, facts, statuses, decisions) with lifecycle management
- Unified storage in PostgreSQL with pgvector for hybrid semantic and structured search
- Multi-path retrieval (vector, full-text, entity graph) with weighted RRF fusion
- Cross-agent briefings, corroboration, and credential scrubbing for security
- MCP server integration for seamless agent interoperability

## Why It Matters for RAG Builders
Zengram enables multi-agent AI systems to share and retrieve context across sessions and machines, eliminating memory silos and improving coordination in RAG pipelines.
