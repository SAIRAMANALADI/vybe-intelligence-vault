## Summary
Wind is a utility-first styling framework for Flutter that enables developers to rapidly build modern apps using Tailwind CSS-like className strings. It maps these strings to optimized Flutter widget trees, supports dark mode, responsive design, state prefixes, and includes three AI integration layers for agent-based development.

## Key Features
- Tailwind-syntax className strings for Flutter widgets, enabling rapid UI development with familiar syntax
- 27 W-prefix widgets (e.g., WDiv, WText, WButton) and 24 theme fields for customizable styling
- Dark mode, responsive design, state prefixes (hover, focus), and platform-specific styling (iOS, Android, web)
- Three AI integration layers: MCP server, AI skills for agents (Claude Code, Cursor, etc.), and server-driven UI via WDynamic
- Production-stable since 1.0 with 90%+ test coverage, CI enforcement, and comprehensive documentation

## Why It Matters for RAG Builders
Wind bridges the gap between Tailwind CSS and Flutter, enabling developers to leverage familiar utility-first styling while integrating AI-driven development workflows for faster, more maintainable UI construction.
