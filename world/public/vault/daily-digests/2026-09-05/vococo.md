## Summary
Vococo is a personal AI assistant framework designed for single-user, voice-first interactions with multi-channel access (TUI, CLI, Web PWA). It supports real-time voice conversations, task automation, long-term memory, and multi-vendor model switching while prioritizing security and self-maintenance.

## Key Features
- Multi-channel access (TUI, CLI, Web PWA) with shared session state
- Voice-first capabilities (STT, TTS, real-time Omni calls)
- Long-term memory management with Markdown-based recall and storage
- Multi-vendor model switching (DeepSeek, Kimi, Anthropic-compatible endpoints)
- Built-in task scheduler (cron, intervals, one-time tasks) with automation suggestions

## Why It Matters for RAG Builders
Vococo provides a robust, voice-first agent framework with built-in memory and task automation, making it ideal for developers building personalized AI assistants with minimal setup overhead.
