## Summary
A Model Context Protocol (MCP) server for Syncro MSP that implements a decision tree architecture for efficient tool navigation, enabling AI assistants to interact with Syncro's MSP platform (customers, tickets, assets, contacts, invoices) via structured tooling and lazy loading.

## Key Features
- Decision tree architecture for hierarchical tool navigation, reducing cognitive load for LLMs
- Lazy loading of domain handlers and Syncro client for efficient resource usage
- Full Syncro API coverage across customers, tickets, assets, contacts, and invoices
- Interactive ticket card rendering in MCP Apps hosts (e.g., Claude Desktop) with round-trip comment functionality
- Multiple deployment options including one-click deployments to DigitalOcean and Cloudflare Workers

## Why It Matters for RAG Builders
It enables AI assistants to seamlessly integrate with Syncro MSP's ecosystem, providing structured and efficient tool access for managing MSP operations.
