## Summary
TeleCoder bridges Telegram to a local Claude Code agent, enabling users to interact with a full-featured AI assistant via their phone. It supports real-time file editing, web browsing, voice transcription, and multi-model routing with failover capabilities.

## Key Features
- Full Claude Code agent with tool access (Bash, file I/O, code editing, web browsing) running locally
- Telegram-based interface with streaming responses, session memory, and rich output formatting
- Provider router for model failover (Claude Code SDK, PTY transport, or CCR proxy)
- Integrated voice transcription, text-to-speech, and media extraction (YouTube, Reddit, TikTok)
- Multi-project support with session forking, scheduling, and terminal teleportation

## Why It Matters for RAG Builders
TeleCoder enables seamless, mobile-first interaction with a powerful local AI agent, making advanced AI tooling accessible from any device while supporting failover and multi-model routing for reliability.
