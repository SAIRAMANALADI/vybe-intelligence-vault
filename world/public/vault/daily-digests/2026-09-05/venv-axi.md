## Summary
venv-axi provides an Agent eXperience Interface (AXI) for introspecting Python virtual environments, enabling agents to query exact signatures, dependencies, and module structures at pinned versions in a token-efficient TOON format. It bridges the gap between documentation tools and runtime introspection for private or undocumented packages.

## Key Features
- Live introspection of Python virtual environments to extract exact signatures and dependencies at pinned versions
- TOON format output for token efficiency in AI agent contexts
- MCP server integration for exposing introspection tools to agents
- Support for private, internal, and undocumented package distributions
- Automated setup for ambient context injection (AGENTS.md, MCP config)

## Why It Matters for RAG Builders
It enables AI agents to accurately introspect and utilize exact versions of dependencies, including private packages, ensuring reliable and version-specific symbol resolution for RAG and agent workflows.
