## Summary
A lightweight CLI/TUI agent that connects LLMs to system tools, files, network, memory, and automation with real tool calling capabilities. Supports both native and prompt-based tool invocation modes, runs locally or in the cloud, and features a Textual-based TUI with streaming responses.

## Key Features
- Dual-mode tool calling (native and prompt-based) for broad LLM compatibility
- Textual-based TUI with streaming responses, animations, and sidebar navigation
- Over 100 built-in tools for file system, shell, Python, HTTP, Git, memory, and desktop automation
- Docker sandbox for isolated and secure tool execution
- Supports local and cloud LLM backends (Ollama, LM Studio, vLLM, OpenAI, Groq, Mistral, etc.)

## Why It Matters for RAG Builders
It provides a minimal, single-file agent framework with robust tool integration and dual-mode tool calling, enabling RAG builders to easily connect LLMs to real-world actions and automation.
