## Summary
xander-operator is an AI-powered orchestrator for safe, auditable browser automation and research, combining Playwright for web interaction with optional vector memory, LLM synthesis, and human-in-the-loop approval gates to ensure reliability and traceability.

## Key Features
- Stable web interaction via Playwright with robust selectors and error handling
- Human approval gates for sensitive actions to enforce safety and compliance
- Optional vector memory (Chroma/FAISS) for semantic recall of past actions and context
- LLM-powered research synthesis with caching (OpenAI or Ollama) for intelligent answer generation
- Structured logging, HTML reporting, and CLI tools for auditing and reviewing task execution

## Why It Matters for RAG Builders
It provides a production-ready framework for building trustworthy AI agents that interact with the web, combining safety, memory, and synthesis capabilities critical for RAG pipelines and autonomous research workflows.
