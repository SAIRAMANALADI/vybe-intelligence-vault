## Summary
The Vault is a local-first memory operating system for AI-assisted work that provides durable project memory for coding agents and human operators. It enables cross-session continuity by storing decisions, handoffs, and context outside chat history, accessible via MCP clients like Codex or Claude Desktop.

## Key Features
- Durable project memory storage for AI agents across sessions
- MCP server integration for seamless client connectivity (Codex, Claude, etc.)
- Optional Graphify extension for project graph-aware recall
- Vault Collab extension for provider-neutral multi-agent collaboration
- Desktop console with project hygiene, recall, and lifecycle controls

## Why It Matters for RAG Builders
It provides a critical continuity layer for RAG/AI stacks by preserving project context, decisions, and handoffs locally, enabling agents to recall relevant information across sessions without relying on ephemeral chat history.
