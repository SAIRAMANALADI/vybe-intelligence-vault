## Summary
Unofficial API for Yahoo Finance providing financial market data access via CLI, MCP, and Agent Skill interfaces. Enables real-time and historical stock data retrieval, including quotes, charts, and fundamentals for AI-driven applications.

- CLI and programmatic interfaces for flexible integration

- TypeScript-first with strong typing and auto-completion
