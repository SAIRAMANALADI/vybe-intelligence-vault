## Summary
StratumCode is a local-first software engineering agent that follows a rigorous, evidence-driven workflow for code changes, ensuring every step is auditable, reversible, and transparent. It breaks down tasks into structured phases like investigation, design, planning, implementation, and validation, enforcing hard constraints via runtime checks.

## Key Features
- Structured, multi-phase workflow with explicit state transitions and hard runtime constraints
- Evidence-based task analysis, investigation, and design with acceptance criteria and behavior contracts
- Patch planning and atomic, transactional code modifications with rollback support
- LSP and MCP integration for deep code intelligence and external tooling
- Time-line event tracking, usage statistics, and deterministic validation of changes

## Why It Matters for RAG Builders
StratumCode ensures AI-driven code changes are transparent, auditable, and reversible, making it essential for building trustworthy RAG pipelines and AI engineering workflows.
