## Summary
Skill Forge CLI is a command-line tool that standardizes, validates, and publishes AI agent skills across multiple frameworks (Claude, OpenAI, LangChain) with automated secret scrubbing, multi-format export, and versioned releases.

## Key Features
- Universal skill parser supporting multiple agent frameworks (Claude, OpenAI, LangChain)
- Automated secret and credential scrubbing with regex and ML-enhanced detection
- Multi-format export (JSON, YAML, Markdown, Python, TypeScript) for cross-platform compatibility
- Intelligent channel recommender for optimal skill distribution (GitHub, ClawHub, NPM, PyPI)
- Semantic versioning with automatic changelog generation and version bumping

## Why It Matters for RAG Builders
It streamlines the process of packaging and deploying AI skills across frameworks, reducing fragmentation and ensuring secure, versioned releases for RAG and agent-based systems.
