## Summary
TIMPS Swarm is an MCP-based framework that deploys 161 specialized AI agents into coding tools like Claude Code, Cursor, and VS Code as parallel sub-agents or MCP tools. It enables local-first, BYOK (Bring Your Own Keys) AI workflows with zero backend or API key requirements, leveraging Ollama or external LLM providers for offline or cloud-based operations.

## Key Features
- Deploys 161 specialist AI agents across 9 categories (e.g., security, diagnostics, workflow automation) into IDEs as MCP tools and parallel sub-agents.
- Zero-setup security audits (CVE detection, secret scanning) via `npx timps-swarm audit ./` with no backend or API keys required.
- Idempotent and reversible MCP server configuration for 11+ IDEs (Claude Code, Cursor, VS Code, etc.) with explicit environment variable handling.
- Local-first operation with Ollama or pluggable LLM providers (Gemini, Anthropic, OpenAI, Groq) for offline or cloud-based AI workflows.
- Built-in self-critic agent for quality scoring and iterative refinement, enabling closed-loop agent collaboration.
