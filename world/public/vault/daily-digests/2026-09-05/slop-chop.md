## Summary
slop-chop is a CLI tool and library that detects and removes AI-generated writing patterns (e.g., em-dashes, stock phrases, structural tells) from text using deterministic rules and optional LLM-based rewrites. It supports multiple integrations including VS Code, JetBrains, Neovim, Obsidian, and CI/CD pipelines.

## Key Features
- Two-pass cleaning: deterministic rules pass followed by optional LLM rewrite pass
- Supports custom profiles and presets for tailored text cleaning
- Integrates with IDEs (VS Code, JetBrains, Neovim), browsers, and CI/CD pipelines
- Provides scoring metrics to quantify AI writing patterns in text
- Offers CLI, library, HTTP API, and plugin-based usage

## Why It Matters for RAG Builders
It provides a reliable, automated way to clean AI-generated text patterns for RAG pipelines, ensuring higher-quality, human-like outputs without manual intervention.
