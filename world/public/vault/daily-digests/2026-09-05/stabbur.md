## Summary
stabbur is a tool for building and maintaining a local library of LLM models, aggregating models from Hugging Face, Ollama, and LM Studio. It provides a Typer CLI and a browser-based chat UI (Loft) for managing, running, and interacting with models locally, with support for vision, audio, and tool-aware chat.

## Key Features
- Aggregates models from multiple sources (Hugging Face, Ollama, LM Studio) into a single local library
- Supports GGUF, MLX, and voice models with automatic runtime detection and execution
- Provides both a Typer CLI and a browser-based chat UI (Loft) for model interaction
- Enables offline model serving with OpenAI-compatible API endpoints
- Includes a Chrome side panel extension for seamless integration with web browsing

## Why It Matters for RAG Builders
stabbur enables RAG builders to maintain a local, offline library of models for privacy, cost efficiency, and reliability, while providing flexible serving and interaction options.
