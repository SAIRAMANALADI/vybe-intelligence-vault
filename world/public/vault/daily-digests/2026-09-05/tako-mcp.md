## Summary
Tako MCP is a hosted Model Context Protocol (MCP) server that provides agents with industry-leading live web search and licensed proprietary data, including financials, macroeconomic indicators, and sports data. It enables agents to search, answer, visualize, and fetch structured data with citations and inline charts.

## Key Features
- Industry-leading live web search with licensed proprietary data (financials, macroeconomics, sports, etc.)
- Citation-backed answers with inline charts and structured data visualization
- Free tier with 10 requests/minute and optional OAuth/Bearer token authentication for full access
- Supports multi-step research via Tako's Answer Agent (opt-in)
- One-click installation across multiple IDEs and clients (Claude, VS Code, Cursor, etc.)
