## Summary
BizRadar AI is an AI-powered startup intelligence agent that transforms startup ideas into structured business intelligence reports using a hand-built ReAct agent, parallel tool execution, real-time web search, and RAG-grounded document analysis. It prevents hallucinations by grounding answers in retrieved documents and live web sources.

## Key Features
- Hand-built ReAct agent loop for structured reasoning and tool execution
- Parallel tool execution via ThreadPoolExecutor for faster analysis
- Real-time web search with cited sources via Tavily API
- RAG-grounded document analysis using ChromaDB for accurate answers
- Sliding window memory for conversation context and PDF document ingestion

## Why It Matters for RAG Builders
BizRadar AI provides a critical framework for building trustworthy, hallucination-free RAG systems that ground answers in both live web sources and user-provided documents, essential for AI stack builders requiring reliable business intelligence.
