# Live Intelligence Layer

Welcome to the live intelligence portal. This layer organizes real-time signals, trending assets, new research, product updates, and developer tracks collected from public feeds. 

These lists are automatically regenerated every 3 hours.

## Intelligence Subsections

*   [Latest AI Signals](latest-ai-signals.md) - The newest resources sorted by date and score.
*   [Best of This Week](best-of-this-week.md) - Weekly highlights across engineering, web development, and startup builders.
*   [Trending Tools](trending-tools.md) - High usefulness/quality score tools.
*   [Trending Repositories](trending-repos.md) - Active codebases and developer packages.
*   [Research Watch](research-watch.md) - Papers, benchmarks, and model evals.
*   [Product Watch](product-watch.md) - Launch templates, chatbot widgets, and SaaS boilerplates.
*   [Startup Watch](startup-watch.md) - Startup validation resources, SaaS guides, and market opportunities.
*   [Web Development Watch](webdev-watch.md) - Frontend designs, creative 3D web libraries, and animations.
